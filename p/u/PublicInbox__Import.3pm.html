PublicInbox::Import(3) Documentación de Perl aportada por el usuario PublicInbox::Import(3)

NOMBRE

PublicInbox::Import - importador de mensajes para buzones públicos v1

VERSIÓN

versión 1.0

SINOPSIS

use PublicInbox::Eml;
# PublicInbox::Eml existe a partir de public-inbox 1.5.0,
# Email::MIME se usó en versiones anteriores
use PublicInbox::Git;
use PublicInbox::Import;
chomp(my $git_dir = `git rev-parse --git-dir`);
$git_dir or die "GIT_DIR= debe especificarse\n";
my $git = PublicInbox::Git->new($git_dir);
my @committer = ('inbox', 'inbox@example.org');
my $im = PublicInbox::Import->new($git, @committer);
# para añadir un mensaje:
my $message = "De: <u\@example.org>\n".
        "Asunto: mensaje de prueba \n" .
        "Fecha: Thu, 01 Jan 1970 00:00:00 +0000\n".
        "Message-ID: <m\@example.org>\n".
        "\nmensaje de prueba";
my $parsed = PublicInbox::Eml->new($message);
my $ret = $im->add($parsed);
if (!defined $ret) {
        warn "duplicado: ", $parsed->header_raw('Message-ID'), "\n";
} else {
        print "importado en la marca $ret\n";
}
$im->done;
# para eliminar un mensaje
my $junk = PublicInbox::Eml->new($message);
my ($mark, $orig) = $im->remove($junk);
if ($mark eq 'MISSING') {
        print "no encontrado\n";
} elsif ($mark eq 'MISMATCH') {
        print "El mensaje existe pero no coincide\n\n",
                $orig->as_string, "\n\n";
} else {
        print "eliminado en la marca $mark\n\n",
                $orig->as_string, "\n";
}
$im->done;

DESCRIPCIÓN

Un importador y eliminador para buzones públicos que toma mensajes de "PublicInbox::Eml" o Email::MIME como entrada y los almacena en un repositorio git como se documenta en https://public-inbox.org/public-inbox-v1-format.txt, excepto que no permite Message-IDs duplicados.

Requiere que estén instalados git(1) y git-fast-import(1).

MÉTODOS

new

my $im = PublicInbox::Import->new($git, @committer);

Inicializa un nuevo objeto PublicInbox::Import.

add

my $parsed = PublicInbox::Eml->new($message);
$im->add($parsed);

Añade un mensaje al repositorio git. Esto adquirirá "$GIT_DIR/ssoma.lock" e iniciará git-fast-import(1) si es necesario.

Los mensajes añadidos no serán visibles para otros procesos hasta que se llame a "done", pero se puede llamar a "remove" sobre ellos.

remove

my $junk = PublicInbox::Eml->new($message);
my ($code, $orig) = $im->remove($junk);

Elimina un mensaje del repositorio. En caso de éxito, devuelve un código numérico prefijado por ':' que representa la marca de git-fast-import y el mensaje original como un objeto PublicInbox::Eml (o Email::MIME). Si el mensaje no se pudo encontrar, el código es "MISSING" y el mensaje original es undef. Si hay una discrepancia donde se coincide con el "Message-ID" pero el asunto y el cuerpo no coinciden, el código devuelto es "MISMATCH" y se devuelve el mensaje en conflicto como orig.

done

Finaliza el git-fast-import(1) y desbloquea el repositorio. Llamar a esto es necesario para finalizar los cambios en un repositorio.
