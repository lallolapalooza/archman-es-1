PublicInbox::Git(3) Documentación aportada por el usuario de Perl PublicInbox::Git(3)

NOMBRE

PublicInbox::Git - envoltorio de git

VERSIÓN

versión 1.0

SINOPSIS

use PublicInbox::Git;
chomp(my $git_dir = `git rev-parse --git-dir`);
$git_dir or die "GIT_DIR= debe especificarse\n";
my $git = PublicInbox::Git->new($git_dir);

DESCRIPCIÓN

API inestable fuera del método "new". Requiere que git(1) esté instalado.

MÉTODOS

new

my $git = PublicInbox::Git->new($git_dir);

Inicializa un nuevo objeto PublicInbox::Git para usar con PublicInbox::Import. Este es el único método de API pública que admitimos. Todo lo demás en este módulo está sujeto a cambios.

VER TAMBIÉN

Git, PublicInbox::Import
