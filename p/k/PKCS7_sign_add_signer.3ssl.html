PKCS7_sign_add_signer(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS7_SIGN_ADD_SIGNER(3ssl) OpenSSL PKCS7_SIGN_ADD_SIGNER(3ssl)

NOMBRE

PKCS7_sign_add_signer, PKCS7_add_certificate, PKCS7_add_crl - añadir información a la estructura PKCS7

SINOPSIS

#include <openssl/pkcs7.h>
PKCS7_SIGNER_INFO *PKCS7_sign_add_signer(PKCS7 *p7, X509 *signcert,
                                         EVP_PKEY *pkey, const EVP_MD *md, int flags);
int PKCS7_add_certificate(PKCS7 *p7, X509 *cert);
int PKCS7_add_crl(PKCS7 *p7, X509_CRL *crl);

DESCRIPCIÓN

PKCS7_sign_add_signer() añade un firmante con el certificado signcert y la clave privada pkey usando el digest de mensaje md a una estructura de datos firmados PKCS7 p7.

La estructura PKCS7 debe obtenerse de una llamada inicial a PKCS7_sign() con la bandera PKCS7_PARTIAL establecida o en el caso de volver a firmar una estructura de datos firmada PKCS#7 válida.

Si el parámetro md es NULL, se utilizará el digest por defecto para el algoritmo de clave pública.

A menos que la bandera PKCS7_REUSE_DIGEST esté establecida, la estructura PKCS7 devuelta no está completa y debe ser finalizada ya sea mediante streaming (si es aplicable) o una llamada a PKCS7_final().

NOTAS

El propósito principal de esta función es proporcionar un control más fino sobre una estructura de datos firmados PKCS#7 donde los valores por defecto de la función más simple PKCS7_sign() no son apropiados. Por ejemplo, si se necesitan múltiples firmantes o algoritmos de digest no predeterminados.

Cualquiera de las siguientes banderas (combinadas con OR) puede ser pasada en el parámetro flags.

Si se establece PKCS7_REUSE_DIGEST, se intentará copiar el valor del digest de contenido de la estructura PKCS7: para añadir un firmante a una estructura existente. Ocurrirá un error si no se puede encontrar un valor de digest coincidente para copiar. La estructura PKCS7 devuelta será válida y finalizada cuando se establezca esta bandera.

Si se establece PKCS7_PARTIAL además de PKCS7_REUSE_DIGEST, la estructura PKCS7_SIGNER_INO no se finalizará para que se puedan añadir atributos adicionales. En este caso, se necesita una llamada explícita a PKCS7_SIGNER_INFO_sign() para finalizarla.

Si se establece PKCS7_NOCERTS, el certificado del firmante no se incluirá en la estructura PKCS7; sin embargo, el certificado del firmante aún debe proporcionarse en el parámetro signcert. Esto puede reducir el tamaño de la firma si el certificado del firmante se puede obtener por otros medios: por ejemplo, un mensaje firmado previamente.

La estructura signedData incluye varios PKCS#7 authenticatedAttributes, incluyendo la hora de la firma, el tipo de contenido PKCS#7 y la lista de cifradores soportados en un atributo SMIMECapabilities. Si se establece PKCS7_NOATTR, no se utilizarán atributos authenticatedAttributes. Si se establece PKCS7_NOSMIMECAP, solo se omitirán los SMIMECapabilities.

Si está presente, el atributo SMIMECapabilities indica soporte para los siguientes algoritmos: triple DES, RC2 de 128 bits, RC2 de 64 bits, DES y RC2 de 40 bits. Si alguno de estos algoritmos está deshabilitado, no se incluirá.

PKCS7_sign_add_signers() devuelve un puntero interno a la estructura PKCS7_SIGNER_INFO recién añadida, que puede ser utilizada para establecer atributos adicionales antes de que sea finalizada.

PKCS7_add_certificate() añade a la estructura PKCS7 p7 el certificado cert, que puede ser un certificado de entidad final (firmante) o un certificado de CA útil para la construcción de la cadena. Esto se hace internamente por PKCS7_sign_ex(3) y funciones de firma similares. Puede ser necesario usarlo antes de llamar a PKCS7_verify(3) para proporcionar los certificados faltantes necesarios para la verificación.

PKCS7_add_crl() añade la CRL crl a la estructura PKCS7 p7. Esto puede ser llamado para proporcionar información de estado del certificado a incluir al firmar o para usar al verificar la estructura PKCS7.

VALORES DE RETORNO

PKCS7_sign_add_signers() devuelve un puntero interno a la estructura PKCS7_SIGNER_INFO recién añadida o NULL si ocurre un error.

PKCS7_add_certificate() y PKCS7_add_crl() devuelven 1 en caso de éxito, 0 en caso de error.

VER TAMBIÉN

ERR_get_error(3), PKCS7_sign_ex(3), PKCS7_final(3), PKCS7_verify(3)

HISTORIA
