PKCS12_SAFEBAG_get1_cert(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_SAFEBAG_GET1_CERT(3ssl) OpenSSL PKCS12_SAFEBAG_GET1_CERT(3ssl)

NOMBRE

PKCS12_SAFEBAG_get0_attr, PKCS12_SAFEBAG_get0_type, PKCS12_SAFEBAG_get_nid, PKCS12_SAFEBAG_get_bag_nid, PKCS12_SAFEBAG_get0_bag_obj, PKCS12_SAFEBAG_get0_bag_type, PKCS12_SAFEBAG_get1_cert_ex, PKCS12_SAFEBAG_get1_cert, PKCS12_SAFEBAG_get1_crl_ex, PKCS12_SAFEBAG_get1_crl, PKCS12_SAFEBAG_get0_safes, PKCS12_SAFEBAG_get0_p8inf, PKCS12_SAFEBAG_get0_pkcs8 - Obtener objetos de un PKCS12 safeBag

SINOPSIS

#include <openssl/pkcs12.h>
const ASN1_TYPE *PKCS12_SAFEBAG_get0_attr(const PKCS12_SAFEBAG *bag,
                                          int attr_nid);
const ASN1_OBJECT *PKCS12_SAFEBAG_get0_type(const PKCS12_SAFEBAG *bag);
int PKCS12_SAFEBAG_get_nid(const PKCS12_SAFEBAG *bag);
int PKCS12_SAFEBAG_get_bag_nid(const PKCS12_SAFEBAG *bag);
const ASN1_TYPE *PKCS12_SAFEBAG_get0_bag_obj(const PKCS12_SAFEBAG *bag);
const ASN1_OBJECT *PKCS12_SAFEBAG_get0_bag_type(const PKCS12_SAFEBAG *bag);
X509_CRL *PKCS12_SAFEBAG_get1_cert_ex(const PKCS12_SAFEBAG *bag,
                                      OSSL_LIB_CTX *libctx, const char *propq);
X509 *PKCS12_SAFEBAG_get1_cert(const PKCS12_SAFEBAG *bag);
X509_CRL *PKCS12_SAFEBAG_get1_crl_ex(const PKCS12_SAFEBAG *bag,
                                     OSSL_LIB_CTX *libctx, const char *propq);
X509_CRL *PKCS12_SAFEBAG_get1_crl(const PKCS12_SAFEBAG *bag);
const STACK_OF(PKCS12_SAFEBAG) *PKCS12_SAFEBAG_get0_safes(const PKCS12_SAFEBAG *bag);
const PKCS8_PRIV_KEY_INFO *PKCS12_SAFEBAG_get0_p8inf(const PKCS12_SAFEBAG *bag);
const X509_SIG *PKCS12_SAFEBAG_get0_pkcs8(const PKCS12_SAFEBAG *bag);

DESCRIPCIÓN

PKCS12_SAFEBAG_get0_attr() obtiene el valor del atributo correspondiente al attr_nid.

PKCS12_SAFEBAG_get0_type() obtiene el tipo safeBag como un OID, mientras que PKCS12_SAFEBAG_get_nid() obtiene el tipo safeBag como un NID, que podría ser NID_certBag, NID_crlBag, NID_keyBag, NID_secretBag, NID_safeContentsBag o NID_pkcs8ShroudedKeyBag.

PKCS12_SAFEBAG_get_bag_nid() obtiene el tipo del objeto contenido dentro del PKCS12_SAFEBAG. Esto corresponde al tipo de bolsa para la mayoría de las bolsas, pero puede ser arbitrario para las secretBags. PKCS12_SAFEBAG_get0_bag_type() obtiene este tipo como un OID.

PKCS12_SAFEBAG_get0_bag_obj() recupera el objeto contenido dentro del safeBag.

PKCS12_SAFEBAG_get1_cert_ex() y PKCS12_SAFEBAG_get1_crl_ex() devuelven nuevos objetos X509 o X509_CRL del elemento en el safeBag. libctx y propq se utilizan al buscar algoritmos y pueden establecerse opcionalmente a NULL.

PKCS12_SAFEBAG_get1_cert() y PKCS12_SAFEBAG_get1_crl() son lo mismo que PKCS12_SAFEBAG_get1_cert_ex() y PKCS12_SAFEBAG_get1_crl_ex() y establecen libctx y prop a NULL. Esto utilizará el contexto de biblioteca predeterminado.

PKCS12_SAFEBAG_get0_p8inf() y PKCS12_SAFEBAG_get0_pkcs8() devuelven el objeto PKCS8 de un PKCS8shroudedKeyBag o un keyBag.

PKCS12_SAFEBAG_get0_safes() recupera el conjunto de safeBags contenidos dentro de un safeContentsBag.

VALORES DE RETORNO

PKCS12_SAFEBAG_get_nid() y PKCS12_SAFEBAG_get_bag_nid() devuelven el NID del safeBag o del objeto bolsa, o -1 si no hay un NID correspondiente. Otras funciones devuelven un objeto válido del tipo especificado o NULL si ocurrió un error.

VER TAMBIÉN

PKCS12_create(3), PKCS12_add_safe(3), PKCS12_add_safes(3)

HISTORIA

Las funciones PKCS12_SAFEBAG_get1_cert_ex() y PKCS12_SAFEBAG_get1_crl_ex() se añadieron en OpenSSL 3.2.
