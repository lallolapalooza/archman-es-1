NOMBRE

PkgConfig::LibPkgConf - Interfaz a la interfaz de archivos .pc a través de libpkgconf

SINOPSIS

use PkgConfig::LibPkgConf;

if(pkgconf_exists('libarchive'))
{
  my $version = pkgconf_version('libarchive');
  my $cflags  = pkgconf_cflags('libarchive');
  my $libs    = pkgconf_libs('libarchive');
}

DESCRIPCIÓN

Muchas bibliotecas en lenguajes compilados como C o C++ proporcionan archivos ".pc" para especificar las banderas necesarias para compilar y enlazar contra esas bibliotecas. Tradicionalmente, el programa de línea de comandos "pkg-config" se utiliza para consultar estos archivos. Este módulo proporciona una API a nivel de Perl utilizando "libpkgconf" a estos archivos.

Este módulo proporciona una interfaz simplificada para obtener la existencia, la versión, las banderas cflags y las banderas de biblioteca necesarias para compilar contra un paquete, utilizando la configuración de compilación predeterminada de "pkgconf". Para una interfaz más potente, pero complicada, consulte PkgConfig::LibPkgConf::Client. Además, PkgConfig::LibPkgConf::Util proporciona algunas funciones de utilidad útiles que también son proporcionadas por "pkgconf".

FUNCIONES

pkgconf_exists

my $bool = pkgconf_exists $package_name;

Devuelve verdadero si el paquete está disponible.

Exportado por defecto.

pkgconf_version

my $version = pkgconf_version $package_name;

Devuelve la versión del paquete, si existe. Lanzará una excepción si no se encuentra.

Exportado por defecto.

pkgconf_cflags

my $cflags = pkgconf_cflags $package_name;

Devuelve las banderas del compilador para el paquete, si existe. Lanzará una excepción si no se encuentra.

Exportado por defecto.

pkgconf_cflags_static

my $cflags = pkgconf_cflags_static $package_name;

Devuelve las banderas del compilador estático para el paquete, si existe. Lanzará una excepción si no se encuentra.

pkgconf_libs

my $libs = pkgconf_libs $package_name;

Devuelve las banderas de la biblioteca del enlazador para el paquete, si existe. Lanzará una excepción si no se encuentra.

Exportado por defecto.

pkgconf_libs_static

my $libs = pkgconf_libs_static $package_name;

Devuelve las banderas de la biblioteca estática del enlazador para el paquete, si existe. Lanzará una excepción si no se encuentra.

VER TAMBIÉN

El mejor punto de entrada a la interfaz de bajo nivel de "pkgconf" se puede encontrar a través de PkgConfig::LibPkgConf::Client.

Las alternativas incluyen:

PkgConfig
Implementación pura de Perl de "pkg-config" que se puede usar desde la línea de comandos, o como una API desde Perl. No requiere pkg-config en su PATH, por lo que es una dependencia segura para módulos CPAN.
ExtUtils::PkgConfig
Envoltura para la interfaz de línea de comandos "pkg-config". Este módulo fallará al instalarse si "pkg-config" no se puede encontrar en el "PATH", por lo que no es seguro usarlo como dependencia si desea que su módulo CPAN funcione en plataformas donde "pkg-config" no está instalado.
Alien::Base
Proporciona herramientas para construir bibliotecas no-Perl y hacerlas dependencias para sus módulos CPAN, incluso en plataformas donde las bibliotecas no-Perl no están ya instaladas. Incluye ganchos para explorar los archivos ".pc" de "pkg-config" utilizando "pkg-config" o PkgConfig.
