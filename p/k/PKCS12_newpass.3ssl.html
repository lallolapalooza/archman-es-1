PKCS12_newpass(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_NEWPASS(3ssl) OpenSSL PKCS12_NEWPASS(3ssl)

NOMBRE

PKCS12_newpass - cambia la contraseña de una estructura PKCS12

SINOPSIS

#include <openssl/pkcs12.h>
int PKCS12_newpass(PKCS12 *p12, const char *oldpass, const char *newpass);

DESCRIPCIÓN

PKCS12_newpass() cambia la contraseña de una estructura PKCS12.

p12 es un puntero a una estructura PKCS12. oldpass es la contraseña existente y newpass es la nueva contraseña.

Cada uno de oldpass y newpass se interpreta independientemente como una cadena en codificación UTF-8. Si no es UTF-8 válido, se asume que es ISO8859-1 en su lugar.

En particular, esto significa que las contraseñas en el conjunto de caracteres de la localización (o página de códigos en Windows) pueden necesitar ser convertidas a UTF-8 antes de su uso. Esto puede incluir contraseñas de archivos de texto locales, o entradas de la terminal o línea de comandos. Consulte la documentación de UI_OpenSSL(3), por ejemplo.

Si la estructura PKCS12 no tiene contraseña, entonces debes usar la cadena vacía "" para oldpass. Usar NULL para oldpass resultará en un fallo de PKCS12_newpass().

Si se utiliza la contraseña incorrecta para oldpass, la función fallará, con un error de verificación MAC. En casos raros, la estructura PKCS12 no contiene un MAC: en este caso, normalmente fallará con un error de relleno de descifrado.

VALORES DE RETORNO

PKCS12_newpass() devuelve 1 en caso de éxito o 0 en caso de fallo. Las aplicaciones pueden recuperar el último error de PKCS12_newpass() con ERR_get_error().

EJEMPLOS

Este ejemplo carga un archivo PKCS#12, cambia su contraseña y escribe el resultado en un nuevo archivo.

#include <stdio.h>
#include <stdlib.h>
#include <openssl/pem.h>
#include <openssl/err.h>
#include <openssl/pkcs12.h>
int main(int argc, char **argv)
{
    FILE *fp;
    PKCS12 *p12;
    if (argc != 5) {
        fprintf(stderr, "Uso: pkread p12file contraseña nuevacontraseña opfile\n");
        return 1;
    }
    if ((fp = fopen(argv[1], "rb")) == NULL) {
        fprintf(stderr, "Error al abrir el archivo %s\n", argv[1]);
        return 1;
    }
    p12 = d2i_PKCS12_fp(fp, NULL);
    fclose(fp);
    if (p12 == NULL) {
        fprintf(stderr, "Error al leer el archivo PKCS#12\n");
        ERR_print_errors_fp(stderr);
        return 1;
    }
    if (PKCS12_newpass(p12, argv[2], argv[3]) == 0) {
        fprintf(stderr, "Error al cambiar la contraseña\n");
        ERR_print_errors_fp(stderr);
        PKCS12_free(p12);
        return 1;
    }
    if ((fp = fopen(argv[4], "wb")) == NULL) {
        fprintf(stderr, "Error al abrir el archivo %s\n", argv[4]);
        PKCS12_free(p12);
        return 1;
    }
    i2d_PKCS12_fp(fp, p12);
    PKCS12_free(p12);
    fclose(fp);
    return 0;
}

ERRORES

La contraseña es una cadena terminada en NULL que se convierte a forma Unicode internamente. Como resultado, algunas contraseñas no pueden ser proporcionadas a esta función.
