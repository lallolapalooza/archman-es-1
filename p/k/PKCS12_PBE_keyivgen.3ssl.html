PKCS12_PBE_keyivgen(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_PBE_KEYIVGEN(3ssl) OpenSSL PKCS12_PBE_KEYIVGEN(3ssl)

NOMBRE

PKCS12_PBE_keyivgen, PKCS12_PBE_keyivgen_ex, PKCS12_pbe_crypt, PKCS12_pbe_crypt_ex - Cifrado basado en contraseña PKCS#12

SINOPSIS

#include <openssl/evp.h>
int PKCS12_PBE_keyivgen(EVP_CIPHER_CTX *ctx, const char *pass, int passlen,
                        ASN1_TYPE *param, const EVP_CIPHER *cipher,
                        const EVP_MD *md_type, int en_de);
int PKCS12_PBE_keyivgen_ex(EVP_CIPHER_CTX *ctx, const char *pass, int passlen,
                           ASN1_TYPE *param, const EVP_CIPHER *cipher,
                           const EVP_MD *md_type, int en_de,
                           OSSL_LIB_CTX *libctx, const char *propq);
unsigned char *PKCS12_pbe_crypt(const X509_ALGOR *algor,
                                const char *pass, int passlen,
                                const unsigned char *in, int inlen,
                                unsigned char **data, int *datalen,
                                int en_de);
unsigned char *PKCS12_pbe_crypt_ex(const X509_ALGOR *algor,
                                   const char *pass, int passlen,
                                   const unsigned char *in, int inlen,
                                   unsigned char **data, int *datalen,
                                   int en_de, OSSL_LIB_CTX *libctx,
                                   const char *propq);

DESCRIPCIÓN

PKCS12_PBE_keyivgen() y PKCS12_PBE_keyivgen_ex() toman una contraseña pass de longitud passlen, parámetros param y una función de resumen de mensajes md_type y realizan una derivación de clave según PKCS#12. La clave resultante se utiliza luego para inicializar el contexto de cifrado ctx con un cifrador cipher para cifrado (en_de=1) o descifrado (en_de=0).

PKCS12_PBE_keyivgen_ex() también permite a la aplicación especificar un contexto de biblioteca libctx y una consulta de propiedad propq para seleccionar implementaciones de algoritmos apropiadas.

PKCS12_pbe_crypt() y PKCS12_pbe_crypt_ex() cifrarán o descifrarán un búfer basándose en el algoritmo en algor y la contraseña pass de longitud passlen. La entrada proviene de in de longitud inlen y la salida va a un búfer asignado con malloc devuelto en *data de longitud datalen. La operación está determinada por en_de, cifrado (en_de=1) o descifrado (en_de=0).

PKCS12_pbe_crypt_ex() permite a la aplicación especificar un contexto de biblioteca libctx y una consulta de propiedad propq para seleccionar implementaciones de algoritmos apropiadas.

pass es la contraseña utilizada en la derivación de longitud passlen. pass es un parámetro opcional y puede ser NULL. Si passlen es -1, la función calculará la longitud de pass usando strlen().

salt es la sal utilizada en la derivación de longitud saltlen. Si salt es NULL, saltlen debe ser 0. La función no intentará calcular la longitud de la salt porque no se supone que termine en NULL.

iter es el recuento de iteraciones y su valor debe ser mayor o igual que 1. RFC 2898 sugiere un recuento de iteraciones de al menos 1000. Cualquier iter menor que 1 se trata como una única iteración.

digest es la función de resumen de mensajes utilizada en la derivación.

Las funciones que terminan en _ex() toman los parámetros opcionales libctx y propq que se utilizan para seleccionar implementaciones de algoritmos apropiadas.

NOTAS

Las funciones se utilizan típicamente en PKCS#12 para cifrar objetos.

Estas funciones no hacen suposiciones sobre la contraseña dada. Simplemente se tratará como una secuencia de bytes.

VALORES DE RETORNO

PKCS12_PBE_keyivgen(), PKCS12_PBE_keyivgen_ex() devuelven 1 si tienen éxito o 0 si hay un error.

PKCS12_pbe_crypt() y PKCS12_pbe_crypt_ex() devuelven un búfer que contiene la salida o NULL si ocurrió un error.

CONFORME A

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VER TAMBIÉN

HISTORIA
