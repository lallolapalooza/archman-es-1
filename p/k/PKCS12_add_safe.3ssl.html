PKCS12_add_safe(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_ADD_SAFE(3ssl) OpenSSL PKCS12_ADD_SAFE(3ssl)

NOMBRE

PKCS12_add_safe, PKCS12_add_safe_ex, PKCS12_add_safes, PKCS12_add_safes_ex - Crear y añadir objetos a una estructura PKCS#12

SINOPSIS

#include <openssl/pkcs12.h>
int PKCS12_add_safe(STACK_OF(PKCS7) **psafes, STACK_OF(PKCS12_SAFEBAG) *bags,
                   int safe_nid, int iter, const char *pass);
int PKCS12_add_safe_ex(STACK_OF(PKCS7) **psafes, STACK_OF(PKCS12_SAFEBAG) *bags,
                       int safe_nid, int iter, const char *pass,
                       OSSL_LIB_CTX *ctx, const char *propq);
PKCS12 *PKCS12_add_safes(STACK_OF(PKCS7) *safes, int p7_nid);
PKCS12 *PKCS12_add_safes_ex(STACK_OF(PKCS7) *safes, int p7_nid,
                            OSSL_LIB_CTX *ctx, const char *propq);

DESCRIPCIÓN

PKCS12_add_safe() crea una nueva contentInfo PKCS7 que contiene los PKCS12_SAFEBAGs proporcionados y la añade a un conjunto de contentInfos PKCS7. Su tipo depende del valor de safe_nid:

  • Si safe_nid es -1, se crea una contentInfo PKCS7 de tipo data.
  • Si safe_nid es un NID de algoritmo PBE válido, se crea una contentInfo PKCS7 de tipo encryptedData. El algoritmo utiliza pass como contraseña y iter como recuento de iteraciones. Si iter es cero, se utiliza un valor por defecto de 2048 para el recuento de iteraciones.
  • Si safe_nid es 0, se crea una contentInfo PKCS7 de tipo encryptedData utilizando un algoritmo de cifrado por defecto, actualmente NID_pbe_WithSHA1And3_Key_TripleDES_CBC.

PKCS12_add_safe_ex() es idéntica a PKCS12_add_safe() pero permite un contexto de biblioteca ctx y una consulta de propiedades propq para seleccionar implementaciones de algoritmos.

PKCS12_add_safes() crea una estructura PKCS12 que contiene el conjunto proporcionado de contentInfos PKCS7. Los safes se encapsulan primero dentro de una contentInfo PKCS7 de tipo p7_nid. Actualmente, el único tipo admitido es NID_pkcs7_data.

PKCS12_add_safes_ex() es idéntica a PKCS12_add_safes() pero permite un contexto de biblioteca ctx y una consulta de propiedades propq para seleccionar implementaciones de algoritmos.

NOTAS

PKCS12_add_safe() realiza suposiciones sobre la codificación de la frase de contraseña dada. Consulte passphrase-encoding(7) para más información.

VALORES DE RETORNO

PKCS12_add_safe() devuelve un valor de 1 indicando éxito o 0 en caso de fallo.

PKCS12_add_safes() devuelve una estructura PKCS12 válida o NULL si ocurrió un error.

CONFORME A

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VER TAMBIÉN

PKCS12_create(3)

HISTORIA

PKCS12_add_safe_ex() y PKCS12_add_safes_ex() se añadieron en OpenSSL 3.0.
