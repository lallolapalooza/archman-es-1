PkgConfig::LibPkgConf::Client(3) Documentación de Perl aportada por el usuario PkgConfig::LibPkgConf::Client(3)

NOMBRE

PkgConfig::LibPkgConf::Client - Consultar bibliotecas instaladas para compilar y enlazar software

SINOPSIS

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
$client->env;

my $pkg = $client->find('libarchive');
my $cflags = $pkg->cflags;
my $libs = $pkg->libs;

DESCRIPCIÓN

Los objetos PkgConfig::LibPkgConf::Client almacenan toda la información necesaria para "libpkgconf", permitiendo que múltiples instancias se ejecuten en paralelo.

CONSTRUCTOR

new

my $client = PkgConfig::LibPkgConf::Client->new(%opts);
my $client = PkgConfig::LibPkgConf::Client->new(\%opts);

Crea una instancia de PkgConfig::LibPkgConf::Client. Las opciones posibles incluyen:

path
La ruta de búsqueda para encontrar archivos ".pc". Esto puede especificarse como una cadena con el carácter separador de ruta apropiado, o como una referencia a una lista. Esto anulará los valores predeterminados compilados en "pkgconf" y las variables de entorno "PKG_CONFIG_PATH" o "PKG_CONFIG_LIBDIR".
filter_lib_dirs
Lista de directorios para filtrar bibliotecas. Esto anula el valor predeterminado compilado en "pkgconf" y la variable de entorno "PKG_CONFIG_SYSTEM_LIBRARY_PATH".
filter_include_dirs
Lista de directorios para filtrar includes. Esto anula el valor predeterminado compilado en "pkgconf" y la variable de entorno "PKG_CONFIG_SYSTEM_INCLUDE_PATH".

variables de entorno tenidas en cuenta:

PKG_CONFIG_PATH
PKG_CONFIG_LIBDIR
PKG_CONFIG_SYSTEM_LIBRARY_PATH
PKG_CONFIG_SYSTEM_INCLUDE_PATH
PKG_CONFIG_ALLOW_SYSTEM_CFLAGS
PKG_CONFIG_ALLOW_SYSTEM_LIBS

ATRIBUTOS

path

my @path = $client->path;

La ruta de búsqueda para encontrar archivos ".pc".

filter_lib_dirs

my @dirs = $client->filter_lib_dirs;

Lista de directorios para filtrar bibliotecas.

filter_include_dirs

my @dirs = $client->filter_include_dirs;

Lista de directorios para filtrar includes.

sysroot_dir

my $dir = $client->sysroot_dir;
$client->sysroot_dir($dir);

Obtiene o establece el directorio sysroot.

buildroot_dir

my $dir = $client->buildroot_dir;
$client->buildroot_dir($dir);

Obtiene o establece el directorio buildroot.

maxdepth

my $int = $client->maxdepth;
$client->maxdepth($int);

Obtiene o establece la profundidad máxima de dependencia. Esto es 2000 por defecto.

MÉTODOS

env

my $client->env;

Este método carga la configuración para el objeto cliente desde el entorno utilizando las variables de entorno estándar "pkg-config" o "pkgconf". Respeta la siguiente lista de variables de entorno:

PKG_CONFIG_LOG

find

my $pkg = $client->find($package_name);

Busca en el archivo <.pc> el paquete con el nombre de paquete dado $package_name. Si lo encuentra, devuelve una instancia de PkgConfig::LibPkgConf::Package. Si no lo encuentra, devuelve "undef".

package_from_file

my $pkg = $client->package_from_file($filename);

Carga el archivo <.pc> específico.

scan_all

$client->scan_all(sub {
  my($client, $package) = @_;
  ...
  return $bool;
});

Itera sobre todos los paquetes y llama a la subrutina dada referenciada para cada paquete. $package es una instancia de PkgConfig::LibPkgConf::Package. El escaneo continuará mientras se devuelva un valor no verdadero (como $bool).

global

$client->global($key => $value);
my $value = $client->global($key);

Define u obtiene la variable global.

error

my $client->error($message);

Se llama cuando "libpkgconf" se encuentra con un error no fatal. Por defecto, el error simplemente se muestra como una advertencia usando Carp. La intención de este método es que si desea anular ese comportamiento, creará una subclase de PkgConfig::LibPkgConf::Client e implementará su propia versión del método "error".

audit_set_log

$client->audit_set_log($filename, $mode);

Abre un archivo con el estilo C "fopen" $mode, y lo utiliza para el registro de auditoría. El archivo es administrado completamente por la clase cliente y se cerrará cuando el objeto salga de ámbito. Ejemplos:

$client->audit_set_log("audit.log", "a"); # agregar a archivo existente
$client->audit_set_log("audit2.log", "w"); # nuevo o reemplazar archivo
