PKCS12_SAFEBAG_create_cert(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_SAFEBAG_CREATE_CERT(3ssl) OpenSSL PKCS12_SAFEBAG_CREATE_CERT(3ssl)

NOMBRE

PKCS12_SAFEBAG_create_cert, PKCS12_SAFEBAG_create_crl, PKCS12_SAFEBAG_create_secret, PKCS12_SAFEBAG_create0_p8inf, PKCS12_SAFEBAG_create0_pkcs8, PKCS12_SAFEBAG_create_pkcs8_encrypt, PKCS12_SAFEBAG_create_pkcs8_encrypt_ex - Crear objetos PKCS#12 safeBag

SINOPSIS

#include <openssl/pkcs12.h>
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_cert(X509 *x509);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_crl(X509_CRL *crl);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_secret(int type, int vtype,
                                             const unsigned char* value,
                                             int len);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create0_p8inf(PKCS8_PRIV_KEY_INFO *p8);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create0_pkcs8(X509_SIG *p8);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_pkcs8_encrypt(int pbe_nid,
                                                    const char *pass,
                                                    int passlen,
                                                    unsigned char *salt,
                                                    int saltlen, int iter,
                                                    PKCS8_PRIV_KEY_INFO *p8inf);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_create_pkcs8_encrypt_ex(int pbe_nid,
                                                       const char *pass,
                                                       int passlen,
                                                       unsigned char *salt,
                                                       int saltlen, int iter,
                                                       PKCS8_PRIV_KEY_INFO *p8inf,
                                                       OSSL_LIB_CTX *ctx,
                                                       const char *propq);

DESCRIPCIÓN

PKCS12_SAFEBAG_create_cert() crea un nuevo PKCS12_SAFEBAG de tipo NID_certBag que contiene el certificado suministrado.

PKCS12_SAFEBAG_create_crl() crea un nuevo PKCS12_SAFEBAG de tipo NID_crlBag que contiene el crl suministrado.

PKCS12_SAFEBAG_create_secret() crea un nuevo PKCS12_SAFEBAG de tipo correspondiente a un secretBag de PKCS#12. El contenido de secretBag se etiqueta como type con un valor ASN1 de tipo vtype construido utilizando los bytes en value de longitud len.

PKCS12_SAFEBAG_create0_p8inf() crea un nuevo PKCS12_SAFEBAG de tipo NID_keyBag que contiene la estructura PKCS8 suministrada.

PKCS12_SAFEBAG_create0_pkcs8() crea un nuevo PKCS12_SAFEBAG de tipo NID_pkcs8ShroudedKeyBag que contiene la estructura PKCS8 suministrada.

PKCS12_SAFEBAG_create_pkcs8_encrypt() crea un nuevo PKCS12_SAFEBAG de tipo NID_pkcs8ShroudedKeyBag cifrando el PKCS8 p8inf suministrado. Si pbe_nid es 0, se utiliza un algoritmo de cifrado predeterminado. pass es la contraseña y iter es el número de iteraciones. Si iter es cero, se utiliza un valor predeterminado de 2048. Si salt es NULL, se genera una sal aleatoriamente.

PKCS12_SAFEBAG_create_pkcs8_encrypt_ex() es idéntica a PKCS12_SAFEBAG_create_pkcs8_encrypt() pero permite utilizar un contexto de biblioteca ctx y una consulta de propiedad propq para seleccionar implementaciones de algoritmos.

NOTAS

PKCS12_SAFEBAG_create_pkcs8_encrypt() hace suposiciones con respecto a la codificación de la frase de contraseña dada. Consulte passphrase-encoding(7) para obtener más información.

PKCS12_SAFEBAG_create_secret() se añadió en OpenSSL 3.0.

VALORES DE RETORNO

Todas estas funciones devuelven una estructura PKCS12_SAFEBAG válida o NULL si ocurrió un error.

CONFORMIDAD

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VER TAMBIÉN

PKCS12_create(3), PKCS12_add_safe(3), PKCS12_add_safes(3)

HISTORIA
