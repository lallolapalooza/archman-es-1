(5) Manual de Formatos de Archivo (5)

NOMBRE

PKGINFO - Información sobre paquetes basados en ALPM (versión 2).

DESCRIPCIÓN

El formato PKGINFO es un formato textual que describe metadatos de paquetes. Dichos archivos se encuentran en la raíz de los paquetes ALPM y se denominan .PKGINFO. Son utilizados, por ejemplo, por los gestores de paquetes para evaluar y presentar el contexto de un paquete dentro de su ecosistema. Los casos de uso incluyen la representación de metadatos comunes y la relación con otros paquetes.

El formato PKGINFO existe en múltiples versiones. La información en este documento es para la versión 2, que es la versión actual y se introdujo con la versión 6.1.0 de pacman el 2024-03-04.

Formato General

Un archivo PKGINFO consta de una serie de líneas, cada una proporcionando información sobre un aspecto de un paquete. Las líneas que comienzan con el signo ‘#’ son comentarios y siempre se ignoran. El espacio en blanco inicial siempre se ignora.

A menos que se indique lo contrario, la información contenida en un archivo PKGINFO se considera cubierta por el conjunto de los 95 caracteres imprimibles ASCII[1].

Cambios desde la última versión

Se ha añadido la nueva palabra clave xdata para rastrear datos adicionales para un paquete.

Palabras clave

Cada línea codifica información que representa una asignación de palabra clave. Todas las asignaciones de palabras clave consisten en una clave de la siguiente lista seguida inmediatamente de un espacio en blanco, un signo ‘=’, otro espacio en blanco y un valor.

Por defecto, debe haber exactamente una asignación de palabra clave por palabra clave en un PKGINFO. Como excepción a esta regla, las palabras clave license, replaces, group, conflict, provides, backup, depend, optdepend, makedepend y checkdepend pueden proporcionarse cero o más veces. Como excepción adicional, la palabra clave xdata se proporciona una o más veces.

pkgname

El nombre del paquete. El valor es un nombre-paquete-alpm (ej. ejemplo).

pkgbase

La base-paquete-alpm del paquete. El valor es una base-paquete-alpm (ej. ejemplo).

xdata

Los datos *adicionales* asociados con el paquete. Esta palabra clave debe asignarse una vez para definir un valor específico, pero puede proporcionarse varias veces después para proporcionar datos adicionales. El valor es una cadena codificada en UTF-8, que representa otro par clave-valor, delimitado por un signo ‘=’ (ej. clave=valor).

Un PKGINFO debe contener una asignación de palabra clave xdata que defina una asignación pkgtype en su valor (ej. pkgtype=pkg). Los valores válidos de pkgtype son debug (para paquetes de depuración), pkg (para paquetes individuales), src (para paquetes fuente) y split (para paquetes divididos).

Se pueden proporcionar asignaciones de palabra clave xdata adicionales siguiendo las reglas generales sobre el formato de sus valores.

pkgver

La versión completa del paquete. Tenga en cuenta que esto no debe confundirse con alpm-pkgver, ¡que solo representa un subconjunto de esta palabra clave! El valor es una versión-paquete-alpm, ya sea en forma *completa* o *completa con época* (ej. 1.0.0-1 o 1:1.0.0-1, respectivamente).

pkgdesc

La descripción del paquete. El valor es una cadena UTF-8, de cero o más caracteres de longitud (ej. Un proyecto utilizado para algo). Las descripciones de paquetes no deben tener espacios en blanco al principio ni al final, no deben contener caracteres de espacio en blanco excepto el espacio “ “ y no deben tener espacios sucesivos. También se sugiere que sea “corta” y que no contenga el nombre del paquete (ver pkgname).

url

La URL del proyecto del paquete. El valor es una URL válida o una cadena vacía (ej. https://example.org).

builddate

La fecha en que comenzó la compilación del paquete. El valor debe ser numérico y debe representar los segundos desde la Época, también conocido como "tiempo Unix" (ej. 1729181726).

packager

El ID de Usuario de la entidad que compiló el paquete. El valor está destinado a ser utilizado para búsquedas de identidad y representa un ID de Usuario OpenPGP[2]. Como tal, el valor es una cadena codificada en UTF-8, que convencionalmente se compone de un nombre y una dirección de correo electrónico, lo que se alinea con el formato descrito en RFC 28223.

size

El tamaño del contenido del paquete (sin comprimir y desempaquetar) en bytes. El valor es un entero no negativo que representa el tamaño absoluto del contenido del paquete, con múltiples archivos con enlaces simbólicos contados solo una vez (ej. 181849963).

arch

La arquitectura del paquete (ver alpm-architecture para más información). El valor debe estar cubierto por el conjunto de caracteres alfanuméricos y ‘_’ (ej. x86_64 o any).

license

Una licencia que se aplica al paquete. Esta palabra clave puede asignarse cero o más veces. El valor representa un identificador de licencia, que es una cadena de longitud distinta de cero (ej. GPL). Aunque no se aplican restricciones específicas para el valor aparte de su longitud, se recomienda encarecidamente depender de expresiones de licencia SPDX (ej. GPL-3.0-or-later o Apache-2.0 OR MIT). Consulte la Lista de Licencias SPDX[4] para obtener más información.

replaces

Otro *componente virtual* o paquete, que el paquete reemplaza al instalarse. Esta palabra clave puede asignarse cero o más veces. El valor es una relación-paquete-alpm de tipo reemplazo (ej. ejemplo o ejemplo=1.0.0).

group

Una cadena arbitraria, que denota un grupo a nivel de distribución al que pertenece el paquete. Los grupos se utilizan, por ejemplo, por los gestores de paquetes para agrupar paquetes y permitir su instalación masiva, o por otro software para mostrar información sobre estos paquetes relacionados. Esta palabra clave puede asignarse cero o más veces. El valor está representado por una cadena UTF-8. Aunque es posible usar una cadena UTF-8, se recomienda encarecidamente depender del formato pkgname para el valor en su lugar, ya que los gestores de paquetes pueden usar group para instalar un grupo completo de paquetes.

conflict

Otro *componente virtual* o paquete, con el que el paquete entra en conflicto. Esta palabra clave puede asignarse cero o más veces. El valor es una relación-paquete-alpm de tipo conflicto (ej. ejemplo o ejemplo=1.0.0).

provides

Otro *componente virtual* o paquete, que el paquete proporciona. Esta palabra clave puede asignarse cero o más veces. El valor es una relación-paquete-alpm de tipo provisión (ej. ejemplo o ejemplo=1.0.0).

NAME

PKGINFO - Package information file format

DESCRIPTION

The PKGINFO file contains metadata about a package, which is used by the pacman(8) package manager. This file is typically created by makepkg(8) during the package building process.

The file format is a simple key-value pair format. Each line contains a single key-value pair, separated by an equals sign (=). Keys are case-sensitive. Values can contain spaces and special characters, but certain characters may need to be escaped depending on the context.

backup

Una ruta de archivo relativa dentro del paquete, que denota un archivo para que el administrador de paquetes guarde copias de seguridad en caso de que cambie o se elimine durante una acción de actualización del paquete (ver archivos .pacnew y .pacsave de pacman). Esta palabra clave puede asignarse cero o más veces. El valor debe ser una ruta de archivo Unix relativa válida (por ejemplo, etc/package.conf).

depend

Una dependencia en tiempo de ejecución del paquete (componente virtual o paquete). Esta palabra clave puede asignarse cero o más veces. El valor es una relación de paquete alpm de tipo dependencia en tiempo de ejecución (por ejemplo, example o example=1.0.0).

optdepend

Una dependencia opcional del paquete (componente virtual o paquete). Esta palabra clave puede asignarse cero o más veces. El valor es una relación de paquete alpm de tipo dependencia opcional (por ejemplo, example o example: este es una descripción).

makedepend

Una dependencia en tiempo de compilación del paquete (componente virtual o paquete). Esta palabra clave puede asignarse cero o más veces. El valor es una relación de paquete alpm de tipo dependencia de compilación (por ejemplo, example o example=1.0.0).

checkdepend

Una dependencia para ejecutar pruebas del proyecto upstream del paquete. Esta palabra clave puede asignarse cero o más veces. El valor es una relación de paquete alpm de tipo dependencia de prueba (por ejemplo, example o example=1.0.0).

EJEMPLOS

pkgname = example
pkgbase = example
xdata = pkgtype=pkg
pkgver = 1:1.0.0-1
pkgdesc = Un proyecto que hace algo
url = https://example.org
builddate = 1729181726
packager = John Doe <john@example.org>
size = 181849963
arch = any
license = GPL-3.0-or-later
license = LGPL-3.0-or-later
replaces = other-package>0.9.0-3
group = package-group
group = other-package-group
conflict = conflicting-package<1.0.0
conflict = other-conflicting-package<1.0.0
provides = some-component
provides = some-other-component=1:1.0.0-1
backup = etc/example/config.toml
backup = etc/example/other-config.txt
depend = glibc
depend = gcc-libs
optdepend = python: para special-python-script.py
optdepend = ruby: para special-ruby-script.rb
makedepend = cmake
makedepend = python-sphinx
checkdepend = extra-test-tool
checkdepend = other-extra-test-tool
