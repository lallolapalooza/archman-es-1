PKCS7_decrypt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS7_DECRYPT(3ssl) OpenSSL PKCS7_DECRYPT(3ssl)

NOMBRE

PKCS7_decrypt - Descifra el contenido de una estructura envelopedData PKCS#7

SINOPSIS

#include <openssl/pkcs7.h>
int PKCS7_decrypt(PKCS7 *p7, EVP_PKEY *pkey, X509 *cert, BIO *data, int flags);

DESCRIPCIÓN

PKCS7_decrypt() extrae y descifra el contenido de una estructura envelopedData PKCS#7. pkey es la clave privada del destinatario, cert es el certificado del destinatario, data es un BIO para escribir el contenido y flags es un conjunto opcional de indicadores.

NOTAS

Aunque el certificado del destinatario no es necesario para descifrar los datos, sí lo es para localizar al destinatario apropiado (de posibles varios) en la estructura PKCS#7.

Los siguientes indicadores se pueden pasar en el parámetro flags.

Si el indicador PKCS7_TEXT está activado, se eliminan las cabeceras MIME de tipo text/plain del contenido. Si el contenido no es de tipo text/plain, se devuelve un error.

VALORES DE RETORNO

PKCS7_decrypt() devuelve 1 en caso de éxito o 0 en caso de fallo. El error se puede obtener de ERR_get_error(3)

ERRORES

PKCS7_decrypt() debe recibir la clave y el certificado del destinatario correctos. Sería mejor si pudiera buscar la clave y el certificado correctos en una base de datos.

La falta de procesamiento en una sola pasada y la necesidad de mantener todos los datos en memoria, como se menciona en PKCS7_sign(), también se aplica a PKCS7_verify().

VER TAMBIÉN

ERR_get_error(3), PKCS7_encrypt(3)
