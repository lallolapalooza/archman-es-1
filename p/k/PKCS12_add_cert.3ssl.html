PKCS12_add_cert(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_ADD_CERT(3ssl) OpenSSL PKCS12_ADD_CERT(3ssl)

NOMBRE

PKCS12_add_cert, PKCS12_add_key, PKCS12_add_key_ex, PKCS12_add_secret - Añadir un objeto a un conjunto de safeBags PKCS#12

SINOPSIS

#include <openssl/pkcs12.h>
PKCS12_SAFEBAG *PKCS12_add_cert(STACK_OF(PKCS12_SAFEBAG) **pbags, X509 *cert);
PKCS12_SAFEBAG *PKCS12_add_key(STACK_OF(PKCS12_SAFEBAG) **pbags,
                              EVP_PKEY *key, int key_usage, int iter,
                              int key_nid, const char *pass);
PKCS12_SAFEBAG *PKCS12_add_key_ex(STACK_OF(PKCS12_SAFEBAG) **pbags,
                                  EVP_PKEY *key, int key_usage, int iter,
                                  int key_nid, const char *pass,
                                  OSSL_LIB_CTX *ctx, const char *propq);
PKCS12_SAFEBAG *PKCS12_add_secret(STACK_OF(PKCS12_SAFEBAG) **pbags,
                                 int nid_type, const unsigned char *value, int len);

DESCRIPCIÓN

Estas funciones crean un nuevo PKCS12_SAFEBAG y lo añaden al conjunto de safeBags en pbags.

PKCS12_add_cert() crea un certBag PKCS#12 que contiene el certificado proporcionado y lo añade al conjunto de safeBags PKCS#12.

PKCS12_add_key() crea un keyBag PKCS#12 (sin cifrar) o un pkcs8shroudedKeyBag (cifrado) que contiene el EVP_PKEY proporcionado y lo añade al conjunto de safeBags PKCS#12. Si key_nid no es -1 entonces la clave se cifra con el algoritmo proporcionado, usando pass como contraseña y iter como número de iteraciones. Si iter es cero entonces se utiliza un valor por defecto de 2048 para el número de iteraciones.

PKCS12_add_key_ex() es idéntica a PKCS12_add_key() pero permite usar un contexto de biblioteca ctx y una consulta de propiedades propq para seleccionar implementaciones de algoritmos.

PKCS12_add_secret() crea un secretBag PKCS#12 con un OID correspondiente al nid_type proporcionado que contiene el valor proporcionado como una cadena de octetos ASN1. Esto se añade luego al conjunto de safeBags PKCS#12.

NOTAS

Si un certificado contiene un alias o un keyid entonces se usará para el friendlyName o localKeyID correspondiente en la estructura PKCS12.

PKCS12_add_key() hace suposiciones sobre la codificación de la frase de contraseña dada. Véase passphrase-encoding(7) para más información.

VALORES DE RETORNO

Una estructura PKCS12_SAFEBAG válida o NULL si ocurrió un error.

CONFORME A

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VER TAMBIÉN

PKCS12_create(3)

HISTORIAL

PKCS12_add_secret() y PKCS12_add_key_ex() fueron añadidas en OpenSSL 3.0.
