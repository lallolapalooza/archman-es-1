PKCS12_gen_mac(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_GEN_MAC(3ssl) OpenSSL PKCS12_GEN_MAC(3ssl)

NOMBRE

PKCS12_gen_mac, PKCS12_setup_mac, PKCS12_set_mac, PKCS12_set_pbmac1_pbkdf2, PKCS12_verify_mac, PKCS12_get0_mac - Funciones para crear y manipular una estructura MAC PKCS#12

SINOPSIS

#include <openssl/pkcs12.h>
int PKCS12_gen_mac(PKCS12 *p12, const char *pass, int passlen,
                   unsigned char *mac, unsigned int *maclen);
int PKCS12_verify_mac(PKCS12 *p12, const char *pass, int passlen);
int PKCS12_set_mac(PKCS12 *p12, const char *pass, int passlen,
                   unsigned char *salt, int saltlen, int iter,
                   const EVP_MD *md_type);
int PKCS12_set_pbmac1_pbkdf2(PKCS12 *p12, const char *pass, int passlen,
                                  unsigned char *salt, int saltlen, int iter,
                                  const EVP_MD *md_type,
                                  const char *prf_md_name);
int PKCS12_setup_mac(PKCS12 *p12, int iter, unsigned char *salt,
                     int saltlen, const EVP_MD *md_type);
void PKCS12_get0_mac(const ASN1_OCTET_STRING **pmac,
                     const X509_ALGOR **pmacalg,
                     const ASN1_OCTET_STRING **psalt,
                     const ASN1_INTEGER **piter,
                     const PKCS12 *p12);

DESCRIPCIÓN

PKCS12_gen_mac() genera un HMAC sobre todo el objeto PKCS#12 utilizando la contraseña proporcionada junto con un conjunto de parámetros ya configurados. El mecanismo de generación de claves por defecto utilizado es PKCS12KDF.

PKCS12_verify_mac() verifica el HMAC del objeto PKCS#12 utilizando la contraseña proporcionada.

PKCS12_setup_mac() establece la parte MAC de la estructura PKCS#12 con los parámetros proporcionados.

PKCS12_set_mac() establece el MAC y los parámetros del MAC en el objeto PKCS#12. PKCS12_set_pbmac1_pbkdf2() establece el MAC y los parámetros del MAC en el objeto PKCS#12 cuando se utiliza PBMAC1 con PBKDF2 para la protección del objeto PKCS#12.

pass es la frase de contraseña a utilizar en el HMAC. salt es el valor de salt a utilizar, iter es el número de iteraciones y md_type es la función de resumen de mensajes a utilizar. prf_md_name especifica el resumen utilizado para PBKDF2 en el KDF de PBMAC1.

PKCS12_get0_mac() recupera cualquier valor MAC incluido, el objeto X509_ALGOR, el salt y el recuento de iteraciones del objeto PKCS12.

NOTAS

Si salt es NULL, se generará y utilizará un salt adecuado.

Si iter es 1, se omitirá un recuento de iteraciones de la estructura PKCS#12.

PKCS12_gen_mac(), PKCS12_verify_mac(), PKCS12_set_mac() y PKCS12_set_pbmac1_pbkdf2() hacen suposiciones sobre la codificación de la frase de contraseña dada. Consulte passphrase-encoding(7) para más información.

VALORES DE RETORNO

Todas las funciones que devuelven un entero devuelven 1 en caso de éxito y 0 si ocurrió un error.

ENTORNO

LEGACY_GOST_PKCS12
Si esta variable de entorno está establecida, la generación de MAC que utiliza algoritmos de hash GOST R 34.11-94 o GOST 34.11-2012 se realiza de la manera habitual y no de acuerdo con la especificación proporcionada en la recomendación metodológica MP 26.2.002-2012 (o en sus versiones posteriores, recomendación de estandarización P 50.1.112-2016 o P 1323565.1.041-2022) del Comité Técnico 26, que especifica que la clave utilizada para la generación de MAC debe ser los últimos 32 bytes de la secuencia de 96 bytes generada por PKCS5_PBKDF2_HMAC(3) y no la secuencia completa.
