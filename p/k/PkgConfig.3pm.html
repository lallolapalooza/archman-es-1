NOMBRE

PkgConfig - Reemplazo de PkgConfig en Perl Puro y Solo Núcleo

SINOPSIS

Como reemplazo de "pkg-config"

$ ppkg-config --libs --cflags --static gio-2.0
#produce (líneas rotas artificialmente para legibilidad):
# -I/usr/include/glib-2.0 -I/usr/lib/glib-2.0/include
# -pthread -lgio-2.0 -lz -lresolv -lgobject-2.0
# -lgmodule-2.0 -ldl -lgthread-2.0 -pthread -lrt -lglib-2.0

"pkg-config.pl" se puede usar como un alias para "ppkg-config" en plataformas que lo soporten. También se puede instalar como "pkg-config", aunque no se recomienda si tu sistema tiene un "pkg-config" nativo.

Comparar con:
$ pkg-config --libs --cflags --static gio-2.0

#produce ( "" ):
# -pthread -I/usr/include/glib-2.0 -I/usr/lib/glib-2.0/include
# -pthread -lgio-2.0 -lz -lresolv -lgobject-2.0 -lgmodule-2.0
# -ldl -lgthread-2.0 -lrt -lglib-2.0

Desde otro módulo Perl

use PkgConfig;
my $o = PkgConfig->find('gio');
if($o->errmsg) {
    #manejar error
} else {
    my $prefix = $o->get_var('prefix');
    my @cflags = $o->get_cflags;
    my @ldflags = $o->get_ldflags;
}

DESCRIPCIÓN

"PkgConfig" proporciona un reemplazo en Perl puro y solo núcleo para la utilidad "pkg-config".

Esta no es una descripción de los usos de "pkg-config", sino una descripción de las diferencias entre la versión C y la de Perl.

Mientras que "pkg-config" es un binario compilado enlazado con glib, la versión en Perl puro no tiene tal requisito y funcionará dondequiera que Perl ( >= 5.6 ) lo haga.

Las principales opciones soportadas son las comunes "--libs", "--cflags", "--static", "--exists" y "--modversion".

OPCIONES DE SCRIPT

USO

<nombrepaquete1 nombrepaquete2..> [ --opciones ]

ARGUMENTOS

Por defecto, se debe suministrar un nombre de biblioteca a menos que se especifique --version o --real-version.

La salida normalmente debería ser adecuada para pasar a tu compilador favorito.

--libs

(También) imprime flags del enlazador. Las dependencias se recorren en orden. Las dependencias de nivel superior aparecerán antes en la línea de comandos que las dependencias de nivel inferior.

--libs-only-L

Imprime la parte -L/-R de "--libs". Define la ruta de búsqueda de bibliotecas pero sin las bibliotecas con las que enlazar.

--libs-only-l

Imprime la parte -l de "--libs".

--libs-only-other

Imprime la parte de "--libs" no cubierta por "--libs-only-L" y "--libs-only-l", como "--pthread".

--list-all

Lista todos los paquetes conocidos.

--cflags

(También) imprime flags del compilador y del preprocesador C.

--cflags-only-I

Imprime la parte -I de "--cflags".

--cflags-only-other

Imprime las partes de "--cflags" no cubiertas por "--cflags-only-I".

--modversion

Imprime la versión de un paquete dado.

--static

Usa dependencias y bibliotecas adicionales si se enlaza contra una versión estática de la biblioteca solicitada.

--exists

Devuelve éxito (0) si el paquete existe en la ruta de búsqueda.

--with-path=RUTA

Antepone "RUTA" a la lista de rutas de búsqueda que contienen archivos ".pc".

Esta opción se puede especificar varias veces con diferentes rutas, y todas se añadirán.

--env-only

Usando esta opción, sólo se reconocen las rutas especificadas en "PKG_CONFIG_PATH" y se ignoran los valores por defecto codificados.

--guess-paths

Invoca "gcc" y "ld" para determinar las rutas por defecto del enlazador e inclusiones. Las rutas por defecto se excluirán de los flags explícitos de -L y -I.

--define-variable=VARIABLE=VALOR

Define una variable, anulando cualquier definición de variable similar en el archivo .pc, y permitiendo que tu valor se interpola con usos posteriores.

--variable=VARIABLE

Esto devuelve el valor de una variable definida en el archivo .pc de un paquete.

--print-variables

Imprime todas las variables definidas encontradas en los archivos .pc.

--version

La versión objetivo de "pkg-config" emulada por este script.

--real-version

La versión real de este script.

--debug

Imprime información de depuración.

--silence-errors

Desactiva los errores. Este es el valor por defecto para argumentos que no son --libs/--cflags/--modversion.

--print-errors

Imprime errores en STDERR y tiene precedencia sobre "--silence-errors".

--short-errors

Ignorado, pero reconocido por compatibilidad.

--errors-to-stdout

Imprime errores en STDOUT y tiene precedencia sobre "--print-errors".

ENTORNO

Las variables "PKG_CONFIG_PATH" y "PKG_CONFIG_LIBDIR" se respetan y se usan como una lista separada por dos puntos (separada por punto y coma en Windows) de directorios que contienen archivos ".pc".

Otras variables de entorno reconocidas tanto por "pkg-config" como por PkgConfig incluyen:

PKG_CONFIG_ALLOW_SYSTEM_CFLAGS
PKG_CONFIG_ALLOW_SYSTEM_LIBS

Si Win32API::Registry está instalado, en Windows (pero no en Cygwin) PkgConfig también consultará estas claves del registro. Los nombres se ignoran, pero los valores son rutas que contienen archivos ".pc".

HKEY_CURRENT_USER\Software\pkgconfig\PKG_CONFIG_PATH
HKEY_LOCAL_MACHINE\Software\pkgconfig\PKG_CONFIG_PATH

El soporte del registro debe considerarse algo experimental, sujeto a cambios en el futuro, aunque no sin una buena razón. La lógica detrás de esta advertencia es que esta característica está documentada en varios lugares, pero aún no he encontrado una versión funcional que implemente esta característica.

OPCIONES DE MÓDULO

PkgConfig->find

my $result = PkgConfig->find($libreria, %opciones);

Encuentra una biblioteca y devuelve un objeto resultado. $libreria puede ser el nombre de una sola biblioteca o una referencia a una matriz de nombres de bibliotecas.

Las opciones son en forma de claves y valores de hash, y se reconocen las siguientes:

"search_path"
"search_path_override"
Anteponer rutas de búsqueda además de las rutas especificadas en $ENV{PKG_CONFIG_PATH}. El valor es una referencia a una matriz.

la variante "_override" ignora los valores por defecto (como "PKG_CONFIG_PATH").

"file_path"
Especifica la ruta completa del archivo .pc que deseas cargar. No necesita estar en la ruta de búsqueda (aunque las dependencias sí deberán estarlo). Útil si conoces la ruta completa del archivo .pc exacto que deseas.
