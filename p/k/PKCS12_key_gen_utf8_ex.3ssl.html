PKCS12_key_gen_utf8_ex(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_KEY_GEN_UTF8_EX(3ssl) OpenSSL PKCS12_KEY_GEN_UTF8_EX(3ssl)

NOMBRE

PKCS12_key_gen_asc, PKCS12_key_gen_asc_ex, PKCS12_key_gen_uni, PKCS12_key_gen_uni_ex, PKCS12_key_gen_utf8, PKCS12_key_gen_utf8_ex - Derivación de clave basada en contraseña PKCS#12

SINOPSIS

#include <openssl/pkcs12.h>
int PKCS12_key_gen_asc(const char *pass, int passlen, unsigned char *salt,
                       int saltlen, int id, int iter, int n,
                       unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_asc_ex(const char *pass, int passlen, unsigned char *salt,
                          int saltlen, int id, int iter, int n,
                          unsigned char *out, const EVP_MD *md_type,
                          OSSL_LIB_CTX *ctx, const char *propq);
int PKCS12_key_gen_uni(unsigned char *pass, int passlen, unsigned char *salt,
                       int saltlen, int id, int iter, int n,
                       unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_uni_ex(unsigned char *pass, int passlen, unsigned char *salt,
                          int saltlen, int id, int iter, int n,
                          unsigned char *out, const EVP_MD *md_type,
                          OSSL_LIB_CTX *ctx, const char *propq);
int PKCS12_key_gen_utf8(const char *pass, int passlen, unsigned char *salt,
                        int saltlen, int id, int iter, int n,
                        unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_utf8_ex(const char *pass, int passlen, unsigned char *salt,
                           int saltlen, int id, int iter, int n,
                           unsigned char *out, const EVP_MD *md_type,
                           OSSL_LIB_CTX *ctx, const char *propq);

DESCRIPCIÓN

Estos métodos realizan una derivación de clave según PKCS#12 (RFC7292) con una contraseña de entrada pass de longitud passlen, una sal salt de longitud saltlen, un contador de iteraciones iter y un algoritmo de resumen md_type. El byte de ID id determina cómo se pretenden utilizar los bits de clave resultantes:

  • Si ID=1, entonces los bits pseudoraleatorios que se están produciendo se utilizarán como material de clave para realizar cifrado o descifrado.
  • Si ID=2, entonces los bits pseudoraleatorios que se están produciendo se utilizarán como un IV (Valor Inicial) para cifrado o descifrado.
  • Si ID=3, entonces los bits pseudoraleatorios que se están produciendo se utilizarán como una clave de integridad para MACing.

El formato previsto de la contraseña proporcionada se determina por el método elegido:

  • PKCS12_key_gen_asc() y PKCS12_key_gen_asc_ex() esperan una contraseña con formato ASCII.
  • PKCS12_key_gen_uni() y PKCS12_key_gen_uni_ex() esperan una contraseña con formato Unicode.
  • PKCS12_key_gen_utf8() y PKCS12_key_gen_utf8_ex() esperan una contraseña codificada en UTF-8.

pass es la contraseña utilizada en la derivación de longitud passlen. pass es un parámetro opcional y puede ser NULL. Si passlen es -1, la función calculará la longitud de pass usando strlen().

salt es la sal utilizada en la derivación de longitud saltlen. Si salt es NULL, entonces saltlen debe ser 0. La función no intentará calcular la longitud de la salt ya que no se asume que esté terminada en nulo.

iter es el contador de iteraciones y su valor debe ser mayor o igual a 1. RFC 2898 sugiere un contador de iteraciones de al menos 1000. Cualquier iter menor que 1 se trata como una única iteración.

digest es la función de resumen de mensajes utilizada en la derivación.

La clave derivada se escribirá en out. El tamaño del buffer out se especifica a través de n.

Las funciones que terminan en _ex() permiten utilizar un contexto de biblioteca ctx y una consulta de propiedades propq para seleccionar implementaciones de algoritmos.

NOTAS

Una aplicación típica de esta función es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en pass, una sal en salt y un contador de iteraciones.

Aumentar el parámetro iter ralentiza el algoritmo, lo que dificulta que un atacante realice un ataque de fuerza bruta utilizando un gran número de contraseñas candidatas.

VALORES DE RETORNO

Devuelve 1 si tiene éxito o 0 si hay un error.

CONFORMIDAD

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VER TAMBIÉN
