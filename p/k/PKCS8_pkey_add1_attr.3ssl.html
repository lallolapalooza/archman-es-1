PKCS8_pkey_add1_attr(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS8_PKEY_ADD1_ATTR(3ssl) OpenSSL PKCS8_PKEY_ADD1_ATTR(3ssl)

NOMBRE

PKCS8_pkey_get0_attrs, PKCS8_pkey_add1_attr, PKCS8_pkey_add1_attr_by_NID, PKCS8_pkey_add1_attr_by_OBJ - Funciones de atributos PKCS8

SINOPSIS

#include <openssl/x509.h>
const STACK_OF(X509_ATTRIBUTE) *
PKCS8_pkey_get0_attrs(const PKCS8_PRIV_KEY_INFO *p8);
int PKCS8_pkey_add1_attr(PKCS8_PRIV_KEY_INFO *p8, X509_ATTRIBUTE *attr);
int PKCS8_pkey_add1_attr_by_NID(PKCS8_PRIV_KEY_INFO *p8, int nid, int type,
                                const unsigned char *bytes, int len);
int PKCS8_pkey_add1_attr_by_OBJ(PKCS8_PRIV_KEY_INFO *p8, const ASN1_OBJECT *obj,
                               int type, const unsigned char *bytes, int len);

DESCRIPCIÓN

PKCS8_pkey_get0_attrs() devuelve una STACK const de X509_ATTRIBUTE presentes en la estructura const PKCS8_PRIV_KEY_INFO pasada p8.

PKCS8_pkey_add1_attr() añade un X509_ATTRIBUTE construido attr a la estructura PKCS8_PRIV_KEY_INFO existente p8.

PKCS8_pkey_add1_attr_by_NID() y PKCS8_pkey_add1_attr_by_OBJ() construyen un nuevo X509_ATTRIBUTE a partir de los argumentos pasados y lo añaden a la estructura PKCS8_PRIV_KEY_INFO existente p8.

VALORES DE RETORNO

PKCS8_pkey_add1_attr(), PKCS8_pkey_add1_attr_by_NID(), y PKCS8_pkey_add1_attr_by_OBJ() devuelven 1 para éxito y 0 para fallo.

NOTAS

La STACK de X509_ATTRIBUTE está presente en muchas estructuras relacionadas con X509 y algunas de ellas tienen el conjunto correspondiente de funciones similares.
