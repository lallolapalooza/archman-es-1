PKCS12_item_decrypt_d2i(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS12_ITEM_DECRYPT_D2I(3ssl) OpenSSL PKCS12_ITEM_DECRYPT_D2I(3ssl)

NOMBRE

PKCS12_item_decrypt_d2i, PKCS12_item_decrypt_d2i_ex, PKCS12_item_i2d_encrypt, PKCS12_item_i2d_encrypt_ex - Funciones de cifrado/descifrado de ítems PKCS12

SINOPSIS

#include <openssl/pkcs12.h>
void *PKCS12_item_decrypt_d2i(const X509_ALGOR *algor, const ASN1_ITEM *it,
                              const char *pass, int passlen,
                              const ASN1_OCTET_STRING *oct, int zbuf);
void *PKCS12_item_decrypt_d2i_ex(const X509_ALGOR *algor, const ASN1_ITEM *it,
                                 const char *pass, int passlen,
                                 const ASN1_OCTET_STRING *oct, int zbuf,
                                 OSSL_LIB_CTX *libctx,
                                 const char *propq);
ASN1_OCTET_STRING *PKCS12_item_i2d_encrypt(X509_ALGOR *algor,
                                           const ASN1_ITEM *it,
                                           const char *pass, int passlen,
                                           void *obj, int zbuf);
ASN1_OCTET_STRING *PKCS12_item_i2d_encrypt_ex(X509_ALGOR *algor,
                                              const ASN1_ITEM *it,
                                              const char *pass, int passlen,
                                              void *obj, int zbuf,
                                              OSSL_LIB_CTX *ctx,
                                              const char *propq);

DESCRIPCIÓN

PKCS12_item_decrypt_d2i() y PKCS12_item_decrypt_d2i_ex() descifran una cadena de octetos que contiene un objeto codificado en ASN.1 utilizando el algoritmo algor y la contraseña pass de longitud passlen. Si zbuf es distinto de cero, el búfer de salida se pondrá a cero después del descifrado.

PKCS12_item_i2d_encrypt() y PKCS12_item_i2d_encrypt_ex() cifran un objeto ASN.1 it usando el algoritmo algor y la contraseña pass de longitud passlen, devolviendo un objeto codificado en obj. Si zbuf es distinto de cero, el búfer que contiene la codificación de entrada se pondrá a cero después del cifrado.

Las funciones que terminan en _ex() permiten utilizar un contexto de biblioteca ctx y una consulta de propiedad propq para seleccionar implementaciones de algoritmos.

VALORES DE RETORNO

PKCS12_item_decrypt_d2i() y PKCS12_item_decrypt_d2i_ex() devuelven el objeto descifrado o NULL si se produjo un error.

PKCS12_item_i2d_encrypt() y PKCS12_item_i2d_encrypt_ex() devuelven los datos cifrados como una Cadena de Octetos ASN.1 o NULL si se produjo un error.

VER TAMBIÉN

PKCS12_pbe_crypt_ex(3), PKCS8_encrypt_ex(3)

HISTORIA

PKCS12_item_decrypt_d2i_ex() y PKCS12_item_i2d_encrypt_ex() se añadieron en OpenSSL 3.0.
