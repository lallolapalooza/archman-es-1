PKCS8_encrypt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS8_ENCRYPT(3ssl) OpenSSL PKCS8_ENCRYPT(3ssl)

NOMBRE

PKCS8_decrypt, PKCS8_decrypt_ex, PKCS8_encrypt, PKCS8_encrypt_ex, PKCS8_set0_pbe, PKCS8_set0_pbe_ex - Funciones de cifrado/descifrado PKCS8

SINOPSIS

#include <openssl/x509.h>
PKCS8_PRIV_KEY_INFO *PKCS8_decrypt(const X509_SIG *p8, const char *pass,
                                   int passlen);
PKCS8_PRIV_KEY_INFO *PKCS8_decrypt_ex(const X509_SIG *p8, const char *pass,
                                      int passlen, OSSL_LIB_CTX *ctx,
                                      const char *propq);
X509_SIG *PKCS8_encrypt(int pbe_nid, const EVP_CIPHER *cipher,
                        const char *pass, int passlen, unsigned char *salt,
                        int saltlen, int iter, PKCS8_PRIV_KEY_INFO *p8);
X509_SIG *PKCS8_encrypt_ex(int pbe_nid, const EVP_CIPHER *cipher,
                           const char *pass, int passlen, unsigned char *salt,
                           int saltlen, int iter, PKCS8_PRIV_KEY_INFO *p8,
                           OSSL_LIB_CTX *ctx, const char *propq);
X509_SIG *PKCS8_set0_pbe(const char *pass, int passlen,
                        PKCS8_PRIV_KEY_INFO *p8inf, X509_ALGOR *pbe);
X509_SIG *PKCS8_set0_pbe_ex(const char *pass, int passlen,
                            PKCS8_PRIV_KEY_INFO *p8inf, X509_ALGOR *pbe,
                            OSSL_LIB_CTX *ctx);

DESCRIPCIÓN

PKCS8_encrypt() y PKCS8_encrypt_ex() realizan el cifrado de un objeto p8 usando la contraseña pass de longitud passlen, sal salt de longitud saltlen y número de iteraciones iter. El X509_SIG resultante contiene los parámetros del algoritmo codificados y la clave cifrada.

PKCS8_decrypt() y PKCS8_decrypt_ex() realizan el descifrado de un X509_SIG en p8 usando la contraseña pass de longitud passlen junto con los parámetros del algoritmo obtenidos de p8.

PKCS8_set0_pbe() y PKCS8_set0_pbe_ex() realizan el cifrado de p8inf usando la contraseña pass de longitud passlen y los parámetros pbe.

Las funciones que terminan en _ex() permiten utilizar un contexto de biblioteca ctx y una consulta de propiedades propq para seleccionar implementaciones de algoritmos.

VALORES DE RETORNO

PKCS8_encrypt(), PKCS8_encrypt_ex(), PKCS8_set0_pbe() y PKCS8_set0_pbe_ex() devuelven una clave cifrada en una estructura X509_SIG o NULL si ocurre un error.

PKCS8_decrypt() y PKCS8_decrypt_ex() devuelven un PKCS8_PRIV_KEY_INFO o NULL si ocurre un error.

CONFORMIDAD

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

VER TAMBIÉN

crypto(7)

HISTORIA

PKCS8_decrypt_ex(), PKCS8_encrypt_ex() y PKCS8_set0_pbe_ex() se añadieron en OpenSSL 3.0.
