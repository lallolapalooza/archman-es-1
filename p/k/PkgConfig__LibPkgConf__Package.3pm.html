PkgConfig::LibPkgConf::Package(3) Documentación de Perl contribuida por el usuario PkgConfig::LibPkgConf::Package(3)

NOMBRE

PkgConfig::LibPkgConf::Package - Representa un paquete

SINOPSIS

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
$client->env;

my $pkg = $client->find('libarchive');

# usar con system en forma escalar:
my $cflags = $pkg->cflags;
my $libs = $pkg->libs;
system "$cc $cflags foo.c";
system "$cc -o foo foo.o $libs";

# usar con system en forma de lista:
my @cflags = $pkg->list_cflags;
my @libs   = $pkg->list_libs;
system $cc, @cflags, 'foo.c';
system $cc, -p => 'foo', 'foo.o', @libs;

DESCRIPCIÓN

El objeto PkgConfig::LibPkgConf::Package almacena información del paquete. Parte de la información del paquete son las banderas del compilador y del enlazador. Esto se puede obtener como cadenas de texto con "cflags" y "libs" y como una lista con "list_cflags" y "list_libs". En la forma de cadena, los escapes se conservan, pero en la forma de lista los escapes de espacios en blanco se convierten en espacios. Esto significa que si está utilizando la forma de cadena de "system"/"exec", debe usar los accesores de cadena, y si está utilizando la forma de lista de "system"/"exec", debe usar los accesores de lista.

MÉTODOS

libs

Banderas de bibliotecas. Esto generalmente incluye cosas como "-L/foo/lib" y "-lfoo".

libs_static

Banderas de bibliotecas estáticas.

cflags

Banderas del compilador. Esto generalmente incluye cosas como "-I/foo/include" y "-DFOO=1".

cflags_static

Banderas estáticas del compilador.

list_libs

my @fragments = $package->list_libs;

Banderas de bibliotecas como una lista de fragmentos PkgConfig::LibPkgConf::Fragment. Esto es similar al método "libs" anterior, pero como devuelve una lista en lugar de una sola cadena, se puede usar para filtrar banderas específicas. Por ejemplo:

# equivalente a pkgconf --libs-only-L
my @lib_dirs = grep { $_->type eq 'L' } $package->list_libs;
# equivalente a pkgconf --libs-only-l
my @libs = grep { $_->type eq 'l' } $package->list_libs;

list_libs_static

my @fragments = $package->list_libs_static;

Similar a "list_libs", pero para las banderas de bibliotecas estáticas.

list_cflags

my @fragments = $package->list_cflags;

Banderas del compilador como una lista de fragmentos PkgConfig::LibPkgConf::Fragment. Esto es similar al método "cflags" anterior, pero como devuelve una lista en lugar de una sola cadena, se puede usar para filtrar banderas específicas. Por ejemplo:

# equivalente a pkgconf --cflags-only-I
my @include_dirs = grep { $_->type eq 'I' } $package->list_cflags;
# equivalente a pkgconf --cflags-only-other
my @other_cflags = grep { $_->type ne 'I' } $package->list_cflags;

list_cflags_static

my @fragments = $package->list_cflags_static;

Similar a "list_cflags", pero para las banderas estáticas del compilador.

variable

my $value = $package->variable($key);

Busca el valor para la variable dada. Devuelve el valor si se encuentra, de lo contrario, devolverá undef (técnicamente una lista vacía).
