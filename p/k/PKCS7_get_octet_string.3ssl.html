PKCS7_get_octet_string(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS7_GET_OCTET_STRING(3ssl) OpenSSL PKCS7_GET_OCTET_STRING(3ssl)

NOMBRE

PKCS7_get_octet_string - devolver una cadena de octetos de una estructura envelopedData de PKCS#7

SINOPSIS

#include <openssl/pkcs7.h>
ASN1_OCTET_STRING *PKCS7_get_octet_string(PKCS7 *p7);

DESCRIPCIÓN

PKCS7_get_octet_string() devuelve un puntero a una cadena de octetos ASN1 de una estructura envelopedData de PKCS#7 o NULL si la estructura no se puede analizar.

NOTAS

Como indica el 0, PKCS7_get_octet_string() devuelve punteros internos que no deben ser liberados por el llamador.

VALORES DEVUELTOS

PKCS7_get_octet_string() devuelve un puntero ASN1_OCTET_STRING.

VER TAMBIÉN

PKCS7_type_is_data(3)
