PKCS5_PBKDF2_HMAC(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PKCS5_PBKDF2_HMAC(3ssl) OpenSSL PKCS5_PBKDF2_HMAC(3ssl)

NOMBRE

PKCS5_PBKDF2_HMAC, PKCS5_PBKDF2_HMAC_SHA1 - rutinas de derivación basadas en contraseña con salt y contador de iteraciones

SINOPSIS

#include <openssl/evp.h>
int PKCS5_PBKDF2_HMAC(const char *pass, int passlen,
                      const unsigned char *salt, int saltlen, int iter,
                      const EVP_MD *digest,
                      int keylen, unsigned char *out);
int PKCS5_PBKDF2_HMAC_SHA1(const char *pass, int passlen,
                           const unsigned char *salt, int saltlen, int iter,
                           int keylen, unsigned char *out);

DESCRIPCIÓN

PKCS5_PBKDF2_HMAC() deriva una clave de una contraseña utilizando un salt y un contador de iteraciones según se especifica en RFC 2898.

pass es la contraseña utilizada en la derivación de longitud passlen. pass es un parámetro opcional y puede ser NULL. Si passlen es -1, la función calculará la longitud de pass utilizando strlen().

salt es el salt utilizado en la derivación de longitud saltlen. Si salt es NULL, entonces saltlen debe ser 0. La función no intentará calcular la longitud del salt ya que no se supone que esté terminado en nulo.

iter es el contador de iteraciones y su valor debe ser mayor o igual a 1. RFC 2898 sugiere un contador de iteraciones de al menos 1000. Cualquier valor de iter menor que 1 es inválido; tales valores resultarán en fallo y generarán el error PROV_R_INVALID_ITERATION_COUNT.

digest es la función de resumen de mensajes utilizada en la derivación. PKCS5_PBKDF2_HMAC_SHA1() llama a PKCS5_PBKDF2_HMAC() con EVP_sha1().

La clave derivada se escribirá en out. El tamaño del buffer out se especifica a través de keylen.

NOTAS

Una aplicación típica de esta función es derivar material de clave para un algoritmo de cifrado a partir de una contraseña en pass, un salt en salt y un contador de iteraciones.

Aumentar el parámetro iter ralentiza el algoritmo, lo que dificulta que un atacante realice un ataque de fuerza bruta utilizando un gran número de contraseñas candidatas.

Estas funciones no hacen suposiciones sobre la contraseña dada. Simplemente se tratará como una secuencia de bytes.

VALORES DE RETORNO

PKCS5_PBKDF2_HMAC() y PBKCS5_PBKDF2_HMAC_SHA1() devuelven 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN

evp(7), RAND_bytes(3), EVP_BytesToKey(3), passphrase-encoding(7)
