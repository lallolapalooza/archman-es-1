Advertencia

A partir de PhysicsFS 2.1, usa PHYSFS_EnumerateCallback con PHYSFS_enumerate() en su lugar; te da más control sobre el proceso.

Estos se utilizan para informar una lista de entradas de directorio a un llamador original, un archivo/directorio/enlace simbólico por callback. Todas las cadenas están codificadas en UTF-8. Las funciones no deben intentar modificar ni liberar la memoria de ninguna cadena.

Puedes cambiar la raíz de un archivo en cualquier momento, alterando el árbol de archivos interpolado (dependiendo de dónde cambien las rutas, otro archivo puede estar proporcionando varios archivos). Establecer una nueva raíz no se limita a los archivos en la ruta de búsqueda; puedes establecer una también en el directorio de escritura, lo que podría ser útil si tienes archivos abiertos para escritura y por lo tanto no puedes cambiar el directorio de escritura en este momento.

No es un error establecer un subdirectorio que no existe como raíz de un archivo; sin embargo, en este caso no se verá ningún archivo. Si los directorios faltantes terminan creándose (un mkdir en el sistema de archivos físico, etc.) entonces esto se reflejará en el árbol interpolado.

Detailed Description

These functions convert an unsigned integer from the platform's native byte order to the specified endianness (big-endian or little-endian) and write it to a file.

These are convenience functions. The general way to write to a file is via PHYSFS_write().
