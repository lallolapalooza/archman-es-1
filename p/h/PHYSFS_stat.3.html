int   PHYSFS_mount (const char * newDir, const char * mountPoint, int   appendToPath)


Añade un archivo de archivo o un directorio a la ruta de búsqueda. Si esto
    es un duplicado, la entrada no se añade de nuevo, aunque la función tenga éxito.
    No puede añadir el mismo archivo de archivo a dos puntos de montaje diferentes:
    la comprobación de duplicados se realiza contra el archivo y no contra el
    punto 
de montaje.

Cuando monta un archivo de archivo, se añade a un sistema de archivos
    virtual...todos los archivos en todos los archivos de archivo se interpolan en
    un único árbol de archivos jerárquico. Dos archivos de archivo montados en el
    mismo lugar (o un archivo de archivo con archivos que se superponen con otro
    punto de montaje) pueden tener archivos superpuestos: en tal caso, se selecciona
    el archivo más antiguo en la ruta de búsqueda y los otros archivos son
    inaccesibles para la aplicación. Esto permite que los archivos de archivo se
    usen para sobrescribir revisiones anteriores; puede usar el mecanismo de montaje
    para colocar archivos de archivo en un punto específico en el árbol de archivos
    y prevenir superposiciones; esto es 
útil para mods descargables que podrían
    pisar sobre los datos de la aplicación o entre ellos, por ejemplo.

El punto de montaje no necesita existir antes del montaje, lo cual es
    diferente a lo que aquellos familiarizados con el concepto de "montar" de Unix
    esperarían. Además, se pueden montar más de un archivo de archivo en el mismo
    punto de montaje, o los puntos de montaje y el contenido del archivo de archivo
