MMV(3) Documentación de Perl aportada por el usuario MMV(3)

NOMBRE

PCP::MMV - Módulo Perl para instrumentación de Valores Mapeados en Memoria

SINOPSIS

use PCP::MMV;

DESCRIPCIÓN

El módulo Perl PCP::MMV contiene los enlaces de lenguaje para construir programas Perl instrumentados con la infraestructura de Valores Mapeados en Memoria del Performance Co-Pilot (PCP), un mecanismo de transporte de datos eficiente para hacer que los datos de rendimiento de un programa Perl estén disponibles como métricas de PCP utilizando el PMDA MMV.

VER TAMBIÉN

mmv_stats_init(3), mmv_inc_value(3), mm_set_value(3), mmv_lookup_value_desc(3), mmv(5) y PMDA(3).

La lista de correo de PCP pcp@groups.io se puede utilizar para preguntas sobre este módulo.

Se pueden encontrar más detalles en https://pcp.io
