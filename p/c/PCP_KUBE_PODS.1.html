PCP_KUBE_PODS(1) Manual de Comandos Generales PCP_KUBE_PODS(1)

NOMBRE

pcp-kube-pods - lista los pods de Kubernetes a escanear en busca de servicios PCP en ejecución

SINOPSIS

$PCP_BINADM_DIR/discover/pcp-kube-pods

DESCRIPCIÓN

pcp-kube-pods utiliza kubectl(1) para proporcionar una lista de direcciones IP de los PODs que se ejecutan en un clúster de Kubenetes local, que pueden estar ejecutando servicios PCP como pmcd(1) y pmproxy(1).

Es utilizado por el comando pmfind(1) y la API pmDiscoverServices(3) como un comando de tipo "shell".

El script invoca la línea de comandos kubectl get pod (ver kubectl-get(1)) para descubrir las direcciones IP de los pods. El campo de salida .status.podIP se extrae del objeto(s) de pod de Kubernetes. Se pueden especificar opciones adicionales a través del archivo de configuración, como -l service=database para restringir los resultados utilizando etiquetas de pod de Kubernetes. El archivo de configuración predeterminado es $PCP_SYSCONF_DIR/discover/pcp-kube-pods.conf.

Si no se encuentra ningún comando kubectl local, no se informa nada y se devuelve un código de salida que indica éxito.

DIAGNÓSTICOS

Todos los diagnósticos producidos son proporcionados por el comando kubectl.

El estado de salida de kubectl se propaga sin cambios.

ARCHIVOS

$PCP_BINADM_DIR/discover
ruta predeterminada para comandos de descubrimiento de direcciones como pcp-kube-pods
$PCP_SYSCONF_DIR/discover/pcp-kube-pods.conf
archivo de configuración que contiene las opciones de línea de comandos que se pasan a kubectl-get
$PCP_SYSCONF_DIR/discover/pcp-kube-pods.disabled
la existencia de este archivo hace que el script no informe nada

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

kubectl-get(1), kubectl(1), pmcd(1), pmfind(1), pmDiscoverServices(3) y pcp.env(5).
