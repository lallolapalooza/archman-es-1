LogImport(3) Documentación de Perl contribuida por el usuario LogImport(3)

NOMBRE

PCP::LogImport - Módulo Perl para importar datos de rendimiento y crear un archivo de Performance Co-Pilot

SINOPSIS

use PCP::LogImport;

DESCRIPCIÓN

El módulo PCP::LogImport contiene las vinculaciones de lenguaje para construir aplicaciones Perl que importan datos de rendimiento desde un archivo o una fuente en tiempo real y crean un archivo de Performance Co-Pilot (PCP) adecuado para su uso con las herramientas de PCP.

Las rutinas de este módulo proporcionan envolturas alrededor de la biblioteca libpcp_import y algunas de las rutinas de la biblioteca libpcp.
