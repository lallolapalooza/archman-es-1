NOMBRE

PCPIntro - introducción a las bibliotecas de Performance Co-Pilot (PCP)

INTRODUCCIÓN

Performance Co-Pilot (PCP) es un conjunto de herramientas diseñado para monitorizar y gestionar el rendimiento a nivel de sistema.

Las bibliotecas de PCP soportan las APIs necesarias para crear nuevas herramientas de monitorización de rendimiento y nuevos agentes (o PMDA) para exportar datos de rendimiento. La biblioteca libpcp se utiliza en ambos casos. La biblioteca libpcp_pmda se utiliza solo para PMDA.

Las rutinas individuales de la biblioteca se documentan en sus propias entradas de página de manual.

La mayoría de las rutinas devuelven un valor entero; mayor o igual a cero para éxito y menor que cero para un error. Los códigos de error tienen nombres simbólicos definidos en <pcp/pmapi.h>. Otros valores negativos se utilizan para codificar errores que pueden mapearse a los valores tradicionales de errno definidos en <errno.h>, con el valor negado. Para traducir todos los códigos de error de PCP a mensajes útiles, utilice pmerr(1) o pmErrStr(3); este último también puede utilizarse para decodificar los casos de -errno.

ERRORES GENERALES

Estos errores comunes pueden ocurrir en varias interacciones de PCP.

PM_ERR_TIMEOUT
Tiempo de espera agotado esperando una respuesta de PMCD
Muchas interacciones entre aplicaciones PCP implican paso de mensajes síncrono, y estas están sujetas a restricciones de tiempo de espera. Estos errores se encuentran con mayor frecuencia al usar conexiones de red con tasas de datos lentas o latencias largas.

Para tiempos de espera de cliente-pmcd, consulte PCPIntro(1) para variables de entorno que pueden usarse para modificar los umbrales de tiempo de espera. Para tiempos de espera de pmcd-PMDA, consulte las opciones -t y -q de pmcd(1) y la métrica PCP pmcd.control.timeout que puede cambiarse dinámicamente con pmstore(1).

PM_ERR_APPVERSION
La aplicación monitorizada no soporta esta versión de la métrica
Algunas métricas de rendimiento no están disponibles en versiones específicas del PMDA asociado, o pueden no estar disponibles porque la instrumentación subyacente ha cambiado o no está instalada o no está habilitada. Este error se utiliza en los resultados de pmFetch(3) para indicar estas situaciones.
PM_ERR_IPC
Fallo del protocolo IPC
Fallo genérico del protocolo en una tubería o socket que conecta dos aplicaciones PCP, por ejemplo, cliente-pmcd, o cliente-pmtime, o PMDA-pmcd o pmlc-pmlogger.
PM_ERR_TEXT
No hay texto de una línea o de ayuda disponible
Establecido por un PMDA y devuelto a un cliente PCP para indicar que el PMDA no puede proporcionar la métrica solicitada o el texto de ayuda del dominio de instancias.
PM_ERR_VALUE
Falta valor(es) de métrica
Este error se utiliza para varias condiciones en las que el valor de una métrica de rendimiento es inapropiado para el contexto en el que se está utilizando, por ejemplo:
(a)
Valor incorrecto para la métrica pmcd.timezone al intentar establecer la zona horaria a través de pmNewContextZone(3) para un contexto remoto o de archivo.
(b)
Intento de interpolar valores para una métrica con tipo de datos no numérico a partir de un conjunto de archivos PCP.
(c)
Una estructura de datos de resultado incorrecta pasada a pmStore(3).
PM_ERR_NAME
Nombre de métrica desconocido
Exactamente lo que dice el mensaje.
PM_ERR_PMID
Identificador de métrica desconocido o ilegal
Exactamente lo que dice el mensaje.
PM_ERR_INDOM
Identificador de dominio de instancia desconocido o ilegal
Una solicitud nombra un dominio de instancia que es desconocido o PM_INDOM_NULL. Puede ocurrir como consecuencia del identificador del dominio de instancia pasado por un cliente PCP a pmGetInDom(3), pmLookupInDom(3), pmNameInDom(3), pmGetInDomArchive(3), pmLookupInDomArchive(3), pmNameInDomArchive(3) o una solicitud pasada de pmcd(1) a un PMDA.
PM_ERR_EOF
Canal IPC cerrado
Fin de archivo en una tubería o socket que conecta dos aplicaciones PCP, por ejemplo, cliente-pmcd, o cliente-pmtime o PMDA-pmcd.
PM_ERR_NOCONTEXT
Intento de usar un contexto ilegal
Típicamente causado por un cliente PCP que intenta hacer llamadas antes de llamar a pmNewContext(3) o después de llamar a pmDestroyContext(3).
PM_ERR_PERMISSION
Sin permiso para realizar la operación solicitada
Los controles de acceso específicos de PCP se aplican a pmcd(1) y pmlogger(1). Los errores de permisos específicos de la plataforma se devuelven como -EPERM.
PM_ERR_CONV
Conversión de valor o escala imposible
Algunas solicitudes de conversión de valor son ilegales, por ejemplo, un nombre simbólico de bandera de depuración incorrecto para la opción -D/--debug, o pedir a pmExtractValue(3) que convierta tipos de datos no numéricos a números y viceversa.
PM_ERR_TRUNC
Truncamiento en la conversión de valor
Algunas solicitudes de conversión a pmExtractValue(3) no se pueden realizar basándose en los tipos y valores de las métricas involucradas, en cuyo caso la conversión resultaría en pérdida de precisión.
PM_ERR_SIGN
Valor negativo en la conversión a sin signo
Algunas solicitudes de conversión a pmExtractValue(3) no se pueden realizar basándose en los tipos y valores de las métricas involucradas, en cuyo caso la conversión de un valor negativo a un valor sin signo.
PM_ERR_TYPE
Tipo de métrica desconocido o ilegal
El tipo de métrica se mantiene en el descriptor de métrica y a veces se codifica en los valores de métrica devueltos por una llamada a pmFetch(3). Los valores legales para el tipo de métrica están definidos por las macros PM_TYPE_* en <pcp/pmapi.h>.
PM_ERR_UNIT
Especificación de pmUnits ilegal
Algunas solicitudes de conversión a pmConvScale(3) no se pueden realizar debido a especificaciones ilegales o incompatibles de las unidades de origen y destino.
PM_ERR_PROFILE
Se requieren identificadores de instancia explícitos
Algunos PMDA, especialmente el PMDA proc, no devolverán "todas las instancias" para una solicitud pmFetch(3) debido al costo. El cliente debe construir explícitamente un perfil de instancia usando pmAddProfile(3) y/o pmDelProfile(3) antes de llamar a pmFetch(3). Ver también la opción -F/--fetchall de pminfo(1).
PM_ERR_INST
Identificador de instancia desconocido o ilegal
Una solicitud a un PMDA nombra una instancia que es desconocida. Puede ocurrir como consecuencia del perfil establecido antes de una llamada a pmFetch(3), o un nombre o identificador de instancia explícito

PMAPI ERRORS

These errors are returned by the Performance Metrics Application Programming Interface (PMAPI) library, libpcp.

PM_ERR_CONGESTION
pmda out of file descriptors
This error is generated by a Performance Metrics Domain Agent (PMDA) when it is unable to allocate a new file descriptor because the system-wide limit has been reached. The PMDA should be restarted after the system configuration has been adjusted.
PM_ERR_EINVAL
Invalid argument to subroutine
This error code is returned when a subroutine is called with one or more invalid arguments. The documentation for each subroutine details the valid range of arguments.
PM_ERR_PMDA_COMM
Communication error with a PMDA
This indicates a protocol error or a communication failure between the Performance Metrics Collection Daemon (pmcd(1)) and a PMDA. Typically this may be caused by the PMDA crashing or exiting prematurely.
PM_ERR_PMDA_TIMEOUT
Timeout waiting for a PMDA
A request to a PMDA has timed out. This may be due to the PMDA being overloaded, or it may indicate a deadlock condition within the PMDA.
PM_ERR_DUPLICATE_PMID
Duplicate performance metric identifier
This error is returned if a PMDA attempts to register a performance metric identifier (pmid) that has already been registered by another PMDA within the same performance metric domain.
PM_ERR_FALLBACK
PMNS lookup failed, attempting fallback
When looking up performance metric names, the Performance Metrics Namespace (PMNS) is consulted first. If the lookup fails, a fallback mechanism may be invoked to search for the metric definition in the PMDA configuration files. This error indicates that the lookup failed and the fallback mechanism was also unsuccessful.
PM_ERR_INMMAP
Cannot mmap PMNS file
This error occurs when the libpcp library is unable to memory-map the PMNS file. This could be due to insufficient permissions or other file system issues.
PM_ERR_INDOM_TOOBIG
Instance domain size exceeds limit
The number of instances in an instance domain exceeds the maximum allowed limit. This is a safeguard against excessively large instance domains that could lead to performance issues or memory exhaustion.
PM_ERR_INST_TOOBIG
Instance label too long
The label for an instance of a performance metric exceeds the maximum allowed length. Instance labels should be kept reasonably short to avoid potential display or storage issues.
PM_ERR_INTERIM_VALUE
Interim value returned
This error is returned when a PMDA provides an interim or estimated value for a performance metric. This may happen during periods of high system load or when a precise value cannot be immediately determined.
PM_ERR_IOERR
I/O error detected
A general input/output error occurred during an operation. This could be related to disk access, network communication, or other I/O related activities.
PM_ERR_MAXVAL
Maximum value exceeded
The value of a performance metric exceeded its defined maximum limit. This could indicate an anomaly or a potential issue with the monitored system.
PM_ERR_MINTEXTLEN
Minimum text length not met
This error is returned when the provided text for a metric description or help text is shorter than the minimum required length.
PM_ERR_NONFATAL_PMDA
Non-fatal error reported by PMDA
A PMDA has reported an error that is not critical enough to halt operations, but may indicate a minor issue or a warning condition.
PM_ERR_NONLEAF
PMNS node not a leaf node
This error occurs when an attempt is made to treat a non-leaf node in the PMNS as if it were a leaf node (i.e., a performance metric). PMNS nodes can represent either individual metrics or groups of metrics.
PM_ERR_NOTFOUND
Name not found
The specified name could not be found in the relevant context, such as the PMNS or a PMDA's registered metrics.
PM_ERR_NOTIMPLEMENT
Functionality not implemented
The requested functionality is not yet implemented in the current version of the library or PMDA.
PM_ERR_NOSTORE
Storing metrics not supported
The current context or PMDA does not support storing metric values. Storing is typically used for setting metric values, which may not be applicable in all environments (e.g., read-only archive contexts).
PM_ERR_NOSTORE_ITEM
Storing specific item not supported
Similar to PM_ERR_NOSTORE, but indicates that storing is not supported for a particular metric or item within a metric.
PM_ERR_OFFSET
Offset out of bounds
An offset value used to access data is outside the valid bounds of the data structure or buffer.
PM_ERR_PMNSBADNODE
Bad node in PMNS tree
The PMNS tree contains an invalid or corrupted node, preventing proper traversal or lookup operations.
PM_ERR_PMNSConflict
PMNS node name conflict
There is a naming conflict within the PMNS, where multiple nodes have the same name at the same level, which is not allowed.
PM_ERR_PMNSLOCKED
PMNS is locked
An attempt was made to modify the PMNS while it is locked, preventing changes. This is typically a safeguard during initialization or critical operations.
PM_ERR_PMNSNODOT
PMNS node without domain
A node in the PMNS is missing its associated domain identifier, making it impossible to uniquely identify the performance metric.
PM_ERR_PMNSRETURN
PMNS return value error
An unexpected or invalid return value was received from a PMNS operation, indicating an internal inconsistency or error.
PM_ERR_PMNSSEMANTIC
Semantic error in PMNS
There is a semantic issue within the PMNS, such as a metric being defined with incompatible semantics or properties.
PM_ERR_PMNSSYNTAX
Syntax error in PMNS
The PMNS definition contains a syntax error, preventing it from being parsed correctly.
PM_ERR_PMNSUNKNOWN
Unknown PMNS node or name
The specified node or name does not exist in the PMNS.
PM_ERR_PMNSUNLINK
PMNS unlink failed
An attempt to remove a node or entry from the PMNS failed.
PM_ERR_PMDA_NOREGSITER
No registered site for PMDA
A PMDA is attempting to register itself, but no valid site information is available. This usually indicates a configuration problem with the PMDA or the system.
PM_ERR_PMDA_NOSETDISC
PMDA does not support discovery
The PMDA does not support the discovery mechanism used to identify available performance metrics. This might happen if the PMDA is old or does not implement the necessary protocols.
PM_ERR_PMDA_NOSUPPORT_PMNS_VER
PMDA does not support PMNS version
The PMDA is incompatible with the version of the PMNS being used. A newer version of the PMDA might be required, or the PMNS needs to be updated.
PM_ERR_PMDA_PID_ALREADY_RUNNING
PMDA PID already running
An attempt was made to start a PMDA process, but a process with the same identifier (PID) is already running. This prevents duplicate instances of the PMDA from starting.
PM_ERR_PMDA_READ_TIMEOUT
PMDA read timeout
The read operation from a PMDA timed out. This suggests that the PMDA is not responding in a timely manner, possibly due to being overloaded or stuck.
PM_ERR_PMDA_SEMANTICS
Semantic error in PMDA output
The data returned by a PMDA has semantic inconsistencies or does not conform to the expected format or meaning of the performance metric.
PM_ERR_PMDA_SYNTAX
Syntax error in PMDA output
The data returned by a PMDA has a syntax error, meaning it is malformed or does not follow the expected structure for performance metric data.
PM_ERR_PMDA_TIMEOUT
PMDA timeout
A request to a PMDA timed out. This is a general timeout error and may indicate that the PMDA is unresponsive or has encountered an internal issue.
PM_ERR_PMDA_UNKNOWN_METRIC
PMDA does not know requested metric
The PMDA was asked for a performance metric that it does not provide or does not recognize. This could happen if the client is using an outdated metric name or identifier.
PM_ERR_PMDA_WRITE_TIMEOUT
PMDA write timeout
The write operation to a PMDA timed out. This could indicate issues with the PMDA's ability to accept data or communication problems.
PM_ERR_PMDA_ZOMBIE
PMDA process is a zombie
The PMDA process has become a zombie process, indicating it has terminated but its parent process has not yet collected its exit status. This typically points to issues with process management or termination handling.
PM_ERR_PMDA_ZOMBIE_CHILD
PMDA has zombie child processes
The PMDA itself has zombie child processes. This suggests that the PMDA is not properly managing its child processes, leading to resource leaks or potential issues.
PM_ERR_PMNS_BAD_DOMAIN
Invalid performance metric domain identifier
The performance metric domain identifier is invalid or does not correspond to any known domain.
PM_ERR_PMNS_BAD_PMID
Invalid performance metric identifier
The performance metric identifier (pmid) is invalid or does not exist within the specified domain.
PM_ERR_PMNS_NULL_DOMAIN
Null performance metric domain pointer
A null pointer was passed where a valid performance metric domain identifier was expected.
PM_ERR_PMNS_NULL_PMNS
Null PMNS pointer
A null pointer was passed where a valid pointer to the PMNS structure was expected.
PM_ERR_PMNS_REFUSED
PMNS query refused
The PMNS server refused the query. This could be due to various reasons, such as network issues, authentication failures, or server-side errors.
PM_ERR_PMNS_RETRY
PMNS query retry needed
The PMNS query needs to be retried. This might happen due to temporary network glitches or server load conditions.
PM_ERR_PMNS_TIMEOUT
PMNS query timeout
The query to the PMNS timed out. The server did not respond within the expected timeframe.
PM_ERR_TEXTLOOKUP
Text lookup failed
Failed to retrieve help text or description for a performance metric. This could be due to missing text files, corruption, or issues with the lookup mechanism.
PM_ERR_TOOMANY
Too many items
The number of items (e.g., metrics, instances) exceeds the maximum allowed limit. This is a safety measure to prevent excessive resource consumption.
PM_ERR_TOOMANY_ARGS
Too many arguments
A function was called with more arguments than it can handle. Check the function signature and the number of arguments provided.
PM_ERR_TOOMANY_INSTANCES
Too many instances for metric
The number of instances provided for a metric exceeds the allowed limit. This is relevant when registering or updating metrics with multiple instances.
PM_ERR_TOOMANY_METRICS
Too many metrics
The number of metrics requested or processed exceeds the maximum allowed limit. This might occur when fetching a large number of metrics simultaneously.
PM_ERR_TOOSMALL
Insufficient elements in list
Parameter passing error by caller specifying a list with less than one element to pmFetch(3), pmLookupName(3) or pmStore(3).
PM_ERR_WAITING
Waiting for PMDA response
This indicates that a response from a PMDA is still pending. It is not necessarily an error, but may signify that the PMDA is taking a long time to respond.
PM_ERR_NULL_ARG
Null argument passed to subroutine
A null pointer was passed as an argument to a function where a valid pointer was expected. This is a common programming error.
PM_ERR_INTR
Operation interrupted
The operation was interrupted, possibly by a signal or an external event. The operation may need to be retried.
PM_ERR_BADXML
Malformed XML data
The XML data being processed is malformed or does not conform to the expected schema. This is often encountered when parsing configuration files or other XML-based data sources.
PM_ERR_PMDA_TEXTDOMAIN
PMDA text domain error
An error occurred while accessing or processing the text domain associated with a PMDA. This domain contains help text and descriptions for performance metrics.
PM_ERR_PMNS_TEXTDOMAIN
PMNS text domain error
An error occurred while accessing or processing the text domain associated with the PMNS. This domain contains help text and descriptions for performance metrics defined in the namespace.

PM_ERR_PMDA_VALUE_RANGE
