LogSummary(3) Documentación de Perl contribuida por el usuario LogSummary(3)

NOMBRE

PCP::LogSummary - Interfaz de Perl para pmlogsummary(1)

SINOPSIS

use PCP::LogSummary;
my $summary = new PCP::LogSummary($log, \@metrics, $start, $end);

DESCRIPCIÓN

El módulo PCP::LogSummary es un envoltorio alrededor del comando Performance Co-Pilot pmlogsummary(1). Su propósito principal es automatizar la producción de datos pmlogsummary post-procesados, en particular para automatizar el paso donde los datos resumidos se importan en una hoja de cálculo para un análisis posterior. Esto ha demostrado ser a menudo un proceso iterativo; hecho manualmente implica mucho copiar y pegar, y puede ser una pérdida de tiempo considerable.
