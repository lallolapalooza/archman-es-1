POE::Component::Client::HTTP::Request(3) Documentación de Perl contribuida por el usuario POE::Component::Client::HTTP::Request(3)

NOMBRE

POE::Component::Client::HTTP::Request - una clase de solicitud HTTP

VERSIÓN

versión 0.949

SINOPSIS

# Usado internamente por POE::Component::Client::HTTP

DESCRIPCIÓN

POE::Component::Client::HTTP::Request encapsula el estado de las solicitudes que POE::Component::Client::HTTP gestiona durante su ciclo de vida. Resulta que hay mucho estado que administrar.

CONSTRUCTOR

new PARÁMETROS NOMBRADOS

Crea un objeto POE::Component::Client::HTTP para administrar una solicitud. El constructor acepta varios parámetros nombrados:

Solicitud => HTTP_SOLICITUD
Un objeto POE::Component::Client::HTTP::Request encapsula un objeto HTTP::Request normal. Requerido.
Fábrica => POE_COMPONENT_CLIENT_HTTP_FÁBRICA_SOLICITUDES
La solicitud puede crear solicitudes adicionales durante su vida útil, por ejemplo, al seguir redirecciones. El parámetro Fábrica especifica la POE::Component::Client::HTTP::RequestFactory que se puede utilizar para crearlas. Requerido.
Devolución_de_llamada => DEVOLUCIÓN_DE_LLAMADA_RESPUESTA
POE::Component::Client::HTTP crea una devolución de llamada que se utilizará para enviar respuestas a la sesión solicitante. Requerido.
Progreso => DEVOLUCIÓN_DE_LLAMADA_PROGRESO
Establece la notificación de progreso si el usuario ha solicitado eventos de progreso. Opcional.
Proxy
Establece el proxy utilizado para esta solicitud, si lo solicita el usuario. Opcional.

MÉTODOS

ID

Devuelve el ID único de la solicitud.

devolver_respuesta

Envía una respuesta a la sesión del usuario. Llamado por POE::Component::Client::HTTP cuando ha llegado una respuesta completa.

añadir_eof

Llamado por POE::Component::Client::HTTP para indicar que ha llegado el fin de archivo (EOF).

añadir_contenido DATOS_ANALIZADOS

Llamado por POE::Component::Client::HTTP para agregar datos de contenido a una respuesta construida incrementalmente. Si DATOS_ANALIZADOS es un objeto, se trata como un objeto HTTP::Headers y sus encabezados se asimilan en la respuesta que está siendo construida por la solicitud. De lo contrario, DATOS_ANALIZADOS se adjunta al contenido de la respuesta.

temporizador TEMPORIZADOR

Accesorio para manipular el temporizador de tiempo de espera de la solicitud. Establece el temporizador de la solicitud si se especifica TEMPORIZADOR, de lo contrario, simplemente recupera el que está actualmente asociado con la solicitud.

crear_temporizador TIEMPO_DE_ESPERA

Crea y establece un temporizador para esta solicitud. TIEMPO_DE_ESPERA es el número de segundos que puede vivir esta solicitud.

eliminar_tiempo_de_espera

Desactiva el temporizador asociado con esta solicitud y lo descarta.

devolucion_de_llamada DEVOLUCIÓN_DE_LLAMADA

Accesorio para manipular la devolución de llamada asociada con esta solicitud. Establece la devolución de llamada si DEVOLUCIÓN_DE_LLAMADA está definido, de lo contrario, simplemente la recupera.

hace_redirección ALGO

FIXME - No estoy seguro de lo que hace este accesorio.

verificar_redirección

Verifica si la última respuesta es una redirección, si se permite seguir redirecciones y si no se ha alcanzado el número máximo de redirecciones. Inicia una redirección si todas las condiciones son favorables.

cerrar_conexión

Cada objeto de solicitud activo contiene una conexión interna. Este método la cierra.

enviar_a_rueda

Transmite la solicitud al socket asociado con esta solicitud.

rueda

Un accesorio para devolver la rueda asociada con esta solicitud.

error CÓDIGO_ERROR, MENSAJE_ERROR

Genera una respuesta de error y la envía de vuelta a la sesión del usuario.

error_conexión MENSAJE_FALLO_CONEXIÓN

Genera una respuesta de error de conexión y la envía de vuelta a la sesión del usuario.

host

Devuelve el host con el que la solicitud está intentando trabajar.

puerto

Devuelve el puerto con el que la solicitud está intentando trabajar.

esquema

Devuelve el esquema para esta solicitud.
