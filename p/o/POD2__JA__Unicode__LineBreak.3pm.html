NOMBRE

Unicode::LineBreak~[ja] - Algoritmo de salto de línea Unicode UAX #14

SINOPSIS

use Unicode::LineBreak;
$lb = Unicode::LineBreak->new();
$broken = $lb->break($string);

DESCRIPCIÓN

Unicode::LineBreak implementa el algoritmo de salto de línea Unicode descrito en el Anexo Unicode #14 (UAX #14). Al determinar los puntos de salto, también considera la propiedad East_Asian_Width definida en el Anexo Unicode #11 (UAX #11).

Terminología

Se utilizan los siguientes términos de forma conveniente:

Salto obligatorio (mandatory break) se define por reglas básicas y se aplica obligatoriamente independientemente de los caracteres circundantes. Salto de oportunidad (break opportunity) se realiza cuando el usuario decide realizar un salto de línea. En UAX #14, los saltos de oportunidad se dividen en salto directo (direct break) e indirecto (indirect break).

Los caracteres alfabéticos (alphabetic characters) son aquellos que normalmente no brindan una oportunidad de salto a otros caracteres y no se pueden separar entre caracteres idénticos. Los caracteres ideográficos (ideographic characters) son aquellos que normalmente se pueden separar entre ellos. En UAX #14, la mayoría de los caracteres alfabéticos se clasifican como AL y la mayoría de los caracteres ideográficos como ID (estas terminologías son imprecisas desde la perspectiva de la lingüística). Para muchos sistemas de escritura, los puntos de salto no están claros para caracteres individuales, por lo que se utiliza un método de búsqueda para los diccionarios. Los caracteres que no son ni alfabéticos ni ideográficos se clasifican según las reglas de UAX #14.

El ancho de carácter (character width) de una cadena de caracteres no se refiere al número de caracteres en la cadena. Cada carácter es ancho (wide), estrecho (narrow) o no espaciado (nonspacing), ocupando 2, 1 o 0 unidades de espacio, respectivamente. Los caracteres pueden ocupar un rango más amplio de anchos dependiendo del sistema de escritura utilizado. El número de caracteres en una cadena de texto no se refiere a la cantidad de caracteres en la cadena. Cada carácter es ancho (wide), estrecho (narrow) o no espaciado (nonspacing), ocupando 2, 1 o 0 unidades de espacio, respectivamente. Los caracteres pueden ocupar un rango más amplio de anchos dependiendo del sistema de escritura utilizado.

Acción de división definida por el usuario

Cuando cualquier división excede las limitaciones de CharMax, ColMax o ColMin, se puede realizar una división urgente en la cadena de texto que se está heredando. Cuando se especifica una referencia a una subrutina para la opción "Urgent", esa subrutina debe tomar dos argumentos.

@post-split = &subroutine(SELF, STR);

SELF es el objeto Unicode::LineBreak, y STR es la cadena de texto Unicode a dividir.

La subrutina debe devolver una matriz de los resultados de la división de la cadena STR.

Nota: Los índices de las cadenas son en realidad listas de elementos literales. Consulte Unicode::GCString~[ja].

Por ejemplo, el siguiente código inserta guiones en los nombres de algunos compuestos químicos (como los de la tiamina) para que puedan ser saltados de línea.

sub hyphenize {
    return map {$_ =~ s/yl$/yl-/; $_} split /(\w+?yl(?=\w))/, $_[1];
}
my $lb = Unicode::LineBreak->new(Urgent => \&hyphenize);
$output = $lb->break("Methionylthreonylthreonylglutaminylarginyl...");

Cuando se especifica una referencia de matriz de [REGEX, SUBREF] para la opción "Prep", la subrutina debe tomar dos argumentos.

@post-split = &subroutine(SELF, STR);

SELF es el objeto Unicode::LineBreak, y STR es la cadena de texto Unicode a dividir que coincide con REGEX.

La subrutina debe devolver una matriz de los resultados de la división de la cadena STR.

Por ejemplo, el siguiente código divide las URL de HTTP utilizando las reglas de [CMOS].

my $url = qr{http://[\x21-\x7E]+}i;
sub breakurl {
    my $self = shift;
    my $str = shift;
    return split m{(?<=[/]) (?=[^/]) |
                   (?<=[^-.]) (?=[-~.,_?\#%=&]) |
                   (?<=[=&]) (?=.)}x, $str;
}
my $lb = Unicode::LineBreak->new(Prep => [$url, \&breakurl]);
$output = $lb->break($string);

Mantenimiento de estado

El objeto Unicode::LineBreak se utiliza como tabla hash. Se pueden almacenar elementos arbitrarios durante la vida útil del objeto.

Por ejemplo, el siguiente código divide los párrafos con líneas en blanco.

sub paraformat {
    my $self = shift;
    my $action = shift;
    my $str = shift;

    if ($action eq 'sot' or $action eq 'sop') {
        $self->{'line'} = '';
    } elsif ($action eq '') {
        $self->{'line'} = $str;
    } elsif ($action eq 'eol') {
        return "\n";
    } elsif ($action eq 'eop') {
        if (length $self->{'line'}) {
            return "\n\n";
        } else {
            return "\n";
        }
    } elsif ($action eq 'eot') {
        return "\n";
    }
    return undef;
}
my $lb = Unicode::LineBreak->new(Format => \¶format);
$output = $lb->break($string);

Cálculo de la longitud de la cadena

Cuando se especifica una referencia a una subrutina para la opción "Sizing", esa subrutina debe tomar cinco argumentos.

$num_seats = &subroutine(SELF, LEN, PRE, SPC, STR);

SELF es el objeto Unicode::LineBreak, LEN es la longitud de la cadena de texto previa, PRE es la cadena de texto Unicode previa, SPC es el espacio en blanco que se añadirá, y STR es la cadena de texto Unicode a procesar.

La subrutina debe devolver el número de asientos para "PRE.SPC.STR". El número de asientos puede ser un número de punto flotante. La unidad del número de asientos es arbitraria, pero debe ser coherente con las opciones "ColMin" y "ColMax".

Nota: Los índices de las cadenas son en realidad listas de elementos literales. Consulte Unicode::GCString~[ja].

Por ejemplo, el siguiente código procesa como si hubiera tabulaciones de 8 asientos por línea.

sub tabbedsizing {
    my ($self, $cols, $pre, $spc, $str) = @_;

    my $spcstr = $spc.$str;
    while ($spcstr->lbc == LB_SP) {
        my $c = $spcstr->item(0);
        if ($c eq "\t") {
            $cols += 8 - $cols % 8;
        } else {
            $cols += $c->columns;
        }
        $spcstr = $spcstr->substr(1);
    }
    $cols += $spcstr->columns;
    return $cols;
};
my $lb = Unicode::LineBreak->new(LBClass => [ord("\t") => LB_SP],
                                 Sizing => \&tabbedsizing);
$output = $lb->break($string);

Modificación manual de las propiedades de los caracteres

Con las opciones "LBClass" u "EAWidth", las propiedades de división de línea (tipo) o las propiedades East_Asian_Width de caracteres individuales pueden modificarse manualmente. Se definen varias constantes para facilitar su uso.

Propiedad de división de línea

Caracteres que prohíben el inicio de línea, como pseudónimos.

Por defecto, los pseudónimos y otros similares se tratan como caracteres que prohíben el inicio de línea (NS o CJ). Por ejemplo:

Marcas de cita ambiguas

Inicialmente, algunas marcas se tratarán como marcas de cita ambiguas (QU).

"BACKWARD_QUOTES() => LB_OP, FORWARD_QUOTES() => LB_CL"
En algunos idiomas (holandés, inglés, italiano, portugués, español, turco, y muchos idiomas del sudeste asiático), se utilizan comillas (', “) que son giros de 9 para las marcas de apertura, y comillas (', ”) que son giros de 9 para las marcas de cierre.
"FORWARD_QUOTES() => LB_OP, BACKWARD_QUOTES() => LB_CL"
En otros idiomas (checo, danés, eslovaco), se utilizan comillas (', ”) para las marcas de apertura y comillas (', “) que son giros de 9 para las marcas de cierre.
"BACKWARD_GUILLEMETS() => LB_OP, FORWARD_GUILLEMETS() => LB_CL"
En francés, griego, ruso, etc., se utilizan guillemets (‹, ‚) para la izquierda como marcas de apertura y guillemets (›, ’) para la derecha como marcas de cierre.
"FORWARD_GUILLEMETS() => LB_OP, BACKWARD_GUILLEMETS() => LB_CL"
En alemán y eslovaco, se utilizan guillemets (›, ’) para la derecha como marcas de apertura y guillemets (‹, ‚) para la izquierda como marcas de cierre.

En alemán, finés, noruego, sueco, se utilizan comillas (', ”) y guillemets (›, ’) tanto para marcas de apertura como de cierre.

El espacio ideográfico puede venir al inicio de línea. Antes de Unicode 6.2, esta era la operación inicial.
"IDEOGRAPHIC_SPACE() => LB_SP"
El espacio ideográfico no aparece al inicio de línea y se omite al final de línea.

Propiedad East_Asian_Width

En los sistemas de alfabetos latino, griego y cirílico, algunos caracteres tienen la propiedad East_Asian_Width Ambiguous (A). Por lo tanto, estos caracteres se tratan como caracteres anchos en el contexto "EASTASIAN". Al especificar "EAWidth => [AMBIGUOUS_*() => EA_N]", esos caracteres se tratan como caracteres estrechos.

"AMBIGUOUS_ALPHABETICS() => EA_N"
Todos los caracteres siguientes se tratan como caracteres de propiedad East_Asian_Width N (Neutral).
"AMBIGUOUS_CYRILLIC() => EA_N"
"AMBIGUOUS_GREEK() => EA_N"
"AMBIGUOUS_LATIN() => EA_N"
Caracteres de los sistemas de alfabetos latino, griego y cirílico con el rango Ambiguo (A) se tratan como caracteres Neutros (N).

Sin embargo, muchos caracteres de los conjuntos de caracteres de codificación de Asia Oriental, que se dibujaban como caracteres anchos en diversas ocasiones, están codificados como caracteres estrechos (Na) en el estándar Unicode. Al especificar las siguientes opciones de EAWidth, estos caracteres se tratan como caracteres anchos en el contexto "EASTASIAN".

"QUESTIONABLE_NARROW_SIGNS() => EA_A"
U+00A2 Símbolo de centavo, U+00A3 Símbolo de libra, U+00A5 Símbolo de yen (o símbolo de yuan), U+00A6 Barra de interrupción, U+00AC Negación, U+00AF Macrón

Conformidad con el estándar

Los valores de propiedad de los caracteres utilizados en este módulo se basan en la versión 8.0.0 del estándar Unicode.

Este módulo implementa el estándar de implementación UAX14-C2.

NOTAS DE IMPLEMENTACIÓN

  • Se selecciona si los caracteres de ciertas palabras se tratan como NS o ID.
  • Se selecciona si los signos de puntuación de colisión y las marcas de unión de colisión se tratan como ID o AL.
  • Los caracteres clasificados como AI se resuelven como AL e ID.
  • Los caracteres clasificados como CB no se resuelven.
  • Los caracteres clasificados como CJ se resuelven siempre como NS. Menos estricto
