POE::Resources(3) Documentación de Perl contribuida por el usuario POE::Resources(3)

NOMBRE

POE::Resources - cargador de recursos de POE

SINOPSIS

# Previsto para uso interno de POE::Kernel.
use POE::Resources;
POE::Resources->load();

DESCRIPCIÓN

POE::Kernel está dividido internamente en diferentes recursos que son gestionados por separado por clases de mezcla individuales.

POE::Resources está diseñado como un gestor de macros de alto nivel para las clases POE::Resource. Actualmente implementa un único método, load(), que carga todas las clases POE::Resource.

MÉTODOS

POE::Resources tiene una interfaz pública, pero está diseñado para ser utilizado internamente por POE::Kernel. Los programadores de aplicaciones nunca deberían necesitar usar POE::Resources directamente.

load

POE::Kernel llama a load() para cargar todos los módulos POE::Resource conocidos.

Cada recurso puede ser manejado por un módulo puramente en Perl, o por un módulo XS. Para cada clase de recurso, load() primero intenta cargar la versión "POE::XS::Resource::..." del módulo. Si falla, load() recurre a "POE::Resource::...".

VER TAMBIÉN

Ver "Resources" en POE::Kernel para información pública sobre los recursos de POE.

Ver POE::Resource para una discusión general sobre los recursos y las clases que los gestionan.
