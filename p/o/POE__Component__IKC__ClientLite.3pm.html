NOMBRE

POE::Component::IKC::ClientLite - Cliente ligero para IKC

SINOPSIS

use POE::Component::IKC::ClientLite;
$poe = POE::Component::IKC::ClientLite->new(port=>1337);
die POE::Component::IKC::ClientLite::error() unless $poe;
$poe->post("Session/event", $param)
    or die $poe->error;

# mala forma de obtener un valor de retorno
my $foo=$poe->call("Session/other_event", $param)
    or die $poe->error;
# mejor forma de obtener un valor de retorno
my $ret=$poe->post_respond("Session/other_event", $param)
    or die $poe->error;
# asegurarse de que la conexión está activa
$poe->ping() 
    or $poe->disconnect;

DESCRIPCIÓN

ClientLite es una implementación de cliente IKC pequeña y puramente en Perl. Es muy básica porque está pensada para usarse en lugares donde POE no encajaría, como mod_perl.

Maneja la reconexión automática. Cuando envías un evento, ClientLite intentará enviar el paquete a través del cable. Si falla, intentará reconectar. Si no puede, devuelve un error. Si puede, volverá a enviar el paquete. Si *esto* falla, bueno, mala suerte.

MÉTODOS

spawn

my $poe = POE::Component::IKC::ClientLite->spawn( %params );

Crea un nuevo objeto PoCo::IKC::ClientLite. Se supone que los parámetros son compatibles con PoCo::IKC::Client, pero los sockets Unix aún no se manejan... Además, hay 3 parámetros adicionales:

block_size
Tamaño, en octetos (bytes de 8 bits), de cada bloque que se lee del socket a la vez. Por defecto es 65535.
timeout
Tiempo, en segundos, que "call" y "post_respond" esperarán una respuesta. Por defecto son 30 segundos.
connect_timeout
Tiempo, en segundos, para esperar a que se complete una fase de la negociación de la conexión. Por defecto es "timeout". Hay 4 fases de negociación, por lo que un "connect_timeout" por defecto de 30 segundos significa que podría tomar potencialmente 2 minutos conectarse.
protocol
Qué protocolo de negociación IKC usar. El protocolo original ("IKC") era síncrono y lento. El nuevo protocolo ("IKC0") envía toda la información a la vez. IKC0 se degradará elegantemente a IKC, si el cliente y el servidor no coinciden.

El valor por defecto es IKC0.

connect

$poe->connect or die $poe->error;

Se conecta al kernel remoto si aún no estamos conectados. Puedes usar este método para asegurarte de que la conexión está abierta antes de intentar hacer algo.

Devuelve verdadero si la conexión fue exitosa, falso si no. Puedes verificar "error" para ver cuál fue el problema.

disconnect

Desconecta del servidor IKC remoto.

error

my $error=POE::Component::IKC::ClientLite::error();
$error=$poe->error();

Devuelve el último error. Se puede llamar como método de objeto, o como una función global.

post

$poe->post($specifier, $data);

Envía el evento especificado por $specifier al kernel remoto. $data son los parámetros que deseas enviar junto con el evento. Devolverá 1 en caso de éxito (es decir, los datos pudieron ser enviados... no que el evento fue recibido) y undef() si no pudimos conectarnos o reconectarnos al kernel remoto.

post_respond

my $ret=$poe->post_respond($specifier, $data);

Envía el evento especificado por $specifier al kernel remoto. $data son los parámetros que deseas enviar junto con el evento. Espera hasta que el kernel remoto envíe un mensaje de vuelta y devuelve su carga útil. La espera expira después del valor que le diste a POE::Component::IKC->spawn.

Los eventos en el lado lejano deben ser conscientes de post_respond. En particular, ARG0 no es $data como esperarías, sino un arrayref que contiene $data seguido de un especificador que debería usarse para enviar de vuelta.

sub my_event
{
    my($kernel, $heap, $args)=@_[KERNEL, HEAP, ARG0];
    my $p=$args->[0];
    $heap->{rsvp}=$args->[1];
    # .... haz muchas cosas aquí
}
# eventualmente, hemos terminado
sub finished
{
    my($kernel, $heap, $return)=@_[KERNEL, HEAP, ARG0];
    $kernel->post(IKC=>'post', $heap->{rsvp}, $return);
}

responded

my $ret = $poe->responded( $state );
my @ret = $poe->responded( $state );

Espera por $state del kernel remoto. $state debe ser un nombre de estado simple. Cualquier solicitud del kernel remoto para otros estados es rechazada. Un manejador remoto respondería usando el remitente proxy.

call

my $ret=$poe->call($specifier, $data);

Esta es la mala forma de obtener información de vuelta de un evento remoto. Sigue la semántica esperada del POE estándar. Funciona mejor que post_respond, sin embargo, porque no requiere que cambies tu interfaz o escribas un envoltorio.

ping

unless($poe->ping) {
    # ¡la conexión está caída! ¡la conexión está caída!
}

Descubre si todavía estamos conectados al kernel remoto. Este método NO intentará reconectarse al servidor remoto.

name

Devuelve nuestro nombre local. Esto es lo que el kernel remoto piensa que somos. No puedo decir realmente que este sea el nombre del kernel local, porque, bueno, esto no es realmente un kernel. Pero bueno.

NAME

POE::Component::IKC::ClientLite - An IKC client that does not use Perl's AUTOLOAD

SYNOPSIS

 use POE::Component::IKC::ClientLite;

 my $client = POE::Component::IKC::ClientLite->new(
  Alias => 'my_client_alias',
  -debug => 1,
 );

 $client->yield(
  'some_other_alias',
  "some message data",
 );

 $poe_kernel->run;

DESCRIPTION

POE::Component::IKC::ClientLite is a non-AUTOLOAD based IKC client component. It differs from POE::Component::IKC::Client in that it explicitly defines all of its methods rather than relying on AUTOLOAD.

IKC (Inter-Kernel Communication) is a mechanism for POE kernels to communicate with each other. This component implements a client-side interface to IKC.

METHODS

new
    my $client = POE::Component::IKC::ClientLite->new(
     Alias => 'my_client_alias',
     # Other IKC options...
     -debug => 1, # Optional: Enable debugging
    );
Creates a new IKC client. The Alias option is mandatory and specifies the alias under which this client will be known to the IKC system. Other options are passed directly to the underlying IKC implementation.
yield
    $client->yield( $destination_alias, $message_data );
Sends a message to another IKC client. $destination_alias is the alias of the target client, and $message_data is the content of the message.
shutdown
    $client->shutdown;
Shuts down the IKC client component.

FUNCTIONS

This component does not export any functions.
