NAME

MIME::Charset~[ja] - MIME charset information

SYNOPSIS

use MIME::Charset:
$charset = MIME::Charset->new("euc-jp")

Get charset information:

$benc = $charset->body_encoding; # e.g. "Q"
$cset = $charset->as_string; # e.g. "US-ASCII"
$henc = $charset->header_encoding; # e.g. "S"
$cset = $charset->output_charset; # e.g. "ISO-2022-JP"

Transform text data:

($text, $charset, $encoding) =
    $charset->header_encode(
       "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef",
       Charset => 'euc-jp');
# ... returns ("<encoded string>", "ISO-2022-JP", "B")
($text, $charset, $encoding) =
    $charset->body_encode(
        "Collectioneur path\xe9tiquement ",
        Charset => 'latin1');
# ... returns ("original string", "ISO-8859-1", "QUOTED-PRINTABLE")
$len = $charset->encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e",
    Charset => "utf-8",
    Encoding => "b");
# ... returns 28

Module constant manipulation:

MIME::Charset::alias("csEUCKR", "euc-kr");
MIME::Charset::default("iso-8859-1");
MIME::Charset::fallback("us-ascii");

Non-OO functions (deprecated soon):

use MIME::Charset qw(:info);
$benc = body_encoding("iso-8859-2"); # "Q"
$cset = canonical_charset("ANSI X3.4-1968"); # "US-ASCII"
$henc = header_encoding("utf-8"); # "S"
$cset = output_charset("shift_jis"); # "ISO-2022-JP"
use MIME::Charset qw(:trans);
($text, $charset, $encoding) =
    header_encode(
       "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef",
       "euc-jp");
# ... (returns "<encoded text>", "ISO-2022-JP", "B")
($text, $charset, $encoding) =
    body_encode(
        "Collectioneur path\xe9tiquement ".
        "\xe9clectique de d\xe9chets",
        "latin1");
# ... (returns "<original text>", "ISO-8859-1", "QUOTED-PRINTABLE")
$len = encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e", "b", "utf-8"); # 28

DESCRIPTION

MIME::Charset provides information about character sets used in MIME messages over the Internet.

Definitions

A character set is a MIME term for a method of converting a sequence of octets into a sequence of characters. This includes the concept of both a Character Composition Set (CCS) and a Character Encoding Scheme (CES) as defined by ISO/IEC.

An encoding is a MIME term for the method of representing either the message body or the message header body as a sequence of US-ASCII characters, which are printable.

Constructor

$charset = MIME::Charset->new([CHARSET [, OPTS]])
Creates a character set object.

OPTS may specify the following options. NOTE: When Unicode/multi-byte support is not enabled (see "USE_ENCODE"), the following options have no effect.

Mapping => MAPTYPE
Whether to extend the actual mapping used for the character set name. "EXTENDED" uses extended mappings. "STANDARD" uses strict, standardized mappings. The default is "EXTENDED".

Retrieving Charset Information

$charset->body_encoding
body_encoding CHARSET
Returns the recommended transport encoding for the message body of the CHARSET.

The return value is one of "B" (BASE64), "Q" (QUOTED-PRINTABLE), "S" (Subject line style, less common), or "undef" (no transport encoding needed --- 7BIT or 8BIT). This differs from the header encoding.

$charset->as_string
canonical_charset CHARSET
Returns the canonical name of the character set.
$charset->decoder
Returns an "Encode::Encoding" object used to decode the character set into Unicode. Returns undef if the character set is not specified or if it is a character set unknown to this module.
$charset->dup
Duplicates the character set object.
$charset->encode

BUGS

This module does not fully support multi-byte character sets unless the underlying Encode module is configured with multi-byte support.

This module provides character encoding conversion facilities.

The encode and decode functions convert between character encodings. The functions are designed to be used from Perl scripts for general purpose conversion.

find_encoding CHARSET

$codec->find_encoding(CHARSET)
Returns an encoding object (codec) for the given CHARSET. Returns undef if the character set is not supported.

CHARSET is used to encode and decode by MIME type. It is recommended to use an alternative character set for encoding to prevent character corruption. Returns the "Encode::Encoding" object.

If CHARSET is specified, the encoder of the $charset object (or the name of the character set to be output) is replaced by CHARSET. In other words, the $charset object becomes a converter from the original character set to the new CHARSET.

NAME

MIME::Charset - Character set handling for MIME

SYNOPSIS

  use MIME::Charset;

  my $charset = MIME::Charset->new('ISO-2022-JP');
  my $encoded_header = $charset->header_encode('Perl');
  my $encoded_body   = $charset->body_encode('Perl');

  print $charset->output_charset(), "\n";
  print $charset->header_encoding(), "\n";
  print $charset->body_encoding(), "\n";

  my $charset = MIME::Charset->new('UTF-8');
  print $charset->output_charset(), "\n";
  print $charset->header_encoding(), "\n";
  print $charset->body_encoding(), "\n";

  my $charset = MIME::Charset->new();
  print $charset->output_charset(), "\n";
  print $charset->header_encoding(), "\n";
  print $charset->body_encoding(), "\n";

DESCRIPTION

This module determines the encoding and charset for MIME.

When you create a MIME::Charset object with arguments, it determines the properties of that character set.

If no arguments are given, the properties remain unchanged.

In either case, it returns the current properties of the character set as a list of three elements (HEADERENC, BODYENC, ENCCHARSET).

HEADERENC is the recommended encoding method for the message header. You can specify "B", "Q", "S" (all shorter), or "undef" (no encoding needed).

BODYENC is the recommended transfer encoding for the message body. You can specify "B", "Q", "S" (all shorter), or "undef" (no encoding needed).

ENCCHARSET is the recommended character set name for use in MIME messages on the internet, in exchange with the specified CHARSET. If exchange is not necessary (or the current module doesn't know about suitable characters), ENCCHARSET is "undef".

NOTE: In future versions of this function, it might be necessary to add mandatory arguments (e.g., about character width, line wrapping behavior). Therefore, the return format might also change. To obtain individual properties, you should use "header_encoding", "body_encoding", and "output_charset".

CONSTANTS

USE_ENCODE
A flag for Unicode/multi-byte conversion. When the conversion to Unicode and multi-byte is effective, a non-empty string is set. Currently, this flag is empty from Perl 5.7.3 onwards, and an empty string in Perl versions prior to that.

ERROR HANDLING

For the "Replacement" option in "body_encode" and "header_encode", the following can be specified:

"DEFAULT"
Replaces invalid characters with replacement characters. For character sets based on UCM, a <subchar> is sometimes used as the symbol container.
"FALLBACK"
Uses a fallback character set to try the "DEFAULT" method (see "fallback"). If the fallback character set is undefined and a conversion error occurs, the code outputs an error message and dies. ("fallback" is described in Encode).
"CROAK"
The code outputs an error message and dies immediately. However, the fatal error can be caught by an eval{}, so it can be prevented from dying if needed. This is the same for "STRICT".
"PERLQQ"
"HTMLCREF"
"XMLCREF"
Uses the methods defined in the Encode module: "FB_PERLQQ", "FB_HTMLCREF", and "FB_XMLCREF".
A number
A numerical value can also be specified. See "Handling Malformed Data" in Encode for details.

If the error handling method is not specified, or if an error handling method other than those listed above is specified, it defaults to "DEFAULT".

CONFIGURATION FILES

The default values for the parameter settings can be changed by modifying the configuration file MIME/Charset/Defaults.pm. For details, please read MIME/Charset/Defaults.pm.sample.

DESCRIPTION

MIME::Charset es un módulo de Perl que permite la fácil identificación, validación y obtención de información sobre juegos de caracteres MIME.

Proporciona una interfaz orientada a objetos para trabajar con juegos de caracteres, permitiendo obtener sus nombres MIME oficiales, descripciones y nombres IANA.

El módulo se basa en una base de datos interna de juegos de caracteres conocidos, que se puede extender o modificar según sea necesario.

Métodos

new( $charset_name )
Crea un nuevo objeto MIME::Charset para el juego de caracteres especificado por $charset_name. El nombre puede ser el nombre MIME oficial, un nombre IANA, una descripción o un alias.
mime_name
Devuelve el nombre MIME oficial del juego de caracteres.
description
Devuelve una descripción legible por humanos del juego de caracteres.
iana_name
Devuelve el nombre IANA oficial del juego de caracteres.
list
Devuelve una lista de todos los objetos MIME::Charset conocidos.
find( $name )
Busca y devuelve un objeto MIME::Charset que coincida con el nombre dado. La búsqueda es insensible a mayúsculas y minúsculas y considera nombres MIME, nombres IANA, descripciones y alias.
UNKNOWN
Constante que representa un juego de caracteres desconocido.
is_known( $charset_name )
Devuelve verdadero si el juego de caracteres con el nombre dado es conocido por el módulo.
add( $mime_name, $description, \@aliases )
Agrega un nuevo juego de caracteres a la base de datos interna. $mime_name es el nombre MIME oficial, $description es una descripción y \@aliases es una lista de alias opcionales.
add_alias( $mime_name, $alias )
Agrega un alias para un juego de caracteres existente.
count
Devuelve el número de juegos de caracteres conocidos.
unload( $charset_name )
Descarga un juego de caracteres específico de la base de datos interna.
unload_all
Descarga todos los juegos de caracteres de la base de datos interna.
