NOMBRE

POE::Resource::Signals - gestor de señales interno para POE::Kernel

SINOPSIS

No hay API pública.

DESCRIPCIÓN

POE::Resource::Signals es una clase de mezcla para POE::Kernel. Proporciona las características necesarias para gestionar señales. Se utiliza internamente por POE::Kernel, por lo que no tiene una interfaz pública.

VER TAMBIÉN

Ver "Señales" en POE::Kernel para una discusión más profunda sobre el manejo de señales de POE.

Ver "Métodos de observador de señales" en POE::Kernel para la API pública de señales de POE.

Ver "Recursos" en POE::Kernel para información pública sobre los recursos de POE.

Ver POE::Resource para una discusión general sobre recursos y las clases que los gestionan.
