Pod::Simple::PullParser(3perl) Guía del programador de Perl Pod::Simple::PullParser(3perl)

NOMBRE

Pod::Simple::PullParser -- una interfaz de análisis por extracción para analizar Pod

SINOPSIS

my $parser = SomePodProcessor->new;
$parser->set_source( "whatever.pod" );
$parser->run;

O:

my $parser = SomePodProcessor->new;
$parser->set_source( $some_filehandle_object );
$parser->run;

O:

my $parser = SomePodProcessor->new;
$parser->set_source( \$document_source );
$parser->run;

O:

my $parser = SomePodProcessor->new;
$parser->set_source( \@document_lines );
$parser->run;

Y en otro lugar:

require 5;
package SomePodProcessor;
use strict;
use base qw(Pod::Simple::PullParser);
sub run {
  my $self = shift;
 Token:
  while(my $token = $self->get_token) {
    ...procesar cada token...
  }
}

DESCRIPCIÓN

Esta clase es para usar Pod::Simple para construir un procesador de Pod, pero uno que utiliza una interfaz basada en un flujo de objetos de token, en lugar de basarse en eventos.

Esta es una subclase de Pod::Simple y hereda todos sus métodos.

Una subclase de Pod::Simple::PullParser debería definir un método "run" que llama a "$token = $parser->get_token" para extraer tokens.

Consulta el código fuente de Pod::Simple::RTF para ver un ejemplo de un formateador que utiliza Pod::Simple::PullParser.

MÉTODOS

my $token = $parser->get_token
Esto devuelve el siguiente objeto token (que será de una subclase de Pod::Simple::PullParserToken), o undef si el flujo del analizador ha llegado al final del documento.
$parser->unget_token( $token )
$parser->unget_token( $token1, $token2, ... )
Esto restaura el(los) objeto(s) token al principio del flujo del analizador.

La fuente tiene que ser establecida antes de poder analizar nada. La forma de nivel más bajo es llamar a "set_source":

$parser->set_source( $filename )
$parser->set_source( $filehandle_object )
$parser->set_source( \$document_source )
$parser->set_source( \@document_lines )

O puedes llamar a estos métodos, que Pod::Simple::PullParser ha definido para que funcionen igual que los métodos del mismo nombre de Pod::Simple:

$parser->parse_file(...)
$parser->parse_string_document(...)
$parser->filter(...)
$parser->parse_from_file(...)

Para que funcionen, la subclase de formateo de Pod de Pod::Simple::PullParser tiene que haber definido un método $parser->run; por lo tanto, se aconseja que todas las subclases de Pod::Simple::PullParser lo hagan. Ver la Sinopsis arriba, o el código fuente de Pod::Simple::RTF.

Los autores de subclases de formateadores pueden encontrar útiles estos métodos para llamar en un objeto analizador del que aún no has empezado a extraer tokens:

my $title_string = $parser->get_title
Esto intenta obtener la cadena del título de $parser, obteniendo algunos tokens, escaneándolos en busca del título y luego devolviéndolos para que puedas procesar el flujo de tokens desde el principio.

Por ejemplo, supongamos que tienes un documento que empieza:

=head1 NAME
Hoo::Boy::Wowza -- Stuff B<wow> yeah!

$parser->get_title en ese documento devolverá "Hoo::Boy::Wowza -- Stuff wow yeah!". Si el documento empieza con:

=head1 Name
Hoo::Boy::W00t -- Stuff B<w00t> yeah!

Entonces necesitarás pasar la opción "nocase" para reconocer "Name":

$parser->get_title(nocase => 1);

En casos donde get_title no puede encontrar el título, devolverá una cadena vacía ("").

my $title_string = $parser->get_short_title
Esto es igual que get_title, excepto que devuelve solo el nombre del módulo, si el título parece ser del formato "SomeModuleName -- description".

Por ejemplo, supongamos que tienes un documento que empieza:

=head1 NAME
Hoo::Boy::Wowza -- Stuff B<wow> yeah!

entonces $parser->get_short_title en ese documento devolverá "Hoo::Boy::Wowza".

Pero si el documento empieza:

=head1 NAME
Hooboy, stuff B<wow> yeah!

entonces $parser->get_short_title en ese documento devolverá "Hooboy, stuff wow yeah!". Si el documento empieza con:

=head1 Name
Hoo::Boy::W00t -- Stuff B<w00t> yeah!

Entonces necesitarás pasar la opción "nocase" para reconocer "Name":

$parser->get_short_title(nocase => 1);

Si el título no se puede encontrar, entonces get_short_title devuelve una cadena vacía ("").

$author_name = $parser->get_author
Esto funciona como get_title excepto que devuelve el contenido de la sección "=head1 AUTHOR\n\nParagraph...\n", asumiendo que esa sección no es terriblemente larga. Para reconocer una sección "=head1 Author\n\nParagraph\n", pasa la opción "nocase": 
$parser->get_author(nocase => 1);

(Este método también tolera "AUTHORS" en lugar de "AUTHOR".)

$description_name = $parser->get_description
Esto funciona como get_title excepto que devuelve el contenido de la sección "=head1 DESCRIPTION\n\nParagraph...\n", asumiendo que esa sección no es terriblemente larga. Para reconocer una sección "=head1 Description\n\nParagraph\n", pasa la opción "nocase": 
$parser->get_description(nocase => 1);
$version_block = $parser->get_version
Esto funciona como get_title excepto que devuelve el contenido del bloque "=head1 VERSION\n\n[BIG BLOCK]\n". ¡Nota que esto NO devuelve el $VERSION del módulo! Para reconocer una sección "=head1 Version\n\n[BIG BLOCK]\n", pasa la opción "nocase": 
$parser->get_version(nocase => 1);

NOTA

En realidad no tienes que definir un método "run". Si estás escribiendo una clase formateadora de Pod, deberías definir un "run" solo para que los usuarios puedan llamar a "parse_file", etc., pero no tienes que hacerlo.

Y si no estás escribiendo una clase formateadora, sino que solo estás escribiendo un programa que hace algo simple con un objeto Pod::PullParser (y no un objeto de una subclase), entonces no hay razón para molestarse en crear una subclase para añadir un método "run".
