NOMBRE

Pod::Simple::PullParserTextToken -- tokens de texto de Pod::Simple::PullParser

SINOPSIS

(Ver Pod::Simple::PullParser)

DESCRIPCIÓN

Cuando haces $parser->get_token en un Pod::Simple::PullParser, podrías obtener un objeto de esta clase.

Esta es una subclase de Pod::Simple::PullParserToken y hereda todos sus métodos, y añade estos métodos:

$token->text
Esto devuelve el texto que contiene este token. Por ejemplo, analizar C<foo> devolverá un token de inicio de C, un token de texto y un token de fin de C. Y si quieres obtener el "foo" del token de texto, llama a "$token->text"
$token->text(algumacadenadetexto)
Esto cambia la cadena que contiene este token. Probablemente no necesitarás hacer esto.
$token->text_r()
Esto devuelve una referencia escalar a la cadena que contiene este token. Esto puede ser útil si no quieres copiar en memoria el valor de texto potencialmente grande (bueno, tan grande como un párrafo o un bloque verbatim) como lo haría llamar a $token->text.

O, si quieres alterar el valor, incluso puedes hacer cosas como estas:

for ( ${  $token->text_r  } ) {  # Lo alias con $_ !!
  s/ The / the /g; # solo como ejemplo
  if( 'A' eq chr(65) ) {  # (si en un mundo ASCII)
    tr/\xA0/ /;
    tr/\xAD//d;
  }
  ...o como quieras alterar el valor...
  (Ten en cuenta que a partir de Perl v5.8, puedes usar, por ejemplo,
      my $nbsp = chr utf8::unicode_to_native(0xA0);
      s/$nbsp/ /g;
  para manejar lo anterior independientemente de si es un mundo ASCII o no)
}

Es poco probable que necesites construir un objeto de esta clase por ti mismo, pero si quieres hacerlo, llama a "Pod::Simple::PullParserTextToken->new( texto )"
