NOMBRE

POE::Component::IKC::Specifier - Especificador de eventos IKC

SINOPSIS

use POE;
use POE::Component::IKC::Specifier;
$state=specifier_parse('poe://*/timeserver/connect');
print 'El estado extranjero es '.specifier_name($state);

DESCRIPCIÓN

Este es un módulo auxiliar que encapsula los especificadores IKC de POE. Un especificador IKC es una forma de designar un kernel, una sesión o un estado dentro de un clúster IKC.

Los especificadores IKC tienen el siguiente formato:

poe:://kernel/sesion/estado

kernel puede ser un nombre de kernel, un ID de kernel, en blanco (para el kernel local), un '*' (todos los kernels extranjeros conocidos) o host:puerto (no soportado actualmente).

sesión puede ser cualquier alias de sesión que haya sido publicado por el kernel extranjero.

estado es un estado que ha sido publicado por una sesión extranjera.

Ejemplos:

"poe://Pulse/timeserver/connect"
Estado 'connect' en la sesión 'timeserver' en el kernel 'Pulse'.
"poe:/timeserver/connect"
Estado 'connect' en la sesión 'timeserver' en el kernel local.
"poe://*/timeserver/connect"
Estado 'connect' en la sesión 'timeserver' en cualquier kernel extranjero conocido.
"poe://Billy/bob/"
Sesión 'bob' en el kernel extranjero 'Billy'.

FUNCIONES EXPORTADAS

specifier_parse($spec)

Convierte un especificador en la representación interna (referencia a hash). Devuelve undef() si el especificador no era válido.

print Dumper specifer_parse('poe://Pulse/timeserver/time');

imprimiría

$VAR1 = {
    kernel => 'Pulse',
    session => 'timeserver',
    state => 'time',
};

Nota: la representación interna podría cambiar algún día.

specifier_name($spec)

Convierte un especificador en una cadena.
