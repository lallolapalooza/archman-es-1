Pod::Wordlist(3) Documentación de Perl contribuida por el usuario Pod::Wordlist(3)

NOMBRE

Pod::Wordlist - Palabras en inglés que aparecen en la documentación de Perl

VERSIÓN

versión 1.26

DESCRIPCIÓN

Pod::Wordlist es utilizado por Pod::Spell, proporcionando un conjunto de palabras que son jerga inglesa que aparece en la documentación de Perl, pero que no se encuentran en léxicos generales de inglés. (Por ejemplo: autovivify, backreference, chroot, stringify, wantarray).

También puedes usar esta lista de palabras con tu procesador de textos simplemente pegando el contenido de "share/wordlist" en tu procesador de textos, eliminando el código Perl inicial para que solo quede la lista de palabras, y luego revisando la ortografía de esta lista resultante y añadiendo cada palabra en ella a tu léxico privado.

MÉTODOS

learn_stopwords

$wordlist->learn_stopwords( $text );

Modifica la lista de stopwords basándose en un bloque de texto. Consulta las reglas para <añadir stopwords|Pod::Spell/ADDING STOPWORDS> para más detalles.

is_stopword

if ( $wordlist->is_stopword( $word ) ) { ... }

Devuelve verdadero si la palabra se encuentra en la lista de stopwords.

strip_stopwords

my $out = $wordlist->strip_stopwords( $text );

Devuelve una cadena con palabras separadas por espacios del texto original con las stopwords eliminadas.

ATRIBUTOS

wordlist

ref $self->wordlist eq 'HASH'; # verdadero

Esta es la instancia de la lista de palabras.

no_wide_chars

Si es verdadero, las palabras con caracteres fuera del rango Latin-1 0x00 a 0xFF se eliminarán como stopwords.

LISTA DE PALABRAS

Tenga en cuenta que el alcance de este archivo es solo en inglés, específicamente en inglés americano. (Pero puede encontrarlo útil para incorporarlo en sus propios léxicos, incluso si son para otros dialectos/idiomas).

eliminar cualquier q{'s} antes de añadir a la lista.

La lista debe estar ordenada y ser única. Lo siguiente funcionará (con GNU Coreutils).

sort share/wordlist -u > /tmp/sorted && mv /tmp/sorted share/wordlist
