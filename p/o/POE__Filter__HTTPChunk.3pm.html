NOMBRE

POE::Filter::HTTPChunk - Analizador no bloqueante de fragmentos HTTP incrementales.

VERSIÓN

versión 0.949

SINOPSIS

# No es un programa completo.
use POE::Filter::HTTPChunk;
use POE::Wheel::ReadWrite;
sub setup_io {
  $_[HEAP]->{io_wheel} = POE::Wheel::ReadWrite->new(
    Filter => POE::Filter::HTTPChunk->new(),
    # Ver POE::Wheel::ReadWrite para otros parámetros requeridos.
  );
}

DESCRIPCIÓN

Este filtro analiza fragmentos HTTP de un flujo de datos. Es utilizado por POE::Component::Client::HTTP para realizar la mayor parte del análisis de bajo nivel de HTTP.

CONSTRUCTOR

new

"new" no toma parámetros y devuelve un objeto POE::Filter::HTTPChunk nuevo y reluciente, listo para usar.

MÉTODOS

POE::Filter::HTTPChunk soporta los siguientes métodos. La mayoría de ellos se adhieren a la API estándar de POE::Filter. La documentación de POE::Filter explica la API con más detalle.

get_one_start ARRAYREF

Acepta una referencia a un array que contiene cero o más fragmentos de datos crudos. Estos se añaden al buffer de entrada del filtro. El filtro intentará analizar esos datos cuando se llame a get_one().

$filter_httpchunk->get_one_start(\@stream_data);

get_one

Analiza un único fragmento HTTP del buffer de entrada del filtro. Los datos se introducen en el buffer mediante el método get_one_start(). Devuelve una referencia a un array que contiene cero o un fragmento HTTP analizado.

$ret_arrayref = $filter_httpchunk->get_one();

get_pending

Devuelve una referencia a un array de datos de flujo actualmente en espera de ser analizados. Se utiliza para transferir sin problemas datos no analizados entre un filtro antiguo y uno nuevo cuando se cambia el filtro de una rueda.

$pending_arrayref = $filter_httpchunk->get_pending();
