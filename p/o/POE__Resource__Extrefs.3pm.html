NOMBRE

POE::Resource::Extrefs - gestor interno de recuentos de referencias para POE::Kernel

SINOPSIS

No hay API pública.

DESCRIPCIÓN

POE::Resource::Extrefs es una clase mix-in para POE::Kernel. Proporciona las funciones para gestionar los recuentos de referencias de sesiones, específicamente las que las aplicaciones pueden utilizar. POE::Resource::Extrefs es utilizado internamente por POE::Kernel, por lo que no tiene una interfaz pública.

VER TAMBIÉN

Ver "Contadores de referencias públicos" en POE::Kernel para la API pública de extref.

Ver "Recursos" en POE::Kernel para obtener información pública sobre los recursos de POE.

Ver POE::Resource para una discusión general sobre los recursos y las clases que los gestionan.

ERRORES

Los contadores de referencias no tienen información de propiedad, por lo que los recuentos de referencias de una entidad pueden entrar en conflicto con los de otra. Esto normalmente no es un problema si todas las entidades se comportan correctamente.
