NOMBRE

Pod::Simple::Checker -- comprueba la sintaxis Pod de un documento

SINOPSIS

perl -MPod::Simple::Checker -e \
 "exit Pod::Simple::Checker->filter(shift)->any_errata_seen" \
 thingy.pod

DESCRIPCIÓN

Esta clase sirve para comprobar la validez sintáctica de Pod. Funciona básicamente actuando como una versión simplona de Pod::Simple::Text que formatea solo la sección "Errores de Pod" (si Pod::Simple genera alguna para el documento dado).

Esta es una subclase de Pod::Simple y hereda todos sus métodos.

VER TAMBIÉN

Pod::Simple, Pod::Simple::Text, Pod::Checker
