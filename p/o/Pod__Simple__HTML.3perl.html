NOMBRE

Pod::Simple::HTML - convertir Pod a HTML

SINOPSIS

perl -MPod::Simple::HTML -e Pod::Simple::HTML::go thingy.pod

DESCRIPCIÓN

Esta clase se utiliza para hacer una representación HTML de un documento Pod.

Esta es una subclase de Pod::Simple::PullParser y hereda todos sus métodos (y opciones).

Tenga en cuenta que si desea realizar una conversión por lotes de muchos documentos Pod a HTML, debería consultar el módulo Pod::Simple::HTMLBatch.

LLAMADA DESDE PERL

Código mínimo

use Pod::Simple::HTML;
my $p = Pod::Simple::HTML->new;
$p->output_string(\my $html);
$p->parse_file('path/to/Module/Name.pm');
open my $out, '>', 'out.html' or die "Cannot open 'out.html': $!\n";
print $out $html;

Ejemplo más detallado

use Pod::Simple::HTML;

Establecer el tipo de contenido:

$Pod::Simple::HTML::Content_decl =  q{<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" >};
my $p = Pod::Simple::HTML->new;

Incluir una única fuente de javascript:

$p->html_javascript('http://abc.com/a.js');

O insertar múltiples fuentes de javascript en la cabecera (o, dado el caso, incluir cualquier cosa, aunque no se recomienda)

$p->html_javascript('
    <script type="text/javascript" src="http://abc.com/b.js"></script>
    <script type="text/javascript" src="http://abc.com/c.js"></script>');

Incluir una única fuente CSS en la cabecera:

$p->html_css('/style.css');

o insertar múltiples fuentes CSS:

$p->html_css('
    <link rel="stylesheet" type="text/css" title="pod_stylesheet" href="http://remote.server.com/jquery.css">
    <link rel="stylesheet" type="text/css" title="pod_stylesheet" href="/style.css">');

Indicar al analizador dónde debe ir la salida. En este caso, se colocará en la variable $html:

my $html;
$p->output_string(\$html);

Analizar y procesar un archivo con Pod:

$p->parse_file('path/to/Module/Name.pm');

TODO todos (la mayoría?) métodos con acceso a atributos

Las siguientes variables deben establecerse **antes** de la llamada al constructor ->new.

Establecer la cadena que se incluye antes de la etiqueta de apertura <html>:

$Pod::Simple::HTML::Doctype_decl = qq{<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN"
  "http://www.w3.org/TR/html4/loose.dtd">\n};

Establecer el tipo de contenido en la cabecera HTML: (por defecto ISO-8859-1)

$Pod::Simple::HTML::Content_decl =  q{<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" >};

Establecer el valor que se incrustará en las etiquetas de apertura de las etiquetas F, C y el texto literal. F se mapea a <em>, C se mapea a <code>, el texto literal se mapea a <pre> (Computerese por defecto es "")

$Pod::Simple::HTML::Computerese =  ' class="some_class_name';

html_css

html_javascript

title_prefix

title_postfix

html_header_before_title

Esto incluye todo antes de la etiqueta de apertura <title>, incluyendo el tipo de documento y la etiqueta de apertura <title>. La siguiente llamada la establecerá como un archivo HTML simple:

$p->html_header_before_title('<html><head><title>');

top_anchor

Por defecto, Pod::Simple::HTML añade una ancla ficticia en la parte superior del HTML. Puedes cambiarla llamando

$p->top_anchor('<a name="zz" >');

html_h_level

Normalmente, =head1 se convertirá en <h1>, =head2 se convertirá en <h2>, etc. Usar el método html_h_level cambiará estos niveles, estableciendo el nivel h de las etiquetas =head1:

$p->html_h_level(3);

Asegurará que =head1 se convierta en <h3> y =head2 se convertirá en <h4>, etc...

index

Establécelo a algún valor verdadero si quieres que se añada un índice (en realidad, una tabla de contenidos) al principio del HTML generado.

$p->index(1);

html_header_after_title

Incluye la etiqueta de cierre de </title> y el resto de la cabecera hasta la apertura del body

$p->html_header_after_title('</title>...</head><body id="my_id">');

html_footer

El final del documento:

$p->html_footer( qq[\n<!-- end doc -->\n\n</body></html>\n] );

SUBCLASES

Se pueden usar cualquiera de los métodos descritos anteriormente, pero para una mayor personalización es necesario sobrescribir algunos de los métodos:

package My::Pod;
use strict;
use warnings;
use base 'Pod::Simple::HTML';
# debe devolver una cadena URL como
# http://some.other.com/page.html
# #anchor_in_the_same_file
# /internal/ref.html
sub do_pod_link {
  # Objeto My::Pod y objeto Pod::Simple::PullParserStartToken
  my ($self, $link) = @_;
  say $link->tagname;          # será L para los enlaces
  say $link->attr('to');       #
  say $link->attr('type');     # siempre será 'pod'
  say $link->attr('section');
  # Enlaces locales a nuestro sitio web
  if ($link->tagname eq 'L' and $link->attr('type') eq 'pod') {
    my $to = $link->attr('to');
    if ($to =~ /^Padre::/) {
        $to =~ s{::}{/}g;
        return "/docs/Padre/$to.html";
    }
  }
  # todos los demás enlaces son generados por la clase padre
  my $ret = $self->SUPER::do_pod_link($link);
  return $ret;
}
1;

Mientras tanto, en script.pl:

use My::Pod;
my $p = My::Pod->new;
my $html;
$p->output_string(\$html);
$p->parse_file('path/to/Module/Name.pm');
open my $out, '>', 'out.html' or die;
print $out $html;
