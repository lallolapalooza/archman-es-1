NOMBRE

POE::Wheel::Curses - entrada no bloqueante para Curses

SINOPSIS

use Curses;
use POE qw(Wheel::Curses);
POE::Session->create(
  inline_states => {
    _start => sub {
      $_[HEAP]{console} = POE::Wheel::Curses->new(
        InputEvent => 'got_keystroke',
      );
    },
    got_keystroke => sub {
      my $keystroke = $_[ARG0];
      # Hacer que las pulsaciones de teclas de control y extendidas sean imprimibles.
      if ($keystroke lt ' ') {
        $keystroke = '<' . uc(unctrl($keystroke)) . '>';
      }
      elsif ($keystroke =~ /^\d{2,}$/) {
        $keystroke = '<' . uc(keyname($keystroke)) . '>';
      }
      # Simplemente mostrarlo.
      addstr($keystroke);
      noutrefresh();
      doupdate;
      # Hay que salir de alguna manera.
      delete $_[HEAP]{console} if $keystroke eq "<^C>";
    },
  }
);
POE::Kernel->run();
exit;

DESCRIPCIÓN

POE::Wheel::Curses implementa entrada no bloqueante para programas Curses.

POE::Wheel::Curses emitirá un "InputEvent" de su elección cada vez que se registre un evento de entrada en un dispositivo de entrada reconocido (teclado y a veces ratón, dependiendo de la biblioteca curses). Mientras tanto, las aplicaciones pueden estar haciendo otras cosas como monitorizar conexiones de red o procesos hijos, o gestionar temporizadores y cosas así.

MÉTODOS PÚBLICOS

POE::Wheel::Curses es bastante simple.

new

new() crea un nuevo objeto POE::Wheel::Curses. Durante la construcción, la rueda registra un observador de entrada para STDIN (a través de select_read()) y registra un manejador interno para preprocesar las pulsaciones de teclas.

new() acepta un solo parámetro "InputEvent". "InputEvent" contiene el nombre del evento que la rueda emitirá siempre que haya entrada en la consola o terminal. Como con todas las ruedas, el evento se enviará a la sesión que estaba activa cuando se construyó la rueda.

Cabe señalar que una aplicación solo puede tener un objeto POE::Wheel::Curses activo.

EVENTOS Y PARÁMETROS

Estos son los eventos enviados por POE::Wheel::Curses.

InputEvent

"InputEvent" define el evento que se emitirá cuando POE::Wheel::Curses detecte y lea la entrada de la consola. Este evento incluye dos parámetros:

$_[ARG0] contiene la pulsación de tecla cruda tal como la recibió Curses::getch(). Una aplicación puede procesar la pulsación de tecla usando Curses::unctrl() y Curses::keyname() en la pulsación de tecla.

$_[ARG1] contiene el ID del objeto POE::Wheel::Curses.

Los eventos del ratón no son portátiles. A partir de octubre de 2009, depende de la aplicación decidir si llama a mousemask().
