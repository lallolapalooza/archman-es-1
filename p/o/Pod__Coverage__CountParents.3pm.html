Pod::Coverage::CountParents(3) Documentación de Perl contribuida por el usuario Pod::Coverage::CountParents(3)

NOMBRE

Pod::Coverage::CountParents - subclase de Pod::Coverage que examina el árbol de herencia

SINOPSIS

# todo en una invocación
use Pod::Coverage::CountParents package => 'Fishy';
# OO directo
use Pod::Coverage::CountParents;
my $pc = new Pod::Coverage::CountParents package => 'Pod::Coverage';
print "¡Somos geniales!" if $pc->coverage == 1;

DESCRIPCIÓN

Este módulo extiende Pod::Coverage para incluir la documentación de las clases padre al identificar la cobertura del código.

Si deseas documentación completa, te sugerimos consultar la documentación de Pod::Coverage.

VER TAMBIÉN
