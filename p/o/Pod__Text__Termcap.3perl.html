Pod::Text::Termcap(3perl) Guía del programador de Perl Pod::Text::Termcap(3perl)

NOMBRE

Pod::Text::Termcap - Convierte datos POD a texto ASCII con escapes de formato

SINOPSIS

use Pod::Text::Termcap;
my $parser = Pod::Text::Termcap->new (sentence => 0, width => 78);
# Lee POD de STDIN y escribe a STDOUT.
$parser->parse_from_filehandle;
# Lee archivo.pod y escribe a archivo.txt.
$parser->parse_from_file ('archivo.pod', 'archivo.txt');

DESCRIPCIÓN

Pod::Text::Termcap es una subclase simple de Pod::Text que resalta el texto de salida utilizando las secuencias de escape de termcap correctas para la terminal actual. Aparte de los códigos de formato, funciona en todos los sentidos como Pod::Text. Vea Pod::Text para detalles y opciones disponibles.

Este módulo utiliza Term::Cap para encontrar la configuración de la terminal correcta. Consulte la documentación de ese módulo para saber cómo encuentra la información de la base de datos de terminales y cómo anular ese comportamiento si es necesario. Si no puede encontrar cadenas de control para el formato en negrita y subrayado, ese formato se omite, lo que resulta en la misma salida que Pod::Text.

COMPATIBILIDAD

Pod::Text::Termcap 0.04 (basado en Pod::Parser) fue la primera versión de este módulo incluida con Perl, en Perl 5.6.0.

La API actual basada en Pod::Simple se añadió en Pod::Text::Termcap 2.00. Pod::Text::Termcap 2.01 se incluyó en Perl 5.9.3, la primera versión de Perl en incorporar esos cambios.

Pod::Text::Termcap 4.13 dejó de establecer la variable de entorno TERMPATH durante la carga del módulo. También dejó de recurrir a las secuencias de escape VT100 si Term::Cap no podía encontrar secuencias de escape utilizables, produciendo en su lugar una salida sin formato para mejores resultados en terminales tontas. La siguiente versión en incorporarse a Perl, 4.14, se incluyó en Perl 5.31.8.

Varios problemas con el ajuste y la longitud de línea se corrigieron tan recientemente como Pod::Text::Termcap 6.0.0.

Este módulo hereda su API y la mayor parte de su comportamiento de Pod::Text, por lo que los detalles en "COMPATIBILIDAD" en Pod::Text también se aplican. Pod::Text y Pod::Text::Termcap han tenido la misma versión de módulo desde 4.00, incluida en Perl 5.23.7. (Lamentablemente, divergen en formas confusas antes de eso).

ADVERTENCIAS

El ajuste de línea solo se realiza en espacios y tabulaciones ASCII, en lugar de utilizar un algoritmo de ajuste de línea correcto y consciente de Unicode.
