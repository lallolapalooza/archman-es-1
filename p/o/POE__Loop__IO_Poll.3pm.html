sub skip_tests {
return "IO::Poll no es 100% compatible con $^O" if (
$^O eq "MSWin32" and not $ENV{POE_DANTIC}
);
return "Las pruebas de IO::Poll requieren el módulo IO::Poll" if (
do { eval "use IO::Poll"; $@ }
); }

NOMBRE

POE::Loop::IO_Poll - un puente que permite que POE sea impulsado por IO::Poll

SINOPSIS

Ver POE::Loop.

DESCRIPCIÓN

POE::Loop::IO_Poll implementa la interfaz documentada en POE::Loop. Por lo tanto, no tiene documentación propia. Por favor, consulte POE::Loop para más detalles.

VER TAMBIÉN

POE, POE::Loop, IO::Poll, POE::Loop::PerlSignals
