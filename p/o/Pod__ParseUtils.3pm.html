Pod::ParseUtils(3) User Contributed Perl Documentation Pod::ParseUtils(3)

NOMBRE

Pod::ParseUtils - utilidades para el análisis y conversión de POD

SINOPSIS

use Pod::ParseUtils;
my $list = new Pod::List;
my $link = Pod::Hyperlink->new('Pod::Parser');

DESCRIPCIÓN

NOTA: Este módulo se considera obsoleto; las versiones modernas de Perl (5.31.1 y superiores) eliminarán Pod-Parser del núcleo y usarán Pod::Simple para todo lo relacionado con POD.

Pod::ParseUtils contiene algunos paquetes auxiliares orientados a objetos para el análisis y procesamiento de POD (es decir, en formateadores y traductores de POD).

Pod::List

Pod::List se puede usar para mantener información sobre listas POD (escritas como =over ... =item ... =back) para su posterior procesamiento. Los siguientes métodos están disponibles:

Pod::List->new()
Crea un nuevo objeto de lista. Las propiedades se pueden especificar a través de una referencia a hash de la siguiente manera: 
my $list = Pod::List->new({ -start => $., -indent => 4 });

Consulte los métodos/propiedades individuales para obtener detalles.

$list->file()
Sin argumento, recupera el nombre del archivo en el que se encuentra la lista. Esto debe haberse establecido previamente especificando -file en el método new() o llamando al método file() con un argumento escalar.
$list->start()
Sin argumento, recupera el número de línea donde comenzó la lista. Esto debe haberse establecido previamente especificando -start en el método new() o llamando al método start() con un argumento escalar.
$list->indent()
Sin argumento, recupera el nivel de indentación de la lista especificado en "=over n". Esto debe haberse establecido previamente especificando -indent en el método new() o llamando al método indent() con un argumento escalar.
$list->type()
Sin argumento, recupera el tipo de lista, que puede ser un valor arbitrario, por ejemplo "OL", "UL", ... si se piensa en el formato HTML. Esto debe haberse establecido previamente especificando -type en el método new() o llamando al método type() con un argumento escalar.
$list->rx()
Sin argumento, recupera una expresión regular para simplificar las cadenas de elementos individuales una vez que se ha determinado el tipo de lista. Uso: Por ejemplo, al convertir a HTML, se podría eliminar el número inicial en una lista ordenada ya que "<OL>" ya imprime números. Esto debe haberse establecido previamente especificando -rx en el método new() o llamando al método rx() con un argumento escalar.
$list->item()
Sin argumento, recupera la matriz de los elementos de esta lista. Los elementos pueden ser representados por cualquier escalar. Si se ha proporcionado un argumento, se añade a la lista de elementos.
$list->parent()
Sin argumento, recupera información sobre el contenedor padre de esta lista, que se representa como un escalar arbitrario. Esto debe haberse establecido previamente especificando -parent en el método new() o llamando al método parent() con un argumento escalar.
$list->tag()
Sin argumento, recupera información sobre la etiqueta de la lista, que puede ser cualquier escalar. Esto debe haberse establecido previamente especificando -tag en el método new() o llamando al método tag() con un argumento escalar.

Pod::Hyperlink

Pod::Hyperlink es una clase para la manipulación de hipervínculos POD. Uso:

my $link = Pod::Hyperlink->new('texto alternativo|página/"sección en página"');

La clase Pod::Hyperlink está diseñada principalmente para analizar el contenido de la secuencia "L<...>", proporcionando una interfaz simple para acceder a las diferentes partes de un hipervínculo POD para su posterior procesamiento. También se puede usar para construir hipervínculos.

Pod::Hyperlink->new()
El método new() puede recibir un conjunto de pares clave/valor o un solo valor escalar, a saber, el contenido de una secuencia "L<...>". Se devuelve un objeto de la clase "Pod::Hyperlink". El valor "undef" indica un fallo, el mensaje de error se almacena en $@.
$link->parse($string)
Este método se puede usar para analizar (o volver a analizar) un (nuevo) hipervínculo, es decir, el contenido de una secuencia "L<...>". El resultado se almacena en el objeto actual. Las advertencias se almacenan en la propiedad warnings. Por ejemplo, secciones como "L<open(2)>" están obsoletas, ya que no apuntan a documentos Perl. "L<DBI::foo(3p)>" también es incorrecto, la sección del manual se puede omitir simplemente.
$link->markup($string)
Establece/recupera el valor textual del enlace. Esta cadena contiene marcadores especiales "P<>" y "Q<>" que deben ser expandidos por el motor de expansión de secuencias internas del traductor al código específico del formateador para resaltar/activar el hipervínculo. Los detalles deben implementarse en el traductor.
$link->text()
Este método devuelve la representación textual del hipervínculo como se indicó anteriormente, pero sin marcadores (solo lectura). Dependiendo del tipo de enlace, estas son una de las siguientes alternativas (los + y * denotan las partes del texto que están marcadas): 
+perl+                    L<perl>
*$|* en +perlvar+         L<perlvar/$|>
*OPTIONS* en +perldoc+    L<perldoc/"OPTIONS">
*DESCRIPTION*             L<"DESCRIPTION">
$link->warning()
Después del análisis, este método devuelve cualquier advertencia encontrada durante el proceso de análisis.
$link->file()
$link->line()
Simples ranuras para almacenar información sobre la línea y el archivo en los que se encontró el enlace. Deben completarse manualmente.
$link->page()
Este método establece o devuelve la página POD a la que apunta este enlace.
$link->node()
Como arriba, pero el texto del nodo de destino del enlace.
$link->alttext()
Establece o devuelve un texto alternativo especificado en el enlace.
$link->type()
El tipo de nodo, ya sea "section" o "item". Como tipo no oficial, también existe "hyperlink", derivado de, por ejemplo, "Lhttp://perl.com"
$link->link()
Devuelve el enlace como el contenido de "L<>". Recíproco a parse().

Pod::Cache

Pod::Cache mantiene información sobre un conjunto de documentos POD, especialmente los nodos para hipervínculos. Los siguientes métodos están disponibles:

Pod::Cache->new()
Crea un nuevo objeto de caché. Este objeto puede contener un número arbitrario de documentos POD de la clase Pod::Cache::Item.
$cache->item()
Añade un nuevo elemento a la caché. Sin argumentos, este método devuelve una lista de todos los elementos de la caché.
$cache->find_page($name)
Busca un documento POD llamado $name en la caché. Devuelve una referencia al objeto Pod::Cache::Item correspondiente o undef si no se encuentra.

Pod::Cache::Item

Pod::Cache::Item mantiene información sobre documentos POD individuales, que se pueden agrupar en un objeto Pod::Cache. Está destinado a mantener información sobre los nodos de hipervínculos de los documentos POD. Los siguientes métodos están disponibles:

Pod::Cache::Item->new()
Crea un nuevo objeto.
$cacheitem->page()
Establece/recupera el nombre del documento POD (por ejemplo, "Pod::Parser").
$cacheitem->description()
Establece/recupera la descripción corta del POD que se encuentra en la sección "=head1 NAME&q

Pod::ParseUtils(3pm) - Arch Linux Man Pages

NAME

Pod::ParseUtils - Utilities for parsing POD documentation.

SYNOPSIS

 use Pod::Parser;

 sub parse_pod {
     my ($parser, $text, $file) = @_;
     my $page = new Pod::Parser;
     $page->parse_file($file);
     # ... do something with $page ...
 }

DESCRIPTION

This module provides a set of utilities for parsing POD documentation and creating an internal representation of the POD document that can be easily manipulated. It is a base class for POD parsers and provides methods for accessing and manipulating the parsed POD data.

The Pod::ParseUtils class provides a convenient way to create a POD document object. The methods below allow you to set and retrieve various properties of the POD document.

$cacheitem->new()
Creates a new Pod::ParseUtils object.
$cacheitem->title($title)
Set/retrieve the POD document title.
$cacheitem->section($section)
Set/retrieve the POD document section.
$cacheitem->path($path)
Set/retrieve the storage path for the POD file.
$cacheitem->file($file)
Set/retrieve the name of the POD file.
$cacheitem->nodes(@nodes)
Add a node (or a list of nodes) to the document's node list. The order is preserved, meaning nodes are added from first to last. If no argument is given, the current list of nodes is returned in the order they were added. A node can be any scalar, but typically is a pair consisting of a node string and a unique ID, which is necessary for the find_node method to function correctly.
$cacheitem->find_node($name)
Searches for a node or index entry with the name $name within the object. Returns the unique ID of the node (i.e., the second element of the array stored in the node array) or undef if the node is not found.
$cacheitem->idx(@indices)
Add an index entry (or a list of them) to the document's index list. The order is preserved, meaning entries are added from first to last. If no argument is given, the current list of index entries is returned in the order they were added. An index entry can be any scalar, but typically is a pair consisting of a string and a unique ID.
