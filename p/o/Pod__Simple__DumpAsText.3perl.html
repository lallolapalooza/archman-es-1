NOMBRE

Pod::Simple::DumpAsText -- volcar eventos de análisis de Pod como texto

SINOPSIS

perl -MPod::Simple::DumpAsText -e \
 "exit Pod::Simple::DumpAsText->filter(shift)->any_errata_seen" \
 thingy.pod

DESCRIPCIÓN

Esta clase es para volcar, como texto, los eventos obtenidos del análisis de un documento Pod. Esta clase es de interés para quienes escriben formateadores de Pod basados en Pod::Simple. Es útil para ver exactamente qué eventos se obtienen de un Pod que se introduce.

Esta es una subclase de Pod::Simple y hereda todos sus métodos.
