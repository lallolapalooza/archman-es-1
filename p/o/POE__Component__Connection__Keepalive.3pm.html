POE::Component::Connection::Keepalive(3) Documentación de Perl aportada por el usuario POE::Component::Connection::Keepalive(3)

NOMBRE

POE::Component::Connection::Keepalive - un envoltorio de rueda para un socket mantenido vivo

VERSIÓN

versión 0.272

SINOPSIS

Ver la SINOPSIS de POE::Component::Client::Keepalive para un
ejemplo completo y funcional.
my $connection = $response->{connection};
$heap->{connection} = $connection;
$connection->start( InputEvent => "got_input" );
delete $heap->{connection};  # Cuando ya no se necesite.

DESCRIPCIÓN

POE::Component::Connection::Keepalive es una clase auxiliar para POE::Component::Client::Keepalive. Envuelve sockets gestionados, proporcionando algunas características adicionales.

Los objetos Connection liberan sus sockets subyacentes cuando son DESTRUÍDOS. Esto elimina la necesidad de liberar explícitamente los sockets cuando hayas terminado con ellos.

Los objetos Connection gestionan objetos POE::Wheel::ReadWrite internamente, ahorrando un poco de esfuerzo.

new
Crea una nueva instancia de POE::Component::Connection::Keepalive. Acepta dos parámetros: Un manejador de socket (socket) y una referencia a un objeto POE::Component::Client::Keepalive para gestionar el socket cuando se destruya la conexión. 
my $conn = POE::Component::Connection::Keepalive->new(
  socket  => $socket_handle,
  manager => $poe_component_client_keepalive,
);

new() es llamado normalmente por un objeto POE::Component::Client::Keepalive.

start
Inicia un objeto POE::Wheel::ReadWrite. Todos los parámetros excepto Handle para start() se pasan directamente al constructor de POE::Wheel::ReadWrite. Handle es proporcionado por el objeto connection. start() devuelve una referencia al nuevo objeto POE::Wheel::ReadWrite, pero no es necesario guardar una copia de esa rueda. El objeto connection guarda una copia de la referencia internamente, por lo que la rueda persistirá mientras la conexión lo haga. El objeto POE::Wheel::ReadWrite será DESTRUIDO cuando el objeto connection lo sea.

# Conexión asíncrona desde Client::Keepalive.
sub handle_connection {
  my $connection_info = $_[ARG0];
  $_[HEAP]->{connection} = $connection_info->{connection};
  $heap->{connection}->start(
    InputEvent => "got_input",
    ErrorEvent => "got_error",
  );
}
# Detener la conexión (y la rueda) cuando ocurre un error.
sub handle_error {
  delete $_[HEAP]->{connection};
}
wheel
Devuelve una referencia al objeto POE::Wheel::ReadWrite interno, para que se puedan llamar métodos sobre él. 
$heap->{connection}->wheel()->pause_input();
close
Cierra la conexión inmediatamente. Llama también a shutdown_input() y shutdown_output() en la rueda.
