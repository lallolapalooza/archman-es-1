POE::Filter::HTTPHead(3) Documentación de Perl aportada por el usuario POE::Filter::HTTPHead(3)

NOMBRE

POE::Filter::HTTPHead - filtra datos como objetos HTTP::Response

VERSIÓN

versión 0.949

SINÓPSIS

$filtro = POE::Filter::HTTPHead->new();
$ref_array_de_objetos_respuesta =
  $filtro->get($ref_array_de_fragmentos_crudos_del_driver);
$ref_array_de_restos = $filtro->get_pending();

DESCRIPCIÓN

El filtro HTTPHead convierte datos de flujo que tienen el formato apropiado en un objeto HTTP::Response. En un mundo totalmente POE, esto se colocaría en el otro extremo de una conexión como POE::Filter::HTTPD

new

Crea un nuevo filtro para analizar cabeceras HTTP. No toma parámetros y devuelve un objeto POE::Filter::HTTPHead flamante.

MÉTODOS

Consulta POE::Filter para ver la documentación de la API pública.

get_pending

Devuelve datos sin analizar pendientes en el búfer de entrada de este filtro. Es utilizado por los objetos POE::Wheel para cambiar de filtro sin problemas.

Los detalles se pueden encontrar en la documentación de POE::Filter.
