NOMBRE

Pod::Simple::SimpleTree -- analiza Pod en un árbol de análisis simple

SINOPSIS

% cat ptest.pod
=head1 PASTEL
¡Me gusta el B<pastel>!
% perl -MPod::Simple::SimpleTree -MData::Dumper -e \
   "print Dumper(Pod::Simple::SimpleTree->new->parse_file(shift)->root)" \
   ptest.pod
$VAR1 = [
          'Document',
          { 'start_line' => 1 },
          [
            'head1',
            { 'start_line' => 1 },
            'PASTEL'
          ],
          [
            'Para',
            { 'start_line' => 3 },
            '¡Me gusta ',
            [
              'B',
              {},
              'pastel'
            ],
            '!'
          ]
        ];

DESCRIPCIÓN

Esta clase es de interés para quienes escriben un procesador/formateador de Pod.

Esta clase toma Pod y lo analiza, devolviendo un árbol de análisis hecho solo de arrayrefs, hashrefs y cadenas.

Esta es una subclase de Pod::Simple y hereda todos sus métodos.

Esta clase está inspirada en el estilo de análisis "Tree" de XML::Parser, aunque no utiliza exactamente el mismo formato LoL.

MÉTODOS

Al final del análisis, llama a "$parser->root" para obtener el nodo superior del árbol.

CONTENIDO DEL ÁRBOL

Cada nodo de elemento en el árbol de análisis se representa mediante un arrayref de la forma: "[ nombre_del_elemento, \%atributos, ...subnodos... ]". Vea el volcado del árbol de ejemplo en la Sinopsis, arriba.

Cada nodo de texto en el árbol se representa mediante un escalar de cadena simple (sin ref). Por lo tanto, puede probar ref($nodo) para ver si tiene un nodo de elemento o solo un nodo de texto.

El nodo superior del árbol es "[ 'Documento', \%atributos, ...subnodos... ]"
