NOMBRE

POE::Resource::FileHandles - gestor interno de manejadores de archivos para POE::Kernel

SINOPSIS

No hay API pública.

DESCRIPCIÓN

POE::Resource::FileHandles es una clase mixta para POE::Kernel. Proporciona las características de bajo nivel para gestionar manejadores de archivos. Es utilizado internamente por POE::Kernel, por lo que no tiene una interfaz pública.

VER TAMBIÉN

Ver "Observadores de I/O (Selects)" en POE::Kernel para la API pública de observadores de archivos.

Ver "Recursos" en POE::Kernel para información pública sobre recursos de POE.

Ver POE::Resource para una discusión general sobre recursos y las clases que los gestionan.

ERRORES

POE observa I/O basándose en manejadores de archivos en lugar de descriptores de archivos, lo que significa que puede haber conflictos entre su API y un bucle de eventos subyacente basado en descriptores. Esto no suele ser un problema, pero puede requerir una solución alternativa en ciertos casos extremos.
