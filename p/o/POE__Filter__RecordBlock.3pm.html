NOMBRE

POE::Filter::RecordBlock - traducir entre registros discretos y bloques de ellos

SINOPSIS

Hola, estimado lector. Esta SINOPSIS no contiene un ejemplo de programa completamente funcional porque su humilde documentador no puede encontrar un caso de uso corto y razonable para este módulo. $filter = new POE::Filter::RecordBlock( BlockSize => 4 );

DESCRIPCIÓN

En la entrada, POE::Filter::RecordBlock traduce un flujo de elementos discretos a un "bloque" de ellos. Lo hace recogiendo elementos hasta que tiene BlockSize de ellos, luego devolviendo todos en una referencia de array.

En la salida, este módulo aplana las referencias de array.

Este módulo puede ser obsoleto en el futuro. Por favor, póngase en contacto con el mantenedor si este módulo le resulta útil.

MÉTODOS PÚBLICOS DEL FILTRO

Además de los métodos habituales de POE::Filter, POE::Filter::RecordBlock admite lo siguiente.

new

new() toma al menos un argumento obligatorio, BlockSize, que debe estar definido y ser mayor que cero. new() también acepta un parámetro booleano CheckPut que indica si put() debe verificar el tamaño de bloque adecuado antes de permitir que los datos se serialicen.

No se recomienda usar CheckPut, ya que habilita un búfer de escritura en el filtro, rompiendo así put() para un uso normal.

put_pending

put_pending() devuelve una referencia de array de cualquier registro que esté esperando ser enviado. Es el equivalente de salida del accesador get_pending() de POE::Filter. put_pending() no es parte de la API canónica de POE::Filter, por lo que nada lo utilizará. Depende de las aplicaciones manejar la salida pendiente, siempre que sea apropiado hacerlo.

blocksize

blocksize() es un accesor/mutador para el valor BlockSize de POE::Filter::RecordBlock.

checkput

checkput() es un accesor/mutador para el indicador CheckPut de POE::Filter::RecordBlock.

ERRORES

Este filtro puede mantener un búfer de salida que ninguna otra parte de POE conocerá.

Este filtro implementa una característica altamente especializada y aparentemente no de utilidad general.

¿Alguien usa este filtro? Este filtro puede ser obsoleto si nadie se pronuncia.
