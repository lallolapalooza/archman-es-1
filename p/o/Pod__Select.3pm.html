Paquete: perl-pod-parser

Pod::Select(3) Documentación Perl contribuida por el usuario Pod::Select(3)

NOMBRE

Pod::Select, podselect() - extraer secciones seleccionadas de POD de la entrada

SINOPSIS

use Pod::Select;
## Seleccionar todas las secciones POD para cada archivo en @filelist
## e imprimir el resultado en la salida estándar.
podselect(@filelist);
## Igual que arriba, pero escribir en tmp.out
podselect({-output => "tmp.out"}, @filelist):
## Seleccionar de la listade archivos dada, solo aquellas secciones POD que están
## dentro de una sección de 1er nivel llamada cualquiera de: NAME, SYNOPSIS, OPTIONS.
podselect({-sections => ["NAME|SYNOPSIS", "OPTIONS"]}, @filelist):
## Seleccionar la sección "DESCRIPTION" de los PODS de STDIN y escribir
## el resultado en STDERR.
podselect({-output => ">&STDERR", -sections => ["DESCRIPTION"]}, \*STDIN);

o

use Pod::Select;
## Crear un objeto parser para seleccionar secciones POD de la entrada
$parser = new Pod::Select();
## Seleccionar todas las secciones POD para cada archivo en @filelist
## e imprimir el resultado en tmp.out.
$parser->parse_from_file("<&STDIN", "tmp.out");
## Seleccionar de la listade archivos dada, solo aquellas secciones POD que están
## dentro de una sección de 1er nivel llamada cualquiera de: NAME, SYNOPSIS, OPTIONS.
$parser->select("NAME|SYNOPSIS", "OPTIONS");
for (@filelist) { $parser->parse_from_file($_); }
## Seleccionar las secciones "DESCRIPTION" y "SEE ALSO" de los PODS de
## STDIN y escribir el resultado en STDERR.
$parser->select("DESCRIPTION");
$parser->add_selection("SEE ALSO");
$parser->parse_from_filehandle(\*STDIN, \*STDERR);

REQUIERE

perl5.005, Pod::Parser, Exporter, Carp

EXPORTA

podselect()

DESCRIPCION

NOTA: Este módulo se considera obsoleto; las versiones modernas de Perl (5.31.1 y superiores) van a eliminar Pod-Parser del núcleo y usarán Pod::Simple para todas las cuestiones de POD.

podselect() es una función que extraerá secciones especificadas de la documentación POD de un flujo de entrada. Esta capacidad es proporcionada por el módulo Pod::Select, que es una subclase de Pod::Parser. Pod::Select proporciona un método llamado select() para especificar el conjunto de secciones POD a seleccionar para procesamiento/impresión. podselect() simplemente crea un objeto Pod::Select y luego invoca podselect() seguido de parse_from_file().

ESPECIFICACIONES DE SECCIÓN

podselect() y Pod::Select::select() pueden recibir una o más "especificaciones de sección" para restringir el texto procesado solo al conjunto deseado de secciones y sus subsecciones correspondientes. Una especificación de sección es una cadena que contiene una o más expresiones regulares al estilo Perl separadas por barras ("/"). Si necesita usar una barra literalmente dentro de un título de sección, puede escaparla con una barra invertida ("\/").

La sintaxis formal de una especificación de sección es:

•
regex-titulo-head1/regex-titulo-head2/...

Cualquier expresión regular omitida o vacía se establecerá por defecto a ".*". Tenga en cuenta que cada expresión regular dada se ancla implícitamente añadiendo "^" y "$" al principio y al final. Además, si una expresión regular dada comienza con un carácter "!", entonces la expresión se *niega* (así que "!foo" coincidiría con cualquier cosa *excepto* "foo").

Algunos ejemplos de especificaciones de sección son:

  • Coincidir con las secciones "NAME" y "SYNOPSIS" y todas sus subsecciones:

    "NAME|SYNOPSIS"

  • Coincidir solo con las subsecciones "Question" y "Answer" de la sección "DESCRIPTION":

    "DESCRIPTION/Question|Answer"

  • Coincidir con la subsección "Comments" de *todas* las secciones:

    "/Comments"

  • Coincidir con todas las subsecciones de "DESCRIPTION" *excepto* "Comments":

    "DESCRIPTION/!Comments"

  • Coincidir con la sección "DESCRIPTION" pero *no* coincidir con ninguna de sus subsecciones:

    "DESCRIPTION/!.+"

  • Coincidir con todas las secciones de nivel superior pero ninguna de sus subsecciones:

    "/!.+"

MÉTODOS DE OBJETO

Los siguientes métodos se proporcionan en este módulo. Cada uno toma una referencia al objeto mismo como parámetro implícito.

curr_headings()

($head1, $head2, $head3, ...) = $parser->curr_headings();
$head1 = $parser->curr_headings(1);

Este método devuelve una lista de los encabezados de sección y subsección activos actualmente en el documento que se está procesando. La lista de encabezados devuelta corresponde al párrafo analizado más recientemente de la entrada.

Si se proporciona un argumento, debe corresponder al número de encabezado de sección deseado, en cuyo caso solo se devuelve el encabezado de sección especificado. Si no hay un encabezado de sección actual en el nivel especificado, se devuelve "undef".

select()

$parser->select($section_spec1,$section_spec2,...);

Este método se utiliza para seleccionar las secciones y subsecciones particulares de la documentación POD que se imprimirán y/o procesarán. El conjunto existente de secciones seleccionadas se *reemplaza* con el conjunto dado de secciones. Consulte add_selection() para añadir al conjunto actual de secciones seleccionadas.

Cada uno de los argumentos $section_spec debe ser una especificación de sección como se describe en "ESPECIFICACIONES DE SECCIÓN". Las especificaciones de sección son analizadas por este método y las expresiones regulares resultantes se almacenan en el objeto que llama.

Si no se proporcionan argumentos $section_spec, se borra el conjunto existente de secciones seleccionadas (lo que significa que se procesarán *todas* las secciones).

Este método *no* debe ser anulado normalmente por subclases.

add_selection()

$parser->add_selection($section_spec1,$section_spec2,...);

Este método se utiliza para añadir a las secciones y subsecciones actualmente seleccionadas de la documentación POD que se imprimirán y/o procesarán. Consulte <select()> para reemplazar las secciones actualmente seleccionadas.

Cada uno de los argumentos $section_spec debe ser una especificación de sección como se describe en "ESPECIFICACIONES DE SECCIÓN". Las especificaciones de sección son analizadas por este método y las expresiones regulares resultantes se almacenan en el objeto que llama.

Este método *no* debe ser anulado normalmente por subclases.

clear_selections()

$parser->clear_selections();

Este método no toma argumentos, tiene el mismo efecto exacto que invocar <select()> sin argumentos.

match_section()

$boolean = $parser->match_section($heading1,$heading2,...);

Devuelve un valor verdadero si los títulos de encabezado de sección y subsección dados coinciden con cualquiera de las especificaciones de sección seleccionadas actualmente en vigor por llamadas anteriores a select() y add_selection() (o si no hay secciones explícitamente seleccionadas/deseleccionadas).

Los argumentos $heading1, $heading2, etc. son los títulos de encabezado de las secciones, subsecciones, etc. correspondientes que se intentan hacer coincidir. Si $headingN se omite, se establece por defecto al encabezado de sección correspondiente actual en la entrada.

Este método *no* debe ser anulado normalmente por subclases.

Pod::Select (3pm)

NAME

Pod::Select - Selectively extract text from POD files

SYNOPSIS

    use Pod::Select;
    my $parser = Pod::Select->new(%options);
    # ... process files ...
    # ... call $parser->parse_file($filename) or $parser->parse_from_string($string) ...
    # ...
    if ($parser->is_selected($paragraph)) {
        # ... process the paragraph ...
    }

REQUIRES

None

EXPORTS

None by default. The function podselect is exported if requested.

DESCRIPTION

The Pod::Select module is used to select sections of POD (Plain Old Documentation) from one or more POD documents, and to process those selected sections. The module is based on the Pod::Parser module, and is intended to be used as a base class for other modules that need to extract specific POD sections (for example, pod2text, pod2html, etc.).

The primary mechanism for selecting sections is through the @sections argument to the new() constructor (or the -sections option to the podselect() function). This argument is an array of section specifications, where each specification is a string describing the section or subsection to be selected.

The format of a section specification is described in the "SECTION SPECIFICATIONS" section below.

SECTION SPECIFICATIONS

A section specification is a string that identifies a section or subsection. The format is:

    "section_name"
    "section_name/subsection_name"

A section or subsection name is a string that matches the text of a section or subsection heading in the POD document. The matching is case-insensitive.

If only a section name is given, then all subsections within that section are also selected.

If no section specifications are given, then all sections and subsections of the POD document are selected.

OBJECT METHODS

my $boolean = $parser->is_selected($paragraph);

This method is used to determine if the block of text given in $paragraph falls within the currently selected set of POD sections and subsections to be printed or processed. This method is also responsible for keeping track of the current input section and subsections. It is assumed that $paragraph is the most recently read (but not yet processed) input paragraph.

The value returned will be true if the $paragraph and the rest of the text in the same section as $paragraph should be selected (included) for processing; otherwise a false value is returned.

EXPORTED FUNCTIONS

The following functions are exported by this module. Please note that these are functions (not methods) and therefore "do not" take an implicit first argument.

podselect()

podselect(\%options,@filelist);

podselect will print the raw (untranslated) POD paragraphs of all POD sections in the given input files specified by @filelist according to the options given in "\%options".

If any argument to podselect is a reference to a hash (associative array) then the values with the following keys are processed as follows:

-output
A string corresponding to the desired output file (or ">&STDOUT" or ">&STDERR"), or a filehandle to write on. The default is to use standard output.
-sections
A reference to an array of sections specifications (as described in "SECTION SPECIFICATIONS") which indicate the desired set of POD sections and subsections to be selected from input. If no section specifications are given, then all sections of the PODs are used.

All other arguments are optional and should correspond to filehandles to read from or the names of input files containing POD sections. A file name of "", "-" or "<&STDIN" will be interpreted to mean standard input (which is the default if no arguments are given).

PRIVATE METHODS AND DATA

Pod::Select makes uses a number of internal methods and data fields which clients should not need to see or use. For the sake of avoiding name collisions with client data and methods, these methods and fields are briefly discussed here. Determined hackers may obtain further information about them by reading the Pod::Select source code.

Private data fields are stored in the hash-object whose reference is returned by the new() constructor for this class. The names of all private methods and data-fields used by Pod::Select begin with a prefix of "_" and match the regular expression "/^_\w+$/".
