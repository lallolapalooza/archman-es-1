NOMBRE

POE::Test::Sequence - Ayuda de prueba de POE para verificar una secuencia de eventos

SINOPSIS

Lo siento, no hay sinopsis en este momento.
Sin embargo, consulta t/90_regression/whjackson-followtail.t en el conjunto de pruebas de POE para un ejemplo completo.

DESCRIPCIÓN

POE::Test::Sequence es una ayuda de prueba que abstrae mucha de la tediosa complejidad necesaria para verificar el orden relativo de los eventos.

Con este módulo, se puede probar la secuencia de eventos sin depender necesariamente de tiempos específicos transcurridos entre ellos.

create_generic_session

El método create_generic_session() crea una POE::Session que dirige todos los eventos a través del objeto POE::Test::Sequence. Devuelve el objeto POE::Session, pero el programa de prueba no necesita almacenarlo en ningún lugar. De hecho, se recomienda no hacerlo sin entender las implicaciones.

Las implicaciones se pueden encontrar en la documentación de POE::Kernel y POE::Session.

Se puede encontrar un ejemplo de create_generic_session() en el programa de prueba t/90_regression/leolo-alarm-adjust.t de POE.

new

Crea un nuevo objeto de secuencia. Toma pares de parámetros con nombre, actualmente solo "sequence", que hace referencia a una matriz de pasos. Cada paso es una referencia a una matriz que contiene el evento esperado, un parámetro requerido para ese evento y una referencia de código para el paso siguiente opcional a tomar después de verificar ese evento.

my $sequence = POE::Test::Sequence->new(
  sequence => [
  [ got_idle_event => 0, sub { append_to_log("text") } ],
  ...,
]
);

next() utiliza los dos primeros elementos del paso para verificar que los pasos se están produciendo en el orden en que deberían. El tercer elemento es devuelto por next() y es adecuado para su uso como destino de goto(). Consulte el método next() para obtener más detalles.

next

El método next() requiere un nombre de evento y un parámetro escalar. Estos se comparan con los dos primeros elementos del siguiente paso de la secuencia para asegurarse de que los eventos ocurran en el orden en que deben ocurrir.

sub handle_start_event {
  goto $sequence->next("got_start_event", 0);
}

test_count

test_count() devuelve el número de pasos de prueba en el objeto de secuencia. Está destinado a ser utilizado para la planificación de pruebas.

use Test::More;
my $sequence = POE::Test::Sequence->new( ... );
plan tests => $sequence->test_count();

ERRORES

create_generic_session() está codificado para pasar solo el nombre del evento y el valor numérico 0 a next(). Esto está bien solo para las secuencias más genéricas.
