Pod::Text::Color(3perl) Guía de referencia para programadores de Perl Pod::Text::Color(3perl)

NOMBRE

Pod::Text::Color - Convierte datos POD a texto ASCII formateado con color

SINOPSIS

use Pod::Text::Color;
my $parser = Pod::Text::Color->new (sentence => 0, width => 78);
# Lee POD de STDIN y escribe a STDOUT.
$parser->parse_from_filehandle;
# Lee file.pod y escribe a file.txt.
$parser->parse_from_file ('file.pod', 'file.txt');

DESCRIPCIÓN

Pod::Text::Color es una subclase simple de Pod::Text que resalta el texto de salida usando secuencias de escape de color ANSI. Aparte del color, funciona en todos los aspectos como Pod::Text. Consulte Pod::Text para obtener detalles y opciones disponibles.

Term::ANSIColor se utiliza para obtener colores y, por lo tanto, debe estar instalado para usar este módulo.

COMPATIBILIDAD

Pod::Text::Color 0.05 (basado en Pod::Parser) fue la primera versión de este módulo incluida con Perl, en Perl 5.6.0.

La API actual basada en Pod::Simple se agregó en Pod::Text::Color 2.00. Pod::Text::Color 2.01 se incluyó en Perl 5.9.3, la primera versión de Perl en incorporar esos cambios.

Varios problemas con el ajuste de línea y la longitud de línea se solucionaron tan recientemente como en Pod::Text::Color 6.0.0.

Este módulo hereda su API y la mayor parte de su comportamiento de Pod::Text, por lo que los detalles en "COMPATIBILIDAD" en Pod::Text también se aplican. Pod::Text y Pod::Text::Color han tenido la misma versión de módulo desde 4.00, incluida en Perl 5.23.7. (Desafortunadamente, divergen de maneras confusas antes de eso).

ADVERTENCIAS

El ajuste de línea se realiza solo en espacios y tabulaciones ASCII, en lugar de utilizar un algoritmo de ajuste de línea correcto y consciente de Unicode.
