POE::Component::Resolver::Sidecar(3) Documentación de Perl aportada por el usuario POE::Component::Resolver::Sidecar(3)

NOMBRE

POE::Component::Resolver::Sidecar - delegar subproceso para llamar a getaddrinfo()

VERSIÓN

versión 0.921

SINOPSIS

Se usa internamente por POE::Component::Resolver.

DESCRIPCIÓN

POE::Component::Resolver crea subprocesos para llamar a getaddrinfo() para que el programa principal no se bloquee durante ese tiempo.

El código real de llamada a getaddrinfo() se abstrae en este módulo para que pueda ejecutarse en un programa ejecutable separado. Esto reduce la huella de memoria de bifurcar todo el proceso principal solo para getaddrinfo().

Es un patrón fuerte y útil que otros POE::Components han implementado antes. POE::Quickie lo hace de forma genérica. POE::Component::SimpleDBI y POE::Component::EasyDBI lo hacen para que sus subprocesos DBI sean relativamente ligeros.

main

El código principal para leer las solicitudes de POE::Component::Resolver de STDIN y escribir las respuestas de getaddrinfo() en STDOUT.

VER TAMBIÉN

POE::Component::Generic es una implementación genérica de este patrón.

POE::Quickie es otra implementación genérica de este patrón.

ERRORES

Ninguno conocido.
