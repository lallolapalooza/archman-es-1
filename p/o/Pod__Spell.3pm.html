NOMBRE

Pod::Spell - un formateador para la corrección ortográfica de Pod

VERSIÓN

versión 1.26

SINOPSIS

use Pod::Spell;
Pod::Spell->new->parse_from_file( 'File.pm' );
Pod::Spell->new->parse_from_filehandle( $infile, $outfile );

También mira podspell

% perl -MPod::Spell -e "Pod::Spell->new->parse_from_file(shift)" Thing.pm |spell |fmt

...o en lugar de canalizar a spell o "ispell", usa ">temp.txt", y abre temp.txt en tu procesador de textos para la corrección ortográfica.

DESCRIPCIÓN

Pod::Spell es un formateador de Pod cuya salida es buena para la corrección ortográfica. Pod::Spell es bastante parecido a Pod::Text, excepto que no pone mucho esfuerzo en el formateo real, y suprime cosas que parecen símbolos de Perl o jerga de Perl (para que tu programa de corrección ortográfica no se queje de palabras misteriosas como "$thing" o ""Foo::Bar"" o "hashref").

Esta clase funciona filtrando palabras que parecen Perl o cualquier forma de lenguaje informático (como "$thing" o ""N>7"" o ""@{$foo}{'bar','baz'}"", cualquier cosa en códigos C<...> o F<...>, cualquier cosa en párrafos verbatim (bloques de código), y cualquier cosa en la lista de palabras a ignorar. La lista predeterminada de palabras a ignorar para un documento comienza con la lista de palabras a ignorar definida por Pod::Wordlist, y puede ser complementada (por documento) teniendo una región de "=for stopwords" / "=for :stopwords" en un documento.

MÉTODOS

new

Pod::Spell->new(%options)

Crea una nueva instancia de Pod::Spell. Acepta varias opciones:

debug
Cuando se establece a un valor verdadero, mostrará mensajes de depuración sobre cómo se está procesando el Pod.

Por defecto es falso.

stopwords
Puede especificarse para usar una instancia alternativa de lista de palabras.

Por defecto es una nueva instancia de Pod::Wordlist.

no_wide_chars
Se pasará a Pod::Wordlist al crear una nueva instancia. Hace que todas las palabras con caracteres fuera del rango Latin-1 se eliminen de la salida.

stopwords

$self->stopwords->isa('Pod::WordList'); # verdadero

parse_from_filehandle($in_fh,$out_fh)

Este método toma un manejador de archivo de entrada (que se asume ya abierto para lectura) y lee todo el flujo de entrada buscando bloques (párrafos) de documentación POD para ser procesados. Si no se proporciona un primer argumento, se utiliza el manejador de archivo de entrada predeterminado "STDIN".

El parámetro $in_fh puede ser cualquier objeto que proporcione un método getline() para recuperar una sola línea de texto de entrada (por lo tanto, se podría usar un objeto envoltorio apropiado para procesar PODs de una sola cadena o un array de cadenas).

parse_from_file($filename,$outfile)

Este método toma un nombre de archivo y hace lo siguiente:

  • abre los archivos de entrada y salida para lectura (creando los manejadores de archivo apropiados)
  • invoca el método parse_from_filehandle() pasándole los manejadores de archivo de entrada y salida correspondientes.
  • cierra los archivos de entrada y salida.

Si se proporciona el nombre de archivo de entrada especial "", "-" o "<&STDIN", se utiliza el manejador de archivo STDIN para la entrada (y no se realiza ninguna apertura ni cierre). Si no se especifica ningún nombre de archivo de entrada, se implica "-". También se aceptan referencias a manejadores de archivo, u objetos que admiten las operaciones de E/S regulares (como "<$fh>" o "$fh-<Egt>getline>"); los manejadores deben estar ya abiertos.

Si se proporciona un segundo argumento, debe ser el nombre del archivo de salida deseado. Si se proporciona el nombre de archivo de salida especial "-" o ">&STDOUT", se utiliza el manejador de archivo STDOUT para la salida (y no se realiza ninguna apertura ni cierre). Si se proporciona el nombre de archivo de salida especial ">&STDERR", se utiliza el manejador de archivo STDERR para la salida (y no se realiza ninguna apertura ni cierre). Si no se está utilizando ningún manejador de archivo de salida y no se especifica ningún nombre de archivo de salida, se implica "-". Alternativamente, también se aceptan referencias a manejadores de archivo u objetos que admiten las operaciones de E/S regulares (como "print", por ejemplo IO::String); el objeto debe estar ya abierto.

CODIFICACIONES

Si tu Pod está codificado en algo diferente a Latin-1, debería declarar una codificación usando la directiva perlpod ""=encoding nombre_codificacion"".

AÑADIR PALABRAS A IGNORAR

Puedes añadir palabras a ignorar por documento con regiones "=for stopwords" / "=for :stopwords", así:

=for stopwords  plok Pringe zorch   snik !qux
foo bar baz quux quuux

Esto añade cada palabra en ese párrafo después de "stopwords" a la lista de palabras a ignorar, efectiva para el resto del documento. En tal lista, las palabras están separadas por espacios. (La cantidad de espacio no importa, siempre que no haya líneas en blanco en medio del párrafo.) Las formas plurales se añaden automáticamente usando Lingua::EN::Inflect. Las palabras que comienzan con "!" se eliminan de la lista de palabras a ignorar -- así "!qux" elimina "qux" de la lista de palabras a ignorar, si estaba allí en primer lugar. Ten en cuenta que si una palabra a ignorar está completamente en minúsculas, significa que está permitida en *cualquier* mayúscula; pero si la palabra tiene alguna letra mayúscula, significa que está permitida *solo* con *esa* mayúscula. Así que una entrada de Wordlist de "perl" permitiría "perl", "Perl" y (menos interesante) "PERL", "pERL", "PerL", etc. Sin embargo, una entrada de Wordlist de "Perl" solo detecta "Perl", no "perl". Así que si querías asegurarte de escribir solo "Perl", nunca "perl", podrías añadir esto al principio de tu documento:

=for stopwords !perl Perl

Entonces todas las instancias de la palabra "Perl" se eliminarían de la versión formateada por Pod::Spell de tu documento, pero cualquier instancia de la palabra "perl" permanecería (a menos que estuvieran en un código C<...> o F<...>).

Puedes tener varias regiones de "=for stopwords" en tu documento. Puedes incluso expresarlas así:

=begin stopwords
plok Pringe zorch
snik !qux
foo bar
baz quux quuux
=end stopwords

Si quieres usar secuencias E<...> en una región de "stopwords", tienes que usar ":stopwords", como aquí:

=for :stopwords
virtE<ugrave>

...lo que significa que estás añadiendo una palabra a ignorar de "virtù". Si hubieras omitido los dos puntos ":", eso significaría que estabas añadiendo una palabra a ignorar de "virtE<ugrave>" (con una E literal, un < literal, etc.), lo cual no tendría ningún efecto, ya que cualquier ocurrencia de virtE<ugrave> no se parece de todos modos a una palabra normal del lenguaje humano, y por lo tanto sería filtrada antes de que se consultara la lista de palabras a ignorar.

DESCRIPCIÓN

Pod::Spell utiliza un solo pase sobre el POD. Las palabras vacías deben añadirse antes de que aparezcan en el POD.

SUGERENCIA

Si introduce la salida de Pod::Spell en su procesador de textos y ejecuta una comprobación ortográfica, asegúrese de que no también está ejecutando una comprobación gramatical; ya que Pod::Spell elimina palabras que considera símbolos de Perl, jerga o palabras vacías, esto significa que tendrá frases agramaticales, dado que faltan palabras y todo. Y no necesita un corrector gramatical para decirle eso.
