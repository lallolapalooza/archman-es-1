Pod::Simple::Methody(3perl) Guía de Referencia del Programador de Perl Pod::Simple::Methody(3perl)

NOMBRE

Pod::Simple::Methody -- convierte eventos de Pod::Simple en llamadas a métodos

SINOPSIS

require 5;
use strict;
package SomePodFormatter;
use base qw(Pod::Simple::Methody);
sub handle_text {
  my($self, $text) = @_;
  ...
}
sub start_head1 {
  my($self, $attrs) = @_;
  ...
}
sub end_head1 {
  my($self) = @_;
  ...
}

...y métodos start_/end_ para cualesquiera otros eventos que desees capturar.

DESCRIPCIÓN

Esta clase es de interés para personas que escriben formateadores de Pod basados en Pod::Simple.

Esta clase (que es muy pequeña -- léase el código fuente) sobrescribe los métodos _handle_element_start, _handle_text, y _handle_element_end de Pod::Simple para que los eventos del analizador se conviertan en llamadas a métodos. (De lo contrario, es una subclase de Pod::Simple y hereda todos sus métodos).

Puedes usar esta clase como clase base para un formateador/procesador de Pod.

LLAMADA A MÉTODOS

Cuando Pod::Simple ve un "=head1 Hola", por ejemplo, básicamente hace esto:

$parser->_handle_element_start( "head1", \%attributes );
$parser->_handle_text( "Hola" );
$parser->_handle_element_end( "head1" );

Pero si creas una subclase de Pod::Simple::Methody, en su lugar hará esto cuando vea un "=head1 Hola":

$parser->start_head1( \%attributes ) if $parser->can('start_head1');
$parser->handle_text( "Hola" )   if $parser->can('handle_text');
$parser->end_head1()                 if $parser->can('end_head1');

Si Pod::Simple envía un evento donde el nombre del elemento tiene un guion, punto o dos puntos, el nombre del método correspondiente tendrá un guion bajo en su lugar. Por ejemplo, "foo.bar:baz" se convierte en start_foo_bar_baz y end_foo_bar_baz.

Ver el código fuente de Pod::Simple::Text para un ejemplo de uso de esta clase.
