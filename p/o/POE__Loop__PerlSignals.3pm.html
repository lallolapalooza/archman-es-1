NOMBRE

POE::Loop::PerlSignals - rutinas comunes de manejo de señales para los puentes de POE::Loop

SINOPSIS

Véase POE::Loop.

DESCRIPCIÓN

POE::Loop::PerlSignals implementa código común para manejar señales para muchos bucles de eventos diferentes. La mayoría de los bucles no manejan señales de forma nativa, por lo que este código se ha abstraído en un módulo reutilizable.

POE::Loop::PerlSignals sigue la interfaz pública de POE::Loop para el manejo de señales. Por lo tanto, consulte POE::Loop para obtener más detalles.

VER TAMBIÉN

POE, POE::Loop
