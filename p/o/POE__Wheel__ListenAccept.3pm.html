POE::Wheel::ListenAccept(3) Documentación de Perl aportada por el usuario POE::Wheel::ListenAccept(3)

NOMBRE

POE::Wheel::ListenAccept - aceptar conexiones de sockets de escucha regulares

SINOPSIS

Ver "SINOPSIS" en POE::Wheel::SocketFactory para una versión más simple de este programa.

#!perl
use warnings;
use strict;
use IO::Socket;
use POE qw(Wheel::ListenAccept Wheel::ReadWrite);
POE::Session->create(
  inline_states => {
    _start => sub {
      # Inicia el servidor.
      $_[HEAP]{server} = POE::Wheel::ListenAccept->new(
        Handle => IO::Socket::INET->new(
          LocalPort => 12345,
          Listen => 5,
        ),
        AcceptEvent => "on_client_accept",
        ErrorEvent => "on_server_error",
      );
    },
    on_client_accept => sub {
      # Empieza a interactuar con el cliente.
      my $client_socket = $_[ARG0];
      my $io_wheel = POE::Wheel::ReadWrite->new(
        Handle => $client_socket,
        InputEvent => "on_client_input",
        ErrorEvent => "on_client_error",
      );
      $_[HEAP]{client}{ $io_wheel->ID() } = $io_wheel;
    },
    on_server_error => sub {
      # Cierra el servidor.
      my ($operation, $errnum, $errstr) = @_[ARG0, ARG1, ARG2];
      warn "Error del servidor $operation $errnum: $errstr\n";
      delete $_[HEAP]{server};
    },
    on_client_input => sub {
      # Maneja la entrada del cliente.
      my ($input, $wheel_id) = @_[ARG0, ARG1];
      $input =~ tr[a-zA-Z][n-za-mN-ZA-M]; # ASCII rot13
      $_[HEAP]{client}{$wheel_id}->put($input);
    },
    on_client_error => sub {
      # Maneja el error del cliente, incluyendo la desconexión.
      my $wheel_id = $_[ARG3];
      delete $_[HEAP]{client}{$wheel_id};
    },
  }
);
POE::Kernel->run();
exit;

DESCRIPCIÓN

POE::Wheel::ListenAccept implementa llamadas accept() no bloqueantes para sockets de servidor de escucha normales. La aplicación proporciona el socket, utilizando algún medio normal como socket(), IO::Socket::INET o IO::Socket::UNIX. POE::Wheel::ListenAccept supervisa el socket de escucha y emite eventos cada vez que se acepta un nuevo cliente.

Por favor, consulte POE::Wheel::SocketFactory si necesita connect() no bloqueante o una solución de escucha/aceptación con más funciones.

POE::Wheel::ListenAccept solo acepta conexiones de clientes. No lee ni escribe datos, por lo que no necesita ni incluye un método put(). POE::Wheel::ReadWrite generalmente maneja el socket del cliente aceptado.

MÉTODOS PÚBLICOS

new

new() crea un nuevo objeto POE::Wheel::ListenAccept para un socket de escucha dado. El objeto generará eventos relacionados con el socket mientras exista.

new() acepta dos parámetros con nombre requeridos:

Handle

El parámetro del constructor "Handle" debe contener un manejador de socket de escucha. POE::Wheel::FollowTail supervisará este socket y accept() nuevas conexiones a medida que lleguen.

AcceptEvent

"AcceptEvent" es un nombre de evento requerido que POE::Wheel::ListenAccept emitirá para cada socket de cliente aceptado. "EVENTOS PÚBLICOS" lo describe en detalle.

ErrorEvent

"ErrorEvent" es un nombre de evento opcional que se emitirá cada vez que ocurra un problema grave. Por favor, consulte "EVENTOS PÚBLICOS" para más detalles.

event

event() permite a una sesión cambiar los eventos emitidos por una rueda sin destruir y recrear el objeto. Acepta uno o más de los eventos listados en "EVENTOS PÚBLICOS". Los nombres de eventos indefinidos deshabilitan esos eventos.

Ignorar conexiones:

sub ignore_new_connections {
  $_[HEAP]{tailor}->event( AcceptEvent => "on_ignored_accept" );
}
sub handle_ignored_accept {
  # no hace nada
}

ID

El método ID() devuelve el ID único de la rueda. Es útil para almacenar la rueda en un hash. Todos los eventos de POE::Wheel deben ir acompañados de un ID de rueda, que permite que la rueda sea referenciada en sus manejadores de eventos.

sub setup_listener {
  my $wheel = POE::Wheel::ListenAccept->new(... etc ...);
  $_[HEAP]{listeners}{$wheel->ID} = $wheel;
}

EVENTOS PÚBLICOS

POE::Wheel::ListenAccept emite un par de eventos.

AcceptEvent

"AcceptEvent" nombra el evento que se emitirá para cada socket de cliente recién aceptado. Va acompañado de tres parámetros:

$_[ARG0] contiene el manejador del socket del cliente recién aceptado. Depende de la aplicación hacer algo con este socket. La mayoría de los casos de uso implican pasar el socket a un constructor de POE::Wheel::ReadWrite.

$_[ARG1] contiene el valor de retorno de la llamada accept(), que a menudo es el extremo remoto codificado del extremo remoto del socket.

$_[ARG2] contiene el ID único del objeto POE::Wheel::ListenAccept. Este es el mismo valor que el devuelto por el método ID() de la rueda.

Un manejador de ejemplo de "AcceptEvent":

sub accept_state {
  my ($client_socket, $remote_addr, $wheel_id) = @_[ARG0..ARG2];
  # Hace que la dirección remota sea legible por humanos.
  my ($port, $packed_ip) = sockaddr_in($remote_addr);
  my $dotted_quad = inet_ntoa($packed_ip);
  print(
    "Rueda $wheel_id aceptó una conexión desde ",
    "$dotted_quad puerto $port.\n"
  );
  # Crea una sesión para interactuar con el socket.
  create_server_session($handle);
}

ErrorEvent

"ErrorEvent" nombra el evento que se generará cada vez que no se pueda aceptar una nueva conexión con éxito. Este evento va acompañado de cuatro parámetros:

$_[ARG0] contiene el nombre de la operación que falló. Normalmente es 'accept', pero ten en cuenta que no es necesariamente un nombre de función.

$_[ARG1] y $_[ARG2] contienen los valores numéricos y de cadena de $!, respectivamente. POE::Wheel::ListenAccept sabe cómo manejar EAGAIN (y equivalentes dependientes del sistema), por lo que este error nunca se devolverá.

$_[ARG3] contiene el ID único de la rueda, que puede ser útil para cerrar una rueda particular de un grupo de ellas.

Un manejador de eventos de ejemplo de "ErrorEvent". Esto asume que las ruedas se guardan como en el ejemplo "ID".

sub error_state {
  my ($operation, $errnum, $errstr, $wheel_id) = @_[ARG0..ARG3];
  warn "La rueda $wheel_id generó un error $operation $errnum: $errstr\n";
  delete $_[HEAP]{listeners}{$wheel_id};
}

VER TAMBIÉN

POE::Wheel describe las operaciones básicas de todas las ruedas con más detalle. Necesitas saber esto.

POE::Wheel::ReadWrite para una forma posible de manejar clientes una vez que tienes sus sockets.
