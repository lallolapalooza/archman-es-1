NOMBRE

Pod::InputObjects - objetos que representan párrafos de entrada POD, comandos, etc.

SINOPSIS

use Pod::InputObjects;

REQUIERE

perl5.004, Carp

EXPORTA

Nada.

DESCRIPCIÓN

NOTA: Este módulo se considera obsoleto; las versiones modernas de Perl (5.31.1 y posteriores) eliminarán Pod-Parser del núcleo y usarán Pod::Simple para todo lo relacionado con POD.

Este módulo define algunos objetos de entrada básicos utilizados por Pod::Parser al leer y analizar texto POD de una fuente de entrada. Se definen los siguientes objetos:

paquete Pod::Paragraph
Un objeto que corresponde a un párrafo de texto de entrada POD. Puede ser un párrafo normal, un párrafo literal o un párrafo de comando (ver perlpod).
paquete Pod::InteriorSequence
Un objeto que corresponde a un comando de secuencia interior del texto de entrada POD (ver perlpod).
paquete Pod::ParseTree
Un objeto que corresponde a un árbol de texto POD analizado. Cada "nodo" en un árbol de análisis (o ptree) es una cadena de texto o una referencia a un objeto Pod::InteriorSequence. Los nodos aparecen en el árbol de análisis en el orden en que fueron analizados de izquierda a derecha.

Cada uno de estos objetos de entrada se describe con más detalle en las secciones siguientes.

Pod::Paragraph

Un objeto que representa un párrafo de texto de entrada POD. Tiene los siguientes métodos/atributos:

Pod::Paragraph->new()

my $pod_para1 = Pod::Paragraph->new(-text => $text);
my $pod_para2 = Pod::Paragraph->new(-name => $cmd,
                                    -text => $text);
my $pod_para3 = new Pod::Paragraph(-text => $text);
my $pod_para4 = new Pod::Paragraph(-name => $cmd,
                                   -text => $text);
my $pod_para5 = Pod::Paragraph->new(-name => $cmd,
                                    -text => $text,
                                    -file => $filename,
                                    -line => $line_number);

Este es un método de clase que construye un objeto "Pod::Paragraph" y devuelve una referencia al nuevo objeto de párrafo. Puede recibir uno o dos argumentos de palabra clave. La palabra clave "-text" indica el texto correspondiente del párrafo POD. La palabra clave "-name" indica el nombre del comando POD correspondiente, como "head1" o "item" (no debe contener el prefijo "="); esto solo es necesario si el párrafo POD corresponde a un párrafo de comando. Las palabras clave "-file" y "-line" indican el nombre del archivo y el número de línea correspondientes al inicio del párrafo.

$pod_para->cmd_name()

my $para_cmd = $pod_para->cmd_name();

Si este párrafo es un párrafo de comando, este método devolverá el nombre del comando (sin ningún prefijo "=").

$pod_para->text()

my $para_text = $pod_para->text();

Este método devolverá el texto correspondiente del párrafo.

$pod_para->raw_text()

my $raw_pod_para = $pod_para->raw_text();

Este método devolverá el texto *crudo* del párrafo POD, exactamente como apareció en la entrada.

$pod_para->cmd_prefix()

my $prefix = $pod_para->cmd_prefix();

Si este párrafo es un párrafo de comando, este método devolverá el prefijo utilizado para denotar el comando (que debería ser la cadena "=" o "==").

$pod_para->cmd_separator()

my $separator = $pod_para->cmd_separator();

Si este párrafo es un párrafo de comando, este método devolverá el texto utilizado para separar el nombre del comando del resto del párrafo (si lo hay).

$pod_para->parse_tree()

my $ptree = $pod_parser->parse_text( $pod_para->text() );
$pod_para->parse_tree( $ptree );
$ptree = $pod_para->parse_tree();

Este método obtendrá/establecerá el árbol de análisis correspondiente del texto del párrafo.

$pod_para->file_line()

my ($filename, $line_number) = $pod_para->file_line();
my $position = $pod_para->file_line();

Devuelve el nombre de archivo y el número de línea actuales para el objeto de párrafo. Si se llama en un contexto de lista, devuelve una lista de dos elementos: primero el nombre del archivo, luego el número de línea. Si se llama en un contexto escalar, devuelve una cadena que contiene el nombre del archivo, seguido de dos puntos (':'), seguido del número de línea.

Pod::InteriorSequence

Un objeto que representa un comando de secuencia interior POD. Tiene los siguientes métodos/atributos:

Pod::InteriorSequence->new()

my $pod_seq1 = Pod::InteriorSequence->new(-name => $cmd
                                          -ldelim => $delimiter);
my $pod_seq2 = new Pod::InteriorSequence(-name => $cmd,
                                         -ldelim => $delimiter);
my $pod_seq3 = new Pod::InteriorSequence(-name => $cmd,
                                         -ldelim => $delimiter,
                                         -file => $filename,
                                         -line => $line_number);
my $pod_seq4 = new Pod::InteriorSequence(-name => $cmd, $ptree);
my $pod_seq5 = new Pod::InteriorSequence($cmd, $ptree);

Este es un método de clase que construye un objeto "Pod::InteriorSequence" y devuelve una referencia al nuevo objeto de secuencia interior. Debe recibir dos argumentos de palabra clave. La palabra clave "-ldelim" indica el delimitador izquierdo correspondiente de la secuencia interior (por ejemplo, '<'). La palabra clave "-name" indica el nombre del comando de secuencia interior correspondiente, como "I", "B" o "C". Las palabras clave "-file" y "-line" indican el nombre del archivo y el número de línea correspondientes al inicio de la secuencia interior. Si se proporciona el argumento $ptree, debe ser el último argumento y debe ser una cadena, o bien una referencia a un array adecuada para pasar a Pod::ParseTree::new (o puede ser una referencia a un objeto Pod::ParseTree).

Pod::InputObjects(3pm) — Arch manual pages

NAME

Pod::InputObjects — Provides the base-class and the concrete Pod::InteriorSequence and Pod::ParseTree objects

SYNOPSIS

    use Pod::InputObjects;

    # $pod_seq is a Pod::InteriorSequence object
    my $cmd_name = $pod_seq->cmd_name();
    $pod_seq->append("new text");

    # $ptree is a Pod::ParseTree object
    my $children = $ptree->children();
    $ptree->prepend( $new_item );

REQUIRES

Pod::Parser

EXPORTS

None. You must explicitly qualify all object methods.

DESCRIPTION

The Pod::Parser module is used to parse plain-text POD documentation. When it encounters text it outputs a Pod::ParseTree object. When it encounters an interior sequence (see Pod::Parser documentation), it outputs a Pod::InteriorSequence object.

This module provides the base classes for these objects, as well as the concrete implementations for them.

Pod::InteriorSequence

This object corresponds to a POD interior sequence. An interior sequence is any sequence of text starting with a letter, followed by zero or more letters, numbers, or underscores, followed by a left angle bracket ("<"), and ending with a right angle bracket (">"). It can be used to embed Perl code within POD documentation.

The text within the interior sequence is parsed into a Pod::ParseTree object. For example, the POD text:

    L<Something>

is parsed into a Pod::InteriorSequence object, where the command name is "L" and the associated parse-tree is a Pod::ParseTree object containing a single text-string "Something".

$pod_seq->cmd_name()

$pod_seq->cmd_name();

The name of the interior sequence command.

$pod_seq->prepend()

$pod_seq->prepend($text);
$pod_seq1->prepend($pod_seq2);

Prepends the given string or parse-tree or sequence object to the parse-tree of this interior sequence.

$pod_seq->append()

$pod_seq->append($text);
$pod_seq1->append($pod_seq2);

Appends the given string or parse-tree or sequence object to the parse-tree of this interior sequence.

$pod_seq->nested()

$outer_seq = $pod_seq->nested || print "not nested";

If this interior sequence is nested inside of another interior sequence, then the outer/parent sequence that contains it is returned. Otherwise "undef" is returned.

$pod_seq->raw_text()

my $seq_raw_text = $pod_seq->raw_text();

This method will return the raw text of the POD interior sequence, exactly as it appeared in the input.

$pod_seq->left_delimiter()

my $ldelim = $pod_seq->left_delimiter();

The leftmost delimiter beginning the argument text to the interior sequence (should be "<").

$pod_seq->right_delimiter()

The rightmost delimiter beginning the argument text to the interior sequence (should be ">").

$pod_seq->parse_tree()

my $ptree = $pod_parser->parse_text($paragraph_text);
$pod_seq->parse_tree( $ptree );
$ptree = $pod_seq->parse_tree();

This method will get/set the corresponding parse-tree of the interior sequence's text.

$pod_seq->file_line()

my ($filename, $line_number) = $pod_seq->file_line();
my $position = $pod_seq->file_line();

Returns the current filename and line number for the interior sequence object. If called in a list context, it returns a list of two elements: first the filename, then the line number. If called in a scalar context, it returns a string containing the filename, followed by a colon (':'), followed by the line number.

Pod::InteriorSequence::DESTROY()

This method performs any necessary cleanup for the interior-sequence. If you override this method then it is imperative that you invoke the parent method from within your own method, otherwise interior-sequence storage will not be reclaimed upon destruction!

Pod::ParseTree

This object corresponds to a tree of parsed POD text. As POD text is scanned from left to right, it is parsed into an ordered list of text-strings and Pod::InteriorSequence objects (in order of appearance). A Pod::ParseTree object corresponds to this list of strings and sequences. Each interior sequence in the parse-tree may itself contain a parse-tree (since interior sequences may be nested).

Pod::ParseTree->new()

my $ptree1 = Pod::ParseTree->new;
my $ptree2 = new Pod::ParseTree;
my $ptree4 = Pod::ParseTree->new($array_ref);
my $ptree3 = new Pod::ParseTree($array_ref);

This is a class method that constructs a "Pod::Parse_tree" object and returns a reference to the new parse-tree. If a single-argument is given, it must be a reference to an array, and is used to initialize the root (top) of the parse tree.

$ptree->top()

my $top_node = $ptree->top();
$ptree->top( $top_node );
$ptree->top( @children );

This method gets/sets the top node of the parse-tree. If no arguments are given, it returns the topmost node in the tree (the root), which is also a Pod::ParseTree. If it is given a single argument that is a reference, then the reference is assumed to a parse-tree and becomes the new top node. Otherwise, if arguments are given, they are treated as the new list of children for the top node.

$ptree->children()

This method gets/sets the children of the top node in the parse-tree. If no arguments are given, it returns the list (array) of children (each of which should be either a string or a Pod::InteriorSequence. Otherwise, if arguments are given, they are treated as the new list of children for the top node.

$ptree->prepend()

This method prepends the given text or parse-tree to the current parse-tree. If the first item on the parse-tree is text and the argument is also text, then the text is prepended to the first item (not added as a separate string). Otherwise the argument is added as a new string or parse-tree before the current one.

$ptree->append()

This method appends the given text or parse-tree to the current parse-tree. If the last item on the parse-tree is text and the argument is also text, then the text is appended to the last item (not added as a separate string). Otherwise the argument is added as a new string or parse-tree after the current one.

$ptree->raw_text()

my $ptree_raw_text = $ptree->raw_text();

This method will return the raw text of the POD parse-tree exactly as it appeared in the input.

Pod::ParseTree::DESTROY()

This method performs any necessary cleanup for the parse-tree. If you override this method then it is imperative that you invoke the parent method from within your own method, otherwise parse-tree storage will not be reclaimed upon destruction!
