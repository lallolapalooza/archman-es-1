POE::Filter::Block(3) Documentación de Perl aportada por el usuario POE::Filter::Block(3)

NOMBRE

POE::Filter::Block - traducir datos entre flujos y bloques

SINOPSIS

#!perl
use warnings;
use strict;
use POE::Filter::Block;
my $filter = POE::Filter::Block->new( BlockSize => 8 );
# Imprime tres líneas: abcdefgh, ijklmnop, qrstuvwx.
# Los bytes "y" y "z" permanecen en el buffer y esperan la finalización del
# siguiente bloque de 8 bytes.
$filter->get_one_start([ "abcdefghijklmnopqrstuvwxyz" ]);
while (1) {
  my $block = $filter->get_one();
  last unless @$block;
  print $block->[0], "\n";
}
# Imprime una línea: yz123456
$filter->get_one_start([ "123456" ]);
while (1) {
  my $block = $filter->get_one();
  last unless @$block;
  print $block->[0], "\n";
}

DESCRIPCIÓN

POE::Filter::Block traduce datos entre flujos seriales y bloques. Puede manejar bloques de longitud fija y prefijados por longitud, y puede extenderse para manejar otros tipos de bloques.

Los bloques de longitud fija se usan cuando el constructor de Block se llama con un valor de BlockSize. De lo contrario, el filtro Block usa bloques prefijados por longitud.

Los usuarios que especifican tamaños de bloque menores que uno se merecen lo que obtienen.

En modo de longitud variable, se puede especificar un parámetro LengthCodec. El valor de LengthCodec debe ser una referencia a una lista de dos funciones: el codificador de longitud y el decodificador de longitud:

LengthCodec => [ \&encoder, \&decoder ]

El codificador toma una referencia a un buffer y le antepone la longitud del buffer. El codificador predeterminado antepone la representación ASCII de la longitud del buffer y un byte chr(0) para separar la longitud de los datos reales:

sub _default_encoder {
  my $stuff = shift;
  substr($$stuff, 0, 0) = length($$stuff) . "\0";
  return;
}

El decodificador correspondiente devuelve la longitud del bloque después de eliminarla y el separador del buffer. No devuelve nada si no se puede determinar ninguna longitud.

sub _default_decoder {
  my $stuff = shift;
  unless ($$stuff =~ s/^(\d+)\0//s) {
    warn length($1), " strange bytes removed from stream"
      if $$stuff =~ s/^(\D+)//s;
    return;
  }
  return $1;
}

Este filtro retiene los bloques incompletos hasta que se completan en un buffer de delimitación. Para controlar el uso de memoria, se impone un tamaño máximo del buffer de delimitación. Este tamaño máximo tiene un valor predeterminado de 512 MB (512*1024*1024 octetos). Puede cambiar este límite de tamaño con el parámetro "MaxBuffer".

MaxBuffer => 1099511627776  # ¡Un terabyte!

El tamaño de cada bloque individual también está limitado. Por defecto, cada bloque no puede tener más de 64 MB. Puede cambiar este límite de tamaño con el parámetro "MaxLength".

MaxLength => 10             # bloques pequeños

Recuerde que MaxBuffer debe ser mayor que MaxLength. Además, debe haber espacio para el prefijo de longitud.

Si se excede la restricción "MaxLength" o "MaxBuffer", "POE::Filter::Bock" lanzará una excepción.

MÉTODOS PÚBLICOS DEL FILTRO

POE::Filter::Block no tiene métodos públicos adicionales.
