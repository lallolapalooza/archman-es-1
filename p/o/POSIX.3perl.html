NOMBRE

POSIX - Interfaz de Perl para IEEE Std 1003.1

SINOPSIS

use POSIX ();
use POSIX qw(setsid);
use POSIX qw(:errno_h :fcntl_h);
printf "EINTR es %d\n", EINTR;
my $id_sesion = POSIX::setsid();
my $fd = POSIX::open($ruta, O_CREAT|O_EXCL|O_WRONLY, 0644);
    # nota: eso es un descriptor de archivo, *NO* un manejador de archivo

DESCRIPCIÓN

El módulo POSIX permite acceder a todos (o casi todos) los identificadores estándar de POSIX 1003.1. Muchos de estos identificadores han sido dotados de interfaces estilo Perl.

Este documento presenta una lista condensada de las características disponibles en el módulo POSIX. Consulte las páginas del manual de su sistema operativo para obtener información general sobre la mayoría de las características. Consulte perlfunc para las funciones que se indica que son idénticas o casi idénticas a las funciones integradas de Perl.

La primera sección describe las funciones POSIX de la especificación 1003.1. La segunda sección describe algunas clases para objetos de señales, objetos TTY y otros objetos varios. Las secciones restantes enumeran varias constantes y macros en una organización que sigue aproximadamente IEEE Std 1003.1b-1993.

La notación "[C99]" indica funciones que se añadieron en la versión ISO/IEC 9899:1999 del estándar del lenguaje C. Algunas pueden no estar disponibles en su sistema si éste se adhiriera a un estándar anterior. Los intentos de usar cualquiera de las faltantes resultarán en un mensaje de error fatal en tiempo de ejecución.

ADVERTENCIAS

Todo se exporta por defecto (con un puñado de excepciones). Esta es una desafortunada característica de compatibilidad hacia atrás y su uso es fuertemente desaconsejado. Debe evitar la exportación (diciendo "use POSIX ();", como de costumbre) y luego usar nombres completamente calificados (por ejemplo, "POSIX::SEEK_END"), o proporcionar una lista de importación explícita. Si no hace ninguna de las dos cosas y opta por el predeterminado (como en "use POSIX;"), importará cientos y cientos de símbolos en su espacio de nombres.

Algunas funciones no están implementadas porque son específicas de C. Si intenta llamar a estas, imprimirán un mensaje indicando que no están implementadas y sugerirán usar el equivalente en Perl, si existe. Por ejemplo, intentar acceder a la llamada setjmp() provocará el mensaje ""setjmp() es específico de C: use eval {} en su lugar"".

Además, algunos proveedores maliciosos afirmarán el cumplimiento de 1003.1, pero en realidad no lo son: no pasarán las suites de pruebas de cumplimiento POSIX (PCTS). Por ejemplo, un proveedor puede no definir "EDEADLK", o la semántica de los valores de errno establecidos por open(2) podrían no ser exactamente correctos. Perl no intenta verificar el cumplimiento POSIX. Esto significa que actualmente puede decir con éxito "use POSIX", y luego más adelante en su programa descubrir que su proveedor ha sido negligente y no hay una macro "ICANON" utilizable después de todo. Esto podría interpretarse como un error.

FUNCIONES

"_exit"
Es idéntica a la función C _exit(). Sale del programa inmediatamente, lo que significa, entre otras cosas, que las E/S en búfer no se vacían.

Tenga en cuenta que al usar hilos y en Linux, esta no es una buena manera de salir de un hilo porque en Linux los procesos y los hilos son algo similar (Nota: aunque esta es la situación a principios de 2003, hay proyectos en marcha para tener hilos con semántica más al estilo POSIX en Linux). Si no desea regresar de un hilo, desvincule el hilo.

"abort"
Es idéntica a la función C abort(). Termina el proceso con una señal "SIGABRT" a menos que sea capturada por un manejador de señales o si el manejador no retorna normalmente (por ejemplo, realiza un "longjmp").
"abs"
Es idéntica a la función integrada de Perl abs(), retornando el valor absoluto de su argumento numérico (excepto que POSIX::abs() debe proporcionarse un valor explícito (en lugar de depender de un $_ implícito): 
$valor_absoluto = POSIX::abs(42);   # bueno
$valor_absoluto = POSIX::abs();     # lanza una excepción
"access"
Determina la accesibilidad de un archivo. 
if( POSIX::access( "/", &POSIX::R_OK ) ){
        print "tengo permiso de lectura\n";
}

Retorna "undef" en caso de falla. Nota: no use access() con fines de seguridad. Entre la llamada a access() y la operación para la que se está preparando, los permisos podrían cambiar: una clásica condición de carrera.

"acos"
Es idéntica a la función C acos(), retornando el arcocoseno de su argumento numérico. Ver también Math::Trig.
"acosh"
Es idéntica a la función C acosh(), retornando el arcocoseno hiperbólico de su argumento numérico [C99]. Ver también Math::Trig. Añadida en Perl v5.22.
"alarm"
Es idéntica a la función integrada de Perl alarm(), ya sea para armar o desarmar el temporizador "SIGARLM", excepto que POSIX::alarm() debe proporcionarse un valor explícito (en lugar de depender de un $_ implícito): 
POSIX::alarm(3)     # bueno
POSIX::alarm()      # lanza una excepción
"asctime"
Es idéntica a la función C asctime(). Retorna una cadena de la forma 
"Vie Jun  2 18:22:13 2000\n\0"

y se llama así:

$asctime = asctime($seg, $min, $hora, $dia_mes, $mes,
                   $anio, $dia_sem, $dia_anio, $horario_verano);

El $mes tiene base cero: enero equivale a 0. El $anio tiene base 1900: 2001 equivale a 101. $dia_sem y $dia_anio por defecto son cero (y generalmente se ignoran de todos modos), y $horario_verano por defecto es -1.

Nota que el resultado siempre está en inglés. Use "strftime" en su lugar para obtener un resultado adecuado para la configuración regional actual. El formato %c de esa función produce la representación preferida de la configuración regional.

"asin"
Es idéntica a la función C asin(), retornando el arcoseno de su argumento numérico. Ver también Math::Trig.
"asinh"
Es idéntica a la función C asinh(), retornando el arcocoseno hiperbólico de su argumento numérico [C99]. Ver también Math::Trig. Añadida en Perl v5.22.
"assert"
No implementada, pero puedes usar "die" en perlfunc y el módulo Carp para lograr cosas similares.
"atan"
Es idéntica a la función C atan(), retornando el arcotangente de su argumento numérico. Ver también Math::Trig.
"atanh"
Es idéntica a la función C atanh(), retornando el arcotangente hiperbólico de su argumento numérico [C99]. Ver también Math::Trig. Añadida en Perl v5.22.
"atan2"
Es idéntica a la función integrada de Perl atan2(), retornando el arcotangente definido por sus dos argumentos numéricos, la coordenada y y la coordenada x. Ver también Math::Trig.
"atexit"
No implementada. atexit() es específico de C: use "END {}" en su lugar, ver perlmod.
"atof"
No implementada. atof() es específico de C. Perl convierte cadenas a números de forma transparente. Si necesita forzar un escalar a un número, súmele cero.
"atoi"
No implementada. atoi() es específico de C. Perl convierte cadenas a números de forma transparente. Si necesita forzar un escalar a un número, súmele cero. Si necesita solo la parte entera, ver "int" en perlfunc.
"atol"
No implementado. atol() es específico de C. Perl convierte cadenas a números transparentemente. Si necesitas forzar un escalar a número, súmale cero. Si solo necesitas la parte entera, consulta "int" en perlfunc.
"bsearch"
bsearch() no se proporciona. Para realizar una búsqueda binaria en listas de palabras, consulta Search::Dict.
"calloc"
No implementado. calloc() es específico de C. Perl realiza la gestión de memoria de forma transparente.
"cbrt"
La raíz cúbica [C99]. Añadido en Perl v5.22.
"ceil"
Es idéntico a la función C ceil(), y devuelve el valor entero más pequeño mayor o igual que el argumento numérico dado.
"chdir"
Es idéntico a la función incorporada de Perl chdir(), que permite cambiar el directorio de trabajo (predeterminado), consulta "chdir" en perlfunc, con la excepción de que POSIX::chdir() debe recibir un valor explícito (en lugar de depender de un $_ implícito): 
$rv = POSIX::chdir('ruta/al/dir');      # correcto
$rv = POSIX::chdir();                   # lanza excepción
"chmod"
Es idéntico a la función incorporada de Perl chmod(), que permite cambiar los permisos de archivos y directorios, consulta "chmod" en perlfunc, con la excepción de que POSIX::chmod() solo puede cambiar un archivo a la vez (en lugar de una lista de archivos): 
$c = chmod 0664, $archivo1, $archivo2;          # correcto
$c = POSIX::chmod 0664, $archivo1;           # lanza excepción
$c = POSIX::chmod 0664, $archivo1, $archivo2;   # lanza excepción

Al igual que con la función incorporada chmod(), $archivo puede ser un nombre de archivo o un manejador de archivo.

"chown"
Es idéntico a la función incorporada de Perl chown(), que permite cambiar los propietarios y grupos de archivos y directorios, consulta "chown" en perlfunc.
"clearerr"
No implementado. Usa el método IO::Handle::clearerr() en su lugar, para restablecer el estado de error (si lo hay) y el estado de fin de archivo (si lo hay) del flujo dado.
"clock"
Es idéntico a la función C clock(), y devuelve la cantidad de tiempo de procesador consumido en microsegundos.
"close"
Cierra el archivo. Utiliza descriptores de archivo como los obtenidos al llamar a "POSIX::open". 
$fd = POSIX::open( "archivo", &POSIX::O_RDONLY );
POSIX::close( $fd );

Devuelve "undef" en caso de fallo.

Consulta también "close" en perlfunc.

"closedir"
Es idéntico a la función incorporada de Perl closedir() para cerrar un manejador de directorio, consulta "closedir" en perlfunc.
"cos"
Es idéntico a la función incorporada de Perl cos() para devolver el coseno de su argumento numérico, excepto que POSIX::cos() debe recibir un valor explícito (en lugar de depender de un $_ implícito): 
$coseno = POSIX::cos(3);    # correcto
$coseno = POSIX::cos();     # lanza excepción

Consulta "cos" en perlfunc; consulta también Math::Trig.

"cosh"
Es idéntico a la función C cosh(), para devolver el coseno hiperbólico de su argumento numérico. Consulta también Math::Trig.
"copysign"
Devuelve "x" pero con el signo de "y" [C99]. Añadido en Perl v5.22. 
$x_con_signo_de_y = POSIX::copysign($x, $y);

Consulta también "signbit".

"creat"
Crea un nuevo archivo. Devuelve un descriptor de archivo como los devueltos por "POSIX::open". Usa "POSIX::close" para cerrar el archivo. 
$fd = POSIX::creat( "archivo", 0611 );
POSIX::close( $fd );

Consulta también "sysopen" en perlfunc y su bandera "O_CREAT".

"ctermid"
Genera el nombre de ruta para la terminal de control. 
$ruta = POSIX::ctermid();
"ctime"
Es idéntico a la función C ctime() y equivalente a "asctime(localtime(...))", consulta "asctime" y "localtime".
"cuserid" [POSIX.1-1988]
Obtiene el nombre de inicio de sesión del propietario del proceso actual. 
$nombre = POSIX::cuserid();

Nota: esta función no ha sido especificada por POSIX desde 1990 y se incluye solo por compatibilidad con versiones anteriores. El código nuevo debería usar getlogin() en su lugar.

"difftime"
Es idéntico a la función C difftime(), para devolver la diferencia de tiempo (en segundos) entre dos momentos (tal como los devuelve time()), consulta "time".
"div"
No implementado. div() es específico de C, usa "int" en perlfunc en la división habitual "/" y el módulo "%".
"dup"
Es similar a la función C dup(), para duplicar un descriptor de archivo.

Utiliza descriptores de archivo como los obtenidos al llamar a "POSIX::open".

Devuelve "undef" en caso de fallo.

"dup2"
Es similar a la función C dup2(), para duplicar un descriptor de archivo a otro descriptor de archivo conocido.

Utiliza descriptores de archivo como los obtenidos al llamar a "POSIX::open".

Devuelve "undef" en caso de fallo.

"erf"
La función de error [C99]. Añadido en Perl v5.22.
"erfc"
La función de error complementaria [C99]. Añadido en Perl v5.22.
"errno"
Devuelve el valor de errno. 
$errno = POSIX::errno();

Esto es idéntico a los valores numéricos de $!, consulta "$ERRNO" en perlvar.

"execl"
No implementado. execl() es específico de C, consulta "exec" en perlfunc.
"execle"
No implementado. execle() es específico de C, consulta "exec" en perlfunc.
"execlp"
No implementado. execlp() es específico de C, consulta "exec" en perlfunc.
"execv"
No implementado. execv() es específico de C, consulta "exec" en perlfunc.
"execve"
No implementado. execve() es específico de C, consulta "exec" en perlfunc.
"execvp"
No implementado. execvp() es específico de C, consulta "exec" en perlfunc.
"exit"
Es idéntico a la función incorporada de Perl exit() para salir del programa, consulta "exit" en perlfunc.
"exp"
Es idéntico a la función incorporada de Perl exp() para devolver la exponencial (base e) del argumento numérico, excepto que POSIX::exp() debe recibir un valor explícito (en lugar de depender de un $_ implícito): 
$exp = POSIX::exp(3);    # correcto
$exp = POSIX::exp();     # lanza excepción

Consulta "exp" en perlfunc.

"expm1"
Equivalente a "exp(x) - 1", pero más preciso para valores de argumento pequeños [C99]. Añadido en Perl v5.22.

Consulta también "log1p".

"fabs"
Es idéntico a la función incorporada de Perl abs() para devolver el valor absoluto del argumento numérico, excepto que POSIX::fabs() debe recibir un valor explícito (en lugar de depender de un $_ implícito): 
$valor_absoluto = POSIX::fabs(3);    # correcto
$valor_absoluto = POSIX::fabs();     # lanza excepción

Consulta "abs" en perlfunc.

"fdopen"
No implementado. Usa el método IO::Handle::new_from_fd() en su lugar, o consulta "open" en perlfunc.
"feof"

"floor"

"POSIX::SigRt"

%SIGRT
Un hash de los manejadores de señales en tiempo real de POSIX. Es una extensión del %SIG estándar, el $POSIX::SIGRT{SIGRTMIN} es aproximadamente equivalente a $SIG{SIGRTMIN}, pero las operaciones de POSIX en tiempo real (ver más abajo) se realizan con "POSIX::SigSet" y "POSIX::sigaction" en lugar de acceder a %SIG.

Puede establecer los elementos de %POSIX::SIGRT para configurar los manejadores de señales en tiempo real de POSIX, utilizar "delete" y "exists" en los elementos, y utilizar "scalar" en %POSIX::SIGRT para saber cuántas señales en tiempo real de POSIX hay disponibles ("SIGRTMAX - SIGRTMIN + 1", "SIGRTMAX" es una señal válida en tiempo real de POSIX).

Establecer los elementos de %SIGRT es equivalente a llamar a esto:

sub new {
  my ($rtsig, $handler, $flags) = @_;
  my $sigset = POSIX::SigSet($rtsig);
  my $sigact = POSIX::SigAction->new($handler,$sigset,$flags);
  sigaction($rtsig, $sigact);
}

Los flags tienen un valor predeterminado de cero; si desea algo diferente, puede usar "local" en $POSIX::SigRt::SIGACTION_FLAGS, o puede derivar de POSIX::SigRt y definir su propio new() (el método STORE del hash enlazado de %SIGRT llama a "new($rtsig, $handler, $SIGACTION_FLAGS)", donde $rtsig varía de cero a "SIGRTMAX - SIGRTMIN + 1)").

Al igual que con cualquier señal, puede usar "sigaction($rtsig, undef, $oa)" para recuperar el manejador de señales instalado (o, más bien, la acción de señal).

NOTA: si las señales en tiempo real de POSIX realmente funcionan en su sistema, o si Perl se ha compilado de manera que funcione con ellas, está fuera de esta discusión.

CAVEATS

Due to the nature of the wait() and waitpid() functions, they can be tricky to use from Perl. The return value is a bitmask, and the macros for decoding it are provided to help with this. Note that the ${^CHILD_ERROR_NATIVE} variable holds the raw value returned by the underlying C call.

On some systems, character classification and conversion functions might depend on the current locale. Use setlocale() to set the locale appropriately.

The strfmon() and wstrfmon() functions are not universally available. Use the have_strfmon() and have_wstrfmon() functions to check for their availability.

The strftime() and wcsftime() functions are not universally available. Use the have_strftime() and have_wcsftime() functions to check for their availability.

"WNOHANG"
Do not suspend the calling process until a child process changes state but instead return immediately.
"WUNTRACED"
Catch stopped child processes.
Macros
"WIFEXITED" "WEXITSTATUS" "WIFSIGNALED" "WTERMSIG" "WIFSTOPPED" "WSTOPSIG"
"WIFEXITED"
WIFEXITED(${^CHILD_ERROR_NATIVE}) returns true if the child process exited normally (exit() or by falling off the end of main())
"WEXITSTATUS"
WEXITSTATUS(${^CHILD_ERROR_NATIVE}) returns the normal exit status of the child process (only meaningful if WIFEXITED(${^CHILD_ERROR_NATIVE}) is true)
"WIFSIGNALED"
WIFSIGNALED(${^CHILD_ERROR_NATIVE}) returns true if the child process terminated because of a signal
"WTERMSIG"
WTERMSIG(${^CHILD_ERROR_NATIVE}) returns the signal the child process terminated for (only meaningful if WIFSIGNALED(${^CHILD_ERROR_NATIVE}) is true)
"WIFSTOPPED"
WIFSTOPPED(${^CHILD_ERROR_NATIVE}) returns true if the child process is currently stopped (can happen only if you specified the WUNTRACED flag to waitpid())
"WSTOPSIG"
WSTOPSIG(${^CHILD_ERROR_NATIVE}) returns the signal the child process was stopped for (only meaningful if WIFSTOPPED(${^CHILD_ERROR_NATIVE}) is true)
