NOMBRE

Pod::Html - módulo para convertir archivos pod a HTML

SINOPSIS

use Pod::Html;
pod2html([opciones]);

DESCRIPCIÓN

Convierte archivos del formato pod (ver perlpod) al formato HTML. Puede generar automáticamente índices y referencias cruzadas, y mantiene una caché de los elementos que sabe cómo referenciar cruzadamente.

FUNCIONES

pod2html

pod2html("pod2html",
         "--podpath=lib:ext:pod:vms",
         "--podroot=/usr/src/perl",
         "--htmlroot=/perl/nmanual",
         "--recurse",
         "--infile=foo.pod",
         "--outfile=/perl/nmanual/foo.html");

pod2html toma los siguientes argumentos:

backlink
--backlink

Convierte cada encabezado "head1" en un enlace de vuelta al principio de la página. Por defecto, no se generan enlaces de retroceso.

cachedir
--cachedir=nombre

Crea la caché de directorios en el directorio dado.

css
--css=hoja-de-estilos

Especifica la URL de una hoja de estilos en cascada. También deshabilita todos los atributos "style" de HTML/CSS que se generan por defecto (para evitar conflictos).

flush
--flush

Vacía la caché de directorios.

header
--header
--noheader

Crea bloques de encabezado y pie de página que contienen el texto de la sección "NAME". Por defecto, no se generan encabezados.

help
--help

Muestra el mensaje de uso.

htmldir
--htmldir=nombre

Establece el directorio al que serán relativos todos los enlaces cruzados en el archivo HTML resultante. No pasar este argumento hace que todos los enlaces sean absolutos, ya que este es el valor que indica a Pod::Html la raíz del árbol de documentación.

No use este argumento y --htmlroot en la misma llamada a pod2html; son mutuamente excluyentes.

htmlroot
--htmlroot=nombre

Establece la URL base para los archivos HTML. Cuando se hacen referencias cruzadas, la raíz HTML se antepone a la URL.

No use este argumento si desea enlaces relativos: use --htmldir en su lugar.

No pase este argumento y --htmldir a pod2html; son mutuamente excluyentes.

index
--index
--noindex

Genera un índice al principio del archivo HTML. Este es el comportamiento por defecto.

infile
--infile=nombre

Especifica el archivo pod a convertir. La entrada se toma de STDIN si no se especifica ningún archivo de entrada.

outfile
--outfile=nombre

Especifica el archivo HTML a crear. La salida va a STDOUT si no se especifica ningún archivo de salida.

poderrors
--poderrors
--nopoderrors

Incluye una sección "ERRORES POD" en el archivo de salida si hubo algún error de POD en el archivo de entrada. Esta sección se incluye por defecto.

podpath
--podpath=nombre:...:nombre

Especifica qué subdirectorios del podroot contienen archivos pod cuyos formularios convertidos a HTML se pueden enlazar en referencias cruzadas.

podroot
--podroot=nombre

Especifica el directorio base para encontrar pods de bibliotecas. El valor por defecto es el directorio de trabajo actual.

quiet
--quiet
--noquiet

No muestre mensajes de advertencia *mayoritariamente inofensivos*. Estos mensajes se mostrarán por defecto. Pero esto no es lo mismo que el modo "verbose".

recurse
--recurse
--norecurse

Recorre recursivamente los subdirectorios especificados en podpath (comportamiento por defecto).

title
--title=título

Especifica el título del archivo HTML resultante.

verbose
--verbose
--noverbose

Muestra mensajes de progreso. Por defecto, no se mostrarán.

Anteriores Funciones Auxiliares Exportadas

Antes de perl-5.36, las siguientes tres funciones eran exportadas por Pod::Html, ya sea por defecto o bajo petición:

  • htmlify() (por defecto)
  • anchorify() (bajo petición)
  • relativize_url() (bajo petición)

La definición y documentación de estas funciones se ha trasladado a Pod::Html::Util, que puede verse a través de "perldoc Pod::Html::Util".

A partir de perl-5.38, estas funciones deben importarse explícitamente desde Pod::Html::Util. Por favor, modifique su código según sea necesario.

ENTORNO

Utiliza $Config{pod2html} para configurar las opciones por defecto.
