POE::Filter::Stackable(3) Documentación de Perl contribuida por el usuario POE::Filter::Stackable(3)

NOMBRE

POE::Filter::Stackable - combina múltiples objetos POE::Filter

SINOPSIS

#!perl
use POE qw(
  Wheel::FollowTail
  Filter::Line Filter::Grep Filter::Stackable
);
POE::Session->create(
  inline_states => {
    _start => sub {
      my $parse_input_as_lines = POE::Filter::Line->new();
      my $select_sudo_log_lines = POE::Filter::Grep->new(
        Put => sub { 1 },
        Get => sub {
          my $input = shift;
          return $input =~ /sudo\[\d+\]/i;
        },
      );
      my $filter_stack = POE::Filter::Stackable->new(
        Filters => [
          $parse_input_as_lines, # último en put, primero en get
          $select_sudo_log_lines, # primero en put, último en get
        ]
      );
      $_[HEAP]{tailor} = POE::Wheel::FollowTail->new(
        Filename => "/var/log/system.log",
        InputEvent => "got_log_line",
        Filter => $filter_stack,
      );
    },
    got_log_line => sub {
      print "Log: $_[ARG0]\n";
    }
  }
);
POE::Kernel->run();
exit;

DESCRIPCIÓN

POE::Filter::Stackable combina múltiples filtros de tal manera que parecen ser un solo filtro. Todos los métodos habituales de POE::Filter funcionan, pero los datos se pasan secretamente a través de los filtros apilados antes de ser devueltos. Los objetos POE::Wheel y los programas independientes no necesitan modificaciones para funcionar con una pila de filtros.

En la "SINOPSIS", POE::Filter::Line y POE::Filter::Grep se combinan en un solo filtro que solo devuelve un tipo particular de línea. Esto puede ser más eficiente que filtrar líneas en el espacio de la aplicación, ya que es posible que se deban despachar y manejar menos eventos.

Internamente, los filtros se almacenan en un array.

Los datos añadidos por get_one_start() fluirán a través del array de filtros en orden de índice creciente. El filtro #0 tendrá la primera oportunidad, seguido por el filtro #1 y así sucesivamente. La llamada a get_one() devolverá un elemento después de que haya pasado por el último filtro.

put() pasa los datos a través de los filtros en orden de índice descendente. Los datos pasarán primero por el filtro con el índice más alto, y put() devolverá los resultados después de que los datos hayan pasado por el filtro #0.

MÉTODOS PÚBLICOS DE FILTRO

Además de los métodos habituales de POE::Filter, POE::Filter::Stackable también soporta lo siguiente.

new

Por defecto, new() crea una pila de filtros vacía que se comporta como POE::Filter::Stream. Puede recibir parámetros opcionales para inicializar la pila con un array de filtros.

my $sudo_lines = POE::Filter::Stackable->new(
  Filters => [
    POE::Filter::Line->new(),
    POE::Filter::Grep->new(
      Put => sub { 1 }, # poner todos los elementos
      Get => sub { shift() =~ /sudo\[\d+\]/i },
    ),
  ]
);

pop

Se comporta como el pop() incorporado de Perl para la pila de filtros. El filtro con el índice más alto se elimina de la pila y se devuelve. Cualquier dato que quede en el búfer de entrada del filtro se pierde, pero una aplicación siempre puede llamar a "get_pending" en POE::Filter en el filtro devuelto.

my $last_filter = $stackable->pop();
my $last_buffer = $last_filter->get_pending();

shift

Se comporta como el shift() incorporado de Perl para la pila de filtros. El filtro 0 se elimina de la pila y se devuelve. Cualquier dato que quede en el búfer de entrada del filtro se pasa al nuevo primer elemento de la pila, o se pierde si la pila queda vacía. Una aplicación también puede llamar a "get_pending" en POE::Filter en el filtro devuelto para examinar el búfer de entrada del filtro.

my $first_filter = $stackable->shift();
my $first_buffer = $first_filter->get_pending();

push FILTRO[, FILTRO]

push() añade uno o más FILTROs nuevos al final de la pila. Los FILTROs recién añadidos procesarán la entrada en último lugar y manejarán la salida en primer lugar.

# Invertir datos leídos a través de la pila.
# Codificar rot13 los datos enviados a través de la pila.
$stackable->push(
  POE::Filter::Map->(
    Get => sub { return scalar reverse shift() },
    Put => sub { local $_ = shift(); tr[a-zA-Z][n-za-mN-ZA-M]; $_ },
  )
);

unshift FILTRO[, FILTRO]

unshift() añade uno o más FILTROs nuevos al principio de la pila. Los FILTROs recién añadidos procesarán la entrada en primer lugar y manejarán la salida en último lugar.

filters

filters() devuelve una lista de los filtros dentro del filtro Stackable, en el orden nativo de la pila.

Llamar a "$filter_stack->filters()" en la "SINOPSIS" devolvería una lista de dos objetos filtro:

POE::Filter::Line=ARRAY(0x8b5ee0)
POE::Filter::Grep=ARRAY(0x8b5f7c)

filter_types

filter_types() devuelve una lista de nombres de clase para cada filtro en la pila, en el orden nativo de la pila.

Llamar a "$filter_stack->filter_types()" en la "SINOPSIS" devolvería una lista de dos nombres de clase:

POE::FIlter::Line
POE::Filter::Grep

Podría ser fácilmente reemplazado por:

my @filter_types = map { ref } $filter_stack->filters;
