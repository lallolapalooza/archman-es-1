Pod::Coverage(3) Documentación de Perl proporcionada por el usuario Pod::Coverage(3)

NOMBRE

Pod::Coverage - Verifica si la documentación de un módulo es completa

SINOPSIS

# Al principio...
perl -MPod::Coverage=Pod::Coverage -e666
# todo en una invocación
use Pod::Coverage package => 'Fishy';
# estilo OO
use Pod::Coverage;
my $pc = Pod::Coverage->new(package => 'Pod::Coverage');
print "¡Lo petamos!" if $pc->coverage == 1;

DESCRIPCIÓN

A los desarrolladores no les gusta escribir documentación. Les gusta aún menos cuando su computadora se lo recuerda, pero tal vez se lo agradezcan a largo plazo. Si no, perlmodstyle les dice que deben hacerlo, así que deben obedecer.

Este módulo proporciona una herramienta para determinar si la documentación de un módulo es completa.

Espera encontrar un bloque "=head(n>1)" o "=item" que documente una subrutina.

Considera:


# un ejemplo de Foo.pm
package Foo;
=item foo La subrutina foo = cut sub foo {} sub bar {} 1;
__END__

En este ejemplo, "Foo::foo" está cubierto, pero "Foo::bar" no lo está, por lo que el módulo "Foo" está cubierto solo al 50% (0.5).

Métodos

Pod::Coverage->new(package => $package)
Crea un nuevo objeto Pod::Coverage.

"package" el nombre del paquete a analizar

"private" un array de expresiones regulares que definen qué símbolos se consideran privados (y por lo tanto no deben documentarse) por defecto [ qr/^_/, qr/^(un)?import$/, qr/^DESTROY$/, qr/^AUTOLOAD$/, qr/^bootstrap$/,
qr/^(TIE( SCALAR | ARRAY | HASH | HANDLE ) |
FETCH | STORE | UNTIE | FETCHSIZE | STORESIZE |
POP | PUSH | SHIFT | UNSHIFT | SPLICE | DELETE |
EXISTS | EXTEND | CLEAR | FIRSTKEY | NEXTKEY | PRINT | PRINTF |
WRITE | READLINE | GETC | READ | CLOSE | BINMODE | OPEN |
EOF | FILENO | SEEK | TELL | SCALAR )$/x,
qr/^( MODIFY | FETCH )_( REF | SCALAR | ARRAY | HASH | CODE |
GLOB | FORMAT | IO )_ATTRIBUTES$/x,
qr/^CLONE(_SKIP)?$/, ]

Esto debería cubrir todos los métodos mágicos típicos de objetos tie(), atributos, generalmente todos los métodos que no son llamados por un usuario, sino que son utilizados internamente por perl.

"also_private" los elementos se agregan al array de privados.

"trustme" un array de expresiones regulares que definen qué símbolos quieres que se asuman documentados correctamente, incluso si no puedes encontrar ninguno.

Si se proporciona "pod_from", entonces se analiza el archivo para obtener la documentación, en lugar de usar Pod::Find.

Si se proporciona "nonwhitespace", entonces solo se cuentan las secciones de documentación que tienen caracteres no blancos.

object->coverage
Devuelve el porcentaje de cobertura como un valor en el rango de 0 a 1.
object->why_unrated
"$object->coverage" puede devolver "undef", indicando que no se pudo determinar la cobertura para un paquete. Si esto ocurre, deberías poder comprobar "why_unrated" para obtener una excusa útil.
object->naked/$object->uncovered
Devuelve una lista de subrutinas no cubiertas, llamará a la cobertura si aún no se ha llamado. Nota: los símbolos privados y los símbolos 'trustme' se omitirán.
object->covered
Devuelve una lista de subrutinas cubiertas, llamará a la cobertura si aún no se ha llamado. Nota: los símbolos privados y los símbolos 'trustme' se omitirán.

Soporte de depuración

Para permitir la depuración interna, mientras que el optimizador puede hacer su trabajo, "Pod::Coverage" utiliza subrutinas constantes para definir cómo se rastrea.

Úsalo así:

sub Pod::Coverage::TRACE_ALL () { 1 }
use Pod::Coverage;

Las constantes soportadas son:

TRACE_ALL
Rastrea todo. Bueno, ¿eso es todo? ¿Gracias por venir?

Interfaz de herencia

Estos métodos abstractos, aunque funcionales en "Pod::Coverage", pueden hacer tu vida más fácil si quieres heredar de "Pod::Coverage" para adaptarte a tu estilo doméstico.

NOTA Considera esta interfaz como en estado de evolución hasta que esta notificación sea eliminada.

object->_CvGV($symbol)
Devuelve el GV para el coderef proporcionado. Utilizado por "_get_syms" para identificar el código definido localmente.

Aunque probablemente no lo vayas a reescribir.

object->_get_syms($package)
Devuelve una lista de símbolos a verificar del paquete especificado.
_get_pods
Extrae marcas de documentación del paquete actual.

Devuelve un arrayref o undef en caso de fallo.

_private_check($symbol)
Devuelve verdadero si el símbolo debe considerarse privado.
_trustme_check($symbol)
Devuelve verdadero si el símbolo es un símbolo 'trustme'

ERRORES

Dado el método utilizado para identificar subrutinas documentadas, "Pod::Coverage" puede ignorar completamente tu estilo de codificación y declarar tu código como no documentado. ¡Los pacientes, los parches o las pruebas que falten son bienvenidos!
