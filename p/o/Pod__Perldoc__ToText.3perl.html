Pod::Perldoc::ToText(3perl) Guía de referencia del programador de Perl Pod::Perldoc::ToText(3perl)

NOMBRE

Pod::Perldoc::ToText - permite a Perldoc renderizar Pod como texto plano

SINOPSIS

perldoc -o text Nombre::De::Módulo

DESCRIPCIÓN

Esta es una clase "complementaria" que permite a Perldoc usar Pod::Text como clase formateadora.

Soporta las siguientes opciones, que se explican en Pod::Text: alt, indent, loose, quotes, sentence, width

Por ejemplo:

perldoc -o text -w indent:5 Nombre::De::Módulo

ADVERTENCIA

Este módulo puede cambiar para usar una clase formateadora de texto diferente en el futuro, y esto puede cambiar qué opciones son soportadas.

VER TAMBIÉN

Pod::Text, Pod::Perldoc
