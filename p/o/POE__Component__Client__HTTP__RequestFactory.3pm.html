POE::Component::Client::HTTP::RequestFactory(3) Documentación de Perl contribuida por el usuario POE::Component::Client::HTTP::RequestFactory(3)

NOMBRE

POE::Component::Client::HTTP::RequestFactory - un objeto fábrica de solicitudes HTTP

VERSIÓN

versión 0.949

SINOPSIS

# Usado internamente por POE::Component::Client::HTTP

CONSTRUCTOR

new

Crea un nuevo objeto fábrica de solicitudes. Espera sus parámetros en un hashref.

Se aceptan los siguientes parámetros. Se explican en detalle en POE::Component::Client::HTTP.

  • Agent
  • MaxSize
  • Streaming
  • Protocol
  • From
  • CookieJar
  • NoProxy
  • Proxy
  • FollowRedirects
  • Timeout

MÉTODOS

timeout [$timeout]

Método que le permite consultar y/o cambiar el valor de tiempo de espera para las solicitudes creadas por esta fábrica.

is_streaming

Accesorio para el parámetro Streaming

agent

Accesorio para el parámetro Agent

from

getter/setter para el parámetro From

create_request

Crea una nueva POE::Component::Client::HTTP::Request

max_response_size

Método para recuperar el tamaño máximo de una respuesta, tal como se establece mediante el parámetro "MaxSize" del método spawn() de Client::HTTP.

block_size

Accesorio para el parámetro Streaming

frob_cookies $response

Almacena las cookies del parámetro HTTP::Response pasado a nuestro almacén de cookies

max_redirect_count [$count]

Función para obtener/establecer el número máximo de redireccionamientos a seguir automáticamente. Esto le permite recuperar o modificar el valor que pasó con el parámetro FollowRedirects al método "spawn" de Client::HTTP.

parse_proxy $proxy

Este método estático se utiliza para analizar proxies. El $proxy puede ser una referencia de matriz como [host, puerto] o una cadena separada por comas como "http://1.2.3.4:80/,http://2.3.4.5:80/".

parse_proxy() devuelve una referencia de matriz de tuplas de dos elementos (también referencias de matriz), cada una que contiene un host y un puerto:

[ [ host1, puerto1 ],
  [ host2, puerto2 ],
  ...
]
