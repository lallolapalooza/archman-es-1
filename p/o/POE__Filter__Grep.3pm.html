POE::Filter::Grep(3) Documentación de Perl aportada por el usuario POE::Filter::Grep(3)

NOMBRE

POE::Filter::Grep - seleccionar o eliminar elementos basándose en reglas simples

SINOPSIS

#!perl
use POE qw(
  Wheel::FollowTail
  Filter::Line Filter::Grep Filter::Stackable
);
POE::Session->create(
  inline_states => {
    _start => sub {
      my $parse_input_as_lines = POE::Filter::Line->new();
      my $select_sudo_log_lines = POE::Filter::Grep->new(
        Put => sub { 1 },
        Get => sub {
          my $input = shift;
          return $input =~ /sudo\[\d+\]/i;
        },
      );
      my $filter_stack = POE::Filter::Stackable->new(
        Filters => [
          $parse_input_as_lines, # primero en get, último en put
          $select_sudo_log_lines, # primero en put, último en get
        ]
      );
      $_[HEAP]{tailor} = POE::Wheel::FollowTail->new(
        Filename => "/var/log/system.log",
        InputEvent => "got_log_line",
        Filter => $filter_stack,
      );
    },
    got_log_line => sub {
      print "Log: $_[ARG0]\n";
    }
  }
);
POE::Kernel->run();
exit;

DESCRIPCIÓN

POE::Filter::Grep selecciona o elimina elementos basándose en pruebas simples. Puede ser utilizado para filtrar la entrada, la salida o ambas. Este filtro se nombra y modela según la función incorporada grep() de Perl.

POE::Filter::Grep está diseñado para ser combinado con otros filtros a través de POE::Filter::Stackable. En el ejemplo de "SINOPSIS", se crea una pila de filtros para analizar registros como líneas y eliminar todas las entradas que no pertenezcan a un proceso sudo. (O si su vaso está medio lleno, la pila solo selecciona las entradas que SÍ mencionan sudo).

MÉTODOS PÚBLICOS DEL FILTRO

Además de los métodos habituales de POE::Filter, POE::Filter::Grep también soporta lo siguiente.

new

new() construye un nuevo objeto POE::Filter::Grep. Debe ser llamado con un solo parámetro de Código, o con parámetros de Salida y Entrada. Los valores para Código, Salida y Entrada son referencias de código que, al ser invocadas, devuelven verdadero para seleccionar un elemento o falso para rechazarlo. Una función de Código se usará tanto para entrada como para salida, mientras que las funciones de Entrada y Salida permiten que la entrada y salida sean filtradas de diferentes maneras. El elemento en cuestión se pasará como el único parámetro de la función.

sub reject_bidoofs {
  my $pokemon = shift;
  return 1 if $pokemon ne "bidoof";
  return;
}
my $gotta_catch_nearly_all = POE::Filter::Grep->new(
  Code => \&reject_bidoofs,
);

Forzar comportamiento de solo lectura:

my $read_only = POE::Filter::Grep->new(
  Get => sub { 1 },
  Put => sub { 0 },
);

modify

modify() cambia el comportamiento de un objeto POE::Filter::Grep en tiempo de ejecución. Acepta los mismos parámetros que new() y reemplaza las pruebas existentes por unas nuevas.

# No regalar nuestros Dialgas.
$gotta_catch_nearly_all->modify(
  Get => sub { 1 },
  Put => sub { return shift() ne "dialga" },
);
