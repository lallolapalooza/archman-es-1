NOMBRE

Pod::Find - encontrar documentos POD en árboles de directorios

SINOPSIS

use Pod::Find qw(pod_find simplify_name);
my %pods = pod_find({ -verbose => 1, -inc => 1 });
foreach(keys %pods) {
   print "encontrado POD de librería `$pods{$_}' en $_\n";
}
print "nombre_pod=",simplify_name('a/b/c/mymodule.pod'),"\n";
$location = pod_where( { -inc => 1 }, "Pod::Find" );

DESCRIPCIÓN

NOTA: Este módulo se considera obsoleto; las versiones modernas de Perl (5.31.1 y anteriores) eliminarán Pod-Parser del núcleo y usarán Pod::Simple para todas las cuestiones relacionadas con POD.

Pod::Find proporciona un conjunto de funciones para localizar archivos POD. Tenga en cuenta que ninguna función se exporta por defecto para evitar la contaminación de su espacio de nombres, así que asegúrese de especificarlas en la declaración use si las necesita:

use Pod::Find qw(pod_find);

A partir de esta versión se ignoran los directorios típicos de SCM (gestión de configuración de software). Estos son: RCS, CVS, SCCS, .svn, .hg, .git, .sync

"pod_find( { %opts } , @directorios )"

La función pod_find busca documentos POD en un conjunto dado de archivos y/o directorios. Devuelve un hash con los nombres de archivo como claves y el nombre del POD como valor. El nombre del POD se deriva del nombre del archivo y su posición en el árbol de directorios.

Por ejemplo, al buscar en $HOME/perl5lib, el archivo $HOME/perl5lib/MyModule.pm obtendría el nombre de POD MyModule, mientras que $HOME/perl5lib/Myclass/Subclass.pm sería Myclass::Subclass. La información del nombre se puede usar para traductores de POD.

Solo se encuentran archivos de texto que contienen al menos un comando POD válido.

Se imprime una advertencia si se encuentra más de un archivo POD con el mismo nombre de POD, por ejemplo, CPAN.pm en diferentes directorios. Esto generalmente indica ocurrencias duplicadas de módulos en la ruta de búsqueda de @INC.

OPCIONES El primer argumento para pod_find puede ser una referencia a un hash con opciones. Los restantes son directorios que se buscan recursivamente o archivos. Los nombres POD de los archivos son los nombres base simples con cualquier extensión similar a Perl (.pm, .pl, .pod) eliminada.

"-verbose => 1"
Imprimir información de progreso mientras se escanea.
"-perl => 1"
Aplicar heurísticas específicas de Perl para encontrar los POD correctos. Esto incluye eliminar extensiones similares a Perl, omitir subdirectorios que son numéricos pero *no* coinciden con el identificador de versión del intérprete de Perl actual, suprimir site_perl como nombre de jerarquía de módulo, etc.
"-script => 1"
Buscar PODs en el scriptdir de instalación del intérprete de Perl actual. Esto se toma del módulo Config local.
"-inc => 1"
Buscar PODs en las rutas @INC del intérprete de Perl actual. Esto considera automáticamente las rutas especificadas en el entorno "PERL5LIB" ya que estas son incluidas en @INC por el propio intérprete de Perl.

simplify_name( $str )

La función simplify_name es equivalente a basename, pero también elimina extensiones similares a Perl (.pm, .pl, .pod) y extensiones como .bat, .cmd en Win32 y OS/2, o .com en VMS, respectivamente.

"pod_where( { %opts }, $pod )"

Devuelve la ubicación de un documento pod dado un directorio de búsqueda y un nombre de módulo (ej. "File::Find") o script (ej. "perldoc").

Opciones:

"-inc => 1"
Buscar en @INC el pod y también el "scriptdir" definido en el módulo Config.
"-dirs => [ $dir1, $dir2, ... ]"
Referencia a un array de directorios de búsqueda. Estos se buscan en orden antes de buscar en @INC (si es -inc). Se usa el directorio actual si no se especifica ninguno.
"-verbose => 1"
Listar directorios a medida que se buscan.

Devuelve la ruta completa de la primera ocurrencia del archivo. Los nombres de paquete (ej. 'A::B') se convierten automáticamente en nombres de directorio en el directorio seleccionado. (ej. en unix 'A::B' se convierte en 'A/B'). Además, se les añade '.pm', '.pl' y '.pod' automáticamente a la búsqueda si es necesario.

También se comprueba un subdirectorio pod/ si existe en alguno de los directorios de búsqueda dados. Esto asegura que se encuentre, por ejemplo, perlfunc.

Se asume que si se proporciona un nombre de módulo, ese nombre coincide con el nombre del archivo. Los POD no se abren para comprobar la entrada 'NAME'.

Se realiza una comprobación para asegurarse de que el archivo que se encuentra contiene alguna documentación pod.

"contains_pod( $file , $verbose )"

Devuelve verdadero si el nombre de archivo proporcionado (no el módulo POD) contiene alguna información pod.
