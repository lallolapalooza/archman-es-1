NOMBRE

Pod::Simple::RTF -- formatea Pod como RTF

SINOPSIS

perl -MPod::Simple::RTF -e \
 "exit Pod::Simple::RTF->filter(shift)->any_errata_seen" \
 thingy.pod > thingy.rtf

DESCRIPCIÓN

Esta clase es un formateador que toma Pod y lo renderiza como RTF, útil para ver/imprimir en MSWord, WordPad/write.exe, TextEdit, etc.

Esta es una subclase de Pod::Simple y hereda todos sus métodos.

ATRIBUTOS DE CONTROL DE FORMATO

Puedes establecer estos atributos en el objeto analizador antes de llamar a "parse_file" (o un método similar) en él:

$parser->head1_halfpoint_size( tamaño_en_medio_puntos_entero );
$parser->head2_halfpoint_size( tamaño_en_medio_puntos_entero );
$parser->head3_halfpoint_size( tamaño_en_medio_puntos_entero );
$parser->head4_halfpoint_size( tamaño_en_medio_puntos_entero );
Estos métodos establecen el tamaño (en medio puntos, como 52 para 26 puntos) que tendrán estos niveles de encabezado.
$parser->codeblock_halfpoint_size( tamaño_en_medio_puntos_entero );
Este método establece el tamaño (en medio puntos, como 21 para 10.5 puntos) que tendrán los bloques de código (secciones de texto sin formato).
$parser->header_halfpoint_size( tamaño_en_medio_puntos_entero );
Este método establece el tamaño (en medio puntos, como 15 para 7.5 puntos) que tendrá el encabezado en cada página. El encabezado es generalmente solo "nombre_modulo p. número_página".
$parser->normal_halfpoint_size( tamaño_en_medio_puntos_entero );
Este método establece el tamaño (en medio puntos, como 26 para 13 puntos) que tendrá el texto normal en párrafos.
$parser->no_proofing_exemptions( verdadero_o_falso );
Establece este valor a verdadero si no quieres que el formateador intente poner un código oculto en todos los símbolos de Perl (en la medida de lo posible) que los etiquete como que no están en inglés, y por lo tanto no valen la pena de revisar la ortografía.
$parser->doc_lang( código_decimal_de_idioma_de_microsoft )
Esto establece el código de idioma para etiquetar este documento. Por defecto, es el valor de la variable de entorno "RTFDEFLANG", o si no está establecida, entonces el valor 1033 (para inglés de EE. UU.).

Establecer esto apropiadamente es útil si quieres usar el RTF para corregir la ortografía, y/o si quieres que justifique el texto correctamente.

Aquí hay algunos valores notables:

1033  Inglés de EE. UU.
2057  Inglés del Reino Unido
3081  Inglés de Australia
4105  Inglés de Canadá
1034  Español de España
2058  Español de México
1031  Alemán de Alemania
1036  Francés de Francia
3084  Francés de Canadá
1035  Finlandés
1044  Noruego (Bokmal)
2068  Noruego (Nynorsk)

Si estás particularmente interesado en personalizar aún más la salida de este módulo, consulta el código fuente y/o escríbeme.
