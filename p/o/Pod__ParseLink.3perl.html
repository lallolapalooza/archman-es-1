Pod::ParseLink(3perl) Guía de referencia del programador de Perl Pod::ParseLink(3perl)

NOMBRE

Pod::ParseLink - Analiza un código de formato L<> en texto POD

SINOPSIS

use Pod::ParseLink;
my $link = get_link();
my ($text, $inferred, $name, $section, $type) = parselink($link);

DESCRIPCIÓN

Este módulo solo proporciona una función, parselink(), que toma el texto de un código de formato L<> y lo analiza. Devuelve el texto del ancla para el enlace (si se proporcionó alguno), el texto del ancla posiblemente inferido del nombre y la sección, el nombre o la URL, la sección si la hay, y el tipo de enlace. El tipo será uno de "url", "pod", o "man", indicando una URL, un enlace a una página POD o un enlace a una página de manual de Unix.

El análisis se implementa según perlpodspec. Por compatibilidad con versiones anteriores, los enlaces en los que no hay sección y el nombre contiene espacios, o los enlaces en los que la totalidad del enlace (excepto el texto del ancla si se proporciona) está encerrado entre comillas dobles, se interpretan como enlaces a una sección (L</section>).

El texto del ancla inferido se implementa según perlpodspec:

L<name>         =>  L<name|name>
L</section>     =>  L<"section"|/section>
L<name/section> =>  L<"section" in name|name/section>

El nombre puede contener códigos de formato E<> y Z<> incrustados, y la sección, el texto del ancla y el texto del ancla inferido pueden contener cualquier código de formato. Las comillas dobles alrededor de la sección se eliminan como parte del análisis, al igual que cualquier espacio en blanco inicial o final.

Si el texto del escape L<> está completamente entre comillas dobles, se interpreta como un enlace a una sección por compatibilidad con versiones anteriores.

No se intenta resolver los códigos de formato. Esto debe hacerse después de llamar a parselink() (ya que los códigos de formato E<> se pueden usar para escapar caracteres que de otro modo serían significativos para el analizador y la resolución de estos antes del análisis resultaría en un análisis incorrecto de un código de formato como:

L<verticalE<verbar>barE<sol>slash>

que debe interpretarse como un enlace a la página POD "vertical|bar/slash" y no como un enlace a la sección "slash" de la página POD "bar" con un texto de ancla de "vertical". Tenga en cuenta que no solo el texto del ancla necesitará tener los códigos de formato expandidos, sino también el destino del enlace (para tratar con los códigos de formato E<> y Z<>), y puede ser necesario un manejo especial de la sección dependiendo de si el traductor desea considerar el marcado en las secciones como significativo al resolver enlaces. Consulte perlpodspec para obtener más información.
