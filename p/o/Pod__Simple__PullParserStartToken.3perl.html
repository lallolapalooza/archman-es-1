Pod::Simple::PullParserStartToken(3perl) Guía de programación de Perl Pod::Simple::PullParserStartToken(3perl)

NOMBRE

Pod::Simple::PullParserStartToken -- tokens de inicio de Pod::Simple::PullParser

SINOPSIS

(Véase Pod::Simple::PullParser)

DESCRIPCIÓN

Cuando ejecutas $parser->get_token en un objeto Pod::Simple::PullParser, podrías obtener un objeto de esta clase.

Esta es una subclase de Pod::Simple::PullParserToken y hereda todos sus métodos, y añade estos métodos:

$token->tagname
Esto devuelve el nombre de etiqueta para este objeto de token de inicio. Por ejemplo, analizar una línea "=head1 ..." te dará un token de inicio con el nombre de etiqueta "head1", token(s) para su contenido y luego un token de fin con el nombre de etiqueta "head1".
$token->tagname(alguna_cadena)
Esto cambia el nombre de etiqueta para este objeto de token de inicio. Probablemente no necesitarás hacer esto.
$token->tag(...)
Un atajo para $token->tagname(...)
$token->is_tag(alguna_cadena) o $token->is_tagname(alguna_cadena)
Estos son atajos para "$token->tag() eq alguna_cadena"
$token->attr(nombre_atributo)
Esto devuelve el valor del atributo nombre_atributo para este objeto de token de inicio, o undef.

Por ejemplo, analizar un enlace L<Foo/"Bar"> producirá un token de inicio con un atributo "to" con el valor "Foo", un atributo "type" con el valor "pod", y un atributo "section" con el valor "Bar".

$token->attr(nombre_atributo, nuevo_valor)
Esto establece el atributo nombre_atributo para este objeto de token de inicio a nuevo_valor. Probablemente no necesitarás hacer esto.
$token->attr_hash
Esto devuelve el hashref que es el conjunto de atributos para este token de inicio. Esto es útil si (por ejemplo) quieres preguntar cuáles son todos los atributos -- puedes simplemente hacer "keys %{$token->attr_hash}"

Es poco probable que necesites construir un objeto de esta clase para ti mismo, pero si quieres hacerlo, llama "Pod::Simple::PullParserStartToken->new( nombre_etiqueta, hash_atributos )"
