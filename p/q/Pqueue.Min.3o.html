Colas de prioridad mínimas

type t

El tipo de colas de prioridad.

type elt

El tipo de elementos de la cola de prioridad.

val create : unit -> t

Devuelve una nueva cola de prioridad, inicialmente vacía.

val length : t -> int

Devuelve el número de elementos en una cola de prioridad.

val is_empty : t -> bool

is_empty q es true si y solo si q está vacía, es decir, si y solo si length q = 0.

val add : t -> elt -> unit

add q x añade el elemento x a la cola de prioridad q.

val add_iter : t -> ((elt -> unit) -> 'x -> unit) -> 'x -> unit

add_iter q iter x añade cada elemento de x al final de q. Esto es iter (add q) x.

val min_elt : t -> elt option

min_elt q es un elemento de q con prioridad mínima o None si la cola está vacía. La cola no se modifica.

val get_min_elt : t -> elt

get_min_elt q devuelve un elemento de q con prioridad mínima, o lanza Invalid_argument si la cola está vacía. La cola no se modifica.

val pop_min : t -> elt option

pop_min q elimina y devuelve un elemento de la cola q con prioridad mínima, o devuelve None si la cola está vacía.

val remove_min : t -> unit

remove_min q elimina un elemento de la cola q con prioridad mínima. No hace nada si q está vacía.

val clear : t -> unit

clear q elimina todos los elementos de q.

val copy : t -> t

copy q es una nueva cola de prioridad con los mismos elementos que q.

Conversiones de otras estructuras de datos

val of_array : elt array -> t

of_array a devuelve una nueva cola de prioridad que contiene los elementos del array a. Se ejecuta en tiempo lineal.

val of_list : elt list -> t

of_list l devuelve una nueva cola de prioridad que contiene los elementos de la lista l. Se ejecuta en tiempo lineal.

val of_iter : ((elt -> unit) -> 'x -> unit) -> 'x -> t

of_iter iter x devuelve una nueva cola de prioridad que contiene los elementos de x, obtenidos de iter.

Por ejemplo, of_iter Seq.iter s devuelve una nueva cola de prioridad que contiene todos los elementos de la secuencia s (siempre que sea finita).

Se ejecuta en tiempo lineal (excluyendo el tiempo dedicado a iter).

Iteración

El orden en que se recorren los elementos de una cola de prioridad no está especificado.

Mutar una cola de prioridad (añadiendo o eliminando elementos) durante una iteración de la cola es un error de programación. Dicho error puede ser detectado y señalado por la implementación del array dinámico subyacente, pero esto no está garantizado.

val iter_unordered : (elt -> unit) -> t -> unit

iter_unordered f q aplica f a todos los elementos de q. El orden en que se pasan los elementos a f no está especificado.

El comportamiento no está especificado si la cola de prioridad es modificada por f durante la iteración.

val fold_unordered : ('acc -> elt -> 'acc) -> 'acc -> t -> 'acc

fold_unordered f accu q es (f (... (f (f accu x1) x2) ...)
xn) donde x1,x2,...,xn son los elementos de q. El orden en que se pasan los elementos a f no está especificado.

El comportamiento no está especificado si la cola de prioridad es modificada por f durante la iteración.
