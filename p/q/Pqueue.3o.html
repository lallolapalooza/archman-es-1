Colas de prioridad.

El módulo Pqueue implementa una estructura de datos de colas de prioridad, dado un tipo totalmente ordenado para los elementos. Esta es una estructura de datos mutable. Se proporcionan tanto colas de prioridad mínimas como máximas.

La implementación utiliza un heap almacenado en un array dinámico, y por lo tanto es razonablemente eficiente: acceder al elemento mínimo (resp. máximo) toma tiempo constante, y la inserción y eliminación toman tiempo logarítmico en el tamaño de la cola de prioridad. Tenga en cuenta que of_array se ejecuta en tiempo lineal (y por lo tanto debe preferirse a inserciones repetidas con add).

Está bien tener varios elementos con la misma prioridad. No se garantiza nada con respecto al orden en que serán extraídos. Sin embargo, se garantiza que el elemento devuelto por min_elt (o get_min_elt ) es el que se elimina de la cola de prioridad por pop_min (o remove_min ). Esto es importante en muchos algoritmos (por ejemplo, al examinar varias colas de prioridad y luego seleccionar una para eliminar).

Colas de prioridad polimórficas

Los siguientes functores, más complejos, crean colas polimórficas de tipo 'a t , al igual que otros contenedores polimórficos (listas, arrays...). Requieren una noción de "elementos polimórficos" 'a
elt que pueden compararse sin depender de los valores de 'a.

Un escenario de uso es cuando el usuario desea pasar prioridades separadamente del valor almacenado en la cola. Esto se hace utilizando pares prioridad * 'a como elementos.

      module Prio : OrderedType = ...
      module PrioQueue = Pqueue.MakeMinPoly(struct
        type 'a t = Prio.t * 'a
        let compare (p1, _) (p2, _) = Prio.compare p1 p2
      end)
      (* por ejemplo, ahora tenemos: *)
      PrioQueue.add: 'a PrioQueue.t -> Prio.t * 'a -> unit
      PrioQueue.min_elt: 'a PrioQueue.t -> (Prio.t * 'a) option
