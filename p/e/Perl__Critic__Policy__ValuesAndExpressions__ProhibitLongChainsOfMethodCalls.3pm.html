Perl::Critic::Policy::ValuesAndExpressions::ProhibitLongChainsOfMethodCalls(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ValuesAndExpressions::ProhibitLongChainsOfMethodCalls(3pm)

NOMBRE

Perl::Critic::Policy::ValuesAndExpressions::ProhibitLongChainsOfMethodCalls - Las cadenas largas de llamadas a métodos indican código estrechamente acoplado.

AFILIACIÓN

Esta Política es parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Una cadena larga de llamadas a métodos generalmente indica que el código sabe demasiado sobre las interrelaciones entre objetos. Si el código es capaz de navegar directamente a través de una red de objetos, entonces cuando la red cambie de estructura en el futuro, el código deberá ser modificado para lidiar con el cambio. El código está demasiado estrechamente acoplado y es frágil.

$x = $y->a;           # ok
$x = $y->a->b;        # ok
$x = $y->a->b->c;     # cuestionable, pero permitido por defecto
$x = $y->a->b->c->d;  # no ok

CONFIGURACIÓN

Esta política tiene una opción: "max_chain_length" que controla hasta dónde se permite que el código navegue. El valor predeterminado es 3.

POR HACER

Agregar una opción "class_method_exemptions" para permitir cosas como

File::Find::Rule
    ->name('*.blah')
    ->not_name('thingy')
    ->readable()
    ->directory()
    ->in(@roots);
