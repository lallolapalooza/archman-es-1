Perl::Critic::Policy::ErrorHandling::RequireCarping(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ErrorHandling::RequireCarping(3pm)

NOMBRE

Perl::Critic::Policy::ErrorHandling::RequireCarping - Usa funciones de Carp en lugar de "warn" o "die".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Las funciones "die" y "warn" reportan tanto el archivo como el número de línea donde ocurrió la excepción. Pero si alguien más está usando tu subrutina, generalmente no le importa dónde explotó tu código. En cambio, quieren saber dónde su código invocó la subrutina. El módulo Carp proporciona métodos alternativos que reportan la excepción desde el archivo y número de línea del llamador.

Por defecto, esta política no se quejará de "die" o "warn" si puede determinar que el mensaje siempre resultará en una nueva línea en la terminal. Dado que perl suprime los nombres de archivo y números de línea en esta situación, se asume que tampoco se desean rastreos de pila y que ninguna de las funciones de Carp es necesaria.

die "oops" if $explosion;             # no es correcto
warn "Where? Where?!" if $tiger;      # no es correcto
open my $mouth, '<', 'food'
    or die 'of starvation';           # no es correcto
if (! $dentist_appointment) {
    warn "You have bad breath!\n";    # correcto
}
die "$clock not set.\n" if $no_time;  # correcto
my $message = "$clock not set.\n";
die $message if $no_time;             # no es correcto, no es obvio

CONFIGURACIÓN

Por defecto, esta política permite el uso de "die" y "warn" que terminan en una nueva línea explícita. Si le das a esta política una opción "allow_messages_ending_with_newlines" en tu archivo .perlcriticrc con un valor falso, entonces esta política prohibirá tales usos.

[ErrorHandling::RequireCarping]
allow_messages_ending_with_newlines = 0

Si le das a esta política una opción "allow_in_main_unless_in_subroutine" en tu archivo .perlcriticrc con un valor verdadero, entonces esta política permitirá "die" y "warn" en el espacio de nombres main:: a menos que aparezcan en una subrutina, incluso si no terminan en una nueva línea explícita.

[ErrorHandling::RequireCarping]
allow_in_main_unless_in_subroutine = 1

ERRORES

Debería permitir "die" cuando sea obvio que el "mensaje" es una referencia.

VER TAMBIÉN

Carp::Always
