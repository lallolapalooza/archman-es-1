Perl__Critic__Policy__ControlStructures__ProhibitPostfixControls(3pm)

Paquete: perl-perl-critic

Licencias: PerlArtistic

Perl::Critic::Policy::ControlStructures::ProhibitPostfixControls(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ControlStructures::ProhibitPostfixControls(3pm)

NOMBRE

Perl::Critic::Policy::ControlStructures::ProhibitPostfixControls - Escribe "if($condicion){ hacer_algo() }" en lugar de "hacer_algo() if $condicion".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Conway desaconseja el uso de estructuras de control postfix ("if", "for", "unless", "until", "when", "while") porque ocultan el flujo de control. Los controles "unless" y "until" son particularmente malvados porque llevan a dobles negaciones que son difíciles de comprender. El único uso tolerable de un postfix "if"/"when" es cuando sigue a una interrupción de bucle como "last", "next", "redo", o "continue".

hacer_algo() if $condicion;           # no está bien
if ($condicion) { hacer_algo() }      # está bien
hacer_algo() while $condicion;        # no está bien
while ($condicion) { hacer_algo() }   # está bien
hacer_algo() unless $condicion;       # no está bien
hacer_algo() unless ! $condicion;     # muy mal
if (! $condicion) { hacer_algo() }    # está bien
hacer_algo() until $condicion;        # no está bien
hacer_algo() until ! $condicion;      # muy mal
while (! $condicion) { hacer_algo() } # está bien
hacer_algo($_) for @lista;             # no está bien
LOOP:
for my $n (0..100) {
    next if $condicion;                 # está bien
    last LOOP if $otra_condicion;      # también está bien
    next when m< 0 \z >xms;             # también está bien
}

CONFIGURACIÓN

Se puede especificar un conjunto de construcciones a ignorar por esta política asignando un valor a 'allow' de una cadena de palabras clave separadas por espacios: "if", "for", "unless", "until", "when", y/o "while". Un ejemplo de especificación de estructuras de control permitidas en un archivo .perlcriticrc:

[ControlStructures::ProhibitPostfixControls]
allow = for if until

Por defecto, todas las palabras clave de control postfix están prohibidas.

El conjunto de funciones de control de flujo que están exentas de la restricción también se puede configurar con la directiva 'flowcontrol' en su archivo .perlcriticrc:

[ControlStructures::ProhibitPostfixControls]
flowcontrol = warn die carp croak cluck confess goto exit

Esto es útil si estás usando módulos adicionales que agregan cosas como "assert" o "throw".

NOTAS

Las funciones "die", "croak", y "confess" se usan frecuentemente como controles de flujo al igual que "next" o "last". Por lo tanto, esta política le permite usar un "if" postfix cuando la sentencia comienza con una de esas funciones. También es bastante común usar "warn", "carp", y "cluck" con un "if" postfix, por lo que esos también están permitidos.

La palabra clave "when" se agregó al lenguaje después de que se escribiera Perl Best Practices. Esta política trata a "when" de la misma manera que a "if", es decir, está permitido después de construcciones de control de flujo. Gracias a brian d foy por la inspiración http://www.effectiveperlprogramming.com/blog/543.
