NOMBRE

Perl::Critic::PolicyParameter::Behavior::Enumeration - Acciones apropiadas para un valor enumerado.

DESCRIPCIÓN

Proporciona un conjunto estándar de funcionalidades para un Perl::Critic::PolicyParameter enumerado, de modo que el desarrollador de una política no tenga que proporcionarla él mismo.

NOTA: No instancies esta clase. Utiliza la instancia única que mantiene Perl::Critic::PolicyParameter.

SOPORTE DE INTERFAZ

Esta se considera una clase no pública. Su interfaz está sujeta a cambios sin previo aviso.

MÉTODOS

"initialize_parameter( $parameter, $specification )"
Conecta la funcionalidad que este comportamiento proporciona al parámetro, basándose en la configuración proporcionada por la especificación.

Este comportamiento busca dos elementos de configuración:

enumeration_values
Obligatorio. El conjunto de valores válidos para el parámetro, como una referencia a un array.
enumeration_allow_multiple_values
Opcional, por defecto es falso. ¿Debería el parámetro admitir un solo valor o aceptar varios?
generate_parameter_description( $parameter )
Crea una descripción del parámetro, basándose en la descripción del parámetro en sí, pero mejorándola con información de este comportamiento.

En este caso específico, el universo de valores se añade al final.
