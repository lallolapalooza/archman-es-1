Perl::Critic::Policy::ValuesAndExpressions::RequireInterpolationOfMetachars(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ValuesAndExpressions::RequireInterpolationOfMetachars(3pm)

NOMBRE

Perl::Critic::Policy::ValuesAndExpressions::RequireInterpolationOfMetachars - Advierte que podrías haber usado comillas simples cuando en realidad querías comillas dobles.

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Esta política te advierte si usas comillas simples o "q//" con una cadena que tiene metacaracteres sin escapar que podrían necesitar interpolación. Es difícil saber con certeza si una cadena realmente debe ser interpolada sin mirar la tabla de símbolos. Esta política simplemente hace una suposición educada buscando metacaracteres y sigilos que generalmente indican que la cadena debe ser interpolada.

Excepciones

  • Nombres de variables para "use vars": 
    use vars '$x';          # ok
use vars ('$y', '$z');  # ok
use vars qw< $a $b >;   # ok
  • Cosas que parecen direcciones de correo electrónico: 
    print 'john@foo.com';           # ok
$address = 'suzy.bar@baz.net';  # ok

CONFIGURACIÓN

La opción "rcs_keywords" te permite evitar que esta política se queje de cosas que parecen variables RCS, por ejemplo, al derivar valores para variables $VERSION.

Por ejemplo, si tienes código como

our ($VERSION) = (q<$Revision$> =~ m/(\d+)/mx);

Puedes especificar

[ValuesAndExpressions::RequireInterpolationOfMetachars]
rcs_keywords = Revision

en tu archivo .perlcriticrc para proporcionar una exención.

NOTAS

El propio pragma "warnings" de Perl también te advierte sobre esto.
