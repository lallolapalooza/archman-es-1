NOMBRE

Perl::Critic::UserProfile - El contenido del perfil del usuario, a menudo .perlcriticrc.

DESCRIPCIÓN

Esta es una clase auxiliar que encapsula el contenido del perfil del usuario, que normalmente se almacena en un archivo .perlcriticrc. No hay partes que el usuario pueda reparar aquí.

SOPORTE DE INTERFAZ

Esta se considera una clase no pública. Su interfaz está sujeta a cambios sin previo aviso.

CONSTRUCTOR

"new( -profile => $p )"
-profile es la ruta al perfil del usuario. Si -profile no está definido, busca el perfil en ./.perlcriticrc y luego en $HOME/.perlcriticrc. Si ninguno de esos archivos existe, entonces se crea UserProfile con valores predeterminados.

Este objeto no tiene en cuenta ninguna anulación de línea de comandos; Perl::Critic::Config se encarga de eso.

MÉTODOS

options_processor()
Devuelve el objeto Perl::Critic::OptionsProcessor para este UserProfile.
policy_is_disabled( $policy )
Dado una referencia a un objeto Perl::Critic::Policy o el nombre de uno, devuelve verdadero si el usuario ha deshabilitado esa política en su perfil.
policy_is_enabled( $policy )
Dado una referencia a un objeto Perl::Critic::Policy o el nombre de uno, devuelve verdadero si el usuario ha habilitado explícitamente esa política en su perfil de usuario.
policy_params( $policy )
Dado una referencia a un objeto Perl::Critic::Policy o el nombre de uno, devuelve un Perl::Critic::PolicyConfig para los parámetros de configuración del usuario para esa política.
raw_policy_params( $policy )
Dado una referencia a un objeto Perl::Critic::Policy o el nombre de uno, devuelve una referencia a un hash de los parámetros de configuración del usuario para esa política.
listed_policies()
Devuelve una lista de los nombres de todas las Políticas que se mencionan en el perfil. Los nombres de las Políticas estarán completamente calificados (por ejemplo, Perl::Critic::Foo).
source()
El lugar de donde provino la información del perfil, si está disponible. Generalmente la ruta a un .perlcriticrc.

VER TAMBIÉN

Perl::Critic::Config, Perl::Critic::OptionsProcessor
