NOMBRE

Pegex::Module - Clase base para módulos de interfaz de gramática Pegex

SINOPSIS

package MyLanguage;
use Pegex::Base;
extends 'Pegex::Module';
use Pegex::Parser;
has parser_class => 'Pegex::Parser';
has grammar_class => 'MyLanguage::Grammar';
has receiver_class => 'MyLanguage::AST';
1;

DESCRIPCIÓN

El módulo en la sinopsis anterior es un módulo completo de análisis de lenguaje. Simplemente hereda de Pegex::Module, y luego anula los atributos "grammar_class" y "receiver_class". Pegex::Module proporciona el método parse().

XXX

En este punto, también debe especificar el atributo "parser_class". La herencia de este valor predeterminado no está funcionando.
