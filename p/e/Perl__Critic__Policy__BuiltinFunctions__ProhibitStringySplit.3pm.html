Perl::Critic::Policy::BuiltinFunctions::ProhibitStringySplit(3pm) Documentación de Perl aportada por el usuario Perl::Critic::Policy::BuiltinFunctions::ProhibitStringySplit(3pm)

NOMBRE

Perl::Critic::Policy::BuiltinFunctions::ProhibitStringySplit - Escribe "split /-/, $string" en lugar de "split '-', $string".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

La función "split" siempre interpreta el argumento PATTERN como una expresión regular, incluso si lo especificas como una cadena. Esto causa mucha confusión si la cadena contiene metacaracteres de expresiones regulares. Por lo tanto, para mayor claridad, expresa siempre el argumento PATTERN como una expresión regular.

$string = 'Fred|Barney';
@names = split '|', $string; # no es correcto, es ('F', 'r', 'e', 'd', '|', 'B', 'a' ...)
@names = split m/[|]/, $string; # correcto, es ('Fred', Barney')

Cuando el PATTERN es un espacio simple, la función "split" tiene un comportamiento especial, por lo que Perl::Critic perdona ese uso. Consulta "perldoc -f split" para obtener más información.

CONFIGURACIÓN

Esta política no es configurable, excepto por las opciones estándar.
