Perl::Critic::PolicyParameter::Behavior::Integer(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::PolicyParameter::Behavior::Integer(3pm)

NOMBRE

Perl::Critic::PolicyParameter::Behavior::Integer - Acciones apropiadas para un parámetro entero.

DESCRIPCIÓN

Proporciona un conjunto estándar de funcionalidades para un parámetro entero de Perl::Critic::PolicyParameter para que el desarrollador de una política no tenga que proporcionarlo él/ella mismo/a.

El analizador proporcionado por este comportamiento permite guiones bajos ("_") en los valores de entrada, como en un literal numérico de Perl.

NOTA: No instancie esta clase. Use la instancia única mantenida por Perl::Critic::PolicyParameter.

SOPORTE DE INTERFAZ

Esta clase se considera no pública. Su interfaz está sujeta a cambios sin previo aviso.

MÉTODOS

"initialize_parameter( $parameter, $specification )"
Conecta la funcionalidad que proporciona este comportamiento al parámetro, basándose en la configuración proporcionada por la especificación.

Este comportamiento busca dos elementos de configuración:

integer_minimum
Opcional. El valor mínimo aceptable. Inclusivo.
integer_maximum
Opcional. El valor máximo aceptable. Inclusivo.
generate_parameter_description( $parameter )
Crea una descripción del parámetro, basándose en la descripción del propio parámetro, pero mejorándola con información de este comportamiento.

En este caso, esto significa incluir los valores mínimo y máximo.
