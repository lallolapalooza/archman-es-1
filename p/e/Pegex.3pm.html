NOMBRE

Pegex - Marco de análisis sintáctico PEG acemista

VERSIÓN

Este documento describe Pegex versión 0.75.

SINOPSIS

use Pegex;
my $result = pegex($grammar)->parse($input);

o con opciones:

use Pegex;
use ReceiverClass;
my $parser = pegex($grammar, 'ReceiverClass');
my $result = $parser->parse($input);

o de forma más explícita:

use Pegex::Parser;
use Pegex::Grammar;
my $pegex_grammar = Pegex::Grammar->new(
    text => $grammar,
);
my $parser = Pegex::Parser->new(
    grammar => $pegex_grammar,
);
my $result = $parser->parse($input);

o personalizado explícitamente:

{
    package MyGrammar;
    use Pegex::Base;
    extends 'Pegex::Grammar';
    has text => "tu texto de definición de gramática va aquí";
    has receiver => "MyReceiver";
}
{
    package MyReceiver;
    use base 'Pegex::Receiver';
    got_some_rule { ... }
    got_other_rule { ... }
}
use Pegex::Parser;
my $parser = Pegex::Parser->new(
    grammar => MyGrammar->new,
    receiver => MyReceiver->new,
);
$parser->parse($input);
my $result = $parser->receiver->data;

DESCRIPCIÓN

Pegex es un marco de análisis sintáctico acemista. ¡Te permite crear fácilmente analizadores que funcionarán de manera equivalente en muchos lenguajes de programación! La inspiración para Pegex proviene del motor de análisis sintáctico en el que se basa el lenguaje de programación postmoderno Perl 6. Pegex trae esta belleza a los otros lenguajes *solo* modernos que tienen un motor de expresiones regulares normal disponible.

Pegex recibe su nombre al combinar Gramáticas de Expresiones Sintácticas (PEG) con Expresiones Regulares (Regex). Eso es realmente lo que hace Pegex.

PEG es la nueva y genial forma de especificar elegantemente gramáticas de descenso recursivo. El lenguaje Perl 6 se define en términos de un lenguaje PEG que se autodenomina Reglas de Perl 6. Las expresiones regulares son familiares para los programadores de la mayoría de los lenguajes de programación modernos. Pegex define una sintaxis PEG simple, donde todas las terminales son expresiones regulares. Esto significa que Pegex puede ser bastante rápido y potente.

Pegex intenta ser la forma más sencilla de definir Lenguajes Específicos de Dominio (DSLs) nuevos (o antiguos) que necesitan ser utilizados en varios lenguajes y entornos de programación. Cosas como JSON, YAML, Markdown, etc. También es excelente para escribir analizadores/compiladores que solo necesitan funcionar en un idioma.

USO

El módulo "Pegex.pm" en sí (este módulo) es solo una forma trivial de usar el marco Pegex. Está destinado únicamente a los usos más sencillos.

Este módulo exporta una única función, "pegex", que toma una cadena de gramática Pegex como entrada. También puede pasar un nombre de clase receptora después de la gramática.

my $parser = pegex($grammar, 'MyReceiver');

La función "pegex" devuelve un objeto Pegex::Parser, en el que típicamente se llamaría al método parse(), que (en caso de éxito) devolverá una estructura de datos con los datos analizados.

Consulte Pegex::API para obtener más detalles.

DEPURACIÓN DE PEGEX

Pegex (Pegex::Parser) tiene muchos métodos de depuración fáciles de usar. Consulte la sección "Debugging" de Pegex::Parser para obtener detalles.
