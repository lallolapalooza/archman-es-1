NOMBRE

Pegex::Parser - Runtime del analizador Pegex

SINOPSIS

use Pegex::Parser;
use SomeGrammarClass;
use SomeReceiverClass;
my $parser = Pegex::Parser->new(
    grammar => SomeGrammarClass->new,
    receiver => SomeReceiverClass->new,
);
my $result = $parser->parse($SomeInputText);

DESCRIPCIÓN

Pegex::Parser es el componente de Pegex que proporciona el runtime del motor de análisis. Requiere un objeto Grammar y un objeto Receiver. Su método parse() toma una entrada que se espera que coincida con la gramática y aplica las reglas de la gramática a la entrada. A medida que se aplica la gramática, se notifica al receptor de las coincidencias. El receptor es libre de hacer lo que desee, pero a menudo construye los datos en una estructura comúnmente conocida como Árbol de Análisis (Parse Tree).

Cuando el método de análisis se completa, devuelve cualquier objeto que el receptor haya proporcionado como resultado final. Si la gramática falla al coincidir con la entrada durante el proceso, el método de análisis generará un error con mucha información sobre el fallo.

ATRIBUTOS

El constructor del objeto Pegex::Parser "new" acepta estos atributos:

"grammar"
Un objeto Pegex::Grammar. Requerido.
"receiver"
Un objeto Pegex::Receiver.
"debug"
Booleano. Activa la depuración. Por defecto es falso.
"recursion_limit"
Entero. Nivel de recursión para terminar. Por defecto 0 (desactivado).
"recursion_warn_limit"
Entero. Nivel de recursión para advertir. Por defecto 0 (desactivado).
"iteration_limit"
Entero. Número de coincidencias a intentar antes de terminar. Por defecto 0 (desactivado).

DEPURACIÓN

Pegex::Parser actualmente tiene 4 configuraciones útiles para la depuración. Estas se pueden establecer como atributos del objeto Pegex::Parser, variables globales o variables de entorno:

"debug" o $Pegex::Parser::Debug o $ENV{PERL_PEGEX_DEBUG}
Si se establece en un valor verdadero, habilita mensajes de rastreo muy útiles para cada operación de coincidencia interna.
"recursion_limit" o "Pegex::Parser::RecursionLimit" o $ENV{PERL_PEGEX_RECURSION_LIMIT}
Si se establece en un número mayor que 0, Pegex::Parser terminará después de alcanzar ese número de nivel de recursión.
"recursion_warn_limit" o "Pegex::Parser::RecursionWarnLimit" o $ENV{PERL_PEGEX_RECURSION_WARN_LIMIT}
Si se establece en un número mayor que 0, Pegex::Parser emitirá una advertencia cada vez que se alcance ese número de nivel de recursión.
"iteration_limit" o "Pegex::Parser::IterationLimit" o $ENV{PERL_PEGEX_ITERATION_LIMIT}
Si se establece en un número mayor que 0, Pegex::Parser terminará después de intentar ese número de coincidencias.
"debug_indent" o $Pegex::Parser::DebugIndent o $ENV{PERL_PEGEX_DEBUG_INDENT}
Indica al analizador cuántos espacios se deben usar para la sangría de la salida de depuración. Por defecto es 1.
"debug_color" o $Pegex::Parser::DebugColor o $ENV{PERL_PEGEX_DEBUG_COLOR}
Si está habilitado, coloreará los eventos "got" y "not" en la salida de depuración ("bright_green" y "bright_red" respectivamente). El color estará habilitado por defecto para la depuración. Requiere Term::ANSIColor.
"always" o 1
El color está habilitado.
"auto"
El color está habilitado cuando STDERR es una tty.
"never" o 0
El color está deshabilitado.

Puedes configurar los colores específicos utilizados añadiéndolos así:

PERL_PEGEX_DEBUG_COLOR='always, cyan bold, black on_yellow'

Para ver los colores disponibles, consulta Term::ANSIColor.

Nota: El uso de estas variables conlleva una pequeña penalización de rendimiento, pero si no las
usas, todo el código de depuración se optimiza y se elimina.
