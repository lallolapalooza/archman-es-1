Perl::Critic::Policy(3pm) Documentación de Usuario de Perl Perl::Critic::Policy(3pm)

NOMBRE

Perl::Critic::Policy - Clase base para todos los módulos de Política.

DESCRIPCIÓN

Perl::Critic::Policy es la clase base abstracta para todos los objetos de Política. Si estás desarrollando tus propias Políticas, tu trabajo es implementar y sobrescribir sus métodos en una subclase. Para trabajar con el motor Perl::Critic, tu implementación debe comportarse como se describe a continuación. Para una explicación detallada sobre cómo crear nuevos módulos de Política, por favor consulta el documento Perl::Critic::DEVELOPER incluido en esta distribución.

SOPORTE DE INTERFAZ

Esta se considera una clase pública. Cualquier cambio en su interfaz pasará por un ciclo de deprecación.

MÉTODOS

new( ... )
No llames a esto. Como autor de Política, no implementes esto. Usa el método initialize_if_enabled() para la configuración de tu Política. Consulta la documentación para desarrolladores para más información.
initialize_if_enabled( $config )
Esto recibe una instancia de Perl::Critic::PolicyConfig como parámetro, y solo se invoca si esta Política es habilitada por el usuario. Por lo tanto, este es el lugar preferido para que las subclases realicen cualquier inicialización.

Las implementaciones de este método deben devolver un valor booleano que indique si la Política debe continuar habilitada. Para la mayoría de las subclases, esto siempre será $TRUE. Las Políticas que dependen de módulos externos u otras facilidades del sistema que pueden o no estar disponibles deben probar la disponibilidad de estas dependencias y devolver $FALSE si no lo están.

prepare_to_scan_document( $document )
El parámetro está a punto de ser escaneado por esta Política. Lo que sea que esta Política quiera hacer en términos de preparación debe ocurrir aquí. Devuelve un valor booleano que indica si el documento debe ser escaneado en absoluto; si este es un valor falso, esta Política no se aplicará al documento. Por defecto, no hace nada más que devolver $TRUE.
" violates( $element, $document ) "
Dado un PPI::Element y un PPI::Document, devuelve uno o más objetos Perl::Critic::Violation si el $element viola esta Política. Si no hay violaciones, entonces devuelve una lista vacía. Si la Política encuentra una excepción, entonces debería "croak" con un mensaje de error y dejar que el llamador decida cómo manejarlo.

violates() es un método abstracto y abortará si intentas invocarlo directamente. Es el corazón de todos los módulos de Política, y tu subclase **debe** sobrescribir este método.

" violation( $description, $explanation, $element ) "
Devuelve una referencia a un nuevo objeto "Perl::Critic::Violation". Los argumentos son una descripción de la violación (como cadena), una explicación de la política (como cadena) o una serie de números de página en PBP (como un array ref), una referencia al elemento PPI que causó la violación.

Estos son los mismos que el constructor para Perl::Critic::Violation, pero sin la severidad. La Política en sí misma conoce la severidad.

" new_parameter_value_exception( $option_name, $option_value, $source, $message_suffix ) "
Crea una Perl::Critic::Exception::Configuration::Option::Policy::ParameterValue para esta Política.
" throw_parameter_value_exception( $option_name, $option_value, $source, $message_suffix ) "
Crea y lanza una Perl::Critic::Exception::Configuration::Option::Policy::ParameterValue. Útil en implementaciones de analizadores de parámetros.
get_long_name()
Devuelve el nombre completo del paquete de esta política.
get_short_name()
Devuelve el nombre de esta política sin el prefijo "Perl::Critic::Policy::".
is_enabled()
Responde si esta política está realmente activa o no. Devuelve un valor verdadero si lo está, un valor falso pero definido si no lo está, y un valor indefinido si aún no se ha decidido si lo estará.
applies_to()
Devuelve una lista de los nombres de las clases PPI que interesan a esta Política. Por defecto, el resultado es "PPI::Element". Sobrescribir este método en subclases de Política debería llevar a aumentos significativos de rendimiento.
default_maximum_violations_per_document()
Devuelve el número máximo de violaciones predeterminado que esta política informará por documento. Por defecto, esto no está definido, pero las subclases pueden sobrescribirlo.
get_maximum_violations_per_document()
Devuelve el número máximo de violaciones que esta política informará para un solo documento. Si esto no está definido, entonces no hay límite. Si "set_maximum_violations_per_document()" no ha sido invocado, entonces se devuelve "default_maximum_violations_per_document()".
set_maximum_violations_per_document()
Especifica el número máximo de violaciones que esta política debe informar para un documento.
default_severity()
Devuelve la severidad predeterminada para violar esta Política. Consulta las constantes $SEVERITY en Perl::Critic::Utils para una enumeración de los posibles valores de severidad. Por defecto, este método devuelve $SEVERITY_LOWEST. Los autores de subclases de Perl::Critic::Policy deberían sobrescribir este método para devolver un valor que consideren apropiado para su Política. En general, las Políticas que son ampliamente aceptadas o tienden a prevenir errores deberían tener una severidad mayor que aquellas que son más subjetivas o cosméticas en naturaleza.
get_severity()
Devuelve la severidad de violar esta Política. Si la severidad no ha sido definida explícitamente llamando a "set_severity", entonces se devuelve la "default_severity". Consulta las constantes $SEVERITY en Perl::Critic::Utils para una enumeración de los posibles valores de severidad.
set_severity( $N )
Establece la severidad para violar esta Política. Los clientes de objetos Perl::Critic::Policy pueden llamar a este método para asignar una severidad diferente a la Política si no están de acuerdo con la "default_severity". Consulta las constantes $SEVERITY en Perl::Critic::Utils para una enumeración de los posibles valores.
default_themes()
Devuelve una lista ordenada de los temas predeterminados asociados con esta Política. El método predeterminado devuelve una lista vacía. Los autores de políticas deberían sobrescribir este método para devolver una lista de temas apropiados para su política.
get_themes()
Devuelve una lista ordenada de los temas asociados con esta Política. Si no has añadido temas o establecido los temas explícitamente, este método solo devuelve los temas predeterminados.
set_themes( @THEME_LIST )
Establece los temas asociados con esta Política. Cualquier tema existente se sobrescribe. Los temas duplicados se eliminarán.
add_themes( @THEME_LIST )
Añade temas adicionales a esta Política. Cualquier tema existente se conserva. Los temas duplicados se eliminarán.
get_abstract()
Recupera el resumen de esta política (la parte de la sección NAME de la POD después del nombre del módulo), si está disponible.

NAME

Perl::Critic::Policy - Abstract base class for policies

DESCRIPTION

This module is an abstract base class for all policies that are used by Perl::Critic. It provides a default implementation of the various methods that a policy must implement, and provides a hook into the policy configuration.

INTERFACE SUPPORT

All policies must implement the following interface methods:

themes()
Return a list of strings that represent the themes that this policy belongs to. For example, "NamingConventions", "Documentation", "SuboptimalCode".
severity()
Return the default severity level for this policy. The severity level is an integer between 1 and 5, where 1 is the least severe and 5 is the most severe.
description()
Return a string describing what the policy does. This will be displayed in the POD output when the verbosity level is set accordingly.
supports_parameters()
Return true if the policy supports parameters. Defaults to false.
violates( $element )
This is the primary method that all policies must implement. It is called by Perl::Critic for each element (a subroutine, a statement, a scalar expression, etc.) in the code. If the policy is violated by the element, the method should return a Perl::Critic::Violation object describing the violation. Otherwise, it should return false.

METHODS

supported_themes()
Returns a list of themes supported by Perl::Critic itself. This is used internally by Perl::Critic to determine which themes are available.
check_level()
Returns the minimum severity level required for this policy to be checked. This is set by the "--severitylevel" command-line option, or the "severitylevel" configuration option.
active_themes()
Returns a list of themes that are currently active for this policy. This is determined by the "--themes" and "--exclude-themes" command-line options, or the "themes" and "exclude_themes" configuration options.
is_active()
Returns true if the policy is currently active. A policy is active if at least one of its active themes is also an active theme in the configuration. In other words, if the policy's themes intersect with the globally active themes, and the policy's severity level is greater than or equal to the configured minimum severity level.
max_violations()
Returns the maximum number of violations allowed for this policy per document. This is set by the "--max-violations" command-line option, or the "max_violations" configuration option.
get_name()
Returns the fully qualified name of the policy, e.g. "Perl::Critic::Policy::NamingConventions::ProhibitMixedCaseNames".
get_short_name()
Returns the short name of the policy, e.g. "ProhibitMixedCaseNames".
get_abstract()
Retrieve the abstract for this policy (the part of the NAME section of the POD after the module name), if it is available.
get_raw_abstract()
Retrieve the abstract for this policy (the part of the NAME section of the POD after the module name), if it is available, in the unparsed form.
parameter_metadata_available()
Returns whether information about the parameters is available.
get_parameters()
Returns a reference to an array containing instances of Perl::Critic::PolicyParameter.

Note that this will return an empty list if the parameters for this policy are unknown. In order to differentiate between this circumstance and the one where this policy does not take any parameters, it is necessary to call parameter_metadata_available().

set_format( $format )
Class method. Sets the format for all Policy objects when they are evaluated in string context. The default is "%p\n". See "OVERLOADS" for formatting options.
get_format()
Class method. Returns the current format for all Policy objects when they are evaluated in string context.
to_string()
Returns a string representation of the policy. The content of the string depends on the current value returned by get_format(). See "OVERLOADS" for the details.
is_safe()
Answer whether this Policy can be used to analyze untrusted code, i.e. the Policy doesn't have any potential side effects.

This method returns a true value by default.

An "unsafe" policy might attempt to compile the code, which, if you have "BEGIN" or "CHECK" blocks that affect files or connect to databases, is not a safe thing to do. If you are writing a such a Policy, then you should override this method to return false.

By default Perl::Critic will not run unsafe policies.

DOCUMENTATION

When your Policy module first "use"s Perl::Critic::Violation, it will try and extract the DESCRIPTION section of your Policy module's POD. This information is displayed by Perl::Critic if the verbosity level is set accordingly. Therefore, please include a DESCRIPTION section in the POD for any Policy modules that you author. Thanks.

OVERLOADS

Perl::Critic::Violation overloads the "" operator to produce neat little messages when evaluated in string context.

Formats are a combination of literal and escape characters similar to the way "sprintf" works. If you want to know the specific formatting capabilities, look at String::Format. Valid escape characters are:

%P
Name of the Policy module.
%p
Name of the Policy without the "Perl::Critic::Policy::" prefix.
%a
The policy abstract.
%O
List of supported policy parameters. Takes an option of a format string for "to_formatted_string" in Perl::Critic::PolicyParameter. For example, this can be used like "%{%n - %d\n}O" to get a list of parameter names followed by their descriptions.
%U
A message stating that the parameters for the policy are unknown if parameter_metadata_available() returns false. Takes an option of what the message should be, which defaults to "Cannot programmatically discover what parameters this policy takes.". The value of this option is interpolated in order to expand the standard escape sequences ("\n", "\t", etc.).
%S
The default severity level of the policy.
%s
The current severity level of the policy.
%T
The default themes for the policy.
%t
The current themes for the policy.
%V
The default maximum number of violations per document of the policy.
%v
The current maximum number of violations per document of the policy.
