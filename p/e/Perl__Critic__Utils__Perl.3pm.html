Perl::Critic::Utils::Perl(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Utils::Perl(3pm)

NOMBRE

Perl::Critic::Utils::Perl - Funciones de utilidad para tratar problemas del lenguaje Perl.

SINOPSIS

use Perl::Critic::Utils::Perl qw< :all >;
my $nombre = symbol_without_sigil('$foo');    # $nombre es "foo".

DESCRIPCIÓN

Esto maneja varios problemas con Perl, el lenguaje, que no están necesariamente relacionados con PPI.

SOPORTE DE INTERFAZ

Este se considera un módulo público. Cualquier cambio en su interfaz pasará por un ciclo de deprecación.

SUBRUTINAS IMPORTABLES

symbol_without_sigil( $simbolo )
Devuelve el nombre del símbolo especificado sin ningún sigilo al principio. El parámetro puede ser una cadena Perl normal o un PPI::Element.
