NOMBRE

Perl::Critic::Policy::Modules::ProhibitExcessMainComplexity - Minimizar la complejidad en el código que está fuera de las subrutinas.

AFILIACIÓN

Esta política es parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Todo lo demás siendo igual, el código complicado es más propenso a errores y más caro de mantener que el código más simple. El primer paso para gestionar la complejidad es establecer métricas de complejidad formales. Una de esas métricas es la puntuación de McCabe, que describe el número de rutas posibles a través de un bloque de código. Esta Política aproxima la puntuación de McCabe sumando el número de declaraciones y operadores condicionales dentro de un bloque de código. La investigación ha demostrado que una puntuación de McCabe superior a 20 es un signo de código de alto riesgo y potencialmente incontrolable. Véase http://en.wikipedia.org/wiki/Cyclomatic_complexity para una discusión sobre el número de McCabe y otras métricas de complejidad.

Mientras que Perl::Critic::Policy::Subroutines::ProhibitExcessComplexity evalúa la complejidad de cada subrutina, esta Política evalúa la complejidad total de todo el código que está fuera de cualquier declaración de subrutina.

La prescripción habitual para reducir la complejidad es refactorizar el código en subrutinas más pequeñas. El libro de Mark Dominus, "Higher Order Perl", también describe callbacks, recursión, memoización, iteradores y otras técnicas que ayudan a crear código Perl simple y extensible.

CONFIGURACIÓN

La puntuación máxima aceptable de McCabe se puede establecer con el elemento de configuración "max_mccabe".

Si la suma de todo el código fuera de cualquier subrutina tiene una puntuación de McCabe superior a este número, generará una violación de la Política. El valor predeterminado es 20. Un ejemplo de sección para un .perlcriticrc:

[Modules::ProhibitExcessMainComplexity]
max_mccabe = 30

NOTAS

"Todo debe hacerse tan simple como sea posible, pero no más simple."
                                                -- Albert Einstein

La complejidad es subjetiva, pero las métricas de complejidad formales siguen siendo increíblemente valiosas. Cada problema tiene un nivel de complejidad inherente, por lo que no es necesariamente óptimo minimizar el número de McCabe. Así que no se ofenda si su código activa esta Política. Simplemente considere si podría haber una forma más simple de realizar el trabajo.
