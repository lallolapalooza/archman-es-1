Perl::Critic::Utils(3pm) Documentación de contribuciones de Perl Perl::Critic::Utils(3pm)

NOMBRE

Perl::Critic::Utils - Subrutinas de utilidad genéricas y constantes para Perl::Critic y distribuciones derivadas.

DESCRIPCIÓN

Este módulo proporciona varias subrutinas estáticas y variables útiles para desarrollar subclases de Perl::Critic::Policy. A menos que estés escribiendo módulos de política, probablemente no te preocupe este paquete.

SOPORTE DE INTERFAZ

Este módulo se considera un módulo público. Cualquier cambio en su interfaz pasará por un ciclo de deprecación.

SUBS IMPORTABLES

"find_keywords( $doc, $keyword )"
OBSOLETO: Desde la versión 0.11, cada política se evalúa en cada elemento del documento. Así que no deberías necesitar buscar un keyword específico. Si deseas usar esto, por favor impórtalo mediante el tag ":deprecated", en lugar de directamente, para marcar el módulo como que necesita actualización.
is_assignment_operator( $element )
Devuelve verdadero si el token representa uno de los operadores de asignación (por ejemplo, "= &&= ||= //= += -=").
is_perl_global( $element )
Devuelve verdadero si el token representa una de las variables globales proporcionadas por el módulo inglés, o una de las variables globales predefinidas como "%SIG", "%ENV", o "@ARGV". El sigilo del símbolo se ignora, por lo que cosas como "$ARGV" o "$ENV" también devuelven verdadero.
is_perl_builtin( $element )
Devuelve verdadero si el token representa una llamada a una función incorporada del lenguaje.
is_perl_bareword( $element )
Devuelve verdadero si el token representa una palabra clave (bareword) (por ejemplo, "if", "else", "sub", "package").
is_perl_filehandle( $element )
Devuelve verdadero si el token representa uno de los manejadores de archivos globales (por ejemplo, "STDIN", "STDERR", "STDOUT", "ARGV"). Nota: esta función devolverá falso si se le pasa un manejador de archivos representado como un glob (por ejemplo, "*STDIN").
is_perl_builtin_with_list_context( $element )
Devuelve verdadero si el token representa una llamada a una función incorporada del lenguaje que proporciona un contexto de lista a los tokens siguientes.
is_perl_builtin_with_multiple_arguments( $element )
Devuelve verdadero si el token representa una llamada a una función incorporada del lenguaje que puede tomar múltiples argumentos.
is_perl_builtin_with_no_arguments( $element )
Devuelve verdadero si el token representa una llamada a una función incorporada del lenguaje que no puede tomar ningún argumento.
is_perl_builtin_with_one_argument( $element )
Devuelve verdadero si el token representa una llamada a una función incorporada del lenguaje que toma un solo y único argumento.
is_perl_builtin_with_optional_argument( $element )
Devuelve verdadero si el token representa una llamada a una función incorporada del lenguaje que puede tomar un argumento opcional (máximo uno).

Los conjuntos de valores para los cuales is_perl_builtin_with_multiple_arguments(), is_perl_builtin_with_no_arguments(), is_perl_builtin_with_one_argument() y is_perl_builtin_with_optional_argument() devuelven verdadero son disjuntos y su unión es exactamente el conjunto de valores para los cuales is_perl_builtin() devuelve verdadero.

is_perl_builtin_with_zero_and_or_one_arguments( $element )
Devuelve verdadero si el token representa una llamada a una función incorporada del lenguaje que toma cero y/o un argumento.

Devuelve verdadero si cualquiera de is_perl_builtin_with_no_arguments(), is_perl_builtin_with_one_argument() o is_perl_builtin_with_optional_argument() devuelve verdadero.

is_qualified_name( $name )
Devuelve verdadero si el nombre tiene un componente de módulo, es decir, contiene "::".
precedence_of( $element )
Devuelve la precedencia del operador, donde 1 es la mayor precedencia. Devuelve undef si la precedencia no puede ser determinada (lo cual suele ocurrir porque no es un operador).
is_hash_key( $element )
Devuelve verdadero si el elemento es una clave de un hash literal. PPI no distingue entre palabras clave (como palabras o llamadas a funciones) y palabras clave en índices de hash (considerados literales). Por lo tanto, esta subrutina es útil si tu política está buscando elementos de tipo PPI::Token::Word y deseas filtrar aquellos que están en índices de hash. En ambos ejemplos siguientes, "foo" se considera una clave de hash: 
$hash1{foo} = 1;
%hash2 = (foo => 1);

Pero si la palabra clave está seguida por una lista de argumentos, Perl la tratará como una llamada a una función. Así, en estos ejemplos, "foo" no se considera una clave de hash:

$hash1{ foo() } = 1;
&hash2 = (foo() => 1);
is_included_module_name( $element )
Devuelve verdadero si el elemento es el nombre de un módulo que se está incluyendo mediante "use", "require" o "no".
is_integer( $value )
Devuelve verdadero si el parámetro, como cadena, parece un valor entero.
is_class_name( $element )
Devuelve verdadero si el elemento inmediatamente siguiente es el operador de desreferencia "->". Cuando una palabra clave tiene "->" en el lado derecho, generalmente significa que es el nombre de la clase (desde la cual se está llamando a un método).
is_label_pointer( $element )
Devuelve verdadero si el elemento es el nombre de un puntero a etiqueta.

si el elemento es la etiqueta en una "next", "last", "redo", o "goto" declaración. Tenga en cuenta que esto no es lo mismo que la declaración de etiqueta.
is_method_call( $elemento )
Dado un PPI::Token::Word, devuelve verdadero si el elemento que precede inmediatamente a este elemento es el operador de desreferencia "->". Cuando una palabra desnuda tiene un "->" en el lado **izquierdo**, generalmente significa que es el nombre de un método (que se está llamando desde una clase).
is_package_declaration( $elemento )
Dado un PPI::Token::Word, devuelve verdadero si el elemento es el nombre de un paquete que se está declarando.
is_subroutine_name( $elemento )
Dado un PPI::Token::Word, devuelve verdadero si el elemento es el nombre de una declaración de subrutina. Esto es útil para distinguir palabras desnudas y llamadas a funciones de declaraciones de subrutinas.
is_function_call( $elemento )
Dado un PPI::Token::Word, devuelve verdadero si el elemento parece ser una llamada a una función estática. Específicamente, esta función devuelve verdadero si "is_hash_key", "is_method_call", "is_subroutine_name", "is_included_module_name", "is_package_declaration", "is_perl_bareword", "is_perl_filehandle", "is_label_pointer" y "is_subroutine_name" devuelven falso para el elemento dado.
first_arg( $elemento )
Dado un PPI::Element que se presume que es una llamada a función (que suele ser un PPI::Token::Word), devuelve el primer argumento. Esto es similar a parse_arg_list() y sigue la misma lógica. Tenga en cuenta que para el código: 
int($x + 0.5)

esta función devolverá solo $x, no la expresión completa. Esto es diferente del comportamiento de parse_arg_list(). Otra advertencia es:

int(($x + $y) + 0.5)

que devuelve "($x + $y)" como una instancia de PPI::Structure::List.

parse_arg_list( $elemento )
Dado un PPI::Element que se presume que es una llamada a función (que suele ser un PPI::Token::Word), divide las expresiones de los argumentos en arreglos de tokens. Devuelve una lista que contiene referencias a cada uno de esos arreglos. Esto es útil porque los paréntesis son opcionales al llamar a una función, y PPI los analiza de manera muy diferente. Por lo tanto, este método es un árbol de análisis de nodos PPI de pobre hombre. No es infalible porque no respeta la precedencia. En general, no me gusta cómo funciona esta función, así que no cuentes con que sea estable (o que exista).
split_nodes_on_comma( @nodos )
Esto tiene el mismo tipo de retorno que parse_arg_list() pero espera recibir los nodos que representan el interior de una lista, como: 
'foo', 1, 2, 'bar'
is_script( $documento )
Esta subrutina está obsoleta y se eliminará en una versión futura. Deberías usar el método "is_program()" en Perl::Critic::Document en su lugar.
is_in_void_context( $token )
Dado un PPI::Token, responde si parece estar en un contexto nulo.
policy_long_name( $nombre_politica )
Dado un nombre de clase de política en forma larga o corta, devuelve la forma larga.
policy_short_name( $nombre_politica )
Dado un nombre de clase de política en forma larga o corta, devuelve la forma corta.
all_perl_files( @directorios )
Dada una lista de directorios, busca recursivamente en todos los directorios (en profundidad) y devuelve una lista de rutas para todos los archivos que son archivos de código Perl. Se omiten los archivos administrativos de CVS o Subversion, así como los que parecen archivos temporales o de copia de seguridad.

Un archivo de código Perl es:

  • Cualquier archivo que termine en .PL, .pl, .pm, .psgi, o .t
  • Cualquier archivo que tenga una primera línea con un shebang que contenga 'perl'
severity_to_number( $severidad )
Si $severidad se proporciona como un entero, esta función devuelve $severidad pero normalizado para que se encuentre entre $SEVERITY_LOWEST y $SEVERITY_HIGHEST. Si $severidad se proporciona como una cadena, esta función devuelve el número de severidad correspondiente. Si la cadena no tiene un número correspondiente, esta función lanzará una excepción.
is_valid_numeric_verbosity( $severidad )
Responde si el argumento tiene una traducción a un formato de Violación.
verbosity_to_format( $nivel_verbosidad )
Dado un nivel de verbosidad entre 1 y 10, devuelve la cadena de formato predefinida correspondiente. Estos formatos son adecuados para pasarlos al método "set_format" en Perl::Critic::Violation. Consulte la documentación de perlcritic para ver una lista de los formatos predefinidos.
hashify( @lista )
Dada @lista, devuelve un hash donde @lista está en las claves y cada valor es 1. Los valores duplicados en @lista se eliminan silenciosamente.
interpolate( $literal )
Dado un string $literal que puede contener caracteres de control (por ejemplo, '\t' '\n'), esta función realiza una doble interpolación en el string y lo devuelve como si hubiera sido declarado entre comillas dobles. Por ejemplo: 
'foo \t bar \n' ...se convierte en... "foo \t bar \n"
shebang_line( $documento )
Dado un PPI::Document, comprueba si comienza con "#!". Si es así, devuelve esa línea. De lo contrario, devuelve undef.
words_from_string( $str )
Dado el string de configuración $str, devuelve todas las palabras del string. Esto es más seguro que dividir por espacios en blanco.
"is_unchecked_call( $elemento, $modulos_autodie )"
Dado un PPI::Element, comprueba si contiene una llamada a función cuyo valor de retorno no se comprueba. El segundo argumento es una referencia de arreglo de nombres de módulos que exportan "autodie". El módulo "autodie" siempre se incluye en esta lista por defecto.

NAME

Perl::Critic::Utils - Utility subs for Perl::Critic modules

DESCRIPTION

This module provides utility subroutines that are used by various Perl::Critic modules. It is not intended to be used directly by end-users.

INTERFACE SUPPORT

The interface to this module is not stable. It is intended for internal use by Perl::Critic only. Any of the subroutines or variables provided by this module could be changed or removed at any time without warning.

IMPORTABLE SUBS

The following subroutines are exported by default.

$SCOLON
$SPACE
$SLASH
$BSLASH
$LEFT_PAREN
$RIGHT_PAREN

IMPORTABLE VARIABLES

The following variables are exported by default.

$SEVERITY
The default severity for a Policy.
$VERBOSITY
The default verbosity for a Policy.

You can import specific sets of subroutines and variables using import tags.
