NOMBRE

Perl::Critic::Utils::PPI - Funciones de utilidad para tratar con objetos PPI.

DESCRIPCIÓN

Proporciona clasificación de elementos PPI.

SOPORTE DE INTERFAZ

Este módulo se considera público. Cualquier cambio en su interfaz pasará por un ciclo de depreciación.

SUBS IMPORTABLES

is_ppi_expression_or_generic_statement( $element )
Responde si el parámetro es una expresión o una declaración genérica. Es decir, el parámetro es un PPI::Statement::Expression o la clase del parámetro es PPI::Statement y no una de sus subclases distintas de "Expression".
is_ppi_generic_statement( $element )
Responde si el parámetro es una declaración genérica, es decir, el parámetro es una PPI::Statement pero no una de sus subclases.
is_ppi_statement_subclass( $element )
Responde si el parámetro es una declaración especializada, es decir, el parámetro es una PPI::Statement pero la clase del parámetro no es PPI::Statement.
is_ppi_simple_statement( $element )
Responde si el parámetro representa una declaración simple, es decir, si el parámetro es una PPI::Statement, PPI::Statement::Break, PPI::Statement::Include, PPI::Statement::Null, PPI::Statement::Package, o PPI::Statement::Variable.
is_ppi_constant_element( $element )
Responde si el parámetro representa un valor constante, es decir, si el parámetro es un PPI::Token::Number, PPI::Token::Quote::Literal, PPI::Token::Quote::Single, o PPI::Token::QuoteLike::Words, o es un PPI::Token::Quote::Double o PPI::Token::Quote::Interpolate que de hecho no contiene variables interpoladas.

Esta subrutina **no** interpreta ningún tipo de here document como un valor constante, y puede que no lo haga hasta que PPI::Token::HereDoc adquiera las porciones relevantes de la interfaz de PPI::Token::Quote.

Esta subrutina tampoco interpreta entidades creadas por el módulo Readonly o el pragma constant, porque la infraestructura para detectar estos parece no estar presente, y el autor de esta subrutina (el **no** Sr. Shank ni el Sr. Thalhammer) carece del conocimiento/experiencia/ánimo para ponerla en práctica.

is_subroutine_declaration( $element )
¿Es el parámetro una declaración de subrutina, nombrada o no?
is_in_subroutine( $element )
¿Es el parámetro una subrutina o está dentro de una?
get_constant_name_element_from_declaring_statement($statement)
Esta subrutina está depreciada. Debería usar "get_constant_name_elements_from_declaring_statement()" en PPIx::Utils::Traversal en su lugar.

Dada una PPI::Statement, si la declaración es una "use constant" o una declaración Readonly, devuelve el nombre de lo que se está definiendo.

Dado

use constant 1.16 FOO => 'bar';

esto devolverá "FOO". De manera similar, dado

Readonly::Hash my %FOO => ( bar => 'baz' );

esto devolverá "%FOO".

Advertencia: en el caso en que se declaren múltiples constantes usando la misma declaración "use constant" (por ejemplo, "use constant { FOO => 1, BAR => 2 };"), esta subrutina devolverá el PPI::Structure::Constructor que declara. En el caso de "use constant 1.16 { FOO => 1, BAR => 2 };" puede devolver un PPI::Structure::Block en lugar de un PPI::Structure::Constructor, debido a un error de análisis en PPI.

get_next_element_in_same_simple_statement( $element )
Dado un PPI::Element, esta subrutina devuelve el siguiente elemento en la misma declaración simple según lo definido por is_ppi_simple_statement(). Si no se encuentra ningún elemento siguiente, esta subrutina simplemente retorna.

Si el $element no está definido o no está bendecido, simplemente retornamos.

Si el $element satisface is_ppi_simple_statement(), retornamos, **a menos** que tenga un padre que sea un PPI::Structure::List.

Si el $element es el último elemento significativo en su PPI::Node, lo reemplazamos con su padre e iteramos de nuevo.

De lo contrario, devolvemos "$element->snext_sibling()".

get_previous_module_used_on_same_line( $element )
Dado un PPI::Element, devuelve el PPI::Element que representa el nombre del módulo incluido por el anterior "use" o "require" en la misma línea que el $element. Si no se encuentra ninguno, simplemente retorna.

Por ejemplo, con la línea

use version; our $VERSION = ...;

dada la instancia PPI::Token::Symbol para $VERSION, esto devolverá "version".

Si el elemento dado está en un "use" o <require>, el retorno es del anterior "use" o "require" en la línea, si lo hay.
