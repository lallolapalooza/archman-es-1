Perl__Critic__Policy__BuiltinFunctions__ProhibitUselessTopic(3pm)

Paquete: perl-perl-critic

Licencias: PerlArtistic

Perl::Critic::Policy::BuiltinFunctions::ProhibitUselessTopic(3pm) Documentación Perl contribuida por el usuario Perl::Critic::Policy::BuiltinFunctions::ProhibitUselessTopic(3pm)

NOMBRE

Perl::Critic::Policy::BuiltinFunctions::ProhibitUselessTopic - No pasar $_ a funciones incorporadas que lo asumen, o a la mayoría de los operadores de prueba de archivos.

AFILIACIÓN

Esta política es parte de la distribución Perl::Critic.

DESCRIPCIÓN

Hay una serie de lugares donde $_, o la variable "tópico", es innecesaria.

Tópico innecesario para ciertas funciones incorporadas de Perl

Muchas funciones incorporadas de Perl operarán sobre $_ si no se pasa ningún argumento. Por ejemplo, la función "length" operará sobre $_ por defecto. Este fragmento:

for ( @list ) {
    if ( length( $_ ) == 4 ) { ...

Se escribe de forma más idiomática como:

for ( @list ) {
    if ( length == 4 ) { ...

En el caso de la función "split", el segundo argumento es el que por defecto es $_. Este fragmento:

for ( @list ) {
    my @args = split /\t/, $_;

Se escribe mejor como:

for ( @list ) {
    my @args = split /\t/;

Hay una función incorporada para la que esta política no comprueba: "reverse" llamada con $_.

La función "reverse" solo opera sobre $_ si se llama en contexto escalar. Por lo tanto:

for ( @list ) {
    my $backwards = reverse $_;

Se escribe mejor como:

for ( @list ) {
    my $backwards = reverse;

Sin embargo, la distinción entre contexto escalar y de lista en "reverse" aún no funciona. Ver ERRORES CONOCIDOS abajo.

Tópico innecesario para la mayoría de los operadores de prueba de archivos

Otro lugar donde $_ es innecesario es con un operador de prueba de archivos.

# Estos son idénticos.
my $size = -s $_;
my $size = -s;
# Estos son idénticos.
if ( -r $_ ) { ...
if ( -r ) { ...

La excepción es después del operador de prueba de archivo "-t", que en lugar de usar por defecto $_, usa por defecto "STDIN".

# Estos NO son idénticos.
if ( -t $_ ) { ...
if ( -t ) { ...  # Comprueba STDIN, no $_

ERRORES CONOCIDOS

Esta política marca un falso positivo en "reverse" llamada en contexto de lista, ya que "reverse" en contexto de lista no asume $_.

my $s = reverse( $_ ); # $_ es inútil.
my @a = reverse( $_ ); # $_ no es inútil aquí.

CONFIGURACIÓN

Esta política no es configurable excepto por las opciones estándar.
