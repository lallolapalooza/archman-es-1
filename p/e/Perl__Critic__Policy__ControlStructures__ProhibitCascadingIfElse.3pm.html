NOMBRE

Perl::Critic::Policy::ControlStructures::ProhibitCascadingIfElse - No escribas cadenas largas de "if-elsif-else".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Las cadenas largas de "if-elsif" son difíciles de digerir, especialmente si son más largas que una sola página o pantalla. Si se prueba la igualdad, utiliza en su lugar una búsqueda en hash.

if ($condition1) {         #ok
    $foo = 1;
}
elsif ($condition2) {      #ok
    $foo = 2;
}
elsif ($condition3) {      #ok
    $foo = 3;
}
elsif ($condition4) {      #¡demasiados!
    $foo = 4;
}
else {                     #ok
    $foo = $default;
}

CONFIGURACIÓN

Esta política puede configurarse con un número máximo de alternativas "elsif" permitidas. El valor predeterminado es 2. Esto se puede especificar mediante un elemento "max_elsif" en el archivo .perlcriticrc:

[ControlStructures::ProhibitCascadingIfElse]
max_elsif = 3
