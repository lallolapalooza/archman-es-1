Perl::Critic::Policy::Variables::ProhibitUnusedVariables(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::Variables::ProhibitUnusedVariables(3pm)

NOMBRE

Perl::Critic::Policy::Variables::ProhibitUnusedVariables - No pidas almacenamiento que no necesitas.

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Las variables no utilizadas abarrotan el código y requieren que el lector haga una contabilidad mental para averiguar si la variable se utiliza realmente o no.

En este momento, esta política es muy limitada para garantizar que no haya falsos positivos. Esperemos que esto se vuelva más sofisticado pronto.

Ahora mismo, solo busca variables léxicas simplemente declaradas y no inicializadas.

my $x;          # no está bien, asumiendo que no hay otras apariciones.
my @y = ();     # está bien, aún no manejado.
our $z;         # está bien, global.
local $w;       # está bien, global.

Este módulo es muy simple: no realiza detección de ámbitos, es decir, si el mismo nombre de variable se utiliza en dos ubicaciones diferentes, incluso si no son la misma variable, esta política no se quejará.

Hay que empezar por algún lado.

CONFIGURACIÓN

Esta política no es configurable excepto por las opciones estándar.
