Perl::Critic::Violation(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Violation(3pm)

NOMBRE

Perl::Critic::Violation - Una violación de una Política encontrada en algún código fuente.

SINOPSIS

use PPI;
use Perl::Critic::Violation;
my $elem = $doc->child(0);      # $doc es un objeto PPI::Document
my $desc = 'Código que causa el problema';    # Describe la violación
my $expl = [1,45,67];           # Números de página de PBP
my $sev  = 5;                   # Nivel de severidad de esta violación
my $vio  = Perl::Critic::Violation->new($desc, $expl, $node, $sev);

DESCRIPCIÓN

Perl::Critic::Violation es la representación genérica de una violación individual de Política. Su propósito principal es proporcionar una capa de abstracción para que los clientes de Perl::Critic no tengan que saber nada sobre PPI. El método "violations" de todas las subclases de Perl::Critic::Policy debe devolver una lista de estos objetos Perl::Critic::Violation.

SOPORTE DE INTERFAZ

Esta se considera una clase pública. Cualquier cambio en su interfaz pasará por un ciclo de depreciación.

CONSTRUCTOR

"new( $description, $explanation, $element, $severity )"
Devuelve una referencia a un nuevo objeto "Perl::Critic::Violation". Los argumentos son una descripción de la violación (como cadena), una explicación de la política (como cadena) o una serie de números de página en PBP (como referencia a un ARRAY), una referencia al elemento PPI que causó la violación y la severidad de la violación (como entero).

MÉTODOS

description()
Devuelve una breve descripción de la violación específica. En otras palabras, este valor puede cambiar para cada violación.
explanation()
Devuelve una explicación de la política como cadena o como referencia a un arreglo de números de página en PBP. Este valor generalmente no cambiará según el código específico que viola la política.
location()
No uses este método. Usa los métodos line_number(), logical_line_number(), column_number(), visual_column_number() y logical_filename() en su lugar.

Devuelve una referencia a un arreglo de cinco elementos que contiene el número de línea y los números de columna real y virtual, el número lógico y el nombre de archivo lógico donde ocurrió esta Violación, como en PPI::Element.

line_number()
Devuelve el número de línea física en el que se encontró la violación.
logical_line_number()
Devuelve el número de línea lógica en el que se encontró la violación. Este puede diferir del número de línea física cuando hubo directivas "#line" en el código.
column_number()
Devuelve la columna física en la que se encontró la violación. Esto significa que los caracteres de tabulación dura cuentan como un solo carácter.
visual_column_number()
Devuelve la columna en la que se encontró la violación, tal como aparecería si los caracteres de tabulación dura se expandieran, basándose en el valor de "tab_width [ $width ]" en PPI::Document.
filename()
Devuelve la ruta al archivo donde ocurrió esta Violación. En algunos casos, la ruta puede no estar definida porque el código fuente no se leyó directamente de un archivo.
logical_filename()
Devuelve la ruta lógica al archivo donde ocurrió la Violación. Esto puede diferir de filename() cuando hubo una directiva "#line" en el código.
severity()
Devuelve la severidad de esta Violación como un entero que varía de 1 a 5, donde 5 es la más severa.
sort_by_severity( @violation_objects )
Si necesitas ordenar las Violaciones por severidad, usa esta útil rutina: 
@sorted = Perl::Critic::Violation::sort_by_severity(@violations);
sort_by_location( @violation_objects )
Si necesitas ordenar las Violaciones por ubicación, usa esta útil rutina: 
@sorted = Perl::Critic::Violation::sort_by_location(@violations);
diagnostics()
Devuelve una cadena formateada que contiene una discusión completa de la motivación y los detalles del módulo de Política que creó esta Violación. Esta información se extrae automáticamente de la sección "DESCRIPTION" de la POD del módulo de Política.
policy()
Devuelve el nombre de la Perl::Critic::Policy que creó esta Violación.
source()
Devuelve la cadena de código fuente que causó esta excepción. Si el código abarca varias líneas (por ejemplo, sentencias multilínea, subrutinas u otros bloques), solo se devolverá la línea que contiene la violación.
element_class()
Devuelve la subclase PPI::Element del código que causó esta excepción.
set_format( $format )
Método de clase. Establece el formato para todos los objetos Violation cuando se evalúan en contexto de cadena. El valor predeterminado es '%d en la línea %l, columna %c. %e'. Consulta "SOBRECARGAS" para ver las opciones de formato.
get_format()
Método de clase. Devuelve el formato actual para todos los objetos Violation cuando se evalúan en contexto de cadena.
to_string()
Devuelve una representación en cadena de esta violación. El contenido de la cadena depende del valor actual de la variable de paquete $format. Consulta "SOBRECARGAS" para obtener detalles.

SOBRECARGAS

Perl::Critic::Violation sobrecarga el operador "" para producir mensajes concisos cuando se evalúa en contexto de cadena.

Los formatos son una combinación de literales y caracteres de escape similares a la forma en que funciona "sprintf". Si deseas conocer las capacidades específicas de formato, consulta String::Format. Los caracteres de escape válidos son:

Escape    Significado
-------   ----------------------------------------------------------------
%c        Número de columna donde ocurrió la violación
%d        Discusión diagnóstica completa de la violación (DESCRIPTION en POD)
%e        Explicación de la violación o números de página en PBP
%F        Solo el nombre del archivo lógico donde ocurrió la violación.
%f        Ruta al archivo lógico donde ocurrió la violación.
%G        Solo el nombre del archivo físico donde ocurrió la violación.
%g        Ruta al archivo físico donde ocurrió la violación.
%l        Número de línea lógica donde ocurrió la violación
%L        Número de línea física donde ocurrió la violación
%m        Breve descripción de la violación
%P        Nombre completo del módulo de Política que creó la violación
%p        Nombre de la Política sin el prefijo Perl::Critic::Policy::
%r        La cadena de código fuente que causó la violación
%C        La clase del PPI::Element que causó la violación
%s        El nivel de severidad de la violación

Perl::Critic::Violation(3pm)

NAME

Perl::Critic::Violation — Representación de un error de código.

SYNOPSIS

use Perl::Critic;
my $critic = Perl::Critic->new(@options);
my @violations = $critic->critique($file);
my $violation = shift @violations;

# Obtener información sobre la violación
my $message = $violation->formatted()
my $severity = $violation->severity()
my $score = $violation->score()
my $policy = $violation->policy()
my $line = $violation->line()
my $column = $violation->column()
my $filename = $violation->filename()

# Establecer el formato de salida
Perl::Critic::Violation::set_format("%l:%c:%m");

DESCRIPTION

A Perl::Critic::Violation object represents a single violation of a policy discovered by Perl::Critic.

The Perl::Critic::Violation module provides methods for accessing information about a violation, such as the message, severity, score, policy, and location (file, line, and column).

INTERFACE SUPPORT

Perl::Critic::Violation supports the following methods:

CONSTRUCTOR

There is no public constructor for Perl::Critic::Violation objects. They are created internally by Perl::Critic when violations are found.

METHODS

column
Returns the column number of the violation.
filename
Returns the filename in which the violation occurred. If the violation occurred in code provided as a string (not a file), this will return undef.
formatted
Returns the violation message, formatted according to the format string set by Perl::Critic::Violation::set_format().
line
Returns the line number of the violation.
message
Returns the raw violation message string.
policy
Returns the Perl::Critic::Policy object that generated the violation.
score
Returns the numerical score of the violation. This is used to calculate the overall score of the code being analyzed.
severity
Returns the severity level of the violation (e.g., 'low', 'medium', 'high').
set_format( $format_string )
Sets the format string to be used by the formatted() method. The format string supports the following placeholders:

See "Plain Old Comments (Not!)" in perlsyn for the details. Under normal circumstances, the values of %F, %f, and %l will match the values of %G, %g, and %L, respectively. In the presence of a "#line" directive, the values of %F, %f, and %l will change to take that directive into account. The values of %G, %g, and %L are unaffected by those directives.

Here are some examples:

Perl::Critic::Violation::set_format("%m at line %l, column %c.
");
# looks like "Mixed case variable name at line 6, column 23.
"
Perl::Critic::Violation::set_format("%m near '%r'
");
# looks like "Mixed case variable name near 'my $theGreatAnswer = 42;'
"
Perl::Critic::Violation::set_format("%l:%c:%p
");
# looks like "6:23:NamingConventions::Capitalization
"
Perl::Critic::Violation::set_format("%m at line %l. %e.
%d
");
# looks like "Mixed case variable name at line 6.  See page 44 of PBP.
  Conway's recommended naming convention is to use lower-case words
  separated by underscores.  Well-recognized acronyms can be in ALL
  CAPS, but must be separated by underscores from other parts of the
  name.
"
