NOMBRE

Perl::Critic::Policy::ControlStructures::ProhibitUnreachableCode - No escribir código después de un "die, exit, o next" incondicional.

AFILIACIÓN

Esta política es parte de la distribución central de Perl::Critic.

DESCRIPCIÓN

Esta política prohíbe el código que sigue a una sentencia que altera incondicionalmente el flujo del programa. Esto incluye llamadas a "exit", "die", "return", "next", "last" y "goto". Debido al uso común, "croak" y "confess" de Carp también están incluidos.

El código es alcanzable si se cumple alguna de las siguientes condiciones:

  • La sentencia que altera el flujo tiene una condición adjunta.
  • La sentencia está en el lado derecho de un operador "&&", "||", "//", "and", "or", o "err".
  • El código está prefijado con una etiqueta (potencialmente alcanzable a través de "goto").
  • El código es una subrutina.

EJEMPLOS

# no está bien
exit;
print "123\n";
# está bien
exit if !$xyz;
print "123\n";
# no está bien
for ( 1 .. 10 ) {
    next;
    print 1;
}
# está bien
for ( 1 .. 10 ) {
    next if $_ == 5;
    print 1;
}
# no está bien
sub foo {
    my $bar = shift;
    return;
    print 1;
}
# está bien
sub foo {
    my $bar = shift;
    return if $bar->baz();
    print 1;
}
# no está bien
die;
print "123\n";
# está bien
die;
LABEL: print "123\n";
# no está bien
croak;
do_something();
# está bien
croak;
sub do_something {}

CONFIGURACIÓN

Esta política no es configurable excepto por las opciones estándar.
