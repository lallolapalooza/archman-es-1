Perl::Critic::Exception::AggregateConfiguration(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Exception::AggregateConfiguration(3pm)

NOMBRE

Perl::Critic::Exception::AggregateConfiguration - Una colección de un conjunto de problemas encontrados en la configuración y/o opciones de línea de comandos.

DESCRIPCIÓN

Un conjunto de configuraciones puede tener múltiples problemas. Este es un objeto para recolectar todos los problemas encontrados para que el usuario pueda verlos en una sola ejecución.

SOPORTE DE INTERFAZ

Esta se considera una clase pública. Cualquier cambio en su interfaz pasará por un ciclo de depreciación.

MÉTODOS

añadir_excepción( $excepción )
Acumula el parámetro con el resto de las excepciones.
añadir_excepciones_de( $agregado )
Acumula las excepciones de otra instancia de esta clase.
excepciones()
Devuelve una referencia a un array de las excepciones recolectadas.
añadir_excepción_o_relanzar( $error_evaluado )
Si el parámetro es una instancia de Perl::Critic::Exception::Configuration o Perl::Critic::Exception::AggregateConfiguration, lo añade. De lo contrario, "die" con el parámetro, si es una referencia, o "confess" con él. Si el parámetro es falso, simplemente devuelve.
tiene_excepciones()
Indica si se han encontrado problemas de configuración.
mensaje_completo()
Concatena los mensajes de excepción. Ver "full_message" en Exception::Class.
