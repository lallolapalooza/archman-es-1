Perl__Critic__Policy__BuiltinFunctions__ProhibitUniversalIsa(3pm)

Perl::Critic::Policy::BuiltinFunctions::ProhibitUniversalIsa(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::BuiltinFunctions::ProhibitUniversalIsa(3pm)

NOMBRE

Perl::Critic::Policy::BuiltinFunctions::ProhibitUniversalIsa - Escribir "eval { $foo->isa($pkg) }" en lugar de "UNIVERSAL::isa($foo, $pkg)".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

print UNIVERSAL::isa($obj, 'Foo::Bar') ? 'yes' : 'no';  #no está bien
print eval { $obj->isa('Foo::Bar') } ? 'yes' : 'no';    #ok

A partir de Perl 5.9.3, el uso de "UNIVERSAL::isa" como función ha sido deprecado y se prefiere la forma de método. Anteriormente, se recomendaba la forma funcional porque daba resultados válidos incluso cuando el objeto era "undef" o un escalar sin bendecir. Sin embargo, la forma funcional hace imposible que los paquetes anulen isa(), una técnica que es crucial para implementar objetos simulados y algunas fachadas.

Otra alternativa a UNIVERSAL::isa es el método "_INSTANCE" de Param::Util, que es más rápido.

Vea el módulo CPAN UNIVERSAL::isa para una discusión incendiaria sobre este tema.

CONFIGURACIÓN

Esta política no es configurable, excepto por las opciones estándar.
