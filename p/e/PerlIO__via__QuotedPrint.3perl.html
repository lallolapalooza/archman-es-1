NOMBRE

PerlIO::via::QuotedPrint - capa PerlIO para cadenas quoted-printable

SINOPSIS

use PerlIO::via::QuotedPrint;
open(my $in, '<:via(QuotedPrint)', 'archivo.qp') or
    die "No se puede abrir archivo.qp para leer: $!\n";
open(my $out, '>:via(QuotedPrint)', 'archivo.qp') or
    die "No se puede abrir archivo.qp para escribir: $!\n";

DESCRIPCIÓN

Este módulo implementa una capa PerlIO que opera sobre archivos codificados en formato quoted-printable. Decodificará de quoted-printable al leer de un manejador y codificará a quoted-printable al escribir a un manejador.
