Perl::Critic::Policy::ValuesAndExpressions::ProhibitCommaSeparatedStatements(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ValuesAndExpressions::ProhibitCommaSeparatedStatements(3pm)

NOMBRE

Perl::Critic::Policy::ValuesAndExpressions::ProhibitCommaSeparatedStatements - No usar el operador coma como separador de sentencias.

AFILIACIÓN

Esta Política es parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

El separador de sentencias coma de Perl tiene una precedencia muy baja, lo que lleva a código que parece estar usando el separador de elementos de lista coma cuando en realidad no lo está haciendo. Conway sugiere no usar el separador de sentencias para prevenir esta situación.

La confusión que causa el separador de sentencias se debe principalmente a que los operadores de asignación tienen una precedencia mayor.

Por ejemplo, intentar combinar dos arrays en otro de esta forma no funcionará:

@x = @y, @z;

porque es equivalente a

@x = @y;
@z;

Por el contrario, existen las funciones incorporadas, como "print", que normalmente fuerzan el resto de la sentencia a un contexto de lista, pero no cuando se llaman como una subrutina.

Es poco probable que esto produzca lo que se pretende:

print join q{, }, 2, 3, 5, 7, ": los primos de un solo dígito.\n";

La solución obvia es añadir paréntesis. Colocarlos así

print join( q{, }, 2, 3, 5, 7 ), ": los primos de un solo dígito.\n";

funcionará, pero

print ( join q{, }, 2, 3, 5, 7 ), ": los primos de un solo dígito.\n";

no lo hará, porque es equivalente a

print( join q{, }, 2, 3, 5, 7 );
": los primos de un solo dígito.\n";

CONFIGURACIÓN

Esta política se puede configurar para permitir que la última sentencia en un bloque "map" o "grep" sea separada por coma. Esto se hace mediante la opción "allow_last_statement_to_be_comma_separated_in_map_and_grep" así:

[ValuesAndExpressions::ProhibitCommaSeparatedStatements]
allow_last_statement_to_be_comma_separated_in_map_and_grep = 1

Con esta opción desactivada (por defecto), la siguiente sentencia viola esta política.

%hash = map {$_, 1} @list;

Con esta opción activada, esta sentencia está permitida. Incluso si esta opción está desactivada, usar una coma gorda "=>" funciona, pero eso fuerza la estandarización del primer valor, lo cual puede no ser lo que quieres.

ERRORES CONOCIDOS

Necesita comprobar "scalar( algo, algo )".
