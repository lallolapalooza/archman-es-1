Perl::Critic::Policy::Variables::ProhibitPunctuationVars(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::Variables::ProhibitPunctuationVars(3pm)

NOMBRE

Perl::Critic::Policy::Variables::ProhibitPunctuationVars - Escribe "$EVAL_ERROR" en lugar de "$@".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

El vocabulario de Perl de variables de puntuación como $!, $., y $^ son quizás la principal causa de su reputación como línea de ruido inescrutable. La alternativa simple es usar el módulo English para darles nombres claros.

$| = undef;                      # no es correcto
use English qw(-no_match_vars);
local $OUTPUT_AUTOFLUSH = undef; # correcto

CONFIGURACIÓN

Las variables temporales $_ y @_ son muy comunes y bastante bien entendidas, por lo que están exentas de esta política. Lo mismo ocurre con el manejador de archivos predeterminado "_", utilizado con menos frecuencia por stat(). Todas las variables de captura de expresiones regulares ($1, $2, ...) también están exentas. $] está exenta porque no tiene un equivalente en English y Module::CoreList se basa en ella.

Puedes agregar más excepciones a tu configuración. En tu archivo perlcriticrc, agrega un bloque como este:

[Variables::ProhibitPunctuationVars]
allow = $@ $!

La propiedad "allow" debe ser una lista de variables de puntuación separadas por espacios en blanco.

Otras opciones de configuración controlan el análisis de cadenas interpoladas en la búsqueda de variables prohibidas. No tienen efecto en la detección de variables de puntuación fuera de las cadenas interpoladas.

[Variables::ProhibitPunctuationVars]
string_mode = thorough

La opción "string_mode" controla si y cómo se buscan las cadenas interpoladas para detectar variables de puntuación. Al configurar "string_mode = thorough", el valor predeterminado, se buscan casos especiales que pueden parecer variables de puntuación pero no lo son, por ejemplo $#foo, un contador de índice de matriz; $$bar, una desreferencia escalar; o $::baz, un símbolo global.

Al configurar "string_mode = disable", se ignoran por completo todas las cadenas interpoladas.

Al configurar "string_mode = simple", se utiliza una expresión regular simple para encontrar coincidencias. En este modo, las variables mágicas $$, "$'", $# y $: se ignoran dentro de las cadenas interpoladas debido al alto riesgo de falsos positivos. El modo simple se conserva de una versión anterior del código de cadenas interpoladas. Su uso solo se recomienda como solución alternativa si aparecen errores en el modo thorough.

La opción "string_mode" desaparecerá cuando se implemente el análisis de cadenas interpoladas en PPI. Consulte "ADVERTENCIAS" a continuación.

ERRORES

Las variables de puntuación que confunden el análisis del documento de PPI pueden no ser detectadas correctamente o en absoluto, y pueden impedir la detección de otras posteriores. En particular, se sabe que $" causa dificultades en cadenas interpoladas.

ADVERTENCIAS

ProhibitPunctuationVars se basa exclusivamente en PPI para encontrar variables de puntuación en el código, pero realiza todo el análisis de cadenas interpoladas por sí mismo. Cuando, en algún momento, esta funcionalidad se transfiera a PPI, ProhibitPunctuationVars dejará de realizar la interpolación y la opción "string_mode" desaparecerá.
