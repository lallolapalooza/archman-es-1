Perl::Critic::Policy::Modules::RequireFilenameMatchesPackage(3pm) Documentación de Perl aportada por el usuario Perl::Critic::Policy::Modules::RequireFilenameMatchesPackage(3pm)

NOMBRE

Perl::Critic::Policy::Modules::RequireFilenameMatchesPackage - La declaración del paquete debe coincidir con el nombre del archivo.

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

La declaración del paquete siempre debe coincidir con el nombre del archivo que la contiene. Por ejemplo, "package Foo::Bar;" debería estar en un archivo llamado "Bar.pm". Esto facilita a los desarrolladores determinar de qué archivo proviene un símbolo cuando lo ven en su código. Por ejemplo, al ver "Foo::Bar->new()", debería poder encontrar la definición de la clase para "Foo::Bar" en un archivo llamado Bar.pm.

Por lo tanto, esta política requiere que el último componente del primer nombre de paquete declarado en el archivo coincida con el nombre de archivo físico. O si se utilizan directivas "#line", entonces debe coincidir con el nombre de archivo lógico definido por la directiva "#line" prevaleciente en el punto de la declaración del paquete. Aquí hay algunos ejemplos:

# Cualquiera de los siguientes en el archivo "Foo/Bar/Baz.pm":
package Foo::Bar::Baz;     # ok
package Baz;               # ok
package Nuts;              # no es ok (no coincide con el nombre de archivo físico)
# usando directivas #line en el archivo "Foo/Bar/Baz.pm":
#line 1 Nuts.pm
package Nuts;             # ok
package Baz;              # no es ok (contradice la directiva #line)

Si el archivo no se considera un módulo, entonces esta política no se aplica. Además, si el primer espacio de nombres de paquete que se encuentra en el archivo es "main", entonces esta política no se aplica.

CONFIGURACIÓN

Esta política no es configurable, excepto por las opciones estándar.
