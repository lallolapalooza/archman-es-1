PEM_read_bio_ex(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PEM_READ_BIO_EX(3ssl) OpenSSL PEM_READ_BIO_EX(3ssl)

NOMBRE

PEM_read_bio_ex, PEM_FLAG_SECURE, PEM_FLAG_EAY_COMPATIBLE, PEM_FLAG_ONLY_B64 - leer archivos en formato PEM con procesamiento personalizado

SINOPSIS

#include <openssl/pem.h>
#define PEM_FLAG_SECURE             0x1
#define PEM_FLAG_EAY_COMPATIBLE     0x2
#define PEM_FLAG_ONLY_B64           0x4
int PEM_read_bio_ex(BIO *in, char **name, char **header,
                    unsigned char **data, long *len, unsigned int flags);

DESCRIPCIÓN

PEM_read_bio_ex() lee datos en formato PEM de un BIO de entrada, produciendo el nombre del tipo de datos contenidos, la información de la cabecera relativa a los datos posiblemente cifrados, y la carga útil de datos binarios (después de la decodificación base64). Generalmente, solo debe usarse para implementar funciones de la familia PEM_read_bio para tipos de datos específicos u otros usos, pero se expone para permitir una mayor flexibilidad sobre cómo se realiza el procesamiento, si es necesario.

Si se establece PEM_FLAG_SECURE, los búferes intermedios utilizados para leer líneas de entrada se asignan desde el heap seguro.

Si se establece PEM_FLAG_EAY_COMPATIBLE, se utiliza un algoritmo simple para eliminar los caracteres de espacio en blanco y control del final de cada línea, para ser compatible con el comportamiento histórico de PEM_read_bio().

Si se establece PEM_FLAG_ONLY_B64, se requiere que todos los caracteres sean caracteres base64 válidos (o nuevas líneas); los caracteres no base64 se tratan como fin de entrada.

Si no se establece ni PEM_FLAG_EAY_COMPATIBLE ni PEM_FLAG_ONLY_B64, se ignoran los caracteres de control.

Si se establecen tanto PEM_FLAG_EAY_COMPATIBLE como PEM_FLAG_ONLY_B64, se devuelve un error; estas opciones no son compatibles entre sí.

NOTAS

El llamador debe liberar el almacenamiento asignado para *name, *header y *data. Si se estableció PEM_FLAG_SECURE, use OPENSSL_secure_free(); de lo contrario, se utiliza OPENSSL_free().

VALORES DE RETORNO

PEM_read_bio_ex() devuelve 1 para éxito o 0 para fallo.

VER TAMBIÉN

PEM_bytes_read_bio(3)

HISTORIA

La función PEM_read_bio_ex() se añadió en OpenSSL 1.1.1.
