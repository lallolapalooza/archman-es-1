Perl__Critic__OptionsProcessor(3pm)

Paquete: perl-perl-critic

Perl::Critic::OptionsProcessor(3pm) Documentación aportada por el usuario de Perl Perl::Critic::OptionsProcessor(3pm)

NOMBRE

Perl::Critic::OptionsProcessor - Los valores predeterminados de configuración global, combinados con los valores de la línea de comandos.

DESCRIPCIÓN

Esta es una clase auxiliar que encapsula los parámetros predeterminados para construir un objeto Perl::Critic::Config. No hay partes que el usuario pueda reparar aquí.

SOPORTE DE INTERFAZ

Esta se considera una clase no pública. Su interfaz está sujeta a cambios sin previo aviso.

CONSTRUCTOR

new( %PARAMETROS_POR_DEFECTO )
Devuelve una referencia a un nuevo objeto "Perl::Critic::OptionsProcessor". Puede anular los valores predeterminados codificados pasando pares nombre-valor que corresponden a los métodos que se enumeran a continuación.

Normalmente, esto solo lo invoca Perl::Critic::UserProfile, que pasa los valores globales de un archivo .perlcriticrc. Este objeto no contiene información para Políticas individuales.

MÉTODOS

exclude()
Devuelve una referencia a una lista de los patrones de exclusión predeterminados. Si hay patrones de exclusión predeterminados, la lista estará vacía.
force()
Devuelve el valor predeterminado del indicador "force" (ya sea 1 o 0).
include()
Devuelve una referencia a una lista de los patrones de inclusión predeterminados. Si hay patrones de exclusión predeterminados, la lista estará vacía.
only()
Devuelve el valor predeterminado del indicador "only" (ya sea 1 o 0).
profile_strictness()
Devuelve el valor predeterminado de "profile_strictness" como una cadena no validada.
single_policy()
Devuelve el patrón predeterminado de "single-policy". (Como cadena).
severity()
Devuelve la configuración predeterminada de "severity". (1..5).
theme()
Devuelve la configuración predeterminada de "theme". (Como cadena).
top()
Devuelve la configuración predeterminada de "top". (Ya sea 0 o un entero positivo).
verbose()
Devuelve la configuración predeterminada de "verbose". (Ya sea un número o una cadena de formato).
color()
Devuelve la configuración predeterminada de "color". (Ya sea 1 o 0).
pager()
Devuelve la configuración predeterminada de "pager". (Ya sea una cadena vacía o la cadena del comando del paginador).
allow_unsafe()
Devuelve la configuración predeterminada de "allow-unsafe". (Ya sea 1 o 0).
criticism_fatal()
Devuelve la configuración predeterminada de "criticism-fatal" (ya sea 1 o 0).
color_severity_highest()
Devuelve el color que se utilizará para colorear las violaciones de mayor gravedad.
color_severity_high()
Devuelve el color que se utilizará para colorear las violaciones de alta gravedad.
color_severity_medium()
Devuelve el color que se utilizará para colorear las violaciones de gravedad media.
color_severity_low()
Devuelve el color que se utilizará para colorear las violaciones de baja gravedad.
color_severity_lowest()
Devuelve el color que se utilizará para colorear las violaciones de menor gravedad.
program_extensions()
Devuelve una referencia al array de extensiones de nombres de archivo que se interpretarán como programas Perl.

VER TAMBIÉN

Perl::Critic::Config, Perl::Critic::UserProfile
