NOMBRE

Perl::Critic::Policy::ValuesAndExpressions::ProhibitQuotesAsQuotelikeOperatorDelimiters - No usar comillas ("'", """, "`") como delimitadores para los operadores similares a comillas.

AFILIACIÓN

Esta política es parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Con la obvia excepción de usar comillas simples para prevenir la interpolación, usar comillas con los operadores similares a comillas un poco que derrota el propósito de ellos y produce código ofuscado, causando problemas para los mantenedores futuros y sus editores/IDEs.

$x = q"q";                # no es correcto
$x = q'q';                # no es correcto
$x = q`q`;                # no es correcto
$x = qq"q";               # no es correcto
$x = qr"r";               # no es correcto
$x = qw"w";               # no es correcto
$x = qx`date`;            # no es correcto
$x =~ m"m";               # no es correcto
$x =~ s"s"x";             # no es correcto
$x =~ tr"t"r";            # no es correcto
$x =~ y"x"y";             # no es correcto
$x =~ m'$x';              # correcto
$x =~ s'$x'y';            # correcto
$x = qr'$x'm;             # correcto
$x = qx'finger foo@bar';  # correcto

CONFIGURACIÓN

Esta política tiene tres opciones: "single_quote_allowed_operators", "double_quote_allowed_operators", y "back_quote_allowed_operators", que controlan qué operadores tienen permitido usar cada uno de "'", """, "`" como delimitadores, respectivamente.

Los valores permitidos para estas opciones son una selección separada por espacios de los operadores "m", "q", "qq", "qr", "qw", "qx", "s", "tr" y "y".

Por defecto, las comillas dobles y las comillas invertidas (backticks) no tienen permitido ser delimitadores para ningún operador y las comillas simples tienen permitido ser delimitadores para los operadores "m", "qr", "qx" y "s". Estos valores por defecto son equivalentes a tener lo siguiente en tu archivo .perlcriticrc:

[ValuesAndExpressions::ProhibitQuotesAsQuotelikeOperatorDelimiters]
single_quote_allowed_operators = m s qr qx
double_quote_allowed_operators =
back_quote_allowed_operators =
