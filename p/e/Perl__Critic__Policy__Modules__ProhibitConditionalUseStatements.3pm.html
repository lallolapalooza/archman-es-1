Perl::Critic::Policy::Modules::ProhibitConditionalUseStatements(3pm) Documentación de Perl aportada por el usuario Perl::Critic::Policy::Modules::ProhibitConditionalUseStatements(3pm)

NOMBRE

Perl::Critic::Policy::Modules::ProhibitConditionalUseStatements - Evitar poner lógica condicional alrededor de las inclusiones en tiempo de compilación.

AFILIACIÓN

Esta Política es parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Los módulos incluidos a través de "use" se cargan en tiempo de compilación. Poner lógica condicional alrededor de la declaración "use" no tiene ningún efecto sobre si el módulo se cargará. Hacerlo también puede servir para confundir al lector sobre la intención original del autor.

Si necesita cargar un módulo condicionalmente, debería usar "require" en su lugar.

Esta política detectará las siguientes formas de declaraciones condicionales de "use":

# if-elsif-else
if ($a == 1) { use Module; }
if ($a == 1) { } elsif ($a == 2) { use Module; }
if ($a == 1) { } else { use Module; }
# for/foreach
for (1..$a) { use Module; }
foreach (@a) { use Module; }
# while
while ($a == 1) { use Module; }
# unless
unless ($a == 1) { use Module; }
# until
until ($a == 1) { use Module; }
# do-condition
do { use Module; } if $a == 1;
do { use Module; } while $a == 1;
do { use Module; } unless $a == 1;
do { use Module; } until $a == 1;
# operator-do
$a == 1 || do { use Module; };
$a == 1 && do { use Module; };
$a == 1 or do { use Module; };
$a == 1 and do { use Module; };
# eval no string
eval { use Module; };

Incluir un módulo a través de "use" en bloques vacíos, bloques do independientes o evals de cadena está permitido.

# bloque vacío
{ use Module; }
# do
do { use Module; }
# eval de cadena
eval "use Module";

CONFIGURACIÓN

Esta Política no es configurable excepto por las opciones estándar.
