Vista general de Pegex

En el siguiente diagrama, hay un lenguaje simple llamado Foo. El diagrama muestra cómo Pegex puede tomar una gramática de texto que define Foo y generar un analizador que puede analizar fuentes de Foo en datos (árboles de sintaxis abstracta).

Para su información (FYI)

Pegex se autoaloja. Esto significa que la sintaxis del lenguaje de gramática de Pegex se define mediante una gramática de Pegex. Esto es importante porque (al igual que cualquier lenguaje basado en Pegex) facilita la portabilidad a nuevos lenguajes de programación. Puede encontrar la gramática de Pegex para gramáticas de Pegex aquí: http://github.com/ingydotnet/pegex-pgx/.

Pegex se inspiró originalmente en las Reglas de Perl 6. También toma ideas del módulo de Perl 5 de Damian Conway, Regexp::Grammars. Pegex intenta tomar las mejores ideas de estas grandes obras y hacer que funcionen en tantos lenguajes como sea posible. Eso es Acmeísmo.

Trucos de autocompilación

Puede divertirse usando Pegex para compilarse a sí mismo. Primero, obtenga el repositorio de gramática de Pegex:

git clone git://github.com/ingydotnet/pegex-pgx.git
cd pegex-pgx

Luego, analice y muestre la gramática de Pegex con Pegex:

perl -MXXX -MPegex -e 'XXX pegex("pegex.pgx")->parse("pegex.pgx")'

Para una vista diferente del árbol de datos, intente:

perl -MXXX -MPegex -e 'XXX pegex("pegex.pgx", receiver => "Pegex::Tree")->parse("pegex.pgx")'

Finalmente, para emular el compilador de Pegex, haga esto:

perl -MXXX -MPegex -e 'XXX pegex("pegex.pgx", receiver => "Pegex::Pegex::AST")->parse("pegex.pgx")'

Esto especifica una clase de "recepción" que puede dar forma a los resultados en algo útil. De hecho, esta es la esencia exacta de Pegex::Grammar::Pegex.

Un EJEMPLO del mundo real

TestML es un nuevo lenguaje de pruebas unitarias Acmeísta. Es perfecto para software que necesita ejecutarse de manera equivalente en más de un lenguaje. De hecho, ¡¡el propio Pegex se prueba con TestML!!

TestML tiene una gramática de especificación de lenguaje: http://www.testml.org/specification/language/

La implementación de Perl6 de TestML utiliza esta gramática en: https://github.com/ingydotnet/testml-pm6/blob/master/lib/TestML/Parser/Grammar.pm

Todas las demás implementaciones de TestML utilizan esta gramática de Pegex: https://github.com/ingydotnet/testml-pgx/blob/master/testml.pgx

En Perl 5, Pegex::Compiler se utiliza para compilar la gramática en esta simple estructura de datos (mostrada en YAML): https://github.com/ingydotnet/testml-pgx/blob/master/testml.pgx.yaml

La gramática también se puede precompilar a JSON: https://github.com/ingydotnet/testml-pgx/blob/master/testml.pgx.json

Pegex::Compiler compila aún más esto en un árbol de gramática solo para Perl 5, que se convierte en este módulo: https://github.com/ingydotnet/testml-pm/blob/master/lib/TestML/Compiler/Pegex/Grammar.pm

TestML::Parser::Grammar es una subclase de Pegex::Grammar. Se puede utilizar para analizar archivos TestML. TestML::Parser llama al método parse() de la gramática con un objeto TestML::AST que recibe callbacks cuando varias reglas coinciden, y utiliza la información para construir un objeto TestML::Document.

Por lo tanto, TestML es un lenguaje Acmeísta escrito en Pegex. Se puede portar fácilmente a todos los lenguajes donde existe Pegex. De hecho, ¡debe portarse a esos lenguajes para probar la nueva implementación de Pegex!
