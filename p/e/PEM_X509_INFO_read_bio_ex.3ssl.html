PEM_X509_INFO_read_bio_ex(3ssl)

Paquete: openssl

Licencias: Apache-2.0

PEM_X509_INFO_READ_BIO_EX(3ssl) OpenSSL PEM_X509_INFO_READ_BIO_EX(3ssl)

NOMBRE

PEM_X509_INFO_read_ex, PEM_X509_INFO_read, PEM_X509_INFO_read_bio_ex, PEM_X509_INFO_read_bio - leer estructuras de datos codificadas en PEM en uno o más objetos X509_INFO

SINOPSIS

#include <openssl/pem.h>
STACK_OF(X509_INFO) *PEM_X509_INFO_read_ex(FILE *fp, STACK_OF(X509_INFO) *sk,
                                           pem_password_cb *cb, void *u,
                                           OSSL_LIB_CTX *libctx,
                                           const char *propq);
STACK_OF(X509_INFO) *PEM_X509_INFO_read(FILE *fp, STACK_OF(X509_INFO) *sk,
                                        pem_password_cb *cb, void *u);
STACK_OF(X509_INFO) *PEM_X509_INFO_read_bio_ex(BIO *bio,
                                               STACK_OF(X509_INFO) *sk,
                                               pem_password_cb *cb, void *u,
                                               OSSL_LIB_CTX *libctx,
                                               const char *propq);
STACK_OF(X509_INFO) *PEM_X509_INFO_read_bio(BIO *bp, STACK_OF(X509_INFO) *sk,
                                            pem_password_cb *cb, void *u);

DESCRIPCIÓN

PEM_X509_INFO_read_ex() carga los objetos X509_INFO desde un archivo fp.

PEM_X509_INFO_read() es similar a PEM_X509_INFO_read_ex() pero utiliza el contexto de biblioteca predeterminado (NULL) libctx y una consulta de propiedad vacía propq.

PEM_X509_INFO_read_bio_ex() carga los objetos X509_INFO utilizando un bio bp.

PEM_X509_INFO_read_bio() es similar a PEM_X509_INFO_read_bio_ex() pero utiliza el contexto de biblioteca predeterminado (NULL) libctx y una consulta de propiedad vacía propq.

Cada uno de los objetos X509_INFO cargados puede contener una CRL, un certificado y/o una clave privada. Los elementos se leen secuencialmente y, en la medida en que sean de un tipo diferente a los elementos leídos antes, se combinan en el mismo objeto X509_INFO. La idea detrás de esto es que, por ejemplo, si un certificado va seguido de una clave privada, se supone que la clave privada corresponde al certificado.

Si la pila de entrada sk es NULL, se asigna una nueva pila; de lo contrario, se extiende la pila dada.

Los parámetros opcionales cb y u se pueden usar para proporcionar una frase de contraseña necesaria para descifrar estructuras PEM cifradas (normalmente solo claves privadas). Consulte PEM_read_bio_PrivateKey(3) y passphrase-encoding(7) para obtener detalles.

El contexto de biblioteca libctx y la consulta de propiedad propq se utilizan para obtener algoritmos de los proveedores.

VALORES DE RETORNO

PEM_X509_INFO_read_ex(), PEM_X509_INFO_read(), PEM_X509_INFO_read_bio_ex() y PEM_X509_INFO_read_bio() devuelven una pila de objetos X509_INFO o NULL en caso de error.

VER TAMBIÉN

PEM_read_bio_ex(3), PEM_read_bio_PrivateKey(3), passphrase-encoding(7)

HISTORIA

Las funciones PEM_X509_INFO_read_ex() y PEM_X509_INFO_read_bio_ex() se añadieron en OpenSSL 3.0.
