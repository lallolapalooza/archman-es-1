Perl::Critic::Policy::Variables::RequireLocalizedPunctuationVars(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::Variables::RequireLocalizedPunctuationVars(3pm)

NOMBRE

Perl::Critic::Policy::Variables::RequireLocalizedPunctuationVars - Las variables mágicas deben asignarse como "local".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Las variables de puntuación (y sus equivalentes de English.pm) son variables globales. Jugar con variables globales es peligroso en un programa complejo, ya que puede provocar errores muy sutiles y difíciles de corregir. Si debes cambiar una variable mágica en un programa no trivial, hazlo en un ámbito local.

Por ejemplo, para incorporar un manejador de archivos en un escalar, es común establecer el separador de registros en undef en lugar de una nueva línea. Si eliges hacer esto (en lugar de usar Path::Tiny!) asegúrate de localizar la variable global y cambiarla durante el menor tiempo posible.

# MALO:
$/ = undef;
my $content = <$fh>;
# MEJOR:
my $content;
{
    local $/ = undef;
    $content = <$fh>;
}
# Un modismo popular:
my $content = do { local $/ = undef; <$fh> };

Esta política también permite el uso de "my". Perl impide el uso de "my" con variables de puntuación "apropiadas", pero permite $a, @ARGV, los nombres declarados por English, etc. Sin embargo, no es una buena práctica de codificación, y esta política específica no se preocupa por quejarse de ello.

Hay exenciones para $_ y @_, y el equivalente en inglés $ARG.

CONFIGURACIÓN

Puedes configurar tus propias exenciones usando la opción "allow":

[Variables::RequireLocalizedPunctuationVars]
allow = @ARGV $ARGV

Estas se añaden a las exenciones predeterminadas.
