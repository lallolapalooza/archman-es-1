NOMBRE

Pegex::Regex - Usar Pegex como una Expresión Regular

SINOPSIS

{
    # Activar expresiones regulares de Pegex en el ámbito léxico.
    use Pegex::Regex;
    my $gramática = qr{$texto_gramática}x;
    $texto =~ $gramática;
    my $resultado = \%/;
    # Desactivar Pegex en este ámbito.
    no Pegex::Regex;
}

DESCRIPCIÓN

Este es un módulo de azúcar trivial que te permite usar gramáticas analizadoras de Pegex como expresiones regulares, si te gusta ese tipo de cosas.

Básicamente, es un clon de la API del módulo Regexp::Grammars de Damian Conway. Pones una gramática en un "qr{...}x" y la aplicas a la cadena de entrada que quieres analizar. Si el análisis es exitoso, obtienes una estructura de datos del contenido en "%/".

En mi opinión, construir un analizador de descenso recursivo completamente dentro de una expresión regular no es la forma más clara de codificar. Pero, por supuesto, TMTOWTDI. :)

NOTA

Este módulo es solo para diversión experimental. Consulta Pegex para saber la forma correcta de usar el framework de análisis de Pegex.

TMTOWTDI

Aquí tienes un fragmento de código Pegex::Regex:

use Pegex::Regex;
$texto =~ qr{... Texto de la gramática Pegex ...};
$datos = \%/;

Y el código Pegex equivalente:

use Pegex;
my $datos = pegex('... Texto de la gramática Pegex ...')->parse($texto);

ADVERTENCIA

Esta droga de entrada, er, módulo, técnicamente ni siquiera debería funcionar.

Convierte tu "gramática dentro de una expresión regular" en una Pegex::Grammar usando la sobrecarga qr{}, y luego convierte tu expresión regular en sí misma en un *shim* que llama al método de análisis por ti. Esto es altamente mágico y técnicamente hace una llamada reentrante al motor de expresiones regulares, lo cual aún no está soportado. Úsalo bajo tu propio riesgo.

Mejor aún, hazte un favor y aprende a usar el conjunto de herramientas de Pegex sin este azúcar ::Regex. ":-)"
