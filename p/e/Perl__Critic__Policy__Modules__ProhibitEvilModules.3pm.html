Perl::Critic::Policy::Modules::ProhibitEvilModules(3pm) Documentación Perl de Contribución de Usuarios Perl::Critic::Policy::Modules::ProhibitEvilModules(3pm)

NOMBRE

Perl::Critic::Policy::Modules::ProhibitEvilModules - Prohibir módulos que no están aprobados por tu tienda.

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Utiliza esta política si deseas prohibir el uso de módulos específicos. Estos pueden ser módulos que consideres obsoletos, con errores, sin soporte, inseguros o que simplemente no te gustan.

CONFIGURACIÓN

El conjunto de módulos prohibidos se puede configurar mediante las opciones "modules" y "modules_file".

El valor de "modules" debe ser una cadena de nombres de módulo completamente calificados y/o expresiones regulares separadas por espacios. Un ejemplo de prohibición de dos módulos específicos en un archivo .perlcriticrc:

[Modules::ProhibitEvilModules]
modules = Getopt::Std Autoload

Las expresiones regulares se identifican por valores que comienzan y terminan con barras. Cualquier módulo cuyo nombre coincida con "m/patrón/" será prohibido. Por ejemplo:

[Modules::ProhibitEvilModules]
modules = /Acme::/

causará que todos los módulos que coincidan con "m/Acme::/" sean prohibidos.

Además, puedes anular el mensaje predeterminado ("Módulo prohibido "módulo" utilizado") con el tuyo propio, para dar sugerencias para acciones alternativas. Para hacerlo, coloca tu mensaje entre llaves después del nombre del módulo o la expresión regular. Como esto:

[Modules::ProhibitEvilModules]
modules = Fatal {Se encontró uso de Fatal. Usa autodie en su lugar} /Acme::/ {No usamos módulos de broma}

De manera similar, la opción "modules_file" proporciona el nombre de un archivo que contiene especificaciones para módulos prohibidos. Solo se permite una especificación de módulo por línea y los comentarios comienzan con una almohadilla (#) y continúan hasta el final de la línea; no se necesitan llaves para delimitar mensajes:

Evil     # Prohibir el módulo "Evil" y usar el mensaje predeterminado.
# Prohibir el módulo "Fatal" y dar un mensaje de reemplazo.
Fatal Se encontró uso de Fatal. Usa autodie en su lugar.
# Usar una expresión regular.
/Acme::/     No usamos módulos de broma.

Por defecto, se informan los módulos que han sido desaprobados por los desarrolladores de Perl 5; en el momento de escribir esto, son Class::ISA, Pod::Plainer, Shell y Switch. Especificar un valor para la opción "modules" anulará esto.

NOTAS

Ten en cuenta que esta política no se aplica a los pragmas.
