Perl::Critic::Policy::NamingConventions::ProhibitAmbiguousNames(3pm) Documentación de Perl aportada por el usuario Perl::Critic::Policy::NamingConventions::ProhibitAmbiguousNames(3pm)

NOMBRE

Perl::Critic::Policy::NamingConventions::ProhibitAmbiguousNames - No uses nombres de variables o subrutinas vagos como 'last' o 'record'.

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Conway enumera una colección de palabras inglesas que son altamente ambiguas como nombres de variables o subrutinas. Por ejemplo, $last puede significar anterior o final.

Esta política comprueba una lista de palabras ambiguas para nombres de variables.

CONFIGURACIÓN

La lista por defecto de palabras prohibidas es:

abstract bases close contract last left no record right second set

Esta lista puede cambiarse dando un valor para "forbid" de una serie de palabras prohibidas separadas por espacios.

Por ejemplo, si decides que "bases" es un nombre válido para variables (p. ej., en bioinformática), entonces pon algo como lo siguiente en "$HOME/.perlcriticrc":

[NamingConventions::ProhibitAmbiguousNames]
forbid = last set left right no abstract contract record second close

ERRORES

Actualmente, esta política comprueba la variable y el nombre de la subrutina completos, no partes del nombre. Por ejemplo, detecta $last pero no $last_record. Esperemos que las versiones futuras detecten ambos casos.

Algunas sentencias de variables serán falsos positivos si tienen asignaciones donde el lado derecho utiliza nombres prohibidos. Por ejemplo, en este caso, "last" activa incorrectamente una violación.

my $previous_record = $Foo::last;
