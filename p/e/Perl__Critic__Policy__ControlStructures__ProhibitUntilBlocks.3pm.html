Perl::Critic::Policy::ControlStructures::ProhibitUntilBlocks(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ControlStructures::ProhibitUntilBlocks(3pm)

NOMBRE

Perl::Critic::Policy::ControlStructures::ProhibitUntilBlocks - Escribe "while(! $condición)" en lugar de "until($condición)".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Conway desaconseja el uso de "until" porque conduce a dobles negaciones que son difíciles de entender. En su lugar, invierte la lógica y usa "while".

until($condición)     { hacer_algo() } # no está bien
until(! $no_bandera)     { hacer_algo() } # realmente mal
while( ! $condición)  { hacer_algo() } # está bien

Esta política solo cubre la forma de bloque de "until". Para la variedad postfija, consulta "ProhibitPostfixControls".

CONFIGURACIÓN

Esta política no es configurable excepto por las opciones estándar.

VER TAMBIÉN
