Perl::Critic::Command(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Command(3pm)

NOMBRE

Perl::Critic::Command - Las entrañas de perlcritic.

SINOPSIS

use Perl::Critic::Command qw< run >;
local @ARGV = qw< --statistics-only lib >;
run();

DESCRIPCIÓN

Esta es la implementación del comando perlcritic. Puedes usar esto para ejecutar el comando sin pasar por un intérprete de comandos.

SOPORTE DE INTERFAZ

Esta se considera una clase pública. Sin embargo, su interfaz es experimental y probablemente cambiará.

SUBRUTINAS IMPORTABLES

run()
Realiza el equivalente del comando perlcritic. Desafortunadamente, en la actualidad, esto no toma ningún parámetro sino que usa @ARGV para obtener su entrada. No cuentes con que esto cambie; no cuentes con la interfaz actual.

POR HACER

Hacer que run() tome parámetros. El equivalente de @ARGV debería pasarse como una referencia.

Convertir esto en un objeto.
