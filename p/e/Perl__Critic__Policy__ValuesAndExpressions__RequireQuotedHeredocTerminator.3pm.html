Perl::Critic::Policy::ValuesAndExpressions::RequireQuotedHeredocTerminator(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ValuesAndExpressions::RequireQuotedHeredocTerminator(3pm)

NOMBRE

Perl::Critic::Policy::ValuesAndExpressions::RequireQuotedHeredocTerminator - Escribe " print <<'THE_END' " o " print <<"THE_END" ".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Poner comillas simples o dobles alrededor del terminador de tu HEREDOC hace obvio para el lector si el contenido se interpolará o no.

print <<END_MESSAGE;    # no está bien
Hola Mundo
END_MESSAGE
print <<'END_MESSAGE';  # está bien
Hola Mundo
END_MESSAGE
print <<"END_MESSAGE";  # está bien
$saludo
END_MESSAGE

CONFIGURACIÓN

Esta política no es configurable, excepto por las opciones estándar.
