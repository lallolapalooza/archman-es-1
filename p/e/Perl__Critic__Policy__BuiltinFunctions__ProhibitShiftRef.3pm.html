Perl::Critic::Policy::BuiltinFunctions::ProhibitShiftRef(3pm) Documentación de Perl aportada por el usuario Perl::Critic::Policy::BuiltinFunctions::ProhibitShiftRef(3pm)

NOMBRE

Perl::Critic::Policy::BuiltinFunctions::ProhibitShiftRef - Prohibir "\shift" en el código

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Prohibir el uso de "\shift", ya que está asociado con errores en Perl y sus módulos.

Antecedentes

A menudo, "\shift" se utiliza para crear referencias que actúan de forma muy similar a un alias. Al crear un "alias" con nombre, el código se vuelve más legible. Por ejemplo:

sub rutina {
    my $cadena_larga = \shift;
    print $$cadena_larga;
}

es más legible que

sub rutina {
    print $_[0];    # cadena_larga
}

Desafortunadamente, esta legibilidad adicional trae consigo problemas nuevos y emocionantes, detallados en la siguiente sección.

Problemas con "\shift"

Al evitar "\shift", se pueden evitar varios problemas en Perl, incluyendo:

Fuga de memoria desde Perl 5.22
El problema #126676 se introdujo en Perl 5.21.4 y se activa cuando se usa "\shift". El error no se ha resuelto a partir de Perl 5.28.

En resumen, el error hace que el contador de referencias de la variable aliasada se incremente al ejecutar la subrutina, pero no se decrementa después de que la subrutina retorna. Además de fugas de memoria, este problema también puede retrasar la limpieza de objetos hasta la Destrucción Global, lo que puede causar problemas adicionales.

Para más información, véase https://rt.perl.org/Public/Bug/Display.html?id=126676.

Cuelgues de Devel::Cover
Un problema separado y de larga data en Devel::Cover (desde al menos 1.21) hace que el código de prueba se cuelgue ocasionalmente (segfault). Esto evita que se escriban los datos de cobertura, lo que resulta en métricas malas.

El error en sí no es causado por "\shift", sino que aparece en código como el siguiente:

sub mi_abrir {
    open ${ \$_[0] }, ">test";
}

Sin embargo, este código rara vez se vería en producción. Se manifestaría más probablemente con "\shift", como ocurre a continuación:

sub mi_abrir {
    my $fh = \shift;
    open $$fh, ">test";
}

Por lo tanto, aunque "\shift" no es la causa, a menudo está asociado con el problema.

Para más información, véase https://github.com/pjcj/Devel--Cover/issues/125.

CONFIGURACIÓN

Esta política no es configurable, excepto por las opciones estándar.
