NOMBRE

Perl::Critic::Policy::NamingConventions::Capitalization - Distingue diferentes componentes del programa por mayúsculas/minúsculas.

AFILIACIÓN

Esta política es parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Conway recomienda distinguir diferentes componentes del programa por mayúsculas/minúsculas.

Las subrutinas, métodos y variables normales están todas en minúsculas.

my $foo;            # ok
my $foo_bar;        # ok
sub foo {}          # ok
sub foo_bar {}      # ok
my $Foo;            # no ok
my $foo_Bar;        # no ok
sub Foo     {}      # no ok
sub foo_Bar {}      # no ok

Los nombres de paquetes y clases están en mayúsculas.

package IO::Thing;     # ok
package Web::FooBar    # ok
package foo;           # no ok
package foo::Bar;      # no ok

Las constantes están en mayúsculas.

Readonly::Scalar my $FOO = 42;  # ok
Readonly::Scalar my $foo = 42;  # no ok

Existen otras opiniones sobre los detalles, por ejemplo, en perlstyle. Esta política se puede configurar para que coincida con casi cualquier estilo que se te ocurra.

CONFIGURACIÓN

Puedes especificar reglas de capitalización para las siguientes cosas: "packages", "subroutines", "local_lexical_variables", "scoped_lexical_variables", "file_lexical_variables", "global_variables", "constants" y "labels".

"constants" son cosas declaradas mediante constant o Readonly.

use constant FOO => 193;
Readonly::Array my @BAR => qw< a b c >;

"global_variables" son cualquier cosa declarada usando "local", "our" o vars. "file_lexical_variables" son variables declaradas en el ámbito del archivo.

"scoped_lexical_variables" son variables declaradas dentro de bloques vacíos que están fuera de cualquier subrutina u otras estructuras de control; estas se crean generalmente para limitar el ámbito de las variables a un subconjunto dado de subrutinas. Por ejemplo:

sub foo { ... }
{
    my $thingy;
    sub bar { ... $thingy ... }
    sub baz { ... $thingy ... }
}

Todas las demás declaraciones de variables se consideran "local_lexical_variables".

Cada una de las opciones "packages", "subroutines", "local_lexical_variables", "scoped_lexical_variables", "file_lexical_variables", "global_variables", "constants" y "labels" puede especificarse como uno de ":single_case", ":all_lower", ":all_upper:", ":starts_with_lower", ":starts_with_upper", o ":no_restriction" o una expresión regular; cualquier valor que no empiece con dos puntos, ":", se considera una expresión regular. La etiqueta ":single_case" significa que un nombre puede ser completamente en minúsculas o completamente en mayúsculas. Si se especifica una expresión regular, se rodea de "\A" y "\z".

"packages" tiene como valor por defecto ":starts_with_upper". "subroutines", "local_lexical_variables", "scoped_lexical_variables", "file_lexical_variables" y "global_variables" tienen como valor por defecto ":single_case". Y "constants" y "labels" tienen como valor por defecto ":all_upper".

Hay opciones correspondientes de "package_exemptions", "subroutine_exemptions", "local_lexical_variable_exemptions", "scoped_lexical_variable_exemptions", "file_lexical_variable_exemptions", "global_variable_exemptions", "constant_exemptions" y "label_exemptions" que son listas de expresiones regulares para eximir de la regla de capitalización correspondiente. Estos valores también terminan siendo rodeados por "\A" y "\z".

"package_exemptions" tiene como valor por defecto "main". "global_variable_exemptions" tiene como valor por defecto "\$VERSION @ISA @EXPORT(?:_OK)? %EXPORT_TAGS \$AUTOLOAD %ENV %SIG \$TODO". "subroutine_exemptions" tiene como valor por defecto "AUTOLOAD BUILD BUILDARGS CLEAR CLOSE DELETE DEMOLISH DESTROY EXISTS EXTEND FETCH FETCHSIZE FIRSTKEY GETC NEXTKEY POP PRINT PRINTF PUSH READ READLINE SCALAR SHIFT SPLICE STORE STORESIZE TIEARRAY TIEHANDLE TIEHASH TIESCALAR UNSHIFT UNTIE WRITE" que debería cubrir todas las subrutinas estándar de Perl, además de las de Moose.

Tenga en cuenta que "package_exemptions" no comprueba nombres de paquetes completos. Para "Foo::Bar::baz", comprobará "Foo", "Bar" y "baz" secuencialmente.

Por ejemplo, si desea que todas las variables locales estén en minúsculas y que las variables globales comiencen con "G_" y, de lo contrario, no contengan guiones bajos, pero que se exima a cualquier variable con un nombre que contenga "THINGY", puede poner lo siguiente en su .perlcriticrc:

[NamingConventions::Capitalization]
local_lexical_variables = :all_lower
global_variables = G_(?:(?!_)\w)+
global_variable_exemptions = .*THINGY.*

PENDIENTE

Manejar "use vars". Tratar las subrutinas constantes como variables constantes. Manejar manejadores de archivos desnudos. Debe haber "esquemas" o formas de especificar "perlstyle" o "pbp". Diferenciar constantes Readonly léxicas en ámbitos.

ERRORES

Esta política no detectará problemas con la declaración de $y a continuación:

for (my $x = 3, my $y = 5; $x < 57; $x += 3) {
    ...
}

NOMBRE

Perl::Critic::Policy::NamingConventions::Capitalization - Checks for common naming convention violations.

AFILIACIÓN

This policy is part of the Perl::Critic distribution.

DESCRIPCIÓN

This policy checks for common naming convention violations. It will complain about variables and subroutine names that do not follow standard Perl naming conventions. For example, it will complain about subroutine names that start with a capital letter, unless they are also part of a package name.

CONFIGURACIÓN

This policy does not accept any configuration options.
