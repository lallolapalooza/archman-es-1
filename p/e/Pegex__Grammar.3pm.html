Pegex::Grammar(3) Documentación de Perl proporcionada por el usuario Pegex::Grammar(3)

NOMBRE

Pegex::Grammar - Clase base de la gramática Pegex

SINOPSIS

Define una gramática Pegex (para la sintaxis Foo):

package Pegex::Foo::Grammar;
use base 'Pegex::Base';
extends 'Pegex::Grammar';
has text => q{
foo: bar baz
... resto de la gramática Foo ...
};

luego úsala para analizar algo de Foo:

use Pegex::Parser;
my $parse_tree = Pegex::Parser->new(
    grammar => 'Pegex::Foo::Grammar',
    receiver => 'Pegex::Tree',
)->parse('my/file.foo');

DESCRIPCIÓN

Pegex::Grammar es una clase base para definir tus propias clases de gramática Pegex. Solo necesitas proporcionar la vista de la gramática a través de los atributos "text" o "file".

Cuando Pegex::Parser utiliza tu gramática, la querrá en forma de árbol (compilada), por lo que Pegex::Grammar proporciona soporte de compilación automática.

PROPIEDADES Y MÉTODOS

tree
Esta es la estructura de datos que contiene la gramática compilada para tu sintaxis. Normalmente es producida por "Pegex::Compiler". Puedes incrustarla en el método "tree", o de lo contrario se llamará al método "make_tree" para producirla.

El método "make_tree" llamará a Pegex::Compiler para compilar la propiedad "text" por defecto. Puedes definir tu propio método "make_tree" para anular este comportamiento.

A menudo querrás generar tus propias subclases de Pegex::Grammar de forma automatizada. Los módulos Pegex y TestML lo hacen para ser eficientes. Esto también te permite mantener el texto de tu gramática en un archivo separado, y a menudo en un repositorio separado, para que pueda ser compartido por implementaciones de módulos de múltiples lenguajes de programación.

Ver https://github.com/ingydotnet/pegex-pgx y https://github.com/ingydotnet/pegex-pm/blob/master/lib/Pegex/Pegex/Grammar.pm.

text
Este es simplemente el texto de tu gramática. Si defines esto, deberías (probablemente) no definir la propiedad "tree". Este texto de gramática se compilará automáticamente cuando se requiera la "tree".
file
Este es el archivo donde vive tu gramática Pegex. Normalmente se usa cuando estás creando un módulo Pegex. La ruta es relativa al directorio raíz de tu módulo.
make_tree
Este método se llama cuando la gramática necesita la versión compilada.
