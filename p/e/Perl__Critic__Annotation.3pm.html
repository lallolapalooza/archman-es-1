Perl::Critic::Annotation(3pm) Documentación de Perl contribuida por usuarios Perl::Critic::Annotation(3pm)

NOMBRE

Perl::Critic::Annotation - Una anotación "## no critic" en un documento.

SINOPSIS

use Perl::Critic::Annotation;
$anotacion = Perl::Critic::Annotation->new( -elemento => $elemento_ppi_no_critico );
$booleano = $anotacion->deshabilita_linea( $numero );
$booleano = $anotacion->deshabilita_politica( $objeto_politica );
$booleano = $anotacion->deshabilita_todas_las_politicas();
($inicio, $fin) = $anotacion->rango_efectivo();
@nombres_politicas_deshabilitadas = $anotacion->politicas_deshabilitadas();

DESCRIPCION

"Perl::Critic::Annotation" representa una única anotación "## no critic" en un PPI::Document. La Anotación se encarga de analizar la anotación y lleva la cuenta de qué líneas y políticas afecta. Está destinada a encapsular los detalles de las anotaciones no críticas y a proporcionar una forma para que los objetos de Política interactúen con las anotaciones (a través de un Perl::Critic::Document).

SOPORTE DE INTERFAZ

Esta se considera una clase no pública. Su interfaz está sujeta a cambios sin previo aviso.

MÉTODOS DE CLASE

crear_anotaciones( -doc => $doc )
Dado un Perl::Critic::Document, encuentra todas las anotaciones "## no critic" y construye una nueva "Perl::Critic::Annotation" para cada una de ellas y las devuelve. El orden de los objetos devueltos no está definido. Generalmente se espera que los clientes utilicen esta interfaz en lugar de llamar directamente al constructor de "Perl::Critic::Annotation".

CONSTRUCTOR

"new( -elemento => $ppi_elemento_anotacion )"
Devuelve una referencia a un nuevo objeto Annotation. El argumento -elemento es obligatorio y debe ser un "PPI::Token::Comment" que cumpla con la sintaxis "## no critic".

MÉTODOS

deshabilita_linea( $linea )
Devuelve verdadero si esta Anotación deshabilita $linea para alguna (o todas las) Políticas.
deshabilita_politica( $objeto_politica )
deshabilita_politica( $nombre_politica )
Devuelve verdadero si esta Anotación deshabilita $objeto_politica o $nombre_politica en alguna (o todas las) líneas.
deshabilita_todas_las_politicas()
Devuelve verdadero si esta Anotación deshabilita todas las Políticas en alguna (o todas las) líneas. Si este método devuelve verdadero, "politicas_deshabilitadas" devolverá una lista vacía.
rango_efectivo()
Devuelve una lista de dos elementos, que representa los números de la primera y última línea donde esta Anotación tiene efecto.
politicas_deshabilitadas()
Devuelve una lista de los nombres de las Políticas que se ven afectadas por esta Anotación. Si esta lista está vacía, significa que todas las Políticas se ven afectadas por esta Anotación, y deshabilita_todas_las_politicas() debería devolver verdadero.
elemento()
Devuelve el PPI::Element donde comenzó esta anotación. Típicamente es una instancia de PPI::Token::Comment.
