Perl::Critic::Theme(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Theme(3pm)

NOMBRE

Perl::Critic::Theme - Construir conjuntos temáticos de políticas.

DESCRIPCIÓN

Esta es una clase auxiliar para evaluar expresiones temáticas en conjuntos de objetos Policy. No hay partes que el usuario pueda reparar aquí.

SOPORTE DE INTERFAZ

Esta se considera una clase no pública. Su interfaz está sujeta a cambios sin previo aviso.

MÉTODOS

"new( -rule => $expresión_regla )"
Devuelve una referencia a un nuevo objeto Perl::Critic::Theme. "-rule" es una expresión de cadena que se evalúa como verdadera o falsa para cada Policy. Ver "REGLAS TEMÁTICAS" para más información.
"policy_is_thematic( -policy => $policy )"
Dado una referencia a un objeto Perl::Critic::Policy, este método evalúa la regla contra los temas que están asociados con la Policy. Devuelve 1 si la Policy satisface la regla, 0 de lo contrario.
rule()
Devuelve la expresión de regla utilizada para construir este Tema. La regla puede haber sido traducida a una expresión normalizada. Ver "REGLAS TEMÁTICAS" para más información.

REGLAS TEMÁTICAS

Una regla temática es una expresión booleana simple, donde los operandos son los nombres de cualquiera de los temas asociados con las Perl::Critic::Policies.

Los nombres de tema pueden combinarse con operadores lógicos para formar expresiones arbitrariamente complejas. La precedencia es la misma que en matemáticas normales, pero también puedes usar paréntesis para forzar la precedencia. Los operadores soportados son:

Operador    Alternativa    Ejemplo
----------------------------------------------------------------
&&          and            'pbp && core'
||          or             'pbp || (bugs && security)'
!           not            'pbp && ! (portability || complexity)'

Ver "CONFIGURACIÓN" en Perl::Critic para más información sobre cómo personalizar los temas para cada Policy.

SUBRUTINAS

cook_rule( $regla )
Estandariza una regla en código Perl casi ejecutable. El "casi" proviene del hecho de que los nombres de tema se dejan tal cual.

CONSTANTES

$RULE_INVALID_CHARACTER_REGEX
Una expresión regular que devolverá el primer carácter en la expresión coincidente que no es válido en una regla.
