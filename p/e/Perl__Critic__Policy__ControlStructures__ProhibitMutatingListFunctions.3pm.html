Perl::Critic::Policy::ControlStructures::ProhibitMutatingListFunctions(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ControlStructures::ProhibitMutatingListFunctions(3pm)

NOMBRE

Perl::Critic::Policy::ControlStructures::ProhibitMutatingListFunctions - No modificar funciones de listas que mutan el contenido de la lista.

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

"map", "grep" y otros operadores de lista están destinados a transformar arrays en otros arrays aplicando código a los elementos del array uno por uno. Para mayor velocidad, los elementos se referencian a través de un alias de $_ en lugar de copiarlos. Como consecuencia, si el bloque de código de "map" o "grep" modifica $_ de alguna manera, en realidad está modificando el array fuente. Esto SÍ está técnicamente permitido, pero esos efectos secundarios pueden ser bastante sorprendentes, especialmente cuando el array que se pasa es @_ o quizás values(%ENV). En su lugar, los autores deberían restringir la modificación de arrays in-situ a constructos de "for(@array) { ... }" en su lugar, o usar List::SomeUtils:apply() o List::MoreUtils::apply().

CONFIGURACIÓN

Por defecto, esta política se aplica a las siguientes funciones de lista:

map grep
List::Util qw(first)
List::MoreUtils qw(any all none notall true false firstidx
                   first_index lastidx last_index insert_after
                   insert_after_string)
List::SomeUtils qw(any all none notall true false firstidx
                   first_index lastidx last_index insert_after
                   insert_after_string)

Esta lista puede ser anulada en el archivo .perlcriticrc de esta manera:

[ControlStructures::ProhibitMutatingListFunctions]
list_funcs = map grep List::Util::first

O, simplemente se puede añadir a la lista así:

[ControlStructures::ProhibitMutatingListFunctions]
add_list_funcs = Foo::Bar::listmunge

LIMITACIONES

Esta política deliberadamente no se aplica a "for (@array) { ... }" ni a List::MoreUtils::apply() List::SomeUtils::apply().

Actualmente, la política solo detecta el uso explícito de módulos externos como este:

my @out = List::MoreUtils::any {s/^foo//} @in;
my @out = List::SomeUtils::any {s/^foo//} @in;

Y no así:

use List::MoreUtils qw(any);
my @out = any {s/^foo//} @in;
use List::SomeUtils qw(any);
my @out = any {s/^foo//} @in;

Esta política solo busca modificaciones de $_. Otras acciones indebidas podrían incluir la modificación de $a y $b en "sort" y similares. Eso está fuera del alcance de esta política.

VER TAMBIÉN

Hay una discusión sobre esta política en http://perlmonks.org/index.pl?node_id=743445.
