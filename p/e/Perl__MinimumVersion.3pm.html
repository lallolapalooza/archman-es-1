Perl::MinimumVersion(3) Documentación de contribuciones de Perl Perl::MinimumVersion(3)

NOMBRE

Perl::MinimumVersion - Encontrar la versión mínima de Perl necesaria para ejecutar código Perl

SINTAXIS

# Crear el objeto de verificación de versiones
$object = Perl::MinimumVersion->new( $filename );
$object = Perl::MinimumVersion->new( \$source  );
$object = Perl::MinimumVersion->new( $ppi_document );
# Encontrar la versión mínima
$version = $object->minimum_version;

DESCRIPCIÓN

"Perl::MinimumVersion" toma código Perl y calcula la versión mínima de Perl necesaria para ejecutarlo. Dado que se basa en PPI, puede realizar esta tarea sin tener que cargar el código de forma completa.

Actualmente, prueba tanto la sintaxis de tu código como el uso de dependencias explícitas como "require 5.008".

Los planes futuros incluyen soporte para seguimiento de dependencias de módulos.

Usar "Perl::MinimumVersion" es muy simple, la sintaxis casi cubre todo.

La distribución viene con un script llamado perlver, que es la forma más fácil de ejecutar "Perl::MinimumVersion" en tu código:

% perlver lib/Foo/Bar.pm

Ver la documentación de perlver para más detalles.

MÉTODOS

new

# Crear el objeto de verificación de versiones
$object = Perl::MinimumVersion->new( $filename );
$object = Perl::MinimumVersion->new( \$source  );
$object = Perl::MinimumVersion->new( $ppi_document );

El constructor "new" crea un nuevo objeto de verificación de versiones para un PPI::Document. También puedes proporcionar el documento a leer como un nombre de archivo o como un referencia a un "SCALAR" que contiene el código.

Devuelve un nuevo objeto "Perl::MinimumVersion", o "undef" en caso de error.

Document

El acceso "Document" puede utilizarse para obtener el objeto PPI::Document de vuelta del verificador de versiones.

minimum_version

El método "minimum_version" es el método principal para encontrar la versión mínima de Perl necesaria según los factores "all" en el documento.

Actualmente, esto es solo la sintaxis y dependencias explícitas, ya que "Perl::Depends" aún no está completo.

Devuelve un objeto de versión, o "undef" en caso de error.

minimum_explicit_version

El método "minimum_explicit_version" verifica el código para buscar dependencias explícitas como:

use 5.006;
require 5.005_03;

Aunque hay casi siempre solo una de estas en un archivo, si hay más de una encontrada, se devolverá la dependencia más alta.

Devuelve un objeto de versión, false si no se encontraron dependencias, o "undef" en caso de error.

minimum_syntax_version $limit

El método "minimum_syntax_version" prueba solo la sintaxis del documento para determinar su versión mínima, a la extensión que sea posible.

Toma un parámetro de objeto de versión definido como el valor más bajo conocido actualmente. Por ejemplo, si ya se sabe que debe ser 5.006 o superior, se puede proporcionar un parámetro de qv(5.006) y el método no realizará ningún prueba por debajo de esta versión. Esto debería proporcionar beneficios significativos en documentos grandes y complejos.

Los límites de la parser de Perl significan que este método puede proporcionar resultados artificialmente bajos, pero no debería ser artificialmente altos.

Por ejemplo, si "minimum_syntax_version" devuelve 5.006, puedes estar seguro de que no lo ejecutará en nada inferior, aunque hay un riesgo de que durante la ejecución real use algún feature no testable que cree una dependencia en una versión más alta.

Devuelve un objeto de versión, false si no se encontraron dependencias, o "undef" en caso de error.

minimum_external_version

ADVERTENCIA: Este método aún no ha sido implementado. Cualquier uso intentado lanzará una excepción

El método "minimum_external_version" examina el código para buscar dependencias de otros archivos externos, y recorre recursivamente el árbol de dependencias aplicando las mismas pruebas a esos archivos.

Devuelve un objeto "version", false si no se encontraron dependencias, o "undef" en caso de error.

version_markers

Este método devuelve una lista de pares en el formato:

($version, \@markers)

Cada par representa todas las marcas que se encontraron indicando que la versión fue la más baja necesaria. @markers es un array de strings. Actualmente, estos strings no son tan claros como podrían ser, pero esto podría cambiarse en el futuro. En otras palabras: no te confíes en ellos como identificadores específicos.

PROBLEMAS

Perl::MinimumVersion hace un trabajo razonable para capturar las dependencias explícitas más conocidas.

Pero es muy fácil añadir una nueva verificación de sintaxis, así que si encuentras algo que este falta, copia y pega uno de los funciones existentes de verificación de 5 líneas, modifícalo para encontrar lo que quieres, y reporta a rt.cpan.org, junto con la versión necesaria.

No necesito un dif completo... solo la función y la versión.

LO QUE DEBES HACER

Escribir más verificadores de versiones

- Operadores y estructuras de la lenguaje Perl 5.10

- Uso de tres argumentos open

Escribir el verificador de dependencias explícitas

Escribir el descenso de módulos recursivo

_while_readdir para el postfix sin corchetes

Verificar más features de 5.12 (actualmente solo detectando "package NAME VERSION;", "...", y "use feature ':5.12'")
