Perl::Critic::Policy::ValuesAndExpressions::ProhibitInterpolationOfLiterals(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::ValuesAndExpressions::ProhibitInterpolationOfLiterals(3pm)

NOMBRE

Perl::Critic::Policy::ValuesAndExpressions::ProhibitInterpolationOfLiterals - Usar siempre comillas simples para cadenas literales.

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

No usar comillas dobles o "qq//" si la cadena no requiere interpolación. Esto ahorra al intérprete algo de trabajo y le indica al lector que realmente se pretendía que la cadena fuera literal.

print "foobar";     # no está bien
print 'foobar';     # está bien
print qq/foobar/;   # no está bien
print q/foobar/;    # está bien
print "$foobar";    # está bien
print "foobar\n";   # está bien
print qq/$foobar/;  # está bien
print qq/foobar\n/; # está bien
print qq{$foobar};  # preferido
print qq{foobar\n}; # preferido

El uso de comillas dobles podría ser razonable si la cadena contiene caracteres de comillas simples (').

print "it's me";    # está bien, si la opción de configuración está activada

CONFIGURACIÓN

Los tipos de estilos de comillas que se eximirán de esta política se pueden configurar a través de la opción "allow". Debe ser una combinación separada por espacios de algunos o todos los siguientes estilos: "qq{}", qq(), "qq[]", y "qq//".

Esto es útil porque algunas personas han configurado su editor para aplicar resaltado de sintaxis especial dentro de ciertos estilos de comillas. Por ejemplo, puedes ajustar "vim" para usar resaltado de SQL para todo lo que aparece entre comillas "qq{}" o "qq[]". Pero si esas cadenas son literales, Perl::Critic se quejará. Para evitar esto, coloca lo siguiente en tu archivo .perlcriticrc:

[ValuesAndExpressions::ProhibitInterpolationOfLiterals]
allow = qq{} qq[]

La opción "allow_if_string_contains_single_quote" permite cadenas entre comillas dobles si la cadena contiene un carácter de comilla simple ('). Por defecto está desactivada; para activarla, coloca lo siguiente en tu archivo .perlcriticrc:

[ValuesAndExpressions::ProhibitInterpolationOfLiterals]
allow_if_string_contains_single_quote = 1
