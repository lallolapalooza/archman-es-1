Perl::Critic::Policy::Variables::ProhibitPackageVars(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Policy::Variables::ProhibitPackageVars(3pm)

NOMBRE

Perl::Critic::Policy::Variables::ProhibitPackageVars - Elimina globales declaradas con "our" o "use vars".

AFILIACIÓN

Esta política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Conway sugiere evitar las variables de paquete por completo, ya que exponen tus internos a otros paquetes. Nunca uses una variable de paquete cuando una variable léxica sea suficiente. Si tu paquete necesita mantener algún estado dinámico, considera usar un objeto o closures para mantener el estado privado.

Esta política asume que estás utilizando "strict vars" para que las declaraciones de variables sin calificar no sean variables de paquete por defecto. Por lo tanto, se queja si declaras una variable con "our" o "use vars", o si haces referencia a una variable con un nombre de paquete completamente calificado.

$Some::Package::foo = 1;    # no está bien
our $foo            = 1;    # no está bien
use vars '$foo';            # no está bien
$foo = 1;                   # no permitido por 'strict'
local $foo = 1;             # mal gusto, pero técnicamente aceptable.
use vars '$FOO';            # aceptable, porque está TODO EN MAYÚSCULAS
my $foo = 1;                # aceptable

En la práctica, sin embargo, no es realmente práctico prohibir todas las variables de paquete. Variables comunes como $VERSION y @EXPORT son necesarias para que sean globales, al igual que cualquier variable que desees exportar. Para solucionar esto, la política ignora cualquier variable que esté en TODO EN MAYÚSCULAS. Esto te obliga a poner todas tus variables exportadas también en TODO EN MAYÚSCULAS, lo que parece ser la práctica habitual de todos modos.

CONFIGURACIÓN

Hay margen para excepciones. Algunos módulos, como el módulo principal File::Find, utilizan variables de paquete como su única interfaz, y otros como Data::Dumper utilizan variables de paquete como su interfaz más común. Estos módulos se pueden especificar desde tu archivo .perlcriticrc, y la política los ignorará.

[Variables::ProhibitPackageVars]
packages = Data::Dumper File::Find FindBin Log::Log4perl

Esta es la configuración por defecto. Usar "packages =" anulará estos valores predeterminados.

También puedes añadir paquetes a los valores predeterminados de la siguiente manera:

[Variables::ProhibitPackageVars]
add_packages = My::Package

Puedes añadir el paquete "main" a la lista de paquetes, pero eso solo aceptará variables explícitamente en el paquete "main".
