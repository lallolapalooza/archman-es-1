Perl::Critic::Policy::InputOutput::RequireCheckedSyscalls(3pm) Documentación de Perl aportada por el usuario Perl::Critic::Policy::InputOutput::RequireCheckedSyscalls(3pm)

NOMBRE

Perl::Critic::Policy::InputOutput::RequireCheckedSyscalls - Valor de retorno de la función marcada ignorado.

AFILIACIÓN

Esta Política es parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

Realiza idénticamente a InputOutput::RequireCheckedOpen/Close, excepto que este es configurable para aplicarse a cualquier función, ya sea central o definida por el usuario.

Si tu módulo usa Fatal, Fatal::Exception, o autodie, entonces cualquier función envuelta por esos módulos no activará esta política. Por ejemplo:

use Fatal qw(open);
open my $fh, $filename;  # ninguna violación
close $fh;               # sí violación
use autodie;
open $filehandle, $mode, $filename;   # ninguna violación

Actualmente, autodie no se trata correctamente como un pragma; sus efectos léxicos no se tienen en cuenta.

CONFIGURACIÓN

Esta política observa una lista configurable de nombres de funciones. Por defecto, se aplica a "open", "print", "say" y "close". Puedes anular esto para establecerlo en una lista diferente de funciones con las configuraciones "functions" y "exclude_functions". Para hacer esto, pon entradas en un archivo .perlcriticrc como este:

[InputOutput::RequireCheckedSyscalls]
functions = open opendir read readline readdir close closedir

Hemos definido algunos atajos para crear esta lista

[InputOutput::RequireCheckedSyscalls]
functions = :defaults opendir readdir closedir
[InputOutput::RequireCheckedSyscalls]
functions = :builtins
[InputOutput::RequireCheckedSyscalls]
functions = :all

El atajo ":builtins" anterior representa todas las funciones incorporadas que tienen condiciones de error (alrededor de 65 de ellas, muchas bastante oscuras).

Puedes requerir la comprobación de todas las funciones incorporadas excepto "print" combinando "functions" y "exclude_functions":

[InputOutput::RequireCheckedSyscalls]
functions = :builtins
exclude_functions = print

Esto es mucho más fácil de leer que la alternativa.

El ":all" es el caso insano: debes comprobar el valor de retorno de CADA llamada a función, incluso "return" y "exit". Sí, esta "característica" es exagerada y está desperdiciando ciclos de CPU en tu computadora simplemente por existir. Ñam ñam. No debería codificar después de medianoche.

Si creas un módulo que exporta "autodie", puedes informar a esta política al respecto con la configuración "autodie_modules":

[InputOutput::RequireCheckedSyscalls]
autodie_modules = My::Thing
