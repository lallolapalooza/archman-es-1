NOMBRE

PerlIO::via::dynamic - capas PerlIO dinámicas

SINOPSIS

open $fh, $fname;
$p = PerlIO::via::dynamic->new
 (translate =>
   sub { $_[1] =~ s/\$Filename[:\w\s\-\.\/\\]*\$/\$Filename: $fname\$/e},
  untranslate =>
   sub { $_[1] =~ s/\$Filename[:\w\s\-\.\/\\]*\$/\$Filename\$/});
$p->via ($fh);
binmode $fh, $p->via; # obsoleto

DESCRIPCIÓN

"PerlIO::via::dynamic" se utiliza para crear capas PerlIO dinámicas. Es útil cuando el comportamiento o la capa depende de variables. No deberías usar este módulo como capa via directamente (es decir, :via(dynamic)).

Usa el constructor para crear nuevas capas, con dos argumentos: translate y untranslate. Luego usa "$p-"via ($fh)> para envolver el manejador. Una vez que <$fh> sea destruido, se eliminará el espacio de nombres temporal para la capa de E/S.

Ten en cuenta que PerlIO::via::dynamic usa los campos escalares para referenciar el objeto que representa el espacio de nombres dinámico.

OPCIONES

translate
Una función que traduce el búfer al *escribir*.
untranslate
Una función que traduce el búfer al *leer*.
use_read
Usa "READ" en lugar de "FILL" para la capa. Útil cuando el llamante espera una cantidad exacta de datos de la lectura, y la función "untranslate" puede devolver una longitud diferente.

Por defecto, "PerlIO::via::dynamic" crea una capa basada en líneas para facilitar la implementación de "translate".
