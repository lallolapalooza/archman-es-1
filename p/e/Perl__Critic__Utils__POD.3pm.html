Perl::Critic::Utils::POD(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::Utils::POD(3pm)

NOMBRE

Perl::Critic::Utils::POD - Funciones de utilidad para tratar con POD.

SINOPSIS

use Perl::Critic::Utils::POD qw< get_pod_section_from_file >;
my $synopsis =
    get_pod_section_from_file('Perl/Critic/Utils/POD.pm', 'SYNOPSIS');
my $see_also =
    get_pod_section_from_filehandle($file_handle, 'SEE ALSO');
my $see_also_content = trim_pod_section($see_also);
# "Funciones de utilidad para tratar con POD."
my $module_abstract =
    get_module_abstract_from_file('Perl/Critic/Utils/POD.pm');
my $module_abstract =
    get_module_abstract_from_filehandle($file_handle);

DESCRIPCIÓN

Proporciona medios para acceder a fragmentos de POD.

SOPORTE DE INTERFAZ

Este se considera un módulo público. Cualquier cambio en su interfaz pasará por un ciclo de degradación.

SUBRUTINAS IMPORTABLES

get_pod_file_for_module( $module_name )
Determina dónde encontrar el POD para el parámetro.

Esto depende de que el módulo ya esté cargado; no encontrará la ruta para módulos arbitrarios.

Si hay un archivo con extensión ".pod" junto a la ubicación real del módulo, se devolverá con preferencia sobre el módulo real.

"get_raw_pod_section_from_file( $file_name, $section_name )"
Recupera la sección POD especificada (es decir, algo marcado con "=head1") del archivo. Esto no está interpretado; las escapadas no se procesan y estarán presentes las subsecciones. Por ejemplo, si el contenido contiene "C<$x>", el valor de retorno contendrá "C<$x>".

No devuelve nada si no se encuentra dicha sección.

Lanza una Perl::Critic::Exception::IO si hay un problema con el archivo.

"get_raw_pod_section_from_filehandle( $file_handle, $section_name )"
Hace lo mismo que get_raw_pod_section_from_file(), pero con un manejador de archivo.
"get_raw_pod_section_from_string( $source, $section_name )"
Hace lo mismo que get_raw_pod_section_from_file(), pero con una cadena que contiene el POD sin procesar.
"get_raw_pod_section_for_module( $module_name, $section_name )"
Hace lo mismo que get_raw_pod_section_from_file(), pero con un nombre de módulo.

Lanza una Perl::Critic::Exception::Generic si no se puede encontrar un archivo que contenga POD para el módulo.

"get_pod_section_from_file( $file_name, $section_name )"
Recupera la sección POD especificada (es decir, algo marcado con "=head1") del archivo. Esto se interpreta en texto plano.

No devuelve nada si no se encuentra dicha sección.

Lanza una Perl::Critic::Exception::IO si hay un problema con el archivo.

"get_pod_section_from_filehandle( $file_handle, $section_name )"
Hace lo mismo que get_pod_section_from_file(), pero con un manejador de archivo.
"get_pod_section_from_string( $source, $section_name )"
Hace lo mismo que get_pod_section_from_file(), pero con una cadena que contiene el POD sin procesar.
"get_pod_section_for_module( $module_name, $section_name )"
Hace lo mismo que get_pod_section_from_file(), pero con un nombre de módulo.

Lanza una Perl::Critic::Exception::Generic si no se puede encontrar un archivo que contenga POD para el módulo.

trim_raw_pod_section( $pod_section )
Devuelve una copia del parámetro, eliminando cualquier "=item1 BLAH" inicial y todo el espacio en blanco inicial y final (incluidos los saltos de línea) después de eso.

Por ejemplo, usar una de las funciones "get_raw_pod_section_from_*" para obtener la sección "NAME" de este módulo y luego llamar a trim_raw_pod_section() sobre el resultado te daría "Perl::Critic::Utils::POD - Funciones de utilidad para tratar con POD.".

trim_pod_section( $pod_section )
Devuelve una copia del parámetro, eliminando cualquier línea inicial y los saltos de línea en blanco iniciales y el espacio en blanco final (incluidos los saltos de línea) después de eso. Ten en cuenta que solo permanecerá el espacio en blanco inicial en la primera línea real de la sección.

Dado que no puede contar con un marcador de "=item1", esto es mucho menos fiable que trim_raw_pod_section().

get_raw_module_abstract_from_file( $file_name )
Intenta analizar la sección "NAME" del archivo especificado y obtener el resumen del módulo a partir de ahí. Si tiene éxito, devuelve el resumen. Si falla, ya sea porque no hay sección "NAME" o no hay resumen después del nombre del módulo, no devuelve nada. Si parece que hay un resumen mal formado, lanza una Perl::Critic::Exception::Fatal::Generic.

Ejemplos de secciones "NAME" "bien formadas" sin resúmenes:

Some::Module
Some::Other::Module -

Ejemplos de secciones "NAME" que resultarán en una excepción:

Some::Bad::Module This has no hyphen.
Some::Mean::Module -- This has double hyphens.
Some::Nasty::Module - This one attempts to
span multiple lines.
get_raw_module_abstract_from_filehandle( $file_handle )
Hace lo mismo que get_raw_module_abstract_from_file(), pero con un manejador de archivo.
get_raw_module_abstract_from_string( $source )
Hace lo mismo que get_raw_module_abstract_from_file(), pero con una cadena que contiene el POD sin procesar.
get_raw_module_abstract_for_module( $module_name )
Hace lo mismo que get_raw_module_abstract_from_file(), pero para un nombre de módulo.
get_module_abstract_from_file( $file_name )
Hace lo mismo que get_raw_module_abstract_from_file(), pero con las escapadas interpretadas.
get_module_abstract_from_filehandle( $file_handle )
Hace lo mismo que get_module_abstract_from_file(), pero con un manejador de archivo.
get_module_abstract_from_string( $source )
Hace lo mismo que get_module_abstract_from_file(), pero con una cadena que contiene el POD sin procesar.
get_module_abstract_for_module( $module_name )
Hace lo mismo que get_module_abstract_from_file(), pero para un nombre de módulo.
