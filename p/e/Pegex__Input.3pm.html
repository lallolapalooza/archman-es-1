Pegex::Input(3) Documentación de Perl aportada por el usuario Pegex::Input(3)

NOMBRE

Pegex::Input - Abstracción de entrada del analizador Pegex

SINOPSIS

use Pegex;
use Pegex::Input;
my $ast = pegex($foo_grammar)->parse(Pegex::Input->new(string => $foo_input));

DESCRIPCIÓN

Pegex::Parser analiza la entrada. La entrada puede ser una cadena, una referencia a cadena, una ruta de archivo o un manejador de archivo abierto. Pegex::Input es una abstracción sobre cualquier tipo de entrada. Proporciona una interfaz uniforme para el analizador.

USO

Llamas a new() con dos argumentos, donde el primer argumento es el tipo de entrada:

Pegex::Input->new(file => 'file.txt')

Los siguientes tipos de entrada están disponibles:

cadena
La entrada es una cadena.
referencia_cadena
La entrada es una referencia a cadena. Esto puede ser deseable para cadenas muy largas.
archivo
La entrada es un nombre de ruta de archivo que se abrirá y leerá.
manejador
La entrada proviene de un manejador de archivo abierto que se leerá.
