Perl::Critic::Policy::Subroutines::ProhibitReturnSort(3pm) Documentación Perl de Contribución de Usuarios Perl::Critic::Policy::Subroutines::ProhibitReturnSort(3pm)

NOMBRE

Perl::Critic::Policy::Subroutines::ProhibitReturnSort - El comportamiento de "sort" no está definido si se llama en contexto escalar.

AFILIACIÓN

Esta Política forma parte de la distribución principal de Perl::Critic.

DESCRIPCIÓN

El comportamiento de la función incorporada "sort" no está definido si se llama en contexto escalar. Por lo tanto, si escribe una subrutina que directamente "return" el resultado de una operación de "sort", su código se comportará de forma impredecible si alguien llama a su subrutina en un contexto escalar. Esta Política emite una violación si la palabra clave "return" es seguida directamente por la función "sort". Para devolver de forma segura una lista ordenada de valores de una subrutina, primero debe asignar los valores ordenados a una variable temporal. Por ejemplo:

sub frobulate {
    return sort @list;  # ¡no está bien!
    my @sorted_list = sort @list;
    return @sorted_list # OK
}

BUGS CONOCIDOS

Esta Política no es sensible a la función "wantarray". Por lo tanto, el siguiente código generaría una violación falsa:

sub frobulate {
    if (wantarray) {
        return sort @list;
    }
    else{
        return join @list;
    }
}

CONFIGURACIÓN

Esta Política no es configurable, excepto por las opciones estándar.
