Perl::Critic::Document(3pm) Documentación de Perl aportada por el usuario Perl::Critic::Document(3pm)

NOMBRE

Perl::Critic::Document - Envoltura de caché para un PPI::Document.

SINOPSIS

use PPI::Document;
use Perl::Critic::Document;
my $doc = PPI::Document->new('Foo.pm');
$doc = Perl::Critic::Document->new(-source => $doc);
## Luego usa la instancia como si fuera un PPI::Document

DESCRIPCIÓN

Perl::Critic realiza muchas iteraciones sobre el árbol del documento PPI a través del método PPI::Document::find(). Para ahorrar algo de tiempo, esta clase pre-almacena en caché muchas de las llamadas comunes a find() en una sola travesía. Luego, en solicitudes posteriores, devolvemos los datos almacenados en caché.

Esto se implementa como una fachada, donde las llamadas a los métodos se delegan a la instancia "PPI::Document" almacenada.

ADVERTENCIAS

Esta fachada no implementa los operadores sobrecargados de PPI::Document (es decir, el trabajo de "use overload ..."). Por lo tanto, los usuarios de esta fachada no deben confiar en ese azúcar sintáctico. Así, por ejemplo, en lugar de "my $source = "$doc";" se debe escribir "my $source = $doc->content();"

¿Quizás existe un módulo CPAN que implemente una fachada mejor que la nuestra aquí?

SOPORTE DE INTERFAZ

Esta se considera una clase pública. Cualquier cambio en su interfaz pasará por un ciclo de depreciación.

CONSTRUCTOR

"new(-source => $fuente_código, '-filename-override' => $nombre_archivo, '-program-extensions' => [extensiones_programa])"
Crea una nueva instancia que referencia una instancia de PPI::Document. La $fuente_código puede ser el nombre de un archivo, una referencia a un escalar que contenga código fuente real, o un PPI::Document o PPI::Document::File.

En caso de que $fuente_código sea una referencia a un escalar que contenga código fuente real o un PPI::Document, la Perl::Critic::Document resultante no tendrá nombre de archivo. Esto puede hacer que Perl::Critic::Document clasifique incorrectamente el código fuente como un módulo o script. Para evitar este problema, opcionalmente puede establecer "-filename-override" para forzar que Perl::Critic::Document tenga un $nombre_archivo específico. No use esta opción si $fuente_código ya es el nombre de un archivo, o si es una referencia a un PPI::Document::File.

El argumento '-program-extensions' es opcional y es una referencia a una lista de cadenas y/o expresiones regulares. Las cadenas se convertirán en expresiones regulares que coinciden con el final de un nombre de archivo, y cualquier documento cuyo nombre de archivo coincida con una de las expresiones regulares se considerará un programa.

Si no se especifica -program-extensions, o si no determina el tipo de documento, el documento se considerará un programa si la fuente tiene una línea shebang o si su nombre de archivo (si existe) coincide con "m/ [.] PL \z /smx".

MÉTODOS

ppi_document()
Accesor para la instancia PPI::Document envuelta. Tenga en cuenta que alterar esta instancia de cualquier manera puede causar fallos impredecibles en el análisis posterior de Perl::Critic, ya que algunas cachés pueden quedar obsoletas.
find($wanted)
find_first($wanted)
find_any($wanted)
Envolturas de caché para los métodos PPI. Si $wanted es un nombre de clase PPI simple, entonces se emplea la caché. De lo contrario, reenviamos la llamada al método correspondiente de la instancia "PPI::Document".
namespaces()
Devuelve una lista de los namespaces (nombres de paquetes) en el documento.
subdocuments_for_namespace($namespace)
Devuelve una lista de subdocumentos que contienen los elementos en el namespace dado. Por ejemplo, dado que el documento actual es para la fuente 
foo();
package Foo;
package Bar;
package Foo;

este método devolverá dos Perl::Critic::Documents para un parámetro de "Foo". Para más información, vea "split_ppi_node_by_namespace" en PPIx::Utils::Traversal.

ppix_regexp_from_element($element)
Envoltura de caché para "PPIx::Regexp->new($element)". Si $element es un "PPI::Element" se emplea la caché, de lo contrario simplemente devuelve los resultados de "PPIx::Regexp->new()". En cualquier caso, devuelve "undef" a menos que el argumento sea algo que PPIx::Regexp realmente entienda.
"element_is_in_lexical_scope_after_statement_containing( $inner, $outer )"
¿Está el elemento $inner en el ámbito léxico después de la sentencia que contiene el elemento $outer?

En el caso en que $outer sea en sí mismo un elemento que define un ámbito, devuelve verdadero si $outer contiene a $inner. En cualquier otro caso, $inner debe estar después del último elemento de la sentencia que contiene a $outer, y el ámbito más interno para $outer también contiene a $inner.

Esto no es lo mismo que preguntar si $inner es visible desde $outer.

filename()
Devuelve el nombre del archivo para el código fuente si es aplicable (PPI::Document::File) o "undef" en caso contrario (PPI::Document).
isa( $classname )
Para ser compatible con otros módulos que esperan recibir un PPI::Document, la clase Perl::Critic::Document se hace pasar por la clase PPI::Document.
highest_explicit_perl_version()
Devuelve un objeto de versión para el requisito de versión de Perl más alto declarado en el documento a través de una sentencia "use" o "require". Devuelve nada si no hay ninguna declaración de versión.
uses_module($module_or_pragma_name)
Responde si hay un "use", "require", o "no" con el nombre dado en este documento. Tenga en cuenta que no hay diferenciación entre módulos y pragmas aquí.
process_annotations()
Hace que este Document se escanee a sí mismo y marque qué líneas y políticas están deshabilitadas por las anotaciones "## no critic".
"line_is_disabled_for_policy($line, $policy_object)"
Devuelve verdadero si el $policy_object o $policy_name dado ha sido deshabilitado en la $line en este Documento. De lo contrario, devuelve falso.
add_annotation( $annotation )
Añade un objeto $annotation a este Documento.
annotations()
Devuelve una lista que contiene todas las Anotaciones de Perl::Critic que se encontraron en este Documento.

"permalink" href="#add_suppressed_violation($violation)">add_suppressed_violation($violation)
Informa a este Documento que se encontró una $violación pero no se informó porque cayó en una línea que había sido suprimida por una anotación "## no critic". Devuelve $self.
suppressed_violations()
Devuelve una lista de referencias a todas las Violaciones de Perl::Critic que se encontraron en este Documento pero que fueron suprimidas.
is_program()
Devuelve si este documento se considera un programa.
is_module()
Devuelve si este documento se considera un módulo Perl.
