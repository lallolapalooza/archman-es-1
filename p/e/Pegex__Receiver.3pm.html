NOMBRE

Pegex::Receiver - Clase base para todos los receptores de Pegex

SINOPSIS

package MiReceptor;
use base 'Pegex::Receiver';
# Manejar datos para una regla específica
sub got_nombredelaregla {
    my ($self, $got) = @_;
    # ... procesar ...
    return $resultado;
}
# Manejar datos para cualquier otra regla
sub gotrule {
    my ($self, $got) = @_;
    return $resultado;
}
# Pre-procesar
sub initial { ... }
# Post-procesar
sub final {
    ...;
    return $resultado_final;
}

DESCRIPCIÓN

En Pegex, un receptor es el objeto de clase al que un analizador pasa los datos capturados cuando una regla de una gramática coincide con una parte de un flujo de entrada. Un receptor proporciona métodos de acción para convertir los datos analizados en lo que el analizador pretende hacer.

Esta es la clase base de todas las clases receptoras de Pegex.

No hace mucho, que es lo correcto. Si usas esta clase como tu receptor, no hará ningún trabajo adicional. Consulta Pegex::Tree para conocer una clase base receptora que te ayudará a organizar tus coincidencias por defecto.

Cómo funciona un receptor

Una gramática Pegex está compuesta por reglas con nombre, expresiones regulares y grupos. Cuando una expresión regular coincide, el analizador crea una matriz de sus cadenas de captura. Cuando un grupo coincide, el analizador crea una matriz de todas las matrices de subcoincidencia. De esta manera se forma un árbol de análisis.

Cuando una regla con nombre coincide, se llama a un método de acción en la clase receptora. Al método se le pasa el árbol de análisis actual y devuelve lo que el analizador considerará el nuevo árbol de análisis.

Esto da lugar a una API muy elegante y comprensible.

API

Esta sección documenta los métodos que puedes incluir en una subclase receptora.

"got_$rulename($got)"
Un método de acción para una regla nombrada específica. 
sub got_regla42 {
    my ($self, $got) = @_;
    ...
    return $resultado;
}

El valor $got que se pasa es el valor actual del árbol de análisis. Lo que se devuelve es lo que quieras que sea el nuevo valor.

gotrule($got)
El método de acción para una regla nombrada que no tiene un método de acción específico.
initial()
Se llama al principio de una operación de análisis, antes de que comience el análisis.
final($got)
Se llama al final de una operación de análisis. Lo que devuelva esta acción, será el resultado del análisis.

Métodos

"parser"
Un atributo que contiene el objeto analizador que se está ejecutando actualmente. Esto puede ser muy útil para introspeccionar lo que está sucediendo y, posiblemente, modificar la gramática sobre la marcha. (¡Solo para expertos!)
flatten($array)
Un método de utilidad que puede convertir un array de arrays en un solo array. Por ejemplo: 
$self->flatten([1, [2, [3, 4], 5], 6]);
# produce [1, 2, 3, 4, 5, 6]

Los hashes se dejan sin cambios. El array se modifica in situ, pero también es el valor devuelto.
