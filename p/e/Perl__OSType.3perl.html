Perl::OSType(3perl) Guía de Referencia del Programador de Perl Perl::OSType(3perl)

NOMBRE

Perl::OSType - Mapear nombres de sistemas operativos de Perl a tipos genéricos

VERSIÓN

versión 1.010

SINOPSIS

use Perl::OSType ':all';
$current_type = os_type();
$other_type = os_type('dragonfly'); # devuelve 'Unix'

DESCRIPCIÓN

Los módulos que proporcionan comportamientos específicos del sistema operativo a menudo necesitan saber si el sistema operativo actual coincide con un tipo más genérico de sistemas operativos. Por ejemplo, 'linux' es un tipo de sistema operativo 'Unix' y también lo es 'freebsd'.

Este módulo proporciona un mapeo entre un nombre de sistema operativo, tal como lo proporciona $^O, y un tipo más genérico. La versión inicial se basa en los mapeos de tipos de SO proporcionados en Module::Build y ExtUtils::CBuilder. (Por lo tanto, a los sistemas operativos de Microsoft se les da el tipo 'Windows' en lugar de 'Win32').

USO

No se exportan funciones por defecto. La etiqueta de exportación ":all" exportará todas las funciones listadas a continuación.

os_type()

$os_type = os_type();
$os_type = os_type('MSWin32');

Devuelve un único tipo de SO genérico para un nombre de sistema operativo dado. Sin argumentos, devuelve el tipo de SO para el valor actual de $^O. Si el sistema operativo no se reconoce, la función devolverá una cadena vacía.

is_os_type()

$is_windows = is_os_type('Windows');
$is_unix    = is_os_type('Unix', 'dragonfly');

Dado un tipo de SO y un nombre de SO, devuelve verdadero o falso si el nombre del SO es de ese tipo. Al igual que con "os_type", utilizará el sistema operativo actual como predeterminado si no se proporciona ningún nombre de SO.
