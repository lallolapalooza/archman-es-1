NOMBRE

Pegex::Compiler - Compilador de Pegex

SINOPSIS

use Pegex::Compiler;
my $grammar_text = '... texto de la gramática ...';
my $pegex_compiler = Pegex::Compiler->new();
my $grammar_tree = $pegex_compiler->compile($grammar_text)->tree;

o:

perl -Ilib -MYourGrammarModule=compile

DESCRIPCIÓN

El compilador Pegex transforma una cadena de gramática Pegex (o archivo) en una forma compilada. La forma compilada se conoce como árbol de gramática, que es simplemente una estructura de datos anidada.

El árbol de gramática se puede serializar a YAML, JSON, Perl o cualquier otro lenguaje de programación. Esto lo hace extremadamente portable. Pegex::Grammar tiene métodos para serializar a todas estas formas.

NOTA: A menos que estés desarrollando módulos basados en Pegex, puedes ignorar
este módulo de forma segura. Incluso si lo haces, probablemente no lo usarás directamente. Ver [Compilación en el Lugar] a continuación.

MÉTODOS

Los siguientes métodos públicos están disponibles:

"$compiler = Pegex::Compiler->new();"
Devuelve un nuevo objeto Pegex::Compiler.
"$grammar_tree = $compiler->compile($grammar_input);"
Compila un texto de gramática en un árbol de gramática que puede ser utilizado por un Pegex::Parser. Este método llama a los métodos "parse" y "combinate" y devuelve el árbol resultante.

La entrada puede ser una cadena, una referencia a cadena, una ruta de archivo, un manejador de archivo o un objeto Pegex::Input. Devuelve $self para que puedas encadenarlo a otros métodos.

"$compiler->parse($grammar_text)"
El primer paso de una "compile" es "parse". Esto aplica la gramática del lenguaje Pegex a tu texto de gramática y produce un árbol no optimizado.

Este método devuelve $self para que puedas encadenarlo a otros métodos.

"$compiler->combinate()"
Antes de que un árbol de gramática Pegex pueda ser utilizado para analizar cosas, necesita ser combinado. Este proceso convierte los tokens de expresiones regulares en expresiones regulares reales. También combina algunas reglas y elimina las reglas que no son necesarias o que han sido combinadas. El resultado es un árbol de gramática Pegex que puede ser utilizado por un Pegex::Parser.

NOTA: Mientras que la fase de análisis de una compilación es siempre la misma para varios
lenguajes de programación, la fase de combinación tiene en cuenta las necesidades especiales
del lenguaje de destino. Pegex::Compiler solo combina para Perl, aunque esto a menudo es suficiente en lenguajes similares como
Ruby o Python (expresiones regulares basadas en PCRE). Lenguajes como Java probablemente necesiten
usar sus propios combinadores.

"$compiler->tree()"
Devuelve el estado actual del árbol de gramática (como una referencia hash).
"$compiler->to_yaml()"
Serializa el árbol de gramática actual a YAML.
"$compiler->to_json()"
Serializa el árbol de gramática actual a JSON.
"$compiler->to_perl()"
Serializa el árbol de gramática actual a Perl.

COMPILACIÓN EN EL LUGAR

Cuando escribes un módulo basado en Pegex, querrás precompilar tu gramática a Perl para que no tenga penalización de carga. Pegex::Grammar proporciona un mecanismo especial para esto. Digamos que tienes una clase como esta:

package MyThing::Grammar;
use Pegex::Base;
extends 'Pegex::Grammar';
use constant file => '../mything-grammar-repo/mything.pgx';
sub make_tree {
}

Simplemente usa este comando:

perl -Ilib -MMyThing::Grammar=compile

y Pegex::Grammar llamará a Pegex::Compile para poner tu gramática compilada dentro de tu subrutina "make_tree". En realidad, escribirá el texto en tu módulo. Esto hace que sea trivial actualizar tu módulo de gramática después de realizar cambios en el archivo de gramática.

Ver Pegex::JSON para un ejemplo.
