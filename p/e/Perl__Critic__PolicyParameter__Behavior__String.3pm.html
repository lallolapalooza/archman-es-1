Perl::Critic::PolicyParameter::Behavior::String(3pm) Documentación de Perl contribuida por el usuario Perl::Critic::PolicyParameter::Behavior::String(3pm)

NOMBRE

Perl::Critic::PolicyParameter::Behavior::String - Acciones apropiadas para un parámetro de cadena simple.

DESCRIPCIÓN

Proporciona un conjunto estándar de funcionalidades para un parámetro de Perl::Critic::PolicyParameter de tipo cadena, de modo que el desarrollador de una política no tenga que proporcionarla él/ella mismo/a.

NOTA: No instancies esta clase. Utiliza la instancia singleton que mantiene Perl::Critic::PolicyParameter.

SOPORTE DE INTERFAZ

Esta se considera una clase no pública. Su interfaz puede cambiar sin previo aviso.

MÉTODOS

"initialize_parameter( $parameter, $specification )"
Conecta la funcionalidad que este comportamiento proporciona al parámetro. Actualmente, este comportamiento no es personalizable por la especificación.
