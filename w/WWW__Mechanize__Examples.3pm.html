SINOPSIS

¡Mucha gente ha aprendido WWW::Mechanize, y ahora, tú también puedes!

A continuación se presentan muestras proporcionadas por usuarios de WWW::Mechanize en acción. Si tienes ejemplos que te gustaría aportar, por favor envíalos a "<andy@petdance.com>".

También puedes mirar los archivos t/*.t en la distribución.

Ten en cuenta que estos ejemplos no pretenden realizar ninguna tarea específica. Para lo que yo sé, ya no son funcionales porque los sitios que golpearon han cambiado. Están aquí para dar ejemplos de cómo la gente ha usado WWW::Mechanize.

Ten en cuenta que los ejemplos están en orden inverso a como los recibí, por lo que los ejemplos más recientes están siempre en la parte superior.

Calculadora de Densidad de Starbucks, por Nat Torkington

Aquí hay un par de programas de Nat Torkington, editor de O'Reilly Media y coautor del Perl Cookbook.

Rael [Dornfest] descubrió que puedes averiguar fácilmente cuántos Starbucks hay en un área buscando "Starbucks". Así que escribí un rastreador tonto para algunos datos de censo antiguos y obtuve algunas cifras de densidad de Starbucks. Estos números no tienen ningún significado debido a errores por usar datos de censo antiguos junto con falsos positivos en la búsqueda de Yahoo (por ejemplo, "Dodie Starbuck-Your Style Desgn" en Portland OR). "get_pop_data"

#!/usr/bin/perl -w
use WWW::Mechanize;
use Storable;
$url = 'http://www.census.gov/population/www/documentation/twps0027.html';
$m = WWW::Mechanize->new();
$m->get($url);
$c = $m->content;
$c =~ m{<A NAME=.tabA.>(.*?)</TABLE>}s
  or die "No se puede encontrar la tabla de población\n";
$t = $1;
@outer = $t =~ m{<TR.*?>(.*?)</TR>}gs;
shift @outer;
foreach $r (@outer) {
  @bits = $r =~ m{<TD.*?>(.*?)</TD>}gs;
  for ($x = 0; $x < @bits; $x++) {
    $b = $bits[$x];
    @v = split /\s*<BR>\s*/, $b;
    foreach (@v) { s/^\s+//; s/\s+$// }
    push @{$data[$x]}, @v;
  }
}
for ($y = 0; $y < @{$data[0]}; $y++) {
    $data{$data[1][$y]} = {
        NAME => $data[1][$y],
        RANK => $data[0][$y],
        POP  => comma_free($data[2][$y]),
        AREA => comma_free($data[3][$y]),
        DENS => comma_free($data[4][$y]),
    };
}
store(\%data, "cities.dat");
sub comma_free {
  my $n = shift;
  $n =~ s/,//;
  return $n;
}

"plague_of_coffee"

#!/usr/bin/perl -w
use WWW::Mechanize;
use strict;
use Storable;
$SIG{__WARN__} = sub {} ;  # ssssssh
my $Cities = retrieve("cities.dat");
my $m = WWW::Mechanize->new();
$m->get("http://local.yahoo.com/");
my @cities = sort { $Cities->{$a}{RANK} <=> $Cities->{$b}{RANK} } keys %$Cities;
foreach my $c ( @cities ) {
  my $fields = {
    'stx' => "starbucks",
    'csz' => $c,
  };
  my $r = $m->submit_form(form_number => 2,
                          fields => $fields);
  die "No se pudo enviar el formulario" unless $r->is_success;
  my $hits = number_of_hits($r);
  #  my $ppl  = sprintf("%d", 1000 * $Cities->{$c}{POP} / $hits);
  #  print "$c tiene $hits Starbucks. Eso es uno por cada $ppl personas.\n";
  my $density = sprintf("%.1f", $Cities->{$c}{AREA} / $hits);
  print "$c : $density\n";
}
sub number_of_hits {
  my $r = shift;
  my $c = $r->content;
  if ($c =~ m{\d+ de <b>(\d+)</b> resultados totales para}) {
    return $1;
  }
  if ($c =~ m{Lo sentimos, no se encontró nada en o cerca de}) {
    return 0;
  }
  if ($c =~ m{Tu búsqueda coincidió con múltiples ciudades}) {
    warn "Tu búsqueda coincidió con múltiples ciudades\n";
    return 0;
  }
  if ($c =~ m{Lo sentimos, no pudimos encontrar esa ubicación}) {
    warn "No hay ciudades\n";
    return 0;
  }
  if ($c =~ m{No se pudo encontrar.*?, mostrando resultados para}) {
    warn "Sin coincidencias\n";
    return 0;
  }
  die "Respuesta desconocida\n$c\n";
}

pb-upload, por John Beppu

Este programa toma nombres de archivo de imágenes de la línea de comandos y los sube a una carpeta de www.photobucket.com. John Beppu, el autor, dice:

Tenía 92 imágenes que quería subir, y hacerlo a través de un navegador habría sido tortura. Pero gracias a mech, todo lo que tuve que hacer fue `./pb.upload *.jpg` y verlo hacer su trabajo. Me sentí bien. Si tuviera más tiempo, implementaría WWW::Photobucket sobre WWW::Mechanize.
#!/usr/bin/perl -w
use strict;
use WWW::Mechanize;
my $login    = "nombre_de_usuario";
my $password = "contraseña";
my $folder   = "carpeta";
my $url = "http://img78.photobucket.com/albums/v281/$login/$folder/";
# iniciar sesión en tu cuenta de photobucket.com
my $mech = WWW::Mechanize->new();
$mech->get($url);
$mech->submit_form(
    form_number => 1,
    fields      => { password => $password },
);
die unless ($mech->success);
# subir archivos de imagen especificados en la línea de comandos
foreach (@ARGV) {
    print "$_\n";
    $mech->form_number(2);
    $mech->field('the_file[]' => $_);
    $mech->submit();
}

listmod, por Ian Langworth

Ian Langworth contribuye esta pequeña joya que brindará alegría a los administradores de listas de correo agobiados. Descarta mensajes de spam a través de la interfaz web de mailman.

#!/arch/unix/bin/perl
use strict;
use warnings;
#
# listmod - alternativa rápida a la interfaz de lista de mailman
#
# uso: listmod crew XXXXXXXX
#
die "uso: $0 <nombre_lista> <contraseña>\n" unless @ARGV == 2;
my ($listname, $password) = @ARGV;
use CGI qw(unescape);
use WWW::Mechanize;
my $m = WWW::Mechanize->new( autocheck => 1 );
use Term::ReadLine;
my $term = Term::ReadLine->new($0);
# enviar el formulario, obtener la cookie, ir a la página de administración de la lista
$m->get("https://lists.ccs.neu.edu/bin/admindb/$listname");
$m->set_visible( $password );
$m->click;
# salir si no hay nada que hacer
print "No hay solicitudes pendientes.\n" and exit
    if $m->content =~ /No hay solicitudes pendientes/;
# seleccionar el primer formulario y examinar su contenido
$m->form_number(1);
my $f = $m->current_form or die "¡No se pudo obtener el primer formulario!\n";
# obtener el elemento del formulario base para cada elemento de correo electrónico
my @items = map {m/^.+?-(.+)/} grep {m/senderbanp/} $f->param
    or die "¡No se pudieron obtener los elementos en el primer formulario!\n";
# iterar a través de los elementos, solicitar al usuario, confirmar acciones
foreach my $item (@items) {
    # mostrar información del elemento
    my $sender = unescape($item);
    my ($subject) = [$f->find_input("senderbanp-$item")->value_names]->[1]
        =~ /Subject:\s+(.+?)\s+Size:/g;
    # solicitar al usuario
    my $choice = '';
    while ( $choice !~ /^[DAX]$/ ) {
        print "$sender\: '$subject'\n";
        $choice = uc $term->readline("Acción: posponer/aceptar/descartar [dax]: ");
        print "\n\n";
    }
    # establecer el botón
    $m->field("senderaction-$item" => {D=>0,A=>1,X=>3}->{$choice});
}
# enviar acciones
$m->click;

ccdl, por Andy Lester

Steve McConnell, autor de la obra cumbre Code Complete, ha publicado los capítulos de la segunda edición en formato PDF en su sitio web. Necesitaba descargarlos para llevarlos a Kinko's para que los imprimieran.
Este pequeño programa hizo eso por mí.

#!/usr/bin/perl -w
use strict;
use WWW::Mechanize;
my $start = "http://www.stevemcconnell.com/cc2/cc.htm";
my $mech = WWW::Mechanize->new( autocheck => 1 );
$mech->get( $start );
my @links = $mech->find_all_links( url_regex => qr/\d+.+\.pdf$/ );
for my $link ( @links ) {
    my $url = $link->url_abs;
    my $filename = $url;
    $filename =~ s[^.+/][];
    print "Descargando $url"
; $mech->get( $url, ':content_file' => $filename ); print " ", -s $filename, " bytes\n"; }

quotes.pl, por Andy Lester

Este era un programa que iba a incluir un hack en Spidering Hacks, pero se cortó en el último minuto, probablemente porque va en contra de los TOS de IMDB raspar información de él. Lo presento aquí como un ejemplo, no como una sugerencia de que infrinjas sus TOS.

La última vez que lo comprobé, no funcionaba porque su HTML no coincidía, pero sigue siendo bueno como código de ejemplo.

#!/usr/bin/perl -w
use strict;
use WWW::Mechanize;
use Getopt::Long;
use Text::Wrap;
my $match = undef;
my $random = undef;
GetOptions(
    "match=s" => \$match,
    "random" => \$random,
) or exit 1;
my $movie = shift @ARGV or die "Debe especificar una película\n";
my $quotes_page = get_quotes_page( $movie );
my @quotes = extract_quotes( $quotes_page );
if ( $match ) {
    $match = quotemeta($match);
    @quotes = grep /$match/i, @quotes;
}
if ( $random ) {
    print $quotes[rand @quotes];
}
else {
    print join( "\n", @quotes );
}
sub get_quotes_page {
    my $movie = shift;
    my $mech = WWW::Mechanize->new;
    $mech->get( "http://www.imdb.com/search" );
    $mech->success or die "No se puede obtener la página de búsqueda";
    $mech->submit_form(
        form_number => 2,
        fields => {
            title   => $movie,
            restrict    => "Solo películas",
        },
    );
    my @links = $mech->find_all_links( url_regex => qr[^/Title] )
        or die "No se encontraron coincidencias para \"$movie\".\n";
    # Usar el primer enlace
    my ( $url, $title ) = @{$links[0]};
    warn "Comprobando $title...\n";
    $mech->get( $url );
    my $link = $mech->find_link( text_regex => qr/Citas memorables/i )
        or die qq{"$title" ¡no tiene citas en IMDB!\n};
    warn "Obteniendo citas...\n\n";
    $mech->get( $link->[0] );
    return $mech->content;
}
sub extract_quotes {
    my $page = shift;
    # Eliminar el HTML no deseado al principio...
    $page =~ s/.+Memorable Quotes//si;
    $page =~ s/.+?(<a name)/$1/si;
    # ... y el final de la página
    $page =~ s/Browse titles in the movie quotes.+$//si;
    $page =~ s/<p.+$//g;
    # Citas separadas por una etiqueta <HR>
    my @quotes = split( /<hr.+?>/, $page );
    for my $quote ( @quotes ) {
        my @lines = split( /<br>/, $quote );
        for ( @lines ) {
            s/<[^>]+>//g;   # Eliminar etiquetas HTML
            s/\s+/ /g;          # Comprimir espacios en blanco
            s/^ //;     # Eliminar espacio inicial
            s/ $//;     # Eliminar espacio final
            s/&#34;/"/g;    # Reemplazar comillas de entidad HTML
            # Ajustar texto a 72 columnas
            $Text::Wrap::columns = 72;
            $_ = wrap( '', '    ', $_ );
        }
        $quote = join( "\n", @lines );
    }
    return @quotes;
}

cpansearch.pl, por Ed Silva

Una pequeña utilidad rápida para buscar en CPAN y abrir un navegador con una página de resultados.

#!/usr/bin/perl
# activar las funciones de seguridad de perl
use strict;
use warnings;
# determinar el nombre del módulo que estamos buscando
my $module_name = $ARGV[0]
  or die "Debe especificar el nombre del módulo en la línea de comandos";
# crear un nuevo navegador
use WWW::Mechanize;
my $browser = WWW::Mechanize->new();
# decirle que obtenga la página principal
$browser->get("http://search.cpan.org/");
# bien, rellenar el cuadro con el nombre del
# módulo que queremos buscar
$browser->form_number(1);
$browser->field("query", $module_name);
$browser->click();
# hacer clic en el enlace que coincide con el nombre del módulo
$browser->follow_link( text_regex => $module_name );
my $url = $browser->uri;
# iniciar un navegador...
system('galeon', $url);
exit(0);

lj_friends.cgi, por Matt Cashner

#!/usr/bin/perl
# Proporciona un feed rss de la lista de amigos de un usuario de pago de LiveJournal
# Entradas completas, entradas protegidas, etc.
# Añadir a tu lector de rss favorito como
# http://tu.sitio.com/cgi-bin/lj_friends.cgi?user=USUARIO&password=CONTRASEÑA
use warnings;
use strict;
use WWW::Mechanize;
use CGI;
my $cgi = CGI->new();
my $form = $cgi->Vars;

$agent->get('http://www.livejournal.com/login.bml');
$agent->form_number('3');

$agent->field('password',$form->{password});

$agent->get('http://www.livejournal.com/customview.cgi?user='.$form->{user}.'&styleid=225596&checkcookies=1');
print "Content-type: text/plain\n\n";
print $agent->content();

Hackeando Movable Type, por Dan Rinzel

use strict;
use WWW::Mechanize;
# una herramienta para publicar automáticamente entradas en un blog de Movable Type, y establecer fechas de creación arbitrarias
my $mech = WWW::Mechanize->new();
my $entry;
$entry->{title} = "Título de entrada automática de prueba";
$entry->{btext} = "Cuerpo de entrada automática de prueba";
$entry->{date} = '2002-04-15 14:18:00';
my $start = qq|http://mi.sitio.blog/mt.cgi|;
$mech->get($start);
$mech->field('username','und3f1n3d');
$mech->field('password','obscur3d');
$mech->submit(); # para obtener la cookie de inicio de sesión
$mech->get(qq|$start?__mode=view&_type=entry&blog_id=1|);
$mech->form_name('entry_form');
$mech->field('title',$entry->{title});
$mech->field('category_id',1); # ajustar según sea necesario
$mech->field('text',$entry->{btext});
$mech->field('status',2); # publicar, o 1 = borrador
$results = $mech->submit();
# si estamos de acuerdo con que esta entrada se marque con la fecha y hora "AHORA" (sin {date} en %entry)
# hemos terminado. De lo contrario, es hora de ser astutos.
# MT devuelve una redirección 302 desde este formulario. la propia redirección contiene un manejador de eventos <body onload="">
# que lleva al usuario a una versión editable del formulario donde se puede editar la fecha de creación
# el formato de fecha de MT de AAAA-MM-DD HH:MI:SS es el único que no generará un error.
if ($entry->{date} && $entry->{date} =~ /^\d{4}-\d{2}-\d{2}\s+\d{2}:\d{2}:\d{2}/) {
    # viajar por la redirección
    $results = $mech->get($results->{_headers}->{location});
    $results->{_content} =~ /<body onLoad="([^\"]+)"/is;
    my $js = $1;
    $js =~ /\'([^']+)\'/;
    $results = $mech->get($start.$1);
    $mech->form_name('entry_form');
    $mech->field('created_on_manual',$entry->{date});
    $mech->submit();
}

get-despair, por Randal Schwartz

Randal envió este bot que recorre el sitio despair.com descargando todas las imágenes.

use strict;
$|++;
use WWW::Mechanize;
use File::Basename;
my $m = WWW::Mechanize->new;
$m->get("http://www.despair.com/indem.html");
my @top_links = @{$m->links};
for my $top_link_num (0..$#top_links) {
    next unless $top_links[$top_link_num][0] =~ /^http:/;
    $m->follow_link( n=>$top_link_num ) or die "no se puede seguir $top_link_num";
    print $m->uri, "\n";
    for my $image (grep m{^http://store4}, map $_->[0], @{$m->links}) {
        my $local = basename $image;
        print " $image...", $m->mirror($image, $local)->message, "\n"
    }
    $m->back or die "no se puede volver";
}
