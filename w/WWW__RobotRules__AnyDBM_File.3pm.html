WWW::RobotRules::AnyDBM_File(3) Documentación Perl contribuida por el usuario WWW::RobotRules::AnyDBM_File(3)

NOMBRE

WWW::RobotRules::AnyDBM_File - Reglas de Robot persistentes

SINOPSIS

require WWW::RobotRules::AnyDBM_File;
require LWP::RobotUA;
# Crear un agente de usuario robot que utiliza un RobotRules con caché en disco
my $rules = WWW::RobotRules::AnyDBM_File->new( 'mi-robot/1.0', 'archivo_cache' );
my $ua = LWP::RobotUA->new( 'mi-robot/1.0', 'yo@foo.com', $rules );
# Luego simplemente usa $ua como de costumbre
$res = $ua->request($req);

DESCRIPCIÓN

Esta es una subclase de WWW::RobotRules que utiliza el paquete AnyDBM_File para implementar el almacenamiento en caché persistente en disco de la información de robots.txt y de las visitas a hosts.

El constructor (el método new()) toma un argumento adicional que especifica el nombre del archivo DBM a utilizar. Si el archivo DBM ya existe, entonces se puede especificar undef como nombre del agente, ya que el nombre se puede obtener de la base de datos DBM.

VER TAMBIÉN

WWW::RobotRules, LWP::RobotUA
