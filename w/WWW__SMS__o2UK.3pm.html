Instalar

Los módulos de Perl se pueden encontrar en http://search.cpan.org/

openssl

Obtener la última versión de openssl en http://www.openssl.org
linux:/usr/src # tar -zxvf openssl-0.9.6g.tar.gz   
$ ./config
$ make
$ make test
$ make install

NET::SSL

Obtener la última versión de Net::Ssl en http://search.cpan.org/author/CHAMAS/    
linux:/usr/src # tar -zxvf Crypt-SSLeay-0.45.tar.gz
  > perl Makefile.PL
  > make
  > make test
  > make install

WWW::SMS

Obtener la última versión de Www::Sms en http://search.cpan.org/author/GIULIENK/
actualizar SMS.pm con el nuevo proveedor si se desea
copiar o2UK.pm en tu directorio de biblioteca perl /WWW/SMS/, por ejemplo en:
linux:/usr/lib/perl5/site_perl/5.6.1/WWW/SMS>
tienes que registrarte en O2 http://www.o2.co.uk/ (anteriormente genie)
que es gratis por el momento y puedes enviar 100 sms/mes gratis
tienes que pasar el nombre de usuario/contraseña o el archivo que lo contiene
todavía no conozco todas las tarjetas SIM proporcionadas: o2 y vodafone funcionan
¡y pruébalo!
use WWW::SMS;
# prefijo internacional, prefijo del operador, número de teléfono, texto del mensaje
my $sms = WWW::SMS->new('44', '7777', '123456', 'Este es un test.','username' => 'tu_usuario_o2', 'password' => 'tu_contraseña_o2');
for ( $sms->gateways() ) {
    print "Intentando $_...\n";
    if ( $sms->send($_) ) {               # intentar enviar un sms...
        last;                             # ¡hasta que tenga éxito! ;)
    } else {
        print $WWW::SMS::Error;           # ¡sin suerte!
    }
}
