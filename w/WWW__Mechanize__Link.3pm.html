Paquete: perl-www-mechanize

WWW::Mechanize::Link(3) Documentación de Perl aportada por el usuario WWW::Mechanize::Link(3)

NOMBRE

WWW::Mechanize::Link - Objeto de enlace para WWW::Mechanize

VERSIÓN

versión 2.20

SINOPSIS

Objeto de enlace para encapsular todas las cosas que Mech necesita pero que nadie quiere manejar como un array.

Constructor

new()

my $link = WWW::Mechanize::Link->new( {
    url  => $url,
    text => $text,
    name => $name,
    tag  => $tag,
    base => $base,
    attr => $attr_href,
} );

Por compatibilidad, también se admite esta interfaz antigua:

new( $url, $text, $name, $tag, $base, $attr_href )

Crea y devuelve un nuevo objeto "WWW::Mechanize::Link".

Accesorios

$link->url()

URL del enlace

$link->text()

Texto del enlace

$link->name()

Atributo NAME de la etiqueta de origen, si existe.

$link->tag()

Nombre de etiqueta (uno de: "a", "area", "frame", "iframe" o "meta").

$link->base()

URL base a la que son relativos los enlaces.

$link->attrs()

Devuelve una referencia hash de todos los atributos y valores de atributos en la etiqueta.

$link->URI()

Devuelve la URL como un objeto URI::URL.

$link->url_abs()

Devuelve un objeto URI::URL para la forma absoluta de la cadena.

VER TAMBIÉN

WWW::Mechanize y WWW::Mechanize::Image
