NOMBRE

Win32::DBIODBC - Capa de emulación Win32::ODBC para el DBI

SINOPSIS

use Win32::DBIODBC;     # en lugar de use Win32::ODBC

DESCRIPCIÓN

Esta es una capa de emulación de Win32::ODBC para el DBI de calidad *muy* básica y *muy* alfa. Para usarla, simplemente reemplaza

use Win32::ODBC;

en tus scripts con

use Win32::DBIODBC;

O, mientras experimentas, puedes precargar este módulo sin cambiar tus scripts haciendo

perl -MWin32::DBIODBC tu_nombre_de_script

PENDIENTE

El manejo de errores es prácticamente inexistente.
