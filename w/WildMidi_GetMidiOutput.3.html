WildMidi_GetMidiOutput(3)

Paquete: wildmidi

Licencias: GPL-3.0-or-later AND LGPL-3.0-or-later

WildMidi_GetMidiOutput(3) Manual del programador de WildMidi WildMidi_GetMidiOutput(3)

NOMBRE

WildMidi_GetMidiOutput - obtener un archivo midi de un archivo que se está procesando.

BIBLIOTECA

libWildMidi

SINOPSIS

#include <wildmidi_lib.h>

int WildMidi_GetMidiOutput (midi *handle, int8_t **buffer, uint32_t *size)

DESCRIPCIÓN

Escribe los datos en formato midi del archivo que se está procesando en la ubicación de memoria apuntada por buffer. Los datos estarán en formato tipo-0 para archivos tipo-0 y tipo-1. Para archivos tipo-2, los datos estarán en formato tipo-2 a menos que se establezca la opción WM_MO_SAVEASTYPE0.

handle
El identificador obtenido al abrir un archivo con WildMidi_Open(3) o WildMidi_OpenBuffer(3)
buffer
La ubicación de memoria donde libWildMidi debe almacenar los datos midi del handle. El buffer se asignará con malloc() y debe ser liberado con free() por el llamador cuando ya no sea necesario.
size
La ubicación donde libWildMidi debe almacenar el tamaño de los datos midi almacenados en buffer.

VALOR DE RETORNO

Devuelve -1 en caso de error, de lo contrario devuelve 0
