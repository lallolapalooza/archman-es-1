WildMidi_GetOutput(3)

Paquete: wildmidi

Licencias: GPL-3.0-or-later AND LGPL-3.0-or-later

WildMidi_GetOutput(3) Manual del programador de WildMidi WildMidi_GetOutput(3)

NOMBRE

WildMidi_GetOutput - recuperar datos de audio sin procesar

BIBLIOTECA

libWildMidi

SINOPSIS

#include <wildmidi_lib.h>

int WildMidi_GetOutput (midi *handle, int8_t *buffer, uint32_t size);

DESCRIPCIÓN

Coloca size bytes de datos de audio de un handle, abierto previamente por WildMidi_Open(3) o WildMidi_OpenBuffer(3), en un puntero de búfer apuntado por buffer.

buffer debe tener al menos size bytes, siendo size un múltiplo de 4 ya que los datos se almacenan en formato estéreo intercalado de 16 bits.

handle
El identificador obtenido al abrir un archivo midi con WildMidi_Open(3) o WildMidi_OpenBuffer(3)
buffer
La ubicación proporcionada por el programa llamante donde libWildMidi debe almacenar los datos de audio. Los datos de audio se almacenarán como estéreo intercalado de 16 bits con signo en el orden de bytes nativo.
size
El tamaño del búfer en bytes. Dado que libWildMidi procesa el audio en formato estéreo intercalado de 16 bits, este valor debe ser un múltiplo de 4.

VALOR DE RETORNO

Devuelve -1 en caso de error junto con un mensaje de error enviado a stderr, 0 cuando no hay más datos de audio, de lo contrario, el número de bytes de datos de audio escritos en buffer.

NOTA: si el valor de retorno es menor que el tamaño que proporcionó, esto no indica un error, simplemente significa que la biblioteca llegó al final del midi antes de poder llenar el búfer.
