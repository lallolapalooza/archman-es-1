NOMBRE

WMShell — La clase de widget WMShell

SINOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPCIÓN

WMShell es un widget de nivel superior que encapsula la interacción con el gestor de ventanas.

Clases

WMShell hereda comportamiento y recursos de las clases Core, Composite y Shell.

El puntero de clase es wmShellWidgetClass.

El nombre de la clase es WMShell.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y utilice las letras restantes (en minúscula o mayúscula, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G), o si no es aplicable (N/A).

XmNbaseHeight
Especifica la base para una progresión de alturas preferidas para que el gestor de ventanas la use al dimensionar el widget. Las alturas preferidas son XmNbaseHeight más múltiplos enteros de XmNheightInc, con un mínimo de XmNminHeight y un máximo de XmNmaxHeight. Si no se proporciona un valor inicial para XmNbaseHeight pero sí para XmNbaseWidth, el valor de XmNbaseHeight se establece en 0 (cero) cuando el widget se realiza.
XmNbaseWidth
Especifica la base para una progresión de anchos preferidos para que el gestor de ventanas la use al dimensionar el widget. Los anchos preferidos son XmNbaseWidth más múltiplos enteros de XmNwidthInc, con un mínimo de XmNminWidth y un máximo de XmNmaxWidth. Si no se proporciona un valor inicial para XmNbaseWidth pero sí para XmNbaseHeight, el valor de XmNbaseWidth se establece en 0 (cero) cuando el widget se realiza.
XmNheightInc
Especifica el incremento para una progresión de alturas preferidas para que el gestor de ventanas la use al dimensionar el widget. Las alturas preferidas son XmNbaseHeight más múltiplos enteros de XmNheightInc, con un mínimo de XmNminHeight y un máximo de XmNmaxHeight. Si no se proporciona un valor inicial para XmNheightInc pero sí para XmNwidthInc, el valor de XmNheightInc se establece en 1 cuando el widget se realiza.
XmNiconMask
Especifica un mapa de bits que el gestor de ventanas podría usar para recortar el mapa de bits XmNiconPixmap para hacer que el icono no sea rectangular.
XmNiconPixmap
Especifica un mapa de bits que el gestor de ventanas podría usar como el icono de la aplicación.
XmNiconWindow
Especifica el ID de una ventana que el gestor de ventanas podría usar como el icono de la aplicación.
XmNiconX
Especifica un lugar adecuado para colocar el icono de la aplicación; esto es una pista para el gestor de ventanas en coordenadas de ventana raíz. Debido a que el gestor de ventanas controla la política de colocación de iconos, este recurso puede ser ignorado.
XmNiconY
Especifica un lugar adecuado para colocar el icono de la aplicación; esto es una pista para el gestor de ventanas en coordenadas de ventana raíz. Debido a que el gestor de ventanas controla la política de colocación de iconos, este recurso puede ser ignorado.
XmNinitialState
Especifica el estado en el que la aplicación desea que se inicie la instancia del widget. Debe ser una de las constantes NormalState o IconicState.

XmNmaxHeight
Especifica la altura máxima que la aplicación desea que tenga la instancia del widget.
XmNmaxWidth
Especifica el ancho máximo que la aplicación desea que tenga la instancia del widget.
XmNminAspectX

XmNminWidth
Especifica el ancho mínimo que la aplicación desea que tenga la instancia del widget.
XmNtitle
Especifica el nombre de la aplicación que debe mostrar el administrador de ventanas. El valor predeterminado es el nombre del icono, si se especifica; de lo contrario, es el nombre de la aplicación. Cuando se llama a XtGetValues en este recurso, el valor devuelto es un puntero al valor real del recurso y no debe liberarse.
XmNtitleEncoding
Especifica un tipo de propiedad que representa la codificación de la cadena XmNtitle. Si se ha establecido un procedimiento de idioma, el valor predeterminado es None; de lo contrario, el valor predeterminado es XA_STRING. Cuando el widget se realiza, si el valor es None, se supone que el nombre correspondiente está en la configuración regional actual. El nombre se pasa a XmbTextListToTextProperty con un estilo de codificación de XStdICCTextStyle. La codificación resultante es STRING si el nombre es completamente convertible a STRING; de lo contrario, es COMPOUND_TEXT. Los valores de los recursos de codificación no se modifican; permanecen como None.
XmNtransient
Especifica un valor booleano que es True si la instancia del widget es transitoria, típicamente una ventana emergente en nombre de otro widget. El administrador de ventanas puede tratar la ventana de un widget transitorio de manera diferente a otras ventanas. Por ejemplo, un administrador de ventanas puede no minimizar una ventana transitoria por separado de su aplicación asociada. Las aplicaciones y los usuarios normalmente no deben modificar este recurso.
XmNwaitForWm
Cuando es True, especifica que Intrinsics espera la duración dada por el recurso XmNwmTimeout a que el administrador de ventanas responda a ciertas acciones antes de asumir que no hay ningún administrador de ventanas presente. Este recurso es alterado por Intrinsics a medida que recibe, o no recibe, respuestas del administrador de ventanas.
XmNwidthInc
Especifica la base para una progresión de anchos preferidos para que el administrador de ventanas los utilice al dimensionar el widget. Los anchos preferidos son XmNbaseWidth más múltiplos enteros de XmNwidthInc, con un mínimo de XmNminWidth y un máximo de XmNmaxWidth. Si no se proporciona un valor inicial para XmNwidthInc pero sí para XmNheightInc, el valor de XmNwidthInc se establece en 1 cuando el widget se realiza.
XmNwindowGroup
Especifica el ID de una ventana con la que está asociada esta instancia del widget. Por convención, esta ventana es la "líder" de un grupo de ventanas. Un administrador de ventanas puede tratar todas las ventanas de un grupo de alguna manera; por ejemplo, puede moverlas o minimizarlas juntas.
Si no se especifica ningún valor inicial, el valor se establece en la ventana del primer widget ancestro realizado en la jerarquía padre cuando el widget se realiza. Si se especifica un valor de XtUnspecifiedWindowGroup, no se establece ningún grupo de ventanas.
XmNwinGravity
Especifica la gravedad de la ventana que utilizará el administrador de ventanas para posicionar el widget. Si no se especifica ningún valor inicial, el valor se establece cuando el widget se realiza. Si XmNgeometry no es NULL, XmNwinGravity se establece en la gravedad de la ventana devuelta por XWMGeometry. De lo contrario, XmNwinGravity se establece en NorthWestGravity.
XmNwmTimeout
Especifica la duración que Intrinsics espera a que el administrador de ventanas responda a ciertas acciones antes de asumir que no hay ningún administrador de ventanas presente. El valor está en milisegundos y no debe ser negativo.

Transacciones

Esta sección describe las transacciones que son proporcionadas por este widget.

WMShell(3)

NAME

WMShell - the Workstation Manager Shell widget

SYNOPSIS

WMShell widget

DESCRIPTION

The WMShell widget is a subclass of the Core widget. It is intended to be used as the base for application shell widgets, such as the ApplicationShell widget. The WMShell widget provides a basic interface for applications that will run under the Motif Window Manager (mwm) or a compatible window manager. It does not provide any geometry management or other features beyond those of the Core widget.

The WMShell widget is not intended to be used directly by application developers. Instead, it serves as a base class for other shell widgets that provide more specific functionality.

WIDGET RELATIONS

The WMShell widget is a subclass of the Core widget.

CALLBACKS

The WMShell widget does not define any callbacks.

RESOURCES

The WMShell widget inherits all of the resources of the Core widget.

Translations

There are no translations for WMShell.

RELATED

Composite(3), Core(3), and Shell(3).
