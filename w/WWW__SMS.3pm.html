NOMBRE

WWW::SMS - envía SMS utilizando el servicio proporcionado por sitios web gratuitos

SINOPSIS

use WWW::SMS;
my $sms = WWW::SMS->new(
    '39',                # prefijo internacional
    '333',               # prefijo del operador
    '1234567',           # número de teléfono
    'Este es un mensaje de prueba.',   # texto del mensaje
    username => 'abcde', # parámetros opcionales
    passwd => 'edcba'    # en forma de hash
);
# o ahora incluso simplemente
my $sms = WWW::SMS->new($numero_entero, $textomensaje);

for ( $sms->gateways(sorted => 'reliability') ) {
                               # para cada gateway compatible
    if ($sms->send( $_ ) {     # intentar enviar el sms
        last;                  # hasta que tenga éxito
    } else {
        print $WWW::SMS:Error; # aquí está el error
    }
}

DESCRIPCIÓN

WWW::SMS es un framework de Perl para enviar SMS gratuitos a través de la web.

Se debe crear un nuevo objeto WWW::SMS con el método new. Una vez creado, puedes enviarlo a través de uno de los submódulos disponibles.

WWW::SMS->new(PREFIJOINT, PREFIJOOP, NUMEROTELEFONO, TEXTOMENSAJE [, OPCIONES]);
WWW::SMS->new(NUMEROENTERO, TEXTOMENSAJE [, OPCIONES]);
Este es el constructor de objetos SMS por defecto.

"PREFIJOINT" es el prefijo internacional: algunos gateways simplemente no usan el prefijo internacional, pero pon algo aquí de todos modos.

"PREFIJOOP" es el prefijo del operador.

"NUMEROTELEFONO" no hay mucho que decir.

"NUMEROENTERO" el constructor alternativo usa el número completo de tu teléfono móvil: incluye el prefijo internacional y el prefijo del operador. Se basa en la base de datos de Telephone::Number para dividir tu número en sus 3 partes básicas. Así que, si no estás seguro, simplemente usa el constructor de "número de teléfono en tres partes".

"TEXTOMENSAJE" incluso aquí no hay mucho que decir. Los submódulos cortarán el SMS a la longitud máxima permitida por el operador. De todos modos, puedes comprobar la longitud máxima buscando la constante MAXLENGTH en los submódulos.

"OPCIONES" se pasan en forma de hash. Las útiles para configurar incluyen:

"proxy" tu proxy HTTP.

"cookie_jar" El archivo donde almacenar las cookies. Si no se establece, cada cookie va al archivo "lwpcookies.txt" en tu directorio de trabajo.

"username" y "passwd" Usados por gateways basados en registro.

Otros parámetros pueden ser requeridos por submódulos específicos.

MÉTODOS

$sms->send("GATEWAY")
Envía $sms usando "GATEWAY": devuelve 1 si es exitoso, 0 si hay errores. El último error está en la variable $WWW::SMS::Error.

"GATEWAY" el gateway que deseas usar para enviar el SMS: debe ser un escalar.

gateways([OPCIONES])
Escanea los directorios de @INC y devuelve un ARRAY que contiene los nombres de los submódulos de gateway disponibles. Si se usa en un objeto SMS, la lista de submódulos devuelta se filtra por la capacidad PREFIX. Así: 
WWW::SMS->gateways(); #devuelve cada gateway disponible
$sms->gateways(); #devuelve solo los gateways que pueden enviar $sms
# gateways compatibles ordenados por fiabilidad
$sms->gateways(sorted => 'reliability');

DIRECTRICES DE SUBMÓDULOS

Entonces, ¿ahora tienes WWW::SMS pero qué sigue? Bueno, toda la genialidad reside en los submódulos. Un submódulo tiene que hacer el trabajo sucio de OBTENER y ENVIAR páginas web. ¿Cómo escribir un submódulo entonces? Hay algunos puntos a observar:

1 Mira primero los submódulos proporcionados como ejemplo!
Sí, copiar y pegar una estructura de submódulo es un buen punto de partida.
2 sub MAXLENGTH
Por favor, establece la constante EXPORTABLE "MAXLENGTH" a la longitud máxima de SMS que el gateway para el que estás escribiendo el script permite.
3 @PREFIXES
"@PREFIXES" debe ser un array de objetos "Telephone::Number". "Telephone::Number"->new toma 3 parámetros: cada uno puede ser un escalar o una referencia a un array. Cada escalar o elemento de los arrays referenciados es una expresión regular. El código verificará que el número de teléfono coincida al menos con una de las expresiones regulares para cada uno de prefijo int, prefijo y número de teléfono. Si no tienes una expresión regular para uno de estos campos, simplemente pasa undef a "Telephone::Number"->new. Mira otros submódulos para formarte mejor una opinión.
4 Pasos y $WWW::SMS::Error
Haz GETs y POSTs como quieras, usando otros submódulos como te plazca. Solo recuerda marcar cada GET o POST con un número de paso incremental. Y cuando tengas un error, por favor, establece la variable de error $WWW::SMS::Error a algo útil e incluye el número de paso en ella, para que la depuración sea más fácil. Luego devuelve 0. Si todo va bien, simplemente devuelve 1.
5 ¡Envía tu módulo de vuelta a la comunidad!
Eso es importante, porque tener un alto número disponible de gateways funcionales es difícil (los sitios web cambian muy rápido), así que todos deberían compartir su implementación de submódulos nueva y genial. Gracias.
