NOMBRE

WWW::Mechanize::Cookbook - Recetas para usar WWW::Mechanize

VERSIÓN

versión 2.20

INTRODUCCIÓN

Primero, ten en cuenta que muchas de estas cosas se pueden hacer solo usando LWP::UserAgent. Como "WWW::Mechanize" es una subclase de LWP::UserAgent, cualquier cosa que funcione en "LWP::UserAgent" debería funcionar en "WWW::Mechanize". Consulta la página del manual de lwpcook incluida con LWP.

BÁSICOS

Lanzar el navegador WWW::Mechanize

use WWW::Mechanize;
my $mech = WWW::Mechanize->new( autocheck => 1 );

El parámetro "autocheck => 1" le dice a Mechanize que termine si alguna operación de E/S falla, para que no tengas que comprobarlo manualmente. Es más fácil así. Si quieres hacer tu propia comprobación de errores, omítelo.

Obtener una página

$mech->get( "http://search.cpan.org" );
print $mech->content;

"$mech->content" contiene el HTML crudo de la página web. No está analizado ni procesado de ninguna manera, al menos a través del método "content".

Obtener una página en un archivo

A veces quieres volcar tus resultados directamente a un archivo. Por ejemplo, no tiene sentido leer un JPEG en memoria si solo vas a escribirlo inmediatamente. Esto también puede ayudar con problemas de memoria en archivos grandes.

$mech->get( "http://www.cpan.org/src/stable.tar.gz",
            ":content_file" => "stable.tar.gz" );

Obtener una página protegida por contraseña

Generalmente, solo llama a "credentials" antes de obtener la página.

$mech->credentials( 'admin' => 'password' );
$mech->get( 'http://10.11.12.13/password.html' );
print $mech->content();

ENLACES

Encontrar todos los enlaces de imágenes

Encuentra todos los enlaces que apuntan a un JPEG, GIF o PNG.

my @links = $mech->find_all_links(
    tag => "a", url_regex => qr/\.(jpe?g|gif|png)$/i );

Encontrar todos los enlaces de descarga

Encuentra todos los enlaces que contienen la palabra "descarga" (en inglés, "download").

my @links = $mech->find_all_links(
    tag => "a", text_regex => qr/\bdownload\b/i );

AVANZADO

Ver qué se enviará sin enviar nada

$mech->add_handler("request_send", sub { shift->dump; exit; });
$mech->get("http://www.example.com");
