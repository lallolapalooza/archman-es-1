Module type S
= sig end

La firma de salida del funtor Weak.Make .

type data

El tipo de los elementos almacenados en la tabla.

type t

El tipo de las tablas que contienen elementos de tipo data . Tenga en cuenta que los conjuntos hash débiles no se pueden serializar utilizando output_value o las funciones del módulo Marshal.

val create : int -> t

create n crea un nuevo conjunto hash débil vacío, de tamaño inicial n . La tabla crecerá según sea necesario.

val clear : t -> unit

Elimina todos los elementos de la tabla.

val merge : t -> data -> data

merge t x devuelve una instancia de x encontrada en t si existe, de lo contrario, agrega x a t y devuelve x .

val add : t -> data -> unit

add t x agrega x a t . Si ya existe una instancia de x en t , no se especifica cuál se devolverá en llamadas posteriores a find y merge .

val remove : t -> data -> unit

remove t x elimina de t una instancia de x . No hace nada si no existe ninguna instancia de x en t .

val find : t -> data -> data

find t x devuelve una instancia de x encontrada en t .

Raises Not_found si no existe dicho elemento.

val find_opt : t -> data -> data option

find_opt t x devuelve una instancia de x encontrada en t o None si no existe dicho elemento.

Since 4.05

val find_all : t -> data -> data list

find_all t x devuelve una lista de todas las instancias de x encontradas en t .

val mem : t -> data -> bool

mem t x devuelve true si existe al menos una instancia de x en t , de lo contrario devuelve false .

val iter : (data -> unit) -> t -> unit

iter f t llama a f en cada elemento de t , en algún orden no especificado. No se especifica qué sucede si f intenta modificar t en sí.

val fold : (data -> 'acc -> 'acc) -> t -> 'acc -> 'acc

fold f t init calcula (f d1 (... (f dN init))) donde d1 ... dN son los elementos de t en algún orden no especificado. No se especifica qué sucede si f intenta modificar t en sí.

val count : t -> int

Cuenta el número de elementos en la tabla. count t da el mismo resultado que fold (fun _ n -> n+1) t 0 pero no retrasa la desasignación de los elementos muertos.

val stats : t -> int * int * int * int * int * int

Devuelve estadísticas de la tabla. Los números son, en orden: longitud de la tabla, número de entradas, suma de las longitudes de los cubos, longitud del cubo más pequeño, longitud mediana del cubo, longitud del cubo más grande.
