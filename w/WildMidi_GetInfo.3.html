WildMidi_GetInfo(3) Manual del programador de WildMidi WildMidi_GetInfo(3)

NOMBRE

WildMidi_GetInfo - obtener información sobre un midi

BIBLIOTECA

libWildMidi

SINOPSIS

#include <wildmidi_lib.h>

struct _WM_Info *WildMidi_GetInfo (midi *handle);

DESCRIPCIÓN

Obtiene información que le permite determinar la posición de la canción, las opciones actuales y cualquier información de derechos de autor.

handle
El identificador obtenido al abrir un archivo midi con WildMidi_Open(3) o WildMidi_OpenBuffer(3)

VALOR DEVUELTO

En caso de error, devuelve NULL y muestra un mensaje de error en stderr.

De lo contrario, devuelve un puntero a una estructura que contiene la información.

struct _WM_Info {
   char *copyright;
   uint32_t current_sample;
   uint32_t approx_total_samples;
   uint32_t total_midi_time;
   uint16_t mixer_options;
   uint32_t total_midi_time;
};
copyright
Un puntero a una cadena terminada en \0 que contiene los eventos MIDI de derechos de autor encontrados mientras se procesaba el archivo MIDI al que se refiere handle. Si se encontró más de un evento de derechos de autor, cada uno está separado por \n

Si copyright es NULL, no se encontraron eventos MIDI de derechos de autor.

current_sample
Este es el número de muestras estéreo que libWildMidi ha procesado para el archivo MIDI al que se refiere handle. Puede usar este valor para determinar el tiempo de reproducción actual dividiendo este valor por la rate dada cuando libWildMidi fue inicializado por WildMidi_Init(3).
approx_total_samples
Este es el número total de muestras estéreo que libWildMidi espera procesar. Esto se puede utilizar para obtener el tiempo total de reproducción dividiendo este valor por la rate dada cuando libWildMidi fue inicializado por WildMidi_Init(3). Además, al dividir current_sample entre este valor y multiplicar por 100, se obtiene el porcentaje procesado actualmente.
total_midi_time
Este es el tiempo total de eventos MIDI en 1/1000 de segundo. Difiere de approx_total_samples en que solo indica el tiempo total dentro del archivo MIDI y no tiene en cuenta el tiempo adicional para terminar de reproducir la muestra suavemente.
mixer_options
WM_MO_LOG_VOLUME
Uso de configuraciones de volumen curvas en lugar de lineales.
WM_MO_ENHANCED_RESAMPLING
El remuestreador mejorado está activo
WM_MO_REVERB
Se está añadiendo reverberación a la salida final.
