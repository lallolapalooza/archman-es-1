NOMBRE

WWW::RobotRules - base de datos de permisos derivados de robots.txt

SINOPSIS

use WWW::RobotRules;
my $rules = WWW::RobotRules->new('MOMspider/1.0');
use LWP::Simple qw(get);
{
  my $url = "http://some.place/robots.txt";
  my $robots_txt = get $url;
  $rules->parse($url, $robots_txt) if defined $robots_txt;
}
{
  my $url = "http://some.other.place/robots.txt";
  my $robots_txt = get $url;
  $rules->parse($url, $robots_txt) if defined $robots_txt;
}
# Ahora podemos verificar si una URL es válida para esos servidores
# cuyos archivos "robots.txt" hemos obtenido y analizado:
if($rules->allowed($url)) {
    $c = get $url;
    ...
}

DESCRIPCIÓN

Este módulo analiza los archivos /robots.txt según lo especificado en "A Standard for Robot Exclusion", en http://www.robotstxt.org/wc/norobots.html Los administradores web pueden usar el archivo /robots.txt para prohibir que los robots que cumplen las normas accedan a partes de su sitio web.

Los archivos analizados se guardan en un objeto WWW::RobotRules, y este objeto proporciona métodos para verificar si el acceso a una URL dada está prohibido. El mismo objeto WWW::RobotRules puede usarse para uno o más archivos /robots.txt analizados en cualquier número de hosts.

Se proporcionan los siguientes métodos:

$rules = WWW::RobotRules->new($robot_name)
Este es el constructor para objetos WWW::RobotRules. El primer argumento dado a new() es el nombre del robot.
$rules->parse($robot_txt_url, $content, $fresh_until)
El método parse() toma como argumentos la URL que se utilizó para recuperar el archivo /robots.txt y el contenido del archivo.
$rules->allowed($uri)
Devuelve TRUE si a este robot se le permite recuperar esta URL.
$rules->agent([$name])
Obtener/establecer el nombre del agente. NOTA: Cambiar el nombre del agente borrará las reglas de robots.txt y los tiempos de expiración de la caché.

ROBOTS.TXT

El formato y la semántica del archivo "/robots.txt" son los siguientes (este es un resumen editado de http://www.robotstxt.org/wc/norobots.html):

El archivo consta de uno o más registros separados por una o más líneas en blanco. Cada registro contiene líneas de la forma

<nombre-campo>: <valor>

El nombre del campo no distingue entre mayúsculas y minúsculas. El texto después del carácter '#' en una línea se ignora durante el análisis. Esto se usa para comentarios. Los siguientes <nombre-campo> se pueden usar:

User-Agent
El valor de este campo es el nombre del robot para el que el registro describe la política de acceso. Si hay más de un campo User-Agent, el registro describe una política de acceso idéntica para más de un robot. Se necesita al menos un campo por registro. Si el valor es '*', el registro describe la política de acceso predeterminada para cualquier robot que no haya coincidido con ninguno de los otros registros.

Los campos User-Agent deben aparecer antes que los campos Disallow. Si un registro contiene un campo User-Agent después de un campo Disallow, eso constituye un registro mal formado. Este analizador asumirá que se debería haber colocado una línea en blanco antes de ese campo User-Agent, y dividirá el registro en dos. Todos los campos anteriores al campo User-Agent constituirán un registro, y el campo User-Agent será el primer campo de un nuevo registro.

Disallow
El valor de este campo especifica una URL parcial que no debe ser visitada. Puede ser una ruta completa o una ruta parcial; cualquier URL que comience con este valor no será recuperada.

Los registros no reconocidos se ignoran.

EJEMPLOS DE ROBOTS.TXT

El siguiente archivo "/robots.txt" de ejemplo especifica que ningún robot debe visitar ninguna URL que comience con "/cyberworld/map/" o "/tmp/":

User-agent: *
Disallow: /cyberworld/map/ # Este es un espacio de URL virtual infinito
Disallow: /tmp/ # estos desaparecerán pronto

Este archivo "/robots.txt" de ejemplo especifica que ningún robot debe visitar ninguna URL que comience con "/cyberworld/map/", excepto el robot llamado "cybermapper":

User-agent: *
Disallow: /cyberworld/map/ # Este es un espacio de URL virtual infinito
# Cybermapper sabe a dónde ir.
User-agent: cybermapper
Disallow:

Este ejemplo indica que ningún robot debe visitar más este sitio :

# vete
User-agent: *
Disallow: /

Este es un ejemplo de un archivo robots.txt mal formado.

# robots.txt para ancientcastle.example.com
# Me he encerrado.
User-agent: *
Disallow: /
# El castillo es ahora tu hogar, así que puedes ir a donde quieras.
User-agent: Belle
Disallow: /west-wing/ # ¡excepto el ala oeste!
# Es bueno ser el Príncipe...
User-agent: Beast
Disallow:

A este archivo le faltan las líneas en blanco requeridas entre los registros. Sin embargo, la intención es clara.
