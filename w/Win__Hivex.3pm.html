Win::Hivex(3) Documentación aportada por el usuario de Perl Win::Hivex(3)

NOMBRE

Win::Hivex - Enlaces de Perl para leer y escribir archivos de colmena del Registro de Windows

SINOPSIS

use Win::Hivex;
$h = Win::Hivex->open ('SOFTWARE');
$root_node = $h->root ();
print $h->node_name ($root_node);

DESCRIPCIÓN

El módulo "Win::Hivex" proporciona un enlace XS de Perl a la API de hivex(3) para leer y escribir archivos binarios de colmena del Registro de Windows.

ERRORES

Todos los errores se convierten en llamadas a "croak" (ver Carp(3)).

MÉTODOS

open
$h = Win::Hivex->open ($nombre_archivo,
                       [verbose => 1,]
                       [debug => 1,]
                       [write => 1,]
                       [unsafe => 1,])

Abre un archivo de colmena binaria del Registro de Windows.

Las banderas "verbose" y "debug" habilitan diferentes niveles de mensajes de depuración.

La bandera "write" es necesaria si vas a modificar el archivo de colmena (ver "ESCRITURA EN ARCHIVOS DE COLMENA" en hivex(3)).

Esta función devuelve un manejador de colmena. El manejador de colmena se cierra automáticamente cuando su recuento de referencias cae a 0.

root
$nodo = $h->root ()

Devuelve el nodo raíz de la colmena. Todas las colmenas válidas deben contener un nodo raíz.

Esto devuelve un manejador de nodo.

last_modified
$int64 = $h->last_modified ()

Devuelve la hora de modificación de la cabecera de la colmena.

El valor devuelto es una hora de archivo de Windows. Para convertirlo a un "time_t" de Unix, consulta: http://stackoverflow.com/questions/6161776/convert-windows-filetime-to-second-in-unix-linux/6161842#6161842

node_name
$cadena = $h->node_name ($nodo)

Devuelve el nombre del nodo.

Ten en cuenta que el nombre del nodo raíz es ficticio, como "$$$PROTO.HIV" (pueden ser posibles otros nombres: parece depender de la herramienta o programa que creó la colmena en primer lugar). Solo puedes conocer el nombre "real" del nodo raíz sabiendo de qué archivo de registro proviene originalmente esta colmena, lo cual es un conocimiento que está fuera del alcance de esta biblioteca.

El nombre se recodifica a UTF-8 y puede contener caracteres NUL incrustados.

node_name_len
$tamaño = $h->node_name_len ($nodo)

Devuelve la longitud del nombre del nodo tal como lo produce "node_name".

Esto devuelve un tamaño.

node_timestamp
$int64 = $h->node_timestamp ($nodo)

Devuelve la hora de modificación del nodo.

El valor devuelto es una hora de archivo de Windows. Para convertirlo a un "time_t" de Unix, consulta: http://stackoverflow.com/questions/6161776/convert-windows-filetime-to-second-in-unix-linux/6161842#6161842

node_children
@nodos = $h->node_children ($nodo)

Devuelve una matriz de nodos que son las subclaves (hijos) del "nodo".

Esto devuelve una lista de manejadores de nodo.

node_get_child
$nodo = $h->node_get_child ($nodo, $nombre)

Devuelve el hijo del nodo con el nombre "nombre", si existe.

El nombre se compara sin distinción entre mayúsculas y minúsculas.

Esto devuelve un manejador de nodo, o "undef" si el nodo no se encontró.

node_nr_children
$tamaño = $h->node_nr_children ($nodo)

Devuelve el número de nodos tal como lo produce "node_children".

Esto devuelve un tamaño.

node_parent
$nodo = $h->node_parent ($nodo)

Devuelve el padre del "nodo".

El puntero padre del nodo raíz en los archivos de registro que hemos examinado parece ser inválido, por lo que esta función devolverá un error si se llama en el nodo raíz.

Esto devuelve un manejador de nodo.

node_values
@valores = $h->node_values ($nodo)

Devuelve la matriz de pares (clave, valor) adjuntos a este nodo.

Esto devuelve una lista de manejadores de valor.

node_get_value
$valor = $h->node_get_value ($nodo, $clave)

Devuelve el valor adjunto a este nodo que tiene el nombre "clave", si existe.

El nombre de la clave se compara sin distinción entre mayúsculas y minúsculas.

Ten en cuenta que para obtener la clave predeterminada, debes pasar la cadena vacía "" aquí. La clave predeterminada a menudo se escribe como "@", pero dentro de las colmenas no tiene significado y no te dará la clave predeterminada.

Esto devuelve un manejador de valor.

node_nr_values
$tamaño = $h->node_nr_values ($nodo)

Devuelve el número de pares (clave, valor) adjuntos a este nodo como produce "node_values".

Esto devuelve un tamaño.

value_key_len
$tamaño = $h->value_key_len ($val)

Devuelve la longitud de la clave (nombre) de un par (clave, valor) como produce "value_key". La longitud puede ser legítimamente 0, por lo que errno es el mecanismo necesario para comprobar errores.

En el contexto de los Registros de Windows, un nombre de longitud cero significa que este valor es la clave predeterminada para este nodo en el árbol. Esto generalmente se escribe como "@".

La clave se recodifica a UTF-8 y puede contener caracteres NUL incrustados.

Esto devuelve un tamaño.

value_key
$cadena = $h->value_key ($val)

Devuelve la clave (nombre) de un par (clave, valor). El nombre se re-codifica como UTF-8 y se devuelve como una cadena.

La cadena debe ser liberada por el llamador cuando ya no sea necesaria.

Ten en cuenta que esta función puede devolver una cadena de longitud cero. En el contexto de los Registros de Windows, esto significa que este valor es la clave predeterminada para este nodo en el árbol. Esto generalmente se escribe como "@".

value_type
($tipo, $len) = $h->value_type ($val)

Devuelve la longitud de los datos y el tipo de datos del valor en este par (clave, valor). Ver también "value_value" que devuelve toda esta información, y el valor en sí. Además, las funciones "value_*" a continuación que se pueden usar para devolver el valor de una forma más útil cuando se conoce el tipo de antemano.

Win::Hivex(3pm)

NAME

Win::Hivex - Perl bindings for the hivex library

SYNOPSIS

 use Win::Hivex;

 my $h = Win::Hivex->open ($filename);
 # or
 my $h = Win::Hivex->open_memory ($data);

 my $root = $h->root;
 my $node = $h->node_get_child ($root, "subkey");

 my $val = $h->node_get_value ($node, "myval");
 my ($type, $data) = $h->value_value ($val);

 if ($type eq "hive_t_string") {
  my $str = $h->value_string ($val);
  # ...
 } elsif ($type eq "hive_t_dword") {
  my $dword = $h->value_dword ($val);
  # ...
 }

 $h->node_set_value ($node, $new_val_handle);

 $h->commit ("newfile.hiv");
 $h->close;

DESCRIPTION

This module provides Perl bindings for the libguestfs hivex library. The hivex library allows access to Windows registry hives.

For more details, see the hivex documentation at http://libguestfs.org/hivex.

ERRORS

Methods can fail. If they fail, they will return undef, and set the Perl global variable $! and $@ to an error code. If the error is from the underlying hivex library, the error code will be a string starting with "hivex: ". If the error is a standard POSIX error, then $! will be set appropriately.

METHODS

open
$hive = Win::Hivex->open ($filename, [$read_only])

Open a Windows registry hive file named "filename". If "read_only" is true (the default), the hive is opened read-only. If false, the hive is opened for reading and writing.

Returns a hive handle on success, or undef on failure.

open_memory
$hive = Win::Hivex->open_memory ($data)

Open a Windows registry hive from a string containing the file data. This is useful for accessing hives that have been read from disk or network by other means.

Returns a hive handle on success, or undef on failure.

close
$h->close ()

Close the hive handle. Any uncommitted changes are lost.

root
$node = $h->root ()

Return the root node of the hive.

node_get_child
$node = $h->node_get_child ($parent, $name)

Return the child node of "parent" named "name".

The name matching is case-insensitive.

node_get_value
$val = $h->node_get_value ($node, $name)

Return the value handle named "name" from the node "node".

The name matching is case-insensitive.

node_get_reg_value
$val = $h->node_get_reg_value ($node, $name)

Return the value handle named "name" from the node "node". This is the same as node_get_value, but uses the registry name convention (e.g. "(Default)")

node_struct_length
$size = $h->node_struct_length ($node)

Return the length of the node data structure.

This returns a size.

value_struct_length
$size = $h->value_struct_length ($val)

Return the length of the value data structure.

This returns a size.

value_data_cell_offset
($len, $value) = $h->value_data_cell_offset ($val)

Return the offset and length of the value's data cell.

The data cell is a registry structure that contains the length (a 4 byte, little endian integer) followed by the data.

If the length of the value is less than or equal to 4 bytes then the offset and length returned by this function is zero as the data is inlined in the value.

Returns 0 and sets errno on error.

value_value
($type, $data) = $h->value_value ($val)

Return the value of this (key, value) pair. The value should be interpreted according to its type (see "hive_type").

value_string
$string = $h->value_string ($val)

If this value is a string, return the string reencoded as UTF-8 (as a C string). This only works for values which have type "hive_t_string", "hive_t_expand_string" or "hive_t_link".

value_multiple_strings
@strings = $h->value_multiple_strings ($val)

If this value is a multiple-string, return the strings reencoded as UTF-8 (in C, as a NULL-terminated array of C strings, in other language bindings, as a list of strings). This only works for values which have type "hive_t_multiple_strings".

value_dword
$int32 = $h->value_dword ($val)

If this value is a DWORD (Windows int32), return it. This only works for values which have type "hive_t_dword" or "hive_t_dword_be".

value_qword
$int64 = $h->value_qword ($val)

If this value is a QWORD (Windows int64), return it. This only works for values which have type "hive_t_qword".

commit
$h->commit ([$filename|undef])

Commit (write) any changes which have been made.

"filename" is the new file to write. If "filename" is null/undefined then we overwrite the original file (ie. the file name that was passed to "open").

Note this does not close the hive handle. You can perform further operations on the hive after committing, including making more modifications. If you no longer wish to use the hive, then you should close the handle after committing.

node_add_child
$node = $h->node_add_child ($parent, $name)

Add a new child node named "name" to the existing node "parent". The new child initially has no subnodes and contains no keys or values. The sk-record (security descriptor) is inherited from the parent.

The parent must not have an existing child called "name", so if you want to overwrite an existing child, call "node_delete_child" first.

This returns a node handle.

node_delete_child
$h->node_delete_child ($node)

Delete the node "node". All values at the node and all subnodes are deleted (recursively). The "node" handle and the handles of all subnodes become invalid. You cannot delete the root node.

node_set_values
$h->node_set_values ($node, \@values)

This call can be used to set all the (key, value) pairs stored in "node".

"node" is the node to modify.

@values is an array of (keys, value) pairs. Each element should be a hashref containing "key", "t" (type) and "data".

Any existing values stored at the node are discarded, and their "value" handles become invalid. Thus you can remove all values stored at "node" by passing "@values = []".

node_set_value
$h->node_set_value ($node, $val)

This call can be used to replace a single "(key, value)" pair stored in "node". If the key does not already exist, then a new key is added. Key matching is case insensitive.

"node" is the node to modify.
