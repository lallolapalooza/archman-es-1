WildMidi_OpenBuffer(3) Manual del programador de WildMidi WildMidi_OpenBuffer(3)

NOMBRE

WildMidi_OpenBuffer - Abrir un búfer de archivo midi para procesamiento

BIBLIOTECA

libWildMidi

SINOPSIS

#include <wildmidi_lib.h>

midi *WildMidi_OpenBuffer (uint8_t *midibuffer, uint32_t size)

DESCRIPCIÓN

Abrir un archivo, que has almacenado en memoria, para su procesamiento.

midibuffer
La ubicación en memoria del archivo almacenado. Este búfer debe estar en formato de archivo HMP, HMI, MIDI o XMIDI. Una vez que se llama a esta función, cualquier cambio en el búfer no tendrá ningún efecto.
size
Este es el tamaño del archivo midi en bytes que se almacena en memoria.

VALOR DE RETORNO

Devuelve NULL en caso de error, de lo contrario devuelve un manejador para el búfer midi abierto.
