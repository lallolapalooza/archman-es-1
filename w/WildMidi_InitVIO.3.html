WildMidi_InitVIO(3) Manual del programador de WildMidi WildMidi_InitVIO(3)

NOMBRE

WildMidi_InitVIO - Inicializa la biblioteca con callbacks de E/S de archivo

BIBLIOTECA

libWildMidi

SINOPSIS

#include <wildmidi_lib.h>

WildMidi_InitVIO (struct _WM_VIO *callbacks, const char *config_file, uint16_t rate, uint16_t options)

DESCRIPCIÓN

Inicializa libWildMidi en preparación para la reproducción y establece los punteros de función para la E/S de archivo según lo proporcionado por el llamador. Esta función solo necesita ser llamada una vez por el programa que utiliza libWildMidi.

callbacks
Puntero a una estructura de callbacks de E/S de archivo. La estructura _WM_VIO es como la siguiente: 
struct _WM_VIO {
 /* Esta función debe asignar un búfer que tenga el tamaño
  * del archivo solicitado más uno (tamaño+1), rellenar el búfer
  * con el contenido del archivo y el segundo parámetro con el
  * tamaño del archivo. */
    void * (* allocate_file)(const char *, uint32_t *);
 /* Esta función debe liberar la memoria del búfer dado */
    void   (* free_file)    (void *);
};
archivo-de-configuración
El archivo que contiene la configuración de instrumentos para la biblioteca.
tasa
La tasa de sonido a la que desea que se generen los datos de audio. Las tasas aceptadas por libWildMidi son 11025 - 65000.
opciones
Las opciones iniciales a establecer para la biblioteca. ver abajo.
WM_MO_VOLUMEN_LOGARITMICO
Por defecto, la biblioteca utiliza niveles de volumen lineales típicamente usados en reproductores MIDI de computadora. Estos pueden diferir un poco de los niveles de volumen encontrados en algunos hardware MIDI que pueden usar una curva de volumen basada en decibelios. Esta opción establece los niveles de volumen a lo que se esperaría en tales dispositivos.
WM_MO_MUESTREO_MEJORADO
Por defecto, libWildMidi utiliza interpolación lineal para el remuestreo de las muestras de sonido. Establecer esta opción habilita a la biblioteca a utilizar un método de remuestreo que intenta rellenar los huecos, dando un sonido más rico.
WM_MO_REVERBERACIÓN
libWildMidi tiene un motor de reverberación de 8 reflexiones. Usa esta opción para dar más profundidad a la salida.
WM_MO_TEMPO_COMPLETO
Ignora la parte fraccionaria o decimal de un ajuste de tempo. Si tienes problemas de temporización, prueba WM_MO_TEMPO_REDONDEADO antes de probar esta opción. Esta opción se añadió debido a que algunos programas no soportan los tempos fraccionarios permitidos en la especificación MIDI.
WM_MO_TEMPO_REDONDEADO
Redondea la parte fraccionaria o decimal de un ajuste de tempo. Prueba esta opción si tienes problemas de temporización, si esto falla entonces prueba WM_MO_TEMPO_COMPLETO. Esta opción se añadió debido a que algunos programas no soportan los tempos fraccionarios permitidos en la especificación MIDI.
