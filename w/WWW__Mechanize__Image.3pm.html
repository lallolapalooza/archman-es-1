WWW::Mechanize::Image(3) Documentación de Perl contribuida por el usuario WWW::Mechanize::Image(3)

NOMBRE

WWW::Mechanize::Image - Objeto de imagen para WWW::Mechanize

VERSIÓN

versión 2.20

SINOPSIS

Objeto de imagen para encapsular todas las cosas que Mech necesita

Constructor

new()

Crea y devuelve un nuevo objeto "WWW::Mechanize::Image".

my $image = WWW::Mechanize::Image->new( {
    url    => $url,
    base   => $base,
    tag    => $tag,
    name   => $name,     # Desde la etiqueta INPUT
    height => $height,   # opcional
    width  => $width,    # opcional
    alt    => $alt,      # opcional
    attrs  => $attr_ref, # opcional
} );

Accesoress

$image->url()

URL de la imagen desde el atributo "src" de la etiqueta de origen.

Puede ser "undef" si la etiqueta de origen no tiene un atributo "src".

$image->base()

URL base a la que son relativas las enlaces.

$image->name()

Nombre del campo del atributo NAME, si existe.

$image->tag()

Nombre de la etiqueta (ya sea "image" o "input")

$image->height()

Altura de la imagen

$image->width()

Ancho de la imagen

$image->alt()

Atributo ALT de la etiqueta de origen, si existe.

$image->attrs()

Referencia hash de todos los atributos y sus valores en la etiqueta.

$image->URI()

Devuelve la URL como un objeto URI::URL.

$image->url_abs()

Devuelve la URL como una cadena de URL absoluta.

VER TAMBIÉN

WWW::Mechanize y WWW::Mechanize::Link
