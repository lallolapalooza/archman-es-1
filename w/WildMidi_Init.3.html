WildMidi_Init(3) Manual del programador de WildMidi WildMidi_Init(3)

NOMBRE

WildMidi_Init - Inicializa la biblioteca

BIBLIOTECA

libWildMidi

SINOPSIS

#include <wildmidi_lib.h>

WildMidi_Init (const char *archivo_configuracion, uint16_t tasa, uint16_t opciones)

DESCRIPCIÓN

Inicializa libWildMidi en preparación para la reproducción. Esta función solo necesita ser llamada una vez por el programa que utiliza libWildMidi.

archivo_configuracion
El archivo que contiene la configuración de instrumentos para la biblioteca.
tasa
La tasa de sonido con la que deseas que se generen los datos de audio. Las tasas aceptadas por libWildMidi son de 11025 - 65000.
opciones
Las opciones iniciales a establecer para la biblioteca. ver abajo.
WM_MO_LOG_VOLUME
Por defecto, la biblioteca utiliza niveles de volumen lineales típicamente usados en reproductores MIDI de computadora. Estos pueden diferir un poco de los niveles de volumen encontrados en algunos hardwares MIDI que pueden usar una curva de volumen basada en decibelios. Esta opción establece los niveles de volumen a lo que esperarías en dichos dispositivos.
WM_MO_ENHANCED_RESAMPLING
Por defecto, libWildMidi usa interpolación lineal para el remuestreo de las muestras de sonido. Establecer esta opción habilita la biblioteca a usar un método de remuestreo que intenta llenar los vacíos, dando un sonido más rico.
WM_MO_REVERB
libWildMidi tiene un motor de reverberación de 8 reflexiones. Usa esta opción para dar más profundidad a la salida.
WM_MO_WHOLETEMPO
Ignora la parte fraccionaria o decimal de un ajuste de tempo. Si tienes problemas de temporización, prueba WM_MO_ROUNDTEMPO antes de probar esta opción. Esta opción se añadió debido a que algunos software no soportan tempos fraccionarios permitidos en la especificación MIDI.
WM_MO_ROUNDTEMPO
Redondea la parte fraccionaria o decimal de un ajuste de tempo. Prueba esta opción si tienes problemas de temporización, si esto falla, prueba WM_MO_WHOLETEMPO. Esta opción se añadió debido a que algunos software no soportan tempos fraccionarios permitidos en la especificación MIDI.
