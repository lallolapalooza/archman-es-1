NOMBRE

Tie::Scalar, Tie::StdScalar - definiciones de clase base para escalares atados

SINOPSIS

package NuevoEscalar;
require Tie::Scalar;
@ISA = qw(Tie::Scalar);
sub FETCH { ... }           # Proporcionar un método necesario
sub TIESCALAR { ... }       # Sobrescribir método heredado
package NuevoStdEscalar;
require Tie::Scalar;
@ISA = qw(Tie::StdScalar);
# Todos los métodos se proporcionan por defecto, así que define
# sólo lo que necesite ser sobrescrito
sub FETCH { ... }
package main;
tie $nuevo_escalar, 'NuevoEscalar';
tie $nuevo_std_escalar, 'NuevoStdEscalar';

DESCRIPCIÓN

Este módulo proporciona algunos métodos esqueléticos para clases de atar escalares. Consulte perltie para obtener una lista de las funciones requeridas para atar un escalar a un paquete. El paquete base Tie::Scalar proporciona un método "new", así como los métodos "TIESCALAR", "FETCH" y "STORE". El paquete Tie::StdScalar proporciona todos los métodos especificados en perltie. Hereda de Tie::Scalar y hace que los escalares atados a él se comporten exactamente como los escalares integrados, permitiendo la sobrecarga selectiva de métodos. El método "new" se proporciona como un medio de soporte heredado para clases que olvidan proporcionar su propio método "TIESCALAR".

Para los desarrolladores que deseen escribir sus propias clases de escalares atados, los métodos se resumen a continuación. La sección perltie no sólo documenta estos, sino que también tiene ejemplos de código:

TIESCALAR nombre_clase, LISTA
El método invocado por el comando "tie $escalar, nombre_clase". Asocia una nueva instancia escalar con la clase especificada. "LISTA" representaría argumentos adicionales (en la línea de AnyDBM_File y compatriotas) necesarios para completar la asociación.
FETCH this
Recupera el valor del escalar atado referenciado por this.
STORE this, valor
Almacena datos valor en el escalar atado referenciado por this.
DESTROY this
Libera el almacenamiento asociado con el escalar atado referenciado por this. Esto es raramente necesario, ya que Perl gestiona su memoria bastante bien. Pero la opción existe, en caso de que una clase desee realizar acciones específicas al destruir una instancia.

Tie::Scalar vs Tie::StdScalar

"Tie::Scalar" proporciona todos los métodos necesarios, pero hay que tener en cuenta que no hacen nada útil. Llamar a "Tie::Scalar::FETCH" o "Tie::Scalar::STORE" resulta en un croak (que se puede atrapar). Y si heredas de "Tie::Scalar", debes proporcionar un método "new" o un método "TIESCALAR".

Si buscas una clase que haga todo por ti lo que no definas tú mismo, usa la clase "Tie::StdScalar", no la clase "Tie::Scalar".
