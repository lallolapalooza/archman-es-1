TIOCTTYGSTRUCT(2const) TIOCTTYGSTRUCT(2const)

NOMBRE

TIOCTTYGSTRUCT - depuración del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/ioctl.h>
int ioctl(int fd, TIOCTTYGSTRUCT, struct tty_struct *argp);
#include <linux/tty.h>
struct tty_struct;

DESCRIPCIÓN

Obtiene la tty_struct correspondiente a fd.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

HISTORIA

Esta operación fue eliminada en Linux 2.5.67.

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
