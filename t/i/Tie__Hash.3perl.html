Tie::Hash(3perl) Guía de referencia para programadores de Perl Tie::Hash(3perl)

NOMBRE

Tie::Hash, Tie::StdHash, Tie::ExtraHash - definiciones de clases base para hashes atados

SINOPSIS

package NuevoHash;
require Tie::Hash;
@ISA = qw(Tie::Hash);
sub DELETE { ... }          # Proporciona el método necesario
sub CLEAR { ... }           # Sobrescribe el método heredado
package NuevoStdHash;
require Tie::Hash;
@ISA = qw(Tie::StdHash);
# Todos los métodos proporcionados por defecto, define
# solo aquellos que necesiten ser sobrescritos
# Los accesores acceden al almacenamiento en %{$_[0]};
# TIEHASH debe devolver una referencia al almacenamiento real
sub DELETE { ... }
package NuevoExtraHash;
require Tie::Hash;
@ISA = qw(Tie::ExtraHash);
# Todos los métodos proporcionados por defecto, define
# solo aquellos que necesiten ser sobrescritos
# Los accesores acceden al almacenamiento en %{$_[0][0]};
# TIEHASH debe devolver una referencia a un array con el primer elemento
# siendo la referencia al almacenamiento real
sub DELETE {
  $_[0][1]->('del', $_[0][0], $_[1]); # Llama al escritor de informes
  delete $_[0][0]->{$_[1]};           #  $_[0]->SUPER::DELETE($_[1])
}
package main;
tie %nuevo_hash, 'NuevoHash';
tie %nuevo_std_hash, 'NuevoStdHash';
tie %nuevo_extra_hash, 'NuevoExtraHash',
    sub {warn "Haciendo \U$_[1]\E de $_[2].\n"};

DESCRIPCIÓN

Este módulo proporciona algunos métodos esqueléticos para clases de hashes atados. Consulte perltie para obtener una lista de las funciones necesarias para atar un hash a un paquete. El paquete básico Tie::Hash proporciona un método "new", así como los métodos "TIEHASH", "EXISTS" y "CLEAR". Los paquetes Tie::StdHash y Tie::ExtraHash proporcionan la mayoría de los métodos para hashes descritos en perltie (las excepciones son "UNTIE" y "DESTROY"). Hacen que los hashes atados se comporten exactamente como hashes estándar, y permiten la sobrescritura selectiva de métodos. Tie::Hash tiene soporte heredado para el método "new": se usa si "TIEHASH" no está definido en el caso de que una clase olvide incluir un método "TIEHASH".

Para los desarrolladores que deseen escribir sus propios hashes atados, los métodos requeridos se definen brevemente a continuación. Consulte la sección perltie para obtener una descripción más detallada, así como ejemplos de código:

TIEHASH nombre_clase, LISTA
El método invocado por el comando "tie %hash, nombre_clase". Asocia una nueva instancia de hash con la clase especificada. "LISTA" representaría argumentos adicionales (en la línea de AnyDBM_File y sus compatriotas) necesarios para completar la asociación.
STORE this, clave, valor
Almacena el dato valor en la clave para el hash atado this.
FETCH this, clave
Recupera el dato de la clave para el hash atado this.
FIRSTKEY this
Devuelve la primera clave del hash.
NEXTKEY this, ultimaclave
Devuelve la siguiente clave del hash.
EXISTS this, clave
Verifica que la clave existe en el hash atado this.

La implementación de Tie::Hash es un stub que simplemente falla.

DELETE this, clave
Elimina la clave del hash atado this.
CLEAR this
Borra todos los valores del hash atado this.
SCALAR this
Devuelve lo que la evaluación del hash en contexto escalar produce.

Tie::Hash no implementa este método (pero Tie::StdHash y Tie::ExtraHash sí lo hacen).

Herencia de Tie::StdHash

Los métodos accesores asumen que el almacenamiento real de los datos en el hash atado está en el hash referenciado por tied(%tiedhash). Por lo tanto, el método "TIEHASH" sobrescrito debe devolver una referencia a un hash, y los métodos restantes deben operar en el hash referenciado por el primer argumento:

package HashReporte;
our @ISA = 'Tie::StdHash';
sub TIEHASH  {
  my $storage = bless {}, shift;
  warn "Nuevo HashReporte creado, almacenado en $storage.\n";
  $storage
}
sub STORE    {
  warn "Almacenando datos con clave $_[1] en $_[0].\n";
  $_[0]{$_[1]} = $_[2]
}

Herencia de Tie::ExtraHash

Los métodos accesores asumen que el almacenamiento real de los datos en el hash atado está en el hash referenciado por "(tied(%tiedhash))->[0]". Por lo tanto, el método "TIEHASH" sobrescrito debe devolver una referencia a un array con el primer elemento siendo una referencia a un hash, y los métodos restantes deben operar en el hash "%{ $_[0]->[0] }":

package HashReporte;
our @ISA = 'Tie::ExtraHash';
sub TIEHASH  {
  my $class = shift;
  my $storage = bless [{}, @_], $class;
  warn "Nuevo HashReporte creado, almacenado en $storage.\n";
  $storage;
}
sub STORE    {
  warn "Almacenando datos con clave $_[1] en $_[0].\n";
  $_[0][0]{$_[1]} = $_[2]
}

El método "TIEHASH" por defecto almacena argumentos "extra" para tie() a partir del índice 1 en el array referenciado por tied(%tiedhash); este es el mismo algoritmo de almacenamiento que en la subrutina TIEHASH anterior. Por lo tanto, un paquete típico que hereda de Tie::ExtraHash no necesita sobrescribir este método.

"SCALAR", "UNTIE" y "DESTROY"

Los métodos "UNTIE" y "DESTROY" no están definidos en Tie::Hash, Tie::StdHash, ni Tie::ExtraHash. Los hashes atados no requieren la presencia de estos métodos, pero si se definen, los métodos se llamarán en el momento adecuado, consulte perltie.

"SCALAR" solo está definido en Tie::StdHash y Tie::ExtraHash.

Si es necesario, estos métodos deben ser definidos por el paquete que hereda de Tie::Hash, Tie::StdHash o Tie::ExtraHash. Consulte "SCALAR" en perltie para saber qué sucede cuando "SCALAR" no existe.

MÁS INFORMACIÓN

Los paquetes relacionados con varias implementaciones de DBM (DB_File, NDBM_File, etc.) muestran ejemplos de hashes atados generales, al igual que el módulo Config. Si bien estos no utilizan Tie::Hash, sirven como buenos ejemplos de trabajo.
