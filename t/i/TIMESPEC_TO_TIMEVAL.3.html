TIMEVAL_TO_TIMESPEC(3) Manual de funciones de biblioteca TIMEVAL_TO_TIMESPEC(3)

NOMBRE

TIMEVAL_TO_TIMESPEC, TIMESPEC_TO_TIMEVAL - convertir entre estructuras de tiempo

SINOPSIS

#define _GNU_SOURCE
#include <sys/time.h>
void TIMEVAL_TO_TIMESPEC(const struct timeval *tv, struct timespec *ts);
void TIMESPEC_TO_TIMEVAL(struct timeval *tv, const struct timespec *ts);

DESCRIPCIÓN

Estas macros convierten de una estructura timeval(3type) a una estructura timespec(3type), y viceversa, respectivamente.

Esto es especialmente útil para escribir interfaces que reciben un tipo, pero se implementan con llamadas a funciones que reciben el otro.

ESTÁNDARES

GNU, BSD.
