Tie::Handle(3perl) Guía del programador de Perl Tie::Handle(3perl)

NOMBRE

Tie::Handle - definiciones de clase base para manejadores enlazados

SINOPSIS

package NewHandle;
require Tie::Handle;
@ISA = qw(Tie::Handle);
sub READ { ... }            # Proporcionar un método necesario
sub TIEHANDLE { ... }       # Sobrescribe el método heredado
package main;
tie *FH, 'NewHandle';

DESCRIPCIÓN

Este módulo proporciona algunos métodos esqueléticos para clases de enlazado de manejadores. Consulte perltie para ver una lista de las funciones requeridas para enlazar un manejador a un paquete. El paquete base Tie::Handle proporciona un método "new", así como los métodos "TIEHANDLE", "PRINT", "PRINTF" y "GETC".

Para los desarrolladores que deseen escribir sus propias clases de manejadores enlazados, los métodos se resumen a continuación. La sección perltie no solo documenta estos, sino que también tiene código de ejemplo:

TIEHANDLE nombre_clase, LISTA
El método invocado por el comando "tie *glob, nombre_clase". Asocia una nueva instancia de glob con la clase especificada. "LISTA" representaría argumentos adicionales (en la línea de AnyDBM_File y sus compatriotas) necesarios para completar la asociación.
WRITE esto, escalar, longitud, desplazamiento
Escribe longitud bytes de datos desde escalar comenzando en desplazamiento.
PRINT esto, LISTA
Imprime los valores de LISTA
PRINTF esto, formato, LISTA
Imprime los valores de LISTA usando formato
READ esto, escalar, longitud, desplazamiento
Lee longitud bytes de datos en escalar comenzando en desplazamiento.
READLINE esto
Lee una sola línea
GETC esto
Obtiene un solo carácter
CLOSE esto
Cierra el manejador
OPEN esto, nombre_archivo
Abre (reabre) el manejador
BINMODE esto
Especifica que el contenido es binario
EOF esto
Comprueba el fin de archivo.
TELL esto
Devuelve la posición en el archivo.
SEEK esto, desplazamiento, origen
Posiciona el archivo.

Comprueba el fin de archivo.

DESTROY esto
Libera el almacenamiento asociado con el manejador enlazado referenciado por esto. Esto rara vez es necesario, ya que Perl gestiona su memoria bastante bien. Pero la opción existe, en caso de que una clase desee realizar acciones específicas al destruir una instancia.

COMPATIBILIDAD

Esta versión de Tie::Handle no está relacionada ni es compatible con el módulo Tie::Handle (3.0) disponible en CPAN. Fue por accidente que aparecieron dos módulos con el mismo nombre. El conflicto de nombres se ha resuelto a favor de este módulo que viene con el núcleo de perl en septiembre de 2000 y, en consecuencia, el número de versión se ha incrementado a 4.0.
