TIOCSLCKTRMIOS(2const) TIOCSLCKTRMIOS(2const)

NOMBRE

TIOCGLCKTRMIOS, TIOCSLCKTRMIOS - bloqueo de la estructura termios

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de las constantes TIOC*CLKTRMIOS */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGLCKTRMIOS, struct termios *argp);
int ioctl(int fd, TIOCSLCKTRMIOS, const struct termios *argp);
#include <asm/termbits.h>
struct termios;

DESCRIPCIÓN

La estructura termios de una terminal puede ser bloqueada. El bloqueo es en sí mismo una estructura termios, con bits o campos distintos de cero indicando un valor bloqueado.

TIOCGLCKTRMIOS
Obtiene el estado de bloqueo de la estructura termios de la terminal.
TIOCSLCKTRMIOS
Establece el estado de bloqueo de la estructura termios de la terminal. Solo un proceso con la capacidad CAP_SYS_ADMIN puede hacer esto.

VALOR DEVUELTO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EPERM
Permiso insuficiente.

ADVERTENCIAS

Tenga en cuenta que struct termios de <asm/termbits.h> es diferente e incompatible con struct termios de <termios.h>. Estas llamadas ioctl requieren struct termios de <asm/termbits.h>.

VER TAMBIÉN

ioctl(2), ioctl_tty(2), TCSETS(2const)
