TIFFREADDIRECTORY(3tiff) LibTIFF TIFFREADDIRECTORY(3tiff)

NOMBRE

TIFFReadDirectory - obtener el contenido del siguiente directorio en un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
int TIFFReadDirectory(TIFF *tif)

DESCRIPCIÓN

Lee el siguiente directorio en el archivo especificado y lo convierte en el directorio actual. Las aplicaciones solo necesitan llamar a TIFFReadDirectory() para leer múltiples subarchivos en un solo archivo TIFF —el primer directorio de un archivo se lee automáticamente cuando se llama a TIFFOpen().

NOTAS

Si la biblioteca se compila con STRIPCHOP_SUPPORT habilitado, las imágenes que tienen una sola tira o mosaico de datos sin comprimir se tratan automáticamente como si estuvieran compuestas por múltiples tiras o mosaicos de aproximadamente 8 kilobytes cada uno. Esta operación se realiza solo en memoria; no altera el contenido del archivo. Sin embargo, la construcción de las "tiras cortadas" es visible para la aplicación a través del número de tiras [mosaicos] devuelto por TIFFNumberOfStrips() [TIFFNumberOfTiles()].

VALORES DE RETORNO

Si el siguiente directorio se leyó correctamente, se devuelve 1. De lo contrario, se devuelve 0 si se encontró un error o si no hay más directorios que leer.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR(). Del mismo modo, los mensajes de advertencia se dirigen a la rutina TIFFWarningExtR().

Error de búsqueda al acceder al directorio TIFF:

Ocurrió un error al posicionarse en la ubicación del directorio.

Tipo de datos incorrecto %d para el campo "%s":

La entrada de etiqueta en el directorio tenía un tipo de datos incorrecto. Por ejemplo, una etiqueta ImageDescription con un tipo de datos SHORT.

Directorio TIFF al que le falta el campo requerido "%s":

La especificación TIFF 5.0 requiere que la etiqueta especificada esté presente, pero falta. El directorio es (generalmente) inutilizable.

%s: Racional con denominador cero:

Una etiqueta de directorio tiene un valor RATIONAL cuyo denominador es cero.

Recuento incorrecto %d para el campo "%s" (%lu, esperando %lu); etiqueta ignorada:

El campo de recuento de la etiqueta es incorrecto. Por ejemplo, un recuento distinto de 1 para una etiqueta SubFileType.

No se pueden manejar valores por muestra diferentes para el campo "%s":

La etiqueta tiene valores SamplesPerPixel y no todos son iguales; por ejemplo, BitsPerSample. La biblioteca no puede manejar imágenes de este tipo.

Desajuste de recuento para el campo "%s"; se esperaban %d, se obtuvieron %d:

El campo de recuento en una etiqueta no concuerda con el número esperado por la biblioteca. Esto nunca debería suceder, por lo que si sucede, la biblioteca se niega a leer el directorio.

Directorio TIFF inválido; las etiquetas no están ordenadas en orden ascendente:

Las etiquetas del directorio no están ordenadas correctamente según lo especificado en la especificación TIFF 5.0. Este error no es fatal.

Ignorando campo desconocido con etiqueta %d (0x%x):

Se encontró una etiqueta desconocida en el directorio; la biblioteca ignora todas esas etiquetas.

Directorio TIFF al que le falta el campo requerido "ImageLength":

La imagen viola la especificación al no tener un campo necesario. No hay forma de que la biblioteca se recupere de este error.

Directorio TIFF al que le falta el campo requerido "PlanarConfig":

La imagen viola la especificación al no tener un campo necesario. No hay forma de que la biblioteca se recupere de este error.

Directorio TIFF al que le falta el campo requerido "StripOffsets":

La imagen tiene múltiples tiras, pero carece de la etiqueta que especifica el desplazamiento del archivo a cada tira de datos. No hay forma de que la biblioteca se recupere de este error.

Directorio TIFF al que le falta el campo requerido "TileOffsets":

La imagen tiene múltiples mosaicos, pero carece de la etiqueta que especifica el desplazamiento del archivo a cada mosaico de datos. No hay forma de que la biblioteca se recupere de este error.

Directorio TIFF al que le falta el campo requerido "StripByteCounts":

La imagen tiene múltiples tiras, pero carece de la etiqueta que especifica el tamaño de cada tira de datos. No hay forma de que la biblioteca se recupere de este error.

Directorio TIFF al que le falta el campo requerido "StripByteCounts", calculando a partir de imagelength:

La imagen viola la especificación al no tener un campo necesario. Sin embargo, cuando la imagen consta de una sola tira o mosaico, la biblioteca estimará el valor faltante basándose en el tamaño del archivo.

Campo "StripByteCounts" erróneo, ignorando y calculando a partir de imagelength:

Ciertos proveedores violan la especificación al escribir cero para la etiqueta StripByteCounts cuando desean dejar el valor sin especificar. Si la imagen tiene una sola tira, la biblioteca estimará el valor faltante basándose en el tamaño del archivo.
