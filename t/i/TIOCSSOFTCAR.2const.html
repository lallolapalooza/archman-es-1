TIOCSSOFTCAR(2const) TIOCSSOFTCAR(2const)

NOMBRE

TIOCGSOFTCAR, TIOCSSOFTCAR - marcar una línea como local

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de constantes TIOC*SOFTCAR */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGSOFTCAR, int *argp);
int ioctl(int fd, TIOCSSOFTCAR, const int *argp);

DESCRIPCIÓN

TIOCGSOFTCAR
("Obtener bandera de portadora de software") Obtiene el estado de la bandera CLOCAL en el campo c_cflag de la estructura termios.
TIOCSSOFTCAR
("Establecer bandera de portadora de software") Establece la bandera CLOCAL en la estructura termios cuando *argp no es cero, y la despeja en caso contrario.

Si la bandera CLOCAL de una línea está desactivada, la señal de detección de portadora de hardware (DCD) es significativa, y un open(2) del terminal correspondiente se bloqueará hasta que DCD se aserte, a menos que se proporcione la bandera O_NONBLOCK. Si CLOCAL está activada, la línea se comporta como si DCD estuviera siempre aseverada. La bandera de portadora de software generalmente se activa para dispositivos locales y está desactivada para líneas con módems.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
