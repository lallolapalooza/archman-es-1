NOMBRE

TIFFError - interfaz de manejo de errores de la biblioteca

SINOPSIS

#include <tiffio.h>
#include <stdarg.h>
void TIFFError(const char *module, const char *fmt, ...)
void TIFFErrorExt(thandle_t fd, const char *module, const char *fmt, ...)
void TIFFErrorExtR(TIFF *tif, const char *module, const char *fmt, ...)
typedef void (*TIFFErrorHandler)(const char *module, const char *fmt, va_list ap)
typedef void (*TIFFErrorHandlerExt)(thandle_t fd, const char *module, const char *fmt, va_list ap)
typedef int (*TIFFErrorHandlerExtR)(TIFF *tif, void *user_data, const char *module, const char *fmt, va_list ap)
TIFFErrorHandler TIFFSetErrorHandler(TIFFErrorHandler handler)
TIFFErrorHandlerExt TIFFSetErrorHandlerExt(TIFFErrorHandlerExt handler)

DESCRIPCIÓN

TIFFError() invoca la función de manejo de errores de toda la biblioteca para (normalmente) escribir un mensaje de error en stderr. El parámetro fmt es una cadena de formato de printf() y se pueden suministrar argumentos adicionales. El parámetro module se interpreta como una cadena que, si no es cero, debe imprimirse antes del mensaje; normalmente se utiliza para identificar el módulo de software en el que se detecta un error.

Las aplicaciones que deseen capturar el control en caso de error deben usar TIFFSetErrorHandler() para reemplazar el manejador de errores predeterminado. Se puede instalar una función de manejo de errores **NULL** (0) para suprimir los mensajes de error.

Hay disponibles dos devoluciones de llamada de manejo de errores más específicas de la aplicación, cada una con diferentes parámetros de llamada y paso de parámetros al manejador. Cada manejador también está vinculado a una función de mensaje de error, es decir, TIFFErrorExt() y TIFFErrorExtR() si la aplicación pretende llamar al manejador con esos parámetros extendidos.

TIFFErrorExt() proporciona un identificador de archivo como parámetro. Dentro de **libtiff**, TIFFErrorExt() se llama pasando tif->tif_clientdata como fd, que representa el identificador de archivo TIFF (descriptor de archivo). El manejador específico de la aplicación y de toda la biblioteca para TIFFErrorExt() se configura con TIFFSetErrorHandlerExt().

TIFFErrorExtR() (introducido con libtiff 4.5) se llama con su identificador TIFF y, por lo tanto, proporciona acceso a un manejador de errores por identificador TIFF (reentrante). Esto significa que para diferentes identificadores TIFF, se pueden configurar diferentes manejadores de errores. Este manejador específico de la aplicación se puede configurar al abrir un archivo TIFF con una de las siguientes funciones: TIFFOpenExt(), TIFFOpenWExt(), TIFFFdOpenExt() o TIFFClientOpenExt(). Además, se puede proporcionar una **estructura de datos definida por el usuario** user_data para el manejador de errores.

NOTA

Ambas funciones TIFFError() y TIFFErrorExt() intentan llamar a ambas funciones manejadoras si están definidas. Primero se llama a TIFFErrorHandler() y luego a TIFFErrorHandlerExt(). Sin embargo, TIFFError() pasa un "0" como identificador de archivo a TIFFErrorHandlerExt().

TIFFErrorExtR() intenta primero llamar al manejador de errores definido por identificador TIFF. Si TIFFErrorHandlerExtR() no está definido o devuelve 0, se llaman TIFFErrorHandler() y luego TIFFErrorHandlerExt(). A partir de libtiff 4.5, TIFFErrorExtR() se utiliza dentro de la biblioteca **libtiff** donde está disponible el identificador TIFF. De lo contrario, ¡se utiliza TIFFErrorExt()!

VALORES DE RETORNO

TIFFSetErrorHandler() y TIFFSetErrorHandlerExt() devuelven una referencia a la función de manejo de errores anterior.

TIFFErrorHandlerExtR() devuelve un entero como "stop" para controlar la llamada a otras funciones de manejo de mensajes de error dentro de TIFFErrorExtR():

  • 0: se llaman ambas funciones TIFFErrorHandler() y TIFFErrorHandlerExt().
  • no cero: no se llama a ninguna otra función de mensaje de error.
