Time::Format(3) Documentación de Perl aportada por el usuario Time::Format(3)

NOMBRE

Time::Format - Formateo fácil de fecha/hora.

VERSIÓN

Esta es la versión 1.16 de Time::Format, 19 de febrero de 2020.

SINOPSIS

use Time::Format qw(%time %strftime %manip);
$time{$format}
$time{$format, $unixtime}
print "Hoy es $time{'yyyy/mm/dd'}\n";
print "Ayer fue $time{'yyyy/mm/dd', time-24*60*60}\n";
print "La hora es $time{'hh:mm:ss'}\n";
print "Otra hora es $time{'H:mm am tz', $otra_hora}\n";
print "Marca de tiempo: $time{'yyyymmdd.hhmmss.mmm'}\n";

%time también acepta cadenas de Date::Manip y objetos DateTime:

$dm = Date::Manip::ParseDate('el lunes pasado');
print "El lunes pasado fue $time{'Month d, yyyy', $dm}";
$dt = DateTime->new (....);
print "Aquí hay otra fecha: $time{'m/d/yy', $dt}";

También acepta la mayoría de cadenas ISO-8601 de fecha/hora:

$t = '2005/10/31T17:11:09';   # separador de fecha: / o - o .
$t = '2005-10-31 17.11.09';   # separador intermedio: T o _ o espacio
$t = '20051031_171109';       # separador de hora: : o .
$t = '20051031171109';        # se pueden omitir los separadores
$t = '2005/10/31';            # solo fecha es aceptable
$t = '17:11:09';              # solo hora es aceptable
# Pero no:
$t = '20051031';              # solo fecha sin separadores
$t = '171109';                # solo hora sin separadores
# ...porque parecen números de tiempo epoch.

%strftime funciona como el "strftime" de POSIX, si te gustan esos formatos con "%".

$strftime{$format}
$strftime{$format, $unixtime}
$strftime{$format, $sec,$min,$hour, $mday,$mon,$year, $wday,$yday,$isdst}
print "Estilo POSIX: $strftime{'%A, %B %d, %Y', 0,0,0,12,11,95,2}\n";
print "Estilo POSIX: $strftime{'%A, %B %d, %Y', 1054866251}\n";
print "Estilo POSIX: $strftime{'%A, %B %d, %Y'}\n";       # hora actual

%manip funciona como la función "UnixDate" de Date::Manip.

$manip{$format};
$manip{$format, $when};
print "Date::Manip: $manip{'%m/%d/%Y'}\n";            # hora actual
print "Date::Manip: $manip{'%m/%d/%Y','el martes pasado'}\n";

Estos también se pueden usar como funciones independientes:

use Time::Format qw(time_format time_strftime time_manip);
print "Hoy es ", time_format('yyyy/mm/dd', $alguna_hora), "\n";
print "Estilo POSIX: ", time_strftime('%A %B %d, %Y',$alguna_hora), "\n";
print "Date::Manip: ", time_manip('%m/%d/%Y',$alguna_hora), "\n";

DESCRIPCIÓN

Este módulo crea pseudovariables globales que formatean fechas y horas, de acuerdo con códigos de formato que les pasas en cadenas.

Los códigos de formato de %time están diseñados para ser fáciles de recordar y usar, y para ocupar tantos caracteres como sea posible del valor de salida del tiempo. Por ejemplo, el código de año de cuatro dígitos es ""yyyy"", la abreviatura de mes de tres letras es ""Mon"".

Lo bueno de tener una interfaz similar a una variable en lugar de llamadas a funciones es que los valores se pueden usar dentro de cadenas (así como fuera de cadenas en expresiones ordinarias). Las fechas se usan con frecuencia dentro de cadenas (mensajes de registro, salida, registros de datos, etc.), por lo que tener la capacidad de interpolarlas directamente es conveniente.

Perl permite expresiones arbitrarias dentro de llaves de un hash, incluso cuando ese hash se está interpolando en una cadena. Esto te permite hacer cálculos sobre la marcha mientras formateas tiempos y los insertas en cadenas. Ve el ejemplo de "ayer" arriba.

Las cadenas de formato están diseñadas pensando en los programadores. ¿Qué necesitas con más frecuencia? Año de 4 dígitos, mes, día, hora en base 24, minuto, segundo -- usualmente con ceros iniciales. Estos seis son los formatos más fáciles de usar y recordar en Time::Format: "yyyy", "mm", "dd", "hh", "mm", "ss". Las variantes de estos formatos siguen una fórmula simple y consistente. Este módulo es para cualquiera que esté cansado de intentar recordar los códigos arcanos de strftime(3), o de escribir interminablemente "$t[4]++; $t[5]+=1900" mientras formateas manualmente tiempos o fechas.

Ten en cuenta que "mm" (y códigos relacionados) se usan tanto para meses como para minutos. Esto es una característica. %time resuelve la ambigüedad examinando otros códigos de formato cercanos. Si está en el contexto de un año o un día, se asume "mes". Si está en el contexto de una hora o un segundo, se asume "minuto".

Las cadenas de formato no están destinadas a abarcar todas las necesidades de fecha/hora jamás concebidas. Pero, ¿con qué frecuencia necesitas el día del año (el %j de strftime) o el número de semana (el %W de strftime)?

Para capacidades que %time no proporciona, %strftime proporciona una interfaz al "strftime" de POSIX, y %manip proporciona una interfaz a la función "UnixDate" del módulo Date::Manip.

Si el módulo complementario Time::Format_XS también está instalado, Time::Format lo detectará y lo usará. Esto resultará en un aumento significativo de velocidad para %time y "time_format".

VARIABLES

tiempo
$time{$formato}
$time{$formato,$valor_tiempo};

Formatea un número de tiempo unix (segundos desde la época), objeto DateTime, DateTime en cadena, cadena Date::Manip o cadena ISO-8601, según el formato especificado. Si se omite la expresión de tiempo, se usa la hora actual. La cadena de formato puede contener cualquiera de los siguientes:

yyyy       año de 4 dígitos
yy         año de 2 dígitos
m          número de mes de 1 o 2 dígitos, 1-12
mm         número de mes de 2 dígitos, 01-12
?m         mes con espacio inicial si es < 10
Month      nombre completo del mes, mayúsculas/minúsculas mixtas
MONTH      nombre completo del mes, en mayúsculas
month      nombre completo del mes, en minúsculas
Mon        abreviatura de 3 letras del mes, mayúsculas/minúsculas mixtas
MON  mon   ídem, versiones en mayúsculas y minúsculas
d          número del día, 1-31
dd         número del día, 01-31
?d         día con espacio inicial si es < 10
th         sufijo del día (st, nd, rd, o th)
TH         sufijo en mayúsculas
Weekday    nombre del día de la semana, mayúsculas/minúsculas mixtas
WEEKDAY    nombre del día de la semana, en mayúsculas
weekday    nombre del día de la semana, en minúsculas
Day        abreviatura de 3 letras del día de la semana, mayúsculas/minúsculas mixtas
DAY  day   ídem, versiones en mayúsculas y minúsculas
h          hora, 0-23
hh         hora, 00-23
?h         hora, 0-23 con espacio inicial si es < 10
H          hora, 1-12
HH         hora, 01-12
?H         hora, 1-12 con espacio inicial si es < 10
m          minuto, 0-59
mm         minuto, 00-59
?m         minuto, 0-59 con espacio inicial si es < 10
s          segundo, 0-59
ss         segundo, 00-59
?s         segundo, 0-59 con espacio inicial si es < 10
mmm        milésima de segundo, 000-999
uuuuuu     millonésima de segundo, 000000-999999
am   a.m.  La cadena "am" o "pm" (segunda forma con puntos)
pm   p.m.  igual que "am" o "a.m."
AM   A.M.  igual que "am" o "a.m." pero en mayúsculas
PM   P.M.  igual que "AM" o "A.M."
tz         abreviatura de zona horaria

La milésima y millonésima de segundo requieren Time::HiRes, de lo contrario siempre serán cero. La zona horaria requiere POSIX, de lo contrario será la cadena vacía. Los códigos de segundo ("s", "ss", "?s") pueden ser 60 o 61 en circunstancias raras (segundos bisiestos, si tu sistema soporta tales).

Cualquier cosa en la cadena de formato que no sea de los patrones anteriores se deja intacta. Cualquier carácter precedido por una barra invertida se deja solo y no se usa para ninguna parte de un código de formato. Consulta la sección "COMILLAS" para más detalles.

En su mayor parte, cada uno de los códigos de formato anteriores ocupa tanto espacio como la cadena de salida que genera. Las excepciones son los códigos cuya salida tiene una longitud variable: "Weekday", "Month", la zona horaria y los códigos de un solo carácter.

;, y los códigos de "Day" devuelven el nombre del mes o día de la semana en la representación de mayúsculas y minúsculas preferida para la configuración regional activa. Por lo tanto, en una configuración regional de habla inglesa, el séptimo mes sería "July" (primera letra mayúscula, el resto minúsculas); mientras que en una configuración regional de habla francesa, sería "juillet" (todo en minúsculas). Consulte la sección "QUOTING" para conocer las formas de controlar las mayúsculas y minúsculas de los nombres de meses/días de la semana.

Tenga en cuenta que los formatos ""mm"", ""m"" y ""?m"" son ambiguos. %time intenta adivinar si quiso decir "month" (mes) o "minute" (minuto) basándose en los caracteres cercanos en la cadena de formato. Por lo tanto, un formato de ""yyyy/mm/dd hh:mm:ss"" se analiza correctamente como "año mes día, hora minuto segundo". Si %time no puede determinar si quiso decir "month" o "minute", deja "mm", "m" o "?m" sin traducir. Para eliminar la ambigüedad, puede usar los siguientes códigos:

m{on}        mes, 1-12
mm{on}       mes, 01-12
?m{on}       mes, 1-12 con espacio inicial si es < 10
m{in}        minuto, 0-59
mm{in}       minuto, 00-59
?m{in}       minuto, 0-59 con espacio inicial si es < 10

En otras palabras, añada ""{on}"" o ""{in}"" para que ""m"", ""mm"" o ""?m"" no sean ambiguos.

strftime
$strftime{$format, $sec,$min,$hour, $mday,$mon,$year, $wday,$yday,$isdst}
$strftime{$format, $unixtime}
$strftime{$format}

Para aquellos que prefieren los extraños formatos % de strftime, o que necesitan cumplimiento POSIX, o que necesitan números de semana u otras características que %time no proporciona.

manip
$manip{$format};
$manip{$format,$when};

Proporciona una interfaz para la función "UnixDate" del módulo Date::Manip. Esta función es bastante lenta, pero puede analizar una amplia variedad de entradas de fechas. Consulte el módulo Date::Manip para obtener detalles sobre las entradas aceptadas.

Si desea utilizar los códigos de %time, pero necesita la flexibilidad de entrada de %manip, puede usar la función "ParseDate" de Date::Manip:

print "$time{'yyyymmdd', ParseDate('last sunday')}";

FUNCIONES

time_format
time_format($format);
time_format($format, $unix_time);

Esta es una interfaz de función para %time. Acepta los mismos códigos de formato y todo. Esto se proporciona para personas que quieren que las llamadas a funciones *parezcan* llamadas a funciones, ¡no hashes! :-) Los dos siguientes son equivalentes:

$x = $time{'yyyy/mm/dd'};
$x = time_format('yyyy/mm/dd');
time_strftime
time_strftime($format, $sec,$min,$hour, $mday,$mon,$year, $wday,$yday,$isdst);
time_strftime($format, $unixtime);
time_strftime($format);

Esta es una interfaz de función para %strftime. Simplemente llama a POSIX::"strftime", pero proporciona una pequeña ventaja sobre llamar directamente a "strftime", ya que puede pasar la hora como hora unix (segundos desde la época) u omitirla para obtener la hora actual.

time_manip
manip($format);
manip($format,$when);

Esta es una interfaz de función para %manip. Llama a Date::Manip::"UnixDate" internamente. No proporciona mucha ventaja sobre llamar directamente a "UnixDate", excepto que puede omitir el parámetro $when para obtener la hora actual.

COMILLAS

Esta sección se aplica solo a las cadenas de formato utilizadas por %time y "time_format".

A veces es necesario suprimir la expansión de algunos caracteres de formato en una cadena de formato. Por ejemplo:

$time{'Hour: hh; Minute: mm{in}; Second: ss'};

En la expresión anterior, la "H" de "Hour" se expandiría, al igual que la "d" de "Second". El resultado sería algo como:

8our: 08; Minute: 10; Secon17: 30

No sería una buena solución dividir la declaración anterior en tres llamadas a %time:

"Hour: $time{hh}; Minute: $time{'mm{in}'}; Second: $time{ss}"

porque la hora podría cambiar de una llamada a la siguiente, lo que sería un problema cuando los números se reiniciaran (por ejemplo, un instante después de las 7:59:59).

Por esta razón, puede escapar códigos de formato individuales con una barra invertida:

$time{'\Hour: hh; Minute: mm{in}; Secon\d: ss'};

Tenga en cuenta que con cadenas entre comillas dobles (y qq//), la barra invertida debe duplicarse, porque Perl primero interpola la cadena:

$time{"\\Hour: hh; Minute: mm{in}; Secon\\d: ss"};

Para mayor comodidad, Time::Format simula los operadores de comillas en línea \Q y \E integrados de Perl. Todo en una cadena entre un \Q y \E no se interpolará como parte de ningún código de formato:

$time{'\QHour:\E hh; \QMinute:\E mm{in}; \QSecond:\E ss'};

Nuevamente, dentro de cadenas interpoladas, la barra invertida debe duplicarse, de lo contrario Perl interpretará y eliminará la secuencia \Q...\E antes de que Time::Format la reciba:

$time{"\\QHour:\\E hh; \\QMinute:\\E mm{in}; \\QSecond\\E: ss"};

Time::Format también reconoce y simula las secuencias \U, \L, \u y \l. Esto es realmente útil solo para un control más fino de los formatos Month, Mon, Weekday y Day. Por ejemplo, en algunas configuraciones regionales, los nombres de los meses están en minúsculas por convención. Al principio de una oración, es posible que desee asegurarse de que el primer carácter esté en mayúscula:

$time{'\uMonth \Qis the finest month of all.'};

Nuevamente, asegúrese de usar \Q y asegúrese de duplicar las barras invertidas en cadenas interpoladas, de lo contrario obtendrá algo feo como:

July i37 ste fine37t july of all.

EJEMPLOS

$time{'Weekday Month d, yyyy'}   Thursday June 5, 2003
$time{'Day Mon d, yyyy'}         Thu Jun 5, 2003
$time{'dd/mm/yyyy'}              05/06/2003
$time{yymmdd}                    030605
$time{'yymmdd',time-86400}       030604
$time{'dth of Month'}            5th of June
$time{'H:mm:ss am'}              1:02:14 pm
$time{'hh:mm:ss.uuuuuu'}         13:02:14.171447
$time{'yyyy/mm{on}/dd hh:mm{in}:ss.mmm'}  2003/06/05 13:02:14.171
$time{'yyyy/mm/dd hh:mm:ss.mmm'}          2003/06/05 13:02:14.171
$time{"It's H:mm."}              It'14 1:02.    # ¡ERROR!
$time{"It'\\s H:mm."}            It's 1:02.     # La barra invertida lo arregla.
                                                                              .
                                                                              .
# Renombrar un archivo basado en la fecha de hoy:
rename $file, "${file}_$time{yyyymmdd}";
# Renombrar un archivo basado en su fecha de última modificación:
rename $file, "${file}_$time{'yyyymmdd',(stat $file)[9]}";
# Ejemplos de stftime
$strftime{'%A %B %d, %Y'}                 Thursday June 05, 2003
$strftime{'%A %B %d, %Y',time+86400}      Friday June 06, 2003
# Ejemplos de manip
$manip{'%m/%d/%Y'}                                   06/05/2003
$manip{'%m/%d/%Y','yesterday'}                       06/04/2003
$manip{'%m/%d/%Y','first monday in November 2000'}   11/06/2000

INTERNACIONALIZACION

Si el módulo I18N::Langinfo está disponible, Time::Format devolverá los nombres de los días de la semana y de los meses en el idioma apropiado para la configuración regional actual. Si no, se utilizarán nombres en inglés.

Los programadores en configuraciones regionales no inglesas pueden desear proporcionar un alias para %time en su idioma preferido. Esto se puede hacer asignando "\%time" a un typeglob:

# Francés
use Time::Format;
use vars '%temps';  *temps = \%time;
print "C'est aujourd'hui le $temps{'d Month'}\n";
# Alemán
use Time::Format;
use vars '%zeit';   *zeit = \%time;
print "Heutiger Tag ist $zeit{'d.m.yyyy'}\n";

EXPORTACIONES

Los siguientes símbolos se exportan a su espacio de nombres por defecto:

%time
time_format

Los siguientes símbolos están disponibles para importar a su espacio de nombres:

%strftime
%manip
time_strftime
time_manip

La etiqueta ":all" importará todos estos a su espacio de nombres. Ejemplo:

use Time::Format ':all';

LIMITACIONES

La cadena de formato utilizada por %time no debe tener $; como subcadena en ningún lugar. $; (por defecto, el carácter ASCII 28, o 1C hexadecimal) se utiliza para separar los valores pasados al hash ligado, y por lo tanto Time::Format interpretará su cadena de formato como dos o más argumentos si contiene $;. La función "time_format" no tiene esta limitación.

REQUISITOS

Time::Local
I18N::Langinfo, si desea que funcionen las configuraciones regionales no inglesas.
POSIX, si elige usar %strftime o desea que funcione el formato C<tz>.
Time::HiRes, si desea que funcionen los formatos de tiempo C<mmm> y C<uuuuuu>.
Date::Manip, si elige usar %manip.
Time::Format_XS es opcional pero hará que C<%time> y C<time_format>
    sean mucho más rápidos. La versión de Time::Format_XS instalada debe coincidir
    con la versión de Time::Format instalada; de lo contrario, Time::Format
    no la utilizará (y emitirá una advertencia).
