NOMBRE

Time::Human - Convierte el formato localtime() a la hora del "reloj parlante"

SINOPSIS

use Time::Human;
print "La hora es ahora ", humanize(localtime());

DESCRIPCIÓN

Este módulo proporciona una representación "vaga" de la hora en lenguaje natural; está diseñado originalmente para aplicaciones de texto a voz y otras interfaces basadas en voz.

Está completamente internacionalizado: si miras el código, verás una variable global llamada %Time::Human::templates, que puedes rellenar para otros idiomas. Si lo internacionalizas, por favor envíame plantillas para otros idiomas para ser incluidas en futuras versiones. Puedes establecer el idioma predeterminado a través de la variable global $Time::Human::Language

$Time::Human::Evening y $Time::Human::Night deciden las horas a las que la tarde se convierte en noche y la noche se convierte en madrugada en tu cultura. Por ejemplo, los griegos pueden querer que la tarde comience a las 11 p.m.; para los hackers, la tarde puede comenzar a las 3 a.m.

USO

Parámetros de importación

Este módulo no acepta argumentos para su método "import" (de hecho, ni siquiera tiene un
método "import").

Exportaciones

Este módulo exporta un único *símbolo*, la función "humanize".
