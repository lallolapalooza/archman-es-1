NOMBRE

TIFFWriteEncodedStrip - comprime y escribe una tira de datos a un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
tsize_t TIFFWriteEncodedStrip(TIFF *tif, tstrip_t strip, tdata_t buf, tsize_t size)

DESCRIPCIÓN

Comprime size bytes de datos crudos de buf y escribe el resultado en la tira especificada; reemplazando cualquier dato previamente escrito. Tenga en cuenta que el valor de strip es un número de tira "crudo". Es decir, el llamador debe tener en cuenta si los datos están organizados en planos separados (PlanarConfiguration = 2).

NOTAS

La biblioteca escribe datos codificados usando el orden de bytes nativo de la máquina. Se espera que los lectores TIFF implementados correctamente realicen cualquier intercambio de bytes necesario para procesar correctamente los datos de imagen con BitsPerSample mayor que 8.

El número de tira debe ser válido de acuerdo con la configuración actual de las etiquetas ImageLength y RowsPerStrip. Una imagen puede crecer dinámicamente aumentando el valor de ImageLength antes de cada llamada a TIFFWriteEncodedStrip.

VALORES DE RETORNO

Se devuelve -1 si se encontró un error. De lo contrario, se devuelve el valor de size.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

%s: Archivo no abierto para escritura:

El archivo se abrió para lectura, no para escritura.

No se pueden escribir líneas de escaneo en una imagen con mosaicos:

Se asume que la imagen está organizada en mosaicos porque las etiquetas TileWidth y TileLength se establecieron con TIFFSetField().

%s: Se debe establecer "ImageWidth" antes de escribir datos\fP:

El ancho de la imagen no se estableció antes de la primera escritura. Consulte TIFFSetField() para obtener información sobre cómo hacerlo.

%s: Se debe establecer "PlanarConfiguration" antes de escribir datos:

La organización de los datos no se definió antes de la primera escritura. Consulte TIFFSetField() para obtener información sobre cómo hacerlo.

%s: No hay espacio para los arrays de tiras":

No había suficiente espacio para los arrays que contienen las compensaciones de las tiras y los recuentos de bytes.
