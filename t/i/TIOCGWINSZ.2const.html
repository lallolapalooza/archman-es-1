TIOCSWINSZ(2const) TIOCSWINSZ(2const)

NOMBRE

TIOCGWINSZ, TIOCSWINSZ - obtener y establecer el tamaño de la ventana

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de las constantes TIOC*WINSZ */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGWINSZ, struct winsize *argp);
int ioctl(int fd, TIOCSWINSZ, const struct winsize *argp);
#include <asm/termios.h>
struct winsize {
    unsigned short ws_row;
    unsigned short ws_col;
    unsigned short ws_xpixel;  /* no utilizado */
    unsigned short ws_ypixel;  /* no utilizado */
};

DESCRIPCIÓN

Los tamaños de ventana se guardan en el kernel, pero no son utilizados por el kernel (excepto en el caso de consolas virtuales, donde el kernel actualizará el tamaño de la ventana cuando cambie el tamaño de la consola virtual, por ejemplo, al cargar una nueva fuente).

TIOCGWINSZ
Obtener tamaño de ventana.
TIOCSWINSZ
Establecer tamaño de ventana.

Cuando el tamaño de la ventana cambia, se envía una señal SIGWINCH al grupo de procesos en primer plano.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

VER TAMBIÉN

ioctl(2), ioctl_tty(2const)
