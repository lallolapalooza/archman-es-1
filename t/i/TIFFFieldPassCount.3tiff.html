NOMBRE

TIFFFieldPassCount - obtener si se debe pasar un recuento a TIFFGetField/TIFFSetField

SINOPSIS

#include <tiffio.h>
int TIFFFieldPassCount(const TIFFField *fip)

DESCRIPCIÓN

TIFFFieldPassCount() devuelve verdadero (distinto de cero) si TIFFGetField() y TIFFSetField() esperan un valor de recuento antes de pasar el puntero de datos real.

fip es un puntero de información de campo devuelto previamente por TIFFFindField(), TIFFFieldWithTag(), TIFFFieldWithName().

Cuando se requiere un recuento, será de tipo uint32_t si TIFFFieldReadCount() informa TIFF_VARIABLE2, y de tipo uint16_t en caso contrario. Utilice TIFFFieldWriteCount() para TIFFSetField(), respectivamente. (Esta distinción es crítica para el uso de TIFFGetField(), pero normalmente no lo es para el uso de TIFFSetField()).

Una función alternativa para la determinación del valor de recuento es TIFFFieldSetGetCountSize().

VALOR DE RETORNO

TIFFFieldPassCount() devuelve un entero que siempre es 1 (verdadero) o 0 (falso).
