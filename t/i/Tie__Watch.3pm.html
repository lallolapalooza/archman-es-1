NOMBRE

Tie::Watch - colocar puntos de vigilancia en variables de Perl.

SINOPSIS

use Tie::Watch;
$watch = Tie::Watch->new(
    -variable => \$frog,
    -debug    => 1,
    -shadow   => 0,                      
    -fetch    => [\&fetch, 'arg1', 'arg2', ..., 'argn'],
    -store    => \&store,
    -destroy  => sub {print "Valor final=$frog.\n"},
}
%vinfo = $watch->Info;
$args  = $watch->Args(-fetch);
$val   = $watch->Fetch;
print "val=", $watch->Say($val), ".\n";
$watch->Store('Hola');
$watch->Unwatch;

DESCRIPCIÓN

Este módulo de clase vincula una o más subrutinas de su invención a una variable de Perl. Todas las variables pueden tener callbacks de FETCH, STORE y DESTROY. Adicionalmente, los arrays pueden definir callbacks de CLEAR, DELETE, EXISTS, EXTEND, FETCHSIZE, POP, PUSH, SHIFT, SPLICE, STORESIZE y UNSHIFT, y los hashes pueden definir callbacks de CLEAR, DELETE, EXISTS, FIRSTKEY y NEXTKEY. Si estos términos no le son familiares, le sugiero *realmente* que lea perltie.

Con Tie::Watch puede:

. alterar el valor de una variable
. evitar que el valor de una variable sea cambiado
. invocar un callback de Perl/Tk cuando una variable cambia
. rastrear referencias a una variable

El formato del callback sigue el esquema de Perl/Tk: proporcione un referencia de código, o, proporcione una referencia de array y pase la referencia de código del callback en el primer elemento del array, seguido por los argumentos del callback. (Ver ejemplos en la Sinopsis, arriba.)

Tie::Watch proporciona callbacks por defecto para cualquiera que usted no especifique. Aparte de afectar negativamente el rendimiento, realizan la acción estándar que esperaría, por lo que la variable se comporta "normalmente". Una vez que anula un callback por defecto, quizás para insertar código de depuración como sentencias `print`, su callback normalmente termina llamando al método subyacente (anulado). ¡Pero no tiene que hacerlo!

Para mapear un nombre de método vinculado a un nombre de callback por defecto, simplemente ponga en minúsculas el nombre del método vinculado y ponga en mayúsculas su primer carácter. Así, FETCH se convierte en Fetch, NEXTKEY se convierte en Nextkey, y así sucesivamente.

Aquí hay dos callbacks para un escalar. El callback FETCH (lectura) no hace nada más que ilustrar el hecho de que devuelve el valor a asignar a la variable. El callback STORE (escritura) pone en mayúsculas la variable y la devuelve. En todos los casos, el callback *debe* devolver el valor correcto de lectura o escritura; típicamente, lo hace invocando el método subyacente.

my $fetch_scalar = sub {
    my($self) = @_;
    $self->Fetch;
};
my $store_scalar = sub {
    my($self, $new_val) = @_;
    $self->Store(uc $new_val);
};

Aquí hay callbacks FETCH y STORE para un array o hash. Hacen esencialmente lo mismo que los callbacks escalares, pero proporcionan un poco más de información.

my $fetch = sub {
    my($self, $key) = @_;
    my $val = $self->Fetch($key);
    print "En callback fetch, key=$key, val=", $self->Say($val);
    my $args = $self->Args(-fetch);
    print ", args=('", join("', '",  @$args), "')" if $args;
    print ".\n";
    $val;
};
my $store = sub {
    my($self, $key, $new_val) = @_;
    my $val = $self->Fetch($key);
    $new_val = uc $new_val;
    $self->Store($key, $new_val);
    print "En callback store, key=$key, val=", $self->Say($val),
      ", new_val=", $self->Say($new_val);
    my $args = $self->Args(-store);
    print ", args=('", join("', '",  @$args), "')" if $args;
    print ".\n";
    $new_val;
};

En todos los casos, el primer parámetro es una referencia al objeto Watch, utilizado para invocar los siguientes métodos de clase.

MÉTODOS

$watch = Tie::Watch->new(-options => values);
El método constructor de puntos de vigilancia que acepta pares de opción/valor para crear y configurar el objeto Watch. La única opción requerida es -variable.

-variable es una *referencia* a una variable escalar, de array o de hash.

-debug (por defecto 0) es 1 para activar sentencias de impresión de depuración internas de Tie::Watch.

-shadow (por defecto 1) es 0 para deshabilitar el sombreado de arrays y hashes. Para prevenir recursión infinita, Tie::Watch mantiene variables paralelas para arrays y hashes. Cuando se crea el punto de vigilancia, la variable sombra paralela se inicializa con el contenido de la variable vigilada, y cuando se elimina el punto de vigilancia, la variable sombra se copia a la variable original. Por lo tanto, los cambios hechos durante el proceso de vigilancia no se pierden. El sombreado está activado por defecto. Si deshabilita el sombreado, cualquier cambio hecho a un array o hash se pierde cuando se elimina el punto de vigilancia.

Especifique cualquiera de los siguientes parámetros de callback relevantes, en el formato descrito anteriormente: -fetch, -store, -destroy. Adicionalmente para arrays: -clear, -extend, -fetchsize, -pop, -push, -shift, -splice, -storesize y -unshift. Adicionalmente para hashes: -clear, -delete, -exists, -firstkey y -nextkey.

$args = $watch->Args(-fetch);
Devuelve una referencia a una lista de argumentos para el callback especificado, o indefinido si no hay ninguno.
$watch->Fetch(); $watch->Fetch($key);
Devuelve el valor actual de una variable. $key es requerido para un array o hash.
%vinfo = $watch->Info();
Devuelve un hash que detalla los internos del objeto Watch, con estas claves: 
%vinfo = {
    -variable =>  SCALAR(0x200737f8)
    -debug    =>  '0'
    -shadow   =>  '1'
    -value    =>  'HELLO SCALAR'
    -destroy  =>  ARRAY(0x200f86cc)
    -fetch    =>  ARRAY(0x200f8558)
    -store    =>  ARRAY(0x200f85a0)
    -legible  =>  datos anteriores formateados como una lista de cadenas, para imprimir
}

Para objetos Watch de array o hash, la clave -value es reemplazada por una clave -ptr que es una referencia al array o hash paralelo. Adicionalmente, para un array o hash, hay pares clave/valor para todos los callbacks específicos de la variable.

$watch->Say($val);
Utilizado principalmente para depuración, devuelve $val entre comillas si es necesario, o la cadena "undefined" para valores indefinidos.
$watch->Store($new_val); $watch->Store($key, $new_val);
Almacena el nuevo valor de una variable. $key es requerido para un array o hash.
$watch->Unwatch();
Dejar de vigilar la variable.

CONSIDERACIONES DE EFICIENCIA

Si puede vivir usando los métodos de clase proporcionados, por favor hágalo. Puede manipular el hash del objeto directamente y mejorar el rendimiento de la vigilancia, a riesgo de que su código se rompa en el futuro.
