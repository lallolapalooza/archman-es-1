TIFFSTRIP(3tiff) LibTIFF TIFFSTRIP(3tiff)

NOMBRE

TIFFstrip - rutinas de utilidad relacionadas con las tiras

SINOPSIS

#include <tiffio.h>
uint32_t TIFFDefaultStripSize(TIFF *tif, uint32_t estimate)
tmsize_t TIFFStripSize(TIFF *tif)
uint64_t TIFFStripSize64(TIFF *tif)
tmsize_t TIFFVStripSize(TIFF *tif, uint32_t nrows)
uint64_t TIFFVStripSize64(TIFF *tif, uint32_t nrows)
tmsize_t TIFFRawStripSize(TIFF *tif, uint32_t strip)
uint64_t TIFFRawStripSize64(TIFF *tif, uint32_t strip)
tstrip_t TIFFComputeStrip(TIFF *tif, uint32_t row, tsample_t sample)
tstrip_t TIFFNumberOfStrips(TIFF *tif)
int TIFFSetupStrips(TIFF *tif)

DESCRIPCIÓN

TIFFDefaultStripSize() devuelve el número de filas para una tira de tamaño razonable según la configuración actual de las etiquetas ImageWidth, BitsPerSample y SamplesPerPixel, y cualquier requisito específico de la compresión. Si el parámetro estimate, si no es cero, se toma como una estimación del tamaño de tira deseado y se ajusta según los requisitos específicos de la compresión. El valor devuelto por esta función se utiliza típicamente para definir la etiqueta RowsPerStrip. En ausencia de requisitos inusuales, TIFFDefaultStripSize intenta crear tiras que tengan aproximadamente 8 kilobytes de datos sin comprimir.

TIFFStripSize() devuelve el tamaño equivalente de una tira de datos tal como se devolvería en una llamada a TIFFReadEncodedStrip() o como se esperaría en una llamada a TIFFWriteEncodedStrip(). Si ocurre un error, se devuelve 0.

TIFFStripSize64() devuelve el tamaño equivalente de una tira de datos como uint64_t. Si ocurre un error, se devuelve 0.

TIFFVStripSize() devuelve el número de bytes en una tira con nrows filas de datos. Si ocurre un error, se devuelve 0.

TIFFVStripSize64() devuelve el número de bytes en una tira con nrows filas de datos como uint64_t. Si ocurre un error, se devuelve 0.

TIFFRawStripSize() devuelve el número de bytes de una tira sin procesar (es decir, sin decodificar). Si ocurre un error, se devuelve 0xFFFFFFFF (=(tmsize_t(-1)).

TIFFRawStripSize64() devuelve el número de bytes de una tira sin procesar como uint64_t. Si ocurre un error, se devuelve 0xFFFFFFFF (=(uint64_t(-1)).

TIFFComputeStrip() devuelve la tira que contiene las coordenadas especificadas. Siempre se devuelve una tira válida; los valores de coordenadas fuera de rango se ajustan a los límites de la imagen. El parámetro row siempre se utiliza para calcular una tira. El parámetro sample solo se utiliza si los datos están organizados en planos separados (PlanarConfiguration = 2).

TIFFNumberOfStrips() devuelve el número de tiras en la imagen.

TIFFSetupStrips() configura o restablece los parámetros de tira y la memoria de la matriz de tiras.

DIAGNÓSTICOS

Ninguno.
