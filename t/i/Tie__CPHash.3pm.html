Tie::CPHash(3) Documentación de Perl contribuida por el usuario Tie::CPHash(3)

NOMBRE

Tie::CPHash - Tabla hash que preserva mayúsculas pero no distingue entre ellas.

VERSIÓN

Este documento describe la versión 2.000 de Tie::CPHash, lanzada el 17 de enero de 2015.

SINOPSIS

use Tie::CPHash 2; # permite inicialización durante el tie
tie %cphash, 'Tie::CPHash', key => 'value';
$cphash{'Hello World'} = 'Hi there!';
printf("La clave `%s' se usó para almacenar `%s'.\n",
       tied(%cphash)->key('HELLO WORLD'),
       $cphash{'HELLO world'});

DESCRIPCIÓN

El módulo Tie::CPHash proporciona una tabla hash que preserva mayúsculas pero no distingue entre ellas. Esto significa que

$cphash{KEY}    $cphash{key}
$cphash{Key}    $cphash{keY}

todas se refieren a la misma entrada. Además, el hash recuerda qué forma de la clave se utilizó por última vez para almacenar la entrada. Las funciones "keys" y "each" devolverán la clave que se usó para establecer el valor.

Un ejemplo debería aclarar esto:

tie %h, 'Tie::CPHash', Hello => 'World';
print $h{HELLO};            # Imprime 'World'
print keys(%h);             # Imprime 'Hello'
$h{HELLO} = 'WORLD';
print $h{hello};            # Imprime 'WORLD'
print keys(%h);             # Imprime 'HELLO'

Tie::CPHash versión 2.000 introdujo la capacidad de pasar una lista de pares "clave => valor" para inicializar el hash (junto con el método "add" que lo potencia). La lista debe incluir un valor para cada clave, o el constructor fallará.

El método adicional "key" te permite obtener la capitalización de una clave específica:

# Cuando se ejecuta después del ejemplo anterior, esto imprime 'HELLO':
print tied(%h)->key('Hello');

(La función "tied" devuelve el objeto al que está enlazado %h.)

Si necesitas un hash que no distinga entre mayúsculas y minúsculas, pero no necesites preservar la capitalización, simplemente usa $hash{lc $key} en lugar de $hash{$key}. Esto tiene mucha menos sobrecarga que Tie::CPHash.

"use Tie::CPHash;" no exporta nada a tu espacio de nombres.

MÉTODOS

add

tied(%h)->add( key => value, ... );
tied(%h)->add( \@list_of_key_value_pairs );

Este método (introducido en la versión 2.000) agrega claves y valores al hash. Es igual que

%h = @list_of_key_value_pairs;

excepto que no vacía el hash primero. Acepta una lista o una referencia a un array. Falla si la lista tiene un número impar de entradas. Devuelve el objeto hash enlazado.

Si la lista contiene claves duplicadas, el último par "clave => valor" de la lista gana. (No puedes pasar un hashref a "add" porque sería ambiguo qué clave ganaría si dos claves difirieran solo en mayúsculas/minúsculas).

Para aquellos acostumbrados a Tie::IxHash, "add" está aliasado tanto a "Push" como a "Unshift". (Tie::CPHash no preserva el orden de las claves.)

key

$set_using_key = tied(%h)->key( $key )

Este método te permite obtener la capitalización de una clave específica. Por ejemplo:

$h{HELLO} = 'World';
print tied(%h)->key('Hello'); # imprime HELLO

Si la clave no existe en el hash, devuelve "undef".

DIAGNÓSTICOS

Número impar de elementos en CPHash add
Pasaste una lista con un número impar de elementos al método "add" (o a "tie", que usa "add"). La lista debe contener un valor para cada clave.
