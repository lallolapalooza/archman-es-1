Time::HiRes(3perl) Guía de referencia del programador de Perl Time::HiRes(3perl)

NOMBRE

Time::HiRes - Alarma de alta resolución, dormir, obtener hora actual, temporizadores de intervalo

SINOPSIS

use Time::HiRes qw( usleep ualarm gettimeofday tv_interval nanosleep
                    clock_gettime clock_getres clock_nanosleep clock
                    stat lstat utime);
usleep ($microsegundos);
nanosleep ($nanosegundos);
ualarm ($microsegundos);
ualarm ($microsegundos, $microsegundos_intervalo);
$t0 = [gettimeofday];
($segundos, $microsegundos) = gettimeofday;
$elapsed = tv_interval ( $t0, [$segundos, $microsegundos]);
$elapsed = tv_interval ( $t0, [gettimeofday]);
$elapsed = tv_interval ( $t0 );
use Time::HiRes qw ( time alarm sleep );
$ahora_fracciones = time;
sleep ($segundos_flotantes);
alarm ($segundos_flotantes);
alarm ($segundos_flotantes, $intervalo_segundos_flotantes);
use Time::HiRes qw( setitimer getitimer );
setitimer ($cual, $segundos_flotantes, $intervalo_segundos_flotantes );
getitimer ($cual);
use Time::HiRes qw( clock_gettime clock_getres clock_nanosleep
          CLOCK_REALTIME ITIMER_REAL ITIMER_VIRTUAL ITIMER_PROF
          ITIMER_REALPROF );
$tiempo_real   = clock_gettime(CLOCK_REALTIME);
$resolucion = clock_getres(CLOCK_REALTIME);
clock_nanosleep(CLOCK_REALTIME, 1.5e9);
clock_nanosleep(CLOCK_REALTIME, time()*1e9 + 10e9, TIMER_ABSTIME);
mi $ticktock = clock();
use Time::HiRes qw( stat lstat );
mi @stat = stat("archivo");
mi @stat = stat(FH);
mi @stat = lstat("archivo");
use Time::HiRes qw( utime );
utime $segundos_flotantes, $segundos_flotantes, archivo...;

DESCRIPCION

El módulo "Time::HiRes" implementa una interfaz de Perl a las llamadas del sistema "usleep", "nanosleep", "ualarm", "gettimeofday" y "setitimer"/"getitimer", en otras palabras, tiempo y temporizadores de alta resolución. Vea la sección "EJEMPLOS" a continuación y los scripts de prueba para su uso; consulte la documentación de su sistema para la descripción de las llamadas subyacentes "nanosleep" o "usleep", "ualarm", "gettimeofday" y "setitimer"/"getitimer".

Si su sistema carece de gettimeofday() o de una emulación del mismo, no obtendrá gettimeofday() ni la forma de un argumento de tv_interval(). Si su sistema carece de todos los siguientes: nanosleep(), usleep(), select() y "poll", no obtendrá Time::HiRes::usleep(), Time::HiRes::nanosleep() o Time::HiRes::sleep(). Si su sistema carece tanto de ualarm() como de setitimer(), no obtendrá Time::HiRes::ualarm() o Time::HiRes::alarm().

Si intenta importar una función no implementada en la sentencia "use", fallará en tiempo de compilación.

Si su suspensión de subsegundos se implementa con nanosleep() en lugar de con usleep(), puede mezclar la suspensión de subsegundos con señales ya que nanosleep() no utiliza señales. Esto, sin embargo, no es portable, y primero debe comprobar el valor verdadero de &Time::HiRes::d_nanosleep para ver si tiene nanosleep, y luego leer cuidadosamente la documentación de su API C de nanosleep() para cualquier peculiaridad.

Si está utilizando "nanosleep" para algo que no sea mezclar la suspensión con señales, considere si Perl es la herramienta que debería estar utilizando para trabajos que requieran precisión de nanosegundos.

Recuerde que, a menos que esté trabajando en un sistema de tiempo real duro, cualquier reloj y temporizador será impreciso, especialmente si está trabajando en un sistema multiusuario de pre-emisión. Comprenda la diferencia entre el tiempo de reloj de pared (wallclock time) y el tiempo de proceso (en sistemas tipo UNIX, la suma de tiempos de usuario y sistema). Cualquier intento de dormir X segundos probablemente terminará durmiendo más que eso, pero no se sorprenda si termina durmiendo ligeramente menos.

Las siguientes funciones pueden ser importadas desde este módulo. Ninguna función se exporta por defecto.

gettimeofday ()
En contexto de array, devuelve un array de dos elementos con los segundos y microsegundos desde la época. En contexto escalar, devuelve segundos flotantes como Time::HiRes::time() (ver abajo).
usleep ( $microsegundos )
Duerme durante el número de microsegundos (millonésimas de segundo) especificado. Devuelve el número de microsegundos realmente dormidos. Puede dormir durante más de un segundo, a diferencia de la llamada del sistema "usleep". También puede dormir durante cero segundos, lo que a menudo funciona como un yield de hilo. Vea también Time::HiRes::sleep() y clock_nanosleep().

No espere que usleep() sea exacto hasta un microsegundo.

nanosleep ( $nanosegundos )
Duerme durante el número de nanosegundos (milmillonésimas de segundo) especificado. Devuelve el número de nanosegundos realmente dormidos (preciso solo hasta microsegundos, los mil más cercanos). Puede dormir durante más de un segundo. También puede dormir durante cero segundos, lo que a menudo funciona como un yield de hilo. Vea también Time::HiRes::sleep(), Time::HiRes::usleep() y clock_nanosleep().

No espere que nanosleep() sea exacto hasta un nanosegundo. Tener incluso una precisión de mil nanosegundos es bueno.

ualarm ( $microsegundos [, $microsegundos_intervalo ] )
Emite una llamada "ualarm"; $microsegundos_intervalo es opcional y será cero si no se especifica, resultando en un comportamiento similar a "alarm".

Devuelve el tiempo restante en la alarma en microsegundos, o "undef" si ocurrió un error.

ualarm(0) cancelará una ualarm() pendiente.

Tenga en cuenta que la interacción entre alarmas y sueños no está especificada.

tv_interval
tv_interval ( $ref_a_gettimeofday [, $ref_a_gettimeofday_posterior] )

Devuelve los segundos flotantes entre las dos horas, que deberían haber sido devueltas por gettimeofday(). Si se omite el segundo argumento, se utiliza la hora actual.

time ()
Devuelve segundos flotantes desde la época. Esta función puede ser importada, resultando en un buen reemplazo directo para el "time" proporcionado con el núcleo de Perl; vea los "EJEMPLOS" a continuación.

NOTA 1: Este temporizador de mayor resolución puede devolver valores menores o mayores que el time() del núcleo, dependiendo de si su plataforma redondea los valores del temporizador de mayor resolución hacia arriba, hacia abajo o al segundo más cercano para obtener el time() del núcleo, pero naturalmente la diferencia nunca debería ser más de medio segundo. Vea también "clock_getres", si está disponible en su sistema.

NOTA 2: Desde el domingo 9 de septiembre de 2001 a la 01:46:40 AM GMT, cuando los segundos de time() desde la época se desbordaron a 1_000_000_000, el formato de punto flotante predeterminado de Perl y los segundos desde la época se han conspirado para producir un error aparente: si imprime el valor de Time::HiRes::time() parece que solo obtiene cinco decimales, no seis como se prometió (microsegundos). No se preocupe, los microsegundos están ahí (suponiendo que su plataforma soporte tal granularidad en primer lugar). Lo que está sucediendo es que el formato de punto flotante predeterminado de Perl solo muestra 15 dígitos. En este caso, eso significa diez dígitos antes del separador decimal y cinco después. Para ver los microsegundos puede usar "printf"/"sprint

Time::HiRes(3perl)

NAME

Time::HiRes - Access to high-resolution timer

SYNOPSIS

use Time::HiRes qw( time alarm usleep nanosleep);
print time(), "\n";
alarm(1);
usleep(500000); # sleep for 0.5 seconds
print "Woke up\n";
nanosleep(1_000_000); # sleep for 1 millisecond

DESCRIPTION

This module provides access to a high-resolution timer. The functions exported by this module are:

  • time(): Returns the current time as a floating-point number of seconds since the epoch.
  • clock_gettime(what): Returns the value of a clock. See clock_gettime(3) for details.
  • clock_nanosleep(clock_id, flags, request, remain): Suspends execution for a specified interval. See clock_nanosleep(3) for details.
  • alarm(seconds): Schedules a SIGALRM signal to be sent after seconds seconds.
  • usleep(microseconds): Suspends execution for microseconds microseconds.
  • nanosleep(nanoseconds): Suspends execution for nanoseconds nanoseconds.
  • gettimeofday(): Returns the current time as a pair of (seconds, microseconds).
  • settimeofday(seconds, microseconds): Sets the current time. This function requires superuser privileges.
  • sleep(seconds): Suspends execution for seconds seconds. This function is a wrapper around nanosleep.
  • select(...): A high-resolution version of the built-in select.

OPTIONS

None.

EXAMPLES

See SYNOPSIS.

C API

This module does not provide a C API.

DIAGNOSTICS

None.

CAVEATS

The precision of the timer depends on the underlying operating system and hardware. On some systems, usleep and nanosleep may not be able to sleep for the requested duration with the requested precision.
