NOMBRE

TIFFReadRawTile - devuelve un tile de datos sin decodificar de un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
tsize_t TIFFReadRawTile(TIFF *tif, ttile_t tile, tdata_t buf, tsize_t size)

DESCRIPCIÓN

Lee el contenido del tile especificado en el búfer de datos (suministrado por el usuario). Tenga en cuenta que el valor de tile es un número de tile “crudo”. Es decir, el llamador debe tener en cuenta si los datos están organizados en planos separados (PlanarConfiguration = 2). TIFFComputeTile() hace esto automáticamente al convertir un cuádruple de coordenadas (x,y,z,sample) en un número de tile. Para leer un tile completo de datos, el búfer de datos debe ser típicamente al menos tan grande como el valor devuelto por TIFFTileSize().

VALORES DE RETORNO

Se devuelve el número real de bytes de datos que se colocaron en buf; TIFFReadRawTile() devuelve -1 si se encontró un error.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().
