NOMBRE

TIFFWriteRawStrip - escribe una tira de datos sin procesar en un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
tsize_t TIFFWriteRawStrip(TIFF *tif, tstrip_t strip, tdata_t buf, tsize_t size)

DESCRIPCIÓN

Añade size bytes de datos sin procesar a la tira especificada.

NOTAS

El número de tira debe ser válido según la configuración actual de las etiquetas ImageLength y RowsPerStrip. Una imagen puede crecer dinámicamente incrementando el valor de ImageLength antes de cada llamada a TIFFWriteRawStrip().

VALORES DEVUELTOS

Se devuelve -1 si ocurrió un error. De lo contrario, se devuelve el valor de size.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

%s: El archivo no está abierto para escritura:

El archivo se abrió para lectura, no para escritura.

No se pueden escribir líneas de escaneo en una imagen con teselas:

Se asume que la imagen está organizada en teselas porque las etiquetas TileWidth y TileLength se han establecido con TIFFSetField().

%s: Se debe establecer "ImageWidth" antes de escribir datos:

El ancho de la imagen no se ha establecido antes de la primera escritura. Consulte TIFFSetField() para obtener información sobre cómo hacerlo.

%s: Se debe establecer "PlanarConfiguration" antes de escribir datos:

La organización de los datos no se ha definido antes de la primera escritura. Consulte TIFFSetField() para obtener información sobre cómo hacerlo.

%s: No hay espacio para los arrays de tiras":

No hubo suficiente espacio para los arrays que almacenan los desplazamientos y los recuentos de bytes de las tiras.

%s: Tira %d fuera de rango, máximo %d:

La tira especificada no es una tira válida según las dimensiones de imagen especificadas actualmente.
