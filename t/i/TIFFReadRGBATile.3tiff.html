TIFFREADRGBATILE(3tiff) LibTIFF TIFFREADRGBATILE(3tiff)

NOMBRE

TIFFReadRGBATile - lee y decodifica una tesela de imagen en un raster de formato fijo

SINOPSIS

#include <tiffio.h>
int TIFFReadRGBATile(TIFF *tif, uint32_t x, uint32_t y, uint32_t *raster)
int TIFFReadRGBATileExt(TIFF *tif, uint32_t col, uint32_t row, uint32_t *raster, int stop_on_error)

DESCRIPCIÓN

TIFFReadRGBATile() lee una única tesela de una imagen basada en teselas en memoria, almacenando el resultado en el raster RGBA suministrado por el usuario. Se asume que el raster es un array de entradas de 32 bits de TileWidth × TileLength, donde TileWidth es el ancho de una tesela (TIFFTAG_TILEWIDTH) y TileLength es la altura de una tesela (TIFFTAG_TILELENGTH).

TIFFReadRGBATileExt() proporciona el parámetro stop_on_error. Su comportamiento se describe en TIFFReadRGBAImage.

Los valores x e y son los desplazamientos desde la esquina superior izquierda hasta la esquina superior izquierda de la tesela a leer. Deben ser un múltiplo exacto del ancho y largo de la tesela.

Tenga en cuenta que se asume que el raster está organizado de manera que el píxel en la ubicación (x, y) es raster [ y × width + x ]; con el origen del raster en la esquina inferior izquierda de la tesela. Es decir, organización de abajo hacia arriba. Las teselas de borde que quedan parcialmente fuera de la imagen se rellenarán con áreas cero apropiadas.

Los píxeles del raster son muestras roja, verde, azul y alfa de 8 bits empaquetadas. Se deben usar las macros TIFFGetR, TIFFGetG, TIFFGetB y TIFFGetA para acceder a las muestras individuales. Las imágenes sin información de mateado alfa asociado tienen un alfa constante de 1.0 (255).

Consulte la página de TIFFRGBAImage para obtener más detalles sobre cómo se convierten varios tipos de imágenes en valores RGBA.

NOTAS

Las muestras deben ser de 1, 2, 4, 8 o 16 bits. Las muestras colorimétricas por píxel deben ser 1, 3 o 4 (es decir, SamplesPerPixel - ExtraSamples).

Los mapas de color de imágenes de paleta que parecen estar escritos incorrectamente como valores de 8 bits se escalan automáticamente a 16 bits.

TIFFReadRGBATile() es solo un envoltorio para las instalaciones más generales de TIFFRGBAImage. Su principal ventaja sobre la función similar TIFFReadRGBAImage() es que para imágenes grandes no es necesario asignar un único búfer capaz de contener toda la imagen, solo lo suficiente para una tesela. La función TIFFReadRGBAStrip() realiza una operación similar para imágenes con bandas.

VALORES DE RETORNO

Se devuelve 1 si la imagen se leyó y convirtió correctamente. De lo contrario, se devuelve 0 si se encontró un error.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

"Lo sentimos, no se pueden manejar imágenes de %d bits":

La imagen tenía BitsPerSample distinto de 1, 2, 4, 8 o 16.

"Lo sentimos, no se pueden manejar imágenes de %d canales":

La imagen tenía SamplesPerPixel distinto de 1, 3 o 4.

Falta la etiqueta necesaria "PhotometricInterpretation":

La imagen no tenía una etiqueta que describiera cómo mostrar los datos.

No hay etiqueta "PhotometricInterpretation", se asume RGB:

La imagen carecía de una etiqueta que describiera cómo mostrarla, pero debido a que tiene 3 o 4 muestras por píxel, se asume que es RGB.

No hay etiqueta "PhotometricInterpretaion", se asume min-is-black:

La imagen carecía de una etiqueta que describiera cómo mostrarla, pero debido a que tiene 1 muestra por píxel, se asume que es una imagen en escala de grises o de dos niveles.

"No hay espacio para la tabla de conversión fotométrica":

No había memoria suficiente para una tabla utilizada para convertir las muestras de imagen a RGB de 8 bits.

Falta la etiqueta requerida "Colormap":

Una imagen de paleta no tenía la etiqueta requerida Colormap.

"No hay espacio para el búfer de tesela":

No había memoria suficiente para asignar un búfer de E/S.

"No hay espacio para el búfer de banda":

No había memoria suficiente para asignar un búfer de E/S.

"No se puede manejar el formato":

La imagen tiene un formato (combinación de BitsPerSample, SamplesPerPixel e PhotometricInterpretation) que TIFFReadRGBAImage() no puede manejar.

"No hay espacio para la tabla de mapeo B&N":

No había memoria suficiente para asignar una tabla utilizada para mapear datos en escala de grises a RGB.

"No hay espacio para la tabla de mapeo de Paleta":

No había memoria suficiente para asignar una tabla utilizada para mapear datos a RGB de 8 bits.
