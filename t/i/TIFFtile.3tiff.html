Paquete: libtiff

Licencias: libtiff

TIFFtile(3tiff) LibTIFF TIFFtile(3tiff)

NOMBRE

TIFFtile - Rutinas de utilidad relacionadas con las teselas

SINOPSIS

#include <tiffio.h>
void TIFFDefaultTileSize(TIFF *tif, uint32_t *tw, uint32_t *th)
tsize_t TIFFTileSize(TIFF *tif)
uint64_t TIFFTileSize64(TIFF *tif)
tsize_t TIFFTileRowSize(TIFF *tif)
uint64_t TIFFTileRowSize64(TIFF *tif)
tsize_t TIFFVTileSize(TIFF *tif, uint32_t nrows)
uint64_t TIFFVTileSize64(TIFF *tif, uint32_t nrows)
ttile_t TIFFComputeTile(TIFF *tif, uint32_t x, uint32_t y, uint32_t z, tsample_t sample)
int TIFFCheckTile(TIFF *tif, uint32_t x, uint32_t y, uint32_t z, tsample_t sample)
ttile_t TIFFNumberOfTiles(TIFF *tif)

DESCRIPCIÓN

TIFFDefaultTileSize() devuelve el ancho y alto de píxeles de una tesela de tamaño razonable; adecuada para configurar las etiquetas TileWidth y TileLength. Si los valores tw y th pasados son distintos de cero, se ajustan para reflejar cualquier requisito específico de la compresión. El ancho y alto devueltos se restringen a ser un múltiplo de 16 píxeles para cumplir con la especificación TIFF.

TIFFTileSize() devuelve el tamaño equivalente para una tesela de datos, tal como se devolvería en una llamada a TIFFReadTile() o como se esperaría en una llamada a TIFFWriteTile(). TIFFTileSize64() devuelve un número uint64_t. Si ocurre un error, se devuelve 0.

TIFFVTileSize() devuelve el número de bytes en una tesela alineada por filas con nrows de datos. TIFFVTileSize64() devuelve un número uint64_t. Si ocurre un error, se devuelve 0.

TIFFTileRowSize() devuelve el número de bytes de una fila de datos en una tesela. TIFFTileRowSize64() devuelve un número uint64_t. Si ocurre un error, se devuelve 0.

TIFFComputeTile() devuelve la tesela que contiene las coordenadas especificadas. Siempre se devuelve una tesela válida; los valores de coordenadas fuera de rango se ajustan a los límites de la imagen. Los parámetros x e y siempre se utilizan para calcular una tesela. El parámetro z se usa si la imagen tiene más de 1 rebanada (ImageDepth > 1). El parámetro sample se usa solo si los datos están organizados en planos separados (PlanarConfiguration = 2).

TIFFCheckTile() devuelve un valor distinto de cero si las coordenadas proporcionadas están dentro de los límites de la imagen y cero en caso contrario. El parámetro x se comprueba con el valor de la etiqueta ImageWidth. El parámetro y se comprueba con el valor de la etiqueta ImageLength. El parámetro z se comprueba con el valor de la etiqueta ImageDepth (si está definida). El parámetro sample se comprueba con el valor del parámetro SamplesPerPixel si los datos están organizados en planos separados.

TIFFNumberOfTiles() devuelve el número de teselas en la imagen.

DIAGNÓSTICOS

Ninguno.
