TIOCMSET(2const) TIOCMSET(2const)

NOMBRE

TIOCMGET, TIOCMSET, TIOCMBIC, TIOCMBIS, TIOCMIWAIT, TIOCGICOUNT - control del módem

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de constantes TIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCMGET, int *argp);
int ioctl(int fd, TIOCMSET, const int *argp);
int ioctl(int fd, TIOCMBIC, const int *argp);
int ioctl(int fd, TIOCMBIS, const int *argp);
int ioctl(int fd, TIOCMIWAIT, int arg);
int ioctl(int fd, TIOCGICOUNT, struct serial_icounter_struct *argp);
#include <linux/serial.h>
struct serial_icounter_struct;

DESCRIPCIÓN

TIOCMGET
Obtener el estado de los bits del módem.
TIOCMSET
Establecer el estado de los bits del módem.
TIOCMBIC
Borrar los bits del módem indicados.
TIOCMBIS
Establecer los bits del módem indicados.

Los siguientes bits son utilizados por los ioctls anteriores:

TIOCM_LE DSR (listo/habilitación de línea del conjunto de datos)
TIOCM_DTR DTR (terminal de datos listo)
TIOCM_RTS RTS (solicitud de envío)
TIOCM_ST TXD secundario (transmisión)
TIOCM_SR RXD secundario (recepción)
TIOCM_CTS CTS (listo para enviar)
TIOCM_CAR DCD (detección de portadora de datos)
TIOCM_CD ver TIOCM_CAR
TIOCM_RNG RNG (anillo)
TIOCM_RI ver TIOCM_RNG
TIOCM_DSR DSR (listo para el conjunto de datos)
TIOCMIWAIT
Esperar a que cambie cualquiera de los 4 bits del módem (DCD, RI, DSR, CTS). Los bits de interés se especifican como una máscara de bits en arg, combinando mediante OR los valores de bits TIOCM_RNG, TIOCM_DSR, TIOCM_CD y TIOCM_CTS. El llamador debe usar TIOCGICOUNT para ver qué bit ha cambiado.
TIOCGICOUNT
Obtener los recuentos de interrupciones de línea serial de entrada (DCD, RI, DSR, CTS). Los recuentos se escriben en la estructura serial_icounter_struct apuntada por argp.
Nota: se cuentan ambas transiciones 1->0 y 0->1, excepto para RI, donde solo se cuentan las transiciones 0->1.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

EJEMPLOS

Comprobar el estado de DTR en el puerto serial.

#include <asm/termbits.h>
#include <fcntl.h>
#include <stdio.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(void)
{
    int fd, serial;
    fd = open("/dev/ttyS0", O_RDONLY);
    ioctl(fd, TIOCMGET, &serial);
    if (serial & TIOCM_DTR)
        puts("TIOCM_DTR está establecido");
    else
        puts("TIOCM_DTR no está establecido");
    close(fd);
}

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
