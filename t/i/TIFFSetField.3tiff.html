TIFFSETFIELD(3tiff) LibTIFF TIFFSETFIELD(3tiff)

NOMBRE

TIFFSetField - establece el valor(es) de una etiqueta en un archivo TIFF abierto para escritura

SINOPSIS

#include <tiffio.h>
#include <stdarg.h>
int TIFFSetField(TIFF *tif, ttag_t tag, ...)
int TIFFVSetField(TIFF *tif, ttag_t tag, va_list ap)
int TIFFUnsetField(TIFF *tif, uint32_t tag)

DESCRIPCIÓN

TIFFSetField() establece el valor de un campo o pseudoe-tiqueta en el directorio actual asociado con el archivo TIFF abierto tif. (Una pseudoe-tiqueta es un parámetro que se utiliza para controlar la operación de la biblioteca TIFF pero cuyo valor no se lee ni se escribe en el archivo subyacente). Para establecer el valor de un campo, el archivo debe haber sido abierto previamente para escritura con TIFFOpen(). Las pseudoe-tiquetas se pueden establecer independientemente de si el archivo se abrió para lectura o escritura. El campo se identifica por tag, uno de los valores definidos en el archivo de inclusión tiff.h (ver también la tabla a continuación). El valor real se especifica usando una lista de argumentos variables, según lo prescrito por la interfaz stdarg.h.

TIFFVSetField() es funcionalmente equivalente a TIFFSetField() excepto que toma un puntero a una lista de argumentos variables. TIFFVSetField() es útil para escribir rutinas que se encuentran en capas superiores a la funcionalidad proporcionada por TIFFSetField().

TIFFUnsetField() borra el contenido del campo en la estructura interna. Si es un campo personalizado, se elimina de la lista de etiquetas conocidas.

Las etiquetas entendidas por libtiff, el número de valores de parámetros y los tipos esperados para los valores de parámetros se muestran a continuación. Los tipos de datos son:

ETIQUETAS TIPOS DE DATOS

Tipo Descripción
char* una cadena terminada en nulo correspondiente al tipo de datos ASCII
uint16_t un valor sin signo de 16 bits
uint32_t un valor sin signo de 32 bits;
uint16_t* un arreglo de valores sin signo de 16 bits.
void* un arreglo de valores de datos de tipo no especificado.

Consulte la especificación TIFF para obtener información sobre el significado de cada etiqueta.

VALORES DE RETORNO

Se devuelve 1 si la operación fue exitosa. De lo contrario, se devuelve 0 si se detectó un error.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

%s: No se puede modificar la etiqueta "%s" mientras se escribe:

Ya se han escrito datos en el archivo, por lo que el valor de la etiqueta especificada no se puede cambiar. Esta restricción se aplica a todas las etiquetas que afectan el formato de los datos escritos.

%d: Valor incorrecto para "%s":

Se proporcionó un valor no válido para la etiqueta nombrada.
