TIFFREADRAWSTRIP(3tiff) LibTIFF TIFFREADRAWSTRIP(3tiff)

NOMBRE

TIFFReadRawStrip - devuelve el contenido no decodificado de una tira de datos de un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
tsize_t TIFFReadRawStrip(TIFF *tif, tstrip_t strip, tdata_t buf, tsize_t size)

DESCRIPCIÓN

Lee el contenido de la tira especificada en el búfer de datos (suministrado por el usuario). Tenga en cuenta que el valor de strip es un número de tira “crudo”. Es decir, el llamante debe tener en cuenta si los datos están organizados en planos separados (PlanarConfiguration = 2) o no. Para leer una tira completa de datos, el búfer de datos debería ser típicamente al menos tan grande como el número devuelto por TIFFStripSize().

VALORES DE RETORNO

Se devuelve el número real de bytes de datos que se colocaron en buf; TIFFReadRawStrip() devuelve -1 si se encontró un error.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

VER TAMBIÉN
