NOMBRE

Tie::Array - clase base para arrays enlazados

SINOPSIS

package Tie::NewArray;
use Tie::Array;
@ISA = ('Tie::Array');
# métodos obligatorios
sub TIEARRAY { ... }
sub FETCH { ... }
sub FETCHSIZE { ... }
sub STORE { ... }       # obligatorio si los elementos se pueden escribir
sub STORESIZE { ... }   # obligatorio si se pueden añadir/eliminar elementos
sub EXISTS { ... }      # obligatorio si se espera que exista() funcione
sub DELETE { ... }      # obligatorio si se espera que delete() funcione
# métodos opcionales - para eficiencia
sub CLEAR { ... }
sub PUSH { ... }
sub POP { ... }
sub SHIFT { ... }
sub UNSHIFT { ... }
sub SPLICE { ... }
sub EXTEND { ... }
sub DESTROY { ... }
package Tie::NewStdArray;
use Tie::Array;
@ISA = ('Tie::StdArray');
# todos los métodos proporcionados por defecto
package main;
$object = tie @somearray,'Tie::NewArray';
$object = tie @somearray,'Tie::StdArray';
$object = tie @somearray,'Tie::NewStdArray';

DESCRIPCIÓN

Este módulo proporciona métodos para clases de enlazado de arrays. Consulte perltie para obtener una lista de las funciones necesarias para enlazar un array a un paquete. El paquete básico Tie::Array proporciona métodos "DESTROY" y "EXTEND" de tipo stub que no hacen nada, métodos "DELETE" y "EXISTS" de tipo stub que hacen croak() si los built-ins delete() o exists() se llaman alguna vez en el array enlazado, e implementaciones de "PUSH", "POP", "SHIFT", "UNSHIFT", "SPLICE" y "CLEAR" en términos de "FETCH", "STORE", "FETCHSIZE", "STORESIZE" básicos.

El paquete Tie::StdArray proporciona métodos eficientes requeridos para arrays enlazados que se implementan como referencias bendecidas a un array de perl "interno". Hereda de Tie::Array y debe hacer que los arrays enlazados se comporten exactamente como arrays estándar, permitiendo la sobrecarga selectiva de métodos.

Para los desarrolladores que deseen escribir sus propios arrays enlazados, los métodos requeridos se definen brevemente a continuación. Consulte la sección perltie para obtener una descripción más detallada, así como ejemplos de código:

TIEARRAY nombre_clase, LISTA
El método de clase se invoca con el comando "tie @array, nombre_clase". Asocia una instancia de array con la clase especificada. "LISTA" representaría argumentos adicionales (en la línea de AnyDBM_File y compatriotas) necesarios para completar la asociación. El método debe devolver un objeto de una clase que proporcione los métodos a continuación.
STORE este, índice, valor
Almacena el dato valor en el índice para el array enlazado asociado con el objeto este. Si esto hace que el array sea más grande, se debe devolver el mapeo de "undef" de la clase para las nuevas posiciones.
FETCH este, índice
Recupera el dato en el índice para el array enlazado asociado con el objeto este.
FETCHSIZE este
Devuelve el número total de elementos en el array enlazado asociado con el objeto este. (Equivalente a scalar(@array)).
STORESIZE este, recuento
Establece el número total de elementos en el array enlazado asociado con el objeto este a recuento. Si esto hace que el array sea más grande, se debe devolver el mapeo de "undef" de la clase para las nuevas posiciones. Si el array se vuelve más pequeño, se deben eliminar las entradas más allá del recuento.
EXTEND este, recuento
Llamada informativa de que es probable que el array crezca para tener recuento elementos. Se puede utilizar para optimizar la asignación. Este método no debe hacer nada.
EXISTS este, clave
Verifica que el elemento en el índice clave exista en el array enlazado este.

La implementación de Tie::Array es un stub que simplemente hace croak.

DELETE este, clave
Elimina el elemento en el índice clave del array enlazado este.

La implementación de Tie::Array es un stub que simplemente hace croak.

CLEAR este
Borra (elimina, borra, ...) todos los valores del array enlazado asociado con el objeto este.
DESTROY este
Método destructor de objetos normal.
PUSH este, LISTA
Añade los elementos de LISTA al final del array.
POP este
Elimina el último elemento del array y lo devuelve.
SHIFT este
Elimina el primer elemento del array (desplazando los demás hacia abajo) y lo devuelve.
UNSHIFT este, LISTA
Inserta los elementos de LISTA al principio del array, moviendo los elementos existentes hacia arriba para hacer espacio.
SPLICE este, desplazamiento, longitud, LISTA
Realiza el equivalente de "splice" en el array.

desplazamiento es opcional y por defecto es cero; los valores negativos cuentan desde el final del array.

longitud es opcional y por defecto es el resto del array.

LISTA puede estar vacía.

Devuelve una lista de los elementos originales de longitud en desplazamiento.

ADVERTENCIAS

Por el momento no hay soporte para el array enlazado @ISA. Existe un conflicto potencial entre las entradas mágicas necesarias para detectar el establecimiento de @ISA y las necesarias para implementar 'tie'.
