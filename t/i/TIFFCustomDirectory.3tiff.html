TIFFCUSTOMDIRECTORY(3tiff) LibTIFF TIFFCUSTOMDIRECTORY(3tiff)

NOMBRE

TIFFCustomDirectory - rutinas para crear un directorio personalizado

SINOPSIS

#include <tiffio.h>
int TIFFCreateCustomDirectory(TIFF *tif, const TIFFFieldArray *infoarray)
int TIFFCreateEXIFDirectory(TIFF *tif)
int TIFFCreateGPSDirectory(TIFF *tif)
int TIFFWriteCustomDirectory(TIFF *tif, uint64 *pdiroff)
int TIFFReadCustomDirectory(TIFF *tif, toff_t diroff, const TIFFFieldArray *infoarray)
int TIFFReadEXIFDirectory(TIFF *tif, toff_t diroff)
int TIFFReadGPSDirectory(TIFF *tif, toff_t diroff)
const TIFFFieldArray *_TIFFGetExifFields(void)
const TIFFFieldArray *_TIFFGetGpsFields(void)

DESCRIPCIÓN

Las siguientes rutinas crean un directorio personalizado y recuperan información sobre directorios en un archivo TIFF abierto.

TIFFCreateCustomDirectory(), TIFFCreateEXIFDirectory(), TIFFCreateGPSDirectory() configurarán un directorio personalizado o uno de los directorios predefinidos EXIF o GPS y establecerán el contexto del manejador TIFF tif a ese directorio personalizado para funciones como TIFFSetField().

TIFFWriteCustomDirectory() escribirá el contenido del directorio personalizado actual en el archivo y devolverá el desplazamiento a ese directorio en pdiroff. Ese desplazamiento debe escribirse en el IFD principal:

 /* Volver al primer directorio y añadir el puntero EXIFIFD. */
TIFFSetDirectory(tif, 0);
TIFFSetField(tif, TIFFTAG_EXIFIFD, pdiroff);

TIFFReadCustomDirectory() leerá el directorio personalizado desde el desplazamiento arbitrario en el infoarray y establecerá el contexto del manejador TIFF tif a ese directorio personalizado para funciones como TIFFReadField(). El TIFFFieldArray infoarray debe ajustarse al diseño del directorio personalizado. Para los directorios predefinidos EXIF y GPS, las definiciones relevantes de TIFFFieldArray están ocultas dentro de las funciones TIFFReadEXIFDirectory() y TIFFReadGPSDirectory(). El código es muy similar a TIFFReadDirectory(). El desplazamiento al directorio personalizado diroff debe leerse primero desde la etiqueta TIFF relativa.

_TIFFGetExifFields() y _TIFFGetGpsFields() devolverán un puntero a la lista de definiciones internas de libtiff de las etiquetas EXIF y GPS, respectivamente.

NOTAS

Tenga en cuenta

  • que hasta que un directorio no se escriba en el archivo Y se lea de nuevo, las funciones de consulta no recuperarán la información correcta.
  • que el directorio recién creado no existirá en el archivo hasta que se haya llamado a TIFFWriteDirectory(), TIFFCheckpointDirectory(), TIFFFlush() o TIFFClose().
  • que TIFFCreateDirectory() y TIFFWriteDirectory() crean un nuevo directorio, liberan la estructura *tif y configuran una nueva.
  • que a diferencia de TIFFWriteDirectory(), TIFFCheckpointDirectory() no libera las estructuras de datos del directorio en memoria.
  • que LibTiff no admite cadenas de directorios personalizadas (NextIFD apuntando a otro IFD). NextIFD de los directorios personalizados siempre se establece en cero y debe ser cero al leer.

Desafortunadamente, para crear o leer directorios personalizados con campos predefinidos, es necesario incluir el privado tif_dir.h. Sin embargo, para los directorios EXIF y GPS, que tienen un esquema predefinido dentro de libtiff, esto no es necesario. Hay algunos programas de prueba que demuestran brevemente la creación y lectura de directorios EXIF, GPS y personalizados. Consulte test/custom_dir.c y test/custom_dir_EXIF_231.c

PUNTOS Y INSTRUCCIONES DETALLADAS

Escribir archivos TIFF con más de un directorio (IFD) no es fácil debido a que se deben conocer algunos efectos secundarios.

El punto principal aquí es que solo puede haber una estructura tif en la memoria principal para un archivo, que solo puede contener las etiquetas de un directorio a la vez. Es inútil trabajar con dos punteros diferentes tiffOut1, tiffOut2, porque solo hay UN objeto TIFF (directorio TIFF) dentro de libtiff. Si desea direccionar un segundo directorio en el archivo, las etiquetas del directorio actual deben guardarse primero en el archivo, de lo contrario se perderán (sobrescribirán o mezclarán). Luego, la estructura tif en la memoria principal debe limpiarse, de lo contrario, las etiquetas antiguas se incluirán en el nuevo directorio. Esto se puede hacer creando una nueva estructura tif vacía o leyendo un directorio previamente guardado en el archivo.

Una secuencia para manejar un segundo (o tercer) directorio TIFF, en este caso el IFD GPS, es la siguiente:

1.
Crear archivo TIFF
2.
Completar los metadatos "normales"
3.
Establecer la etiqueta para el directorio personalizado con un valor "dummy" para que la etiqueta quede reservada. El valor final se insertará más tarde. Esto evita que el directorio principal se escriba nuevamente en el archivo en un área adicional, dejando el primer área de memoria sin usar:
TIFFSetField(tiffOut, TIFFTAG_GPSIFD, dir_offset);
4.
Guardar el directorio TIFF actual en el archivo. De lo contrario, se perderá. Recuerde también el número del directorio actual:
TIFFWriteDirectory(tiffOut);
dirNum = TIFFCurrentDirectory(tiffOut);
5.
Crear el segundo directorio TIFF (por ejemplo, directorio personalizado) y establecer sus campos. El TIFFFieldArray infoarray debe especificarse de antemano en algún lugar de sus archivos de inclusión privados. Se proporciona un ejemplo para el directorio EXIF en tif_dirinfo.c
TIFFCreateCustomDirectory(tiffOut, infoarray);        /* para un directorio personalizado real */
/* o alternativamente, use GPS o EXIF con la estructura de campo IFD TIFFFieldArray predefinida */
TIFFCreateGPSDirectory(tiffOut);
TIFFSetField(tiffOut, GPSTAG_VERSIONID, gpsVersion);  /* establecer campos del directorio personalizado */

Tenga en cuenta que cada TIFFCreateDirectory() o TIFFWriteDirectory() aparentemente libera la estructura *tif y configura una nueva.

6.
Escribir el directorio personalizado en el archivo. El desplazamiento a ese directorio en el archivo se devuelve en dir_offset.
TIFFWriteCustomDirectory(tiffOut, &dir_offset);
7.
Recargar el primer directorio (es decir, el directorio TIFF original). Aparentemente, esto lee los datos de nuevo desde el archivo.
TIFFSetDirectory(tiffOut, dirNum);
8.
Establecer el valor de desplazamiento correcto de la etiqueta IFD del directorio personalizado y guardar esos cambios en el archivo.
TIFFSetField(tiffOut, TIFFTAG_GPSIFD, dir_offset);
TIFFWriteDirectory(tiffOut);

VALORES DE RETORNO

Todas las funciones devuelven 1 en caso de éxito y 0 en caso de error. En caso de error, se escribe un mensaje de error en el canal de errores estándar.

LUES

Se devuelve 1 cuando el contenido se escribe correctamente en el archivo. De lo contrario, se devuelve 0 si se encontró un error al escribir el contenido del directorio.

DIAGNÓSTICO

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR(). Del mismo modo, los mensajes de advertencia se dirigen a la rutina TIFFWarningExtR().
