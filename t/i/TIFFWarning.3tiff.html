TIFFWARNING(3tiff) LibTIFF TIFFWARNING(3tiff)

NOMBRE

TIFFWarning - Interfaz de advertencia de la biblioteca

SINOPSIS

#include <tiffio.h>
#include <stdarg.h>
void TIFFWarning(const char *module, const char *fmt, ...)
void TIFFWarningExt(thandle_t fd, const char *module, const char *fmt, ...)
void TIFFWarningExtR(TIFF *tif, const char *module, const char *fmt, ...)
typedef void (*TIFFWarningHandler)(const char *module, const char *fmt, va_list ap)
typedef void (*TIFFWarningHandlerExt)(thandle_t fd, const char *module, const char *fmt, va_list ap)
typedef int (*TIFFWarningHandlerExtR)(TIFF *tif, void *user_data, const char *module, const char *fmt, va_list ap)
TIFFWarningHandler TIFFSetWarningHandler(TIFFWarningHandler handler)
TIFFWarningHandlerExt TIFFSetWarningHandlerExt(TIFFWarningHandlerExt handler)

DESCRIPCIÓN

TIFFWarning() invoca la función manejadora de advertencias a nivel de biblioteca para escribir (normalmente) un mensaje de advertencia en stderr. El parámetro fmt es una cadena de formato de printf(), y se pueden proporcionar argumentos adicionales. El parámetro module se interpreta como una cadena que, si no es cero, debe imprimirse antes del mensaje; típicamente se utiliza para identificar el módulo de software en el que se detecta una advertencia.

Las aplicaciones que deseen capturar el control en caso de una advertencia deben usar TIFFSetWarningHandler() para anular el manejador de advertencias predeterminado. Se puede instalar un manejador de advertencias NULL (0) para suprimir los mensajes de advertencia.

Hay dos devoluciones de llamada de manejador de advertencias más disponibles para aplicaciones específicas, cada una con diferentes parámetros de llamada y pasando parámetros al manejador. Cada manejador también está vinculado a una función de mensaje de advertencia, es decir, TIFFWarningExt() y TIFFWarningExtR() si la aplicación pretende llamar al manejador con esos parámetros extendidos.

TIFFWarningExt() proporciona un identificador de archivo como parámetro. Dentro de libtiff, TIFFWarningExt() se llama pasando tif->tif_clientdata como fd, que representa el identificador de archivo TIFF (descriptor de archivo). El manejador de aplicación específico y el de toda la biblioteca para TIFFWarningExt() se configuran con TIFFSetWarningHandlerExt().

TIFFWarningExtR() (introducido con libtiff 4.5) se llama con su identificador TIFF y, por lo tanto, proporciona acceso a un manejador de advertencias por identificador TIFF (reentrante). Esto significa que para diferentes identificadores TIFF, se pueden configurar diferentes manejadores de advertencias. Este manejador de aplicación específico se puede configurar cuando se abre un archivo TIFF con una de las siguientes funciones: TIFFOpenExt(), TIFFOpenWExt(), TIFFFdOpenExt() o TIFFClientOpenExt(). Además, se puede proporcionar una **estructura de datos definida por el usuario** user_data para el manejador de advertencias.

NOTA

Ambas funciones, TIFFWarning() y TIFFWarningExt(), intentan llamar a ambas funciones manejadoras si están definidas. Primero se llama a TIFFWarningHandler() y luego a TIFFWarningHandlerExt(). Sin embargo, TIFFWarning() pasa un "0" como identificador de archivo a TIFFWarningHandlerExt().

TIFFWarningExtR() primero intenta llamar al manejador de advertencias definido por identificador TIFF. Si TIFFWarningHandlerExtR() no está definido o devuelve 0, se llaman TIFFWarningHandler() y luego TIFFWarningHandlerExt(). A partir de libtiff 4.5, se utiliza TIFFWarningExtR() dentro de la biblioteca libtiff.

VALORES DE RETORNO

TIFFSetWarningHandler() y TIFFSetWarningHandlerExt() devuelven una referencia a la función manejadora de advertencias anterior.

TIFFWarningHandlerExtR() devuelve un entero como "parada" para controlar la llamada a otras funciones manejadoras de advertencias dentro de TIFFWarningExtR():

  • 0: se llaman ambas funciones TIFFWarningHandler() y TIFFWarningHandlerExt().
  • Distinto de cero: no se llama a ninguna otra función de mensaje de advertencia.
