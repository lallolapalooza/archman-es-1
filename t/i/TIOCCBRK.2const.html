TIOCCBRK(2const) TIOCCBRK(2const)

NOMBRE

TCSBRK, TCSBRKP, TIOCSBRK, TIOCCBRK - enviar una interrupción (break)

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de las constantes T*BRK* */
#include <sys/ioctl.h>
int ioctl(int fd, TCSBRK, int arg);
int ioctl(int fd, TCSBRKP, int arg);
int ioctl(int fd, TIOCSBRK);
int ioctl(int fd, TIOCCBRK);

DESCRIPCIÓN

TCSBRK
Equivalente a tcsendbreak(fd, arg).
Si el terminal está usando transmisión de datos serie asíncrona, y arg es cero, entonces envía una interrupción (un flujo de bits cero) durante entre 0.25 y 0.5 segundos. Si el terminal no está usando transmisión de datos serie asíncrona, entonces o bien se envía una interrupción, o bien la función retorna sin hacer nada. Cuando arg no es cero, nadie sabe qué sucederá.
(SVr4, UnixWare, Solaris y Linux tratan tcsendbreak(fd,arg) con arg no cero como tcdrain(fd). SunOS trata arg como un multiplicador y envía un flujo de bits arg veces más largo que para arg cero. DG/UX y AIX tratan arg (cuando no es cero) como un intervalo de tiempo medido en milisegundos. HP-UX ignora arg.)
TCSBRKP
La llamada versión "POSIX" de TCSBRK. Trata arg no cero como un intervalo de tiempo medido en decisegundos, y no hace nada cuando el driver no soporta interrupciones.
TIOCSBRK
Activar interrupción, es decir, empezar a enviar bits cero.
TIOCCBRK
Desactivar interrupción, es decir, dejar de enviar bits cero.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1, y errno se establece para indicar el error.

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
