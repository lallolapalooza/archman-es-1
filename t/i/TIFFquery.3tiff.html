NOMBRE

TIFFquery - rutinas de consulta

SINOPSIS

#include <tiffio.h>
tdir_t TIFFCurrentDirectory(TIFF *tif)
uint64_t TIFFCurrentDirOffset(TIFF *tif)
int TIFFLastDirectory(TIFF *tif)
tdir_t TIFFNumberOfDirectories(TIFF *tif)
uint32_t TIFFCurrentRow(TIFF *tif)
tstrip_t TIFFCurrentStrip(TIFF *tif)
ttile_t TIFFCurrentTile(TIFF *tif)
int TIFFFileno(TIFF *tif)
char *TIFFFileName(TIFF *tif)
int TIFFGetMode(TIFF *tif)
int TIFFIsTiled(TIFF *tif)
int TIFFIsBigEndian(TIFF *tif)
int TIFFIsBigTIFF(TIFF *tif)
int TIFFIsByteSwapped(TIFF *tif)
int TIFFIsMSB2LSB(TIFF *tif)
int TIFFIsUpSampled(TIFF *tif)
const char *TIFFGetVersion(void)

DESCRIPCIÓN

Las siguientes rutinas de consulta devuelven información de estado sobre la estructura de directorios de un archivo TIFF abierto.

TIFFCurrentDirectory() devuelve el índice del directorio actual (los directorios se numeran a partir de 0). Este número es adecuado para usarlo con la rutina TIFFSetDirectory(). Se devuelve un valor de 65535 (directorio inexistente) si el directorio aún no se ha escrito en el archivo después de abrirlo.

TIFFCurrentDirOffset() devuelve el desplazamiento del archivo del directorio actual (en lugar de un índice). El desplazamiento del archivo es adecuado para usarlo con la rutina TIFFSetSubDirectory(). Esto es necesario para acceder a subdirectorios enlazados a través de una etiqueta SubIFD.

TIFFLastDirectory() devuelve un valor distinto de cero si el directorio actual es el último directorio del archivo; de lo contrario, se devuelve cero.

TIFFNumberOfDirectories() devuelve el número de directorios en un archivo. Tenga en cuenta que los directorios recién creados, que no están “escritos” en el archivo, no cuentan.

NOTA:

Tenga en cuenta que el valor de retorno de las funciones de consulta de directorio anteriores no es válido hasta que el directorio se “escribe” en el archivo Y se lee de nuevo, por ejemplo, TIFFSetDirectory() o TIFFReadDirectory().

Las siguientes rutinas de consulta devuelven información sobre un archivo TIFF abierto y sus datos de imagen.

TIFFCurrentRow(), TIFFCurrentStrip() y TIFFCurrentTile() devuelven la fila, tira y mosaico actuales, respectivamente, que se están leyendo o escribiendo. Estos valores se actualizan cada vez que se realiza una lectura o escritura.

TIFFFileno() devuelve el descriptor de archivo subyacente utilizado para acceder a la imagen TIFF en el sistema de archivos.

TIFFFileName() devuelve la ruta de argumento pasada a TIFFOpen() o TIFFFdOpen().

TIFFGetMode() devuelve el modo con el que se abrió el archivo subyacente. En los sistemas UNIX, este es el valor pasado a la llamada al sistema open() (2).

TIFFIsTiled() devuelve un valor distinto de cero si los datos de la imagen tienen una organización en mosaicos. Se devuelve cero si los datos de la imagen están organizados en tiras.

TIFFIsBigEndian() devuelve un valor distinto de cero si el archivo es BigEndian y cero si el archivo es LittleEndian.

TIFFIsBigTIFF() devuelve un valor distinto de cero si el archivo está en el estilo BigTIFF.

TIFFIsByteSwapped() devuelve un valor distinto de cero si los datos de la imagen tenían un orden de bytes diferente al de la máquina host. Se devuelve cero si los archivos TIFF y los órdenes de bytes del host local son los mismos. Tenga en cuenta que las funciones TIFFReadTile(), TIFFReadEncodedStrip() y TIFFReadScanline() normalmente ya realizan el intercambio de bytes al orden del host local si es necesario.

TIFFIsMSB2LSB() devuelve un valor distinto de cero si los datos de la imagen se devuelven con el bit 0 como el bit más significativo.

TIFFIsUpSampled() devuelve un valor distinto de cero si los datos de la imagen devueltos a través de las rutinas de la interfaz de lectura se están re-muestreando. Esto puede ser útil para las aplicaciones que desean calcular los tamaños de los búferes de E/S para reflejar este uso (aunque las rutinas habituales de tamaño de tiras y mosaicos ya hacen esto).

TIFFGetVersion() devuelve una cadena ASCII que tiene un sello de versión para el software de la biblioteca TIFF.
