TIOCPKT(2const) TIOCPKT(2const)

NOMBRE

TIOCPKT, TIOCGPKT, TIOCSPTLCK, TIOCGPTLCK, TIOCGPTPEER - ioctl de pseudoterminal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de constantes TIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCPKT, const int *mode);
int ioctl(int fd, TIOCPKT, int *mode);
int ioctl(int fd, TIOCSPTLCK, const int *lock);
int ioctl(int fd, TIOCGPTLCK, int *lock);
int ioctl(int fd, TIOCGPTPEER, int flags);

DESCRIPCIÓN

TIOCPKT
Habilita (cuando *mode es distinto de cero) o deshabilita el modo paquete. Solo se puede aplicar al lado maestro de un pseudoterminal (y devolverá ENOTTY en caso contrario). En modo paquete, cada read(2) subsiguiente devolverá un paquete que contendrá un único byte de control distinto de cero, o tendrá un único byte que contiene cero ('\0') seguido de datos escritos en el lado esclavo del pseudoterminal. Si el primer byte no es TIOCPKT_DATA (0), es un OR de uno o más de los siguientes bits:
TIOCPKT_FLUSHREAD Se vacía la cola de lectura del terminal.
TIOCPKT_FLUSHWRITE Se vacía la cola de escritura del terminal.
TIOCPKT_STOP La salida al terminal se detiene.
TIOCPKT_START La salida al terminal se reanuda.
TIOCPKT_DOSTOP Los caracteres de inicio y detención son ^S / ^Q.
TIOCPKT_NOSTOP Los caracteres de inicio y detención no son ^S / ^Q.
Mientras el modo paquete está en uso, la presencia de información de estado de control para ser leída del lado maestro puede detectarse mediante un select(2) para condiciones excepcionales o un poll(2) para el evento POLLPRI.
Este modo es utilizado por rlogin(1) y rlogind(8) para implementar un inicio de sesión remoto con eco local y control de flujo local de ^S/^Q.
TIOCGPKT
Devuelve la configuración actual del modo paquete en el entero al que apunta mode.
TIOCSPTLCK
Establece (si *lock es distinto de cero) o elimina (si *lock es cero) el bloqueo en el dispositivo esclavo del pseudoterminal. (Ver también unlockpt(3).)
TIOCGPTLCK
Coloca el estado de bloqueo actual del dispositivo esclavo del pseudoterminal en la ubicación apuntada por lock.
TIOCGPTPEER
Dado un descriptor de archivo en fd que se refiere a un maestro de pseudoterminal, abre (con los flags dados al estilo de open(2)) y devuelve un nuevo descriptor de archivo que se refiere al dispositivo esclavo del pseudoterminal par. Esta operación se puede realizar independientemente de si el nombre de ruta del dispositivo esclavo es accesible a través del espacio de nombres de montaje del proceso que llama.
Los programas conscientes de la seguridad que interactúan con espacios de nombres pueden desear usar esta operación en lugar de open(2) con el nombre de ruta devuelto por ptsname(3), y funciones de biblioteca similares que tienen APIs inseguras. (Por ejemplo, la confusión puede ocurrir en algunos casos al usar ptsname(3) con un nombre de ruta donde un sistema de archivos devpts se ha montado en un espacio de nombres de montaje diferente.)

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

ENOTTY
