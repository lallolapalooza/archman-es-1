TIFFREADENCODEDSTRIP(3tiff) LibTIFF TIFFREADENCODEDSTRIP(3tiff)

NOMBRE

TIFFReadEncodedStrip - lee y decodifica una tira de datos de un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
tmsize_t TIFFReadEncodedStrip(TIFF *tif, uint32_t strip, void *buf, tmsize_t size)

DESCRIPCIÓN

Lee la tira de datos especificada y coloca hasta size bytes de información descomprimida en el búfer de datos (proporcionado por el usuario).

NOTAS

El valor de strip es un número de tira "crudo". Es decir, el llamante debe tener en cuenta si los datos están organizados en planos separados (PlanarConfiguration = 2) o no. Para leer una tira completa de datos, el búfer de datos debe ser típicamente al menos tan grande como el número devuelto por TIFFStripSize(). Si se pasa -1 en el parámetro size, se leerá la tira completa. Debes asegurarte de tener suficiente espacio asignado para el búfer.

La biblioteca intenta ocultar las diferencias de orden de bits y bytes entre la imagen y la máquina nativa convirtiendo los datos al orden nativo de la máquina. La inversión de bits se realiza si la etiqueta FillOrder es opuesta al orden de bits nativo de la máquina. Las muestras de 16 y 32 bits se intercambian automáticamente de bytes si el archivo se escribió con un orden de bytes opuesto al orden de bytes nativo de la máquina.

VALORES DE RETORNO

Se devuelve el número real de bytes de datos que se colocaron en buf; TIFFReadEncodedStrip() devuelve -1 si se encontró un error.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().
