NOMBRE

Time::ParseDate -- análisis de fechas tanto relativas como absolutas

SINOPSIS

use Time::ParseDate;
$segundos_desde_1enero1970 = parsedate("12/11/94 2pm", NO_RELATIVE => 1)
$segundos_desde_1enero1970 = parsedate("12/11/94 2pm", %options)

OPCIONES

El análisis de fechas también puede utilizar opciones. Las opciones son las siguientes:

FUZZY   -> está bien no analizar toda la cadena de fecha
NOW     -> la hora "actual" para tiempos relativos (por defecto time())
ZONE    -> zona horaria local (por defecto $ENV{TZ})
WHOLE   -> se debe analizar toda la cadena de entrada
GMT     -> se asume que la hora de entrada es GMT, no localtime
UK      -> prefiere fechas estilo UK (dd/mm en lugar de mm/dd)
DATE_REQUIRED -> no establecer fecha por defecto
TIME_REQUIRED -> no establecer hora por defecto
NO_RELATIVE -> la hora de entrada no es relativa a NOW
TIMEFIRST -> intenta analizar la hora antes que la fecha [no por defecto]
PREFER_PAST -> cuando el año o el día de la semana es ambiguo, asume pasado
PREFER_FUTURE -> cuando el año o el día de la semana es ambiguo, asume futuro
SUBSECOND -> analiza fracciones de segundo
VALIDATE -> solo acepta valores normales para HHMMSS, YYMMDD. De lo contrario,
        días como -1 pueden dar el último día del mes anterior.

DESCRIPCIÓN

Este módulo reconoce los formatos de fecha/hora mencionados. Por lo general, se especifica una fecha y una hora. Hay numerosas opciones para controlar lo que se reconoce y lo que no.

El código de retorno es siempre el tiempo en segundos desde el 1 de enero de 1970 o undef si no pudo analizar el tiempo.

Si se especifica una zona horaria, debe ir después de la hora. Las especificaciones de año se pueden añadir al final de las horas absolutas.

Si parsedate() se llama desde un contexto de matriz, devolverá dos elementos. En caso de éxito, devolverá los segundos y lo que queda de la cadena de entrada. En caso de fallo, devolverá "undef" y una cadena de error.

EJEMPLOS

$segundos = parsedate("Mon Jan  2 04:24:27 1995");
$segundos = parsedate("Tue Apr 4 00:22:12 PDT 1995");
$segundos = parsedate("04.04.95 00:22", ZONE => PDT);
$segundos = parsedate("Jan 1 1999 11:23:34.578", SUBSECOND => 1);
$segundos = parsedate("122212 950404", ZONE => PDT, TIMEFIRST => 1);
$segundos = parsedate("+3 secs", NOW => 796978800);
$segundos = parsedate("2 months", NOW => 796720932);
$segundos = parsedate("last Tuesday");
$segundos = parsedate("Sunday before last");
($segundos, $restante) = parsedate("today is the day");
($segundos, $error) = parsedate("today is", WHOLE=>1);
