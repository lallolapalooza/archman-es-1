TIFFRGBAImage(3tiff) LibTIFF TIFFRGBAImage(3tiff)

NOMBRE

TIFFRGBAImage - leer y decodificar una imagen en un ráster

SINOPSIS

#include <tiffio.h>
typedef unsigned char TIFFRGBValue
typedef struct _TIFFRGBAImage TIFFRGBAImage
int TIFFRGBAImageOK(TIFF *tif, char emsg[1024])
int TIFFRGBAImageBegin(TIFFRGBAImage *img, TIFF *tif, int stopOnError, char emsg[1024])
int TIFFRGBAImageGet(TIFFRGBAImage *img, uint32_t *raster, uint32_t width, uint32_t height)
void TIFFRGBAImageEnd(TIFFRGBAImage *img)

DESCRIPCIÓN

Las rutinas descritas aquí proporcionan una interfaz de alto nivel a través de la cual se pueden leer imágenes TIFF en memoria. Las imágenes pueden basarse en tiras o teselas y tener una variedad de características diferentes: bits/muestra, muestras/píxel, fotometría, etc. El estado de decodificación se encapsula en una estructura TIFFRGBAImage, lo que permite capturar el estado de varias imágenes y cambiar rápidamente entre ellas. El formato del ráster de destino se puede personalizar según las necesidades de una aplicación particular instalando rutinas personalizadas que manipulan los datos de la imagen de acuerdo con los requisitos de la aplicación.

El uso predeterminado para estas rutinas es:

  • verificar si una imagen se puede procesar usando TIFFRGBAImageOK()
  • construir un bloque de estado del decodificador usando TIFFRGBAImageBegin()
  • leer y decodificar una imagen en un ráster de destino usando TIFFRGBAImageGet(), y luego
  • liberar recursos usando TIFFRGBAImageEnd()

TIFFRGBAImageGet() se puede llamar varias veces para decodificar una imagen utilizando diferentes parámetros de estado. Si se van a mostrar varias imágenes y no hay suficiente espacio para cada uno de los rásteres decodificados, se pueden gestionar varios bloques de estado y luego se pueden realizar llamadas a TIFFRGBAImageGet() según sea necesario para mostrar una imagen.

Se asume que el ráster generado es una matriz de entradas de 32 bits de ancho x alto, donde ancho debe ser menor o igual al ancho de la imagen (alto puede tener cualquier tamaño distinto de cero). Si las dimensiones del ráster son menores que las de la imagen, los datos de la imagen se recortan a los límites del ráster. Si la altura del ráster es mayor que la de la imagen, los datos de la imagen se colocan en la parte inferior del ráster. (Tenga en cuenta que se asume que el ráster está organizado de tal manera que el píxel en la ubicación (x, y) es raster [ y × ancho + x ]; con el origen del ráster en la esquina inferior izquierda).

Los píxeles del ráster son muestras de rojo, verde, azul y alfa empaquetadas de 8 bits. Se deben utilizar las macros TIFFGetR, TIFFGetG, TIFFGetB y TIFFGetA para acceder a muestras individuales. Las imágenes sin información de mate alfa asociado tienen un alfa constante de 1.0 (255).

TIFFRGBAImageGet() convierte imágenes que no son de 8 bits escalando los valores de las muestras. Las imágenes de paleta, escala de grises, de nivel binario, CMYK y YCbCr se convierten a RGB de forma transparente. Los píxeles del ráster se devuelven sin corregir por ninguna información de colorimetría presente en el directorio.

El parámetro stopOnError especifica cómo actuar si se encuentra un error al leer la imagen. Si stopOnError es distinto de cero, un error terminará la operación; de lo contrario, TIFFRGBAImageGet() continuará procesando datos hasta que se hayan solicitado todos los datos posibles de la imagen.

FORMATOS DE RÁSTER ALTERNATIVOS

Para utilizar el soporte principal para leer y procesar imágenes TIFF, pero escribir los datos del ráster resultantes en un formato diferente, solo necesita anular los "métodos put" utilizados para almacenar los datos del ráster. Estos métodos se definen en la estructura TIFFRGBAImage y se configuran inicialmente mediante TIFFRGBAImageBegin() para que apinten a rutinas que empaquetan datos del ráster en el formato de píxel ABGR predeterminado. Se utilizan dos rutinas diferentes según la organización física de los datos de la imagen en el archivo: PlanarConfiguration = 1 (muestras empaquetadas) y PlanarConfiguration = 2 (muestras separadas). Tenga en cuenta que este mecanismo se puede utilizar para transformar los datos antes de almacenarlos en el ráster. Por ejemplo, se pueden convertir los datos en índices de mapa de color para su visualización en una pantalla con mapa de color.

ALMACENAMIENTO Y VISUALIZACIÓN DE RÁSTER SIMULTÁNEOS

Es fácil mostrar una imagen mientras se carga en memoria anulando los métodos put, como se describe anteriormente, para admitir formatos de ráster alternativos. Simplemente mantenga una referencia a los métodos put predeterminados configurados por TIFFRGBAImageBegin() y luego invoquelos antes o después de cada operación de visualización. Un ejemplo de método "put" para actualizar la pantalla a medida que se completa el ráster:

static void
putContigAndDraw(TIFFRGBAImage* img, uint32_t* raster,
    uint32_t x, uint32_t y, uint32_t w, uint32_t h,
    int32_t fromskew, int32_t toskew,
    unsigned char* cp)
{
    (*putContig)(img, raster, x, y, w, h, fromskew, toskew, cp);
    if (x+w == width) {
        w = width;
        if (img->orientation == ORIENTATION_TOPLEFT)
            lrectwrite(0, y-(h-1), w-1, y, raster-x-(h-1)*w);
        else
            lrectwrite(0, y, w-1, y+h-1, raster);
    }
}

(La rutina original proporcionada por la biblioteca se guarda en la variable putContig.)

SOPORTE PARA FORMATOS TIFF ADICIONALES

Las rutinas TIFFRGBAImage() admiten los sabores más comunes de TIFF. Es posible ampliar este soporte anulando el "método get" invocado por TIFFRGBAImageGet() para leer datos de imágenes TIFF. Los detalles de cómo hacerlo son un tanto complicados; lo mejor es hacer una copia de un método get existente y modificarlo para satisfacer las necesidades de una aplicación.

NOTAS

Las muestras deben tener 1, 2, 4, 8 o 16 bits. Las muestras colorimétricas/píxel deben ser 1, 3 o 4 (es decir, SamplesPerPixel -ExtraSamples).

Los mapas de color de imágenes de paleta que parecen estar escritos incorrectamente como valores de 8 bits se escalan automáticamente a 16 bits.

VALORES DE RETORNO

Todas las rutinas devuelven 1 si la operación fue exitosa. De lo contrario, se devuelve 0 si se encontró un error y stopOnError es cero.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

"Lo siento, no puedo manejar imágenes de %d bits":

La imagen tenía BitsPerSample distinto de 1, 2, 4, 8 o 16.

"Lo siento, no puedo manejar imágenes de %d canales":

La imagen tenía SamplesPerPixel distinto de 1, 3 o 4.

Falta la etiqueta necesaria "PhotometricInterpretation":

La imagen no tenía una etiqueta que describa cómo mostrar los datos.

No hay etiqueta "PhotometricInterpretation", se asume RGB:

A la imagen le faltaba una etiqueta que describiera cómo mostrarla, pero debido a que tiene 3 o 4 muestras/píxel, se asume que es RGB.

No hay etiqueta "PhotometricInterpretation", se asume min-es-negro:

A la imagen le faltaba una etiqueta que describiera cómo mostrarla, pero debido a que tiene 1 muestra

TIFFRGBAImage(3tiff)

NOMBRE

TIFFRGBAImage, TIFFReadRGBAImage, TIFFReadRGBAStrip, TIFFReadRGBATile, TIFFRGBAImageOK, TIFFRGBAImageGet

SINOPSIS

#include <tiffio.h>

int TIFFRGBAImage(TIFF* tif,
uint32* raster,
uint32 rows,
uint32 cols);

int TIFFReadRGBAImage(TIFF* tif,
uint32* raster,
uint32 rows,
uint32 cols,
int stoponerr,
int read_strips);

int TIFFReadRGBAStrip(TIFF* tif,
uint32* raster,
uint32 rows,
uint32 cols);

int TIFFReadRGBATile(TIFF* tif,
uint32* raster,
uint32 rows,
uint32 cols);

int TIFFRGBAImageOK(TIFF* tif);

int TIFFRGBAImageGet(TIFF* tif,
uint32* raster,
uint32 rows,
uint32 cols);

DESCRIPCIÓN

Las funciones TIFFRGBAImage, TIFFReadRGBAImage, TIFFReadRGBAStrip y TIFFReadRGBATile son un conjunto de interfaces de nivel superior para leer datos de imagen en un formato de ráster RGBA de 8 bits por canal. El sistema de destino es un array de enteros sin signo de 32 bits de tamaño `rows * cols`. La memoria para este array debe ser asignada por el llamador. Los datos se almacenan en orden de fila principal, con los píxeles ordenados de izquierda a derecha y las filas ordenadas de arriba a abajo. La información de color y transparencia se almacena en los bytes más significativos del entero de 32 bits. Específicamente, el byte más significativo es el canal rojo, seguido del verde, el azul y finalmente el canal alfa (transparencia). Cada canal está representado por 8 bits de datos, por lo que los valores varían de 0 a 255. Un valor de alfa de 255 representa opacidad total, mientras que un valor de 0 representa transparencia total.

La función TIFFRGBAImage intenta leer una imagen como un ráster RGBA. Devuelve 1 si la imagen se puede leer como un ráster RGBA y 0 en caso contrario. Esta función intenta realizar la conversión por sí misma. Si la imagen no puede ser representada directamente como RGBA (por ejemplo, es CMYK), la función intenta realizar la conversión necesaria. Si la imagen no se puede leer como un ráster RGBA o si hay un error de lectura, la función devuelve 0.

La función TIFFReadRGBAImage es similar a TIFFRGBAImage, pero proporciona control adicional sobre el manejo de errores y el método de lectura. Si `stoponerr` es distinto de cero, la función se detendrá en el primer error. Si `read_strips` es distinto de cero, la función leerá la imagen en forma de tiras; de lo contrario, la leerá en forma de teselas. La función devuelve 1 si la imagen se lee correctamente y 0 en caso contrario.

Las funciones TIFFReadRGBAStrip y TIFFReadRGBATile se utilizan para leer datos de imagen como tiras o teselas, respectivamente. Están diseñadas para usarse cuando la imagen está organizada en tiras o teselas, y proporcionan un control más granular sobre el proceso de lectura. Ambas funciones devuelven 1 si la imagen se lee correctamente y 0 en caso contrario.

La función TIFFRGBAImageOK comprueba si una imagen se puede leer como un ráster RGBA sin realizar ninguna conversión. Devuelve 1 si la imagen se puede leer directamente como RGBA y 0 en caso contrario.

La función TIFFRGBAImageGet es similar a TIFFReadRGBAImage, pero asume que la imagen es RGBA o se puede convertir fácilmente a RGBA. Intenta leer la imagen como un ráster RGBA y devuelve 1 si tiene éxito, 0 en caso contrario. Esta función es una versión más simple de TIFFReadRGBAImage y puede ser más adecuada para imágenes que ya están en un formato compatible.

FORMATOS DE RÁSTER ALTERNATIVOS

Las funciones TIFFReadRGBAImage, TIFFReadRGBAStrip y TIFFReadRGBATile pueden configurarse para devolver un formato de ráster alternativo estableciendo el modificador `(photometric,bits.depth,rows.cols)` que se pasa a la función TIFFSetTagExtender. Esto se utiliza principalmente para la salida en formato RGB. El valor por defecto es RGBA.

ALMACENAMIENTO Y VISUALIZACIÓN SIMULTÁNEOS DE RÁSTER

Las funciones TIFFReadRGBAImage, TIFFReadRGBAStrip y TIFFReadRGBATile se pueden utilizar para leer y mostrar imágenes simultáneamente. Al llamar a estas funciones repetidamente, puede procesar la imagen en trozos más pequeños, lo que permite la visualización en tiempo real y el procesamiento de imágenes grandes sin consumir una gran cantidad de memoria. Las funciones TIFFReadRGBAStrip y TIFFReadRGBATile son especialmente útiles para este propósito, ya que permiten leer la imagen en forma de tiras o teselas, respectivamente.

APOYO A FORMATOS TIFF ADICIONALES

Las funciones TIFFRGBAImage, TIFFReadRGBAImage, TIFFReadRGBAStrip y TIFFReadRGBATile se pueden ampliar para admitir formatos TIFF adicionales. Esto se hace registrando un nuevo extensor de etiquetas con la función TIFFSetTagExtender. El extensor de etiquetas es una función que se llama cuando se encuentra una etiqueta desconocida en un archivo TIFF. La función del extensor de etiquetas es responsable de manejar la etiqueta y realizar las acciones apropiadas. Esto permite ampliar la funcionalidad de la biblioteca libtiff para admitir formatos TIFF personalizados o específicos de la aplicación.

NOTAS

Estas funciones son compatibles con las siguientes configuraciones de imágenes TIFF:

  • Formatos de imagen de bits por muestra de 1, 2, 4, 8 y 16 bits.
  • Interpretaciones fotométricas de blanco y negro, escala de grises, RGB y paleta.
  • Compresión de línea, packbits, LZW y JPEG.
  • Tiras y teselas.

Las funciones intentan leer la imagen en un formato RGBA de 32 bits. Si la imagen está en formato CMYK, se realizará una conversión. La conversión de paleta se realiza mediante una tabla de consulta de 256 entradas. Las imágenes con más de 256 colores en la paleta se truncan a 256 colores. Las imágenes en blanco y negro y en escala de grises se convierten a RGB. Las imágenes en blanco y negro se convierten a RGB utilizando una tabla de consulta de 2 bits. Las imágenes en escala de grises se convierten a RGB utilizando una tabla de consulta de 8 bits.

El formato de píxel RGBA se representa como un entero sin signo de 32 bits. El canal rojo se almacena en los bits 24-31, el verde en los bits 16-23, el azul en los bits 8-15 y el alfa en los bits 0-7.

Las funciones TIFFReadRGBAImage, TIFFReadRGBAStrip y TIFFReadRGBATile asignan memoria interna para almacenar los datos de la imagen. El llamador es responsable de liberar esta memoria utilizando la función TIFFFree.

VALORES DE RETORNO

Todas las funciones devuelven 1 si la operación se realiza correctamente y 0 si se produce un error.
