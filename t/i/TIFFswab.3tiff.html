DESCRIPCIÓN

Las siguientes rutinas son utilizadas por la biblioteca para intercambiar datos de 16, 32 y 64 bits y para invertir el orden de los bits en los bytes.

TIFFSwabShort() y TIFFSwabLong() y TIFFSwabFloat() intercambian los bytes en un único elemento de 16 y 32 bits, respectivamente.

TIFFSwabLong8() y TIFFSwabDouble() intercambian los bytes en un único elemento de 64 bits.

TIFFSwabArrayOfTriples() intercambia el primer y el tercer byte de cada tripleta (tres bytes) dentro del array de bytes. El segundo byte de cada tripleta permanece sin cambios.

TIFFSwabArrayOfShort() y TIFFSwabArrayOfLong(), TIFFSwabArrayOfFloat() intercambian los bytes en un array de elementos de 16 y 32 bits, respectivamente.

TIFFSwabArrayOfLong8() y TIFFSwabArrayOfDouble() intercambian los bytes en un array de elementos de 64 bits.

TIFFReverseBits() reemplaza cada byte en data con el valor equivalente con los bits invertidos. Esta operación se realiza con una tabla de búsqueda, que se devuelve utilizando la función TIFFGetBitRevTable(). El parámetro reversed especifica qué tabla se debe devolver. Proporcione 1 si desea la tabla de inversión de bits. Proporcione 0 para obtener la tabla que no invierte los valores de los bits. Es una tabla de búsqueda que puede utilizarse como una “función identidad”; es decir, TIFFNoBitRevTable[n] == n.
