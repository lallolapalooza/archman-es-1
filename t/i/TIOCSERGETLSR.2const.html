FIONREAD(2const) FIONREAD(2const)

NOMBRE

FIONREAD, TIOCINQ, TIOCOUTQ, TCFLSH, TIOCSERGETLSR - recuento de búfer y vaciado

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de constantes */
#include <sys/ioctl.h>
int ioctl(int fd, FIONREAD, int *argp);
int ioctl(int fd, TIOCINQ, int *argp);
int ioctl(int fd, TIOCOUTQ, int *argp);
int ioctl(int fd, TCFLSH, int arg);
int ioctl(int fd, TIOCSERGETLSR, int *argp);

DESCRIPCIÓN

FIONREAD
Obtener el número de bytes en el búfer de entrada.
TIOCINQ
Igual que FIONREAD.
TIOCOUTQ
Obtener el número de bytes en el búfer de salida.
TCFLSH
Equivalente a tcflush(fd, arg).
Ver tcflush(3) para los valores de argumento TCIFLUSH, TCOFLUSH, TCIOFLUSH.
TIOCSERGETLSR
Obtener el registro de estado de la línea. El registro de estado tiene el bit TIOCSER_TEMT activado cuando el búfer de salida está vacío y también el transmisor de hardware está físicamente vacío.
No tiene por qué ser compatible con todos los controladores tty serie.
tcdrain(3) no espera y retorna inmediatamente cuando el bit TIOCSER_TEMT está activado.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1, y errno se establece para indicar el error.

VER TAMBIÉN

ioctl(2), ioctl_tty(2), tcflush(3), termios(3)
