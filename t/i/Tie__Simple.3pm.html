NOMBRE

Tie::Simple - Variables ties hechas más fácil: mucho, mucho, mucho más fácil...

VERSIÓN

versión 1.04

SINÓPSIS

use Tie::Simple;
tie $scalar, 'Tie::Simple', $data,
    FETCH     => sub { ... },
    STORE     => sub { ... };
tie @array, 'Tie::Simple', $data,
    FETCH     => sub { ... },
    STORE     => sub { ... },
    FETCHSIZE => sub { ... },
    STORESIZE => sub { ... },
    EXTEND    => sub { ... },
    EXISTS    => sub { ... },
    DELETE    => sub { ... },
    CLEAR     => sub { ... },
    PUSH      => sub { ... },
    POP       => sub { ... },
    SHIFT     => sub { ... },
    UNSHIFT   => sub { ... },
    SPLICE    => sub { ... };
tie %hash, 'Tie::Simple', $data,
    FETCH     => sub { ... },
    STORE     => sub { ... },
    DELETE    => sub { ... },
    CLEAR     => sub { ... },
    EXISTS    => sub { ... },
    FIRSTKEY  => sub { ... },
    NEXTKEY   => sub { ... };

    PRINT     => sub { ... },

DESCRIPCIÓN

Este módulo agrega la capacidad de crear tipos de objetos de tie rápidamente sin tener que crear una clase completa. Lo hace de manera tal de intentar hacer la vida de los desarrolladores más fácil cuando se necesiten ties de uso único que encuentro a menudo.

El paquete "Tie::Simple" es realmente un front-end a otros clases que hacen la mayor parte de las cosas cuando se tie, pero este paquete hace el trabajo de la burbuja para automáticamente determinar lo que estás intentando hacer.

He intentado hacer este tan intuitivo como sea posible y dependiendo de otros elementos de Perl donde pueda para minimizar la necesidad de documentación y hacer este extra, extra, spiffy.

TYING SIMPLE

Para configurar tu tie rápida, simplemente empieza con la declaración típica de tie en la variable a la que estás tying. Debes siempre tie a "Tie::Simple" y no directamente a los otros paquetes incluidos con este módulo, ya que estos son solo helpers (aunque en realidad son clases de tie).

El tipo de tie depende del tipo de la variable dada como primer argumento a tie. Esto debería ser bastante obvio desde el "SINÓPSIS" anterior. Por lo tanto, los argumentos son:

1.
La variable a tie.
2.
La cadena 'Tie::Simple'.
3.
Un valor escalar (a partir de aquí, llamado "datos locales").
4.
Una lista de pares nombre/CÓDIGO.

En este punto, necesitas tener algún conocimiento de tying antes de poder continuar. Sugiero que leas la documentación de perltie.

Como notas en el documento de perltie, cada paquete de tie define funciones cuyo primer argumento se llama "this". El tercer argumento, datos locales, tomará el lugar de "this" en todas las llamadas de subrutina en la lista de pares nombre/CÓDIGO. Cada nombre debería ser el nombre de la función que se definiría para el tipo de tie adecuado si tuvieras una definición completa de paquete. La subrutina asociada al nombre será la que reciba los argumentos especificados en la documentación de perltie, pero en lugar de "this" se le dará el valor de datos locales que has establecido (podría incluso ser "undef" si no lo necesitas).

TIES PUEDEN SER AÚN MÁS SIMPLES

La sintaxis anterior muestra las rutinas típicas que podrías definir. (He omitido los métodos "UNTIE" y "DESTROY" pero puedes definirlos si lo necesitas, pero asegúrate de leer la documentación de perltie sobre posibles problemas.) Sin embargo, el "SINÓPSIS" es más completo que probablemente necesitas en la mayoría de los casos. Esto se debe a que "Tie::Simple" intenta aprovechar al máximo algunas de las funciones de built-ins de Perl que ayudan a crear paquetes de tie.
