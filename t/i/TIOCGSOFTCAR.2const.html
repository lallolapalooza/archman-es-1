TIOCSSOFTCAR(2const) TIOCSSOFTCAR(2const)

NOMBRE

TIOCGSOFTCAR, TIOCSSOFTCAR - marcar una línea como local

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de constantes TIOC*SOFTCAR */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGSOFTCAR, int *argp);
int ioctl(int fd, TIOCSSOFTCAR, const int *argp);

DESCRIPCIÓN

TIOCGSOFTCAR
("Obtener indicador de portadora de software") Obtiene el estado del indicador CLOCAL en el campo c_cflag de la estructura termios.
TIOCSSOFTCAR
("Establecer indicador de portadora de software") Establece el indicador CLOCAL en la estructura termios cuando *argp es distinto de cero, y lo borra en caso contrario.

Si el indicador CLOCAL de una línea está desactivado, la señal de detección de portadora (DCD) del hardware es significativa, y una llamada a open(2) del terminal correspondiente se bloqueará hasta que se active DCD, a menos que se proporcione el indicador O_NONBLOCK. Si CLOCAL está establecido, la línea se comporta como si DCD estuviera siempre activado. El indicador de portadora de software suele activarse para dispositivos locales y está desactivado para líneas con módems.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
