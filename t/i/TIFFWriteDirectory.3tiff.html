TIFFWRITEDIRECTORY(3tiff) LibTIFF TIFFWRITEDIRECTORY(3tiff)

NOMBRE

TIFFWriteDirectory - escribir el directorio actual en un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
int TIFFWriteDirectory(TIFF *tif)
int TIFFRewriteDirectory(TIFF *tif)
int TIFFCheckpointDirectory(TIFF *tif)
void TIFFSetWriteOffset(TIFF *tif, toff_t off)
int TIFFWriteCheck(TIFF *tif, int tiles, const char *module)

DESCRIPCIÓN

TIFFWriteDirectory() escribirá el contenido del directorio actual (IFD) en el archivo y preparará para crear un nuevo directorio (IFD) usando TIFFCreateDirectory(). Las aplicaciones solo necesitan llamar a TIFFWriteDirectory() al escribir múltiples subarchivos (imágenes) en un único archivo TIFF. Esto se llama “TIFF multipágina” o “TIFF multiimagen” (ver Multi Page / Multi Image TIFF). TIFFWriteDirectory() es llamado automáticamente por TIFFClose() y TIFFFlush() para escribir un directorio modificado si el archivo está abierto para escritura.

La función TIFFRewriteDirectory() opera de manera similar a TIFFWriteDirectory(), pero puede ser llamada con directorios leídos o escritos previamente que ya tienen una ubicación establecida en el archivo. Reescribirá el directorio, pero en lugar de colocarlo en su ubicación anterior (como haría TIFFWriteDirectory()), lo colocará al final del archivo, corrigiendo el puntero del directorio precedente o la cabecera del archivo para que apunte a su nueva ubicación. Esto es particularmente importante en casos donde el tamaño del directorio y los datos a los que apunta ha crecido, por lo que no cabrá en el espacio disponible en la ubicación antigua.

TIFFCheckpointDirectory() escribe el estado actual del directorio tiff en el archivo para hacer que lo que está actualmente en el archivo sea legible. A diferencia de TIFFWriteDirectory(), TIFFCheckpointDirectory() no libera las estructuras de datos del directorio en memoria, por lo que pueden ser actualizadas (mientras se escriben tiras/teselas) y escritas de nuevo. Al leer un archivo parcial de este tipo, en el peor de los casos obtendrás un error de lectura tiff para la primera tira/tesela encontrada que esté incompleta, pero al menos obtendrás todos los datos válidos en el archivo hasta ese punto. Cuando el archivo esté completo, simplemente usa TIFFWriteDirectory() como de costumbre para finalizarlo limpiamente.

TIFFSetWriteOffset() establece el desplazamiento de escritura actual. Esto solo debe usarse para establecer el desplazamiento a una ubicación previa conocida (con mucho cuidado), o a 0 para que la próxima escritura se añada al final del archivo.

TIFFWriteCheck() verifica que el archivo sea escribible y que la información del directorio esté configurada correctamente. Al hacer esto último, también “congelamos” el estado del directorio para que la información importante no cambie.

VALORES DE RETORNO

Se devuelve 1 cuando el contenido se escribe correctamente en el archivo. De lo contrario, se devuelve 0 si se encontró un error al escribir el contenido del directorio.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

"Error post-encoding antes de escribir el directorio":

Antes de escribir el contenido del directorio actual, se vacían los datos pendientes. Este mensaje indica que ocurrió un error al hacer esto.

"Error al vaciar datos antes de escribir el directorio":

Antes de escribir el contenido del directorio actual, se vacían los datos pendientes. Este mensaje indica que ocurrió un error al hacer esto.

"No se puede escribir el directorio, falta espacio":

No hubo suficiente espacio para asignar un área temporal para el directorio que se iba a escribir.

"Error al escribir el recuento del directorio":

Ocurrió un error de escritura al escribir el recuento de campos en el directorio.

"Error al escribir el contenido del directorio":

Ocurrió un error de escritura al escribir los campos del directorio.

"Error al escribir el enlace del directorio":

Ocurrió un error de escritura al escribir el enlace al siguiente directorio.

Error al escribir datos para el campo "%s":

Ocurrió un error de escritura al escribir datos indirectos para el campo especificado.

"Error al escribir la cabecera TIFF":

Ocurrió un error de escritura al reescribir la cabecera al principio del archivo.

"Error al obtener el recuento del directorio":

Ocurrió un error de lectura al obtener el campo de recuento del directorio para un directorio anterior. Esto puede ocurrir al configurar un enlace al directorio que se está escribiendo.

"Error al obtener el enlace del directorio":

Ocurrió un error de lectura al obtener el campo de enlace del directorio para un directorio anterior. Esto puede ocurrir al configurar un enlace al directorio que se está escribiendo.
