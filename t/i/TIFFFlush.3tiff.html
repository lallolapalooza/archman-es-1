NOMBRE

TIFFFlush - vacía las escrituras pendientes a un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
int TIFFFlush(TIFF *tif)
int TIFFFlushData(TIFF *tif)

DESCRIPCIÓN

TIFFFlush() provoca que se realicen las escrituras pendientes para el archivo especificado (incluidas las escrituras para el directorio actual). En operación normal, esta llamada nunca es necesaria: la biblioteca realiza automáticamente el vaciado requerido.

TIFFFlushData() vacía cualquier dato de imagen pendiente para que el archivo especificado sea escrito; los datos relacionados con el directorio no se vacían. En operación normal, esta llamada nunca es necesaria: la biblioteca realiza automáticamente el vaciado requerido.

VALORES DE RETORNO

Se devuelve 0 si se encuentra un error, de lo contrario se devuelve 1.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().
