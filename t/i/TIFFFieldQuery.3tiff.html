TIFFFieldQuery(3tiff) LibTIFF TIFFFieldQuery(3tiff)

NOMBRE

TIFFFieldQuery - rutinas para consultar información de campos TIFF

SINOPSIS

#include <tiffio.h>
const TIFFField *TIFFFieldWithName(TIFF *tif, const char *field_name)
const TIFFField *TIFFFieldWithTag(TIFF *tif, uint32_t tag)
const TIFFField *TIFFFindField(TIFF *tif, uint32_t tag, TIFFDataType dt)
int TIFFFieldIsAnonymous(const TIFFField *fip)
int TIFFFieldSetGetSize(const TIFFField *fip)
int TIFFFieldSetGetCountSize(const TIFFField *fip)

DESCRIPCIÓN

TIFFFieldWithName() y TIFFFieldWithTag() devuelven un puntero a la estructura de información del campo TIFF fip por el field_name de la etiqueta o por su número de tag.

TIFFFindField() busca la estructura de información del campo TIFF fip de un número de tag dado y un TIFFDataType dt específico. Con dt== TIFF_ANY el comportamiento es el mismo que para TIFFFieldWithTag().

Todas las tres funciones devuelven NULL cuando la etiqueta no está registrada dentro de libtiff (ver también Registro Automático de Etiquetas Predeterminadas).

Una búsqueda dependiente de TIFFDataType podría ser útil cuando la misma etiqueta está definida dos veces pero con diferentes tipos de datos, lo cual ocurre en casos raros como TIFFTAG_XCLIPPATHUNITS. Sin embargo, libtiff actualmente no soporta múltiples definiciones de la misma etiqueta.

Las siguientes rutinas devuelven información de estado sobre los campos TIFF.

fip es un puntero a la información del campo devuelto previamente por TIFFFindField(), TIFFFieldWithTag(), TIFFFieldWithName().

TIFFFieldIsAnonymous() devuelve verdadero (distinto de cero) si el campo, leído del archivo, es desconocido para libtiff y se ha auto-registrado un campo anónimo. La devolución es cero "0" si el campo es conocido por libtiff. Ver Registro Automático de Etiquetas Predeterminadas para más información.

TIFFFieldSetGetSize() devuelve el tamaño de los datos en bytes del tipo de dato del campo utilizado para el almacenamiento interno de libtiff. Este es también el tamaño de los datos del parámetro que se debe proporcionar a TIFFSetField() y TIFFGetField(). Los valores TIFF_RATIONAL personalizados pueden almacenarse internamente como float o double. TIFFFieldSetGetSize() devolvería "4" u "8", respectivamente.

TIFFFieldSetGetCountSize() devuelve el tamaño del parámetro count de TIFFSetField() y TIFFGetField() y también si es requerido: 0=ninguno, 2= uint16_t, 4= uint32_t. Ver también la descripción de TIFFFieldReadCount().
