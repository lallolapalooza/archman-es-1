Tie::RefHash(3perl) Guía del programador de Perl Tie::RefHash(3perl)

NOMBRE

Tie::RefHash - Usa referencias como claves de hash

VERSIÓN

versión 1.41

SINOPSIS

require 5.004;
use Tie::RefHash;
tie HASHVARIABLE, 'Tie::RefHash', LIST;
tie HASHVARIABLE, 'Tie::RefHash::Nestable', LIST;
untie HASHVARIABLE;

DESCRIPCIÓN

Este módulo proporciona la capacidad de usar referencias como claves de hash si primero enlaza ("tie") la variable de hash a este módulo. Normalmente, solo las claves del propio hash enlazado se conservan como referencias; para usar referencias como claves en hashes de hashes, use Tie::RefHash::Nestable, incluido como parte de Tie::RefHash.

Está implementado utilizando la interfaz TIEHASH estándar de perl. Consulte la entrada "tie" en perlfunc(1) y perltie(1) para obtener más información.

La versión Nestable funciona buscando referencias de hash que se están almacenando y convirtiéndolas en hashes enlazados para que también puedan tener referencias como claves. Esto ocurrirá sin previo aviso cada vez que almacene una referencia a uno de sus propios hashes en el hash enlazado.

EJEMPLO

use Tie::RefHash;
tie %h, 'Tie::RefHash';
$a = [];
$b = {};
$c = \*main;
$d = \"gunk";
$e = sub { 'foo' };
%h = ($a => 1, $b => 2, $c => 3, $d => 4, $e => 5);
$a->[0] = 'foo';
$b->{foo} = 'bar';
for (keys %h) {
   print ref($_), "\n";
}
tie %h, 'Tie::RefHash::Nestable';
$h{$a}->{$b} = 1;
for (keys %h, keys %{$h{$a}}) {
   print ref($_), "\n";
}

SOPORTE DE HILOS

Tie::RefHash admite completamente los hilos utilizando el método "CLONE".

SOPORTE STORABLE

Se proporcionan ganchos Storable para una serialización y clonación semánticamente correctas de refhashes enlazados.
