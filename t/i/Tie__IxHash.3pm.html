Tie::IxHash(3) Documentación aportada por el usuario de Perl Tie::IxHash(3)

NOMBRE

Tie::IxHash - arrays asociativos ordenados para Perl

SINOPSIS

# uso simple
use Tie::IxHash;
tie HASHVARIABLE, 'Tie::IxHash' [, LISTA];
# Interfaz OO con características más potentes
use Tie::IxHash;
TIEOBJECT = Tie::IxHash->new( [LISTA] );
TIEOBJECT->Splice( OFFSET [, LONGITUD [, LISTA]] );
TIEOBJECT->Push( LISTA );
TIEOBJECT->Pop;
TIEOBJECT->Shift;
TIEOBJECT->Unshift( LISTA );
TIEOBJECT->Keys( [LISTA] );
TIEOBJECT->Values( [LISTA] );
TIEOBJECT->Indices( LISTA );
TIEOBJECT->Delete( [LISTA] );
TIEOBJECT->Replace( OFFSET, VALOR, [CLAVE] );
TIEOBJECT->Reorder( LISTA );
TIEOBJECT->SortByKey;
TIEOBJECT->SortByValue;
TIEOBJECT->Length;

DESCRIPCIÓN

Este módulo de Perl implementa hashes de Perl que conservan el orden en que se añadieron los elementos del hash. El orden no se ve afectado cuando se cambian los valores correspondientes a claves existentes en el IxHash. Los elementos también pueden establecerse en cualquier orden arbitrario suministrado. Las operaciones familiares de array de Perl también se pueden realizar en el IxHash.

Interfaz Estándar "TIEHASH"

El mecanismo estándar "TIEHASH" está disponible. Se recomienda esta interfaz para usos simples, ya que el uso es exactamente el mismo que el de los hashes normales de Perl después de que se declara el "tie".

Interfaz de Objeto

Este módulo también proporciona una interfaz orientada a objetos extendida que puede usarse para operaciones más potentes con el IxHash. Los siguientes métodos están disponibles:

FETCH, STORE, DELETE, EXISTS
Estos métodos estándar de "TIEHASH" obligatorios por Perl se pueden usar directamente. Consulte la entrada "tie" en perlfunc(1) para obtener detalles.
Push, Pop, Shift, Unshift, Splice
Estos métodos adicionales que se asemejan a las funciones de Perl están disponibles para operar en pares clave-valor en el IxHash. El comportamiento es el mismo que el de las funciones correspondientes de Perl, excepto cuando una clave de hash suministrada ya existe en el hash. En ese caso, el valor existente se actualiza pero su orden no se ve afectado. Para alterar incondicionalmente el orden de un par clave-valor suministrado, primero "DELETE" el elemento del IxHash.
Keys
Devuelve un array de claves de elementos del IxHash correspondientes a la lista de índices suministrados. Devuelve un array de todas las claves si se llama sin argumentos. Tenga en cuenta que el valor de retorno es útil principalmente cuando se utiliza en un contexto de lista (ya que Perl lo convertirá al número de elementos del array en un contexto escalar, y eso puede no ser muy útil).

Si se proporciona un solo argumento, devuelve la única clave correspondiente al índice. Esto es usable tanto en contexto escalar como de lista.

Values
Devuelve un array de valores de elementos del IxHash correspondientes a la lista de índices suministrados. Devuelve un array de todos los valores si se llama sin argumentos. Tenga en cuenta que el valor de retorno es útil principalmente cuando se utiliza en un contexto de lista (ya que Perl lo convertirá al número de elementos del array en un contexto escalar, y eso puede no ser muy útil).

Si se proporciona un solo argumento, devuelve el único valor correspondiente al índice. Esto es usable tanto en contexto escalar como de lista.

Indices
Devuelve un array de índices correspondientes a la lista de claves suministradas. Tenga en cuenta que el valor de retorno es útil principalmente cuando se utiliza en un contexto de lista (ya que Perl lo convertirá al número de elementos del array en un contexto escalar, y eso puede no ser muy útil).

Si se proporciona un solo argumento, devuelve el único índice correspondiente a la clave. Esto es usable tanto en contexto escalar como de lista.

Delete
Elimina los elementos con las claves suministradas del IxHash.
Replace
Sustituye el elemento del IxHash en el índice especificado con el par valor-clave suministrado. Si no se suministra una clave, simplemente sustituye el valor en el índice con el valor suministrado. Si ya existe un elemento con la clave suministrada, se eliminará primero del IxHash.
Reorder
Este método se puede utilizar para manipular el orden interno de los elementos del IxHash proporcionando una lista de claves en el orden deseado. Tenga en cuenta, sin embargo, que cualquier elemento del IxHash cuyas claves no estén en la lista se eliminará del IxHash.
Length
Devuelve el número de elementos del IxHash.
SortByKey
Reordena los elementos del IxHash por comparación textual de las claves.
SortByValue
Reordena los elementos del IxHash por comparación textual de los valores.
Clear
Restablece el IxHash a su estado original: sin elementos en absoluto.

EJEMPLO

use Tie::IxHash;
# interfaz simple
$t = tie(%myhash, 'Tie::IxHash', 'a' => 1, 'b' => 2);
%myhash = (first => 1, second => 2, third => 3);
$myhash{fourth} = 4;
@keys = keys %myhash;
@values = values %myhash;
print("y") if exists $myhash{third};
# interfaz OO
$t = Tie::IxHash->new(first => 1, second => 2, third => 3);
$t->Push(fourth => 4); # lo mismo que $myhash{'fourth'} = 4;
($k, $v) = $t->Pop;    # $k es 'fourth', $v es 4
$t->Unshift(neg => -1, zeroth => 0); 
($k, $v) = $t->Shift;  # $k es 'neg', $v es -1
@oneandtwo = $t->Splice(1, 2, foo => 100, bar => 101);
@keys = $t->Keys;
@values = $t->Values;
@indices = $t->Indices('foo', 'zeroth');
@itemkeys = $t->Keys(@indices);
@itemvals = $t->Values(@indices);
$t->Replace(2, 0.3, 'other');
$t->Delete('second', 'zeroth');
$len = $t->Length;     # número de pares clave-valor
$t->Reorder(reverse @keys);
$t->SortByKey;
$t->SortByValue;

ERRORES

No se puede especificar una longitud negativa a "Splice". Sin embargo, los índices negativos están permitidos.

NOTA

La indexación siempre comienza en 0 (a pesar de la configuración actual de $[) para todas las funciones.

PENDIENTE

La adición de elementos con claves que ya existen al final del IxHash debe controlarse mediante un interruptor.

Proporcionar la interfaz "TIEARRAY" cuando se estabilice en Perl.

Reescribir usando XSUBs para eficiencia.
