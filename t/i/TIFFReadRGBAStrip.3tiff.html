TIFFREADRGBASTRIP(3tiff) LibTIFF TIFFREADRGBASTRIP(3tiff)

NOMBRE

TIFFReadRGBAStrip - lee y decodifica una tira de imagen en un ráster de formato fijo

SINOPSIS

#include <tiffio.h>
int TIFFReadRGBAStrip(TIFF *tif, uint32_t fila, uint32_t *raster)
int TIFFReadRGBAStripExt(TIFF *tif, uint32_t fila, uint32_t *raster, int detener_en_error)

DESCRIPCIÓN

TIFFReadRGBAStrip() lee una única tira de una imagen basada en tiras en memoria, almacenando el resultado en el raster RGBA suministrado por el usuario. Se asume que el ráster es un array de entradas de 32 bits de **ImageWidth** × **RowsPerStrip**, donde **ImageWidth** es el ancho de la imagen (TIFFTAG_IMAGEWIDTH) y **RowsPerStrip** son las líneas máximas en una tira (TIFFTAG_ROWSPERSTRIP).

TIFFReadRGBAStripExt() proporciona el parámetro detener_en_error. Su comportamiento se describe en TIFFReadRGBAImage.

El valor fila debe ser la fila de la primera fila en la tira (tira × **RowsPerStrip**, basada en cero).

Tenga en cuenta que se asume que el ráster está organizado de tal manera que el píxel en la ubicación (x, y) es raster [ y × ancho + x ]; con el origen del ráster en la **esquina inferior izquierda** de la tira. Es decir, organización de abajo hacia arriba. Al leer una tira final parcial en el archivo, la última línea de la imagen comenzará al principio del búfer.

Los píxeles del ráster son muestras rojas, verdes, azules y alfa empaquetadas de 8 bits. Se deben usar las macros TIFFGetR, TIFFGetG, TIFFGetB y TIFFGetA para acceder a muestras individuales. Las imágenes sin información de mateo Alfa asociado tienen un Alfa constante de 1.0 (255).

Consulte la página TIFFRGBAImage para obtener más detalles sobre cómo se convierten varios tipos de imágenes en valores RGBA.

NOTAS

Las muestras deben tener 1, 2, 4, 8 o 16 bits. Las muestras/píxel colorimétricas deben ser 1, 3 o 4 (es decir, **SamplesPerPixel** - **ExtraSamples**).

Los mapas de color de imágenes de paleta que parecen estar escritos incorrectamente como valores de 8 bits se escalan automáticamente a 16 bits.

TIFFReadRGBAStrip() es solo un envoltorio alrededor de las instalaciones más generales de TIFFRGBAImage. Su principal ventaja sobre la función similar TIFFReadRGBAImage() es que para imágenes grandes no es necesario asignar un único búfer capaz de contener toda la imagen, solo lo suficiente para una tira. La función TIFFReadRGBATile() realiza una operación similar para imágenes con teselas.

VALORES DE RETORNO

Se devuelve 1 si la imagen se leyó y convirtió correctamente. De lo contrario, se devuelve 0 si se encontró un error.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

"Lo siento, no puedo manejar imágenes de %d bits":

La imagen tenía BitsPerSample distinto de 1, 2, 4, 8 o 16.

"Lo siento, no puedo manejar imágenes de %d canales":

La imagen tenía SamplesPerPixel distinto de 1, 3 o 4.

Falta la etiqueta requerida "PhotometricInterpretation":

La imagen no tenía una etiqueta que describiera cómo mostrar los datos.

No hay etiqueta "PhotometricInterpretation", asumiendo RGB:

A la imagen le faltaba una etiqueta que describiera cómo mostrarla, pero como tiene 3 o 4 muestras/píxel, se asume que es RGB.

No hay etiqueta "PhotometricInterpretation", asumiendo min-is-black:

A la imagen le faltaba una etiqueta que describiera cómo mostrarla, pero como tiene 1 muestra/píxel, se asume que es una imagen en escala de grises o de dos niveles.

"No hay espacio para la tabla de conversión fotométrica":

No hubo suficiente memoria para una tabla utilizada para convertir muestras de imagen a RGB de 8 bits.

Falta la etiqueta requerida "Colormap":

Una imagen de paleta no tenía una etiqueta Colormap requerida.

"No hay espacio para el búfer de teselas":

No hubo suficiente memoria para asignar un búfer de E/S.

"No hay espacio para el búfer de tiras":

No hubo suficiente memoria para asignar un búfer de E/S.

"No se puede manejar el formato":

La imagen tiene un formato (combinación de BitsPerSample, SamplesPerPixel y PhotometricInterpretation) que TIFFReadRGBAImage() no puede manejar.

"No hay espacio para la tabla de mapeo B&N":

No hubo suficiente memoria para asignar una tabla utilizada para mapear datos en escala de grises a RGB.

"No hay espacio para la tabla de mapeo de paleta":

No hubo suficiente memoria para asignar una tabla utilizada para mapear datos a RGB de 8 bits.
