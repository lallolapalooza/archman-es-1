TIOCCONS(2const) TIOCCONS(2const)

NOMBRE

TIOCCONS - redirigir la salida de la consola

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de TIOCCONS */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCCONS);

DESCRIPCIÓN

Redirige la salida que normalmente iría a /dev/console o /dev/tty0 al terminal dado. Si este fuera el maestro de un pseudoterminal, envíala al esclavo.

Solo un proceso con la capacidad CAP_SYS_ADMIN puede hacer esto.

Si la salida ya estaba redirigida, se devuelve EBUSY, pero la redirección se puede detener usando esta llamada ioctl con fd apuntando a /dev/console o /dev/tty0.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EBUSY
La salida ya estaba redirigida.
EPERM
Permisos insuficientes.

HISTORIAL

Antes de Linux 2.6.10, cualquiera podía hacer esto siempre que la salida no estuviera redirigida todavía; CAP_SYS_ADMIN no era necesario.

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
