TIFFSIZE(3tiff) LibTIFF TIFFSIZE(3tiff)

NOMBRE

TIFFsize - devuelve el tamaño de varios elementos asociados con un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
tsize_t TIFFRasterScanlineSize(TIFF *tif)
uint64_t TIFFRasterScanlineSize64(TIFF *tif)
tsize_t TIFFScanlineSize(TIFF *tif)
uint64_t TIFFScanlineSize64(TIFF *tif)

DESCRIPCIÓN

TIFFScanlineSize() devuelve el tamaño en bytes de una fila de datos tal como se devolvería en una llamada a TIFFReadScanline(), o como se esperaría en una llamada a TIFFWriteScanline(). Tenga en cuenta que este número puede ser 1/samples-per-pixel si los datos se almacenan como planos separados. El ScanlineSize en caso de YCbCrSubsampling se define como el tamaño de tira dividido por la altura de tira, es decir, el tamaño de un paquete de líneas de submuestreo vertical dividido por el submuestreo vertical. Por lo tanto, debería tener sentido cuando se multiplica por un múltiplo del submuestreo vertical. TIFFScanlineSize64() devuelve el tamaño como uint64_t.

TIFFRasterScanlineSize() devuelve el tamaño en bytes de una línea de escaneo de ráster completa, decodificada y empaquetada. Tenga en cuenta que este valor puede ser diferente del valor devuelto por TIFFScanlineSize() si los datos se almacenan como planos separados. TIFFRasterScanlineSize64() devuelve el tamaño como uint64_t.
