Time::localtime(3perl) Guía de referencia para programadores de Perl Time::localtime(3perl)

NOMBRE

Time::localtime - Interfaz por nombre a la función incorporada localtime() de Perl

SINOPSIS

use Time::localtime;
printf "El año es %d\n", localtime->year() + 1900;
$ahora = ctime();
use Time::localtime;
use File::stat;
$cadena_fecha = ctime(stat($archivo)->mtime);

DESCRIPCIÓN

Por defecto, este módulo anula la función incorporada localtime(), reemplazándola por una versión que devuelve objetos "Time::tm". Este objeto tiene métodos que devuelven el nombre del campo de estructura similar de la estructura tm de C de time.h; a saber: sec, min, hour, mday, mon, year, wday, yday, e isdst.

También puede importar todos los campos de la estructura directamente a su espacio de nombres como variables normales usando la etiqueta de importación :FIELDS. (Tenga en cuenta que esto todavía anula sus funciones principales.) Acceda a estos campos como variables con un prefijo "tm_" delante de sus nombres de método. Por lo tanto, "$tm_obj->mday()" corresponde a $tm_mday si importa los campos.

La función ctime() proporciona una forma de acceder al sentido escalar de la función original CORE::localtime().

Para acceder a esta funcionalidad sin las anulaciones principales, pase a la "use" una lista de importación vacía, y luego acceda a las funciones principales con sus nombres completos calificados. Por otro lado, las funciones incorporadas todavía están disponibles a través del pseudopaquete "CORE::".

NOTA

Aunque esta clase se implementa actualmente utilizando el módulo Class::Struct para construir una clase similar a una estructura, no debe confiar en esto.
