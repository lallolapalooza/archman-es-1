TIFFREADRGBAIMAGE(3tiff) LibTIFF TIFFREADRGBAIMAGE(3tiff)

NOMBRE

TIFFReadRGBAImage - lee y decodifica una imagen en un raster de formato fijo

SINOPSIS

#include <tiffio.h>
TIFFGetR(abgr)
((abgr)&0xff)
TIFFGetG(abgr)
(((abgr) >> 8) & 0xff)
TIFFGetB(abgr)
(((abgr) >> 16) & 0xff)
TIFFGetA(abgr)
(((abgr) >> 24) & 0xff)
int TIFFReadRGBAImage(TIFF *tif, uint32_t width, uint32_t height, uint32_t *raster, int stopOnError)
int TIFFReadRGBAImageOriented(TIFF *tif, uint32_t width, uint32_t height, uint32_t *raster, int orientation, int stopOnError)

DESCRIPCIÓN

TIFFReadRGBAImage() lee una imagen basada en tiras o teselas en memoria, almacenando el resultado en el raster proporcionado por el usuario. Se asume que el raster es un array de entradas de 32 bits de width x height, donde width debe ser menor o igual al ancho de la imagen (height puede ser cualquier tamaño no nulo). Si las dimensiones del raster son menores que las de la imagen, los datos de la imagen se recortan a los límites del raster. Si la altura del raster es mayor que la de la imagen, los datos de la imagen se colocan en la parte inferior del raster. (Tenga en cuenta que se asume que el raster está organizado de manera que el píxel en la ubicación (x, y) es raster [ y x width + x ]; con el origen del raster en la esquina inferior izquierda).

TIFFReadRGBAImageOriented() funciona como TIFFReadRGBAImage() excepto que el usuario puede especificar la posición del origen del raster con el parámetro orientation. Se admiten cuatro orientaciones:

  • ORIENTATION_TOPLEFT: origen en la esquina superior izquierda,
  • ORIENTATION_TOPRIGHT: origen en la esquina superior derecha,
  • ORIENTATION_BOTLEFT: origen en la esquina inferior izquierda
  • ORIENTATION_BOTRIGHT: origen en la esquina inferior derecha.

Si elige ORIENTATION_BOTLEFT, el resultado será el mismo que el devuelto por TIFFReadRGBAImage().

Los píxeles del raster son muestras de rojo, verde, azul y alfa empaquetadas en 8 bits. Se deben usar las macros TIFFGetR, TIFFGetG, TIFFGetB y TIFFGetA para acceder a las muestras individuales. Las imágenes sin información de mateado alfa asociado tienen un Alfa constante de 1.0 (255).

TIFFReadRGBAImage() convierte imágenes que no son de 8 bits escalando los valores de las muestras. Las imágenes de paleta, escala de grises, bilevel, CMYK y YCbCr se convierten a RGB de forma transparente. Los píxeles del raster se devuelven sin corregir por ninguna información de colorimetría presente en el directorio.

El parámetro stopOnError especifica cómo actuar si se encuentra un error al leer la imagen. Si stopOnError no es cero, un error terminará la operación; de lo contrario, TIFFReadRGBAImage() continuará procesando datos hasta que se soliciten todos los datos posibles de la imagen.

NOTAS

En C++ el parámetro stopOnError tiene un valor predeterminado de 0.

SamplesPerPixel debe ser de 1, 2, 4, 8 o 16 bits. Las muestras/píxel colorimétricas deben ser de 1, 3 o 4 (es decir, SamplesPerPixel menos ExtraSamples).

Los mapas de color de imágenes de paleta que parecen estar escritos incorrectamente como valores de 8 bits se escalan automáticamente a 16 bits.

IFFReadRGBAImage() es solo un envoltorio para las instalaciones más generales de TIFFRGBAImage.

VALORES DE RETORNO

Se devuelve 1 si la imagen se leyó y convirtió correctamente. De lo contrario, se devuelve 0 si se encontró un error y stopOnError es cero.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

"Lo sentimos, no podemos manejar imágenes de %d bits":

La imagen tenía BitsPerSample distinto de 1, 2, 4, 8 o 16.

"Lo sentimos, no podemos manejar imágenes de %d canales":

La imagen tenía SamplesPerPixel distinto de 1, 3 o 4.

Falta la etiqueta necesaria "PhotometricInterpretation":

La imagen no tenía una etiqueta que describiera cómo mostrar los datos.

No hay etiqueta "PhotometricInterpretation", asumiendo RGB:

La imagen carecía de una etiqueta que describiera cómo mostrarla, pero como tiene 3 o 4 muestras/píxel, se asume que es RGB.

No hay etiqueta "PhotometricInterpretation", asumiendo min-es-negro:

La imagen carecía de una etiqueta que describiera cómo mostrarla, pero como tiene 1 muestra/píxel, se asume que es una imagen en escala de grises o bilevel.

"No hay espacio para la tabla de conversión fotométrica":

No había suficiente memoria para una tabla utilizada para convertir las muestras de la imagen a RGB de 8 bits.

Falta la etiqueta requerida "Colormap":

Una imagen de paleta no tenía una etiqueta Colormap requerida.

"No hay espacio para el búfer de teselas":

No había suficiente memoria para asignar un búfer de E/S.

"No hay espacio para el búfer de tiras":

No había suficiente memoria para asignar un búfer de E/S.

"No se puede manejar el formato":

La imagen tiene un formato (combinación de BitsPerSample, SamplesPerPixel y PhotometricInterpretation) que TIFFReadRGBAImage() no puede manejar.

"No hay espacio para la tabla de mapeo B&N":

No había suficiente memoria para asignar una tabla utilizada para mapear datos en escala de grises a RGB.

"No hay espacio para la tabla de mapeo de paleta":

No había suficiente memoria para asignar una tabla utilizada para mapear datos a RGB de 8 bits.

Description

TIFFReadRGBAImage lee una imagen TIFF y la convierte a formato RGBA. La imagen se amplía o se reduce según sea necesario para que quepa en el búfer de píxeles de destino. El formato RGBA utiliza 8 bits por canal para Rojo, Verde, Azul y Alfa. Cada píxel se representa como un valor de 32 bits sin signo (uint32_t). Los componentes de color se almacenan en orden de bytes de red (big-endian) como (R G B A).

Si stoponfirst se establece en 1, la función se detendrá en la primera imagen que encuentre y devolverá el número de imágenes procesadas. Si se establece en 0, leerá todas las imágenes y devolverá el número total de imágenes leídas.

El parámetro bytesrotated es un puntero a un entero que recibirá la cantidad de bytes que se han rotado en la imagen (si procede). Esto es útil para imágenes que están orientadas incorrectamente.

Notes

Esta función es una conveniencia de alto nivel para leer imágenes TIFF y convertirlas a un formato común. Para un control más detallado sobre la lectura de imágenes, considera usar las funciones de bajo nivel de la biblioteca libtiff.

Return Values

TIFFReadRGBAImage devuelve 1 si la operación fue exitosa, y 0 en caso de error. En caso de error, se puede usar TIFFError para obtener más información sobre el problema.

Diagnostics

Los errores comunes incluyen archivos TIFF mal formados, memoria insuficiente y problemas de permisos de archivo.
