TIFFMEMORY(3tiff) LibTIFF TIFFMEMORY(3tiff)

NOMBRE

TIFFmemory - funciones relacionadas con la gestión de memoria para su uso con archivos TIFF

SINOPSIS

#include <tiffio.h>
tdata_t _TIFFmalloc(tsize_t size)
tdata_t _TIFFrealloc(tdata_t buffer, tsize_t size)
void _TIFFfree(tdata_t buffer)
void _TIFFmemset(tdata_t s, int c, tsize_t n)
void _TIFFmemcpy(tdata_t dest, const tdata_t src, tsize_t n)
int _TIFFmemcmp(const tdata_t s1, const tdata_ts2, tsize_t n)
void *_TIFFCheckMalloc(TIFF *tif, tmsize_t nmemb, tmsize_t elem_size, const char *what)
void *_TIFFCheckRealloc(TIFF *tif, void *buffer, tmsize_t nmemb, tmsize_t elem_size, const char *what)

DESCRIPCIÓN

Estas rutinas se proporcionan para escribir software portátil que utiliza libtiff; ocultan cualquier problema relacionado con la gestión de memoria, como el manejo de arquitecturas segmentadas que se encuentran en máquinas de 16 bits.

_TIFFmalloc() y _TIFFrealloc() se utilizan para asignar y reasignar dinámicamente memoria utilizada por libtiff; como la memoria pasada a las rutinas de E/S. La memoria asignada a través de estas interfaces se libera al sistema utilizando la rutina _TIFFfree().

La memoria asignada a través de una de las interfaces anteriores se puede establecer en un valor conocido utilizando _TIFFmemset(), copiar a otra ubicación de memoria utilizando _TIFFmemcpy() o comparar su igualdad utilizando _TIFFmemcmp(). Estas rutinas se ajustan a las rutinas C equivalentes: memset(), memcpy(), memcmp(), respectivamente.

_TIFFCheckMalloc() y _TIFFCheckRealloc() están comprobando el desbordamiento de enteros antes de llamar a _TIFFmalloc() y _TIFFrealloc(), respectivamente.
