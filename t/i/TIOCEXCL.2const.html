TIOCEXCL(2const) TIOCEXCL(2const)

NOMBRE

TIOCEXCL, TIOCGEXCL, TIOCNXCL - modo exclusivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de las constantes TIOC*XCL */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCEXCL);
int ioctl(int fd, TIOCGEXCL, int *argp);
int ioctl(int fd, TIOCNXCL);

DESCRIPCIÓN

TIOCEXCL
Pone la terminal en modo exclusivo. No se permiten más operaciones de open(2) en la terminal. (Fallan con EBUSY, excepto para un proceso con la capacidad CAP_SYS_ADMIN).
TIOCGEXCL
Si la terminal está actualmente en modo exclusivo, coloca un valor distinto de cero en la ubicación apuntada por argp; de lo contrario, coloca cero en *argp.
TIOCNXCL
Deshabilita el modo exclusivo.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

HISTORIAL

TIOCGEXCL
Linux 3.8.

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
