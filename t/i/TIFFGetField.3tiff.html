NOMBRE

TIFFGetField - obtener el valor(es) de una etiqueta en un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
#include <stdarg.h>
int TIFFGetField(TIFF *tif, ttag_t tag, ...)
int TIFFVGetField(TIFF *tif, ttag_t tag, va_list ap)
int TIFFGetFieldDefaulted(TIFF *tif, ttag_t tag, ...)
int TIFFVGetFieldDefaulted(TIFF *tif, ttag_t tag, va_list ap)

DESCRIPCIÓN

TIFFGetField() devuelve el valor de una etiqueta o pseudo-etiqueta asociada con el directorio actual del archivo TIFF abierto tif. (Una pseudo-etiqueta es un parámetro que se utiliza para controlar el funcionamiento de la biblioteca TIFF pero cuyo valor no se lee ni se escribe en el archivo subyacente.) El archivo debe haber sido abierto previamente con TIFFOpen(). La etiqueta se identifica por tag, uno de los valores definidos en el archivo de inclusión tiff.h (ver también la tabla a continuación). El tipo y número de valores devueltos dependen de la etiqueta solicitada. La interfaz de programación utiliza una lista de argumentos variables según lo prescrito por la interfaz stdarg.h. Los valores devueltos solo deben interpretarse si TIFFGetField() devuelve 1.

TIFFVGetField() es funcionalmente equivalente a TIFFGetField() excepto que toma un puntero a una lista de argumentos variables. TIFFVGetField() es útil para superponer interfaces sobre la funcionalidad proporcionada por TIFFGetField().

TIFFGetFieldDefaulted() y TIFFVGetFieldDefaulted() son idénticas a TIFFGetField() y TIFFVGetField(), respectivamente, excepto que si una etiqueta no está definida en el directorio actual y tiene un valor predeterminado, se devuelve ese valor predeterminado.

Las etiquetas comprendidas por libtiff, el número de valores de parámetro y los tipos para los valores devueltos se muestran a continuación. Los tipos de datos se especifican como en C y corresponden a los tipos utilizados para especificar valores de etiqueta a TIFFSetField(). Recuerde que TIFFGetField() devuelve valores de parámetro, por lo que todos los tipos de datos listados son punteros al almacenamiento donde se deben devolver los valores. Consulte la especificación TIFF (o la especificación industrial relevante) para obtener información sobre el significado de cada etiqueta y sus posibles valores.

AUTOREGISTERED TAGS

If you can’t find the tag in the table above that means this is an unsupported tag and is not directly supported by the libtiff library. You will still be able to read it’s value if you know the data type of that tag. For example, if you want to read the LONG value from the tag 33424 and ASCII string from the tag 36867 you can use the following code:

uint32_t  count;
void    *data;
TIFFGetField(tiff, 33424, &count, &data);
printf("Tag %d: %d, count %d\n", 33424, *(uint32_t *)data, count);
TIFFGetField(tiff, 36867, &count, &data);
printf("Tag %d: %s, count %d\n", 36867, (char *)data, count);

RETURN VALUES

1 is returned if the tag is defined in the current directory; otherwise a 0 is returned.

DIAGNOSTICS

All error messages are directed to the TIFFErrorExtR() routine.

Unknown field, tag 0x%x:

An unknown tag was supplied.
