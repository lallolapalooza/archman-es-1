NOMBRE

TIFFbuffer - Rutinas de control de búfer de E/S

SINOPSIS

#include <tiffio.h>
int TIFFReadBufferSetup(TIFF *tif, tdata_t buffer, tsize_t size)
int TIFFWriteBufferSetup(TIFF *tif, tdata_t buffer, tsize_t size)

DESCRIPCIÓN

Las siguientes rutinas se proporcionan para el control del cliente de los búferes de E/S utilizados por la biblioteca. Las aplicaciones nunca necesitan usar estas rutinas; solo se proporcionan para clientes "inteligentes" que desean optimizar el uso de la memoria y/o eliminar posibles operaciones de copia que pueden ocurrir al trabajar con imágenes que tienen datos almacenados sin compresión.

TIFFReadBufferSetup() configura el búfer de datos utilizado para leer datos sin procesar (codificados) de un archivo. Si el puntero especificado es NULL (cero), se asigna un búfer del tamaño apropiado. De lo contrario, el llamador debe garantizar que el búfer sea lo suficientemente grande como para contener cualquier tira de datos sin procesar individual. TIFFReadBufferSetup() devuelve un valor distinto de cero si la configuración fue exitosa y cero en caso contrario.

TIFFWriteBufferSetup() configura el búfer de datos utilizado para escribir datos sin procesar (codificados) en un archivo. Si el tamaño especificado es -1, el tamaño del búfer se selecciona para contener un mosaico o tira completa, o al menos 8 kilobytes, lo que sea mayor. Si el búfer especificado es NULL (cero), se asigna dinámicamente un búfer del tamaño apropiado. TIFFWriteBufferSetup() devuelve un valor distinto de cero si la configuración fue exitosa y cero en caso contrario.

DIAGNÓSTICOS

%s: No hay espacio para el búfer de datos en la línea de escaneo %ld:

TIFFReadBufferSetup() no pudo asignar dinámicamente espacio para un búfer de datos.

%s: No hay espacio para el búfer de salida:

TIFFWriteBufferSetup() no pudo asignar dinámicamente espacio para un búfer de datos.
