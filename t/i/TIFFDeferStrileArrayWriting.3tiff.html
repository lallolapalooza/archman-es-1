NOMBRE

TIFFDeferStrileArrayWriting - posponer escritura de arreglos de strile

SINOPSIS

#include <tiffio.h>
int TIFFDeferStrileArrayWriting(TIFF *tif)
int TIFFForceStrileArrayWriting(TIFF *tif)

DESCRIPCIÓN

TIFFDeferStrileArrayWriting() es una función de escritura avanzada que debe usarse en una secuencia particular, y generalmente junto con TIFFForceStrileArrayWriting(), para lograr su efecto deseado. Su objetivo es controlar cuándo y dónde se escriben los arreglos StripOffsets / StripByteCounts o TileOffsets / TileByteCounts en el archivo.

El propósito de esto es generar archivos 'cloud-optimized geotiff' donde el primer KB del archivo solo contenga las entradas IFD sin los arreglos de strile potencialmente grandes. Estos se escriben posteriormente.

Más precisamente, cuando se llama a TIFFWriteCheck(), las entradas de etiqueta para esos arreglos se escribirán con tipo = conteo = desplazamiento = 0 como un valor temporal.

Su efecto solo es válido para el directorio actual, y antes de que se llame a TIFFWriteDirectory() por primera vez, y se restablecerá al cambiar de directorio.

La secuencia típica de llamadas es:

TIFFOpen()
/* o TIFFCreateDirectory(tif) */
/* Establecer campos con llamadas a TIFFSetField(tif, ...) */
TIFFDeferStrileArrayWriting(tif)
TIFFWriteCheck(tif, ...)
TIFFWriteDirectory(tif)
/* ... potencialmente crear otros directorios y volver al directorio anterior */
TIFFForceStrileArrayWriting(tif) /* emitir los arreglos al final del archivo */

RETORNOS

1 en caso de éxito, 0 en caso contrario.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR(). De manera similar, los mensajes de advertencia se dirigen a la rutina TIFFWarningExtR().
