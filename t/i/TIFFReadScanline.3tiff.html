TIFFREADSCANLINE(3tiff) LibTIFF TIFFREADSCANLINE(3tiff)

NOMBRE

TIFFReadScanline - lee y decodifica una línea de escaneo de datos de un archivo TIFF abierto

SINOPSIS

#include <tiffio.h>
int TIFFReadScanline(TIFF *tif, tdata_t buf, uint32_t row, tsample_t sample)

DESCRIPCIÓN

Lee los datos de la fila especificada en el búfer de datos (proporcionado por el usuario) buf. Los datos se devuelven descomprimidos y en el orden de bytes y bits nativo, pero de lo contrario están empaquetados (ver más abajo). El búfer debe ser lo suficientemente grande como para contener una línea de escaneo completa de datos. Las aplicaciones deben llamar a la rutina TIFFScanlineSize() para conocer el tamaño (en bytes) de un búfer de línea de escaneo. El parámetro row siempre lo utiliza TIFFReadScanline(); el parámetro sample solo se utiliza si los datos están organizados en planos separados (PlanarConfiguration = 2).

NOTAS

La biblioteca intenta ocultar las diferencias de orden de bits y bytes entre la imagen y la máquina nativa convirtiendo los datos al orden de la máquina nativa. La inversión de bits se realiza si la etiqueta FillOrder es opuesta al orden de bits de la máquina nativa. Las muestras de 16 y 32 bits se intercambian automáticamente de bytes si el archivo se escribió con un orden de bytes opuesto al orden de bytes de la máquina nativa.

En C++, el parámetro sample tiene un valor predeterminado de 0.

VALORES DE RETORNO

TIFFReadScanline() devuelve -1 si detecta un error; de lo contrario, devuelve 1.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().

"El algoritmo de compresión no admite acceso aleatorio":

Se solicitaron datos en un orden no secuencial de un archivo que utiliza un algoritmo de compresión y que tiene RowsPerStrip mayor que uno. Es decir, los datos de la imagen se almacenan en forma comprimida, y con varias filas empaquetadas en una tira. En este caso, la biblioteca no admite acceso aleatorio a los datos. Los datos deben accederse secuencialmente, o el archivo debe convertirse para que cada tira esté compuesta por una fila de datos.

ERRORES

La lectura de datos YCbCr submuestreados no funciona correctamente porque, para PlanarConfiguration = 2, el tamaño de una línea de escaneo no se calcula por muestra, y para PlanarConfiguration = 1, la biblioteca no desempaqueta las muestras entrelazadas por bloques; utilice las interfaces basadas en tiras y teselas para leer estos formatos.
