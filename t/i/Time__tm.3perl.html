Time::tm(3perl) Guía del programador de Perl Time::tm(3perl)

NOMBRE

Time::tm - objeto interno usado por Time::gmtime y Time::localtime

SINOPSIS

No uses este módulo directamente.

DESCRIPCIÓN

Este módulo se usa internamente como clase base para las funciones Time::localtime y Time::gmtime. Crea un objeto struct Time::tm que es accesible al igual que la estructura tm de C de time.h; específicamente con sec, min, hour, mday, mon, year, wday, yday, e isdst.

Esta clase es solo una interfaz interna.
