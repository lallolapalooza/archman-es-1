NOMBRE

TIFFDataWidth - obtener el tamaño de los tipos de datos TIFF

SINOPSIS

#include <tiffio.h>
int TIFFDataWidth(TIFFDataType type)

DESCRIPCIÓN

TIFFDataWidth() devuelve el tamaño de type dentro del archivo TIFF en bytes. Actualmente se soportan los siguientes tipos de datos:

  • TIFF_BYTE
  • TIFF_ASCII
  • TIFF_SBYTE
  • TIFF_UNDEFINED
  • TIFF_SHORT
  • TIFF_SSHORT
  • TIFF_LONG
  • TIFF_SLONG
  • TIFF_FLOAT
  • TIFF_IFD
  • TIFF_RATIONAL
  • TIFF_SRATIONAL
  • TIFF_DOUBLE
  • TIFF_LONG8
  • TIFF_SLONG8
  • TIFF_IFD8

VALORES DEVUELTOS

TIFFDataWidth() devuelve el número de bytes ocupados por el elemento del tipo dado dentro del archivo TIFF. Se devuelve 0 cuando se suministra un tipo de datos desconocido.
