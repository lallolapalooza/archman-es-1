Tie::Cycle(3) Documentación de Perl aportada por el usuario Tie::Cycle(3)

NOMBRE

Tie::Cycle - Cicla a través de una lista de valores mediante un escalar.

SINOPSIS

use v5.10;
use Tie::Cycle;
tie my $cycle, 'Tie::Cycle', [ qw( FFFFFF 000000 FFFF00 ) ];
say $cycle; # FFFFFF
say $cycle; # 000000
say $cycle; # FFFF00
say $cycle; # FFFFFF  vuelve al principio
(tied $cycle)->reset;  # vuelve al principio

DESCRIPCIÓN

"Tie::Cycle" se utiliza para recorrer una lista una y otra vez. Una vez que se llega al final de la lista, se vuelve al principio. No tiene que preocuparse de nada de esto, ya que la magia de tie se encarga de ello.

El tie toma una referencia a un array como tercer argumento. El tie debería tener éxito a menos que el argumento no sea una referencia a un array. Versiones anteriores requerían que se usara un array con más de un elemento (¿cuál es el propósito de buclear de lo contrario?), pero he eliminado esa restricción, ya que el número de elementos que desea usar puede cambiar según la situación.

Durante el tie, este módulo crea una copia superficial de la referencia del array. Si la referencia del array contiene referencias, y esas referencias se cambian después del tie, los elementos del ciclo también cambiarán. Consulte el script test.pl incluido para ver un ejemplo de este efecto.

MÉTODOS DEL OBJETO

Puede llamar a métodos sobre el objeto subyacente (al que accede con tied() ).

reset
Devuelve el iterador a la posición inicial. La siguiente operación de lectura proporcionará el primer elemento de la lista.
previous
Proporciona el elemento anterior. Esto no afecta a la posición actual.
next
Proporciona el siguiente elemento. Esto no afecta a la posición actual. Puede inspeccionar el siguiente elemento si lo desea.
