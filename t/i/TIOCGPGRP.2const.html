TIOCSPGRP(2const) TIOCSPGRP(2const)

NOMBRE

TIOCGPGRP, TIOCSPGRP, TIOCGSID - ID de grupo de procesos y de sesión

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de constantes TIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGPGRP, pid_t *argp);
int ioctl(int fd, TIOCSPGRP, const pid_t *argp);
int ioctl(int fd, TIOCGSID, pid_t *argp);

DESCRIPCIÓN

TIOCGPGRP
Cuando tiene éxito, es equivalente a *argp = tcgetpgrp(fd).
Obtiene el ID del grupo de procesos del grupo de procesos en primer plano en este terminal.
TIOCSPGRP
Equivalente a tcsetpgrp(fd, *argp).
Establece el ID del grupo de procesos en primer plano de este terminal.
TIOCGSID
Cuando tiene éxito, es equivalente a *argp = tcgetsid(fd).
Obtiene el ID de sesión del terminal dado. Falla con el error ENOTTY si el terminal no es un pseudoterminal maestro y no es nuestro terminal de control. Extraño.

VALOR DEVUELTO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

ENOTTY
El terminal no es un pseudoterminal maestro y no es nuestro terminal de control.
EPERM
Permiso insuficiente.

VER TAMBIÉN

ioctl(2), ioctl_tty(2), tcgetpgrp(3), tcsetpgrp(3), tcgetsid(3)
