NOMBRE

TIFFCustomTagList - devuelve información sobre la lista de etiquetas personalizadas

SINOPSIS

#include <tiffio.h>
int TIFFGetTagListCount(TIFF *tif)
uint32_t TIFFGetTagListEntry(TIFF *tif, int tag_index)

DESCRIPCIÓN

TIFFGetTagListCount() devuelve el número de entradas en la lista de etiquetas personalizadas.

TIFFGetTagListEntry() devuelve el número de etiqueta de la (n-ésima - 1) entrada dentro de la lista de etiquetas personalizadas. Si el tag_index es mayor o igual al número de entradas en la lista de etiquetas, se devuelve 0xFFFFFFFF (=(uint32_t(-1)).

NOTA

Las etiquetas conocidas por libtiff se definen como etiquetas 'con nombre' y muchas como etiquetas personalizadas. Las definiciones de etiquetas personalizadas se manejan en una lista interna de etiquetas personalizadas. Esta lista también se puede extender añadiendo definiciones de etiquetas a esa lista, de modo que libtiff conozca esas etiquetas. Ver Definición de Etiquetas de Aplicación
