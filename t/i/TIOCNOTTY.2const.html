TIOCNOTTY(2const) TIOCNOTTY(2const)

NOMBRE

TIOCSCTTY, TIOCNOTTY - controlando la terminal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de las constantes TIOC*TTY */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCSCTTY, int arg);
int ioctl(int fd, TIOCNOTTY);

DESCRIPCIÓN

TIOCSCTTY
Convierte la terminal dada en la terminal de control del proceso que llama. El proceso que llama debe ser un líder de sesión y no tener ya una terminal de control. Para este caso, arg debe especificarse como cero.
Si esta terminal ya es la terminal de control de un grupo de sesión diferente, entonces el ioctl falla con EPERM, a menos que el llamante tenga la capacidad CAP_SYS_ADMIN y arg sea igual a 1, en cuyo caso la terminal es robada, y todos los procesos que la tenían como terminal de control la pierden.
TIOCNOTTY
Si la terminal dada era la terminal de control del proceso que llama, renuncia a esta terminal de control. Si el proceso era líder de sesión, entonces envía SIGHUP y SIGCONT al grupo de procesos en primer plano y todos los procesos de la sesión actual pierden su terminal de control.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EPERM
Permiso insuficiente.

VER TAMBIÉN

ioctl(2), ioctl_tty(2)
