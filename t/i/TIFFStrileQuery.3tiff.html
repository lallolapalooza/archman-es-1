TIFFSTRILEQUERY(3tiff) LibTIFF TIFFSTRILEQUERY(3tiff)

NOMBRE

TIFFStrileQuery - obtener el recuento de bytes y el desplazamiento de las franjas

SINOPSIS

#include <tiffio.h>
uint64_t TIFFGetStrileByteCount(TIFF *tif, uint32_t strile);
uint64_t TIFFGetStrileOffset(TIFF *tif, uint32_t strile);
uint64_t TIFFGetStrileByteCountWithErr(TIFF *tif, uint32_t strile, int *pbErr);
uint64_t TIFFGetStrileOffsetWithErr(TIFF *tif, uint32_t strile, int *pbErr);

DESCRIPCIÓN

Hacer que la carga diferida de los desplazamientos/recuentos de bytes de las franjas esté disponible en tiempo de ejecución y añadir capacidades de carga de desplazamientos/recuentos de bytes por franja. Parte de este commit hace que el comportamiento que se cumplía anteriormente cuando libtiff se compilaba con -DDEFER_STRILE_LOAD esté disponible para las compilaciones por defecto.

Al especificar el nuevo flag D (Deferred - Diferido) de TIFFOpen(), la carga del desplazamiento/recuento de bytes de las franjas se difiere. En ese modo, los arrays StripOffsets / StripByteCounts o TileOffsets / TileByteCounts solo se cargan cuando se accede a ellos por primera vez. Esto puede acelerar la apertura de archivos almacenados en red cuando solo se necesita la recuperación de metadatos.

Otra adición es la capacidad de cargar solo los valores del desplazamiento/recuento de bytes de la franja de interés en lugar de todo el array. Esto se habilita con el nuevo flag O (Ondemand - Bajo demanda) de TIFFOpen() (que implica D).

Se han añadido las funciones públicas TIFFGetStrileOffset(), TIFFGetStrileOffsetWithErr(), TIFFGetStrileByteCount() y TIFFGetStrileByteCountWithErr() a la API. Son de particular interés cuando se utilizan archivos dispersos (con offset == bytecount == 0) y se desea detectar si una franja está presente o no sin descomprimir los datos, o actualizar un archivo disperso existente.

TIFFGetStrileByteCount() devuelve el valor del array TileByteCounts / StripByteCounts para la tesela/franja especificada.

TIFFGetStrileByteCountWithErr() proporciona además pbErr como un puntero int a una variable de retorno de error, que se establece en "0" para un retorno exitoso o en "1" para un retorno de error.

TIFFGetStrileOffset() devuelve el valor del array TileOffsets / StripOffsets para la tesela/franja especificada.

TIFFGetStrileOffsetWithErr() proporciona además pbErr como un puntero int a una variable de retorno de error, que se establece en "0" para un retorno exitoso o en "1" para un retorno de error.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR(). Asimismo, los mensajes de advertencia se dirigen a la rutina TIFFWarningExtR().
