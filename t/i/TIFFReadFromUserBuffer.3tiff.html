NOMBRE

TIFFReadFromUserBuffer - decodifica datos usando un búfer definido por el usuario

SINOPSIS

#include <tiffio.h>
int TIFFReadFromUserBuffer(TIFF *tif, uint32_t strile, void *inbuf, tmsize_t insize, void *outbuf, tmsize_t outsize)

DESCRIPCIÓN

Utiliza el búfer de entrada proporcionado (inbuf, insize) y lo descomprime en (outbuf, outsize). Esta función reemplaza el uso de TIFFReadEncodedStrip() / TIFFReadEncodedTile() cuando el usuario puede proporcionar el búfer para los datos de entrada, por ejemplo, cuando desea evitar que libtiff lea los valores de desplazamiento/conteo de strile de las matrices StripOffsets / StripByteCounts o TileOffsets / TileByteCounts. El contenido de inbuf debe ser escribible (si se necesita inversión de bits).

VALORES DE RETORNO

Devuelve 1 en caso de éxito, 0 en caso contrario.

DIAGNÓSTICOS

Todos los mensajes de error se dirigen a la rutina TIFFErrorExtR().
