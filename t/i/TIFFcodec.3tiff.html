DESCRIPCIÓN

libtiff soporta una variedad de esquemas de compresión implementados por codecs de software. Cada codec se adhiere a una interfaz modular que proporciona la decodificación y codificación de datos de imagen; así como otros métodos para inicialización, configuración, limpieza y control de tamaños de tira y teja predeterminados. Los codecs se identifican por el valor asociado a la etiqueta Compression de TIFF; por ejemplo, 5 para la compresión LZW.

La rutina TIFFRegisterCODEC() puede usarse para aumentar o anular el conjunto de codecs disponibles para una aplicación. Si el scheme especificado ya tiene un codec registrado, este es anulado y cualquier imagen con datos codificados con este esquema de compresión será decodificada usando el codec proporcionado.

TIFFIsCODECConfigured() devuelve 1 si el codec está configurado y funcionando. De lo contrario, se devolverá 0.

TIFFGetConfiguredCODECs() obtiene la lista de codecs configurados, tanto incorporados como registrados por el usuario. La función devuelve un array de registros TIFFCodec (el último registro debe ser NULL) o NULL si la función falló. El llamador es responsable de liberar esta estructura.
