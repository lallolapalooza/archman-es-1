NOMBRE

TopLevelShell — La clase del widget TopLevelShell

SINOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPCIÓN

TopLevelShell se utiliza para ventanas normales de nivel superior, como cualquier widget de nivel superior adicional que una aplicación necesite.

Clases

TopLevelShell hereda el comportamiento y los recursos de Core, Composite, Shell, WMShell y VendorShell.

El puntero de clase es topLevelShellWidgetClass.

El nombre de la clase es TopLevelShell.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G), o no es aplicable (N/A).

XmNiconic
Si es True cuando se crea el widget, especifica que el widget debe comenzar como un icono cuando se materialice. Un valor de False indica que el widget no se materializará como un icono. Este recurso solo anulará el recurso XmNinitialState cuando se especifique en la llamada que crea el widget.
XmNiconName
Especifica la forma abreviada del nombre de la aplicación que mostrará el administrador de ventanas cuando la aplicación se convierta en icono. Cuando se llama a XtGetValues en este recurso, el valor devuelto es un puntero al valor real del recurso y no debe liberarse.
XmNiconNameEncoding
Especifica un tipo de propiedad que representa la codificación de la cadena XmNiconName. Si se ha establecido un procedimiento de idioma, el valor predeterminado es None; de lo contrario, el valor predeterminado es XA_STRING. Cuando el widget se materializa, si el valor es None, se asume que el nombre correspondiente está en la configuración regional actual. El nombre se pasa a XmbTextListToTextProperty con un estilo de codificación de XStdICCTextStyle. La codificación resultante es STRING si el nombre es completamente convertible a STRING, de lo contrario es COMPOUND_TEXT. Los valores de los recursos de codificación no se modifican; permanecen como None.

NAME

TopLevelShell - the shell widget of the application's top-level window

SYNOPSIS

#include <X11/Shell.h>
#include <X11/Intrinsic.h>
#include <X11/Xutil.h>
#include <X11/Xmu/WinUtil.h>

Widget toplevel;
toplevel = XtCreatePopupShell(
    name,
    topLevelShellWidgetClass,
    parent,
    args,
    num_args
);

Widget XtCreateWidget(
    "widget_name",
    topLevelShellWidgetClass,
    parent,
    args,
    num_args
);

DESCRIPTION

The TopLevelShell widget is a subclass of WMShell and is used for the application's top-level window. It manages the interaction between the application and the window manager, allowing the user to control the size, position, and iconification of the application's window.

The TopLevelShell widget provides the basic functionality required for a window to be managed by the window manager. It handles interactions with the window manager, such as setting window properties, handling resize requests, and managing iconification.

The TopLevelShell widget is a subclass of WMShell. It inherits all the resources of WMShell and adds some of its own.
