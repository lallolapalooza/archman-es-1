TransientShell TransientShell

NOMBRE

TransientShell — Clase de widget TransientShell

SINOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPCIÓN

TransientShell se utiliza para ventanas de shell que pueden ser manipuladas por el gestor de ventanas, pero no se les permite ser minimizadas por separado. Por ejemplo, los cuadros de diálogo no tienen sentido sin su aplicación asociada. Solo se minimizan si se minimiza la ventana principal del shell.

CLASES

TransientShell hereda comportamiento y recursos de Core, Composite, Shell, WMShell y VendorShell.

El puntero de clase es transientShellWidgetClass.

El nombre de la clase es TransientShell.

NAME

TransientShell

a transient shell widget

SYNOPSIS

#include <X11/Shell.h>
#include <Xm/Transient.h>

DESCRIPTION

The TransientShell widget is a subclass of Shell. It is used to create a transient shell, which is a pop-up shell that is unmanaged when the pop-up is dismissed. Transient shells are typically used for dialog boxes, menus, and other temporary windows.

The TransientShell widget has the following resources:
