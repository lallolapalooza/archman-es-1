NOMBRE

Test2::Util::Table - Formatear una cabecera y filas en una tabla

DESCRIPCIÓN

Esto se utiliza en algunas pruebas fallidas para proporcionar diagnósticos sobre lo que ha ido mal. Este módulo es capaz de formatear genéricamente filas de datos en tablas.

SINOPSIS

use Test2::Util::Table qw/table/;
my @table = table(
    max_width => 80,
    collapse => 1, # No mostrar columnas vacías
    header => [ 'nombre', 'edad', 'color de pelo' ],
    rows => [
        [ 'Fred Picapiedra',  2000000, 'negro' ],
        [ 'Vilma Picapiedra', 1999995, 'rojo' ],
        ...,
    ],
);
# El array @table contiene cada línea de la tabla, no se añaden saltos de línea.
say $_ for @table;

Esto imprime una tabla como esta:

+-----------------+---------+------------+
| nombre          | edad    | color pelo |
+-----------------+---------+------------+
| Fred Picapiedra | 2000000 | negro      |
| Vilma Picapiedra| 1999995 | rojo       |
| ...             | ...     | ...        |
+-----------------+---------+------------+

EXPORTACIONES

@filas = table(...)

La función devuelve una lista de líneas, las líneas no tienen el carácter de salto de línea "\n" añadido.

Opciones:

header => [ ... ]
Si deseas una cabecera, especifícala aquí. Esto toma un arrayref con el encabezado de cada columna.
rows => [ [...], [...], ... ]
Debe ser un arrayref que contenga un arrayref por fila.
collapse => $bool
Úsalo si deseas ocultar columnas vacías, es decir, cualquier columna que no tenga datos en ninguna fila. Tener una cabecera para la columna no afectará a la colapsión.
max_width => $num
Establece el ancho máximo de la tabla, la tabla puede que no sea tan grande, pero no será mayor. Si no se especifica, intentará encontrar el ancho de tu terminal y lo usará, de lo contrario, recurrirá a 80.
sanitize => $bool
Esto saneará todos los datos de la tabla de tal manera que los saltos de línea, caracteres de control y todo espacio en blanco excepto el ASCII 20 ' ' serán reemplazados por secuencias de escape. Esto evita que los saltos de línea, tabulaciones y espacios similares interrumpan la tabla.

Nota: los saltos de línea se marcan como '\n', pero también se inserta un salto de línea en los datos para que típicamente se muestren de una manera que sea útil para los humanos.

Ejemplo:

my $field = "hola\nadios\nbaz\n";
print join "\n" => table(
    sanitize => 1,
    rows => [
        [$field,      'col2'     ],
        ['fila2 col1', 'fila2 col2']
    ]
);

Imprime:

+-----------------+-----------+
| hola\n          | col2      |
| adios\n         |           |
| baz\n           |           |
|                 |           |
| fila2 col1      | fila2 col2|
+-----------------+-----------+

Así que marca los saltos de línea insertando la secuencia de escape, pero también muestra los datos a través de tantas líneas como se mostrarían normalmente.

mark_tail => $bool
Esto reemplazará el último carácter de espacio en blanco de cualquier espacio en blanco final con su secuencia de escape. Esto hace que sea más fácil notar el espacio en blanco final al comparar valores.

mi $cols = term_size()

Intenta encontrar el ancho en columnas (caracteres) de la terminal actual. Devuelve 80 como una apuesta segura si no puede encontrarlo de otra manera.

NOTA SOBRE CARACTERES UNICODE/ANCHO

Algunos caracteres unicode, como "婧" ("U+5A67") son más anchos que otros. Estos se renderizarán bien si usas "use utf8;" según sea necesario y está instalado Unicode::GCString, sin embargo, si el módulo no está instalado, habrá anomalías en la tabla:

+-----+-----+---+
| a   | b   | c |
+-----+-----+---+
| 婧 | x   | y |
| x   | y   | z |
| x   | 婧 | z |
+-----+-----+---+
