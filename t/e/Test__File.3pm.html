NOMBRE

Test::File -- probar atributos de archivos

SINOPSIS

use Test::File;

DESCRIPCIÓN

Este módulo proporciona una colección de utilidades de prueba para atributos de archivos.

Algunos atributos no tienen sentido fuera de Unix, por lo que algunas pruebas se ven obligadas a saltar si creen que no funcionarán en el sistema. Si tienes una forma de hacer que estas funciones funcionen en Windows, por favor envíame un parche. :D Si quieres fingir que estás en Windows en un sistema no Windows (por ejemplo, para probar skip()), puedes establecer la variable de entorno "PRETEND_TO_BE_WINDOWS".

El parámetro opcional NAME para cada función te permite especificar un nombre para la prueba. Si no se le proporciona, se utilizará un valor predeterminado razonable.

has_symlinks
Devuelve verdadero si este módulo cree que el sistema actual soporta enlaces simbólicos.
file_exists_ok( NOMBRE_ARCHIVO [, NOMBRE ] )

file_not_exists_ok( NOMBRE_ARCHIVO [, NOMBRE ] )
Ok si el archivo no existe, y no ok si existe.
file_empty_ok( NOMBRE_ARCHIVO [, NOMBRE ] )

file_executable_ok( FILENAME [, NAME ] )
Ok si el archivo existe y es ejecutable, no ok si el archivo no existe o no es ejecutable.

Esta prueba se omite automáticamente si cree que está en una plataforma Windows.

file_not_executable_ok( FILENAME [, NAME ] )
Ok si el archivo existe y no es ejecutable, no ok si el archivo no existe o es ejecutable.

file_mode_is( FILENAME, MODE [, NAME ] )
Ok si el archivo existe y el modo coincide, no ok si el archivo no existe o el modo no coincide.

Esta prueba se omite automáticamente si cree que está en una plataforma Windows.

Contribuido por Shawn Sorichetti "<ssoriche@coloredblocks.net>"

file_mode_isnt( FILENAME, MODE [, NAME ] )
Ok si el archivo existe y el modo no coincide, no ok si el archivo no existe o el modo coincide.

Esta prueba se omite automáticamente si cree que está en una plataforma Windows.

Contribuido por Shawn Sorichetti "<ssoriche@coloredblocks.net>"

file_mode_has( FILENAME, MODE [, NAME ] )
Ok si el archivo existe y tiene todos los bits del modo activados, no ok si el archivo no existe o el modo no coincide. Es decir, "FILEMODE & MODE == MODE" debe ser verdadero.

Esta prueba se omite automáticamente si cree que está en una plataforma Windows.

Contribuido por Ricardo Signes "<rjbs@cpan.org>"

file_mode_hasnt( FILENAME, MODE [, NAME ] )
Ok si el archivo existe y tiene todos los bits del modo desactivados, no ok si el archivo no existe o el modo coincide. Es decir, "FILEMODE & MODE == 0" debe ser verdadero.

Esta prueba se omite automáticamente si cree que está en una plataforma Windows.

Contribuido por Ricardo Signes "<rjbs@cpan.org>"

file_is_symlink_ok( FILENAME [, NAME ] )
Ok si FILENAME es un enlace simbólico, incluso si apunta a un archivo inexistente. Esta prueba se omite automáticamente si el sistema operativo no admite enlaces simbólicos.
file_is_not_symlink_ok( FILENAME [, NAME ] )
Ok si FILENAME no es un enlace simbólico. Esta prueba se omite automáticamente si el sistema operativo no admite enlaces simbólicos. Si el archivo no existe, la prueba falla.
symlink_target_exists_ok( SYMLINK [, TARGET] [, NAME ] )
Ok si FILENAME es un enlace simbólico y apunta a un archivo existente. Con el argumento opcional TARGET, la prueba falla si el objetivo de SYMLINK no es TARGET. Esta prueba se omite automáticamente si el sistema operativo no admite enlaces simbólicos. Si el archivo no existe, la prueba falla.
symlink_target_dangles_ok( SYMLINK [, NAME ] )
Ok si FILENAME es un enlace simbólico y si no apunta a un archivo existente. Esta prueba se omite automáticamente si el sistema operativo no admite enlaces simbólicos. Si el archivo no existe, la prueba falla.
symlink_target_is( SYMLINK, TARGET [, NAME ] )
Ok si FILENAME es un enlace simbólico y si apunta a TARGET. Esta prueba se omite automáticamente si el sistema operativo no admite enlaces simbólicos. Si el archivo no existe, la prueba falla.
symlink_target_is_absolute_ok( SYMLINK [, NAME ] )
Ok si FILENAME es un enlace simbólico y si su objetivo es una ruta absoluta. Esta prueba se omite automáticamente si el sistema operativo no admite enlaces simbólicos. Si el archivo no existe, la prueba falla.
dir_exists_ok( DIRECTORYNAME [, NAME ] )
Ok si el archivo existe y es un directorio, no ok si el archivo no existe, o existe pero no es un directorio.

Contribuido por Buddy Burden "<barefoot@cpan.org>".

dir_contains_ok( DIRECTORYNAME, FILENAME [, NAME ] )
Ok si el directorio existe y contiene el archivo, no ok si el directorio no existe, o existe pero no contiene el archivo.

Contribuido por Buddy Burden "<barefoot@cpan.org>".

link_count_is_ok( FILE, LINK_COUNT [, NAME ] )
Ok si el recuento de enlaces a FILE es LINK_COUNT. LINK_COUNT se interpreta como un entero. Un LINK_COUNT que se evalúa como 0 devuelve Ok si el archivo no existe.
link_count_gt_ok( FILE, LINK_COUNT [, NAME ] )
Ok si el recuento de enlaces a FILE es mayor que LINK_COUNT. LINK_COUNT se interpreta como un entero. Un LINK_COUNT que se evalúa como 0 devuelve Ok si el archivo tiene al menos un enlace.
link_count_lt_ok( FILE, LINK_COUNT [, NAME ] )
Ok si el recuento de enlaces a FILE es menor que LINK_COUNT. LINK_COUNT se interpreta como un entero. Un LINK_COUNT que se evalúa como 0 devuelve Ok si el archivo tiene al menos un enlace.
owner_is( FILE , OWNER [, NAME ] )
Ok si el propietario de FILE es el mismo que OWNER. OWNER puede ser un nombre de usuario de texto o un ID de usuario numérico. La prueba se omite en Dos y Mac OS <= 9. Si el archivo no existe, la prueba falla.

Contribuido por Dylan Martin

owner_isnt( FILE, OWNER [, NAME ] )
Ok si el propietario de FILE no es el mismo que OWNER. OWNER puede ser un nombre de usuario de texto o un ID de usuario numérico. La prueba se omite en Dos y Mac OS <= 9. Si el archivo no existe, la prueba falla.

Contribuido por Dylan Martin

group_is( FILE , GROUP [, NAME ] )
Ok si el grupo de FILE es el mismo que GROUP. GROUP puede ser un nombre de grupo de texto o un ID de grupo numérico. La prueba se omite en Dos, Mac OS <= 9 y cualquier otro sistema operativo que no admita getpwuid() y sus similares. Si el archivo no existe, la prueba falla.

Contribuido por Dylan Martin

group_isnt( FILE , GROUP [, NAME ] )
Ok si el grupo de FILE no es el mismo que GROUP. GROUP puede ser un nombre de grupo de texto o un ID de grupo numérico. La prueba se omite en Dos, Mac OS <= 9 y cualquier otro sistema operativo que no admita getpwuid() y sus similares. Si el archivo no existe, la prueba falla.

Contribuido por Dylan Martin

file_mtime_age_ok( FILE [, WITHIN_SECONDS ] [, NAME ] )
Ok si el tiempo de modificación de FILE está DENTRO_DE_SEGUNDOS inclusive del tiempo actual del sistema. Esta prueba utiliza stat() para obtener el mtime. Si el archivo no existe, la prueba falla. Si stat() falla, la prueba se omite.
file_mtime_gt_ok( FILE, UNIXTIME [, NAME ] )
Ok si el mtime de FILE es > UNIXTIME. Esta prueba utiliza stat() para obtener el mtime. Si stat() falla, esta prueba se omite. Si FILE no existe, esta prueba falla.
file_mtime_lt_ok( FILE, UNIXTIME, [, NAME ] )
Ok si el tiempo de modificación de FILE es < UNIXTIME. Esta prueba utiliza stat() para obtener el mtime. Si stat() falla, esta prueba se omite. Si FILE Test::File(3pm)
