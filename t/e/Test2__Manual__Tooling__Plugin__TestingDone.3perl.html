NOMBRE

Test2::Manual::Tooling::Plugin::TestingDone - Ejecutar código cuando el archivo de pruebas finaliza, o cuando se llama a done_testing.

DESCRIPCIÓN

Esta es una forma de agregar comportamiento al final de un archivo de pruebas. Este código se ejecuta ya sea cuando se llama a done_testing(), o cuando el archivo de pruebas ya no tiene más código en tiempo de ejecución para ejecutar.

Cuando se activa mediante done_testing(), esto se ejecutará ANTES de que se calcule y envíe el plan. Esto significa que ES seguro hacer aserciones de prueba en esta devolución de llamada.

CÓDIGO COMPLETO ANTICIPADO

package Test2::Plugin::MyPlugin;
use Test2::API qw{test2_add_callback_testing_done};
sub import {
    my $class = shift;
    test2_add_callback_testing_done(sub {
        ok(!$some_global, '$some_global no fue establecido');
        print "El archivo de pruebas ha terminado, o done_testing acaba de ser llamado\n"
    });
}
1;

LÍNEA POR LÍNEA

use Test2::API qw{test2_add_callback_testing_done};
Esto importa la devolución de llamada test2_add_callback_testing_done().
test2_add_callback_testing_done(sub { ... });
Esto agrega nuestra devolución de llamada para ser llamada cuando las pruebas hayan terminado.
ok(!$some_global, '$some_global no fue establecido')
Es seguro hacer aserciones en este tipo de devolución de llamada. Este código simplemente afirma que una variable global nunca fue establecida durante la ejecución de la prueba.
print "El archivo de pruebas ha terminado, o done_testing acaba de ser llamado\n"
Esto imprime un mensaje cuando se ejecuta la devolución de llamada.

BAJO EL CAPÓ

Antes de test2_add_callback_testing_done() este tipo de cosas todavía era posible, pero era difícil de hacer correctamente, aquí está el código para hacerlo:

test2_add_callback_post_load(sub {
    my $stack = test2_stack();
    # Aseguramos que tenemos al menos un hub, pero no necesariamente queremos
    # el que devuelve.
    $stack->top;
    # Queremos el hub raíz, no el superior.
    my ($root) = Test2::API::test2_stack->all;
    # Aseguramos que el hub no cree que no ha sucedido nada.
    $root->set_active(1);
    # Ahora podemos agregar nuestro código de seguimiento
    $root->follow_up(sub {
        # Tu código de devolución de llamada aquí
    });
});
