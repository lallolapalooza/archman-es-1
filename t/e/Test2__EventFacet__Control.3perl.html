Test2::EventFacet::Control(3perl) Guía de Referencia del Programador de Perl Test2::EventFacet::Control(3perl)

NOMBRE

Test2::EventFacet::Control - Faceta para acciones y comportamientos del hub.

DESCRIPCIÓN

Esta faceta se utiliza cuando el evento necesita dar instrucciones a los internos de Test2.

CAMPOS

$string = $control->{details}
$string = $control->details()
Explicación legible por humanos para el comportamiento especial.
$bool = $control->{global}
$bool = $control->global()
Verdadero si el evento es de naturaleza global y debe ser visto por todos los hubs.
$exit = $control->{terminate}
$exit = $control->terminate()
Definido si la prueba debe salir inmediatamente, el valor es el código de salida y puede ser 0.
$bool = $control->{halt}
$bool = $control->halt()
Verdadero si todas las pruebas deben detenerse inmediatamente.
$bool = $control->{has_callback}
$bool = $control->has_callback()
Verdadero si el método callback($hub) en el evento debe ser llamado.
$encoding = $control->{encoding}
$encoding = $control->encoding()
Esto se puede utilizar para cambiar la codificación a partir de este evento en adelante.
$phase = $control->{phase}
$phase = $control->phase()
Se utiliza para señalar que ha ocurrido un cambio de fase. Actualmente, solo se señala la fase END de perl.

FUENTE

El repositorio de código fuente de Test2 se puede encontrar en https://github.com/Test-More/test-more/.
