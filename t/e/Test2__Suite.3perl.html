Test2::Suite(3perl) Guía de Referencia del Programador de Perl Test2::Suite(3perl)

NOMBRE

Test2::Suite - Distribución con un rico conjunto de herramientas construidas sobre el framework Test2.

DESCRIPCIÓN

Un rico conjunto de herramientas, plugins, bundles, etc., construidos sobre la biblioteca de pruebas Test2. Si estás interesado en escribir pruebas, esta es la distribución para ti.

¿QUÉ SON LAS HERRAMIENTAS, PLUGINS Y BUNDLES?

HERRAMIENTAS
Las herramientas son paquetes que exportan funciones para su uso en archivos de prueba. Estas funciones típicamente generan eventos. Las herramientas NUNCA DEBEN alterar el comportamiento de otras herramientas o del sistema en general.
PLUGINS
Los plugins son paquetes que producen efectos o alteran el comportamiento de las herramientas. Un ejemplo sería un plugin que provoca que la prueba se detenga después del primer fallo. Los plugins NO DEBEN exportar nada.
BUNDLES
Los bundles son colecciones de herramientas y plugins. Un bundle debe cargar y volver a exportar funciones de paquetes de Herramientas. Un bundle también puede cargar y configurar cualquier número de plugins.

Si quieres escribir algo que tanto exporte nuevas funciones como afecte al comportamiento, deberías escribir una distribución de Herramientas y una distribución de Plugins, y luego un Bundle que los cargue ambos. Esto es importante ya que ayuda a evitar el problema donde un paquete exporta herramientas muy deseadas, pero también produce efectos secundarios indeseables.

BUNDLES INCLUIDOS

Test2::V0
Estos no residen en el espacio de nombres de bundles ya que son las formas principales de usar Test2::Suite.

La versión más reciente actual es Test2::V0.

use Test2::V0;
# strict y warnings están activados para ti ahora.
ok(...);
# Nota: 'is' realiza una comparación profunda, a diferencia de 'is' de Test::More.
is(...);
...
done_testing;

Este bundle incluye cada herramienta listada en la sección "HERRAMIENTAS INCLUIDAS" abajo, excepto Test2::Tools::ClassicCompare. Este bundle proporciona la mayor parte de lo que cualquier persona que escriba pruebas podría necesitar. Este es también el bundle/conjunto de herramientas preferido del autor de Test2.

Consulta Test2::V0 para obtener documentación completa.

use Test2::Bundle::Extended;
# strict y warnings están activados para ti ahora.

# Nota: 'is' realiza una comparación profunda, a diferencia de 'is' de Test::More.

Este bundle incluye cada herramienta listada en la sección "HERRAMIENTAS INCLUIDAS" abajo, excepto Test2::Tools::ClassicCompare. Este bundle proporciona la mayor parte de lo que cualquier persona que escriba pruebas podría necesitar. Este es también el bundle/conjunto de herramientas preferido del autor de Test2.

Consulta Test2::Bundle::Extended para obtener documentación completa.

More
use Test2::Bundle::More;
use strict;
use warnings;
plan 3; # O puedes usar done_testing al final
ok(...);
is(...); # Nota: Comparación de cadenas
is_deeply(...);
...
done_testing; # Usar en lugar de plan

Este bundle está diseñado para ser un reemplazo casi directo de Test::More. Hay algunas diferencias notables a tener en cuenta. Faltan algunas exportaciones: "eq_array", "eq_hash", "eq_set", $TODO, "explain", "use_ok", "require_ok". Además, ya no es posible establecer el plan en la importación: "use .. tests => 5". $TODO ha sido reemplazado por la función todo(). La planificación se realiza usando "plan", "skip_all" o "done_testing".

Consulta Test2::Bundle::More para obtener documentación completa.

Simple
use Test2::Bundle::Simple;
use strict;
use warnings;
plan 1;
ok(...);

Este bundle está diseñado para ser un reemplazo casi directo de Test::Simple. Consulta Test2::Bundle::Simple para obtener documentación completa.

HERRAMIENTAS INCLUIDAS

Basic
Basic proporciona la mayoría de las herramientas esenciales que antes se encontraban en Test::More. Sin embargo, no exporta ninguna herramienta utilizada para la comparación. Las funciones básicas "pass", "fail", "ok" están presentes, al igual que las funciones para planificar.

Consulta Test2::Tools::Basic para obtener documentación completa.

Compare
Proporciona "is", "like", "isnt", "unlike" y varias utilidades adicionales. Nota: Todas estas son herramientas de comparación profunda y funcionan como una combinación de "is" y "is_deeply" de Test::More.

Consulta Test2::Tools::Compare para obtener documentación completa.

ClassicCompare
Proporciona "is", "like", "isnt", "unlike" y "is_deeply" con el estilo de Test::More. También proporciona "cmp_ok".

Consulta Test2::Tools::ClassicCompare para obtener documentación completa.

Class
Proporciona funciones para probar objetos y clases, como "isa_ok".

Consulta Test2::Tools::Class para obtener documentación completa.

Defer
Proporciona funciones para escribir funciones de prueba en un lugar y ejecutarlas más tarde. Esto es útil para probar cosas que se ejecutan en un estado alterado.

Consulta Test2::Tools::Defer para obtener documentación completa.

Encoding
Exporta una única función que se puede utilizar para cambiar la codificación de toda la salida de tus pruebas.

Consulta Test2::Tools::Encoding para obtener documentación completa.

Exports
Proporciona herramientas para verificar exportaciones. Puedes verificar si las funciones han sido importadas o no.

Consulta Test2::Tools::Exports para obtener documentación completa.

Mock
Proporciona herramientas para hacer mocking de objetos y clases. Esto se basa en gran medida en Mock::Quick, pero se han añadido varias mejoras de interfaz que no se pueden añadir a Mock::Quick sin romper la retrocompatibilidad.

Consulta Test2::Tools::Mock para obtener documentación completa.

Ref
Exporta herramientas para validar y comparar referencias.

Consulta Test2::Tools::Ref para obtener documentación completa.

Spec
Esta es una implementación de RSPEC con soporte de concurrencia.

Consulta Test2::Tools::Spec para más detalles.

Subtest
Exporta herramientas para ejecutar subpruebas.

Consulta Test2::Tools::Subtest para obtener documentación completa.

Target
Esto te permite cargar el(los) paquete(s) que pretendes probar, y aliasearlos en constantes/variables de paquete.

Consulta Test2::Tools::Target para obtener documentación completa.

INCLUDED PLUGINS

BailOnFail
This is a plugin that will cause the test suite to bail out on the first failure. This is useful for large test suites where you do not want to waste time running tests after you have already failed.

See Test2::Plugin::BailOnFail for complete documentation.

DieOnFail
This is a plugin that will cause the test suite to die on the first failure. This is useful for large test suites where you do not want to waste time running tests after you have already failed.

See Test2::Plugin::DieOnFail for complete documentation.

ExitSummary
This plugin gives you statistics and diagnostics at the end of your test in the event of a failure.

See Test2::Plugin::ExitSummary for complete documentation.

SRand
Use this to set the random seed to a specific seed, or to the current date.

See Test2::Plugin::SRand for complete documentation.

UTF8
Turn on utf8 for your testing. This sets the current file to be utf8, it also sets STDERR, STDOUT, and your formatter to all output utf8.

See Test2::Plugin::UTF8 for complete documentation.

INCLUDED REQUIREMENT CHECKERS

AuthorTesting
Using this package will cause the test file to be skipped unless the AUTHOR_TESTING environment variable is set.

See Test2::Require::AuthorTesting for complete documentation.

EnvVar
Using this package will cause the test file to be skipped unless a custom environment variable is set.

See Test2::Require::EnvVar for complete documentation.

Fork
Using this package will cause the test file to be skipped unless the system is capable of forking (including emulated forking).

See Test2::Require::Fork for complete documentation.

RealFork
Using this package will cause the test file to be skipped unless the system is capable of true forking.

See Test2::Require::RealFork for complete documentation.

Module
Using this package will cause the test file to be skipped unless the specified module is installed (and optionally at a minimum version).

See Test2::Require::Module for complete documentation.

Perl
Using this package will cause the test file to be skipped unless the specified minimum perl version is met.

See Test2::Require::Perl for complete documentation.

Threads
Using this package will cause the test file to be skipped unless the system has threading enabled.

Note: This will not turn threading on for you.

See Test2::Require::Threads for complete documentation.
