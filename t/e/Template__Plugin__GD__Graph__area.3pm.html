NOMBRE

Template::Plugin::GD::Graph::area - Crea gráficos de área con ejes y leyendas

SINOPSIS

[% USE g = GD.Graph.area(x_size, y_size); %]

EJEMPLOS

[% FILTER null;
    data = [
        ["1","2","3","4","5","6","7", "8", "9"],
        [    5,   12,   24,   33,   19,    8,    6,    15,    21],
        [   -1,   -2,   -5,   -6,   -3,  1.5,    1,   1.3,     2]
    ];  

    USE my_graph = GD.Graph.area();
    my_graph.set(
            two_axes => 1,  
            zero_axis => 1,
            transparent => 0,
    );  
    my_graph.set_legend('eje izquierdo', 'eje derecho' );
    my_graph.plot(data).png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Graph.area proporciona una interfaz a la clase GD::Graph::area definida por el módulo GD::Graph. Permite que uno o más conjuntos de datos (x,y) se representen como líneas con el área entre la línea y el eje x sombreado, además de ejes y leyendas.

Consulte GD::Graph para obtener más detalles.
