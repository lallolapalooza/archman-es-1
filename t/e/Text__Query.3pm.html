NOMBRE

Text::Query - Marco de procesamiento de consultas

SINOPSIS

use Text::Query;

# Constructor
$query = Text::Query->new([QSTRING] [OPCIONES]);
# Métodos
$query->prepare(QSTRING [OPCIONES]);
$query->match([OBJETIVO]);
$query->matchscalar([OBJETIVO]);

DESCRIPCIÓN

Este módulo proporciona un objeto que compara una fuente de datos con una expresión de consulta.

Las expresiones de consulta se compilan a una forma interna cuando se crea un nuevo objeto o se llama al método "prepare"; no se recompilan en cada comparación.

La clase proporcionada por este módulo utiliza cuatro paquetes para procesar la consulta. El analizador de consultas analiza la pregunta y llama a un constructor de expresiones de consulta (forma interna de la pregunta). Luego se llama al optimizador para reducir la complejidad de la expresión. El solucionador aplica la expresión a una fuente de datos.

Los siguientes analizadores están disponibles:

Text::Query::ParseAdvanced
Text::Query::ParseSimple

Los siguientes constructores están disponibles:

Text::Query::BuildAdvancedString
Text::Query::BuildSimpleString

El siguiente solucionador está disponible:

Text::Query::SolveSimpleString
Text::Query::SolveAdvancedString

CONSTRUCTOR

new ([QSTRING] [OPCIONES])
Este es el constructor para un nuevo objeto Text::Query. Si se proporciona un "QSTRING", se compilará a la forma interna.

"OPCIONES" se pasan en forma de hash, utilizando pares de clave y valor. Las opciones posibles son:

-parse - Nombre del paquete del analizador. El valor predeterminado es Text::Query::ParseSimple.

-build - Nombre del paquete del constructor. El valor predeterminado es Text::Query::Build.

-optimize - Nombre del paquete del optimizador. El valor predeterminado es Text::Query::Optimize.

-solve - Nombre del paquete del solucionador. El valor predeterminado es Text::Query::Solve.

-mode - Nombre del grupo predefinido de paquetes a utilizar. Las opciones
actualmente son "simple_text" y "advanced_text".

Estas opciones son manejadas por el método "configure".

Todas las demás opciones se pasan a la función "prepare" del analizador. Consulte las páginas del manual correspondientes para obtener una descripción.

Si "QSTRING" no está definido, la función prepare no se llama.

El constructor fallará si se proporcionó un "QSTRING" y tenía sintaxis ilegal.

MÉTODOS

configure ([OPCIONES])
Establece los paquetes de "parse", "build", "optimize" o "solve". Consulte la descripción del "CONSTRUCTOR" para obtener explicaciones.
prepare (QSTRING [OPCIONES])
Compila la expresión de consulta en "QSTRING" a su forma interna y establece cualquier opción (igual que en el constructor). "prepare" se puede utilizar para cambiar la expresión de consulta y las opciones para un objeto de consulta existente. Si se omiten las "OPCIONES", cualquier opción establecida por una llamada anterior a "prepare" es persistente.

El optimizador (-optimize) se llama con el resultado del analizador (-parse). El analizador utiliza el constructor (-build) para construir la forma interna.

Este método devuelve una referencia al objeto de consulta si la sintaxis de la expresión era legal, o falla si no lo era.

match ([OBJETIVO])
Llama al método match del solucionador (-solve).
matchscalar ([OBJETIVO])
Llama al método matchscalar del solucionador (-solve).
