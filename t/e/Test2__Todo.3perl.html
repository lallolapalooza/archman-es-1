Test2::Todo(3perl) Guía de referencia del programador de Perl Test2::Todo(3perl)

NOMBRE

Test2::Todo - Extensión TODO para Test2.

DESCRIPCIÓN

Este es un objeto que te permite crear y gestionar estados TODO para las pruebas. Esta es una extensión, no un plugin ni una herramienta. Esta biblioteca puede ser utilizada por plugins y herramientas para gestionar estados todo.

Si simplemente deseas escribir una prueba todo, deberías consultar la función "todo" proporcionada por Test2::Tools::Basic.

SINOPSIS

use Test2::Todo;
# Iniciar el todo
my $todo = Test2::Todo->new(reason => 'Arreglar más tarde');
# Se considerará todo, por lo que el conjunto seguirá pasando
ok(0, "uy");
# Terminar el todo
$todo->end;
# El TODO ha terminado, esta prueba realmente fallará.
ok(0, "uy");

OPCIONES DE CONSTRUCCIÓN

reason (requerido)
La razón del todo, puede ser cualquier valor definido.
hub (opcional)
El hub al que se debe aplicar el estado TODO. Si no se proporciona ninguno, se utilizará el hub global actual.

MÉTODOS DE INSTANCIA

$todo->end
Termina el estado todo.

MÉTODOS DE CLASE

$count = Test2::Todo->hub_in_todo($hub)
Si el hub tiene algún objeto todo, esto devolverá el número total de ellos. Si el hub no tiene objetos todo, devolverá 0.

OTRAS NOTAS

Cómo funciona

Cuando se crea una instancia, se añade una subrutina de filtro al Test2::Hub. Este filtro establecerá los atributos "todo" y "diag_todo" en todos los eventos a medida que llegan. Cuando la instancia se destruye, o se llama a end(), el filtro se elimina.

Cuando se inserta un nuevo hub (como al iniciar un subtest), el nuevo hub heredará el filtro, pero solo establecerá "diag_todo", no establecerá "todo" en los eventos de los hubs hijos.

$todo->end se llama al destruir

Si tu objeto $todo sale de ámbito y es recolectado por el recolector de basura, el todo terminará.

¿Puedo usar múltiples instancias?

Sí. La última creada que aún esté activa será la que gane.
