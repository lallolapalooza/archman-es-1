NOMBRE

Test2::EventFacet::Error - Faceta para errores que necesitan ser mostrados.

DESCRIPCIÓN

Esta faceta se usa cuando un evento necesita transmitir errores.

NOTAS

Esta faceta tiene la clave de hash 'errors', y es una lista de facetas en lugar de un solo elemento.

CAMPOS

$cadena = $error->{detalles}
$cadena = $error->detalles()
Explicación del error, o el error mismo (como una excepción). En perl las excepciones pueden ser objetos bendecidos, por lo que este campo puede contener un objeto bendecido.
$cadena_corta = $error->{etiqueta}
$cadena_corta = $error->etiqueta()
Etiqueta corta para categorizar el error. Normalmente tiene 10 caracteres o menos, los formateadores pueden truncar etiquetas más largas.
$booleano = $error->{fallo}
$booleano = $error->fallo()
No todos los errores son fatales, algunos se muestran habiendo sido ya manejados. Establece esto a verdadero si quieres que el error cause que la prueba falle. Sin esto, el error es simplemente un mensaje de diagnóstico que no tiene efecto en el resultado general de pasar/fallar.

FUENTE

El repositorio de código fuente para Test2 se puede encontrar en https://github.com/Test-More/test-more/.
