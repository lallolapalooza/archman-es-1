NOMBRE

Test2::EventFacet::Hub - Faceta para los hubs por los que pasa un evento.

DESCRIPCIÓN

Estos son un registro de los hubs por los que pasa un evento. El hub más reciente es el primero de la lista.

CAMPOS DE FACETA

$cadena = $trace->{details}
$cadena = $trace->details()
La clase del hub o subclase
$entero = $trace->{pid}
$entero = $trace->pid()
PID del hub al que se envió este evento.
$entero = $trace->{tid}
$entero = $trace->tid()
El ID del hilo del hub al que se envió el evento.
$hid = $trace->{hid}
$hid = $trace->hid()
El ID del hub al que se envió el evento.
$huuid = $trace->{huuid}
$huuid = $trace->huuid()
El UUID del hub al que se envió el evento.
$entero = $trace->{nested}
$entero = $trace->nested()
Qué tan anidado estaba el hub.
$booleano = $trace->{buffered}
$booleano = $trace->buffered()
Verdadero si el evento fue almacenado en búfer y no enviado al formateador independientemente de un padre (Esto nunca debería establecerse cuando nested es 0 o "undef").
