Template::Plugin::GD::Graph::bars3d(3) Documentación de Perl contribuida por el usuario Template::Plugin::GD::Graph::bars3d(3)

NOMBRE

Template::Plugin::GD::Graph::bars3d - Crea gráficos de barras 3D con ejes y leyendas

SINOPSIS

[% USE g = GD.Graph.bars3d(tamaño_x, tamaño_y); %]

EJEMPLOS

[% FILTER null;
    datos = [
        ["Ene", "Feb", "Mar", "Abr", "May", "Jun", "Jul", "Ago",
                                     "Sep", "Oct", "Nov", "Dic", ],
        [-5, -4, -3, -3, -1,  0,  2,  1,  3,  4,  6,  7],
        [4,   3,  5,  6,  3,1.5, -1, -3, -4, -6, -7, -8],
        [1,   2,  2,  3,  4,  3,  1, -1,  0,  2,  3,  2],
    ];

    USE mi_grafico = GD.Graph.bars3d();

    mi_grafico.set( 
            etiqueta_x => 'Mes',
            etiqueta_y => 'Medida de éxito',
            titulo => 'Un gráfico de barras 3D',
            valor_max_y => 8,
            valor_min_y => -8,
            numero_ticks_y => 16,
            saltar_etiqueta_y => 2,
            eje_caja => 0,
            ancho_linea => 3,
            solo_eje_cero => 1,
            posicion_etiqueta_x => 1,  
            posicion_etiqueta_y => 1,  

            saltar_etiqueta_x => 3,
            offset_tick_x => 2,

            transparente => 0,
    );      
    mi_grafico.set_leyenda("Nosotros", "Ellos", "Otros");
    mi_grafico.plot(datos).png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Graph.bars3d proporciona una interfaz para la clase GD::Graph::bars3d definida por el módulo GD::Graph3d. Permite que uno o más conjuntos de datos (x,y) se representen como barras y frente a x con una apariencia tridimensional, junto con ejes y leyendas.

Ver GD::Graph3d para más detalles.
