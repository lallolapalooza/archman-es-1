Test2::Bundle::Simple(3perl) Guía de referencia para programadores de Perl Test2::Bundle::Simple(3perl)

NOMBRE

Test2::Bundle::Simple - CASI un reemplazo directo para Test::Simple.

DESCRIPCIÓN

Este paquete está pensado para ser un reemplazo (casi) directo para Test::Simple. Ver "DIFERENCIAS CLAVE CON Test::Simple" para más detalles.

SINOPSIS

use Test2::Bundle::Simple;
ok(1, "pasa");
done_testing;

PLUGINS

Esto carga Test2::Plugin::ExitSummary.

HERRAMIENTAS

Estas son todas de Test2::Tools::Basic.

ok($bool, $nombre)
Ejecuta una prueba. Si bool es verdadero, la prueba pasa. Si bool es falso, falla.
plan($count)
Indica al sistema cuántas pruebas esperar.
skip_all($reason)
Indica al sistema que omita todas las pruebas (esto saldrá del script).
done_testing();
Indica al sistema que todas las pruebas están completas. Puedes usar esto en lugar de establecer un plan.

DIFERENCIAS CLAVE CON Test::Simple

No puedes planificar en la importación.
ESTO NO FUNCIONARÁ: 
use Test2::Bundle::Simple tests => 5;

En su lugar, debes planificar en una declaración separada:

use Test2::Bundle::Simple;
plan 5;
Tienes tres subs importadas para usar en la planificación
Usa plan($count), skip_all($reason), o done_testing() para tu planificación.
