NOMBRE

Test::Memory::Cycle - Comprueba fugas de memoria y referencias de memoria circulares

VERSIÓN

Versión 1.06

SINOPSIS

La recolección de basura de Perl tiene un gran problema: las referencias circulares no se pueden limpiar. Una referencia circular puede ser tan simple como dos referencias que se refieren entre sí:

my $mom = {
    name => "Marilyn Lester",
};
my $me = {
    name => "Andy Lester",
    mother => $mom,
};
$mom->{son} = $me;

"Test::Memory::Cycle" está construido sobre "Devel::Cycle" para ofrecerte una forma sencilla de comprobar estas referencias circulares.

use Test::Memory::Cycle;
my $object = new MyObject;
# Haz cosas con el objeto.
memory_cycle_ok( $object );

También puedes usar memory_cycle_exists() para asegurarte de que tienes un ciclo donde esperas tener uno.

FUNCIONES

"memory_cycle_ok( $referencia, $msg )"

Comprueba que $referencia no tiene referencias de memoria circulares.

"memory_cycle_exists( $referencia, $msg )"

Comprueba que $referencia **tiene** referencias de memoria circulares.

"weakened_memory_cycle_ok( $referencia, $msg )"

Comprueba que $referencia no tiene referencias de memoria circulares, pero a diferencia de "memory_cycle_ok", también comprobará ciclos debilitados producidos con "weaken" de Scalar::Util.

"weakened_memory_cycle_exists( $referencia, $msg )"

Comprueba que $referencia **tiene** referencias de memoria circulares, pero a diferencia de "memory_cycle_exists", también comprobará ciclos debilitados producidos con "weaken" de Scalar::Util.
