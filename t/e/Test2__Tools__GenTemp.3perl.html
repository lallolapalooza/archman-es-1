NOMBRE

Test2::Tools::GenTemp - Herramienta para generar un directorio temporal poblado.

DESCRIPCIÓN

Esto exporta una herramienta que te ayuda a crear un directorio temporal, directorios anidados y archivos de texto dentro de él.

SINOPSIS

use Test2::Tools::GenTemp qw/gen_temp/;
my $dir = gen_temp(
    a_file => "Contenido de a_file",
    a_dir  => {
        'a_file' => 'Contenido de a_dir/afile',
        a_nested_dir => { ... },
    },
    ...
);
done_testing;

EXPORTACIONES

Todas las subs se exportan por defecto.

gen_temp(archivo => 'contenido', subdirectorio => [ subdirectorio_archivo => 'contenido', ...], ...)
gen_temp(-directorio_temporal => \@ARGUMENTOS_DIRECTORIO_TEMPORAL, archivo => 'contenido', subdirectorio => [ subdirectorio_archivo => 'contenido', ...], ...)
Esto generará un nuevo directorio temporal con todos los archivos y subdirectorios que especifiques, de forma recursiva. El directorio temporal inicial se crea usando File::Temp::tempdir(), puedes pasar argumentos a tempdir usando el argumento "-directorio_temporal => [...]".
