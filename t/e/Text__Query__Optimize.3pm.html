Text::Query::Optimize(3) Documentación de Perl aportada por el usuario Text::Query::Optimize(3)

NOMBRE

Text::Query::Parse - Clase base para analizadores de consultas

SINOPSIS

package Text::Query::OptimizeSmart;
use Text::Query::Optimize;

use vars qw(@ISA);
@ISA = qw(Text::Query::Optimize);

DESCRIPCIÓN

Este módulo proporciona una clase base virtual para optimizadores de consultas.

Define el método "optimize" que es llamado por el objeto "Text::Query" para optimizar la consulta interna.

MÉTODOS

optimize (INTERNO)
Devuelve el argumento "INTERNO" después de la optimización. La implementación por defecto devuelve el argumento sin modificar.
