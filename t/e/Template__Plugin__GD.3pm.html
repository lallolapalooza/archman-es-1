NOMBRE

Template::Plugin::GD - Plugin(s) GD para el Template Toolkit

SINOPSIS

[% USE GD;

   # crear una imagen
   img = GD.image(width, height)
   # asignar algunos colores
   black = img.colorAllocate(0,   0,   0);
   red   = img.colorAllocate(255, 0,   0);
   blue  = img.colorAllocate(0,   0, 255);
   # dibujar un óvalo azul
   img.arc(50, 50, 95, 75, 0, 360, blue);
   # rellenarlo de rojo
   img.fill(50, 50, red);
   # mostrar imagen binaria en formato PNG
   img.png | redirect('example.png');
%]

DESCRIPCIÓN

La distribución Template-GD proporciona varios módulos de plugin del Template Toolkit para interactuar con los módulos GD de Lincoln Stein. Estos, a su vez, proporcionan una interfaz a la biblioteca gráfica GD de Thomas Boutell.

Estos plugins se distribuyeron como parte del Template Toolkit hasta la versión 2.15 lanzada en febrero de 2006. En ese momento fueron extraídos a esta distribución separada.

Para obtener información general sobre el Template Toolkit, consulta la documentación del módulo Template o http://template-toolkit.org. Para obtener información sobre cómo usar plugins, consulta Template::Plugins y "USE" en Template::Manual::Directives.

MÉTODOS

El módulo plugin GD proporciona varios métodos para crear otros objetos GD. Pero primero necesitas cargar el plugin GD.

[% USE GD %]

Luego puedes llamar a los siguientes objetos sobre él.

image(width, height)

Crea un nuevo objeto GD::Image.

[% image = GD.image(100, 200) %]

polygon()

Crea un nuevo objeto GD::Polygon.

[% poly = GD.polygon;
   poly.addPt(50,0);
   poly.addPt(99,99);
   poly.addPt(0,99);
   image.filledPolygon(poly, blue);
%]

text()

Crea un nuevo objeto GD::Text.

[%  text = GD.text;
    text.set_text('Some text');
%]

PLUGINS GD

Estos son los plugins GD proporcionados en esta distribución.

Template::Plugin::GD

Módulo frontal para la colección de plugins GD.

Template::Plugin::GD::Image

Interfaz de plugin que proporciona acceso directo al módulo GD::Image.

[% USE image = GD.Image %]

Template::Plugin::GD::Polygon

Interfaz de plugin que proporciona acceso directo al módulo GD::Polygon.

[% USE poly = GD.Polygon;
   poly.addPt(50,0);
   poly.addPt(99,99);
   poly.addPt(0,99);
   image.filledPolygon(poly, blue);
%]

Template::Plugin::GD::Text

Interfaz de plugin que proporciona acceso directo al módulo GD::Text.

[%  USE text = GD.Text;
    text.set_text('Some text');
%]

Template::Plugin::GD::Text::Align

Interfaz de plugin para el módulo GD::Text::Align para crear texto alineado.

Template::Plugin::GD::Text::Wrap

Interfaz de plugin para el módulo GD::Text::Wrap para crear texto con saltos de línea.

Template::Plugin::GD::Graph::area

Interfaz de plugin para el módulo GD::Graph::area para crear gráficos de área con ejes y leyendas.

Template::Plugin::GD::Graph::bars3d

Interfaz de plugin para el módulo GD::Graph::bars3d para crear gráficos de barras 3D con ejes y leyendas.

Template::Plugin::GD::Graph::bars

Interfaz de plugin para el módulo GD::Graph::bars para crear gráficos de barras con ejes y leyendas.

Template::Plugin::GD::Graph::lines3d

Interfaz de plugin para el módulo GD::Graph::lines3d para crear gráficos de líneas 3D con ejes y leyendas.

Template::Plugin::GD::Graph::lines

Interfaz de plugin para el módulo GD::Graph::lines para crear gráficos de líneas con ejes y leyendas.

Template::Plugin::GD::Graph::linespoints

Interfaz de plugin para el módulo GD::Graph::linespoints para crear gráficos de líneas/puntos con ejes y leyendas.

Template::Plugin::GD::Graph::mixed

Interfaz de plugin para el módulo GD::Graph::mixed para crear gráficos mixtos con ejes y leyendas.

Template::Plugin::GD::Graph::pie3d

Interfaz de plugin para el módulo GD::Graph::pie3d para crear gráficos de pastel 3D con leyendas.

Template::Plugin::GD::Graph::pie

Interfaz de plugin para el módulo GD::Graph::pie para crear gráficos de pastel con leyendas.

Template::Plugin::GD::Graph::points

Interfaz de plugin para el módulo GD::Graph::points para crear gráficos de puntos con ejes y leyendas.

Template::Plugin::GD::Constants

Proporciona acceso a varias constantes GD.

[% USE gdc = GD.Constants;
   font = gdc.gdLargeFont
%]
