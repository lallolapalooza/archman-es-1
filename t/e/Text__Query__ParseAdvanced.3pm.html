NOMBRE

Text::Query::ParseAdvanced - Analiza la sintaxis de consulta avanzada de AltaVista

SINOPSIS

use Text::Query;
my $q=new Text::Query('hola y mundo',
                      -parse => 'Text::Query::ParseAdvanced',
                      -solve => 'Text::Query::SolveAdvancedString',
                      -build => 'Text::Query::BuildAdvancedString');

DESCRIPCIÓN

Este módulo proporciona un objeto que analiza una cadena que contiene una expresión de consulta booleana similar a una "consulta avanzada" de AltaVista.

Es una clase base de Text::Query::Parse;

Las expresiones de consulta consisten en cadenas literales (o expresiones regulares) unidas por los siguientes operadores, en orden de precedencia de menor a mayor:

OR, |
AND, &
NEAR, ~
NOT, !

Los nombres de los operadores no distinguen entre mayúsculas y minúsculas. Tenga en cuenta que si desea utilizar un "|" en una expresión regular, debe escaparlo para evitar que se interprete como un operador de consulta. Las subexpresiones pueden ir entre comillas simples o dobles para que coincidan literalmente con "and", "or" o "not" y pueden agruparse entre paréntesis ("(, )") para alterar la precedencia de evaluación.

Una subexpresión entre paréntesis también puede concatenarse con otras subexpresiones para que coincidan con secuencias: "(Perl o Python) intérprete" coincidiría con "intérprete Perl" o "intérprete Python". La concatenación tiene una precedencia mayor que NOT pero menor que AND. La yuxtaposición de palabras simples tiene la precedencia más alta de todas.

OPCIONES

Estas son las opciones adicionales del método "prepare" y del constructor.

-near por defecto es 10
Establece el número de palabras que pueden ocurrir entre dos expresiones y seguir satisfaciendo el operador NEAR.
-operators por defecto es and, or, not, near
Establece los nombres de los operadores. El argumento de la opción es un puntero a una tabla hash que mapea los nombres por defecto a los nombres deseados. Por ejemplo: 
{
    'or' => 'ou',
    'and' => 'et',
    'near' => 'proche',
    'not' => 'non',
}
-scope_map por defecto es {}
Mapea los nombres de ámbito a otros nombres. Si se especifica un ámbito como "ámbito:", busca en el mapa una entrada cuya clave sea "ámbito" y reemplaza "ámbito" con el escalar encontrado. Por ejemplo: 
{
    'ámbito' => 'otroámbito'
}
