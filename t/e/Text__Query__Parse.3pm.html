NOMBRE

Text::Query::Parse - Clase base para analizadores de consultas

SINOPSIS

package Text::Query::ParseThisSyntax;
use Text::Query::Parse;

use vars qw(@ISA);
@ISA = qw(Text::Query::Parse);

DESCRIPCIÓN

Este módulo proporciona una clase base virtual para analizadores de consultas.

Define el método "prepare" que es llamado por el objeto "Text::Query" para compilar la cadena de consulta.

MIEMBROS

-build Puntero a un objeto Text::Query::Build.
scope Pila de alcance. Define el contexto en el que se debe resolver la consulta.
token El token actual. Destruido por "prepare".
tokens Una referencia a la lista de todos los tokens. Rellenado por parse_tokens. Destruido por "prepare".
parseopts Una referencia a una tabla hash que contiene todos los parámetros dados a la función "prepare".
-verbose Entero que indica el nivel de verbosidad deseado.

MÉTODOS

prepare (QSTRING [OPCIONES])
Compila la expresión de consulta en "QSTRING" a forma interna y establece cualquier opción. Primero llama a "build_init" para reiniciar el constructor y destruir los miembros "token" y "tokens". Luego llama a "parse_tokens" para rellenar el miembro "tokens". Luego llama a "expression" para usar los tokens de "tokens". Se espera que "expression" llame a las funciones "build_*" para construir la expresión compilada. Finalmente, llama a "build_final_expression" con el resultado de "expression".

Un analizador derivado debe redefinir esta función para definir valores predeterminados para opciones específicas.

expression ()
Debe ser redefinido por el paquete derivado. Devuelve la forma interna de la pregunta construida a partir de las funciones "build_*" utilizando los "tokens".
parse_tokens (QSTRING)
Debe ser redefinido por el paquete derivado. Analiza el escalar "QSTRING" y rellena el miembro "tokens" con unidades léxicas.
build_*
Atajos a la función correspondiente del objeto Text::Query::Build que se encuentra en el miembro "-build".

OPCIONES

Estas son las opciones del método "prepare" y del constructor.

-quotes por defecto es \'\"\'
Define los caracteres de cita.
-case por defecto es 0
Si es verdadero, realiza una coincidencia sensible a mayúsculas y minúsculas.
-litspace por defecto es 0
Si es verdadero, coincide con espacios (excepto entre operadores) en "QSTRING" literalmente. Si es falso, coincide con espacios como "\s+".
-regexp por defecto es 0
Si es verdadero, trata los patrones en "QSTRING" como expresiones regulares en lugar de texto literal.
-whole por defecto es 0
Si es verdadero, solo coincide con palabras completas, no con subcadenas de palabras.
