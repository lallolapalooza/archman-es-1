NOMBRE

Test2::Compare::Delta - Representación de diferencias entre estructuras de datos anidadas.

DESCRIPCIÓN

Este se utiliza por Test2::Compare. Cuando se comparan estructuras de datos, se devolverá una delta. Las deltas son un estructura de datos de árbol que representan todas las diferencias entre dos estructuras de datos otras.

MÉTODOS

MÉTODOS DE CLASE

$class->add_column($NAME => sub { ... })
$class->add_column($NAME, %PARAMS)
Esta puede ser utilizada para añadir columnas a la tabla que se produce cuando una comparación falla. El primer argumento debe siempre ser el nombre de la columna, que debe ser único.

La primera forma simplemente toma un coderef que produce el valor que debería verse en la columna para cualquier delta. Los argumentos pasados a la subsonda son el delta y el ID de la fila.

Test2::Compare::Delta->add_column(
    Foo => sub {
        my ($delta, $id) = @_;
        return $delta->... ? 'foo' : 'bar'
    },
);

La segunda forma permite algunas opciones adicionales. El parámetro 'value' es obligatorio y debe ser un coderef. Todos los otros parámetros son opcionales.

Test2::Compare::Delta->add_column(
    'Foo',    # nombre de la columna
    value => sub { ... },    # cómo obtener el valor de la celda
    alias       => 'FOO',    # nombre de mostrar (usado en cabecera de tabla)
    no_collapse => $bool,    # mostrar la columna incluso si no tiene valores?
);
$bool = $class->remove_column($NAME)
Esta eliminará la columna especificada. Esta devolverá true si la columna existía y fue eliminada. Esta devolverá false si la columna no existía. No se lanzan excepciones. Si una columna ausente es un problema, debes comprobar el retorno tú mismo.
$class->set_column_alias($NAME, $ALIAS)
Esta puede ser utilizada para cambiar el nombre de la cabecera, reemplazando los nombres por nuevos.

ATRIBUTOS

$bool = $delta->verified
$delta->set_verified($bool)
Esto será verdadero si el delta mismo se coincidió, si el delta se coincidió, el problema está en los hijos del delta, no en el delta mismo.
$aref = $delta->id
$delta->set_id([$type, $name])
ID del delta, utilizado para producir la ruta en el estructurado de datos. Un ejemplo es "['HASH' => 'foo']", que significa que el delta está en la ruta "...->{'foo'}". Los tipos válidos son "HASH", "ARRAY", "SCALAR", "META", y "METHOD".
$val = $delta->got
$delta->set_got($val)
Los deltas se generan comparando un estructura de datos recibida 'got' contra una estructura de datos de chequeo 'check'. El atributo 'got' contiene el valor recibido para la comparación.
$check = $delta->chk
$check = $delta->check
$delta->set_chk($check)
$delta->set_check($check)
Los deltas se generan comparando un estructura de datos recibida 'got' contra una estructura de datos de chequeo 'check'. El atributo 'check' contiene el valor esperado en la comparación.

"check" y "chk" son alias del mismo atributo.

$aref = $delta->children
$delta->set_children([$delta1, $delta2, ...])
Un delta puede tener deltas hijos. Si lo tiene, este es un arrayref con esos hijos.
$dne = $delta->dne
$delta->set_dne($dne)
Algunas comparaciones pueden resultar en que uno o el otro no exista por completo, en cuyo caso este se establece en el nombre del atributo que no existe. Esto puede ser establecido en 'got' o 'check'.
$e = $delta->exception
$delta->set_exception($e)
Esta se establecerá en la excepción en caso de que la comparación falló debido a una excepción siendo lanzada.

OTRAS

$string = $delta->render_got
Renderiza la cadena que se debe usar en una tabla para representar el valor recibido en una comparación.
$string = $delta->render_check
Renderiza la cadena que se debe usar en una tabla para representar el valor esperado en una comparación.
$bool = $delta->should_show
Devuelve verdadero si el delta debe mostrarse en la tabla. Esto es normally verdadero para cualquier delta no verificado. También será verdadero para deltas que contienen información útil de depuración adicional.
$aref = $delta->filter_visible
Genera un arrayref de "[ $path => $delta ]" para todos los deltas que deben mostrarse en la tabla.
$aref = $delta->table_header
Devuelve un array ref de las cabeceras de la tabla.
$string = $delta->table_op
Devuelve el operador que debe mostrarse en la tabla.
$string = $delta->table_check_lines
Devuelve las líneas definidas (información de depuración adicional) que deben mostrarse.
$string = $delta->table_got_lines
Devuelve las líneas generadas (información de depuración adicional) que deben mostrarse.
$aref = $delta->table_rows
Devuelve un arrayref de filas de la tabla, cada fila es un arrayref.
@table_lines = $delta->table
Devuelve todas las líneas de la tabla que deben mostrarse.
