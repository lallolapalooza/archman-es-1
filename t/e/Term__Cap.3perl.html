Term::Cap(3perl) Guía de programación de Perl Term::Cap(3perl)

NOMBRE

Term::Cap - Interfaz termcap de Perl

SINOPSIS

require Term::Cap;
$terminal = Term::Cap->Tgetent({ TERM => undef, OSPEED => $ospeed });
$terminal->Trequire(qw/ce ku kd/);
$terminal->Tgoto('cm', $col, $row, $FH);
$terminal->Tputs('dl', $count, $FH);
$terminal->Tpad($string, $count, $FH);

DESCRIPCIÓN

Estas son funciones de bajo nivel para extraer y utilizar capacidades de una base de datos de capacidades de terminal (termcap).

Se encontrará más información sobre las capacidades del terminal en la página del manual de termcap en la mayoría de los sistemas tipo Unix.

MÉTODOS

Las cadenas de salida para Tputs se almacenan en caché para recuentos de 1 para mejorar el rendimiento. Tgoto y Tpad no almacenan en caché. "$self->{_xx}" son los datos raw de termcap y "$self->{xx}" es la versión en caché.

print $terminal->Tpad($self->{_xx}, 1);

Tgoto, Tputs y Tpad devuelven la cadena y también enviarán la cadena a $FH si se especifica.

Tgetent
Devuelve una referencia de objeto bendecida que el usuario puede usar para enviar las cadenas de control al terminal usando Tputs y Tgoto.

La función extrae la entrada del tipo de terminal especificado TERM (por defecto la variable de entorno TERM) de la base de datos.

Buscará en el entorno una variable TERMCAP. Si se encuentra y el valor no comienza con una barra, y el nombre del tipo de terminal es el mismo que la cadena de entorno TERM, se utiliza la cadena TERMCAP en lugar de leer un archivo termcap. Si comienza con una barra, la cadena se utiliza como nombre de ruta del archivo termcap a buscar. Si TERMCAP no comienza con una barra y el nombre es diferente de TERM, Tgetent busca los archivos $HOME/.termcap, /etc/termcap, y /usr/share/misc/termcap, en ese orden, a menos que exista la variable de entorno TERMPATH, en cuyo caso especifica una lista de nombres de ruta de archivo (separados por espacios o dos puntos) que se buscarán en su lugar. Siempre que se busquen varios archivos y aparezca un campo tc en la entrada solicitada, la entrada que nombra debe encontrarse en el mismo archivo o en uno de los archivos subsiguientes. Si hay un ":tc=...:" en la cadena de la variable de entorno TERMCAP, continuará la búsqueda en los archivos como se mencionó anteriormente.

La entrada termcap extraída está disponible en el objeto como "$self->{TERMCAP}".

Toma una referencia de hash como argumento con dos claves opcionales:

OSPEED
La velocidad de bits de salida del terminal (a menudo erróneamente llamada velocidad en baudios) para este terminal; si no se establece, se generará una advertencia y se establecerá por defecto a 9600. OSPEED puede especificarse como velocidades de termios POSIX/termio SYSV (donde 9600 equivale a 9600) o una velocidad de estilo DSD antiguo (donde 13 equivale a 9600).
TERM
El tipo de terminal cuya entrada termcap se utilizará; si no se proporciona, se establecerá por defecto a $ENV{TERM}; si eso no está configurado, Tgetent fallará.

Llama a "croak" en caso de fallo.

Tpad
Emite una cadena literal con el relleno apropiado para el terminal actual.

Toma tres argumentos:

$string
La cadena literal a emitir. Si comienza con un número y un opcional '*' entonces el relleno se incrementará en una cantidad relativa a este número; si está presente el '*', esta cantidad se multiplicará por $cnt. Esta parte de $string se elimina antes de la emisión.
$cnt
Se utilizará para modificar el relleno aplicado a la cadena como se describe anteriormente.
$FH
Un manejador de archivo opcional (o IO::Handle) al que se imprimirá la salida.

Se devuelve la $string rellenada.

Tputs
Emite la cadena para la capacidad dada, rellenada apropiadamente sin ninguna sustitución de parámetros.

Toma tres argumentos:

$cap
La capacidad cuya cadena debe emitirse.
$cnt
Un contador pasado a Tpad para modificar el relleno aplicado a la cadena de salida. Si $cnt es cero o uno, la cadena resultante se almacenará en caché.
$FH
Un manejador de archivo opcional (o IO::Handle) al que se imprimirá la salida.

Se devolverá la cadena apropiada para la capacidad.

Tgoto
Tgoto decodifica una cadena de direccionamiento de cursor con los parámetros dados.

Hay cuatro argumentos:

$cap
El nombre de la capacidad que se emitirá.
$col
El primer valor que se sustituirá en la cadena de salida (normalmente la columna en una capacidad de direccionamiento de cursor).
$row
El segundo valor que se sustituirá en la cadena de salida (normalmente la fila en capacidades de direccionamiento de cursor).
$FH
Un manejador de archivo opcional (o IO::Handle) al que se imprimirá la cadena de salida.

Las sustituciones se realizan con $col y $row en la cadena de salida con los siguientes formatos de línea de sprintf():

%%   emite `%'
%d   emite el valor como en printf %d
%2   emite el valor como en printf %2d
%3   emite el valor como en printf %3d
%.   emite el valor como en printf %c
%+x  suma x al valor, luego haz %.
%>xy si valor > x entonces suma y, sin emisión
%r   invierte el orden de dos parámetros, sin emisión
%i   incrementa en uno, sin emisión
%B   BCD (16*(valor/10)) + (valor%10), sin emisión
%n   OR exclusivo de todos los parámetros con 0140 (Datamedia 2500)
%D   Código inverso (valor - 2*(valor%16)), sin emisión (Delta Data)

Se devolverá la cadena de salida.

Trequire
Toma una lista de capacidades como argumento y fallará si no se encuentra alguna.

EJEMPLOS

use Term::Cap;
# Obtener la velocidad de salida del terminal
require POSIX;
my $termios = POSIX::Termios->new;
$termios->getattr;
my $ospeed = $termios->getospeed;
# Código antiguo de ioctl para obtener ospeed:
#     require 'ioctl.pl';
#     ioctl(TTY,$TIOCGETP,$sgtty);
#     ($ispeed,$ospeed) = unpack('cc',$sgtty);
# asignar e inicializar una estructura de terminal
my $terminal = Term::Cap->Tgetent({ TERM => undef, OSPEED => $ospeed });
# requerir que ciertas capacidades estén disponibles
$terminal->Trequire(qw/ce ku kd/);
# Rutinas de salida, si $FH es indefinido, solo devuelven la cadena
# Tgoto realiza la expansión de % con los argumentos dados
$terminal->Tgoto('cm', $col, $row, $FH);
# Tputs no realiza ninguna expansión de %.
$terminal->Tputs('dl', $count = 1, $FH);

Term::Cap(3perl) - Interfaz de terminal de control

NAME

Term::Cap - Interfaz de terminal de control

SYNOPSIS

 use Term::Cap;
 $terminal = Term::Cap->Tgetent($fh)
 $terminal->Tgoto($row, $col)
 $terminal->Tput('cl')
 $terminal->Twrite('cuf', $n)
 # ... and other Tput calls ...

DESCRIPTION

La interfaz Term::Cap le permite controlar las capacidades de su terminal.

Construye sobre la biblioteca terminfo o termcap para obtener información sobre el terminal.

Para obtener más información, consulte la documentación de terminfo o termcap en su sistema.

EXAMPLES

 use Term::Cap;
 my $term = Term::Cap->Tgetent(STDOUT);
 if ($term) {
  print $term->Tgoto(1, 1); # Mover cursor a la esquina superior izquierda
  print $term->Tput('cl'); # Borrar pantalla
  print "Hola, mundo!\n";
 } else {
  print "No se pudo obtener la información del terminal.\n";
 }
