Text::ParseWords(3perl) Guía de referencia para programadores de Perl Text::ParseWords(3perl)

NOMBRE

Text::ParseWords - analiza texto en una lista de tokens o lista de listas

SINOPSIS

use Text::ParseWords;
@listas = nested_quotewords($delimitador, $mantener, @lineas);
@palabras = quotewords($delimitador, $mantener, @lineas);
@palabras = shellwords(@lineas);
@palabras = parse_line($delimitador, $mantener, $linea);
@palabras = old_shellwords(@lineas); # ¡OBSOLETO!

DESCRIPCIÓN

Las funciones nested_quotewords() y quotewords() aceptan un delimitador (que puede ser una expresión regular) y una lista de líneas, y luego las divide en una lista de palabras ignorando los delimitadores que aparecen dentro de comillas. quotewords() devuelve todos los tokens en una única lista larga, mientras que nested_quotewords() devuelve una lista de listas de tokens correspondientes a los elementos de @lineas. parse_line() tokeniza una única cadena. Las funciones *quotewords() simplemente llaman a parse_line(), por lo que si solo estás dividiendo una línea, puedes llamar a parse_line() directamente y ahorrar una llamada a función.

El argumento $mantener controla qué sucede con los delimitadores y los caracteres especiales:

true
Si es verdadero, los tokens se dividen en el delimitador especificado, pero todos los demás caracteres (incluyendo comillas y barras invertidas) se mantienen en los tokens.
false
Si $mantener es falso, las funciones *quotewords() eliminan todas las comillas y barras invertidas que no estén escapadas por barra invertida o dentro de comillas simples (es decir, quotewords() intenta interpretar estos caracteres de manera similar al shell Bourne). Nota: esta semántica es significativamente diferente de la versión original de este módulo distribuida con Perl 5.000 a 5.004.
"delimitadores"
Como característica adicional, $mantener puede ser la palabra clave "delimitadores", lo que hace que las funciones conserven los delimitadores en cada cadena como tokens en las listas de tokens, además de conservar los caracteres de comillas y barras invertidas.

shellwords() está escrita como un caso especial de quotewords(), y realiza la tokenización con espacios en blanco como delimitador, similar a la mayoría de los shells de Unix.

EJEMPLOS

El programa de ejemplo:

use Text::ParseWords;
@palabras = quotewords('\s+', 0, q{this   is "a test" of\ quotewords \"for you});
$i = 0;
foreach (@palabras) {
    print "$i: <$_>\n";
    $i++;
}

produce:

0: <this>
1: <is>
2: <a test>
3: <of quotewords>
4: <"for>
5: <you>

demostrando:

0
una palabra simple
1
se omiten múltiples espacios debido a nuestro $delimitador
2
uso de comillas para incluir un espacio en una palabra
3
uso de una barra invertida para incluir un espacio en una palabra
4
uso de una barra invertida para eliminar el significado especial de una comilla doble
5
otra palabra simple (note la falta de efecto de la comilla doble acentuada por la barra invertida)

Reemplazar "quotewords('\s+', 0, q{this is...})" con "shellwords(q{this is...})" es una forma más sencilla de lograr lo mismo.
