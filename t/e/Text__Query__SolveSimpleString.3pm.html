NOMBRE

Text::Query::SolveSimpleString - Aplica una expresión de consulta a cadenas

SINOPSIS

use Text::Query;
my $q=new Text::Query('+hello +world',
                      -parse => 'Text::Query::ParseSimple',
                      -solve => 'Text::Query::SolveSimpleString',
                      -build => 'Text::Query::BuildSimpleString');
$q->match('this hello is a world')

DESCRIPCIÓN

Aplica una expresión construida por "Text::Query::BuildSimpleString" a una lista de cadenas.

MÉTODOS

match ([OBJETIVO])
Si "OBJETIVO" es un escalar, "match" devuelve un valor verdadero si la cadena especificada por "OBJETIVO" coincide con la expresión de consulta del objeto de consulta. Si "OBJETIVO" no se proporciona, la coincidencia se realiza contra $_.

Si "OBJETIVO" es un array, "match" devuelve una lista (posiblemente vacía) de todos los elementos coincidentes. Si los elementos del array son referencias a sub-arrays, la coincidencia se realiza contra el primer elemento de cada sub-array. Esto permite asociar información arbitraria (por ejemplo, nombres de archivo) con cada cadena para que coincida.

Si "OBJETIVO" es una referencia a un array, "match" devuelve una referencia a una lista (posiblemente vacía) de todos los elementos coincidentes.

matchscalar ([OBJETIVO])
Se comporta igual que "MATCH" cuando "OBJETIVO" es un escalar o no se proporciona. Es ligeramente más rápido que "MATCH" en estas circunstancias.
