NOMBRE

Template::Plugin::GD::Graph::lines - Crear gráficos de líneas con ejes y leyendas

SINOPSIS

[% USE g = GD.Graph.lines(x_size, y_size); %]

EJEMPLOS

[% FILTER null;
    USE g = GD.Graph.lines(300,200);
    x = [1, 2, 3, 4];
    y = [5, 4, 2, 3];
    g.set(
            x_label => 'Etiqueta X',
            y_label => 'Etiqueta Y',
            title => 'Título'
    );
    g.plot([x, y]).png | stdout(1);
   END;
-%]
[% FILTER null;
    data = [
        ["Ene", "Feb", "Mar", "Abr", "May", "Jun", "Jul", "Ago",
                                     "Sep", "Oct", "Nov", "Dic", ],
        [-5, -4, -3, -3, -1,  0,  2,  1,  3,  4,  6,  7],
        [4,   3,  5,  6,  3,1.5, -1, -3, -4, -6, -7, -8],
        [1,   2,  2,  3,  4,  3,  1, -1,  0,  2,  3,  2],
    ];

    USE my_graph = GD.Graph.lines();
    my_graph.set(
            x_label => 'Mes',
            y_label => 'Medida de éxito',
            title => 'Un Gráfico de Líneas Sencillo',
            y_max_value => 8,
            y_min_value => -8,
            y_tick_number => 16,
            y_label_skip => 2,
            box_axis => 0,
            line_width => 3,
            zero_axis_only => 1,
            x_label_position => 1,
            y_label_position => 1,
            x_label_skip => 3,
            x_tick_offset => 2,
            transparent => 0,
    );
    my_graph.set_legend("Nosotros", "Ellos", "Otros");
    my_graph.plot(data).png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Graph.lines proporciona una interfaz a la clase GD::Graph::lines definida por el módulo GD::Graph. Permite que uno o más conjuntos de datos (x,y) se representen como líneas de y frente a x con ejes y leyendas.

Consulta GD::Graph para más detalles.
