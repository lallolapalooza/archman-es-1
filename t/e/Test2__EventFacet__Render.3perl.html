Test2::EventFacet::Render(3perl) Guía del programador de Perl Test2::EventFacet::Render(3perl)

NOMBRE

Test2::EventFacet::Render - Faceta que dicta cómo renderizar un evento.

DESCRIPCIÓN

Esta faceta se utiliza para dictar cómo el evento debe ser renderizado por las herramientas de renderizado estándar de test2. Si esta faceta está presente, SOLO lo que se especifica en ella será renderizado. Se asume que cualquier cosa importante o digna de mención estará presente aquí, ninguna otra faceta será considerada para renderizado/visualización.

Esta faceta es de tipo lista, puedes añadir tantos elementos como necesites.

CAMPOS

$cadena = $render->[#]->{details}
$cadena = $render->[#]->details()
Texto legible por humanos para mostrar.
$cadena = $render->[#]->{tag}
$cadena = $render->[#]->tag()
Etiqueta que debe prefijar/identificar el texto principal.
$cadena = $render->[#]->{facet}
$cadena = $render->[#]->facet()
Opcional, si el texto de visualización se generó a partir de otra faceta, aquí se debe indicar de qué faceta provino.
$modo = $render->[#]->{mode}
$modo = $render->[#]->mode()
calculado
Calculado significa que la faceta se generó a partir de otra faceta. Las facetas calculadas pueden ser borradas y regeneradas cada vez que el estado del evento cambia.
reemplazar
Reemplazar significa que la faceta está destinada a reemplazar el renderizado normal del evento.
