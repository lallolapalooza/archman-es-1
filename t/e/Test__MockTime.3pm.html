Test::MockTime(3) Documentación de Perl aportada por el usuario Test::MockTime(3)

NOMBRE

Test::MockTime - Reemplaza el tiempo real con tiempo simulado

VERSIÓN

Versión 0.17

SINOPSIS

use Test::MockTime qw( :all );
set_relative_time(-600);
# haz algunas pruebas dependiendo de que el tiempo aumente desde hace 600 segundos
set_absolute_time(0);
# haz algunas pruebas más dependiendo de que el tiempo comience desde la época
# la época puede variar según la plataforma. ver perlport.
set_fixed_time(CORE::time());
# haz algunas pruebas más dependiendo de que el tiempo permanezca en la hora actual real
set_absolute_time('1970-01-01T00:00:00Z');
# haz algunas pruebas dependiendo de que el tiempo comience en la hora de la época Unix
set_fixed_time('01/01/1970 00:00:00', '%m/%d/%Y %H:%M:%S');
# haz algunas pruebas dependiendo de que el tiempo permanezca en la hora de la época Unix
restore_time();
# reanuda el servicio normal

DESCRIPCIÓN

Este módulo fue creado para permitir que los conjuntos de pruebas prueben código en puntos específicos del tiempo. Específicamente, reemplaza localtime, gmtime y time en tiempo de compilación y luego depende del usuario que proporcione un tiempo simulado a través de set_relative_time, set_absolute_time o set_fixed_time para alterar futuras llamadas a gmtime, time o localtime.

SUBRUTINAS/MÉTODOS

set_absolute_time
Si se le da un único argumento numérico, el argumento es una hora absoluta (por ejemplo, si se proporciona 0, la hora absoluta será la época), y calcula el desplazamiento para permitir que las llamadas subsiguientes a time, gmtime y localtime reflejen esto.

por ejemplo, en el siguiente código

Test::MockTime::set_absolute_time(0);
my ($start) = time;
sleep 2;
my ($end) = time;

La variable $end debería contener 2 segundos después de la época;

Si se dan dos argumentos, el primer argumento se toma como una hora absoluta en algún formato de cadena (por ejemplo, "01/01/1970 00:00:00"). El segundo argumento se toma como una cadena de formato "strptime" (por ejemplo, "%m/%d/%Y %H:%M:%S"). Si se da un único argumento, pero este no es numérico, se asume una cadena de formato "strptime" de "%Y-%m-%dT%H:%M:%SZ".

por ejemplo, en el siguiente código

Test::MockTime::set_absolute_time('1970-01-01T00:00:00Z');
my ($start) = time;
sleep 2;
my ($end) = time;

La variable $end debería contener 2 segundos después de la época Unix;

set_relative_time($relative)
toma como argumento un valor relativo a la hora actual (por ejemplo, si se proporciona -10, la hora actual se convertirá a la hora real de la máquina - 10 segundos) y calcula el desplazamiento para permitir que las llamadas subsiguientes a time, gmtime y localtime lo reflejen.

por ejemplo, en el siguiente código

my ($start) = time;
Test::MockTime::set_relative_time(-600);
sleep 600;
my ($end) = time;

La variable $end debería contener valores iguales o muy similares a la variable $start.

set_fixed_time
Si se le da un único argumento numérico, el argumento es una hora absoluta (por ejemplo, si se proporciona 0, la hora absoluta será la época). Todas las llamadas subsiguientes a gmtime, localtime y time devolverán este valor.

por ejemplo, en el siguiente código

Test::MockTime::set_fixed_time(time)
my ($start) = time;
sleep 3;
my ($end) = time;

Las variables $end y $start contendrán los mismos resultados

Si se dan dos argumentos, el primer argumento se toma como una hora absoluta en algún formato de cadena (por ejemplo, "01/01/1970 00:00:00"). El segundo argumento se toma como una cadena de formato "strptime" (por ejemplo, "%m/%d/%Y %H:%M:%S"). Si se da un único argumento, pero este no es numérico, se asume una cadena de formato "strptime" de "%Y-%m-%dT%H:%M:%SZ".

restore()
restaura los valores predeterminados de manejo del tiempo. "restore_time" es un alias. Cuando se exporta con la etiqueta 'all', esta subrutina se exporta como "restore_time".

CONFIGURACIÓN Y ENTORNO

Test::MockTime no requiere archivos de configuración ni variables de entorno.

DEPENDENCIAS

Test::MockTime depende de los siguientes módulos de Perl no principales.

•
Time::Piece 1.08 o superior
