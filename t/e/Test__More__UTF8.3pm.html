Test::More::UTF8(3) Documentación de Perl contribuida por el usuario Test::More::UTF8(3)

NOMBRE

Test::More::UTF8 - Mejora de Test::More para proyectos basados en UTF8

SINOPSIS

use Test::More;
use Test::More::UTF8;
# ahora podemos usar cadenas marcadas fácilmente sin advertencias como "Wide character in print ..."
is("\x{410}","\x{420}"); # obtuvimos un mensaje de fallo sin advertencias

LIMITACIONES

Este módulo solo tiene sentido para perl 5.8 y superior

CARACTERÍSTICAS

Este módulo también activa por defecto el pragma utf8. Para desactivarlo, añada la opción "-utf8"

use Test::More::UTF8 qw(-utf8);

Por defecto, se aplicará binmode ':utf8' a todos los manejadores de salida: failure_output, todo_output, output. Es posible elegir solo algunos de ellos

use Test::More::UTF8 qw(failure); # activa :utf8 solo en failure_output
use Test::More::UTF8 qw(todo); # activa :utf8 solo en todo_output
use Test::More::UTF8 qw(out); # activa :utf8 solo en output
