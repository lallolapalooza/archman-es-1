NOMBRE

Template::Base - Módulo de clase base que implementa funcionalidad común

SINOPSIS

package My::Module;
use base qw( Template::Base );
sub _init {
    my ($self, $config) = @_;
    $self->{ doodah } = $config->{ doodah }
        || return $self->error("No se especificó 'doodah'");
    return $self;
}
package main;
my $object = My::Module->new({ doodah => 'foobar' })
    || die My::Module->error();

DESCRIPCIÓN

Módulo de clase base que implementa un constructor y funcionalidad de reporte de errores para varios módulos de Template Toolkit.

MÉTODOS PÚBLICOS

new(\%config)

Método constructor que acepta una referencia a un array de hashes o una lista de parámetros "nombre => valor" que se combinan en un hash. Luego se llama al método _init(), pasándole el hash de configuración, y este debe devolver verdadero/falso para indicar éxito o fracaso. Se devuelve una referencia a un nuevo objeto, o undef en caso de error. Cualquier mensaje de error generado se puede examinar a través del método de clase error() o directamente a través de la variable de paquete $ERROR en la clase derivada.

my $module = My::Module->new({ ... })
    || die My::Module->error(), "\n";
my $module = My::Module->new({ ... })
    || die "error del constructor: $My::Module::ERROR\n";

error($msg, ...)

Puede llamarse como un método de objeto para obtener/establecer el miembro interno "_ERROR" o como un método de clase para obtener/establecer la variable $ERROR en el paquete de la clase derivada.

my $module = My::Module->new({ ... })
    || die My::Module->error(), "\n";
$module->do_something()
    || die $module->error(), "\n";

Cuando se llama con parámetros (múltiples parámetros se concatenan), este método establecerá la variable correspondiente y devolverá undef. Esto se utiliza con frecuencia dentro de métodos de objeto para informar errores al llamador.

package My::Module;
sub foobar {
    my $self = shift;
    # otro código...
    return $self->error('algún tipo de error...')
        if $some_condition;
}

debug($msg, ...)

Genera un mensaje de depuración al concatenar todos los argumentos pasados en una cadena y lo imprime en "STDERR". Se añade un prefijo para indicar el módulo del llamador.

package My::Module;
sub foobar {
    my $self = shift;
    $self->debug('llamado a foobar()');
    # otro código...
}

Cuando se llama al método foobar(), se envía el siguiente mensaje a "STDERR":

[My::Module] llamado a foobar()

Los objetos pueden establecer un valor interno "DEBUG" que el método debug() examinará. Si este valor establece los bits relevantes para indicar "DEBUG_CALLER", entonces el nombre de archivo y el número de línea del llamador se añadirán al mensaje.

use Template::Constants qw( :debug );
my $module = My::Module->new({
    DEBUG => DEBUG_SERVICE | DEBUG_CONTEXT | DEBUG_CALLER,
});
$module->foobar();

Esto genera un mensaje de error como:

[My::Module] llamado a foobar() en My/Module.pm línea 6

module_version()

Devuelve el número de versión de un módulo, tal como se define en la variable de paquete $VERSION.
