NOMBRE

Template::Plugin::GD::Polygon - Interfaz a la clase Polygon del módulo GD

SINOPSIS

[% USE poly = GD.Polygon;
   poly.addPt(50,0);
   poly.addPt(99,99);
%]

EJEMPLOS

[% FILTER null;
    USE im   = GD.Image(100,100);
    USE c    = GD.Constants;
    # asignar algunos colores
    white = im.colorAllocate(255,255,255);
    black = im.colorAllocate(0,  0,  0);
    red   = im.colorAllocate(255,0,  0);
    blue  = im.colorAllocate(0,  0,255);
    green = im.colorAllocate(0,  255,0);
    # hacer el fondo transparente e entrelazado
    im.transparent(white);
    im.interlaced('true');
    # Poner un borde negro a la imagen
    im.rectangle(0,0,99,99,black);
    # Dibujar un óvalo azul
    im.arc(50,50,95,75,0,360,blue);
    # Y rellenarlo de rojo
    im.fill(50,50,red);
    # Dibujar un triángulo azul definiendo un polígono
    USE poly = GD.Polygon;
    poly.addPt(50,0);
    poly.addPt(99,99);
    poly.addPt(0,99);
    im.filledPolygon(poly, blue);
    # Salida de imagen binaria en formato PNG
    im.png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Polygon proporciona una interfaz a la clase GD::Polygon de GD.pm.

Consulta GD para una descripción completa de la biblioteca GD y todos los métodos que se pueden llamar a través del plugin GD.Polygon. Consulta Template::Plugin::GD::Image para la interfaz principal de las funciones GD. Consulta Template::Plugin::GD::Constants para un plugin que permite acceder a las constantes de GD.pm.
