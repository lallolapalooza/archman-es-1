Text::Abbrev(3perl) Guía del programador de Perl Text::Abbrev(3perl)

NOMBRE

Text::Abbrev - abbrev - crea una tabla de abreviaturas a partir de una lista

SINOPSIS

use Text::Abbrev;
abbrev $hashref, LIST

DESCRIPCIÓN

Almacena todas las truncaciones inequívocas de cada elemento de LIST como claves en el array asociativo referenciado por $hashref. Los valores son los elementos originales de la lista.

EJEMPLO

$hashref = abbrev qw(list edit send abort gripe);
%hash = abbrev qw(list edit send abort gripe);
abbrev $hashref, qw(list edit send abort gripe);
abbrev(*hash, qw(list edit send abort gripe));
