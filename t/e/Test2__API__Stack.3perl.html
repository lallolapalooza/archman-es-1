Test2::API::Stack(3perl) Guía de referencia para programadores de Perl Test2::API::Stack(3perl)

NOMBRE

Test2::API::Stack - Objeto para gestionar una pila de instancias de Test2::Hub.

***NOTA INTERNA***

¡Los detalles internos de este paquete están sujetos a cambios en cualquier momento! Los métodos públicos proporcionados no cambiarán de forma incompatible con versiones anteriores, pero los detalles de implementación subyacentes sí. ¡No rompas la encapsulación aquí!

DESCRIPCIÓN

Este módulo se utiliza para representar y gestionar una pila de objetos Test2::Hub. Los hubs suelen estar en una pila para que puedas insertar un nuevo hub que pueda interceptar y manejar eventos de forma diferente al hub principal.

SINOPSIS

my $stack = Test2::API::Stack->new;
my $hub = $stack->top;

MÉTODOS

$stack = Test2::API::Stack->new()
Esto creará una nueva instancia de pila vacía. Se ignoran todos los argumentos.
$hub = $stack->new_hub()
$hub = $stack->new_hub(%params)
$hub = $stack->new_hub(%params, class => $class)
Esto generará un nuevo hub y lo insertará en la parte superior de la pila. Opcionalmente, puedes proporcionar argumentos que se pasarán al constructor del objeto Test2::Hub.

Si especificas el argumento "'class' => $class", el nuevo hub será una instancia de la clase especificada.

A menos que tus parámetros especifiquen los argumentos 'formatter' o 'ipc', el formateador y la instancia IPC se heredarán del hub superior actual. Puedes establecer los parámetros a "undef" para evitar tener un formateador o una instancia IPC.

Si no hay un hub superior y no pides que el IPC y el formateador sean indefinidos, se creará un nuevo formateador y se utilizará la instancia IPC de Test2::API.

$hub = $stack->top()
Esto devolverá el hub superior de la pila. Si aún no hay un hub superior, lo creará.
$hub = $stack->peek()
Esto devolverá el hub superior de la pila. Si aún no hay un hub superior, devolverá undef.
$stack->cull
Esto llamará a "$hub->cull" en todos los hubs de la pila.
@hubs = $stack->all
Esto devolverá todos los hubs de la pila como una lista.
$stack->clear
Esto eliminará completamente todos los hubs de la pila. Normalmente no querrás hacer esto, pero hay algunas razones válidas para ello.
$stack->push($hub)
Esto insertará el nuevo hub en la pila.
$stack->pop($hub)
Esto extraerá un hub de la pila; si el hub en la parte superior de la pila no coincide con el hub que esperas (pasado como argumento), lanzará una excepción.
