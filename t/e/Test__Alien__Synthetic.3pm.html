NOMBRE

Test::Alien::Synthetic - Un objeto alienígena simulado para pruebas

VERSIÓN

versión 2.84

SINOPSIS

use Test2::V0;
use Test::Alien;

my $alien = synthetic {
  cflags => '-I/foo/bar/include',
  libs   => '-L/foo/bar/lib -lbaz',
};

alien_ok $alien;

done_testing;

DESCRIPCIÓN

Esta clase se utiliza para modelar una clase Alien sintética que implementa la interfaz mínima de Alien::Base necesaria para Test::Alien.

Puede ser útil si tienes una distribución Alien que no se basa en Alien::Base y que necesitas probar.

NOTA: El nombre de esta clase puede cambiar en el futuro, así que no te refieras directamente a este nombre de clase. En su lugar, crea instancias de esta clase utilizando la función Test::Alien#synthetic.

ATRIBUTOS

cflags

Cadena que contiene las banderas del compilador

cflags_static

Cadena que contiene las banderas del compilador estáticas

libs

Cadena que contiene el enlazador y las banderas de bibliotecas

libs_static

Cadena que contiene el enlazador estático y las banderas de bibliotecas

dynamic_libs

Referencia de lista que contiene las bibliotecas dinámicas.

bin_dir

Directorio de binarios de herramientas.

runtime_prop

Propiedades en tiempo de ejecución.

EJEMPLO

Aquí tienes un ejemplo completo usando Alien::Libarchive, que es una distribución Alien que no se basa en Alien::Base.

use strict;
use warnings;
use Test2::V0;
use Test::Alien;
use Alien::Libarchive;

my $real = Alien::Libarchive->new;
my $alien = synthetic {
  cflags       => scalar $real->cflags,
  libs         => scalar $real->libs,
  dynamic_libs => [$real->dlls],
};

alien_ok $alien;

xs_ok do { local $/; <DATA> }, with_subtest {
  my($module) = @_;
  my $ptr = $module->archive_read_new;
  like $ptr, qr{^[0-9]+$};
  $module->archive_read_free($ptr);
};

ffi_ok { symbols => [qw( archive_read_new )] }, with_subtest {
  my($ffi) = @_;
  my $new  = $ffi->function(archive_read_new => [] => 'opaque');
  my $free = $ffi->function(archive_read_close => ['opaque'] => 'void');
  my $ptr = $new->();
  like $ptr, qr{^[0-9]+$};
  $free->($ptr);
};

done_testing;

#include "perl.h"
#include "XSUB.h"
#include <archive.h>

    const char *class;
  CODE:
    RETVAL = (void*) archive_read_new();
  OUTPUT:
    RETVAL

void archive_read_free(class, ptr);
    const char *class;
    void *ptr;
