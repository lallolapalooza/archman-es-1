NOMBRE

Test2::Manual::Anatomy::IPC - Manual del sistema IPC.

DESCRIPCIÓN

Este documento describe el sistema IPC.

¿QUÉ ES EL SISTEMA IPC?

El sistema IPC se activa cargando Test2::IPC. Esto hace que los hubs sean conscientes de los procesos/hilos y que reenvíen eventos al proceso/hilo principal según sea necesario.

¿CÓMO AFECTA EL SISTEMA IPC A TODO?

Test2::API y Test2::API::Instance tienen algunos comportamientos que se activan si Test2::IPC se carga antes de que se inicialice el estado global. Principalmente, se iniciará un controlador IPC y se almacenará en el estado global.

Si se inicializa un controlador IPC, todos los hubs se inicializarán con una referencia a la instancia del controlador. Si un hub tiene una instancia de controlador IPC, la usará para reenviar eventos a los procesos e hilos principales.

¿QUÉ HACE UN CONTROLADOR IPC?

Un Test2::IPC::Driver proporciona una forma de enviar datos de eventos a un proceso+hilo+hub de destino (o a todos globalmente). El controlador también debe proporcionar una forma para que un proceso/hilo/hub lea los eventos pendientes que se le han enviado.

¿CÓMO FUNCIONA EL CONTROLADOR IPC POR DEFECTO?

El controlador IPC por defecto es Test2::IPC::Driver::Files. Este controlador por defecto, cuando se inicializa, comienza creando un directorio temporal. Cada vez que un evento necesita ser enviado a otro proceso/hilo/hub, el evento se escribirá en un archivo usando Storable. El archivo se escribe con el proceso, hilo y hub de destino como parte del nombre de archivo. Todos los hubs revisarán regularmente los eventos IPC pendientes y los procesarán.

Este controlador se optimiza aún más utilizando un pequeño bloque de memoria compartida (SHM). Cada vez que se envía un nuevo evento a través de IPC, la SHM se actualiza para tener un nuevo valor. Los hubs no se molestarán en comprobar si hay nuevos eventos IPC a menos que el valor de la SHM haya cambiado desde su última consulta. Un resultado de esto es que el sistema IPC es sorprendentemente rápido y no pierde tiempo consultando el disco duro cuando no hay eventos pendientes.
