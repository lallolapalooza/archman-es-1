NOMBRE

Text::Query::BuildSimpleString - Constructor para Text::Query::ParseSimple para construir expresiones regulares

SINOPSIS

use Text::Query;
my $q=new Text::Query('+hello +world',
                      -parse => 'Text::Query::ParseSimple',
                      -solve => 'Text::Query::SolveSimpleString',
                      -build => 'Text::Query::BuildSimpleString');

DESCRIPCIÓN

Construye una expresión regular para hacer coincidir la consulta simple analizada por Text::Query::ParseSimple. Las palabras de la consulta pueden ser expresiones regulares y proporcionarán el resultado esperado si la opción "-regexp" está establecida.
