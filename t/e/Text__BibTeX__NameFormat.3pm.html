Text::BibTeX::NameFormat(3pm) Documentación de Perl contribuida por el usuario Text::BibTeX::NameFormat(3pm)

NOMBRE

Text::BibTeX::NameFormat - formato de nombres en estilo BibTeX

SINTAXIS

use Text::BibTeX::NameFormat;
$format = Text::BibTeX::NameFormat->($parts, $abbrev_first);
$format->set_text ($part,
                   $pre_part, $post_part,
                   $pre_token, $post_token);
$format->set_options ($part, $abbrev, $join_tokens, $join_part
## Usa el encoding/binmode y el formato de normalización almacenado en $name
$formatted_name = $format->apply ($name);

DESCRIPCIÓN

Después de dividir un nombre en sus componentes (representados como un objeto "Text::BibTeX::Name"), a menudo deseas volver a unirlo de nuevo como una cadena de texto formateada de manera consistente. "Text::BibTeX::NameFormat" proporciona una forma muy flexible de hacer esto, generalmente en dos etapas: primero, crea una "formatación de nombre" que describa cómo unir los tokens y los componentes de cualquier nombre, y luego aplica la forma a un nombre particular.

La "formatación de nombre" está encapsulada en un objeto "Text::BibTeX::NameFormat". El constructor ("new") incluye algunos trucos ingeniosos que significan que puedes casi siempre usarlo solo, sin necesidad de personalizar el objeto de forma significativa. Si es necesario personalizar el objeto, sin embargo, las métodos set_text() y set_options() ofrecen esa capacidad.

Nota: "Text::BibTeX::NameFormat" es un traducción directa del interfaz de la librería C btparse. Esta página de ayuda está diseñada para proporcionar suficiente información para usar la clase Perl, pero para más detalles y ejemplos, consulte bt_format_names.

CONSTANTES

Dos tipos enumerados para manejar nombres y la formatación de nombres han sido trasladados de C a Perl. En la documentación de btparse, verás referencias a "bt_namepart" y "bt_joinmethod". El primero enumera los cuatro "componentes" de un nombre BibTeX: primero, von, último y jr; sus valores (en ambos C y Perl) son "BTN_FIRST", "BTN_VON", "BTN_LAST" y "BTN_JR". El segundo enumera las formas en las que bt_format_name() (la función C que corresponde al método "apply" de "Text::BibTeX::NameFormat") puede unir los tokens vecinos: "BTJ_MAYTIE", "BTJ_SPACE", "BTJ_FORCETIE" y "BTJ_NOTHING". Ambos conjuntos de valores pueden importarse de la modulación "Text::BibTeX" usando los tags de importación "nameparts" y "joinmethods". Por ejemplo:

use Text::BibTeX qw(:nameparts :joinmethods);
use Text::BibTeX::Name;
use Text::BibTeX::NameFormat;

Los valores de "parte" se utilizan para especificar el texto de alrededor o las opciones de formato para cada parte: por ejemplo, puedes proporcionar el texto de "pre-token" o el flag de "abbreviate" para una parte sin afectar otras partes. Los valores de "join methods" son dos de los tres opciones de formato que puedes configurar para una parte: puedes controlar cómo unir los tokens individuales de un nombre ("JR Smith", o "J R Smith", o "J~R Smith") y puedes controlar cómo unir el último token de una parte con la siguiente parte ("la Roche" versus "la~Roche").

MÉTODOS

new(PARTS, ABBREV_FIRST)
Creación de un nuevo formato de nombre, con las dos configuraciones más comunes: qué partes incluir (y en qué orden) y si abbreviar el primer nombre. PARTS debe ser una cadena con máximo cuatro caracteres, representando cada parte que deseas incluir en un nombre formateado (por defecto "fvlj"). Por ejemplo, "fvlj" significa formatear los nombres en orden "primero von último jr", mientras que "vljf" indica "von último jr primero". ABBREV_FIRST es un valor booleano: falso para imprimir el primer nombre completo, y verdadero para abreviarlo con puntos después de cada token y conectivos entre los tokens (por defecto falso). Todos los puntuación y espacios entre tokens son controlables independientemente con los métodos "set_text" y "set_options", aunque estos se usarán raramente; los valores por defecto se eligen de manera sensible basado en los valores de PARTS y ABBREV_FIRST que proporciones. Ver la descripción de bt_create_name_format() en bt_format_names para detalles completos.
set_text (PART, PRE_PART, POST_PART, PRE_TOKEN, POST_TOKEN)
Permitir personalizar algún texto alrededor de una parte del nombre. Cada parte del nombre tiene cuatro posibles bloques de texto que rodean o están dentro de ella: antes/after el parte como un todo, y antes/after cada token dentro de la parte. Por ejemplo, si deseas controlar la puntuación después de cada token en el primer nombre y estás abreviando los nombres, usarías: 
$format->set_text ('first', undef, undef, undef, '');

este código establecería el texto de post-token como cadena vacía, resultando en nombres como "J R Smith". (Normalmente, los nombres abreviados tendrán un punto después de cada token: "J. R. Smith".) Nota: proporcionar "undef" para los otros tres valores deja them inalterados.

Ver bt_format_names para información completa sobre la formateo de nombres.

set_options (PART, ABBREV, JOIN_TOKENS, JOIN_PART)
Permitir personalizar más un formato de nombre: puedes establecer el flag de abreviación y los dos métodos de unión de tokens. Sin embargo, no hay mecanismo para dejar un valor inalterado; debes establecer todo con "set_options".

Por ejemplo, si borrar los puntos de los tokens abreviados en el primer nombre no es suficiente, quieres ahorrar espacio uniendo los tokens abreviados juntos: "JR Smith" en lugar de "J R Smith". Suponiendo que las dos llamadas anteriores hayan sido realizadas, el siguiente hará el trabajo: 

$format->set_options (BTN_FIRST,
                      1,             # mantener el mismo valor para el flag de abreviación
                      BTJ_NOTHING,   # unir los tokens juntos
                      BTJ_SPACE);    # espacio después del último token de la parte

Nota: sin embargo, nos vimos obligados a conocer (y proporcionar) los valores actuales del flag de abreviación y el método de unión de parte después de realizar solo el método de unión intra-part.

apply (NAME)
Una vez que se ha creado y configurado el formato de nombre según tus deseos, puedes usar el método "apply" para formatear cualquier número de nombres. NAME debe ser un objeto "Text::BibTeX::Name" (es decir, un nombre ya separado); "apply" devuelve una cadena que contiene los componentes del nombre formateados según el estructura del "Text::BibTeX::NameFormat" a la que se llama.

EJEMPLOS

Aunque el proceso de dividir y formatear nombres puede sonar complejo y confuso al leer el contenido anterior (así como Text::BibTeX::Name), en realidad es bastante simple. Hay realmente tres pasos a preocuparse: dividir el nombre (crear un objeto "Text::BibTeX::Name"), crear y personalizar el formato y usarlo.

Text::BibTeX::NameFormat(3pm)

NAME

Text::BibTeX::NameFormat – control formatting of BibTeX names

SYNOPSIS

    use Text::BibTeX::NameFormat;
    use Text::BibTeX::Name;

    # Create a name object
    my $name = Text::BibTeX::Name->new('Charles Louis Xavier Joseph de la Vall{\'e}e Poussin');

    # Create a format object
    my $format = Text::BibTeX::NameFormat->new('vljf', 1);

    # Apply the format to the name
    my $formatted_name = $format->apply($name);
    # or
    my $formatted_name = $name->format($format);

DESCRIPTION

This module provides a means of specifying how a Text::BibTeX::Name object should be formatted, and then applying that format.

The primary use case is to provide a way to take a name parsed according to BibTeX's often-complex rules, and reformat it according to a desired style (e.g., "Lastname, Firstname" or "Firstname Lastname", with options for titles, particles, and suffixes).

Formatting is controlled by a format string, described below, and an optional argument that influences the format string.

The general workflow is:

  1. Create a Text::BibTeX::Name object from the raw name string.
  2. Create a Text::BibTeX::NameFormat object, specifying the desired format.
  3. Apply the format to the name object using either the Text::BibTeX::NameFormat::apply method or the Text::BibTeX::Name::format method.

The actual formatting logic is within the Text::BibTeX::NameFormat::apply method. The Text::BibTeX::Name::format method is simply a convenience wrapper.

CONSTANTS

There are no public constants exported by this module.

METHODS

new(FORMAT_STRING, ARG_OPTIONAL)
Creates a new Text::BibTeX::NameFormat object. FORMAT_STRING is a string that controls the order and format of name parts. ARG_OPTIONAL is an optional argument that modifies the formatting behavior based on the FORMAT_STRING. See the section on FORMAT STRINGS below.
apply(NAME_OBJECT)
Takes a Text::BibTeX::Name object, NAME_OBJECT, applies the format rules defined in the NameFormat object, and returns the formatted name string.
format(NAME_OBJECT)
This is a synonym for apply. It is provided for consistency with the Text::BibTeX::Name interface.

FORMAT STRINGS

The FORMAT_STRING controls the output. The string consists of characters representing name parts, optionally modified by modifiers.

The available name part characters are:

f
First name(s).
v
Von part (e.g., "de la").
l
Last name.
j
Jr. part (e.g., "Jr.", "III").
t
Title (e.g., "Sir", "Dame").

The optional ARG_OPTIONAL argument to new determines how multiple occurrences of the same name part character are handled, and how the name parts are abbreviated. It is an integer.

If ARG_OPTIONAL is 0 (or omitted), each part is printed in full as it appears in the name.

If ARG_OPTIONAL is 1, the first name is abbreviated (e.g., "C." instead of "Charles"). The last name, von part, jr part, and title are printed in full.

If ARG_OPTIONAL is 2, both first and last names are abbreviated.

The FORMAT_STRING can also contain modifiers that affect punctuation and spacing:

.
A period will be appended to the preceding token if it is f (first name).
,
A comma will be appended to the preceding token if it is f (first name) or j (jr. part).
~
A non-breaking space (TeX tie) will be inserted between the preceding token and the next token.

The default format string is "vljf" with an optional argument of 0.

Commonly used format strings:

"vljf"
Format: von, last, jr, first. No abbreviations, no extra punctuation.
"vljf", 1
Format: von, last, jr, first. First name abbreviated. Results in "de~la Vall{\'e}e~Poussin, C.~L. X.~J." for the example name.
"vl, f, j"
Format: von, last, comma, first, comma, jr. No abbreviations.
"f l"
Format: first, last. No abbreviations.
"f l", 1
Format: first, last. First name abbreviated.

Note that the formatting rules attempt to be intelligent about spacing and punctuation. For example, if a von part is missing, it won't produce extra spaces or commas.

EXAMPLES

Here's a typical usage scenario. First, create a name object. The first step is covered in Text::BibTeX::Name; here's a brief example:

$orig_name = 'Charles Louis Xavier Joseph de la Vall{\'e}e Poussin';
$name = Text::BibTeX::Name->new($orig_name);

The various parts of the name can now be accessed through "Text::BibTeX::Name" methods; for instance "$name->part('von')" returns the list "("de","la")".

Creating the name format is equally simple:

$format = Text::BibTeX::NameFormat->new('vljf', 1);

creates a format that will print the name in "von last jr first" order, with the first name abbreviated. And for no extra charge, you get the right punctuation at the right place: a comma before any `jr' or `first' tokens, and periods after each `first' token.

For instance, we can perform no further customization on this format, and apply it immediately to $name. There are in fact two ways to do this, depending on whether you prefer to think of it in terms of "Applying the format to a name" or "formatting a name". The first is done with "Text::BibTeX::NameFormat"'s "apply" method:

$formatted_name = $format->apply ($name);

while the second uses "Text::BibTeX::Name"'s "format" method:

$formatted_name = $name->format ($format);

which is just a wrapper around "Text::BibTeX::NameFormat::apply". In either case, the result with the example name and format shown is

de~la Vall{\'e}e~Poussin, C.~L. X.~J.

Note the strategic insertion of TeX "ties" (non-breakable spaces) at sensitive spots in the name. (The exact rules for insertion of discretionary ties are given in bt_format_names.)
