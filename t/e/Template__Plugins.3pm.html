Template::Plugins(3) Documentación Perl aportada por el usuario Template::Plugins(3)

NOMBRE

Template::Plugins - Módulo proveedor de plugins

SINOPSIS

use Template::Plugins;
$plugin_provider = Template::Plugins->new(\%options);
($plugin, $error) = $plugin_provider->fetch($name, @args);

DESCRIPCIÓN

El módulo "Template::Plugins" define una clase proveedora que puede ser usada para cargar e instanciar módulos plugin de Template Toolkit.

MÉTODOS

new(\%params)

Método constructor que instancia y devuelve una referencia a un objeto "Template::Plugins". Una referencia a un hash de configuración puede ser pasada como parámetro. Estas se describen a continuación.

Tenga en cuenta que el módulo frontal Template crea un proveedor "Template::Plugins", pasando todos los elementos de configuración. Por lo tanto, los ejemplos que se muestran a continuación en la forma:

$plugprov = Template::Plugins->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});

también se pueden usar a través del módulo Template como:

$ttengine = Template->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});

así como la forma más explícita de:

$plugprov = Template::Plugins->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});
$ttengine = Template->new({
    LOAD_PLUGINS => [ $plugprov ],
});

fetch($name, @args)

Se llama para solicitar que se proporcione un plugin de un nombre dado. El módulo relevante se carga primero (si es necesario) y se llama al método de clase load() para devolver el nombre de la clase fábrica (normalmente el mismo nombre de paquete) o un objeto fábrica (un prototipo). Luego se llama al método new() como método de clase u objeto contra la fábrica, pasando todos los parámetros restantes.

Devuelve una referencia a un nuevo objeto plugin o "($error, STATUS_ERROR)" en caso de error. También puede devolver "(undef, STATUS_DECLINED)" para rechazar la solicitud. Si "TOLERANT" está configurado, todos los errores se devolverán como rechazos.

OPCIONES DE CONFIGURACIÓN

La siguiente lista resume las opciones de configuración que pueden ser proporcionadas al constructor new() de "Template::Plugins". Por favor, consulte Template::Manual::Config para más detalles y ejemplos de cada opción de configuración en uso.

PLUGINS

La opción PLUGINS puede ser usada para proporcionar una referencia a un hash que mapea nombres de plugins a nombres de módulos Perl.

my $plugins = Template::Plugins->new({
    PLUGINS => {
        cgi => 'MyOrg::Template::Plugin::CGI',
        foo => 'MyOrg::Template::Plugin::Foo',
        bar => 'MyOrg::Template::Plugin::Bar',
    },
});

PLUGIN_BASE

Si un plugin no está definido en el hash PLUGINS, entonces PLUGIN_BASE se usa para intentar construir un nombre de módulo Perl correcto que pueda ser cargado exitosamente.

# PLUGIN_BASE de valor único
my $plugins = Template::Plugins->new({
    PLUGIN_BASE => 'MyOrg::Template::Plugin',
});
# PLUGIN_BASE de valor múltiple
my $plugins = Template::Plugins->new({
    PLUGIN_BASE => [   'MyOrg::Template::Plugin',
                       'YourOrg::Template::Plugin'  ],
});

LOAD_PERL

La opción LOAD_PERL puede ser configurada para permitirle cargar módulos Perl regulares (es decir, aquellos que no residen en "Template::Plugin" o en otro namespace definido por el usuario) como plugins.

Si un plugin no puede ser cargado usando los enfoques PLUGINS o PLUGIN_BASE, entonces, si LOAD_PERL está configurado, el proveedor hará un último intento de cargar el módulo sin anteponer ningún prefijo a la ruta del módulo.

A diferencia de los plugins regulares, los módulos cargados usando LOAD_PERL no reciben una referencia a Template::Context como primer argumento al método constructor new().

TOLERANT

El flag TOLERANT puede ser configurado para indicar que el módulo "Template::Plugins" debe ignorar cualquier error encontrado al cargar un plugin y en su lugar devolver "STATUS_DECLINED".

DEBUG

La opción DEBUG puede ser usada para habilitar mensajes de depuración para el módulo "Template::Plugins" configurándola para incluir el valor "DEBUG_PLUGINS".

use Template::Constants qw( :debug );
my $template = Template->new({
    DEBUG => DEBUG_FILTERS | DEBUG_PLUGINS,
});
