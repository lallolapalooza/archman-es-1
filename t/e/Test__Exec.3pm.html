Test__Exec(3pm)

Paquete: perl-test2-tools-process

Licencias: PerlArtistic

Test::Exec(3) Documentación de Perl contribuida por el usuario Test::Exec(3)

NOMBRE

Test::Exec - Prueba que cierto código llama a exec sin terminar las pruebas

VERSIÓN

versión 0.07

SINOPSIS

use Test::More;
use Test::Exec;

is_deeply exec_arrayref { exec 'foo', 'bar', 'baz' }, [qw( foo bar baz )], '¡ejecución encontrada!';
is exec_arrayref { }, undef, '¡no se ejecutó!';

done_testing;

DESCRIPCIÓN

Test::Exec proporciona las herramientas más sencillas posibles para probar código que podría llamar a "exec", lo que de otro modo terminaría tu prueba llamando a otro programa. Este código debería detectar y capturar las llamadas a "exec", incluso si están dentro de un "eval".

El concepto y la implementación se basaron en Test::Exit, pero aplicados a "exec" en lugar de a "exit".

FUNCIONES

exec_arrayref

exec_arrayref { ... }

ejecuta el código dado. Si el código llama a "exec", esta función devolverá un arrayref con sus argumentos. Si el código nunca llama a "exec", devolverá "undef".

never_exec_ok

never_exec_ok { ... }

Ejecuta el código dado. Si el código llama a "exec", entonces la prueba fallará (pero exec será interceptado y no se realizará).

PRECAUCIONES

Este módulo instala su propia versión de "exec" en "CORE::GLOBAL::exec", y puede interactuar mal con cualquier otro código que también esté intentando hacer tales cosas.

VER TAMBIÉN

Test::Exit
Muy similar a (e inspiración de) este módulo, pero para pruebas de "exit" en lugar de "exec".
Test::Mock::Cmd
Proporciona una interfaz para simular "system", "qx" y "exec".
