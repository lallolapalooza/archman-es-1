NOMBRE

Text::Kakasi::JP - Text::Kakasi inversor kanji kana simple

SINOPIS

use Text::Kakasi;
# funcional
$res = Text::Kakasi::getopt_argv('kakasi', '-ieuc', '-w');
$str = Text::Kakasi::do_kakasi($texto_japones);
# orientado a objetos
$obj = Text::Kakasi->new('-ieuc','-w');
$str = $obj->get($texto_japones);

DESCRIPCIÓN

El módulo Text::Kakasi es un módulo Perl que envuelve kakasi (kanji kana simple inversor), un programa que convierte texto japonés a romaji, hiragana, katakana, etc. kakasi puede usarse como método de entrada para convertir entre diferentes escrituras y sistemas de codificación, y como herramienta de procesamiento de texto para convertir diferentes escrituras y sistemas de codificación. kakasi es una herramienta muy útil para convertir el texto japonés que se encuentra en Internet. Puede encontrar más información sobre kakasi en http://kakasi.namazu.org/.

Text::Kakasi es un módulo que proporciona una interfaz Perl para el programa kakasi, proporcionando el mismo conjunto de funcionalidades. Este módulo se basa en la versión 1.05 de kakasi y es compatible al 100% con Perl 5.8 y versiones posteriores. Sin embargo, el módulo Text::Kakasi utiliza la biblioteca kakasi de forma interna, por lo que no podrá utilizarlo si no tiene la biblioteca kakasi instalada en su sistema.

APIS FUNCIONALES

Debido a que las funciones de Text::Kakasi son exportadas a Text::Kakasi por defecto, usted no necesita poner explícitamente el prefijo "Text::Kakasi::" antes de llamar a las funciones. Sin embargo, si desea importar explícitamente las funciones que necesita, puede hacerlo de la siguiente manera:

use Text::Kakasi qw/getopt_argv do_kakasi/
$err = getopt_argv($arg1, $arg2, ...)
Esta función configura kakasi. Los argumentos son los mismos que los argumentos de línea de comandos de kakasi. Por ejemplo, si ejecuta kakasi con los siguientes argumentos de línea de comandos: 
kakasi -ieuc -w
entonces llamará a la función de la siguiente manera: 
Text::Kakasi::getopt_argv('-ieuc', '-w');
El valor de retorno de esta función es 0 si la configuración fue exitosa, y un valor distinto de cero si ocurrió un error.

Si la llamada a la función es exitosa, devolverá 0, de lo contrario devolverá un valor distinto de cero. Esta función es sólo una interfaz para la configuración de kakasi. Si usted quiere realizar la conversión, tiene que llamar a la función do_kakasi o get.

Esta función realiza la conversión kakasi en la cadena $str. Si la cadena es vacía o si ocurre un error durante la conversión, la función devolverá "undef".

Para la versión 1.x, las llamadas a "kakasi" requieren que las opciones se establezcan utilizando la función getopt_argv() antes de llamar a la función do_kakasi(). Sin embargo, esto no es necesario si se utiliza la interfaz orientada a objetos.

NAME

Text::Kakasi - Japanese morpheme analyzer

SYNOPSIS

use Text::Kakasi;

# Functional API
getopt_argv('-w'); # -w: word split, -s: skip unknown, -r: romaji, -H: Hiragana, -K: Katakana, -J: Kanji
$processed = do_kakasi($raw_japanese);

# OOP API
my $k = Text::Kakasi->new();
$processed = $k->set('-w')->get($raw_japanese);

# You can chain the calls
$processed = Text::Kakasi->new->set('-w')->get($raw_japanese);

DESCRIPTION

Text::Kakasi is a Japanese morpheme analyzer. It takes Japanese text as input and outputs the result in various forms, such as romaji, hiragana, katakana, or kanji.

Text::Kakasi has two APIs: Functional API and Object-Oriented API.

Functional APIs

getopt_argv($args ...)
This function is equivalent to calling kakasi(1) command line options. The options are parsed using Text::Kakasi::getopt_argv. The default values are used if no arguments are given. 
# Default:
getopt_argv(); # Equivalent to kakasi -Ja -Ka -Ha -Ma -E -U -S
# Example:
getopt_argv('-w'); # Equivalent to kakasi -w

Note that getopt_argv() affects the global state. It is recommended to use the OOP API if you need to process multiple texts with different settings.

$processed = do_kakasi($raw_japanese);
This function is equivalent to calling Text::Kakasi::do_kakasi() in the OOP API. It takes Japanese text as input and returns the processed text based on the current settings from getopt_argv(). 
# Functional
getopt_argv('-w');
$processed = do_kakasi($raw_japanese);

If getopt_argv() is not called before do_kakasi(), the default settings will be used.

Object-Oriented APIs

Version 2.0 introduced Object-Oriented APIs. The functional APIs described above are just wrappers for the methods of the Text::Kakasi object (OOP). This API is more flexible and recommended for general use.

$k = Text::Kakasi->new($args ...)
Creates a new Text::Kakasi object. This is equivalent to calling Text::Kakasi->new->set($args ...). It allows you to pass arguments directly to the constructor. 
# Functional API style:
my $k = Text::Kakasi->new;
$k->set('-w');
# OOP API style:
my $k = Text::Kakasi->new('-w');

The set() method is called internally if arguments are provided to new(). This makes it easier to configure the object during creation.

$k->set($args ...)
This method sets the options for the Text::Kakasi object. It is similar to getopt_argv() but operates on the object itself. 
my $k = Text::Kakasi->new;
$k->set('-w'); # Text::Kakasi::getopt_argv('-w');

You can chain multiple set() calls or pass multiple arguments at once. The set() method returns the object itself, allowing for method chaining. This is useful for setting multiple options and then calling get() immediately.

my $tokenized = $k->set('-w')->get($raw_japanese);

If there's an error during option parsing, you can retrieve the error message using "$k->error".

$k->error
Returns the error message if there was an error during the initialization or setting of options. Returns undef if no error occurred.
$processed = $k->get($raw_japanese);
This method performs the Kakasi processing on the given Japanese text. It is equivalent to calling do_kakasi() in the functional API. The processing is done based on the options set using set(). 
# Functional
getopt_argv('-w'); $processed = do_kakasi($raw_japanese);
# OOP
$k->set('-w')->get($raw_japanese);

Perl 5.8 Features

Perl 5.8 introduced built-in support for character encodings through the Encode module. Text::Kakasi leverages this feature to handle various encodings more robustly. By default, Kakasi operates on bytes, but with Perl 5.8 and later, you can specify input and output encodings using the -i and -o options respectively.

$result = $k->set(qw/-iutf8 -outf8 -w/)->get($utf8);

This is significantly more convenient than the old way.

$euc = encode('eucjp' => $utf8);
getopt_argv('-w');
$tmp = do_kakasi($euc);
$result = decode('eucjp' => $tmp);

When "-outf8" is specified, $k->get returns a UTF-8 string. Otherwise, it returns the result in the same encoding as the input.

If $Text::Kakasi::HAS_ENCODE is 0, it means that the Encode module is not available or not working correctly. In such cases, Text::Kakasi will fall back to byte-level processing. Users are advised to ensure that the Encode module is installed and functioning properly if they intend to use character encoding features.

DESCRIPTION

Text::Kakasi::JP is a Perl module that provides an interface to the Kakasi (Kanji Analysis and Conversion Library) library. Kakasi is a powerful tool for Japanese morphological analysis, allowing you to decompose Japanese text into its constituent words and convert Kanji to Hiragana, Katakana, or Romaji.

This module allows you to use Kakasi's functionality directly from Perl, making it easy to integrate Japanese text processing into your Perl scripts.

Constructor

new(%options)
Creates a new Text::Kakasi::JP object. The %options hash allows you to configure the behavior of the Kakasi library. Common options include:
  • input_mode: Specifies the character encoding of the input string. Possible values include 'UTF8', 'EUC', 'SJIS', 'JIS7', 'JIS7_2', 'JIS2004', 'JIS2004_2', 'JIS2004_3', 'JIS2004_4', 'UNICODE', 'UNICODE2', 'UNICODE3', 'UTF7', 'UTF16', 'UTF16BE', 'UTF16LE', 'UTF32', 'UTF32BE', 'UTF32LE', 'UJIS'.
  • output_mode: Specifies the character encoding for the output. Same possible values as input_mode.
  • mode: Specifies the analysis mode. Common values are 'JIS7' (default), 'JIS7_2', 'JIS2004', 'JIS2004_2', 'JIS2004_3', 'JIS2004_4'.
  • coding: A shortcut for setting both input_mode and output_mode to the same value.
  • filter: Enables or disables specific filters. For example, 'filter' => 'hiragana' would apply the hiragana filter.
See the Kakasi documentation for a complete list of options.

Methods

parse(TEXT)
Parses the input TEXT and returns an array of hashes. Each hash represents a word and contains keys like 'orig' (original word), 'base' (base form), 'reading' (Hiragana reading), and 'kana' (Katakana reading). The character encoding of the returned data is determined by the output_mode set in the constructor.
convert(TEXT, MODE)
Converts the input TEXT to the specified MODE. The MODE can be one of the output encoding formats listed for output_mode in the constructor. This method is a convenient way to directly obtain the processed text in a desired format without manually iterating through the results of parse().
set_option(NAME, VALUE)
Sets a specific option for the Kakasi object after it has been created.
get_option(NAME)
Retrieves the value of a specific option.

Object-Oriented APIs

This module provides an object-oriented interface to the Kakasi library. You create an instance of the Text::Kakasi::JP class and then call its methods (parse, convert, etc.) on that instance. This approach allows you to maintain different configurations for Kakasi analysis within your script if needed.

Perl 5.8 Features

This module is compatible with Perl 5.8 and later. It utilizes standard Perl features and does not require any special version-specific syntax that would hinder compatibility with older Perl versions.
