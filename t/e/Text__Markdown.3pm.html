Text::Markdown(3) Documentación de Perl contribuida por el usuario Text::Markdown(3)

NOMBRE

Text::Markdown - Convertir sintaxis Markdown a (X)HTML

SINOPSIS

use Text::Markdown 'markdown';
my $html = markdown($text);
use Text::Markdown 'markdown';
my $html = markdown( $text, {
    empty_element_suffix => '>',
    tab_width => 2,
} );
use Text::Markdown;
my $m = Text::Markdown->new;
my $html = $m->markdown($text);
use Text::Markdown;
my $m = Text::MultiMarkdown->new(
    empty_element_suffix => '>',
    tab_width => 2,
);
my $html = $m->markdown( $text );

DESCRIPCIÓN

Markdown es un filtro de texto a HTML; traduce un formato de texto estructurado fácil de leer / fácil de escribir a HTML. El formato de texto de Markdown es muy similar al del correo electrónico de texto plano y admite características como encabezados, *énfasis*, bloques de código, citas en bloque y enlaces.

La sintaxis de Markdown no está diseñada como un lenguaje de marcado genérico, sino específicamente para servir como front-end para (X)HTML. Puede usar etiquetas HTML a nivel de span en cualquier lugar de un documento Markdown, y también puede usar etiquetas HTML a nivel de bloque (como <div> y <table>).

SINTAXIS

Este módulo implementa la sintaxis de Markdown 'original' de:

http://daringfireball.net/projects/markdown/

Tenga en cuenta que Text::Markdown asegura que la salida siempre termine con un salto de línea. El hecho de que los saltos de línea múltiples se colapsen en uno tiene sentido, ya que este es el comportamiento de HTML hacia los espacios en blanco. El hecho de que siempre haya un salto de línea al final tiene sentido nuevamente, dado que la salida siempre estará anidada en un elemento de nivel de bloque (en contraposición a un elemento en línea). Ese elemento de bloque puede ser un "<p>" (la mayoría de las veces), o una "<table>".

Markdown no se interpreta en elementos HTML a nivel de bloque, para que los fragmentos de HTML pegados (por ejemplo, widgets de JavaScript, contadores web) no se interpreten de forma mágica (mal). Para el procesamiento selectivo de Markdown en algunos, pero no en otros, elementos HTML de bloque, agregue un atributo "markdown" al elemento de bloque y establezca su valor a 1, "on" o "yes":

<div markdown="1" class="navbar">
* Inicio
* Acerca de
* Contacto
<div>

El atributo extra "markdown" se eliminará al generar la salida.

OPCIONES

Text::Markdown admite una serie de opciones para su procesador que controlan el comportamiento del documento de salida.

Estas opciones se pueden proporcionar al constructor, o en un hash dentro de llamadas individuales al método "markdown". Consulte la SINOPSIS para ver ejemplos de ambos estilos.

Las opciones para el procesador son:

empty_element_suffix
Esta opción controla el final de las etiquetas de elementos vacíos: 
'/>' para XHTML (por defecto)
'>' para HTML
tab_width
Controla el ancho de la indentación en el marcado generado. Por defecto es 4.
trust_list_start_value
Si es verdadero, las listas ordenadas usarán el primer número como punto de partida para la numeración. Esto le permitirá continuar donde lo dejó escribiendo: 
1. foo
2. bar
párrafo
3. baz
6. quux

(Tenga en cuenta que en el anterior, quux se numerará como 4.)

MÉTODOS

new

Un constructor simple, consulte las secciones SINTAXIS y OPCIONES para obtener más información.

markdown

La función principal en lo que respecta al mundo exterior. Consulte la SINOPSIS para obtener detalles sobre su uso.

urls

Devuelve una referencia a un hash con la clave siendo la referencia markdown y el valor siendo la URL.

Útil para crear scripts que preprocesan una lista de enlaces antes del contenido principal. Consulte t/05options.t para ver un ejemplo de este hashref devuelto al método markdown para crear enlaces.

OTRAS IMPLEMENTACIONES

Markdown ha sido reimplementado en varios idiomas y con varias adiciones.

Los que he encontrado se enumeran a continuación:

C - <http://www.pell.portland.or.us/~orc/Code/discount>
Discount - Markdown original, pero en C. La implementación más rápida disponible y pasa MDTest. Agrega su propio conjunto de características personalizadas.
python - <http://www.freewisdom.org/projects/python-markdown/>
Python Markdown, que es en su mayor parte compatible con el original, con una interesante API de extensiones.
ruby (maruku) - <http://maruku.rubyforge.org/>
Una de las implementaciones más agradables que existen. Construye un árbol de análisis internamente, por lo que es muy flexible.
php - <http://michelf.com/projects/php-markdown/>
Una portación directa de Markdown.pl, también tiene una versión 'extra' mantenida por separado, que agrega varias características que fueron tomadas prestadas por MultiMarkdown.
lua - <http://www.frykholm.se/files/markdown.lua>
Port a lua. Simple y ligero (como es lua).
haskell - <http://johnmacfarlane.net/pandoc/>
Pandoc es una biblioteca más general, que admite Markdown, reStructuredText, LaTeX y más.
javascript - <http://www.attacklab.net/showdown-gui.html>
Port directo (más o menos) de Markdown.pl a JavaScript

ESTA DISTRIBUCIÓN

Tenga en cuenta que esta distribución es una bifurcación del proyecto original Markdown de John Gruber, y *no* está aprobada por él de ninguna manera.

Aunque este código tiene como objetivo ser compatible con el Markdown.pl original (e incorpora y pasa la suite de pruebas de Markdown), al tiempo que corrige una serie de errores en el original, puede haber diferencias entre el comportamiento de este módulo y Markdown.pl. Si encuentra alguna diferencia en la que crea que Text::Markdown se comporta de manera contraria a la especificación de Markdown, infórmelo como un error.

Text::Markdown *no* extiende el dialecto de markdown de ninguna manera de lo que se documenta en daringfireball. Si desea características adicionales, debería considerar Text::MultiMarkdown.

Perl module to convert Markdown text to HTML

NAME

Text::Markdown - Perl module to convert Markdown text to HTML

SYNOPSIS

 use Text::Markdown;
 my $text = "This is *italic* text.\n\nThis is **bold** text.";
 my $html = markdown($text);
 print $html;
 # Output:
 # <p>This is <em>italic</em> text.</p>
 #
 # <p>This is <strong>bold</strong> text.</p>

DESCRIPTION

This module implements the Markdown conversion syntax described at http://daringfireball.net/projects/markdown/. It provides a single function, markdown, which takes a string containing Markdown text and returns a string containing the equivalent HTML.

The implementation aims for compliance with the original specifications.

SYNTAX

The module uses the standard Markdown syntax. For details, please refer to the official Markdown documentation:

See also:
http://daringfireball.net/projects/markdown/

OPTIONS

The markdown function accepts an optional hashref of options to modify its behavior. The available options are:

safe
If set to a true value, the output will be "safely" encoded. This means that HTML tags within the input will be converted to entities, and any potential XSS vulnerabilities will be mitigated. Defaults to false.
entities
If set to a true value, non-ASCII characters will be converted to HTML entities. Defaults to false.

Example:

 my $html = markdown($text, { safe => 1, entities => 1 });

METHODS

This module provides a single function, markdown. There are no object-oriented methods available.

OTHER IMPLEMENTATIONS

There are several other implementations of Markdown in Perl, including:

  • Text::Markdown::Discount - a wrapper around the Discount C library.
  • Markdown - another implementation.
  • Text::MultiMarkdown - an extension of Markdown with additional features.
