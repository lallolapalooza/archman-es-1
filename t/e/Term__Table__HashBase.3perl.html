Term::Table::HashBase(3perl) Guía del Programador de Perl Term::Table::HashBase(3perl)

NOMBRE

Term::Table::HashBase - Construye clases basadas en hashes.

SINOPSIS

Una clase:

package My::Class;
use strict;
use warnings;
# Genera 3 accesores
use Term::Table::HashBase qw/foo -bar ^baz <bat >ban +boo/;
# Oportunidad para inicializar valores predeterminados
sub init {
    my $self = shift;    # Ningún otro argumento
    $self->{+FOO} ||= "foo";
    $self->{+BAR} ||= "bar";
    $self->{+BAZ} ||= "baz";
    $self->{+BAT} ||= "bat";
    $self->{+BAN} ||= "ban";
    $self->{+BOO} ||= "boo";
}
sub print {
    print join ", " => map { $self->{$_} } FOO, BAR, BAZ, BAT, BAN, BOO;
}

Subclasearla

package My::Subclass;
use strict;
use warnings;
# Nota, deberías subclasear antes de cargar HashBase.
use base 'My::Class';
use Term::Table::HashBase qw/bub/;
sub init {
    my $self = shift;
    # Obtenemos las constantes de la clase base de forma gratuita.
    $self->{+FOO} ||= 'SubFoo';
    $self->{+BUB} ||= 'bub';
    $self->SUPER::init();
}

Usarla:

package main;
use strict;
use warnings;
use My::Class;
# Todas estas son funcionalmente idénticas
my $one   = My::Class->new(foo => 'MyFoo', bar => 'MyBar');
my $two   = My::Class->new({foo => 'MyFoo', bar => 'MyBar'});
my $three = My::Class->new(['MyFoo', 'MyBar']);
# ¡Lectores!
my $foo = $one->foo;    # 'MyFoo'
my $bar = $one->bar;    # 'MyBar'
my $baz = $one->baz;    # Valor predeterminado: 'baz'
my $bat = $one->bat;    # Valor predeterminado: 'bat'
# '>ban' significa solo asignador, sin lector
# '+boo' significa sin asignador ni lector, solo la constante BOO
# ¡Asignadores!
$one->set_foo('A Foo');
#'-bar' significa solo lectura, por lo que el asignador lanzará una excepción (pero está definido).
$one->set_bar('A bar');
# '^baz' significa asignador obsoleto, esto advertirá que el asignador
# está obsoleto.
$one->set_baz('A Baz');
# '<bat' significa que no hay asignador definido en absoluto
# '+boo' significa sin asignador ni lector, solo la constante BOO
$one->{+FOO} = 'xxx';

DESCRIPCIÓN

Este paquete se utiliza para generar clases basadas en referencias a hashes. El uso de esta clase te proporcionará un método new(), además de generar los accesores que solicites. Los accesores generados serán lectores (getters), y también se generarán asignadores "set_ACCESOR" para ti. También obtienes constantes para cada accesor (en mayúsculas) que devuelven la clave en el hash para ese accesor. También se admite la herencia simple.

MÉTODOS

PROPORCIONADOS POR HASH BASE

$it = $class->new(%PARES)
$it = $class->new(\%PARES)
$it = $class->new(\@VALORES_ORDENADOS)
Crea una nueva instancia.

HashBase no exportará new() si ya existe un método new() en la cadena de herencia de tu paquete.

Si no quieres este método, puedes definir el tuyo propio, solo tienes que declararlo antes de cargar Term::Table::HashBase.

package My::Package;
# Predeclarar new() para que HashBase no nos dé uno.
sub new;
use Term::Table::HashBase qw/foo bar baz/;
# Ahora definimos nuestro propio método new.
sub new { ... }

Esto hace que HashBase vea que tienes tu propio método new(). Alternativamente, puedes definir el método antes de cargar HashBase en lugar de simplemente declararlo, pero eso dispersa tus declaraciones `use`.

La forma más común de crear un objeto es pasar pares clave/valor, donde cada clave es un atributo y cada valor es lo que deseas asignar a ese atributo. No se realiza ninguna comprobación para verificar si los atributos o valores son válidos; puedes hacerlo en init() si lo deseas.

Si lo deseas, puedes pasar una referencia a hash en lugar de pares. Cuando lo hagas, la referencia a hash se copiará, y la copia se devolverá "bendecida" como un objeto. No hay forma de pedirle a HashBase que "bendiga" una referencia a hash específica.

En algunos casos, un objeto puede tener solo 1 o 2 atributos, en cuyo caso una referencia a hash puede ser demasiado verbosa para tu gusto. En estos casos, puedes pasar una referencia a array con solo valores. Los valores se asignarán a los atributos en el orden en que se enumeraron los atributos. Cuando haya herencia involucrada, los atributos de las clases padre vendrán antes que los de las subclases.

GANCHOS

$self->init()
Esto te da la oportunidad de establecer algunos valores predeterminados para tus campos. El único argumento es $self con sus índices ya establecidos desde el constructor.

Nota: Term::Table::HashBase busca un método `init` usando "$class->can('init')" durante la construcción. NO llama a can() en el objeto creado. Ten en cuenta también que el resultado de la comprobación se almacena en caché; solo se comprueba una vez, la primera vez que se crea una instancia de tu clase. Esto significa que agregar un método init() DESPUÉS de la primera construcción dará como resultado que sea ignorado.

ACCESORES

LECTURA/ESCRITURA

Para generar accesores, los enumeras al usar el módulo:

use Term::Table::HashBase qw/foo/;

Esto generará las siguientes subrutinas en tu espacio de nombres:

foo()
Lector (getter), se utiliza para obtener el valor del campo "foo".
set_foo()
Asignador (setter), se utiliza para establecer el valor del campo "foo".
FOO()
Constante, devuelve la clave del campo "foo" en el hash de la clase. Las subclases también obtendrán esta función como una constante, no simplemente como un método; eso significa que se copia en el espacio de nombres de la subclase.

La razón principal para usar estas constantes es ayudar a evitar errores de ortografía y errores tipográficos similares. No te ayudará si olvidas prefijar el '+'.

SOLO LECTURA

use Term::Table::HashBase qw/-foo/;
set_foo()
Lanza una excepción indicándote que el atributo es de solo lectura. Esto se exporta para anular cualquier asignador activo para el atributo en una clase padre.

ASIGNADOR OBSOLETO

use Term::Table::HashBase qw/^foo/;
set_foo()
Esto establecerá el valor, pero también te advertirá que el método está obsoleto.

SIN ASIGNADOR

use Term::Table::HashBase qw/<foo/;

Solo te proporciona un lector, no se define ningún método "set_foo" en absoluto.

SIN LECTOR

use Term::Table::HashBase qw/>foo/;

Solo te proporciona un asignador ("set_foo"), no se define ningún método "foo" en absoluto.

SOLO CONSTANTE

use Term::Table::HashBase qw/+foo/;

Esto no crea ningún método para ti, solo agrega la constante "FOO".

SUBCLASES

HERENCIA SIMPLE

Para usar la herencia, simplemente usa base como lo harías normalmente. Cuando uses Term::Table::HashBase en una subclase, debes asegurarte de que se llame a la superclase init(). Si tu subclase necesita definir sus propias constantes, o si desea anular el comportamiento de un accesador en la clase padre, puede hacerlo. En el siguiente ejemplo, definimos un nuevo atributo `bub` y anulamos `foo`.

package My::Class;
use strict;
use warnings;
use Term::Table::HashBase qw/foo bar/;
sub init {
    my $self = shift;
    $self->{+FOO} ||= 'DefaultFoo';
    $self->{+BAR} ||= 'DefaultBar';
}
package My::Subclass;
use base 'My::Class';
use Term::Table::HashBase qw/bub -foo/;
# Nota:
# '-foo' aquí significa que definimos un accesador que lanza una excepción
# para set_foo().
# Si no se especifica lo contrario, las constantes de la clase padre (FOO, BAR)
# son también accesibles desde aquí.
sub init {
    my $self = shift;
    # Esta es la forma estándar de inicializar tus propios campos.
    $self->{+BUB} ||= 'DefaultBub';
    # Y aquí es como inicializamos campos de la clase padre.
    # No hay diferencia entre $self->{+FOO} y $self->FOO() aquí.
    $self->{+FOO} ||= 'SubclassFoo';
    # Si tuvieras que llamar a SUPER::init() entonces tu
    # $self->{+FOO} ||= 'SubclassFoo' würde überschrieben,
    # y no se le estaría dando un valor predeterminado, sino que se estaría
    # estableciendo después de que SUPER::init() establezca uno.
    # Así que tienes que llamar a SUPER::init() DESPUÉS de esto.
    $self->SUPER::init();
}
# Sobrescribe el lector
sub foo {
    my $self = shift;
    return "foo is: " . $self->BAR; # Nota el uso de BAR aquí
}

SUBCLASSING

Puedes crear una subclase de una clase HashBase existente.

use base 'Another::HashBase::Class';
use Term::Table::HashBase qw/foo bar baz/;

La clase base se añade a @ISA por ti, y todas las constantes de las clases base se añaden automáticamente a las subclases.

OBTENER UNA LISTA DE ATRIBUTOS PARA UNA CLASE

Term::Table::HashBase proporciona una función para recuperar una lista de atributos para una clase Term::Table::HashBase.

@list = Term::Table::HashBase::attr_list($class)
@list = $class->Term::Table::HashBase::attr_list()
Cualquiera de las dos formas anteriores funcionará. Esto devolverá una lista de atributos definidos en el objeto. Esta lista se devuelve en el orden de definición de atributos; los atributos de la clase padre se listan antes que los atributos de la subclase. Los atributos duplicados se eliminarán antes de devolver la lista.

Nota: Esta lista se utiliza en el constructor "$class->new(\@ARRAY)" para determinar el atributo al que se emparejará cada valor.
