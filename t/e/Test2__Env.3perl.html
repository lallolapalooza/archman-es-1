Test2::Env(3perl) Guía de referencia para programadores de Perl Test2::Env(3perl)

NOMBRE

Test2::Env - Documentación para variables de entorno usadas o establecidas por Test2.

DESCRIPCIÓN

Esta es una lista de variables de entorno que son establecidas o leídas por Test2.

AUTHOR_TESTING

Esta variable de entorno es leída por Test2. Cuando se establece, Test2 ejecutará pruebas que normalmente se omiten, a menos que un autor del módulo esté realizando pruebas adicionales específicas del autor.

AUTOMATED_TESTING

Esta variable de entorno es leída por Test2. Cuando se establece, indica que las pruebas están siendo ejecutadas por un sistema automatizado y no es posible la interacción humana.

Ver Test2::Require::AuthorTesting.

EXTENDED_TESTING

Esta variable de entorno es leída por Test2. Cuando se establece, indica que se ejecutarán pruebas extendidas que normalmente deberían omitirse.

Ver Test2::Require::ExtendedTesting.

HARNESS_ACTIVE

Esta variable de entorno es leída por Test2. Normalmente es establecida por "prove" (Test::Harness) o "yath" (App::Yath).

NONINTERACTIVE_TESTING

Esta variable de entorno es leída por Test2. Cuando se establece, indica que las pruebas no serán interactivas.

Ver Test2::Require::NonInteractiveTesting.

RELEASE_TESTING

Esta variable de entorno es leída por Test2. Cuando se establece, indica que se están realizando pruebas de lanzamiento, lo que puede ejecutar más pruebas de lo normal.

Ver Test2::Require::ReleaseTesting.

T2_FORMATTER

Esto se puede usar para establecer el formateador que usará Test2. Si se establece en una cadena sin prefijo '+', entonces se agregará 'Test2::Formatter::' al principio del nombre del módulo. Si el '+' está presente, se eliminará y no se realizarán más modificaciones al nombre del módulo.

T2_IN_PRELOAD

Test2 establece esto cuando el modo de precarga está activo. Esto se usa principalmente para App::Yath y herramientas similares que precargan Test2, y luego bifurcan para ejecutar pruebas.

TABLE_TERM_SIZE

Esto se usa para establecer un ancho de terminal para cosas como tablas de mensajes de diagnóstico.

TEST2_ACTIVE

Test2 establece esta variable cuando se están ejecutando pruebas.

TEST2_ENABLE_PLUGINS

Esto se puede usar para forzar la carga de plugins cuando se carga la API de Test2. Toma una lista de uno o más nombres de plugins separados por comas. Si el nombre del módulo no tiene un '+' delante, se asume y se agrega el espacio de nombres "Test2::Plugin::". Si un '+' está presente al principio de un nombre de módulo, se eliminará y no se realizarán más modificaciones.

Ejemplos:

TEST2_ENABLE_PLUGINS=BailOnFail
Test2_ENABLE_PLUGINS=SRand,+My::Plugin::Name

TEST_ACTIVE

Establecido por Test2 cuando se están ejecutando pruebas.

TS_MAX_DELTA

Se utiliza para determinar cuántas líneas como máximo de salida se proporcionarán cuando is() encuentre una discrepancia de estructura de datos profunda.

FUENTE

El repositorio de código fuente de Test2-Suite se puede encontrar en https://github.com/Test-More/test-more/.
