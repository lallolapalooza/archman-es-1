Test2::Warnings(3) Documentación aportada por el usuario de Perl Test2::Warnings(3)

NOMBRE

Test2::Warnings - Probar advertencias y la falta de ellas

VERSIÓN

versión 0.038

SINOPSIS

use Test2::V0;
use Test::Warnings;
pass('yay!');
done_testing;

emite TAP:

ok 1 - yay!
ok 2 - no hay advertencias (inesperadas) (a través de done_testing)
1..2

y:

use Test::More tests => 3;
use Test::Warnings 0.005 ':all';
pass('yay!');
like(warning { warn "oh noes!" }, qr/^oh noes/, 'advertimos');

emite TAP:

ok 1 - yay!
ok 2 - advertimos
ok 3 - no hay advertencias (inesperadas) (a través del bloque END)
1..3

DESCRIPCIÓN

Ver Test::Warnings para la documentación completa.

Por ahora, este es un simple envoltorio alrededor de Test::Warnings, pero existe un plan para convertirlo en un puerto completo y eliminar toda la compatibilidad antigua de Test::Builder y usar el conjunto de pruebas de Test2 correctamente.
