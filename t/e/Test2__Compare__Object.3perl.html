Test2::Compare::Object(3perl) Guía de referencia para programadores de Perl Test2::Compare::Object(3perl)

NOMBRE

Test2::Compare::Object - Representación de un objeto durante la comparación profunda.

DESCRIPCIÓN

Esta clase te permite especificar un objeto esperado en una comparación profunda. Puedes verificar los campos/elementos de la referencia subyacente, llamar a métodos para verificar resultados y hacer comprobaciones de metadatos sobre el tipo de objeto y el tipo de referencia.

MÉTODOS

$clase = $obj->meta_class
La meta-clase a utilizar al verificar el tipo de objeto. Esto se lista principalmente porque es útil anularlo para subclases de objetos especializadas.

Esto normalmente solo devuelve Test2::Compare::Meta.

$clase = $obj->object_base
La clase base esperada al verificar el tipo de objeto. Esto se lista principalmente porque es útil anularlo para subclases de objetos especializadas.

Esto normalmente solo devuelve 'UNIVERSAL'.

$obj->add_prop(...)
Añade una meta-propiedad a comprobar, ver Test2::Compare::Meta. Este método solo delega.
$obj->add_field(...)
Añade un campo hash a comprobar, ver Test2::Compare::Hash. Este método solo delega.
$obj->add_item(...)
Añade un elemento de array a comprobar, ver Test2::Compare::Array. Este método solo delega.
$obj->add_call($método, $verificación)
$obj->add_call($método, $verificación)
$obj->add_call($método, $verificación, $nombre)
$obj->add_call($método, $verificación, $nombre, $contexto)
Añade una comprobación de llamada de método. Esto llamará al método especificado en tu objeto y verificará el resultado. $método puede ser un nombre de método, una referencia a un array o una referencia a una función (coderef).

Si es una referencia a un array, el primer elemento debe ser el nombre del método, y el resto son argumentos que se le pasarán.

En el caso de una referencia a una función, puede ser útil proporcionar un nombre alternativo. Cuando no se proporciona un nombre, el nombre es $método o la cadena '\&CODE'.

Si $contexto es 'list', el método se invocará en contexto de lista, y el resultado será una referencia a un array.

Si $contexto es 'hash', el método se invocará en contexto de lista, y el resultado será una referencia a un hash (esto emitirá una advertencia si el método devuelve un número impar de valores).
