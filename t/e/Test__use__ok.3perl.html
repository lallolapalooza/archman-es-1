Test::use::ok(3perl) Guía de referencia del programador de Perl Test::use::ok(3perl)

NOMBRE

Test::use::ok - Alternativa a Test::More::use_ok

SINOPSIS

use ok 'Some::Module';

DESCRIPCIÓN

Según la documentación de Test::More, se recomienda ejecutar use_ok() dentro de un bloque "BEGIN", para que las funciones se exporten en tiempo de compilación y los prototipos se respeten correctamente.

Es decir, en lugar de escribir esto:

use_ok( 'Some::Module' );
use_ok( 'Other::Module' );

Se debería escribir esto:

BEGIN { use_ok( 'Some::Module' ); }
BEGIN { use_ok( 'Other::Module' ); }

Sin embargo, la gente a menudo olvida añadir "BEGIN", o agrupa incorrectamente "use_ok" con otras pruebas en un solo bloque "BEGIN", lo que puede crear sutiles diferencias en el orden de ejecución.

Con este módulo, simplemente cambia todos los "use_ok" en los scripts de prueba por "use ok", y se ejecutarán en tiempo de "BEGIN". El espacio explícito después de "use" deja claro que esta es una acción única en tiempo de compilación.
