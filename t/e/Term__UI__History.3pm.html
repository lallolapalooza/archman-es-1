NOMBRE

Term::UI::History - función de historial

SINOPSIS

use Term::UI::History qw[history];
history("Algún mensaje");
### recuperar el historial en formato imprimible
$hist  = Term::UI::History->history_as_string;
### redirigir la salida
local $Term::UI::History::HISTORY_FH = \*STDERR;

DESCRIPCIÓN

Este módulo proporciona la función "history" para "Term::UI", imprimiendo y guardando toda la interacción de "UI".

Consulta la página del manual de "Term::UI" para obtener detalles sobre el uso desde "Term::UI".

Este módulo hereda de "Log::Message::Simple". Consulta su página del manual para obtener funcionalidad adicional disponible a través de este paquete.

FUNCIONES

history("cadena_de_mensaje" [,VERBOSE])

Registra un mensaje en la pila y lo imprime en "STDOUT" (o en realidad en $HISTORY_FH, ver la sección "VARIABLES GLOBALES" a continuación), si la opción "VERBOSE" es verdadera.

La opción "VERBOSE" por defecto es verdadera.

VARIABLES GLOBALES

$HISTORY_FH
Este es el manejador de archivo donde se imprimen todos los mensajes enviados a history(). Por defecto es *STDOUT.
