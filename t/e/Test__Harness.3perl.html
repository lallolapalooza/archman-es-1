Test::Harness(3perl) Guía del programador de Perl Test::Harness(3perl)

NOMBRE

Test::Harness - Ejecutar scripts de prueba estándar de Perl con estadísticas

VERSIÓN

Versión 3.50

SINOPSIS

use Test::Harness;
runtests(@test_files);

DESCRIPCIÓN

Aunque, por razones históricas, la distribución Test::Harness toma su nombre de este módulo, ahora solo existe para proporcionar a TAP::Harness una interfaz que sea algo compatible hacia atrás con Test::Harness 2.xx. Si está escribiendo código nuevo, considere usar TAP::Harness directamente en su lugar.

Se proporciona emulación para "runtests" y "execute_tests", pero la interfaz 'Straps' conectable que las versiones anteriores de Test::Harness admitían no se reproduce aquí. Straps ahora está disponible como un módulo independiente: Test::Harness::Straps.

Consulte TAP::Parser, TAP::Harness para la documentación principal de esta distribución.

FUNCIONES

Las siguientes funciones están disponibles.

runtests( @archivos_de_prueba )

Esto ejecuta todos los @archivos_de_prueba dados y determina si pasaron o fallaron basándose en su salida a STDOUT (detalles arriba). Imprime cada prueba individual que falló junto con un informe resumen y cuánto tiempo tardó todo.

Devuelve verdadero si todo salió bien. De lo contrario, hará die() con uno de los mensajes en la sección DIAGNÓSTICOS.

execute_tests( pruebas => \@archivos_de_prueba, salida => \*FH )

Ejecuta todos los @archivos_de_prueba dados (al igual que runtests()) pero no genera el informe final. Durante las pruebas, la información de progreso se escribirá en el descriptor de archivo de salida actualmente seleccionado (generalmente "STDOUT"), o en el descriptor de archivo proporcionado por el parámetro "salida". La salida es opcional.

Devuelve una lista de dos valores, $total y $fallados, que describen los resultados. $total es una referencia hash resumen de todas las pruebas ejecutadas. Sus claves y valores son estos:

bonus           Número de pruebas individuales 'todo' que pasaron inesperadamente
max             Número de pruebas individuales ejecutadas
ok              Número de pruebas individuales pasadas
sub_skipped     Número de pruebas individuales omitidas
todo            Número de pruebas individuales 'todo'
files           Número de archivos de prueba ejecutados
good            Número de archivos de prueba pasados
bad             Número de archivos de prueba fallidos
tests           Número de archivos de prueba dados originalmente
skipped         Número de archivos de prueba omitidos

Si "$total->{bad} == 0" y "$total->{max} > 0", has tenido una prueba exitosa.

$fallados es una referencia hash de todos los scripts de prueba que fallaron. Cada clave es el nombre de un script de prueba, cada valor es otra referencia hash que representa cómo falló ese script. Sus claves son estas:

name        Nombre de la prueba que falló
estat       Valor de salida del script
wstat       Estado de espera del script
max         Número de pruebas individuales
failed      Número que falló
canon       Lista de pruebas que fallaron (como cadena).

$fallados debería estar vacío si todo pasó.

EXPORTAR

&runtests es exportado por "Test::Harness" por defecto.

&execute_tests, $verbose, $switches y $debug se exportan bajo petición.

VARIABLES DE ENTORNO QUE TAP::HARNESS::COMPATIBLE CONFIGURA

"Test::Harness" configura estas antes de ejecutar las pruebas individuales.

"HARNESS_ACTIVE"
Se establece en un valor verdadero. Permite a las pruebas determinar si se están ejecutando a través del harness o por cualquier otro medio.
"HARNESS_VERSION"
Esta es la versión de "Test::Harness".

VARIABLES DE ENTORNO QUE AFECTAN A TEST::HARNESS

"HARNESS_PERL_SWITCHES"
Establecer esto añade interruptores de línea de comandos de Perl a cada archivo de prueba ejecutado.

Por ejemplo, "HARNESS_PERL_SWITCHES=-T" activará el modo de detección de trampas. "HARNESS_PERL_SWITCHES=-MDevel::Cover" ejecutará "Devel::Cover" para cada prueba.

"-w" siempre está activado. Puedes desactivarlo en la prueba con "BEGIN { $^W = 0 }".

"HARNESS_TIMER"
Establecer esto como verdadero hará que el harness muestre el número de milisegundos que tardó cada prueba. También puedes usar el interruptor "--timer" de prove.
"HARNESS_VERBOSE"
Si es verdadero, "Test::Harness" mostrará los resultados detallados de la ejecución de sus pruebas. Establecer $Test::Harness::verbose lo anulará, o puedes usar el interruptor "-v" en la utilidad prove.
"HARNESS_OPTIONS"
Proporciona opciones adicionales al harness. Las opciones actualmente admitidas son:
"j<n>"
Ejecuta <n> (por defecto 9) trabajos paralelos.
"c"
Intenta colorear la salida. Ver "new" en TAP::Formatter::Base.
"a<archivo.tgz>"
Utilizará TAP::Harness::Archive como clase de harness, y guardará el TAP en "archivo.tgz"
"fPaquete-Con-Guiones"
Establece la clase formadora (formatter_class) del harness que se está ejecutando. Dado que "HARNESS_OPTIONS" se separa por ":", usamos "-" en su lugar.

Se pueden separar múltiples opciones con dos puntos:

HARNESS_OPTIONS=j9:c make test
"HARNESS_SUBCLASS"
Especifica una subclase de TAP::Harness que se utilizará en lugar de TAP::Harness.
"HARNESS_SUMMARY_COLOR_SUCCESS"
Determina el Term::ANSIColor para el resumen en caso de éxito. Este color por defecto es 'green'.
"HARNESS_SUMMARY_COLOR_FAIL"
Determina el Term::ANSIColor para el fallo en caso de éxito. Este color por defecto es 'red'.

Modo de detección de trampas

Normalmente, cuando un programa Perl se ejecuta en modo de detección de trampas, el contenido de la variable de entorno "PERL5LIB" no aparece en @INC.

Dado que "PERL5LIB" se utiliza a menudo durante las pruebas para añadir directorios de compilación a @INC, "Test::Harness" pasa los nombres de los directorios encontrados en "PERL5LIB" como interruptores -I. El efecto neto de esto es que "PERL5LIB" se respeta incluso en modo de detección de trampas.
