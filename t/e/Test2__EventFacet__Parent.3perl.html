NOMBRE

Test2::EventFacet::Parent - Faceta para eventos que contienen otros eventos

DESCRIPCIÓN

Esta faceta se utiliza cuando un evento contiene otros eventos, como una subprueba.

CAMPOS

$cadena = $padre->{detalles}
$cadena = $padre->detalles()
Descripción legible por humanos del evento.
$id_hub = $padre->{hid}
$id_hub = $padre->hid()
ID del hub que se representa en la relación padre-hijo.
$referencia_array = $padre->{hijos}
$referencia_array = $padre->hijos()
Referencia a un array que contiene los hashes de datos de faceta de los eventos anidados bajo este.

Para obtener los eventos reales, necesita obtenerlos directamente del evento padre

$booleano = $padre->{bufferizado}
$booleano = $padre->bufferizado()
Verdadero si la subprueba está en búfer (lo que significa que el formateador probablemente aún no las ha visto).

FUENTE

El repositorio de código fuente de Test2 se puede encontrar en https://github.com/Test-More/test-more/.
