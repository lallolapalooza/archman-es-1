NOMBRE

Test2::Plugin::UTF8 - Plugin de Test2 para probar con utf8.

DESCRIPCIÓN

Cuando se utiliza, este plugin hará que las pruebas funcionen con utf8. Esto incluye activar la pragmática utf8 y actualizar el formateador de salida de Test2 para usar utf8.

SINOPSIS

use Test2::Plugin::UTF8;

Esto es similar a:

use utf8;
BEGIN {
    require Test2::Tools::Encoding;
    Test2::Tools::Encoding::set_encoding('utf8');
}

También puedes deshabilitar la importación de utf8 usando 'encoding_only' para habilitar solo la codificación utf8 en la salida.

use Test2::Plugin::UTF8 qw(encoding_only);

opciones de importación

encoding_only

No importa utf8 en tu prueba y solo habilita el modo de codificación en la salida.

NOTAS

Este módulo actualmente configura los manejadores de salida para tener la capa de salida ':utf8'. Algunos podrían preferir ':encoding(utf-8)' que es más estricto al verificar caracteres. Existe un debate sobre si la codificación a utf8 desde los internos de perl puede fallar alguna vez, por lo que puede que no importe. Esto también fue elegido porque la alternativa causa fallos de segmentación en los hilos, véase perlbug 31923 https://rt.perl.org/Public/Bug/Display.html?id=31923.

FUENTE
