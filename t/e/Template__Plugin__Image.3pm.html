NOMBRE

Template::Plugin::Image - Plugin de acceso a tamaños de imagen

SINOPSIS

[% USE Image(nombre_archivo) %]
[% Image.width %]
[% Image.height %]
[% Image.size.join(', ') %]
[% Image.attr %]
[% Image.tag %]

DESCRIPCIÓN

Este plugin proporciona una interfaz a los módulos Image::Info o Image::Size para determinar el tamaño de los archivos de imagen.

Puedes especificar el nombre del plugin como '"Image"' o '"image"'. El objeto plugin creado tendrá entonces el mismo nombre. El nombre del archivo de imagen debe especificarse como un argumento posicional o con nombre.

[% # todos estos son válidos, elige el que prefieras %]
[% USE Image('foo.gif') %]
[% USE image('bar.gif') %]
[% USE Image 'ping.gif' %]
[% USE image(name='baz.gif') %]
[% USE Image name='pong.gif' %]

Se puede utilizar un parámetro "root" para especificar la ubicación del archivo de imagen:

[% USE Image(root='/ruta/a/raiz', name='imagenes/home.png') %]
# ruta de la imagen: /ruta/a/raiz/imagenes/home.png
# src de img: imagenes/home.png

En casos donde la ruta de la imagen y la URL de la imagen no coinciden, especifica el nombre del archivo directamente:

[% USE Image(file='/ruta/a/home.png', name='/imagenes/home.png') %]

El parámetro "alt" se puede usar para especificar un nombre alternativo para la imagen, para usar en la construcción de un elemento XHTML (ver el método tag() abajo).

[% USE Image('home.png', alt="Inicio") %]

También puedes proporcionar un nombre alternativo para un objeto plugin de "Image".

[% USE img1 = image 'foo.gif' %]
[% USE img2 = image 'bar.gif' %]

El método "name" devuelve el nombre del archivo de imagen.

[% img1.name %]     # foo.gif

Los métodos "width" y "height" devuelven el ancho y la altura de la imagen, respectivamente. El método "size" devuelve una referencia a una lista de 2 elementos que contiene el ancho y la altura.

[% USE image 'foo.gif' %]
ancho: [% image.width %]
alto: [% image.height %]
tamaño: [% image.size.join(', ') %]

El método "modtime" devuelve la hora de modificación del archivo en cuestión, adecuada para usar con el plugin Date, por ejemplo:

[% USE image 'foo.gif' %]
[% USE date %]
[% date.format(image.modtime, "%B, %e %Y") %]

El método "attr" devuelve la altura y el ancho como atributos HTML/XML.

[% USE image 'foo.gif' %]
[% image.attr %]

Salida típica:

width="60" height="20"

El método "tag" devuelve una etiqueta XHTML completa que hace referencia a la imagen.

[% USE image 'foo.gif' %]
[% image.tag %]

Salida típica:

<img src="foo.gif" width="60" height="20" alt="" />

Puedes proporcionar cualquier atributo adicional que deba agregarse a la etiqueta XHTML.

[% USE image 'foo.gif' %]
[% image.tag(class="logo" alt="Logo") %]

Salida típica:

<img src="foo.gif" width="60" height="20" alt="Logo" class="logo" />

Ten en cuenta que el atributo "alt" es obligatorio en un elemento "img" XHTML estricto (incluso si está vacío), por lo que siempre se agrega incluso si no proporcionas explícitamente un valor para él. Puedes hacerlo como un argumento del método "tag", como se muestra en el ejemplo anterior, o como un argumento

[% USE image('foo.gif', alt='Logo') %]

CAPTURA DE ERRORES

Si el archivo de imagen no se puede encontrar, los métodos anteriores lanzarán un error de "Image". Puedes encerrar las llamadas a estos métodos en un bloque "TRY...CATCH" para capturar cualquier error potencial.

[% TRY;
     image.width;
   CATCH;
     error;      # imprime el error
   END
%]

USANDO Image::Info

En tiempo de ejecución, el plugin intenta cargar Image::Info con preferencia sobre Image::Size. Si se encuentra Image::Info, entonces algunos métodos adicionales están disponibles, además de "size", "width", "height", "attr", y "tag". Estos métodos adicionales llevan el nombre de los elementos que Image::Info recupera de la propia imagen. Los tipos de métodos disponibles dependen del tipo de imagen (ver Image::Info para más detalles). Estos métodos adicionales siempre incluirán los siguientes:

file_media_type

Este es el tipo MIME apropiado para el formato de archivo dado. El valor correspondiente es una cadena como: ""image/png"" o ""image/jpeg"".

file_ext

Esta es la extensión de nombre de archivo sugerida para un archivo del formato de archivo dado. El valor es una cadena de 3 letras en minúsculas como ""png"", ""jpg"".

color_type

El valor es una cadena corta que describe qué tipo de valores codifican los píxeles. El valor puede ser uno de los siguientes:

Gray
GrayA
RGB
RGBA
CMYK
YCbCr
CIELab

Estos nombres también pueden ir precedidos por ""Indexed-"" si la imagen está compuesta por índices de una paleta. De estos, solo es probable que ocurra ""Indexed-RGB"".

(Es similar al campo TIFF PhotometricInterpretation, pero se encontró que este nombre era demasiado largo, por lo que usamos el término inspirado en PNG en su lugar.)

resolution

El valor de este campo normalmente indica el tamaño físico de la imagen en pantalla o papel. Cuando falta el especificador de unidad, este campo denota la cuadratura de los píxeles en la imagen.

La sintaxis de este campo es:

<res> <unit>
<xres> "/" <yres> <unit>
<xres> "/" <yres>

Los campos "<res>", "<xres>" y "<yres>" son números. El "<unit>" es una cadena como "dpi", "dpm" o "dpcm" (que denota "puntos por pulgada/cm/metro").

SamplesPerPixel

Esto indica cuántos canales hay en la imagen. Para algunos formatos de imagen, este número puede ser mayor que el número implícito por "color_type".

BitsPerSample

Esto indica cuántos bits se utilizan para codificar cada una de las muestras. El valor es una referencia a una matriz que contiene números. El número de elementos en la matriz debe ser el mismo que "SamplesPerPixel".

Comment

Comentarios textuales encontrados en el archivo. El valor es una referencia a una matriz si se encuentran varios comentarios.

Interlace

Si la imagen está entrelazada, esto devuelve el tipo de entrelazado.

Compression

Esto devuelve el nombre del algoritmo de compresión utilizado.

Gamma

Un número que indica la curva gamma de la imagen (ej. 2.2)
