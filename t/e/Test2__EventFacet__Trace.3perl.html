Test2::EventFacet::Trace(3perl) Guía del programador de Perl Test2::EventFacet::Trace(3perl)

NOMBRE

Test2::EventFacet::Trace - Información de depuración para eventos

DESCRIPCIÓN

El objeto Test2::API::Context, así como todos los tipos de Test2::Event, necesitan tener acceso a información sobre dónde fueron creados. Este objeto representa esa información.

SINOPSIS

use Test2::EventFacet::Trace;
my $trace = Test2::EventFacet::Trace->new(
    frame => [$package, $file, $line, $subname],
);

CAMPOS DEL FACET

$string = $trace->{details}
$string = $trace->details()
Se usa como un mensaje de rastreo personalizado que se utilizará EN LUGAR de "en <ARCHIVO> línea <LÍNEA>" al llamar a "$trace->debug".
$frame = $trace->{frame}
$frame = $trace->frame()
Obtiene el arrayref del marco de llamada. 
[$package, $file, $line, $subname]
$int = $trace->{pid}
$int = $trace->pid()
El ID del proceso en el que se generó el evento.
$int = $trace->{tid}
$int = $trace->tid()
El ID del hilo en el que se generó el evento.
$id = $trace->{cid}
$id = $trace->cid()
El ID del contexto que se utilizó para crear el evento.
$uuid = $trace->{uuid}
$uuid = $trace->uuid()
El UUID del contexto que se utilizó para crear el evento. (Si el etiquetado uuid estaba habilitado)
($pkg, $file, $line, $subname) = $trace->call
Obtiene la información básica de llamada como una lista.
@caller = $trace->full_call
Obtiene los resultados completos de caller(N).
$warning_bits = $trace->warning_bits
Obtiene el índice 9 de la información completa del llamador. Este es el campo warnings_bits.

El valor de esto no es portable entre versiones de perl o incluso entre procesos. Sin embargo, se puede usar en el proceso que lo generó para reproducir la configuración de advertencias en un nuevo ámbito.

eval <<EOT;
BEGIN { ${^WARNING_BITS} = $trace->warning_bits };
... la configuración de advertencias del contexto se aplica aquí ...
EOT

CAMPOS RELACIONADOS CON HUB DESACONSEJADOS

Estos campos no siempre fueron establecidos correctamente por las herramientas. Estos campos están **MAYORMENTE** obsoletos por los facetas de Test2::EventFacet::Hub. Estos campos no son requeridos, y pueden solo reflejar el hub que estaba activo cuando se creó el evento, lo cual no es necesariamente lo mismo que el hub a través del cual se envió el evento.

Algunas herramientas hicieron un buen trabajo estableciendo estos campos al hub correcto, pero no siempre se puede confiar en eso. Use la lista de facetas 'hubs' en su lugar.

$hid = $trace->{hid}
$hid = $trace->hid()
El ID del hub que estaba activo cuando se creó el evento.
$huuid = $trace->{huuid}
$huuid = $trace->huuid()
El UUID del hub que estaba activo cuando se creó el evento. (Si el etiquetado uuid estaba habilitado).
$int = $trace->{nested}
$int = $trace->nested()
Qué tan anidado está el evento.
$bool = $trace->{buffered}
$bool = $trace->buffered()
Verdadero si el evento estaba en búfer y no se envió al formateador independientemente de un padre (Esto nunca debería establecerse cuando nested es 0 o "undef").

MÉTODOS

Nota: Todos los marcos de faceta son también métodos.

$trace->set_detail($msg)
$msg = $trace->detail
Se utiliza para obtener/establecer un mensaje de rastreo personalizado que se utilizará EN LUGAR de "en <ARCHIVO> línea <LÍNEA>" al llamar a "$trace->debug".

detail() es un alias del campo de facet "details" por compatibilidad hacia atrás.

$str = $trace->debug
Normalmente devuelve la cadena "en <ARCHIVO> línea <LÍNEA>". Si "detail" está establecido, entonces su valor se devolverá en su lugar.
$trace->alert($MENSAJE)
Esto emite una advertencia en el marco (nombre de archivo y número de línea donde se deben reportar los errores).
$trace->throw($MENSAJE)
Esto lanza una excepción en el marco (nombre de archivo y número de línea donde se deben reportar los errores).
($package, $file, $line, $subname) = $trace->call()
Obtiene los detalles del llamador para la información de depuración. Aquí es donde se deben reportar los errores.
$pkg = $trace->package
Obtiene el paquete de información de depuración.
$file = $trace->file
Obtiene el nombre de archivo de información de depuración.
$line = $trace->line
Obtiene el número de línea de información de depuración.
$subname = $trace->subname
Obtiene el nombre de la subrutina de información de depuración.
$sig = trace->signature
Obtiene una cadena de firma que identifica este rastreo. Esto se usa para verificar si varios eventos están relacionados. La firma incluye pid, tid, archivo, número de línea y el cid.
