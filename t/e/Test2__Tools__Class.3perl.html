Test2::Tools::Class(3perl) Guía del programador de Perl Test2::Tools::Class(3perl)

NOMBRE

Test2::Tools::Class - Implementación de Test2 de las herramientas para probar clases.

DESCRIPCIÓN

Herramientas basadas en Test2 para validar clases y objetos. Estas son similares a algunas herramientas de Test::More, pero tienen una interfaz más consistente.

SINOPSIS

use Test2::Tools::Class;
isa_ok($CLASE_O_INSTANCIA, $CLASE_PADRE1, $CLASE_PADRE2, ...);
isa_ok($CLASE_O_INSTANCIA, [$CLASE_PADRE1, $CLASE_PADRE2, ...], "Nombre de la prueba");
can_ok($CLASE_O_INSTANCIA, $METODO1, $METODO2, ...);
can_ok($CLASE_O_INSTANCIA, [$METODO1, $METODO2, ...], "Nombre de la prueba");
DOES_ok($CLASE_O_INSTANCIA, $ROL1, $ROL2, ...);
DOES_ok($CLASE_O_INSTANCIA, [$ROL1, $ROL2, ...], "Nombre de la prueba");

EXPORTA

Todas las subrutinas se exportan por defecto.

can_ok($cosa, @metodos)
can_ok($cosa, \@metodos, $nombre_prueba)
Esto comprueba que $cosa (ya sea un nombre de clase o una instancia bendecida) tiene los métodos especificados.

Si el segundo argumento es una referencia a array, se utilizará como la lista de métodos, dejando el tercer argumento como el nombre de la prueba.

isa_ok($cosa, @clases)
isa_ok($cosa, \@clases, $nombre_prueba)
Esto comprueba que $cosa (ya sea un nombre de clase o una instancia bendecida) es o hereda de las clases especificadas.

Si el segundo argumento es una referencia a array, se utilizará como la lista de clases, dejando el tercer argumento como el nombre de la prueba.

DOES_ok($cosa, @roles)
DOES_ok($cosa, \@roles, $nombre_prueba)
Esto comprueba que $cosa (ya sea un nombre de clase o una instancia bendecida) implementa los roles especificados.

Si el segundo argumento es una referencia a array, se utilizará como la lista de roles, dejando el tercer argumento como el nombre de la prueba.

Nota 1: Esto utiliza el método "$clase->DOES(...)", no el método does() que proporciona Moose.

Nota 2: No todos los Perl tienen el método DOES(); si usas esto en esos Perl, la prueba se saltará.
