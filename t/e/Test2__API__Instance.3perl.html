Test2::API::Instance(3perl) Guía de referencia para programadores de Perl Test2::API::Instance(3perl)

NOMBRE

Test2::API::Instance - Objeto utilizado por Test2::API internamente

DESCRIPCIÓN

Este objeto encapsula el estado compartido global rastreado por Test2. Una única instancia global de este paquete se almacena (y se oculta) en el paquete Test2::API.

No hay ninguna razón para usar directamente este paquete. Este paquete se documenta por completitud. Este paquete puede cambiar o desaparecer por completo en cualquier momento. El uso directo o el *monkeypatching* de este paquete no está soportado de ninguna manera.

SINOPSIS

use Test2::API::Instance;
my $obj = Test2::API::Instance->new;
$pid = $obj->pid
PID de esta instancia.
$obj->tid
ID de hilo de esta instancia.
$obj->reset()
Restablece el objeto a los valores predeterminados.
$obj->load()
Establece el estado interno en cargado y ejecuta y almacena las devoluciones de llamada posteriores a la carga.
$bool = $obj->loaded
Comprueba si el estado está establecido como cargado.
$arrayref = $obj->post_load_callbacks
Obtiene las devoluciones de llamada posteriores a la carga.
$obj->add_post_load_callback(sub { ... })
Añade una devolución de llamada posterior a la carga. Si load() ya ha sido llamada, la devolución de llamada se ejecutará inmediatamente. Si load() no ha sido llamada, la devolución de llamada se almacenará y ejecutará más tarde cuando se llame a load().
$hashref = $obj->contexts()
Obtiene un hashref de todos los contextos activos indexados por id de hub.
$arrayref = $obj->context_acquire_callbacks
Obtiene todas las devoluciones de llamada de adquisición de contexto.
$arrayref = $obj->context_init_callbacks
Obtiene todas las devoluciones de llamada de inicialización de contexto.
$arrayref = $obj->context_release_callbacks
Obtiene todas las devoluciones de llamada de liberación de contexto.
$arrayref = $obj->pre_subtest_callbacks
Obtiene todas las devoluciones de llamada pre-subtest.
$obj->add_context_init_callback(sub { ... })
Añade una devolución de llamada de inicialización de contexto. Las subs se llaman cada vez que se crea un contexto. Las subs reciben el contexto recién creado como su único argumento.
$obj->add_context_release_callback(sub { ... })
Añade una devolución de llamada de liberación de contexto. Las subs se llaman cada vez que se libera un contexto. Las subs reciben el contexto liberado como su único argumento. Estas devoluciones de llamada no deben llamar a la liberación en el contexto.
$obj->add_pre_subtest_callback(sub { ... })
Añade una devolución de llamada pre-subtest. Las subs se llaman cada vez que se va a ejecutar un subtest. Las subs reciben el nombre del subtest, el coderef y cualquier argumento.
$obj->set_exit()
Esto está pensado para ser llamado en un bloque "END { ... }". Esto examinará el estado de las pruebas y establecerá $?. Esto también llamará a cualquier devolución de llamada de finalización y esperará a los procesos/hilos hijos.
$obj->set_ipc_pending($val)
Indica a otros procesos e hilos que hay un evento pendiente. $val debe ser un valor único que ningún otro hilo/proceso generará.

Nota: Esto también hará que el proceso actual vea un evento pendiente.

$pending = $obj->get_ipc_pending()
Esto devuelve -1 si no es posible saberlo.

Esto devuelve 0 si no hay eventos pendientes.

Esto devuelve 1 si hay eventos pendientes.

$timeout = $obj->ipc_timeout;
$obj->set_ipc_timeout($timeout);
Cuánto tiempo esperar a los procesos e hilos hijos antes de abortar.
$drivers = $obj->ipc_drivers
Obtiene la lista de controladores IPC.
$obj->add_ipc_driver($DRIVER_CLASS)
Añade un controlador IPC a la lista. El controlador IPC añadido más recientemente se convertirá en el global durante la inicialización. Si se añade un controlador después de que haya ocurrido la inicialización, se generará una advertencia: 
"IPC driver $driver loaded too late to be used as the global ipc driver"
$bool = $obj->ipc_polling
Comprueba si el sondeo está habilitado.
$obj->enable_ipc_polling
Activa el sondeo. Esto obtendrá eventos de otros procesos e hilos cada vez que se cree un contexto.
$obj->disable_ipc_polling
Desactiva el sondeo IPC.
$bool = $obj->no_wait
$bool = $obj->set_no_wait($bool)
Obtiene/establece no_wait. Esta opción se utiliza para desactivar la espera de procesos/hilos al salir.
$arrayref = $obj->exit_callbacks
Obtiene las devoluciones de llamada de salida.
$obj->add_exit_callback(sub { ... })
Añade una devolución de llamada de salida. Esta devolución de llamada será llamada por set_exit().
$bool = $obj->finalized
Comprueba si el objeto está finalizado. La finalización ocurre cuando se llama a ipc(), stack() o format() en el objeto. Una vez que ocurre la finalización, estos campos se consideran inmutables (no se aplican aquí, se aplican por Test2).
$ipc = $obj->ipc
Obtiene la única instancia IPC verdadera.
$obj->ipc_disable
Desactiva la IPC
$bool = $obj->ipc_disabled
Comprueba si la IPC está deshabilitada
$stack = $obj->stack
Obtiene la única pila de hubs verdadera.
$formatter = $obj->formatter
Obtiene el formateador global. Por defecto, es el paquete 'Test2::Formatter::TAP'. Podría ser cualquier paquete que implemente el método write(). También puede ser un objeto instanciado.
$bool = $obj->formatter_set()
Comprueba si se ha establecido un formateador.
$obj->add_formatter($class)
$obj->add_formatter($obj)
Añade un formateador. El formateador añadido más recientemente se convertirá en el global durante la inicialización. Si se añade un formateador después de que haya ocurrido la inicialización, se generará una advertencia: 
"Formatter $formatter loaded too late to be used as the global formatter"
$obj->set_add_uuid_via(sub { ... })
$sub = $obj->add_uuid_via()
Esto te permite proporcionar un generador de UUID. Si se proporciona, los UUID se adjuntarán a todos los eventos, hubs y contextos. Esto es útil para almacenar, rastrear y vincular estos objetos.

La subrutina que proporciones debe devolver siempre un identificador único. La mayoría de las cosas esperarán una cadena UUID válida, sin embargo, nada en Test2::API lo impone.

La subrutina recibirá exactamente 1 argumento, el tipo de cosa que se está etiquetando: 'context', 'hub' o 'event'. En el futuro, se podrán etiquetar elementos adicionales, en cuyo caso se pasarán cadenas nuevas. Estos son puramente informativos, puedes (y normalmente deberías) ignorarlos.

Test2 API Instance Manual

NAME

Test2::API::Instance - Test2 API Instance

DESCRIPTION

This is a base class for all Test2 APIs.

It provides a basic structure for interacting with Test2. Test2 is a framework for writing tests in Perl. This module is part of that framework.

SYNOPSIS

use Test2::API::Instance;

# This is a base class and is not meant to be used directly.
# Subclasses like Test2::API::Test implement actual functionality.
