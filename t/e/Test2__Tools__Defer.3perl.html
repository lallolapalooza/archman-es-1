NOMBRE

Test2::Tools::Defer - Escribe pruebas que se ejecutarán en un momento posterior

DESCRIPCIÓN

A veces necesitas probar cosas ANTES de cargar las funciones necesarias. Este módulo te permite hacer eso. Puedes escribir pruebas y luego hacer que se ejecuten más tarde, después de que se cargue "Test2". Le dices qué función de prueba ejecutar y qué argumentos darle. El nombre de la función y los argumentos se almacenarán para ejecutarse más tarde. Cuando estés listo, ejecuta do_def() para iniciarlas una vez que las funciones estén definidas.

SINOPSIS

use strict;
use warnings;
use Test2::Tools::Defer;
BEGIN {
    def ok => (1, 'pass');
    def is => ('foo', 'foo', 'runs is');
    ...
}
use Test2::Tools::Basic;
do_def(); # Ejecuta las pruebas
# Declara algunas pruebas más para ejecutar más tarde:
def ok => (1, "otra pasada");
...
do_def(); # ejecuta las nuevas pruebas
done_testing;

EXPORTACIONES

def function => @args;
Esto almacenará el nombre de la función y los argumentos para ejecutarse más tarde. Ten en cuenta que cada paquete tiene un almacén separado de pruebas para ejecutar.
do_def()
Esto ejecutará todas las pruebas almacenadas. También restablecerá la lista para que esté vacía, de modo que puedas agregar más pruebas para ejecutar incluso más tarde.
