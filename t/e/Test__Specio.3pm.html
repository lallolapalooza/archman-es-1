Test::Specio(3) Documentación de Perl contribuida por el usuario Test::Specio(3)

NOMBRE

Test::Specio - Ayudantes de prueba para Specio

VERSIÓN

versión 0.53

SINOPSIS

use Test::Specio qw( test_constraint :vars );
test_constraint(
    t('Foo'), {
        accept => [ 'foo', 'bar' ],
        reject => [ 42,    {}, $EMPTY_STRING, $HASH_REF ],
    }
);

DESCRIPCIÓN

Este paquete proporciona algunas funciones y variables auxiliares para probar tipos Specio.

EXPORTACIONES

Este módulo proporciona las siguientes exportaciones:

test_constraint( $tipo, $pruebas, [ $describer ] )

Esta subrutina acepta dos argumentos. El primero debe ser un objeto de tipo Specio. El segundo es un hashref que puede contener las claves "accept" y "reject". Cada clave debe contener un arrayref de valores que el tipo acepta o rechaza.

El tercer argumento es opcional. Se trata de una referencia a una subrutina que se llamará para generar una descripción del valor que se está probando. Por defecto, llama a la subrutina "describe" de este paquete, pero puedes proporcionar la tuya.

describe($valor)

Dada un valor, esta subrutina devuelve una cadena que describe ese valor de una manera útil para la salida de pruebas. Conoce las diversas clases utilizadas para las variables exportadas por este paquete y hará algo inteligente con dichas variables.

builtins_tests( $GLOB, $GLOB_OVERLOAD, $GLOB_OVERLOAD_FH )

Esta subrutina devuelve un hashref que contiene variables de prueba para todos los tipos integrados. El hashref tiene un formato como este:

{
    Bool => {
        accept => [
            $ZERO,
            $ONE,
            $BOOL_OVERLOAD_TRUE,
            $BOOL_OVERLOAD_FALSE,
            ...,
        ],
        reject => [
            $INT,
            $NEG_INT,
            $NUM,
            $NEG_NUM,
            ...,
            $OBJECT,
        ],
    },
    Maybe => {...},
}

Necesitas pasar un glob, un objeto que sobrecarga la globificación, y un objeto que sobrecarga la globificación para devolver un manejador de archivos abierto. Ver más abajo para más detalles sobre cómo crear estas cosas.

create_BAR_handle_code()

Devuelve una cadena que puedes "evaluar" para crear un manejador de archivos bar llamado "BAR". Esto debería usarse así:

local *BAR;
{
    local $@;
    eval create_BAR_handle_code();
    die $@ if $@;
}

Variables

Este módulo también exporta muchas variables que contienen valores útiles para probar restricciones. Ten en cuenta que las referencias son siempre vacías a menos que se indique lo contrario. Puedes importar estas variables individualmente o importarlas todas con la etiqueta de importación ":vars".

  • $ZERO
  • $ONE
  • $INT

    Un entero positivo arbitrario.

  • $NEG_INT

    Un entero negativo arbitrario.

  • $NUM

    Un número positivo no entero arbitrario.

  • $NEG_NUM

    Un número negativo no entero arbitrario.

  • $EMPTY_STRING
  • $STRING

    Una cadena no vacía arbitraria.

  • $NUM_IN_STRING

    Una cadena arbitraria que contiene un número.

  • $INT_WITH_NL1

    Una cadena que contiene un entero seguido de un salto de línea.

  • $INT_WITH_NL2

    Una cadena que contiene un salto de línea seguido de un entero.

  • $SCALAR_REF
  • $SCALAR_REF_REF

    Una referencia que contiene una referencia a un escalar.

  • $ARRAY_REF
  • $HASH_REF
  • $CODE_REF
  • $GLOB_REF
  • $FH

    Un manejador de archivos abierto.

  • $FH_OBJECT

    Un objeto IO::File abierto.

  • $REGEX

    Una expresión regular creada con "qr//".

  • $REGEX_OBJ

    Una expresión regular creada con "qr//" que luego fue bendecida en una clase.

  • $FAKE_REGEX

    Una expresión regular no-regex bendecida en la clase "Regexp" que Perl utiliza internamente para objetos "qr//".

  • $OBJECT

    Un objeto arbitrario.

  • $UNDEF
  • $CLASS_NAME

    Una cadena que contiene un nombre de paquete cargado.

  • $BOOL_OVERLOAD_TRUE

    Un objeto que sobrecarga la boolificación para devolver verdadero.

  • $BOOL_OVERLOAD_FALSE

    Un objeto que sobrecarga la boolificación para devolver falso.

  • $STR_OVERLOAD_EMPTY

    Un objeto que sobrecarga la stringificación para devolver una cadena vacía.

  • $STR_OVERLOAD_FULL

    Un objeto que sobrecarga la stringificación para devolver una cadena no vacía.

  • $STR_OVERLOAD_CLASS_NAME

    Un objeto que sobrecarga la stringificación para devolver un nombre de paquete cargado.

  • $NUM_OVERLOAD_ZERO
  • $NUM_OVERLOAD_ONE
  • $NUM_OVERLOAD_NEG
  • $NUM_OVERLOAD_DECIMAL
  • $NUM_OVERLOAD_NEG_DECIMAL
  • $CODE_OVERLOAD
  • $SCALAR_OVERLOAD

    Un objeto que sobrecarga la desreferenciación escalar para devolver una cadena no vacía.

  • $ARRAY_OVERLOAD

    Un objeto que sobrecarga la desreferenciación de array para devolver un array no vacío.

  • $HASH_OVERLOAD

    Un objeto que sobrecarga la desreferenciación de hash para devolver un hash no vacío.

Globs y el paquete _T::GlobOverload

Para crear un glob que puedas pasar para las pruebas, usa este código:

my $GLOB = do {
    no warnings 'once';
    *SOME_GLOB;
};

El paquete "_T::GlobOverload" se define al cargar "Test::Specio" para que puedas crear tus propios objetos de sobrecarga de glob. Dichos objetos no pueden exportarse porque el glob que devuelven no se transfiere correctamente entre paquetes.

Puedes crear una variable así:

local *FOO;
my $GLOB_OVERLOAD = _T::GlobOverload->new( \*FOO );

Si quieres crear un objeto de sobrecarga de glob que devuelva un manejador de archivos, haz esto:

local *BAR;
open BAR, '<', $some_file or die $!;
my $GLOB_OVERLOAD_FH = _T::GlobOverload->new( \*BAR );
