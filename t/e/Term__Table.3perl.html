Term::Table(3perl) Guía de referencia para programadores de Perl Term::Table(3perl)

NOMBRE

Term::Table - Formatea una cabecera y filas en una tabla

DESCRIPCIÓN

Esto es utilizado por algunas pruebas fallidas para proporcionar diagnósticos sobre lo que ha ido mal. Este módulo es capaz de formatear filas de datos en tablas.

SINOPSIS

use Term::Table;
my $tabla = Term::Table->new(
    max_width      => 80,    # Por defecto al tamaño de la terminal
    pad            => 4,     # Relleno extra entre la tabla y max_width (por defecto 4)
    allow_overflow => 0,     # Por defecto es 0, cuando está desactivado se lanzará una excepción si la tabla es demasiado grande
    collapse       => 1,     # No mostrar columnas vacías
    header => ['nombre', 'edad', 'color de pelo'],
    rows   => [
        ['Pedro Picapiedra',  2000000, 'negro'],
        ['Vilma Picapiedra', 1999995, 'rojo'],
        ...
    ],
);
say $_ for $tabla->render;

Esto imprime una tabla como esta:

+------------------+---------+------------+
| nombre           | edad    | color de pelo |
+------------------+---------+------------+
| Pedro Picapiedra | 2000000 | negro      |
| Vilma Picapiedra | 1999995 | rojo       |
| ...              | ...     | ...        |
+------------------+---------+------------+

INTERFAZ

use Term::Table;
my $tabla = Term::Table->new(...);

OPCIONES

header => [ ... ]
Si desea una cabecera, especifíquela aquí. Esto toma un arrayref con el encabezado de cada columna.
rows => [ [...], [...], ... ]
Debe ser un arrayref que contenga un arrayref por fila.
collapse => $bool
Úselo si desea ocultar columnas vacías, es decir, cualquier columna que no tenga datos en ninguna fila. Tener una cabecera para la columna no afectará a la reducción.
max_width => $num
Establezca el ancho máximo de la tabla, la tabla puede no ser de este tamaño, pero no será mayor. Si no se especifica, intentará encontrar el ancho de su terminal y usarlo; de lo contrario, recurrirá al ancho de la terminal o a 80.
pad => $num
Por defecto 4, relleno adicional para los cálculos del ancho de fila. Por defecto es para compatibilidad heredada. Establezca esto a 0 para desactivar el relleno.
allow_overflow => $bool
Por defecto 0. Si esto está desactivado, se lanzará una excepción si la tabla no se puede ajustar al ancho máximo. Si esto se establece en 1, la tabla se renderizará de todos modos, más grande que el ancho máximo, si no es posible mantenerse dentro del ancho máximo. En otras palabras, esto convierte el ancho máximo de un límite estricto a una recomendación flexible.
sanitize => $bool
Esto saneará todos los datos de la tabla para que los saltos de línea, los caracteres de control y todos los espacios en blanco excepto el ASCII 20 ' ' se reemplacen con secuencias de escape. Esto evita que los saltos de línea, las tabulaciones y los espacios en blanco similares interrumpan la tabla.

Nota: los saltos de línea se marcan como "\n", pero también se inserta un salto de línea en los datos para que normalmente se muestre de una manera útil para los humanos.

Ejemplo:

my $campo = "foo\nbar\nbaz\n";
print join "\n" => table(
    sanitize => 1,
    rows => [
        [$campo,      'col2'     ],
        ['fila2 col1', 'fila2 col2']
    ]
);

Imprime:

+-----------------+-----------+
| foo\n           | col2      |
| bar\n           |           |
| baz\n           |           |
|                 |           |
| fila2 col1      | fila2 col2 |
+-----------------+-----------+

Por lo tanto, marca los saltos de línea insertando la secuencia de escape, pero también muestra los datos en tantas líneas como lo haría normalmente.

mark_tail => $bool
Esto reemplazará el último carácter de espacio en blanco de cualquier espacio en blanco final con su secuencia de escape. Esto facilita la detección de espacios en blanco finales al comparar valores.
show_header => $bool
Establezca esto en falso para ocultar la cabecera. Esto es verdadero por defecto si se establece la cabecera, falso si no se proporciona cabecera.
auto_columns => $bool
Establezca esto en verdadero para agregar automáticamente columnas que no están nombradas en la cabecera. Esto es falso por defecto si se proporciona una cabecera, y es verdadero por defecto cuando no hay cabecera.
no_collapse => [ $num_col_a, $num_col_b, ... ]
no_collapse => [ $nombre_col_a, $nombre_col_b, ... ]
no_collapse => { $num_col_a => 1, $num_col_b => 1, ... }
no_collapse => { $nombre_col_a => 1, $nombre_col_b => 1, ... }
Especifique (por número y/o nombre) las columnas que no deben eliminarse cuando estén vacías. La forma 'nombre' solo funciona cuando se especifica una cabecera. Actualmente no hay protección para asegurar que los nombres que especifica estén realmente en la cabecera, los nombres no válidos se ignoran, se aceptarán con gusto los parches para solucionar esto.

NOTA SOBRE CARACTERES UNICODE/DE ANCHO VARIABLE

Algunos caracteres unicode, como "婧" ("U+5A67") son más anchos que otros. Estos se renderizarán bien si "use utf8;" según sea necesario y está instalado Unicode::GCString; sin embargo, si el módulo no está instalado, habrá anomalías en la tabla:

+-----+-----+---+
| a   | b   | c |
+-----+-----+---+
| 婧 | x   | y |
| x   | y   | z |
| x   | 婧 | z |
+-----+-----+---+
