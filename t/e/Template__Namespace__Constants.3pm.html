NOMBRE

Template::Namespace::Constants - Plegado de constantes en tiempo de compilación

SINOPSIS

# forma fácil de definir constantes
use Template;
my $tt = Template->new({
    CONSTANTS => {
        pi => 3.14,
        e  => 2.718,
    },
});
# forma detallada, práctica
use Template::Namespace::Constants;
my $tt = Template->new({
    NAMESPACE => {
        constants => Template::Namespace::Constants->new({
            pi => 3.14,
            e  => 2.718,
        },
    },
});

DESCRIPCIÓN

El módulo "Template::Namespace::Constants" implementa un manejador de espacios de nombres que se conecta al módulo compilador "Template::Directive". Esto realiza el plegado de constantes en tiempo de compilación de variables en un espacio de nombres particular.

MÉTODOS

new(\%constantes)

El método constructor new() crea y devuelve una referencia a un nuevo objeto Template::Namespace::Constants. Esto crea una caché interna para almacenar las definiciones de variables constantes pasadas como argumentos.

my $handler = Template::Namespace::Constants->new({
    pi => 3.14,
    e  => 2.718,
});

ident(\@ident)

Método llamado para resolver un identificador de variable a una forma compilada. En este caso, el método recupera el valor constante correspondiente de su caché interna y lo devuelve.
