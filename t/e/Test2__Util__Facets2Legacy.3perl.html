Test2::Util::Facets2Legacy(3perl) Guía de referencia para programadores de Perl Test2::Util::Facets2Legacy(3perl)

NOMBRE

Test2::Util::Facets2Legacy - Convierte datos de facetas a la API de eventos heredada.

DESCRIPCIÓN

Este módulo exporta varias subrutinas de la antigua API de eventos (ver Test2::Event). Estas subrutinas pueden ser usadas como métodos en cualquier objeto que proporcione un método personalizado facet_data(). Estas subrutinas también pueden ser usadas como funciones que toman un hashref de datos de facetas como argumentos.

SINOPSIS

COMO MÉTODOS

package My::Event;
use Test2::Util::Facets2Legacy ':ALL';
sub facet_data { return { ... } }

Luego, para usarlo:

my $e = My::Event->new(...);
my $causes_fail = $e->causes_fail;
my $summary     = $e->summary;
....

COMO FUNCIONES

use Test2::Util::Facets2Legacy ':ALL';
my $f = {
    assert => { ... },
    info => [{...}, ...],
    control => {...},
    ...
};
my $causes_fail = causes_fail($f);
my $summary     = summary($f);

NOTA SOBRE CICLOS

Cuando se usan como métodos, todas estas subrutinas llaman a "$e->facet_data()". El método predeterminado facet_data() en Test2::Event se basa en los métodos heredados que este módulo emula para funcionar. Como resultado de esto, es muy fácil crear errores de recursión infinita.

Estos métodos tienen detección de ciclos y lanzarán una excepción temprana si se detecta un ciclo. uuid() es actualmente la única subrutina en esta biblioteca que tiene un comportamiento de respaldo cuando se detectan ciclos.

EXPORTA

Nada se exporta por defecto. Debes especificar qué métodos importar o usar la etiqueta ':ALL'.

$bool = $e->causes_fail()
$bool = causes_fail($f)
Verifica si el evento o las facetas resultan en un estado de fallo.
$bool = $e->diagnostics()
$bool = diagnostics($f)
Verifica si el evento o las facetas contienen información de diagnóstico.
$bool = $e->global()
$bool = global($f)
Verifica si el evento o las facetas necesitan ser procesados globalmente.
$bool = $e->increments_count()
$bool = increments_count($f)
Verifica si el evento o las facetas realizan una aserción.
$bool = $e->no_display()
$bool = no_display($f)
Verifica si el evento o las facetas deben ser renderizados u ocultados.
($max, $directive, $reason) = $e->sets_plan()
($max, $directive, $reason) = sets_plan($f)
Verifica si el evento o las facetas establecen un plan y devuelve los detalles del plan.
$id = $e->subtest_id()
$id = subtest_id($f)
Obtiene el ID del subtest, si existe.
$string = $e->summary()
$string = summary($f)
Obtiene el resumen del evento o del hash de facetas, si existe.
$undef_or_int = $e->terminate()
$undef_or_int = terminate($f)
Verifica si el evento o las facetas deben resultar en la terminación del proceso; si es así, se devuelve el código de salida (que podría ser 0). Se devuelve undef si no se solicita ninguna terminación.
$uuid = $e->uuid()
$uuid = uuid($f)
Obtiene el UUID de las facetas o del evento.

Nota: Esto recurrirá a "$e->SUPER::uuid()" si se detecta un ciclo y se utiliza un evento como argumento.
