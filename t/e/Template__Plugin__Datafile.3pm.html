NOMBRE

Template::Plugin::Datafile - Plugin para construir registros desde un archivo de datos simple

SINOPSIS

[% USE mi_datos = datafile('/ruta/al/archivo_datos') %]
[% USE mi_datos = datafile('/ruta/al/archivo_datos', delim = '|') %]
[% USE mi_datos = datafile('/ruta/al/archivo_datos', encoding = 'UTF-8') %]
[% FOREACH registro = mi_datos %]
   [% registro.esto %]  [% registro.aquello %]
[% END %]

DESCRIPCIÓN

Este plugin proporciona una instalación simple para construir una lista de referencias de hash, cada una de las cuales representa un registro de datos de estructura conocida, a partir de un archivo de datos.

[% USE datafile(nombre_archivo) %]

Se debe especificar un nombre de archivo absoluto (al menos para esta implementación inicial; en una versión futura podría usar también "INCLUDE_PATH"). También se puede proporcionar un parámetro opcional "delim" para especificar un carácter delimitador alternativo. El parámetro opcional "encoding" puede usarse para especificar la codificación del archivo de entrada.

[% USE lista_usuarios = datafile('/ruta/al/archivo/usuarios')     %]
[% USE cosas   = datafile('elementos', delim = '|') %]

El formato del archivo es intencionadamente simple. La primera línea define los nombres de los campos, delimitados por dos puntos con espacios en blanco opcionales alrededor. Las líneas subsiguientes definen registros que contienen elementos de datos, también delimitados por dos puntos. Por ejemplo:

id : nombre : email : tel
abw : Andy Wardley : abw@tt2.org : 555-1234
sam : Simon Matthews : sam@tt2.org : 555-9876

Cada línea se lee, se divide en campos compuestos y luego se usa para inicializar un array hash que contiene los nombres de los campos como claves relevantes. El plugin devuelve una referencia de lista bendecida que contiene las referencias de hash en el orden definido en el archivo.

[% FOREACH usuario = lista_usuarios %]
   [% usuario.id %]: [% usuario.nombre %]
[% END %]

La primera línea del archivo **debe** contener las definiciones de campo. Después de la primera línea, se ignorarán las líneas en blanco, así como las líneas de comentarios que comienzan con un '"#"'.

ERRORES

Debería manejar nombres de archivo relativos a "INCLUDE_PATH". No permite el uso de '":"' en un campo. Se necesita algún mecanismo de escape.
