NOMBRE

Template::Plugin::Dumper - Interfaz de plugin para Data::Dumper

SINOPSIS

[% USE Dumper %]

[% Dumper.dump(variable) %]
[% Dumper.dump_html(variable) %]

DESCRIPCIÓN

Esta es una interfaz de plugin muy simple de Template Toolkit para el módulo Data::Dumper. Un objeto "Dumper" se instanciará mediante la siguiente directiva:

[% USE Dumper %]

Como plugin estándar, también puedes especificar su nombre en minúsculas:

[% USE dumper %]

Las opciones "Pad", "Indent" y "Varname" de "Data::Dumper" se admiten como argumentos del constructor para afectar la salida generada. Consulta Data::Dumper para obtener más detalles.

[% USE dumper(Indent=0, Pad="<br>") %]

Estas opciones también se pueden especificar en minúsculas.

[% USE dumper(indent=0, pad="<br>") %]

MÉTODOS

El objeto "Dumper" admite dos métodos. Cada uno generará en la plantilla el contenido de las variables pasadas al método del objeto.

dump()

Genera un volcado de texto sin formato de la(s) estructura(s) de datos pasada(s)

[% USE Dumper %]
[% Dumper.dump(myvar) %]
[% Dumper.dump(myvar, yourvar) %]

dump_html()

Genera un volcado de las estructuras de datos, como dump(), pero con los caracteres <, > y & convertidos a sus entidades HTML equivalentes y los saltos de línea convertidos a <br>.

[% USE Dumper %]
[% Dumper.dump_html(myvar) %]
