NOMBRE

Test::Object - Pruebas exhaustivas de objetos a través de manejadores registrados

VERSIÓN

versión 0.08

SINOPSIS

###################################################################
# En tu módulo de pruebas, registra manejadores de pruebas para cada nombre de clase #
###################################################################

package My::ModuleTester;

use Test::More;
use Test::Object;

# Foo::Bar es una subclase de Foo
Test::Object->register(
      class => 'Foo',
      tests => 5,
      code  => \&foo_ok,
      );
Test::Object->register(
      class => 'Foo::Bar',
      # Sin número fijo de pruebas
      code  => \&foobar_ok,
      );

sub foo_ok {
      my $object = shift;
      ok( $object->foo, '->foo devuelve verdadero' );
}

sub foobar_ok {
      my $object = shift;
      is( $object->foo, 'bar', '->foo devuelve "bar"' );
}

1;



###################################################################
# En el script de prueba, prueba el objeto contra todas las clases registradas #
###################################################################

#!/usr/bin/perl -w

use Test::More 'no_plan';
use Test::Object;
use My::ModuleTester;

my $object = Foo::Bar->new;
isa_ok( $object, 'Foo::Bar' );
object_ok( $object );

DESCRIPCIÓN

En situaciones donde tienes árboles de clases profundos, existe una situación común en la que pruebas 4 o 5 subclases más abajo, las cuales deberían seguir el comportamiento correcto no solo de la subclase, sino de todas las clases padre.

Esto debe hacerse para asegurar que la implementación de una subclase no haya "roto" de alguna manera el comportamiento del objeto en un sentido más general.

"Test::Object" es un paquete de pruebas diseñado para permitirte probar fácilmente lo que crees que es un objeto válido contra el comportamiento esperado de **todas** las clases en su árbol de herencia con una sola llamada.

Para hacer esto, "registras" pruebas (en forma de referencias a código o funciones) con "Test::Object", asociando cada prueba con una clase en particular.

Cuando llamas a "object_ok" en tu script de prueba, "Test::Object" comprobará el objeto contra todas las pruebas registradas. Por cada clase para la que tu objeto responda a "$object->isa($class)", se llamará a la función de prueba apropiada.

Hacerlo de esta manera permite que objetos adaptadores y otras cosas que responden a "isa" de manera diferente a la predeterminada aún sean probados contra las clases que afirman ser correctamente.

Esto también significa que más de una prueba podría ser "contada" por cada llamada a "object_ok". Debes tener esto en cuenta correctamente en tu recuento de pruebas esperado.
