NOMBRE

Template::Plugin::GD::Graph::pie - Crear gráficos circulares con leyendas

SINOPSIS

[% USE g = GD.Graph.pie(tamaño_x, tamaño_y); %]

EJEMPLOS

[% FILTER null;
    datos = [
        ["1º","2º","3º","4º","5º","6º"],
        [    4,    2,    3,    4,    3,  3.5]
    ];
    USE mi_grafico = GD.Graph.pie( 250, 200 );
    mi_grafico.set(
            titulo => 'Un Gráfico Circular',
            etiqueta => 'Etiqueta',
            clr_etiqueta_eje => 'negro',
            altura_torta => 36,
            transparente => 0,
    );
    mi_grafico.plot(datos).png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Graph.pie proporciona una interfaz a la clase GD::Graph::pie definida por el módulo GD::Graph. Permite que un conjunto de datos (x,y) se represente como un gráfico circular. Los valores x suelen ser cadenas.

Consulte GD::Graph para obtener más detalles.
