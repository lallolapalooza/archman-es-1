Test::Builder::Module(3perl) Guía de referencia del programador de Perl Test::Builder::Module(3perl)

NOMBRE

Test::Builder::Module - Clase base para módulos de prueba

SINOPSIS

# Emula Test::Simple
package Tu::Modulo;
my $CLASE = __PACKAGE__;
use parent 'Test::Builder::Module';
@EXPORT = qw(ok);
sub ok ($;$) {
    my $tb = $CLASE->builder;
    return $tb->ok(@_);
}

1;

DESCRIPCIÓN

Esta es una superclase para módulos basados en Test::Builder. Proporciona un puñado de funcionalidades comunes y un método para acceder al objeto Test::Builder subyacente.

Importación

Test::Builder::Module es una subclase de Exporter, lo que significa que tu módulo también es una subclase de Exporter. @EXPORT, @EXPORT_OK, etc. funcionan normalmente.

Se proporcionan algunos métodos para gestionar la parte de "use Tu::Modulo tests => 23".

import

Test::Builder::Module proporciona un método import() que funciona de manera similar al de Test::More, estableciendo el plan y controlando la exportación de funciones y variables. Esto permite que tu módulo establezca el plan independientemente de Test::More.

Todos los argumentos pasados a import() se pasan a "Tu::Modulo->builder->plan()", con la excepción de "import =>[qw(cosas para importar)]".

use Tu::Modulo import => [qw(esto aquello)], tests => 23;

indica importar las funciones esto() y aquello(), además de establecer el plan en 23 pruebas.

import() también establece el atributo exported_to() de tu constructor para que sea el llamador de la función import().

Se pueden añadir comportamientos adicionales a tu método import() sobrescribiendo import_extra().

import_extra

Tu::Modulo->import_extra(\@argumentos_import)

import_extra() es llamado por import(). Proporciona una oportunidad para que añadas comportamientos a tu módulo basándote en su lista de importación.

Cualquier argumento adicional que no deba pasarse a plan() debe ser eliminado por este método.

Ver Test::More para un ejemplo de su uso.

NOTA Este mecanismo es *MUY ALFA Y PROBABLEMENTE CAMBIARÁ*, ya que en su forma actual parece un poco un hack feo.

Constructor

Test::Builder::Module proporciona algunos métodos para acceder al objeto Test::Builder subyacente.

builder

my $constructor = Tu::Clase->builder;

Este método devuelve el objeto Test::Builder asociado a Tu::Clase. No es un constructor, por lo que puedes llamarlo tantas veces como quieras.

Esta es la forma preferida de obtener el objeto Test::Builder. No debes obtenerlo a través de "Test::Builder->new" como se recomendaba anteriormente.

El objeto devuelto por builder() puede cambiar en tiempo de ejecución, por lo que debes llamar a builder() dentro de cada función en lugar de almacenarlo en una variable global.

sub ok {
    my $constructor = Tu::Clase->builder;
    return $constructor->ok(@_);
}
