NOMBRE

Template::Plugin::Math - Plugin que proporciona funciones matemáticas.

SINOPSIS

[% USE Math %]
[% Math.sqrt(9) %]

DESCRIPCIÓN

El plugin Math proporciona numerosas funciones matemáticas para su uso dentro de las plantillas.

MÉTODOS

"Template::Plugin::Math" pone a disposición las siguientes funciones del núcleo de Perl:

abs
atan2
cos
exp
hex
int
log
oct
rand
sin
sqrt
srand

Además, si el módulo Math::Trig se puede cargar, las siguientes funciones también están disponibles:

pi
tan
csc
cosec
sec
cot
cotan
asin
acos
atan
acsc
acosec
asec
acot
acotan
sinh
cosh
tanh
csch
cosech
sech
coth
cotanh
asinh
acosh
atanh
acsch
acosech
asech
acoth
acotanh
rad2deg
rad2grad
deg2rad
deg2grad
grad2rad
grad2deg

Si el módulo Math::TrulyRandom está disponible y tienes tiempo para esperar, el método "truly_random_number" está disponible:

[% Math.truly_random_number %]
