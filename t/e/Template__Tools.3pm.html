Template::Tools - Herramientas de Línea de Comandos para Template Toolkit

Herramientas de plantillas

Template Toolkit incluye las siguientes herramientas de línea de comandos para procesar plantillas.

tpage

El script tpage se puede usar para procesar una sola plantilla utilizando Template Toolkit.

$ tpage --define msg="Hola Mundo" greeting.tt2

Utilice la opción "-h" para obtener un resumen de las opciones:

$ tpage -h

Consulte la documentación de Template::Tools::tpage para obtener más información y ejemplos de uso.

ttree

El script ttree se puede usar para procesar un directorio completo de plantillas.

$ ttree --src /ruta/a/plantillas --dest /ruta/a/salida

Utilice la opción "-h" para obtener un resumen de las opciones:

$ ttree -h

Consulte la documentación de Template::Tools::ttree para obtener más información y ejemplos de uso.
