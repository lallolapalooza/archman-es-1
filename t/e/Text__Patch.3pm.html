NOMBRE

Text::Patch - Aplica parches a texto con un parche dado

SINOPSIS

use Text::Patch;
$output = patch( $source, $diff, STYLE => "Unified" );
use Text::Diff;
$src  = ...
$dst  = ...
$diff = diff( \$src, \$dst, { STYLE => 'Unified' } );
$out  = patch( $src, $diff, { STYLE => 'Unified' } );
print "Patch exitoso" if $out eq $dst;

DESCRIPCIÓN

Text::Patch combina texto fuente con datos de diferencia (diff) dados. Los datos de diff son producidos por el módulo Text::Diff o por la utilidad diff estándar (man diff, ver opción -u).

patch( $source, $diff, opciones... )
El primer argumento es el texto fuente (original). El segundo son los datos de diff. El tercer argumento puede ser una referencia a un hash con opciones o todos los argumentos restantes se considerarán opciones de parche: 
$output = patch( $source, $diff, STYLE => "Unified", ... );
$output = patch( $source, $diff, { STYLE => "Unified", ... } );

Las opciones son:

STYLE => 'Unified'

STYLE puede ser "Unified", "Context" o "OldStyle".
