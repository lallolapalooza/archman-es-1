NOMBRE

Test::Mock::Guard - Librería simple de mocks de pruebas usando RAII.

SINOPSIS

use Test::More;
use Test::Mock::Guard qw(mock_guard);
package Some::Class;
sub new { bless {} => shift }
sub foo { "foo" }
sub bar { 1; }
package main;
{
    my $guard = mock_guard( 'Some::Class', { foo => sub { "bar" }, bar => 10 } );
    my $obj = Some::Class->new;
    is( $obj->foo, "bar" );
    is( $obj->bar, 10 );
}
my $obj = Some::Class->new;
is( $obj->foo, "foo" );
is( $obj->bar, 1 );
done_testing;

DESCRIPCION

Test::Mock::Guard es una librería de mocks de pruebas que utiliza RAII. Este módulo es capaz de cambiar el comportamiento de los métodos en cada ámbito. Vea el código de ejemplo en SINOPSIS.

FUNCIÓN DE EXPORTACIÓN

mock_guard( @definiciones_de_clase )

@definiciones_de_clase tiene el siguiente formato.

clave
Nombre de la clase u objeto a mockear.
valor
Referencia a un hash. Las claves son nombres de métodos; los valores son referencias de código o escalares. Si el valor es una referencia de código, se utiliza como método. Si el valor es un escalar, el método devolverá el valor especificado.

Puedes mockear métodos de instancia así como métodos de clase (esta característica fue proporcionada por cho45):

use Test::More;
use Test::Mock::Guard qw(mock_guard);
package Some::Class;
sub new { bless {} => shift }
sub foo { "foo" }
package main;
my $obj1 = Some::Class->new;
my $obj2 = Some::Class->new;
{
    my $obj2 = Some::Class->new;
    my $guard = mock_guard( $obj2, { foo => sub { "bar" } } );
    is ($obj1->foo, "foo", "obj1 no ha cambiado" );
    is( $obj2->foo, "bar", "obj2 está mockeado" );
}
is( $obj1->foo, "foo", "obj1" );
is( $obj2->foo, "foo", "obj2" );
done_testing;

MÉTODOS

new( @definiciones_de_clase )

Ver la definición de "mock_guard".

contador_de_llamadas( $nombre_de_clase_o_objeto, $nombre_de_metodo )

Devuelve un número de llamadas de $nombre_de_metodo en $nombre_de_clase_o_objeto.
