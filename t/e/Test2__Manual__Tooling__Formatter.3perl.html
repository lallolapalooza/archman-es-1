Test2::Manual::Tooling::Formatter(3perl) Guía del programador de Perl Test2::Manual::Tooling::Formatter(3perl)

NOMBRE

Test2::Manual::Tooling::Formatter - Cómo escribir un formateador personalizado, en nuestro caso un formateador JSONL.

DESCRIPCIÓN

Este tutorial explica un formateador mínimo que produce cada evento como una cadena JSON en su propia línea. Un formateador real será probablemente significativamente más complicado, pero esto te dará los conceptos básicos necesarios para empezar.

CÓDIGO COMPLETO POR ADELANTADO

package Test2::Formatter::MyFormatter;
use strict;
use warnings;
use JSON::MaybeXS qw/encode_json/;
use base qw/Test2::Formatter/;
sub new { bless {}, shift }
sub encoding {};
sub write {
    my ($self, $e, $num, $f) = @_;
    $f ||= $e->facet_data;
    print encode_json($f), "\n";
}
1;

LÍNEA POR LÍNEA

use base qw/Test2::Formatter/;
Todos los formateadores deben heredar de Test2::Formatter.
sub new { bless {}, shift }
Los formateadores necesitan ser objetos instanciables, este es un método new() mínimo.
sub encoding {};
Para este ejemplo dejamos esta sub vacía. En general, deberías implementar esta sub para asegurarte de que cumples con las situaciones en las que se establece la codificación. Test2::V0 intentará establecer la codificación a UTF8.
sub write { ... }
El método write() es el más importante, cada evento se envía aquí.
my ($self, $e, $num, $f) = @_;
El método write() recibe 3 o 4 argumentos, el cuarto es opcional.
$self
El formateador en sí.
$e
El evento que se está escribiendo
$num
El número de aserción más reciente. Si el evento que se está procesando es una aserción, este se habrá incrementado en 1 desde la última llamada a write. Para eventos que no son aserciones, este número se establece en la aserción más reciente.
$f
ESTE PUEDE SER un hashref que contiene todos los datos de faceta del evento. Más a menudo que no, este será indefinido. Esto solo se establece si los datos de faceta eran necesarios para el hub, y generalmente no lo son.
$f ||= $e->facet_data;
Queremos volcar los datos de faceta del evento. Esto establecerá $f en los datos de faceta a menos que ya tengamos los datos de faceta.
print encode_json($f), "\n";
Esta línea imprime los datos de faceta codificados en JSON y una nueva línea.
