Test::Number::Delta(3) Documentación de Perl contribuida por el usuario Test::Number::Delta(3)

NOMBRE

Test::Number::Delta - Compara la diferencia entre números contra una tolerancia dada

VERSIÓN

versión 1.06

SINOPSIS

# Importar funciones de prueba
use Test::Number::Delta;
# Prueba de igualdad con tolerancia por defecto
delta_ok( 1e-5, 2e-5, 'valores dentro de 1e-6');
# Prueba de desigualdad con tolerancia por defecto
delta_not_ok( 1e-5, 2e-5, 'valores no dentro de 1e-6');
# Proporcionar tolerancia específica
delta_within( 1e-3, 2e-3, 1e-4, 'valores dentro de 1e-4');
delta_not_within( 1e-3, 2e-3, 1e-4, 'valores no dentro de 1e-4');
# Comparar arrays o matrices
@a = ( 3.14, 1.41 );
@b = ( 3.15, 1.41 );
delta_ok( \@a, \@b, 'comparar @a y @b' );
# Establecer una tolerancia por defecto diferente
use Test::Number::Delta within => 1e-5;
delta_ok( 1.1e-5, 2e-5, 'valores dentro de 1e-5'); # ok
# Establecer una tolerancia relativa
use Test::Number::Delta relative => 1e-3;
delta_ok( 1.01, 1.0099, 'valores dentro de 1.01e-3');

DESCRIPCIÓN

En algún momento u otro, la mayoría de los programadores se encuentran necesitando comparar números de punto flotante para igualdad. El idio ma típico es probar si el valor absoluto de la diferencia de los números está dentro de una tolerancia deseada, usualmente llamada épsilon. Este módulo proporciona dicha función para usar con Test::More. El uso es similar a otras funciones de prueba descritas en Test::More. Semánticamente, la función "delta_within" reemplaza este tipo de construcción:

ok ( abs($p - $q) < $epsilon, '$p es igual a $q' ) or
    diag "$p no es igual a $q con una tolerancia de $epsilon";

Si bien no hay nada de malo en esa construcción, es tedioso escribirla repetidamente en un script de prueba. Este módulo hace lo mismo con una sola llamada a función. La función "delta_ok" es similar, pero utiliza un valor por defecto global para épsilon o calcula un épsilon 'relativo' sobre la marcha para que épsilon se escale automáticamente al tamaño de los argumentos de "delta_ok". Ambas funciones se exportan automáticamente.

Dado que la comprobación de la igualdad de punto flotante no siempre es confiable, no es posible comprobar el límite de 'igual a' de 'menor o igual a épsilon'. Por lo tanto, Test::Number::Delta solo compara si el valor absoluto de la diferencia es menor que épsilon (para pruebas de igualdad) o mayor que épsilon (para pruebas de desigualdad).

USO

use Test::Number::Delta;

Sin argumentos, épsilon tiene por defecto 1e-6. (Una elección arbitraria por parte del autor).

use Test::Number::Delta within => 1e-9;

Para especificar un valor por defecto diferente para épsilon, proporcione un parámetro "within" al importar el módulo. El valor debe ser distinto de cero.

use Test::Number::Delta relative => 1e-3;

Como alternativa a usar un valor fijo para épsilon, proporcione un parámetro "relative" al importar el módulo. Esto indica que "delta_ok" debe probar la igualdad con un épsilon que se escala al tamaño de los argumentos. Épsilon se calcula como el valor relativo multiplicado por el valor absoluto del argumento con la mayor magnitud. Matemáticamente, para los argumentos 'x' e 'y':

epsilon = relative * max( abs(x), abs(y) )

Por ejemplo, un valor relativo de "0.01" significaría que los argumentos son iguales si difieren en menos del 1% del valor mayor de los dos. Un valor relativo de 1e-6 significa que los argumentos deben diferir en menos de una millonésima parte del valor mayor. El valor relativo debe ser distinto de cero.

Combinar con un plan de prueba

use Test::Number::Delta 'no_plan';
# o
use Test::Number::Delta within => 1e-9, tests => 1;

Si aún no se ha especificado un plan de prueba, el parámetro opcional para Test::Number::Delta puede ir seguido de un plan de prueba (ver Test::More para más detalles). Si se proporciona un parámetro para Test::Number::Delta, debe ir primero.

FUNCIONES

delta_within

delta_within(  $p,  $q, $epsilon, '$p y $q son iguales dentro de $epsilon' );
delta_within( \@p, \@q, $epsilon, '@p y @q son iguales dentro de $epsilon' );

Esta función prueba la igualdad dentro de un valor de épsilon dado. La prueba es verdadera si el valor absoluto de la diferencia entre $p y $q es menor que épsilon. Si la prueba es verdadera, imprime una declaración de "OK" para usar en pruebas. Si la prueba no es verdadera, esta función imprime un reporte de fallo y diagnóstico. Épsilon debe ser distinto de cero.

Los valores a comparar pueden ser escalares o referencias a arrays. Si los valores son referencias a arrays, la comparación se realiza elemento a elemento para cada índice del array. La comparación elemento a elemento es recursiva, por lo que también se pueden comparar matrices.

Por ejemplo, este fragmento de código compara dos matrices:

my @a = (   [ 3.14, 6.28 ],
            [ 1.41, 2.84 ]   );
my @b = (   [ 3.14, 6.28 ],
            [ 1.42, 2.84 ]   );
delta_within( \@a, \@b, 1e-6, 'comparar @a y @b' );

La muestra imprime lo siguiente:

not ok 1 - comparar @a y @b
# En [1][0]: 1.4100000 y 1.4200000 no son iguales con una tolerancia de 0.000001

delta_ok

delta_ok(  $p,  $q, '$p y $q son suficientemente cercanos a ser iguales' );
delta_ok( \@p, \@q, '@p y @q son suficientemente cercanos a ser iguales' );

Esta función prueba la igualdad dentro de un valor de épsilon por defecto. Ver "USO" para detalles sobre cómo cambiar el valor por defecto. De lo contrario, esta función funciona igual que "delta_within".

delta_not_within

delta_not_within(  $p,  $q, '$p y $q son diferentes' );
delta_not_within( \@p, \@q, $epsilon, '@p y @q son diferentes' );

Esta prueba compara la desigualdad por encima de un valor de épsilon dado. La prueba es verdadera si el valor absoluto de la diferencia entre $p y $q es mayor que épsilon. Para comparaciones de arrays o matrices, la prueba es verdadera si *cualquier* par de valores difiere en más que épsilon. De lo contrario, esta función funciona igual que "delta_within".

delta_not_ok

delta_not_ok(  $p,  $q, '$p y $q son diferentes' );
delta_not_ok( \@p, \@q, '@p y @q son diferentes' );

Esta función prueba la desigualdad por encima de un valor de épsilon por defecto. Ver "USO" para detalles sobre cómo cambiar el valor por defecto. De lo contrario, esta función funciona igual que "delta_not_within".

Test::Number::Delta(3pm) - ArchWiki

NAME

Test::Number::Delta - Test for numbers within a delta

VERSION

1.06

SYNOPSIS

  use Test::Number::Delta qw( test_delta );
  
  test_delta( 1.0, 2.0, 0.1 );  # fails
  test_delta( 1.0, 1.05, 0.1 ); # passes
  test_delta( 1, 1.05, 0.1 );   # passes
  test_delta( 1, 1.05, "0.1" ); # passes
  test_delta( 1, 1.05, "0.1", "Test description" ); # passes
  test_delta( 1, 1.05, "0.1", "Test description %d/%d" ); # passes
  
  # Using the import tag
  use Test::Number::Delta { delta => 0.01 };
  test_delta( 1.0, 1.005 ); # passes
  
  # Using the import tag with description
  use Test::Number::Delta { delta => 0.01, description => "Default delta test" };
  test_delta( 1.0, 1.005 ); # passes
  
  # Using the import tag with description format
  use Test::Number::Delta { delta => 0.01, description_format => "Testing %s" };
  test_delta( 1.0, 1.005, undef, "A value" ); # passes

DESCRIPTION

This module provides a single subroutine, test_delta, which tests whether two numbers are within a specified delta of each other. It is designed to be used in a testing context such as Test::More.

The test passes if abs($number - $expected) <= $delta. The comparison is performed using floating-point arithmetic, so the delta is necessary to account for small inaccuracies.

All arguments are automatically converted to floating-point numbers if they are not already.

USAGE

The test_delta subroutine can be imported using:

  use Test::Number::Delta qw( test_delta );

Or, it can be imported with default arguments using an import hash:

  use Test::Number::Delta { delta => 0.01 };

Default arguments can also include a default description:

  use Test::Number::Delta { delta => 0.01, description => "My default test" };

And a default description format:

  use Test::Number::Delta { delta => 0.01, description_format => "Testing %s" };

FUNCTIONS

test_delta

The test_delta subroutine takes the following arguments:

number
The actual value obtained.
expected
The expected value.
delta
The maximum allowed difference between number and expected. If this argument is undefined, the default delta (0.000001) is used. If a default delta was specified during import, that value is used.
description
An optional test description. If this argument is undefined, no description is used. If a default description was specified during import, that value is used.
description_format
An optional description format string, which will be passed to Test::More's diag function if the test fails. If this argument is undefined, no special formatting is used. If a default description format was specified during import, that value is used.

The test_delta subroutine returns true on success and false on failure. It also calls the appropriate Test::More functions (ok and diag) to report the test results.
