NOMBRE

Test2::Util::Sub - Herramientas para inspeccionar y manipular subs.

DESCRIPCIÓN

Utilidades utilizadas por Test2::Tools para inspeccionar y manipular subrutinas.

EXPORTACIONES

Todas las exportaciones son opcionales, debes especificar las subs a importar.

$nombre = sub_name(\&sub)
Obtiene el nombre de la sub.
mi $hr = sub_info(\&código)
Esto devuelve un hashref con información sobre la sub: 
{
    ref        => \&código,
    cobj       => $cobj,
    name       => "Some::Mod::code",
    file       => "Some/Mod.pm",
    package    => "Some::Mod",
    # Nota: Estos han sido ajustados basándose en conjeturas.
    start_line => 22,
    end_line   => 42,
    lines      => [22, 42],
    # ¡No es un error, estas líneas son diferentes!
    all_lines  => [23, 25, ..., 39, 41],
};
$info->{ref} => \&código
Esta es la sub original pasada a sub_info().
$info->{cobj} => $cobj
Esta es la representación de objeto c de la referencia de código.
$info->{name} => "Some::Mod::code"
Este es el nombre de la referencia de código. Para referencias de código anónimas, puede terminar con '__ANON__'. Tenga en cuenta también que el paquete 'main' es especial y 'main::' puede omitirse.
$info->{file} => "Some/Mod.pm"
El archivo en el que se definió la sub.
$info->{package} => "Some::Mod"
El paquete en el que se definió la sub.
$info->{start_line} => 22
$info->{end_line} => 42
$info->{lines} => [22, 42]
Estos tres campos son la línea de inicio, la línea de fin y el array con ambos, *ajustados*. Es importante tener en cuenta que estas líneas han sido ajustadas y pueden no ser precisas.

Las líneas se obtienen recorriendo las ops. Como tal, la primera línea es la línea de la primera declaración y la última línea es la línea de la última declaración. Esto significa que en subs de varias líneas, las líneas suelen estar desplazadas en 1. Las líneas en estas claves se ajustarán por usted si detecta una sub de varias líneas.

$info->{all_lines} => [23, 25, ..., 39, 41]
Este es un array con las líneas de cada declaración en la sub. A diferencia de los otros campos de línea, estas no han sido ajustadas por usted.
