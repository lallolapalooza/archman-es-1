NOMBRE

Term::ReadPassword - Pedir al usuario una contraseña

SINOPSIS

use Term::ReadPassword;
while (1) {
  my $password = read_password('contraseña: ');
  redo unless defined $password;
  if ($password eq 'flubber') {
    print "Acceso concedido.\n";
    last;
  } else {
    print "Acceso denegado.\n";
    redo;
  }
}

DESCRIPCIÓN

Este módulo te permite pedir al usuario una contraseña de la forma tradicional, desde el teclado, sin que se muestre en pantalla.

Esto no está pensado para su uso en la web; la autenticación de usuarios en la web es un asunto completamente distinto. Además, este módulo generalmente debería usarse junto con la función crypt() de Perl, que se vende por separado.

La función read_password muestra un aviso, lee una línea de texto del teclado y luego devuelve esa línea al llamador. La línea de texto no incluye el carácter de nueva línea, por lo que no es necesario usar chomp.

Mientras el usuario introduce el texto, se procesan algunos caracteres especiales. El carácter de borrado (o el carácter de retroceso) retrocede un carácter, eliminando el último carácter del búfer de entrada (si lo hay). El carácter CR (o el carácter LF) señalará el fin de la entrada, haciendo que se devuelva el búfer de entrada acumulado. Control-U vaciará el búfer de entrada. Y, opcionalmente, el carácter Control-C puede usarse para terminar la operación de entrada. (Ver detalles a continuación.) Todos los demás caracteres, incluso aquellos que normalmente tendrían propósitos especiales, se añadirán al búfer de entrada.

Sin embargo, no se recomienda usar los caracteres de control, aún no especificados, en tus contraseñas, ya que esos caracteres podrían adquirir un significado en una futura versión de este módulo. Las aplicaciones que permiten al usuario establecer sus propias contraseñas pueden desear imponer esta regla, quizás con código similar a este:

{
  # Bloque desnudo para ámbito y redo
  my $new_pw = read_password("Introduce tu nueva contraseña: ");
  if ($new_pw =~ /([^\x20-\x7E])/) {
    my $bad = unpack "H*", $1;
    print "Tu contraseña no puede contener el ";
    print "carácter con código hexadecimal $bad.\n";
    redo;
  } elsif (length($new_pw) < 5) {
    print "¡Tu contraseña debe ser más larga!\n";
    redo;
  } elsif ($new_pw ne read_password("Introdúcela de nuevo: ")) {
    print "Las contraseñas no coinciden.\n";
    redo;
  } else {
    &change_password($new_pw);
    print "Tu contraseña ha sido cambiada.\n";
  }
}

El segundo parámetro de read_password es el valor opcional de "idle_timeout". Si es un número distinto de cero y no hay entrada de teclado durante ese número de segundos, la operación de entrada terminará. Ten en cuenta que este no es un límite de tiempo total, ya que el temporizador se reinicia con cada nuevo carácter.

El tercer parámetro permitirá opcionalmente que la operación de entrada sea terminada por el usuario con Control-C. Si no se proporciona, o es falso, un Control-C escrito se introducirá en el búfer de entrada como cualquier otro carácter. En ese caso, no hay forma desde el teclado de terminar el programa mientras espera entrada. (Es decir, la capacidad normal de generar señales desde el teclado se suspende durante la llamada a read_password).

Si la operación de entrada termina anticipadamente (ya sea porque se excedió el tiempo de espera inactivo o porque se habilitó y se presionó un Control-C), el valor de retorno será "undef". En cualquier caso, no se proporciona ninguna forma de descubrir qué (si es que algo) se escribió antes de la terminación anticipada, o por qué se terminó la operación de entrada.

Para desalentar a los usuarios a escribir sus contraseñas en cualquier lugar excepto en el aviso, se descartará cualquier entrada que haya sido "escrita previamente" antes de que aparezca el aviso. Y ya sea que la operación de entrada termine normalmente o no, se imprimirá un carácter de nueva línea, para que el cursor no permanezca en la línea después del aviso.

ERRORES

Los usuarios de Windows querrán Term::ReadPassword::Win32.

Este módulo tiene una interfaz mal diseñada y debería ser completamente reconsiderada y probablemente reunida con la versión de Windows.

Los usuarios que deseen ver los caracteres de la contraseña reflejados como asteriscos pueden establecer $Term::ReadPassword::USE_STARS a un valor verdadero. Los errores son que algunos terminales pueden no borrar los asteriscos cuando el usuario corrige un error, y que usar asteriscos filtra información a los observadores casuales.

SEGURIDAD

Pensarías que un módulo que maneja contraseñas estaría lleno de características de seguridad. Pensarías eso, pero estarías equivocado. Por ejemplo, perl no proporciona ninguna forma de borrar un fragmento de datos de la memoria. (Es fácil borrarlo de manera que no se pueda acceder desde perl, pero eso no es lo mismo que expurgarlo de la memoria real.) Si has introducido una contraseña, incluso si la variable que contenía esa contraseña ha sido borrada, podría ser posible que alguien encuentre esa contraseña, en texto plano, en un volcado central. Y ese es solo un posible agujero de seguridad.

En resumen, si la seguridad seria es un problema, no uses este módulo.
