NOMBRE

Text::Wrap - ajuste de línea para formar párrafos simples

SINOPSIS

Ejemplo 1

use Text::Wrap;
$initial_tab = "\t";    # Tabulación antes de la primera línea
$subsequent_tab = "";   # Todas las demás líneas alineadas a la izquierda
print wrap($initial_tab, $subsequent_tab, @text);
print fill($initial_tab, $subsequent_tab, @text);
$lines = wrap($initial_tab, $subsequent_tab, @text);
@paragraphs = fill($initial_tab, $subsequent_tab, @text);

Ejemplo 2

use Text::Wrap qw(wrap $columns $huge);
$columns = 132;         # Ajustar en 132 caracteres
$huge = 'die';
$huge = 'wrap';
$huge = 'overflow';

Ejemplo 3

use Text::Wrap;
$Text::Wrap::columns = 72;
print wrap('', '', @text);

DESCRIPCIÓN

Text::Wrap::wrap() es un formateador de párrafos muy simple. Formatea un párrafo a la vez, dividiendo las líneas en los límites de las palabras. La sangría se controla para la primera línea ($initial_tab) y todas las líneas subsiguientes ($subsequent_tab) de forma independiente. Tenga en cuenta: $initial_tab y $subsequent_tab son las cadenas literales que se utilizarán: es poco probable que desee pasar un número.

Text::Wrap::fill() es un formateador simple de varios párrafos. Formatea cada párrafo por separado y luego los une cuando termina. Destruirá cualquier espacio en blanco en el texto original. Divide el texto en párrafos buscando espacios en blanco después de un salto de línea. En otros aspectos, actúa como wrap().

wrap() comprime los espacios en blanco al final en un salto de línea, y fill() elimina todos los espacios en blanco al final.

Ambos wrap() y fill() devuelven una única cadena.

A diferencia de la utilidad Unix antigua fmt(1), este módulo tiene en cuenta correctamente los caracteres combinados Unicode (como los diacríticos) que puedan aparecer en cada línea, tanto para la expansión como para la no expansión. Estos son caracteres de sobreimpresión que no incrementan la posición lógica. Asegúrese de tener habilitadas las configuraciones de Unicode apropiadas.

SOBREESCRITURAS

Text::Wrap::wrap() tiene una serie de variables que controlan su comportamiento. Dado que otros módulos podrían estar utilizando Text::Wrap::wrap(), se sugiere que deje estas variables en paz. Si no puede hacer eso, utilice "local($Text::Wrap::VARIABLE) = TUVALOR" cuando cambie los valores para que se restaure el valor original. Este truco local() no funcionará si importa la variable a su propio espacio de nombres.

Las líneas se ajustan en $Text::Wrap::columns columnas (valor predeterminado: 76). $Text::Wrap::columns debe establecerse al ancho completo de su dispositivo de salida. De hecho, cada línea resultante tendrá una longitud no superior a "$columns - 1".

Es posible controlar qué caracteres terminan las palabras modificando $Text::Wrap::break. Establezca esto en una cadena como '[\s:]' (para dividir antes de espacios o dos puntos) o una expresión regular precompilada como "qr/[\s']/" (para dividir antes de espacios o apóstrofes). El valor predeterminado es simplemente '\s'; es decir, las palabras se terminan con espacios. (Esto significa, entre otras cosas, que la puntuación final como puntos o comas se queda con la palabra a la que están "adjuntas".) Establecer $Text::Wrap::break a una expresión regular que no consuma ningún carácter (quizás solo una aserción de lookahead) provocará advertencias.

Nota para principiantes: En el ejemplo 2, arriba, $columns se importa al espacio de nombres local y se establece localmente. En el ejemplo 3, $Text::Wrap::columns se establece en su propio espacio de nombres sin importarlo.

Text::Wrap::wrap() comienza su trabajo expandiendo todas las tabulaciones de su entrada a espacios. Lo último que hace es volver a convertir los espacios en tabulaciones. Si no desea tabulaciones en sus resultados, establezca $Text::Wrap::unexpand a un valor falso. Igualmente, si no desea usar tabulaciones de 8 caracteres, establezca $Text::Wrap::tabstop al número de caracteres que desea para sus tabulaciones.

Si desea separar sus líneas con algo que no sea "\n", establezca $Text::Wrap::separator a su preferencia. Esto reemplaza todos los saltos de línea con $Text::Wrap::separator. Si solo desea conservar los saltos de línea existentes pero agregar nuevas divisiones con otra cosa, establezca $Text::Wrap::separator2 en su lugar.

Cuando se encuentran palabras más largas que $columns, se rompen. wrap() agrega un "\n" en la columna $columns. Este comportamiento se puede anular estableciendo $huge a 'die' o a 'overflow'. Cuando se establece a 'die', las palabras grandes causarán que se llame a die(). Cuando se establece a 'overflow', las palabras grandes se dejarán intactas.

Notas históricas: 'die' solía ser el valor predeterminado de $huge. Ahora, 'wrap' es el valor predeterminado.

EJEMPLOS

Código:

print wrap("\t","",<<END);
This is a bit of text that forms 
a normal book-style indented paragraph
END

Resultado:

"     This is a bit of text that forms
a normal book-style indented paragraph   
"

Código:

$Text::Wrap::columns=20;
$Text::Wrap::separator="|";
print wrap("","","This is a bit of text that forms a normal book-style paragraph");

Resultado:

"This is a bit of|text that forms a|normal book-style|paragraph"

Para el manejo correcto de caracteres de ancho medio y completo de Asia Oriental, consulte Text::WrapI18N. Para controles más detallados: Text::Format.

Text::Wrap - Perl core modules

Text::Wrap

manpages/Text/Wrap.pm.html

A simple text wrapping module.

SYNOPSIS

use Text::Wrap;
print wrap( 'This is a long string that needs to be wrapped.  ', 40 );
print wrap( <<END_TEXT, 40 ) , "-----\n" , wrap( <<END_TEXT, 40 );
This is a long string that needs to be wrapped.
This is another long string that needs to be wrapped.

END_TEXT
END_TEXT

DESCRIPTION

This module provides a single function, wrap, which performs text wrapping. It's designed to be simple and avoid the overhead of more complex modules like Text::Format.

The wrap function takes two arguments: the text to wrap, and the desired width. It returns the wrapped text. The text is split into lines at whitespace characters, ensuring that no line exceeds the specified width.

Leading and trailing whitespace on each line are preserved. Multiple spaces between words are also preserved.

The wrap function does not attempt to perform any intelligent formatting, such as justification or hyphenation. It is intended for basic text wrapping tasks.

FUNCTIONS

wrap( TEXT, WIDTH )
Wraps the given TEXT to the specified WIDTH. Returns the wrapped text.
