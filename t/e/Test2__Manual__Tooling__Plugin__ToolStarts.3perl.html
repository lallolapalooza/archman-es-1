Test2::Manual::Tooling::Plugin::ToolStarts(3perl) Guía de referencia para programadores de Perl Test2::Manual::Tooling::Plugin::ToolStarts(3perl)

NOMBRE

Test2::Manual::Tooling::Plugin::ToolStarts - Cómo añadir comportamientos que ocurren cuando una herramienta inicia su trabajo.

DESCRIPCIÓN

Este tutorial te ayudará a escribir plugins que tengan comportamiento cuando una herramienta comienza. Todas las herramientas deben empezar adquiriendo un objeto de contexto. Este tutorial te muestra los hooks que puedes usar para aprovechar la adquisición del contexto.

CÓDIGO COMPLETO POR ADELANTADO

package Test2::Plugin::MyPlugin;
use Test2::API qw{
    test2_add_callback_context_init
    test2_add_callback_context_acquire
};
sub import {
    my $class = shift;
    # Informarnos cada vez que una herramienta solicita un contexto, y darnos
    # una oportunidad de modificar los parámetros antes de encontrarlo.
    test2_add_callback_context_acquire(sub {
        my $params_ref = shift;
        print "Una herramienta ha solicitado el contexto\n";
    });
    # Llamar a la función de retorno cada vez que se crea un nuevo contexto,
    # no se llama si se encuentra un contexto existente.
    test2_add_callback_context_init(sub {
        my $ctx_ref = shift;
        print "Se ha creado un nuevo contexto\n";
    });
}
1;

LÍNEA POR LÍNEA

use Test2::API qw{test2_add_callback_context_init test2_add_callback_context_acquire};
Esto importa las funciones de retorno de llamada test2_add_callback_context_init() y test2_add_callback_context_acquire().
test2_add_callback_context_acquire(sub { ... })
Aquí es donde añadimos nuestra función de retorno de llamada para la adquisición del contexto. Cada vez que se llama a Test2::API::context(), se ejecutará la función de retorno de llamada.
my $params_ref = shift
En las funciones de retorno de llamada de test2_add_callback_context_acquire(), recibimos exactamente 1 argumento, una referencia a los parámetros que context() usará para encontrar el contexto.
print "Una herramienta ha solicitado el contexto\n"
Imprime una notificación cada vez que una herramienta pide un contexto.
test2_add_callback_context_init(sub { ... })
Añade nuestra función de retorno de llamada de inicialización del contexto. Estas funciones de retorno de llamada se activan cada vez que se crea un contexto completamente nuevo. No se llama si se encuentra un contexto existente. En resumen, esto solo se dispara para la herramienta de nivel superior, no para herramientas anidadas.
my $ctx_ref = shift
Las referencias a código para test2_add_callback_context_init() recibirán exactamente 1 argumento, el contexto recién creado.
print "Se ha creado un nuevo contexto\n"
Imprime una notificación cada vez que se crea un nuevo contexto.
