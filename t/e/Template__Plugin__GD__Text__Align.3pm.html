NOMBRE

Template::Plugin::GD::Text::Align - Dibuja cadenas alineadas en imágenes GD

SINOPSIS

[% USE align = GD.Text.Align(gd_image); %]

EJEMPLOS

[% FILTER null;
    USE im  = GD.Image(100,100);
    USE gdc = GD.Constants;
    # asignar algunos colores
    black = im.colorAllocate(0,   0, 0);
    red   = im.colorAllocate(255,0,  0);
    blue  = im.colorAllocate(0,  0,  255);
    # Dibujar un óvalo azul
    im.arc(50,50,95,75,0,360,blue);
    USE a = GD.Text.Align(im);
    a.set_font(gdc.gdLargeFont);
    a.set_text("Hola");
    a.set(colour => red, halign => "center");
    a.draw(50,70,0);
    # Salida de imagen en formato PNG
    im.png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Text.Align proporciona una interfaz para el módulo GD::Text::Align. Permite dibujar texto en imágenes GD con varias alineaciones y orientaciones.

Vea GD::Text::Align para más detalles. Vea Template::Plugin::GD::Text::Wrap para un plugin que le permite renderizar texto con saltos de línea en imágenes GD.
