Test2::Tools(3perl) Guía del programador de Perl Test2::Tools(3perl)

NOMBRE

Test2::Tools - Documentación para Herramientas.

DESCRIPCIÓN

Las herramientas (Tools) son módulos que exportan funciones de prueba, típicamente todas relacionadas con un aspecto específico de las pruebas. Si tienes un par de categorías de exportaciones diferentes, puede que quieras dividirlas en módulos separados.

Las herramientas deben exportar funciones de prueba. La carga de herramientas **no** debe tener efectos secundarios, ni alterar el comportamiento de otras herramientas. Si quieres alterar comportamientos o crear efectos secundarios, probablemente quieras escribir un Test2::Plugin.

PREGUNTAS FRECUENTES

¿Por qué se llama Test2::Tools y no Test2::Tool?
Esta pregunta surge ya que Tools es el único espacio de nombres en plural. Esto se debe a que cada Plugin debe ser una unidad distinta de funcionalidad, pero una distribución de Tools puede (y usualmente debe) exportar varias herramientas. Un paquete (bundle) también se describe típicamente como una sola unidad. A nadie le gustaría Test2::Bundles::Foo.
¿Mis herramientas deben heredar de Test2::Tools?
No. Actualmente esta clase está vacía. Eventualmente podríamos querer añadir comportamiento, en cuyo caso no queremos que nadie herede de ella todavía.

¿CÓMO ESCRIBO UN MÓDULO DE 'TOOLS'?

Es muy fácil escribir herramientas:

package Test2::Tools::Mine
use strict;
use warnings;
# Todas las herramientas deben usar la función context()
use Test2::API qw/context/;
our @EXPORTS = qw/ok plan/;
use base 'Exporter';
sub ok($;$) {
    my ($bool, $name) = @_;
    # Todas las funciones de herramientas deben empezar obteniendo un contexto
    my $ctx = context();
    # El contexto es la interfaz principal para generar eventos
    $ctx->ok($bool, $name);
    # Cuando termines, liberas el contexto
    $ctx->release;
    return $bool ? 1 : 0;
}
sub plan {
    my ($max) = @_;
    my $ctx = context();
    $ctx->plan($max);
    $ctx->release;
}
1;

Consulta Test2::API::Context para obtener documentación sobre lo que el objeto $ctx puede hacer.
