NOMBRE

Template::Toolkit - Sistema de procesamiento de plantillas

Introducción

Template Toolkit es una colección de módulos Perl que implementan un sistema de procesamiento de plantillas rápido, flexible, potente y extensible.

Es "agnóstico a la entrada" y puede utilizarse igualmente bien para procesar cualquier tipo de documento de texto: HTML, XML, CSS, Javascript, código Perl, texto plano, etc. Sin embargo, se utiliza con mayor frecuencia para generar contenido web estático y dinámico, por lo que nos centraremos en eso aquí.

Aunque Template Toolkit está escrito en Perl, no es necesario ser un programador de Perl para utilizarlo. Fue diseñado para permitir a los no programadores crear y mantener fácilmente sitios web basados en plantillas sin tener que meterse con código Perl o volverse loco con copiar y pegar.

Sin embargo, Template Toolkit también está diseñado para ser extremadamente flexible y extensible. Si eres un programador de Perl, o conoces a alguien que lo sea, puedes conectar fácilmente Template Toolkit con tu código, datos, bases de datos y aplicaciones web existentes. Además, puedes extender fácilmente Template Toolkit mediante el uso de su mecanismo de plugins y otras APIs para desarrolladores.

Independientemente del contexto en el que lo utilice, el propósito principal de Template Toolkit es permitirle crear una clara separación entre los elementos de presentación de su sitio web y todo lo demás.

Si está generando páginas web estáticas, puede utilizarlo para separar los elementos de interfaz de usuario repetidos comúnmente en cada página (encabezados, menús, pies de página, etc.) del contenido principal. Si está generando páginas web dinámicas para el front-end de una aplicación web, también lo utilizará para mantener el código Perl del back-end completamente separado de las plantillas HTML del front-end. En cualquier caso, una clara separación de responsabilidades es lo que le permite concentrarse en una cosa a la vez sin que las otras cosas se interpongan. Y de eso se trata Template Toolkit.

Documentación

La documentación de Template Toolkit se organiza en cinco secciones.

Template::Manual contiene información detallada sobre el uso de Template Toolkit. Proporciona ejemplos de su uso e incluye una referencia completa del lenguaje de plantillas, opciones de configuración, filtros, plugins y otras partes componentes.

La página Template::Modules enumera los módulos Perl que componen Template Toolkit. Explica brevemente qué hace cada uno y proporciona un enlace a la documentación completa de cada módulo para obtener más información. Si es un programador de Perl que busca utilizar Template Toolkit desde sus programas Perl, esta sección probablemente le interesará.

La mayor parte, si no toda, la información que necesita para llamar a Template Toolkit desde Perl se encuentra en la documentación del módulo Template. Solo necesita empezar a pensar en los otros módulos si desea extender o modificar Template Toolkit de alguna manera, o si está interesado en mirar bajo el capó para ver cómo funciona todo.

La documentación de cada módulo está incrustada como POD en cada módulo, por lo que siempre puede usar "perldoc" desde la línea de comandos para leer la documentación de un módulo. Por ejemplo:

$ perldoc Template
$ perldoc Template::Context
  ...etc...

Cabe señalar que toda la demás documentación, incluido el manual del usuario, está disponible como POD. Por ejemplo:

$ perldoc Template::Manual
$ perldoc Template::Manual::Config
  ...etc...

La sección Template::Tools contiene la documentación de Template::Tools::tpage y Template::Tools::ttree. Estos son dos programas de línea de comandos que se distribuyen con Template Toolkit. tpage se utiliza para procesar un único archivo de plantilla, ttree para procesar directorios enteros de archivos de plantilla.

La sección Template::Tutorial contiene dos tutoriales introductorios sobre el uso de Template Toolkit. El primero es Template::Tutorial::Web sobre la generación de contenido web. El segundo es Template::Tutorial::Datafile sobre el uso de Template Toolkit para generar otros formatos de datos, incluido XML.

La última sección del manual es Template::FAQ, que contiene respuestas a algunas de las preguntas más frecuentes sobre Template Toolkit.

Puede leer la documentación en formato HTML ya sea en línea en el sitio web de Template Toolkit, http://template-toolkit.org/, o descargando la versión HTML de la documentación de http://template-toolkit.org/download/index.html#html_docs y descomprimiéndola en su máquina local.
