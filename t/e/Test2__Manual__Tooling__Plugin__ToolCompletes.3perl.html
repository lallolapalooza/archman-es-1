NOMBRE

Test2::Manual::Tooling::Plugin::ToolCompletes - Cómo añadir comportamientos que ocurren cuando una herramienta completa su trabajo.

DESCRIPCIÓN

Este tutorial ayuda a comprender cómo añadir comportamientos que ocurren cuando una herramienta ha terminado su trabajo. Todas las herramientas necesitan adquirir y luego liberar un contexto, para este tutorial hacemos uso de los hooks de liberación que se llaman cada vez que una herramienta libera el objeto de contexto.

CÓDIGO COMPLETO POR ADELANTADO

package Test2::Plugin::MyPlugin;
use Test2::API qw{test2_add_callback_context_release};
sub import {
    my $class = shift;
    test2_add_callback_context_release(sub {
        my $ctx_ref = shift;
        print "Context was released\n";
    });
}
1;

LÍNEA POR LÍNEA

use Test2::API qw{test2_add_callback_context_release};
Esto importa la callback test2_add_callback_context_release().
test2_add_callback_context_release(sub { ... })
my $ctx_ref = shift
Los coderefs para test2_add_callback_context_release() recibirán exactamente 1 argumento, el contexto que se está liberando.
print "Context was released\n"
Imprime una notificación cada vez que se libera el contexto.
