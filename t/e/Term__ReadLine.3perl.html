Term::ReadLine(3perl) Guía del programador Perl Term::ReadLine(3perl)

NOMBRE

Term::ReadLine - Interfaz de Perl a varios paquetes "readline". Si no se encuentra ningún paquete real, sustituye stubs en lugar de funciones básicas.

SINOPSIS

use Term::ReadLine;
my $term = Term::ReadLine->new('Simple Perl calc');
my $prompt = "Introduce tu expresión aritmética: ";
my $OUT = $term->OUT || \*STDOUT;
while ( defined ($_ = $term->readline($prompt)) ) {
  my $res = eval($_);
  warn $@ if $@;
  print $OUT $res, "\n" unless $@;
  $term->addhistory($_) if /\S/;
}

DESCRIPCIÓN

Este paquete es solo una interfaz para otros paquetes. Es un stub para configurar una interfaz común a las diversas implementaciones de ReadLine que se encuentran en CPAN (bajo el espacio de nombres "Term::ReadLine::*").

Conjunto mínimo de funciones compatibles

Todas las funciones compatibles deben llamarse como métodos, es decir, como

$term = Term::ReadLine->new('nombre');

o como

$term->addhistory('fila');

donde $term es un valor de retorno de Term::ReadLine->new().

"ReadLine"
devuelve el paquete real que ejecuta los comandos. Entre los valores posibles se encuentran "Term::ReadLine::Gnu", "Term::ReadLine::Perl", "Term::ReadLine::Stub".
"new"
devuelve el manejador para llamadas posteriores a las siguientes funciones. El argumento es el nombre de la aplicación. Opcionalmente puede ir seguido de dos argumentos para los manejadores de archivo "IN" y "OUT". Estos argumentos deben ser globs.
"readline"
obtiene una línea de entrada, *posiblemente* con soporte real de "readline". Se elimina la nueva línea final. Devuelve "undef" en "EOF".
"addhistory"
añade la línea al historial de entrada, desde donde se puede utilizar si el "readline" real está presente.
"IN", "OUT"
devuelven los manejadores de archivo para entrada y salida o "undef" si la entrada y salida de "readline" no se pueden utilizar para Perl.
"MinLine"
Si se proporciona un argumento, es un consejo sobre el tamaño mínimo de la línea para ser incluida en el historial. "undef" significa no incluir nada en el historial. Devuelve el valor anterior.
"findConsole"
devuelve un array con dos cadenas que dan los nombres más apropiados para los archivos de entrada y salida utilizando las convenciones "<$in", ">out".

Las cadenas devueltas pueden no ser útiles para open() de 3 argumentos.

Atributos
devuelve una referencia a un hash que describe la configuración interna del paquete. Los nombres de las claves en este hash se ajustan a las convenciones estándar con el prefijo "rl_" eliminado.
"Features"
Devuelve una referencia a un hash con claves que son las características presentes en la implementación actual. Varias características opcionales se utilizan en la interfaz mínima: "appname" debe estar presente si se reconoce el primer argumento de "new", y "minline" debe estar presente si el método "MinLine" no es un dummy. "autohistory" debe estar presente si las líneas se añaden al historial automáticamente (quizás sujeto a "MinLine"), y "addhistory" si el método "addhistory" no es un dummy.

Si el método "Features" informa de que la característica "attribs" está presente, el método "Attribs" no es un dummy.

Funciones adicionales compatibles

En realidad, "Term::ReadLine" puede utilizar otro paquete que admita un conjunto más rico de comandos.

Todos estos comandos son llamables a través de la interfaz de métodos y tienen nombres que se ajustan a las convenciones estándar con el prefijo "rl_" eliminado.

El paquete stub incluido con la distribución de perl permite algunos métodos adicionales:

"tkRunning"
hace que el bucle de eventos de Tk se ejecute mientras se espera la entrada del usuario (es decir, durante el método "readline").
"event_loop"
Registra callbacks para esperar la entrada del usuario (es decir, durante el método "readline"). Esto reemplaza a tkRunning.

El primer callback registrado es el callback para esperar. Se espera que el callback llame al bucle de eventos actual hasta que haya algo esperando en el manejador de archivo de entrada. El parámetro pasado es el valor devuelto por el segundo callback.

El segundo callback registrado es el callback para registro. El manejador de archivo de entrada (a menudo STDIN, pero no necesariamente) será pasado.

Por ejemplo, con AnyEvent:

$term->event_loop(sub {
  my $data = shift;
  $data->[1] = AE::cv();
  $data->[1]->recv();
}, sub {
  my $fh = shift;
  my $data = [];
  $data->[0] = AE::io($fh, 0, sub { $data->[1]->send() });
  $data;
});

El segundo callback es opcional si el callback se registra antes de la llamada a $term->readline.

La desregistro se realiza en este caso llamando a event_loop con "undef" como su parámetro:

$term->event_loop(undef);

Esto hará que se elimine la referencia al array de datos, permitiendo que la recolección de basura normal lo limpie. Con AnyEvent, eso hará que $data->[0] se limpie, y AnyEvent cancelará automáticamente el observador en ese momento. Si otro bucle requiere más que eso para limpiar un observador de archivo, será responsabilidad del llamador manejarlo.

"ornaments"
hace que la línea de comandos destaque utilizando datos de termcap. El argumento de "ornaments" debe ser 0, 1, o una cadena de la forma "aa,bb,cc,dd". Los cuatro componentes de esta cadena deben ser nombres de *capacidades de terminal*, los dos primeros se emitirán para hacer que el prompt destaque, los dos últimos para hacer que la línea de entrada destaque.
"newTTY"
toma dos argumentos que son el manejador de archivo de entrada y el manejador de archivo de salida. Cambia para usar estos manejadores de archivo.

Se puede verificar si el paquete ReadLine cargado actualmente soporta estos métodos comprobando las "Features" correspondientes.

EXPORTACIÓN

ENTORNO

La variable de entorno "PERL_RL" rige qué clon de ReadLine se carga. Si el valor es falso, se utiliza una interfaz dummy. Si el valor es verdadero, debe ser la cola del nombre del paquete a usar, como "Perl" o "Gnu".

Como caso especial, si el valor de esta variable está separado por espacios, la cola puede usarse para deshabilitar los adornos estableciendo la cola como "o=0" o "ornaments=0". La cabeza debe ser como se describió anteriormente, por ejemplo

Si la variable no está establecida, o si la cabeza de la lista separada por espacios está vacía, se carga el mejor paquete disponible.

export "PERL_RL=Perl o=0" # Usar ReadLine de Perl sin adornos
export "PERL_RL= o=0"     # Usar el mejor ReadLine disponible sin adornos
