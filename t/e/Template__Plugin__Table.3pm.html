NOMBRE

Template::Plugin::Table - Plugin para presentar datos en una tabla

SINOPSIS

[% USE table(lista, filas=n, columnas=n, superposicion=n, relleno=0) %]
[% FOREACH item IN table.fila(n) %]
   [% item %]
[% END %]
[% FOREACH item IN table.columna(n) %]
   [% item %]
[% END %]
[% FOREACH fila IN table.filas %]
   [% FOREACH item IN fila %]
      [% item %]
   [% END %]
[% END %]
[% FOREACH columna IN table.columnas %]
   [% columna.primero %] - [% columna.ultimo %] ([% columna.tamano %] entradas)
[% END %]

DESCRIPCIÓN

El plugin "Table" te permite formatear una lista de elementos de datos en una tabla virtual. Cuando creas un plugin "Table" a través de la directiva "USE", simplemente pasa una referencia de lista como primer parámetro y luego especifica un número fijo de filas o columnas.

[% USE Table(lista, filas=5) %]
[% USE table(lista, columnas=5) %]

El nombre del plugin "Table" también puede especificarse en minúsculas como se muestra en el segundo ejemplo anterior. También puedes especificar un nombre de variable alternativo para el plugin según la sintaxis regular de Template Toolkit.

[% USE midatos = table(lista, filas=5) %]

El plugin presenta entonces una vista similar a una tabla del conjunto de datos. Los datos no se reorganizan realmente de ninguna manera, pero están disponibles a través de los métodos fila(), columna(), filas() y columnas() como si estuvieran formateados en una simple tabla bidimensional de "n" filas x "n" columnas.

Así, si tuviéramos una lista de ejemplo "alfabeto" que contuviera las letras de la '"a"' a la '"z"', las directivas "USE" anteriores crearían plugins que representarían las siguientes vistas del alfabeto.

[% USE table(alfabeto, ... %]
filas=5                  columnas=5
a  f  k  p  u  z        a  g  m  s  y
b  g  l  q  v           b  h  n  t  z
c  h  m  r  w           c  i  o  u
d  i  n  s  x           d  j  p  v
e  j  o  t  y           e  k  q  w
                        f  l  r  x

Podemos solicitar una fila o columna particular utilizando los métodos fila() y columna().

[% USE table(alfabeto, filas=5) %]
[% FOREACH item = table.fila(0) %]
   # [% item %] se establece en cada uno de [ a f k p u z ] por turno
[% END %]
[% FOREACH item = table.columna(2) %]
   # [% item %] se establece en cada uno de [ m n o p q r ] por turno
[% END %]

Los datos en las filas se devuelven de izquierda a derecha, las columnas de arriba a abajo. La primera fila/columna es 0. Por defecto, las filas o columnas que contienen valores vacíos se rellenarán con el valor indefinido para completarlas al mismo tamaño que todas las demás filas o columnas.

Por ejemplo, la última fila (fila 4) en el primer ejemplo contendría los valores "[ e j o t y indefinido ]". Template Toolkit aceptará de forma segura estos valores indefinidos e imprimirá una cadena vacía. También puedes usar la directiva IF para comprobar si el valor está establecido.

[% FOREACH item = table.fila(4) %]
   [% IF item %]
      Elemento: [% item %]
   [% END %]
[% END %]

Puedes deshabilitar explícitamente la opción "relleno" al crear el plugin para devolver filas/columnas acortadas donde los datos estén vacíos.

[% USE table(alfabeto, columnas=5, relleno=0) %]
[% FOREACH item = table.columna(4) %]
   # [% item %] se establece en cada uno de 'y z'
[% END %]

El método filas() devuelve todas las filas/columnas de la tabla como una referencia a una lista de filas (que a su vez son referencias de lista). El método fila(), cuando se llama sin argumentos, llama a filas() para devolver todas las filas de la tabla.

Lo mismo ocurre con columnas() y columna().

[% USE table(alfabeto, columnas=5) %]
[% FOREACH fila IN table.filas %]
   [% FOREACH item IN fila %]
      [% item %]
   [% END %]
[% END %]

Template Toolkit proporciona los métodos virtuales "primero", "ultimo" y "tamano" que pueden llamarse en referencias de lista para devolver la primera/última entrada o el número de entradas en una lista. El siguiente ejemplo muestra cómo podríamos usar esto para proporcionar un índice alfabético dividido en 3 partes iguales.

[% USE table(alfabeto, columnas=3, relleno=0) %]
[% FOREACH grupo IN table.columna %]
   [ [% grupo.primero %] - [% grupo.ultimo %] ([% grupo.tamano %] letras) ]
[% END %]

Esto produce la siguiente salida:

[ a - i (9 letras) ]
[ j - r (9 letras) ]
[ s - z (8 letras) ]

También podemos usar el método virtual de propósito general "unir" que une los elementos de la lista usando la cadena de conexión especificada.

[% USE table(alfabeto, columnas=5) %]
[% FOREACH fila IN table.filas %]
   [% fila.unir(' - ') %]
[% END %]

Los datos en la tabla se ordenan hacia abajo en lugar de transversalmente, pero se pueden transformar fácilmente en la salida. Por ejemplo, para formatear nuestros datos en 5 columnas con datos ordenados transversalmente en lugar de verticalmente, especificamos "filas=5" para ordenar los datos de esta manera:

a  f  .  .
b  g  .
c  h
d  i
e  j

y luego iteramos hacia abajo por cada columna (a-e, f-j, etc.) imprimiendo los datos transversalmente.

a  b  c  d  e
f  g  h  i  j
.  .
.

El código de ejemplo para hacer esto sería muy similar al siguiente:

[% USE table(alfabeto, filas=3) %]
[% FOREACH columnas IN table.columnas %]
  [% FOREACH item IN columnas %]
    [% item %]
  [% END %]
[% END %]

Salida:

a  b  c
d  e  f
g  h  i
j  .  .
.

Además de una referencia de lista, al constructor del plugin "Table" se le puede pasar una referencia a un objeto Template::Iterator o a una subclase del mismo. Primero se llama al método get_all() de Template::Iterator en el iterador para devolver todos los elementos restantes. Estos estarán disponibles a través de la interfaz habitual de Table.

[% USE DBI(dsn,usuario,contrasena) -%]
# query() devuelve un iterador
[% resultados = DBI.query('SELECT * FROM alfabeto ORDER BY letra') %]
# pasar al plugin Table
[% USE tabla(resultados, filas=8 superposicion=1 relleno=0) -%]
[% FOREACH fila IN tabla.columnas -%]
   [% fila.primero.letra %] - [% fila.ultimo.letra %]:
      [% fila.unir(', ') %]
[% END %]
