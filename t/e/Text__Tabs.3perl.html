Text::Tabs(3perl) Guía de referencia para programadores de Perl Text::Tabs(3perl)

NOMBRE

Text::Tabs - expande y desexpande tabulaciones como expand(1) y unexpand(1) de unix

SINOPSIS

use Text::Tabs;
$tabstop = 4;  # predeterminado = 8
@lineas_sin_tabulaciones = expand(@lineas_con_tabulaciones);
@lineas_con_tabulaciones = unexpand(@lineas_sin_tabulaciones);

DESCRIPCIÓN

Text::Tabs hace la mayor parte de lo que hacen las utilidades de unix expand(1) y unexpand(1). Dada una línea con tabulaciones, "expand" reemplaza esas tabulaciones con el número apropiado de espacios. Dada una línea con o sin tabulaciones, "unexpand" agrega tabulaciones cuando puede ahorrar bytes al hacerlo, como el comando "unexpand -a".

A diferencia de las utilidades antiguas de unix, este módulo tiene en cuenta correctamente los caracteres combinatorios de Unicode (como los diacríticos) que puedan ocurrir en cada línea, tanto para la expansión como para la desexpansión. Estos son caracteres de sobreimpresión que no incrementan la posición lógica. Asegúrese de tener habilitada la configuración de Unicode apropiada.

EXPORTACIONES

Se exportan las siguientes:

expand
unexpand
$tabstop
La variable $tabstop controla cuántas posiciones de columna están separadas las tabulaciones. El valor predeterminado es 8.

Tenga en cuenta que local($tabstop) no hace lo correcto y si desea usar "local" para anular $tabstop, necesita usar local($Text::Tabs::tabstop).

EJEMPLO

#!perl
# unexpand -a
use Text::Tabs;
while (<>) {
  print unexpand $_;
}

En lugar del comando "expand" del shell, use:

perl -MText::Tabs -n -e 'print expand $_'

En lugar del comando "unexpand -a" del shell, use:

perl -MText::Tabs -n -e 'print unexpand $_'

ERRORES

Text::Tabs solo maneja tabulaciones ("\t") y caracteres combinatorios ("/\pM/"). No cuenta hacia atrás para espacios de retroceso ("\b"), omite otros caracteres de control no imprimibles ("/\pC/"), o de lo contrario, trata con cualquier otro carácter de ancho cero, medio y completo.
