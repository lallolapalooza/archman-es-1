Template__Stash__XS(3pm)

Paquete: perl-template-toolkit

Licencias: PerlArtistic

Template::Stash::XS(3) Documentación aportada por el usuario de Perl Template::Stash::XS(3)

NOMBRE

Template::Stash::XS - Almacén de variables de alta velocidad escrito en C

SINOPSIS

use Template;
use Template::Stash::XS;
my $stash = Template::Stash::XS->new(\%vars);
my $tt2   = Template->new({ STASH => $stash });

DESCRIPCIÓN

El módulo Template:Stash::XS es una implementación de Template::Stash escrita en C. Las "XS" en el nombre se refieren al sistema de extensión XS de Perl para interconectar Perl con código C. Funciona igual que la implementación normal de Perl de Template::Stash pero se ejecuta aproximadamente el doble de rápido.

La forma más fácil de usar el almacén XS es configurar Template Toolkit para que lo use por defecto. Puedes hacerlo en el momento de la instalación (cuando ejecutas "perl Makefile.PL") respondiendo 's' a las preguntas:

¿Desea compilar el módulo Stash XS?      s
¿Desea usar el Stash XS por defecto?    s

Consulta el archivo INSTALL distribuido con Template Toolkit para obtener más detalles sobre la instalación.

Si no eliges usar el almacén XS por defecto, entonces deberías usar el elemento de configuración "STASH" cuando crees un nuevo objeto Template. Este debe hacer referencia a un objeto de almacén XS que hayas creado manualmente.

use Template;
use Template::Stash::XS;
my $stash = Template::Stash::XS->new(\%vars);
my $tt2   = Template->new({ STASH => $stash });

Alternativamente, puedes establecer la variable de paquete $Template::Config::STASH de la siguiente manera:

use Template;
use Template::Config;
$Template::Config::STASH = 'Template::Stash::XS';
my $tt2 = Template->new();

El almacén XS se utilizará automáticamente.

Si quieres usar el almacén XS por defecto y no quieres reinstalar Template Toolkit, puedes modificar manualmente el módulo "Template/Config.pm" cerca de la línea 42 para que diga:

$STASH = 'Template::Stash::XS';
