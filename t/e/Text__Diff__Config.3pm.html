Text::Diff::Config(3) Documentación de Perl aportada por el usuario Text::Diff::Config(3)

NOMBRE

Text::Diff::Config - configuración global para Text::Diff (como un módulo separado).

SINOPSIS

use Text::Diff::Config;

$Text::Diff::Config::Output_Unicode = 1;

DESCRIPCIÓN

Este módulo configura Text::Diff y sus módulos relacionados. Actualmente solo contiene una variable global $Text::Diff::Config::Output_Unicode, que es un indicador booleano que, si se establece, emite caracteres unicode tal como son, sin escaparlos como " \x{HHHH} " primero.

Se inicializa con el valor de $ENV{DIFF_OUTPUT_UNICODE} , pero puede establecerse a un valor diferente en tiempo de ejecución, incluso usando local.
