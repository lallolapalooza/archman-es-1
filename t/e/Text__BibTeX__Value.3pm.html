Text__BibTeX__Value(3pm)

Text::BibTeX::Value(3pm) Documentación de Perl contribuida por usuarios Text::BibTeX::Value(3pm)

NOMBRE

Text::BibTeX::Value - interfaces a valores BibTeX y valores simples

SINOPSIS

use Text::BibTeX;
$entry = Text::BibTeX::Entry->new;
# establece la bandera 'preserve_values' a 1 para este análisis
$entry->parse ($filename, $filehandle, 1);
# el método 'get' ahora devuelve un objeto Text::BibTeX::Value
# en lugar de una cadena
$value = $entry->get ($field);
# consulta el objeto `Value` (lista de objetos SimpleValue)
@all_values = $value->values;
$first_value = $value->value (0);
$last_value = $value->value (-1);
# consulta los objetos de valor simple -- el tipo será uno de BTAST_STRING,
# BTAST_MACRO, o BTAST_NUMBER
use Text::BibTex (':nodetypes');   # importa constantes de "tipo de nodo"
$is_macro = ($first_value->type == BTAST_MACRO);
$text = $first_value->text;

DESCRIPCIÓN

La clase "Text::BibTeX::Value" proporciona dos clases, "Text::BibTeX::Value" y "Text::BibTeX::SimpleValue", que respectivamente dan acceso a los valores "compuestos" de BibTeX y "valores simples". Recuerda que cada valor de campo en un registro de BibTeX es la concatenación de uno o más valores simples, y cada uno de esos valores simples puede ser una cadena literal, un macro (abreviatura) o un número. Normalmente con "Text::BibTeX", los valores de campo se procesan "completamente", así que solo tendrás acceso a la cadena resultante de expandir macros, convertir números a cadenas, concatenar todas las sub-cadenas y reducir espacios en blanco en la cadena resultante.

Por ejemplo, en el siguiente registro:

@article{homer97,
  author = "Homer Simpson" # y # "Ned Flanders",
  title = {Territorial Imperatives in Modern Suburbia},
  journal = jss,
  year = 1997
}

vemos el rango completo de opciones. El campo "author" tiene tres valores simples: una cadena, un macro ("and"), y otra cadena. El campo "title" es una sola cadena, y los campos "journal" y "year" son respectivamente una sola macro y un número. Si parseas este registro en el modo normal:

$entry = Text::BibTeX::Entry->new($entry_text);

entonces el método "get" en "$entry" devolvería cadenas simples. Suponiendo que la macro "and" esté definida como " and ", entonces:

$entry->get ('author')

devolvería la cadena Perl "Homer Simpson and Ned Flanders".

Sin embargo, también puedes pedir que la biblioteca preserve los valores de entrada en tus registros, es decir, no pierdas la información sobre qué valores usan macros, qué valores están compuestos de múltiples valores simples, y así sucesivamente. Hay dos formas de hacer esta solicitud: por archivo y por entrada. Para una solicitud por archivo, usa el método "preserve_values" en tu objeto "File":

$bibfile = Text::BibTeX::File->new($filename);
$bibfile->preserve_values (1);
$entry = Text::BibTeX::Entry->new($bibfile);
$entry->get ($field);        # devuelve un objeto Value
$bibfile->preserve_values (0);
$entry = Text::BibTeX::Entry->new($bibfile);
$entry->get ($field);        # devuelve una cadena

Si no estás utilizando un objeto "File" o quieres tener mayor control, entonces tienes que pasar el flag "preserve_values" cuando invoques "read", "parse" o "parse_s" en tus objetos "Entry":

# sin objeto File, parseando desde un texto
$entry = Text::BibTeX::Entry->new;
$entry->parse_s ($entry_text, 0);  # preserve_values=0 (por defecto)
$entry->get ($field);        # devuelve una cadena
$entry->parse_s ($entry_text, 1);
$entry->get ($field);        # devuelve un objeto Value object
# usando un objeto File, pero con control más fino
$entry->read ($bibfile, 0);  # ahora get devuelve cadenas (por defecto)
$entry->read ($bibfile, 1);  # ahora get devuelve objetos Value

Un valor compuesto, generalmente llamado un valor, es simplemente una lista de valores simples. La clase "Text::BibTeX::Value" (aquí llamada "Value") proporciona una interfaz simple a esta lista; puedes solicitar la lista completa o un miembro individual de la lista. La clase "SimpleValue" te da acceso a los núcleos de cada valor simple, que consisten en el "tipo" y el "texto". El tipo solo indica si este valor simple es una cadena, un macro o un número; se representa mediante la traducción Perl del tipo de nodo desde C. Los tipos posibles son "BTAST_STRING", "BTAST_NUMBER" y "BTAST_MACRO". El texto es simplemente lo que aparece en el texto original del registro, ya sea una cadena, un número o una macro.

Por ejemplo, podríamos parsear el registro anterior en modo "preserve values" así:

$entry->parse_s ($entry_text, 1);   # preserve_values es 1

Luego, usando el método "get" en "$entry" devolvería no una cadena, sino un objeto "Value". Podríamos obtener la lista de todos los valores simples usando el método "values", o un valor individual usando "value":

$author = $entry->get ('author');   # ahora un objeto Text::BibTeX::Value
@all_values = $author->values;      # array de Text::BibTeX::SimpleValue
$second = $author->value (1);       # igual que $all_values[1]

Los valores simples se pueden consultar usando los métodos "Text::BibTeX::SimpleValue", "type" y "text":

$all_values[0]->type;               # devuelve BTAST_STRING
$second->type;                      # devuelve BTAST_MACRO
$all_values[0]->text;               # "Homer Simpson"
$second->text;                      # "and" (¡NO la expansión del macro!)
$entry->get ('year')->value (0)->text;   # "1997"

MÉTODOS

Normalmente, no necesitarás crear objetos "Value" o "SimpleValue"—estos se crearán para ti cuando un registro es parseado, y se te devolverán por el método "get" de la clase "Entry". Por lo tanto, los métodos de consulta ("values" y "value" para la clase "Value", "type" y "text" para la clase "SimpleValue") probablemente sean todo lo que debes tener en cuenta. Si lo deseas, sin embargo, puedes crear nuevos objetos "Value" y "SimpleValue" usando los constructores respectivos de las clases. También puedes volver a instalar objetos "Value" recién creados en un objeto "Entry" existente usando el método "set" de la entrada; no importa cómo se parseó el registro, esto es aceptable en cualquier momento.

Métodos de Text::BibTeX::Value

new (SVAL, ...)
Crear un objeto "Value" nuevo a partir de una lista de valores simples. Cada valor simple, SVAL, puede ser o bien un objeto "SimpleValue" o una referencia a una lista de dos elementos que contenga el tipo y el texto del valor simple. Por ejemplo, una forma de recrear el campo "author" del registro de ejemplo en "DESCRIPCIÓN" sería: 
$and_macro = Text::BibTeX::SimpleValue->new (BTAST_MACRO, 'and');
$value = Text::BibTeX::Value->new 
   ([BTAST_STRING, 'Homer Simpson'],
    $and_macro,
    [BTAST_STRING, 'Ned Flanders']);

El objeto "Value" resultante podría luego instalarse en un registro usando el método "set" de la clase "Entry".

NAME

Text::BibTeX::Value - Representação de valores de entrada do BibTeX

SYNOPSIS

    use Text::BibTeX qw(:nodetypes);

    # Cria um valor composto
    my $value = Text::BibTeX::Value->new([
        Text::BibTeX::SimpleValue->new(BTAST_STRING, 'Hello'),
        Text::BibTeX::SimpleValue->new(BTAST_NUMBER, '123'),
        Text::BibTeX::SimpleValue->new(BTAST_STRING, 'World'),
    ]);

    # Obtém os valores simples
    my @simple_values = $value->values;

    # Obtém um valor simples específico
    my $first_simple_value = $value->value(0);
    my $last_simple_value = $value->value(-1);

DESCRIPTION

Esta classe representa um valor de entrada do BibTeX. Um valor do BibTeX pode ser um único item (como uma string ou um número) ou uma sequência de itens (como um nome de autor com várias partes).

Um "Value" object é essencialmente uma lista de "SimpleValue" objects. Você não vai criar estes objetos diretamente, mas eles serão criados para você quando você fizer o parse de uma entrada do BibTeX.

METHODS

new (LIST)
Cria um novo "Value" object. LIST deve ser uma lista de "SimpleValue" objects. Se você precisar converter uma lista de strings e tipos para uma lista de "SimpleValue" objects, use o método "Text::BibTeX::SimpleValue::new" para cada item.
values ()
Retorna a lista de objetos "SimpleValue" que compõem um objeto "Value".
value (NUM)
Retorna o objeto "SimpleValue" NUM a partir da lista de objetos "SimpleValue" que compõem um objeto "Value". Isso é como uma referência de array Perl: NUM é baseado em zero, e números negativos contam a partir do final do array.

Métodos Text::BibTeX::SimpleValue

new (TYPE, TEXT)
Cria um novo objeto "SimpleValue" com o TYPE e TEXT especificados. TYPE deve ser um dos tipos permitidos para valores simples do BibTeX, ou seja, "BTAST_STRING", "BTAST_NUMBER", ou "BTAST_MACRO". Provavelmente você vai querer importar essas constantes de "Text::BibTeX" usando a tag de exportação "nodetypes": 
use Text::BibTeX qw(:nodetypes);

TEXT pode ser qualquer string. Note que se TYPE for "BTAST_NUMBER" e TEXT não for uma string de dígitos, o objeto "SimpleValue" será criado de qualquer forma, mas um aviso será emitido. Nenhum aviso é emitido sobre macros inexistentes.

type ()
Retorna o tipo de um valor simples. Este será um dos "tipos de nó" permitidos, conforme descrito em "new" acima.
text ()
Retorna o texto de um valor simples. Esta é apenas o texto que aparece na entrada original - nome da macro não expandida ou número não convertido. (Claro, converter números não faz diferença em Perl; de fato, é tudo o mesmo em C também, já que o código C mantém os números como strings de dígitos. É simplesmente uma questão de saber se a string de dígitos é representada como uma string ou um número, o que você pode querer saber se deseja preservar a estrutura da entrada o máximo possível.)
