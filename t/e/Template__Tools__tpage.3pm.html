NOMBRE

Template::Tools::tpage - Procesar plantillas desde la línea de comandos

USO

tpage [ --define var=valor ] archivo(s)

DESCRIPCIÓN

El script tpage es un simple envoltorio alrededor del procesador Template Toolkit. Los archivos especificados por nombre en la línea de comandos son procesados en turno por el procesador de plantillas y la salida resultante se envía a STDOUT y puede ser redirigida correspondientemente. por ejemplo:

tpage mi_archivo > mi_archivo.out
tpage encabezado mi_archivo pie > mi_archivo.html

Si no se especifican nombres de archivo en la línea de comandos, tpage leerá STDIN para la entrada.

La opción "--define" puede ser utilizada para establecer los valores de las variables de la plantilla. por ejemplo:

tpage --define autor="Andy Wardley" esqueleto.pm > MiMódulo.pm

El archivo de configuración .tpagerc

Puedes usar un archivo .tpagerc en tu directorio de inicio.

El propósito de este archivo es establecer cualquier opción de configuración *global* que desees aplicar *cada vez* que se ejecute tpage. Por ejemplo, puedes usar "include_path" para usar archivos de plantilla de un directorio de plantillas genérico.

Ejecuta "tpage -h" para un resumen de las opciones disponibles.

Ver Template para información general sobre el Perl Template Toolkit y el lenguaje y características de las plantillas.
