Text::Template::Preprocess(3) Documentación de Perl contribuida por el usuario Text::Template::Preprocess(3)

NOMBRE

Text::Template::Preprocess - Expandir texto de plantilla con Perl incrustado

VERSIÓN

versión 1.61

SINOPSIS

use Text::Template::Preprocess;
my $t = Text::Template::Preprocess->new(...);  # idéntico a Text::Template
# Rellenar plantilla, pero preprocesar cada fragmento de código con pp().
my $result = $t->fill_in(..., PREPROCESSOR => \&pp);
my $old_pp = $t->preprocessor(\&new_pp);

DESCRIPCIÓN

"Text::Template::Preprocess" proporciona una nueva opción "PREPROCESSOR" para "fill_in". Si se proporciona la opción "PREPROCESSOR", debe ser una referencia a una subrutina preprocesadora. Al rellenar una plantilla, "Text::Template::Preprocessor" usará esta subrutina para preprocesar el fragmento de programa antes de evaluar el código.

La subrutina preprocesadora se llamará repetidamente, una vez por cada fragmento de programa. El fragmento de programa estará en $_. La subrutina debe modificar el contenido de $_ y retornar. "Text::Template::Preprocess" ejecutará entonces el contenido de $_ e insertará el resultado en la parte apropiada de la plantilla.

"Text::Template::Preprocess" los objetos también soportan un método de utilidad, preprocessor(), que establece un nuevo preprocesador para el objeto. Este preprocesador se utiliza para todas las llamadas subsiguientes a "fill_in", excepto donde se anule por una opción explícita de "PREPROCESSOR". preprocessor() devuelve la función preprocesadora predeterminada anterior, o indefinida si no había ninguna. Cuando se invoca sin argumentos, preprocessor() devuelve la función preprocesadora predeterminada actual del objeto sin cambiarla.

En todos los demás aspectos, "Text::Template::Preprocess" es idéntico a "Text::Template".

¿POR QUÉ?

Un propósito posible: Si tus archivos contienen mucho JavaScript, como esto:

Texto plano aquí...
{ código perl }
<script language=JavaScript>
      if (br== "n3") { 
          // etc.
      }
</script>
{ más código perl }
Más texto plano...

No quieres que "Text::Template" confunda las llaves del programa JavaScript con código Perl ejecutable. Una estrategia:

sub quote_scripts {
  s(<script(.*?)</script>)(q{$1})gsi;
}
