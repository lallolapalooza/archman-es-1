Test::Output(3) Documentación de Perl aportada por el usuario Test::Output(3)

NOMBRE

Test::Output - Utilidades para probar mensajes de STDOUT y STDERR.

SINOPSIS

 use Test::More tests => 4;
 use Test::Output;
 sub writer {
   print "Escribir salida.\n";
   print STDERR "Error de salida.\n";
 }
 stdout_is(\&writer,"Escribir salida.\n",'Probar STDOUT');
 stderr_isnt(\&writer,"No hay error de salida.\n",'Probar STDERR');
 combined_is(
             \&writer,
             "Escribir salida.\nError de salida.\n",
             'Probar STDOUT & STDERR combinado'
            );
 output_is(
           \&writer,
           "Escribir salida.\n",
           "Error de salida.\n",
           'Probar STDOUT & STDERR'
         );
# Usar bloques desnudos.
stdout_is { print "prueba" } "prueba", "Probar STDOUT";
stderr_isnt { print "mala prueba" } "prueba", "Probar STDERR";
output_is { print 'STDOUT'; print STDERR 'STDERR' }
  "STDOUT", "STDERR", "Probar salida";

DESCRIPCIÓN

Test::Output proporciona una interfaz sencilla para probar la salida enviada a "STDOUT" o "STDERR". Se incluyen varias utilidades diferentes para intentar ser lo más flexible posible para el probador.

Asimismo, Capture::Tiny proporciona un mecanismo de captura mucho más robusto que el Test::Output::Tie original.

PRUEBAS

STDOUT

stdout_is
stdout_isnt
stdout_is  ( $coderef, $esperado, 'descripción' );
stdout_is    { ... } $esperado, 'descripción';
stdout_isnt( $coderef, $esperado, 'descripción' );
stdout_isnt  { ... } $esperado, 'descripción';

stdout_is() captura la salida enviada a "STDOUT" desde $coderef y la compara con $esperado. La prueba pasa si son iguales.

stdout_isnt() pasa si "STDOUT" no es igual a $esperado.

stdout_like
stdout_unlike
stdout_like  ( $coderef, qr/$esperado/, 'descripción' );
stdout_like    { ... } qr/$esperado/, 'descripción';
stdout_unlike( $coderef, qr/$esperado/, 'descripción' );
stdout_unlike  { ... } qr/$esperado/, 'descripción';

stdout_like() captura la salida enviada a "STDOUT" desde $coderef y la compara con la expresión regular en $esperado. La prueba pasa si la expresión regular coincide.

stdout_unlike() pasa si STDOUT no coincide con la expresión regular.

STDERR

stderr_is
stderr_isnt
stderr_is  ( $coderef, $esperado, 'descripción' );
stderr_is    {... } $esperado, 'descripción';
stderr_isnt( $coderef, $esperado, 'descripción' );
stderr_isnt  {... } $esperado, 'descripción';

stderr_is() es similar a "stdout_is", excepto que captura "STDERR". La prueba pasa si "STDERR" de $coderef es igual a $esperado.

stderr_isnt() pasa si "STDERR" no es igual a $esperado.

stderr_like
stderr_unlike
stderr_like  ( $coderef, qr/$esperado/, 'descripción' );
stderr_like   { ...} qr/$esperado/, 'descripción';
stderr_unlike( $coderef, qr/$esperado/, 'descripción' );
stderr_unlike  { ...} qr/$esperado/, 'descripción';

stderr_like() es similar a stdout_like() excepto que compara la expresión regular $esperado con "STDERR" capturado desde $codref. La prueba pasa si la expresión regular coincide.

stderr_unlike() pasa si "STDERR" no coincide con la expresión regular.

SALIDA COMBINADA

combined_is
combined_isnt
combined_is   ( $coderef, $esperado, 'descripción' );
combined_is   {... } $esperado, 'descripción';
combined_isnt ( $coderef, $esperado, 'descripción' );
combined_isnt {... } $esperado, 'descripción';

combined_is() dirige "STDERR" a "STDOUT" y luego captura "STDOUT". Esto es equivalente a "2>&1" de UNIX. La prueba pasa si la "STDOUT" y "STDERR" combinadas de $coderef son iguales a $esperado.

combined_isnt() pasa si la "STDOUT" y "STDERR" combinadas no son iguales a $esperado.

combined_like
combined_unlike
combined_like   ( $coderef, qr/$esperado/, 'descripción' );
combined_like   { ...} qr/$esperado/, 'descripción';
combined_unlike ( $coderef, qr/$esperado/, 'descripción' );
combined_unlike { ...} qr/$esperado/, 'descripción';

combined_like() es similar a combined_is() excepto que compara una expresión regular ("$esperado)" con "STDOUT" y "STDERR" capturados desde $codref. La prueba pasa si la expresión regular coincide.

combined_unlike() pasa si la "STDOUT" y "STDERR" combinadas no coinciden con la expresión regular.

SALIDA

output_is
output_isnt
output_is  ( $coderef, $esperado_stdout, $esperado_stderr, 'descripción' );
output_is    {... } $esperado_stdout, $esperado_stderr, 'descripción';
output_isnt( $coderef, $esperado_stdout, $esperado_stderr, 'descripción' );
output_isnt  {... } $esperado_stdout, $esperado_stderr, 'descripción';

La función output_is() es una combinación de las funciones stdout_is() y stderr_is(). Por ejemplo:

output_is(sub {print "foo"; print STDERR "bar";},'foo','bar');

es funcionalmente equivalente a

stdout_is(sub {print "foo";},'foo')
  && stderr_is(sub {print STDERR "bar";},'bar');

excepto que $coderef solo se ejecuta una vez.

A diferencia de stdout_is() y stderr_is(), que ignoran STDERR y STDOUT respectivamente, output_is() requiere tanto "STDOUT" como "STDERR"

Test::Output(3pm)

NAME

Test::Output – Test STDOUT and STDERR

SYNOPSIS

    use Test::More tests => 1;
    use Test::Output qw( output_is stdout_is );

    output_is(
        sub {
            print "foo";
            print STDERR "bar";
        },
        'foo',
        'bar'
    );

DESCRIPTION

Test::Output provides an easy way to test the output of code to STDOUT and STDERR. It builds upon Test::Builder.

The primary functions are for testing exact matches (output_is, stdout_is, stderr_is) and for testing against regular expressions (output_like, stdout_like, stderr_like).

It also provides ways to capture output without testing (stdout_from, stderr_from, output_from, combined_from).

All of these functions can take a coderef or a block of code.

TESTS

The following subs are available:

output_is
stdout_is
stderr_is
    output_is( $coderef, $expected_stdout, $expected_stderr, 'description' );
    output_is { ... } $expected_stdout, $expected_stderr, 'description';
    stdout_is( $coderef, $expected_stdout, 'description' );
    stdout_is { ... } $expected_stdout, 'description';
    stderr_is( $coderef, $expected_stderr, 'description' );
    stderr_is { ... } $expected_stderr, 'description';

output_is, stdout_is, and stderr_is test if the output from the code matches exactly.

output_is tests both STDOUT and STDERR. It takes a coderef and two expected strings. The test passes if both strings match the respective output channels.

Setting either $expected_stdout or $expected_stderr to "undef" ignores "STDOUT" or "STDERR" respectively.

    output_is(sub {print "foo"; print STDERR "bar";},'foo',undef);

is the same as

    stdout_is(sub {print "foo";},'foo')

output_isnt provides the opposite function of output_is. It is a combination of stdout_isnt and stderr_isnt.

    output_isnt(sub {print "foo"; print STDERR "bar";},'bar','foo');

is functionally equivalent to

    stdout_isnt(sub {print "foo";},'bar')
      && stderr_isnt(sub {print STDERR "bar";},'foo');

As with output_is, setting either $expected_stdout or $expected_stderr to "undef" ignores the output to that facility.

    output_isnt(sub {print "foo"; print STDERR "bar";},undef,'foo');

is the same as

    stderr_is(sub {print STDERR "bar";},'foo')
output_like
output_unlike
    output_like( $coderef, $regex_stdout, $regex_stderr, 'description' );
    output_like { ... } $regex_stdout, $regex_stderr, 'description';
    output_unlike( $coderef, $regex_stdout, $regex_stderr, 'description' );
    output_unlike { ... } $regex_stdout, $regex_stderr, 'description';

output_like and output_unlike follow the same principles as output_is and output_isnt except they use a regular expression for matching.

output_like attempts to match $regex_stdout and $regex_stderr against "STDOUT" and "STDERR" produced by $coderef. The test passes if both match.

    output_like(sub {print "foo"; print STDERR "bar";},qr/foo/,qr/bar/);

The above test is successful.

Like output_is, setting either $regex_stdout or $regex_stderr to "undef" ignores the output to that facility.

    output_like(sub {print "foo"; print STDERR "bar";},qr/foo/,undef);

is the same as

    stdout_like(sub {print "foo"; print STDERR "bar";},qr/foo/);

output_unlike test pass if output from $coderef doesn't match $regex_stdout and $regex_stderr.

EXPORTS

By default, all subroutines are exported by default.

  • :stdout - the subs with "stdout" in the name.
  • :stderr - the subs with "stderr" in the name.
  • :functions - the subs with "_from" at the end.
  • :output - the subs with "output" in the name.
  • :combined - the subs with "combined" in the name.
  • :tests - everything that outputs TAP
  • :all - everything (which is the same as the default)

FUNCTIONS

stdout_from

    my $stdout = stdout_from($coderef)
    my $stdout = stdout_from { ... };

stdout_from() executes $coderef and captures STDOUT.

stderr_from

    my $stderr = stderr_from($coderef)
    my $stderr = stderr_from { ... };

stderr_from() executes $coderef and captures "STDERR".

output_from

    my ($stdout, $stderr) = output_from($coderef)
    my ($stdout, $stderr) = output_from {...};

output_from() executes $coderef one time capturing both "STDOUT" and "STDERR".

combined_from

    my $combined = combined_from($coderef);
    my $combined = combined_from {...};

combined_from() executes $coderef one time combines "STDOUT" and "STDERR", and captures them. combined_from() is equivalent to using "2>&1" in UNIX.
