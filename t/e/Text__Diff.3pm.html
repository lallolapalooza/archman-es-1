Text::Diff(3) Documentación de Perl aportada por el usuario Text::Diff(3)

NOMBRE

Text::Diff - Realizar diferencias entre archivos y conjuntos de registros

SINOPSIS

use Text::Diff;
## Mezclar y combinar nombres de archivo, cadenas, manejadores de archivos, subs productoras,
## o arrays de registros; devuelve la diferencia en una cadena.
## ADVERTENCIA: puede devolver diferencias B<grandes> para archivos grandes.
my $diff = diff "file1.txt", "file2.txt", { STYLE => "Context" };
my $diff = diff \$string1,   \$string2,   \%options;
my $diff = diff \*FH1,       \*FH2;
my $diff = diff \&reader1,   \&reader2;
my $diff = diff \@records1,  \@records2;
## También puede mezclar tipos de entrada:
my $diff = diff \@records1,  "file_B.txt";

DESCRIPCIÓN

diff() proporciona un conjunto básico de servicios similar a la utilidad "diff" de GNU. No es ni de lejos tan completo en características como "diff" de GNU, pero está mejor integrado con Perl y disponible en todas las plataformas. A menudo es más rápido que llamar externamente al ejecutable "diff" del sistema para archivos pequeños, y generalmente más lento en archivos más grandes.

Se basa en Algorithm::Diff para, bueno, el algoritmo. Esto puede no producir la misma diferencia exacta que un ejecutable "diff" local del sistema, pero será una diferencia válida y comprensible por "patch". No hemos visto diferencias entre la lógica de Algorithm::Diff y la de "diff" de GNU, pero no las hemos examinado para asegurarnos de que sean idénticas.

Nota: Si no desea importar la función "diff", haga lo siguiente:

use Text::Diff ();
require Text::Diff;

Eso es una ocurrencia bastante rara, por lo que diff() se exporta por defecto.

Si pasa un nombre de archivo, pero el archivo no se puede leer, entonces diff() "croak".

OPCIONES

diff() toma dos parámetros de los cuales obtener la entrada y un conjunto de opciones para controlar su salida. Las opciones son:

NOMBRE_ARCHIVO_A, MTIME_A, NOMBRE_ARCHIVO_B, MTIME_B
El nombre del archivo y los tiempos de modificación de los "archivos".

Estos se rellenan automáticamente para cada archivo cuando diff() recibe un nombre de archivo, a menos que se proporcione un valor definido.

Si no se proporciona un nombre de archivo y no se proporcionan NOMBRE_ARCHIVO_A y NOMBRE_ARCHIVO_B o son "undef", la cabecera no se imprimirá.

No se usa en las diferencias de "OldStyle".

DESPLAZAMIENTO_A, DESPLAZAMIENTO_B
El índice de la primera línea / elemento. Estos tienen un valor predeterminado de 1 para todos los tipos de parámetros excepto las referencias ARRAY, para las cuales el valor predeterminado es 0. Esto se debe a que las referencias ARRAY se presumen que son estructuras de datos, mientras que las otras son texto orientado a líneas.
ESTILO
"Unified", "Context", "OldStyle", o una referencia a un objeto o clase para una clase que proporcione métodos file_header(), hunk_header(), hunk(), hunk_footer() y file_footer(). Los dos métodos footer() se proporcionan solo para sobreescritura; ninguno de los formatos los proporciona.

Por defecto es "Unified" (a diferencia de "diff" estándar, pero Unified es lo que se usa más a menudo al enviar parches y es el más legible para humanos de los tres.

Si el paquete indicado por ESTILO no tiene un método hunk(), diff() lo cargará automáticamente (carga diferida). Dado que todos esos paquetes deben heredar de "Text::Diff::Base", esto debería ser genial.

Los estilos se pueden especificar como nombres de clase ("ESTILO => 'Foo'"), en cuyo caso se les llamará con new() sin parámetros, o como objetos ("ESTILO => Foo->new").

CONTEXTO
Cuántas líneas antes y después de cada diferencia mostrar. Ignorado en las diferencias de estilo antiguo. Por defecto es 3.
SALIDA
Ejemplos y sus subrutinas equivalentes: 
SALIDA   => \*FOOHANDLE,   # como: sub { print FOOHANDLE shift() }
SALIDA   => \$output,      # como: sub { $output .= shift }
SALIDA   => \@output,      # como: sub { push @output, shift }
SALIDA   => sub { $output .= shift },

Si no se proporciona "SALIDA", devuelve las diferencias en una cadena. Si "SALIDA" es una referencia "CODE", se llamará una vez con la cabecera del archivo (opcional), y una vez por cada cuerpo de bloque con el texto a emitir. Si "SALIDA" es un IO::Handle, la salida se emitirá a ese manejador.

PREFIJO_NOMBRE_ARCHIVO_A, PREFIJO_NOMBRE_ARCHIVO_B
La cadena a imprimir antes del nombre del archivo en la cabecera. No se usa en las diferencias de "OldStyle". Los valores predeterminados son "---", "+++" para Unified y "***", "+++" para Context.
GENERADOR_CLAVE, ARGUMENTOS_GENERADOR_CLAVE
Estos se pasan a "traverse_sequences" en Algorithm::Diff.

Nota: si no se define ninguna opción "NOMBRE_ARCHIVO_", la cabecera no se imprimirá. Si al menos una está presente, la otra y ambas opciones "MTIME_" deben estar presentes o se generarán advertencias de "Uso de variable indefinida" (excepto en las diferencias de "OldStyle", que ignora estas opciones).

Clases de formato

Estas funciones implementan los formatos de salida. Se agrupan en clases para que diff() pueda usar nombres de clase para llamar al conjunto correcto de rutinas de salida y para que usted pueda heredar de ellas fácilmente. No hay constructores ni métodos de instancia para estas clases, aunque las subclases pueden proporcionarlos si es necesario.

Cada clase tiene métodos file_header(), hunk_header(), hunk(), y footer() idénticos a los documentados en la sección "Text::Diff::Unified". header() se llama antes de que se llame por primera vez a hunk(), footer() después. La función de pie de página predeterminada es un método vacío proporcionado para sobreescribir:

sub footer { return ""Fin del parche\n"" }

Algunos formatos de salida son proporcionados por módulos externos (que se cargan automáticamente), como Text::Diff::Table. Estos se documentan aquí para mantener la documentación simple.

Text::Diff::Base

Devuelve "" para todos los métodos (aparte de new()).

Text::Diff::Unified::file_header
$s = Text::Diff::Unified->file_header( $options );

Devuelve una cadena que contiene una cabecera unificada. El único parámetro es el hash "options" pasado a diff(), que contiene al menos:

NOMBRE_ARCHIVO_A  => $fn1,
MTIME_A     => $mtime1,
NOMBRE_ARCHIVO_B  => $fn2,
MTIME_B     => $mtime2

Puede contener también

PREFIJO_NOMBRE_ARCHIVO_A    => &q
"---", FILENAME_PREFIX_B => "+++",

para anular los prefijos predeterminados (se muestran los valores predeterminados).

Text::Diff::Unified::hunk_header
Text::Diff::Unified->hunk_header( \@ops, $options );

Devuelve una cadena que contiene el encabezado de una sección de diff unificado.

Text::Diff::Unified::hunk
Text::Diff::Unified->hunk( \@seq_a, \@seq_b, \@ops, $options );

Devuelve una cadena que contiene la salida de una sección de diff unificado.

LIMITACIONES

Debe cargar ambos archivos de entrada completamente en memoria y almacenarlos con una cantidad normal de sobrecarga de Perl (una ubicación de arreglo) por registro. Esto se infiere de la implementación de Algorithm::Diff, que toma dos arreglos. Si Algorithm::Diff alguna vez ofrece un modo incremental, esto se puede cambiar (contacte a los mantenedores de Algorithm::Diff y "Text::Diff" si necesita esto; no debería ser demasiado difícil atar arreglos de esta manera).

No proporciona la mayoría de las opciones más refinadas de GNU "diff": escaneo recursivo de árboles de directorios, ignorar líneas en blanco / espacios en blanco, etc., etc. Todos estos se pueden agregar a medida que el tiempo lo permita y surja la necesidad, muchos son bastante fáciles; se agradecen los parches.

Utiliza clausuras internamente, esto puede provocar fugas en las versiones de Perl 5.6.1 y anteriores si se usa muchas veces durante la vida útil de un proceso.

VER TAMBIÉN

Algorithm::Diff - la implementación subyacente del algoritmo de diferencias utilizado por "Text::Diff".

YAML::Diff - encuentra diferencias entre dos documentos YAML.

HTML::Differences - encuentra diferencias entre dos documentos HTML. Utiliza un enfoque más sensato que HTML::Diff.

XML::Diff - encuentra diferencias entre dos documentos XML.

Array::Diff - encuentra las diferencias entre dos arreglos de Perl.

Hash::Diff - encuentra las diferencias entre dos hashes de Perl.

Data::Diff - encuentra diferencias entre estructuras de datos arbitrarias.
