NOMBRE

Text::Query::Solve - Clase base para la resolución de consultas

SINOPSIS

package Text::Query::SolveSource;
use Text::Query::Parse;

use vars qw(@ISA);
@ISA = qw(Text::Query::Solve);

DESCRIPCIÓN

Este módulo proporciona una clase base virtual para la resolución de consultas.

Define el método "match" y "matchscalar" que es llamado por el objeto "Text::Query" para aplicar una consulta a una fuente de datos.

MÉTODOS

match (EXPR [TARGET])
Si "TARGET" es un escalar, "match" devuelve un valor verdadero si la fuente de datos especificada por "TARGET" coincide con la expresión de consulta "EXPR". Si no se proporciona "TARGET", la coincidencia se realiza contra $_.

Si "TARGET" es un array, "match" devuelve una lista (posiblemente vacía) de todos los elementos coincidentes. Si los elementos del array son referencias a sub-arrays, la coincidencia se realiza contra el primer elemento de cada sub-array. Esto permite asociar información arbitraria (por ejemplo, nombres de archivo) con cada fuente de datos a coincidir.

Si "TARGET" es una referencia a un array, "match" devuelve una referencia a una lista (posiblemente vacía) de todos los elementos coincidentes.

matchscalar (EXPR [TARGET])
Se comporta igual que "MATCH" cuando "TARGET" es un escalar o no se proporciona.
