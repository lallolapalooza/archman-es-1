NOMBRE

Test::utf8 - pruebas útiles de utf8

SINOPSIS

# comprobar que la cadena es válida
is_valid_string($string);   # comprobar que la cadena es válida
is_sane_utf8($string);      # comprobar que no está doblemente codificada
# comprobar que la cadena tiene ciertos atributos
is_flagged_utf8($string1);   # tiene la bandera utf8 establecida
is_within_ascii($string2);   # solo tiene caracteres ascii
isnt_within_ascii($string3); # tiene caracteres fuera del rango ascii
is_within_latin_1($string4); # solo tiene caracteres latin-1
isnt_within_ascii($string5); # tiene caracteres fuera del rango latin-1

DESCRIPCIÓN

Este módulo es una colección de pruebas útiles para trabajar con cadenas utf8 en Perl.

Este módulo tiene dos tipos de pruebas: Las pruebas de validez comprueban si una cadena es válida y no está corrupta, mientras que las pruebas de características comprobarán que la cadena tiene un conjunto dado de características.

Pruebas de Validez

is_valid_string($string, $testname)
Comprueba si la cadena es "válida", es decir, esto pasa y devuelve verdadero a menos que la bandera utf8 interna no se haya establecido en un escalar que no esté hecho de una secuencia de bytes utf-8 válida.

Esto *nunca* debería suceder y, en teoría, esta prueba siempre debería pasar. A menos que usted (o un módulo que utilice) manipule internamente un escalar usando funciones privadas de Encode o código XS, nunca debería encontrarse en una situación en la que tenga un escalar corrupto. Pero si lo hace, y lo hace, esta función debería ayudarle a detectar el problema.

Para ser claros, aquí hay un ejemplo del caso de error que esto puede detectar:

my $mark = "Mark";
my $leon = "L\x{e9}on";
is_valid_string($mark);  # pasa, no es utf8
is_valid_string($leon);  # pasa, no es utf8
my $iloveny = "I \x{2665} NY";
is_valid_string($iloveny);      # pasa, utf8 correcto
my $acme = "L\x{c3}\x{a9}on";
Encode::_utf8_on($acme);      # (por favor, no haga cosas como esta)
is_valid_string($acme);       # pasa, secuencia de bytes utf8 correcta mejorada
Encode::_utf8_on($leon);      # (esto es por lo que no hace cosas como esta)
is_valid_string($leon);       # falla! el byte \x{e9} no es utf8 válido
is_sane_utf8($string, $name)
Esta prueba falla si la cadena contiene algo que parece ser utf8 dudoso, es decir, contiene algo que se parece a la secuencia multibyte de un carácter latin-1 pero perl no ha sido instruido para tratarlo como tal. Las cadenas que no son utf8 siempre pasan automáticamente.

Algunos ejemplos pueden ayudar:

# Esto pasará porque es una cadena latin-1 normal
is_sane_utf8("Hello L\x{e9}eon");
# esto fallará porque el \x{c3}\x{a9} se parece a la
# secuencia de bytes utf8 de e-aguda
my $string = "Hello L\x{c3}\x{a9}on";
is_sane_utf8($string);
# esto pasará porque el utf8 se interpreta correctamente como utf8
Encode::_utf8_on($string)
is_sane_utf8($string);

Obviamente, esto no es cien por cien fiable. El caso extremo en el que esto fallará es donde tenga "\x{c2}" (que es "LETRA LATINA MAYÚSCULA CON CIRCUNFLEJO") o "\x{c3}" (que es "LETRA LATINA MAYÚSCULA CON TILDE") seguido de uno de los símbolos de puntuación de latin-1.

# una letra A mayúscula con tilde rodeada de comillas inteligentes
# esto fallará porque verá el "\x{c2}\x{94}" y pensará
# que en realidad es la secuencia utf8 de la comilla final
is_sane_utf8("\x{93}\x{c2}\x{94}");

Sin embargo, dado que esto rara vez ocurre, esta prueba es razonablemente fiable en la mayoría de los casos. Aún así, se debe tener cuidado en los casos en que los datos dinámicos se colocan junto a la puntuación latin-1 para evitar falsos negativos.

Existen dos situaciones para que esta prueba falle; la cadena contiene secuencias de bytes utf8 y la cadena no ha sido marcada como utf8 (esto normalmente significa que la obtuvo de una fuente externa como una biblioteca C; cuando Perl necesita almacenar una cadena internamente como utf8, realiza su propia codificación y marcado de forma transparente) o una cadena marcada como utf8 contiene secuencias de bytes que, al traducirse a caracteres, se parecen a una secuencia de bytes utf8. Los diagnósticos de la prueba le indican cuál es el caso.

Pruebas de Características de Cadena

Estas rutinas le permiten comprobar el rango de caracteres en una cadena. Tenga en cuenta que estas rutinas no ven la codificación real que perl utiliza internamente para almacenar los caracteres, solo comprueban si la cadena contiene solo caracteres que se pueden representar en la codificación nombrada:

is_within_ascii
Prueba que una cadena solo contiene caracteres del conjunto de caracteres ASCII.
is_within_latin_1
Prueba que una cadena solo contiene caracteres de latin-1.

Simplemente compruebe si un escalar está o no marcado como utf8 por los internos de perl:

is_flagged_utf8($string, $name)
Pasa si la cadena está marcada por los internos de perl como utf8, falla si no lo está.
isnt_flagged_utf8($string,$name)
Lo opuesto a "is_flagged_utf8", pasa si y solo si la cadena no está marcada como utf8 por los internos de perl.

Nota: puede referirse a esta función como "isn't_flagged_utf8" si realmente lo desea.
