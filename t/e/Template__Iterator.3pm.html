NOMBRE

Template::Iterator - Iterador de datos utilizado por la directiva FOREACH

SINOPSIS

my $iter = Template::Iterator->new(\@data, \%options);

DESCRIPCIÓN

El módulo "Template::Iterator" define un iterador de datos genérico para su uso por la directiva "FOREACH".

Puede ser utilizado como clase base para iteradores personalizados.

MÉTODOS PÚBLICOS

new($data)

Método constructor. Se pasa una referencia a una lista de valores como primer parámetro. Las llamadas posteriores a get_first() y get_next() devolverán cada elemento de la lista.

my $iter = Template::Iterator->new([ 'foo', 'bar', 'baz' ]);

El constructor también aceptará una referencia a un array de hashes y lo expandirá en una lista en la que cada entrada es un array de hashes que contiene un elemento '"key"' y '"value"', ordenado según las claves del hash.

my $iter = Template::Iterator->new({
    foo => 'Foo Item',
    bar => 'Bar Item',
});

Esto es equivalente a:

my $iter = Template::Iterator->new([
    { key => 'bar', value => 'Bar Item' },
    { key => 'foo', value => 'Foo Item' },
]);

Cuando se pasa un solo elemento que no es una referencia a un array, el constructor creará automáticamente una lista que contiene ese único elemento.

my $iter = Template::Iterator->new('foo');

Esto es equivalente a:

my $iter = Template::Iterator->new([ 'foo' ]);

Tenga en cuenta que un solo elemento que es un objeto basado en una referencia a un ARRAY bendecido NO será tratado como un array y se agrupará en una lista que contiene esa referencia de objeto.

my $list = bless [ 'foo', 'bar' ], 'MyListClass';
my $iter = Template::Iterator->new($list);

equivalente a:

my $iter = Template::Iterator->new([ $list ]);

El iterador devolverá solo un elemento, una referencia al objeto "MyListClass", $list.

Al agregar un método as_list() a la clase "MyListClass", podemos forzar al constructor "Template::Iterator" a tratar el objeto como una lista y usar los datos contenidos en él.

package MyListObject;
sub new {
    my $class = shift;
    bless [ @_ ], $class;
}
package main;
my $list = MyListObject->new('foo', 'bar');
my $iter = Template::Iterator->new($list);

Esto es entonces funcionalmente equivalente a:

my $iter = Template::Iterator->new([ $list ]);

El iterador devolverá solo un elemento, una referencia al objeto "MyListObject", $list.

Al agregar un método as_list() a la clase "MyListObject", podemos forzar al constructor "Template::Iterator" a tratar el objeto como una lista y usar los datos contenidos en él.

package MyListObject;
...
sub as_list {
    my $self = shift;
    return $self;
}
package main;
my $list = MyListObject->new('foo', 'bar');
my $iter = Template::Iterator->new($list);

El iterador ahora devolverá los dos elementos, '"foo"' y '"bar"', que "MyObjectList" encapsula.

get_first()

Devuelve un par "($valor, $error)" para el primer elemento del conjunto del iterador. El $error devuelto puede ser cero o indefinido para indicar que se devolvió un dato válido con éxito. Devuelve un error de "STATUS_DONE" si la lista está vacía.

get_next()

Devuelve un par "($valor, $error)" para el siguiente elemento del conjunto del iterador. Devuelve un error de "STATUS_DONE" si se han visitado todos los elementos de la lista.

get_all()

Devuelve un par "(\@valores, $error)" para todos los elementos restantes del conjunto del iterador. Devuelve un error de "STATUS_DONE" si se han visitado todos los elementos de la lista.

size()

Devuelve el tamaño del conjunto de datos o undef si es desconocido.

max()

Devuelve el número de índice máximo (es decir, el índice del último elemento) que es equivalente a size() - 1.

index()

Devuelve el número de índice actual que está en el rango 0 a max().

count()

Devuelve el número de iteración actual en el rango 1 a size(). Esto es equivalente a index() + 1.

first()

Devuelve un valor booleano para indicar si el iterador se encuentra actualmente en la primera iteración del conjunto.

last()

Devuelve un valor booleano para indicar si el iterador se encuentra actualmente en la última iteración del conjunto.

prev()

Devuelve el elemento anterior en el conjunto de datos, o "undef" si el iterador está en el primer elemento.

next()

Devuelve el siguiente elemento en el conjunto de datos o "undef" si el iterador está en el último elemento.

number()

Este es un alias de 'count' para proporcionar compatibilidad con versiones anteriores. Ver count.

parity()

Devuelve la cadena de texto "even" o "odd" para indicar la paridad del número de iteración actual (comenzando en 1). Esto se usa típicamente para crear tablas cebra rayadas.

<table>
[% FOREACH name IN ['Arthur', 'Ford', 'Trillian'] -%]
  <tr class="[% loop.parity %]">
    <td>[% name %]</td>
  </tr>
[% END %]
</table>

Esto producirá la siguiente salida:

<table>
  <tr class="odd">
    <td>Arthur</td>
  </tr>
  <tr class="even">
    <td>Ford</td>
  </tr>
  <tr class="odd">
    <td>Trillian</td>
  </tr>
</table>

Luego puedes estilizar los elementos "tr.odd" y "tr.even" usando CSS:

tr.odd td {
    background-color: black;
    color: white;
}
tr.even td {
    background-color: white;
    color: black;
}

odd()

Devuelve un valor booleano (0/1) para indicar si el número de iteración actual (comenzando en 1) es un número impar. En otras palabras, esto devolverá un valor verdadero para la primera iteración, la tercera, la quinta, y así sucesivamente.

even()

Devuelve un valor booleano (0/1) para indicar si el número de iteración actual (comenzando en 1) es un número par. En otras palabras, esto devolverá un valor verdadero para la segunda iteración, la cuarta, la sexta, y así sucesivamente.

Template::Iterator(3pm)

Página de manual de Template::Iterator(3pm) en Arch Linux

NOMBRE

Template::Iterator - Iterador para el sistema de plantillas Template Toolkit

SINOPSIS

use Template::Iterator;

my $iterator = Template::Iterator->new(
    items   => [ ... ],
    depth   => 1,
    context => $context,
);

my $item = $iterator->next;
while ($item) {
    # hacer algo con $item
    $item = $iterator->next;
}

# o usando el iterador en un bucle for
for my $item ($iterator->items) {
    # hacer algo con $item
}

DESCRIPCIÓN

El módulo Template::Iterator proporciona una forma de iterar sobre una lista de elementos, manteniendo un registro de la profundidad de anidamiento y el contexto actual. Es utilizado internamente por Template::Constants y Template::Service para gestionar el procesamiento de bloques y directivas dentro de las plantillas.

Los objetos Template::Iterator se crean típicamente con una lista de elementos (que pueden ser variables, bloques, o cualquier otro tipo de dato que necesite ser procesado) y un contexto opcional.

El método next() devuelve el siguiente elemento de la lista, o undef si se ha llegado al final. También incrementa el contador de profundidad si se entra en un nuevo nivel de anidamiento (por ejemplo, al procesar un bloque anidado).

El método items(), cuando se llama sin argumentos, devuelve todos los elementos restantes de la lista como una matriz. Cuando se llama con un argumento (una matriz), reemplaza la lista de elementos actual con la nueva matriz.

MÉTODOS PÚBLICOS

  • new( %args ): Constructor. Acepta los siguientes argumentos:
    • items: Una referencia a una lista de elementos a iterar.
    • depth: La profundidad inicial del iterador (normalmente 0 o 1).
    • context: Un objeto de contexto opcional.
  • next(): Devuelve el siguiente elemento de la lista o undef. Incrementa la profundidad si es necesario.
  • items( [ @new_items ] ): Devuelve la lista de elementos. Si se proporcionan argumentos, reemplaza la lista actual.
  • depth( [ $new_depth ] ): Devuelve o establece la profundidad actual del iterador.
  • context( [ $new_context ] ): Devuelve o establece el objeto de contexto.
  • reset(): Restablece el iterador al principio de la lista de elementos.
