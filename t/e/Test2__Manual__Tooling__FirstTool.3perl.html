NOMBRE

Test2::Manual::Tooling::FirstTool - Escribe tu primera herramienta con Test2.

DESCRIPCIÓN

Este tutorial te ayudará a escribir tu primera herramienta clonando la herramienta ok().

CÓDIGO COMPLETO ANTICIPADO

package Test2::Tools::MyOk;
use strict;
use warnings;
use Test2::API qw/context/;
use base 'Exporter';
our @EXPORT = qw/ok/;
sub ok($;$@) {
    my ($bool, $name, @diag) = @_;
    my $ctx = context();
    return $ctx->pass_and_release($name) if $bool;
    return $ctx->fail_and_release($name, @diag);
}
1;

LÍNEA POR LÍNEA

sub ok($;$@) {
En este caso, estamos emulando la función ok() exportada por Test2::Tools::Basic.

ok() y herramientas de prueba similares usan prototipos para forzar el análisis de argumentos. Tus herramientas de prueba no necesitan necesariamente prototipos; como con cualquier función de perl, debes tomar la decisión basándote en cómo se usa.

El prototipo requiere al menos 1 argumento, que se forzará a un contexto escalar. El segundo argumento es opcional y también se fuerza a ser escalar; es el nombre de la prueba. Cualquier argumento restante se trata como mensajes de diagnóstico que solo se usarán si la prueba falla.

my ($bool, $name, @diag) = @_;
Esta línea no necesita mucha explicación, simplemente estamos capturando los argumentos.
my $ctx = context();
Esta es una línea vital en **TODAS** las herramientas. El objeto de contexto es la API principal para las herramientas de prueba. **DEBES** obtener un contexto si quieres emitir algún evento, como hacer afirmaciones. Además, el contexto es responsable de asegurarse de que los fallos se atribuyan al archivo y número de línea correctos.

**Nota:** Una función de prueba **DEBE** liberar siempre el contexto cuando termina; no puedes simplemente dejar que salga del ámbito y sea recolectado por el recolector de basura. Test2 hace un buen trabajo gritándote si cometes este error.

**Nota:** **NO DEBES** almacenar ni pasar nunca un objeto de contexto *real*. Si deseas conservar un contexto por cualquier motivo, debes usar clone para hacer una copia "my $copy = $ctx->clone". La copia puede pasarse o almacenarse, pero el original **DEBE** liberarse cuando hayas terminado con él.

return $ctx->pass_and_release($name) if $bool;
Cuando $bool es verdadero, esta línea utiliza el objeto de contexto para emitir un evento Test2::Event::Pass. Además de emitir el evento, también liberará el objeto de contexto y devolverá verdadero.

Esta es una forma abreviada de:

if($bool) {
    $ctx->pass($name);
    $ctx->release;
    return 1;
}
return $ctx->fail_and_release($name, @diag);
Esta línea emite un evento Test2::Event::Fail, libera el objeto de contexto y devuelve falso. El evento de fallo incluirá cualquier mensaje de diagnóstico del array @diag.

Esta es una forma abreviada de:

$ctx->fail($name, @diag);
$ctx->release;
return 0;
