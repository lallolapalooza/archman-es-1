NOMBRE

Text::Iconv - interfaz de Perl para la función de conversión de juegos de caracteres iconv()

SINAPSIS

use Text::Iconv;
$converter = Text::Iconv->new("codificacióndeorigen", "codificacióndestino");
$convertido = $converter->convert("Texto a convertir");

DESCRIPCIÓN

El módulo Text::Iconv proporciona una interfaz de Perl a la función iconv() tal como se define en la Single UNIX Specification.

El método convert() convierte la codificación de los caracteres de la cadena de entrada del juego de caracteres de origen (fromcode) al juego de caracteres de destino (tocode), y devuelve el resultado.

La configuración de fromcode y tocode, así como sus combinaciones permitidas, dependen de la implementación. Los valores válidos se especifican en la documentación del sistema; la utilidad iconv(1) también debería proporcionar una opción -l que liste todos los juegos de caracteres compatibles.

Métodos utilitarios

Los objetos Text::Iconv también proporcionan los siguientes métodos:

retval() devuelve el valor de retorno de la función subyacente iconv() para la última conversión; según la Single UNIX Specification, este valor indica "el número de conversiones no idénticas realizadas". Tenga en cuenta, sin embargo, que las implementaciones de iconv varían ampliamente en la interpretación de esta especificación.

Este método se puede llamar después de llamar a convert(), por ejemplo:

$result = $converter->convert("lorem ipsum dolor sit amet");
$retval = $converter->retval;

Cuando se llama antes de la primera llamada a convert(), o si ocurrió un error durante la conversión, retval() devuelve undef.

get_attr(): Este método solo está disponible con GNU libiconv, de lo contrario, lanza una excepción. El método get_attr() le permite consultar varios atributos que influyen en el comportamiento de convert(). Los atributos actualmente compatibles son trivialp, transliterate y discard_ilseq, por ejemplo:

$state = $converter->get_attr("transliterate");

Consulte iconvctl(3) para más detalles. Para garantizar la portabilidad a otras implementaciones de iconv, primero debe comprobar la disponibilidad de este método utilizando eval {}, por ejemplo:

eval { $conv->get_attr("trivialp") };
if ($@)
{
  # get_attr() no está disponible
}
else
{
  # get_attr() está disponible
}

Este método debe considerarse experimental.

set_attr(): Este método solo está disponible con GNU libiconv, de lo contrario, lanza una excepción. El método set_attr() le permite establecer varios atributos que influyen en el comportamiento de convert(). Los atributos actualmente compatibles son transliterate y discard_ilseq, por ejemplo:

$state = $converter->set_attr("transliterate");

Consulte iconvctl(3) para más detalles. Para garantizar la portabilidad a otras implementaciones de iconv, primero debe comprobar la disponibilidad de este método utilizando eval {}, cf. la descripción de set_attr() arriba.

Este método debe considerarse experimental.

ERRORES

Si la conversión no se puede inicializar, se lanza una excepción (usando croak()).

Manejo de errores de conversión

Text::Iconv proporciona un atributo de clase raise_error y un método de clase correspondiente para establecer y obtener su valor. El manejo de errores durante la conversión depende de la configuración de este atributo. Si raise_error se establece en un valor verdadero, se lanza una excepción; de lo contrario, el método convert() solo devuelve undef. Por defecto, raise_error es falso. Ejemplo de uso:

Text::Iconv->raise_error(1);     # Los errores de conversión lanzan excepciones
Text::Iconv->raise_error(0);     # Los errores de conversión devuelven undef
$a = Text::Iconv->raise_error(); # Obtiene la configuración actual

Manejo de errores de conversión por objeto

Como característica experimental, Text::Iconv también proporciona un atributo de instancia raise_error y un método correspondiente para establecer y obtener su valor. Si raise_error es undef, se aplican la configuración a nivel de clase. Si raise_error es 1 o 0 (verdadero o falso), la configuración del objeto anula la configuración a nivel de clase.

Consulte iconv(3) para obtener detalles sobre los errores que pueden ocurrir.

Conversión de undef

Convertir undef, por ejemplo,

$converted = $converter->convert(undef);

siempre devuelve undef. Esto no se considera un error.

NOTAS

Los juegos de caracteres compatibles, sus nombres, las conversiones admitidas y la calidad de las conversiones dependen del sistema.
