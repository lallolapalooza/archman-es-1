Term::Animation::Entity

SINOPSIS

use Term::Animation::Entity;
# Constructor
my $entidad = Term::Animation::Entity->new(
    forma         => ';-)',
    posicion      => [ 1, 2, 3 ],
    argumentos_callback => [ 0, 1, 0, 0 ],
);

RESUMEN

Un objeto sprite para usar con Term::Animation

DESCRIPCIÓN

Term::Animation::Entity es utilizado por Term::Animation para representar un único sprite en la pantalla.

PARÁMETROS

nombre < ESCALAR >
      Una cadena que identifica unívocamente este objeto
forma < REF >
      El arte ASCII para este objeto. Puede ser proporcionado como:
                1) Una sola cadena de texto multilínea (sin animación)
                2) Un array de cadenas de texto multilínea, donde cada
                   elemento es un fotograma de animación individual
                3) Un array de arrays 2D. Cada elemento en el array exterior
                   es un fotograma de animación individual.
      Si se proporciona un array, cada elemento es un fotograma de animación.
      Si se proporciona 1) o 2), se eliminará una única nueva línea
      del principio de cada cadena. 3) es lo que el módulo usa internamente.
auto_trans < BOOLEANO >
      Si se debe hacer automáticamente transparente el espacio en blanco al principio de cada línea.
      Predeterminado: 0
posicion < ARRAY_REF >
      Una lista que especifica las coordenadas iniciales x, y y z
      Predeterminado: [ 0, 0, 0 ]
callback < REFERENCIA_SUBRUTINA >
      Rutina de callback para esta entidad. Predeterminado: I<move_entity()>
argumentos_callback < REF >
      Argumentos para la rutina de callback.
frame_actual < ENTERO >
      Fotograma de animación con el que comenzar. Predeterminado: 0
wrap < BOOLEANO >
      Si esta entidad debe envolverse al borde de la pantalla. Predeterminado: 0
transparente < ESCALAR >
      Carácter utilizado para indicar transparencia. Predeterminado: ?
morir_fuera_pantalla < BOOLEANO >
      Si esta entidad debe ser eliminada si
      sale de la pantalla. Predeterminado: 0
morir_entidad < ENTIDAD >
      Especifica una entidad (referencia o nombre). Cuando la
      entidad nombrada muere, esta entidad también debe morir. Predeterminado: indefinido
tiempo_muerte < ENTERO >
      El tiempo en el que esta entidad debe morir. Este
      debe ser un tiempo de época UNIX, tal como lo devuelve
      I<time>. Predeterminado: indefinido
frame_muerte < ENTERO >
      Especifica el número de fotogramas que deben mostrarse
      antes de que esta entidad sea eliminada. Predeterminado: indefinido
cb_muerte < REFERENCIA_SUBRUTINA >
      Rutina de callback utilizada cuando esta entidad muere
args_cb_muerte < REF >
      Argumentos para la rutina de callback de muerte de la entidad
color
      Máscara de color. Esto sigue el mismo formato que 'forma'.
      Consulte la sección 'COLOR' a continuación para más detalles.
color_predeterminado < ESCALAR >
      Un color predeterminado a usar para la entidad. Consulte la sección 'COLOR'
      para más detalles.
datos < REF >
      Almacena algunos datos sobre esta entidad. No es utilizado por el módulo.
      Puedes usarlo para almacenar información de estado sobre esta entidad.

NAME

Term::Animation::Entity — represent animated objects

SYNOPSIS

    use Term::Animation;
    my $anim = Term::Animation->new( ... );
    my $entity = Term::Animation::Entity->new(
        animation => $anim,
        shape     => [qw(
            . . .
            . o .
            . . .
        )],
        position  => [2, 3],
        callback  => sub { ... },
        die_time  => 1000000000,
        die_entity => 'some_other_entity',
    );
    $anim->add_entity($entity);

ABSTRACT

Represent animated objects. This is the base class for all animated objects.

DESCRIPTION

This module provides the base class for entities that will be drawn on the screen by Term::Animation. The base class provides basic functionality like positioning, collision detection, and callbacks. Subclasses will usually override the callback method to provide custom animation logic.

See Term::Animation for a more complete explanation of how animations are constructed and run.

PARAMETERS

The following parameters can be passed to the new method:

animation

A reference to the Term::Animation object this entity belongs to. This is required.

shape

A reference to an array of strings representing the shape of the entity. The array is treated as a list of lines. Any characters other than space will be drawn. For example:

    shape => [ qw(
        ###
        # #
        ###
    )]

You can also pass a subroutine reference here, which will be called each animation cycle with the entity and the animation object as arguments. The subroutine should return a reference to the shape array.

position

A reference to a two-element array representing the (x, y) position of the entity on the screen. Defaults to (0, 0).

callback

A subroutine reference that will be called each animation cycle. The subroutine is called with the entity and the animation object as arguments. If the callback returns a false value, the entity will be removed from the animation.

die_time

A UNIX epoch time. If the current time is greater than this value, the entity will be removed from the animation. Set to undef to disable.

die_entity

Get or set an entity whose death will cause the death of this entity. Either an entity name or Term::Animation::Entity reference are accepted, but an entity name is always returned. Set to undef to disable.

color

Set the color for the entity. This can be either a single character (e.g., R) or the full name of the color (e.g., red).

default_color

Get or set the default color for the entity. The color can be either a single character or the full name of the color.

color_mask

Set the color mask for the entity. See the Term::Animation/COLOR section of Term::Animation for details.

METHODS

position
$entity->position( $new_x, $new_y );
($x, $y) = $entity->position();

Get or set the (x, y) position of the entity.

x
$entity->x( $new_x );
$x = $entity->x();

Get or set the x position of the entity.

y
$entity->y( $new_y );
$y = $entity->y();

Get or set the y position of the entity.

shape
$entity->shape($new_shape);

Set the sprite image for the entity. See the "shape" argument to new for details.

callback
$entity->callback($new_callback);
$callback = $entity->callback();

Get or set the callback subroutine for the entity.

animation
$entity->animation( $anim );
$anim = $entity->animation();

Get or set the Term::Animation object that this entity is part of.

die_time
$entity->die_time( $time );
$time = $entity->die_time();

Get or set the UNIX epoch time when this entity should die. Set to undef to disable.

die_entity
$entity->die_entity( $other_entity );
$other_entity = $entity->die_entity;

Get or set an entity whose death will cause the death of this entity. Either an entity name or Term::Animation::Entity reference are accepted, but an entity name is always returned. Set to undef to disable.

collisions
$collisions = $entity->collisions();

Returns a reference to a list of entities that this entity collided with during this animation cycle.

default_color
$entity->default_color( 'blue' );
$def_color = $entity->default_color();

Get or set the default color for the entity. The color can be either a single character or the full name of the color.

color_mask
$entity->color_mask( $mask );

Set the color mask for the entity. See the Term::Animation/COLOR section of Term::Animation for details.

move_entity
The default callback. You can also call this from your own callback to do the work of moving and animating the entity after you have done whatever other processing you want to do. 
sub my_callback {
  my ($entity, $animation) = @_;

  # do something here

  return $entity->move_object($animation);
}
kill
$entity->kill();

Remove this entity from the animation. This is equivilent to:

$animation->del_entity($entity);

This does not destroy the object, so you can still readd it later (or put it in a different animation) as long as you have a reference to it.
