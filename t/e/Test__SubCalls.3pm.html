NOMBRE

Test::SubCalls - Rastrea el número de veces que se llaman las subs

VERSIÓN

versión 1.10

SINOPSIS

use Test::SubCalls;

# Comienza a rastrear llamadas a una sub nombrada
sub_track( 'Foo::foo' );

# Ejecuta algo de código de prueba
...

# Prueba que una sub en algún lugar profundo de la base de código fue llamada
# un número específico de veces.
sub_calls( 'Foo::foo', 5 );
sub_calls( 'Foo::foo', 5, 'Usa un mensaje de prueba personalizado' );

# Restablece los contadores para una o todas las subs
sub_reset( 'Foo::foo' );
sub_reset_all();

DESCRIPCIÓN

Hay una serie de situaciones diferentes (como probar código de caché) en las que querrás hacer una serie de pruebas y luego verificar que alguna subrutina subyacente en el código se llamó un número específico de veces.

Este módulo proporciona una serie de funciones para hacer pruebas de esta manera en asociación con tus scripts de prueba normales de Test::More (o similares).

FUNCIONES

En la naturaleza de los módulos de prueba, todas las funciones se exportan por defecto.

sub_track $nombre_sub

La función "sub_track" crea un nuevo rastreador de llamadas para una función nombrada.

La sub a rastrear debe proporcionarse por nombre, las referencias a la función en sí son insuficientes.

Devuelve verdadero si se agregó, o muere por error.

sub_calls $nombre_sub, $llamadas_esperadas [, $mensaje ]

La función "sub_calls" es la función de prueba principal (y única) proporcionada por "Test::SubCalls". Una sola llamada representará una prueba en tu plan.

Toma el nombre de la subrutina tal como se proporcionó originalmente a "sub_track", el número esperado de veces que debería haberse llamado la subrutina y un mensaje de prueba opcional.

Si no se proporciona ningún mensaje, se proporcionará un mensaje por defecto.

La prueba es correcta si el número de veces que se llamó la sub coincide con el número esperado, o no es correcta si no.

sub_reset $nombre_sub

Para evitar que los usuarios repetidos tengan que tomar recuentos antes y después cuando comienzan a probar desde cero, se ha proporcionado la función "sub_reset" para restablecer un contador de llamadas de sub a cero.

Devuelve verdadero o muere si el nombre de la sub no es válido o no se está rastreando actualmente.

sub_reset_all

Proporcionada principalmente como una conveniencia, la función "sub_reset_all" restablecerá todos los contadores definidos actualmente.

Devuelve verdadero.
