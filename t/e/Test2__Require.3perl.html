Test2::Require(3perl) Guía de referencia para programadores de Perl Test2::Require(3perl)

NOMBRE

Test2::Require - Clase base y documentación para paquetes de pruebas de tipo 'skip-unless'.

DESCRIPCIÓN

Los paquetes Test2::Require::* son paquetes que cargas para asegurar que tu archivo de pruebas se omita a menos que se cumpla un requisito específico. Los módulos en este espacio de nombres pueden heredar de Test2::Require si lo desean, pero no es estrictamente necesario hacerlo.

¿CÓMO ESCRIBO UN MÓDULO DE 'REQUIRE'?

COMO UNA SUBCLASE

package Test2::Require::Widget;
use strict;
use warnings;
use base 'Test2::Require';
sub HAVE_WIDGETS { ... };
sub skip {
    my $class = shift;
    my @import_args = @_;
    if (HAVE_WIDGETS()) {
        # Tenemos widgets, no omitir
        return undef;
    }
    else {
        # No hay widgets, omitir la prueba
        return "Omitido porque no hay widgets" unless HAVE_WIDGETS();
    }
}
1;

Una subclase de Test2::Require simplemente necesita implementar un método skip(). Este método recibirá todos los argumentos de importación. Este método debería devolver undef si la prueba debe ejecutarse, y debería devolver una razón para omitir si la prueba debe omitirse.

AUTÓNOMO

Si no deseas heredar de Test2::Require, deberías escribir un método import():

package Test2::Require::Widget;
use strict;
use warnings;
use Test2::API qw/context/;
sub HAVE_WIDGETS { ... };
sub import {
    my $class = shift;
    # Tenemos widgets, debería ejecutarse.
    return if HAVE_WIDGETS();
    # Usar el objeto de contexto para crear el evento
    my $ctx = context();
    $ctx->plan(0, SKIP => "Omitido porque no hay widgets");
    $ctx->release;
}
1;
