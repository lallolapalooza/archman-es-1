Test2::Tools::Ref(3perl) Guía de referencia para programadores de Perl Test2::Tools::Ref(3perl)

NOMBRE

Test2::Tools::Ref - Herramientas para validar referencias.

DESCRIPCIÓN

Este módulo contiene herramientas que le permiten verificar que algo es una referencia. También tiene herramientas para comprobar si dos referencias son exactamente la misma referencia, o diferentes. Ninguna de las funciones de este módulo realiza comparaciones profundas.

SINOPSIS

use Test2::Tools::Ref;
# Asegurarse de que algo es una referencia.
ref_ok($ref);
# Comprobar que $ref es una referencia HASH
ref_ok($ref, 'HASH', 'Debe ser un hash')
ref_is($refa, $refb, "Misma referencia exacta");
ref_is_not($refa, $refb, "No es la misma referencia exacta");

EXPORTACIONES

Todas las subrutinas se exportan por defecto.

ref_ok($cosa)
ref_ok($cosa, $tipo)
ref_ok($cosa, $tipo, $nombre)
Esto comprueba que $cosa es una referencia. Si se especifica $tipo, comprobará que $cosa es de ese tipo de referencia.
ref_is($ref1, $ref2, $nombre)
Verificar que dos referencias son exactamente la misma referencia.
ref_is_not($ref1, $ref2, $nombre)
Verificar que dos referencias no son exactamente la misma referencia.
