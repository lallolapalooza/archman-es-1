NOMBRE

Template::Plugin::String - Interfaz orientada a objetos para manipulación de cadenas

SINOPSIS

# crear objetos String a través de la directiva USE
[% USE String %]
[% USE String 'texto inicial' %]
[% USE String text => 'texto inicial' %]
# o desde un String existente a través de new()
[% newstring = String.new %]
[% newstring = String.new('nuevo texto de cadena') %]
[% newstring = String.new( text => 'nuevo texto de cadena' ) %]
# o desde un String existente a través de copy()
[% newstring = String.copy %]
# añadir texto a la cadena
[% String.append('texto a añadir') %]
# formatear con relleno a la izquierda, derecha o centro/centro
[% String.left(20) %]
[% String.right(20) %]
[% String.center(20) %]   # ortografía americana
[% String.centre(20) %]   # ortografía europea
# y varios otros métodos...

DESCRIPCIÓN

Este módulo implementa una clase "String" para realizar operaciones de cadena sobre texto de manera orientada a objetos.

Puede crear un objeto "String" a través de la directiva "USE", añadiendo cualquier valor de texto inicial como argumento o como parámetro nombrado "text".

[% USE String %]
[% USE String 'texto inicial' %]
[% USE String text='texto inicial' %]

El objeto creado se referenciará como "String" por defecto, pero puede proporcionar un nombre de variable diferente para el objeto que se asignará:

[% USE saludo = String 'Hola Mundo' %]

Una vez que tenga un objeto "String", puede usarlo como prototipo para crear otros objetos "String" con el método new().

[% USE String %]
[% saludo = String.new('Hola Mundo') %]

El método new() también acepta una cadena de texto inicial como argumento o el parámetro nombrado "text".

[% saludo = String.new( text => 'Hola Mundo' ) %]

También puede llamar a copy() para crear un nuevo "String" como una copia del original.

[% saludo2 = saludo.copy %]

El objeto "String" tiene un método text() para devolver el contenido de la cadena.

[% saludo.text %]

Sin embargo, es suficiente simplemente imprimir la cadena y dejar que el operador de conversión a cadena sobrecargado llame al método text() automáticamente por usted.

[% saludo %]

Por lo tanto, puede tratar los objetos "String" prácticamente como cualquier fragmento de texto normal, interpolándolo en otras cadenas, por ejemplo:

[% msg = "Se imprimió '$saludo' y luego se volcó el núcleo\n" %]

También tiene el beneficio de numerosos otros métodos para manipular la cadena.

[% msg.append("PD No comas nieve amarilla") %]

Tenga en cuenta que todos los métodos operan y mutan el contenido de la cadena en sí. Si desea operar sobre una copia de la cadena, simplemente tome una copia primero:

[% msg.copy.append("PD No comas nieve amarilla") %]

Estos métodos devuelven una referencia al propio objeto "String". Esto permite encadenar múltiples métodos juntos.

[% msg.copy.append('foo').right(72) %]

También significa que en los ejemplos anteriores, se devuelve el "String", lo que hace que se llame al método text(), lo que resulta en la impresión del nuevo valor de la cadena. Para suprimir la impresión de la cadena, puede usar la directiva "CALL".

[% foo = String.new('foo') %]
[% foo.append('bar') %]         # imprime "foobar"
[% CALL foo.append('bar') %]    # nada

MÉTODOS CONSTRUCTORES

Estos métodos se utilizan para crear nuevos objetos "String".

new()

Crea una nueva cadena utilizando un valor inicial pasado como argumento posicional o el parámetro nombrado "text".

[% USE String %]
[% msg = String.new('Hola Mundo') %]
[% msg = String.new( text => 'Hola Mundo' ) %]

copy()

Crea un nuevo objeto "String" que contiene una copia de la cadena original.

[% msg2 = msg.copy %]

MÉTODOS INSPECTORES

Estos métodos se utilizan para examinar la cadena.

text()

Devuelve el valor de texto interno de la cadena. El operador de conversión a cadena está sobrecargado para llamar a este método. Por lo tanto, lo siguiente es equivalente:

[% msg.text %]
[% msg %]

length()

Devuelve la longitud de la cadena.

[% USE String("foo") %]
[% String.length %]   # => 3

search($pattern)

Busca en la cadena la expresión regular especificada en $pattern, devolviendo verdadero si se encuentra o falso en caso contrario.

[% item = String.new('foo bar baz wiz waz woz') %]
[% item.search('wiz') ? '¡WIZZY! :-)' : 'no wizzy :-(' %]

split($pattern, $limit)

Divide la cadena basándose en el delimitador $pattern y el $limit opcional. Delega a la split() interna de Perl, por lo que los parámetros son exactamente los mismos.

[% FOREACH item.split %]
     ...
[% END %]
[% FOREACH item.split('baz|waz') %]
     ...
[% END %]

MÉTODOS MUTADORES

Estos métodos modifican el valor interno de la cadena. Por ejemplo:

[% USE str=String('foobar') %]
[% str.append('.html') %]   # str => 'foobar.html'

El valor de "str" es ahora '"foobar.html"'. Si no desea modificar la cadena, simplemente tome una copia primero.

[% str.copy.append('.html') %]

Todos estos métodos devuelven una referencia al propio objeto "String". Esto tiene dos beneficios importantes. El primero es que cuando se usa como arriba, el objeto "String" '"str"' devuelto por el método append() se convertirá a cadena con una llamada a su método text(). Esto devolverá el contenido de cadena recién modificado. En otras palabras, una directiva como:

[% str.append('.html') %]

actualizará la cadena y también imprimirá el nuevo valor. Si solo desea actualizar la cadena pero no imprimir el nuevo valor, use "CALL".

[% CALL str.append('.html') %]

El otro beneficio de que estos métodos devuelvan una referencia al "String" es que puede encadenar tantas llamadas a métodos diferentes como desee. Por ejemplo:

[% String.append('.html').trim.format(href) %]

Aquí están los métodos:

push($suffix, ...) / append($suffix, ...)

Añade todos los argumentos al final de la cadena. El método append() se proporciona como un alias para push().

[% msg.push('foo', 'bar') %]
[% msg.append('foo', 'bar') %]

pop($suffix)

Elimina el sufijo pasado como argumento del final de la Cadena.

[% USE String 'foo bar' %]
[% String.pop(' bar')   %]   # => 'foo'

Template::Plugin::String(3pm) — Perl Template Toolkit Manual

NAME

Template::Plugin::String - String manipulation plugin for the Template Toolkit

SYNOPSIS

    [% USE String %]
    [% USE msg = String('some text') %]

    [% String.reverse %]
    [% msg.reverse %]

    [% msg.append(' more text') %]
    [% msg.prepend('leading text ') %]

    [% msg.ljust(20) %]
    [% msg.rjustify(20) %]
    [% msg.center(20) %]

    [% msg.remove(' ') %]
    [% msg.replace(' ', '_') %]
    [% msg.repeat(3) %]

    [% msg.upper %]
    [% msg.lower %]
    [% msg.capital %]

    [% msg.chomp %]
    [% msg.chop %]
    [% msg.trim %]
    [% msg.collapse %]

DESCRIPTION

The String plugin provides a set of convenience methods for manipulating strings within your templates. You can either use the plugin as a singleton object via the String variable (as shown in the reverse example above) or instantiate it as a named variable, typically using the USE directive with a string argument.

Methods are generally designed to be chained, as shown in the chomp, chop, trim and collapse examples.

CONSTRUCTOR METHODS

String( [ STRING ] )

The constructor method takes an optional string argument which is the initial value for the String object.

    [% USE msg = String('Hello World') %]

INSPECTOR METHODS

length()

Returns the length of the string.

    [% USE msg = String('Hello World') %]
    Length: [% msg.length %]  # => Length: 11
count($search)

Returns the number of times the $search string occurs within the string.

    [% USE msg = String('foo bar foo baz') %]
    Count: [% msg.count('foo') %]  # => Count: 2

MUTATOR METHODS

These methods return a new String object with the modified value. The original object remains unchanged unless you assign the result back to the original variable name.

append($string)

Appends the specified $string to the end of the current string.

    [% USE msg = String('foo') %]
    [% msg.append(' bar') %]  # => 'foo bar'
prepend($string)

Prepends the specified $string to the beginning of the current string.

    [% USE msg = String('bar') %]
    [% msg.prepend('foo ') %]  # => 'foo bar'
shift($prefix)

Removes the prefix passed as an argument from the start of the String.

    [% USE String 'foo bar' %]
    [% String.shift('foo ') %]   # => 'bar'
left($pad)

If the length of the string is less than $pad then the string is left formatted and padded with spaces to $pad length.

    [% msg.left(20) %]
right($pad)

As per left() but right padding the "String" to a length of $pad.

    [% msg.right(20) %]
center($pad) / centre($pad)

As per left() and right() but formatting the "String" to be centered within a space padded string of length $pad. The centre() method is provided as an alias for center().

    [% msg.center(20) %]    # American spelling
    [% msg.centre(20) %]    # European spelling
format($format)

Apply a format in the style of sprintf() to the string.

    [% USE String("world") %]
    [% String.format("Hello %s\n") %]  # => "Hello World\n"
upper()

Converts the string to upper case.

    [% USE String("foo") %]
    [% String.upper %]  # => 'FOO'
lower()

Converts the string to lower case

    [% USE String("FOO") %]
    [% String.lower %]  # => 'foo'
capital()

Converts the first character of the string to upper case.

    [% USE String("foo") %]
    [% String.capital %]  # => 'Foo'

The remainder of the string is left untouched. To force the string to be all lower case with only the first letter capitalised, you can do something like this:

    [% USE String("FOO") %]
    [% String.lower.capital %]  # => 'Foo'
chop()

Removes the last character from the string.

    [% USE String("foop") %]
    [% String.chop %]   # => 'foo'
chomp()

Removes the trailing newline from the string.

    [% USE String("foo\n") %]
    [% String.chomp %]  # => 'foo'
trim()

Removes all leading and trailing whitespace from the string

    [% USE String("   foo   \n\n ") %]
    [% String.trim %]   # => 'foo'
collapse()

Removes all leading and trailing whitespace and collapses any sequences of multiple whitespace to a single space.

    [% USE String(" \n\r  \t  foo   \n \n bar  \n") %]
    [% String.collapse %]   # => "foo bar"
truncate($length, $suffix)

Truncates the string to $length characters.

    [% USE String('long string') %]
    [% String.truncate(4) %]  # => 'long'

If $suffix is specified then it will be appended to the truncated string. In this case, the string will be further shortened by the length of the suffix to ensure that the newly constructed string complete with suffix is exactly $length characters long.

    [% USE msg = String('Hello World') %]
    [% msg.truncate(8, '...') %]   # => 'Hello...'
replace($search, $replace)

Replaces all occurrences of $search in the string with $replace.

    [% USE String('foo bar foo baz') %]
    [% String.replace('foo', 'wiz')  %]  # => 'wiz bar wiz baz'
remove($search)

Remove all occurrences of $search in the string.

    [% USE String('foo bar foo baz') %]
    [% String.remove('foo ')  %]  # => 'bar baz'
repeat($count)

Repeats the string $count times.

    [% USE String('foo ') %]
    [% String.repeat(3)  %]  # => 'foo foo foo '
