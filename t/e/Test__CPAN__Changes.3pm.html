NOMBRE

Test::CPAN::Changes - Validación del archivo Changes en una distribución de CPAN

SINOPSIS

# en xt/author/cpan-changes.t
use Test::More;
use Test::CPAN::Changes;
changes_ok;
# comprobando una versión específica
use My::Module;
use Test::More;
use Test::CPAN::Changes;
changes_ok({ version => My::Module->VERSION });

DESCRIPCIÓN

Este módulo permite a los autores de CPAN escribir pruebas automatizadas para asegurar que sus registros de cambios coincidan con la especificación.

SUBRUTINAS

changes_ok( \%args )

Envoltorio simple para "changes_file_ok". Declara un plan de prueba y utiliza el nombre de archivo predeterminado de "Changes".

changes_file_ok( $filename, \%arg )

Comprueba el contenido del archivo de cambios con respecto a la especificación. No se declara ningún plan y si el nombre del archivo no está definido, se utiliza "Changes".

Se realizan cuatro pruebas. El archivo debe ser analizable, debe contener lanzamientos y las versiones y fechas listadas deben ser válidas.

%arg puede incluir una entrada de version, en cuyo caso se realizan dos pruebas adicionales. La entrada para esa versión debe existir y tener contenido. Esto es útil para asegurar que la versión que se está lanzando actualmente tenga cambios documentados.
