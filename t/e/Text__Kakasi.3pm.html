Paquete: perl-text-kakasi

Kakasi(3) Documentación de Perl aportada por el usuario Kakasi(3)

NOMBRE

Text::Kakasi - Interfaz de Perl para kakasi

SINOPSIS

use Text::Kakasi;
# funcional
$res = Text::Kakasi::getopt_argv('-JJ', '-c', '-w');
$str = Text::Kakasi::do_kakasi($texto_japones);
# orientado a objetos
$obj = Text::Kakasi->new('-JJ', '-c', '-w');
$str = $obj->get($texto_japones);

DESCRIPCIÓN

Este módulo proporciona una interfaz para kakasi (inversor simple de kanji a kana). kakasi es un conjunto de programas y bibliotecas que hacen lo contrario de lo que hacen los métodos de entrada japoneses. Le proporcionas japonés y kakasi lo convierte a su representación fonética. kakasi también puede ser utilizado para tokenizar texto japonés. Para saber más sobre kakasi, consulta http://kakasi.namazu.org/.

Text::Kakasi ahora presenta APIs tanto funcionales como orientadas a objetos. Las APIs funcionales son 100% compatibles con la ver. 1.05. Pero para aprovechar las "Características de Perl 5.8", deberías usar las APIs OOP en su lugar.

Consulta Text::Kakasi::JP para la versión japonesa de este documento.

APIs Funcionales

Nota: "Text::Kakasi::" se omite. Text::Kakasi no exporta estas funciones por defecto. Puedes importar estas funciones de la siguiente manera;

use Text::Kakasi qw/getopt_argv do_kakasi/;
$err = getopt_argv($arg1, $arg2, ...)
inicializa kakasi con opciones. Las opciones son las mismas que las del comando "kakasi". Aquí hay un resumen de kakasi 2.3.4. 
-a[jE] -j[aE] -g[ajE] -k[ajKH]
-E[aj] -K[ajkH] -H[ajkK] -J[ajkKH]
-i{oldjis,newjis,dec,euc,sjis}
 -o{oldjis,newjis,dec,euc,sjis}
-r{hepburn,kunrei} -p -s -f -c"chars" 
 [jisyo1, jisyo2,,,]
Conjuntos de caracteres:
     a: ascii  j: jisroman  g: graphic  k: kana 
     (j,k     definidos en jisx0201)
     E: kigou  K: katakana  H: hiragana J: kanji
     (E,K,H,J definidos en jisx0208)
Opciones:
  -i: sistema de codificación de entrada    -o: sistema de codificación de salida
  -r: sistema de conversión de romaji
  -p: listar todas las lecturas (con la opción -J)
  -s: insertar caracteres separadores (con la opción -J)
  -f: modo furigana (con la opción -J)
  -c: saltar caracteres dentro de jukugo
      (con la opción -J: por defecto TAB CR LF ESPACIO)
  -C: mayúsculas en romaji (con la opción -Ja o -Jj)
  -U: mayúsculas en romaji (con la opción -Ja o -Jj)
  -u: llamar a fflush() después de la salida de 1 carácter
  -w: modo wakatigaki

Devuelve 0 en caso de éxito y un valor distinto de cero en caso de fallo.

A diferencia de la versión 1.x donde tenías que empezar el primer argumento con "kakasi", puedes omitirlo en la versión 2.x (añadir "kakasi" no causa daño, por lo que se preserva la compatibilidad).

$result_str = do_kakasi($str)
aplica kakasi a $str y devuelve el resultado. Si algo sale mal, devuelve "undef".
close_kanwadic()
cierra los archivos de diccionario que se abrieron implícitamente. Esta función es solo para compatibilidad retroactiva y nunca deberías tener que usarla hoy en día.

APIs Orientadas a Objetos

A partir de la versión 2.0, Text::Kakasi también ofrece APIs OOP.

$k = Text::Kakasi->new($args ...)
Construye un objeto. Si se proporcionan argumentos, es lo mismo que "Text::Kakasi->new->set($args ...)"
$k->set($args ...)
Interfaz OOP para "getopt_argv". 
my $k = Text::Kakasi->new;
$k->set('-w'); # Text::Kakasi::getopt_argv('-w');

A diferencia de getopt_argv() que devuelve el estado, "set" devuelve el objeto mismo, por lo que puedes hacer esto:

my $tokenized = $k->set('-w')->get($raw_japanese);

Para obtener el estado de "$k->set", usa "$k->error".

Consulta también "Características de Perl 5.8".

$k->error
devuelve el estado del último método.
$result = $k->get($raw_japanese);
Interfaz OOP para "do_kakasi". Los siguientes códigos son equivalentes. 
# Funcional
getopt_argv('-w'); $result = do_kakasi($raw_japanese);
# OOP
$k->set('-w')->get($raw_japanese);

Características de Perl 5.8

Perl 5.8 introduce el módulo Encode, que transcodifica varias codificaciones. Este módulo aprovecha esta característica, pero para mantener la compatibilidad retroactiva con la versión 1.x, esta característica solo se habilita cuando se usa la interfaz OOP (la versión 1.x solo proporcionaba APIs funcionales).

En Perl 5.8 y superior, "-icodificación" y "-ocodificación" son manejados por el módulo Encode, por lo que puedes usar codificaciones que Kakasi no soporta, como utf8. En otras palabras,

$result = $k->set(qw/-iutf8 -outf8 -w/)->get($utf8);

Es análogo a:

$euc = encode('eucjp' => $utf8);
getopt_argv('-w');
$tmp = do_kakasi($euc);
$result = decode('eucjp' => $tmp);

Cuando especificas "-outf8", "$k->get" devolverá la cadena con la bandera utf8 activada.

Puedes suprimir esta característica estableciendo $Text::Kakasi::HAS_ENCODE a 0, en cuyo caso esta característica no se usará.
