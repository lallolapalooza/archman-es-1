NOMBRE

Text::Tabs - expandir y contraer tabulaciones como unix expand(1) y unexpand(1)

SINOPSIS

use Text::Tabs;
$tabstop = 4;  # por defecto = 8
@lines_without_tabs = expand(@lines_with_tabs);
@lines_with_tabs = unexpand(@lines_without_tabs);

DESCRIPCIÓN

Text::Tabs hace la mayor parte de lo que hacen las utilidades de unix expand(1) y unexpand(1). Dada una línea con tabulaciones, "expand" reemplaza esas tabulaciones con el número apropiado de espacios. Dada una línea con o sin tabulaciones, "unexpand" agrega tabulaciones cuando puede ahorrar bytes al hacerlo, como el comando "unexpand -a".

A diferencia de las viejas utilidades de unix, este módulo tiene en cuenta correctamente cualquier carácter de combinación Unicode (como los diacríticos) que pueda ocurrir en cada línea tanto para la expansión como para la contraexpansión. Estos son caracteres de sobreescritura que no incrementan la posición lógica. Asegúrese de tener habilitada la configuración Unicode apropiada.

EXPORTA

Se exportan los siguientes elementos:

expand
unexpand
$tabstop
La variable $tabstop controla cada cuántas posiciones de columna están las tabulaciones. El valor por defecto es 8.

Tenga en cuenta que local($tabstop) no hace lo correcto y si desea usar "local" para anular $tabstop, necesita usar local($Text::Tabs::tabstop).

EJEMPLO

#!perl
# unexpand -a
use Text::Tabs;
while (<>) {
  print unexpand $_;
}

En lugar del comando "expand" del shell, use:

perl -MText::Tabs -n -e 'print expand $_'

En lugar del comando "unexpand -a" del shell, use:

perl -MText::Tabs -n -e 'print unexpand $_'

ERRORES

Text::Tabs solo maneja tabulaciones ("\t") y caracteres de combinación ("/\pM/"). No cuenta hacia atrás para retrocesos ("\t"), omite otros caracteres de control no imprimibles ("/\pC/"), o de otra manera maneja cualquier otro carácter de ancho cero, medio y completo.
