Template::Parser(3) Documentación Perl contribuida por el usuario Template::Parser(3)

NOMBRE

Template::Parser - Analizador LALR(1) para compilar documentos de plantilla

SINOPSIS

use Template::Parser;
$parser   = Template::Parser->new(\%config);
$template = $parser->parse($text)
    || die $parser->error(), "\n";

DESCRIPCIÓN

El módulo "Template::Parser" implementa un analizador LALR(1) y métodos asociados para analizar documentos de plantilla en código Perl.

MÉTODOS PÚBLICOS

new(\%params)

El constructor new() crea y devuelve una referencia a un nuevo objeto "Template::Parser".

Se puede proporcionar una referencia a un hash como parámetro para proporcionar valores de configuración. Consulte "OPCIONES DE CONFIGURACIÓN" a continuación para ver un resumen de estas opciones y Template::Manual::Config para obtener detalles completos.

my $parser = Template::Parser->new({
    START_TAG => quotemeta('<+'),
    END_TAG   => quotemeta('+>'),
});

parse($text)

El método parse() analiza el texto pasado en el primer parámetro y devuelve una referencia a un array de hash con los datos que definen la representación compilada de la plantilla, adecuada para pasarla al método constructor new() de Template::Document. En caso de error, devuelve undef.

$data = $parser->parse($text)
    || die $parser->error();

La referencia de hash $data devuelta contiene un elemento "BLOCK" con el código Perl compilado para la plantilla, un elemento "DEFBLOCKS" con una referencia a un array de hash de sub-plantillas "BLOCK" definidas dentro de la plantilla, y un elemento "METADATA" con una referencia a un array de hash de valores de metadatos definidos en etiquetas "META".

OPCIONES DE CONFIGURACIÓN

El módulo "Template::Parser" acepta las siguientes opciones de configuración. Por favor, consulte Template::Manual::Config para más detalles sobre cada opción.

START_TAG, END_TAG

Las opciones START_TAG y END_TAG se utilizan para especificar secuencias de caracteres o expresiones regulares que marcan el inicio y el final de una directiva de plantilla.

my $parser = Template::Parser->new({
    START_TAG => quotemeta('<+'),
    END_TAG   => quotemeta('+>'),
});

TAG_STYLE

La opción TAG_STYLE se puede usar para establecer START_TAG y END_TAG según estilos de etiquetas predefinidos.

my $parser = Template::Parser->new({
    TAG_STYLE => 'star',     # [* ... *]
});

PRE_CHOMP, POST_CHOMP

PRE_CHOMP y POST_CHOMP se pueden establecer para eliminar cualquier espacio en blanco antes o después de una etiqueta de directiva, respectivamente.

my $parser = Template::Parser-E<gt>new({
    PRE_CHOMP  => 1,
    POST_CHOMP => 1,
});

INTERPOLATE

El indicador INTERPOLATE se puede establecer para permitir que las variables se incrusten en bloques de texto plano.

my $parser = Template::Parser->new({
    INTERPOLATE => 1,
});

Las variables deben ir precedidas de un signo "$" para identificarlas, usando llaves para delimitar explícitamente el nombre de la variable cuando sea necesario.

Hola ${name},
El día de hoy es ${day.today}.

ANYCASE

La opción ANYCASE se puede establecer para permitir que las palabras clave de las directivas se especifiquen en cualquier caso.

# con ANYCASE establecido a 1
[% INCLUDE foobar %]    # OK
[% include foobar %]    # OK
[% include = 10   %]    # ERROR, 'include' es una palabra reservada

GRAMMAR

El elemento de configuración GRAMMAR se puede usar para especificar una gramática alternativa para el analizador. Esto permite construir y usar un lenguaje de plantillas modificado o completamente nuevo con Template Toolkit.

use MyOrg::Template::Grammar;
my $parser = Template::Parser->new({
    GRAMMAR = MyOrg::Template::Grammar->new();
});

Por defecto, se creará y utilizará automáticamente una instancia de la gramática predeterminada de Template::Grammar si no se especifica un elemento "GRAMMAR".

DEBUG

La opción DEBUG se puede usar para habilitar varias funciones de depuración del módulo "Template::Parser".

use Template::Constants qw( :debug );
my $template = Template->new({
    DEBUG => DEBUG_PARSER | DEBUG_DIRS,
});
