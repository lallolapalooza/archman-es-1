Test2::Util(3perl) Guía de referencia del programador de Perl Test2::Util(3perl)

NOMBRE

Test2::Util - Herramientas utilizadas por Test2 y sus derivados.

DESCRIPCIÓN

Colección de herramientas utilizadas por Test2 y sus derivados.

EXPORTACIÓN

Todas las exportaciones son opcionales. Debes especificar las subs a importar.

($exito, $error) = try { ... }
Evalúa el bloque de código, devuelve el éxito o el fracaso, y el mensaje de error. Este código protege $@ y $!, se restaurarán al final de la ejecución. Este código también bloquea temporalmente los manejadores de $SIG{DIE}.
proteger { ... }
Similar a try, excepto que no captura excepciones. La idea aquí es proteger $@ y $! de cambios. $@ y $! se restaurarán a lo que fueran antes de la ejecución siempre que tenga éxito. Si la ejecución falla, $! aún se restaurará, pero $@ contendrá la excepción que se está lanzando.
PUEDE_FORK
Verdadero si este sistema es capaz de forkear real o pseudo.
PUEDE_REALMENTE_FORK
Verdadero si el sistema puede realmente forkeo. Esto será falso en sistemas donde fork está emulado.
PUEDE_HILO
Verdadero si este sistema es capaz de usar hilos.
USA_HILOS
Devuelve verdadero si los hilos están habilitados, falso si no lo están.
obtener_tid
Esto devolverá el ID del hilo actual cuando los hilos estén habilitados, de lo contrario devolverá 0.
mi $archivo = pkg_a_archivo($paquete)
Convierte un nombre de paquete a un nombre de archivo.
$cadena = separador_ipc()
Obtiene el separador IPC. Actualmente, esta es siempre la cadena '~'.
$cadena = generar_uid()
Genera un ID único (NO UN UUID). Este será típicamente el ID del proceso, el ID del hilo, la hora y un entero incremental, todo unido con el separador_ipc().

Estos ID son lo suficientemente únicos para la mayoría de los propósitos. Para que se generen ID idénticos, debes tener 2 procesos con el mismo PID generando ID al mismo tiempo con el mismo estado actual del entero incremental. Esto es algo perfectamente razonable de esperar que suceda en múltiples máquinas, pero es bastante improbable que suceda en una sola máquina.

Esto puede fallar en ser único si un proceso genera un ID, llama a exec, y lo hace de nuevo después de exec y todo sucede en menos de un segundo. También puede suceder si los ID de proceso del sistema se ciclan en menos de un segundo, permitiendo que 2 programas diferentes que usan este generador se ejecuten con el mismo PID en menos de un segundo. Ambos casos son suficientemente improbables. Si necesitas ID universalmente únicos, o ID que sean únicos en estas condiciones, busca Data::UUID.

($ok, $err) = renombrar_arch($nombre_viejo, $nombre_nuevo)
Renombra un archivo, esto envuelve a rename() de una manera que lo hace más confiable entre plataformas al intentar renombrar archivos que has alterado recientemente.
($ok, $err) = borrar_arch($nombre_archivo)
Elimina un archivo, esto envuelve a unlink() de una manera que lo hace más confiable entre plataformas al intentar eliminar archivos que has alterado recientemente.

NOTAS && CAUTELAS

5.10.0
Perl 5.10.0 tiene un error cuando se compila con versiones más nuevas de gcc. Este error causa una caída del segmento cada vez que se lanza un nuevo hilo. Test2 intentará detectar esto y advertirá que el sistema no es capaz de forkear cuando se detecta.
Devel::Cover
Devel::Cover no soporta hilos. CAN_THREAD devolverá falso si Devel::Cover se carga antes de que se ejecute la comprobación por primera vez.
