NOMBRE

Term::ExtendedColor - Salida de pantalla de color usando 256 colores

SINTAXIS

use Term::ExtendedColor qw(:all);
# O use el tag 'attributes' para solo importar las funciones para establecer
# atributos.
# Esta importará las siguientes funciones:
# fg(), bg(), bold(), underline(), inverse(), italic(), clear()
use Term::ExtendedColor ':attributes';
## Colores de frente
my $red_text = fg('red2', 'este es en rojo');
my $spring   = fg('springgreen3', 'este es verde');
## Colores de fondo
print bg('red5', "Texto de color por defecto en fondo rojo"), "\n";
my $red_on_green = fg('red3', bg('green12', 'Texto rojo en fondo verde'));
print "$red_on_green\n";
## Attributos de caídas en cascada
Term::ExtendedColor::autoreset(0);
my $bold  = fg('bold', 'Este es en negrita');
my $red   = fg('red2', 'Este es rojo... y negrita');
my $green = bg('green28', 'Este es rojo en fondo verde');
# Debe asegurarse de limpiar todos los atributos cuando autoreset esté desactivado,
# de lo contrario el shell del usuario se verá dañado
my $clear = clear();
print "$bold\n";
print "$red\n";
print "$green $clear\n";
## Sin atributos de color
# Vuelva a activar autoreset
Term::ExtendedColor::autoreset(1);
for(qw(italic underline blink reverse bold)) {
  print fg($_, $_), "\n";
}
# Para conveniencia
my $bolded = bold("Texto en negrita!");
my $italic = italic("Texto en cursiva!");
## Elimine todos los atributos de los datos de entrada
my @colored;
push(@colored, fg('bold', fg('red2', 'Negrita y rojo')));
push(@colored, fg('green13', fg('cursiva', 'Verde, cursiva')));
print "$_\n" for @colored;
print "$_\n" for uncolor(@colored);

DESCRIPCIÓN

Term::ExtendedColor proporciona funciones para enviar secuencias de escape llamadas "extendidas" a la terminal. Esta debería usarse con un terminal que soporte 256 colores; véase la sección de NOTAS para una matriz de emuladores de terminal actualmente que lo soportan.

EXPORTS

Sin embargo, no se importan por defecto.

Dos tags son proporcionados para conveniencia:

# Importar todas las funciones
use Term::ExtendedColor qw(:all);
# Importar funciones para establecer atributos
# fg(), bg(), bold(), italic(), underline(), inverse(), clear()
use Term::ExtendedColor qw(:attributes);

FUNCIONES

fg($color, $string)

my $green = fg('green2', 'fondo verde');
my @blue  = fg('blue4',  ['tomar referencias de arrays también']);
my $x_color = fg('mediumorchid1', 'usando mapeos de los colores de X11');
my $arbitary_color = fg(4, 'este es coloreado en el color ANSI 5');
my $raw_seq = fg('38;5;197;48;5;53;1;3;4;5;7', 'esto funciona también');

Establece colores de frente y atributos.

Ver "COLORS AND ATTRIBUTES" para argumentos válidos del primer argumento. Además, los colores pueden especificarse usando su valor índice:

my $yellow = fg(220, 'marrón');

Si el variable interna $AUTORESET es no cero (por defecto), cada elemento en la lista de strings se envolverá en secuencias de escape de tal manera que los atributos solicitados se establezcan antes del string y se restan a los defaults después del string.

Los atributos de caídas en cascada pueden activarse estableciendo $AUTORESET a un valor falso.

Term::ExtendedColor::autoreset( 0 );
my $red   = fg('red1', 'Rojo');
my $green = fg('green1', 'Verde');
print "Texto después de $red es rojo hasta $green\n";
print "Texto aún es verde, ", bold('y ahora negrita también!');
# Si no lo resetea ahora, hay un riesgo de que el prompt del usuario se vea dañado.
clear(); # Todos los atributos y colores se restan a los defaults

Si se pasa un atributo inválido, el dato original se devuelve sin cambios.

Si no se pasa ningún atributo, se lanza una excepción.

bg($color, $string)

my $green_bg = bg('green4', 'fondo verde');
my @blue_bg  = bg('blue6',  ['fondo azul']);

Como fg(), pero establece el color de fondo.

uncolor($string) | uncolour($string)

my $stripped = uncolor($colored_data);
my @no_color = uncolor(\@colored);
my @no_color = uncolor(@colored);

Elimina todas las secuencias de escape de color y atributo de los datos de entrada.

Ver uncolor para una utilidad de línea de comandos usando esta función.

get_colors() | get_colours()

my $colors = get_colors();

Devuelve un referencia a un hash con todos los atributos y colores disponibles.

clear()

Cuando se llama en contexto escalar, devuelve la secuencia de escape que resetea todos los atributos a sus valores predeterminados.

Cuando se llama en contexto void, imprime directamente la secuencia.

autoreset()

Enciende / apaga el autoreset. Está activo por defecto.

Term::ExtendedColor::autoreset( 0 ); # Apagar autoreset

bold(\@data)

Función de conveniencia que podría usarse en lugar de "fg('bold', \@data)";

Cuando se llama sin argumentos, devuelve una cadena que apaga el atributo de negrita.

italic(\@data)

Función de conveniencia que podría usarse en lugar de "fg('italic', \@data)";

Cuando se llama sin argumentos, devuelve una cadena que apaga el atributo de cursiva.

underline(\@data)

Función de conveniencia que podría usarse en lugar de "fg('underline', \@data)";

Cuando se llama sin argumentos, devuelve una cadena que apaga el atributo de subrayado.

inverse(\@data)

Modo de contraste / inverso. Función de conveniencia que podría usarse en lugar de "fg('inverse', \@data)";

Cuando se llama sin argumentos, devuelve una cadena que apaga el atributo de inverso.

NOTAS

Las secuencias de escape generadas por este módulo cumplen con la extensión del estándar ANSI de colores, implementada primero en xterm en 1999. Los primeros 16 índices (0 - 15) son los colores ANSI regulares, mientras que el índice 16 - 255 es la extensión. No todos los emuladores de terminal lo soportan, aunque he tenido dificultad en encontrar uno que no lo haga. :)

Terminal    256 colores
----------------------
aterm               no
eterm              yes
gnome-terminal     yes
konsole            yes
lxterminal         yes
mrxvt              yes
roxterm            yes
rxvt                no
rxvt-unicode       yes *
sakura             yes
terminal           yes
terminator         yes
vte                yes
xterm              yes
iTerm2             yes
Terminal.app        no
GNU Screen         yes
tmux               yes
TTY/VC              no

* Antes se necesitaba un parche. La soporte completa fue agregada en la versión 9.09.

No hay manera de dar estos colores de extensión nombres significativos.

Nuestro primer pensamiento fue mapearlos contra algunos nombres estándar de color, como los en la especificación HTML 4.0 o la uno de SVG. No coincidieron.

Por lo tanto, se les nombran por su color base (rojo, verde, magenta) más el índice; el primer índice (siempre 1) es el más claro de esa color, mientras que el último índice es el más oscuro.

También se pueden usar algunos nombres de color de X, como se definen en "rgb.txt". Debe tener en cuenta que los valores de color no coinciden exactamente; es solo una aproximación.

Una lista completa de los colores disponibles puede obtenerse con get_colors(). Ver "COLORS AND ATTRIBUTES" para una lista completa. Todos los colores mapeados también pueden obtenerse programáticamente con get_colors().

COLORS Y ATTRIBUTOS

Atributos

Los siguientes atributos son soportados:

normal
bold
dark
italic
underline
blink
reverse
hidden

Por ejemplo, puede obtener texto en negrita usando fg('bold', 'esto es negrita').

Colores ANSI Básicos

Estos son los 16 colores ANSI estándar.

Color       Foreground      Background
--------------------------------------
Black       black, brblack  blackbg, brblackbg
Red         red, brred      redbg, brredbg
Green       green, brgreen  greenbg, brgreenbg
Yellow      yellow, bryellow yellowbg, bryellowbg
Blue        blue, brblue    bluebg, brbluebg
Magenta     magenta, brmagenta magentabg, brmagenta
Cyan        cyan, brcyan    cyanbg, brcyanbg
White       white, brwhite  whitebg, brwhitebg

Los colores "br" (negrita) son los mismos que sus contrapartes no-negrita. En la mayoría de los casos, esto es solo una cuestión de nombre sin ningún efecto.

Colores Extendidos 0-255

Estos son los 256 colores soportados por la mayoría de los emuladores de terminal modernos.

Los colores de frente y de fondo se pueden especificar usando su nombre (ej. red1, red2, red3, etc.) o su número de índice.

Los nombres de color que terminan en un número son colores extendidos. Los nombres de color sin un número son los colores ANSI básicos.

Para el color de frente:

fg( 'color', 'texto' )

Para el color de fondo:

bg( 'color', 'texto' )

Para más detalles sobre los colores, véase la lista de colores de Vim.

Ejemplo:

my $red_bold = fg('red', bg('black', 'Esto es texto rojo en fondo negro'));
my $color_197 = fg(197, 'esto es texto en el color 197');

NAME

Term::ExtendedColor - provides support for extended colors and attributes

SYNOPSIS

    use Term::ExtendedColor;

    # Supported by Term::ExtendedColor functions:
    # colors: fg, bg, color
    # attributes: reset, clear, normal, bold, bright, faint, italic,
    #             underline, blink, blink_ms, reverse, conceal

    # Example with named colors
    print fg('red'), "This is red text\n";
    print bg('blue'), "This text has a blue background\n";
    print color('red', 'blue'), "This text is red on blue\n";
    print bold('This is bold text'), "\n";
    print color('red', 'bold', 'This is bold red text'), "\n";
    print reset(), "This text is back to normal\n";

    # Example with 256-color codes
    print fg('color1', '256'), "This is color 1\n";
    print fg('color255', '256'), "This is color 255\n";
    print color('color1;1', '256'), "This is color 1 on color 1\n";
    print color('color1;2', '256'), "This is color 1 on color 2\n";
    print color('color2;1', '256'), "This is color 2 on color 1\n";
    print color('color255;256', '256'), "This is color 255 on color 256\n";

    # Example with RGB color codes
    print fg('rgb:000000'), "This is black\n";
    print fg('rgb:FF0000'), "This is red\n";
    print fg('rgb:00FF00'), "This is green\n";
    print fg('rgb:0000FF'), "This is blue\n";
    print fg('rgb:FFFF00'), "This is yellow\n";
    print fg('rgb:FF00FF'), "This is magenta\n";
    print fg('rgb:00FFFF'), "This is cyan\n";
    print fg('rgb:FFFFFF'), "This is white\n";

    # Example with raw color codes
    print fg('48;5;89;38;5;197;1;3;4;7', 'foo');
    # Sets background to color 89, foreground to color 197, bold, italic, underline, reverse

DESCRIPTION

This module provides functions to generate ANSI escape sequences for the terminal for colors and attributes. It supports named colors, 256-color codes, and RGB color codes.

EXPORTS

The following functions are exported by default:

    fg, bg, color, reset, clear, normal, bold, bright, faint, italic,
    underline, blink, blink_ms, reverse, conceal

The following arrays are exported on request:

    %color_names
    @color_names

FUNCTIONS

fg(COLOR, TEXT)
Set foreground color.
bg(COLOR, TEXT)
Set background color.
color(COLOR, TEXT)
Set both foreground and background colors.
color(FOREGROUND, BACKGROUND, TEXT)
Set both foreground and background colors.
color(COLOR, ATTRIBUTES, TEXT)
Set foreground color and attributes.
color(FOREGROUND, BACKGROUND, ATTRIBUTES, TEXT)
Set foreground, background, and attributes.
reset()
Reset all attributes.
clear()
Clear screen.
normal()
Set normal intensity.
bold()
Set bold intensity.
bright()
Set bright intensity.
faint()
Set faint intensity.
italic()
Set italic attribute.
underline()
Set underline attribute.
blink()
Set slow blink attribute.
blink_ms()
Set rapid blink attribute.
reverse()
Set reverse video attribute.
conceal()
Set conceal attribute.

The COLOR argument can be one of the following:

  • A named color (e.g., 'red', 'blue').
  • A 256-color code (e.g., 'color1', 'color255').
  • An RGB color code (e.g., 'rgb:FF0000').
  • A raw color code (e.g., '48;5;89;38;5;197').

The ATTRIBUTES argument can be a comma-separated list of attribute names (e.g., 'bold,italic,underline').

NOTES

Not all terminals support all colors and attributes. The behavior may vary depending on the terminal emulator.
