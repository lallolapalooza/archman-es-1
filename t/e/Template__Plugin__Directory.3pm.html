NOMBRE

Template::Plugin::Directory - Plugin para generar listados de directorios

SINOPSIS

[% USE dir = Directory(dirpath) %]
# files devuelve una lista de archivos regulares
[% FOREACH file = dir.files %]
   [% file.name %] [% file.path %] ...
[% END %]
# dirs devuelve una lista de subdirectorios
[% FOREACH subdir = dir.dirs %]
   [% subdir.name %] [% subdir.path %] ...
[% END %]
# list devuelve ambos intercalados en orden
[% FOREACH item = dir.list %]
   [% IF item.isdir %]
      Directorio: [% item.name %]
   [% ELSE %]
      Archivo: [% item.name %]
   [% END %]
[% END %]
# define una VISTA para mostrar directorios/archivos
[% VIEW myview %]
   [% BLOCK file %]
   Archivo: [% item.name %]
   [% END %]
   [% BLOCK directory %]
   Directorio: [% item.name %]
   [% item.content(myview) | indent -%]
   [% END %]
[% END %]
# muestra el contenido del directorio usando la vista
[% myview.print(dir) %]

DESCRIPCIÓN

Este plugin de Template Toolkit proporciona una interfaz simple para los listados de directorios. Se deriva del módulo Template::Plugin::File y utiliza instancias de objetos de Template::Plugin::File para representar archivos dentro de un directorio. Los subdirectorios dentro de un directorio se representan mediante más instancias de "Template::Plugin::Directory".

El constructor espera el nombre de un directorio como argumento.

[% USE dir = Directory('/tmp') %]

Luego proporciona acceso a los archivos y subdirectorios contenidos dentro del directorio.

# archivos regulares (no directorios)
[% FOREACH file IN dir.files %]
   [% file.name %]
[% END %]
# solo directorios
[% FOREACH file IN dir.dirs %]
   [% file.name %]
[% END %]
# archivos y/o directorios
[% FOREACH file IN dir.list %]
   [% file.name %] ([% file.isdir ? 'directorio' : 'archivo' %])
[% END %]

El constructor del plugin generará un error de "Directory" si la ruta especificada no existe, no es un directorio o falla al stat() (ver Template::Plugin::File). De lo contrario, escaneará el directorio y creará listas llamadas '"files"' que contienen archivos, '"dirs"' que contienen directorios y '"list"' que contienen ambos archivos y directorios combinados. La opción "nostat" se puede establecer para deshabilitar todas las comprobaciones de archivos/directorios y el escaneo de directorios.

Cada archivo en el directorio será representado por una instancia de objeto Template::Plugin::File, y cada directorio por otra "Template::Plugin::Directory". Si se establece la bandera "recurse", entonces esos directorios contendrán entradas anidadas adicionales, y así sucesivamente. Con la bandera "recurse" sin establecer, como es por defecto, cada uno es solo un marcador de posición para el directorio y no contiene ningún contenido adicional a menos que se llame explícitamente a su método scan(). La bandera "isdir" se puede probar contra archivos y/o directorios, devolviendo verdadero si el elemento es un directorio o falso si es un archivo regular.

[% FOREACH file = dir.list %]
   [% IF file.isdir %]
      * Directorio: [% file.name %]
   [% ELSE %]
      * Archivo: [% file.name %]
   [% END %]
[% END %]

Este ejemplo muestra cómo podrías recorrer un árbol de directorios, mostrando el contenido a medida que avanzas. Con la bandera de recursión deshabilitada, como es por defecto, debemos llamar explícitamente al método scan() en cada directorio, para forzarlo a buscar archivos y subdirectorios adicionales contenidos en él.

[% USE dir = Directory(dirpath) %]
* [% dir.path %]
[% INCLUDE showdir %]
[% BLOCK showdir -%]
  [% FOREACH file = dir.list -%]
    [% IF file.isdir -%]
    * [% file.name %]
      [% file.scan -%]
      [% INCLUDE showdir dir=file FILTER indent(4) -%]
    [% ELSE -%]
    - [% f.name %]
    [% END -%]
  [% END -%]
 [% END %]

Este ejemplo se adapta (con algo de reformateo para mayor claridad) de una prueba en t/directry.t que produce la siguiente salida:

* test/dir
    - file1
    - file2
    * sub_one
        - bar
        - foo
    * sub_two
        - waz.html
        - wiz.html
    - xyzfile

La bandera "recurse" se puede establecer (deshabilitada por defecto) para hacer que el constructor recorra automáticamente todos los subdirectorios, creando un nuevo objeto "Template::Plugin::Directory" para cada uno y llenándolo con cualquier contenido adicional. En este caso, no es necesario llamar explícitamente al método scan().

[% USE dir = Directory(dirpath, recurse=1) %]
   ...
    [% IF file.isdir -%]
    * [% file.name %]
      [% INCLUDE showdir dir=file FILTER indent(4) -%]
    [% ELSE -%]
       ...

El plugin de directorio también proporciona soporte para vistas. Una vista se puede definir como un bloque "VIEW ... END" y debe contener definiciones de "BLOCK" para archivos ('"file"') y directorios ('"directory"').

[% VIEW myview %]
[% BLOCK file %]
   - [% item.name %]
[% END %]
[% BLOCK directory %]
   * [% item.name %]
     [% item.content(myview) FILTER indent %]
[% END %]
[% END %]

Luego se puede llamar al método print() de la vista, pasando el objeto "Directory" como argumento.

[% USE dir = Directory(dirpath, recurse=1) %]
[% myview.print(dir) %]

Cuando un directorio se presenta a una vista, ya sea como "[% myview.print(dir) %]" o "[% dir.present(view) %]", se procesa el bloque "directory" dentro de la vista "myview". La variable "item" se establecerá como alias del objeto "Directory".

[% BLOCK directory %]
   * [% item.name %]
     [% item.content(myview) FILTER indent %]
[% END %]

En este ejemplo, primero se imprime el nombre del directorio y luego se llama al método content(view) para presentar cada elemento dentro del directorio a la vista. Los directorios adicionales se mapearán al bloque "directory" y los archivos se mapearán al bloque "file".

Con la opción de recursión deshabilitada, como es por defecto, el bloque "directory" debería llamar explícitamente a un scan() en cada directorio.

[% VIEW myview %]
[% BLOCK file %]
   - [% item.name %]
[% END %]
[% BLOCK directory %]
   * [% item.name %]
     [% item.scan %]
     [% item.content(myview) FILTER indent %]
[% END %]
[% END %]
[% USE dir = Directory(dirpath) %]
[% myview.print(dir) %]

NOMBRE

Template::Plugin::Directory - plugin de directorio para el Toolkit de Plantillas

SINOPSIS

  [% USE Directory(path => '/path/to/directory') %]
  [% USE Directory('/path/to/directory') %]

  
    
  [% FOREACH item IN Directory.dir() %]
    
  • [% item.name %]
    • 
  [% END %]

DESCRIPCIÓN

El plugin Template::Plugin::Directory es un plugin para el Toolkit de Plantillas que proporciona acceso a la información de los directorios. Permite listar el contenido de un directorio y acceder a las propiedades de cada elemento (nombre, tipo, etc.).

Se instancia utilizando la directiva USE, especificando la ruta del directorio como argumento posicional o mediante la opción path.

El objeto devuelto por el plugin tiene un método dir() que devuelve una lista de objetos, cada uno representando un elemento del directorio. Cada uno de estos objetos tiene las siguientes propiedades:

  • name: El nombre del archivo o subdirectorio.
  • type: El tipo de elemento, que puede ser 'file' o 'directory'.
  • path: La ruta completa al elemento.
