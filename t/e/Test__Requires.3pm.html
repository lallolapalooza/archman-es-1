Test::Requires(3) Documentación de Perl contribuida por el usuario Test::Requires(3)

NOMBRE

Test::Requires - Comprueba si el módulo puede ser cargado

SINOPSIS

# en tu Makefile.PL
use inc::Module::Install;
test_requires 'Test::Requires';
# en tu test
use Test::More tests => 10;
use Test::Requires {
    'HTTP::MobileAttribute' => 0.01, # salta todo si HTTP::MobileAttribute no está instalado
};
isa_ok HTTP::MobileAttribute->new, 'HTTP::MobileAttribute::NonMobile';
# o
use Test::More tests => 10;
use Test::Requires qw( 
    HTTP::MobileAttribute
);
isa_ok HTTP::MobileAttribute->new, 'HTTP::MobileAttribute::NonMobile';
# o
use Test::More tests => 10;
use Test::Requires;
test_requires 'Some::Optional::Test::Required::Modules';
isa_ok HTTP::MobileAttribute->new, 'HTTP::MobileAttribute::NonMobile';

DESCRIPCIÓN

Test::Requires comprueba si el módulo puede ser cargado.

Si esto falla, en lugar de fallar las pruebas, salta todas las pruebas.

Test::Requires también puede ser utilizado para requerir una versión mínima de Perl:

use Test::Requires "5.010";  # ¡¡se requiere el uso de comillas!!

# o
use Test::Requires "v5.10";
