NOMBRE

Template::Document - Objeto de documento de plantilla compilado

SINOPSIS

use Template::Document;
$doc = Template::Document->new({
    BLOCK => sub { # algún código perl; devuelve $algún_texto },
    DEFBLOCKS => {
        header => sub { # más código perl; devuelve $algún_texto },
        footer => sub { # blah blah blah; devuelve $algún_texto },
    },
    METADATA => {
        author  => 'Andy Wardley',
        version => 3.14,
    }
}) || die $Template::Document::ERROR;
print $doc->process($context);

DESCRIPCIÓN

Este módulo define una clase de objeto cuyas instancias representan documentos de plantilla compilados. El módulo Template::Parser crea una instancia de "Template::Document" para encapsular una plantilla mientras se compila en código Perl.

El método constructor, new(), espera una referencia a un array hash que contenga los elementos "BLOCK", "DEFBLOCKS" y "METADATA".

El elemento "BLOCK" debe contener una referencia a una subrutina Perl o una representación textual de código Perl, tal como la genera el módulo Template::Parser. Esto se evalúa luego en una referencia de subrutina usando eval().

El elemento "DEFBLOCKS" debe referenciar un array hash que contenga "BLOCK"s nombrados adicionales que puedan definirse en la plantilla. Las claves representan los nombres de "BLOCK" y los valores deben ser referencias de subrutinas o cadenas de texto de código Perl según el elemento "BLOCK" principal.

El elemento "METADATA" debe referenciar un array hash de elementos de metadatos relevantes para el documento.

El método process() puede ser llamado en el objeto "Template::Document" instanciado, pasando una referencia a un objeto Template::Context como primer parámetro. Esto instalará cualquier bloque definido localmente ("DEFBLOCKS") en la caché de "BLOCKS" en el contexto (a través de una llamada a visit()) para que puedan ser resueltos posteriormente por el contexto. La subrutina principal "BLOCK" se ejecuta entonces, pasando la referencia del contexto como parámetro. El texto devuelto por la subrutina de plantilla es devuelto por el método process(), después de llamar al método leave() del contexto para permitir la limpieza y la des-registración de los "BLOCKS" nombrados previamente instalados.

Un método "AUTOLOAD" proporciona acceso a los elementos "METADATA" del documento. El módulo Template::Service instala una referencia al objeto principal "Template::Document" en el stash como la variable "template". Esto permite acceder a los elementos de metadatos desde dentro de las plantillas, incluyendo las plantillas "PRE_PROCESS".

header:

<html>
<head>
<title>[% template.title %]
</head>
...

Los objetos "Template::Document" son usualmente creados por Template::Parser pero pueden ser instanciados manualmente o subclasificados para proporcionar componentes de plantilla personalizados.

MÉTODOS

new(\%config)

Método constructor que acepta una referencia a un array hash conteniendo la estructura como se muestra en este ejemplo:

$doc = Template::Document->new({
    BLOCK => sub { # algún código perl; devuelve $algún_texto },
    DEFBLOCKS => {
        header => sub { # más código perl; devuelve $algún_texto },
        footer => sub { # blah blah blah; devuelve $algún_texto },
    },
    METADATA => {
        author  => 'Andy Wardley',
        version => 3.14,
    }
}) || die $Template::Document::ERROR;

Los elementos "BLOCK" y "DEFBLOCKS" pueden expresarse como referencias a subrutinas Perl o como cadenas de texto que contienen definiciones de subrutinas Perl, como se genera por el módulo Template::Parser. Estos se evalúan en referencias de subrutinas usando eval().

Devuelve un nuevo objeto "Template::Document" o "undef" en caso de error. El método de clase error() puede ser llamado, o la variable de paquete $ERROR inspeccionada para recuperar el mensaje de error relevante.

process($context)

Rutina de procesamiento principal para el documento de plantilla compilado. Se debe pasar una referencia a un objeto Template::Context como primer parámetro. El método instala cualquier bloque definido localmente a través de una llamada al método visit() del contexto, procesa su propia plantilla (pasando la referencia del contexto como parámetro) y luego llama a leave() en el contexto para permitir la limpieza.

print $doc->process($context);

Devuelve una cadena de texto que representa la salida generada para la plantilla. Los errores se lanzan a través de die().

block()

Devuelve una referencia a la subrutina principal "BLOCK".

blocks()

Devuelve una referencia al array hash de subrutinas "DEFBLOCKS" nombradas.

variables()

Devuelve una referencia a un hash de variables usadas en la plantilla. Esto requiere que la opción TRACE_VARS esté habilitada.

meta()

Devuelve una referencia a un hash de cualquier elemento META definido en la plantilla.

AUTOLOAD

Un método autoload devuelve elementos de "METADATA".

print $doc->author();

MÉTODOS DE CLASE

Estos métodos se utilizan internamente.

as_perl($content)

Este método genera una representación Perl de la plantilla.

my $perl = Template::Document->as_perl({
    BLOCK     => $main_block,
    DEFBLOCKS => {
        foo   => $foo_block,
        bar   => $bar_block,
    },
    METADATA  => {
        name  => 'my_template',
    }
});

write_perl_file(\%config)

Este método se utiliza para escribir plantillas Perl compiladas en disco. Si la opción "COMPILE_EXT" (para indicar una extensión de archivo para guardar plantillas compiladas) está configurada, entonces el módulo Template::Parser llama a esta subrutina antes de llamar al constructor new(). En esta etapa, el analizador tiene una representación de la plantilla como cadenas de texto que contienen código Perl. Podemos escribir eso en un archivo, encerrado en un pequeño envoltorio que nos permitirá posteriormente hacer require() del archivo y hacer que Perl lo analice y compile en un "Template::Document". Por lo tanto, tenemos persistencia de plantillas compiladas.

FUNCIONES INTERNAS

catch_warnings()

Este es un manejador simple utilizado para capturar cualquier error que surja cuando el código Perl compilado de la plantilla se evalúa por primera vez (es decir, evaluado por Perl para crear una subrutina de plantilla en tiempo de compilación, en lugar de que la plantilla se procese en tiempo de ejecución).

is_utf8()

Esto se mapea a "utf8::is_utf8" para versiones de Perl que lo tienen (> 5.008) o a "Encode::is_utf8" para Perl 5.008. Las versiones anteriores de Perl no son compatibles.
