Test2::Bundle::More(3perl) Guía del programador de Perl Test2::Bundle::More(3perl)

NOMBRE

Test2::Bundle::More - CASI un reemplazo directo para Test::More.

DESCRIPCION

Este paquete está destinado a ser un reemplazo (en su mayoría) directo para Test::More. Ver "DIFERENCIAS CLAVE CON Test::More" para más detalles.

SINOPSIS

use Test2::Bundle::More;
ok(1, "pasar");
...
done_testing;

PLUGINS

Carga Test2::Plugin::ExitSummary.

HERRAMIENTAS

Estas son de Test2::Tools::Basic. Ver Test2::Tools::Basic para más detalles.

ok($bool, $nombre)
pass($nombre)
fail($nombre)
skip($por_que, $cantidad)
$todo = todo($why)
diag($mensaje)
note($mensaje)
plan($cantidad)
skip_all($por_que)
done_testing()
BAIL_OUT($por_que)

Estas son de Test2::Tools::ClassicCompare. Ver Test2::Tools::ClassicCompare para más detalles.

is($obtenido, $esperado, $nombre)
isnt($obtenido, $noesperado, $nombre)
like($obtenido, qr/coincidencia/, $nombre)
unlike($obtenido, qr/desajuste/, $nombre)
is_deeply($obtenido, $esperado, "Comparación profunda")
cmp_ok($obtenido, $op, $esperado, $nombre)

Estas son de Test2::Tools::Class. Ver Test2::Tools::Class para más detalles.

isa_ok($cosa, @clases)
can_ok($cosa, @subs)

Esto es de Test2::Tools::Subtest. Se llama subtest_streamed() en ese paquete.

subtest $nombre => sub { ... }

DIFERENCIAS CLAVE CON Test::More

No puedes planificar al importar.
ESTO NO FUNCIONARÁ: 
use Test2::Bundle::More tests => 5;

En cambio, debes planificar en una declaración separada:

use Test2::Bundle::More;
plan 5;
Tienes tres subs importadas para usar en la planificación
Usa plan($cantidad), skip_all($razon) o done_testing() para tu planificación.
isa_ok acepta argumentos diferentes
"isa_ok" en Test::More era: 
isa_ok($cosa, $isa, $nombre_alternativo_cosa);

Esto era muy inconsistente con herramientas como "can_ok($cosa, @subs)".

En Test2::Bundle::More, isa_ok() toma una $cosa y una lista de @isa.

isa_ok($cosa, $clase1, $clase2, ...);

ESTAS FUNCIONES Y VARIABLES HAN SIDO ELIMINADAS

$TODO
Ver todo().
use_ok()
require_ok()
No son necesarias. Usa "use" y "require" directamente. Si hay un error al cargar el módulo, la prueba capturará el error y fallará.
todo_skip()
No es necesario.
eq_array()
eq_hash()
eq_set()
Desaconsejado en Test::More.
explain()
Esto inició una pelea entre los desarrolladores de Test, quienes ahora pueden escribir sus propias implementaciones en Test2. (Ver explain en Test::Most vs Test::More. Pista: Test::Most lo escribió primero, luego Test::More lo agregó, pero rompió la compatibilidad).
new_ok()
No es necesario.
