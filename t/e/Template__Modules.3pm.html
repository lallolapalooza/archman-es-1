Módulos del Template Toolkit

Esta documentación proporciona una visión general de los diferentes módulos que componen el Template Toolkit.

Template

El módulo Template es la interfaz para el Template Toolkit para programadores Perl.

use Template;
my $tt = Template->new();
$tt->process('hello.html', message => 'Hola Mundo');

Template::Base

El módulo Template::Base implementa una clase base de la cual derivan los otros módulos del Template Toolkit. Implementa funcionalidad común para crear objetos, reportar errores, depurar, etc.

Template::Config

El módulo Template::Config define la configuración del Template Toolkit para su sistema. Es un ejemplo de un módulo factoría que es responsable de instanciar los diversos módulos utilizados en el Template Toolkit.

Por ejemplo, el módulo Template::Config define la variable de paquete $STASH que indica qué versión de Template::Stash está utilizando por defecto. Si eligió usar el stash XS más rápido al instalar el Template Toolkit, esto se establecerá como:

$STASH = 'Template::Stash::XS';

De lo contrario, obtendrá el stash Perl normal:

$STASH = 'Template::Stash';

Este enfoque significa que otras partes del Template Toolkit no tienen que preocuparse de qué stash está utilizando. Simplemente piden al módulo Template::Config que cree un stash del tipo correcto.

Template::Constants

Template::Constants define una serie de constantes que son utilizadas por el Template Toolkit.

Por ejemplo, el conjunto de etiquetas ":chomp" define las constantes "CHOMP_???" que se pueden utilizar con las opciones de configuración "PRE_CHOMP" y "POST_CHOMP".

use Template::Constants ':chomp';
my $tt = Template->new({
    PRE_CHOMP => CHOMP_COLLAPSE,
});

Template::Context

El módulo Template::Context define un contexto de ejecución en el que se procesan las plantillas. Un contexto realiza un seguimiento de todas las plantillas, variables, plugins y otros recursos que están disponibles (directa o indirectamente a través de objetos delegados) y proporciona métodos para obtener, almacenar y realizar diversas operaciones sobre ellos.

Template::Document

El módulo Template::Document implementa un objeto de documento de plantilla compilado. Este es generado por el módulo Template::Parser.

Template::Exception

El módulo Template::Exception implementa un objeto de excepción que se utiliza para la notificación de errores en tiempo de ejecución.

Template::Filters

El módulo Template::Filters implementa un proveedor de filtros. Incluye la colección principal de filtros que se pueden usar a través de la directiva "FILTER".

Template::Iterator

El módulo Template::Iterator implementa un iterador de datos que recorre cada elemento de una lista por turno. Es utilizado por la directiva "FOREACH". Dentro de un bloque "FOREACH", la variable "loop" siempre hace referencia al objeto iterador actual.

[%  FOREACH item IN list;
      IF loop.first;
         # primer elemento del bucle
      ELSIF loop.last;
         # último elemento del bucle
      ELSE;
         # cualquier otro elemento del bucle
      END;
    END
%]

Template::Namespace::Constants

El módulo Template::Namespace::Constants se utiliza internamente para representar constantes. Estas pueden resolverse inmediatamente en el momento en que se compila una plantilla.

Template::Parser

El módulo Template::Parser se utiliza para analizar una plantilla de origen y convertirla en código Perl que se pueda ejecutar.

Template::Plugin

El módulo Template::Plugin es una clase base para los plugins del Template Toolkit que se pueden cargar bajo demanda desde dentro de una plantilla utilizando la directiva "USE".

Template::Plugins

El módulo Template::Plugins es el proveedor de plugins. Carga y prepara los plugins cuando son solicitados desde dentro de una plantilla.

Template::Provider

El módulo Template::Provider es responsable de cargar, compilar y almacenar en caché las plantillas.

Template::Service

El módulo Template::Service implementa una capa de servicio que se encuentra justo detrás del módulo Template, y justo delante de un Template::Context. Maneja cada solicitud para procesar una plantilla (reenviada desde el módulo Template). Agrega las cabeceras y/o pies de página (especificados a través de las opciones "PRE_PROCESS" y "POST_PROCESS"), aplica cualquier envoltorio (la opción "WRAPPER") y captura cualquier error devuelto (la opción "ERRORS").

Template::Stash

El módulo Template::Stash se utiliza para obtener y almacenar variables de plantilla. Implementa toda la magia asociada con el operador punto.

Template::Stash::XS

El módulo Template::Stash::XS es una implementación de alta velocidad de Template::Stash escrita en C.

Template::Test

El módulo Template::Test se utiliza para automatizar los scripts de prueba del Template Toolkit.

pacman

Nombre

pm - Una utilidad de línea de comandos para gestionar paquetes.

Sinopsis

pm [opciones] [paquete]

Descripción

pm es una herramienta para facilitar la gestión de paquetes en Arch Linux. Permite buscar, instalar, actualizar, eliminar y listar paquetes del sistema.

Opciones

  • -S, --sync: Sincroniza e instala paquetes.
  • -R, --remove: Elimina paquetes.
  • -U, --upgrade: Actualiza paquetes.
  • -Ss, --search: Busca paquetes en las bases de datos de repositorios.
  • -Qi, --info: Muestra información detallada sobre un paquete instalado.
  • -Qe, --explicit: Lista los paquetes instalados explícitamente.
  • -Qu, --queryupgrades: Lista los paquetes que se pueden actualizar.
  • -h, --help: Muestra este mensaje de ayuda y sale.
  • -v, --version: Muestra información de la versión y sale.

Ejemplos

# Instalar el paquete 'firefox'
pm -S firefox

# Eliminar el paquete 'vlc'
pm -R vlc

# Actualizar todos los paquetes del sistema
pm -Syu

# Buscar paquetes que contengan la palabra 'editor'
pm -Ss editor

# Mostrar información sobre el paquete instalado 'git'
pm -Qi git
