Test2::Compare::Base(3perl) Guía del programador de Perl Test2::Compare::Base(3perl)

NOMBRE

Test2::Compare::Base - Clase base para clases de comparación.

DESCRIPCIÓN

Todas las clases de comparación para Test2::Compare deben heredar de esta clase base.

SINOPSIS

package Test2::Compare::MyCheck;
use strict;
use warnings;
use base 'Test2::Compare::Base';
use Test2::Util::HashBase qw/stuff/;
sub name { 'STUFF' }
sub operator {
    my $self = shift;
    my ($got) = @_;
    return 'eq';
}
sub verify {
    my $self = shift;
    my $params = @_;
    # ¡Siempre comprueba si $got existe! Este método debe devolver falso si no
    # se recibió ningún valor.
    return 0 unless $params{exists};
    my $got = $params{got};
    # Devuelve verdadero si ambos valores coinciden. ¡Esto incluye undef, 0 y otros
    # valores falsos!
    return $got eq $self->stuff;
}

MÉTODOS

Algunos de estos deben ser sobrescritos, otros pueden serlo.

$dclass = $check->delta_class
Devuelve la subclase delta que debe utilizarse. Por defecto se utiliza Test2::Compare::Delta.
@deltas = $check->deltas(id => $id, exists => $bool, got => $got, convert => \&convert, seen => \%seen)
Debe devolver deltas hijos.
@lines = $check->got_lines($got)
Esta es tu oportunidad de proporcionar números de línea para errores en la estructura $got.
$op = $check->operator()
$op = $check->operator($got)
Devuelve el operador que se utilizó para comparar la comprobación con los datos recibidos en $got. Si no había ningún valor para `got`, no habrá argumentos; `undef` solo será un argumento si se vio `undef` en $got. Así es como se puede diferenciar entre un valor faltante y uno indefinido.
$bool = $check->verify(id => $id, exists => $bool, got => $got, convert => \&convert, seen => \%seen)
Devuelve verdadero si hay una coincidencia superficial, es decir, ambos elementos son arrayrefs, ambos elementos son la misma cadena o el mismo número, etc. Esto no debe recursar, ya que las comprobaciones profundas se realizan en "$check->deltas()".
$name = $check->name
Obtiene el nombre de la comprobación.
$display = $check->render
Lo que se debe mostrar en una tabla para esta comprobación, normalmente el nombre o el valor.
$delta = $check->run(id => $id, exists => $bool, got => $got, convert => \&convert, seen => \%seen)
Aquí es donde se realiza la comprobación, primero una comprobación superficial utilizando "$check->verify", luego comprobando "$check->deltas()". "\%seen" se utiliza para prevenir ciclos.
