Test2::Compare::Array(3perl) Guía de referencia para programadores de Perl Test2::Compare::Array(3perl)

NOMBRE

Test2::Compare::Array - Representación interna de una comparación de arrays.

DESCRIPCIÓN

Este módulo es una representación interna de un array para fines de comparación.

MÉTODOS

$ref = $arr->inref()
Si la instancia se construyó a partir de un array real, esto devolverá la referencia a ese array.
$bool = $arr->ending
$arr->set_ending($bool)
Establezca esto en verdadero si desea fallar cuando el array que se está validando tenga más elementos que la verificación. Es decir, si verifica los índices 0-3 pero el array tiene valores para los índices 0-4, fallará y listará ese último elemento del array como inesperado. Si se establece en falso, se asume que no le importan los elementos adicionales.
$hashref = $arr->items()
Devuelve el hashref de pares "clave => valor" que se verificarán en el array.
$arr->set_items($hashref)
Acepta un hashref para permitir omitir índices si se desea.

Nota: que no hay validación al usar "set_items", es mejor usar la interfaz "add_item".

$arrayref = $arr->order()
Devuelve un arrayref de todos los índices que se verificarán, en orden.
$arr->set_order($arrayref)
Establece el orden en que se verificarán los índices.

Nota: que no hay validación al usar "set_order", es mejor usar la interfaz "add_item".

$name = $arr->name()
Siempre devuelve la cadena "<ARRAY>".
$bool = $arr->verify(got => $got, exists => $bool)
Comprueba si $got es una referencia de array o no.
$idx = $arr->top_index()
Devuelve el índice superior que se está verificando. Esto devolverá undef si no hay elementos, o 0 si solo hay 1 elemento.
$arr->add_item($item)
Agrega un elemento a la lista de valores a verificar.
$arr->add_item($idx => $item)
Agrega un elemento a la lista de valores a verificar en el índice especificado.
$arr->add_filter(sub { ... })
Agrega una subrutina de filtro. El filtro recibe todos los valores restantes del array que se está verificando y debe devolver los valores que aún deben verificarse. El filtro se ejecutará entre el último elemento agregado y el siguiente elemento agregado.
@deltas = $arr->deltas(got => $got, convert => \&convert, seen => \%seen)
Encuentra las diferencias entre los valores esperados del array y los del arrayref $got.
