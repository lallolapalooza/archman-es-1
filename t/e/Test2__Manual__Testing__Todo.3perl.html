NOMBRE

Test2::Manual::Testing::Todo - Tutorial para marcar pruebas como TODO.

DESCRIPCIÓN

Este tutorial cubre el proceso de marcar pruebas como TODO. También describe cómo funciona TODO internamente.

LA HERRAMIENTA

use Test2::Tools::Basic qw/todo/;

BLOQUE TODO

Esta forma es de baja magia. Todas las pruebas dentro del bloque se marcan como todo, las pruebas fuera del bloque no son todo. No necesitas gestionar ninguna variable. El defecto de esta forma es que añade un par de niveles a la pila, lo que puede romper algunas pruebas de alta magia.

En general, esta es la forma preferida a menos que tengas un caso especial que requiera la forma de variable.

todo "Razón para el todo" => sub {
    ok(0, "falla pero es todo");
    ...
};

VARIABLE TODO

Esta forma mantiene el alcance de TODO durante la vida de la variable. Esto es útil para pruebas que son sensibles a los cambios de alcance. Esto emula de cerca el estilo de Test::More que localizaba la variable de paquete $TODO. Una vez que la variable se destruye (se establece en undef, fin de alcance, etc.) el estado TODO termina.

my $todo = todo "Razón para el todo";
ok(0, "falla pero es todo");
...
$todo = undef;

EVENTOS MANUALES DE TODO

use Test2::API qw/context/;
sub todo_ok {
    my ($bool, $name, $todo) = @_;
    my $ctx = context();
    $ctx->send_event('Ok', pass => $bool, effective_pass => 1, todo => $todo);
    $ctx->release;
    return $bool;
}

El evento Test2::Event::Ok tiene un campo "todo" que debe contener la razón del todo. El evento también tiene los campos "pass" y "effective_pass". El campo "pass" es el valor real de pase/falla. El campo "effective_pass" se utiliza para determinar si el evento es una falla real (siempre debe establecerse en verdadero con todo).

CÓMO LAS HERRAMIENTAS DE TODO FUNCIONAN INTERNAMENTE

La biblioteca Test2::Todo obtiene la instancia actual de Test2::Hub y añade un filtro. El filtro que se añade establecerá los campos "todo" y "effective_pass" en cualquier evento Test2::Event::Ok que pase por el hub. El filtro también convierte los eventos Test2::Event::Diag en eventos Test2::Event::Note.
