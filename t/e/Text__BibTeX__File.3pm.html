NOMBRE

Text::BibTeX::File - interfaz para archivos BibTeX completos

SINOPSIS

use Text::BibTeX::File;
$bib = Text::BibTeX::File->new("foo.bib") or die "foo.bib: $!\n";
# o:
$bib =  Text::BibTeX::File->new;
$bib->open("foo.bib", {binmode => 'utf-8', normalization => 'NFC'}) || die "foo.bib: $!\n";
$bib->set_structure ($structure_name,
                     $option1 => $value1, ...);
$at_eof = $bib->eof;
$bib->close;

DESCRIPCIÓN

"Text::BibTeX::File" proporciona una interfaz orientada a objetos para archivos BibTeX. Su propósito más obvio es hacer un seguimiento de un nombre de archivo y un manejador de archivo juntos para su uso por el módulo "Text::BibTeX::Entry" (que es mucho más interesante). Además, le permite especificar ciertas opciones que son aplicables a una base de datos completa (archivo), en lugar de tener que especificarlas para cada entrada en el archivo. Actualmente, puede especificar la estructura de la base de datos y algunas opciones de estructura. Estos conceptos están completamente documentados en Text::BibTeX::Structure.

MÉTODOS

Creación de objetos, operaciones de archivo

new ([FILENAME], [OPTS])
Crea un nuevo objeto "Text::BibTeX::File". Si se proporciona FILENAME, lo pasa al método "open" (junto con OPTS). Si "open" falla, "new" falla y devuelve falso; si "open" tiene éxito (o si no se proporciona FILENAME), "new" devuelve la referencia del nuevo objeto.
open (FILENAME [OPTS])
Abre el archivo especificado por FILENAME. OPTS es un hashref que puede tener los siguientes valores:
MODE
modo según lo especificado por IO::File
PERMS
permisos según lo especificado por IO::File. Solo se puede usar en conjunción con "MODE"
BINMODE
Por defecto, Text::BibTeX utiliza bytes directamente. Por lo tanto, debe codificar las cadenas en consecuencia con la codificación de los archivos que está leyendo. También puede seleccionar UTF-8. En este caso, Text::BibTeX devolverá cadenas UTF-8 en modo NFC. Tenga en cuenta que en este momento los archivos con BOM no son compatibles.

Los valores válidos son 'raw/bytes' o 'utf-8'.

NORMALIZATION
Por defecto, Text::BibTeX genera UTF-8 en forma NFC. Puede cambiar esto pasando el nombre de una forma diferente.

Los valores válidos son las formas admitidas por el módulo Unicode::Normalize ('NFD', 'NFDK' etc.)

RESET_MACROS
Por defecto, Text::BibTeX acumula macros. Esto significa que cuando abre un segundo archivo, las macros definidas por el primero todavía están disponibles. Esto puede dar lugar a advertencias sobre macros que se redefinen.

Esta opción se puede utilizar para forzar a Text::BibTeX a limpiar todas las definiciones de macros (excepto las macros de mes).

close ()
Cierra el manejador de archivo asociado con el objeto. Si no hay tal manejador de archivo (es decir, "open" nunca se llamó en el objeto), no hace nada.
eof ()
Devuelve el estado de fin de archivo del manejador de archivo asociado con el objeto: un valor verdadero significa que estamos al final del archivo.

Propiedades del objeto

set_structure (STRUCTURE [, OPTION => VALUE, ...])
Establece la estructura de la base de datos para un archivo BibTeX. En el nivel más simple, esto significa que se espera que las entradas del archivo cumplan con ciertos requisitos de campo según lo especificado por el módulo de estructura. También le da acceso completo a los métodos de la clase de entrada estructurada particular para esta estructura, lo que le permite realizar operaciones específicas para este tipo de base de datos. Consulte "INTERACCIONES DE CLASE" en Text::BibTeX::Structure para conocer todas las consecuencias de establecer la estructura de la base de datos para un objeto "Text::BibTeX::File".
structure ()
Devuelve el nombre de la estructura de la base de datos asociada con el objeto (según lo establecido por "set_structure").
preserve_values ([PRESERVE])
Establece el indicador de "conservar valores", para controlar el análisis futuro de las entradas de este archivo. Si PRESERVE no se proporciona, devuelve el estado actual del indicador. Consulte Text::BibTeX::Value para obtener detalles sobre el análisis en modo de "conservación de valores".
