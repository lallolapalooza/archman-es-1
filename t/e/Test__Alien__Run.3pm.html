Test::Alien::Run(3) Documentación de Contribución de Usuarios de Perl Test::Alien::Run(3)

NOMBRE

Test::Alien::Run - Objeto de ejecución

VERSIÓN

versión 2.84

SINOPSIS

use Test2::V0;
use Test::Alien;

run_ok([ $^X, -e => 'print "some output"; exit 22'])
  ->exit_is(22)
  ->out_like(qr{some});

DESCRIPCIÓN

Esta clase almacena información sobre una ejecución de proceso realizada por Test::Alien#run_ok. Esa función es la *ÚNICA* forma de crear una instancia de esta clase.

ATRIBUTOS

out

my $str = $run->out;

La salida estándar de la ejecución.

err

my $str = $run->err;

El error estándar de la ejecución.

exit

my $int = $run->exit;

El valor de salida de la ejecución.

signal

my $int = $run->signal;

La señal que terminó la ejecución, o cero si el proceso se terminó normalmente.

MÉTODOS

Estos métodos devuelven el propio objeto de ejecución, por lo que pueden encadenarse, como en la sinopsis anterior.

success

$run->success;
$run->success($message);

Pasa si el proceso terminó normalmente con un valor de salida de 0.

exit_is

$run->exit_is($exit);
$run->exit_is($exit, $message);

Pasa si el proceso terminó con el valor de salida dado.

exit_isnt

$run->exit_isnt($exit);
$run->exit_isnt($exit, $message);

Pasa si el proceso terminó con un valor de salida diferente al dado.

out_like

$run->out_like($regex);
$run->out_like($regex, $message);

Pasa si la salida de la ejecución coincide con el patrón dado.

out_unlike

$run->out_unlike($regex);
$run->out_unlike($regex, $message);

Pasa si la salida de la ejecución no coincide con el patrón dado.

err_like

$run->err_like($regex);
$run->err_like($regex, $message);

Pasa si el error estándar de la ejecución coincide con el patrón dado.

err_unlike

$run->err_unlike($regex);
$run->err_unlike($regex, $message);

Pasa si el error estándar de la ejecución no coincide con el patrón dado.

note

$run->note;

Envía la salida y el error estándar como una nota de prueba.

diag

$run->diag;

Envía la salida y el error estándar como un diagnóstico de prueba.
