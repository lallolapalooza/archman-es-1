NOMBRE

Test2::Manual::Anatomy::Utilities - Visión general de las utilidades para Test2.

DESCRIPCIÓN

Esta es una breve descripción general de las utilidades proporcionadas por Test2.

Test2::Util

Test2::Util proporciona funciones para ayudarte a obtener información sobre el sistema actual o para ejecutar tareas genéricas que tienden a ser específicas de Test2.

Esta utilidad proporciona cosas como una implementación interna de "try {...}" y constantes para cosas como el soporte de hilos y bifurcaciones.

Test2::Util::ExternalMeta

Test2::Util::ExternalMeta te permite adjuntar metadatos a una clase de objeto de forma rápida y sencilla.

Test2::Util::Facets2Legacy

Test2::Util::Facets2Legacy es un conjunto de funciones que puedes importar en una clase de eventos más reciente para proporcionar la API de eventos clásica.

Test2::Util::HashBase

Test2::Util::HashBase es una copia local de Object::HashBase. Todas las clases de objetos proporcionadas por Test2 utilizan esto para generar métodos y accesores.
