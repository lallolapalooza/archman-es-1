Test2::Tools::Basic(3perl) Guía del programador de Perl Test2::Tools::Basic(3perl)

NOMBRE

Test2::Tools::Basic - Implementación de Test2 de las herramientas básicas de pruebas.

DESCRIPCIÓN

Esta es una implementación basada en Test2 de las herramientas más básicas que originalmente proporcionaba Test::More. No todas las herramientas de Test::More son proporcionadas por este paquete, solo las básicas/simples. Algunas herramientas han sido modificadas para mejorar las capacidades de diagnóstico.

SINOPSIS

use Test2::Tools::Basic;
ok($x, "test simple");
if ($pasando) {
    pass('una prueba que pasa');
}
else {
    fail('una prueba que falla');
}
diag "Este es un mensaje de diagnóstico en STDERR";
note "Este es un mensaje de diagnóstico en STDOUT";
{
    my $todo = todo "Razón para todo";
    ok(0, "esta prueba es todo");
}
ok(1, "esta prueba no es todo");
todo "razón" => sub {
    ok(0, "esta prueba es todo");
};
ok(1, "esta prueba no es todo");
SKIP: {
    skip "Esto borrará tu disco";
    # Esto nunca se ejecuta:
    ok(!system('sudo rm -rf /'), "Borrar disco");
}
done_testing;

EXPORTACIONES

Todas las subs se exportan por defecto.

PLANIFICACIÓN

plan($num)
plan('tests' => $num)
plan('skip_all' => $razon)
Establece el número de pruebas esperadas. Esto debe hacerse al principio o al final, nunca en medio de las pruebas.

Para compatibilidad heredada, puedes especificar 'tests' como el primer argumento antes del número. También puedes usar esto para saltar todo con el prefijo 'skip_all', seguido de una razón para saltar.

skip_all($razon)
Establece el plan en 0 con una razón y luego sale verdadero. Esto debe usarse antes de que se ejecuten las pruebas.
done_testing
Se utiliza para marcar el final de las pruebas. Esta es una forma segura de tener un número dinámico o desconocido de pruebas.
bail_out($razon)
Se invoca cuando algo ha salido terriblemente mal: detiene todo, mata todos los hilos y procesos, termina el proceso con un estado de salida falso.

ASERCIONES

ok($bool)
ok($bool, $nombre)
ok($bool, $nombre, @diag)
Aserción simple. Si $bool es verdadero, la prueba pasa, y si es falso, la prueba falla. El nombre de la prueba es opcional, y todos los argumentos después del nombre se agregan como mensaje de diagnóstico si y solo si la prueba falla. Si la prueba pasa, todos los argumentos de diagnóstico serán ignorados.
pass()
pass($nombre)
Dispara una prueba que pasa (un único evento Ok). El nombre es opcional
fail()
fail($nombre)
fail($nombre, @diag)
Dispara una prueba que falla (un único evento Ok). El nombre y los diagnósticos son opcionales.

DIAGNÓSTICOS

diag(@mensajes)
Escribe mensajes de diagnóstico. Todos los elementos en @mensajes se unirán en una sola cadena sin separador. Cuando se usa TAP, los diagnósticos se envían a STDERR.

Devuelve falso, para preservar el fallo.

note(@mensajes)
Escribe mensajes de nota de diagnóstico. Todos los elementos en @mensajes se unirán en una sola cadena sin separador. Cuando se usa TAP, las notas se envían a STDOUT.

METADATO

$todo = todo($razon)
todo $razon => sub { ... }
Se utiliza para marcar algunos resultados como TODO. TODO significa que la prueba puede fallar, pero no hará que falle el conjunto de pruebas general.

Hay dos formas de usar esto. La primera es usar un bloque de código, y el TODO solo se aplicará al bloque de código.

ok(1, "antes"); # No es TODO
todo 'esto fallará' => sub {
    # Esto es TODO, al igual que cualquier otra prueba en este bloque.
    ok(0, "blah");
};
ok(1, "después"); # No es TODO

La otra forma es usar una variable con ámbito. El TODO terminará cuando la variable sea destruida o establecida a undef.

ok(1, "antes"); # No es TODO
{
    my $todo = todo 'esto fallará';
    # Esto es TODO, al igual que cualquier otra prueba en este bloque.
    ok(0, "blah");
};
ok(1, "después"); # No es TODO

Esto es lo mismo, pero sin el ámbito "{...}".

ok(1, "antes"); # No es TODO
my $todo = todo 'esto fallará';
ok(0, "blah"); # TODO
$todo = undef;
ok(1, "después"); # No es TODO
skip($por_que)
skip($por_que, $cantidad)
Se utiliza para saltar algunas pruebas. Esto requiere que envuelvas tus pruebas en un bloque etiquetado como "SKIP:". Esto es algo mágico. Si no se especifica $cantidad, emitirá un solo resultado. Si especificas $cantidad, emitirá esa cantidad de resultados. 
SKIP: {
    skip "Esto borrará tu disco";
    # Esto nunca se ejecuta:
    ok(!system('sudo rm -rf /'), "Borrar disco");
}
