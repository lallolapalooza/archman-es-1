Test2::Compare::Bag(3perl) Guía del programador de Perl Test2::Compare::Bag(3perl)

NOMBRE

Test2::Compare::Bag - Representación interna de una bolsa para comparación.

DESCRIPCIÓN

Este módulo es una representación interna de una bolsa con fines de comparación.

MÉTODOS

$bool = $arr->ending
$arr->set_ending($bool)
Establece esto en verdadero si deseas fallar cuando el array que se está validando tenga más elementos que la verificación. Es decir, si verificas 4 elementos pero el array tiene 5 valores, fallará y listará ese elemento no coincidente en el array como inesperado. Si se establece en falso, se asume que no te importan los elementos extra.
$arrayref = $arr->items()
Devuelve la referencia al array de valores a verificar en el array.
$arr->set_items($arrayref)
Acepta una referencia a un array.

Nota: no hay validación al usar "set_items", es mejor usar la interfaz "add_item".

$name = $arr->name()
Siempre devuelve la cadena "<BAG>".
$bool = $arr->verify(got => $got, exists => $bool)
Comprueba si $got es una referencia a un array o no.
$arr->add_item($item)
Agrega un elemento a la lista de valores a verificar.
@deltas = $arr->deltas(got => $got, convert => \&convert, seen => \%seen)
Encuentra las diferencias entre los valores esperados de la bolsa y los de la referencia al array $got.
