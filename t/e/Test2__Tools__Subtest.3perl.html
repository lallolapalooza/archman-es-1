NOMBRE

Test2::Tools::Subtest - Herramientas para escribir subpruebas

DESCRIPCIÓN

Este paquete exporta subrutinas que te permiten escribir subpruebas.

Hay dos tipos de subpruebas: con búfer y en flujo. Las subpruebas en flujo imitan las subpruebas de Test::More en el sentido de que renderizan todos los eventos tan pronto como se producen. Las subpruebas con búfer esperan hasta que la subprueba se completa antes de renderizar cualquier resultado.

La principal diferencia es que las subpruebas en flujo son ilegibles cuando se combinan con concurrencia. Las subpruebas con búfer se ven bien con cualquier número de hilos y procesos concurrentes.

SINOPSIS

CON BÚFER

use Test2::Tools::Subtest qw/subtest_buffered/;
subtest_buffered my_test => sub {
    ok(1, "evento de subprueba A");
    ok(1, "evento de subprueba B");
};

Esto producirá una salida como esta:

ok 1 - my_test {
    ok 1 - evento de subprueba A
    ok 2 - evento de subprueba B
    1..2
}

EN FLUJO

La opción predeterminada es 'con búfer'. Si deseas subpruebas en flujo, la forma en que lo hace Test::Builder, usa esto:

use Test2::Tools::Subtest qw/subtest_streamed/;
subtest_streamed my_test => sub {
    ok(1, "evento de subprueba A");
    ok(1, "evento de subprueba B");
};

Esto producirá una salida como esta:

# Subtest: my_test
    ok 1 - evento de subprueba A
    ok 2 - evento de subprueba B
    1..2
ok 1 - Subtest: my_test

NOTA IMPORTANTE

Puedes usar "bail_out" o "skip_all" en una subprueba, pero no en un bloque BEGIN o una declaración "use". Esto se debe a la forma en que funciona el control de flujo dentro de un bloque BEGIN. Esto normalmente no es un problema, pero puede ocurrir en raras condiciones usando eval, o archivos de script como subpruebas.

EXPORTACIONES

subtest_streamed $name => $sub
subtest_streamed($name, $sub, @args)
subtest_streamed $name => \%params, $sub
subtest_streamed($name, \%params, $sub, @args)
Ejecuta el coderef de la subprueba, emitiendo eventos a medida que ocurren.

"\%params" es un hashref con cualquier argumento que desees pasar a la construcción del hub.

subtest_buffered $name => $sub
subtest_buffered($name, $sub, @args)
subtest_buffered $name => \%params, $sub
subtest_buffered($name, \%params, $sub, @args)
Ejecuta el coderef de la subprueba, renderizando los eventos todos a la vez cuando la subprueba se completa.

"\%params" es un hashref con cualquier argumento que desees pasar a la construcción del hub.
