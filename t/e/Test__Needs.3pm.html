NOMBRE

Test::Needs - Omitir pruebas cuando los módulos no están disponibles

SINOPSIS

# se necesita un módulo
use Test::Needs 'Some::Module';
# se necesitan múltiples módulos
use Test::Needs 'Some::Module', 'Some::Other::Module';
# se necesita una versión dada de un módulo
use Test::Needs {
  'Some::Module' => '1.005',
};
# comprobar más tarde
use Test::Needs;
test_needs 'Some::Module';
# omite el resto de la subprueba
use Test::More;
use Test::Needs;
subtest 'mi subprueba' => sub {
  test_needs 'Some::Module';
  ...
};
# comprobar la versión de perl
use Test::Needs { perl => 5.020 };

DESCRIPCIÓN

Omitir scripts de prueba si los módulos no están disponibles. Los módulos solicitados se cargarán y, opcionalmente, se comprobarán sus versiones. Si el módulo falta, el script de prueba se omitirá. Los módulos que se encuentren pero que fallen al compilar saldrán con un error en lugar de omitirse.

Si se usa en una subprueba, el resto de la subprueba se omitirá.

La omisión funcionará incluso si ya se han ejecutado algunas pruebas o si se ha declarado un plan.

Las versiones se comprueban mediante una llamada a "$module->VERSION($wanted_version)". Las versiones deben proporcionarse en un formato que sea aceptado. No se realiza ningún procesamiento adicional sobre ellas.

Si se utiliza "perl" como módulo, la versión se comprueba con la versión de perl en ejecución ($]). La versión se puede especificar como un número, una cadena decimal punteada, una cadena v o un objeto de versión.

Si la variable de entorno "RELEASE_TESTING" está establecida, las pruebas fallarán en lugar de omitirse. Las subpruebas se abortarán, pero el script de prueba continuará ejecutándose después de ese punto.

EXPORTACIONES

test_needs

Tiene la misma interfaz que al usar Test::Needs en una "use".

VER TAMBIÉN

Test::Requires
Un módulo similar, con algunas diferencias importantes. Test::Requires actuará como una declaración de "use" (a pesar de su nombre), llamando a la subrutina de importación. Bajo "RELEASE_TESTING", fallará (BAIL_OUT) si un módulo no se carga en lugar de usar un fallo de prueba normal. Tampoco distingue entre módulos faltantes y módulos rotos.
Test2::Require::Module
Parte del ecosistema Test2. Solo admite la ejecución como un comando "use" para omitir un plan completo.
Test2::Require::Perl
Parte del ecosistema Test2. Solo admite la ejecución como un comando "use" para omitir un plan completo. Comprueba las versiones de perl.
Test::If
Actúa como una declaración de "use". Solo admite la ejecución como un comando "use" para omitir un plan completo. Puede omitir basándose en los resultados de subrutinas.
