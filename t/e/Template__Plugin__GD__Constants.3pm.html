NOMBRE

Template::Plugin::GD::Constants - Interfaz a las constantes del módulo GD

SINOPSIS

[% USE gdc = GD.Constants %]
# --> las constantes gdc.gdBrushed, gdc.gdSmallFont, gdc.GD_CMP_IMAGE
#     están ahora disponibles

EJEMPLOS

[% FILTER null;
    USE gdc = GD.Constants;
    USE im  = GD.Image(200,100);
    black = im.colorAllocate(0  ,0,  0);
    red   = im.colorAllocate(255,0,  0);
    r = im.string(gdc.gdLargeFont, 10, 10, "Texto Rojo Grande", red);
    im.png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Constants proporciona acceso a las diversas constantes del módulo GD (como gdBrushed, gdSmallFont, gdTransparent, GD_CMP_IMAGE, etc.). Cuando se usa GD.pm en perl, exporta varias constantes al espacio de nombres del llamador. Este plugin hace que esas constantes exportadas estén disponibles como variables de plantilla.

Ver Template::Plugin::GD::Image y GD para más ejemplos y detalles.
