Test__FailWarnings(3pm)

Paquete: perl-test-failwarnings

Licencias: PerlArtistic, GPL

Test::FailWarnings(3) Documentación Perl contribuida por el usuario Test::FailWarnings(3)

NOMBRE

Test::FailWarnings - Añade fallos de prueba si se detectan advertencias

VERSIÓN

versión 0.008

SINOPSIS

Archivo de prueba:

use strict;
use warnings;
use Test::More;
use Test::FailWarnings;
ok( 1, "primera prueba" );
ok( 1 + "lkadjaks", "añadir no numérico" );
done_testing;

Salida:

ok 1 - primera prueba
not ok 2 - Test::FailWarnings debería capturar no advertencias
#   Fallo de prueba 'Test::FailWarnings debería capturar no advertencias'
#   en t/bin/main-warn.pl línea 7.
# La advertencia fue 'El argumento "lkadjaks" no es numérico en la suma (+) en t/bin/main-warn.pl línea 7.'
ok 3 - añadir no numérico
1..3
# Parece que fallaste 1 prueba de 3.

DESCRIPCIÓN

Este módulo engancha $SIG{__WARN__} y convierte las advertencias en llamadas fail() de Test::More. Está diseñado para ser usado con "done_testing", cuando no necesitas conocer el recuento de pruebas con antelación.

Al igual que con Test::NoWarnings, esto no captura advertencias si otras cosas localizan $SIG{__WARN__}, ya que está diseñado para capturar advertencias *no manejadas*.

USO

Sobrescribiendo $SIG{__WARN__}

Al "importar", $SIG{__WARN__} se reemplaza con "Test::FailWarnings::handler".

use Test::FailWarnings;  # global

Si no deseas un reemplazo global, requiere el módulo en su lugar y localízalo en el ámbito que desees.

require Test::FailWarnings;
{
    local $SIG{__WARN__} = \&Test::FailWarnings::handler;
    # ... las advertencias emitirán fail() aquí
}

Cuando el manejador informe sobre el origen de la advertencia, buscará más allá de cualquier paquete que llame que comience con "Carp" o "warnings" para intentar detectar el origen real de la advertencia.

Permitiendo advertencias de dependencias

Si deseas ignorar fallos provenientes de fuera de tu propio código, puedes establecer $Test::FailWarnings::ALLOW_DEPS a un valor verdadero. Puedes hacerlo en la línea de "use" con "-allow_deps".

use Test::FailWarnings -allow_deps => 1;

Cuando es verdadero, solo se emitirán advertencias si parecen originarse de un nombre de archivo que coincida con "qr/^(?:t|xt|lib|blib)/"

Permitiendo advertencias de módulos específicos

Si deseas crear una lista blanca de módulos específicos, puedes añadir sus nombres de paquete a @Test::NoWarnings::ALLOW_FROM. Puedes hacerlo en la línea de "use" con "-allow_from".

use Test::FailWarnings -allow_from => [ qw/Annoying::Module/ ];

VER TAMBIÉN

  • Test::NoWarnings -- captura advertencias e informa en un bloque "END". No es compatible (aún) con "done_testing".
  • Test::Warnings -- un reemplazo para Test::NoWarnings que funciona con done_testing
  • Test::Warn -- prueba las advertencias sin desencadenar fallos de este módulo
