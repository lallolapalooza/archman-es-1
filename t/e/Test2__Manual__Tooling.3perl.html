Test2::Manual::Tooling(3perl) Guía de referencia para programadores de Perl Test2::Manual::Tooling(3perl)

NOMBRE

Test2::Manual::Tooling - Página del manual para autores de herramientas.

DESCRIPCIÓN

Esta sección cubre la escritura de nuevas herramientas, plugins y otros componentes de Test2.

TUTORIALES DE HERRAMIENTAS

PRIMERA HERRAMIENTA

Test2::Manual::Tooling::FirstTool - Introducción a la escritura de herramientas clonando ok().

MIGRACIÓN DESDE Test::Builder

Test2::Manual::Tooling::TestBuilder - Esta sección mapea métodos de Test::Builder a conceptos de Test2.

ANIDAMIENTO DE HERRAMIENTAS

Test2::Manual::Tooling::Nesting - Cómo llamar a otras herramientas desde tu herramienta.

HERRAMIENTAS CON SUBPRUEBAS

Test2::Manual::Tooling::Subtest - Cómo escribir herramientas que utilizan subpruebas.

PROBANDO TUS HERRAMIENTAS DE PRUEBA

Test2::Manual::Tooling::Testing - Cómo escribir pruebas para tus herramientas de prueba.

TUTORIALES DE PLUGINS

REALIZAR ACCIONES CUANDO COMIENZA UNA NUEVA HERRAMIENTA

Test2::Manual::Tooling::Plugin::ToolStarts - Cómo agregar comportamientos que ocurren cuando una herramienta comienza su trabajo.

REALIZAR ACCIONES DESPUÉS DE QUE UNA HERRAMIENTA HA TERMINADO

Test2::Manual::Tooling::Plugin::ToolCompletes - Cómo agregar comportamientos que ocurren cuando una herramienta completa su trabajo.

REALIZAR ACCIONES AL FINALIZAR LAS PRUEBAS

Test2::Manual::Tooling::Plugin::TestingDone - Cómo agregar comportamientos que ocurren cuando las pruebas han finalizado (es decir, done_testing, o fin de la prueba).

REALIZAR ACCIONES JUSTO ANTES DE SALIR

Test2::Manual::Tooling::Plugin::TestExit - Cómo agregar de forma segura comportamientos previos a la salida.

ESCRIBIENDO UN FORMATO JSONL SIMPLE

Test2::Manual::Tooling::Formatter - Cómo escribir un formato personalizado, en nuestro caso, un formato JSONL.

DÓNDE ENCONTRAR HOOKS Y APIS

API global
Test2::API es la API global. Se utiliza principalmente por plugins que proporcionan comportamiento global.
En hubs
Test2::Hub es la clase base para todos los hubs. Aquí es donde residen los hooks para manipular eventos o ejecutar cosas al finalizar las pruebas.
