Test::TypeTiny(3) Documentación de Perl aportada por el usuario Test::TypeTiny(3)

NOMBRE

Test::TypeTiny - funciones útiles para probar la eficacia de las restricciones de tipo

SINOPSIS

use strict;
use warnings;
use Test::More;
use Test::TypeTiny;

use Types::Mine qw(Integer Number);

should_pass(1, Integer);
should_pass(-1, Integer);
should_pass(0, Integer);
should_fail(2.5, Integer);

ok_subtype(Number, Integer);

done_testing;

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Test::TypeTiny proporciona algunas funciones útiles para probar restricciones de tipo.

Funciones

"should_pass($value, $type, $test_name)"
"should_pass($value, $type)"
Prueba que pasa si y solo si $value pasa "$type->check".
"should_fail($value, $type, $test_name)"
"should_fail($value, $type)"
Prueba que pasa si y solo si $value falla "$type->check".
"ok_subtype($type, @subtypes)"
Prueba que pasa si y solo si todas @subtypes son subtipos de $type.
"EXTENDED_TESTING"
Constante booleana exportable.
matchfor(@things)
Asistente para coincidir excepciones. No exportado por defecto. Ver también Test::Fatal::matchfor.

ENTORNO

Si la variable de entorno "EXTENDED_TESTING" está configurada a verdadero, este módulo promocionará cada prueba "should_pass" o "should_fail" a un bloque de subprueba y probará la restricción de tipo de manera en línea y no en línea.

Esta variable debe configurarse en tiempo de compilación (es decir, antes de que se cargue este módulo).

ERRORES

Por favor, informe de cualquier error en https://github.com/tobyink/p5-type-tiny/issues.

VER TAMBIÉN

Type::Tiny.

Para una alternativa a "should_pass", ver Test::Deep::Type que aceptará gustosamente una restricción de tipo Type::Tiny en lugar de una de MooseX::Types.
