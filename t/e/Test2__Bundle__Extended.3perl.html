Test2::Bundle::Extended(3perl) Guía de referencia para programadores de Perl Test2::Bundle::Extended(3perl)

NOMBRE

Test2::Bundle::Extended - Nombre antiguo para Test2::V0

*** OBSOLETO ***

Este paquete ha sido renombrado a Test2::V0, en el que la etiqueta :v1 ha sido eliminada por ser innecesaria.

DESCRIPCIÓN

Este es el paquete "big-daddy". Incluye casi todas las herramientas y varios plugins que utiliza el autor de Test2. Este paquete se utiliza extensamente para probar Test2::Suite.

SINOPSIS

use Test2::Bundle::Extended ':v1';
ok(1, "pasa");
...
done_testing;

RESOLVIENDO CONFLICTOS CON MOOSE

use Test2::Bundle::Extended '!meta';

Moose y Test2::Bundle::Extended exportan subrutinas meta() muy diferentes. Añadir '!meta' a los argumentos de importación evitará que la subrutina sea importada. Este paquete también exporta la subrutina con el nombre meta_check() para que puedas usar esta forma como alternativa.

ETIQUETAS

:v1
:DEFAULT
Los siguientes son todos idénticos: 
use Test2::Bundle::Extended;
use Test2::Bundle::Extended ':v1';
use Test2::Bundle::Extended ':DEFAULT';

RENOMBRANDO AL IMPORTAR

use Test2::Bundle::Extended ':v1', '!ok', ok => {-as => 'my_ok'};

Este paquete utiliza Importer para exportar, por lo que puedes usar cualquier argumento que este acepte.

Explicación:

:v1
Usa la etiqueta por defecto, todas las exportaciones por defecto.
'!ok'
No exporta ok()
ok => {-as => 'my_ok'}
De hecho, importa ok() pero bajo el nombre my_ok().

Si no hubieras añadido el argumento '!ok', tendrías tanto ok() como my_ok()

PRAGMAS

Todos estos se pueden deshabilitar mediante argumentos de importación individuales, o mediante el argumento "-no_pragmas".

use Test2::Bundle::Extended -no_pragmas => 1;

STRICT

El pragma strict está activado para ti. Puedes desactivarlo con los argumentos de importación "-no_strict" o "-no_pragmas":

use Test2::Bundle::Extended -no_strict => 1;

WARNINGS

El pragma warnings está activado para ti. Puedes desactivarlo con los argumentos de importación "-no_warnings" o "-no_pragmas":

use Test2::Bundle::Extended -no_warnings => 1;

UTF8

Esto se hace realmente a través del plugin Test2::Plugin::UTF8, consulta la sección "PLUGINS" para más detalles.

Nota: "-no_pragmas => 1" desactivará todo el plugin.

PLUGINS

SRAND

Ver Test2::Plugin::SRand.

Esto establecerá la semilla aleatoria en la fecha actual. Puedes proporcionar una semilla alternativa con la opción de importación "-srand":

use Test2::Bundle::Extended -srand => 1234;

UTF8

Ver Test2::Plugin::UTF8.

Esto establecerá el archivo y todos los manejadores de salida (incluidos los manejadores de formato) a utf8. Esto activará el pragma utf8 para el ámbito actual.

Esto se puede deshabilitar usando los argumentos de importación "-no_utf8 => 1" o "-no_pragmas => 1".

use Test2::Bundle::Extended -no_utf8 => 1;

RESUMEN DE SALIDA

Ver Test2::Plugin::ExitSummary.

Este plugin no tiene configuración.

HERRAMIENTAS

OBJETIVO

Ver Test2::Tools::Target.

Puedes especificar una clase objetivo con el argumento de importación "-target". Si no proporcionas un objetivo, entonces $CLASS y CLASS() no serán importados.

use Test2::Bundle::Extended -target => 'My::Class';
print $CLASS;  # My::Class
print CLASS(); # My::Class

O puedes especificar nombres:

use Test2::Bundle::Extended -target => { pkg => 'Some::Package' };
pkg()->xxx; # Llamar 'xxx' en Some::Package
$pkg->xxx;  # Lo mismo
$CLASS
Variable de paquete que contiene el nombre de la clase objetivo.
$class = CLASS()
Función constante que devuelve el nombre de la clase objetivo.

$check = prop($name => $expect)
$check = check($thing)
