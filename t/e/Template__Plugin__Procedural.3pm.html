NOMBRE

Template::Plugin::Procedural - Clase base para plugins procedurales

SINOPSIS

package Template::Plugin::LWPSimple;
use base qw(Template::Plugin::Procedural);
use LWP::Simple;  # exporta 'get'
1;
[% USE LWPSimple %]
[% LWPSimple.get("http://www.tt2.org/") %]

DESCRIPCIÓN

"Template::Plugin::Procedural" es una clase base para plugins de Template Toolkit que hace que las subrutinas definidas se llamen directamente en lugar de como un método. Esencialmente, esto significa que las subrutinas no recibirán el nombre de la clase o el objeto como su primer argumento.

Esto es muy útil al crear plugins para módulos que normalmente funcionan exportando subrutinas que no esperan argumentos adicionales.

A pesar de que las subrutinas no se llamarán de forma OO, la herencia sigue funcionando con normalidad. Una clase que utiliza "Template::Plugin::Procedural" puede ser subclaseada y tanto las subrutinas definidas en la subclase como las subrutinas definidas en la clase original estarán disponibles para el Template Toolkit y se llamarán sin el argumento de clase/objeto.
