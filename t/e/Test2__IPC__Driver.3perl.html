Test2::IPC::Driver(3perl) Guía de referencia para programadores de Perl Test2::IPC::Driver(3perl)

NOMBRE

Test2::IPC::Driver - Clase base para controladores IPC de Test2.

SINOPSIS

package Test2::IPC::Driver::MiDriver;
use base 'Test2::IPC::Driver';
...

MÉTODOS

$self->abortar($msg)
Si una IPC encuentra un error fatal, debería usar esto. Imprimirá el mensaje en STDERR con el prefijo 'IPC Fatal Error: ' y luego saldrá forzosamente con el código 255. Los errores de IPC pueden ocurrir en hilos o procesos distintos al principal, este método proporciona la mejor oportunidad para que el harness note el error.
$self->abortar_rastreo($msg)
Esto es lo mismo que "$ipc->abortar($msg)" excepto que utiliza "Carp::longmess" para agregar un rastreo de pila al mensaje.

CARGA DE CONTROLADORES

Test2::IPC::Driver tiene un método import(). Todos los controladores heredan este método de importación. Este método de importación registra el controlador.

En la mayoría de los casos, solo necesita cargar el controlador IPC deseado para que funcione. Debe cargar este controlador lo antes posible. Se emitirá una advertencia si lo carga demasiado tarde para que sea efectivo.

use Test2::IPC::Driver::MiDriver;
...

ESCRITURA DE CONTROLADORES

package Test2::IPC::Driver::MiDriver;
use strict;
use warnings;
use base 'Test2::IPC::Driver';
sub es_viable {
    return 0 if $^O eq 'win32'; # No funcionará en windows.
    return 1;
}
sub agregar_hub {
    my $self = shift;
    my ($hid) = @_;
    ... # Hacer posible contactar al hub
}
sub soltar_hub {
    my $self = shift;
    my ($hid) = @_;
    ... # Nada debería intentar contactar al hub anymore.
}
sub enviar {
    my $self = shift;
    my ($hid, $e, $global) = @_;
    ... # Enviar el evento al hub apropiado.
    # Esto puede notificar a otros procesos/hilos que hay un evento pendiente.
    Test2::API::test2_ipc_set_pending($uniq_val);
}
sub depurar {
    my $self = shift;
    my ($hid) = @_;
    my @eventos = ...; # Aquí es donde obtienes los eventos para el hub
    return @eventos;
}
sub esperando {
    my $self = shift;
    ... # Notificar a todos los procesos y hilos en espera que el proceso
    ... # principal/hilo está esperando que terminen.
}
1;

MÉTODOS QUE LAS SUBCLASES DEBEN IMPLEMENTAR

$ipc->es_viable
Debería devolver verdadero si el controlador funciona en el entorno actual. Debería devolver falso si no es así. Este es un método de CLASE.
$ipc->agregar_hub($hid)
Esto se usa para alertar al controlador de que un nuevo hub está esperando eventos. El controlador debe mantener un registro de los IDs de proceso e hilo, el hub solo debe ser liberado por el proceso+hilo que lo inició. 
sub agregar_hub {
    my $self = shift;
    my ($hid) = @_;
    ... # Hacer posible contactar al hub
}
$ipc->soltar_hub($hid)
Esto se usa para alertar al controlador de que un hub ya no acepta eventos. El controlador debe mantener un registro de los IDs de proceso e hilo, el hub solo debe ser liberado por el proceso+hilo que lo inició (la responsabilidad de hacer cumplir esto recae en el controlador). 
sub soltar_hub {
    my $self = shift;
    my ($hid) = @_;
    ... # Nada debería intentar contactar al hub anymore.
}
$ipc->enviar($hid, $evento);
$ipc->enviar($hid, $evento, $global);
Se utiliza para enviar eventos desde el proceso/hilo actual al hub especificado en su proceso+hilo. 
sub enviar {
    my $self = shift;
    my ($hid, $e) = @_;
    ... # Enviar el evento al hub apropiado.
    # Esto puede notificar a otros procesos/hilos que hay un evento pendiente.
    Test2::API::test2_ipc_set_pending($uniq_val);
}

Si $global es verdadero, el controlador debería enviar el evento a todos los hubs en todos los procesos e hilos.

@eventos = $ipc->depurar($hid)
Se utiliza para recopilar los eventos que se han enviado al hub especificado. 
sub depurar {
    my $self = shift;
    my ($hid) = @_;
    my @eventos = ...; # Aquí es donde obtienes los eventos para el hub
    return @eventos;
}
$ipc->esperando()
Esto se llama en el proceso padre cuando ha terminado y está esperando que todos los procesos e hilos hijos completen. 
sub esperando {
    my $self = shift;
    ... # Notificar a todos los procesos y hilos en espera que el proceso
    ... # principal/hilo está esperando que terminen.
}

MÉTODOS QUE LAS SUBCLASES PUEDEN IMPLEMENTAR O SOBREESCRIBIR

$ipc->controlador_abortar($msg)
Este es un hook llamado por "Test2::IPC::Driver->abortar()". Esta es tu oportunidad de limpiar cuando ocurre un aborto. No puedes prevenir el aborto, pero puedes aceptarlo de manera elegante.
