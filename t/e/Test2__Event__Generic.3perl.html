Test2::Event::Generic(3perl) Guía del programador de Perl Test2::Event::Generic(3perl)

NOMBRE

Test2::Event::Generic - Tipo de evento genérico.

DESCRIPCIÓN

Este es un evento genérico que te permite personalizar todos los campos de la API de eventos. Esto es útil si necesitas un evento personalizado que no tenga sentido como una subclase de evento reutilizable publicada.

SINOPSIS

use Test2::API qw/context/;
sub send_custom_fail {
    my $ctx = shift;
    $ctx->send_event('Generic', causes_fail => 1, summary => 'El cielo se está cayendo');
    $ctx->release;
}
send_custom_fail();

MÉTODOS

$e->facet_data($data)
$data = $e->facet_data
Obtiene o establece los datos de facetas (ver Test2::Event). Si no se establecen datos de facetas, se llamará a "Test2::Event->facet_data" para producir facetas a partir de los demás datos.
$e->callback($hub)
Llama al callback personalizado si está establecido, de lo contrario, no hace nada.
$e->set_callback(sub { ... })
Establece el callback personalizado. El callback personalizado debe ser un coderef. El primer argument para tu callback será el evento mismo, el segundo será el Test2::Event::Hub que está utilizando el callback.
$bool = $e->causes_fail
$e->set_causes_fail($bool)
Obtiene/establece el atributo "causes_fail". Esto tiene un valor predeterminado de 0.
$bool = $e->diagnostics
$e->set_diagnostics($bool)
Obtiene/establece el atributo "diagnostics". Esto tiene un valor predeterminado de 0.
$bool_or_undef = $e->global
@bool_or_empty = $e->global
$e->set_global($bool_or_undef)
Obtiene/establece el atributo "diagnostics". Esto tiene un valor predeterminado de una lista vacía que es undef en contexto escalar. Esto no está soportado.
$bool = $e->increments_count
$e->set_increments_count($bool)
Obtiene/establece el atributo "increments_count". Esto tiene un valor predeterminado de 0.
$bool = $e->no_display
$e->set_no_display($bool)
Obtiene/establece el atributo "no_display". Esto tiene un valor predeterminado de 0.
@plan = $e->sets_plan
Obtiene el plan si este evento establece uno. El plan es una lista de hasta 3 elementos: "($count, $directive, $reason)". $count debe ser definido, los otros pueden ser undef, o no existir en absoluto.
$e->set_sets_plan(\@plan)
Establece el plan. Debes pasar un arrayref con hasta 3 elementos.
$summary = $e->summary
$e->set_summary($summary_or_undef)
Obtiene/establece el resumen. Esto tendrá por defecto el paquete del evento 'Test2::Event::Generic'. Puedes establecerlo a cualquier valor. Establecer esto a "undef" lo reiniciará a su valor predeterminado.
$int_or_undef = $e->terminate
@int_or_empty = $e->terminate
$e->set_terminate($int_or_undef)
Esto obtendrá/establecerá el atributo "terminate". Esto tiene un valor predeterminado de undef en contexto escalar, o una lista vacía en contexto de lista. Establecer esto a undef lo borrará completamente. Esto debe ser establecido a un entero positivo (0 o mayor).
