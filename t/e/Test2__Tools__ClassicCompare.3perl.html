NOMBRE

Test2::Tools::ClassicCompare - Herramientas de comparación clásicas (estilo Test::More).

DESCRIPCIÓN

Esto proporciona funciones de comparación que se comportan como lo hacían en Test::More, a diferencia del plugin Test2::Tools::Compare que las ha modificado.

SINOPSIS

use Test2::Tools::ClassicCompare qw/is is_deeply isnt like unlike cmp_ok/;
is($got, $expect, "Estos son iguales cuando se convierten a cadena");
isnt($got, $unexpected, "Estos no son iguales cuando se convierten a cadena");
like($got, qr/.../, "'got' coincide con el patrón");
unlike($got, qr/.../, "'got' no coincide con el patrón");
is_deeply($got, $expect, "Estas estructuras son iguales cuando se comprueban profundamente");
cmp_ok($GOT, $OP, $WANT, 'Compara estos elementos usando el operador especificado');

EXPORTACIONES

$bool = is($got, $expect)
$bool = is($got, $expect, $name)
$bool = is($got, $expect, $name, @diag)
Esto realiza una comparación de cadenas de los dos argumentos. Si los dos argumentos son iguales después de la conversión a cadena, la prueba pasa. La prueba también pasará si ambos argumentos son undef.

El nombre de la prueba $name es opcional.

Las @diag de la prueba son opcionales, son mensajes de diagnóstico adicionales que se mostrarán si la prueba falla. Los diagnósticos se ignoran si la prueba pasa.

Es importante tener en cuenta que esta herramienta considera que "1" y "1.0" no son iguales, ya que utiliza una comparación de cadenas.

Consulta Test2::Tools::Compare si deseas una función is() que intente ser más inteligente por ti.

$bool = isnt($got, $dont_expect)
$bool = isnt($got, $dont_expect, $name)
$bool = isnt($got, $dont_expect, $name, @diag)
Esta es la inversa de is(), pasa cuando las cadenas no son iguales.
$bool = like($got, $pattern)
$bool = like($got, $pattern, $name)
$bool = like($got, $pattern, $name, @diag)
Comprueba si $got coincide con el patrón especificado. Fallará si no coincide.

El nombre de la prueba $name es opcional.

Las @diag de la prueba son opcionales. Contienen mensajes de diagnóstico adicionales que se mostrarán si la prueba falla. Los diagnósticos se ignoran si la prueba pasa.

$bool = unlike($got, $pattern)
$bool = unlike($got, $pattern, $name)
$bool = unlike($got, $pattern, $name, @diag)
Esta es la inversa de like(). Fallará si $got coincide con $pattern.
$bool = is_deeply($got, $expect)
$bool = is_deeply($got, $expect, $name)
$bool = is_deeply($got, $expect, $name, @diag)
Esto realiza una comprobación profunda, comparando las estructuras en $got con las de $expect. Se recursará en hashrefs, arrayrefs y scalar refs. Todos los demás valores se convertirán a cadena y se compararán como cadenas. Es importante tener en cuenta que esta herramienta considera que "1" y "1.0" no son iguales, ya que utiliza una comparación de cadenas.

Esto es lo mismo que Test2::Tools::Compare::is().

cmp_ok($got, $op, $expect)
cmp_ok($got, $op, $expect, $name)
cmp_ok($got, $op, $expect, $name, @diag)
Compara $got con $expect usando el operador especificado en $op. Esto es efectivamente un "eval "\$got $op \$expect"" con algunas otras cosas para hacerlo más sensato. Esto es útil para comparar números, objetos sobrecargados, etc.

Nota sobre sobrecargas: La entrada se pasa tal cual a la comparación. Si la comparación falla entre dos objetos sobrecargados, los diagnósticos intentarán mostrarte la forma de sobrecarga que se utilizó en las comparaciones. Es posible que los diagnósticos sean incorrectos, aunque se han hecho intentos para mejorarlos desde Test::More.

Excepciones: Si la comparación resulta en una excepción, la prueba fallará y se mostrará la excepción.

cmp_ok() tiene una lista interna de operadores que soporta. Si proporcionas un operador no soportado, emitirá una advertencia. Puedes añadir operadores al hash %Test2::Tools::ClassicCompare::OPS, la clave debe ser el operador y el valor debe ser 'str' para operadores de comparación de cadenas, 'num' para operadores numéricos, o cualquier otro valor verdadero para otros operadores.

Operadores soportados:

== (num)
!= (num)
>= (num)
<= (num)
> (num)
< (num)
<=> (num)
eq (str)
ne (str)
gt (str)
lt (str)
ge (str)
le (str)
cmp (str)
!~ (str)
=~ (str)
&&
||
xor
or
and
//
&
|
~~
