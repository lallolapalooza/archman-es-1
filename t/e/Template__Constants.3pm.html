NOMBRE

Template::Constants - Define constantes para el Template Toolkit

SINOPSIS

use Template::Constants qw( :status :error :all );

DESCRIPCIÓN

El módulo "Template::Constants" define, y opcionalmente exporta al espacio de nombres del llamante, una serie de constantes utilizadas por el paquete Template.

Las constantes pueden usarse especificando explícitamente el paquete "Template::Constants":

use Template::Constants;
print Template::Constants::STATUS_DECLINED;

Las constantes pueden importarse al espacio de nombres del llamante nombrándolas como opciones en la declaración "use Template::Constants":

use Template::Constants qw( STATUS_DECLINED );
print STATUS_DECLINED;

Alternativamente, se puede especificar uno de los siguientes identificadores de conjuntos de etiquetas para importar conjuntos de constantes: '":status"', '":error"', '":all"'.

use Template::Constants qw( :status );
print STATUS_DECLINED;

Consulte la documentación del módulo "Exporter" para obtener más información sobre la exportación de variables.

CONJUNTOS DE ETIQUETAS EXPORTABLES

Se definen los siguientes conjuntos de etiquetas y constantes asociadas:

:status
    STATUS_OK             # ningún problema, continuar
    STATUS_RETURN         # finalizó el bloque actual y continuó (ok)
    STATUS_STOP           # parada controlada (ok)
    STATUS_DONE           # el iterador ha terminado (ok)
    STATUS_DECLINED       # el proveedor se negó a atender la solicitud (ok)
    STATUS_ERROR          # condición de error general (no ok)
:error
    ERROR_RETURN          # devuelve un código de estado (p. ej., 'stop')
    ERROR_FILE            # error de archivo: E/S, análisis, recursión
    ERROR_UNDEF           # se usó un valor de variable indefinido
    ERROR_PERL            # error en el bloque [% PERL %]
    ERROR_FILTER          # error de filtro
    ERROR_PLUGIN          # error de plugin
:chomp                  # para PRE_CHOMP y POST_CHOMP
    CHOMP_NONE            # no eliminar espacios en blanco
    CHOMP_ONE             # eliminar espacios en blanco hasta la nueva línea
    CHOMP_ALL             # nombre antiguo para CHOMP_ONE (obsoleto)
    CHOMP_COLLAPSE        # colapsar espacios en blanco a un solo espacio
    CHOMP_GREEDY          # eliminar todos los espacios en blanco, incluidas las nuevas líneas
:debug
    DEBUG_OFF             # no hacer nada
    DEBUG_ON              # indicador de depuración básico
    DEBUG_UNDEF           # lanzar undef en variables indefinidas
    DEBUG_VARS            # depuración general de variables
    DEBUG_DIRS            # depuración de directivas
    DEBUG_STASH           # depuración general de stash
    DEBUG_CONTEXT         # depuración de contexto
    DEBUG_PARSER          # depuración del analizador
    DEBUG_PROVIDER        # depuración del proveedor
    DEBUG_PLUGINS         # depuración de plugins
    DEBUG_FILTERS         # depuración de filtros
    DEBUG_SERVICE         # depuración de contexto
    DEBUG_ALL             # todo
    DEBUG_CALLER          # añadir información de archivo/línea del llamante
    DEBUG_FLAGS           # mapa de bits utilizado internamente
:all
    Todas las constantes anteriores.
