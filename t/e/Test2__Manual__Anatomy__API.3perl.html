Test2::Manual::Anatomy::API(3perl) Guía de referencia del programador de Perl Test2::Manual::Anatomy::API(3perl)

NOMBRE

Test2::Manual::Anatomy::API - Documentación interna de la API.

DESCRIPCIÓN

Este documento cubre algunos de los detalles internos de Test2::API.

DETALLES DE IMPLEMENTACIÓN

Test2::API

Test2::API proporciona una interfaz funcional a cualquier estado global de test2. Esta API debe preservarse independientemente de los detalles internos de cómo y dónde se almacena el estado global.

Este módulo en sí mismo no almacena ningún estado (con algunas excepciones menores), sino que depende de Test2::API::Instance para almacenar el estado. Este módulo está realmente destinado a ser la capa entre el consumidor y los detalles de implementación. Idealmente, los detalles de implementación pueden cambiar de cualquier manera que deseen, y este módulo puede actualizarse para utilizar los nuevos detalles sin romper nada.

Test2::API::Instance

Test2::API::Instance es donde se gestiona realmente el estado global. Esto es un detalle de implementación y no debe confiarse en él. Es completamente posible que Test2::API::Instance se elimine por completo o se cambie de formas incompatibles. Realmente, estos detalles son libres de cambiar siempre que Test2::API no se rompa.

Test2::API::Instance está bastante bien documentado, por lo que no se necesita documentación adicional para esta página de manual.
