Test::Base::Filter(3) Documentación de Perl aportada por la comunidad Test::Base::Filter(3)

NOMBRE

Test::Base::Filter - Clase por defecto para filtrar Test::Base

SINOPSIS

package MyTestSuite;
use Test::Base -Base;
... código reutilizable de prueba ...
package MyTestSuite::Filter;
use Test::Base::Filter -Base;
sub my_filter1 {
    ...
}

DESCRIPCIÓN

Los filtros son clave para escribir pruebas basadas en datos con Test::Base. Test::Base::Filter es una clase que contiene un gran conjunto de filtros genéricos por defecto. Puedes heredar fácilmente de ella para agregar/sobrescribir funcionalidad.

FILTROS

Esta es una lista de los filtros por defecto (en orden alfabético):

"append"
list => list

Añade una cadena a cada elemento de una lista.

--- numbers lines chomp append=-#\n join
one
two
three
"array"
list => scalar

Crea una referencia a una lista anónima a partir de una lista de valores.

"base64_decode"
scalar => scalar

Decodifica datos en base64. Se usa para pruebas binarias.

"base64_encode"
scalar => scalar

Codifica datos en base64. Se usa para pruebas binarias.

"chomp"
list => list

Elimina el salto de línea final de cada valor de cadena en una lista.

"chop"

list => list

Elimina el último carácter de cada valor de cadena en una lista.
"dumper"
scalar => list

Toma un dato estructurado (presumiblemente de otro filtro como eval) y usa Data::Dumper para mostrarlo en un formato canónico.

"escape"
scalar => scalar

Elimina el escape de todos los caracteres escapados con barra invertida.

"eval"
scalar => list

Ejecuta el comando "eval" de Perl sobre los datos y usa el valor devuelto como los datos.

"eval_all"
scalar => list

Ejecuta el comando "eval" de Perl sobre los datos y devuelve una lista de 4 valores:

1) El valor devuelto
2) El error en $@
3) STDOUT capturado
4) STDERR capturado
"eval_stderr"
scalar => scalar

Ejecuta el comando "eval" de Perl sobre los datos y devuelve el STDERR capturado.

"eval_stdout"
scalar => scalar

Ejecuta el comando "eval" de Perl sobre los datos y devuelve el STDOUT capturado.

"exec_perl_stdout"
list => scalar

El código Perl se escribe en un archivo temporal y se ejecuta. Se captura STDOUT y se devuelve.

"flatten"
scalar => list

Toma un hash o una referencia a lista y la aplana en una lista.

"get_url"
scalar => scalar

Se elimina el salto de línea del texto y se considera una URL. Luego se usa LWP::Simple::get para obtener el contenido de la URL.

"hash"
list => scalar

Toma una lista de pares clave-valor y la convierte en una referencia a un hash anónimo.

"head[=numero]"
list => list

Toma una lista y devuelve un número de elementos desde el principio de la misma. El número por defecto es uno.

"join"
list => scalar

Une una lista de cadenas en un solo escalar.

"Join"
Une las cadenas de referencias a array en una lista y devuelve las cadenas en lugar de las referencias a array.
"lines"
scalar => list

Divide los datos en una lista de líneas. Cada línea (excepto la última si el filtro "chomp" está primero) tendrá un salto de línea al final.

"norm"
scalar => scalar

Normaliza los datos. Cambia los saltos de línea no Unix a saltos de línea Unix.

"prepend=cadena"
list => list

Prepara una cadena al principio de cada valor de cadena en una lista.

"read_file"
scalar => scalar

Lee el contenido del archivo nombrado por el contenido actual y devuelve el contenido del archivo.

"regexp[=xism]"
scalar => scalar

El filtro "regexp" convierte el bloque de datos en un objeto de expresión regular. Puedes pasar modificadores adicionales después de un igual.

Si el texto contiene más de una línea y no se especifican modificadores, se asumen los modificadores 'xism'.

"reverse"
list => list

Invierte los elementos de una lista.

"Reverse"
list => list

Invierte la lista de cadenas dentro de una lista de referencias a array.

"slice=x[,y]"
list => list

Devuelve el elemento número x hasta el elemento número y de una lista.

"sort"
list => list

Ordena los elementos de una lista en orden de comparación característico.

"Sort"
list => list

Ordena la lista de cadenas dentro de una lista de referencias a array.

"split[=cadena|patrón]"
scalar => list

Divide una cadena en una lista. Recibe un parámetro opcional de cadena o regexp. El valor por defecto es "s+". Lo mismo que el comando "split" de Perl.

"Split[=cadena|patrón]"
list => list

Divide cada cadena de una lista y las convierte en referencias a array.

"strict"
scalar => scalar

Añade al texto:

use strict;
use warnings;

al texto del bloque.

"tail[=numero]"
list => list

Devuelve un número de elementos desde el final de una lista. El número por defecto es uno.

"trim"
list => list

Elimina líneas en blanco extra del principio y el final de los datos. Esto permite separar visualmente tus datos de prueba con líneas en blanco.

"unchomp"
list => list

Añade un salto de línea a cada valor de cadena en una lista.

"write_file[=nombre_archivo]"
scalar => scalar

Escribe el contenido del bloque en el archivo nombrado. Devuelve el nombre del archivo.

"yaml"
scalar => list

Aplica la función YAML::Load al bloque de datos y usa la estructura resultante. Requiere YAML.pm.
