NOMBRE

Template::Plugin::View - Plugin para crear vistas (Template::View)

SINOPSIS

[% USE view(
        prefix = 'splash/'          # prefijo/sufijo de plantilla
        suffix = '.tt2'
        bgcol  = '#ffffff'          # y cualquier otra variable que
        style  = 'Fancy HTML'       # desees definir como metadatos de vista,
        items  = [ foo, bar.baz ]   # incluyendo datos complejos y
        foo    = bar ? baz : x.y.z  # expresiones
%]
[% view.title %]                    # acceder a metadatos de vista
[% view.header(title = 'Foo!') %]   # "métodos" de vista procesan bloques o
[% view.footer %]                   # plantillas con prefijo/sufijo añadido

DESCRIPCIÓN

Este módulo de plugin crea objetos Template::View. Las vistas son una característica experimental y están sujetas a cambios en el futuro cercano. Mientras tanto, consulta Template::View para obtener más información.
