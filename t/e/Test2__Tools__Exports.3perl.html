Test2::Tools::Exports(3perl) Guía de referencia para programadores de Perl Test2::Tools::Exports(3perl)

NOMBRE

Test2::Tools::Exports - Herramientas para validar exportadores.

DESCRIPCIÓN

Estas son herramientas para comprobar que los símbolos se han importado en tu espacio de nombres.

SINOPSIS

use Test2::Tools::Exports
use Data::Dumper;
imported_ok qw/Dumper/;
not_imported_ok qw/dumper/;

EXPORTACIONES

Todas las subrutinas se exportan por defecto.

imported_ok(@SIMBOLOS)
Comprueba que los símbolos especificados existen en el paquete actual. Esto no encontrará subrutinas heredadas. Solo encontrará símbolos en la tabla de símbolos del paquete actual. Esto **NO** confirmará que los símbolos se definieron fuera del paquete mismo. 
imported_ok( '$escalar', '@array', '%hash', '&sub', 'also_a_sub' );

@SIMBOLOS puede contener cualquier número de símbolos. Cada elemento del array debe ser una cadena. La cadena debe ser el nombre de un símbolo. Si hay un sigilo presente, buscará ese tipo específico; si no hay sigilo, se usará como nombre de subrutina.

not_imported_ok(@SIMBOLOS)
Comprueba que los símbolos especificados no existen en el paquete actual. Esto no encontrará subrutinas heredadas. Solo buscará símbolos en la tabla de símbolos del paquete actual. 
not_imported_ok( '$escalar', '@array', '%hash', '&sub', 'also_a_sub' );

@SIMBOLOS puede contener cualquier número de símbolos. Cada elemento del array debe ser una cadena. La cadena debe ser el nombre de un símbolo. Si hay un sigilo presente, buscará ese tipo específico. Si no hay sigilo, se usará como nombre de subrutina.

ADVERTENCIAS

Antes de Perl 5.10, es muy difícil distinguir entre un escalar de paquete no declarado y uno declarado e indefinido. Actualmente "imported_ok" y "not_imported_ok" no pueden ver escalares de paquete declarados usando "our $var" a menos que la variable haya sido asignada un valor definido.

Esto pasará en perls recientes, pero fallará en perls anteriores a 5.10:

use Test2::Tools::Exports;
our $foo;
# Falla en perl anterior a 5.10
imported_ok(qw/$foo/);

Si $foo se importa de otro módulo, o se importa usando "use vars qw/$foo/;", entonces funcionará en todas las versiones de perl soportadas.

use Test2::Tools::Exports;
use vars qw/$foo/;
use Some::Module qw/$bar/;
# Siempre funciona
imported_ok(qw/$foo $bar/);
