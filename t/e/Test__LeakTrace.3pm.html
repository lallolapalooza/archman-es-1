NOMBRE

Test::LeakTrace - Rastrea fugas de memoria

VERSIÓN

Este documento describe la versión 0.17 de Test::LeakTrace.

SINOPSIS

use Test::LeakTrace;
# informe simple
leaktrace{
    # ...
};
# salida detallada
leaktrace{
    # ...
} -verbose;
# con callback
leaktrace{
    # ...
} sub {
    my($ref, $file, $line) = @_;
    warn "fuga $ref de $file línea\n";
};
my @refs = leaked_refs{
    # ...
};
my @info = leaked_info{
    # ...
};
my $count = leaked_count{
    # ...
};
# interfaz de prueba estándar
use Test::LeakTrace;
no_leaks_ok{
    # ...
} 'sin fugas de memoria';
leaks_cmp_ok{
    # ...
} '<', 10;

DESCRIPCIÓN

"Test::LeakTrace" proporciona varias funciones que rastrean fugas de memoria. Este módulo escanea las arenas, el sistema de asignación de memoria, por lo que puede detectar cualquier SV con fugas en bloques dados.

SV con fugas son SVs que no se liberan después del final de la ámbito en el que se crearon. Estos SVs incluyen variables globales y cachés internos. Por ejemplo, si llama a un método en un bloque de rastreo, perl puede preparar una caché para el método. Por lo tanto, para rastrear fugas reales, no_leaks_ok() y leaks_cmp_ok() ejecutan un bloque más de una vez.

INTERFAZ

Funciones exportadas

"leaked_info { BLOQUE }"

Ejecuta el BLOQUE y devuelve una lista de SVs con fugas y los lugares de donde provienen los SVs, es decir, "[$ref, $file, $line]".

"leaked_refs { BLOQUE }"

Ejecuta el BLOQUE y devuelve una lista de SVs con fugas.

"leaked_count { BLOQUE }"

Ejecuta el BLOQUE y devuelve el número de SVs con fugas.

"leaktrace { BLOQUE } ?(modo | \&callback)"

Ejecuta el BLOQUE e informa de los SVs con fugas a *STDERR.

Los modos definidos son:

-simple
Por defecto. Informa de la identidad del SV con fugas (tipo y dirección), nombre del archivo y número de línea.
-sv_dump
Además de -simple, volca el contenido del sv usando sv_dump(), que también implementa Devel::Peek::Dump().
-lines
Además de -simple, imprime las líneas de origen sospechosas.
-verbose
Tanto -sv_dump como -lines.

"no_leaks_ok { BLOQUE } ?descripción"

Prueba que el BLOQUE no tenga fugas de SVs. Esta es una función de prueba que utiliza "Test::Builder".

Tenga en cuenta que el BLOQUE se llama más de una vez. Esto se debe a que el BLOQUE puede preparar cachés que no son fugas de memoria.

"leaks_cmp_ok { BLOQUE } operador_comparacion, numero, ?descripcion"

Prueba que el BLOQUE tenga un número específico de SVs con fugas. Esta es una función de prueba que utiliza "Test::Builder".

Tenga en cuenta que el BLOQUE se llama más de una vez. Esto se debe a que el BLOQUE puede preparar cachés que no son fugas de memoria.

count_sv()

Cuenta todos los SVs en la arena.

Interfaz de script

Al igual que "Devel::LeakTrace", se proporciona "Test::LeakTrace::Script" para scripts completos.

Los argumentos de la directiva "use Test::LeakTrace::Script" son los mismos que los de leaktrace().

$ TEST_LEAKTRACE=-sv_dump perl -MTest::LeakTrace::Script script.pl
$ perl -MTest::LeakTrace::Script=-verbose script.pl
#!perl
# ...
use Test::LeakTrace::Script sub{
    my($ref, $file, $line) = @_;
    # ...
};
# ...

EJEMPLOS

Prueba de módulos

Aquí hay una plantilla de script de prueba que verifica las fugas de memoria.

#!perl -w
use strict;
use constant HAS_LEAKTRACE => eval{ require Test::LeakTrace };
use Test::More HAS_LEAKTRACE ? (tests => 1) : (skip_all => 'require Test::LeakTrace');
use Test::LeakTrace;
use Some::Module;
leaks_cmp_ok{
    my $o = Some::Module->new();
    $o->something();
    $o->something_else();
} '<', 1;

DEPENDENCIAS

Perl 5.8.1 o posterior, y un compilador C.

ADVERTENCIAS

"Test::LeakTrace" no funciona con "Devel::Cover" y módulos que instalan sus propias rutinas "runops", o el ejecutor de perl. Por lo tanto, si las funciones de prueba de este módulo detectan rutinas "runops" extrañas, no hacen nada y reportan como correcto.

    NOMBRE

    Test::LeakTrace - Rastrea fugas de memoria en pruebas de Perl

    SINopsis

    package MyTest;
use base qw(Test::Unit::TestCase);
use Test::LeakTrace;
sub test_leaks {
    my $self = shift;
    test_leaks_and_compare;
    # Código que esperas que tenga fugas
}
1;

    DESCRIPCIÓN

    Este módulo te ayuda a encontrar fugas de memoria en tus pruebas de Perl. Una fuga de memoria ocurre cuando un programa asigna memoria y luego no la libera cuando ya no es necesaria. Con el tiempo, esto puede llevar a un agotamiento de la memoria y a fallos del programa.

    Test::LeakTrace funciona ejecutando tu código de prueba en un entorno aislado y luego examinando la memoria asignada. Si detecta memoria que no se ha liberado, te alertará.

    MÉTODOS

    • test_leaks_and_compare: Ejecuta el código de prueba y compara la memoria asignada con una línea base conocida. Si hay diferencias significativas, se informa.

    • test_leaks: Ejecuta el código de prueba y solo informa sobre la memoria no liberada sin compararla con una línea base.

    OPCIONES

    • tolerance: Especifica la cantidad de memoria que se puede diferir entre ejecuciones sin considerarse una fuga.

    • verbose: Si se establece en verdadero, proporciona más detalles sobre la memoria asignada y liberada.

    EJEMPLO

    package MyTest;
use base qw(Test::Unit::TestCase);
use Test::LeakTrace;
sub test_leaky_function {
    my $self = shift;
    test_leaks_and_compare( tolerance => 1024 ); # Tolera hasta 1KB de diferencia
    my $data = create_large_data_structure();
    # Usar $data ...
    # Nota: $data no se libera explícitamente aquí, simulando una fuga
}
1;
