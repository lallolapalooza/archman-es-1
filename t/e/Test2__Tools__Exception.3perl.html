Test2::Tools::Exception(3perl) Guía del programador de Perl Test2::Tools::Exception(3perl)

NOMBRE

Test2::Tools::Exception - Herramientas de Test2 para comprobar excepciones

DESCRIPCIÓN

Esta es la implementación de Test2 de código utilizado para probar excepciones. Es similar a Test::Fatal, pero intencionalmente hace mucho menos.

SINOPSIS

use Test2::Tools::Exception qw/dies lives/;
like(
    dies { die 'xxx' },
    qr/xxx/,
    "Obtuve una excepción"
);
ok(lives { ... }, "no murió") or note($@);

EXPORTACIONES

Todas las subrutinas se exportan por defecto.

$e = dies { ... }
Esto atrapará cualquier excepción que lance el bloque de código. Si no se lanza ninguna excepción, la subrutina devolverá undef. Si se lanza una excepción, esta será devuelta. Esta función preserva $@, no se alterará de su valor antes de llamar a la subrutina.
$bool = lives { ... }
Esto atrapará cualquier excepción lanzada en el bloque de código. Devolverá verdadero cuando no haya ninguna excepción y falso cuando la haya. $@ se preserva de antes de llamar a la subrutina cuando no hay excepción. Cuando se atrapa una excepción, $@ contendrá la excepción para que puedas examinarla.
$bool = try_ok { ... }
$bool = try_ok { ... } "Descripción de la prueba"
Esto ejecutará el bloque de código atrapando cualquier excepción. Si no hay ninguna excepción, se emitirá un evento de éxito. Si la prueba falla, se emitirá un evento de fallo y la excepción se informará como diagnóstico.

Nota: Esta función no preserva $@ en caso de fallo; se establecerá con la excepción que lance el bloque de código, esto es intencionado para que puedas obtener la excepción si lo deseas.

DIFERENCIAS CON TEST::FATAL

Test::Fatal establece $Test::Builder::Level de tal manera que las pruebas fallidas dentro del bloque de excepción se informan en la línea donde se llama a exception(). No estoy de acuerdo con esto y creo que la línea real de la prueba fallida es más importante. En última instancia, aunque Test::Fatal no puede ser cambiado, la gente probablemente ya depende de ese comportamiento.
