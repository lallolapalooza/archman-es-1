NOMBRE

Test::Builder::Tester::Color - activar el color en Test::Builder::Tester

SINOPSIS

Al ejecutar un script de prueba
  perl -MTest::Builder::Tester::Color test.t

DESCRIPCIÓN

Importar este módulo hace que la subrutina color en Test::Builder::Tester se llame con un valor verdadero, activando el resaltado de color en la salida de depuración.

El único propósito de este módulo es habilitar el resaltado de color desde la línea de comandos.

AUTOR

Copyright Mark Fowler <mark@twoshortplanks.com> 2002.

Este programa es software libre; puedes redistribuirlo y/o modificarlo bajo los mismos términos que Perl.

ERRORES

Este módulo no tendrá ningún efecto a menos que Term::ANSIColor esté instalado.

VER TAMBIÉN

Test::Builder::Tester, Term::ANSIColor
