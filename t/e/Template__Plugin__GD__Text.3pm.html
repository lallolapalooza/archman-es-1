NOMBRE

Template::Plugin::GD::Text - Utilidades de texto para usar con GD

SINOPSIS

[% USE gd_text = GD.Text %]

EJEMPLOS

[%
    USE gd_c = GD.Constants;
    USE t = GD.Text;
    x = t.set_text('Some text');
    r = t.get('width', 'height', 'char_up', 'char_down');
    r.join(":"); "\n";     # returns 54:13:13:0.
-%]
[%
    USE gd_c = GD.Constants;
    USE t = GD.Text(text => 'FooBar Banana', font => gd_c.gdGiantFont);
    t.get('width'); "\n";  # returns 117.
-%]

DESCRIPCIÓN

El plugin GD.Text proporciona una interfaz al módulo GD::Text. Permite calcular atributos de cadenas como el ancho y la altura en píxeles.

Ver GD::Text para más detalles. Ver Template::Plugin::GD::Text::Align y Template::Plugin::GD::Text::Wrap para plugins que permiten renderizar texto alineado o con saltos de línea en imágenes GD.
