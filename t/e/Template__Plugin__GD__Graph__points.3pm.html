NOMBRE

Template::Plugin::GD::Graph::points - Crea gráficos de puntos con ejes y leyendas

SINOPSIS

[% USE g = GD.Graph.points(x_size, y_size); %]

EJEMPLOS

[% FILTER null; 
    data = [
        ["1ro","2do","3ro","4to","5to","6to","7mo", "8vo", "9no"],
        [    5,   12,   24,   33,   19,    8,    6,    15,    21],
        [    1,    2,    5,    6,    3,  1.5,    2,     3,     4],
    ];
    USE my_graph = GD.Graph.points();
    my_graph.set(
            x_label => 'Etiqueta X',
            y_label => 'Etiqueta Y',
            title => 'Un Gráfico de Puntos',
            y_max_value => 40,
            y_tick_number => 8,
            y_label_skip => 2,
            legend_placement => 'RC',
            long_ticks => 1,
            marker_size => 6, 
            markers => [ 1, 7, 5 ],

            transparent => 0,
    );  
    my_graph.set_legend('uno', 'dos');
    my_graph.plot(data).png | stdout(1);
   END; 
-%]

DESCRIPCIÓN

El plugin GD.Graph.points proporciona una interfaz a la clase GD::Graph::points definida por el módulo GD::Graph. Permite graficar uno o más conjuntos de datos (x,y) como puntos, además de ejes y leyendas.

Consulte GD::Graph para obtener más detalles.
