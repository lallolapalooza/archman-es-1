Test::RequiresInternet(3) Documentación de Perl contribuida por el usuario Test::RequiresInternet(3)

NOMBRE

Test::RequiresInternet - Prueba fácilmente la conectividad de red

VERSIÓN

versión 0.05

SINOPSIS

use Test::More;
use Test::RequiresInternet ('www.example.com' => 80, 'foobar.io' => 25);
# si llegas aquí, los sockets se conectaron exitosamente a los hosts/puertos anteriores
plan tests => 1;
ok(do_that_internet_thing());

VISIÓN GENERAL

Este módulo está destinado a probar fácilmente la conectividad de red antes de que las pruebas funcionales comiencen con recursos de Internet no locales. No requiere ningún módulo más allá de los proporcionados en el núcleo de Perl.

Si no se especifica un par host/puerto, el módulo usa por defecto "www.google.com" en el puerto 80.

Opcionalmente, puedes especificar el puerto por su nombre, como en "http" o "ldap". Si haces esto, el módulo de prueba intentará buscar el número de puerto usando "getservbyname".

Si especificas un host y un puerto, deben especificarse en **pares**. Es un error fatal omitir uno u otro.

Si la variable de entorno "NO_NETWORK_TESTING" está configurada, las pruebas se omitirán sin intentar ninguna conexión de socket.

Si los sockets no pueden conectarse a los hosts y puertos especificados, la excepción se captura, se informa y las pruebas se omiten.
