NOMBRE

Template::View - vista personalizada del contexto de procesamiento de plantillas

SINOPSIS

# definir una vista
[% VIEW view
        # algunos argumentos estándar
        prefix        => 'mi_',
        suffix        => '.tt2',
        notfound      => 'archivo_no_encontrado'
        ...
        # cualquier otro dato
        title         => 'Título de Mi Vista'
        other_item    => 'Datos Aleatorios de Joe'
        ...
%]
   # añadir nuevas definiciones de datos, a través de la autorreferencia 'mi'
   [% mi.autor = "$abw.nombre <$abw.email>" %]
   [% mi.copia   = "&copy; Copyright 2000 $mi.autor" %]
   # definir un bloque local
   [% BLOCK encabezado %]
   Este es el bloque de encabezado, título: [% título o mi.título %]
   [% END %]
[% END %]
# acceder a los elementos de datos para la vista
[% vista.título %]
[% vista.otro_item %]
# acceder a bloques directamente ('include_naked' opción, establecida por defecto)
[% vista.encabezado %]
[% vista.encabezado(título => 'Nuevo Título') %]
# las plantillas no locales tienen prefijo/sufijo adjuntos
[% vista.pie %]           # => [% INCLUDE mi_pie.tt2 %]
# forma más verbosa de acceso a bloques
[% vista.incluir( 'encabezado', título => 'El Título del Encabezado' ) %]
[% vista.incluir_encabezado( título => 'El Título del Encabezado' ) %]
# forma muy corta de lo anterior ('include_naked' opción, establecida por defecto)
[% vista.encabezado( título => 'El Título del Encabezado' ) %]
# las plantillas no locales tienen prefijo/sufijo adjuntos
[% vista.pie %]           # => [% INCLUDE mi_pie.tt2 %]
# fallback en la plantilla 'notfound' ('mi_archivo_no_encontrado.tt2')
# si la plantilla no se encuentra
[% vista.incluir('faltante') %]
[% vista.incluir_faltante %]
[% vista.faltante %]
# print() incluye una plantilla relevante para el tipo de argumento
[% vista.imprimir("algún texto") %]     # tipo=TEXTO, plantilla='texto'
[% BLOCK mi_texto.tt2 %]           # 'texto' con prefijo/sufijo
   Texto: [% item %]
[% END %]
# ahora imprimir() una referencia hash, mapeada a la plantilla 'hash'
[% vista.imprimir(hash_referencia_alguna) %]   # tipo=HASH, plantilla='hash'
[% BLOCK mi_hash.tt2 %]           # 'hash' con prefijo/sufijo
   claves del hash: [% item.claves.ordenar.unir(', ')
[% END %]
# ahora imprimir() una referencia de lista, mapeada a la plantilla 'lista'
[% vista.imprimir(mi_lista_referencia) %]     # tipo=ARRAY, plantilla='lista'
[% BLOCK mi_lista.tt2 %]           # 'lista' con prefijo/sufijo
   lista: [% item.unir(', ') %]
[% END %]
# print() mapea 'Mi::Objeto' a 'Mi_Objeto'
[% vista.imprimir(mi_obj) %]
[% BLOCK mi_Mi_Objeto.tt2 %]
   [% item.esto %], [% item.aquello %]
[% END %]
# actualizar tabla de mapeo
[% vista.mapa.ARRAY = 'mi_plantilla_lista' %]
[% vista.mapa.TEXTO  = 'mi_bloque_texto'    %]
# cambiar prefijo, sufijo, nombre del elemento, etc.
[% vista.prefijo = 'tu_' %]
[% vista.por_defecto = 'cualquier_obj' %]
...

MÉTODOS

new($context, \%config)

Crea una nueva Template::View que presenta una vista personalizada del objeto $context especificado.

Se puede pasar una referencia a un array de hashes de opciones de configuración como segundo argumento.

prefijo
Prefijo añadido a todos los nombres de plantillas. 
[% USE vista(prefijo => 'mi_') %]
[% vista.vista('foo', a => 20) %]     # => mi_foo
sufijo
Sufijo añadido a todos los nombres de plantillas. 
[% USE vista(sufijo => '.tt2') %]
[% vista.vista('foo', a => 20) %]     # => foo.tt2
mapa
Array de hashes que mapea tipos de referencia a nombres de plantillas. El método print() utiliza esto para determinar qué plantilla usar para presentar cualquier elemento. Los elementos TEXT, HASH y ARRAY por defecto son 'texto', 'hash' y 'lista' respectivamente. 
[% USE vista(mapa => { ARRAY   => 'mi_lista',
                     HASH    => 'tu_hash',
                     Mi::Foo => 'mi_foo', } ) %]
[% vista.imprimir(texto_alguno) %]         # => texto
[% vista.imprimir(una_lista) %]            # => mi_lista
[% vista.imprimir(un_hash) %]            # => tu_hash
[% vista.imprimir(un_foo) %]             # => mi_foo
[% BLOCK texto %]
   Texto: [% item %]
[% END %]
[% BLOCK mi_lista %]
   lista: [% item.unir(', ') %]
[% END %]
[% BLOCK tu_hash %]
   claves del hash: [% item.claves.ordenar.unir(', ')
[% END %]
[% BLOCK mi_foo %]
   Foo: [% item.esto %], [% item.aquello %]
[% END %]
método
Nombre de un método que los objetos pasados a print() pueden proporcionar para presentarse a la vista. Si no se encuentra una entrada de mapa específica para una referencia de objeto y esta soporta el método (por defecto: 'presentar') entonces se llamará al método, pasando la vista como argumento. El objeto puede entonces hacer callbacks contra la vista para presentarse. 
paquete Foo;
sub presentar {
    mi ($self) = @_;
    return "una vista regular de un Foo\n";
}
sub depurar {
    mi ($self) = @_;
    return "una vista de depuración de un Foo\n";
}

En una plantilla:

[% USE vista %]
[% vista.imprimir(objeto_mi_foo) %]     # una vista regular de un Foo
[% USE vista(método => 'depurar') %]
[% vista.imprimir(objeto_mi_foo) %]     # una vista de depuración de un Foo
por defecto
Plantilla por defecto a usar si no se encuentra una entrada de mapa específica para un elemento. 
[% USE vista(por_defecto => 'mi_objeto') %]
[% vista.imprimir(referencia_obj) %]            # => mi_objeto

Si no se proporciona una entrada de mapa ni un valor por defecto, la vista intentará construir un nombre de plantilla a partir de la clase del objeto, sustituyendo cualquier secuencia de caracteres no alfanuméricos por guiones bajos únicos, por ejemplo:

# 'fubar' es un objeto de clase Foo::Bar
[% vista.imprimir(fubar) %]             # => Foo_Bar

Cualquier prefijo y sufijo actual se añadirá tanto al nombre de la plantilla por defecto como a cualquier nombre construido a partir de la clase del objeto.

notfound
Plantilla de fallback a usar si alguna otra no se encuentra.
item
Nombre de la variable de plantilla a la que el método print() asigna el elemento actual. Por defecto es 'item'. 
[% USE vista %]
[% BLOCK lista %]
   [% item.unir(', ') %]
[% END %]
[% vista.imprimir(una_lista) %]
[% USE vista(item => 'cosa') %]
[% BLOCK lista %]
   [% cosa.unir(', ') %]
[% END %]
[% vista.imprimir(una_lista) %]
view_prefix
Prefijo de los métodos que deberían ser mapeados a vista() por AUTOLOAD. Por defecto es 'vista_'. 
[% USE vista %]
[% vista.vista_encabezado() %]                    # => vista('encabezado')
[% USE vista(view_prefix => 'muestrame_el_' %]
[% vista.muestrame_el_encabezado() %]             # => vista('encabezado')
view_naked
Bandera para indicar si se debe intentar mapear nombres de métodos a nombres de plantillas donde no coincidan con el view_prefix. Por defecto es 0. 
[% USE vista(view_naked => 1) %]
[% vista.encabezado() %]                 # => vista('encabezado')
