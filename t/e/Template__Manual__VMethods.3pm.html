Template::Manual::VMethods - Métodos Virtuales

Métodos Virtuales Escalares

chunk(size)

Divide el valor en una lista de fragmentos de un tamaño determinado.

[% ccard_no = "1234567824683579";
   ccard_no.chunk(4).join
%]

Salida:

1234 5678 2468 3579

Si el tamaño se especifica como un número negativo, el texto se dividirá de derecha a izquierda. Esto da la agrupación correcta para los números, por ejemplo.

[% number = 1234567;
   number.chunk(-3).join(',')
%]

Salida:

1,234,567

collapse

Devuelve el texto eliminando los espacios en blanco iniciales y finales y convirtiendo las secuencias internas de espacios en blanco en un solo espacio.

[% text = "  The bird\n  is the word" %]
[% text.collapse %]       # The bird is the word

defined

Devuelve verdadero si el valor está definido.

[% user = get_user(uid) IF uid.defined %]

dquote

Devuelve el texto con los caracteres de comillas dobles escapados con un prefijo de barra invertida. Los caracteres de nueva línea en el texto se reemplazarán por "\n".

[% quote = 'He said "Oh really?"' %]
[% quote.dquote %]        # He said \"Oh really?\"

hash

Devuelve el valor como una referencia de hash que contiene una sola entrada con la clave "value" indicando el valor escalar original. Al igual que con el método virtual "list", esto se usa generalmente para ayudar a dar formato a los datos en diferentes formatos.

lcfirst

Devuelve el texto con la primera letra convertida a minúscula.

[% word = 'BIRD' %]
[% word.lcfirst %]        # bIRD

length

Devuelve la longitud de la representación de cadena del elemento:

[% IF password.length < 8 %]
   Password too short, dumbass!
[% END %]

empty

Devuelve verdadero si la cadena está vacía:

[% IF details.empty %]
   No details specified
[% END %]

list

Devuelve el valor como una lista de un solo elemento. Esto puede ser útil si tiene una variable que puede contener un solo elemento o una lista y desea tratarlos por igual. El método "list" se puede llamar contra una referencia de lista y simplemente devolverá la referencia original, efectivamente sin hacer nada.

[% thing.list.size %]     # thing puede ser un escalar o una lista

lower

Devuelve el texto en minúsculas.

[% word = 'BIRD' %]
[% word.lower %]          # bird

match(pattern, global)

Realiza una coincidencia de expresión regular en la cadena utilizando el patrón pasado como argumento. Si el patrón coincide con la cadena, el método devuelve una referencia a una lista de todas las cadenas capturadas entre paréntesis en el patrón.

[% name = 'Larry Wall' %]
[% matches = name.match('(\w+) (\w+)') %]
[% matches.1 %], [% matches.0 %]    # Wall, Larry

Si el patrón no coincide, el método devuelve falso, en lugar de devolver una lista vacía que Perl y Template Toolkit consideran un valor verdadero. Esto le permite escribir expresiones como esta.

[% "We're not worthy!" IF name.match('Larry Wall') %]
[% IF (matches = name.match('(\w+) (\w+)')) %]
   pattern matches: [% matches.join(', ') %]
[% ELSE %]
   pattern does not match
[% END %]

Cualquier modificador de expresiones regulares, como "/s", debe añadirse en la expresión regular utilizando la sintaxis "(?s)". Por ejemplo, para modificar la expresión regular para ignorar los espacios en blanco (el modificador "/x"), use:

[% re = '(?x)
           (\w+)
           [ ]
           (\w+)
         ';
  matches = name.match(re);
%]

Para realizar una búsqueda global y encontrar el patrón tantas veces como aparezca en la cadena de origen, proporcione un valor verdadero para el argumento "global" después del patrón.

[% text = 'bandanna';
   text.match('an+', 1).join(', ')      # an, ann
%]

repeat(n)

Repite la cadena un número especificado de veces.

[% name = 'foo' %]
[% name.repeat(3) %]                # foofoofoo

replace(search, replace)

Imprime la cadena con todas las instancias del primer argumento (especificado como una expresión regular de Perl) reemplazadas por el segundo.

[% name = 'foo, bar & baz' %]
[% name.replace('\W+', '_') %]        # foo_bar_baz

Puede usar $1, $2, etc., para referenciar partes capturadas (entre paréntesis) en la expresión regular. Tenga cuidado de poner la cadena de reemplazo entre comillas *simples*. Si usa comillas *dobles*, TT intentará interpolar las variables antes de pasar la cadena al método virtual "replace".

[% name = 'FooBarBaz' %]
[% name.replace('([A-Z])', ' $1') %]  # Foo Bar Baz

remove(pattern)

Imprime la cadena con todas las instancias del patrón (especificado como una expresión regular de Perl) eliminadas.

[% name = 'foo, bar & baz' %]
[% name.remove('\W+') %]    # foobarbaz

search(pattern)

Realiza una función similar a match, pero simplemente devuelve verdadero si la cadena coincide con el patrón de expresión regular pasado como argumento.

[% name = 'foo bar baz' %]
[% name.search('bar') ? 'bar' : 'no bar' %]     # bar

Este método virtual está ahora obsoleto en favor de match. Continúe, no hay nada más que ver aquí.

size

Siempre devuelve 1 para valores escalares. Este método se proporciona para la coherencia con los métodos de tamaño de hash y lista.

split(pattern)

Llama a la función split() de Perl para dividir una cadena en una lista de cadenas.

[% FOREACH dir IN mypath.split(':') %]
   [% dir %]
[% END %]

substr(offset, length, replacement)

Devuelve una subcadena que comienza en "offset", durante "length" caracteres.

[% str 'foo bar baz wiz waz woz') %]
[% str.substr(4, 3) %]    # bar

Si no se especifica "length", devuelve todo desde el "offset" hasta el final de la cadena.

[% str.substr(12) %]      # wiz waz woz

Si se especifican tanto "length" como "replacement", el método reemplaza todo desde "offset" durante "length" caracteres con $replacement. Luego se devuelve la subcadena eliminada de la cadena.

[% str.substr(0, 11, 'FOO') %]   # foo bar baz
[% str %]                        # FOO wiz waz woz

squote

Devuelve el texto con los caracteres de comilla simple escapados con un prefijo de barra invertida.

[% tim = "Tim O'Reilly" %]
[% tim.squote %]          # Tim O\'Reilly

trim

Devuelve el texto con los espacios en blanco iniciales y finales eliminados.

[% text = '  hola  mundo  ' %]
[% text.trim %]           # hola  mundo

ucfirst

Devuelve el texto con la primera letra convertida a mayúscula.

[% word = 'pájaro' %]
[% word.ucfirst %]        # Pájaro

upper

Devuelve el texto en mayúsculas.

[% word = 'pájaro' %]
[% word.upper %]          # PÁJARO

Métodos Virtuales de Hash

keys

Devuelve una lista de claves en el hash. No se devuelven en ningún orden particular, pero el orden es el mismo que para el método de valores correspondiente.

[% FOREACH key IN hash.keys %]
   * [% key %]
[% END %]

Si desea las claves en orden ordenado, utilice el método de lista "sort".

[% FOREACH key IN hash.keys.sort %]
   * [% key %]
[% END %]

Una vez obtenidas las claves en orden ordenado, puede utilizar la interpolación de variables para obtener el valor. Esto se muestra en el siguiente ejemplo mediante el uso de $key para obtener el elemento del "hash" cuya clave se almacena en la variable "key".

[% FOREACH key IN hash.keys.sort %]
   * [% key %] = [% hash.$key %]
[% END %]

Alternativamente, puede utilizar el método "pairs" para obtener una lista de pares clave/valor en orden ordenado.

values

Devuelve una lista de los valores en el hash. Al igual que con el método "keys", no se devuelven en ningún orden particular, aunque es el mismo orden en el que se devuelven las claves.

[% hash.values.join(', ') %]

items

Devuelve una lista de ambas claves y valores expandidos en una sola lista.

[% hash = {
      a = 10
      b = 20
   };
   hash.items.join(', ')    # a, 10, b, 20
%]

each

Este método actualmente devuelve lo mismo que el método "items".

Sin embargo, tenga en cuenta que este método cambiará en la próxima versión principal de Template Toolkit (v3) para devolver lo mismo que el método "pairs". Esto se hará en un esfuerzo por hacer que estos métodos virtuales sean más consistentes entre sí y con la forma en que funciona Perl.

En previsión de esto, recomendamos que deje de usar "hash.each" y utilice en su lugar "hash.items".

pairs

Este método devuelve una lista de pares clave/valor. Se devuelven en orden ordenado según las claves.

[% FOREACH pair IN product.pairs %]
   * [% pair.key %] es [% pair.value %]
[% END %]

list

Devuelve el contenido del hash en formato de lista. Se puede pasar un argumento para indicar los elementos deseados requeridos en la lista: "keys" para devolver una lista de las claves (igual que "hash.keys"), "values" para devolver una lista de los valores (igual que "hash.values"), "each" para devolver como lista de claves y valores (igual que "hash.each"), o "pairs" para devolver una lista de pares clave/valor (igual que "hash.pairs").

[% keys   = hash.list('keys') %]
[% values = hash.list('values') %]
[% items  = hash.list('each') %]
[% pairs  = hash.list('pairs') %]

Cuando se llama sin argumento, actualmente devuelve lo mismo que el método "pairs". Sin embargo, tenga en cuenta que este método cambiará en la próxima versión principal de Template Toolkit (v3) para devolver una referencia a una lista que contiene la referencia de hash única (según el método de lista escalar).

En previsión de esto, recomendamos que deje de usar "hash.list" y utilice en su lugar "hash.pairs".

sort, nsort

Devuelve una lista de las claves, ordenadas alfabéticamente ("sort") o numéricamente ("nsort") según los valores correspondientes en el hash.

[% FOREACH n IN phones.sort %]
   [% phones.$n %] es [% n %],
[% END %]

import

El método "import" se puede llamar en un array de hash para importar el contenido de otro array de hash.

[% hash1 = {
     foo = 'Foo'
     bar = 'Bar'
   }
   hash2 = {
       wiz = 'Wiz'
       woz = 'Woz'
   }
%]
[% hash1.import(hash2) %]
[% hash1.wiz %]             # Wiz

También puede llamar al método import() por sí solo para importar un array de hash al hash del espacio de nombres actual.

[% user = { id => 'lwall', name => 'Larry Wall' } %]
[% import(user) %]
[% id %]: [% name %]        # lwall: Larry Wall

defined, exists

Devuelve un valor verdadero o falso si un elemento en el hash denotado por la clave pasada como argumento está definido o existe, respectivamente.

[% hash.defined('somekey') ? 'yes' : 'no' %]
[% hash.exists('somekey') ? 'yes' : 'no' %]

Cuando se llama sin argumento, "hash.defined" devuelve verdadero si el hash en sí está definido (por ejemplo, el mismo efecto que "scalar.defined").

delete

Elimina uno o más elementos del hash.

[% hash.delete('foo', 'bar') %]

size

Devuelve el número de pares clave/valor en el hash.

empty

Devuelve verdadero si el hash está vacío:

[% IF config.empty %]
   No hay configuración disponible
[% END %]

item

Devuelve un elemento del hash utilizando una clave pasada como argumento.

[% hash.item('foo') %]  # lo mismo que hash.foo

Métodos Virtuales de Lista

first, last

Devuelve el primer/último elemento de la lista. El elemento no se elimina de la lista.

[% results.first %] a [% results.last %]

Si a cualquiera se le da un argumento numérico "n", devuelven los primeros o los últimos "n" elementos:

Los primeros 5 resultados son [% results.first(5).join(", ") %].

size, max

Devuelve el tamaño de una lista (número de elementos) y el índice máximo (tamaño - 1), respectivamente.

[% results.size %] resultados de búsqueda coincidieron con tu consulta

empty

Devuelve verdadero si la lista está vacía:

[% IF results.empty %]
   No se encontraron resultados
[% END %]

defined

Devuelve un valor verdadero o falso si el elemento en la lista denotado por el argumento está definido.

[% list.defined(3) ? 'yes' : 'no' %]

Cuando se llama sin argumento, "list.defined" devuelve verdadero si la lista en sí está definida (por ejemplo, el mismo efecto que "scalar.defined").

reverse

Devuelve los elementos de la lista en orden inverso.

[% FOREACH s IN scores.reverse %]
   ...
[% END %]

join

Une los elementos de la lista en una sola cadena, utilizando la función join() de Perl.

[% items.join(', ') %]

grep

Devuelve una lista de los elementos de la lista que coinciden con un patrón de expresión regular.

[% FOREACH directory.files.grep('\.txt$') %]
   ...
[% END %]

sort, nsort

Devuelve los elementos en orden alfabético ("sort") o numérico ("nsort").

[% library = books.sort %]

Se puede proporcionar un argumento para especificar una clave de búsqueda. Cuando un elemento de la lista es una referencia a hash, la clave de búsqueda se utilizará para recuperar un valor del hash que luego se usará como valor de comparación. Cuando un elemento es un objeto que implementa un método con ese nombre, se llamará al método para devolver un valor de comparación.

[% library = books.sort('author') %]

En el ejemplo, la lista "books" puede contener referencias a hash con una clave "author" u objetos con un método "author".

También puede especificar varias claves de ordenación.

[% library = books.sort('author', 'title') %]

En este caso, los libros se ordenarán principalmente por autor. Si dos o más libros tienen autores con el mismo nombre, se ordenarán por título.

unshift(item), push(item)

Promoción automática de escalares a listas para métodos virtuales

Además de los métodos virtuales escalares listados en la sección anterior, también puedes llamar a cualquier método virtual de una lista a un escalar. El elemento se convertirá automáticamente en una lista con un solo elemento y se llamará el método virtual correspondiente.

Una ventaja particular de esta situación ocurre cuando se llama a subrutinas o métodos de objetos que devuelvan una lista de elementos, en lugar de la referencia preferida a una lista de elementos. En este caso, el Template Toolkit automáticamente fusiona los elementos devueltos en una lista.

El resultado es que puedes seguir utilizando módulos existentes o código que devuelva listas de elementos sin tener que refactorizarlo para mantener a Template Toolkit feliz (devolviendo referencias a listas). El módulo "Class::DBI" es un ejemplo de un módulo especialmente útil que devuelve valores de esta manera.

Si solo se devuelve un único elemento de una subrutina, el Template Toolkit asumirá que se quería devolver un único valor (en lugar de una lista con un único elemento) y lo dejará como está. Si estás ejecutando una consulta de base de datos, por ejemplo, podrías obtener un único elemento o varios que luego se fusionen en una lista.

El directivo "FOREACH" acepta tanto una lista como un único elemento que se trate como una lista. Por lo tanto, es seguro escribir directivos como este, asumiendo que la variable "something" está vinculada a una subrutina que pueda devolver uno o más elementos:

[% FOREACH item IN something %]
   ...
[% END %]

La promoción automática de escalares a listas solo se aplica a un elemento, lo cual significa que también puedes usar los métodos virtuales de lista de forma segura, incluso si solo se devuelve un elemento. Por ejemplo:

[% something.first %]
[% something.join %]
[% something.reverse.join(', ') %]

Nota: esta es una última estrategia. Si el único elemento devuelto es un objeto con una método "first", por ejemplo, se llamará al método "first" en preferencia al método virtual de lista.

Definición de métodos virtuales personalizados

Puedes definir tus propios métodos virtuales para escalares, listas y arrays de asociaciones. Las variables de Template::Stash $SCALAR_OPS, $LIST_OPS y $HASH_OPS son referencias a arrays de asociaciones que definen estos métodos virtuales. Las funciones "HASH_OPS" y "LIST_OPS" son subrutinas que aceptan un referencia a un array o una asociación como el primer argumento. Las funciones "SCALAR_OPS" son subrutinas que aceptan un valor escalar como el primer argumento. Todos los otros argumentos especificados cuando se llama al método se pasan a la subrutina.

# cargar Template::Stash para mostrar las tablas de métodos
use Template::Stash;
# definir un método de lista que devuelva una nueva lista de números impares
$Template::Stash::LIST_OPS->{ odd } = sub {
    my $list = shift;
    return [ grep { $_ % 2 } @$list ];
};

Un ejemplo de plantilla:

[% primes = [ 2, 3, 5, 7, 9 ] %]
[% primes.odd.join(', ') %]         # 3, 5, 7, 9
