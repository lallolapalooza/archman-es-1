NOMBRE

Test2::EventFacet::Info::Table - Representación intermedia de una tabla.

DESCRIPCIÓN

Representación intermedia de una tabla para su uso en métodos especializados de Test::API::Context que generan facetas de Test2::EventFacet::Info.

SINOPSIS

use Test2::EventFacet::Info::Table;
use Test2::API qw/context/;
sub my_tool {
    my $ctx = context();
    ...
    $ctx->fail(
        $name,
        "mensaje de diagnóstico de fallo",
        Test2::EventFacet::Info::Table->new(
            # Requerido
            rows => [['a', 'b'], ['c', 'd'], ...],
            # Altamente recomendado
            as_string => "... cadena a imprimir cuando la tabla no pueda ser representada ...",
            # Opcional
            header => ['col1', 'col2'],
            collapse => $bool,
            no_collapse => ['col1', ...],
        ),
    );
    ...
    $ctx->release;
}
my_tool();

ATRIBUTOS

$header_aref = $t->header()
$rows_aref = $t->rows()
$bool = $t->collapse()
$aref = $t->no_collapse()
Los anteriores están directamente vinculados a la estructura hashref de tabla descrita en Test2::EventFacet::Info.
$str = $t->as_string()
Esto devuelve la forma de cadena de la tabla si se estableció, de lo contrario, devuelve la cadena "<TABLA NO MOSTRADA>".
$href = $t->as_hash()
Esto devuelve la estructura de datos utilizada para las tablas por Test2::EventFacet::Info.
%args = $t->info_args()
Esto devuelve los argumentos que deben usarse para construir la estructura Test2::EventFacet::Info adecuada. 
return (table => $t->as_hash(), details => $t->as_string());
