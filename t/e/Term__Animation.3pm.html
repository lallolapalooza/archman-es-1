Term::Animation(3) User Contributed Perl Documentation Term::Animation(3)

NOMBRE

Term::Animation - Framework para animaciones de sprites ASCII

SINOPSIS

use Term::Animation;
# Constructores
$anim = Term::Animation->new();
$anim = Term::Animation->new($curses_window);

RESUMEN

Un framework para producir animaciones de sprites usando arte ASCII.

DESCRIPCIÓN

Este módulo proporciona un framework para producir animaciones de sprites usando arte ASCII. A cada 'sprite' ASCII se le da uno o más fotogramas (frames) y se coloca en la animación como un 'objeto de animación'. Un objeto de animación puede tener una rutina de callback (de retorno de llamada) que controla la posición y el fotograma del objeto.

Si el constructor no recibe argumentos, asume que se está ejecutando en pantalla completa y se comporta en consecuencia. Alternativamente, puede aceptar una ventana de curses (creada con la llamada newwin de Curses) como argumento y dibujará en esa ventana.

EJEMPLOS

Este ejemplo mueve un objeto pequeño a través de la pantalla de izquierda a derecha.

use Term::Animation;
use Curses;
$anim = Term::Animation->new();
# establece el retardo para getch
halfdelay( 2 );
# crea una forma simple que podemos mover
$shape = "<=O=>";
# convierte nuestra forma en un objeto de animación
$anim->new_entity(
             shape         => $shape,        # forma del objeto
             position      => [3, 7, 10],    # fila / columna / profundidad
             callback_args => [1, 0, 0, 0],  # la rutina de callback
                                             #  por defecto toma una lista
                                             #  de deltas x,y,z,frame
             wrap          => 1              # activa el wrap de pantalla
);
# bucle de animación
while(1) {
  # ejecuta y muestra un solo fotograma de animación
  $anim->animate();
  # usa getch para controlar la velocidad de fotogramas y obtener
  # entrada al mismo tiempo. (no es una buena idea si esperas
  # mucha entrada)
  my $input = getch();
  if($input eq 'q') { last; }
}
# termina limpiamente la animación para evitar dañar la terminal del usuario
$anim->end();

Esto ilustra cómo dibujar tu animación en una ventana de Curses existente.

use Term::Animation;
use Curses;
# Term::Animation no llamará a initscr por ti si
# le pasas una ventana
initscr();
$win = newwin(5,10,8,7);
$anim = Term::Animation->new($win);

Todo lo demás sería idéntico al ejemplo anterior.

new
$anim = Term::Animation->new();

El constructor. Opcionalmente toma una ventana de curses existente para dibujar.

new_entity
$anim->new_entity(
      shape         => $shape,
      position      => [ 1, 2, 3 ],
      callback_args => [ 1, 0, 0 ]
);

Crea un nuevo objeto Term::Animation::Entity y lo añade a la animación. Esto es idéntico a:

my $entity = Term::Animation::Entity->new(...);
$anim->add_entity($entity);

Ver Term::Animation::Entity/PARAMETERS y Term::Animation::Entity/new en Term::Animation::Entity para detalles sobre cómo llamar a este método.

color_name
$name = $anim->color_name( $color );

Devuelve el nombre completo de un color, dado un nombre completo o una abreviatura de un solo carácter.

color_id
$id = $anim->color_id( $color );

Devuelve la abreviatura de un solo carácter para un color, dado un nombre completo o una abreviatura.

is_valid_color
my $is_valid = $anim->is_valid_color($color_name);

Devuelve verdadero si la cadena proporcionada es un nombre de color válido ('blue') o un ID de color válido ('b').

color
my $state = $anim->color();
$anim->color($new_state);

Habilita o deshabilita el color ANSI. Esto DEBE llamarse inmediatamente después de crear el objeto de animación si deseas color, porque la llamada start_color de Curses debe hacerse de inmediato. Luego puedes activar y desactivar el color cuando quieras.

background
$anim->background( $color );

Cambia el color de fondo. El color de fondo por defecto es negro. Solo puedes tener un color de fondo para toda la ventana de Curses en la que se esté ejecutando la animación.

animate
$anim->animate();

Realiza un ciclo de animación único. Ejecuta todos los callbacks, realiza la detección de colisiones y actualiza la pantalla.

track_framerate
$anim->track_framerate(1);
$tracking_framerate = $anim->track_framerate();

Obtiene o establece el indicador que indica si el módulo debe realizar un seguimiento de la velocidad de fotogramas de la animación. Esto está habilitado por defecto.

framerate
$frames_per_second = $anim->framerate();

Devuelve el número aproximado de fotogramas que se muestran por segundo, según lo indicado por las llamadas al método animate.

screen_size
my ($width, $height, $assumed_size) = $anim->screen_size();

Devuelve el ancho y alto de la pantalla. El tercer valor devuelto es un booleano que indica si se utilizó o no el tamaño de pantalla por defecto, porque no se pudo determinar el tamaño.

update_term_size
$anim->update_term_size();

Llama a esto si sospechas que el tamaño de la terminal ha cambiado (por ejemplo, si recibes una señal SIGWINCH). Llama a remove_all_entities después de esto si deseas recrear tu animación desde cero.

add_entity
$anim->add_entity( $entity1, $entity2, $entity3 );

Añade una o más entidades de animación a la animación.

del_entity
$anim->del_entity( $entity_name );
$anim->del_entity( $entity_ref );

Elimina una entidad de la animación. Acepta el nombre de una entidad o una referencia a la entidad misma.

remove_all_entities
$anim->remove_all_entities();

Elimina todas las objetos de animación. Esto es útil si necesitas reiniciar la animación (por ejemplo, después de un redimensionamiento de pantalla).

entity_count
$number_of_entities = $anim->entity_count();

Devuelve el número de entidades en la animación.

get_entities
$entity_list = $anim->get_entities();

Devuelve una referencia a una lista de todas las entidades en la animación.

get_entities_of_type
$entity_list = $anim->get_entities_of_type( $type );

Devuelve una referencia a una lista de todas las entidades en la animación que tienen el tipo dado.

is_living
my $is_living = $anim->is_living( $entity );

Devuelve 1 si el nombre o referencia de la entidad está en la animación y no está programada para ser eliminada. Devuelve 0 en caso contrario.

Term::Animation(3pm)

NAME

Term::Animation - object oriented interface for terminal animation

SYNOPSIS

    use Term::Animation;
    my $anim = Term::Animation->new(
        {
            width      => 80,
            height     => 24,
            fps        => 10,
            window     => $some_existing_window, # Optional
            fullscreen => 1,                 # Optional
            title      => "My Animation",      # Optional
            bg_color   => 'BLUE',              # Optional
        }
    );
    # ... build entities ...
    $anim->animate();
    # ... animation finishes ...
    $anim->end();

ABSTRACT

This module provides an object oriented interface for creating terminal animations. This module is little more than a wrapper around the Curses module and the Term::Animation::Entity class.

DESCRIPTION

Term::Animation is used to create simple animations in the terminal. It provides a convenient way to manage multiple animated entities on the screen, and handle updates and callbacks.

The constructor for Term::Animation takes a hash reference of parameters:

width
The width of the animation window. Defaults to the current terminal width.
height
The height of the animation window. Defaults to the current terminal height.
fps
The desired frames per second for the animation. Defaults to 10.
window
An existing Curses window object. If not supplied, a new Curses window will be created.
fullscreen
If true, the animation will take over the entire screen. If false (the default), it will use a smaller window if one is specified.
title
Sets the terminal window title (if supported by the terminal).
bg_color
Sets the background color for the entire animation window. Accepts any valid Curses color name (red, blue, green, etc.).

EXAMPLES

See the documentation for Term::Animation::Entity for examples of how to create and manage entities.

METHODS

new( \%params )
my $anim = Term::Animation->new({
        width => 80,
        height => 24,
        fps => 10,
    });

Creates a new Term::Animation object. See the DESCRIPTION section for a list of valid parameters.

new_entity( \%params )
my $entity = $anim->new_entity(
        name => "My Entity",
        shape => $shape_string,
        position => [ $x, $y, $z ],
        callback => \&my_callback,
        callback_args => [ ... ],
        color => $color_mask,
        default_color => "RED",
    );

Creates a new Term::Animation::Entity object and adds it to the animation list. The parameters are passed directly to the Term::Animation::Entity constructor. See the documentation for Term::Animation::Entity for details.

animate( [ $steps ] )
$anim->animate( 100 );

Starts the animation loop. If $steps is provided, the animation will run for that many steps and then stop. Otherwise, it will run until explicitly stopped or until all entities have been marked for deletion.

Calls the callback routine for each entity, updates their positions, and redraws the screen.

stop
$anim->stop();

Stops the animation loop.

update_term_size
$anim->update_term_size();

Refreshes the stored screen dimensions. This should be called if the terminal window size has changed during the animation. After calling this, you should call redraw_screen to ensure the screen is correctly updated.

width
$width = $anim->width();

Returns the width of the screen.

height
$height = $anim->height();

Returns the height of the screen.

size()
$size = $anim->size();

Returns the number of characters in the curses window (width * height).

redraw_screen
$anim->redraw_screen();

Clears everything from the screen and redraws what should be there. This should be called after update_term_size, or if the user indicates that the screen should be redrawn to get rid of artifacts.

gen_path
# gen_path (x,y,z, x,y,z, [ frame_pattern ], [ steps ])
$anim->gen_path( $x1, $y1, $z1, $x2, $y2, $z2, [ 1, 2, 0, 2 ], 'longest' );

Given beginning and end points, this will return a path for the entity to follow that can be given to the default callback routine, move_entity. The first set of x,y,z coordinates are the point the entity will begin at, the second set is the point the entity will end at.

You can optionally supply a list of frames to cycle through. The list will be repeated as many times as needed to finish the path. If no list of frames is supplied, only the first frame will be used.

You can also request the number of steps you would like for the entity to take to finish the path. The default is 'shortest'. Valid arguments are:
longest The longer of the X and Y distances
shortest The shorter of the X and Y distances
X,Y or Z The x, y or z distance
<number> Explicitly specify the number of steps to take

end
$anim->end();

Runs the Curses endwin function to return your terminal to its normal mode. This is called automatically when the object is destroyed if the animation is running full screen (if you did not pass an existing Curses window to the constructor).

CALLBACK ROUTINES

Callback routines for all entities are called each time animate is called. A default callback routine is supplied, move_entity, which is sufficient for most basic movement. If you want to create an entity that exhibits more complex behavior, you will have to write a custom callback routine for it.

Callback routines take two arguments, a reference to the Term::Animation::Entity object that it should act on, and a reference to the Term::Animation instance that called it. Any arguments required to tell the callback what to do with the object, or any state that needs to be maintained, should be put in the callback_args element of the object. callback_args is only referenced by the callback routine, and thus can contain any datastructure that you find useful.

Here is an example custom callback that will make an entity move randomly around the screen:

sub random_movement {
    my ($entity, $anim) = @_;
    # get the current position of the entity
    my ($x, $y, $z) = $entity->position();
    # we'll use callback_args to store the last axis we moved in
    my $last_move = $entity->callback_args();
    # if we moved in x last time, move in y this time
    if($last_move eq 'x') {
        $entity->callback_args('y');
        # move by -1, 0 or 1
        $y += int(rand(3)) - 1;
    } else {
        $entity->callback_args('x');
        $x += int(rand(3)) - 1;
    }
    # return the absolute x,y,z coordinates to move to
    return ($x, $y, $z);
}

The return value of your callback routine should be of the form:

return ($x, $y, $z, $frame)

$x, $y and $z represent the X, Y and Z coordinates to which the object should move. $frame is the frame number that the object should display, if it has multiple frames of animation. Any values that are unspecified or undef will remain unchanged.

You can also call the default callback from within your callback, if you want it to handle movement for you. For example, if your callback is simply used to decide when an entity should die:

sub wait_for_file {
    my ($entity, $anim) = @_;
    # kill this entity if a certain file shows up
    if(-e "/path/to/file") {
        $entity->kill();
        return();
    }
    # use the default callback to handle the actual movement
    return $entity->move_entity($anim);
}

If you use this, be aware that move_entity relies on callback_args, so you cannot use it to store your own arbitrary data.

COLOR

ANSI color is available for terminals that support it. Only a single background color can be used for the window (it would look terrible in most cases otherwise anyway). Colors for entities are specified by using a 'mask' that indicates the color for each character. For example, say we had a single frame of a bird:

$bird = q#
---. .-. .---
  --\'v'/--
     \ /
     " "
#;

To indicate the colors you want to use for the bird, create a matching mask, with the first letter of each color in the appropriate position (except black, which is 'k'). Pass this mask as the color parameter.

$mask = q#
BBBB BBB BBBB
  BBBWYWBBB
     B B
     Y Y
#;

When specifying a color, using uppercase indicates the color should be bold. So 'BLUE' or 'B' means bold blue, and 'blue' or 'b' means non-bold blue. 'Blue' means you get an error message.

You can also provide a default color with the default_color parameter. This color will be used for any character that does not have an entry in the mask. If you want the entire entity to be a single color, you can just provide a default color with no mask.

The available colors are: red, green, blue, cyan, magenta, yellow, black and white.

Here's an example call to build_object for the bird above.

$anim->new_entity (
          name              => "Bird",
          shape             => $bird,
          position          => [ 5, 8, 7 ],
          callback_args     => [ 1, 2, 0, 0 ],
          color             => $mask,
          default_color     => "BLUE"
);
