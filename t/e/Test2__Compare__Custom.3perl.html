Test2::Compare::Custom(3perl) Guía del programador de Perl Test2::Compare::Custom(3perl)

NOMBRE

Test2::Compare::Custom - Comprobación de campo personalizada para comparaciones.

DESCRIPCIÓN

A veces querrás hacer algo complicado o inusual al validar un campo anidado dentro de una estructura de datos profunda. Podrías extraerlo de la estructura y probarlo por separado, o puedes usar esto para incrustar la comprobación. Esto proporciona una forma de escribir comprobaciones personalizadas para campos en comparaciones profundas.

SINOPSIS

my $cus = Test2::Compare::Custom->new(
    name => 'IsRef',
    operator => 'ref(...)',
    stringify_got => 1,
    code => sub {
        my %args = @_;
        return $args{got} ? 1 : 0;
    },
);
# Pasa
is(
    { a => 1, ref => {},   b => 2 },
    { a => 1, ref => $cus, b => 2 },
    "Esto pasará"
);
# Falla
is(
    {a => 1, ref => 'notref', b => 2},
    {a => 1, ref => $cus,     b => 2},
    "Esto fallará"
);

ARGUMENTOS

Tu subrutina personalizada recibirá 4 argumentos en un hash:

code => sub {
    my %args = @_;
    # proporciona got, exists, operator, name
    return ref($args{got}) ? 1 : 0;
},

$_ también se localiza en "got" para facilitar a aquellos que necesiten usar expresiones regulares.

got
$_
El valor a comprobar.
exists
Será un booleano. Será verdadero si "got" existe en absoluto. Si "exists" es falso, significa que "got" no es simplemente undef, sino que no existe en absoluto (piensa en comprobar el valor de una clave hash que no existe).
operator
El operador especificado en la construcción.
name
El nombre proporcionado en la construcción.

MÉTODOS

$code = $cus->code
Devuelve el coderef proporcionado en la construcción.
$name = $cus->name
Devuelve el nombre proporcionado en la construcción.
$op = $cus->operator
Devuelve el operador proporcionado en la construcción.
$stringify = $cus->stringify_got
Devuelve la bandera stringify_got proporcionada en la construcción.
$bool = $cus->verify(got => $got, exists => $bool)
