NOMBRE

Text::Query::ParseSimple - Analizar la sintaxis de consulta simple de AltaVista

SINOPSIS

use Text::Query;
my $q=new Text::Query('hola y mundo',
                      -parse => 'Text::Query::ParseSimple',
                      -solve => 'Text::Query::SolveSimpleString',
                      -build => 'Text::Query::BuildSimpleString');

DESCRIPCIÓN

Este módulo proporciona un objeto que analiza una cadena que contiene una expresión de consulta Booleana similar a una "consulta simple" de AltaVista. Los elementos de la expresión de consulta pueden tener pesos asignados.

Es la clase base de Text::Query::Parse;

Las expresiones de consulta se compilan en una forma interna cuando se crea un nuevo objeto o se llama al método "prepare"; no se recompilan en cada coincidencia.

Las expresiones de consulta consisten en palabras (secuencias de caracteres que no son espacios en blanco) o frases (cadenas entre comillas) separadas por espacios en blanco. Las palabras o frases precedidas por un "+" deben estar presentes para que la expresión coincida; las palabras o frases precedidas por un "-" deben estar ausentes para que la expresión coincida.

Las palabras o frases pueden ir seguidas opcionalmente de un número entre paréntesis (no se permiten espacios entre la palabra o frase y el número entre paréntesis). Este número especifica el peso asignado a la palabra o frase. Si no se proporciona peso, se asume un peso de 1.
