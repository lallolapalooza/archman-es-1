Paquete: perl-template-toolkit

Template::Plugin::Date(3) Documentación de Perl contribuida por el usuario Template::Plugin::Date(3)

NOMBRE

Template::Plugin::Date - Plugin para generar cadenas de fecha con formato

SINOPSIS

[% USE date %]
# usar hora actual y formato predeterminado
[% date.format %]
# especificar hora como segundos desde la época
# o como una cadena 'h:m:s d-m-a' o 'a-m-d h:m:s'
[% date.format(960973980) %]
[% date.format('4:20:36 21/12/2000') %]
[% date.format('2000/12/21 4:20:36') %]
# especificar formato
[% date.format(mytime, '%H:%M:%S') %]
# especificar localización
[% date.format(date.now, '%a %d %b %y', 'en_GB') %]
# parámetros con nombre
[% date.format(mytime, format = '%H:%M:%S') %]
[% date.format(locale = 'en_GB') %]
[% date.format(time       = date.now,
               format     = '%H:%M:%S',
               locale     = 'en_GB'
               use_offset = 1) %]
# especificar formato predeterminado al plugin
[% USE date(format = '%H:%M:%S', locale = 'de_DE') %]
[% date.format %]
...

DESCRIPCIÓN

El plugin "Date" proporciona una forma fácil de generar cadenas de fecha y hora con formato, delegando a la rutina strftime() de "POSIX".

El plugin puede ser cargado a través de la familiar directiva USE.

[% USE date %]

Esto crea un objeto plugin con el nombre predeterminado de '"date"'. Se puede especificar un nombre alternativo de la siguiente manera:

[% USE myname = date %]

El plugin proporciona el método format() que acepta un valor de tiempo, una cadena de formato y un nombre de localización. Todos estos parámetros son opcionales, utilizando la hora actual del sistema, el formato predeterminado ('"%H:%M:%S %d-%b-%Y"') y la localización actual, respectivamente, si no se definen. Los valores predeterminados para la hora, el formato y/o la localización se pueden especificar como parámetros con nombre en la directiva "USE".

[% USE date(format = '%a %d-%b-%Y', locale = 'fr_FR') %]

Cuando se llama sin parámetros, el método format() devuelve una cadena que representa la hora actual del sistema, formateada por strftime() según el formato predeterminado y para la localización predeterminada (que puede no ser la actual, si la localización se establece en la directiva "USE").

[% date.format %]

El plugin permite especificar una hora/fecha como segundos desde la época, tal como lo devuelve time().

Última modificación del archivo: [% date.format(filemod_time) %]

La hora/fecha también puede especificarse como una cadena de la forma "h:m:s d/m/a" o "a/m/d h:m:s". Cualquiera de los caracteres : / - o espacio puede usarse para delimitar los campos.

[% USE day = date(format => '%A', locale => 'en_GB') %]
[% day.format('4:20:00 9-13-2000') %]

Salida:

Tuesday

También se puede pasar una cadena de formato al método format(), y una especificación de localización puede seguir a esta.

[% date.format(filemod, '%d-%b-%Y') %]
[% date.format(filemod, '%d-%b-%Y', 'en_GB') %]

Un cuarto parámetro permite forzar la salida en GMT, en el caso de entrada de segundos desde la época:

[% date.format(filemod, '%d-%b-%Y', 'en_GB', 1) %]

Tenga en cuenta que en este caso, si la hora local no es GMT, especificar también '%Z' (zona horaria) en el parámetro de formato llevará a un resultado extremadamente engañoso.

Para mantener la compatibilidad con versiones anteriores, el uso del marcador %z en la cadena de formato (para mostrar el desplazamiento UTC) actualmente requiere que el parámetro "use_offset" se establezca en un valor verdadero. Esto también se puede pasar como quinto parámetro a format (pero lo anterior probablemente será más claro).

Cualquiera o todos estos parámetros pueden ser con nombre. Los parámetros posicionales siempre deben estar en el orden "($time, $format, $locale)".

[% date.format(format => '%H:%M:%S') %]
[% date.format(time => filemod, format => '%H:%M:%S') %]
[% date.format(mytime, format => '%H:%M:%S') %]
[% date.format(mytime, format => '%H:%M:%S', locale => 'fr_FR') %]
[% date.format(mytime, format => '%H:%M:%S', gmt => 1) %]
...etc...

El método now() devuelve la hora actual del sistema en segundos desde la época.

[% date.format(date.now, '%A') %]

El método calc() se puede utilizar para crear una interfaz para el módulo "Date::Calc" (si está instalado en su sistema).

[% calc = date.calc %]
[% calc.Monday_of_Week(22, 2001).join('/') %]

El método manip() se puede utilizar para crear una interfaz para el módulo "Date::Manip" (si está instalado en su sistema).

[% manip = date.manip %]
[%= manip.UnixDate("Noon Yesterday","%Y %b %d %H:%M") %]
