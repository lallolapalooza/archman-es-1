Template::Manual::Plugins - Plugins estándar

PLUGINS DEL TEMPLATE TOOLKIT

Los siguientes módulos plugin se distribuyen con el Template Toolkit. Algunos de los plugins interactúan con módulos externos (detallados a continuación) que deben descargarse de cualquier sitio CPAN e instalarse antes de usar el plugin.

Assert

¡Nuevo en 2.20! El plugin Assert añade un método virtual "assert" que puedes usar para detectar valores indefinidos.

Por ejemplo, considera este dotop:

[% user.name %]

Si "user.name" es un valor indefinido, TT ignorará silenciosamente el hecho e imprimirá nada. Si "USA" el plugin "assert", puedes añadir el v-método "assert" entre los elementos "user" y "name", así:

[% user.assert.name %]

Ahora, si "user.name" es un valor indefinido, se lanzará una excepción:

error de aserción - valor indefinido para nombre

CGI

El plugin CGI es un envoltorio para el módulo CGI.pm de Lincoln Stein. El plugin se distribuye con el Template Toolkit (ver Template::Plugin::CGI) y el módulo CGI en sí se distribuye con versiones recientes de Perl, o está disponible en CPAN.

[% USE CGI %]
[% CGI.param('nombre_parametro') %]
[% CGI.start_form %]
[% CGI.popup_menu( Nombre   => 'color',
                   Valores => [ 'Verde', 'Marrón' ] ) %]
[% CGI.end_form %]

Datafile

Proporciona una interfaz a datos almacenados en un archivo de texto plano en un formato delimitado simple. La primera línea del archivo especifica los nombres de los campos que deben estar delimitados por cualquier secuencia de caracteres no de palabra. Las líneas subsiguientes definen datos usando el mismo delimitador que en la primera línea. Las líneas en blanco y los comentarios (líneas que comienzan con '#') se ignoran. Ver Template::Plugin::Datafile para más detalles.

/tmp/misdatos:

# definir nombres para cada campo
id : email : nombre : tel
# aquí están los datos
fred : fred@aqui.com : Fred Smith : 555-1234
bill : bill@aqui.com : Bill White : 555-5678

ejemplo:

[% USE listausuario = datafile('/tmp/misdatos') %]
[% FOREACH usuario = listausuario %]
   [% usuario.nombre %] ([% usuario.id %])
[% END %]

Date

El plugin Date proporciona una forma fácil de generar cadenas de fecha y hora formateadas delegando a la rutina POSIX strftime(). Ver Template::Plugin::Date y POSIX para más detalles.

[% USE fecha %]
[% fecha.format %]           # hora/fecha actual
Última modificación del archivo: [% fecha.format(template.modtime) %]

Directory

El plugin Directory proporciona una interfaz simple a un directorio y a los archivos dentro de él. Ver Template::Plugin::Directory para más detalles.

[% USE dir = Directory('/tmp') %]
[% FOREACH archivo = dir.files %]
    # todos los archivos planos en el directorio
[% END %]
[% FOREACH archivo = dir.dirs %]
    # todos los subdirectorios
[% END %]

DBI

El plugin "DBI" ya no se distribuye como parte del Template Toolkit (a partir de la versión 2.15). Ahora está disponible como una distribución separada Template::DBI desde CPAN.

Dumper

El plugin Dumper proporciona una interfaz al módulo Data::Dumper. Ver Template::Plugin::Dumper y Data::Dumper para más detalles.

[% USE dumper(indent=0, pad="<br>") %]
[% dumper.dump(mivar, tuvar) %]

File

El plugin File proporciona una abstracción general para archivos y puede ser utilizado para obtener información sobre archivos específicos dentro de un sistema de archivos. Ver Template::Plugin::File para más detalles.

[% USE File('/tmp/foo.html') %]
[% File.name %]     # foo.html
[% File.dir %]      # /tmp
[% File.mtime %]    # hora de modificación

Filter

Este módulo implementa un plugin de clase base que puede ser subclasificado para crear fácilmente tus propios módulos que definen e instalan nuevos filtros.

package MiOrg::Template::Plugin::MiFiltro;
use Template::Plugin::Filter;
use base qw( Template::Plugin::Filter );
sub filter {
    my ($self, $texto) = @_;
    # ...modificar $texto...
    return $texto;
}

Ejemplo de uso:

# ahora cargarlo...
[% USE MiFiltro %]
# ...y usar el objeto devuelto como filtro
[% FILTER $MiFiltro %]
  ...
[% END %]

Ver Template::Plugin::Filter para más detalles.

Format

El plugin Format proporciona una forma simple de formatear texto según un formato similar a printf(). Ver Template::Plugin::Format para más detalles.

[% USE negrita = format('<b>%s</b>') %]
[% negrita('Hola') %]

GD

Los plugins "GD" ya no forman parte de la distribución principal del Template Toolkit. Ahora están disponibles en CPAN en una distribución separada Template::GD.

HTML

El plugin HTML es muy básico, implementando algunos métodos útiles para generar HTML. Es probable que se extienda en el futuro o se integre con un proyecto más grande para generar elementos HTML de manera genérica.

[% USE HTML %]
[% HTML.escape("si (a < b && c > d) ..." %]
[% HTML.attributes(border => 1, cellpadding => 2) %]
[% HTML.element(tabla => { border => 1, cellpadding => 2 }) %]

Ver Template::Plugin::HTML para más detalles.

Iterator

El plugin Iterator proporciona una forma de crear un objeto Template::Iterator para iterar sobre un conjunto de datos. Un iterador se crea automáticamente mediante la directiva "FOREACH" y se aliada a la variable "loop". Este plugin permite crear explícitamente un iterador con un nombre dado, o el nombre del plugin por defecto, "iterator". Ver Template::Plugin::Iterator para más detalles.

[% USE iterator(lista, args) %]
[% FOREACH item = iterator %]
   [% '<ul>' IF iterator.first %]
   <li>[% item %]
   [% '</ul>' IF iterator.last %]
[% END %]

Pod

Este plugin proporciona una interfaz al módulo Pod::POM, que analiza documentos POD en un modelo de objeto interno que luego puede ser recorrido y presentado a través del Template Toolkit.

[% USE Pod(archivo_pod) %]
[% FOREACH head1 = Pod.head1;
     FOREACH head2 = head1/head2;
       ...
     END;
   END
%]

Scalar

El Template Toolkit llama a subrutinas definidas por el usuario y métodos de objeto utilizando el contexto de array de Perl por defecto.

# TT2 llama a métodos de objeto en contexto de array por defecto
[% object.method %]

Este módulo plugin proporciona una forma para que llames a subrutinas y métodos en contexto escalar.

[% USE scalar %]
# forzarlo a usar contexto escalar
[% object.scalar.method %]
# también funciona con referencias a subrutinas
[% scalar.mi_ref_sub %]

String

El plugin String implementa una interfaz orientada a objetos para manipular cadenas. Ver Template::Plugin::String para más detalles.

[% USE String 'Hola' %]
[% String.append(' Mundo') %]
[% msg = String.new('Otra cadena') %]
[% msg.replace('cadena', 'texto') %]
La cadena "[% msg %]" tiene [% msg.length %] caracteres.

Table

El plugin Table te permite formatear una lista de elementos de datos en una tabla virtual especificando

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

Tabla

La Tabla plugin genera una tabla de datos a partir de una lista de elementos, dividiéndola en un número fijo de filas o columnas, con una superposición opcional. Ver Template::Plugin::Table para más detalles.

[% USE tabla(lista, filas=10, superposicion=1) %]
[% CADA item = tabla.columna(3) %]
   [% item %]
[% FIN %]

URL

El plugin URL proporciona una forma sencilla de construir URLs a partir de una parte base y un conjunto variable de parámetros. Ver Template::Plugin::URL para más detalles.

[% USE mi_cgi = url('/cgi-bin/bar.pl', debug=1) %]
[% mi_cgi %]
   # ==> /cgi/bin/bar.pl?debug=1
[% mi_cgi(modo='submit') %]
   # ==> /cgi/bin/bar.pl?modo=submit&debug=1

Ajustar

El plugin Ajustar utiliza el módulo Text::Wrap para proporcionar un formato de párrafo sencillo. Ver Template::Plugin::Wrap y Text::Wrap para más detalles.

[% USE ajustar %]
[% ajustar(mitexto, 40, '* ', '  ') %]  # usar sub ajustar
[% mitexto FILTER ajustar(40) -%]       # o filtro ajustar

El módulo "Text::Wrap" está disponible en CPAN:

http://www.cpan.org/modules/by-module/Text/

XML

Los plugins "XML::DOM", "XML::RSS", "XML::Simple" y "XML::XPath" ya no se distribuyen con Template Toolkit a partir de la versión 2.15

Ahora están disponibles en una distribución separada Template::XML.
