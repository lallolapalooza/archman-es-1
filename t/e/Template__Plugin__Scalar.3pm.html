NOMBRE

Template::Plugin::Scalar - llamar a métodos de objetos en contexto escalar

SINOPSIS

[% USE scalar %]
# TT2 llama a métodos de objetos en contexto de array por defecto
[% object.method %]
# forzar el uso de contexto escalar
[% object.scalar.method %]
# también funciona con referencias a subrutinas
[% scalar.my_sub_ref %]

DESCRIPCIÓN

El Template Toolkit llama a subrutinas y métodos de objetos definidos por el usuario utilizando el contexto de array de Perl por defecto. Este módulo de plugin proporciona una forma de llamar a subrutinas y métodos en contexto escalar.
