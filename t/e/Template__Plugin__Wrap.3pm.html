NOMBRE

Template::Plugin::Wrap - Interfaz de plugin para Text::Wrap

SINOPSIS

[% USE wrap %]
# llama a la subrutina wrap
[% wrap(mytext, width, initial_tab,  subsequent_tab) %]
# o usa el FILTRO wrap
[% mytext FILTER wrap(width, initital_tab, subsequent_tab) %]

DESCRIPCIÓN

Este plugin proporciona una interfaz para el módulo Text::Wrap, que ofrece formato de párrafo simple.

Define una subrutina "wrap" que puede ser llamada, pasando el texto de entrada y parámetros opcionales adicionales para especificar el ancho de página (por defecto: 72) y los caracteres de tabulación para la primera y las líneas subsiguientes (sin valores predeterminados).

[% USE wrap %]
[% text = BLOCK %]
First, attach the transmutex multiplier to the cross-wired
quantum homogeniser.
[% END %]
[% wrap(text, 40, '* ', '  ') %]

Salida:

* First, attach the transmutex
  multiplier to the cross-wired quantum
  homogeniser.

También registra un filtro "wrap" que acepta los mismos tres argumentos opcionales, pero toma el texto de entrada directamente a través de la entrada del filtro.

Ejemplo 1:

[% FILTER bullet = wrap(40, '* ', '  ') -%]
First, attach the transmutex multiplier to the cross-wired quantum
homogeniser.
[%- END %]

Salida:

* First, attach the transmutex
  multiplier to the cross-wired quantum
  homogeniser.

Ejemplo 2:

[% FILTER bullet -%]
Then remodulate the shield to match the harmonic frequency, taking
care to correct the phase difference.
[% END %]

Salida:

* Then remodulate the shield to match
  the harmonic frequency, taking
  care to correct the phase difference.
