Test::Simple(3perl) Guía del programador de Perl Test::Simple(3perl)

NOMBRE

Test::Simple - Utilidades básicas para escribir pruebas.

SINOPSIS

use Test::Simple tests => 1;
ok( $foo eq $bar, 'foo es bar' );

DESCRIPCIÓN

¡Si no estás familiarizado con las pruebas, lee Test::Tutorial primero!

Este es un módulo extremadamente simple y básico para escribir pruebas adecuadas para módulos CPAN y otros propósitos. Si deseas realizar pruebas más complicadas, utiliza el módulo Test::More (un reemplazo directo para este).

La unidad básica de las pruebas de Perl es el `ok`. Por cada cosa que desees probar, tu programa imprimirá un "ok" o "not ok" para indicar éxito o fallo. Haces esto con la función ok() (ver abajo).

La única otra restricción es que debes pre-declarar cuántas pruebas planeas ejecutar. Esto es en caso de que algo salga horriblemente mal durante la prueba y tu programa de prueba se aborte, o se salte una prueba o cualquier otra cosa. Lo haces así:

use Test::Simple tests => 23;

Debes tener un plan.

ok
ok( $foo eq $bar, $nombre );
ok( $foo eq $bar );

ok() recibe una expresión (en este caso "$foo eq $bar"). Si es verdadera, la prueba tuvo éxito. Si es falsa, no.

ok() imprime "ok" o "not ok" junto con un número de prueba (eso lo lleva contando por ti).

# Esto produce "ok 1 - El infierno aún no se ha congelado" (o not ok)
ok( get_temperature($hell) > 0, 'El infierno aún no se ha congelado' );

Si proporcionas un $nombre, ese se imprimirá junto con el "ok/not ok" para que sea más fácil encontrar tu prueba si falla (simplemente busca el nombre). También hace que sea más fácil para el próximo que entienda para qué sirve tu prueba. Se recomienda encarecidamente que utilices nombres de prueba.

Todas las pruebas se ejecutan en contexto escalar. Así que esto:

ok( @stuff, 'Tengo algunas cosas' );

hará lo que quieres (fallará si `stuff` está vacío)

Test::Simple comenzará imprimiendo el número de pruebas ejecutadas en el formato "1..M" (así que "1..5" significa que vas a ejecutar 5 pruebas). Este formato extraño permite a Test::Harness saber cuántas pruebas planeas ejecutar en caso de que algo salga horriblemente mal.

Si todas tus pruebas tuvieron éxito, Test::Simple saldrá con cero (lo cual es normal). Si algo falló, saldrá con cuántas fallaron. Si ejecutas menos (o más) pruebas de las que planeaste, las faltantes (o extras) se considerarán fallos. Si nunca se ejecutaron pruebas, Test::Simple emitirá una advertencia y saldrá con 255. Si la prueba murió, incluso después de haber completado con éxito todas sus pruebas, todavía se considerará un fallo y saldrá con 255.

Así que los códigos de salida son...

0                   todas las pruebas exitosas
255                 la prueba murió o todas pasaron pero con un número incorrecto de pruebas ejecutadas
cualquier otro número    cuántas fallaron (incluyendo las faltantes o extras)

Si fallas más de 254 pruebas, se informará como 254.

Este módulo de ninguna manera intenta ser un sistema de pruebas completo. Es solo para que empieces. Una vez que estés en marcha, se recomienda que mires Test::More.

EJEMPLO

Aquí hay un ejemplo de un archivo .t simple para el módulo ficticio Film.

use Test::Simple tests => 5;
use Film;  # Lo que estás probando.
my $btaste = Film->new({ Title    => 'Bad Taste',
                         Director => 'Peter Jackson',
                         Rating   => 'R',
                         NumExplodingSheep => 1
                       });
ok( defined($btaste) && ref $btaste eq 'Film',     'new() funciona' );
ok( $btaste->Title      eq 'Bad Taste',     'Title() get'    );
ok( $btaste->Director   eq 'Peter Jackson', 'Director() get' );
ok( $btaste->Rating     eq 'R',             'Rating() get'   );
ok( $btaste->NumExplodingSheep == 1,        'NumExplodingSheep() get' );

Producirá una salida como esta:

1..5
ok 1 - new() funciona
ok 2 - Title() get
ok 3 - Director() get
not ok 4 - Rating() get
#   Fallo de prueba 'Rating() get'
#   en t/film.t en la línea 14.
ok 5 - NumExplodingSheep() get
# Parece que fallaste 1 de 5 pruebas

Indicando que el método Film::Rating() está roto.

ADVERTENCIAS

Test::Simple solo informará un máximo de 254 fallos en su código de salida. Si este es un problema, probablemente tengas un script de prueba muy grande. Divídelo en varios archivos. (De lo contrario, culpa a los chicos de Unix por usar un entero corto sin signo como estado de salida).

Debido a que los códigos de salida de VMS son muy, muy diferentes al resto del universo, y perl los manipula horriblemente de manera que me interfieren, funciona así en VMS.

0     SS$_NORMAL        todas las pruebas exitosas
4     SS$_ABORT         algo salió mal

Desafortunadamente, no puedo diferenciar más.

NOTAS

Test::Simple está probado explícitamente hasta perl 5.6.0.

Test::Simple es seguro para hilos (thread-safe) en perl 5.8.1 y posteriores.

HISTORIAL

Este módulo fue concebido mientras hablaba con Tony Bowden en su cocina una noche sobre los problemas que tenía al escribir una característica realmente complicada en el nuevo módulo de Pruebas. Él observó que el principal problema no es lidiar con estos casos extremos, sino que la gente odia escribir pruebas en absoluto. Lo que se necesitaba era un módulo muerto de simple que eliminara todo el trabajo arduo de las pruebas y fuera muy, muy fácil de aprender. Paul Johnson tuvo simultáneamente esta idea (desafortunadamente, no estaba en la cocina de Tony). Este es.

VER TAMBIÉN

Test::More
¡Más funciones de prueba! Una vez que superes Test::Simple, mira Test::More. Test::Simple es 100% compatible con versiones futuras con Test::More (es decir, puedes usar Test::More en lugar de Test::Simple en tus programas y las cosas seguirán funcionando).

Busca en el SEE ALSO de Test::More otros módulos de prueba.
