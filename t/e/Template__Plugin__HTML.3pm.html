Template::Plugin::HTML(3) Documentación de usuario de Perl Template::Plugin::HTML(3)

NOMBRE

Template::Plugin::HTML - Plugin para crear elementos HTML

SINOPSIS

[% USE HTML %]
[% HTML.escape("si (a < b && c > d) ..." %]
[% HTML.element(table => { border => 1, cellpadding => 2 }) %]
[% HTML.attributes(border => 1, cellpadding => 2) %]

DESCRIPCIÓN

El plugin "HTML" es un plugin muy básico, que implementa algunos métodos útiles para generar HTML.

MÉTODOS

escape(texto)

Devuelve el texto fuente con cualquier carácter reservado de HTML como "<", ">", etc., escapados correctamente a sus equivalentes de entidad.

atributos(hash)

Devuelve los elementos del array hash pasados por referencia correctamente formateados (por ejemplo, valores entre comillas y escapados correctamente) como atributos para un elemento HTML.

añadir_atributo(atributos)

Esto proporciona una forma de añadir atributos incrementalmente al objeto. Los valores pasados se almacenan en el objeto. Llamar a elemento con solo una etiqueta o atributos sin parámetros utilizará los atributos guardados.

USE tag = HTML;
tag.add_attributes( { class => 'navbar' } );
tag.add_attributes( { id => 'foo' } );
tag.add_attributes( { class => 'active' } );
tag.element( 'li' ); # <li class="navbar active" id="foo">

Este método tiene dos alias: add_attribute() y add().

reemplazar_atributo(atributos)

Esto reemplazará un valor de atributo en lugar de añadirlo al existente.

USE tag = HTML;
tag.add_attributes( { class => 'navbar' } );
tag.add_attributes( { id => 'foo' } );
tag.replace_attributes( { class => 'active' } );
tag.element( 'li' ); # <li class="active" id="foo">

Este método tiene dos alias: replace_attribute() y replace().

limpiar_atributos

Limpia cualquier atributo guardado

elemento(tipo, atributos)

Genera un elemento HTML del tipo especificado y con los atributos proporcionados como referencia a un array hash opcional como segundo argumento o como argumentos con nombre.

[% HTML.element(table => { border => 1, cellpadding => 2 }) %]
[% HTML.element('table', border=1, cellpadding=2) %]
[% HTML.element(table => attribs) %]

DEPURACIÓN

El plugin HTML acepta una opción "sorted" como argumento del constructor que, cuando se establece en cualquier valor verdadero, hace que los atributos generados por el método attributes() (directamente o a través de element()) se devuelvan en orden ordenado. El orden de los atributos no es importante en HTML, pero esto se proporciona principalmente para fines de depuración, donde es útil tener los atributos generados en un orden determinista en lugar del orden en que el hash se sentía al devolver las claves.

[% USE HTML(sorted=1) %]
[% HTML.element( foo => { charlie => 1, bravo => 2, alpha => 3 } ) %]

genera:

<foo alpha="3" bravo="2" charlie="1">
