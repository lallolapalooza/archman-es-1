NOMBRE

Plugin que proporciona información sobre archivos

SINOPSIS

[% USE File(ruta_archivo) %]
[% File.path %]         # ruta completa
[% File.name %]         # nombre del archivo
[% File.dir %]          # directorio

DESCRIPCIÓN

Este plugin proporciona una abstracción de un archivo. Puede usarse para obtener detalles sobre archivos en el sistema de archivos, o para representar archivos abstractos (por ejemplo, al crear una página de índice) que puedan o no existir en un sistema de archivos.

Se debe especificar un nombre de archivo o ruta como argumento del constructor. Por ejemplo:

[% USE File('foo.html') %]
[% USE File('foo/bar/baz.html') %]
[% USE File('/foo/bar/baz.html') %]

El archivo debe existir en el sistema de archivos actual (a menos que la opción "nostat" esté activada, ver más abajo) como un archivo absoluto cuando se especifica con un prefijo "/" como por ejemplo "/foo/bar/baz.html", o de lo contrario como un archivo relativo al directorio actual. El constructor realiza un stat() en el archivo y proporciona los 13 elementos devueltos como ítems del plugin:

dev ino mode nlink uid gid rdev size
atime mtime ctime blksize blocks

por ejemplo:

[% USE File('/foo/bar/baz.html') %]
[% File.mtime %]
[% File.mode %]
...

Además, los ítems "user" y "group" se establecen con los nombres de usuario y grupo correspondientes obtenidos mediante llamadas a getpwuid() y getgrgid() para el archivo "uid" y "gid" respectivamente. En plataformas Windows 32 en las que getpwuid() y getgrgid() no están disponibles, estos valores son indefinidos.

[% USE File('/tmp/foo.html') %]
[% File.uid %]      # ejemplo: 500
[% File.user %]     # ejemplo: abw

Esta búsqueda de usuario/grupo puede ser desactivada estableciendo la opción "noid".

[% USE File('/tmp/foo.html', noid=1) %]
[% File.uid %]      # ejemplo: 500
[% File.user %]     # nada

El flag "isdir" será establecido si el archivo es un directorio.

[% USE File('/tmp') %]
[% File.isdir %]    # 1

Si el stat() en el archivo falla (por ejemplo, el archivo no existe, permisos incorrectos, etc.), el constructor lanzará una excepción "File". Esta puede capturarse dentro de un bloque "TRY...CATCH".

[% TRY %]
   [% USE File('/tmp/myfile') %]
   ¡El archivo existe!
[% CATCH File %]
   Error: [% error.info %]
[% END %]

Nota: la capitalización del tipo de excepción, "File", indica que se lanzó una excepción por el plugin "File", para distinguirlo de una excepción regular "file" lanzada por el Template Toolkit.

Nota: el plugin "File" también puede referirse como "file" en minúsculas. Sin embargo, las excepciones siempre son de tipo "File", independientemente de la capitalización del nombre del plugin usado.

[% USE file('foo.html') %]
[% file.mtime %]

Como con cualquier otro plugin del Template Toolkit, se puede especificar un nombre alternativo para el objeto creado.

[% USE foo = file('foo.html') %]
[% foo.mtime %]

La opción "nostat" puede especificarse para evitar que el constructor del plugin realice un stat() en el archivo especificado. En este caso, el archivo no necesita existir en el sistema de archivos, no se intentará verificar que exista, y no se lanzará una excepción si no existe. Los valores de los ítems usualmente devueltos por stat() se establecerán como vacíos.

[% USE file('/some/where/over/the/rainbow.html', nostat=1)
[% file.mtime %]     # nada

MÉTODOS

Todos los plugins "File", independientemente de la opción "nostat", tienen un número de ítems relacionados con la ruta original especificada.

path

La ruta completa, original, especificada al constructor.

[% USE file('/foo/bar.html') %]
[% file.path %]     # /foo/bar.html

name

El nombre del archivo sin directorios previos.

[% USE file('/foo/bar.html') %]
[% file.name %]     # bar.html

dir

El componente directorio de la ruta, sin el nombre del archivo.

[% USE file('/foo/bar.html') %]
[% file.name %]     # /foo

ext

La extensión del archivo, si existe, que aparece al final de la ruta, no incluida la extensión.

[% USE file('/foo/bar.html') %]
[% file.ext %]      # html

home

Contiene una cadena de la forma "../.." que representa el camino hacia el directorio raíz del archivo.

[% USE file('bar.html') %]
[% file.home %]     # nada
[% USE file('foo/bar.html') %]
[% file.home %]     # ..
[% USE file('foo/bar/baz.html') %]
[% file.home %]     # ../..

root

El ítem "root" puede especificarse como un argumento del constructor, indicando un directorio raíz en el cual reside el archivo nombrado. Este es de lo contrario vacío.

[% USE file('foo/bar.html', root='/tmp') %]
[% file.root %]     # /tmp

abs

Devuelve la ruta absoluta del archivo construyendo una ruta a partir de los argumentos "root" y "path".

[% USE file('foo/bar.html', root='/tmp') %]
[% file.path %]     # foo/bar.html
[% file.root %]     # /tmp
[% file.abs %]      # /tmp/foo/bar.html

rel(path)

Devuelve una ruta relativa desde el archivo actual hasta otra ruta especificada como argumento. Se construye concatenando la ruta al ítem "home".

[% USE file('foo/bar/baz.html') %]
[% file.rel('wiz/waz.html') %]      # ../../wiz/waz.html

EJEMPLOS

[% USE file('/foo/bar/baz.html') %]
[% file.path  %]      # /foo/bar/baz.html
[% file.dir   %]      # /foo/bar
[% file.name  %]      # baz.html
[% file.home  %]      # ../..
[% file.root  %]      # ''
[% file.abs   %]      # /foo/bar/baz.html
[% file.ext   %]      # html
[% file.mtime %]      # 987654321
[% file.atime %]      # 987654321
[% file.uid   %]      # 500
[% file.user  %]      # abw
[% USE file('foo.html') %]
[% file.path %]           # foo.html
[% file.dir  %]       # ''
[% file.name %]           # foo.html
[% file.root %]       # ''
[% file.home %]       # ''
[% file.abs  %]       # foo.html
[% USE file('foo/bar/baz.html') %]
[% file.path %]           # foo/bar/baz.html
[% file.dir  %]       # foo/bar
[% file.name %]           # baz.html
[% file.root %]       # ''
[% file.home %]       # ../..
[% file.abs  %]       # foo/bar/baz.html
[% USE file('foo/bar/baz.html', root='/tmp') %]
[% file.path %]           # foo/bar/baz.html
[% file.dir  %]       # foo/bar
[% file.name %]           # baz.html
[% file.root %]       # /tmp
[% file.home %]       # ../..
[% file.abs  %]       # /tmp/foo/bar/baz.html
# calcular otras rutas de archivo relativas a este archivo y a su raíz
[% USE file('foo/bar/baz.html', root => '/tmp/tt2') %]
[% file.path('baz/qux.html') %]         # ../../baz/qux.html
[% file.dir('wiz/woz.html')  %]     # ../../wiz/woz.html
