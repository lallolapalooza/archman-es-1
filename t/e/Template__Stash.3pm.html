Template::Stash(3) Documentación de Perl aportada por el usuario Template::Stash(3)

NOMBRE

Template::Stash - Almacenamiento mágico para variables de plantilla

SINOPSIS

use Template::Stash;
my $stash = Template::Stash->new(\%vars);
# obtener valores de variables
$value = $stash->get($variable);
$value = $stash->get(\@compound);
# establecer valor de variable
$stash->set($variable, $value);
$stash->set(\@compound, $value);
# valor de variable por defecto
$stash->set($variable, $value, 1);
$stash->set(\@compound, $value, 1);
# establecer valores de variables en masa
$stash->update(\%new_vars)
# métodos para (des-)localizar variables
$stash = $stash->clone(\%new_vars);
$stash = $stash->declone();

DESCRIPCIÓN

El módulo "Template::Stash" define una clase de objeto que se utiliza para almacenar valores de variables para el uso en tiempo de ejecución del procesador de plantillas. Los valores de las variables se almacenan internamente en una referencia de hash (que a su vez se bendice para crear el objeto) y son accesibles a través de los métodos get() y set().

Las variables pueden hacer referencia a hashes, arrays, subrutinas y objetos, así como a valores simples. El stash realiza automáticamente la magia adecuada al tratar con variables, llamando a código o a métodos de objetos, indexando en listas, hashes, etc.

El stash tiene los métodos clone() y declone() que son utilizados por el procesador de plantillas para hacer copias temporales del stash para la localización de cambios realizados en las variables.

MÉTODOS PÚBLICOS

new(\%params)

El método constructor new() crea y devuelve una referencia a un nuevo objeto "Template::Stash".

my $stash = Template::Stash->new();

Se puede pasar una referencia de hash para proporcionar variables y valores que se utilizarán para inicializar el stash.

my $stash = Template::Stash->new({ var1 => 'value1',
                                   var2 => 'value2' });

get($variable)

El método get() recupera la variable nombrada por el primer parámetro.

$value = $stash->get('var1');

Las variables compuestas con puntos se pueden recuperar especificando los elementos de la variable mediante una referencia a una lista. Cada nodo en la variable ocupa dos entradas en la lista. La primera da el nombre del elemento de la variable, la segunda es una referencia a una lista de argumentos para ese elemento, o 0 si no hay ninguno.

[% foo.bar(10).baz(20) %]
$stash->get([ 'foo', 0, 'bar', [ 10 ], 'baz', [ 20 ] ]);

set($variable, $value, $default)

El método set() establece la variable nombrada en el primer parámetro al valor especificado en el segundo.

$stash->set('var1', 'value1');

Si el tercer parámetro se evalúa como un valor verdadero, la variable se establece solo si no tenía un valor verdadero antes.

$stash->set('var2', 'default_value', 1);

Las variables compuestas con puntos pueden especificarse como en get() arriba.

[% foo.bar = 30 %]
$stash->set([ 'foo', 0, 'bar', 0 ], 30);

La variable mágica '"IMPORT"' puede especificarse, cuyo valor correspondiente debe ser una referencia de hash. El contenido del array hash se copia (es decir, se importa) en el espacio de nombres actual.

# foo.bar = baz, foo.wiz = waz
$stash->set('foo', { 'bar' => 'baz', 'wiz' => 'waz' });
# importar 'foo' en el espacio de nombres principal: bar = baz, wiz = waz
$stash->set('IMPORT', $stash->get('foo'));

update($variables)

Este método se puede utilizar para establecer o actualizar varias variables a la vez.

$stash->update({
    foo => 10,
    bar => 20,
});

getref($variable)

Esta característica no documentada devuelve un closure que puede ser llamado para obtener el valor de una variable. Se utiliza para implementar referencias de variables que se evalúan de forma perezosa.

[% x = \foo.bar.baz %]          # x es una referencia a foo.bar.baz
[% x %]                         # evalúa foo.bar.baz

clone(\%params)

El método clone() crea y devuelve un nuevo objeto "Template::Stash" que representa una copia localizada del stash padre. Las variables se pueden actualizar libremente en el stash clonado y, cuando se llama a declone(), se devuelve el stash original con todos sus miembros intactos y en el mismo estado que tenían antes de que se llamara a clone().

Para mayor comodidad, se puede pasar un hash de parámetros a clone() que se utiliza para actualizar cualquier variable simple (es decir, aquellas que no contienen ningún elemento de espacio de nombres como "foo" y "bar" pero no "foo.bar") mientras se clona el stash. Para agregar y actualizar variables complejas, se debe usar el método set() después de llamar a "clone()". Esto resolverá y/o creará correctamente cualquier hash de espacio de nombres necesario.

Un stash clonado mantiene una referencia al stash del que fue copiado en su miembro "_PARENT".

declone()

El método declone() devuelve la referencia "_PARENT" y se puede usar para restaurar el estado de un stash como se describe arriba.

define_vmethod($type, $name, $code)

Este método se puede usar para definir nuevos métodos virtuales. El primer argumento debe ser "scalar" o "item" para definir un método virtual escalar, "hash" para definir métodos virtuales de hash, o "array" o "list" para métodos virtuales de array. El segundo argumento debe ser el nombre del nuevo método. El tercer argumento debe ser una referencia a una subrutina que implementa el método. El elemento de datos en el que se llama al método virtual se pasa a la subrutina como primer argumento.

$stash->define_vmethod(
    item => ucfirst => sub {
        my $text = shift;
        return ucfirst $text
    }
);

MÉTODOS INTERNOS

dotop($root, $item, \@args, $lvalue)

Este es el método principal de operación de "punto" que evalúa elementos de variables contra su raíz.

undefined($ident, $args)

Este método se llama cuando get() encuentra un valor no definido. Si la opción STRICT está activa, lanzará una excepción indicando el uso de un valor no definido. De lo contrario, devolverá silenciosamente una cadena vacía.

El método puede ser redefinido en una subclase para implementar un manejo alternativo de valores no definidos.
