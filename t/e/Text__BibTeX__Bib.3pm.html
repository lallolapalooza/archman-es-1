Text::BibTeX::Bib(3pm) Documentación de Perl contribuida por el usuario Text::BibTeX::Bib(3pm)

NOMBRE

Text::BibTeX::Bib - define la estructura de la base de datos "Bib"

SINOPSIS

$bibfile = Text::BibTeX::File $filename->new;
$bibfile->set_structure ('Bib',
                         # Valores de opción predeterminados:
                         sortby => 'name',
                         namestyle => 'full'
                         nameorder => 'first',
                         atitle => 1,
                         labels => 'numeric');
# Valores de opción alternativos:
$bibfile->set_option (sortby => 'year');
$bibfile->set_option (namestyle => 'nopunct');
$bibfile->set_option (namestyle => 'nospace');
$bibfile->set_option (nameorder => 'last');
$bibfile->set_option (atitle => 0);   
$bibfile->set_option (labels => 'alpha');   # ¡aún no implementado!
# analizar entrada de $bibfile y hacerla automáticamente una BibEntry
$entry = Text::BibTeX::Entry->new($bibfile);
# o obtener una entrada de otro lugar que esté codificada para ser
# una BibEntry
$entry = Text::BibTeX::BibEntry->new(...);
$sortkey = $entry->sort_key;
@blocks = $entry->format;

DESCRIPCIÓN

(¡NOTA! No creas todo lo que lees en este documento. Las clases descritas aquí no están terminadas y solo se han probado ligeramente. La implementación actual es una prueba de concepto, para convencerme a mí (y a cualquiera que pudiera estar interesado) de que realmente es posible reimplementar BibTeX 0.99 en Perl usando las clases principales de "Text::BibTeX"; este principio se demuestra vagamente mediante los módulos "Bib*" actuales, pero no se prueba realmente. Faltan muchas características importantes necesarias para reimplementar los estilos estándar de BibTeX 0.99, a pesar de que este documento pueda afirmarlo bruscamente. Si estás interesado en usar estas clases, deberías empezar por leer y comprender el código, y contribuir con las piezas que faltan y que necesitas.)

"Text::BibTeX::Bib" implementa la estructura de la base de datos para bibliografías tal como la definen los estilos estándar de BibTeX 0.99. Lo hace proporcionando dos clases, "BibStructure" y "BibEntry" (la anteposición "Text::BibTeX" se implica y se omitirá el resto de este documento). Estas dos clases, al ser específicas para datos bibliográficos, están fuera de la jerarquía de clases principal de "Text::BibTeX", pero se distribuyen junto con ella, ya que proporcionan un ejemplo canónico de una estructura de base de datos específica utilizando clases derivadas de la jerarquía principal.

"BibStructure", que deriva de la clase "Structure", se ocupa de la estructura en su conjunto: maneja las opciones de estructura y describe todos los tipos y campos que componen la estructura de la base de datos. Si estás interesado en escribir tus propios módulos de estructura de base de datos, la interfaz estándar para ambos se describe en Text::BibTeX::Structure; si solo estás interesado en averiguar la estructura exacta de la base de datos o las opciones compatibles con la estructura "Bib", has venido al lugar correcto. (Sin embargo, puede que tengas que leer un poco de verborrea excesiva debido al doble propósito de este módulo: primero, reimplementar los estilos estándar de BibTeX 0.99, y segundo, proporcionar un ejemplo para otros programadores que deseen implementar módulos de estructura de base de datos nuevos o derivados).

"BibEntry" deriva de la clase "StructuredEntry" y proporciona métodos que operan sobre entradas individuales que se presumen provienen de una base de datos que cumple con la estructura definida por la clase "BibStructure". (En realidad, para ser completamente preciso, "BibEntry" hereda de dos clases intermedias, "BibSort" y "BibFormat". Estas dos clases solo existen para reducir la cantidad de código en el módulo "Bib", y gracias a la magia de la herencia, su existencia suele ser irrelevante. Pero es posible que quieras consultar esas dos clases si te interesan los detalles sórdidos de la clasificación y formateo de entradas de bases de datos bibliográficas de estilo BibTeX 0.99.)

OPCIONES DE ESTRUCTURA

"BibStructure" maneja varias "opciones de estructura" suministradas por el usuario y métodos para tratarlas. Las opciones actualmente compatibles con la estructura de la base de datos "Bib", y los valores permitidos para ellas, son:

"sortby"
Cómo clasificar las entradas. Valores válidos: "name" (clasificar por nombres de autor, año y título), "year" (clasificar por año, nombres de autor y título). La clasificación por "nombres de autor" es un poco más complicada que simplemente usar el campo "author"; consulta Text::BibTeX::BibSort para más detalles. Valor predeterminado: "name".
"namestyle"
Cómo imprimir los nombres de autor (y editor): "full" para nombres completos sin abreviar, "abbrev" para nombres abreviados con puntos, "nopunct" para nombres abreviados con espacio pero sin puntos, y "nospace" para abreviar sin espacio ni puntos. Valor predeterminado: "full".
"nameorder"
El orden en que se imprimen los nombres: "first" para el orden "nombre apellido jr", y "last" para el orden "apellido jr nombre". Valor predeterminado: "first".
"atitle_lower"
Una opción booleana: si es verdadera, los títulos que no son de libro se cambiarán a "capitalización de oración: las palabras que siguen a los dos puntos y a la puntuación final de la oración se capitalizarán, y todo lo demás en la profundidad de llaves cero se cambiará a minúsculas. Valor predeterminado: verdadero.
"labels"
El tipo de etiquetas bibliográficas a generar: "numeric" o "alpha". (Las etiquetas alfabéticas aún no están implementadas, por lo que esta opción se ignora actualmente.) Valor predeterminado: "numeric".

Además, se admiten varias "opciones de marcado". Las opciones de marcado son distintas porque no cambian cómo se extrae el texto de las entradas de la base de datos y posteriormente se manipula; más bien, suministran fragmentos de marcado que rodean el texto derivado de la base de datos. Las opciones de marcado son siempre listas de dos elementos: la primera para "activar" alguna característica del lenguaje de marcado y la segunda para desactivarla. Por ejemplo, si el lenguaje de destino es LaTeX2e y deseas enfatizar los nombres de las revistas, proporcionarías una referencia de lista "['\emph{','}']" para la opción "journal_mkup". Si en cambio estuvieras generando HTML, podrías proporcionar "['<emph>','</emph>']". Para mantener el módulo de estructura general con respecto a los lenguajes de marcado, todas las opciones de marcado están vacías por defecto. (O, más bien, todas son referencias a listas que consisten en dos cadenas vacías).

"name_mkup"
Marcado para añadir alrededor de la lista de nombres de autor.
"atitle_mkup"
Marcado para añadir alrededor de títulos que no son de libro (artículos).
"btitle_mkup"
Marcado para añadir alrededor de títulos de libros.
"journal_mkup"
Marcado para añadir alrededor de nombres de revistas.

Métodos de opción

Según lo requerido por el módulo "Text::BibTeX::Structure", "Text::BibTeX::Bib" proporciona dos métodos para manejar opciones: "known_option" y "default_option". (Los otros dos métodos de opción, "set_options" y "get_options", simplemente se heredan de "Text::BibTeX::Structure".)

known_option (OPCIÓN)
Devuelve verdadero si OPCIÓN es una de las opciones de la lista anterior.
default_option (OPCIÓN)
Devuelve el valor predeterminado para la OPCIÓN dada.

ESTRUCTURA DE BASE DE DATOS

El otro propósito de una clase de estructura es proporcionar un método, "describe_entry", que enumera los tipos de entrada permitidos y los campos conocidos para la estructura. Los programadores que deseen escribir su propio módulo de estructura de base de datos deben consultar Text::BibTeX::Structure para conocer las convenciones y los requisitos de este método; el propósito del presente documento es describir la estructura de la base de datos "Bib".

Los tipos de entrada permitidos y los campos reconocidos para ellos son:

"article"
Campos requeridos: "author", "title", "journal", "year". Campos opcionales: "volume", "number", "pages", "month", "note".
"book"
Campos requeridos: "title", "publisher", "year". Campos opcionales: "series", "address", "edition", "month", "note". Campos restringidos: exactamente uno de "author", "editor"; como máximo uno de "volume", "number".
"booklet"
Campos requeridos: "title". Opcionales: "author", "howpublished", "address", "month", "year", "note".
"inbook"
Campos requeridos: "publisher", "year". Campos opcionales: "series", "type", "address", "edition", "month", "note". Campos restringidos: exactamente uno de "author", "editor"; al menos uno de "chapter", "pages"; como máximo uno de "volume", "number".
"incollection"
Campos requeridos: "author", "title", "booktitle", "publisher", "year". Campos opcionales: "editor", "series", "type", "chapter", "pages", "address", "edition", "month", "note". Campos restringidos: como máximo uno de "volume", "number".
"inproceedings"
"conference"
Campos requeridos: "author", "title", "booktitle", "year". Campos opcionales: "editor", "series", "pages", "address", "month", "organization", "publisher", "note". Campos restringidos: como máximo uno de "volume", "number".
"manual"
Campos requeridos: "title". Campos opcionales: "author", "organization", "address", "edition", "month", "year", "note".
"mastersthesis"
Campos requeridos: "author", "title", "school", "year". Campos opcionales: "type", "address", "month", "note".
"misc"
Campos requeridos: ninguno. Campos opcionales: "author", "title", "howpublished", "month", "year", "note".
"phdthesis"
Campos requeridos: "author", "title", "school", "year". Campos opcionales: "type", "address", "month", "note".
"proceedings"
Campos requeridos: "title", "year". Campos opcionales: "editor", "series", "address", "month", "organization", "publisher", "note". Campos restringidos: como máximo uno de "volume", "number".
"techreport"
Campos requeridos: "author", "title", "institution", "year". Campos opcionales: "type", "number", "address", "month", "note".
"unpublished"
Campos requeridos: "author", "title", "note". Campos opcionales: "month", "year".

CLASE DE ENTRADA ESTRUCTURADA

La segunda clase proporcionada por el módulo "Text::BibTeX::Bib" es "BibEntry" (de nuevo, se implica un "Text::BibTeX" inicial). Al ser esta una clase de entrada estructurada, se deriva de "StructuredEntry". Las convenciones y requisitos para dicha clase se documentan en Text::BibTeX::Structure para beneficio de los programadores que implementan sus propios módulos de estructura.

Si desea escribir utilidades que hagan uso de la estructura de la base de datos "Bib", debería llamar a uno de los métodos "oficialmente admitidos" proporcionados por la clase "BibEntry". Actualmente, solo hay dos: "sort_key" y "format". Estos se implementan realmente en las clases "BibSort" y "BibFormat", respectivamente, que son clases base de "BibEntry". Por lo tanto, consulte Text::BibTeX::BibSort y Text::BibTeX::BibFormat para obtener detalles sobre estos dos métodos.
