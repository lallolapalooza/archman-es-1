Test2::Util::ExternalMeta(3perl) Guía de referencia para programadores de Perl Test2::Util::ExternalMeta(3perl)

NOMBRE

Test2::Util::ExternalMeta - Permite que herramientas de terceros adjunten metadatos de forma segura a tus instancias.

DESCRIPCIÓN

Este paquete te permite definir una forma clara y consistente para que las herramientas de terceros adjunten metadatos a tus instancias. Si tu objeto consume este paquete e importa sus métodos, entonces los metadatos de terceros tienen un lugar seguro donde vivir.

SINOPSIS

package Mi::Objeto;
use strict;
use warnings;
use Test2::Util::ExternalMeta qw/meta get_meta set_meta delete_meta/;
...

Ahora para usarlo:

my $inst = Mi::Objeto->new;
$inst->set_meta(foo => 'bar');
my $val = $inst->get_meta('foo');

¿DÓNDE SE ALMACENAN LOS DATOS?

Este paquete asume que tus instancias son hashrefs "bendecidos" (blessed), no funcionará si no es así. Almacenará todos los metadatos en la clave "_meta" en el hash de tus objetos. Si tu objeto hace uso de la clave "_meta" en su hash subyacente, entonces hay un conflicto y no puedes usar este paquete.

EXPORTACIONES

$val = $obj->meta($key)
$val = $obj->meta($key, $default)
Esto obtendrá el valor para el meta $key especificado. Normalmente devolverá "undef" cuando no haya un valor para la $key, sin embargo, puedes especificar un valor $default para establecerlo cuando aún no haya un valor establecido.
$val = $obj->get_meta($key)
Esto obtendrá el valor para el meta $key especificado. Esto no tiene la sobrecarga de $default que tiene meta().
$val = $obj->delete_meta($key)
Esto eliminará el valor de un meta $key especificado. El $val antiguo será devuelto.
$obj->set_meta($key, $val)
Establece el valor de un meta $key especificado.

RESTRICCIONES DE CLAVE META

Las claves meta deben estar definidas y deben ser verdaderas cuando se usan como booleanas. Las claves no pueden ser referencias. Tienes libertad para "stringificar" una referencia "$ref" para usarla como clave, pero este paquete no la "stringificará" por ti.
