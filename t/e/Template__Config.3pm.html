NOMBRE

Template::Config - Módulo fábrica para instanciar otros módulos de TT2

SINOPSIS

use Template::Config;

DESCRIPCIÓN

Este módulo implementa varios métodos para cargar e instanciar otros módulos que componen el Template Toolkit. Proporciona una forma consistente de crear componentes del toolkit y permite usar módulos personalizados en lugar de los habituales.

Las variables de paquete como $STASH, $SERVICE, $CONTEXT, etc., contienen el nombre por defecto del módulo/paquete para cada componente (Template::Stash, Template::Service y Template::Context, respectivamente) y son utilizadas por los diversos métodos de fábrica (stash(), service() y context()) para cargar el módulo apropiado. Cambiar estas variables de paquete hará que las llamadas posteriores al método de fábrica relevante carguen e instancien un objeto de la nueva clase.

MÉTODOS PÚBLICOS

load($module)

Carga un módulo usando require() de Perl. Cualquier ocurrencia de '"::"' en el nombre del módulo se convertirá a '"/"', y se añadirá '".pm"'. Devuelve 1 si tiene éxito o undef si hay un error. Usa "$class->error()" para examinar la cadena de error.

preload()

Este método precarga todos los demás módulos "Template::*" que es probable que se utilicen. Es llamado automáticamente por el módulo Template cuando se ejecuta bajo mod_perl (si $ENV{MOD_PERL} está establecido).

parser(\%config)

Instancia un nuevo objeto analizador de la clase cuyo nombre está denotado por la variable de paquete $PARSER (por defecto: Template::Parser). Devuelve una referencia a un objeto analizador recién instanciado o undef si hay un error.

provider(\%config)

Instancia un nuevo objeto proveedor de plantillas (por defecto: Template::Provider). Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

plugins(\%config)

Instancia un nuevo objeto proveedor de plugins (por defecto: Template::Plugins). Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

filters(\%config)

Instancia un nuevo objeto proveedor de filtros (por defecto: Template::Filters). Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

stash(\%vars)

Instancia un nuevo objeto stash (Template::Stash o Template::Stash::XS dependiendo del valor por defecto establecido en el momento de la instalación) usando el contenido del array hash opcional pasado por parámetro como definiciones de variables iniciales. Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

context(\%config)

Instancia un nuevo objeto contexto de plantilla (por defecto: Template::Context). Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

service(\%config)

Instancia un nuevo objeto servicio de plantilla (por defecto: Template::Service). Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

iterator(\%config)

Instancia un nuevo objeto iterador de plantilla (por defecto: Template::Iterator). Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

constants(\%config)

Instancia un nuevo manejador de espacio de nombres para la reducción de constantes en tiempo de compilación (por defecto: Template::Namespace::Constants). Devuelve una referencia a objeto o undef si hay un error, como se indicó anteriormente.

instdir($dir)

Devuelve el directorio raíz de la instalación de Template Toolkit bajo el cual están instalados los componentes opcionales. Cualquier directorio relativo especificado como argumento se añadirá al directorio devuelto.

# por ejemplo, devuelve '/usr/local/tt2'
my $ttroot = Template::Config->instdir()
    || die "$Template::Config::ERROR\n";
# por ejemplo, devuelve '/usr/local/tt2/templates'
my $template = Template::Config->instdir('templates')
    || die "$Template::Config::ERROR\n";

Devuelve "undef" y establece $Template::Config::ERROR apropiadamente si los componentes opcionales del Template Toolkit no han sido instalados.
