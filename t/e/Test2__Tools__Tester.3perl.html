Test2::Tools::Tester(3perl) Guía de referencia para programadores de Perl Test2::Tools::Tester(3perl)

NOMBRE

Test2::Tools::Tester - Herramientas para ayudarte a probar otras herramientas de prueba.

DESCRIPCIÓN

Esta es una colección de herramientas que son útiles al probar otras herramientas de prueba.

SINOPSIS

use Test2::Tools::Tester qw/event_groups filter_events facets/;
use Test2::Tools::Basic qw/plan pass ok/;
use Test2::Tools::Compare qw/is like/;
my $events = intercept {
    plan 11;
    pass('pass');
    ok(1, 'pass');
    is(1, 1, "pass");
    like(1, 1, "pass");
};
# Capturar eventos generados por herramientas en Test2::Tools::Basic
my $basic = filter $events => 'Test2::Tools::Basic';
# Capturar eventos generados por Test2::Tools::Basic;
my $compare = filter $events => 'Test2::Tools::Compare';
# Capturar eventos generados por herramientas llamadas 'ok'.
my $oks = filter $events => qr/.*::ok$/;
my $grouped = group_events $events;
# Divide los eventos en esta estructura:
{
    '__NA__' => [ ... ],
    'Test2::Tools::Basic' => {
        '__ALL__' => [ $events->[0], $events->[1], $events->[2] ],
        plan => [ $events->[0] ],
        pass => [ $events->[1] ],
        ok => [ $events->[2] ],
    },
    Test2::Tools::Compare => { ... },
}
# Obtener un arrayref de todos los facetas de aserción de la lista de eventos.
my $assert_facets = facets assert => $events;
# [
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
# ]
# Lo mismo, pero para facetas de información
my $info_facets = facets info => $events;

EXPORTACIONES

No se exportan subrutinas por defecto.

$array_ref = filter $events => $PACKAGE
$array_ref = filter $events => $PACKAGE1, $PACKAGE2
$array_ref = filter $events => qr/match/
$array_ref = filter $events => qr/match/, $PACKAGE
Esta función toma un arrayref de eventos como primer argumento. Todos los argumentos adicionales deben ser un nombre de paquete o una expresión regular. Cualquier evento que sea generado por una herramienta en cualquiera de los paquetes, o por una herramienta que coincida con cualquiera de las expresiones regulares, será devuelto en un arrayref.
$grouped = group_events($events)
Esta función itera sobre todos los eventos en el arrayref de argumentos y los divide en grupos. La estructura de datos resultante es: 
{ PACKAGE => { SUBNAME => [ $EVENT1, $EVENT2, ... ]}}

Si el paquete de un evento no se conoce, se colocará en un arrayref bajo la clave '__NA__' en la raíz de la estructura. Si un nombre de subrutina no se conoce, típicamente irá bajo la clave '__ANON__' dentro del nombre del paquete.

Además, hay una clave '__ALL__' bajo cada paquete que almacena todos los eventos agrupados en ese grupo.

Un ejemplo más completo:

{
    '__NA__' => [ $event->[3] ],
    'Test2::Tools::Basic' => {
        '__ALL__' => [ $events->[0], $events->[1], $events->[2] ],
        plan => [ $events->[0] ],
        pass => [ $events->[1] ],
        ok => [ $events->[2] ],
    },
}
$arrayref = facets TYPE => $events
Esta función compilará una lista de todos los facetas del tipo especificado que se encuentren en el arrayref de eventos. Si el faceta tiene un paquete "Test2::EventFacet::TYPE" disponible, entonces el faceta se construirá en una instancia de la clase, de lo contrario, se dejará como un hashref. El orden de los facetas se conserva. 
my $assert_facets = facets assert => $events;
# [
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
#   bless({ details => 'pass', pass => 1}, 'Test2::EventFacet::Assert'),
# ]
