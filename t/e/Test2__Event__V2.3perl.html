NOMBRE

Test2::Event::V2 - Evento de segunda generación.

DESCRIPCIÓN

Este es el tipo de evento que debe usarse en lugar de Test2::Event o sus subclases heredadas.

SINOPSIS

USANDO UN CONTEXTO

use Test2::API qw/context/;
sub my_tool {
    my $ctx = context();
    my $event = $ctx->send_ev2(info => [{tag => 'NOTE', details => "This is a note"}]);
    $ctx->release;
    return $event;
}

USANDO EL CONSTRUCTOR

use Test2::Event::V2;
my $e = Test2::Event::V2->new(
    trace => {frame => [$PKG, $FILE, $LINE, $SUBNAME]},
    info  => [{tag => 'NOTE', details => "This is a note"}],
);

MÉTODOS

Esta clase hereda de Test2::Event.

$fd = $e->facet_data()
Esto devolverá un hashref de datos de facetas. Cada hash de faceta será una copia superficial de la original.
$about = $e->about()
Esto devolverá el hashref de la faceta 'about'.

NOTA: Esto devolverá el hashref interno, no una copia.

$trace = $e->trace()
Esto devolverá la faceta 'trace', normalmente bendecida (pero esto no se impone cuando la traza se establece usando set_trace().

NOTA: Esto devolverá la traza interna, no una copia.

MUTACIÓN

$e->add_amnesty({...})
Heredado de Test2::Event. Esto se puede usar para agregar facetas de 'amnesty' a un evento existente. Cada nuevo elemento se agrega al FINAL de la lista.

NOTA: Los elementos SON bendecidos cuando se agregan.

$e->add_hub({...})
Heredado de Test2::Event. Esto es utilizado por los hubs para sellar eventos a medida que pasan. Los nuevos elementos se agregan al INICIO de la lista.

NOTA: Los elementos NO SON bendecidos cuando se agregan.

$e->set_uuid($UUID)
Heredado de Test2::Event, sobreescrito para vivificar/mutar también la faceta 'about'.
$e->set_trace($trace)
Heredado de Test2::Event, lo que te permite cambiar la traza.

Nota: Este método no bendice/clona la traza por ti. Muchas cosas esperarán que la traza esté bendecida, por lo que probablemente deberías hacerlo.

METADATOS DE TERCEROS

Este objeto consume Test2::Util::ExternalMeta, que proporciona una forma coherente para que adjuntes metadatos a instancias de esta clase. Esto es útil para herramientas, complementos y otras extensiones.
