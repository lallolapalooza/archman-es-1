Test2::Manual::Anatomy(3perl) Guía de referencia para programadores de Perl Test2::Manual::Anatomy(3perl)

NOMBRE

Test2::Manual::Anatomy - El centro para la documentación de los componentes internos de Test2.

DESCRIPCIÓN

Esta sección cubre los aspectos internos de la arquitectura de Test2. Esta es información útil para los constructores de herramientas, pero es información esencial para los mantenedores de Test2.

DE EXTREMO A EXTREMO

El documento Test2::Manual::Anatomy::EndToEnd es una visión general de Test2 desde la carga hasta la finalización.

EVENTOS

El documento Test2::Manual::Anatomy::Event explica los aspectos internos de los eventos.

EL CONTEXTO

El documento Test2::Manual::Anatomy::Context explica cómo funciona el objeto Test2::API::Context.

LA API Y LA INSTANCIA DE LA API

El documento Test2::Manual::Anatomy::API explica el funcionamiento interno de la API de Test2.

HUBS

El documento Test2::Manual::Anatomy::Hubs explica el funcionamiento interno de la pila de hubs de Test2, y los hubs dentro de ella.

EL SISTEMA IPC

El documento Test2::Manual::Anatomy::IPC describe el sistema IPC.

UTILIDADES INTERNAS

El documento Test2::Manual::Anatomy::Utilities describe varias utilidades proporcionadas por el sistema Test2.

VER TAMBIÉN

Test2::Manual - Índice principal del manual.

FUENTE

El repositorio de código fuente de Test2-Manual se puede encontrar en https://github.com/Test-More/test-more/.
