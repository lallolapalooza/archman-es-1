NOMBRE

Test::Mouse - Funciones de prueba para características específicas de Mouse

SINOPSIS

use Test::More plan => 1;
use Test::Mouse;
meta_ok($class_or_obj, "... Foo tiene un ->meta");
does_ok($class_or_obj, $role, "... Foo cumple el rol Baz");
has_attribute_ok($class_or_obj, $attr_name, "... Foo tiene el atributo 'bar'");

DESCRIPCIÓN

Este módulo proporciona algunas funciones de prueba útiles para clases basadas en Mouse. Es una primera versión experimental, por lo que los comentarios y sugerencias son muy bienvenidos.

FUNCIONES EXPORTADAS

meta_ok ($class_or_object)
Prueba si una clase u objeto tiene una metaclasse.
does_ok ($class_or_object, $role, ?$message)
Prueba si una clase u objeto cumple un rol determinado, similar a lo que hace "isa_ok" para el método "isa".
has_attribute_ok($class_or_object, $attr_name, ?$message)
Prueba si una clase u objeto tiene un atributo determinado, similar a lo que hace "can_ok" para los métodos.
with_immutable { CODE } @class_names
Ejecuta CODE (que debe contener pruebas normales) dos veces, y hace que cada clase en @class_names sea inmutable entre ambas ejecuciones.
