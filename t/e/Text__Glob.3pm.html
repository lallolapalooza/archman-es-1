Paquete: perl-text-glob

Text::Glob(3) Documentación de Perl contribuida por el usuario Text::Glob(3)

NOMBRE

Text::Glob - comparar patrones de globbing contra texto

SINOPSIS

use Text::Glob qw( match_glob glob_to_regex );
print "coincide\n" if match_glob( "foo.*", "foo.bar" );
# imprime foo.bar y foo.baz
my $regex = glob_to_regex( "foo.*" );
for ( qw( foo.bar foo.baz foo bar ) ) {
    print "coincide: $_\n" if /$regex/;
}

DESCRIPCIÓN

Text::Glob implementa la comparación estilo glob(3) que puede ser utilizada para comparar contra texto, en lugar de obtener nombres de un sistema de archivos. Si quieres hacer globbing de archivos completo usa el módulo File::Glob en su lugar.

Rutinas

match_glob( $glob, @cosas_a_probar )
Devuelve la lista de cosas que coinciden con el glob de la lista fuente.
glob_to_regex( $glob )
Devuelve una expresión regular compilada que es el equivalente del patrón de globbing.
glob_to_regex_string( $glob )
Devuelve una cadena de expresión regular que es el equivalente del patrón de globbing.

SINTAXIS

Los siguientes metacaracteres y reglas son respetados.

"*" - coincide cero o más caracteres
"a*" coincide con "a", "aa", "aaaa" y muchas muchas más.
"?" - coincide exactamente un carácter
"a?" coincide con "aa", pero no con "a", o "aaa"
Conjuntos/rangos de caracteres
"example.[ch]" coincide con "example.c" y "example.h"

"demo.[a-c]" coincide con "demo.a", "demo.b", y "demo.c"

alternancia
"example.{foo,bar,baz}" coincide con "example.foo", "example.bar", y "example.baz"
el . inicial debe ser coincidido explícitamente
"*.foo" no coincide con ".bar.foo". Para esto, debes especificar el punto inicial en el patrón glob (".*.foo"), o establecer $Text::Glob::strict_leading_dot a un valor falso al compilar la expresión regular.
"*" y "?" no coinciden con el separador (es decir, no coinciden con "/")
"*.foo" no coincide con "bar/baz.foo". Para esto, debes coincidir explícitamente la / en el glob ("*/*.foo"), o establecer $Text::Glob::strict_wildcard_slash a un valor falso al compilar la expresión regular, o cambiar el separador que usa Text::Glob estableciendo $Text::Glob::seperator a un valor alternativo al compilar la expresión regular.

ERRORES

El código usa qr// para producir expresiones regulares compiladas, por lo tanto, este módulo requiere la versión 5.005_03 o posterior de perl.
