NOMBRE

Text::LineFold - Plegado de líneas para texto plano

SINOPSIS

use Text::LineFold;
$lf = Text::LineFold->new();

# Plegar líneas
$plegado = $lf->fold($cadena, 'PLAIN');
$indentado = $lf->fold(' ' x 8, ' ' x 4, $cadena);
# Desplegar líneas
$desplegado = $lf->unfold($cadena, 'FIXED');

DESCRIPCIÓN

Text::LineFold pliega o despliega líneas de texto plano. Como se enfoca principalmente en mensajes de correo electrónico de texto plano, también se soporta el formato fluyente RFC 3676.

Interfaz Pública

new ([CLAVE => VALOR, ...])
Constructor. Para pares CLAVE => VALOR, ver el método config.
$self->config (CLAVE)
$self->config ([CLAVE => VAL, ...])
Método de instancia. Obtiene o actualiza la configuración. Se pueden especificar los siguientes pares CLAVE => VALOR.
Charset => CHARSET
Juego de caracteres que se utiliza para codificar la cadena. Puede ser una cadena o un objeto MIME::Charset. El valor predeterminado es "UTF-8".
Language => LANGUAGE
Junto con la opción Charset, esto puede usarse para definir el contexto de idioma/región. El valor predeterminado es "XX". Ver también "Context" en la opción Unicode::LineBreak.
Newline => STRING
Cadena que se utilizará para la secuencia de nueva línea. El valor predeterminado es "\n".
OutputCharset => CHARSET
Juego de caracteres que se utiliza para codificar el resultado de fold()/unfold(). Puede ser una cadena o un objeto MIME::Charset. Si se especifica el valor especial "_UNICODE_", el resultado será una cadena Unicode. El valor predeterminado es el valor de la opción Charset.
TabSize => NUMBER
Ancho de columna de las paradas de tabulación. Cuando se especifica 0, se ignoran las paradas de tabulación. El valor predeterminado es 8.

$self->fold (CADENA, [MÉTODO])
$self->fold (TAB_INICIAL, TAB_SUBSECUENTE, CADENA, ...)
Método de instancia. fold() pliega las líneas de la cadena CADENA y la devuelve. Se eliminan los espacios excedentes y las tabulaciones horizontales al final de la línea, las secuencias de nueva línea se reemplazan por la especificada en la opción Newline y se añade una nueva línea al final del texto si no existe. Las tabulaciones horizontales se tratan como paradas de tabulación según la opción TabSize.

Con el primer estilo, se pueden especificar las siguientes opciones para el argumento MÉTODO.

"FIXED"
Las líneas precedidas por ">" no se plegarán. Los párrafos se separan por una línea vacía.
"FLOWED"
Formato "Format=Flowed; DelSp=Yes" definido por RFC 3676.
"PLAIN"
Método predeterminado. Todas las líneas se pliegan.

El segundo estilo es similar a "wrap()" en Text::Wrap. Todas las líneas se pliegan. TAB_INICIAL se inserta al principio de los párrafos y TAB_SUBSECUENTE al principio de otras líneas rotas.

$self->unfold (CADENA, MÉTODO)
Une los párrafos plegados de la cadena CADENA y la devuelve.

Las siguientes opciones se pueden especificar para el argumento MÉTODO.

"FIXED"
Método predeterminado. Las líneas precedidas por ">" no se unirán. Trata la línea vacía como separador de párrafo.
"FLOWED"
Despliega el formato "Format=Flowed; DelSp=Yes" definido por RFC 3676.
"FLOWEDSP"
Despliega el formato "Format=Flowed; DelSp=No" definido por RFC 3676.
