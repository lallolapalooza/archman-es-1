Template::Filters(3) Documentación Perl contribuida por el usuario Template::Filters(3)

NOMBRE

Template::Filters - Filtros de post-procesamiento para bloques de plantilla

SINOPSIS

use Template::Filters;
$filters = Template::Filters->new(\%config);
($filter, $error) = $filters->fetch($name, \@args, $context);
if ($filter) {
    print &$filter("un texto");
}
else {
    print "No se pudo obtener el filtro $name: $error\n";
}

DESCRIPCIÓN

El módulo "Template::Filters" implementa un proveedor para crear subrutinas que implementan los filtros estándar. Se pueden proporcionar filtros personalizados adicionales a través de la opción de configuración FILTERS.

MÉTODOS

new(\%params)

Método constructor que instancia y devuelve una referencia a un objeto "Template::Filters". Se puede pasar una referencia a un array de hash de elementos de configuración como parámetro. Estos se describen a continuación.

my $filters = Template::Filters->new({
    FILTERS => { ... },
});
my $template = Template->new({
    LOAD_FILTERS => [ $filters ],
});

El módulo Template crea un módulo "Template::Filters" predeterminado si la opción LOAD_FILTERS no se especifica. Todos los parámetros de configuración se reenvían al constructor.

$template = Template->new({
    FILTERS => { ... },
});

fetch($name, \@args, $context)

Se llama para solicitar que se proporcione un filtro de un nombre dado. El nombre del filtro debe especificarse como primer parámetro. Este debe ser uno de los filtros estándar o uno especificado en el hash de configuración FILTERS. El segundo argumento debe ser una referencia a un array que contenga los parámetros de configuración para el filtro. Este puede especificarse como 0 o undef donde no se proporcionan parámetros. El tercer argumento debe ser una referencia al objeto Template::Context actual.

El método devuelve una referencia a una subrutina de filtro en caso de éxito. También puede devolver "(undef, STATUS_DECLINE)" para rechazar la solicitud, permitiendo la delegación a otros proveedores de filtros en la cadena de responsabilidad de LOAD_FILTERS. En caso de error, se devuelve "($error, STATUS_ERROR)", donde $error es un mensaje de error o un objeto Template::Exception que indica el error ocurrido.

Cuando la opción "TOLERANT" está activada, los errores se degradan automáticamente a una respuesta "STATUS_DECLINE".

use_html_entities()

Este método de clase se puede llamar para configurar el filtro "html_entity" para usar el módulo HTML::Entities. Se generará un error si no está instalado en su sistema.

use Template::Filters;
Template::Filters->use_html_entities();

use_apache_util()

Este método de clase se puede llamar para configurar el filtro "html_entity" para usar el módulo Apache::Util. Se generará un error si no está instalado en su sistema.

use Template::Filters;
Template::Filters->use_apache_util();

use_rfc2732()

Este método de clase se puede llamar para configurar los filtros "uri" y "url" para usar el estándar RFC2732 anterior para hacer coincidir caracteres no seguros.

use_rfc3986()

Este método de clase se puede llamar para configurar los filtros "uri" y "url" para usar el estándar RFC3986 más reciente para hacer coincidir caracteres no seguros.

OPCIONES DE CONFIGURACIÓN

La siguiente lista resume las opciones de configuración que se pueden proporcionar al constructor new() de "Template::Filters". Consulte Template::Manual::Config para obtener más información sobre cada opción.

FILTERS

La opción FILTERS se puede utilizar para especificar filtros personalizados que luego se pueden usar con la directiva FILTER como cualquier otro. Estos se agregan a los filtros estándar que están disponibles por defecto.

$filters = Template::Filters->new({
    FILTERS => {
        'sfilt1' =>   \&static_filter,
        'dfilt1' => [ \&dyanamic_filter_factory, 1 ],
    },
});

TOLERANT

La bandera TOLERANT se puede establecer para indicar que el módulo "Template::Filters" debe ignorar cualquier error y, en su lugar, devolver "STATUS_DECLINED".

DEBUG

La opción DEBUG se puede usar para habilitar mensajes de depuración para el módulo Template::Filters estableciéndola para incluir el valor "DEBUG_FILTERS".

use Template::Constants qw( :debug );
my $template = Template->new({
    DEBUG => DEBUG_FILTERS | DEBUG_PLUGINS,
});
