Test__Exit(3pm)

Paquete: perl-test-exit

Licencias: PerlArtistic

Test::Exit(3) Documentación de Perl contribuida por el usuario Test::Exit(3)

NOMBRE

Test::Exit - Probar que cierto código llama a exit() sin terminar la ejecución de pruebas

VERSIÓN

versión 0.11

SINOPSIS

use Test::More tests => 4;
use Test::Exit;

is exit_code { exit 75; }, 75, "procmail no encontrado";
exits_ok { exit 1; } "saliendo con salida";
never_exits_ok { print "¡Hola!"; } "no saliendo no sale"l
exits_zero { exit 0; } "salió con éxito";
exits_nonzero { exit 42; } "salió con fallo";

DESCRIPCIÓN

Test::Exit proporciona algunas herramientas sencillas para probar código que podría llamar a exit(), proporcionándote el código de estado sin terminar la ejecución del archivo de prueba.

El único criterio que se prueba es que el código proporcionado llame o no llame a exit(). Si el código lanza una excepción, la excepción se propagará y tendrás que capturarla tú mismo. Llamar a die() no se considera salir a efectos de estas pruebas.

A diferencia de las versiones anteriores de este módulo, la versión actual no utiliza excepciones para realizar su trabajo, por lo que incluso si llamas a exit() dentro de un "eval", todo debería funcionar.

FUNCIONES

exit_code

Ejecuta el código dado. Si el código llama a exit(), entonces "exit_code" devolverá un número, que es el estado con el que exit() habría salido. Si el código nunca llama a exit(), devuelve "undef". Esta es la interfaz similar a Test::Fatal. Todas las demás funciones son envolturas para esta, conservadas por motivos de compatibilidad.

exits_ok

Prueba que el código proporcionado llama a exit() en algún momento.

exits_nonzero

Prueba que el código proporcionado llama a exit() con un valor distinto de cero.

exits_zero

Prueba que el código proporcionado llama a exit() con un valor cero (éxito).

never_exits_ok

Prueba que el código proporcionado se completa sin llamar a exit().
