NOMBRE

Test::MinimumVersion - ¿tu código requiere una versión de perl más nueva de lo que crees?

VERSIÓN

versión 0.101083

SINOPSIS

Ejemplo de minimum-perl.t:

#!perl
use Test::MinimumVersion;
all_minimum_version_ok('5.008');

VERSIÓN DE PERL

Esta biblioteca debería ejecutarse en versiones de perl lanzadas incluso hace mucho tiempo. Debería funcionar en cualquier versión de perl lanzada en los últimos diez años.

Aunque puede funcionar en versiones de perl más antiguas, no se garantiza que la versión mínima requerida no aumente. La versión puede aumentarse por cualquier motivo, y no hay promesa de que se acepten parches para reducir la versión mínima de perl requerida.

FUNCIONES

minimum_version_ok

minimum_version_ok($archivo, $versión);

Esta prueba pasa si el archivo dado no parece requerir ninguna versión de perl más nueva que $versión, que puede ser una cadena de versión o un objeto de versión.

all_minimum_version_ok

all_minimum_version_ok($versión, \%arg);

Dado una cadena de versión o un objeto de versión, esta rutina produce un plan de prueba (si no hay plan) y prueba cada archivo relevante con "minimum_version_ok".

Los archivos relevantes se encuentran mediante File::Find::Rule::Perl.

"\%arg" es opcional. Los argumentos válidos son:

paths   - en qué directorios buscar archivos; por defecto (bin, script, t, lib,
          xt/smoke, y cualquier archivo .pm o .PL en el directorio de trabajo
          actual) si contiene archivos, se comprobarán
no_plan - no planificar las pruebas que se van a ejecutar
skip    - archivos a omitir; esto puede ser útil en casos extraños como archivos
          gigantes, archivos detectados falsamente como Perl, o código que
          utiliza un filtro de origen; debe ser un arrayref de nombres de archivo

all_minimum_version_from_metayml_ok

all_minimum_version_from_metayml_ok(\%arg);

Esta rutina comprueba META.yml para ver si hay una entrada en requires para perl. Si no se encuentra ningún archivo META.yml o ninguna versión de perl, todas las pruebas se omiten. Si se encuentra una versión, la prueba procede como si "all_minimum_version_ok" se hubiera llamado con esa versión.

all_minimum_version_from_metajson_ok

all_minimum_version_from_metajson_ok(\%arg);

Esta rutina comprueba META.json para ver si hay una entrada en requires para perl. Si no se encuentra ningún archivo META.json o ninguna versión de perl, todas las pruebas se omiten. Si se encuentra una versión, la prueba procede como si "all_minimum_version_ok" se hubiera llamado con esa versión.
