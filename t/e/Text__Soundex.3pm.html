NOMBRE

Text::Soundex - Implementación del algoritmo soundex.

SINOPSIS

use Text::Soundex;
# Algoritmo original.
$code = soundex($name);    # Obtener el código soundex para un nombre.
@codes = soundex(@names);  # Obtener la lista de códigos para una lista de nombres.
# Variante American Soundex (NARA) - Usada para datos del censo de EE.UU.
$code = soundex_nara($name);    # Obtener el código soundex para un nombre.
@codes = soundex_nara(@names);  # Obtener la lista de códigos para una lista de nombres.
# Redefinir el valor que soundex() devolverá si la cadena de entrada
# no contiene ningún sonido identificable.
$Text::Soundex::nocode = 'Z000';

DESCRIPCIÓN

Soundex es un algoritmo fonético para indexar nombres por sonido, tal como se pronuncian en inglés. El objetivo es que los nombres con la misma pronunciación se codifiquen a la misma representación para que puedan ser emparejados a pesar de pequeñas diferencias en la ortografía. Soundex es el más conocido de todos los algoritmos fonéticos y se usa a menudo (incorrectamente) como sinónimo de "algoritmo fonético". Las mejoras a Soundex son la base de muchos algoritmos fonéticos modernos. (Wikipedia, 2007)

Este módulo implementa el algoritmo soundex original desarrollado por Robert Russell y Margaret Odell, patentado en 1918 y 1922, así como una variación llamada "American Soundex" utilizada para datos del censo de EE.UU., y mantenida actualmente por los Archivos Nacionales y Administración de Registros (NARA).

El algoritmo soundex puede ser reconocido de The Art of Computer Programming de Donald Knuth. El algoritmo descrito por Knuth es el algoritmo NARA.

El valor devuelto para cadenas que no tienen codificación soundex se define usando $Text::Soundex::nocode. El valor por defecto es "undef", sin embargo, valores como 'Z000' son alternativas comúnmente usadas.

Para compatibilidad hacia atrás con versiones anteriores de este módulo, $Text::Soundex::nocode se exporta al espacio de nombres del llamador como $soundex_nocode.

En contexto escalar, soundex() devuelve el código soundex de su primer argumento. En contexto de lista, se devuelve una lista en la que cada elemento es el código soundex para el argumento correspondiente pasado a soundex(). Por ejemplo, el siguiente código asigna @codes el valor "('M200', 'S320')":

@codes = soundex qw(Mike Stok);

Para usar "Text::Soundex" para generar códigos que puedan ser usados para buscar en uno de los Censos de EE.UU. disponibles públicamente, se debe usar una variante del algoritmo soundex:

use Text::Soundex;
$code = soundex_nara($name);

Un ejemplo de dónde difieren estos algoritmos es el siguiente:

use Text::Soundex;
print soundex("Ashcraft"), "\n";       # imprime: A226
print soundex_nara("Ashcraft"), "\n";  # imprime: A261

EJEMPLOS

Los ejemplos de Donald Knuth de nombres y los códigos soundex a los que se mapean se listan a continuación:

Euler, Ellery -> E460
Gauss, Ghosh -> G200
Hilbert, Heilbronn -> H416
Knuth, Kant -> K530
Lloyd, Ladd -> L300
Lukasiewicz, Lissajous -> L222

así:

$code = soundex 'Knuth';         # $code contiene 'K530'
@list = soundex qw(Lloyd Gauss); # @list contiene 'L300', 'G200'

LIMITACIONES

Dado que el algoritmo soundex se usó originalmente hace mucho tiempo en EE.UU., solo considera el alfabeto y la pronunciación ingleses. En particular, se ignorarán los caracteres no ASCII. El método recomendado para tratar caracteres con acentos u otros caracteres unicode es usar el módulo Text::Unidecode disponible en CPAN. Usa el módulo explícitamente:

use Text::Soundex;
use Text::Unidecode;
print soundex(unidecode("Fran\xE7ais")), "\n"; # Imprime "F652\n"

O usa la conveniente rutina envoltorio:

use Text::Soundex 'soundex_unicode';
print soundex_unicode("Fran\xE7ais"), "\n";    # Imprime "F652\n"

Dado que el algoritmo soundex mapea un espacio grande (cadenas de longitud arbitraria) a un espacio pequeño (una letra más 3 dígitos), no se puede hacer ninguna inferencia sobre la similitud de dos cadenas que terminan con el mismo código soundex. Por ejemplo, tanto "Hilbert" como "Heilbronn" terminan con un código soundex de "H416".

HISTORIAL

La versión 3 es una actualización significativa para dar soporte a versiones de Perl posteriores a Perl 5.004. Específicamente, la versión XS de la subrutina soundex() entiende cadenas codificadas con UTF-8 (cadenas unicode).

La versión 2 de este módulo fue una reescritura de Mark Mielke ("mark@mielke.cc") para mejorar la velocidad de las subrutinas. La versión XS de la subrutina soundex() se introdujo en la 2.00.

La versión 1 de este módulo fue escrita por Mike Stok ("mike@stok.co.uk") y se incluyó en el conjunto de la biblioteca principal de Perl.

Dave Carlsen ("dcarlsen@csranet.com") hizo la solicitud para incluir el algoritmo NARA. La página de soundex de NARA se puede ver en: "http://www.archives.gov/research/census/soundex.html"
