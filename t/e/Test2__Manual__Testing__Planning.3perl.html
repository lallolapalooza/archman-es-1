NOMBRE

Test2::Manual::Testing::Planning - Las muchas maneras de establecer un plan.

DESCRIPCIÓN

Este tutorial cubre las muchas maneras de establecer un plan.

CONTADOR DE PRUEBAS

La función plan() es proporcionada por Test2::Tools::Basic. Esta función le permite especificar un número exacto de pruebas a ejecutar. Esto se puede hacer al inicio de las pruebas o al final. Esto no se puede hacer a mitad de las pruebas.

use Test2::Tools::Basic;
plan(10); # Se esperan 10 pruebas
...

PRUEBA TERMINADA

La función done_testing() es proporcionada por Test2::Tools::Basic. Esta función establecerá automáticamente el plan al número de pruebas que se ejecutaron. Esto debe usarse al final de las pruebas.

use Test2::Tools::Basic;
...
done_testing();

SALTAR TODO

La función skip_all() es proporcionada por Test2::Tools::Basic. Esta función establecerá el plan a 0 y saldrá de la prueba inmediatamente. Puede proporcionar una razón para omitir, explicando por qué la prueba debe omitirse.

use Test2::Tools::Basic;
skip_all("Esta prueba no se ejecutará aquí") if ...;
...

EVENTO DE PLAN PERSONALIZADO

Un plan es simplemente un evento Test2::Event::Plan que se envía al hub actual. Siempre podría escribir su propia herramienta para establecer el plan.

use Test2::API qw/context/;
sub set_plan {
    my $count = @_;
    my $ctx = context();
    $ctx->send_event('Plan', max => $count);
    $ctx->release;
    return $count;
}
