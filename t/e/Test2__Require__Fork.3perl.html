Test2::Require::Fork(3perl) Guía de referencia del programador de Perl Test2::Require::Fork(3perl)

NOMBRE

Test2::Require::Fork - Omitir un archivo de prueba a menos que el sistema soporte la bifurcación (fork)

DESCRIPCIÓN

Es bastante común escribir pruebas que necesiten hacer una bifurcación (fork). No todos los sistemas soportan la bifurcación. Esta biblioteca hace el trabajo difícil de comprobar si la bifurcación está soportada en el sistema actual. Si la bifurcación no está soportada, entonces se omitirán todas las pruebas y se saldrá con éxito.

SINOPSIS

use Test2::Require::Fork;
... Código que hace una bifurcación ...

EXPLICACIÓN

Comprobar si el sistema actual soporta la bifurcación no es sencillo. Aquí hay un ejemplo de cómo hacerlo:

use Config;
sub CAN_FORK {
    return 1 if $Config{d_fork};
    # Algunas plataformas usan ithreads para imitar la bifurcación
    return 0 unless $^O eq 'MSWin32' || $^O eq 'NetWare';
    return 0 unless $Config{useithreads};
    return 0 unless $Config{ccflags} =~ /-DPERL_IMPLICIT_SYS/;
    # Los hilos no son fiables antes de 5.008001
    return 0 unless $] >= 5.008001;
    # Devel::Cover actualmente tiene problemas con los hilos
    return 0 if $INC{'Devel/Cover.pm'};
    return 1;
}

Duplicar este código no trivial en todas las pruebas que necesitan hacer una bifurcación es propenso a errores. Es fácil olvidar partes, o hacerlo mal. Además de estas comprobaciones, también necesitas decirle al gestor de pruebas (harness) que no se deben ejecutar pruebas y por qué.

VER TAMBIÉN

Test2::Require::RealFork
Similar a este módulo, pero omitirá en cualquier perl que solo tenga emulación de fork.
Test2::Require::Threads
Omitir el archivo de prueba si el sistema no soporta hilos.
