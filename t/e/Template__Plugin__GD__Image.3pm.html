NOMBRE

Template::Plugin::GD::Image - Interfaz con la biblioteca gráfica GD

SINOPSIS

[% USE im = GD.Image(ancho, alto) %]

EJEMPLOS

[% FILTER null;
    USE gdc = GD.Constants;
    USE im  = GD.Image(200,100);
    negro = im.colorAllocate(0  ,0,  0);
    rojo   = im.colorAllocate(255,0,  0);
    r = im.string(gdc.gdLargeFont, 10, 10, "Texto Rojo Grande", rojo);
    im.png | stdout(1);
   END;
-%]
[% FILTER null;
    USE im = GD.Image(100,100);
    # asignar algunos colores
    negro = im.colorAllocate(0,   0, 0);
    rojo   = im.colorAllocate(255,0,  0);
    azul  = im.colorAllocate(0,  0,  255);
    # Dibujar un óvalo azul
    im.arc(50,50,95,75,0,360,azul);
    # Y rellenarlo de rojo
    im.fill(50,50,rojo);
    # Salida de imagen binaria en formato PNG
    im.png | stdout(1);
   END;
-%]
[% FILTER null;
    USE im   = GD.Image(100,100);
    USE c    = GD.Constants;
    USE poly = GD.Polygon;
    # asignar algunos colores
    blanco = im.colorAllocate(255,255,255);
    negro = im.colorAllocate(0,  0,  0);
    rojo   = im.colorAllocate(255,0,  0);
    azul  = im.colorAllocate(0,  0,255);
    verde = im.colorAllocate(0,  255,0);
    # hacer el fondo transparente e entrelazado
    im.transparent(blanco);
    im.interlaced('true');
    # Poner un marco negro alrededor de la imagen
    im.rectangle(0,0,99,99,negro);
    # Dibujar un óvalo azul
    im.arc(50,50,95,75,0,360,azul);
    # Y rellenarlo de rojo
    im.fill(50,50,rojo);
    # Dibujar un triángulo azul
    poly.addPt(50,0);
    poly.addPt(99,99);
    poly.addPt(0,99);
    im.filledPolygon(poly, azul);
    # Salida de imagen binaria en formato PNG
    im.png | stdout(1);
   END;
-%]

DESCRIPCIÓN

El plugin GD.Image proporciona una interfaz a la clase GD::Image de GD.pm. La clase GD::Image es la interfaz principal para GD.pm.

Es muy importante que no haya salida de plantilla adicional antes o después de la imagen. Dado que algunos métodos devuelven valores que de otro modo aparecerían en la salida, se recomienda envolver el código GD.Image en un filtro null. Los métodos que producen la salida final (por ejemplo, png, jpeg, gd, etc.) pueden entonces hacer que su salida aparezca explícitamente usando el filtro stdout, con un argumento distinto de cero para forzar el modo binario (requerido para sistemas operativos no modernos).

Ver GD para una descripción completa de la biblioteca GD y todos los métodos que se pueden llamar a través del plugin GD.Image. Ver Template::Plugin::GD::Constants para un plugin que le permite acceder a las constantes de GD.pm.
