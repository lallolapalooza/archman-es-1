Template::Stash::Context(3) Documentación de Perl contribuida por el usuario Template::Stash::Context(3)

NOMBRE

Template::Stash::Context - Stash experimental que permite la definición de contexto de lista/escalar

SINOPSIS

use Template;
use Template::Stash::Context;
my $stash = Template::Stash::Context->new(\%vars);
my $tt2   = Template->new({ STASH => $stash });

DESCRIPCIÓN

Este es un objeto stash alternativo que incluye un parche de Craig Barratt para implementar varios métodos virtuales nuevos que permiten que las variables de plantilla separadas por puntos indiquen si los métodos de objeto y las subrutinas deben llamarse en contexto escalar o de lista. Agrega una pequeña sobrecarga a cada llamada de stash y soy un poco reacio a aplicarla al stash predeterminado principal sin investigar primero los efectos. Así que, por ahora, se implementa como un módulo stash separado que nos permitirá probarlo, compararlo y activarlo o desactivarlo según sea necesario.

Esto es lo que Craig tiene que decir al respecto:

Aquí hay un mejor conjunto de características para el núcleo. Adjunto una nueva versión de Stash.pm (basada en TT2.02) que:

* admite el operador especial "scalar" que fuerza el contexto escalar en las llamadas a funciones, por ejemplo:

cgi.param("foo").scalar

llama a cgi.param("foo") en contexto escalar (a diferencia de mi operador escalar débil de anoche). El contexto de array es el predeterminado.

Con operandos que no son funciones, scalar se comporta como la versión perl (por ejemplo, no-op para escalar, tamaño para arrays, etc.).

* admite el operador especial "ref" que se comporta como el ref de perl. Si se aplica a una función, la función no se llama. Por ejemplo:

cgi.param("foo").ref

NO llama a cgi.param y se evalúa como "CODE". Del mismo modo, HASH.ref, ARRAY.ref devuelven lo que esperas.

* agrega un nuevo operador escalar y de lista llamado "array" que es un no-op para arrays y promueve escalares a arrays de un elemento.

* permite que los operadores escalares se apliquen a arrays y hashes en su lugar, por ejemplo, ARRAY.repeat(3) repite cada elemento en su lugar.

* permite que los operadores de lista se apliquen a escalares promocionando los escalares a arrays de un elemento (como un "array" implícito). Así que puedes hacer cosas como SCALAR.size, SCALAR.join y obtener un resultado útil.

Esto también significa que ahora puedes usar x.0 para obtener de forma segura el primer elemento, ya sea x un array o un escalar.

El nuevo Stash.pm pasa el conjunto de pruebas TT2.02. Pero no he probado mucho las nuevas características. Un problema de implementación persistente es que los operadores "scalar" y "ref" tienen una precedencia mayor que los nombres de variables de usuario.
