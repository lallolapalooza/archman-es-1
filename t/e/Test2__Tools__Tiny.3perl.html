Test2::Tools::Tiny(3perl) Guía del programador de Perl Test2::Tools::Tiny(3perl)

NOMBRE

Test2::Tools::Tiny - Conjunto de herramientas diminutas para almas desafortunadas que no pueden usar Test2::Suite.

DESCRIPCIÓN

Realmente deberías mirar Test2::Suite. Este paquete contiene herramientas esenciales muy básicas implementadas usando Test2. Existe solo para que Test2 y otras herramientas requeridas por Test2::Suite puedan ser probadas. Este es el paquete que Test2 usa para probarse a sí mismo.

USAR Test2::Suite EN SU LUGAR

Usa Test2::Suite si es posible.

EXPORTACIÓN

ok($bool, $nombre)
ok($bool, $nombre, @diag)
Ejecuta una simple aserción.
is($got, $deseado, $nombre)
is($got, $deseado, $nombre, @diag)
Asegura que 2 cadenas sean iguales.
isnt($got, $no_deseado, $nombre)
isnt($got, $no_deseado, $nombre, @diag)
Asegura que 2 cadenas no sean iguales.
like($got, $regex, $nombre)
like($got, $regex, $nombre, @diag)
Comprueba que la cadena de entrada coincida con la expresión regular.
unlike($got, $regex, $nombre)
unlike($got, $regex, $nombre, @diag)
Comprueba que la cadena de entrada no coincida con la expresión regular.
is_deeply($got, $deseado, $nombre)
is_deeply($got, $deseado, $nombre, @diag)
Compara 2 estructuras de datos. Tenga en cuenta que esta es una implementación *DUMB* que compara la salida de Data::Dumper con ambas estructuras.
diag($msg)
Emite un mensaje de diagnóstico a STDERR.
note($msg)
Emite un mensaje de diagnóstico a STDOUT.
skip_all($reason)
Omite todas las pruebas.
todo $razón => sub { ... }
Ejecuta un bloque en modo TODO.
plan($count)
Establece el plan.
done_testing()
Establece el plan al recuento de pruebas actual.
$warnings = warnings { ... }
Captura una referencia de array de advertencias del bloque.
$exception = exception { ... }
Captura una excepción.
tests $nombre => sub { ... }
Ejecuta una subprueba.
$output = capture { ... }
Captura la salida de STDOUT y STDERR.

El resultado se ve así:

{
    STDOUT => "...",
    STDERR => "...",
}
