Test__Alien__Build(3pm)

Paquete: perl-alien-build

Licencias: PerlArtistic

Test::Alien::Build(3) Documentación de Perl aportada por el usuario Test::Alien::Build(3)

NOMBRE

Test::Alien::Build - Herramientas para probar Alien::Build + alienfile

VERSIÓN

version 2.84

SINOPSIS

use Test2::V0;
use Test::Alien::Build;

# Devuelve una instancia de Alien::Build.
my $build = alienfile_ok q{
  use alienfile;

  plugin 'My::Plugin' => (
    foo => 1,
    bar => 'string',
    ...
  );
};

alien_build_ok 'construye correctamente.';

done_testing;

DESCRIPCIÓN

Este módulo proporciona algunas herramientas para probar Alien::Build y alienfile. Fuera del desarrollo principal de Alien::Build, es probablemente más útil para los desarrolladores de Plugins de Alien::Build.

Este módulo también anula una serie de variables de entorno específicas de Alien::Build, con el fin de hacer que las pruebas sean reproducibles incluso cuando se establecen anulaciones en diferentes entornos. Por lo tanto, si desea probar estas variables en varios estados, debería configurarlas explícitamente en su script de prueba. Estas variables se anulan si están definidas: "ALIEN_BUILD_PRELOAD" "ALIEN_BUILD_POSTLOAD" "ALIEN_INSTALL_TYPE".

FUNCIONES

alienfile

my $build = alienfile;
my $build = alienfile q{ use alienfile ... };
my $build = alienfile filename => 'alienfile';

Crea una instancia de Alien::Build a partir del alienfile dado. Las dos primeras formas son abreviaturas.

my $build = alienfile;
# es lo mismo que
my $build = alienfile filename => 'alienfile';

y

my $build = alienfile q{ use alienfile ... };
# es lo mismo que
my $build = alienfile source => q{ use alienfile ... };

Excepto que la segunda forma abreviada establece el número de línea antes de alimentar la fuente a Alien::Build para que obtenga diagnósticos con los números de línea correctos.

source
La fuente del alienfile como una cadena. Debe especificar "source" o "filename".
filename
El nombre del archivo para el alienfile. Debe especificar "source" o "filename".
root
La raíz de construcción.
stage
El área de preparación para la construcción.
prefix
El prefijo de instalación para la construcción.

alienfile_ok

my $build = alienfile_ok;
my $build = alienfile_ok q{ use alienfile ... };
my $build = alienfile_ok filename => 'alienfile';
my $build = alienfile_ok $build;

Igual que "alienfile" anterior, excepto que se ejecuta como una prueba y no lanzará una excepción en caso de fallo (devolverá undef en su lugar).

[version 1.49]

A partir de la versión 1.49, también puede pasar una instancia de Alien::Build ya formada. Esto le permite hacer algo como esto:

subtest 'una subprueba' => sub {
  my $build = alienfile q{ use alienfile; ... };
  alienfile_skip_if_missing_prereqs; # omitir si faltan las dependencias de alienfile
  alienfile_ok $build;  # pasar/fallar retrasado para la compilación de alienfile
};

alienfile_skip_if_missing_prereqs

alienfile_skip_if_missing_prereqs;
alienfile_skip_if_missing_prereqs $phase;

Omite la prueba o subprueba si faltan las dependencias para el alienfile. Si no se proporciona $phase, se detectará "share" o "system".

alien_install_type_is

alien_install_type_is $type;
alien_install_type_is $type, $name;

Prueba simple para ver si el tipo de instalación es el esperado. $type debe ser "system" o "share".

alien_download_ok

my $file = alien_download_ok;
my $file = alien_download_ok $name;

Realiza un intento de descarga y prueba que resulta en un archivo o directorio. Devuelve el archivo o directorio si tiene éxito. Devuelve "undef" en caso contrario.

alien_extract_ok

my $dir = alien_extract_ok;
my $dir = alien_extract_ok $archive;
my $dir = alien_extract_ok $archive, $name;
my $dir = alien_extract_ok undef, $name;

Realiza un intento de extracción y prueba que resulta en un directorio. Devuelve el directorio si tiene éxito. Devuelve "undef" en caso contrario.

alien_build_ok

my $alien = alien_build_ok;
my $alien = alien_build_ok $name;
my $alien = alien_build_ok { class => $class };
my $alien = alien_build_ok { class => $class }, $name;

Ejecuta las fases de descarga y construcción. Pasa si la construcción tiene éxito. Devuelve una instancia de Alien::Base que puede pasarse a "alien_ok" de Test::Alien. Devuelve "undef" si la prueba falla.

Opciones

class
La clase base a usar para tu alien. Por defecto es Alien::Base. Debe ser una subclase de Alien::Base, o al menos adherirse a su API.

alien_build_clean

alien_build_clean;

Elimina todos los archivos con la construcción actual, excepto el prefijo de tiempo de ejecución. Esto ayuda a probar que la instalación final no dependerá de los archivos de construcción.

alien_clean_install

alien_clean_install;

Ejecuta "$build->clean_install" y verifica que no haya fallado.

alien_checkpoint_ok

alien_checkpoint_ok;
alien_checkpoint_ok $test_name;

Prueba el punto de control de una construcción.

alien_resume_ok

alien_resume_ok;
alien_resume_ok $test_name;

Prueba a reanudar una construcción con puntos de control.

alien_rc

alien_rc $code;

Crea un archivo "rc.pl" en un directorio temporal y establece ALIEN_BUILD_RC. Útil para probar plugins que deberían llamarse desde "~/.alienbuild/rc.pl". Tenga en cuenta que debido a la naturaleza de cómo funciona el archivo "~/.alienbuild/rc.pl", ¡solo puede usarlo una vez!

alien_subtest

alien_subtest $test_name => sub {
  ...
};

Borra el objeto de construcción y borra el objeto de construcción antes y después de la subprueba.

Test::Alien::Build(3pm)

NAME

Test::Alien::Build - helpers for testing Alien::Build modules

VERSION

This document describes version 0.51 of Test::Alien::Build.

SYNOPSIS

  use Test::More tests => 1;
  use Test::Alien::Build;
  
  my $alien_build = Test::Alien::Build->new(
    module_name => 'Alien::Test::Build::Example',
    requires => [ 'Alien::Build' ],
  );
  
  $alien_build->run_build_test;
  
  # or if you want to check install
  
  my $alien_build = Test::Alien::Build->new(
    module_name => 'Alien::Test::Build::Example',
    requires => [ 'Alien::Build' ],
    install => 1,
  );
  
  $alien_build->run_install_test;

DESCRIPTION

This module provides helpers for testing Alien::Build modules.

It can be used to run the tests that are normally run by Alien::Build itself.

It will verify that the alien module can be built, installed, and that the correct files are installed.

FUNCTIONS

The module provides a single constructor:

  new(%args)

The following arguments are accepted:

module_name
This is the name of the alien module you are testing. It is mandatory.
requires
A list of modules that the alien module depends on. This is mandatory.
install
If set to true, then the module will be installed. This defaults to false. This means that only the build will be tested.
install_target
The target to use when installing the module. Defaults to install.
make_install_args
Arguments to pass to the install target. Defaults to an empty list.
build_target
The target to use when building the module. Defaults to build.
make_build_args
Arguments to pass to the build target. Defaults to an empty list.
script
The build script to use. Defaults to Build.PL.
tmpdir
The directory to use for building and installing the module. Defaults to a temporary directory created by File::Temp.
config_args
Arguments to pass to the Build.PL script. Defaults to an empty list.

The following methods are provided:

run_build_test()
Runs the build tests for the alien module.
run_install_test()
Runs the install tests for the alien module.
