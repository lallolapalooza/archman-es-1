NOMBRE

Template::Plugin::URL - Plugin para construir URLs complejas

SINOPSIS

[% USE url('/cgi-bin/foo.pl') %]
[% url(debug = 1, id = 123) %]
   # ==> /cgi/bin/foo.pl?debug=1&amp;id=123
[% USE mycgi = url('/cgi-bin/bar.pl', mode='browse', debug=1) %]
[% mycgi %]
   # ==> /cgi/bin/bar.pl?mode=browse&amp;debug=1
[% mycgi(mode='submit') %]
   # ==> /cgi/bin/bar.pl?mode=submit&amp;debug=1
[% mycgi(debug='d2 p0', id='D4-2k[4]') %]
   # ==> /cgi/bin/bar.pl?mode=browse&amp;debug=d2%20p0&amp;id=D4-2k%5B4%5D

DESCRIPCIÓN

El plugin "URL" puede ser usado para construir URLs complejas a partir de un prefijo base y un array hash de parámetros de consulta adicionales.

El constructor debe recibir una URL base y, opcionalmente, un array hash de referencia de parámetros y valores por defecto. Usado desde una plantilla, se vería algo como lo siguiente:

[% USE url('http://www.somewhere.com/cgi-bin/foo.pl') %]
[% USE url('/cgi-bin/bar.pl', mode='browse') %]
[% USE url('/cgi-bin/baz.pl', mode='browse', debug=1) %]

Cuando el plugin se llama sin argumentos, la base y los parámetros por defecto se devuelven como una cadena de consulta formateada.

[% url %]

Para los tres ejemplos anteriores, estos producirán las siguientes salidas:

http://www.somewhere.com/cgi-bin/foo.pl
/cgi-bin/bar.pl?mode=browse
/cgi-bin/baz.pl?mode=browse&amp;debug=1

Nótese que los parámetros adicionales se separan por '"&amp;"' en lugar de simplemente '"&"'. Este es el comportamiento correcto para páginas HTML, pero es, desafortunadamente, incorrecto cuando se crean URLs que no necesitan ser codificadas de forma segura para HTML. Esto probablemente será corregido en una futura versión del plugin (muy probablemente con TT3). Mientras tanto, puedes establecer $Template::Plugin::URL::JOINT a "&" para obtener el comportamiento correcto.

Se pueden especificar también parámetros adicionales a la URL:

[% url(mode='submit', id='wiz') %]

Lo cual, para los mismos tres ejemplos, produce:

http://www.somewhere.com/cgi-bin/foo.pl?mode=submit&amp;id=wiz
/cgi-bin/bar.pl?mode=browse&amp;id=wiz
/cgi-bin/baz.pl?mode=browse&amp;debug=1&amp;id=wiz

Una nueva URL base también puede ser especificada como la primera opción:

[% url('/cgi-bin/waz.pl', test=1) %]

produciendo

/cgi-bin/waz.pl?test=1
/cgi-bin/waz.pl?mode=browse&amp;test=1
/cgi-bin/waz.pl?mode=browse&amp;debug=1&amp;test=1

El orden de los parámetros no es determinista debido a que los hashes de Perl son en sí mismos desordenados. Esto no es un problema ya que el orden de los parámetros CGI es insignificante (hasta donde sé). Todos los valores serán debidamente escapados gracias a algo de código prestado del módulo "CGI" de Lincoln Stein. Por ejemplo:

[% USE url('/cgi-bin/woz.pl') %]
[% url(name="Elrich von Benjy d'Weiro") %]

Aquí los caracteres de espacio y comilla simple ""'"" se escapan en la salida:

/cgi-bin/woz.pl?name=Elrich%20von%20Benjy%20d%27Weiro

Se puede proporcionar un nombre alternativo para el plugin en el momento de la construcción, según la sintaxis regular de Template Toolkit.

[% USE mycgi = url('cgi-bin/min.pl') %]
[% mycgi(debug=1) %]
