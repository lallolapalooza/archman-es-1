NOMBRE

Text::Roman - Permite la conversión entre números romanos y arábigos.

VERSIÓN

versión 3.5

SINOPSIS

#!/usr/bin/env perl
use strict;
use warnings;
use Text::Roman qw(:all);
print int2roman(123), "\n";
my $roman = "XXXV";
print roman2int($roman), "\n" if isroman($roman);
my $milhar = 'L_X_XXIII'; # = 60,023
print milhar2int($milhar), "\n" if ismilhar($milhar);

DESCRIPCIÓN

Este paquete soporta tanto números romanos convencionales (que varían de 1 a 3999) como números romanos Milhar, una variación que utiliza una barra sobre el número para indicar la multiplicación por 1_000. Para los propósitos de este módulo, la sintaxis aceptable consiste en un guion bajo sufijado al número, por ejemplo, IV_V = 4_005. El término Milhar aparentemente deriva de la palabra portuguesa para "miles" y el rango de esta notación extiende el rango de los números romanos a 3999 * 1000 + 3999 = 4_002_999.

Nota: las funciones de este paquete tratan los números romanos de manera insensible a mayúsculas y minúsculas, de modo que "VI" == "vI" == "Vi" == "vi".

Las siguientes funciones pueden ser importadas en el paquete llamador por nombre:

FUNCIONES

isroman

Comprueba si una cadena es un número romano válido. Devuelve un valor booleano.

int2roman

Convierte un entero expresado en números arábigos a su número romano correspondiente. Si el entero proporcionado está fuera del rango expresable en notación romana, se devuelve undef.

roman2int

Hace lo contrario de "int2roman", convirtiendo un número romano a su valor entero.

ismilhar

Determina si una cadena califica como un número romano Milhar.

milhar2int

Convierte un número romano Milhar a un entero.

ismroman/mroman2int/roman

Estas funciones pertenecen a la interfaz antigua del módulo y se consideran obsoletas. No las use en código nuevo y eventualmente serán descontinuadas; se mapean de la siguiente manera:

  • ismroman => ismilhar
  • mroman2int => milhar2int
  • roman => int2roman

CAMBIOS

Algunos cambios que vale la pena destacar de la encarnación anterior de este módulo:

importaciones de namespace
La llamada a use ahora debe solicitar explícitamente los nombres de funciones importadas en su namespace.
valores predeterminados de argumento / contexto vacío
Todas las funciones ahora operarán sobre $_ cuando no se pasen argumentos, y establecerán $_ cuando se llamen en un contexto vacío. Esto permite escribir código como: 
@x = qw/V III XI IV/;
roman2int() for @x;
print join("-", @x);

en lugar del más feo:

@x = qw/V III XI IV/;
$_ = roman2int($_) for @x;
print join("-", @x);

ESPECIFICACIÓN

Los números romanos se pueden describir utilizando la siguiente fórmula tipo BNF:

a   = I{1,3}
b   = V\a?|IV|\a
e   = X{1,3}\b?|X{0,3}IX|\b
ee  = IX|\b
f   = L\e?|XL\ee?|\e
g   = C{1,3}\f?|C{0,3}XC\ee?|\f
gg  = XC\ee?|\f
h   = D\g?|CD\gg?|\g
j   = M{1,3}\h?|M{0,3}CM\gg?|\h

REFERENCIAS
