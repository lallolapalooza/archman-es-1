NOMBRE

Text::Query::Build - Clase base para constructores de consultas

SINOPSIS

package Text::Query::BuildMy;
use Text::Query::Build;

use vars qw(@ISA);
@ISA = qw(Text::Query::Build);

DESCRIPCIÓN

Este módulo proporciona una clase base virtual para constructores de consultas.

Los constructores de consultas son llamados por la lógica del analizador. Un conjunto dado de funciones es proporcionado por el constructor para que coincida con una lógica Booleana. Todos los métodos devuelven un escalar correspondiente al código que realiza las opciones especificadas.

Los parámetros Q1 y Q2 son del mismo tipo de escalar que los valores de retorno.

MÉTODOS

matchstring()
Devuelve una cadena que representa la última expresión construida. Dos expresiones idénticas deberían generar la misma cadena. Esto es para fines de prueba.

MÉTODOS DE GENERACIÓN DE CÓDIGO

build_init()
Se llama antes de construir la expresión. Una oportunidad para inicializar los datos del objeto.
build_final_expression(Q1)
Realiza cualquier procesamiento final para generar código que coincida con una expresión de nivel superior. El valor de retorno NO es necesariamente de un tipo que pueda pasarse a los otros métodos de generación de código.
build_expression(Q1,Q2)
Genera código para que coincida con "Q1" O "Q2"
build_expression_finish(Q1)
Genera cualquier código necesario para encerrar una expresión.
build_conj(Q1,Q2,F)
Genera código necesario para que coincida con "Q1" Y "Q2". F será verdadero si esta es la primera vez que se llama a este método en una secuencia de varias conjunciones.
build_near(Q1,Q2)
Genera código necesario para que coincida con "Q1" CERCA DE "Q2".
build_concat(Q1,Q2)
Genera código necesario para que coincida con "Q1" seguido inmediatamente por "Q2".
build_negation(Q1)
Genera código necesario para que coincida con NO "Q1".
build_literal(Q1)
Genera código para que coincida con "Q1" como un literal.
build_scope_start($scope)
Genera código para entrar en el contexto de consulta $scope.
build_scope_end($scope,Q1)
Genera código necesario para que coincida con "Q1" en el contexto $scope.
build_mandatory(Q1)
Genera código para que coincida con "Q1" (piensa en + en la sintaxis de AltaVista).
build_forbiden(Q1)
Genera código para que coincida con NO "Q1" (piensa en - en la sintaxis de AltaVista).
