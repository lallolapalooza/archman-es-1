Test2::Compare(3perl) Guía de referencia para programadores de Perl Test2::Compare(3perl)

NOMBRE

Test2::Compare - Extensión de Test2 para escribir herramientas de comparación profunda.

DESCRIPCIÓN

Esta biblioteca es la fuerza impulsora detrás de herramientas de comparación profunda como Test2::Tools::Compare::is() y Test2::Tools::ClassicCompare::is_deeply().

SINOPSIS

package Test2::Tools::MyCheck;
use Test2::Compare::MyCheck;
use Test2::Compare qw/compare/;
sub MyCheck {
    my ($got, $exp, $name, @diag) = @_;
    my $ctx = context();
    my $delta = compare($got, $exp, \&convert);
    if ($delta) {
        $ctx->fail($name, $delta->diag, @diag);
    }
    else {
        $ctx->ok(1, $name);
    }
    $ctx->release;
    return !$delta;
}
sub convert {
    my $thing = shift;
    return $thing if blessed($thing) && $thing->isa('Test2::Compare::MyCheck');
    return Test2::Compare::MyCheck->new(stuff => $thing);
}

Ver Test2::Compare::Base para detalles sobre cómo escribir una comprobación personalizada.

EXPORTACIONES

$delta = compare($got, $expect, \&convert)
Esto comparará las estructuras en $got con las de $expect. La subrutina de conversión debe convertir estructuras simples dentro de $expect en comprobaciones. Si hay diferencias en las estructuras, se informarán como un árbol Test2::Compare::Delta.
$build = get_build()
Obtiene la compilación global actual, si existe.
push_build($build)
Establece la compilación global actual.
$build = pop_build($build)
Anula la compilación global actual. Esto lanzará una excepción si la compilación pasada es diferente de la actual global.
build($class, sub { ... })
Ejecuta el bloque de código proporcionado con una nueva instancia de $class como compilación actual. Devuelve la nueva compilación.
$check = convert($thing)
$check = convert($thing, $config)
Esta función de conversión es utilizada por strict_convert() y relaxed_convert() internamente. También puede ser utilizada como base para otras funciones de conversión.

Si desea utilizarla con una configuración personalizada, debe envolverla en otra subrutina, así:

sub my_convert {
    my $thing_to_convert = shift;
    return convert(
        $thing_to_convert,
        { ... }
    );
}

O la variante corta:

sub my_convert { convert($_[0], { ... }) }

Existen varias opciones de configuración, aquí están con la configuración predeterminada listada primero:

implicit_end => 1
Esta opción alterna los límites de arrays/hashes. Si es verdadera, no se permitirán claves de hash ni índices de array adicionales. Esta configuración afecta a los objetos de comparación generados y a los que se pasan.
use_regex => 1
Esta opción alterna la coincidencia de expresiones regulares. Cuando es verdadera (predeterminada), las expresiones regulares se convierten en comprobaciones de tal manera que los valores deben coincidir con la expresión regular. Cuando es falsa, las expresiones regulares se comparan para ver si son expresiones regulares idénticas.
use_code => 0
Esta opción alterna la coincidencia de código. Cuando es falsa (predeterminada), las referencias de subrutina en las estructuras deben ser la misma referencia de subrutina especificada. Cuando es verdadera, las referencias de subrutina se ejecutarán para verificar el valor.
$check = strict_convert($thing)
Convierte $thing en un objeto Test2::Compare::*. Esto se comportará estrictamente, lo que significa que utiliza esta configuración:
implicit_end => 1
Se comprobarán los límites de los arrays cuando este objeto se utilice en una comparación. No se pueden presentar claves de hash inesperadas.
use_code => 0
Las referencias de subrutina se compararán como referencias (es decir, ¿son estas referencias de subrutina la misma referencia?).
use_regex => 0
Las expresiones regulares se compararán directamente (es decir, ¿son las expresiones regulares las mismas?).
$compare = relaxed_convert($thing)
Convierte $thing en un objeto Test2::Compare::*. Esto será relajado, lo que significa que utiliza esta configuración:
implicit_end => 0
No se comprobarán los límites de los arrays cuando este objeto se utilice en una comparación. Se pueden presentar claves de hash inesperadas.
use_code => 1
Las referencias de subrutina se ejecutarán para verificar un valor.
use_regex => 1
Los valores se comprobarán con las expresiones regulares proporcionadas.

ESCRIBIR UNA VARIANTE DE IS/LIKE

use Test2::Compare qw/compare convert/;
sub my_like($$;$@) {
    my ($got, $exp, $name, @diag) = @_;
    my $ctx = context();
    # Un convertidor personalizado que hace lo mismo que el utilizado por like()
    my $convert = sub {
        my $thing = shift;
        return convert(
            $thing,
            {
                implicit_end => 0,
                use_code     => 1,
                use_regex    => 1,
            }
        );
    };
    my $delta = compare($got, $exp, $convert);
    if ($delta) {
        $ctx->fail($name, $delta->diag, @diag);
    }
    else {
        $ctx->ok(1, $name);
    }
    $ctx->release;
    return !$delta;
}

El trabajo de una herramienta de comparación lo realizan 3 entidades:

compare()
La función compare() toma la estructura que obtuvo, la especificación que desea verificar y una subrutina "\&convert" que convertirá cualquier cosa que no sea una instancia de una subclase de Test2::Compare::Base en una de ellas.

Esta herramienta utilizará la función "\&convert" en la especificación y luego producirá una estructura Test2::Compare::Delta que describa todas las formas en que la estructura que obtuvo se desvía de la especificación.

\&convert~2
Convierte cualquier cosa que no sea una instancia de una subclase de Test2::Compare::Base y la convierte en una. Los objetos que produce son capaces de verificar que una estructura coincide con una especificación.
$delta~2
Finalmente se devuelve una instancia de Test2::Compare::Delta. Este objeto representa todas las formas en que la estructura que obtuvo se desvió de la especificación. El delta es un árbol y puede contener deltas hijos para estructuras anidadas.

El delta es capaz de renderizarse a sí mismo como una tabla; use "@lines = $delta->diag" para obtener la tabla (las líneas en @lines no terminarán con "\n").

La función convert() proporcionada por este paquete contiene todo el comportamiento de especificación de like() e is(). Está destinada a ser envuelta en una subrutina que pase un hash de configuración, lo que le permite controlar el comportamiento.

Es libre de escribir su propia función "$check = compare($thing)", solo necesita aceptar un solo argumento y producir una única instancia de una subclase de Test2::Compare::Base.
