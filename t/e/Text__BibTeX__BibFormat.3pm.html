NOMBRE

Text::BibTeX::BibFormat - formatea entradas bibliográficas

SINOPSIS

# Suponiendo que $entry proviene de una base de datos con estructura 'Bib'
# (es decir, que está bendecida en la clase BibEntry, que hereda
# el método format de BibFormat):
@bloques = $entry->format;

DESCRIPCIÓN

La clase "Text::BibTeX::BibFormat" es una clase base de "Text::BibTeX::BibEntry" para formatear entradas bibliográficas. Por lo tanto, realiza el trabajo principal de cualquier programa que pretenda suplantar a BibTeX en sí; el otro trabajo importante (ordenar) es manejado por su clase compañera, "Text::BibTeX::BibSort".

"BibFormat" (el prefijo "Text::BibTeX" se omitirá por brevedad) presta atención a casi todas las opciones de estructura descritas en Text::BibTeX::Bib; solo ignora aquellas que cubren la ordenación, actualmente solo "sortby". En particular, todas las opciones de "markup" controlan qué lenguaje se genera por "BibFormat"; si ninguna de esas opciones se establece, generará texto plano sin marcas.

El único método en la interfaz documentada de "BibFormat" (hasta ahora) es "format". (La clase define muchos otros métodos, pero estos no deberían ser necesarios para usuarios externos, por lo que no están documentados y están sujetos a cambios).

MÉTODOS

format ()
Formatea una única entrada para su inclusión en la bibliografía de algún documento. El procesamiento exacto realizado depende en gran medida del tipo de entrada y de los campos presentes; en general, deberías poder unir las salidas de "format" para crear un único párrafo para incluir en un documento en el lenguaje de marcado con el que estés trabajando.

Devuelve una lista de "bloques", que pueden ser unidos como frases (para una bibliografía "densa" tradicional) o impresos en líneas separadas (para un formato de bibliografía "abierta"). Cada bloque es una referencia a una lista de frases; las frases deben unirse con un punto intermedio. Cada frase es una cadena simple o una lista de cláusulas; las cláusulas deben unirse con una coma intermedia. Cada cláusula es simplemente una cadena simple.

Consulta el código fuente de "btformat" para ver un ejemplo de cómo utilizar la salida de "format".

VER TAMBIÉN
