Test2::Tools::Mock(3perl) Guía de referencia del programador de Perl Test2::Tools::Mock(3perl)

NOMBRE

Test2::Tools::Mock - Mocking de clases/instancias para Test2.

DESCRIPCIÓN

El mocking es a menudo una parte esencial de las pruebas. Esta biblioteca cubre algunas de las necesidades de mocking más comunes. Este plugin está fuertemente influenciado por Mock::Quick, pero con una API mejorada. Este plugin también está diseñado para funcionar bien con otros plugins de maneras que Mock::Quick no podría.

SINOPSIS

my $mock = mock 'Some::Class' => (
    track => $BOOL, # Habilitar/Deshabilitar el seguimiento en las subs definidas a continuación
    add => [
        new_method => sub { ... },
    ],
    override => [
        replace_method => sub { ... },
    ],
    set => [
        replace_or_inject => sub { ... },
    ],
    track => $bool, # Habilitar/deshabilitar el seguimiento nuevamente para afectar los mocks creados después de este punto
    ..., # Las claves de argumento pueden repetirse
);
Some::Class->new_method();        # Llama al método recién inyectado
Some::Class->replace_method();    # Llama a nuestro método de reemplazo.
$mock->override(...) # Sobrescribir algunos más
$mock = undef; # Deshace todo el mocking, restaurando todos los métodos originales.
my $simple_mock = mock {} => (
    add => [
        is_active => sub { ... }
    ]
);
$simple_mock->is_active();        # Llama a nuestro método recién mockeado.

EXPORTACIONES

POR DEFECTO

mock
Esta es una función integral que delega a uno de los otros métodos dependiendo de cómo se utilice. Si no se siente cómodo con una función que tiene muchos comportamientos potenciales, puede usar una de las otras funciones directamente.
@mocks = mocked($object)
@mocks = mocked($class)
Verifica si un objeto o clase está mockeado. Si está mockeado, se devolverán los objetos $mock (Test2::Mock).
$mock = mock $class => ( ... );
$mock = mock $instance => ( ... )
$mock = mock 'class', $class => ( ... )
Estas formas delegan a mock_class() para mockear un paquete. La tercera forma es ser explícito sobre qué tipo de mocking desea.
$obj = mock()
$obj = mock { ... }
$obj = mock 'obj', ...;
Estas formas delegan a mock_obj() para crear instancias de paquetes anónimos donde los métodos se vivifican según sea necesario.
mock $mock => sub { ... }
mock $method => ( ... )
Estas formas van juntas, la primera forma establecerá $mock como la compilación de mock actual, luego ejecutará la subrutina. Dentro de la subrutina puede declarar especificaciones de mock usando la segunda forma. La primera forma delega a mock_build().

La segunda forma llama al método especificado en la compilación actual. Esta segunda forma delega a mock_do().

POR SOLICITUD

DEFINICIÓN DE MOCKS

$obj = mock_obj( ... )
$obj = mock_obj { ... } => ( ... )
$obj = mock_obj sub { ... }
$obj = mock_obj { ... } => sub { ... }
Este método le permite generar rápidamente un objeto bendecido. El objeto será una instancia de un nombre de paquete generado aleatoriamente. Los métodos se vivificarán como accesores de lectura/escritura según sea necesario.

Los argumentos pueden ser cualquier método disponible para Test2::Mock seguido de un argumento. Si el primer argumento es un hashref, se bendecirá como su nuevo objeto.

Si proporciona una referencia de código en lugar de pares clave/valor, se ejecutará la referencia de código para construir el mock. (Ver la sección "CONSTRUCCIÓN DE MOCKS").

$mock = mock_class $class => ( ... )
$mock = mock_class $instance => ( ... )
$mock = mock_class ... => sub { ... }
Esto creará una nueva instancia de Test2::Mock para controlar el paquete especificado. Si le da una referencia bendecida, utilizará la clase de la instancia.

Los argumentos pueden ser cualquier método disponible para Test2::Mock seguido de un argumento. Si el primer argumento es un hashref, se bendecirá como su nuevo objeto.

Si proporciona una referencia de código en lugar de pares clave/valor, se ejecutará la referencia de código para construir el mock. (Ver la sección "CONSTRUCCIÓN DE MOCKS").

CONSTRUCCIÓN DE MOCKS

mock_build $mock => sub { ... }
Establece $mock como la compilación actual, luego ejecuta el código especificado. $mock ya no será la compilación actual cuando la subrutina finalice.
$mock = mock_building()
Obtiene el objeto $mock de compilación actual.
mock_do $method => $args
Ejecuta el método especificado en el objeto de compilación actual.

GENERADORES DE MÉTODOS

$sub = mock_accessor $field
Genera un accesorio de lectura/escritura para el campo especificado. Esto generará una subrutina como la siguiente: 
$sub = sub {
    my $self = shift;
    ($self->{$field}) = @_ if @_;
    return $self->{$field};
};
$sub = mock_getter $field
Genera un accesorio de solo lectura para el campo especificado. Esto generará una subrutina como la siguiente: 
$sub = sub {
    my $self = shift;
    return $self->{$field};
};
$sub = mock_setter $field
Genera un accesorio de escritura para el campo especificado. Esto generará una subrutina como la siguiente: 
$sub = sub {
    my $self = shift;
    ($self->{$field}) = @_;
};
%pairs = mock_accessors(qw/name1 name2 name3/)
Genera varios accesorios de lectura/escritura a la vez, devuelve pares clave/valor donde la clave es el nombre del campo y el valor es la referencia de código.
%pairs = mock_getters(qw/name1 name2 name3/)
Genera varios accesorios de solo lectura a la vez, devuelve pares clave/valor donde la clave es el nombre del campo y el valor es la referencia de código.
%pairs = mock_setters(qw/name1 name2 name3/)
Genera varios accesorios de escritura a la vez, devuelve pares clave/valor donde la clave es el nombre del campo y el valor es la referencia de código.

OBJETOS DE CONTROL MOCK

my $mock = mock(...);

Los objetos Mock son instancias de Test2::Mock. Consulte la documentación de esta clase para conocer sus métodos.
