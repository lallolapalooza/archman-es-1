Test2::EventFacet::Info(3perl) Guía de Referencia del Programador de Perl Test2::EventFacet::Info(3perl)

NOMBRE

Test2::EventFacet::Info - Faceta para información que podría interesar a un desarrollador.

DESCRIPCIÓN

Esta faceta representa mensajes destinados a humanos que les ayudarán a comprender un resultado o a diagnosticar un fallo.

NOTAS

Esta faceta aparece en una lista en lugar de ser un único elemento.

CAMPOS

$cadena_o_estructura = $info->{details}
$cadena_o_estructura = $info->details()
Cadena legible por humanos o estructura de datos, esta es la información a mostrar. Los formateadores son libres de representar las estructuras como deseen. Puede contener un objeto bendecido.

Si el atributo "table" (ver más abajo) está establecido, un renderizador puede optar por mostrar la tabla en lugar de los detalles.

$estructura = $info->{table}
$estructura = $info->table()
Si los datos que la faceta "info" necesita transmitir se pueden representar como una tabla, los datos pueden colocarse en este atributo en una forma más cruda para una mejor visualización. Los datos también deben representarse en el atributo "details" para renderizadores que no soporten la representación directa de tablas.

La estructura de la tabla:

my %tabla = {
    header => [ 'encabezado columna 1', 'encabezado columna 2', ... ], # Opcional
    rows => [
        ['fila 1 columna 1', 'fila 1, columna 2', ... ],
        ['fila 2 columna 1', 'fila 2, columna 2', ... ],
        ...
    ],
    # Permitir al renderizador ocultar columnas vacías si es verdadero, Opcional
    collapse => $BOOL,
    # Enumerar por nombre o número las columnas que nunca deben colapsarse
    no_collapse => \@LIST,
}
$cadena_corta = $info->{tag}
$cadena_corta = $info->tag()
Etiqueta corta para categorizar la información. Normalmente tiene 10 caracteres o menos; los formateadores pueden truncar etiquetas más largas.
$booleano = $info->{debug}
$booleano = $info->debug()
Establece esto a verdadero si el mensaje es crítico o explica un fallo. Esta es información que los formateadores deberían mostrar incluso en modos menos verbosos.

Cuando es falso, la información no se considera crítica y puede no renderizarse en modos menos verbosos.

$booleano = $info->{important}
$booleano = $info->important
Esto debe establecerse para mensajes que no son de depuración pero que son lo suficientemente importantes como para mostrarlos cuando un formateador está en modo silencioso. Un formateador debería enviar estos a STDOUT, no a STDERR, pero debería mostrarlos incluso en modo no verboso.
