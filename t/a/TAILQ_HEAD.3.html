DESCRIPCIÓN

Estas macros definen y operan sobre colas dobles enlazadas.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola se encabeza con una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la cola. Se pueden agregar nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRE_CABEZA, TIPO) cabeza;

donde struct NOMBRE_CABEZA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct NOMBRE_CABEZA *puntero_cabeza;

(Los nombres cabeza y puntero_cabeza son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

TAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabeza.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola. cabeza.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elemento antes del elemento elemento_lista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elemento_lista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior en la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento en la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabeza en dirección hacia adelante, asignando cada elemento en su turno a variable. variable se establece a NULL si el bucle termina normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabeza en dirección inversa, asignando cada elemento en su turno a variable.

Eliminación

TAILQ_REMOVE() elimina el elemento elemento de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola cabeza.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que variable sea eliminada o liberada dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación al permitir que variable sea eliminada de la lista y liberada de forma segura desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    TAILQ_ENTRY(entrada) entradas;             /* Cola doble */
};
TAILQ_HEAD(cola_doble_cabeza, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cola_doble_cabeza cabeza;                   /* Cabeza de cola doble */
    int i;
    TAILQ_INIT(&cabeza);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    TAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    TAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    n3 = malloc(sizeof(struct entrada));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entradas);
    TAILQ_REMOVE(&cabeza, n2, entradas);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &cabeza, entradas)
        np->datos = i++;
                                            /* Recorrido inverso */
    TAILQ_FOREACH_REVERSE(np, &cabeza, cola_doble_cabeza, entradas)
        printf("%i\n", np->datos);
                                            /* Eliminación de la cola doble */
    n1

NAME

TAILQ_HEAD, TAILQ_INIT, TAILQ_EMPTY, TAILQ_FIRST, TAILQ_NEXT, TAILQ_PREV, TAILQ_LAST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_INSERT_HEAD, TAILQ_INSERT_BEFORE, TAILQ_INSERT_AFTER, TAILQ_INSERT_TAIL, TAILQ_REMOVE, TAILQ_REPLACE, TAILQ_SWAP - queue macros

LIBRARY

Libucb (libucb, -lucb)

SYNOPSIS 

#include <sys/queue.h>

/*
 * Structure definitions for tail queues.
 */
#define TAILQ_HEAD(name, type)                                          \
struct name {                                                           \
    struct type *tqh_first;    /* first member */                        \
    struct type **tqh_last;     /* last member */                         \
}

#define TAILQ_INIT(head)                                                \
    do {                                                                \
        (head)->tqh_first = NULL;                                       \
        *(head)->tqh_last = NULL;                                       \
    } while (0)

#define TAILQ_EMPTY(head)                                               \
    ((head)->tqh_first == NULL)

#define TAILQ_FIRST(head)                                               \
    ((head)->tqh_first)

#define TAILQ_NEXT(elm, field)                                          \
    ((elm)->field.next)

#define TAILQ_PREV(elm, type, field)                                    \
    ((elm)->field.prev)

#define TAILQ_LAST(head, name)                                          \
    (TAILQ_EMPTY(head) ? NULL :                                         \
        ((struct name *)                                                \
            ((char *)((head)->tqh_last) - offsetof(struct name, field.prev))) \
    )

#define TAILQ_FOREACH(var, head, field)                                 \
    for ((var) = TAILQ_FIRST((head));                                   \
        (var);                                                          \
        (var) = TAILQ_NEXT((var), field))

#define TAILQ_FOREACH_REVERSE(var, head, name, field)                   \
    for ((var) = TAILQ_LAST((head), name);                              \
        (var);                                                          \
        (var) = TAILQ_PREV((var), name, field))

#define TAILQ_INSERT_HEAD(head, elm, field)                             \
    do {                                                                \
        (elm)->field.next = (head)->tqh_first;                         \
        if (!TAILQ_EMPTY(head))                                         \
            (head)->tqh_first->field.prev = &(elm)->field.next;       \
        else                                                            \
            *(head)->tqh_last = &(elm)->field.next;                   \
        (head)->tqh_first = (elm);                                      \
        (elm)->field.prev = NULL;                                       \
    } while (0)

#define TAILQ_INSERT_TAIL(head, elm, field)                             \
    do {                                                                \
        (elm)->field.next = NULL;                                       \
        (elm)->field.prev = (head)->tqh_last;                          \
        *(head)->tqh_last = &(elm)->field.next;                       \
        (head)->tqh_last = &(elm)->field.next;                        \
        (head)->tqh_first = (elm);                                      \
    } while (0)

#define TAILQ_INSERT_BEFORE(listelm, elm, field)                        \
    do {                                                                \
        (elm)->field.next = (listelm);                                  \
        if (!(elm)->field.next->field.prev)                            \
            (head)->tqh_first = (elm);                                  \
        else                                                            \
            (elm)->field.next->field.prev = &(elm)->field.next;       \
        (elm)->field.prev = (elm)->field.next->field.prev;              \
        (elm)->field.next = (elm)->field.next;                          \
        *(elm)->field.next->field.prev = &(elm)->field.next;          \
    } while (0)

#define TAILQ_INSERT_AFTER(listelm, elm, field)                         \
    do {                                                                \
        (elm)->field.next = (listelm)->field.next;                      \
        if ((elm)->field.next != NULL)                                  \
            (elm)->field.next->field.prev = &(elm)->field.next;       \
        else                                                            \
            (head)->tqh_last = &(elm)->field.next;                    \
        (elm)->field.prev = &(listelm)->field.next;                     \
        (listelm)->field.next = (elm);                                  \
    } while (0)

#define TAILQ_REMOVE(head, elm, field)                                  \
    do {                                                                \
        if ((elm)->field.next != NULL)                                  \
            (elm)->field.next->field.prev = (elm)->field.prev;          \
        else                                                            \
            (head)->tqh_last = (elm)->field.prev;                       \
        *(elm)->field.prev = (elm)->field.next;                         \
        if ((elm) == (head)->tqh_first)                                 \
            (head)->tqh_first = (elm)->field.next;                      \
    } while (0)

#define TAILQ_REPLACE(head, oldelm, newelm, field)                      \
    do {                                                                \
        if (((newelm)->field.next = (oldelm)->field.next) != NULL)      \
            (newelm)->field.next->field.prev = &(newelm)->field.next;\
        else                                                            \
            (head)->tqh_last = &(newelm)->field.next;                 \
        (newelm)->field.prev = (oldelm)->field.prev;                    \
        *(newelm)->field.prev = &(newelm)->field.next;                \
        if ((oldelm) == (head)->tqh_first)                              \
            (head)->tqh_first = (newelm);                               \
    } while (0)

#define TAILQ_SWAP(head1, head2, type, field)                           \
    do {                                                                \
        struct type *tmp;                                               \
        tmp = (head1)->tqh_first;                                       \
        (head1)->tqh_first = (head2)->tqh_first;                        \
        (head2)->tqh_first = tmp;                                       \
        tmp = (head1)->tqh_last;                                        \
        (head1)->tqh_last = (head2)->tqh_last;                          \
        (head2)->tqh_last = tmp;                                        \
        if (((head1)->tqh_first) != NULL)                               \
            (head1)->tqh_first->field.prev = &(head1)->tqh_first;     \
        if (((head2)->tqh_first) != NULL)                               \
            (head2)->tqh_first->field.prev = &(head2)->tqh_first;     \
    } while (0)

DESCRIPTION

These macros provide a facility to define and manipulate tail queues. A tail queue is a doubly linked list where pointers to the first and last elements are maintained. This allows for efficient insertion and deletion at both ends of the queue.

To use these macros, you must first define a structure that contains a `TAILQ_HEAD` member. This structure will represent the queue itself. 

struct my_node {
    int data;
    TAILQ_ENTRY(my_node) link; /* Name of the queue entry */
};

struct my_queue {
    TAILQ_HEAD(my_queue_head, my_node) head; /* Name of the queue head */
};

The `TAILQ_HEAD` macro defines a structure that holds pointers to the first and last elements of the queue. The first argument is the name of the queue head structure, and the second argument is the type of the elements in the queue.

The `TAILQ_ENTRY` macro defines the structure that will be used within each element of the queue. This structure contains `next` and `prev` pointers that link the elements together. The argument to `TAILQ_ENTRY` is the type name of the element.

The following macros are provided for manipulating tail queues:

TAILQ_INIT(head)
Initializes the tail queue pointed to by `head`. The queue will be empty.
TAILQ_EMPTY(head)
Returns true if the tail queue pointed to by `head` is empty, false otherwise.
TAILQ_FIRST(head)
Returns a pointer to the first element in the tail queue pointed to by `head`. Returns NULL if the queue is empty.
TAILQ_NEXT(elm, field)
Returns a pointer to the next element in the tail queue after the element pointed to by `elm`. `field` is the name of the tail queue entry member within the element structure.
TAILQ_PREV(elm, type, field)
Returns a pointer to the previous element in the tail queue before the element pointed to by `elm`. `type` is the name of the element type, and `field` is the name of the tail queue entry member within the element structure.
TAILQ_LAST(head, name)
Returns a pointer to the last element in the tail queue pointed to by `head`. `name` is the name of the element type. Returns NULL if the queue is empty.
TAILQ_FOREACH(var, head, field)
A macro for iterating over the elements in the tail queue in forward order. `var` is the loop variable, `head` is the queue head, and `field` is the name of the tail queue entry member within the element structure.
TAILQ_FOREACH_REVERSE(var, head, name, field)
A macro for iterating over the elements in the tail queue in reverse order. `var` is the loop variable, `head` is the queue head, `name` is the name of the element type, and `field` is the name of the tail queue entry member within the element structure.
TAILQ_INSERT_HEAD(head, elm, field)
Inserts the element pointed to by `elm` at the head of the tail queue pointed to by `head`. `field` is the name of the tail queue entry member within the element structure.
TAILQ_INSERT_TAIL(head, elm, field)
Inserts the element pointed to by `elm` at the tail of the tail queue pointed to by `head`. `field` is the name of the tail queue entry member within the element structure.
TAILQ_INSERT_BEFORE(listelm, elm, field)
Inserts the element pointed to by `elm` before the element pointed to by `listelm`. `field` is the name of the tail queue entry member within the element structure.
TAILQ_INSERT_AFTER(listelm, elm, field)
Inserts the element pointed to by `elm` after the element pointed to by `listelm`. `field` is the name of the tail queue entry member within the element structure.
TAILQ_REMOVE(head, elm, field)
Removes the element pointed to by `elm` from the tail queue pointed to by `head`. `field` is the name of the tail queue entry member within the element structure.
TAILQ_REPLACE(head, oldelm, newelm, field)
Replaces the element pointed to by `oldelm` with the element pointed to by `newelm` in the tail queue pointed to by `head`. `field` is the name of the tail queue entry member within the element structure.
TAILQ_SWAP(head1, head2, type, field)
Swaps the contents of the two tail queues pointed to by `head1` and `head2`. `type` is the name of the element type, and `field` is the name of the tail queue entry member within the element structure.

RETURN VALUE

None of these macros return a value, except for TAILQ_EMPTY, TAILQ_FIRST, TAILQ_NEXT, TAILQ_PREV, and TAILQ_LAST, which return pointers to queue elements or NULL.

STANDARDS

These macros are derived from BSD Unix.

HISTORY

The tail queue macros first appeared in FreeBSD 2.2.

CAVEATS

When using TAILQ_FOREACH or TAILQ_FOREACH_REVERSE, if you modify the queue by adding or removing elements, you may get unexpected results. It is safer to use the other queue manipulation macros within the loop, or to break out of the loop before modifying the queue.

The `TAILQ_INSERT_BEFORE` macro requires the `head` of the list to be available.

EXAMPLES

The following example demonstrates how to use the tail queue macros to create and manipulate a queue of integers. 

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    TAILQ_ENTRY(node) entries;
};

int
main(void)
{
    struct node *n1, *n2;
    struct {
        TAILQ_HEAD(my_list_head, node) head;
    } my_list;

    TAILQ_INIT(&my_list.head);

    /* Add some nodes to the queue */
    n1 = malloc(sizeof(*n1));
    n1->data = 10;
    TAILQ_INSERT_TAIL(&my_list.head, n1, entries);

    n2 = malloc(sizeof(*n2));
    n2->data = 20;
    TAILQ_INSERT_TAIL(&my_list.head, n2, entries);

    /* Iterate over the queue */
    printf("Queue contents:\n");
    TAILQ_FOREACH(n1, &my_list.head, entries) {
        printf("data = %d\n", n1->data);
    }

    /* Remove the first node */
    n1 = TAILQ_FIRST(&my_list.head);
    TAILQ_REMOVE(&my_list.head, n1, entries);
    free(n1);

    /* Add a node to the head */
    n1 = malloc(sizeof(*n1));
    n1->data = 5;
    TAILQ_INSERT_HEAD(&my_list.head, n1, entries);

    /* Iterate over the queue in reverse */
    printf("\nQueue contents (reverse):\n");
    TAILQ_FOREACH_REVERSE(n1, &my_list.head, my_list_head, entries) {
        printf("data = %d\n", n1->data);
    }

    /* Free all remaining nodes */
    n1 = TAILQ_FIRST(&my_list.head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&my_list.head);

    exit(EXIT_SUCCESS);
}
