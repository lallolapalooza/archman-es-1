NOMBRE

TAP::Parser::ResultFactory - Fábrica para crear objetos de salida de TAP::Parser

SINOPSIS

use TAP::Parser::ResultFactory;
my $token   = {...};
my $factory = TAP::Parser::ResultFactory->new;
my $result  = $factory->make_result( $token );

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Esta es una clase fábrica simple que devuelve una subclase de TAP::Parser::Result que representa el fragmento de datos TAP actual (generalmente una sola línea). Es utilizada principalmente por TAP::Parser::Grammar. A menos que estés creando una subclase, probablemente no necesitarás usar este módulo directamente.

MÉTODOS

Métodos de Clase

"new"

Crea una nueva clase fábrica. *Nota:* Actualmente no necesitas instanciar una fábrica para poder usarla.

"make_result"

Devuelve una instancia de la clase apropiada para el token de prueba pasado.

my $result = TAP::Parser::ResultFactory->make_result($token);

También se puede llamar como un método de instancia.

"class_for"

Toma un argumento: $type. Devuelve la clase para este $type, o causa un error con "croak".

"register_type"

Toma dos argumentos: $type, $class

Esto te permite sobrescribir un tipo existente con tu propio tipo personalizado, o registrar un tipo completamente nuevo, por ejemplo:

# crear un tipo de resultado personalizado:
package MyResult;
use strict;
use base 'TAP::Parser::Result';
# registrar con la fábrica:
TAP::Parser::ResultFactory->register_type( 'my_type' => __PACKAGE__ );
# usarlo:
my $r = TAP::Parser::ResultFactory->( { type => 'my_type' } );

Tu tipo personalizado debería ser recogido automáticamente por TAP::Parser.

CREACIÓN DE SUBCLASES

Por favor, consulta "SUBCLASSING" en TAP::Parser para una visión general de la creación de subclases.

Hay algunas cosas a tener en cuenta al crear tu propia "ResultFactory":

1.
La fábrica en sí nunca se instancia (esto *podría* cambiar en el futuro). Esto significa que "_initialize" nunca se llama.
2.
"TAP::Parser::Result->new" nunca se llama, los $tokens son re-bautizados (reblessed). ¡Esto *cambiará* en una versión futura!
3.
Las subclases de TAP::Parser::Result se registrarán a sí mismas con TAP::Parser::ResultFactory directamente: 
package MyFooResult;
TAP::Parser::ResultFactory->register_type( foo => __PACKAGE__ );

Por supuesto, depende de ti decidir si ignorarlas o no.

Ejemplo

package MyResultFactory;
use strict;
use MyResult;
use base 'TAP::Parser::ResultFactory';
# forzar que todos los resultados sean 'MyResult'
sub class_for {
  return 'MyResult';
}
1;
