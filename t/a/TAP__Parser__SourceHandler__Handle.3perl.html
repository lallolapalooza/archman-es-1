TAP::Parser::SourceHandler::Handle(3perl) Guía de referencia del programador de Perl TAP::Parser::SourceHandler::Handle(3perl)

NOMBRE

TAP::Parser::SourceHandler::Handle - Transmite TAP desde un IO::Handle o un GLOB.

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::Executable;
my $source = TAP::Parser::Source->new->raw( \*TAP_FILE );
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::Handle';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPCIÓN

Esta es una clase TAP::Parser::SourceHandler para TAP crudo almacenado en un IO Handle. Tiene 2 trabajos:

1. Determinar si el TAP::Parser::Source que recibe es un IO::Handle o un GLOB que contiene salida TAP cruda ("can_handle").

2. Crea un iterador para IO::Handle y globs ("make_iterator").

A menos que estés escribiendo un plugin o una subclase de TAP::Parser, probablemente no necesitarás usar este módulo directamente.

MÉTODOS

Métodos de clase

"can_handle"

my $vote = $class->can_handle( $source );

Emite los siguientes votos:

0.9 if $source es un IO::Handle
0.8 si $source es un glob

"make_iterator"

my $iterator = $class->make_iterator( $source );

Devuelve un nuevo TAP::Parser::Iterator::Stream para la fuente.

"iterator_class"

La clase del iterador a usar, sobrescribir si estás creando una subclase. Por defecto es TAP::Parser::Iterator::Stream.

SUBCLASES

Por favor, consulta "SUBCLASSING" en TAP::Parser para una descripción general de la creación de subclases.
