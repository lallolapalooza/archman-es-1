DESCRIPCIÓN

Estas macros definen y operan sobre colas dobles enlazadas de cola.

En las definiciones de macro, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro TAILQ_HEAD().

Creación

Una cola de cola se encabeza mediante una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están doblemente enlazados para que se pueda eliminar un elemento arbitrario sin recorrer la cola. Se pueden añadir nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura que se va a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola. Más tarde, se puede declarar un puntero a la cabecera de la cola como:


struct NOMBRE_CABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario).

TAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

TAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabecera.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola. cabecera.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elem_lista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior de la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabecera en la dirección hacia adelante, asignando cada elemento a su vez a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabecera en la dirección inversa, asignando cada elemento a su vez a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elem de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola cabecera.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que var se elimine o libere dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación al permitir que var se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola de cola */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Cabecera de cola de cola */
    int i;
    TAILQ_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido inverso */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de TailQ */
    n1

DESCRIPTION

These macros provide an implementation of a tail queue, a doubly linked list that allows for efficient insertion and deletion at both the head and the tail of the list. A tail queue is especially useful when implementing queues or stacks.

A tail queue is defined by a head structure, declared using the TAILQ_HEAD macro. The head structure contains pointers to the first and last elements of the queue, and optionally a count of the number of elements.

TAILQ_HEAD(tailhead, elem);

Here, tailhead is the name of the structure that will be used as the head of the queue, and elem is the type of the elements in the queue. The structure will be named struct tailhead.

Each element in the queue must contain a tail queue entry, declared using the TAILQ_ENTRY macro. The entry structure contains pointers to the next and previous elements in the queue.

struct elem {
    struct tailhead list_entries;
    int data;
};

Here, list_entries is the name of the tail queue entry field within the elem structure.

The following macros are available:

  • TAILQ_INIT(headp);

    Initializes the tail queue specified by headp. This macro should be used to initialize any tail queue head before its first use.

  • TAILQ_INSERT_HEAD(headp, elm, field);

    Inserts the element elm at the head of the tail queue headp. The field argument is the name of the tail queue entry field in the element structure.

  • TAILQ_INSERT_TAIL(headp, elm, field);

    Inserts the element elm at the tail of the tail queue headp.

  • TAILQ_INSERT_BEFORE(listelm, elm, field);

    Inserts the element elm before the element listelm in the tail queue. The head pointer is not needed.

  • TAILQ_INSERT_AFTER(headp, listelm, elm, field);

    Inserts the element elm after the element listelm in the tail queue headp. The head pointer is needed.

  • TAILQ_REMOVE(headp, elm, field);

    Removes the element elm from the tail queue headp. The field argument is the name of the tail queue entry field in the element structure.

  • TAILQ_REPLACE(headp, elm, newelm, field);

    Replaces the element elm with the element newelm in the tail queue headp. The field argument is the name of the tail queue entry field in the element structure.

  • TAILQ_GETNEXT(elm, field);

    Returns a pointer to the next element in the tail queue after elm. This is equivalent to TAILQ_NEXT.

  • TAILQ_NEXT(elm, field);

    Returns a pointer to the next element in the tail queue after elm. If elm is the last element, it returns NULL.

  • TAILQ_PREV(elm, field);

    Returns a pointer to the previous element in the tail queue before elm. If elm is the first element, it returns NULL.

  • TAILQ_LAST(headp, field);

    Returns a pointer to the last element in the tail queue headp. If the queue is empty, it returns NULL.

  • TAILQ_FOREACH(var, headp, field);

    Iterates over the tail queue headp from the first element to the last. In each iteration, the current element is assigned to var. The field argument is the name of the tail queue entry field in the element structure.

  • TAILQ_FOREACH_SAFE(var, next, headp, field);

    Similar to TAILQ_FOREACH, but provides a safe way to iterate over the list when elements might be removed during iteration. The next argument is used to store the pointer to the next element before the current element is processed.

  • TAILQ_FOREACH_REVERSE(var, headp, field);

    Iterates over the tail queue headp from the last element to the first. In each iteration, the current element is assigned to var.

  • TAILQ_FOREACH_REVERSE_SAFE(var, prev, headp, field);

    Similar to TAILQ_FOREACH_REVERSE, but provides a safe way to iterate over the list when elements might be removed during iteration. The prev argument is used to store the pointer to the previous element before the current element is processed.

  • TAILQ_FIRST(headp);

    Returns a pointer to the first element in the tail queue headp. If the queue is empty, it returns NULL.

  • TAILQ_SWAP(head1, head2, field);

    Swaps the contents of the two tail queues head1 and head2. The field argument is the name of the tail queue entry field in the element structure.

RETURN VALUE

The TAILQ_FIRST, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, and TAILQ_GETNEXT macros return pointers to the respective elements in the queue, or NULL if the queue is empty or the requested element does not exist.

STANDARDS

The TAILQ_* macros are compatible with the BSD operating systems.

HISTORY

The tail queue macros first appeared in FreeBSD 3.0.

CAVEATS

When using TAILQ_FOREACH or TAILQ_FOREACH_REVERSE, modifying the list (adding or removing elements) while iterating may lead to unexpected behavior. Use TAILQ_FOREACH_SAFE or TAILQ_FOREACH_REVERSE_SAFE for safe iteration.

The TAILQ_INSERT_BEFORE and TAILQ_INSERT_AFTER macros require a pointer to an existing element in the list, not the head pointer. Care must be taken to ensure that the provided list element is actually part of the list.

EXAMPLES

The following example demonstrates the usage of tail queue macros to manage a list of integers.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_item {
    int data;
    TAILQ_ENTRY(my_item) entries;
};

int
main(void)
{
    struct my_item *item, *next_item;
    TAILQ_HEAD(my_list_head, my_item) head;

    TAILQ_INIT(&head);

    /* Add items to the tail queue */
    item = malloc(sizeof(*item));
    item->data = 10;
    TAILQ_INSERT_TAIL(&head, item, entries);

    item = malloc(sizeof(*item));
    item->data = 20;
    TAILQ_INSERT_TAIL(&head, item, entries);

    item = malloc(sizeof(*item));
    item->data = 30;
    TAILQ_INSERT_HEAD(&head, item, entries);

    /* Iterate through the tail queue */
    printf("Forward iteration:\n");
    TAILQ_FOREACH(item, &head, entries) {
        printf("Item data: %d\n", item->data);
    }

    /* Iterate backwards through the tail queue */
    printf("\nBackward iteration:\n");
    TAILQ_FOREACH(item, &head, entries) { /* Need to get last element first */ }
    if (item) {
        do {
            printf("Item data: %d\n", item->data);
            item = TAILQ_PREV(item, entries);
        } while (item != NULL);
    }


    /* Remove an item */
    item = TAILQ_FIRST(&head);
    if (item != NULL) {
        TAILQ_REMOVE(&head, item, entries);
        free(item);
    }

    printf("\nAfter removing the first item:\n");
    TAILQ_FOREACH(item, &head, entries) {
        printf("Item data: %d\n", item->data);
    }

    /* Clear the tail queue */
    TAILQ_FOREACH_SAFE(&head, item, next_item, entries) {
        TAILQ_REMOVE(&head, item, entries);
        free(item);
    }
    TAILQ_INIT(&head);

    printf("\nQueue cleared.\n");

    return 0;
}

The code above defines a simple tail queue of my_item structures. It demonstrates inserting elements at the head and tail, iterating forwards and backwards, removing an element, and finally clearing the entire queue. The TAILQ_FOREACH_SAFE macro is used for safe removal during iteration.
