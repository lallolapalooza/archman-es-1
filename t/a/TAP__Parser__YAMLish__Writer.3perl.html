TAP::Parser::YAMLish::Writer(3perl) Guía de referencia para programadores de Perl TAP::Parser::YAMLish::Writer(3perl)

NOMBRE

TAP::Parser::YAMLish::Writer - Escribe datos YAMLish

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::YAMLish::Writer;

my $data = {
    one => 1,
    two => 2,
    three => [ 1, 2, 3 ],
};

my $yw = TAP::Parser::YAMLish::Writer->new;

# Escribir en un array...
$yw->write( $data, \@some_array );

# ...un manejador de archivo abierto...
$yw->write( $data, $some_file_handle );

# ...una cadena ...
$yw->write( $data, \$some_string );

# ...o un closure
$yw->write( $data, sub {
    my $line = shift;
    print "$line\n";
} );

DESCRIPCIÓN

Codifica un escalar, una referencia a hash o una referencia a array como YAMLish.

MÉTODOS

Métodos de clase

"new"

my $writer = TAP::Parser::YAMLish::Writer->new;

El constructor "new" crea y devuelve un objeto "TAP::Parser::YAMLish::Writer" vacío.

Métodos de instancia

"write"

$writer->write($obj, $output );

Codifica un escalar, una referencia a hash o una referencia a array como YAML.

my $writer = sub {
    my $line = shift;
    print SOMEFILE "$line\n";
};

my $data = {
    one => 1,
    two => 2,
    three => [ 1, 2, 3 ],
};

my $yw = TAP::Parser::YAMLish::Writer->new;
$yw->write( $data, $writer );

El argumento $output puede ser:

  • una referencia a un escalar al que se añadirá YAML
  • el manejador de un archivo abierto
  • una referencia a un array en el que se insertará YAML
  • una referencia de código

Si se proporciona una referencia de código, la subrutina se llamará una vez por cada línea de salida con la línea como único argumento. Las líneas pasadas no tendrán salto de línea al final.
