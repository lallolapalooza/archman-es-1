TAP::Object(3perl) Guía de referencia del programador de Perl TAP::Object(3perl)

NOMBRE

TAP::Object - Clase base que proporciona funcionalidad común a todos los módulos "TAP::*"

VERSIÓN

Versión 3.50

SINOPSIS

package TAP::Whatever;
use strict;
use base 'TAP::Object';
# Implementación de new() por TAP::Object
sub _initialize {
    my ( $self, @args) = @_;
    # inicializa tu objeto
    return $self;
}
# ... más tarde ...
my $obj = TAP::Whatever->new(@args);

DESCRIPCIÓN

"TAP::Object" proporciona un constructor predeterminado y un modelo de excepciones para todas las clases "TAP::*". Las excepciones se lanzan usando Carp.

MÉTODOS

Métodos de clase

"new"

Crea un nuevo objeto. Cualquier argumento pasado a "new" se pasará al método "_initialize". Devuelve un nuevo objeto.

Métodos de instancia

"_initialize"

Inicializa un nuevo objeto. Este método es un stub por defecto, deberías sobrescribirlo según sea apropiado.

Nota: "new" espera que devuelvas $self o que lances una excepción. Ver "_croak", y Carp.

"_croak"

Lanza una excepción usando "croak" de Carp, por ejemplo:

$self->_croak( 'por qué yo?', 'aaarrgh!' );

También puede ser llamado como un método de *clase*.

$class->_croak( 'esto también funciona' );

"_confess"

Lanza una excepción usando "confess" de Carp, por ejemplo:

$self->_confess( 'por qué yo?', 'aaarrgh!' );

También puede ser llamado como un método de *clase*.

$class->_confess( 'esto también funciona' );

"_construct"

Crea una nueva instancia de la clase especificada.

"mk_methods"

Crea getters/setters simples.

__PACKAGE__->mk_methods(@nombres_de_método);
