NOMBRE

DESCRIPCIÓN

Estas macros definen y operan sobre colas con seguimiento doblemente enlazadas.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_DE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro TAILQ_HEAD().

Creación

Una cola con seguimiento está encabezada por una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están doblemente enlazados para que se pueda eliminar un elemento arbitrario sin recorrer la cola. Se pueden añadir nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara como sigue:


TAILQ_HEAD(NOMBRE_DE_CABECERA, TIPO) cabeza;

donde struct NOMBRE_DE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola. Posteriormente, se puede declarar un puntero a la cabeza de la cola como:


struct NOMBRE_DE_CABECERA *punterocabeza;

(Los nombres cabeza y punterocabeza son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

TAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabeza.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola. cabeza.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elementolista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elementolista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior de la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabeza en la dirección hacia adelante, asignando cada elemento en turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabeza en la dirección inversa, asignando cada elemento en turno a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elem de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola cabeza.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

SALVEDADES

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    TAILQ_ENTRY(entrada) entradas;             /* Cola con seguimiento */
};
TAILQ_HEAD(colaencabezada, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct colaencabezada cabeza;                   /* Cabeza de cola con seguimiento */
    int i;
    TAILQ_INIT(&cabeza);                      /* Inicializa la cola */
    n1 = malloc(sizeof(struct entrada));      /* Inserta al principio */
    TAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Inserta al final */
    TAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Inserta después */
    TAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    n3 = malloc(sizeof(struct entrada));      /* Inserta antes */
    TAILQ_INSERT_BEFORE(n2, n3, entradas);
    TAILQ_REMOVE(&cabeza, n2, entradas);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &cabeza, entradas)
        np->datos = i++;
                                            /* Recorrido inverso */
    TAILQ_FOREACH_REVERSE(np, &cabeza, colaencabezada, entradas)
        printf("%i\n", np->datos);
                                            /* Eliminación de la cola con seguimiento */
    while (!TAILQ_EMPTY(&cabeza)) {
        n1 = TAILQ_FIRST(&cabeza);
        TAILQ_REMOVE(&cabeza, n1, entradas);
        free(n1);
    }
    exit(EXIT_SUCCESS);
}

EJEMPLOS

#include <err.h>
#include <stdio.h>
#include <stdlib.h>

#include "queue.h"

struct node {
    int data;
    TAILQ_ENTRY(node) entries;
};

TAILQ_HEAD(head_s, node);

int
main(void) {
    struct node *n1, *n2;
    struct head_s head;

    TAILQ_INIT(&head);

    /* Añadir nodos */
    n1 = malloc(sizeof(struct node));
    if (n1 == NULL)
        err(EXIT_FAILURE, NULL);
    n1->data = 1;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    n1 = malloc(sizeof(struct node));
    if (n1 == NULL)
        err(EXIT_FAILURE, NULL);
    n1->data = 2;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    n1 = malloc(sizeof(struct node));
    if (n1 == NULL)
        err(EXIT_FAILURE, NULL);
    n1->data = 3;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    /* Imprimir la cola */
    printf("Cola: ");
    TAILQ_FOREACH(n1, &head, entries) {
        printf("%d ", n1->data);
    }
    printf("\n");

    /* Eliminar nodos */
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
