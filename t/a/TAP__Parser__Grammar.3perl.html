TAP::Parser::Grammar(3perl) Guía del programador de Perl TAP::Parser::Grammar(3perl)

NOMBRE

TAP::Parser::Grammar - Una gramática para el protocolo Test Anything Protocol.

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Grammar;
my $grammar = $self->make_grammar({
  iterator => $tap_parser_iterator,
  parser   => $tap_parser,
  version  => 12,
});
my $result = $grammar->tokenize;

DESCRIPCIÓN

"TAP::Parser::Grammar" tokeniza líneas de un TAP::Parser::Iterator y construye subclases de TAP::Parser::Result para representar los tokens.

No intentes usar esta clase directamente. No tendría sentido. Está aquí principalmente para asegurar que podremos tener gramáticas conectables cuando TAP se expanda en algún momento futuro (además, estas cosas estaban realmente desordenando el analizador).

MÉTODOS

Métodos de Clase

"new"

my $grammar = TAP::Parser::Grammar->new({
    iterator => $iterator,
    parser   => $parser,
    version  => $version,
});

Devuelve un objeto de gramática TAP::Parser que analizará el flujo TAP del iterador especificado. Ambos argumentos "iterator" y "parser" son obligatorios. Si "version" no está configurado, por defecto es 12 (ver "set_version" para más detalles).

Métodos de Instancia

"set_version"

$grammar->set_version(13);

Indica a la gramática qué versión de la sintaxis TAP debe admitir. La versión más baja admitida es la 12. Aunque 'TAP version' no es sintaxis válida de la versión 12, se acepta para que se puedan analizar números de versión más altos.

"tokenize"

my $token = $grammar->tokenize;

Este método devolverá un objeto TAP::Parser::Result que representa la línea actual de TAP.

"token_types"

my @types = $grammar->token_types;

Devuelve los diferentes tipos de tokens que esta gramática puede analizar.

"syntax_for"

my $syntax = $grammar->syntax_for($token_type);

Devuelve una expresión regular precompilada que coincidirá con un trozo de TAP correspondiente al tipo de token. Por ejemplo (y no es que debas prestarle mucha atención, "$grammar->syntax_for('comment')" devolverá "qr/^#(.*)/".

"handler_for"

my $handler = $grammar->handler_for($token_type);

Devuelve una referencia de código que, al recibir una línea de TAP apropiada, devuelve el token analizado correspondiente a esa línea. Como resultado, el bucle básico de análisis de TAP se parece a lo siguiente:

my @tokens;
my $grammar = TAP::Grammar->new;
LINE: while ( defined( my $line = $parser->_next_chunk_of_tap ) ) {
    for my $type ( $grammar->token_types ) {
        my $syntax  = $grammar->syntax_for($type);
        if ( $line =~ $syntax ) {
            my $handler = $grammar->handler_for($type);
            push @tokens => $grammar->$handler($line);
            next LINE;
        }
    }
    push @tokens => $grammar->_make_unknown_token($line);
}

GRAMÁTICA TAP

NOTA: Esta gramática está un poco desactualizada. Todavía hay alguna discusión al respecto y se proporcionará una nueva cuando tengamos las cosas mejor definidas.

TAP::Parser no utiliza una gramática formal porque TAP es esencialmente un protocolo basado en flujos. De hecho, es completamente legal tener un flujo infinito. Por la misma razón por la que no aplicamos expresiones regulares a flujos, no estamos utilizando una gramática formal aquí. En su lugar, analizamos el TAP por líneas.

A efectos de compatibilidad futura, cualquier resultado que no coincida con la siguiente gramática se denomina actualmente TAP::Parser::Result::Unknown. No es un error de análisis.

Una gramática formal se parecería a lo siguiente:

(*
    Por el momento, hago trampa en la EBNF permitiendo
    que ciertos términos se definan mediante clases de caracteres POSIX
    utilizando la siguiente sintaxis:
      digit ::= [:digit:]
    Por lo que sé, eso no es EBNF válido.  Demándame.  No
    sabía cómo escribir "char" de otra manera (cuestiones de Unicode).
    Sugerencias bienvenidas.
*)
tap            ::= version? { comment | unknown } leading_plan lines
                   |
                   lines trailing_plan {comment}
version        ::= 'TAP version ' positiveInteger {positiveInteger} "\n"
leading_plan   ::= plan skip_directive? "\n"
trailing_plan  ::= plan "\n"
plan           ::= '1..' nonNegativeInteger
lines          ::= line {line}
line           ::= (comment | test | unknown | bailout ) "\n"
test           ::= status positiveInteger? description? directive?
status         ::= 'not '? 'ok '
description    ::= (character - (digit | '#')) {character - '#'}
directive      ::= todo_directive | skip_directive
todo_directive ::= hash_mark 'TODO' ' ' {character}
skip_directive ::= hash_mark 'SKIP' ' ' {character}
comment        ::= hash_mark {character}
hash_mark      ::= '#' {' '}
bailout        ::= 'Bail out!' {character}
unknown        ::= { (character - "\n") }
(* Clases de caracteres POSIX y otros terminales *)
digit              ::= [:digit:]
character          ::= ([:print:] - "\n")
positiveInteger    ::= ( digit - '0' ) {digit}
nonNegativeInteger ::= digit {digit}
