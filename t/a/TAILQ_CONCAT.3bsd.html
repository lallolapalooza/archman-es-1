DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element or at the head of the list. An SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A singly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element

LISTAS SIMPLES

Una lista simple se encabeza mediante una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista simple. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la lista simple después de un elemento existente, al principio de la lista simple o al final de la lista simple. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos que se enlazarán en la lista simple. Un puntero al encabezado de la lista simple se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista simple head.

La macro SLIST_CONCAT concatena la lista simple encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista simple.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista simple.

La macro SLIST_FIRST devuelve el primer elemento de la lista simple o NULL si la lista simple está vacía.

La macro SLIST_FOREACH recorre la lista simple referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista simple referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH, aquí se permite eliminar var y liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista simple referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista simple.

La macro SLIST_INSERT_TAIL inserta el nuevo elemento elm al final de la lista simple.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento que sigue a elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro, ya que recorre toda la lista. Se debe utilizar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE LISTA SIMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Encabezado de lista simple. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Lista simple. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializar la lista. */

n1 = malloc(sizeof(struct entry));	/* Insertar al principio. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación del principio. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Eliminación de lista. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

COLAS DE FIN DE LISTA SIMPLE

Una cola de fin de lista simple se encabeza mediante una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de fin de lista y otro al último elemento de la cola de fin de lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola de fin de lista después de un elemento existente, al principio de la cola de fin de lista o al final de la cola de fin de lista. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos que se enlazarán en la cola de fin de lista. Un puntero al encabezado de la cola de fin de lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de fin de lista head.

La macro STAILQ_CONCAT concatena la cola de fin de lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de fin de lista.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola de fin de lista.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de fin de lista o NULL si la cola de fin de lista está vacía.

La macro STAILQ_FOREACH recorre la cola de fin de lista referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de fin de lista referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite eliminar var y liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola de fin de lista referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de fin de lista.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de fin de lista.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de fin de lista. Si la cola de fin de lista está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de fin de lista, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento que sigue a elm de la cola de fin de lista. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola de fin de lista.

La macro STAILQ_REMOVE_HEAD elimina el elemento del principio de la cola de fin de lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola de fin de lista deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

Se debe utilizar una cola de fin de lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas de fin de lista largas.

while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación más rápida de TailQ. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista se encabeza mediante una estructura definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma doble para que un elemento arbitrario pueda eliminarse sin recorrer la lista. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero al encabezado de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro, ya que recorre la totalidad de la lista head1. Se debe utilizar una cola de fin de lista si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por he

EJEMPLO LIST

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Cabeza de la lista. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Lista. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Inicializa la lista. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Eliminación. */
free(n2);
					/* Recorrido hacia adelante. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Recorrido seguro hacia adelante. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Eliminación de lista. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Eliminación rápida de lista. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

COLAS DE FIN

Una cola de fin se encabeza mediante una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de fin y otro al último elemento de la cola de fin. Los elementos están doblemente enlazados para que se pueda eliminar un elemento arbitrario sin recorrer la cola de fin. Se pueden añadir nuevos elementos a la cola de fin después de un elemento existente, antes de un elemento existente, al principio de la cola de fin o al final de la cola de fin. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se van a enlazar en la cola de fin. Un puntero a la cabeza de la cola de fin se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola de fin head.

La macro TAILQ_CONCAT concatena la cola de fin encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro TAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola de fin.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos en la cola de fin.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de fin o NULL si la cola de fin está vacía.

La macro TAILQ_FOREACH recorre la cola de fin referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. var se establece en NULL si el bucle se completa normalmente o si no había elementos.

La macro TAILQ_FOREACH_FROM se comporta de manera idéntica a TAILQ_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en el TAILQ referenciado por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de fin referenciada por head en dirección inversa, asignando cada elemento en turno a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta de manera idéntica a TAILQ_FOREACH_REVERSE cuando var es NULL; de lo contrario, trata var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en el TAILQ referenciado por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referenciada por head en dirección hacia adelante o inversa respectivamente, asignando cada elemento en turno a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten eliminar var y liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a TAILQ_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en el TAILQ referenciado por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta de manera idéntica a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL; de lo contrario, trata var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en el TAILQ referenciado por head.

La macro TAILQ_INIT inicializa la cola de fin referenciada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de fin.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de fin.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de fin. Si la cola de fin está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola de fin, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola de fin, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de fin.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

NAME

                    
TAILQ_CONCAT, TAILQ_FOREACH_SAFE, TAILQ_SWAP — tail queue macros

                

                

                    
LIBRARY

                    
libbsd

                

                

                    
SYNOPSIS

                    
#include <sys/queue.h>

                    
void
                        

                        TAILQ_CONCAT(head1, head2);

                    
#define
                        

                        TAILQ_FOREACH_SAFE(var, head, field, nextvar);

                    
void
                        

                        TAILQ_SWAP(head1, head2, type);

                

                

                    
DESCRIPTION

                    
The TAILQ_CONCAT() macro concatenates the tail queue head2 onto the end of the tail queue head1. Both head1 and head2 must be initialized tail queues. After the operation, head2 will be an empty tail queue.

                    
The TAILQ_FOREACH_SAFE() macro is similar to the TAILQ_FOREACH() macro, but it is safe to use within the loop body: the nextvar variable holds the pointer to the next element, so that the current element can be safely removed or freed. If the current element is removed or freed, nextvar can be used to continue the iteration.

                    
The TAILQ_SWAP() macro swaps the contents of the two tail queues head1 and head2. The queues must be of the same type type.

                

                

                    
SINGLY-LINKED LISTS

                    
These macros operate on singly-linked lists. A singly-linked list is a sequence of elements, each containing a pointer to the next element in the sequence. The list is represented by a pointer to the first element, and the last element contains a NULL pointer. The list structure is usually defined as:

                    
struct mylist {
        struct mylist *next;
        /* ... other data ... */
    };

                    
and the list head is defined as:

                    
struct mylist *my_list_head = NULL;

                    
The list macros use the next pointer to chain the elements together.

                

                

                    
SINGLY-LINKED LIST EXAMPLE

                    
struct node {
        int data;
        struct node *next;
    };
    struct node *head = NULL;
    struct node *temp, *current;
    struct node *new_node = malloc(sizeof(struct node));
    new_node->data = 10;
    new_node->next = head;
    head = new_node;
    /* Iterate through the list */
    current = head;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    /* Free the list */
    current = head;
    while (current != NULL) {
        temp = current;
        current = current->next;
        free(temp);
    }

                

                

                    
SINGLY-LINKED TAIL QUEUES

                    
A singly-linked tail queue is a singly-linked list that keeps track of the last element in the list. This allows for efficient insertion at the end of the list. The list structure is usually defined as:

                    
struct mytailq {
        struct mytailq *next;
        /* ... other data ... */
    };
    struct mytailq_head {
        struct mytailq *first;
        struct mytailq *last;
    };

                    
The list macros use the next pointer to chain the elements together, and the head structure keeps pointers to the first and last elements.

                

                

                    
SINGLY-LINKED TAIL QUEUE EXAMPLE

                    
struct node {
        int data;
        struct node *next;
    };
    struct tailq_head {
        struct node *first;
        struct node *last;
    };
    struct tailq_head my_tailq;
    TAILQ_INIT(&my_tailq);
    struct node *new_node = malloc(sizeof(struct node));
    new_node->data = 10;
    new_node->next = NULL;
    TAILQ_INSERT_TAIL(&my_tailq, new_node, next);
    /* ... */

                

                

                    
LISTS

                    
The LIST macros operate on singly-linked lists. A list is defined by a pointer to the first element. Each element in the list is a structure that contains a pointer to the next element. The list is terminated by a NULL pointer.

                    
The list macros are defined as follows:

                    
LIST_HEAD(list_name, type)
    List head definition.
LIST_ENTRY(type)
    List entry definition.
LIST_INIT(head)
    Initialize an empty list.
LIST_INSERT_HEAD(head, elm, field)
    Insert element elm at the head of the list.
LIST_INSERT_AFTER(listelm, elm, field)
    Insert element elm after listelm.
LIST_INSERT_BEFORE(listelm, elm, field)
    Insert element elm before listelm.
LIST_REMOVE(elm, field)
    Remove element elm from the list.
LIST_MOVE(listelm, elm)
    Move element elm to the list headed by listelm.
LIST_FIRST(head)
    Get the first element of the list.
LIST_NEXT(elm, field)
    Get the next element in the list.
LIST_PREV(elm, field)
    Get the previous element in the list.
LIST_EMPTY(head)
    Check if the list is empty.
LIST_SWAP(head1, head2, type)
    Swap the contents of two lists.
LIST_FOREACH(var, head, field)
    Iterate over the list.

                

                

                    
LIST EXAMPLE

                    
struct mynode {
        int data;
        LIST_ENTRY(mynode) next;
    };
    LIST_HEAD(mylisthead, mynode) mylist;
    struct mynode *element;
    LIST_INIT(&mylist);
    element = malloc(sizeof(struct mynode));
    element->data = 10;
    LIST_INSERT_HEAD(&mylist, element, next);
    LIST_FOREACH(element, &mylist, next) {
        printf("%d\n", element->data);
    }

                

                

                    
TAIL QUEUES

                    
The TAILQ macros operate on doubly-linked lists. A tail queue is defined by a structure that contains pointers to the first and last elements. Each element in the queue is a structure that contains pointers to the next and previous elements. The queue is terminated by NULL pointers.

                    
The tail queue macros are defined as follows:

                    
TAILQ_HEAD(tailq_name, type)
    Tail queue head definition.
TAILQ_ENTRY(type)
    Tail queue entry definition.
TAILQ_INIT(head)
    Initialize an empty tail queue.
TAILQ_INSERT_HEAD(head, elm, field)
    Insert element elm at the head of the tail queue.
TAILQ_INSERT_TAIL(head, elm, field)
    Insert element elm at the tail of the tail queue.
TAILQ_INSERT_AFTER(listelm, elm, field)
    Insert element elm after listelm.
TAILQ_INSERT_BEFORE(listelm, elm, field)
    Insert element elm before listelm.
TAILQ_REMOVE(head, elm, field)
    Remove element elm from the tail queue.
TAILQ_MOVE(head, elm, field)
    Move element elm to the tail queue headed by head.
TAILQ_FIRST(head)
    Get the first element of the tail queue.
TAILQ_LAST(head, headname)
    Get the last element of the tail queue.
TAILQ_NEXT(elm, field)
    Get the next element in the tail queue.
TAILQ_PREV(elm, headname, field)
    Get the previous element in the tail queue.
TAILQ_EMPTY(head)
    Check if the tail queue is empty.
TAILQ_SWAP(head1, head2, type)
    Swap the contents of two tail queues.
TAILQ_FOREACH(var, head, field)
    Iterate over the tail queue.

                

                

                    
TAIL QUEUE EXAMPLE

                    
struct mynode {
        int data;
        TAILQ_ENTRY(mynode) next;
    };
    TAILQ_HEAD(mytailqhead, mynode) mytailq;
    struct mynode *element;
    TAILQ_INIT(&mytailq);
    element = malloc(sizeof(struct mynode));
    element->data = 10;
    TAILQ_INSERT_TAIL(&mytailq, element, next);
    TAILQ_FOREACH(element, &mytailq, next) {
        printf("%d\n", element->data);
    }

                    
The following example shows how to use TAILQ_SWAP:

                    
struct mynode {
        int data;
        TAILQ_ENTRY(mynode) next;
    };
    TAILQ_HEAD(mytailqhead, mynode) mytailq1, mytailq2;
    struct mynode *element1, *element2;
    TAILQ_INIT(&mytailq1);
    TAILQ_INIT(&mytailq2);
    element1 = malloc(sizeof(struct mynode));
    element1->data = 10;
    TAILQ_INSERT_TAIL(&mytailq1, element1, next);
    element2 = malloc(sizeof(struct mynode));
    element2->data = 20;
    TAILQ_INSERT_TAIL(&mytailq2, element2, next);
    TAILQ_SWAP(&mytailq1, &mytailq2, mynode);

                    
Now mytailq1 contains the element with data 20, and mytailq2 contains the element with data 10.

                    
The following example shows how to use TAILQ_FOREACH_SAFE:

                    
struct mynode {
        int data;
        TAILQ_ENTRY(mynode) next;
    };
    TAILQ_HEAD(mytailqhead, mynode) mytailq;
    struct mynode *element, *next_element;
    TAILQ_INIT(&mytailq);
    /* ... insert elements into mytailq ... */
    TAILQ_FOREACH_SAFE(element, &mytailq, next, next_element) {
        if (element->data == some_value) {
            TAILQ_REMOVE(&mytailq, element, next);
            free(element);
        }
    }

                

                

                    
DIAGNOSTICS

                    
When debugging queue(3), it can be useful to trace queue changes. To enable tracing, define the macro QUEUE_MACRO_DEBUG_TRACE at compile time.

                    
It can also be useful to trash pointers that have been unlinked from a queue, to detect use after removal. To enable pointer trashing, define the macro QUEUE_MACRO_DEBUG_TRASH at compile time. The macro QMD_IS_TRASHED(void *ptr) returns true if ptr has been trashed by the QUEUE_MACRO_DEBUG_TRASH option.
