NOMBRE

TAP::Parser::Result::Plan - Token de resultado de plan.

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Esta es una subclase de TAP::Parser::Result. Se devolverá un token de esta clase si se encuentra una línea de plan.

1..1
ok 1 - ¡hoo hooo!

1..1 es el plan. Hay que tener un plan.

Métodos de instancia

"plan"

if ( $result->is_plan ) {
   print $result->plan;
}

Esto es meramente un sinónimo de "as_string".

"tests_planned"

my $planned = $result->tests_planned;

Devuelve el número de pruebas planificadas. Por ejemplo, un plan de 1..17 hará que este método devuelva '17'.

"directive"

my $directive = $plan->directive;

Si se incluye una directiva SKIP con el plan, este método la devolverá.

1..0 # SKIP: ¿por qué molestarse?

"has_skip"

if ( $result->has_skip ) { ... }

Devuelve un valor booleano que indica si esta prueba tiene o no una directiva SKIP.

"explanation"

my $explanation = $plan->explanation;

Si se incluyó una directiva SKIP con el plan, este método devolverá la explicación, si la hay.
