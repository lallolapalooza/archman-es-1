DESCRIPCIÓN

Estas macros definen y operan sobre colas con doble enlace final.

En las definiciones de las macros, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola final está encabezada por una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados doblemente para que se pueda eliminar un elemento arbitrario sin recorrer la cola. Se pueden añadir nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct HEADNAME *headp;

(Los nombres head y headp son elegibles por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

TAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola head.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola. head.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elm al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elm al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elm antes del elemento listelm.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elm después del elemento listelm.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior de la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por head en dirección hacia atrás, asignando cada elemento en turno a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elm de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TYPE primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola head.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en BSD pero no en glibc, solucionan esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola final */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Cabeza de la cola final */
    int i;
    TAILQ_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido hacia atrás */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de la cola final */

EJEMPLOS

Para liberar una cola encadenada TAILQ, podrías usar el siguiente código:

struct my_list head;
struct my_node *n1, *n2;

TAILQ_INIT(&head);
/* ... llenar la cola ... */

n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
