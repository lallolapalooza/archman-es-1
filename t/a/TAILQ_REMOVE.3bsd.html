DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas con cola enlazadas simples
  4. Colas con cola
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento de la lista.
  3. Eliminación en O(1) de una entrada del principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier entrada en la lista.
  2. Concatenación en O(n) de dos listas.

Las colas con cola enlazadas simples añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Eliminación en O(n) de cualquier entrada en la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones de listas deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones son aproximadamente un 20% más lentas que las listas enlazadas simples.

Las colas con cola enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todos los tipos de estructuras de datos enlazadas doblemente (listas y colas con cola) permiten adicionalmente:

  1. Inserción de una nueva entrada antes de cualquier elemento en la lista.
  2. Eliminación en O(1) de cualquier entrada en la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos enlazadas doblemente. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para comenzar el recorrido y la lista en la que está contenida.

Las colas con cola añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de listas deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones son aproximadamente un 20% más lentas que las listas enlazadas simples.

En las definiciones de macros, TIPO es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NOMBRE que es de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NOMBRE que es de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, o TAILQ_CLASS_ENTRY. El argumento NOMBRE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse utilizando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, o TAILQ_CLASS_HEAD. Consulte los ejemplos a continuación para obtener más explicaciones sobre cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados simplemente para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación en O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(NOMBRE_CABEZA, TIPO) cabeza;

donde NOMBRE_CABEZA es el nombre de la estructura que se va a definir, y TIPO es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar posteriormente como:

struct NOMBRE_CABEZA *puntero_cabeza;

(Los nombres cabeza y puntero_cabeza son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista cabeza.

La macro SLIST_CONCAT concatena la lista encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista cabeza1. Se debe utilizar una cola con cola enlazada simple si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY se evalúa como verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por cabeza en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por cabeza.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por cabeza en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí está permitido tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por cabeza.

La macro SLIST_INIT inicializa la lista referenciada por cabeza.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elemento al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elemento después del elemento

LISTAS SIMPLEMENTE ENLAZADAS

Una lista simplemente enlazada está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados simplemente para minimizar el espacio y la sobrecarga de manipulación de punteros, a expensas de una eliminación de O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se van a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento posterior a elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe utilizar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

COLAS DE LISTA SIMPLEMENTE ENLAZADA CON COLA

Una cola de lista simplemente enlazada con cola está encabezada por una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de lista con cola y otro al último elemento de la cola de lista con cola. Los elementos están enlazados simplemente para minimizar el espacio y la sobrecarga de manipulación de punteros, a expensas de una eliminación de O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola de lista con cola después de un elemento existente, al principio de la cola de lista con cola o al final de la cola de lista con cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se van a enlazar en la cola de lista con cola. Un puntero a la cabeza de la cola de lista con cola se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa un inicializador para la cola de lista con cola head.

La macro STAILQ_CONCAT concatena la cola de lista con cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de lista con cola.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola de lista con cola.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de lista con cola o NULL si la cola de lista con cola está vacía.

La macro STAILQ_FOREACH recorre la cola de lista con cola referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de lista con cola referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola de lista con cola referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de lista con cola.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de lista con cola.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de lista con cola. Si la cola de lista con cola está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de lista con cola, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento posterior a elm de la cola de lista con cola. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola de lista con cola.

La macro STAILQ_REMOVE_HEAD elimina el elemento del principio de la cola de lista con cola. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola de lista con cola deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de lista con cola. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe utilizar una cola de lista doblemente enlazada con cola si esta macro es necesaria en rutas de código de alto uso o para operar en colas de lista con cola largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

LISTAS

Una lista está encabezada por una estructura definida por la macro LIST_HEAD. Esta estructura contiene un puntero único al primer elemento de la lista. Los elementos están doblemente enlazados de modo que un elemento arbitrario puede eliminarse sin recorrer la lista. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se van a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe utilizar una cola de lista si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

DESCRIPTION These macros implement singly linked lists and doubly linked queues. They are designed to be efficient and to use a minimal amount of memory. They are often used in the kernel, but are also available for userland programs. A list is a singly linked list, headed by a structure defined by the LIST_HEAD macro. This structure contains a pointer to the first element in the list. The elements are singly linked so that an arbitrary element can be removed, but only after traversing the list to find its predecessor. New elements can be added to the list before an existing element, or at the head of the list. A LIST_HEAD structure is declared as follows: LIST_HEAD(HEADNAME, TYPE, FIELD) head; where HEADNAME is the name of the structure to be defined, TYPE is the type of the elements to be linked into the list, and FIELD is the name of the list entry field within TYPE. A pointer to the head of the list can later be declared as: struct HEADNAME *headp; The names HEADNAME and headp are user selectable. The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head. The macro LIST_ENTRY declares a structure that connects the elements in the list. The macro LIST_INIT initializes the list referenced by head. The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list. The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm. The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm. The macro LIST_FIRST returns the first element in the list or NULL if the list is empty. The macro LIST_LAST returns the last element in the list or NULL if the list is empty. The macro LIST_EMPTY evaluates to true if there are no items on the list. The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var. The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head. The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal. The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head. The macro LIST_NEXT returns the next element in the list, or NULL if this is the last. The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm. The macro LIST_REMOVE removes the element elm from the list. The macro LIST_SWAP swaps the contents of head1 and head2. A tail queue is a doubly linked list, headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows: TAILQ_HEAD(HEADNAME, TYPE, FIELD) head; where HEADNAME is the name of the structure to be defined, TYPE is the type of the elements to be linked into the tail queue, and FIELD is the name of the tail queue entry field within TYPE. A pointer to the head of the tail queue can later be declared as: struct HEADNAME *headp; The names HEADNAME and headp are user selectable. The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head. The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former. The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue. The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue. The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty. The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements. The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head. The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var. The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head. The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal. The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head. The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head. The macro TAILQ_INIT initializes the tail queue referenced by head. The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue. The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm. The macro TAILQ_LAST returns the last item on the tail queue. DIAGNÓSTICOS

Al depurar queue(3), puede ser útil trazar los cambios en la cola. Para habilitar la trazabilidad, defina la macro QUEUE_MACRO_DEBUG_TRACE en el momento de la compilación.

También puede ser útil "ensuciar" los punteros que han sido desvinculados de una cola, para detectar su uso después de la eliminación. Para habilitar el "ensuciamiento" de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH en el momento de la compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido "ensuciado" por la opción QUEUE_MACRO_DEBUG_TRASH.
