DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas con cola enlazadas simples
  4. Colas con cola
Las cuatro estructuras admiten la siguiente funcionalidad:
  1. Inserción de una nueva entrada al principio de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento de la lista.
  3. Eliminación en O(1) de una entrada desde el principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo admiten la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier entrada en la lista.
  2. Concatenación en O(n) de dos listas.

Las colas con cola enlazadas simples añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Eliminación en O(n) de cualquier entrada en la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que las listas enlazadas simples.

Las colas con cola enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todos los tipos de estructuras de datos doblemente enlazadas (listas y colas con cola) permiten además:

  1. Inserción de una nueva entrada antes de cualquier elemento de la lista.
  2. Eliminación en O(1) de cualquier entrada de la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) son aproximadamente el doble que los de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos doblemente enlazadas. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para comenzar el recorrido y la lista en la que está contenida.

Las colas con cola añaden la siguiente funcionalidad:

  1. Las entradas pueden ser añadidas al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que las listas enlazadas simples.

En las definiciones de macro, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que sea del tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macro, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que sea del tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Ver los ejemplos a continuación para una mayor explicación de cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro, ya que recorre la totalidad de la lista head1. Se debe utilizar una cola con cola enlazada simple si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH() aquí está permitido tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento en la lista después de elm o NULL si elm es el último elemento.

La macro SLIST_REMOVE elimina el elemento elm de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento que sigue a listelm de la lista.

La macro SLIST_SWAP intercambia el contenido de las dos listas encabezadas por head1 y head2.

COLAS CON COLA ENLAZADAS SIMPLES

Una cola con cola enlazada simple está encabezada por una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene dos punteros: uno al primer elemento de la lista y otro al último. Los elementos están enlazados de forma simple con un puntero al siguiente elemento. Las colas con cola enlazadas simples admiten la inserción de elementos al principio o al final de la lista y la eliminación de elementos desde el principio de la lista en O(1). La eliminación de elementos arbitrarios de la lista requiere O(n).

Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER se evalúa a un inicializador para la lista head.

La macro STAILQ_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. El uso de esta macro debe evitarse, ya que recorre la totalidad de la lista head1. Se debe utilizar una cola con cola si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro STAILQ_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos de la lista.

La macro STAILQ_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro STAILQ_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en el STAILQ referenciado por head.

La macro STAILQ_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de STAILQ_FOREACH, aquí está permitido tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en el STAILQ referenciado por head.

La macro STAILQ_INIT inicializa la lista referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la lista.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la lista.

La macro STAILQ_NEXT devuelve el siguiente elemento en la lista después de elm o NULL si elm es el último elemento.

La macro STAILQ_PREV devuelve el elemento anterior en la lista antes de elm o NULL si elm es el primer elemento.

La macro STAILQ_REMOVE elimina el elemento elm de la lista.

La macro STAILQ_SWAP intercambia el contenido de las dos listas encabezadas por head1 y head2.

LISTAS DOBLEMENTE ENLAZADAS

Una lista doblemente enlazada está encabezada por una estructura definida por la macro LIST_HEAD. Esta estructura contiene dos punteros: uno al primer elemento de la lista y otro al último. Los elementos están doblemente enlazados, permitiendo la inserción y eliminación de elementos en O(1) en cualquier parte de la lista.

Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro LIST_PREV devuelve el elemento anterior en la lista antes de elm o NULL si elm es el primer elemento.

La macro LIST_REMOVE elimina el elemento elm de la lista.

La macro LIST_SWAP intercambia el contenido de las dos listas encabezadas por head1 y head2.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element, or at the head of the list. A SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the singly-linked list headed by head2 onto the end of the one headed by head1, removing all entries from the former.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the singly-linked list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the singly linked list referenced by head.

The macro SLIST_INSERT_AFTER inserts the new element elm after the existing element listelm.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_NEXT returns the next element in the list.

The macro SLIST_REMOVE_AFTER removes the element after elm from the list. Unlike SLIST_REMOVE, this macro does not traverse the entire list.

The macro SLIST_REMOVE_HEAD removes the element elm from the head of the list. For optimum efficiency, elements being removed from the head of the list should explicitly use this macro instead of the generic SLIST_REMOVE macro.

The macro SLIST_REMOVE removes the element elm from the list. Use of this macro should be avoided as it traverses the entire list. A doubly-linked list should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_SWAP swaps the contents of head1 and head2.

SINGLY-LINKED LIST EXAMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Singly-linked List head. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Singly-linked List. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Deletion. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Deletion from the head. */
free(n3);
					/* Forward traversal. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Safe forward traversal. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

LISTS

The macro LIST_EMPTY evaluates to true if there are no items on the list.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the tail queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro TAILQ_NEXT returns the next item on the tail queue, or NULL if this item is the last.

The macro TAILQ_PREV returns the previous item on the tail queue, or NULL if this item is the first.

The macro TAILQ_REMOVE removes the element elm from the tail queue.

The macro TAILQ_SWAP swaps the contents of head1 and head2.

DIAGNÓSTICOS

Al depurar queue(3), puede ser útil rastrear los cambios en la cola. Para habilitar el rastreo, defina la macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.

También puede ser útil "desordenar" los punteros que se han desvinculado de una cola, para detectar su uso después de la eliminación. Para habilitar el desorden de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido desordenado por la opción QUEUE_MACRO_DEBUG_TRASH.
