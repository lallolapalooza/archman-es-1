TAILQ(3) Manual de funciones de biblioteca TAILQ(3)

NOMBRE

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE - implementación de una cola con seguimiento doblemente enlazada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
TAILQ_ENTRY(TIPO);
TAILQ_HEAD(NOMBRECABECERA, TIPO);
TAILQ_HEAD NOMBRECABECERA_INICIALIZADOR(TAILQ_HEAD cabecera);
void TAILQ_INIT(TAILQ_HEAD *cabecera);
int TAILQ_EMPTY(TAILQ_HEAD *cabecera);
void TAILQ_INSERT_HEAD(TAILQ_HEAD *cabecera,
                         struct TIPO *elemento, TAILQ_ENTRY NOMBRE);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *cabecera,
                         struct TIPO *elemento, TAILQ_ENTRY NOMBRE);
void TAILQ_INSERT_BEFORE(struct TIPO *elementolista,
                         struct TIPO *elemento, TAILQ_ENTRY NOMBRE);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *cabecera, struct TIPO *elementolista,
                         struct TIPO *elemento, TAILQ_ENTRY NOMBRE);
struct TIPO *TAILQ_FIRST(TAILQ_HEAD *cabecera);
struct TIPO *TAILQ_LAST(TAILQ_HEAD *cabecera, NOMBRECABECERA);
struct TIPO *TAILQ_PREV(struct TIPO *elemento, NOMBRECABECERA, TAILQ_ENTRY NOMBRE);
struct TIPO *TAILQ_NEXT(struct TIPO *elemento, TAILQ_ENTRY NOMBRE);
TAILQ_FOREACH(struct TIPO *variable, TAILQ_HEAD *cabecera,
                         TAILQ_ENTRY NOMBRE);
TAILQ_FOREACH_REVERSE(struct TIPO *variable, TAILQ_HEAD *cabecera, NOMBRECABECERA,
                         TAILQ_ENTRY NOMBRE);
void TAILQ_REMOVE(TAILQ_HEAD *cabecera, struct TIPO *elemento,
                         TAILQ_ENTRY NOMBRE);
void TAILQ_CONCAT(TAILQ_HEAD *cabecera1, TAILQ_HEAD *cabecera2,
                         TAILQ_ENTRY NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre colas con seguimiento doblemente enlazadas.

En las definiciones de macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRECABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola con seguimiento se encabeza con una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la cola. Los nuevos elementos pueden ser añadidos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRECABECERA, TIPO) cabecera;

donde struct NOMBRECABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola. Más tarde, se puede declarar un puntero a la cabecera de la cola como:


struct NOMBRECABECERA *cabecerp;

(Los nombres cabecera y cabecerp son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

TAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabecera.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola. cabecera.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elemento antes del elemento elementolista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elementolista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior de la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabecera en la dirección hacia adelante, asignando cada elemento en su turno a variable. variable se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabecera en la dirección inversa, asignando cada elemento en su turno a variable.

Eliminación

TAILQ_REMOVE() elimina el elemento elemento de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola cabecera.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que variable sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación permitiendo que variable sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola con seguimiento */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Cabecera de cola con seguimiento */
    int i;
    TAILQ_INIT(&head);                      /* Inicializa la cola */
    n1 = malloc(sizeof(struct entry));      /* Inserta al principio */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Inserta al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Inserta después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Inserta antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido inverso */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de la cola */
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        np = TAILQ_NEXT(n1, entries);
        TAILQ_REMOVE(&head, n1, entries);
        free(n1);
        n1 = np;
    }
    return 0;
}

TAILQ_EMPTY(3bsd) - Arch Linux man pages

NAME

TAILQ_EMPTY - query if a tail queue is empty

LIBRARY

libbsd

SYNOPSIS

#include <sys/queue.h>

TAILQ_EMPTY(const TAILQ_HEAD(., _type) *head);

DESCRIPTION

The TAILQ_EMPTY macro is used to check if a tail queue is empty. It returns true if the queue is empty, and false otherwise.

The head argument is a pointer to the tail queue head.

RETURN VALUE

The TAILQ_EMPTY macro returns a non-zero value if the queue is empty, and 0 otherwise.

STANDARDS

The TAILQ_EMPTY macro is part of the BSD queue macros. It is expected to be available on any system that supports the BSD style queue manipulation macros.

HISTORY

The tail queue macros were first implemented in 386BSD.

CAVEATS

None.

EXAMPLES

The following example demonstrates how to use TAILQ_EMPTY to check if a tail queue is empty:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct my_node {
    int            data;
    TAILQ_ENTRY(my_node) entries;
};

int
main()
{
    TAILQ_HEAD(my_list, my_node) head;
    struct my_node *n1;

    TAILQ_INIT(&head);

    if (TAILQ_EMPTY(&head)) {
        printf("The queue is empty.\n");
    }

    n1 = malloc(sizeof(struct my_node));
    if (n1 == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    n1->data = 10;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    if (TAILQ_EMPTY(&head)) {
        printf("The queue is empty.\n");
    } else {
        printf("The queue is not empty.\n");
    }

    while ((n1 = TAILQ_FIRST(&head)) != NULL) {
        TAILQ_REMOVE(&head, n1, entries);
        free(n1);
    }

    if (TAILQ_EMPTY(&head)) {
        printf("The queue is now empty.\n");
    }

    return 0;
}

The following example shows how to free all the elements in a tail queue:

void
free_tailq(TAILQ_HEAD(_list, _entry) *head)
{
    struct _entry *n1, *n2;

    n1 = TAILQ_FIRST(head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(head);
    exit(EXIT_SUCCESS);
}
