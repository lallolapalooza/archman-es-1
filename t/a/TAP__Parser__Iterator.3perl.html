TAP::Parser::Iterator(3perl) Guía de referencia del programador de Perl TAP::Parser::Iterator(3perl)

NOMBRE

TAP::Parser::Iterator - Clase base para iteradores de fuentes TAP

VERSIÓN

Versión 3.50

SINOPSIS

# para subclasear:
use TAP::Parser::Iterator ();
use base 'TAP::Parser::Iterator';
sub _initialize {
  # ver TAP::Object...
}
sub next_raw { ... }
sub wait     { ... }
sub exit     { ... }

DESCRIPCIÓN

Esta es una clase base de iterador simple que define la API de iterador de TAP::Parser. Los iteradores se crean típicamente a partir de TAP::Parser::SourceHandlers.

MÉTODOS

Métodos de clase

"new"

Crea un iterador. Proporcionado por TAP::Object.

Métodos de instancia

"next"

while ( my $item = $iter->next ) { ... }

Itera a través de él, por supuesto.

"next_raw"

Nota: este método es abstracto y debe ser anulado.

while ( my $item = $iter->next_raw ) { ... }

Itera la entrada bruta sin aplicar ninguna corrección para sintaxis de entrada peculiar.

"handle_unicode"

Si es necesario, cambia el flujo de entrada para manejar unicode. Esto solo tiene algún efecto para flujos basados en manejo de E/S.

La implementación predeterminada no hace nada.

"get_select_handles"

Devuelve una lista de manejadores de archivos que pueden ser utilizados en un nivel superior en una llamada a select() para indicar que este Iterador está listo. Los iteradores que no se basan en manejadores deben devolver una lista vacía.

La implementación predeterminada no hace nada.

"wait"

Nota: este método es abstracto y debe ser anulado.

my $wait_status = $iter->wait;

Devuelve el estado de "wait" para este iterador.

"exit"

Nota: este método es abstracto y debe ser anulado.

my $wait_status = $iter->exit;

Devuelve el estado de "exit" para este iterador.
