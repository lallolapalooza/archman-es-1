NOMBRE

TAP::Parser::Result::Test - Token de resultado de prueba.

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Esta es una subclase de TAP::Parser::Result. Se devolverá un token de esta clase si se encuentra una línea de prueba.

1..1
ok 1 - ¡woo hooo!

MÉTODOS SOBREESCRITOS

Esta clase es el caballo de batalla del sistema TAP::Parser. La mayoría de las líneas TAP serán líneas de prueba y, si "$result->is_test", tienes un montón de métodos a tu disposición.

Métodos de instancia

"ok"

my $ok = $result->ok;

Devuelve el texto literal del estado "ok" o "not ok".

"number"

my $test_number = $result->number;

Devuelve el número de la prueba, incluso si la salida TAP original no proporcionó ese número.

"description"

my $description = $result->description;

Devuelve la descripción de la prueba, si la hay. Esta es la porción después del número de prueba pero antes de la directiva.

"directive"

my $directive = $result->directive;

Devuelve "TODO" o "SKIP" si alguna de las directivas estaba presente para una línea de prueba.

"explanation"

my $explanation = $result->explanation;

Si una prueba tenía una directiva "TODO" o "SKIP", este método devolverá la explicación acompañante, si está presente.

not ok 17 - 'Los cerdos pueden volar' # TODO falta ácido

Para la línea anterior, la explicación es falta ácido.

"is_ok"

if ( $result->is_ok ) { ... }

Devuelve un valor booleano que indica si la prueba pasó o no. Recuerda que para las pruebas TODO, la prueba siempre pasa.

Si la prueba no está planificada, este método siempre devolverá falso. Ver "is_unplanned".

"is_actual_ok"

if ( $result->is_actual_ok ) { ... }

Devuelve un valor booleano que indica si la prueba pasó o no, independientemente de su estado TODO.

"actual_passed"

Obsoleto. Por favor, usa "is_actual_ok" en su lugar.

"todo_passed"

if ( $test->todo_passed ) {
   # la prueba tuvo éxito inesperadamente
}

Si esta es una prueba TODO y una línea 'ok', este método devuelve verdadero. De lo contrario, siempre devolverá falso (independientemente del estado de paso en pruebas no TODO).

Esto se usa para rastrear qué pruebas tuvieron éxito inesperadamente.

"todo_failed"

# obsoleto en favor de 'todo_passed'.  Este método tuvo un nombre horriblemente equivocado.

Este fue un método mal nombrado. Indica qué pruebas TODO tuvieron éxito inesperadamente. Ahora emitirá una advertencia y llamará a "todo_passed".

"has_skip"

if ( $result->has_skip ) { ... }

Devuelve un valor booleano que indica si esta prueba tiene una directiva SKIP.

"has_todo"

if ( $result->has_todo ) { ... }

Devuelve un valor booleano que indica si esta prueba tiene una directiva TODO.

"as_string"

print $result->as_string;

Este método imprime la prueba como una cadena. Probablemente será similar, pero no necesariamente idéntica, a la línea de prueba original. Las directivas se capitalizan, es posible que se elimine algo de espacio en blanco y se agregará un número de prueba si no estaba presente en la línea original. Si necesita el texto original de la línea de prueba, use el método "raw".

"is_unplanned"

if ( $test->is_unplanned ) { ... }
$test->is_unplanned(1);

Si un número de prueba es mayor que el número de pruebas planificadas, este método devolverá verdadero. Las pruebas no planificadas siempre devolverán falso para "is_ok", independientemente de si la prueba "has_todo".

Tenga en cuenta que si las pruebas tienen un plan final, no es posible establecer esta propiedad para pruebas no planificadas, ya que no sabemos que no está planificada hasta que se alcanza el plan:

print <<'END';
ok 1
ok 2
1..1
END
