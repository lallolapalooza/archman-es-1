TAP::Parser::Iterator::Process(3perl) Guía del programador de Perl TAP::Parser::Iterator::Process(3perl)

NOMBRE

TAP::Parser::Iterator::Process - Iterador para fuentes TAP basadas en procesos

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Iterator::Process;
my %args = (
 command  => ['python', 'setup.py', 'test'],
 merge    => 1,
 setup    => sub { ... },
 teardown => sub { ... },
);
my $it   = TAP::Parser::Iterator::Process->new(\%args);
my $line = $it->next;

DESCRIPCIÓN

Este es un simple envoltorio iterador para ejecutar procesos externos, utilizado por TAP::Parser. A menos que estés escribiendo un plugin o subclasificando, probablemente no necesites usar este módulo directamente.

MÉTODOS

Métodos de clase

"new"

Crea un iterador. Espera un argumento que contiene un hashref del tipo:

command  => \@command_to_execute
merge    => $intentar_fusionar_stderr_y_stdout?
setup    => $callback_para_configurar_comando
teardown => $callback_para_desmontar_comando

Intenta usar IPC::Open3 & IO::Select para comunicarse con el proceso generado si están disponibles. Retrocede a open().

Métodos de instancia

"next"

Itera a través de la salida del proceso, por supuesto.

"next_raw"

Itera la entrada cruda sin aplicar ninguna corrección para una sintaxis de entrada peculiar.

"wait"

Obtiene el estado de espera para el proceso de este iterador.

"exit"

Obtiene el estado de salida para el proceso de este iterador.

"handle_unicode"

Actualiza el flujo de entrada para manejar UTF8.

"get_select_handles"

Devuelve una lista de manejadores de archivos que pueden ser usados en un nivel superior en una llamada a select() para indicar que este Iterador está listo. Los iteradores que no están basados en manejadores deben devolver una lista vacía.
