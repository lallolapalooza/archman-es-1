TAP::Formatter::File::Session(3perl) Guía de referencia del programador de Perl TAP::Formatter::File::Session(3perl)

NOMBRE

TAP::Formatter::File::Session - Delegado de salida de Harness para salida de archivo

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Esto proporciona formato de salida orientado a archivos para TAP::Harness. Es particularmente importante cuando se ejecuta con pruebas paralelas, ya que garantiza que los resultados de las pruebas no se intercalen, incluso cuando se ejecuta de forma detallada.

MÉTODOS

resultado

Almacena los resultados para su posterior salida, todos juntos.

cerrar_prueba

Cuando el archivo de prueba finaliza, emite el resumen, todo junto.
