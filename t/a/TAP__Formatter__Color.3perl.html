NOMBRE

TAP::Formatter::Color - Ejecuta scripts de prueba de Perl con color

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Tenga en cuenta que este harness es experimental. Puede que no le gusten los colores que he elegido y aún no he proporcionado una forma fácil de ignorarlos.

Este harness de pruebas es el mismo que TAP::Harness, pero los resultados de las pruebas se muestran en color. Las pruebas que pasan se imprimen en verde. Las pruebas que fallan se muestran en rojo. Las pruebas omitidas son azules sobre un fondo blanco y las pruebas TODO se imprimen en blanco.

Si no se puede encontrar Term::ANSIColor (y Win32::Console::ANSI si se ejecuta en Windows), las pruebas se ejecutarán sin color.

SINOPSIS

use TAP::Formatter::Color;
my $harness = TAP::Formatter::Color->new( \%args );
$harness->runtests(@tests);

MÉTODOS

Métodos de clase

"new"

El constructor devuelve un nuevo objeto "TAP::Formatter::Color". Si no está instalado Term::ANSIColor, devuelve undef.

"can_color"

Test::Formatter::Color->can_color()

Devuelve un booleano que indica si este módulo puede generar realmente salida en color. Esto será falso si no pudo cargar los módulos necesarios para la plataforma actual.

"set_color"

Establece el color de salida.
