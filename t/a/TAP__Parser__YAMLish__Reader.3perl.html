NOMBRE

TAP::Parser::YAMLish::Reader - Lee datos YAMLish de un iterador

VERSIÓN

Versión 3.50

SINOPSIS

DESCRIPCIÓN

Tenga en cuenta que partes de este código se derivaron de YAML::Tiny con el permiso de Adam Kennedy.

MÉTODOS

Métodos de clase

"new"

El constructor "new" crea y devuelve un objeto vacío de "TAP::Parser::YAMLish::Reader".

my $reader = TAP::Parser::YAMLish::Reader->new;

Métodos de instancia

"read"

my $got = $reader->read($iterator);

Lee YAMLish de un TAP::Parser::Iterator y devuelve la estructura de datos que representa.

"get_raw"

my $source = $reader->get_source;

Devuelve el código fuente YAMLish crudo de la lectura más reciente de "read".
