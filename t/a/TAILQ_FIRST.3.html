DESCRIPCIÓN

Estas macros definen y operan sobre colas dobles de cola final.

En las definiciones de macro, TYPE es el nombre de una estructura definida por el usuario que debe contener un campo de tipo TAILQ_ENTRY, nombre NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola de cola es dirigida por una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento en la cola y el otro al último elemento en la cola. Los elementos están vinculados de forma que un elemento arbitrario puede ser removido sin recorrer la cola. Los elementos nuevos pueden agregarse a la cola después de un elemento existente, antes de un elemento existente, al frente de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara así:


TAILQ_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos vinculados en la cola. Una dirección de puntero al encabezado de la cola puede ser declarada posteriormente como:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

TAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola head.

TAILQ_INIT() inicializa la cola referida por

TAILQ_EMPTY() evalúa a true si no hay elementos en la cola. head.

Inserción

TAILQ_INSERT_HEAD() inserta el elemento nuevo elm al frente de la cola.

TAILQ_INSERT_TAIL() inserta el elemento nuevo elm al final de la cola.

TAILQ_INSERT_BEFORE() inserta el elemento nuevo elm antes del elemento listelm.

TAILQ_INSERT_AFTER() inserta el elemento nuevo elm después del elemento listelm.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor devuelto es NULL.

TAILQ_PREV() devuelve el elemento anterior de la cola, o NULL si este es el primero.

TAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este es el último.

TAILQ_FOREACH() recorre la cola referida por head en la dirección forward, asignando cada elemento a var por orden. var se establece a NULL si el ciclo termina normalmente, o si no hay elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referida por head en la dirección reversa, asignando cada elemento a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elm de la cola.

Otros_mechanismos

TAILQ_CONCAT() concatenación de la cola de head2 a la cola de head1, removiendo todos los elementos de la anterior.

VALOR_DEVOLUPADO

TAILQ_EMPTY() devuelve no cero si la cola está vacía, y cero si hay al menos un elemento.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero al primer, último, anterior, o siguiente TYPE estructura, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola head.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

CAMBIOS_Y_PORQUÉ

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten remover o liberar var dentro del ciclo, ya que podría interferir con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSDs pero no en glibc, corrigir esta limitación al permitir que var sea removido y liberado dentro del ciclo sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola de cola */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Encabezado de cola */
    int i;
    TAILQ_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al frente */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Eliminación */
    free(n2);
                                            /* Recorrido forward */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido reverse */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de cola */
    n

EJEMPLOS

Para liberar todos los elementos de una cola doblemente enlazada definida por TAILQ_HEAD y luego reinicializar la cola, puede usar el siguiente código:

    struct my_item *n1, *n2;

    TAILQ_FOREACH_SAFE(n1, &head, entries, n2) {
        TAILQ_REMOVE(&head, n1, entries);
        free(n1);
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);

Alternativamente, puede usar esto:

    struct my_item *n1, *n2;

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
