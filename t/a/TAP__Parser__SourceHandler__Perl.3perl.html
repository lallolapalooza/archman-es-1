TAP::Parser::SourceHandler::Perl(3perl) Guía de referencia del programador de Perl TAP::Parser::SourceHandler::Perl(3perl)

NOMBRE

TAP::Parser::SourceHandler::Perl - Transmite TAP desde un ejecutable de Perl

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::Perl;
my $source = TAP::Parser::Source->new->raw( \'script.pl' );
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::Perl';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPCIÓN

Este es un manejador de fuente TAP::Parser de Perl - tiene 2 tareas:

1. Determinar si el TAP::Parser::Source que recibe es realmente un script de Perl ("can_handle").

2. Crea un iterador para fuentes de Perl ("make_iterator").

A menos que estés escribiendo un plugin o subclasificando TAP::Parser, probablemente no necesites usar este módulo directamente.

MÉTODOS

Métodos de clase

"can_handle"

my $vote = $class->can_handle( $source );

Solo vota si $source parece un archivo. Emite los siguientes votos:

0.9  si tiene un shebang tipo "#!...perl"
0.3  si tiene algún shebang
0.8  si es un archivo .t
0.9  si es un archivo .pl
0.75 si está en un directorio 't'
0.25 por defecto (compatibilidad con versiones anteriores)

"make_iterator"

my $iterator = $class->make_iterator( $source );

Construye y devuelve un nuevo TAP::Parser::Iterator::Process para la fuente. Asume que "$source->raw" contiene una referencia al script de perl. Lanza una excepción ("croak") si el archivo no se pudo encontrar.

El comando a ejecutar se construye de la siguiente manera:

$perl @switches $perl_script @test_args

El comando perl a usar se determina con "get_perl". El comando generado garantiza preservar:

PERL5LIB
PERL5OPT
Modo Taint, si está configurado en el shebang del script

Nota: el comando generado no respetará ninguna línea de shebang definida en tu script de Perl. Esto solo es un problema si has compilado una versión personalizada de Perl o si deseas usar una versión específica de Perl para una prueba y otra versión para otra, por ejemplo:

#!/path/to/a/custom_perl --some --args
#!/usr/local/perl-5.6/bin/perl -w

Actualmente, necesitas escribir un plugin para evitar esto.

"get_taint"

Decodifica cualquier switch de taint de una línea shebang de Perl.

# $taint será 't'
my $taint = TAP::Parser::SourceHandler::Perl->get_taint( '#!/usr/bin/perl -t' );
# $untaint no estará definido
my $untaint = TAP::Parser::SourceHandler::Perl->get_taint( '#!/usr/bin/perl' );

"get_perl"

Obtiene la versión de Perl que actualmente ejecuta la suite de pruebas.

SUBCLASES

Por favor, consulta "SUBCLASSING" en TAP::Parser para una descripción general de la subclasificación.

Ejemplo

package MyPerlSourceHandler;
use strict;
use TAP::Parser::SourceHandler::Perl;
use base 'TAP::Parser::SourceHandler::Perl';
# usa la versión de perl de la línea shebang en el archivo de prueba
sub get_perl {
    my $self = shift;
    if (my $shebang = $self->shebang( $self->{file} )) {
        $shebang =~ /^#!(.*\bperl.*?)(?:(?:\s)|(?:$))/;
        return $1 if $1;
    }
    return $self->SUPER::get_perl(@_);
}
