TAP::Parser::Source(3perl) Guía del programador de Perl TAP::Parser::Source(3perl)

NOMBRE

TAP::Parser::Source - una fuente TAP y metadatos sobre ella

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Source;
my $source = TAP::Parser::Source->new;
$source->raw( \'referencia a la fuente TAP cruda' )
       ->config( \%config )
       ->merge( $booleano )
       ->switches( \@switches )
       ->test_args( \@args )
       ->assemble_meta;
do { ... } if $source->meta->{is_file};
# ver assemble_meta para una lista completa de datos disponibles

DESCRIPCIÓN

Una fuente TAP es algo que produce un flujo de TAP para que el analizador lo consuma, como un archivo ejecutable, un archivo de texto, un archivo, un manejador de IO, una base de datos, etc. Los "TAP::Parser::Source" encapsulan estas fuentes crudas y proporcionan algunos metadatos útiles sobre ellas. Son utilizados por TAP::Parser::SourceHandlers, que hacen lo necesario para producir y capturar un flujo de TAP desde la fuente cruda, y lo empaquetan en un TAP::Parser::Iterator para que el analizador lo consuma.

A menos que estés escribiendo un nuevo TAP::Parser::SourceHandler, un plugin o subclasificando TAP::Parser, probablemente no necesites usar este módulo directamente.

MÉTODOS

Métodos de clase

"new"

my $source = TAP::Parser::Source->new;

Devuelve un nuevo objeto "TAP::Parser::Source".

Métodos de instancia

"raw"

my $raw = $source->raw;
$source->raw( $algun_valor );

Getter/setter encadenado para la fuente TAP cruda. Es una referencia, ya que puede contener grandes cantidades de datos (p.ej., TAP crudo).

"meta"

my $meta = $source->meta;
$source->meta({ %algun_valor });

Getter/setter encadenado para metadatos sobre la fuente. Esto es un hashref vacío por defecto. Ver "assemble_meta" para más información.

"has_meta"

Verdadero si la fuente tiene metadatos.

"config"

my $config = $source->config;
$source->config({ %algun_valor });

Getter/setter encadenado para la configuración de la fuente, si se ha proporcionado alguna por el usuario. Cómo se usa depende de ti. Esto es un hashref vacío por defecto. Ver "config_for" para más información.

"merge"

my $merge = $source->merge;
$source->config( $bool );

Getter/setter encadenado para el indicador que dicta si STDOUT y STDERR deben fusionarse (donde sea apropiado). Por defecto es undef.

"switches"

my $switches = $source->switches;
$source->config([ @switches ]);

Getter/setter encadenado para la lista de interruptores de línea de comandos que deben pasarse a la fuente (donde sea apropiado). Por defecto es undef.

"test_args"

my $test_args = $source->test_args;
$source->config([ @test_args ]);

Getter/setter encadenado para la lista de argumentos de línea de comandos que deben pasarse a la fuente (donde sea apropiado). Por defecto es undef.

"assemble_meta"

my $meta = $source->assemble_meta;

Recopila metadatos sobre la fuente "cruda", los almacena en "meta" y los devuelve como un hashref. Esto se hace para que los TAP::Parser::SourceHandlers no tengan que repetir verificaciones comunes. Actualmente esto incluye:

  is_scalar => $bool,
  is_hash   => $bool,
  is_array  => $bool,
  # para escalares:
  length => $n
  has_newlines => $bool
  # solo se realiza si el escalar parece un nombre de archivo
  is_file => $bool,
  is_dir  => $bool,
  is_symlink => $bool,
  file => {
      # solo se realiza si el escalar parece un nombre de archivo
      basename => $string, # incluyendo extensión
      dir      => $string,
      ext      => $string,
      lc_ext   => $string,
      # verificaciones del sistema
      exists  => $bool,
      stat    => [ ... ], # perldoc -f stat
      empty   => $bool,
      size    => $n,
      text    => $bool,
      binary  => $bool,
      read    => $bool,
      write   => $bool,
      execute => $bool,
      setuid  => $bool,
      setgid  => $bool,
      sticky  => $bool,
      is_file => $bool,
      is_dir  => $bool,
      is_symlink => $bool,
      # solo se realiza si el archivo es un enlace simbólico
      lstat      => [ ... ], # perldoc -f lstat
      # solo se realiza si el archivo es un archivo de texto legible
      shebang => $first_line,
  }
# para arrays:
size => $n,

"shebang"

Obtiene la línea shebang para un archivo script.

my $shebang = TAP::Parser::Source->shebang( $algun_script );

Puede ser llamado como método de clase.

"config_for"

my $config = $source->config_for( $clase );

Devuelve la "config" para la $clase dada. Los nombres de clase pueden ser completamente calificados o abreviados, p.ej.:

# estos son equivalentes
$source->config_for( 'Perl' );
$source->config_for( 'TAP::Parser::SourceHandler::Perl' );

Si se proporciona una $clase completamente calificada, su versión abreviada se comprueba primero.
