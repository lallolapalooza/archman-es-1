TAP::Harness::Env(3perl) Guía de referencia del programador de Perl TAP::Harness::Env(3perl)

NOMBRE

TAP::Harness::Env - Analizar variables de entorno relacionadas con el harness según corresponda

VERSIÓN

Versión 3.50

SINOPSIS

my $harness = TAP::Harness::Env->create(\%extra_args)

DESCRIPCIÓN

Este módulo implementa las variables de entorno que Test::Harness usa con TAP::Harness, y crea la clase apropiada con los argumentos apropiados.

MÉTODOS

•
create( \%args )

Esta función lee el entorno y genera una tabla hash de argumentos apropiada a partir de él. Si se le dan argumentos en %extra_args, estos anularán los valores por defecto del entorno. Acepta "harness_class" (que por defecto es "TAP::Harness"), y cualquier argumento que la clase harness acepte.

VARIABLES DE ENTORNO

"HARNESS_PERL_SWITCHES"
Establecer esto añade interruptores de línea de comandos de perl a cada archivo de prueba ejecutado.

Por ejemplo, "HARNESS_PERL_SWITCHES=-T" activará el modo de contaminaciòn (taint mode). "HARNESS_PERL_SWITCHES=-MDevel::Cover" ejecutará "Devel::Cover" para cada prueba.

"HARNESS_VERBOSE"
Si es verdadero, "TAP::Harness" mostrará los resultados detallados de la ejecución de sus pruebas.
"HARNESS_SUBCLASS"
Especifica una subclase de TAP::Harness que se utilizará en lugar de TAP::Harness.
"HARNESS_OPTIONS"
Proporciona opciones adicionales al harness. Las opciones actualmente soportadas son:
"j<n>"
Ejecuta <n> (por defecto 9) trabajos paralelos.
"c"
Intenta colorear la salida. Ver "new" en TAP::Formatter::Base.
"a<file.tgz>"
Usará TAP::Harness::Archive como clase harness, y guardará el TAP en "file.tgz"
"fPackage-With-Dashes"
Establece la clase formateadora (formatter_class) del harness que se está ejecutando. Dado que "HARNESS_OPTIONS" está separada por ":", usamos "-" en su lugar.

Se pueden separar múltiples opciones con dos puntos:

HARNESS_OPTIONS=j9:c make test
"HARNESS_TIMER"
Establecer esto a verdadero hará que el harness muestre el número de milisegundos que tardó cada prueba. También puedes usar el interruptor "--timer" de prove.
"HARNESS_COLOR"
Intenta producir salida en color.
"HARNESS_IGNORE_EXIT"
Si se establece en un valor verdadero, instruye a "TAP::Parser" para ignorar el estado de salida y espera de los scripts de prueba.
