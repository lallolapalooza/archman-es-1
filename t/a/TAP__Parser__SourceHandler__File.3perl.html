TAP::Parser::SourceHandler::File(3perl) Guía del programador de Perl TAP::Parser::SourceHandler::File(3perl)

NOMBRE

TAP::Parser::SourceHandler::File - Transmite TAP desde un archivo de texto.

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::File;
my $source = TAP::Parser::Source->new->raw( \'file.tap' );
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::File';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPCIÓN

Este es un manejador de fuentes TAP::Parser de TAP crudo almacenado en un archivo - tiene 2 trabajos:

1. Determina si la fuente cruda que se le da es un archivo que contiene salida TAP cruda. Ver TAP::Parser::IteratorFactory para más detalles.

2. Toma TAP crudo del archivo de texto dado y lo convierte en un iterador.

A menos que estés escribiendo un plugin o subclase de TAP::Parser, probablemente no necesites usar este módulo directamente.

MÉTODOS

Métodos de clase

"can_handle"

my $vote = $class->can_handle( $source );

Solo vota si $source parece ser un archivo regular. Emite los siguientes votos:

0.9 si es un archivo .tap
0.9 si tiene una extensión que coincide con alguna dada en la configuración del usuario.

"make_iterator"

my $iterator = $class->make_iterator( $source );

Devuelve un nuevo TAP::Parser::Iterator::Stream para la fuente. Realiza un "croak" en caso de error.

"iterator_class"

La clase del iterador a usar, anúlala si estás subclaseando. Por defecto es TAP::Parser::Iterator::Stream.

CONFIGURACIÓN

{
 extensions => [ @case_insensitive_exts_to_match ]
}
