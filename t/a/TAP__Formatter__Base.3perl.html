TAP::Formatter::Base(3perl) Guía de referencia para programadores de Perl TAP::Formatter::Base(3perl)

NOMBRE

TAP::Formatter::Base - Clase base para delegados de salida de harness

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Esto proporciona formato de salida orientado a la consola para TAP::Harness.

SINOPSIS

use TAP::Formatter::Console;
my $harness = TAP::Formatter::Console->new( \%args );

MÉTODOS

Métodos de clase

"new"

my %args = (
   verbose => 1,
)
my $harness = TAP::Formatter::Console->new( \%args );

El constructor devuelve un nuevo objeto "TAP::Formatter::Console". Si se crea un TAP::Harness sin "formatter", se crea automáticamente un "TAP::Formatter::Console". Si se pasaron algunas de las siguientes opciones a TAP::Harness->new, se pasarán a este constructor, que acepta un hashref opcional cuyas claves permitidas son:

  • "verbosity"

    Establece el nivel de verbosidad.

  • "verbose"

    Imprime resultados de pruebas individuales en STDOUT.

  • "timer"

    Añade el tiempo de ejecución de cada prueba a la salida. Utiliza Time::HiRes si está disponible.

  • "failures"

    Muestra los fallos de las pruebas (esto es inútil si se selecciona "verbose").

  • "comments"

    Muestra comentarios de las pruebas (esto es inútil si se selecciona "verbose").

  • "quiet"

    Suprime parte de la salida de las pruebas (principalmente fallos mientras se ejecutan las pruebas).

  • "really_quiet"

    Suprime todo excepto el resumen de las pruebas.

  • "silent"

    Suprime toda la salida.

  • "errors"

    Si se encuentran errores de análisis en la salida TAP, se hará una nota de esto en el informe resumen. Para ver todos los errores de análisis, establezca este argumento a verdadero:

    errors => 1
  • "directives"

    Si se establece a un valor verdadero, solo se mostrarán los resultados de las pruebas con directivas. Esto anula otras configuraciones como "verbose", "failures", o "comments".

  • "stdout"

    Un manejador de archivo para capturar la salida estándar.

  • "color"

    Si se define, especifica si se desea salida a color. Si "color" no está definido, se usará salida a color por defecto si el soporte de color está disponible en la plataforma actual y la salida no está siendo redirigida.

  • "jobs"

    El número de trabajos concurrentes que manejará este formateador.

  • "show_count"

    Valor booleano. Si es falso, deshabilita el contador de pruebas "X/Y" que aparece mientras se ejecutan las pruebas.

Cualquier clave cuyo valor sea "undef" será ignorada.

"prepare"

Llamado por Test::Harness antes de que se genere cualquier salida de prueba.

Esto es un aviso y puede que no se llame en el caso en que las pruebas estén siendo suministradas a Test::Harness por un iterador.

"open_test"

Llamado para crear una nueva sesión de prueba. Una sesión de prueba se ve así:

my $session = $formatter->open_test( $test, $parser );
while ( defined( my $result = $parser->next ) ) {
    $session->result($result);
    exit 1 if $result->is_bailout;
}
$session->close_test;

"summary"

$harness->summary( $aggregate );

"summary" imprime el informe resumen después de que se ejecutan todas las pruebas. El primer argumento es un agregado para resumir. Un segundo argumento opcional puede ser establecido a un valor verdadero para indicar que el resumen se está emitiendo como resultado de una ejecución de prueba interrumpida.
