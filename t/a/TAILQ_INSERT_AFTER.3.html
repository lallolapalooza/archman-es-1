TAILQ(3) Manual de funciones estándar TAILQ(3)

NAME

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_REMOVE - implementación de una cola doble tail

LIBRARY

Librería de C estándar (libc, -lc)

SYNOPSIS

#include <sys/queue.h>
TAILQ_ENTRY(TYPE);
TAILQ_HEAD(HEADNAME, TYPE);
TAILQ_HEAD TAILQ_HEAD_INITIALIZER(TAILQ_HEAD head);
void TAILQ_INIT(TAILQ_HEAD *head);
int TAILQ_EMPTY(TAILQ_HEAD *head);
void TAILQ_INSERT_HEAD(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_BEFORE(struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_FIRST(TAILQ_HEAD *head);
struct TYPE *TAILQ_LAST(TAILQ_HEAD *head, HEADNAME);
struct TYPE *TAILQ_PREV(struct TYPE *elm, HEADNAME, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_NEXT(struct TYPE *elm, TAILQ_ENTRY NAME);
TAILQ_FOREACH(struct TYPE *var, TAILQ_HEAD *head,
                         TAILQ_ENTRY NAME);
TAILQ_FOREACH_REVERSE(struct TYPE *var, TAILQ_HEAD *head, HEADNAME,
                         TAILQ_ENTRY NAME);
void TAILQ_REMOVE(TAILQ_HEAD *head, struct TYPE *elm,
                         TAILQ_ENTRY NAME);
void TAILQ_CONCAT(TAILQ_HEAD *head1, TAILQ_HEAD *head2,
                         TAILQ_ENTRY NAME);

DESCRIPCIÓN

Estas macro definen y operan sobre una cola doble tail. En las definiciones de macro, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, con el nombre NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola doble se encabeza por una estructura definida con la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento en la cola y el otro al último elemento en la cola. Los elementos están vinculados de manera que un elemento arbitrario puede ser removido sin recorrer la cola. Los elementos nuevos pueden agregarse a la cola después de un elemento existente, antes de un elemento existente, al frente de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara así: 

TAILQ_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos vinculados en la cola. Una dirección del puntero al cabeza de la cola puede ser declarada más tarde así: 

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

TAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola head.

TAILQ_INIT() inicializa la cola referida por head.

TAILQ_EMPTY() evalúa a true si no hay elementos en la cola head.

Inserción

TAILQ_INSERT_HEAD() inserta el elemento nuevo elm al frente de la cola.

TAILQ_INSERT_TAIL() inserta el elemento nuevo elm al final de la cola.

TAILQ_INSERT_BEFORE() inserta el elemento nuevo elm antes del elemento listelm.

TAILQ_INSERT_AFTER() inserta el elemento nuevo elm después del elemento listelm.

Recorrido

TAILQ_FIRST() devuelve el primer elemento en la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento en la cola. Si la cola está vacía, el valor devuelto es NULL.

TAILQ_PREV() devuelve el elemento anterior en la cola, o NULL si este es el primero.

TAILQ_NEXT() devuelve el siguiente elemento en la cola, o NULL si este es el último.

TAILQ_FOREACH() recorre la cola referida por head en la dirección forward, asignando cada elemento a var por turnos. var se establece a NULL si el bucle termina normalmente, o si no hay elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referida por head en la dirección reverse, asignando cada elemento a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elm de la cola.

Otras_ventajas

TAILQ_CONCAT() concatená la cola encabezada por head2 al final de la cola encabezada por head1, eliminando todos los elementos de la anterior.

VALOR_RETORNA

TAILQ_EMPTY() devuelve no cero si la cola está vacía, y cero si hay al menos un elemento.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV() y TAILQ_NEXT() devuelven un puntero al primer, último, anterior o siguiente TYPE estructura, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola head.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

CAVEATS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten la remoción de var o su liberación dentro del bucle, ya que podría interferir con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSDs pero no en glibc, corriguen esta limitación al permitir que var se pueda removido de la lista y liberado dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola doble tail */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Cabeza de la cola */
    int i;
    TAILQ_INIT(&head);                      /* Inicializa la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al frente */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Borrar */
    free(n2);
                                            /* Recorrido forward */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido reverse */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Borrado de la cola */

TAILQ_INSERT_AFTER(3)

NAME

TAILQ_INSERT_AFTER, TAILQ_INSERT_BETWEEN, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_REMOVE - macros for manipulating tail queues

LIBRARY

libbsd

SYNOPSIS

    #include <sys/queue.h>

    void
    TAILQ_INSERT_AFTER(tailq, listelm, elm);

    void
    TAILQ_INSERT_BETWEEN(tailq, listelm1, listelm2, elm);

    void
    TAILQ_INSERT_HEAD(tailq, elm);

    void
    TAILQ_INSERT_TAIL(tailq, elm);

    void
    TAILQ_REMOVE(tailq, elm);

DESCRIPTION

These macros provide functionality for manipulating tail queues. A tail queue is a doubly linked list that is ordered, and allows for efficient insertion and deletion of elements anywhere in the list. The elements of the queue are defined by the user.

The structures used in the macros are defined as follows:

    typedef struct _tailq_head {
        struct _tailq_head  *tqh_first;  /* first element */
        struct _tailq_head **tqh_last;  /* last element */
    } tailq_head;

    typedef struct _tailq_entry {
        struct _tailq_entry  *tqe_next;   /* next element */
        struct _tailq_entry  **tqe_prev;  /* previous element */
    } tailq_entry;

The TAILQ_INSERT_* macros insert the element elm into the tail queue specified by tailq.

TAILQ_INSERT_HEAD
Insert the element elm at the head of the tail queue.
TAILQ_INSERT_TAIL
Insert the element elm at the tail of the tail queue.
TAILQ_INSERT_AFTER
Insert the element elm after the element listelm in the tail queue.
TAILQ_INSERT_BETWEEN
Insert the element elm between the elements listelm1 and listelm2 in the tail queue.

The TAILQ_REMOVE macro removes the element elm from the tail queue specified by tailq.

Note that the macros do not handle the memory allocation or deallocation of the elements. The user is responsible for managing the memory of the elements.

RETURN VALUE

None of these macros return a value.

STANDARDS

These macros are non-standard but commonly found in BSD-derived systems. They are part of the libbsd library.

HISTORY

The tail queue macros first appeared in 4.4BSD.

CAVEATS

Care must be taken when using these macros. For example, trying to remove an element that is not in the queue, or trying to insert an element after a non-existent element, can lead to undefined behavior.

The TAILQ_INSERT_BETWEEN macro assumes that listelm1 and listelm2 are adjacent elements in the queue, with listelm1 preceding listelm2.

EXAMPLES

The following example shows how to initialize a tail queue, insert elements into it, and then remove and free them:

    #include <stdio.h>
    #include <stdlib.h>
    #include <sys/queue.h>

    typedef struct my_node {
        int data;
        tailq_entry entries;
    } my_node;

    int
    main() {
        struct tailq_head head;
        struct my_node *n1, *n2;

        TAILQ_INIT(&head);

        /* Allocate and insert nodes */
        n1 = malloc(sizeof(struct my_node));
        n1->data = 10;
        TAILQ_INSERT_TAIL(&head, n1, entries);

        n2 = malloc(sizeof(struct my_node));
        n2->data = 20;
        TAILQ_INSERT_TAIL(&head, n2, entries);

        /* Iterate through the queue */
        for (n1 = TAILQ_FIRST(&head); n1 != NULL; n1 = TAILQ_NEXT(n1, entries)) {
            printf("%d ", n1->data);
        }
        printf("\n");

        /* Remove and free nodes */
        n1 = TAILQ_FIRST(&head);
        while (n1 != NULL) {
            n2 = TAILQ_NEXT(n1, entries);
            free(n1);
            n1 = n2;
        }
        TAILQ_INIT(&head);
        exit(EXIT_SUCCESS);
    }
