TAP::Parser::IteratorFactory(3perl) Guía de referencia del programador de Perl TAP::Parser::IteratorFactory(3perl)

NOMBRE

TAP::Parser::IteratorFactory - Determina qué objetos SourceHandler usar para una Source dada

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::IteratorFactory;
my $factory = TAP::Parser::IteratorFactory->new({ %config });
my $iterator  = $factory->make_iterator( $filename );

DESCRIPCIÓN

Esta es una clase fábrica que toma un TAP::Parser::Source y lo ejecuta a través de todos los TAP::Parser::SourceHandlers registrados para ver cuál debería manejar la fuente.

Si eres un autor de plugins, te interesará cómo "registrar_handler", cómo funciona "detect_source".

MÉTODOS

Métodos de clase

"new"

Crea una nueva clase fábrica:

my $sf = TAP::Parser::IteratorFactory->new( $config );

$config es opcional. Si se proporciona, establece "config" y llama a "load_handlers".

"register_handler"

Registra un nuevo TAP::Parser::SourceHandler con esta fábrica.

__PACKAGE__->register_handler( $handler_class );

"handlers"

Lista de manejadores que han sido registrados.

Métodos de instancia

"config"

my $cfg = $sf->config;
$sf->config({ Perl => { %config } });

Getter/setter en cadena para la configuración de los manejadores de fuente disponibles. Este es un hashref con claves del nombre de la clase del manejador cuyos valores contienen la configuración que se pasará a los manejadores durante la detección y creación. Los nombres de clase pueden estar completamente calificados o abreviados, por ejemplo:

# estos son equivalentes
$sf->config({ 'TAP::Parser::SourceHandler::Perl' => { %config } });
$sf->config({ 'Perl' => { %config } });

"load_handlers"

$sf->load_handlers;

Carga las clases de manejador definidas en "config". Por ejemplo, dada una configuración:

$sf->config({
  MySourceHandler => { some => 'config' },
});

"load_handlers" intentará cargar la clase "MySourceHandler" buscando en @INC en este orden:

TAP::Parser::SourceHandler::MySourceHandler
MySourceHandler

"croak" en caso de error.

"make_iterator"

my $iterator = $src_factory->make_iterator( $source );

Dado un TAP::Parser::Source, encuentra el TAP::Parser::SourceHandler más adecuado para usarlo para crear un TAP::Parser::Iterator (ver "detect_source"). Muere en caso de error.

"detect_source"

Dado un TAP::Parser::Source, detecta qué tipo de fuente es y devuelve *un* TAP::Parser::SourceHandler (el más confiable). Muere en caso de error.

El algoritmo de detección funciona algo así:

for (@registered_handlers) {
  # les preguntamos qué tan confiados están en manejar esta fuente
  $confidence{$handler} = $handler->can_handle( $source )
}
# elegimos el manejador más confiable

Los empates se manejan eligiendo el primer manejador.
