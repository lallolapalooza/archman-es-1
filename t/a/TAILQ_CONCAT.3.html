TAILQ_CONCAT(3) Manual de funciones de biblioteca TAILQ_CONCAT(3)

NAME

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_REMOVE - implementación de una cola doble de fin

LIBRARY

Librería de C estándar (libc, -lc)

SINTAXIS

#include <sys/queue.h>
TAILQ_ENTRY(TYPE);
TAILQ_HEAD(HEADNAME, TYPE);
TAILQ_HEAD TAILQ_HEAD_INITIALIZER(TAILQ_HEAD head);
void TAILQ_INIT(TAILQ_HEAD *head);
int TAILQ_EMPTY(TAILQ_HEAD *head);
void TAILQ_INSERT_HEAD(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_BEFORE(struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_FIRST(TAILQ_HEAD *head);
struct TYPE *TAILQ_LAST(TAILQ_HEAD *head, HEADNAME);
struct TYPE *TAILQ_PREV(struct TYPE *elm, HEADNAME, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_NEXT(struct TYPE *elm, TAILQ_ENTRY NAME);
TAILQ_FOREACH(struct TYPE *var, TAILQ_HEAD *head,
                         TAILQ_ENTRY NAME);
TAILQ_FOREACH_REVERSE(struct TYPE *var, TAILQ_HEAD *head, HEADNAME,
                         TAILQ_ENTRY NAME);
void TAILQ_REMOVE(TAILQ_HEAD *head, struct TYPE *elm,
                         TAILQ_ENTRY NAME);
void TAILQ_CONCAT(TAILQ_HEAD *head1, TAILQ_HEAD *head2,
                         TAILQ_ENTRY NAME);

DESCRIPCIÓN

Estas macros definen y operan en una cola doble de fin.

En las definiciones de las macros, TYPE es el nombre de un estructura definida por el usuario que debe contener un campo de tipo TAILQ_ENTRY, denominado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola de fin está dirigida por una estructura definida con la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al elemento primero en la cola y el otro al último. Los elementos están ligados de forma doble, lo que permite eliminar cualquier elemento sin recorrer la cola. Los elementos nuevos pueden agregarse a la cola después de un elemento existente, antes de otro, en el inicio de la cola o en el final. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos que se vinculan a la cola. Un puntero a la cabeza de la cola puede posteriormente ser declarado como:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

TAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola head.

TAILQ_INIT() inicializa la cola referida por head.

TAILQ_EMPTY() devuelve true si no hay elementos en la cola. head.

Inserción

TAILQ_INSERT_HEAD() inserta el elemento nuevo elm al inicio de la cola.

TAILQ_INSERT_TAIL() inserta el elemento nuevo elm al final de la cola.

TAILQ_INSERT_BEFORE() inserta el elemento nuevo elm antes del elemento listelm.

TAILQ_INSERT_AFTER() inserta el elemento nuevo elm después del elemento listelm.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor devuelto es NULL.

TAILQ_PREV() devuelve el elemento anterior en la cola, o NULL si este es el primero.

TAILQ_NEXT() devuelve el siguiente elemento en la cola, o NULL si este es el último.

TAILQ_FOREACH() recorre la cola referida por head en la dirección forward, asignando cada elemento a var. var se establece en NULL si el bucle termina normalmente, o si no hay elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referida por head en la dirección inversa, asignando cada elemento a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elm de la cola.

Otras características

TAILQ_CONCAT() concatenación de la cola de fin dirigida por head2 al final de la cola de fin dirigida por head1, eliminando todos los elementos del anterior.

VALOR_RETORNO

TAILQ_EMPTY() devuelve no cero si la cola está vacía, y cero si hay al menos un elemento.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero al primer, último, anterior, o siguiente TYPE estructura, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola head.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

CAMBIOS_DE_PUNTAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten eliminar o liberar var dentro del bucle, ya que podría interferir con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en BSD pero no en glibc, corrigen este límite permitiendo a var ser eliminado y liberado dentro del bucle sin interferir con el recorrido.

EJEMPLO

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola de fin */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Cabeza de la cola */
    int i;
    TAILQ_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al inicio */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Eliminación */
    free(n2);
                                            /* Recorrido forward */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido reverse */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de la cola */
    while (!TAILQ_EMPTY(&head)) {
        np = TAILQ_FIRST(&head);
        TAILQ_REMOVE(&head, np, entries);
        free(np);
    }
    return 0;
}
TAILQ_CONCAT(3bsd) — Arch Linux man pages

NAME

TAILQ_CONCAT — concatenate two doubly-linked lists

LIBRARY

Libbsd

SYNOPSIS

#include <sys/queue.h>
void
TAILQ_CONCAT(TAILQ_HEAD(type, name) *head1, TAILQ_HEAD(type, name) *head2);

DESCRIPTION

The TAILQ_CONCAT macro appends the contents of the doubly-linked list pointed to by head2 to the end of the doubly-linked list pointed to by head1. After the operation, the list head2 will be empty.

RETURN VALUE

None.

STANDARDS

The TAILQ_CONCAT macro is expected to be part of the IEEE Std 1003.1-2008 («POSIX.1») standard, but it is not available in the standard as of version 2017.

HISTORY

The TAILQ macros first appeared in FreeBSD 3.0.

CAVEATS

The elements must be of the same type and must have been inserted into the lists using the same TAILQ macros.

It is the responsibility of the caller to ensure that the head1 and head2 arguments are valid pointers to TAILQ heads.

EXAMPLES

The following example concatenates the list l1 to the end of the list l2, then frees all elements of l2, and finally initializes the list l2 to an empty list:

struct my_list_head {
    TAILQ_ENTRY(my_list_node) entries;
    /* ... */
};
struct my_list_head l1, l2;
struct my_list_head *n1, *n2;
TAILQ_INIT(&l1);
TAILQ_INIT(&l2);
/* ... populate l1 and l2 ... */
TAILQ_CONCAT(&l1, &l2);
/* Now l1 contains all elements, and l2 is empty */
/* Free all elements from the concatenated list */
n1 = TAILQ_FIRST(&l1);
while (n1 != NULL) {
    n2 = TAILQ_NEXT(n1, entries);
    free(n1);
    n1 = n2;
}
TAILQ_INIT(&l1);
/* If l2 was intended to be reused: */
TAILQ_INIT(&l2);
    exit(EXIT_SUCCESS);
}
