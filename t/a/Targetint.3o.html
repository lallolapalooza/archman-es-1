Módulo Targetint
: sig end

Números enteros de procesador nativos.

Este módulo proporciona operaciones sobre el tipo de enteros signados de 32 bits (en plataformas de 32 bits de destino) o enteros signados de 64 bits (en plataformas de 64 bits de destino). Este tipo de entero tiene exactamente la misma anchura que el tipo de puntero en el compilador C. Todas las operaciones aritméticas sobre el tipo se realizan módulo 2^32 o 2^64 según el tamaño de palabra de la arquitectura de destino.

Advertencia: este módulo es inestable y parte de Compiler_libs .

type t

El tipo de números enteros de destino.

val zero : t

El número entero de destino 0.

val one : t

El número entero de destino 1.

val minus_one : t

El número entero de destino -1.

val neg : t -> t

Negación unaria.

val add : t -> t -> t

Adición.

val sub : t -> t -> t

Sustracción.

val mul : t -> t -> t

Multiplicación.

val div : t -> t -> t

División entera. Lanza Division_by_zero si el segundo argumento es cero. Esta división redondea el cociente real de sus argumentos hacia cero, como se especifica para el operador (/) .

val unsigned_div : t -> t -> t

La misma que Targetint.div , a menos que los argumentos y el resultado se interpreten como enteros unsigned.

val rem : t -> t -> t

Resto entero. Si y no es cero, el resultado de Targetint.rem x y satisface las siguientes propiedades: Targetint.zero <= Nativeint.rem x y < Targetint.abs y y x = Targetint.add (Targetint.mul (Targetint.div x y) y)
(Targetint.rem x y) . Si y = 0 , Targetint.rem x y lanza Division_by_zero .

val unsigned_rem : t -> t -> t

La misma que Targetint.rem , a menos que los argumentos y el resultado se interpreten como enteros unsigned.

val succ : t -> t

Sucedor. Targetint.succ x es Targetint.add x Targetint.one .

val pred : t -> t

Predecesor. Targetint.pred x es Targetint.sub x Targetint.one .

val abs : t -> t

abs x es el valor absoluto de x . En min_int esto es min_int mismo y así se mantiene negativo.

val size : int

La cantidad de bits en un número entero de destino nativo.

val max_int : t

El número entero más grande representable en el destino, que es 2^31 - 1 en una plataforma de 32 bits o 2^63 - 1 en una plataforma de 64 bits.

val min_int : t

El número entero más pequeño representable en el destino, que es -2^31 en una plataforma de 32 bits o -2^63 en una plataforma de 64 bits.

val logand : t -> t -> t

AND lógico bit a bit.

val logor : t -> t -> t

OR lógico bit a bit.

val logxor : t -> t -> t

XOR lógico bit a bit.

val lognot : t -> t

Negación lógica bit a bit.

val shift_left : t -> int -> t

Targetint.shift_left x y desplaza x a la izquierda en y bits. El resultado es indeterminado si y < 0 o y >= bitsize , donde bitsize es 32 en una plataforma de 32 bits y 64 en una plataforma de 64 bits.

val shift_right : t -> int -> t

Targetint.shift_right x y desplaza x a la derecha en y bits. Este es un desplazamiento aritmético: el bit de signo de x se repite y se inserta en los bits vacíos. El resultado es indeterminado si y < 0 o y >= bitsize .

val shift_right_logical : t -> int -> t

Targetint.shift_right_logical x y desplaza x a la derecha en y bits. Este es un desplazamiento lógico: se insertan ceros en los bits vacíos, independientemente del signo de x . El resultado es indeterminado si y < 0 o y >= bitsize .

val of_int : int -> t

Convierte el entero dado (tipo int) a un número entero de destino (tipo t), módulo el tamaño de palabra del destino.

val of_int_exn : int -> t

Convierte el entero dado (tipo int) a un número entero de destino (tipo t ). Lanza un error grave si la conversión no es exacta.

val to_int : t -> int

Convierte el número entero dado (tipo t) a un entero (tipo int ). El bit más significativo se pierde durante la conversión.

val of_float : float -> t

Convierte un número de punto flotante dado a un número entero de destino, descartando la parte fraccionaria (redondear hacia cero). El resultado de la conversión es indefinido si, tras el redondeo, el número está fuera del rango [ Targetint.min_int, Targetint.max_int ].

val to_float : t -> float

Convierte un número entero dado a un número de punto flotante.

val of_int32 : int32 -> t

Convierte el entero dado (tipo int32) a un número entero de destino.

val to_int32 : t -> int32

Convierte el número entero dado (tipo t) a un entero de 32 bits (tipo int32 ). En plataformas de 64 bits, el entero de 64 bits nativo se toma módulo 2^32, es decir, se pierden los 32 bits más significativos. En plataformas de 32 bits, la conversión es exacta.

val of_int64 : int64 -> t

Convierte el entero dado (tipo int64) a un número entero de destino.

val to_int64 : t -> int64

Convierte el número entero dado (tipo t) a un entero de 64 bits (tipo int64 ).

val of_string : string -> t

Convierte una cadena dada a un número entero de destino. La cadena se lee en decimal (por defecto) o en hexadecimal, octal o binario si comienza con 0x, 0o o 0b. Se lanza Failure "int_of_string" si la cadena dada no es una representación válida de un entero o si el entero representado excede el rango de enteros representable en el tipo nativeint .

val to_string : t -> string

Devuelve la representación en cadena de su argumento, en decimal.

val compare : t -> t -> int

La función de comparación para números enteros de destino, con la misma especificación que compare . Con el tipo t , esta función compare permite pasar el módulo Targetint como argumento a los funtores Set.Make y Map.Make .

val unsigned_compare : t -> t -> int

La misma que Targetint.compare , a menos que los argumentos se interpreten como enteros unsigned.

val equal : t -> t -> bool

La función de igualdad para números enteros de destino.

type repr =
| Int32 of int32
| Int64 of int64

val repr : t -> repr

La representación concreta de un entero nativo.

val print : Format.formatter -> t -> unit

Imprime un número entero de destino en un formateador.
