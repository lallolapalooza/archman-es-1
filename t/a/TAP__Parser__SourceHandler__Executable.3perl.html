TAP::Parser::SourceHandler::Executable(3perl) Guía del programador de Perl TAP::Parser::SourceHandler::Executable(3perl)

NOMBRE

TAP::Parser::SourceHandler::Executable - Transmite la salida de una fuente TAP ejecutable

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::Executable;
my $source = TAP::Parser::Source->new->raw(['/usr/bin/ruby', 'mytest.rb']);
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::Executable';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

DESCRIPCIÓN

Este es un TAP::Parser::SourceHandler *ejecutable* - tiene 2 tareas:

1. Averiguar si el TAP::Parser::Source que recibe es un comando ejecutable ("can_handle").

2. Crear un iterador para comandos ejecutables ("make_iterator").

A menos que estés escribiendo un plugin o una subclase de TAP::Parser, probablemente no necesites usar este módulo directamente.

MÉTODOS

Métodos de Clase

"can_handle"

my $vote = $class->can_handle( $source );

Solo vota si $source parece un archivo ejecutable. Emite los siguientes votos:

0.9  si es un hash con la clave 'exec'
0.8  si es un archivo .bat
0.75 si tiene el bit de ejecución activado

"make_iterator"

my $iterator = $class->make_iterator( $source );

Devuelve un nuevo TAP::Parser::Iterator::Process para la fuente. "$source->raw" debe estar en una de las siguientes formas:

{ exec => [ @exec ] }
[ @exec ]
$file

Realiza un "croak" en caso de error.

"iterator_class"

La clase del iterador a utilizar, anula si estás creando una subclase. Por defecto es TAP::Parser::Iterator::Process.

SUBCLASES

Por favor, consulta "SUBCLASSING" en TAP::Parser para una visión general de la creación de subclases.

Ejemplo

package MyRubySourceHandler;
use strict;
use Carp qw( croak );
use TAP::Parser::SourceHandler::Executable;
use base 'TAP::Parser::SourceHandler::Executable';
# espera $handler->(['mytest.rb', 'cmdline', 'args']);
sub make_iterator {
  my ($self, $source) = @_;
  my @test_args = @{ $source->test_args };
  my $rb_file   = $test_args[0];
  croak("error: Archivo Ruby '$rb_file' no encontrado!") unless (-f $rb_file);
  return $self->SUPER::raw_source(['/usr/bin/ruby', @test_args]);
}
