NOMBRE

TAP::Parser::Result::Version - Token de versión de sintaxis TAP.

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Esta es una subclase de TAP::Parser::Result. Se devolverá un token de esta clase si se encuentra una línea de versión.

TAP version 13
ok 1
not ok 2

La primera versión de TAP en incluir un número de versión explícito es la 13.
