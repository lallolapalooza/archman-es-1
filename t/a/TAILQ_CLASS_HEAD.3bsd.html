TAILQ_HEAD

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden usarse en ambos C y C++:

  1. Lista
  2. Lista doblemente ligada
  3. Cola de lista doblemente ligada
  4. Lista de cola
Todas las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de un nuevo elemento al frente de la lista.
  2. Inserción de un nuevo elemento después de cualquier elemento de la lista.
  3. Eliminación de un elemento en el frente de la lista en O(1).
  4. Travesía forward de la lista.
  5. Cambio de contenido entre dos listas.
Las listas doblemente ligadas son las más simples de las cuatro estructuras y solo soportan la funcionalidad descrita anteriormente. Las listas doblemente ligadas son ideales para aplicaciones con grandes datasets y pocos o ningún eliminado, o para implementar una cola LIFO. Las listas doblemente ligadas añaden la siguiente funcionalidad:
  1. Eliminación de cualquier elemento de la lista en O(n).
  2. Conexión de dos listas en O(n).
Las colas de lista doblemente ligadas añaden la siguiente funcionalidad:
  1. Elementos pueden agregarse al final de una lista.
  2. Eliminación de cualquier elemento de la lista en O(n).
  3. Podrían ser concatenadas.
Sin embargo:
  1. Todas las inserciones de elementos en una lista deben especificar el frente de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente el 15% mayor y las operaciones se ejecutan aproximadamente 20% más lentamente que en listas doblemente ligadas.
Las colas de lista doblemente ligadas son ideales para aplicaciones con grandes datasets y pocos o ningún eliminado, o para implementar una cola FIFO. Todas las estructuras de datos doblemente ligadas (listas y colas) además permiten:
  1. Inserción de un nuevo elemento antes de cualquier elemento de la lista.
  2. Eliminación de cualquier elemento de la lista en O(1).
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (a menos que se elimine) es aproximadamente el doble que en las estructuras de lista doblemente ligadas.
Las listas son las más simples de las estructuras de datos doblemente ligadas. Añaden la siguiente funcionalidad sobre lo anterior:
  1. Conexión de dos listas en O(n).
  2. Podrían ser recorridas en sentido inverso.
Sin embargo:
  1. Para recorrer en sentido inverso, debe especificarse un elemento inicial y la lista en la cual se encuentra.
Las colas añaden la siguiente funcionalidad:
  1. Elementos pueden agregarse al final de una lista.
  2. Podrían ser recorridas en sentido inverso, de cola a cabeza.
  3. Podrían ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de elementos en una lista deben especificar el frente de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente el 15% mayor y las operaciones se ejecutan aproximadamente 20% más lentamente que en listas doblemente ligadas.
En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Véase los ejemplos siguientes para una explicación más detallada de cómo se utilizan estas macros.

SINGLY-LINKED LISTS

Una lista doblemente ligada está dirigida por una estructura definida mediante la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos son doblemente ligados para minimizar el espacio y el overhead de manipulación de punteros, pero con el costo de O(n) para eliminar elementos arbitrarios. Los nuevos elementos pueden agregarse a la lista después de un elemento existente o al frente de la lista. Una estructura SLIST_HEAD se declara así:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a vincular en la lista. Un puntero al frente de la lista puede ser posteriormente declarado así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatenará la lista dirigida por head2 al final de la lista dirigida por head1, eliminando todos los elementos del anterior. Su uso debería evitarse ya que recorre toda la lista head1. Debe usarse una cola de lista doblemente ligada si se necesita esta macro en caminos de alto uso o para operar sobre listas largas.

La macro SLIST_EMPTY evalúa a true si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referida por head en la dirección forward, asignando cada elemento en su orden a var.

La macro SLIST_FOREACH_FROM comporta de manera idéntica a SLIST_FOREACH cuando var es NULL, en cuyo caso trata var como un elemento previamente encontrado de la lista referida por head y comienza el ciclo desde var en lugar del primer elemento de la lista referida por head.

La macro SLIST_FOREACH_SAFE recorre la lista referida por head en la dirección forward, asignando cada elemento en su orden a var. Sin embargo, a diferencia de SLIST_FOREACH() aquí es permitido remover var tanto como liberarla dentro del ciclo de manera segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, en cuyo caso trata var como un elemento previamente encontrado de la lista referida por head y comienza el ciclo desde var en lugar del primer elemento de la lista referida por head.

La macro SLIST_INIT inicializa la lista referida por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al frente de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm en la lista.

La macro SLIST_INIT inicializa la lista referida por head.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple se encabeza mediante una estructura definida por la macro SLIST_HEAD. Los elementos son enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros. Las nuevas entradas pueden añadirse al principio de la lista, o después de una entrada existente. Una estructura SLIST_HEAD se declara como:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista puede declararse posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH, aquí está permitido tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento posterior a elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm de la cabeza de la lista. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la lista deberían usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debería usar una lista doblemente enlazada si esta macro se necesita en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

	...

free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación del principio. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...

SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {

COLAS CON PUNTA ENLAZADAS SIMPLES

Una cola con punta enlazada simple se encabeza mediante una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola con punta y otro al último elemento de la cola con punta. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la cola con punta después de un elemento existente, al principio de la cola con punta, o al final de la cola con punta. Una estructura STAILQ_HEAD se declara como sigue:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la cola con punta. Un puntero a la cabeza de la cola con punta puede declararse posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola con punta head.

La macro STAILQ_CONCAT concatena la cola con punta encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola con punta.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola con punta.

La macro STAILQ_FIRST devuelve el primer elemento de la cola con punta o NULL si la cola con punta está vacía.

La macro STAILQ_FOREACH recorre la cola con punta referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro STAILQ_FOREACH_FROM se comporta idénticamente a STAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola con punta referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta idénticamente a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola con punta referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola con punta.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola con punta.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola con punta. Si la cola con punta está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola con punta, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento posterior a elm de la cola con punta. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola con punta.

La macro STAILQ_REMOVE_HEAD elimina el elemento de la cabeza de la cola con punta. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la cola con punta deberían usar esta macro explícitamente en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola con punta. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debería usar una cola con punta doblemente enlazada si esta macro se necesita en rutas de código de alto uso o para operar en colas con punta largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola con punta. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar al principio. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación del principio. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Eliminación de TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación más rápida de TailQ. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista se encabeza mediante una estructura definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados doblemente para que un elemento arbitrario pueda ser eliminado sin recorrer la lista. Se pueden añadir nuevos elementos a la lista después de un elemento existente, antes de un elemento existente, o al principio de la lista. Una estructura LIST_HEAD se declara como sigue:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista puede declararse posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. El uso de esta macro debe evitarse ya que recorre la totalidad de la lista head1. Se debería usar una cola con punta si esta macro se necesita en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por

">head en la dirección hacia adelante, asignando cada elemento a su vez a var.

La macro LIST_FOREACH_FROM se comporta idénticamente a LIST_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

La macro LIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento a su vez a var. Sin embargo, a diferencia de LIST_FOREACH() aquí está permitido tanto remover var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro LIST_FOREACH_FROM_SAFE se comporta idénticamente a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

La macro LIST_INIT inicializa la lista referenciada por head.

La macro LIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro LIST_NEXT devuelve el siguiente elemento de la lista, o NULL si es el último.

La macro LIST_PREV devuelve el elemento anterior de la lista, o NULL si es el primero. La lista head debe contener el elemento elm.

La macro LIST_REMOVE elimina el elemento elm de la lista.

La macro LIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE LIST

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Cabecera de la lista. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Lista. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Inicializa la lista. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Eliminación. */
free(n2);
					/* Recorrido hacia adelante. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Recorrido seguro hacia adelante. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Eliminación de la lista. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Eliminación de lista más rápida. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

COLAS DE COLA

Una cola de cola está encabezada por una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de cola y otro al último elemento de la cola de cola. Los elementos están enlazados doblemente para que un elemento arbitrario pueda ser eliminado sin recorrer la cola de cola. Los nuevos elementos se pueden agregar a la cola de cola después de un elemento existente, antes de un elemento existente, al principio de la cola de cola o al final de la cola de cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá, y TYPE es el tipo de los elementos que se enlazarán en la cola de cola. Un puntero a la cabecera de la cola de cola puede declararse posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro TAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola de cola head.

La macro TAILQ_CONCAT concatena la cola de cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro TAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola de cola.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos en la cola de cola.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

La macro TAILQ_FOREACH recorre la cola de cola referenciada por head en la dirección hacia adelante, asignando cada elemento a su vez a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de cola referenciada por head en la dirección inversa, asignando cada elemento a su vez a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta idénticamente a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario trata a var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referenciada por head en dirección hacia adelante o inversa respectivamente, asignando cada elemento a su vez a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE hacen posible tanto remover var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario trata a var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

La macro TAILQ_INIT inicializa la cola de cola referenciada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de cola.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de cola.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de cola. Si la cola de cola está vacía, el valor de retorno es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola de cola, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola de cola, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de cola.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLA DE COLA

TAILQ_HEAD(tailhead, entry) head =
    TAILQ_HEAD_INITIALIZER(head);
struct tailhead *headp;			/* Cabecera de la cola de cola. */
struct entry {
	...
	TAILQ_ENTRY(entry) entries;	/* Cola de cola. */
	...
} *n1, *n2, *n3, *np;

TAILQ_INIT(&head);			/* Inicializa la cola. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
TAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Inserta al final. */
TAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
TAILQ_INSERT_AFTER(&head, n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */
TAILQ_INSERT_BEFORE(n2, n3, entries);

TAILQ_REMOVE(&head, n2, entries);	/* Eliminación. */
free(n2);
					/* Recorrido hacia adelante. */
TAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
TAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	TAILQ_REMOVE(&head, np, entries);
	free(np);
}
					/* Recorrido inverso. */
TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
	np-> ...
					/* Eliminación de cola de cola. */
while (!TAILQ_EMPTY(&head)) {
	n1 = TAILQ_FIRST(&head);
	TAILQ_REMOVE(&head, n1, entries);
	free(n1);
}
					/* Eliminación de cola de cola más rápida. */
n1 = TAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = TAILQ_NEXT(n1, entries));
	free(n1);
	n1 = n2;
}
TAILQ_INIT(&head);

DIAGNÓSTICOS

Al depurar queue(3), puede ser útil trazar los cambios en la cola. Para habilitar el trazado, define la macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.

También puede ser útil triturar punteros que se han desvinculado de una cola, para detectar su uso después de la eliminación. Para habilitar el triturado de punteros, define la macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido triturado por la opción QUEUE_MACRO_DEBUG_TRASH.
