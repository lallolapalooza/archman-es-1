TAILQ(3) Manual de funciones de biblioteca TAILQ(3)

NOMBRE

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE - implementación de una cola de lista doblemente enlazada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
TAILQ_ENTRY(TIPO);
TAILQ_HEAD(NOMBRE_CABEZA, TIPO);
TAILQ_HEAD NOMBRE_CABEZA_INICIALIZADOR(TAILQ_HEAD cabeza);
void TAILQ_INIT(TAILQ_HEAD *cabeza);
int TAILQ_EMPTY(TAILQ_HEAD *cabeza);
void TAILQ_INSERT_HEAD(TAILQ_HEAD *cabeza,
                         struct TIPO *elem, TAILQ_ENTRY NOMBRE);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *cabeza,
                         struct TIPO *elem, TAILQ_ENTRY NOMBRE);
void TAILQ_INSERT_BEFORE(struct TIPO *elemlista,
                         struct TIPO *elem, TAILQ_ENTRY NOMBRE);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *cabeza, struct TIPO *elemlista,
                         struct TIPO *elem, TAILQ_ENTRY NOMBRE);
struct TIPO *TAILQ_FIRST(TAILQ_HEAD *cabeza);
struct TIPO *TAILQ_LAST(TAILQ_HEAD *cabeza, NOMBRE_CABEZA);
struct TIPO *TAILQ_PREV(struct TIPO *elem, NOMBRE_CABEZA, TAILQ_ENTRY NOMBRE);
struct TIPO *TAILQ_NEXT(struct TIPO *elem, TAILQ_ENTRY  NOMBRE);
TAILQ_FOREACH(struct TIPO *var, TAILQ_HEAD *cabeza,
                         TAILQ_ENTRY NOMBRE);
TAILQ_FOREACH_REVERSE(struct TIPO *var, TAILQ_HEAD *cabeza, NOMBRE_CABEZA,
                         TAILQ_ENTRY NOMBRE);
void TAILQ_REMOVE(TAILQ_HEAD *cabeza, struct TIPO *elem,
                         TAILQ_ENTRY NOMBRE);
void TAILQ_CONCAT(TAILQ_HEAD *cabeza1, TAILQ_HEAD *cabeza2,
                         TAILQ_ENTRY  NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre colas de lista doblemente enlazadas.

En las definiciones de macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro TAILQ_HEAD().

Creación

Una cola de lista está encabezada por una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la cola. Se pueden añadir nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRE_CABEZA, TIPO) cabeza;

donde struct NOMBRE_CABEZA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct NOMBRE_CABEZA *cabezap;

(Los nombres cabeza y cabezap son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

TAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola cabeza.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() evalúa a verdadero si no hay elementos en la cola. cabeza.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elemlista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elemlista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior en la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento en la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabeza en la dirección hacia adelante, asignando cada elemento en turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabeza en la dirección inversa, asignando cada elemento en turno a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elem de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola cabeza.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación permitiendo que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    TAILQ_ENTRY(entrada) entradas;             /* Cola de lista */
};
TAILQ_HEAD(cola_lista_cabeza, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cola_lista_cabeza cabeza;                   /* Cabeza de la cola de lista */
    int i;
    TAILQ_INIT(&cabeza);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    TAILQ_INSERT_HEAD(&cabeza, n1, entradas);
    n1 = malloc(sizeof(struct entrada));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    TAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);
    n3 = malloc(sizeof(struct entrada));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entradas);
    TAILQ_REMOVE(&cabeza, n2, entradas);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &cabeza, entradas)
        np->datos = i++;
                                            /* Recorrido inverso */
    TAILQ_FOREACH_REVERSE(np, &cabeza, cola_lista_cabeza, entradas)
        printf("%i\n", np->datos);
                                            /* Eliminación de TailQ */

TAILQ_FOREACH(3bsd) — Linux man pages

NAME

TAILQ_FOREACH, TAILQ_FOREACH_SAFE, TAILQ_NEXT — iterate over a tail queue

LIBRARY

Library Is Like So:

#include <sys/queue.h>

SYNOPSIS

#define TAILQ_FOREACH(var, head)                                           \
    for ((var) = TAILQ_FIRST((head));                                             \
        (var);                                                                     \
        (var) = TAILQ_NEXT((var), field))                                         \
        /* empty */
#define TAILQ_FOREACH_SAFE(var, head, field)                             \
    for ((var) = TAILQ_FIRST((head));                                             \
        (var) != NULL &&                                                        \
            ((var) = TAILQ_NEXT((var), field));                                    \
        /* empty */

#define TAILQ_NEXT(elm, field)                                           \
    ((elm)->field.tqe_next)

DESCRIPTION

The TAILQ_FOREACH macro is the standard way to iterate over a tail queue. The macro iterates over the elements of the tail queue, as defined by the list pointed to by head. In each iteration the current element is assigned to the variable var.

The TAILQ_FOREACH_SAFE macro is similar to TAILQ_FOREACH, but it is safe to use if the macro body removes the current element from the queue. This is accomplished by assigning the result of TAILQ_NEXT to var within the for loop's increment section.

The TAILQ_NEXT macro returns a pointer to the next element in the tail queue after the element elm. The field parameter specifies the name of the tailq_entry structure member used to link the elements together.

RETURN VALUE

The TAILQ_NEXT macro returns a pointer to the next element in the tail queue, or NULL if the current element is the last one.

STANDARDS

These macros were inspired by the BSD queue macros, and are implemented in many operating systems, including Linux.

HISTORY

The tail queue macros first appeared in FreeBSD 3.0.

CAVEATS

When using TAILQ_FOREACH, care must be taken when removing elements from the tail queue within the loop body. If the current element is removed, the subsequent call to TAILQ_NEXT may result in undefined behavior. TAILQ_FOREACH_SAFE avoids this problem.

EXAMPLES

The following example demonstrates how to iterate over a tail queue and free its elements:

struct my_struct {
    struct entry entries;
    int data;
};

struct my_struct *n1, *n2;
struct my_head head; /* Assume head is initialized */

TAILQ_INIT(&head);

/* ... add elements to the tail queue ... */

n1 = TAILQ_FIRST(&head);
while (n1 != NULL) {
    n2 = TAILQ_NEXT(n1, entries);
    free(n1);
    n1 = n2;
}
TAILQ_INIT(&head);
exit(EXIT_SUCCESS);
