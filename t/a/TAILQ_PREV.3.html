NOMBRE

DESCRIPCIÓN

Estas macros definen y operan sobre colas dobles enlazadas.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRECABECERA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro TAILQ_HEAD().

Creación

Una cola se encabeza con una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último. Los elementos están doblemente enlazados para que un elemento arbitrario pueda eliminarse sin recorrer la cola. Se pueden añadir nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRECABECERA, TIPO) cabecera;

donde struct NOMBRECABECERA es la estructura que se va a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabecera de la cola se puede declarar más tarde como:


struct NOMBRECABECERA *punterocabecera;

(Los nombres cabecera y punterocabecera son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

TAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabecera.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola. cabecera.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elemento antes del elemento elementolista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elementolista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior de la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabecera en la dirección hacia adelante, asignando cada elemento en su momento a variable. variable se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabecera en la dirección inversa, asignando cada elemento en su momento a variable.

Eliminación

TAILQ_REMOVE() elimina el elemento elemento de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la cola cabecera.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que variable se elimine o libere dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación al permitir que variable se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola doble */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Cabecera de la cola doble */
    int i;
    TAILQ_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido inverso */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de la cola doble */
    n1

EJEMPLOS

Para liberar todos los elementos de una cola TAILQ y luego reiniciarla, se puede usar el siguiente código:

    struct foo *n1, *n2;
    struct head_type head;

    TAILQ_INIT(&head);
    /* ... añadir elementos a la cola ... */

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
