TAP::Parser::Result(3perl) Guía del programador de Perl TAP::Parser::Result(3perl)

NOMBRE

TAP::Parser::Result - Clase base para objetos de salida de TAP::Parser

VERSIÓN

Versión 3.50

SINOPSIS

# clase abstracta - no destinada a ser utilizada directamente
# véase TAP::Parser::ResultFactory para un uso preferido
# directamente:
use TAP::Parser::Result;
my $token  = {...};
my $result = TAP::Parser::Result->new( $token );

DESCRIPCIÓN

Esta es una clase base simple utilizada por TAP::Parser para almacenar objetos que representan la información de salida de prueba actual de TAP (generalmente una sola línea). A menos que esté creando una subclase, probablemente no necesitará usar este módulo directamente.

MÉTODOS

"new"

# véase TAP::Parser::ResultFactory para un uso preferido
# para usar directamente:
my $result = TAP::Parser::Result->new($token);

Devuelve una instancia de la clase apropiada para el token de prueba pasado.

Métodos booleanos

Los siguientes métodos devuelven un valor booleano y deben ser sobrescritos en la subclase apropiada.

  • "is_plan"

    Indica si esta es o no la línea del plan de pruebas.

    1..3
  • "is_pragma"

    Indica si esta es o no una línea de pragma.

    pragma +strict
  • "is_test"

    Indica si esta es o no una línea de prueba.

    ok 1 Está bien!
  • "is_comment"

    Indica si esto es o no un comentario.

    # este es un comentario
  • "is_bailout"

    Indica si esta es o no una línea de salida anticipada.

    ¡Salida anticipada! Nos quedamos sin cristales de dilitio.
  • "is_version"

    Indica si esta es o no una línea de versión TAP.

    TAP version 4
  • "is_unknown"

    Indica si la línea actual pudo ser analizada.

    ... esta línea es basura ...
  • "is_yaml"

    Indica si esto es o no un bloque YAML.

"raw"

print $result->raw;

Devuelve la línea original de texto que fue analizada.

"type"

my $type = $result->type;

Devuelve el "tipo" de un token, como "comment" o "test".

"as_string"

print $result->as_string;

Imprime una representación en cadena del token. Esto podría no ser la salida exacta, sin embargo. A las pruebas se les añadirán números de prueba si no están presentes, las directivas TODO y SKIP se capitalizarán y, en general, las cosas se limpiarán. Si necesita el texto original del token, consulte el método "raw".

"is_ok"

if ( $result->is_ok ) { ... }

Informa si un resultado dado ha pasado o no. Cualquier cosa que no sea un resultado de prueba devuelve verdadero. Esto se proporciona simplemente como un atajo conveniente.

"passed"

Obsoleto. Utilice "is_ok" en su lugar.

"has_directive"

if ( $result->has_directive ) {
   ...
}

Indica si el resultado dado tiene o no una directiva TODO o SKIP.

"has_todo"

if ( $result->has_todo ) {
    ...
}

Indica si el resultado dado tiene o no una directiva TODO.

"has_skip"

if ( $result->has_skip ) {
    ...
}

Indica si el resultado dado tiene o no una directiva SKIP.

"set_directive"

Establece la directiva asociada con este token. Se utiliza internamente para simular pruebas TODO.

SUBCLASES

Por favor, vea "SUBCLASES" en TAP::Parser para una descripción general de la creación de subclases.

Recuerde: si desea que el analizador utilice su subclase automáticamente, deberá registrarla con "register_type" en TAP::Parser::ResultFactory.

Si está creando un tipo de resultado completamente nuevo, probablemente también necesitará crear una subclase de TAP::Parser::Grammar, o de lo contrario, nunca se utilizará.

Ejemplo

package MyResult;
use strict;
use base 'TAP::Parser::Result';
# registrar con la fábrica:
TAP::Parser::ResultFactory->register_type( 'my_type' => __PACKAGE__ );
sub as_string { 'Mis resultados se ven todos iguales' }
