NOMBRE

TAP::Parser::Scheduler::Job - Un trabajo de prueba individual.

VERSIÓN

Versión 3.50

SINOPSIS

use TAP::Parser::Scheduler::Job;

DESCRIPCIÓN

Representa un 'trabajo' de prueba individual.

MÉTODOS

Métodos de clase

"new"

my $job = TAP::Parser::Scheduler::Job->new(
    $filename, $description
);

Dados el nombre de archivo y la descripción de una prueba como escalares, devuelve un nuevo objeto TAP::Parser::Scheduler::Job.

Métodos de instancia

"on_finish"

$self->on_finish(\&method).

Registra una clausura para que se llame cuando se destruya este trabajo. La devolución de llamada recibirá el objeto "TAP::Parser::Scheduler::Job" como su único argumento.

"finish"

$self->finish;

Se llama cuando un trabajo se completa para desbloquearlo. Si se ha registrado una devolución de llamada con "on_finish", la llama. De lo contrario, no hace nada.

Atributos

$self->filename;
$self->description;
$self->context;

Todos estos son "getters" que devuelven los datos establecidos para estos atributos durante la construcción del objeto.

"filename"

"description"

"context"

"as_array_ref"

Para compatibilidad con versiones anteriores en las devoluciones de llamada.

"is_spinner"

$self->is_spinner;

Devuelve falso, indicando que este es un trabajo real en lugar de un 'spinner'. Los spinners se devuelven cuando el planificador todavía tiene trabajos pendientes pero no puede devolver uno (debido al bloqueo) en este momento.
