NOMBRE

TAP::Parser::Result::Bailout - Token de resultado de abandono.

VERSIÓN

Versión 3.50

DESCRIPCIÓN

Esta es una subclase de TAP::Parser::Result. Se devolverá un token de esta clase si se encuentra una línea de abandono.

1..5
ok 1 - ¡hurra!
Abandono! Pues, adiós a "¡hurra!"

MÉTODOS SOBREESCRITOS

Métodos de instancia

"explanation"

if ( $result->is_bailout ) {
    my $explanation = $result->explanation;
    print "Nos retiramos porque ($explanation)";
}

Si, y solo si, un token es un token de abandono, puedes obtener una "explicación" a través de este método. La explicación es el texto que sigue a las místicas palabras "Abandono!" que aparecen en la salida tap.
