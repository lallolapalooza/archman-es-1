NOMBRE

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE - implementación de una cola de elementos enlazados doblemente (tail queue)

DESCRIPCIÓN

Estas macros definen y operan sobre colas de elementos enlazados doblemente (tail queues).

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_DE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola de elementos está encabezada por una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y el otro al último elemento de la cola. Los elementos están enlazados doblemente para que un elemento arbitrario pueda ser eliminado sin recorrer la cola. Los nuevos elementos pueden ser añadidos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola, o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRE_DE_CABEZA, TIPO) cabeza;

donde struct NOMBRE_DE_CABEZA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola puede ser declarado posteriormente como:


struct NOMBRE_DE_CABEZA *puntero_a_cabeza;

(Los nombres cabeza y puntero_a_cabeza son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos en la cola.

TAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola cabeza.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() evalúa a verdadero si no hay elementos en la cola. cabeza.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elem_lista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior en la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento en la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabeza en dirección hacia adelante, asignando cada elemento en turno a var. var se establece a NULL si el bucle finaliza normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabeza en dirección hacia atrás, asignando cada elemento en turno a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elem de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola cabeza.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, corrigen esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Cola de elementos */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Cabeza de la cola de elementos */
    int i;
    TAILQ_INIT(&head);                      /* Inicializar la cola */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insertar al final */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Recorrido hacia atrás */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de TailQ */
    n

EXAMPLES

The following code snippet shows how to remove all elements from a doubly linked list:

    struct my_list_head head;
    struct my_list_entry *n1, *n2;
    TAILQ_INIT(&head);
    /* ... add elements to the list ... */
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
