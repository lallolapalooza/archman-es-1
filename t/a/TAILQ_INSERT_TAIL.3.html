DESCRIPCIÓN

Estas macros definen y operan sobre colas de colas doblemente enlazadas.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABEZA es el nombre de una estructura definida por el usuario que debe declararse utilizando la macro TAILQ_HEAD().

Creación

Una cola de colas está encabezada por una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y el otro al último elemento de la cola. Los elementos están doblemente enlazados para que un elemento arbitrario pueda eliminarse sin recorrer la cola. Se pueden añadir nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRE_CABEZA, TIPO) cabeza;

donde struct NOMBRE_CABEZA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:


struct NOMBRE_CABEZA *puntero_cabeza;

(Los nombres cabeza y puntero_cabeza son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

TAILQ_HEAD_INITIALIZER() se evalúa como un inicializador para la cola cabeza.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() se evalúa como verdadero si no hay elementos en la cola. cabeza.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elemento al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elemento al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elemento antes del elemento elemento_lista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elemento después del elemento elemento_lista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior en la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento en la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabeza en dirección hacia adelante, asignando cada elemento por turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabeza en dirección inversa, asignando cada elemento por turno a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elemento de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabeza2 al final de la encabezada por cabeza1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la cola cabeza.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que var se elimine o libere dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación permitiendo que var se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

DESCRIPTION

These functions implement the tail queue data structure. A tail queue is a doubly linked list that is accessible from both ends. The macros are designed to be used with structures that contain a pointer to the previous and next element in the list. The next argument should be the name of the macro field within the structure that points to the next element, and the prev argument should be the name of the macro field within the structure that points to the previous element.

The TAILQ_HEAD macro is used to declare a tail queue head. The first argument is the name of the queue and the second argument is the type of the elements in the queue.

The TAILQ_INIT macro initializes an empty tail queue.

The TAILQ_INSERT_TAIL macro inserts the element elm at the end of the tail queue head.

The TAILQ_INSERT_HEAD macro inserts the element elm at the beginning of the tail queue head.

The TAILQ_INSERT_AFTER macro inserts the element elm after the element listelm in the tail queue head.

The TAILQ_INSERT_BEFORE macro inserts the element elm before the element listelm in the tail queue head.

The TAILQ_REMOVE macro removes the element elm from the tail queue head.

The TAILQ_REPLACE macro replaces the element oldelm with the element newelm in the tail queue head.

The TAILQ_FIND macro searches the tail queue head for the element elm.

RETURN VALUE

The TAILQ_FIND macro returns a pointer to the element if found, otherwise NULL.

STANDARDS

These functions implement the tail queue data structure, which is part of the BSD C library. They are not part of any official C standard.

HISTORY

The tail queue implementation first appeared in 4.4BSD.

CAVEATS

These macros assume that the elements in the queue are properly initialized and linked. Incorrect usage can lead to memory corruption or crashes.

EXAMPLES

The following example demonstrates how to use the TAILQ_INSERT_TAIL macro to insert elements into a tail queue:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct entry {
    char *data;
    TAILQ_ENTRY(entry) entries;
};

TAILQ_HEAD(my_list, entry);

int
main(void)
{
    struct my_list head;
    struct entry *n1, *n2;

    TAILQ_INIT(&head);

    n1 = malloc(sizeof(struct entry));
    n1->data = "first";
    TAILQ_INSERT_TAIL(&head, n1, entries);

    n2 = malloc(sizeof(struct entry));
    n2->data = "second";
    TAILQ_INSERT_TAIL(&head, n2, entries);

    /* Traverse the list */
    for (n1 = TAILQ_FIRST(&head); n1 != NULL; n1 = TAILQ_NEXT(&head, n1, entries)) {
        printf("%s\n", n1->data);
    }

    /* Free the memory */
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
