Tdbc_Init(3)

Paquete: tcl

Licencias: TCL

Tdbc_Init(3) Conectividad de Base de Datos Tcl Tdbc_Init(3)

NOMBRE

Tdbc_Init, Tdbc_MapSqlState, Tdbc_TokenizeSql - Procedimientos C para facilitar la escritura de controladores TDBC

SINOPSIS

#include <tdbc.h>
int
Tdbc_Init(interp)
Tcl_Obj *
Tdbc_TokenizeSql(interp, sqlcode)
const char *
Tdbc_MapSqlState(state)

ARGUMENTOS

Tcl_Interp *interp (in/out)
Puntero a un intérprete de Tcl.
const char *state (in)
Puntero a una cadena de caracteres que contiene un 'estado SQL' de un error de base de datos.
const char *sqlcode (in)
Puntero a una cadena de caracteres que contiene una declaración SQL.

DESCRIPCIÓN

La biblioteca TDBC proporciona varios procedimientos C que simplifican la escritura de un controlador TDBC. Incluyen un procedimiento que tokeniza una declaración SQL, localizando variables para ser sustituidas, y un procedimiento que acepta un estado SQL y devuelve una clase de error para la información de error del intérprete.

Tdbc_Init debe ser invocado antes que cualquier otra llamada TDBC. Acepta un puntero a un intérprete de Tcl y se encarga de cargar la biblioteca TDBC. Devuelve TCL_OK si la biblioteca Tcl se cargó correctamente, y TCL_ERROR en caso contrario. Si se devuelve TCL_ERROR, el resultado del intérprete contiene el mensaje de error.

Tdbc_TokenizeSql acepta un puntero a un intérprete de Tcl y un puntero a una cadena de caracteres que contiene una o más declaraciones SQL. Tokeniza las declaraciones SQL y devuelve un puntero a un Tcl_Obj que contiene una lista de los tokens que componen la declaración. Concatenar los tokens producirá el código SQL original. El Tcl_Obj devuelto tiene un contador de referencias de cero. El llamador es responsable de gestionar el contador de referencias según sea necesario. Consulte TOKENS a continuación para ver una descripción de lo que puede haber en la lista de tokens devuelta.

Tdbc_MapSqlState acepta un puntero a una cadena, generalmente de cinco caracteres de longitud, que es el 'estado SQL' resultante de un error de base de datos. Devuelve una cadena de caracteres que es adecuada para ser incluida como clase de error al construir el código de error para un error en un controlador TDBC. (Por convención, el código de error es una lista que tiene al menos cuatro elementos: "TDBC claseError estadoSql nombreDriver detalles...".)

TOKENS

Cada token devuelto por Tdbc_TokenizeSql puede ser uno de los siguientes:

[1]
Una variable enlazada, que comienza con uno de los caracteres ':', '@', o '$'. El resto de la cadena es el nombre de la variable y consistirá en caracteres alfanuméricos y guiones bajos. (El carácter inicial no será numérico).
[2]
Un punto y coma que separa dos declaraciones SQL.
[3]
Algo más en una declaración SQL. El tokenizador no intenta analizar SQL; simplemente identifica variables enlazadas (distinguiéndolas de cadenas similares que aparecen dentro de comillas o comentarios) y delimitadores de sentencias.
