Types::Standard::CycleTuple(3) Documentación de Contribución de Usuarios de Perl Types::Standard::CycleTuple(3)

NOMBRE

Types::Standard::CycleTuple - utilidad exportadora para la restricción de tipo CycleTuple

SINOPSIS

use Types::Standard -types;

# Forma normal de validar una lista de pares de enteros.
#
CycleTuple->of( Int, Int )->assert_valid( [ 7, 49, 8, 64 ] );

use Types::Standard::CycleTuple IntPairs => { of => [ Int, Int ] },

# Atajo exportado
#
assert_IntPairs [ 7, 49, 8, 64 ];

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Este es principalmente código interno, pero también puede actuar como una utilidad exportadora.

Exportaciones

Types::Standard::CycleTuple se puede usar experimentalmente como un exportador.

use Types::Standard 'Int';
use Types::Standard::CycleTuple IntPairs => { of => [ Int, Int ] };

Esto exportará las siguientes funciones a su espacio de nombres:

"IntPairs"
Se pueden exportar varios tipos a la vez:

use Types::Standard -types;
use Types::Standard::CycleTuple (
  IntIntPairs   => { of => [ Int, Int ] },
  StrIntPairs   => { of => [ Str, Int ] },
);

assert_StrIntPairs [ one => 1, two => 2 ];   # no debería fallar

Es posible restringir aún más el cycletuple usando "where":

use Types::Standard::CycleTuple MyThing => { of => [ ... ], where => sub { ... } };
