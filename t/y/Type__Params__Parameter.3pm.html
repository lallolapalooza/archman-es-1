Type::Params::Parameter(3) Documentación de contribución de usuarios de Perl Type::Params::Parameter(3)

NOMBRE

Type::Params::Parameter - representación interna de un parámetro en una firma de función

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Este es mayormente código interno, pero puede ser usado para proporcionar introspección básica para las firmas.

Constructor

nuevo(%atributos)

Atributos

Todos los atributos son de solo lectura.

"type" TypeTiny
Restricción de tipo para el parámetro.
"default" CodeRef|ScalarRef|Ref|Str|Undef
Un valor predeterminado para el parámetro: ya sea un coderef para generar un valor, una referencia a una cadena de código Perl para generar el valor, una referencia a un array vacío o un hash vacío, una cadena literal para usar como valor predeterminado, o un undef literal para usar como valor predeterminado.
"strictness" Bool|ScalarRef
Un booleano que indica si ser más estricto con las verificaciones de tipo, o una referencia a una cadena de código Perl que nombra una variable o constante de Perl que controla el comportamiento estricto.
"clone" Bool
El método para acceder a esto se llama "should_clone" por ninguna razón particular.
"coerce" Bool
Por defecto es verdadero si "type" tiene una coerción.
"optional" Bool
Por defecto es verdadero si hay un "default" o si "type" es un subtipo de Optional.
"in_list" Bool
Booleano que solo se usa cuando la firma tiene la función "list_to_named" habilitada.
"default_on_undef" Bool
¿Debería activarse el valor predeterminado si el llamador pasa un undef explícito?

Atributos relacionados con parámetros nombrados

"name" Str
"alias" ArrayRef[Str]
"getter" Str
"predicate" Str

Métodos

Predicados

Los métodos predicados devuelven verdadero/falso para indicar la presencia o ausencia de atributos.

"has_type"
"has_default"
"has_strictness"
"has_name"
"has_alias"

Otros métodos

"might_supply_new_value"
Indica que el parámetro no puede ser simplemente referenciado dentro de @_ porque se podría usar un valor predeterminado, el valor dado podría ser coaccionado, o el valor dado podría ser clonado usando Storable.
