Type::Tiny::Union(3) Documentación de Perl aportada por el usuario Type::Tiny::Union(3)

NOMBRE

Type::Tiny::Union - restricciones de tipo de unión

SINOPSIS

Usando el operador "|" sobrecargado:

package Local::Stash {
  use Moo;
  use Types::Common qw( ArrayRef HashRef );

  has data => (
    is   => 'ro',
    isa  => HashRef | ArrayRef,
  );
}

my $x = Local::Stash->new( data => {} );  # ok
my $y = Local::Stash->new( data => [] );  # ok

Usando la interfaz orientada a objetos de Type::Tiny::Union:

package Local::Stash {
  use Moo;
  use Types::Common qw( ArrayRef HashRef );
  use Type::Tiny::Union;

  my $AnyData = Type::Tiny::Union->new(
    name             => 'AnyData',
    type_constraints => [ HashRef, ArrayRef ],
  );

  has data => (
    is   => 'ro',
    isa  => $AnyData,
  );
}

Usando la interfaz funcional de Type::Utils:

package Local::Stash {
  use Moo;
  use Types::Common qw( ArrayRef HashRef );
  use Type::Utils;

  my $AnyData = union AnyData => [ HashRef, ArrayRef ];

  has data => (
    is   => 'ro',
    isa  => $AnyData,
  );
}

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Restricciones de tipo de unión.

Este paquete hereda de Type::Tiny; vea ese para la mayor parte de la documentación. Las principales diferencias se enumeran a continuación:

Constructor

El constructor "new" de Type::Tiny sigue funcionando, por supuesto. Pero también existe:

new_by_overload(%atributos)
Al igual que el constructor "new", pero a veces devolverá otra restricción de tipo que no es estrictamente una instancia de Type::Tiny::Union, pero que aún así encapsula el mismo significado. Este constructor es utilizado por la sobrecarga del operador "|" de Type::Tiny.

Atributos

"type_constraints"
Arrayref de restricciones de tipo.

Cuando se pasa al constructor, si alguna de las restricciones de tipo en la unión es en sí misma una restricción de tipo de unión, esta se "desempaqueta" en la nueva unión.

"constraint"
A diferencia de Type::Tiny, *no* puedes pasar una coderef de restricción al constructor. En su lugar, confía en el valor predeterminado.
"inlined"
A diferencia de Type::Tiny, *no* puedes pasar una coderef de inlining al constructor. En su lugar, confía en el valor predeterminado.
"parent"
A diferencia de Type::Tiny, *no* puedes pasar una coderef de inlining al constructor. En su lugar, se calculará automáticamente un padre.
"coercion"
Probablemente no pases esto al constructor. (Actualmente no está prohibido, ya que puede haber un uso para él que no he pensado).

El valor predeterminado generado automáticamente será un objeto Type::Coercion::Union.

Métodos

find_type_for($value)
Devuelve la primera restricción de tipo individual en la unión que $value aprueba.
stringifies_to($constraint)
Ver Type::Tiny::ConstrainedObject.
numifies_to($constraint)
Ver Type::Tiny::ConstrainedObject.
"with_attribute_values($attr1 => $constraint1, ...)"
Ver Type::Tiny::ConstrainedObject.

Sobrecarga

•
La arrayrecificación llama a "type_constraints".
