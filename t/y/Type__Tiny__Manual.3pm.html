NOMBRE

Type::Tiny::Manual - una descripción general de Type::Tiny

SINOPSIS

Type::Tiny es una pequeña clase de Perl http://www.perl.org/ para escribir restricciones de tipo, inspirada en la API de restricciones de tipo de Moose y MooseX::Types. Tiene solo una dependencia no central (e incluso esa es simplemente un módulo que se distribuyó previamente como parte de Type::Tiny pero que desde entonces se ha separado), y se puede usar con Moose, Mouse o Moo (o ninguno de los anteriores).

Type::Tiny es utilizado por más de 1000 distribuciones de Perl en CPAN (Comprehensive Perl Archive Network) y puede considerarse un marco estable y maduro para aplicar tipos de datos de manera eficiente y confiable.

Type::Tiny viene incluido con Type::Library, un marco para organizar restricciones de tipo en colecciones. También se incluye Types::Standard, una biblioteca de restricciones de tipo útiles inspirada en Moose. También se proporciona Type::Params, para permitir la comprobación y coerción muy rápidas de parámetros de funciones y métodos.

El siguiente ejemplo te da una idea de algunas de las características de estos módulos. Si no lo entiendes todo, no pasa nada; para eso está el resto del manual. Aunque el ejemplo utiliza Moo, el "use Moo" podría cambiarse por "use Moose" o "use Mouse" y seguiría funcionando.

use v5.36;

package Horse {
  use Moo;
  use Types::Standard qw( Str Int Enum ArrayRef InstanceOf );
  use Type::Params qw( signature_for );
  use namespace::autoclean;

  has name => (
    is       => 'ro',
    isa      => Str,
    required => 1,
  );

  has gender => (
    is       => 'ro',
    isa      => Enum[qw( f m )],
  );

  has age => (
    is       => 'rw',
    isa      => Int->where( '$_ >= 0' ),
  );

  has children => (
    is       => 'ro',
    isa      => ArrayRef[ InstanceOf['Horse'] ],
    default  => sub { return [] },
  );

  signature_for add_child => (
    method     => Object,
    positional => [ InstanceOf['Horse'] ],
  );

  sub add_child ( $self, $child ) {
    push $self->children->@*, $child;
    return $self;
  }
}

package main;

my $boldruler = Horse->new(
  name    => "Bold Ruler",
  gender  => 'm',
  age     => 16,
);

my $secretariat = Horse->new(
  name    => "Secretariat",
  gender  => 'm',
  age     => 0,
);

$boldruler->add_child( $secretariat );

use Types::Standard qw( is_Object assert_Object );

# is_Object devolverá un booleano
#
if ( is_Object $boldruler ) {
  say $boldruler->name;
}

# assert_Object devolverá $secretariat o morirá
#
say assert_Object( $secretariat )->name;

MANUAL

Incluso si estás usando Type::Tiny con otros kits de herramientas de programación orientada a objetos (como Moose o Mouse), deberías empezar con las secciones de Moo del manual. La mayoría de la información es directamente transferible y las secciones de Moose y Mouse del manual listan las diferencias menores entre usar Type::Tiny con Moo y con ellas.

En general, este manual asume que usas Perl 5.36 o superior y puede utilizar ejemplos que no funcionen en versiones anteriores de Perl. Type::Tiny sí funciona en versiones anteriores de Perl, pero no todos los ejemplos y características del manual se ejecutarán sin ajustes. (Por ejemplo, puede que necesites reemplazar las variables "state" con variables léxicas, evitar la sintaxis "package NAME { BLOCK }", desempaquetar @_ en lugar de usar firmas de subrutinas, etc.)

    Uso avanzado de Type::Tiny con Moo, incluyendo uniones e intersecciones, "stringifies_to", "numifies_to", "with_attribute_values", y "where".
