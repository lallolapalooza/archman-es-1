MANUAL

¿Qué es un Tipo?

Hasta ahora, todos los ejemplos te han mostrado cómo trabajar con tipos, pero no hemos visto qué es realmente un tipo.

use Types::Standard qw( Int );
my $type = Int;

"Int" en el código anterior es simplemente una función llamada con cero argumentos que devuelve un objeto Perl bendecido. Es este objeto el que define qué es el tipo Int y es responsable de verificar que los valores cumplan su definición.

use Types::Standard qw( HashRef Int );
my $type = HashRef[Int];

La función "HashRef", si se llama sin parámetros, devuelve el objeto que define el tipo HashRef, al igual que la función "Int" lo hizo antes. Pero la diferencia aquí es que se llama con un parámetro, un arrayref que contiene el objeto de tipo Int. Lo utiliza para crear el tipo HashRef[Int] y lo devuelve.

Como cualquier objeto, puedes llamar a métodos sobre él. Los métodos más importantes que debes conocer son:

# comprueba el valor y devuelve un booleano
#
$type->check($value);

# devuelve un mensaje de error sobre que $value falla la comprobación del tipo
# pero en realidad no comprueba el valor
#
$type->get_message($value);

# transforma el valor
#
my $coerced = $type->coerce($value);

Ya hemos visto algunos otros métodos antes en el tutorial.

# crea un nuevo tipo, igual que el tipo antiguo, pero que tiene transformaciones
#
my $new_type = $type->plus_coercions( ... );

# sintaxis diferente para tipos parametrizados
#
my $href = HashRef;
my $int = Int;
my $href_of_int = $href->of($int);

Así que ahora deberías entender esto:

use Types::Standard qw( ArrayRef Dict Optional );
use Types::Common::Numeric qw( PositiveInt );
use Types::Common::String qw( NonEmptyStr );

my $RaceInfo = Dict[
  year    => PositiveInt,
  race    => NonEmptyStr,
  jockey  => Optional[NonEmptyStr],
];

has latest_event  => ( is => 'rw', isa => $RaceInfo );
has wins          => ( is => 'rw', isa => ArrayRef[$RaceInfo] );
has losses        => ( is => 'rw', isa => ArrayRef[$RaceInfo] );

Esto puede ayudarte a evitar la repetición si tienes un tipo parametrizado complejo que necesitas reutilizar varias veces.

"where"

Uno de los métodos más útiles que puedes llamar en un objeto de tipo es "where".

use Types::Standard qw( Int );

has lucky_number => (
  is   => 'ro',
  isa  => Int->where(sub { $_ != 13 }),
);

Creo que ya entiendes lo que hace. Crea una nueva restricción de tipo sobre la marcha, limitando el tipo original.

Al igual que con las transformaciones, estas restricciones se pueden expresar como un coderef o como una cadena de código Perl, operando sobre la variable $_. Y al igual que con las transformaciones, usar una cadena de código dará como resultado un mejor rendimiento.

use Types::Standard qw( Int );

has lucky_number => (
  is   => 'ro',
  isa  => Int->where(q{ $_ != 13 }),
);

Vamos a transformar un hashref de cadenas a partir de un arrayref de cadenas de tamaño par:

use Types::Standard qw( HashRef ArrayRef Str );

has stringhash => (
  is   => 'ro',
  isa  => HashRef->of(Str)->plus_coercions(
    ArrayRef->of(Str)->where(q{ @$_ % 2 == 0 }), q{
      my %h = @$_;
      \%h;
    },
  ),
  coerce => 1,  # ¡nunca lo olvides!
);

Si entiendes eso, realmente estás en la clase avanzada. ¡Felicitaciones!

Uniones

A veces quieres aceptar una cosa u otra. Esto es bastante fácil con Type::Tiny.

use Types::Standard qw( HashRef ArrayRef Str );

has strings => (
  is    => 'ro',
  isa   => ArrayRef[Str] | HashRef[Str],
);

Type::Tiny sobrecarga el operador OR bit a bit, por lo que cosas como esta deberían funcionar "simplemente".

Dicho esto, ahora cualquier código que llame a "$self->strings" probablemente necesitará verificar si el valor es un arrayref o un hashref antes de hacer nada con él. Así que puede ser más simple en general si simplemente eliges una de las opciones y transformas la otra en ella.

Intersecciones

Similar a una unión es una intersección.

package MyAPI::Client {
  use Moo;
  use Types::Standard qw( HasMethods InstanceOf );

  has ua => (
    is    => 'ro',
    isa   => (InstanceOf["MyUA"]) & (HasMethods["store_cookie"]),
  );
}

Aquí estamos comprobando que la UA es una instancia de la clase MyUA y también ofrece el método "store_cookie". Quizás "store_cookie" no es proporcionado por la propia clase MyUA, sino por varias subclases de MyUA.

Las intersecciones no son tan útiles como las uniones. Esto se debe a que a menudo no tienen sentido. "(ArrayRef) & (HashRef)" sería una referencia que apuntaría simultáneamente a un array y a un hash, lo cual es imposible.

Ten en cuenta que al usar intersecciones, es una buena práctica poner paréntesis alrededor de cada tipo. Esto es para desambiguar el significado de "&" para Perl, porque Perl lo usa como operador AND bit a bit, pero también como sigilo para las subrutinas.

Complementos

Para cualquier tipo Foo existe un tipo complementario ~Foo (pronunciado "no Foo").

package My::Class {
  use Moo;
  use Types::Standard qw( ArrayRef CodeRef );

  has things => ( is => 'ro', isa => ArrayRef[~CodeRef] );
}

"things" es ahora un arrayref de cualquier cosa excepto coderefs.

Si necesitas un número que no sea un entero:

Num & ~Int

Types::Standard incluye dos tipos que son complementarios entre sí: Undef y Defined.

NegativeInt podría parecer el complemento de PositiveOrZeroInt, pero cuando lo piensas, no lo es. Hay valores que caen en ninguna de las categorías, como no enteros, cadenas no numéricas, referencias, undef, etc.

"stringifies_to" y "numifies_to"

La restricción de tipo Object proporciona los métodos "stringifies_to" y "numifies_to" que probablemente se explican mejor con ejemplos.

"Object->numifies_to(Int)" significa cualquier objeto donde "0 + $object" es un entero.

"Object->stringifies_to(StrMatch[$re])" significa cualquier objeto donde "$object" coincide con la expresión regular.

"Object->stringifies_to($re)" también funciona como un atajo.

"Object->numifies_to($coderef)" y "Object->stringifies_to($coderef)" también funcionan, donde el coderef comprueba $_ y devuelve un booleano.

Otros tipos que también son lógicamente objetos, como HasMethods parametrizado, InstanceOf y ConsumerOf, también deberían proporcionar métodos "stringifies_to" y "numifies_to".

"stringifies_to" y "numifies_to" funcionan en uniones si *todos* los tipos de la unión ofrecen el método.

"stringifies_to" y "numifies_to" funcionan en intersecciones si *al menos uno de* los tipos de la intersección ofrece el método.
