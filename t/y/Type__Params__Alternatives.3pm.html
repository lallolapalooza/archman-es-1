Type::Params::Alternatives(3) Documentación de Perl aportada por el usuario Type::Params::Alternatives(3)

NOMBRE

Type::Params::Alternatives - subclase de Type::Params::Signature para firmas "multi"

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Este es principalmente código interno, pero puede ser utilizado para proporcionar introspección básica para firmas.

Este módulo es una subclase de Type::Parameters::Signature, por lo que hereda atributos y métodos de esa clase.

Constructor

new(%atributos)

Atributos

Todos los atributos son de solo lectura.

"base_options" HashRef
"alternatives" ArrayRef[HashRef|ArrayRef|CodeRef]
"sig_class" ClassName
"meta_alternatives" ArrayRef[HashRef]
Construido automáticamente a partir de "alternatives"; no establezca esto usted mismo.
"parameters" ArrayRef
Anulado de la clase padre para devolver siempre el arrayref vacío.
"message" Str
Mensaje de error a lanzar cuando ninguna de las alternativas coincide. Este es un atributo desnudo sin método accesor.

ERRORES
