NOMBRE

Type::Tiny::Manual::NonOO - Type::Tiny en código no orientado a objetos

MANUAL

Aunque Type::Tiny fue diseñado pensando en la programación orientada a objetos, especialmente clases y roles al estilo Moose, puede ser utilizado en programación procedural e imperativa.

Si has leído Type::Tiny::Manual::UsingWithMoo, deberías entender cómo Type::Params puede ser usado para validar parámetros de métodos. Esta misma técnica puede ser aplicada a subs regulares también. Más información sobre la verificación de parámetros se puede encontrar en Type::Tiny::Manual::Params.

Las funciones "is_*" y "assert_*" exportadas por librerías de tipos pueden ser útiles en código no-OO también. Ver Type::Tiny::Manual::UsingWithMoo3.

Type::Tiny y el Smart Match

Perl 5.10 introdujo el operador de smart match "~~", que ha sido desaprobado desde entonces porque, aunque la idea general es bastante sólida, los detalles eran un poco confusos.

Sin embargo, Type::Tiny tiene soporte para smart match y lo estoy documentando aquí porque no hay un lugar mejor para ponerlo.

Lo siguiente puede ser usado para verificar si un valor pasa una restricción de tipo:

$valor ~~ AlgúnTipo

Donde se vuelve raro es si $valor es un objeto y sobrecarga "~~". ¿Qué sobrecarga de "~~" gana? No lo sé.

Es mejor usar:

AlgúnTipo->check( $valor )   # más fiable, probablemente más rápido
is_AlgúnTipo($valor)         # más fiable, definitivamente más rápido

También es posible hacer:

$valor ~~ AlgúnTipo->coercion

Esto verifica si $valor coincide con algún tipo que pueda ser forzado a AlgúnTipo.

Pero es mejor usar:

AlgúnTipo->coercion->has_coercion_for_value( $valor )

"given" y "when"

Relacionado con el operador de smart match está la sintaxis "given"/"when".

Esto no hará lo que quieres que haga:

use Types::Standard qw( Str Int );

given ( $valor ) {
  when ( Int ) { ... }
  when ( Str ) { ... }
}

Esto hará lo que querías:

use Types::Standard qw( is_Str is_Int );

given ( $valor ) {
  when ( \&is_Int ) { ... }
  when ( \&is_Str ) { ... }
}

Lo siento, así son las cosas en Perl.

Mejor aún:

use Types::Standard qw( Str Int );
use Type::Utils qw( match_on_type );

match_on_type $valor => (
  Str, sub { ... },
  Int, sub { ... },
);

Si esto forma parte de un bucle u otra parte de código llamada frecuentemente, puedes compilar las verificaciones una vez y usarlas muchas veces:

use Types::Standard qw( Str Int );
use Type::Utils qw( compile_match_on_type );

my $tabla_de_enrutamiento = compile_match_on_type(
  Str, sub { ... },
  Int, sub { ... },
);

$tabla_de_enrutamiento->($_) for @muchos_valores;

Como con la mayoría de las cosas en Type::Tiny, esos coderefs pueden ser reemplazados por cadenas de código Perl.
