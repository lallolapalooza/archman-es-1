NOMBRE

Type::Tiny::ConstrainedObject - comportamiento compartido para Type::Tiny::Class, etc.

ESTADO

Este módulo se considera experimental.

DESCRIPCIÓN

Métodos

Los siguientes métodos existen para Type::Tiny::Class, Type::Tiny::Role, Type::Tiny::Duck y cualquier restricción de tipo que herede de "Object" o "Overload" en Types::Standard.

Estos métodos también funcionarán para Type::Tiny::Intersection si al menos uno de los tipos en la intersección proporciona estos métodos.

Estos métodos también funcionarán para Type::Tiny::Union si todos los tipos de la unión proporcionan estos métodos.

stringifies_to($constraint)
Genera una nueva restricción de tipo hijo que verifica la stringificación del objeto contra una restricción. Por ejemplo: 
my $type  = Type::Tiny::Class->new(class => 'URI');
my $child = $type->stringifies_to( StrMatch[qr/^http:/] );

$child->assert_valid( URI->new("http://example.com/") );

En el ejemplo anterior, $child es una restricción de tipo que verifica que los objetos estén bendecidos en (o hereden de) la clase URI, y cuando se stringifican (por ejemplo, a través de sobrecarga), el resultado coincide con la expresión regular "qr/^http:/".

$constraint puede ser una restricción de tipo, algo que se puede coaccionar a una restricción de tipo (como un coderef que devuelve un booleano), una cadena de código Perl que opera en $_, o una referencia a una expresión regular.

Por lo tanto, lo siguiente funcionaría:

my $child = $type->stringifies_to( sub { qr/^http:/ } );
my $child = $type->stringifies_to(       qr/^http:/   );
my $child = $type->stringifies_to(       'm/^http:/'  );

my $child = $type->where('"$_" =~ /^http:/');
numifies_to($constraint)
Lo mismo que "stringifies_to" pero verifica la numificación.

Lo siguiente podría ser útil:

use Types::Standard qw(Int Overload);
my $IntLike = Int | Overload->numifies_to(Int)
"with_attribute_values($attr1 => $constraint1, ...)"
Esto se explica mejor con un ejemplo: 
use Types::Common qw( InstanceOf StrMatch IntRange );

my $person = InstanceOf['Local::Human'];
my $woman  = $person->with_attribute_values(
   gender   => StrMatch[ qr/^F/i  ],
   age      => IntRange[ 18 => () ],
);

$woman->assert_valid($alice);

Esta afirmación primero verificará que $alice sea un Local::Human, luego verificará que "$alice->gender" comience con una "F", y finalmente verificará que "$alice->age" sea un entero de al menos 18.

Nuevamente, las restricciones pueden ser restricciones de tipo, coderefs, cadenas de código Perl o expresiones regulares.

Técnicamente, los "atributos" no necesitan ser atributos de Moo/Moose/Mouse, sino cualquier método que se pueda llamar sin parámetros y que devuelva un escalar.
