NOMBRE

Type::Tie - vincular una variable a una restricción de tipo

SINOPSIS

Type::Tie es una respuesta a este tipo de problema...

use strict;
use warnings;

{
   package Local::Testing;
   use Moose;
   has numbers => ( is => "ro", isa => "ArrayRef[Num]" );
}

# Buena lista de números.
my @N = ( 1, 2, 3, 3.14159 );

# Crear un objeto con una referencia a esa lista.
my $object = Local::Testing->new(numbers => \@N);

# Todo bien hasta ahora...

# ¡Ahora mira esto!
push @N, "Monkey!";
print $object->dump;

# ¡Houston, tenemos un problema!

Simplemente declara @N así:

use Type::Tie;
use Types::Standard qw( Num );

ttie my @N, Num, ( 1, 2, 3, 3.14159 );

Ahora, cualquier intento de añadir un valor no numérico a @N fallará.

DESCRIPCIÓN

Este módulo exporta una única función: "ttie". "ttie" vincula una variable a una restricción de tipo, asegurando que los valores almacenados en la variable se conformen a la restricción de tipo. Si la restricción de tipo tiene coerciones, estas se utilizarán si es necesario para garantizar que los valores asignados a la variable se conformen.

use Type::Tie;
use Types::Standard qw( Int Num );

ttie my $count, Int->plus_coercions(Num, 'int $_'), 0;

print tied($count)->type, "\n";   # 'Int'

$count++;            # ok
$count = 2;          # ok
$count = 3.14159;    # ok, coercionado a 3
$count = "Monkey!";  # falla

Aunque los ejemplos en la documentación (y la suite de pruebas) muestran restricciones de tipo de Types::Standard, cualquier objeto de restricción de tipo que soporte las interfaces de Type::API debería funcionar. Esto incluye:

  • Moose::Meta::TypeConstraint / MooseX::Types
  • Mouse::Meta::TypeConstraint / MouseX::Types
  • Specio
  • Type::Tiny

Sin embargo, con Type::Tiny, ni siquiera necesitas "use Type::Tie".

use Types::Standard qw( Int Num );

tie my $count, Int->plus_coercions(Num, 'int $_'), 0;

print tied($count)->type, "\n";   # 'Int'

$count++;            # ok
$count = 2;          # ok
$count = 3.14159;    # ok, coercionado a 3
$count = "Monkey!";  # falla

Clonado de variables vinculadas

Si clonas variables vinculadas con "dclone" de Storable, el clon también estará vinculado. El módulo Clone también es capaz de clonar variables vinculadas con éxito. Con otras técnicas de clonación, su nivel de éxito puede variar.
