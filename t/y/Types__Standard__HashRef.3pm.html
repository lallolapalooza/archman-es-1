Types::Standard::HashRef(3) Documentación de Perl aportada por el usuario Types::Standard::HashRef(3)

NOMBRE

Types::Standard::HashRef - utilidad exportadora para la restricción de tipo HashRef

SINOPSIS

use Types::Standard -types;

# Forma normal de validar un hashref de enteros.
#
HashRef->of( Int )->assert_valid( { uno => 1 } );

use Types::Standard::HashRef IntHash => { of => Int },

# Atajo exportado
#
assert_IntHash { uno => 1 };

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Este es principalmente código interno, pero también puede actuar como utilidad exportadora.

Exportaciones

Types::Standard::HashRef puede usarse experimentalmente como exportador.

use Types::Standard 'Int';
use Types::Standard::HashRef IntHash => { of => Int };

Esto exportará las siguientes funciones a tu espacio de nombres:

"IntHash"
is_IntHash( $valor )
assert_IntHash( $valor )
to_IntHash( $valor )

Se pueden exportar varios tipos a la vez:

use Types::Standard -types;
use Types::Standard::HashRef (
  IntHash  => { of => Int },
  NumHash  => { of => Num },
  StrHash  => { of => Str },
);

assert_IntHash { dos => 2 };   # no debería fallar

Es posible restringir aún más el hashref utilizando "where":

use Types::Standard::HashRef MyThing => { of => Int, where => sub { ... } };
