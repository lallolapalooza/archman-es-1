Type::Tiny::Role(3) Documentación de Perl Contribuida por el Usuario Type::Tiny::Role(3)

NOMBRE

Type::Tiny::Role - restricciones de tipo basadas en el método "DOES"

SINOPSIS

Uso a través de Types::Standard:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str ConsumerOf );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => ConsumerOf[ 'Local::Traits::DoesOwnership' ],
    default  => sub { Local::Person->new },
  );
}

Uso de la característica de exportación de Type::Tiny::Class:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Role (
    Owner => { role => 'Local::Traits::DoesOwnership' },
  );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => Owner,
    default  => sub { Local::Person->new },
  );
}

Uso de la interfaz orientada a objetos de Type::Tiny::Role:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Class;

  my $Owner = Type::Tiny::Role->new(
    role => 'Local::Traits::DoesOwnership',
  );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Owner,
    default  => sub { Local::Person->new },
  );
}

Uso de la interfaz funcional de Type::Utils:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Utils;

  my $Owner = role_type 'Local::Traits::DoesOwnership';

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Owner,
    default  => sub { Local::Person->new },
  );
}

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Restricciones de tipo de la forma general "{ $_->DOES("Some::Role") }".

Este paquete hereda de Type::Tiny; consulta ese para la mayor parte de la documentación. Las principales diferencias se enumeran a continuación:

Atributos

"role"
El rol para la restricción.

Tenga en cuenta que este paquete no suscribe a ningún sabor particular de roles (Moose::Role, Mouse::Role, Moo::Role, Role::Tiny, etc.). Simplemente confía en el método "DOES" del objeto (ver UNIVERSAL).

"constraint"
A diferencia de Type::Tiny, no puede pasar una coderef de restricción al constructor. En su lugar, confíe en el predeterminado.
"inlined"
A diferencia de Type::Tiny, no puede pasar una coderef de inlining al constructor. En su lugar, confíe en el predeterminado.
"parent"
El padre es siempre Types::Standard::Object y no se puede pasar al constructor.

Métodos

stringifies_to($constraint)
Ver Type::Tiny::ConstrainedObject.
numifies_to($constraint)
Ver Type::Tiny::ConstrainedObject.
"with_attribute_values($attr1 => $constraint1, ...)"
Ver Type::Tiny::ConstrainedObject.

Exportaciones

Type::Tiny::Role puede ser utilizado como un exportador.

use Type::Tiny::Role 'MyApp::Printable';

Esto exportará las siguientes funciones en su espacio de nombres:

"MyAppPrintable"
is_MyAppPrintable( $value )
assert_MyAppPrintable( $value )
to_MyAppPrintable( $value )

Se pueden exportar varios tipos a la vez:

use Type::Tiny::Role qw( MyApp::Printable MyApp::Sendable );
