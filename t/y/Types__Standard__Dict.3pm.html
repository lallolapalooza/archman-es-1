Types::Standard::Dict(3) Documentación de Perl aportada por el usuario Types::Standard::Dict(3)

NOMBRE

Types::Standard::Dict - utilidad exportadora y funciones de utilidad para la restricción de tipo Dict

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Este es principalmente código interno, pero tiene una función pública.

Función

Types::Standard::Dict::combine(@dicts)
Crea una restricción de tipo combinada, intentando ser permisivo.

Los dos tipos siguientes deberían ser equivalentes:

my $type1 = Types::Standard::Dict::combine(
  Dict[ name => Str ],
  Dict[ age => Int, Slurpy[HashRef[Int]] ],
  Dict[ id => Str, name => ArrayRef, Slurpy[ArrayRef] ],
);

my $type2 = Dict[
  name => Str|ArrayRef,
  age => Int,
  id => Str,
  Slurpy[ HashRef[Int] | ArrayRef ],
];

¡Tenga en cuenta que un hashref que satisfaga el tipo combinado no satisfaría ninguna de las restricciones Dict individuales, ni viceversa!

Esta función puede ser exportada:

use Types::Standard -types;
use Types::Standard::Dict combine => { -as => 'combine_dicts' };

my $type1 = combine_dicts(
  Dict[ name => Str ],
  Dict[ age => Int, Slurpy[HashRef[Int]] ],
  Dict[ id => Str, name => ArrayRef, Slurpy[ArrayRef] ],
);

Exports

Types::Standard::Dict puede usarse experimentalmente como exportador.

use Types::Standard 'Str';
use Types::Standard::Dict Credentials => { of => [
  username => Str,
  password => Str,
] };

Esto exportará las siguientes funciones a su espacio de nombres:

"Credentials"
is_Credentials( $value )
assert_Credentials( $value )
to_Credentials( $value )

Se pueden exportar varios tipos a la vez:

use Types::Standard -types;

use Types::Standard::Dict (
  Credentials => { of => [
    username => Str,
    password => Str,
  ] },
  Headers => { of => [
    'Content-Type' => Optional[Str],
    'Accept'       => Optional[Str],
    'User-Agent'   => Optional[Str],
  ] },
);

# Exportando esto por separado para que pueda usar los tipos definidos por
# la primera exportación.
use Types::Standard::Dict (
  HttpRequestData => { of => [
    credentials => Credentials,
    headers     => Headers,
    url         => Str,
    method      => Enum[ qw( OPTIONS HEAD GET POST PUT DELETE PATCH ) ],
  ] },
);

assert_HttpRequestData( {
  credentials => { username => 'bob', password => 's3cr3t' },
  headers     => { 'Accept' => 'application/json' },
  url         => 'http://example.net/api/v1/stuff',
  method      => 'GET',
} );

Es posible restringir aún más el hashref usando "where":

use Types::Standard::Dict MyThing => { of => [ ... ], where => sub { ... } };
