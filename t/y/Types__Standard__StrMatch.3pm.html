Types::Standard::StrMatch(3) Documentación de Contribución de Usuarios de Perl Types::Standard::StrMatch(3)

NOMBRE

Types::Standard::StrMatch - utilidad de exportación para la restricción de tipo StrMatch

SINOPSIS

use Types::Standard -types;

# Forma normal de validar una cadena contra una expresión regular.
#
StrMatch->of( qr/.../ )->assert_valid( "foo" );

use Types::Standard::StrMatch Identifier => { re => qr/.../ },

# Atajo exportado
#
assert_Identifier "foo";

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Este es en su mayoría código interno, pero también puede actuar como una utilidad de exportación.

Exportaciones

Types::Standard::ScalarRef puede usarse experimentalmente como exportador.

use Types::Standard::StrMatch Identifier => { re => qr/.../ };

Esto exportará las siguientes funciones a tu espacio de nombres:

"Identifier"
is_Identifier( $value )
assert_Identifier( $value )
to_Identifier( $value )

Se pueden exportar varios tipos a la vez:

use Types::Standard -types;
use Types::Standard::StrMatch (
  Identifier  => { re => qr/.../ },
  Url         => { re => qr/.../ },
       Email       => { re => qr/.../ },
);

assert_Email 'tobyink@example.net';   # no debería morir

Es posible restringir aún más la cadena usando "where":

use Types::Standard::StrMatch MyThing => { re => qr/.../, where => sub { ... } };
