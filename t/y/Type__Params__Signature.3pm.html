Type::Params::Signature(3) Documentación Perl contribuida por el usuario Type::Params::Signature(3)

NOMBRE

Type::Params::Signature - representación interna de la firma de una función

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCION

Este es principalmente un código interno, pero puede ser utilizado para proporcionar introspección básica para las firmas.

Constructores

new(%atributos)
"new_from_compile($estilo, %atributos)"
new_from_v2api(\%atributos)

Atributos

Todos los atributos son de solo lectura.

"paquete" NombreClase
El paquete para el que proporcionamos una firma. Se utilizará para buscar nombres de tipos de tipo cadena.
"subnombre" Str
La subrutina para la que proporcionamos una firma.
"descripcion" Str
"metodo" ArrayRef[InstanceOf['Type::Params::Parameter']]
"cabeza" ArrayRef[InstanceOf['Type::Params::Parameter']]
"cola" ArrayRef[InstanceOf['Type::Params::Parameter']]
"parametros" ArrayRef[InstanceOf['Type::Params::Parameter']]
"variable" InstanceOf['Type::Params::Parameter']
"en_muerte" CodeRef
"estrictez" Bool|ScalarRef
"siguiente" CodeRef
"ir_siguiente" CodeRef
Alias de "siguiente".
"puede_acortar" Bool
Indica si la firma no tiene potencial para alterar @_ permitiendo que se devuelva sin ser copiada si las comprobaciones de tipo pasan. En general, no deberías proporcionar esto al constructor y confiar en Type::Params::Signature para averiguarlo.
"coderef" InstanceOf['Eval::TypeTiny::CodeAccumulator']
Probablemente no querrás proporcionar esto al constructor. ¡El propósito de este módulo es construirlo para ti!

Atributos relacionados con parámetros con nombre

"es_con_nombre" Bool
"permite_guion" Bool
"bendecir" Bool|NombreClase
"clase" NombreClase
"constructor" Str
"atributos_clase" HashRef
HashRef adecuado para pasar al método "importar" de Class::XSAccessor. Se generará un valor predeterminado basado en "parámetros"
"con_nombre_a_lista" ArrayRef
Puede ser coaccionado desde un booleano basado en "parámetros".
"lista_a_con_nombre" Bool
"rastreo_oo" Bool
Por defecto es verdadero. Indica si los hashrefs de $arg bendecidos creados por la firma incluirán una clave '~~caller'.

Atributos desnudos

Estos atributos pueden pasarse a los constructores y pueden hacer algo, pero no se proporcionan métodos para acceder a los valores más tarde.

"posicional" o "pos" ArrayRef
"con_nombre" ArrayRef
"multiple" o "multi" ArrayRef
"retorna" Bool
Atajo para establecer simultáneamente "retorna_escalar" y "retorna_lista".
"quiere_fuente" Bool
"quiere_detalles" Bool
"quiere_objeto" Bool
"racionalizar_variables" Bool

Métodos

Predicados

Los métodos predicados devuelven verdadero/falso para indicar la presencia o ausencia de atributos.

"tiene_descripcion"
"tiene_cabeza"
"tiene_cola"
"tiene_parametros"
"tiene_variable"
"tiene_en_muerte"
"tiene_estrictez"
"tiene_retorna_escalar"
"tiene_retorna_lista"

Métodos de creación de clases

Estos métodos se llamarán automáticamente durante la construcción del objeto y normalmente no deberían llamarse. Son métodos públicos en caso de que se desee subclase Type::Params::Signature.

"hacer_clase_pp"
Construye la clase especificada en "bendecir" evaluando código Perl.
"hacer_clase_xs"
Construye la clase especificada en "bendecir" usando Class::XSAccessor.
"hacer_clase"
Llama a "hacer_clase_pp" o "hacer_clase_xs".
"hacer_codigo_clase_pp"
Genera el código para "hacer_clase_pp".

Otros métodos

"BUILD"
Llamado por los constructores. No deberías llamar a esto.
"retornar_deseado"
Normalmente devuelve el coderef de la firma, a menos que "quiere_fuente", "quiere_detalles", o "quiere_objeto" se proporcionaran al constructor, en cuyo caso devolverá el código fuente del coderef, un hashref de detalles, o $self.

AMBIENTE

"PERL_TYPE_PARAMS_XS"
Afecta a la construcción de accesores para objetos $arg. Si se establece en verdadero, usará Class::XSAccessor. Si se establece en falso, usará Perl puro. Si esta variable de entorno no existe, usará Class::XSAccessor.

Si Class::XSAccessor no está instalado o es demasiado antiguo, se usará Perl puro como fallback.

NAME

Type::Tiny - una alternativa más pequeña, rápida y limpia a Moose::Util::TypeConstraints

STATUS

Este módulo está en fase beta, pero está previsto que sea la base de Type::Tiny::XS (que será mucho más rápido) y de Type::Tiny::Strict (que aplicará más restricciones a la hora de definir tus tipos).

Los cambios de ruptura en la API se anunciarán en esta sección.

DESCRIPTION

Type::Tiny es una alternativa más pequeña, rápida y limpia a Moose::Util::TypeConstraints. Viene con un conjunto de tipos incorporados que debería ser suficiente para la mayoría de las necesidades.

Type::Tiny se centra en la simplicidad y el rendimiento. Intenta tener una API pequeña y coherente.

ENVIRONMENT

No hay variables de entorno especiales que afecten a este módulo.
