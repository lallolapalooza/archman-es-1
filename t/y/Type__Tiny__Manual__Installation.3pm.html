NOMBRE

Type::Tiny::Manual::Installation - cómo instalar Type::Tiny

MANUAL

La instalación de Type-Tiny debería ser sencilla.

Instalación con cpanminus

Si tienes cpanm, solo necesitas una línea:

% cpanm Type::Tiny

Si estás instalando en un directorio del sistema, puede que necesites pasar el flag "-S" a cpanm, que usa sudo para instalar el módulo:

% cpanm -S Type::Tiny

Instalación con el Shell CPAN

Alternativamente, si tu shell CPAN está configurado, deberías poder hacer:

% cpan Type::Tiny

Instalación Manual

Como último recurso, puedes instalarlo manualmente. Descarga el tarball y descomprímelo.

Consulta el archivo META.json para una lista de pre-requisitos. Instala estos primero.

Para construir Type-Tiny:

% perl Makefile.PL
% make && make test

Luego instálalo:

% make install

Si estás instalando en un directorio del sistema, puede que necesites ejecutar:

% sudo make install

Dependencias

Type::Tiny requiere al menos Perl 5.8.1, aunque ciertas características relacionadas con Unicode (por ejemplo, nombres de restricciones de tipo no ASCII) pueden funcionar mejor en versiones más nuevas de Perl.

Type::Tiny requiere Exporter::Tiny, un módulo que previamente se incluía en esta distribución, pero que desde entonces se ha separado como una distribución independiente. No te preocupes, es rápido y fácil de instalar.

En tiempo de ejecución, Type::Tiny también requiere los siguientes módulos de Perl: B, B::Deparse, Carp, Data::Dumper, Scalar::Util, Text::Balanced, overload, strict, y warnings. Todos estos vienen incluidos con Perl mismo.

Ciertas características requieren módulos adicionales. Las trazas de pila en excepciones requieren Devel::StackTrace. El plugin Reply::Plugin::TypeTiny para Reply requiere Reply (obviamente).

Type::Tiny::XS no es requerido, pero si está disponible, proporciona un impulso de velocidad para algunas verificaciones de tipo. (Establecer la variable de entorno "PERL_TYPE_TINY_XS" a falso, o establecer "PERL_ONLY" a verdadero suprimirá el uso de Type::Tiny::XS, incluso si está disponible.)

La suite de pruebas adicionalmente requiere Test::More, Test::Fatal y Test::Requires. Test::More viene incluido con Perl, pero si estás usando una versión de Perl anterior a 5.14, necesitarás actualizar al menos a la versión 0.96 de Test::More. Test::Requires y Test::Fatal (más Try::Tiny del que depende Test::Fatal) se incluyen con Type::Tiny en el directorio "inc", así que no necesitas instalarlos por separado.

Si usas Type::Tiny en conjunción con Moo, entonces se recomienda al menos Moo 1.006000. Si usas Type::Tiny con Moose, entonces se recomienda al menos Moose 2.0000. Si usas Type::Tiny con Mouse, entonces se recomienda al menos Mouse 1.00. Type::Tiny se ha probado mayormente con versiones antiguas de estos paquetes.

Type::Tiny y cperl

cperl http://perl11.org/cperl/ es una versión extendida de Perl con varios cambios incompatibles con los lanzamientos oficiales de Perl 5.

A partir de Type::Tiny 1.010001, cperl es una plataforma soportada para Type::Tiny con algunas advertencias. En el momento de escribir esto, Moose no se instala en los últimos lanzamientos de cperl, por lo que usar Type::Tiny con Moose en cperl no ha sido probado. Moo se puede forzar para instalar, y Type::Tiny se verifica que funcione con Moo en cperl. cperl no solo habilita una nueva categoría de advertencias llamada "shadow" (lo cual es bueno; son potencialmente útiles) sino que habilita las advertencias shadow por defecto (lo cual es molesto). Type::Tiny no (y probablemente nunca) intentará solucionar estas advertencias. Si las advertencias te molestan, deberías poder capturarlas usando $SIG{__WARN__}. Ciertas características de Eval::TypeTiny están rotas bajo cperl, pero no se cree que tengan ningún efecto práctico en Type::Tiny o sus otros módulos incluidos.
