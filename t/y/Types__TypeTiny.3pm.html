Types::TypeTiny(3) Documentación de Perl contribuida por el usuario Types::TypeTiny(3)

NOMBRE

Types::TypeTiny - restricciones de tipo utilizadas internamente por Type::Tiny

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

El tipo BoolLike es actualmente inestable.

DESCRIPCIÓN

Dogfooding.

Esto no es una verdadera biblioteca de tipos basada en Type::Library; eso implicaría demasiada circularidad. Pero exporta algunas restricciones de tipo que, aunque diseñadas para ser utilizadas dentro de Type::Tiny, pueden ser más útiles en general.

Tipos

  • StringLike

    Acepta cadenas de texto y objetos que sobrecargan la transformación a cadena.

  • BoolLike

    Acepta undef, "", 0, 1; acepta cualquier objeto bendecido que sobrecargue "bool"; acepta cualquier objeto bendecido que sobrecargue "0+" para devolver 0 o 1. (Necesita llamar realmente a la operación sobrecargada para comprobarlo.) También acepta cualquier objeto que herede de "boolean" o informe de ello como un rol ("DOES").

    Advertencia: un objeto que sobrecarga "0+" sin habilitar también los fallbacks de sobrecarga puede ser en realidad inútil como booleano práctico. Pero algunos objetos comunes como los booleanos de JSON::PP sobrecargan "0+" en lugar de sobrecargar "bool" (¡afortunadamente con los fallbacks habilitados!) por lo que necesitamos admitir esto.

    La intención de este tipo es ser una versión de Bool que también acepta objetos booleanos comunes como JSON::PP::Boolean. Actualmente es inestable y la definición exacta del tipo puede cambiar para implementar mejor esa funcionalidad prevista.

  • HashLike[`a]

    Acepta referencias a hashes y objetos que sobrecargan la transformación a hash.

    Desde Types::TypeTiny 1.012, puede ser parametrizado con otra restricción de tipo como HashLike[Int].

  • ArrayLike[`a]

    Acepta referencias a arrays y objetos que sobrecargan la transformación a array.

    Desde Types::TypeTiny 1.012, puede ser parametrizado con otra restricción de tipo como ArrayLike[Int].

  • CodeLike

    Acepta referencias a código y objetos que sobrecargan la transformación a código.

  • TypeTiny

    Acepta objetos bendecidos de Type::Tiny.

  • _ForeignTypeConstraint

    Cualquier referencia que to_TypeTiny reconozca como algo que puede ser coaccionado a un objeto Type::Tiny.

    Sí, el guion bajo está incluido.

Funciones de coerción

to_TypeTiny($constraint)
Promueve (o "degrada" si se prefiere) una restricción de tipo "extranjera" a un objeto Type::Tiny. Puede manejar:
  • Tipos de Moose (incluidos objetos Moose::Meta::TypeConstraint y objetos MooseX::Types::TypeDecorator).
  • Tipos de Mouse (incluidos objetos Mouse::Meta::TypeConstraint).
  • Objetos de Validation::Class y Validation::Class::Simple.
  • Tipos construidos usando Type::Library::Compiler.
  • Cualquier objeto que proporcione métodos "check" y "get_message". (Esto incluye tipos Specio y Type::Nano.) Si el objeto proporciona "has_coercion" y métodos de coerción, estos se utilizarán para manejar la citación. Si el objeto proporciona métodos "can_be_inlined" y "inline_check", estos se utilizarán para manejar la inserción en línea. Si el objeto proporciona un método "name", se asumirá que devuelve el nombre del tipo.
  • Coderefs (¡pero no coderefs bendecidos u objetos que sobrecargan "&{}" a menos que proporcionen los métodos descritos anteriormente!) Se espera que los coderefs devuelvan verdadero si y solo si $_ pasa la restricción de tipo. Si $_ falla la restricción de tipo, pueden devolver falso o morir con un mensaje de error útil.
  • Coderefs habilitados para Sub::Quote. Estos se manejan de la misma manera que arriba, pero Type::Tiny consultará Sub::Quote para determinar si pueden ser insertados en línea.

Métodos

Estos se implementan para que "Types::TypeTiny->meta->get_type($foo)" funcione, para una compatibilidad aproximada con una biblioteca de tipos real de Type::Library.

"meta"
"type_names"
get_type($name)
has_type($name)
"coercion_names"
get_coercion($name)
has_coercion($name)
