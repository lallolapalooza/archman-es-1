Type::Library(3) Documentación de Perl contribuida por el usuario Type::Library(3)

NOMBRE

Type::Library - bibliotecas de tipos diminutas, pero compatibles con Moo(se)

SINOPSIS

package Types::Mine {
   use Scalar::Util qw(looks_like_number);
   use Type::Library -base;
   use Type::Tiny;

   my $NUM = "Type::Tiny"->new(
      name       => "Number",
      constraint => sub { looks_like_number($_) },
      message    => sub { "$_ ain't a number" },
   );

   __PACKAGE__->meta->add_type($NUM);

   __PACKAGE__->meta->make_immutable;
}

package Ermintrude {
   use Moo;
   use Types::Mine qw(Number);
   has favourite_number => (is => "ro", isa => Number);
}

package Bullwinkle {
   use Moose;
   use Types::Mine qw(Number);
   has favourite_number => (is => "ro", isa => Number);
}

package Maisy {
   use Mouse;
   use Types::Mine qw(Number);
   has favourite_number => (is => "ro", isa => Number);
}

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Type::Library es una clase diminuta para crear bibliotecas de tipos similares a MooseX::Types que son compatibles con Moo, Moose y Mouse.

Si está leyendo esto porque quiere crear una biblioteca de tipos, probablemente sea mejor que lea Type::Tiny::Manual::Libraries.

Métodos de biblioteca de tipos

Una biblioteca de tipos es una clase singleton. Utilice el método "meta" para obtener un objeto bendecido al que se pueden llamar otros métodos. Por ejemplo:

Types::Mine->meta->add_type($foo);
add_type($type) o add_type(%opts)
Añade un tipo a la biblioteca. Si se proporciona %opts, este método llama primero a "Type::Tiny->new(%opts)" y añade el tipo resultante.

Añadir un tipo llamado "Foo" a la biblioteca definirá automáticamente cuatro funciones en el espacio de nombres de la biblioteca:

"Foo"
Devuelve el objeto Type::Tiny.
is_Foo($value)
Devuelve verdadero si y solo si $value pasa la restricción de tipo.
assert_Foo($value)
Devuelve $value si y solo si $value pasa la restricción de tipo. Muere en caso contrario.
to_Foo($value)
Convierte el valor al tipo.
get_type($name)
Obtiene el objeto "Type::Tiny" correspondiente al nombre.
has_type($name)
Booleano; devuelve verdadero si el tipo existe en la biblioteca.
"type_names"
Enumera todos los tipos definidos por la biblioteca.
add_coercion($c) o add_coercion(%opts)
Añade una coerción independiente a la biblioteca. Si se proporciona %opts, este método llama primero a "Type::Coercion->new(%opts)" y añade la coerción resultante.

Añadir una coerción llamada "FooFromBar" a la biblioteca definirá automáticamente una función en el espacio de nombres de la biblioteca:

"FooFromBar"
Devuelve el objeto Type::Coercion.
get_coercion($name)
Obtiene el objeto "Type::Coercion" correspondiente al nombre.
has_coercion($name)
Booleano; devuelve verdadero si la coerción existe en la biblioteca.
"coercion_names"
Enumera todas las coecciones independientes definidas por la biblioteca.
import(@args)
Las bibliotecas basadas en Type::Library son exportadoras.
"make_immutable"
Evita que se añadan nuevas restricciones de tipo y coecciones a la biblioteca, y también llama a "$type->coercion->freeze" en cada restricción de tipo de la biblioteca.

(Antes de Type::Library v2, "make_immutable" llamaba a "$type->coercion->freeze" en cada restricción de la biblioteca, pero no impedía que se añadieran nuevas restricciones de tipo y coecciones a la biblioteca.)

Funciones exportadas de la biblioteca de tipos

Las bibliotecas de tipos son exportadoras. Para los propósitos de los siguientes ejemplos, asuma que la biblioteca "Types::Mine" define los tipos "Number" y "String".

# No exporta nada.
# 
use Types::Mine;

# Exporta una función "String" que es una constante que devuelve
# la restricción de tipo String.
#
use Types::Mine qw( String );

# Exporta tanto String como Number como se describe arriba.
#
use Types::Mine qw( String Number );

# Igual.
#
use Types::Mine qw( :types );

# Exporta "coerce_String" y "coerce_Number", así como cualquier otra
# coerción
#
use Types::Mine qw( :coercions );

# Exporta una subrutina "is_String" de modo que "is_String($foo)" sea equivalente
# a "String->check($foo)".
#
use Types::Mine qw( is_String );

# Exporta "is_String" y "is_Number".
#
use Types::Mine qw( :is );

# Exporta una subrutina "assert_String" de modo que "assert_String($foo)" sea
# equivalente a "String->assert_return($foo)".
#
use Types::Mine qw( assert_String );

# Exporta "assert_String" y "assert_Number".
#
use Types::Mine qw( :assert );

# Exporta una subrutina "to_String" de modo que "to_String($foo)" sea equivalente
# a "String->coerce($foo)".
#
use Types::Mine qw( to_String );

# Exporta "to_String" y "to_Number".
#
use Types::Mine qw( :to );

# Exporta "String", "is_String", "assert_String" y "coerce_String".
#
use Types::Mine qw( +String );

# Exporta todo.
#
use Types::Mine qw( :all );

Las bibliotecas de tipos heredan automáticamente de Exporter::Tiny; consulte la documentación de ese módulo para obtener consejos y trucos para importar desde bibliotecas.

Métodos de Type::Library

Las secciones anteriores describen las características de las bibliotecas creadas con Type::Library. Los siguientes métodos están disponibles en Type::Library mismo.

"setup_type_library( $package, $utils, \@extends )"
Configura un paquete para ser una biblioteca de tipos. $utils es un booleano que indica si se debe importar Type::Utils en el paquete. @extends es una lista de bibliotecas de tipos existentes que el paquete debe extender.
