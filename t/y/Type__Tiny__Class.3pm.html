Type::Tiny::Class(3) Documentación de Perl aportada por el usuario Type::Tiny::Class(3)

NOMBRE

Type::Tiny::Class - restricciones de tipo basadas en el método "isa"

SINOPSIS

Usando a través de Types::Standard:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str InstanceOf );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => InstanceOf[ 'Local::Person' ],
    default  => sub { Local::Person->new },
  );
}

Usando la función de exportación de Type::Tiny::Class:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Class 'Local::Person';

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => LocalPerson,
    default  => sub { LocalPerson->new },
  );
}

Usando la interfaz orientada a objetos de Type::Tiny::Class:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Class;

  my $Person = Type::Tiny::Class->new( class => 'Local::Person' );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Person,
    default  => sub { $Person->new },
  );
}

Usando la interfaz funcional de Type::Utils:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Utils;

  my $Person = class_type 'Local::Person';

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Person,
    default  => sub { $Person->new },
  );
}

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Restricciones de tipo de la forma general "{ $_->isa("Some::Class") }".

Este paquete hereda de Type::Tiny; consulta este último para la mayor parte de la documentación. Las diferencias principales se enumeran a continuación:

Constructor

"new"
Cuando se llama al constructor en una instancia de Type::Tiny::Class, pasa la llamada al constructor de la clase para la restricción. Por ejemplo: 
my $type = Type::Tiny::Class->new(class => "Foo::Bar");
my $obj  = $type->new(hello => "World");
say ref($obj);   # imprime "Foo::Bar"

Este pequeño truco de "hacer lo que el usuario quiere" fue tomado prestado de MooseX::Types::TypeDecorator, pero Type::Tiny no lleva la idea tan lejos.

Atributos

"class"
La clase para la restricción.
"constraint"
A diferencia de Type::Tiny, no puedes pasar un coderef de restricción al constructor. En su lugar, confía en el valor predeterminado.
"inlined"
A diferencia de Type::Tiny, no puedes pasar un coderef de incrustación al constructor. En su lugar, confía en el valor predeterminado.
"parent"
El padre se calcula automáticamente y no se puede pasar al constructor.

Métodos

"plus_constructors($source, $method_name)"
Muy similar a "plus_coercions", pero agrega coerciones que pasan a través de un constructor. (De hecho, esto se implementa como un envoltorio para "plus_coercions").

Ejemplo:

package MyApp::Minion;

use Moose; extends "MyApp::Person";

use Types::Standard qw( HashRef Str );
use Type::Utils qw( class_type );

my $Person = class_type({ class => "MyApp::Person" });

has boss => (
   is     => "ro",
   isa    => $Person->plus_constructors(
      HashRef,     "new",
      Str,         "_new_from_name",
   ),
   coerce => 1,
);

package main;

MyApp::Minion->new(
   ...,
   boss => "Bob",  ## vía MyApp::Person->_new_from_name
);

MyApp::Minion->new(
   ...,
   boss => { name => "Bob" },  ## vía MyApp::Person->new
);

Dado que la coerción de "HashRef" a través del constructor es un deseo común, si llamas a "plus_constructors" sin ningún argumento en absoluto, este es el valor predeterminado.

$classtype->plus_constructors(HashRef, "new")
$classtype->plus_constructors()  ## idéntico al anterior

Esto es útil para clases basadas en Moose/Mouse/Moo.

stringifies_to($constraint)
Ver Type::Tiny::ConstrainedObject.
numifies_to($constraint)
Ver Type::Tiny::ConstrainedObject.
"with_attribute_values($attr1 => $constraint1, ...)"
Ver Type::Tiny::ConstrainedObject.

Exportaciones

Type::Tiny::Class puede usarse como exportador.

use Type::Tiny::Class 'HTTP::Tiny';

Esto exportará las siguientes funciones a tu espacio de nombres:

"HTTPTiny"
is_HTTPTiny( $value )
assert_HTTPTiny( $value )
to_HTTPTiny( $value )

También podrás usar "HTTPTiny->new(...)" como atajo para "HTTP::Tiny->new(...)".

Se pueden exportar varios tipos a la vez:

use Type::Tiny::Class qw( HTTP::Tiny LWP::UserAgent );

NOMBRE

Type::Tiny::Class - Clases como tipos de datos

SINOSIS


package My::Class;
use Type::Tiny;
use strict;
use warnings;

# ... tu código ...

1;
__PACKAGE__->export_types;

ESTADO

Estable. Este módulo está maduro y se mantiene activamente.

DESCRIPCIÓN

Type::Tiny::Class proporciona una forma sencilla de definir tipos de datos basados en clases. Permite definir tipos que coincidan con una clase específica o con cualquier clase que herede de ella.

Al usar Type::Tiny::Class, puedes crear tipos de datos personalizados que representan instancias de tus clases, lo que facilita la validación y el manejo de tipos en tu código Perl.
