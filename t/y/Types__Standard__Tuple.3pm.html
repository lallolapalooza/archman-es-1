Types::Standard::Tuple(3) Documentación aportada por el usuario de Perl Types::Standard::Tuple(3)

NOMBRE

Types::Standard::Tuple - Utilidad de exportación para la restricción de tipo Tuple

SINOPSIS

use Types::Standard -types;

# Forma normal de validar un par de enteros.
#
Tuple->of( Int, Int )->assert_valid( [ 7, 49 ] );

use Types::Standard::Tuple IntPair => { of => [ Int, Int ] },

# Atajo exportado
#
assert_IntPair [ 7, 49 ];

ESTADO

Este módulo no está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Este es principalmente código interno, pero también puede actuar como una utilidad de exportación.

Exportaciones

Types::Standard::Tuple puede usarse experimentalmente como un exportador.

use Types::Standard 'Int';
use Types::Standard::Tuple IntPair => { of => [ Int, Int ] };

Esto exportará las siguientes funciones a tu espacio de nombres:

"IntPair"
is_IntPair( $valor )
assert_IntPair( $valor )
to_IntPair( $valor )

Se pueden exportar varios tipos a la vez:

use Types::Standard -types;
use Types::Standard::HashRef (
  IntPair  => { of => [ Int, Int ] },
  StrInt   => { of => [ Str, Int ] },
);

assert_StrInt [ two => 2 ];   # no debería fallar

Es posible restringir aún más la tupla usando "where":

use Types::Standard::Tuple MyThing => { of => [ ... ], where => sub { ... } };
