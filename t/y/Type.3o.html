Testigo de igualdad de tipos

type (_, _) eq =
| Equal : ('a, 'a) eq

El propósito de eq es representar igualdades de tipos que pueden no ser conocidas por el verificador de tipos (por ejemplo, porque pueden depender de datos dinámicos).

Un valor de tipo (a, b) eq representa el hecho de que los tipos a y b son iguales.

Si se tiene un valor eq : (a, b) eq que prueba que los tipos a y b son iguales, se puede usar para convertir un valor de tipo a a un valor de tipo b mediante coincidencia de patrones en Equal:

      let cast (type a) (type b) (Equal : (a, b) Type.eq) (a : a) : b = a

En tiempo de ejecución, esta función simplemente devuelve su segundo argumento sin cambios.

Identificadores de tipo

module Id : sig end

Identificadores de tipo.

Un identificador de tipo es un valor que denota un tipo. Dados dos identificadores de tipo, se pueden probar con Type.Id.provably_equal para demostrar que denotan el mismo tipo. Tenga en cuenta que:

-Identificadores desiguales no implican tipos desiguales: un mismo tipo puede ser denotado por más de un identificador.

-Los identificadores de tipo se pueden serializar (marshalled), pero obtienen una identidad nueva y distinta al deserializar, por lo que las igualdades se pierden.

Ver un ejemplo de uso de Type.Id.
