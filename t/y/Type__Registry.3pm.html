Type::Registry(3) Documentación de Perl aportada por el usuario Type::Registry(3)

NOMBRE

Type::Registry - un hashref glorificado para buscar restricciones de tipo

SINOPSIS

package Foo::Bar;

use Type::Registry;

my $reg = "Type::Registry"->for_me;  # un registro para Foo::Bar

# Registrar todos los tipos de Types::Standard
$reg->add_types(-Standard);

# Registrar solo un tipo de Types::XSD
$reg->add_types(-XSD => ["NonNegativeInteger"]);

# Registrar todos los tipos de MyApp::Types
$reg->add_types("MyApp::Types");

# Crear un alias de tipo
$reg->alias_type("NonNegativeInteger" => "Count");

# Buscar una restricción de tipo
my $type = $reg->lookup("ArrayRef[Count]");

$type->check([1, 2, 3.14159]);  # falla

Alternativamente:

package Foo::Bar;

use Type::Registry qw( t );

# Registrar todos los tipos de Types::Standard
t->add_types(-Standard);

# Registrar solo un tipo de Types::XSD
t->add_types(-XSD => ["NonNegativeInteger"]);

# Registrar todos los tipos de MyApp::Types
t->add_types("MyApp::Types");

# Crear un alias de tipo
t->alias_type("NonNegativeInteger" => "Count");

# Buscar una restricción de tipo
my $type = t("ArrayRef[Count]");

$type->check([1, 2, 3.14159]);  # falla

ESTADO

Este módulo está cubierto por la política de estabilidad de Type-Tiny.

DESCRIPCIÓN

Un registro de tipos es básicamente un hashref que mapea nombres de tipos a objetos de restricciones de tipo.

Constructores

"new"
Crea un nuevo hashref glorificado.
for_class($class)
Crea o devuelve el hashref glorificado existente asociado con la clase dada.

Tenga en cuenta que cualquier restricción de tipo que haya importado de bibliotecas de tipos basadas en Type::Library estará automáticamente disponible en el registro de su clase.

"for_me"
Crea o devuelve el hashref glorificado existente asociado con el llamador.

Métodos

add_types(@libraries)
La lista de bibliotecas se trata como una "optlist" (al estilo de Data::OptList).

Las cadenas son los nombres de las bibliotecas de tipos; si el primer carácter es un guión, se expande al prefijo "Types::". Si va seguido de un arrayref, esta es la lista de tipos a importar de esa biblioteca. De lo contrario, importa todos los tipos de la biblioteca.

use Type::Registry qw(t);

t->add_types(-Standard);  # O: t->add_types("Types::Standard");

t->add_types(
   -TypeTiny => ['HashLike'],
   -Standard => ['HashRef' => { -as => 'RealHash' }],
);

Las bibliotecas MooseX::Types (y experimentalmente, MouseX::Types) también se pueden agregar de esta manera, pero *no pueden ir seguidas de un arrayref de* *tipos a importar*.

"add_type($type, $name)"
La forma singular tan esperada de "add_types". Dado un objeto de restricción de tipo, lo agrega al registro con un nombre dado. El nombre puede omitirse, en cuyo caso se llama a "$type->name", y Type::Registry generará un error si $type es anónimo. Si se proporciona explícitamente un nombre, a Type::Registry no le importa en absoluto si la restricción de tipo es anónima.

Este método puede incluso agregar restricciones de tipo MooseX::Types y MouseX::Types; de hecho, cualquier cosa que pueda ser manejada por la función "to_TypeTiny" de Types::TypeTiny. (Tenga en cuenta que to_TypeTiny *siempre* resulta en una restricción de tipo anónima, por lo que se requerirá $name).

"alias_type($oldname, $newname)"
Crea un alias para un tipo existente.
simple_lookup($name)
Busca un tipo en el registro por nombre.

Devuelve undef si no se encuentra.

foreign_lookup($name)
Similar a "simple_lookup", pero si el nombre del tipo contiene "::", intentará cargarlo desde una biblioteca de tipos. (E intentará cargar ese módulo).
lookup($name)
Busca por nombre, con un DSL. 
t->lookup("Int|ArrayRef[Int]")

El DSL se puede resumir como:

X               tipo de este registro
My::Lib::X      tipo de una biblioteca de tipos
~X              tipo complementario
X | Y           unión
X & Y           intersección
X[...]          tipo parametrizado
slurpy X        tipo slurpy
Foo::Bar::      tipo de clase

Falla si no se encuentra.

make_union(@constraints), make_intersection(@constraints), make_class_type($class), make_role_type($role)
Métodos de conveniencia para crear algunas restricciones de tipo comunes.
"AUTOLOAD"
Sobrecargado para llamar a "lookup". 
$registry->Str;  # como $registry->lookup("Str")
"get_parent", set_parent($reg), "clear_parent", "has_parent"
Cosas avanzadas. Permite que un registro tenga un registro "padre" del cual hereda restricciones de tipo.

Funciones

"t"
Esta clase puede exportar una función "t" que actúa como ""Type::Registry"->for_class($importing_class)".

ERRORES

Type::Registry(3pm)

Type::Registry Perl Programmer's Reference Guide

NOMBRE

Type::Registry - Registrar tipos de datos personalizados

SINOPSIS


use Type::Registry;

my $registry = Type::Registry->new;

$registry->register_type(
    name => 'My::Custom::Type',
    parent => 'Str',
    validation_code => sub {
        my ($value) = @_;
        return $value =~ /^[a-z]+$/;
    },
);

my $type = $registry->get_type('My::Custom::Type');
print $type->name, "\n"; # My::Custom::Type

if ($type->validate('hello')) {
    print "Valid\n"; # Valid
} else {
    print "Invalid\n";
}

if ($type->validate('Hello')) {
    print "Valid\n";
} else {
    print "Invalid\n"; # Invalid
}

DESCRIPCIÓN

Type::Registry es un módulo de Perl que proporciona un mecanismo para registrar y gestionar tipos de datos personalizados. Permite definir tipos con nombres, jerarquías (herencia de otros tipos) y código de validación específico.

MÉTODOS

new

Crea una nueva instancia de Type::Registry.

register_type(%args)

Registra un nuevo tipo de dato en el registro. Los argumentos aceptados son:

  • name: El nombre del tipo (cadena). Obligatorio.
  • parent: El nombre del tipo padre del que hereda este tipo (cadena). Opcional.
  • validation_code: Un código de subrutina que valida un valor dado. Debe devolver verdadero si el valor es válido, falso en caso contrario. Obligatorio.
get_type($name)

Devuelve el objeto de tipo registrado con el nombre dado. Lanza una excepción si el tipo no se encuentra.

has_type($name)

Devuelve verdadero si existe un tipo registrado con el nombre dado, falso en caso contrario.

EJEMPLO

El ejemplo de la sección SINOPSIS demuestra cómo crear un registro, registrar un tipo personalizado `My::Custom::Type` que hereda de `Str` y tiene una validación que solo permite letras minúsculas, y luego cómo usarlo para validar valores.
