TPMLIB_VolatileAll_Store(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_VolatileAll_Store(3) TPMLIB_VolatileAll_Store(3)

NOMBRE

TPMLIB_VolatileAll_Store - almacenar todo el estado volátil del TPM en un búfer

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_VolatileAll_Store(unsigned char **buffer,
uint32_t *buflen);

DESCRIPCIÓN

La función TPMLIB_VolatileAll_Store() se utiliza para obtener el estado volátil del TPM. La función asignará un buffer y devolverá el número de bytes de información de estado en la variable buflen.

ERRORES

TPM_SUCCESS
La función se completó con éxito.
TPM_FAIL
Fallo general.

Para obtener una lista completa de los códigos de error de TPM, consulte el archivo de inclusión libtpms/tpm_error.h.

VER TAMBIÉN

TPMLIB_MainInit(3), TPMLIB_Terminate(3), TPMLIB_RegisterCallbacks(3)
