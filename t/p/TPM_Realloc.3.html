TPM_Realloc(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPM_Malloc(3) TPM_Malloc(3)

NOMBRE

TPM_Malloc - Asignar memoria

TPM_Realloc - Reasignar memoria

TPM_Free - Liberar memoria

SINOPSIS

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_memory.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPM_Malloc(unsigned char **buffer,
uint32_t size);

TPM_RESULT TPM_Realloc(unsigned char **buffer,
uint32_t size);

void TPM_Free(unsigned char *buffer);

DESCRIPCIÓN

La función TPM_Malloc() se utiliza para asignar un buffer del tamaño dado. El buffer asignado se devolverá en el parámetro buffer.

La función TPM_Realloc() se utiliza para cambiar el tamaño de un buffer. El nuevo tamaño del buffer se proporciona en el parámetro size. El buffer reasignado contendrá los datos del buffer original.

Ambas funciones tienen la restricción de que el buffer que pueden asignar está limitado a TPM_ALLOC_MAX (64k) bytes. Este tamaño es suficiente para todos los buffers necesarios por el TPM.

Al completarse con éxito, las funciones devuelven TPM_SUCCESS. En caso de que el buffer solicitado exceda el límite, se devolverá TPM_SIZE. Consulte otros posibles códigos de error a continuación.

La función TPM_Free() libera la memoria previamente asignada utilizando TPM_Malloc() o TPM_Realloc().

ERRORES

TPM_SUCCESS
La función se completó con éxito.
TPM_SIZE
El tamaño del buffer solicitado excede el límite o el sistema se ha quedado sin memoria.
TPM_FAIL
El buffer solicitado tiene un tamaño de 0.

Para obtener una lista completa de los códigos de error de TPM, consulte el archivo de inclusión libtpms/tpm_error.h
