TPMLIB_Process(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_Process(3) TPMLIB_Process(3)

NOMBRE

TPMLIB_Process - procesa un comando TPM

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_Process(unsigned char **respbuffer**,
uint32_t *resp_size**,
uint32_t *respbufsize**,
unsigned char *command**,
uint32_t command_size**);**

DESCRIPCIÓN

La función TPMLIB_Process() se utiliza para enviar comandos TPM al TPM y recibir los resultados.

El parámetro command proporciona el búfer para el comando TPM y command_size el número de bytes válidos del comando TPM dentro de ese búfer.

respbuffer es un puntero a un búfer donde el TPM devolverá su resultado. Si no se proporciona ningún búfer (respbuffer es NULL), el TPM asignará un búfer. El parámetro resp_size devuelve el número de bytes válidos de respuesta del TPM en el búfer. Se garantiza que el número de bytes válidos en la respuesta no excederá el tamaño máximo del búfer de E/S. Utilice la API TPMLIB_GetTPMProperty() con el parámetro TPMPROP_TPM_BUFFER_MAX para obtener el tamaño máximo. El usuario debe indicar el tamaño de un búfer proporcionado con el parámetro respbufsize. Si el búfer no es lo suficientemente grande para la respuesta, el TPM liberará el búfer proporcionado y asignará uno de tamaño suficiente y adaptará respbufsize. El búfer devuelto solo está sujeto a restricciones de tamaño como se explica para TPM_Malloc().

ERRORES

TPM_SUCCESS
La función se completó con éxito.
TPM_FAIL
Fallo general.

Para una lista completa de códigos de error TPM, consulte el archivo de inclusión libtpms/tpm_error.h

EJEMPLO

#include <stdio.h>
#include <libtpms/tpm_types.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
static unsigned char TPM_Startup_ST_CLEAR[] = {
    0x00, 0xC1, 0x00, 0x00, 0x00, 0x0C, 0x00, 0x00, 0x00, 0x99,
    0x00, TPM_ST_CLEAR
};
int main(void) {
    TPM_RESULT res;
    unsigned char *respbuffer = NULL;
    uint32_t resp_size = 0;
    uint32_t respbufsize = 0;
    unsigned char *command;
    uint32_t command_size;
    [...]
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
         fprintf(stderr, "No se pudo iniciar el TPM.\n");
         return 1;
    }
    [...]
    /* construir comando TPM */
    command = TPM_Startup_ST_CLEAR;
    command_size = sizeof(TPM_Startup_ST_CLEAR);
    [...]
    res = TPMLIB_Process(&respbuffer, &resp_size,
                         &respbufsize,
                         command, command_size);
    [...]
    TPMLIB_Terminate();
    return 0;
}
