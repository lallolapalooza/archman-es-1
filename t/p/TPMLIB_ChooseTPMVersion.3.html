TPMLIB_ChooseTPMVersion(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_ChooseTPMVersion(3) TPMLIB_ChooseTPMVersion(3)

NOMBRE

TPMLIB_ChooseTPMVersion - Elige la versión del TPM

SINOPSIS

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_library.h>

TPM_RESULT TPMLIB_ChooseTPMVersion(TPMLIB_TPMVersion ver);

typedef enum TPMLIB_TPMVersion {
   TPMLIB_TPM_VERSION_1_2,
   TPMLIB_TPM_VERSION_2,
} TPMLIB_TPMVersion;

DESCRIPCIÓN

La función TPMLIB_ChooseTPMVersion() se utiliza para elegir la versión del TPM, ya sea TPM 1.2 o TPM 2.

Esta función debe ser llamada antes de que se llame a TPMLIB_MainInit(), de lo contrario devolverá un error. Esta función puede ser llamada de nuevo una vez que se haya llamado a TPMLIB_Terminate().

Si no se llama a esta función, la última versión del TPM elegida se iniciará con TPMLIB_MainInit(). Si no se llama a esta función, se utilizará un TPM 1.2.

ERRORES

TPM_SUCCESS
La versión del TPM fue elegida con éxito.
TPM_FAIL
La elección del TPM fue incorrecta, o TPMLIB_MainInit() ya ha sido llamada.

Para una lista completa de los códigos de error del TPM, consulte el archivo de inclusión libtpms/tpm_error.h

VER TAMBIÉN

TPMLIB_MainInit(3), TPMLIB_Terminate(3)
