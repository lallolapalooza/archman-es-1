TPMLIB_SetDebugPrefix(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_SetDebugFD(3) TPMLIB_SetDebugFD(3)

NOMBRE

TPMLIB_SetDebugFD - Establece el descriptor de archivo al que se enviarán las salidas de depuración

TPMLIB_SetDebugLevel - Establece el nivel de depuración

TPMLIB_SetDebugPrefix - Establece el prefijo para cada línea de depuración

BIBLIOTECA

TPM library (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_library.h>

uint32_t TPMLIB_SetDebugFD(int fd);

uint32_t TPMLIB_SetDebugLevel(unsigned int level);

uint32_t TPMLIB_SetDebugPrefix(const char *prefix);

DESCRIPCION

TPMLIB_SetDebugFD() permite establecer el descriptor de archivo al que se enviarán las salidas de depuración.

TPMLIB_SetDebugLevel() permite establecer el nivel de depuración. Solo los niveles de depuración mayores que 1 producirán salida. El nivel de sangría de una línea determinará si se imprime. Las líneas con 0 de sangría se imprimirán en el nivel de depuración 1, 1 espacio de sangría en el nivel de depuración 2 y así sucesivamente.

TPMLIB_SetDebugPrefix() permite establecer un prefijo que se imprimirá delante de cada línea de salida de depuración. El prefijo se puede utilizar para una mayor sangría.
