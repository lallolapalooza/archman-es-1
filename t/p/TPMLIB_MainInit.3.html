TPMLIB_MainInit(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_MainInit(3) TPMLIB_MainInit(3)

NOMBRE

TPMLIB_MainInit - Inicializa el TPM

TPMLIB_Terminate - Termina el TPM

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_MainInit(void);

TPM_RESULT TPMLIB_Terminate(void);

DESCRIPCIÓN

Las funciones TPMLIB_MainInit() y TPMLIB_Terminate() se utilizan para inicializar y terminar el TPM respectivamente. La función TPMLIB_MainInit() debe llamarse antes de que el TPM procese cualquier comando TPM. La función TPMLIB_Terminate() se llama para liberar todos los recursos internos (asignaciones de memoria) que el TPM ha utilizado y debe llamarse después de que el último comando TPM haya sido procesado por el TPM. La función TPMLIB_MainInit() se puede llamar nuevamente después.

Utilice TPMLIB_RegisterCallbacks() para establecer funciones de devolución de llamada para la inicialización y para escribir y restaurar el estado interno en un formato portable.

ERRORES

TPM_SUCCESS
La función se completó con éxito.
TPM_FAIL
Fallo general.

Para obtener una lista completa de los códigos de error del TPM, consulte el archivo de inclusión libtpms/tpm_error.h

EJEMPLO

#include <stdio.h>
#include <libtpms/tpm_types.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
int main(void) {
    TPM_RESULT res;
    unsigned char *respbuffer = NULL;
    uint32_t resp_size = 0;
    uint32_t respbufsize = 0;
    unsigned char *command;
    uint32_t command_size;
    [...]
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
        fprintf(stderr, "No se pudo iniciar el TPM.\n");
        return 1;
    }
    [...]
    /* construir comando TPM */
    [...]
    res = TPMLIB_Process(&respbuffer, &resp_size,
                         &respbufsize,
                         command, command_size);
    [...]
    TPMLIB_Terminate();
    return 0;
}
