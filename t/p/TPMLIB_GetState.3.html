TPMLIB_GetState(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_SetState(3) TPMLIB_SetState(3)

NOMBRE

TPMLIB_SetState - Establece el estado volátil, permanente o de guardado del TPM

TPMLIB_GetState - Obtiene el estado volátil, permanente o de guardado del TPM

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_library.h>

TPM_RESULT TPMLIB_SetState(enum TPMLIB_StateType st,
const unsigned char *buffer, uint32_t buflen);

TPM_RESULT TPMLIB_GetState(enum TPMLIB_StateType st,
unsigned char **buffer, uint32_t *buflen);

DESCRIPCIÓN

La función TPMLIB_SetState() permite establecer uno de los bloques de estado del TPM. El bloque de estado pasado se verifica para determinar si puede ser aceptado y se devuelve un código de error del TPM en caso de que no pueda ser aceptado. En caso de aceptación, el bloque de estado se pasará al TPM al llamar a TPM_MainInit(). Establecer un bloque de estado oculta un archivo que puede contener el mismo tipo de bloque y que se leería de lo contrario. Es necesario llamar a esta función con un puntero NULL para el parámetro buffer para ocultar un bloque de estado en un archivo.

Solo es posible establecer los bloques de estado después de haber llamado a TPMLIB_ChooseTPMVersion(). Todos los bloques de estado se borran cuando se elige una versión diferente del TPM usando TPMLIB_ChooseTPMVersion o cuando una llamada a TPMLIB_SetState() falla porque no se pudo aceptar un bloque de estado.

El orden en el que se establecen los bloques de estado es importante. El primer bloque de estado debe ser el que representa el estado permanente del TPM. Solo después de eso se pueden establecer los bloques de estado volátil o de guardado.

La función TPMLIB_GetState() permite obtener el estado actual del TPM. Mientras el TPM no se haya iniciado, esta función devuelve el bloque de estado establecido previamente con TPMLIB_SetState() o el estado se lee de un archivo. Una vez que el TPM se ha iniciado, se devuelve el estado del TPM en ejecución.

El tipo de estado del TPM TPMLIB_STATE_SAVE_STATE (estado de guardado) se puede establecer con esta función. Se devolverá el mismo bloque de estado hasta que se llame a TPM_Startup(ST_STATE), después de lo cual se devolverá un bloque vacío. Este bloque también solo se puede leer después de que se haya enviado TPM_SaveState() al TPM.

VER TAMBIÉN

TPMLIB_ChooseTPMVersion(3), TPMLIB_MainInit(3), TPMLIB_Terminate(3)
