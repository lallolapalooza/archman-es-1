TPMLIB_GetInfo(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_GetInfo(3) TPMLIB_GetInfo(3)

NOMBRE

TPMLIB_GetInfo - Obtener información sobre la implementación del TPM

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_library.h>

char *TPMLIB_GetInfo(TPMLIB_InfoFlags flags);

DESCRIPCIÓN

La función TPMLIB_GetInfo() permite consultar las especificaciones de la implementación del TPM y obtener una cadena JSON como respuesta. Qué datos se deben devolver se puede especificar en el parámetro flags, que puede ser una concatenación lógica 'or' de banderas. Si las banderas pasadas no son compatibles, no se devuelve nada. Si se pasa un 0, se devuelve un objeto JSON vacío '{}'.

Las siguientes banderas están definidas y devuelven objetos JSON como se muestra:

TPMLIB_INFO_TPMSPECIFICATION
{"TPMSpecification":{"family":"1.2","level":2,"revision":116}}
TPMLIB_INFO_TPMATTRIBUTES
{"TPMAttributes":{"manufacturer":"id:00001014","version":"id:00740001","model":"swtpm"}}
TPMLIB_INFO_TPMFEATURES (desde v0.8.0)
{"TPMFeatures":{"RSAKeySizes":[1024,2048,3072]}}

Este objeto JSON puede extenderse en el futuro.

TPMLIB_INFO_RUNTIME_ALGORITHMS (desde v0.10.0)
{
  "RuntimeAlgorithms": {
    "Implemented": "rsa,rsa-min-size=1024,tdes,tdes-min-size=128,sha1,hmac," \
                   "aes,aes-min-size=128,mgf1,keyedhash,xor,sha256,sha384," \
                   "sha512,null,rsassa,rsaes,rsapss,oaep,ecdsa,ecdh,ecdaa," \
                   "sm2,ecschnorr,ecmqv,kdf1-sp800-56a,kdf2,kdf1-sp800-108," \
                   "ecc,ecc-min-size=192,ecc-nist,ecc-bn,ecc-nist-p192," \
                   "ecc-nist-p224,ecc-nist-p256,ecc-nist-p384," \
                   "ecc-nist-p521,"ecc-bn-p256,ecc-bn-p638,ecc-sm2-p256," \
                   "symcipher,camellia,camellia-min-size=128,cmac,ctr,ofb," \
                   "cbc,cfb,ecb",
    "CanBeDisabled": "tdes,sha1,sha512,rsassa,rsaes,rsapss,ecmqv,ecc-nist," \
                     "ecc-bn,ecc-nist-p192,ecc-nist-p224,ecc-nist-p521," \
                     "ecc-bn-p256,ecc-bn-p638,ecc-sm2-p256,camellia,cmac," \
                     "ctr,ofb,cbc,ecb",
    "Enabled": "rsa,rsa-min-size=1024,hmac,aes,aes-min-size=128,mgf1," \
               "keyedhash,xor,sha256,sha384,null,oaep,ecdsa,ecdh,ecdaa," \
               "sm2,ecschnorr,kdf1-sp800-56a,kdf2,kdf1-sp800-108,ecc," \
               "ecc-min-size=192,ecc-bn,ecc-nist-p192,ecc-nist-p224," \
               "ecc-nist-p256,ecc-nist-p384,ecc-nist-p521,ecc-bn-p256," \
               "ecc-bn-p638,ecc-sm2-p256,symcipher,camellia," \
               "camellia-min-size=128,cmac,ctr,ofb,cbc,ecb",
    "Disabled": "tdes,sha1,sha512,rsassa,rsaes,rsapss,ecmqv,ecc-nist"
  }
}

Este objeto JSON enumera todos los algoritmos *implementados*, así como las curvas de criptografía de curva elíptica (ECC) compatibles. Estos verbos enumerados bajo CanBeDisabled representan algoritmos y curvas ECC que un usuario puede omitir de un perfil, haciéndolos así inaccesibles para las aplicaciones. Los verbos enumerados bajo Enabled y Disabled representan algoritmos que están habilitados y deshabilitados en el perfil activo actualmente.

Los verbos ecc-nist y ecc-bn son atajos que habilitan todas las curvas ECC NIST implementadas actualmente (ecc-nist-p192, ecc-nist-p256, ...) y las curvas BN (Baretto-Naehrig) (ecc-bn-p256, ecc-bn-p638). Si se omiten, las curvas individuales aún pueden enumerarse individualmente para habilitarlas. Dado que ecc-nist-p256 y ecc-nist-p384 no se pueden deshabilitar, deben enumerarse si no se usa el atajo ecc-nist.

También se describen los tamaños mínimos de clave para rsa, ecc, tdes, aes y camellia.

Cuando se agreguen nuevos algoritmos y curvas ECC al TPM en el futuro, este objeto JSON devolverá más algoritmos.

VALOR DE RETORNO

Esta función devuelve una cadena JSON en caso de éxito y un puntero NULL si se produjo un error de asignación de memoria.

TPMLIB_GetInfo(3) — libtpms

NAME

TPMLIB_GetInfo — get TPM information

LIBRARY

libtpms (libtpms, -ltpms)

SYNOPSIS

#include <tpmlib.h>
char *
TPMLIB_GetInfo(void);

DESCRIPTION

The function TPMLIB_GetInfo() returns a string containing information about the TPM. The string includes the manufacturer, the version, and the vendor ID. The format of the string is: "TPM manufacturer: <MANUFACTURER>, TPM version: <VERSION>, TPM vendor ID: <VENDOR_ID>".

RETURN VALUE

On success, TPMLIB_GetInfo() returns a pointer to a string containing TPM information. The caller is responsible to free() the returned string.

On failure, TPMLIB_GetInfo() returns NULL.
