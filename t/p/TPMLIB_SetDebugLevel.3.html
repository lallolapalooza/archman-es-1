TPMLIB_SetDebugLevel(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_SetDebugFD(3) TPMLIB_SetDebugFD(3)

NOMBRE

TPMLIB_SetDebugFD - Establece el descriptor de archivo al que se enviará la salida de depuración

TPMLIB_SetDebugLevel - Establece el nivel de depuración

TPMLIB_SetDebugPrefix - Establece el prefijo para cada línea de depuración

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_library.h>

uint32_t TPMLIB_SetDebugFD(int fd);

uint32_t TPMLIB_SetDebugLevel(unsigned int level);

uint32_t TPMLIB_SetDebugPrefix(const char *prefix);

DESCRIPCIÓN

TPMLIB_SetDebugFD() permite establecer el descriptor de archivo al que se enviará la salida de depuración.

TPMLIB_SetDebugLevel() permite establecer el nivel de depuración. Solo los niveles de depuración mayores que 1 producirán salida. El nivel de indentación de una línea determinará si se imprime. Las líneas con 0 de indentación se imprimirán en el nivel de depuración 1, 1 espacio de indentación en el nivel de depuración 2 y así sucesivamente.

TPMLIB_SetDebugPrefix() permite establecer un prefijo que se imprimirá delante de cada línea de salida de depuración. El prefijo puede utilizarse para una indentación adicional.
