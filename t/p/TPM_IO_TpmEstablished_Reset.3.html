TPM_IO_TpmEstablished_Reset(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPM_IO_TpmEstablished_Get(3) TPM_IO_TpmEstablished_Get(3)

NOMBRE

TPM_IO_TpmEstablished_Get - obtener el valor del flag TPMEstablished

TPM_IO_TpmEstablished_Reset - reiniciar el flag TPMEstablished

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_tis.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPM_IO_TpmEstablished_Get(TPM_BOOL *tpmEstablished);

TPM_RESULT TPM_IO_TpmEstablished_Reset(void);

DESCRIPCIÓN

La función TPM_IO_TpmEstablished_Get() devuelve el valor del flag TPMEstablished de los datos permanentes del TPM.

La función TPM_IO_TpmEstablished_Reset() reinicia el flag TPMEstablished.

ERRORES

TPM_SUCCESS
La función se completó con éxito.
TPM_FAIL
Fallo general.
TPM_BAD_LOCALITY
La localidad utilizada para reiniciar los flags es incorrecta.

Para obtener una lista completa de los códigos de error del TPM, consulte el archivo de inclusión libtpms/tpm_error.h
