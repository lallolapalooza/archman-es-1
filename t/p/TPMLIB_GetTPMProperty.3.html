TPMLIB_GetTPMProperty(3)

Paquete: libtpms

Licencias: BSD-3-Clause

TPMLIB_GetTPMProperty(3) TPMLIB_GetTPMProperty(3)

NOMBRE

TPMLIB_GetTPMProperty - Obtener una propiedad en tiempo de ejecución del TPM

BIBLIOTECA

Biblioteca TPM (libtpms, -ltpms)

SINOPSIS

#include <libtpms/tpm_library.h>

TPM_RESULT TPMLIB_GetTPMProperty(enum TPMLIB_TPMProperty, int *result);

DESCRIPCION

La llamada a TPMLIB_GetTPMProperty() se utiliza para recuperar parámetros en tiempo de ejecución del TPM, como el número de sesiones de autorización que puede mantener o los tamaños máximos de los blobs de estado permanente, guardado o volátil.

Esta función se puede llamar antes o después de que se haya creado el TPM. La implementación actual de libtpms devolverá el mismo valor antes y después de que se haya iniciado el TPM.

Con la introducción de la función TPMLIB_ChooseTPMVersion(), la llamada a esta función debe ejecutarse después de que se haya elegido la versión del TPM. La razón es que las diferentes versiones del TPM pueden devolver valores diferentes.

Las siguientes propiedades se han definido:

TPMPROP_TPM_RSA_KEY_LENGTH_MAX
El tamaño máximo de una clave RSA.
TPMPROP_TPM_BUFFER_MAX
Los tamaños máximos de los búferes de comandos y resultados del TPM.
TPMPROP_TPM_KEY_HANDLES
El número de ranuras de claves.
TPMPROP_TPM_OWNER_EVICT_KEY_HANDLES
El número de claves que el propietario puede desalojar.
TPMPROP_TPM_MIN_AUTH_SESSIONS
El número de sesiones de autorización.
TPMPROP_TPM_MIN_TRANS_SESSIONS
El número de sesiones de transporte.
TPMPROP_TPM_MIN_DAA_SESSIONS
El número de sesiones DAA.
TPMPROP_TPM_MIN_SESSION_LIST
El tamaño de la lista de sesiones.
TPMPROP_TPM_MIN_COUNTERS
El número de contadores monotónicos.
TPMPROP_TPM_NUM_FAMILY_TABLE_ENTRY_MIN
El número de entradas de familia.
TPMPROP_TPM_NUM_DELEGATE_TABLE_ENTRY_MIN
El número de entradas de delegados.
TPMPROP_TPM_SPACE_SAFETY_MARGIN
El margen de seguridad de espacio utilizado para los tamaños del peor caso de los blobs de estado guardado y estado volátil. Este margen de seguridad no se utiliza para el tamaño del blob de datos permanente.
TPMPROP_TPM_MAX_NV_SPACE
El tamaño máximo del blob de datos permanente.
TPMPROP_TPM_MAX_SAVESTATE_SPACE
El tamaño máximo del blob de estado guardado (incluye el margen de seguridad de espacio).
TPMPROP_TPM_MAX_VOLATILESTATE_SPACE
El tamaño máximo del blob de estado volátil (incluye el margen de seguridad de espacio).

ERRORES

TPM_SUCCESS
La función se completó correctamente.
TPM_FAIL
Se consultó una propiedad indefinida.

Para obtener una lista completa de los códigos de error de TPM, consulte el archivo de inclusión libtpms/tpm_error.h

EJEMPLO

#include <stdio.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
int main(void) {
    TPM_RESULT res;
    int result;
    int rc = 0;
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
        fprintf(stderr, "No se pudo iniciar el TPM.\n");
        return 1;
    }
    if (TPMLIB_GetTPMProperty(TPMPROP_TPM_RSA_KEY_LENGTH_MAX, &result)
        != TPM_SUCCESS) {
        fprintf(stderr, "No se pudo leer el tamaño máximo de las claves RSA.\n");
        goto err_exit;
    }
    fprintf(stdout, "Tamaño máximo de las claves RSA: %d\n", result);
err_exit:
    TPMLIB_Terminate();
    return 0;
}
