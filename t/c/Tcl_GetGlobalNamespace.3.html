ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el que existe el espacio de nombres y donde se realizan las búsquedas de nombres. También donde se escriben los mensajes de error.
const char *name (entrada)
El nombre del espacio de nombres o comando a crear o acceder.
ClientData clientData (entrada)
Un puntero de cliente proporcionado por el creador del espacio de nombres. Tcl no lo interpreta en absoluto.
Tcl_NamespaceDeleteProc *deleteProc (entrada)
Un puntero a una función que se llamará cuando se elimine el espacio de nombres, o NULL si no se realiza ninguna llamada de retorno.
Tcl_Namespace *nsPtr (entrada)
El espacio de nombres a manipular, o NULL (para que no sea Tcl_DeleteNamespace) para manipular el espacio de nombres actual.
Tcl_Obj *objPtr (salida)
Una referencia a un valor no compartido en el que se escribirá la salida de la función.
const char *pattern (entrada)
El patrón tipo glob (ver Tcl_StringMatch) que describe los comandos a importar o exportar.
int resetListFirst (entrada)
Si la lista de patrones de exportación debe restablecerse antes de añadir el patrón actual.
int allowOverwrite (entrada)
Si los nuevos comandos creados por esta acción de importación pueden sobrescribir comandos existentes.
Tcl_Namespace *contextNsPtr (entrada)
La ubicación en la jerarquía de espacios de nombres donde se debe realizar la búsqueda de un espacio de nombres o comando en relación con el término de búsqueda cuando no está enraizado en el espacio de nombres global. NULL indica el espacio de nombres actual.
int flags (entrada)
Combinación OR de bits que controlan cómo se debe realizar la búsqueda. Los siguientes flags son compatibles: TCL_GLOBAL_ONLY (indica que la búsqueda siempre debe realizarse en relación con el espacio de nombres global), TCL_NAMESPACE_ONLY (solo para Tcl_FindCommand; indica que la búsqueda siempre debe realizarse en relación con el espacio de nombres de contexto), y TCL_LEAVE_ERR_MSG (indica que se dejará un mensaje de error en el intérprete si la búsqueda falla).
Tcl_Obj *handlerPtr (entrada)
Un fragmento de script que se instalará como manejador de comandos desconocidos para el espacio de nombres, o NULL para restablecer el manejador a su valor predeterminado.

DESCRIPCIÓN

Los espacios de nombres son contextos de nombres jerárquicos que pueden contener comandos y variables. También mantienen una lista de patrones que describe qué comandos se exportan, y pueden importar comandos que han sido exportados por otros espacios de nombres. Los espacios de nombres también se pueden manipular a través del comando Tcl namespace.

La estructura Tcl_Namespace encapsula un espacio de nombres y se garantiza que tendrá los siguientes campos: name (el nombre local del espacio de nombres, sin caracteres separadores de espacios de nombres, vacío denota el espacio de nombres global), fullName (el nombre completo especificado del espacio de nombres), clientData, deleteProc (los valores especificados en la llamada a Tcl_CreateNamespace), y parentPtr (un puntero al espacio de nombres contenedor, o NULL para el espacio de nombres global).

Tcl_CreateNamespace crea un nuevo espacio de nombres. deleteProc tendrá la siguiente firma de tipo:

typedef void Tcl_NamespaceDeleteProc(
        ClientData clientData);

Tcl_DeleteNamespace elimina un espacio de nombres, llamando a deleteProc definido para el espacio de nombres (si existe).

Tcl_AppendExportList recupera los patrones de exportación para un espacio de nombres dado y los añade (como elementos de lista) a objPtr.

Tcl_Export establece y añade patrones de exportación para un espacio de nombres. Los patrones se añaden a menos que el flag resetListFirst sea verdadero.

Tcl_Import importa comandos que coinciden con un patrón a un espacio de nombres. Tenga en cuenta que el patrón debe incluir el nombre del espacio de nombres del que importar. Esta función devuelve TCL_ERROR si se intenta importar un comando sobre un comando existente, a menos que el flag allowOverwrite se haya establecido.

Tcl_ForgetImport elimina las importaciones que coinciden con un patrón.

Tcl_GetCurrentNamespace devuelve el espacio de nombres actual para un intérprete.

Tcl_GetGlobalNamespace devuelve el espacio de nombres global para un intérprete.

Tcl_FindNamespace busca un espacio de nombres llamado name dentro del contexto del espacio de nombres contextNsPtr. Si no se encuentra el espacio de nombres, se devuelve NULL.

Tcl_FindCommand busca un comando llamado name dentro del contexto del espacio de nombres contextNsPtr. Si no se encuentra el comando, se devuelve NULL.

Tcl_GetNamespaceUnknownHandler devuelve el manejador de comandos desconocidos para el espacio de nombres, o NULL si no hay ninguno establecido.

Tcl_SetNamespaceUnknownHandler establece el manejador de comandos desconocidos para el espacio de nombres. Si handlerPtr es NULL, el manejador se restablece a su valor predeterminado.
