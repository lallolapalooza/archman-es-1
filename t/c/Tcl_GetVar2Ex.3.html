#include <tcl.h>

Tcl_Obj *

Tcl_SetVar(interp, varName, newValue, flags)

const char *
Tcl_SetVar2(interp, name1, name2, newValue, flags)

Tcl_Obj *
Tcl_ObjSetVar2(interp, part1Ptr, part2Ptr, newValuePtr, flags)

Tcl_Obj *
Tcl_GetVar2Ex(interp, name1, name2, flags)

const char *
Tcl_GetVar(interp, varName, flags)

const char *
Tcl_GetVar2(interp, name1, name2, flags)

Tcl_Obj *
Tcl_ObjGetVar2(interp, part1Ptr, part2Ptr, flags)

int
Tcl_UnsetVar(interp, varName, flags)

int
Tcl_UnsetVar2(interp, name1, name2, flags)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene la variable.
const char *name1 (entrada)
Contiene el nombre de una variable de matriz (si name2 no es NULL) o (si name2 es NULL) ya sea el nombre de una variable escalar o un nombre completo que incluye tanto el nombre de la variable como el índice. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular.
const char *name2 (entrada)
Si no es NULL, proporciona el nombre del elemento dentro de la matriz; en este caso, name1 debe referirse a una variable de matriz.
Tcl_Obj *newValuePtr (entrada)
Punta a un valor Tcl que contiene el nuevo valor para la variable.
int flags (entrada)
Combinación OR de bits que proporciona información adicional. Consulte a continuación las valores válidos.
const char *varName (entrada)
Nombre de la variable. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de una matriz.
const char *newValue (entrada)
Nuevo valor para la variable, especificado como una cadena terminada en nulo. Se almacena una copia de este valor en la variable.
Tcl_Obj *part1Ptr (entrada)
Punta a un valor Tcl que contiene el nombre de la variable. El nombre puede incluir una serie de calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de una variable de matriz.
Tcl_Obj *part2Ptr (entrada)
Si no es NULL, punta a un valor que contiene el nombre de un elemento dentro de una matriz y part1Ptr debe referirse a una variable de matriz.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar, leer y eliminar variables de Tcl desde código C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 y Tcl_ObjSetVar2 crearán una nueva variable o modificarán una existente. Estos procedimientos establecen la variable dada al valor proporcionado por newValuePtr o newValue y devuelven un puntero al nuevo valor de la variable, que se almacena en la estructura de variables de Tcl. Tcl_SetVar2Ex y Tcl_ObjSetVar2 toman el nuevo valor como un Tcl_Obj y devuelven un puntero a un Tcl_Obj. Tcl_SetVar y Tcl_SetVar2 toman el nuevo valor como una cadena y devuelven una cadena; generalmente son menos eficientes que Tcl_ObjSetVar2. Tenga en cuenta que el valor de retorno puede ser diferente del argumento newValuePtr o newValue, debido a las modificaciones realizadas por los rastreadores de escritura. Si ocurre un error al establecer la variable (por ejemplo, se hace referencia a una variable de matriz sin proporcionar un índice a la matriz), se devuelve NULL y se deja un mensaje de error en el resultado de interp si está activado el bit de indicador TCL_LEAVE_ERR_MSG.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 y Tcl_ObjGetVar2 devuelven el valor actual de una variable. Los argumentos de estos procedimientos se tratan de la misma manera que los argumentos de los procedimientos descritos anteriormente. En circunstancias normales, el valor de retorno es un puntero al valor de la variable. Para Tcl_GetVar2Ex y Tcl_ObjGetVar2, el valor se devuelve como un puntero a un Tcl_Obj. Para Tcl_GetVar y Tcl_GetVar2, el valor se devuelve como una cadena; esto suele ser menos eficiente, por lo que se prefiere Tcl_GetVar2Ex o Tcl_ObjGetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de matriz para una variable escalar), se devuelve NULL y se deja un mensaje de error en el resultado de interp si está activado el bit de indicador TCL_LEAVE_ERR_MSG.

Tcl_UnsetVar y Tcl_UnsetVar2 se pueden utilizar para eliminar una variable, de modo que los intentos posteriores de leer la variable devuelvan un error. Los argumentos de estos procedimientos se tratan de la misma manera que los argumentos de los procedimientos anteriores. Si la variable se elimina correctamente, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si está activado el bit de indicador TCL_LEAVE_ERR_MSG. Si se especifica un elemento de matriz, se elimina el elemento dado pero la matriz permanece. Si se especifica un nombre de matriz sin un índice, se elimina toda la matriz.

El nombre de una variable se puede especificar a estos procedimientos de cuatro maneras:

[1]
Si se invoca Tcl_SetVar, Tcl_GetVar o Tcl_UnsetVar, el nombre de la variable se proporciona como una sola cadena, varName. Si varName contiene un paréntesis abierto y termina con un paréntesis cerrado, entonces el valor entre los paréntesis se trata como un índice (que puede tener cualquier valor de cadena) y los caracteres antes del primer paréntesis abierto se tratan como el nombre de una variable de matriz. Si varName no tiene paréntesis como se describe anteriormente, entonces toda la cadena se trata como el nombre de una variable escalar.
[2]
Si se proporcionan los argumentos name1 y name2 y name2 no es NULL, entonces se especifica un elemento de matriz y el nombre de la matriz y el índice ya han sido separados por el llamador: name1 contiene el nombre y name2 contiene el índice. Se genera un error si name1 contiene un paréntesis abierto y termina con un paréntesis cerrado (elemento de matriz) y name2 no es NULL.
[3]
Si name2 es NULL, name1 se trata igual que varName en el caso [1] anterior (puede ser el nombre de una variable escalar o un elemento de matriz).

El argumento flags se puede utilizar para especificar cualquiera de varias opciones a los procedimientos. Consiste en una combinación OR de los siguientes bits.

TCL_GLOBAL_ONLY
En circunstancias normales, los procedimientos buscan variables de la siguiente manera. Si una llamada a procedimiento está activa en interp, la variable se busca en el nivel actual de llamada al procedimiento. De lo contrario, la variable se busca primero en el espacio de nombres actual, luego en el espacio de nombres global. Sin embargo, si este bit está activado en flags, la variable se busca solo en el espacio de nombres global, incluso si hay una llamada a procedimiento activa. Si se proporcionan tanto TCL_GLOBAL_ONLY como TCL_NAMESPACE_ONLY, se ignora TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
Si este bit está activado en flags, la variable se busca solo en el espacio de nombres actual; si un procedimiento está activo, se ignoran sus variables, y el espacio de nombres global también se ignora a menos que sea el espacio de nombres actual.
TCL_LEAVE_ERR_MSG
Si se devuelve un error y este bit está activado en flags, se dejará un mensaje de error en el resultado del intérprete, donde se puede recuperar con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de indicador no está activado, no se dejará ningún mensaje de error y el resultado del intérprete no se modificará.
TCL_APPEND_VALUE
Si este bit está activado, newValuePtr o newValue se añaden al valor actual en lugar de reemplazarlo. Si la variable no está definida actualmente, se ignora el bit. Este bit solo lo utilizan los procedimientos Tcl_Set*.
TCL_LIST_ELEMENT
Si este bit está activado, newValue se convierte en un elemento de lista válido de Tcl antes de establecer (o añadir a) la variable. Se añade un espacio separador antes del nuevo

NAME

Tcl_SetVar, Tcl_SetVar2, Tcl_GetVar, Tcl_GetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 - manipulate Tcl variables

SYNOPSIS

#include <tcl.h>

int
Tcl_SetVar(interp, name, value, flags)
Tcl_Obj *
Tcl_SetVar2(interp, name1, name2, value, flags)
Tcl_Obj *
Tcl_GetVar(interp, name, flags)
Tcl_Obj *
Tcl_GetVar2(interp, name1, name2, flags)
int
Tcl_UnsetVar(interp, name, flags)
int
Tcl_UnsetVar2(interp, name1, name2, flags)

ARGUMENTS

Tcl_Interp *interp
Interpreter in which to manipulate variables.
const char *name
Name of the scalar variable or array.
const char *name1
Name of the first part of a variable name (if it is an array element).
const char *name2
Name of the second part of a variable name (if it is an array element).
Tcl_Obj *value
New value for the variable.
int flags
Any combination of TCL_GLOBAL_ONLY, TCL_LEAVE_ERR_MSG, TCL_APPEND_VALUE, TCL_LIST_ELEMENT, TCL_EXPAND_WORD.

DESCRIPTION

These procedures provide Tcl C code access to Tcl variables.

Tcl_SetVar and Tcl_SetVar2 are used to set the value of a Tcl variable. name is the name of the variable, or the name of an array if name2 is NULL. If name2 is not NULL, then the variable is assumed to be an array element, with name name1 for the array name and name2 for the index. If name2 is NULL then name is the name of the variable, which can be a scalar variable or an array. The value is specified by the value object. The flags argument is an OR-ed combination of zero or more of the following flags:

TCL_GLOBAL_ONLY
If this flag is set, the variable is treated as global, even if it is set from within a procedure. If this flag is not set, then if the variable name is not found in any of the current procedure's local variables, Tcl will search for it in global scope.
TCL_LEAVE_ERR_MSG
If this flag is set, then if an error occurs, Tcl will leave the error message in the interpreter's result object. If the flag is not set, then the error message is discarded. This flag is useful when you want to handle errors yourself.
TCL_APPEND_VALUE
If this flag is set, the new value is appended to the existing value of the variable. This flag may only be used if the variable already exists. The existing value is converted to a string representation before appending. The variable must be a scalar variable.
TCL_LIST_ELEMENT
If this flag is set, the new value is appended as a new element to the list stored in the variable. The variable must already exist and contain a list (or be empty, or contain "{", or end in " }"). Appending to a list variable means that the new element is added to the end of the list, and the list is re-encoded as a string. A new element is NOT added if the list element is going to be the first element in a list or sublist (i.e. the variable's current value is empty, or contains the single character “{”, or ends in “ }”). When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.
TCL_EXPAND_WORD
If this flag is set, then the variable is treated as if it were an unquoted word in a Tcl command. This means that characters like '$', '@', '{', '}' will be interpreted as substitutions. This flag is typically used when setting variables from user input, where such substitutions might be intended.

Tcl_SetVar and Tcl_SetVar2 return TCL_OK if the variable was set successfully, and TCL_ERROR if an error occurred. If TCL_LEAVE_ERR_MSG is set and an error occurs, the error message is left in the interpreter's result object; otherwise, the result is undefined.

Tcl_GetVar and Tcl_GetVar2 return the current value of a variable. The arguments to these procedures are treated in the same way as the arguments to Tcl_SetVar and Tcl_SetVar2. Under normal circumstances, the return value is a pointer to the variable's value (which is stored in Tcl's variable structure and will not change before the next call to Tcl_SetVar or Tcl_SetVar2). Tcl_GetVar and Tcl_GetVar2 use the flag bits TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG, both of which have the same meaning as for Tcl_SetVar. If an error occurs in reading the variable (e.g. the variable does not exist or an array element is specified for a scalar variable), then NULL is returned.

Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a variable, so that future calls to Tcl_GetVar or Tcl_GetVar2 for the variable will return an error. The arguments to these procedures are treated in the same way as the arguments to Tcl_GetVar and Tcl_GetVar2. If the variable is successfully removed then TCL_OK is returned. If the variable cannot be removed because it does not exist then TCL_ERROR is returned. If an array element is specified, the given element is removed but the array remains. If an array name is specified without an index, then the entire array is removed.
