ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el cual se va a crear o encontrar el ensemble. También donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener un valor NULL para el interp, pero todas las demás funciones no deben.
const char *name (entrada)
El nombre del comando ensemble a crear.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres al cual se va a vincular el comando ensemble, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto OR de bits de flags que describen la configuración básica del ensemble. Actualmente solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando ensemble también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando ensemble a buscar.
int flags (entrada)
Un conjunto OR de bits de flags que controlan el comportamiento de Tcl_FindEnsemble. Actualmente solo TCL_LEAVE_ERR_MSG es soportado.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando ensemble, o que usted desea usar para probar como comando ensemble en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la cual escribir los bits de flags actuales del ensemble; actualmente solo está definido el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario para usar como prefijo de mapeo de subcomando a comando de implementación en el ensemble. Puede ser NULL si el diccionario de mapeo se va a eliminar.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la cual escribir el diccionario de mapeo actual del ensemble.
Tcl_Obj *listObj (entrada)
Un valor de lista para usar como lista de parámetros formales pre-subcomando, la lista definida de subcomandos en el diccionario o el prefijo del comando manejador de subcomandos desconocidos. Puede ser NULL si la lista de subcomandos o el manejador de desconocidos se van a eliminar.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la cual escribir la lista actual de parámetros formales pre-subcomando, la lista definida de subcomandos o el prefijo del manejador de desconocidos actual.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la cual escribir el manejador del espacio de nombres al cual está vinculado el ensemble.

DESCRIPCION

Un ensemble es un comando, asociado a algún espacio de nombres, que consiste en una colección de comandos subordinados implementados por otros comandos Tcl. El primer argumento del comando ensemble es siempre interpretado como un selector que indica qué subcomando ejecutar.

Los ensembles se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete en el cual se crea o se encuentra el ensemble, el nombre del ensemble a crear, el espacio de nombres dentro del intérprete en el cual se asocia el ensemble, y el conjunto de flags por defecto de los ensembles. El resultado de la función es el token de comando para el ensemble, que puede ser utilizado para configurar el ensemble mediante la API descrita en PROPIEDADES DEL ENSEMBLE.

Dado el nombre de un comando ensemble, se puede recuperar el token para ese comando usando Tcl_FindEnsemble. Si el nombre dado (en cmdNameObj) no se refiere a un comando ensemble, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está seteado en flags) se deja un mensaje de error en el resultado del intérprete.

Un token de comando puede ser verificado para ver si se refiere a un ensemble usando Tcl_IsEnsemble. Este devuelve 1 si el token se refiere a un ensemble, o 0 de lo contrario.

PROPIEDADES DEL ENSEMBLE

Cada ensemble tiene cuatro propiedades de lectura y escritura, y una propiedad de lectura solo. Las propiedades son:

flags (lectura/escritura)
El conjunto de flags para el ensemble, expresado como un bit-field. Actualmente, el único flag público es TCL_ENSEMBLE_PREFIX que se establece cuando los prefijos inambiguos de subcomandos son permitidos para ser resueltos a implementaciones como también exactas coincidencias. Los flags pueden ser leídos y escritos usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambos funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras que se usan como prefijo de comando (reemplazando los primeros dos palabras del comando, que son el comando ensemble本身 y el nombre del subcomando), o NULL si cada subcomando se mapea a la misma nombre de comando en el espacio de nombres del ensemble. Por defecto es NULL. Puede ser leído y escrito usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambos funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y el diccionario obtenido de Tcl_GetEnsembleMappingDict debe siempre tratarse como inmutable incluso si no es compartido. Todos los nombres de comando en los prefijos establecidos mediante Tcl_SetEnsembleMappingDict deben ser completamente cualificados.
lista de parámetros de subcomando formal (lectura/escritura)
Una lista de nombres de parámetros formales (las cuales solo se usan cuando se generan mensajes de error) que se invocan entre el nombre del ensemble y el argumento de subcomando. NULL (por defecto) es equivalente a una lista vacía. Puede ser leído y escrito usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambos funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y el diccionario obtenido de Tcl_GetEnsembleParameterList debe siempre tratarse como inmutable incluso si no es compartido.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el ensemble, o NULL si este se deriva de los claves del diccionario de mapeo (ver arriba) o (si eso también es NULL) de los comandos exportados por el espacio de nombres asociado. Puede ser leído y escrito usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambos funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y la lista obtenida de Tcl_GetEnsembleSubcommandList debe siempre tratarse como inmutable incluso si es no compartido.
prefijo de comando de handler de subcomandos desconocidos (lectura/escritura)
Una lista de palabras que se prependen al frente de cualquier subcomando cuando este es desconocido para el ensemble (según el prefijo actual de resolución). Por defecto es NULL. Puede ser leído y escrito usando Tcl_GetEnsembleUnknownHandler y Tcl_SetEnsembleUnknownHandler respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble).

Tcl_SetEnsembleSubcommandList(3)

NAME

Tcl_SetEnsembleSubcommandList, Tcl_GetEnsembleSubcommandList, Tcl_SetEnsembleUnknownHandler, Tcl_GetEnsembleUnknownHandler, Tcl_SetEnsembleNamespace, Tcl_GetEnsembleNamespace, Tcl_SetEnsembleMapping, Tcl_GetEnsembleMapping - manipulate ensemble command properties

SYNOPSIS

#include <tcl.h>

int
Tcl_SetEnsembleSubcommandList(interp, token, list);
Tcl_Obj *
Tcl_GetEnsembleSubcommandList(interp, token);
int
Tcl_SetEnsembleUnknownHandler(interp, token, handler);
Tcl_Obj *
Tcl_GetEnsembleUnknownHandler(interp, token);
int
Tcl_SetEnsembleNamespace(interp, token, nsToken);
Tcl_Obj *
Tcl_GetEnsembleNamespace(interp, token);
int
Tcl_SetEnsembleMapping(interp, token, mapping);
Tcl_Obj *
Tcl_GetEnsembleMapping(interp, token);

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting and for resolving namespace tokens.
Tcl_CommandToken token
Token for the ensemble command to modify.
Tcl_Obj *list
A Tcl object containing a list of subcommand names and associated command procedures.
Tcl_Obj *handler
A Tcl object containing a script to invoke when an unknown subcommand is encountered.
Tcl_CommandToken nsToken
Token for the namespace associated with the ensemble.
Tcl_Obj *mapping
A Tcl object containing a dictionary mapping subcommand names to command procedures.

DESCRIPTION

These functions are used to manipulate the properties of an ensemble command. An ensemble command is a command that dispatches to one of several subcommands based on its first argument. The properties of an ensemble command define how this dispatching is performed.

The Tcl_SetEnsembleSubcommandList and Tcl_GetEnsembleSubcommandList functions manipulate the list of subcommands for an ensemble. The list argument to Tcl_SetEnsembleSubcommandList should be a Tcl object containing a list. Each element of the list should itself be a list of two elements: a subcommand name (a string) and the Tcl script or command to execute for that subcommand. If list is NULL, then any existing subcommand list is removed. The subcommand list is consulted first when determining which subcommand to execute.

The Tcl_SetEnsembleUnknownHandler and Tcl_GetEnsembleUnknownHandler functions manipulate the unknown handler for an ensemble. The handler argument to Tcl_SetEnsembleUnknownHandler should be a Tcl object containing a script. This script will be executed if the subcommand is not found in the subcommand list or the mapping dictionary. If handler is NULL, then the default behavior of generating an error message will be used when an unknown subcommand is encountered. The unknown handler script is invoked with the ensemble name as its first argument, followed by the arguments passed to the ensemble. The unknown handler should return a Tcl result code. If the handler script is invoked, it is responsible for performing any error reporting itself, and should typically return TCL_ERROR. If the unknown handler returns TCL_OK, the ensemble command will return normally, and the return value of the handler script will be the return value of the ensemble command.

The Tcl_SetEnsembleNamespace and Tcl_GetEnsembleNamespace functions manipulate the namespace associated with an ensemble. The nsToken argument to Tcl_SetEnsembleNamespace should be a token for a namespace. If nsToken is NULL, then any existing namespace association is removed. The namespace is used as a fallback for resolving subcommand names if both the subcommand list and the mapping dictionary are empty or NULL. When the namespace is deleted, the ensemble is also deleted.

The Tcl_SetEnsembleMapping and Tcl_GetEnsembleMapping functions manipulate the mapping dictionary for an ensemble. The mapping argument to Tcl_SetEnsembleMapping should be a Tcl object containing a dictionary. The keys of the dictionary should be subcommand names (strings), and the values should be Tcl scripts or commands to execute for those subcommands. If mapping is NULL, then any existing mapping is removed. The mapping dictionary is consulted after the subcommand list but before the namespace.

All of the Tcl_Set* functions return TCL_OK if the property was successfully set, and TCL_ERROR otherwise. All of the Tcl_Get* functions return a Tcl object pointer if the property was successfully retrieved, and NULL otherwise. The Tcl objects returned by the Tcl_Get* functions should be treated as immutable and should not be modified.

The following properties are associated with an ensemble command:

subcommandlist (read-write)
The list of subcommands and their associated procedures. See the Tcl_SetEnsembleSubcommandList and Tcl_GetEnsembleSubcommandList functions for more details. If NULL, the default behavior - generate a suitable error message - will be used when an unknown subcommand is encountered. May be read and written using Tcl_GetEnsembleSubcommandList and Tcl_SetEnsembleSubcommandList respectively. The result of both functions is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleSubcommandList should always be treated as immutable even if it is unshared.
unknownhandler (read-write)
The script to execute when an unknown subcommand is encountered. See the namespace ensemble command for more details. If NULL, the default behavior - generate a suitable error message - will be used when an unknown subcommand is encountered. May be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The result of both functions is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.
bound namespace (read-only)
The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).
