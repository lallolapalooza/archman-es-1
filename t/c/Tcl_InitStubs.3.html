Tcl_InitStubs(3) Procedimientos de la biblioteca Tcl Tcl_InitStubs(3)

NOMBRE

Tcl_InitStubs - inicializa el mecanismo de "stubs" de Tcl

SINOPSIS

#include <tcl.h>

const char *
Tcl_InitStubs(interp, version, exact)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Identificador del intérprete de Tcl.
const char *version (entrada)
Una cadena de versión que consiste en uno o más números decimales separados por puntos.
int exact (entrada)
Si es distinto de cero, significa que solo la versión específica especificada por version es aceptable. Si es cero, significa que las versiones más nuevas que version también son aceptables siempre que tengan el mismo número de versión principal que version.

INTRODUCCIÓN

El mecanismo de "stubs" de Tcl define una forma de enlazar dinámicamente extensiones a una implementación de Tcl particular en tiempo de ejecución. Esto proporciona dos beneficios significativos a los usuarios de Tcl:

1)
Las extensiones que utilizan el mecanismo de "stubs" se pueden cargar en múltiples versiones de Tcl sin ser recompiladas o relinkeadas.
2)
Las extensiones que utilizan el mecanismo de "stubs" se pueden cargar dinámicamente en aplicaciones Tcl enlazadas estáticamente.

El mecanismo de "stubs" logra esto exportando tablas de funciones que definen una interfaz a la API de Tcl. La extensión accede entonces a la API de Tcl a través de offsets en la tabla de funciones, por lo que no hay referencias directas a ninguno de los símbolos de la biblioteca de Tcl. Esta redirección es transparente para la extensión, por lo que un desarrollador de extensiones puede seguir utilizando todas las funciones públicas de Tcl como se documenta.

El mecanismo de "stubs" no requiere cambios en las aplicaciones que incorporan intérpretes de Tcl. Solo los desarrolladores que crean extensiones de Tcl basadas en C necesitan tomar medidas para utilizar el mecanismo de "stubs" con sus extensiones.

Habilitar el mecanismo de "stubs" para una extensión requiere los siguientes pasos:

1)
Llamar a Tcl_InitStubs en la extensión antes de llamar a cualquier otra función de Tcl.
2)
Definir el símbolo USE_TCL_STUBS. Típicamente, incluirías la bandera -DUSE_TCL_STUBS al compilar la extensión.
3)
Enlazar la extensión con la biblioteca de "stubs" de Tcl en lugar de la biblioteca estándar de Tcl. Por ejemplo, para usar la ABI de Tcl 8.6 en plataformas Unix, el nombre de la biblioteca es libtclstub8.6.a; en plataformas Windows, el nombre de la biblioteca es tclstub86.lib.

Si la extensión también requiere la API de Tk, también debe llamar a Tk_InitStubs para inicializar la interfaz de "stubs" de Tk y enlazar con las bibliotecas de "stubs" de Tk. Consulte la página de Tk_InitStubs para obtener más información.

DESCRIPCIÓN

Tcl_InitStubs intenta inicializar los punteros de la tabla de "stubs" y asegurarse de que se carga la versión correcta de Tcl. Además de un identificador de intérprete, acepta como argumentos un número de versión y una bandera booleana que indica si la extensión requiere una coincidencia exacta de versión o no. Si exact es 0, la extensión indica que las versiones más nuevas de Tcl son aceptables siempre que tengan el mismo número de versión principal que version; un valor distinto de cero significa que solo se acepta la version especificada. Tcl_InitStubs devuelve una cadena que contiene la versión real de Tcl que cumple con la solicitud, o NULL si la versión de Tcl no es aceptable, no admite "stubs" o se produjo alguna otra condición de error.
