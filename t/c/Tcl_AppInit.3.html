Tcl_AppInit(3) Procedimientos de la biblioteca Tcl Tcl_AppInit(3)

NOMBRE

Tcl_AppInit - realiza la inicialización específica de la aplicación

SINOPSIS

#include <tcl.h>

int
Tcl_AppInit(interp)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete para la aplicación.

DESCRIPCIÓN

Tcl_AppInit es un procedimiento de "gancho" que es invocado por los programas principales de las aplicaciones Tcl, como tclsh y wish. Su propósito es permitir la creación de nuevas aplicaciones Tcl sin modificar los programas principales proporcionados como parte de Tcl y Tk. Para crear una nueva aplicación, escribe una nueva versión de Tcl_AppInit para reemplazar la versión predeterminada proporcionada por Tcl, y luego enlaza tu nuevo Tcl_AppInit con la biblioteca Tcl.

Tcl_AppInit es invocado por Tcl_Main y Tk_Main después de su propia inicialización y antes de entrar en el bucle principal para procesar comandos. Aquí hay algunos ejemplos de cosas que Tcl_AppInit podría hacer:

[1]
Llamar a procedimientos de inicialización para varios paquetes utilizados por la aplicación. Cada procedimiento de inicialización agrega nuevos comandos a interp para su paquete y realiza otra inicialización específica del paquete.
[2]
Procesar argumentos de línea de comandos, a los cuales se puede acceder desde las variables Tcl argv y argv0 en interp.
[3]
Invocar un script de inicio para inicializar la aplicación.
[4]
Usar las rutinas Tcl_SetStartupScript y Tcl_GetStartupScript para establecer o consultar el archivo y la codificación que la rutina activa Tcl_Main o Tk_Main usará como script de inicio.

Tcl_AppInit devuelve TCL_OK o TCL_ERROR. Si devuelve TCL_ERROR, debe dejar un mensaje de error en el resultado del intérprete; de lo contrario, el resultado se ignora.

Además de Tcl_AppInit, tu aplicación también debe contener un procedimiento main que llame a Tcl_Main de la siguiente manera:

Tcl_Main(argc, argv, Tcl_AppInit);

El tercer argumento a Tcl_Main da la dirección del procedimiento de inicialización específico de la aplicación a invocar. Esto significa que no tienes que usar el nombre Tcl_AppInit para el procedimiento, pero en la práctica el nombre es casi siempre Tcl_AppInit (en versiones anteriores a Tcl 7.4, el nombre Tcl_AppInit era implícito; no había forma de especificar explícitamente el procedimiento). La mejor manera de empezar es hacer una copia del archivo tclAppInit.c de la biblioteca Tcl o del directorio fuente. Ya contiene un procedimiento main y una plantilla para Tcl_AppInit que puedes modificar para tu aplicación.
