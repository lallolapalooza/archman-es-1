Tcl_ListObj(3) Procedimientos de la biblioteca Tcl Tcl_ListObj(3)

NOMBRE

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipular valores Tcl como listas

SINOPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de lista, se deja un mensaje de error en el valor de resultado del intérprete a menos que interp sea NULL.
Tcl_Obj *listPtr (entrada/salida)
Punta al valor de lista que se va a manipular. Si listPtr no apunta ya a un valor de lista, se intentará convertirlo.
Tcl_Obj *elemListPtr (entrada/salida)
Para Tcl_ListObjAppendList, esto apunta a un valor de lista que contiene elementos para añadir a listPtr. Cada elemento de *elemListPtr se convertirá en un nuevo elemento de listPtr. Si *elemListPtr no es NULL y no apunta ya a un valor de lista, se intentará convertirlo. Si ocurre un error durante la conversión, ambos procedimientos devuelven TCL_ERROR y dejan un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió en un valor de lista, liberan cualquier representación interna antigua. Del mismo modo, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si lo convierte en un valor de lista. Después de añadir cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento ya que listPtr ahora también se refiere a él. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no ocurre ningún error, los dos procedimientos devuelven TCL_OK después de añadir los valores.
Tcl_Obj *objPtr (entrada)
Para Tcl_ListObjAppendElement, apunta al valor Tcl que se añadirá a listPtr. Para Tcl_SetListObj, apunta al valor Tcl que se convertirá en un valor de lista que contiene los objc elementos del array referenciado por objv.
int *objcPtr (entrada)
Punta a la ubicación donde Tcl_ListObjGetElements almacena el número de valores de elementos en listPtr.
Tcl_Obj ***objvPtr (salida)
Una ubicación donde Tcl_ListObjGetElements almacena un puntero a un array de punteros a los valores de los elementos de listPtr.
int objc (entrada)
El número de valores Tcl que Tcl_NewListObj insertará en un nuevo valor de lista, y Tcl_ListObjReplace insertará en listPtr. Para Tcl_SetListObj, el número de valores Tcl a insertar en objPtr.
Tcl_Obj *const objv[] (entrada)
Un array de punteros a valores. Tcl_NewListObj insertará estos valores en un nuevo valor de lista y Tcl_ListObjReplace los insertará en un listPtr existente. Cada valor se convertirá en un elemento de lista separado.
int *lengthPtr (salida)
Punta a la ubicación donde Tcl_ListObjLength almacena la longitud de la lista.
int index (entrada)
Índice del elemento de lista que Tcl_ListObjIndex debe devolver. El primer elemento tiene índice 0.
Tcl_Obj **objPtrPtr (salida)
Punta al lugar donde Tcl_ListObjIndex debe almacenar un puntero al valor del elemento de lista resultante.
int first (entrada)
Índice del elemento de lista inicial que Tcl_ListObjReplace debe reemplazar. El primer elemento de la lista tiene índice 0.
int count (entrada)
El número de elementos que Tcl_ListObjReplace debe reemplazar.

DESCRIPCIÓN

Los valores de lista de Tcl tienen una representación interna que admite la indexación y la adición eficientes. Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar y añadir a valores de lista de Tcl desde código C.

Tcl_ListObjAppendList y Tcl_ListObjAppendElement añaden uno o más valores al final del valor de lista al que se refiere listPtr. Tcl_ListObjAppendList añade cada elemento del valor de lista al que se refiere elemListPtr, mientras que Tcl_ListObjAppendElement añade el único valor al que se refiere objPtr. Ambos procedimientos intentarán convertir el valor al que se refiere listPtr en un valor de lista si es necesario. Si se produce un error durante la conversión, ambos procedimientos devuelven TCL_ERROR y dejan un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Del mismo modo, si elemListPtr no se refiere ya a un valor de lista, Tcl_ListObjAppendList intentará convertirlo y, si se produce un error durante la conversión, devolverá TCL_ERROR y dejará un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió en un valor de lista, liberan cualquier representación interna antigua. Del mismo modo, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si lo convierte en un valor de lista. Después de añadir cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento, ya que listPtr ahora también se refiere a él. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no se produce ningún error, los dos procedimientos devuelven TCL_OK después de añadir los valores.

Tcl_NewListObj y Tcl_SetListObj crean un nuevo valor o modifican un valor existente para contener los objc elementos del array referenciado por objv, donde cada elemento es un puntero a un valor Tcl. Si objc es menor o igual a cero, devuelven un valor vacío. Si objv es NULL, la lista resultante contiene 0 elementos, con espacio reservado en una representación interna para objc elementos más (para evitar su reasignación posterior). La representación de cadena del nuevo valor se deja inválida. Los dos procedimientos incrementan los contadores de referencias de los elementos en objc ya que el valor de la lista ahora se refiere a ellos. El nuevo valor de lista devuelto por Tcl_NewListObj tiene un contador de referencias cero.

Tcl_ListObjGetElements devuelve un recuento y un puntero a un array de los elementos de un valor de lista. Devuelve el recuento almacenándolo en la dirección objcPtr. Del mismo modo, devuelve el puntero al array almacenándolo en la dirección objvPtr. La memoria apuntada es gestionada por Tcl y no debe ser liberada ni escrita por el llamador. Si la lista está vacía, se almacena 0 en objcPtr y NULL en objvPtr. Si listPtr no es ya un valor de lista, Tcl_ListObjGetElements intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar el recuento y el puntero al array.

Tcl_ListObjLength devuelve el número de elementos del valor de lista al que se refiere listPtr. Devuelve este recuento almacenando un entero en la dirección lengthPtr. Si el valor no es ya un valor de lista, Tcl_ListObjLength intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar la longitud de la lista.

El procedimiento Tcl_ListObjIndex devuelve un puntero al valor en el elemento index de la lista referenciada por listPtr. Devuelve este valor almacenando un puntero a él en la dirección objPtrPtr. Si listPtr no se refiere ya a un valor de lista, Tcl_ListObjIndex intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Si el índice está fuera de rango, es decir, index es negativo o mayor o igual que el número de elementos de la lista, Tcl_ListObjIndex almacena un NULL en objPtrPtr y devuelve TCL_OK. De lo contrario, devuelve TCL_OK después de almacenar el puntero al valor del elemento. El contador de referencias del elemento de lista no se incrementa; el llamador debe hacerlo si necesita conservar un puntero al elemento.

Tcl_ListObjReplace reemplaza cero o más elementos de la lista referenciada por listPtr con los objc valores del array referenciado por objv. Si listPtr no apunta a un valor de lista, Tcl_ListObjReplace intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de reemplazar los valores. Si objv es NULL, no se añaden nuevos elementos. Si el argumento first es cero o negativo, se refiere al primer elemento. Si el valor de count es cero o negativo, no se elimina ningún elemento; los nuevos elementos se insertan simplemente antes del elemento designado por first. Las cuentas de referencia de los elementos insertados desde objv se incrementan, ya que la lista resultante ahora se refiere a ellos. De manera similar, las cuentas de referencia de los valores reemplazados se decrementan.

Dado que Tcl_ListObjReplace combina la inserción y eliminación de elementos, puede utilizarse para implementar una serie de operaciones de lista. Por ejemplo, el siguiente código inserta los valores objc referenciados por el array de punteros de valor objv justo antes del elemento index de la lista referenciada por listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

De manera similar, el siguiente código añade los valores objc referenciados por el array objv al final de la lista listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

Los count elementos de la lista a partir de first pueden eliminarse simplemente llamando a Tcl_ListObjReplace con un objvPtr NULL:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
