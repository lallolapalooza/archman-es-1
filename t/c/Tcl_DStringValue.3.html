NOMBRE

Tcl_DStringInit, Tcl_DStringAppend, Tcl_DStringAppendElement, Tcl_DStringStartSublist, Tcl_DStringEndSublist, Tcl_DStringLength, Tcl_DStringValue, Tcl_DStringSetLength, Tcl_DStringTrunc, Tcl_DStringFree, Tcl_DStringResult, Tcl_DStringGetResult - manipular cadenas dinámicas

SINOPSIS

#include <tcl.h>

int
Tcl_DStringLength(dsPtr)

char *

Tcl_DStringGetResult(interp, dsPtr)

ARGUMENTOS

Tcl_DString *dsPtr (entrada/salida)
Puntero a la estructura que se utiliza para gestionar una cadena dinámica.
const char *bytes (entrada)
Puntero a los caracteres que se añadirán a la cadena dinámica.
const char *element (entrada)
Puntero a los caracteres que se añadirán como elemento de lista a la cadena dinámica.
int length (entrada)
Número de bytes de bytes a añadir a la cadena dinámica. Si es -1, se añaden todos los caracteres hasta el carácter de terminación nulo.
int newLength (entrada)
Nueva longitud para la cadena dinámica, sin incluir el carácter de terminación nulo.
Tcl_Interp *interp (entrada/salida)
Intérprete cuyo resultado se establecerá desde o se moverá a la cadena dinámica.

DESCRIPCIÓN

Las cadenas dinámicas proporcionan un mecanismo para construir cadenas arbitrariamente largas añadiendo información gradualmente. Si la cadena dinámica es corta, no habrá sobrecarga de asignación de memoria; a medida que la cadena crece, se asignará espacio adicional según sea necesario.

Tcl_DStringInit inicializa una cadena dinámica a longitud cero. La estructura Tcl_DString debe haber sido asignada por el llamador. No se hacen suposiciones sobre el estado actual de la estructura; cualquier cosa que ya contenga se descarta. Si la estructura se ha utilizado previamente, se debe llamar primero a Tcl_DStringFree para liberar cualquier memoria asignada para la cadena antigua.

Tcl_DStringAppend añade nueva información a una cadena dinámica, asignando más memoria para la cadena si es necesario. Si length es menor que cero, se añade todo en bytes a la cadena dinámica; de lo contrario, length especifica el número de bytes a añadir. Tcl_DStringAppend devuelve un puntero a los caracteres de la nueva cadena. La cadena también se puede recuperar del campo string de la estructura Tcl_DString.

Tcl_DStringAppendElement es similar a Tcl_DStringAppend excepto que no toma un argumento length (añade todo element) y convierte la cadena en un elemento de lista adecuado antes de añadirla. Tcl_DStringAppendElement añade un espacio separador antes del nuevo elemento de lista, a menos que el nuevo elemento de lista sea el primero en una lista o sublista (es decir, o bien la cadena actual está vacía, o contiene el único carácter '{', o los dos últimos caracteres de la cadena actual son ' {'). Tcl_DStringAppendElement devuelve un puntero a los caracteres de la nueva cadena.

Tcl_DStringStartSublist y Tcl_DStringEndSublist pueden utilizarse para crear listas anidadas. Para añadir un elemento de lista que sea en sí mismo una sublista, llame primero a Tcl_DStringStartSublist, luego llame a Tcl_DStringAppendElement para cada uno de los elementos de la sublista, y finalmente llame a Tcl_DStringEndSublist para finalizar la sublista. Tcl_DStringStartSublist añade un carácter de espacio si es necesario, seguido de una llave de apertura; Tcl_DStringEndSublist añade una llave de cierre. Las listas pueden anidarse a cualquier profundidad.

Tcl_DStringLength es una macro que devuelve la longitud actual de una cadena dinámica (sin incluir el carácter nulo de terminación). Tcl_DStringValue es una macro que devuelve un puntero al contenido actual de una cadena dinámica.

Tcl_DStringSetLength cambia la longitud de una cadena dinámica. Si newLength es menor que la longitud actual de la cadena, la cadena se trunca. Si newLength es mayor que la longitud actual de la cadena, la cadena se hará más larga y se asignará nuevo espacio para ella si es necesario. Sin embargo, Tcl_DStringSetLength no inicializará el nuevo espacio excepto para proporcionar un carácter nulo de terminación; depende del llamador llenar el nuevo espacio. Tcl_DStringSetLength no libera el espacio de almacenamiento de la cadena, incluso si la cadena se trunca a longitud cero, por lo que aún será necesario llamar a Tcl_DStringFree.

Tcl_DStringTrunc cambia la longitud de una cadena dinámica. Este procedimiento ahora está obsoleto. En su lugar, se debe utilizar Tcl_DStringSetLength.

Se debe llamar a Tcl_DStringFree cuando haya terminado de usar la cadena. Libera cualquier memoria que se haya asignado para la cadena y reinicializa el valor de la cadena a una cadena vacía.

Tcl_DStringResult establece el resultado de interp al valor de la cadena dinámica dada por dsPtr. Lo hace moviendo un puntero de dsPtr al resultado del intérprete. Esto ahorra el costo de asignar nueva memoria y copiar la cadena. Tcl_DStringResult también reinicializa la cadena dinámica a una cadena vacía.

Tcl_DStringGetResult hace lo contrario de Tcl_DStringResult. Establece el valor de dsPtr al resultado de interp y borra el resultado de interp. Si es posible, lo hace moviendo un puntero en lugar de copiar la cadena.
