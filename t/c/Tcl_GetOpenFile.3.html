Tcl_GetOpenFile(3) Procedimientos de la biblioteca Tcl Tcl_GetOpenFile(3)

NOMBRE

Tcl_GetOpenFile - Devuelve un FILE* para un canal registrado en el intérprete dado (solo Unix)

SINOPSIS

#include <tcl.h>

int
Tcl_GetOpenFile(interp, chanID, write, checkUsage, filePtr)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete de Tcl del cual se obtendrá el manejador de archivo.
const char *chanID (entrada)
Identificador de cadena del canal, como stdin o file4.
int write (entrada)
Distinto de cero significa que el archivo se usará para escribir, cero significa que se usará para leer.
int checkUsage (entrada)
Si es distinto de cero, se generará un error si el archivo no se abrió para el acceso indicado por write.
ClientData *filePtr (salida)
Puntero a la palabra en la que se almacenará el puntero a la estructura FILE para el archivo dado por chanID.

DESCRIPCIÓN

Tcl_GetOpenFile toma como argumento un identificador de archivo del tipo devuelto por el comando open y devuelve en *filePtr un puntero a la estructura FILE para el archivo. El argumento write indica si el puntero FILE se usará para leer o escribir. En algunos casos, como un canal que se conecta a una tubería de subprocesos, se devolverán punteros FILE diferentes para leer y escribir. Tcl_GetOpenFile normalmente devuelve TCL_OK. Si ocurre un error en Tcl_GetOpenFile (por ejemplo, chanID no tenía sentido o checkUsage estaba configurado y el archivo no se abrió para el acceso especificado por write), entonces se devuelve TCL_ERROR y el resultado del intérprete contendrá un mensaje de error. En la implementación actual, se ignora checkUsage y siempre se realizan comprobaciones de coherencia.

Tenga en cuenta que esta interfaz solo se admite en la plataforma Unix.

PALABRAS CLAVE

canal, manejador de archivo, permisos, tubería, leer, escribir
