Tcl_GetInt(3)

Paquete: tcl

Licencias: TCL

Tcl_GetInt(3) Procedimientos de la biblioteca Tcl Tcl_GetInt(3)

NOMBRE

Tcl_GetInt, Tcl_GetDouble, Tcl_GetBoolean - convertir de cadena a entero, doble o booleano

SINOPSIS

#include <tcl.h>

int
Tcl_GetInt(interp, src, intPtr)

int
Tcl_GetDouble(interp, src, doublePtr)

int
Tcl_GetBoolean(interp, src, intPtr)

ARGUMENTOS

Tcl_Interp *interp (in)
Intérprete a usar para la notificación de errores.
const char *src (in)
Valor textual a convertir.
int *intPtr (out)
Puntero al lugar donde almacenar el valor entero convertido desde src.
double *doublePtr (out)
Puntero al lugar donde almacenar el valor de punto flotante de doble precisión convertido desde src.

DESCRIPCIÓN

Estos procedimientos convierten de cadenas a enteros o valores de punto flotante de doble precisión o booleanos (representados como enteros con valor 0 o 1). Cada uno de los procedimientos toma un argumento src, lo convierte a una forma interna de un tipo particular y almacena el valor convertido en la ubicación indicada por el tercer argumento del procedimiento. Si todo va bien, cada uno de los procedimientos devuelve TCL_OK. Si src no tiene la sintaxis adecuada para el tipo deseado, se devuelve TCL_ERROR, se deja un mensaje de error en el resultado del intérprete y no se almacena nada en *intPtr o *doublePtr.

Tcl_GetInt espera que src consista en una colección de dígitos enteros, opcionalmente con signo y opcionalmente precedidos y seguidos por espacios en blanco. Si los dos primeros caracteres de src después de los espacios en blanco y el signo opcionales son “0x”, entonces se espera que src esté en formato hexadecimal; de lo contrario, si los primeros caracteres de este tipo son “0o”, entonces se espera que src esté en formato octal; de lo contrario, si los primeros caracteres de este tipo son “0b”, entonces se espera que src esté en formato binario; de lo contrario, si el primer carácter de este tipo es “0”, entonces se espera que src esté en formato octal; de lo contrario, se espera que src esté en formato decimal.

Tcl_GetDouble espera que src consista en un número de punto flotante, que es: espacios en blanco; un signo; una secuencia de dígitos; un punto decimal “.”; una secuencia de dígitos; la letra “e”; un exponente decimal con signo; y más espacios en blanco. Cualquiera de los campos puede omitirse, excepto que los dígitos antes o después del punto decimal deben estar presentes y si la “e” está presente, debe ir seguida del número del exponente. Si no hay campos aparte del signo y la secuencia inicial de dígitos (es decir, sin punto decimal o indicador de exponente), esa secuencia inicial de dígitos debe tomar una de las formas que admite Tcl_GetInt, descritas anteriormente. El uso de “,” como punto decimal no está admitido ni debe haber ningún otro separador de inter-dígitos presente.

Tcl_GetBoolean espera que src especifique un valor booleano. Si src es alguno de 0, false, no o off, entonces Tcl_GetBoolean almacena un valor cero en *intPtr. Si src es alguno de 1, true, yes o on, entonces se almacena 1 en *intPtr. Cualquiera de estos valores puede abreviarse, y las grafías en mayúsculas también son aceptables.
