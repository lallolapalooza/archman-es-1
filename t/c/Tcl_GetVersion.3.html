Tcl_GetVersion(3) Procedimientos de biblioteca Tcl Tcl_GetVersion(3)

NOMBRE

Tcl_GetVersion - obtener la versión de la biblioteca en tiempo de ejecución

SINOPSIS

#include <tcl.h>

Tcl_GetVersion(major, minor, patchLevel, type)

ARGUMENTOS

int *major (salida)
Número de versión principal de la biblioteca Tcl.
int *minor (salida)
Número de versión menor de la biblioteca Tcl.
int *patchLevel (salida)
El nivel de parche de la biblioteca Tcl (o número alfa o beta).
Tcl_ReleaseType *type (salida)
El tipo de lanzamiento, también indica el tipo de nivel de parche. Puede ser uno de TCL_ALPHA_RELEASE, TCL_BETA_RELEASE, o TCL_FINAL_RELEASE.

DESCRIPCIÓN

Se debe usar Tcl_GetVersion para consultar el número de versión de la biblioteca Tcl en tiempo de ejecución. Esto es útil al usar una biblioteca Tcl cargada dinámicamente o al escribir una extensión compatible con stubs. Por ejemplo, si escribe una extensión que está vinculada contra la biblioteca de stubs de Tcl, podría cargarse en un programa vinculado a una versión de Tcl más antigua de lo esperado. Use Tcl_GetVersion para verificar este hecho y, posiblemente, para cambiar el comportamiento de su extensión.

Tcl_GetVersion acepta NULL para cualquiera de los argumentos. Por ejemplo, si no le importa el patchLevel de la biblioteca, pase un NULL para el argumento patchLevel.

PALABRAS CLAVE
