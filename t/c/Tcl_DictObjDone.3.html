ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de diccionario, se deja un mensaje de error en el valor de resultado del intérprete, a menos que interp sea NULL.
Tcl_Obj *dictPtr (entrada/salida)
Punta al valor de diccionario que se manipulará. Si dictPtr aún no apunta a un valor de diccionario, se intentará convertirlo en uno.
Tcl_Obj *keyPtr (entrada)
Punta a la clave para el par clave/valor que se está manipulando dentro del valor del diccionario.
Tcl_Obj **keyPtrPtr (salida)
Punta a una variable a la que se colocará la clave de un par clave/valor. Puede ser NULL para indicar que el llamador no está interesado en la clave.
Tcl_Obj *valuePtr (entrada)
Punta al valor para el par clave/valor que se está manipulando dentro del valor del diccionario (o subvalor, en el caso de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (salida)
Punta a una variable a la que se colocará el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, esto puede ser NULL para indicar que el llamador no está interesado en el valor.
int *sizePtr (salida)
Punta a una variable a la que se colocará el número de pares clave/valor contenidos en el diccionario.
Tcl_DictSearch *searchPtr (entrada/salida)
Puntero a un registro que se utilizará para seguir el progreso en la enumeración de todos los pares clave/valor en un diccionario. El contenido del registro será inicializado por la llamada a Tcl_DictObjFirst. Si la enumeración debe terminar antes de que se devuelvan todos los valores del diccionario, el registro de búsqueda *debe* pasarse a Tcl_DictObjDone para permitir la liberación de los bloqueos internos.
int *donePtr (salida)
Punta a una variable a la que se escribirá un valor distinto de cero cuando se complete la enumeración de los pares clave/valor en un diccionario, y un cero en caso contrario.
int keyc (entrada)
Indica el número de claves que se proporcionarán en la matriz keyv.
Tcl_Obj *const *keyv (entrada)
Matriz de keyc punteros a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList utilizarán para localizar el par clave/valor a manipular dentro de los subdiccionarios del valor de diccionario principal que se les pasa.

DESCRIPCIÓN

Los valores de diccionario de Tcl tienen una representación interna que admite un mapeo eficiente de claves a valores y que garantiza que el orden particular de las claves dentro del diccionario permanece el mismo módulo de cualquier clave que se elimine (lo que las elimina del orden) o se agregue (lo que las agrega al final del orden). Si se reinterpretan como una lista, los valores en los índices de valor par en la lista serán las claves del diccionario, y cada uno será seguido (en el índice de valor impar) por el valor asociado con esa clave.

Los procedimientos descritos en esta página del manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde código C.

Tcl_NewDictObj crea un valor de diccionario nuevo y vacío. La representación de cadena del valor será inválida y el contador de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario dado y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o un NULL si la clave no tiene mapeo dentro del diccionario. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no se puede convertir a un diccionario.

Tcl_DictObjPut actualiza el diccionario dado para que la clave dada se mapee al valor dado; cualquier clave puede existir como máximo una vez en cualquier diccionario particular. El diccionario no debe ser compartido, pero la clave y el valor sí pueden serlo. Este procedimiento puede aumentar el contador de referencias tanto de la clave como del valor si se demuestra que es necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no se puede convertir a un diccionario.

Tcl_DictObjRemove actualiza el diccionario dado para que la clave dada no tenga mapeo a ningún valor. El diccionario no debe ser compartido, pero la clave sí puede serlo. La clave realmente almacenada en el diccionario tendrá su contador de referencias decrementado si estaba presente. No es un error si la clave no existía previamente. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no se puede convertir a un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario dado. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no se puede convertir a un diccionario.

Tcl_DictObjFirst inicia una iteración sobre todos los pares clave/valor en el diccionario dado, colocando la clave y el valor en las variables apuntadas por los argumentos keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que el llamador no está interesado en la clave o el valor respectivamente.) El siguiente par clave/valor en el diccionario se puede recuperar con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modificarán el procesamiento de la iteración, a menos que el diccionario no esté compartido, en cuyo caso esto provocará una terminación prematura de la iteración en su lugar (que los scripts de Tcl no pueden activar a través del comando dict.) El argumento searchPtr apunta a una pieza de contexto que se utiliza para identificar qué iteración particular se está realizando y se inicializa con la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero si hay más pares clave/valor para iterar, o a un valor distinto de cero si la iteración se completa. El orden de iteración no está definido por la implementación. Si el argumento dictPtr no se puede convertir a un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y en caso contrario devuelve TCL_OK.

Cuando se llama a Tcl_DictObjFirst en un diccionario, se coloca un bloqueo en el diccionario para permitir que ese diccionario se itere de forma segura sin tener en cuenta si el diccionario se modifica durante la iteración. Debido a esto, una vez que la iteración sobre las claves de un diccionario ha finalizado (ya sea porque se han iterado todos los valores, como lo indica la variable indicada por el argumento donePtr que se establece en uno, o porque no se requieren más valores), la función Tcl_DictObjDone debe llamarse con el mismo searchPtr que se pasó a Tcl_DictObjFirst para que los bloqueos internos puedan ser liberados. Una vez que un searchPtr particular se pasa a Tcl_DictObjDone, pasarlo a Tcl_DictObjNext (sin inicializarlo primero con Tcl_DictObjFirst) dará como resultado que no se produzcan valores y que la variable apuntada por donePtr se establezca en uno. Es seguro llamar a Tcl_DictObjDone varias veces en el mismo searchPtr por cada llamada a Tcl_DictObjFirst.

Los procedimientos Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son análogos cercanos a Tcl_DictObjPut y Tcl_DictObjRemove respectivamente, excepto que en lugar de trabajar con un solo diccionario, están diseñados para operar en un árbol anidado de diccionarios, con diccionarios internos almacenados como valores dentro de diccionarios externos. Los argumentos keyc y keyv especifican una lista de claves (con las claves más externas primero) que actúa como ruta al par clave/valor a afectar. Tcl_DictObjDone

NAME

Tcl_DictObjDone – finish iterating over a dictionary

SYNOPSIS

#include <tcl.h>

void
Tcl_DictObjDone(
    Tcl_DictSearch *searchPtr
);

ARGUMENTS

“searchPtr”–
A pointer to the dictionary search structure initialized by Tcl_DictObjFirst.

DESCRIPTION

The Tcl_DictObjDone function should be called when iteration over a dictionary has finished. This function releases the internal lock on the dictionary that was set by Tcl_DictObjFirst. It is safe to call Tcl_DictObjDone even if the loop terminated prematurely due to an error or a `break` statement.

Failure to call Tcl_DictObjDone will result in a memory leak or incorrect behavior if the dictionary is modified after the loop.

This function is part of the dictionary iteration interface, which allows iterating over the key-value pairs of a dictionary.

Other functions in this interface include:

  • Tcl_DictObjFirst: Starts an iteration over the dictionary.
  • Tcl_DictObjNext: Advances the iteration to the next key-value pair.
  • Tcl_DictObjNextDict: A convenience function for iterating over nested dictionaries.

This interface is particularly useful for scenarios where you need to process all entries in a dictionary, such as searching for a specific value or transforming the dictionary's contents. Constructing a path into a dictionary (e.g., accessing nested dictionary elements) can be easily done using repeated calls to Tcl_DictObjGet. However, for creating nested dictionaries, Tcl_DictObjPutKeyList is more suitable, as it creates non-terminal keys as dictionaries if they don't already exist. Conversely, Tcl_DictObjRemoveKeyList requires that all non-terminal keys exist and have dictionaries as their values.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters.  This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used.  The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
