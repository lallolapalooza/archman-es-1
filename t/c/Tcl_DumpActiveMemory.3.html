Tcl_DumpActiveMemory(3)

Paquete: tcl

Licencias: TCL

Tcl_DumpActiveMemory(3) Procedimientos de la biblioteca Tcl Tcl_DumpActiveMemory(3)

NOMBRE

Tcl_DumpActiveMemory, Tcl_InitMemory, Tcl_ValidateAllMemory - Interfaz de asignación de memoria validada

SINOPSIS

#include <tcl.h>

int
Tcl_DumpActiveMemory(fileName)

void
Tcl_InitMemory(interp)

void
Tcl_ValidateAllMemory(fileName, line)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete de Tcl en el que agregar comandos.
const char *fileName (entrada)
Para Tcl_DumpActiveMemory, nombre del archivo al que se escribirá la información de memoria. Para Tcl_ValidateAllMemory, nombre del archivo desde el que se realiza la llamada (normalmente __FILE__).
int line (entrada)
Número de línea en el que se realiza la llamada a Tcl_ValidateAllMemory (normalmente __LINE__).

DESCRIPCION

Estas funciones proporcionan acceso a la información de depuración de memoria de Tcl. Solo son funcionales cuando Tcl se ha compilado con TCL_MEM_DEBUG definido en tiempo de compilación. Cuando TCL_MEM_DEBUG no está definido, estas funciones no hacen nada.

Tcl_DumpActiveMemory generará una lista de toda la memoria actualmente asignada en el archivo especificado. La información generada para cada bloque de memoria asignada es: direcciones de inicio y fin (excluyendo la zona de guardia), tamaño, archivo de origen donde se llamó a ckalloc para asignar el bloque y el número de línea en ese archivo. Es especialmente útil llamar a Tcl_DumpActiveMemory después de que se haya eliminado el intérprete de Tcl.

Tcl_InitMemory agrega el comando memory de Tcl al intérprete proporcionado por interp. Tcl_InitMemory es llamado por Tcl_Main.

Tcl_ValidateAllMemory fuerza una validación de las zonas de guardia de todos los bloques de memoria asignados actualmente. Normalmente, la validación de un bloque ocurre cuando se libera, a menos que la validación completa esté habilitada, en cuyo caso la validación de todos los bloques ocurre cuando se llaman ckalloc y ckfree. Esta función fuerza que la validación ocurra en cualquier momento.

VER TAMBIÉN

TCL_MEM_DEBUG, memory
