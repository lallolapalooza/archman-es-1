Tcl_SplitList(3)

Tcl_SplitList(3) Procedimientos de la biblioteca Tcl Tcl_SplitList(3)

NOMBRE

Tcl_SplitList, Tcl_Merge, Tcl_ScanElement, Tcl_ConvertElement, Tcl_ScanCountedElement, Tcl_ConvertCountedElement - manipular listas Tcl

SINOPSIS

#include <tcl.h>

int
Tcl_SplitList(interp, list, argcPtr, argvPtr)

char *
Tcl_Merge(argc, argv)

int
Tcl_ScanElement(src, flagsPtr)

int
Tcl_ScanCountedElement(src, length, flagsPtr)

int
Tcl_ConvertElement(src, dst, flags)

int
Tcl_ConvertCountedElement(src, length, dst, flags)

ARGUMENTOS

Tcl_Interp *interp (salida)
Intérprete a utilizar para la generación de informes de error. Si es NULL, no se deja ningún mensaje de error.
const char *list (entrada)
Puntero a una cadena con la estructura de lista correcta.
int *argcPtr (salida)
Se rellena con el número de elementos en list.
const char ***argvPtr (salida)
*argvPtr se rellenará con la dirección de una matriz de punteros a las cadenas que son los elementos extraídos de list. Habrá *argcPtr entradas válidas en la matriz, seguidas de una entrada NULL.
int argc (entrada)
Número de elementos en argv.
const char *const *argv (entrada)
Matriz de cadenas para fusionar en una sola lista. Cada cadena se convertirá en un elemento separado de la lista.
const char *src (entrada)
Cadena que se convertirá en un elemento de una lista.
int *flagsPtr (entrada)
Puntero a una palabra para rellenar con información sobre src. El valor de *flagsPtr debe pasarse a Tcl_ConvertElement.
int length (entrada)
Número de bytes en la cadena src.
char *dst (entrada)
Lugar para copiar el elemento de lista convertido. Debe contener suficientes caracteres para alojar la cadena convertida.
int flags (entrada)
Información sobre src. Debe ser el valor devuelto por una llamada anterior a Tcl_ScanElement, posiblemente combinado con OR con TCL_DONT_USE_BRACES.

DESCRIPCIÓN

Estos procedimientos se pueden utilizar para desmontar y volver a ensamblar listas de Tcl. Tcl_SplitList divide una lista en sus elementos constituyentes, devolviendo una matriz de punteros a los elementos utilizando argcPtr y argvPtr. Mientras extrae los argumentos, Tcl_SplitList obedece las reglas habituales para las sustituciones de barra invertida y las llaves. El área de memoria apuntada por *argvPtr se asigna dinámicamente; además de la matriz de punteros, también contiene copias de todos los elementos de la lista. Es responsabilidad del llamador liberar todo este almacenamiento. Por ejemplo, supongamos que ha llamado a Tcl_SplitList con el siguiente código:

int argc, code;
char *string;
char **argv;
...
code = Tcl_SplitList(interp, string, &argc, &argv);

Entonces debería liberar el almacenamiento eventualmente con una llamada como la siguiente:

Tcl_Free((char *) argv);

Tcl_SplitList normalmente devuelve TCL_OK, lo que significa que la lista se analizó correctamente. Si hubo un error de sintaxis en list, entonces se devuelve TCL_ERROR y el resultado del intérprete apuntará a un mensaje de error que describe el problema (si interp no era NULL). Si se devuelve TCL_ERROR, no se asigna memoria y *argvPtr no se modifica.

Tcl_Merge es el inverso de Tcl_SplitList: toma una colección de cadenas proporcionadas por argc y argv y genera una cadena de resultado que tiene una estructura de lista correcta. Esto significa que los comandos como index se pueden usar para extraer los elementos originales nuevamente. Además, si el resultado de Tcl_Merge se pasa a Tcl_Eval, se analizará en argc palabras cuyos valores serán los mismos que las cadenas argv pasadas a Tcl_Merge. Tcl_Merge modificará los elementos de la lista con llaves y/o barras invertidas para producir una estructura de lista Tcl correcta. La cadena de resultado se asigna dinámicamente usando Tcl_Alloc; el llamador debe liberar el espacio eventualmente usando Tcl_Free.

Si el resultado de Tcl_Merge se pasa a Tcl_SplitList, los elementos devueltos por Tcl_SplitList serán idénticos a los pasados a Tcl_Merge. Sin embargo, lo contrario no es cierto: si Tcl_SplitList recibe una cadena dada, y la argc y argv resultantes se pasan a Tcl_Merge, la cadena resultante puede no ser la misma que la cadena original pasada a Tcl_SplitList. Esto se debe a que Tcl_Merge puede usar barras invertidas y llaves de manera diferente a la cadena original.

Tcl_ScanElement y Tcl_ConvertElement son los procedimientos que realizan todo el trabajo real de Tcl_Merge. Tcl_ScanElement analiza su argumento src y determina cómo usar barras invertidas y llaves al convertirlo en un elemento de lista. Devuelve una sobreestimación del número de caracteres necesarios para representar src como un elemento de lista, y almacena información en *flagsPtr que es necesaria para Tcl_ConvertElement.

Tcl_ConvertElement es un procedimiento compañero de Tcl_ScanElement. Realiza el trabajo real de convertir una cadena en un elemento de lista. Su argumento flags debe ser el mismo que el valor devuelto por Tcl_ScanElement. Tcl_ConvertElement escribe un elemento de lista correcto en la memoria que comienza en *dst y devuelve un recuento del número total de caracteres escritos, que no será mayor que el resultado devuelto por Tcl_ScanElement. Tcl_ConvertElement solo escribe el elemento de lista real sin espacios iniciales o finales: corresponde al llamador incluir espacios entre elementos de lista adyacentes.

Tcl_ConvertElement utiliza uno de dos enfoques diferentes para manejar los caracteres especiales en src. Siempre que sea posible, maneja los caracteres especiales rodeando la cadena con llaves. Esto produce una salida de aspecto limpio, pero no se puede usar en algunas situaciones, como cuando src contiene llaves desequilibradas. En estas situaciones, Tcl_ConvertElement maneja los caracteres especiales generando secuencias de escape con barras invertidas. El llamador puede insistir en el segundo enfoque combinando con OR el valor de bandera devuelto por Tcl_ScanElement con TCL_DONT_USE_BRACES. Aunque esto producirá un resultado más feo, es útil en algunas situaciones especiales, como cuando Tcl_ConvertElement se utiliza para generar una parte de un argumento para un comando Tcl. En este caso, rodear src con llaves haría que el comando no se analizara correctamente.

Por defecto, Tcl_ConvertElement utilizará comillas en su salida para asegurarse de que el primer carácter de un elemento no sea el carácter de almohadilla (#). Esto es para asegurarse de que el primer elemento de cualquier lista pasada a eval no se analice incorrectamente como el inicio de un comentario. Cuando un elemento de lista no es el primer elemento de una lista, esta comilla no es necesaria. Cuando el llamador puede estar seguro de que el elemento no es el primer elemento de una lista, puede deshabilitar la comilla del carácter de almohadilla inicial combinando con OR el valor de bandera devuelto por Tcl_ScanElement con TCL_DONT_QUOTE_HASH.

Tcl_ScanCountedElement y Tcl_ConvertCountedElement son lo mismo que Tcl_ScanElement y Tcl_ConvertElement, excepto que la longitud de la cadena src la especifica el argumento length, y la cadena puede contener nulos incrustados.
