ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el que se debe crear o encontrar el conjunto. También donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener un NULL para el interp, pero todas las demás funciones no deben serlo.
const char *name (entrada)
El nombre del comando de conjunto que se creará.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres al que se enlazará el comando de conjunto, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto OR de bits de bandera que describen la configuración básica del conjunto. Actualmente, solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando de conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando de conjunto a buscar.
int flags (entrada)
Un conjunto OR de bits de bandera que controlan el comportamiento de Tcl_FindEnsemble. Actualmente, solo se admite TCL_LEAVE_ERR_MSG.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para probar como un comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la que escribir los bits de bandera del conjunto actual; actualmente, solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario para usar como mapeo de nombre de subcomando a lista de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el comando de conjunto en sí y el nombre del subcomando), o NULL si el diccionario de mapeo debe eliminarse.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la que escribir el diccionario de mapeo de conjunto actual.
Tcl_Obj *listObj (entrada)
Un valor de lista para usar para la lista de parámetros formales antes del subcomando, la lista definida de subcomandos en el diccionario o el prefijo de comando del manejador de subcomandos desconocido. Puede ser NULL si la lista de subcomandos o el manejador desconocido deben eliminarse.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la que escribir la lista actual de parámetros formales antes del subcomando, la lista definida de subcomandos o el prefijo del manejador desconocido actual.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la que escribir el identificador del espacio de nombres al que está enlazado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, enlazado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos Tcl. El primer argumento al comando de conjunto se interpreta siempre como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete para trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que enlazar el conjunto, y el conjunto predeterminado de banderas de conjunto. El resultado de la función es el token del comando para el conjunto, que puede usarse para configurar aún más el conjunto utilizando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token de ese comando puede obtenerse usando Tcl_FindEnsemble. Si el nombre de comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Un token de comando puede ser verificado para ver si se refiere a un conjunto usando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

banderas (lectura/escritura)
El conjunto de banderas para el conjunto, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX, que se establece cuando los prefijos no ambiguos de los subcomandos se permiten resolver a implementaciones, así como las coincidencias exactas. Las banderas pueden leerse y escribirse usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el comando de conjunto en sí y el nombre del subcomando), o NULL si cada subcomando debe mapearse al comando con el mismo nombre no calificado en el espacio de nombres enlazado del conjunto. Por defecto es NULL. Puede leerse y escribirse usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable incluso si no se comparte. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros antes del subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Puede leerse y escribirse usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable incluso si no se comparte.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto debe derivarse de las claves del diccionario de mapeo (ver arriba) o (si este también es NULL) del conjunto de comandos exportados por el espacio de nombres enlazado. Puede leerse y escribirse usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable incluso si no se comparte.
prefijo de comando del manejador de subcomandos desconocido (lectura/escritura)
Una lista de palabras para anteponer a cualquier subcomando cuando el subcomando es desconocido para el conjunto (según la regla actual de manejo de prefijos); consulte

las páginas de manual de Tcl para obtener más detalles.

Los valores de diccionario y lista devueltos por las funciones Tcl_Get... no deben ser modificados, ya que pueden ser compartidos entre interpretadores.

Las funciones Tcl_GetEnsemble... que devuelven un puntero a un valor de objeto (como Tcl_GetEnsembleMappingDict) devuelven TCL_OK y establecen el puntero de salida en un puntero a un objeto que contiene el valor solicitado en caso de éxito. Devuelven TCL_ERROR si el token dado no se refiere a un conjunto.

Las funciones Tcl_SetEnsemble... que toman un valor de objeto como entrada devuelven TCL_OK en caso de éxito y TCL_ERROR en caso de fallo (por ejemplo, si el token dado no se refiere a un conjunto).

Finalmente, Tcl_GetEnsembleNamespace busca el espacio de nombres en el que está enlazado el conjunto especificado por token y escribe un puntero a ese espacio de nombres en la ubicación de memoria a la que apunta namespacePtrPtr. Devuelve TCL_OK en caso de éxito, o TCL_ERROR si token no se refiere a un conjunto.

EJEMPLO

# Ensemble creation, property setting and lookup
set ns [lindex [namespace children ::] 0] ;# Get the global namespace
set token [Tcl_CreateEnsemble $interp "myensemble" $ns TCL_ENSEMBLE_PREFIX]
set mapping {add {my_add_cmd arg1 arg2}
             sub {my_sub_cmd arg1}}
Tcl_SetEnsembleMappingDict $interp $token $mapping
set params {arg1 arg2}
Tcl_SetEnsembleParameterList $interp $token $params
set subcommands {add sub delete}
Tcl_SetEnsembleSubcommandList $interp $token $subcommands

# ... later ...

set token2 [Tcl_FindEnsemble $interp "myensemble" 0]
if {$token == $token2} {
    puts "Found the ensemble!"
}
if {[Tcl_IsEnsemble $token]} {
    puts "It's an ensemble!"
}

DESCRIPCIÓN

El comando Tcl_CreateEnsemble crea un nuevo comando de ensemble y lo adjunta al intérprete interp con el nombre name. El nombre debe ser un nombre de comando válido. Si namespacePtr es NULL, el ensemble se crea en el namespace global. De lo contrario, se crea en el namespace contenido en namespacePtr. La mayoría de los ensembles se crean directamente en el namespace global. Cuando se crea un ensemble, normalmente también se le asocia un comando de Tcl existente que actúa como su implementación principal. Esto se hace a través del argumento cmdPtr. Este comando de Tcl se invoca cuando el ensemble se llama directamente. Tcl proporciona la capacidad de construir un ensemble de forma anidada, donde los subcomandos de un ensemble pueden ser ellos mismos ensembles. El argumento cdictPtr es un diccionario que mapea nombres de subcomandos a los comandos de Tcl que los implementan. Si cdictPtr es NULL, entonces no hay subcomandos disponibles que se puedan llamar directamente y el ensemble debe dirigir su entrada a un manejador de subcomandos desconocidos. El argumento slicPtr es una lista que contiene los nombres de los subcomandos disponibles para el ensemble. Si slicPtr es NULL, entonces el ensemble buscará subcomandos en el diccionario de mapeo. Si ambos cdictPtr y slicPtr son NULL, entonces el ensemble no tiene subcomandos y sólo se invoca el manejador de subcomandos desconocidos. El argumento handlerPtr es un manejador de subcomandos desconocidos, que se invoca cuando se llama a un subcomando que no está disponible en el diccionario de mapeo o en la lista de subcomandos. Si handlerPtr es NULL, el comportamiento predeterminado es generar un mensaje de error adecuado. El resultado de Tcl_CreateEnsemble es un token de comando para el nuevo ensemble. Este token se puede utilizar para manipular el ensemble más tarde. Los ensembles se pueden leer y escribir utilizando los comandos Tcl_GetEnsembleMappingDict, Tcl_SetEnsembleMappingDict, Tcl_GetEnsembleSubcommandList, Tcl_SetEnsembleSubcommandList, Tcl_GetEnsembleUnknownHandler y Tcl_SetEnsembleUnknownHandler.

El comando Tcl_CreateEnsembleForCommand crea un nuevo ensemble y lo asocia con un comando Tcl existente representado por cmdToken. Este comando existe para proporcionar un mecanismo para registrar un comando Tcl existente como un ensemble, lo que puede ser útil para reutilizar comandos Tcl existentes como parte de la funcionalidad de ensemble.

El comando Tcl_GetEnsembleFromToken devuelve el token de comando para el ensemble dado el nombre name. Esto es útil para obtener un token para un ensemble existente para que se pueda usar con otras funciones de API de ensemble.

El comando Tcl_DeleteEnsemble elimina el ensemble dado por ensembleToken del intérprete. Esto desregistra el comando del ensemble y libera cualquier recurso asociado con él.

El comando Tcl_PanicEnsemble se utiliza para generar una llamada de pánico de Tcl si el ensemble dado por ensembleToken no puede recuperarse de un error. Esto suele ocurrir cuando un componente interno crítico de Tcl falla y es necesario terminar el proceso para evitar un estado inconsistente.

Los siguientes comandos se utilizan para consultar y modificar las propiedades de un ensemble existente:

mapping dictionary namespace (lectura/escritura)
El diccionario de mapeo de subcomandos para el ensemble. Si es NULL, el ensemble utiliza la lista de subcomandos para determinar qué subcomandos están disponibles. Si ambos son NULL, se invoca el manejador de subcomandos desconocidos. Puede ser leído y escrito utilizando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de Tcl_GetEnsembleMappingDict es un código de resultado de Tcl (TCL_OK o TCL_ERROR si el token no se refiere a un ensemble) y la lista obtenida de Tcl_GetEnsembleMappingDict debe tratarse como inmutable.
subcommand list namespace (lectura/escritura)
La lista de subcomandos disponibles para el ensemble. Si es NULL, el ensemble utiliza el diccionario de mapeo para determinar qué subcomandos están disponibles. Si ambos son NULL, se invoca el manejador de subcomandos desconocidos. Puede ser leído y escrito utilizando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de Tcl_GetEnsembleSubcommandList es un código de resultado de Tcl (TCL_OK o TCL_ERROR si el token no se refiere a un ensemble) y la lista obtenida de Tcl_GetEnsembleSubcommandList debe tratarse como inmutable.
unknown handler namespace (lectura/escritura)
El manejador de subcomandos desconocidos para el ensemble. Si es NULL, el comportamiento predeterminado es generar un mensaje de error adecuado cuando se encuentra un subcomando desconocido. Puede ser leído y escrito utilizando Tcl_GetEnsembleUnknownHandler y Tcl_SetEnsembleUnknownHandler respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y la lista obtenida de Tcl_GetEnsembleUnknownHandler debe tratarse siempre como inmutable, incluso si no se comparte.
bound namespace (lectura)
El namespace al que está enlazado el ensemble; cuando se elimina el namespace, también lo hará el ensemble, y este namespace es también el namespace cuya lista de comandos exportados se utiliza si tanto el diccionario de mapeo como las propiedades de la lista de subcomandos son NULL. Puede ser leído utilizando Tcl_GetEnsembleNamespace, que devuelve un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble).
