Tcl_OOInitStubs(3) Funciones de la biblioteca TclOO Tcl_OOInitStubs(3)

NOMBRE

Tcl_OOInitStubs - inicializa el acceso a la biblioteca a la funcionalidad TclOO

SINOPSIS

#include <tclOO.h>

const char *
Tcl_OOInitStubs(interp)

ARGUMENTOS

Tcl_Interp *interp (entrada)
El intérprete de Tcl con el que se integra la interfaz C de TclOO y cuya interfaz C se va a utilizar.

DESCRIPCIÓN

Cuando una biblioteca de extensión va a utilizar la interfaz C expuesta por TclOO, debe usar Tcl_OOInitStubs para inicializar su acceso a esa interfaz desde su función *_Init (o *_SafeInit), pasando el interp que se pasó a esa rutina como contexto. Si el resultado de llamar a Tcl_OOInitStubs es NULL, la inicialización falló y se habrá dejado un mensaje de error en el resultado del intérprete. De lo contrario, la inicialización tuvo éxito y la API de TclOO puede usarse a partir de entonces; se devuelve la versión de la API de TclOO.

Al usar esta función, se debe definir el símbolo #define C USE_TCLOO_STUBS y vincular el código de su biblioteca contra la biblioteca de "stubs" de Tcl, o ese símbolo #define no debe definirse y su código de biblioteca debe vincularse directamente contra la biblioteca principal de Tcl.

NOTA DE COMPATIBILIDAD RETROACTIVA

Si se está vinculando contra el paquete de compatibilidad retroactiva Tcl 8.5 para TclOO, solo se admite la configuración habilitada para "stubs" y también se debe vincular contra la biblioteca independiente de "stubs" de TclOO; esa biblioteca es una parte integrada de la biblioteca principal de "stubs" de Tcl en Tcl 8.6.
