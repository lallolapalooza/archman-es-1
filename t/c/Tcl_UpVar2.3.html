Tcl_UpVar2(3)

Paquete: tcl

Licencias: TCL

Tcl_UpVar(3) Procedimientos de la biblioteca Tcl Tcl_UpVar(3)

NOMBRE

Tcl_UpVar, Tcl_UpVar2 - vincula una variable a otra

SINOPSIS

#include <tcl.h>

int
Tcl_UpVar(interp, frameName, sourceName, destName, flags)

int
Tcl_UpVar2(interp, frameName, name1, name2, destName, flags)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene las variables; también se utiliza para informar de errores.
const char *frameName (entrada)
Identifica el marco de pila que contiene la variable de origen. Puede tener cualquiera de las formas aceptadas por el comando upvar, como #0 o 1.
const char *sourceName (entrada)
Nombre de la variable de origen, en el marco dado por frameName. Puede referirse a una variable escalar o a una variable de matriz con un índice entre paréntesis.
const char *destName (entrada)
Nombre de la variable de destino, que se vinculará a la variable de origen para que las referencias a destName se refieran a la otra variable. No debe existir actualmente, excepto como una variable vinculada mediante upvar.
int flags (entrada)
Uno de TCL_GLOBAL_ONLY, TCL_NAMESPACE_ONLY o 0; si no es cero, entonces destName es una variable global o de espacio de nombres; de lo contrario, es local al procedimiento actual (o al espacio de nombres actual si no hay procedimiento activo).
const char *name1 (entrada)
Primera parte del nombre de la variable de origen (nombre escalar, o nombre de matriz sin índice de matriz).
const char *name2 (entrada)
Si la variable de origen es un elemento de una matriz, proporciona el índice del elemento. Para variables de origen escalares, es NULL.

DESCRIPCIÓN

Tcl_UpVar y Tcl_UpVar2 proporcionan la misma funcionalidad que el comando upvar: crean un enlace desde una variable de origen a una variable de destino, de modo que las referencias a la variable de destino se pasen de forma transparente a la variable de origen. El nombre de la variable de origen puede especificarse como una única cadena, como xyx o a(24) (llamando a Tcl_UpVar), o en dos partes donde el nombre de la matriz se ha separado del nombre del elemento (llamando a Tcl_UpVar2). El nombre de la variable de destino se especifica en una única cadena; no puede ser un elemento de matriz.

Ambos procedimientos devuelven TCL_OK o TCL_ERROR, y dejan un mensaje de error en el resultado del intérprete si se produce un error.

Al igual que con el comando upvar, la variable de origen no tiene por qué existir; si existe, desvincularla más tarde no destruye el enlace. La variable de destino puede existir en el momento de la llamada, pero si es así, debe existir como una variable vinculada.
