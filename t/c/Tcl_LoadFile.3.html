Tcl_LoadFile(3)

Paquete: tcl

Licencias: TCL

Load(3) Procedimientos de la biblioteca Tcl Load(3)

NOMBRE

Tcl_LoadFile, Tcl_FindSymbol - carga de bibliotecas dinámicas independiente de la plataforma

SINOPSIS

#include <tcl.h>

int
Tcl_LoadFile(interp, pathPtr, symbols, flags, procPtrs, loadHandlePtr)

void *
Tcl_FindSymbol(interp, loadHandle, symbol)

ARGUMENTOS

Tcl_Interp *interp (in)
Intérprete a usar para reportar mensajes de error.
Tcl_Obj *pathPtr (in)
El nombre del archivo a cargar. Si es un nombre único, se utilizará la ruta de búsqueda de bibliotecas del entorno actual para resolverlo.
const char *const symbols[] (in)
Matriz de nombres de símbolos a resolver durante la carga de la biblioteca, o NULL si no hay símbolos que resolver. Si se proporciona una matriz, la última entrada de la matriz debe ser NULL.
int flags (in)
El valor normalmente debe ser 0, pero también se permiten TCL_LOAD_GLOBAL o TCL_LOAD_LAZY o una combinación de ambos.
void *procPtrs (out)
Punta a una matriz que contendrá las direcciones de las funciones descritas en el argumento symbols. Debe ser NULL si no hay símbolos que resolver.
Tcl_LoadHandle *loadHandlePtr (out)
Punta a una variable que contendrá el manejador del token abstracto que describe la biblioteca que se ha cargado.
Tcl_LoadHandle loadHandle (in)
Token abstracto que describe la biblioteca en la que buscar un símbolo.
const char *symbol (in)
El nombre del símbolo a buscar.

DESCRIPCION

Tcl_LoadFile carga un archivo del sistema de archivos (incluyendo potencialmente cualquier sistema de archivos virtual que se haya instalado) y proporciona un manejador para él que puede usarse en operaciones posteriores. La matriz symbols, si no es NULL, proporciona un conjunto de nombres de símbolos (típicamente funciones) que deben resolverse desde la biblioteca y que se almacenarán en la matriz indicada por procPtrs. Si alguno de los símbolos no se resuelve, la carga del archivo fallará con un mensaje de error dejado en el intérprete (si no es NULL). El resultado de Tcl_LoadFile es un código de error estándar de Tcl. La biblioteca puede descargarse con Tcl_FSUnloadFile.

Tcl_FindSymbol localiza un símbolo en una biblioteca cargada y lo devuelve. Si el símbolo no se encuentra, devuelve NULL y establece un mensaje de error en el interp dado (si no es NULL). Tenga en cuenta que es inseguro utilizar esta operación en un manejador que se ha pasado a Tcl_FSUnloadFile.

VER TAMBIÉN

Tcl_FSLoadFile(3), Tcl_FSUnloadFile(3), load(n), unload(n)
