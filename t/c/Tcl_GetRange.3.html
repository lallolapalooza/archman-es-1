ARGUMENTOS

const char *bytes (entrada)
Punta al primer byte de una matriz de bytes codificados en UTF-8 utilizada para establecer o añadir a un valor de cadena. Esta matriz de bytes puede contener caracteres nulos incrustados a menos que numChars sea negativo. (Las aplicaciones que necesiten bytes nulos deben representarlos como la secuencia de dos bytes \300\200, usar Tcl_ExternalToUtf para convertir, o Tcl_NewByteArrayObj si la cadena es una colección de bytes no interpretados).
int length (entrada)
El número de bytes a copiar de bytes al inicializar, establecer o añadir a un valor de cadena. Si es negativo, se utilizan todos los bytes hasta el primer nulo.
const Tcl_UniChar *unicode (entrada)
Punta al primer byte de una matriz de caracteres Unicode utilizada para establecer o añadir a un valor de cadena. Esta matriz de bytes puede contener caracteres nulos incrustados a menos que numChars sea negativo.
int numChars (entrada)
El número de caracteres Unicode a copiar de unicode al inicializar, establecer o añadir a un valor de cadena. Si es negativo, se utilizan todos los caracteres hasta el primer carácter nulo.
int index (entrada)
El índice del carácter Unicode a devolver.
int first (entrada)
El índice del primer carácter Unicode en el rango Unicode a devolver como un nuevo valor.
int last (entrada)
El índice del último carácter Unicode en el rango Unicode a devolver como un nuevo valor.
Tcl_Obj *objPtr (entrada/salida)
Punta a un valor a manipular.
Tcl_Obj *appendObjPtr (entrada)
El valor a añadir a objPtr en Tcl_AppendObjToObj.
int *lengthPtr (salida)
Si no es NULL, la ubicación donde Tcl_GetStringFromObj almacenará la longitud de la representación de cadena del valor.
const char *string (entrada)
Valor de cadena terminado en nulo a añadir a objPtr.
va_list argList (entrada)
Una lista de argumentos que debe haber sido inicializada con va_start y limpiada con va_end.
int limit (entrada)
Número máximo de bytes a añadir.
const char *ellipsis (entrada)
Sufijo a añadir cuando el límite provoca truncamiento de la cadena. Si se pasa NULL, se utiliza el sufijo “...”.
const char *format (entrada)
Cadena de control de formato incluyendo especificadores de conversión %.
int objc (entrada)
El número de elementos a formatear o concatenar.
Tcl_Obj *objv[] (entrada)
La matriz de valores a formatear o concatenar.
int newLength (entrada)
Nueva longitud para el valor de cadena de objPtr, sin incluir el carácter nulo final.

DESCRIPCIÓN

Los procedimientos descritos en esta entrada del manual permiten manipular valores Tcl como valores de cadena. Utilizan la representación interna del valor para almacenar información adicional y hacer que las manipulaciones de cadena sean más eficientes. En particular, hacen que una serie de operaciones de adición sean eficientes al asignar espacio de almacenamiento adicional para la cadena, de modo que no tenga que ser copiada en cada adición. Además, los cálculos de indexación y longitud se optimizan porque la representación de cadena Unicode se calcula y almacena en caché según sea necesario. Al utilizar la familia de funciones Tcl_Append* donde el resultado del intérprete es el valor al que se está añadiendo, es importante llamar primero a Tcl_ResetResult para asegurarse de que no está añadiendo involuntariamente a datos existentes en el valor de resultado.

Tcl_NewStringObj y Tcl_SetStringObj crean un nuevo valor o modifican uno existente para que contenga una copia de la cadena dada por bytes y length. Tcl_NewUnicodeObj y Tcl_SetUnicodeObj crean un nuevo valor o modifican uno existente para que contenga una copia de la cadena Unicode dada por unicode y numChars. Tcl_NewStringObj y Tcl_NewUnicodeObj devuelven un puntero a un valor recién creado con recuento de referencias cero. Los cuatro procedimientos establecen el valor para que contenga una copia de la cadena especificada. Tcl_SetStringObj y Tcl_SetUnicodeObj liberan cualquier representación de cadena antigua, así como cualquier representación interna antigua del valor.

Tcl_GetStringFromObj y Tcl_GetString devuelven la representación de cadena de un valor. Esto se proporciona mediante el puntero devuelto y (para Tcl_GetStringFromObj) la longitud, que se almacena en lengthPtr si no es NULL. Si la representación de cadena UTF del valor no es válida (su puntero de bytes es NULL), la representación de cadena se regenera a partir de la representación interna del valor. El almacenamiento al que apunta el puntero devuelto es propiedad del gestor de valores. Se pasa como un puntero escribible para que el autor de la extensión que crea su propio Tcl_ObjType pueda modificar la representación de cadena dentro de Tcl_UpdateStringProc de su Tcl_ObjType. Excepto para ese propósito limitado, el puntero devuelto por Tcl_GetStringFromObj o Tcl_GetString debe tratarse como de solo lectura. Se recomienda que este puntero se asigne a una variable (const char *). Incluso en las situaciones limitadas en las que escribir en este puntero es aceptable, se debe tener cuidado de respetar la semántica de copia en escritura requerida por Tcl_Obj, con llamadas apropiadas a Tcl_IsShared y Tcl_DuplicateObj antes de cualquier modificación in situ de la representación de cadena. El procedimiento Tcl_GetString se utiliza en el caso común en el que el llamador no necesita la longitud de la representación de cadena.

Tcl_GetUnicodeFromObj y Tcl_GetUnicode devuelven el valor de un valor como una cadena Unicode. Esto se proporciona mediante el puntero devuelto y (para Tcl_GetUnicodeFromObj) la longitud, que se almacena en lengthPtr si no es NULL. El almacenamiento al que apunta el puntero devuelto es propiedad del gestor de valores y el llamador no debe modificarlo. El procedimiento Tcl_GetUnicode se utiliza en el caso común en el que el llamador no necesita la longitud de la representación de cadena unicode.

Tcl_GetUniChar devuelve el carácter index'ésimo en la representación Unicode del valor. Se asume que el índice está en el rango apropiado.

Tcl_GetRange devuelve un nuevo valor compuesto por los caracteres entre first y last (inclusive) en la representación Unicode del valor. Si la representación Unicode del valor no es válida, la representación Unicode se regenera a partir de la representación de cadena del valor. Si first < 0, entonces la cadena devuelta comienza al principio del valor. Si last < 0, entonces la cadena devuelta termina al final del valor.

> devuelve el número de caracteres (en lugar de bytes) en el valor de cadena.

Tcl_AppendToObj anexa los datos proporcionados por bytes y length a la representación de cadena del valor especificado por objPtr. Si el valor tiene una representación de cadena no válida, se intenta convertir bytes al formato Unicode. Si la conversión es exitosa, la forma convertida de bytes se anexa a la representación Unicode del valor. De lo contrario, la representación Unicode del valor se invalida y se convierte al formato UTF, y bytes se anexa a la nueva representación de cadena del valor. Eventualmente, el crecimiento del búfer se realiza mediante grandes asignaciones para optimizar múltiples llamadas.

Tcl_AppendUnicodeToObj anexa la cadena Unicode proporcionada por unicode y numChars al valor especificado por objPtr. Si el valor tiene una representación Unicode no válida, unicode se convierte al formato UTF y se anexa a la representación de cadena del valor. Las anexiones se optimizan para manejar anexiones repetidas de manera relativamente eficiente (sobreasigna el espacio de cadena o Unicode para evitar reasignaciones y copias repetidas del valor de cadena del valor).

Tcl_AppendObjToObj es similar a Tcl_AppendToObj, pero anexa el valor de cadena o Unicode (el que exista y sea más adecuado para ser anexado a objPtr) de appendObjPtr a objPtr.

Tcl_AppendStringsToObj es similar a Tcl_AppendToObj excepto que se le pueden pasar más de un valor para anexar y cada valor debe ser una cadena terminada en nulo (es decir, ninguno de los valores puede contener caracteres nulos internos). Se puede proporcionar cualquier número de argumentos string, pero el último argumento debe ser (char *)NULL para indicar el final de la lista.

Tcl_AppendStringsToObjVA es lo mismo que Tcl_AppendStringsToObj excepto que en lugar de tomar un número variable de argumentos, toma una lista de argumentos.

Tcl_AppendLimitedToObj es similar a Tcl_AppendToObj excepto que impone un límite a la cantidad de bytes que se anexan. Esto puede ser útil cuando la cadena a anexar puede ser muy grande, pero no se debe permitir que el valor que se está construyendo crezca sin límites. Un uso común es al construir un mensaje de error, donde el resultado final debe mantenerse lo suficientemente corto como para ser legible. Se anexan bytes de bytes a objPtr, pero no más de limit bytes en total. Si el límite impide que se anexen todos los length bytes disponibles, la anexión se realiza de manera que los últimos bytes anexados provienen de la cadena ellipsis. Esto permite indicar la truncación en la cadena. Cuando length es -1, se anexan todos los bytes hasta el primer carácter nulo, sujeto al límite. Cuando ellipsis es NULL, se utiliza la cadena predeterminada .... Cuando ellipsis no es NULL, debe apuntar a una cadena terminada en nulo en la codificación UTF interna de Tcl. El número de bytes anexados puede ser menor que el menor de length y limit cuando se anexan menos bytes para anexar solo caracteres completos de varios bytes.

Tcl_Format es la interfaz de nivel C del motor del comando format. El procedimiento de comando real para format es poco más que

Tcl_Format(interp, Tcl_GetString(objv[1]), objc-2, objv+2);

Los valores de Tcl_Obj objc en objv se formatean en una cadena según la especificación de conversión en el argumento format, siguiendo la documentación del comando format. La cadena formateada resultante se convierte a un nuevo Tcl_Obj con un recuento de referencias de cero y se devuelve. Si ocurre algún error durante la producción de la cadena formateada, se devuelve NULL y se registra un mensaje de error en interp, si interp no es NULL.

Tcl_AppendFormatToObj es una forma alternativa de anexión de Tcl_Format con una funcionalidad equivalente a:

Tcl_Obj *newPtr = Tcl_Format(interp, format, objc, objv);
if (newPtr == NULL) return TCL_ERROR;
Tcl_AppendObjToObj(objPtr, newPtr);
Tcl_DecrRefCount(newPtr);
return TCL_OK;

pero con mayor comodidad y eficiencia cuando se necesita la funcionalidad de anexión.

Tcl_ObjPrintf sirve como reemplazo para la secuencia común

char buf[SOME_SUITABLE_LENGTH];
sprintf(buf, format, ...);
Tcl_NewStringObj(buf, -1);

pero con mayor comodidad y sin necesidad de determinar SOME_SUITABLE_LENGTH. El formato se realiza con el mismo motor de formato central utilizado por Tcl_Format. Esto significa que el conjunto de especificadores de conversión compatibles es el del comando format, pero el comportamiento es lo más similar posible a sprintf. Los especificadores de formato que fueron agregados por C99 (como "hh", "ll", "j", "z", "t", "L") no son compatibles. Cuando un especificador de formato pasado a Tcl_ObjPrintf incluye una precisión, el valor se toma como un número de bytes, como lo hace sprintf, y no como un número de caracteres, como lo hace format. Esto se hace asumiendo que el código C es más probable que sepa cuántos bytes está manejando que la cantidad de caracteres codificados que esos bytes representan. Los argumentos variables pasados deben ser de los tipos que serían adecuados para pasar a sprintf. Tenga en cuenta en este ejemplo de uso, x es de tipo int.

int x = 5;
Tcl_Obj *objPtr = Tcl_ObjPrintf("Value is %d", x);

Si el valor de format contiene inconsistencias internas o formatos de especificador no válidos, la cadena resultante formateada producida por Tcl_ObjPrintf será un mensaje de error que describe el error. Sin embargo, es imposible proporcionar protección en tiempo de ejecución contra desajustes entre el formato y cualquier argumento posterior. Algunos compiladores pueden proporcionar protección en tiempo de compilación.

Tcl_AppendPrintfToObj es una forma alternativa de anexión de Tcl_ObjPrintf con funcionalidad equivalente a

Tcl_Obj *newPtr = Tcl_ObjPrintf(format, ...);
Tcl_AppendObjToObj(objPtr, newPtr);
Tcl_DecrRefCount(newPtr);

pero con mayor comodidad y eficiencia cuando se necesita la funcionalidad de anexión.

El procedimiento Tcl_SetObjLength cambia la longitud del valor de cadena de su argumento objPtr. Si el argumento newLength es mayor que el espacio asignado para la cadena del valor, entonces se reasigna el espacio de la cadena y el valor antiguo se copia al nuevo espacio; los bytes entre la longitud antigua de la cadena y la nueva longitud pueden tener valores arbitrarios. Si el argumento newLength es menor que la longitud actual de la cadena del valor, con objPtr->length se reduce sin reasignar el espacio de la cadena; el tamaño de asignación original para la cadena se registra en el valor, de modo que la longitud de la cadena se puede ampliar en una llamada posterior a Tcl_SetObjLength sin reasignar almacenamiento. En todos los casos, Tcl_SetObjLength deja un carácter nulo en objPtr->bytes[newLength].

Tcl_AttemptSetObjLength es idéntico en función a Tcl_SetObjLength excepto que si no se puede asignar suficiente memoria para satisfacer la solicitud, no hace que el intérprete de Tcl entre en panic. Por lo tanto, si newLength es mayor que el espacio asignado para la cadena del valor, y no hay suficiente memoria disponible para satisfacer la solicitud, Tcl_AttemptSetObjLength no tomará ninguna acción y devolverá 0 para indicar fallo. Si hay suficiente memoria para satisfacer la solicitud, Tcl_AttemptSetObjLength se comporta igual que Tcl_SetObjLength y devuelve 1 para indicar éxito.

La función Tcl_ConcatObj devuelve un nuevo valor de cadena cuyo valor es la concatenación separada por espacios de las representaciones de cadena de todos los valores en la matriz objv. Tcl_ConcatObj elimina los espacios en blanco al principio y al final al copiar las representaciones de cadena de la matriz objv al resultado. Si un elemento de la matriz objv consiste únicamente en espacios en blanco, ese valor se ignora por completo. Esta eliminación de espacios en blanco se agregó para hacer que la salida del comando concat sea más limpia. Tcl_ConcatObj devuelve un puntero a un valor recién creado con un recuento de referencias de cero.
