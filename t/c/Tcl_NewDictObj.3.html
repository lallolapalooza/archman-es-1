ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de diccionario, se deja un mensaje de error en el resultado del intérprete a menos que interp sea NULL.
Tcl_Obj *dictPtr (entrada/salida)
Puntero al valor del diccionario que se va a manipular. Si dictPtr aún no apunta a un valor de diccionario, se intentará convertirlo en uno.
Tcl_Obj *keyPtr (entrada)
Puntero a la clave para el par clave/valor que se manipula dentro del valor del diccionario.
Tcl_Obj **keyPtrPtr (salida)
Puntero a una variable a la que se le asignará la clave de un par clave/valor. Puede ser NULL para indicar que el llamante no está interesado en la clave.
Tcl_Obj *valuePtr (entrada)
Puntero al valor para el par clave/valor que se manipula dentro del valor del diccionario (o subvalor, en el caso de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (salida)
Puntero a una variable a la que se le asignará el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, esto puede ser NULL para indicar que el llamante no está interesado en el valor.
int *sizePtr (salida)
Puntero a una variable a la que se le asignará el número de pares clave/valor contenidos en el diccionario.
Tcl_DictSearch *searchPtr (entrada/salida)
Puntero a la estructura a utilizar para mantener el seguimiento del progreso en la enumeración de todos los pares clave/valor en un diccionario. Los contenidos de la estructura serán inicializados por la llamada a Tcl_DictObjFirst. Si la enumeración debe ser terminada antes de que se devuelvan todos los valores del diccionario, el registro de búsqueda *debe* ser pasado a Tcl_DictObjDone para permitir la liberación de los bloqueos internos.
int *donePtr (salida)
Puntero a una variable a la que se le asignará un valor distinto de cero cuando se complete la enumeración de los pares clave/valor en un diccionario, y cero en caso contrario.
int keyc (entrada)
Indica el número de claves que se proporcionarán en el array keyv.
Tcl_Obj *const *keyv (entrada)
Array de keyc punteros a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList utilizarán para localizar el par clave/valor a manipular dentro de los sub-diccionarios del valor del diccionario principal que se les pasa.

DESCRIPCIÓN

Los valores de diccionario Tcl tienen una representación interna que soporta un mapeo eficiente de claves a valores y que garantiza que el orden particular de las claves dentro del diccionario se mantenga igual módulo cualquier clave que se elimine (lo que las elimina del orden) o se añada (lo que las añade al final del orden). Si se reinterpreta como una lista, los valores en los índices de valor par en la lista serán las claves del diccionario, y cada uno estará seguido (en el índice de valor impar) por el valor asociado a esa clave.

Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde código C.

Tcl_NewDictObj crea un nuevo valor de diccionario vacío. La representación en cadena del valor será inválida y el contador de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario dado y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o NULL si la clave no tiene un mapeo dentro del diccionario. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjPut actualiza el diccionario dado para que la clave dada mapee al valor dado; cada clave puede existir como máximo una vez en cualquier diccionario particular. El diccionario no debe ser compartido, pero la clave y el valor sí pueden serlo. Este procedimiento puede aumentar el contador de referencias de la clave y el valor si resulta necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjRemove actualiza el diccionario dado para que la clave dada no tenga mapeo a ningún valor. El diccionario no debe ser compartido, pero la clave sí puede serlo. La clave realmente almacenada en el diccionario tendrá su contador de referencias decrementado si estaba presente. No es un error si la clave no existía previamente. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario dado. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjFirst inicia una iteración sobre todos los pares clave/valor en el diccionario dado, colocando la clave y el valor en las variables apuntadas por los argumentos keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que el llamante no está interesado en la clave o el valor respectivamente.) El siguiente par clave/valor en el diccionario se puede recuperar con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modificarán el procesamiento de la iteración a menos que el diccionario no esté compartido, en cuyo caso esto provocará la terminación prematura de la iteración (que los scripts de Tcl no pueden provocar a través del comando dict.) El argumento searchPtr apunta a una parte del contexto que se utiliza para identificar qué iteración particular se está realizando y se inicializa con la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero si hay más pares clave/valor para iterar, o a un valor distinto de cero si la iteración está completa. El orden de iteración no está definido por la implementación. Si el argumento dictPtr no puede ser convertido a un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y de lo contrario devuelve TCL_OK.

Cuando se llama a Tcl_DictObjFirst sobre un diccionario, se coloca un bloqueo en el diccionario para permitir que dicho diccionario sea iterado de forma segura sin importar si el diccionario se modifica durante la iteración. Debido a esto, una vez que la iteración sobre las claves de un diccionario ha finalizado (ya sea porque se han iterado todos los valores, como lo indica el valor uno en la variable apuntada por el argumento donePtr, o porque no se requieren más valores), la función Tcl_DictObjDone debe ser llamada con el mismo searchPtr que se pasó a Tcl_DictObjFirst para que los bloqueos internos puedan ser liberados. Una vez que un searchPtr particular se pasa a Tcl_DictObjDone, pasarlo a Tcl_DictObjNext (sin inicializarlo previamente con Tcl_DictObjFirst) resultará en que no se produzcan valores y que la variable apuntada por donePtr se establezca en uno. Es seguro llamar a Tcl_DictObjDone varias veces en el mismo searchPtr por cada llamada a Tcl_DictObjFirst.

Los procedimientos Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son análogos a Tcl_DictObjPut y Tcl_DictObjRemove respectivamente, excepto que en lugar de trabajar con un solo diccionario, están diseñados para operar en un árbol anidado de diccionarios, con diccionarios internos almacenados como valores dentro de diccionarios externos. Los argumentos keyc y keyv especifican una lista de claves (con las claves más externas primero) que actúa como una ruta al par clave/valor a afectar. ARGUMENTS

In addition to the standard Tcl object and interpreter arguments, the following arguments are used:

dictPtr
A pointer to a Tcl object representing a dictionary. The object must have type `TCL_DDROBJECT`.
keyPtr
A pointer to a Tcl object to be used as a key in the dictionary.
valuePtr
A pointer to a Tcl object to be used as a value in the dictionary.
keyList
A Tcl list object containing zero or more Tcl objects, each of which is a key in the dictionary.
searchPtr
A pointer to a Tcl dictionary search structure. This structure is used to manage dictionary iteration.
donePtr
A pointer to an integer. If the value pointed to by this is non-zero, it indicates that the iteration is complete.
valuePtrPtr
A pointer to a pointer to a Tcl object. On return, this will point to the value associated with a given key.
boolPtr
A pointer to an integer. On return, this will point to the boolean value associated with a given key.
doublePtr
A pointer to a double. On return, this will point to the double value associated with a given key.
intPtr
A pointer to an integer. On return, this will point to the integer value associated with a given key.
longPtr
A pointer to a long integer. On return, this will point to the long integer value associated with a given key.
key
A C string representing the key to search for.
srcDictPtr
A pointer to a source dictionary Tcl object.
destDictPtr
A pointer to a destination dictionary Tcl object.

DESCRIPTION

The Tcl dictionary type provides a hash table implementation for storing key-value pairs. The functions described here provide a C API for manipulating dictionary objects.

Tcl_NewDictObj creates and returns a new, empty dictionary object.

Tcl_DictObjPut stores the value specified by valuePtr in the dictionary specified by dictPtr, associated with the key specified by keyPtr. If the key already exists in the dictionary, its value is updated. Otherwise, a new key-value pair is added. The dictionary object is modified in place.

Tcl_DictObjGet retrieves the value associated with the key specified by keyPtr from the dictionary specified by dictPtr. On return, valuePtrPtr will point to the Tcl object representing the value. If the key is not found in the dictionary, *valuePtrPtr will be set to NULL and TCL_ERROR is returned.

Tcl_DictObjLength returns the number of key-value pairs in the dictionary specified by dictPtr.

The following functions are used for iterating over the key-value pairs in a dictionary:

Tcl_DictObjFirst
Initializes a dictionary search. On return, keyPtrPtr and valuePtrPtr will point to the first key-value pair in the dictionary, and donePtr will be set to non-zero if the dictionary is empty. The search structure must be initialized with Tcl_DictObjFirst before calling Tcl_DictObjNext or Tcl_DictObjDone.
Tcl_DictObjNext
Advances the search to the next key-value pair in the dictionary. On return, keyPtrPtr and valuePtrPtr will point to the next key-value pair, and donePtr will be set to non-zero if the end of the dictionary has been reached.
Tcl_DictObjDone
Cleans up the search structure initialized by Tcl_DictObjFirst.

Tcl_DictObjAppendKey and Tcl_DictObjAppendValue are used to append a key and value to a dictionary that is being built. These functions are typically used together.

Tcl_DictObjPutKeyList is similar to Tcl_DictObjPut, but the key is specified as a list of objects. This is useful for creating nested dictionaries. If intermediate dictionaries in the key list do not exist, they are created automatically.

The following functions provide convenient access to specific value types:

Tcl_DictObjGetBoolean
Retrieves the boolean value associated with the given key. The value is converted to a boolean using Tcl's standard boolean conversion rules. On return, boolPtr points to the boolean value.
Tcl_DictObjGetDouble
Retrieves the double-precision floating-point value associated with the given key. The value is converted to a double using Tcl's standard double conversion rules. On return, doublePtr points to the double value.
Tcl_DictObjGetInt
Retrieves the integer value associated with the given key. The value is converted to an integer using Tcl's standard integer conversion rules. On return, intPtr points to the integer value.
Tcl_DictObjGetLong
Retrieves the long integer value associated with the given key. The value is converted to a long integer using Tcl's standard long integer conversion rules. On return, longPtr points to the long integer value.
Tcl_DictObjGetString
Retrieves the string value associated with the given key. On return, valuePtrPtr points to the Tcl object representing the string value.
Tcl_DictObjGetHashKey
Similar to Tcl_DictObjGet, but the key is specified as a hash key.
Tcl_DictObjNextHashKey
Similar to Tcl_DictObjNext, but the key is specified as a hash key.

Tcl_DictObjRemoveKey removes the key-value pair specified by keyPtr from the dictionary specified by dictPtr. If the key is not found, the dictionary remains unchanged.

Tcl_DictObjRemoveKeyList removes all key-value pairs specified by the keys in keyList from the dictionary specified by dictPtr. If any key in keyList is not found in the dictionary, an error is returned and the dictionary remains unchanged.

Tcl_DictObjCopy copies the contents of the source dictionary srcDictPtr to the destination dictionary destDictPtr. The destination dictionary is cleared before the copy operation. This function is useful for creating a deep copy of a dictionary.

The dictionary iteration interface is designed to be used in a loop. The search structure searchPtr maintains the state of the iteration. It is important to call Tcl_DictObjDone when the iteration is finished, even if the loop is exited prematurely. This ensures that any internal locks on the dictionary are released.

Creating nested dictionaries is straightforward with Tcl_DictObjPutKeyList. For example, to set a value in a nested dictionary `a.b.c`, you would use a key list containing the objects for `a`, `b`, and `c`. Intermediate dictionaries are created automatically as needed. Conversely, Tcl_DictObjRemoveKeyList requires that all non-terminal keys in the key list exist and have dictionaries as their values.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters. This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used. The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
