ARGUMENTOS

const char *bytes (entrada)
Puntero al primer byte de una matriz de bytes codificados en UTF-8 utilizados para establecer o anexar a un valor de cadena. Esta matriz de bytes puede contener caracteres nulos incrustados a menos que numChars sea negativo. (Las aplicaciones que necesiten bytes nulos deben representarlos como la secuencia de dos bytes \300\200, usar Tcl_ExternalToUtf para convertir, o Tcl_NewByteArrayObj si la cadena es una colección de bytes no interpretados).
int length (entrada)
El número de bytes a copiar de bytes al inicializar, establecer o anexar a un valor de cadena. Si es negativo, se usan todos los bytes hasta el primer nulo.
const Tcl_UniChar *unicode (entrada)
Puntero al primer byte de una matriz de caracteres Unicode utilizados para establecer o anexar a un valor de cadena. Esta matriz de bytes puede contener caracteres nulos incrustados a menos que numChars sea negativo.
int numChars (entrada)
El número de caracteres Unicode a copiar de unicode al inicializar, establecer o anexar a un valor de cadena. Si es negativo, se usan todos los caracteres hasta el primer carácter nulo.
int index (entrada)
El índice del carácter Unicode a devolver.
int first (entrada)
El índice del primer carácter Unicode en el rango Unicode a devolver como un nuevo valor.
int last (entrada)
El índice del último carácter Unicode en el rango Unicode a devolver como un nuevo valor.
Tcl_Obj *objPtr (entrada/salida)
Puntero a un valor a manipular.
Tcl_Obj *appendObjPtr (entrada)
El valor a anexar a objPtr en Tcl_AppendObjToObj.
int *lengthPtr (salida)
Si no es NULL, la ubicación donde Tcl_GetStringFromObj almacenará la longitud de la representación de cadena del valor.
const char *string (entrada)
Valor de cadena terminado en nulo a anexar a objPtr.
va_list argList (entrada)
Una lista de argumentos que debe haber sido inicializada usando va_start, y limpiada usando va_end.
int limit (entrada)
Número máximo de bytes a anexar.
const char *ellipsis (entrada)
Sufijo a anexar cuando el límite provoca truncamiento de la cadena. Si se pasa NULL, se usa el sufijo “...”.
const char *format (entrada)
Cadena de control de formato que incluye especificadores de conversión %.
int objc (entrada)
El número de elementos a formatear o concatenar.
Tcl_Obj *objv[] (entrada)
La matriz de valores a formatear o concatenar.
int newLength (entrada)
Nueva longitud para el valor de cadena de objPtr, sin incluir el carácter nulo final.

DESCRIPCIÓN

Los procedimientos descritos en esta entrada del manual permiten manipular valores Tcl como valores de cadena. Utilizan la representación interna del valor para almacenar información adicional y hacer que las manipulaciones de cadenas sean más eficientes. En particular, hacen que una serie de operaciones de anexión sean eficientes al asignar espacio de almacenamiento adicional para la cadena, de modo que no tenga que ser copiada en cada anexión. Además, los cálculos de indexación y longitud se optimizan porque la representación de cadena Unicode se calcula y almacena en caché según sea necesario. Al usar la familia de funciones Tcl_Append* donde el resultado del intérprete es el valor al que se está anexando, es importante llamar a Tcl_ResetResult primero para asegurarse de que no está anexando inadvertidamente a datos existentes en el valor de resultado.

Tcl_NewStringObj y Tcl_SetStringObj crean un nuevo valor o modifican un valor existente para contener una copia de la cadena proporcionada por bytes y length. Tcl_NewUnicodeObj y Tcl_SetUnicodeObj crean un nuevo valor o modifican un valor existente para contener una copia de la cadena Unicode proporcionada por unicode y numChars. Tcl_NewStringObj y Tcl_NewUnicodeObj devuelven un puntero a un valor recién creado con un recuento de referencias cero. Los cuatro procedimientos establecen el valor para que contenga una copia de la cadena especificada. Tcl_SetStringObj y Tcl_SetUnicodeObj liberan cualquier representación de cadena antigua, así como cualquier representación interna antigua del valor.

Tcl_GetStringFromObj y Tcl_GetString devuelven la representación de cadena de un valor. Esto se proporciona mediante el puntero devuelto y (para Tcl_GetStringFromObj) la longitud, que se almacena en lengthPtr si no es NULL. Si la representación de cadena UTF del valor no es válida (su puntero de bytes es NULL), la representación de cadena se regenera a partir de la representación interna del valor. El almacenamiento referenciado por el puntero devuelto es propiedad del administrador de valores. Se pasa de vuelta como un puntero escribible para que el autor de la extensión que crea su propio Tcl_ObjType pueda modificar la representación de cadena dentro de Tcl_UpdateStringProc de su Tcl_ObjType. Excepto para ese propósito limitado, el puntero devuelto por Tcl_GetStringFromObj o Tcl_GetString debe tratarse como de solo lectura. Se recomienda que este puntero se asigne a una variable (const char *). Incluso en las situaciones limitadas donde la escritura en este puntero es aceptable, se debe tener cuidado de respetar las semánticas de copia en escritura requeridas por Tcl_Obj, con llamadas apropiadas a Tcl_IsShared y Tcl_DuplicateObj antes de cualquier modificación in situ de la representación de cadena. El procedimiento Tcl_GetString se utiliza en el caso común en el que el llamador no necesita la longitud de la representación de cadena.

Tcl_GetUnicodeFromObj y Tcl_GetUnicode devuelven el valor de un valor como una cadena Unicode. Esto se proporciona mediante el puntero devuelto y (para Tcl_GetUnicodeFromObj) la longitud, que se almacena en lengthPtr si no es NULL. El almacenamiento referenciado por el puntero de bytes devuelto es propiedad del administrador de valores y no debe ser modificado por el llamador. El procedimiento Tcl_GetUnicode se utiliza en el caso común en el que el llamador no necesita la longitud de la representación de cadena Unicode.

Tcl_GetUniChar devuelve el carácter index en la representación Unicode del valor. Se asume que el índice está en el rango apropiado.

Tcl_GetRange devuelve un valor recién creado que consta de los caracteres entre first y last (inclusive) en la representación Unicode del valor. Si la representación Unicode del valor no es válida, la representación Unicode se regenera a partir de la representación de cadena del valor. Si first < 0, entonces la cadena devuelta comienza al principio del valor. Si last < 0, entonces la cadena devuelta termina al final del valor.

DESCRIPCIÓN

Estas funciones proporcionan una forma eficiente de construir y manipular objetos Tcl, especialmente aquellos que representan cadenas de texto.

Tcl_NewStringObj crea un nuevo objeto Tcl con una representación de cadena inicializada a partir de los bytes y la longitud proporcionados. Si length es -1, se asume que bytes es una cadena terminada en nulo y su longitud se calcula en consecuencia.

Tcl_GetStringFromObj devuelve un puntero a la representación de cadena del objeto especificado por objPtr. Es importante tener en cuenta que esta función devuelve el número de caracteres (en lugar de bytes) en la representación de cadena del valor.

Tcl_AppendToObj añade los datos dados por bytes y length a la representación de cadena del valor especificado por objPtr. Si el valor tiene una representación de cadena inválida, se intenta convertir bytes al formato Unicode. Si la conversión es exitosa, se añade la forma convertida de bytes a la representación Unicode del valor. De lo contrario, la representación Unicode del valor se invalida y se convierte al formato UTF, y bytes se añade a la nueva representación de cadena del valor. Eventualmente, el crecimiento del búfer se realiza mediante grandes asignaciones para optimizar múltiples llamadas.

Tcl_AppendUnicodeToObj añade la cadena Unicode dada por unicode y numChars al valor especificado por objPtr. Si el valor tiene una representación Unicode inválida, unicode se convierte al formato UTF y se añade a la representación de cadena del valor. Las adiciones se optimizan para manejar adiciones repetidas de manera relativamente eficiente (se sobredimensiona el espacio de cadena o Unicode para evitar reasignaciones y copias repetidas del valor de cadena del valor).

Tcl_AppendObjToObj es similar a Tcl_AppendToObj, pero añade el valor de cadena o Unicode (el que exista y sea más adecuado para añadir a objPtr) de appendObjPtr a objPtr.

Tcl_AppendStringsToObj es similar a Tcl_AppendToObj excepto que se le pueden pasar más de un valor para añadir y cada valor debe ser una cadena terminada en nulo (es decir, ninguno de los valores puede contener caracteres nulos internos). Se puede proporcionar cualquier número de argumentos string, pero el último argumento debe ser (char *)NULL para indicar el final de la lista.

Tcl_AppendStringsToObjVA es lo mismo que Tcl_AppendStringsToObj excepto que en lugar de tomar un número variable de argumentos, toma una lista de argumentos.

Tcl_AppendLimitedToObj es similar a Tcl_AppendToObj excepto que impone un límite a cuántos bytes se añaden. Esto puede ser útil cuando la cadena a añadir puede ser muy grande, pero no se debe permitir que el valor que se está construyendo crezca sin límites. Un uso común es al construir un mensaje de error, donde el resultado final debe mantenerse lo suficientemente corto como para ser leído. Los bytes de bytes se añaden a objPtr, pero no se deben añadir más de limit bytes en total. Si el límite impide que se añadan los length bytes disponibles, la adición se realiza de manera que los últimos bytes añadidos provienen de la cadena ellipsis. Esto permite dejar una indicación de la truncación en la cadena. Cuando length es -1, se añaden todos los bytes hasta el primer byte cero, sujeto al límite. Cuando ellipsis es NULL, se utiliza la cadena predeterminada .... Cuando ellipsis no es NULL, debe apuntar a una cadena terminada en nulo en la codificación UTF interna de Tcl. El número de bytes añadidos puede ser menor que el menor de length y limit cuando es necesario añadir menos bytes para añadir solo caracteres multibyte completos.

Tcl_Format es la interfaz a nivel C del motor del comando format. El procedimiento de comando real para format es poco más que

Tcl_Format(interp, Tcl_GetString(objv[1]), objc-2, objv+2);

Los valores de Tcl_Obj objc en objv se formatean en una cadena según la especificación de conversión en el argumento format, siguiendo la documentación del comando format. La cadena formateada resultante se convierte en un nuevo Tcl_Obj con un refcount de cero y se devuelve. Si ocurre algún error durante la producción de la cadena formateada, se devuelve NULL y se registra un mensaje de error en interp, si interp no es NULL.

Tcl_AppendFormatToObj es una forma alternativa de añadir de Tcl_Format con una funcionalidad equivalente a:

Tcl_Obj *newPtr = Tcl_Format(interp, format, objc, objv);
if (newPtr == NULL) return TCL_ERROR;
Tcl_AppendObjToObj(objPtr, newPtr);
Tcl_DecrRefCount(newPtr);
return TCL_OK;

pero con mayor comodidad y eficiencia cuando se necesita la funcionalidad de añadir.

Tcl_ObjPrintf sirve como reemplazo para la secuencia común

char buf[SOME_SUITABLE_LENGTH];
sprintf(buf, format, ...);
Tcl_NewStringObj(buf, -1);

pero con mayor comodidad y sin necesidad de determinar SOME_SUITABLE_LENGTH. El formateo se realiza con el mismo motor de formateo central utilizado por Tcl_Format. Esto significa que el conjunto de especificadores de conversión compatibles es el del comando format, pero el comportamiento es lo más similar posible a sprintf. Los especificadores de formato que fueron añadidos por C99 (como "hh", "ll", "j", "z", "t", "L") no son compatibles. Cuando un especificador de formato pasado a Tcl_ObjPrintf incluye una precisión, el valor se toma como un número de bytes, como hace sprintf, y no como un número de caracteres, como hace format. Esto se hace asumiendo que el código C es más propenso a saber cuántos bytes está manejando que cuántos caracteres codificados representan esos bytes. Los argumentos variables pasados deben ser de los tipos que serían adecuados para pasar a sprintf. Tenga en cuenta en este ejemplo de uso, x es de tipo int.

int x = 5;
Tcl_Obj *objPtr = Tcl_ObjPrintf("Valor es %d", x);

Si el valor de format contiene inconsistencias internas o formatos de especificador inválidos, la cadena resultante formateada producida por Tcl_ObjPrintf será un mensaje de error que describa el error. Sin embargo, es imposible proporcionar protección en tiempo de ejecución contra desajustes entre el formato y cualquier argumento posterior. Algunos compiladores pueden proporcionar protección en tiempo de compilación.

Tcl_AppendPrintfToObj es una forma alternativa de añadir de Tcl_ObjPrintf con una funcionalidad equivalente a

Tcl_Obj *newPtr = Tcl_ObjPrintf(format, ...);
Tcl_AppendObjToObj(objPtr, newPtr);
Tcl_DecrRefCount(newPtr);

pero con mayor comodidad y eficiencia cuando se necesita la funcionalidad de añadir.

El procedimiento Tcl_SetObjLength cambia la longitud del valor de cadena de su argumento objPtr. Si el argumento newLength es mayor que el espacio asignado para la cadena del valor, se reasigna el espacio de la cadena y se copia el valor antiguo al nuevo espacio; los bytes entre la longitud antigua de la cadena y la nueva longitud pueden tener valores arbitrarios. Si el argumento newLength es menor que la longitud actual de la cadena del valor, objPtr->length se reduce sin reasignar el espacio de la cadena; el tamaño de asignación original para la cadena se registra en el valor, de modo que la longitud de la cadena se pueda ampliar en una llamada posterior a Tcl_SetObjLength sin reasignar almacenamiento. En todos los casos, Tcl_SetObjLength deja un carácter nulo en objPtr->bytes[newLength].

Tcl_AttemptSetObjLength es idéntico en función a Tcl_SetObjLength excepto que si no se puede asignar suficiente memoria para satisfacer la solicitud, no hace que el intérprete de Tcl entre en panic. Por lo tanto, si newLength es mayor que el espacio asignado para la cadena del valor, y no hay suficiente memoria disponible para satisfacer la solicitud, Tcl_AttemptSetObjLength no tomará ninguna acción y devolverá 0 para indicar fallo. Si hay suficiente memoria para satisfacer la solicitud, Tcl_AttemptSetObjLength se comporta igual que Tcl_SetObjLength y devuelve 1 para indicar éxito.

La función Tcl_ConcatObj devuelve un nuevo valor de cadena cuyo valor es la concatenación separada por espacios de las representaciones de cadena de todos los valores en el array objv. Tcl_ConcatObj elimina los espacios en blanco iniciales y finales al copiar las representaciones de cadena del array objv al resultado. Si un elemento del array objv consiste únicamente en espacios en blanco, ese valor se ignora por completo. Esta eliminación de espacios en blanco se añadió para que la salida del comando concat tuviera un aspecto más limpio. Tcl_ConcatObj devuelve un puntero a un valor recién creado con un ref count de cero.
