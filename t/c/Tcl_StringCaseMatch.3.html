Tcl_StringCaseMatch(3)

Paquete: tcl

Licencias: TCL

Tcl_StringCaseMatch(3) Procedimientos de la biblioteca Tcl Tcl_StringCaseMatch(3)

NOMBRE

Tcl_StringMatch, Tcl_StringCaseMatch - probar si una cadena coincide con un patrón

SINOPSIS

#include <tcl.h>

int
Tcl_StringMatch(str, pattern)

int
Tcl_StringCaseMatch(str, pattern, flags)

ARGUMENTOS

const char *str (entrada)
Cadena a probar.
const char *pattern (entrada)
Patrón para comparar con la cadena. Puede contener caracteres especiales de los conjuntos *?\[].
int flags (entrada)
Combinación OR de indicadores de coincidencia, actualmente solo TCL_MATCH_NOCASE. 0 especifica una búsqueda sensible a mayúsculas y minúsculas.

DESCRIPCIÓN

Este procedimiento de utilidad determina si una cadena coincide con un patrón dado. Si lo hace, Tcl_StringMatch devuelve 1. De lo contrario, Tcl_StringMatch devuelve 0. El algoritmo utilizado para la coincidencia es el mismo algoritmo utilizado en el comando Tcl string match y es similar al algoritmo utilizado por el shell C para la coincidencia de nombres de archivo; consulte la entrada del manual de Tcl para obtener más detalles.

En Tcl_StringCaseMatch, el algoritmo es el mismo, pero tiene la opción de hacer que la coincidencia no distinga entre mayúsculas y minúsculas. Si elige esto (pasando TCL_MATCH_NOCASE), entonces la cadena y el patrón se comparan esencialmente en minúsculas.

PALABRAS CLAVE

coincidencia, patrón, cadena
