NOMBRE

Tcl_SourceRCFile - incluir el archivo rc de Tcl

SINOPSIS

#include <tcl.h>

void
Tcl_SourceRCFile(interp)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete de Tcl para incluir el archivo rc.

DESCRIPCIÓN

Tcl_SourceRCFile se utiliza para incluir el archivo rc de Tcl al inicio. Normalmente lo invocan Tcl_Main o Tk_Main. El nombre del archivo que se incluye se obtiene de la variable global tcl_rcFileName en el intérprete dado por interp. Si esta variable no está definida, o si el archivo que indica no se encuentra, no se realiza ninguna acción.

PALABRAS CLAVE

inicialización específica de la aplicación, programa principal, archivo rc
