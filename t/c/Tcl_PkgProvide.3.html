Tcl_PkgProvide(3) Procedimientos de la biblioteca Tcl Tcl_PkgProvide(3)

NOMBRE

Tcl_PkgRequire, Tcl_PkgRequireEx, Tcl_PkgRequireProc, Tcl_PkgPresent, Tcl_PkgPresentEx, Tcl_PkgProvide, Tcl_PkgProvideEx - control de versión de paquetes

SINOPSIS

#include <tcl.h>

const char *
Tcl_PkgRequire(interp, name, version, exact)

const char *
Tcl_PkgRequireEx(interp, name, version, exact, clientDataPtr)

int
Tcl_PkgRequireProc(interp, name, objc, objv, clientDataPtr)

const char *
Tcl_PkgPresent(interp, name, version, exact)

const char *
Tcl_PkgPresentEx(interp, name, version, exact, clientDataPtr)

int
Tcl_PkgProvide(interp, name, version)

int
Tcl_PkgProvideEx(interp, name, version, clientData)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete donde se necesita o está disponible el paquete.
const char *name (entrada)
Nombre del paquete.
const char *version (entrada)
Una cadena de especificación de versión como se describe para package require.
int exact (entrada)
Distinto de cero significa que solo la versión particular especificada por version es aceptable. Cero significa que las versiones más nuevas que version también son aceptables siempre que tengan el mismo número de versión principal que version.
const void *clientData (entrada)
Valor arbitrario a asociar con el paquete.
void *clientDataPtr (salida)
Puntero a un lugar donde almacenar el valor asociado con el paquete coincidente. Solo se cambia si el puntero no es NULL y la función se completó con éxito. El almacenamiento puede ser de cualquier tipo de puntero con el mismo tamaño que un puntero void.
int objc (entrada)
Número de requisitos.
Tcl_Obj* objv[] (entrada)
Matriz de requisitos.

DESCRIPCIÓN

Estos procedimientos proporcionan interfaces a nivel de C para las instalaciones de gestión de paquetes y versiones de Tcl.

Tcl_PkgRequire es equivalente al comando package require, Tcl_PkgPresent es equivalente al comando package present y Tcl_PkgProvide es equivalente al comando package provide.

Consulte la documentación de los comandos Tcl para obtener detalles sobre lo que hacen estos procedimientos.

Si Tcl_PkgPresent o Tcl_PkgRequire se completan con éxito, devuelven un puntero a la cadena de versión de la versión del paquete que se proporciona en el intérprete (que puede ser diferente de version); si ocurre un error, devuelven NULL y dejan un mensaje de error en el resultado del intérprete.

Tcl_PkgProvide devuelve TCL_OK si se completa con éxito; si ocurre un error, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete.

Tcl_PkgProvideEx, Tcl_PkgPresentEx y Tcl_PkgRequireEx permiten establecer y recuperar los datos del cliente asociados con el paquete. En todos los demás aspectos, son equivalentes a las funciones correspondientes.

Tcl_PkgRequireProc es la forma de package require que maneja múltiples requisitos. Las otras formas existen por compatibilidad con versiones anteriores y traducen sus invocaciones a esta forma.
