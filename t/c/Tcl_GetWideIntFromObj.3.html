Punta al lugar donde almacenar el valor entero recuperado de objPtr.

mp_int *bigValue (entrada/salida)

double doubleValue (entrada)
Valor doble del cual se determina la parte entera y se utiliza para inicializar un valor entero de precisión múltiple.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar y leer valores de Tcl que contienen valores integrales.

Las diferentes rutinas existen para acomodar diferentes tipos integrales en C con los cuales se pueden intercambiar valores. Los tipos integrales de C para los cuales Tcl proporciona rutinas de intercambio de valores son int, long int, Tcl_WideInt y mp_int. Los tipos int y long int son proporcionados por el estándar del lenguaje C. El tipo Tcl_WideInt es un typedef definido para ser cualquier tipo integral con signo que cubra al menos el rango de enteros de 64 bits (-9223372036854775808 a 9223372036854775807). Dependiendo de la plataforma y del compilador C, el tipo real podría ser long int, long long int, __int64 o algo más. El tipo mp_int es un tipo de entero de precisión múltiple definido por la biblioteca de enteros de precisión múltiple LibTomMath.

Las rutinas Tcl_NewIntObj, Tcl_NewLongObj, Tcl_NewWideIntObj y Tcl_NewBignumObj crean y devuelven cada una un nuevo valor Tcl inicializado al valor integral del argumento. El valor Tcl devuelto no está compartido.

Las rutinas Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj y Tcl_SetBignumObj establecen cada una el valor de un valor Tcl existente apuntado por objPtr al valor integral proporcionado por el otro argumento. El argumento objPtr debe apuntar a un valor Tcl no compartido. Cualquier intento de establecer el valor de un valor Tcl compartido viola la política de copia en escritura de Tcl. Cualquier representación de cadena o representación interna existente en el valor Tcl no compartido se liberará como consecuencia de establecer el nuevo valor.

Las rutinas Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj y Tcl_TakeBignumFromObj intentan recuperar un valor integral del tipo apropiado del valor Tcl objPtr. Si el intento tiene éxito, se devuelve TCL_OK, y el valor se escribe en el almacenamiento proporcionado por el llamador. El intento podría fallar si objPtr no contiene un valor integral, o si el valor excede el rango del tipo de destino. Si el intento falla, se devuelve TCL_ERROR, y si interp no es NULL, se deja un mensaje de error en interp. El Tcl_ObjType de objPtr puede cambiarse para hacer que las llamadas posteriores a la misma rutina sean más eficientes. A diferencia de las otras funciones, Tcl_TakeBignumFromObj puede establecer el contenido del valor Tcl objPtr a una cadena vacía en el proceso de recuperación del valor entero de precisión múltiple.

La elección entre Tcl_GetBignumFromObj y Tcl_TakeBignumFromObj está determinada por cómo el llamador seguirá utilizando objPtr. Si después de recuperar el valor mp_int de objPtr, el llamador no hará más uso de objPtr, entonces usar Tcl_TakeBignumFromObj permite a Tcl detectar cuándo un objPtr no compartido permite que el valor se mueva en lugar de copiarse, lo que debería ser más eficiente. Si algo más tarde en el llamador requiere que objPtr continúe teniendo el mismo valor, entonces se debe elegir Tcl_GetBignumFromObj.

La rutina Tcl_InitBignumFromDouble es un procedimiento de utilidad que extrae la parte entera de doubleValue y almacena ese valor entero en el valor mp_int bigValue.
