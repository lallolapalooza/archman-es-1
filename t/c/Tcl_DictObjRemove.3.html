Punta al valor para el par clave/valor que se manipula dentro del valor del diccionario (o sub-valor, en el caso de Tcl_DictObjPutKeyList.)

Punta a una variable que contendrá el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, esto puede ser NULL para indicar que el llamador no está interesado en el valor.
int *sizePtr (out)
Punta a una variable que contendrá el número de pares clave/valor contenidos dentro del diccionario.

Puntero al registro a utilizar para seguir el progreso en la enumeración de todos los pares clave/valor en un diccionario. El contenido del registro se inicializará con la llamada a Tcl_DictObjFirst. Punta a una variable que contendrá un valor distinto de cero cuando haya completado la enumeración de los pares clave/valor en un diccionario, y un cero en caso contrario.

Indica el número de claves que se proporcionarán en la matriz keyv.
Tcl_Obj *const *keyv (in)
Matriz de keyc punteros a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList utilizarán para localizar el par clave/valor a manipular dentro de los sub-diccionarios del valor de diccionario principal que se les pasa.

DESCRIPCIÓN

Los valores de diccionario de Tcl tienen una representación interna que soporta un mapeo eficiente de claves a valores y que garantiza que el orden particular de las claves dentro del diccionario permanece el mismo módulo cualquier clave que se elimine (lo que las elimina del orden) o que se añada (lo que las añade al final del orden). Si se reinterpretan como una lista, los valores en los índices de valor par de la lista serán las claves del diccionario, y cada uno será seguido (en el índice de valor impar) por el valor asociado con esa clave.

Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde código C.

Tcl_NewDictObj crea un nuevo valor de diccionario vacío. La representación de cadena del valor será inválida y el contador de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario dado y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o un NULL si la clave no tiene mapeo dentro del diccionario. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir a un diccionario.

Tcl_DictObjPut actualiza el diccionario dado para que la clave dada mapee al valor dado; cualquier clave puede existir como máximo una vez en cualquier diccionario particular. El diccionario no debe compartirse, pero la clave y el valor sí. Este procedimiento puede aumentar el contador de referencias de la clave y del valor si resulta necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir a un diccionario.

Tcl_DictObjRemove actualiza el diccionario dado para que la clave dada no tenga ningún mapeo a ningún valor. El diccionario no debe compartirse, pero la clave sí. La clave realmente almacenada en el diccionario tendrá su contador de referencias decrementado si estaba presente. No es un error si la clave no existía previamente. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir a un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario dado. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir a un diccionario.

Tcl_DictObjFirst inicia una iteración sobre todos los pares clave/valor en el diccionario dado, colocando la clave y el valor en las variables apuntadas por los argumentos keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que el llamador no está interesado en la clave o el valor respectivamente.) El siguiente par clave/valor en el diccionario se puede recuperar con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modificarán el procesamiento de la iteración a menos que el diccionario no esté compartido, cuando esto activará una terminación prematura de la iteración en su lugar (lo cual los scripts de Tcl no pueden activar a través del comando dict.) El argumento searchPtr apunta a una pieza de contexto que se utiliza para identificar qué iteración particular se está realizando, y se inicializa con la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero si hay más pares clave/valor para iterar, o a un valor distinto de cero si la iteración está completa. El orden de iteración está definido por la implementación. Si el argumento dictPtr no se puede convertir a un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y de lo contrario devuelve TCL_OK.

Cuando se llama a Tcl_DictObjFirst en un diccionario, se coloca un bloqueo en el diccionario para permitir que ese diccionario se itere de forma segura sin tener en cuenta si el diccionario se modifica durante la iteración. Debido a esto, una vez que la iteración sobre las claves de un diccionario ha finalizado (ya sea porque se han iterado todos los valores, como indica que la variable indicada por el argumento donePtr está establecida en uno, o porque no se requieren más valores) la función Tcl_DictObjDone *debe* llamarse con el mismo searchPtr que se pasó a Tcl_DictObjFirst para que los bloqueos internos puedan liberarse. Una vez que se pasa un searchPtr particular a Tcl_DictObjDone, pasarlo a Tcl_DictObjNext (sin inicializarlo primero con Tcl_DictObjFirst) resultará en que no se produzcan valores y que la variable apuntada por donePtr se establezca en uno. Es seguro llamar a Tcl_DictObjDone varias veces en el mismo searchPtr por cada llamada a Tcl_DictObjFirst.

Los procedimientos Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son los análogos directos de Tcl_DictObjPut y Tcl_DictObjRemove respectivamente, excepto que en lugar de trabajar con un solo diccionario, están diseñados para operar en un árbol anidado de diccionarios, con diccionarios internos almacenados como valores dentro de diccionarios externos. Los argumentos keyc y keyv especifican una lista de claves (con las claves más externas primero) que actúa como ruta hacia el par clave/valor a afectar. Tenga en cuenta que no existe una operación correspondiente para leer un valor para una lista de claves.

DESCRIPTION

These functions provide an interface for manipulating Tcl dictionary objects. Dictionary objects are Tcl objects with type TCL_OBJTYPE_DICT. They store key-value pairs. The keys and values are themselves Tcl objects.

Tcl_DictObjPut inserts a key-value pair into the dictionary object dictPtr. If the key keyPtr already exists in the dictionary, its value is updated to valuePtr. Otherwise, a new key-value pair is added. The function returns TCL_OK if the operation was successful, and TCL_ERROR otherwise. The caller is responsible for managing the reference counts of the key and value objects.

Tcl_DictObjGet retrieves the value associated with the key keyPtr from the dictionary object dictPtr. If the key is found, the associated value object is stored in valuePtrPtr and the function returns TCL_OK. If the key is not found, valuePtrPtr is set to NULL and the function returns TCL_OK. If the dictionary object is not of type dictionary, TCL_ERROR is returned.

Tcl_DictObjFirst initializes a dictionary search object searchPtr for iterating over the dictionary dictPtr. It retrieves the first key and value object, storing them in keyPtrPtr and valuePtrPtr respectively. The donePtr is set to 1 if the dictionary is empty, and 0 otherwise. This function should be called before using Tcl_DictObjNext.

Tcl_DictObjNext continues the dictionary iteration. It retrieves the next key and value object, storing them in keyPtrPtr and valuePtrPtr respectively. The donePtr is set to 1 if the end of the dictionary has been reached, and 0 otherwise.

Tcl_DictObjKey returns the current key object in the iteration. The returned object should not be modified.

Tcl_DictObjValue returns the current value object in the iteration. The returned object should not be modified.

Tcl_DictObjDone cleans up the dictionary search object searchPtr. This should be called after the iteration is complete.

Tcl_DictObjRemoveKeyList removes the entry specified by the key list keyList from the dictionary dictPtr. If any non-terminal keys in the list do not exist or do not have dictionary values, an error is returned. The function returns TCL_OK on success and TCL_ERROR on failure.

Tcl_DictObjPutKeyList inserts a value into a nested dictionary structure specified by the key list keyList. If intermediate dictionaries do not exist, they are created. The value valuePtr is inserted at the location specified by the final key in the list. The function returns TCL_OK on success and TCL_ERROR on failure.

Tcl_DictObjDelete removes the entry specified by the key keyPtr from the dictionary dictPtr.

Tcl_DictObjSize returns the number of key-value pairs in the dictionary dictPtr.

Tcl_DictObjClear removes all key-value pairs from the dictionary dictPtr.

Nested dictionaries can be constructed with a path such as this through repeated use of Tcl_DictObjGet. With Tcl_DictObjPutKeyList, nested dictionaries are created for non-terminal keys where they do not already exist. With Tcl_DictObjRemoveKeyList, all non-terminal keys must exist and have dictionaries as their values.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters. This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used. The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
