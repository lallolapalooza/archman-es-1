Tcl_BackgroundError(3) Procedimientos de la biblioteca Tcl Tcl_BackgroundError(3)

NOMBRE

Tcl_BackgroundException, Tcl_BackgroundError - reportar excepción de Tcl que ocurrió en procesamiento en segundo plano

SINOPSIS

#include <tcl.h>

Tcl_BackgroundException(interp, code)

Tcl_BackgroundError(interp)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que ocurrió la excepción.
int code (entrada)
El código de retorno excepcional a reportar.

DESCRIPCIÓN

Este procedimiento se invoca típicamente cuando una excepción de Tcl (cualquier código de retorno que no sea TCL_OK) ocurre durante el “procesamiento en segundo plano” como la ejecución de un manejador de eventos. Cuando ocurre tal excepción, la condición se reporta a Tcl o a un widget o algún otro código C, y no suele haber una forma obvia para que ese código informe la excepción al usuario. En estos casos, el código llama a Tcl_BackgroundException con un argumento interp que identifica el intérprete en el que ocurrió la excepción, y un argumento code que contiene el valor del código de retorno de la excepción. El estado del intérprete, incluyendo cualquier mensaje de error en el resultado del intérprete, y los valores de cualquier entrada en el diccionario de opciones de retorno, se captura y guarda. Tcl_BackgroundException organiza para que el bucle de eventos invoque en algún momento posterior el comando registrado en ese intérprete para manejar errores en segundo plano mediante el comando interp bgerror, pasando los valores capturados como argumentos. El comando manejador registrado está destinado a reportar la excepción de una manera específica de la aplicación. El comando manejador recibe dos argumentos, el resultado del intérprete y las opciones de retorno del intérprete en el momento en que ocurrió el error. Si la aplicación no registra un comando manejador, el comando manejador predeterminado intentará llamar a bgerror para reportar el error. Si surge una condición de error al invocar el comando manejador, entonces Tcl_BackgroundException reporta el error imprimiendo un mensaje en el archivo de error estándar.

Tcl_BackgroundException no invoca el comando manejador inmediatamente porque esto podría interferir potencialmente con los scripts que están en proceso en el momento en que ocurrió el error. En su lugar, invoca el comando manejador más tarde como una devolución de llamada inactiva.

Es posible que muchas excepciones en segundo plano se acumulen antes de que se invoque el comando manejador. Cuando esto sucede, cada una de las excepciones se procesa en orden. Sin embargo, si el comando manejador devuelve una excepción de interrupción (break), se omiten todos los informes de error restantes para el intérprete.

La rutina Tcl_BackgroundError es una interfaz más antigua y simple útil cuando el código de excepción reportado es TCL_ERROR. Es equivalente a:

Tcl_BackgroundException(interp, TCL_ERROR);
