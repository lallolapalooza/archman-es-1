ARGUMENTOS

Tcl_Interp *interp (in)
Si ocurre un error al convertir un valor en un valor de diccionario, se deja un mensaje de error en el valor de resultado del interprete, a menos que interp sea NULL.
Tcl_Obj *dictPtr (in/out)
Apunta a un valor de diccionario a manipular. Si dictPtr no ya apunta a un valor de diccionario, se intentará convertirlo.
Tcl_Obj *keyPtr (in)
Apunta a la clave para la pares clave/valor a manipular dentro del valor de diccionario.
Tcl_Obj **keyPtrPtr (out)
Apunta a una variable que contendrá la clave de un par clave/valor. Puede ser NULL para indicar que el llamante no quiere la clave.
Tcl_Obj *valuePtr (in)
Apunta a la valor de la clave/valor a manipular dentro del valor de diccionario (o sub-valor en el caso de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (out)
Apunta a una variable que contendrá el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, puede ser NULL para indicar que el llamante no quiere el valor.
int *sizePtr (out)
Apunta a una variable que contendrá el número de pares clave/valor en el diccionario.
Tcl_DictSearch *searchPtr (in/out)
Apuntador a un registro para mantener el seguimiento de la progresión en el enumerado de todos los pares clave/valor en un diccionario. Los contenidos del registro se inicializan mediante la llamada a Tcl_DictObjFirst. Si se desea terminar la iteración antes de que todos los valores del diccionario hayan sido devueltos, el registro de búsqueda debe ser pasado a Tcl_DictObjDone para liberar los bloques de seguridad internos.
int *donePtr (out)
Apunta a una variable que contendrá un valor no cero cuando la iteración de pares clave/valor en un diccionario ha completado, y cero en caso contrario.
int keyc (in)
Indica el número de claves que se proporcionarán en el array keyv.
Tcl_Obj *const *keyv (in)
Array de keyc apuntadores a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList usarán para localizar el par clave/valor a afectar dentro de los sub-diccionarios del valor principal del diccionario.

DESCRIPCIÓN

Los valores de diccionario Tcl tienen una representación interna que soporta el mapeo eficiente de claves a valores y garantiza que el orden de las claves dentro del diccionario permanezca el mismo, excepto si se eliminan (que los remueven del orden) o se añaden (que los añaden al final del orden). Si se reinterpretan como una lista, los valores en los índices pares de la lista serán las claves del diccionario, y cada una se seguirá (en el índice impar) por el valor asociado a esa clave.

Las funciones descritas en esta página de manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde el código C.

Tcl_NewDictObj crea un nuevo valor de diccionario vacío. La representación de cadena del valor será inválida, y el contador de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o NULL si no hay mapeo para esa clave en el diccionario. El resultado de esta operación es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido en un diccionario.

Tcl_DictObjPut actualiza el diccionario para que la clave dada mapee al valor dado; cualquier clave puede existir en un diccionario como máximo una vez. El diccionario no debe ser compartido, pero la clave y el valor sí pueden. Esta operación puede incrementar el contador de referencias tanto de la clave como del valor si es necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de esta operación es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido en un diccionario.

Tcl_DictObjRemove actualiza el diccionario para que la clave dada no mapee a ningún valor. El diccionario no debe ser compartido, pero la clave sí puede. La clave que realmente se almacena en el diccionario decrementará su contador de referencias si estaba presente. No es un error si la clave no existía previamente. El resultado de esta operación es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido en un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario. El resultado de esta operación es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido en un diccionario.

Tcl_DictObjFirst comienza la iteración sobre todos los pares clave/valor en el diccionario, colocando la clave y el valor en las variables apuntadas por keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que el llamante no quiere la clave o el valor respectivamente). El siguiente par clave/valor en el diccionario puede ser obtenido con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modifican la iteración, excepto si el diccionario no está compartido, en cuyo caso se detendrá la iteración prematuramente (lo cual no puede ser provocado por el comando dict en scripts Tcl). El argumento searchPtr apunta a un contexto que se usa para identificar cuál iteración específica se está realizando, y se inicializa con la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero si hay más pares clave/valor por iterar, o a no cero si la iteración ha terminado. El orden de iteración está definido por la implementación. Si dictPtr no puede ser convertido en un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y de lo contrario devuelve TCL_OK.

Cuando se llama Tcl_DictObjFirst a un diccionario, se coloca un bloque de control en el diccionario para que pueda ser iterado de forma segura sin importar si el diccionario se modifica durante la iteración. Debido a esto, una vez que la iteración sobre los pares clave de un diccionario ha terminado (ya sea porque el número de valores iterados ha sido completo indicado por el argumento donePtr ha sido seteado a uno, o porque no se requieren más valores), debe llamarse Tcl_DictObjDone con el mismo searchPtr que fue pasado a Tcl_DictObjFirst para liberar los bloques de control internos. Una vez que un searchPtr específico ha sido pasado a Tcl_DictObjDone, pasar a Tcl_DictObjNext (sin primero inicializarlo con Tcl_DictObjFirst) resultará en la producción de ningún valor y el variable apuntada por donePtr será seteada a uno. Es seguro llamar Tcl_DictObjDone múltiples veces en el mismo searchPtr para cada llamada a Tcl_DictObjFirst.

Las funciones Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son análogas a Tcl_DictObjPut y Tcl_DictObjRemove, excepto que trabajan con un árbol de diccionarios anidados en lugar de un único diccionario. Los argumentos keyc y keyv especifican una lista de claves (con claves más externas primero) que actúa como un camino hacia el par clave/valor a afectar. ARGUMENTS

Tcl_Interp *interp (in)
Interpreter to use for error reporting.
Tcl_Obj *dictPtr (in)
The dictionary object to modify or query.
Tcl_Obj *keyPtr (in)
The key object.
Tcl_Obj *valuePtr (in)
The value object.
Tcl_Obj **valuePtrPtr (out)
If non-NULL, this will be set to a pointer to the value object associated with the key.
Tcl_DictSearch *searchPtr (in/out)
Pointer to a dictionary search structure.
int *donePtr (out)
Flag indicating if the iteration is finished.
Tcl_Obj *keyList (in)
A list object containing keys.

DESCRIPTION

The Tcl dictionary type provides a versatile mechanism for storing and retrieving key-value pairs. The functions described here allow for programmatic manipulation of Tcl dictionaries.

Tcl_DictObjPut inserts a key-value pair into the dictionary specified by dictPtr. If the key already exists, its value is updated. If the key does not exist, a new entry is created. The interpreter's result is set to a Tcl object representing the dictionary. Returns TCL_OK on success, TCL_ERROR otherwise.

Tcl_DictObjGet retrieves the value associated with keyPtr from the dictionary dictPtr. If valuePtrPtr is not NULL, it is set to point to the value object. Returns TCL_OK if the key is found, TCL_ERROR if the key is not found or an error occurs.

The functions Tcl_DictObjSearch, Tcl_DictObjNext, and Tcl_DictObjDone provide an interface for iterating over the key-value pairs in a dictionary. Tcl_DictObjSearch initializes a search structure pointed to by searchPtr, obtaining the first key and value. Tcl_DictObjNext advances the search to the next key-value pair. Tcl_DictObjDone cleans up the search structure. The iteration can be used to search for specific keys or values, or to process all entries in the dictionary.

Tcl_DictObjPutKeyList is similar to Tcl_DictObjPut, but allows for insertion of a value at a potentially nested key path specified by keyList. Intermediate dictionary keys are created as needed. For example, if keyList contains {"a", "b", "c"}, this function will ensure that a dictionary exists at path {"a", "b"} and then insert the value associated with key "c" within that dictionary.

Tcl_DictObjRemoveKeyList removes a key-value pair from a dictionary, potentially at a nested path specified by keyList. All intermediate dictionary keys in the path must exist and be dictionaries themselves. This function is useful for cleaning up nested dictionary structures.

The nested dictionary manipulation functions Tcl_DictObjPutKeyList and Tcl_DictObjRemoveKeyList are particularly useful for managing complex, hierarchical data structures within Tcl. They simplify the process of creating and modifying nested dictionaries, reducing the amount of boilerplate code required.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters.  This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used.  The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
