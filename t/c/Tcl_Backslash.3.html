Tcl_Backslash(3) Procedimientos de la biblioteca Tcl Tcl_Backslash(3)

NOMBRE

Tcl_Backslash - analizar una secuencia de barra invertida

SINOPSIS

#include <tcl.h>

char
Tcl_Backslash(src, countPtr)

ARGUMENTOS

const char *src (entrada)
Puntero a una cadena que comienza con una barra invertida.
int *countPtr (salida)
Si countPtr no es NULL, *countPtr se llena con el número de caracteres de la secuencia de barra invertida, incluido el carácter de barra invertida.

DESCRIPCION

El uso de Tcl_Backslash está obsoleto en favor de Tcl_UtfBackslash.

Este es un procedimiento de utilidad proporcionado para la compatibilidad con versiones anteriores con extensiones de Tcl no internacionalizadas. Analiza una secuencia de barra invertida y devuelve el byte bajo del carácter Unicode correspondiente a la secuencia. Tcl_Backslash modifica *countPtr para contener el número de caracteres en la secuencia de barra invertida.

Consulte la entrada del manual de Tcl para obtener información sobre las secuencias de barra invertida válidas. Todas las secuencias descritas en la entrada del manual de Tcl son compatibles con Tcl_Backslash.

VER TAMBIÉN

Tcl(n), Tcl_UtfBackslash(3)
