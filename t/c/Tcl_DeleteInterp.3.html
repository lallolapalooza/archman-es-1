Tcl_CrearInterp(3) Procedimientos de la biblioteca Tcl Tcl_CrearInterp(3)

NOMBRE

Tcl_CrearInterp, Tcl_DeleteInterp, Tcl_InterpActiv, Tcl_InterpDeletado - crear y eliminar intérpretes de comandos Tcl

SINOPSIS

#include <tcl.h>

Tcl_Interp *
Tcl_CrearInterp()

Tcl_DeleteInterp(interp)

int
Tcl_InterpActiv(interp)

int
Tcl_InterpDeletado(interp)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Token para el intérprete a ser destruido o consultado.

DESCRIPCIÓN

Tcl_CrearInterp crea una nueva estructura de intérprete y devuelve un token para ella. El token es necesario en llamadas a otros procedimientos Tcl, como Tcl_CrearComando, Tcl_Eval y Tcl_DeleteInterp. El token devuelto por Tcl_CrearInterp solo puede ser pasado a procedimientos Tcl llamados desde el mismo hilo que la llamada original a Tcl_CrearInterp. No es seguro para múltiples hilos pasar el mismo token a procedimientos Tcl. El nuevo intérprete se inicializa con los comandos de la biblioteca Tcl y con variables estándar como tcl_platform y env. Para vincular comandos adicionales, llame a Tcl_CrearComando, y para crear variables adicionales, llame a Tcl_SetVar.

Tcl_DeleteInterp marca un intérprete como destruido; el intérprete se eliminará eventualmente cuando todas las llamadas a Tcl_Preserve para él hayan sido igualadas con llamadas a Tcl_Release. En ese momento, todos los recursos asociados con él, incluidos variables, procedimientos y enlaces de comandos específicos de la aplicación, se eliminarán. Después de que Tcl_DeleteInterp devuelva, cualquier uso de Tcl_Eval en este intérprete fallará y devolverá TCL_ERROR. Después de la llamada a Tcl_DeleteInterp, es seguro examinar el resultado del intérprete, consultar o definir, anular o recuperar valores de variables, y examinar la pila de evaluación en tiempo real. Vea la sección INTÉRPRETES Y GESTIÓN DE MEMORIA para más detalles.

Tcl_InterpDeletado devuelve un valor distinto de cero si se llamó a Tcl_DeleteInterp con interp como argumento; esto indica que el intérprete se eliminará eventualmente, cuando la última llamada a Tcl_Preserve para él coincida con una llamada a Tcl_Release. Si devuelve un valor distinto de cero, cualquier uso de Tcl_Eval en este intérprete devolverá TCL_ERROR.

Tcl_InterpDeletado es útil en callbacks de eliminación para distinguir entre cuándo solo se está eliminando la memoria de la que es responsable el callback y cuándo se está eliminando el propio intérprete. En el primer caso, el callback puede recrear los datos que se están eliminando, pero esto podría provocar un ciclo infinito si el intérprete se está eliminando.

Tcl_InterpActiv es útil para determinar si hay ejecuciones de scripts en un intérprete, lo cual es información útil cuando Tcl está incrustado en un entorno de recolección de basura y es necesario determinar si el intérprete es un candidato para su eliminación. La función devuelve verdadero si el intérprete tiene al menos una ejecución activa dentro de él, y falso en caso contrario.

INTÉRPRETES Y GESTIÓN DE MEMORIA

Tcl_DeleteInterp puede llamarse en cualquier momento en un intérprete que pueda ser utilizado por evaluaciones internas y C en diversas extensiones. Tcl implementa un mecanismo simple que permite a los llamadores usar intérpretes sin tener que preocuparse por su eliminación en llamadas internas, y sin requerir código especial para protegerlos, en la mayoría de los casos. Este mecanismo garantiza que los usuarios de intérpretes dentro de llamadas internas puedan continuar usándolos incluso después de que Tcl_DeleteInterp se haya llamado.

El mecanismo depende de la coincidencia de llamadas a Tcl_Preserve con llamadas a Tcl_Release. Si se ha llamado a Tcl_DeleteInterp, el intérprete solo se liberará cuando la última llamada a Tcl_Preserve haya sido igualada con una llamada a Tcl_Release. Consulte la entrada del manual para Tcl_Preserve para describir estas funciones.

Las reglas para cuándo el usuario debe llamar a Tcl_Preserve y Tcl_Release son simples:

Intérpretes Pasados como Argumentos
Las funciones que reciben un intérprete como argumento pueden usar el intérprete de forma segura sin necesidad de protección especial. Por lo tanto, cuando escriba una extensión compuesta por nuevos comandos Tcl, no se requiere código especial para proteger los intérpretes recibidos como argumentos. Esto cubre la mayoría de los usos.
Creación y Eliminación de Intérpretes
Al crear un nuevo intérprete y usarlo en una llamada a Tcl_Eval, Tcl_VarEval, Tcl_GlobalEval, Tcl_SetVar, o Tcl_GetVar, se deben envolver todos los usos del intérprete con un par de llamadas a Tcl_Preserve y Tcl_Release. Recuerde que es inseguro usar el intérprete una vez que se ha llamado a Tcl_Release. Para asegurar que el intérprete se elimine correctamente cuando ya no lo necesite, llame a Tcl_InterpDeletado para verificar si algún otro código ya llamó a Tcl_DeleteInterp; si no lo ha hecho, llame a Tcl_DeleteInterp antes de llamar a Tcl_Release en su código.
Recuperación de un Intérprete de una Estructura de Datos
Al recuperar un intérprete de una estructura de datos (por ejemplo, el cliente de un callback) para usarlo en una de las funciones de evaluación (Tcl_Eval, Tcl_VarEval, Tcl_GlobalEval, Tcl_EvalObjv, etc.) o en funciones de acceso a variables (Tcl_SetVar, Tcl_GetVar, Tcl_SetVar2Ex, etc.) se deben envolver todos los usos del intérprete con un par de llamadas a Tcl_Preserve y Tcl_Release; es inseguro reutilizar el intérprete una vez que se ha llamado a Tcl_Release. Si el intérprete está almacenado dentro de una estructura de datos de callback, el mecanismo de eliminación adecuado debe ser establecido por el código que crea la estructura para que el intérprete se elimine de la estructura (por ejemplo, estableciendo el campo a NULL) cuando se elimina el intérprete. De lo contrario, podría estar utilizando un intérprete que ya ha sido liberado y cuya memoria podría haberse reutilizado.

Todos los usos de intérpretes en Tcl y Tk ya están protegidos. Los redactores de extensiones deben asegurarse de que su código también proteja adecuadamente cualquier otro intérprete utilizado, como se describe arriba.

Nota: Los mecanismos de protección no funcionan bien con sistemas de recolección de basura convencionales. Cuando se encuentre en un entorno gestionado, Tcl_InterpActiv debe usarse para determinar cuándo un intérprete es un candidato para su eliminación debido a su inactividad.

Tcl_DeleteInterp

Tcl_DeleteInterp - destruye un intérprete de Tcl

Sintaxis

#include <tcl.h>

int
Tcl_DeleteInterp(interp)
    Tcl_Interp *interp;

Descripción

La rutina Tcl_DeleteInterp destruye el intérprete especificado por interp. Todas las variables, comandos, registros y otros objetos asociados con el intérprete se liberan. Después de llamar a Tcl_DeleteInterp, el puntero interp ya no es válido y no se debe utilizar.

Argumentos

interp (in)
Puntero al intérprete que se va a destruir.

Devolución

La rutina Tcl_DeleteInterp no devuelve ningún valor.

Ejemplo

Tcl_Interp *interp = Tcl_CreateInterp();
// ... usar el intérprete ...
Tcl_DeleteInterp(interp);
