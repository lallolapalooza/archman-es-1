Paquete: tcl

Load(3) Procedimientos de la biblioteca Tcl Load(3)

NOMBRE

Tcl_LoadFile, Tcl_FindSymbol - carga de bibliotecas dinámicas independiente de la plataforma

SINOPSIS

#include <tcl.h>

int
Tcl_LoadFile(interp, pathPtr, symbols, flags, procPtrs, loadHandlePtr)

void *
Tcl_FindSymbol(interp, loadHandle, symbol)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a utilizar para reportar mensajes de error.
Tcl_Obj *pathPtr (entrada)
El nombre del archivo a cargar. Si es un nombre único, se utilizará la ruta de búsqueda de bibliotecas del entorno actual para resolverlo.
const char *const symbols[] (entrada)
Matriz de nombres de símbolos a resolver durante la carga de la biblioteca, o NULL si no se deben resolver símbolos. Si se proporciona una matriz, la última entrada de la matriz debe ser NULL.
int flags (entrada)
El valor normalmente debe ser 0, pero también se permiten TCL_LOAD_GLOBAL o TCL_LOAD_LAZY o una combinación de ambos.
void *procPtrs (salida)
Puntero a una matriz que contendrá las direcciones de las funciones descritas en el argumento symbols. Debe ser NULL si no se deben resolver símbolos.
Tcl_LoadHandle *loadHandlePtr (salida)
Puntero a una variable que contendrá el manejador (handle) del token abstracto que describe la biblioteca que ha sido cargada.
Tcl_LoadHandle loadHandle (entrada)
Token abstracto que describe la biblioteca en la que buscar un símbolo.
const char *symbol (entrada)
El nombre del símbolo a buscar.

DESCRIPCIÓN

Tcl_LoadFile carga un archivo desde el sistema de archivos (incluyendo potencialmente cualquier sistema de archivos virtual que se haya instalado) y proporciona un manejador para él que puede usarse en operaciones posteriores. La matriz symbols, si no es NULL, suministra un conjunto de nombres de símbolos (típicamente funciones) que deben ser resueltos desde la biblioteca y que se almacenarán en la matriz indicada por procPtrs. Si alguno de los símbolos no se resuelve, la carga del archivo fallará con un mensaje de error dejado en el intérprete (si este no es NULL). El resultado de Tcl_LoadFile es un código de error estándar de Tcl. La biblioteca puede ser descargada con Tcl_FSUnloadFile.

Tcl_FindSymbol localiza un símbolo en una biblioteca cargada y lo devuelve. Si no se encuentra el símbolo, devuelve NULL y establece un mensaje de error en el interp dado (si este no es NULL). Tenga en cuenta que es inseguro usar esta operación en un manejador que haya sido pasado a Tcl_FSUnloadFile.

VER TAMBIÉN

Tcl_FSLoadFile(3), Tcl_FSUnloadFile(3), load(n), unload(n)
