Tcl_RegisterConfig(3) Procedimientos de la biblioteca Tcl Tcl_RegisterConfig(3)

NOMBRE

Tcl_RegisterConfig - procedimientos para registrar información de configuración incrustada

SINOPSIS

#include <tcl.h>

void
Tcl_RegisterConfig(interp, pkgName, configuration, valEncoding)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Se refiere al intérprete para el cual se registra la información de configuración incrustada. No debe ser NULL.
const char *pkgName (entrada)
Contiene el nombre del paquete que registra la información de configuración incrustada como una cadena ASCII. Esto significa que esta información también está en UTF-8. No debe ser NULL.
const Tcl_Config *configuration (entrada)
Se refiere a una matriz de entradas Tcl_Config que contiene la información incrustada en la biblioteca binaria. No debe ser NULL. El final de la matriz se señala mediante una clave idéntica a NULL o una clave que se refiere a la cadena vacía.
const char *valEncoding (entrada)
Contiene el nombre de la codificación utilizada para almacenar los valores de configuración como una cadena ASCII. Esto significa que esta información también está en UTF-8. No debe ser NULL.

DESCRIPCIÓN

La función descrita aquí tiene su base en TIP 59 y proporciona extensiones con soporte para la incrustación de información de configuración en su biblioteca binaria y la generación de una interfaz a nivel de Tcl para consultar esta información.

Para incrustar información de configuración en su biblioteca binaria, una extensión debe definir una matriz no volátil de entradas Tcl_Config en uno de sus archivos fuente y luego llamar a Tcl_RegisterConfig para registrar esa información.

Tcl_RegisterConfig toma cuatro argumentos; primero, una referencia al intérprete con el que estamos registrando la información, segundo, el nombre del paquete que registra su información de configuración, tercero, un puntero a una matriz de estructuras y cuarto, una cadena que declara la codificación utilizada por los valores de configuración.

La cadena valEncoding contiene el nombre de una codificación conocida por Tcl. Todos estos nombres utilizan solo caracteres del subconjunto ASCII de UTF-8 y, por lo tanto, están implícitamente en la codificación UTF-8. Se espera que las claves sean texto legible en inglés y, por lo tanto, que utilicen el subconjunto ASCII de UTF-8. En otras palabras, también se espera que estén en UTF-8. Sin embargo, los valores asociados con las claves pueden ser cualquier cadena. Para estos, el contenido de valEncoding define qué codificación se utilizó para representar los caracteres de las cadenas.

Cada elemento de la matriz configuration se refiere a dos cadenas que contienen la clave y el valor asociados con esa clave. El final de la matriz se señala mediante una clave vacía o una clave idéntica a NULL. La función **no** crea una copia de la matriz configuration. Esto significa que el llamador debe asegurarse de que la memoria que contiene esta matriz nunca se libere. Este es el significado detrás de la palabra **no volátil** utilizada anteriormente. La forma más fácil de lograr esto es definir una matriz estática global de entradas Tcl_Config. Consulte el archivo "generic/tclPkgConfig.c" en las fuentes del núcleo de Tcl para ver un ejemplo.

Cuando se llama, Tcl_RegisterConfig:

(1)
creará un espacio de nombres con el nombre pkgName proporcionado, si aún no existe.
(2)
creará el comando pkgconfig en ese espacio de nombres y lo vinculará a la información proporcionada para que las claves de configuration y sus valores asociados puedan recuperarse mediante llamadas a pkgconfig.

El comando pkgconfig proporcionará dos subcomandos, list y get:

::pkgName::pkgconfig list
Devuelve una lista que contiene los nombres de todas las claves definidas.
::pkgName::pkgconfig get key
Devuelve el valor de configuración asociado con la key especificada.

TCL_CONFIG

La estructura Tcl_Config contiene los siguientes campos:

typedef struct Tcl_Config {
    const char *key;
    const char *value;
} Tcl_Config;
