Tcl_PutEnv(3) Procedimientos de la biblioteca Tcl Tcl_PutEnv(3)

NOMBRE

Tcl_PutEnv - procedimientos para manipular el entorno

SINOPSIS

#include <tcl.h>

int
Tcl_PutEnv(assignment)

ARGUMENTOS

const char *assignment (entrada)
Información sobre la variable de entorno en el formato “NOMBRE=valor”. El argumento assignment está en la codificación del sistema.

DESCRIPCIÓN

Tcl_PutEnv establece una variable de entorno. La información se pasa en una sola cadena de la forma “NOMBRE=valor”. Este procedimiento está destinado a ser un sustituto de la llamada al sistema putenv de UNIX. Todas las aplicaciones basadas en Tcl que utilicen putenv deben redefinirla a Tcl_PutEnv para que se interconecten correctamente con el tiempo de ejecución de Tcl.

VéASE TAMBIÉN

env(n)

PALABRAS CLAVE

entorno, variable
