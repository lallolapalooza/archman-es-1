Tcl_AllowExceptions(3) Procedimientos de la biblioteca Tcl Tcl_AllowExceptions(3)

NOMBRE

Tcl_AllowExceptions - permitir todas las excepciones en la próxima evaluación de script

SINOPSIS

#include <tcl.h>

Tcl_AllowExceptions(interp)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que se evaluará el script.

DESCRIPCIÓN

Si un script se evalúa en el nivel superior (es decir, no hay otros scripts pendientes de evaluación cuando se invoca el script), y si el script termina con un código de finalización distinto de TCL_OK, TCL_ERROR o TCL_RETURN, Tcl normalmente lo convierte en un código de retorno TCL_ERROR con un mensaje apropiado. Los procedimientos de evaluación de scripts de Tcl que actúan de esta manera son Tcl_EvalObjEx, Tcl_EvalObjv, Tcl_Eval, Tcl_EvalEx, Tcl_GlobalEval, Tcl_GlobalEvalObj, Tcl_VarEval y Tcl_VarEvalVA.

Sin embargo, si se invoca Tcl_AllowExceptions inmediatamente antes de llamar a uno de esos procedimientos, se permiten códigos de finalización arbitrarios del script y se devuelven sin modificación. Esto es útil en casos en los que el llamador puede manejar excepciones como TCL_BREAK o TCL_CONTINUE de una manera significativa.
