ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el que se creará o encontrará el conjunto. También donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres empiezan con Tcl_GetEnsemble pueden tener un valor NULL para el interp, pero todas las demás funciones no deben tenerlo.
const char *name (entrada)
El nombre del comando del conjunto que se va a crear.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres al que se va a vincular el comando del conjunto, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto OR'ed de bits de bandera que describen la configuración básica del conjunto. Actualmente, solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando del conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando del conjunto a buscar.
int flags (entrada)
Un conjunto OR'ed de bits de bandera que controlan el comportamiento de Tcl_FindEnsemble. Actualmente solo se admite TCL_LEAVE_ERR_MSG.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para pruebas como un comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la que escribir los bits de bandera actuales del conjunto; actualmente, solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario para usar como mapeo de subcomando a prefijo de comando de implementación en el conjunto. Puede ser NULL si se va a eliminar el diccionario de mapeo.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la que escribir el diccionario de mapeo actual del conjunto.
Tcl_Obj *listObj (entrada)
Un valor de lista para usar como lista de parámetros formales previos al subcomando, la lista definida de subcomandos en el diccionario o el prefijo de comando del manejador de subcomandos desconocido. Puede ser NULL si la lista de subcomandos o el manejador desconocido van a ser eliminados.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la que escribir la lista formal actual de parámetros previos al subcomando, la lista definida de subcomandos o el prefijo del manejador desconocido actual.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la que escribir el manejador del espacio de nombres al que está vinculado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, vinculado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos Tcl. El primer argumento del comando del conjunto se interpreta siempre como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean utilizando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete en el que trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que vincular el conjunto, y el conjunto predeterminado de banderas de conjunto. El resultado de la función es el token del comando para el conjunto, que puede utilizarse para configurar aún más el conjunto utilizando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token de ese comando puede recuperarse utilizando Tcl_FindEnsemble. Si el nombre del comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Se puede comprobar un token de comando para ver si se refiere a un conjunto utilizando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

flags (lectura/escritura)
El conjunto de banderas para el conjunto, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX, que se establece cuando los prefijos no ambiguos de los subcomandos se permiten resolver a implementaciones, así como coincidencias exactas. Las banderas pueden leerse y escribirse utilizando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el propio comando del conjunto y el nombre del subcomando), o NULL si cada subcomando debe mapearse al comando con el mismo nombre no calificado en el espacio de nombres vinculado del conjunto. Por defecto es NULL. Puede leerse y escribirse mediante Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable, incluso si no está compartido. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros previos al subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se utilizan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Puede leerse y escribirse mediante Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable, incluso si no está compartido.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto se deriva de las claves del diccionario de mapeo (ver arriba) o (si también es NULL) del conjunto de comandos exportados por el espacio de nombres vinculado. Puede leerse y escribirse mediante Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable incluso si no está compartida.

Tcl_SetEnsembleUnknownHandler(3)

NAME

Tcl_SetEnsembleUnknownHandler, Tcl_GetEnsembleUnknownHandler - control the handler for unknown subcommands in an ensemble

SYNOPSIS

#include <tcl.h>

int
Tcl_SetEnsembleUnknownHandler(ensembleToken, handler);
int
Tcl_GetEnsembleUnknownHandler(ensembleToken, handlerPtr);

ARGUMENTS

Tcl_Obj *ensembleToken
Token for the ensemble whose unknown handler is to be set or retrieved.
Tcl_Obj *handler
The new handler for unknown subcommands. This is a Tcl list, where the first element is the name of a command or procedure to call, and subsequent elements are arguments to be passed to that command or procedure. If NULL, any existing unknown handler is removed and the default behavior is restored.
Tcl_Obj **handlerPtr
If non-NULL, the handler for unknown subcommands is written here as a Tcl list. The list is guaranteed to be valid, and may be shared or unshared. handlerPtr is set to NULL if there is no unknown handler set (i.e., if the default behavior is in effect).

DESCRIPTION

The Tcl_SetEnsembleUnknownHandler function establishes a handler to be invoked when an unknown subcommand is supplied to an ensemble. The ensembleToken argument is a token previously returned by a call to Tcl_CreateEnsemble. The handler argument is a Tcl list that specifies the command or procedure to invoke, along with any fixed arguments. The first element of the list should be a string representing the name of a command or procedure. If the ensemble is part of a namespace, this command or procedure may be namespaced. Any subsequent elements of the list are arguments that will be passed to the handler command or procedure. The actual subcommand name and its arguments will be appended to this list when the handler is invoked.

If handler is NULL, any existing unknown handler for the ensemble is removed, and the ensemble reverts to its default behavior, which is to generate a suitable error message indicating that the subcommand was not recognized.

The Tcl_GetEnsembleUnknownHandler function retrieves the current unknown handler for the ensemble specified by ensembleToken. If an unknown handler is currently set, the handler is stored in the Tcl list pointed to by handlerPtr. If no unknown handler is set (i.e., the ensemble is using its default behavior), handlerPtr is set to NULL. The caller is responsible for managing the memory associated with the list returned in handlerPtr if it is unshared. This function returns a Tcl result code: TCL_OK on success, and TCL_ERROR if ensembleToken does not refer to a valid ensemble.

The unknown handler mechanism is described in detail in the documentation for the namespace ensemble command. The list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.

bound namespace (read-only)

The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).
