Tcl_GetNameOfExecutable(3)

Paquete: tcl

Licencias: TCL

Tcl_FindExecutable(3) Procedimientos de la biblioteca Tcl Tcl_FindExecutable(3)

NOMBRE

Tcl_FindExecutable, Tcl_GetNameOfExecutable - identificar o devolver el nombre del archivo binario que contiene la aplicación

SINOPSIS

#include <tcl.h>

void
Tcl_FindExecutable(argv0)

const char *
Tcl_GetNameOfExecutable()

ARGUMENTOS

char *argv0 (entrada)
El primer argumento de la línea de comandos del programa, que da el nombre de la aplicación.

DESCRIPCION

El procedimiento Tcl_FindExecutable calcula el nombre de ruta completo del archivo ejecutable desde el que se invocó la aplicación y lo guarda para uso interno de Tcl. El nombre de ruta del ejecutable es necesario para varios propósitos en Tcl. Por ejemplo, es necesario en algunas plataformas en la implementación del comando load. También es devuelto por el comando info nameofexecutable.

En plataformas UNIX, este procedimiento se invoca típicamente como lo primero que hace el programa principal de la aplicación; debe pasársele argv[0] como argumento. Es importante no cambiar el directorio de trabajo antes de la invocación. Tcl_FindExecutable utiliza argv0 junto con la variable de entorno PATH para encontrar el ejecutable de la aplicación, si es posible. Si no logra encontrar el binario, entonces las llamadas futuras a info nameofexecutable devolverán una cadena vacía.

En plataformas Windows, este procedimiento se invoca típicamente como lo primero que hace el programa principal de la aplicación; Su argumento argv[0] solo se usa para indicar si el ejecutable tiene un canal stderr (cualquier valor no nulo) o no (el valor nulo). Si nunca se llama a Tcl_SetPanicProc y no se está ejecutando un depurador, esto determina si el mensaje de pánico se envía a stderr o a un cuadro de diálogo del sistema estándar.

Tcl_GetNameOfExecutable simplemente devuelve un puntero al nombre de ruta completo interno del archivo ejecutable tal como lo calculó Tcl_FindExecutable. Esta llamada al procedimiento es el equivalente de la API C al comando info nameofexecutable. Se devuelve NULL si el nombre de ruta completo interno no se ha calculado o es desconocido.
