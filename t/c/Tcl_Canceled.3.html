Tcl_Cancel(3) Procedimientos de la biblioteca Tcl Tcl_Cancel(3)

NOMBRE

Tcl_CancelEval, Tcl_Canceled - cancelar scripts de Tcl

SINOPSIS

#include <tcl.h>
int
Tcl_CancelEval(interp, resultObjPtr, clientData, flags)

int
Tcl_Canceled(interp, flags)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que cancelar el script.
Tcl_Obj *resultObjPtr (entrada)
Mensaje de error a usar en la cancelación, o NULL para usar un mensaje predeterminado. Si no es NULL, se decrementará el recuento de referencias de este objeto antes de que Tcl_CancelEval retorne.
int flags (entrada)
Combinación OR de bits de flags que especifican opciones adicionales. Para Tcl_CancelEval, actualmente solo se admite TCL_CANCEL_UNWIND. Para Tcl_Canceled, actualmente solo se admiten TCL_LEAVE_ERR_MSG y TCL_CANCEL_UNWIND.
ClientData clientData (entrada)
Actualmente reservado para uso futuro. Debe establecerse a NULL.

DESCRIPCIÓN

Tcl_CancelEval cancela o desenrolla el script en curso poco después de la próxima invocación de manejadores asíncronos, provocando que TCL_ERROR sea el código de retorno para ese script. Esta función es segura para hilos y puede ser llamada desde cualquier hilo del proceso.

Tcl_Canceled comprueba si el script en curso ha sido cancelado y retorna TCL_ERROR si lo ha sido. De lo contrario, retorna TCL_OK. Las extensiones pueden usar esta función para comprobar si deben abortar un comando de larga ejecución. Esta función es sensible a los hilos y solo puede ser llamada desde el hilo en el que se creó el intérprete.

BITS DE FLAGS

Se puede usar cualquier combinación OR de los siguientes valores para el argumento flags de procedimientos como Tcl_CancelEval:

TCL_CANCEL_UNWIND
Este flag es utilizado por Tcl_CancelEval y Tcl_Canceled. Para Tcl_CancelEval, si este flag está establecido, el script en curso se cancela y se desenrolla la pila de evaluación del intérprete. Para Tcl_Canceled, si este flag está establecido, el script en curso se considera cancelado solo si se está desenrollando la pila de evaluación del intérprete.
TCL_LEAVE_ERR_MSG
Este flag solo es utilizado por Tcl_Canceled; es ignorado por otros procedimientos. Si se retorna un error y este bit está establecido en flags, se dejará un mensaje de error en el resultado del intérprete, donde puede ser recuperado con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de flag no está establecido, no se deja ningún mensaje de error y el resultado del intérprete no se modificará.

VER TAMBIÉN

interp(n), Tcl_Eval(3), TIP 285
