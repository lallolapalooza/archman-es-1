ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene la variable.
const char *name1 (entrada)
Contiene el nombre de una variable de matriz (si name2 no es NULL) o (si name2 es NULL) ya sea el nombre de una variable escalar o un nombre completo que incluye tanto el nombre de la variable como el índice. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular.
const char *name2 (entrada)
Si no es NULL, proporciona el nombre del elemento dentro de la matriz; en este caso, name1 debe referirse a una variable de matriz.
Tcl_Obj *newValuePtr (entrada)
Puntero a un valor Tcl que contiene el nuevo valor para la variable.
int flags (entrada)
Combinación OR de bits que proporcionan información adicional. Ver abajo para valores válidos.
const char *varName (entrada)
Nombre de la variable. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de una matriz.
const char *newValue (entrada)
Nuevo valor para la variable, especificado como una cadena terminada en NULL. Se almacena una copia de este valor en la variable.
Tcl_Obj *part1Ptr (entrada)
Puntero a un valor Tcl que contiene el nombre de la variable. El nombre puede incluir una serie de calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de una variable de matriz.
Tcl_Obj *part2Ptr (entrada)
Si no es NULL, apunta a un valor que contiene el nombre de un elemento dentro de una matriz y part1Ptr debe referirse a una variable de matriz.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar, leer y eliminar variables de Tcl desde código C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 y Tcl_ObjSetVar2 crearán una nueva variable o modificarán una existente. Estos procedimientos establecen la variable dada al valor proporcionado por newValuePtr o newValue y devuelven un puntero al nuevo valor de la variable, que se almacena en la estructura de variables de Tcl. Tcl_SetVar2Ex y Tcl_ObjSetVar2 toman el nuevo valor como un Tcl_Obj y devuelven un puntero a un Tcl_Obj. Tcl_SetVar y Tcl_SetVar2 toman el nuevo valor como una cadena y devuelven una cadena; generalmente son menos eficientes que Tcl_ObjSetVar2. Tenga en cuenta que el valor de retorno puede ser diferente de los argumentos newValuePtr o newValue, debido a las modificaciones realizadas por los rastreos de escritura. Si ocurre un error al establecer la variable (por ejemplo, se hace referencia a una variable de matriz sin proporcionar un índice a la matriz), se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de indicador TCL_LEAVE_ERR_MSG está establecido.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 y Tcl_ObjGetVar2 devuelven el valor actual de una variable. Los argumentos para estos procedimientos se tratan de la misma manera que los argumentos para los procedimientos descritos anteriormente. En circunstancias normales, el valor de retorno es un puntero al valor de la variable. Para Tcl_GetVar2Ex y Tcl_ObjGetVar2 el valor se devuelve como un puntero a un Tcl_Obj. Para Tcl_GetVar y Tcl_GetVar2 el valor se devuelve como una cadena; esto generalmente es menos eficiente, por lo que se prefieren Tcl_GetVar2Ex o Tcl_ObjGetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de matriz para una variable escalar), entonces se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de indicador TCL_LEAVE_ERR_MSG está establecido.

Tcl_UnsetVar y Tcl_UnsetVar2 se pueden usar para eliminar una variable, de modo que los intentos futuros de leer la variable devuelvan un error. Los argumentos para estos procedimientos se tratan de la misma manera que los argumentos para los procedimientos anteriores. Si la variable se elimina con éxito, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si el bit de indicador TCL_LEAVE_ERR_MSG está establecido. Si se especifica un elemento de matriz, se elimina el elemento dado pero la matriz permanece. Si se especifica un nombre de matriz sin un índice, se elimina toda la matriz.

El nombre de una variable puede especificarse a estos procedimientos de cuatro maneras:

[1]
Si se invoca Tcl_SetVar, Tcl_GetVar o Tcl_UnsetVar, el nombre de la variable se proporciona como una sola cadena, varName. Si varName contiene un paréntesis abierto y termina con un paréntesis cerrado, entonces el valor entre los paréntesis se trata como un índice (que puede tener cualquier valor de cadena) y los caracteres antes del primer paréntesis abierto se tratan como el nombre de una variable de matriz. Si varName no tiene paréntesis como se describe anteriormente, entonces toda la cadena se trata como el nombre de una variable escalar.
[2]
Si se proporcionan los argumentos name1 y name2 y name2 no es NULL, entonces se especifica un elemento de matriz y el nombre de la matriz y el índice ya han sido separados por el llamador: name1 contiene el nombre y name2 contiene el índice. Se genera un error si name1 contiene un paréntesis abierto y termina con un paréntesis cerrado (elemento de matriz) y name2 no es NULL.
[3]
Si name2 es NULL, name1 se trata igual que varName en el caso [1] anterior (puede ser el nombre de una variable escalar o un elemento de matriz).

El argumento flags se puede usar para especificar cualquiera de varias opciones a los procedimientos. Consiste en una combinación OR de los siguientes bits.

TCL_GLOBAL_ONLY
En circunstancias normales, los procedimientos buscan variables de la siguiente manera. Si hay una llamada a procedimiento activa en interp, la variable se busca en el nivel actual de llamada a procedimiento. De lo contrario, la variable se busca primero en el espacio de nombres actual, luego en el espacio de nombres global. Sin embargo, si este bit está establecido en flags, entonces la variable solo se busca en el espacio de nombres global, incluso si hay una llamada a procedimiento activa. Si se dan tanto TCL_GLOBAL_ONLY como TCL_NAMESPACE_ONLY, se ignora TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
Si este bit está establecido en flags, entonces la variable solo se busca en el espacio de nombres actual; si un procedimiento está activo, se ignoran sus variables, y el espacio de nombres global también se ignora a menos que sea el espacio de nombres actual.
TCL_LEAVE_ERR_MSG
Si se devuelve un error y este bit está establecido en flags, entonces se dejará un mensaje de error en el resultado del intérprete, donde puede ser recuperado con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de indicador no está establecido, no se dejará ningún mensaje de error y el resultado del intérprete no se modificará.
TCL_APPEND_VALUE
Si este bit está establecido, entonces newValuePtr o newValue se agrega al valor actual en lugar de reemplazarlo. Si la variable no está definida actualmente, entonces se ignora el bit. Este bit solo es utilizado por los procedimientos Tcl_Set*.
TCL_LIST_ELEMENT
Si este bit está establecido, entonces newValue se convierte en un elemento de lista Tcl válido antes de establecer (o agregar a) la variable. Se agrega un espacio separador antes del nuevo

DESCRIPTION

Tcl_SetVar and Tcl_SetVar2 are used to set the value of a Tcl variable. The varNamePtr is a pointer to the name of the variable to modify. If the variable is an array element, then arrayPtr should point to the array name and indexPtr should point to the index. If the variable is a scalar, then arrayPtr and indexPtr should both be NULL. The value argument points to the string that should become the new value of the variable. If value is NULL, then the variable is unset.

The flags argument controls how the variable is accessed. TCL_GLOBAL_ONLY means that the variable is accessed in the global scope, regardless of the current procedure context. TCL_LEAVE_ERR_MSG means that if an error occurs, the error message should be left in the interpreter's result, rather than being overwritten. In addition, if the variable is being set and the flags argument has the TCL_APPEND_VALUE bit set, then the value is appended to the existing value of the variable instead of replacing it. If the variable does not exist, it is created. The appending operation requires that the variable's value must be a list. The value must also be a list. This is not true if the variable is being set to an empty string, or if the variable is being set to the string "{", or if the variable is being set to a string ending in " }". In these cases, the variable is treated as a scalar. If the variable is a list and the value is being appended, the new value should not be treated as a list element unless the list element is going to be the first element in a list or sublist (i.e. the variable's current value is empty, or contains the single character “{”, or ends in “ }”). When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.

Tcl_GetVar and Tcl_GetVar2 return the current value of a variable. The arguments to these procedures are treated in the same way as the arguments to Tcl_SetVar and Tcl_SetVar2. Under normal circumstances, the return value is a pointer to the variable's value (which is stored in Tcl's variable structure and will not change before the next call to Tcl_SetVar or Tcl_SetVar2). Tcl_GetVar and Tcl_GetVar2 use the flag bits TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG, both of which have the same meaning as for Tcl_SetVar. If an error occurs in reading the variable (e.g. the variable does not exist or an array element is specified for a scalar variable), then NULL is returned.

Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a variable, so that future calls to Tcl_GetVar or Tcl_GetVar2 for the variable will return an error. The arguments to these procedures are treated in the same way as the arguments to Tcl_GetVar and Tcl_GetVar2. If the variable is successfully removed then TCL_OK is returned. If the variable cannot be removed because it does not exist then TCL_ERROR is returned. If an array element is specified, the given element is removed but the array remains. If an array name is specified without an index, then the entire array is removed.
