Tcl_ListObj(3) Procedimientos de la biblioteca Tcl Tcl_ListObj(3)

NOMBRE

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipular valores Tcl como listas

SINOPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de lista, se deja un mensaje de error en el resultado del intérprete a menos que interp sea NULL.
Tcl_Obj *listPtr (entrada/salida)
Punta al valor de lista que se va a manipular. Si listPtr no apunta ya a un valor de lista, se intentará convertirlo en uno.
Tcl_Obj *elemListPtr (entrada/salida)
Para Tcl_ListObjAppendList, esto apunta a un valor de lista que contiene elementos para agregar a listPtr. Cada elemento de *elemListPtr se convertirá en un nuevo elemento de listPtr. Si *elemListPtr no es NULL y no apunta ya a un valor de lista, se intentará convertirlo en uno.
Tcl_Obj *objPtr (entrada)
Para Tcl_ListObjAppendElement, apunta al valor Tcl que se agregará a listPtr. Para Tcl_SetListObj, apunta al valor Tcl que se convertirá en un valor de lista que contiene los objc elementos de la matriz referenciada por objv.
int *objcPtr (entrada)
Punta a la ubicación donde Tcl_ListObjGetElements almacena el número de valores de elementos en listPtr.
Tcl_Obj ***objvPtr (salida)
Una ubicación donde Tcl_ListObjGetElements almacena un puntero a una matriz de punteros a los valores de los elementos de listPtr.
int objc (entrada)
El número de valores Tcl que Tcl_NewListObj insertará en un nuevo valor de lista, y Tcl_ListObjReplace insertará en listPtr. Para Tcl_SetListObj, el número de valores Tcl a insertar en objPtr.
Tcl_Obj *const objv[] (entrada)
Una matriz de punteros a valores. Tcl_NewListObj insertará estos valores en un nuevo valor de lista y Tcl_ListObjReplace los insertará en un listPtr existente. Cada valor se convertirá en un elemento de lista separado.
int *lengthPtr (salida)
Punta a la ubicación donde Tcl_ListObjLength almacena la longitud de la lista.
int index (entrada)
Índice del elemento de la lista que Tcl_ListObjIndex debe devolver. El primer elemento tiene el índice 0.
Tcl_Obj **objPtrPtr (salida)
Punta al lugar donde Tcl_ListObjIndex debe almacenar un puntero al valor del elemento de lista resultante.
int first (entrada)
Índice del elemento de lista inicial que Tcl_ListObjReplace debe reemplazar. El primer elemento de la lista tiene el índice 0.
int count (entrada)
El número de elementos que Tcl_ListObjReplace debe reemplazar.

DESCRIPCIÓN

Los valores de lista de Tcl tienen una representación interna que soporta la indexación y la adición eficientes. Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar y agregar a valores de lista de Tcl desde código C.

Tcl_ListObjAppendList y Tcl_ListObjAppendElement ambos agregan uno o más valores al final del valor de lista referenciado por listPtr. Tcl_ListObjAppendList agrega cada elemento del valor de lista referenciado por elemListPtr, mientras que Tcl_ListObjAppendElement agrega el valor único referenciado por objPtr. Ambos procedimientos convertirán el valor referenciado por listPtr en un valor de lista si es necesario. Si ocurre un error durante la conversión, ambos procedimientos devuelven TCL_ERROR y dejan un mensaje de error en el resultado del intérprete si interp no es NULL. De manera similar, si elemListPtr no se refiere ya a un valor de lista, Tcl_ListObjAppendList intentará convertirlo en uno y, si ocurre un error durante la conversión, devolverá TCL_ERROR y dejará un mensaje de error en el resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió en un valor de lista, liberan cualquier representación interna antigua. De manera similar, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si lo convierte en un valor de lista. Después de agregar cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento ya que listPtr también se refiere a él. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no ocurre ningún error, los dos procedimientos devuelven TCL_OK después de agregar los valores.

Tcl_NewListObj y Tcl_SetListObj crean un nuevo valor o modifican un valor existente para contener los objc elementos de la matriz referenciada por objv, donde cada elemento es un puntero a un valor Tcl. Si objc es menor o igual a cero, devuelven un valor vacío. Si objv es NULL, la lista resultante contiene 0 elementos, con espacio reservado en una representación interna para objc elementos más (para evitar su reasignación posterior). La representación de cadena del nuevo valor se deja invalidada. Los dos procedimientos incrementan los contadores de referencia de los elementos en objc ya que el valor de lista ahora se refiere a ellos. El nuevo valor de lista devuelto por Tcl_NewListObj tiene un contador de referencia cero.

Tcl_ListObjGetElements devuelve un conteo y un puntero a una matriz de los elementos en un valor de lista. Devuelve el conteo almacenándolo en la dirección objcPtr. De manera similar, devuelve el puntero de la matriz almacenándolo en la dirección objvPtr. La memoria apuntada es gestionada por Tcl y no debe ser liberada ni escrita por el llamador. Si la lista está vacía, se almacena 0 en objcPtr y NULL en objvPtr. Si listPtr no es ya un valor de lista, Tcl_ListObjGetElements intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar el conteo y el puntero de la matriz.

Tcl_ListObjLength devuelve el número de elementos en el valor de lista referenciado por listPtr. Devuelve este conteo almacenando un entero en la dirección lengthPtr. Si el valor no es ya un valor de lista, Tcl_ListObjLength intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar la longitud de la lista.

El procedimiento Tcl_ListObjIndex devuelve un puntero al valor en el elemento index de la lista referenciada por listPtr. Devuelve este valor almacenando un puntero a él en la dirección objPtrPtr. Si listPtr no se refiere ya a un valor de lista, Tcl_ListObjIndex intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. Si el índice está fuera de rango, es decir, index es negativo o mayor o igual al número de elementos en la lista, Tcl_ListObjIndex almacena un NULL en objPtrPtr y devuelve TCL_OK. De lo contrario, devuelve TCL_OK después de almacenar el puntero al valor del elemento. El contador de referencias para el elemento de la lista no se incrementa; el llamador debe hacerlo si necesita retener un puntero al elemento.

Tcl_ListObjReplace reemplaza cero o más elementos de la lista referenciada por listPtr con los valores objc en la matriz referenciada por objv. Si listPtr no apunta a un valor de lista, Tcl_ListObjReplace intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de reemplazar los valores. Si objv es NULL, no se agregan nuevos elementos. Si el argumento first es cero o negativo, se refiere al primer elemento. NAME

Tcl_ListObjReplace, Tcl_ListObjAppendElement, Tcl_ListObjDelete, Tcl_ListObjInsert — modify list objects

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)
int
Tcl_ListObjAppendElement(interp, listPtr, elementPtr)
int
Tcl_ListObjDelete(interp, listPtr, first, count)
int
Tcl_ListObjInsert(interp, listPtr, index, objc, objv)

ARGUMENTS

Tcl_Interp *interp (in)
Interpreter to use for error reporting and reference counting. If interp is NULL, then no error reporting is done.
Tcl_Obj *listPtr (in/out)
Points to the list object to modify. The object must already have list type.
int first (in)
For Tcl_ListObjReplace and Tcl_ListObjDelete, this is the index of the first element to replace or delete. For Tcl_ListObjInsert, this is the index where the new elements should be inserted.
int count (in)
For Tcl_ListObjReplace and Tcl_ListObjDelete, this is the number of elements to replace or delete. If count is zero or negative, then no elements are deleted.
int objc (in)
The number of elements in the array objv. Ignored if objv is NULL.
Tcl_Obj **objv (in)
For Tcl_ListObjReplace and Tcl_ListObjInsert, this is a pointer to an array of objects. These objects will be appended to the list.
Tcl_Obj *elementPtr (in)
For Tcl_ListObjAppendElement, this is a pointer to the object to be appended.

DESCRIPTION

These functions provide a general mechanism for modifying list objects. They all modify the list object referred to by listPtr in place. If the operation is successful, they return TCL_OK. If an error occurs, they return TCL_ERROR and if interp is not NULL, an error message is left in the interpreter's result.

Tcl_ListObjReplace is the most general of these functions. It replaces the elements of the list starting at index first with the objc elements in the array objv. If count is specified, then count elements are removed from the list before the new elements are inserted. If count is less than or equal to zero, then no elements are removed and the new elements are inserted at index first. If objc is less than or equal to zero, or if objv is NULL, then no elements are added.

If first is greater than or equal to the number of elements in the list, then the new elements are appended to the end of the list. If count is greater than the number of elements from first to the end of the list, then all elements from first to the end of the list are removed.

Tcl_ListObjAppendElement appends a single element to the end of the list. It is equivalent to calling Tcl_ListObjReplace with first set to the current length of the list, count set to 0, objc set to 1, and objv pointing to the single element.

Tcl_ListObjDelete deletes elements from the list. It is equivalent to calling Tcl_ListObjReplace with objc set to 0 and objv set to NULL.

Tcl_ListObjInsert inserts elements into the list. It is equivalent to calling Tcl_ListObjReplace with count set to 0.

In all cases, the functions maintain the list's internal representation. They also update the reference counts of the objects involved. If new objects are added to the list, their reference counts are incremented. If objects are removed from the list, their reference counts are decremented. The list object's string representation is invalidated, forcing it to be recalculated if it is needed.

The arguments first and count are interpreted similarly to the way indices and counts are interpreted in Tcl list commands. For example, a negative index refers to an element counted from the end of the list.

The following code illustrates how Tcl_ListObjReplace can be used to implement the append command:

int
MyListAppend(Tcl_Interp *interp, Tcl_Obj *listPtr, int objc, Tcl_Obj *const objv[])
{
    int len;
    int result = Tcl_ListObjLength(interp, listPtr, &len);
    if (result == TCL_OK) {
        result = Tcl_ListObjReplace(interp, listPtr, len, 0, objc, objv);
    }
    return result;
}

The following code illustrates how Tcl_ListObjReplace can be used to implement the linsert command:

int
MyListInsert(Tcl_Interp *interp, Tcl_Obj *listPtr, int index, int objc, Tcl_Obj *const objv[])
{
    return Tcl_ListObjReplace(interp, listPtr, index, 0, objc, objv);
}

The following code illustrates how Tcl_ListObjReplace can be used to implement the lrange command:

int
MyListRange(Tcl_Interp *interp, Tcl_Obj *listPtr, int first, int count, Tcl_Obj **resultPtr)
{
    Tcl_Obj *newPtr;

    newPtr = Tcl_ListObjReplace(interp, listPtr, first, count, 0, NULL);
    if (newPtr == NULL) {
        return TCL_ERROR;
    }
    *resultPtr = newPtr;
    return TCL_OK;
}

Note that the example for lrange returns a new list object. The other examples modify the list object in place. Tcl_ListObjReplace itself does not return a new object; it modifies the object pointed to by listPtr. The example for lrange illustrates a common pattern where one first calls Tcl_ListObjReplace to get the desired sublist, and then uses the returned value. However, this is not strictly necessary; one could also copy the list first, then perform the deletion.

The function Tcl_ListObjReplace can also be used to implement the list deletion operation. For example, the following code deletes count elements from the list starting at index first:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);

If count is zero or negative, no elements are deleted. If first is greater than or equal to the number of elements in the list, then no elements are deleted; the new elements are appended to the list. count gives the number of elements to replace. If count is zero or negative then no elements are deleted; the new elements are simply inserted before the one designated by first. Tcl_ListObjReplace invalidates listPtr's old string representation. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

Because Tcl_ListObjReplace combines both element insertion and deletion, it can be used to implement a number of list operations. For example, the following code inserts the objc values referenced by the array of value pointers objv just before the element index of the list referenced by listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

Similarly, the following code appends the objc values referenced by the array objv to the end of the list listPtr:

result = Tcl_ListObjAppendElement(interp, listPtr, elementPtr);

The count list elements starting at first can be deleted by simply calling Tcl_ListObjReplace with a NULL objvPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
