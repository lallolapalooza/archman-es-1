DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como una cantidad de tamaño fijo y sin signo. Un carácter UTF-8 es un carácter Unicode representado como una secuencia de longitud variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 multibyte consta de un byte líder seguido de algunos bytes seguidores.

TCL_UTF_MAX es el número máximo de bytes que se tarda en representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 que comienza en buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 comenzando en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamante debe asegurarse de que el buffer de origen sea lo suficientemente largo para que esta rutina no se salga del final y no acceda a memoria inexistente o aleatoria; si se sabe que el buffer de origen está terminado en null, esto no ocurrirá. Si la entrada no está en formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada a UTF-8, almacenando el resultado en un Tcl_DString inicializado previamente. Debe especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El espacio para el valor de retorno se añade al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada a Unicode, almacenando el resultado en el Tcl_DString inicializado previamente. En el argumento length, puede especificar la longitud de la cadena UTF-8 dada en bytes o “-1”, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El espacio para el valor de retorno se añade al final del Tcl_DString. La cadena Unicode se termina con un carácter null de Unicode.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en null y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en null y el número de caracteres a comparar. Se supone que ambas cadenas tienen al menos numChars caracteres. Tcl_UniCharNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a o menor que 0 si la primera cadena es mayor que, igual a o menor que la segunda cadena, respectivamente. Tcl_UniCharNcasecmp es la versión Unicode insensible a mayúsculas y minúsculas.

Tcl_UniCharCaseMatch es el equivalente Unicode a Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en null, un patrón Unicode y un valor booleano que especifica si la coincidencia debe ser sensible a mayúsculas y minúsculas, y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en null y el número de caracteres a comparar. (Se supone que ambas cadenas tienen al menos numChars caracteres.) Tcl_UtfNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a o menor que 0 si la primera cadena es mayor que, igual a o menor que la segunda cadena, respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas y minúsculas al comparar caracteres en mayúsculas, minúsculas o de título.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 de origen src de length bytes es lo suficientemente larga como para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté formada correctamente. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars que están representados por la cadena UTF-8 src. La longitud de la cadena de origen es length bytes. Si la longitud es negativa, se utilizan todos los bytes hasta el primer byte null.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en null src. El terminador null se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última ocurrencia del Tcl_UniChar

DESCRIPTION

These procedures provide support for working with strings that are encoded using the UTF-8 representation of Unicode. The UTF-8 encoding uses one to four bytes to represent a single Unicode character.

Tcl_UniCharAtIndex returns the Unicode character at the specified character index in the UTF-8 string src. The string must be null-terminated or padded with enough bytes to contain the character at index. The index is a 0-based index of characters, not bytes. If index is negative, the behavior is undefined. Tcl_UniCharAtIndex is similar to calling Tcl_UniCharNext repeatedly.

Tcl_UniCharNext returns the Unicode character at the current position in the UTF-8 string src and advances the pointer to the next character. The string must be null-terminated or padded with enough bytes to contain at least one full character. The return value is the Unicode character, which may be truncated if the string is not null-terminated and does not contain a complete character at the current position.

Tcl_UniCharPrev returns the Unicode character just before the position indicated by src. The start argument is the beginning of the string, and is used to prevent stepping beyond the beginning of the string. The string must contain only complete characters. If src is at the beginning of the string, the behavior is undefined.

Tcl_UtfCharComplete checks if the first length bytes of the UTF-8 string src contain one or more complete Unicode characters. It returns 1 if the bytes are complete, and 0 otherwise. This is useful for determining if it is safe to call Tcl_UtfNext or Tcl_UtfPrev without reading past the end of a buffer.

Tcl_UtfNext returns a pointer to the next UTF-8 character in the string src. The null terminator is considered part of the UTF-8 string.

Given src, a pointer to some location in a UTF-8 string, Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
