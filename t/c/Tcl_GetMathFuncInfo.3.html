Tcl_CreateMathFunc(3) Procedimientos de la biblioteca Tcl Tcl_CreateMathFunc(3)

NOMBRE

Tcl_CreateMathFunc, Tcl_GetMathFuncInfo, Tcl_ListMathFuncs - Definir, consultar y enumerar funciones matemáticas para expresiones

AVISO DE EVENTUAL DESAPROBACIÓN

Las funciones Tcl_CreateMathFunc y Tcl_GetMathFuncInfo quedan algo obsoletas por la capacidad de crear funciones para expresiones colocando comandos en el espacio de nombres tcl::mathfunc, como se describe en la página del manual mathfunc; no se espera que la API descrita en esta página se mantenga indefinidamente.

SINOPSIS

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,
                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que se definirá la nueva función.
const char *name (entrada)
Nombre para la nueva función.
int numArgs (entrada)
Número de argumentos para la nueva función; también da el tamaño del array argTypes.
Tcl_ValueType *argTypes (entrada)
Puntero a un array que indica los tipos permitidos para cada argumento de la función.
Tcl_MathProc *proc (entrada)
Procedimiento que implementa la función.
ClientData clientData (entrada)
Valor arbitrario de una palabra para pasar a proc cuando se invoca.
int *numArgsPtr (salida)
Puntero a una variable que se establecerá para contener el número de argumentos de la función.
Tcl_ValueType **argTypesPtr (salida)
Puntero a una variable que se establecerá para contener un puntero a un array que indica los tipos permitidos para cada argumento de la función, el cual deberá liberarse con Tcl_Free.
Tcl_MathProc **procPtr (salida)
Puntero a una variable que se establecerá para contener un puntero al código de implementación de la función (o NULL si la función se implementa directamente en bytecode).
ClientData *clientDataPtr (salida)
Puntero a una variable que se establecerá para contener el argumento clientData pasado a Tcl_CreateMathFunc cuando se creó la función, si la función no se implementa directamente en bytecode.
const char *pattern (entrada)
Patrón para comparar con los nombres de las funciones para filtrarlas (pasando a Tcl_StringMatch), o NULL para no aplicar ningún filtro.

DESCRIPCIÓN

Tcl permite usar una serie de funciones matemáticas en expresiones, como sin, cos e hypot. Estas funciones se representan mediante comandos en el espacio de nombres tcl::mathfunc. La función Tcl_CreateMathFunc es una forma obsoleta para que las aplicaciones añadan funciones adicionales a las ya proporcionadas por Tcl o para reemplazar funciones existentes. No debe ser utilizada por aplicaciones nuevas, que deben crear funciones matemáticas usando Tcl_CreateObjCommand para crear un comando en el espacio de nombres tcl::mathfunc.

En la interfaz Tcl_CreateMathFunc, Name es el nombre de la función tal como aparecerá en las expresiones. Si name no existe ya en el espacio de nombres ::tcl::mathfunc, se crea un nuevo comando en ese espacio de nombres. Si name ya existe, se reemplaza la función existente. NumArgs y argTypes describen los argumentos de la función. Cada entrada en el array argTypes debe ser uno de TCL_INT, TCL_DOUBLE, TCL_WIDE_INT o TCL_EITHER para indicar si el argumento correspondiente debe ser un entero, un valor de punto flotante de doble precisión, un entero grande (de 64 bits) o cualquiera, respectivamente.

Cada vez que se invoca la función en una expresión, Tcl invocará proc. Proc debe tener argumentos y resultado que coincidan con el tipo Tcl_MathProc:

typedef int Tcl_MathProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_Value *args,
        Tcl_Value *resultPtr);

Cuando se invoca proc, los argumentos clientData e interp serán los mismos que los pasados a Tcl_CreateMathFunc. Args apuntará a un array de numArgs estructuras Tcl_Value, que describen los argumentos reales de la función:

typedef struct Tcl_Value {
    Tcl_ValueType type;
    long intValue;
    double doubleValue;
    Tcl_WideInt wideValue;
} Tcl_Value;

El campo type indica el tipo del argumento y es uno de TCL_INT, TCL_DOUBLE o TCL_WIDE_INT. Coincidirá con el valor argTypes especificado para la función, a menos que el valor argTypes fuera TCL_EITHER. Tcl convierte el argumento suministrado en la expresión al tipo solicitado en argTypes, si es necesario. Dependiendo del valor del campo type, el campo intValue, doubleValue o wideValue contendrá el valor real del argumento.

Proc debe calcular su resultado y almacenarlo como un entero en resultPtr->intValue o como un valor flotante en resultPtr->doubleValue. También debe establecer resultPtr->type a uno de TCL_INT, TCL_DOUBLE o TCL_WIDE_INT para indicar qué valor se estableció. En circunstancias normales, proc debería devolver TCL_OK. Si ocurre un error al ejecutar la función, proc debería devolver TCL_ERROR y dejar un mensaje de error en el resultado del intérprete.

Tcl_GetMathFuncInfo recupera los valores asociados con la función name que se pasaron a una llamada previa de Tcl_CreateMathFunc. Normalmente, el código de retorno es TCL_OK, pero si la función nombrada no existe, se devuelve TCL_ERROR y se coloca un mensaje de error en el resultado del intérprete.

Si no ocurrió un error, la referencia al array colocada en la variable apuntada por argTypesPtr es recién asignada y debe liberarse pasándola a Tcl_Free. Algunas funciones (el conjunto estándar implementado en el núcleo, y aquellas definidas colocando comandos en el espacio de nombres tcl::mathfunc) no tienen información de tipo de argumento; intentar recuperar valores para ellas causa que se almacene un NULL en la variable apuntada por procPtr y la variable apuntada por clientDataPtr no se modificará. La variable apuntada por numArgsPointer contendrá -1, y no se almacenarán tipos de argumento en la variable apuntada por argTypesPointer.

Tcl_ListMathFuncs devuelve un valor Tcl que contiene una lista de todas las funciones matemáticas definidas en el intérprete cuyo nombre coincide con pattern. El valor devuelto tiene un recuento de referencias de cero.

    SINAPSIS

    #include <tcl.h>

int
Tcl_GetMathFuncInfo(interp, name, typePtr, minArgsPtr, maxArgsPtr, procPtr)
    Tcl_Interp *interp;
    const char *name;
    int *typePtr;
    int *minArgsPtr;
    int *maxArgsPtr;
    Tcl_MathUnion *procPtr;

    ARGUMENTOS

    interp (entrada)
    Intérprete de Tcl en el que buscar la función matemática.
    name (entrada)
    El nombre de la función matemática que se busca.
    typePtr (salida)
    Puntero a un entero donde se almacenará el tipo de retorno de la función. Los valores posibles son TCL_MATH_INT, TCL_MATH_REAL, TCL_MATH_ANY.
    minArgsPtr (salida)
    Puntero a un entero donde se almacenará el número mínimo de argumentos requerido por la función.
    maxArgsPtr (salida)
    Puntero a un entero donde se almacenará el número máximo de argumentos permitido por la función.
    procPtr (salida)
    Puntero a una estructura Tcl_MathUnion donde se almacenará la información del procedimiento de la función.

    DESCRIPCIÓN

    La función Tcl_GetMathFuncInfo busca información sobre la función matemática especificada por name en el intérprete interp. Si se encuentra la función, su tipo de retorno, el número mínimo y máximo de argumentos, y el puntero a su procedimiento se almacenan en las ubicaciones de memoria apuntadas por typePtr, minArgsPtr, maxArgsPtr y procPtr, respectivamente.

    Los valores posibles para el tipo de retorno son:

    • TCL_MATH_INT: La función devuelve un entero.
    • TCL_MATH_REAL: La función devuelve un número de punto flotante.
    • TCL_MATH_ANY: La función puede devolver un entero o un número de punto flotante.

    Si la función no se encuentra o ocurre un error, la función devuelve TCL_ERROR y establece el mensaje de error en el intérprete. De lo contrario, devuelve TCL_OK.
