DESCRIPCIÓN

Estas funciones son para el acceso a la funcionalidad de múltiples intérpretes Tcl desde dentro de programas C. Permiten la gestión de múltiples intérpretes en una relación jerárquica, y la gestión de alias, comandos que cuando se invocan en un intérprete se ejecutan en otro. El valor devuelto por esas funciones que devuelven un int es either TCL_OK o TCL_ERROR. Si TCL_ERROR es devuelto, entonces el resultado del intérprete contiene un mensaje de error.

Tcl_CreateSlave crea un nuevo intérprete como hijo de interp. También crea un comando hijo llamado childName en interp que permite a interp manipular el nuevo hijo. Si isSafe es cero, el comando crea un hijo confiable en el cual el código Tcl tiene acceso a todos los comandos Tcl. Si es 1, el comando crea un hijo "seguro" en el cual el código Tcl tiene acceso solo a un conjunto de comandos Tcl definidos como "Safe Tcl"; ver la entrada del man para el comando Tcl interp. Si la creación del nuevo hijo intérprete falla, se devuelve NULL.

Tcl_CreateChild es un sinónimo de Tcl_CreateSlave.

Tcl_IsSafe devuelve 1 si interp es "seguro" (se creó con el flag TCL_SAFE_INTERPRETER especificado), 0 de lo contrario.

Tcl_MakeSafe marca interp como "seguro", de manera que futuras llamadas a Tcl_IsSafe devuelvan 1. También elimina de interp cualquier funcionalidad conocida que pueda ser potencialmente insegura (comandos y variables). Sin embargo, no puede saber qué partes de una extensión o aplicación son seguras y no hace ningún intento de eliminar esas partes, por lo que la seguridad no está garantizada después de llamar a Tcl_MakeSafe. Los usuarios deben tener cuidado con el uso de Tcl_MakeSafe para evitar afirmaciones falsas de seguridad. Para muchos casos, Tcl_CreateSlave puede ser una mejor opción, ya que crea intérpretes en un estado conocido seguro.

Tcl_GetSlave devuelve un puntero a un intérprete hijo de interp. El intérprete hijo se identifica por childName. Si no existe tal intérprete hijo, se devuelve NULL.

Tcl_GetChild es un sinónimo de Tcl_GetSlave.

Tcl_GetMaster devuelve un puntero al intérprete padre de interp. Si interp no tiene un padre (es decir, es un intérprete de nivel superior), se devuelve NULL.

Tcl_GetParent es un sinónimo de Tcl_GetMaster.

Tcl_GetInterpPath almacena en el resultado de interp la ruta relativa entre interp y childInterp; childInterp debe ser hijo de interp. Si el cálculo de la ruta relativa se realiza con éxito, se devuelve TCL_OK, de lo contrario TCL_ERROR y se almacena un mensaje de error en el resultado de interp.

Tcl_CreateAlias crea un comando llamado childCmd en childInterp que al ser invocado causará que se ejecute el comando targetCmd en targetInterp. Los argumentos especificados por los strings en argv siempre se agregan a cualquier argumento proporcionado en la invocación de childCmd y se pasan a targetCmd. Esta operación devuelve TCL_OK si es exitosa, de lo contrario TCL_ERROR y se almacena un mensaje de error en el valor de resultado de childInterp. Nota: no hay restricciones en la relación de ancestro entre childInterp y targetInterp (como creada por Tcl_CreateSlave). Cualquier dos intérpretes pueden usarse sin restricciones sobre cómo están relacionados.

Tcl_CreateAliasObj es similar a Tcl_CreateAlias pero toma un vector de valores para pasar como argumentos adicionales en lugar de un vector de strings.

Tcl_GetAliasObj devuelve información en forma de un puntero a un vector de estructuras Tcl_Obj sobre un alias aliasName en interp. Cualquier uno de los campos de resultado puede ser NULL, en cuyo caso el correspondiente dato no se devuelve. Si un campo de resultado es no-NULL, la dirección indicada se establece al correspondiente dato. Por ejemplo, si targetCmdPtr es no-NULL, se establece a un puntero al nombre del comando de destino.

NAME

Tcl_CreateAliasObj, Tcl_ExposeCommand, Tcl_HideCommand — create and manage aliases for Tcl commands

SYNOPSIS

#include <tcl.h>

Tcl_Obj *
Tcl_CreateAliasObj(interp, cmdName, numArgs, objv)
Tcl_Command
Tcl_ExposeCommand(interp, hiddenCmdName, cmdName)
Tcl_Command
Tcl_HideCommand(interp, cmdName, hiddenCmdName)

ARGUMENTS

Tcl_Interp *interp
Interpreter to create the alias in.
const char *cmdName
Name for the new alias command.
int numArgs
Number of arguments in objv.
Tcl_Obj *const objv[]
Array of arguments for the alias command. The first element is the command to be aliased.
const char *hiddenCmdName
Name of a hidden command.
const char *cmdName
Name of an exposed command.

DESCRIPTION

These functions are used to create and manage aliases, which are commands that invoke other commands. They allow a command to be invoked via different names, potentially with different arguments.

Tcl_CreateAliasObj creates a new command named cmdName in the interpreter interp. When the new command is invoked, it will execute the command specified by the first element of objv, passing it the remaining elements of objv as arguments, plus any additional arguments passed to the alias command. The alias command is created in the namespace that is current when Tcl_CreateAliasObj is called. The alias command is created as an object-based command. The return value is a pointer to the Tcl_Command for the new alias. If an error occurs during creation (e.g., if a command named cmdName already exists), the interpreter's result will be set to an error message and NULL will be returned.

Tcl_ExposeCommand moves the command named hiddenCmdName from the set of hidden commands to the set of exposed commands, putting it under the name cmdName. HiddenCmdName must be the name of an existing hidden command, or the operation will return TCL_ERROR and leave an error message as the result of interp. If an exposed command named cmdName already exists, the operation returns TCL_ERROR and leaves an error message as the result of interp. If the operation succeeds, it returns TCL_OK. After executing this command, attempts to use cmdName in any script evaluation mechanism will again succeed.

Tcl_HideCommand moves the command named cmdName from the set of exposed commands to the set of hidden commands, under the name hiddenCmdName. CmdName must be the name of an existing exposed command, or the operation will return TCL_ERROR and leave an error message as the result of interp. Currently both cmdName and hiddenCmdName must not contain namespace qualifiers, or the operation will return TCL_ERROR and leave an error message as the result of interp. The CmdName will be looked up in the global namespace, and not relative to the current namespace, even if the current namespace is not the global one. If a hidden command whose name is hiddenCmdName already exists, the operation also returns TCL_ERROR and an error message is left as the result of interp. If the operation succeeds, it returns TCL_OK. After executing this command, attempts to use cmdName in any script evaluation mechanism will fail.

For a description of the Tcl interface to multiple interpreters, see interp(n).
