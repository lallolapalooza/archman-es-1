ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el cual existe la namespace y donde se realizan las búsquedas de nombres. También donde se escriben los mensajes de resultado de error.
const char *name (entrada)
El nombre de la namespace o comando a crear o acceder.
ClientData clientData (entrada)
Un puntero de contexto proporcionado por el creador de la namespace. Tcl no lo interpreta en absoluto.
Tcl_NamespaceDeleteProc *deleteProc (entrada)
Un puntero a una función a llamar cuando se elimine la namespace, o NULL si no se va a realizar ninguna devolución de llamada.
Tcl_Namespace *nsPtr (entrada)
La namespace a manipular, o NULL (para otros que no sean Tcl_DeleteNamespace) para manipular la namespace actual.
Tcl_Obj *objPtr (salida)
Una referencia a un valor no compartido en el que se escribirá la salida de la función.
const char *pattern (entrada)
El patrón estilo glob (ver Tcl_StringMatch) que describe los comandos a importar o exportar.
int resetListFirst (entrada)
Si la lista de patrones de exportación debe reiniciarse antes de añadir el patrón actual.
int allowOverwrite (entrada)
Si los nuevos comandos creados por esta acción de importación pueden sobrescribir comandos existentes.
Tcl_Namespace *contextNsPtr (entrada)
La ubicación en la jerarquía de namespaces donde se debe realizar la búsqueda de una namespace o comando en relación con cuando el término de búsqueda no está anclado en la namespace global. NULL indica la namespace actual.
int flags (entrada)
Combinación OR de bits que controlan cómo se debe realizar la búsqueda. Los siguientes flags son compatibles: TCL_GLOBAL_ONLY (indica que la búsqueda siempre se realizará en relación con la namespace global), TCL_NAMESPACE_ONLY (solo para Tcl_FindCommand; indica que la búsqueda siempre se realizará en relación con la namespace de contexto), y TCL_LEAVE_ERR_MSG (indica que se dejará un mensaje de error en el intérprete si la búsqueda falla).
Tcl_Obj *handlerPtr (entrada)
Un fragmento de script para ser instalado como manejador de comando desconocido para la namespace, o NULL para restablecer el manejador a su valor predeterminado.

DESCRIPCIÓN

Las namespaces son contextos de nombres jerárquicos que pueden contener comandos y variables. También mantienen una lista de patrones que describen qué comandos se exportan, y pueden importar comandos que hayan sido exportados por otros namespaces. Las namespaces también pueden ser manipuladas a través del comando Tcl namespace.

La estructura Tcl_Namespace encapsula una namespace, y se garantiza que tenga los siguientes campos en ella: name (el nombre local de la namespace, sin caracteres separadores de namespace, con vacío indicando la namespace global), fullName (el nombre completo de la namespace), clientData, deleteProc (los valores especificados en la llamada a Tcl_CreateNamespace), y parentPtr (un puntero a la namespace padre, o NULL para la namespace global).

Tcl_CreateNamespace crea una nueva namespace. El deleteProc tendrá la siguiente firma de tipo:

typedef void Tcl_NamespaceDeleteProc(
        ClientData clientData);

Tcl_DeleteNamespace elimina una namespace, llamando al deleteProc definido para la namespace (si existe).

Tcl_AppendExportList obtiene los patrones de exportación de una namespace dada y los añade (como elementos de lista) a objPtr.

Tcl_Export establece y añade a los patrones de exportación de una namespace. Los patrones se añaden excepto si el resetListFirst está activado.

Tcl_Import importa comandos que coincidan con un patrón a una namespace. Nota que el patrón debe incluir el nombre de la namespace desde la cual se va a importar. Esta función devuelve TCL_ERROR si se intenta importar un comando sobre un comando existente, a menos que el allowOverwrite esté activado.

Tcl_ForgetImport elimina importaciones que coincidan con un patrón.

Tcl_GetCurrentNamespace devuelve la namespace actual para un intérprete.

Tcl_GetGlobalNamespace devuelve la namespace global para un intérprete.

Tcl_FindNamespace busca una namespace con el nombre name dentro del contexto de la namespace contextNsPtr. Si no se puede encontrar, se devuelve NULL.

Tcl_FindCommand busca un comando con el nombre name dentro del contexto de la namespace contextNsPtr. Si no se puede encontrar, se devuelve NULL.

Tcl_GetNamespaceUnknownHandler devuelve el manejador de comando desconocido para la namespace, o NULL si no está configurado.

Tcl_SetNamespaceUnknownHandler establece el manejador de comando desconocido para la namespace. Si handlerPtr es NULL, se restablece el manejador a su valor predeterminado.
