Tcl_ListObj(3) Procedimientos de la biblioteca Tcl Tcl_ListObj(3)

NOMBRE

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipular valores Tcl como listas

SINOPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor a un valor de lista, se deja un mensaje de error en el resultado del intérprete, a menos que interp sea NULL.
Tcl_Obj *listPtr (entrada/salida)
Punta al valor de lista que se va a manipular. Si listPtr no apunta ya a un valor de lista, se intentará convertirlo.
Tcl_Obj *elemListPtr (entrada/salida)
Para Tcl_ListObjAppendList, apunta a un valor de lista que contiene elementos para agregar a listPtr. Cada elemento de *elemListPtr se convertirá en un nuevo elemento de listPtr. Si *elemListPtr no es NULL y no apunta ya a un valor de lista, se intentará convertirlo. Si ocurre un error durante la conversión, tanto esta función como Tcl_ListObjAppendElement devuelven TCL_ERROR y dejan un mensaje de error en el resultado del intérprete si interp no es NULL. Ambas funciones invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió a un valor de lista, liberan cualquier representación interna antigua. Del mismo modo, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si lo convierte a un valor de lista. Después de agregar cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento ya que listPtr ahora también se refiere a él. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no ocurre ningún error, los dos procedimientos devuelven TCL_OK después de agregar los valores.
Tcl_Obj *objPtr (entrada)
Para Tcl_ListObjAppendElement, apunta al valor Tcl que se agregará a listPtr. Para Tcl_SetListObj, apunta al valor Tcl que se convertirá en un valor de lista que contiene los objc elementos de la matriz referenciada por objv.
int *objcPtr (entrada)
Apunta a la ubicación donde Tcl_ListObjGetElements almacena el número de valores de elementos en listPtr.
Tcl_Obj ***objvPtr (salida)
Una ubicación donde Tcl_ListObjGetElements almacena un puntero a una matriz de punteros a los valores de los elementos de listPtr.
int objc (entrada)
El número de valores Tcl que Tcl_NewListObj insertará en un nuevo valor de lista, y Tcl_ListObjReplace insertará en listPtr. Para Tcl_SetListObj, el número de valores Tcl a insertar en objPtr.
Tcl_Obj *const objv[] (entrada)
Una matriz de punteros a valores. Tcl_NewListObj insertará estos valores en un nuevo valor de lista y Tcl_ListObjReplace los insertará en un listPtr existente. Cada valor se convertirá en un elemento de lista separado.
int *lengthPtr (salida)
Apunta a la ubicación donde Tcl_ListObjLength almacena la longitud de la lista.
int index (entrada)
Índice del elemento de la lista que Tcl_ListObjIndex debe devolver. El primer elemento tiene el índice 0.
Tcl_Obj **objPtrPtr (salida)
Apunta al lugar donde Tcl_ListObjIndex debe almacenar un puntero al valor del elemento de lista resultante.
int first (entrada)
Índice del elemento de lista inicial que Tcl_ListObjReplace debe reemplazar. El primer elemento de la lista tiene el índice 0.
int count (entrada)
El número de elementos que Tcl_ListObjReplace debe reemplazar.

DESCRIPCIÓN

Los valores de lista de Tcl tienen una representación interna que admite indexación y anexión eficientes. Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar y anexar valores de lista de Tcl desde código C.

Tcl_ListObjAppendList y Tcl_ListObjAppendElement ambos agregan uno o más valores al final del valor de lista al que se hace referencia en listPtr. Tcl_ListObjAppendList anexa cada elemento del valor de lista al que se hace referencia en elemListPtr, mientras que Tcl_ListObjAppendElement anexa el único valor al que se hace referencia en objPtr. Ambos procedimientos convertirán el valor al que se hace referencia en listPtr a un valor de lista si es necesario.

Tcl_NewListObj y Tcl_SetListObj crean un nuevo valor o modifican un valor existente para que contenga los objc elementos de la matriz a la que se hace referencia en objv, donde cada elemento es un puntero a un valor Tcl. Si objc es menor o igual a cero, devuelven un valor vacío. Si objv es NULL, la lista resultante contiene 0 elementos, con espacio reservado en una representación interna para objc elementos más (para evitar su reasignación posterior). La representación de cadena del nuevo valor se deja inválida. Los dos procedimientos incrementan los recuentos de referencias de los elementos en objc ya que el valor de lista ahora se refiere a ellos. El nuevo valor de lista devuelto por Tcl_NewListObj tiene un recuento de referencias de cero.

Tcl_ListObjGetElements devuelve el número y un puntero a una matriz de los elementos de un valor de lista. Devuelve el número almacenándolo en la dirección objcPtr. De manera similar, devuelve el puntero de la matriz almacenándolo en la dirección objvPtr. La memoria apuntada es gestionada por Tcl y no debe ser liberada ni escrita por el llamador. Si la lista está vacía, se almacena 0 en objcPtr y NULL en objvPtr. Si listPtr no es ya un valor de lista, Tcl_ListObjGetElements intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar el número y el puntero de la matriz.

Tcl_ListObjLength devuelve el número de elementos en el valor de lista al que se hace referencia en listPtr. Devuelve este número almacenando un entero en la dirección lengthPtr. Si el valor no es ya un valor de lista, Tcl_ListObjLength intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar la longitud de la lista.

El procedimiento Tcl_ListObjIndex devuelve un puntero al valor en el elemento index de la lista a la que se hace referencia en listPtr. Devuelve este valor almacenando un puntero a él en la dirección objPtrPtr. Si listPtr no se refiere ya a un valor de lista, Tcl_ListObjIndex intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. Si el índice está fuera de rango, es decir, index es negativo o mayor o igual al número de elementos en la lista, Tcl_ListObjIndex almacena NULL en objPtrPtr y devuelve TCL_OK. De lo contrario, devuelve TCL_OK después de almacenar el puntero al valor del elemento. El recuento de referencias para el elemento de la lista no se incrementa; el llamador debe hacerlo si necesita retener un puntero al elemento.

Tcl_ListObjReplace reemplaza cero o más elementos de la lista a la que se hace referencia en listPtr con los objc valores de la matriz a la que se hace referencia en objv. Si listPtr no apunta a un valor de lista, Tcl_ListObjReplace intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de reemplazar los valores. Si objv es NULL, no se agregan nuevos elementos. Si el argumento first es cero o negativo, se refiere al primer elemento. Tcl_ListObjReplace(3) — Tcl

NAME

Tcl_ListObjReplace — replace a slice of a list with new elements

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_Obj *listPtr
Points to the list object to modify. Must have list type.
int first
Index of the first element to replace. If negative, it counts from the end of the list.
int count
Number of elements to replace. If count is zero or negative, no elements are deleted, and the new elements are inserted at the position given by first. If count is greater than the number of elements remaining in the list from first onwards, then all elements from first onwards are deleted.
int objc
Number of new elements to insert.
Tcl_Obj *const *objv
Array of new elements to insert.

DESCRIPTION

Tcl_ListObjReplace is the primary primitive for modifying Tcl list objects. It is used to replace a sub-sequence of elements in a list object with new elements. The list object is specified by listPtr, and the sub-sequence to replace is specified by the indices first and count. The new elements are specified by objc and objv.

The sub-sequence to be replaced starts at index first and contains count elements. If count is positive, then the count elements starting at index first are deleted. If count is zero or negative, no elements are deleted; the new elements are inserted at index first. If count is greater than the number of elements remaining in the list from first onwards, then all elements from first onwards are deleted. The new elements are taken from the array objv, and there are objc such elements. If objc is zero then no elements are inserted.

The first argument is an index into the list. If first is negative, it is treated as an index from the end of the list. For example, -1 refers to the last element, -2 refers to the second to last element and so on. If first is greater than or equal to the number of elements in the list, the new elements are appended to the end of the list. If count is specified as 0 and first is specified as equal to the number of elements in the list, the new elements are appended to the list.

If count is specified as greater than or equal to the number of elements in the list, then all elements from first onwards are deleted. If count is greater than the number of elements from first to the end of the list, then all elements from first to the end are deleted.

If listPtr does not have a list representation, Tcl will attempt to create one. If this fails, an error will be returned. If listPtr already has a list representation, it will be updated to reflect the changes. If listPtr also has a string representation, it will be invalidated. If count is less than or equal to the number of elements in the list starting at first, and objc is less than or equal to count, then it is possible for the list to retain its list representation without allocating new memory for the elements that are not replaced. Tcl will try to do this if possible.

The reference counts of the objects in objv are incremented because the new list will now refer to them. The reference counts of any objects that are replaced are decremented.

Tcl_ListObjReplace returns the Tcl return code. It returns TCL_OK if the operation was successful, and TCL_ERROR (and sets result in interp) if the list object could not be modified (e.g. if it didn’t have a list representation).

The following examples show how Tcl_ListObjReplace can be used:

To insert the elements in objv (objc of them) before element index of the list listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

To append the elements in objv (objc of them) to the end of the list listPtr:

result = Tcl_ListObjReplace(interp, listPtr, length, 0,
        objc, objv);

where length is the current number of elements in the list.

To delete count elements starting at index first from the list listPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);

To replace count elements starting at index first with the elements in objv (objc of them):

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        objc, objv);
