ARGUMENTOS

Tcl_Interp *interp (in/out)
El intérprete en el cual se creará o encontrará el ensayo. También es donde se escriben los mensajes de resultado de error. Las funciones que empiezan con Tcl_GetEnsemble pueden tener NULL para el interp, pero todas las otras funciones deben no.
const char *name (in)
El nombre del comando de ensayo a crear.
Tcl_Namespace *namespacePtr (in)
El espacio de nombres en el cual se va a bindear el comando de ensayo, o NULL para el espacio de nombres actual.
int ensFlags (in)
Un conjunto de bits OR'ed que describen la configuración básica del ensayo. Actualmente solo un bit tiene sentido, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando de ensayo debe también coincidir con prefijos ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (in)
Un valor que contiene el nombre del comando de ensayo a buscar.
int flags (in)
Un conjunto de bits OR'ed que controlan el comportamiento de Tcl_FindEnsemble. Actualmente solo TCL_LEAVE_ERR_MSG es soportado.
Tcl_Command token (in)
Un token de comando normal que se refiere a un comando de ensayo, o que se quiera usar para probar como un comando de ensayo en Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Un puntero a una variable en la cual se escribe los bits de flags actuales del ensayo; actualmente solo el bit TCL_ENSEMBLE_PREFIX está definido.
Tcl_Obj *dictObj (in)
Un objeto de diccionario que se utiliza para el diccionario de mapeo de subcomandos a la cadena de prefijo de comando de implementación en el ensayo. Puede ser NULL si el diccionario de mapeo es a ser eliminado.
Tcl_Obj **dictObjPtr (out)
Un puntero a una variable en la cual se escribe el diccionario de mapeo de subcomandos actual.
Tcl_Obj *listObj (in)
Un objeto de lista que se utiliza para el listado de parámetros formales de subcomandos, el listado definido de subcomandos en el diccionario o la cadena de prefijo de comando de manejo de subcomandos desconocidos. Puede ser NULL si el listado de subcomandos o el manejo de subcomandos desconocidos se va a eliminar.
Tcl_Obj **listObjPtr (out)
Un puntero a una variable en la cual se escribe el listado de parámetros formales de subcomandos, el listado definido de subcomandos o el prefijo actual del manejo de subcomandos desconocidos.
Tcl_Namespace **namespacePtrPtr (out)
Un puntero a una variable en la cual se escribe el handle del espacio de nombres en el cual se bindeará el ensayo.

DESCRIPCIÓN

Un ensayo es un comando, vinculado a un espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos Tcl. El primer argumento del comando de ensayo siempre se interpreta como un selector que indica qué subcomando ejecutar.

Los ensayos se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete a trabajar dentro, el nombre del ensayo a crear, el espacio de nombres dentro del intérprete en el cual se va a vincular el ensayo, y el conjunto de flags por defecto del ensayo. El resultado de la función es el token de comando para el ensayo, que puede ser utilizado para configurar el ensayo usando la API descrita en PROPIEDADES DEL ENSAYO.

Dado el nombre de un comando de ensayo, el token para ese comando puede ser recuperado usando Tcl_FindEnsemble. Si el nombre dado (en cmdNameObj) no refiere a un comando de ensayo, el resultado de la función es NULL y, si el bit TCL_LEAVE_ERR_MSG está seteado en flags, un mensaje de error se deja en el resultado del intérprete.

Un token de comando puede ser chequeado para ver si se refiere a un ensayo usando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un ensayo, o 0 de lo contrario.

PROPIEDADES DEL ENSAYO

Cada ensayo tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

flags (lectura/escritura)
El conjunto de bits que representan las flags del ensayo, expresados como un campo de bits. Actualmente, el único flag público es TCL_ENSEMBLE_PREFIX que se establece cuando los prefijos ambiguos de subcomandos son permitidos para ser resueltos a implementaciones así como coincidencias exactas. Los flags pueden leerse y escribirse usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas estas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensayo).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras que se usan como prefijo de comando (reemplazando las primeras dos palabras del comando, que son el comando de ensayo y el nombre de subcomando), o NULL si cada subcomando se mapea a un comando con el mismo nombre no cualificado en el espacio de nombres del ensayo. Por defecto, es NULL. Puede ser leído y escrito usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas estas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensayo) y el diccionario obtenido de Tcl_GetEnsembleMappingDict debe siempre tratarse como inmutable incluso si no lo es compartido. Todos los nombres de comandos en los prefijos establecidos mediante Tcl_SetEnsembleMappingDict deben ser completamente cualificados.
lista de parámetros formales de subcomandos (lectura/escritura)
Una lista de nombres de parámetros formales (solamente usados cuando se generan mensajes de error) que se invocan entre el nombre del ensayo y el argumento de subcomando. NULL (por defecto) es equivalente a una lista vacía. Puede ser leído y escrito usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas estas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensayo) y el diccionario obtenido de Tcl_GetEnsembleParameterList debe siempre tratarse como inmutable incluso si no lo es compartido.
lista de nombres de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el ensayo, o NULL si este es derivado de las claves del diccionario de mapeo (ver arriba) o (si eso también es NULL) de los comandos exportados por el espacio de nombres vinculado. Puede ser leído y escrito usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas estas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensayo) y el listado obtenido de Tcl_GetEnsembleSubcommandList debe siempre tratarse como inmutable incluso si no lo es compartido.
prefijo de comando de manejo de subcomandos desconocidos (lectura/escritura)
Una lista de palabras que se anteponen al principio de cualquier subcomando cuando este es desconocido para el ensayo (según el prefijo actual de manejo). Puede ser leído y escrito usando Tcl_GetEnsembleUnknownHandler y Tcl_SetEnsembleUnknownHandler respectivamente. El resultado de ambas estas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensayo).

DESCRIPTION

An ensemble is a command that dispatches to one of its subcommands based on the first word of the command arguments. The namespace ensemble command creates and manipulates ensemble commands.

The following functions provide programmatic access to the properties of an ensemble:

subcommandlist namespace (read-only)
The list of subcommands for the ensemble. If this property is NULL, then the ensemble looks for subcommands in the mapping dictionary, and if that is also NULL, it looks in the list of exported commands of the ensemble's bound namespace. May be read and written using Tcl_GetEnsembleSubcommandList and Tcl_SetEnsembleSubcommandList respectively. The result of Tcl_GetEnsembleSubcommandList is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained should always be treated as immutable even if it is unshared.
unknownhandler namespace (read-only)
The name of a procedure to be called when an unknown subcommand is encountered. If this property is NULL, the default behavior - generate a suitable error message - will be used when an unknown subcommand is encountered. May be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The result of Tcl_GetEnsembleUnknownHandler is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.
bound namespace (read-only)
The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).
mapping namespace (read-only)
A dictionary mapping subcommand names to commands. If this property is NULL, then the ensemble looks for subcommands in the subcommand list, and if that is also NULL, it looks in the list of exported commands of the ensemble's bound namespace. May be read and written using Tcl_GetEnsembleMapping and Tcl_SetEnsembleMapping respectively. The result of Tcl_GetEnsembleMapping is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the dictionary obtained should always be treated as immutable even if it is unshared.
parent namespace (read-only)
The ensemble of which this ensemble is a subcommand. Returns NULL if the ensemble has no parent. May be read using Tcl_GetEnsembleParent which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).

The following functions create and manipulate ensemble commands:

Tcl_NewEnsemble
Creates a new, empty ensemble command and returns its token. The command is initially not installed in any interpreter. Use Tcl_AddEnsemble to install it.
Tcl_AddEnsemble
Installs the ensemble command represented by token as a subcommand of the ensemble represented by subcommand. The new ensemble will be created in the namespace that is the parent of subcommand. If subcommand is NULL, the new ensemble is created in the current namespace of the interpreter.
Tcl_DisownEnsemble
Removes an ensemble from its parent ensemble. The ensemble command itself is not deleted, but it is no longer accessible as a subcommand. This is called automatically when a namespace is deleted.

The functions Tcl_GetEnsembleSubcommandList, Tcl_SetEnsembleSubcommandList, Tcl_GetEnsembleUnknownHandler, Tcl_SetEnsembleUnknownHandler, Tcl_GetEnsembleNamespace, Tcl_SetEnsembleNamespace, Tcl_GetEnsembleMapping, Tcl_SetEnsembleMapping, and Tcl_GetEnsembleParent all return a Tcl result code of TCL_OK on success, or TCL_ERROR if the token does not refer to an ensemble. The Tcl objects returned by the *_Get* functions should be treated as immutable even if they are unshared.

The function Tcl_Panic is used to indicate an unrecoverable error. It prints the given message to standard error and terminates the process.
