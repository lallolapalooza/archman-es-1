DESCRIPCIÓN

Un método es una operación realizada sobre un objeto asociado con el objeto. Cada método debe estar asociado con un objeto o una clase; los métodos asociados a una clase se asocian con todas las instancias (directas e indirectas) de esa clase.

Dado un método, se puede encontrar la declaración del método usando Tcl_MethodDeclarerClass, que devuelve la clase a la que está asociado el método (o NULL si el método no está asociado a ninguna clase) y Tcl_MethodDeclarerObject, que devuelve el objeto al cual está asociado el método (o NULL si el método no está asociado a un objeto). El nombre del método puede recuperarse con Tcl_MethodName y la exportación del método puede recuperarse con Tcl_MethodIsPublic. También se puede investigar el tipo del método en un grado limitado; la función Tcl_MethodIsType devuelve si un método es de un tipo específico, asignando el valor clientData a la variable señalada por clientDataPtr si (y solo si) el tipo coincide.

CREACIÓN DE MÉTODOS

Los métodos se crean con Tcl_NewMethod y Tcl_NewInstanceMethod, que crean un método asociado a una clase o a un objeto respectivamente. En ambos casos, el argumento nameObj proporciona el nombre del método a crear, el argumento isPublic indica si el método debe exportarse inicialmente, el argumento methodTypePtr describe la implementación del método (ver la sección TIPOS DE MÉTODOS siguiente) y el argumento clientData proporciona algunos datos específicos de implementación que se pasan a la implementación del método cuando se llama.

Si el argumento nameObj de Tcl_NewMethod es NULL, se crea un método sin nombre, que se usa para constructores y destructores. Los constructores deben instalarse en su clase con la función Tcl_ClassSetConstructor, y los destructores (que no requieren argumentos) deben instalarse en su clase con la función Tcl_ClassSetDestructor. Los métodos sin nombre no deben usarse para ningún otro propósito que no sea constructor o destructor, y los métodos nombrados no deben usarse como constructores o destructores. Además, un methodTypePtr NULL se usa para proporcionar una señal interna y no debe usarse en el código del usuario.

CONTEXTOS DE LLAMADA A MÉTODOS

Cuando se llama un método, se pasa un referente de contexto de llamada a métodos como uno de los argumentos de la función de implementación. Este contexto puede ser inspeccionado para proporcionar información sobre el llamador, pero no debe ser devuelto después de que el método se complete.

El método que se está llamando se puede recuperar mediante Tcl_ObjectContextMethod, y el objeto que causó la invocación del método se puede recuperar con Tcl_ObjectContextObject. El número de argumentos que se omiten (por ejemplo, el nombre del objeto y el nombre del método en una invocación normal) se lee con Tcl_ObjectContextSkippedArgs, y el contexto también puede reportar si está trabajando como un filtro para otro método mediante Tcl_ObjectContextIsFiltering.

Durante la ejecución de un método, el implementador del método puede elegir invocar las etapas de la cadena de llamada de métodos que vienen después del método actual. Esto (el núcleo del comando next) se realiza mediante Tcl_ObjectContextInvokeNext. Nota: esta función no modifica la pila de llamada, a diferencia del comando next; si el implementador del método ha agregado uno o más frames adicionales a la pila como parte de su implementación, también debe ser responsable de eliminar temporalmente esos frames de la pila mientras la función Tcl_ObjectContextInvokeNext está en ejecución. Nota también: el contexto de llamada nunca se elimina durante la ejecución de esta función.

TIPOS DE MÉTODOS

Los tipos de métodos se describen mediante un puntero a una estructura Tcl_MethodType, que se define así:

typedef struct {
    int version;
    const char *name;
    Tcl_MethodCallProc *callProc;
    Tcl_MethodDeleteProc *deleteProc;
    Tcl_CloneProc *cloneProc;
} Tcl_MethodType;

El campo version permite la expansión futura de la estructura, y debe declararse siempre igual a TCL_OO_METHOD_VERSION_CURRENT. El campo name proporciona un nombre legible por humanos para el tipo, y es el valor que se expone mediante los comandos info class methodtype y info object methodtype de Tcl.

El campo callProc proporciona una función que se llama cuando se invoca el método; debe ser siempre no NULL.

El campo deleteProc proporciona una función que se usa para eliminar un método específico, y se llama cuando el método se reemplaza o se elimina; si el campo es NULL, se asume que el clientData del método no necesita ninguna acción especial para su eliminación.

El campo cloneProc es una función que se usa para copiar el clientData de un método (como parte de Tcl_CopyObjectInstance) o NULL para indicar que el clientData puede ser copiado directamente.

NAME

Tcl_NewMethod, Tcl_NewConstructor, Tcl_NewInstanceMethod, Tcl_MethodCallProc, Tcl_MethodDeleteProc, Tcl_CloneProc - create and manage TclOO methods

SYNOPSIS

#include <tclOO.h>
Tcl_Method
Tcl_NewMethod(interp, name, callProc, clientData,
        deleteProc);
Tcl_Method
Tcl_NewConstructor(interp, name, callProc,
        clientData, deleteProc);
Tcl_Method
Tcl_NewInstanceMethod(interp, name, callProc,
        clientData, deleteProc, cloneProc);

ARGUMENTS

Tcl_Interp *interp (in)
Interpreter to use for error reporting and object creation.
const char *name (in)
The name of the method.
Tcl_MethodCallProc *callProc (in)
The procedure to call when the method is invoked.
ClientData clientData (in)
Arbitrary data associated with the method.
Tcl_MethodDeleteProc *deleteProc (in)
Procedure to call when the method is deleted.
Tcl_CloneProc *cloneProc (in)
Procedure to call when the method is copied.

DESCRIPTION

These functions are used to create new methods that can be added to classes or objects.

Tcl_NewMethod
Creates a new method with the given name and procedure to call when it is invoked.
Tcl_NewConstructor
Creates a new constructor method. This is a special type of method that is invoked when an object is created.
Tcl_NewInstanceMethod
Creates a new instance method. This is a method that is associated with a specific object instance.

The clientData argument is a value that will be passed to the method's call procedure, delete procedure, and clone procedure. This allows methods to maintain state.

The deleteProc argument is a procedure that will be called when the method is deleted. This is useful for freeing any resources allocated by the method's clientData.

The cloneProc argument is a procedure that will be called when the method is copied. This is useful for creating a deep copy of the method's clientData.

METHOD TYPES

There are three types of methods:

Method
A general-purpose method that can be invoked on an object or class.
Constructor
A special method that is invoked when an object is created.
Instance Method
A method that is associated with a specific object instance.

The following callback signatures are used for methods:

TCL_METHODCALLPROC FUNCTION SIGNATURE

Functions matching this signature are called when the method is invoked.

typedef int Tcl_MethodCallProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_ObjectContext objectContext,
        int objc,
        Tcl_Obj *const *objv);

The clientData argument to a Tcl_MethodCallProc is the value that was given when the method was created, the interp is a place in which to execute scripts and access variables as well as being where to put the result of the method, and the objc and objv fields give the parameter objects to the method. The calling context of the method can be discovered through the objectContext argument, and the return value from a Tcl_MethodCallProc is any Tcl return code (e.g. TCL_OK, TCL_ERROR).

TCL_METHODDELETEPROC FUNCTION SIGNATURE

Functions matching this signature are used when a method is deleted, whether through a new method being created or because the object or class is deleted.

typedef void Tcl_MethodDeleteProc(
        ClientData clientData);

The clientData argument to a Tcl_MethodDeleteProc will be the same as the value passed to the clientData argument to Tcl_NewMethod or Tcl_NewInstanceMethod when the method was created.

TCL_CLONEPROC FUNCTION SIGNATURE

Functions matching this signature are used to copy a method when the object or class is copied using Tcl_CopyObjectInstance (or oo::copy).

typedef int Tcl_CloneProc(
        Tcl_Interp *interp,
        ClientData oldClientData,
        ClientData *newClientDataPtr);

The interp argument gives a place to write an error message when the attempt to clone the object is to fail, in which case the clone procedure must also return TCL_ERROR; it should return TCL_OK otherwise. The oldClientData field to a Tcl_CloneProc gives the value from the method being copied from, and the newClientDataPtr field will point to a variable in which to write the value for the method being copied to.
