NOMBRE

Tcl_SetErrno, Tcl_GetErrno, Tcl_ErrnoId, Tcl_ErrnoMsg - manipulan errno para almacenar y recuperar códigos de error

SINÓPSIS

#include <tcl.h>

void
Tcl_SetErrno(errorCode)

int
Tcl_GetErrno()

const char *
Tcl_ErrnoId()

const char *
Tcl_ErrnoMsg(errorCode)

ARGUMENTOS

int errorCode (entrada)
Un código de error POSIX como ENOENT.

DESCRIPCIÓN

Tcl_SetErrno y Tcl_GetErrno proporcionan acceso portátil a la variable errno, que se utiliza para registrar un código de error POSIX después de llamadas al sistema y otras operaciones como Tcl_Gets. Estos procedimientos son necesarios porque los accesos a variables globales no pueden realizarse a través de límites de módulos en algunas plataformas.

Tcl_SetErrno establece la variable errno al valor del argumento errorCode. Los procedimientos C que deseen devolver información de error a sus llamadores a través de errno deben llamar a Tcl_SetErrno en lugar de establecer errno directamente.

Tcl_GetErrno devuelve el valor actual de errno. Los procedimientos que deseen acceder a errno deben llamar a este procedimiento en lugar de acceder a errno directamente.

Tcl_ErrnoId y Tcl_ErrnoMsg devuelven representaciones en cadena de los valores de errno. Tcl_ErrnoId devuelve un identificador textual legible por máquina como “EACCES” que corresponde al valor actual de errno. Tcl_ErrnoMsg devuelve una cadena legible por humanos como “permiso denegado” que corresponde al valor de su argumento errorCode. El argumento errorCode es típicamente el valor devuelto por Tcl_GetErrno. Las cadenas devueltas por estas funciones están asignadas estáticamente y el llamador no debe liberarlas ni modificarlas.
