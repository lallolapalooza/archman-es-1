Tcl_Chdir(3)

Tcl_GetCwd(3) Procedimientos de la biblioteca Tcl Tcl_GetCwd(3)

NOMBRE

Tcl_GetCwd, Tcl_Chdir - manipulan el directorio de trabajo actual

SINOPSIS

#include <tcl.h>

char *
Tcl_GetCwd(interp, bufferPtr)

int
Tcl_Chdir(dirName)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que se informará de un error, si lo hay.
Tcl_DString *bufferPtr (entrada/salida)
Esta cadena dinámica se utiliza para almacenar el directorio de trabajo actual. En el momento de la llamada debe estar sin inicializar o libre. El llamador debe llamar eventualmente a Tcl_DStringFree para liberar cualquier cosa almacenada aquí.
const char *dirName (entrada)
Ruta del archivo en formato UTF-8.

DESCRIPCIÓN

Estos procedimientos pueden utilizarse para manipular el directorio de trabajo actual de la aplicación. Proporcionan acceso a nivel de C a la misma funcionalidad que el comando Tcl pwd.

Tcl_GetCwd devuelve un puntero a una cadena que especifica el directorio actual, o NULL si no se pudo determinar el directorio actual. Si se devuelve NULL, se deja un mensaje de error en el resultado del interp. El almacenamiento de la cadena de resultado se asigna en bufferPtr; el llamador debe llamar a Tcl_DStringFree() cuando el resultado ya no sea necesario. El formato de la ruta es UTF-8.

Tcl_Chdir cambia el directorio de trabajo actual de la aplicación al valor especificado en dirName. El formato de la cadena pasada debe ser UTF-8. La función devuelve -1 en caso de error o 0 si tiene éxito.
