ARGUMENTOS

int intValue (entrada)
Valor entero utilizado para inicializar o establecer un valor Tcl.
long longValue (entrada)
Valor entero largo utilizado para inicializar o establecer un valor Tcl.
Tcl_WideInt wideValue (entrada)
Valor entero ancho utilizado para inicializar o establecer un valor Tcl.
Tcl_Obj *objPtr (entrada/salida)
Para Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj, y Tcl_SetBignumObj, este apunta al valor en el cual se almacenará un valor entero. Para Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj, y Tcl_TakeBignumFromObj, este se refiere al valor desde el cual se obtiene un valor entero.
Tcl_Interp *interp (entrada/salida)
Si no es nulo, se deja un mensaje de error aquí cuando el intento de recuperación de valor entero falla.
int *intPtr (salida)
Almacena el valor entero obtenido de objPtr.
long *longPtr (salida)
Almacena el valor entero largo obtenido de objPtr.
Tcl_WideInt *widePtr (salida)
Almacena el valor entero ancho obtenido de objPtr.
mp_int *bigValue (entrada/salida)
Apunta a una estructura de entero de multiprecisión definida por la librería LibTomMath.
double doubleValue (entrada)
Valor doble desde el cual se determina la parte entera y se usa para inicializar un valor entero de multiprecisión.

DESCRIPCIÓN

Estas funciones se utilizan para crear, modificar y leer valores Tcl que contienen valores enteros.

Hay rutinas diferentes para adaptarse a diferentes tipos de enteros en C con los cuales se puedan intercambiar valores. Las rutinas de intercambio de valores para los tipos de enteros C son int, long int, Tcl_WideInt y mp_int. Los tipos int y long int son proporcionados por el estándar C. El tipo Tcl_WideInt es un typedef que se define como el tipo integral con signo que cubre al menos el rango de 64 bits (-9223372036854775808 a 9223372036854775807). Dependiendo de la plataforma y del compilador C, el tipo real podría ser long int, long long int, __int64 o algo similar. El tipo mp_int es un tipo de multiprecisión definido por la librería LibTomMath de multiprecisión.

Las rutinas Tcl_NewIntObj, Tcl_NewLongObj, Tcl_NewWideIntObj y Tcl_NewBignumObj crean y devuelven un nuevo valor Tcl inicializado al valor entero del argumento. El valor Tcl devuelto no está compartido.

Las rutinas Tcl_SetIntObj, Tcl_SetLongObj, Tcl_SetWideIntObj y Tcl_SetBignumObj establecen el valor de un valor Tcl existente apuntado por objPtr al valor entero proporcionado por el otro argumento. El argumento objPtr debe apuntar a un valor Tcl no compartido. Cualquier intento de establecer el valor de un valor compartido viola la política de copia en escritura de Tcl. Cualquier representación de cadena o interna en el valor no compartido se liberará como consecuencia de establecer el nuevo valor.

Las rutinas Tcl_GetIntFromObj, Tcl_GetLongFromObj, Tcl_GetWideIntFromObj, Tcl_GetBignumFromObj y Tcl_TakeBignumFromObj intentan recuperar un valor entero del tipo adecuado del valor Tcl apuntado por objPtr. Si el intento tiene éxito, se devuelve TCL_OK y el valor se escribe en el almacenamiento proporcionado por el llamador. El intento puede fallar si objPtr no contiene un valor entero, o si el valor excede el rango del tipo de destino. Si el intento falla, se devuelve TCL_ERROR y, si interp no es nulo, se deja un mensaje de error en interp. El tipo Tcl_ObjType de objPtr puede cambiar para hacer las llamadas posteriores más eficientes. A diferencia de otras funciones, Tcl_TakeBignumFromObj puede establecer el contenido del valor Tcl objPtr en una cadena vacía durante el proceso de recuperación del valor entero de multiprecisión.

La elección entre Tcl_GetBignumFromObj y Tcl_TakeBignumFromObj se rige por cómo el llamador continuará utilizando objPtr. Si después de recuperar el valor mp_int de objPtr, el llamador no utilizará más objPtr, entonces usar Tcl_TakeBignumFromObj permite a Tcl detectar cuándo un valor no compartido objPtr permite mover el valor en lugar de copiarlo, lo cual debería ser más eficiente. Si alguna parte posterior del llamador requiere que objPtr continúe manteniendo el mismo valor, entonces debe usarse Tcl_GetBignumFromObj.

La rutina Tcl_InitBignumFromDouble es una rutina de utilidad que extrae la parte entera de doubleValue y almacena ese valor entero en el valor mp_int bigValue.
