Tcl_Sleep(3) Procedimientos de la biblioteca Tcl Tcl_Sleep(3)

NOMBRE

Tcl_Sleep - retrasa la ejecución durante un número determinado de milisegundos

SINOPSIS

#include <tcl.h>

Tcl_Sleep(ms)

ARGUMENTOS

int ms (entrada)
Número de milisegundos para dormir.

DESCRIPCIÓN

Este procedimiento retrasa el proceso que llama por el número de milisegundos dado por el parámetro ms y regresa después de que haya transcurrido ese tiempo. Se utiliza típicamente para cosas como hacer parpadear un botón, donde el retraso es corto y la aplicación no necesita hacer nada mientras espera. Para retrasos más largos donde la aplicación necesita responder a otros eventos durante el retraso, se debe usar el procedimiento Tcl_CreateTimerHandler en lugar de Tcl_Sleep.

PALABRAS CLAVE

dormir, tiempo, esperar
