NOMBRE

TCGETS, TCSETS, TCSETSW, TCSETSF, TCGETS2, TCSETS2, TCSETSW2, TCSETSF2, TCGETA, TCSETA, TCSETAW, TCSETAF - obtener y establecer atributos de terminal

#include <sys/ioctl.h>
int ioctl(int fd, TCGETS, struct termios *argp);

DESCRIPCIÓN

TCGETS
Equivalente a tcgetattr(fd, argp).
Obtiene la configuración actual del puerto serie.
TCSETS
Equivalente a tcsetattr(fd, TCSANOW, argp).
Establece la configuración actual del puerto serie.
TCSETSW
Equivalente a tcsetattr(fd, TCSADRAIN, argp).
Permite que el búfer de salida se vacíe y establece la configuración actual del puerto serie.
TCSETSF
Equivalente a tcsetattr(fd, TCSAFLUSH, argp).
Permite que el búfer de salida se vacíe, descarta la entrada pendiente y establece la configuración actual del puerto serie.

Los siguientes cuatro ioctls son iguales a TCGETS, TCSETS, TCSETSW, TCSETSF, excepto que toman un struct termios2 * en lugar de un struct termios *. Si el miembro de la estructura c_cflag contiene el indicador BOTHER, entonces la velocidad de transmisión se almacena en los miembros de la estructura c_ispeed y c_ospeed como valores enteros. Estos ioctls no son compatibles con todas las arquitecturas.

ADVERTENCIAS

struct termios de <asm/termbits.h> es diferente e incompatible con struct termios de <termios.h>. Estas llamadas ioctl requieren struct termios de <asm/termbits.h>.

EJEMPLOS

Obtener o establecer una velocidad de transmisión arbitraria en el puerto serie.

/* SPDX-License-Identifier: GPL-2.0-or-later */
#include <asm/termbits.h>
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
#if !defined BOTHER
    fprintf(stderr, "BOTHER no es compatible\n");
    /* El programa puede recurrir a TCGETS/TCSETS con constantes Bnnn */
    exit(EXIT_FAILURE);
#else
    /* Declarar la estructura tio, su tipo depende del ioctl compatible */
# if defined TCGETS2
    struct termios2 tio;
# else
    struct termios tio;
# endif
    int fd, rc;
    if (argc != 2 && argc != 3 && argc != 4) {
        fprintf(stderr, "Uso: %s dispositivo [salida [entrada] ]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_RDWR | O_NONBLOCK | O_NOCTTY);
    if (fd < 0) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /* Obtener la configuración actual del puerto serie a través del ioctl compatible */
# if defined TCGETS2
    rc = ioctl(fd, TCGETS2, &tio);
# else
    rc = ioctl(fd, TCGETS, &tio);
# endif
    if (rc) {
        perror("TCGETS");
        close(fd);
        exit(EXIT_FAILURE);
    }
    /* Cambiar la velocidad de transmisión cuando se proporcionan más argumentos */
    if (argc == 3 || argc == 4) {
        /* Limpiar la velocidad de transmisión de salida actual y rellenar un nuevo valor */
        tio.c_cflag &= ~CBAUD;
        tio.c_cflag |= BOTHER;
        tio.c_ospeed = atoi(argv[2]);
        /* Limpiar la velocidad de transmisión de entrada actual y rellenar un nuevo valor */
        tio.c_cflag &= ~(CBAUD << IBSHIFT);
        tio.c_cflag |= BOTHER << IBSHIFT;
        /* Cuando no se proporciona el 4º argumento, se reutiliza la velocidad de transmisión de salida */
        tio.c_ispeed = (argc == 4) ? atoi(argv[3]) : atoi(argv[2]);
        /* Establecer la nueva configuración del puerto serie a través del ioctl compatible */
# if defined TCSETS2
        rc = ioctl(fd, TCSETS2, &tio);
# else
        rc = ioctl(fd, TCSETS, &tio);
# endif
        if (rc) {
            perror("TCSETS");
            close(fd);
            exit(EXIT_FAILURE);
        }
        /* Y obtener los nuevos valores que realmente se configuraron */
# if defined TCGETS2
        rc = ioctl(fd, TCGETS2, &tio);
# else
        rc = ioctl(fd, TCGETS, &tio);
# endif
        if (rc) {
            perror("TCGETS");
            close(fd);
            exit(EXIT_FAILURE);
        }
    }
    close(fd);
    printf("velocidad de transmisión de salida: %u\n", tio.c_ospeed);
    printf("velocidad de transmisión de entrada: %u\n", tio.c_ispeed);
    exit(EXIT_SUCCESS);
#endif
}

TCSETSF(2) — Linux manual page

NAME

tcgetsp, tcsetsp, tcgetpgrp, tcsetpgrp - control the foreground process group of a terminal

LIBRARY

Realtime Library (libc, -lrt)

SYNOPSIS

#include <termios.h>

pid_t tcgetpgrp(int fd);
int tcsetpgrp(int fd, pid_t pgrp);

DESCRIPTION

The tcgetpgrp() function returns the process group ID (PGID) of the foreground process group on the terminal associated with the file descriptor fd. If the terminal is not associated with a process group, or if an error occurs, -1 is returned and errno is set appropriately.

The tcsetpgrp() function sets the foreground process group of the terminal associated with the file descriptor fd to pgrp. The calling process must have the same terminal associated with one of its file descriptors, and its process group ID must be the same as pgrp. If pgrp is not a valid process group ID, or if an error occurs, -1 is returned and errno is set appropriately.

A terminal can only have one foreground process group at a time. This is the process group that receives terminal-generated signals (like SIGINT, SIGQUIT, SIGTSTP) and is considered to be "controlling" the terminal.

RETURN VALUE

On success, tcgetpgrp() returns the foreground process group ID. On failure, it returns -1 and errno is set.

On success, tcsetpgrp() returns 0. On failure, it returns -1 and errno is set.

ERRORS

EBADF
fd is not a valid file descriptor.
ENOTTY
The file descriptor fd is not associated with a terminal.
EPERM
The calling process does not have the permission to set the foreground process group (e.g., it is not a member of the specified process group or does not have the required capabilities).
EINVAL
pgrp is not a valid process group ID.

HISTORY

These functions first appeared in POSIX.1-1990.

CAVEATS

Calling tcsetpgrp() with a pgrp that is not the calling process's current process group ID or a member of the same session can lead to a race condition. A process should only attempt to become the foreground process group if it is already part of the same session and its process group ID matches the requested pgrp.

EXAMPLES

The following example shows how to get and set the foreground process group of a terminal:

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include termios.h>

int main() {
    pid_t current_pgrp, new_pgrp;
    int fd = STDOUT_FILENO; // Assuming stdout is connected to a terminal

    // Get the current foreground process group
    current_pgrp = tcgetpgrp(fd);
    if (current_pgrp == -1) {
        perror("tcgetpgrp");
        exit(EXIT_FAILURE);
    }
    printf("Current foreground process group ID: %d\n", current_pgrp);

    // Set a new foreground process group (e.g., the current process's group)
    // Note: This is a simplified example. In a real application,
    // you'd likely want to ensure 'new_pgrp' is a valid PGID
    // and that the caller has permission.
    new_pgrp = getpgrp(); // Get the current process group ID
    if (tcsetpgrp(fd, new_pgrp) == -1) {
        perror("tcsetpgrp");
        // Continue execution even if setting fails, just report it.
    } else {
        printf("Successfully set foreground process group to: %d\n", new_pgrp);
    }

    // You could potentially get it again to verify, but it might change
    // immediately if other processes are also interacting with the terminal.

    return 0;
}
