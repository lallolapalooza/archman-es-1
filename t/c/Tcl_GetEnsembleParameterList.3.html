ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el que se creará o encontrará el conjunto. También es donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener NULL para interp, pero todas las demás funciones no deben tenerlo.
const char *name (entrada)
El nombre del comando de conjunto a crear.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres al que se enlazará el comando de conjunto, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto OR de bits de bandera que describen la configuración básica del conjunto. Actualmente, solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando de conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando de conjunto a buscar.
int flags (entrada)
Un conjunto OR de bits de bandera que controlan el comportamiento de Tcl_FindEnsemble. Actualmente, solo TCL_LEAVE_ERR_MSG es soportado.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para probar como un comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la que escribir los bits de bandera actuales del conjunto; actualmente, solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario para usar en el mapeo de subcomando a prefijo de comando de implementación en el conjunto. Puede ser NULL si el diccionario de mapeo debe eliminarse.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la que escribir el diccionario de mapeo actual del conjunto.
Tcl_Obj *listObj (entrada)
Un valor de lista para usar en la lista de parámetros formales pre-subcomando, la lista definida de subcomandos en el diccionario o el prefijo del comando manejador de subcomando desconocido. Puede ser NULL si la lista de subcomandos o el manejador desconocido deben eliminarse.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la que escribir la lista actual de parámetros formales pre-subcomando, la lista definida de subcomandos o el prefijo manejador desconocido actual.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la que escribir el manejador del espacio de nombres al que está enlazado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, enlazado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos de Tcl. El primer argumento del comando de conjunto se interpreta siempre como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean utilizando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete en el que trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que enlazar el conjunto y el conjunto predeterminado de banderas de conjunto. El resultado de la función es el token del comando para el conjunto, que puede usarse para configurar aún más el conjunto utilizando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token de ese comando puede obtenerse usando Tcl_FindEnsemble. Si el nombre de comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Un token de comando puede verificarse para ver si se refiere a un conjunto usando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

banderas (lectura/escritura)
El conjunto de banderas para el conjunto, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX, que se establece cuando los prefijos no ambiguos de subcomandos pueden resolverse a implementaciones, así como las coincidencias exactas. Las banderas se pueden leer y escribir usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el propio comando de conjunto y el nombre del subcomando), o NULL si cada subcomando debe mapearse al comando con el mismo nombre no cualificado en el espacio de nombres enlazado del conjunto. Por defecto es NULL. Se puede leer y escribir usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable, incluso si no se comparte. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente cualificados.
lista formal de parámetros pre-subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Se puede leer y escribir usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable, incluso si no se comparte.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto se deriva de las claves del diccionario de mapeo (ver arriba) o (si eso también es NULL) del conjunto de comandos exportados por el espacio de nombres enlazado. Se puede leer y escribir usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable, incluso si no se comparte.
prefijo de comando manejador de subcomando desconocido (lectura/escritura)
Una lista de palabras para anteponer a cualquier subcomando cuando el subcomando es desconocido para el conjunto (de acuerdo con las reglas de manejo de prefijos actuales). Si este valor es NULL (el valor predeterminado), cualquier subcomando desconocido resulta en un error.
espacio de nombres (solo lectura)
El espacio de nombres al que está enlazado el conjunto. Este valor puede ser leído usando Tcl_GetEnsembleNamespace. El resultado de esta función es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).

FLAGS

Actualmente solo se define el siguiente indicador de conjunto:

TCL_ENSEMBLE_PREFIX
Permite que los prefijos no ambiguos de los nombres de subcomandos se resuelvan a una implementación, además de las coincidencias exactas.

EJEMPLOS

Un ejemplo de cómo crear un conjunto:


    Tcl_Namespace *nsPtr;
    Tcl_Command cmdToken;
    Tcl_Interp *interp;
    ...
    nsPtr = Tcl_CreateNamespace(interp, "myens", NULL);
    cmdToken = Tcl_CreateEnsemble(interp, "mycommand", nsPtr, 0);
    if (cmdToken == NULL) {
        /* handle error */
    }
    Tcl_SetEnsembleParameterList(interp, cmdToken, Tcl_NewListObj());
    Tcl_SetEnsembleSubcommandList(interp, cmdToken, Tcl_NewListObj());
    Tcl_SetEnsembleMappingDict(interp, cmdToken, Tcl_NewDictObj());
    Tcl_SetEnsembleFlags(interp, cmdToken, TCL_ENSEMBLE_PREFIX);
    ...
