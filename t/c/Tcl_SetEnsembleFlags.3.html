ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el que se va a crear o encontrar el conjunto. También donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener un valor NULL para interp, pero todas las demás funciones no deben.
const char *name (entrada)
El nombre del comando de conjunto a crear.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres al que se va a vincular el comando de conjunto, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto OR de bits de bandera que describen la configuración básica del conjunto. Actualmente, solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando de conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando de conjunto a buscar.
int flags (entrada)
Un conjunto OR de bits de bandera que controlan el comportamiento de Tcl_FindEnsemble. Actualmente, solo se admite TCL_LEAVE_ERR_MSG.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para pruebas como comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la que escribir los bits de bandera actuales del conjunto; actualmente, solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario que se utilizará para el mapeo de subcomando a prefijo de comando de implementación en el conjunto. Puede ser NULL si el diccionario de mapeo se va a eliminar.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la que escribir el diccionario de mapeo actual del conjunto.
Tcl_Obj *listObj (entrada)
Un valor de lista que se utilizará para la lista de parámetros formales pre-subcomando, la lista definida de subcomandos en el diccionario o el prefijo del comando manejador de subcomandos desconocidos. Puede ser NULL si la lista de subcomandos o el manejador de desconocidos se van a eliminar.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la que escribir la lista actual de parámetros formales pre-subcomando, la lista definida de subcomandos o el prefijo de comando actual de desconocidos.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la que escribir el manejador del espacio de nombres al que está vinculado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, vinculado a algún espacio de nombres, que consta de una colección de subcomandos implementados por otros comandos de Tcl. El primer argumento al comando de conjunto siempre se interpreta como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean utilizando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete dentro del cual trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que vincular el conjunto y el conjunto predeterminado de banderas de conjunto. El resultado de la función es el token de comando para el conjunto, que puede usarse para configurar aún más el conjunto utilizando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token de ese comando puede recuperarse utilizando Tcl_FindEnsemble. Si el nombre de comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Se puede verificar un token de comando para ver si se refiere a un conjunto utilizando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

flags (lectura/escritura)
El conjunto de banderas para el conjunto, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX, que se establece cuando se permiten prefijos no ambiguos de subcomandos para ser resueltos a implementaciones, así como coincidencias exactas. Las banderas pueden leerse y escribirse utilizando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el propio comando de conjunto y el nombre del subcomando), o NULL si cada subcomando debe mapearse al comando con el mismo nombre no calificado en el espacio de nombres vinculado del conjunto. Por defecto es NULL. Se puede leer y escribir utilizando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable, incluso si no está compartido. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros pre-subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Se puede leer y escribir utilizando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable, incluso si no está compartido.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto se deriva de las claves del diccionario de mapeo (ver arriba) o (si este también es NULL) del conjunto de comandos exportados por el espacio de nombres vinculado. Se puede leer y escribir utilizando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable, incluso si no está compartida.
prefijo de comando manejador de subcomando desconocido (lectura/escritura)
Una lista de palabras para anteponer a cualquier subcomando cuando el subcomando es desconocido para el conjunto (según la regla de manejo de prefijos actual); ver

Tcl_SetEnsembleFlags, Tcl_GetEnsembleFlags, Tcl_SetEnsembleUnknownHandler, Tcl_GetEnsembleUnknownHandler, Tcl_GetEnsembleNamespace - configurar y consultar los atributos de un ensemble

ARGUMENTOS

char *ensembleToken (entrada)
Token del ensemble a consultar o modificar.
Tcl_Obj *flags (entrada)
Lista de objetos Tcl que representan los flags a establecer. 
       TCL_ENSEMBLE_RESET   Reset the ensemble.
       TCL_ENSEMBLE_SUBCOMMANDS
                            The ensemble should be implemented by
                            subcommands. See the
                            namespace ensemble command for more
                            details. If NULL, the default behavior - generate
                            a suitable error message - will be used when an
                            unknown subcommand is encountered. May be read and
                            written using Tcl_GetEnsembleUnknownHandler
                            and Tcl_SetEnsembleUnknownHandler respectively.
                            The result of both functions is a Tcl result code
                            (TCL_OK, or TCL_ERROR if the token
                            does not refer to an ensemble) and the list
                            obtained from Tcl_GetEnsembleUnknownHandler
                            should always be treated as immutable even if it
                            is unshared.

The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).

DESCRIPCIÓN

La comando namespace ensemble se utiliza para crear y administrar ensembles. Los ensembles son un mecanismo de organización de comandos en Tcl, que permite agrupar comandos relacionados bajo un mismo nombre y tratarlos como subcomandos de un comando principal.

La función Tcl_SetEnsembleFlags se utiliza para establecer o eliminar flags asociados a un ensemble específico, identificado por su token. Los flags disponibles son:

  • TCL_ENSEMBLE_RESET: Reinicia el ensemble.
  • TCL_ENSEMBLE_SUBCOMMANDS: Indica que el ensemble debe ser implementado mediante subcomandos. Si este flag no se establece y se invoca un subcomando desconocido, se generará un mensaje de error adecuado.

La función Tcl_GetEnsembleFlags recupera los flags actualmente asociados a un ensemble y los almacena en la ubicación de memoria apuntada por flagsPtr. El resultado de esta función es un código de resultado de Tcl (TCL_OK o TCL_ERROR si el token no se refiere a un ensemble).

Las funciones Tcl_SetEnsembleUnknownHandler y Tcl_GetEnsembleUnknownHandler permiten configurar y consultar el script que se ejecutará cuando se invoque un subcomando desconocido dentro de un ensemble. Si el script es NULL, se utilizará el comportamiento predeterminado (generar un mensaje de error).

La función Tcl_GetEnsembleNamespace recupera el namespace al que está enlazado el ensemble. Cuando el namespace es eliminado, el ensemble también lo será. Este namespace también se utiliza para la lista de comandos exportados si tanto el diccionario de mapeo como la propiedad de la lista de subcomandos son NULL.

Los resultados devueltos por Tcl_GetEnsembleUnknownHandler deben ser tratados como inmutables, incluso si no se comparten.

bound namespace (solo lectura)
El namespace al que está enlazado el ensemble; cuando el namespace se elimina, el ensemble también lo hará, y este namespace es también el namespace cuya lista de comandos exportados se utiliza si tanto el diccionario de mapeo como las propiedades de la lista de subcomandos son NULL. Se puede leer utilizando Tcl_GetEnsembleNamespace, que devuelve un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble).
