Tcl_CreateMathFunc(3) Procedimientos de la biblioteca Tcl Tcl_CreateMathFunc(3)

NOMBRE

Tcl_CreateMathFunc, Tcl_GetMathFuncInfo, Tcl_ListMathFuncs - Definir, consultar y enumerar funciones matemáticas para expresiones

AVISO DE EVENTUAL DEPRECACIÓN

Las funciones Tcl_CreateMathFunc y Tcl_GetMathFuncInfo se vuelven algo obsoletas por la capacidad de crear funciones para expresiones colocando comandos en el espacio de nombres tcl::mathfunc, como se describe en la página del manual mathfunc; no se espera que la API descrita en esta página se mantenga indefinidamente.

SINOPSIS

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,
                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el cual se definirá la nueva función.
const char *name (entrada)
Nombre para la nueva función.
int numArgs (entrada)
Número de argumentos para la nueva función; también da el tamaño del array argTypes.
Tcl_ValueType *argTypes (entrada)
Punta a un array que da los tipos permisibles para cada argumento de la función.
Tcl_MathProc *proc (entrada)
Procedimiento que implementa la función.
ClientData clientData (entrada)
Valor arbitrario de una palabra para pasar a proc cuando se invoque.
int *numArgsPtr (salida)
Punta a una variable que se establecerá para contener el número de argumentos de la función.
Tcl_ValueType **argTypesPtr (salida)
Punta a una variable que se establecerá para contener un puntero a un array que da los tipos permisibles para cada argumento de la función, el cual deberá liberarse usando Tcl_Free.
Tcl_MathProc **procPtr (salida)
Punta a una variable que se establecerá para contener un puntero al código de implementación de la función (o NULL si la función se implementa directamente en bytecode).
ClientData *clientDataPtr (salida)
Punta a una variable que se establecerá para contener el argumento clientData pasado a Tcl_CreateMathFunc cuando se creó la función si la función no se implementa directamente en bytecode.
const char *pattern (entrada)
Patrón para comparar con los nombres de las funciones para filtrarlos (pasando a Tcl_StringMatch), o NULL para no aplicar ningún filtro.

DESCRIPCIÓN

Tcl permite que un número de funciones matemáticas se utilicen en expresiones, como sin, cos e hypot. Estas funciones se representan mediante comandos en el espacio de nombres tcl::mathfunc. La función Tcl_CreateMathFunc es una forma obsoleta para que las aplicaciones añadan funciones adicionales a las ya proporcionadas por Tcl o para reemplazar funciones existentes. No debe ser utilizada por nuevas aplicaciones, las cuales deben crear funciones matemáticas usando Tcl_CreateObjCommand para crear un comando en el espacio de nombres tcl::mathfunc.

En la interfaz Tcl_CreateMathFunc, Name es el nombre de la función tal como aparecerá en las expresiones. Si name no existe ya en el espacio de nombres ::tcl::mathfunc, entonces se crea un nuevo comando en ese espacio de nombres. Si name ya existe, se reemplaza la función existente. NumArgs y argTypes describen los argumentos de la función. Cada entrada en el array argTypes debe ser uno de TCL_INT, TCL_DOUBLE, TCL_WIDE_INT o TCL_EITHER para indicar si el argumento correspondiente debe ser un entero, un valor de punto flotante de doble precisión, un entero ancho (de 64 bits) o cualquiera, respectivamente.

Cada vez que la función se invoque en una expresión, Tcl invocará proc. Proc debe tener argumentos y un resultado que coincidan con el tipo Tcl_MathProc:

typedef int Tcl_MathProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_Value *args,
        Tcl_Value *resultPtr);

Cuando se invoque proc, los argumentos clientData e interp serán los mismos que se pasaron a Tcl_CreateMathFunc. Args apuntará a un array de estructuras Tcl_Value de tamaño numArgs, que describen los argumentos reales de la función:

typedef struct Tcl_Value {
    Tcl_ValueType type;
    long intValue;
    double doubleValue;
    Tcl_WideInt wideValue;
} Tcl_Value;

El campo type indica el tipo del argumento y es uno de TCL_INT, TCL_DOUBLE o TCL_WIDE_INT. Coincidirá con el valor argTypes especificado para la función a menos que el valor argTypes sea TCL_EITHER. Tcl convierte el argumento suministrado en la expresión al tipo solicitado en argTypes, si es necesario. Dependiendo del valor del campo type, el campo intValue, doubleValue o wideValue contendrá el valor real del argumento.

Proc debe calcular su resultado y almacenarlo como un entero en resultPtr->intValue o como un valor flotante en resultPtr->doubleValue. También debe establecer resultPtr->type a uno de TCL_INT, TCL_DOUBLE o TCL_WIDE_INT para indicar qué valor se estableció. En circunstancias normales, proc debería devolver TCL_OK. Si ocurre un error al ejecutar la función, proc debería devolver TCL_ERROR y dejar un mensaje de error en el resultado del intérprete.

Tcl_GetMathFuncInfo recupera los valores asociados con la función name que se pasaron a una llamada anterior de Tcl_CreateMathFunc. Normalmente, el código de retorno es TCL_OK, pero si la función nombrada no existe, se devuelve TCL_ERROR y se coloca un mensaje de error en el resultado del intérprete.

Si no ocurrió un error, la referencia al array colocada en la variable apuntada por argTypesPtr es recién asignada y debe ser liberada pasándola a Tcl_Free. Algunas funciones (el conjunto estándar implementado en el núcleo, y aquellas definidas colocando comandos en el espacio de nombres tcl::mathfunc) no tienen información de tipos de argumentos; intentar recuperar valores para ellas causa que se almacene un NULL en la variable apuntada por procPtr y la variable apuntada por clientDataPtr no se modificará. La variable apuntada por numArgsPointer contendrá -1, y no se almacenarán tipos de argumentos en la variable apuntada por argTypesPointer.

Tcl_ListMathFuncs devuelve un valor Tcl que contiene una lista de todas las funciones matemáticas definidas en el intérprete cuyo nombre coincide con pattern. El valor devuelto tiene un recuento de referencias de cero.

Tcl_CreateMathFunc(3)

NOMBRE

Tcl_CreateMathFunc - crea una función matemática para Tcl

SINAPSIS

#include <tcl.h>

int
Tcl_CreateMathFunc(interp, name, proc, clientData)
    Tcl_Interp *interp;
    const char *name;
    Tcl_MathFunc *proc;
    Tcl_ClientData clientData;

DESCRIPCIÓN

El procedimiento Tcl_CreateMathFunc se usa para crear una nueva función matemática que pueda ser llamada desde Tcl. El argumento interp es el intérprete de Tcl en el que se creará la función. El argumento name es el nombre que tendrá la función en Tcl. El argumento proc es un puntero a la función C que implementará la función matemática. El argumento clientData es un dato de cliente que se pasará a la función proc cada vez que sea llamada.

La función proc debe tener la siguiente firma:

typedef double (*Tcl_MathFunc) (ClientData clientData, Tcl_Interp *interp, int numArgs);

La función proc recibirá el clientData, el intérprete y el número de argumentos pasados a la función. Deberá devolver el resultado de la función matemática como un double. Si ocurre un error, la función deberá establecer un mensaje de error en el intérprete usando Tcl_SetResult y devolver un valor que indique el error (por ejemplo, un valor especial como NaN o lanzar una excepción si el sistema lo soporta).

La función Tcl_CreateMathFunc devuelve TCL_OK si la función se creó correctamente, o TCL_ERROR si ocurrió un error (por ejemplo, si el nombre de la función ya está en uso).
