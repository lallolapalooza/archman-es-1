const char *hiddenCmdName (entrada)

DESCRIPCIÓN

Estos procedimientos están destinados al acceso a la instalación de múltiples intérpretes desde programas C. Permiten gestionar múltiples intérpretes en una relación jerárquica y la gestión de alias, comandos que, cuando se invocan en un intérprete, ejecutan un comando en otro intérprete. El valor de retorno para aquellos procedimientos que devuelven un int es TCL_OK o TCL_ERROR. Si se devuelve TCL_ERROR, el resultado del intérprete contiene un mensaje de error.

Tcl_CreateSlave crea un nuevo intérprete como hijo de interp. También crea un comando hijo llamado childName en interp que permite a interp manipular al nuevo hijo. Si isSafe es cero, el comando crea un hijo confiable en el que el código Tcl tiene acceso a todos los comandos Tcl. Si es 1, el comando crea un hijo “seguro” en el que el código Tcl solo tiene acceso al conjunto de comandos Tcl definidos como “Safe Tcl”; consulte la entrada del manual para el comando interp de Tcl para obtener más detalles. Si la creación del nuevo intérprete hijo falló, se devuelve NULL.

Tcl_CreateChild es un sinónimo de Tcl_CreateSlave.

Tcl_IsSafe devuelve 1 si interp es “seguro” (fue creado con el indicador TCL_SAFE_INTERPRETER especificado), 0 de lo contrario.

Tcl_MakeSafe marca interp como “seguro”, de modo que las llamadas futuras a Tcl_IsSafe devuelvan 1. También elimina toda la funcionalidad principal potencialmente insegura conocida (tanto comandos como variables) de interp. Sin embargo, no puede saber qué partes de una extensión o aplicación son seguras y no intenta eliminar esas partes, por lo que la seguridad no está garantizada después de llamar a Tcl_MakeSafe. Los llamantes querrán tener cuidado con su uso de Tcl_MakeSafe para evitar falsas afirmaciones de seguridad. Para muchas situaciones, Tcl_CreateSlave puede ser una mejor opción, ya que crea intérpretes en un estado de seguridad conocido.

Tcl_GetSlave devuelve un puntero a un intérprete hijo de interp. El intérprete hijo se identifica por childName. Si no existe dicho intérprete hijo, se devuelve NULL.

Tcl_GetChild es un sinónimo de Tcl_GetSlave.

Tcl_GetMaster devuelve un puntero al intérprete maestro de interp. Si interp no tiene maestro (es un intérprete de nivel superior), se devuelve NULL.

Tcl_GetParent es un sinónimo de Tcl_GetMaster.

Tcl_GetInterpPath almacena en el resultado de interp la ruta relativa entre interp y childInterp; childInterp debe ser hijo de interp. Si el cálculo de la ruta relativa tiene éxito, se devuelve TCL_OK, de lo contrario, se devuelve TCL_ERROR y se almacena un mensaje de error como resultado de interp.

Tcl_CreateAlias crea un comando llamado childCmd en childInterp que, cuando se invoca, hará que se invoque el comando targetCmd en targetInterp. Los argumentos especificados por las cadenas contenidas en argv se anteponen siempre a cualquier argumento suministrado en la invocación de childCmd y se pasan a targetCmd. Esta operación devuelve TCL_OK si tiene éxito, o TCL_ERROR si falla; en ese caso, queda un mensaje de error en el resultado del valor de childInterp. Tenga en cuenta que no hay restricciones en la relación de ascendencia (tal como se creó con Tcl_CreateSlave) entre childInterp y targetInterp. Se pueden utilizar dos intérpretes cualesquiera, sin restricciones sobre cómo están relacionados.

Tcl_CreateAliasObj es similar a Tcl_CreateAlias excepto que toma un vector de valores para pasar como argumentos adicionales en lugar de un vector de cadenas.

Tcl_GetAliasObj devuelve información en forma de un puntero a un vector de estructuras Tcl_Obj sobre un alias aliasName en interp. Cualquiera de los campos de resultado puede ser NULL, en cuyo caso el dato correspondiente no se devuelve. Si un campo de resultado no es NULL, la dirección indicada se establece en el dato correspondiente. Por ejemplo, si targetCmdPtr no es NULL, se establece en un puntero a la cadena que contiene el nombre del comando de destino.

Tcl_GetAlias es similar a Tcl_GetAliasObj excepto que devuelve un puntero a un vector de cadenas en lugar de un vector de estructuras Tcl_Obj. Tcl_GetAlias está obsoleto.

Tcl_HideCommand oculta el comando cmdName en el intérprete interp. El comando oculto se puede hacer visible más tarde mediante Tcl_ExposeCommand o se puede invocar utilizando el nombre hiddenCmdName. Si se intenta ocultar un comando que no existe, o si ya existe un comando con el nombre hiddenCmdName, se devuelve TCL_ERROR.

Tcl_ExposeCommand hace visible el comando oculto en el intérprete interp con el nombre cmdName. Si no existe un comando oculto con el nombre hiddenCmdName, o si ya existe un comando llamado cmdName, se devuelve TCL_ERROR.

Tcl_GetAlias(3) - Tcl API Documentation

NAME

Tcl_GetAlias, Tcl_CreateAlias, Tcl_DeleteAlias, Tcl_ExposeCommand, Tcl_HideCommand – manipulate command aliases

SYNOPSIS

#include <tcl.h>

int
Tcl_GetAlias(interp, cmdName, numChars, aliasPtr);
int
Tcl_CreateAlias(interp, cmdName, resultProc, clientData, deleteProc);
int
Tcl_DeleteAlias(interp, cmdName);
int
Tcl_ExposeCommand(interp, hiddenCmdName, cmdName);
int
Tcl_HideCommand(interp, cmdName, hiddenCmdName);

ARGUMENTS

interp (Tcl_Interp*)
Interpreter to operate in.
cmdName (const char*)
Name of the command to get, create, delete, expose or hide.
numChars (int)
Number of characters in cmdName.
aliasPtr (char**)
Address to store a pointer to the alias command.
resultProc (Tcl_CmdProc*)
Procedure to execute for the alias.
clientData (ClientData)
Arbitrary one-word value to pass to resultProc.
deleteProc (Tcl_CmdDeleteProc*)
Procedure to call when the alias is deleted.
hiddenCmdName (const char*)
Name of the hidden command.

DESCRIPTION

Tcl allows commands to be aliased, so that a single command can be implemented by multiple Tcl commands. The Tcl command alias creates a new command whose effect is to invoke another command. The Tcl command unalias removes a command alias. This provides a way to implement new commands that are simply front-ends to existing commands, possibly with modified arguments. The C API provides Tcl_GetAlias, Tcl_CreateAlias, and Tcl_DeleteAlias for the same purpose.

Tcl_GetAlias returns the command associated with cmdName. If cmdName does not exist or is not an alias, it returns TCL_ERROR and leaves an error message as the result of interp. If cmdName exists and is an alias, it returns TCL_OK and stores a pointer to the alias command in aliasPtr.

Tcl_CreateAlias creates a new alias command named cmdName. When this command is invoked, resultProc will be called with clientData and the interpreter's arguments. When the alias is deleted, deleteProc will be called with clientData. Both resultProc and deleteProc may be NULL. The return value is TCL_OK on success and TCL_ERROR on failure (e.g., if cmdName already exists).

Tcl_DeleteAlias removes the alias command named cmdName. If cmdName does not exist or is not an alias, it returns TCL_ERROR and leaves an error message as the result of interp. If the alias is successfully deleted, deleteProc (if not NULL) will be called with clientData. The return value is TCL_OK on success and TCL_ERROR on failure.

The commands Tcl_ExposeCommand and Tcl_HideCommand are used to manage hidden and exposed commands within an interpreter. When a command is created, it is initially an exposed command. It can be moved to the set of hidden commands using Tcl_HideCommand, and moved back to the set of exposed commands using Tcl_ExposeCommand.

Hidden commands are not visible to Tcl scripts in the normal way. They can only be invoked indirectly, for example, by being aliased to an exposed command. Exposed commands are visible and can be invoked directly by Tcl scripts.

Tcl_ExposeCommand moves the command named hiddenCmdName from the set of hidden commands to the set of exposed commands, putting it under the name cmdName. HiddenCmdName must be the name of an existing hidden command, or the operation will return TCL_ERROR and leave an error message as the result of interp. If an exposed command named cmdName already exists, the operation returns TCL_ERROR and leaves an error message as the result of interp. If the operation succeeds, it returns TCL_OK. After executing this command, attempts to use cmdName in any script evaluation mechanism will again succeed.

Tcl_HideCommand moves the command named cmdName from the set of exposed commands to the set of hidden commands, under the name hiddenCmdName. CmdName must be the name of an existing exposed command, or the operation will return TCL_ERROR and leave an error message as the result of interp. Currently both cmdName and hiddenCmdName must not contain namespace qualifiers, or the operation will return TCL_ERROR and leave an error message as the result of interp. The CmdName will be looked up in the global namespace, and not relative to the current namespace, even if the current namespace is not the global one. If a hidden command whose name is hiddenCmdName already exists, the operation also returns TCL_ERROR and an error message is left as the result of interp. If the operation succeeds, it returns TCL_OK. After executing this command, attempts to use cmdName in any script evaluation mechanism will fail.

For a description of the Tcl interface to multiple interpreters, see interp(n).
