ARGUMENTOS

Tcl_Interp *interp (in/out)
El intérprete en el que se va a crear o encontrar el conjunto. También donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener un NULL para el interp, pero todas las demás funciones no deben.
const char *name (in)
El nombre del comando de conjunto a crear.
Tcl_Namespace *namespacePtr (in)
El espacio de nombres al que se va a vincular el comando de conjunto, o NULL para el espacio de nombres actual.
int ensFlags (in)
Un conjunto de bits de bandera OR'ed que describen la configuración básica del conjunto. Actualmente solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando de conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (in)
Un valor que contiene el nombre del comando de conjunto a buscar.
int flags (in)
Un conjunto de bits de bandera OR'ed que controlan el comportamiento de Tcl_FindEnsemble. Actualmente solo TCL_LEAVE_ERR_MSG está soportado.
Tcl_Command token (in)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para pruebas como un comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Puntero a una variable en la que escribir los bits de bandera actuales del conjunto; actualmente solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (in)
Un valor de diccionario para usar en el mapeo de subcomando a prefijo de comando de implementación en el conjunto. Puede ser NULL si se va a eliminar el diccionario de mapeo.
Tcl_Obj **dictObjPtr (out)
Puntero a una variable en la que escribir el diccionario de mapeo actual del conjunto.
Tcl_Obj *listObj (in)
Un valor de lista para usar en la lista de parámetros formales pre-subcomando, la lista de subcomandos definidos en el diccionario o el prefijo de comando del manejador de subcomandos desconocido. Puede ser NULL si la lista de subcomandos o el manejador desconocido se van a eliminar.
Tcl_Obj **listObjPtr (out)
Puntero a una variable en la que escribir la lista actual de parámetros formales pre-subcomando, la lista de subcomandos definidos o el prefijo del manejador desconocido actual.
Tcl_Namespace **namespacePtrPtr (out)
Puntero a una variable en la que escribir el manejador del espacio de nombres al que está vinculado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, vinculado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos Tcl. El primer argumento del comando de conjunto siempre se interpreta como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete dentro del cual trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que vincular el conjunto, y el conjunto predeterminado de banderas de conjunto. El resultado de la función es el token del comando para el conjunto, que puede usarse para configurar aún más el conjunto usando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token de ese comando puede obtenerse usando Tcl_FindEnsemble. Si el nombre de comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Se puede verificar un token de comando para ver si se refiere a un conjunto usando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura-escritura y una propiedad de solo lectura. Las propiedades son:

flags (lectura-escritura)
El conjunto de banderas para el conjunto, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX que se establece cuando se permiten prefijos no ambiguos de subcomandos para ser resueltos a implementaciones, así como coincidencias exactas. Las banderas pueden leerse y escribirse usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura-escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el comando de conjunto en sí y el nombre del subcomando), o NULL si cada subcomando debe mapearse al comando con el mismo nombre no calificado en el espacio de nombres vinculado del conjunto. Por defecto es NULL. Puede leerse y escribirse usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable, incluso si no está compartido. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros pre-subcomando (lectura-escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Puede leerse y escribirse usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable, incluso si no está compartido.
lista de subcomandos (lectura-escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto se deriva de las claves del diccionario de mapeo (ver arriba) o (si este último también es NULL) de el conjunto de comandos exportados por el espacio de nombres vinculado. Puede leerse y escribirse usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable incluso si no está compartido.
prefijo de comando del manejador de subcomando desconocido (lectura-escritura)
Una lista de palabras para anteponer a cualquier subcomando cuando el subcomando es desconocido para el conjunto (según las reglas actuales de manejo de prefijos

o si el subcomando no se encuentra en el diccionario de mapeo ni en la lista de subcomandos). Si es NULL (el valor predeterminado), los subcomandos desconocidos fallan con un error. Puede leerse y escribirse usando Tcl_GetEnsembleUnknownHandler y Tcl_SetEnsembleUnknownHandler respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleUnknownHandler debe tratarse como inmutable, incluso si no está compartida. Todos los nombres de comandos en los prefijos de manejadores desconocidos deben estar completamente calificados.

Finalmente, puede obtenerse el espacio de nombres al que está vinculado un conjunto usando Tcl_GetEnsembleNamespace. El resultado es un código de resultado Tcl y el puntero a espacio de nombres se coloca en la variable a la que apunta namespacePtrPtr.

NIVEL DE TECNOLOGÍA

Este API solo está disponible en Tcl 8.6 y versiones posteriores.
