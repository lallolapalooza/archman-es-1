Tcl_ListObj(3) Procedimientos de la biblioteca Tcl Tcl_ListObj(3)

NOMBRE

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipular valores Tcl como listas

SINAPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTOS

Tcl_Interp *interp (in)
Si ocurre un error durante la conversión de un valor a un valor de lista, se deja un mensaje de error en el valor de resultado del intérprete, a menos que interp sea NULL.
Tcl_Obj *listPtr (in/out)
Indica el valor de lista a manipular. Si listPtr no ya apunta a un valor de lista, se intentará convertirlo a uno.
Tcl_Obj *elemListPtr (in/out)
Para Tcl_ListObjAppendList, esta apunta a un valor de lista que contendrá los elementos a añadir a listPtr. Cada elemento de *elemListPtr se convierte en un nuevo elemento de listPtr. Si *elemListPtr no es NULL y no ya apunta a un valor de lista, se intentará convertirlo a uno.
Tcl_Obj *objPtr (in)
Para Tcl_ListObjAppendElement, apunta al valor Tcl a añadir a listPtr. Para Tcl_SetListObj, apunta al valor Tcl que se convertirá en un valor de lista que contiene los objc elementos del array referido por objv.
int *objcPtr (in)
Apunta a la ubicación donde Tcl_ListObjGetElements almacena el número de valores de elemento en listPtr.
Tcl_Obj ***objvPtr (out)
Una ubicación donde Tcl_ListObjGetElements almacena un puntero a un array de punteros a los valores de elemento de listPtr.
int objc (in)
El número de valores Tcl que Tcl_NewListObj insertará en un nuevo valor de lista, y Tcl_ListObjReplace insertará en listPtr. Para Tcl_SetListObj, el número de valores Tcl a insertar en objPtr.
Tcl_Obj *const objv[] (in)
Un array de punteros a valores. Tcl_NewListObj insertará estos valores en un nuevo valor de lista y Tcl_ListObjReplace insertará ellos en un valor existente de listPtr. Cada valor se convierte en un elemento separado de la lista.
int *lengthPtr (out)
Apunta a la ubicación donde Tcl_ListObjLength almacena la longitud de la lista.
int index (in)
Índice del elemento de lista que Tcl_ListObjIndex devuelve. El primer elemento tiene índice 0.
Tcl_Obj **objPtrPtr (out)
Apunta a la ubicación donde Tcl_ListObjIndex almacena un puntero al valor del elemento de lista resultante.
int first (in)
Índice del primer elemento de lista que Tcl_ListObjReplace reemplaza. El primer elemento tiene índice 0.
int count (in)
El número de elementos que Tcl_ListObjReplace reemplaza.

DESCRIPCIÓN

Los valores de lista de Tcl tienen una representación interna que soporta la indexación eficiente y la concatenación. Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar y concatenar valores de lista de Tcl desde código C.

Tcl_ListObjAppendList y Tcl_ListObjAppendElement añaden uno o más valores al final del valor de lista referido por listPtr. Tcl_ListObjAppendList añade cada elemento del valor de lista referido por elemListPtr, mientras que Tcl_ListObjAppendElement añade el valor individual referido por objPtr. Ambos procedimientos convertirán el valor referido por listPtr a un valor de lista si es necesario. Si ocurre un error durante la conversión, ambos procedimientos devolverán TCL_ERROR y dejarán un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De igual forma, si elemListPtr no ya refiere a un valor de lista, Tcl_ListObjAppendList intentará convertirlo a uno y, si ocurre un error durante la conversión, devolverá TCL_ERROR y dejará un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación antigua de listPtr y, si fue convertido a un valor de lista, liberarán cualquier representación interna antigua. Similarmente, Tcl_ListObjAppendList liberará cualquier representación interna antigua de elemListPtr si lo convierte en un valor de lista. Después de añadir cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias de los elementos, ya que listPtr ahora también lo refiere. Por el mismo motivo, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no hay errores, los dos procedimientos devolverán TCL_OK después de añadir los valores.

Tcl_NewListObj y Tcl_SetListObj crean un nuevo valor o modifican un valor existente para contener los objc elementos del array referido por objv, donde cada elemento es un puntero a un valor Tcl. Si objc es menor o igual a cero, devuelven un valor vacío. Si objv es NULL, el valor de lista resultante contiene 0 elementos, con espacio reservado en la representación interna para más elementos (objc) (para evitar su reasignación posterior). El nuevo valor tiene una representación de cadena invalida. Los dos procedimientos incrementan los contadores de referencias de los elementos en objc, ya que el valor de lista ahora los refiere. El valor de lista devuelto por Tcl_NewListObj tiene un contador de referencias igual a cero.

Tcl_ListObjGetElements devuelve un contador y un puntero a un array de los elementos de un valor de lista. El contador se almacena en la dirección objcPtr, mientras que el puntero al array se almacena en la dirección objvPtr. La memoria apuntada se gestiona por Tcl y no debe liberarse ni modificarse por el llamador. Si el valor de lista está vacío, 0 se almacena en objcPtr y NULL en objvPtr. Si listPtr no ya es un valor de lista, Tcl_ListObjGetElements intentará convertirlo a uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar el contador y el puntero al array.

Tcl_ListObjLength devuelve el número de elementos en el valor de lista referido por listPtr. El contador se almacena en la dirección lengthPtr. Si el valor no ya es un valor de lista, Tcl_ListObjLength intentará convertirlo a uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar la longitud del valor de lista.

El procedimiento Tcl_ListObjIndex devuelve un puntero al valor en el elemento index del valor de lista referido por listPtr. El valor se almacena en la dirección objPtrPtr como un puntero a él. Si listPtr no ya refiere a un valor de lista, Tcl_ListObjIndex intentará convertirlo a uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Si el índice está fuera de rango, es decir, index es negativo o mayor que el número de elementos en la lista, Tcl_ListObjIndex almacena NULL en objPtrPtr y devuelve TCL_OK. De lo contrario, devuelve TCL_OK después de almacenar el puntero al valor del elemento. El contador de referencias del elemento de lista no se incrementa; el llamador debe hacerlo si necesita conservar un puntero a él.

Tcl_ListObjReplace reemplaza cero o más elementos de la lista referida por listPtr con los objc valores del array referido por objv. Si listPtr no apunta a un valor de lista, Tcl_ListObjReplace intentará convertirlo a uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de reemplazar los valores. Si objv es NULL, no se añaden nuevos elementos. Si el argumento first es cero o negativo, se refiere al primer elemento. Si first es mayor o igual a count, se reemplaza el primer elemento.

Tcl_ListObjReplace(3) - Arch Linux manual page

NAME

Tcl_ListObjReplace

replace elements in a list

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)
    Tcl_Interp *interp;
    Tcl_Obj *listPtr;
    int first;
    int count;
    int objc;
    const Tcl_Obj *const objv[];

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_Obj *listPtr
Object whose list value is to be modified. This object must have type TCL_LIST_OBJ.
int first
Index of the first element to replace. If first is negative, it is treated as 0. If first is greater than the number of elements in the list, it is treated as the number of elements in the list.
int count
Number of elements to delete. If count is negative or zero, then no elements are deleted.
int objc
Number of new elements to insert. If objc is zero then no elements are inserted.
const Tcl_Obj *const objv[]
Array of objects to insert into the list. Ignored if objc is zero.

DESCRIPTION

Tcl_ListObjReplace is used to replace a part of a list with new elements. The list object referred to by listPtr is modified by deleting count elements starting at index first, and then inserting the objc elements from the array objv at that position.

The indices for list elements start at 0. If first is greater than or equal to the number of elements in the list, the new elements are appended to the end of the list. If count is greater than the number of elements available starting at first, then all elements from first to the end of the list are deleted. If count is negative or zero, no elements are deleted. If objc is zero, no elements are inserted.

If count is zero or negative, and objc is positive, then the new elements are inserted into the list just before the element at index first. The original elements are not deleted. If first is greater than the current number of elements in the list, the new elements are appended to the end of the list.

If objc is zero, then the operation is just a deletion of count elements starting at first. If count is also zero or negative, then no elements are deleted; the new elements are appended to the list.

Tcl_ListObjReplace invalidates listPtr's old string representation. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

Because Tcl_ListObjReplace combines both element insertion and deletion, it can be used to implement a number of list operations. For example, the following code inserts the objc values referenced by the array of value pointers objv just before the element index of the list referenced by listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

Similarly, the following code appends the objc values referenced by the array objv to the end of the list listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

The count list elements starting at first can be deleted by simply calling Tcl_ListObjReplace with a NULL objvPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
