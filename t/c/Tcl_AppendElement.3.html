DESCRIPCIÓN

Los procedimientos descritos aquí son utilidades para manipular el valor de resultado en un intérprete de Tcl. El resultado del intérprete puede ser un valor de Tcl o una cadena. Por ejemplo, Tcl_SetObjResult y Tcl_SetResult establecen el resultado del intérprete a, respectivamente, un valor y una cadena. De manera similar, Tcl_GetObjResult y Tcl_GetStringResult devuelven el resultado del intérprete como un valor y como una cadena. Los procedimientos siempre mantienen consistentes las formas de cadena y valor del resultado del intérprete. Por ejemplo, si se llama a Tcl_SetObjResult para establecer el resultado a un valor, y luego se llama a Tcl_GetStringResult, devolverá la representación de cadena del valor.

Tcl_SetObjResult organiza para que objPtr sea el resultado para interp, reemplazando cualquier resultado existente. El resultado se deja apuntando al valor referenciado por objPtr. El contador de referencias de objPtr se incrementa ya que ahora hay una nueva referencia a él desde interp. El contador de referencias de cualquier valor de resultado antiguo se decrementa y el valor de resultado antiguo se libera si no quedan referencias a él.

Tcl_GetObjResult devuelve el resultado para interp como un valor. El contador de referencias del valor no se incrementa; si el llamador necesita conservar un puntero a largo plazo al valor, debe usar Tcl_IncrRefCount para incrementar su contador de referencias para evitar que se libere prematuramente o se modifique accidentalmente.

Tcl_SetResult organiza para que result sea el resultado para el comando Tcl actual en interp, reemplazando cualquier resultado existente. El argumento freeProc especifica cómo gestionar el almacenamiento para el argumento result; se discute en la sección EL ARGUMENTO TCL_FREEPROC PARA TCL_SETRESULT a continuación. Si result es NULL, entonces freeProc se ignora y Tcl_SetResult reinicializa el resultado de interp para que apunte a una cadena vacía.

Tcl_GetStringResult devuelve el resultado para interp como una cadena. Si el resultado se estableció a un valor mediante una llamada a Tcl_SetObjResult, la forma de valor se convertirá a una cadena y se devolverá. Si la representación de cadena del valor contiene bytes nulos, esta conversión perderá información. Por esta razón, se anima a los programadores a escribir su código para usar los nuevos procedimientos de la API de valor y a llamar a Tcl_GetObjResult en su lugar.

Tcl_ResetResult borra el resultado para interp y deja el resultado en su estado normal vacío inicializado. Si el resultado es un valor, su contador de referencias se decrementa y el resultado se deja apuntando a un valor no compartido que representa una cadena vacía. Si el resultado es una cadena asignada dinámicamente, su memoria se libera y el resultado se deja como una cadena vacía. Tcl_ResetResult también borra el estado de error gestionado por Tcl_AddErrorInfo, Tcl_AddObjErrorInfo y Tcl_SetErrorCode.

Tcl_AppendResult facilita la construcción de resultados de Tcl en piezas. Toma cada uno de sus argumentos result y los agrega en orden al resultado actual asociado con interp. Si el resultado está en su estado vacío inicializado (por ejemplo, se acaba de invocar un procedimiento de comando o se acaba de llamar a Tcl_ResetResult), entonces Tcl_AppendResult establece el resultado a la concatenación de sus argumentos result. Tcl_AppendResult puede llamarse repetidamente a medida que se producen piezas adicionales del resultado. Tcl_AppendResult se encarga de todos los problemas de gestión de almacenamiento asociados con la gestión del resultado de interp, como la asignación de un área de resultado más grande si es necesario. También gestiona la conversión desde y hacia el campo result del interp para manejar la retrocompatibilidad con extensiones de estilo antiguo. Se puede pasar cualquier número de argumentos result en una sola llamada; el último argumento de la lista debe ser (char *)NULL.

Tcl_AppendResultVA es lo mismo que Tcl_AppendResult excepto que en lugar de tomar un número variable de argumentos, toma una lista de argumentos.

Tcl_TransferResult transfiere el estado del intérprete de sourceInterp a targetInterp. Los dos intérpretes deben haber sido creados en el mismo hilo. Si sourceInterp y targetInterp son los mismos, no se hace nada. De lo contrario, Tcl_TransferResult mueve el resultado de sourceInterp a targetInterp, y reinicia el resultado en sourceInterp. También mueve el diccionario de opciones de retorno según lo controlado por el valor del código de retorno code de la misma manera que Tcl_GetReturnOptions.

INTERFACES OBSOLETAS

PROCEDIMIENTOS DE CADENA ANTIGUOS

Se desaconseja el uso de los siguientes procedimientos ya que manipulan el resultado de Tcl como una cadena. Procedimientos como Tcl_SetObjResult que manipulan el resultado como un valor pueden ser significativamente más eficientes.

Tcl_AppendElement es similar a Tcl_AppendResult en que permite construir resultados en piezas. Sin embargo, Tcl_AppendElement toma solo un único argumento element y agrega ese argumento al resultado actual como un elemento de lista Tcl adecuado. Tcl_AppendElement agrega barras invertidas o llaves si es necesario para garantizar que el resultado de interp pueda ser analizado como una lista y que element se extraiga como un único elemento. En condiciones normales, Tcl_AppendElement agregará un carácter de espacio al resultado de interp justo antes de agregar el nuevo elemento de lista, de modo que los elementos de lista en el resultado estén debidamente separados. Sin embargo, si el nuevo elemento de lista es el primero en una lista o sublista (es decir, el resultado actual de interp está vacío, o consiste en el único carácter “{”, o termina en los caracteres “ {”) entonces no se agrega ningún espacio.

Tcl_FreeResult realiza parte del trabajo de Tcl_ResetResult. Libera la memoria asociada con el resultado de interp. También establece interp->freeProc a cero, pero no cambia interp->result ni borra el estado de error. Tcl_FreeResult se usa más comúnmente cuando un procedimiento está a punto de reemplazar un valor de resultado con otro.
