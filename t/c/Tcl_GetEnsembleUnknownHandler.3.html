ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el cual se crea o se encuentra el ensemble. También es el lugar donde se escriben los mensajes de resultado de error. Las funciones cuyo nombre empieza con Tcl_GetEnsemble pueden tener un NULL para el interp, pero todas las otras funciones deben tener uno no nulo.
const char *name (entrada)
El nombre del comando de ensemble a crear.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres en el cual se va a vincular el comando de ensemble, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto ORed de bits de bandera que describen la configuración básica del ensemble. Actualmente solo un bit tiene sentido, TCL_ENSEMBLE_PREFIX, que se activa cuando el comando de ensemble debe también coincidir con prefijos de subcomandos inambiguos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando de ensemble a buscar.
int flags (entrada)
Un conjunto ORed de bits que controlan el comportamiento de Tcl_FindEnsemble. Actualmente solo TCL_LEAVE_ERR_MSG es soportado.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando de ensemble, o que deseas usar para probar como un comando de ensemble en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Un puntero a una variable en la que se escriben los bits de bandera actuales del ensemble; actualmente solo el bit TCL_ENSEMBLE_PREFIX está definido.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario para usar como diccionario de mapeo de prefijo de comando de implementación para el comando de ensemble. Puede ser NULL si el diccionario de mapeo va a ser eliminado.
Tcl_Obj **dictObjPtr (salida)
Un puntero a una variable en la que se escribe el diccionario de mapeo de prefijo del comando de ensemble.
Tcl_Obj *listObj (entrada)
Un valor de lista para usar como lista de parámetros formales de subcomandos, la lista de subcomandos definidos en el diccionario o el prefijo de comando de subcomandos no definidos. Puede ser NULL si la lista de subcomandos o el prefijo de comando de subcomandos no definidos van a ser eliminados.
Tcl_Obj **listObjPtr (salida)
Un puntero a una variable en la que se escribe la lista de parámetros formales de subcomandos, la lista de subcomandos definidos o el prefijo actual del comando de subcomandos no definido.
Tcl_Namespace **namespacePtrPtr (salida)
Un puntero a una variable en la que se escribe el manejador del espacio de nombres al cual está vinculado el ensemble.

DESCRIPCIÓN

Un ensemble es un comando, vinculado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos Tcl. El primer argumento del comando de ensemble siempre se interpreta como un selector que indica qué subcomando se ejecutará.

Los ensembles se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete en el cual se trabajará, el nombre del ensemble a crear, el espacio de nombres dentro del intérprete en el cual se va a vincular el ensemble, y el conjunto de banderas por defecto del ensemble. El resultado de la función es el token de comando para el ensemble, que puede ser usado para configurar el ensemble usando la API descrita en PROPIEDADES DE ENSEMBLE.

Dado el nombre de un comando de ensemble, el token para ese comando puede ser recuperado usando Tcl_FindEnsemble. Si el nombre dado (en cmdNameObj) no se refiere a un comando de ensemble, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está seteado en flags) un mensaje de error es dejado en el resultado del intérprete.

Un token de comando puede ser comprobado para ver si se refiere a un ensemble usando Tcl_IsEnsemble. Esta devuelve 1 si el token se refiere a un ensemble, o 0 de lo contrario.

PROPIEDADES DE ENSEMBLE

Cada ensemble tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

flags (lectura/escritura)
El conjunto de banderas para el ensemble, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX, que se establece cuando los prefijos inambiguos de subcomandos pueden ser resueltos a implementaciones así como coincidencias exactas. Las banderas pueden leerse y escribirse usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapa de nombres de subcomandos a listas de palabras que se usarán como prefijo de comando (reemplazando las primeras dos palabras, que son el comando de ensemble y el nombre del subcomando), o NULL si cada subcomando debe ser mapeado a un comando con el nombre no cualificado en el espacio de nombres del ensemble. El valor predeterminado es NULL. Puede leerse y escribirse usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y el diccionario obtenido de Tcl_GetEnsembleMappingDict debe tratarse siempre como inmutable incluso si no es compartido. Todos los nombres de comando en los prefijos establecidos mediante Tcl_SetEnsembleMappingDict deben ser completamente cualificados.
lista de parámetros formales pre-subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (que solo se usan cuando se generan mensajes de error) que se invocan entre el nombre del ensemble y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Puede leerse y escribirse usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y el diccionario obtenido de Tcl_GetEnsembleParameterList debe tratarse siempre como inmutable incluso si no es compartido.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el ensemble, o NULL si estos se derivan de las claves del diccionario de mapeo (ver arriba) o (si eso también es NULL) de los comandos exportados por el espacio de nombres vinculado. Puede leerse y escribirse usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y la lista obtenida de Tcl_GetEnsembleSubcommandList debe tratarse siempre como inmutable incluso si no es compartida.
comando manejador de subcomando desconocido (lectura/escritura)
Una lista de palabras que se anteponen a cualquier subcomando cuando este no es conocido por el ensemble (según el manejo actual de prefijos). Puede ser NULL si el prefijo de comando de subcomandos no definidos va a ser eliminado. El prefijo debe usarse para generar mensajes de error.

Tcl_GetEnsembleUnknownHandler(3)

NAME

Tcl_GetEnsembleUnknownHandler, Tcl_SetEnsembleUnknownHandler - control the handler for unknown subcommands in an ensemble

SYNOPSIS

#include <tcl.h>

CONST char *
Tcl_GetEnsembleUnknownHandler(interp, token)
Tcl_Interp *interp;
Tcl_EnsembleToken token;

int
Tcl_SetEnsembleUnknownHandler(interp, token, handlerList)
Tcl_Interp *interp;
Tcl_EnsembleToken token;
CONST char *handlerList;

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting and resolving the handler.
Tcl_EnsembleToken token
The ensemble token returned by Tcl_CreateEnsemble.
CONST char *handlerList
A Tcl list of commands to be executed when an unknown subcommand is encountered. If NULL, the default behavior of generating an error message is used.

DESCRIPTION

The Tcl_GetEnsembleUnknownHandler function returns the Tcl list of commands currently set as the unknown subcommand handler for the ensemble specified by token. If no unknown handler is set, and the ensemble has a parent, the handler of the parent ensemble is returned. If there is no parent ensemble or no handler set on the parent, the function returns NULL. The returned list is a pointer to internal storage and should be treated as immutable by the caller. It is valid for the lifetime of the ensemble or until the handler is changed.

The Tcl_SetEnsembleUnknownHandler function sets the unknown subcommand handler for the ensemble specified by token to be the Tcl list of commands in handlerList. The commands in handlerList are invoked in order, with the first one that returns a valid result being the final handler. If handlerList is NULL, the unknown subcommand handler is reset to the default behavior (i.e., generate an error message). The handlerList is evaluated and stored internally by the ensemble mechanism.

The unknown subcommand handler is invoked when an ensemble is invoked with a subcommand that is not found in its mapping dictionary or subcommand list. The handler is called with the same arguments as the original ensemble invocation, plus the unknown subcommand name as the first argument. The handler should return a Tcl result code indicating success or failure.

The commands specified in the handlerList are executed in the context of the namespace in which the ensemble was created. This ensures that commands in the handler list are resolved correctly.

Note that the ensemble mechanism itself uses an unknown handler for its internal operations. This handler is accessible via the unknown subcommand of the namespace ensemble command. The unknown subcommand allows you to query and modify the unknown handler for a given ensemble.

The unknown handler for an ensemble can be specified when the ensemble is created using the unknown option of the namespace ensemble command. If not specified, the ensemble inherits the unknown handler from its parent ensemble, or uses the default behavior if it has no parent.

The result of Tcl_GetEnsembleUnknownHandler is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.

unknown
The unknown subcommand handler for the ensemble. This is a Tcl list of commands that will be executed when an unknown subcommand is encountered. If NULL, the default behavior - generate a suitable error message - will be used when an unknown subcommand is encountered. May be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The result of both functions is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.
bound namespace (read-only)
The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).
