ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene la variable.
const char *name1 (entrada)
Contiene el nombre de una variable de arreglo (si name2 no es NULL) o (si name2 es NULL) ya sea el nombre de una variable escalar o un nombre completo que incluye tanto el nombre de la variable como el índice. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular.
const char *name2 (entrada)
Si no es NULL, da el nombre del elemento dentro del arreglo; en este caso name1 debe referirse a una variable de arreglo.
Tcl_Obj *newValuePtr (entrada)
Punta a un valor Tcl que contiene el nuevo valor para la variable.
int flags (entrada)
Combinación OR de bits que proporcionan información adicional. Ver abajo para valores válidos.
const char *varName (entrada)
Nombre de la variable. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de un arreglo.
const char *newValue (entrada)
Nuevo valor para la variable, especificado como una cadena terminada en null. Se almacena una copia de este valor en la variable.
Tcl_Obj *part1Ptr (entrada)
Punta a un valor Tcl que contiene el nombre de la variable. El nombre puede incluir una serie de calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de una variable de arreglo.
Tcl_Obj *part2Ptr (entrada)
Si no es NULL, punta a un valor que contiene el nombre de un elemento dentro de un arreglo y part1Ptr debe referirse a una variable de arreglo.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar, leer y eliminar variables de Tcl desde código C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2, y Tcl_ObjSetVar2 crearán una nueva variable o modificarán una existente. Estos procedimientos establecen la variable dada al valor proporcionado por newValuePtr o newValue y devuelven un puntero al nuevo valor de la variable, que se almacena en la estructura de variables de Tcl. Tcl_SetVar2Ex y Tcl_ObjSetVar2 toman el nuevo valor como un Tcl_Obj y devuelven un puntero a un Tcl_Obj. Tcl_SetVar y Tcl_SetVar2 toman el nuevo valor como una cadena y devuelven una cadena; generalmente son menos eficientes que Tcl_ObjSetVar2. Tenga en cuenta que el valor de retorno puede ser diferente del argumento newValuePtr o newValue, debido a las modificaciones realizadas por los traces de escritura. Si ocurre un error al establecer la variable (por ejemplo, se hace referencia a una variable de arreglo sin proporcionar un índice para ella), se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está establecido.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2, y Tcl_ObjGetVar2 devuelven el valor actual de una variable. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos descritos anteriormente. En circunstancias normales, el valor de retorno es un puntero al valor de la variable. Para Tcl_GetVar2Ex y Tcl_ObjGetVar2, el valor se devuelve como un puntero a un Tcl_Obj. Para Tcl_GetVar y Tcl_GetVar2, el valor se devuelve como una cadena; esto generalmente es menos eficiente, por lo que se prefieren Tcl_GetVar2Ex o Tcl_ObjGetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de arreglo para una variable escalar), entonces se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está establecido.

Tcl_UnsetVar y Tcl_UnsetVar2 se pueden usar para eliminar una variable, de modo que los intentos futuros de leer la variable devuelvan un error. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos anteriores. Si la variable se elimina correctamente, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está establecido. Si se especifica un elemento de arreglo, se elimina el elemento dado pero el arreglo permanece. Si se especifica un nombre de arreglo sin un índice, se elimina todo el arreglo.

El nombre de una variable se puede especificar a estos procedimientos de cuatro maneras:

[1]
Si se invoca Tcl_SetVar, Tcl_GetVar, o Tcl_UnsetVar, el nombre de la variable se proporciona como una única cadena, varName. Si varName contiene un paréntesis de apertura y termina con un paréntesis de cierre, entonces el valor entre los paréntesis se trata como un índice (que puede tener cualquier valor de cadena) y los caracteres antes del primer paréntesis de apertura se tratan como el nombre de una variable de arreglo. Si varName no tiene paréntesis como se describe anteriormente, entonces toda la cadena se trata como el nombre de una variable escalar.
[2]
Si se proporcionan los argumentos name1 y name2 y name2 no es NULL, entonces se especifica un elemento de arreglo y el nombre del arreglo y el índice ya han sido separados por el llamador: name1 contiene el nombre y name2 contiene el índice. Se genera un error si name1 contiene un paréntesis de apertura y termina con un paréntesis de cierre (elemento de arreglo) y name2 no es NULL.
[3]
Si name2 es NULL, name1 se trata igual que varName en el caso [1] anterior (puede ser el nombre de una variable escalar o un elemento de arreglo).

El argumento flags se puede usar para especificar cualquiera de varias opciones a los procedimientos. Consiste en una combinación OR de los siguientes bits.

TCL_GLOBAL_ONLY
En circunstancias normales, los procedimientos buscan variables de la siguiente manera. Si una llamada a procedimiento está activa en interp, la variable se busca en el nivel actual de llamada a procedimiento. De lo contrario, la variable se busca primero en el espacio de nombres actual, luego en el espacio de nombres global. Sin embargo, si este bit está establecido en flags, entonces la variable solo se busca en el espacio de nombres global, incluso si hay una llamada a procedimiento activa. Si se dan tanto TCL_GLOBAL_ONLY como TCL_NAMESPACE_ONLY, se ignora TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
Si este bit está establecido en flags, entonces la variable solo se busca en el espacio de nombres actual; si un procedimiento está activo, se ignoran sus variables, y el espacio de nombres global también se ignora a menos que sea el espacio de nombres actual.
TCL_LEAVE_ERR_MSG
Si se devuelve un error y este bit está establecido en flags, entonces se dejará un mensaje de error en el resultado del intérprete, donde se puede recuperar con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de flag no está establecido, no se deja ningún mensaje de error y el resultado del intérprete no se modificará.
TCL_APPEND_VALUE

Tcl_ObjGetVar2(3) - Arch Linux man page

NAME

Tcl_ObjSetVar2, Tcl_ObjGetVar2, Tcl_ObjUnsetVar2 - access Tcl variables as arbitrary objects

SYNOPSIS

#include <tcl.h>

int
Tcl_ObjSetVar2(
    Tcl_Interp *interp,
    const char *varName,
    const char *arrayName,
    Tcl_Obj *newValuePtr,
    int flags)

Tcl_Obj *
Tcl_ObjGetVar2(
    Tcl_Interp *interp,
    const char *varName,
    const char *arrayName,
    int flags)

int
Tcl_ObjUnsetVar2(
    Tcl_Interp *interp,
    const char *varName,
    const char *arrayName,
    int flags)

ARGUMENTS

interp (in)
Interpreta el intérprete de Tcl en el que se va a operar.
varName (in)
El nombre de la variable.
arrayName (in)
Si se especifica un nombre de array, la variable es un elemento de ese array. Si es NULL, la variable no es un elemento de array.
newValuePtr (in)
Un puntero a un objeto Tcl que representa el nuevo valor de la variable. Esta función toma posesión del objeto, por lo que el llamador no debe modificarlo ni liberarlo.
flags (in)
Banderas de bits que especifican cómo modificar la variable. Ver Tcl_SetVar para una descripción de los bits de bandera.

DESCRIPTION

Estas funciones son la interfaz orientada a objetos para establecer, obtener y anular la configuración de variables de Tcl. Operan en variables de Tcl y elementos de array. El valor de la variable se pasa como un Tcl_Obj en lugar de una cadena. El objeto se incrusta dentro de la estructura de la variable de Tcl.

Tcl_ObjSetVar2 establece el valor de la variable especificada por varName y opcionalmente arrayName a newValuePtr. Si arrayName es NULL, la variable es una variable escalar. Si arrayName no es NULL, la variable es un elemento de array. El argumento flags es una máscara de bits que se puede usar para controlar el comportamiento, como especificar que la variable debe tratarse como global o que no se debe crear si no existe. Si la operación tiene éxito, devuelve TCL_OK, de lo contrario, devuelve TCL_ERROR y establece el mensaje de error en el intérprete.

Si se establece la bandera TCL_APPEND_VALUE, el valor de newValuePtr se adjunta al valor actual de la variable. El valor actual de la variable debe ser una cadena o un objeto que se pueda convertir a una cadena. Si el valor actual es una lista, el nuevo valor se anexa como un nuevo elemento de lista. La operación de anexo a una lista no se realiza si el elemento de la lista va a ser el primer elemento de una lista o sublista (es decir, el valor actual de la variable está vacío, o contiene el único carácter "{", o termina en " }"). Al anexar, el valor original de la variable también debe ser una lista válida, para que la operación sea el anexo de un nuevo elemento de lista a una lista.

Tcl_ObjGetVar2 devuelve el valor actual de la variable como un objeto Tcl. Los argumentos a este procedimiento se tratan de la misma manera que los argumentos a Tcl_ObjSetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de array para una variable escalar), entonces se devuelve NULL.

Tcl_ObjUnsetVar2 puede usarse para eliminar una variable, de modo que las llamadas futuras a Tcl_ObjGetVar2 para la variable devuelvan un error. Los argumentos a este procedimiento se tratan de la misma manera que los argumentos a Tcl_ObjGetVar2. Si la variable se elimina correctamente, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR. Si se especifica un elemento de array, se elimina el elemento dado pero el array permanece. Si se especifica un nombre de array sin índice, se elimina todo el array.
