ARGUMENTOS

Tcl_Interp *interp (salida)
Intérprete a utilizar para la notificación de errores. Si es NULL, no se deja ningún mensaje de error.
const char *list (entrada)
Puntero a una cadena con estructura de lista correcta.
int *argcPtr (salida)
Se rellena con el número de elementos en list.
const char ***argvPtr (salida)
*argvPtr se rellenará con la dirección de un array de punteros a las cadenas que son los elementos extraídos de list. Habrá *argcPtr entradas válidas en el array, seguidas de una entrada NULL.
int argc (entrada)
Número de elementos en argv.
const char *const *argv (entrada)
Array de cadenas a fusionar en una sola lista. Cada cadena se convertirá en un elemento separado de la lista.
const char *src (entrada)
Cadena que se convertirá en un elemento de una lista.
int *flagsPtr (entrada)
Puntero a una palabra para rellenar con información sobre src. El valor de *flagsPtr debe pasarse a Tcl_ConvertElement.
int length (entrada)
Número de bytes en la cadena src.
char *dst (entrada)
Lugar donde copiar el elemento de lista convertido. Debe contener suficientes caracteres para albergar la cadena convertida.
int flags (entrada)
Información sobre src. Debe ser el valor devuelto por una llamada anterior a Tcl_ScanElement, posiblemente combinado con OR con TCL_DONT_USE_BRACES.

DESCRIPCIÓN

Estos procedimientos pueden utilizarse para desmontar y volver a montar listas Tcl. Tcl_SplitList divide una lista en sus elementos constituyentes, devolviendo un array de punteros a los elementos utilizando argcPtr y argvPtr. Mientras extrae los argumentos, Tcl_SplitList obedece las reglas habituales de sustituciones de barras invertidas y llaves. El área de memoria apuntada por *argvPtr se asigna dinámicamente; además del array de punteros, también contiene copias de todos los elementos de la lista. Es responsabilidad del llamador liberar toda esta memoria. Por ejemplo, suponga que ha llamado a Tcl_SplitList con el siguiente código:

int argc, code;
char *string;
char **argv;
...
code = Tcl_SplitList(interp, string, &argc, &argv);

Entonces, eventualmente debería liberar la memoria con una llamada como la siguiente:

Tcl_Free((char *) argv);

Tcl_SplitList normalmente devuelve TCL_OK, lo que significa que la lista se analizó correctamente. Si hubo un error de sintaxis en list, entonces se devuelve TCL_ERROR y el resultado del intérprete apuntará a un mensaje de error que describe el problema (si interp no era NULL). Si se devuelve TCL_ERROR, no se asigna memoria y *argvPtr no se modifica.

Tcl_Merge es la inversa de Tcl_SplitList: toma una colección de cadenas dadas por argc y argv y genera una cadena resultante que tiene una estructura de lista correcta. Esto significa que comandos como index pueden usarse para extraer los elementos originales nuevamente. Además, si el resultado de Tcl_Merge se pasa a Tcl_Eval, se analizará en argc palabras cuyos valores serán los mismos que las cadenas argv pasadas a Tcl_Merge. Tcl_Merge modificará los elementos de la lista con llaves y/o barras invertidas para producir una estructura de lista Tcl correcta. La cadena resultante se asigna dinámicamente usando Tcl_Alloc; el llamador debe liberar el espacio eventualmente usando Tcl_Free.

Si el resultado de Tcl_Merge se pasa a Tcl_SplitList, los elementos devueltos por Tcl_SplitList serán idénticos a los pasados a Tcl_Merge. Sin embargo, lo contrario no es cierto: si Tcl_SplitList recibe una cadena dada, y los argc y argv resultantes se pasan a Tcl_Merge, la cadena resultante puede no ser la misma que la cadena original pasada a Tcl_SplitList. Esto se debe a que Tcl_Merge puede usar barras invertidas y llaves de manera diferente a la cadena original.

Tcl_ScanElement y Tcl_ConvertElement son los procedimientos que realizan todo el trabajo real de Tcl_Merge. Tcl_ScanElement analiza su argumento src y determina cómo usar barras invertidas y llaves al convertirlo en un elemento de lista. Devuelve una sobreestimación del número de caracteres requeridos para representar src como un elemento de lista, y almacena información en *flagsPtr que se necesita para Tcl_ConvertElement.

Tcl_ConvertElement es un procedimiento complementario a Tcl_ScanElement. Realiza el trabajo real de convertir una cadena en un elemento de lista. Su argumento flags debe ser el mismo que el valor devuelto por Tcl_ScanElement. Tcl_ConvertElement escribe un elemento de lista correcto en la memoria a partir de *dst y devuelve un recuento del número total de caracteres escritos, que no será mayor que el resultado devuelto por Tcl_ScanElement. Tcl_ConvertElement escribe solo el elemento de lista real sin espacios iniciales o finales: es responsabilidad del llamador incluir espacios entre elementos de lista adyacentes.

Tcl_ConvertElement utiliza uno de dos enfoques diferentes para manejar los caracteres especiales en src. Siempre que sea posible, maneja los caracteres especiales rodeando la cadena con llaves. Esto produce una salida limpia, pero no se puede usar en algunas situaciones, como cuando src contiene llaves desequilibradas. En estas situaciones, Tcl_ConvertElement maneja los caracteres especiales generando secuencias de barras invertidas para ellos. El llamador puede insistir en el segundo enfoque combinando el valor de bandera devuelto por Tcl_ScanElement con TCL_DONT_USE_BRACES. Aunque esto producirá un resultado más feo, es útil en algunas situaciones especiales, como cuando Tcl_ConvertElement se utiliza para generar una parte de un argumento para un comando Tcl. En este caso, rodear src con llaves haría que el comando no se analizara correctamente.

Por defecto, Tcl_ConvertElement utilizará comillas en su salida para asegurarse de que el primer carácter de un elemento no sea el carácter de almohadilla (“#”). Esto es para asegurarse de que el primer elemento de cualquier lista pasada a eval no se analice incorrectamente como el comienzo de un comentario. Cuando un elemento de lista no es el primer elemento de una lista, estas comillas no son necesarias. Cuando el llamador puede estar seguro de que el elemento no es el primer elemento de una lista, puede deshabilitar las comillas del primer carácter de almohadilla combinando el valor de bandera devuelto por Tcl_ScanElement con TCL_DONT_QUOTE_HASH.

Tcl_ScanCountedElement y Tcl_ConvertCountedElement son iguales a Tcl_ScanElement y Tcl_ConvertElement, excepto que la longitud de la cadena src está especificada por el argumento length, y la cadena puede contener nulos incrustados.

NOMBRE

Tcl_ConvertCountedElement - Convierte un elemento de lista Tcl al tipo deseado.

SINOPSIS

#include <tcl.h>

int
Tcl_ConvertCountedElement(interp, string, length, type, dstPtr)
    Tcl_Interp *interp;
    const char *string;
    int length;
    int type;
    void *dstPtr;

ARGUMENTOS

interp (in)
Intérprete de Tcl.
string (in)
Puntero a la cadena que contiene el elemento de la lista.
length (in)
Longitud de la cadena.
type (in)
El tipo Tcl al que se debe convertir el elemento (por ejemplo, TCL_CONVERT_INT, TCL_CONVERT_DOUBLE, TCL_CONVERT_STRING).
dstPtr (out)
Puntero a la ubicación donde se almacenará el valor convertido.

DESCRIPCIÓN

La función Tcl_ConvertCountedElement convierte un elemento de lista Tcl especificado por string y length al tipo indicado por type y almacena el resultado en la ubicación apuntada por dstPtr. La función maneja automáticamente las conversiones de tipos comunes de Tcl y reporta errores si la conversión falla. El parámetro interp se utiliza para reportar mensajes de error.

Los tipos de conversión admitidos incluyen:

  • TCL_CONVERT_INT: Convierte a un entero.
  • TCL_CONVERT_DOUBLE: Convierte a un número de punto flotante.
  • TCL_CONVERT_STRING: Copia la cadena al destino (dstPtr debe ser un puntero a char * y el llamador es responsable de liberar la memoria asignada).
  • Otros tipos pueden ser admitidos dependiendo de la implementación de Tcl.

La función devuelve TCL_OK si la conversión es exitosa y TCL_ERROR si falla. En caso de error, se puede encontrar un mensaje de error en el campo result del intérprete.
