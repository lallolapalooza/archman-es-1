Tcl_CreateTrace(3)

Tcl_CreateTrace(3) Procedimientos de biblioteca de Tcl Tcl_CreateTrace(3)

NOMBRE

Tcl_CreateTrace, Tcl_CreateObjTrace, Tcl_DeleteTrace - configurar para que se trace la ejecución de comandos

SINOPSIS

#include <tcl.h>

Tcl_Trace
Tcl_CreateTrace(interp, level, proc, clientData)

Tcl_Trace
Tcl_CreateObjTrace(interp, level, flags, objProc, clientData, deleteProc)

Tcl_DeleteTrace(interp, trace)

ARGUMENTOS

Tcl_Interp *interp (in)
Intérprete que contiene el comando a ser trazado o desactivado.
int level (in)
Los comandos que se ejecuten a nivel de profundidad igual o menor que este valor serán trazados, excepto si 0 se especifica. 1 significa solo comandos a nivel de profundidad superior, 2 significa comandos a nivel de profundidad superior o aquellos que se invocan como consecuencia directa de la ejecución de comandos a nivel de profundidad superior (cuerpos de procedimiento, comandos anidados, etc.). Y 0 significa que los comandos en cualquier nivel se trazan.
int flags (in)
Flags que regulan la ejecución de la traza. Ver detalles más adelante.
Tcl_CmdObjTraceProc *objProc (in)
Procedimiento que se invoca para cada comando que se ejecute. Ver detalles sobre la secuencia de llamada.
Tcl_CmdTraceProc *proc (in)
Procedimiento que se invoca para cada comando que se ejecute. Ver detalles sobre la secuencia de llamada.
ClientData clientData (in)
Valor arbitrario de una sola palabra que se pasa a objProc o proc.
Tcl_CmdObjTraceDeleteProc *deleteProc (in)
Procedimiento que se invoca cuando se elimina la traza. Ver detalles sobre la secuencia de llamada. Un puntero nulo es permitido y produce un callback vacío cuando se elimina la traza.
Tcl_Trace trace (in)
Token para la traza a eliminar (valor devuelto de la llamada previa a Tcl_CreateTrace).

DESCRIPCIÓN

Tcl_CreateObjTrace configura para que se trate la ejecución de comandos. Después de ser llamado, objProc se invocará antes de que el intérprete invoque cualquier procedimiento de comando cuando evalúe comandos en interp. El valor devuelto por Tcl_CreateObjTrace es un token para la traza, que puede ser pasado a Tcl_DeleteTrace para eliminar la traza. Hay múltiples trazas en ejecución simultáneamente para el mismo intérprete.

objProc debe tener argumentos y resultados que coincidan con el tipo Tcl_CmdObjTraceProc:

typedef int Tcl_CmdObjTraceProc(
        ClientData clientData,
        Tcl_Interp* interp,
        int level,
        const char *command,
        Tcl_Command commandToken,
        int objc,
        Tcl_Obj *const objv[]);

Los parámetros clientData y interp son copias de los argumentos correspondientes dados a Tcl_CreateTrace. ClientData típicamente apunta a un conjunto de datos de aplicación que describe lo que se debe hacer cuando se invoque objProc. El parámetro level da la profundidad de nivel del comando (1 para comandos a nivel de profundidad superior que se pasan a Tcl_Eval por la aplicación, 2 para comandos a nivel de profundidad inferior que se pasan a Tcl_Eval durante el parseo o interpretación de comandos nivel 1, y así sucesivamente). El parámetro command apunta a una cadena que contiene el texto del comando, antes de cualquier sustitución de argumentos. El parámetro commandToken es un token Tcl que identifica el comando a ejecutar. El token puede ser pasado a Tcl_GetCommandName, Tcl_GetCommandInfoFromToken o Tcl_SetCommandInfoFromToken para modificar la definición del comando. Los parámetros objc y objv designan el número final de parámetros y el vector de parámetros que se pasarán al comando, y han tenido todas las sustituciones realizadas.

La callback objProc debe retornar un código de retorno estándar de Tcl. Si este código es TCL_OK (caso normal), el intérprete invocará el comando. Cualquier otro código de retorno se trata como si el comando hubiera devuelto ese estado y no se invocará. La callback objProc no debe modificar objv de ninguna manera.

La traza solo ocurre para comandos en niveles de profundidad menores o iguales que el parámetro level (es decir, el parámetro level de la callback objProc siempre será menor o igual que el parámetro level de Tcl_CreateTrace).

La traza tiene un efecto significativo en el rendimiento de ejecución, ya que impide la generación de código en línea para comandos Tcl como if y while para que puedan ser trazados. Si no se requieren trazas para comandos de nivel de built-in, el parámetro flags puede ser establecido en el valor constante TCL_ALLOW_INLINE_COMPILATION. En este caso, las trazas para comandos de nivel de built-in pueden o no generar callbacks de traza, dependiendo del estado del intérprete, pero el rendimiento de ejecución será mejor. (Esta funcionalidad es deseable, por ejemplo, cuando se usa Tcl_CreateObjTrace para implementar un profiler de ejecución en tiempo de ejecución.)

Las llamadas a objProc se realizan por el parser Tcl inmediatamente antes de invocar el procedimiento de comando para el comando (cmdProc). Esto ocurre después del parseo y sustitución de argumentos, por lo que las trazas de comandos sustituidos ocurren antes que las trazas de los comandos que contienen las sustituciones. Si hay un error de sintaxis en un comando o no hay procedimiento de comando asociado a un nombre de comando, no se realizará ninguna traza para ese comando. Si una cadena pasada a Tcl_Eval contiene múltiples comandos (entre corchetes, o en líneas diferentes), se realizarán múltiples llamadas a objProc, una para cada comando.

Tcl_DeleteTrace elimina una traza, de modo que no se realizarán más llamadas a los procedimientos asociados a la traza. Después de que Tcl_DeleteTrace devuelva, el llamador nunca debe usar el token trace.

Cuando Tcl_DeleteTrace se llama, el intérprete invoca el deleteProc que se pasó como parámetro a Tcl_CreateObjTrace. El deleteProc debe corresponder al tipo Tcl_CmdObjTraceDeleteProc:

typedef void Tcl_CmdObjTraceDeleteProc(
        ClientData clientData);

El parámetro clientData será el mismo que el clientData original que se pasó a Tcl_CreateObjTrace.

Tcl_CreateTrace es una alternativa de interfaz para la traza de comandos, no recomendada para nuevas aplicaciones. Se proporciona para la compatibilidad con código desarrollado en versiones antiguas del intérprete Tcl. Es similar a Tcl_CreateObjTrace, pero su parámetro proc debe tener argumentos y resultado que coincidan con el tipo Tcl_CmdTraceProc:

typedef void Tcl_CmdTraceProc(
        ClientData clientData,
        Tcl_Interp *interp,
        int level,
        char *command,
        Tcl_CmdProc *cmdProc,
        ClientData cmdClientData,
        int argc,
        const char *argv[]);

Los parámetros de la callback proc son similares a los de la callback objProc anteriormente. El commandToken se sustituye por cmdProc, un puntero al procedimiento de comando (basado en texto) que se invocará; y cmdClientData, los datos de cliente que se pasarán al procedimiento. El objc se sustituye por un parámetro argv, que da los argumentos al comando como cadenas de texto. Proc no debe modificar las cadenas command o argv.

Si una traza creada con Tcl_CreateTrace está en efecto, la compilación de código en línea para comandos Tcl como if y while está siempre desactivada. No hay notificación cuando se elimina una traza creada con Tcl_CreateTrace. No hay manera de ser notificado cuando la traza creada con Tcl_CreateTrace se elimina. No hay manera para que el procedimiento asociado a una llamada a Tcl_CreateTrace pueda abortar la ejecución del comando command.
