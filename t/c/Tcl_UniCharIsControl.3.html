DESCRIPCIÓN

Todas las rutinas descritas examinan caracteres Unicode y devuelven un valor booleano. Un valor de retorno distinto de cero significa que el carácter pertenece a la clase de caracteres asociada con la rutina llamada. El resto de este documento solo describe las clases de caracteres asociadas con las diversas rutinas.

CLASES DE CARACTERES

Tcl_UniCharIsAlnum comprueba si el carácter es un carácter Unicode alfanumérico.

Tcl_UniCharIsAlpha comprueba si el carácter es un carácter Unicode alfabético.

Tcl_UniCharIsControl comprueba si el carácter es un carácter de control Unicode.

Tcl_UniCharIsDigit comprueba si el carácter es un carácter Unicode numérico.

Tcl_UniCharIsGraph comprueba si el carácter es cualquier carácter imprimible de Unicode excepto el espacio.

Tcl_UniCharIsLower comprueba si el carácter es un carácter Unicode en minúscula.

Tcl_UniCharIsPrint comprueba si el carácter es un carácter imprimible de Unicode.

Tcl_UniCharIsPunct comprueba si el carácter es un carácter de puntuación de Unicode.

Tcl_UniCharIsSpace comprueba si el carácter es un carácter de espacio en blanco de Unicode.

Tcl_UniCharIsUpper comprueba si el carácter es un carácter Unicode en mayúscula.

Tcl_UniCharIsWordChar comprueba si el carácter es alfanumérico o una marca de puntuación conector.
