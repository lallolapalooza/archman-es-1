DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como una cantidad fija, sin signo, de enteros. Una cadena UTF-8 es un carácter Unicode representado como una secuencia variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 de varios bytes es una serie de bytes que comienza con un byte líder y es seguida por algunos bytes de cola.

TCL_UTF_MAX es el número máximo de bytes que se necesitan para representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 al inicio de buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El usuario debe asegurarse de que el buffer de entrada sea lo suficientemente largo para que esta rutina no se salga del final y no se refiera a memoria inexistente o aleatoria; si el buffer de entrada se conoce como terminado en nulo, esto no ocurrirá. Si la entrada no está en formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada en UTF-8 y almacena el resultado en un Tcl_DString inicializado previamente. Debes especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El espacio de almacenamiento del valor de retorno se aplica al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada en Unicode y almacena el resultado en el Tcl_DString inicializado previamente. En el argumento length, puedes especificar la longitud de la cadena UTF-8 dada en bytes o "-1", en cuyo caso Tcl_UtfToUniCharDString usa strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El espacio de almacenamiento del valor de retorno se aplica al final del Tcl_DString. La cadena Unicode se termina con un carácter Unicode nulo.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en nulo y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en nulo y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres. Tcl_UniCharNcmp compara las dos cadenas carácter por carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a o menor que 0 si la primera cadena es mayor que, igual a o menor que la segunda cadena respectivamente. Tcl_UniCharNcasecmp es la versión insensible a mayúsculas/minúsculas del carácter Unicode.

Tcl_UniCharCaseMatch es el equivalente Unicode de Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en nulo, un patrón Unicode y un valor booleano que indica si la coincidencia debe ser sensible a mayúsculas/minúsculas y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en nulo y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres.) Tcl_UtfNcmp compara las dos cadenas carácter por carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a o menor que 0 si la primera cadena es mayor que, igual a o menor que la segunda cadena respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas/minúsculas al comparar caracteres de letras mayúsculas, minúsculas o capitalizadas.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 src de length bytes es suficiente para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté correctamente formada. Esta rutina es utilizada por procedimientos que trabajan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars representados por la cadena UTF-8 src. La longitud de la cadena fuente es length bytes. Si la longitud es negativa, se usan todos los bytes hasta el primer carácter nulo.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El carácter de terminación se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. La cadena se considera terminada en nulo.

DESCRIPTION

These functions provide support for manipulating strings in the UTF-8 encoding.

Tcl_UniCharAtIndex returns the 32-bit character (Tcl_UniChar) at the given byte index in the UTF-8 string src. The source string must contain at least index bytes. Behavior is undefined if index is negative.

Tcl_UtfToUniChar converts the first UTF-8 character in src to a Tcl_UniChar and stores it in *uniCharPtr. It returns the number of bytes in the UTF-8 character. Tcl_UtfToUniChar can safely handle 1 to 4 bytes per character.

Tcl_UtfNext returns the next UTF-8 character in the string starting at src. It returns the number of bytes in the character. The caller is responsible for ensuring that src points to a valid character. If src points past the end of the string, or to an incomplete character, the behavior is undefined.

Tcl_UtfCharComplete checks if the string starting at s and of length len contains a complete UTF-8 character. It returns 1 if the character is complete, 0 otherwise.

Tcl_UtfFindFirst searches for the first occurrence of the character c in the UTF-8 string src. It returns a pointer to the beginning of the character if found, or NULL otherwise. The character c must be a single-byte character.

Tcl_UtfNext returns a pointer to the next character in the UTF-8 string src. The null terminator is considered part of the UTF-8 string.

Given src, a pointer to some location in a UTF-8 string, Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
