DESCRIPTION

These routines convert between UTF-8 strings and Tcl_UniChars. A Tcl_UniChar is a Unicode character represented as a fixed-size integer. A UTF-8 character is a Unicode character represented as a variable-length sequence of up to TCL_UTF_MAX bytes. A UTF-8 multibyte sequence consists of a head byte followed by zero or more tail bytes.

TCL_UTF_MAX is the maximum number of bytes that are needed to represent a Unicode character in UTF-8 encoding.

Tcl_UniCharToUtf stores the Tcl_UniChar ch as a UTF-8 string starting at buf. The return value is the number of bytes stored in buf.

Tcl_UtfToUniChar reads a UTF-8 character starting at src and stores it as a Tcl_UniChar at *chPtr. The return value is the number of bytes read from src. The caller must ensure that the input buffer is sufficiently long so that this routine does not overrun and dereference invalid or random memory; if the input buffer is known to be null-terminated, this will not happen. If the input is not correctly formed UTF-8, Tcl_UtfToUniChar will store the first byte of src in *chPtr as a Tcl_UniChar between 0x80 and 0xFF and return 1.

Tcl_UniCharToUtfDString converts the given Unicode string to UTF-8, storing the result in a pre-initialized Tcl_DString. You must specify uniLength, the length of the given Unicode string. The return value is a pointer to the UTF-8 representation of the Unicode string. The storage for the return value is appended to the end of the Tcl_DString.

Tcl_UtfToUniCharDString converts the given UTF-8 string to Unicode, storing the result in the pre-initialized Tcl_DString. In the length argument, you can specify the length of the given UTF-8 string in bytes or -1, in which case Tcl_UtfToUniCharDString uses strlen to calculate the length. The return value is a pointer to the Unicode representation of the UTF-8 string. The storage for the return value is appended to the end of the Tcl_DString. The Unicode string is null-terminated.

Tcl_UniCharLen is the Unicode equivalent of strlen. It takes a null-terminated Unicode string and returns the number of Unicode characters (not bytes) in that string.

Tcl_UniCharNcmp and Tcl_UniCharNcasecmp are the Unicode equivalents of strncmp and strncasecmp, respectively. They both take two null-terminated Unicode strings and the number of characters to compare. Both strings are assumed to be at least numChars characters long. Tcl_UniCharNcmp compares the two strings character by character according to Unicode character order. It returns a value greater than, equal to, or less than 0 if the first string is greater than, equal to, or less than the second string, respectively. Tcl_UniCharNcasecmp is the case-insensitive version for Unicode.

Tcl_UniCharCaseMatch is the Unicode equivalent of Tcl_StringCaseMatch. It takes a null-terminated Unicode string, a Unicode pattern, and a boolean indicating whether the match should be case-sensitive and returns whether the string matches the pattern.

Tcl_UtfNcmp is the UTF-8 equivalent of strncmp. It takes two null-terminated UTF-8 strings and the number of characters to compare. (Both strings are assumed to be at least numChars characters long. Tcl_UtfNcmp compares the two strings character by character according to Unicode character order. It returns a value greater than, equal to, or less than 0 if the first string is greater than, equal to, or less than the second string, respectively.)

Tcl_UtfNcasecmp is the UTF-8 equivalent of strncasecmp. It is similar to Tcl_UtfNcmp except that comparisons ignore case differences when comparing upper case, lower case, or title case characters.

Tcl_UtfCharComplete returns 1 if the UTF-8 string src of length bytes is sufficient to be decoded by Tcl_UtfToUniChar/Tcl_UtfNext, or 0 otherwise. This function does not guarantee that the UTF-8 string is well-formed. This routine is used by procedures working byte by byte that need to know if a complete Tcl_UniChar has been seen.

Tcl_NumUtfChars is the UTF-8 equivalent of strlen. It returns the number of Tcl_UniChars represented by the UTF-8 string src. The length of the source string is length bytes. If length is negative, all bytes up to the first null character are used.

Tcl_UtfFindFirst is the UTF-8 equivalent of strchr. It returns a pointer to the first occurrence of Tcl_UniChar ch in the null-terminated UTF-8 string src. The null character is considered part of the UTF-8 string.

Tcl_UtfFindLast is the UTF-8 equivalent of strrchr. It returns a pointer to the last occurrence of Tcl_UniChar ch in the null-terminated UTF-8 string src.

Tcl_UtfNext advances src to the beginning of the next UTF-8 character. It returns a pointer to the next character, or NULL if src points to the null terminator.

Tcl_UtfPrev moves backwards from src to find the beginning of the previous UTF-8 character. start is a pointer to the beginning of the string. The caller must ensure that src points to a valid UTF-8 character within the string starting at start. It returns a pointer to the previous character, or start if no previous character exists.

Tcl_UniCharAtIndex returns the Tcl_UniChar at the given index in the UTF-8 string src. Index is 0-based. Returns the null character if index is out of bounds.

Tcl_UtfAtIndex returns a pointer to the character at the given index in the UTF-8 string src. Index is 0-based. Returns a pointer to the null terminator if index is out of bounds.

Tcl_UtfBackslash converts a Tcl backslash sequence starting at src to a single character. The result is stored in the buffer dst, which must be large enough to hold TCL_UTF_MAX characters. If readPtr is not NULL, it is filled with the number of bytes consumed from src, including the backslash character. The function returns the number of bytes stored in dst.

NAME

Tcl_UniCharCaseMatch, Tcl_UniCharToUpper, Tcl_UniCharToLower, Tcl_UniCharToTitle, Tcl_UniCharToFold, Tcl_UniCharLen, Tcl_UniCharNcmp, Tcl_UniCharNcasecmp, Tcl_UniCharToUTF, Tcl_UniCharFromUTF, Tcl_UniCharToUTF - manipulate Tcl_UniChar strings

ARGUMENTS

s1, s2
Pointers to null-terminated arrays of Tcl_UniChar characters.
ch
A single Tcl_UniChar character.
uniStr
A pointer to a null-terminated array of Tcl_UniChar characters.
n
The maximum number of Tcl_UniChar characters to compare.
buf
A buffer to store the UTF-8 representation of the character.
utf
A pointer to a null-terminated UTF-8 string.
utfPtr
A pointer to a pointer to a null-terminated UTF-8 string.

DESCRIPTION

These functions provide low-level access to Tcl's internal Unicode and UTF-8 string representations.

Tcl_UniCharCaseMatch compares two null-terminated strings of Tcl_UniChar characters for case-insensitive equality. It returns 1 if the strings are equal, 0 otherwise.

Tcl_UniCharToUpper, Tcl_UniCharToLower, and Tcl_UniCharToTitle convert a Tcl_UniChar character to its uppercase, lowercase, or titlecase equivalent, respectively. If no such equivalent exists, the original character is returned. These functions honor the Unicode case mapping tables.

Tcl_UniCharToFold converts a Tcl_UniChar character to its case-folding equivalent. Case folding is a more general form of case conversion used for caseless matching, and it is required for proper sorting and matching of strings in many languages. If no case-folding equivalent exists, the original character is returned.

Tcl_UniCharLen returns the number of Tcl_UniChar characters in a null-terminated string. This is equivalent to a call to strlen() on a C character array.

Tcl_UniCharNcmp compares the first n Tcl_UniChar characters of two null-terminated strings. It returns a negative value if s1 < s2, zero if s1 = s2, and a positive value if s1 > s2.

Tcl_UniCharNcasecmp compares the first n Tcl_UniChar characters of two null-terminated strings case-insensitively. It returns a negative value if s1 < s2, zero if s1 = s2, and a positive value if s1 > s2.

Tcl_UniCharToUTF converts a single Tcl_UniChar character to its UTF-8 representation and stores it in the buffer pointed to by buf. The buffer must be large enough to hold the UTF-8 representation (at most TCL_UTF_MAX bytes). The function returns the number of bytes written to the buffer.

Tcl_UniCharFromUTF converts a UTF-8 string pointed to by utf to a Tcl_UniChar character. It returns the Tcl_UniChar character. The input string must contain a valid UTF-8 encoding of a single character. It is the caller's responsibility to ensure that the input string is properly terminated or that enough bytes are available.

Tcl_UniCharFromUTFVar is similar to Tcl_UniCharFromUTF, but it takes a pointer to a pointer to the UTF-8 string. It converts the character pointed to by *utfPtr and then advances *utfPtr to point to the next UTF-8 character in the string. This is useful for iterating through a UTF-8 string character by character.

The following functions deal with UTF-8 strings directly:

Tcl_UtfToUniChar converts the UTF-8 string starting at src to a Tcl_UniChar character. It returns the Tcl_UniChar character and stores a pointer to the next UTF-8 character in the string in *srcPtr. The null terminator is considered part of the UTF-8 string.

Tcl_UniCharToUtf converts the Tcl_UniChar character ch to its UTF-8 representation and stores it in the buffer pointed to by dst. The buffer must be large enough to hold the UTF-8 representation (at most TCL_UTF_MAX bytes). The function returns the number of bytes written to the buffer.

Tcl_UtfNext returns a pointer to the next UTF-8 character in the string src. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UniCharToUTF index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
