Tcl_GetAssocData(3)

Paquete: tcl

Licencias: TCL

Tcl_SetAssocData(3) Procedimientos de biblioteca Tcl Tcl_SetAssocData(3)

NOMBRE

Tcl_GetAssocData, Tcl_SetAssocData, Tcl_DeleteAssocData - gestionar asociaciones de claves de cadena y datos especificados por el usuario con intérpretes Tcl

SINOPSIS

#include <tcl.h>

ClientData
Tcl_GetAssocData(interp, key, delProcPtr)

Tcl_SetAssocData(interp, key, delProc, clientData)

Tcl_DeleteAssocData(interp, key)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que se ejecutará el comando especificado.
const char *key (entrada)
Clave para la asociación con la que se almacenarán los datos o de la que se eliminarán o recuperarán los datos. Típicamente el prefijo del módulo para un paquete.
Tcl_InterpDeleteProc *delProc (entrada)
Procedimiento a llamar cuando se elimine interp.
Tcl_InterpDeleteProc **delProcPtr (entrada)
Puntero a la ubicación en la que se almacenará la dirección del procedimiento de eliminación actual para la asociación. Se ignora si es NULL.
ClientData clientData (entrada)
Valor arbitrario de una palabra asociado con la clave dada en este intérprete. Estos datos son propiedad del llamador.

DESCRIPCIÓN

Estos procedimientos permiten a las extensiones asociar sus propios datos con un intérprete Tcl. Una asociación consta de una clave de cadena, típicamente el nombre de la extensión, y un valor de una palabra, que es típicamente un puntero a una estructura de datos que contiene datos específicos de la extensión. Tcl no realiza ninguna interpretación de la clave ni del valor de una asociación.

La gestión del almacenamiento se facilita almacenando con cada asociación un procedimiento a llamar cuando se elimine el intérprete. Este procedimiento puede desechar el espacio ocupado por los datos del cliente de la manera que considere oportuna.

Tcl_SetAssocData crea una asociación entre una clave de cadena y un dato especificado por el usuario en el intérprete dado. Si ya existe una asociación con la clave dada, Tcl_SetAssocData la sobrescribe con la nueva información. Corresponde a los llamadores organizar su uso de nombres para evitar conflictos, por ejemplo, utilizando nombres de paquetes como claves. Si el argumento deleteProc no es NULL, especifica la dirección de un procedimiento a invocar si el intérprete se elimina antes de que se elimine la asociación. DeleteProc debe tener argumentos y un resultado que coincidan con el tipo Tcl_InterpDeleteProc:

typedef void Tcl_InterpDeleteProc(
        ClientData clientData,
        Tcl_Interp *interp);

Cuando se invoca deleteProc, los argumentos clientData e interp serán los mismos que los argumentos correspondientes pasados a Tcl_SetAssocData. El procedimiento de eliminación no se invocará si la asociación se elimina antes de que se elimine el intérprete.

Tcl_GetAssocData devuelve el dato almacenado en la asociación con la clave especificada en el intérprete dado y, si el campo delProcPtr no es NULL, la dirección indicada por él recibe la dirección del procedimiento de eliminación almacenado con esta asociación. Si no existe ninguna asociación con la clave especificada en el intérprete dado, Tcl_GetAssocData devuelve NULL.

Tcl_DeleteAssocData elimina una asociación con una clave especificada en el intérprete dado. Luego llama al procedimiento de eliminación.

PALABRAS CLAVE

asociación, datos, procedimiento de eliminación, intérprete, clave
