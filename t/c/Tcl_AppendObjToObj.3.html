ARGUMENTOS

const char *bytes (in)
Punta al primer byte de un arreglo de bytes UTF-8 usado para establecer o añadir una valor de cadena. Este arreglo de bytes puede contener caracteres nulos incrustados, a menos que numChars sea negativo. (Aplicaciones que necesitan caracteres nulos deben representarlos como la secuencia de dos bytes \300\200, usar Tcl_ExternalToUtf para convertir, o usar Tcl_NewByteArrayObj si el string es una colección de bytes no interpretados.)
int length (in)
El número de bytes a copiar de bytes al inicializar, establecer o añadir una valor de cadena. Si es negativo, se usan todos los bytes hasta el primer carácter nulo.
const Tcl_UniChar *unicode (in)
Punta al primer byte de un arreglo de caracteres Unicode usado para establecer o añadir una valor de cadena. Este arreglo de bytes puede contener caracteres nulos incrustados, a menos que numChars sea negativo.
int numChars (in)
El número de caracteres Unicode a copiar de unicode al inicializar, establecer o añadir una valor de cadena. Si es negativo, se usan todos los caracteres hasta el primer carácter nulo.
int index (in)
El índice del carácter Unicode a devolver.
int first (in)
El índice del primer carácter Unicode en el rango de caracteres Unicode a devolver como nuevo valor.
int last (in)
El índice del último carácter Unicode en el rango de caracteres Unicode a devolver como nuevo valor.
Tcl_Obj *objPtr (in/out)
Punta a un valor a manipular.
Tcl_Obj *appendObjPtr (in)
El valor a añadir a objPtr en Tcl_AppendObjToObj.
int *lengthPtr (out)
Si no es NULL, el lugar donde Tcl_GetStringFromObj almacenará la longitud de la representación de cadena de un valor.
const char *string (in)
Valor de cadena terminado en nulo a añadir a objPtr.
va_list argList (in)
Una lista de argumentos que debe haber sido inicializada usando va_start, y limpiada usando va_end.
int limit (in)
El número máximo de bytes a añadir.
const char *ellipsis (in)
El sufijo a añadir cuando el límite lleva a truncamiento de cadena. Si se pasa NULL, se usa el sufijo “...”.
const char *format (in)
Controlador de formato incluyendo especificadores de conversión %.
int objc (in)
El número de elementos a formatear o concatenar.
Tcl_Obj *objv[] (in)
El array de valores a formatear o concatenar.
int newLength (in)
La nueva longitud de la representación de cadena de objPtr, sin incluir el carácter nulo final.

DESCRIPCIÓN

Los procedimientos descritos en esta página de manual permiten manipular valores Tcl como valores de cadena. Utilizan la representación interna del valor para almacenar información adicional, lo que hace que las operaciones de manipulación de cadenas sean más eficientes. En particular, hacen una serie de operaciones de adición eficientes al reservar espacio adicional para la cadena, por lo que no es necesario copiarla cada vez que se añade. Además, los índices y los cálculos de longitud se optimizan porque la representación de cadena Unicode se calcula y almacena en caché según sea necesario. Al utilizar las familias de procedimientos Tcl_Append* donde el resultado del intérprete es el valor a añadir, es importante llamar a Tcl_ResetResult primero para asegurarse de que no estamos añadiendo intencionalmente a datos existentes en el valor de resultado.

Tcl_NewStringObj y Tcl_SetStringObj crean un nuevo valor o modifican uno existente para almacenar una copia de la cadena proporcionada por bytes y length. Tcl_NewUnicodeObj y Tcl_SetUnicodeObj crean un nuevo valor o modifican uno existente para almacenar una copia de la cadena Unicode proporcionada por unicode y numChars. Tcl_NewStringObj y Tcl_NewUnicodeObj devuelven un puntero a un nuevo valor con un contador de referencias cero. Los cuatro procedimientos establecen el valor para almacenar una copia de la cadena especificada. Tcl_SetStringObj y Tcl_SetUnicodeObj liberan cualquier representación interna o de cadena previa del valor.

Tcl_GetStringFromObj y Tcl_GetString devuelven la representación de cadena de un valor. Esta se proporciona mediante el puntero de bytes devuelto y (para Tcl_GetStringFromObj) la longitud, que se almacena en lengthPtr si no es NULL. Si la representación de cadena UTF del valor no es válida (su puntero de bytes es NULL), la representación de cadena se regenera a partir de la representación interna del valor. El almacenamiento al que apunta el puntero de bytes devuelto es propiedad del gestor de valores. Se devuelve como un puntero escribible para que los autores de Tcl_ObjType puedan modificar la representación de cadena dentro del Tcl_UpdateStringProc de su Tcl_ObjType. Excepto para este propósito limitado, el puntero devuelto por Tcl_GetStringFromObj o Tcl_GetString debe tratarse como de solo lectura. Se recomienda asignar este puntero a una variable (const char *) de tipo const. Incluso en las situaciones limitadas en las que la escritura a este puntero es aceptable, se debe tener cuidado de respetar las semánticas de copia en escritura requeridas por Tcl_Obj, con llamadas apropiadas a Tcl_IsShared y Tcl_DuplicateObj antes de cualquier modificación in situ de la representación de cadena. El procedimiento Tcl_GetString se utiliza en el caso común en el que el llamante no necesita la longitud de la representación de cadena.

Tcl_GetUnicodeFromObj y Tcl_GetUnicode devuelven el valor de un valor como una cadena Unicode. Esto se proporciona mediante el puntero devuelto y (para Tcl_GetUnicodeFromObj) la longitud, que se almacena en lengthPtr si no es NULL. El almacenamiento al que apunta el puntero de bytes devuelto es propiedad del gestor de valores y no debe ser modificado por el llamante. El procedimiento Tcl_GetUnicode se utiliza en el caso común en el que el llamante no necesita la longitud de la representación de cadena Unicode.

Tcl_GetUniChar devuelve el carácter index-ésimo en la representación Unicode del valor. Se asume que el índice está en el rango adecuado.

Tcl_GetRange devuelve un nuevo valor compuesto por los caracteres entre first y last (incluidos) en la representación Unicode del valor. Si la representación Unicode del valor no es válida, se regenera la representación Unicode del valor a partir de la representación de cadena del valor. Si first < 0, la cadena devuelta comienza al principio del valor. Si last < 0, la cadena devuelta termina al final del valor.
