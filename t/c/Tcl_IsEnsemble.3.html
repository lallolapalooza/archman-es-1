ARGUMENTOS

Tcl_Interp *interp (en/salida)
El intérprete en el que se creará o encontrará el conjunto. También es donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener un NULL para el interp, pero todas las demás funciones no deben tenerlo.
const char *name (en)
El nombre del comando del conjunto que se creará.
Tcl_Namespace *namespacePtr (en)
El espacio de nombres al que se enlazará el comando del conjunto, o NULL para el espacio de nombres actual.
int ensFlags (en)
Un conjunto OR de bits de bandera que describen la configuración básica del conjunto. Actualmente, solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando del conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (en)
Un valor que contiene el nombre del comando del conjunto a buscar.
int flags (en)
Un conjunto OR de bits de bandera que controlan el comportamiento de Tcl_FindEnsemble. Actualmente solo se admite TCL_LEAVE_ERR_MSG.
Tcl_Command token (en)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para probar como comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la que escribir los bits de bandera actuales del conjunto; actualmente solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (en)
Un valor de diccionario para usar en el mapeo de subcomando a prefijo de comando de implementación en el conjunto. Puede ser NULL si el diccionario de mapeo se va a eliminar.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la que escribir el diccionario de mapeo actual del conjunto.
Tcl_Obj *listObj (en)
Un valor de lista para usar en la lista de parámetros formales pre-subcomando, la lista definida de subcomandos en el diccionario o el prefijo del comando manejador de subcomando desconocido. Puede ser NULL si la lista de subcomandos o el manejador desconocido van a eliminarse.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la que escribir la lista actual de parámetros formales pre-subcomando, la lista definida de subcomandos o el prefijo del manejador desconocido actual.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la que escribir el manejador del espacio de nombres al que está enlazado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, enlazado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos de Tcl. El primer argumento al comando del conjunto se interpreta siempre como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete en el que trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que enlazar el conjunto y el conjunto de banderas por defecto del conjunto. El resultado de la función es el token de comando para el conjunto, que puede usarse para configurar adicionalmente el conjunto utilizando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token para ese comando puede obtenerse usando Tcl_FindEnsemble. Si el nombre de comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Un token de comando puede ser verificado para ver si se refiere a un conjunto usando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

banderas (lectura/escritura)
El conjunto de banderas para el conjunto, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX, que se establece cuando se permiten prefijos no ambiguos de subcomandos para ser resueltos a implementaciones, así como coincidencias exactas. Las banderas pueden leerse y escribirse usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el comando del conjunto y el nombre del subcomando), o NULL si cada subcomando debe ser mapeado al comando con el mismo nombre no calificado en el espacio de nombres enlazado del conjunto. Por defecto es NULL. Puede leerse y escribirse usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable, incluso si no se comparte. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros pre-subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor por defecto) es equivalente a la lista vacía. Puede leerse y escribirse usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable, incluso si no se comparte.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto se deriva de las claves del diccionario de mapeo (ver arriba) o (si eso también es NULL) del conjunto de comandos exportados por el espacio de nombres enlazado. Puede leerse y escribirse usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable, incluso si no se comparte.
prefijo de comando manejador de subcomando desconocido (lectura/escritura)
Una lista de palabras para anteponer a cualquier subcomando cuando el subcomando es desconocido para el conjunto (según la regla de manejo de prefijos actual); consulte el comando unknown de Tcl. Puede leerse y escribirse usando Tcl_GetEnsembleUnknownHandler y Tcl_SetEnsembleUnknownHandler respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleUnknownHandler siempre debe tratarse como inmutable, incluso si no se comparte.
espacio de nombres (solo lectura)
El espacio de nombres al que está enlazado el conjunto. Puede leerse usando Tcl_GetEnsembleNamespace. El resultado de esta función es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).

HISTORIA

La API de conjuntos se introdujo en Tcl 8.4.

ARGUMENTS

bound namespace (read-only)
The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).

DESCRIPTION

Ensembles provide a mechanism for implementing command dispatching based on subcommands. They are designed to simplify the implementation of complex commands with many subcommands, or commands whose subcommands are implemented in different namespaces.

Tcl_IsEnsemble checks if the given token refers to an ensemble. It returns 1 if true, 0 otherwise.

Tcl_FindEnsemble searches for an ensemble by name and returns a Tcl_Command token representing it. It returns NULL if the ensemble is not found or if the name refers to something other than an ensemble.

Tcl_CreateEnsemble creates a new ensemble with the given name, parent ensemble, and flags. The subcommands argument is a list of subcommand names, the map argument is a dictionary mapping subcommand names to command tokens, and the unknown argument is a script to be executed when an unknown subcommand is encountered. If NULL, the default behavior - generate a suitable error message - will be used when an unknown subcommand is encountered. May be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The result of both functions is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.

Tcl_GetEnsembleSubcommandList retrieves the list of subcommands for a given ensemble token. The list is returned in subcommandsPtr.

Tcl_GetEnsembleMappingDict retrieves the mapping dictionary for a given ensemble token. The dictionary is returned in mapPtr.

Tcl_GetEnsembleUnknownHandler retrieves the unknown handler script for a given ensemble token. The script is returned in unknownPtr.

Tcl_SetEnsembleUnknownHandler sets the unknown handler script for a given ensemble token. The unknown argument is the script to set.

Tcl_GetEnsembleNamespace retrieves the namespace to which the ensemble is bound. The namespace is returned in nsPtr.

Tcl_GetEnsembleName retrieves the name of the ensemble. The name is returned in namePtr.

Tcl_SetEnsembleName sets the name of the ensemble.

Tcl_DeleteEnsemble deletes the given ensemble. All subcommands and children ensembles are also deleted.

Tcl_GetEnsembleArgumentVector retrieves the argument vector for a given ensemble token. The argument vector is returned in argVecPtr.

Tcl_SetEnsembleArgumentVector sets the argument vector for a given ensemble token. The argVec argument is the argument vector to set.

Tcl_GetEnsembleParent returns the ensemble token of the parent ensemble, or NULL if the ensemble is a top-level ensemble.

Tcl_GetEnsembleToken returns a Tcl_Command token representing the ensemble with the given name.

Tcl_CanonicalizeEnsembleToken converts a potentially indirect token into a direct token.

Tcl_GetEnsembleFromToken returns the ensemble token associated with the given token. If the token is not an ensemble, it returns NULL.
