DESCRIPCION

Estos procedimientos están diseñados para acceder a la instalación de múltiples intérpretes desde programas C. Permiten gestionar múltiples intérpretes en una relación jerárquica, y la gestión de alias, comandos que cuando se invocan en un intérprete ejecutan un comando en otro intérprete. El valor de retorno para aquellos procedimientos que devuelven un int es TCL_OK o TCL_ERROR. Si se devuelve TCL_ERROR, el resultado del intérprete contiene un mensaje de error.

Tcl_CreateSlave crea un nuevo intérprete como hijo de interp. También crea un comando hijo llamado childName en interp que permite a interp manipular al nuevo hijo. Si isSafe es cero, el comando crea un hijo confiable en el que el código Tcl tiene acceso a todos los comandos Tcl. Si es 1, el comando crea un hijo “seguro” en el que el código Tcl solo tiene acceso a un conjunto de comandos Tcl definidos como “Safe Tcl”; consulte la entrada del manual para el comando interp de Tcl para obtener detalles. Si la creación del nuevo intérprete hijo falló, se devuelve NULL.

Tcl_CreateChild es un sinónimo de Tcl_CreateSlave.

Tcl_IsSafe devuelve 1 si interp es “seguro” (fue creado con el indicador TCL_SAFE_INTERPRETER especificado), 0 en caso contrario.

Tcl_MakeSafe marca interp como “seguro”, de modo que las llamadas futuras a Tcl_IsSafe devuelvan 1. También elimina toda la funcionalidad central potencialmente insegura conocida (tanto comandos como variables) de interp. Sin embargo, no puede saber qué partes de una extensión o aplicación son seguras y no intenta eliminar esas partes, por lo que la seguridad no está garantizada después de llamar a Tcl_MakeSafe. Los llamadores querrán tener cuidado con el uso de Tcl_MakeSafe para evitar falsas afirmaciones de seguridad. Para muchas situaciones, Tcl_CreateSlave puede ser una mejor opción, ya que crea intérpretes en un estado conocido como seguro.

Tcl_GetSlave devuelve un puntero a un intérprete hijo de interp. El intérprete hijo se identifica mediante childName. Si no existe tal intérprete hijo, se devuelve NULL.

Tcl_GetChild es un sinónimo de Tcl_GetSlave.

Tcl_GetMaster devuelve un puntero al intérprete maestro de interp. Si interp no tiene maestro (es un intérprete de nivel superior), se devuelve NULL.

Tcl_GetParent es un sinónimo de Tcl_GetMaster.

Tcl_GetInterpPath almacena en el resultado de interp la ruta relativa entre interp y childInterp; childInterp debe ser un hijo de interp. Si el cálculo de la ruta relativa tiene éxito, se devuelve TCL_OK, de lo contrario, se devuelve TCL_ERROR y se almacena un mensaje de error como resultado de interp.

Tcl_CreateAlias crea un comando llamado childCmd en childInterp que, cuando se invoca, hará que el comando targetCmd se invoque en targetInterp. Los argumentos especificados por las cadenas contenidas en argv siempre se anteponen a cualquier argumento suministrado en la invocación de childCmd y se pasan a targetCmd. Esta operación devuelve TCL_OK si tiene éxito, o TCL_ERROR si falla; en ese caso, se deja un mensaje de error en el resultado del valor de childInterp. Tenga en cuenta que no hay restricciones en la relación de ascendencia (tal como la crea Tcl_CreateSlave) entre childInterp y targetInterp. Se pueden utilizar dos intérpretes cualesquiera, sin restricciones sobre cómo están relacionados.

Tcl_CreateAliasObj es similar a Tcl_CreateAlias excepto que toma un vector de valores para pasar como argumentos adicionales en lugar de un vector de cadenas.

Tcl_GetAliasObj devuelve información en forma de un puntero a un vector de estructuras Tcl_Obj sobre un alias aliasName en interp. Cualquiera de los campos de resultado puede ser NULL, en cuyo caso el dato correspondiente no se devuelve. Si un campo de resultado no es NULL, la dirección indicada se establece en el dato correspondiente. Por ejemplo, si targetCmdPtr no es NULL, se establece en un puntero a la cadena que contiene el nombre del comando de destino.

Tcl_ExposeCommand(3)

Introducción a la API de Tcl

NOMBRE

Tcl_ExposeCommand, Tcl_HideCommand - exponer y ocultar comandos en un intérprete de Tcl

SINÓPSIS

#include <tcl.h>
int
Tcl_ExposeCommand(interp, hiddenCmdName, cmdName);
int
Tcl_HideCommand(interp, cmdName, hiddenCmdName);

ARGUMENTOS

Tcl_Interp *interp
Intérprete de Tcl en el que realizar la operación.
const char *hiddenCmdName
El nombre del comando en el conjunto de comandos ocultos.
const char *cmdName
El nombre del comando en el conjunto de comandos expuestos.

DESCRIPCIÓN

Las funciones Tcl_ExposeCommand y Tcl_HideCommand se utilizan para mover comandos entre el conjunto de comandos expuestos y el conjunto de comandos ocultos de un intérprete. Los comandos expuestos son visibles y pueden ser invocados directamente desde scripts de Tcl. Los comandos ocultos no son directamente invocables desde scripts, pero pueden ser invocados mediante un comando alias o por otros comandos expuestos. El conjunto de comandos ocultos se utiliza típicamente para proporcionar una interfaz pública a un módulo o para implementar mecanismos de control de acceso. Las operaciones de ocultar/exponer sólo afectan a los comandos que han sido registrados utilizando Tcl_CreateCommand. Los comandos integrados no pueden ser ocultados o expuestos de esta manera. Las llamadas a estas funciones son un error si el comando solicitado no existe o si ya existe un comando con el nombre de destino. Una llamada exitosa devuelve TCL_OK. Una llamada fallida devuelve TCL_ERROR y el resultado del intérprete contendrá un mensaje de error.

Tcl_ExposeCommand mueve el comando llamado hiddenCmdName del conjunto de comandos ocultos al conjunto de comandos expuestos, poniéndolo bajo el nombre cmdName. hiddenCmdName debe ser el nombre de un comando oculto existente, o la operación devolverá TCL_ERROR y dejará un mensaje de error como resultado de interp. Si ya existe un comando expuesto llamado cmdName, la operación devolverá TCL_ERROR y dejará un mensaje de error como resultado de interp. Si la operación tiene éxito, devolverá TCL_OK. Después de ejecutar este comando, los intentos de usar cmdName en cualquier mecanismo de evaluación de scripts volverán a tener éxito.

Tcl_HideCommand mueve el comando llamado cmdName del conjunto de comandos expuestos al conjunto de comandos ocultos, bajo el nombre hiddenCmdName. cmdName debe ser el nombre de un comando expuesto existente, o la operación devolverá TCL_ERROR y dejará un mensaje de error como resultado de interp. Actualmente, tanto cmdName como hiddenCmdName no deben contener calificadores de espacio de nombres, o la operación devolverá TCL_ERROR y dejará un mensaje de error como resultado de interp. El cmdName se buscará en el espacio de nombres global, y no en relación con el espacio de nombres actual, incluso si el espacio de nombres actual no es el global. Si ya existe un comando oculto cuyo nombre es hiddenCmdName, la operación también devolverá TCL_ERROR y se dejará un mensaje de error como resultado de interp. Si la operación tiene éxito, devolverá TCL_OK. Después de ejecutar este comando, los intentos de usar cmdName en cualquier mecanismo de evaluación de scripts fallarán.

Para una descripción de la interfaz de Tcl para múltiples intérpretes, ver interp(n).
