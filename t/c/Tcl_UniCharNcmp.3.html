DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como una cantidad de tamaño fijo sin signo. Un carácter UTF-8 es un carácter Unicode representado como una secuencia de longitud variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 multibyte consta de un byte de encabezado seguido de un cierto número de bytes de seguimiento.

TCL_UTF_MAX es el número máximo de bytes que se necesitan para representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 comenzando en buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 comenzando en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamador debe asegurarse de que el búfer de origen sea lo suficientemente largo para que esta rutina no se salga del final y no desreferencie memoria inexistente o aleatoria; si se sabe que el búfer de origen está terminado en nulo, esto no sucederá. Si la entrada no tiene el formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada a UTF-8, almacenando el resultado en un Tcl_DString previamente inicializado. Debe especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada a Unicode, almacenando el resultado en el Tcl_DString previamente inicializado. En el argumento length, puede especificar la longitud de la cadena UTF-8 dada en bytes o “-1”, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString. La cadena Unicode está terminada con un carácter nulo Unicode.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en nulo y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en nulo y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres de longitud. Tcl_UniCharNcmp compara las dos cadenas carácter a carácter según el orden de caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena respectivamente. Tcl_UniCharNcasecmp es la versión Unicode insensible a mayúsculas y minúsculas.

Tcl_UniCharCaseMatch es el equivalente Unicode a Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en nulo, un patrón Unicode y un valor booleano que especifica si la comparación debe ser sensible a mayúsculas y minúsculas y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en nulo y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres de longitud). Tcl_UtfNcmp compara las dos cadenas carácter a carácter según el orden de caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas y minúsculas al comparar caracteres mayúsculos, minúsculos o de título.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 de origen src de length bytes es lo suficientemente larga para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté formada correctamente. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars que están representados por la cadena UTF-8 src. La longitud de la cadena de origen es length bytes. Si la longitud es negativa, se utilizan todos los bytes hasta el primer byte nulo.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfNext devuelve un puntero al siguiente carácter UTF-8 después de la cadena UTF-8 src. El valor de retorno es el puntero del byte de inicio del siguiente carácter UTF-8, o un puntero nulo si src apuntaba a un carácter final (terminador nulo).

Tcl_UtfPrev devuelve un puntero al carácter UTF-8 anterior a la cadena UTF-8 src, pero no anterior al puntero start. El valor de retorno es el puntero del byte de inicio del carácter anterior. Si no hay carácter anterior (es decir, si src ya apunta al inicio de la cadena UTF-8 o más allá), el comportamiento no está definido.

Tcl_UniCharAtIndex devuelve el carácter Unicode en el índice especificado dentro de la cadena UTF-8 src. La cadena se interpreta como una secuencia de caracteres Unicode, no de bytes. Si el índice está fuera de rango, el valor devuelto no está definido.

Tcl_UtfAtIndex devuelve un puntero al carácter UTF-8 en el índice especificado dentro de la cadena UTF-8 src. La cadena se interpreta como una secuencia de caracteres UTF-8, no de bytes. Si el índice está fuera de rango, el valor devuelto no está definido.

Tcl_UtfBackslash procesa una secuencia de barra invertida comenzando en la posición src. Rellena *readPtr con el número de bytes leídos de src (incluido el carácter de barra invertida) y almacena los bytes resultantes en dst. El valor de retorno es el número de bytes escritos en dst. Esto se utiliza para la interpolación de cadenas.

ARGUMENTS

Arguments

The procedures described below deal with Tcl's internal representation of Unicode strings, which is UTF-8. See the Tcl manual entry for a full description of UTF-8. The procedures are divided into two groups: those that operate on UTF-8 strings (type `char *`) and those that operate on arrays of Tcl_UniChar values (type `Tcl_UniChar *`). Tcl_UniChar is a synonym for `int` and is large enough to hold any Unicode character.

The UTF-8 string procedures assume that the string is null-terminated, unless otherwise specified. UTF-8 uses a variable number of bytes per character, so operations that step through a string character-by-character are needed.

DESCRIPTION

Tcl_UniCharNcmp and Tcl_UniCharNcasecmp compare the first n Tcl_UniChar characters of the null-terminated strings pointed to by uni1 and uni2. They return a negative value if uni1 is less than uni2, zero if uni1 is equal to uni2, and a positive value if uni1 is greater than uni2. Tcl_UniCharNcasecmp ignores case.

Tcl_UniCharToUtf converts a single Tcl_UniChar character into its UTF-8 representation in buf. At most TCL_UTF_MAX bytes are written. The return value is the number of bytes written. This is the inverse of Tcl_UtfToUniChar.

Tcl_UtfToUniChar converts the first UTF-8 character in src into a Tcl_UniChar and stores it in *wideCharPtr. The return value is the number of bytes consumed from src. If the character is malformed or incomplete, 0 is returned and *wideCharPtr is set to 0.

Tcl_UniCharToUtfDString converts the first n Tcl_UniChar characters in uni to UTF-8 and appends the result to the Tcl_DString dsPtr. The return value is the number of bytes appended. If n is negative, the entire string uni is converted.

Tcl_UtfToUniCharDString converts the first n bytes in the UTF-8 string src to Tcl_UniChar characters and appends the result to the Tcl_DString dsPtr. The return value is the number of Tcl_UniChar characters appended. If n is negative, the entire string src is converted.

Tcl_UniCharLen returns the number of Tcl_UniChar characters in the null-terminated string uni.

Tcl_UniCharByteLen returns the number of bytes required to store the first n Tcl_UniChar characters from uni in UTF-8 format. If n is negative, the entire string uni is converted.

Tcl_UniCharAtIndex returns a pointer to the Tcl_UniChar character at the specified character (not byte) index in the null-terminated string uni. The string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the null-terminated UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfNext returns a pointer to the next UTF-8 character in the string starting at src. The null terminator is considered part of the UTF-8 string.

Tcl_UtfCharComplete checks if the UTF-8 character starting at src is complete. It returns true if the character is complete and well-formed, or if src points to the null terminator. It returns false if the character is incomplete (i.e., requires more bytes than are available in the first len bytes of the string).

Tcl_UniCharToWide converts a Tcl_UniChar character to a wide character (which is the same type as Tcl_UniChar). This function is provided for compatibility with older versions of Tcl.

Tcl_WideToUniChar converts a wide character to a Tcl_UniChar character. This function is provided for compatibility with older versions of Tcl.

Tcl_UniCharToWideDString converts a sequence of Tcl_UniChar characters to wide characters and appends them to the Tcl_DString dsPtr. The return value is the number of wide characters appended.

Tcl_WideToUniCharDString converts a sequence of wide characters to Tcl_UniChar characters and appends them to the Tcl_DString dsPtr. The return value is the number of Tcl_UniChar characters appended.

Tcl_UniCharMatch and Tcl_UniCharCaseMatch compare two null-terminated Tcl_UniChar strings for equality. Tcl_UniCharCaseMatch ignores case. They return 1 if the strings match and 0 otherwise.

The functions Tcl_UniCharIsAlnum, Tcl_UniCharIsAlpha, Tcl_UniCharIsDigit, Tcl_UniCharIsSpace, Tcl_UniCharIsCntrl, Tcl_UniCharIsGraph, Tcl_UniCharIsLower, Tcl_UniCharIsPrint, Tcl_UniCharIsUpper, and Tcl_UniCharIsWord all take a single Tcl_UniChar character as input and return true if the character satisfies the specified Unicode property, and false otherwise. The definitions of these properties conform to the Unicode standard.

Tcl_UniCharToLower and Tcl_UniCharToUpper convert a Tcl_UniChar character to its lowercase or uppercase equivalent, respectively. If no equivalent exists, the original character is returned. The conversions take locale into account.

Tcl_UniCharToFold converts a Tcl_UniChar character to its case-folding equivalent. This is a more general form of case conversion used for caseless matching.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.

Tcl_GetUniCharFromUtf converts the first character from the UTF-8 string src (of length len) into a Tcl_UniChar. It returns the Tcl_UniChar value. If the character is malformed or incomplete, 0 is returned.

Tcl_PutUniCharToUtf converts the Tcl_UniChar character wideChar into its UTF-8 representation and stores it in the buffer buf. At most TCL_UTF_MAX bytes are written. The return value is the number of bytes written. This is equivalent to Tcl_UniCharToUtf.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].
