Tcl_ListObj(3) Procedimientos de la biblioteca Tcl Tcl_ListObj(3)

NOMBRE

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipular valores Tcl como listas

SINOPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de lista, se deja un mensaje de error en el resultado del intérprete, a menos que interp sea NULL.
Tcl_Obj *listPtr (entrada/salida)
Punta al valor de lista que se va a manipular. Si listPtr no apunta ya a un valor de lista, se intentará convertirlo en uno.
Tcl_Obj *elemListPtr (entrada/salida)
Para Tcl_ListObjAppendList, apunta a un valor de lista que contiene elementos a añadir a listPtr. Cada elemento de *elemListPtr se convertirá en un nuevo elemento de listPtr. Si *elemListPtr no es NULL y ya no apunta a un valor de lista, se intentará convertirlo en uno.
Tcl_Obj *objPtr (entrada)
Para Tcl_ListObjAppendElement, apunta al valor Tcl que se añadirá a listPtr. Para Tcl_SetListObj, apunta al valor Tcl que se convertirá en un valor de lista que contiene los objc elementos de la matriz referenciada por objv.
int *objcPtr (entrada)
Punta a la ubicación donde Tcl_ListObjGetElements almacena el número de valores de elemento en listPtr.
Tcl_Obj ***objvPtr (salida)
Una ubicación donde Tcl_ListObjGetElements almacena un puntero a una matriz de punteros a los valores de elemento de listPtr.
int objc (entrada)
El número de valores Tcl que Tcl_NewListObj insertará en un nuevo valor de lista, y que Tcl_ListObjReplace insertará en listPtr. Para Tcl_SetListObj, el número de valores Tcl a insertar en objPtr.
Tcl_Obj *const objv[] (entrada)
Una matriz de punteros a valores. Tcl_NewListObj insertará estos valores en un nuevo valor de lista y Tcl_ListObjReplace los insertará en un listPtr existente. Cada valor se convertirá en un elemento de lista separado.
int *lengthPtr (salida)
Punta a la ubicación donde Tcl_ListObjLength almacena la longitud de la lista.
int index (entrada)
Índice del elemento de lista que Tcl_ListObjIndex debe devolver. El primer elemento tiene el índice 0.
Tcl_Obj **objPtrPtr (salida)
Punta al lugar donde Tcl_ListObjIndex debe almacenar un puntero al valor del elemento de lista resultante.
int first (entrada)
Índice del elemento de lista inicial que Tcl_ListObjReplace debe reemplazar. El primer elemento de la lista tiene el índice 0.
int count (entrada)
El número de elementos que Tcl_ListObjReplace debe reemplazar.

DESCRIPCIÓN

Los valores de lista Tcl tienen una representación interna que soporta la indexación y la adición eficiente. Los procedimientos descritos en esta página del manual se utilizan para crear, modificar, indexar y añadir a valores de lista Tcl desde código C.

Tcl_ListObjAppendList y Tcl_ListObjAppendElement ambos añaden uno o más valores al final del valor de lista referenciado por listPtr. Tcl_ListObjAppendList añade cada elemento del valor de lista referenciado por elemListPtr mientras que Tcl_ListObjAppendElement añade el valor único referenciado por objPtr. Ambos procedimientos convertirán el valor referenciado por listPtr en un valor de lista si es necesario. Si ocurre un error durante la conversión, ambos procedimientos devuelven TCL_ERROR y dejan un mensaje de error en el resultado del intérprete si interp no es NULL. De manera similar, si elemListPtr no se refiere ya a un valor de lista, Tcl_ListObjAppendList intentará convertirlo en uno y si ocurre un error durante la conversión, devolverá TCL_ERROR y dejará un mensaje de error en el resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió en un valor de lista, liberan cualquier representación interna antigua. De manera similar, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si lo convierte en un valor de lista. Después de añadir cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento ya que listPtr ahora también se refiere a él. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no ocurre ningún error, los dos procedimientos devuelven TCL_OK después de añadir los valores.

Tcl_NewListObj y Tcl_SetListObj crean un nuevo valor o modifican un valor existente para contener los objc elementos de la matriz referenciada por objv, donde cada elemento es un puntero a un valor Tcl. Si objc es menor o igual a cero, devuelven un valor vacío. Si objv es NULL, la lista resultante contiene 0 elementos, con espacio reservado en una representación interna para objc elementos más (para evitar su reasignación posterior). La representación de cadena del nuevo valor se deja inválida. Los dos procedimientos incrementan los contadores de referencias de los elementos en objc ya que el valor de lista ahora se refiere a ellos. El nuevo valor de lista devuelto por Tcl_NewListObj tiene un contador de referencias cero.

Tcl_ListObjGetElements devuelve un recuento y un puntero a una matriz de los elementos de un valor de lista. Devuelve el recuento almacenándolo en la dirección objcPtr. De manera similar, devuelve el puntero a la matriz almacenándolo en la dirección objvPtr. La memoria apuntada es gestionada por Tcl y no debe ser liberada ni escrita por el llamador. Si la lista está vacía, se almacena 0 en objcPtr y NULL en objvPtr. Si listPtr no es ya un valor de lista, Tcl_ListObjGetElements intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar el recuento y el puntero a la matriz.

Tcl_ListObjLength devuelve el número de elementos en el valor de lista referenciado por listPtr. Devuelve este recuento almacenando un entero en la dirección lengthPtr. Si el valor no es ya un valor de lista, Tcl_ListObjLength intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar la longitud de la lista.

El procedimiento Tcl_ListObjIndex devuelve un puntero al valor en el elemento index de la lista referenciada por listPtr. Devuelve este valor almacenando un puntero a él en la dirección objPtrPtr. Si listPtr no se refiere ya a un valor de lista, Tcl_ListObjIndex intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. Si el índice está fuera de rango, es decir, index es negativo o mayor o igual que el número de elementos en la lista, Tcl_ListObjIndex almacena un NULL en objPtrPtr y devuelve TCL_OK. De lo contrario, devuelve TCL_OK después de almacenar el puntero al valor del elemento. El contador de referencias para el elemento de lista no se incrementa; el llamador debe hacerlo si necesita conservar un puntero al elemento.

Tcl_ListObjReplace reemplaza cero o más elementos de la lista referenciada por listPtr con los objc valores en la matriz referenciada por objv. Si listPtr no apunta a un valor de lista, Tcl_ListObjReplace intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de reemplazar los valores. Si objv es NULL, no se añaden nuevos elementos. Si el argumento first es cero o negativo, se refiere al primer elemento. Tcl_ListObjReplace(3)

NAME

Tcl_ListObjReplace - replace elements in a list value

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_Obj **listPtr
Pointer to the object containing the list value.
int first
Index of the first element to replace. If negative, it indicates an offset from the end of the list.
int count
Number of elements to delete, starting at first. If 0 or negative, no elements are deleted.
int objc
Number of new elements to insert. If 0, no elements are inserted.
const Tcl_Obj *const *objv
Array of new elements to insert. This argument is ignored if objc is 0.

DESCRIPTION

This procedure replaces a number of elements in the list value pointed to by listPtr with a new set of elements. The list value must already exist and be of list type. The elements to be replaced are specified by the first and count arguments. The new elements are specified by the objc and objv arguments.

The first argument is the index of the first element to be replaced. Indices start at 0 for the first element. If first is negative, then it indicates an offset from the end of the list: -1 refers to the last element, -2 to the second-to-last, and so on. If first is greater than or equal to the number of elements in the list, the new elements are appended to the end of the list. If first is less than the negative of the number of elements in the list, then the insertion point will be the beginning of the list.

The count argument specifies how many elements should be deleted from the list, starting at the position given by first. If count is zero or negative, then no elements are deleted. The new elements are simply inserted before the element designated by first. If count is greater than the number of elements available from first to the end of the list, then all elements from first to the end of the list are deleted.

The objc argument specifies the number of new elements to insert, and objv is an array of pointers to the objects that make up the new elements. If objc is zero, then no elements are inserted. If objc is positive, then the objc elements are inserted into the list at the position specified by first. If the count argument was positive, then the specified elements are first deleted, and then the new elements are inserted. If count was zero or negative, the new elements are simply inserted at the position indicated by first, shifting the existing elements at and after that position to make space. If first is greater than or equal to the number of elements in the list, then the new elements are appended to the end of the list, regardless of the value of count.

If the list is modified, Tcl_ListObjReplace invalidates the existing string representation of the list. It also updates the reference counts of the objects involved. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

Because Tcl_ListObjReplace combines both element insertion and deletion, it can be used to implement a number of list operations. For example, the following code inserts the objc values referenced by the array of value pointers objv just before the element index of the list referenced by listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

Similarly, the following code appends the objc values referenced by the array objv to the end of the list listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

The count list elements starting at first can be deleted by simply calling Tcl_ListObjReplace with a NULL objvPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
