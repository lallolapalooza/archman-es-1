DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como una cantidad fija y de tamaño fijo. Un carácter UTF-8 es un carácter Unicode representado como una secuencia de longitud variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 multibyte consta de un byte líder seguido de algunos bytes de seguimiento.

TCL_UTF_MAX es el número máximo de bytes que se necesitan para representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 comenzando en buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 comenzando en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamador debe asegurarse de que el búfer de origen sea lo suficientemente largo para que esta rutina no se salga del final y desreferencie memoria inexistente o aleatoria; si se sabe que el búfer de origen está terminado en nulo, esto no sucederá. Si la entrada no está en formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada a UTF-8, almacenando el resultado en un Tcl_DString inicializado previamente. Debe especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada a Unicode, almacenando el resultado en el Tcl_DString inicializado previamente. En el argumento length, puede especificar la longitud de la cadena UTF-8 dada en bytes o “-1”, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString. La cadena Unicode se termina con un carácter nulo Unicode.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en nulo y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en nulo y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres de longitud. Tcl_UniCharNcmp compara las dos cadenas carácter a carácter según el orden de caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente. Tcl_UniCharNcasecmp es la versión Unicode insensible a mayúsculas y minúsculas.

Tcl_UniCharCaseMatch es el equivalente Unicode a Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en nulo, un patrón Unicode y un valor booleano que especifica si la coincidencia debe ser sensible a mayúsculas y minúsculas y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en nulo y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres de longitud). Tcl_UtfNcmp compara las dos cadenas carácter a carácter según el orden de caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas y minúsculas al comparar caracteres mayúsculos, minúsculos o de título.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 de origen src de length bytes es lo suficientemente larga para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté correctamente formada. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars que están representados por la cadena UTF-8 src. La longitud de la cadena de origen es de length bytes. Si la longitud es negativa, se utilizan todos los bytes hasta el primer byte nulo.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfNext devuelve un puntero al siguiente carácter UTF-8 después de src. Si src apunta al último carácter UTF-8 de una cadena, devolverá un puntero al byte nulo de terminación.

Tcl_UtfPrev devuelve un puntero al carácter UTF-8 anterior a src. start debe apuntar al principio de la cadena UTF-8. Si src apunta al primer carácter UTF-8 de una cadena, devolverá start.

Tcl_UniCharAtIndex devuelve el Tcl_UniChar en el index especificado dentro de la cadena UTF-8 src. El índice 0 corresponde al primer carácter.

Tcl_UtfAtIndex devuelve un puntero al carácter UTF-8 en el index especificado dentro de la cadena UTF-8 src. El índice 0 corresponde al primer carácter.

Tcl_UtfBackslash decodifica secuencias de escape de barra invertida Unicode de Tcl (como \n, \r, \t, \uXXXX, etc.) en la cadena de entrada src. Almacena los bytes resultantes en el búfer de salida dst. Si readPtr no es NULL, se rellena con el número de bytes leídos de src para el carácter decodificado, incluido el carácter de barra invertida. El valor de retorno es el número de bytes escritos en dst. Esta rutina admite los mismos códigos de escape que el comando Tcl string backslash.

DESCRIPTION

These procedures provide routines for converting between Tcl's internal representation of characters, which is UTF-8, and the C char type. They also provide routines for finding the Nth character in a UTF-8 string, and for parsing backslash-escaped sequences.

Tcl_UniCharToUtf converts a single Unicode character, represented as a Tcl_UniChar (which is a 32-bit integer type), into a UTF-8 sequence. The result is stored in the buffer pointed to by utf. At most TCL_UTF_MAX bytes will be written into the buffer. The return value is the number of bytes written. The caller is responsible for ensuring that the buffer utf is large enough to hold the result.

Tcl_UniCharsToUtf converts a sequence of Unicode characters, starting at uni and consisting of len characters, into a UTF-8 sequence. The result is stored in the buffer pointed to by utf. The return value is the number of bytes written. The caller is responsible for ensuring that the buffer utf is large enough to hold the result.

Tcl_UniCharLength returns the number of bytes required to store the UTF-8 representation of the Unicode character uniChar. This will be between 1 and 4, inclusive. For example, a Tcl_UniChar value of 0x20 corresponds to the UTF-8 byte sequence 0x20, which is one byte.

Tcl_UtfToUniChar converts a single UTF-8 character into a Unicode character. The UTF-8 character is read from the string pointed to by utf. The function returns the Unicode character. If the input string is not a valid UTF-8 character, the function returns 0xFFFD (the Unicode replacement character) and sets *lenPtr to 1. If the input does not contain a complete character (i.e., it ends mid-character), the function returns 0xFFFD and sets *lenPtr to the number of bytes consumed (which will be less than a full character). Otherwise, it returns the Unicode character and sets *lenPtr to the number of bytes consumed to form the character (1 to 4 bytes).

Tcl_UtfToUniChars converts a sequence of UTF-8 characters into Unicode characters. The UTF-8 characters are read from the string pointed to by utf. The result is stored in the buffer pointed to by uni. The argument len is the maximum number of bytes to read from the utf string. The argument len is also the maximum number of Unicode characters to write into the uni buffer. The return value is the number of Unicode characters written. The caller is responsible for ensuring that the buffer uni is large enough to hold the result. If any invalid UTF-8 sequences are encountered, they are converted to the Unicode replacement character (U+FFFD).

Tcl_UtfLength computes the length of a UTF-8 string in characters, not bytes. It stores the result in *lengthPtr and returns the number of bytes consumed. If the string is not valid UTF-8, it returns the number of bytes consumed up to the invalid sequence and stores the number of characters found so far in *lengthPtr. If the string is valid UTF-8, it consumes the entire string and returns its length in bytes.

Tcl_UniCharAtIndex returns the Tcl_UniChar character at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfCharComplete checks if the UTF-8 string starting at str and having length length contains a complete character. This is useful when reading from input streams where a character may be split across read operations. It returns true if the string ends on a character boundary or if the string is empty. Otherwise, it returns false.

Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The string is assumed to be null-terminated. The null terminator is considered part of the UTF-8 string.

Given src, a pointer to some location in a UTF-8 string, Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
