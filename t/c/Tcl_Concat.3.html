Tcl_Concat(3) Procedimientos de la biblioteca Tcl Tcl_Concat(3)

NOMBRE

Tcl_Concat - concatenar una colección de cadenas

SINOPSIS

#include <tcl.h>

const char *
Tcl_Concat(argc, argv)

ARGUMENTOS

int argc (entrada)
Número de cadenas.
const char *const argv[] (entrada)
Matriz de cadenas a concatenar. Debe tener argc elementos.

DESCRIPCIÓN

Tcl_Concat es un procedimiento de utilidad utilizado por varios comandos de Tcl. Dada una colección de cadenas, las concatena en una sola cadena, con las cadenas originales separadas por espacios. Este procedimiento se comporta de manera diferente a Tcl_Merge, en el sentido de que los argumentos simplemente se concatenan: no se hace ningún esfuerzo para garantizar una estructura de lista adecuada. Sin embargo, en el uso más común, los argumentos serán listas adecuadas en sí mismos; si esto es cierto, entonces el resultado también tendrá una estructura de lista adecuada.

Tcl_Concat elimina los espacios en blanco iniciales y finales al copiar las cadenas de argv al resultado. Si un elemento de argv consiste únicamente en espacios en blanco, esa cadena se ignora por completo. Esta eliminación de espacios en blanco se añadió para que la salida del comando concat tenga una apariencia más limpia.

La cadena resultante se asigna dinámicamente usando Tcl_Alloc; el llamador debe eventualmente liberar el espacio llamando a Tcl_Free.
