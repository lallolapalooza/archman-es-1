Tcl_NRExprObj(3)

Paquete: tcl

Licencias: TCL

NRE(3) Procedimientos de la biblioteca Tcl NRE(3)

NOMBRE

Tcl_NRCreateCommand, Tcl_NRCallObjProc, Tcl_NREvalObj, Tcl_NREvalObjv, Tcl_NRCmdSwap, Tcl_NRExprObj, Tcl_NRAddCallback - Evaluación no recursiva (sin pila) de scripts Tcl.

SINOPSIS

#include <tcl.h>

Tcl_Command
Tcl_NRCreateCommand(interp, cmdName, proc, nreProc, clientData,
                    deleteProc)

int
Tcl_NRCallObjProc(interp, nreProc, clientData, objc, objv)

int
Tcl_NREvalObj(interp, objPtr, flags)

int
Tcl_NREvalObjv(interp, objc, objv, flags)

int
Tcl_NRCmdSwap(interp, cmd, objc, objv, flags)

int
Tcl_NRExprObj(interp, objPtr, resultPtr)

void
Tcl_NRAddCallback(interp, postProcPtr, data0, data1, data2, data3)

ARGUMENTOS

Tcl_Interp *interp (entrada)
El Intérprete relevante.
const char *cmdName (entrada)
Nombre del comando a crear.
Tcl_ObjCmdProc *proc (entrada)
Se llama para evaluar un comando. A menudo es solo un pequeño envoltorio que usa Tcl_NRCallObjProc para llamar a nreProc usando una nueva trampolina. Se comporta de la misma manera que el argumento proc de Tcl_CreateObjCommand(3) (véase).
Tcl_ObjCmdProc *nreProc (entrada)
Se llama en lugar de proc cuando ya se está utilizando una trampolina.
ClientData clientData (entrada)
Valor arbitrario de una palabra pasado a proc, nreProc, deleteProc y objProc.
Tcl_CmdDeleteProc *deleteProc (entrada/salida)
Se llama antes de que se elimine cmdName del intérprete, permitiendo la limpieza específica del comando. Puede ser NULL.
int objc (entrada)
Número de elementos en objv.
Tcl_Obj **objv (entrada)
Palabras en el comando.
Tcl_Obj *objPtr (entrada)
Un script o expresión a evaluar.
int flags (entrada)
Como se describe para Tcl_EvalObjv.
Tcl_Command cmd (entrada)
Token a utilizar en lugar de uno derivado de la primera palabra de objv para evaluar un comando.
Tcl_Obj *resultPtr (salida)
Puntero a un Tcl_Obj no compartido donde se almacena el resultado de la evaluación si el código de retorno es TCL_OK.
Tcl_NRPostProc *postProcPtr (entrada)
Una función para empujar.
ClientData data0 (entrada)
ClientData data1 (entrada)
ClientData data2 (entrada)
ClientData data3 (entrada)
data0 a través de data3 son cuatro valores de una palabra que se pasarán a la función designada por postProcPtr cuando se invoque.

DESCRIPCIÓN

Estas funciones proporcionan una interfaz a la pila de funciones que un intérprete itera para evaluar comandos. La rutina detrás de un comando se implementa mediante una función inicial y cualquier función adicional que la rutina empuja en la pila a medida que avanza. El intérprete mismo empuja funciones en la pila para reaccionar al final de una rutina y para ejercer otras formas de control, como cambiar entre pilas en progreso y la evaluación de otros scripts en niveles adicionales sin agregar marcos a la pila de C. Para ejecutar una rutina, se llama a la función inicial de la rutina y luego un pequeño fragmento de código llamado trampolina toma iterativamente funciones de la pila y las llama, usando el valor de la última llamada como el valor de la rutina.

Tcl_NRCallObjProc llama a nreProc usando una nueva trampolina.

Tcl_NRCreateCommand, una alternativa a Tcl_CreateObjCommand, resuelve cmdName, que puede contener calificadores de espacio de nombres, en relación con el espacio de nombres actual, crea un comando con ese nombre y devuelve un token para el comando que puede usarse en llamadas posteriores a Tcl_GetCommandName. Excepto en algunos casos que se señalan a continuación, cualquier comando existente con el mismo nombre se elimina primero. Si interp está en proceso de ser eliminado, Tcl_NRCreateCommand no crea ningún comando, no elimina ningún comando y devuelve NULL.

Tcl_NREvalObj empuja una función que es como Tcl_EvalObjEx pero no consume espacio en la pila de C.

Tcl_NREvalObjv empuja una función que es como Tcl_EvalObjv pero no consume espacio en la pila de C.

Tcl_NRCmdSwap es como Tcl_NREvalObjv, pero usa cmd, un token devuelto previamente por Tcl_CreateObjCommand o Tcl_GetCommandFromObj, en lugar de resolver la primera palabra de objv.

Tcl_NRExprObj empuja una función que evalúa objPtr como una expresión de la misma manera que Tcl_ExprObj pero sin consumir espacio en la pila de C.

Todas las funciones devuelven TCL_OK si la evaluación del script, comando o expresión se ha programado con éxito. De lo contrario (por ejemplo, si el nombre del comando no se puede resolver), devuelven TCL_ERROR y almacenan un mensaje como resultado del intérprete.

Tcl_NRAddCallback empuja postProcPtr. La firma para Tcl_NRPostProc es:

typedef int
Tcl_NRPostProc(
        ClientData data[],
        Tcl_Interp *interp,
        int result);

data es un puntero a una matriz que contiene data0 a través de data3. result es el valor devuelto por la función anterior que implementa parte de la rutina.

EJEMPLO

El siguiente comando utiliza Tcl_EvalObjEx, que consume espacio en la pila de C, para evaluar un script:

int
TheCmdOldObjProc(
    ClientData clientData,
    Tcl_Interp *interp,
    int objc,
    Tcl_Obj *const objv[])
{
    int result;
    Tcl_Obj *objPtr;
    ... preparación ...
    result = Tcl_EvalObjEx(interp, objPtr, 0);
    ... postprocesamiento ...
    return result;
}
Tcl_CreateObjCommand(interp, "theCommand",
        TheCmdOldObjProc, clientData, TheCmdDeleteProc);

Para evitar consumir espacio en la pila de C, TheCmdOldObjProc se renombra a TheCmdNRObjProc y el paso de postprocesamiento se divide en una función separada, TheCmdPostProc, que se empuja en la pila de funciones. Tcl_EvalObjEx se reemplaza con Tcl_NREvalObj, que utiliza una trampolina en lugar de consumir espacio en la pila de C. Una nueva versión de TheCmdOldObjProc es solo un envoltorio que usa Tcl_NRCallObjProc para llamar a TheCmdNRObjProc:

int
TheCmdOldObjProc(
    ClientData clientData,
    Tcl_Interp *interp,
    int objc,
    Tcl_Obj *const objv[])
{
    return Tcl_NRCallObjProc(interp, TheCmdNRObjProc,
            clientData, objc, objv);
}
int
TheCmdNRObjProc
    ClientData clientData,
    Tcl_Interp *interp,
    int objc,
    Tcl_Obj *const objv[])
{
    Tcl_Obj *objPtr;
    ... preparación ...
    Tcl_NRAddCallback(interp, TheCmdPostProc,
            data0, data1, data2, data3);
    /* data0 .. data3 son hasta cuatro elementos de una palabra para
     * pasar al procedimiento de postprocesamiento */
    return Tcl_NREvalObj(interp, objPtr, 0);
}
int
TheCmdNRPostProc(
    ClientData data[],
    Tcl_Interp *interp,
    int result)
{
    /* data[0] .. data[3] son las cuatro palabras de datos
     * pasadas a Tcl_NRAddCallback */
    ... postprocesamiento ...
    return result;
}

Cualquier función que componga una rutina puede empujar otras funciones, lo que permite implementar construcciones de bucle y secuencia utilizando la pila de funciones.
