Tcl_SignalId(3) Procedimientos de la biblioteca Tcl Tcl_SignalId(3)

NOMBRE

Tcl_SignalId, Tcl_SignalMsg - Convertir códigos de señal

SINOPSIS

#include <tcl.h>

const char *
Tcl_SignalId(sig)

const char *
Tcl_SignalMsg(sig)

ARGUMENTOS

int sig (entrada)
Un número de señal POSIX como SIGPIPE.

DESCRIPCIÓN

Tcl_SignalId y Tcl_SignalMsg devuelven una representación en cadena del número de señal proporcionado (sig). Tcl_SignalId devuelve un identificador textual legible por máquina como "SIGPIPE". Tcl_SignalMsg devuelve una cadena legible por humanos como "error de bus". Las cadenas devueltas por estas funciones se asignan estáticamente y el llamador no debe liberarlas ni modificarlas.
