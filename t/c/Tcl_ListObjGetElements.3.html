Tcl_ListObj(3) Tcl Library Procedures Tcl_ListObj(3)

NOMBRE

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipular valores de Tcl como listas

SINOPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de lista, se deja un mensaje de error en el valor de resultado del intérprete a menos que interp sea NULL.
Tcl_Obj *listPtr (entrada/salida)
Punta al valor de lista que se manipulará. Si listPtr no apunta ya a un valor de lista, se intentará convertirlo en uno.
Tcl_Obj *elemListPtr (entrada/salida)
Para Tcl_ListObjAppendList, esto apunta a un valor de lista que contiene elementos para ser añadidos a listPtr. Cada elemento de *elemListPtr se convertirá en un nuevo elemento de listPtr. Si *elemListPtr no es NULL y no apunta ya a un valor de lista, se intentará convertirlo en uno.
Tcl_Obj *objPtr (entrada)
Para Tcl_ListObjAppendElement, apunta al valor de Tcl que se añadirá a listPtr. Para Tcl_SetListObj, apunta al valor de Tcl que se convertirá en un valor de lista que contiene los objc elementos del array referenciado por objv.
int *objcPtr (entrada)
Punta a la ubicación donde Tcl_ListObjGetElements almacena el número de valores de elemento en listPtr.
Tcl_Obj ***objvPtr (salida)
Una ubicación donde Tcl_ListObjGetElements almacena un puntero a un array de punteros a los valores de elemento de listPtr.
int objc (entrada)
El número de valores de Tcl que Tcl_NewListObj insertará en un nuevo valor de lista, y que Tcl_ListObjReplace insertará en listPtr. Para Tcl_SetListObj, el número de valores de Tcl para insertar en objPtr.
Tcl_Obj *const objv[] (entrada)
Un array de punteros a valores. Tcl_NewListObj insertará estos valores en un nuevo valor de lista y Tcl_ListObjReplace los insertará en un listPtr existente. Cada valor se convertirá en un elemento de lista separado.
int *lengthPtr (salida)
Punta a la ubicación donde Tcl_ListObjLength almacena la longitud de la lista.
int index (entrada)
Índice del elemento de la lista que Tcl_ListObjIndex debe devolver. El primer elemento tiene el índice 0.
Tcl_Obj **objPtrPtr (salida)
Punta al lugar donde Tcl_ListObjIndex debe almacenar un puntero al valor del elemento de lista resultante.
int first (entrada)
Índice del elemento de lista inicial que Tcl_ListObjReplace debe reemplazar. El primer elemento de la lista tiene el índice 0.
int count (entrada)
El número de elementos que Tcl_ListObjReplace debe reemplazar.

DESCRIPCIÓN

Los valores de lista de Tcl tienen una representación interna que admite la indexación y la adición eficientes. Los procedimientos descritos en esta página del manual se utilizan para crear, modificar, indexar y añadir valores de lista de Tcl desde código C.

Tcl_ListObjAppendList y Tcl_ListObjAppendElement ambos añaden uno o más valores al final del valor de lista referenciado por listPtr. Tcl_ListObjAppendList añade cada elemento del valor de lista referenciado por elemListPtr mientras que Tcl_ListObjAppendElement añade el único valor referenciado por objPtr. Ambos procedimientos convertirán el valor referenciado por listPtr en un valor de lista si es necesario. Si ocurre un error durante la conversión, ambos procedimientos devuelven TCL_ERROR y dejan un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De manera similar, si elemListPtr no se refiere ya a un valor de lista, Tcl_ListObjAppendList intentará convertirlo en uno y, si ocurre un error durante la conversión, devolverá TCL_ERROR y dejará un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió en un valor de lista, liberan cualquier representación interna antigua. De manera similar, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si la convierte en un valor de lista. Después de añadir cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento, ya que listPtr también se refiere a él. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no ocurre ningún error, los dos procedimientos devuelven TCL_OK después de añadir los valores.

Tcl_NewListObj y Tcl_SetListObj crean un nuevo valor o modifican uno existente para contener los objc elementos del array referenciado por objv, donde cada elemento es un puntero a un valor de Tcl. Si objc es menor o igual a cero, devuelven un valor vacío. Si objv es NULL, la lista resultante contiene 0 elementos, con espacio reservado en una representación interna para objc elementos más (para evitar su reasignación posterior). La representación de cadena del nuevo valor se deja invalidada. Los dos procedimientos incrementan los contadores de referencias de los elementos en objc, ya que el valor de lista ahora se refiere a ellos. El nuevo valor de lista devuelto por Tcl_NewListObj tiene un contador de referencias cero.

Tcl_ListObjGetElements devuelve un recuento y un puntero a un array de los elementos de un valor de lista. Devuelve el recuento almacenándolo en la dirección objcPtr. De manera similar, devuelve el puntero del array almacenándolo en la dirección objvPtr. La memoria apuntada es gestionada por Tcl y no debe ser liberada ni escrita por el llamante. Si la lista está vacía, se almacena 0 en objcPtr y NULL en objvPtr. Si listPtr no es ya un valor de lista, Tcl_ListObjGetElements intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar el recuento y el puntero del array.

Tcl_ListObjLength devuelve el número de elementos en el valor de lista referenciado por listPtr. Devuelve este recuento almacenando un entero en la dirección lengthPtr. Si el valor no es ya un valor de lista, Tcl_ListObjLength intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar la longitud de la lista.

El procedimiento Tcl_ListObjIndex devuelve un puntero al valor en el elemento index de la lista referenciada por listPtr. Devuelve este valor almacenando un puntero a él en la dirección objPtrPtr. Si listPtr no se refiere ya a un valor de lista, Tcl_ListObjIndex intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. Si el índice está fuera de rango, es decir, index es negativo o mayor o igual que el número de elementos de la lista, Tcl_ListObjIndex almacena un NULL en objPtrPtr y devuelve TCL_OK. De lo contrario, devuelve TCL_OK después de almacenar el puntero al valor del elemento. El contador de referencias para el elemento de la lista no se incrementa; el llamante debe hacerlo si necesita conservar un puntero al elemento.

Tcl_ListObjReplace reemplaza cero o más elementos de la lista referenciada por listPtr con los objc valores del array referenciado por objv. Si listPtr no apunta a un valor de lista, Tcl_ListObjReplace intentará convertirlo en uno; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el valor de resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de reemplazar los valores. Si objv es NULL, no se añaden nuevos elementos. Si el argumento first es cero o negativo, se refiere al primer elemento. Tcl_ListObjReplace(3) — Tcl

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(
    Tcl_Interp *interp,
    Tcl_Obj *listPtr,
    int first,
    int count,
    int objc,
    Tcl_Obj *const *objv
);

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_Obj *listPtr
Pointer to the list object whose elements are to be replaced. Must be a list object.
int first
Index of the first element to be replaced. Negative values are supported, indicating an offset from the end of the list.
int count
Number of elements to delete. If count is zero or negative, no elements are deleted, and the new elements are inserted at index first. If count is positive, then count elements are deleted starting at index first. If count is greater than the number of elements remaining in the list starting at index first, then all elements from first to the end of the list are deleted.
int objc
Number of new elements to insert. If objc is zero then no elements are inserted.
Tcl_Obj *const *objv
Array of pointers to the new elements to insert. If objc is zero, then objv is ignored.

DESCRIPTION

This procedure modifies the list object referenced by listPtr by deleting count elements starting at index first and then inserting objc new elements from the array objv at that same location. If the list object does not currently have internal list representation then it will be created. After the modification the list object's internal list representation will be updated. If the list object had a string representation it will be invalidated.

The index first is an integer. If first is negative then it is interpreted as an offset from the end of the list, i.e., an index of -1 refers to the last element.

If count is zero or negative then no elements are deleted; the new elements given by objv are simply inserted before the element currently at index first. If first is equal to the number of elements in the list, the new elements are appended to the list.

If objc is zero then no elements are inserted. This can be used to delete elements from a list. For example, to delete 3 elements starting at index 5, one would call:

result = Tcl_ListObjReplace(interp, listPtr, 5, 3, 0, NULL);

If count is less than or equal to zero and objc is greater than zero, then the elements are inserted without deleting any elements. If first is equal to the current length of the list, then the new elements are appended to the list.

If objc is greater than zero and count is less than or equal to zero, the new elements are inserted without deleting any elements. The new elements are inserted just before the element originally at index first. If first is equal to the current number of elements in the list, the new elements are appended to the list.

If count is greater than or equal to zero and objc is greater than zero, then count elements are deleted starting at index first, and then objc elements are inserted at that position. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

If count is greater than or equal to the number of elements remaining in the list starting at index first, then all elements from first to the end of the list are deleted. If objc is zero, then no elements are added.

If count is greater than or equal to the current number of elements in the list, and objc is zero, then the list is emptied. If count is greater than or equal to the number of elements remaining in the list starting at index first and objc is zero, then all elements from first to the end of the list are deleted.

If objc is greater than zero and count is less than or equal to zero, then the new elements are inserted without deleting any elements. If first is equal to the current length of the list, then the new elements are appended to the list.

If count is negative or zero, then the elements are simply inserted. If first is beyond the end of the list, it is treated as the end of the list. The listPtr's old string representation is invalidated. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

Because Tcl_ListObjReplace combines both element insertion and deletion, it can be used to implement a number of list operations. For example, the following code inserts the objc values referenced by the array of value pointers objv just before the element index of the list referenced by listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

Similarly, the following code appends the objc values referenced by the array objv to the end of the list listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

The count list elements starting at first can be deleted by simply calling Tcl_ListObjReplace with a NULL objvPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
