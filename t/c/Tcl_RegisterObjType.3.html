Tcl_ObjType(3) Procedimientos de la biblioteca Tcl Tcl_ObjType(3)

NOMBRE

Tcl_RegisterObjType, Tcl_GetObjType, Tcl_AppendAllObjTypes, Tcl_ConvertToType - manipular tipos de valor Tcl

SINOPSIS

#include <tcl.h>

Tcl_RegisterObjType(typePtr)

const Tcl_ObjType *
Tcl_GetObjType(typeName)

int
Tcl_AppendAllObjTypes(interp, objPtr)

int
Tcl_ConvertToType(interp, objPtr, typePtr)

ARGUMENTOS

const Tcl_ObjType *typePtr (entrada)
Punta a la estructura que contiene información sobre el tipo de valor Tcl. Este almacenamiento debe vivir para siempre, típicamente siendo asignado estáticamente.
const char *typeName (entrada)
El nombre de un tipo de valor Tcl que Tcl_GetObjType debe buscar.
Tcl_Interp *interp (entrada)
Intérprete a usar para reportar errores.
Tcl_Obj *objPtr (entrada)
Para Tcl_AppendAllObjTypes, esto apunta al valor al cual se añade el nombre de cada tipo de valor como un elemento de lista. Para Tcl_ConvertToType, esto apunta a un valor que debe haber sido el resultado de una llamada previa a Tcl_NewObj.

DESCRIPCIÓN

Los procedimientos en esta página del manual gestionan los tipos de valor Tcl (a veces denominados tipos de objeto o Tcl_ObjType por razones históricas). Se utilizan para registrar nuevos tipos de valor, buscar tipos y forzar conversiones de un tipo a otro.

Tcl_RegisterObjType registra un nuevo tipo de valor Tcl en la tabla de todos los tipos de valor que Tcl_GetObjType puede buscar por nombre. Hay otros tipos de valor soportados por Tcl también, que Tcl elige no registrar. Las extensiones pueden elegir registrar los tipos de valor que crean o no. El argumento typePtr apunta a una estructura Tcl_ObjType que describe el nuevo tipo dando su nombre y proporcionando punteros a cuatro procedimientos que implementan el tipo. Si la tabla de tipos ya contiene un tipo con el mismo nombre que en typePtr, este es reemplazado por el nuevo tipo. La estructura Tcl_ObjType se describe en la sección LA ESTRUCTURA TCL_OBJTYPE a continuación.

Tcl_GetObjType devuelve un puntero al Tcl_ObjType registrado con el nombre typeName. Devuelve NULL si no se registra ningún tipo con ese nombre.

Tcl_AppendAllObjTypes añade el nombre de cada tipo de valor registrado como un elemento de lista al valor Tcl referenciado por objPtr. El valor de retorno es TCL_OK a menos que haya un error al convertir objPtr a un valor de lista; en ese caso, se devuelve TCL_ERROR.

Tcl_ConvertToType convierte un valor de un tipo a otro si es posible. Crea una nueva representación interna para objPtr apropiada para el tipo de destino typePtr y establece su miembro typePtr según lo determinado llamando a la rutina typePtr->setFromAnyProc. Cualquier representación interna para el tipo antiguo de objPtr se libera. Si ocurre un error durante la conversión, devuelve TCL_ERROR y deja un mensaje de error en el valor resultante para interp a menos que interp sea NULL. De lo contrario, devuelve TCL_OK. Pasar un interp NULL permite usar este procedimiento como una prueba para ver si la conversión se puede hacer (y de hecho se hizo).

En muchos casos, la rutina typePtr->setFromAnyProc establecerá objPtr->typePtr al valor del argumento typePtr, pero eso ya no está garantizado. El setFromAnyProc es libre de establecer la representación interna para objPtr para utilizar otro Tcl_ObjType relacionado, si lo considera oportuno.

LA ESTRUCTURA TCL_OBJTYPE

Los escritores de extensiones pueden definir nuevos tipos de valor definiendo cuatro procedimientos e inicializando una estructura Tcl_ObjType para describir el tipo. Los escritores de extensiones también pueden pasar un puntero a su estructura Tcl_ObjType a Tcl_RegisterObjType si desean permitir que otras extensiones busquen su Tcl_ObjType por nombre con la rutina Tcl_GetObjType. La estructura Tcl_ObjType se define como sigue:

typedef struct Tcl_ObjType {
    const char *name;
    Tcl_FreeInternalRepProc *freeIntRepProc;
    Tcl_DupInternalRepProc *dupIntRepProc;
    Tcl_UpdateStringProc *updateStringProc;
    Tcl_SetFromAnyProc *setFromAnyProc;
} Tcl_ObjType;

EL CAMPO NAME

El miembro name describe el nombre del tipo, por ejemplo, int. Cuando se registra un tipo, este es el nombre utilizado por los llamadores de Tcl_GetObjType para buscar el tipo. Para tipos no registrados, el campo name es principalmente útil para la depuración. Los cuatro miembros restantes son punteros a procedimientos llamados por el código genérico de valor Tcl:

EL CAMPO SETFROMANYPROC

El miembro setFromAnyProc contiene la dirección de una función que se llama para crear una representación interna válida a partir de la representación de cadena de un valor.

typedef int Tcl_SetFromAnyProc(
        Tcl_Interp *interp,
        Tcl_Obj *objPtr);

Si no se puede crear una representación interna a partir de la cadena, devuelve TCL_ERROR y pone un mensaje que describe el error en el valor resultante para interp a menos que interp sea NULL. Si setFromAnyProc tiene éxito, almacena la nueva representación interna, establece el miembro typePtr de objPtr para que apunte a la estructura Tcl_ObjType correspondiente a la nueva representación interna y devuelve TCL_OK. Antes de establecer la nueva representación interna, el setFromAnyProc debe liberar cualquier representación interna del tipo antiguo de objPtr; lo hace llamando al freeIntRepProc del tipo antiguo si no es NULL.

Como ejemplo, el setFromAnyProc para el tipo de lista Tcl incorporado obtiene una representación de cadena actualizada para objPtr llamando a Tcl_GetStringFromObj. Analiza la cadena para verificar que está en un formato de lista válido y para obtener cada valor elemento de la lista, y, si esto tiene éxito, almacena los elementos de la lista en la representación interna de objPtr y establece el miembro typePtr de objPtr para que apunte a la estructura Tcl_ObjType del tipo de lista.

No libere la representación interna antigua de objPtr a menos que la reemplace con una nueva o restablezca el miembro typePtr a NULL.

El miembro setFromAnyProc puede establecerse en NULL, si las rutinas que utilizan la representación interna no necesitan derivar esa representación interna de un valor de cadena arbitrario. Sin embargo, en este caso, pasar un puntero al tipo a Tcl_ConvertToType provocará un error, por lo que para evitar esta posibilidad, el tipo no debe registrarse.

EL CAMPO UPDATESTRINGPROC

El miembro updateStringProc contiene la dirección de una función que se llama para crear una representación de cadena válida a partir de la representación interna de un valor.

typedef void Tcl_UpdateStringProc(
        Tcl_Obj *objPtr);

El miembro bytes de objPtr siempre es NULL cuando se llama. Siempre debe establecer bytes en no NULL antes de devolver. Requerimos que el array de bytes de la representación de cadena tenga un nulo después del último byte, en el desplazamiento length, y que no tenga bytes nulos antes de eso; esto permite que las representaciones de cadena se traten como cadenas C convencionales terminadas en nulo. Estas restricciones se cumplen fácilmente utilizando la codificación interna UTF de Tcl para la representación de cadena, igual que se haría para otras rutinas Tcl que aceptan valores de cadena como argumentos. El almacenamiento para el array de bytes debe ser asignado en el heap por Tcl_Alloc o ckalloc. Tenga en cuenta que los updateStringProc deben asignar suficiente espacio para los bytes de la cadena y el byte nulo de terminación.

El updateStringProc para el tipo double incorporado de Tcl, por ejemplo, llama a Tcl_PrintDouble para escribir en un buffer de tamaño TCL_DOUBLE_SPACE, luego asigna y copia la representación de cadena a espacio justo suficiente para contenerla. Un puntero al espacio asignado se almacena en el miembro bytes.

El miembro updateStringProc puede establecerse en NULL, si las rutinas que utilizan la representación interna están escritas de manera que la representación de cadena nunca se invalida. Fallar

NOMBRE

TCL_REGISTER_OBJTYPE

SINOPSIS

TCL_REGISTER_OBJTYPE( objtype )

ARGUMENTOS

objtype - Una estructura Tcl_ObjType que describe el tipo de valor.

DESCRIPCIÓN

La función Tcl_RegisterObjType registra un nuevo tipo de valor con el intérprete Tcl. Asocia la estructura objtype con el tipo de valor y proporciona un mecanismo para que otras partes del intérprete Tcl determinen el tipo de un valor.

LA ESTRUCTURA TCL_OBJTYPE

La estructura Tcl_ObjType contiene la información necesaria para determinar el tipo de un valor. Incluye el identificador del type, la cadena name, la función dupIntRepProc, la función freeIntRepProc y otras funciones relacionadas.

typedef struct Tcl_ObjType {
    int type;
    char *name;
    Tcl_DupInternalRepProc *dupIntRepProc;
    Tcl_FreeInternalRepProc *freeIntRepProc;
    Tcl_ObjType *next;
} Tcl_ObjType;

El campo type identifica el tipo de valor. El campo name es una cadena que describe el tipo, como "integer", "list" o "string". Los campos dupIntRepProc y freeIntRepProc son punteros a funciones que manejan la copia y la liberación de la representación interna de un valor.
