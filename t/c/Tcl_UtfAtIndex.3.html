DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como una cantidad de tamaño fijo y sin signo. Un carácter UTF-8 es un carácter Unicode representado como una secuencia de longitud variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 multibyte consta de un byte de liderazgo seguido de un número de bytes de seguimiento.

TCL_UTF_MAX es el número máximo de bytes que se tarda en representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 a partir de buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 comenzando en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamador debe asegurarse de que el búfer de origen sea lo suficientemente largo como para que esta rutina no se salga del final y dereference memoria inexistente o aleatoria; si se sabe que el búfer de origen está terminado en nulo, esto no ocurrirá. Si la entrada no está en formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada a UTF-8, almacenando el resultado en un Tcl_DString previamente inicializado. Debe especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada a Unicode, almacenando el resultado en el Tcl_DString previamente inicializado. En el argumento length, puede especificar la longitud de la cadena UTF-8 dada en bytes o “-1”, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString. La cadena Unicode está terminada con un carácter nulo Unicode.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en nulo y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en nulo y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres de longitud. Tcl_UniCharNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente. Tcl_UniCharNcasecmp es la versión insensible a mayúsculas/minúsculas de Unicode.

Tcl_UniCharCaseMatch es el equivalente Unicode a Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en nulo, un patrón Unicode y un valor booleano que especifica si la coincidencia debe ser sensible a mayúsculas/minúsculas y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en nulo y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres de longitud). Tcl_UtfNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas/minúsculas al comparar caracteres mayúsculas, minúsculas o de título.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 fuente src de length bytes es lo suficientemente larga como para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté formada correctamente. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars que están representados por la cadena UTF-8 src. La longitud de la cadena fuente es de length bytes. Si la longitud es negativa, se utilizan todos los bytes hasta el primer byte nulo.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfNext corresponde a strchr para cadenas UTF-8. Devuelve un puntero al siguiente carácter Tcl_UniChar en la cadena UTF-8 src. Se asume que src apunta a un carácter UTF-8 válido y no al terminador nulo. El valor devuelto apunta al byte que sigue inmediatamente al carácter UTF-8.

Tcl_UtfPrev corresponde a strrchr para cadenas UTF-8. Devuelve un puntero al carácter Tcl_UniChar anterior en la cadena UTF-8. Se asume que src apunta a un carácter UTF-8 válido y no al terminador nulo. El valor devuelto apunta al primer byte del carácter UTF-8 anterior.

Tcl_UniCharAtIndex devuelve el Tcl_UniChar en el índice dado index en la cadena Unicode dada src. Los índices comienzan en 0. Si index es negativo o mayor o igual que el número de caracteres Unicode en la cadena, se devuelve un carácter nulo (U+0000).

Tcl_UtfAtIndex devuelve un puntero al primer byte del carácter Tcl_UniChar en el índice dado index en la cadena UTF-8 dada src. Los índices comienzan en 0. Si index es negativo o mayor o igual que el número de caracteres Unicode en la cadena, se devuelve un puntero a la cadena terminadora nula.

Tcl_UtfBackslash analiza una secuencia de barra invertida comenzando en src. Si se encuentra una secuencia de barra invertida válida, se almacena la representación de un solo carácter Unicode de esa secuencia en el búfer dst (que debe ser de al menos TCL_UTF_MAX bytes de tamaño) y se devuelve el número de bytes consumidos de src. Si readPtr no es NULL, se rellena con este número. Si no se encuentra una secuencia de barra invertida, el primer byte de src se copia a dst, y se devuelve 1. Si src es un carácter que no requiere una barra invertida (por ejemplo, 'a'), ese carácter se copia a dst y se devuelve 1. El procesamiento de secuencias de barra invertida incluye caracteres especiales como \n, \r, \t, \b, \f, \v, \a, \0, y también secuencias para representar números octales y hexadecimales, así como secuencias Unicode de la forma \uXXXX y \UXXXXXXXX. Tenga en cuenta que si la cadena de entrada no contiene un carácter de barra invertida, este procedimiento se comporta como Tcl_UtfToUniChar pero en el búfer de salida dado, y se leen 1 byte de la entrada. Si la cadena de entrada está vacía, se devuelve 0.

DESCRIPTION

These procedures provide various ways to convert between Tcl’s internal representation of Unicode characters (as 32-bit values) and UTF-8 encoded strings.

Tcl_UniCharToUtf converts a single Unicode character `ch’ to its UTF-8 representation, storing the result in the buffer `buf’. The buffer must be large enough to hold the result (at most TCL_UTF_MAX bytes). The return value is the number of bytes written to `buf’.

Tcl_UniCharToUTFLen returns the number of bytes required to store the UTF-8 representation of the Unicode character `ch’.

Tcl_UtfToUniChar converts a single UTF-8 character to a Unicode value. The character is pointed to by `src’. The return value is the Unicode value. `readLenPtr’ points to a location that will receive the number of bytes read from `src’ to form the character. Behavior is undefined if `src’ does not point to a valid UTF-8 character.

Tcl_UtfToUniCharLen returns the number of bytes used by the UTF-8 character starting at `src’.

Tcl_UniCharToUtfDString converts a string of Unicode characters `uniStr’ of length `uniLen’ to UTF-8 and appends it to the Tcl_DString `dstPtr’.

Tcl_UtfToUniCharDString converts a UTF-8 string `src’ of length `srcLen’ to Unicode and appends it to the Tcl_DString `dstPtr’.

Tcl_UtfCharComplete checks if the bytes given by `src’ and `len’ form one or more complete UTF-8 characters. It returns the number of bytes that form the complete characters, or 0 if no complete characters are found. If the string ends with an incomplete character, it returns the number of bytes processed before the incomplete character. This function is useful for handling fragments of UTF-8 strings that may be received over time.

Tcl_UtfNext returns a pointer to the first byte of the next UTF-8 character in the string `src’. The null terminator is considered part of the UTF-8 string.

Given `src’, a pointer to some location in a UTF-8 string, Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at `start’. If the UTF-8 string is made up entirely of complete and well-formed characters, and `src’ points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns `start’.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to `start’; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from `start’. When `src’ is greater than `start’, it always returns a pointer less than `src’ and greater than or equal to (`src` - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte `src[-1]’, or might include it if the right trail bytes are present at `src’ and greater. Tcl_UtfPrev never reads the byte `src[0]’ nor the byte `start[-1]’ nor the byte `src[-TCL_UTF_MAX-1]’.

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) `index’ in the UTF-8 string `src’. The source string must contain at least `index’ characters. Behavior is undefined if a negative `index’ is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) `index’ in the UTF-8 string `src’. The source string must contain at least `index’ characters. This is equivalent to calling Tcl_UniCharToUniChar `index’ times. If a negative `index’ is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer `dstPtr’. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies `*readPtr’ to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
