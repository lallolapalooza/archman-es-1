Tcl_UpVar(3)

Paquete: tcl

Licencias: TCL

Tcl_UpVar(3) Procedimientos de la biblioteca Tcl Tcl_UpVar(3)

NOMBRE

Tcl_UpVar, Tcl_UpVar2 - vincular una variable a otra

SINOPSIS

#include <tcl.h>

int
Tcl_UpVar(interp, nombreMarco, nombreFuente, nombreDestino, banderas)

int
Tcl_UpVar2(interp, nombreMarco, nombre1, nombre2, nombreDestino, banderas)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene las variables; también se utiliza para informar errores.
const char *nombreMarco (entrada)
Identifica el marco de la pila que contiene la variable fuente. Puede tener cualquiera de las formas aceptadas por el comando upvar, como #0 o 1.
const char *nombreFuente (entrada)
Nombre de la variable fuente, en el marco dado por nombreMarco. Puede referirse a una variable escalar o a una variable de matriz con un índice entre paréntesis.
const char *nombreDestino (entrada)
Nombre de la variable de destino, que se vinculará a la variable fuente para que las referencias a nombreDestino se dirijan a la otra variable. No debe existir actualmente excepto como variable vinculada mediante upvar.
int banderas (entrada)
Una de TCL_GLOBAL_ONLY, TCL_NAMESPACE_ONLY o 0; si es distinta de cero, entonces nombreDestino es una variable global o de espacio de nombres; de lo contrario, es local al procedimiento actual (o al espacio de nombres actual si no hay ningún procedimiento activo).
const char *nombre1 (entrada)
Primera parte del nombre de la variable fuente (nombre escalar o nombre de matriz sin índice).
const char *nombre2 (entrada)
Si la variable fuente es un elemento de una matriz, proporciona el índice del elemento. Para las variables fuente escalares, es NULL.

DESCRIPCIÓN

Tcl_UpVar y Tcl_UpVar2 proporcionan la misma funcionalidad que el comando upvar: crean un enlace desde una variable fuente a una variable de destino, de modo que las referencias al destino se transmiten de forma transparente a la fuente. El nombre de la variable fuente se puede especificar como una única cadena como xyx o a(24) (llamando a Tcl_UpVar) o en dos partes donde el nombre de la matriz se ha separado del nombre del elemento (llamando a Tcl_UpVar2). El nombre de la variable de destino se especifica en una única cadena; no puede ser un elemento de matriz.

Ambos procedimientos devuelven TCL_OK o TCL_ERROR, y dejan un mensaje de error en el resultado del intérprete si ocurre un error.

Al igual que con el comando upvar, la variable fuente no necesita existir; si existe, desvincularla más tarde no destruye el enlace. La variable de destino puede existir en el momento de la llamada, pero si es así, debe existir como una variable vinculada.
