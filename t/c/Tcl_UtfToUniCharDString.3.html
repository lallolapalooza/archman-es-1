DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como un entero fijo y de tamaño fijo. Una cadena UTF-8 es un carácter Unicode representado como una secuencia de bytes variable, de hasta TCL_UTF_MAX bytes. Una secuencia multibyte UTF-8 consiste en un byte de encabezado seguido de algunos bytes de cola.

TCL_UTF_MAX es el número máximo de bytes que se necesitan para representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 en el inicio de buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee una cadena UTF-8 en el inicio de src y la almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamador debe asegurarse de que el buffer de entrada sea lo suficientemente largo para que esta rutina no se salga del límite y no acceda a memoria no existente o aleatoria; si el buffer de entrada se sabe que está terminado en nulo, esto no ocurrirá. Si la entrada no está en formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada en UTF-8, almacenando el resultado en un Tcl_DString previamente inicializado. Debes especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El almacenamiento del valor de retorno se añade al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada en Unicode, almacenando el resultado en el Tcl_DString previamente inicializado. En el argumento length, puedes especificar la longitud de la cadena UTF-8 dada en bytes o -1, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El almacenamiento del valor de retorno se añade al final del Tcl_DString. La cadena Unicode se termina con un carácter Unicode nulo.

Tcl_UniCharLen es el equivalente a strlen para caracteres Unicode. Acepta una cadena terminada en nulo de caracteres Unicode y devuelve el número de caracteres Unicode (no de bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp son los equivalentes a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Ambos aceptan dos cadenas terminadas en nulo de caracteres Unicode y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres. Tcl_UniCharNcmp compara las dos cadenas carácter por carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente. Tcl_UniCharNcasecmp es la versión que no distingue entre mayúsculas y minúsculas de Tcl_UniCharNcmp.

Tcl_UniCharCaseMatch es el equivalente Unicode de Tcl_StringCaseMatch. Acepta una cadena terminada en nulo de caracteres Unicode, un patrón Unicode y un valor booleano que indica si la coincidencia debe distinguir entre mayúsculas y minúsculas, y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp es el equivalente a strncmp para cadenas UTF-8. Acepta dos cadenas terminadas en nulo de UTF-8 y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres.) Tcl_UtfNcmp compara las dos cadenas carácter por carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente.

Tcl_UtfNcasecmp es el equivalente a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias en mayúsculas/minúsculas al comparar caracteres en mayúsculas, minúsculas o titulares.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 src de length bytes es suficientemente larga para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté formada correctamente. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si un Tcl_UniChar ha sido completamente visto.

Tcl_NumUtfChars es el equivalente a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars representados por la cadena UTF-8 src. La longitud de la cadena de entrada es length bytes. Si la longitud es negativa, se usan todos los bytes hasta el primer carácter nulo.

Tcl_UtfFindFirst es el equivalente a strchr para cadenas UTF-8. Devuelve un puntero a la primera ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El carácter nulo se considera parte de la cadena UTF-8.

Tcl_UtfFindLast es el equivalente a strrchr para cadenas UTF-8. Devuelve un puntero a la última ocurrencia de ch en la cadena UTF-8 terminada en nulo src. El carácter nulo se considera parte de la cadena UTF-8.

DESCRIPTION

These procedures provide a way to convert between Tcl Unicode characters (represented as 32-bit integers) and UTF-8 strings. They are useful when you need to process strings that may contain characters outside the standard ASCII range.

Tcl_UniCharToUtfDString converts the Unicode string uniIn of length len into a UTF-8 string which is appended to the Tcl dynamic string dstPtr. The return value is the number of bytes written to dstPtr.

Tcl_UtfToUniCharDString converts the UTF-8 string src of length length into a Unicode string which is appended to the Tcl dynamic string dstPtr. If length is negative, the string is treated as null-terminated. The return value is the number of Unicode characters written to dstPtr.

Tcl_UtfToUniChar converts a single UTF-8 character at the location pointed to by srcPtr into a Tcl_UniChar. It returns the Tcl_UniChar value and advances *srcPtr to point to the next character in the UTF-8 string. The caller is responsible for ensuring that *srcPtr points to a valid UTF-8 character. If the character is not valid or complete, the behavior is undefined. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfToUniChar.

Tcl_UniCharAtIndex returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UtfCharComplete checks if the UTF-8 string src of length length contains at least one complete UTF-8 character. It returns a non-zero value if the string contains at least one complete character, and 0 otherwise. This is useful for determining if it is safe to call Tcl_UtfNext or Tcl_UtfToUniChar on a potentially incomplete string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
