NOMBRE

Tcl_WrongNumArgs - genera un mensaje de error estándar para un número incorrecto de argumentos

SINOPSIS

#include <tcl.h>

Tcl_WrongNumArgs(interp, objc, objv, message)

ARGUMENTOS

Tcl_Interp interp (entrada)
Intérprete en el que se informará del error: el mensaje de error se almacena en su valor de resultado.
int objc (entrada)
Número de argumentos iniciales de objv a incluir en el mensaje de error.
Tcl_Obj *const objv[] (entrada)
Argumentos del comando que recibió un número incorrecto de argumentos.
const char *message (entrada)
Información adicional del error a imprimir después de los argumentos iniciales de objv. Esto típicamente indica la sintaxis aceptable del comando. Este argumento puede ser NULL.

DESCRIPCIÓN

Tcl_WrongNumArgs es un procedimiento de utilidad que es invocado por los procedimientos de comando cuando descubren que han recibido un número incorrecto de argumentos. Tcl_WrongNumArgs genera un mensaje de error estándar y lo almacena en el valor de resultado de interp. El mensaje incluye los objc elementos iniciales de objv más message. Por ejemplo, si objv consiste en los valores foo y bar, objc es 1, y message es “fileName count”, entonces el valor del resultado de interp se establecerá en la siguiente cadena:

número incorrecto de argumentos: debería ser "foo fileName count"

Si objc es 2, el resultado se establecerá en la siguiente cadena:

número incorrecto de argumentos: debería ser "foo bar fileName count"

Objc suele ser 1, pero puede ser 2 o más para comandos como string y los comandos de widgets de Tk, que utilizan el primer argumento como subcomando.

Algunos de los valores en el array objv pueden ser abreviaturas de un subcomando. El comando Tcl_GetIndexFromObj convertirá el valor de cadena abreviada en un indexObject. Si ocurre un error en el análisis del subcomando, nos gustaría usar el nombre completo del subcomando en lugar de la abreviatura. Si el comando Tcl_WrongNumArgs encuentra algún indexObjects en el array objv, usará el nombre completo del subcomando en el mensaje de error en lugar del nombre abreviado que se pasó originalmente. Usando el ejemplo anterior, supongamos que bar es en realidad una abreviatura de barfly y el valor es ahora un indexObject porque se pasó a Tcl_GetIndexFromObj. En este caso, el mensaje de error sería:

número incorrecto de argumentos: debería ser "foo barfly fileName count"
