ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de diccionario, se deja un mensaje de error en el valor de resultado del intérprete, a menos que interp sea NULL.
Tcl_Obj *dictPtr (entrada/salida)
Puntero al valor del diccionario que se va a manipular. Si dictPtr aún no apunta a un valor de diccionario, se intentará convertirlo en uno.
Tcl_Obj *keyPtr (entrada)
Puntero a la clave del par clave/valor que se manipula dentro del valor del diccionario.
Tcl_Obj **keyPtrPtr (salida)
Puntero a una variable a la que se le asignará la clave de un par clave/valor. Puede ser NULL para indicar que el llamador no está interesado en la clave.
Tcl_Obj *valuePtr (entrada)
Puntero al valor del par clave/valor que se manipula dentro del valor del diccionario (o sub-valor, en el caso de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (salida)
Puntero a una variable a la que se le asignará el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, puede ser NULL para indicar que el llamador no está interesado en el valor.
int *sizePtr (salida)
Puntero a una variable a la que se le asignará el número de pares clave/valor contenidos en el diccionario.
Tcl_DictSearch *searchPtr (entrada/salida)
Puntero a la estructura que se utilizará para seguir el progreso en la enumeración de todos los pares clave/valor de un diccionario. El contenido de la estructura se inicializará mediante la llamada a Tcl_DictObjFirst. Si la enumeración debe terminarse antes de que se devuelvan todos los valores del diccionario, la estructura de búsqueda debe pasarse a Tcl_DictObjDone para permitir la liberación de los bloqueos internos.
int *donePtr (salida)
Puntero a una variable a la que se escribirá un valor distinto de cero cuando la enumeración de los pares clave/valor en un diccionario haya completado, y cero en caso contrario.
int keyc (entrada)
Indica el número de claves que se proporcionarán en la matriz keyv.
Tcl_Obj *const *keyv (entrada)
Matriz de keyc punteros a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList utilizarán para localizar el par clave/valor a manipular dentro de los sub-diccionarios del valor de diccionario principal que se les pasa.

DESCRIPCIÓN

Los valores de diccionario de Tcl tienen una representación interna que admite un mapeo eficiente de claves a valores y que garantiza que el orden particular de las claves dentro del diccionario permanece el mismo módulo las claves que se eliminan (lo que las elimina del orden) o se agregan (lo que las agrega al final del orden). Si se reinterpretan como una lista, los valores en los índices con valores pares en la lista serán las claves del diccionario, y cada uno será seguido (en el índice de valor impar) por el valor asociado con esa clave.

Los procedimientos descritos en esta página del manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde código C.

Tcl_NewDictObj crea un nuevo valor de diccionario vacío. La representación de cadena del valor será inválida y el recuento de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario dado y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o NULL si la clave no tiene un mapeo dentro del diccionario. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir en un diccionario.

Tcl_DictObjPut actualiza el diccionario dado para que la clave dada mapee al valor dado; cada clave puede existir como máximo una vez en cualquier diccionario particular. El diccionario no debe ser compartido, pero la clave y el valor sí pueden serlo. Este procedimiento puede aumentar el recuento de referencias de la clave y el valor si resulta necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir en un diccionario.

Tcl_DictObjRemove actualiza el diccionario dado para que la clave dada no tenga mapeo a ningún valor. El diccionario no debe ser compartido, pero la clave sí puede serlo. La clave realmente almacenada en el diccionario tendrá su recuento de referencias decrementado si estaba presente. No es un error si la clave no existía previamente. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir en un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario dado. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no se puede convertir en un diccionario.

Tcl_DictObjFirst inicia una iteración sobre todos los pares clave/valor en el diccionario dado, colocando la clave y el valor en las variables apuntadas por los argumentos keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que el llamador no está interesado en la clave o el valor respectivamente.) El siguiente par clave/valor en el diccionario se puede recuperar con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modificarán el procesamiento de la iteración a menos que el diccionario no esté compartido, lo que activará la terminación prematura de la iteración en su lugar (lo que los scripts de Tcl no pueden activar a través del comando dict.) El argumento searchPtr apunta a una pieza de contexto que se utiliza para identificar qué iteración particular se está realizando y se inicializa mediante la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero si hay más pares clave/valor para iterar, o a un valor distinto de cero si la iteración está completa. El orden de iteración está definido por la implementación. Si el argumento dictPtr no se puede convertir en un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y de lo contrario devuelve TCL_OK.

Cuando se llama a Tcl_DictObjFirst en un diccionario, se coloca un bloqueo en el diccionario para permitir que ese diccionario se itere de forma segura sin tener en cuenta si el diccionario se modifica durante la iteración. Debido a esto, una vez que la iteración sobre las claves de un diccionario ha finalizado (ya sea porque se han iterado todos los valores, como lo indica el establecimiento a uno de la variable indicada por el argumento donePtr, o porque no se requieren más valores), la función Tcl_DictObjDone debe llamarse con el mismo searchPtr que se pasó a Tcl_DictObjFirst para que los bloqueos internos puedan liberarse. Una vez que un searchPtr particular se pasa a Tcl_DictObjDone, pasarlo a Tcl_DictObjNext (sin inicializarlo primero con Tcl_DictObjFirst) dará como resultado que no se produzcan valores y que la variable apuntada por donePtr se establezca en uno. Es seguro llamar a Tcl_DictObjDone varias veces en el mismo searchPtr por cada llamada a Tcl_DictObjFirst.

Los procedimientos Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son análogos cercanos a Tcl_DictObjPut y Tcl_DictObjRemove respectivamente, excepto que en lugar de trabajar con un solo diccionario, están diseñados para operar en un árbol anidado de diccionarios, con diccionarios internos almacenados como valores dentro de diccionarios externos. Los argumentos keyc y keyv especifican una lista de claves (con las claves más externas primero) que actúa como ruta al par clave/valor a afectar. ARGUMENTS

Tcl_Interp *interp (in)
Interpreter to use for error reporting. If null, no error reporting is done.
Tcl_Obj *dictPtr (in)
The dictionary object to operate on. Must be of type TCL_LINK_REV. If not, an error is returned.
Tcl_Obj *keyPtr (in)
A pointer to the object to be used as a key. The internal representation of the key object is copied. It is safe to modify the original key object after this call.
Tcl_Obj **valuePtrPtr (out)
If non-NULL, points to a location where a pointer to the value object is written. This value object is owned by the dictionary object, and its reference count is not incremented. If the value object needs to be retained, its reference count must be incremented explicitly. It is safe to modify the value object only if it is not shared with other dictionary objects.
Tcl_Obj *valuePtr (in)
A pointer to the object to be stored as the value. The internal representation of the value object is copied. It is safe to modify the original value object after this call.
Tcl_Obj **resultPtrPtr (out)
If non-NULL, points to a location where a pointer to a new dictionary object containing the keys is written. This result object is newly created and must be disposed of by the caller using Tcl_DecrRefCount.
Tcl_DictSearch *searchPtr (inout)
Pointer to a Tcl_DictSearch structure. This structure must have been initialized by a call to Tcl_DictObjFirst. The structure stores the state of the iteration.
Tcl_Obj *keys (in)
A list-like object containing the keys to operate on. The object may contain multiple keys, which are interpreted as a sequence of dictionary keys. For example, a key sequence of {a b c} can be used to refer to the value associated with the key path a.b.c.

DESCRIPTION

These are the low-level functions for manipulating dictionary objects. A dictionary object is a Tcl object whose internal representation is a hash table mapping keys to values. Keys and values are themselves Tcl objects.

Tcl_DictObjSize returns the number of key-value pairs in the dictionary object dictPtr. If dictPtr is not a dictionary object, or if interp is not null and an error occurs, an error is returned and the interpreter's result is set to an error message. Otherwise, the number of elements is returned as an integer.

Tcl_DictObjGet retrieves the value associated with the key specified by keyPtr from the dictionary object dictPtr. The value is returned via valuePtrPtr. If the key is not found in the dictionary, valuePtrPtr is set to NULL and TCL_OK is returned. If an error occurs, TCL_ERROR is returned.

Tcl_DictObjPut inserts or updates the key-value pair specified by keyPtr and valuePtr into the dictionary object dictPtr. If the key already exists, its value is updated. If the key does not exist, a new key-value pair is created. If an error occurs, TCL_ERROR is returned, otherwise TCL_OK is returned.

Tcl_DictObjGetKeys returns a new dictionary object containing all the keys in the dictionary object dictPtr. The caller is responsible for disposing of this new object using Tcl_DecrRefCount.

Tcl_DictObjNextKey is part of the dictionary iteration interface. It is used in conjunction with Tcl_DictObjFirst and Tcl_DictObjDone to iterate over the keys in a dictionary. searchPtr points to a Tcl_DictSearch structure initialized by Tcl_DictObjFirst. This call retrieves the next key in the iteration, via keyPtrPtr, and sets the boolean done to true if there are no more keys. If an error occurs, TCL_ERROR is returned.

Tcl_DictObjAppendKeyList is used to append a value to a list associated with a potentially nested key. The keys are specified by the list object keys. If intermediate dictionaries do not exist, they are created. If the final key exists, the value is appended to the list associated with that key. If the final key does not exist, a new list is created with the value and associated with the final key. If the value associated with the final key is not a list, it is converted into a list with the new value appended.

Tcl_DictObjRemoveKeyList removes the key-value pair specified by the key list keys from the dictionary object dictPtr. All non-terminal keys must exist and have dictionaries as their values. If an error occurs, TCL_ERROR is returned, otherwise TCL_OK is returned.

Tcl_DictObjPutKeyList is used to put a value associated with a potentially nested key. The keys are specified by the list object keys. If intermediate dictionaries do not exist, they are created. If the final key exists, its value is updated. If the final key does not exist, a new key-value pair is created. This function is useful for setting values in nested dictionaries, as the path is easy to construct from repeated use of Tcl_DictObjGet. With Tcl_DictObjPutKeyList, nested dictionaries are created for non-terminal keys where they do not already exist. With Tcl_DictObjRemoveKeyList, all non-terminal keys must exist and have dictionaries as their values.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters.  This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used.  The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
