Tcl_SetByteArrayObj(3)

Paquete: tcl

Licencias: TCL

Tcl_ByteArrayObj(3) Procedimientos de la biblioteca Tcl Tcl_ByteArrayObj(3)

NOMBRE

Tcl_NewByteArrayObj, Tcl_SetByteArrayObj, Tcl_GetByteArrayFromObj, Tcl_SetByteArrayLength - manipulan valores de Tcl como arreglos de bytes

SINOPSIS

#include <tcl.h>

Tcl_Obj *
Tcl_NewByteArrayObj(bytes, length)

void
Tcl_SetByteArrayObj(objPtr, bytes, length)

unsigned char *
Tcl_GetByteArrayFromObj(objPtr, lengthPtr)

unsigned char *
Tcl_SetByteArrayLength(objPtr, length)

ARGUMENTOS

const unsigned char *bytes (entrada)
El arreglo de bytes utilizado para inicializar o establecer un valor de arreglo de bytes. Puede ser NULL incluso si length es distinto de cero.
int length (entrada)
La longitud del arreglo de bytes. Debe ser >= 0.
Tcl_Obj *objPtr (entrada/salida)
Para Tcl_SetByteArrayObj, esto apunta al valor que se convertirá al tipo arreglo de bytes. Para Tcl_GetByteArrayFromObj y Tcl_SetByteArrayLength, esto apunta al valor del cual obtener el valor de arreglo de bytes; si objPtr no apunta ya a un valor de arreglo de bytes, se convertirá a uno.
int *lengthPtr (salida)
Si no es NULL, se rellena con la longitud del arreglo de bytes en el valor.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar y leer valores de arreglo de bytes de Tcl desde código C. Los valores de arreglo de bytes se utilizan típicamente para almacenar los resultados de operaciones de E/S binaria o estructuras de datos creadas con el comando binary. En Tcl, un arreglo de bytes no es equivalente a una cadena. Conceptualmente, una cadena es un arreglo de caracteres Unicode, mientras que un arreglo de bytes es un arreglo de cantidades de 8 bits sin significado implícito. Se proporcionan funciones accesoras para obtener la representación en cadena de un arreglo de bytes o para convertir un valor arbitrario en un arreglo de bytes. La obtención de la representación en cadena de un valor de arreglo de bytes (llamando a Tcl_GetStringFromObj) produce una secuencia UTF-8 correctamente formada con una correspondencia uno a uno entre los bytes en la representación interna y los caracteres UTF-8 en la representación en cadena.

Tcl_NewByteArrayObj y Tcl_SetByteArrayObj crearán un nuevo valor de tipo arreglo de bytes o modificarán un valor existente para que tenga el tipo arreglo de bytes. Ambos procedimientos establecen el tipo del valor a arreglo de bytes y establecen la representación interna del valor a una copia del arreglo de bytes proporcionado por bytes. Tcl_NewByteArrayObj devuelve un puntero a un valor recién asignado con un contador de referencias cero. Tcl_SetByteArrayObj invalida cualquier representación de cadena antigua y, si el valor no es ya un valor de arreglo de bytes, libera cualquier representación interna antigua. Si bytes es NULL, el nuevo arreglo de bytes contiene valores arbitrarios.

Tcl_GetByteArrayFromObj convierte un valor de Tcl a tipo arreglo de bytes y devuelve un puntero a la nueva representación interna del valor como un arreglo de bytes. La longitud de este arreglo se almacena en lengthPtr si lengthPtr no es NULL. El almacenamiento para el arreglo de bytes es propiedad del valor y no debe ser liberado. El contenido del arreglo puede ser modificado por el llamador solo si el valor no se comparte y el llamador invalida la representación en cadena.

Tcl_SetByteArrayLength convierte el valor de Tcl a tipo arreglo de bytes y cambia la longitud de la representación interna del valor como un arreglo de bytes. Si length es mayor que el espacio actualmente asignado para el arreglo, el arreglo se reasigna a la nueva longitud; los bytes recién asignados al final del arreglo tienen valores arbitrarios. Si length es menor que el espacio actualmente asignado para el arreglo, la longitud del arreglo se reduce a la nueva longitud. El valor de retorno es un puntero al nuevo arreglo de bytes del valor.
