Tcl_ListObjAppendList(3)

Paquete: tcl

Licencias: TCL

Tcl_ListObj(3) Procedimientos de la biblioteca Tcl Tcl_ListObj(3)

NOMBRE

Tcl_ListObjAppendList, Tcl_ListObjAppendElement, Tcl_NewListObj, Tcl_SetListObj, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_ListObjIndex, Tcl_ListObjReplace - manipular valores de Tcl como listas

SINAPSIS

#include <tcl.h>

int
Tcl_ListObjAppendList(interp, listPtr, elemListPtr)

int
Tcl_ListObjAppendElement(interp, listPtr, objPtr)

Tcl_Obj *
Tcl_NewListObj(objc, objv)

Tcl_SetListObj(objPtr, objc, objv)

int
Tcl_ListObjGetElements(interp, listPtr, objcPtr, objvPtr)

int
Tcl_ListObjLength(interp, listPtr, lengthPtr)

int
Tcl_ListObjIndex(interp, listPtr, index, objPtrPtr)

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de lista, se deja un mensaje de error en el resultado del intérprete a menos que interp sea NULL.
Tcl_Obj *listPtr (entrada/salida)
Puntero al valor de lista que se va a manipular. Si listPtr no apunta ya a un valor de lista, se intentará convertirlo.
Tcl_Obj *elemListPtr (entrada/salida)
Para Tcl_ListObjAppendList, apunta a un valor de lista que contiene elementos para agregar a listPtr. Cada elemento de *elemListPtr se convertirá en un nuevo elemento de listPtr. Si *elemListPtr no es NULL y no apunta ya a un valor de lista, se intentará convertirlo. Si ocurre un error durante la conversión, ambos procedimientos devuelven TCL_ERROR y dejan un mensaje de error en el resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió a un valor de lista, liberan cualquier representación interna antigua. De manera similar, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si lo convierte a un valor de lista. Después de agregar cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento ya que listPtr también lo refiere. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no ocurre ningún error, los dos procedimientos devuelven TCL_OK después de agregar los valores.
Tcl_Obj *objPtr (entrada)
Para Tcl_ListObjAppendElement, apunta al valor de Tcl que se agregará a listPtr. Para Tcl_SetListObj, apunta al valor de Tcl que se convertirá en un valor de lista que contiene los objc elementos de la matriz referenciada por objv.
int *objcPtr (entrada)
Puntero a la ubicación donde Tcl_ListObjGetElements almacena el número de valores de elemento en listPtr.
Tcl_Obj ***objvPtr (salida)
Una ubicación donde Tcl_ListObjGetElements almacena un puntero a una matriz de punteros a los valores de los elementos de listPtr.
int objc (entrada)
El número de valores de Tcl que Tcl_NewListObj insertará en un nuevo valor de lista, y Tcl_ListObjReplace insertará en listPtr. Para Tcl_SetListObj, el número de valores de Tcl para insertar en objPtr.
Tcl_Obj *const objv[] (entrada)
Una matriz de punteros a valores. Tcl_NewListObj insertará estos valores en un nuevo valor de lista y Tcl_ListObjReplace los insertará en un listPtr existente. Cada valor se convertirá en un elemento de lista separado.
int *lengthPtr (salida)
Puntero a la ubicación donde Tcl_ListObjLength almacena la longitud de la lista.
int index (entrada)
Índice del elemento de lista que Tcl_ListObjIndex debe devolver. El primer elemento tiene el índice 0.
Tcl_Obj **objPtrPtr (salida)
Puntero al lugar donde Tcl_ListObjIndex debe almacenar un puntero al valor del elemento de lista resultante.
int first (entrada)
Índice del elemento de lista inicial que Tcl_ListObjReplace debe reemplazar. El primer elemento de la lista tiene el índice 0.
int count (entrada)
El número de elementos que Tcl_ListObjReplace debe reemplazar.

DESCRIPCIÓN

Los valores de lista de Tcl tienen una representación interna que admite la indexación y la adición eficientes. Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar y agregar valores de lista de Tcl desde código C.

Tcl_ListObjAppendList y Tcl_ListObjAppendElement agregan uno o más valores al final del valor de lista referenciado por listPtr. Tcl_ListObjAppendList agrega cada elemento del valor de lista referenciado por elemListPtr mientras que Tcl_ListObjAppendElement agrega el único valor referenciado por objPtr. Ambos procedimientos convertirán el valor referenciado por listPtr a un valor de lista si es necesario. Si ocurre un error durante la conversión, ambos procedimientos devuelven TCL_ERROR y dejan un mensaje de error en el resultado del intérprete si interp no es NULL. De manera similar, si elemListPtr no se refiere ya a un valor de lista, Tcl_ListObjAppendList intentará convertirlo a uno y, si ocurre un error durante la conversión, devolverá TCL_ERROR y dejará un mensaje de error en el resultado del intérprete si interp no es NULL. Ambos procedimientos invalidan cualquier representación de cadena antigua de listPtr y, si se convirtió a un valor de lista, liberan cualquier representación interna antigua. De manera similar, Tcl_ListObjAppendList libera cualquier representación interna antigua de elemListPtr si lo convierte a un valor de lista. Después de agregar cada elemento en elemListPtr, Tcl_ListObjAppendList incrementa el contador de referencias del elemento ya que listPtr también lo refiere. Por la misma razón, Tcl_ListObjAppendElement incrementa el contador de referencias de objPtr. Si no ocurre ningún error, los dos procedimientos devuelven TCL_OK después de agregar los valores.

Tcl_NewListObj y Tcl_SetListObj crean un nuevo valor o modifican un valor existente para contener los objc elementos de la matriz referenciada por objv, donde cada elemento es un puntero a un valor de Tcl. Si objc es menor o igual a cero, devuelven un valor vacío. Si objv es NULL, la lista resultante contiene 0 elementos, con espacio reservado en una representación interna para objc elementos más (para evitar su reasignación posterior). La representación de cadena del nuevo valor se deja inválida. Los dos procedimientos incrementan los contadores de referencias de los elementos en objc, ya que el valor de lista ahora se refiere a ellos. El nuevo valor de lista devuelto por Tcl_NewListObj tiene un contador de referencias cero.

Tcl_ListObjGetElements devuelve un recuento y un puntero a una matriz de los elementos de un valor de lista. Devuelve el recuento almacenándolo en la dirección objcPtr. De manera similar, devuelve el puntero de la matriz almacenándolo en la dirección objvPtr. La memoria apuntada es administrada por Tcl y no debe ser liberada ni escrita por el llamador. Si la lista está vacía, se almacena 0 en objcPtr y NULL en objvPtr. Si listPtr no es ya un valor de lista, Tcl_ListObjGetElements intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar el recuento y el puntero de la matriz.

Tcl_ListObjLength devuelve el número de elementos en el valor de lista referenciado por listPtr. Devuelve este recuento almacenando un entero en la dirección lengthPtr. Si el valor no es ya un valor de lista, Tcl_ListObjLength intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de almacenar la longitud de la lista.

El procedimiento Tcl_ListObjIndex devuelve un puntero al valor en el elemento index de la lista referenciada por listPtr. Devuelve este valor almacenando un puntero a él en la dirección objPtrPtr. Si listPtr no se refiere ya a un valor de lista, Tcl_ListObjIndex intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. Si el índice está fuera de rango, es decir, index es negativo o mayor o igual al número de elementos en la lista, Tcl_ListObjIndex almacena un NULL en objPtrPtr y devuelve TCL_OK. De lo contrario, devuelve TCL_OK después de almacenar el puntero del valor del elemento. El contador de referencias del elemento de lista no se incrementa; el llamador debe hacerlo si necesita conservar un puntero al elemento.

Tcl_ListObjReplace reemplaza cero o más elementos de la lista referenciada por listPtr con los objc valores de la matriz referenciada por objv. Si listPtr no apunta a un valor de lista, Tcl_ListObjReplace intentará convertirlo; si la conversión falla, devuelve TCL_ERROR y deja un mensaje de error en el resultado del intérprete si interp no es NULL. De lo contrario, devuelve TCL_OK después de reemplazar los valores. Si objv es NULL, no se agregan nuevos elementos. Si el argumento first es cero o negativo, se refiere al primer elemento. Si first es mayor o igual al número de elementos en la lista, el nuevo elemento se agrega al final de la lista. Si el argumento count es cero o negativo, no se elimina ningún elemento.

NOMBRE

Tcl_ListObjReplace - reemplaza un rango de elementos en una lista

SINOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(interp, listPtr, first, count, objc, objv)
    Tcl_Interp *interp;
    Tcl_Obj *listPtr;
    int first;
    int count;
    int objc;
    Tcl_Obj *const objv[];

ARGUMENTOS

Tcl_Interp *interp
Intérprete a utilizar para reportar errores.
Tcl_Obj *listPtr
El objeto lista que será modificado.
int first
El índice del primer elemento a reemplazar o insertar antes. Si es negativo, se tratará como 0. Si es mayor o igual a la longitud de la lista, los nuevos elementos se añadirán al final. Si es 0, los nuevos elementos se insertarán al principio de la lista.
int count
El número de elementos a eliminar de la lista, comenzando en el índice first. Si count es cero o negativo, no se eliminarán elementos, y los nuevos elementos se insertarán antes del elemento designado por first. Si count es mayor que el número de elementos restantes en la lista desde first, se eliminarán todos los elementos restantes.
int objc
El número de elementos en la matriz objv. Si es cero, no se añadirán elementos.
Tcl_Obj *const objv[]
Una matriz de punteros a objetos Tcl que se insertarán en la lista. Si objv es NULL y objc es cero, no se insertan nuevos elementos. El contenido de objv se copia a la lista; los recuentos de referencia se ajustan apropiadamente.

DESCRIPCIÓN

Tcl_ListObjReplace reemplaza un rango de elementos en la lista especificada por listPtr con los elementos dados en objv. La operación puede insertar, eliminar o reemplazar elementos, dependiendo de los valores de first y count.

Si count es positivo, se eliminarán count elementos de la lista comenzando en el índice first. Si objc es positivo, los objc elementos de objv se insertarán en la lista en la posición first. El resultado es que los elementos originales de la lista que estaban en o después del índice first son desplazados para dar cabida a los nuevos elementos.

Si count es cero o negativo, no se eliminan elementos; los nuevos elementos se insertan simplemente antes del elemento designado por first. Esto es útil para insertar elementos sin eliminar ninguno.

Si objc es cero, no se insertan nuevos elementos. Si count es positivo en este caso, la operación simplemente elimina count elementos de la lista comenzando en el índice first.

Si count es positivo y objc también lo es, la operación reemplaza los count elementos comenzando en el índice first con los objc elementos de objv. Si objc es menor que count, la lista se acortará. Si objc es mayor que count, la lista se alargará.

Si first es mayor o igual a la longitud actual de la lista, los nuevos elementos se añadirán al final de la lista, independientemente del valor de count. Si count es cero o negativo en este caso, no se eliminan elementos y los nuevos elementos se añaden al final.

Si first es negativo, se trata como 0, insertando los nuevos elementos al principio de la lista y eliminando los count primeros elementos.

Tcl_ListObjReplace invalida la representación de cadena anterior de listPtr. Los recuentos de referencia de cualquier elemento insertado desde objv se incrementan ya que la lista resultante hace referencia a ellos. De manera similar, se decrementan los recuentos de referencia para cualquier valor reemplazado.

Dado que Tcl_ListObjReplace combina tanto la inserción como la eliminación de elementos, se puede utilizar para implementar una serie de operaciones de lista. Por ejemplo, el siguiente código inserta los valores objc referenciados por la matriz de punteros de valor objv justo antes del elemento index de la lista referenciada por listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

De manera similar, el siguiente código añade los valores objc referenciados por la matriz objv al final de la lista listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

Los count elementos de la lista que comienzan en first pueden eliminarse simplemente llamando a Tcl_ListObjReplace con un objvPtr NULL:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
