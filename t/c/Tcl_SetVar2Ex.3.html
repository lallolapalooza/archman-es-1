ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene la variable.
const char *name1 (entrada)
Contiene el nombre de una variable de matriz (si name2 no es NULL) o (si name2 es NULL) el nombre de una variable escalar o un nombre completo que incluye tanto el nombre de la variable como el índice. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular.
const char *name2 (entrada)
Si no es NULL, proporciona el nombre del elemento dentro de la matriz; en este caso, name1 debe hacer referencia a una variable de matriz.
Tcl_Obj *newValuePtr (entrada)
Punta a un valor Tcl que contiene el nuevo valor para la variable.
int flags (entrada)
Combinación OR de bits que proporcionan información adicional. Vea abajo para los valores válidos.
const char *varName (entrada)
Nombre de la variable. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de una matriz.
const char *newValue (entrada)
Nuevo valor para la variable, especificado como una cadena terminada en nulo. Se almacena una copia de este valor en la variable.
Tcl_Obj *part1Ptr (entrada)
Punta a un valor Tcl que contiene el nombre de la variable. El nombre puede incluir una serie de calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de una variable de matriz.
Tcl_Obj *part2Ptr (entrada)
Si no es NULL, apunta a un valor que contiene el nombre de un elemento dentro de una matriz y part1Ptr debe hacer referencia a una variable de matriz.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar, leer y eliminar variables Tcl desde código C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 y Tcl_ObjSetVar2 crearán una nueva variable o modificarán una existente. Estos procedimientos establecen la variable dada al valor proporcionado por newValuePtr o newValue y devuelven un puntero al nuevo valor de la variable, que se almacena en la estructura de variables de Tcl. Tcl_SetVar2Ex y Tcl_ObjSetVar2 toman el nuevo valor como un Tcl_Obj y devuelven un puntero a un Tcl_Obj. Tcl_SetVar y Tcl_SetVar2 toman el nuevo valor como una cadena y devuelven una cadena; generalmente son menos eficientes que Tcl_ObjSetVar2. Tenga en cuenta que el valor de retorno puede ser diferente del argumento newValuePtr o newValue, debido a las modificaciones realizadas por los rastreadores de escritura. Si ocurre un error al establecer la variable (por ejemplo, se hace referencia a una variable de matriz sin proporcionar un índice a la matriz), se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de indicador TCL_LEAVE_ERR_MSG está activado.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 y Tcl_ObjGetVar2 devuelven el valor actual de una variable. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos descritos anteriormente. En circunstancias normales, el valor de retorno es un puntero al valor de la variable. Para Tcl_GetVar2Ex y Tcl_ObjGetVar2, el valor se devuelve como un puntero a un Tcl_Obj. Para Tcl_GetVar y Tcl_GetVar2, el valor se devuelve como una cadena; esto generalmente es menos eficiente, por lo que se prefieren Tcl_GetVar2Ex o Tcl_ObjGetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de matriz para una variable escalar), se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de indicador TCL_LEAVE_ERR_MSG está activado.

Tcl_UnsetVar y Tcl_UnsetVar2 se pueden usar para eliminar una variable, de modo que los intentos futuros de leer la variable devuelvan un error. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos anteriores. Si la variable se elimina correctamente, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si el bit de indicador TCL_LEAVE_ERR_MSG está activado. Si se especifica un elemento de matriz, se elimina el elemento dado pero la matriz permanece. Si se especifica un nombre de matriz sin índice, se elimina toda la matriz.

El nombre de una variable puede especificarse a estos procedimientos de cuatro maneras:

[1]
Si se invoca Tcl_SetVar, Tcl_GetVar o Tcl_UnsetVar, el nombre de la variable se proporciona como una sola cadena, varName. Si varName contiene un paréntesis de apertura y termina con un paréntesis de cierre, entonces el valor entre los paréntesis se trata como un índice (que puede tener cualquier valor de cadena) y los caracteres antes del primer paréntesis de apertura se tratan como el nombre de una variable de matriz. Si varName no tiene paréntesis como se describe anteriormente, entonces toda la cadena se trata como el nombre de una variable escalar.
[2]
Si se proporcionan los argumentos name1 y name2 y name2 no es NULL, entonces se especifica un elemento de matriz y el nombre de la matriz y el índice ya han sido separados por el llamador: name1 contiene el nombre y name2 contiene el índice. Se genera un error si name1 contiene un paréntesis de apertura y termina con un paréntesis de cierre (elemento de matriz) y name2 no es NULL.
[3]
Si name2 es NULL, name1 se trata de manera similar a varName en el caso [1] anterior (puede ser el nombre de una variable escalar o un elemento de matriz).

El argumento flags se puede usar para especificar cualquiera de varias opciones a los procedimientos. Consiste en una combinación OR de los siguientes bits.

TCL_GLOBAL_ONLY
En circunstancias normales, los procedimientos buscan variables de la siguiente manera. Si una llamada a procedimiento está activa en interp, la variable se busca en el nivel actual de llamada a procedimiento. De lo contrario, la variable se busca primero en el espacio de nombres actual, luego en el espacio de nombres global. Sin embargo, si este bit está activado en flags, la variable se busca solo en el espacio de nombres global, incluso si hay una llamada a procedimiento activa. Si se proporcionan tanto TCL_GLOBAL_ONLY como TCL_NAMESPACE_ONLY, se ignora TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
Si este bit está activado en flags, la variable se busca solo en el espacio de nombres actual; si hay un procedimiento activo, sus variables se ignoran, y el espacio de nombres global también se ignora a menos que sea el espacio de nombres actual.
TCL_LEAVE_ERR_MSG
Si se devuelve un error y este bit está activado en flags, se dejará un mensaje de error en el resultado del intérprete, donde se puede recuperar con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de indicador no está activado, no se dejará ningún mensaje de error y el resultado del intérprete no se modificará.
TCL_APPEND_VALUE
Si este bit está activado, entonces newValuePtr o newValue se agregan al valor actual en lugar de reemplazarlo. Si la variable no está definida actualmente, el bit se ignora. Este bit solo lo usan los procedimientos Tcl_Set*.
TCL_LIST_ELEMENT
Si este bit está activado, entonces newValue se convierte en un elemento de lista Tcl válido antes de establecer (o agregar a) la variable. Se agrega un espacio separador antes del nuevo

NAME

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_GetVar2, Tcl_GetVar, Tcl_UnsetVar2, Tcl_UnsetVar – manipulate Tcl variables

SYNOPSIS

#include <tcl.h>

int
Tcl_SetVar2Ex(interp, name1, name2, valuePtr, flags)
Tcl_Obj *Tcl_SetVar(interp, name, value, flags)
int
Tcl_GetVar2(interp, name1, name2, flags)
Tcl_Obj *Tcl_GetVar(interp, name, flags)
int
Tcl_UnsetVar2(interp, name1, name2, flags)
Tcl_UnsetVar(interp, name, flags)

ARGUMENTS

Tcl_Interp *interp
Tcl interpreter.
const char *name1
Name of the variable. If name2 is NULL, then this is the full variable name. Otherwise, it is the name of an array variable.
const char *name2
Index of the array element, or NULL. If not NULL, then the variable is treated as an array element named name1(name2).
Tcl_Obj *valuePtr
New value for the variable, represented as a Tcl object.
const char *value
New value for the variable, as a C string. Ignored if valuePtr is non-NULL. The string is converted to a Tcl object.
int flags
Bit-field, may be any of
TCL_GLOBAL_ONLY
Use only global scope for the variable.
TCL_LEAVE_ERR_MSG
If an error occurs, leave the error message in the interpreter's result. If not set, the error message is discarded.
TCL_APPEND_VALUE
Append valuePtr or value to the existing value of the variable. If valuePtr or value represents a list, it is appended as a new list element.
TCL_LIST_ELEMENT
Append valuePtr or value as a new element to the list value of the variable. This is similar to TCL_APPEND_VALUE, but requires the variable to already contain a list. The new element is added after the last element of the list, unless the list element itself is a list. If the list element is itself a list, it is appended as a single element.

DESCRIPTION

These procedures provide C-level access to Tcl variables. They allow a Tcl extension to read, write, and unset Tcl variables within a Tcl interpreter.

Tcl_SetVar2Ex and Tcl_SetVar are used to set the value of a Tcl variable. The variable is specified by name1 and name2. If name2 is NULL, the variable is treated as a scalar variable named name1. If name2 is not NULL, then the variable is treated as an element of an array named name1, with index name2. The new value is specified by valuePtr if it is non-NULL, otherwise it is specified by the C string value. The string value is converted into a Tcl object. The flags argument controls how the variable is set and may be specified as the bitwise OR of any of the following values:

TCL_GLOBAL_ONLY
This flag indicates that the variable should be set in the global scope, even if the call is executed within a procedure.
TCL_LEAVE_ERR_MSG
If this flag is set, error messages resulting from the variable setting operation (e.g., trying to set an array element for a scalar variable) will be left in the interpreter's result.
TCL_APPEND_VALUE
This flag causes the new value to be appended to the existing value of the variable. If the existing value is not a list, the new value is converted to a list with the old and new values as elements. If the existing value is a list, the new value is appended as a new element to the list. If the new value is also a list, its elements are appended as separate elements to the existing list.
TCL_LIST_ELEMENT
This flag is similar to TCL_APPEND_VALUE, but it requires the variable to already contain a list. If the variable's value is not a list, an error occurs. The new value is appended as a single element to the end of the list. If the new value is itself a list, it is appended as a single element, not expanded into its components.

If the variable does not exist, it is created. If the operation is successful, Tcl_SetVar2Ex returns TCL_OK. If an error occurs and TCL_LEAVE_ERR_MSG was specified, the error message is left in the interpreter's result and the return value is TCL_ERROR. If an error occurs and TCL_LEAVE_ERR_MSG was not specified, the return value is TCL_ERROR and the interpreter's result is cleared.

Tcl_SetVar is a simplified version of Tcl_SetVar2Ex that takes the variable name as a single string and the value as a C string. It implicitly converts the C string value to a Tcl object.

When using the TCL_LIST_ELEMENT flag, the new value is appended as a list element unless the list element is going to be the first element in a list or sublist (i.e. the variable's current value is empty, or contains the single character “{”, or ends in “ }”). When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.

Tcl_GetVar and Tcl_GetVar2 return the current value of a variable. The arguments to these procedures are treated in the same way as the arguments to Tcl_SetVar and Tcl_SetVar2. Under normal circumstances, the return value is a pointer to the variable's value (which is stored in Tcl's variable structure and will not change before the next call to Tcl_SetVar or Tcl_SetVar2). Tcl_GetVar and Tcl_GetVar2 use the flag bits TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG, both of which have the same meaning as for Tcl_SetVar. If an error occurs in reading the variable (e.g. the variable does not exist or an array element is specified for a scalar variable), then NULL is returned.

Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a variable, so that future calls to Tcl_GetVar or Tcl_GetVar2 for the variable will return an error. The arguments to these procedures are treated in the same way as the arguments to Tcl_GetVar and Tcl_GetVar2. If the variable is successfully removed then TCL_OK is returned. If the variable cannot be removed because it does not exist then TCL_ERROR is returned. If an array element is specified, the given element is removed but the array remains. If an array name is specified without an index, then the entire array is removed.
