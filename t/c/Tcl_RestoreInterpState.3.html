Tcl_RestoreInterpState(3)

Paquete: tcl

Licencias: TCL

Tcl_SaveResult(3) Procedimientos de la biblioteca Tcl Tcl_SaveResult(3)

NOMBRE

Tcl_SaveInterpState, Tcl_RestoreInterpState, Tcl_DiscardInterpState, Tcl_SaveResult, Tcl_RestoreResult, Tcl_DiscardResult - guardar y restaurar el estado de un intérprete

SINOPSIS

#include <tcl.h>

Tcl_InterpState
Tcl_SaveInterpState(interp, status)

int
Tcl_RestoreInterpState(interp, state)

Tcl_DiscardInterpState(state)

Tcl_SaveResult(interp, savedPtr)

Tcl_RestoreResult(interp, savedPtr)

Tcl_DiscardResult(savedPtr)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete para el cual se debe guardar el estado.
int status (entrada)
Valor de código de retorno para guardar como parte del estado del intérprete.
Tcl_InterpState state (entrada)
Token de estado guardado que se restaurará o descartará.
Tcl_SavedResult *savedPtr (entrada)
Puntero a la ubicación donde se debe guardar o restaurar el resultado del intérprete.

DESCRIPCIÓN

Estas rutinas permiten que un procedimiento C tome una instantánea del estado actual de un intérprete para que pueda restaurarse después de una llamada a Tcl_Eval o alguna otra rutina que modifique el estado del intérprete. Hay dos tríos de rutinas que están destinadas a trabajar juntas.

El primer trío almacena la instantánea del estado del intérprete en un token opaco devuelto por Tcl_SaveInterpState. Ese valor de token puede ser pasado de nuevo a Tcl_RestoreInterpState o Tcl_DiscardInterpState, dependiendo de si el estado del intérprete va a ser restaurado. Mientras una de las últimas dos rutinas sea llamada, Tcl se encargará de la gestión de la memoria.

El segundo trío almacena la instantánea solo del resultado del intérprete (no de su estado completo) en memoria asignada por el llamador. A estas rutinas se les pasa un puntero a Tcl_SavedResult que se utiliza para almacenar suficiente información para restaurar el resultado del intérprete. Tcl_SavedResult puede ser asignado en la pila del procedimiento llamador. Estas rutinas no guardan el estado de ninguna información de error en el intérprete (por ejemplo, las opciones de retorno -errorcode o -errorinfo, cuando un error está en curso).

Dado que las rutinas Tcl_SaveInterpState, Tcl_RestoreInterpState y Tcl_DiscardInterpState realizan un superconjunto de las funciones proporcionadas por las otras rutinas, cualquier código nuevo solo debe utilizar las rutinas más potentes. Las rutinas más antiguas y menos potentes Tcl_SaveResult, Tcl_RestoreResult y Tcl_DiscardResult existen solo para la conveniencia de los programas existentes que puedan estar usándolas ya.

Tcl_SaveInterpState toma una instantánea de aquellas porciones del estado del intérprete que componen el resultado completo de la evaluación de scripts. Esto incluye el resultado del intérprete, el código de retorno (pasado como argumento status, y cualquier opción de retorno, incluyendo -errorinfo y -errorcode cuando un error está en curso. Esta instantánea se devuelve como un token opaco de tipo Tcl_InterpState. La llamada a Tcl_SaveInterpState no modifica el estado del intérprete. A diferencia de Tcl_SaveResult, no reinicia el intérprete.

Tcl_RestoreInterpState acepta un token Tcl_InterpState devuelto previamente por Tcl_SaveInterpState y restaura el estado del intérprete al estado contenido en esa instantánea. El valor de retorno de Tcl_RestoreInterpState es el valor de estado pasado originalmente a Tcl_SaveInterpState cuando se creó el token de instantánea.

Tcl_DiscardInterpState se llama para liberar un token Tcl_InterpState devuelto previamente por Tcl_SaveInterpState cuando esa instantánea no debe ser restaurada en un intérprete.

El token Tcl_InterpState devuelto por Tcl_SaveInterpState debe ser eventualmente pasado a Tcl_RestoreInterpState o Tcl_DiscardInterpState para evitar una fuga de memoria. Una vez que el token Tcl_InterpState es pasado a uno de ellos, el token ya no es válido y no debe ser usado más.

Tcl_SaveResult mueve los resultados de cadena y valor de interp a la ubicación especificada por statePtr. Tcl_SaveResult borra el resultado para interp y deja el resultado en su estado normal de inicialización vacía.

Tcl_RestoreResult mueve los resultados de cadena y valor de statePtr de vuelta a interp. Cualquier resultado o error que ya estuviera en el intérprete será borrado. El statePtr queda en un estado no inicializado y no puede ser usado hasta otra llamada a Tcl_SaveResult.

Tcl_DiscardResult libera el estado del intérprete guardado almacenado en statePtr. La estructura de estado queda en un estado no inicializado y no puede ser usada hasta otra llamada a Tcl_SaveResult.

Una vez que se llama a Tcl_SaveResult para guardar el resultado del intérprete, se debe llamar a Tcl_RestoreResult o Tcl_DiscardResult para limpiar adecuadamente la memoria asociada con el estado guardado.
