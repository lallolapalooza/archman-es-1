NOMBRE

TCGETS, TCSETS, TCSETSW, TCSETSF, TCGETS2, TCSETS2, TCSETSW2, TCSETSF2, TCGETA, TCSETA, TCSETAW, TCSETAF - obtener y establecer atributos de terminal

DESCRIPCIÓN

TCGETS
Equivalente a tcgetattr(fd, argp).
Obtiene la configuración actual del puerto serie.
TCSETS
Equivalente a tcsetattr(fd, TCSANOW, argp).
Establece la configuración actual del puerto serie.
TCSETSW
Equivalente a tcsetattr(fd, TCSADRAIN, argp).
Permite que el búfer de salida se vacíe y establece la configuración actual del puerto serie.
TCSETSF
Equivalente a tcsetattr(fd, TCSAFLUSH, argp).
Permite que el búfer de salida se vacíe, descarta la entrada pendiente y establece la configuración actual del puerto serie.

Los siguientes cuatro ioctls son iguales a TCGETS, TCSETS, TCSETSW, TCSETSF, excepto que toman un struct termios2 * en lugar de un struct termios *. Si el miembro de la estructura c_cflag contiene la bandera BOTHER, entonces la velocidad en baudios se almacena en los miembros de la estructura c_ispeed y c_ospeed como valores enteros. Estos ioctls no son compatibles en todas las arquitecturas.

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ADVERTENCIAS

struct termios de <asm/termbits.h> es diferente e incompatible con struct termios de <termios.h>. Estas llamadas ioctl requieren struct termios de <asm/termbits.h>.

EJEMPLOS

Obtener o establecer una velocidad en baudios arbitraria en el puerto serie.

/* SPDX-License-Identifier: GPL-2.0-or-later */
#include <asm/termbits.h>
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
#if !defined BOTHER
    fprintf(stderr, "BOTHER no es compatible\n");
    /* El programa puede recurrir a TCGETS/TCSETS con constantes Bnnn */
    exit(EXIT_FAILURE);
#else
    /* Declarar la estructura tio, su tipo depende del ioctl soportado */
# if defined TCGETS2
    struct termios2 tio;
# else
    struct termios tio;
# endif
    int fd, rc;
    if (argc != 2 && argc != 3 && argc != 4) {
        fprintf(stderr, "Uso: %s dispositivo [salida [entrada] ]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_RDWR | O_NONBLOCK | O_NOCTTY);
    if (fd < 0) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /* Obtener la configuración actual del puerto serie a través del ioctl soportado */
# if defined TCGETS2
    rc = ioctl(fd, TCGETS2, &tio);
# else
    rc = ioctl(fd, TCGETS, &tio);
# endif
    if (rc) {
        perror("TCGETS");
        close(fd);
        exit(EXIT_FAILURE);
    }
    /* Cambiar la velocidad en baudios cuando se proporcionaron más argumentos */
    if (argc == 3 || argc == 4) {
        /* Limpiar la velocidad en baudios de salida actual y establecer un nuevo valor */
        tio.c_cflag &= ~CBAUD;
        tio.c_cflag |= BOTHER;
        tio.c_ospeed = atoi(argv[2]);
        /* Limpiar la velocidad en baudios de entrada actual y establecer un nuevo valor */
        tio.c_cflag &= ~(CBAUD << IBSHIFT);
        tio.c_cflag |= BOTHER << IBSHIFT;
        /* Cuando el 4to argumento no se proporciona, se reutiliza la velocidad en baudios de salida */
        tio.c_ispeed = (argc == 4) ? atoi(argv[3]) : atoi(argv[2]);
        /* Establecer la nueva configuración del puerto serie a través del ioctl soportado */
# if defined TCSETS2
        rc = ioctl(fd, TCSETS2, &tio);
# else
        rc = ioctl(fd, TCSETS, &tio);
# endif
        if (rc) {
            perror("TCSETS");
            close(fd);
            exit(EXIT_FAILURE);
        }
        /* Y obtener los nuevos valores que realmente se configuraron */
# if defined TCGETS2
        rc = ioctl(fd, TCGETS2, &tio);
# else
        rc = ioctl(fd, TCGETS, &tio);
# endif
        if (rc) {
            perror("TCGETS");
            close(fd);
            exit(EXIT_FAILURE);
        }
    }
    close(fd);
    printf("velocidad en baudios de salida: %u\n", tio.c_ospeed);
    printf("velocidad en baudios de entrada: %u\n", tio.c_ispeed);
    exit(EXIT_SUCCESS);
#endif
}

NOMBRE

tcsets, tcgetwinsize, tcsetwinsize - establecer y obtener el tamaño de la ventana de terminal

BIBLIOTECA

Curses library (libncurses)
Compatibilidad con POSIX

SINOPSIS

#include <curses.h>
#include <term.h>

int tcgetwinsize(const int fd, struct winsize *ws);
int tcsetwinsize(const int fd, const struct winsize *ws);
int tcgetwinsize(const int fd, struct winsize *ws);
int tcsetwinsize(const int fd, const struct winsize *ws);

DESCRIPCIÓN

Las funciones tcgetwinsize y tcsetwinsize se utilizan para obtener y establecer, respectivamente, la información sobre el tamaño de la ventana de terminal asociada con el descriptor de archivo fd. El tamaño de la ventana se almacena en una estructura winsize, definida en <termios.h>.

La estructura winsize tiene los siguientes campos:

struct winsize {
    unsigned short ws_row;    /* filas */
    unsigned short ws_col;    /* columnas */
    unsigned short ws_xpixel; /* píxeles horizontales (0 si no está definido) */
    unsigned short ws_ypixel; /* píxeles verticales (0 si no está definido) */
};

Para obtener el tamaño de la ventana, llame a tcgetwinsize con el descriptor de archivo de la terminal y un puntero a una estructura winsize. El sistema operativo rellenará la estructura con el número de filas, columnas y píxeles horizontales y verticales.

Para establecer el tamaño de la ventana, llame a tcsetwinsize con el descriptor de archivo de la terminal y un puntero a una estructura winsize que contenga los nuevos valores deseados. Si se establecen los píxeles a 0, el sistema operativo intentará determinar un tamaño apropiado en píxeles basado en la información de la terminal.

Si la terminal no admite la obtención o establecimiento de información de tamaño de ventana, estas funciones devolverán -1 y establecerán errno en ENOTTY.

VALOR DE RETORNO

En caso de éxito, tcgetwinsize y tcsetwinsize devuelven 0. En caso de error, devuelven -1 y establecen errno apropiadamente.

ERRORES

EBADF
El descriptor de archivo fd no es válido.
ENOTTY
El descriptor de archivo fd no está asociado con una terminal, o la terminal no admite la obtención o establecimiento de información de tamaño de ventana.

HISTORIA

Las funciones tcgetwinsize y tcsetwinsize aparecieron por primera vez en la biblioteca libcurses.

ADVERTENCIAS

El comportamiento de estas funciones puede variar dependiendo de la implementación específica de la biblioteca curses y del sistema operativo subyacente. Es posible que algunas terminales no admitan la obtención o establecimiento de información de tamaño de ventana.

EJEMPLOS

A continuación se muestra un ejemplo de cómo usar tcgetwinsize para obtener el tamaño de la ventana de terminal:


#include <curses.h>
#include <term.h>
#include <stdio.h>

int main() {
    struct winsize ws;
    int fd = 0; // Descriptor de archivo para la entrada estándar (terminal)

    if (tcgetwinsize(fd, &ws) == -1) {
        perror("tcgetwinsize");
        return 1;
    }

    printf("Tamaño de la ventana: %d filas, %d columnas\n", ws.ws_row, ws.ws_col);
    printf("Tamaño en píxeles: %d x %d\n", ws.ws_xpixel, ws.ws_ypixel);

    return 0;
}
