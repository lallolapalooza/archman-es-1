DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como una cantidad de tamaño fijo y sin signo. Un carácter UTF-8 es un carácter Unicode representado como una secuencia de longitud variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 multibyte consta de un byte de cabecera seguido de algunos bytes de seguimiento.

TCL_UTF_MAX es el número máximo de bytes que se tarda en representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 comenzando en buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 comenzando en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamador debe asegurarse de que el búfer de origen sea lo suficientemente largo como para que esta rutina no se salga del final y desreferencie memoria inexistente o aleatoria; si se sabe que el búfer de origen está terminado en nulo, esto no ocurrirá. Si la entrada no tiene el formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada a UTF-8, almacenando el resultado en un Tcl_DString inicializado previamente. Debe especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El espacio para el valor de retorno se añade al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada a Unicode, almacenando el resultado en el Tcl_DString inicializado previamente. En el argumento length, puede especificar la longitud de la cadena UTF-8 dada en bytes o “-1”, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El espacio para el valor de retorno se añade al final del Tcl_DString. La cadena Unicode se termina con un carácter nulo Unicode.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en nulo y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en nulo y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres de longitud. Tcl_UniCharNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente. Tcl_UniCharNcasecmp es la versión Unicode insensible a mayúsculas y minúsculas.

Tcl_UniCharCaseMatch es el equivalente Unicode a Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en nulo, un patrón Unicode y un valor booleano que especifica si la comparación debe ser sensible a mayúsculas y minúsculas, y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en nulo y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres de longitud). Tcl_UtfNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena, respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas/minúsculas al comparar caracteres en mayúscula, minúscula o de título.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 de origen src de length bytes es lo suficientemente larga como para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté formada correctamente. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars que están representados por la cadena UTF-8 src. La longitud de la cadena de origen es de length bytes. Si la longitud es negativa, se utilizan todos los bytes hasta el primer byte nulo.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera aparición del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última aparición del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfNext devuelve un puntero al siguiente carácter UTF-8 después de src. El resultado no está definido si src no apunta a un carácter UTF-8 válido. Esta rutina se utiliza para iterar a través de una cadena UTF-8.

Tcl_UtfPrev devuelve un puntero al carácter UTF-8 anterior a src. El argumento start apunta al inicio de la cadena UTF-8. El resultado no está definido si src no apunta a un carácter UTF-8 válido.

Tcl_UniCharAtIndex devuelve el Tcl_UniChar en el índice index de la cadena UTF-8 src. El índice se cuenta en caracteres Unicode, no en bytes.

Tcl_UtfAtIndex devuelve un puntero al inicio del carácter UTF-8 en el índice index de la cadena UTF-8 src. El índice se cuenta en caracteres Unicode, no en bytes.

Tcl_UtfBackslash interpreta una secuencia de barra invertida que comienza en src. El primer carácter de la secuencia es el carácter de barra invertida. La rutina determina el valor Unicode correspondiente de la secuencia y lo almacena como una cadena UTF-8 en *dst. El valor de retorno es el número de bytes almacenados en *dst. Si readPtr no es NULL, se rellena con el número de bytes consumidos de la entrada, incluido el carácter de barra invertida.

DESCRIPTION

These procedures provide facilities for converting between Tcl's internal Unicode representation (Tcl_UniChar) and the UTF-8 encoding used in strings.

Tcl_UniCharNcmp compares up to n Tcl_UniChar characters starting at ch1Ptr and ch2Ptr. It returns 0 if the characters are equal, a negative value if *ch1Ptr is less than *ch2Ptr, and a positive value if *ch1Ptr is greater than *ch2Ptr.

Tcl_UniCharNcasecmp is similar to Tcl_UniCharNcmp, but it performs a case-insensitive comparison.

Tcl_UniCharLen returns the number of Tcl_UniChar characters in the null-terminated Unicode string at chPtr.

Tcl_UniCharToUtf converts a single Tcl_UniChar character to its UTF-8 representation and stores it in utfBuffer. The return value is the number of bytes written to utfBuffer. utfBuffer must be at least TCL_UTF_MAX bytes long.

Tcl_UtfToUniChar converts a single UTF-8 character starting at utf to its Tcl_UniChar representation, which is stored in *chPtr. The return value is the number of bytes consumed from utf. This function can be used to step through a UTF-8 string character by character. If the character is incomplete or malformed, it is treated as a replacement character (U+FFFD).

Tcl_UniCharToUtfDString converts a sequence of Tcl_UniChar characters starting at chPtr into a UTF-8 representation stored in the Tcl_DString utfPtr. The return value is the number of bytes written to the Tcl_DString.

Tcl_UtfToUniCharDString converts a sequence of UTF-8 bytes starting at utf into a sequence of Tcl_UniChar characters stored in the Tcl_DString chPtr. The conversion stops after numBytes bytes have been processed or the end of the string is reached. The return value is the number of Tcl_UniChar characters written to the Tcl_DString.

Tcl_UniCharToEncoded converts a single Tcl_UniChar character to its representation in the specified encoding and stores it in buffer. The return value is the number of bytes written to buffer. The caller must ensure that buffer is large enough.

Tcl_EncodedToUniChar converts a single character from the specified encoding in buffer to its Tcl_UniChar representation, which is stored in *chPtr. The return value is the number of bytes consumed from buffer.

Tcl_UniCharToUtfChar converts a single Tcl_UniChar character to its UTF-8 representation and returns a pointer to that representation. The UTF-8 representation is stored in a static buffer internal to Tcl, so it is only valid until the next call to Tcl_UniCharToUtfChar or related functions. The return value is the number of bytes in the UTF-8 representation.

Tcl_UniCharToUtfCharDString is similar to Tcl_UniCharToUtfDString, but it converts a single Tcl_UniChar character to its UTF-8 representation and stores it in the Tcl_DString utfPtr.

Tcl_UtfNext returns a pointer to the next UTF-8 character in the string src. The null terminator is considered part of the UTF-8 string.

Given src, a pointer to some location in a UTF-8 string, Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
