ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene la variable.
const char *name1 (entrada)
Contiene el nombre de una variable de matriz (si name2 es no NULL) o (si name2 es NULL) ya sea el nombre de una variable escalar o un nombre completo que incluye tanto el nombre de la variable como el índice. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular.
const char *name2 (entrada)
Si no es NULL, proporciona el nombre del elemento dentro de la matriz; en este caso, name1 debe hacer referencia a una variable de matriz.
Tcl_Obj *newValuePtr (entrada)
Puntero a un valor Tcl que contiene el nuevo valor para la variable.
int flags (entrada)
Combinación OR de bits que proporcionan información adicional. Consulte a continuación para ver los valores válidos.
const char *varName (entrada)
Nombre de la variable. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede hacer referencia a una variable escalar o a un elemento de una matriz.
const char *newValue (entrada)
Nuevo valor para la variable, especificado como una cadena terminada en nulo. Se almacena una copia de este valor en la variable.
Tcl_Obj *part1Ptr (entrada)
Puntero a un valor Tcl que contiene el nombre de la variable. El nombre puede incluir una serie de calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede hacer referencia a una variable escalar o a un elemento de una variable de matriz.
Tcl_Obj *part2Ptr (entrada)
Si no es NULL, apunta a un valor que contiene el nombre de un elemento dentro de una matriz y part1Ptr debe hacer referencia a una variable de matriz.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar, leer y eliminar variables de Tcl desde código C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 y Tcl_ObjSetVar2 crearán una nueva variable o modificarán una existente. Estos procedimientos establecen la variable dada al valor proporcionado por newValuePtr o newValue y devuelven un puntero al nuevo valor de la variable, que se almacena en la estructura de variables de Tcl. Tcl_SetVar2Ex y Tcl_ObjSetVar2 toman el nuevo valor como un Tcl_Obj y devuelven un puntero a un Tcl_Obj. Tcl_SetVar y Tcl_SetVar2 toman el nuevo valor como una cadena y devuelven una cadena; generalmente son menos eficientes que Tcl_ObjSetVar2. Tenga en cuenta que el valor de retorno puede ser diferente del argumento newValuePtr o newValue, debido a modificaciones realizadas por trazas de escritura. Si ocurre un error al establecer la variable (por ejemplo, se hace referencia a una variable de matriz sin proporcionar un índice en la matriz), se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está activado.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 y Tcl_ObjGetVar2 devuelven el valor actual de una variable. Los argumentos de estos procedimientos se tratan de la misma manera que los argumentos de los procedimientos descritos anteriormente. En circunstancias normales, el valor de retorno es un puntero al valor de la variable. Para Tcl_GetVar2Ex y Tcl_ObjGetVar2, el valor se devuelve como un puntero a un Tcl_Obj. Para Tcl_GetVar y Tcl_GetVar2, el valor se devuelve como una cadena; esto suele ser menos eficiente, por lo que se prefieren Tcl_GetVar2Ex o Tcl_ObjGetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de matriz para una variable escalar), entonces se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está activado.

Tcl_UnsetVar y Tcl_UnsetVar2 se pueden utilizar para eliminar una variable, de modo que los intentos futuros de leer la variable devuelvan un error. Los argumentos de estos procedimientos se tratan de la misma manera que los argumentos de los procedimientos anteriores. Si la variable se elimina correctamente, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está activado. Si se especifica un elemento de matriz, se elimina el elemento dado pero la matriz permanece. Si se especifica el nombre de una matriz sin un índice, se elimina toda la matriz.

El nombre de una variable se puede especificar a estos procedimientos de cuatro maneras:

[1]
Si se invoca Tcl_SetVar, Tcl_GetVar o Tcl_UnsetVar, el nombre de la variable se proporciona como una sola cadena, varName. Si varName contiene un paréntesis abierto y termina con un paréntesis cerrado, entonces el valor entre los paréntesis se trata como un índice (que puede tener cualquier valor de cadena) y los caracteres antes del primer paréntesis abierto se tratan como el nombre de una variable de matriz. Si varName no tiene paréntesis como se describe anteriormente, entonces toda la cadena se trata como el nombre de una variable escalar.
[2]
Si se proporcionan los argumentos name1 y name2 y name2 no es NULL, entonces se especifica un elemento de matriz y el nombre de la matriz y el índice ya han sido separados por el llamador: name1 contiene el nombre y name2 contiene el índice. Se genera un error si name1 contiene un paréntesis abierto y termina con un paréntesis cerrado (elemento de matriz) y name2 no es NULL.
[3]
Si name2 es NULL, name1 se trata igual que varName en el caso [1] anterior (puede ser el nombre de una variable escalar o de un elemento de matriz).

El argumento flags se puede utilizar para especificar cualquiera de varias opciones a los procedimientos. Consiste en una combinación OR de los siguientes bits.

TCL_GLOBAL_ONLY
En circunstancias normales, los procedimientos buscan variables de la siguiente manera. Si una llamada a procedimiento está activa en interp, la variable se busca en el nivel actual de llamada de procedimiento. De lo contrario, la variable se busca primero en el espacio de nombres actual, luego en el espacio de nombres global. Sin embargo, si este bit está activado en flags, la variable se busca solo en el espacio de nombres global, incluso si hay una llamada de procedimiento activa. Si se proporcionan tanto TCL_GLOBAL_ONLY como TCL_NAMESPACE_ONLY, se ignora TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
Si este bit está activado en flags, la variable se busca solo en el espacio de nombres actual; si un procedimiento está activo, sus variables se ignoran, y el espacio de nombres global también se ignora a menos que sea el espacio de nombres actual.
TCL_LEAVE_ERR_MSG
Si se devuelve un error y este bit está activado en flags, se dejará un mensaje de error en el resultado del intérprete, donde se puede recuperar con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de bandera no está activado, no se deja ningún mensaje de error y el resultado del intérprete no se modificará.
TCL_APPEND_VALUE
Si este bit está activado, entonces newValuePtr o newValue se agrega al valor actual en lugar de reemplazarlo. Si la variable no está definida actualmente, entonces se ignora el bit. Este bit solo es utilizado por los procedimientos Tcl_Set*.
TCL_LIST_ELEMENT
Si este bit está activado, entonces newValue se convierte en un elemento de lista Tcl válido antes de establecer (o agregar a) la variable. Se agrega un espacio separador antes del nuevo

NOMBRE

Tcl_ObjSetVar2, Tcl_ObjSetVar

SINTAXIS

Tcl_ObjSetVar2(ObjPtr, Var, Value, Flags)
Tcl_ObjSetVar(ObjPtr, Var, Value)

ARGUMENTOS

ObjPtr
un puntero al objeto.
Var
el nombre de la variable.
Value
el valor a asignar.
Flags
flags para la operación.

DESCRIPCIÓN

Las funciones Tcl_ObjSetVar2 y Tcl_ObjSetVar establecen el valor de una variable dentro de un objeto Tcl. Los argumentos se manejan de manera similar a como lo haría el comando Tcl_ObjSetVar.

En circunstancias normales, estas funciones devuelven un puntero al valor de la variable. Este valor está almacenado en la estructura de variables de Tcl y no cambiará hasta la próxima llamada a Tcl_ObjSetVar o Tcl_ObjSetVar2.

Tcl_ObjSetVar2 utiliza los bits de flags TCL_GLOBAL_ONLY y TCL_LEAVE_ERR_MSG. Ambos tienen el mismo significado que en Tcl_ObjSetVar.

Si ocurre un error al intentar leer la variable (por ejemplo, si la variable no existe o se intenta especificar un elemento de array para una variable escalar), la función devolverá NULL.

Tcl_ObjSetVar2(ObjPtr, Var, Value, Flags) devuelve el valor actual de la variable. Los argumentos para estos procedimientos se tratan de la misma manera que los argumentos para Tcl_ObjSetVar. En circunstancias normales, el valor de retorno es un puntero al valor de la variable (que se almacena en la estructura de variables de Tcl y no cambiará antes de la próxima llamada a Tcl_ObjSetVar o Tcl_ObjSetVar2). Tcl_ObjSetVar2 utiliza los bits de flags TCL_GLOBAL_ONLY y TCL_LEAVE_ERR_MSG, ambos tienen el mismo significado que para Tcl_ObjSetVar. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de array para una variable escalar), se devuelve NULL.

Tcl_ObjSetVar(ObjPtr, Var, Value) devuelve el valor actual de la variable. Los argumentos para estos procedimientos se tratan de la misma manera que los argumentos para Tcl_ObjSetVar. En circunstancias normales, el valor de retorno es un puntero al valor de la variable (que se almacena en la estructura de variables de Tcl y no cambiará antes de la próxima llamada a Tcl_ObjSetVar o Tcl_ObjSetVar2). Tcl_ObjSetVar utiliza los bits de flags TCL_GLOBAL_ONLY y TCL_LEAVE_ERR_MSG, ambos tienen el mismo significado que para Tcl_ObjSetVar. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de array para una variable escalar), se devuelve NULL.
