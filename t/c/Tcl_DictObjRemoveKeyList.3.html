ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor a un valor de diccionario, se deja un mensaje de error en el resultado del intérprete a menos que interp sea NULL.
Tcl_Obj *dictPtr (entrada/salida)
Puntero al valor del diccionario que se va a manipular. Si dictPtr ya no apunta a un valor de diccionario, se intentará convertirlo a uno.
Tcl_Obj *keyPtr (entrada)
Puntero a la clave para el par clave/valor que se está manipulando dentro del valor del diccionario.
Tcl_Obj **keyPtrPtr (salida)
Puntero a una variable a la que se le colocará la clave de un par clave/valor. Puede ser NULL para indicar que el llamante no está interesado en la clave.
Tcl_Obj *valuePtr (entrada)
Puntero al valor para el par clave/valor que se está manipulando dentro del valor del diccionario (o sub-valor, en el caso de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (salida)
Puntero a una variable a la que se le colocará el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, esto puede ser NULL para indicar que el llamante no está interesado en el valor.
int *sizePtr (salida)
Puntero a una variable a la que se le colocará el número de pares clave/valor contenidos en el diccionario.
Tcl_DictSearch *searchPtr (entrada/salida)
Puntero al registro que se utilizará para seguir el progreso en la enumeración de todos los pares clave/valor en un diccionario. El contenido del registro será inicializado por la llamada a Tcl_DictObjFirst. Si la enumeración debe terminar antes de que se devuelvan todos los valores del diccionario, el registro de búsqueda *debe* pasarse a Tcl_DictObjDone para permitir la liberación de los bloqueos internos.
int *donePtr (salida)
Puntero a una variable a la que se escribirá un valor distinto de cero cuando haya finalizado la enumeración de los pares clave/valor en un diccionario, y cero en caso contrario.
int keyc (entrada)
Indica el número de claves que se proporcionarán en el array keyv.
Tcl_Obj *const *keyv (entrada)
Array de keyc punteros a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList utilizarán para localizar el par clave/valor a manipular dentro de los sub-diccionarios del valor del diccionario principal que se les pasa.

DESCRIPCIÓN

Los valores de diccionario de Tcl tienen una representación interna que soporta un mapeo eficiente de claves a valores y que garantiza que el orden particular de las claves dentro del diccionario permanece igual módulo cualquier clave que se elimine (lo que las elimina del orden) o se añada (lo que las añade al final del orden). Si se reinterpreta como una lista, los valores en los índices pares de la lista serán las claves del diccionario, y cada uno irá seguido (en el índice impar) por el valor asociado a esa clave.

Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde código C.

Tcl_NewDictObj crea un nuevo valor de diccionario vacío. La representación de cadena del valor será inválida y el contador de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario dado y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o un NULL si la clave no tiene mapeo dentro del diccionario. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede convertirse a un diccionario.

Tcl_DictObjPut actualiza el diccionario dado para que la clave dada mapee al valor dado; cualquier clave puede existir como máximo una vez en cualquier diccionario particular. El diccionario no debe ser compartido, pero la clave y el valor sí pueden serlo. Este procedimiento puede aumentar el contador de referencias de la clave y el valor si resulta necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede convertirse a un diccionario.

Tcl_DictObjRemove actualiza el diccionario dado para que la clave dada no tenga mapeo a ningún valor. El diccionario no debe ser compartido, pero la clave sí puede serlo. La clave realmente almacenada en el diccionario tendrá su contador de referencias decrementado si estaba presente. No es un error si la clave no existía previamente. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede convertirse a un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario dado. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede convertirse a un diccionario.

Tcl_DictObjFirst inicia una iteración sobre todos los pares clave/valor en el diccionario dado, colocando la clave y el valor en las variables apuntadas por los argumentos keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que el llamante no está interesado en la clave o el valor respectivamente.) El siguiente par clave/valor en el diccionario puede recuperarse con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modificarán el procesamiento de la iteración a menos que el diccionario no esté compartido, en cuyo caso esto activará una terminación prematura de la iteración en su lugar (que los scripts de Tcl no pueden activar a través del comando dict.) El argumento searchPtr apunta a una pieza de contexto que se utiliza para identificar qué iteración particular se está realizando, y se inicializa con la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero si hay más pares clave/valor para iterar, o distinto de cero si la iteración está completa. El orden de iteración está definido por la implementación. Si el argumento dictPtr no puede convertirse a un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y de lo contrario devuelve TCL_OK.

Cuando se llama a Tcl_DictObjFirst sobre un diccionario, se coloca un bloqueo en el diccionario para permitir que ese diccionario se itere de forma segura sin tener en cuenta si el diccionario se modifica durante la iteración. Debido a esto, una vez que la iteración sobre las claves de un diccionario ha terminado (ya sea porque se han iterado todos los valores como lo indica la variable apuntada por el argumento donePtr al establecerse en uno, o porque ya no se necesitan más valores) la función Tcl_DictObjDone debe ser llamada con el mismo searchPtr que se pasó a Tcl_DictObjFirst para que los bloqueos internos puedan ser liberados. Una vez que un searchPtr particular se pasa a Tcl_DictObjDone, pasarlo a Tcl_DictObjNext (sin inicializarlo primero con Tcl_DictObjFirst) resultará en que no se producirán valores y la variable apuntada por donePtr se establecerá en uno. Es seguro llamar a Tcl_DictObjDone múltiples veces en el mismo searchPtr para cada llamada a Tcl_DictObjFirst.

Los procedimientos Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son los análogos cercanos de Tcl_DictObjPut y Tcl_DictObjRemove respectivamente, excepto que en lugar de trabajar con un solo diccionario, están diseñados para operar en un árbol anidado de diccionarios, con diccionarios internos almacenados como valores dentro de diccionarios externos. Los argumentos keyc y keyv especifican una lista de claves (con las claves más externas primero) que actúa como ruta al par clave/valor a afectar. EJEMPLO

Usando la interfaz de iteración de diccionarios para buscar y determinar si existe una clave que se mapea a sí misma:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Supongamos que interp y objPtr son parámetros. Esta es la
 * forma idiomática de iniciar una iteración sobre el diccionario;
 * establece un bloqueo en la representación interna que garantiza
 * que no haya problemas de modificación concurrente cuando se utiliza
 * también la gestión normal del recuento de referencias. El bloqueo
 * se libera automáticamente cuando finaliza el bucle, pero debe
 * liberarse manualmente cuando se realiza una salida excepcional del bucle.
 * Sin embargo, es seguro intentar liberar el bloqueo
 * incluso si hemos terminado de iterar sobre el bucle.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Tenga en cuenta que strcmp() no es una buena forma de comparar
     * valores y se utiliza aquí solo a efectos de demostración.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
