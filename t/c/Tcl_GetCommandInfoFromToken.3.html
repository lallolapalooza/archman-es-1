ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que crear un nuevo comando o que contiene un comando.
const char *cmdName (entrada)
Nombre del comando.
Tcl_ObjCmdProc *proc (entrada)
Implementación del nuevo comando: se llamará a proc cada vez que se invoque cmdName como un comando.
ClientData clientData (entrada)
Valor arbitrario de una palabra para pasar a proc y deleteProc.
Tcl_CmdDeleteProc *deleteProc (entrada)
Procedimiento que se llamará antes de que cmdName sea eliminado del intérprete; permite la limpieza específica del comando. Si es NULL, no se llama a ningún procedimiento antes de eliminar el comando.
Tcl_Command token (entrada)
Token para el comando, devuelto por una llamada anterior a Tcl_CreateObjCommand. El comando no debe haber sido eliminado.
Tcl_CmdInfo *infoPtr (entrada/salida)
Puntero a la estructura que contiene diversa información sobre un comando de Tcl.
Tcl_Obj *objPtr (entrada)
Valor que contiene el nombre de un comando de Tcl.

DESCRIPCIÓN

Tcl_CreateObjCommand define un nuevo comando en interp y lo asocia con el procedimiento proc de tal manera que siempre que se invoque name como un comando de Tcl (por ejemplo, a través de una llamada a Tcl_EvalObjEx) el intérprete de Tcl llamará a proc para procesar el comando.

Tcl_CreateObjCommand elimina cualquier comando name existente ya asociado con el intérprete (sin embargo, ver abajo para una excepción donde el comando existente no se elimina). Devuelve un token que puede ser usado para referirse al comando en llamadas posteriores a Tcl_GetCommandName. Si name contiene algún calificador de espacio de nombres ::, entonces el comando se agrega al espacio de nombres especificado; de lo contrario, el comando se agrega al espacio de nombres global. Si se llama a Tcl_CreateObjCommand para un intérprete que está en proceso de ser eliminado, entonces no crea un nuevo comando y devuelve NULL. proc debe tener argumentos y resultado que coincidan con el tipo Tcl_ObjCmdProc:

typedef int Tcl_ObjCmdProc(
        ClientData clientData,
        Tcl_Interp *interp,
        int objc,
        Tcl_Obj *const objv[]);

Cuando se invoca proc, los parámetros clientData e interp serán copias de los argumentos clientData e interp pasados a Tcl_CreateObjCommand. Típicamente, clientData apunta a una estructura de datos específica de la aplicación que describe qué hacer cuando se invoca el procedimiento del comando. Objc y objv describen los argumentos del comando, objc da el número de valores de argumento (incluyendo el nombre del comando) y objv da los valores de los argumentos. El array objv contendrá objc valores, apuntando a los valores de los argumentos. A diferencia de argv[argv] utilizado en un procedimiento de comando basado en cadenas, objv[objc] no contendrá NULL.

Adicionalmente, cuando se invoca proc, no debe modificar los contenidos del array objv asignando nuevos valores de puntero a cualquier elemento del array (por ejemplo, objv[2] = NULL) porque esto causará pérdida de memoria y corrupción de la pila de ejecución. El `const` en la declaración de objv hará que los compiladores compatibles con ANSI informen dicho intento de asignación como un error. Sin embargo, es aceptable modificar la representación interna de cualquier valor de argumento individual. Por ejemplo, el usuario puede llamar a Tcl_GetIntFromObj en objv[2] para obtener la representación entera de ese valor; esa llamada puede cambiar el tipo del valor al que apunta objv[2], pero no cambiará a dónde apunta objv[2].

proc debe devolver un código entero que sea TCL_OK, TCL_ERROR, TCL_RETURN, TCL_BREAK, o TCL_CONTINUE. Consulte la página del manual de visión general de Tcl para obtener detalles sobre el significado de estos códigos. La mayoría de los comandos normales solo devolverán TCL_OK o TCL_ERROR. Además, si proc necesita devolver un resultado no vacío, puede llamar a Tcl_SetObjResult para establecer el resultado del intérprete. En el caso de un código de retorno TCL_OK, este da el resultado del comando, y en el caso de TCL_ERROR, este da un mensaje de error. Antes de invocar un procedimiento de comando, Tcl_EvalObjEx establece el resultado del intérprete para que apunte a un valor que representa una cadena vacía, por lo que los comandos simples pueden devolver un resultado vacío sin hacer nada en absoluto.

Los contenidos del array objv pertenecen a Tcl y no se garantiza que persistan una vez que proc devuelva: proc no debe modificarlos. Llame a Tcl_SetObjResult si desea devolver algo del array objv.

Normalmente, Tcl_CreateObjCommand elimina cualquier comando name existente asociado con el intérprete. Sin embargo, si el comando existente fue creado por una llamada anterior a Tcl_CreateCommand, Tcl_CreateObjCommand no elimina el comando sino que organiza para que el intérprete de Tcl llame al Tcl_ObjCmdProc proc en el futuro. El antiguo Tcl_CmdProc basado en cadenas asociado con el comando se conserva y su dirección puede obtenerse mediante llamadas posteriores a Tcl_GetCommandInfo. Esto se hace por compatibilidad con versiones anteriores.

DeleteProc será invocado cuando (si) name sea eliminado. Esto puede ocurrir a través de una llamada a Tcl_DeleteCommand, Tcl_DeleteCommandFromToken, o Tcl_DeleteInterp, o reemplazando name en otra llamada a Tcl_CreateObjCommand. DeleteProc se invoca antes de que se elimine el comando y brinda a la aplicación la oportunidad de liberar cualquier estructura asociada con el comando. DeleteProc debe tener argumentos y resultado que coincidan con el tipo Tcl_CmdDeleteProc:

typedef void Tcl_CmdDeleteProc(
        ClientData clientData);

El argumento clientData será el mismo que el argumento clientData pasado a Tcl_CreateObjCommand.

Tcl_DeleteCommand elimina un comando de un intérprete de comandos. Una vez completada la llamada, los intentos de invocar cmdName en interp resultarán en errores. Si cmdName no está enlazado como un comando en interp, entonces Tcl_DeleteCommand no hace nada y devuelve -1; de lo contrario, devuelve 0. No hay restricciones sobre cmdName: puede referirse a un comando incorporado, un comando específico de la aplicación o un procedimiento de Tcl. Si name contiene algún calificador de espacio de nombres ::, el comando se elimina del espacio de nombres especificado.

Dado un token devuelto por Tcl_CreateObjCommand, Tcl_DeleteCommandFromToken elimina el comando de un intérprete de comandos. Eliminará un comando incluso si ese comando ha sido renombrado. Una vez completada la llamada, los intentos de invocar el comando en interp resultarán en errores. Si el comando correspondiente a token ya ha sido eliminado de interp, entonces Tcl_DeleteCommand no hace nada y devuelve -1; de lo contrario, devuelve 0.

Tcl_GetCommandInfo comprueba si su argumento cmdName existe como un comando en interp. cmdName puede incluir calificadores de espacio de nombres :: para identificar un comando en un espacio de nombres particular. Si el comando no se encuentra, devuelve 0. De lo contrario, coloca información sobre el comando en la estructura Tcl_CmdInfo apuntada por infoPtr y devuelve 1. Una estructura Tcl_CmdInfo tiene los siguientes campos:

typedef struct Tcl_CmdInfo {
  Tcl_ObjCmdProc *objProcPtr;
  ClientData clientData;
  Tcl_CmdDeleteProc *deleteProcPtr;
  const char *cmdNamePtr;
}

Los campos son los siguientes:

objProcPtr
Puntero al procedimiento de comando del objeto para el comando. Este campo es NULL si el comando fue creado con Tcl_CreateCommand en lugar de Tcl_CreateObjCommand.
clientData
Datos del cliente pasados al crear el comando.
deleteProcPtr
Puntero al procedimiento de eliminación del comando, o NULL si no se especificó ninguno.
cmdNamePtr
Puntero a una cadena que contiene el nombre del comando. La cadena es válida solo mientras el comando exista y no sea renombrado. No se debe modificar el contenido de esta cadena.

Tcl_SetCommandInfo modifica la información sobre un comando existente. Útil para actualizar el clientData o el deleteProcPtr de un comando. No es posible cambiar el objProcPtr o el cmdNamePtr de un comando de esta manera.

Tcl_GetCommandInfoFromToken y Tcl_SetCommandInfoFromToken son versiones de Tcl_GetCommandInfo y Tcl_SetCommandInfo que operan en un token de comando en lugar de un nombre de comando.

Tcl_GetCommandName devuelve el nombre del comando asociado con el token dado. El nombre de comando devuelto es una cadena constante cuya validez está garantizada solo mientras el comando asociado no sea eliminado o renombrado.

Tcl_GetCommandFullName coloca el nombre completo (incluyendo calificadores de espacio de nombres) del comando asociado con el token dado en el objeto Tcl apuntado por objPtr.

Tcl_GetCommandFromObj busca un comando cuyo nombre está contenido en el objeto Tcl objPtr. Si se encuentra el comando, se devuelve su token; de lo contrario, se devuelve un token NULL. El comando debe existir en el intérprete interp.
