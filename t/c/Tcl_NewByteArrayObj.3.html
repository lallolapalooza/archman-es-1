Tcl_NewByteArrayObj(3)

Paquete: tcl

Licencias: TCL

Tcl_ByteArrayObj(3) Procedimientos de la biblioteca Tcl Tcl_ByteArrayObj(3)

NOMBRE

Tcl_NewByteArrayObj, Tcl_SetByteArrayObj, Tcl_GetByteArrayFromObj, Tcl_SetByteArrayLength - manipular valores Tcl como arrays de bytes

SINOPSIS

#include <tcl.h>

Tcl_Obj *
Tcl_NewByteArrayObj(bytes, length)

void
Tcl_SetByteArrayObj(objPtr, bytes, length)

unsigned char *
Tcl_GetByteArrayFromObj(objPtr, lengthPtr)

unsigned char *
Tcl_SetByteArrayLength(objPtr, length)

ARGUMENTOS

const unsigned char *bytes (entrada)
El array de bytes utilizado para inicializar o establecer un valor de array de bytes. Puede ser NULL incluso si length no es cero.
int length (entrada)
La longitud del array de bytes. Debe ser >= 0.
Tcl_Obj *objPtr (entrada/salida)
Para Tcl_SetByteArrayObj, esto apunta al valor que se convertirá a tipo array de bytes. Para Tcl_GetByteArrayFromObj y Tcl_SetByteArrayLength, esto apunta al valor del cual obtener el valor del array de bytes; si objPtr no apunta ya a un valor de array de bytes, se convertirá a uno.
int *lengthPtr (salida)
Si no es NULL, se rellena con la longitud del array de bytes en el valor.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar y leer valores de array de bytes de Tcl desde código C. Los valores de array de bytes se utilizan típicamente para contener los resultados de operaciones de E/S binarias o estructuras de datos creadas con el comando binary. En Tcl, un array de bytes no es equivalente a una cadena. Conceptualmente, una cadena es un array de caracteres Unicode, mientras que un array de bytes es un array de cantidades de 8 bits sin significado implícito. Se proporcionan funciones accesoras para obtener la representación de cadena de un array de bytes o para convertir un valor arbitrario a un array de bytes. La obtención de la representación de cadena de un valor de array de bytes (llamando a Tcl_GetStringFromObj) produce una secuencia UTF-8 correctamente formada con una correspondencia uno a uno entre los bytes de la representación interna y los caracteres UTF-8 de la representación de cadena.

Tcl_NewByteArrayObj y Tcl_SetByteArrayObj crearán un nuevo valor de tipo array de bytes o modificarán un valor existente para que tenga el tipo array de bytes. Ambos procedimientos establecen el tipo del valor a array de bytes y establecen la representación interna del valor a una copia del array de bytes proporcionado por bytes. Tcl_NewByteArrayObj devuelve un puntero a un valor recién asignado con un contador de referencias de cero. Tcl_SetByteArrayObj invalida cualquier representación de cadena antigua y, si el valor no es ya un valor de array de bytes, libera cualquier representación interna antigua. Si bytes es NULL, el nuevo array de bytes contiene valores arbitrarios.

Tcl_GetByteArrayFromObj convierte un valor Tcl a tipo array de bytes y devuelve un puntero a la nueva representación interna del valor como un array de bytes. La longitud de este array se almacena en lengthPtr si lengthPtr no es NULL. El almacenamiento para el array de bytes es propiedad del valor y no debe liberarse. El contenido del array puede ser modificado por el llamador solo si el valor no se comparte y el llamador invalida la representación de cadena.

Tcl_SetByteArrayLength convierte el valor Tcl a tipo array de bytes y cambia la longitud de la representación interna del valor como un array de bytes. Si length es mayor que el espacio actualmente asignado para el array, el array se reasigna a la nueva longitud; los bytes recién asignados al final del array tienen valores arbitrarios. Si length es menor que el espacio actualmente asignado para el array, la longitud del array se reduce a la nueva longitud. El valor de retorno es un puntero al nuevo array de bytes del valor.
