Paquete: tcl

Licencias: TCL

Tcl_GetStdChannel(3) Procedimientos de la biblioteca Tcl Tcl_GetStdChannel(3)

NOMBRE

Tcl_GetStdChannel, Tcl_SetStdChannel - procedimientos para recuperar y reemplazar los canales estándar

SINOPSIS

#include <tcl.h>

Tcl_Channel
Tcl_GetStdChannel(type)

Tcl_SetStdChannel(channel, type)

ARGUMENTOS

int type (entrada)
El identificador para el canal estándar a recuperar o modificar. Debe ser uno de TCL_STDIN, TCL_STDOUT o TCL_STDERR.
Tcl_Channel channel (entrada)
El canal a utilizar como nuevo valor para el canal estándar especificado.

DESCRIPCIÓN

Tcl define tres canales especiales que son utilizados por varios comandos relacionados con E/S si no se especifican otros canales. El canal de entrada estándar tiene un nombre de canal de stdin y es utilizado por read y gets. El canal de salida estándar se llama stdout y es utilizado por puts. El canal de error estándar se llama stderr y se utiliza para reportar errores. Además, los canales estándar son heredados por cualquier proceso hijo creado usando exec u open en ausencia de otras redirecciones.

Los canales estándar son en realidad alias para otros canales normales. El canal actual asociado con un canal estándar se puede recuperar llamando a Tcl_GetStdChannel con uno de TCL_STDIN, TCL_STDOUT o TCL_STDERR como type. El valor de retorno será un canal válido o NULL.

Se puede establecer un nuevo canal para el canal estándar especificado por type llamando a Tcl_SetStdChannel con un nuevo canal o NULL en el argumento channel. Si el canal especificado se cierra mediante una llamada posterior a Tcl_Close, el canal estándar correspondiente se establecerá automáticamente en NULL.

Si se pasa un valor no NULL para channel a Tcl_SetStdChannel, entonces ese mismo valor debe pasarse a Tcl_RegisterChannel, de la siguiente manera:

Tcl_RegisterChannel(NULL, channel);

Esto es una solución alternativa a un error de diseño en Tcl_SetStdChannel, que no realiza algunas tareas de mantenimiento de conteo de referencias. Este error de diseño no puede corregirse sin contradecir las suposiciones de algún código existente que llama a Tcl_SetStdChannel.

Si se llama a Tcl_GetStdChannel antes de Tcl_SetStdChannel, Tcl construirá un nuevo canal para envolver el identificador de archivo estándar apropiado específico de la plataforma. Si se llama a Tcl_SetStdChannel antes de Tcl_GetStdChannel, el canal predeterminado no se creará.

Si uno de los canales estándar se establece en NULL, ya sea llamando a Tcl_SetStdChannel con un argumento channel NULL, o llamando a Tcl_Close en el canal, la siguiente llamada a Tcl_CreateChannel establecerá automáticamente el canal estándar con el canal recién creado. Si más de un canal estándar es NULL, los canales estándar se asignarán comenzando con la entrada estándar, seguida de la salida estándar, y el error estándar será el último.

Consulte Tcl_StandardChannels para un tratado general sobre los canales estándar y el comportamiento de la biblioteca Tcl con respecto a ellos.

VER TAMBIÉN

Tcl_Close(3), Tcl_CreateChannel(3), Tcl_Main(3), tclsh(1)

PALABRAS CLAVE

canal estándar, entrada estándar, salida estándar, error estándar
