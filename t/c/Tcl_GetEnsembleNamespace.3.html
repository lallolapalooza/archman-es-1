ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el que se creará o encontrará el conjunto. También donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener NULL para el interp, pero todas las demás funciones no deben serlo.
const char *name (entrada)
El nombre del comando de conjunto que se creará.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres al que se enlazará el comando de conjunto, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto OR'ed de bits de bandera que describen la configuración básica del conjunto. Actualmente, solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando de conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando de conjunto a buscar.
int flags (entrada)
Un conjunto OR'ed de bits de bandera que controlan el comportamiento de Tcl_FindEnsemble. Actualmente, solo TCL_LEAVE_ERR_MSG es compatible.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para probar como comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la que se escribirán los bits de bandera actuales del conjunto; actualmente, solo está definido el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario que se utilizará para el mapeo del subcomando al prefijo de comando de implementación en el conjunto. Puede ser NULL si el diccionario de mapeo se va a eliminar.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la que se escribirá el diccionario de mapeo actual del conjunto.
Tcl_Obj *listObj (entrada)
Un valor de lista que se utilizará para la lista de parámetros formales previos al subcomando, la lista definida de subcomandos en el diccionario o el prefijo de comando del manejador de subcomandos desconocidos. Puede ser NULL si la lista de subcomandos o el manejador de desconocidos se van a eliminar.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la que se escribirá la lista actual de parámetros formales previos al subcomando, la lista definida de subcomandos o el prefijo actual del manejador de desconocidos.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la que se escribirá el manejador del espacio de nombres al que está enlazado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, enlazado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos de Tcl. El primer argumento al comando de conjunto siempre se interpreta como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete dentro del cual trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que enlazar el conjunto, y el conjunto predeterminado de banderas de conjunto. El resultado de la función es el token del comando para el conjunto, que puede usarse para configurar aún más el conjunto utilizando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token para ese comando puede obtenerse usando Tcl_FindEnsemble. Si el nombre del comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Un token de comando puede ser verificado para ver si se refiere a un conjunto usando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

banderas (lectura/escritura)
El conjunto de banderas para el conjunto, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX que se establece cuando los prefijos no ambiguos de subcomandos se permiten resolver a implementaciones, así como coincidencias exactas. Las banderas pueden ser leídas y escritas usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras que se utilizarán como prefijo de comando (reemplazando las dos primeras palabras del comando que son el comando de conjunto y el nombre del subcomando), o NULL si cada subcomando se mapeará al comando con el mismo nombre no calificado en el espacio de nombres enlazado del conjunto. Por defecto es NULL. Puede ser leído y escrito usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable, incluso si no está compartido. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros previos al subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Puede ser leído y escrito usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable, incluso si no está compartido.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto se deriva de las claves del diccionario de mapeo (ver arriba) o (si ese también es NULL) del conjunto de comandos exportados por el espacio de nombres enlazado. Puede ser leído y escrito usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado de Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable, incluso si no está compartida.
prefijo de comando del manejador de subcomandos desconocidos (lectura/escritura)
Una lista de palabras para anteponer al subcomando cuando este es desconocido para el conjunto (de acuerdo con la regla actual de manejo de prefijos)

DESCRIPCIÓN

El namespace enlazado es el namespace al que está enlazado el conjunto; cuando el namespace se elimina, también lo hará el conjunto, y este namespace es también el namespace cuya lista de comandos exportados se utiliza si tanto el diccionario de mapeo como las propiedades de la lista de subcomandos son NULL. Puede leerse utilizando Tcl_GetEnsembleNamespace, que devuelve un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
