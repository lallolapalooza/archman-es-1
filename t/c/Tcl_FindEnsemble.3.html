ARGUMENTOS

Tcl_Interp *interp (in/out)
El intérprete en el que se creará o encontrará el ensemble. También es donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener NULL para interp, pero todas las demás funciones no deben.
const char *name (in)
El nombre del comando ensemble a crear.
Tcl_Namespace *namespacePtr (in)
El namespace al que se enlazará el comando ensemble, o NULL para el namespace actual.
int ensFlags (in)
Un conjunto OR de bits de bandera que describen la configuración básica del ensemble. Actualmente solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando ensemble también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (in)
Un valor que contiene el nombre del comando ensemble a buscar.
int flags (in)
Un conjunto OR de bits de bandera que controlan el comportamiento de Tcl_FindEnsemble. Actualmente solo TCL_LEAVE_ERR_MSG es soportado.
Tcl_Command token (in)
Un token de comando normal que se refiere a un comando ensemble, o que desea utilizar para probar como comando ensemble en Tcl_IsEnsemble.
int *ensFlagsPtr (out)
Puntero a una variable en la que escribir los bits de bandera actuales del ensemble; actualmente solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (in)
Un valor de diccionario para usar en el mapeo de subcomando a prefijo de comando de implementación en el ensemble. Puede ser NULL si el diccionario de mapeo se va a eliminar.
Tcl_Obj **dictObjPtr (out)
Puntero a una variable en la que escribir el diccionario de mapeo actual del ensemble.
Tcl_Obj *listObj (in)
Un valor de lista para usar para la lista de parámetros formales pre-subcomando, la lista definida de subcomandos en el diccionario o el prefijo de comando del manejador de subcomando desconocido. Puede ser NULL si la lista de subcomandos o el manejador desconocido se van a eliminar.
Tcl_Obj **listObjPtr (out)
Puntero a una variable en la que escribir la lista actual de parámetros formales pre-subcomando, la lista definida de subcomandos o el prefijo actual del manejador desconocido.
Tcl_Namespace **namespacePtrPtr (out)
Puntero a una variable en la que escribir el manejador del namespace al que está enlazado el ensemble.

DESCRIPCIÓN

Un ensemble es un comando, enlazado a algún namespace, que consiste en una colección de subcomandos implementados por otros comandos Tcl. El primer argumento al comando ensemble se interpreta siempre como un selector que indica qué subcomando ejecutar.

Los ensembles se crean usando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete dentro del cual trabajar, el nombre del ensemble a crear, el namespace dentro del intérprete al que enlazar el ensemble, y el conjunto predeterminado de banderas de ensemble. El resultado de la función es el token del comando para el ensemble, que puede usarse para configurar aún más el ensemble utilizando la API descrita a continuación en PROPIEDADES DE ENSEMBLE.

Dado el nombre de un comando ensemble, el token para ese comando puede obtenerse usando Tcl_FindEnsemble. Si el nombre de comando dado (en cmdNameObj) no se refiere a un comando ensemble, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Se puede comprobar un token de comando para ver si se refiere a un ensemble usando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un ensemble, o 0 en caso contrario.

PROPIEDADES DE ENSEMBLE

Cada ensemble tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

flags (lectura/escritura)
El conjunto de banderas para el ensemble, expresado como un campo de bits. Actualmente, la única bandera pública es TCL_ENSEMBLE_PREFIX, que se establece cuando se permiten prefijos no ambiguos de subcomandos para ser resueltos a implementaciones, así como coincidencias exactas. Las banderas pueden ser leídas y escritas usando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el comando ensemble en sí y el nombre del subcomando), o NULL si cada subcomando debe ser mapeado al comando con el mismo nombre no calificado en el namespace enlazado del ensemble. Por defecto es NULL. Puede ser leído y escrito usando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe ser tratado como inmutable incluso si no está compartido. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros pre-subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del ensemble entre el nombre del ensemble y el argumento del subcomando. NULL (el valor por defecto) es equivalente a la lista vacía. Puede ser leído y escrito usando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe ser tratado como inmutable incluso si no está compartido.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el ensemble, o NULL si esto debe derivarse de las claves del diccionario de mapeo (ver arriba) o (si eso también es NULL) del conjunto de comandos exportados por el namespace enlazado. Puede ser leído y escrito usando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un ensemble) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe ser tratada como inmutable incluso si no está compartida.
prefijo de comando manejador de subcomando desconocido (lectura/escritura)
Una lista de palabras para anteponer a cualquier subcomando cuando el subcomando es desconocido para el ensemble (según la regla actual de manejo de prefijos); véase th
