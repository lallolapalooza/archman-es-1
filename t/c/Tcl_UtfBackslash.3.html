DESCRIPCIÓN

Estas rutinas convierten entre cadenas UTF-8 y Tcl_UniChars. Un Tcl_UniChar es un carácter Unicode representado como una cantidad fija de tamaño, sin signo. Un carácter UTF-8 es un carácter Unicode representado como una secuencia de longitud variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 multibyte consta de un byte de liderazgo seguido de algunos bytes de seguimiento.

TCL_UTF_MAX es el número máximo de bytes necesarios para representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 comenzando en buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 comenzando en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamador debe asegurarse de que el búfer de origen sea lo suficientemente largo para que esta rutina no se salga del final y dereference memoria inexistente o aleatoria; si se sabe que el búfer de origen está terminado en nulo, esto no ocurrirá. Si la entrada no tiene el formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada a UTF-8, almacenando el resultado en un Tcl_DString previamente inicializado. Debe especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada a Unicode, almacenando el resultado en el Tcl_DString previamente inicializado. En el argumento length, puede especificar la longitud de la cadena UTF-8 dada en bytes o “-1”, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El almacenamiento para el valor de retorno se anexa al final del Tcl_DString. La cadena Unicode se termina con un carácter nulo Unicode.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en nulo y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en nulo y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres. Tcl_UniCharNcmp compara las dos cadenas carácter a carácter según el orden de caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena respectivamente. Tcl_UniCharNcasecmp es la versión insensible a mayúsculas y minúsculas de Unicode.

Tcl_UniCharCaseMatch es el equivalente Unicode de Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en nulo, un patrón Unicode y un valor booleano que especifica si la coincidencia debe ser sensible a mayúsculas y minúsculas, y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en nulo y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres.) Tcl_UtfNcmp compara las dos cadenas carácter a carácter según el orden de caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas y minúsculas al comparar caracteres en mayúsculas, minúsculas o de título.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 de origen src de length bytes es lo suficientemente larga como para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté formada correctamente. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars representados por la cadena UTF-8 src. La longitud de la cadena de origen es length bytes. Si la longitud es negativa, se utilizan todos los bytes hasta el primer byte nulo.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera aparición del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última aparición del Tcl

Tcl_UtfBackslash

3 — Tcl Library Functions

ARGUMENTS

Constant char *src (in)
        Source string, or pointer within a source string.
int index (in)
        Index into the source string.
int *readPtr (out)
        Pointer to store the number of bytes read from src.
char *dst (out)
        Pointer to destination buffer to store the result.
        Buffer must be large enough to hold TCL_UTF_MAX bytes.
const char *start (in)
        Beginning of the UTF-8 string.
int length (in)
        Number of bytes available in the string.

DESCRIPTION

These procedures provide support for manipulating UTF-8 strings. UTF-8 is a character encoding that represents Unicode characters in a variable-length sequence of 1 to 4 bytes.

Tcl_UniCharAtIndex returns the Tcl_UniChar value of the character at the specified character index in the UTF-8 string src. If the character at index is not completely specified in the string, the value is returned as if the character were padded with null bytes. The null terminator is considered part of the UTF-8 string.

Tcl_UtfNext returns the Tcl_UniChar value of the first character in the UTF-8 string src, and also returns a pointer to the start of the next character in the string via the src argument. The null terminator is considered part of the UTF-8 string.

Tcl_UtfCharComplete is used to check if the character at the beginning of the length bytes string str is complete. It returns true if the character is complete, false otherwise. If the character is incomplete, it returns the number of bytes that are needed to complete the character.

Tcl_UtfPrev is used to step backward through a UTF-8 string. Given start, a pointer to the beginning of a string, and src, a pointer to a location within the string, Tcl_UtfPrev returns a pointer to the start of the character that contains the byte src[-1]. The callers must ensure that src is not equal to start. The null terminator is considered part of the UTF-8 string.

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UniCharAtIndex index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
