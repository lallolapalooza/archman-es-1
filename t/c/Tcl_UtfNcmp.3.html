DESCRIPCIÓN

Estas rutinas convierten cadenas UTF-8 a Tcl_UniChars y viceversa. Un Tcl_UniChar es un carácter Unicode representado como una cantidad de tamaño fijo sin signo. Un carácter UTF-8 es un carácter Unicode representado como una secuencia de longitud variable de hasta TCL_UTF_MAX bytes. Una secuencia UTF-8 multibyte consta de un byte inicial seguido de algunos bytes de seguimiento.

TCL_UTF_MAX es el número máximo de bytes que se tarda en representar un carácter Unicode en la representación UTF-8.

Tcl_UniCharToUtf almacena el Tcl_UniChar ch como una cadena UTF-8 comenzando en buf. El valor de retorno es el número de bytes almacenados en buf.

Tcl_UtfToUniChar lee un carácter UTF-8 comenzando en src y lo almacena como un Tcl_UniChar en *chPtr. El valor de retorno es el número de bytes leídos de src. El llamador debe asegurarse de que el búfer de origen sea lo suficientemente largo para que esta rutina no se salga del final y no desreferencie memoria inexistente o aleatoria; si se sabe que el búfer de origen está terminado en nulo, esto no ocurrirá. Si la entrada no está en formato UTF-8 correcto, Tcl_UtfToUniChar almacenará el primer byte de src en *chPtr como un Tcl_UniChar entre 0x80 y 0xFF y devolverá 1.

Tcl_UniCharToUtfDString convierte la cadena Unicode dada a UTF-8, almacenando el resultado en un Tcl_DString inicializado previamente. Debe especificar uniLength, la longitud de la cadena Unicode dada. El valor de retorno es un puntero a la representación UTF-8 de la cadena Unicode. El espacio para el valor de retorno se añade al final del Tcl_DString.

Tcl_UtfToUniCharDString convierte la cadena UTF-8 dada a Unicode, almacenando el resultado en el Tcl_DString inicializado previamente. En el argumento length, puede especificar la longitud de la cadena UTF-8 dada en bytes o “-1”, en cuyo caso Tcl_UtfToUniCharDString utiliza strlen para calcular la longitud. El valor de retorno es un puntero a la representación Unicode de la cadena UTF-8. El espacio para el valor de retorno se añade al final del Tcl_DString. La cadena Unicode se termina con un carácter nulo Unicode.

Tcl_UniCharLen corresponde a strlen para caracteres Unicode. Acepta una cadena Unicode terminada en nulo y devuelve el número de caracteres Unicode (no bytes) en esa cadena.

Tcl_UniCharNcmp y Tcl_UniCharNcasecmp corresponden a strncmp y strncasecmp, respectivamente, para caracteres Unicode. Aceptan dos cadenas Unicode terminadas en nulo y el número de caracteres a comparar. Se asume que ambas cadenas tienen al menos numChars caracteres. Tcl_UniCharNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena respectivamente. Tcl_UniCharNcasecmp es la versión Unicode insensible a mayúsculas/minúsculas.

Tcl_UniCharCaseMatch es el equivalente Unicode a Tcl_StringCaseMatch. Acepta una cadena Unicode terminada en nulo, un patrón Unicode y un valor booleano que especifica si la comparación debe ser sensible a mayúsculas/minúsculas y devuelve si la cadena coincide con el patrón.

Tcl_UtfNcmp corresponde a strncmp para cadenas UTF-8. Acepta dos cadenas UTF-8 terminadas en nulo y el número de caracteres a comparar. (Se asume que ambas cadenas tienen al menos numChars caracteres.) Tcl_UtfNcmp compara las dos cadenas carácter a carácter según el orden de los caracteres Unicode. Devuelve un entero mayor que, igual a, o menor que 0 si la primera cadena es mayor que, igual a, o menor que la segunda cadena respectivamente.

Tcl_UtfNcasecmp corresponde a strncasecmp para cadenas UTF-8. Es similar a Tcl_UtfNcmp excepto que las comparaciones ignoran las diferencias de mayúsculas/minúsculas al comparar caracteres mayúsculas, minúsculas o de título.

Tcl_UtfCharComplete devuelve 1 si la cadena UTF-8 fuente src de length bytes es lo suficientemente larga para ser decodificada por Tcl_UtfToUniChar/Tcl_UtfNext, o 0 en caso contrario. Esta función no garantiza que la cadena UTF-8 esté correctamente formada. Esta rutina es utilizada por procedimientos que operan byte a byte y necesitan saber si se ha visto un Tcl_UniChar completo.

Tcl_NumUtfChars corresponde a strlen para cadenas UTF-8. Devuelve el número de Tcl_UniChars que están representados por la cadena UTF-8 src. La longitud de la cadena fuente es length bytes. Si la longitud es negativa, se utilizan todos los bytes hasta el primer byte nulo.

Tcl_UtfFindFirst corresponde a strchr para cadenas UTF-8. Devuelve un puntero a la primera ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfFindLast corresponde a strrchr para cadenas UTF-8. Devuelve un puntero a la última ocurrencia del Tcl_UniChar ch en la cadena UTF-8 terminada en nulo src. El terminador nulo se considera parte de la cadena UTF-8.

Tcl_UtfNext devuelve un puntero al siguiente carácter UTF-8 en la cadena src. El número de bytes consumidos se devuelve a través de Tcl_UtfToUniChar. Si la cadena contiene caracteres incompletos o mal formados, se comportará de forma indefinida, pero no se bloqueará.

Tcl_UtfPrev devuelve un puntero al carácter UTF-8 anterior en la cadena src, que comienza en start. El número de bytes consumidos se devuelve a través de Tcl_UtfToUniChar. Si la cadena contiene caracteres incompletos o mal formados, se comportará de forma indefinida, pero no se bloqueará.

Tcl_UniCharAtIndex devuelve el Tcl_UniChar en el índice de carácter dado index en la cadena UTF-8 src. Si el índice está fuera de rango, el comportamiento es indefinido.

Tcl_UtfAtIndex devuelve un puntero al principio del carácter UTF-8 en el índice de carácter dado index en la cadena UTF-8 src. Si el índice está fuera de rango, el comportamiento es indefinido.

Tcl_UtfBackslash decodifica una secuencia de barra invertida desde el inicio de la cadena src. El número de bytes leídos de src (incluido el carácter de barra invertida) se almacena en *readPtr si no es NULL. El byte o bytes decodificados se almacenan en dst. El valor de retorno es el número de bytes escritos en dst. Si la secuencia de barra invertida no es válida, se almacenará el carácter literal y se devolverá 1.

DESCRIPTION

These procedures provide a variety of ways to convert between Tcl's internal Unicode representation (sequences of 16-bit Tcl_UniChar values) and the UTF-8 representation used for strings in Tcl. They also provide character array-like access to UTF-8 strings.

Tcl_UniCharToUtf converts n Unicode characters from uniIn to UTF-8 representation in utfOut. The result in utfOut is not null-terminated. The return value is the number of bytes written to utfOut. If the output buffer is not large enough to hold the converted characters, the behavior is undefined. Use Tcl_UniCharToUniChar to get the number of bytes needed before allocation.

Tcl_UtfToUniChar converts a single UTF-8 character from utfIn to a single Tcl_UniChar in uniOut. The return value is the number of bytes consumed from utfIn. If the character is not well-formed, the behavior is undefined. It is possible for a single Unicode character to take multiple bytes in UTF-8, up to TCL_UTF_MAX bytes.

Tcl_UniCharToUtfDString converts n Unicode characters from uniSrc to UTF-8 representation and appends it to the Tcl_DString dstPtr. The return value is the number of bytes appended. This is the preferred way to convert Unicode to UTF-8 when the result is to be stored in a Tcl_DString.

Tcl_UtfToUniCharDString converts up to n bytes of UTF-8 characters from utfSrc to Unicode representation and appends it to the Tcl_DString dstPtr. The return value is the number of Unicode characters appended. This is the preferred way to convert UTF-8 to Unicode when the result is to be stored in a Tcl_DString.

Tcl_UniCharLen returns the number of bytes required to store the n Unicode characters from uniIn in UTF-8 format. This is useful for pre-allocating buffers.

Tcl_UtfLen returns the number of Unicode characters in the UTF-8 string utfIn. The string must be null-terminated. This is equivalent to calling Tcl_UtfToUniChar repeatedly until the end of the string is reached.

Tcl_UniCharNcmp compares the first n Unicode characters from uni1 and uni2. It returns 0 if the characters are identical, a negative value if uni1 is less than uni2, and a positive value if uni1 is greater than uni2.

Tcl_UtfNcmp compares the first n bytes of the UTF-8 strings utf1 and utf2. It returns 0 if the strings are identical, a negative value if utf1 is less than utf2, and a positive value if utf1 is greater than utf2.

Tcl_UniCharCaseMatch compares the first n Unicode characters from uni1 and uni2, ignoring case. It returns 1 if the characters match, and 0 otherwise.

Tcl_UtfCaseMatch compares the UTF-8 strings utf1 and utf2, ignoring case. It returns 1 if the strings match, and 0 otherwise. The comparison is done character by character, respecting the UTF-8 encoding.

Tcl_UniCharToUtf2 is similar to Tcl_UniCharToUtf, but it also takes an output buffer length outLen. It writes at most outLen bytes to utfOut. The return value is the number of bytes that would have been written if the buffer had been large enough. This can be used to detect truncation.

Tcl_UtfToUniChar2 is similar to Tcl_UtfToUniChar, but it takes an input length inLen and an output buffer length outLen. It converts at most inLen bytes from utfIn to Unicode characters, writing at most outLen characters to uniOut. The return value is the number of bytes consumed from utfIn. This can be used to convert chunks of UTF-8 data.

Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must ensure that utf points to a valid UTF-8 character within the string, and that the string is null-terminated if utf points to the last character. If the string is not null-terminated, use Tcl_UtfCharComplete to ensure that enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through the UTF-8 string that begins at start. It returns a pointer to the beginning of the previous character. If utf points to the beginning of the string or to an invalid character, the behavior is undefined. Repeated calls will step back through the string one character at a time, eventually returning start. It is guaranteed not to read bytes before start.

Tcl_UniCharAtIndex returns the Tcl_UniChar represented at the specified character index index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character index index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash parses a backslash sequence starting at src, converts it to a UTF-8 character, and stores it in dst. At most TCL_UTF_MAX bytes are stored in dst. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes consumed from src, including the backslash. The return value is the number of bytes stored in dst.

Tcl_IsExitChar returns true if the character starting at utf is one of the characters that can terminate a Tcl command without requiring a space after it (e.g., `;`, `\n`, `\r`, `\f`).

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
