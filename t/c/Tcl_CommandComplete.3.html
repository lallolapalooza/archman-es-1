Tcl_CommandComplete(3) Procedimientos de la biblioteca Tcl Tcl_CommandComplete(3)

NOMBRE

Tcl_CommandComplete - Comprueba si hay llaves no emparejadas en un comando Tcl

SINOPSIS

#include <tcl.h>

int
Tcl_CommandComplete(cmd)

ARGUMENTOS

const char *cmd (entrada)
Cadena de comando a probar para ver si está completa.

DESCRIPCIÓN

Tcl_CommandComplete toma una cadena de comando Tcl como argumento y determina si contiene uno o más comandos completos (es decir, si no hay comillas, llaves, corchetes o referencias a variables sin cerrar). Si la cadena de comando está completa, devuelve 1; de lo contrario, devuelve 0.

PALABRAS CLAVE

comando completo, comando parcial
