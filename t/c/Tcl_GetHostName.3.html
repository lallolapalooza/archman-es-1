NOMBRE

Tcl_GetHostName - obtener el nombre del host local

SINOPSIS

#include <tcl.h>

const char *
Tcl_GetHostName()

DESCRIPCIÓN

Tcl_GetHostName es un procedimiento de utilidad utilizado por algunos de los comandos de Tcl. Devuelve un puntero a una cadena que contiene el nombre de la máquina actual, o una cadena vacía si no se puede determinar el nombre. La cadena se asigna estáticamente y el llamador no debe modificarla ni liberarla.
