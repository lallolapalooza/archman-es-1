Tcl_GetIndexFromObjStruct(3)

Paquete: tcl

Licencias: TCL

Tcl_GetIndexFromObj(3) Procedimientos de la biblioteca Tcl Tcl_GetIndexFromObj(3)

NOMBRE

Tcl_GetIndexFromObj, Tcl_GetIndexFromObjStruct - buscar cadena en tabla de palabras clave

SINOPSIS

#include <tcl.h>

int
Tcl_GetIndexFromObj(interp, objPtr, tablePtr, msg, flags,
indexPtr)

int
Tcl_GetIndexFromObjStruct(interp, objPtr, structTablePtr, offset,
                          msg, flags, indexPtr)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a utilizar para informar de errores; si es NULL, entonces no se proporciona ningún mensaje en caso de error.
Tcl_Obj *objPtr (entrada/salida)
El valor de cadena de este valor se utiliza para buscar en tablePtr. La representación interna se modifica para contener el índice de la entrada de tabla coincidente.
const char *const *tablePtr (entrada)
Una matriz de cadenas terminadas en nulo. El final de la matriz está marcado por un puntero de cadena NULL. Tenga en cuenta que las referencias a tablePtr pueden conservarse en la representación interna de objPtr, por lo que esta debe representar la dirección de una matriz asignada estáticamente.
const void *structTablePtr (entrada)
Una matriz de tipo arbitrario, típicamente algún tipo struct. El primer miembro de la estructura debe ser una cadena terminada en nulo. El tamaño de la estructura se da por offset. Tenga en cuenta que las referencias a structTablePtr pueden conservarse en la representación interna de objPtr, por lo que esta debe representar la dirección de una matriz de estructuras asignada estáticamente.
int offset (entrada)
El desplazamiento a sumar a structTablePtr para llegar a la siguiente entrada. El final de la matriz está marcado por un puntero de cadena NULL.
const char *msg (entrada)
Cadena terminada en nulo que describe qué se está buscando, como option. Esta cadena se incluye en los mensajes de error.
int flags (entrada)
Combinación OR-ada de bits que proporcionan información adicional para la operación. El único bit definido actualmente es TCL_EXACT.
int *indexPtr (salida)
El índice de la cadena en tablePtr que coincide con el valor de objPtr se devuelve aquí.

DESCRIPCIÓN

Estos procedimientos proporcionan una forma eficiente para buscar palabras clave, nombres de conmutadores, nombres de opciones y cosas similares donde el valor literal de un valor Tcl debe elegirse de un conjunto predefinido. Tcl_GetIndexFromObj compara objPtr contra cada una de las cadenas en tablePtr para encontrar una coincidencia. Se produce una coincidencia si el valor de cadena de objPtr es idéntico a una de las cadenas en tablePtr, o si es una abreviatura única no vacía para exactamente una de las cadenas en tablePtr y la bandera TCL_EXACT no se especificó; en cualquier caso, el índice de la entrada coincidente se almacena en *indexPtr y se devuelve TCL_OK.

Si no hay ninguna entrada coincidente, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si interp no es NULL. Msg se incluye en el mensaje de error para indicar qué se estaba buscando. Por ejemplo, si msg es option, el mensaje de error tendrá un formato como "mala opción "firt": debe ser first, second, o third".

Si Tcl_GetIndexFromObj se completa con éxito, modifica la representación interna de objPtr para contener la dirección de la tabla y el índice de la entrada coincidente. Si se invoca Tcl_GetIndexFromObj nuevamente con los mismos argumentos objPtr y tablePtr (por ejemplo, durante una reinvocación de un comando Tcl), devuelve el índice coincidente inmediatamente sin tener que repetir la operación de búsqueda. Nota: Tcl_GetIndexFromObj asume que las entradas en tablePtr son estáticas: no deben cambiar entre invocaciones. Si el valor de objPtr es la cadena vacía, Tcl_GetIndexFromObj lo tratará como un valor no coincidente y devolverá TCL_ERROR.

Tcl_GetIndexFromObjStruct funciona igual que Tcl_GetIndexFromObj, excepto que en lugar de tratar tablePtr como una matriz de punteros a cadenas, lo trata como un puntero a la primera cadena en una serie de cadenas que tienen offset bytes entre ellas (es decir, que hay un puntero a la primera matriz de caracteres en tablePtr, un puntero a la segunda matriz de caracteres en tablePtr + offset bytes, etc.) Esto es particularmente útil al procesar cosas como Tk_ConfigurationSpec, cuyas claves de cadena están en el mismo lugar en cada uno de varios elementos de matriz.
