Tcl_SetDoubleObj(3)

Paquete: tcl

Licencias: TCL

Tcl_DoubleObj(3) Procedimientos de la biblioteca Tcl Tcl_DoubleObj(3)

NOMBRE

Tcl_NewDoubleObj, Tcl_SetDoubleObj, Tcl_GetDoubleFromObj - manipular valores de Tcl como valores de punto flotante

SINOPSIS

#include <tcl.h>

Tcl_Obj *
Tcl_NewDoubleObj(doubleValue)

Tcl_SetDoubleObj(objPtr, doubleValue)

int
Tcl_GetDoubleFromObj(interp, objPtr, doublePtr)

ARGUMENTOS

double doubleValue (entrada)
Un valor de punto flotante de doble precisión utilizado para inicializar o establecer un valor de Tcl.
Tcl_Obj *objPtr (entrada/salida)
Para Tcl_SetDoubleObj, esto apunta al valor en el que se almacenará un valor doble. Para Tcl_GetDoubleFromObj, esto se refiere al valor del que se recuperará un valor doble.
Tcl_Interp *interp (entrada/salida)
Cuando no es NULL, se deja un mensaje de error aquí cuando la recuperación del valor doble falla.
double *doublePtr (salida)
Apunta al lugar donde se almacenará el valor doble obtenido de objPtr.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar y leer valores de Tcl que contienen valores de punto flotante de doble precisión.

Tcl_NewDoubleObj crea y devuelve un nuevo valor de Tcl inicializado al valor doble doubleValue. El valor de Tcl devuelto no se comparte.

Tcl_SetDoubleObj establece el valor de un valor de Tcl existente apuntado por objPtr al valor doble doubleValue. El argumento objPtr debe apuntar a un valor de Tcl no compartido. Cualquier intento de establecer el valor de un valor de Tcl compartido viola la política de copia en escritura de Tcl. Cualquier representación de cadena o representación interna existente en el valor de Tcl no compartido se liberará como consecuencia de establecer el nuevo valor.

Tcl_GetDoubleFromObj intenta recuperar un valor doble del valor de Tcl objPtr. Si el intento tiene éxito, se devuelve TCL_OK y el valor doble se escribe en el almacenamiento apuntado por doublePtr. Si el intento falla, se devuelve TCL_ERROR y, si interp no es NULL, se deja un mensaje de error en interp. El Tcl_ObjType de objPtr puede cambiarse para hacer que las llamadas posteriores a Tcl_GetDoubleFromObj sean más eficientes.

VER TAMBIÉN

Tcl_NewObj, Tcl_DecrRefCount, Tcl_IncrRefCount, Tcl_GetObjResult
