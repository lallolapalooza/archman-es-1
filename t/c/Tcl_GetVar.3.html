ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene la variable.
const char *name1 (entrada)
Contiene el nombre de una variable de arreglo (si name2 no es NULL) o (si name2 es NULL) el nombre de una variable escalar o un nombre completo que incluye el nombre de la variable y el índice. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular.
const char *name2 (entrada)
Si no es NULL, proporciona el nombre del elemento dentro del arreglo; en este caso name1 debe referirse a una variable de arreglo.
Tcl_Obj *newValuePtr (entrada)
Punta a un valor Tcl que contiene el nuevo valor para la variable.
int flags (entrada)
Combinación OR de bits que proporcionan información adicional. Vea abajo para valores válidos.
const char *varName (entrada)
Nombre de la variable. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de un arreglo.
const char *newValue (entrada)
Nuevo valor para la variable, especificado como una cadena terminada en nulo. Se almacena una copia de este valor en la variable.
Tcl_Obj *part1Ptr (entrada)
Punta a un valor Tcl que contiene el nombre de la variable. El nombre puede incluir una serie de calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede referirse a una variable escalar o a un elemento de un arreglo.
Tcl_Obj *part2Ptr (entrada)
Si no es NULL, punta a un valor que contiene el nombre de un elemento dentro de un arreglo y part1Ptr debe referirse a una variable de arreglo.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar, leer y eliminar variables Tcl desde código C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 y Tcl_ObjSetVar2 crearán una nueva variable o modificarán una existente. Estos procedimientos establecen la variable dada al valor proporcionado por newValuePtr o newValue y devuelven un puntero al nuevo valor de la variable, que se almacena en la estructura de variables de Tcl. Tcl_SetVar2Ex y Tcl_ObjSetVar2 toman el nuevo valor como un Tcl_Obj y devuelven un puntero a un Tcl_Obj. Tcl_SetVar y Tcl_SetVar2 toman el nuevo valor como una cadena y devuelven una cadena; generalmente son menos eficientes que Tcl_ObjSetVar2. Tenga en cuenta que el valor de retorno puede ser diferente del argumento newValuePtr o newValue, debido a modificaciones realizadas por trazas de escritura. Si ocurre un error al establecer la variable (por ejemplo, se hace referencia a una variable de arreglo sin proporcionar un índice), se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está establecido.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 y Tcl_ObjGetVar2 devuelven el valor actual de una variable. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos descritos anteriormente. En circunstancias normales, el valor de retorno es un puntero al valor de la variable. Para Tcl_GetVar2Ex y Tcl_ObjGetVar2 el valor se devuelve como un puntero a un Tcl_Obj. Para Tcl_GetVar y Tcl_GetVar2 el valor se devuelve como una cadena; esto suele ser menos eficiente, por lo que se prefieren Tcl_GetVar2Ex o Tcl_ObjGetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de arreglo para una variable escalar), entonces se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está establecido.

Tcl_UnsetVar y Tcl_UnsetVar2 se pueden utilizar para eliminar una variable, de modo que los intentos posteriores de leer la variable devuelvan un error. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos anteriores. Si la variable se elimina correctamente, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si el bit de flag TCL_LEAVE_ERR_MSG está establecido. Si se especifica un elemento de arreglo, se elimina el elemento dado pero el arreglo permanece. Si se especifica el nombre de un arreglo sin un índice, se elimina todo el arreglo.

El nombre de una variable se puede especificar a estos procedimientos de cuatro maneras:

[1]
Si se invoca Tcl_SetVar, Tcl_GetVar o Tcl_UnsetVar, el nombre de la variable se proporciona como una sola cadena, varName. Si varName contiene un paréntesis de apertura y termina con un paréntesis de cierre, entonces el valor entre los paréntesis se trata como un índice (que puede tener cualquier valor de cadena) y los caracteres antes del primer paréntesis de apertura se tratan como el nombre de una variable de arreglo. Si varName no tiene paréntesis como se describe anteriormente, entonces toda la cadena se trata como el nombre de una variable escalar.
[2]
Si se proporcionan los argumentos name1 y name2 y name2 no es NULL, entonces se especifica un elemento de arreglo y el nombre del arreglo y el índice ya han sido separados por el llamador: name1 contiene el nombre y name2 contiene el índice. Se genera un error si name1 contiene un paréntesis de apertura y termina con un paréntesis de cierre (elemento de arreglo) y name2 no es NULL.
[3]
Si name2 es NULL, name1 se trata igual que varName en el caso [1] anterior (puede ser un nombre de variable escalar o de elemento de arreglo).

El argumento flags se puede utilizar para especificar cualquiera de varias opciones a los procedimientos. Consiste en una combinación OR de los siguientes bits.

TCL_GLOBAL_ONLY
En circunstancias normales, los procedimientos buscan variables de la siguiente manera. Si una llamada de procedimiento está activa en interp, la variable se busca en el nivel actual de llamada de procedimiento. De lo contrario, la variable se busca primero en el espacio de nombres actual, luego en el espacio de nombres global. Sin embargo, si este bit está establecido en flags, entonces la variable se busca solo en el espacio de nombres global, incluso si hay una llamada de procedimiento activa. Si se proporcionan TCL_GLOBAL_ONLY y TCL_NAMESPACE_ONLY, se ignora TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
Si este bit está establecido en flags, entonces la variable se busca solo en el espacio de nombres actual; si un procedimiento está activo, se ignoran sus variables, y el espacio de nombres global también se ignora a menos que sea el espacio de nombres actual.
TCL_LEAVE_ERR_MSG
Si se devuelve un error y este bit está establecido en flags, entonces se dejará un mensaje de error en el resultado del intérprete, donde se puede recuperar con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de bandera no está establecido, no se dejará ningún mensaje de error y el resultado del intérprete no se modificará.
TCL_APPEND_VALUE
Si este bit está establecido, entonces newValuePtr o newValue se anexan al valor actual en lugar de reemplazarlo. Si la variable no está definida actualmente, entonces se ignora el bit. Este bit solo lo utilizan los procedimientos Tcl_Set*.
TCL_LIST_ELEMENT
Si este bit está establecido, entonces newValue se convierte en un elemento de lista Tcl válido antes de establecer (o anexar a) la variable. Se agrega un separador de espacio antes de la nueva lista

Tcl_GetVar y Tcl_GetVar2 devuelven el valor actual de una variable. Los argumentos de estos procedimientos se tratan de la misma manera que los argumentos de Tcl_SetVar y Tcl_SetVar2. En circunstancias normales, el valor de retorno es un puntero al valor de la variable (que se almacena en la estructura de variables de Tcl y no cambiará antes de la próxima llamada a Tcl_SetVar o Tcl_SetVar2). Si se especifica un nombre de matriz sin índice, se elimina toda la matriz.
