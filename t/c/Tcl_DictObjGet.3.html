ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de diccionario, se deja un mensaje de error en el resultado del intérprete, a menos que interp sea NULL.
Tcl_Obj *dictPtr (entrada/salida)
Punta al valor del diccionario a manipular. Si dictPtr no apunta ya a un valor de diccionario, se intentará convertirlo en uno.
Tcl_Obj *keyPtr (entrada)
Punta a la clave para el par clave/valor que se manipula dentro del valor del diccionario.
Tcl_Obj **keyPtrPtr (salida)
Punta a una variable a la que se le asignará la clave de un par clave/valor. Puede ser NULL para indicar que el llamante no está interesado en la clave.
Tcl_Obj *valuePtr (entrada)
Punta al valor para el par clave/valor que se manipula dentro del valor del diccionario (o sub-valor, en el caso de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (salida)
Punta a una variable a la que se le asignará el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, este puede ser NULL para indicar que el llamante no está interesado en el valor.
int *sizePtr (salida)
Punta a una variable a la que se asignará el número de pares clave/valor contenidos en el diccionario.
Tcl_DictSearch *searchPtr (entrada/salida)
Punta a la estructura a usar para mantener el seguimiento del progreso en la enumeración de todos los pares clave/valor de un diccionario. Los contenidos de la estructura serán inicializados por la llamada a Tcl_DictObjFirst. Si la enumeración se va a terminar antes de que se hayan devuelto todos los valores del diccionario, se *debe* pasar la estructura de búsqueda a Tcl_DictObjDone para permitir la liberación de los bloqueos internos.
int *donePtr (salida)
Punta a una variable a la que se escribirá un valor distinto de cero cuando se haya completado la enumeración de los pares clave/valor de un diccionario, y un cero en caso contrario.
int keyc (entrada)
Indica el número de claves que se proporcionarán en el array keyv.
Tcl_Obj *const *keyv (entrada)
Array de keyc punteros a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList usarán para localizar el par clave/valor a manipular dentro de los sub-diccionarios del valor del diccionario principal que se les pasa.

DESCRIPCIÓN

Los valores de diccionario de Tcl tienen una representación interna que soporta un mapeo eficiente de claves a valores y que garantiza que el orden particular de las claves dentro del diccionario se mantenga igual módulo las claves que se eliminan (lo que las elimina del orden) o se añaden (lo que las añade al final del orden). Si se reinterpretan como una lista, los valores en los índices de valor par de la lista serán las claves del diccionario, y cada uno estará seguido (en el índice de valor impar) por el valor asociado con esa clave.

Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde código C.

Tcl_NewDictObj crea un nuevo valor de diccionario vacío. La representación en cadena del valor será inválida, y el contador de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario dado y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o un NULL si la clave no tiene mapeo dentro del diccionario. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjPut actualiza el diccionario dado para que la clave dada mapee al valor dado; cualquier clave puede existir como máximo una vez en cualquier diccionario particular. El diccionario no debe ser compartido, pero la clave y el valor sí pueden serlo. Este procedimiento puede incrementar el contador de referencias de la clave y el valor si resulta necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjRemove actualiza el diccionario dado para que la clave dada no mapee a ningún valor. El diccionario no debe ser compartido, pero la clave sí puede serlo. La clave realmente almacenada en el diccionario tendrá su contador de referencias decrementado si estaba presente. No es un error si la clave no existía previamente. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario dado. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si el dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjFirst inicia una iteración sobre todos los pares clave/valor del diccionario dado, colocando la clave y el valor en las variables apuntadas por los argumentos keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que el llamante no está interesado en la clave o el valor respectivamente.) El siguiente par clave/valor del diccionario puede ser recuperado con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modificarán el procesamiento de la iteración a menos que el diccionario no esté compartido, momento en el cual esto activará la terminación prematura de la iteración (lo que los scripts de Tcl no pueden activar a través del comando dict.) El argumento searchPtr apunta a una parte del contexto que se utiliza para identificar qué iteración particular se está realizando, y se inicializa con la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero cuando hay más pares clave/valor para iterar, o a un valor distinto de cero si la iteración está completa. El orden de iteración no está definido por la implementación. Si el argumento dictPtr no puede ser convertido a un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y en caso contrario devuelve TCL_OK.

Cuando se llama a Tcl_DictObjFirst sobre un diccionario, se coloca un bloqueo en el diccionario para permitir que ese diccionario sea iterado de forma segura sin importar si el diccionario se modifica durante la iteración. Debido a esto, una vez que la iteración sobre las claves de un diccionario ha finalizado (ya sea porque se han iterado todos los valores, como se indica al establecerse a uno el valor de la variable indicada por el argumento donePtr, o porque no se requieren más valores), la función Tcl_DictObjDone debe ser llamada con el mismo searchPtr que se pasó a Tcl_DictObjFirst para que los bloqueos internos puedan ser liberados. Una vez que se pasa un searchPtr particular a Tcl_DictObjDone, pasarlo a Tcl_DictObjNext (sin inicializarlo primero con Tcl_DictObjFirst) resultará en que no se producirán valores y la variable apuntada por donePtr se establecerá en uno. Es seguro llamar a Tcl_DictObjDone varias veces en el mismo searchPtr por cada llamada a Tcl_DictObjFirst.

Los procedimientos Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son análogos a Tcl_DictObjPut y Tcl_DictObjRemove respectivamente, excepto que en lugar de trabajar con un solo diccionario, están diseñados para operar en un árbol anidado de diccionarios, con diccionarios internos almacenados como valores dentro de diccionarios externos. Los argumentos keyc y keyv especifican una lista de claves (con las claves más externas primero) que actúa como una ruta hacia el par clave/valor a afectar. NOMBRE

Tcl_DictObjGet

SINTAXIS

Tcl_DictObjGet(interp, objPtr, &search, key, value, done)

ARGUMENTOS

interp: puntero al intérprete Tcl

objPtr: puntero al objeto Tcl

search: puntero al objeto Tcl_DictObjSearch

key: puntero a Tcl_Obj

value: puntero a Tcl_Obj

done: puntero a entero

DESCRIPCIÓN

Mantiene toda la estructura del archivo.

EJEMPLO

Usando la interfaz de iteración de diccionarios para buscar si existe una clave que mapea a sí misma:

Tcl_DictSearch search;
    Tcl_Obj *key, *value;
    int done;
    /*
     * Asumir interp y objPtr son parámetros. Este es el
     * modo idiómático de iniciar una iteración sobre el diccionario; establece
     * un bloque en la representación interna que garantiza que no haya
     * modificaciones concurrentes cuando también se use la gestión de referencias
     * normal. El bloque se libera automáticamente al finalizar la iteración, pero
     * debe liberarse manualmente cuando se realice una salida excepcional de la
     * iteración. Sin embargo, es seguro intentar liberar el bloque incluso si hemos
     * terminado la iteración sobre el bloque.
     */
    if (Tcl_DictObjFirst(interp, objPtr, &search,
            &key, &value, &done) != TCL_OK) {
        return TCL_ERROR;
    }
    for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
        /*
         * Nota: strcmp() no es un buen modo de comparar valores y solo se usa
         * aquí para ilustración.
         */
        if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
            break;
        }
    }
    Tcl_DictObjDone(&search);
    Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
    return TCL_OK;
