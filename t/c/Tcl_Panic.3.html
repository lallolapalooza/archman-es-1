Tcl_Panic(3) Procedimientos de la biblioteca Tcl Tcl_Panic(3)

NOMBRE

Tcl_Panic, Tcl_PanicVA, Tcl_SetPanicProc - informar de un error fatal y abortar

SINOPSIS

#include <tcl.h>

void
Tcl_Panic(formato, arg, arg, ...)

void
Tcl_PanicVA(formato, lista_args)

void
Tcl_SetPanicProc(proc_panic)

ARGUMENTOS

const char* formato (entrada)
Una cadena de formato estilo printf.
arg (entrada)
Argumentos que coinciden con la cadena de formato.
va_list lista_args (entrada)
Una lista de argumentos que coinciden con la cadena de formato. Debe haber sido inicializada usando va_start y limpiada usando va_end.
Tcl_PanicProc *proc_panic (entrada)
Procedimiento para informar del mensaje de error fatal y abortar.

DESCRIPCIÓN

Cuando la biblioteca Tcl detecta que sus estructuras de datos internas están en un estado inconsistente, o que sus procedimientos C han sido llamados de una manera inconsistente con su documentación, llama a Tcl_Panic para mostrar un mensaje que describe el error y abortar el proceso. El argumento formato es una cadena de formato que describe cómo formatear los argumentos restantes arg en un mensaje de error, de acuerdo con las mismas reglas de formato utilizadas por la familia de funciones printf. Las mismas reglas de formato también son utilizadas por el comando Tcl integrado format.

En una biblioteca Tcl recién cargada, Tcl_Panic imprime el mensaje de error formateado en el flujo de error estándar del proceso y luego llama a abort para terminar el proceso. Tcl_Panic no regresa. En Windows, cuando se está ejecutando un depurador, el mensaje de error formateado se envía al depurador en su lugar. Si el ejecutable de Windows no tiene un canal de error estándar (por ejemplo, wish.exe), se utiliza un cuadro de diálogo del sistema para mostrar el mensaje de pánico.

Tcl_SetPanicProc puede ser utilizado para modificar el comportamiento de Tcl_Panic. El argumento proc_panic debe coincidir con el tipo Tcl_PanicProc:

typedef void Tcl_PanicProc(
        const char *formato,
        arg, arg,...);

Después de que Tcl_SetPanicProc regresa, cualquier llamada futura a Tcl_Panic llamará a proc_panic, pasando los argumentos formato y arg. proc_panic debe evitar hacer llamadas a la biblioteca Tcl, o a otras bibliotecas que puedan llamar a la biblioteca Tcl, ya que la llamada original a Tcl_Panic indica que la biblioteca Tcl no está en un estado de operación confiable.

El uso típico de Tcl_SetPanicProc organiza la visualización o el reporte del mensaje de error de una manera más adecuada para la aplicación o la plataforma.

Aunque los llamadores principales de Tcl_Panic son los procedimientos de la biblioteca Tcl, Tcl_Panic es una función pública y puede ser llamada por cualquier extensión o aplicación que desee abortar el proceso y que se muestre un mensaje de pánico de la misma manera que se mostrarán los mensajes de pánico de Tcl.

Tcl_PanicVA es lo mismo que Tcl_Panic excepto que en lugar de tomar un número variable de argumentos, toma una lista de argumentos.

VER TAMBIÉN
