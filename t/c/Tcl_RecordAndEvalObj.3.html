Tcl_RecordAndEvalObj(3) Procedimientos de la biblioteca Tcl Tcl_RecordAndEvalObj(3)

NOMBRE

Tcl_RecordAndEvalObj - guarda el comando en la lista de historial antes de evaluarlo

SINOPSIS

#include <tcl.h>

int
Tcl_RecordAndEvalObj(interp, cmdPtr, flags)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete de Tcl en el que evaluar el comando.
Tcl_Obj *cmdPtr (entrada)
Puntero a un valor Tcl que contiene un comando (o secuencia de comandos) a ejecutar.
int flags (entrada)
Combinación OR de bits de indicadores. TCL_NO_EVAL significa registrar el comando pero no evaluarlo. TCL_EVAL_GLOBAL significa evaluar el comando a nivel global en lugar del nivel de pila actual.

DESCRIPCIÓN

Se invoca a Tcl_RecordAndEvalObj para registrar un comando como un evento en la lista de historial y luego ejecutarlo usando Tcl_EvalObjEx (o Tcl_GlobalEvalObj si el bit TCL_EVAL_GLOBAL está establecido en flags). Devuelve un código de finalización como TCL_OK al igual que Tcl_EvalObjEx, así como un valor de resultado que contiene información adicional (un valor de resultado o un mensaje de error) que se puede recuperar usando Tcl_GetObjResult. Si no desea que el comando se registre en la lista de historial, debe invocar Tcl_EvalObjEx en lugar de Tcl_RecordAndEvalObj. Normalmente, solo se llama a Tcl_RecordAndEvalObj con comandos de nivel superior escritos por el usuario, ya que el propósito del historial es permitir al usuario volver a ejecutar comandos invocados recientemente. Si el argumento flags contiene el bit TCL_NO_EVAL, entonces el comando se registra sin ser evaluado.

VEASE TAMBIÉN

Tcl_EvalObjEx, Tcl_GetObjResult
