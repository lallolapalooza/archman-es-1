Tcl_CreateMathFunc(3) Tcl Library Procedures Tcl_CreateMathFunc(3)

NOMBRE

Tcl_CreateMathFunc, Tcl_GetMathFuncInfo, Tcl_ListMathFuncs - Define, consulta y enumera funciones matemáticas para expresiones

AVISO DE EVENTUAL OBSOLESCENCIA

Las funciones Tcl_CreateMathFunc y Tcl_GetMathFuncInfo quedan algo obsoletas por la capacidad de crear funciones para expresiones colocando comandos en el espacio de nombres tcl::mathfunc, como se describe en la página del manual mathfunc; no se espera que la API descrita en esta página se mantenga indefinidamente.

SINÓPSIS

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,
                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que se definirá la nueva función.
const char *name (entrada)
Nombre de la nueva función.
int numArgs (entrada)
Número de argumentos de la nueva función; también da el tamaño del array argTypes.
Tcl_ValueType *argTypes (entrada)
Punta a un array que da los tipos permitidos para cada argumento de la función.
Tcl_MathProc *proc (entrada)
Procedimiento que implementa la función.
ClientData clientData (entrada)
Valor arbitrario de una palabra para pasar a proc cuando se invoque.
int *numArgsPtr (salida)
Punta a una variable que se establecerá para contener el número de argumentos de la función.
Tcl_ValueType **argTypesPtr (salida)
Punta a una variable que se establecerá para contener un puntero a un array que da los tipos permitidos para cada argumento de la función, el cual deberá ser liberado usando Tcl_Free.
Tcl_MathProc **procPtr (salida)
Punta a una variable que se establecerá para contener un puntero al código de implementación de la función (o NULL si la función se implementa directamente en bytecode).
ClientData *clientDataPtr (salida)
Punta a una variable que se establecerá para contener el argumento clientData pasado a Tcl_CreateMathFunc cuando se creó la función si la función no se implementa directamente en bytecode.
const char *pattern (entrada)
Patrón para comparar con los nombres de las funciones para filtrarlas (pasando a Tcl_StringMatch), o NULL para no aplicar ningún filtro.

DESCRIPCIÓN

Tcl permite usar una serie de funciones matemáticas en expresiones, como sin, cos e hypot. Estas funciones se representan mediante comandos en el espacio de nombres tcl::mathfunc. La función Tcl_CreateMathFunc es una forma obsoleta para que las aplicaciones añadan funciones adicionales a las ya proporcionadas por Tcl o para reemplazar funciones existentes. No debe ser utilizada por aplicaciones nuevas, las cuales deben crear funciones matemáticas usando Tcl_CreateObjCommand para crear un comando en el espacio de nombres tcl::mathfunc.

En la interfaz Tcl_CreateMathFunc, Name es el nombre de la función tal como aparecerá en las expresiones. Si name no existe ya en el espacio de nombres ::tcl::mathfunc, se creará un nuevo comando en dicho espacio. Si name ya existe, se reemplazará la función existente. NumArgs y argTypes describen los argumentos de la función. Cada entrada en el array argTypes debe ser uno de TCL_INT, TCL_DOUBLE, TCL_WIDE_INT o TCL_EITHER para indicar si el argumento correspondiente debe ser un entero, un valor de punto flotante de doble precisión, un entero ancho (de 64 bits) o cualquiera, respectivamente.

Cada vez que la función se invoque en una expresión, Tcl invocará proc. Proc debe tener argumentos y resultado que coincidan con el tipo Tcl_MathProc:

typedef int Tcl_MathProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_Value *args,
        Tcl_Value *resultPtr);

Cuando se invoque proc, los argumentos clientData e interp serán los mismos que se pasaron a Tcl_CreateMathFunc. Args apuntará a un array de numArgs estructuras Tcl_Value, que describen los argumentos reales de la función:

typedef struct Tcl_Value {
    Tcl_ValueType type;
    long intValue;
    double doubleValue;
    Tcl_WideInt wideValue;
} Tcl_Value;

El campo type indica el tipo del argumento y es uno de TCL_INT, TCL_DOUBLE o TCL_WIDE_INT. Coincidirá con el valor argTypes especificado para la función, a menos que el valor argTypes fuera TCL_EITHER. Tcl convierte el argumento suministrado en la expresión al tipo solicitado en argTypes, si es necesario. Dependiendo del valor del campo type, el campo intValue, doubleValue o wideValue contendrá el valor real del argumento.

Proc debe calcular su resultado y almacenarlo como un entero en resultPtr->intValue o como un valor flotante en resultPtr->doubleValue. También debe establecer resultPtr->type a uno de TCL_INT, TCL_DOUBLE o TCL_WIDE_INT para indicar qué valor se estableció. En circunstancias normales, proc debería devolver TCL_OK. Si ocurre un error al ejecutar la función, proc debería devolver TCL_ERROR y dejar un mensaje de error en el resultado del intérprete.

Tcl_GetMathFuncInfo recupera los valores asociados con la función name que se pasaron a una llamada previa de Tcl_CreateMathFunc. Normalmente, el código de retorno es TCL_OK, pero si la función nombrada no existe, se devuelve TCL_ERROR y se coloca un mensaje de error en el resultado del intérprete.

Si no ocurrió ningún error, la referencia al array colocada en la variable apuntada por argTypesPtr es de asignación nueva y debe ser liberada pasándola a Tcl_Free. Algunas funciones (el conjunto estándar implementado en el núcleo, y aquellas definidas colocando comandos en el espacio de nombres tcl::mathfunc) no tienen información de tipo de argumento; intentar recuperar valores para ellas provoca que se almacene un NULL en la variable apuntada por procPtr y la variable apuntada por clientDataPtr no se modificará. La variable apuntada por numArgsPointer contendrá -1, y no se almacenarán tipos de argumento en la variable apuntada por argTypesPointer.

Tcl_ListMathFuncs devuelve un valor Tcl que contiene una lista de todas las funciones matemáticas definidas en el intérprete cuyo nombre coincide con pattern. El valor devuelto tiene un recuento de referencias de cero.

Tcl_ListMathFuncs(3)

Tcl_ListMathFuncs - lista las funciones de matemáticas disponibles en Tcl.

NOMBRE

Tcl_ListMathFuncs - lista las funciones de matemáticas disponibles en Tcl.

SINÓPSIS

#include <tcl.h>

int
Tcl_ListMathFuncs(interp, mathName)
    Tcl_Interp *interp;
    const char *mathName;

DESCRIPCIÓN

La función Tcl_ListMathFuncs se utiliza para obtener una lista de las funciones matemáticas disponibles en Tcl. La variable mathName especifica el nombre de la biblioteca de matemáticas de la que se deben listar las funciones. Si mathName es NULL o una cadena vacía, se listarán todas las funciones matemáticas disponibles.

El resultado de la llamada a la función se almacena en la variable de resultado del intérprete interp. Si la operación tiene éxito, la variable de resultado contendrá una lista de cadenas, donde cada cadena es el nombre de una función matemática disponible. Si ocurre un error, la variable de resultado contendrá una cadena de error.
