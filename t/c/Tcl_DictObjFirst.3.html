ARGUMENTOS

Tcl_Interp *interp (entrada)
Si ocurre un error al convertir un valor para que sea un valor de diccionario, se deja un mensaje de error en el valor resultante del intérprete a menos que interp sea NULL.
Tcl_Obj *dictPtr (entrada/salida)
Punta al valor del diccionario que se va a manipular. Si dictPtr no apunta ya a un valor de diccionario, se intentará convertirlo en uno.
Tcl_Obj *keyPtr (entrada)
Punta a la clave para el par clave/valor que se está manipulando dentro del valor del diccionario.
Tcl_Obj **keyPtrPtr (salida)
Punta a una variable a la que se colocará la clave de un par clave/valor. Puede ser NULL para indicar que al llamante no le interesa la clave.
Tcl_Obj *valuePtr (entrada)
Punta al valor del par clave/valor que se está manipulando dentro del valor del diccionario (o subvalor, en el caso de Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (salida)
Punta a una variable a la que se colocará el valor de un par clave/valor. Para Tcl_DictObjFirst y Tcl_DictObjNext, esto puede ser NULL para indicar que al llamante no le interesa el valor.
int *sizePtr (salida)
Punta a una variable en la que se colocará el número de pares clave/valor contenidos en el diccionario.
Tcl_DictSearch *searchPtr (entrada/salida)
Puntero a la estructura a utilizar para mantener el seguimiento del progreso en la enumeración de todos los pares clave/valor en un diccionario. El contenido de la estructura será inicializado por la llamada a Tcl_DictObjFirst. Si la enumeración debe ser terminada antes de que se devuelvan todos los valores del diccionario, el registro de búsqueda *debe* ser pasado a Tcl_DictObjDone para permitir la liberación de los bloqueos internos.
int *donePtr (salida)
Punta a una variable a la que se escribirá un valor distinto de cero cuando se complete la enumeración de los pares clave/valor en un diccionario, y cero en caso contrario.
int keyc (entrada)
Indica el número de claves que se proporcionarán en el array keyv.
Tcl_Obj *const *keyv (entrada)
Array de keyc punteros a valores que Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList usarán para localizar el par clave/valor a manipular dentro de los subdiccionarios del valor de diccionario principal que se les pasa.

DESCRIPCIÓN

Los valores de diccionario Tcl tienen una representación interna que admite un mapeo eficiente de claves a valores y que garantiza que el orden particular de las claves dentro del diccionario se mantiene igual módulo las claves que se eliminan (lo que las elimina del orden) o se añaden (lo que las añade al final del orden). Si se reinterpretan como una lista, los valores en los índices pares de la lista serán las claves del diccionario, y cada uno será seguido (en el índice impar) por el valor asociado con esa clave.

Los procedimientos descritos en esta página de manual se utilizan para crear, modificar, indexar e iterar sobre valores de diccionario desde código C.

Tcl_NewDictObj crea un nuevo valor de diccionario vacío. La representación en cadena del valor será inválida y el contador de referencias del valor será cero.

Tcl_DictObjGet busca la clave dada dentro del diccionario dado y escribe un puntero al valor asociado con esa clave en la variable apuntada por valuePtrPtr, o NULL si la clave no tiene un mapeo dentro del diccionario. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjPut actualiza el diccionario dado de manera que la clave dada mapee al valor dado; cada clave puede existir como máximo una vez en cualquier diccionario particular. El diccionario no debe ser compartido, pero la clave y el valor sí pueden serlo. Este procedimiento puede incrementar el contador de referencias tanto de la clave como del valor si resulta necesario almacenarlos. Ni la clave ni el valor deben ser NULL. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjRemove actualiza el diccionario dado de manera que la clave dada no tenga mapeo a ningún valor. El diccionario no debe ser compartido, pero la clave sí puede serlo. La clave realmente almacenada en el diccionario tendrá su contador de referencias decrementado si existía previamente. No es un error si la clave no existía previamente. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjSize actualiza la variable dada con el número de pares clave/valor actualmente en el diccionario dado. El resultado de este procedimiento es TCL_OK, o TCL_ERROR si dictPtr no puede ser convertido a un diccionario.

Tcl_DictObjFirst inicia una iteración sobre todos los pares clave/valor en el diccionario dado, colocando la clave y el valor en las variables apuntadas por los argumentos keyPtrPtr y valuePtrPtr (que pueden ser NULL para indicar que al llamante no le interesa la clave o el valor respectivamente.) El siguiente par clave/valor en el diccionario puede ser recuperado con Tcl_DictObjNext. Las actualizaciones concurrentes de la representación interna del diccionario no modificarán el procesamiento de la iteración a menos que el diccionario no esté compartido, en cuyo caso esto desencadenará la terminación prematura de la iteración (lo cual los scripts de Tcl no pueden desencadenar a través del comando dict.) El argumento searchPtr apunta a un contexto que se utiliza para identificar qué iteración particular se está realizando, y se inicializa con la llamada a Tcl_DictObjFirst. El argumento donePtr apunta a una variable que se actualiza a cero si hay más pares clave/valor para iterar, o a un valor distinto de cero si la iteración está completa. El orden de iteración está definido por la implementación. Si el argumento dictPtr no puede ser convertido a un diccionario, Tcl_DictObjFirst devuelve TCL_ERROR y la iteración no se inicia, y en caso contrario devuelve TCL_OK.

Cuando se llama a Tcl_DictObjFirst en un diccionario, se coloca un bloqueo en el diccionario para permitir que dicho diccionario sea iterado de forma segura sin tener en cuenta si el diccionario se modifica durante la iteración. Debido a esto, una vez que finaliza la iteración sobre las claves de un diccionario (ya sea porque se han iterado todos los valores como lo indica la variable apuntada por el argumento donePtr al ser establecida a uno, o porque no se requieren más valores), la función Tcl_DictObjDone debe ser llamada con el mismo searchPtr que se pasó a Tcl_DictObjFirst para que los bloqueos internos puedan ser liberados. Una vez que un searchPtr particular es pasado a Tcl_DictObjDone, pasarlo a Tcl_DictObjNext (sin inicializarlo primero con Tcl_DictObjFirst) resultará en que no se produzcan valores y que la variable apuntada por donePtr se establezca a uno. Es seguro llamar a Tcl_DictObjDone múltiples veces en el mismo searchPtr por cada llamada a Tcl_DictObjFirst.

Los procedimientos Tcl_DictObjPutKeyList y Tcl_DictObjRemoveKeyList son análogos a Tcl_DictObjPut y Tcl_DictObjRemove respectivamente, excepto que en lugar de trabajar con un solo diccionario, están diseñados para operar en un árbol anidado de diccionarios, con diccionarios internos almacenados como valores dentro de diccionarios externos. Los argumentos keyc y keyv especifican una lista de claves (con las claves más externas primero) que actúa como una ruta hacia el par clave/valor a ser afectado. Tcl_DictObjFirst(3) - Arch Linux

NAME

Tcl_DictObjFirst, Tcl_DictObjNext, Tcl_DictObjNextKey, Tcl_DictObjDone - iterate over a dictionary object

SYNOPSIS

#include <tcl.h>

int
Tcl_DictObjFirst(interp, dictPtr, searchPtr, keyPtr, valuePtr, donePtr);
int
Tcl_DictObjNext(searchPtr, keyPtr, valuePtr, donePtr);
int
Tcl_DictObjNextKey(searchPtr, keyPtr, donePtr);
void
Tcl_DictObjDone(searchPtr);

ARGUMENTS

Tcl_Interp *interp (in)
Interpreter to use for error reporting. If NULL, no error reporting is done.
Tcl_Obj *dictPtr (in)
Points to the dictionary object to iterate over.
Tcl_DictSearch *searchPtr (in/out)
Points to a Tcl_DictSearch structure that will be initialized by Tcl_DictObjFirst and updated by Tcl_DictObjNext and Tcl_DictObjNextKey. The structure is used to keep track of the iteration state.
Tcl_Obj **keyPtr (out)
Points to a location that will hold a pointer to the key object for the current dictionary element. The pointer is valid until the next call to Tcl_DictObjNext or Tcl_DictObjNextKey, or until Tcl_DictObjDone is called.
Tcl_Obj **valuePtr (out)
Points to a location that will hold a pointer to the value object for the current dictionary element. This argument is ignored by Tcl_DictObjNextKey. The pointer is valid until the next call to Tcl_DictObjNext or Tcl_DictObjNextKey, or until Tcl_DictObjDone is called.
int *donePtr (out)
Points to a location that will be set to non-zero when the iteration is finished, and zero otherwise.

DESCRIPTION

These functions provide an interface for iterating over the key-value pairs of a dictionary object. A dictionary object is represented by a Tcl_Obj with type TCL_DDROBJECT. Dictionaries are implemented internally as hash tables.

The iteration starts by calling Tcl_DictObjFirst. This function initializes the Tcl_DictSearch structure pointed to by searchPtr and returns the first key-value pair in the dictionary. The key and value are returned as pointers to Tcl_Obj structures, which are not duplicated. The caller must not modify these objects directly. The donePtr argument is set to non-zero if the dictionary is empty.

Subsequent elements are retrieved by calling Tcl_DictObjNext or Tcl_DictObjNextKey. Tcl_DictObjNext returns the next key-value pair, while Tcl_DictObjNextKey returns only the next key. Both functions update the keyPtr, valuePtr (for Tcl_DictObjNext), and donePtr arguments. The key and value pointers are valid until the next iteration step or until Tcl_DictObjDone is called.

When the iteration is complete, or if an error occurs during iteration, Tcl_DictObjDone must be called with the searchPtr argument. This function releases any internal resources associated with the iteration. If the iteration was started with a NULL interpreter and exited prematurely without calling Tcl_DictObjDone, the internal representation of the dictionary may be left in a locked state.

The iteration order is not guaranteed. However, the order is stable for a given dictionary object as long as the object is not modified during the iteration. If the dictionary is modified during iteration, the behavior is undefined, but typically results in an error or an incomplete iteration.

Note that the key and value pointers returned by the iteration functions point to objects that are owned by the dictionary. The caller must not modify these objects. If modifications are needed, the caller should create new objects using the returned pointers as input.

The dictionary iteration interface is designed to work correctly with nested dictionaries and key lists. For example, Tcl_DictObjPutKeyList and Tcl_DictObjRemoveKeyList can be used to manipulate nested dictionaries.

With Tcl_DictObjPutKeyList, nested dictionaries are created for non-terminal keys where they do not already exist. With Tcl_DictObjRemoveKeyList, all non-terminal keys must exist and have dictionaries as their values.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters.  This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used.  The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
