Tcl_SetVar(3) Procedimientos de la biblioteca Tcl Tcl_SetVar(3)

NOMBRE

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2, Tcl_ObjSetVar2, Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2, Tcl_ObjGetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 - manipular variables de Tcl

SINOPSIS

#include <tcl.h>

Tcl_Obj *
Tcl_SetVar2Ex(interp, name1, name2, newValuePtr, flags)

const char *
Tcl_SetVar(interp, varName, newValue, flags)

const char *
Tcl_SetVar2(interp, name1, name2, newValue, flags)

Tcl_Obj *
Tcl_ObjSetVar2(interp, part1Ptr, part2Ptr, newValuePtr, flags)

Tcl_Obj *
Tcl_GetVar2Ex(interp, name1, name2, flags)

const char *
Tcl_GetVar(interp, varName, flags)

const char *
Tcl_GetVar2(interp, name1, name2, flags)

Tcl_Obj *
Tcl_ObjGetVar2(interp, part1Ptr, part2Ptr, flags)

int
Tcl_UnsetVar(interp, varName, flags)

int
Tcl_UnsetVar2(interp, name1, name2, flags)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete que contiene la variable.
const char *name1 (entrada)
Contiene el nombre de una variable de matriz (si name2 es no-NULL) o (si name2 es NULL) el nombre de una variable escalar o un nombre completo que incluye tanto el nombre de la variable como el índice. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular.
const char *name2 (entrada)
Si no es NULL, proporciona el nombre del elemento dentro de la matriz; en este caso, name1 debe hacer referencia a una variable de matriz.
Tcl_Obj *newValuePtr (entrada)
Puntero a un valor Tcl que contiene el nuevo valor para la variable.
int flags (entrada)
Combinación OR de bits que proporcionan información adicional. Ver más abajo los valores válidos.
const char *varName (entrada)
Nombre de la variable. Puede incluir calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede hacer referencia a una variable escalar o a un elemento de una matriz.
const char *newValue (entrada)
Nuevo valor para la variable, especificado como una cadena terminada en nulo. Se almacena una copia de este valor en la variable.
Tcl_Obj *part1Ptr (entrada)
Puntero a un valor Tcl que contiene el nombre de la variable. El nombre puede incluir una serie de calificadores de espacio de nombres :: para especificar una variable en un espacio de nombres particular. Puede hacer referencia a una variable escalar o a un elemento de una variable de matriz.
Tcl_Obj *part2Ptr (entrada)
Si no es NULL, apunta a un valor que contiene el nombre de un elemento dentro de una matriz y part1Ptr debe hacer referencia a una variable de matriz.

DESCRIPCIÓN

Estos procedimientos se utilizan para crear, modificar, leer y eliminar variables de Tcl desde código C.

Tcl_SetVar2Ex, Tcl_SetVar, Tcl_SetVar2 y Tcl_ObjSetVar2 crearán una nueva variable o modificarán una existente. Estos procedimientos establecen la variable dada al valor proporcionado por newValuePtr o newValue y devuelven un puntero al nuevo valor de la variable, que se almacena en la estructura de variables de Tcl. Tcl_SetVar2Ex y Tcl_ObjSetVar2 toman el nuevo valor como un Tcl_Obj y devuelven un puntero a un Tcl_Obj. Tcl_SetVar y Tcl_SetVar2 toman el nuevo valor como una cadena y devuelven una cadena; generalmente son menos eficientes que Tcl_ObjSetVar2. Tenga en cuenta que el valor de retorno puede ser diferente del argumento newValuePtr o newValue, debido a las modificaciones realizadas por los rastreos de escritura. Si ocurre un error al establecer la variable (por ejemplo, se hace referencia a una variable de matriz sin proporcionar un índice a la matriz), se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de indicación TCL_LEAVE_ERR_MSG está establecido.

Tcl_GetVar2Ex, Tcl_GetVar, Tcl_GetVar2 y Tcl_ObjGetVar2 devuelven el valor actual de una variable. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos descritos anteriormente. En circunstancias normales, el valor de retorno es un puntero al valor de la variable. Para Tcl_GetVar2Ex y Tcl_ObjGetVar2 el valor se devuelve como un puntero a un Tcl_Obj. Para Tcl_GetVar y Tcl_GetVar2 el valor se devuelve como una cadena; esto suele ser menos eficiente, por lo que se prefiere Tcl_GetVar2Ex o Tcl_ObjGetVar2. Si ocurre un error al leer la variable (por ejemplo, la variable no existe o se especifica un elemento de matriz para una variable escalar), entonces se devuelve NULL y se deja un mensaje de error en el resultado de interp si el bit de indicación TCL_LEAVE_ERR_MSG está establecido.

Tcl_UnsetVar y Tcl_UnsetVar2 se pueden utilizar para eliminar una variable, de modo que los intentos futuros de leer la variable devuelvan un error. Los argumentos a estos procedimientos se tratan de la misma manera que los argumentos a los procedimientos anteriores. Si la variable se elimina correctamente, se devuelve TCL_OK. Si la variable no se puede eliminar porque no existe, se devuelve TCL_ERROR y se deja un mensaje de error en el resultado de interp si el bit de indicación TCL_LEAVE_ERR_MSG está establecido. Si se especifica un elemento de matriz, se elimina el elemento dado pero la matriz permanece. Si se especifica un nombre de matriz sin índice, se elimina toda la matriz.

El nombre de una variable se puede especificar a estos procedimientos de cuatro maneras:

[1]
Si se invoca Tcl_SetVar, Tcl_GetVar o Tcl_UnsetVar, el nombre de la variable se proporciona como una sola cadena, varName. Si varName contiene un paréntesis de apertura y termina con un paréntesis de cierre, entonces el valor entre los paréntesis se trata como un índice (que puede tener cualquier valor de cadena) y los caracteres antes del primer paréntesis de apertura se tratan como el nombre de una variable de matriz. Si varName no tiene paréntesis como se describe anteriormente, entonces toda la cadena se trata como el nombre de una variable escalar.
[2]
Si se proporcionan los argumentos name1 y name2 y name2 no es NULL, entonces se especifica un elemento de matriz y el nombre de la matriz y el índice ya han sido separados por el llamador: name1 contiene el nombre y name2 contiene el índice. Se genera un error si name1 contiene un paréntesis de apertura y termina con un paréntesis de cierre (elemento de matriz) y name2 no es NULL.
[3]
Si name2 es NULL, name1 se trata igual que varName en el caso [1] anterior (puede ser el nombre de una variable escalar o de un elemento de matriz).

El argumento flags se puede utilizar para especificar cualquiera de varias opciones para los procedimientos. Consiste en una combinación OR de los siguientes bits.

TCL_GLOBAL_ONLY
En circunstancias normales, los procedimientos buscan variables de la siguiente manera. Si una llamada a procedimiento está activa en interp, la variable se busca en el nivel actual de llamada a procedimiento. De lo contrario, la variable se busca primero en el espacio de nombres actual, luego en el espacio de nombres global. Sin embargo, si este bit está establecido en flags, la variable se busca solo en el espacio de nombres global, incluso si hay una llamada a procedimiento activa. Si se proporcionan tanto TCL_GLOBAL_ONLY como TCL_NAMESPACE_ONLY, se ignora TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
Si este bit está establecido en flags, la variable se busca solo en el espacio de nombres actual; si un procedimiento está activo, sus variables se ignoran, y el espacio de nombres global también se ignora a menos que sea el espacio de nombres actual.
TCL_LEAVE_ERR_MSG
Si se devuelve un error y este bit está establecido en flags, se dejará un mensaje de error en el resultado del intérprete, donde se puede recuperar con Tcl_GetObjResult o Tcl_GetStringResult. Si este bit de indicación no está establecido, no se deja ningún mensaje de error y el resultado del intérprete no se modificará.
TCL_APPEND_VALUE
Si este bit está establecido, entonces newValuePtr o newValue se anexa al valor actual en lugar de reemplazarlo. Si la variable no está definida actualmente, el bit se ignora. Este bit solo es utilizado por los procedimientos Tcl_Set*.
TCL_LIST_ELEMENT
Si este bit está establecido, entonces newValue se convierte en un elemento de lista Tcl válido antes de establecer (o anexar a) la variable. Se anexa un espacio separador antes del nuevo

Tcl_UnsetVar2(3) — Tcl

NAME

Tcl_SetVar, Tcl_SetVar2, Tcl_GetVar, Tcl_GetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 — get and set values of Tcl variables

SYNOPSIS

#include <tcl.h>

int
Tcl_SetVar(interp, varName, newValue, flags);
int
Tcl_SetVar2(interp, name1, name2, newValue, flags);
char *
Tcl_GetVar(interp, varName, flags);
char *
Tcl_GetVar2(interp, name1, name2, flags);
int
Tcl_UnsetVar(interp, varName, flags);
int
Tcl_UnsetVar2(interp, name1, name2, flags);

ARGUMENTS

Tcl_Interp *interp
Interpreter in which to operate.
const char *varName
Name of the variable. This can be a simple name like “x” or an array element like “a(i)”.
const char *name1
For Tcl_SetVar2 and Tcl_GetVar2, this is the first part of the variable name. If the variable is not an array element, then name2 must be NULL and name1 contains the full variable name. If the variable is an array element, then name1 contains the array name and name2 contains the index.
const char *name2
For Tcl_SetVar2 and Tcl_GetVar2, this is the second part of the variable name (the index if it is an array element). If the variable is not an array element, then name2 must be NULL.
const char *newValue
The new value to store in the variable. This must be a null-terminated string.
int flags
A bitmask that controls how the variable is accessed. It can be “or”-ed with any of the following bits:
TCL_GLOBAL_ONLY
If set, the variable is looked up in the global scope, even if the command is executed in a nested procedure. If not set, the variable is looked up in the current scope (global or local) unless it is written as “::varName”.
TCL_LEAVE_ERR_MSG
If set, then error messages are left in the interpreter’s result if an error occurs. If not set, then the interpreter’s result is cleared if an error occurs.
TCL_APPEND_VALUE
If set, the newValue is appended to the existing value of the variable. If the variable does not exist, it is created with the value newValue. If the variable exists and is not an array element, its value is updated by appending newValue. If the variable exists and is an array element, then the value is updated by appending newValue. When appending, the original value of the variable must be a valid list, so that the operation is the appending of a new list element onto a list.
Tcl_LIST_APPEND
If set, this is a synonym for TCL_APPEND_VALUE.
TCL_LIST_INSERT
If set, the newValue is inserted into the list stored in the variable. If the variable does not exist, it is created with the value newValue. If the variable exists and is not an array element, then newValue is inserted into the list stored in the variable. If the variable exists and is an array element, then newValue is inserted into the list stored in the array element. The insertion point depends on the value of newValue. If newValue is the empty string, nothing happens. If newValue is “{”, then the newValue is inserted as the first element. If newValue ends with “}”, then newValue is inserted as the last element. Otherwise, newValue is inserted as the first element unless the list element is going to be the first element in a list or sublist (i.e. the variable’s current value is empty, or contains the single character “{”, or ends in “}”). When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.

DESCRIPTION

Tcl_SetVar and Tcl_SetVar2 are used to set the value of a Tcl variable. They are the C API equivalents of the Tcl commands set and lappend. The variable is specified by varName in Tcl_SetVar, or by name1 and name2 in Tcl_SetVar2. name1 and name2 are used to specify array elements, e.g. Tcl_SetVar2(interp, "a", "i", "5", 0) sets the array element a(i) to “5”. If the variable is not an array element, name2 must be NULL. The newValue is the value to store in the variable. The flags argument controls how the value is set. TCL_GLOBAL_ONLY forces the variable to be set in the global scope. TCL_LEAVE_ERR_MSG causes error messages to be left in the interpreter result on error. TCL_APPEND_VALUE appends the newValue to the existing value of the variable. TCL_LIST_INSERT inserts the newValue into the list stored in the variable. If the variable does not exist, it is created with the value newValue. If the variable exists and is not an array element, then newValue is inserted into the list stored in the variable. If the variable exists and is an array element, then newValue is inserted into the list stored in the array element. The insertion point depends on the value of newValue. If newValue is the empty string, nothing happens. If newValue is “{”, then the newValue is inserted as the first element. If newValue ends with “}”, then newValue is inserted as the last element. Otherwise, newValue is inserted as the first element unless the list element is going to be the first element in a list or sublist (i.e. the variable's current value is empty, or contains the single character “{”, or ends in “}”). When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.

Tcl_GetVar and Tcl_GetVar2 return the current value of a variable. The arguments to these procedures are treated in the same way as the arguments to Tcl_SetVar and Tcl_SetVar2. Under normal circumstances, the return value is a pointer to the variable's value (which is stored in Tcl's variable structure and will not change before the next call to Tcl_SetVar or Tcl_SetVar2). Tcl_GetVar and Tcl_GetVar2 use the flag bits TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG, both of which have the same meaning as for Tcl_SetVar. If an error occurs in reading the variable (e.g. the variable does not exist or an array element is specified for a scalar variable), then NULL is returned.

Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a variable, so that future calls to Tcl_GetVar or Tcl_GetVar2 for the variable will return an error. The arguments to these procedures are treated in the same way as the arguments to Tcl_GetVar and Tcl_GetVar2. If the variable is successfully removed then TCL_OK is returned. If the variable cannot be removed because it does not exist then TCL_ERROR is returned. If an array element is specified, the given element is removed but the array remains. If an array name is specified without an index, then the entire array is removed.
