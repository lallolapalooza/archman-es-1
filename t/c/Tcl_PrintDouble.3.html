Tcl_PrintDouble(3)

Paquete: tcl

Licencias: TCL

Tcl_PrintDouble(3) Procedimientos de la biblioteca Tcl Tcl_PrintDouble(3)

NOMBRE

Tcl_PrintDouble - Convertir valor flotante a cadena

SINOPSIS

#include <tcl.h>

Tcl_PrintDouble(interp, value, dst)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Antes de Tcl 8.0, la variable tcl_precision en este intérprete controlaba la conversión. A partir de Tcl 8.0, este argumento se ignora y la conversión se controla mediante la variable tcl_precision, que ahora es compartida por todos los intérpretes.
double value (entrada)
Valor de punto flotante a convertir.
char *dst (salida)
Dónde almacenar la cadena que representa value. Debe tener al menos TCL_DOUBLE_SPACE caracteres de espacio.

DESCRIPCIÓN

Tcl_PrintDouble genera una cadena que representa el valor de value y la almacena en memoria en la ubicación indicada por dst. Utiliza el formato %g para generar la cadena, con un giro especial: la cadena se garantiza que contendrá un punto “.” o una “e” para que no parezca un entero. Donde %g generaría un entero sin punto decimal, Tcl_PrintDouble añade “.0”.

Si el valor de tcl_precision no es cero, el resultado tendrá exactamente esa cantidad de dígitos de significación. Si el valor es cero (por defecto), el resultado tendrá el menor número de dígitos necesario para representar el número de forma que Tcl_NewDoubleObj genere el mismo número al recibir la cadena dada. Se aplican las semánticas IEEE de redondeo a par en la conversión.

PALABRAS CLAVE

conversión, doble precisión, punto flotante, cadena
