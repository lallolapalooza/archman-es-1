Tcl_DeleteCloseHandler(3)

Paquete: tcl

Licencias: TCL

Tcl_CreateCloseHandler(3) Procedimientos de la biblioteca Tcl Tcl_CreateCloseHandler(3)

NOMBRE

Tcl_CreateCloseHandler, Tcl_DeleteCloseHandler - organizar devoluciones de llamada cuando los canales se cierran

SINOPSIS

#include <tcl.h>

void
Tcl_CreateCloseHandler(channel, proc, clientData)

void
Tcl_DeleteCloseHandler(channel, proc, clientData)

ARGUMENTOS

Tcl_Channel channel (entrada)
El canal para el cual crear o eliminar una devolución de llamada de cierre.
Tcl_CloseProc *proc (entrada)
El procedimiento a llamar como devolución de llamada.
ClientData clientData (entrada)
Valor arbitrario de una palabra para pasar a proc.

DESCRIPCIÓN

Tcl_CreateCloseHandler organiza que se llame a proc cuando channel se cierre con Tcl_Close o Tcl_UnregisterChannel, o utilizando el comando Tcl close. Proc debe coincidir con el siguiente prototipo:

typedef void Tcl_CloseProc(
        ClientData clientData);

El clientData es el mismo que el valor proporcionado en la llamada a Tcl_CreateCloseHandler.

Tcl_DeleteCloseHandler elimina una devolución de llamada de cierre para channel. Los argumentos proc y clientData identifican qué devolución de llamada de cierre eliminar; Tcl_DeleteCloseHandler no hace nada si sus argumentos proc y clientData no coinciden con el proc y clientData de un gestor de cierre para channel.

VER TAMBIÉN

close(n), Tcl_Close(3), Tcl_UnregisterChannel(3)

PALABRAS CLAVE

callback, cierre de canal
