ARGUMENTOS

Tcl_Interp *interp (entrada/salida)
El intérprete en el que se creará o encontrará el conjunto. También donde se escriben los mensajes de resultado de error. Las funciones cuyos nombres comienzan con Tcl_GetEnsemble pueden tener un valor NULL para interp, pero todas las demás funciones no deben tenerlo.
const char *name (entrada)
El nombre del comando de conjunto a crear.
Tcl_Namespace *namespacePtr (entrada)
El espacio de nombres al que se vinculará el comando de conjunto, o NULL para el espacio de nombres actual.
int ensFlags (entrada)
Un conjunto OR de bits de flags que describen la configuración básica del conjunto. Actualmente, solo un bit tiene significado, TCL_ENSEMBLE_PREFIX, que está presente cuando el comando de conjunto también debe coincidir con prefijos no ambiguos de subcomandos.
Tcl_Obj *cmdNameObj (entrada)
Un valor que contiene el nombre del comando de conjunto a buscar.
int flags (entrada)
Un conjunto OR de bits de flags que controlan el comportamiento de Tcl_FindEnsemble. Actualmente, solo se admite TCL_LEAVE_ERR_MSG.
Tcl_Command token (entrada)
Un token de comando normal que se refiere a un comando de conjunto, o que desea utilizar para pruebas como comando de conjunto en Tcl_IsEnsemble.
int *ensFlagsPtr (salida)
Puntero a una variable en la que escribir los bits de flags actuales del conjunto; actualmente, solo se define el bit TCL_ENSEMBLE_PREFIX.
Tcl_Obj *dictObj (entrada)
Un valor de diccionario para usar en el subcomando para el mapeo del prefijo del comando de implementación en el diccionario del conjunto. Puede ser NULL si el diccionario de mapeo debe eliminarse.
Tcl_Obj **dictObjPtr (salida)
Puntero a una variable en la que escribir el diccionario de mapeo actual del conjunto.
Tcl_Obj *listObj (entrada)
Un valor de lista para usar en la lista de parámetros formales pre-subcomando, la lista definida de subcomandos en el diccionario o el prefijo del comando del manejador de subcomandos desconocidos. Puede ser NULL si la lista de subcomandos o el manejador de subcomandos desconocidos van a ser eliminados.
Tcl_Obj **listObjPtr (salida)
Puntero a una variable en la que escribir la lista actual de parámetros formales pre-subcomando, la lista definida de subcomandos o el prefijo actual del manejador de subcomandos desconocidos.
Tcl_Namespace **namespacePtrPtr (salida)
Puntero a una variable en la que escribir el manejador del espacio de nombres al que está vinculado el conjunto.

DESCRIPCIÓN

Un conjunto es un comando, vinculado a algún espacio de nombres, que consiste en una colección de subcomandos implementados por otros comandos de Tcl. El primer argumento al comando de conjunto se interpreta siempre como un selector que indica qué subcomando ejecutar.

Los conjuntos se crean utilizando Tcl_CreateEnsemble, que toma cuatro argumentos: el intérprete en el que trabajar, el nombre del conjunto a crear, el espacio de nombres dentro del intérprete al que vincular el conjunto y el conjunto de flags predeterminados del conjunto. El resultado de la función es el token del comando para el conjunto, que puede usarse para configurar aún más el conjunto utilizando la API descrita a continuación en PROPIEDADES DEL CONJUNTO.

Dado el nombre de un comando de conjunto, el token de ese comando puede obtenerse utilizando Tcl_FindEnsemble. Si el nombre de comando dado (en cmdNameObj) no se refiere a un comando de conjunto, el resultado de la función es NULL y (si el bit TCL_LEAVE_ERR_MSG está establecido en flags) se deja un mensaje de error en el resultado del intérprete.

Un token de comando puede comprobarse para ver si se refiere a un conjunto utilizando Tcl_IsEnsemble. Esto devuelve 1 si el token se refiere a un conjunto, o 0 en caso contrario.

PROPIEDADES DEL CONJUNTO

Cada conjunto tiene cuatro propiedades de lectura/escritura y una propiedad de solo lectura. Las propiedades son:

flags (lectura/escritura)
El conjunto de flags para el conjunto, expresado como un campo de bits. Actualmente, el único flag público es TCL_ENSEMBLE_PREFIX, que se establece cuando se permiten prefijos no ambiguos de subcomandos para ser resueltos a implementaciones, así como coincidencias exactas. Los flags pueden leerse y escribirse utilizando Tcl_GetEnsembleFlags y Tcl_SetEnsembleFlags respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto).
diccionario de mapeo (lectura/escritura)
Un diccionario que contiene un mapeo de nombres de subcomandos a listas de palabras para usar como prefijo de comando (reemplazando las dos primeras palabras del comando que son el comando de conjunto y el nombre del subcomando), o NULL si cada subcomando debe mapearse al comando con el mismo nombre no calificado en el espacio de nombres vinculado del conjunto. Por defecto es NULL. Puede leerse y escribirse utilizando Tcl_GetEnsembleMappingDict y Tcl_SetEnsembleMappingDict respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleMappingDict siempre debe tratarse como inmutable, incluso si no está compartido. Todos los nombres de comandos en los prefijos establecidos a través de Tcl_SetEnsembleMappingDict deben estar completamente calificados.
lista formal de parámetros pre-subcomando (lectura/escritura)
Una lista de nombres de parámetros formales (los nombres solo se usan al generar mensajes de error) que vienen en la invocación del conjunto entre el nombre del conjunto y el argumento del subcomando. NULL (el valor predeterminado) es equivalente a la lista vacía. Puede leerse y escribirse utilizando Tcl_GetEnsembleParameterList y Tcl_SetEnsembleParameterList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y el diccionario obtenido de Tcl_GetEnsembleParameterList siempre debe tratarse como inmutable, incluso si no está compartido.
lista de subcomandos (lectura/escritura)
Una lista de todos los nombres de subcomandos para el conjunto, o NULL si esto debe derivarse de las claves del diccionario de mapeo (ver arriba) o (si también es NULL) del conjunto de comandos exportados por el espacio de nombres vinculado. Puede leerse y escribirse utilizando Tcl_GetEnsembleSubcommandList y Tcl_SetEnsembleSubcommandList respectivamente. El resultado de ambas funciones es un código de resultado Tcl (TCL_OK, o TCL_ERROR si el token no se refiere a un conjunto) y la lista obtenida de Tcl_GetEnsembleSubcommandList siempre debe tratarse como inmutable, incluso si no está compartido.
prefijo de comando del manejador de subcomando desconocido (lectura/escritura)
