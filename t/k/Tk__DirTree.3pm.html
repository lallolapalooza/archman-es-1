DirTree(3pm) Documentación de Perl aportada por el usuario DirTree(3pm)

NOMBRE

Tk::DirTree - Crear y manipular widgets DirTree

SINOPSIS

    use Tk::DirTree;

    $dirtree = $parent->DirTree(?opciones?);

SUPER-CLASE

La clase DirTree se deriva de la clase Tree y hereda todos los métodos, opciones y subwidgets de su super-clase.

OPCIONES ESTÁNDAR

Tree soporta todas las opciones estándar de un widget Tree. Consulte Tk::options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: browseCmd
Clase: BrowseCmd
Interruptor: -browsecmd
Especifica una devolución de llamada para invocar cada vez que el usuario navega por un directorio (normalmente haciendo clic una vez en el nombre del directorio). La devolución de llamada se invoca con un argumento, la ruta completa del directorio.
Nombre: command
Clase: Command
Interruptor: -command
Especifica la devolución de llamada que se invocará cuando el usuario active un directorio (normalmente haciendo doble clic en el nombre del directorio). La devolución de llamada se invoca con un argumento, la ruta completa del directorio.
Nombre: dircmd
Clase: DirCmd
Interruptor: -dircmd
Especifica la devolución de llamada que se invocará cuando se necesite una lista de directorios para un directorio particular. Si esta opción no se especifica, por defecto el widget DirTree intentará leer el directorio como un directorio de Unix. En ocasiones especiales, el programador de la aplicación puede querer proporcionar un método especial para leer directorios: por ejemplo, cuando necesita listar directorios remotos. En este caso, se puede usar la opción -dircmd. La devolución de llamada especificada acepta dos argumentos: el primero es el nombre del directorio que se va a listar; el segundo es un valor booleano que indica si se deben listar los subdirectorios ocultos. Esta devolución de llamada devuelve una lista de nombres de los subdirectorios de este directorio. Por ejemplo: 
sub read_dir {
    my( $dir, $showhidden ) = @_;
    return( qw/DOS NORTON WINDOWS/ ) if $dir eq "C:\\";
    return();
}
Nombre: showHidden
Clase: ShowHidden
Interruptor: -showhidden
Especifica si se deben mostrar los directorios ocultos. Por defecto, un nombre de directorio que comience con un punto "." se considera un directorio oculto. Esta regla se puede anular proporcionando una opción -dircmd alternativa.
Nombre: directory
Clase: Directory
Interruptor: -directory
Alias: -value
Especifica el nombre del directorio actual que se mostrará en el widget DirTree.

DESCRIPCIÓN

El método constructor DirTree crea una nueva ventana (proporcionada por el argumento $dirtree) y la convierte en un widget DirTree. Se pueden especificar opciones adicionales, descritas anteriormente, en la línea de comandos o en la base de datos de opciones para configurar aspectos del DirTree, como su cursor y relieve. El widget DirTree muestra una vista de lista de un directorio, sus directorios anteriores y sus subdirectorios. El usuario puede elegir uno de los directorios mostrados en la lista o cambiar a otro directorio.

MÉTODOS DEL WIDGET

El método DirTree crea un objeto widget. Este objeto soporta los métodos configure y cget descritos en Tk::options, que se pueden usar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

Los siguientes métodos adicionales están disponibles para los widgets DirTree:

$dirtree->chdir(dir)
Cambia el directorio actual a dir.
