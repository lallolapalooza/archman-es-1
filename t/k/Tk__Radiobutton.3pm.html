NOMBRE

Tk::Radiobutton - Crear y manipular widgets Radiobutton

SINOPSIS

$radiobutton = $parent->Radiobutton(?opciones?);

OPCIONES ESTÁNDAR

-activebackground -activeforeground -anchor -background -bitmap -borderwidth -compound -cursor -disabledforeground -font -foreground -highlightbackground -highlightcolor -highlightthickness -image -justify -padx -pady -relief -takefocus -text -textvariable -underline -wraplength

Ver Tk::options para detalles de las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: command
Clase: Command
Interruptor: -command
Especifica una devolución de llamada de perl/Tk para asociar con el botón. Este comando se invoca típicamente cuando se suelta el botón del ratón 1 sobre la ventana del botón. La variable global del botón (opción -variable) se actualizará antes de que se invoque el comando.
Nombre: height
Clase: Height
Interruptor: -height
Especifica una altura deseada para el botón. Si se está mostrando una imagen o un bitmap en el botón, el valor está en unidades de pantalla (es decir, cualquier forma aceptable para Tk_GetPixels); para texto, está en líneas de texto. Si no se especifica esta opción, la altura deseada del botón se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en él.
Nombre: indicatorOn
Clase: IndicatorOn
Interruptor: -indicatoron
Especifica si se debe dibujar o no el indicador. Debe ser un valor booleano correcto. Si es falso, la opción relief se ignora y el relief del widget siempre será hundido si el widget está seleccionado y elevado de lo contrario.
Nombre de línea de comandos: -offrelief
Nombre de base de datos: offRelief
Clase de base de datos: OffRelief
Especifica el relief para el checkbutton cuando el indicador no está dibujado y el checkbutton está desactivado. El valor predeterminado es raised. Al establecer esta opción a flat y configurar -indicatoron false -overrelief raised, se logra el efecto de tener un botón plano que se eleva al pasar el ratón y que se hunde cuando se activa. Este es el comportamiento que exhiben típicamente los botones de negrita, cursiva y subrayado en la barra de herramientas de un procesador de textos, por ejemplo.
Nombre de línea de comandos: -overrelief
Nombre de base de datos: overRelief
Clase de base de datos: OverRelief
Especifica un relief alternativo para el botón, para ser utilizado cuando el cursor del ratón está sobre el widget. Esta opción se puede utilizar para hacer botones de barra de herramientas, configurando -relief flat -overrelief raised. Si el valor de esta opción es la cadena vacía, entonces no se utiliza ningún relief alternativo cuando el cursor del ratón está sobre el botón. La cadena vacía es el valor predeterminado.
Nombre: selectColor
Clase: Background
Interruptor: -selectcolor
Especifica un color de fondo a usar cuando el botón está seleccionado. Si indicatorOn es verdadero, el color se aplica al indicador. En Windows, este color se utiliza como fondo para el indicador independientemente del estado de selección. Si indicatorOn es falso, este color se utiliza como fondo para todo el widget, en lugar de background o activeBackground, siempre que el widget esté seleccionado. Si se especifica como una cadena vacía, no se utiliza ningún color especial para mostrar cuando el widget está seleccionado.
Nombre: selectImage
Clase: SelectImage
Interruptor: -selectimage
Especifica una imagen para mostrar (en lugar de la opción image) cuando el radiobutton está seleccionado. Esta opción se ignora a menos que se haya especificado la opción image.
Nombre: state
Clase: State
Interruptor: -state
Especifica uno de los tres estados para el radiobutton: normal, active o disabled. En el estado normal, el radiobutton se muestra utilizando las opciones foreground y background. El estado activo se utiliza típicamente cuando el puntero está sobre el radiobutton. En el estado activo, el radiobutton se muestra utilizando las opciones activeForeground y activeBackground. El estado deshabilitado significa que el radiobutton debe ser insensible: las asociaciones predeterminadas se negarán a activar el widget e ignorarán las pulsaciones del botón del ratón. En este estado, las opciones disabledForeground y background determinan cómo se muestra el radiobutton.
Nombre: value
Clase: Value
Interruptor: -value
Especifica el valor que se almacenará en la variable asociada del botón cada vez que se seleccione este botón.
Nombre: variable
Clase: Variable
Interruptor: -variable
Especifica una referencia a una variable que se establecerá cada vez que se seleccione este botón. Los cambios en esta variable también harán que el botón se seleccione o deseleccione a sí mismo. Por defecto es el valor "\$Tk::selectedButton".
Nombre: width
Clase: Width
Interruptor: -width
Especifica un ancho deseado para el botón. Si se está mostrando una imagen o un bitmap en el botón, el valor está en unidades de pantalla (es decir, cualquier forma aceptable para Tk_GetPixels); para texto, está en caracteres. Si no se especifica esta opción, el ancho deseado del botón se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en él.

DESCRIPCIÓN

El método Radiobutton crea una nueva ventana (dada por el argumento $widget) y la convierte en un widget radiobutton. Opciones adicionales, descritas anteriormente, se pueden especificar en la línea de comandos o en la base de datos de opciones para configurar aspectos del radiobutton, como sus colores, fuente, texto y relief inicial. El comando radiobutton devuelve su argumento $widget. En el momento en que se invoca este comando, no debe existir una ventana llamada $widget, pero el padre de $widget debe existir.

NAME

Tk::Radiobutton - Create and manipulate radiobutton widgets

SYNOPSIS

    use Tk;
    use Tk::widgets qw(Radiobutton);

    my $radiobutton = $window->Radiobutton(
        -text    => 'Option 1',
        -variable => \$value,
        -value   => 'val1',
        ...
    );
    $radiobutton->pack;

    my $mw = MainWindow->new;
    my $value;
    $mw->Radiobutton(
        -text    => 'Option 1',
        -variable => \$value,
        -value   => 'val1',
    )->pack;
    $mw->Radiobutton(
        -text    => 'Option 2',
        -variable => \$value,
        -value   => 'val2',
    )->pack;

    MainLoop;

STANDARD OPTIONS

Tk::Radiobutton supports the standard Tk options.

WIDGET-SPECIFIC OPTIONS

Command-line options, or values in the option database, may be used to configure the radiobutton widget. The B<-option> description for each of these corresponds to the Tk man page.

-activebackground
Color for the background of the radiobutton when the mouse is over it.
-activeforeground
Color for the foreground of the radiobutton when the mouse is over it.
-background or -bg
Color for the background of the radiobutton.
-bitmap
A bitmap to display instead of text. The B<-text> option is ignored if this is set.
-borderwidth or -bw
Width of the border around the radiobutton. Default is 1.
-command
A procedure to call when the radiobutton is selected. The procedure is passed the value associated with this radiobutton.
-cursor
Mouse cursor shape to display when the pointer is over the radiobutton.
-disabledforeground
Color for the text and indicator when the radiobutton is disabled. Default is a light gray color.
-fg
Abbreviation for B<-foreground>.
-font
Font to use for the text of the radiobutton.
-foreground or -fg
Color for the text of the radiobutton.
-height
Height for the radiobutton. Default is 1.
-highlightbackground
Color for the highlight border when the widget does not have focus.
-highlightcolor
Color for the highlight border when the widget has focus.
-highlightthickness
Thickness of the highlight border. Default is 1.
-image
A Tk::Photo or Tk::Bitmap object to display. The B<-text> option is ignored if this is set.
-insertbackground
Color of the insertion cursor (not used by Radiobutton).
-insertborderwidth
Width of the insertion cursor border (not used by Radiobutton).
-insertofftime
How long the insertion cursor is on (not used by Radiobutton).
-insertontime
How long the insertion cursor is off (not used by Radiobutton).
-justify
Determines how multiple lines of text are justified. Default is B<right>.
-orient
Indicates whether to lay out the indicator and text horizontally or vertically. Default is B<horizontal>.
-padx
Extra horizontal padding around the radiobutton. Default is 0.
-pady
Extra vertical padding around the radiobutton. Default is 0.
-relief
Specifies how to render the border around the radiobutton. Valid values are B<raised>, B<sunken>, B<flat>, B<ridge>, B<solid>, and B<groove>. Default is B<raised>.
-selectcolor
Color to use for the indicator when the radiobutton is selected. The default depends on the platform.
-selectimage
An image to display when the radiobutton is selected. If this is set, the B<-image> option is ignored.
-setagain
If true, the -command will be called even if the variable's value doesn't change.
-state
Indicates whether the radiobutton is B<normal>, B<disabled>, or B<active>. Default is B<normal>.
-takefocus
Indicates whether the radiobutton should receive focus when tabbing. Default is true.
-text
Text to display next to the radiobutton indicator. This may contain newlines.
-textvariable
A scalar reference to a Tcl variable which will be updated with the text for the radiobutton. If this is set, the B<-text> option is ignored.
-underline
An integer specifying the character in the B<-text> to underline. This character will be underlined, and pressing Alt+<char> will activate the radiobutton. Default is -1 (no character underlined).
-value
The value that the B<-variable> will be set to when this radiobutton is selected. Required for radiobuttons.
-variable
A scalar reference to a Tcl variable associated with this radiobutton. When the radiobutton is selected, the variable is set to its B<-value>. When the radiobutton is deselected, the variable is set to the B<-offvalue>. Required for radiobuttons.
-width
Width for the radiobutton. Default is 1.
-wrapLength
Specifies the maximum length in screen units for a line of text. Lines longer than this will be wrapped onto the next line. Default is 0, meaning no wrapping.
-xscrollcommand
If the text or image is wider than the widget, this option may be used in conjunction with a horizontal scrollbar.
-yscrollcommand
If the text or image is taller than the widget, this option may be used in conjunction with a vertical scrollbar.

DESCRIPTION

A radiobutton widget displays a textual or graphical indicator. When the user clicks on a radiobutton, it becomes selected and its associated variable is set to a specific value. Radiobuttons are typically used in groups, where only one radiobutton in the group can be selected at a time. The group is defined by the B<-variable> option, which should be the same for all radiobuttons in the group.

The B<-value> option specifies the value that the B<-variable> will be set to when this particular radiobutton is selected. The B<-offvalue> option specifies the value that the B<-variable> will be set to when this radiobutton is deselected (or when another radiobutton in the group is selected). If B<-offvalue> is not specified, it defaults to the empty string.

The B<-command> option specifies a procedure to be called whenever the radiobutton's state changes (i.e., when it is selected or deselected). The procedure is called with the B<-value> of the radiobutton as its argument if it is selected, or the B<-offvalue> if it is deselected.

The text can be displayed in multiple lines (separated by newline characters). Text can be optionally underlined using the B<-underline> option. A radiobutton has all the behavior of a simple button: it can display itself in three different ways according to the B<-state> option; it can appear raised, sunken, or flat; it can flash; and it invokes a Perl/Tk callback whenever mouse button 1 is clicked over the radiobutton.

In addition, radiobuttons can be selected. If a radiobutton is selected, the indicator is normally drawn with a selected appearance, and a Tcl variable associated with the radiobutton is set to a particular value (normally 1). Under Unix, the indicator is drawn with a sunken relief and a special color. Under Windows, the indicator is drawn with a round mark inside. If the radiobutton is not selected, then the indicator is drawn with a deselected appearance, and the associated variable is set to a different value (typically 0). Under Unix, the indicator is drawn with a raised relief and no special color. Under Windows, the indicator is drawn without a round mark inside. Typically, several radiobuttons share a single variable and the value of the variable indicates which radiobutton is to be selected. When a radiobutton is selected it sets the value of the variable to indicate that fact; each radiobutton also monitors the value of the variable and automatically selects and deselects itself when the variable's value changes. By default the variable B<selectedButton> is used; its contents give the name of the button that is selected, or the empty string if no button associated with that variable is selected. The name of the variable for a radiobutton, plus the variable to be stored into it, may be modified with options on the command line or in the option database. Configuration options may also be used to modify the way the indicator is displayed (or whether it is displayed at all). By default a radiobutton is configured to select itself on button clicks.

WIDGET METHODS

The Radiobutton method creates a widget object. This object supports the configure and cget methods described in Tk::options which can be used to enquire and modify the options described above. The widget also inherits all the methods provided by the generic Tk::Widget class.

The following additional methods are available for radiobutton widgets:

$radiobutton->deselect
Deselects the radiobutton and sets the associated variable to the B<-offvalue> (or an empty string if B<-offvalue> is not specified). If this radiobutton was not currently selected, the command has no effect.
$radiobutton->flash
Flashes the radiobutton. This is accomplished by redisplaying the radiobutton several times, alternating between active and normal colors. At the end of the flash the radiobutton is left in the same normal/active state as when the command was invoked. This command is ignored if the radiobutton's state is disabled.
$radiobutton->invoke
Does just what would have happened if the user invoked the radiobutton with the mouse: selects the button and invokes its associated Tcl command, if there is one. The return value is the return value from the Tcl command, or an empty string if there is no command associated with the radiobutton. This command is ignored if the radiobutton's state is disabled.
$radiobutton->select
Selects the radiobutton and sets the associated variable to the value corresponding to this widget (the B<-value> option).

BINDINGS

Tk automatically creates class bindings for radiobuttons that give them the following default behavior:

[1]
On Unix systems, a radiobutton activates whenever the mouse passes over it and deactivates whenever the mouse leaves the radiobutton. On Mac and Windows systems, when mouse button 1 is pressed over a radiobutton, the button activates whenever the mouse pointer is inside the button, and deactivates whenever the mouse pointer leaves the button.
[2]
When mouse button 1 is pressed over a radiobutton it is invoked (it becomes selected and the command associated with the button is invoked, if there is one).
[3]
When a radiobutton has the input focus, the space key causes the radiobutton to be invoked.

If the radiobutton's state is disabled then none of the above actions occur: the radiobutton is completely non-responsive.

The behavior of radiobuttons can be changed by defining new bindings for individual widgets or by redefining the class bindings.
