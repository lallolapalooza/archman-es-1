JPEG(3) Documentación de perl/Tk JPEG(3)

NOMBRE

Tk::JPEG - Cargador JPEG para Tk::Photo

SINOPSIS

use Tk;
use Tk::JPEG;
my $image = $widget->Photo('-format' => 'jpeg', -file => 'algo.jpg');

DESCRIPCIÓN

Esta es una extensión para Tk que proporciona un cargador de formato JPEG para el tipo de imagen Photo.

El acceso a JPEG se realiza a través de la versión 5 del software libre JPEG del Independent JPEG Group (IJG).

HISTORIA

Esta extensión funciona para Tk800.015 y posteriores, y está incluida por defecto en Perl/Tk desde Tk804.
