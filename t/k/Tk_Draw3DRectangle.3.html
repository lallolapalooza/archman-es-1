ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a usar para informar errores.
Tk_Window tkwin (entrada)
Token de la ventana (para todos los procedimientos excepto Tk_Get3DBorder, debe ser la ventana para la que se asignó el borde).
Tcl_Obj *objPtr (entrada)
Puntero al valor cuya descripción del color corresponde al fondo (áreas planas). Los bordes iluminados serán más brillantes que este y los bordes en sombra serán más oscuros que este.
const char *colorName (entrada)
Igual que objPtr excepto que el valor se proporciona como una cadena en lugar de un valor.
Drawable drawable (entrada)
Token X de la ventana o mapa de bits; indica dónde se dibujarán los gráficos. Debe ser la ventana X para tkwin o un mapa de bits con la misma pantalla y profundidad que tkwin.
Tk_3DBorder border (entrada)
Token del borde asignado previamente en una llamada a Tk_Get3DBorder.
int x (entrada)
Coordenada X de la esquina superior izquierda del rectángulo que describe el borde o bisel, en píxeles.
int y (entrada)
Coordenada Y de la esquina superior izquierda del rectángulo que describe el borde o bisel, en píxeles.
int width (entrada)
Ancho del rectángulo que describe el borde o bisel, en píxeles.
int height (entrada)
Altura del rectángulo que describe el borde o bisel, en píxeles.
int borderWidth (entrada)
Ancho del borde en píxeles. Positivo significa que el borde está dentro del rectángulo dado por x, y, width, height; negativo significa que el borde está fuera del rectángulo.
int relief (entrada)
Indica la posición 3D del interior del valor relativo al exterior; debe ser TK_RELIEF_RAISED, TK_RELIEF_SUNKEN, TK_RELIEF_GROOVE, TK_RELIEF_SOLID, o TK_RELIEF_RIDGE (también puede ser TK_RELIEF_FLAT para Tk_Fill3DRectangle).
XPoint *pointPtr (entrada)
Puntero a una matriz de puntos que describe el conjunto de vértices de un polígono. El polígono no necesita estar cerrado (se cerrará automáticamente si no lo está).
int numPoints (entrada)
Número de puntos en *pointPtr.
int polyBorderWidth (entrada)
Ancho del borde en píxeles. Si es positivo, el borde se dibuja a la izquierda de la trayectoria dada por pointPtr; si es negativo, el borde se dibuja a la derecha de la trayectoria. Si leftRelief es TK_RELIEF_GROOVE o TK_RELIEF_RIDGE, el borde se centrará en la trayectoria.
int leftRelief (entrada)
Altura del lado izquierdo de la ruta del polígono en relación con el derecho. TK_RELIEF_RAISED significa que el lado izquierdo debe aparecer más alto y TK_RELIEF_SUNKEN significa que el lado derecho debe aparecer más alto; TK_RELIEF_GROOVE y TK_RELIEF_RIDGE significan lo obvio. Para Tk_Fill3DPolygon, también se puede especificar TK_RELIEF_FLAT para indicar que no hay diferencia en la altura.
int leftBevel (entrada)
Distinto de cero significa que este bisel forma el lado izquierdo del valor; cero significa que forma el lado derecho.
int leftIn (entrada)
Distinto de cero significa que el borde izquierdo del bisel horizontal se inclina hacia adentro, de modo que la parte inferior del borde está más lejos a la derecha que la superior. Cero significa que el borde se inclina hacia afuera, de modo que la parte inferior está más lejos a la izquierda que la superior.
int rightIn (entrada)
Distinto de cero significa que el borde derecho del bisel horizontal se inclina hacia adentro, de modo que la parte inferior del borde está más lejos a la izquierda que la superior. Cero significa que el borde se inclina hacia afuera, de modo que la parte inferior está más lejos a la derecha que la superior.
int topBevel (entrada)
Distinto de cero significa que este bisel forma el lado superior del valor; cero significa que forma el lado inferior.
int which (entrada)
Especifica cuál de los contextos gráficos del borde se desea. Debe ser TK_3D_FLAT_GC, TK_3D_LIGHT_GC, o TK_3D_DARK_GC.

DESCRIPCIÓN

Estos procedimientos proporcionan facilidades para dibujar bordes de ventanas de una manera que produce una apariencia tridimensional. Tk_Alloc3DBorderFromObj asigna colores y mapas de bits necesarios para dibujar un borde en la ventana proporcionada por el argumento tkwin. El valor de objPtr es un nombre de color estándar de Tk que determina los colores del borde. El color indicado por objPtr no se usará realmente en el borde; indica el color de fondo de la ventana (es decir, un color para superficies planas). Las porciones iluminadas del borde aparecerán más brillantes que lo indicado por objPtr, y las porciones en sombra del borde aparecerán más oscuras que objPtr.

Tk_Alloc3DBorderFromObj devuelve un token que puede usarse en llamadas posteriores a Tk_Draw3DRectangle. Si ocurre un error al asignar información para el borde (por ejemplo, se proporcionó un nombre de color inválido), se devuelve NULL y se deja un mensaje de error como resultado del intérprete interp. Si se devuelve correctamente, Tk_Alloc3DBorderFromObj almacena información sobre el valor de retorno en objPtr, lo que acelera las llamadas futuras a Tk_Alloc3DBorderFromObj con el mismo objPtr y tkwin.

Tk_Get3DBorder es idéntico a Tk_Alloc3DBorderFromObj excepto que el color se especifica con una cadena en lugar de un valor. Esto evita que Tk_Get3DBorder almacene en caché el valor de retorno, por lo que Tk_Get3DBorder es menos eficiente que Tk_Alloc3DBorderFromObj.

Tk_Get3DBorderFromObj devuelve el token de un borde existente, dado el nombre de la ventana y el color utilizados para crear el borde. Tk_Get3DBorderFromObj no crea realmente el borde; ya debe haber sido creado con una llamada anterior a Tk_Alloc3DBorderFromObj o Tk_Get3DBorder. El valor de retorno se almacena en caché en objPtr, lo que acelera las llamadas futuras a Tk_Get3DBorderFromObj con el mismo objPtr y tkwin.

Una vez creado un borde, se puede invocar Tk_Draw3DRectangle para dibujar el borde. El argumento tkwin especifica la ventana para la que se asignó el borde, y drawable especifica una ventana o mapa de bits en el que se dibujará el borde. Drawable no tiene que referirse a la misma ventana que tkwin, pero debe referirse a un mapa de bits o ventana compatible: uno asociado con la misma pantalla y con la misma profundidad que tkwin. Los argumentos x, y, width, y height definen el cuadro delimitador de la región del borde dentro de drawable (normalmente x e y son cero y width y height son las dimensiones de la ventana), y borderWidth especifica el número de píxeles ocupados realmente por el borde. El argumento relief indica cuál de varios efectos tridimensionales se desea: TK_RELIEF_RAISED significa que el interior del rectángulo debe aparecer elevado en relación con el exterior del rectángulo, y TK_RELIEF_SUNKEN significa que el interior debe aparecer deprimido. TK_RELIEF_GROOVE y TK_RELIEF_RIDGE significan que debe aparecer una ranura o una cresta alrededor del exterior del rectángulo.
