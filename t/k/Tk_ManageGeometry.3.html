Tk_ManageGeometry(3) Procedimientos de la biblioteca Tk Tk_ManageGeometry(3)

NOMBRE

Tk_ManageGeometry - organizar para manejar solicitudes de geometría para una ventana

SINOPSIS

#include <tk.h>

Tk_ManageGeometry(tkwin, mgrPtr, clientData)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token de la ventana a gestionar.
const Tk_GeomMgr *mgrPtr (entrada)
Puntero a la estructura de datos que contiene información sobre el gestor de geometría, o NULL para indicar que la geometría de tkwin ya no debe ser gestionada. La estructura de datos apuntada por mgrPtr debe ser estática: Tk mantiene una referencia a ella mientras la ventana esté gestionada.
ClientData clientData (entrada)
Valor arbitrario de una palabra para pasar a las devoluciones de llamada del gestor de geometría.

DESCRIPCIÓN

Tk_ManageGeometry organiza para que un gestor de geometría particular, descrito por el argumento mgrPtr, controle la geometría de una ventana de contenido particular, dada por tkwin. Si tkwin estaba gestionado previamente por algún otro gestor de geometría, el gestor anterior pierde el control en favor del nuevo. Si mgrPtr es NULL, la gestión de geometría se cancela para tkwin.

La estructura apuntada por mgrPtr contiene información sobre el gestor de geometría:

typedef struct {
    const char *name;
    Tk_GeomRequestProc *requestProc;
    Tk_GeomLostSlaveProc *lostSlaveProc;
} Tk_GeomMgr;
El campo name es el nombre textual del gestor de geometría, como pack o place; este valor será devuelto por el comando winfo manager.

requestProc es un procedimiento en el gestor de geometría que se invocará cada vez que la ventana de contenido llame a Tk_GeometryRequest para cambiar su geometría deseada. requestProc debe tener argumentos y resultados que coincidan con el tipo Tk_GeomRequestProc:

typedef void Tk_GeomRequestProc(
        ClientData clientData,
        Tk_Window tkwin);
Los parámetros para requestProc serán idénticos a los parámetros correspondientes pasados a Tk_ManageGeometry. clientData normalmente apunta a una estructura de datos que contiene información específica de la aplicación sobre cómo gestionar la geometría de tkwin.

El campo lostSlaveProc de mgrPtr apunta a otro procedimiento en el gestor de geometría. Tk invocará lostSlaveProc si algún otro gestor llama a Tk_ManageGeometry para reclamar tkwin al gestor de geometría actual. lostSlaveProc no se invoca si se llama a Tk_ManageGeometry con un valor NULL para mgrPtr (presumiblemente el gestor de geometría actual ha realizado esta llamada, por lo que ya sabe que la ventana ya no está gestionada), ni se llama si mgrPtr es el mismo que el gestor de geometría actual de la ventana. lostSlaveProc debe tener argumentos y resultados que coincidan con el siguiente prototipo:

typedef void Tk_GeomLostSlaveProc(
        ClientData clientData,
        Tk_Window tkwin);
Los parámetros para lostSlaveProc serán idénticos a los parámetros correspondientes pasados a Tk_ManageGeometry.
