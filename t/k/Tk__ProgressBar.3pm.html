NOMBRE

Tk::ProgressBar - Una barra de progreso gráfica

SINOPSIS

use Tk::ProgressBar;
$progreso = $padre->ProgressBar(
    -ancho => 20,
    -largo => 200,
    -anclaje => 's',
    -desde => 0,
    -hasta => 100,
    -bloques => 10,
    -colores => [0, 'green', 50, 'yellow' , 80, 'red'],
    -variable => \$porcentaje_completado
);
$progreso->valor($posicion);

DESCRIPCIÓN

Tk::ProgressBar proporciona un widget que mostrará una representación gráfica de un valor, dados valores de referencia máximos y mínimos.

OPCIONES ESTÁNDAR

Se soportan las siguientes opciones estándar del widget:

-borderwidth
-highlightthickness
Por defecto es 0.
-padx
Por defecto es 0.
-pady
Por defecto es 0.
-relief
Por defecto es "sunken"
-troughcolor
El color que se usará para el fondo (canal) de la barra de progreso. El valor por defecto es usar grey55.

OPCIONES ESPECÍFICAS_DEL_WIDGET

-anchor
Esto se puede usar para posicionar el punto de inicio de la barra. El valor por defecto es 'w' (barra horizontal que empieza desde la izquierda). Una barra vertical se puede configurar usando 's' o 'n'.
-blocks
Esto controla el número de bloques que se usarán para construir la barra de progreso. El valor por defecto es dividir la barra en 10 bloques.
-colors
Controla los colores que se usarán para diferentes posiciones de la barra de progreso. Los colores se deben suministrar como una referencia a un array que contiene pares de posiciones y colores. 
-colores => [ 0, 'green', 50, 'red' ]

significa que para el rango de 0 a 50 la barra de progreso debería ser verde y para valores más altos debería ser roja.

-from
Esto establece el límite inferior de la barra de progreso. Si la barra se establece a un valor por debajo del límite inferior, no se mostrará ninguna barra. Por defecto es 0. Consulte la descripción de "-to" para más información.
-gap
Este es el espaciado (en píxeles) entre cada bloque. Por defecto es 1. Usa 0 para obtener una barra continua.
-length
Especifica la dimensión larga deseada del ProgressBar en unidades de pantalla (es decir, cualquiera de las formas aceptables por Tk_GetPixels). Para ProgressBars verticales esto es la altura del ProgressBar; para escalas horizontales es el ancho del ProgressBar. La longitud por defecto se calcula a partir de los valores de "-padx", "-borderwidth", "-highlightthickness" y la diferencia entre "-from" y "-to".
-resolution
Un valor real que especifica la resolución para la escala. Si este valor es mayor que cero, el valor de la escala siempre se redondeará a un múltiplo par de este valor, al igual que las marcas de graduación y los puntos finales de la escala. Si el valor es menor que cero, no se realizará ningún redondeo. Por defecto es 1 (es decir, el valor será integral).
-to
Esto establece el límite superior de la barra de progreso. Si se especifica un valor (por ejemplo, usando el método "value") que se encuentra por encima de este valor, se mostrará la barra de progreso completa. Por defecto es 100.
-variable
Especifica la referencia a una variable escalar para vincularla al ProgressBar. Siempre que cambie el valor de la variable, el ProgressBar se actualizará para reflejar este valor. (Ver también el método value más abajo).
-value
Esto se puede usar para establecer la posición actual de la barra de progreso cuando se usa junto con la función estándar "configure". Normalmente se recomienda usar el método value en su lugar.
-width
Especifica la dimensión estrecha deseada del ProgressBar en unidades de pantalla (es decir, cualquiera de las formas aceptables por Tk_GetPixels). Para ProgressBars verticales esto es el ancho del ProgressBar; para barras horizontales es la altura del ProgressBar. El ancho por defecto se deriva de los valores de "-borderwidth" y "-pady" y "-highlightthickness".

MÉTODOS DEL_WIDGET

$ProgressBar->valor(?valor?)
Si se omite valor, devuelve el valor actual del ProgressBar. Si se proporciona valor, se establece el valor del ProgressBar. Si se proporciona $valor pero no está definido, se usa el valor de la opción -from.
