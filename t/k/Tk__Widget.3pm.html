NOMBRE

Tk::Widget - Clase base de todos los widgets

SINAPSIS

package Tk::Whatever;
require Tk::Widget;
@ISA = qw(Tk::Widget);
Construct Tk::Widget 'Whatever';
sub Tk_cmd { \&Tk::whatever }

   $widget->método(?arg, arg, ...?)

DESCRIPCIÓN

Tk::Widget es una clase base abstracta para todos los widgets de Tk.

Los métodos genéricos disponibles para todos los widgets incluyen los métodos basados en el mecanismo principal de "winfo" y se utilizan para recuperar información sobre las ventanas gestionadas por Tk. Pueden tomar cualquiera de una serie de formas diferentes, dependiendo del método. Las formas legales son:

$widget->appname?(newName)?
Si no se especifica newName, este método devuelve el nombre de la aplicación (el nombre que puede usarse en comandos send para comunicarse con la aplicación). Si se especifica newName, entonces el nombre de la aplicación se cambia a newName. Si el nombre dado ya está en uso, se le añade un sufijo de la forma `` #2'' o `` #3'' para que el nombre sea único. El resultado del método es el nombre realmente elegido. newName no debe empezar con una letra mayúscula. Esto interferirá con el procesamiento de opciones, ya que se asume que los nombres que empiezan con mayúsculas son clases; como resultado, Tk puede no ser capaz de encontrar algunas opciones para la aplicación. Si los envíos se han deshabilitado eliminando el comando send, este comando los volverá a habilitar y recreará el comando send.
$widget->atom(name)
Devuelve una cadena decimal que representa el identificador entero del átomo cuyo nombre es name. Si no existe ningún átomo con el nombre name, se crea uno nuevo.
$widget->atomname(id)
Devuelve el nombre textual del átomo cuyo identificador entero es id. Este comando es el inverso del comando $widget->atom. Genera un error si no existe dicho átomo.
$widget->bell( ?-nice? );
Este comando hace sonar el timbre en la pantalla de $widget y devuelve una cadena vacía. El comando utiliza la configuración actual relacionada con el timbre para la pantalla, que puede ser modificada con programas como xset.

Si no se especifica -nice, este comando también reinicia el salvapantallas para la pantalla. Algunos salvapantallas lo ignorarán, pero otros se reiniciarán para que la pantalla vuelva a ser visible.

$widget->bindDump
Este comando devuelve una lista de cadenas adecuadas para imprimir, detallando la información de enlace para un widget. Imprime las etiquetas de enlace de un widget. Para cada etiqueta de enlace, imprime todos los enlaces, compuestos por el descriptor del evento y la devolución de llamada. Se imprimen los argumentos de la devolución de llamada y se expanden los objetos **Tk::Ev**.
$widget->Busy?(?-recurse => 1?,-option => value?)?
Este método **configure**a una opción **-cursor** para $widget y (si se especifica **-recurse =** 1>) todos sus descendientes. El cursor a establecer puede pasarse como **-cursor** = cursor> o por defecto es 'watch'. Las opciones adicionales de **configure** se aplican solo a $widget. También añade una etiqueta especial 'Busy' a las bindtags de los widgets configurados de tal manera que los eventos KeyPress, KeyRelease, ButtonPress y ButtonRelease se ignoran (generando los eventos de pulsación una llamada a **bell**). Luego adquiere un grab local para $widget. El estado de los widgets y el grab se restauran mediante una llamada a $widget->Unbusy.
$widget->caret( ?-x => x?, ?-y => y?, ?-height => height? );
Establece y consulta la ubicación del cursor para la visualización de la ventana Tk especificada. El cursor es la ubicación del cursor por pantalla utilizada para indicar el foco global (por ejemplo, para cumplir con las directrices de accesibilidad de Microsoft), así como para la ubicación de las ventanas XIM (X Input Methods) sobre la entrada o las ventanas IME de Windows. Si no se especifican opciones, los últimos valores utilizados para establecer el cursor se devuelven en formato de par opción-valor. -x y -y representan coordenadas relativas a la ventana, y -height es la altura de la ubicación actual del cursor, o la altura de la ventana especificada si no se proporciona ninguna.
$widget->cells
Devuelve una cadena decimal que representa el número de celdas en el mapa de colores para $widget.
$widget->children
$widget->children Devuelve una lista que contiene todos los hijos de $widget. La lista está en orden de apilamiento, con la ventana más baja primero. Las ventanas de nivel superior se devuelven como hijos de sus padres lógicos.
$widget->class
Devuelve el nombre de la clase para $widget.
$widget->colormapfull
Devuelve 1 si se sabe que el mapa de colores para $widget está lleno, 0 en caso contrario. Se sabe que el mapa de colores de una ventana está "lleno" si el último intento de asignar un nuevo color en esa ventana falló y esta aplicación no ha liberado ningún color en el mapa de colores desde la asignación fallida.
$widget->ConfigSpecs
Se utiliza para realizar la configuración delegada de opciones para un mega-widget. Devuelve, en la notación de ConfigSpecs de Tk::Derived (ver Tk::ConfigSpecs), todas las opciones posibles para un widget. Por ejemplo, 
$s = $self->Scale;
$self->ConfigSpecs(
    $s->ConfigSpecs,
    .... más especificaciones de ConfigSpecs
);

devuelve un hash de todas las opciones de Tk::Scale, delegadas a $s - por ejemplo, algunos ejemplos representativos:

-bigincrement => [$s, bigIncrement, BigIncrement, 0, 0]
-digits       => [$s, digits, Digits, 0, 0]
-sliderlength => [$s, sliderLength, SliderLength, 10m, 30]
-troughcolor  => [$s, troughColor, Background, #c3c3c3, #c3c3c3]

Esto proporciona un medio fácil para poblar los ConfigSpecs de un mega-widget con inicializadores.

$widget->containing(rootX,rootY)
Devuelve la ventana que contiene el punto dado por rootX y rootY. RootX y rootY se especifican en unidades de pantalla (es decir, cualquier forma aceptable para Tk_GetPixels) en el sistema de coordenadas de la ventana raíz (si se utiliza un gestor de ventanas de raíz virtual, se utiliza el sistema de coordenadas de la ventana raíz virtual). Si ninguna ventana de esta aplicación contiene el punto, se devuelve una cadena vacía. Al seleccionar la ventana que contiene, los hijos tienen mayor prioridad que los padres y entre los hermanos se elige el más alto en el orden de apilamiento.
$widget->depth
Devuelve una cadena decimal que representa la profundidad de $widget (número de bits por píxel).
$widget->destroy
Este comando elimina la ventana relacionada con $widget, más todos sus descendientes. Si se eliminan todas las MainWindows, se destruirá toda la aplicación.

El objeto perl $widget continúa existiendo mientras existan referencias a él, por ejemplo, hasta que la variable salga del ámbito. Sin embargo, cualquier intento de usar métodos Tk en el objeto fallará. Exists($widget) devolverá falso en tales objetos.

Tenga en cuenta, sin embargo, que mientras exista una ventana para $widget, el objeto perl se mantiene (debido a las "referencias" en las internas de perl/Tk) aunque las variables originales hayan salido del ámbito. (Normalmente esto es intuitivo.)

Exists($widget)
Devuelve 1 si existe una ventana para $widget, 0 si no existe dicha ventana.
$widget->font(option?, arg, arg, ...?)
Crea e inspecciona fuentes. Consulte Tk::Font para obtener más detalles.

$widget->Getimage(nombre)
Dado nombre, busca un archivo de imagen con ese nombre base y devuelve una Tk::Image. Se prueban las extensiones de archivo en este orden: xpm, gif, ppm, xbm hasta que se encuentra una imagen válida. Si no se encuentra ninguna imagen, intenta con una imagen incorporada con ese nombre.
$widget->geometry
Devuelve la geometría para $widget, en la forma anchoxalto+x+y. Todas las dimensiones están en píxeles.
$widget->height
Devuelve una cadena decimal que indica la altura de $widget en píxeles. Cuando una ventana se crea por primera vez, su altura será de 1 píxel; la altura será eventualmente modificada por un gestor de geometría para satisfacer las necesidades de la ventana. Si necesita la altura real inmediatamente después de crear un widget, invoque update para forzar al gestor de geometría a organizarlo, o use $widget->reqheight para obtener la altura solicitada de la ventana en lugar de su altura real.
$widget->id
Devuelve una cadena hexadecimal que indica un identificador de bajo nivel específico de la plataforma para $widget. En plataformas Unix, este es el identificador de ventana X. En Windows, este es el HWND de Windows. En Macintosh, el valor no tiene significado fuera de Tk.
$widget->idletasks
Uno de dos métodos que se utilizan para "actualizar" la aplicación entrando en el bucle de eventos repetidamente hasta que todos los eventos pendientes (incluyendo las devoluciones de llamada inactivas) se hayan procesado.

Si se especifica el método idletasks, entonces no se procesan nuevos eventos ni errores; solo se invocan las devoluciones de llamada inactivas. Esto causa que las operaciones que normalmente se posponen, como las actualizaciones de pantalla y los cálculos de diseño de ventanas, se realicen inmediatamente.

El comando idletasks es útil en scripts donde se han realizado cambios en el estado de la aplicación y desea que esos cambios aparezcan en la pantalla inmediatamente, en lugar de esperar a que el script se complete. La mayoría de las actualizaciones de pantalla se realizan como devoluciones de llamada inactivas, por lo que idletasks hará que se ejecuten. Sin embargo, hay algunos tipos de actualizaciones que solo ocurren en respuesta a eventos, como los activados por cambios en el tamaño de la ventana; estas actualizaciones no ocurrirán en idletasks.

$widget->interps
Devuelve una lista cuyos miembros son los nombres de todos los intérpretes de Tcl (por ejemplo, todas las aplicaciones basadas en Tk) registrados actualmente para una pantalla determinada. El valor de retorno se refiere a la pantalla de $widget.
$widget->ismapped
Devuelve 1 si $widget está actualmente mapeado, 0 en caso contrario.
$widget->lower(?belowThis?)
Si el argumento belowThis se omite, el comando baja $widget para que esté por debajo de todos sus hermanos en el orden de apilamiento (será oscurecido por cualquier hermano que se superponga y no oscurecerá a ningún hermano). Si se especifica belowThis, debe ser el nombre de ruta de una ventana que sea un hermano de $widget o un descendiente de un hermano de $widget. En este caso, el comando lower insertará $widget en el orden de apilamiento justo debajo de belowThis (o del ancestro de belowThis que es un hermano de $widget); esto podría terminar subiendo o bajando $widget.
$widget->MapWindow
Hace que $widget sea "mapeado", es decir, visible en la pantalla. Puede confundir al gestor de geometría (pack, grid, place, ...) que cree que está gestionando el widget.
$widget->manager
Devuelve el nombre del gestor de geometría actualmente responsable de $widget, o una cadena vacía si $widget no es gestionado por ningún gestor de geometría. El nombre suele ser el nombre del método para el gestor de geometría, como pack o place. Si el gestor de geometría es un widget, como canvases o text, el nombre es el comando de clase del widget, como canvas.
$widget->name
Devuelve el nombre de $widget (es decir, su nombre dentro de su padre, en contraposición a su nombre de ruta completo). El comando $mainwin->name devolverá el nombre de la aplicación.
$widget->OnDestroy(callback);
OnDestroy acepta una devolución de llamada estándar de perl/Tk. Cuando la ventana asociada con $widget se destruye, se invoca la devolución de llamada. A diferencia de $widget->bind('<Destroy>',...) los métodos del widget siguen disponibles cuando se ejecuta callback, por lo que (por ejemplo) un widget Text puede guardar su contenido en un archivo.

OnDestroy era necesario para el nuevo mecanismo after.

$widget->parent
Devuelve el padre de $widget, o una cadena vacía si $widget es la ventana principal de la aplicación.
$widget->PathName
Devuelve el nombre de ruta Tk de $widget. Este es el inverso del método "Widget". (Esto es una importación de la interfaz C).
$widget->pathname(id)
Devuelve un objeto cuyo identificador X es id. El identificador se busca en la pantalla de $widget. Id debe ser un entero decimal, hexadecimal u octal y debe corresponder a una ventana en la aplicación invocadora, o se producirá un error que puede ser capturado con "eval { }" o "Tk::catch { }". Si la ventana pertenece a la aplicación, pero no es un objeto (por ejemplo, ventanas envoltorio, encabezado HList, etc.), entonces se devuelve "undef".
$widget->pixels(número)
Devuelve el número de píxeles en $widget correspondiente a la distancia dada por número. Número puede especificarse en cualquiera de las formas aceptables para Tk_GetPixels, como ``2.0c'' o ``1i''. El resultado se redondea al entero más cercano; para un resultado fraccionario, use $widget->fpixels.
$widget->pointerx
Si el puntero del ratón está en la misma pantalla que $widget, devuelve la coordenada x del puntero, medida en píxeles en la ventana raíz de la pantalla. Si se utiliza una ventana raíz virtual en la pantalla, la posición se mide en la raíz virtual. Si el puntero del ratón no está en la misma pantalla que $widget, se devuelve -1.
$widget->pointerxy
Si el puntero del ratón está en la misma pantalla que $widget, devuelve una lista con dos elementos, que son las coordenadas x e y del puntero medidas en píxeles en la ventana raíz de la pantalla. Si se utiliza una ventana raíz virtual en la pantalla, la posición se calcula en la raíz virtual. Si el puntero del ratón no está en la misma pantalla que $widget, ambas coordenadas devueltas son -1.
$widget->pointery
Si el puntero del ratón está en la misma pantalla que $widget, devuelve la coordenada y del puntero, medida en píxeles en la ventana raíz de la pantalla. Si se utiliza una ventana raíz virtual en la pantalla, la posición se calcula en la raíz virtual. Si el puntero del ratón no está en la misma pantalla que $widget, se devuelve -1.
$widget->raise(?aboveThis?)
Si el argumento aboveThis se omite, el comando eleva $widget para que esté por encima de todos sus hermanos en el orden de apilamiento (no será oscurecido por ningún hermano y oscurecerá a cualquier hermano que se superponga). Si se especifica aboveThis, debe ser el nombre de ruta de una ventana que sea un hermano de $widget o un descendiente de un hermano de $widget. En este caso, el comando raise insertará $widget en el orden de apilamiento justo encima de aboveThis (o del ancestro de aboveThis que es un hermano de $widget); esto podría terminar subiendo o bajando $widget.
$widget->reqheight
Devuelve una cadena decimal que indica la altura solicitada de $widget, en píxeles. Este es el valor utilizado por el gestor de geometría de $widget para calcular su geometría.
$widget->reqwidth
Devuelve una cadena decimal que indica el ancho solicitado de $widget, en píxeles. Este es el valor utilizado por el gestor de geometría de $widget para calcular su geometría.
$widget->rgb(color)
Devuelve una lista que contiene tres valores decimales, que son las intensidades de rojo, verde y azul que corresponden a color en la ventana dada por $widget. Color puede especificarse en cualquiera de las formas aceptables para una opción de color.
$widget->rootx

NAME

Tk::Widget - generic widget methods

SYNOPSIS

    $widget->width
    $widget->height
    $widget->screen
    $widget->pathName
    $widget->id
    $widget->parent
    $widget->class
    $widget->children
    $widget->mapped
    $widget->x
    $widget->y

DESCRIPTION

$widget->width
Returns a decimal string giving the width of $widget's border (or $widget if it has no border).
$widget->height
Returns a decimal string giving the height of $widget's border (or $widget if it has no border).
$widget->screen
Returns the name of the screen on which $widget is displayed.
$widget->pathName
Returns the unique path name of $widget.
$widget->id
Returns the Tk internal identifier for $widget.
$widget->parent
Returns a reference to the parent widget of $widget.
$widget->class
Returns the Tk class name of $widget.
$widget->children
Returns a list of the direct children of $widget.
$widget->mapped
Returns a boolean indicating whether $widget is currently mapped to the screen.
$widget->x
