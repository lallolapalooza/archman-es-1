NOMBRE

Tk::Submethods - añadir alias para sub-comandos de tk

SINOPSIS

use Tk::Submethods ( 'comando1' => [qw(sub1 sub2 sub3)],
                     'comando2' => [qw(sub1 sub2 sub3)]);

DESCRIPCIÓN

Crea "->comandoSub(...)" como un alias para "->comando('sub',...)", por ejemplo "->grabRelease" para "->grab('release')".

Para cada par comando/subcomando, esto crea un closure con el comando y subcomando como variables léxicas enlazadas y asigna una referencia a esto a un 'glob' en el paquete del llamador.

Algún día los sub-comandos se podrán crear directamente en el código C.
