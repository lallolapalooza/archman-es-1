NOMBRE

Tk::Compound - Crear imágenes compuestas multilinea.

SINOPSIS

use Tk::Compound;
$imagen = $widget->Compound(nombre,opciones);
$imagen->Line(opciones);
$imagen->Text(opciones);
$imagen->Bitmap(opciones);
$imagen->Image(opciones);
$imagen->Space(opciones);

DESCRIPCIÓN

Los tipos de imagen compuestos se pueden usar para crear imágenes que consisten en múltiples líneas horizontales; cada línea está compuesta por una serie de elementos (textos, mapas de bits, imágenes o espacios) dispuestos de izquierda a derecha. Las imágenes compuestas se utilizan principalmente para incrustar dibujos complejos en widgets que admiten la opción -image. Como se muestra en la sección EJEMPLO a continuación, una imagen compuesta se puede usar para mostrar simultáneamente un mapa de bits y una cadena de texto en un widget Button de Tk.

Las imágenes compuestas solo se pueden usar en ventanas de la misma pantalla que, y con la misma profundidad de píxeles y visual que el $widget utilizado para crearlas.

CREACIÓN DE IMÁGENES COMPUESTAS

Los compuestos se crean utilizando $widget->Compound. Los compuestos admiten las siguientes opciones:

-background => color
Especifica el color de fondo de la imagen compuesta. Este color también se usa como color de fondo predeterminado para los elementos de mapa de bits en la imagen compuesta.
-borderwidth => píxeles
Especifica un valor no negativo que indica el ancho del borde 3D que se traza alrededor de la imagen compuesta.
-font => fuente
Especifica la fuente predeterminada para los elementos de texto en la imagen compuesta.
-foreground => color
Especifica el color de primer plano predeterminado para los elementos de mapa de bits y texto en la imagen compuesta.
-padx => valor
Especifica un valor no negativo que indica cuánto espacio adicional solicitar para la imagen compuesta en la dirección X. El valor puede tener cualquiera de los formatos aceptables para Tk_GetPixels(3).
-pady => valor
Especifica un valor no negativo que indica cuánto espacio adicional solicitar para la imagen compuesta en la dirección Y.
-relief => valor
Especifica el efecto 3D deseado para el fondo de la imagen compuesta. Los valores aceptables son raised, sunken, flat, ridge y groove.
-showbackground => valor
Especifica si se deben dibujar el fondo y los bordes 3D. Debe ser un valor booleano válido. Por defecto, el fondo no se dibuja y la imagen compuesta parece tener un fondo transparente.

COMANDO DE IMAGEN

Cuando se crea una imagen compuesta, Tk también crea un nuevo objeto. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente.

El objeto también admite los siguientes métodos:

$compound->Line?(opción = valor ...>)?
Crea una nueva línea en la parte inferior de la imagen compuesta. Las líneas admiten las siguientes opciones:
-anchor valor
Especifica cómo se alineará la línea en el eje horizontal. Cuando los valores son w, sw o nw, la línea se alinea a la izquierda. Cuando los valores son c, s o n, la línea se alinea en el centro. Cuando los valores son e, se o ne, la línea se alinea a la derecha.
-padx => valor
Especifica un valor no negativo que indica cuánto espacio adicional solicitar para esta línea en la dirección X.
$compound->TipoElemento?(opción = valor ...>)?
Crea un nuevo elemento del tipo TipoElemento al final de la última línea de la imagen compuesta. Todos los tipos de elementos admiten las siguientes opciones comunes:
-anchor valor
Especifica cómo se alineará el elemento en el eje vertical. Cuando los valores son n, nw o ne, el elemento se alinea en la parte superior de la línea. Cuando los valores son c, w o e, el elemento se alinea en el centro de la línea. Cuando los valores son s, se o sw, el elemento se alinea en la parte inferior de la línea.
-padx => valor
Especifica un valor no negativo que indica cuánto espacio adicional solicitar para este elemento en la dirección X.
-pady => valor
Especifica un valor no negativo que indica cuánto espacio adicional solicitar para este elemento en la dirección Y.
tipo-elemento puede ser cualquiera de los siguientes:
$compound->Bitmap?(opción = valor ...>)?
Crea un nuevo elemento de mapa de bits al final de la última línea de la imagen compuesta. Las opciones adicionales aceptadas por el tipo mapa de bits son:
-background => color
Especifica el color de fondo del elemento mapa de bits.
-bitmap => nombre
Especifica un mapa de bits para mostrar en este elemento, en cualquiera de los formatos aceptables para Tk_GetBitmap(3).
-foreground => color
Especifica el color de primer plano del elemento mapa de bits.
$compound->Image?(opción = valor ...>)?
Crea un nuevo elemento de imagen al final de la última línea de la imagen compuesta. Las opciones adicionales aceptadas por el tipo imagen son:
-image => nombre
Especifica una imagen para mostrar en este elemento. nombre debe haber sido creado con el comando image create.
$compound->Space?(opción = valor ...>)?
Crea un nuevo elemento de espacio al final de la última línea de la imagen compuesta. Los elementos de espacio no muestran nada. Simplemente actúan como marcadores de posición que agregan espacio adicional entre elementos dentro de una imagen compuesta. Las opciones adicionales aceptadas por el tipo imagen son:
-width => valor
Especifica el ancho de este espacio. El valor puede tener cualquiera de los formatos aceptables para Tk_GetPixels(3).
-height => valor
Especifica la altura de este espacio. El valor puede tener cualquiera de los formatos aceptables para Tk_GetPixels(3).
$compound->Text?(opción = valor ...>)?
Crea un nuevo elemento de texto al final de la última línea de la imagen compuesta. Las opciones adicionales aceptadas por el tipo texto son:
-background => color
Especifica el color de fondo del elemento de texto.
-font => nombre
Especifica la fuente que se utilizará para este elemento de texto.

NAME

Tk::Compound - Creates a compound image

SYNOPSIS

my $compound = $widget->Compound(
  -relief        => value,
  -borderwidth   => value,
  -highlightthickness => value,
  -highlightcolor => color,
  -background    => color,
  -cursor        => cursorName
);
$compound->*option*(@value);

DESCRIPTION

A Compound object is used to create a compound image. A compound image is a collection of other images that are displayed together as a single image. For example, you could create a compound image that consists of a bitmap and a text string.

The Compound object itself is a widget. You can configure its appearance using options like -relief, -borderwidth, -highlightthickness, -highlightcolor, -background, and -cursor. These options affect the way the compound image is displayed on the screen.

You can add other image objects (like Bitmap, Text, Line, Oval, Polygon, Rectangle, Text, and Photo) to a Compound object. Each of these image objects can be configured with its own specific options. The order in which you add these objects determines their stacking order, with later objects appearing on top of earlier ones.

Once a Compound object is created, it can be used as the value for the -image option of other Tk widgets, such as Button, Label, or Menubutton.

CREATING COMPOUND IMAGES

To create a compound image, you first create a Compound object using the Compound method of a widget. Then, you add other image objects to this Compound object using its methods (e.g., $compound->Bitmap(...), $compound->Text(...)).

The following are the methods available for creating image objects that can be added to a Compound:

Bitmap(options)
Creates a bitmap image. See Tk::Bitmap for available options.
Line(options)
Creates a line image. See Tk::Line for available options.
Oval(options)
Creates an oval image. See Tk::Oval for available options.
Polygon(options)
Creates a polygon image. See Tk::Polygon for available options.
Rectangle(options)
Creates a rectangle image. See Tk::Rectangle for available options.
Text(options)
Creates a text image. See Tk::Text for available options.
Photo(options)
Creates a photo image. See Tk::Photo for available options.
Space(options)
Creates an empty space. This is useful for adding spacing between other image elements in a compound image. See Tk::Space for available options.

IMAGE COMMAND

The following options are available for configuring the image elements within a Compound object:

-background => color
Specifies the background color of the text item.
-foreground => color
Specifies the foreground color of the text item.
-justify value
When there are multiple lines of text displayed in a text item, this option determines how the lines line up with each other. value must be one of left, center, or right. Left means that the lines' left edges all line up, center means that the lines' centers are aligned, and right means that the lines' right edges line up.
-text => string
Specifies a text string to display in this text item.
-underline value
Specifies the integer index of a character to underline in the text item. 0 corresponds to the first character of the text displayed in the text item, 1 to the next character, and so on.
-wraplength value
This option specifies the maximum line length of the label string on this text item. If the line length of the label string exceeds this length, it is wrapped onto the next line, so that no line is longer than the specified length. The value may be specified in any of the standard forms for screen distances. If this value is less than or equal to 0 then no wrapping is done: lines will break only at newline characters in the text.

EXAMPLE

The following example creates a compound image with a bitmap and a text string and places this image into a Button(n) widget. Notice that the image must be created using the widget that it resides in.

my $b = $parent->Button;
my $c = $b->Compound;
$b->configure(-image => $c);
$c->Line;
$c->Bitmap(-bitmap => 'warning');
$c->Space(-width => 8);
$c->Text(-text => "Warning", -underline => 0);
$b->pack;
