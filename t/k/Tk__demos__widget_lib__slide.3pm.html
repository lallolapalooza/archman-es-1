NOMBRE

Tk::SlideSwitch - un interruptor horizontal o vertical de 2 posiciones.

SINOPSIS

use Tk::SlideSwitch;
my $sl = $frame1->SlideSwitch(
    -bg          => 'gray',
    -orient      => 'horizontal',
    -command     => [$self => 'on'],
    -llabel      => [-text => 'OFF', -foreground => 'blue'],
    -rlabel      => [-text => 'ON',  -foreground => 'blue'],
    -troughcolor => 'tan',
)->pack(qw/-side left -expand 1/);

DESCRIPCIÓN

Tk::SlideSwitch es un megawidget compuesto basado en Frame que presenta un widget de Escala binario rodeado por dos widgets de Etiqueta. El valor de la Escala puede ser 0 o 1. Las Etiquetas se posicionan a la izquierda y a la derecha de la Escala si su orientación es horizontal, de lo contrario, en la parte superior e inferior de la Escala.

OPCIONES

Además de todas las opciones de Scale, también se soportan las siguientes opciones/valores:

-llabel
Una referencia a un array de opciones de configuración de Etiqueta izquierda (o superior).
-rlabel
Una referencia a un array de opciones de configuración de Etiqueta derecha (o inferior).

MÉTODOS

No hay métodos especiales.

WIDGETS OFRECIDOS

Se puede acceder a los subwidgets componentes a través del método Subwidget. Este megawidget no tiene subwidgets ofrecidos.

EJEMPLO

Ver Sinopsis.

ERRORES

Este widget utiliza únicamente el gestor de geometría pack.
