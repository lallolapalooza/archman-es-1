NOMBRE

Tk::WidgetDemo - crea una ventana de demostración de widget estándar.

SINOPSIS

use WidgetDemo;
my $TOP = $MW->WidgetDemo(
    -name             => $demo,
    -text             => '¡Aprende a escribir una demostración de widget!',
    -title            => 'Demostración de WidgetDemo',
    -iconname         => 'WidgetDemo',
    -geometry_manager => 'grid',
    -font             => $FONT,
);

DESCRIPCIÓN

Este constructor construye una ventana de demostración de widget estándar, compuesta por tres marcos. El marco superior contiene texto descriptivo de la demostración. El marco inferior contiene los botones "Descartar" y "Ver Código". El marco medio es el contenedor de la demostración, que puede ser gestionado por el administrador de geometría pack o grid.

El atributo -text se proporciona a un widget Label, que se alinea a la izquierda con -wraplength establecido en 4 pulgadas. Si requiere especificaciones diferentes, pase una matriz a -text; el primer elemento es la cadena de texto y los elementos restantes de la matriz son atributos estándar del widget Label - WidgetDemo reorganizará las cosas según sea necesario..

-text => ['¡Hola Mundo!', qw/-wraplength 6i/],
