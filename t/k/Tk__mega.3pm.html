NOMBRE

Tk::mega - Soporte de Perl/Tk para escribir widgets en Perl puro

SINOPSIS

Define el nuevo nombre de clase del widget:

    package Tk::MiNuevoWidget;

Para clases de widgets compuestos:

    use base qw/ Tk::container /; # donde container es Frame o Toplevel

Para clases de widgets derivados:

    use base qw/ Tk::Derived Tk::DerivedWidget /;

Instala el nuevo widget en el espacio de nombres de Tk y establece los constructores de clase e instancia.

    Construct Tk::Widget 'MiNuevoWidget';

    sub ClassInit { my ($self, $args) = @_; ... }

    sub Populate { my ($self, $args) = @_; ... }

DESCRIPCIÓN

El objetivo del soporte de mega-widgets de Perl/Tk es facilitar la creación de mega-widgets que cumplan el mismo protocolo e interfaz que los widgets principales de Tk. Para ver código de ejemplo de mega-widgets, ejecute el programa de demostración widget y vaya a la sección Ejemplos de Mega-Widgets de Perl.

Hay dos tipos de mega-widgets:

  • Widgets Compuestos

    Un widget compuesto se construye con uno o más widgets existentes. El widget compuesto se presenta al usuario como un único widget simple. Un ejemplo conocido es el cuadro de selección de archivos.

  • Widgets Derivados

    Un widget derivado añade/modifica/elimina propiedades y métodos de un único widget (este widget puede ser él mismo un mega-widget).

SOPORTE MEGA-WIDGET

Advertise

Da un nombre simbólico a un subwidget.

Uso:

    $self->Advertise(nombre=>$widget);

Da al subwidget $widget del mega-widget $self el nombre nombre. Se puede recuperar la referencia de un subwidget anunciado con el método Subwidget.

Comentario: Escritores de Mega-Widgets: Asegúrense de documentar los widgets anunciados que están destinados al uso público. Si no hay ninguno, documenten este hecho, por ejemplo:

=head1 WIDGETS ANUNCIADOS
Ninguno.

Callback

Invoca un callback especificado con una opción.

Uso:

    $self->Callback(-opción ?,argumentos ...?);

Callback ejecuta el callback definido con $self->ConfigSpecs(-opción, [CALLBACK, ...]); Si se proporcionan argumentos, se pasan al callback. Si -opción no está definida, no hace nada.

ClassInit

Inicialización de la clase del mega-widget.

Uso:

    sub ClassInit { my ($class, $mw) = @_; ... }

ClassInit se llama una vez por cada MainWindow justo antes de crearse la primera instancia de widget de una clase en el árbol de widgets de MainWindow.

ClassInit se usa a menudo para definir enlaces y/o otros recursos compartidos por todas las instancias, por ejemplo, imágenes.

Ejemplos:

$mw->bind($class,"<Tab>", sub { my $w = shift; $w->Insert("\t"); $w->focus; $w->break});
$mw->bind($class,"<Return>", ['Insert',"\n"]);
$mw->bind($class,"<Delete>",'Delete');

Obsérvese que $class es el nombre de la clase (por ejemplo, Tk::MyText) y $mw es la ventana principal.

No olvide llamar a $class->SUPER::ClassInit($mw) en ClassInit.

Component

Función de conveniencia para crear subwidgets.

Uso:

$cw->Component('Cualquiera', 'NombreAnunciado',
    -delegate => ['metodo1', 'metodo2', ...],
    ... más opciones de widget ...,
);

Component hace varias cosas por usted con una sola llamada:

o Crea el widget

o Lo anuncia con un nombre dado (sobrescrito por la opción 'Name')

o Delega un conjunto de métodos a este widget (opcional)

Ejemplo:

$cw->Component('Button', 'botonSalir', -command => sub{$mw->'destroy'});

ConfigSpecs

Define opciones y su tratamiento

Uso:

$cw->ConfigSpecs(
    -opcion => [ donde, dbname, dbclass, default],
    ...,
    DEFAULT => [donde],
);

Define las opciones de un mega-widget y qué acciones se activan con configure/cget de una opción (ver Tk::ConfigSpecs y Tk::Derived para detalles).

Construct

Hace que el nuevo mega-widget sea conocido por Tk.

Uso:

    Construct clabase 'Nombre';

Construct declara la nueva clase de widget para que su mega-widget funcione como los widgets normales de Perl/Tk.

Ejemplos:

    Construct Tk::Widget 'Cualquiera';     Construct Tk::Menu 'ItemMi';

El primer ejemplo permite usar $widget->Cualquiera para crear un nuevo widget Cualquiera.

El segundo ejemplo restringe el uso del método constructor ItemMi a los widgets derivados de Menu: $esunmenu->ItemMi.

CreateArgs

Procesa las opciones antes de que se cree cualquier widget:

    sub CreateArgs { my ($package, $parent, $args) = @_; ...; return @nuevosargs; }

$package es el paquete del mega-widget (por ejemplo, Tk::MiTexto), $parent el padre del widget a crear y $args la referencia al hash de las opciones especificadas en la llamada al constructor del widget.

No olvide llamar a $package->SUPER::CreateArgs($parent, $args) en CreateArgs.

Delegates

Redirige un método del mega-widget a un subwidget del widget compuesto

Uso:

$cw->Delegates(
    'metodo1' => $subwidget1,
    'metodo2' => 'nombreAnunciado',
    ...,
    'Construct' => $subwidget2,
    'DEFAULT'   => $subwidget3,
);
