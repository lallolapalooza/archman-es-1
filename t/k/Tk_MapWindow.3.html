Tk_MapWindow(3) Procedimientos de la biblioteca Tk Tk_MapWindow(3)

NOMBRE

Tk_MapWindow, Tk_UnmapWindow - mapear o desmapear una ventana

SINOPSIS

#include <tk.h>

Tk_Window
Tk_MapWindow(tkwin)

Tk_UnmapWindow(tkwin)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token de la ventana.

DESCRIPCIÓN

Estos procedimientos pueden usarse para mapear y desmapear ventanas administradas por Tk. Tk_MapWindow mapea la ventana dada por tkwin, y también crea una ventana X correspondiente a tkwin si aún no existe. Consulte la entrada del manual Tk_CreateWindow para obtener información sobre la creación diferida de ventanas. Tk_UnmapWindow desmapea la ventana de tkwin de la pantalla.

Si tkwin es una ventana hija (es decir, se utilizó Tk_CreateWindow para crear una ventana hija), entonces los manejadores de eventos interesados en eventos de mapeo y desmapeo se invocan de inmediato. Si tkwin no es una ventana interna, entonces los manejadores de eventos se invocarán más tarde, después de que X haya procesado la solicitud y devuelto un evento para ella.

Estos procedimientos deben usarse en lugar de los procedimientos X XMapWindow y XUnmapWindow, ya que actualizan la estructura de datos local de Tk para tkwin. Las aplicaciones que usan Tk no deben invocar XMapWindow y XUnmapWindow directamente.
