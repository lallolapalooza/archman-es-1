DESCRIPCION

Tk_WindowId y los otros nombres listados arriba son macros que devuelven campos de la estructura de datos local de Tk para tkwin. Ninguna de estas macros requiere interacción alguna con el servidor; es seguro asumir que todas son rápidas.

Tk_WindowId devuelve el identificador X para tkwin, o NULL si aún no se ha creado ninguna ventana X para tkwin.

Tk_Parent devuelve el token de Tk para el padre lógico de tkwin. El padre es el token que se especificó cuando se creó tkwin, o NULL para ventanas principales.

Tk_Interp devuelve el intérprete Tcl asociado con un tkwin o NULL si hay un error.

Tk_Display devuelve un puntero a la estructura de visualización Xlib correspondiente a tkwin. Tk_DisplayName devuelve una cadena ASCII que identifica la pantalla de tkwin. Tk_ScreenNumber devuelve el índice de la pantalla de tkwin entre todas las pantallas de la pantalla de tkwin. Tk_Screen devuelve un puntero a la estructura Xlib correspondiente a la pantalla de tkwin.

Tk_X, Tk_Y, Tk_Width y Tk_Height devuelven información sobre la ubicación de tkwin dentro de su padre y su tamaño. La información de ubicación se refiere al píxel superior izquierdo en la ventana, o a su borde si lo tiene. La información de ancho y alto se refiere al tamaño interior de la ventana, sin incluir ningún borde. Tk_Changes devuelve un puntero a una estructura que contiene toda la información anterior más algunos campos adicionales. Tk_Attributes devuelve un puntero a una estructura XSetWindowAttributes que describe todos los atributos de la ventana de tkwin, como el pixmap de fondo, la máscara de eventos, etc. (Tk realiza un seguimiento de toda esta información a medida que la aplicación la modifica). Tenga en cuenta: es esencial que las aplicaciones utilicen procedimientos de Tk como Tk_ResizeWindow en lugar de procedimientos X como XResizeWindow, para que Tk pueda mantener sus estructuras de datos actualizadas.

Tk_IsContainer devuelve un valor distinto de cero si tkwin es un contenedor y que alguna otra aplicación puede estar incrustándose dentro de tkwin.

Tk_IsEmbedded devuelve un valor distinto de cero si tkwin no es una ventana independiente, sino que está incrustada en alguna otra aplicación.

Tk_IsMapped devuelve un valor distinto de cero si tkwin está mapeada y cero si tkwin no está mapeada.

Tk_IsTopLevel devuelve un valor distinto de cero si tkwin es una ventana de nivel superior (su padre X es la ventana raíz de la pantalla) y cero si tkwin no es una ventana de nivel superior.

Tk_ReqWidth y Tk_ReqHeight devuelven información sobre el tamaño solicitado de la ventana. Estos valores corresponden a la última llamada a Tk_GeometryRequest para tkwin.

Tk_MinReqWidth y Tk_MinReqHeight devuelven información sobre el tamaño mínimo solicitado de la ventana. Estos valores corresponden a la última llamada a Tk_SetMinimumRequestSize para tkwin.

Tk_InternalBorderLeft, Tk_InternalBorderRight, Tk_InternalBorderTop y Tk_InternalBorderBottom devuelven el ancho de un lado del borde interno que se ha solicitado para tkwin, o 0 si no se ha solicitado ningún borde interno. El valor de retorno es simplemente el último valor pasado a Tk_SetInternalBorder o Tk_SetInternalBorderEx para tkwin.

Tk_Visual, Tk_Depth y Tk_Colormap devuelven información sobre las características visuales de una ventana. Tk_Visual devuelve el tipo visual para la ventana, Tk_Depth devuelve el número de bits por píxel y Tk_Colormap devuelve el mapa de colores actual para la ventana. Las características visuales se establecen normalmente a partir de los valores predeterminados de la pantalla de la ventana, pero pueden ser anuladas llamando a Tk_SetWindowVisual.
