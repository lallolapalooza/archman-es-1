NOMBRE

Tk::Button - Crea y manipula widgets de Botón

SINOPSIS

$boton = $padre->Button(?opciones?);

OPCIONES ESTÁNDAR

-activebackground -activeforeground -anchor -background -bitmap -borderwidth -compound -cursor -disabledforeground -font -foreground -highlightbackground -highlightcolor -highlightthickness -image -justify -padx -pady -relief -repeatdelay -repeatinterval -takefocus -text -textvariable -underline -wraplength

Ver Tk::options para más detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: command
Clase: Command
Interruptor: -command
Especifica una rutina de devolución de llamada de Perl/Tk para asociar con el botón. Este comando se invoca típicamente cuando se suelta el botón 1 del ratón sobre la ventana del botón.
Nombre de línea de comandos: -compound
Nombre de base de datos: compound
Clase de base de datos: Compound
Especifica si el botón debe mostrar tanto una imagen como texto, y si es así, dónde debe colocarse la imagen en relación con el texto. Los valores válidos para esta opción son bottom, center, left, none, right y top. El valor por defecto es none, lo que significa que el botón mostrará una imagen o texto, dependiendo de los valores de las opciones -image y -bitmap.
Nombre: default
Clase: Default
Interruptor: -default
Especifica uno de los tres estados para el anillo por defecto: normal, active, o disabled. En estado activo, el botón se dibuja con la apariencia específica de la plataforma para un botón por defecto. En estado normal, el botón se dibuja con la apariencia específica de la plataforma para un botón no por defecto, dejando suficiente espacio para dibujar la apariencia del botón por defecto. Los estados normal y activo darán como resultado botones del mismo tamaño. En estado deshabilitado, el botón se dibuja con la apariencia de botón no por defecto sin dejar espacio para la apariencia por defecto. El estado deshabilitado puede dar como resultado un botón más pequeño que el estado activo. anillo.
Nombre: height
Clase: Height
Interruptor: -height
Especifica una altura deseada para el botón. Si se está mostrando una imagen o un bitmap en el botón, el valor está en unidades de pantalla (es decir, cualquier forma aceptable por Tk_GetPixels); para texto está en líneas de texto. Si no se especifica esta opción, la altura deseada del botón se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en él.
Nombre de línea de comandos: -overrelief
Nombre de base de datos: overRelief
Clase de base de datos: OverRelief
Especifica un relieve alternativo para el botón, que se utilizará cuando el cursor del ratón esté sobre el widget. Esta opción se puede utilizar para crear botones de barra de herramientas, configurando -relief flat -overrelief raised. Si el valor de esta opción es una cadena vacía, entonces no se utiliza ningún relieve alternativo cuando el cursor del ratón está sobre el botón. La cadena vacía es el valor por defecto.
Nombre: state
Clase: State
Interruptor: -state
Especifica uno de los tres estados del botón: normal, active, o disabled. En estado normal, el botón se muestra utilizando las opciones foreground y background. El estado activo se utiliza típicamente cuando el puntero está sobre el botón. En estado activo, el botón se muestra utilizando las opciones activeForeground y activeBackground. El estado deshabilitado significa que el botón debe ser insensible: las asociaciones por defecto se negarán a activar el widget e ignorarán las pulsaciones del botón del ratón. En este estado, las opciones disabledForeground y background determinan cómo se muestra el botón.
Nombre: width
Clase: Width
Interruptor: -width
Especifica un ancho deseado para el botón. Si se está mostrando una imagen o un bitmap en el botón, el valor está en unidades de pantalla (es decir, cualquier forma aceptable por Tk_GetPixels); para texto está en caracteres. Si no se especifica esta opción, el ancho deseado del botón se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en él.

DESCRIPCIÓN

El método Button crea una nueva ventana (proporcionada por el argumento $widget) y la convierte en un widget de botón. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del botón como sus colores, fuente, texto y relieve inicial. El comando button devuelve su argumento $widget. En el momento en que se invoca este comando, no debe existir una ventana llamada $widget, pero el padre de $widget debe existir.

Un botón es un widget que muestra una cadena de texto, un bitmap o una imagen. Si se muestra texto, debe estar todo en una sola fuente, pero puede ocupar múltiples líneas en la pantalla (si contiene saltos de línea o si ocurre ajuste de línea debido a la opción -wraplength) y uno de los caracteres puede ser opcionalmente subrayado usando la opción -underline. Puede mostrarse de tres maneras diferentes, según la opción -state; puede hacerse que parezca elevado, hundido o plano; y puede hacerse que parpadee. Cuando un usuario invoca el botón (al presionar el botón 1 del ratón con el cursor sobre el botón), se invoca la rutina de devolución de llamada de perl/Tk especificada en la opción -command.

MÉTODOS DEL WIDGET

El método Button crea un objeto widget. Este objeto soporta los métodos configure y cget descritos en Tk::options, que se pueden usar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

Los siguientes métodos adicionales están disponibles para los widgets de botón:

$boton->flash
Hace parpadear el botón. Esto se logra redibujando el botón varias veces, alternando entre los colores activo y normal. Al final del parpadeo, el botón queda en el mismo estado normal/activo que cuando se invocó el comando. Este comando se ignora si el estado del botón es disabled.
$boton->invoke
Invoca la rutina de devolución de llamada asociada con la opción -command del botón, si existe. El valor de retorno es el valor de retorno de la rutina de devolución de llamada, o el valor indefinido si no hay una rutina de devolución de llamada asociada con el botón. Este comando se ignora si el estado del botón es disabled.

DESCRIPTION

A button widget is used to display text and/or an image and to react to button presses. The button can be invoked by pressing mouse button 1 while the pointer is over the button, or by pressing the space bar when the button has the input focus.

SYNOPSIS

    my $button = $parent->Button(
        -text    => 'Click Me',
        -command => sub { print "Button clicked!\n" }
    )->pack;

NAME

Tk::Button - create and manage button widgets

DEFAULT BINDINGS

The default bindings for buttons are as follows:

[1]
If the mouse pointer moves into the button's window, the button's relief changes to sunken. If the pointer moves out of the button's window, the relief reverts to its original value. This binding is only active when mouse button 1 has been pressed over the button. Under Windows, this binding is only active when mouse button 1 has been pressed over the button.
[2]
A button's relief is changed to sunken whenever mouse button 1 is pressed over the button, and the relief is restored to its original value when button 1 is later released.
[3]
If mouse button 1 is pressed over a button and later released over the button, the button is invoked. However, if the mouse is not over the button when button 1 is released, then no invocation occurs.
[4]
When a button has the input focus, the space key causes the button to be invoked.

If the button's state is disabled then none of the above actions occur: the button is completely non-responsive.

The behavior of buttons can be changed by defining new bindings for individual widgets or by redefining the class bindings.
