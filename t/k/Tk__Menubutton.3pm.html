OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos: -compound
Nombre de base de datos: compound
Clase de base de datos: Compound
Especifica si el botón debe mostrar tanto una imagen como texto, y si es así, dónde debe colocarse la imagen en relación con el texto. Los valores válidos para esta opción son bottom, center, left, none, right y top. El valor predeterminado es none, lo que significa que el botón mostrará una imagen o texto, dependiendo de los valores de las opciones -image y -bitmap.
Nombre: direction
Clase: Height
Switch: -direction
Especifica dónde aparecerá el menú. above intenta mostrar el menú encima del menubutton. below intenta mostrar el menú debajo del menubutton. left intenta mostrar el menú a la izquierda del menubutton. right intenta mostrar el menú a la derecha del menubutton. flush muestra el menú directamente sobre el menubutton.
Nombre: height
Clase: Height
Switch: -height
Especifica una altura deseada para el menubutton. Si se está mostrando una imagen o bitmap en el menubutton, el valor está en unidades de pantalla (es decir, cualquier forma aceptable para Tk_GetPixels); para texto está en líneas de texto. Si no se especifica esta opción, la altura deseada del menubutton se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en él.
Nombre: indicatorOn
Clase: IndicatorOn
Switch: -indicatoron
El valor debe ser un valor booleano correcto. Si es verdadero, se mostrará un pequeño rectángulo indicador en el lado derecho del menubutton y las uniones predeterminadas del menú tratarán esto como un menubutton de opción. Si es falso, no se mostrará ningún indicador.
Nombre: menu
Clase: MenuName
Switch: -menu
Especifica el nombre de ruta del menú asociado con este menubutton. El menú debe ser un hijo del menubutton.
Nombre: state
Clase: State
Switch: -state
Especifica uno de los tres estados del menubutton: normal, active o disabled. En estado normal, el menubutton se muestra utilizando las opciones foreground y background. El estado activo se utiliza típicamente cuando el puntero está sobre el menubutton. En estado activo, el menubutton se muestra utilizando las opciones activeForeground y activeBackground. El estado deshabilitado significa que el menubutton debe ser insensible: las uniones predeterminadas rechazarán la activación del widget e ignorarán las pulsaciones del botón del ratón. En este estado, las opciones disabledForeground y background determinan cómo se muestra el botón.
Nombre: width
Clase: Width
Switch: -width
Especifica un ancho deseado para el menubutton. Si se está mostrando una imagen o bitmap en el menubutton, el valor está en unidades de pantalla (es decir, cualquier forma aceptable para Tk_GetPixels); para texto está en caracteres. Si no se especifica esta opción, el ancho deseado del menubutton se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en él.

DESCRIPCIÓN

El método Menubutton crea una nueva ventana (dada por el argumento $widget) y la convierte en un widget menubutton. Opciones adicionales, descritas anteriormente, se pueden especificar en la línea de comandos o en la base de datos de opciones para configurar aspectos del menubutton como sus colores, fuente, texto y alivio inicial. El comando menubutton devuelve su argumento $widget. En el momento en que se invoca este comando, no debe existir una ventana llamada $widget, pero el padre de $widget debe existir.

Un menubutton es un widget que muestra una cadena de texto, un bitmap o una imagen y está asociado con un widget de menú. Si se muestra texto, todo debe estar en una sola fuente, pero puede ocupar varias líneas en la pantalla (si contiene saltos de línea o si se produce un ajuste de línea debido a la opción wrapLength) y uno de los caracteres puede estar opcionalmente subrayado utilizando la opción underline. En el uso normal, presionar el botón del ratón 1 sobre el menubutton hace que el menú asociado se publique justo debajo del menubutton. Si el ratón se mueve sobre el menú antes de soltar el botón del ratón, la liberación del botón hace que se invoque la entrada del menú subyacente. Cuando se suelta el botón, el menú se despublíca.

Los menubuttons generalmente se organizan en grupos llamados barras de menú que permiten el escaneo: si el botón del ratón se presiona sobre un menubutton (haciéndolo publicar su menú) y el ratón se mueve sobre otro menubutton en la misma barra de menú sin soltar el botón del ratón, entonces el menú del primer menubutton se despublica y se publica el menú del nuevo menubutton en su lugar.

Hay varias interacciones entre menubuttons y menús; ver la entrada del manual menu para obtener información sobre varias configuraciones de menú, como menús desplegables y menús de opciones.

MÉTODOS DEL WIDGET

El método Menubutton crea un objeto widget. Este objeto soporta los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El método menu devuelve el menú asociado con el widget. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

UNIONES PREDETERMINADAS

Tk crea automáticamente uniones de clase para los menubuttons que les dan el siguiente comportamiento predeterminado:

[1]
Un menubutton se activa cada vez que el ratón pasa sobre él y se desactiva cada vez que el ratón sale de él.
[2]
Presionar el botón del ratón 1 sobre un menubutton publica el menubutton: su alivio cambia a realzado y su menú asociado se publica debajo del menubutton. Si el ratón se arrastra hacia el menú con el botón aún presionado, y si el botón del ratón se suelta sobre una entrada en el menú, el menubutton se despublica y se invoca la entrada del menú.
[3]
Si el botón 1 se presiona sobre un menubutton y luego se suelta sobre ese menubutton, el menubutton permanece publicado: todavía puedes mover

DESCRIPCIÓN

Tk::Menubutton es un widget que permite al usuario invocar una entrada de menú pasando el ratón sobre un botón de menú y haciendo clic con el botón 1. Una vez que se ha invocado una entrada de menú, el botón de menú se desactiva.

Si se presiona el botón 1 sobre un botón de menú y luego se arrastra sobre otro botón de menú, el botón de menú original se desactiva y el nuevo botón de menú se activa.

Si se presiona el botón 1 sobre un botón de menú y se suelta fuera de cualquier botón de menú o menú, el botón de menú se desactiva sin invocar ninguna entrada de menú.

Cuando se activa un botón de menú, su menú asociado reclama el foco de entrada para permitir la navegación por teclado del menú y sus submenús. Consulte la documentación de menu para obtener detalles sobre estas asociaciones.

Si se ha especificado la opción underline para un botón de menú, la navegación por teclado puede utilizarse para activar el botón de menú: Se puede escribir Alt+x, donde x es el carácter subrayado (o su equivalente en mayúsculas o minúsculas), en cualquier ventana debajo de la ventana superior del botón de menú para activarlo.

Se puede escribir la tecla F10 en cualquier ventana para activar el primer botón de menú debajo de su ventana superior que no esté deshabilitado.

Si el botón de menú tiene el foco de entrada, las teclas de espacio y retorno lo activan.

Si el estado del botón de menú es disabled (deshabilitado), ninguna de las acciones anteriores ocurre: el botón de menú es completamente irresponsable.

El comportamiento de los botones de menú se puede cambiar definiendo nuevas asociaciones para widgets individuales o redefiniendo las asociaciones de clase.
