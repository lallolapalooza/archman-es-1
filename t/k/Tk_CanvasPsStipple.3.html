Tk_CanvasPs(3) Procedimientos de la biblioteca Tk Tk_CanvasPs(3)

NOMBRE

Tk_CanvasPsY, Tk_CanvasPsBitmap, Tk_CanvasPsColor, Tk_CanvasPsFont, Tk_CanvasPsPath, Tk_CanvasPsStipple - procedimientos de utilidad para generar Postscript para lienzos

SINOPSIS

#include <tk.h>

double
Tk_CanvasPsY(canvas, canvasY)

int
Tk_CanvasPsBitmap(interp, canvas, bitmap, x, y, width, height)

int
Tk_CanvasPsColor(interp, canvas, colorPtr)

int
Tk_CanvasPsFont(interp, canvas, tkFont)

Tk_CanvasPsPath(interp, canvas, coordPtr, numPoints)

int
Tk_CanvasPsStipple(interp, canvas, bitmap)

ARGUMENTOS

Tk_Canvas canvas (entrada)
Un token que identifica un widget de lienzo para el cual se está generando Postscript.
double canvasY (entrada)
Coordenada Y en el espacio del lienzo.
Tcl_Interp *interp (entrada/salida)
Un intérprete Tcl; el Postscript se anexa a su resultado, o el resultado puede ser reemplazado por un mensaje de error.
Pixmap bitmap (entrada)
Mapa de bits a utilizar para generar Postscript.
int x (entrada)
Coordenada X dentro de bitmap del borde izquierdo de la región a mostrar.
int y (entrada)
Coordenada Y dentro de bitmap del borde superior de la región a mostrar.
int width (entrada)
Ancho de la región del mapa de bits a mostrar, en píxeles.
int height (entrada)
Alto de la región del mapa de bits a mostrar, en píxeles.
XColor *colorPtr (entrada)
Información sobre el valor del color a establecer en Postscript.
Tk_Font tkFont (entrada)
Fuente para la cual se generará Postscript.
double *coordPtr (entrada)
Puntero a un array de coordenadas para uno o más puntos especificados en coordenadas de lienzo. El orden de los valores en coordPtr es x1, y1, x2, y2, x3, y3, y así sucesivamente.
int numPoints (entrada)
Número de puntos en coordPtr.

DESCRIPCIÓN

Estos procedimientos son llamados por los gestores de tipos de lienzo para llevar a cabo funciones comunes relacionadas con la generación de Postscript. La mayoría de los procedimientos toman un argumento canvas, que se refiere a un widget de lienzo para el cual se está generando Postscript.

Tk_CanvasPsY toma como argumento una coordenada Y en el espacio de un lienzo y devuelve el valor que debe usarse para ese punto en el Postscript que se está generando actualmente para canvas. Las coordenadas Y requieren transformación porque Postscript usa un origen en la esquina inferior izquierda, mientras que X usa un origen en la esquina superior izquierda. Las coordenadas X del lienzo se pueden usar directamente en Postscript sin transformación.

Tk_CanvasPsBitmap genera Postscript para describir una región de un mapa de bits. El Postscript se genera en el formato de datos de imagen adecuado para Postscript, es decir, como datos entre corchetes angulares, un bit por píxel. El Postscript se anexa al resultado del intérprete interp y se devuelve TCL_OK a menos que ocurra un error, en cuyo caso se devuelve TCL_ERROR y el resultado del intérprete se sobrescribe con un mensaje de error.

Tk_CanvasPsColor genera Postscript para establecer el color actual para que corresponda a su argumento colorPtr, teniendo en cuenta cualquier mapa de colores especificado en el comando postscript. Anexa el Postscript al resultado del intérprete interp y devuelve TCL_OK a menos que ocurra un error, en cuyo caso se devuelve TCL_ERROR y el resultado del intérprete se sobrescribe con un mensaje de error.

Tk_CanvasPsFont genera Postscript que establece la fuente actual para que coincida con tkFont lo más cerca posible. Tk_CanvasPsFont tiene en cuenta cualquier mapa de fuentes especificado en el comando postscript, y hace lo mejor que puede para mapear fuentes X a fuentes Postscript. Anexa el Postscript al resultado del intérprete interp y devuelve TCL_OK a menos que ocurra un error, en cuyo caso se devuelve TCL_ERROR y el resultado del intérprete se sobrescribe con un mensaje de error.

Tk_CanvasPsPath genera Postscript para establecer la ruta actual al conjunto de puntos dados por coordPtr y numPoints. Anexa el Postscript resultante al resultado del intérprete interp.

Tk_CanvasPsStipple genera Postscript que rellenará la ruta actual de forma moteada. Utiliza bitmap como patrón de moteado y el color Postscript actual; los unos en el mapa de bits de moteado se dibujan en el color actual, y los ceros no se dibujan en absoluto. El Postscript se anexa al resultado del intérprete interp y se devuelve TCL_OK, a menos que ocurra un error, en cuyo caso se devuelve TCL_ERROR y el resultado del intérprete se sobrescribe con un mensaje de error.
