NOMBRE

Tk::BrowseEntry - widget de entrada con opciones emergentes.

SINOPSIS

use Tk::BrowseEntry;
$b = $frame->BrowseEntry(-label => "Etiqueta", -variable => \$var);
$b->insert("end", "opcion1");
$b->insert("end", "opcion2");
$b->insert("end", "opcion3");
...
$b->pack;

SUPERCLASE

La clase "BrowseEntry" se deriva de la clase "Frame" y hereda todos los métodos, opciones y subwidgets de su superclase. Por defecto, las opciones y métodos se delegan al subwidget de entrada.

DESCRIPCIÓN

BrowseEntry es un ComboBox de "hombre pobre". Puede considerarse una versión mejorada de LabEntry que proporciona un botón para mostrar las opciones de los valores posibles que puede tomar la Entrada. BrowseEntry soporta todas las opciones que soporta LabEntry excepto -textvariable. Esto es reemplazado por -variable. Otras opciones que BrowseEntry soporta:

-arrowimage
Especifica la imagen a usar en el botón de flecha junto al widget de entrada. El valor predeterminado es una imagen de flecha hacia abajo en el archivo cbxarrow.xbm
-autolimitheight
Si se establece a un valor verdadero, la altura de la lista será como máximo el número de entradas en la lista. El máximo general de "-listheight" todavía se aplica.
-autolistwidth
Si se establece a un valor verdadero, el ancho de la lista coincidirá con el ancho de la entrada más grande.
-browsecmd
Especifica una función a llamar cuando se realiza una selección en la lista emergente. Se le pasa el widget y el texto de la entrada seleccionada. Esta función se llama después de que la variable de entrada haya sido asignada al valor.
-browse2cmd
Similar a "-browsecmd", pero la función de devolución de llamada se llama con el índice de la lista en lugar del valor seleccionado.
-buttontakefocus
Establece la opción "-takefocus" del subwidget del botón.
-choices
Especifica la lista de opciones a mostrar. Esta es una referencia a un array de cadenas que especifican las opciones.
-colorstate
El estado del widget se refleja por el color. Una entrada no editable obtendrá un fondo gris claro, mientras que una entrada editable será casi blanca. [Esto puede cambiar]
-listcmd
Especifica la función a llamar cuando se presiona el botón junto a la entrada para mostrar las opciones en la lista. Esto se llama antes de mostrar la lista, por lo que se puede usar para poblar las entradas en la lista.
-listheight
Establece la altura de la lista. Ver también "-autolimitheight".
-listwidth
Especifica el ancho de la lista emergente.
-state
Especifica uno de los tres estados para el widget: normal, solo lectura o desactivado. Si el widget está desactivado, el valor no se puede cambiar y el botón de flecha no se activará. Si el widget está en modo de solo lectura, la entrada no se puede editar, pero se puede cambiar eligiendo un valor de la lista emergente. El estado normal es el predeterminado.
-style
Establece el "estilo" del widget. Los valores permitidos son "MSWin32" y "unix". Por defecto "-style" se establece a la plataforma actual. Los widgets con el estilo "unix" se verán como un widget "BrowseEntry" normal, mientras que con el estilo "MSWin32" la flecha se parecerá al widget combobox estándar de Windows, al mover el ratón las entradas se resaltarán y probablemente incluirá otros cambios.
-variable
Especifica la variable en la que se almacenará el valor introducido.

MÉTODOS

insert(índice, cadena)
Inserta el texto de cadena en el índice especificado. Esta cadena se convierte entonces en una de las opciones disponibles.
delete(índice1, índice2)
Elimina elementos desde índice1 hasta índice2.
get
El método get se delega a la lista de opciones.

WIDGETS ANUNCIADOS

Los siguientes widgets se anuncian:

entry
El widget de entrada.
arrow
El botón con la imagen de flecha.
choices
El widget de nivel superior que contiene la lista de opciones.
slistbox
La lista con desplazamiento que contiene las opciones.

SUBCLASES

Para facilitar la creación de subclases, los siguientes métodos pueden ser sobrescritos para usar otros widgets estándar en la composición del mega widget:

LabEntryWidget
Una clase de widget compatible con Tk::LabEntry utilizada para la entrada.
ButtonWidget
Una clase de widget compatible con Tk::Button utilizada para el botón de flecha.
ListboxWidget
Una clase de widget compatible con Tk::Listbox utilizada para la lista de opciones.

Por ejemplo, para usar un widget "NumEntry" (de la distribución CPAN Tk-GBARR) en lugar del widget "Entry" normal:

package Tk::NumBrowseEntry;
use base qw(Tk::BrowseEntry);
use Tk::NumEntry;
Construct Tk::Widget 'NumBrowseEntry';
sub LabEntryWidget { "NumEntry" }

ERRORES

BrowseEntry realmente debería proporcionar más opciones de ComboBox.

Tk::BrowseEntry - Perl/Tk widget

NAME
Tk::BrowseEntry - A widget that allows browsing of a list of values
SYNOPSIS
use Tk;
use Tk::BrowseEntry;

my $browse_entry = $mw->BrowseEntry(
    -label    => 'Select a value:',
    -listtype => 'listbox', # o 'popup'
    -browsecmd => \&my_callback,
    -variable => \$my_variable,
    -values   => ['Value 1', 'Value 2', 'Value 3'],
    -state    => 'normal'
);
$browse_entry->pack();
SUPER-CLASS
Tk::Frame
DESCRIPTION
The BrowseEntry widget is a composite widget that combines a text entry field with a button. When the button is pressed, it displays a list of values in either a popup list or a separate listbox. The user can then select a value from the list, which will be displayed in the entry field. This widget is useful for providing users with a predefined set of options to choose from, while still allowing them to type in a value if needed (depending on configuration).
METHODS
In addition to the standard Tk widget methods, BrowseEntry supports the following:
  • -browsecmd: A callback executed when a value is selected from the list.
  • -variable: A Tk variable to store the currently selected value.
  • -values: An array reference containing the list of values to display.
  • -listtype: Specifies how the list is displayed ('listbox' or 'popup'). Defaults to 'listbox'.
  • -label: Text for a label widget displayed next to the BrowseEntry.
  • -state: The state of the widget ('normal', 'disabled', 'readonly').
ADVERTISED_WIDGETS
The BrowseEntry widget internally uses a Tk::Entry and either a Tk::Listbox or a Tk::Menu (for 'popup').
SUBCLASSING
Subclassing BrowseEntry is possible but rarely necessary. Most customization can be achieved through its configuration options.
