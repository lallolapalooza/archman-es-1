NOMBRE

Tk_HWNDToWindow - Encuentra información de ventana de Tk para una ventana de Windows

SINOPSIS

#include <tkPlatDecls.h>

Tk_Window
Tk_HWNDToWindow(hwnd)

ARGUMENTOS

HWND hwnd (entrada)
Identificador de ventana de Windows.

DESCRIPCIÓN

Dado un identificador de ventana HWND de Windows, este procedimiento devuelve el manejador Tk_Window correspondiente. Si no hay ningún Tk_Window que corresponda a hwnd, se devuelve NULL.

PALABRAS CLAVE
