Tk_SetClassProcs(3) Procedimientos de la biblioteca Tk Tk_SetClassProcs(3)

NOMBRE

Tk_SetClassProcs - registrar procedimientos específicos del widget

SINOPSIS

#include <tk.h>

Tk_SetClassProcs(tkwin, procs, instanceData)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token de la ventana a modificar.
const Tk_ClassProcs *procs (entrada)
Puntero a la estructura de datos que contiene los procedimientos específicos del widget. La estructura de datos apuntada por procs debe ser estática: Tk mantiene una referencia a ella mientras la ventana exista.
ClientData instanceData (entrada)
Valor arbitrario de una palabra para pasar a las devoluciones de llamada del widget.

DESCRIPCIÓN

Se llama a Tk_SetClassProcs para registrar un conjunto de procedimientos que se utilizan como devoluciones de llamada en diferentes lugares.

La estructura apuntada por procs contiene lo siguiente:

typedef struct Tk_ClassProcs {
    unsigned int size;
    Tk_ClassWorldChangedProc *worldChangedProc;
    Tk_ClassCreateProc *createProc;
    Tk_ClassModalProc *modalProc;
} Tk_ClassProcs;
El campo size se utiliza para simplificar la expansión futura de la estructura. Siempre debe establecerse en (literalmente) sizeof(Tk_ClassProcs).

worldChangedProc se invoca cuando el sistema ha alterado de alguna manera que requiere alguna reacción por parte del widget. Por ejemplo, cuando se reconfigura un alias de fuente (ver la entrada del manual font), los widgets configurados para usar ese alias de fuente deben actualizar su visualización en consecuencia. worldChangedProc debe tener argumentos y resultados que coincidan con el tipo Tk_ClassWorldChangedProc:

typedef void Tk_ClassWorldChangedProc(
        ClientData instanceData);
El parámetro instanceData pasado a worldChangedProc será idéntico al parámetro instanceData pasado a Tk_SetClassProcs.

createProc se utiliza para crear ventanas dependientes de la plataforma. Es invocado por Tk_MakeWindowExist. createProc debe tener argumentos y resultados que coincidan con el tipo Tk_ClassCreateProc:

typedef Window Tk_ClassCreateProc(
        Tk_Window tkwin,
        Window parent,
        ClientData instanceData);
Los parámetros tkwin e instanceData serán idénticos a los parámetros tkwin e instanceData pasados a Tk_SetClassProcs. El parámetro parent será el padre de la ventana a crear. createProc debe devolver la ventana creada.

modalProc se invoca después de que se hayan activado todas las asociaciones en un widget para manejar un bucle modal. modalProc debe tener argumentos y resultados que coincidan con el tipo Tk_ClassModalProc:

typedef void Tk_ClassModalProc(
        Tk_Window tkwin,
        XEvent *eventPtr);
El parámetro tkwin de modalProc será idéntico al parámetro tkwin pasado a Tk_SetClassProcs. El parámetro eventPtr será un puntero a una estructura XEvent que describe el evento que se está procesando.
