NOMBRE

Tk::Adjuster - Permite que el tamaño de los widgets empaquetados sea ajustado por el usuario

SINAPSIS

use Tk::Adjuster;

$ajustador = $widget->Adjuster(?opciones?);

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: restaurar
Clase: Restore
Opción: -restore
Especifica un valor booleano que determina si el Ajustador debe intentar forzarmente hacer espacio para sí mismo (reduciendo el tamaño de su widget gestionado) cuando no está mapeado (por ejemplo, debido a un cambio de tamaño en una ventana de nivel superior). El valor por defecto es 1.
Nombre: lado
Clase: Side
Opción: -side
Especifica el lado en el que se encuentra el widget gestionado en relación con el Ajustador. En conjunción con el gestor de geometría `pack`, esto se refiere al lado del maestro contra el cual se empaquetan el widget gestionado y el Ajustador. Debe ser left, right, top, o bottom. Por defecto es top.
Nombre: widget
Clase: Widget
Opción: -widget
Especifica el widget que será gestionado por el Ajustador.

DESCRIPCIÓN

Tk::Adjuster es un Frame que contiene una "línea" y un "punto".

Arrastrar con el Botón-1 del ratón resulta en una línea que se arrastra para indicar el nuevo tamaño. Soltar el Botón-1 envía GeometryRequests en nombre del widget gestionado, lo que provocará que el empaquetador cambie el tamaño del widget.

Si el arrastre se realiza con la tecla Shift presionada, entonces se envían GeometryRequests en "tiempo real" para que se puedan ver los efectos de flujo de texto, pero como se realiza mucho más trabajo, el comportamiento puede ser lento.

Si el widget se empaqueta con -side => left o -side => right, se ajusta el ancho. Si se empaqueta -side => top o -side => bottom, se ajusta la altura.

packPropagate se desactiva para la ventana maestra para evitar que el ajuste cambie el tamaño total de la ventana. Del mismo modo, packPropagate se desactiva para el widget gestionado si tiene cosas empaquetadas dentro. Esto es para que las GeometryRequests realizadas por Tk::Adjuster no sean anuladas por pack.

Además, el widget gestionado se hace no expandible para evitar que el gestor de geometría reasigne el espacio liberado en el maestro al widget gestionado. Tenga en cuenta, sin embargo, que la expansión se desactiva solo después de que el Ajustador se mapea, lo que permite que el widget gestionado se expanda naturalmente en la creación de la ventana.

El método Tk::Widget, packAdjust, llama a pack en el widget, luego crea una instancia de Tk::Adjuster y empaqueta esa instancia "después" del widget. Sin embargo, su uso tiene dos desventajas: el widget Ajustador no se pone a disposición del llamador y las opciones no se pueden establecer en el Ajustador. Por estas razones, se prefiere el método Tk::Adjuster, packAfter, pero se mantiene packAdjust por compatibilidad con versiones anteriores.

MÉTODOS DEL WIDGET

$ajustador->packAfter(widget_gestionado, ?opciones_pack?)
Este comando configura las opciones -widget y -side del Ajustador respectivamente a widget_gestionado y al valor -side especificado en opciones_pack (top si no se especifica). Luego empaqueta el Ajustador después de widget_gestionado, con -fill establecido en x o y según corresponda.
$ajustador->packForget?(booleano)?
Este comando llama a Tk::Widget::packForget en el Ajustador. Si se proporciona un parámetro y tiene un valor booleano verdadero, entonces también se llama a packForget en el widget gestionado.
$ajustador->esclavo
Este comando devuelve el valor $ajustador->cget('-widget'), es decir, la referencia al widget gestionado.

EJEMPLOS

Uso de un Ajustador para separar dos widgets, donde el widget izquierdo es gestionado, y el widget derecho se expande para llenar el espacio en un redimensionamiento de ventana

a) Usando packAfter (interfaz preferida)

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $lst1 = $f->Listbox();
my $adj1 = $f->Adjuster();
my $lst2 = $f->Listbox();
my $lado = 'left';
$lst1->pack(-side => $lado, -fill => 'both', -expand => 1);
$adj1->packAfter($lst1, -side => $lado);
$lst2->pack(-side => $lado, -fill => 'both', -expand => 1);
MainLoop;

b) Usando packAdjust

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $lst1 = $f->Listbox();
my $lst2 = $f->Listbox();
my $lado = 'left';
$lst1->packAdjust(-side => $lado, -fill => 'both');
$lst2->pack      (-side => $lado, -fill => 'both', -expand => 1);
MainLoop;

c) Usando el Tk::Widget::pack estándar

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $lado = 'left';
my $lst1 = $f->Listbox();
my $adj  = $f->Adjuster(-widget => $lst1, -side => $lado);
my $lst2 = $f->Listbox();
$lst1->pack(-side => $lado, -fill => 'both', -expand => 1);
$adj->pack (-side => $lado, -fill => 'y');
$lst2->pack(-side => $lado, -fill => 'both', -expand => 1);
MainLoop;

Cambiar los ejemplos anteriores para que $lado tenga el valor 'right' significa que el widget izquierdo se expande para llenar el espacio en un redimensionamiento de ventana.

Cambiar los ejemplos anteriores para que $lado tenga el valor 'top' produce un caso de prueba con un Ajustador horizontal. Aquí, el widget inferior se expande para llenar el espacio en un redimensionamiento de ventana. Empaquetar a 'bottom' hace que el widget superior se expanda para llenar el espacio en un redimensionamiento de ventana.

Uso de -restore => 0 para múltiples columnas

En el caso de múltiples columnas (o filas), la funcionalidad de "restauración" del Ajustador puede ser inconveniente. Cuando el usuario ajusta el ancho de una columna y, por lo tanto, desplaza el Ajustador de otra columna fuera de la ventana, este Ajustador intenta restaurarse reduciendo el tamaño de su widget gestionado. Esto tiene el efecto de que los anchos de columna se reducen; y el tamaño original no se restaura cuando el usuario revierte el cambio original. La opción -restore se puede utilizar para desactivar esta funcionalidad. (Sin embargo, tiene cierto sentido dejar -restore activado para el primer Ajustador empaquetado, para que al menos un Ajustador permanezca siempre visible).

use Tk;
use Tk::Adjuster;
my $f = MainWindow->new;
my $lst1 = $f->Listbox();
my $adj1 = $f->Adjuster();
my $lst2 = $f->Listbox();
my $adj2 = $f->Adjuster(-restore => 0);
my $lst3 = $f->Listbox();
my $lado = 'left';
$lst1->pack(-side => $lado, -fill => 'both', -expand => 1);
$adj1->packAfter($lst1, -side => $lado);
$lst2->pack(-side => $lado, -fill => 'both', -expand => 1);
$adj2->packAfter($lst2, -side => $lado);
$lst3->pack(-side => $lado, -fill => 'both', -expand => 1);
MainLoop;

ERRORES

Actualmente no es posible configurar la apariencia del Ajustador. Sería bueno poder establecer el ancho y el relieve de la "línea" del Ajustador y la presencia/ausencia del "punto" en el Ajustador.

Tk::Adjuster funciona teóricamente con el gestor de geometría grid, pero actualmente existen algunos problemas que parecen deberse a errores en grid:

a) Nunca hay un evento Unmap para el ajustador, por lo que la funcionalidad
   de "restaurar" no tiene efecto.
b) Después de ajustar, los widgets sobresalen en el borde del maestro.
c) grid('Propagate', 0) en MainWindow no tiene efecto - la ventana se encoge/crece
   cuando se ajustan los widgets.
d) Los widgets se reordenan a la posición correcta al inicio
