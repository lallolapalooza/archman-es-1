NOMBRE

Tk::Image - Crear y manipular imágenes

SINOPSIS

$imagen = $widget->tipo(?arg arg ...?)

$imagen->método(?arg arg ...?)

DESCRIPCIÓN

Los constructores y métodos de image se utilizan para crear, eliminar y consultar imágenes. Puede tomar varias formas diferentes, dependiendo del tipo.

Los constructores requieren un $widget para invocarlos, esto se utiliza para localizar una MainWindow. (Esto se debe a que el código subyacente de Tk registra las imágenes en la estructura de datos de la MainWindow.)

Las formas legales son:

$widget->tipo?(?nombre?,?opción=>valor ...)?
Crea una nueva imagen y devuelve un objeto. tipo especifica el tipo de la imagen, que debe ser uno de los tipos actualmente definidos (por ejemplo, Bitmap). nombre especifica el nombre para la imagen; si se omite, Tk elige un nombre de la forma imagex, donde x es un entero. Puede haber cualquier número de pares opción=>valor, que proporcionan opciones de configuración para la nueva imagen. El conjunto legal de opciones se define por separado para cada tipo de imagen; véase más abajo los detalles de las opciones para los tipos de imagen integrados. Si ya existe una imagen con el nombre dado, se reemplaza por la nueva imagen y todas las instancias de esa imagen se redibujarán con el nuevo contenido.
$imagen->delete
Elimina la imagen $imagen y devuelve una cadena vacía. Si hay instancias de la imagen mostradas en widgets, la imagen no se eliminará realmente hasta que se liberen todas las instancias. Sin embargo, la asociación entre las instancias y el gestor de imágenes se eliminará. Las instancias existentes conservarán sus tamaños, pero se redibujarán como áreas vacías. Si se recrea una imagen eliminada (con el mismo nombre), las instancias existentes utilizarán la nueva imagen.
$imagen->height
Devuelve una cadena decimal que indica la altura de la imagen nombre en píxeles.
$imagen->inuse
Devuelve un valor booleano que indica si la imagen está en uso por algún widget.
$widget->imageNames
Devuelve una lista que contiene todas las imágenes existentes para la MainWindow de $widget.
$imagen->type
Devuelve el tipo de $imagen (el valor del método type cuando se creó la imagen).
$widget->imageTypes
Devuelve una lista cuyos elementos son todos los tipos de imagen válidos (es decir, todos los valores que pueden suministrarse para el tipo para crear una imagen).
$imagen->width
Devuelve una cadena decimal que indica el ancho de la imagen nombre en píxeles.

TIPOS DE IMAGEN INTEGRADOS

Los siguientes tipos de imagen están definidos por Tk, por lo que estarán disponibles en cualquier aplicación Tk. Las aplicaciones o extensiones individuales pueden definir tipos adicionales.

Bitmap
Cada píxel de la imagen muestra un color de primer plano, un color de fondo o nada. Consulte Tk::Bitmap para obtener más información.
Pixmap
Pixmap es ligeramente más general que Bitmap; cada píxel puede ser cualquier color disponible o "transparente" (representado como el color de fondo en el que se muestra la imagen). Pixmap se utiliza mejor para iconos y otros gráficos sencillos con solo unos pocos colores.

Pixmap se deriva de Tix. Consulte Tk::Pixmap para obtener más información.

Photo
Muestra una variedad de imágenes a todo color, utilizando tramado para aproximar colores en pantallas con capacidades de color limitadas. Consulte la documentación de Tk::Photo para obtener más información.

ADVERTENCIAS

Es necesario utilizar el método "delete" para eliminar un objeto de imagen y liberar la memoria asociada. Simplemente usar una variable léxica para almacenar el objeto de imagen y dejar que la variable salga de alcance o establecerla en "undef" no es suficiente.

VER TAMBIÉN

Tk::Bitmap Tk::Pixmap Tk::Photo
