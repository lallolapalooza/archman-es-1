NOMBRE

Tk::TraceText - Contenidos de texto definidos por una variable rastreada.

SINOPSIS

$tt = $parent->TraceText(-option => value, ... );

DESCRIPCIÓN

Crea un nuevo widget TraceText que se deriva del widget Text estándar. Debido a que hereda todas las opciones y métodos base, se comporta igual que un widget Text. Adicionalmente, TraceText agrega una opción -textvariable, que es una referencia a un escalar de Perl que define el contenido del widget.

Basado en el widget de Tk/Tcl TracedText "widget reemplazado" de Kevin Kenny.

-textvariable
Una referencia a un escalar. El valor de la variable define el contenido del widget TraceText. Usar el teclado para insertar o eliminar texto cambia el valor de la variable, y cambiar la variable modifica el contenido del widget TraceText.

MÉTODOS

Métodos estándar del widget Text.

SUBWIDGETS ANUNCIADOS

Ninguno.

EJEMPLO

my $tt = $mw->TraceText( -textvariable => \$scalar );
