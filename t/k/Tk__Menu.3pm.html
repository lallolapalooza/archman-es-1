Tk__Menu(3pm)

Menu(3) Documentación de Contribución de Usuarios de Perl Menu(3)

NOMBRE

Tk::Menu - Crear y manipular widgets de menú

SINOPSIS

    $menu = $parent->Menu(?opciones?);

OPCIONES ESTÁNDAR

-activebackground -background -disabledforeground -relief -activeborderwidth -borderwidth -font -takefocus -activeforeground -cursor -foreground

Ver Tk::options para detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: postCommand
Clase: Command
Interruptor: -postcommand
Si se especifica esta opción, proporciona una devolución de llamada para ejecutar cada vez que se muestra el menú. La devolución de llamada es invocada por el método post antes de mostrar el menú. Tenga en cuenta que en la versión 8.0 de Macintosh y Windows, todos los comandos de un sistema de menús se ejecutan antes de que se muestre alguno. Esto se debe a las limitaciones de los administradores de menús de las plataformas individuales.
Nombre: selectColor
Clase: Background
Interruptor: -selectcolor
Para las entradas de menú que son casillas de verificación o botones de radio, esta opción especifica el color que se mostrará en el indicador cuando la casilla de verificación o el botón de radio esté seleccionado.
Nombre: tearOff
Clase: TearOff
Interruptor: -tearoff
Esta opción debe tener un valor booleano válido, que especifica si el menú debe incluir una entrada "desprendible" en la parte superior. Si es así, existirá como entrada 0 del menú y las demás entradas comenzarán a numerarse a partir de 1. Los enlaces de menú predeterminados se encargan de que el menú se desprenda cuando se invoca la entrada desprendible.
Nombre: tearOffCommand
Clase: TearOffCommand
Interruptor: -tearoffcommand
Si esta opción tiene un valor no vacío, especifica una devolución de llamada de perl/Tk para invocar cada vez que se desprenda el menú. El comando real consistirá en el valor de esta opción, seguido de un espacio, seguido del nombre de la ventana del menú, seguido de un espacio, seguido del nombre de la ventana del menú desprendido. Por ejemplo, si la opción es ``a b'' y el menú .x.y se desprende para crear un nuevo menú .x.tearoff1, entonces se invocará el comando ``a b .x.y .x.tearoff1''.
Nombre: title
Clase: Title
Interruptor: -title
La cadena se utilizará para titular la ventana creada cuando se desprenda este menú. Si el título es NULL, la ventana tendrá el título del botón del menú o el texto del elemento de cascada desde el cual se invocó este menú.
Nombre: type
Clase: Type
Interruptor: -type
Esta opción puede ser menubar, tearoff o normal, y se establece cuando se crea el menú. Aunque la cadena devuelta por la base de datos de configuración cambiará si se modifica esta opción, esto no afecta el comportamiento del widget de menú. Esto es utilizado por el mecanismo de clonación y normalmente no se establece fuera de la biblioteca Tk.

DESCRIPCIÓN

El método Menu crea una nueva ventana de nivel superior (dada por el argumento $widget) y la convierte en un widget de menú. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del menú tales como sus colores y fuente. El comando menu devuelve su argumento $widget. En el momento en que se invoca este comando, no debe existir una ventana llamada $widget, pero el padre de $widget debe existir.

Un menú es un widget que muestra una colección de entradas de una sola línea dispuestas en una o más columnas. Existen varios tipos diferentes de entradas, cada una con propiedades distintas. Se pueden combinar entradas de diferentes tipos en un solo menú. Las entradas de menú no son lo mismo que los widgets de entrada. De hecho, las entradas de menú ni siquiera son widgets distintos; todo el menú es un solo widget.

Las entradas de menú se muestran con hasta tres campos separados. El campo principal es una etiqueta en forma de cadena de texto, un bitmap o una imagen, controlado por las opciones -label, -bitmap e -image para la entrada. Si se especifica la opción -accelerator para una entrada, se muestra un segundo campo de texto a la derecha de la etiqueta. El acelerador típicamente describe una secuencia de pulsaciones de teclas que se pueden escribir en la aplicación para producir el mismo resultado que invocar la entrada del menú. El tercer campo es un indicador. El indicador está presente solo para las entradas de casilla de verificación o botón de radio. Indica si la entrada está seleccionada o no, y se muestra a la izquierda de la cadena de la entrada.

En uso normal, una entrada se vuelve activa (se muestra de forma diferente) cada vez que el puntero del ratón está sobre la entrada. Si se suelta un botón del ratón sobre la entrada, la entrada se invoca. El efecto de la invocación es diferente para cada tipo de entrada; estos efectos se describen a continuación en las secciones sobre entradas individuales.

Las entradas pueden ser deshabilitadas, lo que hace que sus etiquetas y aceleradores se muestren con colores más tenues. Los enlaces de menú predeterminados no permitirán que una entrada deshabilitada se active o invoque. Las entradas deshabilitadas pueden volver a habilitarse, momento en el cual se vuelve posible activarlas e invocarlas de nuevo.

Cada vez que se cambia la entrada activa de un menú, se envía un evento virtual <<MenuSelect>> al menú. La entrada activa se puede consultar desde el menú, y se puede tomar una acción, como establecer texto de ayuda contextual para la entrada.

ENTRADAS DE COMANDO

El tipo más común de entrada de menú es una entrada de comando, que se comporta de manera muy similar a un widget de botón. Cuando se invoca una entrada de comando, se ejecuta una devolución de llamada. La devolución de llamada se especifica con la opción -command.

ENTRADAS SEPARADORAS

Un separador es una entrada que se muestra como una línea divisoria horizontal. Un separador no se puede activar ni invocar, y no tiene ningún comportamiento aparte de su apariencia de visualización.

ENTRADAS DE CASILLA DE VERIFICACIÓN

Una entrada de menú tipo casilla de verificación se comporta de manera muy similar a un widget de casilla de verificación. Cuando se invoca, alterna entre los estados seleccionado y deseleccionado. Cuando la entrada está seleccionada, se almacena un valor particular en una variable global particular (según lo determinado por las opciones -onvalue y -variable para la entrada); cuando la entrada está deseleccionada, se almacena otro valor (determinado por la opción -offvalue) en la variable global. Se muestra un cuadro indicador a la izquierda de la etiqueta en una entrada de casilla de verificación. Si la entrada está seleccionada, el centro del indicador se muestra en el color dado por la opción -selectcolor para la entrada; de lo contrario, el centro del indicador se muestra en el color de fondo del menú. Si se especifica una opción -command para una entrada de casilla de verificación, su valor se evalúa cada vez que se invoca la entrada; esto ocurre después de alternar el estado seleccionado de la entrada.

ENTRADAS DE BOTÓN DE RADIO

Una entrada de menú tipo botón de radio se comporta de manera muy similar a un botón de radio. Cuando se invoca, el botón de radio se selecciona y cualquier otro botón de radio en el mismo grupo (determinado por la opción -variable) se deselecciona. Se almacena el valor asociado con la entrada (determinado por la opción -value) en la variable global especificada por la opción -variable. Si se especifica una opción -command para una entrada de botón de radio, su valor se evalúa cada vez que se invoca la entrada; esto ocurre después de seleccionar el botón de radio y deseleccionar cualquier otro botón de radio en el grupo.

ENTRADAS DE CASCADE

Una entrada de cascada se utiliza para invocar un menú secundario. Cuando se invoca una entrada de cascada, se muestra el menú secundario asociado. El menú secundario se especifica con la opción -menu.

MÉTODOS

add(type, ?options?)
Agrega una nueva entrada al final del menú. El argumento type debe ser uno de los siguientes: command, separator, checkbutton, radiobutton o cascade. Las opciones disponibles para cada tipo de entrada se describen en la sección DESCRIPCIÓN.
delete(first?last?)
Elimina una o más entradas del menú. Si se omite last, solo se elimina la entrada first. Si first y last son ambos omitidos, se eliminan todas las entradas del menú.
entrycascade(index?options?)
Configura o devuelve información sobre una entrada de cascada. Se utiliza para modificar el menú secundario asociado con una entrada de cascada existente.
entryconfigure(index?options?)
Configura o devuelve información sobre una entrada de menú existente. El argumento index especifica la entrada a configurar (por ejemplo, 0, 1, etc.). Las opciones disponibles dependen del tipo de entrada.
entry(index)
Devuelve una lista de las opciones de configuración para la entrada en el índice especificado.
post(x, y)
Muestra el menú en la pantalla en las coordenadas especificadas (x, y).
unpost()
Oculta el menú de la pantalla.
insert(index, type?options?)
Inserta una nueva entrada en una posición específica del menú. El argumento index especifica la posición donde se insertará la nueva entrada. Los valores de índice válidos son enteros y los especiales end y active.

EVENTOS VIRTUALES

<<MenuSelect>>
Este evento se envía cada vez que la entrada activa del menú cambia.

EJEMPLOS

Crear un menú simple:

my $menu = $parent->Menu();
$menu->add('command', -label => 'Opción 1', -command => sub { print "Opción 1 seleccionada\n"; });
$menu->add('command', -label => 'Opción 2', -command => sub { print "Opción 2 seleccionada\n"; });

Crear un menú con una casilla de verificación:

my $var = '0';
my $menu = $parent->Menu();
$menu->add('checkbutton', -label => 'Activar', -variable => \$var);

Crear un menú con una cascada:

my $submenu = $parent->Menu();
$submenu->add('command', -label => 'Subopción A', -command => sub { print "Subopción A\n"; });
my $menu = $parent->Menu();
$menu->add('cascade', -label => 'Submenú', -menu => $submenu);

HISTORIA DE LOS CAMBIOS

Tk 8.0

Se agregaron los indicadores de casilla de verificación y botón de radio. Los menús de estilo Macintosh y Windows ahora usan el administrador de menús nativo.

Tk 8.4

Se agregó el soporte para imágenes en las etiquetas de menú.
