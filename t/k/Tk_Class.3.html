Tk_Class(3) Procedimientos de la biblioteca Tk Tk_Class(3)

NOMBRE

Tk_SetClass, Tk_Class - establecer o recuperar la clase de una ventana

SINOPSIS

#include <tk.h>

Tk_SetClass(tkwin, class)

Tk_Uid
Tk_Class(tkwin)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token de la ventana.
char *class (entrada)
Nombre de la nueva clase para la ventana.

DESCRIPCIÓN

Se llama a Tk_SetClass para asociar una clase con una ventana particular. La cadena class identifica el tipo de la ventana; todas las ventanas con el mismo tipo general de comportamiento (botón, menú, etc.) deben tener la misma clase. Por convención, todos los nombres de clase comienzan con una letra mayúscula, y existe un comando Tcl con el mismo nombre que cada clase (excepto todo en minúsculas) que se puede usar para crear y manipular ventanas de esa clase. La cadena de clase de una ventana se inicializa a NULL cuando se crea la ventana.

Para las ventanas principales, Tk propaga automáticamente el nombre y la clase a la propiedad WM_CLASS utilizada por los administradores de ventanas. Esto sucede ya sea cuando se crea realmente una ventana principal (por ejemplo, en Tk_MakeWindowExist), o cuando se llama a Tk_SetClass, lo que ocurra más tarde. Si a una ventana principal no se le ha asignado una clase, entonces Tk no establecerá la propiedad WM_CLASS para la ventana.

Tk_Class es una macro que devuelve el valor actual de la clase de tkwin. El valor se devuelve como un Tk_Uid, que puede usarse igual que un puntero a cadena, pero también tiene las propiedades de un identificador único (ver la entrada del manual para Tk_GetUid para más detalles). Si a tkwin aún no se le ha asignado una clase, entonces Tk_Class devolverá NULL.
