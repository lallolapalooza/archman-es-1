NOMBRE

Tk_SetCaretPos - establece la posición del cursor de visualización

SINOPSIS

#include <tk.h>

int
Tk_SetCaretPos(tkwin, x, y, height)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token para la ventana.
int x (entrada)
Coordenada x relativa a la ventana.
int y (entrada)
Coordenada y relativa a la ventana.
int h (entrada)
Altura del cursor en la ventana.

DESCRIPCIÓN

Tk_SetCaretPos establece la ubicación del cursor para la visualización de la Tk_Window especificada tkwin. El cursor es la ubicación del cursor por pantalla utilizada para indicar el foco global (por ejemplo, para cumplir con las directrices de accesibilidad de Microsoft), así como para la ubicación de las ventanas XIM (métodos de entrada X) sobre el punto o las ventanas IME de Windows.
