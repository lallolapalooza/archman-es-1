Paquete: perl-tk

NOMBRE

Tk::TixGrid - Crear y manipular widgets Tix Grid

SINOPSIS

    $tixgrid = $parent->TixGrid?(opciones)?;

DESCRIPCIÓN

Este widget está destinado a ser la base de interfaces similares a "hojas de cálculo". El widget muestra su contenido en una "rejilla" bidimensional de celdas. Cada celda puede contener un elemento de visualización de Tix, que puede ser de texto, gráficos u otros formatos. Consulte Tk::DItem para obtener más información sobre los elementos de visualización de Tix. Dado que estos "elementos" no necesitan ser "ventanas", se pueden manejar grandes rejillas sin consumir recursos excesivos del sistema de visualización.

Las celdas individuales, o grupos de celdas, se pueden formatear con una amplia gama de atributos, como su color, alivio y borde. Sin embargo, dado que el widget está destinado a manejar grandes rejillas, los mecanismos para lograr esto son de bajo nivel y más orientados a callbacks que para otros widgets. La suposición es que, para evitar almacenar detalles de visualización de un gran número de celdas, los datos se recalcularán según sea necesario.

La portabilidad del código C de Tix y algunos de los enlaces a perl/Tk se han realizado, pero aún requieren más trabajo. En varios lugares, la intención del código Tix aún no se comprende. Por ejemplo, la interfaz 'edit' está claramente destinada a la edición de contenido de celdas tipo hoja de cálculo en un widget auxiliar de "entrada" o similar, pero todavía no está claro cómo debería funcionar.

El método TixGrid crea una nueva ventana TixGrid y devuelve una referencia con bendición de este widget TixGrid. Opciones adicionales, descritas a continuación, se pueden especificar en la línea de comandos o en la base de datos de opciones para configurar aspectos del widget TixGrid.

OPCIONES ESTÁNDAR

-background -borderwidth -cursor -font -foreground -height -highlightbackground -highlightcolor -highlightthickness -padx -pady -relief -selectbackground -selectborderwidth -selectforeground -state -takefocus -width -xscrollcommand -yscrollcommand

Consulte Tk::options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: browseCmd
Clase: BrowseCmd
Interruptor: -browsecmd
Si se define, proporciona una devolución de llamada de perl/Tk que se ejecutará cuando el usuario explore una celda de la rejilla (Esto es normalmente el caso cuando el usuario hace clic en una entrada). Cuando se llama a esta devolución de llamada, se le pasan dos parámetros adicionales: x y, donde (x,y) es la ubicación de la celda en la que se acaba de hacer clic.
Nombre: Command
Clase: Command
Interruptor: -command
Si se define, proporciona una devolución de llamada de perl/Tk que se ejecutará cuando el usuario haga doble clic en una celda de la rejilla. Cuando se llama a esta devolución de llamada, se le pasan dos parámetros adicionales: x y, donde (x,y) es la ubicación de la celda en la que se acaba de hacer clic.
Nombre: editDoneCmd
Clase: EditDoneCmd
Interruptor: -editdonecmd
Si se define, proporciona una devolución de llamada de perl/Tk que se ejecutará cuando el usuario haya editado una celda de la rejilla. Cuando se llama a esta devolución de llamada, se le pasan dos parámetros adicionales: x y, donde (x,y) es la ubicación de la celda que acaba de ser editada.
Nombre: editNotifyCmd
Clase: EditNotifyCmd
Interruptor: -editnotifycmd
Si se define, proporciona una devolución de llamada de perl/Tk que se ejecutará cuando el usuario intente editar una celda de la rejilla. Cuando se llama a esta devolución de llamada, se le pasan dos parámetros adicionales: x y, donde (x,y) es la ubicación de la celda. Esta devolución de llamada debe devolver un valor booleano: verdadero indica que la celda es editable y falso de lo contrario.
Nombre: FloatingCols
Clase: floatingCols
Interruptor: -floatingcols
Define el número de columnas adicionales más allá de la rejilla existente que se pueden mostrar al desplazarse.
Nombre: FloatingRows
Clase: floatingRows
Interruptor: -floatingrows
Define el número de filas adicionales más allá de la rejilla existente que se pueden mostrar al desplazarse.
Nombre: formatCmd
Clase: FormatCmd
Interruptor: -formatcmd
Si se define, proporciona una devolución de llamada de perl/Tk que se ejecutará cuando las celdas de la rejilla necesiten ser mostradas en la pantalla. Su propósito principal es dibujar el fondo de la región antes de que se rendericen las celdas encima. Esto se logra normalmente llamando a formatGrid o formatBorder (ver más abajo). Sin embargo, se pueden hacer otros usos de esta devolución de llamada de bajo nivel. Por ejemplo, se puede utilizar para poblar la rejilla de forma "perezosa" llamando al método set solo cuando las celdas entran en la vista.

Cuando se llama a esta devolución de llamada, se le pasan cinco parámetros adicionales: type x1 y1 x2 y2.

x1 y1 x2 y2 proporciona la extensión de la región que necesita ser formateada.

type proporciona el tipo lógico de la región en la rejilla. Puede ser uno de los siguientes.

x_margen
El margen horizontal.
y_margen
El margen vertical.
s_margen
El área en la esquina superior izquierda donde se unen los márgenes horizontal y vertical.
principal
El cuerpo principal, es decir, todas las celdas que no caen en los tres tipos anteriores.
Nombre: leftMargin
Clase: LeftMargin
Interruptor: -leftmargin
Proporciona el ancho del margen vertical en celdas (columnas). Un valor cero indica que no hay margen vertical. Un valor positivo N indica que las primeras N columnas son "etiquetas" y siempre se muestran y no se desplazan.
Nombre: itemType
Clase: ItemType
Interruptor: -itemtype
Tipo de elemento predeterminado para las celdas.
Nombre: selectMode
Clase: SelectMode
Interruptor: -selectmode
Especifica uno de varios estilos para manipular la selección. El valor de la opción puede ser arbitrario, pero las vinculaciones predeterminadas esperan que sea single, browse, multiple o extended; el valor predeterminado es s

OPTIONS

The TixGrid widget supports the following options.

-cellmode
-CellMode
Sets the mode for cell selection. The default value is cell. Valid values are cell, column or row.
-browsecmd
-BrowseCmd
A callback procedure that is called when the grid is scrolled. The procedure is called with two arguments: the new top-leftmost cell (column, row).
-cursor
-Cursor
A cursor to be displayed when the mouse cursor is over the grid.
-editnotify
-EditNotify
A callback procedure that is called when a cell is to be edited. The procedure is called with three arguments: the column, row and the widget path of the TixGrid widget. The procedure should return true if the cell can be edited, and false otherwise.
-focuscell
-FocusCell
The cell that has the keyboard focus.
-formatcmd
-FormatCmd
A callback procedure that is called when the TixGrid needs to draw the background of cells. The procedure is called with three arguments: the widget path of the TixGrid widget, the bounding box of the area to be drawn, and the type of area (grid or border). The procedure is responsible for drawing the background of the specified area. It can call the methods formatGrid and formatBorder to do so.
-gridlines
-GridLines
Specifies whether to draw grid lines between cells. The default value is 1 (true).
-height
-Height
The number of rows that should be visible in the grid. The default is 10.
-pageincrements
-PageIncrements
A list of two integers specifying the number of rows and columns that should be scrolled when the page up/down or page left/right keys are pressed. The default value is (1, 1).
-relief
-Relief
Specifies the relief of the border around the grid. See Tk_ConfigureWidget for valid values.
-selectborderwidth
-SelectBorderwidth
Specifies the border width for selected cells. The default is 1.
-selectcolor
-SelectColor
Specifies the color used to highlight selected cells. The default is system blue.
-selectmode
-SelectMode
Specifies the selection mode. The default is browse. Valid values are browse, extended, and none.
-separator
-Separator
Specifies the character to be used as a separator between cells in the CSV export. Default is ,.
-state
-State
Specifies the state of the grid. Valid values are normal and disabled.
-takefocus
-TakeFocus
Specifies whether the grid should take focus when the Tab key is pressed. Default is 1.
-width
-Width
The number of columns that should be visible in the grid. The default is 20.
-xscrollcommand
-XScrollCommand
Used to control the horizontal scrollbar. Typically, this is set to the path name of a horizontal scrollbar widget's set method.
-yscrollcommand
-YScrollCommand
Used to control the vertical scrollbar. Typically, this is set to the path name of a vertical scrollbar widget's set method.

SPECIFIC OPTIONS

The following options can be specified per-cell or per-row/column.

-celloptions
-CellOptions
Returns a list of options that are valid for cells. These options can be used with the entryconfigure method.
-coloptions
-ColOptions
Returns a list of options that are valid for columns. These options can be used with the sizeColumn method.
-rowoptions
-RowOptions
Returns a list of options that are valid for rows. These options can be used with the sizeRow method.

CALLBACK OPTIONS

The following options specify callback procedures.

-buttoncallback
-ButtonCallback
A callback procedure that is called when a mouse button is pressed or released in a cell. The procedure is called with five arguments: the widget path of the TixGrid widget, the cell's column and row, the mouse button number, and the event type (press or release).
-datacmd
-DataCmd
A callback procedure that is called when the value of a cell is needed. The procedure is called with three arguments: the widget path of the TixGrid widget, the cell's column and row. It should return the value of the cell.
-defaultcmd
-DefaultCmd
A callback procedure that is called when a cell's value is not explicitly defined. The procedure is called with three arguments: the widget path of the TixGrid widget, the cell's column and row. It should return the default value for the cell.
-editendcmd
-EditEndCmd
A callback procedure that is called when editing of a cell is finished. The procedure is called with four arguments: the widget path of the TixGrid widget, the cell's column and row, and the new value of the cell. The procedure should return true if the edit is successful, and false otherwise.
-enterkeycmd
-EnterKeyCmd
A callback procedure that is called when the Enter key is pressed in a cell. The procedure is called with three arguments: the widget path of the TixGrid widget, the cell's column and row.
-leftarrowcmd
-LeftArrowCmd
A callback procedure that is called when the left arrow key is pressed in a cell. The procedure is called with three arguments: the widget path of the TixGrid widget, the cell's column and row.
-rightleftarrowcmd
-RightLeftArrowCmd
A callback procedure that is called when the right arrow key is pressed in a cell. The procedure is called with three arguments: the widget path of the TixGrid widget, the cell's column and row.
-updownarrowcmd
-UpDownArrowCmd
A callback procedure that is called when the up or down arrow key is pressed in a cell. The procedure is called with three arguments: the widget path of the TixGrid widget, the cell's column and row.

-activebackground
-ActiveBackground

-activeforeground
-ActiveForeground

-background / -bg

-checkbutton
-CheckButton

-command

-data

-editwindow

-editwindowoptions
A list of option-value pairs that will be used to configure the edit window widget.
-entry

-entryoptions
A list of option-value pairs that will be used to configure the entry widget specified in the -entry option.
-font

-foreground / -fg

-height

-image

-radiobutton

-radiobuttonoptions
A list of option-value pairs that will be used to configure the radiobutton widget specified in the -radiobutton option.
-relief
The relief style of the cell border.
-row
The row number of the cell. This option is read-only.
-selectbackground
The background color of the cell when it is selected.
-selectforeground
The foreground color of the cell when it is selected.
-state
The state of the cell (normal or disabled).
-text
The text to be displayed in the cell.
-width
The width of the cell in pixels. If not specified, the width will be determined by the text.

PER-ROW AND COLUMN OPTIONS

The following options can be specified for individual rows or columns using the sizeRow and sizeColumn methods.

-minsize
-MinSize
The minimum size (in pixels) for the row or column.
-resize
-Resize
Specifies whether the row or column can be resized by the user. Valid values are true and false.

-Stretch

TIXGRID METHODS

The TixGrid method creates a TixGrid widget and returns a blessed reference of this TixGrid widget. This reference may be used to invoke various operations on the widget. It has the following general form:

    $tixgrid->method?(arg, arg, ...)?

args determine the exact behavior of the method.

This object supports the configure and cget methods described in Tk::options which can be used to inquire and modify the options described above. The widget also inherits all the methods provided by the generic Tk::Widget class.

The following additional methods are possible for TixGrid widgets:

anchorGet(x, y)
anchorSet(x, y)
anchorClear()
Manipulates the anchor cell of the TixGrid widget. The anchor cell is the end of the selection that is fixed while the user is dragging out a selection with the mouse.
(bd,col,row) = bdtype(x,y ?,xDelta,yDelta?)
Determines if the the screen (pixel) position x,y is in a border. This is useful for changing the mouse cursor when the user points at a border - e.g. to indicate that the border can be adjusted interactively.

If in a border returns a list of three elements. First element is 'xy', 'x' or 'y', second two elements are integers. (Value of these are not understood, seem to indicate which column and row of the border the screen position corresponds to?)

If not in a border returns an empty list.

delete(dim, from?, to?)
deleteColumn(from?, to?)
deleteRow(from?, to?)
Dim may be row or column. If to is not given, deletes a single row (or column) at the position from. If to is given, deletes the range of rows (or columns) from position from through to.
dragsite(option, x, y)
dropsite(option, x, y)
Tcl/Tix has (or was going to have) Drag&Drop support. Meaning for perl/Tk is not clear yet.
editApply()
If any cell is being edited, de-highlight the cell and applies the changes.
editSet(x, y)
Highlights the cell at (x,y) for editing, if the -editnotify callback returns true for this cell.
entrycget(x, y, '-option')
entryconfigure(x, y?, -option??=>value, -option=>value, ...?)
Provide a configue interface to cells in the grid. The -options depend on the item type of the cell.
formatBorder(x1,y1, x2,y2, options);
formatGrid(x1,y1, x2,y2, options);
The formatBorder and formatGrid methods can only be called by the -formatcmd callback of the tixGrid widget. They draw the background of the region described by x1,y1, x2,y2 according the the supplied options. One call to -formatcmd callback can make multiple calls to formatBorder and/or formatGrid for different sub-regions.

formatBorder draws the background using Tk relief style, formatGrid also draws grid lines between the cells. It only makes sense to call one or the other for a particular sub-region as one will over-write the other.

The options allowed are:

-background / -bg
-borderwidth / -bd
-filled
-relief
-selectbackground
-xoff
-xon
-yoff
-yon

The -xon/-xoff and -yon/-yoff options are obscure. If anyone can figure out how to do something interesting given what pTk/tixGrFmt.c is doing with them please let Nick know!.

geometryinfo(?width, height?)
Returns list of four values - two sets of two floating point numbers. First set is the scrollbar fractions for x direction, second set is scrollbar fractions for y direction. If width and height are specified then fractions are based on as if window size was of specified size (in pixels, but not allowing normal GetPixels units). Otherwise fractions are based on current size of the window.

Usage obscure.

index(xcoord, ycoord)
Retuns (x, y) of entry at position ($coordx, $coordy). Either coordinate may be 'max' which is largest existing entry in that direction, 'end' which is one beyond largest existing entry, or a number. (This is how you find out how big the grid is.)
infoBbox(x,y)
Return the pixel bounding box of the cell at x,y.
infoExists(x,y)
Returns true if there is an item in the cell at x,y. Throws an exception (dies) if x,y is outside the grid - this may change (Nick doesn't like it).
move(dim, from, to, offset)
moveColumn(from, to, offset)
moveRow(from, to, offset)
Dim may be row or column. Moves the range of rows (or columns) from position from through to by the distance indicated by offset. For example, $tixgrid->moveRow(2, 4, 1) moves the rows 2,3,4 to rows 3,4,5.
nearest(x, y)
Screen pos (pixels) to entry (nx,ny) translation.
selectionAdjust(x1, y1 ?,x2, y2?)
selectionClear(x1, y1 ?,x2, y2?)
selectionIncludes(x1, y1 ?,x2, y2?)
selectionSet(x1, y1 ?,x2, y2?)
selectionToggle(x1, y1 ?,x2, y2?)
Selection support methods - probably buggy.

x1 (y1) has not to be greater than x2 (y2), but only x2 and y2 can be 'max'.

BUG: selectionIncludes: has no visible effect (as in Tix). Eh???

BUG: selectionClear: only works for 0, 0, max, max (as in Tix). Eh???

When x2, y2 are not given they default to x1, y1, respectively.

set(x, y?, -itemtype=>type??, -option=>value, ...?)
Creates a new display item at the cell at (x,y). The optional -itemtype parameter gives the type of the display item. An additional list of option-value pairs specify options of the display item. If a display item already exists at this cell, the old item will be deleted automatically.
size(dim, index?, -option??=>value, ...?)
sizeColumn(index?, -option??=>value, ...?)
sizeRow(index?, -option??=>value, ...?)
Queries or sets the size of the row or column given by dim and index. Dim may be row or column. Index may be any non-negative integer that gives the position of a given row (or column). Index can also be the string default; in this case, this method queries or sets the default size of rows or columns.

If no index is specified, it queries or sets the default size.

The -options allowed are -size, -minsize, and -stretch.

sizeCmd()
Callback is called (with no extra arguments) when grid sizes are re-computed. For example if window changes size, a different font is specified etc.

It is called just after scrollbars (if present) are updated.

selectUnit(unit)
Specifies the selection unit. Valid values are cell, column or row.
topMargin(width)
Gives the width of horizontal margin in cells (rows). A zero indicates that no horizontal margin exists. A positive value N indicates that first N rows are "labels" and are always displayed and not scrolled.
Tk::TixGrid(3pm)

NAME

Tk::TixGrid - A widget to display data in a table

SYNOPSIS

use Tk;
use Tk::TixGrid;

my $mw = MainWindow->new;
my $tixgrid = $mw->TixGrid(
    -rows => 10,
    -cols => 5,
);
$tixgrid->pack;

# ...

$tixgrid->cell(1, 2, -text => 'Hello World!');
$tixgrid->cell(1, 2, -text => 'New Text', -foreground => 'red');
my $text = $tixgrid->cell(1, 2);

$tixgrid->colscfg('1', -size => '100pixels');
$tixgrid->colscfg(-1, -pad0 => 5);
my $width = $tixgrid->colscfg('1', -size);

$tixgrid->rowscfg('1', -size => 'auto');
my $height = $tixgrid->rowscfg('1', -size);

# ...
Tk::MainLoop;

DESCRIPTION

The TixGrid widget is a Tix extension to Tk that displays data in a table format. It is similar to a spreadsheet and allows for easy manipulation of cells, rows, and columns.

STANDARD OPTIONS

The Tk::TixGrid widget supports the standard Tk widget options such as -borderwidth, -relief, -background, etc.

WIDGET-SPECIFIC OPTIONS

When creating a TixGrid widget, the following options can be specified:

-cols => number
Specifies the number of columns in the grid.
-rows => number
Specifies the number of rows in the grid.

WIDGET METHODS

$tixgrid->cell(x, y, ?option-value pairs?...)
Returns or modifies the content and display options of the cell at column x and row y.

If no option-value pairs are given, this method returns a hash containing the current settings of the cell.

If option-value pairs are given, the specified options for the cell are modified.

The following options are supported:

-background => color
Specifies the background color of the cell.
-command => script
Specifies a script to be executed when the cell is selected or activated.
-data => value
Stores arbitrary data in the cell.
-foreground => color
Specifies the foreground color (text color) of the cell.
-image => image object
Specifies an image to be displayed in the cell.
-text => string
Specifies the text to be displayed in the cell.
-textvariable => varname
Specifies a Tk variable whose value will be displayed in the cell.
$tixgrid->colscfg(col, ?option-value pairs?...)
Returns or modifies the configuration of the specified column(s). Col can be a column index (starting from 0), a column name, or a list of column indices/names.

When no option-value pairs are given, this method returns a list containing the current size setting of the given column(s).

When option-value pairs are given, the corresponding options of the size setting of the given column(s) are changed.

The following options are supported:

-pad0 => pixels
Specifies the padding to the left of the column.
-pad1 => pixels
Specifies the padding to the right of the column.
-size => val
Specifies the width of the column. Val can be:
  • auto: The width of the column is set to the widest cell in the column.
  • A valid Tk screen distance unit (e.g., 100, 100p, 2c).
  • A real number followed by the word chars (e.g., 3.4chars) that sets the width of the column to the given number of characters.
$tixgrid->grid_option(?option-value pairs?...)
Returns or modifies the configuration of the grid widget itself.

When no option-value pairs are given, this method returns a hash containing the current grid options.

When option-value pairs are given, the corresponding options of the grid are changed.

The following options are supported:

-browsecommand => script
Specifies a script to be executed when the selection in the grid changes.
-command => script
Specifies a script to be executed when a cell is selected or activated.
-height => value
Specifies the height of the grid in rows.
-width => value
Specifies the width of the grid in columns.
$tixgrid->rowscfg(row, ?option-value pairs?...)
Returns or modifies the configuration of the specified row(s). Row can be a row index (starting from 0), a row name, or a list of row indices/names.

When no option-value pairs are given, this method returns a list containing the current size setting of the given row(s).

When option-value pairs are given, the corresponding options of the size setting of the given row(s) are changed.

The following options are supported:

-pad0 => pixels
Specifies the padding to the top of the row.
-pad1 => pixels
Specifies the padding to the bottom of the row.
-size => val
Specifies the height of the row. Val can be:
  • auto: The height of the row is set to the tallest cell in the row.
  • A valid Tk screen distance unit (e.g., 100, 100p, 2c).
  • A real number followed by the word chars (e.g., 3.4chars) that sets the height of the row to the given number of characters.
$tixgrid->sort(dimension, start, end, ?args ...?)
?docu here? (not supported on Win* OSs up to now)
$tixgrid->unset(x, y)
Clears the cell at (x,y) by removing its display item.
$tixgrid->xview
Normal horizontal scrollbar method.
$tixgrid->yview
Normal vertical scrollbar method.
