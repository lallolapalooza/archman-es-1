NOMBRE

Tk::Derived - Clase base para widgets derivados de otros

SINOPSIS

 package Tk::MiNuevoWidget;
 use Tk::widgets qw/ BaseWidget, lista de widgets Tk /;
 use base qw/ Tk::Derived Tk::BaseWidget /;
 Construct Tk::Widget 'MiNuevoWidget';
 sub ClassInit {
     my( $class, $mw ) = @_;
     #... p. ej., enlaces de clase aquí ...
     $class->SUPER::ClassInit( $mw );
 }
 sub Populate {
     my( $self, $args ) = @_;
     my $flag = delete $args->{-flag};
     if( defined $flag ) {
         # manejar -flag => xxx que solo se puede hacer en el momento de la creación
         # el delete anterior asegura que new() no intente hacer $self->configure( -flag => xxx );
     }
     $self->SUPER::Populate( $args );
     $self = $self->Component( ... );
     $self->Delegates( ... );
     $self->ConfigSpecs(
         '-cursor'    => [ SELF, 'cursor', 'Cursor',   undef ],
         '-something' => [ METHOD, dbName,  dbClass, default ],
         '-text'      => [ $label, dbName,  dbClass, default ],
         '-heading'   => [ {-text => $head},
                             heading, Heading,  'Mi Encabezado' ],
    ); 
}
sub something {
    my( $self, $value) = @_;
    if ( @_ > 1 ) {
       # establecerlo
    }
    return # valor actual
}

DESCRIPCIÓN

Tk::Derived se utiliza con la herencia múltiple de Perl para sobrescribir algunos métodos heredados normalmente de Tk::Widget.

Tk::Derived debe preceder a cualquier widget de Tk en la definición de la clase base de la clase.

El propósito principal de Tk::Derived es aplicar envoltorios a los métodos "configure" y "cget" de los widgets para permitir que el widget derivado añada o modifique el comportamiento de las opciones de configuración admitidas por el widget base.

La clase derivada normalmente debería sobrescribir el método "Populate" proporcionado por Tk::Derived y llamar a "ConfigSpecs" para declarar las opciones de configuración.

Los métodos públicos proporcionados por Tk::Derived son los siguientes:

->ConfigSpecs(-clave => [tipo, nombre, Clase, valor por defecto], ...)
