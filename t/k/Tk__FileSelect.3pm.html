NOMBRE

Tk::FileSelect - un widget para elegir archivos

SINOPSIS

use Tk::FileSelect;
$FSref = $top->FileSelect(-directory => $dir_inicio);
              $top            - una referencia de ventana, p.ej. MainWindow->new
              $dir_inicio     - el punto de partida para FileSelect
$archivo = $FSref->Show;
              Ejecuta el selector de archivos hasta que se acepte un nombre de archivo
              o el usuario presione Cancelar. Devuelve el nombre del archivo
              o la cadena vacía, respectivamente, y desmapea el FileSelect.
$FSref->configure(opcion => valor[, ...])
              Por favor, consulte la subrutina Populate ya que la lista de configuración
              cambia rápidamente.

DESCRIPCIÓN

Este Módulo muestra una ventana de Selector de Archivos, con una entrada de directorio en la parte superior, una lista de directorios en el directorio actual, una lista de archivos en el directorio actual, una entrada para introducir/modificar un nombre de archivo, un botón de aceptar y un botón de cancelar.

Puede introducir un directorio de inicio en la entrada de directorio. Después de presionar Intro, las listas se actualizan. Hacer doble clic en cualquier directorio le muestra el contenido respectivo. Hacer clic simple en un archivo lo introduce en la entrada de archivo para su posterior consideración, hacer doble clic en un archivo cierra el selector de archivos y llama al comando opcional con la ruta completa del archivo seleccionado. Presionar intro en la caja del selector de archivos o presionar el botón de aceptar también funcionará. *NOTA* la caja del selector de archivos solo se destruirá si el nombre del archivo no tiene longitud cero. Si desea encargarse de ello usted mismo, cambie el if(length(.. en la sub accept_file.

95/10/17, SOL, LUCC. lusol@Lehigh.EDU

  • Permitir que se acepten nombres de archivo o directorio.
  • Requerir doble clic para moverse a un nuevo directorio en lugar de un solo clic. Esto permite que un solo clic seleccione un nombre de directorio para que pueda ser aceptado.
  • Agregar la opción -verify list para que los operadores de prueba de archivos estándar de Perl (como -d y -x) puedan especificarse para una validación adicional del nombre. El valor predeterminado es el valor especial '!-d' (no es un directorio), por lo que cualquier nombre puede seleccionarse ya que es un selector de archivos.

    Por ejemplo:

    $fs->configure(-verify => ['-d', [\&codigo_verificacion, $P1, $P2, ... $Pn]]);

    asegura que el nombre seleccionado sea un directorio. Además, si un elemento de la lista es una referencia de matriz, el primer elemento es una referencia de código a una subrutina y los elementos opcionales restantes son sus parámetros. La subrutina se llama así:

    &codigo_verificacion($cd, $hoja, $P1, $P2, ... $Pn);

    donde $cd es el directorio actual, $hoja es un nombre de directorio o archivo, y $P1 .. $Pn son sus parámetros opcionales. La subrutina debe devolver VERDADERO si tiene éxito o FALSO si falla.
