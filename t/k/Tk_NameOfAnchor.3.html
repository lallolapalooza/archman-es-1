Tk_GetAnchorFromObj(3) Procedimientos de la biblioteca Tk Tk_GetAnchorFromObj(3)

NOMBRE

Tk_GetAnchorFromObj, Tk_GetAnchor, Tk_NameOfAnchor - traducir entre cadenas y posiciones de anclaje

SINOPSIS

#include <tk.h>

int
Tk_GetAnchorFromObj(interp, objPtr, anchorPtr)

int
Tk_GetAnchor(interp, string, anchorPtr)

const char *
Tk_NameOfAnchor(anchor)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a utilizar para reportar errores, o NULL.
Tcl_Obj *objPtr (entrada/salida)
El valor de la cadena contiene el nombre del punto de anclaje: “n”, “ne”, “e”, “se”, “s”, “sw”, “w”, “nw”, o “center”; la representación interna se modificará para almacenar el Tk_Anchor correspondiente. En el caso de “center” en la entrada, también se puede usar una abreviatura no vacía del mismo en la entrada.
const char *string (entrada)
Igual que objPtr excepto que la descripción del punto de anclaje se pasa como una cadena.
int *anchorPtr (salida)
Puntero a la ubicación donde se almacenará la posición de anclaje correspondiente a objPtr o string.
Tk_Anchor anchor (entrada)
Posición de anclaje, por ejemplo, TCL_ANCHOR_CENTER.

DESCRIPCIÓN

Tk_GetAnchorFromObj almacena en *anchorPtr una posición de anclaje (tipo enumerado Tk_Anchor) correspondiente al valor de objPtr. El resultado será uno de TK_ANCHOR_N, TK_ANCHOR_NE, TK_ANCHOR_E, TK_ANCHOR_SE, TK_ANCHOR_S, TK_ANCHOR_SW, TK_ANCHOR_W, TK_ANCHOR_NW, o TK_ANCHOR_CENTER. Las posiciones de anclaje se usan típicamente para indicar un punto en un objeto que se utilizará para posicionar el objeto, por ejemplo, TK_ANCHOR_N significa posicionar el punto central superior del objeto en un lugar determinado.

En circunstancias normales, el valor de retorno es TCL_OK y interp no se utiliza. Si string no contiene una posición de anclaje válida o una abreviatura de uno de estos nombres, se devuelve TCL_ERROR, *anchorPtr no se modifica y se almacena un mensaje de error en el resultado de interp si interp no es NULL. Tk_GetAnchorFromObj almacena en caché información sobre el valor de retorno en objPtr, lo que acelera las llamadas futuras a Tk_GetAnchorFromObj con el mismo objPtr.

Tk_GetAnchor es idéntico a Tk_GetAnchorFromObj excepto que la descripción del anclaje se especifica con una cadena en lugar de un objeto. Esto evita que Tk_GetAnchor almacene en caché el valor de retorno, por lo que Tk_GetAnchor es menos eficiente que Tk_GetAnchorFromObj.

Tk_NameOfAnchor es la inversa lógica de Tk_GetAnchor. Dado una posición de anclaje como TK_ANCHOR_N, devuelve una cadena asignada estáticamente correspondiente a anchor. Si anchor no es un valor de anclaje legal, entonces se devuelve “unknown anchor position”.
