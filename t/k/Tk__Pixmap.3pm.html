NOMBRE

Tk::Pixmap - Crea imágenes en color a partir de archivos XPM.

SINOPSIS

    $widget->Pixmap?(nombre?,opciones?)?

DESCRIPCIÓN

XPM es un formato popular de archivo de imagen de X Window para almacenar iconos en color. El tipo de imagen Pixmap se puede usar para crear imágenes en color utilizando archivos XPM.

Los Pixmaps admiten las siguientes opciones:

-data => cadena
Especifica el contenido del pixmap de origen como una cadena. La cadena debe cumplir el formato de archivo XPM (por ejemplo, como lo genera el programa pixmap(1)). Si se especifican tanto la opción -data como la opción -file, la opción -data tiene prioridad. Tenga en cuenta que el código de análisis de archivos XPM en la biblioteca xpm es algo frágil. La primera línea de la cadena debe ser "/* XPM */" o de lo contrario se producirá una falla de segmentación.
-file => nombre
nombre indica el nombre de un archivo cuyo contenido define el pixmap de origen. El archivo debe cumplir con el formato de archivo XPM (por ejemplo, como lo genera el programa pixmap(1)).

MÉTODOS DE IMAGEN

Cuando se crea una imagen de pixmap, Tk también crea un nuevo objeto. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente.
