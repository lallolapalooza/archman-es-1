NOMBRE

Tk::Menu::Item - Clase base para elementos de menú

SINOPSIS

require Tk::Menu::Item;
my $but = $menu->Button(...);
$but->configure(...);
my $what = $but->cget();
package Whatever;
require Tk::Menu::Item;
@ISA = qw(Tk::Menu::Item);
sub PreInit
{
 my ($class,$menu,$info) = @_;
 $info->{'-xxxxx'} = ...
 my $y = delete $info->{'-yyyy'};
}

DESCRIPCIÓN

Tk::Menu::Item es la clase base de la que derivan Tk::Menu::Button, Tk::Menu::Cascade, Tk::Menu::Radiobutton y Tk::Menu::Checkbutton. También existe Tk::Menu::Separator.

Los constructores se declaran de tal manera que $menu->Button(...) etc. hacen lo que se espera.

La opción "-label" se pre-procesa permitiendo prefijar un ~ al carácter para derivar un valor de "-underline". Así,

$menu->Button(-label => 'Ir a ~Casa',...)
es equivalente a
$menu->Button(-label => 'Ir a Casa', -underline => 6, ...)

El elemento de menú "Cascade" crea un submenú y acepta estas opciones:

-menuitems
Una lista de elementos para el submenú. Dentro de esta lista (que también es aceptada por Menu y Menubutton), los dos primeros elementos de cada elemento deben ser el nombre del "constructor" y la etiqueta: 
-menuitems => [
               [Button      => '~Salir', -command => [destroy => $mw]],
               [Checkbutton => '~Aceite',  -variable => \$oil],
              ]
-postcommand
Una llamada de retorno que se invocará antes de mostrar el menú.
-tearoff
Especifica si el submenú se puede extraer o no.
-menuvar
Referencia escalar que se establecerá al submenú recién creado.

El objeto devuelto es actualmente una referencia bendecida a una matriz de dos elementos: el Menú que lo contiene y la 'etiqueta'. Los métodos "configure" y "cget" se mapean a "entryconfigure" y "entrycget" subyacentes.

El propósito principal de la interfaz OO es permitir la definición de clases de elementos derivados que preestablecen las opciones utilizadas para crear un elemento más básico.

ERRORES

Esta interfaz OO es muy nueva. Usar la etiqueta como "clave" es un problema para los elementos separadores que no tienen una. La alternativa sería utilizar un índice en el menú, pero eso es un problema si los elementos se eliminan (o se insertan en otro lugar que no sea al final).

Probablemente también debería haber un punto de entrada PostInit, o una configuración diferida más parecida a un widget.
