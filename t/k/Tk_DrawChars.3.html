Tk_MeasureChars(3) Procedimientos de la biblioteca Tk Tk_MeasureChars(3)

NOMBRE

Tk_MeasureChars, Tk_TextWidth, Tk_DrawChars, Tk_UnderlineChars - rutinas para medir y mostrar cadenas de texto simples de una sola línea.

SINOPSIS

#include <tk.h>

int
Tk_MeasureChars(tkfont, string, numBytes, maxPixels, flags, lengthPtr)

int
Tk_TextWidth(tkfont, string, numBytes)

Tk_DrawChars(display, drawable, gc, tkfont, string, numBytes, x, y)

Tk_UnderlineChars(display, drawable, gc, tkfont, string, x, y, firstByte, lastByte)

ARGUMENTOS

Tk_Font tkfont (entrada)
Token para la fuente en la que se dibujará o medirá el texto. Debe haber sido devuelto por una llamada previa a Tk_GetFont.
const char *string (entrada)
Texto a medir o mostrar. No es necesario que termine en nulo. Los caracteres de control o meta-caracteres no imprimibles de la cadena (como tabulaciones, saltos de línea y otros caracteres de control) se medirán o mostrarán de forma dependiente de la plataforma.
int numBytes (entrada)
El número máximo de bytes a considerar al medir o dibujar string. Debe ser mayor o igual a 0.
int maxPixels (entrada)
Si maxPixels es >= 0, especifica la longitud máxima permitida de la línea en píxeles. Los caracteres de string se procesan solo hasta que se cubran esta cantidad de píxeles. Si maxPixels es < 0, entonces la longitud de la línea no tiene límite y se ignora el argumento flags.
int flags (entrada)
Varios bits de indicadores combinados con OR: TK_PARTIAL_OK indica que se incluya un carácter siempre que alguna parte de él quepa en la longitud dada por maxPixels; de lo contrario, un carácter debe caber completamente para ser considerado. TK_WHOLE_WORDS indica que se detenga en un límite de palabra, si es posible. Si se establece TK_AT_LEAST_ONE, significa que se devuelva al menos un carácter incluso si ningún carácter cupo en la longitud dada por maxPixels. Si se establece TK_AT_LEAST_ONE y también se establece TK_WHOLE_WORDS, significa que si ni siquiera una palabra cabe en la línea, se devuelvan las primeras letras de la palabra que sí cupo; si ni siquiera una letra de la palabra cupo, se devolverá la primera letra.
int *lengthPtr (salida)
Se rellena con el número de píxeles ocupados por el número de caracteres devuelto como resultado de Tk_MeasureChars.
Display *display (entrada)
Pantalla en la que dibujar.
Drawable drawable (entrada)
Ventana o pixmap en el que dibujar.
GC gc (entrada)
Contexto gráfico para dibujar caracteres. La fuente seleccionada en este GC debe ser la misma que tkfont.
int x, y (entrada)
Coordenadas en las que colocar el borde izquierdo de la línea base al mostrar string.
int firstByte (entrada)
El índice del primer byte del primer carácter a subrayar en la string. El subrayado comienza en el borde izquierdo de este carácter.
int lastByte (entrada)
El índice del primer byte del último carácter hasta el cual se dibujará el subrayado. El carácter especificado por lastByte no se subrayará en sí mismo.

DESCRIPCIÓN

Estas rutinas son para medir y mostrar cadenas de texto simples de una sola fuente y una sola línea. Para medir y mostrar texto de una sola fuente y múltiples líneas justificado, consulte la documentación de Tk_ComputeTextLayout. No existe una interfaz de programación en el núcleo de Tk que admita texto de múltiples fuentes y múltiples líneas; el soporte para ese comportamiento debe construirse sobre capas más simples. Tenga en cuenta que las interfaces descritas aquí están orientadas a bytes, no a caracteres, por lo que los valores de índice provenientes de scripts Tcl necesitan ser convertidos a desplazamientos de bytes utilizando Tcl_UtfAtIndex y rutinas relacionadas.

Un glifo es la imagen visible de una letra, número o algún otro símbolo. No todos los códigos de caracteres en una fuente dada tienen un glifo. Caracteres como tabulaciones, saltos de línea/retornos y caracteres de control que no tienen glifo son medidos y mostrados por estos procedimientos de manera dependiente de la plataforma; en X, se reemplazan con secuencias de escape precedidas por una barra invertida, mientras que en Windows y Macintosh pueden sustituirse por cuadros huecos o sólidos. Consulte la documentación de Tk_ComputeTextLayout para obtener una interfaz de programación que admita la expansión independiente de la plataforma de caracteres de tabulación a columnas y saltos de línea/retornos a texto de múltiples líneas.

Tk_MeasureChars se utiliza tanto para calcular la longitud de una cadena dada como para calcular cuántos caracteres de una cadena caben en un espacio dado. El valor de retorno es el número de bytes de string que caben en el espacio especificado por maxPixels sujeto a las condiciones descritas por flags. Si todos los caracteres caben, el valor de retorno será numBytes. Se rellena *lengthPtr con el ancho calculado, en píxeles, de la porción de la cadena que se midió. Por ejemplo, si el valor de retorno es 5, entonces *lengthPtr se rellena con la distancia entre el borde izquierdo de string[0] y el borde derecho de string[4].

Tk_TextWidth es una función envoltorio que proporciona una interfaz más sencilla a la función Tk_MeasureChars. El valor de retorno es cuánto espacio en píxeles necesita la string dada.

Tk_DrawChars dibuja la string en la ubicación dada en el drawable especificado.

Tk_UnderlineChars subraya el rango de caracteres dado en la string dada. No dibuja los caracteres (que se asume que ya fueron mostrados por Tk_DrawChars); solo dibuja el subrayado. Este procedimiento se utiliza para subrayar unos pocos caracteres sin tener que construir una fuente subrayada. Para producir texto subrayado de forma nativa, se debe construir y utilizar la fuente subrayada apropiada.
