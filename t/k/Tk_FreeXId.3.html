Tk_FreeXId(3) Procedimientos de la biblioteca Tk Tk_FreeXId(3)

NOMBRE

Tk_FreeXId - hacer que el identificador de recurso X esté disponible para su reutilización

SINOPSIS

#include <tk.h>

Tk_FreeXId(display, id)

ARGUMENTOS

Display *display (entrada)
Pantalla para la que se asignó id.
XID id (entrada)
Identificador del recurso X (ventana, fuente, pixmap, cursor, contexto gráfico o mapa de colores) que ya no está en uso.

DESCRIPCIÓN

El asignador predeterminado de identificadores de recursos proporcionado por Xlib es muy simple y no permite que los identificadores de recursos se reutilicen. Si una aplicación de larga duración llega al final del espacio de IDs de recursos, generará un error de protocolo X y fallará. Tk reemplaza el asignador de IDs predeterminado con su propio asignador, que permite la reutilización de identificadores. Para que esto funcione, se debe llamar a Tk_FreeXId para informar al asignador sobre los recursos que se han liberado. Tk llama automáticamente a Tk_FreeXId cada vez que libera un recurso, por lo que si utiliza procedimientos como Tk_GetFont, Tk_GetGC y Tk_GetPixmap, no necesitará llamar a Tk_FreeXId. Sin embargo, si asigna recursos directamente desde Xlib, por ejemplo, llamando a XCreatePixmap, entonces debería llamar a Tk_FreeXId cuando llame al procedimiento de liberación de Xlib correspondiente, como XFreePixmap. Si no llama a Tk_FreeXId, el identificador del recurso se perderá, lo que podría causar problemas si la aplicación se ejecuta durante el tiempo suficiente para perder todos los identificadores disponibles.
