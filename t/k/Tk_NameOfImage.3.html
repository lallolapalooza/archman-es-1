NOMBRE

Tk_NameOfImage - Devolver el nombre de la imagen.

SINOPSIS

#include <tk.h>

const char *
Tk_NameOfImage(imageMaster)

ARGUMENTOS

Tk_ImageMaster imageMaster (entrada)
Token de la imagen, que se pasó al createProc del gestor de imágenes cuando se creó la imagen.

DESCRIPCIÓN

Este procedimiento es invocado por los gestores de imágenes para averiguar el nombre de una imagen. Dado el token de la imagen, devuelve el nombre de cadena de la imagen.

Tk_ImageModel es sinónimo de Tk_ImageMaster

PALABRAS CLAVE

gestor de imágenes, nombre de imagen

4.0 Tk
