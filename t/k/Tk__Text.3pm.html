OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: height
Clase: Height
Opción: -height
Especifica la altura deseada para la ventana, en unidades de caracteres de la fuente dada por la opción -font. Debe ser al menos uno.
Nombre: spacing1
Clase: Spacing1
Opción: -spacing1
Solicita espacio adicional por encima de cada línea de texto en el widget, utilizando cualquiera de las formas estándar para distancias de pantalla. Si una línea se ajusta, esta opción solo se aplica a la primera línea en la pantalla. Esta opción puede ser anulada con opciones -spacing1 en las etiquetas.
Nombre: spacing2
Clase: Spacing2
Opción: -spacing2
Para líneas que se ajustan (de modo que cubren más de una línea en la pantalla) esta opción especifica espacio adicional a proporcionar entre las líneas de pantalla que representan una sola línea de texto. El valor puede tener cualquiera de las formas estándar para distancias de pantalla. Esta opción puede ser anulada con opciones -spacing2 en las etiquetas.
Nombre: spacing3
Clase: Spacing3
Opción: -spacing3
Solicita espacio adicional por debajo de cada línea de texto en el widget, utilizando cualquiera de las formas estándar para distancias de pantalla. Si una línea se ajusta, esta opción solo se aplica a la última línea en la pantalla. Esta opción puede ser anulada con opciones -spacing3 en las etiquetas.
Nombre: state
Clase: State
Opción: -state
Especifica uno de los dos estados para el texto: normal o disabled. Si el texto está deshabilitado, no se pueden insertar ni eliminar caracteres y no se mostrará ningún cursor de inserción, incluso si el foco de entrada está en el widget.
Nombre: tabs
Clase: Tabs
Opción: -tabs
Especifica un conjunto de tabuladores para la ventana. El valor de la opción consiste en una lista de distancias de pantalla que indican las posiciones de los tabuladores. Cada posición puede ir opcionalmente seguida en el siguiente elemento de la lista de una de las palabras clave left, right, center o numeric, que especifica cómo justificar el texto en relación con el tabulador. Left es el valor predeterminado; hace que el texto que sigue al carácter de tabulación se posicione con su borde izquierdo en la posición del tabulador. Right significa que el borde derecho del texto que sigue al carácter de tabulación se posiciona en la posición del tabulador, y center significa que el texto se centra en la posición del tabulador. Numeric significa que el punto decimal en el texto se posiciona en la posición del tabulador; si no hay punto decimal, el dígito menos significativo del número se posiciona justo a la izquierda del tabulador; si no hay número en el texto, el texto se justifica a la derecha en la posición del tabulador. Por ejemplo, -tabs => [qw/2c left 4c 6c center/] crea tres tabuladores con intervalos de dos centímetros; los dos primeros usan justificación izquierda y el tercero usa justificación central. Si la lista de tabuladores no tiene suficientes elementos para cubrir todos los tabuladores en una línea de texto, Tk extrapola nuevos tabuladores utilizando el espaciado y la alineación del último tabulador de la lista. El valor de la opción tabs puede ser anulado por opciones -tabs en las etiquetas. Si no se especifica ninguna opción -tabs, o si se especifica como una lista vacía, entonces Tk utiliza tabuladores predeterminados espaciados cada ocho caracteres (de tamaño promedio).
Nombre: width
Clase: Width
Opción: -width
Especifica el ancho deseado para la ventana en unidades de caracteres de la fuente dada por la opción -font. Si la fuente no tiene un ancho uniforme, se utiliza el ancho del carácter ``0'' para la traducción de unidades de caracteres a unidades de pantalla.
Nombre: wrap
Clase: Wrap
Opción: -wrap
Especifica cómo manejar las líneas en el texto que son demasiado largas para ser mostradas en una sola línea de la ventana del texto. El valor debe ser none, char o word. Un modo de ajuste (wrap) none significa que cada línea de texto aparece como exactamente una línea en la pantalla; los caracteres extra que no caben en la pantalla no se muestran. En los otros modos, cada línea de texto se dividirá en varias líneas de pantalla si es necesario para mantener visibles todos los caracteres. En el modo char, una rotura de línea de pantalla puede ocurrir después de cualquier carácter; en el modo word, una rotura de línea solo se realizará en los límites de palabras.

DESCRIPCIÓN

El método Text crea una nueva ventana (dada por el argumento $text) y la convierte en un widget de texto. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del texto, como su color de fondo predeterminado y su relieve. El comando text devuelve el nombre de ruta de la nueva ventana.

Un widget de texto muestra una o más líneas de texto y permite que ese texto sea editado. Los widgets de texto admiten cuatro tipos diferentes de anotaciones en el texto, llamadas etiquetas (tags), marcas (marks), ventanas incrustadas (embedded windows) o imágenes incrustadas (embedded images). Las etiquetas permiten que diferentes porciones del texto se muestren con diferentes fuentes y colores. Además, las devoluciones de llamada de perl/Tk pueden asociarse con etiquetas para que los scripts se invoquen cuando ocurren acciones particulares, como pulsaciones de teclas y clics de botones del ratón, en rangos específicos del texto. Ver "ETIQUETAS" más abajo para más detalles.

La segunda forma de anotación consiste en marcas, que son marcadores flotantes en el texto. Las marcas se utilizan para realizar un seguimiento de varias posiciones interesantes en el texto a medida que se edita. Ver "MARCAS" más abajo para más detalles.

La tercera forma de anotación permite que ventanas arbitrarias se incrusten en un widget de texto. Ver "VENTANAS INCRUSTADAS" más abajo para más detalles.

La cuarta forma de anotación permite que imágenes Tk se incrusten en un widget de texto. Ver "IMÁGENES INCRUSTADAS" más abajo para más detalles.

El widget Text de Perl/Tk no admite deshacer/rehacer; use el widget TextUndo en su lugar.

ÍNDICES

Muchos de los métodos para textos toman uno o más índices como argumentos. Un índice es una cadena utilizada para indicar un lugar particular dentro de un texto, como un lugar para insertar caracteres o un punto final de un rango de caracteres a eliminar. Los índices tienen la sintaxis

base modificador modificador modificador ...

Donde base da un punto de partida y los modificadores ajustan el índice desde el inico

INDICES

An index is a string that refers to a specific character position within the text. Indices are used to specify ranges for operations such as inserting, deleting, or retrieving text. An index consists of a base and optional modifiers. The base specifies a starting point (e.g. move forward or backward one character). Every index must contain a base, but the modifiers are optional.

The base for an index must have one of the following forms:

line.char
Indicates the char'th character on line line. Lines are numbered from 1 for consistency with other UNIX programs that use this numbering scheme. Within a line, characters are numbered from 0. If char is end then it refers to the newline character that ends the line.
@x,y
Indicates the character that covers the pixel whose x and y coordinates within the text's window are x and y.
end
Indicates the end of the text (the character just after the last newline).
mark
Indicates the character just after the mark whose name is mark.
tag.first
Indicates the first character in the text that has been tagged with tag. This form generates an error if no characters are currently tagged with tag.
tag.last
Indicates the character just after the last one in the text that has been tagged with tag. This form generates an error if no characters are currently tagged with tag.
$widget
Indicates the position of the embedded window referenced by $widget. This form generates an error if $widget does not reference to an embedded window.
imageName
Indicates the position of the embedded image whose name is imageName. This form generates an error if there is no embedded image by the given name.

If the base could match more than one of the above forms, such as a mark and imageName both having the same value, then the form earlier in the above list takes precedence. If modifiers follow the base index, each one of them must have one of the forms listed below. Keywords such as chars and wordend may be abbreviated as long as the abbreviation is unambiguous.

+ count chars
Adjust the index forward by count characters, moving to later lines in the text if necessary. If there are fewer than count characters in the text after the current index, then set the index to the last character in the text. Spaces on either side of count are optional.
- count chars
Adjust the index backward by count characters, moving to earlier lines in the text if necessary. If there are fewer than count characters in the text before the current index, then set the index to the first character in the text. Spaces on either side of count are optional.
+ count lines
Adjust the index forward by count lines, retaining the same character position within the line. If there are fewer than count lines after the line containing the current index, then set the index to refer to the same character position on the last line of the text. Then, if the line is not long enough to contain a character at the indicated character position, adjust the character position to refer to the last character of the line (the newline). Spaces on either side of count are optional.
- count lines
Adjust the index backward by count lines, retaining the same character position within the line. If there are fewer than count lines before the line containing the current index, then set the index to refer to the same character position on the first line of the text. Then, if the line is not long enough to contain a character at the indicated character position, adjust the character position to refer to the last character of the line (the newline). Spaces on either side of count are optional.
linestart
Adjust the index to refer to the first character on the line.
lineend
Adjust the index to refer to the last character on the line (the newline).
wordstart
Adjust the index to refer to the first character of the word containing the current index. A word consists of any number of adjacent characters that are letters, digits, or underscores, or a single character that is not one of these.
wordend
Adjust the index to refer to the character just after the last one of the word containing the current index. If the current index refers to the last character of the text then it is not modified.

If more than one modifier is present then they are applied in left-to-right order. For example, the index ``end - 1 chars'' refers to the next-to-last character in the text and ``insert wordstart - 1 c'' refers to the character just before the first one in the word containing the insertion cursor.

TAGS

The first form of annotation in text widgets is a tag. A tag is a textual string that is associated with some of the characters in a text. Tags may contain arbitrary characters, but it is probably best to avoid using the the characters `` '' (space), +, or -: these characters have special meaning in indices, so tags containing them can't be used as indices. There may be any number of tags associated with characters in a text. Each tag may refer to a single character, a range of characters, or several ranges of characters. An individual character may have any number of tags associated with it.

A priority order is defined among tags, and this order is used in implementing some of the tag-related functions described below. When a tag is defined (by associating it with characters or setting its display options or binding callbacks to it), it is given a priority higher than any existing tag. The priority order of tags may be redefined using the ``$text->tagRaise'' and ``$text->tagLower'' methods.

Tags serve three purposes in text widgets. First, they control the way information is displayed on the screen. By default, characters are displayed as determined by the background, font, and foreground options for the text widget. However, display options may be associated with individual tags using the ``$text->tagConfigure'' method. If a character has been tagged, then the display options associated with the tag override the default display style. The following options are currently supported for tags:

-background => color
Color specifies the background color to use for characters associated with the tag. It may have any of the forms accepted by Tk_GetColor.
-bgstipple => bitmap
Bitmap specifies a bitmap that is used as a stipple pattern for the background. It may have any of the forms accepted by Tk_GetBitmap. If bitmap hasn't been specified, or if it is specified as an empty string, then a solid fill will be used for the background.
-borderwidth => pixels
Pixels specifies the width of a 3-D border to draw around the background. It may have any of the forms accepted by Tk_GetPixels. This option is used in conjunction with the -relief option to give a 3-D appearance to the background for characters; it is ignored unless the -background option has been set for the tag.
-elide => boolean
Elide specifies whether the data should be elided. Elided data is not displayed and takes no space on screen, but further on behaves just as normal data.
-data => value
Allows an arbitrary perl scalar value to be associated with the tag.
-fgstipple => bitmap
Bitmap specifies a bitmap that is used as a stipple pattern when drawing text and other foreground information such as underlines. It may have any of the forms accepted by Tk_GetBitmap. If bitmap hasn't been specified, or if it is specified as an empty string, then a solid fill will be used.
-font => fontName
FontName is the name of a font to use for drawing characters. It may have any of the forms accepted by Tk_GetFontStruct.
-foreground => color
Color specifies the color to use when drawing text and other foreground information such as underlines. It may have any of the forms accepted by Tk_GetColor.
-justify => justify
If the first character of a display line has a tag for which this option has been specified, then justify determines how to justify the line. It must be one of left, right, or center. If a line wraps, then the justification for each line on the display is determined by the first character of that display line.
-lmargin1 => pixels
If the first character of a text line has a tag for which this option has been specified, then pixels specifies how much the line should be indented from the left edge of the window. Pixels may have any of the standard forms for screen distances. If a line of text wraps, this option only applies to the first line on the display; the -lmargin2 option controls the indentation for subsequent lines.

Pixels pueden tener cualquier de los formas estándar para distancias de pantalla. Esta opción se utiliza solo cuando se habilita el envoltorio y solo aplica a las líneas segunda y posteriores para una línea de texto.

-offset => pixels
Pixels especifica un cantidad por la que la base de la línea del texto debe ser desplazada verticalmente desde la base de la línea global, en pixeles. Por ejemplo, un desplazamiento positivo puede utilizarse para superScripts y un desplazamiento negativo para subscripts. Pixels pueden tener cualquier de las formas estándar para distancias de pantalla.
-overstrike => boolean
Indica si se debe dibujar un reglamento horizontal a través del medio de los caracteres. Boolean puede tener cualquier de las formas aceptadas por Tk_GetBoolean.

Esta opción se utiliza en conjunto con la opción -borderwidth para dar un aspecto 3D a los fondos para los caracteres; se ignora si el opción -background ha sido establecida para el tag.
-rmargin => pixels
Si el primer carácter de una línea de muestra tiene una etiqueta para la que esta opción ha sido especificada, entonces pixels especifica cuánto de margen debe dejar entre el final de la línea y el borde derecho de la ventana. Pixels pueden tener cualquier de las formas estándar para distancias de pantalla. Esta opción se utiliza solo cuando se habilita el envoltorio. Si una línea de texto se extiende, el margen derecho para cada línea en la muestra se determina según el primer carácter de esa línea de muestra.
-spacing1 => pixels
Pixels especifica cuánto espacio adicional debe dejar por encima de cada línea de texto, usando cualquier de las formas estándar para distancias de pantalla. Si una línea se extiende, esta opción solo aplica a la primera línea en la muestra.
-spacing2 => pixels
Para líneas que se extienden, esta opción especifica cuánto espacio adicional debe dejar entre las líneas de muestra para una única línea de texto. Pixels pueden tener cualquier de las formas estándar para distancias de pantalla.
-spacing3 => pixels
Pixels especifica cuánto espacio adicional debe dejar por debajo de cada línea de texto, usando cualquier de las formas estándar para distancias de pantalla. Si una línea se extiende, esta opción solo aplica al último línea en la muestra.
-tabs => tabList
TabList especifica un conjunto de tab stops en la misma forma que para la opción -tabs de la ventana de texto. Esta opción solo aplica a una línea de muestra si aplica al primer carácter de esa línea. Si esta opción se especifica como un vacío, cancela la opción, dejando que sea indefinida para el tag (por defecto). Si se especifica como un string no vacío que sea una lista vacía, como -tabs = " ">, entonces pide tabstops por defecto de 8 caracteres, como se describe para la opción tabs de la ventana de texto.
-underline => boolean
Boolean especifica si se debe dibujar un subrayado debajo de los caracteres. Puede tener cualquier de las formas aceptadas por Tk_GetBoolean.
-wrap => mode
Mode especifica cómo se debe manejar las líneas que son más anchas que la ventana de texto del texto. Tiene los mismos valores legales que la opción -wrap de la ventana de texto: none, char o word. Si esta opción de etiqueta se especifica, sobrecribe la opción -wrap de la ventana de texto.

Si un carácter tiene varios etiquetas asociadas y si sus opciones de visualización conflitan, se utilizan las opciones de la etiqueta de mayor prioridad. Si una determinada opción de visualización no ha sido especificada para una etiqueta o si está especificada como una cadena vacía, entonces esa opción nunca se utilizará; se utilizará en su lugar la opción de la etiqueta de prioridad siguiente. Si ninguna etiqueta especifica una opción de visualización particular, se utilizará el estilo por defecto de la ventana.

La segunda función de las etiquetas es la asociación de eventos. Se pueden asociar bindings a una etiqueta de manera similar a como se pueden asociar bindings a una clase de widget: cuando ciertos eventos X ocurren en caracteres con la etiqueta dada, se ejecutará una callback específica. Las etiquetas de binding pueden usarse para dar comportamientos a rangos de caracteres; entre otros, esto permite implementar funcionalidades de hipertexto. Para detalles, vea la descripción de la metodología tagBind de la ventana de texto.

La tercera utilización de las etiquetas es para la gestión de selección. Véase "THE SELECTION" a continuación.

MARKS

La segunda forma de anotación en las ventanas de texto es una marca. Las marcas se utilizan para recordar lugares específicos en un texto. Son algo como las etiquetas, en el sentido de que tienen nombres y se refieren a lugares en el archivo, pero una marca no está asociada a caracteres específicos. En cambio, una marca se asocia con el espacio entre dos caracteres. Solo puede haber una posición asociada con una marca en cualquier momento. Si los caracteres alrededor de una marca se eliminan, la marca permanecerá; simplemente tendrá nuevos caracteres vecinos. En contraste, si se elimina los caracteres que contienen una etiqueta, la etiqueta dejará de tener asociación con los caracteres en el archivo. Las marcas pueden ser manipuladas con el método $text-mark de la ventana de texto, y sus ubicaciones actuales se pueden determinar utilizando el nombre de la marca como un índice en las funciones.

Cada marca también tiene un gravity, que es left o right. El gravity de una marca especifica qué ocurre con la marca cuando se inserta texto en el punto de la marca. Si una marca tiene gravity left, entonces la marca se trata como si estuviera asociada al carácter a su izquierda, por lo que la marca se mantendrá a la izquierda de cualquier texto insertado en el punto de la marca. Si la marca tiene gravity right, el texto insertado en el punto de la marca se mostrará a la derecha de la marca. El gravity de una marca se predetermina como right.

El espacio de nombres para marcas es diferente del espacio de nombres para etiquetas: el mismo nombre puede usarse tanto para una marca como para una etiqueta, pero se referirán a cosas diferentes.

Dos marcas tienen significado especial. Primero, la marca insert está asociada con el cursor de inserción, como se describe en "THE INSERTION CURSOR". Segundo, la marca current está asociada con el carácter más cercano al ratón y se ajusta automáticamente para seguir la posición del ratón y cualquier cambio en el texto de la ventana. (Una excepción: current no se actualiza en respuesta a movimientos del ratón si el botón del ratón está presionado; la actualización se deferrará hasta que todos los botones del ratón hayan sido liberados). Ninguna de estas marcas especiales puede ser eliminada.

EMBEDDED WINDOWS

La tercera forma de anotación en las ventanas de texto es una ventana embebida. Cada anotación de ventana embebida causa una ventana para mostrarse en un punto específico en el texto. Podría haber cualquier número de ventanas embebidas en una ventana de texto, y cualquiera de los widgets puede usarse como ventana embebida (sujeto a las reglas normales de gestión de geometría, que requieren que la ventana de texto sea el padre de la ventana embebida o un descendiente del padre de esta). La posición de la ventana embebida en la pantalla se actualizará según se modifique o se desplazare el texto, y se mapará y se desmapeará según se mueva hacia dentro y hacia fuera del área visible de la ventana de texto. Cada ventana embebida ocupa un espacio de índice equivalente a un carácter en la ventana de texto, y puede referirse a la ventana embebida por el nombre de la ventana embebida o por su posición en el espacio de índice de la ventana. Si el rango de texto que contiene la ventana embebida es eliminado, la ventana se destruye.

Cuando una ventana embebida se agrega a una ventana de texto con el método widgetCreate, varios opciones de configuración pueden estar asociadas con ella. Estas opciones pueden modificarse posteriormente con el método widgetConfigure. Las opciones siguientes son actualmente soportadas:

-align => where
Si la ventana no es tan alta como la línea en la que se muestra, esta opción determina dónde se muestra la ventana en la línea. Where debe tener uno de los valores top (alinear la parte superior de la ventana con la parte superior de la línea), center (centrar la ventana dentro del rango de la línea), bottom (alinear la parte inferior de la ventana con la parte inferior del área de la línea), o baseline (alinear la parte inferior de la ventana con la base de la línea).
-create => callback
Spécifie un callback que puede evaluarse para crear la ventana de la anotación. Si no se ha especificado la opción -window para la anotación, este callback se evaluará cuando la anotación esté a punto de mostrarse en la pantalla. Callback debe crear una ventana para la anotación y devolver el nombre de esa ventana como resultado. Si la ventana de la anotación debe ser eliminada alguna vez, el callback se evaluará de nuevo la próxima vez que la anotación se muestre.
-padx => pixels
Pixels especifica el cantidad de espacio extra a dejar en cada lado de la ventana embebida. Puede tener cualquier de las formas estándar definidas para una distancia de pantalla (ver Tk_GetPixels).
-pady => pixels
Pixels especifica el cantidad de espacio extra a dejar en la parte superior y en la parte inferior de la ventana embebida. Puede tener cualquier de las formas estándar definidas para una distancia de pantalla (ver Tk_GetPixels).
-stretch => boolean
Si la altura solicitada de la ventana embebida es menor que la altura de la línea en la que se muestra, esta opción puede usarse para especificar si la ventana debe estirarse verticalmente para llenar su línea. Si se ha especificado la opción -pady además, el espacio solicitado se mantendrá incluso si la ventana estira.
-window => window
Esta opción especifica la ventana que se embeberá en el texto. La window debe ser un widget hijo de la ventana de texto o un hijo de un widget que sea un hijo de la ventana de texto. Si se especifica esta opción, entonces la opción -create no se usa.

Especifica el nombre de una ventana para mostrar en la anotación.

IMAGENES EMBEBIDAS

La forma final de la anotación en los widgets de texto es una imagen embebida. Cada anotación de imagen embebida causa que se muestre una imagen en un punto particular del texto. Puede haber cualquier número de imágenes embebidas en un widget de texto, y una imagen particular puede estar embebida en múltiples lugares en el mismo widget de texto. La posición de la imagen embebida en la pantalla se actualizará a medida que el texto se modifique o se desplace. Cada imagen embebida ocupa un espacio de índice del tamaño de un carácter en el widget de texto, y puede ser referenciada ya sea por su posición en el espacio de índice del widget, o por el nombre que se le asigna cuando la imagen se inserta en el widget de texto con imageCreate. Si se elimina el rango de texto que contiene la imagen embebida, esa copia de la imagen se elimina de la pantalla.

Cuando se agrega una imagen embebida a un widget de texto con el método de creación image, se devuelve un nombre único para esta instancia de la imagen. Este nombre puede usarse luego para referirse a esta instancia de imagen. El nombre se toma como el valor de la opción -name (descrita a continuación). Si no se proporciona la opción -name, se usa el nombre de la imagen -image en su lugar. Si el nombreImagen ya está en uso en el widget de texto, se agrega #nn al final de nombreImagen, donde nn es un entero arbitrario. Esto asegura que el nombreImagen sea único. Una vez que este nombre se asigna a esta instancia de la imagen, no cambia, aunque los valores de -image o -name se puedan cambiar con image configure.

Cuando se agrega una imagen embebida a un widget de texto con el método imageCreate, se pueden asociar varias opciones de configuración. Estas opciones se pueden modificar posteriormente con el método image configure. Las siguientes opciones son compatibles actualmente:

-align => donde
Si la imagen no tiene la misma altura que la línea en la que se muestra, esta opción determina dónde se muestra la imagen en la línea. Donde debe tener uno de los valores top (alinear la parte superior de la imagen con la parte superior de la línea), center (centrar la imagen dentro del rango de la línea), bottom (alinear la parte inferior de la imagen con la parte inferior del área de la línea), o baseline (alinear la parte inferior de la imagen con la línea de base de la línea).
-image => imagen
Especifica el nombre de la imagen Tk a mostrar en la anotación. Si imagen no es una imagen Tk válida, se devuelve un error.
-name => NombreImagen
Especifica el nombre por el cual esta instancia de imagen puede ser referenciada en el widget de texto. Si no se proporciona NombreImagen, se utiliza el nombre de la imagen Tk en su lugar. Si el nombreImagen ya está en uso, se agrega #nn al final del nombre como se describe anteriormente.
-padx => píxeles
Píxeles especifica la cantidad de espacio adicional que se dejará en cada lado de la imagen embebida. Puede tener cualquiera de las formas usuales definidas para una distancia de pantalla.
-pady => píxeles
Píxeles especifica la cantidad de espacio adicional que se dejará en la parte superior y en la parte inferior de la imagen embebida. Puede tener cualquiera de las formas usuales definidas para una distancia de pantalla.

LA SELECCIÓN

El soporte de selección se implementa a través de etiquetas. Si la opción exportSelection para el widget de texto es verdadera, la etiqueta sel se asociará con la selección:

[1]
Cada vez que se etiquetan caracteres con sel, el widget de texto reclamará la propiedad de la selección.
[2]
Los intentos de recuperar la selección serán atendidos por el widget de texto, devolviendo todos los caracteres con la etiqueta sel.
[3]
Si la selección es reclamada por otra aplicación o por otra ventana dentro de esta aplicación, entonces la etiqueta sel se eliminará de todos los caracteres del texto.
[4]
Cada vez que el rango de la etiqueta sel cambia, se genera un evento virtual <<Selection>>.

La etiqueta sel se define automáticamente cuando se crea un widget de texto, y no se puede eliminar con el método ``$text->tagDelete''. Además, las opciones selectBackground, selectBorderWidth y selectForeground para el widget de texto están vinculadas a las opciones -background, -borderwidth y -foreground de la etiqueta sel: los cambios en cualquiera de ellas se reflejarán automáticamente en la otra.

EL CURSOR DE INSERCIÓN

La marca llamada insert tiene un significado especial en los widgets de texto. Se define automáticamente cuando se crea un widget de texto y no se puede desmarcar con el comando de widget ``$text->markUnset''. La marca insert representa la posición del cursor de inserción, y el cursor de inserción se dibujará automáticamente en este punto siempre que el widget de texto tenga el foco de entrada.

EL INDICADOR MODIFICADO

El widget de texto puede hacer un seguimiento de los cambios en el contenido del widget mediante el indicador modificado. Insertar o eliminar texto establecerá este indicador. El indicador se puede consultar, establecer y borrar programáticamente. Cada vez que el indicador cambia de estado, se genera un evento virtual <<Modified>>. Consulte el comando de widget edit modified para más detalles.

MÉTODOS DEL WIDGET

El método Text crea un objeto widget. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

Los siguientes métodos adicionales están disponibles para los widgets de texto. Además, los métodos de texto extendidos documentados en "Mastering Perl/Tk" se incluyen en este pod (con permiso del editor, O'Reilly and Associates Inc.).

$text->adjustSelect
Mueve el punto final de la selección y el punto de anclaje a la ubicación del puntero del ratón.
$text->bbox(índice)
Devuelve una lista de cuatro elementos que describen el área de pantalla del carácter dado por índice. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del área ocupada por el carácter, y los dos últimos elementos dan el ancho y la altura del área. Si el carácter solo es parcialmente visible en la pantalla, el valor devuelto reflejará solo la parte visible. Si el carácter no es visible en la pantalla, el valor devuelto es una lista vacía.
$text->clipboardColumnCopy
Realiza una copia rectangular del texto seleccionado actualmente con una compensación básica para los caracteres de tabulación.
$text->clipboardColumnCut
Realiza un corte rectangular del texto seleccionado actualmente con una compensación básica para los caracteres de tabulación.

Realiza un pegado rectangular del texto en el portapapeles. La esquina superior izquierda se especifica por la posición actual de la marca de inserción con compensación básica para los caracteres de tabulación.
$text->compare(índice1, op, índice2)
Compara los índices dados por índice1 y índice2 según el operador relacional dado por op, y devuelve 1 si se cumple la relación y 0 si no. Op debe ser uno de los operadores <, <=, ==, >=, >, o !=. Si op es ==, se devuelve 1 si los dos índices se refieren al mismo carácter, si op es <, se devuelve 1 si índice1 se refiere a un carácter anterior en el texto que índice2, y así sucesivamente.
$text->Contents(?args?)
Consulta o modifica el contenido completo del widget de texto. Si no se proporcionan argumentos, se devuelve el contenido completo del widget de texto. Si se proporcionan argumentos, se elimina todo el contenido del widget de texto y se reemplaza por la lista de argumentos.
$text->debug(?booleano?)
Si se especifica booleano, debe tener uno de los valores verdaderos o falsos aceptados por Tcl_GetBoolean. Si el valor es verdadero, se activarán las comprobaciones de consistencia internas en el código B-tree asociado con los widgets de texto. Si booleano tiene un valor falso, las comprobaciones de depuración se desactivarán. En cualquier caso, el comando devuelve una cadena vacía. Si booleano no se especifica, el comando devuelve on u off para indicar si la depuración está activada o no. Hay un único interruptor de depuración compartido por todos los widgets de texto: activar o desactivar la depuración en cualquier widget la activa o desactiva para todos los widgets. Para widgets con grandes cantidades de texto, las comprobaciones de consistencia pueden causar una ralentización notable.
$text->delete(índice1, ?índice2?)
Elimina un rango de caracteres del texto. Si se especifican tanto índice1 como índice2, entonces se eliminan todos los caracteres comenzando por el dado por índice1 y terminando justo antes de índice2 (es decir, el carácter en índice2 no se elimina). Si índice2 no especifica una posición posterior en el texto a índice1, entonces no se eliminan caracteres. Si índice2 no se especifica, se elimina el único carácter en índice1. No está permitido eliminar caracteres de manera que el texto quede sin una nueva línea como último carácter. El comando devuelve una cadena vacía. Si se proporcionan más índices, se eliminarán varios rangos de texto. Todos los índices se verifican para determinar su validez antes de realizar cualquier eliminación. Se ordenan y el texto se elimina desde el último rango hasta el primer rango para que la eliminación de texto no cause efectos secundarios indeseados de desplazamiento de índices. Si se proporcionan varios rangos con el mismo índice de inicio, se utiliza el rango más largo. Si se proporcionan rangos superpuestos, se fusionarán
en `spans` que no causen la eliminación de texto fuera de los rangos dados debido a que el texto se desplaza durante la eliminación.
$text->deleteSelected
Elimina el texto seleccionado actualmente.
$text->deleteTextTaggedWith(tag)
Elimina el texto etiquetado con el parámetro tag.
$text->deleteToEndofLine
Elimina desde la ubicación de la marca de inserción hasta el final de la línea.
$text->dlineinfo(index)
Devuelve una lista con cinco elementos que describen el área ocupada por la línea de visualización que contiene el index. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del área ocupada por la línea, los terceros y cuartos elementos dan el ancho y la altura del área, y el quinto elemento da la posición de la línea base para la línea, medida hacia abajo desde la parte superior del área. Toda esta información se mide en píxeles. Si el modo de ajuste de línea actual es none y la línea se extiende más allá de los límites de la ventana, el área devuelta refleja toda el área de la línea, incluidas las porciones que están fuera de la ventana. Si la línea es más corta que el ancho completo de la ventana, el área devuelta refleja solo la porción de la línea que está ocupada por caracteres y ventanas incrustadas. Si la línea de visualización que contiene index no es visible en la pantalla, el valor devuelto es una lista vacía.
$text->dump(?switches?, index1, ?index2?)
Devuelve el contenido del widget de texto desde index1 hasta, pero sin incluir, index2, incluyendo el texto e información sobre marcas, etiquetas y ventanas incrustadas. Si no se especifica index2, se utiliza por defecto un carácter después de index1. La información se devuelve en el siguiente formato:

key1 value1 index1 key2 value2 index2 ...

Los posibles valores de key son text, mark, tagon, tagoff, y $text. El value correspondiente es el texto, el nombre de la marca, el nombre de la etiqueta o el nombre de la ventana. La información de index es el índice del inicio del texto, la marca, la transición de etiqueta o la ventana. Se pueden especificar uno o más de los siguientes modificadores (o sus abreviaturas) para controlar la exportación:

-all
Devuelve información sobre todos los elementos: texto, marcas, etiquetas y ventanas. Este es el valor predeterminado.
-command => callback
En lugar de devolver la información como resultado de la operación de exportación, invoca el callback en cada elemento del widget de texto dentro del rango. Se añaden tres argumentos al callback antes de evaluarlo: la key, el value y el index.
-mark
Incluye información sobre marcas en los resultados de la exportación.
-tag
Incluye información sobre transiciones de etiquetas en los resultados de la exportación. La información de etiquetas se devuelve como elementos tagon y tagoff que indican el inicio y el final de cada rango de cada etiqueta, respectivamente.
-text
Incluye información sobre el texto en los resultados de la exportación. El valor es el texto hasta el siguiente elemento o el final del rango indicado por index2. Un elemento de texto no abarca saltos de línea. Un bloque de texto de varias líneas que no contiene marcas ni transiciones de etiquetas se exportará como un conjunto de segmentos de texto que cada uno termina con un salto de línea. El salto de línea es parte del valor.
-window

Incluye información sobre ventanas incrustadas en los resultados de la exportación. El valor de una ventana es su ruta de acceso Tk, a menos que la ventana aún no se haya creado. (Debe tener un script de creación). En este caso, se devuelve una cadena vacía, y debe consultar la ventana por su posición de índice para obtener más información.

$text->edit( option, ?arg, arg ...? );
Este comando controla el mecanismo de deshacer y el indicador de modificado. El comportamiento exacto del comando depende del argumento de opción que sigue al argumento de edición. Las siguientes formas del comando son actualmente soportadas:
$text->editModified( ?boolean? );
Si boolean no se especifica, devuelve el indicador de modificado del widget. Los comandos de inserción, eliminación, edición de deshacer y edición de rehacer, o el usuario, pueden establecer o borrar el indicador de modificado. Si se especifica boolean, establece el indicador de modificado del widget a boolean.

(No implementado, use TextUndo.) Cuando la opción -undo es verdadera, vuelve a aplicar las últimas ediciones deshechas siempre que no se hayan realizado otras ediciones desde entonces. Genera un error cuando la pila de rehacer está vacía. No hace nada cuando la opción -undo es falsa.

(No implementado, use TextUndo.) Borra las pilas de deshacer y rehacer.

mode puede ser -exact o -regexp. Vea el comando search para más información.

case puede ser -nocase o -case. Vea el comando search para más información.

pattern es una cadena exacta para coincidir si mode es -exact o una expresión regular si el modo de coincidencia es -regexp.

$text->FindAndReplaceAll(mode, case, find, replace)
Igual que el método FindAll, sin embargo sustituye adicionalmente el texto coincidente con los caracteres replace.
$text->FindAndReplacePopUp
Crea una ventana emergente de buscar y reemplazar si aún no existe. Si hay texto seleccionado actualmente, el campo 'buscar' se 'prellenará' con la selección.
$text->FindNext(direction, mode, case, pattern)
Elimina cualquier selección actual y luego realiza una búsqueda de texto hacia adelante o hacia atrás. Todas las coincidencias se etiquetan con la etiqueta sel. direction puede ser -forwards o -backwards. mode, case y pattern son como para el método FindAll.
$text->FindPopUp
Crea una ventana emergente de búsqueda, si aún no existe. Si hay texto seleccionado actualmente, el campo 'buscar' se 'prellenará' con la selección.
$text->FindSelectionNext
Obtiene el texto seleccionado actualmente y elimina todas las selecciones. Luego busca la siguiente cadena exacta, sensible a mayúsculas y minúsculas, que coincida en dirección hacia adelante y selecciona el texto, haciendo visible la nueva selección.
$text->FindSelectionPrevious
Obtiene el texto seleccionado actualmente y elimina todas las selecciones. Luego busca la siguiente cadena exacta, sensible a mayúsculas y minúsculas, que coincida en dirección inversa y selecciona el texto, haciendo visible la nueva selección.
$text->get(index1, ?index2?)
Devuelve un rango de caracteres del texto. El valor devuelto serán todos los caracteres del texto comenzando con el que su índice es index1 y terminando justo antes del que su índice es index2 (el carácter en index2 no será devuelto). Si se omite index2, se devuelve el carácter único en index1. Si no hay caracteres en el rango especificado (por ejemplo, index1 está después del final del archivo o index2 es menor o igual a index1), se devuelve una cadena vacía. Si el rango especificado contiene ventanas incrustadas, no se incluye información sobre ellas en la cadena devuelta. Si se dan múltiples pares de índices, se devolverán múltiples rangos de texto en una lista. Los rangos inválidos no se representarán con cadenas vacías en la lista. Los rangos se devuelven en el orden pasado a get.
$text->getSelected
Devuelve el texto seleccionado actualmente.
$text->GetTextTaggedWith(tag)
Devuelve el texto etiquetado con el parámetro tag.
$text->GotoLineNumber(line_number)

$text->GotoLineNumberPopUp(line_number)
Muestra una ventana emergente, prellenándola con el texto numérico seleccionado (si lo hay), o el número de línea de GotoLineNumber (si lo hay).
$text->image(option, ?arg, arg, ...?)
$text->imageOption(?arg, arg, ...?)
Este método se utiliza para manipular imágenes incrustadas. El comportamiento del método depende del argumento option que sigue al prefijo image. Las siguientes formas de los métodos son actualmente soportadas:
$text->imageCget(index, option)
Devuelve el valor de una opción de configuración para una imagen incrustada. Index identifica la imagen incrustada, y option especifica una opción de configuración particular, que debe ser una de las enumeradas en "IMÁGENES INCORPORADAS".
$text->imageConfigure(index, ?option, value, ...?)
Consulta o modifica las opciones de configuración para una imagen incrustada. Si no se especifica option, devuelve una lista que describe todas las opciones disponibles para la imagen incrustada en index (consulte Tk::options para obtener información sobre el formato de esta lista). Si se especifica option sin value, el comando devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica option). Si se especifican uno o más pares option-value, el comando
modifica las opciones dadas para que tengan los valores dados; en este caso, el comando devuelve una cadena vacía. Consulta "IMÁGENES INCORPORADAS" para obtener información sobre las opciones admitidas.

La búsqueda se puede iniciar en cualquier lugar de un texto y se puede limitar a un rango especificado. Si $text->search(pattern, index, ... ) se llama sin un stopIndex , la búsqueda se propagará alrededor del texto. Por ejemplo, si la búsqueda comienza en el carácter 10 y se le pide que busque hasta el final del texto, continuará desde el principio del texto hasta el carácter 9. Si la búsqueda se inicia en la posición 0 y se le pide que busque hasta el carácter 0, la búsqueda se detendrá después de examinar todos los caracteres del texto. Si la búsqueda comienza en la posición 0 y no se proporciona stopIndex , la búsqueda continuará hasta que se vuelva a alcanzar la posición 0. Las búsquedas de patrones se realizan independientemente de si son nuevas líneas. Para una coincidencia exacta, se conservan las nuevas líneas. Si se especifica stopIndex , la búsqueda se detiene en ese índice: para búsquedas hacia adelante, no se considerará ninguna coincidencia en o después de stopIndex ; para búsquedas hacia atrás, no se considerará ninguna coincidencia anterior en el texto a stopIndex . Si se omite stopIndex , se buscará en todo el texto: cuando se llegue al principio o al final del texto, la búsqueda continuará en el otro extremo hasta que se vuelva a alcanzar la ubicación de inicio; si se especifica stopIndex , no ocurrirá ninguna propagación.

$text->see(index)
Ajusta la vista en la ventana para que el carácter dado por index sea completamente visible. Si index ya es visible, el comando no hace nada. Si index está a una corta distancia fuera de la vista, el comando ajusta la vista lo suficiente como para hacer visible index en el borde de la ventana. Si index está muy lejos de la vista, el comando centra index en la ventana.
$text->selectAll
Selecciona todo el texto en el widget.
$text->selectLine
Selecciona la línea con la marca de inserción.
$text->selectWord
Selecciona la palabra con la marca de inserción.
$text->SetCursor(position)
Mueve la marca de inserción a position .
$text->tag(option, ?arg, arg, ...?)
Este comando se utiliza para manipular etiquetas. El comportamiento exacto del comando depende del argumento option que sigue al argumento tag . Las siguientes formas del comando son compatibles actualmente:
$text->tagAdd(tagName, index1, ?index2, index1, index2, ...?)
Asocia la etiqueta tagName con todos los caracteres que comienzan en index1 y terminan justo antes de index2 (el carácter en index2 no está etiquetado). Un solo comando puede contener cualquier número de pares index1 - index2 . Si se omite el último index2 , entonces se etiqueta el único carácter en index1 . Si no hay caracteres en el rango especificado (por ejemplo, index1 está más allá del final del archivo o index2 es menor o igual a index1 ), entonces el comando no tiene ningún efecto.
$text->tagBind(tagName, ?sequence?, ?script?)
Este comando asocia script con la etiqueta dada por tagName . Cada vez que la secuencia de eventos dada por sequence ocurre para un carácter que ha sido etiquetado con tagName , se invocará el script. Este método es similar al comando bind , excepto que opera en caracteres de un texto en lugar de widgets completos. Consulte la documentación de Tk::bind para obtener detalles completos sobre la sintaxis de sequence y las sustituciones realizadas en script antes de invocarlo. Si se especifican todos los argumentos, se crea una nueva vinculación, reemplazando cualquier vinculación existente para la misma sequence y tagName (si el primer carácter de script es ``+'' entonces script aumenta una vinculación existente en lugar de reemplazarla). En este caso, el valor de retorno es una cadena vacía. Si se omite script , el comando devuelve el script asociado con tagName y sequence (se produce un error si no existe tal vinculación). Si se omiten tanto script como sequence , el comando devuelve una lista de todas las secuencias para las que se han definido vinculaciones para tagName .

Los únicos eventos para los que se pueden especificar vinculaciones son aquellos relacionados con el ratón y el teclado (como Enter , Leave , ButtonPress , Motion y KeyPress ) o eventos virtuales. Las vinculaciones de eventos para un widget de texto utilizan la marca current descrita en "MARCAS" más arriba. Un evento Enter se activa para una etiqueta cuando la etiqueta se vuelve presente por primera vez en el carácter actual, y un evento Leave se activa para una etiqueta cuando deja de estar presente en el carácter actual. Los eventos Enter y Leave pueden ocurrir porque la marca current se movió o porque el carácter en esa posición cambió. Tenga en cuenta que estos eventos son diferentes de los eventos Enter y Leave para las ventanas. Los eventos del ratón y del teclado se dirigen al carácter actual. Si se utiliza un evento virtual en una vinculación, esa vinculación solo puede activarse si el evento virtual está definido por un evento subyacente relacionado con el ratón o el teclado.

Es posible que el carácter actual tenga varias etiquetas, y que cada una de ellas tenga una vinculación para una secuencia de eventos particular. Cuando esto ocurre, se invoca una vinculación por cada etiqueta, en orden de menor a mayor prioridad. Si hay múltiples vinculaciones coincidentes para una sola etiqueta, se elige la vinculación más específica (consulte la documentación del comando bind para obtener detalles). Los comandos continue y break dentro de los scripts de vinculación se procesan de la misma manera que para las vinculaciones creadas con el comando bind .

Si se crean vinculaciones para el widget en su conjunto utilizando el comando bind , esas vinculaciones complementarán las vinculaciones de etiquetas. Las vinculaciones de etiquetas se invocarán primero, seguidas de las vinculaciones para la ventana en su conjunto.

$text->tagCget(tagName, option)
Este comando devuelve el valor actual de la opción llamada option asociada con la etiqueta dada por tagName . Option puede tener cualquiera de los valores aceptados por el método tag configure .
$text->tagConfigure(tagName, ?option?, ?value?, ?option, value, ...?)
Este comando es similar al método configure , excepto que modifica las opciones asociadas con la etiqueta dada por tagName en lugar de modificar las opciones del widget de texto general. Si no se especifica ninguna option , el comando devuelve una lista que describe todas las opciones disponibles para tagName (consulte Tk::options para obtener información sobre el formato de esta lista). Si se especifica option sin value , entonces el comando devuelve una lista que describe la única opción con nombre (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna option ). Si se especifican uno o más pares option-value , entonces el comando modifica la(s) opción(es) dada(s) para que tengan el valor(es) dado(s) en tagName ; en este caso, el comando devuelve una cadena vacía. Consulte "ETIQUETAS" más arriba para obtener detalles sobre las opciones disponibles para las etiquetas.
$text->tagDelete(tagName, ?tagName, ...?)
Elimina toda la información de etiquetas para cada uno de los argumentos tagName . El comando elimina las etiquetas de todos los caracteres del archivo y también elimina cualquier otra información asociada con las etiquetas, como vinculaciones e información de visualización. El comando devuelve una cadena vacía.
$text->tagLower(tagName, ?belowThis?)
Cambia la prioridad de la etiqueta tagName para que sea justo inferior en prioridad a la etiqueta cuyo nombre es belowThis . Si se omite belowThis , entonces la prioridad de tagName se cambia para que sea la de menor prioridad de todas las etiquetas.
$text->tagNames(?index?)
Devuelve una lista cuyos elementos son los nombres de todas las etiquetas que están activas en la posición del carácter dada por index . Si se omite index , entonces el valor de retorno describirá todas las etiquetas que existen para el texto (esto incluye todas las etiquetas que se han nombrado en un comando de widget ``$text->tag'' pero que no han sido eliminadas por un método ``$text->tagDelete'', incluso si actualmente no hay caracteres marcados con la etiqueta). La lista se ordenará de menor a mayor prioridad.
$text->tagNextrange(tagName, index1, ?index2?)
Este comando busca en el texto un rango de caracteres etiquetados con tagName donde el primer carácter del rango no sea anterior al carácter en index1 y no posterior al carácter justo antes de index2 (no se considerará un rango que comience en index2 ). Si existen varios rangos coincidentes, se elige el primero. El valor de retorno del comando es una lista que contiene dos elementos, que son el índice del primer carácter del rango y el índice del carácter justo después del último del rango. Si no se encuentra ningún rango coincidente, el valor de retorno es una cadena vacía. Si no se proporciona index2 , se utiliza por defecto el final del texto.

Este comando busca en el texto un rango de caracteres etiquetados con tagName donde el primer carácter del rango esté antes del carácter en index1 y no anterior al carácter en index2 (se considerará un rango que comience en index2 ). El valor de retorno del comando es una lista que contiene dos elementos, que son el índice del primer carácter del rango y el índice del carácter justo después del último del rango. Cambia la prioridad de la etiqueta tagName para que sea justo superior en prioridad a la etiqueta cuyo nombre es aboveThis . Si se omite aboveThis , entonces la prioridad de tagName se cambia para que sea la de mayor prioridad de todas las etiquetas.

Devuelve una lista que describe todos los rangos de texto que han sido etiquetados con tagName . Los dos primeros elementos de la lista describen el primer rango etiquetado en el texto, los siguientes dos elementos describen el segundo rango, y así sucesivamente. El primer elemento de cada par contiene el índice del primer carácter del rango, y el segundo elemento del par contiene el índice del carácter justo después del último del rango. Si no hay caracteres etiquetados con tag , se devuelve una cadena vacía.

Este comando se utiliza para consultar y cambiar la posición horizontal del texto en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
$text->xview
Devuelve una lista que contiene dos elementos. Cada elemento es una fracción real entre 0 y 1; juntos describen la porción del espacio horizontal del documento que es visible en la ventana. Por ejemplo, si el primer elemento es .2 y el segundo es .6, el 20% del texto está fuera de la pantalla hacia la izquierda, el 40% intermedio es visible en la ventana y el 40% del texto está fuera de la pantalla hacia la derecha. Las fracciones se refieren solo a las líneas que son realmente visibles en la ventana: si las líneas en la ventana son muy cortas, de modo que sean completamente visibles, las fracciones devueltas serán 0 y 1, incluso si hay otras líneas en el texto que son mucho más anchas que la ventana. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -xscrollcommand.
$text->xviewMoveto(fraction)
Ajusta la vista en la ventana para que el *fraction* del espacio horizontal del texto esté fuera de la pantalla hacia la izquierda. *Fraction* es una fracción entre 0 y 1.
$text->xviewScroll(number, what)
Este comando desplaza la vista en la ventana hacia la izquierda o la derecha según *number* y *what*. *Number* debe ser un entero. *What* debe ser units o pages o una abreviatura de uno de estos. Si *what* es units, la vista se ajusta a la izquierda o derecha por *number* caracteres de ancho promedio en la pantalla; si es pages, la vista se ajusta por *number* pantallas completas. Si *number* es negativo, se hacen visibles caracteres más a la izquierda; si es positivo, se hacen visibles caracteres más a la derecha.
$text->yview(?args?)
Este comando se utiliza para consultar y cambiar la posición vertical del texto en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
$text->yview
Devuelve una lista que contiene dos elementos, ambos fracciones reales entre 0 y 1. El primer elemento indica la posición del primer carácter de la línea superior en la ventana, en relación con el texto en su conjunto (0.5 significa que está a mitad del texto, por ejemplo). El segundo elemento indica la posición del carácter justo después del último en la línea inferior de la ventana, en relación con el texto en su conjunto. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -yscrollcommand.
$text->yviewMoveto(fraction)
Ajusta la vista en la ventana para que el carácter dado por *fraction* aparezca en la línea superior de la ventana. *Fraction* es una fracción entre 0 y 1; 0 indica el primer carácter del texto, 0.33 indica el carácter un tercio del camino a través del texto, y así sucesivamente.
$text->yviewScroll(number, what)
Este comando ajusta la vista en la ventana hacia arriba o hacia abajo según *number* y *what*. *Number* debe ser un entero. *What* debe ser units o pages. Si *what* es units, la vista se ajusta hacia arriba o hacia abajo por *number* líneas en la pantalla; si es pages, la vista se ajusta por *number* pantallas completas. Si *number* es negativo, se hacen visibles posiciones anteriores en el texto; si es positivo, se hacen visibles posiciones posteriores en el texto.

Cambia la vista en la ventana de $text para que *index* sea visible. Si la opción -pickplace no se especifica, entonces *index* aparecerá en la parte superior de la ventana. Si se especifica -pickplace, el widget elige dónde aparece *index* en la ventana:
[1]
Si *index* ya es visible en algún lugar de la ventana, el comando no hace nada.
[2]
Si *index* está solo a unas pocas líneas fuera de la ventana superior, se posicionará en la parte superior de la ventana.
[3]
Si *index* está solo a unas pocas líneas fuera de la ventana inferior, se posicionará en la parte inferior de la ventana.
[4]
De lo contrario, *index* se centrará en la ventana.

La opción -pickplace ha sido obsoleta por el comando de widget see (see maneja tanto el movimiento x como el y para hacer visible una ubicación, mientras que -pickplace solo maneja el movimiento en y).

Este comando hace que el primer carácter de la línea después de la dada por *number* sea visible en la parte superior de la ventana. *Number* debe ser un entero. Este comando solía usarse para desplazarse, pero ahora está obsoleto.

BINDINGS

Tk crea automáticamente bindings de clase para los textos que les dan el siguiente comportamiento predeterminado. En las descripciones a continuación, "palabra" se refiere a un grupo contiguo de letras, dígitos o caracteres "_", o cualquier carácter individual que no sean estos.

[1]
Hacer clic con el botón del ratón 1 posiciona el cursor de inserción justo antes del carácter debajo del cursor del ratón, establece el foco de entrada en este widget y borra cualquier selección en el widget. Arrastrar con el botón del ratón 1 marca una selección entre el cursor de inserción y el carácter debajo del ratón.
[2]
Hacer doble clic con el botón del ratón 1 selecciona la palabra debajo del ratón y posiciona el cursor de inserción al principio de la palabra. Arrastrar después de un doble clic marcará una selección que consta de palabras completas.
[3]
Hacer triple clic con el botón del ratón 1 selecciona la línea debajo del ratón y posiciona el cursor de inserción al principio de la línea. Arrastrar después de un triple clic marcará una selección que consta de líneas completas.
[4]
Los extremos de la selección se pueden ajustar arrastrando con el botón del ratón 1 mientras se mantiene presionada la tecla Shift; esto ajustará el extremo de la selección que estaba más cerca del cursor del ratón cuando se presionó el botón 1. Si se hace doble clic con el botón antes de arrastrar, la selección se ajustará en unidades de palabras completas; si se hace triple clic, la selección se ajustará en unidades de líneas completas.
[5]
Hacer clic con el botón del ratón 1 con la tecla Control presionada reposicionará el cursor de inserción sin afectar la selección.
[6]
Si se escriben caracteres de impresión normales, se insertan en el punto del cursor de inserción.
[7]
La vista en el widget se puede ajustar arrastrando con el botón del ratón 2. Si se hace clic con el botón del ratón 2 sin mover el ratón, la selección se copia en el texto en la posición del cursor del ratón. La tecla Insert también inserta la selección, pero en la posición del cursor de inserción.
[8]
Si se arrastra el ratón fuera del widget mientras se mantiene presionado el botón 1, la entrada se desplazará automáticamente para hacer visible más texto (si hay más texto fuera de la pantalla en el lado donde el ratón salió de la ventana).
[9]
Las teclas Izquierda y Derecha mueven el cursor de inserción un carácter hacia la izquierda o la derecha; también borran cualquier selección en el texto. Si se presiona Izquierda o Derecha con la tecla Shift presionada, el cursor de inserción se mueve y la selección se extiende para incluir el nuevo carácter. Control-Izquierda y Control-Derecha mueven el cursor de inserción por palabras, y Control-Shift-Izquierda y Control-Shift-Derecha mueven el cursor de inserción por palabras y también extienden la selección. Control-b y Control-f se comportan igual que Izquierda y Derecha, respectivamente. Meta-b y Meta-f se comportan igual que Control-Izquierda y Control-Derecha, respectivamente.
[10]
Las teclas Arriba y Abajo mueven el cursor de inserción una línea hacia arriba o hacia abajo y borran cualquier selección.

TIED INTERFACE

The Perl/Tk Text widget also has built-in TIEHANDLE methods for print and printf statements. This means you can print to file handles tied to a Text widget, and the tied methods automatically insert the print statement's arguments into the Text widget.

For example:

#!/usr/local/bin/perl -w
use POSIX 'acos';
use Tk;
use strict;
my $mw = MainWindow->new;
my $text = $mw->Text(qw/-width 40 -height 10/)->pack;
tie *STDOUT, ref $text, $text;
print "Hello Text World!\n";
printf "pi ~= %1.5f", acos(-1.0);
MainLoop;

To tie a scrolled Text widget, use the Subwidget method to get to the "real" widget:

my $text = $mw->Scrolled('Text')->pack;
tie *STDOUT, 'Tk::Text', $text->Subwidget('scrolled');

PERFORMANCE ISSUES

Text widgets should run efficiently under a variety of conditions. The text widget uses about 2-3 bytes of main memory for each byte of text, so texts containing a megabyte or more should be practical on most workstations. Text is represented internally with a modified B-tree structure that makes operations relatively efficient even with large texts. Tags are included in the B-tree structure in a way that allows tags to span large ranges or have many disjoint smaller ranges without loss of efficiency. Marks are also implemented in a way that allows large numbers of marks. In most cases it is fine to have large numbers of unique tags, or a tag that has many distinct ranges.

One performance problem can arise if you have hundreds or thousands of different tags that all have the following characteristics: the first and last ranges of each tag are near the beginning and end of the text, respectively, or a single tag range covers most of the text widget. The cost of adding and deleting tags like this is proportional to the number of other tags with the same properties. In contrast, there is no problem with having thousands of distinct tags if their overall ranges are localized and spread uniformly throughout the text.

Very long text lines can be expensive, especially if they have many marks and tags within them.

The display line with the insert cursor is redrawn each time the cursor blinks, which causes a steady stream of graphics traffic. Set the -insertofftime option to 0 avoid this.
