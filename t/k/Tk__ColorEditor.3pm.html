NOMBRE

Tk::ColorEditor - Editor de colores Tk de propósito general

SINOPSIS

use Tk::ColorEditor;
$cref = $mw->ColorEditor(-title => $title, -cursor => @cursor);
$cref->Show;

DESCRIPCIÓN

ColorEditor se implementa como un objeto con varios métodos, descritos a continuación. Primero, cree su objeto ColorEditor durante la inicialización del programa (uno debería ser suficiente), y luego configúrelo especificando una lista de widgets Tk para colorear. Cuando sea el momento de usar el editor, invoque el método Show().

ColorEditor permite cierta personalización: puede alterar el menú de atributos de color agregando y/o eliminando elementos del menú y/o separadores, activar o desactivar la ventana de estado, alterar la lista de widgets de color del configurador, o incluso proporcionar su propia función de callback personalizada para la configuración de color.

1.
Llame al constructor para crear el objeto editor, que a su vez devuelve una referencia bendecida al nuevo objeto: 
use Tk::ColorEditor;
$cref = $mw->ColorEditor(
    -title  => $title,
    -cursor => @cursor,
);
   mw     - una referencia de ventana, generalmente el resultado de una llamada a
            MainWindow->new. Como raíz por defecto de un árbol de widgets, $mw y
            todos los widgets descendientes en el momento de la creación del objeto
            son configurados por el procedimiento de configuración de color por
            defecto. (Probablemente querrá cambiar esto, ¡o podría terminar
            coloreando ColorEditor!)
   title  - Título de Toplevel, por defecto = ' '.
   cursor - una especificación de '-cursor' Tk válida (el valor por defecto es
            'top_left_arrow'). Este cursor se utiliza sobre todos los "puntos
            calientes" de ColorEditor.
2.
Invoque el método configure() para cambiar las características del editor: 
$cref->configure(-option => value, ..., -option-n => value-n);
   opciones:
     -command             : una función de callback para un reemplazo de
                            `set_colors'.
     -widgets             : una referencia a una lista de referencias de widgets
                            para el configurador de color.
     -display_status      : TRUE si se muestra la ventana de estado de
                            ColorEditor al aplicar colores.
     -add_menu_item       : 'SEP', o un elemento del menú de atributos de color.
     -delete_menu_item    : 'SEP', un elemento del menú de atributos de color,
                            o el ordinal del elemento del menú de atributos de
                            color.
Por ejemplo:
   $cref->configure(-delete_menu_item   => 3,
       -delete_menu_item   => 'disabledforeground',
       -add_menu_item      => 'SEP',
       -add_menu_item      => 'Nuevo atributo de color',
       -widgets            => [$ce, $qu, $f2b2],
       -widgets            => [$f2->Descendants],
       -command            => [\&my_special_configurator, some, args ]
   );
3.
Invoque el método Show() en el objeto editor, por ejemplo, mediante un botón o una pulsación de menú: 
$cref->Show;
4.
El método cget(-widgets) devuelve una referencia a una lista de widgets que son coloreados por el configurador. Típicamente, agrega nuevos widgets a esta lista y luego la usa en una llamada posterior a configure() para expandir su lista de colores. 
$cref->configure(
    -widgets => [
        @{$Filesystem_ref->cget(-widgets)}, @{$cref->cget(-widgets)},
    ]
);
5.
El método delete_widgets() espera una referencia a una lista de widgets que luego se eliminan de la lista de colores actual. 
$cref->delete_widgets($OBJTABLE{$objname}->{'-widgets'})
