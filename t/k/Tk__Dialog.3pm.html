NOMBRE

Tk::Dialog - Crear un cuadro de diálogo modal y esperar una respuesta.

SINOPSIS

    $dialogo = $padre->Dialog(-opción => valor, ... );

DESCRIPCIÓN

Este procedimiento forma parte de la biblioteca de scripts de Tk - sus argumentos describen un cuadro de diálogo. Después de crear un cuadro de diálogo, Dialog espera a que el usuario seleccione uno de los Botones, ya sea haciendo clic en el Botón con el ratón o escribiendo intro para invocar el Botón predeterminado (si lo hay). Luego devuelve la cadena de texto del Botón seleccionado.

Mientras espera la respuesta del usuario, Dialog establece un bloqueo local. Esto evita que el usuario interactúe con la aplicación de ninguna manera, excepto para invocar el cuadro de diálogo. Consulte el método Show().

OPCIONES

Las siguientes parejas de opción/valor son compatibles:

-title
Texto que aparecerá en la barra de título del gestor de ventanas para el cuadro de diálogo.
-text
Mensaje que aparecerá en la parte superior del Cuadro de diálogo.
-bitmap
Si no está vacío, especifica un mapa de bits para mostrar en la parte superior del Cuadro de diálogo, a la izquierda del texto. Si esta es una cadena vacía, entonces no se muestra ningún mapa de bits en el Cuadro de diálogo.
-default_button
Cadena de texto de la etiqueta del Botón que muestra el anillo predeterminado.
-buttons
Una referencia a una lista de cadenas de texto de las etiquetas de los Botones. Cada cadena especifica el texto a mostrar en un Botón, en orden de izquierda a derecha.

MÉTODOS

$respuesta = $dialogo->Show(?-global?);
Este método muestra el Cuadro de diálogo, espera la respuesta del usuario y almacena la cadena de texto del Botón seleccionado en $respuesta. Si se especifica -global, se realiza un bloqueo global (en lugar de local).

El Cuadro de diálogo real se muestra utilizando el método Popup. Cualquier otra opción suministrada a Show se pasa a Popup, y puede utilizarse para posicionar el Cuadro de diálogo en la pantalla. Por favor, lea Tk::Popup para obtener detalles.

WIDGETS ANUNCIADOS

Dado que Tk::Dialog es una subclase de Tk::DialogBox, hereda todos los subwidgets anunciados de su superclase: por ejemplo, "B_boton-texto", donde 'texto-boton' es el valor de -text de un Botón. Además, Tk::Dialog anuncia:

mensaje
El widget Label del cuadro de diálogo que contiene el texto del mensaje.
mapa de bits
El widget Label del cuadro de diálogo que contiene la imagen del mapa de bits.

EJEMPLO

$dialogo = $mw->Dialog(-text => '¿Guardar archivo?', -bitmap => 'question', -title => 'Cuadro de diálogo Guardar archivo', -default_button => 'Sí', -buttons => [qw/Sí No Cancelar/]);

PALABRAS CLAVE
