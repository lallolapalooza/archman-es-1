NOMBRE

Tk_Name, Tk_PathName, Tk_NameToWindow - convertir entre nombres y tokens de ventana

SINOPSIS

#include <tk.h>

Tk_Uid
Tk_Name(tkwin)

char *
Tk_PathName(tkwin)

Tk_Window
Tk_NameToWindow(interp, pathName, tkwin)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token para la ventana.
Tcl_Interp *interp (salida)
Intérprete a utilizar para la notificación de errores.
const char *pathName (entrada)
Cadena de caracteres que contiene el nombre de ruta de la ventana.

DESCRIPCIÓN

Cada ventana gestionada por Tk tiene dos nombres, un nombre corto que identifica una ventana entre los hijos del mismo padre, y un nombre de ruta que identifica de forma única la ventana entre todas las ventanas pertenecientes a la misma ventana principal. El nombre de ruta se utiliza más a menudo en Tk que el nombre corto; muchos comandos, como bind, esperan nombres de ruta como argumentos.

La macro Tk_Name devuelve el nombre corto de una ventana, que es el mismo que el argumento name pasado a Tk_CreateWindow cuando se creó la ventana. El valor se devuelve como un Tk_Uid, que puede utilizarse igual que un puntero de cadena pero también tiene las propiedades de un identificador único (consulte la entrada del manual para Tk_GetUid para obtener detalles).

La macro Tk_PathName devuelve un nombre jerárquico para tkwin. Los nombres de ruta tienen una estructura similar a los nombres de archivo en Unix, pero con puntos entre los elementos en lugar de barras: la ventana principal de una aplicación tiene el nombre de ruta “.”; sus hijos tienen nombres como “.a” y “.b”; sus hijos tienen nombres como “.a.aa” y “.b.bb”; y así sucesivamente. Una ventana se considera hijo de otra ventana a efectos de nomenclatura si la segunda ventana se denominó como padre de la primera ventana cuando se creó la primera ventana. Esto no siempre es lo mismo que la jerarquía de ventanas de X. Por ejemplo, una ventana emergente se crea como hija de la ventana raíz, pero su padre lógico suele ser una ventana dentro de la aplicación.

El procedimiento Tk_NameToWindow devuelve el token de una ventana dado su nombre de ruta (el argumento pathName) y otra ventana perteneciente a la misma ventana principal (tkwin). Normalmente devuelve un token para la ventana nombrada, pero si no existe tal ventana, Tk_NameToWindow deja un mensaje de error en el resultado del intérprete interp y devuelve NULL. El argumento tkwin para Tk_NameToWindow es necesario porque los nombres de ruta solo son únicos dentro de una única jerarquía de aplicaciones. Si, por ejemplo, un único proceso ha abierto dos ventanas principales, cada una tendrá una jerarquía de nombres separada y el mismo nombre de ruta podría aparecer en cada una de las jerarquías. Normalmente, tkwin es la ventana principal de la jerarquía deseada, pero no tiene por qué ser así: se puede utilizar cualquier ventana de la jerarquía deseada.
