Paquete: perl-tk

TextUndo(3) Documentación de Perl aportada por el usuario TextUndo(3)

NOMBRE

Tk::TextUndo - widget de texto perl/tk con enlaces para deshacer cambios.

SINOPSIS

    use Tk::TextUndo;

    $deshacertexto = $padre->TextUndo(?-opción=>valor, ...?);

DESCRIPCIÓN

Este ES-UN widget de texto con un historial de 'deshacer' ilimitado pero sin capacidad de 'rehacer'.

Enlaces

El widget "TextUndo" tiene los mismos enlaces que el widget Text. Adicionalmente, tiene los siguientes enlaces:

Evento <L4> <<Undo>>
deshace el último cambio. Pulsar <L4> varias veces deshace paso a paso los cambios realizados en el widget de texto.

Métodos

El widget "TextUndo" tiene los mismos métodos que el widget "Text". Los métodos adicionales para el widget "TextUndo" son:

$texto->Cargar($nombrearchivo);
Carga el contenido del $nombrearchivo en el widget de texto. Cargar() elimina el contenido previo del widget de texto así como su historial de deshacer del archivo anterior.
$texto->Guardar(?$otro Nombredearchivo?)
Guarda el contenido del widget de texto en un archivo. Si no se especifica el $otro Nombredearchivo, el widget de texto escribe el contenido del archivo $nombrearchivo utilizado en la última llamada a Cargar(). Si no se había cargado ningún archivo previamente, aparece un mensaje de error. El nombre de archivo por defecto de la última llamada a Cargar() no se sobrescribe con $otro Nombredearchivo.
$texto->NombreArchivo(?$otro Nombredearchivo?)
Si se pasa un argumento, establece el nombre de archivo asociado con el documento cargado. Devuelve el nombre de archivo actual asociado con el documento.

TECLAS

widget, texto, deshacer

VER TAMBIÉN
