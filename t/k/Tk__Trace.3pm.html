Tk::Trace(3) Documentación de perl/Tk Tk::Trace(3)

NOMBRE

Tk::Trace - emular funciones de rastreo de Tcl/Tk.

SINOPSIS

use Tk::Trace
$mw->traceVariable(\$v, 'wru' => [\&update_meter, $scale]);
%vinfo = $mw->traceVinfo(\$v);
print "Información del rastreo:\n  ", join("\n  ", @{$vinfo{-legible}}), "\n";
$mw->traceVdelete(\$v);

DESCRIPCIÓN

Este módulo de clase emula la familia de comandos trace de Tcl/Tk vinculando subrutinas de su elección a variables de Perl usando las características simples de Tie::Watch.

El formato de la llamada de retorno sigue el esquema de Perl/Tk: proporcione una referencia de código o, proporcione una referencia de arreglo y pase la referencia de código de la llamada de retorno en el primer elemento del arreglo, seguido de los argumentos de la llamada de retorno.

Las llamadas de retorno de usuario reciben estos argumentos:

$_[0]        = undef para un escalar, índice/clave para arreglo/hash
$_[1]        = valor actual (lectura), nuevo (escritura), final (undef) de la variable
$_[2]        = operación (r, w, o u)
$_[3 .. $#_] = argumentos opcionales de la llamada de retorno del usuario

Como usuario de Trace, tiene una responsabilidad importante al escribir su llamada de retorno, ya que usted controla el valor final asignado a la variable. Una llamada de retorno típica podría verse así:

sub callback {
   my($index, $value, $op, @args) = @_;
   return if $op eq 'u';
   # .... código que usa $value ...
   return $value;     # valor final de la variable
}

Tenga en cuenta que el valor de retorno de la llamada de retorno se convierte en el valor final de la variable, tanto para rastreos de lectura como de escritura.

Para operaciones de escritura, la variable se actualiza con su nuevo valor antes de que se invoque la llamada de retorno.

Se pueden adjuntar múltiples llamadas de retorno de lectura, escritura y undef a una variable, las cuales se invocan en orden inverso a su creación.

MÉTODOS

$mw->traceVariable(varRef, op => callback);
varRef es una referencia a la variable escalar, de arreglo o de hash que desea rastrear. op es la operación de rastreo y puede ser cualquier combinación de r para lectura, w para escritura y u para undef. callback es una llamada de retorno estándar de Perl/Tk y se invoca, dependiendo del valor de op, cada vez que la variable se lee, escribe o destruye.
%vinfo = $mw->traceVinfo(varRef);
Devuelve un hash que detalla los internos del objeto Trace, con estas claves: 
%vinfo = (
    -variable =>  varRef
    -debug    =>  '0'
    -shadow   =>  '1'
    -value    =>  'HELLO SCALAR'
    -destroy  =>  callback
    -fetch    =>  callback
    -store    =>  callback
    -legible  =>  datos anteriores formateados como una lista de cadenas, para
                   imprimir
);

Para objetos Trace de arreglos y hashes, la clave -value se reemplaza por una clave -ptr que es una referencia al arreglo o hash paralelo. Además, para un arreglo o hash, hay pares clave/valor para todas las llamadas de retorno específicas de la variable.

$mw->traceVdelete(\$v);
Deja de rastrear la variable.

EJEMPLOS

# Rastrear la variable de un Scale y mover un medidor al unísono.
use Tk;
use Tk::widgets qw/Trace/;
$pi = 3.1415926;
$mw = MainWindow->new;
$c = $mw->Canvas( qw/-width 200 -height 110 -bd 2 -relief sunken/ )->grid;
$c->createLine( qw/100 100 10 100 -tag meter -arrow last -width 5/ );
$s = $mw->Scale( qw/-orient h -from 0 -to 100 -variable/ => \$v )->grid;
$mw->Label( -text => 'Deslízame durante 5 segundos' )->grid;
$mw->traceVariable( \$v, 'w' => [ \&update_meter, $s ] );
$mw->after( 5000 => sub {
    print "Tiempo de dejar de rastrear...\n";
    %vinfo = $s->traceVinfo( \$v );
    print "Información del rastreo:\n  ", join("\n  ", @{$vinfo{-legible}}), "\n";
    $c->traceVdelete( \$v );
});
MainLoop;
sub update_meter {
    my( $index, $value, $op, @args ) = @_;
    return if $op eq 'u';
    $min = $s->cget( -from );
    $max = $s->cget( -to );
    $pos = $value / abs( $max - $min );
    $x = 100.0 - 90.0 * ( cos( $pos * $pi ) );
    $y = 100.0 - 90.0 * ( sin( $pos * $pi ) );
    $c->coords( qw/meter 100 100/, $x, $y );
    return $value;
}
# Entrada de texto predictivo.
use Tk;
use Tk::widgets qw/ LabEntry Trace /;
use strict;
my @words =  qw/radio television telephone turntable microphone/;
my $mw = MainWindow->new;
my $e = $mw->LabEntry(
    qw/ -label Cosa -width 40 /,
    -labelPack    => [ qw/ -side left / ],
    -textvariable => \my $thing,
);
my $t = $mw->Text( qw/ -height 10 -width 50 / );;
$t->pack( $e, qw/ -side top / );
$e->focus;
$e->traceVariable( \$thing, 'w', [ \&trace_thing, $e, $t ] );
foreach my $k ( 1 .. 12 ) {
    $e->bind( "<F${k}>" => [ \&ins, $t, Ev('K') ] );
}
$e->bind( '<Return>' =>
          sub {
              print "$thing\n";
              $_[0]->delete( 0, 'end' );
          }
);
MainLoop;
sub trace_thing {
    my( $index, $value, $op, $e, $t ) = @_;
    return unless $value;
    $t->delete( qw/ 1.0 end / );
    foreach my $w ( @words ) {
        if ( $w =~ /^$value/ ) {
            $t->insert( 'end', "$w\n" );
        }
    }
    return $value;
} # end trace_thing
sub ins {
    my( $e, $t, $K ) = @_;
    my( $index ) = $K =~ /^F(\d+)$/;
    $e->delete( 0, 'end' );
    $e->insert( 'end', $t->get( "$index.0", "$index.0 lineend" ) );
    $t->delete( qw/ 1.0 end / );
} # end ins
