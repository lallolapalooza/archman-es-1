Tk_GetVisual(3) Procedimientos de la Biblioteca Tk Tk_GetVisual(3)

NOMBRE

Tk_GetVisual - traducir de cadena a visual

SINOPSIS

#include <tk.h>

Visual *
Tk_GetVisual(interp, tkwin, string, depthPtr, colormapPtr)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a utilizar para la notificación de errores.
Tk_Window tkwin (entrada)
Token de la ventana en la que se utilizará el visual.
const char *string (entrada)
Cadena que identifica el visual deseado. Ver abajo para formatos válidos.
int *depthPtr (salida)
La profundidad del visual devuelto se almacena aquí.
Colormap *colormapPtr (salida)
Si no es NULL, se encuentra un mapa de colores adecuado para el visual y su identificador se almacena aquí.

DESCRIPCIÓN

Tk_GetVisual toma una descripción en cadena de un visual y encuentra un X Visual adecuado para usar en tkwin, si existe alguno. Devuelve un puntero a la estructura X Visual del visual y almacena el número de bits por píxel en *depthPtr. Si string no es reconocible o si no se pudo encontrar ningún visual adecuado, devuelve NULL y Tk_GetVisual deja un mensaje de error en el resultado del intérprete interp. Si colormap no es NULL, Tk_GetVisual también localiza un mapa de colores apropiado para usar con el visual resultante y almacena su identificador X en *colormapPtr.

El argumento string especifica el visual deseado de una de las siguientes maneras:

clase profundidad
La cadena consiste en un nombre de clase seguido de un entero de profundidad, con cualquier cantidad de espacio en blanco (incluido ninguno) entre ellos. clase selecciona qué tipo de visual se desea y debe ser uno de directcolor, grayscale, greyscale, pseudocolor, staticcolor, staticgray, staticgrey, o truecolor, o una abreviatura única. profundidad especifica cuántos bits por píxel se necesitan para el visual. Si es posible, Tk_GetVisual devolverá un visual con esta profundidad; si no hay un visual de la profundidad deseada, Tk_GetVisual busca primero un visual con mayor profundidad, luego uno con menor profundidad.
predeterminado
Usa el visual predeterminado para la pantalla de tkwin.
nombreRuta
Usa el visual de la ventana dada por nombreRuta. nombreRuta debe ser el nombre de una ventana en la misma pantalla que tkwin.
número
Usa el visual cuyo identificador X es número.
mejor ?profundidad?
Elige el visual “mejor posible”, usando las siguientes reglas, en orden decreciente de prioridad:
(a)
un visual que tenga exactamente la profundidad deseada es mejor, seguido de un visual con mayor profundidad que la solicitada (pero lo menos posible adicional), seguido de un visual con menor profundidad que la solicitada (pero con la mayor profundidad posible);
(b)
si no se especifica ninguna profundidad, se elige el visual más profundo disponible;
(c)
pseudocolor es mejor que truecolor o directcolor, que son mejores que staticcolor, que es mejor que staticgray o grayscale;
(d)
el visual predeterminado para la pantalla es mejor que cualquier otro visual.

CRÉDITOS

La idea de Tk_GetVisual y la primera implementación provinieron de Paul Mackerras.
