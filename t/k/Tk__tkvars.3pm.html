NOMBRE

Tk::tkvars - Variables usadas o establecidas por Tk

DESCRIPCIÓN

Las siguientes variables de perl son establecidas o usadas por Tk en varios momentos de su ejecución. (Para una lista de variables usadas por perl ver perlvar.)

$Tk::library
Esta variable contiene el nombre del archivo de un directorio que contiene los módulos relacionados con Tk. Estos módulos incluyen un archivo de inicialización que normalmente se procesa cada vez que se inicia una aplicación Tk, además de otros archivos que contienen procedimientos que implementan comportamientos predeterminados para los widgets. El valor inicial de $Tk::library se establece cuando se añade Tk a un intérprete; esto se hace buscando un directorio llamado Tk en el directorio donde se encuentra el archivo Tk.pm, o el primer directorio Tk en @INC.

La variable de entorno TK_LIBRARY usada por Tcl/Tk no es soportada por perl/Tk. Por favor, use @INC para cambiar dónde se buscan los módulos.

Nota: esto es un remanente de Tcl. Con perl tiene más sentido usar @INC y %INC).

$Tk::patchLevel
Contiene un entero decimal que indica el nivel de parche actual de Tk. El nivel de parche se incrementa para cada nueva versión o parche, y identifica de forma única una versión oficial de Tk.

Nota: esto es un remanente de Tcl. Con perl tiene más sentido usar $Tk::VERSION descrito a continuación.

$Tk::strictMotif
Esta variable se establece a cero por defecto. Si una aplicación la establece a uno, entonces Tk intenta adherirse lo más posible a los estándares de apariencia de Motif. Por ejemplo, los elementos activos como los botones y los deslizadores de las barras de desplazamiento no cambiarán de color cuando pase el puntero sobre ellos.
$Tk::VERSION
La variable contiene el número de versión actual de la versión de perl/Tk en el formato principal.secundaria. Principal y secundaria son enteros.

El número de versión principal indica en qué versión de Tcl/Tk se basa perl/Tk. Por ejemplo, 402 significa que se basa en Tk 4.2 de Tcl. (Los niveles de parche de Tcl/Tk no se incorporan porque perl/Tk tendía a estar ``adelantado'' en algunas correcciones y detrás en otras. El primer dígito del número de versión principal aumenta en cualquier versión de Tk que incluya cambios que no sean retrocompatibles (es decir, cuando las aplicaciones y scripts de perl/Tk existentes puedan tener que cambiar para funcionar con la nueva versión)).

El número de versión secundaria depende solo de perl/Tk. Usa el esquema 'par'='estable', 'impar'='experimental' que usa linux:

.0xx  - intrínsecamente 'alfa'
.1xx  - 'beta' experimental
.2xx  - estable
.3xx  - experimental
.4xx  - estable
...

El número de versión secundaria aumenta con cada nueva versión de Tk, excepto que se reinicia a cero siempre que cambia el número de versión principal.

$Tk::version
La variable contiene el número de versión actual de la biblioteca Tk en el formato principal.secundaria. Principal y secundaria son enteros. El número de versión principal aumenta en cualquier versión de Tk que incluya cambios que no sean retrocompatibles (es decir, cuando las aplicaciones y scripts de Tk existentes puedan tener que cambiar para funcionar con la nueva versión). El número de versión secundaria aumenta con cada nueva versión de Tk, excepto que se reinicia a cero siempre que cambia el número de versión principal.

Nota: esto es un remanente de Tcl. Con perl tiene más sentido usar $Tk::VERSION descrito a continuación.
