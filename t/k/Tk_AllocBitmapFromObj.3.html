DESCRIPCIÓN

Estos procedimientos gestionan una colección de bitmaps (pixmaps de un solo plano) que están siendo utilizados por una aplicación. Los procedimientos permiten que los bitmaps se reutilicen de manera eficiente, evitando así la sobrecarga del servidor, y también permiten que los bitmaps se nombren con cadenas de caracteres.

Tk_AllocBitmapFromObj devuelve un identificador Pixmap para un bitmap que coincide con la descripción en objPtr y es adecuado para su uso en tkwin. Reutiliza un bitmap existente, si es posible, y crea uno nuevo en caso contrario. El valor de objPtr debe tener una de las siguientes formas:

@fileName
FileName debe ser el nombre de un archivo que contiene una descripción de bitmap en el formato estándar de X11.
name
Name debe ser el nombre de un bitmap definido previamente con una llamada a Tk_DefineBitmap. Los siguientes nombres están predefinidos por Tk:
error
El símbolo internacional “no”: un círculo con una línea diagonal a través de él.

Gris 75%: un patrón de tablero de ajedrez donde tres de cada cuatro bits están activados.
gray50
Gris 50%: un patrón de tablero de ajedrez donde cada segundo bit está activado.
gray25
Gris 25%: un patrón de tablero de ajedrez donde uno de cada cuatro bits está activado.
gray12
Gris 12.5%: un patrón donde un octavo de los bits están activados, consistente en cada cuarto píxel en cada otra fila.

Un símbolo de reloj de arena.

Una letra grande “i”.

En condiciones normales, Tk_AllocBitmapFromObj devuelve un identificador para el bitmap solicitado. Si ocurre un error al crear el bitmap, como cuando objPtr se refiere a un archivo inexistente, entonces se devuelve None y se deja un mensaje de error en el resultado de interp si interp no es NULL. Tk_AllocBitmapFromObj almacena en caché información sobre el valor de retorno en objPtr, lo que acelera las llamadas futuras a procedimientos como Tk_AllocBitmapFromObj y Tk_GetBitmapFromObj.

Tk_GetBitmap es idéntico a Tk_AllocBitmapFromObj excepto que la descripción del bitmap se especifica con una cadena en lugar de un objeto. Esto evita que Tk_GetBitmap almacene en caché el valor de retorno, por lo que Tk_GetBitmap es menos eficiente que Tk_AllocBitmapFromObj.

Tk_GetBitmapFromObj devuelve el token de un bitmap existente, dado la ventana y la descripción utilizadas para crear el bitmap. Tk_GetBitmapFromObj no crea realmente el bitmap; el bitmap ya debe haber sido creado con una llamada anterior a Tk_AllocBitmapFromObj o Tk_GetBitmap. El valor de retorno se almacena en caché en objPtr, lo que acelera las llamadas futuras a Tk_GetBitmapFromObj con el mismo objPtr y tkwin.

Tk_DefineBitmap asocia un nombre con datos de bitmap en memoria para que el nombre pueda usarse en llamadas posteriores a Tk_AllocBitmapFromObj o Tk_GetBitmap. El argumento nameId da un nombre al bitmap; no debe haber sido utilizado previamente en una llamada a Tk_DefineBitmap. Los argumentos source, width y height describen el bitmap. Tk_DefineBitmap normalmente devuelve TCL_OK; si ocurre un error (por ejemplo, ya se ha definido un bitmap llamado nameId) entonces se devuelve TCL_ERROR y se deja un mensaje de error en el resultado del intérprete interp. Nota: Tk_DefineBitmap espera que la memoria apuntada por source sea estática: Tk_DefineBitmap no hace una copia privada de esta memoria, sino que utiliza los bytes apuntados por source más adelante en llamadas a Tk_AllocBitmapFromObj o Tk_GetBitmap.

NOMBRE

Tk_AllocBitmapFromObj, Tk_GetBitmap, Tk_SizeOfBitmap, Tk_NameOfBitmap

SINOPSIS

Tk_AllocBitmapFromObj(interp, bitmap, name, bits, width, height)

Tk_GetBitmap(interp, tkwin, name)

Tk_NameOfBitmap(bitmap)

Tk_SizeOfBitmap(bitmap, widthPtr, heightPtr)

ARGUMENTOS

interp: intérprete

tkwin: ventana Tk

name: nombre del bitmap

bits: datos del bitmap

width: ancho del bitmap

height: alto del bitmap

bitmap: Pixmap

widthPtr: puntero al ancho

heightPtr: puntero al alto

DESCRIPCIÓN

Tk_AllocBitmapFromObj crea un nuevo bitmap a partir de los datos proporcionados. Tk_GetBitmap recupera un bitmap de la base de datos. Tk_NameOfBitmap devuelve el nombre utilizado para crear el bitmap. Tk_SizeOfBitmap devuelve las dimensiones del bitmap.

ERRORES

Tk_AllocBitmapFromObj y Tk_GetBitmap solo consideran el valor inmediato de la descripción de la cadena. Por ejemplo, cuando se pasa un nombre de archivo a Tk_GetBitmap, asume que es seguro reutilizar un bitmap existente creado a partir del mismo nombre de archivo, sin verificar si el archivo en sí ha cambiado o si el directorio actual ha cambiado.
