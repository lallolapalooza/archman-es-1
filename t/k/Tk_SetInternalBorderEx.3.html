Tk_GeometryRequest(3) Procedimientos de la biblioteca Tk Tk_GeometryRequest(3)

NOMBRE

Tk_GeometryRequest, Tk_SetMinimumRequestSize, Tk_SetInternalBorder, Tk_SetInternalBorderEx - especificar geometría deseada o borde interno para una ventana

SINOPSIS

#include <tk.h>

Tk_GeometryRequest(tkwin, reqWidth, reqHeight)

Tk_SetMinimumRequestSize(tkwin, minWidth, minHeight)

Tk_SetInternalBorder(tkwin, width)

Tk_SetInternalBorderEx(tkwin, left, right, top, bottom)

ARGUMENTOS

Tk_Window tkwin (entrada)
Ventana para la que se solicita la geometría.
int reqWidth (entrada)
Ancho deseado para tkwin, en unidades de píxel.
int reqHeight (entrada)
Alto deseado para tkwin, en unidades de píxel.
int minWidth (entrada)
Ancho mínimo deseado solicitado para tkwin, en unidades de píxel.
int minHeight (entrada)
Alto mínimo deseado solicitado para tkwin, en unidades de píxel.
int width (entrada)
Espacio a dejar para el borde interno de tkwin, en unidades de píxel.
int left (entrada)
Espacio a dejar para el lado izquierdo del borde interno de tkwin, en unidades de píxel.
int right (entrada)
Espacio a dejar para el lado derecho del borde interno de tkwin, en unidades de píxel.
int top (entrada)
Espacio a dejar para el lado superior del borde interno de tkwin, en unidades de píxel.
int bottom (entrada)
Espacio a dejar para el lado inferior del borde interno de tkwin, en unidades de píxel.

DESCRIPCIÓN

Tk_GeometryRequest es llamada por el código del widget para indicar su preferencia por las dimensiones de una ventana particular. Los argumentos de Tk_GeometryRequest se ponen a disposición del gestor de geometría para la ventana, que luego decide la geometría real de la ventana. Aunque los gestores de geometría generalmente intentan satisfacer las solicitudes hechas a Tk_GeometryRequest, no hay garantía de que esto siempre sea posible. El código del widget no debe asumir que una solicitud de geometría será satisfecha hasta que reciba un evento ConfigureNotify que indique que el cambio de geometría ha ocurrido. El código del widget nunca debe llamar a procedimientos como Tk_ResizeWindow directamente. En su lugar, debe invocar Tk_GeometryRequest y dejar las decisiones finales de geometría al gestor de geometría.

Si tkwin es una ventana de nivel superior, la información de geometría se pasará al gestor de ventanas utilizando el protocolo ICCCM estándar.

Tk_SetInternalBorder es llamada por el código del widget para indicar que el widget tiene un borde interno. Esto significa que el widget dibuja un borde decorativo dentro de la ventana en lugar de usar los bordes estándar de X, que están fuera del área de la ventana. Por ejemplo, los bordes internos se utilizan para dibujar efectos 3D. Width especifica el ancho del borde en píxeles. Los gestores de geometría utilizarán esta información para evitar colocar cualquier hijo de tkwin que se superponga con los width píxeles más externos del área de tkwin.

Tk_SetInternalBorderEx funciona como Tk_SetInternalBorder pero le permite especificar anchos diferentes para lados diferentes de la ventana.

Tk_SetMinimumRequestSize es llamada por el código del widget para indicar que un gestor de geometría debe solicitar al menos este tamaño para el widget. Esto permite a un widget tener cierto control sobre su tamaño cuando se utiliza un gestor de geometría que se propaga dentro de él.

La información especificada en las llamadas a Tk_GeometryRequest, Tk_SetMinimumRequestSize, Tk_SetInternalBorder y Tk_SetInternalBorderEx se puede recuperar utilizando las macros Tk_ReqWidth, Tk_ReqHeight, Tk_MinReqWidth, Tk_MinReqHeight, Tk_MinReqWidth, Tk_InternalBorderLeft, Tk_InternalBorderRight, Tk_InternalBorderTop y Tk_InternalBorderBottom. Ver la entrada del manual de Tk_WindowId para más detalles.
