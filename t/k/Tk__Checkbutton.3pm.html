NOMBRE

Tk::Checkbutton - Crea y manipula widgets Checkbutton

SINOPSIS

$checkbutton = $padre->Checkbutton(?opciones?);

OPCIONES ESTÁNDAR

-activebackground -activeforeground -anchor -background -bitmap -borderwidth -compound -cursor -disabledforeground -font -foreground -highlightbackground -highlightcolor -highlightthickness -image -justify -padx -pady -relief -takefocus -text -textvariable -underline -wraplength

Ver Tk::options para detalles de las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: command
Clase: Command
Interruptor: -command
Especifica una rutina de devolución de llamada de perl/Tk para asociar con el botón. Este comando se invoca típicamente cuando se suelta el botón 1 del ratón sobre la ventana del botón. La variable global del botón (opción -variable) se actualizará antes de invocar el comando.
Nombre: height
Clase: Height
Interruptor: -height
Especifica una altura deseada para el botón. Si se está mostrando una imagen o un bitmap en el botón, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, está en líneas de texto. Si no se especifica esta opción, la altura deseada del botón se calcula a partir del tamaño de la imagen, el bitmap o el texto que se muestra en él.
Nombre: indicatorOn
Clase: IndicatorOn
Interruptor: -indicatoron
Especifica si se debe dibujar o no el indicador. Debe ser un valor booleano correcto. Si es falso, la opción relief se ignora y el relief del widget es siempre hundido si el widget está seleccionado y levantado en caso contrario.
Nombre de línea de comandos: -offrelief
Nombre de base de datos: offRelief
Clase de base de datos: OffRelief
Especifica el relief para el checkbutton cuando el indicador no está dibujado y el checkbutton está desactivado. El valor por defecto es raised. Al establecer esta opción en flat y configurar -indicatoron false -overrelief raised, se logra el efecto de tener un botón plano que se levanta al pasar el ratón por encima y que se hunde cuando se activa. Este es el comportamiento que suelen exhibir los checkbuttons Negrita, Cursiva y Subrayado en la barra de herramientas de un procesador de textos, por ejemplo.
Nombre: offValue
Clase: Value
Interruptor: -offvalue
Especifica el valor a almacenar en la variable asociada al botón cada vez que este botón se deselecciona. Por defecto es ``0''.
Nombre: onValue
Clase: Value
Interruptor: -onvalue
Especifica el valor a almacenar en la variable asociada al botón cada vez que este botón se selecciona. Por defecto es ``1''.
Nombre de línea de comandos: -overrelief
Nombre de base de datos: overRelief
Clase de base de datos: OverRelief
Especifica un relief alternativo para el botón, que se utilizará cuando el cursor del ratón esté sobre el widget. Esta opción se puede utilizar para crear botones de barra de herramientas, configurando -relief flat -overrelief raised. Si el valor de esta opción es una cadena vacía, entonces no se utiliza ningún relief alternativo cuando el cursor del ratón está sobre el botón. La cadena vacía es el valor por defecto.
Nombre: selectColor
Clase: Background
Interruptor: -selectcolor
Especifica un color de fondo para usar cuando el botón está seleccionado. Si indicatorOn es verdadero, el color se aplica al indicador. En Windows, este color se usa como fondo del indicador independientemente del estado de selección. Si indicatorOn es falso, este color se usa como fondo para todo el widget, en lugar de background o activeBackground, siempre que el widget esté seleccionado. Si se especifica como una cadena vacía, no se usa ningún color especial para mostrar cuando el widget está seleccionado.
Nombre: selectImage
Clase: SelectImage
Interruptor: -selectimage
Especifica una imagen para mostrar (en lugar de la opción image) cuando el checkbutton está seleccionado. Esta opción se ignora a menos que se haya especificado la opción image.
Nombre: state
Clase: State
Interruptor: -state
Especifica uno de los tres estados para el checkbutton: normal, active o disabled. En estado normal, el checkbutton se muestra usando las opciones foreground y background. El estado activo se usa típicamente cuando el puntero está sobre el checkbutton. En estado activo, el checkbutton se muestra usando las opciones activeForeground y activeBackground. El estado deshabilitado significa que el checkbutton debe ser insensible: los bindings por defecto rechazarán la activación del widget e ignorarán las pulsaciones del botón del ratón. En este estado, las opciones disabledForeground y background determinan cómo se muestra el checkbutton.
Nombre: variable
Clase: Variable
Interruptor: -variable
Especifica una referencia a una variable para establecerla e indicar si este botón está seleccionado o no. Por defecto es el miembro "$widget->{'Value'}" del hash del widget. En general, las variables de perl están "undef" a menos que se inicialicen específicamente, lo que no coincidirá con el valor por defecto -onvalue ni con el valor por defecto -offvalue.
Nombre: width
Clase: Width
Interruptor: -width
Especifica un ancho deseado para el botón. Si se está mostrando una imagen o un bitmap en el botón, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto, está en caracteres. Si no se especifica esta opción, el ancho deseado del botón se calcula a partir del tamaño de la imagen, el bitmap o el texto que se muestra en él.

El método Checkbutton crea una nueva ventana (dada por el argumento $widget) y la convierte en un widget checkbutton. Opciones adicionales, descritas anteriormente, pueden ser especificadas en la línea de comandos o en la base de datos de opciones para configurar

NAME

Checkbutton — create and manipulate checkbutton widgets

SYNOPSIS

Checkbutton widget ?options?

Specifies the amount of padding between the checkbutton's indicator and its text/image/labelwidget. The value may be specified in any of the forms acceptable to Tk_ParseDistance. The default is 1.

Specifies the relief style for the checkbutton. This controls the appearance of the 3-D border. The value can be raised, sunken, flat, ridge, solid, or groove. The default is raised.
-selectcolor color
Specifies the color to use for the indicator when the checkbutton is selected. If this option is empty, the indicator is drawn using the button's normal background color (under X11) or with a check mark (under Windows). -selectimage image

Specifies the name of the Tk variable that is associated with the checkbutton. The checkbutton's selected/deselected state will be controlled by this variable. If this option is not set, the checkbutton's value is determined solely by mouse clicks. DESCRIPTION

The Checkbutton command creates a new window for a checkbutton widget with the name given by pathName and the integer index index in its parent, the -w option can be used to specify a window name other than the default. The Checkbutton command is an alias for the button command with the -type option set to checkbutton. It may be used to create child windows for checkbuttons, or to configure existing checkbutton widgets. The following is a description of the checkbutton widget itself.

A checkbutton is a widget that displays a textual string, bitmap or image and a square called an indicator. If text is displayed, it must all be in a single font, but it can occupy multiple lines on the screen (if it contains newlines or if wrapping occurs because of the wrapLength option) and one of the characters may optionally be underlined using the underline option. A checkbutton has all of the behavior of a simple button, including the following: it can display itself in either of three different ways, according to the state option; it can be made to appear raised, sunken, or flat; it can be made to flash; and it invokes a perl/Tk callback whenever mouse button 1 is clicked over the checkbutton.

In addition, checkbuttons can be selected. If a checkbutton is selected then the indicator is normally drawn with a selected appearance, and a Tcl variable associated with the checkbutton is set to a particular value (normally 1). Under Unix, the indicator is drawn with a sunken relief and a special color. Under Windows, the indicator is drawn with a check mark inside. If the checkbutton is not selected, then the indicator is drawn with a deselected appearance, and the associated variable is set to a different value (typically 0). Under Unix, the indicator is drawn with a raised relief and no special color. Under Windows, the indicator is drawn without a check mark inside. By default, the name of the variable associated with a checkbutton is the same as the name used to create the checkbutton. The variable name, and the ``on'' and ``off'' values stored in it, may be modified with options on the command line or in the option database. Configuration options may also be used to modify the way the indicator is displayed (or whether it is displayed at all). By default a checkbutton is configured to select and deselect itself on alternate button clicks. In addition, each checkbutton monitors its associated variable and automatically selects and deselects itself when the variables value changes to and from the button's ``on'' value.

WIDGET METHODS

The Checkbutton method creates a widget object. This object supports the configure and cget methods described in Tk::options which can be used to enquire and modify the options described above. The widget also inherits all the methods provided by the generic Tk::Widget class.

The following additional methods are available for checkbutton widgets:

$checkbutton->deselect
Deselects the checkbutton and sets the associated variable to its ``off'' value.
$checkbutton->flash
Flashes the checkbutton. This is accomplished by redisplaying the checkbutton several times, alternating between active and normal colors. At the end of the flash the checkbutton is left in the same normal/active state as when the command was invoked. This command is ignored if the checkbutton's state is disabled.
$checkbutton->invoke
Does just what would have happened if the user invoked the checkbutton with the mouse: toggle the selection state of the button and invoke the perl/Tk callback associated with the checkbutton, if there is one. The return value is the return value from the perl/Tk callback, or an empty string if there is no command associated with the checkbutton. This command is ignored if the checkbutton's state is disabled.
$checkbutton->select
Selects the checkbutton and sets the associated variable to its ``on'' value.
$checkbutton->toggle
Toggles the selection state of the button, redisplaying it and modifying its associated variable to reflect the new state.

BINDINGS

Tk automatically creates class bindings for checkbuttons that give them the following default behavior:

[1]
On Unix systems, a checkbutton activates whenever the mouse passes over it and deactivates whenever the mouse leaves the checkbutton. On Mac and Windows systems, when mouse button 1 is pressed over a checkbutton, the button activates whenever the mouse pointer is inside the button, and deactivates whenever the mouse pointer leaves the button.
[2]
When mouse button 1 is pressed over a checkbutton, it is invoked (its selection state toggles and the command associated with the button is invoked, if there is one).
[3]
When a checkbutton has the input focus, the space key causes the checkbutton to be invoked. Under Windows, there are additional key bindings; plus (+) and equal (=) select the button, and minus (-) deselects the button.

If the checkbutton's state is disabled then none of the above actions occur: the checkbutton is completely non-responsive.

The behavior of checkbuttons can be changed by defining new bindings for individual widgets or by redefining the class bindings.
