NOMBRE

Tk::Entry - Crear y manipular widgets de tipo Entry

SINTAXIS

    $entry = $parent->Entry(?options?);

OPCIONES ESTÁNDAR

-background -highlightbackground -insertontime -selectforeground -borderwidth -highlightcolor -insertwidth -takefocus -cursor -highlightthickness -justify -textvariable -exportselection -insertbackground -relief -xscrollcommand -font -insertborderwidth -selectbackground -foreground -insertofftime -selectborderwidth

OPCIONES DEL WIDGET

Nombre de la línea de comandos: -disabledbackground
Nombre de la base de datos: disabledBackground
Clase de base de datos: DisabledBackground
Es el color de fondo que se usa cuando el entry está desactivado. Si esta opción está vacía, se usa el color de fondo normal.
Nombre de la línea de comandos: -disabledforeground
Nombre de la base de datos: disabledForeground
Clase de base de datos: DisabledForeground
Es el color de texto que se usa cuando el entry está desactivado. Si esta opción está vacía, se usa el color de texto normal.
Nombre: invalidCommand
Clase: InvalidCommand
Switch: -invalidcommand
Alias: -invcmd
Es un script que se evalúa cuando validateCommand devuelve 0. Establecerlo a "undef" desactiva esta función (por defecto). La mejor utilización de esta opción es establecerlo a bell. Ver Validación para más información.
Nombre de la línea de comandos: -readonlybackground
Nombre de la base de datos: readonlyBackground
Clase de base de datos: ReadonlyBackground
Es el color de fondo que se usa cuando el entry está en modo read-only. Si esta opción está vacía, se usa el color de fondo normal.
Nombre: show
Clase: Show
Switch: -show
Si esta opción está especificada, los contenidos reales del entry no se muestran en la ventana. En su lugar, cada carácter en el valor del entry se muestra como el primer carácter del valor de esta opción, como ``*''. Esto es útil, por ejemplo, si el entry se usa para introducir una contraseña. Si los caracteres en el entry están seleccionados y copiados en otro lugar, el contenido copiado será lo que se muestra, no los contenidos reales del entry.
Nombre: state
Clase: State
Switch: -state
Es uno de los tres estados posibles para el entry: normal, disabled o readonly. Si el entry está en readonly, no se puede cambiar su valor usando comandos del widget y no se mostrará un cursor de inserción, incluso si el foco está en el widget; el contenido del widget puede aún ser seleccionado. Si el entry está en disabled, no se puede cambiar su valor, no se mostrará un cursor de inserción, el contenido no será seleccionable y el entry puede mostrarse en un color diferente, dependiendo de los valores de las opciones -disabledforeground y -disabledbackground。
Nombre: validate
Clase: Validate
Switch: -validate
Es el modo en el que se debe operar la validación: none, focus, focusin, focusout, key o all. Por defecto, es none. Cuando deseas la validación, debes especificar explícitamente el modo que deseas usar. Ver Validación para más información.
Nombre: validateCommand
Clase: ValidateCommand
Switch: -validatecommand
Alias: -vcmd
Es un script que se evalúa cuando deseas validar la entrada en el widget de entry. Establecerlo a "undef" desactiva esta funcionalidad (por defecto). Este comando debe devolver un valor booleano válido. Si devuelve 0 (o el equivalente booleano válido), significa que rechazas la edición y no ocurrirá, y la invalidCommand se evaluará si está establecido. Si devuelve 1, entonces la edición ocurre. Ver Validación para más información.
Nombre: width
Clase: Width
Switch: -width
Es un valor entero que especifica el ancho deseado de la ventana del entry, en caracteres de tamaño medio del fuente del widget. Si el valor es menor o igual a cero, el widget elige un tamaño tan grande como para contener su texto actual.

DESCRIPCIÓN

El método Entry crea un nuevo widget (dado por el argumento $entry) y lo convierte en un widget de tipo entry. Otras opciones, descritas arriba, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos como el color, el fuente y el relieve del entry. El método entry devuelve su argumento $entry. Al invocar este método, no debe existir un widget con nombre $entry, pero el padre de $entry debe existir.

Un entry es un widget que muestra una cadena de texto de una línea y permite editar esa cadena mediante métodos descritos a continuación, que generalmente están asociados a teclas y acciones del ratón. Cuando se crea por primera vez, la cadena del entry es vacía. Una parte de la cadena del entry puede ser seleccionada, como se describe a continuación. Si el entry está exportando su selección (ver opción exportSelection), entonces el entry observará los protocolos estándar de X11 para manejar la selección; las selecciones de entry están disponibles como tipo STRING. Los entry también observan las reglas estándar de Tk para manejar el foco de entrada. Cuando el entry tiene el foco de entrada, se muestra un cursor de inserción para indicar dónde se insertarán nuevos caracteres.

Los entry pueden mostrar cadenas de texto demasiado largas para caber completamente en la ventana del widget. En este caso, solo se mostrará una parte de la cadena; se pueden usar los métodos descritos a continuación para cambiar la vista en la ventana. Los entry usan el mecanismo estándar xScrollCommand para interactuar con las barras de desplazamiento (ver la descripción de la opción -xscrollcommand para más detalles). También soportan la búsqueda, como se describe a continuación.

VALIDACIÓN

La validación de widgets de entry se deriva de parte del parche escrito por jhobbs@cs.uoregon.edu. Esto funciona estableciendo la opción validateCommand a un callback que se evaluará según el modo de validación especificado por la opción validate siguiente:

none

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

none
Por defecto. Esto significa que no se realizará ninguna validación.
focus
Se llamará a validateCommand cuando la entrada reciba o pierda el foco.
focusin
Se llamará a validateCommand cuando la entrada reciba el foco.
focusout
Se llamará a validateCommand cuando la entrada pierda el foco.
key
Se llamará a validateCommand cuando la entrada sea editada.
all
Se llamará a validateCommand para todas las condiciones anteriores.

Se llama a validateCommand y invalidCommand con los siguientes argumentos:

  • El valor propuesto para la entrada. Si está configurando el widget de entrada para que tenga una nueva textvariable, este será el valor de esa textvariable.
  • Los caracteres que se agregarán (o eliminarán). Será "undef" si la validación se debe al foco, a una llamada explícita a validate o si el cambio se debe a que "-textvariable" cambia.
  • El valor actual de la entrada, es decir, antes del cambio propuesto.
  • El índice de la cadena de caracteres que se va a agregar/eliminar, si corresponde. -1 en caso contrario.
  • El tipo de acción. 1 == INSERTAR, 0 == ELIMINAR, -1 si es una validación forzada o validación de textvariable.

En general, textVariable y validateCommand pueden ser peligrosos de mezclar. Si intenta establecer la textVariable a algo que el validateCommand no aceptará, se restablecerá al valor del widget de entrada. Usar la textVariable para fines de solo lectura nunca causará problemas.

El validateCommand se desactivará automáticamente estableciendo validate a none cuando ocurra un error, por ejemplo, cuando validateCommand o invalidCommand encuentren un error en su script durante la evaluación, o validateCommand no devuelva un valor booleano válido.

Con la versión perl/Tk, se supone que la opción validate se "suspende" mientras se ejecuta validateCommand o invalidCommand. Esto es experimental, pero en teoría, cualquiera de las devoluciones de llamada puede "corregir" el valor del widget y anular el cambio propuesto. (validateCommand aún debería devolver falso para evitar que el cambio ocurra cuando devuelve).

MÉTODOS DEL WIDGET

El método Entry crea un objeto widget. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

Muchos de los métodos adicionales para las entradas toman uno o más índices como argumentos. Un índice especifica un carácter particular en la cadena de la entrada, de cualquiera de las siguientes maneras:

número
Especifica el carácter como un índice numérico, donde 0 corresponde al primer carácter de la cadena.
anchor
Indica el punto de anclaje para la selección, que se establece con los métodos selectionFrom y selectionAdjust.
end
Indica el carácter justo después del último de la cadena de la entrada. Esto equivale a especificar un índice numérico igual a la longitud de la cadena de la entrada.
insert
Indica el carácter adyacente e inmediatamente posterior al cursor de inserción.
sel.first
Indica el primer carácter de la selección. Es un error usar esta forma si la selección no está en la ventana de entrada.
sel.last
Indica el carácter justo después del último de la selección. Es un error usar esta forma si la selección no está en la ventana de entrada.
@número
En esta forma, número se trata como una coordenada x en la ventana de la entrada; se utiliza el carácter que abarca esa coordenada x. Por ejemplo, ``@0'' indica el carácter más a la izquierda de la ventana.

Se pueden usar abreviaturas para cualquiera de las formas anteriores, por ejemplo, ``e'' o ``sel.f''. En general, los índices fuera de rango se redondean automáticamente al valor legal más cercano.

Los siguientes métodos adicionales están disponibles para los widgets de entrada:

$entry->bbox(índice)
Devuelve una lista de cuatro números que describen el cuadro delimitador del carácter dado por índice. Los dos primeros elementos de la lista proporcionan las coordenadas x e y de la esquina superior izquierda del área de pantalla cubierta por el carácter (en píxeles en relación con el widget) y los dos últimos elementos proporcionan el ancho y la altura del carácter, en píxeles. El cuadro delimitador puede referirse a un área fuera del área visible de la ventana.
$entry->cget(?opción?)
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando entry.
$entry->configure(?opción?, ?valor, opción, valor, ...?)
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para $entry (consulte Tk::configure para obtener información sobre el formato de esta lista). Si se especifica opción sin valor, el comando devuelve una lista que describe la opción con nombre (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica opción). Si se especifican uno o más pares opción-valor, el comando modifica la(s) opción(es) del widget dada(s) para que tengan el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando entry.
$entry->delete(first, ?last?)
Elimina uno o más elementos de la entrada. first es el índice del primer carácter a eliminar, y last es el índice del carácter justo después del último a eliminar. Si no se especifica last, se devuelve a first+1, es decir, se elimina un solo carácter. Este método devuelve una cadena vacía.
$entry->get
Devuelve la cadena de la entrada.
$entry->icursor(índice)
Organiza la visualización del cursor de inserción justo antes del carácter dado por índice. Devuelve una cadena vacía.
$entry->index(índice)
Devuelve el índice numérico correspondiente a índice.
$entry->insert(índice, cadena)
Inserta los caracteres de cadena justo antes del carácter indicado por índice. Devuelve una cadena vacía.
$entry->scan(opción, args)
$entry->scanOpción(args)
Este método se utiliza para implementar el escaneo en las entradas. Tiene dos formas, dependiendo de Opción:
$entry->scanMark(x)
Registra x y la vista actual en el widget de entrada; se utiliza en conjunción con los métodos posteriores scanDragto. Típicamente, este método está asociado con la pulsación de un botón del ratón en el widget. Devuelve una cadena vacía.
$entry->scanDragto(x)
Este método calcula la diferencia entre su argumento x y el argumento x del último método scanMark para el widget. Luego ajusta la vista hacia la izquierda o hacia la derecha en 10 veces la diferencia en las coordenadas x. Este método se asocia típicamente con eventos de movimiento del ratón en el widget, para producir el efecto de arrastrar la entrada a alta velocidad por el widget. El valor de retorno es una cadena vacía.
$entry->selection(opción, arg)
$entry->selectionOpción(arg)
Este método se utiliza para ajustar la selección dentro de una entrada. Tiene varias formas, dependiendo de Opción:
$entry->selectionAdjust(índice)
Localiza el extremo de la selección más cercano al carácter dado por índice, y ajusta ese extremo de la selección a índice (es decir, incluyendo pero sin pasar de índice). El otro extremo de la selección se convierte en el punto de anclaje para los métodos selectionTo posteriores. Si la selección no está actualmente en la entrada, se crea una nueva selección para incluir los caracteres entre índice y el punto de anclaje de selección más reciente, inclusive. Devuelve una cadena vacía.
$entry->selectionClear
Borra la selección si está actualmente en este widget. Si la selección no está en este widget, el método no tiene ningún efecto. Devuelve una cadena vacía.
$entry->selectionFrom(índice)
Establece el punto de anclaje de la selección justo antes del carácter dado por índice. No cambia la selección. Devuelve una cadena vacía.
$entry->selectionPresent
Devuelve 1 si hay caracteres seleccionados en la entrada, 0 si no hay nada seleccionado.
$entry->selectionRange(inicio, fin)
Establece la selección para incluir los caracteres que comienzan con el índice por inicio y terminan con el anterior a fin. Si fin se refiere al mismo carácter que inicio o a uno anterior, se borrará la selección de la entrada.
$entry->selectionTo(índice)
Si índice está antes del punto de anclaje, establece la selección para los caracteres desde índice hasta, pero sin incluir, el punto de anclaje. Si índice es el mismo que el punto de anclaje, no hace nada. Si índice está después del punto de anclaje, establece la selección para los caracteres desde el punto de anclaje hasta, pero sin incluir, índice. El punto de anclaje se determina por el método más reciente selectionFrom o selectionAdjust en este widget. Si la selección no está en este widget, se crea una nueva selección usando el punto de anclaje más reciente especificado para el widget. Devuelve una cadena vacía.

MÉTODOS DEL WIDGET

$entry->validate
Este comando se utiliza para forzar una evaluación del comando validateCommand independientemente de las condiciones especificadas por la opción validate. Devuelve 0 o 1.
$entry->xview(args)
Este comando se utiliza para consultar y cambiar la posición horizontal del texto en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
$entry->xview
Devuelve una lista que contiene dos elementos. Cada elemento es una fracción real entre 0 y 1; juntos describen el tramo horizontal que es visible en la ventana. Por ejemplo, si el primer elemento es .2 y el segundo es .7, el 20% del texto de la entrada está fuera de pantalla a la izquierda, el 50% medio es visible en la ventana y el 30% del texto está fuera de pantalla a la derecha. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -xscrollcommand.
$entry->xview(index)
Ajusta la vista en la ventana para que el carácter dado por index se muestre en el borde izquierdo de la ventana.
$entry->xviewMoveto(fraction)
Ajusta la vista en la ventana para que el carácter que se encuentra a fraction del texto aparezca en el borde izquierdo de la ventana. Fraction debe ser una fracción entre 0 y 1.
$entry->xviewScroll(number, what)
Este método desplaza la vista en la ventana hacia la izquierda o hacia la derecha según number y what. Number debe ser un entero. What debe ser units o pages o una abreviatura de uno de estos. Si what es units, la vista se ajusta hacia la izquierda o la derecha en number caracteres de ancho promedio en la pantalla; si es pages, la vista se ajusta en number pantallas completas. Si number es negativo, se hacen visibles caracteres más a la izquierda; si es positivo, se hacen visibles caracteres más a la derecha.

ACCIONES PREDETERMINADAS

Tk crea automáticamente enlaces de clase para las entradas que les dan el siguiente comportamiento predeterminado. En las descripciones a continuación, "palabra" se refiere a un grupo contiguo de letras, dígitos o caracteres "_", o cualquier carácter individual que no sea estos.

[1]
Hacer clic en el botón del ratón 1 posiciona el cursor de inserción justo antes del carácter debajo del cursor del ratón, establece el foco de entrada en este widget y borra cualquier selección en el widget. Arrastrar con el botón del ratón 1 marca una selección entre el cursor de inserción y el carácter debajo del ratón.
[2]
Hacer doble clic con el botón del ratón 1 selecciona la palabra debajo del ratón y posiciona el cursor de inserción al principio de la palabra. Arrastrar después de un doble clic marcará una selección que consiste en palabras completas.
[3]
Hacer triple clic con el botón del ratón 1 selecciona todo el texto en la entrada y posiciona el cursor de inserción antes del primer carácter.
[4]
Los extremos de la selección se pueden ajustar arrastrando con el botón del ratón 1 mientras se mantiene presionada la tecla Shift; esto ajustará el extremo de la selección que estaba más cerca del cursor del ratón cuando se presionó el botón 1. Si se hace doble clic en el botón antes de arrastrar, la selección se ajustará en unidades de palabras completas.
[5]
Hacer clic en el botón del ratón 1 con la tecla Control presionada posicionará el cursor de inserción en la entrada sin afectar la selección.
[6]
Si se escriben caracteres de impresión normales en una entrada, se insertan en el punto del cursor de inserción.
[7]
La vista en la entrada se puede ajustar arrastrando con el botón del ratón 2. Si se hace clic en el botón del ratón 2 sin mover el ratón, la selección se copia en la entrada en la posición del cursor del ratón.
[8]
Si el ratón se saca de la entrada por los lados izquierdo o derecho mientras se presiona el botón 1, la entrada se desplazará automáticamente para hacer más texto visible (si hay más texto fuera de pantalla en el lado donde el ratón salió de la ventana).
[9]
Las teclas Izquierda y Derecha mueven el cursor de inserción un carácter hacia la izquierda o la derecha; también borran cualquier selección en la entrada y establecen el ancla de selección. Si se presiona Izquierda o Derecha con la tecla Shift presionada, el cursor de inserción se mueve y la selección se extiende para incluir el nuevo carácter. Control-Izquierda y Control-Derecha mueven el cursor de inserción por palabras, y Control-Shift-Izquierda y Control-Shift-Derecha mueven el cursor de inserción por palabras y también extienden la selección. Control-b y Control-f se comportan igual que Izquierda y Derecha, respectivamente. Meta-b y Meta-f se comportan igual que Control-Izquierda y Control-Derecha, respectivamente.
[10]
La tecla Inicio, o Control-a, moverá el cursor de inserción al principio de la entrada y borrará cualquier selección en la entrada. Shift-Inicio mueve el cursor de inserción al principio de la entrada y también extiende la selección hasta ese punto.
[11]
La tecla Fin, o Control-e, moverá el cursor de inserción al final de la entrada y borrará cualquier selección en la entrada. Shift-Fin mueve el cursor al final y extiende la selección hasta ese punto.
[12]
La tecla Seleccionar y Control-Espacio establecen el ancla de selección en la posición del cursor de inserción. No afectan la selección actual. Shift-Seleccionar y Control-Shift-Espacio ajustan la selección a la posición actual del cursor de inserción, seleccionando desde el ancla hasta el cursor de inserción si no había ninguna selección previamente.
[13]
Control-/ selecciona todo el texto en la entrada.
[14]
Control-\ borra cualquier selección en la entrada.
[15]
La tecla F16 (etiquetada como Copiar en muchas estaciones de trabajo Sun) o Meta-w copia la selección en el widget al portapapeles, si hay una selección.
[16]
La tecla F20 (etiquetada como Cortar en muchas estaciones de trabajo Sun) o Control-w copia la selección en el widget al portapapeles y elimina la selección. Si no hay selección en el widget, estas teclas no tienen efecto.
[17]
La tecla F18 (etiquetada como Pegar en muchas estaciones de trabajo Sun) o Control-y inserta el contenido del portapapeles en la posición del cursor de inserción.
[18]
La tecla Suprimir elimina la selección, si hay una en la entrada. Si no hay selección, elimina el carácter a la derecha del cursor de inserción.
[19]
La tecla Retroceso y Control-h eliminan la selección, si hay una en la entrada. Si no hay selección, elimina el carácter a la izquierda del cursor de inserción.
[20]
Control-d elimina el carácter a la derecha del cursor de inserción.
[21]
Meta-d elimina la palabra a la derecha del cursor de inserción.
[22]
Control-k elimina todos los caracteres a la derecha del cursor de inserción.
[23]
Control-t invierte el orden de los dos caracteres a la derecha del cursor de inserción.

Si la entrada está deshabilitada usando la opción -state, entonces la vista de la entrada aún se puede ajustar y el texto en la entrada aún se puede seleccionar, pero no se mostrará ningún cursor de inserción y no se realizarán modificaciones de texto.

El comportamiento de las entradas se puede cambiar definiendo nuevos enlaces para widgets individuales o redefiniendo los enlaces de clase.
