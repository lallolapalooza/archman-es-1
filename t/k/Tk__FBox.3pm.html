Paquete: perl-tk

Licencias: PerlArtistic, GPL, custom

FBox(3) Documentación de Perl contribuida por el usuario FBox(3)

NOMBRE

Tk::FBox - un diálogo de archivos

SINOPSIS

use Tk::FBox;
$file = $mw->FBox(...)->Show;

DESCRIPCIÓN

"Tk::FBox" es la implementación del diálogo detrás de las llamadas a los métodos "getOpenFile", "getSaveFile" y "chooseDirectory" en el mundo Unix/X11. Como tal, soporta todas las opciones para estos métodos y además:

-sortcmd => sub { $_[0] cmp $_[1] }
Especifica una rutina de devolución de llamada para cambiar la ordenación de los iconos en el widget "IconList". Por defecto, se utilizará el operador "cmp" de Perl.

Del código fuente:

# Usar -sortcmd es realmente extraño :-(
# $top->getOpenFile(-sortcmd => sub { package Tk::FBox; uc $b cmp uc $a});
# o, poco perlesco, pero utilizable (ahora activado en el código):
# $top->getOpenFile(-sortcmd => sub { uc $_[1] cmp uc $_[0]});

¡Esta es una opción experimental!

-type => $type
El tipo debe ser "open" para elegir archivos existentes para abrir (por defecto), "save" para elegir archivos existentes o no existentes para guardar, o "dir" para elegir directorios.
-filter => $glob
Un glob de archivos para restringir los archivos mostrados. Esto solo está activo si no se definen -filetypes.
-force => $bool
Si es verdadero, no habrá diálogo si un archivo ya existe.
