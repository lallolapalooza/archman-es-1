IconList(3) Documentación de Perl aportada por el usuario IconList(3)

NOMBRE

Tk::IconList - un widget de lista de iconos

SINOPSIS

use Tk::IconList;
$il = $mw->IconList(-browsecmd => sub { ... },
                    -command   => sub { ... })->pack;
$il->Add($icon1, $text1);
$il->Add($icon2, $text2);
$il->Arrange;
...
$il->DeleteAll;

DESCRIPCIÓN

OPCIONES

-browsecmd
-command
-font
-item -foreground|-fg

MÉTODOS

DeleteAll
Elimina todos los elementos dentro del subwidget canvas y restablece el estado de IconList.
Add($image, $text)
Añade un icono a IconList con la imagen y el texto designados.
Arrange
Coloca los iconos en una disposición por columnas.
Get
Devuelve el elemento seleccionado.
Invoke
Se llama cuando el usuario invoca IconList (generalmente haciendo doble clic o presionando la tecla Enter) (método interno).
See($tag)
Si el elemento no es (completamente) visible, desplaza el lienzo para que sea visible (método interno).
