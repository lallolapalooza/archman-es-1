Tk__X11Font(3pm)

Paquete: perl-tk

Licencias: PerlArtistic, GPL, custom

X11Font(3) Documentación de Perl contribuida por el usuario X11Font(3)

NOMBRE

Tk::Font - una clase para encontrar fuentes X11

SINOPSIS

use Tk::X11Font;
$font = $widget->X11Font(foundry => 'adobe',
                      family  => 'times',
                      point   => 120
                     );
$font = $widget->X11Font('*-courier-medium-r-normal-*-*');

DESCRIPCIÓN

Este módulo puede ser usado para interrogar al servidor X sobre las fuentes
disponibles.

Establece el campo dado en el nombre de la fuente a $val si se proporciona y devuelve el valor actual o anterior.

Name( [ $max ] )

En un contexto de lista, devuelve una lista de todos los nombres de fuente que coinciden con los campos proporcionados. Devolverá un máximo de $max nombres, o 128 si no se proporciona $max.

En un contexto escalar, devuelve el primer nombre coincidente o undef.

Clone( [ key => value, [ ...]] )

Crea un duplicado del objeto de fuente actual y modifica los campos proporcionados.
