Tk_NameOfJoinStyle(3)

Paquete: tk

Tk_GetJoinStyle(3) Procedimientos de la biblioteca Tk Tk_GetJoinStyle(3)

NOMBRE

Tk_GetJoinStyle, Tk_NameOfJoinStyle - traducir entre cadenas y estilos de unión

SINOPSIS

#include <tk.h>

int
Tk_GetJoinStyle(interp, string, joinPtr)

const char *
Tk_NameOfJoinStyle(join)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a utilizar para reportar errores.
const char *string (entrada)
Cadena que contiene el nombre del estilo de unión - uno de “bevel”, “miter”, o “round” - o una abreviatura única de uno de ellos.
int *joinPtr (salida)
Puntero a la ubicación donde se almacenará el estilo de unión X correspondiente a string.
int join (entrada)
Estilo de unión: uno de JoinBevel, JoinMiter, JoinRound.

DESCRIPCIÓN

Tk_GetJoinStyle coloca en *joinPtr el estilo de unión X correspondiente a string, que será uno de JoinBevel, JoinMiter, o JoinRound. Los estilos de unión se usan típicamente en contextos gráficos X para indicar cómo deben unirse los segmentos de línea adyacentes. Consulte la documentación de X para obtener información sobre lo que implica cada estilo.

En circunstancias normales, el valor de retorno es TCL_OK y interp no se utiliza. Si string no contiene un estilo de unión válido o una abreviatura de uno de estos nombres, entonces se almacena un mensaje de error en el resultado del intérprete interp, se devuelve TCL_ERROR y *joinPtr no se modifica.

Tk_NameOfJoinStyle es la inversa lógica de Tk_GetJoinStyle. Dada una estilo de unión como JoinBevel, devuelve una cadena asignada estáticamente correspondiente a join. Si join no es un estilo de unión legal, entonces se devuelve “unknown join style”.

PALABRAS CLAVE

bisel, estilo de unión, inglete, redondo
