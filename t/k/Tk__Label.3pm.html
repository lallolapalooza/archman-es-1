NOMBRE

Tk::Label - Crear y manipular widgets Label

SINOPSIS

$etiqueta = $padre->Label(?opciones?);

OPCIONES ESTÁNDAR

-activebackground -activeforeground -anchor -background -bitmap -borderwidth -compound -cursor -disabledforeground -font -foreground -highlightbackground -highlightcolor -highlightthickness -image -justify -padx -pady -relief -takefocus -text -textvariable -underline -wraplength

Ver Tk::options para detalles de las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: height
Clase: Height
Cambio: -height
Especifica una altura deseada para la etiqueta. Si se está mostrando una imagen o bitmap en la etiqueta, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto está en líneas de texto. Si no se especifica esta opción, la altura deseada de la etiqueta se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en ella.
Nombre: state
Clase: State
Cambio: -state
Especifica uno de los tres estados para la etiqueta: normal, active o disabled. En el estado normal, la etiqueta se muestra utilizando las opciones foreground y background. En el estado activo, la etiqueta se muestra utilizando las opciones activeForeground y activeBackground. En el estado deshabilitado, las opciones disabledForeground y background determinan cómo se muestra el botón.
Nombre: width
Clase: Width
Cambio: -width
Especifica un ancho deseado para la etiqueta. Si se está mostrando una imagen o bitmap en la etiqueta, el valor está en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels); para texto está en caracteres. Si no se especifica esta opción, el ancho deseado de la etiqueta se calcula a partir del tamaño de la imagen o bitmap o texto que se muestra en ella.

DESCRIPCIÓN

El método Label crea una nueva ventana (proporcionada por el argumento $widget) y la convierte en un widget de etiqueta. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos de la etiqueta, como sus colores, fuente, texto y relieve inicial. El comando label devuelve su argumento $widget. En el momento en que se invoca este comando, no debe existir una ventana llamada $widget, pero el padre de $widget debe existir.

Una etiqueta es un widget que muestra una cadena de texto, un bitmap o una imagen. Si se muestra texto, todo debe estar en una sola fuente, pero puede ocupar varias líneas en la pantalla (si contiene saltos de línea o si se produce un ajuste de línea debido a la opción wrapLength) y uno de los caracteres puede subrayarse opcionalmente usando la opción underline. La etiqueta se puede manipular de algunas maneras sencillas, como cambiar su relieve o texto, utilizando los comandos descritos a continuación.

MÉTODOS DEL WIDGET

El método Label crea un objeto widget. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

VINCULACIONES

Cuando se crea una nueva etiqueta, no tiene vinculaciones de eventos predeterminadas: las etiquetas no están pensadas para ser interactivas.
