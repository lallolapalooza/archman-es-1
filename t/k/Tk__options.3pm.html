NAME

Tk::options - Standard options supported by widgets and their manipulation

SYNOPSIS

    $value = $widget->cget('-option');

    $widget->configure(-option=>value ?,-option=>value ...?);

    @list = $widget->configure('-option');

    @lol = $widget->configure;

DESCRIPTION

All widgets, and images have a standard mechanism for setting and querying attibutes or options. The mechanism is based on two methods configure and cget. The behaviour of these methods is as follows:

$widget->configure(-option=>value ?,-option=>value ...?);
Sets the values of -option to value for each -option=>value pair. The internal new method does an implicit configure in this form with options passed in at widget create time.
$widget->configure('-option')
In array context returns a list of five or two elements. If -option is an alias for another options it return a list consisting of the alias option and the name for the option is is an alias for, e.g., "('-bg', 'background')". If -option is not an alias the returned list has the following five elements:
Option Name
The value of -option, e.g., -background.
Name
The option's name in the option database, e.g., "background".
Class
The option's class value in the option database, e.g., "Background".
Default
The default value for the option if not specified or in the option database, e.g., "grey".
Value
The current value (as returned by cget), e.g., "white".
$widget->configure
Returns a list of lists for all the options supported by $widget. Each sub-list is in the form returned by configure('-option'). (This mechanism is used by the Tk::Derived class to determine the options available from base class.)
$widget->cget('-option')
Returns the current value of -option for $widget.

cget('-option') is clumsy with the need for '' due to perl's parsing rules. Something more subtle using tie might look better.

The following paragraphs describe the common configuration options supported by widgets in the Tk toolkit. Every widget does not necessarily support every option (see the the documentation entries for individual widgets for a list of the standard options supported by that widget), but if a widget does support an option with one of the names listed below, then the option has exactly the effect described below.

In the descriptions below, ``Name'' refers to the option's name in the option database. ``Class'' refers to the option's class value in the option database. ``Switch'' refers to the switch used in widget-creation and configure widget methods to set this value. For example, if an option's configure option is -foreground and there exists a widget $widget, then the call:

    $widget->configure(-foreground=>'black')

may be used to specify the value black for the option in the widget $widget. Configure options may be abbreviated, as long as the abbreviation is unambiguous (abbreviation is deprecated in perl/Tk).

Creation options: Widget Name and Class

The Name and -class options can only be specified when a widget is created, and cannot be changed with configure. These options determine the widget's identity and how Tk applies resource values from the option database (see Tk::option) and so they cannot be assigned by the options database.

Name: name
Switch: Name
Specifies the path element for the widget. Names generally begin with a lowercase letter.

Each widget has a unique pathname that follows the hierarchy from the MainWindow to the widget itself. Since the widget's PathName is used to assign options from the options database, it is important to specify a distinctive Name for any widget that will have non-default options. See Tk::option for details.

Name: class
Switch: -class
Specifies a class for the window. Classes generally begin with an uppercase letter.

This class will be used when querying the option database for the window's other options (see Tk::options), and it will also be used later for other purposes such as bindings. One typically assigns a class to a TopLevel or Frame so that the class will apply to all of that widget's children.

Reconfigurable options

These options can be set at widget creation or changed later via configure.

Name: activeBackground
Class: Foreground
Switch: -activebackground
Specifies background color to use when drawing active elements. An element (a widget or portion of a widget) is active if the mouse cursor is positioned over the element and pressing a mouse button will cause some action to occur. If strict Motif compliance has been requested by setting the $Tk::strictMotif variable, this option will normally be ignored; the normal background color will be used instead. For some elements on Windows and Macintosh systems, the active color will only be used while mouse button 1 is pressed over the element.
Name: activeBorderWidth
Class: BorderWidth
Switch: -activeborderwidth
Specifies a non-negative value indicating the width of the 3-D border drawn around active elements. See above for definition of active elements. The value may have any of the forms acceptable to Tk_GetPixels. This option is typically only available in widgets displaying more than one element at a time (e.g. menus but not buttons).
Name: activeForeground
Class: Background
Switch: -activeforeground
Specifies foreground color to use when drawing active elements. See above for definition of active elements.
Name: activetile
Class: Tile
>
Switch: -activetile
Especifica la imagen utilizada para mostrar dentro de los elementos activos del widget. Consulte anteriormente para ver la definición de elementos activos.
Name: anchor
Class: Anchor
Switch: -anchor
Especifica cómo la información en un widget (por ejemplo, texto o un mapa de bits) se debe mostrar en el widget. Debe ser uno de los valores n, ne, e, se, s, sw, w, nw, o center. Por ejemplo, nw significa mostrar la información de tal manera que su esquina superior izquierda esté en la esquina superior izquierda del widget.
Name: background
Class: Background
Switch: -background
Alias: -bg
Especifica el color de fondo normal a utilizar al mostrar el widget.
Name: bitmap
Class: Bitmap
Switch: -bitmap
Especifica un mapa de bits para mostrar en el widget, en cualquiera de las formas aceptables para Tk_GetBitmap. La forma exacta en que se muestra el mapa de bits puede verse afectada por otras opciones como -anchor o -justify. Típicamente, si se especifica esta opción, anula otras opciones que especifican un valor textual a mostrar en el widget; la opción -bitmap puede restablecerse a una cadena vacía para volver a habilitar una visualización de texto. En widgets que admiten las opciones -bitmap y -image, -image generalmente anulará -bitmap.
Name: borderWidth
Class: BorderWidth
Switch: -borderwidth
Alias: -bd
Especifica un valor no negativo que indica el ancho del borde 3D a dibujar alrededor del exterior del widget (si se está dibujando dicho borde; la opción relief típicamente determina esto). El valor también puede utilizarse al dibujar efectos 3D en el interior del widget. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels.
Name: compound
Class: Compound
Switch: -compound
Especifica si el widget debe mostrar texto y mapas de bits/imágenes al mismo tiempo, y si es así, dónde se debe colocar el mapa de bits/imagen en relación con el texto. Debe ser uno de los valores none, bottom, top, left, right, o center. Por ejemplo, el valor (predeterminado) none especifica que el mapa de bits o la imagen deben (si están definidos) mostrarse en lugar del texto, el valor left especifica que el mapa de bits o la imagen deben mostrarse a la izquierda del texto, y el valor center especifica que el mapa de bits o la imagen deben mostrarse encima del texto.
Name: cursor
Class: Cursor
Switch: -cursor
Especifica el cursor del ratón a utilizar para el widget. El valor puede tener cualquiera de las formas aceptables para Tk_GetCursor.
Name: dash
Class: Dash
Switch: -dash
El valor puede tener cualquiera de las formas aceptadas por Tk_GetDash, como 4, [6,4], ., -, -., o -...
Name: dashoffset
Class: Dashoffset
Switch: -dashoffset
Especifica el desplazamiento en la lista de guiones donde comienza el dibujo.
Name: disabledForeground
Class: DisabledForeground
Switch: -disabledforeground
Especifica el color de primer plano a utilizar al dibujar un elemento deshabilitado. Si la opción se especifica como una cadena vacía (que es típicamente el caso en pantallas monocromáticas), los elementos deshabilitados se dibujan con el color de primer plano normal, pero se atenúan dibujándolos con un patrón de relleno punteado.
Name: disabledtile
Class: Tile
Switch: -disabledtile
Especifica la imagen a utilizar al dibujar un elemento deshabilitado.
Name: exportSelection
Class: ExportSelection
Switch: -exportselection
Especifica si una selección en el widget debe ser también la selección X. El valor puede tener cualquiera de las formas aceptadas por Tcl_GetBoolean, como true, false, 0, 1, yes, o no. Si la selección se exporta, entonces seleccionar en el widget deselecciona la selección X actual, seleccionar fuera del widget deselecciona cualquier selección del widget, y el widget responderá a las solicitudes de recuperación de selección cuando tenga una selección. Lo predeterminado suele ser que los widgets exporten selecciones.
Name: font
Class: Font
Switch: -font
Especifica la fuente a utilizar al dibujar texto dentro del widget.
Name: foreground
Class: Foreground
Switch: -foreground
Alias: -fg
Especifica el color de primer plano normal a utilizar al mostrar el widget.
Name: highlightBackground
Class: HighlightBackground
Switch: -highlightbackground
Especifica el color a mostrar en la región de resaltado de desplazamiento cuando el widget no tiene el foco de entrada.
Name: highlightColor
Class: HighlightColor
Switch: -highlightcolor
Especifica el color a utilizar para el rectángulo de resaltado de desplazamiento que se dibuja alrededor del widget cuando tiene el foco de entrada.
Name: highlightThickness
Class: HighlightThickness
Switch: -highlightthickness
Especifica un valor no negativo que indica el ancho del rectángulo de resaltado a dibujar alrededor del exterior del widget cuando tiene el foco de entrada. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels. Si el valor es cero, no se dibuja ningún resaltado de foco alrededor del widget.
Name: image
Class: Image
Switch: -image
Especifica una imagen para mostrar en el widget, que debe haber sido creada con `image create`. (Consulte Tk::Image para obtener detalles sobre la creación de imágenes). Típicamente, si se especifica la opción -image, anula otras opciones que especifican un mapa de bits o un valor textual a mostrar en el widget; la opción -image puede restablecerse a una cadena vacía para volver a habilitar la visualización de mapas de bits o texto.
Name: insertBackground
Class: Foreground
Switch: -insertbackground
Especifica el color a utilizar como fondo en el área cubierta por el cursor de inserción. Este color normalmente anulará el fondo normal del widget (o el fondo de selección si el cursor de inserción cae en la selección).
Name: insertBorderWidth
Class: BorderWidth
Switch: -insertborderwidth
Especifica un valor no negativo que indica el ancho del borde 3D a dibujar alrededor del cursor de inserción. El valor puede tener cualquiera de las formas aceptables para Tk_GetPixels.
Name: insertOffTime
Class: OffTime
Switch: -insertofftime
Especifica un valor entero no negativo que indica el número de milisegundos que el cursor de inserción debe permanecer ``apagado'' en cada ciclo de parpadeo. Si esta opción es cero, el cursor no parpadea: está siempre encendido.
Nombre: insertOnTime
Clase: OnTime
Opción: -insertontime
Indica un valor no negativo que representa el número de milisegundos que debe permanecer "encendido" el cursor de inserción en cada ciclo de parpadeo.
Nombre: insertWidth
Clase: InsertWidth
Opción: -insertwidth
Indica un valor que representa el ancho total del cursor de inserción. El valor puede tener cualquiera de los formatos aceptados por Tk_GetPixels. Si se ha especificado un borde para el cursor de inserción (usando la opción insertBorderWidth), el borde se dibujará dentro del ancho especificado por insertWidth.
Nombre: jump
Clase: Jump
Opción: -jump
Para widgets con un deslizador que se puede arrastrar para ajustar un valor, como las barras de desplazamiento, esta opción determina cuándo se emiten notificaciones sobre los cambios en el valor del deslizador. El valor de la opción debe ser un booleano en el formato aceptado por Tcl_GetBoolean. Si el valor es falso, se realizan actualizaciones continuas mientras se arrastra el deslizador. Si el valor es verdadero, las actualizaciones se retrasan hasta que se suelte el botón del ratón para finalizar el arrastre; en ese punto, se emite solo una notificación (el valor "salta" en lugar de cambiar gradualmente).
Nombre: justify
Clase: Justify
Opción: -justify
Si hay varias líneas de texto mostradas en un widget, esta opción determina cómo se alinean las líneas entre sí. Debe ser uno de left, center o right. Left significa que los bordes izquierdos de las líneas se alinean, center significa que los centros de las líneas se alinean y right significa que los bordes derechos de las líneas se alinean.
Nombre: offset
Clase: Offset
Opción: -offset
Indica el desplazamiento de los tiles (ver también la opción -tile). Puede tener dos formatos diferentes -offset x,y o -offset side, donde side puede ser n, ne, e, se, s, sw, w, nw o center. En el primer caso, el origen es el origen de la ventana de nivel superior actual. Para el propio canvas y los objetos canvas, el origen es el origen del canvas, pero colocar # delante del par de coordenadas indica el uso del origen de nivel superior. Para los objetos canvas, la opción -offset se usa para el emplosado. Para los elementos de línea y polígono del canvas, también se puede especificar un índice como argumento, que conecta el origen del emplosado o tile a uno de los puntos de coordenada de la línea/polígono.
Nombre: orient
Clase: Orient
Opción: -orient
Para widgets que pueden organizarse con una orientación horizontal o vertical, como las barras de desplazamiento, esta opción especifica qué orientación se debe utilizar. Debe ser horizontal, vertical o una abreviatura de una de ellas.
Nombre: padX
Clase: Pad
Opción: -padx
Indica un valor no negativo que representa la cantidad de espacio adicional a solicitar para el widget en la dirección X. El valor puede tener cualquiera de los formatos aceptados por Tk_GetPixels. Al calcular el tamaño de la ventana, el widget agregará este valor al ancho que normalmente necesitaría (determinado por el ancho de los elementos mostrados en el widget); si el gestor de geometría puede satisfacer esta solicitud, el widget terminará con espacio interno adicional a la izquierda y/o derecha de lo que muestra dentro. La mayoría de los widgets solo usan esta opción para el relleno de texto: si están mostrando un bitmap o una imagen, generalmente ignoran las opciones de relleno.
Nombre: padY
Clase: Pad
Opción: -pady
Indica un valor no negativo que representa la cantidad de espacio adicional a solicitar para el widget en la dirección Y. El valor puede tener cualquiera de los formatos aceptados por Tk_GetPixels. Al calcular el tamaño de la ventana, el widget agregará este valor a la altura que normalmente necesitaría (determinada por la altura de los elementos mostrados en el widget); si el gestor de geometría puede satisfacer esta solicitud, el widget terminará con espacio interno adicional arriba y/o abajo de lo que muestra dentro. La mayoría de los widgets solo usan esta opción para el relleno de texto: si están mostrando un bitmap o una imagen, generalmente ignoran las opciones de relleno.
Nombre: relief
Clase: Relief
Opción: -relief
Indica el efecto 3D deseado para el widget. Los valores aceptados son raised, sunken, flat, ridge, solid y groove. El valor indica cómo debe parecer el interior del widget en relación con su exterior; por ejemplo, raised significa que el interior del widget debe parecer que sobresale de la pantalla, en relación con el exterior del widget.
Nombre: repeatDelay
Clase: RepeatDelay
Opción: -repeatdelay
Indica el número de milisegundos que se debe mantener presionado un botón o tecla antes de iniciar la repetición automática. Se utiliza, por ejemplo, en las flechas de arriba y abajo de las barras de desplazamiento.
Nombre: repeatInterval
Clase: RepeatInterval
Opción: -repeatinterval
Utilizado junto con repeatDelay: una vez que comienza la repetición automática, esta opción determina el número de milisegundos entre cada repetición automática.
Nombre: selectBackground
Clase: Foreground
Opción: -selectbackground
Indica el color de fondo a usar cuando se muestran los elementos seleccionados.
Nombre: selectBorderWidth
Clase: BorderWidth
Opción: -selectborderwidth
Indica un valor no negativo que representa el ancho del borde 3D que se dibuja alrededor de los elementos seleccionados. El valor puede tener cualquiera de los formatos aceptados por Tk_GetPixels.
Nombre: selectForeground
Clase: Background
Opción: -selectforeground
Indica el color de fuente a usar cuando se muestran los elementos seleccionados.
Nombre: setGrid
Clase: SetGrid
Opción: -setgrid
Indica un valor booleano que determina si este widget controla el redimensionamiento de la cuadrícula superior de su ventana. Esta opción se usa generalmente en widgets de texto, donde la información en el widget tiene un tamaño natural (el tamaño de un carácter) y es apropiado que las dimensiones de la ventana sean números enteros de estas unidades. Estos tamaños de ventana naturales forman una cuadrícula. Si la opción setGrid se establece en verdadero, el widget se comunicará con el gestor de geometría para que cuando el usuario redimensione la ventana superior que contiene el widget interactivamente, las dimensiones de la ventana se muestren al usuario en unidades de cuadrícula y el tamaño de la ventana se restrinja a números enteros de unidades de cuadrícula. Consulte "GEOMETRÍA CON CUADRÍCULAS" en Tk::Wm para más detalles.
Nombre: takeFocus
Clase: TakeFocus
Opción: -takefocus
Determina si la ventana acepta el foco durante la navegación con teclado (por ejemplo, Tab y Shift-Tab). Antes de establecer el foco en una ventana, los scripts de navegación consultan el valor de la opción takeFocus. Un valor de 0 significa que la ventana se omite durante la navegación con teclado. Un valor de 1 significa que la ventana recibe el foco siempre que sea visible (es decir, ella y todos sus ancestros estén mapeados). Un valor vacío para la opción significa que los scripts de navegación deciden si focalizar o no la ventana; el algoritmo actual es omitir la ventana si está deshabilitada, si no tiene un keybinding o si no es visible. Si el valor tiene cualquier otro formato, los scripts de navegación toman el valor, le añaden el nombre de la ventana (con un espacio como separador) y evalúan la cadena resultante como un Callback. El script debe devolver 0, 1 o una cadena vacía: un valor de 0 o 1 especifica si la ventana recibirá el foco, y una cadena vacía indica la decisión por defecto descrita anteriormente. Nota: esta interpretación de la opción es completamente definida
Tk::options(3pm) — ArchWiki

NAME

Tk::options — Standard options for Tk widgets

SYNOPSIS

package Tk::options;
use Tk;
use Tk::options qw(options);
options('widget');

DESCRIPTION

This module provides a convenient way to describe the standard options for Tk widgets. It is used internally by Tk but can also be used by custom widget developers. The options function takes a widget class name as an argument and returns a list of option descriptions in the format used by Tk::ConfigSpec.

The following is a list of standard Tk widget options, with their associated names, classes, and switches:

Name: activeBackground
Class: Background
Switch: -activebackground
Specifies the background color to be used when the mouse pointer is over the widget. This option is ignored for widgets that do not have a concept of being “active”.
Name: activeForeground
Class: Foreground
Switch: -activeforeground
Specifies the foreground color to be used when the mouse pointer is over the widget. This option is ignored for widgets that do not have a concept of being “active”.
Name: activeTile
Class: Tile
Switch: -activetile
Specifies the image used to display the widget when the mouse pointer is over it. This option is ignored for widgets that do not have a concept of being “active”.
Name: anchor
Class: Anchor
Switch: -anchor
Specifies how the widget's contents should be anchored within its allocated space. The value is a direction, such as n, ne, e, se, s, sw, w, nw, or center. The default is center.
Name: background
Class: Background
Switch: -background
Specifies the background color of the widget.
Name: bitmap
Class: Bitmap
Switch: -bitmap
Specifies a bitmap to be displayed inside the widget. If this option is specified, it overrides the -text and -image options. If the value is the empty string, then no bitmap is displayed.
Name: borderWidth
Class: BorderWidth
Switch: -borderwidth
Specifies the width of the border around the widget. The value can be a screen distance. Default is 1 or 2 depending on the platform.
Name: command
Class: Command
Switch: -command
Specifies a callback procedure to be executed when the widget is activated. For example, for a button widget, this is the procedure to call when the button is pressed.
Name: cursor
Class: Cursor
Switch: -cursor
Specifies the mouse cursor to be displayed when the pointer is over the widget. If this option is the empty string, the default cursor for the widget is used.
Name: disabledForeground
Class: DisabledForeground
Switch: -disabledforeground
Specifies the foreground color to be used when the widget is disabled. This option is ignored for widgets that cannot be disabled.
Name: exportSelection
Class: Boolean
Switch: -exportselection
A boolean value indicating whether the selection should be exported to other applications when the widget gets the input focus. The default is true.
Name: font
Class: Font
Switch: -font
Specifies the font to be used for text displayed in the widget.
Name: foreground
Class: Foreground
Switch: -foreground
Specifies the foreground color of the widget.
Name: height
Class: Height
Switch: -height
Specifies the desired height of the widget. For text-based widgets, the value is in lines; for other widgets, it's in screen units. If the value is less than or equal to 0, the widget's natural height is used.
Name: highlightBackground
Class: Background
Switch: -highlightbackground
Specifies the color of the highlight rectangle when the widget does not have the input focus. The default is system dependent.
Name: highlightColor
Class: Color
Switch: -highlightcolor
Specifies the color of the highlight rectangle when the widget has the input focus. The default is system dependent.
Name: highlightThickness
Class: BorderWidth
Switch: -highlightthickness
Specifies the width of the highlight rectangle. The default is 1.
Name: image
Class: Image
Switch: -image
Specifies an image to be displayed inside the widget. If this option is specified, it overrides the -text and -bitmap options. If the value is the empty string, then no image is displayed.
Name: justify
Class: Justify
Switch: -justify
Specifies how lines of text should be justified within the widget. Valid values are left, center, and right. The default is left.
Name: menu
Class: Menu
Switch: -menu
Specifies a menu to be associated with the widget. For example, this option can be used to create a pull-down menu for a menu bar.
Name: padx
Class: Pad
Switch: -padx
Specifies the amount of extra space to allocate to the left and right of the widget's contents. The value is a screen distance. Default is 1.
Name: pady
Class: Pad
Switch: -pady
Specifies the amount of extra space to allocate above and below the widget's contents. The value is a screen distance. Default is 1.
Name: relief
Class: Relief
Switch: -relief
Specifies the appearance of the widget's border. Valid values are flat, groove, raised, ridge, solid, and sunken. The default is flat.
Name: screen
Class: Screen
Switch: -screen
Specifies the Tk screen for the widget. This option is usually set when the widget is created and should not be changed afterwards.
Name: state
Class: State
Switch: -state
Specifies whether the widget should be active or disabled. Valid values are normal and disabled. The default is normal.
Name: takeFocus
Class: TakeFocus
Switch: -takefocus
Specifies whether the widget should be included in the keyboard traversal tab order. The value can be 0 (never take focus), 1 (always take focus), or "" (take focus if other widgets in the same window do). The default is "". This option is used by the default bindings to implement keyboard traversal. Callbacks that implement traversal: the widget implementations ignore the option entirely, so you can change its meaning if you redefine the keyboard traversal scripts.
Name: text
Class: Text
Switch: -text
Specifies a string to be displayed inside the widget. The way in which the string is displayed depends on the particular widget and may be determined by other options, such as anchor or justify.
Name: textVariable
Class: Variable
Switch: -textvariable
Specifies the name of a variable. The value of the variable is a text string to be displayed inside the widget; if the variable value changes then the widget will automatically update itself to reflect the new value. The way in which the string is displayed in the widget depends on the particular widget and may be determined by other options, such as anchor or justify.
Name: tile
Class: Tile
Switch: -tile
Specifies image used to display the widget. If image is the empty string, then the normal background color is displayed.
Name: troughColor
Class: Background
Switch: -troughcolor
Specifies the color to use for the rectangular trough areas in widgets such as scrollbars and scales.
Name: troughTile
Class: Tile
Switch: -troughtile
Specifies image used to display in the rectangular trough areas in widgets such as scrollbars and scales.
Name: underline
Class: Underline
Switch: -underline
Specifies the integer index of a character to underline in the widget. This option is used by the default bindings to implement keyboard traversal for menu buttons and menu entries. 0 corresponds to the first character of the text displayed in the widget, 1 to the next character, and so on.
Name: wrapLength
Class: WrapLength
Switch: -wraplength
For widgets that can perform word-wrapping, this option specifies the maximum line length. Lines that would exceed this length are wrapped onto the next line, so that no line is longer than the specified length. The value may be specified in any of the standard forms for screen distances. If this value is less than or equal to 0 then no wrapping is done: lines will break only at newline characters in the text.
Name: xScrollCommand
Class: ScrollCommand
Switch: -xscrollcommand
Specifies a callback used to communicate with horizontal scrollbars. When the view in the widget's window changes (or whenever anything else occurs that could change the display in a scrollbar, such as a change in the total size of the widget's contents), the widget will make a callback passing two numeric arguments in addition to any specified in the callback. Each of the numbers is a fraction between 0 and 1, which indicates a position in the document. 0 indicates the beginning of the document, 1 indicates the end, .333 indicates a position one third the way through the document, and so on. The first fraction indicates the first information in the document that is visible in the window, and the second fraction indicates the information just after the last portion that is visible. Typically the -xscrollcommand option consists of the scrollbar widget object and the method ``set'' i.e. [set => $sb]: this will cause the scrollbar to be updated whenever the view in the window changes. If this option is not specified, then no command will be executed.
Name: yScrollCommand
Class: ScrollCommand
Switch: -yscrollcommand
Specifies a calback used to communicate with vertical scrollbars. This option is treated in the same way as the -xscrollcommand option, except that it is used for vertical scrollbars and is provided by widgets that support vertical scrolling. See the description of -xscrollcommand for details on how this option is used.
