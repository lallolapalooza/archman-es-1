Tk_NameOfRelief(3)

Paquete: tk

Licencias: TCL

Tk_GetReliefFromObj(3) Procedimientos de la biblioteca Tk Tk_GetReliefFromObj(3)

NOMBRE

Tk_GetReliefFromObj, Tk_GetRelief, Tk_NameOfRelief - traducir entre cadenas y valores de alivio

SINOPSIS

#include <tk.h>

int
Tk_GetReliefFromObj(interp, objPtr, reliefPtr)

int
Tk_GetRelief(interp, name, reliefPtr)

const char *
Tk_NameOfRelief(relief)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a utilizar para la notificación de errores.
Tcl_Obj *objPtr (entrada/salida)
El valor de cadena contiene el nombre del alivio, uno de “flat”, “groove”, “raised”, “ridge”, “solid”, o “sunken” (o cualquier abreviatura única de estos al introducir); la representación interna se modificará para almacenar en caché el valor de alivio correspondiente.
const char *name (entrada)
Igual que objPtr excepto que la descripción del alivio se pasa como una cadena.
int *reliefPtr (salida)
Puntero a la ubicación donde almacenar el valor de alivio correspondiente a objPtr o name.
int relief (entrada)
Valor de alivio (uno de TK_RELIEF_FLAT, TK_RELIEF_RAISED, TK_RELIEF_SUNKEN, TK_RELIEF_GROOVE, TK_RELIEF_SOLID, o TK_RELIEF_RIDGE).

DESCRIPCIÓN

Tk_GetReliefFromObj coloca en *reliefPtr el valor de alivio correspondiente al valor de objPtr. Este valor será uno de TK_RELIEF_FLAT, TK_RELIEF_RAISED, TK_RELIEF_SUNKEN, TK_RELIEF_GROOVE, TK_RELIEF_SOLID, o TK_RELIEF_RIDGE. En circunstancias normales, el valor de retorno es TCL_OK y interp no se utiliza. Si objPtr no contiene uno de los nombres de alivio válidos o una abreviatura de ellos, entonces se devuelve TCL_ERROR, *reliefPtr no se modifica y se almacena un mensaje de error en el resultado de interp si interp no es NULL. Tk_GetReliefFromObj almacena en caché información sobre el valor de retorno en objPtr, lo que acelera las llamadas futuras a Tk_GetReliefFromObj con el mismo objPtr.

Tk_GetRelief es idéntico a Tk_GetReliefFromObj excepto que la descripción del alivio se especifica con una cadena en lugar de un objeto. Esto evita que Tk_GetRelief almacene en caché el valor de retorno, por lo que Tk_GetRelief es menos eficiente que Tk_GetReliefFromObj.

Tk_NameOfRelief es el inverso lógico de Tk_GetRelief. Dado un valor de alivio, devuelve la cadena correspondiente (flat, raised, sunken, groove, solid o ridge). Si relief no es un valor de alivio legal, se devuelve “unknown relief”.
