Tk_AddOption(3) Procedimientos de la biblioteca Tk Tk_AddOption(3)

NOMBRE

Tk_AddOption - Añadir una opción a la base de datos de opciones

SINOPSIS

#include <tk.h>

void
Tk_AddOption(tkwin, name, value, priority)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token para la ventana.
const char *name (entrada)
Nombre de la opción de múltiples elementos.
const char *value (entrada)
Valor de la opción.
int priority (entrada)
Nivel de prioridad general a utilizar para la opción.

DESCRIPCIÓN

Este procedimiento se invoca para añadir una opción a la base de datos asociada con la ventana principal de tkwin. Name contiene la opción que se está especificando y consiste en nombres y/o clases separados por asteriscos o puntos, en el formato X habitual. Value contiene la cadena de texto a asociar con name; este valor se devolverá en las llamadas a Tk_GetOption. Priority especifica la prioridad del valor; cuando las opciones se consultan usando Tk_GetOption, se devuelve el valor con la mayor prioridad. Priority debe estar entre 0 y TK_MAX_PRIO (100). Algunos valores de prioridad comunes son:

TK_WIDGET_DEFAULT_PRIO
Se usa para valores predeterminados codificados en los widgets.
TK_STARTUP_FILE_PRIO
Se usa para opciones especificadas en archivos de inicio específicos de la aplicación.
TK_USER_DEFAULT_PRIO
Se usa para opciones especificadas en archivos de valores predeterminados específicos del usuario, como .Xdefaults, bases de datos de recursos cargadas en el servidor X, o archivos de inicio específicos del usuario.
TK_INTERACTIVE_PRIO
Se usa para opciones especificadas interactivamente después de que la aplicación comience a ejecutarse.
