NOMBRE

Tk::Panedwindow - Crear y manipular widgets Panedwindow

SINTAXIS

$panedwindow = $parent->Panedwindow(?opciones?);

-background    -height  -width
-borderwidth   -orient
-cursor        -relief

OPCIONES DEL_WIDGET

Opción: -handlepad
Nombre: handlePad
Clase: HandlePad
Al trazar los mangos de sash, especifica la distancia desde el final de la barra de sash (dependiendo de la orientación del widget) a la que se debe dibujar el mango. Puede ser cualquier valor aceptado por Tk_GetPixels.
Opción: -handlesize
Nombre: handleSize
Clase: HandleSize
Indica el lado del tamaño de un mango de sash. Los mangos siempre se dibujan como cuadrados. Puede ser cualquier valor aceptado por Tk_GetPixels.
Opción: -opaqueresize
Nombre: opaqueResize
Clase: OpaqueResize
Indica si los paneles deben ser redimensionados cuando se mueve la barra de sash (verdadero), o si el redimensionamiento debe ser pospuesto hasta que la barra de sash esté colocada (falso).
Opción: -sashcursor
Nombre: sashCursor
Clase: SashCursor
Cursor del ratón a usar cuando está sobre una barra de sash. Si es nulo, se usará sb_h_double_arrow para paneles de orientación horizontal y sb_v_double_arrow para paneles de orientación vertical.
Opción: -sashpad
Nombre: sashPad
Clase: SashPad
Indica la cantidad de margen a dejar en cada lado de una barra de sash. Puede ser cualquier valor aceptado por Tk_GetPixels.
Opción: -sashrelief
Nombre: sashRelief
Clase: SashRelief
Relieve a usar al dibujar una barra de sash. Puede ser cualquier valor de relieve estándar de Tk.
Opción: -sashwidth
Nombre: sashWidth
Clase: SashWidth
Indica el ancho de cada barra de sash. Puede ser cualquier valor aceptado por Tk_GetPixels.
Opción: -showhandle
Nombre: showHandle
Clase: ShowHandle
Indica si los mangos de sash deben mostrarse. Puede ser cualquier valor booleano válido.

DESCRIPCIÓN

El método Panedwindow crea una nueva ventana (dada por el argumento $panedwindow) y la convierte en un widget Panedwindow. Se pueden especificar otras opciones, descritas arriba, en la línea de comandos o en la base de opciones para configurar aspectos del widget, como el color de fondo y el relieve por defecto.

Un widget Panedwindow contiene cualquier número de paneles, dispuestos horizontal o verticalmente según el valor de la opción -orient. Cada panel contiene un widget, y cada par de paneles está separado por una barra de sash móvil (dicha barra se mueve con movimientos del ratón). Mover una barra de sash provoca que los widgets a cada lado de la barra cambien de tamaño.

MÉTODOS DEL_WIDGET

El método Panedwindow puede invocar varias operaciones en el widget. Tiene la siguiente forma general:

$widget->method(?arg arg ...?);

Los siguientes comandos son posibles para los widgets Panedwindow:

$widget->add(?window ...? ?option value ...?);
Añade una o más ventanas a un panel del Panedwindow, cada una en un panel diferente. Los argumentos consisten en el nombre de una o más ventanas seguidas de pares de argumentos que especifican cómo gestionar las ventanas. Option puede tener cualquier valor aceptado por el subcomando configure.
$widget->cget(option);
Devuelve el valor actual de la opción de configuración dada por option. Option puede tener cualquier valor aceptado por el comando Panedwindow.
$widget->configure(?option?, ?value, option, value, ...?);
Consulta o modifica las opciones de configuración del widget. Si no se especifica option, devuelve una lista que describe todas las opciones disponibles para $widget (ver Tk::configure para información sobre el formato de esta lista). Si option se especifica con un valor value sin, entonces devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica option). Si se especifican uno o más pares de option-value, entonces el comando modifica las opciones dadas en el widget con los valores dados; en este caso, el comando devuelve una cadena vacía. Option puede tener cualquier valor aceptado por el comando Panedwindow.
$widget->forget(?window ...?);
Elimina el panel que contiene $widget del Panedwindow. Se olvidarán todas las opciones de gestión de geometría para $widget.
$widget->identify(x, y);
Identifica el componente de Panedwindow debajo del punto dado por x e y, en coordenadas de ventana. Si el punto está sobre una barra de sash o sobre un mango de sash, el resultado es una lista de dos elementos que contiene el índice de la barra de sash o mango y una palabra que indica si está sobre una barra de sash o sobre un mango, como [0, 'sash'] o [2, 'handle']. Si el punto está sobre cualquier otra parte del Panedwindow, el resultado es una lista vacía.
$widget->proxy(?args?);
Este comando se utiliza para consultar y cambiar la posición de la proxy, utilizada para redimensionar paneles con estilo "rubberband". Puede tomar cualquiera de las siguientes formas:
$widget->proxyCoord;
Devuelve una lista que contiene las coordenadas x e y de la última ubicación de la proxy.
$widget->proxyForget;
Elimina la proxy de la pantalla.
$widget->proxyPlace(x, y);
Ubica la proxy en las coordenadas dadas por x e y.
$widget->sash(?args?);
Este comando se utiliza para consultar y cambiar la posición de las barras de sash en el Panedwindow. Puede tomar cualquiera de las siguientes formas:
$widget->sashCoord(index);
Devuelve las coordenadas x e y actuales de la barra de sash dada por index. Index debe ser un entero entre 0 y el número de paneles en el Panedwindow menos 1. Las coordenadas dadas son las de la esquina superior izquierda del área que contiene la barra de sash. $widget->sashDragto(index, x, y) Este comando calcula la diferencia entre las coordenadas dadas y las coordenadas dadas al último comando sash coord para la barra de sash dada. Luego mueve esa barra la diferencia calculada. El valor devuelto es la cadena vacía.
$widget->sashMark(index, x, y);
Registra x e y para la barra de sash dada por index; se usa junto con los comandos posteriores de dragto para mover la barra de sash.

Tk::Panedwindow(3pm)

NAME

Tk_Panedwindow - A frame that manages a list of panes.

SYNOPSIS

	use Tk::Panedwindow;
	$widget = $parent->Panedwindow(?options?);
	$widget->sashbind(index, callback);
	$widget->sashpos(index, value);
	$widget->sashpos;
	$widget->sashPlace(index, x, y);
	$widget->panecget(option);
	$widget->paneconfigure(?option? ?value option value ...?);
	$widget->panes;

WIDGET-SPECIFIC OPTIONS

See the paneconfigure and panecget subcommands below for a description of the pane configuration options.

DESCRIPTION

A Panedwindow widget is used to manage a list of child windows (called panes). The panes are arranged vertically or horizontally, separated by sashes that the user can drag to change the sizes of the panes. This is useful for implementing interfaces like custom text editors, image viewers, or any application where the user needs to control the relative sizes of multiple sub-windows.

The Panedwindow widget takes a list of child widgets and arranges them in a single row or column. The user can interactively resize the panes by dragging the sashes between them. The sizes of the panes are adjusted proportionally when the Panedwindow widget itself is resized.

WIDGET METHODS

$widget->sashbind(index, callback);
Binds the given callback to the sash specified by index. The callback will be invoked when the sash is clicked. The callback receives one argument: the index of the sash. The default bindings handle sash dragging.
$widget->sashpos(index, value);
Sets the position of the sash specified by index to value. The value is a screen coordinate (pixels).
$widget->sashpos;
Returns a list containing the positions of all sashes in the widget.
$widget->sashPlace(index, x, y);
Place the sash given by index at the given coordinates.
$widget $widget->panecget(option);
Query a management option for $widget. Option may be any value allowed by the paneconfigure subcommand.
$widget $widget->paneconfigure(?option? ?value option value ...?);
Query or modify the management options for $widget. If no option is specified, returns a list describing all of the available options for $widget (see Tk::configure for information on the format of this list). If option is specified with no value, then the command returns a list describing the one named option (this list will be identical to the corresponding sublist of the value returned if no option is specified). If one or more option-value pairs are specified, then the command modifies the given widget option(s) to have the given value(s); in this case the command returns an empty string. The following options are supported:
-after => $widget
Insert the window after the window specified. $widget should be the name of a window already managed by $widget.
-before => $widget
Insert the window before the window specified. $widget should be the name of a window already managed by $widget.
-height => size
Specify a height for the window. The height will be the outer dimension of the window including its border, if any. If size is an empty string, or if -height is not specified, then the height requested internally by the window will be used initially; the height may later be adjusted by the movement of sashes in the Panedwindow. Size may be any value accepted by Tk_GetPixels.
-minsize => n
Specifies that the size of the window cannot be made less than n. This constraint only affects the size of the widget in the paned dimension -- the x dimension for horizontal Panedwindows, the y dimension for vertical Panedwindows. May be any value accepted by Tk_GetPixels.
-padx => n
Specifies a non-negative value indicating how much extra space to leave on each side of the window in the X-direction. The value may have any of the forms accepted by Tk_GetPixels.
-pady => n
Specifies a non-negative value indicating how much extra space to leave on each side of the window in the Y-direction. The value may have any of the forms accepted by Tk_GetPixels.
-sticky => style
If a window's pane is larger than the requested dimensions of the window, this option may be used to position (or stretch) the window within its pane. Style is a string that contains zero or more of the characters n, s, e or w. The string can optionally contains spaces or commas, but they are ignored. Each letter refers to a side (north, south, east, or west) that the window will "stick" to. If both n and s (or e and w) are specified, the window will be stretched to fill the entire height (or width) of its cavity.
-width => size
Specify a width for the window. The width will be the outer dimension of the window including its border, if any. If size is an empty string, or if -width is not specified, then the width requested internally by the window will be used initially; the width may later be adjusted by the movement of sashes in the Panedwindow. Size may be any value accepted by Tk_GetPixels.
$widget->panes;
Returns an ordered list of the widgets managed by $widget.

RESIZING PANES

A pane is resized by grabbing the sash (or sash handle if present) and dragging with the mouse. This is accomplished via mouse motion bindings on the widget. When a sash is moved, the sizes of the panes on each side of the sash, and thus the widgets in those panes, are adjusted.

When a pane is resized from outside (eg, it is packed to expand and fill, and the containing toplevel is resized), space is added to the final (rightmost or bottommost) pane in the window.

KEYWORDS

Panedwindow, widget, geometry management
