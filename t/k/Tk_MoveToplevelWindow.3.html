NOMBRE

Tk_MoveToplevelWindow - Ajustar la posición de una ventana de nivel superior

SINOPSIS

#include <tk.h>

Tk_MoveToplevelWindow(tkwin, x, y)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token de la ventana de nivel superior a mover.
int x (entrada)
Nueva coordenada x para el píxel superior izquierdo del borde de tkwin, o el píxel superior izquierdo del borde decorativo proporcionado para tkwin por el gestor de ventanas, si lo hay.
int y (entrada)
Nueva coordenada y para el píxel superior izquierdo del borde de tkwin, o el píxel superior izquierdo del borde decorativo proporcionado para tkwin por el gestor de ventanas, si lo hay.

DESCRIPCIÓN

En general, una ventana nunca debe establecer su propia posición; esto solo debe ser hecho por el gestor de geometría responsable de la ventana. Para las ventanas de nivel superior, el gestor de ventanas es efectivamente el gestor de geometría; Tk proporciona código de interfaz entre la aplicación y el gestor de ventanas para transmitir los deseos de la aplicación al gestor de geometría. El tamaño deseado para una ventana de nivel superior se transmite utilizando el mecanismo habitual Tk_GeometryRequest. El procedimiento Tk_MoveToplevelWindow puede ser utilizado por una aplicación para solicitar una posición particular para una ventana de nivel superior; este procedimiento es similar en función al comando Tcl wm geometry, excepto que no se pueden especificar desplazamientos negativos. Es invocado por widgets como menús que quieren aparecer en un lugar particular de la pantalla.

Cuando se llama a Tk_MoveToplevelWindow, no pasa inmediatamente la nueva ubicación deseada al gestor de ventanas; pospone esta acción hasta que se haya completado todo el trabajo pendiente, utilizando el mecanismo Tcl_DoWhenIdle.
