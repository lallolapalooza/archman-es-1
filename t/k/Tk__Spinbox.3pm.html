Se pueden especificar opciones adicionales, descritas anteriormente, en la línea de comandos o en la base de datos de opciones para configurar aspectos del Spinbox, como sus colores, fuente y relieve. Un Spinbox es un widget Entry extendido que permite al usuario moverse, o girar, a través de un conjunto fijo de valores ascendentes o descendentes, como horas o fechas, además de editar el valor como en un entry. Al crearse, la cadena de un Spinbox está vacía. Una parte del Spinbox puede seleccionarse como se describe a continuación. Si un Spinbox está exportando su selección (ver la opción exportSelection), observará los protocolos estándar para manejar la selección; las selecciones de Spinbox están disponibles como tipo STRING. Los Spinbox también observan las reglas estándar de Tk para tratar el foco de entrada. Cuando un Spinbox tiene el foco de entrada, muestra un *cursor de inserción* para indicar dónde se insertarán los nuevos caracteres. Los Spinbox son capaces de mostrar cadenas demasiado largas para caber completamente dentro de la ventana del widget. En este caso, solo se mostrará una parte de la cadena; se pueden utilizar comandos descritos a continuación para cambiar la vista en la ventana. Los Spinbox utilizan el mecanismo estándar de -xscrollcommand para interactuar con las barras de desplazamiento (consulte la descripción de la opción -xscrollcommand para obtener detalles). También admiten escaneo, como se describe a continuación. heading: DESCRIPTION - description: > La validación funciona estableciendo la opción validateCommand en una llamada que se evaluará de acuerdo con la opción validate de la siguiente manera:
none
Predeterminado. Esto significa que no se realizará ninguna validación.
focus
validateCommand se llamará cuando el Spinbox reciba o pierda el foco.
focusin
validateCommand se llamará cuando el Spinbox reciba foco.
focusout
validateCommand se llamará cuando el Spinbox pierda el foco.
key
validateCommand se llamará cuando el Spinbox sea editado.
all
validateCommand se llamará para todas las condiciones anteriores.

Los callbacks validateCommand y invalidCommand se invocan con al menos 5 argumentos posicionales, que se *añaden* a los argumentos de callback ya existentes:

  • 1

    El valor propuesto de la entrada. Si está configurando el widget de entrada para tener una nueva variable de texto, este será el valor de esa variable de texto.

  • 2

    Los caracteres que se añadirán (o eliminarán). Será "undef" si la validación se debe al foco, a una llamada explícita para validar o si el cambio se debe a la modificación de "-textvariable".

  • 3

    El valor actual de la entrada, es decir, antes del cambio propuesto.

  • 4

    El índice de la cadena de caracteres a añadir/eliminar, si lo hay. De lo contrario, -1.

  • 5

    Tipo de acción. 1 == INSERTAR, 0 == ELIMINAR, -1 si es una validación forzada o una validación de variable de texto.

En general, textVariable y validateCommand pueden ser peligrosos de mezclar. Se han superado todos los problemas para que el uso de validateCommand no interfiera con el comportamiento tradicional del widget Spinbox. El uso de textVariable para fines de solo lectura nunca causará problemas. El peligro surge cuando se intenta establecer textVariable a algo que validateCommand no aceptaría, lo que hace que validate se convierta en *none* (el invalidCommand no se activará). Lo mismo ocurre cuando se produce un error al evaluar validateCommand.

Principalmente, se producirá un error cuando validateCommand o invalidCommand encuentre un error en su script al evaluar, o cuando validateCommand no devuelva un valor booleano válido. La opción validate también se establecerá en *none* cuando edite el widget Spinbox dentro de validateCommand o invalidCommand. Dichas ediciones anularán la que se estaba validando. Si desea editar el valor del widget durante la validación y mantener la opción validate establecida, debe incluir el comando

my $val = $spinbox->cget(-validate);
$spinbox->configure(-validate => $val);

en validateCommand o invalidCommand (según desde dónde estuviera editando el widget Spinbox). También se recomienda no establecer una textVariable asociada durante la validación, ya que esto puede hacer que el widget Spinbox se desincronice con la textVariable.

heading: VALIDATION - description: > El comando Spinbox crea un objeto de widget cuyo nombre es $widget. Este comando se puede utilizar para invocar varias operaciones en el widget. Tiene la siguiente forma general: 
$widget->method(?arg arg ...?);
Muchos de los métodos para Spinboxes toman uno o más índices como argumentos. Un índice especifica un carácter particular en la cadena del Spinbox, de cualquiera de las siguientes maneras:
number
Especifica el carácter como un índice numérico, donde 0 corresponde al primer carácter de la cadena.
anchor
Indica el punto de anclaje para la selección, que se establece con los métodos select from y select adjust.
end
Indica el carácter inmediatamente posterior al último en la cadena del Spinbox. Esto es equivalente a especificar un índice numérico igual a la longitud de la cadena del Spinbox.
insert
Indica el carácter adyacente e inmediatamente posterior al cursor de inserción.
sel.first
Indica el primer carácter de la selección. Es un error usar esta forma si la selección no está en la ventana del Spinbox.
sel.last
Indica el carácter inmediatamente posterior al último de la selección. Es un error usar esta forma si la selección no está en la ventana del Spinbox.
@number
En esta forma, *number* se trata como una coordenada x en la ventana del Spinbox; se utiliza el carácter que abarca esa coordenada x. Por ejemplo, ``@0'' indica el carácter más a la izquierda en la ventana.
Se pueden usar abreviaturas para cualquiera de las formas anteriores, por ejemplo, ``e'' o ``sel.f''. En general, los índices fuera de rango se redondean automáticamente al valor legal más cercano. Los siguientes comandos son posibles para los widgets Spinbox:
$widget->bbox(index);
Devuelve una lista de cuatro números que describen el cuadro delimitador del carácter dado por *index*. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del área de pantalla cubierta por el carácter (en píxeles relativos al widget) y los dos últimos elementos dan el ancho y la altura del carácter, en píxeles. El cuadro delimitador puede referirse a una región fuera del área visible de la ventana.
$widget->cget(option);
Devuelve el valor actual de la opción de configuración dada por *option*. *Option* puede tener cualquiera de los valores aceptados por el comando Spinbox.
$widget->configure(?option?, ?value, option, value, ...?);
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna *option*, devuelve una lista que describe todas las opciones disponibles para $widget (consulte Tk::configure para obtener información sobre el formato de esta lista). Si se especifica *option* sin *value*, el comando devuelve una lista que describe la opción con el nombre especificado (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna *option*). Si se especifican uno o más pares *option-value*, el comando modifica la(s) opción(es) del widget dada(s) para que tengan el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. *Option* puede tener cualquiera de los valores aceptados.

This command is used to implement scanning on Spinboxes. It has two forms, depending on option:

This command is used to adjust the selection within a Spinbox. It has several forms, depending on option:
$widget->selectionAdjust(index);
Locate the end of the selection nearest to the character given by index, and adjust that end of the selection to be at index (i.e including but not going beyond index). The other end of the selection is made the anchor point for future select to commands. If the selection isn't currently in the Spinbox, then a new selection is created to include the characters between index and the most recent selection anchor point, inclusive. $widget->selectionClear;

$widget->selectionRange(start, end);
Sets the selection to include the characters starting with the one indexed by start and ending with the one just before end. If end refers to the same character as start or an earlier one, then the Spinbox's selection is cleared.
$widget->selectionTo(index);
If index is before the anchor point, set the selection to the characters from index up to but not including the anchor point. If index is the same as the anchor point, do nothing. If index is after the anchor point, set the selection to the characters from the anchor point up to but not including index. The anchor point is determined by the most recent select from or select adjust command in this widget. If the selection isn't in this widget then a new selection is created using the most recent anchor point specified for the widget. Returns an empty string.
$widget->set(?string?);
If string is specified, the Spinbox will try and set it to this value, otherwise it just returns the Spinbox's string. If validation is on, it will occur when setting the string.
$widget->validate;
This command is used to force an evaluation of the validateCommand independent of the conditions specified by the validate option. This is done by temporarily setting the validate option to all. It returns 0 or 1.

This command is used to query and change the horizontal position of the text in the widget's window. It can take any of the following forms:
$widget->xview;
Returns a list containing two elements. Each element is a real fraction between 0 and 1; together they describe the horizontal span that is visible in the window. For example, if the first element is .2 and the second element is .6, 20% of the Spinbox's text is off-screen to the left, the middle 40% is visible in the window, and 40% of the text is off-screen to the right. These are the same values passed to scrollbars via the -xscrollcommand option.
$widget->xview(index);
Adjusts the view in the window so that the character given by index is displayed at the left edge of the window.
$widget->xviewMoveto(fraction);
Adjusts the view in the window so that the character fraction of the way through the text appears at the left edge of the window. Fraction must be a fraction between 0 and 1.
$widget->xviewScroll(number, what);
This command shifts the view in the window left or right according to number and what. Number must be an integer. What must be either units or pages or an abbreviation of one of these. If what is units, the view adjusts left or right by number average-width characters on the display; if it is pages then the view adjusts by number screenfuls. If number is negative then characters farther to the left become visible; if it is positive then characters farther to the right become visible.

DEFAULT BINDINGS

Tk automatically creates class bindings for Spinboxes that give them the following default behavior. In the descriptions below, ``word'' refers to a contiguous group of letters, digits, or ``_'' characters, or any single character other than these.

[1]
Clicking mouse button 1 positions the insertion cursor just before the character underneath the mouse cursor, sets the input focus to this widget, and clears any selection in the widget. Dragging with mouse button 1 strokes out a selection between the insertion cursor and the character under the mouse.
[2]
Double-clicking with mouse button 1 selects the word under the mouse and positions the insertion cursor at the beginning of the word. Dragging after a double click will stroke out a selection consisting of whole words.
[3]
Triple-clicking with mouse button 1 selects all of the text in the Spinbox and positions the insertion cursor before the first character.
[4]
The ends of the selection can be adjusted by dragging with mouse button 1 while the Shift key is down; this will adjust the end of the selection that was nearest to the mouse cursor when button 1 was pressed. If the button is double-clicked before dragging then the selection will be adjusted in units of whole words.
[5]
Clicking mouse button 1 with the Control key down will position the insertion cursor in the Spinbox without affecting the selection.
[6]
If any normal printing characters are typed in a Spinbox, they are inserted at the point of the insertion cursor.
[7]
The view in the Spinbox can be adjusted by dragging with mouse button 2. If mouse button 2 is clicked without moving the mouse, the selection is copied into the Spinbox at the position of the mouse cursor.
[8]
If the mouse is dragged out of the Spinbox on the left or right sides while button 1 is pressed, the Spinbox will automatically scroll to make more text visible (if there is more text off-screen on the side where the mouse left the window).
[9]
The Left and Right keys move the insertion cursor one character to the left or right; they also clear any selection in the Spinbox and set the selection anchor. If Left or Right is typed with the Shift key down, then the insertion cursor moves and the selection is extended to include the new character. Control-Left and Control-Right move the insertion cursor by words, and Control-Shift-Left and Control-Shift-Right move the insertion cursor by words and also extend the selection. Control-b and Control-f behave the same as Left and Right, respectively. Meta-b and Meta-f behave the same as Control-Left and Control-Right, respectively.
[10]
The Home key, or Control-a, will move the insertion cursor to the beginning of the Spinbox and clear any selection in the Spinbox. Shift-Home moves the insertion cursor to the beginning of the Spinbox and also extends the selection to that point.
[11]
The End key, or Control-e, will move the insertion cursor to the end of the Spinbox and clear any selection in the Spinbox. Shift-End moves the cursor to the end and extends the selection to that point.

Spinbox - Perl/Tk Spinbox widget

NAME

Spinbox - widget for selecting text from a list of strings

SYNOPSIS

    use Tk;
    use Tk::widgets qw(Spinbox);
    
    my $spinbox = $mw->Spinbox(?options?);

WIDGET-SPECIFIC OPTIONS

Command-line, configure, or cget arguments. See also tk(3).

-state
Specifies one of the following values: normal or disabled. The default is normal.
-values
A list of strings that are to be displayed in the Spinbox. The default is an empty list.
-command
A procedure to be called whenever the value of the Spinbox changes. The current value of the Spinbox is passed as an argument to the procedure.
-wrap
Specifies one of the following values: true or false. If true the Spinbox is considered to be circular: the value preceding the first element is the last element, and the value following the last element is the first element. The default is true.
-increment
Specifies the amount to increment or decrement the value when the spin buttons are pressed. The default is 1.
-readonlybackground
Specifies the background color for the Spinbox when it is in disabled state. The default is system dependent.
-relief
Specifies the appearance of a 3-D border around the Spinbox. Legal values are raised, sunken, flat, ridge, and groove. The default is flat.
-width
Specifies the desired width of the Spinbox in characters. If negative or zero, the Spinbox width is determined by the width of its elements.
-height
Specifies the desired height of the Spinbox in lines. If negative or zero, the Spinbox height is determined by the height of its elements.
-highlightbackground
Color for the highlight border when the widget has focus. The default is system dependent.
-highlightcolor
Color for the highlight border when the widget has focus. The default is system dependent.
-highlightthickness
Specifies the thickness of the highlight border around the widget. The default is 1.
-bd
Specifies the border width for the Spinbox. The default is system dependent.
-bg
Specifies the normal background color. The default is system dependent.
-fg
Specifies the normal foreground color. The default is system dependent.
-font
Specifies the font to be used for the text in the Spinbox. The default is system dependent.
-justify
Specifies how to justify the text within the Spinbox. Legal values are left, center, and right. The default is left.
-padx
Specifies the amount of extra padding to add to the left and right of the Spinbox contents. The default is system dependent.
-pady
Specifies the amount of extra padding to add to the top and bottom of the Spinbox contents. The default is system dependent.
-cursor
Specifies the cursor to be displayed when the mouse moves over the Spinbox. The default is system dependent.
-exportselection
Specifies one of the following values: true or false. If true, the selection is exported to the Tk selection mechanism. The default is true.
-takefocus
Specifies whether the widget should be eligible to have keyboard focus. The default is true.
-troughcolor
Specifies the color of the trough in which the spin buttons are located. The default is system dependent.
-xscrollcommand
Should be specified as a value of the -command option of an xscroll widget. This controls the horizontal scrollbar. The default is system dependent.
-yscrollcommand
Should be specified as a value of the -command option of an yscroll widget. This controls the vertical scrollbar. The default is system dependent.

DESCRIPTION

The Spinbox widget displays a list of strings, one of which is visible at a time. The user can change the visible string by pressing the spin buttons or by typing in the text entry part of the widget. The Spinbox widget is implemented as a combination of an Entry widget and two Button widgets.

VALIDATION

Spinboxes support the same validation options as Entry widgets. See the validation man page for more information.

WIDGET METHODS

cget(option)
Returns the value of the specified option.
configure(?option value? ?option value ...?
Modifies the configuration options of the widget.
get
Returns the current value of the Spinbox.
insert(index, value)
Inserts the given value at the specified index. The index can be one of the following strings: insert, end, or an integer offset.
delete(first, last)
Deletes the characters in the range from first to last. first and last are indices. The default for last is end.
scan_mark(x, y)
Records the position of the mouse cursor. This is used in conjunction with scan_dragto.
scan_dragto(x, y)
Causes the Spinbox to scroll. This method should be called in response to a mouse button press and drag, using the same coordinates that were passed to scan_mark.

DEFAULT BINDINGS

The Spinbox widget has the following default bindings:

[1]
The left mouse button click selects the widget and positions the insertion cursor.
[2]
The left mouse button double-click selects the word at the mouse cursor.
[3]
The left mouse button triple-click selects the entire line.
[4]
The left mouse button quadruple-click selects the entire widget contents.
[5]
The left mouse button click and drag selects a range of characters.
Shift-Select
Extends the selection to the current position of the insertion cursor.
Control-Shift-Space
Adjusts the selection to the current position of the insertion cursor, selecting from the anchor to the insertion cursor if there was not any selection previously.
[13]
Control-/ selects all the text in the Spinbox.
[14]
Control-\ clears any selection in the Spinbox.
F16
The F16 key (labelled Copy on many Sun workstations) or Meta-w copies the selection in the widget to the clipboard, if there is a selection.
F20
The F20 key (labelled Cut on many Sun workstations) or Control-w copies the selection in the widget to the clipboard and deletes the selection. If there is no selection in the widget then these keys have no effect.
F18
The F18 key (labelled Paste on many Sun workstations) or Control-y inserts the contents of the clipboard at the position of the insertion cursor.
Delete
Deletes the selection, if there is one in the Spinbox. If there is no selection, it deletes the character to the right of the insertion cursor.
BackSpace
The BackSpace key and Control-h delete the selection, if there is one in the Spinbox. If there is no selection, it deletes the character to the left of the insertion cursor.
[20]
Control-d deletes the character to the right of the insertion cursor.
[21]
Meta-d deletes the word to the right of the insertion cursor.
[22]
Control-k deletes all the characters to the right of the insertion cursor.
[23]
Control-t reverses the order of the two characters to the right of the insertion cursor.

If the Spinbox is disabled using the -state option, then the Spinbox's view can still be adjusted and text in the Spinbox can still be selected, but no insertion cursor will be displayed and no text modifications will take place.

The behavior of Spinboxes can be changed by defining new bindings for individual widgets or by redefining the class bindings.
