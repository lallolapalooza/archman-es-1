Tk_Main(3) Procedimientos de la biblioteca Tk Tk_Main(3)

NOMBRE

Tk_Main - programa principal para aplicaciones basadas en Tk

SINOPSIS

#include <tk.h>

Tk_Main(argc, argv, appInitProc)

ARGUMENTOS

int argc (entrada)
Número de elementos en argv.
char *argv[] (entrada)
Matriz de cadenas que contiene los argumentos de la línea de comandos. En Windows, cuando se utiliza -DUNICODE, el tipo de parámetro cambia a wchar_t *.
Tcl_AppInitProc *appInitProc (entrada)
Dirección de un procedimiento de inicialización específico de la aplicación. El valor para este argumento suele ser Tcl_AppInit.

DESCRIPCIÓN

Tk_Main actúa como el programa principal para la mayoría de las aplicaciones basadas en Tk. A partir de Tk 4.0, ya no se llama main porque forma parte de la biblioteca Tk y tener una función main en una biblioteca (particularmente una biblioteca compartida) causa problemas en muchos sistemas. Tener main en la biblioteca Tk también dificultaría el uso de Tk en programas C++, ya que los programas C++ deben tener funciones main especiales de C++.

Normalmente, cada aplicación contiene una pequeña función main que no hace nada más que invocar Tk_Main. Tk_Main realiza entonces todo el trabajo de creación y ejecución de una aplicación tipo wish.

Cuando ha terminado su propia inicialización, pero antes de procesar comandos, Tk_Main llama al procedimiento proporcionado por el argumento appInitProc. Este procedimiento proporciona un "gancho" para que la aplicación realice su propia inicialización, como la definición de comandos específicos de la aplicación. El procedimiento debe tener una interfaz que coincida con el tipo Tcl_AppInitProc:

typedef int Tcl_AppInitProc(
        Tcl_Interp *interp);
AppInitProc es casi siempre un puntero a Tcl_AppInit; para más detalles sobre este procedimiento, consulta la documentación de Tcl_AppInit.

Tk_Main funciona de manera muy similar a Tcl_Main. En particular, Tk_Main admite tanto el modo interactivo como el modo de script de inicio, con el nombre de archivo y la codificación de un script de inicio bajo el control de las rutinas Tcl_SetStartupScript y Tcl_GetStartupScript. Sin embargo, llama a Tk_MainLoop después de procesar cualquier script proporcionado, y en usos interactivos, los eventos registrados con Tcl_CreateFileHandler procesan la entrada del usuario.
