Tk__NoteBook(3pm)

Paquete: perl-tk

Licencias: PerlArtistic, GPL, custom

NoteBook(3) Documentación Perl contribuida por el usuario NoteBook(3)

NOMBRE

Tk::NoteBook - Muestra varias ventanas en un espacio limitado con metáfora de cuaderno.

SINOPSIS

use Tk::NoteBook;
...
$w = $frame->NoteBook();
$page1 = $w->add("pagina1", opciones);
$page2 = $w->add("pagina2", opciones);
...
$page2 = $w->add("pagina2", opciones);

DESCRIPCIÓN

El widget NoteBook proporciona una metáfora de cuaderno para mostrar varias ventanas en un espacio limitado. El cuaderno se divide en una pila de páginas, de las cuales solo una se muestra en cualquier momento. Las otras páginas se pueden seleccionar mediante las pestañas visuales en la parte superior del widget. Además, se puede usar la tecla <Tab> para recorrer las páginas. Si se usa -underline, las combinaciones de teclas Alt- también funcionarán.

El widget acepta todas las opciones de un Frame. Además, admite las siguientes opciones:

-geometríadindámica
Si se establece en falso (predeterminado y recomendado), el tamaño del NoteBook coincidirá con el tamaño de la página más grande. De lo contrario, el tamaño coincidirá con el tamaño de la página actual, lo que provocará que el NoteBook cambie de tamaño al seleccionar páginas diferentes de tamaños diferentes.
-ipadx
La cantidad de relleno horizontal interno alrededor de las páginas.
-ipady
La cantidad de relleno vertical interno alrededor de las páginas.
-colordepáginaanterior
El color de fondo de las pestañas y de la página anterior.
-colorsobradeshabilitados
XXX
-colorfoco
El color del borde de foco alrededor de las pestañas.
-fuente
La fuente de las etiquetas de las pestañas.
-fondoinactivo
XXX
-tabpadx
Relleno horizontal alrededor de la etiqueta de la pestaña.
-tabpady
Relleno vertical alrededor de la etiqueta de la pestaña.

MÉTODOS

Se pueden utilizar los siguientes métodos con un objeto NoteBook además de los métodos estándar.

add(nombreDePágina, opciones)
Añade una página con el nombre nombreDePágina al cuaderno. Devuelve un objeto de tipo Frame. Las opciones reconocidas son:
-anclar
Especifica cómo se debe mostrar la información en una pestaña. Debe ser uno de n, ne, e, se, s, sw, w, nw o center.
-mapaDeBits
Especifica un mapa de bits para mostrar en la pestaña de esta página. El mapa de bits se muestra solo si no se especifican las opciones -etiqueta o -imagen.
-imagen
Especifica una imagen para mostrar en la pestaña de esta página. La imagen se muestra solo si no se especifica la opción -etiqueta.
-etiqueta
Especifica la cadena de texto a mostrar en la pestaña de esta página.
-justificar
Cuando hay varias líneas de texto mostradas en una pestaña, esta opción determina la justificación de las líneas.
-comandoCrear
Especifica una función de devolución de llamada que se llamará la primera vez que la página se muestre en la pantalla. Esta opción se puede usar para retrasar la creación del contenido de una página hasta que sea necesario. Puede ser útil en situaciones donde hay un gran número de páginas en un widget NoteBook; con -comandoCrear, no tiene que hacer que el usuario espere hasta que todas las páginas se hayan construido antes de mostrar la primera página.
-comandoElevar
Especifica una función de devolución de llamada que se llamará cada vez que esta página sea elevada por el usuario.
-estado
Especifica si esta página puede ser elevada por el usuario. Debe ser normal o deshabilitado.
-subrayar
Especifica el índice entero de un carácter para subrayar en la pestaña. Esta opción es utilizada por las combinaciones de teclas predeterminadas para implementar el desplazamiento por teclado para botones de menú y entradas de menú. 0 corresponde al primer carácter del texto mostrado en el widget, 1 al siguiente carácter y así sucesivamente.
-longitudDeAjuste
Esta opción especifica la longitud máxima de línea de la cadena de etiqueta en esta pestaña. Si la longitud de línea de la cadena de etiqueta excede esta longitud, se ajustará a la siguiente línea de forma que ninguna línea sea más larga que la longitud especificada. El valor se puede especificar en cualquier forma estándar para distancias de pantalla. Si este valor es menor o igual a 0, no se realiza ningún ajuste: las líneas se dividirán solo en caracteres de nueva línea en el texto.
delete(nombreDePágina)
Elimina la página identificada por nombreDePágina.
pagecget(nombreDePágina, -opción)
Devuelve el valor actual de la opción de configuración dada por -opción en la página dada por nombreDePágina. Opción puede tener cualquiera de los valores aceptados en el método add.
pageconfigure(nombreDePágina, opciones)
Similar a configure para la página indicada por nombreDePágina. Opciones pueden ser cualquiera de las opciones aceptadas por el método add.
pages
Devuelve una lista que consiste en los nombres de todas las páginas actualmente definidas, es decir, aquellas creadas con el método add.
page_widget(nombreDePágina)
Devuelve la página con el nombre nombreDePágina.
raise(nombreDePágina)
Eleva la página identificada por nombreDePágina.
raised()
Devuelve el nombre de la página actualmente elevada.
geometryinfo
Devuelve las dimensiones del área de las pestañas.
identify(x,y)
Identifica el nombre de la página de la pestaña bajo las coordenadas especificadas. Devuelve una cadena vacía si no hay ninguna pestaña.
info("pages")
Devuelve una lista de todas las páginas.
info("focus")
Devuelve el nombre de la página de la pestaña con el foco actual.
info("focusnext")
Devuelve el nombre de la página de la pestaña que recibiría el siguiente foco.
info("focusprev")
Devuelve el nombre de la página de la pestaña que tenía el foco anterior.
info("active")
Devuelve el nombre de la página de la pestaña activa.

ERRORES

Las opciones "-width" y "-height" no funcionan.
