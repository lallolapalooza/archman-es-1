Tk_GetUid(3) Procedimientos de la biblioteca Tk Tk_GetUid(3)

NOMBRE

Tk_GetUid, Tk_Uid - convertir de cadena a identificador único

SINOPSIS

#include <tk.h>

Tk_Uid
Tk_GetUid(cadena)

ARGUMENTOS

char *cadena (entrada)
Cadena para la cual se desea el identificador único correspondiente.

DESCRIPCIÓN

Tk_GetUid devuelve el identificador único correspondiente a cadena. Los identificadores únicos son similares a los átomos en Lisp, y se utilizan en Tk para acelerar comparaciones y búsquedas. Un identificador único (tipo Tk_Uid) es un puntero a cadena y puede usarse en cualquier lugar donde se pueda usar una variable de tipo “char *”. Sin embargo, se garantiza que existe exactamente un identificador único para cada valor de cadena dado. Si Tk_GetUid se llama dos veces, una con la cadena a y otra con la cadena b, y si a y b tienen el mismo valor de cadena (strcmp(a, b) == 0), entonces Tk_GetUid devolverá exactamente el mismo valor Tk_Uid para cada llamada (Tk_GetUid(a) == Tk_GetUid(b)). Esto significa que las variables de tipo Tk_Uid se pueden comparar directamente (x == y) sin tener que llamar a strcmp. Además, el valor de retorno de Tk_GetUid tendrá el mismo valor de cadena que su argumento (strcmp(Tk_GetUid(a), a) == 0).
