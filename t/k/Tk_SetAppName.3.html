Paquete: tk

Licencias: TCL

Tk_SetAppName(3) Procedimientos de la Biblioteca Tk Tk_SetAppName(3)

NOMBRE

Tk_SetAppName - Establece el nombre de una aplicación para los comandos 'send'

SINOPSIS

#include <tk.h>

const char *
Tk_SetAppName(tkwin, name)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token de la ventana en la aplicación. Se utiliza solo para seleccionar una aplicación concreta.
const char *name (entrada)
Nombre bajo el cual registrar la aplicación.

DESCRIPCIÓN

Tk_SetAppName asocia un nombre con una aplicación dada y registra esa asociación en la pantalla que contiene la ventana principal de la aplicación. Después de invocar este procedimiento, otras aplicaciones en la pantalla podrán utilizar el comando send para invocar operaciones en la aplicación. Si name ya está en uso por alguna otra aplicación en la pantalla, se generará un nuevo nombre añadiendo “ #2” a name; si este nombre también está en uso, el número se incrementará hasta encontrar un nombre no utilizado. El valor de retorno del procedimiento es un puntero al nombre realmente utilizado.

Si la aplicación ya tiene un nombre cuando se llama a Tk_SetAppName, el nuevo nombre reemplaza al antiguo.

Tk_SetAppName también añade un comando send al intérprete de la aplicación, que puede ser utilizado para enviar comandos desde esta aplicación a otras en cualquiera de las pantallas donde la aplicación tenga ventanas.

El registro del nombre de la aplicación persiste hasta que el intérprete sea eliminado o el comando send sea eliminado de interp, momento en el cual el nombre se desregistrará automáticamente y la aplicación dejará de ser accesible a través de send. La aplicación puede volver a ser accesible llamando a Tk_SetAppName.

Tk_SetAppName es llamada automáticamente por Tk_Init, por lo que las aplicaciones normalmente no necesitan llamarla explícitamente.

El comando tk appname proporciona acceso a nivel de Tcl a la funcionalidad de Tk_SetAppName.
