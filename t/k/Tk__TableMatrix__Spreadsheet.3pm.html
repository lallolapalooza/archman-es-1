NOMBRE

Tk::TableMatrix::Spreadsheet - Pantalla de tabla con enlaces similares a hojas de cálculo.

SINOPSIS

use Tk;
use Tk::TableMatrix::Spreadsheet;
my $t = $top->Scrolled('Spreadsheet',
  -rows => 21, -cols => 11, 
  -width => 6, -height => 6,
  -titlerows => 1, -titlecols => 1,
  -variable => $arrayVar,
  -selectmode => 'extended',
  -bg => 'white',
);

DESCRIPCIÓN

Tk::TableMatrix::Spreadsheet es un widget derivado de Tk::TableMatrix que implementa algunos enlaces para que el widget resultante se comporte más como una hoja de cálculo.

Enlaces añadidos:

  • Los manejadores de redimensionamiento de filas/columnas aparecen cuando el cursor se coloca sobre una línea de borde de fila/columna en el área del título de la fila/columna.

    Arrastrar estos manejadores redimensionará la fila o la columna. Si se seleccionan varias filas o columnas, el nuevo tamaño de fila/columna se aplicará a todas las filas/columnas seleccionadas.

    Nota: Con el Tk::TableMatrix base, es posible redimensionar las filas/columnas arrastrando sobre cualquier borde de celda. Para que sea más parecido a una hoja de cálculo, Tk::TableMatrix::Spreadsheet tiene como valor predeterminado habilitar el redimensionamiento de filas/columnas solo a través del arrastre del título de fila/columna. Para anular este comportamiento predeterminado, establezca la opción -resizeborder a 'both' al iniciar.

  • Aparece un menú emergente para insertar/eliminar filas/columnas cuando se hace clic con el botón derecho del ratón en las áreas del título de la fila/columna.
  • Las celdas se activan (es decir, el contenido se vuelve editable) solo cuando se hace doble clic en la celda o se presiona la tecla F2. El comportamiento predeterminado de Tk::TableMatrix es que la celda se active con un solo clic.
  • La tecla Escape cancela cualquier cambio realizado en una celda y borra la selección actual.
  • La tecla Intro hace que la celda actual se mueva hacia abajo.
  • La tecla Tab (o Shift-Tab) hace que la celda actual se mueva hacia la derecha (izquierda).
  • La tecla Suprimir eliminará la selección actual, si no hay ninguna celda activada actualmente.
  • El botón del ratón 2 (botón central) pega desde PRIMARY. (Control-v pega desde el portapapeles).

Información Adicional

Los métodos, opciones, etc., del widget se heredan del widget Tk::TableMatrix. Consulte su documentación para obtener información adicional.
