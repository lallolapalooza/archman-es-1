chooseColor(3) Documentación de Contribución de Usuarios de Perl chooseColor(3)

NOMBRE

Tk::chooseColor - muestra un cuadro de diálogo para que el usuario seleccione un color.

SINOPSIS

    $color = $widget->chooseColor?(-opcion=>valor, ...)?;

DESCRIPCIÓN

El método chooseColor se implementa como un envoltorio de perl del comando principal de tk "tk_chooseColor", y $widget se pasa como argumento a la opción oculta -parent. La implementación del tk_chooseColor interno depende de la plataforma; en Win32 es un diálogo nativo, y en UNIX/X11 se implementa en términos de Tk::ColorEditor.

El método chooseColor muestra un cuadro de diálogo para que el usuario seleccione un color. Los siguientes pares de opción-valor son posibles como argumentos de línea de comandos:

-initialcolor=>color
Especifica el color a mostrar en el diálogo de color cuando este se muestra. color debe estar en un formato aceptable para la función Tk_GetColor.
-parent=>$widget
Hace de $widget el padre lógico del diálogo de color. El diálogo de color se muestra encima de la ventana padre.
-title=>titleString
Especifica una cadena de texto para mostrar como título del cuadro de diálogo. Si esta opción no se especifica, se mostrará un título predeterminado.

Si el usuario selecciona un color, tk_chooseColor devolverá el nombre del color en un formato aceptable para Tk_GetColor. Si el usuario cancela la operación, el comando devolverá undef.

EJEMPLO

$widget->configure(-fg => $parent->chooseColor(-initialcolor => 'gray',
                                               -title => "Elige color"));
