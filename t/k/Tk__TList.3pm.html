NOMBRE

Tk::TList - Crear y manipular widgets Tix Tabular List (Lista Tabular Tix)

SINOPSIS

    $tlist = $parent->TList(?opciones?);

SUPER-CLASE

Ninguna.

OPCIONES ESTÁNDAR

-background -borderwidth -class -cursor -foreground -font -height -highlightcolor -highlightthickness -relief -selectbackground -selectforeground -xscrollcommand -yscrollcommand -width

Ver Tk::options para detalles de las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: browsecmd
Clase: BrowseCmd
Opción: -browsecmd
Especifica una función de llamada de perl/Tk que se ejecutará cuando el usuario navegue por las entradas del widget TList.
Nombre: command
Clase: Command
Opción: -command
Especifica la función de llamada de perl/Tk que se ejecutará cuando el usuario active una entrada de la lista en el widget TList. Normalmente, el usuario activa una entrada de la lista haciendo doble clic en ella o presionando la tecla Intro.
Nombre: foreground
Clase: Foreground
Opción: -foreground
Alias: -fg
Especifica el color de primer plano predeterminado para las entradas de la lista.
Nombre: height
Clase: Height
Opción: -height
Especifica la altura deseada para la ventana en número de caracteres.
Nombre: itemType
Clase: ItemType
Opción: -itemtype
Especifica el tipo de elemento de visualización predeterminado para este widget TList. Cuando llame a los métodos insert, se crearán elementos de visualización de este tipo si no se especifica la opción -itemtype.
Nombre: orient
Clase: Orient
Opción: -orient
Especifica el orden de tabulación de las entradas de la lista. Cuando se establece en "vertical", las entradas se organizan en una columna, de arriba abajo. Si las entradas no caben en una sola columna, las entradas restantes pasarán a la siguiente columna, y así sucesivamente. Cuando se establece en "horizontal", las entradas se organizan en una fila, de izquierda a derecha. Si las entradas no caben en una sola fila, las entradas restantes pasarán a la siguiente fila, y así sucesivamente.
Nombre: padX
Clase: Pad
Opción: -padx
El relleno horizontal predeterminado para las entradas de la lista.
Nombre: padY
Clase: Pad
Opción: -padx
El relleno vertical predeterminado para las entradas de la lista.
Nombre: selectBackground
Clase: SelectBackground
Opción: -selectbackground
Especifica el color de fondo para las entradas de lista seleccionadas.
Nombre: selectBorderWidth
Clase: BorderWidth
Opción: -selectborderwidth
Especifica un valor no negativo que indica el ancho del borde 3D que se dibujará alrededor de los elementos seleccionados. El valor puede tener cualquiera de los formatos aceptables para Tk_GetPixels.
Nombre: selectForeground
Clase: SelectForeground
Opción: -selectforeground
Especifica el color de primer plano para las entradas de lista seleccionadas.
Nombre: selectMode
Clase: SelectMode
Opción: -selectmode
Especifica uno de varios estilos para manipular la selección. El valor de la opción puede ser arbitrario, pero las vinculaciones predeterminadas esperan que sea single, browse, multiple o extended; el valor predeterminado es single.
Nombre: sizeCmd
Clase: SizeCmd
Opción: -sizecmd
Especifica una función de llamada de perl/Tk que se llamará cada vez que el widget TList cambie de tamaño. Este comando puede ser útil para implementar funciones de "barras de desplazamiento de usuario cuando sea necesario".
Nombre: state
Clase: State
Opción: -state
Especifica si el comando TList debe reaccionar a las acciones del usuario. Cuando se establece en "normal", el TList reacciona a las acciones del usuario de la manera normal. Cuando se establece en "disabled", el TList solo se puede desplazar, pero sus entradas no se pueden seleccionar ni activar.
Nombre: width
Clase: Width
Opción: -width
Especifica el ancho deseado para la ventana en caracteres.

DESCRIPCIÓN

El método TList crea una nueva ventana (proporcionada por el argumento $widget) y la convierte en un widget TList. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del widget TList, como su cursor y relieve.

El widget TList se puede utilizar para mostrar datos en formato tabular. Las entradas de la lista de un widget TList son similares a las entradas del widget listbox de Tk. Las principales diferencias son (1) el widget TList puede mostrar las entradas de la lista en formato bidimensional y (2) se pueden usar imágenes gráficas, así como múltiples colores y fuentes para las entradas de la lista.

Cada entrada de lista se identifica mediante un índice, que puede tener las siguientes formas:

número
Un entero que indica la posición de la entrada en la lista. 0 significa la primera posición, 1 significa la segunda posición, y así sucesivamente.
end
Indica el final de la lista. Para algunos comandos, esto significa justo después de la última entrada; para otros comandos
significa la última entrada.
@x,y
Indica el elemento que cubre el punto en la ventana del listbox especificado por x e y (en coordenadas de píxeles). Si ningún elemento cubre ese punto, entonces se usa el elemento más cercano a ese punto.

ELEMENTOS DE VISUALIZACIÓN

Cada entrada de lista en un widget TList está asociada con un elemento de visualización. El elemento de visualización determina qué información visual se debe mostrar para esta entrada de lista. Por favor, consulta Tk::DItem para ver una lista de todos los elementos de visualización.

Cuando se crea una entrada de lista mediante el comando insert, el tipo de su elemento de visualización se determina mediante la opción -itemtype pasada a estos comandos. Si se omite -itemtype, entonces por defecto se utiliza el tipo especificado por la opción -itemtype de este widget TList.

MÉTODOS DEL WIDGET

El método TList crea un objeto de widget.

Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

Los siguientes métodos adicionales están disponibles para los widgets TList:

$tlist->anchorSet(índice)
Establece el ancla al elemento de lista identificado por índice. El ancla es el extremo de la selección que se fija mientras se arrastra una selección con el ratón.
$tlist->anchorClear
Elimina el ancla, si la hay, de este widget TList. Esto solo elimina los resaltados circundantes de la entrada ancla y no afecta su estado de selección.
$tlist->delete(desde, ?hasta?)
Elimina una o más entradas de lista entre las dos entradas especificadas por los índices desde y hasta. Si hasta no se especifica, elimina la única entrada especificada por desde.
$tlist->dragsiteSet(índice)
Establece el sitio de arrastre al elemento de lista identificado por índice. El sitio de arrastre se utiliza para indicar la fuente de una acción de arrastrar y soltar. Actualmente, la funcionalidad de arrastrar y soltar aún no se ha implementado en Tix.
$tlist->dragsiteClear
Elimina el sitio de arrastre, si lo hay, de este widget TList. Esto solo elimina los resaltados circundantes de la entrada del sitio de arrastre y no afecta su estado de selección.
$tlist->dropsiteSet(índice)
Establece el sitio de soltar al elemento de lista identificado por índice. El sitio de soltar se utiliza para indicar el destino de una acción de arrastrar y soltar. Actualmente, la funcionalidad de arrastrar y soltar aún no se ha implementado en Tix.
$tlist->dropsiteClear
Elimina el sitio de soltar, si lo hay, de este widget TList. Esto solo elimina los resaltados circundantes de la entrada del sitio de soltar y no afecta su estado de selección.
$tlist->entrycget(índice, opción)
Devuelve el valor actual de la opción de configuración dada por opción para la entrada identificada por índice. Opción puede tener cualquiera de los valores aceptados por el método insert.
$tlist->entryconfigure(índice, ?opción?, ?valor, opción, valor, ...?)
Consulta o modifica las opciones de configuración de la entrada de lista identificada por índice. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para índice (consulta Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica una opción sin ningún valor, el método devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican una o más pares de opción-valor, el comando modifica la(s) opción(es) dada(s) para que tengan el(los) valor(es) dado(s); en este caso, el método devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el método insert. El conjunto exacto de opciones depende del valor de la opción -itemtype pasada al método insert cuando se crea esta entrada de lista.
$tlist->insert(índice, ?opción, valor, ...?)
Crea una nueva entrada de lista en la posición indicada por índice. Las siguientes opciones de configuración se pueden pasar para configurar la entrada de lista:
-itemtype => tipo
Especifica el tipo de elemento de visualización que se mostrará para la nueva entrada de lista. Tipo debe ser un tipo de elemento de visualización válido. Actualmente, los tipos de elementos de visualización disponibles son image, imagetext, text, y $widget. Si no se especifica esta opción, entonces por defecto se utiliza el tipo especificado por la opción -itemtype de este widget TList.
-state => estado
Especifica si esta entrada puede ser seleccionada o invocada por el usuario. Debe ser normal o disabled.
-data => datos
Datos arbitrarios a asociar con la entrada (un valor escalar de Perl).

El método insert acepta opciones de configuración adicionales para configurar el elemento de visualización asociado con esta entrada de lista. El conjunto de opciones de configuración adicionales depende del tipo de elemento de visualización dado por la opción -itemtype. Consulta Tk::DItem para obtener una lista de las opciones de configuración para cada uno de los tipos de elementos de visualización.

$tlist->info(opción, arg, ...)
Consulta información sobre el widget TList. Opción puede ser una de las siguientes:
$tlist->info(anchor, índice)
Devuelve el índice del ancla actual, si la hay, del widget TList. Si el ancla no está establecida, devuelve una cadena vacía.
$tlist->info(dragsite, índice)
Devuelve el índice del sitio de arrastre actual, si lo hay, del widget TList. Si el sitio de arrastre no está establecido, devuelve una cadena vacía.
$tlist->info(dropsite, índice)
Devuelve el índice del sitio de soltar actual, si lo hay, del widget TList. Si el sitio de soltar no está establecido, devuelve una cadena vacía.
$tlist->info(selection)
Devuelve una lista de elementos seleccionados en el widget TList. Si no hay entradas seleccionadas, devuelve una cadena vacía.
$tlist->nearest(x, y)
Dada una coordenada (x,y) dentro de la ventana TList, este comando devuelve el índice del elemento TList más cercano a esa coordenada.
$tlist->see(índice)
Ajusta la vista en TList para que la entrada dada por índice sea visible. Si la entrada ya es visible, el comando no tiene ningún efecto; de lo contrario, TList se desplaza para que el elemento sea visible en el borde al que está más cerca.
$tlist->selection(opción, arg, ...)
Este comando se utiliza para ajustar la selección dentro de un widget TList. Tiene varias formas, dependiendo de opción:
$tlist->selectionClear(?desde?, ?hasta?)
Cuando no se proporcionan argumentos adicionales, anula la selección de todas las entradas de lista en este widget TList. Cuando solo se proporciona desde, solo se anula la selección de la entrada de lista identificada por desde. Cuando se proporcionan tanto desde como hasta, se anula la selección de todas las entradas de lista entre desde y hasta, inclusive, sin afectar el estado de selección de las entradas fuera de ese rango.
$tlist->selectionIncludes(índice)
Devuelve 1 si la entrada de lista indicada por índice está actualmente seleccionada; de lo contrario, devuelve 0.
$tlist->selectionSet(desde, ?hasta?)
Selecciona todas las entradas de lista entre desde y hasta, inclusive, sin afectar el estado de selección de las entradas fuera de ese rango. Cuando solo se proporciona desde, solo se selecciona la entrada de lista identificada por desde.
$tlist->xview(args)
Este comando se utiliza para consultar y cambiar la posición horizontal de la información en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
$tlist->xview
Devuelve una lista que contiene dos elementos. Cada elemento es una fracción real entre 0 y 1; juntos describen el tramo horizontal que es visible en la ventana. Por ejemplo, si el primer elemento es 0.2 y el segundo es 0.6, el 20% de la entrada TList está fuera de la pantalla hacia la izquierda, el 40% medio es visible en la ventana y el 40% de la entrada está fuera de la pantalla hacia la derecha. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -xscrollcommand.
$tlist->xview(índice)
Ajusta la vista en la ventana para que el elemento de lista identificado por índice se alinee con el borde izquierdo de la ventana.
$tlist->xviewMoveto(fracción)
Ajusta la vista en la ventana para que fracción del ancho total de TList esté fuera de la pantalla hacia la izquierda. Fracción debe ser una fracción entre 0 y 1.
$tlist->xviewScroll(número, qué)
Este comando desplaza la vista en la ventana hacia la izquierda o hacia la derecha de acuerdo con número y qué. Número debe ser un entero. Qué debe ser units o pages o una abreviatura de uno de estos. Si qué es units, la vista se ajusta hacia la izquierda o hacia la derecha en número unidades de carácter (el ancho del carácter 0) en la pantalla; si es pages, la vista se ajusta en número pantallas completas. Si número es negativo, se hacen visibles los caracteres más a la izquierda; si es positivo, se hacen visibles los caracteres más a la derecha.
