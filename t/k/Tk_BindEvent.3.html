NOMBRE

Tk_CreateBindingTable, Tk_DeleteBindingTable, Tk_CreateBinding, Tk_DeleteBinding, Tk_GetBinding, Tk_GetAllBindings, Tk_DeleteAllBindings, Tk_BindEvent - invocar scripts en respuesta a eventos X

Tk_DeleteBinding(interp, bindingTable, object, eventString)

Tk_GetBinding(interp, bindingTable, object, eventString)

Tk_GetAllBindings(interp, bindingTable, object)

Tk_DeleteAllBindings(bindingTable, object)

ARGUMENTOS

Tcl_Interp *interp (in)
Intérprete a usar cuando se invocan las vinculaciones en la tabla de vinculaciones. También se usa para devolver resultados y errores de procedimientos de vinculaciones.
Tk_BindingTable bindingTable (in)
Token para la tabla de vinculaciones; debe haber sido devuelto por alguna llamada previa a Tk_CreateBindingTable.
ClientData object (in)
Identifica el objeto con el cual la vinculación está asociada.
const char *eventString (in)
Cadena que describe la secuencia de eventos.
const char *script (in)
Script Tcl a invocar cuando la vinculación se activa.
int append (in)
Valor distinto de cero significa agregar script al script existente de la vinculación, si existe; cero significa reemplazar el script existente con el nuevo.
XEvent *eventPtr (in)
Evento X a coincidir con las vinculaciones en bindingTable.
Tk_Window tkwin (in)
Identificador de cualquier ventana en la pantalla donde ocurrió el evento. Usado para encontrar información relacionada con la pantalla, como mapas de teclado.
int numObjects (in)
Número de identificadores de objeto apuntados por objectPtr.
ClientData *objectPtr (in)
Apunta a un array de identificadores de objeto: las vinculaciones se consideran para cada uno de estos objetos en orden desde el primero hasta el último.

DESCRIPCIÓN

Estas funciones proporcionan un mecanismo general para crear y invocar vinculaciones. Las vinculaciones se organizan en términos de tablas de vinculación. Una tabla de vinculación consiste en una colección de vinculaciones más un historial de eventos recientes. Dentro de una tabla de vinculaciones, las vinculaciones están asociadas con objetos. El significado de un objeto está definido por los clientes del paquete de vinculaciones. Por ejemplo, Tk usa una tabla de vinculaciones para almacenar todas las vinculaciones creadas por el comando bind. Para esta tabla, los objetos son punteros a cadenas como nombres de ventanas, nombres de clases, o otros tags de vinculación como all. Tk también mantiene una tabla de vinculación separada para cada widget de cuadrícula, que gestiona las vinculaciones creadas por el comando bind del widget de cuadrícula; dentro de esta tabla, un objeto es un puntero a la estructura interna de un elemento de cuadrícula o un identificador Tk_Uid que identifica un tag.

La función Tk_CreateBindingTable crea una nueva tabla de vinculaciones y asocia interp con ella (cuando se invocan las vinculaciones en la tabla, los scripts se evaluarán en interp). Tk_CreateBindingTable devuelve un token para la tabla, que debe usarse en llamadas a otras funciones como Tk_CreateBinding o Tk_BindEvent.

Tk_DeleteBindingTable libera todo el estado asociado con una tabla de vinculaciones. Una vez que devuelva el llamador no debe usar el token bindingTable de nuevo.

Tk_CreateBinding agrega una nueva vinculación a una tabla existente. El argumento object identifica el objeto con el cual la vinculación se asocia, y puede ser cualquier valor de una sola palabra. A menudo es un puntero a una cadena o a un objeto de datos. El argumento eventString identifica el evento o secuencia de eventos para la vinculación; vea la documentación del comando bind para una descripción de su formato. script es el script Tcl a evaluar cuando la vinculación se activa. append indica qué hacer si ya existe una vinculación para object y eventString: si append es cero, script reemplaza la script existente; si append es distinto de cero, el nuevo script se agrega al script existente. Tk_CreateBinding devuelve un código de evento X para todos los eventos asociados con las vinculaciones. Esta información puede ser útil para invocar XSelectInput para seleccionar eventos relevantes, o para desactivar la utilización de ciertos eventos en las vinculaciones. Si ocurre un error al crear la vinculación (por ejemplo, eventString refiere a un evento no existente), 0 es devuelto y un mensaje de error queda como resultado del intérprete interp.

Tk_DeleteBinding elimina de bindingTable la vinculación dada por object y eventString, si tal vinculación existe. Tk_DeleteBinding siempre devuelve TCL_OK. En algunos casos puede resetear el resultado del intérprete a valor por defecto.

Tk_GetBinding devuelve un puntero al script asociado con eventString y object en bindingTable. Si no existe tal vinculación, devuelve NULL y un mensaje de error queda como resultado del intérprete interp.

Tk_GetAllBindings devuelve en el resultado de interp una lista de todas las cadenas de evento para las cuales hay vinculaciones en bindingTable asociadas a object. Si no hay vinculaciones para object, el resultado será una cadena vacía.

Tk_DeleteAllBindings elimina todas las vinculaciones en bindingTable asociadas a object.

Tk_BindEvent se llama para procesar un evento. Crea una copia del evento en una lista interna de eventos asociada con la tabla de vinculaciones, luego verifica las vinculaciones que coinciden con el evento. Tk_BindEvent procesa cada objeto apuntado por objectPtr por orden. Para cada objeto, encuentra todas las vinculaciones que coinciden con el historial de eventos actual, selecciona la vinculación más específica usando el mecanismo de prioridad descrito en la documentación del comando bind, y invoca el script para esa vinculación. Si no hay vinculaciones correspondientes para un objeto, el objeto es saltado. Tk_BindEvent continúa procesando todos los objetos, manejo excepciones como errores, break y continue según la documentación del comando bind.
