Tk_GetGC(3) Procedimientos de la biblioteca Tk Tk_GetGC(3)

NOMBRE

Tk_GetGC, Tk_FreeGC - mantener base de datos de contextos gráficos de solo lectura

SINOPSIS

#include <tk.h>

GC
Tk_GetGC(tkwin, valueMask, valuePtr)

Tk_FreeGC(display, gc)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token para la ventana en la que se utilizará el contexto gráfico.
unsigned long valueMask (entrada)
Máscara de bits (como GCForeground o GCStipple) que indica qué campos de *valuePtr son válidos.
XGCValues *valuePtr (entrada)
Puntero a una estructura que describe los valores deseados para el contexto gráfico.
Display *display (entrada)
Pantalla para la que se asignó gc.
GC gc (entrada)
Identificador X del contexto gráfico que ya no es necesario. Debe haber sido asignado por Tk_GetGC.

DESCRIPCIÓN

Tk_GetGC y Tk_FreeGC gestionan una colección de contextos gráficos que está utilizando una aplicación. Los procedimientos permiten compartir contextos gráficos, evitando así la sobrecarga del servidor que se incurriría si se creara un GC separado para cada uso. Tk_GetGC toma argumentos que describen el contexto gráfico deseado y devuelve un identificador X para un GC que se ajusta a la descripción. El contexto gráfico que se devuelve tendrá valores predeterminados en todos los campos no especificados explícitamente por valueMask y valuePtr.

Tk_GetGC mantiene una base de datos de todos los contextos gráficos que ha creado. Siempre que sea posible, una llamada a Tk_GetGC devolverá un contexto gráfico existente en lugar de crear uno nuevo. Este enfoque puede reducir sustancialmente la sobrecarga del servidor, por lo que generalmente se debe preferir Tk_GetGC sobre el procedimiento Xlib XCreateGC, que crea un nuevo contexto gráfico en cada llamada.

Dado que los valores de retorno de Tk_GetGC se comparten, los llamadores nunca deben modificar los contextos gráficos devueltos por Tk_GetGC. Si un contexto gráfico necesita ser modificado dinámicamente, debe crearse llamando a XCreateGC en lugar de Tk_GetGC.

Cuando un contexto gráfico ya no es necesario, se debe llamar a Tk_FreeGC para liberarlo. Debe haber exactamente una llamada a Tk_FreeGC por cada llamada a Tk_GetGC. Cuando un contexto gráfico ya no esté en uso en ninguna parte (es decir, se haya liberado tantas veces como se haya obtenido), Tk_FreeGC lo liberará al servidor X y lo eliminará de la base de datos.
