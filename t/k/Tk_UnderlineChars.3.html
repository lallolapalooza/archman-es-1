Tk_UnderlineChars(3)

Paquete: tk

Licencias: TCL

Tk_MeasureChars(3) Procedimientos de la Biblioteca Tk Tk_MeasureChars(3)

NOMBRE

Tk_MeasureChars, Tk_TextWidth, Tk_DrawChars, Tk_UnderlineChars - rutinas para medir y mostrar cadenas simples de un solo carácter.

SINOPSIS

#include <tk.h>

int
Tk_MeasureChars(tkfont, string, numBytes, maxPixels, flags, lengthPtr)

int
Tk_TextWidth(tkfont, string, numBytes)

Tk_DrawChars(display, drawable, gc, tkfont, string, numBytes, x, y)

Tk_UnderlineChars(display, drawable, gc, tkfont, string, x, y, firstByte, lastByte)

ARGUMENTOS

Tk_Font tkfont (entrada)
Token de la fuente en la que se dibujará o medirá el texto. Debe haber sido devuelto por una llamada anterior a Tk_GetFont.
const char *string (entrada)
Texto a medir o mostrar. No es necesario que termine en nulo. Cualquier carácter meta no imprimible en la cadena (como tabuladores, saltos de línea y otros caracteres de control) se medirá o mostrará de forma dependiente de la plataforma.
int numBytes (entrada)
El número máximo de bytes a considerar al medir o dibujar string. Debe ser mayor o igual que 0.
int maxPixels (entrada)
Si maxPixels es >= 0, especifica la longitud máxima permitida de línea en píxeles. Los caracteres de string solo se procesan hasta que se cubran esta cantidad de píxeles. Si maxPixels es < 0, entonces la longitud de la línea no tiene límites y se ignora el argumento flags.
int flags (entrada)
Varios bits de bandera combinados con OR: TK_PARTIAL_OK significa incluir un carácter siempre que una parte de él quepa en la longitud dada por maxPixels; de lo contrario, un carácter debe caber completamente para ser considerado. TK_WHOLE_WORDS significa detenerse en un límite de palabra, si es posible. Si TK_AT_LEAST_ONE está establecido, significa devolver al menos un carácter incluso si ningún carácter pudiera caber en la longitud dada por maxPixels. Si TK_AT_LEAST_ONE está establecido y TK_WHOLE_WORDS también está establecido, significa que si ni siquiera una palabra cabe en la línea, devuelve las primeras letras de la palabra que sí cabía; si ni siquiera una letra de la palabra cabía, entonces se devolverá la primera letra igualmente.
int *lengthPtr (salida)
Se llena con el número de píxeles ocupados por el número de caracteres devueltos como resultado de Tk_MeasureChars.
Display *display (entrada)
Pantalla en la que dibujar.
Drawable drawable (entrada)
Ventana o pixmap en la que dibujar.
GC gc (entrada)
Contexto gráfico para dibujar caracteres. La fuente seleccionada en este GC debe ser la misma que la tkfont.
int x, y (entrada)
Coordenadas en las que colocar el borde izquierdo de la línea base al mostrar string.
int firstByte (entrada)
El índice del primer byte del primer carácter a subrayar en la string. El subrayado comienza en el borde izquierdo de este carácter.
int lastByte (entrada)
El índice del primer byte del último carácter hasta el cual se dibujará el subrayado. El carácter especificado por lastByte no se subrayará en sí mismo.

DESCRIPCIÓN

Estas rutinas se utilizan para medir y mostrar cadenas simples de una sola fuente y una sola línea. Para medir y mostrar texto justificado de una sola fuente y múltiples líneas, consulte la documentación de Tk_ComputeTextLayout. No existe una interfaz de programación en el núcleo de Tk que admita texto de múltiples fuentes y múltiples líneas; la compatibilidad con ese comportamiento debe basarse en capas más simples. Tenga en cuenta que las interfaces descritas aquí están orientadas a bytes y no a caracteres, por lo que los valores de índice que provienen de scripts de Tcl deben convertirse a desplazamientos de bytes utilizando Tcl_UtfAtIndex y rutinas relacionadas.

Un glifo es la imagen visible de una letra, número o algún otro símbolo. No todos los códigos de caracteres en una fuente determinada tienen un glifo. Caracteres como tabuladores, saltos de línea/retornos y caracteres de control que no tienen glifo son medidos y mostrados por estos procedimientos de manera dependiente de la plataforma; bajo X, se reemplazan con secuencias de escape con barra invertida, mientras que bajo Windows y Macintosh pueden sustituirse por cuadros huecos o sólidos. Consulte la documentación de Tk_ComputeTextLayout para obtener una interfaz de programación que admita la expansión independiente de la plataforma de caracteres de tabulación en columnas y saltos de línea/retornos en texto multilínea.

Tk_MeasureChars se utiliza tanto para calcular la longitud de una cadena dada como para calcular cuántos caracteres de una cadena caben en un espacio dado. El valor de retorno es el número de bytes de string que caben en el espacio especificado por maxPixels sujeto a las condiciones descritas por flags. Si todos los caracteres caben, el valor de retorno será numBytes. *lengthPtr se llena con el ancho calculado, en píxeles, de la porción de la cadena que se midió. Por ejemplo, si el valor de retorno es 5, entonces *lengthPtr se llena con la distancia entre el borde izquierdo de string[0] y el borde derecho de string[4].

Tk_TextWidth es una función envoltorio que proporciona una interfaz más simple a la función Tk_MeasureChars. El valor de retorno es cuánto espacio en píxeles necesita la string dada.

Tk_DrawChars dibuja la string en la ubicación dada en el drawable especificado.

Tk_UnderlineChars subraya el rango dado de caracteres en la string dada. No dibuja los caracteres (que se asume que fueron mostrados previamente por Tk_DrawChars); solo dibuja el subrayado. Este procedimiento se utiliza para subrayar unos pocos caracteres sin tener que construir una fuente subrayada. Para producir texto subrayado nativamente, se debe construir y utilizar la fuente subrayada apropiada.
