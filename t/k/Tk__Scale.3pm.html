NOMBRE

Tk::Scale - Crear y manipular widgets de Scale

SINOPSIS

$escala = $padre->Scale(?opciones?);

OPCIONES ESTÁNDAR

-activebackground -font -highlightthickness -repeatinterval -background -foreground -orient -takefocus -borderwidth -highlightbackground -relief -troughcolor -cursor -highlightcolor -repeatdelay

Ver Tk::options para más detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: bigIncrement
Clase: BigIncrement
Interruptor: -bigincrement
Algunas interacciones con la escala hacen que su valor cambie en incrementos "grandes"; esta opción especifica el tamaño de los incrementos grandes. Si se especifica como 0, los incrementos grandes por defecto son 1/10 del rango de la escala.
Nombre: command
Clase: Command
Interruptor: -command
Especifica el prefijo de una función de callback de perl/Tk para invocar cada vez que el valor de la escala cambie mediante un método. El comando real consiste en esta opción seguida de un espacio y un número real que indica el nuevo valor de la escala.
Nombre: digits
Clase: Digits
Interruptor: -digits
Un entero que especifica cuántos dígitos significativos se conservarán al convertir el valor de la escala a una cadena. Si el número es menor o igual a cero, la escala elige el valor más pequeño que garantiza que cada posición posible del deslizador se imprima como una cadena diferente.
Nombre: from
Clase: From
Interruptor: -from
Un valor real correspondiente al extremo izquierdo o superior de la escala.
Nombre: label
Clase: Label
Interruptor: -label
Una cadena para mostrar como etiqueta de la escala. Para escalas verticales, la etiqueta se muestra justo a la derecha del extremo superior de la escala. Para escalas horizontales, la etiqueta se muestra justo encima del extremo izquierdo de la escala. Si la opción se especifica como una cadena vacía, no se muestra ninguna etiqueta.
Nombre: length
Clase: Length
Interruptor: -length
Especifica la dimensión larga deseada de la escala en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels). Para escalas verticales, esta es la altura de la escala; para escalas horizontales, es el ancho de la escala.
Nombre: resolution
Clase: Resolution
Interruptor: -resolution
Un valor real que especifica la resolución para la escala. Si este valor es mayor que cero, el valor de la escala siempre se redondeará a un múltiplo par de este valor, al igual que las marcas de graduación y los extremos de la escala. Si el valor es menor que cero, no se realiza ningún redondeo. Por defecto es 1 (es decir, el valor será entero).
Nombre: showValue
Clase: ShowValue
Interruptor: -showvalue
Especifica un valor booleano que indica si se debe mostrar o no el valor actual de la escala.
Nombre: sliderLength
Clase: SliderLength
Interruptor: -sliderlength
Especifica el tamaño del deslizador, medido en unidades de pantalla a lo largo de la dimensión larga del deslizador. El valor puede especificarse en cualquiera de las formas aceptables para Tk_GetPixels.
Nombre: sliderRelief
Clase: SliderRelief
Interruptor: -sliderrelief
Especifica el relieve que se utilizará al dibujar el deslizador, como raised (elevado) o sunken (hundido).
Nombre: state
Clase: State
Interruptor: -state
Especifica uno de los tres estados para la escala: normal, active (activo) o disabled (desactivado). Si la escala está desactivada, el valor no se puede cambiar y la escala no se activará. Si la escala está activa, el deslizador se mostrará utilizando el color especificado por la opción activeBackground.
Nombre: tickInterval
Clase: TickInterval
Interruptor: -tickinterval
Debe ser un valor real. Determina el espaciado entre las marcas de graduación numéricas mostradas debajo o a la izquierda del deslizador. Si es 0, no se mostrarán marcas de graduación.
Nombre: to
Clase: To
Interruptor: -to
Especifica un valor real correspondiente al extremo derecho o inferior de la escala. Este valor puede ser menor o mayor que la opción from.
Nombre: variable
Clase: Variable
Interruptor: -variable
Especifica el nombre de una variable global para vincularla con la escala. Cada vez que cambie el valor de la variable, la escala se actualizará para reflejar este valor. Cada vez que se manipule la escala interactivamente, la variable se modificará para reflejar el nuevo valor de la escala.
Nombre: width
Clase: Width
Interruptor: -width
Especifica la dimensión estrecha deseada del canal en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels). Para escalas verticales, este es el ancho del canal; para escalas horizontales, es la altura del canal.

DESCRIPCIÓN

El método Scale crea una nueva ventana (dada por el argumento $widget) y la convierte en un widget de escala. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos de la escala, como sus colores, orientación y relieve. El comando scale devuelve su argumento $widget. En el momento en que se invoca este comando, no debe existir una ventana llamada $widget, pero el padre de $widget debe existir.

Tk::Scale(3pm) Manual Page

NAME

Scale — create and manipulate a scale widget

SYNOPSIS

pack $w -
grid $w -
place $w -

    $w = Tk::Scale->new( %options )
    $w->configure( %options )
    $w->cget( option )
    $w->coords( ?value? )
    $w->get( ?x, y? )
    $w->identify( x, y )
    $w->set( value )

STANDARD OPTIONS

See Tk::options for a complete description of the standard options for the Scale widget.

WIDGET-SPECIFIC OPTIONS

-bigincrement ?val?
Specifies a value that is used for jumping when the mouse button is held down over the trough. If not specified, defaults to 10 times the resolution.
-command ?cmd?
Specifies a command to be called whenever the scale's value changes. The command will be called with the scale's current value as its argument. If variable is also specified, the command is invoked after the variable has been updated.
-digits ?num?
Specifies the number of digits to display for the scale's value. Defaults to 1.
-from ?val?
Specifies the minimum value of the scale. Defaults to 0.
-gradient ?val?
Specifies the number of pixels between tick marks. Defaults to 1.
-length ?val?
Specifies the length of the scale in screen units (e.g., pixels). Defaults to 100 pixels.
-label ?string?
Specifies text to be displayed above the scale (or to the left for horizontal scales). This option is ignored if the showvalue option is false.
-orient ?orient?
Specifies the orientation of the scale, either vertical or horizontal. Defaults to vertical.
-resolution ?val?
Specifies the smallest increment by which the scale's value may be changed. Defaults to 1.
-scale ?val?
Specifies a multiplier to apply to the from and to values. Defaults to 1.
-showvalue ?bool?
Specifies whether to display the scale's current value. Defaults to true.
-sliderrelief ?relief?
Specifies the relief for the slider. Default is raised.
-sliderthickness ?val?
Specifies the width (for vertical scales) or height (for horizontal scales) of the slider. Defaults to 15 pixels.
-tickinterval ?val?
Specifies the interval between tick marks. If this is non-zero, then tick marks are drawn at intervals of this value. Defaults to 0.
-to ?val?
Specifies the maximum value of the scale. Defaults to 1.
-variable ?name?
Specifies a Tcl variable to be linked with the scale's value. If this option is set, the scale's value will be updated whenever the variable changes, and vice versa. The scale will only accept values that are valid according to its from, to, and resolution options.
-width ?val?
Specifies the width of the scale in screen units (e.g., pixels). Defaults to 25 pixels.

DESCRIPTION

A scale widget provides a graphical mechanism for selecting a numerical value. It consists of a rectangular trough and a slider that moves along the trough. The trough corresponds to a range of real values (determined by the from, to, and resolution options), and the position of the slider selects a particular real value. The slider's position (and hence the scale's value) may be adjusted with the mouse or keyboard as described in the "BINDINGS" section below. Whenever the scale's value is changed, a Tcl command is invoked (using the command option) to notify other interested widgets of the change. In addition, the value of the scale can be linked to a Tcl variable (using the variable option), so that changes in either are reflected in the other.

Three annotations may be displayed in a scale widget: a label appearing at the top right of the widget (top left for horizontal scales), a number displayed just to the left of the slider (just above the slider for horizontal scales), and a collection of numerical tick marks just to the left of the current value (just below the trough for horizontal scales). Each of these three annotations may be enabled or disabled using the configuration options.

WIDGET METHODS

The Scale method creates a widget object. This object supports the configure and cget methods described in Tk::options which can be used to enquire and modify the options described above. The widget also inherits all the methods provided by the generic Tk::Widget class.

The following additional methods are available for scale widgets:

$scale->coords(?value?)
Returns a list whose elements are the x and y coordinates of the point along the centerline of the trough that corresponds to value. If value is omitted then the scale's current value is used.
$scale->get(?x, y?)
If x and y are omitted, returns the current value of the scale. If x and y are specified, they give pixel coordinates within the widget; the command returns the scale value corresponding to the given pixel. Only one of x or y is used: for horizontal scales y is ignored, and for vertical scales x is ignored.
$scale->identify(x, y)
Returns a string indicating what part of the scale lies under the coordinates given by x and y. A return value of slider means that the point is over the slider; trough1 means that the point is over the portion of the slider above or to the left of the slider; and trough2 means that the point is over the portion of the slider below or to the right of the slider. If the point isn't over one of these elements, an empty string is returned.
$scale->set(value)
This command is invoked to change the current value of the scale, and hence the position at which the slider is displayed. Value gives the new value for the scale. The command has no effect if the scale is disabled.

BINDINGS

Tk automatically creates class bindings for scales that give them the following default behavior. Where the behavior is different for vertical and horizontal scales, the horizontal behavior is described in parentheses.

[1]
If button 1 is pressed in the trough, the scale's value will be incremented or decremented by the value of the resolution option so that the slider moves in the direction of the cursor. If the button is held down, the action auto-repeats.
[2]
If button 1 is pressed over the slider, the slider can be dragged with the mouse.
[3]
If button 1 is pressed in the trough with the Control key down, the slider moves all the way to the end of its range, in the direction towards the mouse cursor.
[4]
If button 2 is pressed, the scale's value is set to the mouse position. If the mouse is dragged with button 2 down, the scale's value changes with the drag.
[5]
The Up and Left keys move the slider up (left) by the value of the resolution option.
[6]
The Down and Right keys move the slider down (right) by the value of the resolution option.
[7]
Control-Up and Control-Left move the slider up (left) by the value of the bigIncrement option.
[8]
Control-Down and Control-Right move the slider down (right) by the value of the bigIncrement option.
[9]
Home moves the slider to the top (left) end of its range.
[10]
End moves the slider to the bottom (right) end of its range.

If the scale is disabled using the state option then none of the above bindings have any effect.

The behavior of scales can be changed by defining new bindings for individual widgets or by redefining the class bindings.
