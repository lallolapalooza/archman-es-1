NOMBRE

Tk_SetWindowVisual - cambiar las características visuales de una ventana

SINOPSIS

#include <tk.h>

int
Tk_SetWindowVisual(tkwin, visual, depth, colormap)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token de la ventana.
Visual *visual (entrada)
Nuevo tipo visual a utilizar para tkwin.
int depth (entrada)
Número de bits por píxel deseado para tkwin.
Colormap colormap (entrada)
Nuevo mapa de colores para tkwin, que debe ser compatible con visual y depth.

DESCRIPCIÓN

Cuando Tk crea una nueva ventana, le asigna las características visuales (visual, profundidad y mapa de colores) por defecto para su pantalla. Se puede llamar a Tk_SetWindowVisual para cambiarlas. Se debe llamar a Tk_SetWindowVisual antes de que la ventana se haya creado realmente en X (por ejemplo, antes de que se haya invocado Tk_MapWindow o Tk_MakeWindowExist para la ventana). Lo más seguro es llamar a Tk_SetWindowVisual inmediatamente después de llamar a Tk_CreateWindow. Si tkwin ya se ha creado antes de llamar a Tk_SetWindowVisual, devuelve 0 y no realiza ningún cambio; de lo contrario, devuelve 1 para indicar que la operación se completó con éxito.

Nota: No se debe llamar a Tk_SetWindowVisual si solo desea cambiar el mapa de colores de una ventana sin cambiar su visual o profundidad; llame a Tk_SetWindowColormap en su lugar.

PALABRAS CLAVE

colormap, depth, visual
