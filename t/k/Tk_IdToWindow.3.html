NOMBRE

Tk_IdToWindow - Buscar información de ventana de Tk para una ventana X

SINOPSIS

#include <tk.h>

Tk_Window
Tk_IdToWindow(display, window)

ARGUMENTOS

Display *display (entrada)
Pantalla X que contiene la ventana.
Window window (entrada)
ID X de la ventana.

DESCRIPCIÓN

Dado un identificador de ventana X y la pantalla X a la que corresponde, este procedimiento devuelve el identificador Tk_Window correspondiente. Si no hay ningún Tk_Window que corresponda a window, se devuelve NULL.

PALABRASCLAVE

ID de ventana X
