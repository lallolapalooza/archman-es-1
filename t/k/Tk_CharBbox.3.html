ARGUMENTOS

Tk_Font tkfont (entrada)
Fuente a utilizar al construir y mostrar un diseño de texto. El tkfont debe permanecer válido durante la vida útil del diseño de texto. Debe haber sido devuelto por una llamada previa a Tk_GetFont.
const char *string (entrada)
Cadena potencialmente multilínea cuyas dimensiones se van a calcular y almacenar en el diseño de texto. La string debe permanecer válida durante la vida útil del diseño de texto.
int numChars (entrada)
El número de caracteres a considerar de string. Si numChars es menor que 0, se asume que string es terminada en nulo y se utiliza Tcl_NumUtfChars para determinar la longitud de string.
int wrapLength (entrada)
Longitud máxima permitida de línea, en píxeles. Las líneas en string se dividirán automáticamente en límites de palabras y se ajustarán cuando alcancen esta longitud. Si wrapLength es demasiado pequeña incluso para que un solo carácter quepa en una línea, se expandirá para permitir que un carácter quepa en cada línea. Si wrapLength es <= 0, no hay ajuste automático; las líneas tendrán la longitud que necesiten y solo se ajustarán si se encuentra un carácter de nueva línea/retorno.
Tk_Justify justify (entrada)
Cómo justificar las líneas en un diseño de texto multilínea. Los valores posibles son TK_JUSTIFY_LEFT, TK_JUSTIFY_CENTER o TK_JUSTIFY_RIGHT. Si el diseño de texto solo ocupa una sola línea, entonces justify es irrelevante.
int flags (entrada)
Varios bits de bandera OR-ados juntos. TK_IGNORE_TABS significa que los caracteres de tabulación no deben expandirse al siguiente punto de tabulación. TK_IGNORE_NEWLINES significa que los caracteres de nueva línea/retorno no deben provocar un salto de línea. Si se ignoran las tabulaciones o las nuevas líneas/retornos, se tratarán como caracteres normales, midiéndose y mostrándose de forma dependiente de la plataforma, como se describe en Tk_MeasureChars, y no tendrán comportamientos especiales.
int *widthPtr (salida)
Si no es NULL, se rellena con el ancho, en píxeles, de la línea más ancha en el diseño de texto, o el ancho, en píxeles, del cuadro delimitador para el carácter especificado por index.
int *heightPtr (salida)
Si no es NULL, se rellena con la altura total, en píxeles, de todas las líneas en el diseño de texto, o la altura, en píxeles, del cuadro delimitador para el carácter especificado por index.
Tk_TextLayout layout (entrada)
Un token que representa la información de diseño almacenada en caché sobre el fragmento de texto justificado, multilínea y con una sola fuente. Este token se devuelve por Tk_ComputeTextLayout.
Display *display (entrada)
Pantalla en la que dibujar.
Drawable drawable (entrada)
Ventana o pixmap en la que dibujar.
GC gc (entrada)
Contexto gráfico a utilizar para dibujar el diseño de texto. La fuente seleccionada en este GC debe corresponder al tkfont utilizado al construir el diseño de texto.
int x, y (entrada)
Punto, en píxeles, en el que colocar la esquina superior izquierda del diseño de texto cuando se está dibujando, o las coordenadas de un punto (con respecto a la esquina superior izquierda del diseño de texto) para comprobar contra el diseño de texto.
int firstChar (entrada)
El índice del primer carácter a dibujar del diseño de texto dado. El número 0 significa dibujar desde el principio.
int lastChar (entrada)
El índice del último carácter hasta el que dibujar. El carácter especificado por lastChar en sí no se dibujará. Un número menor que 0 significa dibujar todos los caracteres en el diseño de texto.
int underline (entrada)
Índice del único carácter a subrayar en el diseño de texto, o un número menor que 0 para no subrayar.
int index (entrada)
El índice del carácter cuyo cuadro delimitador se desea. El cuadro delimitador se calcula con respecto a la esquina superior izquierda del diseño de texto.
int *xPtr, *yPtr (salida)
Se rellena con la esquina superior izquierda, en píxeles, del cuadro delimitador para el carácter especificado por index. Tanto xPtr como yPtr (o ambos) pueden ser NULL, en cuyo caso el valor correspondiente no se calcula.
int width, height (entrada)
Especifica el ancho y alto, en píxeles, del área rectangular a comparar para intersección contra el diseño de texto.
Tcl_Interp *interp (salida)
El código Postscript que imprimirá el diseño de texto se adjunta al resultado del intérprete interp.

DESCRIPCIÓN

Estas rutinas son para medir y mostrar texto justificado, multilínea y con una sola fuente. Para medir y mostrar cadenas simples, de una sola fuente y una sola línea, consulte la documentación de Tk_MeasureChars. No hay una interfaz de programación en el núcleo de Tk que admita texto multifuente y multilínea; el soporte para ese comportamiento debe construirse sobre capas más simples. Tenga en cuenta que, a diferencia de las rutinas de visualización de texto de nivel inferior, las funciones descritas aquí operan con longitudes e índices orientados a caracteres en lugar de valores orientados a bytes. Consulte la descripción de Tcl_UtfAtIndex para obtener más detalles sobre la conversión entre desplazamientos de caracteres y bytes.

Las rutinas descritas aquí se basan en la interfaz de programación descrita en la documentación de Tk_MeasureChars. Los caracteres de tabulación y los caracteres de nueva línea/retorno pueden ser tratados especialmente por estos procedimientos, pero todos los demás caracteres se pasan al nivel inferior.

Tk_ComputeTextLayout calcula la información de diseño necesaria para mostrar una cadena de texto justificada, multilínea y con una sola fuente y devuelve un token Tk_TextLayout que contiene esta información. Este token se utiliza en llamadas posteriores a procedimientos como Tk_DrawTextLayout, Tk_DistanceToTextLayout y Tk_FreeTextLayout. La string y tkfont utilizados al calcular el diseño deben permanecer válidos durante la vida útil de este token.

Tk_FreeTextLayout se llama para liberar el almacenamiento asociado con layout cuando ya no se necesita. Un layout no debe utilizarse en ningún otro procedimiento de diseño de texto una vez que se haya liberado.

Tk_DrawTextLayout utiliza la información en layout para mostrar una cadena de texto justificada, multilínea y con una sola fuente en la ubicación especificada.

Tk_UnderlineTextLayout utiliza la información en layout para mostrar un subrayado debajo de un carácter individual. Este procedimiento no dibuja el texto, solo el subrayado. Para producir texto subrayado nativamente, se debe construir y utilizar una fuente subrayada. Todos los caracteres, incluidos las tabulaciones, los caracteres de nueva línea/retorno y los espacios al final de las líneas, se pueden subrayar utilizando este método. Sin embargo, el subrayado nunca se dibujará fuera del ancho calculado de layout; el subrayado se detendrá en el borde para cualquier carácter que se extienda parcialmente fuera de layout, y el subrayado no será visible en absoluto para ningún carácter que se encuentre completamente fuera del diseño.

Tk_PointToChar utiliza la información en layout para determinar el carácter más cercano al punto dado. El punto se especifica con respecto a la esquina superior izquierda del layout, que se considera que está ubicada en (0, 0). Cualquier punto cuyo valor y sea menor que 0 se considerará más cercano al primer carácter en el diseño de texto; cualquier punto cuyo valor y sea mayor que la altura del diseño de texto se considerará más cercano al último carácter en el diseño de texto.
