NOMBRE

Tk::DialogBox - crear y manipular una pantalla de diálogo.

SINOPSIS

use Tk::DialogBox
...
$d = $top->DialogBox(-title => "Título", -buttons => ["OK", "Cancelar"]);
$w = $d->add(Widget, args)->pack;
...
$button = $d->Show;

DESCRIPCIÓN

DialogBox es muy similar a Dialog, excepto que permite cualquier widget en el Frame superior. DialogBox crea dos Frames, top e bottom. El Frame inferior muestra todos los Botones especificados, alineados de izquierda a derecha. El Frame superior actúa como un contenedor para todos los demás widgets que se pueden añadir con el método add().

OPCIONES

Las opciones reconocidas por DialogBox son las siguientes:

-title
Especifica el título del DialogBox. Si no se establece, se utiliza el nombre del programa.
-buttons
Los nombres de los botones que se mostrarán en el Frame inferior. Es una referencia a un array de cadenas que contienen el texto que se pondrá en cada Botón. No hay un valor predeterminado. Si no se especifican nombres de botones, no se mostrarán Botones.
-default_button
Especifica el Botón predeterminado que se considera invocado cuando el usuario presiona <Return> en el DialogBox. Este Botón se resalta. Si no se especifica un Botón predeterminado, se utiliza el primer elemento del array cuya referencia se pasa a la opción -buttons como predeterminado.
-cancel_button
Especifica el Botón que se considera invocado cuando el usuario cierra el DialogBox utilizando el botón de cierre del gestor de ventanas. Si no se proporciona la opción -cancel_button, y si solo hay un botón configurado, este botón también se utiliza como botón de cancelación. De lo contrario, no se considera ningún botón como botón de cancelación; en tal caso, Show simplemente devuelve "undef" cuando el usuario cierra el DialogBox.
-command
Una función de retorno de llamada que se ejecuta después de invocar una acción para cerrar el DialogBox, pero antes de restaurar la información de enfoque y captura. El botón seleccionado se pasa como primer argumento.
-focus
Especifica el widget que recibirá el enfoque inicial después de mostrar el DialogBox. Por defecto, el widget -default_button recibe el enfoque inicial.
-showcommand
Una función de retorno de llamada que se ejecuta antes de mostrar el DialogBox y esperar la entrada del usuario. El propio DialogBox se pasa como primer argumento.

MÉTODOS

DialogBox admite solo dos métodos por el momento:

add(widget, opciones)
Añade el widget indicado por widget. widget puede ser el nombre de cualquier widget Tk (estándar o contribuido). opciones son las opciones que acepta el widget. El widget se anuncia como un subwidget de DialogBox. El nombre de widget se convierte a minúsculas y se utiliza como nombre anunciado. Si se crean varias instancias de widget en el DialogBox, solo la última obtendrá el nombre anunciado. add() no realiza automáticamente pack() o grid() de widget en el DialogBox.
Show(?-global?)
Muestra el Diálogo hasta que el usuario active uno de los Botones en el Frame inferior. Si se especifica el tipo de captura -global, entonces Show utiliza esa captura; de lo contrario, utiliza por defecto una captura local. Devuelve el nombre del Botón activado.

El Diálogo real se muestra utilizando el método Popup. Cualquier otra opción proporcionada a Show se pasa a Popup, y puede utilizarse para posicionar el Diálogo en la pantalla. Por favor, lea Tk::Popup para más detalles.

Exit()
Cierra el cuadro de diálogo, emulando un clic en el botón predeterminado.

WIDGETS ANUNCIADOS

top
La referencia al subwidget de la mitad superior del widget DialogBox, el Frame que contiene los widgets añadidos por el método add.
bottom
La referencia al subwidget de la mitad inferior del widget DialogBox, el Frame que contiene los widgets Button.
B_"texto-botón"
Referencias individuales de subwidgets a los Botones del widget DialogBox. El nombre del subwidget es la cadena B_ concatenada con el valor del atributo -text del Botón.

ERRORES

No hay forma de eliminar un widget una vez que ha sido añadido al Frame superior, a menos que acceda al subwidget top y pase por los widgets hijos.

No hay control sobre la apariencia de los Botones en el Frame inferior, ni forma de controlar la ubicación de los dos Frames entre sí.
