NOMBRE

Tk::clipboard - Manipular el portapapeles de Tk

SINOPSIS

$widget->clipboardOpción?(argumentos)?

DESCRIPCIÓN

Este comando proporciona una interfaz al portapapeles de Tk, que almacena datos para su posterior recuperación utilizando el mecanismo de selección. Para copiar datos al portapapeles, se debe llamar a clipboardClear, seguido de una secuencia de una o más llamadas a clipboardAppend. Para asegurar que el portapapeles se actualiza atómicamente, todas las adiciones deben completarse antes de regresar al bucle de eventos.

Los siguientes métodos son compatibles actualmente:

$widget->clipboardClear
Reclama la propiedad del portapapeles en la pantalla de $widget y elimina cualquier contenido previo. Devuelve una cadena vacía.
$widget->clipboardAppend(?-formato=>formato?,?-tipo=>tipo?,?--?,datos)
Añade datos al portapapeles en la pantalla de $widget en la forma dada por tipo con la representación dada por formato y reclama la propiedad del portapapeles en la pantalla de $widget.
Tipo especifica la forma en que se debe devolver la selección (el "objetivo" deseado para la conversión, en terminología ICCCM), y debe ser un nombre de átomo como STRING o FILE_NAME; consulte el Manual de Convenciones de Comunicación entre Clientes para obtener detalles completos. Tipo tiene como valor predeterminado STRING.

El argumento formato especifica la representación que se debe usar para transmitir la selección al solicitante (la segunda columna de la Tabla 2 del ICCCM), y tiene como valor predeterminado STRING. Si formato es STRING, la selección se transmite como caracteres ASCII de 8 bits. Consulte la documentación de Tk::Selection para obtener una explicación de lo que sucede si formato no es STRING. Tenga en cuenta que los argumentos pasados a clipboardAppend se concatenan antes de la conversión, por lo que el llamador debe tener cuidado de asegurar el espaciado apropiado entre los límites de las cadenas. Todos los elementos añadidos al portapapeles con el mismo tipo deben tener el mismo formato.

Se puede especificar un argumento -- para marcar el final de las opciones: el siguiente argumento siempre se usará como datos. Esta característica puede ser conveniente si, por ejemplo, datos comienza con un -.

$widget->clipboardGet( ?-tipo? );
Recupera datos del portapapeles en la pantalla de widget. -tipo especifica la forma en que se deben devolver los datos y debe ser un nombre de átomo como STRING o FILE_NAME. El tipo tiene como valor predeterminado STRING. Este comando es equivalente a "SelectionGet( -selection => 'CLIPBOARD' )".
