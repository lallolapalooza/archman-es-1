NOMBRE

Tk::Listbox - Crear y manipular widgets Listbox

SINAPSIS

$listbox = $parent->Listbox(?opciones?);

OPCIONES ESTANDAR

-background -borderwidth -cursor -disabledforeground -exportselection -font -foreground -height -highlightbackground -highlightcolor -highlightthickness -offset -relief -selectbackground -selectborderwidth -selectforeground -setgrid -state -takefocus -tile -width -xscrollcommand -yscrollcommand

Ver Tk::options para detalles de las opciones estándar.

OPCIONES ESPECIFICAS DEL WIDGET

Nombre: activeStyle
Clase: ActiveStyle
Cambio: -activestyle
Especifica el estilo con el que se debe dibujar el elemento activo. Debe ser uno de dotbox (mostrar un anillo de foco alrededor del elemento activo), none (ninguna indicación especial del elemento activo) o underline (subrayar el elemento activo). El valor predeterminado es underline.
Nombre: height
Clase: Height
Cambio: -height
Especifica la altura deseada para la ventana, en líneas. Si es cero o menos, entonces la altura deseada para la ventana se hace lo suficientemente grande como para contener todos los elementos en el listbox.
Nombre: listVariable
Clase: Variable
Cambio: -listvariable
Lo siguiente solo está parcialmente implementado en Perl/Tk:

Especifica la referencia de una variable. El valor de la variable es un array que se mostrará dentro del widget; si el valor de la variable cambia, el widget se actualizará automáticamente para reflejar el nuevo valor. Los intentos de asignar una variable con un valor de lista no válido a -listvariable causarán un error. Los intentos de anular una variable en uso como -listvariable fallarán pero no generarán un error.

Nombre: selectMode
Clase: SelectMode
Cambio: -selectmode
Especifica uno de varios estilos para manipular la selección. El valor de la opción puede ser arbitrario, pero los enlaces predeterminados esperan que sea single, browse, multiple o extended; el valor predeterminado es browse.
Nombre: state
Clase: State
Cambio: -state
Especifica uno de dos estados para el listbox: normal o disabled. Si el listbox está deshabilitado, no se pueden insertar ni eliminar elementos, los elementos se dibujan en el color -disabledforeground, y la selección no se puede modificar y no se muestra (aunque la información de selección se conserva).
Nombre: width
Clase: Width
Cambio: -width
Especifica el ancho deseado para la ventana en caracteres. Si la fuente no tiene un ancho uniforme, se utiliza el ancho del carácter ``0'' para traducir de unidades de caracteres a unidades de pantalla. Si es cero o menos, entonces el ancho deseado para la ventana se hace lo suficientemente grande como para contener todos los elementos en el listbox.

DESCRIPCION

El método Listbox crea una nueva ventana (proporcionada por el argumento $widget) y la convierte en un widget listbox. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del listbox como sus colores, fuente, texto y relieve. El comando listbox devuelve su argumento $widget. En el momento en que se invoca este comando, no debe existir una ventana llamada $widget, pero el padre de $widget debe existir.

Un listbox es un widget que muestra una lista de cadenas, una por línea. Cuando se crea por primera vez, un nuevo listbox no tiene elementos. Los elementos pueden agregarse o eliminarse utilizando los métodos descritos a continuación. Además, uno o más elementos pueden seleccionarse como se describe a continuación. Si un listbox está exportando su selección (ver opción exportSelection), entonces observará los protocolos estándar de X11 para manejar la selección. Las selecciones del listbox están disponibles como tipo STRING; el valor de la selección será el texto de los elementos seleccionados, con saltos de línea separando los elementos.

No es necesario que todos los elementos se muestren en la ventana del listbox a la vez; los comandos descritos a continuación pueden usarse para cambiar la vista en la ventana. Los listboxes permiten desplazarse en ambas direcciones utilizando las opciones estándar xScrollCommand y yScrollCommand. También admiten escaneo, como se describe a continuación.

INDICES

Muchos de los métodos para listboxes toman uno o más índices como argumentos. Un índice especifica un elemento particular del listbox, de cualquiera de las siguientes maneras:

número
Especifica el elemento como un índice numérico, donde 0 corresponde al primer elemento en el listbox.
active
Indica el elemento que tiene el cursor de ubicación. Este elemento se mostrará subrayado cuando el listbox tenga el foco del teclado, y se especifica con el método activate.
anchor
Indica el punto de anclaje para la selección, que se establece con el método selection anchor.
end
Indica el final del listbox. Para la mayoría de los comandos, esto se refiere al último elemento en el listbox, pero para algunos comandos como index e insert se refiere al elemento justo después del último.
@x,y
Indica el elemento que cubre el punto en el listbox especificado por x e y (en coordenadas de píxeles). Si ningún elemento cubre ese punto, se utiliza el elemento más cercano a ese punto.

En las descripciones de los métodos a continuación, los argumentos llamados index, first y last siempre contienen índices de texto en una de las formas anteriores.

MÉTODOS DEL WIDGET

El método Listbox crea un objeto widget. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

Los siguientes métodos adicionales están disponibles para los widgets listbox:

$listbox->activate(index)
Establece el elemento activo en el indicado por index. Si index está fuera del rango de elementos en el listbox, se activa el elemento más cercano. El elemento activo se dibuja subrayado cuando el widget tiene el foco de entrada, y su índice se puede recuperar con el índice active.
$listbox->bbox(index)
Devuelve una lista de cuatro números que describen el cuadro delimitador del texto en el elemento dado por index. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del cuadro delimitador del texto del elemento, y los dos últimos elementos dan el ancho y la altura del cuadro delimitador en píxeles. Si el elemento dado por index no está actualmente visible en la ventana, se devuelve una cadena vacía.

per-esquina inferior izquierda del área de la pantalla cubierta por el texto (especificado en píxeles relativos al widget) y los dos últimos elementos dan el ancho y alto del área, en píxeles. Si ninguna parte del elemento dado por índice es visible en la pantalla, o si índice se refiere a un elemento inexistente, entonces el resultado es una cadena vacía; si el elemento es parcialmente visible, el resultado da toda el área del elemento, incluyendo cualquier parte que no sea visible.
$listbox->curselection
Devuelve una lista que contiene los índices numéricos de todos los elementos en el listbox que están actualmente seleccionados. Si no hay ningún elemento seleccionado en el listbox, se devuelve una cadena vacía.
$listbox->delete(first, ?last?)
Elimina uno o más elementos del listbox. first y last son índices que especifican el primer y último elemento en el rango a eliminar. Si last no se especifica, toma el valor de first, es decir, se elimina un solo elemento.
$listbox->get(first, ?last?)
Si se omite last, devuelve el contenido del elemento del listbox indicado por first, o una cadena vacía si first se refiere a un elemento inexistente. Si se especifica last, el comando devuelve una lista cuyos elementos son todos los elementos del listbox entre first y last, inclusive. Ambos, first y last, pueden tener cualquiera de las formas estándar para los índices.
$listbox->index(index)
Devuelve el valor del índice entero que corresponde a index. Si index es end, el valor de retorno es un recuento del número de elementos en el listbox (no el índice del último elemento).
$listbox->insert(index, ?element, element, ...?)
Inserta cero o más elementos nuevos en la lista justo antes del elemento dado por index. Si index se especifica como end, los nuevos elementos se agregan al final de la lista. Devuelve una cadena vacía.
$listbox->itemcget(index, option)
Devuelve el valor actual de la opción de configuración del elemento dado por option. La opción puede tener cualquiera de los valores aceptados por el comando itemconfigure del listbox.
$listbox->itemconfigure(index, ?option, value, option, value, ...?)
Consulta o modifica las opciones de configuración de un elemento en el listbox. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para el elemento (ver Tk_ConfigureInfo para información sobre el formato de esta lista). Si se especifica una opción sin valor, el comando devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican uno o más pares opción-valor, el comando modifica las opciones del widget dadas para que tengan los valores dados; en este caso, el comando devuelve una cadena vacía. Las siguientes opciones son actualmente compatibles con los elementos:
-background => color
Color especifica el color de fondo a usar al mostrar el elemento. Puede tener cualquiera de las formas aceptadas por Tk_GetColor.
-foreground => color
Color especifica el color de primer plano a usar al mostrar el elemento. Puede tener cualquiera de las formas aceptadas por Tk_GetColor.
-selectbackground => color
Color especifica el color de fondo a usar al mostrar el elemento mientras está seleccionado. Puede tener cualquiera de las formas aceptadas por Tk_GetColor.
-selectforeground => color
Color especifica el color de primer plano a usar al mostrar el elemento mientras está seleccionado. Puede tener cualquiera de las formas aceptadas por Tk_GetColor.
$listbox->nearest(y)
Dado una coordenada y dentro de la ventana del listbox, este comando devuelve el índice del elemento del listbox (visible) más cercano a esa coordenada y.
$listbox->scan(option, args)
Este comando se utiliza para implementar escaneo en listboxes. Tiene dos formas, dependiendo de option:
$listbox->scanMark(x, y)
Registra x e y y la vista actual en la ventana del listbox; se utiliza junto con los comandos posteriores de scan dragto. Típicamente, este comando se asocia con la pulsación de un botón del ratón en el widget. Devuelve una cadena vacía.
$listbox->scanDragto(x, y.)
Este comando calcula la diferencia entre sus argumentos x e y y los argumentos x e y del último comando scan mark para el widget. Luego, ajusta la vista en 10 veces la diferencia de coordenadas. Este comando se asocia típicamente con eventos de movimiento del ratón en el widget, para producir el efecto de arrastrar la lista a alta velocidad a través de la ventana. El valor de retorno es una cadena vacía.
$listbox->see(index)
Ajusta la vista en el listbox para que el elemento dado por index sea visible. Si el elemento ya es visible, el comando no tiene efecto; si el elemento está cerca de un borde de la ventana, el listbox se desplaza para poner el elemento a la vista en el borde; de lo contrario, el listbox se desplaza para centrar el elemento.
$listbox->selection(option, arg)
Este comando se utiliza para ajustar la selección dentro de un listbox. Tiene varias formas, dependiendo de option:
$listbox->selectionAnchor(index)
Establece el ancla de selección en el elemento dado por index. Si index se refiere a un elemento inexistente, se utiliza el elemento más cercano. El ancla de selección es el extremo de la selección que se fija mientras se arrastra una selección con el ratón. El índice anchor puede usarse para referirse al elemento ancla.
$listbox->selectionClear(first, ?last?)
Si alguno de los elementos entre first y last (inclusive) están seleccionados, se anulan. El estado de selección no cambia para los elementos fuera de este rango.
$listbox->selectionIncludes(index)
Devuelve 1 si el elemento indicado por index está actualmente seleccionado, 0 si no lo está.
$listbox->selectionSet(first, ?last?)
Selecciona todos los elementos en el rango entre first y last, inclusive, sin afectar el estado de selección de los elementos fuera de ese rango.
$listbox->size
Devuelve una cadena decimal que indica el número total de elementos en el listbox.
$listbox->xview(args)
Este comando se utiliza para consultar y cambiar la posición horizontal de la información en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
$listbox->xview
Devuelve una lista que contiene dos elementos. Cada elemento es una fracción real entre 0 y 1; juntos describen el tramo horizontal que es visible en la ventana. Por ejemplo, si el primer elemento es .2 y el segundo es .6, el 20% del texto del listbox está fuera de la pantalla hacia la izquierda, el 40% central es visible en la ventana, y el 40% del texto está fuera de la pantalla hacia la derecha. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -xscrollcommand.
$listbox->xview(index)
Ajusta la vista en la ventana para que la posición del carácter dada por index se muestre en el borde izquierdo de la ventana. Las posiciones de los caracteres se definen por el ancho del carácter 0.
$listbox->xviewMoveto( fraction );
Ajusta la vista en la ventana para que fraction del ancho total del texto del listbox esté fuera de la pantalla hacia la izquierda. fraction debe ser una fracción entre 0 y 1.
$listbox->xviewScroll( number, what );
Este comando desplaza la vista en la ventana hacia la izquierda o hacia la derecha según number y what. Number debe ser un entero. What debe ser units o pages o una abreviatura de uno de estos. Si what es units, la vista se ajusta hacia la izquierda o hacia la derecha en number unidades de caracteres (el ancho del carácter 0) en la pantalla; si es pages, la vista se ajusta en number pantallas completas. Si number es negativo, se hacen visibles los caracteres más a la izquierda; si es positivo, se hacen visibles los caracteres más a la derecha.
$listbox->yview(?args?)
Este comando se utiliza para consultar y cambiar la posición vertical del texto en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
$listbox->yview
Devuelve una lista que contiene dos elementos, ambos fracciones reales entre 0 y 1. El primer elemento da la posición del elemento del listbox en la parte superior de la ventana, en relación con el listbox en su conjunto (0.5 significa que está a mitad del listbox, por ejemplo). El segundo elemento da la posición del elemento del listbox justo después del último en la ventana, en relación con el listbox en su conjunto. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -yscrollcommand.
$listbox->yview(index)
Ajusta la vista en la ventana para que el elemento dado por index se muestre en la parte superior de la ventana.
$listbox->yviewMoveto( fraction );
Ajusta la vista en la ventana para que el elemento dado por fraction aparezca en la parte superior de la ventana. Fraction es una fracción entre 0 y 1; 0 indica el primer elemento en el listbox, 0.33 indica el elemento que está a un tercio del camino a través del listbox, y así sucesivamente.
$listbox->yviewScroll( number, what );
Este comando ajusta la vista en la ventana hacia arriba o hacia abajo según number y what. Number debe ser un entero. What debe ser units o pages. Si what es units, la vista se ajusta hacia arriba o hacia abajo en number líneas; si es
páginas luego la vista se ajusta según el número de cuadernos de pantalla. Si el número es negativo, los elementos anteriores se vuelven visibles; si es positivo, los elementos posteriores se vuelven visibles.

ENCUADERNACIONES PREDETERMINADAS

Tk crea automáticamente encuadernaciones de clase para listas que proporcionan el mismo efecto que el comportamiento Motif. Gran parte del comportamiento de una lista se determina por su opción selectMode, que selecciona uno de los cuatro modos de manejo de selección.

Si el modo de selección es single o browse, se puede seleccionar como máximo un elemento en la lista. En ambos modos, hacer clic en el botón 1 de un elemento lo selecciona y deselecciona cualquier otro elemento seleccionado. En el modo browse también es posible desplazar la selección con el botón 1.

Si el modo de selección es multiple o extended, se pueden seleccionar cualquier número de elementos, incluidos rangos discontinuos. En el modo multiple, hacer clic en el botón 1 de un elemento intercambia su estado de selección sin afectar a otros elementos. En el modo extended, presionar el botón 1 de un elemento lo selecciona, deselecciona todos los demás y establece el ancla en el elemento bajo el ratón; al desplazar el ratón con el botón 1 presionado, el rango de selección se extiende para incluir todos los elementos entre el ancla y el elemento bajo el ratón, incluido este último.

La mayoría de los usuarios probablemente querrán usar el modo browse para selecciones únicas y el modo extended para selecciones múltiples; los otros modos parecen útiles solo en situaciones especiales.

Cualquier cambio en la selección de la lista genera el evento virtual <<ListboxSelect>>. Es más fácil vincularse a este evento para ser alertado de cualquier cambio en la selección de la lista.

Además del comportamiento descrito anteriormente, el siguiente comportamiento adicional está definido por las encuadernaciones predeterminadas:

[1]
En el modo extended, el rango seleccionado puede ajustarse presionando el botón 1 con la tecla Shift activada: esto modifica la selección para que consista en los elementos entre el ancla y el elemento bajo el ratón, incluido este último. El extremo no anclado de esta nueva selección también puede ser arrastrado con el botón presionado.
[2]
En el modo extended, presionar el botón 1 con la tecla Control activada inicia una operación de alternancia: el ancla se establece en el elemento bajo el ratón y su estado de selección se invierte. El estado de selección de otros elementos no se cambia. Si el ratón se desplaza con el botón 1 presionado, el estado de selección de todos los elementos entre el ancla y el elemento bajo el ratón se establece para que coincida con el estado del elemento anclado; el estado de selección de todos los demás elementos se mantiene como antes de la operación de alternancia.
[3]
Si el ratón sale del área de la ventana de la lista con el botón 1 presionado, la ventana se desplaza hacia afuera del ratón, mostrando información que antes estaba fuera de vista en el lado del ratón. El desplazamiento continúa hasta que el ratón vuelva a entrar en la ventana, se suelte el botón o se alcance el final de la lista.
[4]
El botón 2 puede usarse para escanear. Si se presiona y se arrastra sobre la lista, el contenido de la lista se desplaza rápidamente en la dirección del movimiento del ratón.
[5]
Si se presiona la tecla Up o Down, el cursor activo (elemento seleccionado) se desplaza hacia arriba o hacia abajo un elemento. Si el modo de selección es browse o extended, el nuevo elemento activo también se selecciona y todos los demás elementos se deseleccionan. En el modo extended, el nuevo elemento activo se convierte en el ancla de selección.
[6]
En el modo extended, Shift-Up y Shift-Down desplazan el cursor activo (elemento seleccionado) hacia arriba o hacia abajo un elemento y también extienden la selección a ese elemento de manera similar a arrastrar con el botón 1.
[7]
Las teclas Left y Right desplazan la vista de la lista hacia la izquierda y derecha por el ancho del carácter 0. Control-Left y Control-Right desplazan la vista de la lista hacia la izquierda y derecha por el ancho de la ventana. Control-Prior y Control-Next también desplazan hacia la izquierda y derecha por el ancho de la ventana.
[8]
Las teclas Prior y Next desplazan la vista de la lista hacia arriba y abajo por una página (la altura de la ventana).
[9]
Las teclas Home y End desplazan la vista de la lista horizontalmente hacia los bordes izquierdo y derecho.
[10]
Control-Home establece el cursor activo en el primer elemento de la lista, lo selecciona y deselecciona todo lo demás en la lista.
[11]
Control-End establece el cursor activo en el último elemento de la lista, lo selecciona y deselecciona todo lo demás en la lista.
[12]
En el modo extended, Control-Shift-Home extiende la selección al primer elemento de la lista y Control-Shift-End extiende la selección al último elemento.
[13]
En el modo multiple, Control-Shift-Home mueve el cursor activo al primer elemento de la lista y Control-Shift-End mueve el cursor activo al último elemento.
[14]
La barra espaciadora y el botón Select realizan una selección en el cursor activo (elemento seleccionado) de manera similar a como si se hubiera presionado el botón 1 sobre ese elemento.
[15]
En el modo extended, Control-Shift-space y Shift-Select extienden la selección al elemento activo de manera similar a como si se hubiera presionado el botón 1 con la tecla Shift activada.
[16]
En el modo extended, la tecla Escape cancela la selección más reciente y restaura todos los elementos en el rango seleccionado a su estado anterior.
[17]
Control-barra inclinada selecciona todo el widget, excepto en los modos single y browse, donde selecciona el elemento activo y deselecciona todo lo demás.
[18]
Control-barra invertida deselecciona todo el widget, excepto en el modo browse, donde no tiene efecto.
[19]
La tecla F16 (etiquetada como Copy en muchos equipos Sun) o Meta-w copia la selección del widget al portapapeles, si existe una selección. El comportamiento de las listas puede cambiarse definiendo nuevas encuadernaciones para widgets individuales o redefiniendo las encuadernaciones predeterminadas.

INTERFAZ VINCULADA

El widget Tk::Listbox también puede vincularse a una variable escalar o de matriz, con un comportamiento diferente según el tipo de variable, con los siguientes comandos de vinculación:

use Tk;
my ( @array, $scalar, $other );
my %options = ( ReturnType => "index" );
my $MW = MainWindow->new();
my $lbox = $MW->Listbox()->pack();
my @list = ( "a", "b", "c", "d", "e", "f" );
$lbox->insert('end', @list );
tie @array, "Tk::Listbox", $lbox
tie $scalar, "Tk::Listbox", $lbox;
tie $other, "Tk::Listbox", $lbox, %options;

Actualmente solo se implementa un modificador, una bandera de tres posiciones para variables vinculadas, "ReturnType" que puede tener valores "element", "index" o "both". El valor predeterminado es "element".

Matrices Vinculadas
Si vinculas una matriz a la lista, puedes manipular los elementos actuales de la lista de manera similar a una matriz normal, por ejemplo:
print @array;
push(@array, @list);
my $popped = pop(@array);
my $shifted = shift(@array);
unshift(@array, @list);
delete $array[$index];
print $string if exists $array[$i];
@array = ();
splice @array, $offset, $length, @list

El método delete se implementa de manera ligeramente diferente a la implementación estándar de la matriz. En lugar de establecer el elemento en ese índice a undef, lo elimina físicamente del Listbox. Esto tiene el efecto de cambiar los índices de la matriz, por lo que si deseas eliminar elementos no contiguos de la lista, debes ordenar la lista y aplicar la función delete, por ejemplo:

my @list = ( 1, 2, 4, 12, 20 );
my @remove = reverse sort { $a <=> $b } @list;
delete @array[@remove];

Esto elimina de forma segura los índices 20, 12, 4, 2 y 1 de la lista, sin problemas. También se debe mencionar que una advertencia similar se aplica al método splice (que normalmente se usa en este contexto para realizar la misma tarea).

Escalares Vinculados
Al igual que con las matrices vinculadas, si vinculas un escalar a la lista puedes recuperar los elementos seleccionados en la lista como una matriz referenciada por el escalar, por ejemplo:
my @list = ( "a", "b", "c", "d", "e", "f" );
$lbox->insert('end', sort @list );
$lbox->selectionSet(1);

inserta @list como elementos en una lista existente y selecciona el elemento en la posición 1, que es "b". Si luego

print @$selected;

esto devolverá los elementos seleccionados actualmente, en este caso "b".

Sin embargo, si se pasa el argumento "index" al vincular la lista a un escalar con el valor "index", se devolverán los índices de los elementos seleccionados en lugar de los elementos mismos, es decir, "1". Esto puede ser útil cuando se manipulan tanto el contenido como los elementos seleccionados simultáneamente en la lista.

Es importante destacar que si se especifica el valor "both" en el hash de opciones, el escalar no estará vinculado a una matriz, sino a un hash con claves siendo los índices y valores siendo los elementos en esos índices.

También puedes manipular los elementos seleccionados usando el escalar. Asignando el escalar a una referencia de matriz selecciona cualquier elemento que coincida con los elementos de la lista, los elementos de la matriz que no coincidan se ignoran, por ejemplo:

my @list = ( "a", "b", "c", "d", "e", "f" );
$lbox->insert('end', sort @list );
$lbox->selectionSet(1);

inserta la matriz @list en una lista existente y selecciona el elemento en la posición 1, es decir, "b".

@array = ( "a", "b", "f" );
$selected = \@array;

selecciona los elementos "a", "b" y "f" en la lista.

TIED INTERFACE

ReturnValue

The methods return_value and index (of the Tk::Listbox widget) are tied. This means that when you assign to the tied scalar, the listbox will be updated with the new contents. When you read from the scalar, the contents of the listbox will be returned.

The following options are available for the tied scalar:

Returnstyle

This option controls what is returned when the tied scalar is read. It can be one of:

"index"

Returns a reference to an array containing the currently selected item(s) in the listbox. For a single selection listbox, this will be an array reference with zero or one element. For a multiple selection listbox, it will be an array reference with zero or more elements.

"value"

Returns a reference to an array containing the values of the currently selected item(s) in the listbox. This is only valid if the listbox was populated with an array reference using the set() method.

"both"

Returns a reference to a hash where the keys are the indices of the selected items and the values are the corresponding values from the listbox. This is only valid if the listbox was populated with an array reference using the set() method.

The default value is "index".

ReturnType

This option controls the type of data returned when the tied scalar is read. It can be one of:

"index"

Returns a reference to an array of the indices of the selected items.

"value"

Returns a reference to an array of the values of the selected items.

"both"

Returns a reference to a hash where keys are indices and values are the corresponding values of the selected items.

The default value is "index".

If we are returning "both", i.e. the tied scalar points to a hash, both key and value must match, e.g.

%hash = ( 0 => "a", 1 => "b", 5 => "f" );
$selected = \%hash;

would have the same effect as the previous examples.

It should be noted that, despite being a reference to an array (or possibly a has), you still can not copy the tied variable without it being untied, instead you must pass a reference to the tied scalar between subroutines.
