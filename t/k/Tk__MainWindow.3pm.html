MainWindow(3) Documentación de Perl aportada por el usuario MainWindow(3)

NOMBRE

Tk::MainWindow - Raíz de un árbol de widgets

SINOPSIS

use Tk;
my $mw = MainWindow->new( ... opciones ... );
my $this = $mw->ThisWidget -> pack ;
my $that = $mw->ThatWidget;
...
MainLoop;

DESCRIPCIÓN

Las aplicaciones Perl/Tk (que tienen ventanas asociadas) crean una o más MainWindows que actúan como contenedores y padres de los demás widgets.

Tk::MainWindow es un tipo especial de widget Toplevel. Es la raíz de un árbol de widgets. Por lo tanto "$mw->Parent" devuelve "undef".

El título por defecto de una MainWindow es el nombre base del script (en realidad, el nombre de la Clase utilizado para la búsqueda de opciones, es decir, el nombre base con mayúscula inicial) o 'Ptk' como valor de reserva. Si se crea más de una MainWindow o se ejecutan varias instancias del script al mismo tiempo, se añade la cadena " #n" donde el número "n" se establece para obtener un valor único.

A diferencia del wish estándar de Tcl/Tk, perl/Tk permite crear varias MainWindows. Cuando la *última* MainWindow se destruye, el bucle de eventos de Tk se cierra (el bucle de eventos se entra con la llamada a "MainLoop"). Varios recursos (enlaces, fuentes, imágenes, colores) se mantienen o almacenan en caché para cada MainWindow, por lo que cada MainWindow consume más recursos que un Toplevel. Sin embargo, múltiples MainWindows pueden tener sentido cuando el usuario puede destruirlas de forma independiente.

MÉTODOS

Puedes aplicar todos los métodos que acepta un widget Toplevel.

El método $w->MainWindow aplicado a cualquier widget devolverá la MainWindow a la que pertenece el widget (la MainWindow pertenece a sí misma).

FALTANTE

La documentación está incompleta. Aquí hay *algunos* elementos faltantes que deberían explicarse con más detalle:

  • El nuevo mecanismo para MainWindows es ligeramente diferente a otros widgets.
  • No hay explicación sobre qué recursos están vinculados a una MainWindow (por ejemplo, ClassInit hecho por MainWindow)
  • Paso de opciones de línea de comandos para anular o aumentar los argumentos del método "new" (ver Tk::CmdLine).
