NOMBRE

Tk::exit - Termina la aplicación

SINOPSIS

use Tk qw(exit);
...
B<exit>?(I<código de retorno>)?;

DESCRIPCIÓN

Termina el proceso, devolviendo código de retorno al sistema como estado de salida. Si no se especifica código de retorno, el valor predeterminado es 0.

Si se llama a "exit" desde código invocado a través de una devolución de llamada de Tk, esta versión de Tk de "exit" realiza una limpieza más fiable que el uso del "exit" de Perl.

ADVERTENCIAS

El uso de "exit" desde un proceso bifurcado terminará tanto el proceso hijo como el proceso padre. Como "Tk::exit" se importa por defecto, se debe usar "CORE::exit" en el proceso hijo en su lugar.
