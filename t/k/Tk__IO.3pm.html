NOMBRE

Tk::IO - interfaz de alto nivel para el mecanismo 'fileevent' de Tk

SINOPSIS

mi $fh = Tk::IO->new(-linecommand => callback, -childcommand => callback);
$fh->exec("comando")
$fh->wait
$fh->kill

ADVERTENCIA

LAS INTERFACES PARA ESTE MÓDULO PUEDEN CAMBIAR A MEDIDA QUE EVOLUCIONA EL IO DE PERL Y CON EL PUERTO DE TK4.1

DESCRIPCIÓN

Tk::IO ahora está superpuesto sobre la clase IO::Handle de perl. Las interfaces han cambiado y aún están en evolución.

En teoría, los métodos C que permiten IO no bloqueante como en versiones anteriores de Tk-b* todavía existen. No los he cambiado para usar la información de configuración adicional de perl, ni los he probado mucho.

La suposición es que se usa exec para bifurcar un proceso hijo y se llama a una función de retorno de llamada cada vez que llega una línea completa por la tubería implícita.

"line" debería definirse en términos del separador de registros de entrada de perl, pero aún no lo está.

La función de retorno de llamada -childcommand se llama cuando ocurre el fin de archivo.

$fh->wait se puede usar para esperar al proceso hijo mientras se procesan otros eventos de Tk.

$fh->kill se puede usar para enviar una señal al proceso hijo.

ERRORES

Todavía no está terminado. La idea es usar "exec" para emular "system" de manera no bloqueante.
