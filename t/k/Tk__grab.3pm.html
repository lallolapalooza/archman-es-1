NOMBRE

Tk::grab - Confina los eventos del puntero y del teclado a un subárbol de ventana

SINOPSIS

$widget->grab

$widget->grabOpción

DESCRIPCIÓN

Este conjunto de métodos implementa "grabs" (capturas) simples de puntero y teclado para Tk. Las capturas de Tk son diferentes de las capturas descritas en la documentación de Xlib. Cuando se establece una captura para una ventana particular, Tk restringe todos los eventos del puntero a la ventana de captura y a sus descendientes en la jerarquía de ventanas de Tk. Cada vez que el puntero esté dentro del subárbol de la ventana de captura, el puntero se comportará exactamente como si no hubiera habido ninguna captura y todos los eventos se informarán de la manera normal. Cuando el puntero esté fuera del árbol de $widget, se informarán las pulsaciones y liberaciones de botones y los eventos de movimiento del ratón a $widget, y se ignorarán los eventos de entrada y salida de ventana. El subárbol de captura "posee" el puntero: las ventanas fuera del subárbol de captura seguirán siendo visibles en la pantalla pero estarán inactivas hasta que se libere la captura. El árbol de ventanas debajo de la ventana de captura puede incluir ventanas de nivel superior, en cuyo caso todas esas ventanas de nivel superior y sus descendientes seguirán recibiendo eventos de ratón durante la captura.

Son posibles dos formas de captura: local y global. Una captura local afecta solo a la aplicación que la realiza: los eventos se informarán a otras aplicaciones como si la captura nunca hubiera ocurrido. Las capturas son locales por defecto. Una captura global bloquea todas las aplicaciones de la pantalla, de modo que solo el subárbol dado de la aplicación que realiza la captura será sensible a los eventos del puntero (pulsaciones de botones del ratón, liberaciones de botones del ratón, movimientos del puntero, entradas de ventana y salidas de ventana). Durante las capturas globales, el gestor de ventanas tampoco recibirá eventos del puntero.

Durante las capturas locales, los eventos del teclado (pulsaciones y liberaciones de teclas) se entregan como de costumbre: el gestor de ventanas controla qué aplicación recibe los eventos del teclado, y si se envían a alguna ventana de la aplicación que realiza la captura, se redirigen a la ventana de enfoque. Durante una captura global, Tk captura el teclado de modo que todos los eventos del teclado se envíen siempre a la aplicación que realiza la captura. La captura del teclado se libera cuando se libera la captura.

Las capturas se aplican a pantallas particulares. Si una aplicación tiene ventanas en varias pantallas, puede establecer una captura separada en cada pantalla. La captura en una pantalla particular afecta solo a las ventanas de esa pantalla. Es posible que diferentes aplicaciones en una misma pantalla tengan capturas locales simultáneas, pero solo una aplicación puede tener una captura global en una pantalla dada a la vez.

Los métodos grab admiten cualquiera de las siguientes formas:

$widget->grabCurrent
Devuelve la ventana de captura actual en esta aplicación para la pantalla de $widget, o una cadena vacía si no hay tal ventana.
$widget->grabs
Devuelve una lista cuyos elementos son todas las ventanas capturadas por esta aplicación para todas las pantallas, o una cadena vacía si la aplicación no tiene capturas.

¡Todavía no implementado!

$widget->grabRelease
Libera la captura en $widget si existe una, de lo contrario no hace nada. Devuelve una cadena vacía.
$widget->grab
Establece una captura local en $widget. Si ya había una captura en vigor para esta aplicación en la pantalla de $widget, se libera automáticamente. Si ya existe una captura local en $widget, el comando no hace nada. Devuelve una cadena vacía.
$widget->grabGlobal
Establece una captura global en $widget. Si ya había una captura en vigor para esta aplicación en la pantalla de $widget, se libera automáticamente. Si ya existe una captura global en $widget, el comando no hace nada. Devuelve una cadena vacía.
$widget->grabStatus
Devuelve none si actualmente no hay ninguna captura establecida en $widget, local si hay una captura local establecida en $widget, y global si hay una captura global establecida.

ERRORES

Produjo una implementación increíblemente compleja y poco elegante el efecto de captura simple descrito anteriormente. Dada la implementación actual, no es seguro que las aplicaciones utilicen las instalaciones de captura de Xlib, excepto a través de los procedimientos de captura de Tk. Si las aplicaciones intentan manipular los mecanismos de captura de X directamente, probablemente se romperán.

Si un solo proceso administra varias aplicaciones Tk diferentes, solo una de esas aplicaciones puede tener una captura local para una pantalla dada en un momento dado. Si las aplicaciones están en procesos diferentes, esta restricción no existe.
