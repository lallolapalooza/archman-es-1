NOMBRE

Tk::callbacks - Especificar código para que Tk lo llame.

SINOPSIS

Se puede especificar una llamada en una de las siguientes formas:

Sin argumentos:

... => \&nombre_sub, ...
... => sub { ... }, ...
... => 'nombre_método', ...

O con argumentos:

... => [ \&nombre_sub, args ... ], ...
... => [ sub { ... }, args... ], ...
... => [ 'nombre_método', args... ], ...

DESCRIPCIÓN

Perl/Tk tiene una llamada (callback), mientras que Tcl/Tk tiene una cadena de comando (es decir, un fragmento de Tcl que se ejecutará). Una llamada de perl/Tk puede tener una de las siguientes formas básicas:

  • Referencia a una subrutina "\&nombre_sub"
  • Subrutina anónima (clausura) "sub { ... }"
  • Un nombre de método 'nombre_método'

Cualquiera de estas puede proporcionarse con argumentos encerrándolas y los argumentos en []. Aquí hay algunos ejemplos:

$mw->bind($clase, "<Delete>" => 'Delete');

Esto llamará $widget->Delete, siendo $widget el proporcionado (por bind) como aquel en el que se presionó la tecla Delete.

Si bien es ideal que bind proporcione un objeto widget en muchos casos, puede ser molesto en otros. Usando la forma de lista, este comportamiento se puede modificar:

$a->bind("<Delete>",[$b => 'Delete']);

Dado que el primer elemento $b es un objeto, bind llamará $b->Delete.

Tenga en cuenta que el orden método/objeto solo importa para las llamadas de "bind". El auto-entrecomillado en perl5.001 hace que el primero de estos sea un poco más legible:

$w->configure(-yscrollcommand => [ set => $ysb]);
$w->configure(-yscrollcommand => [ $ysb => 'set' ]);

pero ambos llamarán $ysb->set(argumentos proporcionados por Tk)

Otro uso de los argumentos le permite escribir métodos generalizados que son más fáciles de reutilizar:

$a->bind("<Next>",['Next','Page']);
$a->bind("<Down>",['Next','Line']);

Esto llamará $a->Next('Page') o $a->Next('Line') respectivamente.

Tenga en cuenta que el contenido de "[]" es evaluado por perl cuando se crea la llamada. A menudo es deseable que los argumentos proporcionados a la llamada dependan de los detalles del evento que provocó su ejecución. Para permitir esto, las llamadas se pueden anidar usando el constructor Ev(...). Ev(...) inserta objetos de llamada en la lista de argumentos. Cuando el código de pegamento de perl/Tk está preparando la lista de argumentos para la llamada que está a punto de realizar, detecta estos objetos especiales y aplica recursivamente el proceso de llamada a ellos.

EJEMPLOS

$entry->bind('<Return>' => [$w , 'validate', Ev(['get'])]);
$toplevel->bind('all', '<Visibility>', [\&unobscure, Ev('s')]);
$mw->bind($class, '<Down>', ['SetCursor', Ev('UpDownLine',1)]);
