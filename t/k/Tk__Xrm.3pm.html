NOMBRE

Tk::Xrm - Rutinas de recursos/valores predeterminados/opciones de X que respetan las reglas.

SINOPSIS

use Tk;
use Tk::Xrm;

DESCRIPCIÓN

El uso de este módulo hace que el código de opciones de Tk sea reemplazado por versiones que utilizan rutinas de <X11/Xresource.h>, es decir, las mismas que utiliza cualquier otro kit de herramientas X.

El resultado es que la "coincidencia" de nombre/Clase con la base de datos de opciones sigue las mismas reglas que otros kits de herramientas X. Esto lo hace más predecible y facilita tener un único archivo ~/.Xdefaults que arroje resultados sensatos tanto para aplicaciones Tk como, por ejemplo, Motif.

ERRORES

Actualmente, optionAdd(key => value?, priority?) ignora completamente la prioridad opcional y solo hace XrmPutStringResource(). Quizás debería ser más sutil y hacer XrmMergeDatabases() o XrmCombineDatabase().

Esta versión es un poco más lenta que la reinvención de Tk, pero hay más optimización que se puede realizar.
