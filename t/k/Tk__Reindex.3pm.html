NOMBRE

Tk::Reindex - cambiar el índice base de widgets similares a Text

SINOPSIS

use Tk::ReindexedText;
$t1=$w->ReindexedText(-linestart => 2);
use Tk::ReindexedROText;
$t2=$w->ReindexedROText(-linestart => 0);

DESCRIPCIÓN

Crea una nueva clase de widget basada en widgets similares a Text que puede redefinir la base de numeración de líneas (normalmente los widgets Text comienzan la numeración de líneas en 1), o posiblemente otras manipulaciones de índices.

OPCIONES ESTÁNDAR

El widget recién definido acepta todas las mismas opciones que el widget base, que por defecto es Text.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: lineStart
Clase: LineStart
Interruptor: -linestart
Establece el número de línea de la primera línea en el widget Text. El -toindexcmd y -fromindexcmd por defecto utilizan esta opción de configuración.

- Nombre del ítem: toIndexCmd fromIndexCmd

- Clase del ítem: ToIndexCmd FromIndexCmd

- Interruptor del ítem: -toindexcmd -fromindexcmd

Estas dos opciones especifican llamadas de retorno que se realizan con una lista de índices y son responsables de traducirlos a/desde índices que el widget Text base pueda entender. La llamada de retorno recibe el widget seguido de una lista de índices, y debe devolver una lista de índices traducidos. -toindexcmd debe traducir de índices de 'usuario' a índices 'nativos' compatibles con Text, y -fromindexcmd debe traducir de índices 'nativos' a índices de 'usuario'.

Las llamadas de retorno por defecto simplemente suman/restan el desplazamiento dado por la opción -linestart para todos los índices en formato 'línea.carácter'.

Probablemente sería prudente hacer que estas funciones sean inversas entre sí.

MÉTODOS DE CLASE

importar
Para crear nuevos widgets Reindex, esta función debe llamarse a través de use con el nombre de la clase base similar a Text que se está extendiendo con la capacidad "Reindex". También se debe especificar 'use base(Tk::Reindex Tk::nameofbasewidget)' para ese widget.

ERRORES

He utilizado la palabra "indexes" en lugar de "indices" en toda la documentación.

Todo el código Perl incorporado para enlaces y métodos de widgets utilizará los nuevos índices de 'usuario'. Lo que significa que toda esta manipulación de índices podría romper el código que intenta analizar/manipular índices. O incluso asumir que '1.0' es el índice de inicio. Tk::Text::Contents viene a la mente.
