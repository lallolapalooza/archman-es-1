chooseDirectory(3) Documentación de Perl aportada por el usuario chooseDirectory(3)

NOMBRE

Tk::chooseDirectory - muestra un cuadro de diálogo para que el usuario seleccione un directorio.

SINOPSIS

$widget->chooseDirectory( ?opción valor ...? );

DESCRIPCIÓN

El método chooseDirectory se implementa como un envoltorio de perl para el comando principal de tk "tk_chooseDirectory", y $widget se pasa como argumento a la opción oculta -parent.

El método chooseDirectory muestra un cuadro de diálogo para que el usuario seleccione un directorio. Los siguientes pares de opción-valor son posibles como argumentos de línea de comandos:

-initialdir nombre_directorio
Especifica que los directorios en directorio deben mostrarse cuando aparezca el cuadro de diálogo. Si este parámetro no se especifica, se mostrarán los directorios del directorio de trabajo actual. Si el parámetro especifica una ruta relativa, el valor de retorno convertirá la ruta relativa en una ruta absoluta. Es posible que esta opción no siempre funcione en Macintosh. Esto no es un error. Más bien, el panel de control General Controls en Mac permite al usuario final anular el directorio predeterminado de la aplicación.
-parent $widget
Hace que $widget sea el padre lógico del cuadro de diálogo. El cuadro de diálogo se muestra encima de la ventana de su padre.
-title cadena_título
Especifica una cadena para mostrar como título del cuadro de diálogo. Si esta opción no se especifica, se mostrará un título predeterminado.
-mustexist booleano
Especifica si el usuario puede especificar directorios inexistentes. Si este parámetro es verdadero, el usuario solo puede seleccionar directorios que ya existan. El valor predeterminado es falso.

ADVERTENCIAS

Perl aún no tiene un concepto de sistemas de archivos codificados. Esto significa que las operaciones en nombres de archivo como "opendir" y "open" todavía usan semántica de bytes. Sin embargo, Tk usa semántica de caracteres internamente, lo que significa que puede obtener nombres de archivo con la bandera UTF-8 establecida en funciones como "chooseDirectory", "getOpenFile" y similares. Es responsabilidad del usuario determinar la codificación del sistema de archivos subyacente y convertir el resultado a bytes, por ejemplo:

use Encode;
...
my $dir = $mw->chooseDirectory;
$dir = encode("windows-1252", $dir);
opendir DIR, $dir or die $!;
...

Consulte también "When Unicode Does Not Happen" en perlunicode y "Unicode in Filenames" en perltodo.

EJEMPLO

my $dir = $mw->chooseDirectory(-initialdir => '~',
                               -title => 'Elige un directorio');
if (!defined $dir) {
    warn 'No se ha seleccionado ningún directorio';
} else {
    warn "Seleccionado $dir";
}
