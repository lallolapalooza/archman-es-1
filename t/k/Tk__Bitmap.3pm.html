NOMBRE

Tk::Bitmap - Imágenes que muestran dos colores

SINOPSIS

    $imagen = $widget->Bitmap?(nombre??,opciones?)

DESCRIPCIÓN

Un mapa de bits es una imagen cuyos píxeles pueden mostrar uno de dos colores o ser transparentes. Una imagen de mapa de bits se define por cuatro cosas: un color de fondo, un color de primer plano y dos mapas de bits, llamados fuente y máscara. Cada uno de los mapas de bits especifica valores 0/1 para una matriz rectangular de píxeles, y los dos mapas de bits deben tener las mismas dimensiones. Para los píxeles donde la máscara es cero, la imagen no muestra nada, produciendo un efecto transparente. Para otros píxeles, la imagen muestra el color de primer plano si los datos de la fuente son uno y el color de fondo si los datos de la fuente son cero.

CREACIÓN DE MAPAS DE BITS

Los mapas de bits se crean usando $widget->Bitmap. Los mapas de bits admiten las siguientes opciones:

-fondo => color
Especifica un color de fondo para la imagen de cualquiera de las formas estándar aceptadas por Tk. Si esta opción se establece en una cadena vacía, los píxeles de fondo serán transparentes. Este efecto se logra utilizando el mapa de bits de origen como mapa de bits de máscara, ignorando cualquier opción -datos o -archivo.
-datos => cadena
Especifica el contenido del mapa de bits de origen como una cadena. La cadena debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap). Si se especifican las opciones -datos y -archivo, la opción -datos tiene precedencia.
-archivo => nombre
nombre da el nombre de un archivo cuyo contenido define el mapa de bits de origen. El archivo debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap).
-primerplano => color
Especifica un color de primer plano para la imagen de cualquiera de las formas estándar aceptadas por Tk.
-datosmaskara => cadena
Especifica el contenido de la máscara como una cadena. La cadena debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap). Si se especifican las opciones -datosmaskara y -archivomaskara, la opción -datosmaskara tiene precedencia.
-archivomaskara => nombre
nombre da el nombre de un archivo cuyo contenido define la máscara. El archivo debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap).

MÉTODOS DE IMAGEN

Cuando se crea una imagen de mapa de bits, Tk también crea un nuevo objeto. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente.
