NOMBRE

Tk::LabFrame - marco con etiqueta.

SINOPSIS

    use Tk::LabFrame;

    $f = $parent->LabFrame(?-label=>texto, -labelside=>dónde, ...?);

DESCRIPCIÓN

LabFrame es exactamente igual que Frame y, además, permite añadir una etiqueta al marco.

OPCIONES DEL WIDGET

LabFrame admite las mismas opciones que el widget Frame.

Las opciones adicionales de LabFrame son:

-font => fuente
Especifica la fuente de la etiqueta.
-foreground => color
Especifica el color de primer plano de la etiqueta.
-label => texto
El texto de la etiqueta que se colocará con el Marco.
-labelside => dónde
Dónde puede ser uno de left, right, top, bottom o acrosstop. Los cuatro primeros funcionan como se esperaría y colocan la etiqueta a la izquierda, derecha, encima o debajo del marco, respectivamente. acrosstop crea un marco ranurado alrededor del marco central y coloca la etiqueta cerca de la esquina noroeste de forma que parezca que "sobrescribe" la ranura.
-labelvariable => ref_escalar
Especifica una referencia a una variable y se utiliza como alternativa a -label. Si el valor de la variable cambia, el widget se actualizará automáticamente para reflejar el cambio. Se usa como -textvariable.

SUBWIDGETS ANUNCIADOS

Consulte "Subwidget" en Tk::mega para saber cómo utilizar widgets anunciados.

border
Frame utilizado para mostrar el borde
frame
Frame utilizado para crear nuevos hijos de LabFrame.
label
Label utilizado para mostrar texto.

EJEMPLO

Ejecute el siguiente programa de prueba para verlo en acción:

use strict;
use Tk;
require Tk::LabFrame;
require Tk::LabEntry;
my $test = 'Test this';
my $mw = Tk::MainWindow->new;
my $f = $mw->LabFrame(-label => "Esta es una etiqueta",
                       -labelside => "acrosstop");
$f->LabEntry(-label => "Testing", -textvariable => \$test)->pack;
$f->pack;
Tk::MainLoop;

ERRORES

Quizás LabFrame debería ser subsumido dentro del mecanismo genérico de widgets etiquetados de pTk.
