NOMBRE

Tk::WinPhoto - Cargar una imagen de Photo desde una ventana

SINOPSIS

use Tk;
use Tk::WinPhoto;
my $image = $mw->Photo(-format => 'Window', -data => oct($mw->id));
$image->write($path_name, -format => 'BMP|PPM|XPM');

DESCRIPCIÓN

Esta es una extensión para Tk800.* que cargará una imagen de Photo desde una instantánea de una ventana X especificada por la opción -data.

La ventana debe existir y ser visible. Dado que el código permite capturar ventanas no propiedad de Tk, no intenta forzar esto. Si está capturando una de las ventanas de Tk, use "$w->update".

Si la ventana está mapeada, pero oscurecida por otras ventanas, lo que se captura es el rectángulo que ocuparía la ventana. Esto puede considerarse una característica. Para ventanas propiedad de Tk, se puede usar "$w->raise" para traer la ventana al frente.

Una vez que la imagen Photo se carga, se puede guardar usando "$image->write(-format => ...)" utilizando cualquiera de los formatos que admiten escritura.
