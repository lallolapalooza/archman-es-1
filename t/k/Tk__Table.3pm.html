NOMBRE

Tk::Table - Tabla bidimensional de widgets Tk con desplazamiento

SINOPSIS

use Tk::Table;
$tabla = $padre->Table(-filas => número,
                        -columnas => número,
                        -barras_desplazamiento => ancla,
                        -filas_fijas => número,
                        -columnas_fijas => número,
                        -tomar_foco => booleano);
$widget = $tabla->Button(...);
$anterior = $tabla->put($fila,$col,$widget);
$anterior = $tabla->put($fila,$col,"Texto");  # Etiqueta simple
$widget = $tabla->get($fila,$col);
$cols = $tabla->totalColumnas;
$rows = $tabla->totalFilas;
$tabla->ver($widget);
$tabla->ver($fila,$col);
($fila,$col) = $tabla->Posicion($widget);

DESCRIPCIÓN

Tk::Table es un widget/gestor de geometría completamente en Perl que permite mostrar una tabla bidimensional de widgets arbitrarios de Perl/Tk.

Las entradas en la Tabla son simplemente widgets ordinarios de Perl/Tk. Deben crearse con la Tabla como su padre. Los widgets se posicionan en la tabla usando:

$tabla->put($fila,$col,$widget)

Si $widget no es una referencia, se trata como una cadena y se crea un widget de Etiqueta con la cadena como su texto.

Todos los widgets de cada columna tienen el mismo ancho: el ancho solicitado del widget más ancho de la columna. De manera similar, todos los widgets de cada fila tienen la misma altura: la altura solicitada del widget más alto de la columna.

Se puede marcar un número de filas y/o columnas como 'fijas', por lo que pueden servir como 'encabezados' para el resto de las filas que son desplazables.

El tamaño solicitado de la tabla en su conjunto es tal que se puede mostrar el número de filas especificado por -filas (por defecto 10) y el número de columnas especificado por -columnas (por defecto 10).

Si se indica a la Tabla que puede tomar el foco del teclado, las teclas de cursor y desplazamiento desplazarán los widgets mostrados.

"-barras_desplazamiento". Por defecto, se añadirán barras de desplazamiento en "nw". Para deshabilitar las barras de desplazamiento, establezca "-barras_desplazamiento" a una cadena vacía:

$tabla = $padre->Table(-barras_desplazamiento => '', ...);

La tabla se puede vaciar usando

$tabla->limpiar

los widgets que estaban en la tabla se destruyen.

El widget Tk::Table se deriva de un Tk::Frame, por lo que hereda todas sus opciones de configuración.

La navegación de foco por defecto otorga el foco solo al widget de tabla en su conjunto. Para habilitar la navegación de foco dentro de las celdas de la tabla (por ejemplo, si hay widgets de entrada incrustados), la opción "-tomar_foco" debe establecerse a 0.

ERRORES / Problemas / Posibles mejoras

  • Tablas muy grandes consumen muchas ventanas de X.
  • No hay equivalentes a las opciones -ancla/-relleno, etc. de pack.

VER TAMBIÉN

Tk::grid, Tk::HList, Tk::TableMatrix, Tk::MListbox, Tk::Columns
