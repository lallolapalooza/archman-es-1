NOMBRE

Tk::Tree - Crear y manipular widgets de árbol

SINOPSIS

    use Tk::Tree;

    $tree = $parent->Tree(?opciones?);

SUPER-CLASE

La clase Tree se deriva de la clase HList y hereda todos los métodos, opciones y subwidgets de su super-clase. Un widget Tree no se desplaza por defecto.

OPCIONES ESTANDAR

Tree soporta todas las opciones estándar de un widget HList. Consulte Tk::options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECIFICAS DEL WIDGET

Nombre: browseCmd
Clase: BrowseCmd
Interruptor: -browsecmd
Especifica una rutina de llamada a la que se llamará cada vez que el usuario navegue por una entrada (normalmente haciendo clic con el ratón en la entrada). La rutina de llamada se invoca con un argumento, la ruta de la entrada.
Nombre: closeCmd
Clase: CloseCmd
Interruptor: -closecmd
Especifica una rutina de llamada a la que se llamará cada vez que sea necesario cerrar una entrada (ver "BINDINGS" más abajo). Este método se invoca con un argumento, la ruta de la entrada. Este método debe realizar las acciones apropiadas para cerrar la entrada especificada. Si la opción -closecmd no está especificada, la acción de cierre predeterminada es ocultar todas las entradas hijas de la entrada especificada.
Nombre: command
Clase: Command
Interruptor: -command
Especifica una rutina de llamada a la que se llamará cada vez que el usuario active una entrada (normalmente haciendo doble clic en la entrada). La rutina de llamada se invoca con un argumento, la ruta de la entrada.
Nombre: ignoreInvoke
Clase: IgnoreInvoke
Interruptor: -ignoreinvoke
Un valor booleano que especifica cuándo se debe abrir o cerrar una rama. Una rama siempre se abrirá o cerrará cuando el usuario presione los indicadores (+) y (-). Sin embargo, cuando el usuario invoca una rama (haciendo doble clic o presionando <Intro>), la rama se abrirá o cerrará solo si -ignoreinvoke está establecido en falso (la configuración predeterminada).
Nombre: openCmd
Clase: OpenCmd
Interruptor: -opencmd
Especifica una rutina de llamada a la que se llamará cada vez que sea necesario abrir una entrada (ver "BINDINGS" más abajo). Este método se invoca con un argumento, la ruta de la entrada. Este método debe realizar las acciones apropiadas para abrir la entrada especificada. Si la opción -opencmd no está especificada, la acción de apertura predeterminada es mostrar todas las entradas hijas de la entrada especificada.

DESCRIPCION

El método Tree crea una nueva ventana y la convierte en un widget Tree y devuelve una referencia a ella. Opciones adicionales, descritas anteriormente, se pueden especificar en la línea de comandos o en la base de datos de opciones para configurar aspectos del widget Tree, como su cursor y relieve.

El widget Tree se puede utilizar para mostrar datos jerárquicos en forma de árbol. El usuario puede ajustar la vista del árbol abriendo o cerrando partes del árbol.

Para mostrar una estructura de árbol estática, puede agregar las entradas en el widget Tree y ocultar las entradas deseadas. Luego puede llamar al método autosetmode. Esto configurará el widget Tree de tal manera que maneje automáticamente todos los eventos de apertura y cierre. (Consulte el programa de demostración Tixish/examples/perl-tix-tree).

El método anterior no es aplicable si desea mantener una estructura de árbol dinámica, es decir, si no conoce todas las entradas del árbol y necesita agregar o eliminar entradas posteriormente. Para hacer esto, primero debe crear las entradas en el widget Tree. Luego, use el método setmode para indicar las entradas que se pueden abrir o cerrar, y use las opciones -opencmd y -closecmd para manejar los eventos de apertura y cierre. (Por favor, consulte el programa de demostración Tixish/examples/perl-tix-dyntree).

Utilice cualquiera de:

    $parent->Scrolled('Tree', ... );

o

    $parent->ScrlTree( ... );

para crear un Tree con desplazamiento. Consulte Tk::Scrolled para obtener más detalles.

METODOS DEL WIDGET

El método Tree crea un objeto de widget. Este objeto soporta los métodos configure y cget descritos en Tk::options que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

Los siguientes métodos adicionales están disponibles para los widgets Tree:

$tree->add_pathimage(treeRegExp [, openImg, closeImg])
Este método define imágenes para una ruta dada (las imágenes deben estar en formato xpm). La ruta se puede determinar mediante una expresión regular simplificada. Solo hay tres metacaracteres:
^
al principio de "treeRegExp", igual que en las expresiones regulares de Perl
*
cualquier cosa
$
al final de "TreeRegExp", igual que en las expresiones regulares de Perl

Ejemplos:

$tree->add_pathimage('^root','openfolder','folder');

coincide con "root", "root.foo", "root.bar", pero no con "foo.root"

$tree->add_pathimage('root.*.class','openfolder','folder');

coincide con todas las rutas que contienen "root.<cualquiercosa>.class", pero no con "root.<cualquiercosa>.<cualquiercosa>.class" "*" es una parte de la ruta. Si desea utilizar un comodín para dos niveles, debe utilizar "*.*".

$tree->add_pathimage('class$','openfolder','folder');

Esto coincide con todas las rutas que terminan en "class".

$tree->autosetmode
Este método llama al método setmode para todas las entradas de este widget Tree: si una entrada no tiene entradas hijas, su modo se establece en none. De lo contrario, si la entrada tiene entradas hijas ocultas, su modo se establece en open; de lo contrario, su modo se establece en close.
$tree->child_entries([$path][,$depth])
Este método devuelve en contexto de lista una matriz que contiene todas las rutas de las subentradas dentro de la ruta dada. En contexto escalar, devuelve el número de subentradas en la ruta dada. 
Ejemplo:
  root
   | foo
   | bar
   |  | bar1
   |  | bar2
my @childentries = $tree->child_entries('root.bar');
# devuelve (root.bar.bar1, root.bar.bar2)
my $nr_of_subentries = $tree->child_entries('root',2);
# devuelve 4

Si se omite $path, se asume que se refiere a la entrada superior a 'root'. $depth define el número de niveles.

$tree->close(entryPath)

WIDGET METHODS

$tree->close(entryPath)
Cierra la entrada dada por entryPath si su mode es close.
$tree->getmode(entryPath)
Devuelve el mode actual de la entrada dada por entryPath.
$tree->open(entryPath)
Abre la entrada dada por entryPath si su mode es open.
$tree->setmode(entryPath, mode)
Este método se utiliza para indicar si la entrada dada por entryPath tiene entradas hijas y si las hijas son visibles. mode debe ser uno de open, close o none. Si mode se establece en open, se dibuja un indicador (+) junto a la entrada. Si mode se establece en close, se dibuja un indicador (-) junto a la entrada. Si mode se establece en none, no se dibujarán indicadores para esta entrada. El mode por defecto es none. El modo open indica que la entrada tiene hijos ocultos y que esta entrada puede ser abierta por el usuario. El modo close indica que todos los hijos de la entrada son ahora visibles y que la entrada puede ser cerrada por el usuario.

BINDINGS

Los bindings básicos del ratón y del teclado del widget Tree son los mismos que los bindings del widget HList. Además, las entradas pueden ser abiertas o cerradas bajo las siguientes condiciones:

[1]
Si el mode de la entrada es open, puede ser abierta haciendo clic en su indicador (+).
[2]
Si el mode de la entrada es close, puede ser cerrada haciendo clic en su indicador (-).
