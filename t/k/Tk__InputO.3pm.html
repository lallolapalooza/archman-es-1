InputO(3) Documentación de Perl contribuida por el usuario InputO(3)

NOMBRE

Tk::InputO - Crear y manipular widgets TIX InputO

SINOPSIS

$inputonly = $parent->InputO(?opciones?);

OPCIONES ESTÁNDAR

Solo se admiten las siguientes tres opciones estándar para InputO:

cursor width height

Consulte Tk::options para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

InputO no tiene opciones específicas del widget.

DESCRIPCIÓN

El método InputO crea una nueva ventana (proporcionada por el argumento $widget) y la convierte en un widget InputO. Las opciones adicionales, descritas anteriormente, se pueden especificar en la línea de comandos o en la base de datos de opciones para configurar aspectos de InputO, como su cursor o su ancho.

Los widgets InputO no son visibles para el usuario. El único propósito de los widgets InputO es aceptar entradas del usuario, lo que se puede hacer con el método bind.

MÉTODOS DEL WIDGET

El método InputO crea un objeto widget. Este objeto admite los métodos configure y cget descritos en Tk::options, que se pueden utilizar para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

BINDINGS

Los widgets InputO no tienen bindings predeterminados.
