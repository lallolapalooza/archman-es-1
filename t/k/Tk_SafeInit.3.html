Tk_SafeInit(3)

Paquete: tk

Licencias: TCL

Tk_Init(3) Procedimientos de la biblioteca Tk Tk_Init(3)

NOMBRE

Tk_Init, Tk_SafeInit - añadir Tk a un intérprete y crear una nueva aplicación Tk.

SINOPSIS

#include <tk.h>

int
Tk_Init(interp)

int
Tk_SafeInit(interp)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete en el que cargar Tk. Tk no debe estar ya cargado en este intérprete.

DESCRIPCIÓN

Tk_Init es el procedimiento de inicialización del paquete para Tk. Normalmente es invocado por el procedimiento Tcl_AppInit de una aplicación o por el comando load. Tk_Init añade todos los comandos de Tk a interp y crea una nueva aplicación Tk, incluyendo su ventana principal. Si la inicialización es exitosa, Tk_Init devuelve TCL_OK; si hay un error, devuelve TCL_ERROR. Tk_Init también deja un resultado o mensaje de error en el resultado del intérprete interp.

Si existe una variable argv en interp, Tk_Init trata el contenido de esta variable como una lista de opciones para la nueva aplicación Tk. Las opciones pueden tener cualquiera de las formas documentadas para la aplicación wish (de hecho, wish usa Tk_Init para procesar sus argumentos de línea de comandos).

Tk_SafeInit es idéntico a Tk_Init excepto que elimina todos los comandos de Tk que se consideran inseguros. Dichos comandos y las razones de su exclusión son:

bell
El sonido continuo de la campana es una molestia.
clipboard
Un script malicioso podría reemplazar el contenido del portapapeles con la cadena “rm -r *” y provocar sorpresas cuando se pegue el contenido del portapapeles.
grab
Grab se puede usar para impedir que el usuario utilice otras aplicaciones.
menu
Los menús pueden usarse para cubrir toda la pantalla y para robar la entrada del usuario.
selection
Ver clipboard.
send
Send puede usarse para hacer que intérpretes inseguros ejecuten comandos.
tk
El comando tk recrea el comando send, que es inseguro.
tkwait
Tkwait puede bloquear el proceso contenedor para siempre.
toplevel
Toplevels puede usarse para cubrir toda la pantalla y para robar la entrada del usuario.
wm
Si alguna vez se permiten los toplevels, wm puede usarse para eliminar decoraciones, mover ventanas, etc.

PALABRAS CLAVE

seguro, aplicación, inicialización, cargar, ventana principal
