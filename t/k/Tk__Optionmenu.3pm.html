NOMBRE

Tk::Optionmenu - Permite al usuario seleccionar uno de los valores de opciones predefinidos

SINOPSIS

use Tk::Optionmenu;
$opt = $w->Optionmenu(
                    -options => REFERENCIA_A_LISTA_DE_OPCIONES,
                    -command => CALLBACK,
                    -variable => REFERENCIA_ESCALAR,
                    );
$opt->addOptions( LISTA_DE_OPCIONES );
# LISTA DE OPCIONES es
#   a)  $val1, $val2, $val3,...
#   b)  [ $lab1=>$val1], [$lab2=>val2], ... ]
#   c)  combinación de a) y b), por ejemplo,
#       val1, [$lab2=>val2], val3, val4, [...], ...

DESCRIPCIÓN

El widget Optionmenu permite al usuario elegir entre un conjunto dado de opciones.

Si el usuario debe poder cambiar las opciones disponibles, echa un vistazo a Tk::BrowseEntry.

OPCIONES

-options
Establece (o restablece) la lista de opciones presentadas.
-command
Define la devolución de llamada que se invoca cuando se selecciona una nueva opción.
-variable
Referencia a un escalar que contiene el valor actual de la opción seleccionada.
-textvariable
Referencia a un escalar que contiene la etiqueta de texto del valor actual de la opción seleccionada.

MÉTODOS

addOptions
Añade LISTA_DE_OPCIONES a las opciones ya disponibles.

EJEMPLO

use Tk;
my $mw = MainWindow->new();
my ($var, $tvar);
my $opt = $mw->Optionmenu(
       -options => [[jan=>1], [feb=>2], [mar=>3], [apr=>4]],
       -command => sub { print "got: ", shift, "\n" },
       -variable => \$var,
       -textvariable => \$tvar
      )->pack;
$opt->addOptions([may=>5],[jun=>6],[jul=>7],[aug=>8]);
my $f = $mw->Frame(-relief=>'groove', -borderwidth => 2)->pack;
$f->Label(-textvariable=>\$tvar)->pack(-side => 'left');
$f->Label(-text => " -> ")->pack(-side => 'left');
$f->Label(-textvariable=>\$var)->pack(-side => 'left');
$mw->Button(-text=>'Exit', -command=>sub{$mw->destroy})->pack;
MainLoop;
