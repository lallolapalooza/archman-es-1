NOMBRE

Tk::Animation - Muestra una secuencia de imágenes Tk::Photo

SINOPSIS

use Tk::Animation
mi $img = $widget->Animation('-format' => 'gif', -file => 'algunarchivo.gif');
$img->add_frame(@images);
$img->start_animation;
$img->start_animation( $period );
$img->next_image;
$img->prev_image;
$img->set_image( 0 .. $#frames );
$img->pause_animation;
$img->resume_animation( $period );
$img->fast_forward( $multiplier );
$img->fast_reverse( $multiplier );
$img->stop_animation;
$img->set_disposal_method( $boolean );

DESCRIPCIÓN

En el caso simple cuando "Animation" recibe un GIF estilo GIF89 con múltiples 'fotogramas', construirá un array interno de imágenes "Photo".

El método "add_frame" añade imágenes a la secuencia. Se proporciona para permitir la construcción de animaciones a partir de imágenes separadas. Todas las imágenes deben ser "Photo"s y todas deben tener el mismo tamaño.

start_animation($period) inicia entonces un "repeat" con el $period especificado para secuenciar estas imágenes. En cuanto a un "repeat" en bruto, $period está en milisegundos, para un monitor de 50Hz debería ser de al menos 20ms. Si $period se omite, se determina a partir de los metadatos del GIF (ver más abajo), o si esto no es posible, el valor predeterminado es 100 milisegundos.

"stop_animation" cancela el "repeat" y restablece la imagen a la primera imagen de la secuencia.

Para un control más detallado, "next_image" y "prev_image" avanzan o retroceden un fotograma. "set_image" posiciona aleatoriamente la animación a un fotograma particular.

"pause_animation" pausa la película y "resume_animation" continúa desde el punto de pausa.

"fast_forward" y "fast_reverse" aceleran la película hacia adelante o hacia atrás. $multiplier especifica cuánto más rápido se mueve la animación.

Si Image::Info está instalado, entonces el tiempo del período de repetición y el método de eliminación de las animaciones GIF se determinan directamente a partir de los metadatos del GIF. De lo contrario, el método de eliminación debe establecerse manualmente usando "set_disposal_method" (1 para borrar las imágenes anteriores, 0 para dejar las imágenes anteriores como están). El tiempo del período de repetición se puede proporcionar en el método "start_animation".

NOTAS

"set_disposal_method" se conocía anteriormente como el método "blank", pero el nombre de este método fue un error.

Si el método de eliminación no se establece correctamente, ya sea mediante "set_disposal_method" o determinándolo a partir de los metadatos del GIF, pueden ocurrir las siguientes situaciones: Por defecto, Animation deja el fotograma de película anterior en la foto de animación. Muchas veces, superponer fotogramas sucesivos produce una imagen compuesta que se ve borrosa.

ERRORES

Este módulo no debería depender de un módulo que no se declara como dependencia (Image::Info).

Los retrasos entre imágenes pueden variar en una animación GIF. Este módulo aún no puede manejar esto.

El manejo de los diversos métodos de eliminación no es correcto.
