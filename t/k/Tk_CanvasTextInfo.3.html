NOMBRE

Tk_CanvasTextInfo - información adicional para gestionar elementos de texto en lienzos

SINOPSIS

#include <tk.h>

Tk_CanvasTextInfo *
Tk_CanvasGetTextInfo(canvas)

ARGUMENTOS

Tk_Canvas canvas (entrada)
Un token que identifica un lienzo particular.

DESCRIPCIÓN

Los elementos de texto del lienzo son algo más complicados de gestionar que otros elementos, debido a cosas como la selección y el foco de entrada. Tk_CanvasGetTextInfo puede ser invocado por un gestor de tipos para obtener información adicional necesaria para los elementos que muestran texto. El valor de retorno de Tk_CanvasGetTextInfo es un puntero a una estructura que se comparte entre Tk y todos los elementos que muestran texto. La estructura tiene el siguiente formato:

typedef struct Tk_CanvasTextInfo {
    Tk_3DBorder selBorder;
    int selBorderWidth;
    XColor *selFgColorPtr;
    Tk_Item *selItemPtr;
    int selectFirst;
    int selectLast;
    Tk_Item *anchorItemPtr;
    int selectAnchor;
    Tk_3DBorder insertBorder;
    int insertWidth;
    int insertBorderWidth;
    Tk_Item *focusItemPtr;
    int gotFocus;
    int cursorOn;
} Tk_CanvasTextInfo;
El campo selBorder identifica un Tk_3DBorder que debe utilizarse para dibujar el fondo bajo el texto seleccionado. selBorderWidth proporciona el ancho del borde realzado alrededor del texto seleccionado, en píxeles. selFgColorPtr apunta a un XColor que describe el color de primer plano que se utilizará al dibujar el texto seleccionado. selItemPtr apunta al elemento que está seleccionado actualmente, o NULL si no hay ningún elemento seleccionado o si el lienzo no tiene la selección. selectFirst y selectLast proporcionan los índices de los primeros y últimos caracteres seleccionados en selItemPtr, tal como los devuelve el indexProc para ese elemento. anchorItemPtr apunta al elemento que tiene actualmente el ancla de selección; este no es necesariamente el mismo que selItemPtr. selectAnchor es un índice que identifica la posición del ancla dentro de anchorItemPtr. insertBorder contiene un Tk_3DBorder para usar al dibujar el cursor de inserción; insertWidth proporciona el ancho total del cursor de inserción en píxeles, y insertBorderWidth proporciona el ancho del borde realzado alrededor del cursor de inserción. focusItemPtr identifica el elemento que tiene actualmente el foco de entrada, o NULL si no existe tal elemento. gotFocus es 1 si el widget del lienzo tiene el foco de entrada y 0 en caso contrario. cursorOn es 1 si el cursor de inserción debe dibujarse en focusItemPtr y 0 si no debe dibujarse; este campo se alterna activado y desactivado por Tk para hacer que el cursor parpadee.

La estructura devuelta por Tk_CanvasGetTextInfo se comparte entre Tk y los gestores de tipos; normalmente el gestor de tipos llama a Tk_CanvasGetTextInfo una vez cuando se crea un elemento y luego guarda el puntero en el registro del elemento. Tk actualizará la información en Tk_CanvasTextInfo; por ejemplo, un comando de widget configure podría cambiar el campo selBorder, o un comando de widget select podría cambiar el campo selectFirst, o Tk podría cambiar cursorOn para hacer que el cursor de inserción parpadee activado y desactivado durante las redibujadas sucesivas.

Los gestores de tipos deben tratar todos los campos de la estructura Tk_CanvasTextInfo como de solo lectura, excepto selItemPtr, selectFirst, selectLast y selectAnchor. Los gestores de tipos pueden cambiar selectFirst, selectLast y selectAnchor para ajustarse a inserciones y eliminaciones en el elemento (pero solo si el elemento es el propietario actual de la selección o ancla, según lo determinado por selItemPtr o anchorItemPtr). Si se elimina todo el texto seleccionado en el elemento, el elemento debe establecer selItemPtr a NULL para indicar que ya no hay una selección.
