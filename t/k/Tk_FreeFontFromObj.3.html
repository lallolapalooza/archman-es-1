Tk_AllocFontFromObj(3) Procedimientos de la biblioteca Tk Tk_AllocFontFromObj(3)

NOMBRE

Tk_AllocFontFromObj, Tk_GetFont, Tk_GetFontFromObj, Tk_NameOfFont, Tk_FreeFontFromObj, Tk_FreeFont - mantener la base de datos de fuentes

SINOPSIS

#include <tk.h>

Tk_Font
Tk_AllocFontFromObj(interp, tkwin, objPtr)

Tk_Font
Tk_GetFont(interp, tkwin, string)

Tk_Font
Tk_GetFontFromObj(tkwin, objPtr)

const char *
Tk_NameOfFont(tkfont)

Tk_Font
Tk_FreeFontFromObj(tkwin, objPtr)

void
Tk_FreeFont(tkfont)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a usar para reportar errores. Si es NULL, entonces no se dejan mensajes de error después de los errores.
Tk_Window tkwin (entrada)
Token para la ventana en la que se utilizará la fuente.
Tcl_Obj *objPtr (entrada/salida)
Proporciona el nombre o la descripción de la fuente. Consulte la documentación del comando font para obtener detalles sobre los formatos aceptables. La representación interna se modificará para almacenar en caché la Tk_Font correspondiente.
const char *string (entrada)
Igual que objPtr excepto que la descripción de la fuente se pasa como una cadena y la Tk_Font resultante no se almacena en caché.
Tk_Font tkfont (entrada)
Token opaco de fuente.

DESCRIPCIÓN

Tk_AllocFontFromObj busca la fuente indicada por objPtr y devuelve un token que representa la fuente. El valor de retorno se puede utilizar en llamadas posteriores a procedimientos como Tk_GetFontMetrics, Tk_MeasureChars y Tk_FreeFont. El token Tk_Font seguirá siendo válido hasta que se llame a Tk_FreeFontFromObj o Tk_FreeFont para liberarlo. ObjPtr puede contener un nombre simbólico o una descripción de fuente; consulte la documentación del comando font para obtener una descripción de los formatos válidos. Si Tk_AllocFontFromObj no tiene éxito (porque, por ejemplo, objPtr no contenía una especificación de fuente válida), devuelve NULL y deja un mensaje de error en el resultado de interp si interp no es NULL. Tk_AllocFontFromObj almacena en caché información sobre el valor de retorno en objPtr, lo que acelera las llamadas futuras a procedimientos como Tk_AllocFontFromObj y Tk_GetFontFromObj.

Tk_GetFont es idéntico a Tk_AllocFontFromObj excepto que la descripción de la fuente se especifica con una cadena en lugar de un objeto. Esto evita que Tk_GetFont almacene en caché la Tk_Font correspondiente, por lo que Tk_GetFont es menos eficiente que Tk_AllocFontFromObj.

Tk_GetFontFromObj devuelve el token de una fuente existente, dada la ventana y la descripción utilizadas para crear la fuente. Tk_GetFontFromObj no crea realmente la fuente; la fuente debe haber sido creada previamente con una llamada a Tk_AllocFontFromObj o Tk_GetFont. El valor de retorno se almacena en caché en objPtr, lo que acelera las llamadas futuras a Tk_GetFontFromObj con el mismo objPtr y tkwin.

Tk_AllocFontFromObj y Tk_GetFont mantienen una base de datos de todas las fuentes que han asignado. Si se solicita la misma fuente varias veces (por ejemplo, por diferentes ventanas o para diferentes propósitos), se compartirá una única Tk_Font para todos los usos. Los recursos subyacentes se liberarán automáticamente cuando nadie esté utilizando la fuente.

El procedimiento Tk_NameOfFont es aproximadamente el inverso de Tk_GetFont. Dado un tkfont que fue creado por Tk_GetFont (o Tk_AllocFontFromObj), el valor de retorno es el argumento string que se pasó a Tk_GetFont para crear la fuente. La cadena devuelta por Tk_NameOfFont solo se garantiza que persista hasta que se elimine el tkfont. El llamador no debe modificar esta cadena.

Cuando una fuente ya no es necesaria, se debe llamar a Tk_FreeFontFromObj o Tk_FreeFont para liberarla. Para Tk_FreeFontFromObj, la fuente a liberar se especifica con la misma información utilizada para crearla; para Tk_FreeFont, la fuente a liberar se especifica con su token Tk_Font. Debe haber exactamente una llamada a Tk_FreeFontFromObj o Tk_FreeFont por cada llamada a Tk_AllocFontFromObj o Tk_GetFont.
