Tk_NameOfCapStyle(3)

Paquete: tk

Licencias: TCL

Tk_GetCapStyle(3) Procedimientos de la biblioteca Tk Tk_GetCapStyle(3)

NOMBRE

Tk_GetCapStyle, Tk_NameOfCapStyle - traducir entre cadenas y estilos de remate

SINOPSIS

#include <tk.h>

int
Tk_GetCapStyle(interp, string, capPtr)

const char *
Tk_NameOfCapStyle(cap)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a usar para reportar errores.
const char *string (entrada)
Cadena que contiene el nombre del estilo de remate - uno de “butt”, “projecting”, o “round” - o una abreviatura única de uno de ellos.
int *capPtr (salida)
Puntero a la ubicación en la que almacenar el estilo de remate X correspondiente a string.
int cap (entrada)
Estilo de remate: uno de CapButt, CapProjecting o CapRound.

DESCRIPCIÓN

Tk_GetCapStyle almacena en *capPtr el estilo de remate X correspondiente a string. Este será uno de los valores CapButt, CapProjecting o CapRound. Los estilos de remate se usan típicamente en contextos gráficos de X para indicar cómo deben ser los puntos finales de las líneas. Consulte la documentación de X para obtener información sobre lo que implica cada estilo.

En circunstancias normales, el valor de retorno es TCL_OK y interp no se utiliza. Si string no contiene un estilo de remate válido o una abreviatura de uno de estos nombres, se almacena un mensaje de error en el resultado del intérprete interp, se devuelve TCL_ERROR y *capPtr no se modifica.

Tk_NameOfCapStyle es la inversa lógica de Tk_GetCapStyle. Dado un estilo de remate como CapButt, devuelve una cadena asignada estáticamente correspondiente a cap. Si cap no es un estilo de remate legal, se devuelve “unknown cap style”.

PALABRAS CLAVE

butt, estilo de remate, projecting, round
