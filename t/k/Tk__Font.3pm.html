NOMBRE

Tk::Font - Crear y inspeccionar fuentes.

SINOPSIS

    $widget->Font(opción?, arg, arg, ...?)

    $font->Option?(arg, arg, ...)?

DESCRIPCIÓN

El método Font proporciona varias funciones para tratar con fuentes, como definir fuentes nombradas e inspeccionar las atribuciones reales de una fuente. El comando tiene varias formas diferentes, determinadas por el primer argumento. Las siguientes formas son actualmente admitidas:

$font->actual(-option?)
$widget->fontActual(font?, -option?)
Devuelve información sobre las atribuciones reales que se obtienen al usar font en el display de $font; las atribuciones reales obtenidas pueden diferir de las solicitadas debido a limitaciones del sistema, como la disponibilidad de familias de fuentes y tamaños. font es una descripción de una fuente; véase "DESCRIPCIÓN DE FUENTES" a continuación. Si se especifica option, devuelve el valor de esa atribución; si no se especifica, devuelve una lista de todas las atribuciones y sus valores. Véase "OPCIONES DE FUENTES" para una lista de las posibles atribuciones.
$font->configure(-option??=>valor, -option=>valor, ...?)
Consulta o modifica las atribuciones deseadas para $font. Si no se especifica -option, devuelve una lista que describe todas las opciones y sus valores para fontname. Si se especifica un único -option con ningún valor, devuelve el valor actual de esa atribución. Si se especifican uno o más pares option-value, el método modifica la fuente dada para que tenga los valores especificados; en este caso, todas las ventanas widgets que usen esta fuente se redibujarán utilizando las nuevas atribuciones de la fuente. Véase "OPCIONES DE FUENTES" para una lista de las posibles atribuciones.

Nota: El comportamiento anterior difiere en detalle del método configure en widgets, imágenes, etc.

$font = $widget->Font(-option=>valor, ...>?)
$font = $widget->fontCreate(?fontname??, -option=>valor, ...>?)
Creación de una nueva fuente y devuelve una referencia a ella. fontname especifica el nombre de la fuente; si no se especifica, Tk genera un nuevo nombre de la forma fontx, donde x es un número. Hay cualquier número de pares option-value, que proporcionan las atribuciones deseadas para la nueva fuente nombrada. Véase "OPCIONES DE FUENTES" para una lista de las posibles atribuciones.

Nota: La fuente creada no está compartida entre ventanas de widgets diferentes.

$font->delete
$widget->fontDelete(fontname?, fontname, ...?)
Elimina las fuentes nombradas especificadas. Si hay widgets que usen la fuente nombrada, la fuente no se eliminará realmente hasta que todas las instancias se liberen. Aquellas widgets seguirán mostrando sus valores útiles de la fuente nombrada. Si una fuente nombrada se elimina y luego se recrea con otra llamada a fontCreate, los widgets usarán la nueva fuente y se redibujarán utilizando las nuevas atribuciones de esa fuente.
$widget->fontFamilies
El valor de retorno es una lista de los nombres de familias de fuentes en minúsculas que existen en el display de $widget.
$font->measure(text)
$widget->fontMeasure(font, text)
Medida del espacio que el texto text usaría en el font font cuando se muestre en $widget. font es una descripción de una fuente; véase "DESCRIPCIÓN DE FUENTES" a continuación. El valor de retorno es el ancho total en píxeles de text, sin incluir los píxeles adicionales usados por caracteres como `f` en cursiva. Si el texto contiene nuevas líneas o tabuladores, estos no se expanden ni se tratan especiales cuando se mide el texto.
$font->metrics(-option?)
$widget->fontMetrics(font?, -option?)
Devuelve información sobre las métricas (datos específicos de la fuente), para font cuando se usa en el display de $widget. font es una descripción de una fuente; véase "DESCRIPCIÓN DE FUENTES" a continuación. Si option es especificado, devuelve el valor de esa métrica; si no se especifica, devuelve una lista de todas las métricas y sus valores. Véase "MÉTRICAS DE FUENTES" para una lista de las posibles métricas.
$widget->fontNames
El valor de retorno es una lista de todas las fuentes definidas actualmente para el MainWindow de $widget.

DESCRIPCIÓN DE FUENTES

Los siguientes formatos son aceptados como descripción de una fuente cuando font se especifica como un argumento anterior a la mencionada; estos mismos formatos también son permitidos cuando se especifique la opción -font para widgets.

[1] fontname
Nombre de una fuente nombrada creada con el método fontCreate. Cuando una widget usa una fuente nombrada, se garantiza que no causará un error, siempre que la fuente nombrada exista, independientemente de qué conjunto de atribuciones inválidas o no significativas puedan tener. Si la fuente nombrada no puede mostrarse con las atribuciones especificadas exactamente, se sustituirá automáticamente una fuente más cercana.
[1a] $font
Una fuente creada con el método Font. Este es prácticamente lo mismo que usar una fuente nombrada. El objeto es un puntero al nombre y lleva información adicional, como qué MainWindow esta relacionado en un modo peculiar a Perl/Tk.
[2] systemfont
Nombre específico de una fuente según el sistema, interpretada por el servidor de gráficos. También incluye, bajo X, un XLFD (ver [4]) para el cual se usaba un carácter ``*'', para omitir más de un campo en el nombre. Véase "PROBLEMAS DE SISTEMA" para una lista de las fuentes de sistema.
[3] [family,?size,??style,??style ...?]
Una lista bien formada donde el primer elemento es el familia deseada de la fuente y el segundo elemento (opcional) es el tamaño deseado. El interpretación del atributo size sigue las mismas reglas que para el -size en "OPCIONES DE FUENTES". Cualquier argumento adicional después del size es un estilo de fuente. Los valores posibles para los argumentos de style son los siguientes: 
normal      bold    roman   italic
underline   overstrike
[4] Nombres de fuente X (XLFD)
Nombre de una fuente centrado en Unix de la forma -foundry-family-weight-slant-setwidth-addstyle-pixel-point-resx-resy-spacing-width-charset-encoding. El caracter ``*'', puede usarse para omitir campos individuales que el usuario no prefiere. Deben haber exactamente un ``*'' para cada campo omitido, a menos que un ``*'' al final del XLFD omite cualquier campo restante; el XLFD más corto es simplemente ``*'', significando todos los campos como valores por defecto. Cualquier campo omitido tiene valores por defecto. Para compatibilidad, un XLFD siempre elige una fuente con el tamaño especificado (no el tamaño de punto); aunque este interpretación no es estrictamente correcta, todos los aplicaciones existentes que usen XLFDs supusieron que una ``puntación'' era en realidad un píxeles y se mostrarían incorrectamente (generalmente más grandes) si se utilizara un tamaño de fuente correcto.
[5] option value ?option value ...?
Una lista bien formada de pares option-value que especifiquen las atribuciones deseadas de la fuente, en el mismo formato que al definir una fuente nombrada; véase "OPCIONES DE FUENTES" a continuación.

Cuando se usa una descripción de fuente font, el sistema intenta parsear la descripción según cada una de las cinco reglas mencionadas, en el orden especificado. Los casos [1] y [2] deben coincidir con el nombre de una fuente existente o de una fuente del sistema. Los casos [3], [4] y [5] son aceptados en todos los sistemas y el más cercano.

OPCIONES DE FUENTES

Las siguientes son las opciones posibles para una fuente, según la descripción de la fuente:

family
La familia de la fuente deseada.
size
El tamaño de la fuente deseado.
style
El estilo de la fuente deseado.
weight
El peso de la fuente deseado.
slant
El estilo de la fuente deseado.
overstrike
La opción de sobreimpresión deseada.
underline
La opción de subrayado deseada.
spacing
La opción de espaciado deseada.
charset
El conjunto de caracteres deseado.
encoding
El conjunto de codificación deseado.

Las opciones family, size, style, weight, slant, overstrike, underline, spacing, charset, y encoding son opciones posibles de una fuente.

NOMBRE

Tk::Font - configurar y consultar fuentes tipográficas

DESCRIPCION

Este módulo proporciona un objeto de fuente tipográfica que se puede usar para configurar y consultar fuentes tipográficas de widgets de Tk. Cuando se usa la opción -family, Tk intenta encontrar la fuente nativa más cercana a la familia de fuentes solicitada. Si no es posible encontrar una fuente similar (por ejemplo, si el valor de la familia de fuentes es basura), se elige una fuente predeterminada dependiente del sistema. Si la descripción de la fuente no coincide con ninguno de los patrones anteriores, se genera un error.

METRICAS DE FUENTE

Las siguientes opciones son utilizadas por el método metrics/fontMetrics para consultar datos específicos de la fuente determinados cuando la fuente fue creada. Estas propiedades son para toda la fuente en sí y no para caracteres individuales dibujados en esa fuente. En las siguientes definiciones, la ``línea base'' de una fuente es la línea horizontal donde la parte inferior de la mayoría de las letras se alinea; ciertas letras, como la ``g'' minúscula, se extienden por debajo de la línea base.

-ascent
La cantidad en píxeles que la letra más alta se extiende por encima de la línea base de la fuente, más cualquier espacio en blanco adicional agregado por el diseñador de la fuente. (Se proporciona $font->ascent para compatibilidad.)
-descent
La cantidad máxima en píxeles que cualquier letra se extiende por debajo de la línea base de la fuente, más cualquier espacio en blanco adicional agregado por el diseñador de la fuente. (Se proporciona $font->descent para compatibilidad.)
-linespace
Devuelve la distancia vertical en píxeles entre dos líneas de texto que usan la misma fuente para que ningún carácter de una línea se superponga con ninguno de los caracteres de la otra línea. Generalmente, esta es la suma de la ascensión por encima de la línea base más la descenso por debajo de la línea base.
-fixed
Devuelve un indicador booleano que es ``1'' si esta es una fuente de ancho fijo, donde cada carácter normal tiene el mismo ancho que todos los demás caracteres, o es ``0'' si esta es una fuente de espaciado proporcional, donde los caracteres individuales tienen anchos diferentes. Los anchos de los caracteres de control, caracteres de tabulación y otros caracteres no imprimibles no se incluyen al calcular este valor.

OPCIONES DE FUENTE

Las siguientes opciones son compatibles en todas las plataformas y se utilizan al construir una fuente con nombre o al especificar una fuente usando el estilo [5] como se mencionó anteriormente:

-family => nombre
El nombre de la familia de fuentes, sin distinción entre mayúsculas y minúsculas. Tk garantiza la compatibilidad con las familias de fuentes llamadas Courier (una fuente monoespaciada "máquina de escribir"), Times (una fuente serif "periódico") y Helvetica (una fuente sans-serif "europea"). La familia de fuentes nativa más cercana se sustituirá automáticamente cuando se utilice una de las familias de fuentes anteriores. El nombre también puede ser el nombre de una familia de fuentes nativa específica de la plataforma; en ese caso, funcionará como se desea en una plataforma pero puede que no se muestre correctamente en otras plataformas. Si la familia no se especifica o no se reconoce, se elegirá una fuente predeterminada específica de la plataforma.
-size => tamaño
El tamaño deseado de la fuente. Si el argumento tamaño es un número positivo, se interpreta como un tamaño en puntos. Si tamaño es un número negativo, su valor absoluto se interpreta como un tamaño en píxeles. Si una fuente no se puede mostrar en el tamaño especificado, se elegirá un tamaño cercano. Si tamaño no se especifica o es cero, se elegirá un tamaño predeterminado dependiente de la plataforma.

Los autores originales de Tcl/Tk creían que los tamaños normalmente deberían especificarse en puntos para que la aplicación mantuviera el mismo tamaño de regla en la pantalla, incluso al cambiar las resoluciones de pantalla o al mover scripts entre plataformas. Si bien este es un objetivo admirable, en la práctica no funciona tan bien como esperaban. La correspondencia entre puntos y píxeles se establece cuando la aplicación se inicia, basándose en las supuestas propiedades del monitor instalado, pero se puede anular llamando al comando de escalado. Sin embargo, esto puede ser problemático cuando el sistema no tiene forma de saber si (por ejemplo) se adjunta un monitor de 11" o 22", además, si puede decirlo, entonces algunos tamaños de monitor pueden dar como resultado el uso de fuentes escaladas de menor calidad en lugar de una fuente de mapa de bits "ajustada". Además, especificar píxeles es útil en ciertas circunstancias, como cuando un fragmento de texto debe alinearse con respecto a un mapa de bits de tamaño fijo.

Actualmente, el esquema de Tcl/Tk se utiliza sin cambios, y el tamaño de "punto" se devuelve como real (como un entero) y se utiliza internamente. Se aceptan sugerencias para solucionar comportamientos indeseables.

-weight => peso
El grosor nominal de los caracteres de la fuente. El valor normal especifica una fuente de peso normal, mientras que bold especifica una fuente en negrita. Se elegirá el peso disponible más cercano al especificado. El peso predeterminado es normal.
-slant => inclinacion
La cantidad que los caracteres de la fuente están inclinados con respecto a la vertical. Los valores válidos para inclinación son roman e italic. Una fuente romana es la apariencia normal y vertical de una fuente, mientras que una fuente itálica es aquella que está inclinada un cierto número de grados desde la vertical. Se elegirá la inclinación disponible más cercana a la especificada. La inclinación predeterminada es roman.
-underline => booleano
El valor es un indicador booleano que especifica si los caracteres de esta fuente deben estar subrayados. El valor predeterminado para subrayado es false.
-overstrike => booleano
El valor es un indicador booleano que especifica si se debe dibujar una línea horizontal a través del medio de los caracteres de esta fuente. El valor predeterminado para sobreescritura es false.

Todos los nombres de fuentes X válidos, incluidos los enumerados por xlsfonts(1), están disponibles.
MS Windows:

COMPATIBILIDAD CON VERSIONES ANTERIORES

En versiones anteriores de perl/Tk, el método $widget->Font era un envoltorio de Perl del estilo original de "Nombres de fuentes X (XLFD) [4]" como se describe arriba (que era la única forma admitida por las versiones de tk principal anteriores a la versión tk8.0). Este módulo se proporciona en su forma original (simplemente se ha renombrado) a través de:

use Tk::X11Font;
I<$widget>-E<gt>B<X11Font>(...)

Sin embargo, los métodos del esquema antiguo se han imitado lo más cercanamente posible con el nuevo esquema. Se pretende que el código funcione sin modificaciones, excepto en el caso de usar:

@names = $font->Name;

es decir, el método Name en un contexto de matriz/lista. Ahora devuelve un elemento en todas las plataformas (como lo hacía en Win32), mientras que anteriormente en los sistemas X devolvía una lista de fuentes que coincidían con un patrón poco especificado.

En resumen, los métodos admitidos para compatibilidad son los siguientes:

$newfont = $font->Clone(-option=>value, ...>?)
Devuelve un nuevo objeto de fuente $newfont relacionado con el $font original cambiando los valores de los -options especificados.
$font->Family - se mapea a -family
$font->Weight - se mapea a -weight
$font->Slant - se mapea a -slant
$font->Pixel y Point - se mapean a -size

El nuevo código debe usar $font->configure para lograr el mismo efecto que los últimos cuatro elementos anteriores.

Foundry, Swidth, Adstyle, Xres, Yres, Space, Avgwidth, Registry, Encoding
Se ignoran si se establecen y devuelven '*' si se consultan.
$font->Name
Devuelve el nombre de una fuente con nombre o una representación en cadena de una fuente sin nombre. Usar $font en un contexto escalar hace lo mismo. Tenga en cuenta que esto es claramente diferente del comportamiento de Name de X11Font en un contexto de lista.
$font->Pattern
Devuelve una cadena XLFD para la fuente basada en los valores reales, y algunas heurísticas para mapear las formas de Tk a las convenciones estándar de X.
