NOMBRE

Tk::Toplevel - Crear y manipular widgets Toplevel

SINOPSIS

    $toplevel = $padre->Toplevel(?opciones?);

OPCIONES ESTÁNDAR

-borderwidth -highlightbackground -highlightthickness -takefocus -class -highlightcolor -relief -cursor

Ver Tk::options para detalles de las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: background
Clase: Background
Interruptor: -background
Esta opción es la misma que la opción estándar background excepto que su valor también puede especificarse como un valor indefinido. En este caso, el widget no mostrará fondo ni borde, y no se consumirán colores de su mapa de colores para su fondo y borde.
Nombre: colormap
Clase: Colormap
Interruptor: -colormap
Especifica un mapa de colores a utilizar para la ventana. El valor puede ser new, en cuyo caso se crea un nuevo mapa de colores para la ventana y sus hijos, o el nombre de otra ventana (que debe estar en la misma pantalla y tener la misma visual que $widget), en cuyo caso la nueva ventana utilizará el mapa de colores de la ventana especificada. Si la opción colormap no se especifica, la nueva ventana utiliza el mapa de colores predeterminado de su pantalla. Esta opción no se puede cambiar con el método configure.
Nombre: container
Clase: Container
Interruptor: -container
El valor debe ser booleano. Si es verdadero, significa que esta ventana se utilizará como un contenedor en el que se incrustará alguna otra aplicación (por ejemplo, un toplevel de Tk se puede incrustar usando la opción -use). La ventana admitirá los protocolos adecuados del gestor de ventanas para cosas como solicitudes de geometría. La ventana no debe tener hijos propios en esta aplicación. Esta opción no se puede cambiar con el método configure.
Nombre: height
Clase: Height
Interruptor: -height
Especifica la altura deseada para la ventana en cualquiera de las formas aceptables para Tk_GetPixels. Si esta opción es menor o igual a cero, la ventana no solicitará ningún tamaño.
Nombre: menu
Clase: Menu
Interruptor: -menu
Especifica un widget de menú para que se utilice como barra de menú. En Macintosh, la barra de menú se mostrará en la parte superior del monitor principal. En Microsoft Windows y todas las plataformas UNIX, el menú aparecerá en la ventana toplevel como parte de los adornos de ventana mantenidos por el gestor de ventanas.
Nombre: ""
Clase: ""
Interruptor: -screen
Especifica la pantalla en la que se colocará la nueva ventana. Se puede utilizar cualquier nombre de pantalla válido, incluso uno asociado a una pantalla diferente. Por defecto, la misma pantalla que su padre. Esta opción es especial porque no se puede especificar a través de la base de datos de opciones y no se puede modificar con el método configure.
Interruptor: -title
Especifica el título de la ventana toplevel.
Nombre: use
Clase: Use
Interruptor: -use
Esta opción se utiliza para la incrustación. Si el valor no es una cadena vacía, debe ser el identificador de ventana de una ventana contenedor, especificado como una cadena hexadecimal como las devueltas por el comando winfo id. El widget toplevel se creará como hijo del contenedor dado en lugar de la ventana raíz de la pantalla. Si la ventana contenedor está en una aplicación Tk, debe ser un widget de tipo frame o toplevel para el cual se especificó la opción -container. Esta opción no se puede modificar con el método configure.
Nombre: visual
Clase: Visual
Interruptor: -visual
Especifica la información visual para la nueva ventana en cualquiera de las formas aceptadas por Tk_GetVisual. Si esta opción no se especifica, la nueva ventana utilizará la visualización predeterminada de su pantalla. La opción visual no se puede modificar con el método configure.
Nombre: width
Clase: Width
Interruptor: -width
Especifica el ancho deseado para la ventana en cualquiera de las formas aceptables para Tk_GetPixels. Si esta opción es menor o igual a cero, la ventana no solicitará ningún tamaño.

DESCRIPCIÓN

El método Toplevel crea un nuevo widget toplevel (dado por el argumento $widget). Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del toplevel como su color de fondo y su relieve. El comando toplevel devuelve el nombre de ruta de la nueva ventana.

Un toplevel es similar a un frame, excepto que se crea como una ventana de nivel superior: su padre X es la ventana raíz de una pantalla en lugar del padre lógico de su nombre de ruta. El propósito principal de un toplevel es servir como contenedor para cuadros de diálogo y otras colecciones de widgets. Las únicas características visibles de un toplevel son su color de fondo y un borde 3D opcional para que el toplevel parezca elevado o hundido.

MÉTODOS DEL WIDGET

El método Toplevel crea un objeto widget. Este objeto admite los métodos configure y cget descritos en Tk::options, que pueden utilizarse para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget y la clase Tk::Wm.

BINDINGS

Cuando se crea un nuevo toplevel, no tiene bindings de eventos predeterminados: los toplevels no están diseñados para ser interactivos.
