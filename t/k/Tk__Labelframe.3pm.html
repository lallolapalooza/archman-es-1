NOMBRE

Tk::Labelframe - Crear y manipular widgets Labelframe

SINOPSIS

$labelframe = $parent->Labelframe(?opciones?);

-borderwidth -highlightbackground -pady
-cursor      -highlightcolor      -relief
-font        -highlightthickness  -takefocus
-foreground  -padx                -text

OPCIONES ESPECIFICAS DEL WIDGET

Opción: -background
Nombre: background
Clase: Background
Esta opción es la misma que la opción estándar background excepto que su valor también puede especificarse como una cadena vacía. En este caso, el widget no mostrará ningún fondo ni borde, y no se consumirán colores de su mapa de colores para su fondo y borde.
Opción: -class
Nombre: class
Clase: Class
Especifica una clase para la ventana. Esta clase se utilizará al consultar la base de datos de opciones para las otras opciones de la ventana, y también se utilizará posteriormente para otros fines, como enlaces. La opción class no puede modificarse con el método configure.
Opción: -colormap
Nombre: colormap
Clase: Colormap
Especifica un mapa de colores a utilizar para la ventana. El valor puede ser new, en cuyo caso se crea un nuevo mapa de colores para la ventana y sus hijos, o el nombre de otra ventana (que debe estar en la misma pantalla y tener la misma visual que $widget), en cuyo caso la nueva ventana utilizará el mapa de colores de la ventana especificada. Si no se especifica la opción colormap, la nueva ventana utiliza el mismo mapa de colores que su padre. Esta opción no puede modificarse con el método configure.
Opción: -container
Nombre: container
Clase: Container
El valor debe ser un booleano. Si es verdadero, significa que esta ventana se utilizará como contenedor en el que se incrustará alguna otra aplicación (por ejemplo, un toplevel de Tk se puede incrustar usando la opción -use). La ventana admitirá los protocolos del gestor de ventanas apropiados para cosas como solicitudes de geometría. La ventana no debe tener hijos propios en esta aplicación. Esta opción no puede modificarse con el método configure.
Opción: -height
Nombre: height
Clase: Height
Especifica la altura deseada para la ventana en cualquiera de las formas aceptables por Tk_GetPixels. Si esta opción es menor o igual que cero, la ventana no solicitará ningún tamaño.
Opción: -labelanchor
Nombre: labelAnchor
Clase: LabelAnchor
Especifica dónde colocar la etiqueta. Solo se muestra una etiqueta si la opción -text no es una cadena vacía. Los valores válidos para esta opción son (listados en sentido horario) nw, n, ne, en, e, es, se, s,sw, ws, w y wn. El valor predeterminado es nw.
Opción: -labelwidget
Nombre: labelWidget
Clase: LabelWidget
Especifica un widget para usar como etiqueta. Esto anula cualquier opción -text. El widget debe existir antes de ser utilizado como -labelwidget y si no es un descendiente de esta ventana, se colocará por encima de ella en el orden de apilamiento.
Opción: -visual
Nombre: visual
Clase: Visual
Especifica información visual para la nueva ventana en cualquiera de las formas aceptadas por Tk_GetVisual. Si no se especifica esta opción, la nueva ventana utilizará la misma visual que su padre. La opción visual no puede modificarse con el método configure.
Opción: -width
Nombre: width
Clase: Width
Especifica el ancho deseado para la ventana en cualquiera de las formas aceptables por Tk_GetPixels. Si esta opción es menor o igual que cero, la ventana no solicitará ningún tamaño.

DESCRIPCIÓN

El método Labelframe crea una nueva ventana (dada por el argumento $labelframe) y la convierte en un widget Labelframe. Opciones adicionales, descritas anteriormente, pueden ser especificadas en la línea de comandos o en la base de datos de opciones para configurar aspectos del Labelframe, como su color de fondo y relieve.

Un Labelframe es un widget simple. Su propósito principal es actuar como un espaciador o contenedor para diseños de ventanas complejos. Tiene las características de un Frame más la capacidad de mostrar una etiqueta.

MÉTODOS DEL WIDGET

El método Labelframe puede ser utilizado para invocar varias operaciones en el widget. Tiene la siguiente forma general:

$widget->method(?arg arg ...?);

Los siguientes métodos son posibles para los widgets Labelframe:

$widget->cget(opción);
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando Labelframe.
$widget->configure(?opción?, ?valor, opción, valor, ...?);
Consulta o modifica las opciones de configuración del widget. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para $widget (ver Tk::configure para obtener información sobre el formato de esta lista). Si se especifica opción sin ningún valor, el comando devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna opción). Si se especifican uno o más pares de opción-valor, el comando modifica las opciones del widget dadas para que tengan los valores dados; en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando Labelframe.

ENLACES

Al crear un nuevo Labelframe, no tiene enlaces de eventos predeterminados: los Labelframes no están pensados para ser interactivos.

VER TAMBIÉN
