NOMBRE

Tk::Frame - Crear y manipular widgets Frame

SINOPSIS

    $frame = $parent->Frame(?opciones?);

OPCIONES ESTÁNDAR

-borderwidth -highlightbackground -highlightthickness -takefocus -class -highlightcolor -relief -cursor

Ver Tk::options para detalles de las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre: background
Clase: Background
Interruptor: -background
Esta opción es la misma que la opción estándar background excepto que su valor también puede especificarse como un valor indefinido. En este caso, el widget no mostrará fondo ni borde, y no se consumirán colores de su mapa de colores para su fondo y borde.
Nombre: colormap
Clase: Colormap
Interruptor: -colormap
Especifica un mapa de colores a utilizar para la ventana. El valor puede ser new, en cuyo caso se crea un nuevo mapa de colores para la ventana y sus hijos, o el nombre de otra ventana (que debe estar en la misma pantalla y tener el mismo visual que $widget), en cuyo caso la nueva ventana utilizará el mapa de colores de la ventana especificada. Si la opción colormap no se especifica, la nueva ventana utiliza el mismo mapa de colores que su padre. Esta opción no puede modificarse con el método configure.
Nombre: container
Clase: Container
Interruptor: -container
El valor debe ser un booleano. Si es verdadero, significa que esta ventana se utilizará como contenedor en el que se incrustará alguna otra aplicación (por ejemplo, un toplevel de Tk se puede incrustar usando la opción -use). La ventana soportará los protocolos de gestor de ventanas apropiados para cosas como solicitudes de geometría. La ventana no debe tener hijos propios en esta aplicación. Esta opción no puede modificarse con el método configure.
Nombre: height
Clase: Height
Interruptor: -height
Especifica la altura deseada para la ventana en cualquiera de las formas aceptables para Tk_GetPixels. Si esta opción es menor o igual a cero, la ventana no solicitará ningún tamaño.
Nombre: visual
Clase: Visual
Interruptor: -visual
Especifica la información visual para la nueva ventana en cualquiera de las formas aceptadas por Tk_GetVisual. Si esta opción no se especifica, la nueva ventana utilizará el mismo visual que su padre. La opción visual no puede modificarse con el método configure.
Nombre: width
Clase: Width
Interruptor: -width
Especifica el ancho deseado para la ventana en cualquiera de las formas aceptables para Tk_GetPixels. Si esta opción es menor o igual a cero, la ventana no solicitará ningún tamaño.

DESCRIPCIÓN

El método Frame crea una nueva ventana (dada por el argumento $widget) y la convierte en un widget frame. Opciones adicionales, descritas anteriormente, pueden especificarse en la línea de comandos o en la base de datos de opciones para configurar aspectos del frame como su color de fondo y su relieve. El comando frame devuelve el nombre de ruta de la nueva ventana.

Un frame es un widget simple. Su propósito principal es actuar como un espaciador o contenedor para diseños de ventanas complejos. Las únicas características de un frame son su color de fondo y un borde opcional en 3D para que el frame parezca elevado o hundido.

MÉTODOS DEL WIDGET

El método Frame crea un objeto widget. Este objeto soporta los métodos configure y cget descritos en Tk::options, que pueden utilizarse para consultar y modificar las opciones descritas anteriormente. El widget también hereda todos los métodos proporcionados por la clase genérica Tk::Widget.

ASOCIACIONES

Cuando se crea un nuevo frame, no tiene asociaciones de eventos predeterminadas: los frames no están pensados para ser interactivos.
