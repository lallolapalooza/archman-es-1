NOMBRE

Tk::DropSite - Abstracción del lado de recepción de Arrastrar y Soltar

SINOPSIS

use Tk::DropSite qw(...);
$widget->DropSite(-entercommand => ...,
                  -dropcommand  => ...,
                  -motioncommand  => ...,
                  -dropcommand  => ...,
                 );

DESCRIPCIÓN

"DropSite" crea un objeto que representa un sitio en el que se pueden "Soltar" cosas.

Un DropSite proporciona los siguientes métodos:

$site->Enter($token,$event)
$site->Leave($token,$event)
$site->Motion($token,$event)
$site->Drop($token,$event)
