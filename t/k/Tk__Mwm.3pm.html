Mwm(3) Documentación de Perl contribuida por el usuario Mwm(3)

NOMBRE

Tk::Mwm - Comunicarse con el gestor de ventanas Motif(tm).

SINOPSIS

    use Tk::Mwm;

    $toplevel->mwmOpción?(args)?

    $toplevel->mwm(opción ?,args?)

DESCRIPCIÓN

Interfaz a extensiones especiales soportadas por mwm.

MÉTODOS

$toplevel->mwmDecoration?(?opción??=>valor? ?,...?)?
Cuando no se proporcionan opciones, este método devuelve los valores de todas las opciones de decoración para la ventana de nivel superior con $toplevel. Cuando solo se proporciona una opción sin especificar el valor, se devuelve el valor actual de esa opción. Cuando se pasan más de un par de "opción-valor" a este método, los valores especificados se asignarán a las opciones correspondientes. Como resultado, la apariencia de las decoraciones de Motif alrededor de la ventana de nivel superior cambiará. Las opciones posibles son: -border, -menu, -maximize, -minimize, -resizeh y -title. El valor debe ser un valor booleano. Los valores devueltos por este comando no están definidos cuando la ventana no es administrada por mwm.
$toplevel->mwmIsmwmrunning
El valor devuelto es verdadero si mwm se está ejecutando en la pantalla donde se encuentra la ventana especificada, falso en caso contrario.
$toplevel->mwmProtocol
Cuando no se proporcionan opciones adicionales, este método devuelve todos los protocolos asociados con esta ventana de nivel superior.
$toplevel->mwmProtocol(activate => nombre_protocolo)
Activa el mensaje del protocolo mwm en el menú de mwm.
$toplevel->MwmProtocol(add => nombre_protocolo, mensaje_menu)
Agrega un nuevo mensaje de protocolo mwm para esta ventana de nivel superior. El mensaje se identifica mediante la cadena de nombre especificada en nombre_protocolo. Se agregará un elemento de menú en el menú de mwm según lo especificado por mensaje_menu. Una vez que se agrega un nuevo mensaje de protocolo mwm a una ventana de nivel superior, puede ser capturado por el método protocol de TK. Aquí hay un ejemplo:

    $toplevel->mwmProtocol('add' => 'MI_IMPRIME_HOLA', '"Imprimir Hola" _H Ctrl<Key>H');

    $toplevel->protocol('MI_IMPRIME_HOLA' => sub {print "Hola"});

$toplevel->mwmProtocol('deactivate' => nombre_protocolo)
Desactiva el mensaje del protocolo mwm en el menú de mwm.
$toplevel->mwmProtocol('delete' => nombre_protocolo)
Elimina el mensaje del protocolo mwm del menú de mwm. Tenga en cuenta que el manejador del protocolo del gestor de ventanas asociado con este protocolo (por el método protocol) no se elimina automáticamente. Debe eliminar el manejador del protocolo explícitamente. Por ejemplo:

    $mw->mwmProtocol('delete' => 'MI_IMPRIME_HOLA');

    $mw->protocol('MI_IMPRIME_HOLA' => '');

ERRORES

Esta es una extensión de Tix que perl/Tk ha adoptado. No ha sido probada ya que el autor de perl/Tk no ha tenido tiempo de instalar un gestor de ventanas Motif.

En algunas versiones de mwm, el -border no desaparecerá a menos que -resizeh esté desactivado. Además, el -title no desaparecerá a menos que se desactiven todos los -title, -menu, -maximize y -minimize.
