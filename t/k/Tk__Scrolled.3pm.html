NOMBRE

Tk::Scrolled - Crea un widget con barra(s) de desplazamiento adjunta(s)

SINOPSIS

    $cualquiera = $padre->Scrolled(Cualquiera ?,-barrasdesplazamiento=>donde? ?,...?);

DESCRIPCIÓN

Para detener una avalancha de widgets ScrlWhatever, Perl/Tk introdujo el constructor especial Scrolled. Scrolled crea un widget de la Clase dada Whatever con barra(s) de desplazamiento adjunta(s).

OPCIONES

Todas las opciones, aparte de -barrasdesplazamiento explicadas a continuación, se pasan al constructor del widget Whatever.

-barrasdesplazamiento
Espera como argumento la posición donde se deben crear las barras de desplazamiento: w, e o n, s o una combinación de ellas. Si uno o ambos posiciones van precedidas de o, la barra de desplazamiento solo aparecerá si hay una necesidad 'real' de desplazarse.

SUBWIDGETS ANUNCIADOS

Ver "Subwidget" en Tk::mega sobre cómo usar widgets anunciados.

scrolled
el widget desplazado
widget
igual que scrolled arriba. widget es el tipo de widget pasado a scrolled como primer argumento en minúsculas.
xscrollbar
el widget Scrollbar utilizado para el desplazamiento horizontal (si existe)
yscrollbar
el widget Scrollbar utilizado para el desplazamiento vertical (si existe)
corner
un marco en la esquina entre la barra de desplazamiento vertical y la horizontal

ERRORES

Si un widget no admite las opciones -{x,y}scrollcommand, Scrolled no se queja si la clase de widget especificada no las admite. Por ejemplo:

    $padre->Scrolled('Button', ...)

No se recibe un mensaje de error ni una advertencia cuando se intenta configurar las barras de desplazamiento después de la construcción del widget:

    $ascrolled->configure(-barrasdesplazamiento => 'e');
