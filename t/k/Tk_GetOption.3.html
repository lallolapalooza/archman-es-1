Tk_GetOption(3) Procedimientos de la biblioteca Tk Tk_GetOption(3)

NOMBRE

Tk_GetOption - recuperar una opción de la base de datos de opciones

SINOPSIS

#include <tk.h>

Tk_Uid
Tk_GetOption(tkwin, name, class)

ARGUMENTOS

Tk_Window tkwin (entrada)
Token para la ventana.
const char *name (entrada)
Nombre de la opción deseada.
const char *class (entrada)
Clase de la opción deseada. Nulo significa que no hay clase para esta opción; realizar la búsqueda basándose solo en el nombre.

DESCRIPCIÓN

Este procedimiento se invoca para recuperar una opción de la base de datos asociada con la ventana principal de tkwin. Si existe una opción para tkwin que coincida con el name o class dados, entonces se devuelve en forma de Tk_Uid. Si coinciden múltiples opciones con name y class, entonces se devuelve la de mayor prioridad. Si ninguna opción coincide, entonces se devuelve NULL.

Tk_GetOption almacena en caché las opciones relacionadas con tkwin para que las llamadas sucesivas para la misma tkwin se ejecuten mucho más rápido que las llamadas sucesivas para diferentes ventanas.
