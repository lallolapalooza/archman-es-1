Tk_CreateBindingTable(3) Procedimientos de la biblioteca Tk Tk_CreateBindingTable(3)

NOMBRE

Tk_CreateBindingTable, Tk_DeleteBindingTable, Tk_CreateBinding, Tk_DeleteBinding, Tk_GetBinding, Tk_GetAllBindings, Tk_DeleteAllBindings, Tk_BindEvent - invocar scripts en respuesta a eventos X

SINOPSIS

#include <tk.h>

Tk_BindingTable
Tk_CreateBindingTable(interp)

Tk_DeleteBindingTable(bindingTable)

unsigned long
Tk_CreateBinding(interp, bindingTable, object, eventString, script, append)

int
Tk_DeleteBinding(interp, bindingTable, object, eventString)

const char *
Tk_GetBinding(interp, bindingTable, object, eventString)

Tk_GetAllBindings(interp, bindingTable, object)

Tk_DeleteAllBindings(bindingTable, object)

Tk_BindEvent(bindingTable, eventPtr, tkwin, numObjects, objectPtr)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a utilizar al invocar enlaces en la tabla de enlaces. También se utiliza para devolver resultados y errores de los procedimientos de enlace.
Tk_BindingTable bindingTable (entrada)
Token para la tabla de enlaces; debe haber sido devuelto por alguna llamada anterior a Tk_CreateBindingTable.
ClientData object (entrada)
Identifica el objeto con el que está asociado el enlace.
const char *eventString (entrada)
Cadena que describe la secuencia de eventos.
const char *script (entrada)
Script de Tcl a invocar cuando se activa el enlace.
int append (entrada)
Distinto de cero significa añadir script al script existente para el enlace, si lo hay; cero significa reemplazar el script existente por uno nuevo.
XEvent *eventPtr (entrada)
Evento X a emparejar con los enlaces en bindingTable.
Tk_Window tkwin (entrada)
Identificador de cualquier ventana en la pantalla donde ocurrió el evento. Se utiliza para encontrar información relacionada con la pantalla, como mapas de teclas.
int numObjects (entrada)
Número de identificadores de objeto apuntados por objectPtr.
ClientData *objectPtr (entrada)
Apunta a una matriz de identificadores de objeto: se considerarán los enlaces para cada uno de estos objetos en orden, de primero a último.

DESCRIPCIÓN

Estos procedimientos proporcionan un mecanismo de propósito general para crear e invocar enlaces. Los enlaces se organizan en términos de tablas de enlaces. Una tabla de enlaces consiste en una colección de enlaces más un historial de eventos recientes. Dentro de una tabla de enlaces, los enlaces se asocian con objetos. El significado de un objeto lo definen los clientes del paquete de enlaces. Por ejemplo, Tk utiliza una tabla de enlaces para almacenar todos los enlaces creados por el comando bind. Para esta tabla, los objetos son punteros a cadenas como nombres de ventanas, nombres de clase u otras etiquetas de enlace como all. Tk también mantiene una tabla de enlaces separada para cada widget de lienzo, que gestiona los enlaces creados por el comando de widget bind del lienzo; dentro de esta tabla, un objeto es un puntero a la estructura interna de un elemento del lienzo o un Tk_Uid que identifica una etiqueta.

El procedimiento Tk_CreateBindingTable crea una nueva tabla de enlaces y asocia interp con ella (cuando se invocan los enlaces de la tabla, los scripts se evaluarán en interp). Tk_CreateBindingTable devuelve un token para la tabla, que debe usarse en llamadas a otros procedimientos como Tk_CreateBinding o Tk_BindEvent.

Tk_DeleteBindingTable libera todo el estado asociado con una tabla de enlaces. Una vez que retorna, el llamante ya no debe usar el token bindingTable.

Tk_CreateBinding añade un nuevo enlace a una tabla existente. El argumento object identifica el objeto con el que se va a asociar el enlace, y puede ser cualquier valor de una sola palabra. Típicamente es un puntero a una cadena o estructura de datos. El argumento eventString identifica el evento o secuencia de eventos para el enlace; consulte la documentación del comando bind para una descripción de su formato. script es el script de Tcl que se evaluará cuando se active el enlace. append indica qué hacer si ya existe un enlace para object y eventString: si append es cero, script reemplaza el script antiguo; si append es distinto de cero, el nuevo script se añade al antiguo. Tk_CreateBinding devuelve una máscara de eventos X para todos los eventos asociados con los enlaces. Esta información puede ser útil para invocar XSelectInput para seleccionar eventos relevantes, o para no permitir el uso de ciertos eventos en los enlaces. Si ocurrió un error al crear el enlace (por ejemplo, eventString se refiere a un evento inexistente), entonces se devuelve 0 y se deja un mensaje de error como resultado del intérprete interp.

Tk_DeleteBinding elimina de bindingTable el enlace dado por object y eventString, si dicho enlace existe. Tk_DeleteBinding siempre devuelve TCL_OK. En algunos casos, puede restablecer el resultado del intérprete al valor vacío predeterminado.

Tk_GetBinding devuelve un puntero al script asociado con eventString y object en bindingTable. Si no existe dicho enlace, se devuelve NULL y se deja un mensaje de error como resultado del intérprete interp.

Tk_GetAllBindings devuelve en el resultado de interp una lista de todas las cadenas de eventos para las que existen enlaces en bindingTable asociados con object. Si no hay enlaces para object, el resultado será una cadena vacía.

Tk_DeleteAllBindings elimina todos los enlaces en bindingTable que están asociados con object.

Tk_BindEvent se llama para procesar un evento. Realiza una copia del evento en una lista de historial interna asociada con la tabla de enlaces, luego busca enlaces que coincidan con el evento. Tk_BindEvent procesa cada uno de los objetos apuntados por objectPtr en orden. Para cada objeto, encuentra todos los enlaces que coinciden con el historial de eventos actual, selecciona el enlace más específico utilizando el mecanismo de prioridad descrito en la documentación de bind, e invoca el script para ese enlace. Si no hay enlaces coincidentes para un objeto particular, se ignora el objeto. Tk_BindEvent continúa a través de todos los objetos, manejando excepciones como errores, break y continue como se describe en la documentación de bind.
