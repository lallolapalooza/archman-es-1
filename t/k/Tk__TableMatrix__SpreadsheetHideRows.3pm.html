NOMBRE

Tk::TableMatrix::SpreadsheetHideRows - Visualización de tabla con ocultación/revelación de filas seleccionable

SINOPSIS

use Tk;
use Tk::TableMatrix::SpreadsheetHideRows
my $t = $top->Scrolled('SpreadsheetHideRows', 
  -selectorCol => 3,
  -expandData => $hashRef,
  -rows => 21, -cols => 11, 
  -width => 6, -height => 6,
  -titlerows => 1, -titlecols => 1,
  -variable => $arrayVar,
  -selectmode => 'extended',
  -resizeborders => 'both',
  -bg => 'white',
);

DESCRIPCIÓN

Tk::TableMatrix::SpreadsheetHideRows es un widget derivado de Tk::TableMatrix::Spreadsheet que implementa una visualización similar a una hoja de cálculo de información tabular, donde algunas de las filas de la tabla pueden expandirse/ocultarse haciendo clic en un selector '+/-' en la fila. Esto se puede usar para mostrar información de nivel superior en una tabla, al tiempo que se permite al usuario expandir ciertas filas de la tabla para ver información de nivel de detalle.

Consulte demos/SpreadsheetHideRows en la distribución fuente para un ejemplo sencillo de este widget

Opciones específicas del widget

Además de las opciones estándar del widget Tk::TableMatrix. Se implementan las siguientes opciones:

-selectorCol
Número de columna donde aparecerá el selector +/-. Hacer clic en el selector +/- expandirá/ocultará la información de detalle en la tabla para una fila en particular.
-selectorColWidth
Ancho de la columna utilizada para mostrar el selector +/-. Por defecto es 2.
-expandData
Referencia hash que define los datos de nivel de detalle que se muestran cuando se expande una fila (haciendo clic en el selector +/-). Esta referencia hash debe tener la siguiente estructura: 
$expandData = {  
      row1 => {  tag  => 'detailDataTag',
                 data => $detailData,
                 spans=> $spanData,
                 expandData => $subLevelData
              },
      row2 => { 
         .
         .
}

Donde: 
  row1, row2, ...         Números de fila que serán expandibles.
  tag => 'detailDataTag'  Nombre de la etiqueta que se aplicará a los datos de detalle.
                          (opcional)
  $detailData              Matriz 2D de datos de detalle que se mostrarán cuando
                           se expanda la fila.
                           ej: [ [ r1c1, r1c2, r1c3 ],
                                  [ r2c1, r2c2, r2,c3] ]
  $spans                   Matriz 1D de información de espaciado (opcional) que se
                           utilizará para mostrar la información de detalle.
                           ej:  [ col2 =>  "rows,cols", col4 =>  "rows,cols", ... ]
  $subLevelData            Opcional expandData recursivo utilizado para almacenar
                           los datos de detalle de los datos de detalle.

DATOS DEL MIEMBRO

Los siguientes elementos se almacenan como datos de miembro

defaultCursor
Nombre del puntero del cursor del ratón que se utiliza para las celdas normales (es decir, no de título, no de indicador) en el widget. Se establece en el valor de la opción $widget->cget(-cursor) cuando se crea el widget.
indRowCols
Referencia hash de índices de Fila/Columna donde hay indicadores almacenados. Esta es una referencia hash rápida construida a partir de _expandData.
_expandData
Versión interna del hash expandData. Cualquier sub-detalle de datos (es decir, datos de expansión que se encuentran en niveles inferiores de expandData) que sea visible se coloca en el nivel superior de este hash, para llevar un registro de los expandData visibles.

Métodos del widget

Además del método estándar del widget Tk::TableMatrix. Se implementan los siguientes métodos:

showDetail

Muestra (es decir, expande la tabla) los datos de detalle para una fila dada. Este método se llama cuando un usuario hace clic en un indicador que no está ya expandido.

Uso:

$widget->showDetail($row);  

# Muestra los datos de detalle para la fila número $row

hideDetail

Oculta los datos de detalle para una fila dada. Este método se llama cuando un usuario hace clic en un indicador que ya está expandido.

Uso:

$widget->hideDetail($row);  

# Oculta los datos de detalle para la fila número $row
