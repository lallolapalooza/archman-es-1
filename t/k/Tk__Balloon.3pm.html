NOMBRE

Tk::Balloon - mostrar globos de ayuda emergentes.

SINOPSIS

use Tk::Balloon;
...
$b = $top->Balloon(-statusbar => $widget_de_barra_de_estado);
# Balloon normal:
$b->attach($widget,
           -balloonmsg => "Mensaje de ayuda del balloon",
           -statusmsg => "Mensaje de la barra de estado");
# Balloon adjunto a entradas en un widget de menú:
$b->attach($menu, -state => 'status',
                  -msg => ['primer elemento del menú',
                           'segundo elemento del menú',
                           ...
                          ],
          );
# Balloon adjunto a elementos individuales en un widget de lienzo:
$b->attach($canvas, -balloonposition => 'mouse',
                    -msg => {'item1' => 'msg1',
                             'tag2'  => 'msg2',
                              ...
                            },
          );
# Balloon adjunto a elementos en un widget de listbox:
$b->attach($listbox, -balloonposition => 'mouse',
                     -msg => ['primer elemento de listbox',
                              'segundo elemento de listbox',
                              ...
                             ],
          );

DESCRIPCIÓN

Balloon proporciona el marco para crear y adjuntar globos de ayuda a varios widgets para que, cuando el ratón se detenga sobre el widget durante más de una cantidad de tiempo especificada, aparezca un globo de ayuda.

Globos y Menús o Listboxes

Si el balloon se adjunta a un widget Menu o Listbox y los argumentos del mensaje son referencias a arrays, entonces cada elemento en el array será el mensaje correspondiente a una entrada de menú o elemento de listbox. El mensaje del balloon se mostrará para la entrada sobre la que el ratón se detenga. De lo contrario, se asume que el balloon se adjuntará al widget Menu o Listbox en su conjunto. Puede tener mensajes de estado y de balloon separados, al igual que los balloons normales.

Globos y Lienzos

Si el balloon se adjunta a un widget Canvas y los argumentos del mensaje son referencias a hashes, entonces cada clave del hash debe corresponder a un ID de elemento o etiqueta del lienzo y el valor asociado corresponderá al mensaje para ese elemento del lienzo. El mensaje del balloon se mostrará para el elemento actual (el que está en la posición del ratón). De lo contrario, se asume que el balloon se adjuntará al widget Canvas en su conjunto. Puede tener mensajes de estado y de balloon separados, al igual que los balloons normales.

Globos y HLists

Si el balloon se adjunta a un widget HList y los argumentos del mensaje son referencias a hashes, entonces cada clave del hash debe corresponder a una ruta de HList y el valor asociado corresponderá al mensaje para ese elemento HList. El mensaje del balloon se mostrará para el elemento actual (el que está en la posición del ratón). De lo contrario, se asume que el balloon se adjuntará al widget HList en su conjunto. Puede tener mensajes de estado y de balloon separados, al igual que los balloons normales.

Posición del Balloon

Por defecto, el balloon aparece en la parte inferior derecha del cliente. Si se saliera del borde inferior de la pantalla, se posiciona en la parte superior derecha. Si se saliera del borde derecho de la pantalla, se muestra en la parte inferior izquierda del cliente. Si se saliera tanto del borde inferior como del derecho de la pantalla, se posiciona en la parte superior izquierda del cliente. Por lo tanto, la pequeña flecha siempre apunta al cliente adjunto.

OPCIONES

Balloon acepta todas las opciones que acepta el widget Frame. Además, también se reconocen las siguientes opciones.

-initwait
Especifica el tiempo de espera sin actividad antes de mostrar un globo de ayuda emergente. Especificado en milisegundos. El valor por defecto es 350 milisegundos. Esto se aplica tanto al balloon emergente como al mensaje de la barra de estado.
-state
Puede ser uno de 'balloon', 'status', 'both' o 'none', indicando que el globo de ayuda, la ayuda de la barra de estado, ambos o ninguno respectivamente deben activarse cuando el ratón se detiene sobre el widget cliente. El valor por defecto es 'both'.
-statusbar
Especifica el widget que se utiliza para mostrar el mensaje de estado. Este widget debe aceptar la opción -text y típicamente es un widget Label. Si el widget acepta la opción -textvariable y esa opción está definida, entonces se usa en lugar de la opción -text.
-balloonposition
Puede ser 'widget' o 'mouse'. Controla dónde aparecerá el balloon. 'widget' hace que el balloon aparezca en la esquina inferior derecha del widget al que está adjunto (por defecto), y 'mouse' hace que el balloon aparezca debajo y a la derecha de la posición actual del ratón.
-postcommand
Esta opción toma una referencia a una función (CODE) que se ejecutará antes de que se muestren los mensajes del balloon y de la barra de estado, y debe devolver un valor verdadero o falso para indicar si desea mostrar el balloon o no. Esto también le permite controlar dónde se posiciona el balloon devolviendo un valor verdadero que se parezca a X,Y (coincide con esta expresión regular: "/^(\d+),(\d+)$/"). Si la función llamada por postcommand devuelve un valor que coincide con esa expresión regular, esas coordenadas se usarán como la posición para mostrar el balloon. Advertencia: esta subrutina debe devolver el resultado rápidamente o la respuesta del balloon parecerá lenta.
-cancelcommand
Esta opción toma una referencia a una función (CODE) que se ejecutará antes de que se cancelen los mensajes del balloon y de la barra de estado, y debe devolver un valor verdadero o falso para indicar si desea cancelar el balloon o no. Advertencia: esta subrutina debe devolver el resultado rápidamente o la respuesta del balloon parecerá lenta.
-motioncommand
Esta opción toma una referencia a una función (CODE) que se ejecutará para cualquier evento de movimiento y debe devolver un valor verdadero o falso para indicar si el balloon actualmente mostrado debe ser cancelado (desactivado). Si devuelve verdadero, el balloon definitivamente será cancelado; si devuelve falso, aún puede ser cancelado dependiendo de las reglas internas. Nota: puede aparecer un nuevo balloon después del intervalo de tiempo -initwait; use la opción -postcommand para controlar ese comportamiento. Advertencia: la subrutina debe ser extremadamente rápida o la respuesta del balloon parecerá lenta y consumirá mucha CPU (se ejecuta cada vez que el ratón se mueve sobre los widgets a los que está adjunto el balloon).
-numscreens
Esta opción acepta un entero de 1 o mayor. Esta opción debe usarse para evitar globos desarticulados en múltiples pantallas en modo de pantalla lógica única (SLS). Esto solo funciona actualmente en la dirección horizontal. Ejemplo: Si está ejecutando pantallas duales en modo SLS, entonces establecería este valor a 2. El valor por defecto es 1.

MÉTODOS

El widget Balloon solo admite tres métodos no estándar:

attach(widget, opciones)

Adjunta el widget indicado por widget al sistema de ayuda. Las opciones permitidas son:

-statusmsg
El argumento es el mensaje que se mostrará en la barra de estado cuando el ratón se detenga sobre este cliente. Si no se especifica, pero se especifica -msg, entonces el mensaje que se muestra en la barra de estado es el mismo que el argumento para -msg. Si le da una referencia escalar, esta se desreferencia antes de mostrarse. Útil si se usa postcommand para cambiar el mensaje.
-balloonmsg
El argumento es el mensaje que se mostrará en el balloon emergente. Si este no se especifica, pero se especifica -statusmsg, entonces el mensaje mostrado en el balloon es el mismo que el argumento para -statusmsg. Si le da una referencia escalar, esta se desreferencia antes de mostrarse. Útil si se usa postcommand para cambiar el mensaje.
-msg
Esta es una forma abreviada de especificar tanto -balloonmsg como -statusmsg. Si el argumento es una cadena, se usa como mensaje para ambos. Si es una referencia a array o hash, vea la sección "DESCRIPCIÓN" arriba.
-state
Puede ser uno de 'balloon', 'status', 'both' o 'none' indicando que el globo de ayuda, la ayuda de la barra de estado, ambos o ninguno respectivamente deben activarse cuando el ratón se detiene sobre este cliente. El valor por defecto es el valor de la opción -state del widget Balloon.

configure(options)

Configure las opciones de un balloon adjunto.

detach(widget)

Separa el widget del sistema de ayuda.

cursor(cursorName)

Establece el cursor que se utilizará para los widgets adjuntos.

on(widget)

Activa el balloon para el widget dado.

off(widget)

Desactiva el balloon para el widget dado.

hide

Oculta cualquier balloon visible actualmente.

show

Muestra el balloon para el widget principal del balloon.

destroy

Destruye el balloon y libera toda la memoria asociada.

EJEMPLO

use Tk;
use Tk::Balloon;

my $top = MainWindow->new(-title => "Balloon Example");

my $status = $top->Label(-text => '', -relief => 'sunken', -anchor => 'w')->pack(-side => 'bottom', -fill => 'x');
my $b = $top->Balloon(-statusbar => $status);

my $f1 = $top->Frame()->pack(-pady => 10);
my $button1 = $f1->Button(-text => "Pulsar Aquí")->pack(-side => 'left', -padx => 10);
$b->attach($button1,
           -balloonmsg => "Este es un botón que puedes pulsar.",
           -statusmsg => "Botón de ejemplo");

my $button2 = $f1->Button(-text => "No Pulsar")->pack(-side => 'left', -padx => 10);
$b->attach($button2,
           -balloonmsg => "Este botón no hace nada útil.",
           -statusmsg => "Otro botón");

my $f2 = $top->Frame()->pack(-pady => 10);
my $menu = $f2->Menubutton(-text => "Menú", -tearoff => 0)->pack(-side => 'left', -padx => 10);
$menu->menu(
    -postcommand => sub { $b->configure(-state => 'status') },
    -command => sub { $b->configure(-state => 'both') },
)->add('command', -label => "Opción 1", -command => sub { print "Opción 1 seleccionada\n"; })
 ->add('command', -label => "Opción 2", -command => sub { print "Opción 2 seleccionada\n"; });

$b->attach($menu, -state => 'balloon',
                -msg => ["Primera opción del menú",
                         "Segunda opción del menú",
                        ],
        );

MainLoop;

Tk::Balloon(3pm) — perl-tk — Arch Linux MAN PAGES

NAME

Tk::Balloon - associate pop-up messages with widgets

SYNOPSIS

use Tk::Balloon;
my $balloon = $w->Balloon(?options?)
$balloon->attach($widget, ?options?)
$balloon->detach($widget)
$balloon->destroy

DESCRIPTION

A Balloon widget is used to display short informational messages that are associated with other widgets. When the mouse cursor pauses over a widget that has been attached to a Balloon, a small pop-up window (the balloon) will appear next to the cursor, displaying the message. The message will disappear when the mouse cursor moves off the widget, or when a button is pressed.

Balloons are intended to provide simple, context-sensitive help. They are not intended to replace more complex help systems.

The Balloon widget is a subclass of Tk::Toplevel, but it is usually created using the Balloon method on a widget, rather than directly.

OPTIONS

Balloon widgets support the following general configuration options, in addition to the standard Tk widget options:

-balloonborderwidth number
Specifies the width of the border around the balloon window. Defaults to the border width of the main window.
-balloonfont font
Specifies the font to be used for the text within the balloon. Defaults to the font of the main window.
-balloonforeground color
Specifies the foreground color for the text within the balloon. Defaults to the foreground color of the main window.
-balloonrelief relief
Specifies the relief for the border around the balloon window. Defaults to raised.

METHODS

attach(widget ?options?)
Attaches the specified widget to the balloon. The widget must be a direct child of the balloon widget's parent. Any options specified are associated with this particular widget. These options override any globally set options for the balloon itself.
detach(widget)
Detaches the specified widget from the balloon. The widget will no longer show a balloon message when the mouse pauses over it.
destroy
Destroys the balloon widget and all associated pop-up windows.

The following options can be specified when attaching a widget to a balloon, or when creating the balloon itself (in which case they apply to all attached widgets unless overridden):

-balloonmsg
El argumento es el mensaje que se mostrará en el globo que aparecerá cuando el ratón se detenga sobre este cliente. Al igual que con -statusmsg, si no se especifica, toma su valor de la especificación -msg si existe. Si no se especifica ni -balloonmsg ni -msg, o si son la cadena vacía, entonces no aparecerá ningún globo en lugar de un globo vacío. Si le da una referencia escalar, se desenreferencia antes de mostrarse. Útil si el postcommand se utiliza para cambiar el mensaje.
-msg
El comodín para -statusmsg y -balloonmsg. Esta es una forma conveniente de especificar el mismo mensaje que se mostrará tanto en el globo como en la barra de estado para el cliente.
-initwait
-state
-statusbar
-balloonposition
-postcommand
-cancelcommand
-motioncommand
Estas opciones le permiten anular el valor predeterminado del globo para esas opciones para algunos de los widgets a los que está adjunto. Acepta los mismos valores que los anteriores y tendrá como valor predeterminado el valor de Balloon.

detach(widget)

Desvincula el widget especificado del sistema de ayuda.

destroy

Destruye el globo especificado.

ADVERTISED SUBWIDGETS

La etiqueta del globo se anuncia como "message".

EXAMPLES

Vea la demostración de globos incluida con el script de demostración de widgets que vino con la distribución para ver ejemplos de diversas formas de usar globos.

NOTES

Debido a la sobrecarga asociada con cada globo que crea (desde el seguimiento del movimiento del ratón para saber cuándo activarlos y desactivarlos), verá el mejor rendimiento (bajo consumo de CPU) si crea tantos globos como sea posible y los adjunta a tantos widgets como pueda. En otras palabras, no cree un globo para cada widget al que desee adjuntar uno.

CAVEATS

Al pulsar cualquier botón se desactivará (cancelará) el globo actual, si existe. Normalmente, puede hacer que el globo reaparezca moviendo un poco el ratón. El uso creativo de las 3 opciones de comando puede ayudarle también. Si el ratón está sobre el globo cuando se despubblica un menú, el globo permanecerá hasta que se mueva fuera de él.

BUGS

Si se utilizan globos adjuntos a entradas de listbox o elementos de canvas en un widget desplazable, entonces se debe usar el subwidget:

$balloon->attach($w->Subwidget("scrolled"), -msg => ...);
