NOMBRE

Tk_CollapseMotionEvents, Tk_QueueWindowEvent - Añadir un evento de ventana a la cola de eventos de Tcl

SINOPSIS

#include <tk.h>

int
Tk_CollapseMotionEvents(display, collapse)

Tk_QueueWindowEvent(eventPtr, position)

ARGUMENTOS

Display *display (entrada)
Pantalla para la que controlar la colapso de eventos de movimiento.
int collapse (entrada)
Indica si los eventos de movimiento deben colapsarse o no.
XEvent *eventPtr (entrada)
Un evento para añadir a la cola de eventos. Es importante que todos los campos no utilizados de la estructura se establezcan a cero.
Tcl_QueuePosition position (entrada)
Dónde añadir el nuevo evento en la cola: TCL_QUEUE_TAIL, TCL_QUEUE_HEAD, o TCL_QUEUE_MARK.

DESCRIPCIÓN

Tk_QueueWindowEvent coloca un evento de ventana en la cola de eventos interna de Tcl para su posterior procesamiento. Crea una estructura Tcl_Event, copia el evento en esa estructura y llama a Tcl_QueueEvent para añadir el evento a la cola. Cuando el evento se elimine finalmente de la cola, se procesará como todos los eventos de ventana.

Cuando se reciben múltiples eventos de movimiento para la misma ventana en rápida sucesión, se colapsan por defecto. Este comportamiento puede controlarse con Tk_CollapseMotionEvents. Tk_CollapseMotionEvents siempre devuelve el valor anterior para el comportamiento de colapso en la display.

El argumento position de Tk_QueueWindowEvent tiene el mismo significado que para Tcl_QueueEvent; consulte la documentación de Tcl_QueueEvent para obtener más detalles.
