NOMBRE

Tk::PNG - Cargador PNG para Tk::Photo

SINOPSIS

use Tk;
use Tk::PNG;
my $image = $widget->Photo('-format' => 'png', -file => 'something.png');

DESCRIPCIÓN

Esta es una extensión para Tk que proporciona un cargador de formato PNG para el tipo de imagen Photo.

HISTORIA

Esta extensión viene incluida por defecto con Perl/Tk desde Tk804.
