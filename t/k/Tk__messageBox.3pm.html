NOMBRE

Tk::messageBox - mostrar una ventana de mensaje y esperar la respuesta del usuario.

SINOPSIS

    $respuesta = $widget->messageBox(-opción => valor, ... );

DESCRIPCIÓN

Este método utiliza Tk::Dialog para crear rápidamente varias cajas de diálogo comunes. Un widget de diálogo consta de un mensaje, un ícono y un conjunto de botones (ver la opción -tipo). Después de que se muestra la ventana del mensaje, messageBox espera a que el usuario seleccione uno de los botones y devuelve el texto del botón (tenga en cuenta que es mejor verificar el valor devuelto de forma insensible a mayúsculas y minúsculas). NOTA: a diferencia de Tk::Dialog que crea su widget una vez y puede usarse muchas veces, la ventana messageBox se crea cada vez que se usa.

Los siguientes pares de opciones/valores son compatibles:

-default
El nombre simbólico, sensible a mayúsculas y minúsculas, del botón predeterminado para esta ventana de mensaje ('Ok', 'Cancel', etc.). Consulte -type para obtener una lista de los nombres simbólicos. Si la caja de mensajes tiene solo un botón, se convertirá automáticamente en el predeterminado; de lo contrario, si esta opción no se especifica, no habrá ningún botón predeterminado.
-icon
Especifica un ícono para mostrar. En X11 se pueden especificar cualquiera de los mapas de bits incorporados de Tk. En Windows solo se admiten error, info, question o warning.
-message
Especifica el mensaje a mostrar.
-title
Especifica una cadena para mostrar como título.
-type
Especifica un conjunto predefinido de botones para mostrar. Los siguientes valores son posibles: 'AbortRetryIgnore', 'Ok', 'OkCancel', 'RetryCancel', 'YesNo' o 'YesNoCancel'.

EJEMPLO

$respuesta = $mw->messageBox(-icon => 'question', -message => '¡Hola Mundo!', -title => 'Mi título', -type => 'AbortRetryIgnore', -default => 'Retry');
