Tk_GetScrollInfoObj(3)

Paquete: tk

Tk_GetScrollInfo(3) Procedimientos de la biblioteca Tk Tk_GetScrollInfo(3)

NOMBRE

Tk_GetScrollInfoObj, Tk_GetScrollInfo - analizar argumentos para comandos de desplazamiento

SINOPSIS

#include <tk.h>

int
Tk_GetScrollInfoObj(interp, objc, objv, fractionPtr, stepsPtr)

int
Tk_GetScrollInfo(interp, argc, argv, fractionPtr, stepsPtr)

ARGUMENTOS

Tcl_Interp *interp (entrada)
Intérprete a usar para informar errores.
int objc (entrada)
Número de Tcl_Obj's en la matriz objv.
Tcl_Obj *const * objv (entrada)
Objetos de argumento. Estos representan el comando completo del widget, de los cuales la primera palabra es típicamente el nombre del widget y la segunda palabra es típicamente xview o yview.
int argc (entrada)
Número de cadenas en la matriz argv.
const char ** argv (entrada)
Cadenas de argumento. Estas representan el comando completo del widget, de los cuales la primera palabra es típicamente el nombre del widget y la segunda palabra es típicamente xview o yview.
double *fractionPtr (salida)
Rellenado con la fracción de la opción moveto, si la hay.
int *stepsPtr (salida)
Rellenado con el número de línea o página del valor scroll, si lo hay. El valor puede ser negativo.

DESCRIPCIÓN

Tk_GetScrollInfoObj analiza los argumentos esperados por los comandos de desplazamiento de widgets como xview y yview. Recibe la lista completa de palabras que componen un comando de widget y analiza las palabras a partir de objv[2]. Las palabras a partir de objv[2] deben tener una de las siguientes formas:

moveto fracción
scroll número unidades
scroll número páginas

Cualquiera de las palabras clave moveto, scroll, unidades y páginas puede abreviarse. Si objv tiene la forma moveto, se devuelve TK_SCROLL_MOVETO como resultado y *fractionPtr se rellena con el argumento fracción del comando, que debe ser un valor real adecuado. Si objv tiene la forma scroll, se devuelve TK_SCROLL_UNITS o TK_SCROLL_PAGES y *stepsPtr se rellena con el valor número, que debe ser un entero adecuado. Si se produce un error al analizar los argumentos, se devuelve TK_SCROLL_ERROR y se deja un mensaje de error en el resultado del intérprete interp.

Tk_GetScrollInfo es idéntico en función a Tk_GetScrollInfoObj. Sin embargo, Tk_GetScrollInfo acepta argumentos de cadena, lo que la hace más adecuada para su uso con widgets antiguos.
