THUNAR(1) Comandos de usuario THUNAR(1)

NOMBRE

Thunar - Gestor de archivos para el Entorno de Escritorio Xfce

SINOPSIS

Thunar [opciones] [[URI]...]

Thunar [opciones] --renombrado-masivo [[URI]...]

Thunar [opciones] --salir

DESCRIPCIÓN

Thunar es un gestor de archivos rápido y fácil de usar para el Entorno de Escritorio Xfce. Ha sido diseñado desde cero para ser ligero, con un enfoque especial en la usabilidad. Su interfaz de usuario es limpia e intuitiva, y no incluye opciones confusas o inútiles.

INVOCACIÓN

Thunar toma una lista de URIs para carpetas que deben abrirse en nuevas ventanas del gestor de archivos o archivos que deben seleccionarse en nuevas ventanas del gestor de archivos. Los URIs pueden especificarse como URIs file: o trash:, rutas absolutas o rutas relativas al directorio actual desde el cual se está invocando Thunar. Si no se especifican URIs, se abrirá la carpeta actual en una nueva ventana del gestor de archivos.

Cuando se especifica la opción --renombrado-masivo, no se abrirán ventanas del gestor de archivos, sino que los URIs se pasarán al renombrador masivo. El renombrador masivo permite renombrar varios archivos o carpetas a la vez utilizando diferentes módulos de renombrado.

Opciones

-?, --ayuda

Muestra ayuda breve y sale.

-V, --versión

Muestra información de la versión y sale.

-B, --renombrado-masivo

Abre los URIs en una ventana independiente del renombrador masivo.

--demonio

No termina la instancia de Thunar cuando se cierra la última ventana, sino que la mantiene en ejecución para acelerar la apertura de nuevas ventanas más adelante. Esta es la opción por defecto al iniciar Thunar como parte de la sesión Xfce por defecto o al usar activación D-Bus.

--pantalla=PANTALLA

Usa la PANTALLA de X especificada para la interfaz de usuario.

-q, --salir

Termina cualquier instancia de Thunar que se esté ejecutando en segundo plano (iniciada con la opción --demonio). Este comando debe usarse siempre que se actualice Thunar a una nueva versión para asegurar que no se reutilice una instancia antigua.
