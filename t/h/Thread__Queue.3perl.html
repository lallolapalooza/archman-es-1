Thread::Queue(3perl) Guía de Referencia para Programadores de Perl Thread::Queue(3perl)

NOMBRE

Thread::Queue - Colas seguras para hilos

VERSIÓN

Este documento describe Thread::Queue versión 3.14

SINOPSIS

use strict;
use warnings;
use threads;
use Thread::Queue;
my $q = Thread::Queue->new();    # Una cola vacía nueva
# Hilo trabajador
my $thr = threads->create(
    sub {
        # El hilo se ejecutará en bucle hasta que no haya más trabajo
        while (defined(my $item = $q->dequeue())) {
            # Hacer trabajo con $item
            ...
        }
    }
);
# Enviar trabajo al hilo
$q->enqueue($item1, ...);
# Señalar que no hay más trabajo que enviar
$q->end();
# Unirse al hilo cuando termine
$thr->join();
...
# Contador de elementos en la cola
my $left = $q->pending();
# Dequeue no bloqueante
if (defined(my $item = $q->dequeue_nb())) {
    # Trabajar con $item
}
# Dequeue bloqueante con tiempo de espera de 5 segundos
if (defined(my $item = $q->dequeue_timed(5))) {
    # Trabajar con $item
}
# Establecer un tamaño para una cola
$q->limit = 5;
# Obtener el segundo elemento de la cola sin sacarlo
my $item = $q->peek(1);
# Insertar dos elementos en la cola justo detrás de la cabecera
$q->insert(1, $item1, $item2);
# Extraer los dos últimos elementos de la cola
my ($item1, $item2) = $q->extract(-2, 2);

DESCRIPCIÓN

Este módulo proporciona colas FIFO seguras para hilos que pueden ser accedidas de forma segura por cualquier número de hilos.

Cualquier tipo de dato soportado por threads::shared puede ser pasado a través de colas:

Escalares ordinarios
Referencias a arrays
Referencias a hashes
Referencias a escalares
Objetos basados en lo anterior

Los escalares ordinarios se añaden a las colas tal como están.

Si los demás tipos de datos complejos no están ya compartidos por hilos, serán clonados (recursivamente, si es necesario, e incluyendo cualquier "bless" y configuraciones de solo lectura) en estructuras compartidas por hilos antes de ser colocados en una cola.

Por ejemplo, lo siguiente haría que Thread::Queue creara una referencia de array vacía y compartida a través de &shared([]), copiara los elementos 'foo', 'bar' y 'baz' de @ary en ella, y luego colocara esa referencia compartida en la cola:

my @ary = qw/foo bar baz/;
$q->enqueue(\@ary);

Sin embargo, para lo siguiente, los elementos ya están compartidos, por lo que sus referencias se añaden directamente a la cola, y no se realiza ninguna clonación:

my @ary :shared = qw/foo bar baz/;
$q->enqueue(\@ary);
my $obj = &shared({});
$$obj{'foo'} = 'bar';
$$obj{'qux'} = 99;
bless($obj, 'My::Class');
$q->enqueue($obj);

Ver "LIMITACIONES" para advertencias relacionadas con el paso de objetos a través de colas.

CREACIÓN DE COLAS

->new()
Crea una cola vacía nueva.
->new(LIST)
Crea una cola nueva precargada con la lista de elementos proporcionada.

MÉTODOS BÁSICOS

Los siguientes métodos manejan las colas de forma FIFO (primero en entrar, primero en salir).

->enqueue(LIST)
Añade una lista de elementos al final de la cola.
->dequeue()
->dequeue(COUNT)
Elimina el número solicitado de elementos (por defecto es 1) de la cabecera de la cola y los devuelve. Si la cola contiene menos elementos que los solicitados, el hilo se bloqueará hasta que estén disponibles los elementos necesarios (es decir, hasta que otros hilos "enqueue" más elementos).
->dequeue_nb()
->dequeue_nb(COUNT)
Elimina el número solicitado de elementos (por defecto es 1) de la cabecera de la cola y los devuelve. Si la cola contiene menos elementos que los solicitados, devuelve inmediatamente (es decir, sin bloquear) los elementos que haya en la cola. Si la cola está vacía, se devuelve "undef".
->dequeue_timed(TIMEOUT)
->dequeue_timed(TIMEOUT, COUNT)
Elimina el número solicitado de elementos (por defecto es 1) de la cabecera de la cola y los devuelve. Si la cola contiene menos elementos que los solicitados, el hilo se bloqueará hasta que estén disponibles los elementos necesarios, o hasta que se alcance el tiempo de espera. Si se alcanza el tiempo de espera, devuelve los elementos que haya en la cola, o "undef" si la cola está vacía.

El tiempo de espera puede ser un número de segundos relativo a la hora actual (por ejemplo, 5 segundos desde que se realiza la llamada), o puede ser un tiempo de espera absoluto en segundos de *época*, igual que se usaría con cond_timedwait(). También se admiten fracciones de segundo (por ejemplo, 2.5 segundos) (hasta el límite de la implementación subyacente).

Si "TIMEOUT" falta, es "undef" o es menor o igual a 0, esta llamada se comporta igual que "dequeue_nb".

->pending()
Devuelve el número de elementos que quedan en la cola. Devuelve "undef" si la cola ha finalizado (ver abajo) y no quedan más elementos en la cola.
->limit
Establece el tamaño de la cola. Si se establece, las llamadas a enqueue() se bloquearán hasta que el número de elementos pendientes en la cola caiga por debajo del "limit". El "limit" no impide encolar elementos más allá de ese recuento: 
my $q = Thread::Queue->new(1, 2);
$q->limit = 4;
$q->enqueue(3, 4, 5);   # No se bloquea
$q->enqueue(6);         # Se bloquea hasta que se
                        # dequeue al menos 2 elementos
my $size = $q->limit;   # Devuelve el límite actual (puede devolver
                        # 'undef')
$q->limit = 0;          # El tamaño de la cola es ahora ilimitado

Llamar a cualquiera de los métodos de dequeue con "COUNT" mayor que el "limit" de una cola generará un error.

->end()
Declara que no se añadirán más elementos a la cola.

Todos los hilos bloqueados en llamadas a dequeue() se desbloquearán con los elementos restantes en la cola y/o se devolverá "undef". Cualquier llamada posterior a dequeue() se comportará como dequeue_nb().

Una vez finalizada, no se pueden añadir más elementos a la cola.

MÉTODOS AVANZADOS

Los siguientes métodos pueden utilizarse para manipular elementos en cualquier lugar de una cola.

Para evitar que el contenido de una cola sea modificado por otro hilo mientras se examina y/o se cambia, bloquee la cola dentro de un bloque local:

{
    lock($q);   # Evita que otros hilos cambien el contenido de la cola
    my $item = $q->peek();
    if ($item ...) {
        ...
    }
}
# La cola ahora está desbloqueada
->peek()
->peek(INDEX)
Devuelve un elemento de la cola sin sacarlo. Por defecto, la cabecera de la cola (en la posición de índice 0) si no se especifica ningún índice. Se admiten índices negativos como en los arrays (es decir, -1 es el final de la cola, -2 es el penúltimo, y así sucesivamente).

Si no existen elementos en el índice especificado (es decir, la cola está vacía o el índice está más allá del número de elementos en la cola), se devuelve "undef".

Recuerde que el elemento devuelto no se elimina de la cola, por lo que manipular una referencia a la que se ha hecho "peek" afecta al elemento en la cola.

->insert(INDEX, LIST)
Añade la lista de elementos a la cola en la posición de índice especificada (0 es la cabecera de la lista). Cualquier elemento existente en esa posición y más allá se empuja hacia atrás, más allá de los elementos recién añadidos: 
$q->enqueue(1, 2, 3, 4);
$q->insert(1, qw/foo bar/);
# La cola ahora contiene:  1, foo, bar, 2, 3, 4

Thread::Queue(3perl) — Thread-Safe FIFO Queue

VERSION

This documentation refers to Thread-Queue version 3.15.

SYNOPSIS

  use threads;
  use Thread::Queue;

  # Create a new queue
  my $q = Thread::Queue->new;

  # Create a queue with initial items
  my $q = Thread::Queue->new(1, 2, 3);

  # Add items to the queue
  $q->enqueue(4, 5);

  # Get items from the queue
  my $item = $q->dequeue; # Blocks until an item is available
  my @items = $q->dequeue_nb(2); # Non-blocking, returns up to 2 items

  # Check queue size
  my $size = $q->pending;

  # Insert items at a specific position
  $q->insert(1, 'a', 'b');

  # Extract items from a specific position
  my @extracted = $q->extract(2, 3);

DESCRIPTION

Thread::Queue provides a thread-safe, first-in, first-out (FIFO) queue data structure. It is designed to be used in multi-threaded Perl programs created with the threads module.

All methods that modify the queue are blocking by default, ensuring that operations are synchronized between threads. Non-blocking versions of some methods are also available.

QUEUE CREATION

new()

Creates and returns a new, empty queue object.

my $q = Thread::Queue->new;
new(LIST)

Creates and returns a new queue object initialized with the items in LIST.

my $q = Thread::Queue->new(1, 2, 3);

BASIC METHODS

->enqueue(LIST)
Adds the items in LIST to the end of the queue. This method will block if the queue has a maximum size and is currently full (which is not the default behavior).
->dequeue()
Removes and returns the item at the head of the queue. If the queue is empty, this method blocks until an item becomes available.
->dequeue_nb()
Removes and returns the item at the head of the queue. If the queue is empty, this method returns immediately with an undefined value.
->dequeue_nb(COUNT)
Removes and returns up to COUNT items from the head of the queue. If the queue contains fewer than COUNT items, it returns all available items. If the queue is empty, it returns an empty list. This method is non-blocking.
->pending()
Returns the number of items currently in the queue. This is a snapshot and may be outdated by the time it is returned if other threads are actively using the queue.
->empty()
Returns true if the queue is empty, false otherwise. Similar to pending, this is a snapshot.
->clear()
Removes all items from the queue.

ADVANCED METHODS

->insert(INDEX, LIST)
Inserts the items in LIST into the queue at the specified INDEX. An index of 0 inserts at the head, and an index equal to the current size inserts at the tail.
Negative index positions are supported.

If a negative index position is specified that is less than or equal to the negative of the queue size, the items are inserted at the head of the queue.

If the index position is greater than the number of items in the queue, the list is added to the end.

$q->enqueue(1, 2, 3, 4);
$q->insert(-2, qw/foo bar/);
# Queue now contains:  1, 2, foo, bar, 3, 4

Specifying a negative index position greater than the number of items in the queue adds the list to the head of the queue.

->extract()
->extract(INDEX)
->extract(INDEX, COUNT)
Removes and returns the specified number of items (defaults to 1) from the specified index position in the queue (0 is the head of the queue). When called with no arguments, "extract" operates the same as "dequeue_nb".

This method is non-blocking, and will return only as many items as are available to fulfill the request:

$q->enqueue(1, 2, 3, 4);
my $item  = $q->extract(2)     # Returns 3
                               # Queue now contains:  1, 2, 4
my @items = $q->extract(1, 3)  # Returns (2, 4)
                               # Queue now contains:  1

Specifying an index position greater than the number of items in the queue results in "undef" or an empty list being returned.

$q->enqueue('foo');
my $nada = $q->extract(3)      # Returns undef
my @nada = $q->extract(1, 3)   # Returns ()

Negative index positions are supported. Specifying a negative index position greater than the number of items in the queue may return items from the head of the queue (similar to "dequeue_nb") if the count overlaps the head of the queue from the specified position (i.e. if queue size + index + count is greater than zero):

$q->enqueue(qw/foo bar baz/);
my @nada = $q->extract(-6, 2);  # Returns ()      - (3+(-6)+2) <= 0
my @some = $q->extract(-6, 4);  # Returns (foo)   - (3+(-6)+4) > 0
                                # Queue now contains:  bar, baz
my @rest = $q->extract(-3, 4);  # Returns (bar, baz) -
                                #                   (2+(-3)+4) > 0

NOTES

Queues created by Thread::Queue can be used in both threaded and non-threaded applications.

LIMITATIONS

Passing objects on queues may not work if the objects' classes do not support sharing. See "BUGS AND LIMITATIONS" in threads::shared for more.

Passing array/hash refs that contain objects may not work for Perl prior to 5.10.0.
