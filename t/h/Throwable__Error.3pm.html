NOMBRE

Throwable::Error - una clase fácil de usar para objetos de error

VERSIÓN

versión 1.001

SINOPSIS

package MyApp::Error;
# NOTA: Moo también se puede usar aquí en lugar de Moose
use Moose;
extends 'Throwable::Error';
has execution_phase => (
  is  => 'ro',
  isa => 'MyApp::Phase',
  default => 'startup',
);

...y en tu aplicación...

MyApp::Error->throw("todas las comunicaciones desconectadas");
# o...
MyApp::Error->throw({
  message         => "todas las comunicaciones desconectadas",
  execution_phase => 'shutdown',
});

DESCRIPCIÓN

Throwable::Error es una clase base para excepciones que se lanzarán para señalar errores y abortar el flujo normal del programa. Throwable::Error es una alternativa a Exception::Class, cuyas características son en gran medida proporcionadas por el sistema de objetos Moo sobre el cual se basa Throwable::Error.

Throwable::Error implementa los roles Throwable y StackTrace::Auto. Esto significa que puedes llamar a "throw" en él para crear y lanzar un objeto de error en una sola llamada, y que cada objeto de error tendrá un rastreo de pila para su creación.

ATRIBUTOS

mensaje

Este atributo debe definirse y debe contener una cadena de caracteres que describa la condición de error. Esta cadena se imprimirá en la parte superior del rastreo de pila cuando el error se convierta a cadena.

rastreo_de_pila

Este atributo, proporcionado por StackTrace::Auto, contendrá un objeto de rastreo de pila que garantiza responder al método "as_string". Para obtener más información sobre el rastreo de pila y el comportamiento asociado, consulte la documentación de StackTrace::Auto.

MÉTODOS

como_cadena

Este método proporcionará una cadena que representa el error, que contiene el mensaje del error seguido de su rastreo de pila.
