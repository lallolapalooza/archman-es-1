Tss2_Tcti_Cmd_Init(3) Manual de funciones de biblioteca Tss2_Tcti_Cmd_Init(3)

NOMBRE

Tss2_Tcti_Cmd_Init - Función de inicialización de la biblioteca Cmd TCTI.

SINOPSIS

#include <tss2/tss2_tcti_cmd.h>

TSS2_RC Tss2_Tcti_Cmd_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *contextSize, const char *conf);

La función Tss2_Tcti_Cmd_Init() inicializa un contexto TCTI utilizado para comunicarse con un subproceso especificado en la cadena de configuración. El TCTI envía y recibe utilizando respectivamente la E/S estándar de entrada y salida del subproceso.

DESCRIPCIÓN

Tss2_Tcti_Cmd_Init() intenta inicializar un tcti_context asignado por el llamante de tamaño size utilizando la cadena de configuración conf proporcionada por el llamante. Dado que el tcti_context debe ser un búfer asignado por el llamante, el llamante necesita conocer el tamaño del búfer requerido por la biblioteca TCTI. El tamaño mínimo de este contexto se puede descubrir proporcionando NULL para el parámetro tcti_context y un parámetro size distinto de NULL. La función de inicialización poblará el parámetro size con el tamaño mínimo del búfer tcti_context. Luego, el llamante debe asignar un búfer de este tamaño (o mayor) y llamar nuevamente a Tss2_Tcti_Cmd_Init() proporcionando el tcti_context recién asignado y el tamaño de este contexto en el parámetro size. Este patrón es común a todas las funciones de inicialización TCTI. Proporcionamos un ejemplo de este patrón utilizando la función Tss2_Tcti_Cmd_Init() en la sección titulada EJEMPLO.

El parámetro conf es una cadena C utilizada para configurar el contexto TCTI. Esta cadena de configuración es el comando utilizado para popen(3). La cadena conf no puede ser NULL para este TCTI.

Una vez inicializado, el contexto TCTI devuelto expone la API definida por Trusted Computing Group (TCG) para la comunicación de nivel más bajo con el TPM. Utilizando esta API, el llamante puede intercambiar (enviar / recibir) búferes de comando y respuesta TPM2 con un servicio que puede intercambiar búferes de comando y respuesta TPM2. Sin embargo, en casi todos los casos, el llamante inicializará un contexto utilizando esta función antes de pasar el contexto a una API de nivel superior como la API del Sistema (SAPI), la API del Sistema Mejorada (ESAPI) o la API de Funciones (FAPI) y luego nunca volverá a tocarla.

Para una discusión más detallada de la API TCTI, consulte la "Especificación de la Interfaz de Transmisión de Comandos del TPM y la API del Nivel del Sistema TSS" publicada por el TCG: https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

VALOR DE RETORNO

Una llamada exitosa a Tss2_Tcti_Cmd_Init() devolverá TSS2_RC_SUCCESS. Una llamada infructuosa producirá un código de respuesta descrito en la sección ERRORES.

ERRORES

TSS2_TCTI_RC_BAD_VALUE se devuelve si tanto los parámetros tcti_context como size son NULL, o si el parámetro config es NULL.

EJEMPLO

Fragmento de inicialización TCTI:

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_mssim.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
const char *conf = "XXX TODO MUESTRA"
rc = Tss2_Tcti_Cmd_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Fallo al obtener el tamaño de asignación para el contexto TCTI mssim "
             ": 0x%" PRIx32 ", rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "Asignación para el contexto TCTI fallida: %s",
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Cmd_Init (&tcti_context, &size, conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Fallo al inicializar el contexto TCTI mssim: "
             "0x%" PRIx32 ", rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
