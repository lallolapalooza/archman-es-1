Tss2_Tcti_Device_Init(3) Manual de funciones de biblioteca Tss2_Tcti_Device_Init(3)

NOMBRE

Tss2_Tcti_Device_init - Función de inicialización de la biblioteca TCTI de dispositivo.

SINOPSIS

#include <tcti/tcti_device.h>

TSS2_RC Tss2_Tcti_Device_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *size, const char *conf);

La función Tss2_Tcti_Device_Init() inicializa un contexto TCTI utilizado para comunicarse con el controlador de dispositivo TPM.

DESCRIPCIÓN

Tss2_Tcti_Device_Init() intenta inicializar un tctiContext asignado por el llamador de tamaño size. Dado que el tctiContext debe ser un buffer asignado por el llamador, el llamador necesita conocer el tamaño requerido por la biblioteca TCTI. El tamaño mínimo de este contexto se puede descubrir proporcionando NULL para el tctiContext y un parámetro size distinto de NULL. La función de inicialización poblará el parámetro size con el tamaño mínimo del buffer tctiContext. El llamador debe entonces asignar un buffer de este tamaño (o mayor) y llamar a Tss2_Tcti_Device_Init () nuevamente, proporcionando el tctiContext recién asignado y el tamaño de este contexto en el parámetro size. Este patrón es común a todas las funciones de inicialización de TCTI. Proporcionamos un ejemplo de este patrón utilizando la función Tss2_Tcti_Device_Init() en la sección titulada EJEMPLO.

El parámetro conf es una cadena C. Si esta cadena es NULL, la biblioteca utilizará una cadena de configuración predeterminada para el llamador. Alternativamente, el llamador puede proporcionar una cadena de configuración que debe contener la ruta al nodo del dispositivo expuesto por el controlador del dispositivo TPM.

Una vez inicializado, el contexto TCTI devuelto expone la API definida por Trusted Computing Group (TCG) para la comunicación de nivel más bajo con el dispositivo TPM. Usando esta API, el llamador puede intercambiar (enviar / recibir) buffers de comando y respuesta TPM2 con el controlador del dispositivo TPM. En casi todos los casos, sin embargo, el llamador inicializará un contexto usando esta función antes de pasar el contexto a una API de nivel superior como la API del Sistema (SAPI), y luego no volverá a tocarlo.

Especificación de la API de Interfaz de Transmisión de Comandos TPM2 (TCTI) de TCG TSS 2.0

Para una discusión más completa de la API TCTI, consulte la "Especificación de la API de Interfaz de Transmisión de Comandos TPM2 (TCTI) de TCG TSS 2.0" publicada por TCG:

https://trustedcomputinggroup.org/wp-content/uploads/TSS_TCTI_Version-1.0_Revision-05_Review_END030918.pdf

VALOR DE RETORNO

Una llamada exitosa a Tss2_Tcti_Device_Init() devolverá TSS2_RC_SUCCESS. Una llamada infructuosa producirá un código de respuesta descrito en la sección ERRORES.

ERRORES

TSS2_TCTI_RC_BAD_VALUE se devuelve si algún parámetro contiene valores inesperados. TSS2_TCTI_RC_BAD_REFERENCE se devuelve si algún parámetro es NULL cuando no debería serlo. TSS2_TCTI_RC_BAD_CONTEXT se devuelve si el tamaño del tctiContext proporcionado es insuficiente.

EJEMPLO

Fragmento de inicialización de TCTI:

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_device.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
char *conf = "/dev/tpm0",
rc = Tss2_Tcti_Device_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "No se pudo obtener el tamaño de asignación para el contexto TCTI de dispositivo "
             ": 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "Error al asignar el contexto TCTI: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Device_Init (&tcti_context, &size, &conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Error al inicializar el contexto TCTI del dispositivo: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
