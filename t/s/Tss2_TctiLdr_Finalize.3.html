Tss2_TctiLdr_Finalize(3) Manual de funciones de la biblioteca Tss2_TctiLdr_Finalize(3)

NOMBRE

Tss2_TctiLdr_Finalize - Función para finalizar un contexto TCTI instanciado por la función Tss2_TctiLdr_Initialize.

SINOPSIS

#include <tss2/tss2_tctildr.h>

TSS2_RC Tss2_TctiLdr_Finalize (TSS2_TCTI_CONTEXT **CONTEXTO);

DESCRIPCIÓN

La función Tss2_TctiLdr_Finalize() destruye una instancia de un contexto TCTI instanciado por la función Tss2_TctLdr_Initialize(). También libera cualquier recurso asociado con la carga de la biblioteca TCTI requerida.

El parámetro contexto es un puntero doble a un contexto TCTI. Cuando se finaliza con éxito, la referencia proporcionada se establecerá en NULL por la función.

VALOR DEVUELTO

Esta función no devuelve ningún valor.

EJEMPLO

Código de ejemplo.

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tss2/tss2_tctildr.h>
TSS2_TCTI_CONTEXT *ctx = NULL;
TSS2_RC rc = Tss2_TctiLdr_Initialize (NULL, NULL, &ctx);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "La inicialización del contexto TCTI predeterminado falló con "
             "el código de respuesta: 0x%" PRIx32 ", rc);
    exit (EXIT_FAILURE);
}
if (ctx != NULL)
    Tss2_TctiLdr_Finalize (&ctx);
exit (EXIT_SUCCESS);
