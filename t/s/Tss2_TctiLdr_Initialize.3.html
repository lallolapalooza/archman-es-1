Tss2_TctiLdr_Initialize(3) Manual de Funciones de Biblioteca Tss2_TctiLdr_Initialize(3)

NOMBRE

Tss2_TctiLdr_Initialize, Tss2_TctiLdr_Initialize_Ex - Instanciar e inicializar un contexto TCTI.

SINOPSIS

#include <tss2/tss2_tctildr.h>

TSS2_RC Tss2_TctiLdr_Initialize (const char *nameConf, TSS2_TCTI_CONTEXT **context);

TSS2_RC Tss2_TctiLdr_Initialize_Ex (const char *name, const char *conf, TSS2_TCTI_CONTEXT **context);

DESCRIPCIÓN

Las funciones Tss2_TctiLdr_Initialize() y Tss2_TctiLdr_Initialize_Ex() inicializan un contexto TCTI utilizado para comunicarse con el TPM2 o algún componente intermedio en la pila de software TPM2 de TCG.

Tss2_TctiLdr_Initialize() toma una única cadena que codifica tanto el nombre de la biblioteca TCTI que el llamador desea instanciar como su configuración deseada en el parámetro nameConf. nameConf es una cadena compuesta por dos subcadenas: los parámetros name y conf respectivamente. Estas subcadenas se combinan con name primero, separadas por un único carácter ':' / dos puntos: 'nombre:conf'. Consulte la sección titulada CONFIGURACIÓN TCTI para obtener información sobre la codificación de estas cadenas. El parámetro context se utiliza para devolver una referencia al contexto TCTI creado por la función.

Tss2_TctiLdr_Initialize_Ex() se comporta de manera idéntica a la función Tss2_TctiLdr_Initialize() con la excepción de que el nombre y la configuración TCTI se pasan como cadenas separadas. La codificación de estas cadenas se describe en la sección CONFIGURACIÓN TCTI.

CONFIGURACIÓN TCTI

Si la cadena name es NULL o una cadena vacía, las funciones de inicialización seleccionarán un TCTI predeterminado apropiado para la plataforma. En Linux, esto significa intentar primero cargar una biblioteca llamada libtss2-tcti-default.so. Esto es un marcador de posición para que las distribuciones proporcionen un valor predeterminado específico de la distribución. Se recomienda que esto sea un enlace simbólico a otra biblioteca TCTI instalada. Si los intentos de cargar este objeto compartido fallan, la implementación intentará TCTIs conocidos en el siguiente orden:

•
libtss2-tcti-tabrmd.so.0
•
libtss2-tcti-device.so.0
•
libtss2-tcti-mssim.so.0

Cuando la cadena name no es NULL ni una cadena vacía, la implementación intentará dlopen una biblioteca con el nombre dado. Si esto falla, la implementación asume que se le ha pasado un nombre abreviado e intentará cargar bibliotecas por nombre con las siguientes permutaciones:

•
<nombre>
•
libtss2-tcti-<nombre>.so.0
•
libtss2-tcti-<nombre>.so

La cadena config no es interpretada por las funciones de inicialización TctiLdr y se pasa sin modificar a la función de inicialización para el TCTI seleccionado. El formato de esta cadena es específico del TCTI.

La función Tss2_TctiLdr_Initialize recibe las cadenas name y conf como un único parámetro. En este caso, las cadenas name y conf se concatenan con un único carácter ':' / dos puntos separándolas.

Para una discusión más completa de la API TCTILDR, consulte la "Especificación de la API de la Interfaz de Transmisión de Comandos del TPM2 (TCTI) de TCG 2.0".

VALOR DE RETORNO

Una llamada exitosa a esta función devolverá TSS2_RC_SUCCESS. Una llamada fallida producirá un código de respuesta descrito en la sección ERRORES.

ERRORES

TSS2_TCTI_RC_MEMORY se devuelve si falla la asignación de memoria.

TSS2_TCTI_RC_NOT_SUPPORTED se devuelve cuando el cargador no puede localizar una biblioteca TCTI con el name proporcionado.

TSS2_TCTI_RC_IO_ERROR se devuelve si ocurre un error en el mecanismo subyacente de carga de bibliotecas.

TSS2_TCTI_RC_BAD_REFERENCE se devuelve si el parámetro tctiContext es NULL.

EJEMPLO

Código de ejemplo.

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tss2/tss2_tctildr.h>
TSS2_TCTI_CONTEXT *ctx = NULL;
TSS2_RC rc = Tss2_TctiLdr_Initialize (NULL, &ctx);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "La inicialización del contexto TCTI predeterminado falló con "
             "código de respuesta: 0x%" PRIx32 ", rc);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
