Tss2_TctiLdr_GetInfo(3) Manual de Funciones de Biblioteca Tss2_TctiLdr_GetInfo(3)

NOMBRE

Tss2_TctiLdr_GetInfo - Consultar la biblioteca TctiLdr para obtener la estructura TSS2_TCTI_INFO asociada a una biblioteca TCTI.

SINOPSIS

#include <tss2/tss2_tctildr.h>

TSS2_RC Tss2_TctiLdr_GetInfo (constchar *nombre, TSS2_TCTI_INFO **info);

DESCRIPCIÓN

La función Tss2_TctiLdr_GetInfo() intenta instanciar una estructura TSS2_TCTI_INFO apropiada para la biblioteca TCTI asociada con el nombre proporcionado. La referencia TSS2_TCTI_INFO* devuelta por esta función debe ser liberada por la función Tss2_TctiLdr_FreeInfo ().

El parámetro nombre es una cadena C. Si esta cadena es NULL, la biblioteca seleccionará un TCTI predeterminado para el llamador. Esta es la misma biblioteca TCTI que se usará para inicializar el contexto devuelto por Tss2_TctiLdr_Initialize cuando se le pase un nombre NULL. Si no es NULL, Tss2_TctiLdr_GetInfo () utiliza el mismo algoritmo para mapear la cadena al nombre de una biblioteca TCTI instalada que la función Tss2_TctiLdr_Initialize ().

El parámetro info es una referencia a un TSS2_TCTI_INFO*. La referencia devuelta será asignada por la función y debe ser liberada por el llamador.

VALOR DE RETORNO

Una llamada exitosa a esta función devolverá TSS2_RC_SUCCESS. Una llamada fallida a esta función devolverá un código de respuesta descrito a continuación en la sección ERRORES.

ERRORES

TSS2_TCTI_RC_MEMORY se devuelve si falla la asignación de memoria

TSS2_TCTI_RC_NOT_SUPPORTED se devuelve cuando el cargador no puede localizar una biblioteca TCTI con el nombre proporcionado

TSS2_TCTI_RC_IO_ERROR se devuelve si ocurre un error en el mecanismo subyacente de carga de bibliotecas

TSS2_TCTI_RC_BAD_REFERENCE se devuelve si el parámetro info es NULL

EJEMPLO

Código de ejemplo.

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tss2/tss2_tctildr.h>
TSS2_TCTI_INFO *info = NULL;
TSS2_RC rc = Tss2_TctiLdr_GetInfo (NULL, &info);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "La inicialización del contexto TCTI predeterminado falló con "
             "código de respuesta: 0x%" PRIx32 ", rc);
    exit (EXIT_FAILURE);
}
if (info != NULL) {
    Tss2_TctiLdr_FreeInfo (info);
    info = NULL;
}
exit (EXIT_SUCCESS);
