TS_VERIFY_CTX(3ssl)

Paquete: openssl

Licencias: Apache-2.0

TS_VERIFY_CTX(3ssl) OpenSSL TS_VERIFY_CTX(3ssl)

NOMBRE

TS_VERIFY_CTX, TS_VERIFY_CTX_new, TS_VERIFY_CTX_init, TS_VERIFY_CTX_free, TS_VERIFY_CTX_cleanup, TS_VERIFY_CTX_set_flags, TS_VERIFY_CTX_add_flags, TS_VERIFY_CTX_set0_data, TS_VERIFY_CTX_set0_imprint, TS_VERIFY_CTX_set0_store, TS_VERIFY_CTX_set0_certs, TS_VERIFY_CTX_set_certs, TS_VERIFY_CTS_set_certs, TS_VERIFY_CTX_set_data, TS_VERIFY_CTX_set_imprint, TS_VERIFY_CTX_set_store - gestionar el contexto de verificación de respuesta TS

SINOPSIS

#include <openssl/ts.h>
typedef struct TS_verify_ctx TS_VERIFY_CTX;
TS_VERIFY_CTX *TS_VERIFY_CTX_new(void);
void TS_VERIFY_CTX_init(TS_VERIFY_CTX *ctx);
void TS_VERIFY_CTX_free(TS_VERIFY_CTX *ctx);
void TS_VERIFY_CTX_cleanup(TS_VERIFY_CTX *ctx);
int TS_VERIFY_CTX_set_flags(TS_VERIFY_CTX *ctx, int f);
int TS_VERIFY_CTX_add_flags(TS_VERIFY_CTX *ctx, int f);
int TS_VERIFY_CTX_set0_data(TS_VERIFY_CTX *ctx, BIO *b);
int TS_VERIFY_CTX_set0_imprint(TS_VERIFY_CTX *ctx,
                               unsigned char *hexstr, long len);
int TS_VERIFY_CTX_set0_store(TS_VERIFY_CTX *ctx, X509_STORE *s);
int TS_VERIFY_CTX_set0_certs(TS_VERIFY_CTX *ctx, STACK_OF(X509) *certs);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.4:

BIO *TS_VERIFY_CTX_set_data(TS_VERIFY_CTX *ctx, BIO *b);
unsigned char *TS_VERIFY_CTX_set_imprint(TS_VERIFY_CTX *ctx,
                                         unsigned char *hexstr, long len);
X509_STORE *TS_VERIFY_CTX_set_store(TS_VERIFY_CTX *ctx, X509_STORE *s);
STACK_OF(X509) *TS_VERIFY_CTX_set_certs(TS_VERIFY_CTX *ctx,
                                        STACK_OF(X509) *certs);

La siguiente función ha sido marcada como obsoleta desde OpenSSL 3.0:

STACK_OF(X509) *TS_VERIFY_CTS_set_certs(TS_VERIFY_CTX *ctx,
                                        STACK_OF(X509) *certs);

DESCRIPCIÓN

El Protocolo de Sello de Tiempo (TSP) se define en RFC 3161. TSP es un protocolo utilizado para proporcionar pruebas a largo plazo de la existencia de ciertos datos antes de un tiempo particular. TSP define una Autoridad de Sello de Tiempo (TSA) y una entidad que realiza solicitudes a la TSA. Normalmente, la TSA se denomina el lado del servidor y la entidad que realiza la solicitud se denomina el cliente.

En TSP, cuando un servidor envía una respuesta a un cliente, el servidor normalmente necesita firmar los datos de respuesta - el TimeStampToken (TST) - con su clave privada. Luego, el cliente verifica la cadena de certificados del servidor utilizando el TST recibido.

Para todos los siguientes métodos, a menos que se indique lo contrario, ctx es el contexto de verificación creado de antemano.

TS_VERIFY_CTX_new() devuelve una estructura TS_VERIFY_CTX asignada.

TS_VERIFY_CTX_init() inicializa un contexto de verificación.

TS_VERIFY_CTX_free() libera un objeto TS_VERIFY_CTX. ctx es el contexto de verificación que se va a liberar. Si ctx es NULL, la llamada se ignora.

TS_VERIFY_CTX_set_flags() establece las banderas en el contexto de verificación. f son las banderas que se van a establecer.

TS_VERIFY_CTX_add_flags() agrega banderas al contexto de verificación. f son las banderas que se van a agregar (ORed).

TS_VERIFY_CTX_set0_data() establece los datos a verificar. b es el BIO con los datos. Un BIO asignado previamente se libera.

TS_VERIFY_CTX_set0_imprint() establece la huella digital del mensaje. hexstr es la huella digital del mensaje a asignar. Una huella digital asignada previamente se libera.

TS_VERIFY_CTX_set0_store() establece el almacén para el contexto de verificación. s es el almacén a asignar. Un almacén asignado previamente se libera.

TS_VERIFY_CTX_set0_certs() se utiliza para establecer la cadena de certificados del servidor al verificar un TST. certs es una pila de certificados X509.

TS_VERIFY_CTX_cleanup() libera todos los datos asociados con el objeto TS_VERIFY_CTX dado y lo inicializa. ctx es el contexto de verificación creado de antemano. Si ctx es NULL, la llamada se ignora.

Todas las siguientes funciones descritas están obsoletas. Las aplicaciones deberían usar en su lugar las funciones TS_VERIFY_CTX_set0_data(3), TS_VERIFY_CTX_set0_imprint(3), TS_VERIFY_CTX_set0_store(3), TS_VERIFY_CTX_set0_certs(3).

TS_VERIFY_CTX_set_data() se utiliza para establecer el BIO con los datos a verificar. Un BIO asignado previamente **no se libera** con esta llamada. b es el BIO con los datos a asignar.

TS_VERIFY_CTX_set_imprint() se utiliza para establecer la huella digital del mensaje. Una huella digital asignada previamente **se libera** con esta llamada. hexstr es la cadena con la huella digital del mensaje a asignar.

TS_VERIFY_CTX_set_store() se utiliza para establecer el almacén de certificados. Un almacén asignado previamente **no se libera** con esta llamada. s es el almacén a asignar.

TS_VERIFY_CTX_set_certs() se utiliza para establecer la cadena de certificados del servidor. Una pila asignada previamente **no se libera** con esta llamada. certs es una pila de certificados X509.

TS_VERIFY_CTS_set_certs() es una versión mal escrita de TS_VERIFY_CTX_set_certs() que toma los mismos parámetros y devuelve el mismo resultado.

VALORES DE RETORNO

TS_VERIFY_CTX_new() devuelve una estructura TS_VERIFY_CTX asignada.

TS_VERIFY_CTX_set_flags() devuelve las banderas pasadas a través del parámetro f.

TS_VERIFY_CTX_add_flags() devuelve las banderas del contexto después de que las pasadas a través del parámetro f se les hayan agregado.

TS_VERIFY_CTX_set0_data(), TS_VERIFY_CTX_set0_imprint(), TS_VERIFY_CTX_set0_store(), y TS_VERIFY_CTX_set0_certs() devuelven 1 si el valor pudo ser establecido exitosamente y 0 en caso de algún error.

Las funciones obsoletas TS_VERIFY_CTX_set_data(), TS_VERIFY_CTX_set_imprint(), TS_VERIFY_CTX_set_store(), TS_VERIFY_CTX_set_certs() devuelven el parámetro que el usuario pasa a través del parámetro bio, hexstr, s o certs.

VER TAMBIÉN

OSSL_ESS_check_signing_certs(3)

HISTORIA

TS_VERIFY_CTX_set0_data(), TS_VERIFY_CTX_set0_imprint(), TS_VERIFY_CTX_set0_store(), TS_VERIFY_CTX_set0_certs() reemplazan a las funciones TS_VERIFY_CTX_set_data(), TS_VERIFY_CTX_set_imprint(), TS_VERIFY_CTX_set_store(), TS_VERIFY_CTX_set_certs() que fueron obsoletas en OpenSSL 3.4.0.

La escritura de TS_VERIFY_CTX_set_certs() se corrigió en OpenSSL 3.0.0. La versión mal escrita TS_VERIFY_CTS_set_certs() se ha mantenido por razones de compatibilidad, pero está obsoleta en OpenSSL 3.0.0.
