Tss2_Tcti_Tabrmd_Init(3)

Paquete: tpm2-abrmd

Licencias: BSD-2-Clause

TSS2_TCTI_TABRMD_INIT(3) Pila de software de TPM2 TSS2_TCTI_TABRMD_INIT(3)

NOMBRE

Tss2_Tcti_Tabrmd_Init - Función de inicialización de la biblioteca TCTI de tpm2-abrmd.

SINOPSIS

La función Tss2_Tcti_Tabrmd_Init() se utiliza para inicializar un contexto TCTI para la comunicación con tpm2-abrmd(8).

#include <tcti/tcti-tabrmd.h>

TSS2_RC Tss2_Tcti_Tabrmd_Init (TSS2_TCTI_CONTEXT *tcti_context, size_t *size, const char *conf);

DESCRIPCIÓN

Tss2_Tcti_Tabrmd_Init() intenta inicializar un tcti_context asignado por el llamante de tamaño size con la configuración especificada en la cadena de configuración conf. Dado que el tcti_context debe ser un búfer asignado por el llamante, el llamante necesita conocer el tamaño requerido por la biblioteca TCTI. El tamaño mínimo de este contexto se puede descubrir proporcionando NULL para el parámetro tcti_context y un parámetro size no nulo. La función de inicialización poblará entonces el parámetro size con el tamaño mínimo del búfer tcti_context. El llamante puede entonces asignar un búfer de este tamaño (o mayor) y llamar a tss2_Tcti_Tabrmd_Init() de nuevo, proporcionando el tcti_context recién asignado y el tamaño de este contexto en el parámetro size. Este patrón es común a todas las funciones de inicialización TCTI. Proporcionamos un ejemplo de este patrón utilizando la función Tss2_Tcti_Tabrmd_Init() en la sección titulada EJEMPLO.

El parámetro conf es una cadena de pares clave / valor que describe las propiedades de conexión deseadas para el TCTI. Si el llamante proporciona una cadena conf nula, se utilizarán los valores predeterminados que corresponden a los valores predeterminados de tpm2-abrmd (8). Esto es lo mismo que proporcionar la cadena conf: "bus_name=com.intel.tss2.Tabrmd,bus_type=system". Las claves y los valores están separados por el carácter '=', mientras que cada par clave/valor está separado por el carácter ','. Las claves y valores admitidos son:

•
bus_name - el nombre de dbus propiedad del demonio. Consulte la opción --dbus-name de tpm2-abrmd (8).
•
bus_type - el tipo de bus utilizado para la conexión con el demonio. El valor asociado con esta clave puede ser "system" o "session".

Una vez inicializado, el contexto TCTI devuelto expone la API definida por Trusted Computing Group (TCG) para la comunicación de nivel más bajo con el TPM. Utilizando esta API, el llamante puede intercambiar (enviar / recibir) búferes de comandos y respuestas TPM2 con el tpm2-abrmd (8). En casi todos los casos, sin embargo, el llamante inicializará un contexto utilizando esta función antes de pasar el contexto a una API de nivel superior como la API del Sistema (SAPI), y luego nunca volverá a tocarlo.

Para una discusión más completa de la API TCTI, consulte la especificación "TSS System Level API and TPM Command Transmission Interface Specification" publicada por TCG: https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

VALOR DE RETORNO

Una llamada exitosa a Tss2_Tcti_Tabrmd_Init() devolverá TSS2_RC_SUCCESS. Una llamada infructuosa producirá un código de respuesta descrito en la sección ERRORES.

ERRORES

Se devuelve TSS2_TCTI_RC_BAD_VALUE si el parámetro size es NULL.

Se devuelve TSS2_TCTI_RC_NO_CONNECTION cuando falla la comunicación con tpm2-abrmd (8).

Se devuelve TSS2_TCTI_RC_GENERAL_FAILURE para todos los demás errores.

EJEMPLO

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti-tabrmd.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
rc = tss2_tcti_tabrmd_init (NULL, &size, NULL,
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Falló la obtención del tamaño de asignación para el contexto TCTI de tabrmd "
             ": 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "Fallo de asignación para el contexto TCTI: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = tss2_tcti_tabrmd_init (tcti_context, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Fallo al inicializar el contexto TCTI de tabrmd: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
