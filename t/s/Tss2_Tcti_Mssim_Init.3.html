Tss2_Tcti_Mssim_Init(3) Manual de funciones de biblioteca Tss2_Tcti_Mssim_Init(3)

NOMBRE

Tss2_Tcti_Mssim_Init - Función de inicialización para la biblioteca TCTI del simulador TPM de Microsoft

SINOPSIS

#include <tcti/tcti_mssim.h>

TSS2_RC Tss2_Tcti_Mssim_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *contextSize, const char *conf);

La función Tss2_Tcti_Mssim_Init() inicializa un contexto TCTI utilizado para comunicarse con el simulador TPM2 de Microsoft.

DESCRIPCIÓN

Tss2_Tcti_Mssim_Init() intenta inicializar un tcti_context asignado por el llamante de tamaño contextSize utilizando la cadena de configuración conf proporcionada por el llamante. Dado que el tcti_context debe ser un búfer asignado por el llamante, el llamante necesita conocer el tamaño del búfer requerido por la biblioteca TCTI. El tamaño mínimo de este contexto se puede descubrir proporcionando NULL para el parámetro tcti_context y un parámetro contextSize distinto de NULL. La función de inicialización poblará entonces el parámetro contextSize con el tamaño mínimo del búfer tcti_context. Luego, el llamante debe asignar un búfer de este tamaño (o mayor) y llamar a Tss2_Tcti_Mssim_Init () nuevamente, proporcionando el tcti_context recién asignado y el tamaño de este contexto en el parámetro contextSize. Este patrón es común a todas las funciones de inicialización de TCTI. Proporcionamos un ejemplo de este patrón utilizando la función Tss2_Tcti_Mssim_Init() en la sección titulada EJEMPLO.

El parámetro conf es una cadena C utilizada para configurar el contexto TCTI. Esta cadena de configuración es una serie de pares clave/valor que especifican el host y el puerto utilizados para conectarse a una instancia del simulador TPM2 de Microsoft. Las claves y los valores están separados por el carácter '=', mientras que cada par clave/valor está separado por el carácter ','.

Las únicas claves admitidas en la cadena conf son host y port. El host puede ser una dirección IPv4, una dirección IPv6 o un nombre de host. El puerto debe ser un uint16_t válido en formato de cadena. Si el llamante proporciona una cadena conf NULL, se utilizará el valor predeterminado "host=localhost,port=2321". Si se omite host o port, se utilizará su valor predeterminado respectivo.

Una vez inicializado, el contexto TCTI devuelto expone la API definida por Trusted Computing Group (TCG) para la comunicación de nivel más bajo con el TPM. Utilizando esta API, el llamante puede intercambiar (enviar/recibir) búferes de comandos y respuestas TPM2 con el simulador TPM de Microsoft. Sin embargo, en casi todos los casos, el llamante inicializará un contexto utilizando esta función antes de pasar el contexto a una API de nivel superior como la API del Sistema (SAPI), y luego nunca volverá a tocarlo.

Para una discusión más completa de la API TCTI, consulte la "Especificación de la Interfaz de Transmisión de Comandos del TPM y la API de Nivel del Sistema TSS" publicada por el TCG: https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

VALOR DE RETORNO

Una llamada exitosa a Tss2_Tcti_Mssim_Init() devolverá TSS2_RC_SUCCESS. Una llamada fallida producirá un código de respuesta descrito en la sección ERRORES.

ERRORES

Se devuelve TSS2_TCTI_RC_BAD_VALUE si los parámetros tcti_context y contextSize son NULL, o si el parámetro config es NULL.

EJEMPLO

Fragmento de inicialización de TCTI:

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_mssim.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
const char *conf = "host=localhost,port=2321"
rc = Tss2_Tcti_Mssim_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "No se pudo obtener el tamaño de asignación para el contexto TCTI mssim "
             ": 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "La asignación para el contexto TCTI falló: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Mssim_Init (&tcti_context, &size, conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "No se pudo inicializar el contexto TCTI mssim: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
