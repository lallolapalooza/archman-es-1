NOMBRE

HTML::PullParser - Interfaz alternativa de HTML::Parser

SINOPSIS

use HTML::PullParser;
$p = HTML::PullParser->new(file => "index.html",
                           start => 'event, tagname, @attr',
                           end   => 'event, tagname',
                           ignore_elements => [qw(script style)],
                          ) || die "No se puede abrir: $!";
while (my $token = $p->get_token) {
    #...hacer algo con $token
}

DESCRIPCIÓN

HTML::PullParser es una interfaz alternativa a la clase HTML::Parser. Básicamente, pone HTML::Parser al revés. Usted asocia un archivo (o cualquier objeto IO::Handle o cadena) con el analizador en el momento de la construcción y luego llama repetidamente a $parser->get_token para obtener las etiquetas y el texto encontrados en el documento analizado.

Los siguientes métodos se proporcionan:

$p = HTML::PullParser->new( file => $file, %options )
$p = HTML::PullParser->new( doc => \$doc, %options )
Un "HTML::PullParser" puede construirse para analizar desde un archivo o un documento literal según si la opción "file" o "doc" se pasa al constructor del analizador.

El "file" pasado puede ser un nombre de archivo o un objeto de descriptor de archivo. Si se pasa un nombre de archivo y no se puede abrir para lectura, el constructor devolverá un valor indefinido y $! le dirá por qué falló. De lo contrario, el argumento se toma como algún objeto del que "HTML::PullParser" puede leer() cuando necesita más datos. El flujo se leerá() hasta EOF, pero no se cerrará.

Se puede pasar un "doc" sin referenciar o como referencia a un escalar. Si se pasa una referencia, el valor de este escalar no debe cambiarse antes de que se hayan extraído todos los tokens.

A continuación, se debe configurar la información que se va a devolver para los diferentes tipos de tokens. Esto se hace simplemente asociando una especificación de argumento (tal como se define en HTML::Parser) con los eventos que le interesan. Por ejemplo, si desea que los tokens de "start" se informen como la cadena 'S' seguida del nombre de la etiqueta y los atributos, podría pasar una opción de "start" como esta:

$p = HTML::PullParser->new(
       doc   => $document_a_analizar,
       start => '"S", tagname, @attr',
       end   => '"E", tagname',
     );

Finalmente, se pueden pasar otras opciones de "HTML::Parser", como "ignore_tags" y "unbroken_text". Tenga en cuenta que no debe utilizar las opciones de *_h para configurar los manejadores del analizador. Eso confundiría la lógica interna de "HTML::PullParser".

$token = $p->get_token
Este método devolverá el siguiente token encontrado en el documento HTML, o "undef" al final del documento. El token se devuelve como una referencia de array. El contenido de esta matriz coincide con la especificación de argumento configurada durante la construcción de "HTML::PullParser".
$p->unget_token( @tokens )
Si descubre que ha leído demasiados tokens, puede volver a introducirlos, de modo que se devuelvan la próxima vez que se llame a $p->get_token.
