Descripción detallada

Las aplicaciones que manipulan muchas topologías similares, por ejemplo, una por cada nodo de un clúster homogéneo, pueden querer comprimir las topologías para reducir el uso de memoria.

Este archivo ofrece una forma de manipular la diferencia entre topologías y exportarla/importarla desde/hacia XML. Por lo tanto, la compresión se puede lograr almacenando una topología completamente mientras que las otras solo se describen por sus diferencias con la primera. La topología real se puede reconstruir cuando se necesite aplicando la diferencia precalculada a la topología de referencia.

Esta interfaz se dirige a nodos muy similares. Solo se admiten diferencias muy simples entre topologías, por ejemplo, un cambio en el tamaño de la memoria, el nombre del objeto o algún atributo de información. Las diferencias más complejas, como agregar o eliminar objetos, no se pueden representar en las estructuras de diferencia y, por lo tanto, devuelven errores. Las diferencias entre conjuntos de objetos o conjuntos permitidos en toda la topología tampoco se pueden representar.

Esto significa que no es necesario aplicar la diferencia al examinar la organización del árbol (cuántos niveles, cuántos objetos por nivel, qué tipo de objetos, conjuntos de CPU y nodos, etc.) y al enlazar a objetos. Sin embargo, la diferencia debe aplicarse al examinar los atributos del objeto, como el nombre, el tamaño de la memoria o los atributos de información.

Documentación de funciones

int hwloc_topology_diff_apply (hwloc_topology_t topology, hwloc_topology_diff_t diff, unsigned long flags)

Aplica una diferencia de topología a una topología existente. flags es un conjunto OR de hwloc_topology_diff_apply_flags_e.

La nueva topología se modifica en el lugar. hwloc_topology_dup() puede ser utilizada para duplicarla antes de parchearla.

Si la diferencia no se puede aplicar por completo, todos los elementos aplicados previamente se desaplican antes de devolver.

Retorna

0 en caso de éxito.

-N si la aplicación de la diferencia falló mientras se intentaba aplicar la N-ésima parte de la diferencia. Por ejemplo, se devuelve -1 si el primer elemento de diferencia no se pudo aplicar.

int hwloc_topology_diff_build (hwloc_topology_t topology, hwloc_topology_t newtopology, unsigned long flags, hwloc_topology_diff_t *diff)

Construye una diferencia entre dos topologías. flags es un conjunto OR de hwloc_topology_diff_flags_e.

La diferencia se devuelve en *diff. El caller debe llamar a hwloc_topology_diff_destroy() para liberarla más tarde.

Si las topologías son idénticas, *diff se establece en NULL y la función devuelve 0.

Si las topologías son demasiado diferentes y la diferencia no puede ser representada (por ejemplo, si se agregan o eliminan objetos), la función devuelve 1 y *diff se establece en NULL.

Retorna

0 en caso de éxito, 1 si la diferencia es demasiado compleja.

int hwloc_topology_diff_destroy (hwloc_topology_diff_t diff)

Libera la memoria ocupada por la diferencia de topología `diff`.

Si `diff` es NULL, no hace nada.

Retorna

0 en caso de éxito, -1 en caso de error.

Calcula la diferencia entre 2 topologías. La diferencia se almacena como una lista de entradas hwloc_topology_diff_t que comienza en diff. Se calcula realizando un recorrido en profundidad (depth-first) de ambos árboles de topología simultáneamente.

Si la diferencia entre 2 objetos es demasiado compleja para ser representada (por ejemplo, si algunos objetos tienen tipos diferentes, o diferentes números de hijos), se encola una entrada de diferencia especial de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX . El cálculo de la diferencia no continúa por debajo de estos objetos. Por lo tanto, cada una de estas entradas de diferencia significa que la diferencia entre dos subárboles no pudo ser calculada.

Devuelve

0 si la diferencia puede ser representada correctamente.

0 con diff apuntando a NULL si no hay diferencia entre las topologías.

1 si la diferencia es demasiado compleja (ver arriba). Algunas entradas en la lista serán de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 en cualquier otro error.

Nota

flags actualmente no se utiliza. Debería ser 0.

La salida diff debe ser liberada con hwloc_topology_diff_destroy().

La salida diff solo puede ser exportada a XML o pasada a hwloc_topology_diff_apply() si se devolvió 0, es decir, si no hay ninguna entrada de tipo HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX en la lista.

La salida diff puede ser modificada eliminando algunas entradas de la lista. Las entradas eliminadas deberían ser liberadas pasándolas a hwloc_topology_diff_destroy() (posiblemente como otra lista).

int hwloc_topology_diff_export_xmlbuffer (hwloc_topology_diff_t diff, const char * refname, char ** xmlbuffer, int * buflen)

Exporta una lista de diferencias de topología a un búfer XML. Si no es NULL, refname define una cadena identificadora para la topología de referencia que se usó como base al calcular esta diferencia.
