HTTP::Config(3) Documentación de Perl aportada por el usuario HTTP::Config(3)

SINÓPSIS

use HTTP::Config;
my $c = HTTP::Config->new;
$c->add(m_domain => ".example.com", m_scheme => "http", verbose => 1);

use HTTP::Request;
my $request = HTTP::Request->new(GET => "http://www.example.com");

if (my @m = $c->matching($request)) {
   print "Yadayada\n" if $m[0]->{verbose};
}

DESCRIPCIÓN

Un objeto "HTTP::Config" es una lista de entradas que pueden ser cotejadas contra solicitudes o pares de solicitud/respuesta. Su propósito es mantener datos de configuración que puedan ser buscados dada una solicitud o un objeto de respuesta.

Cada entrada de configuración es un hash. Algunas claves especifican el cotejo que debe ocurrir contra atributos de objetos de solicitud/respuesta. Otras claves pueden ser usadas para mantener datos de usuario.

Se proporcionan los siguientes métodos:

$conf = HTTP::Config->new
Construye un nuevo objeto "HTTP::Config" vacío y lo devuelve.
$conf->entries
Devuelve la lista de entradas en el objeto de configuración. En contexto escalar devuelve el número de entradas.
$conf->empty
Devuelve verdadero si no hay entradas en el objeto de configuración. Esto es solo un atajo para "not $conf->entries".
$conf->add( %matchspec, %other )
$conf->add( \%entry )
Añade una nueva entrada a la configuración. Puedes pasar pares clave/valor separados o una referencia de hash.
$conf->remove( %spec )
Elimina (y devuelve) las entradas que tengan coincidencias para todos los pares clave/valor en %spec. Si %spec está vacío, esto coincidirá con todas las entradas; por lo tanto, vaciará el objeto de configuración.
$conf->matching( $uri, $request, $response )
$conf->matching( $uri )
$conf->matching( $request )
$conf->matching( $response )
Devuelve las entradas que coinciden con el trío dado de $uri, $request y $response.

Si se llama con un único objeto $request, entonces la $uri se obtiene llamando a su método 'uri_canonical'. Si se llama con un único objeto $response, entonces el objeto de solicitud se obtiene llamando a su método 'request'; y luego la $uri se obtiene como si se hubiera proporcionado una única $request.

Las entradas se devuelven con las coincidencias más específicas primero. En contexto escalar devuelve la coincidencia más específica o "undef" si no hay coincidencias.

$conf->add_item( $item, %matchspec )
$conf->remove_items( %spec )
$conf->matching_items( $uri, $request, $response )
Envoltorios que ocultan las propias entradas.

Cotejo

Las siguientes claves en una entrada de configuración especifican el cotejo. Para todas ellas puedes proporcionar una matriz de valores en lugar de un solo valor. La entrada coincide si al menos uno de los valores de la matriz coincide.

Las entradas que requieren cotejo contra un atributo del objeto de respuesta nunca coincidirán a menos que se haya proporcionado un objeto de respuesta.

m_scheme => $scheme
Coincide si la URI utiliza el esquema especificado; por ejemplo, "http".
m_secure => $bool
Si $bool es VERDADERO; coincide si la URI utiliza un esquema seguro. Si $bool es FALSO; coincide si la URI no utiliza un esquema seguro. Un ejemplo de esquema seguro es "https".
m_host_port => "$hostname:$port"
Coincide si el método host_port de la URI devuelve el valor especificado.
m_host => $hostname
Coincide si el método host de la URI devuelve el valor especificado.
m_port => $port
Coincide si el método port de la URI devuelve el valor especificado.
m_domain => ".$domain"
Coincide si el método host de la URI devuelve un valor dentro del dominio dado. El nombre de host "www.example.com" coincidirá, por ejemplo, con el dominio ".com".
m_path => $path
Coincide si el método path de la URI devuelve el valor especificado.
m_path_prefix => $path
Coincide si la ruta de la URI es la ruta especificada o tiene la ruta especificada como prefijo.
m_path_match => $Regexp
Coincide si la expresión regular coincide con la ruta de la URI. Por ejemplo, qr/\.html$/.
m_method => $method
Coincide si el método de solicitud coincide con el valor especificado. Por ejemplo, "GET" o "POST".
m_code => $digit
m_code => $status_code
Coincide si el código de estado de la respuesta coincide. Si se especifica un solo dígito; coincide para todos los códigos de estado de respuesta que comienzan con ese dígito.
m_proxy => $url
Coincide si la solicitud debe enviarse al servidor Proxy dado.
m_media_type => "*/*"
m_media_type => "text/*"
m_media_type => "html"
m_media_type => "xhtml"
m_media_type => "text/html"
Coincide si el tipo de medio de la respuesta coincide.

Con un valor de "html" coincide si $response->content_is_html devuelve VERDADERO. Con un valor de "xhtml" coincide si $response->content_is_xhtml devuelve VERDADERO.

m_uri__$method => undef
Coincide si el objeto URI proporciona el método.
m_uri__$method => $string
Coincide si el método $method de la URI devuelve el valor dado.
m_header__$field => $string
Coincide si la solicitud o la respuesta tienen una cabecera $field con el valor dado.
m_response_attr__$key => undef
m_response_attr__$key => $string
Coincide si el objeto de respuesta tiene esa clave, o la entrada tiene el valor dado.
