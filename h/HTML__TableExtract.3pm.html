NOMBRE

HTML::TableExtract - Módulo Perl para extraer el contenido contenido en tablas dentro de un documento HTML, ya sea como texto o como árboles de elementos codificados.

SINOPSIS

# Las tablas coincidentes se devuelven como objetos de tabla; las tablas se pueden
# emparejar utilizando encabezados de columna, profundidad, recuento dentro de una profundidad,
# atributos de etiqueta de tabla o alguna combinación de los cuatro.
# Ejemplo: Usando información de encabezados de columna.
# Suponga un documento HTML con tablas que tengan "Fecha", "Precio" y
# "Costo" en alguna parte de una fila. Las columnas debajo de esos encabezados son
# lo que desea extraer. Se devolverán en el mismo orden que
# especificó los encabezados ya que 'automap' está habilitado por defecto.
use HTML::TableExtract;
my $te = HTML::TableExtract->new( headers => [qw(Fecha Precio Costo)] );
$te->parse($cadena_html);
# Examinar todas las tablas coincidentes
foreach my $ts ($te->tables) {
  print "Tabla (", join(',', $ts->coords), "):\n";
  foreach my $row ($ts->rows) {
     print join(',', @$row), "\n";
  }
}
# Abreviatura... el método rows() de nivel superior asume la primera tabla encontrada en
# el documento si no se proporcionan argumentos.
foreach my $row ($te->rows) {
   print join(',', @$row), "\n";
}
# Ejemplo: Usando información de profundidad y recuento.
# Cada tabla en el documento tiene una tupla única de profundidad y recuento, por lo que
# cuando se especifican ambas, se trata de una tabla única. La profundidad y el recuento comienzan
# con 0, por lo que en este caso estamos buscando una tabla (profundidad 2)
# dentro de una tabla (profundidad 1) dentro de una tabla (profundidad 0, que es el documento HTML
# de nivel superior). Además, debe ser la tercera (recuento 2)
# instancia de una tabla en esa profundidad.
my $te = HTML::TableExtract->new( depth => 2, count => 2 );
$te->parse_file($archivo_html);
foreach my $ts ($te->tables) {
   print "Tabla encontrada en ", join(',', $ts->coords), ":\n";
   foreach my $row ($ts->rows) {
      print "   ", join(',', @$row), "\n";
   }
}
# Ejemplo: Usando atributos de etiqueta de tabla.
# Si se especifican varios atributos, todos deben estar presentes y ser iguales
# para que ocurra la coincidencia.
my $te = HTML::TableExtract->new( attribs => { border => 1 } );
$te->parse($cadena_html);
foreach my $ts ($te->tables) {
  print "Tabla con border=1 encontrada en ", join(',', $ts->coords), ":\n";
  foreach my $row ($ts->rows) {
     print "   ", join(',', @$row), "\n";
  }
}
# Ejemplo: Extrayendo como una estructura de árbol de HTML::Element
# En lugar de extraer texto plano, el html se puede convertir en un
# árbol de objetos de elemento. El documento HTML está compuesto por
# objetos HTML::Element y las tablas son estructuras HTML::ElementTable
# . Usando esto, el contenido de las tablas dentro de un documento puede
# ser editado en el lugar.
use HTML::TableExtract qw(tree);
my $te = HTML::TableExtract->new( headers => qw(Tarifa Fia Foe Fum) );
$te->parse_file($archivo_html);
my $table = $te->first_table_found;
my $table_tree = $table->tree;
$table_tree->cell(4,4)->replace_content('Golden Goose');
my $table_html = $table_tree->as_HTML;
my $table_text = $table_tree->as_text;
my $document_tree = $te->tree;
my $document_html = $document_tree->as_HTML;

DESCRIPCIÓN

HTML::TableExtract es una subclase de HTML::Parser que sirve para extraer la información de tablas de interés contenidas dentro de un documento HTML. La información de cada tabla extraída se almacena en objetos de tabla. Las tablas se pueden extraer como texto, HTML o estructuras HTML::ElementTable (para edición o manipulación en el lugar).

Actualmente hay cuatro restricciones disponibles para especificar qué tablas le gustaría extraer de un documento: Encabezados, Profundidad, Recuento y Atributos.

Encabezados, la más flexible y adaptable de las técnicas, implica especificar texto en un array que espera que aparezca encima de los datos en las tablas de interés. Una vez que se localizan todos los encabezados en una fila de esa tabla, se extraen todas las celdas posteriores debajo de las columnas que coincidieron con sus encabezados. Se ignoran todas las demás columnas: piénselo como rebanadas verticales a través de una tabla. Además, TableExtract reorganiza automáticamente cada fila en el mismo orden que los encabezados que proporcionó. Si desea deshabilitar esto, establezca automap en 0 durante la creación del objeto y, en su lugar, confíe en el método column_map() para averiguar el orden en que se encontraron los encabezados. Además, TableExtract compensará automáticamente los problemas de expansión de celdas para que las columnas sean realmente las mismas columnas que vería visualmente en un navegador. Este comportamiento se puede deshabilitar estableciendo el parámetro gridmap en 0. El HTML se elimina de todo el contenido textual de una celda antes de que se intenten las coincidencias de encabezados, a menos que se haya habilitado el parámetro keep_html.

Profundidad y Recuento son formas más específicas de especificar tablas en relación entre sí. Profundidad representa cuán profundamente reside una tabla en otras tablas. La profundidad de una tabla de nivel superior en el documento es 0. Una tabla dentro de una tabla de nivel superior tiene una profundidad de 1, y así sucesivamente. Cada profundidad puede considerarse como una capa; las tablas que comparten la misma profundidad están en la misma capa. Dentro de cada una de estas capas, Recuento representa el orden en que se vio una tabla en esa profundidad, comenzando con 0. Proporcionar tanto una profundidad como un recuento especificará de forma única una tabla dentro de un documento.

Atributos coincide en función de los atributos de la etiqueta html <table>, por ejemplo, anchos de borde o color de fondo.

Cada una de las especificaciones de Encabezados, Profundidad, Recuento y Atributos son acumulativas en su efecto sobre la extracción general. Por ejemplo, si solo especifica una Profundidad, entonces obtiene todas las tablas a esa profundidad (tenga en cuenta que estas podrían residir en tablas de nivel superior separadas en todo el documento, ya que la profundidad se extiende a través de las tablas). Si solo especifica un Recuento, entonces se devuelven las tablas con ese Recuento de todas las profundidades (es decir, la n-ésima ocurrencia de una tabla en cada profundidad). Si solo especifica Encabezados, entonces obtiene todas las tablas del documento que contienen esos encabezados de columna. Si ha especificado múltiples restricciones de Encabezados, Profundidad, Recuento y Atributos, entonces cada restricción tiene poder de veto sobre si se extrae una tabla en particular.

Si no se especifican Encabezados, Profundidad, Recuento o Atributos, entonces todas las tablas coinciden.

Al extraer solo texto de las tablas, el texto se decodifica con HTML::Entities por defecto; esto se puede deshabilitar estableciendo el parámetro decode en 0.

Modos de Extracción

El modo de extracción por defecto para HTML::TableExtract es texto plano o HTML. En este modo, las tablas incrustadas se desacoplan completamente unas de otras. En este caso, HTML::TableExtract es una subclase de HTML::Parser:

use HTML::TableExtract;

Alternativamente, las tablas se pueden extraer como estructuras HTML::ElementTable, que a su vez están incrustadas en un árbol de HTML::Element que representa todo el documento HTML. Las tablas incrustadas no se desacoplan unas de otras ya que esta estructura de árbol debe mantenerse. En este caso, HTML::TableExtract es una subclase de HTML::TreeBuilder (a su vez una subclase de HTML:::Parser):

use HTML::TableExtract qw(tree);

En cualquier caso, la interfaz básica para HTML::TableExtract y los objetos de tabla resultantes sigue siendo la misma; todo lo que cambia es lo que puede hacer con los datos resultantes.

HTML::TableExtract es una subclase de HTML::Parser y, como tal, hereda todos sus métodos básicos como parse() y parse_file(). Durante los escaneos, se utilizan start(), end() y text(). Siéntase libre de sobrescribirlos, pero si no los invoca eventualmente en la clase SUPER con algún contenido, los resultados no están garantizados.

Consejos

El propósito principal de este módulo era proporcionar un método flexible para extraer información tabular de documentos HTML sin depender demasiado del diseño del documento. Por esa razón, sugiero usar Encabezados siempre que sea posible; de esta manera, está anclando su extracción en lo que el documento intenta comunicar en lugar de alguna característica del HTML que compone el documento (aparte del hecho de que los datos están contenidos en una tabla).

METHODS

rows()
Return all the rows from within a matched table as a list of array references. If headers were specified, and the keep_headers parameter was set to true, then the first element of this list will be the header row. Otherwise, this method will return a list of array references representing the data rows only.
row($row)
Return a particular row from within a matched table as a list or an array reference, depending on context.
column($col)
Return a particular column from within a matched table as a list or an array reference, depending on context.
cell($row,$col)
Return a particular item from within a matched table, whether it be the text, HTML, or reference to the HTML::Element object of that cell, depending on the mode of extraction. If the cell was covered due to rowspan or colspan effects, will return undef.
space($row,$col)
The same as cell(), except in cases where the given coordinates were covered due to rowspan or colspan issues, in which case the content of the covering cell is returned rather than undef.
depth()
Return the depth at which this table was found.
count()
Return the count for this table within the depth it was found.
coords()
Return depth and count in a list.
tree()
If the module was invoked in tree extraction mode, this accessor provides a reference to the HTML::ElementTable structure encompassing the table.
hrow()
Returns the header row as a list when headers were specified as a constraint. If "keep_headers" was specified initially, this is equivalent to the first row returned by the rows() method.
column_map()
Return the order (via indices) in which the provided headers were found. These indices can be used as slices on rows to either order the rows in the same order as headers or restore the rows to their natural order, depending on whether the rows have been pre-adjusted using the automap parameter.
lineage()
Returns the path of matched tables that led to matching this table. The path is a list of array refs containing depth, count, row, and column values for each ancestor table involved. Note that corresponding table objects will not exist for ancestral tables that did not match specified constraints.

NOTAS SOBRE EL MODO DE EXTRACCIÓN DE ÁRBOLES

Como se mencionó anteriormente, HTML::TableExtract se puede invocar en modo 'tree' donde el HTML resultante y las tablas extraídas se codifican en estructuras de árbol de HTML::Element:

use HTML::TableExtract 'tree';

Hay una serie de cosas a tener en cuenta al usar este modo. Todo el documento HTML se codifica en un árbol de HTML::Element. Cada tabla es parte de esta estructura, pero sin embargo se rastrea por separado a través de una estructura HTML::ElementTable, que es una forma especializada de árbol HTML::Element.

Los objetos HTML::ElementTable son accesibles invocando el método tree() desde dentro de cada objeto de tabla devuelto por HTML::TableExtract. Los objetos HTML::ElementTable tienen sus propios métodos row(), col() y cell() (entre otros). Estos no deben confundirse con los métodos row() y column() proporcionados por los objetos HTML::TableExtract::Table.

Por ejemplo, el método row() de HTML::ElementTable proporcionará una referencia a un 'glob' de todos los elementos de esa fila. Las acciones (como establecer atributos) realizadas en esa referencia de fila afectarán a todos los elementos dentro de esa fila. Por otro lado, el método row() del objeto HTML::TableExtract::Table devolverá una matriz (ya sea por referencia o lista, según el contexto) del contenido de cada celda dentro de la fila. En modo de árbol, el contenido se representa mediante referencias individuales a cada celda, estas son referencias a los mismos objetos HTML::Element que residen en el árbol HTML::Element.

Por lo tanto, los métodos cell() proporcionados en ambos casos devolverán referencias al mismo objeto. La excepción a esto es cuando una 'celda' en la cuadrícula de la tabla fue originalmente 'cubierta' debido a problemas de rowspan o colspan; en este caso, el contenido de la celda será undef. De manera similar, los métodos row() o column() de los objetos HTML::TableExtract::Table devolverán matrices que potencialmente contienen una mezcla de referencias de objetos y undefs. Si va a realizar muchas manipulaciones de los elementos de la tabla, podría ser más eficiente acceder a ellos a través de los métodos proporcionados por el objeto HTML::ElementTable. Consulte HTML::ElementTable para obtener más información sobre cómo manipular esos objetos.

Una alternativa al método cell() en HTML::TableExtract::Table es el método space(). Es en gran medida similar a cell(), excepto cuando se le dan las coordenadas de una celda que estaba cubierta debido a problemas de rowspan o colspan, devolverá el contenido de la celda que cubría ese espacio en lugar de undef. Por lo tanto, si, por ejemplo, la celda (0,0) tenía un rowspan de 2 y un colspan de 2, cell(1,1) devolvería undef y space(1,1) devolvería el mismo contenido que cell(0,0) o space(0,0).
