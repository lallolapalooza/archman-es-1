HTML::Tagset(3) Documentación de Perl aportada por el usuario HTML::Tagset(3)

NOMBRE

HTML::Tagset - tablas de datos útiles para analizar HTML

VERSIÓN

Versión 3.24

SINOPSIS

use HTML::Tagset;
# Luego use cualquiera de los elementos del paquete HTML::Tagset
# según sea necesario

DESCRIPCIÓN

Este módulo contiene varias tablas de datos útiles para diversos tipos de operaciones de análisis de HTML.

Tenga en cuenta que todos los nombres de etiquetas utilizados están en minúsculas.

En la siguiente documentación, un "conjunto de hash" (hashset) es un hash que se utiliza como un conjunto: el hash indica que sus claves están presentes, y los valores reales asociados con las claves no son significativos. (Pero los valores que haya son siempre verdaderos.)

VARIABLES

Tenga en cuenta que ninguna de estas variables se exporta.

conjunto de hash %HTML::Tagset::emptyElement

Este conjunto de hash tiene como valores los nombres de etiqueta (GIs) de elementos que no pueden tener contenido. (Por ejemplo, "base", "br", "hr".) Así que $HTML::Tagset::emptyElement{'hr'} existe y es verdadero. $HTML::Tagset::emptyElement{'dl'} no existe, y por lo tanto no es verdadero.

conjunto de hash %HTML::Tagset::optionalEndTag

Este conjunto de hash lista los nombres de etiqueta de elementos que pueden tener contenido, pero cuyas etiquetas de cierre generalmente pueden omitirse de forma "segura". Ejemplo: $HTML::Tagset::emptyElement{'li'} existe y es verdadero.

hash %HTML::Tagset::linkElements

Los valores en este hash son nombres de etiqueta de elementos que pueden contener enlaces, y el valor para cada uno es una referencia a un array de los nombres de atributos cuyos valores pueden ser enlaces.

hash %HTML::Tagset::boolean_attr

Este hash (no un conjunto de hash) lista qué atributos de qué elementos pueden imprimirse sin mostrar el valor (por ejemplo, el atributo "noshade" de los elementos "hr"). Para elementos con solo un atributo de este tipo, su valor es simplemente el nombre de ese atributo. Para elementos con muchos atributos de este tipo, el valor es una referencia a un conjunto de hash que contiene todos esos atributos.

conjunto de hash %HTML::Tagset::isPhraseMarkup

Este conjunto de hash contiene todos los elementos de nivel de frase.

conjunto de hash %HTML::Tagset::is_Possible_Strict_P_Content

Este conjunto de hash contiene todos los elementos de nivel de frase que pueden ser contenido de un elemento P, para un modelo estricto de HTML.

conjunto de hash %HTML::Tagset::isHeadElement

Este conjunto de hash contiene todos los elementos que deben estar presentes solo en el elemento 'head' de un documento HTML.

conjunto de hash %HTML::Tagset::isList

Este conjunto de hash contiene todos los elementos que pueden contener elementos "li".

conjunto de hash %HTML::Tagset::isTableElement

Este conjunto de hash contiene todos los elementos que se encuentran solo en/dentro de un elemento "table".

conjunto de hash %HTML::Tagset::isFormElement

Este conjunto de hash contiene todos los elementos que se encuentran solo en/dentro de un elemento "form".

conjunto de hash %HTML::Tagset::isBodyElement

Este conjunto de hash contiene todos los elementos que se encuentran solo en/dentro del elemento "body" de un documento HTML.

conjunto de hash %HTML::Tagset::isHeadOrBodyElement

Este conjunto de hash incluye todos los elementos que he notado pueden estar tanto en el head como en el body.

conjunto de hash %HTML::Tagset::isKnown

Este conjunto de hash lista todos los elementos HTML conocidos.

conjunto de hash %HTML::Tagset::canTighten

Este conjunto de hash lista elementos que pueden tener espacios en blanco ignorables como hijos o hermanos.

array @HTML::Tagset::p_closure_barriers

Este array tiene un significado del que solo he visto la necesidad en "HTML::TreeBuilder", pero lo incluyo aquí por si alguien pudiera encontrarlo útil:

Cuando vemos un token "<p>", buscamos en la ascendencia un elemento p que podríamos tener que minimizar. A primera vista, podríamos decir que si hay un p en cualquier lugar de la ascendencia de este nuevo p, debería cerrarse. Pero eso está mal. Considere este documento:

<html>
  <head>
    <title>foo</title>
  </head>
  <body>
    <p>foo
      <table>
        <tr>
          <td>
             foo
             <p>bar
          </td>
        </tr>
      </table>
    </p>
  </body>
</html>

El segundo p está legalmente dentro de un p mucho más alto.

Mi formalización de la razón por la que esto es legal, pero esto:

<p>foo<p>bar</p></p>

no lo es, es que algo sobre la tabla constituye una "barrera" para la aplicación de la regla sobre lo que p debe minimizar.

Así que @HTML::Tagset::p_closure_barriers es la lista de todas esas etiquetas de barrera.

conjunto de hash %isCDATA_Parent

Este conjunto de hash incluye todos los elementos cuyo contenido es CDATA.

ADVERTENCIAS

Puede encontrar útil alterar el comportamiento de módulos (como "HTML::Element" o "HTML::TreeBuilder") que usan "HTML::Tagset"'s tablas de datos alterando las tablas de datos mismas. Puede intentarlo, pero tenga cuidado; y tenga en cuenta que diferentes módulos pueden o no reaccionar de manera diferente a los cambios en las tablas de datos.

Tenga en cuenta que puede ser inapropiado usar estas tablas para producir HTML -- por ejemplo, %isHeadOrBodyElement lista los nombres de etiqueta de todos los elementos que pueden aparecer tanto en el head como en el body, como "script". Eso no significa que esté diciendo que su código que produce HTML deba sentirse libre de poner elementos script en cualquier lugar. Si está produciendo programas que generan HTML, debe estar íntimamente familiarizado con los DTD de HTML o XHTML (disponibles en " http://www.w3.org/""), y debe obedecerlos esclavamente, no las tablas de datos de este documento.
