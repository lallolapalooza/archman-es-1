Los mensajes pueden ser compuestos, es decir, contener otros mensajes. Los mensajes compuestos tienen un tipo de contenido de "multipart/*" o "message/*". Este método dar acceso a los mensajes contenidos.

La forma sin argumentos devolverá una lista de objetos "HTTP::Message". Si el tipo de contenido de $msg no es "multipart/*" o "message/*", entonces esto devolverá la lista vacía. En contexto escalar solo se devuelve el primer objeto. Las partes de mensaje devueltas deben considerarse de solo lectura (versiones futuras de esta biblioteca podrían hacer posible modificar el padre modificando las

partes).

Si el tipo de contenido de $msg es "message/*", entonces solo se devolverá una

parte.

Si el tipo de contenido es "message/http", entonces el valor de retorno será un objeto "HTTP::Request" o un objeto "HTTP::Resp

onse".

Si se proporciona un argumento @parts, entonces el contenido del mensaje será modificado. La forma de referencia de matriz se proporciona para que se pueda proporcionar una lista vacía. La matriz @parts debe contener objetos "HTTP::Message". Los objetos @parts pertenecen a $mess después de esta llamada y no deben ser modificados ni convertidos en parte de otros

mensajes.

Al actualizar el mensaje con este método, si el tipo de contenido antiguo de $mess no es "multipart/*" o "message/*", entonces el tipo de contenido se establece en "multipart/mixed" y todos los demás encabezados de contenido se

eliminan.
