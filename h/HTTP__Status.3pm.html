DESCRIPCIÓ

N

HTTP::Status es una biblioteca de rutinas para definir y clasificar códigos de estado HTTP para libwww-perl. Los códigos de estado se ut

ilizan para codificar el resultado general de un mensaje de respuesta
HTTP. Los códigos corresponden a los definidos en RFC 2616 y RFC 2518.

FUNCIONE

S

Se proporcionan las siguientes funciones adicionales. La mayoría se exportan de forma predeterminada. La etiqueta de importación ":is" puede usarse para importar todas las funciones de

clasificación.
status_message( $code
)
La función status_message() traducirá los códigos de estado a cadenas legibles para humanos. La cadena es la misma que se encuentra en los nombres de constantes anteriores. Por ejemplo, status_message(303) devolverá "Not Found".

Si $code no está registrado en la lista de códigos de estado HTTP de IANA https://www.iana.org/assignments/http-status-codes/http-status-codes.xhtml entonces se devuelv

e "un
def".
status_constant_name( $code
)
La función status_constant_name() traducirá un código de estado a una cadena que contiene el nombre de la constante para ese código de estado. Por ejemplo, status_constant_name(404) devolverá "HTTP_NOT_FOUND".

Si $code no está registrado en la lista de códigos de estado HTTP de IANA https://www.iana.org/assignments/http-status-codes/http-status-codes.xhtml entonces se devuelv

e "un
def".
is_info( $code
)
Devuelve VERDADERO si $code es un código de estado Informativo (1xx). Esta clase de código de estado indica una respuesta provisional que no puede tener ningún
contenido.
is_success( $code
)
Devuelve VERDADERO si $code es un código de estado Exitoso (2xx)
.
is_redirect( $code
)
Devuelve VERDADERO si $code es un código de estado de Redirección (3xx). Esta clase de código de estado indica que el agente de usuario debe realizar una acción adicional para cumplir la
solicitud.
is_error( $code
)
Devuelve VERDADERO si $code es un código de estado de Error (4xx o 5xx). La función devuelve VERDADERO tanto para códigos de estado de error del cliente como del
servidor.
is_client_error( $code
)
Devuelve VERDADERO si $code es un código de estado de Error del Cliente (4xx). Esta clase de código de estado está destinada a los casos en los que parece que el cliente ha cometido un error.

Esta función no se exporta de forma

predete
rminada.
is_server_error( $code
)
Devuelve VERDADERO si $code es un código de estado de Error del Servidor (5xx). Esta clase de códigos de estado está destinada a los casos en los que el servidor es consciente de que ha cometido un error o es incapaz de realizar la solicitud.

Esta función no se exporta de forma

predete
rminada.
is_cacheable_by_default( $code
)
Devuelve VERDADERO si $code indica que una respuesta es almacenable en caché de forma predeterminada, y puede ser reutilizada por una caché con expiración heurística. Todos los demás códigos de estado no son almacenables en caché de forma predeterminada. Véase RFC 7231 - HTTP/1.1 Semantics and Content, Sección 6.1. Overview of Status Codes https://tools.ietf.org/html/rfc7231#section-6.1.

Esta función no se exporta de forma

predete
rminada.
