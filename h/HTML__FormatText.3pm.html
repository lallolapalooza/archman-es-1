NOMBRE

HTML::FormatText - Formatea HTML como texto plano

VERSIÓN

versión 2.16

SINOPSIS

use HTML::TreeBuilder;
$tree = HTML::TreeBuilder->new->parse_file("test.html");
use HTML::FormatText;
$formatter = HTML::FormatText->new(leftmargin => 0, rightmargin => 50);
print $formatter->format($tree);

o, más sencillamente:

use HTML::FormatText;
my $string = HTML::FormatText->format_file(
    'test.html',
    leftmargin => 0, rightmargin => 50
    );

DESCRIPCIÓN

HTML::FormatText es un formateador que genera texto plano. Se ignoran todos los atributos de caracteres (negrita/cursiva/subrayado). El formato de tablas y formularios HTML no está implementado.

HTML::FormatText está basado en HTML::Formatter y la documentación de ese módulo se aplica a este, especialmente "new" en HTML::Formatter, "format_file" en HTML::Formatter y "format_string" en HTML::Formatter.

Puede especificar los siguientes parámetros al construir el formateador:

margen-izquierdo (alias lm)
La columna del margen izquierdo. El valor predeterminado es 3.
margen-derecho (alias rm)
La columna del margen derecho. El valor predeterminado es 72.
