HTTP::Server::Simple::CGI::Environment(3) Documentación de Perl contribuida por el usuario HTTP::Server::Simple::CGI::Environment(3)

NOMBRE

HTTP::Server::Simple::CGI::Environment - una mezcla de HTTP::Server::Simple para proporcionar el protocolo CGI

DESCRIPCIÓN

Esta mezcla abstrae el protocolo CGI de HTTP::Server::Simple::CGI para que sea más fácil proporcionar tus propios manejadores CGI con HTTP::Server::Simple que **no** usen CGI.pm

setup_environment

"setup_environment" generalmente se llama en el accept_hook de la superclase.

Esta rutina en esta subclase limpia el entorno a su estado de inicio.

setup_server_url

Establece la variable de entorno "SERVER_URL".

setup_environment_from_metadata

Este método configura las variables de entorno CGI basándose en varios meta-enlaces, como el protocolo, el nombre del host remoto, la ruta de la solicitud, etc.

Ver la documentación en HTTP::Server::Simple para más detalles.

header

"header" convierte un encabezado HTTP individual en variables de entorno CGI.
