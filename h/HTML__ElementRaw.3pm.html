HTML::ElementRaw(3) Documentación de Perl aportada por el usuario HTML::ElementRaw(3)

NOMBRE

HTML::ElementRaw - Extensión de Perl para HTML::Element(3).

SINOPSIS

use HTML::ElementRaw;
$er = new HTML::ElementRaw;
$text = '<p>Me gustaría que este &nbsp; HTML no se codificara</p>';
$er->push_content($text);
$h = new HTML::Element 'h2';
$h->push_content($er);
# Ahora $text aparecerá como lo escribiste, sin escapar,
# incrustado en el HTML producido por $h.
print $h->as_HTML;

DESCRIPCIÓN

Proporciona una forma de injertar cadenas HTML crudas en tus estructuras de HTML::Element(3). Dado que representan texto crudo, solo pueden ser hojas en tu árbol de elementos HTML. Los únicos métodos que son de utilidad real en este elemento degenerado son push_content() y as_HTML(). El método push_content() simplemente antepondrá el texto proporcionado al contenido actual. Si pasas un HTML::element a push_content, la salida del método as_HTML() de ese elemento se antepondrá.
