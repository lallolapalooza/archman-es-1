Los siguientes encabezados Accept* pueden usarse para describir las preferencias de contenido en una solicitud (Esta descripción es un extracto

editado de

draft-ietf-http-v11-spec-00.ps )

Acce
pt
Este encabezado puede usarse para indicar una lista de rangos de medios que son aceptables como respuesta a la solicitud. El carácter "*" se usa para agrupar tipos de medios en rangos, con "*/*" indicando todos los tipos de medios y "type/*" indicando todos los subtipos de ese tipo.

El parámetro q se usa para indicar el factor de calidad, que representa la preferencia del usuario para ese rango de tipos de medios. El parámetro mbx da el tamaño máximo aceptable del contenido de la respuesta. Los valores predeterminados son: q=1 y mbx=infinity. Si no hay encabezado Accept presente, el cliente acepta todos los tipos de medios con

q=1.

Por

ejemplo:

audio/basic
