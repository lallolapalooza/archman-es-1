DESCRIPCIÓ

N

El "HTML::TokeParser" es una interfaz alternativa a la clase "HTML::Parser". Es una subclase de "HTML::PullParser" con un conjunto predeclarado de tipos de tokens. Si desea que los tokens se informen de manera diferente, probablemente quiera usar "HTML::PullParser" di

rectamente.

Los siguientes métodos están

disponibles:
$p = HTML::TokeParser->new( $filename, %opt
);
$p = HTML::TokeParser->new( $filehandle, %opt
);
$p = HTML::TokeParser->new( \$document, %opt
);
El argumento del constructor del objeto es un nombre de archivo, un objeto manejador de archivo o el documento completo a analizar. Se pueden proporcionar opciones adicionales como pares clave/valor y se procesan según lo documentado por las clases base.

Si el argumento es un escalar simple, se toma como el nombre de un archivo para abrir y analizar. Si el archivo no se puede abrir para lectura, el constructor devolverá "undef" y $! le dirá por qué

falló.

Si el argumento es una referencia a un escalar simple, entonces este escalar se toma como el documento literal a analizar. El valor de este escalar no debe cambiarse antes de que se hayan extraído todos los

tokens.

De lo contrario, el argumento se toma como algún objeto del que el "HTML::TokeParser" puede read() cuando necesita más datos. Normalmente será algún tipo de manejador de archivo. El flujo será read() hasta EOF, pero no se

cerrará.

Un "HTML::TokeParser" recién construido difiere de sus clases base al tener el atributo "unbroken_text" habilitado por defecto. Consulte HTML::Parser para una descripción de este y otros atributos que influyen en cómo se analiza el documento. A menudo es una buena idea habilitar el comportamiento "empty_element_tag

s".

Tenga en cuenta que el resultado del análisis probablemente no será válido si se usa UTF-8 sin decodificar como fuente. Al analizar archivos codificados en UTF-8, active la decodificación

UTF-8: 
open(my $fh, "<:utf8", "index.html") || die "Can't open 'index.html': $!";
my $p = HTML::TokeParser->new( $fh );
# ...

Si se pasa un $filename al constructor, el archivo se abrirá en modo crudo y el resultado del análisis solo será válido si su contenido es Latin-1 o ASCII

puro.

Si analiza desde un búfer de cadena codificado en UTF-8, decódifíquelo

primero: 
utf8::decode($document);
my $p = HTML::TokeParser->new( \$document );
#

$p->
get_token
Este método devolverá el siguiente token encontrado en el documento HTML, o "undef" al final del documento. El token se devuelve como una referencia a un array. El primer elemento del array será una cadena que denota el tipo de este token: "S" para etiqueta de inicio, "E" para etiqueta de fin, "T" para texto, "C" para comentario, "D" para declaración y "PI" para instrucciones de proceso. El resto del array de tokens depende del tipo de esta manera: 
["S",  $tag, $attr, $attrseq, $text]
["E",  $tag, $text]
["T",  $text, $is_data]
["C",  $text]
["D",  $text]
["PI", $token0,
$text]

donde $attr es una referencia a un hash, $attrseq es una referencia a un array y el resto son escalar

es simples. "Argspec" en HTML::Pa
rser explica los detalles.
$p->unget_token( @tokens
)
Si encuentra que ha leído demasiados tokens, puede devolverlos para que se devuelvan la próxima vez que se llame a $p->get_t
oken.

get_tag
$p->get_tag( @tags
)
Este método devuelve la siguiente etiqueta de inicio o fin (omitindo cualquier otro token), o "undef" si no hay más etiquetas en el documento. Si se dan uno o más argumentos, omitimos tokens hasta que se encuentre uno de los tipos de etiqueta especificados. Por ejemplo: 
$p->get_tag("font", "/font")
;

encontrará la siguiente etiqueta de inicio o fin para un elemento

font.

La información de la etiqueta se devuelve como una referencia a un array de la misma forma que para $p->get_token anterior, pero el código de tipo (primer elemento) falta. Una etiqueta de inicio se

devolverá así: 
[$tag, $attr, $attrseq,
$text]

El nombre de la etiqueta de las etiquetas de fin tiene como prefijo "/", es decir, la etiqueta de fin se

devuelve así: 
["/$t
ag", $
text]
$p->
get_text
$p->get_text( @endtags
)
Este método devuelve todo el texto encontrado en la posición actual. Devolverá una cadena de longitud cero si el siguiente token no es texto. Cualquier entidad se convertirá a su carácter correspondiente.

Si se dan uno o más argumentos, devolvemos todo el texto que aparece antes de la primera de las etiquetas especificadas encontradas.

Por ejemplo: 
$p->get_text("p",
"br");

devolverá el texto hasta un elemento de párrafo o de salto de

línea.

El texto puede abarcar etiquetas que deberían convertirse en texto. Esto está controlado por el atributo $p->{textify}, que es un hash que define cómo ciertas etiquetas pueden tratarse como texto. Si el nombre de una etiqueta de inicio coincide con una clave en este hash, entonces esta etiqueta se convierte en texto. El valor del hash se usa para especificar qué atributo de la etiqueta obtener el texto. Si este atributo de la etiqueta falta, se devuelve el nombre de la etiqueta en mayúsculas entre corchetes, por ejemplo, "[IMG]". El valor del hash también puede ser una referencia a una subrutina. En este caso, la rutina se llama con el contenido del token de la etiqueta de inicio como su argumento y el valor de retorno se trata como el

texto.

El valor por defecto de $p->{textify}

es: 
{img => "alt", applet =>
"alt"}

Esto significa que las etiquetas <IMG> y <APPL

ET> se tratan como texto, y que el texto a su
stituir se puede encontrar en el atributo ALT.

get_trimmed_text
$p->get_trimmed_text( @endtags
)
Igual que $p->get_text anterior, pero colapsará cualquier secuencia de espacios en blanco en un solo carácter de espacio. Se elimina el espacio en blanco inicial y
final.
$p->
get_phrase
Esto devolverá todo el texto encontrado en la posición actual ignorando cualquier etiqueta de nivel fraseal. El texto se extrae hasta la primera etiqueta que no sea de nivel fraseal. La conversión de etiquetas a texto es la misma que para get_text(). Este método colapsará el espacio en blanco de la misma manera que get_trimmed_text() lo hace.

La definición de

<i>etiquetas de n
ivel fraseal</i> s
e obtiene del mód
ulo HTML::Tagset.

EJEMPLO

S

Este ejemplo extrae todos los enlaces de un documento. Imprimirá una línea por cada enlace, que contiene la URL y la descripción textual entre las etiquetas <A>...</A>

: 
use HTML::TokeParser;
$p = HTML::TokeParser->new(shift||"index.html");
while (my $token = $p->get_tag("a")) {
    my $url = $token->[1]{href} || "-";
    my $text = $p->get_trimmed_text("/a");
    print "$url\t$text\n";
}

Este ejemplo extrae el <TITLE> del

documento: 
use HTML::TokeParser;
$p = HTML::TokeParser->new(shift||"index.html");
if ($p->get_tag("title")) {
    my $title = $p->get_trimmed_text;
    print "Title: $title\n";
}
