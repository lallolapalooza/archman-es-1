El último enfoque, usando HTML::TreeBuilder, es el opuesto diametral del primer enfoque: El primer enfoque implica solo Perl elemental y una expresión regular, mientras que el enfoque de TreeBuilder implica estar en casa con el concepto de estructuras de datos con forma de árbol y módulos con interfaces orientadas a objetos, así como con las interfaces particulares que proporcionan HTML::TreeBuilder y HTML::

Sin embargo, lo que el enfoque de TreeBuilder tiene a su favor es que es el más robusto, porque implica lidiar con HTML en su formato "nativo": lida con la estructura de árbol que representa el código HTML, sin ninguna consideración de cómo está codificada la fuente y con qué etiquetas

omitidas.

Así, para extraer el texto de los elementos "h1" de un documento

sub get_heading {
  my $tree = HTML::TreeBuilder->new;
  $tree->parse_file($_[0]);   # ¡!
  my $heading;
  my $h1 = $tree->look_down('_tag', 'h1');  # ¡!
  if($h1) {
    $heading = $h1->as_text;   # ¡!
  } else {
    warn "No heading in $_[0]?";
  }
  $tree->delete; # ¡liberar memoria!
  return $heading;
}

Esto usa algunos métodos no familiares que necesitan explicación. El método "parse_file" que hemos visto antes, construye un árbol basado en la fuente del archivo dado. El método "delete" sirve para marcar el contenido de un árbol como disponible para la recolección de basura, cuando ha terminado con el árbol. Por último, pero no menos importante, el método más importante en nuestro sub "get_heading" es el método "look_down". Este método mira hacia abajo el subárbol que comienza en el objeto dado ($h1), buscando elementos que cumplan los criterios que

proporcione.

Los criterios se especifican en la lista de argumentos del método. Cada criterio puede consistir en dos escalares, una clave y un valor, que expresan que quiere elementos que tengan ese atributo (como "_tag", o "src") con el valor dado ("h1"); o el criterio puede ser una referencia a una subrutina que, cuando se llama en el elemento dado, devuelve verdadero si ese es el nodo que está buscando. Si especifica varios criterios, entonces eso se entiende que quiere todos los elementos que satisfagan cada todos los criterios. (En otras palabras, hay un "Y implícito".

)

Y finalmente, hay un poco de optimización: si llama al método "look_down" en un contexto escalar, obtiene solo el primer nodo (o undef si no hay ninguno); y, de hecho, una vez que "look_down" encuentra ese primer elemento coincidente, no se molesta en buscar

más.

Así que el

;

devuelve el primer elemento en o debajo de $tree cuyo atributo "_tag" tiene el valor "h

Dado que los banners publicitarios siempre le suplican que "visite" el sitio patrocinador, podría excluir los elementos "h1" que contienen la palabra "visit" debajo de

ellos:

El primer criterio busca elementos "h1", y el segundo criterio limita esos a solo aquellos cuyo contenido de texto no coincide con "m/\bvisit/". Pero desafortunadamente, eso no funcionará para nuestro ejemplo, ya que el segundo "h1" menciona "ConGlomCo President Schreck to Visit Regional

En su lugar, podría intentar buscar el primer elemento "h1" que no contenga una

Tenga en cuenta que cuando se considera como un valor booleano, un valor de "look_down" en un contexto escalar devuelve falso (específicamente, undef) si no hay un elemento coincidente en o debajo del elemento dado; y devuelve el primer elemento coincidente (que, al ser una referencia y un objeto, es siempre un valor verdadero), si hay alguna coincidencia. aquí,

"

quiere.

use strict;
use HTML::TreeBuilder 2.97;
use LWP::UserAgent;
sub get_headlines {
  my $url = $_[0] || die "What URL?";

  my $response = LWP::UserAgent->new->request(
    HTTP::Request->new( GET => $url )
  );
  unless($response->is_success) {
    warn "Couldn't get $url: ", $response->status_line, "\n";
    return;
  }

  my $tree = HTML::TreeBuilder->new();
  $tree->parse($response->content);
  $tree->eof;

  my @out;
  foreach my $link (
    $tree->look_down(   # !
      '_tag', 'a',
      sub {
        return unless $_[0]->attr('href');
        my @c = $_[0]->content_list;
        @c == 1 and ref $c[0] and $c[0]->tag eq 'b';
      }
    )
  ) {
    push @out, [ $link->attr('href'), $link->as_text ];
  }

  warn "Odd, fewer than 6 stories in $url!" if @out < 6;
  $tree->delete;
  return @out;
}
