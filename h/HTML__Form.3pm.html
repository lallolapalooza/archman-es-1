ENTRADA

S

Un objeto "HTML::Form" contiene una secuencia de entradas. Se pueden obtener referencias a las entradas con los métodos $form->inputs o $form->find_

input.

Tenga en cuenta que no hay una correspondencia uno a uno entre objetos de entrada y elementos <input> en el documento HTML. Un objeto de entrada representa básicamente un par nombre/valor, por lo que cuando múltiples elementos HTML contribuyen al mismo par nombre/valor en el formulario enviado, se

combinan.

Los elementos de entrada que se asignan uno a uno son "text", "textarea", "password", "hidden", "file", "image", "submit" y "checkbox". Para las entradas "radio" y "option" la historia no es tan simple: Todos los elementos <input type="radio"> con el mismo nombre contribuirán al mismo objeto de entrada radio. El número de objetos de entrada radio será el mismo que el número de nombres distintos usados para los elementos <input type="radio">. Para un elemento <select> sin el atributo "multiple" habrá un objeto de entrada de tipo "option". Para un elemento <select multiple> habrá un objeto de entrada por cada elemento <option> contenido. Cada uno de estos objetos de opción tendrá el mismo

nombre.
