NOMBRE

HTML::Filter - Filtrar texto HTML a través del analizador

NOTA

Este módulo está obsoleto. El módulo "HTML::Parser" ahora proporciona la funcionalidad de "HTML::Filter" de manera mucho más eficiente con el manejador "default".

SINOPSIS

require HTML::Filter;
$p = HTML::Filter->new->parse_file("index.html");

DESCRIPCIÓN

"HTML::Filter" es un analizador HTML que por defecto imprime el texto original de cada elemento HTML (una versión lenta de cat(1), básicamente). Los métodos de devolución de llamada pueden ser sobrescritos para modificar el filtrado de algunos elementos HTML y puede sobrescribir el método output() que se llama para imprimir el texto HTML.

"HTML::Filter" es una subclase de "HTML::Parser". Esto significa que el documento debe ser proporcionado al analizador llamando a los métodos $p->parse() o $p->parse_file().

EJEMPLOS

El primer ejemplo es un filtro que eliminará todos los comentarios de un archivo HTML. Esto se logra simplemente sobrescribiendo el método de comentario para que no haga nada.

package CommentStripper;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub comment { }  # ignorar comentarios

El segundo ejemplo muestra un filtro que eliminará cualquier <TABLE> encontrado en el archivo HTML. Especializamos los métodos start() y end() para contar las etiquetas de tabla y luego evitamos la salida cuando estamos dentro de una tabla.

package TableStripper;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub start
{
   my $self = shift;
   $self->{table_seen}++ if $_[0] eq "table";
   $self->SUPER::start(@_);
}
sub end
{
   my $self = shift;
   $self->SUPER::end(@_);
   $self->{table_seen}-- if $_[0] eq "table";
}
sub output
{
    my $self = shift;
    unless ($self->{table_seen}) {
        $self->SUPER::output(@_);
    }
}

Si desea recopilar el texto analizado internamente, puede hacer algo como esto:

package FilterIntoString;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub output { push(@{$_[0]->{fhtml}}, $_[1]) }
sub filtered_html { join("", @{$_[0]->{fhtml}}) }
