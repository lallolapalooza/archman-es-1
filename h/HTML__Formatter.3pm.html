DESCRIPCIÓ

N

HTML::Formatter es una clase base para clases que toman HTML y lo formatean a algún formato de salida. Cuando tomas un objeto de una de estas clases base y llamas a "$formatter-"format( $tree )> con un objeto HTML::TreeBuilder (o HTML::Element), devuelven la cadena formateada apropiadamente para el HTML de

entrada.

Los formateadores HTML son capaces de formatear un árbol de sintaxis HTML en varios formatos imprimibles. Diferentes formateadores producen salida para diferentes medios de salida. Lo común a todos los formateadores es que devolverán la salida formateada cuando se llama al método format(). El método format() toma un objeto HTML::Element (usualmente el objeto raíz de HTML::TreeBuilder) como

parámetro.

NOMBRE DE LA

DISTRIBUCIÓN

Este módulo fue originalmente nombrado "HTML-Format" a pesar de no contener un módulo "HTML::Format" dentro de él. Como las reglas sobre la nomenclatura han sido tomadas más en serio, y la cadena de herramientas de PAUSE https://pause.perl.org/ adaptada de modo que obtener el índice de la distribución fuera más difícil, se volvió obvio que debería renombrar la distribución a "HTML-Formatter" coincidiendo con el módulo base HTML::

Formatter.

A partir de la versión 2.13 esto se publica como la distribución "HTML-Formatter" con cambios correspondientes en el nombre del repositorio git y elementos

asociados.

Debido a la forma en que el módulo está construido, esto no debería tene

r ningún efecto en el código que usa el módulo. Los únicos problemas ser
án donde el nombre de la distribución se usó dentro de las dependencias.
