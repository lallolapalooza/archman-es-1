INFINITY(3) Manual de funciones de la biblioteca INFINITY(3)

NOMBRE

INFINITY, NAN, HUGE_VAL, HUGE_VALF, HUGE_VALL — constantes de punto flotante

BIBLIOTECA

Biblioteca matemática (libm)

SINOPSIS

#define _ISOC99_SOURCE      /* Véase feature_test_macros(7) */
#include <math.h>
INFINITY
NAN
HUGE_VAL
HUGE_VALF
HUGE_VALL

DESCRIPCION

La macro INFINITY se expande a una constante de tipo float que representa el infinito positivo.

La macro NAN se expande a una constante de tipo float que representa un NaN silencioso (cuando es compatible). Un NaN silencioso es un NaN ("not-a-number" o "no es un número") que no genera excepciones cuando se usa en aritmética. Lo opuesto es un NaN señalizante. Véase IEC 60559:1989.

Las macros HUGE_VAL, HUGE_VALF, HUGE_VALL se expanden a constantes de tipos double, float y long double, respectivamente, que representan un valor positivo grande, posiblemente infinito positivo.

ESTANDARES

C11.

HISTORIA

C99.

En un sistema glibc, la macro HUGE_VAL siempre está disponible. La disponibilidad de la macro NAN se puede probar usando #ifdef NAN, y de manera similar para INFINITY, HUGE_VALF, HUGE_VALL. Estas serán definidas por <math.h> si se define _ISOC99_SOURCE o _GNU_SOURCE, o si se define __STDC_VERSION__ y tiene un valor no menor que 199901L.

VER TAMBIÉN

fpclassify(3), math_error(7)
