NOMBRE

HTML::Template::Expr - Extensión de HTML::Template que añade soporte de expresiones

SINOPSIS

use HTML::Template::Expr;
my $template = HTML::Template::Expr->new(filename => 'foo.tmpl');
$template->param(banana_count => 10);
print $template->output();

DESCRIPCIÓN

Este módulo proporciona una extensión para HTML::Template que permite usar expresiones en la sintaxis de la plantilla. Esto es puramente una adición: todas las opciones, sintaxis y comportamientos normales de HTML::Template seguirán funcionando. Consulte HTML::Template para más detalles.

El soporte de expresiones incluye comparaciones, operaciones matemáticas, operaciones de cadenas y un mecanismo que le permite añadir sus propias funciones en tiempo de ejecución. La sintaxis básica es:

<TMPL_IF EXPR="banana_count > 10">
  Tengo muchas bananas.
</TMPL_IF>

Esto mostrará "Tengo muchas bananas" si llama a:

$template->param(banana_count => 100);

En su script. Los <TMPL_VAR> también funcionan con expresiones:

Me gustaría tener <TMPL_VAR EXPR="banana_count * 2"> bananas.

Esto mostrará "Me gustaría tener 200 bananas." con la misma param() llamada que arriba.

MOTIVACIÓN

Algunos de ustedes pueden preguntarse si me han reemplazado por una persona pod. Solo para constatar, sigo pensando que este tipo de cosas debería evitarse. Sin embargo, me doy cuenta de que hay algunas situaciones donde permitir al autor de la plantilla cierta libertad programática puede ser inestimable.

Si no le gusta, no use este módulo. Siga usando el viejo y bueno HTML::Template ¡yo sé que lo haré! Sin embargo, si se encuentra necesitando un poco de programación en su plantilla, por la razón que sea, entonces este módulo puede salvarlo de HTML::Mason.

SINTAXIS BÁSICA

Las variables son cadenas alfanuméricas sin comillas con las mismas restricciones que los nombres de variables en HTML::Template. Sus valores se establecen a través de param(), igual que las variables normales de HTML::Template. Por ejemplo, estas dos líneas son equivalentes:

<TMPL_VAR EXPR="foo">

<TMPL_VAR NAME="foo">

Los números son cadenas sin comillas de números y pueden tener un solo "." para indicar un número de punto flotante. Por ejemplo:

<TMPL_VAR EXPR="10 + 20.5">

Las constantes de cadena deben estar entre comillas, simples o dobles. Por ejemplo:

<TMPL_VAR EXPR="sprintf('%d', foo)">

Puede encadenar operadores para producir booleanos complejos:

<TMPL_IF EXPR="(foo || bar || baz || (bif && bing) || (bananas > 10))">
    Estoy en una situación compleja.
</TMPL_IF>

El analizador es bastante simple, por lo que puede necesitar usar paréntesis para obtener la precedencia deseada.

Todas las funciones deben ser llamadas usando paréntesis completos. Por ejemplo, esto es un error de sintaxis:

<TMPL_IF expr="defined foo">

Pero esto está bien:

<TMPL_IF expr="defined(foo)">

DEFINIR NUEVAS FUNCIONES

Para definir una nueva función, pase una opción "functions" a new:

$t = HTML::Template::Expr->new(filename => 'foo.tmpl',
                               functions => 
                                 { func_name => \&func_handler });

O, puede usar el método de clase "register_function" para registrar la función globalmente:

HTML::Template::Expr->register_function(func_name => \&func_handler);

Usted proporciona una referencia a un subrutina que será llamada durante la salida. Recibirá como argumentos los parámetros especificados en la plantilla. Por ejemplo, aquí hay una función que verifica si un directorio existe:

sub directory_exists {
  my $dir_name = shift;
  return 1 if -d $dir_name;
  return 0;
}

Si llama a HTML::Template::Expr->new() con un argumento "functions" :

$t = HTML::Template::Expr->new(filename => 'foo.tmpl',
                               functions => {
                                  directory_exists => \&directory_exists
                               });

Entonces puede usarla en su plantilla:

<tmpl_if expr="directory_exists('/home/sam')">

Esto puede ser abusado de maneras que me hacen rechinar los dientes.

CONSEJO PARA MOD_PERL

El método de clase "register_function"

puede ser llamado en el startup.pl de mod_perl para definir funciones comunes de uso amplio en HTML::Template::Expr. Añada algo como esto a su startup.pl:

use HTML::Template::Expr; HTML::Template::Expr->register_function(foozicate => sub { ... }); HTML::Template::Expr->register_function(barify => sub { ... }); HTML::Template::Expr->register_function(baznate => sub { ... });

También podría querer pre-compilar algunas plantillas de uso común y almacenarlas en caché. Consulte el FAQ de HTML::Template para instrucciones.

ADVERTENCIAS

Actualmente el módulo fuerza la opción global_vars de HTML::Template a estar activada. Esto desaparecerá en una versión futura, por lo que si necesita global_vars en sus plantillas, debería establecerlo explícitamente.

El módulo no funcionará con los modos file_cache o shared_cache de HTML::Template, pero el almacenamiento en caché normal en memoria debería funcionar. Espero abordar esto en una versión futura.

El módulo es ineficiente, tanto en el análisis como en la evaluación. Trabajaré en esto para versiones futuras y los parches siempre son bienvenidos.
