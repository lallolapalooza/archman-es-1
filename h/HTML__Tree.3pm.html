HTML-Tree es un conjunto de módulos de Perl para crear árboles de análisis a partir de código fuente HTML. Consiste principalmente en dos módulos, cuya documentación debería consultar: HTML::

TreeBuilder y HTML::Element.

HTML::TreeBuilder es el módulo que construye los á

rboles de análisis. (Utiliza HTML::Parser para
realizar el trabajo de dividir el HTML en tokens.)

El árbol que TreeBuilder construye para usted está compuesto por objetos de la clase HTML:

:Element.
