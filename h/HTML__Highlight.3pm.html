MOTIVACIÓ

N

Este módulo fue creado originalmente para funcionar junto con el módulo de indexación de texto completo DBIx::TextIndex para resaltar los resultados de

búsqueda.

La necesidad de un resaltador que tenga en cuenta las coincidencias

con comodines y las etiquetas HTML, y que admita el idioma checo (
u otros idiomas eslavos), fue la motivación para crear este módulo.

DESCRIPCIÓ

N

Este módulo proporciona un resaltado tipo Google de palabras o patrones en documentos HTML. Esta característica se utiliza típicamente para resaltar los resultados de

búsqueda.
El
constructor: 
my $hl = new HTML::Highlight (
        words => [],
        wildcards => [],
        colors => [],
        czech_language => 0,
        debug =>
0 );

Este es el constructor del objeto resaltador. Recibe un número par de

parámetros.

El parámetro words es una referencia a un array de palabras a

resaltar.

El parámetro wildcards es una referencia a un array de comodines, que se aplican a las palabras correspondientes en el array words

.

Un comodín puede ser undef o uno de '%' o

'*'.

El carácter "%" significa "coincidir con cualquier

carácter": 
"%" aplicado a 'car' ==> coincide con "car", "cars", "careful",
...

El carácter "*" significa "coincidir también con la forma plural de la

palabra": 
"*" aplicado a 'car' ==> coincide solo con "car" o
"cars"

Un comodín sin definir significa "coincidir exactamente con la palabra

correspondiente": 
comodín sin definir aplicado a 'car' ==> coincide solo con
"car"

El parámetro colors es una referencia a un array de identificadores de color CSS, que se utilizan para resaltar las palabras correspondientes en el array words

.

Se utilizan colores predeterminados tipo Google si no especificas tus propios colores. El número de colores puede ser menor que el número de palabras; en este caso, los colores se rotan y algunas de las palabras se resaltan por lo tanto usando el mismo

color.

El resaltador tiene en cuenta las etiquetas HTML y por lo tanto no "resalta" una palabra o un patrón dentro de una

etiqueta.

Se puede activar una función de coincidencia insensible a los diacríticos para los idiomas ISO-8859-2 (por ejemplo, el idioma checo) usando la opción czech_language. Esta característica requiere un módulo CzFast que está disponible en CPAN en el directorio del autor TRIPIE o en http://geocities.com/

tripiecz/.

Las configuraciones de locales de tu sistema deben estar configuradas correctamente para usar la caracterís

tica czech
_language.

El único parámetro es un documento en el que quieres resaltar las palab

ras que se pasaron al constructor del objeto resaltador. El método devu

preview_cont
ext 
my $sections = $hl->preview_context($document,
$num);

Este método toma dos parámetros. El primero es el documento que quieres escanear en busca de las palabras que se pasaron al constructor del objeto resaltador. El segundo parámetro es un entero opcional que especifica el número máximo de caracteres en cada una de las secciones de contexto (ver abajo). Este parámetro tiene un valor predeterminado de 80 caracteres si no se especifica. El valor mínimo permitido de este parámetro

es 60.

El método devuelve una referencia a un array de secciones del documento en las que aparecen las palabras que se pasaron al constructor. Las

etiquetas HTML se eliminan antes de que se procese el documento y no están presentes en la salida. Esta característica se utiliza típicamente en los
motores de búsqueda para previsualizar el contexto en el que aparecen las palabras de una consulta de búsqueda en los documentos resultante
s. Las palabras siempre están en el medio de cada una de las secciones. El número de secciones que devuelve este método es igual al número d
e palabras pasadas al constructor del objeto resaltador. Eso significa que solo se tiene en cuenta la primera aparición de cada una de las palabras.
