NOMBRE

HTML::ElementSuper - Extensión de Perl para HTML::Element(3)

SINOPSIS

use HTML::ElementSuper;
### Extensión posicional
$e = new HTML::ElementSuper 'font';
$sibling_number = $e->addr();
$e2 = new HTML::ElementSuper 'p';
$e2->push_content($e);
# 
@coords = $e->position();
$depth_in_pos_tree = $e->depth();
### Extensión reemplazadora
$er = new HTML::ElementSuper 'font';
# El árbol bajo $er, si existe, se descarta.
$er->replace_content(new HTML::Element 'p');
### Extensión envolvente
$ew = new HTML::ElementSuper;
$ew->push_content("Tickle me, baby");
$ew->wrap_content(new HTML::Element 'font', color => 'pink');
print $ew->as_HTML();
### Extensión enmascarable
$em = new HTML::ElementSuper 'td';
$em->mask(1);
print $em->as_HTML; # nada
$em->mask(0);
print $em->as_HTML; # $e y sus hijos son visibles
### Clonación de su propio árbol o del árbol de otro elemento
### (¿es esta la nomenclatura correcta? :-)
$a = new HTML::ElementSuper 'font', size => 2;
$b = new HTML::ElementSuper 'font', color => 'red';
$a_clone  = $a->clone;
$b_clone = $a->clone($b);
# Se pueden clonar múltiples elementos
@clone_clones = $a_clone->clone($a_clone, $b_clone);

DESCRIPCIÓN

HTML::ElementSuper es una extensión para HTML::Element(3) que proporciona varios métodos nuevos para ayudar en la manipulación de elementos. Un HTML::ElementSuper tiene las siguientes propiedades adicionales:

* informar su posición de coordenadas en un árbol de sus pares
* reemplazar su contenido
* envolver su contenido en un nuevo elemento
* enmascararse a sí mismo para que él y sus descendientes sean invisibles para
  traverse()
* clonarse a sí mismo y a otros árboles de objetos basados en HTML::Element
* manejar múltiples valores para atributos

Tenga en cuenta que estas extensiones fueron desarrolladas originalmente para ayudar en la implementación de la clase HTML::ElementTable(3) , pero se consideró que eran lo suficientemente útiles en general como para merecer su propio paquete.

MÉTODOS

new('tag', attr => 'value', ...)
Devuelve un nuevo objeto HTML::ElementSuper. Exactamente igual que el constructor para HTML::Element(3), toma un tipo de etiqueta y atributos opcionales.
push_attr(attr => @values)
Extiende la cadena de valor para un atributo particular. Un ejemplo de esto podría ser cuando desee asignar múltiples clases CSS a un solo elemento. El valor del atributo se extiende usando espacio en blanco como separador.
addr()
Devuelve la posición de este elemento en relación con sus hermanos basándose en el contenido del padre, empezando con 0. Devuelve undef si este elemento no tiene padre. En otras palabras, devuelve el índice de este elemento en el arreglo de contenido del padre.
position()
Devuelve las coordenadas de este elemento en el árbol que habita. Esto se logra llamando sucesivamente a addr() en los elementos ascendientes hasta que se encuentre a) un elemento que no soporte estos métodos, o b) no haya más padres. La lista resultante son las coordenadas n-dimensionales del elemento en el árbol.
replace_content(@new_content)
Método de atajo simple que elimina el contenido actual del elemento antes de añadir el nuevo.
wrap_content($wrapper_element)
Envuelve el contenido existente en el elemento proporcionado. Si el elemento proporcionado resulta ser un no-elemento, se realiza un push_content en su lugar.
mask
mask(mode)
Alterna si este elemento es visible o no para los métodos parentales que visitan el árbol de elementos usando traverse(), como as_HTML(). Los argumentos válidos para mask() son 0 y 1. Devuelve la configuración actual sin argumento.

Esto puede parecer un método extraño de tener, pero ayuda en la gestión de estructuras de árbol dinámicas. Por ejemplo, en HTML::ElementTable(3), cuando expande una celda de tabla simplemente enmascara lo que cubre en lugar de destruirlo. Al reducir la celda de la tabla se revela ese contenido a as_HTML() una vez más.

clone
clone(@elements)
Devuelve un clon de los elementos y todos sus descendientes. Sin argumentos, el elemento se clona a sí mismo, de lo contrario clona los elementos proporcionados como argumentos. Cualquier elemento puede ser clonado siempre que esté basado en HTML::Element(3) . Este método es muy útil para duplicar estructuras de árbol ya que un HTML::Element no puede tener más de un padre en ningún momento... de ahí "árbol".
