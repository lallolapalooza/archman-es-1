Licencias: GPL, PerlArtistic

HTML::AsSubs(3pm) Documentación Perl contribuida por el usuario HTML::AsSubs(3pm)

NOMBRE

HTML::AsSubs - funciones que construyen un árbol de sintaxis HTML

VERSIÓN

Este documento describe la versión 5.07 de HTML::AsSubs, publicada el 31 de agosto de 2017 como parte de HTML-Tree.

SINOPSIS

use HTML::AsSubs;
$h = body(
          h1("Esta es la cabecera"),
          p("Este es el primer párrafo que contiene un ",
            a({href=>'link.html'}, "enlace"),
            " y una ",
            img({src=>'img.gif', alt=>'imagen'}),
            "."
           ),
         );
print $h->as_HTML;

DESCRIPCIÓN

Este módulo exporta funciones que pueden ser utilizadas para construir varios elementos HTML. Las funciones tienen el mismo nombre que las etiquetas del elemento HTML correspondiente y están todas en minúsculas. Si el primer argumento es una referencia a un hash, se usará para inicializar los atributos de este elemento. Los argumentos restantes se consideran contenido.

Para una idea similar (es decir, es otro caso donde el árbol de sintaxis de la fuente de Perl refleja el árbol de sintaxis del HTML producido), ver el método "new_from_lol" de HTML::Element.

Para lo que ahora considero una implementación más limpia de esta misma idea, ver el excelente módulo "XML::Generator", que es lo que sugiero para uso en la vida real. (Sugiero esto por encima de "HTML::AsSubs" y de las funciones de creación de HTML de "CGI.pm".)

ERRORES

La función exportada link() anula la función incorporada link(). La función exportada tr() debe ser llamada usando la sintaxis &tr(...) porque entra en conflicto con el operador incorporado tr/../../.

Funciones Privadas

_elem()

La función _elem() está envuelta por todas las funciones de 'etiqueta' de html. Toma un nombre de etiqueta, un hashref opcional de atributos y una lista de contenido como parámetros.
