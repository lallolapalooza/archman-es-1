HTTP__Cookies__Microsoft(3pm)

Paquete: perl-http-cookies

Licencias: PerlArtistic, GPL

HTTP::Cookies::Microsoft(3) Documentación de Perl aportada por el usuario HTTP::Cookies::Microsoft(3)

NOMBRE

HTTP::Cookies::Microsoft - Acceso a archivos de cookies de Microsoft

VERSIÓN

versión 6.11

SINOPSIS

use LWP;
use HTTP::Cookies::Microsoft;
use Win32::TieRegistry(Delimiter => "/");
my $cookies_dir = $Registry->
     {"CUser/Software/Microsoft/Windows/CurrentVersion/Explorer/Shell Folders/Cookies"};
$cookie_jar = HTTP::Cookies::Microsoft->new(
                  file     => "$cookies_dir\\index.dat",
                  'delayload' => 1,
              );
my $browser = LWP::UserAgent->new;
$browser->cookie_jar( $cookie_jar );

DESCRIPCIÓN

Esta es una subclase de "HTTP::Cookies" que carga los archivos de cookies de Microsoft Internet Explorer 5.x y 6.x para Windows (MSIE).

Consulte la documentación de HTTP::Cookies.

MÉTODOS

Se proporcionan los siguientes métodos:

$cookie_jar = HTTP::Cookies::Microsoft->new;
El constructor acepta parámetros de estilo hash. Además de los parámetros regulares de HTTP::Cookies, HTTP::Cookies::Microsoft reconoce los siguientes: 
delayload:       retrasar la carga de datos de cookies hasta que se
                 realice una solicitud. Esto resulta en un tiempo
                 de ejecución más rápido a menos que se utilicen la
                 mayoría de las cookies, ya que solo los datos de cookies
                 del dominio se cargan bajo demanda.

ADVERTENCIAS

Tenga en cuenta que el código NO soporta guardar en el formato de archivo de cookies de MSIE.
