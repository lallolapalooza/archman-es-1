VERSIÓN

Este documento describe la versión 5.07 de HTML::Parse, publicada el 31 de agosto de 2017 como parte de HTML-Tree.

SINOPSIS

Ver la documentación de HTML::TreeBuilder

DESCRIPCIÓN

Descargo de responsabilidad: Este módulo se proporciona solo para compatibilidad con versiones anteriores de esta biblioteca. El código nuevo no debería usar este módulo y realmente debería usar los módulos HTML::Parser y HTML::TreeBuilder directamente.

El módulo "HTML::Parse" proporciona funciones para analizar documentos HTML. Hay dos funciones exportadas por este módulo:

parse_html($html) o parse_html($html, $obj)
Esta función es realmente solo un sinónimo de $obj->parse($html) y se asume que $obj es una subclase de "HTML::Parser". Consulte HTML::Parser para obtener más documentación.

Si no se especifica $obj, $obj será por defecto un nuevo objeto "HTML::TreeBuilder" creado internamente y configurado con strict_comment() activado. Esa clase implementa un analizador que construye (y es) un árbol de sintaxis HTML con objetos HTML::Element como nodos.

El valor de retorno de parse_html() es $obj.

parse_htmlfile($file, [$obj])
Igual que parse_html(), pero extrae el HTML para analizarlo del archivo especificado.

Devuelve "undef" si el archivo no se pudo abrir, o $obj en caso contrario.

Cuando se crea un objeto "HTML::TreeBuilder", las siguientes variables controlan cómo se realiza el análisis:

$HTML::Parse::IMPLICIT_TAGS
Establecer esta variable en verdadero instruirá al analizador a intentar deducir elementos implícitos y etiquetas de cierre implícitas. Si esta variable es falsa, obtendrá un árbol de análisis que solo refleja el texto tal como está. Podría ser útil para análisis rápidos y sucios. El valor predeterminado es verdadero.

Los elementos implícitos tienen el atributo implicit() establecido.

$HTML::Parse::IGNORE_UNKNOWN
Esta variable controla si las etiquetas desconocidas deben representarse como elementos en el árbol de análisis. El valor predeterminado es verdadero.
$HTML::Parse::IGNORE_TEXT
No representar el contenido de texto de los elementos. Esto ahorra espacio si todo lo que desea es examinar la estructura del documento. El valor predeterminado es falso.
$HTML::Parse::WARN
Llamar a warn() con un mensaje apropiado para errores de sintaxis. El valor predeterminado es falso.

¡RECUERDA!

Los objetos HTML::TreeBuilder deben ser destruidos explícitamente cuando haya terminado con ellos. Consulte HTML::TreeBuilder.
