NOMBRE

HTML::LinkExtor - Extrae enlaces de un documento HTML

SINOPSIS

require HTML::LinkExtor;
$p = HTML::LinkExtor->new(\&cb, "http://www.perl.org/");
sub cb {
    my($tag, %links) = @_;
    print "$tag @{[%links]}\n";
}
$p->parse_file("index.html");

DESCRIPCIÓN

HTML::LinkExtor es un analizador HTML que extrae enlaces de un documento HTML. HTML::LinkExtor es una subclase de HTML::Parser. Esto significa que el documento se debe pasar al analizador llamando a los métodos $p->parse() o $p->parse_file().

$p = HTML::LinkExtor->new
$p = HTML::LinkExtor->new( $callback )
$p = HTML::LinkExtor->new( $callback, $base )
El constructor toma dos argumentos opcionales. El primero es una referencia a una rutina de devolución de llamada. Se llamará a medida que se encuentren enlaces. Si no se proporciona una devolución de llamada, los enlaces simplemente se acumulan internamente y se pueden recuperar llamando al método $p->links().

$base es una URL base opcional utilizada para absolutizar todas las URL encontradas. Necesita tener el módulo URI instalado si proporciona $base.

La devolución de llamada se llama con el nombre de etiqueta en minúsculas como primer argumento, y luego todos los atributos de enlace como pares clave/valor separados. Todos los atributos que no sean de enlace se eliminan.

$p->links
Devuelve una lista de todos los enlaces encontrados en el documento. Los valores devueltos serán matrices anónimas con los siguientes elementos: 
[$tag, $attr => $url1, $attr2 => $url2,...]

El método $p->links también truncará la lista de enlaces interna. Esto significa que si se llama al método dos veces sin ningún análisis entre ellas, la segunda llamada devolverá una lista vacía.

Tenga en cuenta también que $p->links siempre estará vacío si se proporcionó una rutina de devolución de llamada cuando se creó el HTML::LinkExtor.

EJEMPLO

Este es un ejemplo que muestra cómo puede extraer enlaces de un documento recibido usando LWP:

use LWP::UserAgent;
use HTML::LinkExtor;
use URI::URL
$url = "http://www.perl.org/";  # por ejemplo
$ua = LWP::UserAgent->new;
# Configurar una devolución de llamada que recopile enlaces de imágenes
my @imgs = ();
sub callback {
   my($tag, %attr) = @_;
   return if $tag ne 'img';  # solo miramos más de cerca <img ...>
   push(@imgs, values %attr);
}
# Crear el analizador. Desafortunadamente, aún no conocemos la base
# (podría ser diferente de $url)
$p = HTML::LinkExtor->new(\&callback);
# Solicitar el documento y analizarlo a medida que llega
$res = $ua->request(HTTP::Request->new(GET => $url),
                    sub {$p->parse($_[0])});
# Expandir todas las URL de imágenes a absolutas
my $base = $res->base;
@imgs = map { $_ = url($_, $base)->abs; } @imgs;
# Imprimirlas
print join("\n", @imgs), "\n";
