$t->table->push_position;

DESCRIPCIÓ

N

HTML::ElementTable proporciona una estructura altamente mejorada de HTML::ElementSuper con métodos diseñados para man

ipular fácilmente los elementos de una tabla mediante el uso de coordenadas. Los elementos se pueden manipular en
bloque mediante celdas individuales, agrupaciones arbitrarias de celdas, cajas, columnas, filas o la tabla completa.

ACCESO A

ELEMENTOS

A menos que se acceda a un solo elemento, la mayoría del acceso a elementos de la tabla se logra a través de globs, que son colecciones de elementos que se comportan como si fueran un solo objeto de

elemento.

Siempre que sea posible, las operaciones glob se optimizan en el elemento más apropiado. Por ejemplo, si establece un atributo para un glob de fila, el atributo se establecerá ya sea en el elemento <TR> o en los elementos <TD> recopilados, lo que sea

apropiado.

Véase HTML::ElementGlob(3) para más información sobre los globs de

elementos.

NOTAS SOBRE LOS

GLOBS

El globbing era una manera conveniente de tratar colecciones arbitrarias de celdas de tabla como si fueran un solo elemento HTML. Los métodos generalmente se pasan ciega y secuencialmente a los elementos que

contienen.

La mayoría de las veces, esto es bastante intuitivo, como cuando está estableciendo los atributos de las

celdas.

Otras veces, podría ser problemático, como con push_content(). ¿Empuja el mismo objeto a todas las celdas? Las clases basadas en HTML::Element solo admiten un padre, por lo que esto falla si intenta empujar el mismo elemento en múltiples candidatos parentales. En el caso específico de push_content() en globs, los elementos que finalmente se empujan son clones del contenido proporcionado originalmente. Funciona, pero no es necesariamente lo que espera. Un árbol de elementos HTML incestuoso probablemente no es lo que quiere de todos

modos.

Véase HTML::ElementGlob(3) para más detalle

s sobre cómo fu
ncionan los globs.
