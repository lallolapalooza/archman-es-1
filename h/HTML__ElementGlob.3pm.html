NOMBRE

HTML::ElementGlob - Extensión de Perl para gestionar objetos basados en HTML::Element como un único objeto.

SINOPSIS

use HTML::ElementGlob;
$element_a = new HTML::Element 'font', color => 'red';
$element_b = new HTML::Element 'font', color => 'blue';
$element_a->push_content('rojo');
$element_b->push_content('azul');
$p = new HTML::Element 'p';
$p->push_content($element_a, ' y ', $element_b, ' buuuu');
# El tipo de etiqueta del glob no es realmente relevante a menos que
# planees ver el glob as_HTML()
$eglob = new HTML::ElementGlob 'p';
$eglob->glob_push_content($element_a, $element_b);
# Modificar ambos elementos a la vez
$eglob->attr(size => 5);
# Todavía pertenecen a su padre original
print $p->as_HTML;

DESCRIPCIÓN

HTML::ElementGlob es un objeto gestor para múltiples elementos estilo HTML::Element(3). Los hijos del elemento glob conservan sus elementos parentales originales y no tienen conocimiento del glob que los manipula. Todos los métodos que no empiezan con 'glob_' serán pasados, secuencialmente, a todos los elementos contenidos en el elemento glob. Los métodos que empiezan con 'glob_' operarán sobre el glob mismo, en lugar de ser pasados a sus hijos adoptivos.

Por ejemplo, $eglob->attr(size => 3) invocará attr(size => 3) en todos los hijos contenidos por $eglob. $eglob->glob_attr(size => 3), por otro lado, establecerá el atributo attr en el propio glob.

El tipo de etiqueta pasado a HTML::Element::Glob es en gran medida irrelevante en cuanto a cómo se pasan los métodos a los hijos. Sin embargo, si eliges invocar $eglob->as_HTML(), podrías querer elegir una etiqueta que contenga de forma sensata a los hijos agrupados para fines de depuración o visualización.

Los métodos 'glob_*' que operan sobre el propio glob se limitan a los disponibles en un HTML::Element(3). Todos los demás métodos se pasan ciegamente a los hijos agrupados, que pueden ser elementos mejorados con métodos arbitrarios, como HTML::ElementSuper(3).

Los globs de elementos pueden contener otros globs de elementos. En tales casos, los métodos simples se propagarán en cascada hasta los hijos hoja. Los métodos 'glob_*', por supuesto, no se propagarán a los globs hijos. Tendrás que depender de glob_content() para acceder a esos hijos glob y acceder directamente a sus métodos 'glob_*'.
