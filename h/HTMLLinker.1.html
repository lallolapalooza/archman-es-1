NOMBRE

HTMLLinker - herramienta para corregir referencias href en archivos HTML

SINOPSIS

HTMLLinker [opciones] archivos de entrada [ -l archivo de reubicación ] [ -d archivo de destino ]

DESCRIPCIÓN

HTMLLinker es una herramienta para corregir referencias href en archivos HTML, típicamente manuales de referencia API generados al extraer las cadenas de documentación del código fuente por herramientas como autogsdoc(1).

HTMLLinker acepta las siguientes opciones (se permiten múltiples archivos de entrada, opciones -l y -d):

OPCIONES

--help
Imprime una lista corta de opciones disponibles.
--version
Muestra información de la versión.
--verbose
Imprime información adicional mientras procesa.
-Warn [SÍ|NO]
Imprime información adicional sobre enlaces no resueltos.
-LinksMarker [xxx]
Solo corrige enlaces con el atributo rel=xxx
-FixupAllLinks SÍ
Intenta corregir todos los enlaces (no solo aquellos marcados con -LinksMarker.
-PathMappingsFile archivo
Lee los mapeos de reubicación del archivo (en formato de diccionario).
-PathMappings '{"ruta"="otra_ruta";}'
Usa los mapeos de ruta especificados.
-BuildRelocationFileForDir dir
Construye un archivo de reubicación para el directorio dir y lo guarda en dir/table.htmlink. Esta opción es especial y previene cualquier otro procesamiento por parte del enlazador.

VER TAMBIÉN

autogsdoc(1), GNUstep(7).
