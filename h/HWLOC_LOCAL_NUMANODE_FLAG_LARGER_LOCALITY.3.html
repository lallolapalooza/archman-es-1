Descripción

detallada

Las plataformas con memoria heterogénea requieren formas de decidir si un búfer debe asignarse en memoria 'rápida' (como HBM), memoria 'normal' (DDR) o incluso memoria 'lenta' pero de gran capacidad (memoria no volátil). Estos nodos de memoria se denominan 'Objetivos' (Targets) mientras que la CPU que accede a ellos se denomina el 'Iniciador' (Initiator). El rendimiento del acceso depende de su localidad (plataformas NUMA) así como del rendimiento intrínseco de los objetivos (plataformas heterogéneas)

.

Los siguientes atributos describen el rendimiento de los accesos a memoria desde un Iniciador a un Objetivo de memoria, por ejemplo su latencia o ancho de banda. Los Iniciadores que realizan estos accesos a memoria suelen ser algunas PU o Núcleos (descritos como un conjunto de CPU). Por lo tanto, un Núcleo puede elegir dónde asignar un búfer de memoria comparando los atributos de diferentes nodos de memoria objetivo

cercanos.

También hay algunos atributos que son de todo el sistema. Su valor no depende de un iniciador específico que realice un acceso. La capacidad del nodo de memoria es un ejemplo de tal atributo sin

iniciador.

Una forma de usar esta API es comenzar con un cpuset que describa los Núcleos a los que está vinculado un programa. El mejor nodo NUMA objetivo para asignar memoria en este programa en estos Núcleos puede obtenerse pasando este cpuset como iniciador a hwloc_memattr_get_best_target() con el atributo de memoria relevante. Por ejemplo, si el código está limitado por la latencia, use el atributo

Latencia.

Un enfoque más flexible consiste en obtener la lista de nodos NUMA locales pasando este cpuset a hwloc_get_local_numanode_objs(). Los valores de los atributos para estos nodos, si los hay, pueden luego obtenerse con hwloc_memattr_get_value() y compararse manualmente con los criterios

deseados.

Los atributos de memoria también se utilizan internamente para construir Niveles de Memoria (Memory Tiers) que proporcionan una forma fácil de distinguir nodos NUMA de diferentes tipos, como se explica en Memoria Heter

ogénea.

Además de los niveles, hwloc define un conjunto de nodos 'predeterminados' donde las asignaciones normales de memoria deben hacerse (ver hwloc_topology_get_default_nodeset()). Esto también es útil para dividir la máquina en un conjunto de dominios NUMA no superpuestos, por ejemplo para vincular tareas por

dominio.
