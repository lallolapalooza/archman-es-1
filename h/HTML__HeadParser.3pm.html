HTML::HeadParser(3) Documentación de Perl aportada por el usuario HTML::HeadParser(3)

NOMBRE

HTML::HeadParser - Analiza la sección <HEAD> de un documento HTML

SINOPSIS

require HTML::HeadParser;
$p = HTML::HeadParser->new;
$p->parse($text) and print "no ha terminado";
$p->header('Title')          # para acceder a <title>....</title>
$p->header('Content-Base')   # para acceder a <base href="http://...">
$p->header('Foo')            # para acceder a <meta http-equiv="Foo" content="...">
$p->header('X-Meta-Author')  # para acceder a <meta name="author" content="...">
$p->header('X-Meta-Charset') # para acceder a <meta charset="...">

DESCRIPCIÓN

El módulo "HTML::HeadParser" es un especializado (y ligero) "HTML::Parser" que solo analizará la sección <HEAD>...</HEAD> de un documento HTML. El método parse() devolverá un valor FALSE tan pronto como se encuentren elementos <BODY> o texto del cuerpo, y no debería volver a llamarse después de esto.

Tenga en cuenta que "HTML::HeadParser" puede confundirse si se pasa UTF-8 sin decodificar a crudo al método parse(). Asegúrese de que las cadenas se decodifiquen correctamente antes de pasarlas.

El módulo "HTML::HeadParser" mantiene una referencia a un objeto de cabecera, y el analizador actualizará este objeto de cabecera a medida que se reconozcan los diversos elementos de la sección <HEAD> del documento HTML. Los siguientes campos de cabecera se ven afectados:

Content-Base:
La cabecera Content-Base se inicializa a partir del elemento <base href="...">.
Title:
La cabecera Title se inicializa a partir del elemento <title>...</title>.
Isindex:
La cabecera Isindex se añadirá si hay un elemento <isindex> en la cabecera <head>. El valor de la cabecera se inicializa a partir del atributo prompt si está presente. Si no hay ningún atributo prompt, tendrá '?' como valor.
X-Meta-Foo:
Todos los elementos <meta> que contengan un atributo "name" resultarán en cabeceras que usan el prefijo "X-Meta-" añadido al valor del atributo "name" como nombre de la cabecera, y el valor del atributo "content" como valor de la cabecera insertada.

Los elementos <meta> que contengan un atributo "http-equiv" resultarán en cabeceras como las anteriores, pero sin el prefijo "X-Meta-" en el nombre de la cabecera.

Los elementos <meta> que contengan un atributo "charset" resultarán en una cabecera "X-Meta-Charset", utilizando el valor del atributo "charset" como valor de la cabecera insertada.

El carácter ':' no se puede representar en los nombres de los campos de cabecera, por lo que si el elemento meta contiene este carácter, se sustituye por '-' antes de formar el nombre del campo.

MÉTODOS

Los siguientes métodos (además de los proporcionados por la superclase) están disponibles:

$hp = HTML::HeadParser->new
$hp = HTML::HeadParser->new( $header )
El constructor del objeto. El argumento opcional $header debe ser una referencia a un objeto que implemente los métodos header() y push_header() tal como los define la clase "HTTP::Headers". Normalmente será de alguna clase que sea o delegue en la clase "HTTP::Headers".

Si no se proporciona ningún $header, "HTML::HeadParser" creará un objeto "HTTP::Headers" por sí mismo (inicialmente vacío).

$hp->header;
Devuelve una referencia al objeto de cabecera.
$hp->header( $key )
Devuelve un valor de cabecera. Es solo una forma más corta de escribir "$hp->header->header($key)".

EJEMPLO

$h = HTTP::Headers->new;
$p = HTML::HeadParser->new($h);
$p->parse(<<EOT);
<title>Ejemplo estúpido</title>
<base href="http://www.linpro.no/lwp/">
El texto normal empieza aquí.
EOT
undef $p;
print $h->title;   # debería imprimir "Ejemplo estúpido"

VER TAMBIÉN

HTML::Parser, HTTP::Headers

La clase "HTTP::Headers" se distribuye como parte del paquete libwww-perl. Si no tiene esa distribución instalada, necesita proporcionar el argumento $header al constructor "HTML::HeadParser" con su propio objeto que implemente el protocolo documentado.
