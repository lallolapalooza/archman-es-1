Documentación del Tipo de Enumeración

enum hwloc_allow_flags_e

Flags para ser pasados a hwloc_topology_allow().

Enumerador

HWLOC_ALLOW_FLAG_ALL
Marca todos los objetos como permitidos en la topología. cpuset y nodeset pasados a hwloc_topology_allow() deben ser NULL.
HWLOC_ALLOW_FLAG_LOCAL_RESTRICTIONS
Permite solo los objetos que están disponibles para el proceso actual. La topología debe tener HWLOC_TOPOLOGY_FLAG_IS_THISSYSTEM para que el conjunto de recursos disponibles pueda ser recuperado del sistema operativo.

cpuset y nodeset pasados a hwloc_topology_allow() deben ser NULL.

HWLOC_ALLOW_FLAG_CUSTOM
Permite un conjunto personalizado de objetos, pasados a hwloc_topology_allow() como parámetros cpuset y/o nodeset.

enum hwloc_restrict_flags_e

Flags para ser pasados a hwloc_topology_restrict().

Enumerador

HWLOC_RESTRICT_FLAG_REMOVE_CPULESS
Elimina todos los objetos que se han quedado sin CPU. Por defecto, solo se eliminan los objetos que no contienen ni PU ni memoria. Esta flag no puede usarse con HWLOC_RESTRICT_FLAG_BYNODESET.
HWLOC_RESTRICT_FLAG_BYNODESET
Restringe por nodeset en lugar de por CPU set. Solo mantiene los objetos cuyo nodeset está incluido o parcialmente incluido en el conjunto dado. Esta flag no puede usarse con HWLOC_RESTRICT_FLAG_REMOVE_CPULESS.
HWLOC_RESTRICT_FLAG_REMOVE_MEMLESS
Elimina todos los objetos que se han quedado sin memoria. Por defecto, solo se eliminan los objetos que no contienen ni PU ni memoria. Esta flag solo puede usarse con HWLOC_RESTRICT_FLAG_BYNODESET.
HWLOC_RESTRICT_FLAG_ADAPT_MISC
Mueve objetos Misc a ancestros si sus padres son eliminados durante la restricción. Si esta flag no está activada, los objetos Misc son eliminados cuando sus padres son eliminados.
HWLOC_RESTRICT_FLAG_ADAPT_IO
Mueve objetos de I/O a ancestros si sus padres son eliminados durante la restricción. Si esta flag no está activada, los dispositivos de I/O y los puentes son eliminados cuando sus padres son eliminados.

int hwloc_obj_add_other_obj_sets (hwloc_obj_t dst, hwloc_obj_t src)

Configura los sets de CPU/nodo del objeto mediante una operación OR con el conjunto de otro objeto. Para cada cpuset o nodeset definido en src, asigna el conjunto correspondiente en dst y añade src a él mediante la operación OR de conjuntos.

Esta función es útil entre hwloc_topology_alloc_group_object() y hwloc_topology_insert_group_object(). Construye los conjuntos del nuevo Grupo que se insertará como un nuevo padre intermedio de varios objetos.

Retorna

0 en caso de éxito.

-1 con errno establecido a ENOMEM si alguna re-asignación interna falló.

hwloc_obj_t hwloc_topology_alloc_group_object (hwloc_topology_t topology)

Asigna un objeto de Grupo para insertarlo más tarde con hwloc_topology_insert_group_object(). Esta función devuelve un nuevo objeto de Grupo.

El llamador debe (al menos) inicializar sus conjuntos antes de insertar el objeto en la topología, ver hwloc_topology_insert_group_object(). O puede decidir no insertarlo y simplemente liberar el objeto de grupo llamando a hwloc_topology_free_group_object().

Retorna

El objeto asignado en caso de éxito.

NULL en caso de error.

Nota

Si se inserta con éxito mediante hwloc_topology_insert_group_object(), el objeto será liberado cuando se libere toda la topología. Si la inserción falla (p.ej., CPU y nodo-sets NULL o vacíos), se libera antes de devolver el error.

int hwloc_topology_allow (hwloc_topology_t restrict topology, hwloc_const_cpuset_t cpuset, hwloc_const_nodeset_t nodeset, unsigned long flags)

Cambia los conjuntos de PUs y nodos NUMA permitidos en la topología. Esta función solo funciona si se estableció HWLOC_TOPOLOGY_FLAG_INCLUDE_DISALLOWED en la topología. No modifica ningún objeto, solo cambia los conjuntos devueltos por hwloc_topology_get_allowed_cpuset() y hwloc_topology_get_allowed_nodeset().

Es notablemente útil al importar una topología desde otro proceso ejecutándose en un Cgroup de Linux diferente.

flags debe establecerse a una flag entre las del tipo hwloc_allow_flags_e.

Retorna

0 en caso de éxito, -1 en caso de error.

Nota

La eliminación de objetos de una topología debería realizarse mejor con hwloc_topology_restrict().

int hwloc_topology_free_group_object (hwloc_topology_t topology, hwloc_obj_t group)

Libera un objeto de Grupo previamente asignado con hwloc_topology_alloc_group_object(). El objeto de Grupo no debe haber sido insertado en la topología todavía.

Retorna

0 en caso de éxito.

-1 en caso de error.

int hwloc_topology_insert_group_object (hwloc_topology_t topology, hwloc_obj_t group)

Inserta un objeto de Grupo previamente asignado con hwloc_topology_alloc_group_object() en la topología. El objeto de Grupo debe tener su tipo inicializado (p.ej., a HWLOC_OBJTYPE_GROUP) y al menos uno de sus conjuntos (CPU o nodo) deben estar no vacíos.

Los conjuntos del Grupo se usan para encontrar sus hijos. Si algunos hijos están presentes en la topología pero no están cubiertos por ningún conjunto de CPU o nodo del Grupo, y tampoco por los conjuntos de sus padres, entonces son movidos como hijos del Grupo.

Por favor, consulte hwloc_obj_add_other_obj_sets() para construir estos conjuntos de manera sencilla entre la asignación y la inserción.

Retorna

0 en caso de éxito.

-1 en caso de error.

hwloc_obj_t hwloc_topology_insert_misc_object (hwloc_topology_t topology, hwloc_obj_t parent, const char *name)

Crea un objeto Misc y lo inserta bajo el objeto `parent`. Los objetos Misc son objetos genéricos que no se corresponden con ningún tipo de objeto hwloc específico. Se usan a menudo para representar los objetos del sistema operativo que no tienen una correspondencia directa en hwloc, como por ejemplo los dispositivos PCI.

Si `parent` es NULL, el objeto Misc se inserta en la raíz de la topología.

El objeto Misc tiene un nombre dado por `name`. Puede ser NULL.

Retorna

El objeto Misc recién creado en caso de éxito.

NULL en caso de error.

int hwloc_topology_refresh (hwloc_topology_t topology)

Actualiza la topología cargada. Esto es útil si el sistema ha cambiado desde la última vez que se cargó la topología (p.ej. dispositivos añadidos o eliminados).

Esto es solo una actualización parcial. No detectará cambios en la jerarquía de objetos (p.ej. nodos NUMA añadidos o eliminados). Para una actualización completa, se debe llamar a hwloc_topology_load().

Retorna

0 en caso de éxito, -1 en caso de error.

int hwloc_topology_restrict (hwloc_topology_t restrict topology, hwloc_const_bitmap_t set, unsigned long flags)

Modifica la topología para que solo contenga los objetos especificados en el `set`. El conjunto puede ser un conjunto de CPUs (cpuset) o un conjunto de nodos (nodeset), dependiendo de las flags.

Si la flag HWLOC_RESTRICT_FLAG_BYNODESET no está activada, el `set` se interpreta como un cpuset. Entonces, todos los objetos que no contengan ninguna PU dentro del cpuset dado serán eliminados de la topología.

Si la flag HWLOC_RESTRICT_FLAG_BYNODESET está activada, el `set` se interpreta como un nodeset. Entonces, todos los objetos que no contengan ningún nodo NUMA dentro del nodeset dado serán eliminados de la topología.

Las flags HWLOC_RESTRICT_FLAG_REMOVE_CPULESS y HWLOC_RESTRICT_FLAG_REMOVE_MEMLESS pueden ser usadas para eliminar objetos que se han quedado sin PUs o sin memoria respectivamente, incluso si estos objetos siguen conteniendo PUs/memoria permitidas por el `set`.

Las flags HWLOC_RESTRICT_FLAG_ADAPT_MISC y HWLOC_RESTRICT_FLAG_ADAPT_IO pueden ser usadas para mantener objetos Misc y de I/O incluso si sus padres son eliminados. Por defecto, son eliminados también.

Retorna

0 en caso de éxito, -1 en caso de error.
