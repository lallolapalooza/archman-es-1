NOMBRE

HTTP::Daemon::SSL - una clase de servidor http simple con soporte SSL

SINOPSIS

use HTTP::Daemon::SSL;
use HTTP::Status;
# ¡Asegúrate de tener un directorio certs/ con "server-cert.pem"
# y "server-key.pem" antes de ejecutar esto!
my $d = HTTP::Daemon::SSL->new || die;
print "Por favor, contacta conmigo en: <URL:", $d->url, ">\n";
while (my $c = $d->accept) {
    while (my $r = $c->get_request) {
        if ($r->method eq 'GET' and $r->url->path eq "/xyzzy") {
            # recuerda, esto *no* es una práctica recomendada :-)
            $c->send_file_response("/etc/passwd");
        } else {
            $c->send_error(RC_FORBIDDEN)
        }
    }
    $c->close;
    undef($c);
}

DESCRIPCIÓN

Las instancias de la clase HTTP::Daemon::SSL son servidores HTTP/1.1 que escuchan en un socket las solicitudes entrantes. HTTP::Daemon::SSL es una subclase de IO::Socket::SSL, por lo que también puedes realizar operaciones de socket directamente sobre él.

El método accept() devolverá cuando haya una conexión de un cliente disponible. En un contexto escalar, el valor devuelto será una referencia a un objeto de la clase HTTP::Daemon::ClientConn::SSL, que es otra subclase de IO::Socket::SSL. En un contexto de lista, se devuelve una matriz de dos elementos que contiene la referencia al nuevo objeto HTTP::Daemon::ClientConn::SSL y la dirección del par; la matriz estará vacía en caso de fallo. (Ten en cuenta que la versión
1.02 erróneamente no respetó el contexto de lista). Llamar al método get_request() en el objeto HTTP::Daemon::ClientConn::SSL leerá los datos del cliente y devolverá una referencia a un objeto HTTP::Request.

Este demonio HTTPS no hace fork(2) por ti. Tu aplicación, es decir, el usuario de HTTP::Daemon::SSL, es responsable de hacer fork si es deseable. Ten en cuenta también que el usuario es responsable de generar respuestas que cumplan con el protocolo HTTP/1.1. La clase HTTP::Daemon::ClientConn proporciona algunos métodos que facilitan esto.

MÉTODOS

Los siguientes métodos son las únicas diferencias con la clase base HTTP::Daemon:

$d = new HTTP::Daemon::SSL
El constructor acepta los mismos parámetros que el constructor de IO::Socket::SSL. También puede ser llamado sin especificar ningún parámetro, pero deberás asegurarte de tener un certificado y clave SSL para el servidor en certs/server-cert.pem y certs/server-key.pem. Consulta la documentación de IO::Socket::SSL para saber cómo cambiar estas ubicaciones predeterminadas y especificar muchos otros aspectos del comportamiento SSL. El demonio establecerá entonces una cola de escucha de 5 conexiones y asignará un número de puerto aleatorio. Un servidor que quiera enlazarse a una dirección específica en el puerto HTTPS estándar se construirá así: 
$d = new HTTP::Daemon::SSL
      LocalAddr => 'www.algunlugar.com',
      LocalPort => 443;
