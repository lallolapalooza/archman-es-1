NOMBRE

HTML::Entities - Codifica o decodifica cadenas con entidades HTML

SINOPSIS

use HTML::Entities;
$a = "V&aring;re norske tegn b&oslash;r &#230res";
decode_entities($a);
encode_entities($a, "\200-\377");

Por ejemplo, esto:

$input = "vis-à-vis Beyoncé's naïve\npapier-mâché résumé";
print encode_entities($input), "\n"

Imprime esto:

vis-&agrave;-vis Beyonc&eacute;'s na&iuml;ve
papier-m&acirc;ch&eacute; r&eacute;sum&eacute;

DESCRIPCIÓN

Este módulo se encarga de la codificación y decodificación de cadenas con entidades de caracteres HTML. El módulo proporciona las siguientes funciones:

decode_entities( $cadena, ... )
Esta rutina reemplaza las entidades HTML encontradas en $cadena con el carácter Unicode correspondiente. Las entidades no reconocidas se dejan tal cual.

Si se proporcionan varias cadenas como argumento, cada una se decodifica por separado y se devuelve el mismo número de cadenas.

Si se llama en contexto void, los argumentos se decodifican en el lugar.

Esta rutina se exporta por defecto.

_decode_entities( $cadena, \%entidad2car )
_decode_entities( $cadena, \%entidad2car, $prefijo_expandir )
Esto reemplazará en el lugar las entidades HTML en $cadena. Se debe proporcionar el hash %entidad2car. Las entidades nombradas que no se encuentren en el hash %entidad2car se dejan tal cual. Las entidades numéricas se expanden a menos que su valor sea desbordado.

Las claves en %entidad2car son los nombres de las entidades a expandir y sus valores son lo que deberían expandir. Los valores no tienen que ser cadenas de un solo carácter. Si una clave tiene ";" como sufijo, entonces las ocurrencias en $cadena solo se expanden si se terminan correctamente con ";". Las entidades sin ";" se expandirán independientemente de cómo se terminen, para compatibilidad con cómo los navegadores comunes tratan las entidades en el rango Latin-1.

Si $prefijo_expandir es VERDADERO, entonces las entidades sin ";" final en %entidad2car se expandirán incluso como prefijo de un nombre no reconocido más largo. Se utilizará el nombre que más coincida en %entidad2car. Esto está presente principalmente para compatibilidad con una mala característica de MSIE.

$cadena = "foo&nbspbar";
_decode_entities($cadena, { nb => "@", nbsp => "\xA0" }, 1);
print $cadena;  # imprimirá "foo bar"

Esta rutina se exporta por defecto.

encode_entities( $cadena )
encode_entities( $cadena, $caracteres_inseguros )
Esta rutina reemplaza caracteres inseguros en $cadena con su representación de entidad. Se puede proporcionar un segundo argumento para especificar qué caracteres considerar inseguros. Los caracteres inseguros se especifican utilizando la sintaxis de clase de caracteres de expresiones regulares (lo que se encuentra dentro de corchetes en las expresiones regulares).

El conjunto por defecto de caracteres a codificar son los caracteres de control, los caracteres de bit alto y los caracteres "<", "&", ">", "'" y """. Pero esto, por ejemplo, codificaría *solo* los caracteres "<", "&", ">", y """:

$codificado = encode_entities($input, '<>&"');

Y esto solo codificaría caracteres que no sean ASCII planos:

$codificado = encode_entities($input, '^\n\x20-\x25\x27-\x7e');

Esta rutina se exporta por defecto.

encode_entities_numeric( $cadena )
encode_entities_numeric( $cadena, $caracteres_inseguros )
Esta rutina funciona igual que encode_entities, excepto que las entidades de reemplazo son siempre "&#xnum_hex;" y nunca "&nombre_ent;". Por ejemplo, encode_entities("r\xF4le") devuelve "r&ocirc;le", pero encode_entities_numeric("r\xF4le") devuelve "r&#xF4;le".

Esta rutina *no* se exporta por defecto. Pero siempre puedes exportarla con "use HTML::Entities qw(encode_entities_numeric);" o incluso "use HTML::Entities qw(:DEFAULT encode_entities_numeric);"

Todas estas rutinas modifican la cadena pasada como primer argumento, si se llaman en un contexto void. En contextos escalar y de array, se devuelve la cadena codificada o decodificada (sin cambiar la cadena de entrada).

Si prefiere no importar estas rutinas en su espacio de nombres, puede llamarlas como:

use HTML::Entities ();
$decodificado = HTML::Entities::decode($a);
$codificado = HTML::Entities::encode($a);
$codificado = HTML::Entities::encode_numeric($a);

El módulo también puede exportar los hashes %char2entity y %entity2char, que contienen el mapeo de todos los caracteres a las entidades correspondientes (y viceversa, respectivamente).
