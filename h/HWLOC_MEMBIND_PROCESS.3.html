Descripción

detallada

El enlazado de memoria se puede realizar de tres

maneras:
  • asignación de memoria explícita gracias a hwloc_alloc_membind() y funciones relacionadas: el enlazado tendrá efecto sobre la memoria asignada por estas
    • funciones.
  • enlazado de memoria implícito a través de la política de enlazado: hwloc_set_membind() y funciones relacionadas solo definen la política actual del proceso, que se aplicará a las llamadas posteriores a malloc() y funciones
    • relacionadas.
  • migración de rangos de memoria existentes, gracias a hwloc_set_area_membind() y funciones relacio
    • nadas, que mueven dat
os ya asignados.

No todos los sistemas operativos soportan las tres formas. hwloc_topology_get_support() puede usarse para consultar el soporte real de enlazado de memoria en el sistema operativo actualmente en

uso.

Cuando la operación de enlazado solicitada no está disponible y se pasó el indicador HWLOC_MEMBIND_STRICT, la función devuelve -1. errno se establecerá en ENOSYS cuando el sistema soporte la acción o política especificada (por ejemplo, algunos sistemas solo permiten enlazar memoria por hilo, mientras que otros sistemas solo permiten enlazar memoria para todos los hilos de un proceso). errno se establecerá en EXDEV cuando el conjunto solicitado no pueda aplicarse (por ejemplo, algunos sistemas solo permiten enlazar memoria a un solo nodo NUMA)

.

Si no se pasó HWLOC_MEMBIND_STRICT, la función puede fallar también, o el sistema operativo puede usar una operación ligeramente diferente (con efectos secundarios, un conjunto de enlazado más pequeño, etc.) cuando la operación solicitada no esté exactamente

soportada.

La forma más portable, que debería preferirse sobre las demás siempre que sea posible, es la siguiente. Asigna algo de memoria que se espera esté enlazada al conjunto especificado. Para ello, hwloc posiblemente tendrá que cambiar la política de enlazado de memoria actual para lograr realmente enlazar la memoria, si el SO no proporciona ninguna otra manera de asignar simplemente memoria enlazada sin cambiar la política para todas las asignaciones. Esa es la diferencia con hwloc_alloc_membind(), que nunca cambiará la política de enlazado de memoria

actual. 
hwloc_alloc_membind_policy(topology, size, set,
                           HWLOC_MEMBIND_BIND, 0)
;

Cada función de enlazado de memoria de hwloc toma un argumento de mapa de bits que es un conjunto de CPU por defecto, o un conjunto de nodos de memoria NUMA si se especifica el indicador HWLOC_MEMBIND_BYNODESET. Ver Conjuntos de objetos (hwloc_cpuset_t y hwloc_nodeset_t) y La API de mapas de bits para una discusión sobre conjuntos de CPU y conjuntos de nodos de memoria NUMA. También es posible convertir entre conjunto de CPU y conjunto de nodos usando hwloc_cpuset_to_nodeset() o hwloc_cpuset_from_n

odeset().

El enlazado de memoria por conjunto de CPU no puede funcionar para nodos de memoria NUMA sin CPU. Por lo tanto, debería preferirse el enlazado por conjunto de nodos siempre que sea

posible.

enum hwloc_membind_flags_

t

Indicadores de enlazado de memoria. Estos indicadores pueden usarse para refinar la política de enlazado. Todos los indicadores pueden combinarse lógicamente con OR, con la excepción de HWLOC_MEMBIND_PROCESS y HWLOC_MEMBIND_THREAD; estos dos indicadores son mutuamente

excluyentes.

No todos los sistemas soportan todos los tipos de enlazado. hwloc_topology_get_support() puede usarse para consultar el soporte real de enlazado de memoria en el sistema operativo actualmente en uso. Ver la sección 'Descripción detallada' de Enlazado de memoria para una descripción de los errores que pueden

ocurrir.

Enumerador

HWLOC_MEMBIND_PROCESS
Establece la política para todos los hilos del proceso especificado (posiblemente multihilo). Este indicador es mutuamente excluyente con HWLOC_MEMBIND_
THREAD.
HWLOC_MEMBIND_THREAD
Establece la política para un hilo específico del proceso actual. Este indicador es mutuamente excluyente con HWLOC_MEMBIND_PROCE
SS.
HWLOC_MEMBIND_STRICT
Solicita enlazado estricto al SO. La func
ión fallará si el enlazado no pued
e garantizarse / aplicarse completamente.

Este indicador tiene significados ligeramente diferentes dependiendo con qué función se

use.
HWLOC_MEMBIND_MIGRATE
Migra memoria ya asignada. Si la memoria no puede migrarse y se pasó el indicador HWLOC_MEMBIND_STRICT, se devolverá un
error.
HWLOC_MEMBIND_NOCPUBIND
Evita cualquier efecto sobre el enlazado de CPU. En algunos sistemas operativos, algunas funciones subyacentes de enlazado de memoria también enlazan la aplicación a la(s) CPU correspondiente(s). Usar este indicador hará que hwloc evite usar funciones del SO que podrían afectar potencialmente a los enlazados de CPU. Nótese, sin embargo, que usar NOCPUBIND puede reducir el soporte general de enlazado de memoria de hwloc. Específicamente: algunas de las funciones de enlazado de memoria de hwloc pueden fallar con errno establecido a ENOSYS cuando se usan con
NOCPUBIND.
HWLOC_MEMBIND_BYNODESET
Considera el argumento de mapa de bits como un conjunto de nodos. El a
rgumento de mapa de bits se considera un conjunto de nodos si se
da este indicador, o un conjunto de CPU por defecto en caso contrario.

El enlazado de memoria por conjunto de CPU no puede funcionar par

a nodos de memoria NUMA sin CPU. Por lo tanto, debería prefer
irse el enlazado por conjunto de nodos siempre que sea posible.

Function Documentation

void * hwloc_alloc (hwloc_topology_t topology, size_t len)

Allocate some memory. This is equivalent to malloc(), except that it tries to allocate page-aligned memory from the OS.

Returns

a pointer to the allocated area, or NULL on error.

Note

The allocated memory should be freed with hwloc_free().

void * hwloc_alloc_membind (hwloc_topology_t topology, size_t len, hwloc_const_bitmap_t set, hwloc_membind_policy_t policy, int flags)

Allocate some memory on NUMA memory nodes specified by set.

Returns

a pointer to the allocated area.

NULL with errno set to ENOSYS if the action is not supported and HWLOC_MEMBIND_STRICT is given.

NULL with errno set to EXDEV if the binding cannot be enforced and HWLOC_MEMBIND_STRICT is given.

NULL with errno set to ENOMEM if the memory allocation failed even before trying to bind.

If HWLOC_MEMBIND_BYNODESET is specified, set is considered a nodeset. Otherwise it's a cpuset.

Note

The allocated memory should be freed with hwloc_free().

void * hwloc_alloc_membind_policy (hwloc_topology_t topology, size_t len, hwloc_const_bitmap_t set, hwloc_membind_policy_t policy, int flags) [inline]

Allocate some memory on NUMA memory nodes specified by set. First, try to allocate properly with hwloc_alloc_membind(). On failure, the current process or thread memory binding policy is changed with hwloc_set_membind() before allocating memory. Thus this function works in more cases, at the expense of changing the current state (possibly affecting future allocations that would not specify any policy).

If HWLOC_MEMBIND_BYNODESET is specified, set is considered a nodeset. Otherwise it's a cpuset.

Returns

a pointer to the allocated area, or NULL on error.

int hwloc_free (hwloc_topology_t topology, void * addr, size_t len)

Free memory that was previously allocated by hwloc_alloc() or hwloc_alloc_membind().

Returns

0 on success, -1 on error.

int hwloc_get_area_membind (hwloc_topology_t topology, const void * addr, size_t len, hwloc_bitmap_t set, hwloc_membind_policy_t * policy, int flags)

Query the CPUs near the physical NUMA node(s) and binding policy of the memory identified by (addr, len ). The bitmap set (previously allocated by the caller) is filled with the memory area binding.

This function has two output parameters: set and policy. The values returned in these parameters depend on both the flags passed in and the memory binding policies and nodesets of the pages in the address range.

If HWLOC_MEMBIND_STRICT is specified, the target pages are first checked to see if they all have the same memory binding policy and nodeset. If they do not, -1 is returned and errno is set to EXDEV. If they are identical across all pages, the set and policy are returned in set and policy, respectively.

If HWLOC_MEMBIND_STRICT is not specified, the union of all NUMA node(s) containing pages in the address range is calculated. If all pages in the target have the same policy, it is returned in policy. Otherwise, policy is set to HWLOC_MEMBIND_MIXED.

If HWLOC_MEMBIND_BYNODESET is specified, set is considered a nodeset. Otherwise it's a cpuset.

If any other flags are specified, -1 is returned and errno is set to EINVAL.

Returns

0 on success.

-1 with errno set to EINVAL if len is 0.

int hwloc_get_area_memlocation (hwloc_topology_t topology, const void * addr, size_t len, hwloc_bitmap_t set, int flags)

Get the NUMA nodes where memory identified by (addr, len ) is physically allocated. The bitmap set (previously allocated by the caller) is filled according to the NUMA nodes where the memory area pages are physically allocated. If no page is actually allocated yet, set may be empty.

If pages spread to multiple nodes, it is not specified whether they spread equitably, or whether most of them are on a single node, etc.

The operating system may move memory pages from one processor to another at any time according to their binding, so this function may return something that is already outdated.

If HWLOC_MEMBIND_BYNODESET is specified, set is considered a nodeset. Otherwise it's a cpuset.

If HWLOC_MEMBIND_STRICT is specified, then the function fails with errno=EXDEV if memory pages are found upon more than one NUMA node. This allows checking if a memory area is located upon a single specific NUMA node.

Returns

0 on success.

-1 with errno set to EINVAL if len is 0.
