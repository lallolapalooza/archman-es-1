DESCRIPCIÓ

N

HTML::FormatRTF es una clase para objetos que se usan para convertir HTML a RTF. Actualmente no hay soporte adecuado para tablas o

formularios.

Esta es una subclase de HTML::Formatter, cuya documentación deberías consultar para obtener más información sobre métodos subyacentes como "new", "format", "format_file",

etc.

Puedes especificar cualquiera de los siguientes parámetros en la llamada a "new", "format_file" o "format_string"

:
l
m
Cantidad de sangría extra a aplicar al margen izquierdo, en twips (veinteavos de un punto). El valor predeterminado es 0.

Así que si quisieras que el margen izquierdo fuera medio pulgada adicional más grande, establecerías "lm => 720" (ya que hay 1440 twips en una pulgada). Si quisieras que fuera aproximadamente 1.5cm más grande, establecerías "lw => 850" (ya que hay aproxi

madamente 567 twips
en un centímetro).
r
m
Cantidad de sangría extra a aplicar al margen izquierdo, en twips (veinteavos de un punto). El valor predeterminado
es 0.
normal_halfpoint_s
ize
Este es el tamaño del texto normal en el documento, en medios puntos. El valor predeterminado es 22, lo que significa que el texto normal es de 11
puntos.
header_halfpoint_s
ize
Este es el tamaño del texto utilizado en el encabezado de página del documento, en medios puntos. El valor predeterminado es 17, lo que significa que el texto normal es de 7.5 puntos. Actualmente, el encabezado consiste solo en "p. numerodepagina" en la esquina superior derecha, y no puede ser
deshabilitado.
head1_halfpoint_size ... head6_halfpoint_s
ize
Estos controlan el tamaño de fuente de cada nivel de encabezado, en medios twips. Por ejemplo, el valor predeterminado para head3_halfpoint_size es 25, lo que significa que el texto HTML "<h3>...</h3>" será de 12.5 puntos (además de estar subrayado y en la fuente de encabezado)
.
codeblock_halfpoint_s
ize
Esto controla el tamaño de fuente (en medios puntos) del texto utilizado para "<pre>...</pre>". Por defecto, es 18, lo que significa 9
puntos.
fontname_bo
dy
Esta opción controla qué fuente se usará para el cuerpo del texto -- es decir, todo lo que no sea texto de encabezado ni texto en elementos pre/code/tt. El valor predeterminado actualmente es "Times". Otros valores útiles que puedo sugerir usar son "Georgia" o "Bookman Old
Style".
fontname_co
de
Esta opción controla qué fuente se usará para el texto en elementos pre/code/tt. El valor predeterminado actualmente es "Courier
New".
fontname_headi
ngs
Esta opción controla qué nombre de fuente se usará para los encabezados. Puedes usar la misma fuente que fontname_body, pero prefiero una fuente sin serifa, así que el valor predeterminado actualmente es "Arial". También considera "Tahoma" y
"Verdana".
document_langu
age
Esta opción controla qué número de idioma de Microsoft se especificará como el idioma para este documento. El valor predeterminado actual es 1033, para inglés de EE.UU. Consulta una referencia de RTF para otros números de
idioma.
hr_wid
th
Esta opción controla cuántos caracteres de subrayado se usarán para renderizar una etiqueta "<hr>". Su valor predeterminado actualmente es 50. Generalmente puedes dejarlo como está, pero en algunas circunstancias podrías querer usar un número más pequeño o más
grande.
no_prol
og
Si esta opción se establece en un valor verdadero, HTML::FormatRTF se asegurará de no emitir el prólogo RTF antes del documento. Por defecto, esto está desactivado, lo que significa que HTML::FormatRTF emitirá el prólogo. Esta opción es de interés solo para usuarios
avanzados.
no_trail
er
Si esta opción se establece en un valor verdadero, HTML::FormatRTF se asegurará de no emitir el epílogo RTF al final del documento. Por defecto, esto está desactivado, lo que significa que HTML::FormatRTF emitirá el fragmento de RTF que termina el
documento. Esta opción e
s de interés solo para
usuarios avanzados.
