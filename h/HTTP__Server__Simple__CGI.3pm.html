HTTP::Server::Simple::CGI(3) Documentación de Perl contribuida por el usuario HTTP::Server::Simple::CGI(3)

NOMBRE

HTTP::Server::Simple::CGI - versión estilo CGI.pm de HTTP::Server::Simple

DESCRIPCIÓN

HTTP::Server::Simple ya era simple, pero algún listillo señaló que no hay CGI en HTTP, y así nació este módulo para aislar las partes de este manejador relacionadas con CGI.pm.

accept_hook

El accept_hook en esta subclase limpia el entorno a su estado inicial.

post_setup_hook

Inicializa el objeto CGI global, así como otras configuraciones del entorno.

cgi_class [NombreClase]

Obtiene o establece la clase a utilizar para crear el objeto $cgi que se pasa a "handle_request".

Llamado con un único argumento, establece el coderef. Llamado sin argumentos, devuelve el valor actual de este campo.

Para proporcionar una subrutina de inicialización que se ejecutará en el post_setup_hook, consulta "cgi_init".

p. ej.

$servidor->cgi_class('CGI');
$servidor->cgi_init(sub {
    require CGI;
    CGI::initialize_globals();
});

o, si quieres usar CGI::Simple,

$servidor->cgi_class('CGI::Simple');
$servidor->cgi_init(sub {
    require CGI::Simple;
});

cgi_init [CODEREF]

Un coderef que se ejecutará en el post_setup_hook.

Llamado con un único argumento, establece el coderef. Llamado sin argumentos, devuelve el valor actual de este campo.

setup

Este método configura las variables de entorno CGI basándose en varias meta-cabeceras, como el protocolo, el nombre del host remoto, la ruta de la solicitud, etc.

Consulta la documentación de HTTP::Server::Simple para más detalles.

handle_request CGI

Esta rutina se llama cada vez que tu servidor recibe una solicitud que puede manejar.

Se llama con un objeto CGI que ha sido pre-inicializado. Querrás sobrescribir este método en tu subclase

handler

Manejador implementado como parte de la API de HTTP::Server::Simple
