hwlocality_distances_add - Añadir distancias entre objetos

Descripción detallada

La forma habitual de añadir distancias es:

hwloc_distances_add_handle_t handle;
int err = -1;
handle = hwloc_distances_add_create(topology, "name", kind, 0);
if (handle) {
  err = hwloc_distances_add_values(topology, handle, nbobjs, objs, values, 0);
  if (!err)
    err = hwloc_distances_add_commit(topology, handle, flags);
}


Si err es 0 al final, entonces la adición fue exitosa.

Documentación de tipos definidos

typedef void* hwloc_distances_add_handle_t

Manejo (handle) a una nueva estructura de distancias durante su adición a la topología.

Documentación de tipos de enumeración

enum hwloc_distances_add_flag_e

Banderas para añadir una nueva distancia a una topología.

Enumerador

HWLOC_DISTANCES_ADD_FLAG_GROUP
Intentar agrupar objetos basándose en la nueva información de distancia proporcionada. El agrupamiento solo se realiza cuando la estructura de distancias contiene latencias, y cuando todos los objetos son del mismo tipo.
HWLOC_DISTANCES_ADD_FLAG_GROUP_INACCURATE
Si se agrupa, considerar los valores de distancia como inexactos y relajar las comparaciones durante los algoritmos de agrupación. La precisión real puede ser modificada a través de la variable de entorno HWLOC_GROUPING_ACCURACY (véase Variables de entorno).

Documentación de funciones

int hwloc_distances_add_commit (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned long flags)

Comprometer (commit) una nueva estructura de distancias. Esta función finaliza la estructura de distancias e inserta en ella la topología.

El parámetro handle fue previamente devuelto por hwloc_distances_add_create(). Luego se especificaron objetos y valores con hwloc_distances_add_values().

flags configura el comportamiento de la función utilizando un conjunto opcional de hwloc_distances_add_flag_e OR'ado. Puede utilizarse para solicitar el agrupamiento de objetos existentes basándose en distancias.

En caso de error, la estructura temporal de distancias y su contenido se destruyen.

Retorna

0 en caso de éxito.

-1 en caso de error.

hwloc_distances_add_handle_t hwloc_distances_add_create (hwloc_topology_t topology, const char * name, unsigned long kind, unsigned long flags)

Crear una nueva estructura de distancias vacía. Crear una estructura de distancias vacía para ser rellenada con hwloc_distances_add_values() y luego comprometida con hwloc_distances_add_commit().

El parámetro name es opcional, puede ser NULL. De lo contrario, se copiará internamente y podrá ser liberado posteriormente por el llamador.

kind especifica el tipo de distancia como un conjunto OR'ado de hwloc_distances_kind_e. Solo se puede dar un tipo de significado y un tipo de procedencia si es apropiado (por ejemplo, HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH y HWLOC_DISTANCES_KIND_FROM_USER). El tipo HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES se establecerá automáticamente según los objetos que tengan tipos diferentes en hwloc_distances_add_values().

flags debe ser 0 por ahora.

Retorna

Un hwloc_distances_add_handle_t que luego debe pasar a hwloc_distances_add_values() y hwloc_distances_add_commit().

NULL en caso de error.

int hwloc_distances_add_values (hwloc_topology_t topology, hwloc_distances_add_handle_t handle, unsigned nbobjs, hwloc_obj_t * objs, hwloc_uint64_t * values, unsigned long flags)

Especificar los objetos y valores en una nueva estructura de distancias vacía. Especificar los objetos y valores para una nueva estructura de distancias que fue devuelta como un handle por hwloc_distances_add_create(). La estructura debe luego ser comprometida con hwloc_distances_add_commit().

El número de objetos es nbobjs y el array de objetos es objs. Los valores de distancia se almacenan en un array de una dimensión en values. La distancia desde el objeto i hasta el objeto j está en la posición i*nbobjs+j.

nbobjs debe ser al menos 2.

Los arrays objs y values se copiarán internamente, podrán ser liberados posteriormente por el llamador.

En caso de error, la estructura temporal de distancias y su contenido se destruyen.

flags debe ser 0 por ahora.

Retorna

0 en caso de éxito.

-1 en caso de error.
