NOMBRE

HTTP::CookieJar::LWP - Adaptador LWP para HTTP::CookieJar

VERSIÓN

versión 0.014

SINOPSIS

use LWP::UserAgent;
use HTTP::CookieJar::LWP;
my $ua = LWP::UserAgent->new(
  cookie_jar => HTTP::CookieJar::LWP->new
);

DESCRIPCIÓN

Este módulo es un adaptador experimental para que HTTP::CookieJar funcione con LWP. Implementa los dos métodos que "LWP" llama desde HTTP::Cookies.

No es un reemplazo general para usar en cualquier otro sentido de "HTTP::Cookies".
