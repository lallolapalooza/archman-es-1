Estos campos de encabezado se usan para hacer que una solicitud sea condicional. Si el recurso solicitado ha sido (o no ha sido) modificado desde el tiempo especificadod en este campo, entonces el servidor devolverá una "304 Not Modified" respuesta en lugar del propio documento.

El campo de encabezado Content-Type indica el tipo de medio del contenido del mensaje. Por ejemplo.:

El valor devuelto se convertirá a minúsculas, y los parámetros potenciales se recortarán y se devolverán como un valor separado si está en un contexto de lista. Si no existe dicho campo de encabezado, se devuelve la cadena vacía. Esto hace que sea seguro hacer lo siguiente:

   ...

$h->title
El título del documento. En libwww-perl este encabezado se inicializará automáticamente a partir del elemento <TITLE>...</TITLE> de los documentos HTML. Este encabezado ya no forma parte del estándar HTTP.
$h->user_agent
Este campo de encabezado se usa en mensajes de solicitud y contiene información sobre el agente de usuario que origina la solicitud. Por ejemplo.:

$h->server
El campo de encabezado server contiene información sobre el software que utiliza el programa de servidor de origen que maneja la solicitud.
$h->from
Este encabezado debería contener una dirección de correo electrónico de Internet para el usuario humano que controla el agente de usuario que realiza la solicitud. La dirección debería ser utilizable por la máquina, tal como lo define RFC822. Por ejemplo: 
$h->from('King Kong <king@kong.com>');

Este encabezado ya no forma parte del estándar HTTP.

$h->referer
Se usa para especificar la dirección (URI) del documento a partir del cual se obtuvo la dirección del recurso solicitado.

El "Free On-line Dictionary of Computing" dice esto sobre la palabra referer:

<World-Wide Web> Un error ortográfico de "referrer" que de
alguna manera llegó al estándar {HTTP}. El referer (sic) de una
{página web} dada es la {URL} de la página web que contenga el
enlace que el usuario siguió hasta la página actual. La mayoría de los
navegadores envían esta información como parte de una solicitud.
(1998-10-19)

Por demanda popular "referrer" existe como un alias para este método, por lo que puede evitar este error ortográfico en sus programas y aún así enviar lo correcto por la línea.

Al establecer el referrer, este método elimina el fragmento de la URI dada si está presente, tal como lo exige RFC2616. Tenga en cuenta que la eliminación no ocurre automáticamente si se usan los métodos header(), push_header() o init_header() para establecer el referrer.

$h->www_authenticate
Este encabezado debe incluirse como parte de una "401 Unauthorized" respuesta. El valor del campo consiste en un desafío que indica el esquema de autenticación y los parámetros aplicables a la URI solicitada.
$h->proxy_authenticate
Este encabezado debe incluirse en una "407 Proxy Authentication Required" respuesta.
$h->authorization
$h->proxy_authorization
Un agente de usuario que desee autenticarse ante un servidor o un proxy puede hacerlo incluyendo estos encabezados.
$h->authorization_basic
Este método se usa para obtener o establecer un encabezado de autorización que utiliza el "Basic Authentication Scheme". En contexto de lista devolverá dos valores; el nombre de usuario y la contraseña. En contexto escalar devolverá "uname:password" como un valor de cadena única.

Cuando se usa para establecer el valor del encabezado, espera dos argumentos. Por ejemplo.:

$h->authorization_basic($uname, $password);

El método emitirá un error fatal si $uname contiene dos puntos ':'.

$h->proxy_authorization_basic
Igual que authorization_basic() pero establecerá el encabezado "Proxy-Authorization" en su lugar.

NOMBRES DE CAMPO NO CANONICALIZADOS

La ortografía del nombre del campo de encabezado normalmente se canonicaliza, incluyendo la traducción de '_' a '-'. Hay algunas aplicaciones en las que esto no es apropiado. El prefijo de los nombres de campo con ':' le permite forzar una ortografía específica. Por ejemplo, si realmente desea que un nombre de campo de encabezado aparezca como "foo_bar" en lugar de "Foo-Bar", podría establecerlo así:

$h->header(":foo_bar" => 1);

Estos nombres de campo se devuelven con el ':' intacto para $h->header_field_names y para el $h->scan callback, pero los dos puntos no aparecen en $h->as_string.
