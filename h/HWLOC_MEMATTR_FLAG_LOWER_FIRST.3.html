Descripción Detallada

Los atributos de memoria se identifican por un ID (hwloc_memattr_id_t) y un nombre. hwloc_memattr_get_name() y hwloc_memattr_get_by_name() convierten entre ellos (o devuelven un error si el atributo no existe).

El conjunto de hwloc_memattr_id_t válidos es un conjunto contiguo que comienza en 0. Primero contiene atributos predefinidos, como se enumera en hwloc_memattr_id_e (de 0 a HWLOC_MEMATTR_ID_MAX-1). Luego, los atributos personalizados pueden registrarse dinámicamente con hwloc_memattr_register(). Se les asignarán los siguientes IDs (HWLOC_MEMATTR_ID_MAX para el primero, etc.).

Para iterar sobre todos los atributos válidos (ya sean predefinidos o personalizados registrados dinámicamente), se puede iterar sobre los IDs a partir de 0 hasta que hwloc_memattr_get_name() o hwloc_memattr_get_flags() devuelvan un error.

Los valores para un atributo existente o para los personalizados registrados dinámicamente pueden establecerse o modificarse con hwloc_memattr_set_value().

Documentación del tipo de enumeración

enum hwloc_memattr_flag_e

Flags de atributos de memoria. Se pasan a hwloc_memattr_register() y se devuelven por hwloc_memattr_get_flags().

Enumerador

HWLOC_MEMATTR_FLAG_HIGHER_FIRST
Los mejores nodos para este atributo de memoria son aquellos con los valores más altos. Por ejemplo, Ancho de banda.
HWLOC_MEMATTR_FLAG_LOWER_FIRST
Los mejores nodos para este atributo de memoria son aquellos con los valores más bajos. Por ejemplo, Latencia.
HWLOC_MEMATTR_FLAG_NEED_INITIATOR
El valor devuelto para este atributo de memoria depende del iniciador proporcionado. Por ejemplo, Ancho de banda y Latencia, pero no Capacidad.

Documentación de funciones

int hwloc_memattr_get_flags (hwloc_topology_t topology, hwloc_memattr_id_t attribute, unsigned long * flags)

Devuelve los flags del atributo dado. Los flags son un conjunto OR'ed de hwloc_memattr_flag_e.

El puntero de salida flags no puede ser NULL.

Devuelve

0 en caso de éxito.

-1 con errno establecido en EINVAL si el atributo no existe.

int hwloc_memattr_get_name (hwloc_topology_t topology, hwloc_memattr_id_t attribute, const char ** name)

Devuelve el nombre de un atributo de memoria. El puntero de salida name no puede ser NULL.

Devuelve

0 en caso de éxito.

-1 con errno establecido en EINVAL si el atributo no existe.

int hwloc_memattr_register (hwloc_topology_t topology, const char * name, unsigned long flags, hwloc_memattr_id_t * id)

Registra un nuevo atributo de memoria. Añade un nuevo atributo de memoria personalizado. Los flags son un conjunto OR'ed de hwloc_memattr_flag_e. Debe contener uno de HWLOC_MEMATTR_FLAG_HIGHER_FIRST o HWLOC_MEMATTR_FLAG_LOWER_FIRST pero no ambos.

El ID del nuevo atributo está inmediatamente después del último ID de atributo existente (que es el ID del último atributo registrado si lo hay, o el ID del último atributo predefinido en hwloc_memattr_id_e).

Devuelve

0 en caso de éxito.

-1 con errno establecido en EINVAL si se proporciona un conjunto inválido de flags.

-1 con errno establecido en EBUSY si otro atributo ya utiliza este nombre.

int hwloc_memattr_set_value (hwloc_topology_t topology, hwloc_memattr_id_t attribute, hwloc_obj_t target_node, struct hwloc_location * initiator, unsigned long flags, hwloc_uint64_t value)

Establece el valor de un atributo para un nodo NUMA específico. Si el atributo no está relacionado con un iniciador específico (no tiene el flag HWLOC_MEMATTR_FLAG_NEED_INITIATOR), el iniciador location initiator se ignora y puede ser NULL.

El iniciador se copiará en la topología, el llamador deberá liberar cualquier cosa asignada para almacenar el iniciador, por ejemplo, el cpuset.

target_node no puede ser NULL.

attribute no puede ser HWLOC_MEMATTR_ID_CAPACITY ni HWLOC_MEMATTR_ID_LOCALITY.

flags debe ser 0 por ahora.

Nota

El iniciador initiator debe ser de tipo HWLOC_LOCATION_TYPE_CPUSET al referirse a accesos realizados por núcleos de CPU. HWLOC_LOCATION_TYPE_OBJECT no es utilizado actualmente internamente por hwloc, pero los usuarios pueden utilizarlo, por ejemplo, para proporcionar información personalizada sobre accesos a memoria del host realizados por GPUs.

Devuelve

0 en caso de éxito o -1 en caso de error.
