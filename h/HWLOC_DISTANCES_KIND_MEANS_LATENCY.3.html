Documentación del Tipo Enumeración

enum hwloc_distances_kind_e

Tipos de matrices de distancia. El atributo kind de struct hwloc_distances_s es un conjunto de tipos unidos con OR.

Cada matriz de distancia puede tener solo un tipo entre HWLOC_DISTANCES_KIND_FROM_* que especifique de dónde proviene la información de distancia, y un tipo entre HWLOC_DISTANCES_KIND_MEANS_* que especifique si los valores son latencias o anchos de banda.

Enumerador

HWLOC_DISTANCES_KIND_FROM_OS
Estas distancias se obtuvieron del sistema operativo o del hardware.
HWLOC_DISTANCES_KIND_FROM_USER
Estas distancias fueron proporcionadas por el usuario.
HWLOC_DISTANCES_KIND_MEANS_LATENCY
Los valores de distancia son similares a las latencias entre objetos. Los valores son más pequeños para objetos más cercanos, por lo tanto son mínimos en la diagonal de la matriz (distancia entre un objeto y sí mismo). También podría ser el número de saltos de red entre objetos, etc.
HWLOC_DISTANCES_KIND_MEANS_BANDWIDTH
Los valores de distancia son similares a los anchos de banda entre objetos. Los valores son más altos para objetos más cercanos, por lo tanto son máximos en la diagonal de la matriz (distancia entre un objeto y sí mismo). Tales valores son actualmente ignorados para el agrupamiento basado en distancias.
HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES
Esta estructura de distancias cubre objetos de diferentes tipos. Esto puede aplicarse a la estructura 'NVLinkBandwidth' en presencia de un NVSwitch o puerto NVLink de un procesador POWER.

enum hwloc_distances_transform_e

Transformaciones de estructuras de distancias.

Enumerador

HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL
Eliminar objetos NULL de la estructura de distancias. Cada objeto que fue reemplazado con NULL en el array objs es eliminado y el array values es actualizado en consecuencia.

Al menos 2 objetos deben permanecer, de lo contrario hwloc_distances_transform() devolverá -1 con errno establecido a EINVAL.

kind será actualizado con o sin HWLOC_DISTANCES_KIND_HETEROGENEOUS_TYPES de acuerdo con los objetos restantes.

HWLOC_DISTANCES_TRANSFORM_LINKS
Reemplazar los valores de ancho de banda con un número de enlaces. Usualmente todos los valores serán o bien 0 (sin enlace) o 1 (un enlace). Sin embargo, algunas matrices podrían obtener valores más grandes si algunos pares de pares están conectados por diferentes números de enlaces.

Los valores en la diagonal se establecen a 0.

Esta transformación solo se aplica a matrices de ancho de banda.

HWLOC_DISTANCES_TRANSFORM_MERGE_SWITCH_PORTS
Fusionar conmutadores con múltiples puertos en un solo objeto. Esto actualmente solo se aplica a NVSwitches donde las GPUs parecen estar conectadas a diferentes puertos del conmutador. Los puertos del conmutador deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

Esta transformación reemplazará todos los puertos con solo el primero, ahora conectado a todas las GPUs. Los otros puertos son eliminados aplicando HWLOC_DISTANCES_TRANSFORM_REMOVE_NULL internamente.

HWLOC_DISTANCES_TRANSFORM_TRANSITIVE_CLOSURE
Aplicar un cierre transitivo a la matriz para conectar objetos a través de conmutadores. Todos los pares de GPUs serán reportados como directamente conectados en lugar de GPUs que solo están conectadas a conmutadores.

Los puertos del conmutador deben ser objetos con el subtipo 'NVSwitch' como en la matriz NVLinkBandwidth.

Documentación de Funciones

int hwloc_distances_get (hwloc_topology_t topology, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Recuperar matrices de distancia. Recuperar matrices de distancia de la topología en el array distances .

flags no se usa actualmente, debe ser 0.

kind sirve como un filtro. Si es 0, se devuelven todas las matrices de distancia. Si contiene algún HWLOC_DISTANCES_KIND_FROM_*, solo se devuelven las matrices de distancia cuyo tipo coincida con uno de estos. Si contiene algún HWLOC_DISTANCES_KIND_MEANS_*, solo se devuelven las matrices de distancia cuyo tipo coincida con uno de estos.

En la entrada, nr apunta al número de matrices de distancia que pueden ser almacenadas en distances. En la salida, nr apunta al número de matrices de distancia que fueron realmente encontradas, incluso si algunas de ellas no pudieron ser almacenadas en distances. Las matrices de distancia que no pudieron ser almacenadas son ignoradas hwloc(7) — HWLOC_DISTANCES_KIND_MEANS_LATENCY

Description

The Hardware Locality (hwloc) data structure provides a way to get distances between objects of the same type. For example, it can report the latency between NUMA nodes, or the bandwidth between PCI devices.

The distances are described by the struct hwloc_distances_s structure.

  • linesize and nblines define the dimensions of the distance matrix. The number of objects for which distances are given is nblines.
  • objs is an array of pointers to objects. The indices of this array correspond to the rows and columns of the distance matrix. For example, distances->objs[i] is the object corresponding to the i-th row and i-th column of the distance matrix. The number of elements in this array is nblines.
  • values is an array of integers representing the distance matrix. distances->values[i * linesize + j] contains the distance between distances->objs[i] and distances->objs[j]. The value is 0 if i == j. The number of elements in this array is nblines * linesize.
  • kind indicates the meaning of the distances (latency, bandwidth, etc.). It is a bitmask of values from the hwloc_distances_kind_e enumeration. For example, HWLOC_DISTANCES_KIND_MEANS_LATENCY indicates latency.
  • flags is a bitmask of flags.
  • bridge is an optional bridge object if the distances were exported via a bridge.

The hwloc_distances_get() function retrieves all distance matrices. The nr argument will be filled with the number of distance structures found. The distances argument will be filled with an array of pointers to struct hwloc_distances_s structures.

The kind argument filters the requested distance matrices. Only matrices whose kind member is compatible with the requested kind will be returned. For example, passing HWLOC_DISTANCES_KIND_MEANS_LATENCY will return only latency matrices.

The flags argument is reserved and must be set to 0.

If the caller is only interested in a specific type of distance, like latency, it is recommended to check if the desired kind is available using hwloc_distances_get_kind().

The hwloc_distances_get_by_depth(), hwloc_distances_get_by_name() and hwloc_distances_get_by_type() functions are variants of hwloc_distances_get() that filter the results based on depth, name or object type respectively.

hwloc_distances_get_by_depth() retrieves distance matrices for objects at a specific depth. The special value HWLOC_TYPE_DEPTH_BRIDGE can be used to get distances between bridges.

hwloc_distances_get_by_name() retrieves distance matrices matching the given name. The most common name is "NUMALatency".

hwloc_distances_get_by_type() retrieves distance matrices for objects of a specific type.

The hwloc_distances_get_name() function returns a string describing the contents of a distance structure. For example, it might return "NUMALatency".

The hwloc_distances_release() function releases a distance matrix structure previously returned by one of the hwloc_distances_get*() functions. The caller must call this function for each structure obtained.

The hwloc_distances_transform() function applies a transformation to a distance structure. This function can be used to modify the distances or the objects they relate to. The available transformations are defined in the hwloc_distances_transform_e enumeration.

The transform_attr argument is currently unused and must be NULL. The flags argument is also unused and must be 0.

It is possible that a distance matrix is returned, but the value of nr remains 0. This can happen if the underlying system provides distance information, but it's not structured in a way that hwloc can directly use. In such cases, the caller should check the returned nr value and compare it to the initial value before the function call to determine if any distances were actually retrieved. The caller may find out by comparing the value pointed by nr before and after the function call.

Each distance matrix returned in the distances array should be released by the caller using hwloc_distances_release().

Returns

0 on success, -1 on error.

0 on success, -1 on error.

int hwloc_distances_get_by_name (hwloc_topology_t topology, const char * name, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long flags)

Retrieve a distance matrix with the given name. Usually only one distances structure may match a given name.

The name of the most common structure is 'NUMALatency'. Others include 'XGMIBandwidth', 'XGMIHops', 'XeLinkBandwidth', and 'NVLinkBandwidth'.

Returns

0 on success, -1 on error.

int hwloc_distances_get_by_type (hwloc_topology_t topology, hwloc_obj_type_t type, unsigned * nr, struct hwloc_distances_s ** distances, unsigned long kind, unsigned long flags)

Retrieve distance matrices for object of a specific type. Identical to hwloc_distances_get() with the additional type filter.

Returns

0 on success, -1 on error.

const char * hwloc_distances_get_name (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Get a description of what a distances structure contains. For instance 'NUMALatency' for hardware-provided NUMA distances (ACPI SLIT), or NULL if unknown.

Returns

the constant string with the name of the distance structure.

Note

The returned name should not be freed by the caller, it belongs to the hwloc library.

void hwloc_distances_release (hwloc_topology_t topology, struct hwloc_distances_s * distances)

Release a distance matrix structure previously returned by hwloc_distances_get().

Note

This function is not required if the structure is removed with hwloc_distances_release_remove().

int hwloc_distances_transform (hwloc_topology_t topology, struct hwloc_distances_s * distances, enum hwloc_distances_transform_e transform, void * transform_attr, unsigned long flags)

Apply a transformation to a distances structure. Modify a distances structure that was previously obtained with hwloc_distances_get() or one of its variants.

This modifies the local copy of the distances structures but does not modify the distances information stored inside the topology (retrieved by another call to hwloc_distances_get() or exported to XML). To do so, one should add a new distances structure with same name, kind, objects and values (see Add distances between objects) and then remove this old one with hwloc_distances_release_remove().

transform must be one of the transformations listed in hwloc_distances_transform_e.

These transformations may modify the contents of the objs or values arrays.

transform_attr must be NULL for now.

flags must be 0 for now.

Returns

0 on success, -1 on error for instance if flags are invalid.

Note

Objects in distances array objs may be directly modified in place without using hwloc_distances_transform(). One may use hwloc_get_obj_with_same_locality() to easily convert between similar objects of different types.
