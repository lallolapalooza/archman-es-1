HTTP::Headers::Util(3) Documentación de contribución de usuarios de Perl HTTP::Headers::Util(3)

SINÓPSIS

use HTTP::Headers::Util qw(split_header_words);
@values = split_header_words($h->header("Content-Type"));

DESCRIPCIÓN

Este módulo proporciona algunas funciones que ayudan a analizar y construir valores de cabecera HTTP válidos. Ninguna de las funciones se exporta por defecto.

Las siguientes funciones están disponibles:

split_header_words( @header_values )
Esta función analizará los valores de cabecera proporcionados como argumento en una lista de arrays anónimos que contienen pares clave/valor. La función sabe cómo manejar ",", ";" y "=", así como valores entre comillas después de "=". Una lista de tokens separados por espacios se analiza como si estuvieran separados por ";".

Si el @header_values pasado como argumento contiene múltiples valores, se tratan como si fueran un solo valor separado por coma ",".

Esto significa que esta función es útil para analizar campos de cabecera que siguen esta sintaxis (BNF de la especificación HTTP/1.1, pero relajamos el requisito para los tokens).

headers           = #header
header            = (token | parameter) *( [";"] (token | parameter))
token             = 1*<cualquier CHAR excepto CTLs o separadores>
separators        = "(" | ")" | "<" | ">" | "@"
                  | "," | ";" | ":" | "\" | <">
                  | "/" | "[" | "]" | "?" | "="
                  | "{" | "}" | SP | HT
quoted-string     = ( <"> *(qdtext | quoted-pair ) <"> )
qdtext            = <cualquier TEXT excepto <">>
quoted-pair       = "\" CHAR
parameter         = attribute "=" value
attribute         = token
value             = token | quoted-string

Cada *header* se representa mediante un array anónimo de pares clave/valor. Todas las claves se forzarán a minúsculas. El valor de un token simple (que no forma parte de un parámetro) es "undef". Las cabeceras sintácticamente incorrectas no se analizarán necesariamente como usted desearía.

Es más fácil de describir con algunos ejemplos:

split_header_words('foo="bar"; port="80,81"; DISCARD, BAR=baz');
split_header_words('text/html; charset="iso-8859-1"');
split_header_words('Basic realm="\\"foo\\\\bar\\""');

devolverá

[foo=>'bar', port=>'80,81', discard=> undef], [bar=>'baz' ]
['text/html' => undef, charset => 'iso-8859-1']
[basic => undef, realm => "\"foo\\bar\""]

Si no desea que la función convierta los tokens y los nombres de atributo a minúsculas, puede llamarla como "_split_header_words" en su lugar (con un guion bajo inicial).

join_header_words( @arrays )
Esto hará lo contrario de la conversión realizada por split_header_words(). Toma una lista de arrays anónimos como argumentos (o una lista de pares clave/valor) y produce un único valor de cabecera. Los valores de los atributos se entrecomillan si es necesario.

Ejemplo:

join_header_words(["text/plain" => undef, charset => "iso-8859/1"]);
join_header_words("text/plain" => undef, charset => "iso-8859/1");

ambos devolverán la cadena:

text/plain; charset="iso-8859/1"
