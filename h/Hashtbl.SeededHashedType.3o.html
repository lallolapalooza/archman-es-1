val seeded_hash : int -> t -> int

Una función hash con semilla sobre las claves. El primer argumento es la semilla. Debe cumplirse que si equal x y es verdadero, entonces seeded_hash seed x = seeded_hash seed y para cualquier valor de seed. Una opción adecuada para seeded_hash es la función Hashtbl.seeded_hash a continuación.
