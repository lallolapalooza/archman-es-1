HMAC(3ssl)

Paquete: openssl

Licencias: Apache-2.0

HMAC(3ssl) OpenSSL HMAC(3ssl)

NOMBRE

HMAC, HMAC_CTX_new, HMAC_CTX_reset, HMAC_CTX_free, HMAC_Init, HMAC_Init_ex, HMAC_Update, HMAC_Final, HMAC_CTX_copy, HMAC_CTX_set_flags, HMAC_CTX_get_md, HMAC_size - Código de autenticación de mensajes HMAC

SINOPSIS

#include <openssl/hmac.h>
unsigned char *HMAC(const EVP_MD *evp_md, const void *key, int key_len,
                    const unsigned char *data, size_t data_len,
                    unsigned char *md, unsigned int *md_len);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

HMAC_CTX *HMAC_CTX_new(void);
int HMAC_CTX_reset(HMAC_CTX *ctx);
int HMAC_Init_ex(HMAC_CTX *ctx, const void *key, int key_len,
                 const EVP_MD *md, ENGINE *impl);
int HMAC_Update(HMAC_CTX *ctx, const unsigned char *data, size_t len);
int HMAC_Final(HMAC_CTX *ctx, unsigned char *md, unsigned int *len);
void HMAC_CTX_free(HMAC_CTX *ctx);
int HMAC_CTX_copy(HMAC_CTX *dctx, HMAC_CTX *sctx);
void HMAC_CTX_set_flags(HMAC_CTX *ctx, unsigned long flags);
const EVP_MD *HMAC_CTX_get_md(const HMAC_CTX *ctx);
size_t HMAC_size(const HMAC_CTX *e);

La siguiente función ha sido marcada como obsoleta desde OpenSSL 1.1.0, y puede ser oculta completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int HMAC_Init(HMAC_CTX *ctx, const void *key, int key_len,
              const EVP_MD *md);

DESCRIPCIÓN

HMAC es un MAC (código de autenticación de mensajes), es decir, una función hash cifrada utilizada para la autenticación de mensajes, que se basa en una función hash.

HMAC() calcula el código de autenticación de mensajes de los data_len bytes en data utilizando la función hash evp_md y la clave key que tiene una longitud de key_len bytes. La key también puede ser NULL con key_len igual a 0.

Coloca el resultado en md (que debe tener espacio para la salida de la función hash, que no supera los EVP_MAX_MD_SIZE bytes). Si md es NULL, el resumen se coloca en una matriz estática. El tamaño de la salida se coloca en md_len, a menos que sea NULL. Nota: pasar un valor NULL para md para usar la matriz estática no es seguro para hilos.

evp_md es un resumen de mensaje como EVP_sha1(), EVP_ripemd160(), etc. HMAC no admite resúmenes de longitud de salida variable como EVP_shake128() y EVP_shake256().

HMAC() utiliza el OSSL_LIB_CTX predeterminado. Utilice EVP_Q_mac(3) en su lugar si se requiere un contexto de biblioteca.

Todas las funciones descritas a continuación están obsoletas. Las aplicaciones deberían usar en su lugar EVP_MAC_CTX_new(3), EVP_MAC_CTX_free(3), EVP_MAC_init(3), EVP_MAC_update(3) y EVP_MAC_final(3) o la función MAC "rápida" de un solo disparo EVP_Q_mac(3).

HMAC_CTX_new() crea un nuevo HMAC_CTX en memoria del montón.

HMAC_CTX_reset() borra un HMAC_CTX existente y los recursos asociados, haciéndolo adecuado para nuevos cálculos como si fuera recién creado con HMAC_CTX_new().

HMAC_CTX_free() borra la clave y otros datos del HMAC_CTX, libera cualquier recurso asociado y finalmente libera el propio HMAC_CTX. Si el argumento es NULL, no se hace nada.

Las siguientes funciones pueden ser utilizadas si el mensaje no está completamente almacenado en memoria:

HMAC_Init_ex() inicializa o reutiliza una estructura HMAC_CTX para usar la función hash evp_md y la clave key. Si ambos son NULL, o si key es NULL y evp_md es el mismo que la llamada anterior, entonces se reutiliza la clave existente. ctx debe haber sido creado con HMAC_CTX_new() antes del primer uso de un HMAC_CTX en esta función.

Si HMAC_Init_ex() se llama con key NULL y evp_md no es el mismo que el resumen anterior utilizado por ctx, entonces se devuelve un error porque la reutilización de una clave existente con un resumen diferente no está soportada.

HMAC_Init() inicializa una estructura HMAC_CTX para usar la función hash evp_md y la clave key que tiene key_len bytes de longitud.

HMAC_Update() puede ser llamado repetidamente con fragmentos del mensaje a autenticar (len bytes en data).

HMAC_Final() coloca el código de autenticación de mensajes en md, que debe tener espacio para la salida de la función hash.

HMAC_CTX_copy() copia todo el estado interno de sctx a dctx.

HMAC_CTX_set_flags() aplica las banderas especificadas a los EVP_MD_CTX internos. Estas banderas tienen el mismo significado que para EVP_MD_CTX_set_flags(3).

HMAC_CTX_get_md() devuelve el EVP_MD que se ha establecido previamente para el HMAC_CTX suministrado.

HMAC_size() devuelve la longitud en bytes de la salida de la función hash subyacente.

VALORES DE RETORNO

HMAC() devuelve un puntero al código de autenticación de mensajes o NULL si ocurrió un error.

HMAC_CTX_new() devuelve un puntero a un nuevo HMAC_CTX en caso de éxito o NULL si ocurrió un error.

HMAC_CTX_reset(), HMAC_Init_ex(), HMAC_Update(), HMAC_Final() y HMAC_CTX_copy() devuelven 1 en caso de éxito o 0 si ocurrió un error.

HMAC_CTX_get_md() devuelve el EVP_MD previamente establecido para el HMAC_CTX suministrado o NULL si no se ha establecido ningún EVP_MD.

HMAC_size() devuelve la longitud en bytes de la salida de la función hash subyacente o cero en caso de error.

CONFORMIDAD

RFC 2104

VER TAMBIÉN

HISTORIA

Todas las funciones excepto HMAC() fueron marcadas como obsoletas en OpenSSL 3.0.

HMAC_CTX_init() fue reemplazada por HMAC_CTX_reset() en OpenSSL 1.1.0.

HMAC_CTX_cleanup() existió en OpenSSL antes de la versión 1.1.0.

HMAC_CTX_new(), HMAC_CTX_free() y HMAC_CTX_get_md() son nuevas en OpenSSL 1.1.0.

HMAC_Init_ex(), HMAC_Update() y HMAC_Final() no devolvían valores en OpenSSL antes de la versión 1.0.0.
