HTTP::Date(3) Documentación de Contribución de Usuarios de Perl HTTP::Date(3)

NOMBRE

HTTP::Date - HTTP::Date - Rutinas de conversión de fechas

VERSIÓN

versión 6.06

SINOPSIS

use HTTP::Date;
$string = time2str($time);    # Formatear como hora ASCII GMT
$time = str2time($string);    # Convertir fecha ASCII a hora de máquina

DESCRIPCIÓN

Este módulo proporciona funciones que manejan los formatos de fecha utilizados por el protocolo HTTP (y algunos más). Solo las dos primeras funciones, time2str() y str2time(), se exportan por defecto.

time2str( [$tiempo] )
La función time2str() convierte una hora de máquina (segundos desde la época) en una cadena. Si la función se llama sin argumentos o con un argumento indefinido, utilizará la hora actual.

La cadena devuelta está en el formato preferido para el protocolo HTTP. Es un subconjunto de longitud fija del formato definido por RFC 1123, representado en Tiempo Universal (GMT). Un ejemplo de marca de tiempo en este formato es:

Dom, 06 Nov 1994 08:49:37 GMT
str2time( $cadena [, $zona] )
La función str2time() convierte una cadena en hora de máquina. Devuelve "undef" si el formato de $cadena no es reconocido, de lo contrario, lo que sea que las funciones de "Time::Local" puedan deducir de la fecha analizada. Las fechas anteriores a la época del sistema pueden no funcionar en todos los sistemas operativos. Los formatos de fecha reconocidos son los mismos que para parse_date().

La función también toma un segundo argumento opcional que especifica la zona horaria predeterminada a usar al convertir la fecha. Este parámetro se ignora si la zona se encuentra en la propia cadena de fecha. Si este parámetro falta y el formato de la cadena de fecha no contiene ninguna especificación de zona, se asume la zona horaria local.

Si la zona no es ""GMT"" o numérica (como "-0800" o "+0100"), entonces el módulo "Time::Zone" debe estar instalado para que se reconozca la fecha.

parse_date( $cadena )
Esta función intentará analizar una cadena de fecha y luego la devolverá como una lista de valores numéricos seguida de un especificador de zona horaria (posiblemente indefinido); ($año, $mes, $dia, $hora, $min, $seg, $tz). El $año será el año completo de 4 dígitos y los números de $mes comienzan con 1 (para enero).

En contexto escalar, los números se interpolan en una cadena del formato "YYYY-MM-DD hh:mm:ss TZ" y se devuelven.

Si la fecha no se reconoce, se devuelve la lista vacía ("undef" en contexto escalar).

La función es capaz de analizar los siguientes formatos:

"Mié, 09 Feb 1994 22:23:32 GMT"       -- formato HTTP
"Jue Feb  3 17:03:55 GMT 1994"        -- formato ctime(3)
"Jue Feb  3 00:00:00 1994",           -- formato ANSI C asctime()
"Martes, 08-Feb-94 14:15:29 GMT"     -- formato antiguo rfc850 HTTP
"Martes, 08-Feb-1994 14:15:29 GMT"   -- formato rfc850 HTTP roto
"03/Feb/1994:17:03:55 -0700"   -- formato de log común
"09 Feb 1994 22:23:32 GMT"     -- formato HTTP (sin día de la semana)
"08-Feb-94 14:15:29 GMT"       -- formato rfc850 (sin día de la semana)
"08-Feb-1994 14:15:29 GMT"     -- formato rfc850 roto (sin día de la semana)
"1994-02-03 14:15:29 -0100"    -- formato ISO 8601
"1994-02-03 14:15:29"          -- la zona es opcional
"1994-02-03"                   -- solo fecha
"1994-02-03T14:15:29"          -- Usar T como separador
"19940203T141529Z"             -- formato compacto ISO 8601
"19940203"                     -- solo fecha
"08-Feb-94"         -- formato antiguo rfc850 HTTP    (sin día de la semana, sin hora)
"08-Feb-1994"       -- formato rfc850 roto (sin día de la semana, sin hora)
"09 Feb 1994"       -- formato HTTP nuevo propuesto  (sin día de la semana, sin hora)
"03/Feb/1994"       -- formato de log común     (sin hora, sin desplazamiento)
"Feb  3  1994"      -- formato Unix 'ls -l'
"Feb  3 17:03"      -- formato Unix 'ls -l'
"11-15-96  03:52PM"   -- formato Windows 'dir'
"11-15-1996  03:52PM" -- formato Windows 'dir' con año de cuatro dígitos

El analizador ignora los espacios en blanco al principio y al final. También permite que los segundos falten y que el mes sea numérico en la mayoría de los formatos.

Si falta el año, asumimos que la fecha es la primera fecha coincidente *antes* del mes actual. Si el año se proporciona con solo 2 dígitos, parse_date() seleccionará el siglo que haga que el año sea lo más cercano posible a la fecha actual.

time2iso( [$tiempo] )
Igual que time2str(), pero devuelve una cadena con formato "YYYY-MM-DD hh:mm:ss" que representa la hora en la zona horaria local.
time2isoz( [$tiempo] )
Igual que time2str(), pero devuelve una cadena con formato "YYYY-MM-DD hh:mm:ssZ" que representa el Tiempo Universal.
