HWLOC_DISTANCES_ADD_FLAG_GROUP(3)

NOMBRE

HWLOC_DISTANCES_ADD_FLAG_GROUP - Añade un grupo a las distancias.

SINAPSIS

#include <hwloc.h>

int hwloc_distances_add_flag_group(hwloc_distances_t distances, unsigned long long flags, hwloc_obj_t domain, ...);

Descripción Detallada

La función hwloc_distances_add_flag_group añade un grupo de objetos al conjunto de distancias especificado por el parámetro distances. Los objetos que pertenecen al nuevo grupo se indican mediante el parámetro domain y los argumentos posteriores. Las banderas especificadas en el parámetro flags modifican el comportamiento de la adición del grupo.

Este grupo se utiliza para agrupar objetos que se consideran cercanos o que tienen una relación de distancia particular. Por ejemplo, se puede utilizar para agrupar todos los núcleos de un mismo socket o todos los sockets de un mismo nodo NUMA.

Documentación de Funciones

int hwloc_distances_add_flag_group(hwloc_distances_t distances, unsigned long long flags, hwloc_obj_t domain, ...)
Añade un grupo de objetos al conjunto de distancias especificado.
  • distances: Puntero al conjunto de distancias.
  • flags: Banderas que modifican el comportamiento de la adición del grupo. Las banderas disponibles son:
    • HWLOC_DISTANCES_ADD_FLAG_GROUP: Indica que se está añadiendo un grupo.
    • HWLOC_DISTANCES_ADD_FLAG_REPLACE: Reemplaza un grupo existente si ya existe uno con la misma configuración.
    • HWLOC_DISTANCES_ADD_FLAG_REMOVE: Elimina un grupo existente.
  • domain: El primer objeto del dominio que se va a añadir al grupo.
  • ...: Lista variable de objetos que también se añadirán al grupo. Se termina con NULL.

Devuelve 0 en caso de éxito y un valor negativo en caso de error.
