DESCRIPCIÓ

N

Si desea "limpiar" o "sanitizar" la entrada HTML de una manera fiable y flexible, entonces este módulo es para

usted.

No estaba satisfecho con HTML::Sanitizer porque está basa

do en HTML::TreeBuilder, así que pensé en escribir al
go similar que trabaje directamente con HTML::Parser.

Actualiza un conjunto de reglas de atributos. Cada regla puede ser 1/0, una expresión regular o un callback. Los valores con una longitud mayor a 1 carácter son tratados como regexps. ¿Cómo

funciona?

Cuando se encuentra una etiqueta, HTML::Scrubber permite/deniega la etiqueta usando la regla explícita si existe

alguna.

Si no existe una regla explícita, Scrubber aplica la regla

predeterminada.

Si existe una regla explícita, pero es una regla simple rule(1), entonces se aplica la regla de atributos

predeterminada.

#!/usr/bin/perl -w
use HTML::Scrubber;
use strict;
my @allow = qw[ br hr b a ];
my @rules = (
    script => 0,
    img    => {
        src => qr{^(?!http://)}i,    # solo se permiten enlaces de imagen relativos
        alt => 1,                    # atributo alt permitido
        '*' => 0,                    # denegar todos los demás atributos
    },
);
my @default = (
    0 =>                             # regla predeterminada, denegar todas las etiquetas
        {
        '*'    => 1,                             # regla predeterminada, permitir todos los atributos
        'href' => qr{^(?:http|https|ftp)://}i,
        'src'  => qr{^(?:http|https|ftp)://}i,
        #   Si su perl no tiene qr
        #   simplemente use una cadena con longitud mayor a 1
        'cite'        => '(?i-xsm:^(?:http|https|ftp):)',
        'language'    => 0,
        'name'        => 1,                                 # podría ser tramposo, pero bueno ;)
        'onblur'      => 0,
        'onchange'    => 0,
        'onclick'     => 0,
        'ondblclick'  => 0,
        'onerror'     => 0,
        'onfocus'     => 0,
        'onkeydown'   => 0,
        'onkeypress'  => 0,
        'onkeyup'     => 0,
        'onload'      => 0,
        'onmousedown' => 0,
        'onmousemove' => 0,
        'onmouseout'  => 0,
        'onmouseover' => 0,
        'onmouseup'   => 0,
        'onreset'     => 0,
        'onselect'    => 0,
        'onsubmit'    => 0,
        'onunload'    => 0,
        'src'         => 0,
        'type'        => 0,
        }
);
my $scrubber = HTML::Scrubber->new();
$scrubber->allow(@allow);
$scrubber->rules(@rules);    # pares clave/valor
$scrubber->default(@default);
$scrubber->comment(1);       # 1 permitir, 0 denegar

    comment => 1,
    process => 0,
);
require Data::Dumper, die Data::Dumper::Dumper($scrubber) if @ARGV;

REQUISITOS DE

VERSIÓN

A partir de la versión 0.14 he añadido un requisito de versión mínima de perl de 5.8. Esto se debe básicamente a fallos en las instalaciones de perl 5.6 de los "smokers" - lo que parece deberse a mecanismos de instalación y

requisitos.

Dado que no quiero dedicar tiempo a soportar una versión tan antigua (y que puede no funcionar por razones relacionadas con el soporte UTF, etc.), he añadido un "use 5.008;" al módulo

principal.

Si esto es problemático, estoy muy dispuesto a aceptar parches par

a solucionarlo, aunque personalmente no veo una buena razón p
ara soportar una versión que ha quedado obsoleta hace 13 años.
