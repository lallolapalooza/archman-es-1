DESCRIPCIÓN

Existe una macro equivalente para cada llamada a función. Dado que las formas de macro a veces son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones JudyL. Consulte JudyL(3) para obtener más información. Las definiciones de llamadas a funciones se incluyen aquí por completitud.

Una de las dificultades al usar las llamadas a funciones JudyL radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, debe pasar la dirección del puntero en lugar del puntero en sí. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones JudyL tienen un parámetro adicional además de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error o NULL (en cuyo caso no se devuelve la información detallada del error).

En las siguientes descripciones, las funciones se describen en términos de cómo las utilizan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros después de que su programa haya sido completamente depurado. Cuando la macro JUDYERROR_NOTEST no está especificada, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.

NAME

JudyLNextEmpty - Return the index of the next empty slot in a JudyL array

SYNOPSIS

Word_t JudyLNextEmpty( JudyLArray_t ArrayHandle, Word_t Index, Word_t Granularity );

DESCRIPTION

JudyLNextEmpty() returns the index of the next empty slot in the Judy array identified by ArrayHandle. The search starts at Index and proceeds in increments of Granularity. If the array is empty, 0 is returned.

The Judy array ArrayHandle must be initialized with JudyLNew() before calling JudyLNextEmpty().

If Index is 0 and Granularity is 1, JudyLNextEmpty() will return the first empty slot found.

If Index is greater than the maximum index in the array and Granularity is 1, JudyLNextEmpty() will return Index.

If Granularity is greater than 1, JudyLNextEmpty() returns the smallest index i such that i >= Index, i is a multiple of Granularity, and the slot i is empty.

An empty slot is a slot that has never been assigned a value. Slots that have been assigned a value and then unset are not considered empty.

The return value is the index of the next empty slot, or (Word_t)-1 if no empty slot is found within the range of Word_t.

Note: The Judy array implementation uses a variety of data structures that are very efficient for sparse data. The term "empty" refers to a slot that has not been explicitly assigned a value by the user. Therefore, Judy arrays do not have a fixed size, and indices do not necessarily correspond to contiguous memory locations.

The return type is Word_t, which is an unsigned integer type wide enough to hold a pointer on the target architecture. This allows for very large indices.

The `void *` type is used to store arbitrary data. The use of `void_t`, which can be passed by value to functions that take `Pcvoid_t` (constant `Pvoid_t`), and also by address to functions that take `PPvoid_t`.

The return type from most JudyL functions is `PPvoid_t` so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a `Word_t *` when a pointer to a Value is required instead of a pointer to a pointer.

NOMBRE

JudyLNextEmpty - Devuelve el índice de la siguiente ranura vacía en un array JudyL

SINOPSIS

Word_t JudyLNextEmpty( JudyLArray_t ArrayHandle, Word_t Index, Word_t Granularity );

DESCRIPCIÓN

JudyLNextEmpty() devuelve el índice de la siguiente ranura vacía en el array Judy identificado por ArrayHandle. La búsqueda comienza en Index y procede en incrementos de Granularity. Si el array está vacío, se devuelve 0.

El array Judy ArrayHandle debe inicializarse con JudyLNew() antes de llamar a JudyLNextEmpty().

Si Index es 0 y Granularity es 1, JudyLNextEmpty() devolverá la primera ranura vacía encontrada.

Si Index es mayor que el índice máximo en el array y Granularity es 1, JudyLNextEmpty() devolverá Index.

Si Granularity es mayor que 1, JudyLNextEmpty() devuelve el índice más pequeño i tal que i >= Index, i es un múltiplo de Granularity, y la ranura i está vacía.

Una ranura vacía es una ranura a la que nunca se le ha asignado un valor. Las ranuras a las que se les ha asignado un valor y luego se han desasignado no se consideran vacías.

El valor de retorno es el índice de la siguiente ranura vacía, o (Word_t)-1 si no se encuentra ninguna ranura vacía dentro del rango de Word_t.

Nota: La implementación del array Judy utiliza una variedad de estructuras de datos que son muy eficientes para datos dispersos. El término "vacío" se refiere a una ranura que no ha sido asignada explícitamente un valor por el usuario. Por lo tanto, los arrays Judy no tienen un tamaño fijo, y los índices no corresponden necesariamente a ubicaciones de memoria contiguas.

El tipo de retorno es Word_t, que es un tipo entero sin signo lo suficientemente ancho como para contener un puntero en la arquitectura de destino. Esto permite índices muy grandes.

El tipo `void *` se utiliza para almacenar datos arbitrarios. El uso de `void_t`, que puede pasarse por valor a funciones que toman `Pcvoid_t` (constante `Pvoid_t`), y también por dirección a funciones que toman `PPvoid_t`.

El tipo de retorno de la mayoría de las funciones JudyL es `PPvoid_t` para que los valores almacenados en el array puedan ser punteros a otros objetos, lo cual es un uso típico, o se conviertan a un `Word_t *` cuando se requiere un puntero a un Value en lugar de un puntero a un puntero.
