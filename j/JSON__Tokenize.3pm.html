NOMBRE

JSON::Tokenize - Tokenizar JSON

SINOPSIS

use JSON::Tokenize ':all';

my $input = '{"tuttie":["fruity", true, 100]}';
my $token = tokenize_json ($input);
print_tokens ($token, 0);

sub print_tokens
{
    my ($token, $depth) = @_;
    while ($token) {
        my $start = tokenize_start ($token);
        my $end = tokenize_end ($token);
        my $type = tokenize_type ($token);
        print "   " x $depth;
        my $value = substr ($input, $start, $end - $start);
        print "'$value' tiene el tipo '$type'.\n";
        my $child = tokenize_child ($token);
        if ($child) {
            print_tokens ($child, $depth+1);
        }
        my $next = tokenize_next ($token);
        $token = $next;
    }
}

Esto produce la siguiente salida:

'{"tuttie":["fruity", true, 100]}' tiene el tipo 'object'.
   '"tuttie"' tiene el tipo 'string'.
   ':' tiene el tipo 'colon'.
   '["fruity", true, 100]' tiene el tipo 'array'.
      '"fruity"' tiene el tipo 'string'.
      ',' tiene el tipo 'comma'.
      'true' tiene el tipo 'literal'.
      ',' tiene el tipo 'comma'.
      '100' tiene el tipo 'number'.

DESCRIPCIÓN

Este es un módulo para tokenizar una cadena JSON. "Tokenizar" significa dividir la cadena en tokens individuales, sin crear ninguna estructura de Perl. Utiliza el mismo código subyacente que JSON::Parse. La tokenización se puede usar para tareas como seleccionar o buscar partes de una estructura JSON grande sin almacenar cada parte de la estructura completa en memoria.

Este módulo es una parte experimental de JSON::Parse y su interfaz es probable que cambie. Las funciones de tokenización están actualmente escritas de forma muy primitiva.

FUNCIONES

tokenize_child

my $child = tokenize_child ($child);

Recorre el árbol de tokens.

tokenize_end

my $end = tokenize_end ($token);

Obtiene el final del token como un desplazamiento de bytes desde el inicio de la cadena. Tenga en cuenta que es un desplazamiento de bytes, no un desplazamiento de caracteres.

tokenize_json

my $token = tokenize_json ($json);

tokenize_next

my $next = tokenize_next ($token);

Recorre el árbol de tokens.

tokenize_start

my $start = tokenize_start ($token);

Obtiene el inicio del token como un desplazamiento de bytes desde el inicio de la cadena. Tenga en cuenta que es un desplazamiento de bytes, no un desplazamiento de caracteres.

tokenize_text

my $text = tokenize_text ($json, $token);

Dada una token $token de este análisis y el JSON en $json, devuelve el texto que corresponde a la token. Esta es una función de conveniencia escrita en Perl que utiliza "tokenize_start" y "tokenize_end" y "substr" para obtener la cadena de $json.

tokenize_type

my $type = tokenize_type ($token);

Obtiene el tipo de la token como una cadena. Los posibles valores de retorno son:

"array",
"initial state",
"invalid",
"literal",
"number",
"object",
"string",
"unicode escape"
