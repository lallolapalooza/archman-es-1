JudyHSFreeArray.JudyHSFreeArray

Paquete: judy

Licencias: LGPL

JudyHS_funcs(3) Manual de funciones de biblioteca JudyHS_funcs(3)

NOMBRE

Funciones JudyHS - biblioteca C para crear y acceder a un array dinámico, usando un array de bytes de una longitud: Longitud como Índice y una palabra como Valor.

SINOPSIS

PPvoid_t JudyHSIns(PPvoid_t PPJHS, void *Index, Word_t Length, PJError_t PJError);
int      JudyHSDel(PPvoid_t PPJHS, void *Index, Word_t Length, PJError_t PJError);
PPvoid_t JudyHSGet(Pcvoid_t  PJHS, void *Index, Word_t Length, PJError_t PJError);
Word_t   JudyHSFreeArray(PPvoid_t PPJHS, PJError_t PJError);

DESCRIPCIÓN

Existe un equivalente macro para cada llamada a función. Dado que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones JudyHS. Consulte JudyHS(3) para más información. Las definiciones de llamadas a funciones se incluyen aquí para completitud.

Una de las dificultades al usar las llamadas a funciones JudyHS radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudyHS también deben modificar el puntero al array JudyHS, debe pasar la dirección del puntero en lugar del puntero mismo. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten que el compilador detecte errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones JudyHS tienen un parámetro adicional más allá de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error, o NULL (en cuyo caso la información de error no se devuelve, solo PJERR en el parámetro de retorno).

En las siguientes descripciones, las funciones se describen en términos de cómo las usan las macros. Este es el uso sugerido de las macros después de que su programa haya sido completamente depurado. Cuando la macro JUDYERROR_NOTEST no se especifica, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudyHS cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.


JudyHSIns(&PJHS, Index, Length, &JError)
#define JHSI(PValue, PJHS, Index) \
   PValue = JudyLIns(&PJHS, Index, PJE0)

JudyHSDel(&PJHS, Index, Length, &JError)
#define JHSD(Rc_int, PJHS, Index, Length) \
   Rc_int = JudyHSDel(&PJHS, Index, Length, PJE0)

JudyHSGet(PJHS, Index, Length)
#define JHSG(PValue, PJHS, Index, Length) \
   PValue = JudyHSIns(PJHS, Index, Length)

JudyHSFreeArray(&PJHS, &JError)
#define JHSFA(Rc_word, PJHS) \
   Rc_word = JudyHSFreeArray(&PJHS, PJE0)

Las definiciones de todas las funciones Judy, los tipos Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t y PJError_t, las constantes NULL, JU_ERRNO_*, JERR, PPJERR y PJE0 se proporcionan en el archivo de encabezado Judy.h (/usr/include/Judy.h). Nota: Los llamadores deben definir los arrays JudyHS como de tipo Pvoid_t, que puede pasarse por valor a funciones que toman Pcvoid_t (Pvoid_t constante), y también por dirección a funciones que toman PPvoid_t.

El tipo de retorno de la mayoría de las funciones JudyHS es PPvoid_t para que los valores almacenados en el array puedan ser punteros a otros objetos, lo cual es un uso típico, o puedan ser casteados a un Word_t * cuando se requiere un puntero a un valor en lugar de un puntero a un puntero.
