DESCRIPCIÓN

Existe una forma de macro equivalente para cada llamada a función. Dado que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más sencilla que las funciones equivalentes, son la forma preferida de llamar a las funciones JudyL. Consulte JudyL(3) para obtener más información. Las definiciones de las llamadas a funciones se incluyen aquí para su completa referencia.

Una de las dificultades al usar las llamadas a funciones JudyL radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, usted debe pasar la dirección del puntero en lugar del puntero en sí. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones JudyL tienen un parámetro adicional más allá de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error o NULL (en cuyo caso, la información detallada del error no se devuelve).

En las siguientes descripciones, las funciones se describen en términos de cómo las utilizan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros una vez que su programa ha sido completamente depurado. Cuando la macro JUDYERROR_NOTEST no está especificada, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.

JudyL — JudySL array interface for the JudySL array

DESCRIPTION

The JudySL array is a sparse array implementation. The array is keyed by a byte string. The array is sorted by key. The array is composed of 32-bit or 64-bit integers. The application can specify the size of the integers with JudyLAlloc().

JudySLArray **JudySLp is an alias for JudySLArray *JudySL. The JudySL array is passed by value or by reference.

JudyLIns inserts a key/value pair into the JudySL array. The key is specified by Key and KeyLength. The value is specified by Value. If the key is already in the JudySL array, the value is overwritten with the new value. If the key is not in the JudySL array, the key/value pair is inserted.

JudyLGet retrieves the value associated with the key. The key is specified by Key and KeyLength.

JudyLDel deletes the key/value pair from the JudySL array. The key is specified by Key and KeyLength.

JudyLByCount returns the key/value pair at the specified count. The count is zero-based.

JudyLByValue returns the key/value pair with the specified value. If there are multiple keys with the same value, the first one encountered is returned.

JudyLNext returns the next key/value pair in the JudySL array. The key and value are returned by pointer.

JudyLPrev returns the previous key/value pair in the JudySL array. The key and value are returned by pointer.

JudyLLast returns the last key/value pair in the JudySL array. The key and value are returned by pointer.

JudyLFirst returns the first key/value pair in the JudySL array. The key and value are returned by pointer.

JudyLCount returns the number of key/value pairs in the JudySL array.

JudyLFree frees the memory used by the JudySL array. The JudySL array is passed by value.

JudyLAlloc allocates memory for a JudySL array. The size of the array is specified by Example. The size is specified in bytes.

JudyLGetFree returns the amount of free memory in the JudySL array.

JudyLGetUsed returns the amount of used memory in the JudySL array.

JudyLRootSize returns the size of the JudySL array root node.

JudyLKeysToMemory returns the amount of memory used by the keys in the JudySL array.

JudyLValueToMemory returns the amount of memory used by the values in the JudySL array.

JudyLLowerBound returns the key/value pair with the smallest key that is greater than or equal to the specified key.

JudyLUpperBound returns the key/value pair with the largest key that is less than or equal to the specified key.

JudyLNextNew returns the next key/value pair that was not present in the JudySL array the last time the function was called. This is useful for iterating over a subset of the array.

JudyLPrevNew returns the previous key/value pair that was not present in the JudySL array the last time the function was called. This is useful for iterating over a subset of the array.

JudyLLastNew returns the last key/value pair that was not present in the JudySL array the last time the function was called. This is useful for iterating over a subset of the array.

JudyLFirstNew returns the first key/value pair that was not present in the JudySL array the last time the function was called. This is useful for iterating over a subset of the array.

JudyLSearch returns the value associated with the key. If the key is not found, it returns NULL. This is equivalent to JudyLGet.

JudyLStar returns the value associated with the key. If the key is not found, it returns NULL. If the key is a prefix of other keys, it returns the value associated with the key. This is useful for retrieving values associated with keys that are prefixes of other keys.

JudyLStarWalk returns the value associated with the key. If the key is not found, it returns NULL. If the key is a prefix of other keys, it returns the value associated with the key. This is useful for retrieving values associated with keys that are prefixes of other keys. This function is similar to JudyLStar, but it also returns all keys that share the same prefix.

JudyLStarWalkOnce is similar to JudyLStarWalk, but it only returns the value associated with the key. It does not return the keys that share the same prefix.

JudyLQuery returns the value associated with the key. If the key is not found, it returns NULL. This function is similar to JudyLGet, but it also returns the number of keys that match the query.

JudyLQueryMatch returns the number of keys that match the query. The query is specified by Key and KeyLength.

JudyLValueRange returns a JudySL array containing all key/value pairs where the value is within the specified range. The range is specified by MinValue and MaxValue.

JudyLValueRangeNext, JudyLValueRangePrev, JudyLValueRangeLast, and JudyLValueRangeFirst are used to iterate over the JudySL array returned by JudyLValueRange.

JudyLKeyToValue returns the value associated with the key. If the key is not found, it returns NULL. This function is similar to JudyLGet.

JudyLPrefix returns a JudySL array containing all key/value pairs where the key is a prefix of the specified key. The prefix is specified by Key and KeyLength.

JudyLPrefixNext, JudyLPrefixPrev, JudyLPrefixLast, and JudyLPrefixFirst are used to iterate over the JudySL array returned by JudyLPrefix.

The return type from most JudySL functions is PPvoid_t so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a Word_t * when a pointer to a Value is required instead of a pointer to a pointer.
