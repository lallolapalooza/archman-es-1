NOMBRE

Funciones JudySL - Biblioteca de funciones para crear y acceder a un array dinámico, utilizando un índice terminado en nulo (array asociativo)

SINOPSIS

PPvoid_t JudySLIns(      PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
int      JudySLDel(      PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLGet(      Pcvoid_t  PJSLArray, const uint8_t * Index, PJError_t PJError);
Word_t   JudySLFreeArray(PPvoid_t PPJSLArray, PJError_t PJError);
PPvoid_t JudySLFirst(    Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLNext(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLLast(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLPrev(     Pcvoid_t  PJSLArray,       uint8_t * Index, PJError_t PJError);

DESCRIPCIÓN

Existe un equivalente macro para cada llamada a función. Dado que los formularios de macro pueden ser más rápidos y tener una interfaz de manejo de errores más simple que las funciones equivalentes, son el método preferido para llamar a las funciones JudySL. Ver JudySL(3) para más información. Las definiciones de las funciones de llamada se incluyen aquí por completitud.

Una de las dificultades al usar las funciones JudySL es determinar si pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudySL también deben modificar el puntero al array JudySL, debe pasar la dirección del puntero, y no el puntero en sí. Esto a menudo lleva a errores difíciles de depurar en el código programado. En la práctica, las macros permiten a los compiladores detectar errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las funciones JudySL tienen un parámetro adicional que no se especifica en las llamadas macro. Este parámetro es un puntero a una estructura de errores o NULL (en cuyo caso no se devuelve información detallada).

En las descripciones siguientes, las funciones se describen en términos de cómo se utilizan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso recomendado de las macros después de que el programa haya sido completamente depurado. Cuando el macro JUDYERROR_NOTEST no se especifica, se declara una struct de errores que almacena la información de errores devuelta por las funciones JudySL cuando ocurre un error.

Nota: El uso de & en diferentes funciones.


JudySLIns(&PJSLArray, Index, &JError)
#define JSLI(PValue, PJSLArray, Index) \
   PValue = JudyLIns(&PJSLArray, Index, PJE0)

JudySLDel(&PJSLArray, Index, &JError)
#define JSLD(Rc_int, PJSLArray, Index) \
   Rc_int = JudySLDel(&PJSLArray, Index, PJE0)

JudySLGet(PJSLArray, Index, &JError)
#define JSLG(PValue, PJSLArray, Index) \
   PValue = JudySLIns(PJSLArray, Index, PJE0)

JudySLFreeArray(&PJSLArray, &JError)
#define JSLFA(Rc_word, PJSLArray) \
   Rc_word = JudySLFreeArray(&PJSLArray, PJE0)

JudySLFirst(PJSLArray, Index, &JError)
#define JSLF(PValue, PJSLArray, Index) \
   PValue = JudySLFirst(PJSLArray, Index, PJE0)

JudySLNext(PJSLArray, Index, &JError)
#define JSLN(PValue, PJSLArray, Index) \
   PValue = JudySLNext(PJSLArray, Index, PJE0)

JudySLLast(PJSLArray, Index, &JError)
#define JSLL(PValue, PJSLArray, Index) \
   PValue = JudySLLast(PJSLArray, Index, PJE0)

JudySLPrev(PJSLArray, Index, &JError)
#define JSLP(PValue, PJSLArray, Index) \
   PValue = JudySLPrev(PJSLArray, Index, PJE0)

Las definiciones para todas las funciones Judy, los tipos Pvoid_t, Pcvoid_t, PPvoid_t, Word_t , JError_t, y PJError_t, así como las constantes NULL, JU_ERRNO_*, JERR, PPJERR, y PJE0, se proporcionan en el archivo de cabecera Judy.h (/usr/include/Judy.h). Nota: Los llamadores deben definir los arrays JudySL como tipo Pvoid_t, que puede ser pasado por valor a funciones que acepten Pcvoid_t (valor Pvoid_t), y también por dirección a funciones que acepten PPvoid_t).

El tipo de retorno de la mayoría de las funciones JudySL es PPvoid_t, para que los valores almacenados en el array puedan ser punteros a otros objetos, lo cual es una utilización típica, o se puede convertir a Word_t * cuando se requiera un puntero a un valor en lugar de un puntero a un puntero.
