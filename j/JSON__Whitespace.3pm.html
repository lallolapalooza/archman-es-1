NOMBRE

JSON::Whitespace - Alterar el espacio en blanco insignificante de JSON

SINOPSIS

use JSON::Whitespace ':all';

my $in = <<EOF;
{
            "animals":{
                    "kingkong":"🦍"
            },
            "baka":[
                    "ドジ"
            ],
            "fruit":{
                    "grape":"🍇"
            },
            "moons":{
                    "🌑":0
            }
    }
EOF
my $minify = json_minify ($in);
print $minify;

Esto genera la siguiente salida:

{"animals":{"kingkong":"🦍"},"baka":["ドジ"],"fruit":{"grape":"🍇"},"moons":{"🌑":0}}

DESCRIPCIÓN

Este módulo ofrece funciones para manipular la parte de "espacio en blanco insignificante" de una cadena JSON (el espacio en blanco que no está dentro de cadenas). Según la especificación JSON, el "espacio en blanco insignificante" consiste en espacio (%x20), tabulación horizontal (%x09), salto de línea o nueva línea (%x0A) y retorno de carro (%x0D).

FUNCIONES

json_indent

my $indented = json_indent ($json);

Añade indentación a $json.

json_minify

my $minified = json_minify ($json);

Elimina todo el espacio en blanco, incluidas las nuevas líneas finales, de $json.

VER TAMBIÉN

La documentación sobre JSON está en JSON::Parse. JSON::Whitespace se basa en JSON::Tokenize, que divide JSON en tokens sin convertirlo en estructuras de Perl.
