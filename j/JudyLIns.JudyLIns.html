NOMBRE

Funciones JudyL - Biblioteca de funciones para crear y acceder a un array dinámico de palabras, usando cualquier valor de palabra como índice

DESCRIPCIÓN

Existe un equivalente de macro para cada llamada a las funciones. Debido a que las formas de macro son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son el método preferido para llamar a las funciones JudyL. Para obtener más información, véase JudyL(3). Las definiciones de las llamadas a las funciones se incluyen aquí para la completitud.

Una de las dificultades en el uso de las llamadas a las funciones JudyL radica en determinar si pasar un puntero o la dirección de un puntero. Las funciones que modifican el array JudyL deben también modificar el puntero al array JudyL, por lo que debe pasar la dirección del puntero, no el puntero en sí. Esto a menudo lleva a errores difíciles de depurar en el código programado. En la práctica, las macros permiten a los compiladores detectar errores de programación cuando se pasan punteros en lugar de las direcciones de punteros.

Las llamadas a las funciones JudyL tienen un parámetro adicional que no se especifica en las llamadas de macros. Este parámetro es o bien un puntero a una estructura de errores, o NULL (en cuyo caso no se devuelve la información detallada).

En las descripciones siguientes, las funciones se describen en términos de cómo se usan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros después de haber realizado un debug del programa. Cuando el macro JUDYERROR_NOTEST no se especifica, se declara una estructura de errores para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Nota: El símbolo de & en diferentes funciones.

Definiciones para todas las funciones Judy, los tipos Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t, y PJError_t, así como las constantes NULL, JU_ERRNO_*, JERR, PPJERR, y PJE0, se proporcionan en el archivo de cabecera Judy.h (/usr/include/Judy.h). Nota: Los llamadores deben definir los arrays Judy como tipo Pvoid_t.
