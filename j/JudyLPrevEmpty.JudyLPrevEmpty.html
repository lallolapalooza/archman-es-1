DESCRIPCIÓ

N

Existe un macro equivalente para cada llamada a función. Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones JudyL. Véase JudyL(3) para más información. Las definiciones de las llamadas a función se incluyen aquí para

completitud.

Una de las dificultades al usar las llamadas a las funciones JudyL radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, se debe pasar la dirección del puntero en lugar del puntero mismo. Esto a menudo conduce a errores programáticos difíciles de depurar. En la práctica, los macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de

punteros.

Las llamadas a las funciones JudyL tienen un parámetro adicional más allá de los especificados en las llamadas a macro. Este parámetro es o bien un puntero a una estructura de error, o NULL (en cuyo caso la información detallada del error no se devuelve)

.

En las siguientes descripciones, las funciones se describen en términos de cómo los macros las usan (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de los macros después de que su programa haya sido completamente depurado. Cuando el macro JUDYERROR_NOTEST no se especifica, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un

error.

Nótese la colocación del & en las diferentes

funciones.

NAME

JudyLPrevEmpty - Return pointer to the previous JudySL array entry.

SYNOPSIS

 PPvoid_t JudyLPrevEmpty(
    void_t *JudySL
 );

DESCRIPTION

The JudyLPrevEmpty function returns a pointer to the previous JudySL array entry.

If the JudySL array is empty, or if the entry pointed to by JudySL is the first entry, then JudyLPrevEmpty returns (PPvoid_t) 0.

The type PPvoid_t is a pointer to a pointer to a void_t. This is the return type from most JudySL functions, so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a Word_t * when a pointer to a Value is required instead of a pointer to a pointer.

The type void_t is a pointer to a void object. This is the type of the JudySL array itself. It can be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.
