JudySL(3) Manuales de Funciones de la Librería JudySL(3)

NOMBRE

JudySL - Librería de funciones para crear y acceder a un array dinámico, utilizando una cadena nula como un Índice (array asociativo)

SINTAXIS

cc [flags] sourcefiles -lJudy
#include <Judy.h>
#define MAXLINELEN 1000000           // definición máxima de longitud de cadena
Word_t * PValue;                     // valor del elemento del array JudySL
uint8_t  Index[MAXLINELEN];          // cadena
int      Rc_int;                     // valor de retorno
Word_t   Rc_word;                    // valor de retorno completo
Pvoid_t PJSLArray = (Pvoid_t) NULL;  // inicializar array JudySL
JSLI( PValue,  PJSLArray, Index);   // JudySLIns()
JSLD( Rc_int,  PJSLArray, Index);   // JudySLDel()
JSLG( PValue,  PJSLArray, Index);   // JudySLGet()
JSLFA(Rc_word, PJSLArray);          // JudySLFreeArray()
JSLF( PValue,  PJSLArray, Index);   // JudySLFirst()
JSLN( PValue,  PJSLArray, Index);   // JudySLNext()
JSLL( PValue,  PJSLArray, Index);   // JudySLLast()
JSLP( PValue,  PJSLArray, Index);   // JudySLPrev()

DESCRIPCIÓN

Un array JudySL es equivalente a un conjunto ordenado de cadenas, cada una asociada a un Valor (palabra). Un Valor se accede mediante un Índice (clave), que es una cadena nula de cualquier longitud. El espacio de memoria necesario para el array se asigna como pares de índice/valor se insertan, y se libera cuando se eliminan los pares de índice/valor. Esto es un tipo de array asociativo, donde los elementos del array también están ordenados lexicográficamente (en mayúsculas). Esto podría pensarse así:

void * JudySLArray["Toto, I don't think we're in Kansas any more"];

Un array JudySL se aloca con un puntero NULL

Pvoid_t PJSLArray = (Pvoid_t) NULL;
Como con un array ordinario, no hay índices duplicados (cadenas) en un array JudySL.

Usando las macrose descritas aquí, en lugar de las funciones JudySL, el manejo de errores por defecto envía un mensaje a la salida estándard y termina el programa con exit(1).

JSLI(PValue, PJSLArray, Index) // JudySLIns()

Inserta una Índice cadena y Valor en el array JudySL PJSLArray. Si la Índice se inserta correctamente, el Valor se inicializa en 0. Si ya existe el Índice, el Valor no se modifica.

Devuelve PValue apuntando a Valor del Índice. Tu programa debe usar este puntero para modificar el Valor, por ejemplo:

*PValue = 1234;

Nota: JSLI() y JSLD reorganizan el array JudySL. Por lo tanto, los punteros devueltos de anteriores JudySL son inválidos y deben ser reacquiredos.

JSLD(Rc_int, PJSLArray, Index) // JudySLDel()

Elimina el par de índice/valor especificado (elemento del array) de la array JudySL.

Devuelve Rc_int con valor 1 si es exitoso. Si el Índice no estaba presente, devuelve 0.

JSLG(PValue, PJSLArray, Index) // JudySLGet()

Devuelve el puntero a Valor de la Índice.

Devuelve PValue apuntando a Valor de la Índice. Si el Índice no está presente, PValue se setea a NULL.

JSLFA(Rc_word, PJSLArray) // JudySLFreeArray()

Dado un puntero a un array JudySL (PJSLArray), libera el array completo (más rápido que usar JSLN(), JSLD()).

Devuelve Rc_word con valor del número de bytes liberados y PJSLArray setea a NULL.

Funciones de búsqueda JudySL

Las funciones de búsqueda JudySL permiten buscar índices en el array. Puedes buscar inclusivamente o exclusivamente, en direcciones forward o reverse.

Si es exitoso, Índice se devuelve setado a la encontrada, y PValue apunta a Valor de Índice. Si falla, PValue se setea a NULL y Índice no tiene información útil. PValue debe ser probado para no NULL antes de usar Índice, ya que puede fallar una búsqueda.

Nota: Para soportar todos los posibles resultados, el Índice buffer debe ser al menos tan grande como la cadena más larga en el array.

JSLF(PValue, PJSLArray, Index) // JudySLFirst()

Búsqueda (inclusiva) para el primer índice presente que es igual o mayor que el índice pasado. (Empieza con cadena vacía para encontrar el primer índice en el array.) JSLF() es típicamente usado para comenzar un recorrido ordenado de índices válidos en un array JudySL.

uint8_t Index[MAXLINELEN];
strcpy (Index, "");
JSLF(PValue, PJSLArray, Index);

JSLN(PValue, PJSLArray, Index) // JudySLNext()

Búsqueda (exclusiva) para el siguiente índice presente que es mayor que el índice pasado. JSLN() es típicamente usado para continuar un recorrido ordenado de índices válidos en un array JudySL, o para encontrar un "vecino" de un índice dado.

JSLL(PValue, PJSLArray, Index) // JudySLLast()

Búsqueda (inclusiva) para el último índice presente que es igual o menor que el índice pasado. (Empieza con un índice máximo para buscar el último índice en el array, como una cadena de 0xff bytes.) JSLL() es típicamente usado para comenzar un recorrido ordenado inverso de índices válidos en un array JudySL.

JSLP(PValue, PJSLArray, Index) // JudySLPrev()

Búsqueda (exclusiva) para el índice anterior presente que es menor que el índice pasado. JSLP() es típicamente usado para continuar un recorrido ordenado inverso de índices válidos en un array JudySL, o para encontrar un "vecino" de un índice dado.

Ejemplo de una rutina de ordenamiento de cadenas

#include <stdio.h>
#include <Judy.h>
#define MAXLINE 1000000                 // longitud máxima de cadena (línea)
uint8_t   Index[MAXLINE];               // cadena a insertar
int     // Uso:  JudySort < archivo_a_ordenar
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // array JudySL.
    PWord_t   PValue;                   // elemento del array JudySL.
    Word_t    Bytes;                    // tamaño del array JudySL.
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        JSLI(PValue, PJArray, Index);   // insertar cadena en el array
        if (PValue == PJERR)            // si no hay memoria
        {                               // hacer algo
            printf("Malloc falló -- obtener más RAM\n");
            exit(1);
        }
        ++(*PValue);                    // contar instancias de cadena
    }
    Index[0] = '\0';                    // comenzar con la cadena más pequeña.
    JSLF(PValue, PJArray, Index);       // obtener el primer índice
    while (PValue != NULL)
    {
        while ((*PValue)--)             // imprimir duplicados
            printf("%s", Index);
        JSLN(PValue, PJArray, Index);   // obtener el siguiente índice
    }
    JSLFA(Bytes, PJArray);              // liberar el array
    fprintf(stderr, "El array JudySL utilizó %lu bytes de memoria\n", Bytes);
    return (0);
}
    fprintf(stderr, "The JudySL array used %lu bytes of memory\n", Bytes);
    return (0);
}
