JudyL(3) Manual de funciones de la biblioteca JudyL(3)

NOMBRE

Macros de JudyL - biblioteca C para crear y acceder a un array dinámico de palabras, usando una palabra como índice.

SINOPSIS

cc [flags] archivos_fuente -lJudy
#include <Judy.h>
int      Rc_int;                          // código de retorno - entero
Word_t   Rc_word;                         // código de retorno - palabra sin signo
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // puntero al valor de retorno
Pvoid_t  PJLArray = (Pvoid_t) NULL;        // inicializar array JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPCIÓN

Un array JudyL es el equivalente a un array de valores del tamaño de una palabra. Un Valor se aborda mediante un Índice (clave). El array puede ser disperso, y el Índice puede ser cualquier número del tamaño de una palabra. La memoria para soportar el array se asigna a medida que se insertan pares de índice/valor, y se libera a medida que se eliminan pares de índice/valor. Un array JudyL también puede considerarse como un mapeador, es decir, "mapea" una palabra a otra palabra/puntero.

Al igual que con un array normal, no hay índices duplicados en un array JudyL.

El valor puede usarse como un escalar, o como un puntero a una estructura o bloque de datos (o incluso a otro array Judy).

Un array JudyL se asigna con un puntero NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

Utilizando las macros descritas aquí, en lugar de las llamadas a funciones de JudyL, el manejo de errores por defecto envía un mensaje al error estándar y termina el programa con exit(1);. Para otros métodos de manejo de errores, consulte la sección ERRORES. JLI( PValue, PJLArray, Index); // JudyLIns()

Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones JudyL equivalentes, son la forma preferida de llamar a las funciones JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Inserta un Índice y un Valor en el array JudyL PJLArray. Si el Índice se inserta correctamente, el Valor se inicializa a 0. Si el Índice ya estaba presente, el Valor no se modifica.
Devuelve PValue apuntando al Valor. Su programa puede usar este puntero para leer o modificar el Valor hasta que se ejecute el próximo JLI() (insertar), JLD() (eliminar) o JLFA() (liberar array) en PJLArray. Ejemplos:
*PValue = 1234;
Valor = *PValue;
Devuelve PValue establecido a PJERR si ocurrió un fallo de malloc(). Nota: JLI() y JLD() reorganizan el array JudyL. Por lo tanto, PValue devuelto de llamadas anteriores a JudyL se vuelve inválido y debe ser re-adquirido.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Elimina el par Índice/Valor del array JudyL.
Devuelve Rc_int establecido a 1 si es exitoso. Devuelve Rc_int establecido a 0 si el Índice no estaba presente. Devuelve Rc_int establecido a JERR si ocurrió un fallo de malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
Obtiene el puntero PValue asociado con el Índice en el array Judy PJLArray.
Devuelve PValue apuntando al Valor. Devuelve PValue establecido a NULL si el Índice no estaba presente. Devuelve PValue establecido a PJERR si ocurrió un fallo de malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Cuenta el número de índices presentes en el array JudyL PJLArray entre Index1 y Index2 (inclusive).
Devuelve Rc_word establecido al recuento. Un valor de retorno de 0 puede ser válido como recuento.
Para contar todos los índices presentes en un array JudyL, use:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localiza el Nth índice presente en el array JudyL PJLArray (Nth = 1 devuelve el primer índice presente).
Devuelve PValue apuntando a su Valor y Index establecido al Nth índice si se encuentra, de lo contrario devuelve PValue establecido a NULL (el valor de Index no está definido).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Dado un puntero a un array JudyL, libera todo el array (mucho más rápido que usar un bucle JLN(), JLD()).
Devuelve Rc_word establecido al número de bytes liberados y PJLArray establecido a NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Devuelve Rc_word establecido al número de bytes de memoria malloc()'ados por PJLArray. Esta es una rutina muy rápida, y puede usarse antes y después de una llamada JLI() o JLD() con poco impacto en el rendimiento.

Funciones de Búsqueda JudyL
JLF(), JLN(), JLL(), JLP() permiten buscar índices en el array. Puede buscar de forma inclusiva o exclusiva, en dirección hacia adelante o hacia atrás. Si tiene éxito, Index se devuelve establecido al índice encontrado, y PValue se devuelve establecido a un puntero al Valor del Índice. Si no tiene éxito, PValue se devuelve establecido a NULL, y Index no contiene información útil. PValue debe ser probado para no ser NULL antes de usar Index, ya que es posible un fallo de búsqueda.
JLFE(), JLNE(), JLLE(), JLPE() permiten buscar índices que no están presentes ("vacíos") en el array. Puede buscar de forma inclusiva o exclusiva, en dirección hacia adelante o hacia atrás. Si tiene éxito, Index se devuelve establecido a un índice no presente ("vacío"), y Rc_int se devuelve establecido a 1. Si no tiene éxito, Rc_int se devuelve establecido a 0, y Index no contiene información útil. Rc_int debe ser verificado antes de usar Index, ya que es posible un fallo de búsqueda.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Busca (inclusivo) el primer índice presente que sea igual o mayor que el Index pasado. (Comience con Index = 0 para encontrar el primer índice en el array.) JLF() se usa típicamente para iniciar un escaneo en orden ordenado de los índices presentes en un array JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Busca (exclusivo) el siguiente índice presente que sea mayor que el Index pasado. JLN() se usa típicamente para continuar un escaneo en orden ordenado de los índices presentes en un array JudyL, o para localizar un "vecino" de un índice dado.

JLL(PValue, PJLArray, Ind
Busca (exclusivo) el último índice presente que sea menor que el Index pasado. JLL() se usa típicamente para iniciar un escaneo en orden inverso de los índices presentes en un array JudyL.

JLP(PValue, PJLArray, Index) // JudyLPrev()
Busca (exclusivo) el índice anterior presente que sea menor que el Index pasado. JLP() se usa típicamente para continuar un escaneo en orden inverso de los índices presentes en un array JudyL, o para localizar un "vecino" de un índice dado.

JLFE(Rc_int, PJLArray, Index) // JudyLFirstEmpty()
Busca (inclusivo) el primer índice no presente ("vacío") que sea igual o mayor que el Index pasado. JLFE() se usa típicamente para iniciar un escaneo de los índices vacíos en un array JudyL.

JLNE(Rc_int, PJLArray, Index) // JudyLNextEmpty()
Busca (exclusivo) el siguiente índice no presente ("vacío") que sea mayor que el Index pasado. JLNE() se usa típicamente para continuar un escaneo de los índices vacíos en un array JudyL.

JLLE(Rc_int, PJLArray, Index) // JudyLLastEmpty()
Busca (exclusivo) el último índice no presente ("vacío") que sea menor que el Index pasado. JLLE() se usa típicamente para iniciar un escaneo inverso de los índices vacíos en un array JudyL.

JLPE(Rc_int, PJLArray, Index) // JudyLPrevEmpty()
Busca (exclusivo) el índice anterior no presente ("vacío") que sea menor que el Index pasado. JLPE() se usa típicamente para continuar un escaneo inverso de los índices vacíos en un array JudyL.

ERRORES

La macro devuelve códigos de retorno y punteros especiales para indicar errores. Los códigos de retorno especiales son:

PJERR (puntero devuelto)

JERR (entero devuelto)

En caso de error, las macros enviarán un mensaje a stderr y saldrán del programa. El nombre de la macro y el error se incluirán en el mensaje. Esto es útil para la depuración.

Si prefiere otro método de manejo de errores, puede definir la macro JUDY_NO_DEFAULT_ERROR_HANDLING antes de incluir <Judy.h>. Cuando se definen, las macros devuelven los códigos de error especiales mencionados anteriormente y le permiten manejarlos usted mismo.

Si se usa el manejo de errores por defecto, las funciones de JudyL no devuelven nada (void). Si se desactiva el manejo de errores por defecto, las funciones de JudyL devuelven valores según se describe en la sección DESCRIPCIÓN.

Un ejemplo de uso del manejo de errores es el siguiente:

#define JUDY_NO_DEFAULT_ERROR_HANDLING
#include <Judy.h>
...
Pvoid_t PJLArray = (Pvoid_t) NULL;
Word_t Index = 1000;
PWord_t PValue;
...
PValue = JudyLGet(PJLArray, Index);
if (PValue == PJERR) {
    // Manejar el error, tal vez salir o intentar de nuevo
    fprintf(stderr, "JudyLGet failed!\n");
    exit(1);
}
if (PValue == NULL) {
    // El índice no fue encontrado
    ...
}

EJEMPLO

Aquí se muestra un ejemplo simple de uso de las macros JudyL.

#include <Judy.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    Pvoid_t PJLArray = (Pvoid_t) NULL;
    PWord_t PValue;
    Word_t Index, Nth;
    int Rc_int;
    Word_t Rc_word;

    // Insertar algunos elementos
    JLI(PValue, PJLArray, 5); *PValue = 10;
    JLI(PValue, PJLArray, 1); *PValue = 20;
    JLI(PValue, PJLArray, 3); *PValue = 30;
    JLI(PValue, PJLArray, 100); *PValue = 40;

    // Obtener un elemento
    Index = 3;
    PValue = JLG(PJLArray, Index);
    if (PValue != NULL) {
        printf("Value at index %lu: %lu\n", Index, *PValue);
    }

    // Contar elementos
    Rc_word = JLC(PJLArray, 0, -1); // Cuenta todos los elementos
    printf("Total elements: %lu\n", Rc_word);

    // Obtener el N-ésimo elemento
    Nth = 2; // Segundo elemento (índice 3)
    PValue = JLBC(PJLArray, Nth, Index); // Devuelve el índice en la variable Index
    if (PValue != NULL) {
        printf("The %lu'th element is at index %lu with value %lu\n", Nth, Index, *PValue);
    }

    // Escanear los elementos en orden
    printf("Scanning elements:\n");
    JLI(PValue, PJLArray, 0); // Necesario para que JLF funcione correctamente después de JLI
    Index = 0; // Inicializar Index para JLF
    while ((PValue = JLF(PJLArray, Index)) != NULL) {
        printf("  Index: %lu, Value: %lu\n", Index, *PValue);
    }

    // Eliminar un elemento
    Index = 1;
    Rc_int = JLD(PJLArray, Index);
    if (Rc_int == 1) {
        printf("Deleted index %lu\n", Index);
    }

    // Liberar todo el array
    Rc_word = JLFA(PJLArray);
    printf("Freed %lu bytes from the array.\n", Rc_word);

    return 0;
}

Arreglos JudyL multidimensionale

s

Almacenar un puntero a otro arreglo JudyL en el Valor de un arreglo JudyL es una forma sencilla de soportar arreglos multidimensionales dinámicos. Estos arreglos (o árboles) construidos usando arreglos JudyL son muy rápidos y eficientes en memoria. (De hecho, así es como se implementan JudySL y JudyHS). De esta manera se puede lograr un número arbitrario de dimensiones. Para terminar el número de dimensiones (o árbol), el puntero Valor se marca para NO apuntar a otro arreglo Judy. Se usa una bandera JLAP_INVALID en el bit(s) menos significativo(s) del puntero. Después de que la bandera JLAP_INVALID se elimina, se usa como un puntero a los datos del usuario. El archivo de cabecera Judy.h define JLAP_INVALID. Vea el fragmento de código a

continuación.

Nota: La versión actual de Judy.h cambió esta bandera de 0x4 a 0x1 para permitir un malloc() que no entrega memoria en un límite alineado a 8 bytes (como versiones antiguas de valgrind)

.
