DESCRIPCIÓN

Existe una forma de macro equivalente para cada llamada a función. Debido a que las formas de macro a veces son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones JudyL. Vea JudyL(3) para más información. Las definiciones de llamadas a funciones se incluyen aquí por completitud.

Una de las dificultades al usar las llamadas a funciones JudyL radica en determinar si pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, debe pasar la dirección del puntero en lugar del puntero mismo. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten que el compilador detecte errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones JudyL tienen un parámetro adicional más allá de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error o NULL (en cuyo caso, la información detallada del error no se devuelve).

En las siguientes descripciones, las funciones se describen en términos de cómo las usan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros después de que su programa haya sido completamente depurado. Cuando la macro JUDYERROR_NOTEST no está especificada, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.
