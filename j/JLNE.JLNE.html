JudyL(3) Manual de Funciones de Biblioteca JudyL(3)

NOMBRE

Macros JudyL - Biblioteca C para crear y acceder a un array dinámico de palabras, usando una palabra como índice.

SINOPSIS

cc [flags] archivos_fuente -lJudy
#include <Judy.h>
int      Rc_int;                          // código de retorno - entero
Word_t   Rc_word;                         // código de retorno - palabra sin signo
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // puntero al valor de retorno
Pvoid_t PJLArray = (Pvoid_t) NULL;        // inicializar array JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPCIÓN

Un array JudyL es el equivalente a un array de valores del tamaño de una palabra. Un Valor se dirige mediante un Índice (clave). El array puede ser disperso, y el Índice puede ser cualquier número del tamaño de una palabra. La memoria para soportar el array se asigna a medida que se insertan pares de índice/valor, y se libera a medida que se eliminan pares de índice/valor. Un array JudyL también puede considerarse un mapeador, es decir, que "mapea" una palabra a otra palabra/puntero.

Al igual que con un array ordinario, no hay índices duplicados en un array JudyL.

El valor puede usarse como un escalar, o como un puntero a una estructura o bloque de datos (o incluso a otro array Judy).

Un array JudyL se asigna con un puntero NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

Usando las macros descritas aquí, en lugar de las llamadas a funciones JudyL, el manejo de errores por defecto envía un mensaje al error estándar y termina el programa con exit(1);. Para otros métodos de manejo de errores, consulte la sección ERRORES. JLI( PValue, PJLArray, Index); // JudyLIns()

Debido a que las formas de macro a veces son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones JudyL equivalentes, son la forma preferida de llamar a las funciones JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Inserta un Índice y un Valor en el array JudyL PJLArray. Si el Índice se inserta correctamente, el Valor se inicializa a 0. Si el Índice ya estaba presente, el Valor no se modifica.
Devuelve PValue apuntando al Valor. Su programa puede usar este puntero para leer o modificar el Valor hasta que se ejecute la siguiente llamada JLI() (insertar), JLD() (eliminar) o JLFA() (liberar array) en PJLArray. Ejemplos:
*PValue = 1234;
Valor = *PValue;
Devuelve PValue establecido en PJERR si ocurrió un error de malloc(). Nota: JLI() y JLD() reorganizan el array JudyL. Por lo tanto, PValue devuelto de llamadas previas de JudyL se vuelven inválidos y deben ser readquiridos.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Elimina el par Índice/Valor del array JudyL.
Devuelve Rc_int establecido en 1 si es exitoso. Devuelve Rc_int establecido en 0 si el Índice no estaba presente. Devuelve Rc_int establecido en JERR si ocurrió un error de malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
Obtiene el puntero PValue asociado con el Index en el array Judy PJLArray.
Devuelve PValue apuntando al Valor. Devuelve PValue establecido en NULL si el Índice no estaba presente. Devuelve PValue establecido en PJERR si ocurrió un error de malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Cuenta el número de índices presentes en el array JudyL PJLArray entre Index1 y Index2 (inclusive).
Devuelve Rc_word establecido en el recuento. Un valor de retorno de 0 puede ser válido como recuento.
Para contar todos los índices presentes en un array JudyL, use:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localiza el índice Nth que está presente en el array JudyL PJLArray (Nth = 1 devuelve el primer índice presente).
Devuelve PValue apuntando a su Valor e Index establecido en el índice Nth si se encuentra, de lo contrario, devuelve PValue establecido en NULL (el valor de Index no está definido).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Dado un puntero a un array JudyL, libera todo el array (mucho más rápido que usar un bucle JLN(), JLD()).
Devuelve Rc_word establecido en el número de bytes liberados y PJLArray establecido en NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Devuelve Rc_word establecido en el número de bytes de memoria malloc()ados por PJLArray. Esta es una rutina muy rápida, y puede ser utilizada antes y después de una llamada JLI() o JLD() con poco impacto en el rendimiento.

Funciones de Búsqueda JudyL
JLF(), JLN(), JLL(), JLP() le permiten buscar índices en el array. Puede buscar de forma inclusiva o exclusiva, en dirección hacia adelante o hacia atrás. Si tiene éxito, Index se devuelve establecido en el índice encontrado, y PValue se devuelve establecido en un puntero al Valor del Index. Si no tiene éxito, PValue se devuelve establecido en NULL, y Index no contiene información útil. Se debe probar PValue para que no sea NULL antes de usar Index, ya que es posible un fallo de búsqueda.
JLFE(), JLNE(), JLLE(), JLPE() le permiten buscar índices que no están presentes ("vacíos") en el array. Puede buscar de forma inclusiva o exclusiva, en dirección hacia adelante o hacia atrás. Si tiene éxito, Index se devuelve establecido en un índice no presente ("vacío"), y Rc_int se devuelve establecido en 1. Si no tiene éxito, Rc_int se devuelve establecido en 0, y Index no contiene información útil. Se debe comprobar Rc_int antes de usar Index, ya que es posible un fallo de búsqueda.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Busca (inclusivo) el primer índice presente que sea igual o mayor que el Index pasado. (Comience con Index = 0 para encontrar el primer índice en el array.) JLF() se usa típicamente para iniciar un escaneo en orden ordenado de los índices presentes en un array JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Busca (exclusivo) el siguiente índice presente que sea mayor que el Index pasado. JLN() se usa típicamente para continuar un escaneo en orden ordenado de los índices presentes en un array JudyL, o para localizar un "vecino" de un índice dado.

JLNE(3) — Arch manual pages

NAME

JLNE, JudyLNextEmpty - find the next empty index greater than the passed index

SYNOPSIS

#include <Judy.h>

Word_t          Index;
PWord_t         PValue;
int             Rc_int;
Pvoid_t         PJLArray;

Rc_int = JLNE(PValue, PJLArray, Index);

DESCRIPTION

JLNE(), alias JudyLNextEmpty(), searches for the first empty index (i.e., an index that is not present in the JudyL array) that is strictly greater than the passed Index. JudyL arrays are dynamic arrays that contain arbitrary, non-negative integers (indexes) and arbitrary integer pointers (values).

The JudyL array is identified by PJLArray. The index to start searching from is identified by Index. If an empty index is found, its value is returned in PValue and Rc_int is set to 1. If no empty index is found, PValue is set to NULL and Rc_int is set to 0.

See Judy.h for the definition of the various data types used.

JLNE() is typically used to find the next available slot in a JudyL array, or to find gaps between existing indexes.

JudyL Array Traversal Functions

JLF(PValue, PJLArray, Index) // JudyLFirst()
Search (inclusive) for the first index present that is equal to or greater than the passed Index. (Start with Index = 0 to find the first index in the array.)
JLN(PValue, PJLArray, Index) // JudyLNext()
Search (exclusive) for the next index present that is greater than the passed Index.
JLL(PValue, PJLArray, Index) // JudyLLast()
Search (inclusive) for the last index present that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index in the array.) JLL() is typically used to begin a reverse-sorted-order scan of the indexes present in a JudyL array.
JLP(PValue, PJLArray, Index) // JudyLPrev()
Search (exclusive) for the previous index present that is less than the passed Index. JLP() is typically used to continue a reverse-sorted-order scan of the indexes present in a JudyL array, or to locate a "neighbor" of a given index.
JLFE(Rc_int, PJLArray, Index) // JudyLFirstEmpty()
Search (inclusive) for the first index absent that is equal to or greater than the passed Index. (Start with Index = 0 to find the first index absent in the array.)
JLNE(Rc_int, PJLArray, Index) // JudyLNextEmpty()
Search (exclusive) for the next index absent that is greater than the passed Index.
JLLE(Rc_int, PJLArray, Index) // JudyLLastEmpty()
Search (inclusive) for the last index absent that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index absent in the array.)
JLPE(Rc_int, PJLArray, Index) // JudyLPrevEmpty()
Search (exclusive) for the previous index absent that is less than the passed Index.

Multi-dimensional JudyL Arrays

Storing a pointer to another JudyL array in a JudyL array's Value is a simple way to support dynamic multi-dimensional arrays. These arrays (or trees) built using JudyL arrays are very fast and memory efficient. (In fact, that is how JudySL and JudyHS are implemented). An arbitrary number of dimensions can be realized this way. To terminate the number of dimensions (or tree), the Value pointer is marked to NOT point to another Judy array. A JLAP_INVALID flag is used in the least significant bit(s) of the pointer. After the flag JLAP_INVALID is removed, it is used as a pointer to the users data. The Judy.h header file defines JLAP_INVALID. See code fragment below.

Note: The current version of Judy.h changed this flag from 0x4 to 0x1 to allow for a malloc() that does not deliver memory on an 8 byte aligned boundry (such as old versions of valgrind).

The following example code segment can be used to determine whether or not a pointer points to another JudyL:

PValue = (PWord_t)PMultiDimArray;
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Advance to next dimension in array */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Check if pointer to user buffer: */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // mask and cast.
printf("User object pointer is 0x%lx\n", (Word_t) UPointer);
       ...

Note: This works because malloc() guarantees to return a pointer with the least bit(s) == 0x0. You must remove JLAP_INVALID before using the pointer.

ERRORS: See: Judy_3.htm#ERRORS

EXAMPLE

Read a series of index/value pairs from the standard input, store in a JudyL array, and then print out in sorted order.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // array index
Word_t   Value;                     // array element value
Word_t * PValue;                    // pointer to array element value
int      Rc_int;                    // return code
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialize JudyL array
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // store new value
}
// Next, visit all the stored indexes in sorted order, first ascending,
// then descending, and delete each index during the descending pass.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure;
    JLP(PValue, PJLArray, Index);
}
