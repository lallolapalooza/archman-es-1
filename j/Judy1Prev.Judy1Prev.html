DESCRIPCIÓ

N

Existe un macro equivalente para cada llamada de función. Debido a que las formas de macro a veces son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones Judy1. Vea Judy1(3) para más información. Las definiciones de las llamadas a funciones se incluyen aquí por

completitud.

Una de las dificultades al usar las llamadas a funciones Judy1 radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el arreglo Judy1 también deben modificar el puntero al arreglo Judy1, se debe pasar la dirección del puntero en lugar del puntero mismo. Esto a menudo conduce a errores programáticos difíciles de depurar. En la práctica, los macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de

punteros.

Las llamadas a funciones Judy1 tienen un parámetro adicional más allá de los especificados en las llamadas a macros. Este parámetro es o bien un puntero a una estructura de error, o NULL (en cuyo caso la información detallada del error no se devuelve)

.

En las siguientes descripciones, las funciones se describen en términos de cómo las macros las usan (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de los macros después de que su programa haya sido completamente depurado. Cuando el macro JUDYERROR_NOTEST no se especifica, se declara una estructura de error para almacenar la información de error devuelta desde las funciones Judy1 cuando ocurre un

error.

Note la colocación del & en las diferentes

funciones.

NAME

Judy1PrevEmpty, J1PE - find the previous empty index in a Judy1 array

SYNOPSIS

Rc_t Rc_int;
Word_t Index;
PJError_t PJE0 = NULL;
Pvoid_t PJ1Array;

Rc_int = Judy1PrevEmpty(PJ1Array, &Index, PJE0);
J1PE(Rc_int, PJ1Array, Index);

DESCRIPTION

Judy1PrevEmpty() finds the previous empty index in a Judy1 array.

It returns the index of the previous empty slot. If there is no previous empty slot, it returns (Word_t)-1.

The index to search backwards from is passed in by address in Index. The search begins at the index before the one passed in Index. The index is decremented until an empty slot is found or Index becomes negative.

If PJE0 is not NULL, it is a pointer to a JError_t struct which will be filled with error information if an error occurs.

J1PE() is a macro that simplifies calling Judy1PrevEmpty().

Judy1PrevEmpty(PJ1Array, &Index, PJE0)
#define J1PE(Rc_int, PJ1Array, Index) \
   Rc_int = Judy1PrevEmpty(PJ1Array, &Index, PJE0)

Definitions for all of the Judy functions, the types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t, and PJError_t, the constants NULL, JU_ERRNO_*, JERR, and PJE0, are provided in the Judy.h header file (/usr/include/Judy.h). Note: Callers should define Judy1 arrays as type Pvoid_t, which can be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.
