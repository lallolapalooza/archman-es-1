DESCRIPCIÓN

Existe una macro equivalente a cada llamada de función. Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones Judy1. Consulte Judy1(3) para obtener más información. Las definiciones de llamada de función se incluyen aquí para su completa.

Una de las dificultades para usar las llamadas a funciones Judy1 radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array Judy1 también deben modificar el puntero al array Judy1, debe pasar la dirección del puntero en lugar del puntero mismo. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten que el compilador detecte errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones Judy1 tienen un parámetro adicional más allá de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error o NULL (en cuyo caso, la información detallada del error no se devuelve).

En las siguientes descripciones, las funciones se describen en términos de cómo las utilizan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros una vez que su programa se ha depurado por completo. Cuando la macro JUDYERROR_NOTEST no está especificada, se declara una estructura de error para almacenar la información de error devuelta por las funciones Judy1 cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.

Un valor de retorno de 0 puede ser un error, válido como recuento, o puede indicar un caso especial para un array completamente poblado (solo en máquinas de 32 bits). Si es necesario, el siguiente código se puede utilizar para desambiguar esta devolución:
JError_t JError;
Rc_word = Judy1Count(PJ1Array, Index1, Index2, &JError);
if (Rc_word == 0)
{
    if (JU_ERRNO(&JError) == JU_ERRNO_NONE)
        printf("Población del array Judy1 == 0\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_FULL)
        printf("Población del array Judy1 == 2^32\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_NULLPPARRAY)
        goto NullArray;
    if (JU_ERRNO(&JError) >  JU_ERRNO_NFMAX)
        goto Null_or_CorruptArray;
}
