JudySL(3) Manual de funciones de biblioteca JudySL(3)

NOMBRE

Macros JudySL - Biblioteca C para crear y acceder a un array dinámico, utilizando una cadena terminada en nulo como Índice (array asociativo)

SINOPSIS

cc [flags] archivos_fuente -lJudy
#include <Judy.h>
#define MAXLINELEN 1000000           // define la longitud máxima de cadena
Word_t * PValue;                     // elemento del array JudySL
uint8_t  Index[MAXLINELEN];          // cadena
int      Rc_int;                     // valor de retorno
Word_t   Rc_word;                    // valor de retorno de palabra completa
Pvoid_t PJSLArray = (Pvoid_t) NULL;  // inicializa el array JudySL
JSLI( PValue,  PJSLArray, Index);   // JudySLIns()
JSLD( Rc_int,  PJSLArray, Index);   // JudySLDel()
JSLG( PValue,  PJSLArray, Index);   // JudySLGet()
JSLFA(Rc_word, PJSLArray);          // JudySLFreeArray()
JSLF( PValue,  PJSLArray, Index);   // JudySLFirst()
JSLN( PValue,  PJSLArray, Index);   // JudySLNext()
JSLL( PValue,  PJSLArray, Index);   // JudySLLast()
JSLP( PValue,  PJSLArray, Index);   // JudySLPrev()

DESCRIPCIÓN

Un array JudySL es el equivalente a un conjunto ordenado de cadenas, cada una asociada a un Valor (palabra). Un Valor es accedido por un Índice (clave), que es una cadena de caracteres terminada en nulo de cualquier longitud. La memoria para soportar el array se asigna a medida que se insertan pares índice/valor, y se libera a medida que se eliminan pares índice/valor. Esta es una forma de array asociativo, donde los elementos del array también están ordenados lexicográficamente (sensible a mayúsculas/minúsculas) por índices. Esto podría pensarse como

void * JudySLArray["Toto, I don't think we're in Kansas any more"];

Un array JudySL se asigna con un puntero NULL

Pvoid_t PJSLArray = (Pvoid_t) NULL;
Al igual que con un array normal, no hay índices duplicados (cadenas) en un array JudySL.

Usando las macros descritas aquí, en lugar de las llamadas a funciones JudySL, el manejo de errores predeterminado envía un mensaje al error estándar y termina el programa con exit(1).

JSLI(PValue, PJSLArray, Index) // JudySLIns()

Inserta una cadena Índice y un Valor en el array JudySL PJSLArray. Si el Índice se inserta correctamente, el Valor se inicializa a 0. Si el Índice ya estaba presente, el Valor no se modifica.

Devuelve PValue apuntando al Valor del Índice. Su programa debe usar este puntero para modificar el Valor, por ejemplo:

*PValue = 1234;

Nota: JSLI() y JSLD reorganizan el array JudySL. Por lo tanto, los punteros devueltos por llamadas anteriores de JudySL se vuelven inválidos y deben ser re-adquiridos.

JSLD(Rc_int, PJSLArray, Index) // JudySLDel()

Elimina el par Índice/Valor especificado (elemento del array) del array JudySL.

Devuelve Rc_int establecido a 1 si tiene éxito. array y se insertó previamente. Devuelve Rc_int establecido a 0 si el Índice no estaba presente.

JSLG(PValue, PJSLArray, Index) // JudySLGet()

Obtiene el puntero al Valor del Índice.

Devuelve PValue apuntando al Valor del Índice. Devuelve PValue establecido a NULL si el Índice no estaba presente.

JSLFA(Rc_word, PJSLArray) // JudySLFreeArray()

Dado un puntero a un array JudySL (PJSLArray), libera todo el array (mucho más rápido que usar un bucle JSLN(), JSLD()).

Devuelve Rc_word establecido al número de bytes liberados y PJSLArray establecido a NULL.

Funciones de búsqueda JudySL

Las funciones de búsqueda JudySL le permiten buscar índices en el array. Puede buscar de forma inclusiva o exclusiva, en dirección hacia adelante o hacia atrás.

Si tiene éxito, Index se establece en el índice encontrado, y PValue se establece en un puntero al Valor del Index. Si no tiene éxito, PValue se establece en NULL, y Index no contiene información útil. PValue debe ser probado para no ser NULL antes de usar Index, ya que un fallo de búsqueda es posible.

Nota: Para acomodar todas las devoluciones posibles, el buffer Index debe ser al menos tan grande como la cadena más larga almacenada en el array.

JSLF(PValue, PJSLArray, Index) // JudySLFirst()

Busca (inclusivo) el primer índice presente que sea igual o mayor que la cadena Index pasada. (Comience con una cadena nula para encontrar el primer índice en el array.) JSLF() se usa típicamente para *iniciar* un escaneo en orden ordenado de los índices válidos en un array JudySL.

uint8_t Index[MAXLINELEN];
strcpy (Index, "");
JSLF(PValue, PJSLArray, Index);

JSLN(PValue, PJSLArray, Index) // JudySLNext()

Busca (exclusivo) el siguiente índice presente que sea mayor que la cadena Index pasada. JSLN() se usa típicamente para *continuar* un escaneo en orden ordenado de los índices válidos en un array JudySL, o para localizar un "vecino" de un índice dado.

JSLL(PValue, PJSLArray, Index) // JudySLLast()

Busca (inclusivo) el último índice presente que sea igual o menor que la cadena Index pasada. (Comience con una cadena de valor máximo para buscar el último índice en el array, como una cadena de longitud máxima de bytes 0xff.) JSLL() se usa típicamente para *iniciar* un escaneo en orden inverso ordenado de los índices válidos en un array JudySL.

JSLP(PValue, PJSLArray, Index) // JudySLPrev()

Busca (exclusivo) el índice anterior presente que sea menor que la cadena Index pasada. JSLP() se usa típicamente para *continuar* un escaneo en orden inverso ordenado de los índices válidos en un array JudySL, o para localizar un "vecino" de un índice dado.

EJEMPLO de una rutina de ordenación de cadenas

#include <stdio.h>
#include <Judy.h>
#define MAXLINE 1000000                 // longitud máxima de cadena (línea)
uint8_t   Index[MAXLINE];               // cadena a insertar
int     // Uso:  JudySort < archivo_a_ordenar
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // Array Judy.
    PWord_t   PValue;                   // Elemento del array Judy.
    Word_t    Bytes;                    // tamaño del array JudySL.
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        JSLI(PValue, PJArray, Index);   // almacenar cadena en el array
        if (PValue == PJERR)            // si falta memoria?
        {                               // entonces haz algo
            printf("Fallo de Malloc -- obtén más RAM\n");
            exit(1);
        }
        ++(*PValue);                    // contar instancias de la cadena
    }
    Index[0] = '\0';                    // comenzar con la cadena más pequeña.
    JSLF(PValue, PJArray, Index);       // obtener la primera cadena
    while (PValue != NULL)
    {
        while ((*PValue)--)             // imprimir duplicados
            printf("%s", Index);
        JSLN(PValue, PJArray, Index);   // obtener la siguiente cadena
    }
    JSLFA(Bytes, PJArray);              // liberar array
    fprintf(stderr, "El array JudySL usó %lu bytes de memoria\n", Bytes);
    return (0);
}
