Existe un equivalente de macro para cada llamada a función. Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones Judy1. Véase

Una de las dificultades al usar las llamadas a funciones Judy1 radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array Judy1 también deben modificar el puntero al array Judy1, se debe pasar la dirección del puntero en lugar del puntero en sí. Esto a menudo conduce a errores programáticos difíciles de depurar. En la práctica, las macros permiten al compilador detectar errores de programación cuando se pasan

punteros en lugar de direcciones de punteros.

SYNOPSIS

#include <Judy.h>

Judy1_t Judy1PrevEmpty(
    Pvoid_t Judy1Array,
    Word_t *Index,
    JError_t *JError);

DESCRIPTION

The Judy1PrevEmpty function returns the index of an empty slot in the Judy1 array. It is passed a Judy1 array and a pointer to an index. The index is used to search backwards from the slot indicated by the index value.

Judy1PrevEmpty searches backwards in the Judy1 array from the slot indicated by *Index. If it finds an empty slot, it returns the index of that empty slot in *Index and returns the Judy array.

If no empty slot is found in the Judy1 array from the slot indicated by *Index backwards to slot 0, it returns (Word_t)NULL. The value of *Index is undefined in this case.

If an error occurs, it returns (Word_t)NULL and sets *JError to an error code:

  • JU_ERRNO_NULL, The Judy1 array is NULL.
  • JU_ERRNO_BADARRAYTYPE, The Judy1 array is not a Judy1 array.

The value of *Index can be any valid index into the Judy1 array or it can be JU_MAXSIZE.

The macro J1PE is provided for convenience.

#define J1PE(Rc_int, PJ1Array, Index) \
   Rc_int = Judy1PrevEmpty(PJ1Array, &Index, PJE0)

Definitions for all of the Judy functions, the types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t, and PJError_t, the constants NULL, JU_ERRNO_*, JERR, and PJE0, are provided in the Judy.h header file (/usr/include/Judy.h). Note: Callers should define Judy1 arrays as type Pvoid_t, which can be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.
