DESCRIPCIÓ

N

Un arreglo JudyL es el equivalente a un arreglo de valores del tamaño de una palabra. Un Valor se direcciona mediante un Índice (clave). El arreglo puede ser disperso, y el Índice puede ser cualquier número del tamaño de una palabra. La memoria para soportar el arreglo se asigna a medida que se insertan pares índice/valor, y se libera a medida que se eliminan pares índice/valor. Un arreglo JudyL también puede pensarse como un mapeador, que "mapea" una palabra a otra palabra/puntero

.

Como en un arreglo ordinario, no hay índices duplicados en un arreglo

JudyL.

El valor puede usarse como un escalar, o como un puntero a una estructura o bloque de datos (o incluso a otro arreglo Judy)

.

Un arreglo JudyL se asigna con un puntero

NULL

NULL;

Arreglos JudyL multidimensionale

s

Almacenar un puntero a otro arreglo JudyL en el Valor de un arreglo JudyL es una forma sencilla de soportar arreglos multidimensionales dinámicos. Estos arreglos (o árboles) construidos usando arreglos JudyL son muy rápidos y eficientes en memoria. (De hecho, así es como se implementan JudySL y JudyHS). De esta manera se puede lograr un número arbitrario de dimensiones. Para terminar el número de dimensiones (o árbol), el puntero Valor se marca para NO apuntar a otro arreglo Judy. Un indicador JLAP_INVALID se usa en el/los bit(s) menos significativo(s) del puntero. Después de que el indicador JLAP_INVALID se elimina, se usa como un puntero a los datos del usuario. El archivo de cabecera Judy.h define JLAP_INVALID. Vea el fragmento de código a

continuación.

Nota: La versión actual de Judy.h cambió este indicador de 0x4 a 0x1 para permitir un malloc() que no entrega memoria en un límite alineado a 8 bytes (como versiones antiguas de valgrind)

.
