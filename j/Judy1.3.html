DESCRIPCIÓ

N

Un array Judy1 es el equivalente a un array de bits o mapa de bits. Un bit se direcciona mediante un Index (clave). El array puede ser disperso, y el Index puede ser cualquier Value del tamaño de una palabra. Si un índice está presente, representa un bit activado (un bit activado representa un índice presente). Si un índice está ausente, representa un bit desactivado (un bit desactivado representa un índice ausente)

.

Un array Judy1 se asigna con un NULL poi

nter 
Pvoid_t PJ1Array = (Pvoid_t) NULL;
La
memoria para soportar el array se asigna a medida que se activan los bits, y se libera a medida que se desactivan los bits. Si el puntero Judy1 (PJ1Array) es NULL, todos los bits están desactivados (y el array Judy1 no requiere memoria).

Como con un array ordinario, un array Judy1 no contiene índices

duplicados.

Usando las macros descritas aquí, en lugar de las llamadas a la función Judy1, el manejo de errores por defecto envía un mensaje a la salida de error estándar y termina el programa con exit(1). Para otros métodos de manejo de errores, ver la sección ERRORES

.

Funciones de Búsqueda
Judy1
Las funciones de búsqueda Judy1 permiten buscar bits activados o desactivados en el array. Puede buscar inclusiva o exclusivamente, en direcciones hacia adelante o hacia atrás. Todas las funciones de búsqueda usan una secuencia de llamada similar. Rc_int se retorna establecido a 1 para una búsqueda exitosa y el Index encontrado se retorna. Rc_int se retorna establecido a 0 para una búsqueda fallida, y Index no contiene información útil. El código de retorno Rc_int debe verificarse antes de usar el Index retornado, ya que es posible que la búsqueda
falle.

()

Judy1.
