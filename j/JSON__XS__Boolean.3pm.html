NOMBRE

JSON::XS::Boolean - módulo ficticio que proporciona JSON::XS::Boolean

SINOPSIS

# no lo "uses" tú mismo

DESCRIPCIÓN

Este módulo existe solo para proporcionar resolución de sobrecargas para Storable y módulos similares. Solo es necesario para la compatibilidad con datos serializados (por otros módulos como Storable) que fueron decodificados por versiones de JSON::XS anteriores a la 3.0.

Desde la versión 3.0, JSON::PP::Boolean lo ha reemplazado. El soporte para JSON::XS::Boolean se eliminará en una futura versión.
