NOMBRE

Funciones JudyL - Función de librería para crear y acceder a un array dinámico de palabras, utilizando cualquier valor de palabra como índice

SINOPSIS

DESCRIPCIÓN

Existe un equivalente de macro para cada llamada de función. Debido a que los formularios de macro pueden ser más rápidos y tener una interfaz de error más simple que las funciones equivalentes, son la forma preferida de llamada a las funciones JudyL. Ver JudyL(3) para más información. Las definiciones de las funciones de llamada se incluyen aquí para completitud.

Una de las dificultades al usar las llamadas de funciones JudyL es determinar si pasar un puntero o la dirección de un puntero. Porque las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, debe pasar la dirección del puntero, no el puntero mismo. Esto puede llevar a errores difíciles de depurar en el código programático. En la práctica, los macros permiten a los compiladores detectar errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas de funciones JudyL tienen un parámetro adicional que no se especifica en las llamadas de macro. Este parámetro es un puntero a una estructura de error o NULL (en el cual no se devuelve información detallada).

En las descripciones siguientes, las funciones se describen en términos de cómo se utilizan por las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso recomendado después de que el programa haya sido completamente depurado. Cuando el macro JUDYERROR_NOTEST no se especifica, una estructura de error se declara para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Nota la colocación de & en las diferentes funciones.

JudyLDel(3) - Arch Linux

NAME

JudyLDel JudyLDel - delete JudyL array

SYNOPSIS

#include <Judy.h>

Word_t *JudyLDel(JudyL *Array, Word_t KeyIndex);

DESCRIPTION

JudyLDel() deletes the entry with the given KeyIndex from the Array. Returns the value of the deleted entry, or NULL if the entry was not found. The returned value is a pointer to the value which was stored in the Judy array. It may be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.

The return type from most JudyL functions is PPvoid_t so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a Word_t * when a pointer to a Value is required instead of a pointer to a pointer.

NOMBRE

JudyLDel JudyLDel - eliminar matriz JudyL

SINOPSIS

#include <Judy.h>

Word_t *JudyLDel(JudyL *Array, Word_t KeyIndex);

DESCRIPCIÓN

JudyLDel() elimina la entrada con el KeyIndex dado de la Array. Devuelve el valor de la entrada eliminada, o NULL si la entrada no fue encontrada. El valor devuelto es un puntero al valor que se almacenó en la matriz Judy. Puede pasarse por valor a funciones que toman Pcvoid_t (Pvoid_t constante), y también por dirección a funciones que toman PPvoid_t.

El tipo de retorno de la mayoría de las funciones JudyL es PPvoid_t para que los valores almacenados en la matriz puedan ser punteros a otros objetos, lo cual es un uso típico, o se puedan convertir a un Word_t * cuando se requiere un puntero a un Value en lugar de un puntero a puntero.
