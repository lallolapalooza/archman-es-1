DESCRIPCIÓN

Existen macros equivalentes para cada llamada de función. Debido a que los formatos de macros pueden ser más rápidos y tener una interfaz de manejo de errores más sencilla que las funciones equivalentes, son la forma preferida para llamar a las funciones JudyL. Ver JudyL(3) para más información. Las definiciones de las funciones de llamada son incluidas aquí para completar.

Uno de los desafíos en el uso de las llamadas de funciones JudyL radica en determinar si pasar un puntero o el dirección de un puntero. Porque las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, debes pasar la dirección del puntero, no el propio puntero. Esto a menudo lleva a errores difíciles de depurar en el código programático. En la práctica, los macros permiten a los compiladores detectar errores de programación cuando se pasan punteros en lugar de las direcciones de punteros.

Las llamadas de funciones JudyL tienen un parámetro adicional que no se especifica en las llamadas de macro. Este parámetro es o bien un puntero a un estructura de errores, o bien NULL (en cuyo caso no se devuelve la información detallada).

En las descripciones siguientes, las funciones se describen en términos de cómo se usan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros después de que tu programa haya sido completamente depurado. Cuando el macro JUDYERROR_NOTEST no se especifica, se declara un estructura de errores para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Nota la colocación de & en diferentes funciones.

NAME

JudyLMemUsed - Get the amount of memory used by a JudyL array

SYNOPSIS

#include <Judy.h>

Word_t *JudyLMemUsed(
    PJudyL_t JudL);

DESCRIPTION

JudyLMemUsed() returns a pointer to the number of bytes currently used by the JudyL array passed as the argument JudL.

The return value is a pointer to a Word_t. This is so that the JudyL array can be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.

The return type from most JudyL functions is PPvoid_t so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a Word_t * when a pointer to a Value is required instead of a pointer to a pointer.
