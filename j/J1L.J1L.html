Este nuevo componente (Mayo 2004) de Judy es un híbrido que usa las mejores características del hashing y de los métodos Judy. El autor cree que JudyHS es un buen reemplazo para un método de hashing cuando el redimensionamiento de la tabla hash se realiza durante el crecimiento de la población. Un método de hashing correctamente afinado con un tamaño de tabla hash y población estáticos es imbatible en velocidad. Sin

embargo,

JudyHS funcionará mejor que un método de hashing con poblaciones más pequeñas y más grandes que el tamaño óptimo de la tabla hash. JudyHS no tiene un caso de rendimiento degenerado donde el conocimiento del algoritmo hash pueda ser explotado. (Es decir, JudyHS no usa una lista enlazada para manejar colisiones de hash, usa un árbol de arreglos JudyL y un tamaño de tabla hash virtual de 4 mil millones). Los arreglos Judy son tanto eficientes en velocidad como en memoria , sin requerir afinamiento o configuración, a través de una amplia gama de tipos de conjuntos de índices (secuenciales, periódicos, agrupados, aleatorios). La velocidad y el uso de memoria de Judy son típicamente mejores que otros modelos de almacenamiento de datos como listas de saltos, listas enlazadas, binarias, ternarias, árboles B, o incluso hashing, y mejoran con conjuntos de datos muy grandes. Un arreglo Judy se crea simplemente definiendo un puntero nulo y luego almacenando (insertando) el primer elemento en el arreglo bajo ese puntero. La memoria usada por un arreglo Judy es casi proporcional a

la población (número de elementos).

Judy tiene dos Interfaces de Programación de Aplicaciones (APIs): una interfaz de macros C y una interfaz de llamadas a funciones. Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de usar las funciones Judy. En otras palabras, los Valores de un arreglo Judy (excepto Judy1) pueden ser punteros a otros arreglos Judy. NAME

                    
J1L - Judy 1 array insert.

                

                

                    
SYNOPSIS

                    
#include <Judy.h>

                    
Word_t
J1L(JudyLArray*, Word_t, Word_t);

                

                

                    
DESCRIPTION

                    
La función J1L() inserta un entero Word_t en una
                        Judy array de tipo 1. Una Judy array de tipo 1 es
                        una matriz de enteros de 64 bits sin signo (tipo Word_t)
                        donde el índice está codificado utilizando compresión de
                        trie de sufijo de Huffman.

                    
Judy L array (J1L) se utiliza para insertar
                        enteros de 64 bits sin signo (índices). Los valores
                        asociados a los índices pueden ser también enteros de 64 bits
                        sin signo.

                    
La función J1L() devuelve el número de entradas
                        en la Judy array después de la inserción. Si ocurre un
                        error, la función devuelve un valor negativo (un código
                        de error).

                

                

                    
A 10 MINUTE TECHNICAL DESCRIPTION

                    
J1L() es una macro que inserta un entero de 64
                        bits (índice) en una Judy array de tipo 1. Los valores
                        asociados a los índices son también enteros de 64 bits.

                    
Si la Judy array está vacía, J1L() crea un nodo
                        raíz y se convierte en el primer índice.

                    
Si el índice existe en la Judy array, J1L()
                        actualiza el valor asociado con el índice.

                    
Si el índice no existe en la Judy array, J1L()
                        inserta el índice y su valor asociado en la Judy array.

                    
Si la inserción provoca la expansión de la Judy
                        array, la función J1L() devuelve el nuevo número de
                        entradas en la Judy array.

                    
Si ocurre un error, J1L() devuelve un código
                        de error negativo.

                

                

                    
A 3 HOUR TECHNICAL DESCRIPTION (out of date and a bit corny)

                    
En esta sección se discuten las capacidades de
                        manejo de errores de la interfaz de macro de la API de
                        Judy array. La API de la macro de Judy array proporciona
                        las siguientes capacidades de manejo de errores:

                    
1) Manejo de errores predeterminado: La API de
                        la macro de Judy array imprime la información del error y
                        luego sale del programa.

                    
2) Desactivación del manejo de errores de la
                        macro: La API de la macro de Judy array omite el manejo
                        de errores. Esta opción se utiliza cuando se utilizan
                        funciones de la API de Judy que devuelven códigos de
                        error y las pruebas de error no son necesarias.

                    
3) Método de macro JUDYERROR() especificado
                        por el usuario: La macro JUDYERROR() (en Judy.h) permite
                        flexibilidad para manejar los retornos de error según sea
                        necesario para adaptarse a su programa, sin dejar de
                        utilizar las macros de la matriz Judy en lugar de
                        llamadas a funciones.

                

                

                    
AUTHOR

                    
Judy.

                

                

                    
1) Default Error Handling Method

                    
Sin definir JUDYERROR_NOTEST,
                        la siguiente macro se utiliza para el manejo de errores:

                    
#define JUDYERROR(CallerFile, CallerLine, JudyFunc, JudyErrno, JudyErrID) \
{                                                                         \
    (void) fprintf(stderr, "File '%s', line %d: %s(), "               \
        "JU_ERRNO_* == %d, ID == %d\n",                               \
        CallerFile, CallerLine,                                       \
        JudyFunc, JudyErrno, JudyErrID);                              \
    exit(1);                                                              \
}

                    
Como se ve arriba, esta macro imprimirá el
                        nombre del archivo y el número de línea del programa que
                        llama, el nombre de la función Judy que provocó el error,
                        el código de error Judy y el ID de error Judy. A
                        continuación, se saldrá del programa con un código de
                        salida de 1.

                

                

                    
2) Disable Macro Error Handling

                    
Si está definido JUDYERROR_NOTEST,
                        la macro JUDYERROR() no se llama cuando se produce un error.
                        Las macros de la API de Judy continuarán ejecutándose sin
                        pruebas de errores explícitas, devolviendo códigos de
                        error que el programador es responsable de probar. A
                        continuación se muestra un ejemplo de código que utiliza
                        las macros de la API de Judy y la prueba de errores
                        correspondientes:

                    
// Method two (2).

                    
JLI(PValue, PLArray, Index);
if (PValue == PJERR) goto out_of_memory_handling;

                    
JLD(RC_int, PLArray, Index);
if (RC_int == JERR) goto out_of_memory_handling;

                    
J1S(RC_int, P1Array, Index);
if (RC_int == JERR) goto out_of_memory_handling;

                    
J1U(RC_int, P1Array, Index);
if (RC_int == JERR) goto out_of_memory_handling;

                    
Nota: Sin definir 'JUDYERROR_NOTEST', el
                        'goto out_of_memory_handling' nunca se ejecutará y será
                        optimizado por el compilador. Se utilizará el método
                        predeterminado: la Macro imprimirá información de error si
                        ocurre un error, como se explicó anteriormente.

                    
Con 'JUDYERROR_NOTEST' definido, el 'goto
                        out_of_memory_handling' se ejecutará cuando ocurra un error,
                        lo que solo debería suceder cuando falla malloc().

                

                

                    
3)   Método de macro JUDYERROR() especificado por el usuario

                    
La macro JUDYERROR() (en Judy.h)
                        proporciona flexibilidad para manejar los retornos de
                        error según sea necesario para adaptarse a su programa, sin
                        dejar de utilizar las macros de la matriz Judy en lugar de
                        llamadas a funciones. Puede utilizar una macro
                        JUDYERROR() diferente para adaptarse a sus
                        necesidades. El siguiente ejemplo es una posible alternativa
                        al predeterminado. Se utiliza para distinguir entre los dos
                        tipos de errores (descritos anteriormente) y para probar
                        explícitamente los errores restantes de JU_ERRNO_NOMEM
                        posibles en su programa.

                    
// Este es un ejemplo de la API de macro de Judy para continuar cuando no hay memoria
// e imprimir y salir(1) cuando ocurre cualquier otro error.

                    
#ifndef JUDYERROR_NOTEST
#include <stdio.h>  // necesario para fprintf()

                    
// Esta es la macro que las APIs de macro de Judy utilizan para códigos de retorno de -1:

                    
#define JUDYERROR(CallerFile, CallerLine, JudyFunc, JudyErrno, JudyErrID) \
{                                                                         \
    if ((JudyErrno) != JU_ERRNO_NOMEM) /* ! falla malloc() */         \
    {                                                                     \
        (void) fprintf(stderr, "File '%s', line %d: %s(), "               \
            "JU_ERRNO_* == %d, ID == %d\n",                               \
            CallerFile, CallerLine,                                       \
            JudyFunc, JudyErrno, JudyErrID);                              \
        exit(1);                                                          \
    }                                                                     \
}
#endif // JUDYERROR_NOTEST no definido


                    
Esta macro de manejo de errores debe incluirse
                        antes de la declaración #include <Judy.h> en
                        su programa.
