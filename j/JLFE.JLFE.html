Un arreglo JudyL es el equivalente a un arreglo de valores del tamaño de una

palabra. Un

Valor es direccionado por un Índice (clave). El arreglo puede ser disperso, y el Índice puede ser cualquier número del tamaño de una palabra. La memoria para soportar el arreglo es asignada a medida que se insertan pares índice/valor, y liberada a medida que se eliminan pares índice/valor. Un arreglo JudyL también puede ser pensado como un mapeador, es decir, "mapear" una palabra a otra palabra/puntero. Como con un arreglo ordinario, no hay índices duplicados en un arreglo

JudyL.

El valor puede ser usado como un escalar, o un puntero a una estructura o bloque de datos (o incluso otro arreglo Judy)

.

JLF(), JLN(), JLL(), JLP() le permiten buscar índices en el arreglo. Puede buscar inclusiva o exclusivamente, en direcciones hacia adelante o hacia atrás. Si es exitoso, Index es retornado establecido al índice encontrado, y PValue es retornado establecido a un puntero al Valor del Índice. Si no es exitoso, PValue es retornado establecido a NULL, y Index no contiene información útil. PValue debe ser probado para no serNULL antes de usar Index, ya que es posible
que la bús
queda falle.
JLFE(), JLNE(), JLLE(), JLPE() le permiten buscar índices que no están presentes ("vacíos") en el arreglo. Puede buscar inclusiva o exclusivamente, en direcciones hacia adelante o hacia atrás. Si es exitoso, Index es retornado establecido a un índice no presente ("vacío"), y Rc_int es retornado establecido a 1. Si no es exitoso, Rc_int es retornado establecido a 0, y Index no contiene información útil. Rc_int debe ser verificado antes de usar Index, ya que es posible
que la bús

Arreglos JudyL multidimensionale

s

Almacenar un puntero a otro arreglo JudyL en el Valor de un arreglo JudyL es una forma sencilla de soportar arreglos multidimensionales dinámicos. Estos arreglos (o árboles) construidos usando arreglos JudyL son muy rápidos y eficientes en memoria. (De hecho, así es como se implementan JudySL y JudyHS). Un número arbitrario de dimensiones puede realizarse de esta manera. Para terminar el número de dimensiones (o árbol), el Puntero de Valor se marca para NO apuntar a otro arreglo Judy. Una bandera JLAP_INVALID se usa en el/los bit(s) menos significativo(s) del puntero. Después de que la bandera JLAP_INVALID se elimina, se usa como un puntero a los datos del usuario. El archivo de cabecera Judy.h define JLAP_INVALID. Vea el fragmento de código a

continuación.

Nota: La versión actual de Judy.h cambió esta bandera de 0x4 a 0x1 para permitir un malloc() que no entregue memoria en un límite alineado a 8 bytes (como versiones antiguas de valgrind)

.

El siguiente segmento de código de ejemplo puede usarse para determinar si un puntero apunta o no a otro

JudyL: 
PValue = (PWord_t)
PMultiDimArray; 
for (Dim = 0; ;Dim++)

   /* Verificar si es un puntero al búfer del usuario: */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // enmascarar y convertir.
printf("El puntero al objeto del usuario es 0x%lx\n", (Word_t) UPointer);
