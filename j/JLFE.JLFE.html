Arreglos JudyL multidimensionale

s

Almacenar un puntero a otro arreglo JudyL en el Valor de un arreglo JudyL es una forma sencilla de soportar arreglos multidimensionales dinámicos. Estos arreglos (o árboles) construidos usando arreglos JudyL son muy rápidos y eficientes en memoria. (De hecho, así es como se implementan JudySL y JudyHS). Un número arbitrario de dimensiones puede realizarse de esta manera. Para terminar el número de dimensiones (o árbol), el Puntero de Valor se marca para NO apuntar a otro arreglo Judy. Una bandera JLAP_INVALID se usa en el/los bit(s) menos significativo(s) del puntero. Después de que la bandera JLAP_INVALID se elimina, se usa como un puntero a los datos del usuario. El archivo de cabecera Judy.h define JLAP_INVALID. Vea el fragmento de código a

continuación.

Nota: La versión actual de Judy.h cambió esta bandera de 0x4 a 0x1 para permitir un malloc() que no entregue memoria en un límite alineado a 8 bytes (como versiones antiguas de valgrind)

.
