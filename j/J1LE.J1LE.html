Este nuevo añadido (Mayo 2004) a Judy es un híbrido que usa las mejores características de los métodos de hashing y de Judy. El autor cree que JudyHS es un buen reemplazo para un método de hashing cuando el redimensionamiento de la tabla hash se hace durante el crecimiento de la población. Un método de hashing correctamente ajustado con un tamaño de tabla hash estátic

o

y población es imbatible en velocidad. Sin embargo, JudyHS tendrá un mejor rendimiento que un método de hashing con poblaciones más pequeñas y más grandes que el tamaño óptimo de la tabla hash. JudyHS no tiene un caso de rendimiento degenerado donde el conocimiento del algoritmo hash pueda ser explotado. (Es decir, JudyHS no usa una lista enlazada para manejar colisiones hash, usa un árbol de arreglos JudyL y un tamaño de tabla hash virtual de 4 mil millones). Los arreglos Judy son tanto eficientes en velocidad como en memoria , sin requerir ajustes ni configuración, a través de una amplia gama de tipos de conjuntos de índices (secuenciales, periódicos, agrupados, aleatorios). La velocidad y el uso de memoria de Judy son típicamente mejores que otros modelos de almacenamiento de datos como listas de saltos, listas enlazadas, binarias, ternarias, árboles B, o incluso

hashing, y mejoran con conjuntos de datos muy grandes.

Un arreglo Judy es creado simplemente definiendo un puntero nulo y luego almacenando (insertando) el primer elemento en el arreglo bajo ese puntero. La memoria usada por un arreglo Judy es casi proporcional a la población (número de elementos). Judy tiene dos Interfaces de Programación de Aplicaciones (APIs): una interfaz de macros C y una interfaz de llamadas a funciones. Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de usar las funciones Judy. Dado que un arreglo Judy inicial (vacío) es representado por un puntero nulo, es posible construir un arreglo de arreglos Judy. En otras palabras, los Valore

3) Método de Macro JUDYERROR() Especificada por el Usuario

La macro JUDYERROR() (en Judy.h) proporciona flexibilidad para manejar los retornos de error según sea necesario para adaptarse a su programa, mientras aún usa las macros de arreglos Judy en lugar de llamadas a funciones. Puede usar una JUDYERROR() macro diferente para adaptarse a sus necesidades. El siguiente ejemplo es una posible alternativa a la predeterminada. Se utiliza para distinguir entre los dos tipos de errores (descritos anteriormente) y probar explícitamente los errores JU_ERRNO_NOMEM restantes posibles en su programa.

// Este es un ejemplo de la API de macros de Judy para continuar cuando se queda sin memoria
// e imprimir y exit(1) cuando ocurre cualquier otro error.
#ifndef JUDYERROR_NOTEST
#include <stdio.h>  // necesario para fprintf()
// Esta es la macro que las APIs de macros de Judy usan para códigos de retorno de -1:
#define JUDYERROR(CallerFile, CallerLine, JudyFunc, JudyErrno, JudyErrID) \
{                                                                         \
    if ((JudyErrno) != JU_ERRNO_NOMEM) /* ! un fallo de malloc() */       \
    {                                                                     \
        (void) fprintf(stderr, "Archivo '%s', línea %d: %s(), "           \
            "JU_ERRNO_* == %d, ID == %d\n",                               \
            CallerFile, CallerLine,                                       \
            JudyFunc, JudyErrno, JudyErrID);                              \
        exit(1);                                                          \
    }                                                                     \
}
#endif // JUDYERROR_NOTEST no definido
Esta macro de manejo de errores debe incluirse antes de la declaración #include <Judy.h> en su programa.
