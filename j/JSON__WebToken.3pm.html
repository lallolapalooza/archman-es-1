NOMBRE

JSON::WebToken - Implementación de JSON Web Token (JWT)

SINOPSIS

use Test::More;
use JSON;
use JSON::WebToken;
my $claims = {
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
};
my $secret = 'secret';
my $jwt = encode_jwt $claims, $secret;
my $got = decode_jwt $jwt, $secret;
is_deeply $got, $claims;
done_testing;

DESCRIPCIÓN

JSON::WebToken es una implementación de JSON Web Token (JWT) para Perl.

ESTE MÓDULO TIENE UNA INTERFAZ DE NIVEL ALPHA.

MÉTODOS

encode($claims [, $secret, $algorithm, $extra_headers ]) : String

Este método codifica un JWT a partir de una referencia a hash.

my $jwt = JSON::WebToken->encode({
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
}, 'secret');
# $jwt = join '.',
#     'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9',
#     'eyJleHAiOjEzMDA4MTkzODAsImh0dHA6Ly9leGFtcGxlLmNvbS9pc19yb290Ijp0cnVlLCJpc3MiOiJqb2UifQ'
#     '4ldFxjibgJGz_uaIRCIq89b5ipR-sbI2Uq7B2WNEDs0'

El algoritmo de cifrado predeterminado es "HS256". Puede cambiar el algoritmo de la siguiente manera:

my $pricate_key_string = '...';
my $public_key_string  = '...';
my $jwt = JSON::WebToken->encode({
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
}, $pricate_key_string, 'RS256');
my $claims = JSON::WebToken->decode($jwt, $public_key_string);

Cuando utiliza los algoritmos RS256, RS384 o RS512, necesitamos Crypt::OpenSSL::RSA.

Si desea crear un "JWT sin cifrar", debe especificar "none" como algoritmo.

my $jwt = JSON::WebToken->encode({
    iss => 'joe',
    exp => 1300819380,
    'http://example.com/is_root' => JSON::true,
}, '', 'none');
# $jwt = join '.',
#     'eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0',
#     'eyJleHAiOjEzMDA4MTkzODAsImh0dHA6Ly9leGFtcGxlLmNvbS9pc19yb290Ijp0cnVlLCJpc3MiOiJqb2UifQ',
#     ''

decode($jwt [, $secret, $verify_signature, $accepted_algorithms ]) : HASH

Este método decodifica una referencia a hash a partir de una cadena JWT.

my $claims = JSON::WebToken->decode($jwt, $secret, 1, ["RS256"]);

Cualquier algoritmo de firma (excepto "none") es aceptable de forma predeterminada, por lo que debe comprobarlo con el parámetro $accepted_algorithms .

add_signing_algorithm($algorithm, $class)

Este método añade un algoritmo de firma.

# resolve JSON::WebToken::Crypt::MYALG
JSON::WebToken->add_signing_algorithm('MYALGXXX'   => 'MYALG');
# resolve Some::Class::Algorithm
JSON::WebToken->add_signing_algorithm('SOMEALGXXX' => '+Some::Class::Algorithm');

VÉASE TAMBIÉN JSON::WebToken::Crypt::HMAC o JSON::WebToken::Crypt::RAS.

FUNCIONES

encode_jwt($claims [, $secret, $algorithm, $extra_headers ]) : String

Igual que el método encode() .

decode_jwt($jwt [, $secret, $verify_signature, $accepted_algorithms ]) : Hash

Igual que el método decode() .

CÓDIGOS DE ERROR

Se lanzará una excepción JSON::WebToken::Exception con el siguiente código.

ERROR_JWT_INVALID_PARAMETER

Cuando algunos argumentos del método no son válidos.

ERROR_JWT_MISSING_SECRET

Cuando se requiere un secreto. ("alg != "none"")

ERROR_JWT_INVALID_SEGMENT_COUNT

Cuando el número de segmentos del JWT no está entre 2 y 4.

ERROR_JWT_INVALID_SEGMENT_ENCODING

Cuando cada segmento del JWT no está codificado en base64url.

ERROR_JWT_UNWANTED_SIGNATURE

Cuando "alg == "none"" pero se encontró un segmento de firma.

ERROR_JWT_INVALID_SIGNATURE

Cuando la firma del JWT no es válida.

ERROR_JWT_NOT_SUPPORTED_SIGNING_ALGORITHM

Cuando el algoritmo de firma proporcionado no es compatible.

ERROR_JWT_UNACCEPTABLE_ALGORITHM

Cuando el algoritmo de firma proporcionado no está incluido en acceptable_algorithms.

    NAME

    JSON::WebToken - Create and verify JSON Web Tokens (JWTs)

    SYNOPSIS

    
use JSON::WebToken;

my $jwt = JSON::WebToken->new;

# Create a token
my $token = $jwt->encode({
    claim1 => 'value1',
    claim2 => 'value2',
}, 'secret-key');

# Verify a token
my $payload = $jwt->decode($token, 'secret-key');

if ($payload) {
    print "Claim1: ", $payload->{claim1}, "\n";
} else {
    print "Token verification failed\n";
}

    DESCRIPTION

    JSON::WebToken is a Perl module that implements the JSON Web Token (JWT) standard. It allows you to create and verify JWTs, which are a compact, URL-safe means of representing claims to be transferred between two parties.

    JWTs can be signed using HMAC algorithms (like HS256) or using asymmetric cryptography (like RS256). This module supports both.

    METHODS

    new()
    Constructor for the JSON::WebToken object.
    encode( $payload, $key, [%options] )
    Encodes a payload into a JWT.
    • $payload: A hashref containing the claims to be included in the token.
    • $key: The secret key or private key for signing the token.
    • %options: Optional parameters. Supported options include:
      • alg: The signing algorithm to use (e.g., 'HS256', 'RS256'). Defaults to 'HS256'.
      • header: A hashref containing additional header parameters.
    Returns the encoded JWT string.
    decode( $token, $key, [%options] )
    Decodes and verifies a JWT.
    • $token: The JWT string to decode.
    • $key: The secret key or public key for verifying the token's signature.
    • %options: Optional parameters. Supported options include:
      • alg: The expected signing algorithm. If not provided, it will be inferred from the token's header.
      • leeway: Allows for a time drift of the given number of seconds. Defaults to 0.
    Returns the decoded payload as a hashref if verification is successful, otherwise returns undef.

    EXAMPLES

    Creating a token

    
use JSON::WebToken;
my $jwt = JSON::WebToken->new;
my $payload = {
    iss => 'Me',
    exp => time + 3600, # Expires in 1 hour
    iat => time,
    'https://example.com/jwt_claims/isRoot' => TRUE,
};
my $token = $jwt->encode($payload, 'your-super-secret-key');
print "Encoded token: $token\n";

    Verifying a token

    
use JSON::WebToken;
my $jwt = JSON::WebToken->new;
my $token = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJNZSIsImV4cCI6MTY3ODg4NjQwMCwiaWF0IjoxNjc4ODgzODQwLCJodHRwczovL2V4YW1wbGUuY29tL2p3dF9jbGFpbXMvaXNSb290Ijp0cnVlfQ.SflKxwRJSMeKK924Iu0Rl9G3Kz_YjF_d_L3H0Y8f53Y'; # Example token
my $key = 'your-super-secret-key';
my $decoded_payload = $jwt->decode($token, $key);

if ($decoded_payload) {
    print "Token verified successfully!\n";
    use Data::Dumper;
    print Dumper($decoded_payload);
} else {
    print "Token verification failed.\n";
}

    Using RS256 (Asymmetric Cryptography)

    This requires OpenSSL to be installed on your system.

    
use JSON::WebToken;
my $jwt = JSON::WebToken->new;

# Generate keys (run this separately)
# openssl genrsa -out private.pem 2048
# openssl rsa -pubout -in private.pem -out public.pem

# Read keys
my $private_key = do { local $/; open my $fh, '<', 'private.pem' or die $!; <$fh> };
my $public_key  = do { local $/; open my $fh, '<', 'public.pem' or die $!; <$fh> };

my $payload = { data => 'some confidential data' };

# Encode using RS256
my $token = $jwt->encode($payload, $private_key, { alg => 'RS256' });
print "Encoded token (RS256): $token\n";

# Decode using RS256
my $decoded_payload = $jwt->decode($token, $public_key, { alg => 'RS256' });

if ($decoded_payload) {
    print "RS256 Token verified successfully!\n";
    use Data::Dumper;
    print Dumper($decoded_payload);
} else {
    print "RS256 Token verification failed.\n";
}
