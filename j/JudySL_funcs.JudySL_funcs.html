JudySL_funcs(3) Manual de funciones de biblioteca JudySL_funcs(3)

NOMBRE

Funciones JudySL - biblioteca C para crear y acceder a un array dinámico, utilizando una cadena terminada en nulo como índice (array asociativo)

SINOPSIS

PPvoid_t JudySLIns( PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
int      JudySLDel( PPvoid_t PPJSLArray, const uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLGet( Pcvoid_t  PJSLArray, const uint8_t * Index, PJError_t PJError);
Word_t   JudySLFreeArray(PPvoid_t PPJSLArray, PJError_t PJError);
PPvoid_t JudySLFirst( Pcvoid_t  PJSLArray, uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLNext( Pcvoid_t  PJSLArray, uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLLast( Pcvoid_t  PJSLArray, uint8_t * Index, PJError_t PJError);
PPvoid_t JudySLPrev( Pcvoid_t  PJSLArray, uint8_t * Index, PJError_t PJError);

DESCRIPCIÓN

Existe una macro equivalente para cada llamada a función. Dado que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones JudySL. Consulte JudySL(3) para obtener más información. Las definiciones de llamadas a funciones se incluyen aquí por completitud.

Una de las dificultades en el uso de las llamadas a funciones JudySL radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudySL también deben modificar el puntero al array JudySL, debe pasar la dirección del puntero en lugar del puntero en sí. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones JudySL tienen un parámetro adicional más allá de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error, o NULL (en cuyo caso la información detallada del error no se devuelve).

En las siguientes descripciones, las funciones se describen en términos de cómo las utilizan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros después de que su programa se haya depurado por completo. Cuando la macro JUDYERROR_NOTEST no se especifica, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudySL cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.


JudySLIns(&PJSLArray, Index, &JError)
#define JSLI(PValue, PJSLArray, Index) \
   PValue = JudyLIns(&PJSLArray, Index, PJE0)

JudySLDel(&PJSLArray, Index, &JError)
#define JSLD(Rc_int, PJSLArray, Index) \
   Rc_int = JudySLDel(&PJSLArray, Index, PJE0)

JudySLGet(PJSLArray, Index, &JError)
#define JSLG(PValue, PJSLArray, Index) \
   PValue = JudySLIns(PJSLArray, Index, PJE0)

JudySLFreeArray(&PJSLArray, &JError)
#define JSLFA(Rc_word, PJSLArray) \
   Rc_word = JudySLFreeArray(&PJSLArray, PJE0)

JudySLFirst(PJSLArray, Index, &JError)
#define JSLF(PValue, PJSLArray, Index) \
   PValue = JudySLFirst(PJSLArray, Index, PJE0)

JudySLNext(PJSLArray, Index, &JError)
#define JSLN(PValue, PJSLArray, Index) \
   PValue = JudySLNext(PJSLArray, Index, PJE0)

JudySLLast(PJSLArray, Index, &JError)
#define JSLL(PValue, PJSLArray, Index) \
   PValue = JudySLLast(PJSLArray, Index, PJE0)

JudySLPrev(PJSLArray, Index, &JError)
#define JSLP(PValue, PJSLArray, Index) \
   PValue = JudySLPrev(PJSLArray, Index, PJE0)

Las definiciones de todas las funciones JudySL, los tipos Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t y PJError_t, las constantes NULL, JU_ERRNO_*, JERR, PPJERR y PJE0 se proporcionan en el archivo de cabecera Judy.h (/usr/include/Judy.h). Nota: Los llamadores deben definir los arrays JudySL como tipo Pvoid_t, que puede pasarse por valor a funciones que toman Pcvoid_t (Pvoid_t constante), y también por dirección a funciones que toman PPvoid_t.

El tipo de retorno de la mayoría de las funciones de JudySL es PPvoid_t para que los valores almacenados en el array puedan ser punteros a otros objetos, lo cual es un uso típico, o para ser convertidos a un Word_t * cuando se requiere un puntero a un valor en lugar de un puntero a un puntero.
