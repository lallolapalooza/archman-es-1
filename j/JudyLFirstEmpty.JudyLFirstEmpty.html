NOMBRE

Funciones JudyL - Biblioteca C para crear y acceder a un array dinámico de palabras, usando cualquier valor de una palabra como índice

SINOPSIS

DESCRIPCIÓN

Existe un equivalente macro para cada llamada a función. Como las formas de macro a veces son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones JudyL. Vea JudyL(3) para más información. Las definiciones de las llamadas a funciones se incluyen aquí por completitud.

Una de las dificultades en el uso de las llamadas a funciones JudyL reside en determinar si se debe pasar un puntero o la dirección de un puntero. Como las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, debe pasar la dirección del puntero en lugar del puntero mismo. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones JudyL tienen un parámetro adicional más allá de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error, o NULL (en cuyo caso la información detallada del error no se devuelve).

En las siguientes descripciones, las funciones se describen en términos de cómo las usan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros después de que su programa haya sido completamente depurado. Cuando la macro JUDYERROR_NOTEST no se especifica, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Note la colocación del & en las diferentes funciones.

   PValue = JudyLIns(&PJLArray, Index, PJE0)

Las definiciones de todas las funciones Judy, los tipos Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t y PJError_t, las constantes NULL, JU_ERRNO_*, JERR, PPJERR y PJE0, se proporcionan en el archivo de cabecera Judy.h (/usr/include/Judy.h). Nota: Los llamadores deben definir los arrays JudyL como tipo

>Pvoid_t, que puede pasarse por valor a funciones que toman Pcvoid_t (constante Pvoid_t), y también por dirección a funciones que toman PPvoid_t.

El tipo de retorno de la mayoría de las funciones JudyL es PPvoid_t para que los valores almacenados en el array puedan ser punteros a otros objetos, lo cual es un uso típico, o se puedan castear a un Word_t * cuando se requiere un puntero a un Value en lugar de un puntero a un puntero.
