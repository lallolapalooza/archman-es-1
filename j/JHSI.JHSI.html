JHSI(JHSI)

Paquete: judy

Licencias: LGPL

JudyHS(3) Manual de funciones de la biblioteca JudyHS(3)

NOMBRE

Macros JudyHS - biblioteca C para crear y acceder a un array dinámico, usando un array de bytes de Longitud como Índice y una palabra como Valor.

SINOPSIS

cc [flags] archivos_fuente -lJudy
#include <Judy.h>
Word_t  * PValue;                           // elemento del array JudyHS
int       Rc_int;                           // indicador de retorno
Word_t    Rc_word;                          // valor de retorno de palabra completa
Pvoid_t   PJHSArray = (Pvoid_t) NULL;       // inicializar array JudyHS
uint8_t * Index;                            // puntero a array de bytes
Word_t    Length;                           // número de bytes en Index
JHSI( PValue,  PJHSArray, Index, Length);   // JudyHSIns()
JHSD( Rc_int,  PJHSArray, Index, Length);   // JudyHSDel()
JHSG( PValue,  PJHSArray, Index, Length);   // JudyHSGet()
JHSFA(Rc_word, PJHSArray);                  // JudyHSFreeArray()

DESCRIPCIÓN

Un array JudyHS es el equivalente a un array de punteros/valores del tamaño de una palabra. Un Índice es un puntero a un array de bytes de longitud especificada: Longitud. En lugar de usar una cadena terminada en nulo, esta diferencia con JudySL(3) permite que las cadenas contengan todos los bits (específicamente el carácter nulo). Esta nueva adición (mayo de 2004) a los arrays Judy es un híbrido que utiliza las mejores capacidades de los métodos de hashing y Judy. JudyHS no tiene un caso de rendimiento deficiente donde el conocimiento del algoritmo de hash pueda ser utilizado para degradar el rendimiento.

Dado que JudyHS se basa en un método de hash, los Índices no se almacenan en ningún orden particular. Por lo tanto, las funciones de búsqueda de vecinos JudyHSFirst(), JudyHSNext(), JudyHSPrev() y JudyHSLast() no son prácticas. La Longitud de cada array de bytes puede variar de 0 a los límites de malloc() (aproximadamente 2 GB).

El sello distintivo de JudyHS es la velocidad con escalabilidad, pero la eficiencia de memoria es excelente. La velocidad es muy competitiva con los mejores métodos de hashing. La eficiencia de memoria es similar a una lista enlazada de los mismos Índices y Valores. JudyHS está diseñado para escalar de 0 a miles de millones de Índices.

Un array JudyHS se asigna con un puntero NULL

Pvoid_t PJHSArray = (Pvoid_t) NULL;

Debido a que las formas de macro de la API tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de usar JudyHS.

JHSI(PValue, PJHSArray, Index, Length) // JudyHSIns()

Dado un puntero a un array JudyHS (PJHSArray), inserta un string Índice de longitud: Longitud y un Valor en el array JudyHS: PJHSArray. Si el Índice se inserta correctamente, el Valor se inicializa a 0. Si el Índice ya estaba presente, el Valor no se modifica.

Devuelve PValue apuntando al Valor. Su programa debe usar este puntero para leer o modificar el Valor, por ejemplo:

Value = *PValue;
*PValue = 1234;

Nota: JHSI() y JHSD pueden reorganizar el array JudyHS. Por lo tanto, los punteros devueltos por llamadas anteriores a JudyHS se vuelven inválidos y deben ser readquiridos (usando JHSG()).

JHSD(Rc_int, PJHSArray, Index, Length) // JudyHSDel()

Dado un puntero a un array JudyHS (PJHSArray), elimina el Índice especificado junto con el Valor del array JudyHS.

Devuelve Rc_int con valor 1 si se eliminó correctamente del array. Devuelve Rc_int con valor 0 si el Índice no estaba presente.

JHSG(PValue, PJHSArray, Index, Length) // JudyHSGet()

Dado un puntero a un array JudyHS (PJHSArray), busca el Valor asociado con el Índice.

Devuelve PValue apuntando al Valor del Índice. Devuelve PValue con valor NULL si el Índice no estaba presente.

JHSFA(Rc_word, PJHSArray) // JudyHSFreeArray()

Dado un puntero a un array JudyHS (PJHSArray), libera todo el array.

Devuelve Rc_word con el número de bytes liberados y PJHSArray con valor NULL.

ERRORES: Ver: Judy_3.htm#ERRORS

EJEMPLOS

Muestra cómo programar con las macros JudyHS. Este programa imprimirá líneas duplicadas y su número de línea desde stdin.

#include <unistd.h>
#include <stdio.h>
#include <string.h>
#include <Judy.h>
//  Compilado:
//  cc -O PrintDupLines.c -lJudy -o PrintDupLines
#define MAXLINE 1000000                 /* longitud máxima de línea de fgets */
uint8_t   Index[MAXLINE];               // cadena a verificar
int     // Uso:  PrintDupLines < archivo
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // Array Judy.
    PWord_t   PValue;                   // Puntero al elemento del array Judy.
    Word_t    Bytes;                    // tamaño del array JudyHS.
    Word_t    LineNumb = 0;             // número de línea actual
    Word_t    Dups = 0;                 // número de líneas duplicadas
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        LineNumb++;                     // número de línea
        // almacenar cadena en el array
        JHSI(PValue, PJArray, Index, strlen(Index)); 
        if (PValue == PJERR)            // Ver sección ERRORES
        {
            fprintf(stderr, "Sin memoria -- saliendo\n");
            exit(1);
        }
        if (*PValue == 0)               // comprobar si es duplicado
        {
            Dups++;
            printf("Líneas duplicadas %lu:%lu:%s", *PValue, LineNumb, Index);
        }
        else
        {
            *PValue = LineNumb;         // almacenar número de línea
        }
    }
    printf("%lu Duplicados, liberando array JudyHS de %lu Líneas\n", 
                    Dups, LineNumb - Dups);
    JHSFA(Bytes, PJArray);              // liberar array JudyHS
    printf("JudyHSFreeArray() liberó %lu bytes de memoria\n", Bytes);
    return (0);
}
