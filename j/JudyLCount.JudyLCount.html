DESCRIPCIÓN

Existe una forma de macro equivalente para cada llamada a función. Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones JudyL. Consulte JudyL(3) para obtener más información. Las definiciones de las llamadas a funciones se incluyen aquí para completar.

Una de las dificultades en el uso de las llamadas a funciones JudyL radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array JudyL también deben modificar el puntero al array JudyL, debe pasar la dirección del puntero en lugar del puntero en sí. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a funciones JudyL tienen un parámetro adicional además de los especificados en las llamadas a macros. Este parámetro es un puntero a una estructura de error, o NULL (en cuyo caso no se devuelve la información detallada del error).

En las siguientes descripciones, las funciones se describen en términos de cómo las usan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros una vez que su programa se haya depurado por completo. Cuando no se especifica la macro JUDYERROR_NOTEST, se declara una estructura de error para almacenar la información de error devuelta por las funciones JudyL cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.

JudyLCount(3) - Arch Linux

NAME

JudyLCount - JudySL Judy array low-level functions

SYNOPSIS

#include <Judy.h>

NS_JudyLCount(
    Word_t                     Index,
    JudySLSlot_t                   *Slot
);

NS_JudySLValueCount(
    Word_t                     Index,
    JudySLSlot_t                   *Slot
);

DESCRIPTION

JudySL array low-level functions are not meant to be used directly. They are intended to be used by the JudySL array. JudySL array low-level functions have been provided for the JudySL array and are not part of the JudySL array API.

NS_JudyLCount accesses the JudySL array slot and returns the count of matching entries. The Index is a 32-bit index into the JudySL array. The Slot is a pointer to a JudySLSlot_t which will contain the count.

NS_JudySLValueCount accesses the JudySL array slot and returns the count of matching entries for a specific JudySL array value. The Index is a 32-bit index into the JudySL array. The Slot is a pointer to a JudySLSlot_t which will contain the count.

Index values are passed by value and can be passed by value to functions that take Word_t, and also by address to functions that take PWord_t.

The return type from most JudyL functions is PPvoid_t so that the values stored in the array can be pointers to other objects, which is a typical usage, or cast to a Word_t * when a pointer to a Value is required instead of a pointer to a pointer.
