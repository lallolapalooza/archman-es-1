JudySL(3) Manual de funciones de biblioteca JudySL(3)

NOMBRE

JudySL - Librería de C para crear y acceder a un array dinámico, utilizando un string nulo-terminado como un Index (array asociativo)

SINOPSIS

cc [flags] sourcefiles -lJudy
#include <Judy.h>
#define MAXLINELEN 1000000           // definir longitud máxima de string
Word_t * PValue;                     // valor del elemento de array
uint8_t  Index[MAXLINELEN];          // string
int      Rc_int;                     // valor de retorno
Word_t   Rc_word;                    // valor de retorno completo
Pvoid_t PJSLArray = (Pvoid_t) NULL;  // inicializar array JudySL
JSLI( PValue,  PJSLArray, Index);   // JudySLIns()
JSLD( Rc_int,  PJSLArray, Index);   // JudySLDel()
JSLG( PValue,  PJSLArray, Index);   // JudySLGet()
JSLFA(Rc_word, PJSLArray);          // JudySLFreeArray()
JSLF( PValue,  PJSLArray, Index);   // JudySLFirst()
JSLN( PValue,  PJSLArray, Index);   // JudySLNext()
JSLL( PValue,  PJSLArray, Index);   // JudySLLast()
JSLP( PValue,  PJSLArray, Index);   // JudySLPrev()

DESCRIPCIÓN

Un array JudySL es equivalente a un conjunto ordenado de strings, cada uno asociado con un Valor (word). Un Valor se accede mediante un Index (clave), que es un string nulo-terminado de cualquier longitud. El espacio de memoria para el array se asigna como pares de índice/valor se insertan, y se libera cuando se eliminan los pares de índice/valor. Este es un tipo de array asociativo, donde los elementos del array también son ordenados lexicográficamente (casi sensible a la caja) según los índices. Esto puede pensarse así:

void * JudySLArray["Toto, I don't think we're in Kansas any more"];

Un array JudySL se aloca con un NULL pointer

Pvoid_t PJSLArray = (Pvoid_t) NULL;
Como con un array ordinario, no hay índices duplicados (strings) en un array JudySL.

Usando las macros descritas aquí, en lugar de las llamadas JudySL funciones, el manejo de errores por defecto envía un mensaje a stderr y termina el programa con exit(1).

JSLI(PValue, PJSLArray, Index) // JudySLIns()

Inserta un Index string y un Valor en el array JudySL PJSLArray. Si el Index se inserta correctamente, el Valor se inicializa en 0. Si el Index ya estaba presente, el Valor no se modifica.

Devuelve PValue apuntando a Valor del Index. Tu programa debe usar este puntero para modificar el Valor, por ejemplo:

*PValue = 1234;

Nota: JSLI() y JSLD reorganizan el array JudySL. Por lo tanto, los punteros devueltos de anteriores JudySL llamadas son inválidos y deben ser reacquiren.

JSLD(Rc_int, PJSLArray, Index) // JudySLDel()

Elimina el par Index/Valor (elemento del array) de la array JudySL.

Devuelve Rc_int como 1 si es exitoso. Si el Index no estaba previamente insertado, devuelve 0.

JSLG(PValue, PJSLArray, Index) // JudySLGet()

Obtiene el puntero a Valor del Index.

Devuelve PValue apuntando a Valor del Index. Si el Index no estaba presente, devuelve PValue como NULL.

JSLFA(Rc_word, PJSLArray) // JudySLFreeArray()

Dado un puntero a un array JudySL (PJSLArray), libera toda el array (más rápido que usar JSLN(), JSLD() bucles).

Devuelve Rc_word como número de bytes liberados y PJSLArray como NULL.

Funciones de búsqueda JudySL

Las funciones de búsqueda JudySL permiten buscar índices en el array. Puedes buscar inclusivamente o exclusivamente, en direcciones forward o reverse.

Si es exitoso, Index se devuelve como el índice encontrado, y PValue apunta a Valor del Index. Si no es exitoso, PValue se devuelve como NULL, y Index no tiene información útil. PValue debe ser probado para no NULL antes de usar Index, ya que puede fallar una búsqueda.

Nota: Para tomar en cuenta todos los posibles retornos, el Index buffer debe ser al menos tan grande como el string más largo almacenado en el array.

JSLF(PValue, PJSLArray, Index) // JudySLFirst()

Busca (inclusivo) el primer índice presente que es igual o mayor que el string pasado Index. (Empieza con un string vacío para encontrar el primer índice en el array.) JSLF() se usa típicamente para comenzar un escaneo ordenado de índices válidos en un array JudySL.

uint8_t Index[MAXLINELEN];
strcpy (Index, "");
JSLF(PValue, PJSLArray, Index);

JSLN(PValue, PJSLArray, Index) // JudySLNext()

Busca (excluyente) el siguiente índice presente que es mayor que el string pasado Index. JSLN() se usa típicamente para continuar un escaneo ordenado de índices válidos en un array JudySL, o para localizar un vecino de un índice dado.

JSLL(PValue, PJSLArray, Index) // JudySLLast()

Busca (inclusivo) el último índice presente que es igual o menor que el string pasado Index. (Empieza con un string máximo valor para buscar el último índice en el array, como un string de longitud 0xff.) JSLL() se usa típicamente para comenzar un escaneo ordenado inverso de índices válidos en un array JudySL.

JSLP(PValue, PJSLArray, Index) // JudySLPrev()

Busca (excluyente) el índice anterior presente que es menor que el string pasado Index. JSLP() se usa típicamente para continuar un escaneo ordenado inverso de índices válidos en un array JudySL, o para localizar un vecino de un índice dado.

Ejemplo de una rutina de ordenamiento de strings

#include <stdio.h>
#include <Judy.h>
#define MAXLINE 1000000                 // longitud máxima de string (línea)
uint8_t   Index[MAXLINE];               // string a insertar
int     // Uso:  JudySort < archivo_a_ordenar
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // array Judy.
    PWord_t   PValue;                   // elemento de array Judy.
    Word_t    Bytes;                    // tamaño del array JudySL.
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        JSLI(PValue, PJArray, Index);   // insertar string en el array
        if (PValue == PJERR)            // si no hay memoria?
        {                               // así lo haces
            printf("Malloc failed -- get more ram\n");
            exit(1);
        }
        ++(*PValue);                    // contar instancias de string
    }
    Index[0] = '\0';                    // comenzar con el string más pequeño.
    JSLF(PValue, PJArray, Index);       // obtener primer string
    while (PValue != NULL)
    {
        while ((*PValue)--)             // imprimir duplicados
            printf("%s", Index);
        JSLN(PValue, PJArray, Index);   // obtener siguiente string
    }
    JSLFA(Bytes, PJArray);              // liberar array
    fprintf(stderr, "El array JudySL utilizó %lu bytes de memoria\n", Bytes);
    return (0);
}
    fprintf(stderr, "The JudySL array used %lu bytes of memory\n", Bytes);
    return (0);
}
