JLFA(JLFA)

JudyL(3) Funciones de la Biblioteca JudyL(3)

NAME

Macros JudyL - Biblioteca C para crear y acceder a un array dinámico de palabras, utilizando una palabra como índice.

SYNOPSIS

cc [flags] sourcefiles -lJudy
#include <Judy.h>
int      Rc_int;                          // código de retorno - entero
Word_t   Rc_word;                         // código de retorno - palabra sin signo
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // puntero al valor de retorno
Pvoid_t PJLArray = (Pvoid_t) NULL;        // inicializar array JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPTION

Un array JudyL es equivalente a un array de valores de tamaño de palabra. Un Value se direcciona mediante un Index (clave). El array puede ser disperso, y el Index puede ser cualquier número de tamaño de palabra. La memoria para soportar el array se asigna como pares de índice/valor se insertan, y se libera como los pares de índice/valor se eliminan. Un array JudyL también puede considerarse como un mapeador, es decir, "mapear" una palabra a otra palabra/puntero.

Al igual que con un array ordinario, no hay índices duplicados en un array JudyL.

El valor puede usarse como un escalar, o como un puntero a una estructura o bloque de datos (o incluso a otro array JudyL).

Un array JudyL se asigna con un puntero NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

Utilizando los macros descritos aquí, en lugar de las llamadas a funciones JudyL, el manejo de errores por defecto envía un mensaje al error estándar y termina el programa con exit(1);. Para otros métodos de manejo de errores, ver la sección ERRORS. JLI( PValue, PJLArray, Index); // JudyLIns()

Dado que las formas de macro a veces son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones JudyL equivalentes, son el método preferido para llamar a las funciones JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Inserta un Index y un Value en el array JudyL PJLArray. Si el Index se inserta con éxito, el Value se inicializa a 0. Si el Index ya estaba presente, el Value no se modifica.
Devuelve PValue apuntando a Value. Su programa puede usar este puntero para leer o modificar Value hasta que se ejecute el siguiente JLI() (insertar), JLD() (eliminar) o JLFA() (liberar array) en PJLArray. Ejemplos:
*PValue = 1234;
Value = *PValue;
Devuelve PValue establecido en PJERR si falló una malloc(). Nota: JLI() y JLD() reorganizan el array JudyL. Por lo tanto, el PValue devuelto por llamadas anteriores de JudyL se vuelve inválido y debe ser reobtenido.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Elimina el par Index/Value del array JudyL.
Devuelve Rc_int establecido en 1 si se realizó con éxito. Devuelve Rc_int establecido en 0 si el Index no estaba presente. Devuelve Rc_int establecido en JERR si falló una malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
Obtiene el puntero PValue asociado con el Index en el array Judy PJLArray.
Devuelve PValue apuntando a Value. Devuelve PValue establecido en NULL si el Index no estaba presente. Devuelve PValue establecido en PJERR si falló una malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Cuenta el número de índices presentes en el array JudyL PJLArray entre el Index1 y el Index2 (incluido).
Devuelve Rc_word establecido en la cuenta. Un valor de retorno de 0 puede ser válido como una cuenta.
Para contar todos los índices presentes en un array JudyL, use:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localiza el Nth índice presente en el array JudyL PJLArray (Nth = 1 devuelve el primer índice presente).
Devuelve PValue apuntando a su Value y establece Index en el Nth índice si se encuentra, de lo contrario devuelve PValue establecido en NULL (el valor de Index es indefinido).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Dado un puntero a un array JudyL, libera todo el array (mucho más rápido que usar un bucle JLN(), JLD()).
Devuelve Rc_word establecido en el número de bytes liberados y establece PJLArray en NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Devuelve Rc_word establecido en el número de bytes de memoria asignados por malloc() por PJLArray. Esta es una rutina muy rápida, y puede usarse antes y después de una llamada JLI() o JLD() con poco impacto en el rendimiento.

JudyL Search Functions
JLF(), JLN(), JLL(), JLP() le permiten buscar índices en el array. Puede buscar inclusivamente o exclusivamente, en direcciones hacia adelante o hacia atrás. Si se realiza con éxito, Index se devuelve establecido en el índice encontrado, y PValue se devuelve establecido en un puntero al Value del Index. Si no se realiza con éxito, PValue se devuelve establecido en NULL, y Index no contiene información útil. PValue debe probarse para no ser NULL antes de usar Index, ya que es posible un fallo de búsqueda.
JLFE(), JLNE(), JLLE(), JLPE() le permiten buscar índices que no están presentes ("vacíos") en el array. Puede buscar inclusivamente o exclusivamente, en direcciones hacia adelante o hacia atrás. Si se realiza con éxito, Index se devuelve establecido en un índice no presente ("vacío"), y Rc_int se devuelve establecido en 1. Si no se realiza con éxito, Rc_int se devuelve establecido en 0, y Index no contiene información útil. Rc_int debe comprobarse antes de usar Index, ya que es posible un fallo de búsqueda.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Busca (inclusivamente) el primer índice presente que sea igual o mayor al Index pasado. (Comience con Index = 0 para encontrar el primer índice en el array.) JLF() se usa típicamente para iniciar una exploración en orden de clasificación de los índices presentes en un array JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Busca (exclusivamente) el siguiente índice presente que sea mayor que el Index pasado. JLN() se usa típicamente para continuar una exploración en orden de clasificación de los índices presentes en un array JudyL, o para localizar un "vecino" de un índice dado.
