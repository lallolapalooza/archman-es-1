DESCRIPCIÓN

Un

array JudyHS es el equivalente a un array de valores/punteros del tamaño de una palabra. Un Índice es un puntero a un array de bytes de longitud especificada: Longitud. En lugar de usar una cadena terminada en nulo, esta diferencia con JudySL(3) permite que las cadenas contengan todos los bits (específicamente el carácter nulo). Esta nueva adición (mayo de 2004) a los arrays Judy es un híbrido que usa las mejores capacidades del hashing y los métodos Judy. JudyHS no tiene un caso de rendimiento pobre donde el conocimiento

del

algoritmo de hash pueda usarse para degradar el rendimiento. Dado que JudyHS está basado en un método de hash, Los índices no se almacenan en ningún orden particular. Por lo tanto, las funciones de búsqueda de vecinos JudyHSFirst(), JudyHSNext(), JudyHSPrev() y JudyHSLast() no son prác

ticas.

La Longitud de cada array de bytes puede ir de 0 a los límites de malloc() (aproximadamente 2GB). El rasgo distintivo de JudyHS es la velocidad con escalabilidad, pero la eficiencia de memoria es excelente. La velocidad es muy competitiva con los mejores métodos de hashing. La eficienci
