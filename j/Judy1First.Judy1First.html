DESCRIPCIÓN

Existe una forma de macro equivalente para cada llamada a función. Dado que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones Judy1. Consulte Judy1(3) para obtener más información. Las definiciones de llamadas a función se incluyen aquí para completitud.

Una de las dificultades para usar las llamadas a función Judy1 radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el array Judy1 también deben modificar el puntero al array Judy1, debe pasar la dirección del puntero en lugar del puntero en sí. Esto a menudo conduce a errores de programación difíciles de depurar. En la práctica, las macros permiten que el compilador detecte errores de programación cuando se pasan punteros en lugar de direcciones de punteros.

Las llamadas a función Judy1 tienen un parámetro adicional más allá de los especificados en las llamadas macro. Este parámetro es un puntero a una estructura de error o NULL (en cuyo caso no se devuelve información detallada del error).

En las siguientes descripciones, las funciones se describen en términos de cómo las usan las macros (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de las macros una vez que su programa ha sido completamente depurado. Cuando la macro JUDYERROR_NOTEST no se especifica, se declara una estructura de error para almacenar la información de error devuelta por las funciones Judy1 cuando ocurre un error.

Observe la colocación del & en las diferentes funciones.

#define J1S(Rc_int, PJ1Array, Index) \

   Rc_word = Judy1Count(PJ1Array, Index1, Index2, PJE0)
Un valor de retorno de 0 puede ser un error, ser válido como recuento, o puede indicar un caso especial para un array completamente poblado (solo en máquinas de 32 bits). Si es necesario, el siguiente código puede usarse para desambiguar este retorno:
JError_t JError;
Rc_word = Judy1Count(PJ1Array, Index1, Index2, &JError);
if (Rc_word == 0)
{
    if (JU_ERRNO(&JError) == JU_ERRNO_NONE)
        printf("La población del array Judy1 == 0\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_FULL)
        printf("La población del array Judy1 == 2^32\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_NULLPPARRAY)
        goto NullArray;
    if (JU_ERRNO(&JError) >  JU_ERRNO_NFMAX)
        goto Null_or_CorruptArray;
}
