JudyL.JudyL

JudyL(3) Manual de funciones de biblioteca JudyL(3)

NOMBRE

Macros JudyL - biblioteca C para crear y acceder a un array dinámico de palabras, usando una palabra como índice.

SINOPSIS

cc [flags] sourcefiles -lJudy
#include <Judy.h>
int      Rc_int;                          // código de retorno - entero
Word_t   Rc_word;                         // código de retorno - palabra sin signo
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // puntero al valor de retorno
Pvoid_t PJLArray = (Pvoid_t) NULL;        // inicializar array JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPCIÓN

Un array JudyL es el equivalente a un array de valores del tamaño de una palabra. Un Valor se direcciona mediante un Índice (clave). El array puede ser disperso, y el Índice puede ser cualquier número del tamaño de una palabra. La memoria para soportar el array se asigna a medida que se insertan pares índice/valor, y se libera a medida que se eliminan pares índice/valor. Un array JudyL también puede pensarse como un mapeador, es decir, que "mapea" una palabra a otra palabra/puntero.

Como en un array ordinario, no hay índices duplicados en un array JudyL.

El valor puede usarse como un escalar, o un puntero a una estructura o bloque de datos (o incluso otro array Judy).

Un array JudyL se asigna con un puntero NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

Usando las macros descritas aquí, en lugar de las llamadas a la función JudyL, el manejo de errores por defecto envía un mensaje a la salida de error estándar y termina el programa con exit(1);. Para otros métodos de manejo de errores, véase la sección ERRORES . JLI( PValue, PJLArray, Index); // JudyLIns()

Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones JudyLequivalentes, son la forma preferida de llamar a las funciones JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Inserta un Índice y un Valor en el array JudyL PJLArray. Si el Índice se inserta correctamente, el Valor se inicializa a 0. Si el Índice ya estaba presente, el Valor no se modifica.
Devuelve PValue apuntando al Valor. Su programa puede usar este puntero para leer o modificar Valor hasta que se ejecute la siguiente JLI() (inserción), JLD() (eliminación) o JLFA() (freearray) sobre PJLArray. Ejemplos:
*PValue = 1234;
Value = *PValue;
Devuelve PValue establecido a PJERR si ocurrió un fallo de malloc() . Nota: JLI() y JLD() reorganizan el array JudyL. Por lo tanto, PValue devueltos de llamadas anteriores a JudyL se vuelven inválidos y deben ser re-adquiridos.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Elimina el par Índice/Valor del array JudyL.
Devuelve Rc_int establecido a 1 si fue exitoso. Devuelve Rc_int establecido a 0 si Index no estaba presente. Devuelve Rc_int establecido a JERR si ocurrió un fallo de malloc() .

JLG(PValue, PJLArray, Index) // JudyLGet()
Obtiene el puntero PValue asociado con Index en el array Judy PJLArray .
Devuelve PValue apuntando al Valor. Devuelve PValue establecido a NULL si el Índice no estaba presente. Devuelve PValue establecido a PJERR si ocurrió un fallo de malloc() .

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Cuenta el número de índices presentes en el array JudyL PJLArray entre Index1 y Index2 (inclusivo).
Devuelve Rc_word establecido al recuento. Un valor de retorno de 0 puede ser un recuento válido.
Para contar todos los índices presentes en un array JudyL, use:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localiza el índice Nth que está presente en el array JudyL PJLArray (Nth = 1 devuelve el primer índice presente).
Devuelve PValue apuntando a su Valor y Index establecido al índice Nth si se encontró, de lo contrario devuelve PValue establecido a NULL (el valor de Index es indefinido).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Dado un puntero a un array JudyL, libera el array completo (mucho más rápido que usar un bucle JLN(), JLD() ).
Devuelve Rc_word establecido al número de bytes liberados y PJLArray establecido a NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Devuelve Rc_word establecido al número de bytes de memoria malloc()'eados por PJLArray. Esta es una rutina muy rápida, y puede usarse antes y después de una llamada a JLI() o JLD() con poco impacto en el rendimiento.

Funciones de búsqueda JudyL
JLF(), JLN(), JLL(), JLP() le permiten buscar índices en el array. Puede buscar inclusiva o exclusivamente, en direcciones hacia adelante o hacia atrás. Si es exitoso, Index se devuelve establecido al índice encontrado, y PValue se devuelve establecido a un puntero al Valordel Índice. Si no es exitoso, PValue se devuelve establecido a NULL, y Index no contiene información útil. PValue debe probarse para no serNULL antes de usar Index, ya que es posible que la búsqueda falle.
JLFE(), JLNE(), JLLE(), JLPE() le permiten buscar índices que no están presentes ("vacíos") en el array. Puede buscar inclusiva o exclusivamente, en direcciones hacia adelante o hacia atrás. Si es exitoso, Index se devuelve establecido a un índice no presente ("vacío"), y Rc_int se devuelve establecido a 1. Si no es exitoso, Rc_int se devuelve establecido a 0, y Index no contiene información útil. Rc_int debe comprobarse antes de usar Index, ya que es posible que la búsqueda falle.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Busca (inclusivo) el primer índice presente que es igual o mayor que el Indexpasado. (Comience con Index = 0 para encontrar el primer índice en el array.) JLF() se usa típicamente para comenzar un escaneo en orden de clasificación de los índices presentes en un array JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Busca (exclusivo) el siguiente índice presente que es mayor que el índice Indexpasado. JLN() se usa típicamente para continuar un escaneo en orden de clasificación de los índices presentes en un array JudyL, o para localizar un "vecino" de un índice dado.
