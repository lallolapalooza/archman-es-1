NAME

Macros JudyL - Biblioteca C para crear y acceder a un arreglo dinámico de palabras, utilizando una palabra como índice.

SYNOPSIS

cc [flags] sourcefiles -lJudy
#include <Judy.h>
int      Rc_int;                          // código de retorno - entero
Word_t   Rc_word;                         // código de retorno - palabra entera
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // puntero a valor devuelto
Pvoid_t PJLArray = (Pvoid_t) NULL;        // inicializar arreglo JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

DESCRIPCIÓN

Un arreglo JudyL es equivalente a un arreglo de valores de tamaño palabra. Un valor se accede mediante un índice (clave). El arreglo puede ser esparso y el índice puede ser cualquier número de palabra. La memoria para el arreglo se aloca como pares de índice/valor se insertan, y se libera cuando se eliminan. También puede pensarse como un mapeador que "mappea" una palabra a otra palabra/pointer.

No hay índices duplicados en un arreglo JudyL.

El valor puede usarse como escalar, o como puntero a un estructura o bloque de datos (o incluso un arreglo JudyL).

El arreglo JudyL se aloca con un puntero NULL.

Pvoid_t PJLArray = (Pvoid_t) NULL;

Usando las macros descritas aquí, en lugar de las llamadas de funciones JudyL, el manejo de errores por defecto envía un mensaje a la salida estándar y termina el programa con exit(1);. Para otros métodos de manejo de errores, véase la sección ERRORS. JLI( PValue, PJLArray, Index); // JudyLIns()

Puesto que los formularios de macros pueden ser más rápidos y tienen una interfaz de manejo de errores más sencilla que las funciones equivalentes, son el método preferido para llamar a las funciones JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
Inserción de un índice y valor en el arreglo JudyL PJLArray. Si el índice se inserta correctamente, el valor se inicializa a 0. Si el índice ya existía, el valor no se modifica.
Devuelve PValue apuntando a Valor. Tu programa puede usar este puntero para leer o modificar Valor hasta que se ejecute JLI() (insertar), JLD() (eliminar) o JLFA() (liberar arreglo) en PJLArray. Ejemplos:
*PValue = 1234;
Valor = *PValue;
Devuelve PValue apuntando a PJERR si se produjo un falla al malloc(). Nota: JLI() y JLD() reorganizan el arreglo JudyL. Por lo tanto, el PValue devuelto de llamadas previas a JudyL se torna inválido y debe ser re-aceptado.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
Elimina el par de índice/valor de Index del arreglo JudyL PJLArray.
Devuelve Rc_int con valor 1 si fue exitoso. Devuelve Rc_int con valor 0 si el índice no existía. Devuelve Rc_int con valor JERR si se produjo un fallo al malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
Obtiene el puntero PValue asociado con el índice Index en el arreglo JudyL PJLArray.
Devuelve PValue apuntando a Valor. Devuelve PValue apuntando a NULL si el índice no existe. Devuelve PValue apuntando a PJERR si se produjo un fallo al malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
Contar el número de índices presentes en el arreglo JudyL PJLArray entre Index1 y Index2 (inclusivo).
Devuelve Rc_word con valor del conteo. Un valor de retorno de 0 puede ser válido como conteo.
Para contar todos los índices presentes en un arreglo JudyL, usa:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
Localizar el Nth índice presente en el arreglo JudyL PJLArray (Nth = 1 devuelve el primer índice presente).
Devuelve PValue apuntando a su Valor y Index con el Nth índice si lo encuentra, de lo contrario devuelve PValue apuntando a NULL (el valor de Index es undefined).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
Libera el arreglo completo dado un puntero a un arreglo JudyL (más rápido que usar JLN(), JLD()).
Devuelve Rc_word con valor del número de bytes liberados y PJLArray apuntando a NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
Devuelve Rc_word con valor del número de bytes de memoria malloc() usada por PJLArray. Este es una rutina muy rápida y puede ser usada antes y después de una llamada a JLI() o JLD() con poco impacto en la performance.

JudyL Search Functions
JLF(), JLN(), JLL(), JLP() permiten buscar índices en el arreglo. Puedes buscar inclusivamente o excluyentemente en direcciones forward o reverse. Si es exitoso, Index es devuelto apuntando a la índex encontrada, y PValue apunta a un puntero a Valor de la índex encontrada. Si no es exitoso, PValue es devuelto apuntando a NULL, y Index no contiene información útil. PValue debe ser verificado para no ser NULL antes de usar Index, ya que puede haber un fallo en la búsqueda.
JLFE(), JLNE(), JLLE(), JLPE() permiten buscar índices que no estén presentes ("vacíos") en el arreglo. Puedes buscar inclusivamente o excluyentemente en direcciones forward o reverse. Si es exitoso, Index es devuelto apuntando a un índice no presentes ("vacío"), y Rc_int es devuelto con valor 1. Si no es exitoso, Rc_int es devuelto con valor 0, y Index no contiene información útil. Rc_int debe ser verificado antes de usar Index, ya que puede haber un fallo en la búsqueda.

JLF(PValue, PJLArray, Index) // JudyLFirst()
Buscar (inclusivo) el primer índice presente que sea igual o mayor que el índice pasado. (Empieza con Index = 0 para encontrar el primer índice en el arreglo.) JLF() es típicamente usado para comenzar un escaneo en orden creciente de los índices presentes en un arreglo JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
Buscar (excluyente) el siguiente índice presente que sea mayor que el índice pasado. JLN() es típicamente usado para continuar un escaneo en orden creciente de los índices presentes en un arreglo JudyL, o para encontrar un "vecino" de un índice dado.

JLL(PValue, PJLArray, Index) // JudyLLast()
Buscar (inclusivo) el último índice presente que sea igual o menor que el índice pasado. JLL() es típicamente usado para comenzar un escaneos en orden decreciente de los índices presentes en un arreglo JudyL.

JLP(PValue, PJLArray, Index) // JudyLPrev()
Buscar (excluyente) el índice presente anterior que sea menor que el índice pasado. JLP() es típicamente usado para continuar un escaneo en orden decreciente de los índices presentes en un arreglo JudyL, o para encontrar un "vecino" de un índice dado.

JLFE(Rc_int, PJLArray, Index) // JudyLFirstEmpty()
Buscar (inclusivo) el primer índice no presente ("vacío") que sea igual o mayor que el índice pasado. (Empieza con Index = 0 para encontrar el primer índice no presente en el arreglo.) JLFE() es típicamente usado para comenzar un escaneo en orden creciente de los índices no presentes en un arreglo JudyL.

JLNE(Rc_int, PJLArray, Index) // JudyLNextEmpty()
Buscar (excluyente) el siguiente índice no presente ("vacío") que sea mayor que el índice pasado. JLNE() es típicamente usado para continuar un escaneo en orden creciente de los índices no presentes en un arreglo JudyL, o para encontrar el siguiente índice no presente.

JLLE(Rc_int, PJLArray, Index) // JudyLLastEmpty()
Buscar (inclusivo) el último índice no presente ("vacío") que sea igual o menor que el índice pasado. JLLE() es típicamente usado para comenzar un escaneo en orden decreciente de los índices no presentes en un arreglo JudyL.

JLPE(Rc_int, PJLArray, Index) // JudyLPrevEmpty()
Buscar (excluyente) el índice no presente ("vacío") anterior que sea menor que el índice pasado. JLPE() es típicamente usado para continuar un escaneo en orden decreciente de los índices no presentes en un arreglo JudyL, o para encontrar el índice no presente anterior.

ERRORS

Las macros JudyL detectan fallos y devuelven PJERR o JERR y envían un mensaje de error a la salida estándar. La aplicación entonces termina con exit(1). Si se desea una rutina de manejo de errores diferente, hay que cambiar el código.

NAME

JudyL - Judy1 array's low-memory, linear-index, arbitrary-value-type array routines

SYNOPSIS

#include <Judy.h>

Pvoid_t PJLArray;

Word_t Index, Value, *PValue;

int Rc_int;

// Insert functions
Rc_int = JLI(PValue, PJLArray, Index);
Rc_int = JLIE(PValue, PJLArray, Index);
Rc_int = JLIS(PValue, PJLArray, Index, Value);
Rc_int = JLIT(PValue, PJLArray, Index, Value);

// Query functions
Rc_int = JLC(PValue, PJLArray, Index);
Rc_int = JLCE(PValue, PJLArray, Index);
Rc_int = JLO(PValue, PJLArray, Index);
Rc_int = JLOE(PValue, PJLArray, Index);
Rc_int = JLA(PValue, PJLArray, Index);
Rc_int = JLAE(PValue, PJLArray, Index);
Rc_int = JLL(PValue, PJLArray, Index);
Rc_int = JLP(PValue, PJLArray, Index);
Rc_int = JLFE(Rc_int, PJLArray, Index);
Rc_int = JLNE(Rc_int, PJLArray, Index);
Rc_int = JLLE(Rc_int, PJLArray, Index);
Rc_int = JLPE(Rc_int, PJLArray, Index);

// Update functions
Rc_int = JLU(PValue, PJLArray, Index, Value);

// Delete functions
Rc_int = JLD(Rc_int, PJLArray, Index);
Rc_int = JLDT(Rc_int, PJLArray, Index);

// Empty functions
PJLArray = JL(void);
Rc_int = JLE(PJLArray);

// Error code function
int JudyLerror(void);

DESCRIPTION

The JudyL array implementation provides a dynamic, efficient, linear-indexed, arbitrary-value data structure. It is useful when you need to store a sparse array of values where the indexes are integers.

JudyL arrays are conceptually similar to C arrays, but with some significant differences:

  • Dynamic Sizing: JudyL arrays grow and shrink automatically as needed, eliminating the need for manual memory management of the array itself.
  • Sparse Storage: Memory is only allocated for the indexes that are actually in use.
  • Integer Indexes: Indexes must be of type Word_t (typically unsigned 64-bit integer).
  • Arbitrary Value Types: The value stored at each index can be of any type, accessed via a Word_t* pointer. The user is responsible for managing the memory of the values themselves if they are dynamically allocated.
  • Sorted Order: JudyL arrays maintain their indexes in sorted order, allowing for efficient traversal and searching.

The following table summarizes the primary functions:

JLI(PValue, PJLArray, Index) // JudyLInsert()
Insert the Index and allocate space for the Value. If the Index is already present, do nothing to the Value. Return a pointer to the Value. Note: The least significant bit of the returned pointer is cleared.
JLIE(PValue, PJLArray, Index) // JudyLInsertEmpty()
Insert the Index and allocate space for the Value *only if* the Index is not already present. Return a pointer to the Value. If the Index was already present, return NULL.
JLIS(PValue, PJLArray, Index, Value) // JudyLInsertSized()
Insert the Index and Value. If the Index is already present, the existing Value is overwritten. Return a pointer to the allocated Value.
JLIT(PValue, PJLArray, Index, Value) // JudyLInsertValue()
Insert the Index and Value. If the Index is already present, the existing Value is overwritten. Return a pointer to the allocated Value.
JLC(PValue, PJLArray, Index) // JudyLCount()
Return the number of elements currently stored in the JudyL array.
JLCE(PValue, PJLArray, Index) // JudyLCountEmpty()
Return the number of empty slots between the minimum and maximum index. This is not useful for sparse arrays.
JLO(PValue, PJLArray, Index) // JudyLLookup()
Search (inclusive) for the first index present that is equal to or greater than the passed Index. Return a pointer to the Value.
JLOE(PValue, PJLArray, Index) // JudyLLookupEmpty()
Search (inclusive) for the first index absent that is equal to or greater than the passed Index. Return NULL.
JLA(PValue, PJLArray, Index) // JudyLLookupAbsolute()
Search for the index specified by Index. Return a pointer to the Value.
JLAE(PValue, PJLArray, Index) // JudyLLookupAbsoluteEmpty()
Search for the index specified by Index. Return NULL if the index is not present.
JLL(PValue, PJLArray, Index) // JudyLLast()
Search (inclusive) for the last index present that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index in the array.) JLL() is typically used to begin a reverse-sorted-order scan of the indexes present in a JudyL array.
JLP(PValue, PJLArray, Index) // JudyLPrev()
Search (exclusive) for the previous index present that is less than the passed Index. JLP() is typically used to continue a reverse-sorted-order scan of the indexes present in a JudyL array, or to locate a "neighbor" of a given index.
JLFE(Rc_int, PJLArray, Index) // JudyLFirstEmpty()
Search (inclusive) for the first index absent that is equal to or greater than the passed Index. (Start with Index = 0 to find the first index absent in the array.)
JLNE(Rc_int, PJLArray, Index) // JudyLNextEmpty()
Search (exclusive) for the next index absent that is greater than the passed Index.
JLLE(Rc_int, PJLArray, Index) // JudyLLastEmpty()
Search (inclusive) for the last index absent that is equal to or less than the passed Index. (Start with Index = -1, that is, all ones, to find the last index absent in the array.)
JLPE(Rc_int, PJLArray, Index) // JudyLPrevEmpty()
Search (exclusive) for the previous index absent that is less than the passed Index.
JLU(PValue, PJLArray, Index, Value) // JudyLUpdate()
Update the Value at the specified Index. Return a pointer to the updated Value.
JLD(Rc_int, PJLArray, Index) // JudyLDelete()
Delete the Index and its associated Value from the JudyL array. Return 0 on success, or -1 on failure.
JLDT(Rc_int, PJLArray, Index) // JudyLDeleteType()
Delete the Index and its associated Value from the JudyL array. Return 0 on success, or -1 on failure. This function is identical to JLD().
JL(void) // JudyL()
Create an empty JudyL array. Return a pointer to the new array.
JLE(PJLArray) // JudyLEmpty()
Delete all elements from the JudyL array, freeing allocated memory. Return 0 on success, or -1 on failure.

Multi-dimensional JudyL Arrays

Storing a pointer to another JudyL array in a JudyL array's Value is a simple way to support dynamic multi-dimensional arrays. These arrays (or trees) built using JudyL arrays are very fast and memory efficient. (In fact, that is how JudySL and JudyHS are implemented). An arbitrary number of dimensions can be realized this way. To terminate the number of dimensions (or tree), the Value pointer is marked to NOT point to another Judy array. A JLAP_INVALID flag is used in the least significant bit(s) of the pointer. After the flag JLAP_INVALID is removed, it is used as a pointer to the users data. The Judy.h header file defines JLAP_INVALID. See code fragment below.

Note: The current version of Judy.h changed this flag from 0x4 to 0x1 to allow for a malloc() that does not deliver memory on an 8 byte aligned boundry (such as old versions of valgrind).

The following example code segment can be used to determine whether or not a pointer points to another JudyL:

PValue = (PWord_t)PMultiDimArray;
for (Dim = 0; ;Dim++)
{
   if (PValue == (PWord_t)NULL) goto IndexNotFound;
   /* Advance to next dimension in array */
   JLG(PValue, (Pvoid_t)*PValue, Index[Dim]);
   /* Check if pointer to user buffer: */
   if (*PValue & JLAP_INVALID)) break;
}
UPointer = (UPointer_t) (*PValue & ~JLAP_INVALID);  // mask and cast.
printf("User object pointer is 0x%lx\n", (Word_t) UPointer);
       ...

Note: This works because malloc() guarantees to return a pointer with the least bit(s) == 0x0. You must remove JLAP_INVALID before using the pointer.

ERRORS: See: Judy_3.htm#ERRORS

EXAMPLE

Read a series of index/value pairs from the standard input, store in a JudyL array, and then print out in sorted order.

#include <stdio.h>
#include <Judy.h>
Word_t   Index;                     // array index
Word_t   Value;                     // array element value
Word_t * PValue;                    // pointer to array element value
int      Rc_int;                    // return code
Pvoid_t  PJLArray = (Pvoid_t) NULL; // initialize JudyL array
while (scanf("%lu %lu", &Index, &Value))
{
    JLI(PValue, PJLArray, Index);
    If (PValue == PJERR) goto process_malloc_failure;
    *PValue = Value;                 // store new value
}
// Next, visit all the stored indexes in sorted order, first ascending,
// then descending, and delete each index during the descending pass.
Index = 0;
JLF(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLN(PValue, PJLArray, Index);
}
Index = -1;
JLL(PValue, PJLArray, Index);
while (PValue != NULL)
{
    printf("%lu %lu\n", Index, *PValue));
    JLD(Rc_int, PJLArray, Index);
    if (Rc_int == JERR) goto process_malloc_failure;
    JLP(PValue, PJLArray, Index);
}
