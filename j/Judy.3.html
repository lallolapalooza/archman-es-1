S

es un buen reemplazo para un método de hash cuando el redimensionamiento de la tabla hash se realiza durante el crecimiento de la población. Un método de hash correctamente ajustado con un tamaño de tabla hash estático y población es imbatible en velocidad. Sin embargo, JudyHS tendrá un mejor rendimiento que un método de hash con poblaciones más pequeñas y más grandes que el tamaño óptimo de la tabla hash. JudyHS no tiene un caso de rendimiento degenerado donde el conocimiento del algoritmo hash pueda ser explotado. (Es decir, JudyHS no usa una lista enlazada para manejar colisiones de hash, usa un árbol de arreglos JudyL y un tamaño de tabla hash virtual de 4 mil millones). Los arreglos Judy son tanto rápido

s

La velocidad y el uso de memoria de Judy son típicamente mejores que otros modelos de almacenamiento de datos como listas de saltos, listas enlazadas, binarias, ternarias, árboles B, o incluso el hash, y mejoran con conjuntos de datos muy grandes. Un arreglo Judy se crea simplemente definiendo un puntero nulo y luego almacenando (insertando) el primer elemento en el arreglo bajo ese puntero. La memoria usada por un arreglo Judy es casi proporcional a la población (número de elementos). Judy tiene dos Interfaces de Programación de Aplicaciones (API): una interfaz de macro C y una interfaz de llamada a función. Debido a que las formas de macro son a veces más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma

preferida de usar las funciones de Judy.

Dado que un arreglo Judy inicial (vacío) está representado por un puntero nulo, es posible construir un arreglo de arreglos Judy. En otras palabras, los Valores de un arreglo Judy (excepto Judy1) pueden ser punteros a otros arreglos Judy. Esto hace que sea muy simple construir un arreglo con un número arbitrario de dimensiones o tamaños de Índice . (JudySL y JudyHS se implementan usando JudyL de esta manera). 3) Método de Macro JUDYERROR() Especificada por el Usuario

La JUDYERROR() macro (en Judy.h) proporciona flexibilidad para manejar los retornos de error según sea necesario para adaptarse a su programa mientras aún usa las macros de array de Judy en lugar de llamadas a funciones. Puede usar una JUDYERROR() macro diferente para adaptarse a sus necesidades. El siguiente ejemplo es una posible alternativa a la predeterminada. Se usa para distinguir entre los dos tipos de errores (descritos arriba), y probar explícitamente los errores JU_ERRNO_NOMEM restantes posibles en su programa. // Este es un ejemplo de la API de macro de Judy para continuar cuando no hay memoria // e imprimir y exit(1) cuando ocurre cualquier otro error.

#ifndef JUDYERROR_NOTEST
#include <stdio.h>  // necesario para fprintf()
// Esta es la macro que las APIs de macro de Judy usan para los códigos de retorno de -1:
#define JUDYERROR(CallerFile, CallerLine, JudyFunc, JudyErrno, JudyErrID) \
{                                                                         \
    if ((JudyErrno) != JU_ERRNO_NOMEM) /* ! un fallo de malloc() */       \
    {                                                                     \
        (void) fprintf(stderr, "Archivo '%s', línea %d: %s(), "           \
            "JU_ERRNO_* == %d, ID == %d\n",                               \
            CallerFile, CallerLine,                                       \
            JudyFunc, JudyErrno, JudyErrID);                              \
        exit(1);                                                          \
    }                                                                     \
}
#endif // JUDYERROR_NOTEST no definido
