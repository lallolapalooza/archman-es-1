DESCRIPCIÓ

N

Existe un macro equivalente para cada llamada a función. Debido a que las formas de macro a veces son más rápidas y tienen una interfaz de manejo de errores más simple que las funciones equivalentes, son la forma preferida de llamar a las funciones Judy1. Véase Judy1(3) para más información. Las definiciones de las llamadas a funciones se incluyen aquí para

completitud.

Una de las dificultades al usar las llamadas a funciones Judy1 radica en determinar si se debe pasar un puntero o la dirección de un puntero. Dado que las funciones que modifican el arreglo Judy1 también deben modificar el puntero al arreglo Judy1, se debe pasar la dirección del puntero en lugar del puntero mismo. Esto a menudo conduce a errores programáticos difíciles de depurar. En la práctica, los macros permiten al compilador detectar errores de programación cuando se pasan punteros en lugar de direcciones de

punteros.

Las llamadas a funciones Judy1 tienen un parámetro adicional más allá de los especificados en las llamadas a macro. Este parámetro es o bien un puntero a una estructura de error, o NULL (en cuyo caso la información detallada del error no se devuelve)

.

En las siguientes descripciones, las funciones se describen en términos de cómo los macros las usan (solo en el caso de #define JUDYERROR_NOTEST 1). Este es el uso sugerido de los macros después de que su programa haya sido completamente depurado. Cuando el macro JUDYERROR_NOTEST no se especifica, se declara una estructura de error para almacenar la información de error devuelta por las funciones Judy1 cuando ocurre un

error.

Observe la colocación del & en las diferentes

funciones.

Judy1PrevEmpty(3) - Judy C library

NAME

Judy1PrevEmpty, J1PE – find the previous empty index in a Judy1 array

SYNOPSIS

Judy1Counter_t Judy1PrevEmpty(PJ1Array_t PJ1Array, Word_t *Index, JError_t *JError);
#define J1PE(Rc_int, PJ1Array, Index) \
    Rc_int = Judy1PrevEmpty(PJ1Array, &Index, PJE0)

DESCRIPTION

The Judy1PrevEmpty function is used to find an empty index in a Judy1 array. An empty index is an index that is not set in the Judy1 array. Judy1PrevEmpty is an inverse to Judy1NextEmpty(3).

To find the index of the first empty slot, call Judy1PrevEmpty with the index set to 0. To find the index of the next empty slot after the current index, call Judy1PrevEmpty with the index set to the index you wish to start searching backwards from.

The Judy1 array is passed by value. The index is passed by address. Judy1PrevEmpty returns a value that is appropriate for a Judy1(3) array.

The J1PE macro is provided for convenience. It sets the Judy error status to PJE0.

The return value for Judy1PrevEmpty is the next index backwards from the one that is passed in by address. The index is returned by value and also placed back into the address that was passed in.

If the Judy array is empty, the index is set to 0 and the return value is 0.

If there are no more empty slots backwards from the index, the index is set to 0 and the return value is 0.

The Judy library functions require that the Judy array be initialized. This is done via the Judy1Ins(3) or Judy1ByBit(3) functions, or by calling Judy1Init(3).

If an error occurs, *JError will be set to one of the JU_ERRNO_* constants.

Definitions for all of the Judy functions, the types Pvoid_t, Pcvoid_t, PPvoid_t, Word_t, JError_t, and PJError_t, the constants NULL, JU_ERRNO_*, JERR, and PJE0, are provided in the Judy.h header file (/usr/include/Judy.h). Note: Callers should define Judy1 arrays as type Pvoid_t, which can be passed by value to functions that take Pcvoid_t (constant Pvoid_t), and also by address to functions that take PPvoid_t.
