JSVC(1)

Paquete: java-jsvc

Licencias: APACHE

JSVC(1) Proyecto Apache Commons Daemon JSVC(1)

NOMBRE

jsvc - aplicación para lanzar demonios java

SINOPSIS


jsvc
[-jvm nombre JVM] [-client JVM cliente] [-server JVM servidor] [-classpath ruta] [-cp ruta] [-java-home directorio] [-version] [-help] [-?] [-nodetach] [-debug] [-check] [-user usuario] [-wait tiempo de espera] [-restarts máximo de reinicios] [-umask máscara] [-stop] [-verbose:class|gc|jni] [-outfile /ruta/completa/al/archivo] [-errfile /ruta/completa/al/archivo] [-pidfile /ruta/completa/al/archivo] [-Dproperty=valor] [-Xopción]

DESCRIPCIÓN

jsvc ejecuta archivo de clase que implementa una interfaz de Daemon.

OPCIONES

-jvm nombre JVM
usa una máquina virtual Java específica.
-client JVM cliente
usa una máquina virtual Java cliente.
-server JVM servidor
usa una máquina virtual Java servidor.
-cp/ -classpath directorio y archivos zip/jar
establece la ruta de búsqueda para clases y recursos de servicio
-java-home directorio
establece la ruta de tu instalación JDK o JRE (o establece la variable de entorno JAVA_HOME)
-version
muestra la versión actual del entorno Java (para verificar la corrección de -home y -jvm. Implica -nodetach)
-help
muestra esta página de ayuda (implica -nodetach)
-nodetach
no se separa del proceso padre y se convierte en un demonio
-debug
imprime información de depuración de forma detallada
-check
solo verifica el servicio (implica -nodetach)
-stop
detiene el servicio usando el archivo dado en la opción -pidfile
-wait tiempo de espera
espera hasta waittime segundos a que el servicio se inicie. El tiempo de espera debe ser múltiplo de 10 (mínimo 10)
-restarts máximo de reinicios
máximo número de reinicios automáticos -1=infinito (por defecto), 0=ninguno, 1..(INT_MAX-1)=número fijo
-umask máscara
establece la máscara de creación del modo de archivo
-user usuario
usuario utilizado para ejecutar el demonio (por defecto, el usuario actual)
-verbose[:class|gc|jni]
habilita la salida detallada
-outfile /ruta/completa/al/archivo
ubicación para la salida estándar (por defecto, /dev/null). Usa el valor '&2' para simular '1>&2', o 'SYSLOG' para enviar la salida al registro del sistema.
-errfile /ruta/completa/al/archivo
ubicación para la salida de error estándar (por defecto, /dev/null). Usa el valor '&1' para simular '2>&1', o 'SYSLOG' para enviar la salida al registro del sistema.
-pidfile /ruta/completa/al/archivo
ubicación para la salida del archivo que contiene el PID de jsvc (por defecto, /var/run/jsvc.pid)
-D<nombre>=<valor>
establece una propiedad del sistema Java
-X<opción>
establece una opción específica de la máquina virtual

AUTOR

JSVC es parte del proyecto Apache Commons Daemon. Los autores son Jean-Frederic Clere, Remy Maucherat, Yoav Shapira, Bill Barker, Mladen Turk. JSVC se distribuye bajo la Licencia Apache Versión 2.0.
