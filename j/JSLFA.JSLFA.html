DESCRIPCIÓ

N

Un arreglo JudySL es el equivalente a un conjunto ordenado de cadenas, cada una asociada a un Valor (palabra). Un Valor es direccionado por un Índice (clave), que es una cadena de caracteres terminada en nulo de cualquier longitud. La memoria para soportar el arreglo se asigna a medida que se insertan pares índice/valor, y se libera a medida que se eliminan pares índice/valor. Esta es una forma de arreglo asociativo, donde los elementos del arreglo también están ordenados lexicográficamente (sensible a mayúsculas/minúsculas) por índices. Esto podría pensarse

como 
void * JudySLArray["Toto, I don't think we're in Kansas any more"]
;

Un arreglo JudySL se asigna con un puntero

NULL 
Pvoid_t PJSLArray = (Pvoid_t) NULL;
Al
igual que con un arreglo ordinario, no hay índices (cadenas) duplicados en un arreglo JudySL.

Usando las macros descritas aquí, en lugar de las llamadas a la función JudySL, el manejo de errores por defecto envía un mensaje a la salida de error estándar y termina el programa con exit

Funciones de Búsqueda de

JudySL

Las funciones de búsqueda de JudySL le permiten buscar índices en el arreglo. Puede buscar de forma inclusiva o exclusiva, en direcciones hacia adelante o hacia

atrás.

Si es exitoso, Index se devuelve establecido en el índice encontrado, y PValue se devuelve establecido en un puntero al Valor de Index. Si no es exitoso, PValue se devuelve establecido en NULL, y Index no contiene información útil. PValue debe ser probado para no serNULL antes de usar Index, ya que es posible que la búsqueda

falle.

Nota: Para acomodar todas las posibles devoluciones, el búfer Index debe ser al menos tan grande como

la cadena más grande alm
acenada en el arreglo.

JSLF(PValue, PJSLArray, Index) // JudySLFirst(

)

Busca (inclusivamente) el primer índice presente que es igual o mayor que la cadena Index pasada. (Comience con una cadena nula para encontrar el primer índice en el arreglo.) JSLF() se usa típicamente para comenzar un escaneo en orden de clasificación de los índices válidos en un arreglo

)

Busca (exclusivamente) el siguiente índice presente que es mayor que la cadena Index pasada. JSLN() se usa típicamente para continuar un escaneo en orden de clasificación de los índices válidos

Busca (inclusivamente) el último índice presente que es igual o menor que la cadena Index pasada. (Comience con una cadena de valor máximo para buscar el último índice en el arreglo, como una cadena de longitud máxima de bytes 0xff.) #define MAXLINE 1000000                 // max string (line)

int     // Usage:  JudySort < file_to_sort
main()
{
    Pvoid_t   PJArray = (PWord_t)NULL;  // Judy array.
    PWord_t   PValue;                   // Judy array element.
    Word_t    Bytes;                    // size of JudySL
array. 
    while (fgets(Index, MAXLINE, stdin) != (char *)NULL)
    {
        JSLI(PValue, PJArray, Index);   // store string into array
        if (PValue == PJERR)            // if out of memory?
        {                               // so do something
            printf("Malloc failed -- get more ram\n");
            exit(1);
        }
        ++(*PValue);                    // count instances of string
    }
    Index[0] = '\0';                    // start with smallest string.
    JSLF(PValue, PJArray, Index);       // get first string
    while (PValue != NULL)
    {
        while ((*PValue)--)             // print duplicates
            printf("%s", Index);
        JSLN(PValue, PJArray, Index);   // get next string
    }
    JSLFA(Bytes, PJArray);              // free
array 
    fprintf(stderr, "The JudySL array used %lu bytes of memory\n", Bytes);
    return (0);
}
