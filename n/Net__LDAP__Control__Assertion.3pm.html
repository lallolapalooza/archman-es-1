NOMBRE

Net::LDAP::Control::Assertion - Control de Afirmación LDAPv3

SINOSIS

use Net::LDAP;
use Net::LDAP::Control::Assertion;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$assert = Net::LDAP::Control::Assertion->new( assertion => '(sn=Jensen)' );
my $mesg = $ldap->modify( "cn=Barbara Jensen, o=University of Michigan, c=US",
                          replace => { givenName => "Babs" },
                          control => $assert );

DESCRIPCIÓN

"Net::LDAP::Control::Assertion" proporciona una interfaz para la creación y manipulación de objetos que representan el "Control de Afirmación" según se describe en la RFC 4528.

El "Control de Afirmación" permite al cliente especificar una condición, una afirmación, que debe ser VERDADERA para que la operación se procese normalmente. De lo contrario, la operación no se realiza. Por ejemplo, el control se puede usar con la operación Modify para realizar operaciones atómicas de "probar y establecer" y "probar y borrar".

El control es apropiado tanto para operaciones de interrogación como de actualización de LDAP, incluyendo Añadir, Comparar, Borrar, Modificar, ModificarDN (renombrar) y Buscar.

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control, se proporcionan los siguientes.

assertion => FILTRO
Un filtro que especifica la afirmación que debe evaluarse como VERDADERO para que la operación se procese normalmente.

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto que devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.
