Net__Jabber__XDB(3pm)

Net::Jabber::XDB(3) Documentación de Perl contribuida por el usuario Net::Jabber::XDB(3)

NOMBRE

Net::Jabber::XDB - Biblioteca XDB de Jabber

SINOPSIS

Net::Jabber::XDB es un complemento del módulo Net::Jabber. Proporciona al
usuario una interfaz sencilla para establecer y recuperar todas las partes
de un XDB de Jabber.

DESCRIPCIÓN

Net::Jabber::XDB se diferencia de los otros módulos Net::Jabber::* en que el
XMLNS de los datos se divide en más submódulos bajo XDB. Para conocer los
detalles de cada módulo, consulte la documentación de cada módulo
Net::Jabber::Data:*. Para ver la lista de espacios de nombres y módulos
disponibles, consulte Net::Jabber::Data.
Para inicializar el XDB con un <xdb/> de Jabber, debe pasarle la matriz
del árbol de XML::Parser. Por ejemplo:
  my $xdb = new Net::Jabber::XDB(@tree);
Ha habido un cambio en la forma antigua de gestionar las devoluciones de llamada.
Ya no tiene que hacer lo anterior, se pasa un objeto Net::Jabber::XDB a la
función de devolución de llamada para xdb:
  use Net::Jabber qw(Component);
  sub xdb {
    my ($XDB) = @_;
    .
    .
    .
  }
Ahora tiene acceso a todas las funciones de recuperación disponibles.
Para crear un nuevo xdb y enviarlo al servidor:
  use Net::Jabber;
  $XDB = new Net::Jabber::XDB();
  $XDBType = $XDB->NewData( type );
  $XDBType->SetXXXXX("yyyyy");
Ahora puede llamar a las funciones de creación para el XDB y para el <data/>
en el propio objeto Data nuevo. Consulte a continuación las funciones <xdb/>, y
en cada módulo de datos para esas funciones.
Para obtener más información sobre el formato de la matriz que se pasa a la
devolución de llamada, lea la documentación de Net::Jabber::Client.

MÉTODOS

Funciones de recuperación

GetTo()      - devuelve una cadena con el identificador de Jabber,
GetTo("jid")   o un objeto Net::Jabber::JID para la persona que va a
               recibir el <xdb/>. Para obtener el objeto JID, establezca
               la cadena en "jid", de lo contrario déjela en blanco
               para la cadena de texto.
               $to    = $XDB->GetTo();
               $toJID = $XDB->GetTo("jid");
GetFrom()      - devuelve una cadena con el identificador de Jabber,
GetFrom("jid")    o un objeto Net::Jabber::JID para la persona que
                  envió el <xdb/>. Para obtener el objeto JID,
                  establezca la cadena en "jid", de lo contrario
                  déjela en blanco para la cadena de texto.
                  $from    = $XDB->GetFrom();
                  $fromJID = $XDB->GetFrom("jid");
GetType() - devuelve una cadena con el tipo de <xdb/> que es.
            $type = $XDB->GetType();
GetID() - devuelve un entero con el id del <xdb/>.
          $id = $XDB->GetID();
GetAction() - devuelve una cadena con la acción de <xdb/> que es.
            $action = $XDB->GetAction();
GetMatch() - devuelve una cadena con la coincidencia de <xdb/> que es.
            $match = $XDB->GetMatch();
GetError() - devuelve una cadena con la descripción textual del error.
             $error = $XDB->GetError();
GetErrorCode() - devuelve una cadena con el código del error.
                 $errorCode = $XDB->GetErrorCode();
GetData() - devuelve un objeto Net::Jabber::Data que contiene los datos
            en el <data/> del <xdb/>.
            $dataTag = $XDB->GetData();
GetDataXMLNS() - devuelve una cadena con el espacio de nombres de los datos
                 para este <xdb/>, si existe.
                 $xmlns = $XDB->GetDataXMLNS();

Funciones de creación

SetXDB(to=>cadena|JID,    - establece varios campos en el <xdb/> a la vez.
      from=>cadena|JID,     Esta es una acción acumulativa y de
      id=>cadena,           sobrescritura. Si establece el atributo "to"
      type=>cadena,         dos veces, la segunda configuración es la que
      action=>cadena,       se utiliza. Si establece el estado y luego
      match=>cadena)        establece la prioridad, entonces ambos estarán
      errorcode=>cadena,    en la etiqueta <xdb/>. Para las configuraciones
      error=>cadena)        válidas, lea las funciones Set específicas a
                            continuación.
                            $XDB->SetXDB(type=>"get",
                                         to=>"bob\@jabber.org",
                                         data=>"info");
                            $XDB->SetXDB(to=>"bob\@jabber.org",
                                         errorcode=>403,
                                         error=>"Permiso denegado");
SetTo(cadena) - establece el atributo to. Puede pasar una cadena o un
SetTo(JID)      objeto JID. Deben ser identificadores de Jabber válidos
                o el servidor devolverá un mensaje de error.
                (ej. jabber:bob@jabber.org, etc...)
               $XDB->SetTo("bob\@jabber.org");
SetFrom(cadena) - establece el atributo from. Puede pasar una cadena o un
SetFrom(JID)      objeto JID. Deben ser identificadores de Jabber válidos
                  o el servidor devolverá un mensaje de error.
                  (ej. jabber:bob@jabber.org, etc...)
                  $XDB->SetFrom("me\@jabber.org");
SetType(cadena) - establece el atributo type. Las configuraciones válidas
                  son:
                  get      solicitar información
                  set      establecer información
                  result   resultados de una solicitud get
                  error    hubo un error
                  $XDB->SetType("set");
SetAction(cadena) - establece el código de error del <xdb/>.
                    $XDB->SetAction("foo");
SetMatch(cadena) - establece el código de error del <xdb/>.
                   $XDB->SetMatch("foo");
SetErrorCode(cadena) - establece el código de error del <xdb/>.
                       $XDB->SetErrorCode(403);
SetError(cadena) - establece la cadena de error del <xdb/>.
                   $XDB->SetError("Permiso denegado");
NewData(cadena) - crea un nuevo objeto Net::Jabber::Data con el
                   espacio de nombres en la cadena. Para que esta función
                   funcione con un espacio de nombres personalizado, debe
                   definir y registrar ese espacio de nombres con el módulo
                   XDB. Para obtener más información, lea la documentación
                   de Net::Jabber::Data.
                   $dataObj = $XDB->NewData("jabber:xdb:auth");
                   $dataObj = $XDB->NewData("jabber:xdb:roster");
Reply(hash) - crea un nuevo objeto XDB y rellena los campos to/from.
              Si especifica un hash igual que con SetXDB, esos valores
              anularán los valores de Reply.
              $xdbReply = $XDB->Reply();
              $xdbReply = $XDB->Reply(type=>"result");

Funciones de prueba

DefinedTo() - devuelve 1 si el atributo to está definido en el <xdb/>,
              0 en caso contrario.
              $test = $XDB->DefinedTo();
DefinedFrom() - devuelve 1 si el atributo from está definido en el <xdb/>,
                0 en caso contrario.
                $test = $XDB->DefinedFrom();
DefinedID() - devuelve 1 si el atributo id está definido en el <xdb/>,
              0 en caso contrario.
              $test = $XDB->DefinedID();
DefinedType() - devuelve 1 si el atributo type está definido en el <xdb/>,
                0 en caso contrario.
                $test = $XDB->DefinedType();
DefinedAction() - devuelve 1 si el atributo action está definido en el <xdb/>,
                 0 en caso contrario.
                 $test = $XDB->DefinedAction();
DefinedMatch() - devuelve 1 si el atributo match está definido en el <xdb/>,
                 0 en caso contrario.
                 $test = $XDB->DefinedMatch();
DefinedError() - devuelve 1 si <error/> está definido en el <xdb/>,
                 0 en caso contrario.
                 $test = $XDB->DefinedError();
DefinedErrorCode() - devuelve 1 si el atributo code está definido en
                     <error/>, 0 en caso contrario.
                     $test = $XDB->DefinedErrorCode();
