NS_GET_OWNER_UID(2const) NS_GET_OWNER_UID(2const)

NOMBRE

NS_GET_OWNER_UID - descubrir el propietario de un espacio de nombres de usuario

SINOPSIS

#include <linux/nsfs.h>  /* Definición de NS_GET_OWNER_UID */
#include <sys/ioctl.h>
int ioctl(int fd, NS_GET_OWNER_UID, uid_t *uid);

DESCRIPCIÓN

La operación NS_GET_OWNER_UID se puede usar para descubrir el ID de usuario propietario de un espacio de nombres de usuario (es decir, el ID de usuario efectivo del proceso que creó el espacio de nombres de usuario).

fd se refiere a un archivo en /proc/pid/ns/user.

El ID de usuario propietario se devuelve en el uid_t al que apunta el tercer argumento.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
fd no se refiere a un espacio de nombres de usuario.

ESTÁNDARES

Linux.

HISTORIA

Linux 4.11.

VER TAMBIÉN

ioctl(2), ioctl_nsfs(2)
