NOMBRE

Net::DNS::RR::RT - Registro de recurso RT de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre RT preferencia intermedio');

DESCRIPCIÓN

Clase para registros de recurso de DNS Route Through (RT).

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otros comportamientos impredecibles.

preferencia

$preferencia = $rr->preferencia;
$rr->preferencia( $preferencia );

Un entero de 16 bits que representa la preferencia de la ruta. Números más pequeños indican rutas más preferidas.

intermedio

$intermedio = $rr->intermedio;
$rr->intermedio( $intermedio );

El nombre de dominio de un host que servirá como intermedio para alcanzar el host especificado por el nombre del propietario. Se espera que los RR de DNS asociados con el host intermedio incluyan al menos un registro A, X25 o ISDN.
