NOMBRE

Net::LDAP::Extension::Cancel - Operación LDAP de Cancelación

SINOPSIS

use Net::LDAP;
use Net::LDAP::Constant qw(LDAP_SUCCESS LDAP_CANCELED)
use Net::LDAP::Extension::Cancel;
$ldap = Net::LDAP->new( 'ldap.mydomain.eg' );
$ldap->bind('cn=Joe User,cn=People,dc=example,dc=com',
            password => 'secret');
$search = $ldap->search(
                       base     => 'c=US',
                       filter   => '(&(sn=Barr) (o=Texas Instruments))',
                       callback => \&process_entry, # Llamar a esta subrutina por cada entrada
                     );
$mesg = $ldap->cancel($search);
die "error :", $mesg->code(), ": ", $mesg->error()
  if ($mesg->code() != LDAP_CANCELED && mesg->code() != LDAP_SUCCESS);

DESCRIPCIÓN

"Net::LDAP::Extension::Cancel" implementa la operación extendida LDAPv3 "Cancel" descrita en el RFC 3909.

La operación extendida "Cancel" es muy similar a la operación estándar "Abandonar", y tiene la misma firma de llamada. A diferencia de la operación "Abandonar", tiene una respuesta que proporciona una indicación de su resultado.

No implementa ningún objeto por sí misma, sino que extiende el objeto Net::LDAP con otro método:

MÉTODOS

cancelar ( OPERACIÓN, OPCIONES )
Cancela una operación pendiente. "OPERACIÓN" puede ser un número o un objeto que sea una subclase de Net::LDAP::Message, devuelto por una llamada a método anterior.

OPCIONES es una lista de pares clave/valor. Las siguientes claves son reconocidas:

control => CONTROL
control => [ CONTROL, .. ]
Control(es) que se pasarán a la operación.
