NOMBRE

Net::XMPP::Connection - Módulo de Conexión XMPP

SINOPSIS

Net::XMPP::Connection es un paquete privado que sirve como base para cualquier cosa que quiera abrir una conexión de socket a un servidor.

DESCRIPCIÓN

Este módulo no está diseñado para ser utilizado directamente. Deberías estar utilizando Net::XMPP::Client, u otro paquete que herede de Net::XMPP::Connection.
