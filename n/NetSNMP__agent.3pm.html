Paquete: net-snmp

Licencias: BSD

agent(3) Documentación de Perl contribuida por el usuario agent(3)

NOMBRE

NetSNMP::agent - Extensión de Perl para el agente net-snmp.

SINOPSIS

use NetSNMP::agent;
my $agent = new NetSNMP::agent('Name' => 'mi_nombre_agente');

DESCRIPCIÓN

Este módulo implementa un conjunto de API para hacer que un agente SNMP actúe como un agente snmp, un subagente snmp (usando el protocolo de subagente AgentX) y/o APIs embebidas de perl directamente dentro del demonio tradicional del agente net-snmp.

Consulte también el tutorial sobre la API general de C de Net-SNMP, que este módulo implementa a la manera de Perl, y un tutorial específico de Perl en:

http://www.net-snmp.org/tutorial-5/toolkit/

EJEMPLOS

Ejemplo de subagente

use NetSNMP::agent (':all');
use NetSNMP::ASN qw(ASN_OCTET_STR);
my $value = "hola mundo";
sub myhandler {
    my ($handler, $registration_info, $request_info, $requests) = @_;
    my $request;
    for($request = $requests; $request; $request = $request->next()) {
        my $oid = $request->getOID();
        if ($request_info->getMode() == MODE_GET) {
            # ... generalmente, calcularías el valor a partir del oid
            if ($oid == new NetSNMP::OID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0")) {
                $request->setValue(ASN_OCTET_STR, $value);
            }
        } elsif ($request_info->getMode() == MODE_GETNEXT) {
            # ... generalmente, calcularías el valor a partir del oid
            if ($oid < new NetSNMP::OID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0")) {
                $request->setOID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0");
                $request->setValue(ASN_OCTET_STR, $value);
            }
        } elsif ($request_info->getMode() == MODE_SET_RESERVE1) {
            if ($oid != new NetSNMP::OID(".1.3.6.1.4.1.8072.9999.9999.7375.1.0")) {  # haz la comprobación de errores aquí
                $request->setError($request_info, SNMP_ERR_NOSUCHNAME);
            }
        } elsif ($request_info->getMode() == MODE_SET_ACTION) {
            # ... (o usa el valor)
            $value = $request->getValue();
        }
    }
}
my $agent = new NetSNMP::agent(
                        # hace que el agente lea un archivo de configuración my_agent_name.conf
                        'Name' => "mi_nombre_agente",
                        'AgentX' => 1
                        );
$agent->register("mi_nombre_agente", ".1.3.6.1.4.1.8072.9999.9999.7375",
                 \&myhandler);
my $running = 1;
while($running) {
        $agent->agent_check_and_process(1);
}
$agent->shutdown();

CONSTRUCTOR

new ( OPCIONES )
    Este es el constructor para un nuevo objeto NetSNMP::agent.
Opciones posibles son:
    Name    - Nombre del agente (opcional, por defecto es "perl")
              (La librería snmp leerá un archivo de configuración snmp
              NAME.conf basado en este argumento.)
    AgentX  - Haznos un subagente (0 = falso, 1 = verdadero)
              (El agente maestro Net-SNMP debe estar ejecutándose primero)
    Ports   - Puertos en los que este agente escuchará (EJ: "udp:161,tcp:161")
Ejemplo:
    $agent = new NetSNMP::agent(
                             'Name' => 'mi_nombre_agente',
                             'AgentX' => 1
                             );

MÉTODOS

register (NOMBRE, OID, \&rutina_manejadora )
    Registra el manejador de callback con el OID dado.
    $agent->register();
    Un código de retorno de 0 indica que no hay error.
agent_check_and_process ( BLOQUEANTE )
    Ejecuta una iteración del bucle principal.
    BLOQUEANTE - Llamada bloqueante o no bloqueante. 1 = verdadero, 0 = falso.
    $agent->agent_check_and_process(1);
main_loop ()
    Ejecuta el agente en un bucle. No retorna.
shutdown ()
    Cierra el agente o subagente de forma limpia.
    $agent->shutdown();

CALLBACKS DE MANEJADOR

handler ( MANEJADOR, INFORMACION_REGISTRO, INFORMACION_SOLICITUD, SOLICITUDES )
    El manejador es llamado con los siguientes parámetros:
    MANEJADOR                 - FIXME
    INFORMACION_REGISTRO       - ¿cuáles son los significados correctos de estos?
    INFORMACION_SOLICITUD      -
    SOLICITUDES                -
Ejemplo de manejador:
    sub myhandler {
        my ($handler, $reg_info, $request_info, $requests) = @_;
        # ...
    }

La subrutina manejadora será llamada cuando una solicitud SNMP recibida por el agente para cualquier cosa por debajo del OID registrado. El manejador recibe 4 argumentos: $handler, $registration_info, $request_info, $requests. Estos coinciden con los argumentos pasados a la versión C de la misma API. Tenga en cuenta que no son objetos completamente completos sino que son funcionales "suficientemente" en este momento.

funciones del objeto $request_info

getMode ()
    Devuelve el modo de la solicitud. Vea la sección MODOS para
    la lista de modos válidos.
    $mode = $request->getMode();

funciones del objeto $registration_info

getRootOID ()
    Devuelve un objeto NetSNMP::OID que describe el punto de registro
    para el cual se llama al manejador (en caso de que
    registres una función manejadora con múltiples OIDs, lo cual
    sería raro de todos modos)
    $root_oid = $request->getRootOID();

funciones del objeto $request

next ()
    Devuelve la siguiente solicitud en la lista o undef si no hay
    siguiente solicitud.
    $request = $request->next();
getOID ()
    Devuelve el oid de la solicitud (una clase NetSNMP::OID).
    $oid = $request->getOID();
setOID (new NetSNMP::OID("unoid"))
    Establece el OID de la solicitud a un valor oid pasado. Esto
    generalmente solo debe hacerse durante el manejo de solicitudes
    GETNEXT.
    $request->setOID(new NetSNMP::OID("unoid"));
getValue ()
    Devuelve el valor de la solicitud. Se usa, por ejemplo, al
    establecer valores.
    $value = $request->getValue();
    FIXME: ¿cómo obtener el tipo del valor? ¿Está siquiera disponible?
           [Wes: no, todavía no.]
setValue ( TIPO, DATOS )
    Establece los datos que se devolverán al demonio.
    Devuelve 1 si tiene éxito, 0 si hay error.
    TIPO - Tipo de los datos. Consulte NetSNMP::ASN para tipos válidos.
    DATOS - Los datos a devolver.
    $ret = $request->setValue(ASN_OCTET_STR, "prueba");
setError ( INFORMACION_SOLICITUD, CODIGO_ERROR )
    Establece el código de error dado para la solicitud. Consulte la sección
    CÓDIGOS DE ERROR para la lista de códigos válidos.
    $request->setError($request_info, SNMP_ERR_NOTWRITABLE);
getProcessed ()
    El indicador procesado indica que una solicitud no necesita
    ser manejada porque alguien más (un manejador superior) ya la ha
    manejado.
    $processed = $request->getProcessed();
setProcessed ( PROCESADO )
    Establece el indicador procesado en la solicitud. Generalmente,
    no deberías tener que establecerlo tú mismo.
    PROCESADO - 0 = falso, 1 = verdadero
    $request->setProcessed(1);
getDelegated ()
    Si puedes manejar una solicitud en segundo plano o en un momento posterior
    (POR EJEMPLO, estás esperando un descriptor de archivo, o tráfico de red, o ...),
    el indicador delegado se puede establecer en la solicitud. Cuando
    la solicitud se procese en el futuro, el indicador debe restablecerse
    a 0 para que el agente sepa que puede finalizar la solicitud original
    y enviarla de vuelta al gestor. Esto no ha sido probado dentro de perl,
    pero esperemos que funcione.
    $delegated = $request->getDelegated();
setDelegated ( DELEGADO )
    Establece el indicador delegado.
    DELEGADO - 0 = falso, 1 = verdadero
    $request->setDelegated(1);
getRepeat ()
    El indicador de repetición indica que se está manejando una operación
    getbulk y esto indica cuántas respuestas deben devolverse.
    Generalmente, si no te registraste para manejar directamente el soporte
    getbulk por ti mismo, no necesitarás
d para tratar con este valor. $repeat = $request->getRepeat(); setRepeat ( REPEAT ) Establece el recuento de repetición (disminuye después de responder a las solicitudes si gestionas las solicitudes getbulk tú mismo) REPEAT - recuento de repetición ARREGLARME $request->setRepeat(5); getSourceIp () Obtiene la dirección IPv4 del dispositivo que realiza la solicitud al manejador. use Socket; print "Fuente: ", inet_ntoa($request->getSourceIp()), "\n"; getDestIp () Obtiene la dirección IPv4 del destino al que se envió la solicitud. use Socket; print "Destino: ", inet_ntoa($request->getDestIp()), "\n";
