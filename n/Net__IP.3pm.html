Net::IP - Extensión Perl para manipular direcciones IPv4/IPv6

SINTAXIS

use Net::IP;

my $ip = new Net::IP ('193.0.1/24') or die (Net::IP::Error());
print ("IP  : ".$ip->ip()."\n");
print ("Sho : ".$ip->short()."\n");
print ("Bin : ".$ip->binip()."\n");
print ("Int : ".$ip->intip()."\n");
print ("Mask: ".$ip->mask()."\n");
print ("Last: ".$ip->last_ip()."\n");
print ("Len : ".$ip->prefixlen()."\n");
print ("Size: ".$ip->size()."\n");
print ("Type: ".$ip->iptype()."\n");
print ("Rev:  ".$ip->reverse_ip()."\n");

DESCRIPCIÓN

Este módulo proporciona funciones para trabajar con direcciones IPv4/IPv6. El módulo puede ser utilizado como una clase, permitiendo al usuario crear objetos de IP, que pueden ser direcciones IP individuales, prefijos o rangos de direcciones. También existe una forma procedural para acceder a la mayoría de las funciones. La mayoría de las subrutinas pueden tomar direcciones IPv4 y IPv6 de forma transparente.

INTERFAZ ORIENTADA A OBJETOS

Creación de objeto

Un objeto Net::IP puede ser creado a partir de una dirección IP única:

$ip = new Net::IP ('193.0.1.46') || die ...

O a partir de un prefijo sin clases (un prefijo /24 es equivalente a una clase C):

$ip = new Net::IP ('195.114.80/24') || die ...

O a partir de un rango de direcciones:

$ip = new Net::IP ('20.34.101.207 - 201.3.9.99') || die ...

O a partir de una dirección IP más un número:

$ip = new Net::IP ('20.34.10.0 + 255') || die ...

El método new() acepta direcciones IPv4 y IPv6:

$ip = new Net::IP ('dead:beef::/32') || die ...

Opcionalmente, al método se le puede pasar la versión de la dirección. De lo contrario, intentará adivinar la versión (ver _is_ipv4() y _is_ipv6()).

$ip = new Net::IP ('195/8',4); # Clase A

MÉTODOS DE OBJETO

La mayoría de estos métodos son interfaces front-end para las funciones reales, que usan una interfaz procedural. La mayoría de las funciones devuelven undef en caso de error, y un valor verdadero en caso de éxito. A continuación se detalla una descripción de la interfaz procedural.

set

Establece una dirección IP en un objeto IP existente. Esta función tiene la misma funcionalidad que el método new(), pero reutiliza un objeto existente para almacenar la nueva dirección IP.

"$ip->set('130.23.1/24',4);"

Al igual que el método new(), el método set() acepta dos argumentos: una cadena utilizada para construir una dirección IP, prefijo o rango, y opcionalmente la versión de la dirección considerada.

Devuelve un objeto IP en caso de éxito, y undef en caso de error.

error

Devuelve la cadena de error del objeto actual. Esta cadena se establece cuando uno de los métodos produce un error. También hay disponible una función global Error() a nivel de clase.

"warn ($ip->error());"

errno

Devuelve el número de error del objeto actual. El número de error se establece cuando uno de los métodos produce un error. También se establece una variable global $ERRNO cuando se produce un error.

"warn ($ip->errno());"

ip

Devuelve la dirección IP (o la primera dirección de un prefijo o rango) en formato cuádruple como una cadena.

"print ($ip->ip());"

binip

Devuelve la dirección IP como una cadena binaria de 0s y 1s.

"print ($ip->binip());"

prefixlen

Devuelve la longitud en bits del prefijo actual.

"print ($ip->prefixlen());"

version

Devuelve la versión del objeto IP actual (4 o 6).

"print ($ip->version());"

size

Devuelve el número de direcciones IP en el prefijo o rango actual. El uso de esta función requiere Math::BigInt.

"print ($ip->size());"

binmask

Devuelve la máscara binaria del prefijo actual, si aplica.

"print ($ip->binmask());"

mask

Devuelve la máscara en formato cuádruple del prefijo actual.

"print ($ip->mask());"

prefix

Devuelve la prefijación completa (ip+longitud de prefijo) en formato cuádruple (normalizado).

"print ($ip->prefix());"

print

Imprime el objeto IP (IP/prefijo o primero - último)

"print ($ip->print());"

intip

Convierte la dirección IP en formato entero y la devuelve como un objeto Math::BigInt.

"print ($ip->intip());"

hexip

Devuelve la dirección IP en formato hexadecimal.

"print ($ip->hexip());"

hexmask

Devuelve la máscara en formato hexadecimal.

"print ($ip->hexmask());"

short

Devuelve la dirección IP en formato corto: IPv4: 194.5/16; IPv6: ab32:f000::

"print ($ip->short());"

iptype

Devuelve el tipo de IP - esto describe el tipo de una IP (Pública, Privada, Reservada, etc.). Ver la interfaz procedural ip_iptype para más detalles.

"print ($ip->iptype());"

reverse_ip

Devuelve la dirección inversa de una dirección dada (en formato in.addr).

"print ($ip->reverse_ip());"

last_ip

Devuelve la última dirección IP de un prefijo/rango en formato cuádruple.

"print ($ip->last_ip());"

last_bin

Devuelve la última dirección IP de un prefijo/rango en formato binario.

"print ($ip->last_bin());"

last_int

Devuelve la última dirección IP de un prefijo/rango en formato entero.

"print ($ip->last_int());"

find_prefixes

Esta función encuentra todos los prefijos que pueden existir entre las dos direcciones de un rango. La función devuelve una lista de prefijos.

"@list = $ip->find_prefixes($other_ip));"

contains

Comprueba si un objeto IP contiene una dirección IP o un rango de direcciones.

"if ($ip->contains($other_ip)) { ... }"

is_private

Comprueba si una dirección IP es privada según RFC1918.

"if ($ip->is_private()) { ... }"

is_loopback

Comprueba si una dirección IP es de loopback.

"if ($ip->is_loopback()) { ... }"

is_linklocal

Comprueba si una dirección IP es de enlace local (link local).

"if ($ip->is_linklocal()) { ... }"

is_multicast

Comprueba si una dirección IP es multicast.

"if ($ip->is_multicast()) { ... }"

is_reserved

Comprueba si una dirección IP está reservada.

"if ($ip->is_reserved()) { ... }"

is_ipv4

Comprueba si la dirección IP es IPv4.

"if ($ip->is_ipv4()) { ... }"

is_ipv6

Comprueba si la dirección IP es IPv6.

"if ($ip->is_ipv6()) { ... }"

iterate_prefix

Permite iterar a través de un prefijo o rango de direcciones IP.

my $ip_obj = new Net::IP('192.168.0.0/24');
my @list = $ip_obj->iterate_prefix();
foreach my $ip (@list) {
    print $ip->ip()."\n";
}

random_ip

Devuelve una dirección IP aleatoria dentro de un prefijo/rango.

"my $random = $ip->random_ip();"

next_ip

Devuelve la siguiente dirección IP en la secuencia.

"my $next = $ip->next_ip();"

prev_ip

Devuelve la dirección IP anterior en la secuencia.

"my $prev = $ip->prev_ip();"

INTERFAZ PROCEDURAL

La mayoría de las funciones anteriores también están disponibles como funciones globales. Las funciones globales devuelven undef en caso de error y establecen una variable global $ERRNO o usan la función global Net::IP::Error().

# Retorna el objeto Net::IP
$ip = ip_create('192.168.0.1/24');

# Retorna la dirección IP
$str = ip_ip('192.168.0.1');

# Retorna la longitud del prefijo
$len = ip_prefixlen('192.168.0.0/24');

# Comprueba si es privada
if (ip_is_private('192.168.1.1')) { ... }

La siguiente es una lista de las funciones disponibles:

  • ip_create() - Crea un objeto IP.
  • ip_ip() - Devuelve la dirección IP en formato cuádruple.
  • ip_binip() - Devuelve la dirección IP en formato binario.
  • ip_intip() - Devuelve la dirección IP como un entero BigInt.
  • ip_prefixlen() - Devuelve la longitud del prefijo.
  • ip_mask() - Devuelve la máscara en formato cuádruple.
  • ip_binmask() - Devuelve la máscara en formato binario.
  • ip_short() - Devuelve la dirección IP en formato corto.
  • ip_iptype() - Devuelve el tipo de IP (pública, privada, etc.).
  • ip_size() - Devuelve el número de IPs en un prefijo.
  • ip_addr() - Devuelve la dirección en formato IP.
  • ip_reverse() - Devuelve la dirección inversa.
  • ip_last_ip() - Devuelve la última IP de un prefijo.
  • ip_last_bin() - Devuelve la última IP de un prefijo en formato binario.
  • ip_last_int() - Devuelve la última IP de un prefijo como entero.
  • ip_is_private() - Comprueba si una IP es privada.
  • ip_is_loopback() - Comprueba si una IP es de loopback.
  • ip_is_linklocal() - Comprueba si una IP es de enlace local.
  • ip_is_multicast() - Comprueba si una IP es multicast.
  • ip_is_reserved() - Comprueba si una IP está reservada.
  • ip_is_ipv4() - Comprueba si una IP es IPv4.
  • ip_is_ipv6() - Comprueba si una IP es IPv6.
  • ip_find_prefixes() - Encuentra prefijos dentro de un rango.
  • ip_netmask() - Calcula la máscara de red a partir de una dirección IP y su longitud de prefijo.
  • ip_nth_ip() - Obtiene la n-ésima dirección IP en un rango.
  • ip_random_ip() - Obtiene una dirección IP aleatoria dentro de un rango.
  • ip_next_ip() - Obtiene la siguiente dirección IP.
  • ip_prev_ip() - Obtiene la dirección IP anterior.

EJEMPLO

use Net::IP;

# Crear un objeto IP para una red
my $net = new Net::IP('192.168.0.0/24');
die Net::IP::Error() unless $net;

# Imprimir la dirección IP, máscara y longitud del prefijo
print "Network: ", $net->ip(), "\n";
print "Mask: ", $net->mask(), "\n";
print "Prefix Length: ", $net->prefixlen(), "\n";

# Iterar a través de todas las direcciones IP en la red
my @ips = $net->iterate_prefix();
foreach my $ip (@ips) {
    print $ip->ip(), "\n";
}

# Crear un objeto IP para una dirección específica
my $host = new Net::IP('192.168.0.50');
die Net::IP::Error() unless $host;

# Comprobar si la dirección IP pertenece a la red
if ($net->contains($host)) {
    print "192.168.0.50 is within the 192.168.0.0/24 network.\n";
}

# Comprobar si es una dirección privada
if ($host->is_private()) {
    print "192.168.0.50 is a private IP address.\n";
}

INTERFAZ PROCEDURAL

Estas funciones realizan el trabajo real en el módulo. Al igual que los métodos OO, la mayoría de ellas devuelven undef en caso de fallo. Para acceder a los códigos y cadenas de error, en lugar de usar $ip->error() y $ip->errno(), utiliza las funciones globales Error() y Errno().

Las funciones de la interfaz procedural no se exportan por defecto. Para importarlas, debes modificar la declaración use del módulo:

"use Net::IP qw(:PROC);"

Error

Devuelve la cadena de error correspondiente al último error generado en el módulo. También es útil para la interfaz OO, ya que si el método new() falla, no podemos llamar a $ip->error() y debemos usar Error().

warn Error();

Errno

Devuelve un código de error numérico correspondiente a la cadena de error devuelta por Error().

ip_iptobin

Transforma una dirección IP en una cadena binaria.

Parámetros: dirección IP, versión IP

"$binip = ip_iptobin ($ip,6);"

ip_bintoip

Transforma una cadena binaria en una dirección IP.

Parámetros: cadena binaria, versión IP

"$ip = ip_bintoip ($binip,6);"

ip_bintoint

Transforma una cadena binaria en un BigInt.

Parámetros: cadena binaria

"$bigint = new Math::BigInt (ip_bintoint ($binip));"

ip_inttobin

Transforma un BigInt en una cadena binaria. Nota: desactiva las advertencias ("-w"). Esto es necesario porque Math::BigInt no es compatible.

Parámetros: BigInt, versión IP

"$binip = ip_inttobin ($bigint);"

ip_get_version

Intenta adivinar la versión IP de una dirección IP.

Parámetros: dirección IP

"$version = ip_get_version ($ip)"

ip_is_ipv4

Verifica si una dirección IP es de tipo 4.

Parámetros: dirección IP

"ip_is_ipv4 ($ip) and print "$ip es IPv4";"

ip_is_ipv6

Verifica si una dirección IP es de tipo 6.

Parámetros: dirección IP

"ip_is_ipv6 ($ip) and print "$ip es IPv6";"

ip_expand_address

Expande una dirección IP en notación compacta.

Parámetros: dirección IP, versión IP

"$ip = ip_expand_address ($ip,4);"

ip_get_mask

Obtiene la máscara IP a partir de la longitud del prefijo.

Parámetros: longitud del prefijo, versión IP

"$mask = ip_get_mask ($len,6);"

ip_last_address_bin

Devuelve la última dirección binaria de un prefijo.

Parámetros: dirección binaria, longitud del prefijo, versión IP

"$lastbin = ip_last_address_bin ($ip,$len,6);"

ip_splitprefix

Separa un prefijo en dirección IP y longitud de prefijo. Si se le pasa una IP simple, devuelve solo la dirección.

Parámetros: prefijo

"($ip,$len) = ip_splitprefix ($prefix)"

ip_prefix_to_range

Obtiene un rango de direcciones IP a partir de un prefijo.

Parámetros: prefijo, versión IP

"($ip1,$ip2) = ip_prefix_to_range ($prefix,6);"

ip_bincomp

Comparación binaria de dos direcciones IP. El operador toma un operando y una dirección IP como argumentos. Devuelve un valor booleano.

"ip_bincomp ($ip1,'lt',$ip2) == 1 or do {}"

ip_binadd

Suma dos direcciones binarias.

Parámetros: dirección binaria, dirección binaria

"$binip = ip_binadd ($bin1,$bin2);"

ip_get_prefix_length

Obtiene la longitud del prefijo para un rango de 2 direcciones IP.

Parámetros: dirección binaria, dirección binaria

"$len = ip_get_prefix_length ($ip1,$ip2);"

ip_range_to_prefix

Devuelve todos los prefijos entre dos direcciones IP.

Parámetros: dirección IP (formato binario), dirección IP (formato binario), versión IP

Los prefijos devueltos tienen el formato q.q.q.q/nn.

"@prefix = ip_range_to_prefix ($ip1,$ip2,6);"

ip_compress_v4_prefix

Comprime un prefijo IPv4.

Parámetros: dirección IP, longitud del prefijo

"$ip = ip_compress_v4_prefix ($ip, $len);"

ip_compress_address

Comprime una dirección IPv6. Solo devuelve la dirección si es IPv4.

Parámetros: dirección IP, versión IP

"$ip = ip_compress_adress ($ip, $version);"

ip_is_overlap

Verifica si dos rangos de direcciones IP se superponen.

Parámetros: cuatro direcciones binarias (inicio rango1, fin rango1, inicio rango2, fin rango2), versión IP

"(ip_is_overlap($rb1,$re1,$rb2,$re2,4) eq $IP_A_IN_B_OVERLAP) and do {};"

ip_get_embedded_ipv4

Obtiene una IPv4 incrustada en una dirección IP.

ip_check_mask

Verifica la validez de una máscara binaria

Params  : Mask
Returns : 1 o undef (inválido)

"ip_check_mask($binmask) or do {};"

Verifica si la máscara tiene solo 1s seguidos por 0s.

ip_aggregate

Une dos rangos de IPs binarias

Params  : 1er rango (1ra IP, última IP), último rango (1ra IP, última IP), versión de IP
Returns : prefijo o undef (inválido)

"$prefix = ip_aggregate ($bip1,$eip1,$bip2,$eip2) || die ..."

ip_iptypev4

Devuelve el tipo de una dirección IPv4

Params:  IP binaria
Returns: tipo según la tabla siguiente o undef (inválido)

Verificar RFC 5735 y RFC 6598

Bloque                                               Referencia ------------------------------------------------------------------- 0.0.0.0/8                                                Este red Redes privadas                    RFC 1122 PRIVADO 10.0.0.0/8 �

defaults to 6) Returns : type (see ip_iptypev4 and ip_iptypev6 for details) or undef (invalid)

"$type = ip_iptype ($ip);"

ip_check_prefix

Comprueba la validez de un prefijo

Params  : IP binaria, longitud del prefijo, versión IP
Returns : 1 o undef (inválido)

Comprueba si la parte variante de un prefijo solo tiene 0s, y si la longitud es correcta.

"ip_check_prefix ($ip,$len,$ipv) or do {};"

ip_reverse

Obtiene un nombre inverso a partir de un prefijo

Params  : IP, longitud del prefijo, versión IP
Returns : Nombre inverso o undef (error)

"$reverse = ip_reverse ($ip);"

ip_normalize

Normaliza datos a un rango/prefijo de direcciones IP

Params  : Cadena de datos (IP única, Rango, Prefijo)
Returns : ip1, ip2 (si es rango/prefijo) o undef (error)

"($ip1,$ip2) = ip_normalize ($data);"

ip_auth

Devuelve información de autoridad IP del módulo IP::Authority

Params  : IP, versión
Returns : Info de autoridad (RI para RIPE, AR para ARIN, etc)

"$auth = ip_auth ($ip,4);"

Nota: Solo IPv4

BUGS

Se necesita la biblioteca Math::BigInt para las funciones que usan enteros. Estas son ip_inttobin, ip_bintoint, y el método size. En una próxima versión, Math::BigInt será opcional.
