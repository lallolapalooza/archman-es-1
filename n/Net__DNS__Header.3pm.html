NOMBRE

Net::DNS::Header — Cabecera de un paquete DNS

SINOPSIS

use Net::DNS;
$packet = Net::DNS::Packet->new();
$header = $packet->header;

DESCRIPCIÓN

«Net::DNS::Header» representa la parte de la cabecera de un paquete DNS.

MÉTODOS

$packet->header

$packet = Net::DNS::Packet->new();
$header = $packet->header;

Los objetos Net::DNS::Header emergen del método header() de Net::DNS::Packet, y contienen un puntero opaco al objeto Packet padre.

Los objetos de cabecera pueden ser asignados a variables locales adecuadas. Nunca deben ser almacenados en variables globales o estructuras de datos persistentes.

string

print $packet->header->string;

Devuelve una representación en cadena de la cabecera del paquete.

print

$packet->header->print;

Imprime la representación en cadena de la cabecera del paquete.

id

print "query id = ", $packet->header->id, "\n";
$packet->header->id(1234);

Obtiene o establece el número de identificación de la consulta.

opcode

print "query opcode = ", $packet->header->opcode, "\n";
$packet->header->opcode("UPDATE");

Obtiene o establece el opcode de la consulta (el propósito de la consulta).

rcode

print "query response code = ", $packet->header->rcode, "\n";
$packet->header->rcode("SERVFAIL");

Obtiene o establece el código de respuesta de la consulta (el estado de la consulta).

qr

print "query response flag = ", $packet->header->qr, "\n";
$packet->header->qr(0);

Obtiene o establece el flag de respuesta de la consulta.

aa

print "response is ", $packet->header->aa ? "authoritative" : "non-authoritative", "\n";
$packet->header->aa(0);

Obtiene o establece el flag de respuesta autoritativa.

tc

print "packet is ", $packet->header->tc ? "truncated" : "not truncated", "\n";
$packet->header->tc(0);

Obtiene o establece el flag de paquete truncado.

rd

print "recursion was ", $packet->header->rd ? "desired" : "not desired", "\n";
$packet->header->rd(0);

Obtiene o establece el flag de recursión deseada.

ra

print "recursion is ", $packet->header->ra ? "available" : "not available", "\n";
$packet->header->ra(0);

Obtiene o establece el flag de recursión disponible.

z

Bits no asignados, debe ser siempre 0.

ad

print "The response has ", $packet->header->ad ? "been verified" : "not been verified", "\n";
$packet->header->ad(0);

Relevante en el contexto de DNSSEC.

(El bit AD solo se establece en una respuesta donde los firmantes han sido verificados o el servidor es autoritativo para el dato y está autorizado a establecer el bit por política.)

cd

print "checking was ", $packet->header->cd ? "not desired" : "desired", "\n";
$packet->header->cd(0);

Obtiene o establece el flag de checking disabled.

qdcount, zocount

print "## of query records: ", $packet->header->qdcount, "\n";

Devuelve el número de registros en la sección de consulta del paquete. En paquetes de actualización dinámica, este campo se conoce como zocount y se refiere al número de RR en la sección de zona.

ancount, prcount

print "## of answer records: ", $packet->header->ancount, "\n";

Devuelve el número de registros en la sección de respuesta del paquete, que puede diferir del número real en paquetes corruptos. En paquetes de actualización dinámica, este campo se conoce como prcount y se refiere al número de RR en la sección de requisición.

nscount, upcount

print "## of authority records: ", $packet->header->nscount, "\n";

Devuelve el número de registros en la sección de autoridad del paquete, que puede diferir del número real en paquetes corruptos. En paquetes de actualización dinámica, este campo se conoce como upcount y se refiere al número de RR en la sección de actualización.

arcount, adcount

print "## of additional records: ", $packet->header->arcount, "\n";

Devuelve el número de registros en la sección de registros adicionales del paquete, que puede diferir del número real en paquetes corruptos. En paquetes de actualización dinámica, este campo se conoce como adcount.

EXTENSIÓN DEL PROTOCOLO EDNS

do, co

print "DNSSEC_OK flag was ", $packet->header->do ? "not set" : "set", "\n";
$packet->header->do(1);

Obtiene o establece el flag EDNS.

Códigos de respuesta de rcode EDNS

Los códigos de respuesta de rcode EDNS se manejan de forma transparente por $packet->header->rcode().

Tamaño del paquete UDP

$udp_max = $packet->edns->UDPsize;

EDNS ofrece un mecanismo para anunciar el tamaño máximo del paquete UDP que puede ser construido por la pila de red local.

edns

$header  = $packet->header;
$version = $header->edns->version;
@options = $header->edns->options;
$option  = $header->edns->option(n);
$udp_max = $packet->edns->UDPsize;

Función auxiliar que proporciona acceso a la extensión EDNS protocol OPT RR.
