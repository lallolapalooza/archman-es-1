Net::DNS::RR::NSEC(3) Documentación de Perl aportada por el usuario Net::DNS::RR::NSEC(3)

NOMBRE

Net::DNS::RR::NSEC - Registro de recurso NSEC de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new( 'nombre NSEC nxtdname tipolista' );

DESCRIPCIÓN

Clase para registros de recurso NSEC de DNSSEC.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

Se desaconseja el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas y podría resultar en la terminación del programa u otros comportamientos impredecibles.

nxtdname

$nxtdname = $rr->nxtdname;
$rr->nxtdname( $nxtdname );

El campo del Siguiente Nombre de Dominio contiene el siguiente nombre de propietario (en el orden canónico de la zona) que tiene datos autoritativos o contiene un conjunto de registros NS de punto de delegación.

tipolista

@tipolista = $rr->tipolista;
$tipolista = $rr->tipolista;

tipolista() identifica los tipos de conjuntos de registros que existen en el nombre del propietario del registro NSEC. Cuando se llama en contexto de escalar, la lista se interpola en una cadena.

mapatipo

$existe = $rr->mapatipo($rrtype);

mapatipo() devuelve un valor booleano verdadero si el tipo de registro especificado ocurre en el mapa de bits de tipos del registro NSEC.

coincide

$coincide = $rr->coincide( 'ejemplo.foo' );

coincide() devuelve un valor booleano verdadero si la forma canónica del argumento de nombre coincide con el nombre de propietario canónico del registro NSEC.

cubre

$cubierto = $rr->cubre( 'ejemplo.foo' );

cubre() devuelve un valor booleano verdadero si la forma canónica del nombre, o uno de sus ancestros, cae entre el nombre del propietario y el campo nxtdname del registro NSEC.

envolvente, siguientecercano, comodín

$envolvente = $rr->envolvente( 'ejemplo.foo' );
print "envolvente: $envolvente\n" if $envolvente;

envolvente() devuelve el nombre de un envolvente demostrable del argumento del nombre de consulta obtenido del registro NSEC.

siguientecercano() devuelve el siguiente nombre más cercano, que es una etiqueta más largo que el envolvente más cercano. Esto solo es válido después de que envolvente() haya devuelto un nombre de dominio válido.

comodín() devuelve el nombre comodín no expandido del cual se pudo haber sintetizado el nombre siguiente más cercano. Esto solo es válido después de que envolvente() haya devuelto un nombre de dominio válido.
