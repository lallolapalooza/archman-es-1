NOMBRE

Net::DNS::SEC::Tools::QWPrimitives - Primitivas de QWizard para DNSSEC-Tools

SINOPSIS

use Net::DNS::SEC::Tools::QWPrimitives;
use Getopt::Long::GUI;
our @guiargs;
DTGetOptions(  ...,
               ['GUI:nootherargs',1],
               ['GUI:otherprimaries',dnssec_tools_get_qwprimitives()],
               ['GUI:submodules','getzonefiles','getzonenames'],
            );

DESCRIPCIÓN

QWizard es un kit de construcción de GUI dinámicas. Muestra una serie de preguntas, luego recupera y actúa sobre las respuestas. Este módulo proporciona acceso a QWizard para el software DNSSEC-Tools.

En particular, dnssec_tools_get_qwprimitives() devuelve un conjunto de pantallas primarias para solicitar un conjunto de archivos de zona seguidos por un conjunto de nombres de dominio para esos archivos de zona. Estos se insertan luego en @guiargs que deben tratarse como el array ARGV final a procesar.
