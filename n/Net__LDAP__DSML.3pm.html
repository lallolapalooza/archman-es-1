Net::LDAP::DSML(3) Documentación contribuida por los usuarios de Perl Net::LDAP::DSML(3)

NOMBRE

Net::LDAP::DSML — Un escritor de DSML para Net::LDAP

SINAPSIS

Para un registro de directorio;
                            use Net::LDAP;
                            use Net::LDAP::DSML;
                            use IO::File;
                            my $server = "localhost";
                            my $file = "testdsml.xml";
                            my $ldap = Net::LDAP->new($server);
                            $ldap->bind();
                            #
                            # Para i/o de archivo
                            #
                            my $file = "testdsml.xml";
                            my $io = IO::File->new($file, "w")
                                or die ("falló abrir $file como manejador de archivo.$!$n");
                            my $dsml = Net::LDAP::DSML->new(output => $io, pretty_print => 1)
                                or die ("error al crear objeto DSML usando un archivo de salida.$n");
                            #      O
                            #
                            # Para i/o de archivo
                            #
                            open (IO, ">$file") or die ("falló abrir $file.$!$n");
                            my $dsml = Net::LDAP::DSML->new(output => $IO, pretty_print => 1)
                                or die ("error al crear objeto DSML usando un archivo de salida.$n");
                            #      O
                            #
                            # Para uso de arrays.
                            # Pasar una referencia a un array.
                            #
                            my @data = ();
                            $dsml = Net::LDAP::DSML->new(output => \@data, pretty_print => 1)
                                or die ("error al crear objeto DSML usando un array de salida.$n");
                            my $mesg = $ldap->search(
                                base => 'o=airius.com',
                                scope => 'sub',
                                filter => 'ou=accounting',
                                callback => sub {
                                    my ($mesg,$entry) = @_;
                                    $dsml->write_entry($entry)
                                         if (ref $entry eq 'Net::LDAP::Entry');
                                }
                            );
                            die ("error al ejecutar search con $mesg.$n") if $mesg->code();
                            Para esquema de directorio;
                            Un archivo o array puede ser usado para salida, en el siguiente ejemplo solo un array será usado.
                            my $schema = $ldap->schema();
                            my @data = ();
                            my $dsml = Net::LDAP::DSML->new(output => \@data, pretty_print => 1)
                                 or die ("error al crear objeto DSML usando un array de salida.$n");
                            $dsml->write_schema($schema);
                            print ("Finalizado impresión DSML.$n");

DESCRIPCIÓN

El Lenguaje de Marco de Servicios de Directorio (DSML) es el estándar XML para representar información de servicios de directorio en XML.

A la fecha, este módulo solo escribe entidades DSML de registro y esquema. La lectura de entidades DSML es un proyecto futuro.

Finalmente, este módulo será un consumidor y productor de nivel 2 completo, permitiendo al usuario tener conformidad total con DSML. Actualmente, este módulo tiene la capacidad de ser un productor de nivel 2. El usuario debe entender que su servidor de directorio determinará el nivel de consumidor y productor que puede lograr.

Para determinar la conformidad, es útil dividir los documentos DSML en cuatro tipos:

1. Documentos sin esquema de directorio ni referencias a un esquema externo.
2. Documentos sin esquema de directorio pero que contengan al menos una referencia a un esquema externo.
3. Documentos que contengan solo un esquema de directorio.
4. Documentos que contengan tanto un esquema de directorio como entradas.

Un productor de DSML debe poder producir documentos de tipo 1. Un productor de DSML puede, además, producir documentos de tipos 2 a 4.

Un productor que pueda producir documentos de tipo 1 se considera un productor de nivel 1. Un productor que pueda producir documentos de los cuatro tipos se considera un productor de nivel 2.

CALLBACKS

El módulo utiliza callbacks para mejorar el rendimiento (aunque el aspecto de mejorar el rendimiento ;) y reducir el consumo de memoria necesario para parsear grandes documentos DSML. Cada vez que se procesa una sola entrada o esquema, se pasa el objeto Net::LDAP (ya sea un objeto Entry o Schema) a la rutina de callback.

CONSTRUCTOR

new ()
Crea un nuevo objeto Net::LDAP::DSML. Hay dos opciones para este método.

"output" es una referencia a un manejador de archivo que ya ha sido abierto o a un array.

"pretty_print" es una opción que imprime un salto de línea al final de cada secuencia de elementos. Esto hace que la salida XML sea más fácil de leer.

Ejemplo

my $dsml = Net::LDAP::DSML->new();
Imprime datos XML en la salida estándar.
my $dsml = Net::LDAP::DSML->new(output => \@array);
my $dsml = Net::LDAP::DSML->new(output => *FILE);
Imprime datos XML en un archivo o array.
my $dsml = Net::LDAP::DSML->new(output => \@array, pretty_print => 1);
my $dsml = Net::LDAP::DSML->new(output => *FILE, pretty_print => 1);
Imprime datos XML en un archivo o array en estilo de impresión formateada.

MÉTODOS

start_dsml ()
Inicia un archivo DSML.
end_dsml ()
Finaliza un archivo DSML.
write_entry (ENTRY )
ENTRY es un objeto Net::LDAP::Entry. El método write se encarga de parsear los datos LDAP en el objeto Entry y convertirlos al formato XML DSML.

Ejemplo

my $entry = $mesg->entry();
$dsml->write_entry($entry);
write_schema (SCHEMA )
SCHEMA es un objeto Net::LDAP::Schema. El método write_schema se encarga de parsear los datos LDAP en el objeto Schema y convertirlos al formato XML DSML.

Ejemplo

my $schema = $ldap->schema();
$dsml->write_schema($schema);
