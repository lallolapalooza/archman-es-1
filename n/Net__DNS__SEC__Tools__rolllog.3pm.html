NOMBRE

Net::DNS::SEC::Tools::rolllog - Interfaces de registro de rollover de DNSSEC-Tools.

SINOPSIS

use Net::DNS::SEC::Tools::rolllog;
@niveles = rolllog_levels();
$nivel_actual = rolllog_level();
$nivel_anterior = rolllog_level("info");
$nivel_anterior = rolllog_level(LOG_ERR,1);
$archivo_log_actual = rolllog_file();
$archivo_log_anterior = rolllog_file("-");
$archivo_log_anterior = rolllog_file("/var/log/roll.log",1);
$cadena_nivel_log = rolllog_str(8)
$cadena_nivel_log = rolllog_str("info")
$ret = rolllog_num("info");
$bool = rolllog_validlevel($nuevo_nivel);
$bool = rolllog_validlevel(8);
$tz_actual = rolllog_gettz();
$tz_anterior = rolllog_settz('local');
rolllog_log(LOG_INFO,"example.com","la zona es válida");

DESCRIPCIÓN

El módulo Net::DNS::SEC::Tools::rolllog proporciona interfaces de registro para los programas de rollover. Las interfaces de registro permiten registrar mensajes de registro. rollerd debe estar en ejecución, ya que es responsable de actualizar el archivo de registro.

Cada mensaje de registro se asigna a un nivel de registro particular. Los niveles de registro válidos son:

texto    numérico  significado
----     -------   ----------
tmi           1     El nivel más alto: se guardan todos los mensajes
                    de registro.
expire        3     Se proporciona una cuenta regresiva detallada de la
                    expiración de la zona.
info          4     Se registran muchos mensajes informativos.
phase         6     Se indica la fase de rollover actual de cada zona.
err           8     Se registran errores.
fatal         9     Se guardan errores fatales.

Los niveles incluyen todos los niveles numéricamente superiores. Por ejemplo, si el nivel de registro se establece en phase, también se registrarán los mensajes err y fatal.

INTERFACES DE REGISTRO

rolllog_file(newfile,useflag)
Esta rutina establece y recupera el archivo de registro para rollerd. El argumento newfile especifica el nuevo archivo de registro que se establecerá. Si newfile existe, debe ser un archivo regular.

El argumento useflag es un booleano que indica si se debe dar un mensaje descriptivo o no si se proporciona un archivo de registro no válido. Si useflag es verdadero, se da el mensaje y el proceso termina; si es falso, no se da ningún mensaje. Para cualquier condición de error, se devuelve una cadena vacía.

rolllog_gettz()
Esta rutina devuelve el selector de zona horaria que se está utilizando actualmente. Este valor puede ser 'gmt' (para la Hora del Meridiano de Greenwich) o 'local' (para la hora local del host).
rolllog_level(newlevel,useflag)
Esta rutina establece y recupera el nivel de registro para rollerd. El argumento newlevel especifica el nuevo nivel de registro que se establecerá. newlevel puede proporcionarse en formato de texto o numérico.

El argumento useflag es un booleano que indica si se debe dar un mensaje descriptivo y salir si se proporciona un nivel de registro no válido. Si useflag es verdadero, se da el mensaje y el proceso sale; si es falso, se devuelve -1.

Si se llama sin argumentos, se devuelve el nivel de registro actual. De hecho, el nivel actual siempre se devuelve a menos que se encuentre un error. Se devuelve -1 en caso de error.

rolllog_levels()
Esta rutina devuelve una matriz que contiene las formas de texto de los niveles de registro que se pueden configurar por el usuario. Los niveles se devuelven en orden, de más verboso a menos.
rolllog_log(level,group,message)
La interfaz rolllog_log() escribe un mensaje en el archivo de registro. Los mensajes de registro tienen este formato: 
timestamp: group: message

El argumento level es el nivel de registro del mensaje. Solo se escribirá en el archivo de registro si el nivel de registro actual es numéricamente igual o inferior a level.

group permite asociar mensajes. Actualmente es utilizado por rollerd para agrupar mensajes por la zona a la que se aplica el mensaje.

El argumento message es el mensaje de registro en sí. Se eliminan los saltos de línea finales.

rolllog_num(loglevel)
Esta rutina traduce un nivel de registro de texto (proporcionado en loglevel) al nivel de registro numérico asociado. El nivel de registro numérico se devuelve al llamador.

Si loglevel es un nivel de registro no válido, se devuelve -1.

rolllog_settz(tzsel)
Esta rutina establece la zona horaria que se utilizará para las marcas de tiempo en los mensajes escritos en el registro. Este valor tzsel puede ser 'gmt' (Hora del Meridiano de Greenwich) o 'local' (hora local del host). tzsel puede estar en mayúsculas o minúsculas; el valor se convertirá a minúsculas. Si no se pasa ningún valor, se utilizará el valor predeterminado.

Se devuelve el selector de zona horaria actual. Si se proporciona un selector no válido, se devuelve un valor indefinido.

rolllog_str(loglevel)
Esta rutina traduce un nivel de registro (proporcionado en loglevel) al nivel de registro de texto asociado. El nivel de registro de texto se devuelve al llamador.

Si loglevel es una cadena de texto, se verifica para asegurar que es un nivel de registro válido. La capitalización es irrelevante al verificar loglevel.

Si loglevel es numérico, debe estar en el rango válido de niveles de registro. Se devuelve undef si loglevel no es válido.

rolllog_validlevel(level)
Esta interfaz devuelve un valor booleano que indica si el nivel de registro dado es válido.

El argumento level es el nivel de registro que se va a validar. Puede ser un valor numérico o textual.
