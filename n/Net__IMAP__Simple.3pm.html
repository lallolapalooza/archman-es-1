NOMBRE

Net::IMAP::Simple - Extensión de Perl para el manejo simple de cuentas IMAP.

SINOPSIS

use strict;
use warnings;
use Net::IMAP::Simple;
use Email::Simple;
# Crear el objeto
my $imap = Net::IMAP::Simple->new('imap.example.com') ||
   die "No se pudo conectar a IMAP: $Net::IMAP::Simple::errstr\n";
# Iniciar sesión
if(!$imap->login('usuario','contraseña')){
    print STDERR "Fallo al iniciar sesión: " . $imap->errstr . "\n";
    exit(64);
}
# Imprimir los asuntos de todos los mensajes en la BANDEJA DE ENTRADA
my $nm = $imap->select('INBOX');
for(my $i = 1; $i <= $nm; $i++){
    if($imap->seen($i)){
        print "*";
    } else {
        print " ";
    }
    my $es = Email::Simple->new(join '', @{ $imap->top($i) } );
    printf("[%03d] %s\n", $i, $es->header('Subject'));
}
$imap->quit;

DESCRIPCIÓN

Este módulo es una forma simple de acceder a cuentas IMAP.

MÉTODO DE CREACIÓN DE OBJETO

my $imap = Net::IMAP::Simple->new( $servidor [ :puerto ]);
# O
my $imap = Net::IMAP::Simple->new( $servidor [, nombre_opcion => valor_opcion ] );

new

Este método de clase construye un nuevo objeto Net::IMAP::Simple. Toma un parámetro obligatorio que es el servidor al que conectarse, y parámetros opcionales adicionales.

El parámetro del servidor puede especificar solo el servidor, o tanto el servidor como el número de puerto. Para especificar un puerto alternativo, sepárelo del servidor con dos puntos (":"), "example.com:5143".

En caso de éxito se devuelve un objeto. En caso de fallo, no se devuelve nada y se establece un mensaje de error en $Net::IMAP::Simple.

Ver "PREAUTH" abajo para una invocación especial de nombre de host que no usa Sockets (internamente).

Las opciones se proporcionan como un hash a new():

puerto => int
Asigna el número de puerto (predeterminado: 143)
timeout => int (predeterminado: 90)
Tiempo de espera de conexión en segundos.
retry => int (predeterminado: 1)
Intenta reintentar el intento de conexión (x) veces antes de rendirse.
retry_delay => int (predeterminado: 5)
Espera (x) segundos antes de reintentar un intento de conexión.
use_v6 => BOOL
Si se establece en verdadero, intente usar sockets IPv6 en lugar de sockets IPv4.

Esta opción requiere el módulo IO::Socket::INET6.

use_ssl => BOOL
Si se establece en verdadero, intente usar sockets IO::Socket::SSL en lugar de sockets normales.

Tenga en cuenta que no se hace ningún intento de verificar la validez del certificado por defecto. Esto es una seguridad personal terrible, pero coincide con el comportamiento anterior de este módulo. Por favor, considere usar "find_ssl_defaults" abajo.

Esta opción requiere el módulo IO::Socket::SSL.

ssl_version => version
Esto debería ser uno o más de los siguientes (separados por espacios): SSLv3 SSLv2 TLSv1. Si especifica, por ejemplo, "SSLv3 SSLv2", IO::Socket::SSL intentará la negociación automática. En el momento de escribir esto, la cadena predeterminada era negociación automática v3/v2, puede haber cambiado en el momento en que lea esto.

Advertencia: establecer esto también establecerá "use_ssl".

find_ssl_defaults => []
Busca en algunos lugares estándar bibliotecas de certificados CA y, si se encuentran, establece valores predeterminados razonables en la línea de lo siguiente. 
ssl_options => [ SSL_ca_path => "/etc/ssl/certs/",
    SSL_verify_mode => IO::Socket::SSL::SSL_VERIFY_PEER() ]

Advertencia: establecer esto también establecerá "use_ssl".

ssl_options => []
Puede proporcionar sus propias opciones de IO::Socket::SSL si lo desea. Está completamente anulado por "find_ssl_defaults" arriba.
bindaddr => str
Asigna una dirección local para enlazar.
use_select_cache => BOOL
Habilita la caché de select() internamente.
select_cache_ttl => int
El número de segundos que se permite que un resultado de caché de select permanezca activo antes de ejecutar "$imap->select()" nuevamente.
debug => BOOL | \*HANDLE | warn | file:name
Habilita la salida de depuración. Si "\*HANDLE" es un handle de archivo válido, la depuración se escribirá en él. Si es la cadena "warn", la depuración se escribirá usando el comando warn. Si es una cadena de la forma "file:name", se abrirá el archivo nombrado para añadir y se escribirán las depuraciones en él. De lo contrario, la depuración se escribirá en "STDOUT".
readline_callback => CODE
Puede optar por pasar una función de devolución de llamada para preprocesar líneas antes de que se entreguen al resto de los internos de Net::IMAP::Simple. Esto puede ser útil para animar un indicador o modificar el comportamiento de IMAP.

PREAUTH

En lugar de pasar un número de puerto y emitir un login, en algunas situaciones puede ser conveniente autenticarse con (por ejemplo) ssh y simplemente invocar (por ejemplo) dovecot manualmente.

Si el nombre del servidor comienza con "cmd:", Net::IMAP::Simple ejecutará el comando en lugar de construir sockets. Esta es una configuración típica:

my $cmd = "ssh -C mailhost dovecot --exec-mail imap";
my $imap = Net::IMAP::Simple->new("cmd:$cmd");
 # $imap->login(); ... no se necesita esto
my $number_of_messages = $imap->select("INBOX");

MÉTODOS

starttls
$imap->starttls;

Si inicia una sesión IMAP y desea actualizar a SSL más tarde, puede usar esta función para iniciar TLS. Esta función intentará "require" IO::Socket::SSL y Net::SSLeay en tiempo de ejecución.

login
my $msgs_bandeja_entrada = $imap->login($usuario, $contraseña);

Este método toma dos parámetros obligatorios, un nombre de usuario y una contraseña. Este par se autentica contra el servidor. Si la autenticación es exitosa, se devolverá VERDADERO (1).

No se devuelve nada en caso de fallo y el manejador de errores errstr() se establece con el mensaje de error.

status
my $num_mensajes                     = $imap->status($carpeta);
my ($no_vistos, $recientes, $num_mensajes) = $imap->status($carpeta);

Emite un comando "STATUS". El comando "STATUS" cuenta los mensajes sin alterar el estado del buzón con nombre (opcionalmente). Devuelve el número de mensajes, o el número de mensajes no vistos, recientes y el número total de mensajes.

$carpeta es un argumento opcional. status() usará el buzón actual o "INBOX" si no se proporciona el argumento $carpeta.

Este método no utiliza caché.

OTRAS NOTAS

conjunto de secuencias
Los números de mensaje nunca se verifican antes de ser enviados al servidor IMAP (después de todo, este es un módulo "simple"), por lo que en la mayoría de los lugares donde se requieren números de mensaje, se pueden utilizar lo que se conoce como conjuntos de secuencias. Ejemplos: 
$imap->copy(   "3,4,9:22", "ANOTHERBOX" ) or die $imap->errstr;
$imap->delete( "3,4,9:22" ) or die $imap->errstr;
