Net::servent(3perl) Guía de referencia para programadores de Perl Net::servent(3perl)

NOMBRE

Net::servent - interfaz por nombre a las funciones incorporadas de Perl getserv*()

SINOPSIS

use Net::servent;
my $s = getservbyname(shift || 'ftp') || die "no hay servicio";
printf "el puerto para %s es %s, los alias son %s\n",
   $s->name, $s->port, "@{$s->aliases}";
use Net::servent qw(:FIELDS);
getservbyname(shift || 'ftp') || die "no hay servicio";
print "el puerto para $s_name es $s_port, los alias son @s_aliases\n";

DESCRIPCIÓN

Las exportaciones por defecto de este módulo anulan las funciones principales getservent(), getservbyname() y getnetbyport(), reemplazándolas con versiones que devuelven objetos "Net::servent". Toman argumentos segundos por defecto de "tcp". Este objeto tiene métodos que devuelven el nombre de campo de estructura similarmente nombrado de la estructura servent de C de netdb.h; a saber, name, aliases, port y proto. El método aliases devuelve una referencia a una matriz, los demás escalares.

También puede importar todos los campos de la estructura directamente en su espacio de nombres como variables regulares usando la etiqueta de importación :FIELDS. (Tenga en cuenta que esto todavía anula sus funciones principales). Acceda a estos campos como variables nombradas con un prefijo "s_". Por lo tanto, "$serv_obj->name()" corresponde a $s_name si importa los campos. Las referencias a matrices están disponibles como variables de matriz regulares, por lo que, por ejemplo, "@{ $serv_obj->aliases()}" sería simplemente @s_aliases.

La función getserv() es un simple front-end que reenvía un argumento numérico a getservbyport(), y el resto a getservbyname().

Para acceder a esta funcionalidad sin las anulaciones principales, pase a "use" una lista de importación vacía y luego acceda a las funciones con sus nombres completamente calificados. Por otro lado, las funciones incorporadas todavía están disponibles a través del pseudo-paquete "CORE::".

EJEMPLOS

use Net::servent qw(:FIELDS);
while (@ARGV) {
    my ($service, $proto) = ((split m!/!, shift), 'tcp');
    my $valet = getserv($service, $proto);
    unless ($valet) {
        warn "$0: No service: $service/$proto\n"
        next;
    }
    printf "el servicio $service/$proto es el puerto %d\n", $valet->port;
    print "los alias son @s_aliases\n" if @s_aliases;
}

NOTA

Aunque esta clase está implementada actualmente utilizando el módulo Class::Struct para construir una clase similar a una estructura, no debes confiar en esto.
