NOMBRE

Net::DNS::SEC::Tools::tooloptions - Rutinas de opciones de DNSSEC-Tools.

SINOPSIS

use Net::DNS::SEC::Tools::tooloptions;
@specopts = ("propagate+", "waittime=i");
%opts = opts_cmdline($restoreargv,@calleropts);
$optsref = opts_cmdopts(@specopts);
%options = %$optsref;
$zoneref = opts_zonekr($keyrec_file,$keyrec_name,@specopts);
%zone_kr = %$zoneref;
opts_setcsopts(@specopts);
opts_createkrf();
opts_suspend();
opts_restore();
opts_drop();
opts_reset();
opts_gui();
opts_nogui();
$oldaction = opts_onerr(1);
opts_onerr(0);

DESCRIPCIÓN

DNSSEC-Tools soporta un conjunto de opciones comunes a todas las herramientas de la suite. Estas opciones pueden ser establecidas desde los valores por defecto de DNSSEC-Tools, valores establecidos en el archivo de configuración dnssec-tools.conf, en un archivo keyrec, desde opciones específicas del comando, desde opciones de la línea de comandos, o desde cualquier combinación de los cinco. Para imponer una secuencia común de interpretación de opciones, todas las DNSSEC-Tools deben usar las rutinas de tooloptions.pm para inicializar sus opciones.

Las rutinas de tooloptions.pm combinan datos de las fuentes de opciones mencionadas anteriormente en una tabla hash. La tabla hash se devuelve al llamador, que luego usará las opciones según sea necesario.

Las opciones de la línea de comandos se guardan entre llamadas, por lo que un comando puede llamar a las rutinas de tooloptions.pm múltiples veces y aún así tener las opciones de la línea de comandos incluidas en la tabla hash final. Esto es útil para examinar múltiples keyrecs en un solo comando. La inclusión de opciones de la línea de comandos puede ser suspendida y restaurada usando las llamadas opts_suspend() y opts_restore(). Las opciones pueden ser descartadas por completo llamando a opts_drop(); una vez descartadas, las opciones de la línea de comandos nunca podrán ser restauradas. La suspensión, restauración y descarte de opciones de la línea de comandos solo son efectivos después de la llamada inicial a tooloptions.pm.

Las fuentes de opciones se combinan en este orden:

1. Valores por defecto de DNSSEC-Tools
Los valores por defecto de DNSSEC-Tools, tal como se definen en conf.pm, se colocan en una tabla hash, con los nombres de las opciones como clave de la hash.
2. Archivo de configuración de DNSSEC-Tools
Se lee el archivo de configuración de DNSSEC-Tools a nivel del sistema y estos valores de opción se agregan a la colección de opciones. Nuevamente, los nombres de las opciones se usan como clave de la hash.
3. Archivo keyrec
Si se especificó un archivo keyrec, se recuperará el keyrec con el nombre keyrec_name. Los campos del keyrec se agregan a la tabla hash. Cualquier campo cuyo nombre de clave coincida con una clave existente en la hash anulará los valores existentes.
4. Opciones específicas del comando
Las opciones específicas de los comandos que invocan pueden especificarse en @specopts. Este array es analizado por Getoptions() del módulo Perl Getopt::Long. Estas opciones se integran en la tabla hash; posiblemente anulando los valores existentes en la hash. Las opciones dadas en @specopts deben estar en el formato requerido por Getoptions().
5. Opciones de la línea de comandos
Las opciones de la línea de comandos se analizan usando Getoptions() del módulo Perl Getopt::Long. Estas opciones se integran en la tabla hash; de nuevo, posiblemente anulando los valores existentes en la hash. Las opciones dadas en @specopts deben estar en el formato requerido por Getoptions().

Se devuelve una referencia a la tabla hash creada en estos pasos al llamador.

EJEMPLO

dnssec-tools.conf tiene estas entradas:

ksklength      2048
zsklength      1024

example.keyrec tiene esta entrada:

key         "Kexample.com.+005+12345"
        zsklength        "2048"

zonesigner se ejecuta con la siguiente línea de comandos:

zonesigner -zsklength 4096 -wait 3600 ...  example.com

opts_zonekr("example.keyrec","Kexample.com.+005+12345",("wait=i")) leerá cada fuente de opciones en orden, terminando con:
ksklength 1024
zsklength 4096
wait 600

INTERFACES DE TOOLOPTIONS

opts_cmdline($restoreargv,@calleropts)
Esta rutina analiza una línea de comandos buscando los argumentos en el conjunto estándar de opciones y un conjunto opcional de opciones especificadas por el llamador. Si el primer argumento es verdadero, el @ARGV del programa se restaura después del análisis. Si el llamador proporciona otros argumentos, se agregan como opciones adicionales. Las opciones analizadas se devuelven al llamador en una tabla hash.
opts_cmdopts(@csopts)
La llamada opts_cmdopts() construye una tabla hash de opciones a partir del archivo de configuración del sistema, un keyrec y un conjunto de opciones específicas del comando. Se devuelve una referencia a esta tabla hash de opciones al llamador.

Si se proporciona $keyrec_file como una cadena vacía, entonces no se consultará ningún archivo keyrec. En este caso, se asume que $keyrec_name se omitirá por completo.

Si se proporciona un $keyrec_file inexistente y se ha llamado a opts_createkrf(), entonces se creará el archivo keyrec con el nombre dado. opts_createkrf() debe ser llamado por cada archivo keyrec que deba ser creado, ya que el estado de creación de keyrec de tooloptions se reinicia después de que tooloptions() se complete.

opts_zonekr($keyrec_file,$keyrec_name,@csopts)
Esta rutina devuelve una referencia a las opciones recopiladas de las fuentes de opciones básicas y del keyrec de la zona nombrado por $keyrec_name, que se encuentra en $keyrec_file. Los campos del keyrec de KSK y ZSK de la zona también se integran, pero se excluyen los campos keyrec_ de la clave. Esta llamada asegura que el keyrec nombrado es un keyrec de zona; si no lo es, se devuelve undef.

El archivo keyrec se lee con keyrec_read(). Para asegurar que se lea correctamente, se llama a keyrec_close() primero.

El argumento $keyrec_file especifica un archivo keyrec que será consultado. Se cargará el keyrec nombrado por el argumento $keyrec_name. Si se encuentra un archivo keyrec y opts_createkrf() ha sido llamado previamente, entonces el archivo keyrec se creará si no existe.

Si $keyrec_file se proporciona como "", entonces la línea de comandos busca una opción -krfile. Si $keyrec_name se proporciona como "", entonces el nombre se toma de $ARGV[0].

El array @specopts contiene argumentos específicos del comando; los argumentos deben estar en el formato prescrito por el módulo Perl Getopt::Long.

Si la línea de comandos contiene la opción -dtconfig, entonces opts_zonekr() establece esa opción como el archivo de configuración. Luego analiza ese archivo y lo usa como fuente de datos del archivo de configuración.

opts_setcsopts(@csopts)
Esta rutina guarda una copia de las opciones específicas del comando dadas en @csopts. Esta colección de opciones se agrega al array @csopts que puede pasarse a las rutinas de tooloptions.pm.
opts_createkrf()
Esta rutina marca el archivo keyrec para su creación si no existe. Esto es útil para las herramientas que no deben fallar si el archivo keyrec no está presente. La creación se realiza solo si el archivo keyrec se especifica a través de la línea de comandos o el archivo de configuración.
opts_suspend()
Esta rutina suspende el análisis de opciones de la línea de comandos. Las opciones que se analicen después de esta llamada se ignorarán hasta que se llame a opts_restore().
opts_restore()
Esta rutina restaura el análisis de opciones de la línea de comandos. Las opciones que se ignoren mientras el análisis estaba suspendido se analizarán ahora.
opts_drop()
Esta rutina descarta las opciones de la línea de comandos y la capacidad de restaurarlas. Después de llamar a esta rutina, las opciones de la línea de comandos ya no estarán disponibles.
opts_reset()
Esta rutina restablece todas las opciones a sus valores por defecto. Esto es útil para anular las opciones establecidas previamente.
opts_gui()
Esta rutina establece que la interfaz gráfica de usuario (GUI) está activa. Esto puede afectar el comportamiento de algunas herramientas.
opts_nogui()
Esta rutina establece que la interfaz gráfica de usuario (GUI) no está activa. Esto puede afectar el comportamiento de algunas herramientas.
opts_onerr($newaction)
Esta rutina establece la acción a tomar en caso de error de análisis de opciones. Devuelve la acción anterior. Las acciones posibles son: 0 para ignorar el error, 1 para imprimir un mensaje de error y continuar, 2 para terminar el programa.

NAME

NAME
opts_zonekr()
Forzará la creación de un archivo keyrec vacío si el archivo especificado no existe. Esto puede ocurrir en llamadas a opts_zonekr().
opts_suspend()
Detener la inclusión de las opciones de línea de comandos en la tabla de respuestas final.
opts_restore()
Restaurar la inclusión de las opciones de línea de comandos en la tabla de respuestas final.
opts_drop()
Eliminar las opciones de línea de comandos. Estas no estarán disponibles para la construcción de la tabla de respuestas final para este ejecucion de comandos.
opts_reset()
Resetea un flag interno para que las opciones de línea de comandos puedan ser re-examinadas. Esto es usualmente útil si las opciones han sido modificadas por el programa que llama.
opts_gui()
Establece un flag interno para que los argumentos de comandos puedan especificarse con una GUI. La utilización de GUI requiere que Getopt::GUI::Long esté disponible. Si no lo está, entonces Getopt::Long se usará.
opts_nogui()
Establece un flag interno para que la GUI no sea utilizada para especificar los argumentos de comandos.
opts_onerr(exitflag)
Establece un flag interno indicando qué debe hacerse si se especifica una opción inválida en la línea de comandos. Si el valor de exitflag es no cero, el proceso se saldrá en caso de opción inválida; si es cero, el proceso no se saldrá. El comportamiento por defecto es informar un error sin salir.

El comportamiento antiguo se devuelve.
