NOMBRE

Net::Jabber::Server - Biblioteca de servidor Jabber

SINOPSIS

Net::Jabber::Server es un módulo que proporciona al desarrollador un acceso fácil
para desarrollar aplicaciones que necesiten un servidor Jabber embebido.

DESCRIPCIÓN

Server.pm busca proporcionar suficientes APIs de alto nivel y automatización de
las APIs de bajo nivel para que la creación y el lanzamiento de un servidor Jabber
en Perl sea trivial. Para aquellos que deseen trabajar con el bajo nivel, también
pueden hacerlo, pero esas funciones se cubren en la documentación de cada módulo.
Net::Jabber::Server proporciona funciones para ejecutar un servidor Jabber completo que
acepta conexiones entrantes y entrega paquetes a servidores Jabber externos.
Puede usar todas o ninguna de las funciones, no hay requisitos.
Para obtener más información sobre cómo se escribe Net::Jabber, consulte la ayuda
de Net::Jabber.
Para obtener una lista completa de las funciones de alto nivel disponibles, consulte
Net::Jabber::Protocol.

Funciones básicas

use Net::Jabber qw(Server);
$Server = new Net::Jabber::Server();
$Server->Start();
$Server->Start(jabberxml=>"custom_jabber.xml",
               hostname=>"foobar.net");
%status = $Server->Process();
%status = $Server->Process(5);

$Server->Stop();

MÉTODOS

Funciones básicas

new(debuglevel=>0|1|2, - crea el objeto Server. debugfile
    debugfile=>string,   debería establecerse en la ruta para que se escriba el registro
    debugtime=>0|1)      de depuración. Si se establece en "stdout",
                         la depuración irá allí. debuglevel
                         controla la cantidad de depuración. Para obtener más
                         información sobre los valores válidos para
                         debuglevel, debugfile y debugtime, consulte
                         Net::Jabber::Debug.
Start(hostname=>string, - inicia el servidor escuchando en los
      jaberxml=>string)   puertos adecuados. hostname es una forma rápida de indicar
                          al servidor el nombre de host en el que escuchar.
                          jabberxml define la ruta a un archivo de configuración
                          diferente de jabberd (el valor predeterminado es
                          "./jabber.xml").
Process(integer) - toma el período de tiempo de espera como argumento. Si no
                   se especifica un tiempo de espera, la función se bloquea hasta
                   que se reciba un paquete. De lo contrario, espera ese
                   número de segundos y luego sale para que su programa
                   pueda continuar haciendo cosas útiles. NOTA: Esto es
                   importante para las GUI. Necesita dejar tiempo para
                   procesar comandos de GUI, incluso si está esperando paquetes.
                   Los siguientes son los posibles valores de retorno
                   para cada entrada del hash y lo que significan:
                       1   - Estado correcto, datos recibidos.
                       0   - Estado correcto, no se recibieron datos.
                     undef - Estado no correcto, detener el procesamiento.

                   IMPORTANTE: Debe comprobar la salida de cada
                   Process. Si obtiene un undef, la conexión se ha caído y
                   debe actuar en consecuencia.
Stop() - detiene el servidor y cierra todos los subprogramas.
