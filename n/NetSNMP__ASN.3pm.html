NOMBRE

NetSNMP::ASN - Extensión de Perl para tipos ASN.1 de SNMP

SINOPSIS

use NetSNMP::ASN qw(:all);
my $asn_int = ASN_INTEGER;

DESCRIPCIÓN

El módulo NetSNMP::ASN proporciona los tipos ASN.1 para SNMP.
