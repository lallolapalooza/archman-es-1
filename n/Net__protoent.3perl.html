Net::protoent(3perl) Guía de referencia para programadores de Perl Net::protoent(3perl)

NOMBRE

Net::protoent - interfaz por nombre a las funciones incorporadas de Perl getproto*()

SINOPSIS

use Net::protoent;
my $p = getprotobyname(shift || 'tcp') || die "no proto";
printf "proto para %s es %d, alias son %s\n",
   $p->name, $p->proto, "@{$p->aliases}";
use Net::protoent qw(:FIELDS);
getprotobyname(shift || 'tcp') || die "no proto";
print "proto para $p_name es $p_proto, alias son @p_aliases\n";

DESCRIPCIÓN

Las exportaciones predeterminadas de este módulo reemplazan las funciones principales getprotoent(), getprotobyname() y getnetbyport(), reemplazándolas por versiones que devuelven objetos "Net::protoent". Toman argumentos secundarios predeterminados de "tcp". Este objeto tiene métodos que devuelven el campo de estructura con el mismo nombre de la estructura protoent de C de netdb.h; a saber: name, aliases y proto. El método aliases devuelve una referencia a array, los demás escalares.

También puede importar todos los campos de la estructura directamente en su espacio de nombres como variables regulares utilizando la etiqueta de importación :FIELDS. (Tenga en cuenta que esto aún anula sus funciones principales). Acceda a estos campos como variables con un prefijo "p_". Por lo tanto, "$proto_obj->name()" corresponde a $p_name si importa los campos. Las referencias a arrays están disponibles como variables de array regulares, por lo que, por ejemplo, "@{ $proto_obj->aliases() }" sería simplemente @p_aliases.

La función getproto() es un simple front-end que reenvía un argumento numérico a getprotobyport(), y el resto a getprotobyname().

Para acceder a esta funcionalidad sin las anulaciones principales, pase a "use" una lista de importación vacía y luego acceda a las funciones con sus nombres completos calificados. Por otro lado, las funciones incorporadas todavía están disponibles a través del pseudopaquete "CORE::".

NOTA

Aunque esta clase está implementada actualmente utilizando el módulo Class::Struct para construir una clase similar a una estructura, no debe confiar en esto.
