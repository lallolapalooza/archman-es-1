NOMBRE

Net::DNS::RR::CSYNC - registro de recursos CSYNC de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name CSYNC SOAserial flags typelist');

DESCRIPCIÓN

Clase para registros de recursos CSYNC de DNSSEC.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

Se desaconseja el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otro comportamiento impredecible.

SOAserial

soaserial

$soaserial = $rr->soaserial;
$rr->soaserial( $soaserial );

El campo SOA Serial contiene una copia del número de serie SOA de 32 bits de la zona hija.

flags

$flags = $rr->flags;
$rr->flags( $flags );

El campo flags contiene 16 bits de banderas booleanas que definen operaciones que afectan el procesamiento del registro CSYNC.

immediate
$rr->immediate(1);
if ( $rr->immediate ) {
        ...
}

Si no se establece, un agente padre no debe procesar el registro CSYNC hasta que el administrador de la zona apruebe la operación a través de un mecanismo fuera de banda.

soaminimum
$rr->soaminimum(1);
if ( $rr->soaminimum ) {
        ...
}

Si se establece, un agente padre que consulta a los servidores autoritativos hijos no debe actuar sobre datos de zonas que anuncian un número de serie SOA menor que el valor de SOAserial.

typelist

@typelist = $rr->typelist;
$typelist = $rr->typelist;

La lista de tipos indica los tipos de registro que serán procesados por el agente padre. Cuando se llama en contexto escalar, la lista se interpola en una cadena.
