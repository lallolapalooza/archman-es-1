NOMBRE

Net::DBus::Binding::Message::MethodReturn - un mensaje que codifica el retorno de un método

DESCRIPCIÓN

Este módulo forma parte de las APIs de bajo nivel de enlace DBus y no debería ser utilizado por código de aplicación. No se garantizan la estabilidad de las APIs bajo el namespace "Net::DBus::Binding::" entre lanzamientos.

Este módulo proporciona un constructor de conveniencia para crear un mensaje que representa la respuesta a un método.

MÉTODOS

mi $retorno = Net::DBus::Binding::Message::MethodReturn->new( llamada => $llamada_metodo);
Crea un mensaje que representa una respuesta a la llamada al método pasada en el parámetro "llamada".
