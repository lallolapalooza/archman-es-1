Net::DNS::RR::TKEY(3) Documentación de Perl aportada por el usuario Net::DNS::RR::TKEY(3)

NOMBRE

Net::DNS::RR::TKEY - Registro de recursos TKEY de DNS

SINOPSIS

use Net::DNS;
$rr = new Net::DNS::RR('ejemplo.com IN TKEY ... ');

DESCRIPCIÓN

Clase para registros de recursos TKEY (TSIG Key) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete ni el acceso directo a las estructuras de datos internas, ya que podría provocar la terminación del programa u otros comportamientos impredecibles.

algoritmo

$algoritmo = $rr->algorithm;
$rr->algorithm( $algoritmo );

El nombre del algoritmo tiene la forma de un nombre de dominio con el mismo significado que en [RFC 2845]. El algoritmo determina cómo se utiliza realmente el material de clave secreta acordado mediante el RR TKEY para derivar la clave específica del algoritmo.

inicio

$inicio = $rr->inception;
$rr->inception( $inicio );

Tiempo expresado como el número de segundos no bisiestos módulo 2**32 desde el inicio de enero de 1970 GMT.

expiración

$expiracion = $rr->expiration;
$rr->expiration( $expiracion );

Tiempo expresado como el número de segundos no bisiestos módulo 2**32 desde el inicio de enero de 1970 GMT.

modo

$modo = $rr->mode;
$rr->mode( $modo );

El campo modo especifica el esquema general para el acuerdo de claves o el propósito del mensaje DNS TKEY, como se define en [RFC2930(2.5)].

error

$error = $rr->error;
$rr->error( $error );

El campo del código de error es un RCODE extendido.

clave

$clave = $rr->key;
$rr->key( $clave );

Secuencia de octetos que representan los datos de intercambio de claves. El significado de estos datos depende del modo.

otro

$otro = $rr->other;
$rr->other( $otro );

Contenido no definido en la especificación [RFC2930] pero que puede utilizarse en futuras extensiones.
