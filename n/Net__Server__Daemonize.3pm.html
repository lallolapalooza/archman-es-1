NOMBRE

Net::Server::Daemonize - Utilidades seguras de fork y demonización

SINOPSIS

use Net::Server::Daemonize qw(daemonize);
daemonize(
  'nobody',                 # Usuario
  'nobody',                 # Grupo
  '/var/state/mydaemon.pid' # Ruta al archivo PID - opcional
);

DESCRIPCIÓN

Este módulo está diseñado para permitirte demonizar tu servidor de forma sencilla y segura en sistemas que soportan el módulo POSIX. Esto significa que tu script de Perl se ejecuta en segundo plano, y su ID de proceso se almacena en un archivo para que puedas detenerlo fácilmente más tarde.

FUNCIONES EXPORTADAS

daemonize
Rutina principal. Los argumentos son usuario (o ID de usuario), grupo (o ID de grupo o lista de grupos separada por espacios) y archivo PID (ruta al archivo). Esta rutina verificará el archivo PID, realizará un fork seguro, creará el archivo PID (almacenando el PID en el archivo), se convertirá en otro usuario y grupo, cerrará STDIN, STDOUT y STDERR, se separará del grupo de procesos (convertirse en líder de sesión) e instalará $SIG{INT} para eliminar el archivo PID. En otras palabras, demoniza. Todos los errores resultan en un `die`.
safe_fork
Bloquea SIGINT durante el fork. Sin argumentos. Devuelve el PID del hijo del fork. Todos los errores resultan en un `die`.
set_user
Conviértete en otro usuario y grupo. Los argumentos son usuario (o ID de usuario) y grupo (o ID de grupo o lista de grupos separada por espacios).
set_uid
Conviértete en otro usuario. El argumento es usuario (o ID de usuario). Todos los errores provocan un `die`.
set_gid
Conviértete en otro grupo. Los argumentos son grupos (o IDs de grupo o lista de grupos separada por espacios o IDs de grupo). Todos los errores provocan un `die`.
get_uid
Encuentra el UID. El argumento es usuario (el ID de usuario devuelve el ID de usuario). Devuelve el ID de usuario. Todos los errores provocan un `die`.
get_gid
Encuentra los GID. Los argumentos son grupos o lista de grupos separada por espacios. Todos los errores provocan un `die`.
is_root_user
Determina si el proceso se está ejecutando como root. Devuelve 1 o undef.
check_pid_file
Los argumentos son archivo PID (ruta completa al archivo PID). Verifica la existencia del archivo PID. Si el archivo existe, lo abre y determina si el proceso que lo creó todavía se está ejecutando. Esto se hace primero verificando un sistema de archivos `/proc` y segundo usando un comando `ps` (sintaxis BSD). (Si ninguna de estas opciones existe, se asume que el proceso ha terminado). Si el proceso todavía se está ejecutando, se aborta. De lo contrario, devuelve verdadero. Todos los errores provocan un `die`.
create_pid_file.
Los argumentos son archivo PID (ruta completa al archivo PID). Llama a `check_pid_file`. Si tiene éxito (no existe el archivo PID), crea un archivo PID y almacena `$$` en el archivo.
unlink_pid_file
Hace exactamente eso.
