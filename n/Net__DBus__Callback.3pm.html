NOMBRE

Net::DBus::Callback - una devolución de llamada para recibir eventos del reactor

SINOPSIS

use Net::DBus::Callback;
# Asumamos que tenemos un objeto 'terminal' y que tiene un método
# que se invoca cada vez que hay entrada en su terminal.
#
# Para crear una devolución de llamada que invoque este método, se podría usar
my $cb = Net::DBus::Callback->new(object => $terminal,
                                  method => "handle_stdio");
# Lo que sea que esté monitorizando el canal stdio, luego
# invocaría la devolución de llamada, quizás pasando un parámetro con
# datos 'interesantes', como el número de bytes disponibles
$cb->invoke($nbytes)
#... lo que resulta en una llamada a
#  $terminal->handle_stdio($nbytes)

DESCRIPCIÓN

Este módulo proporciona un contenedor simple para almacenar los detalles de una devolución de llamada que se invocará en una fecha posterior. Se utiliza al registrarse para recibir eventos de la clase Net::DBus::Reactor. Nota: El uso de este módulo en código de aplicación ya no es necesario y permanece puramente por compatibilidad con versiones anteriores. En su lugar, simplemente puede pasar una referencia de código de subrutina en cualquier lugar donde se desee una devolución de llamada.

MÉTODOS

my $cb = Net::DBus::Callback->new(method => $name, [args => \@args])
Crea un nuevo objeto de devolución de llamada para invocar una función simple. El parámetro "method" debe ser el nombre de la función completamente calificado a invocar, incluido el nombre del paquete. El parámetro opcional "args" es una referencia a una matriz de parámetros que se pasarán a la devolución de llamada, además de los que se pasen al método "invoke".
my $cb = Net::DBus::Callback->new(object => $object, method => $name, [args => \@args])
Crea un nuevo objeto de devolución de llamada para invocar un método en un objeto. El parámetro "method" debe ser el nombre del método a invocar, mientras que el parámetro "object" debe ser un objeto bendecido en el que se invocará el método. El parámetro opcional "args" es una referencia a una matriz de parámetros que se pasarán a la devolución de llamada, además de los que se pasen al método "invoke". método.
$cb->invoke(@args)
Invoca la devolución de llamada. La lista de argumentos que se pasa a la devolución de llamada es una combinación de los argumentos proporcionados en el constructor de la devolución de llamada, seguidos de los argumentos proporcionados en el método "invoke".
