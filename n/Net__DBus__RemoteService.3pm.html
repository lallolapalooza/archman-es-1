NOMBRE

Net::DBus::RemoteService - Accede a servicios proporcionados en el bus

SINOPSIS

my $bus = Net::DBus->find;
my $service = $bus->get_service("org.freedesktop.DBus");
my $object = $service->get_object("/org/freedesktop/DBus");
foreach (@{$object->ListNames}) {
  print "$_\n";
}

DESCRIPCIÓN

Este objeto proporciona un identificador para un servicio remoto en el bus. Desde este identificador es posible acceder a los objetos asociados con el servicio. Si un servicio no se está ejecutando, se intentará activarlo la primera vez que se llame a un método contra uno de sus objetos.

MÉTODOS

my $service = Net::DBus::RemoteService->new($bus, $owner, $service_name);
Crea un nuevo identificador para un servicio remoto. El parámetro $bus es una instancia de Net::DBus, $owner es el nombre del cliente que proporciona el servicio, mientras que $service_name es el nombre conocido del servicio en el bus. Los nombres de servicio consisten en dos o más tokens, separados por puntos, mientras que los tokens comprenden las letras a-z, A-Z, 0-9 y _, por ejemplo "org.freedesktop.DBus". En general, no es necesario llamar a este constructor; en su lugar, se debe usar el método "get_service" de Net::DBus. Esto almacena en caché los identificadores de servicios remotos, eliminando la recuperación repetida de datos de introspección.
my $bus = $service->get_bus;
Recupera un identificador para el bus al que está adjunto este servicio. El objeto devuelto será una instancia de Net::DBus.
my $service_name = $service->get_service_name
Recupera el nombre del servicio remoto tal como lo conoce el bus.
my $owner_name = $service->get_owner_name;
Recupera el nombre del cliente propietario del servicio en el momento en que se conectó.
my $object = $service->get_object($object_path[, $interface]); =item my $object = $service->get_object($object_path, \%params);
Recupera un identificador para el objeto remoto proporcionado por el servicio con el nombre de $object_path. Si se proporciona el parámetro opcional $interface, el objeto se convertirá inmediatamente a la interfaz designada. Nota: solo es necesario convertir un objeto a una interfaz específica si hay varias interfaces en el objeto que proporcionan métodos con el mismo nombre, o si el objeto remoto admite introspección. El objeto devuelto será una instancia de Net::DBus::RemoteObject.

Está disponible una forma alternativa del método, pasando una referencia de hash de parámetros adicionales. Las claves válidas en el hash son "interface" que especifica el nombre de la interfaz a la que convertir, y "timeout" que especifica un tiempo de espera en milisegundos.

my $timeout = $service->timeout(60 * 1000);
Establece o recupera el valor de tiempo de espera que se utilizará para las solicitudes de DBus que pertenecen a este servicio. El valor está en milisegundos. Si el tiempo de espera de un servicio no está definido, se aplicará el tiempo de espera predeterminado del bus.
