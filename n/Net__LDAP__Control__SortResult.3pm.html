NOMBRE

Net::LDAP::Control::SortResult - Objeto de control de resultado de ordenación en el servidor (SSS)

SINOPSIS

use Net::LDAP::Control::Sort;
use Net::LDAP::Constant qw(LDAP_CONTROL_SORTRESULT);
use Net::LDAP::Util qw(ldap_error_name);
$sort = Net::LDAP::Control::Sort->new(
  order => "cn -age"
);
$mesg = $ldap->search( @args, control => [ $sort ]);
($resp) = $mesg->control( LDAP_CONTROL_SORTRESULT );
if ($resp) {
  if ($resp->result) {
    my $attr = $resp->attr;
    print "Problema al ordenar, ",ldap_error_name($resp->result);
    print " ($attr)"  if $attr;
    print "\n";
  }
  else {
    print "Los resultados están ordenados\n";
  }
}
else {
  print "El servidor no soporta la ordenación\n";
}

DESCRIPCIÓN

"Net::LDAP::Control::SortResult" es una subclase de Net::LDAP::Control. Proporciona una clase para manipular el control de solicitud de ordenación LDAP 1.2.840.113556.1.4.474 tal como se define en RFC-2891.

El servidor devolverá un control de resultado de ordenación en respuesta a una búsqueda con un control de ordenación en el servidor. Si no se devuelve un control de resultado de ordenación, el usuario puede asumir que el servidor no soporta la ordenación y que los resultados no están ordenados.

ARGUMENTOS DEL CONSTRUCTOR

attr
Si "result" indica que hubo un problema con la ordenación y ese problema se debió a uno de los atributos especificados en el control de ordenación. "attr" se establece en el nombre del atributo que causa el problema.
result
Este es el código de resultado que describe si la operación de ordenación fue exitosa. Será uno de los códigos de resultado descritos a continuación.

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto, el cual devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.

CÓDIGOS DE RESULTADO

Los resultados posibles de una solicitud de ordenación se enumeran a continuación. Consulte Net::LDAP::Constant para obtener una definición de cada uno.

LDAP_SUCCESS
LDAP_OPERATIONS_ERROR
LDAP_TIMELIMIT_EXCEEDED
LDAP_STRONG_AUTH_REQUIRED
LDAP_ADMIN_LIMIT_EXCEEDED
LDAP_NO_SUCH_ATTRIBUTE
LDAP_INAPPROPRIATE_MATCHING
LDAP_INSUFFICIENT_ACCESS
LDAP_BUSY
LDAP_UNWILLING_TO_PERFORM
LDAP_OTHER
