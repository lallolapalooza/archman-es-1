Net::Server::Proto::UNIX(3) Documentación de Perl aportada por el usuario Net::Server::Proto::UNIX(3)

NOMBRE

Net::Server::Proto::UNIX - Protocolo UNIX de Net::Server.

SINOPSIS

Ver Net::Server::Proto.

DESCRIPCIÓN

Módulo de protocolo para Net::Server. Este módulo implementa el tipo de socket UNIX SOCK_STREAM. Ver Net::Server::Proto.

Cualquier socket creado durante el inicio se cambiará de propietario al usuario y grupo especificados en los argumentos de inicio.

PARÁMETROS

Los siguientes parámetros pueden especificarse además de los parámetros normales de línea de comandos para un Net::Server. Ver Net::Server para más información sobre cómo leer argumentos.

tipo_unix
Puede ser SOCK_STREAM o SOCK_DGRAM (por defecto es SOCK_STREAM). Esto también se puede pasar en la línea de puerto (ver Net::Server::Proto).

Sin embargo, este método está obsoleto. Si deseas SOCK_STREAM, simplemente usa el proto UNIX sin otros argumentos. Si deseas SOCK_DGRAM, usa el nuevo proto UNIXDGRAM.

MÉTODOS

NS_ruta_unix/NS_tipo_unix
Además de los métodos NS_ estándar de las clases Net::Server::Proto, los tipos UNIX también tienen llamadas heredadas a NS_ruta_unix y NS_tipo_unix.

Desde la versión 2.000, NS_ruta_unix es simplemente un alias para NS_puerto. NS_tipo_unix ahora es redundante con NS_proto.

Estos métodos faltaron entre las versiones 2.000 y 2.003, pero se han devuelto como puentes heredados.

LISTA RÁPIDA DE PARÁMETROS

# uso más reciente
