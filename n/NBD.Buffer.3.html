Buffer persistente utilizado en llamadas AIO.

type t = (char, Stdlib.Bigarray.int8_unsigned_elt, Stdlib.Bigarray.c_layout) Stdlib.Bigarray.Array1.t

Un buffer que persiste entre llamadas, utilizado en NBD.aio_pread , NBD.aio_pwrite y similares.

En libnbd ≤ 1.18 este era un tipo implementado especialmente. Esto era ineficiente ya que no era posible la copia cero.

En libnbd ≥ 1.20 esto es solo un alias para un Bigarray , por lo que puedes usar funciones de Bigarray.Array1 directamente si lo prefieres. Esto también permite la copia cero.

Este tipo es compatible con las bibliotecas bigstring y bigstringaf.

val alloc : int -> t

Asigna un buffer no inicializado. El parámetro es el tamaño en bytes.

En libnbd ≥ 1.20 esto es un alias para Bigarray.Array1.create .

val to_bytes : t -> bytes

Copia el buffer a un objeto OCaml bytes.

En libnbd ≥ 1.20 puedes leer directamente del bigarray para evitar copias si lo deseas.

val to_string : t -> string

Igual que NBD.Buffer.to_bytes pero devuelve un string en su lugar.

val of_bytes : bytes -> t

Copia un objeto OCaml bytes a un buffer recién asignado.

En libnbd ≥ 1.20 puedes escribir directamente en el bigarray para evitar copias si lo deseas.

val of_string : string -> t

Igual que NBD.Buffer.of_bytes pero toma un string en su lugar.

val size : t -> int

Devuelve el tamaño del buffer.

En libnbd ≥ 1.20 esto es un alias para Bigarray.Array1.dim .
