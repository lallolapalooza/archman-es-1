NOMBRE

Net::DNS::RR::CAA - Registro de recurso DNS CAA

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN CAA flags tag value');

DESCRIPCIÓN

Clase para registros de recursos DNS de Autorización de Autoridad de Certificación (CAA).

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otros comportamientos impredecibles.

flags

$flags = $rr->flags;
$rr->flags( $flags );

Número entero sin signo de 8 bits que representa banderas booleanas.

critical
$rr->critical(1);
if ( $rr->critical ) {
        ...
}

Bandera crítica del emisor.

tag

$tag = $rr->tag;
$rr->tag( $tag );

Identificador de propiedad que puede contener los caracteres a-z, A-Z y 0-9. El campo de etiqueta no debe contener ningún otro carácter. La comparación de etiquetas no distingue entre mayúsculas y minúsculas.

value

$value = $rr->value;
$rr->value( $value );

Una secuencia de octetos que representa el valor de la propiedad. Los valores de propiedad se codifican como valores binarios y pueden emplear subformatos.
