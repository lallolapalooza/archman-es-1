Net::DBus::ASyncReply(3) Documentación de Perl contribuida por el usuario Net::DBus::ASyncReply(3)

NOMBRE

Net::DBus::ASyncReply - manejador de respuesta de método asíncrono

SINOPSIS

use Net::DBus::Annotation qw(:call);
my $object = $service->get_object("/org/example/systemMonitor");
# Lista los procesos y sigue trabajando hasta que
# se devuelva la lista.
my $asyncreply = $object->list_processes(dbus_call_async, "algunusuario");
while (!$asyncreply->is_ready) {
  ... haz algún trabajo en segundo plano...
}
my $processes = $asyncreply->get_result;

DESCRIPCIÓN

Este objeto proporciona un manejador para recibir respuestas de métodos asíncronos. Se genera un objeto de respuesta asíncrona al realizar una llamada remota al método con la anotación "dbus_call_async" establecida.

MÉTODOS

$asyncreply->discard_result;
Indica que el llamador ya no está interesado en recibir la respuesta y que debe ser descartada. Después de llamar a este método, este objeto no debe volver a usarse.
$asyncreply->wait_for_result;
Bloquea al llamador esperando la finalización de la respuesta asíncrona. Al regresar de este método, el resultado se puede obtener con el método "get_result".
my $boolean = $asyncreply->is_ready;
Devuelve un valor verdadero si la respuesta asíncrona ya está completa (o ha ocurrido un tiempo de espera). Cuando este método devuelve verdadero, el resultado se puede obtener con el método "get_result".
$asyncreply->set_notify($coderef);
Establece una función de notificación que se invocará cuando la respuesta asíncrona finalmente se complete. La devolución de llamada se invocará con un solo parámetro que es este objeto.
my @data = $asyncreply->get_result;
Recupera los datos asociados con la respuesta asíncrona. Si ocurrió un tiempo de espera, este método lanzará una excepción. Este método solo se puede llamar una vez que la respuesta esté completa, como lo indica el método "is_ready" que devuelve un valor verdadero. Después de llamar a este método, este objeto ya no debe usarse.
