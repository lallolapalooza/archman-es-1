NOMBRE

Net::IPv4Addr - Extensión de Perl para manipular direcciones IPv4.

SINOPSIS

use Net::IPv4Addr qw( :all );
my ($ip,$cidr) = ipv4_parse( "127.0.0.1/24" );
my ($ip,$cidr) = ipv4_parse( "192.168.100.10 / 255.255.255.0" );
my ($net,$msk) = ipv4_network( "192.168.100.30" );
my $broadcast  = ipv4_broadcast( "192.168.100.30/26" );
if ( ipv4_in_network( "192.168.100.0", $her_ip ) ) {
  print "¡Bienvenido!";
}
etc.

DESCRIPCIÓN

Net::IPv4Addr proporciona funciones para analizar direcciones IPv4 tanto en el formato tradicional de dirección/máscara de red como en el nuevo formato CIDR. También hay métodos para calcular la dirección de red y de broadcast, y también para comprobar si una dirección dada está en una red específica.

DIRECCIONES

Todas las funciones de Net::IPv4Addr aceptan direcciones en muchos formatos. El análisis es muy liberal.

Todas estas direcciones serían aceptadas:

127.0.0.1
192.168.001.010/24
192.168.10.10/255.255.255.0
192.168.30.10 / 21
10.0.0.0 / 255.0.0.0
255.255.0.0

Estas no lo serían:

272.135.234.0
192.168/16

La mayoría de las funciones aceptan la dirección y la máscara de red o la longitud de la máscara en el mismo valor escalar o como valores separados. Es decir, ya sea

my($ip,$masklength) = ipv4_parse($cidr_str);
my($ip,$masklength) = ipv4_parse($ip_str,$msk_str);

USO

No se exporta ninguna función por defecto. Utiliza la etiqueta ":all" para importarlas todas o importa explícitamente las que necesites.

FUNCIONES

ipv4_parse
my ($ip,$msklen) = ipv4_parse($cidr_str);
my $cidr = ipv4_parse($ip_str,$msk_str);
my ($ip) = ipv4_parse($ip_str,$msk_str);

Analiza una dirección IPv4 y, en contexto escalar, la dirección en formato CIDR y en contexto de array, la dirección y la longitud de la máscara.

Si los parámetros no contienen una máscara de red o una longitud de máscara, en contexto escalar solo se devuelve la dirección IPv4 y en contexto de array la longitud de la máscara es indefinida.

Si la función no puede analizar su entrada, genera un error (croaks). Captúrala usando "eval" si no te gusta.

ipv4_network
my $cidr = ipv4_network($ip_str);
my $cidr = ipv4_network($cidr_str);
my ($net,$msk) = ipv4_network( $net_str, $msk_str);

En contexto escalar, esta función devuelve la red en formato CIDR en la que se encuentra la dirección. En contexto de array, devuelve la dirección de red y su longitud de máscara como un array de dos elementos. Si la entrada es un host sin máscara de red o longitud de máscara, se asume la máscara de red por defecto.

De nuevo, la función genera un error si la entrada es inválida.

ipv4_broadcast
my ($broadcast) = ipv4_broadcast($ip_str);
my $broadcast   = ipv4_broadcast($ip_str,$msk_str);

Esta función devuelve la dirección de broadcast. Si la entrada no contiene una máscara de red o longitud de máscara, se asume la máscara de red por defecto.

Esta función genera un error si la entrada es inválida.

ipv4_network
my $cidr = ipv4_network($net_str);
my $cidr = ipv4_network($cidr_sstr);
my ($net,$msk) = ipv4_network( $ip_str, $mask_str);

En contexto escalar, esta función devuelve la red en formato CIDR en la que se encuentra la dirección. En contexto de array, devuelve la dirección de red y su longitud de máscara como un array de dos elementos. Si la entrada es un host sin máscara de red o longitud de máscara, se asume la máscara de red por defecto.

De nuevo, la función genera un error si la entrada es inválida.

ipv4_in_network
print "Sí" if ipv4_in_network( $cidr_str1, $cidr_str2);
print "Sí" if ipv4_in_network( $ip_str1, $mask_str1, $cidr_str2 );
print "Sí" if ipv4_in_network( $ip1, $mask1, $ip2, $msk2 );

Esta función comprueba si la segunda red está contenida en la primera y tiene la siguiente semántica:

Si net1 o net2 es una dirección mágica (0.0.0.0 o 255.255.255.255)
entonces esta función devuelve verdadero.
Si net1 es un host, net2 solo estará en la misma red si
es el mismo host.
Si net2 es un host, solo estará contenido en net1 si
forma parte de net1.
Si net2 es solo parte de net1 si está completamente contenido en
net1.

Captura entradas incorrectas con "eval" o de lo contrario.

ipv4_checkip
if ($ip = ipv4_checkip($str) ) {
    # Haz algo
}

Devuelve la dirección IPv4 en la cadena o undef si la entrada no contiene una dirección IPv4 válida.

ipv4_cidr2msk
my $netmask = ipv4_cidr2msk( $cidr );

Devuelve la máscara de red correspondiente a la longitud de máscara dada en la entrada. Como de costumbre, genera un error si no le gusta su entrada (en este caso, un número entre 0 y 32).

ipv4_msk2cidr
my $masklen = ipv4_msk2cidr( $msk );

Devuelve la longitud de máscara de la máscara de red dada en la entrada. Como de costumbre, genera un error si no le gusta su entrada.
