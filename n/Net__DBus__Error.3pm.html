NOMBRE

Net::DBus::Error - Detalles de error para la invocación de métodos remotos

SINOPSIS

package Music::Player::UnknownFormat;
use base qw(Net::DBus::Error);
# Define un tipo de error para un tipo de codificación de pista desconocido
# para un servicio de reproductor de música
sub new {
    my $proto = shift;
    my $class = ref($proto) || $proto;
    my $self = $class->SUPER::new(name => "org.example.music.UnknownFormat",
                                  message => "Formato de codificación de pista desconocido");
}
package Music::Player::Engine;
...recortado...
# Reproducir pistas de música mp3 u ogg, de lo contrario
# lanzar un error
sub play {
    my $self = shift;
    my $url = shift;
    if ($url =~ /\.(mp3|ogg)$/) {
        ...reproducir la pista
    } else {
       die Music::Player::UnknownFormat->new();
    }
}

DESCRIPCIÓN

Este objeto proporciona un manejo de errores fuertemente tipado. Normalmente, un servicio simplemente llamaría

die "algún texto del mensaje"

Al devolver la condición de error al cliente DBus que llama, el mensaje se asocia con un código de error genérico o "org.freedesktop.DBus.Failed". Si bien esto es suficiente para muchas aplicaciones, ocasionalmente es deseable poder capturar y manejar condiciones de error específicas. Para tales escenarios, el servicio debe crear subclases del objeto "Net::DBus::Error" que proporcionen un nombre de error personalizado. Este nombre de error se envía de vuelta al cliente en lugar del código genérico "org.freedesktop.DBus.Failed".

MÉTODOS

mi $error = Net::DBus::Error->new(name => $nombre_error, message => $descripción);
Crea un nuevo objeto de error cuyo nombre está dado por el parámetro "name", y el texto descriptivo largo es proporcionado por el parámetro "message". El parámetro "name" tiene ciertas reglas de formato a las que se debe adherir. Solo debe contener las letras 'a'-'Z', '0'-'9', '-' '_' y '.'. Debe haber al menos dos componentes separados por un '.'. Por ejemplo, un nombre válido es 'org.example.Music.UnknownFormat'.
$error->name
Devuelve el nombre del error DBus asociado con el objeto.
$error->message
Devuelve el texto/mensaje descriptivo asociado con la condición de error.
$error->stringify
Formatea el error como una cadena de manera adecuada para imprimir / registrar / mostrar al usuario, etc.
