Net::XMPP(3pm) Documentación de Perl aportada por el usuario Net::XMPP(3pm)

NOMBRE

Net::XMPP - Biblioteca Perl para XMPP

SINOPSIS

Net::XMPP proporciona al usuario de Perl acceso al Protocolo de Mensajería Instantánea y Presencia Extensible (XMPP).

Para más información sobre XMPP visite:

http://www.xmpp.org

DESCRIPCIÓN

Net::XMPP es una herramienta útil para cualquier script de Perl que desee utilizar el protocolo de mensajería instantánea XMPP. Aunque no es un cliente en sí mismo, proporciona todas las funciones de backend necesarias para hacer factibles y fáciles de usar un cliente CGI o un cliente de línea de comandos de Perl. Net::XMPP es un envoltorio para el resto de los paquetes oficiales Net::XMPP::xxxxxx.

Hay scripts de ejemplo en el directorio `example` que le proporcionan ejemplos de programas XMPP muy sencillos.

NOTA: El analizador que proporciona XML::Stream::Parser, como la mayoría de los analizadores de Perl, es síncrono. Si está en medio del análisis de un paquete y llama a una devolución de llamada definida por el usuario, el Analizador se bloquea hasta que su devolución de llamada finaliza. Esto significa que no puede estar operando en un paquete, enviar otro paquete y esperar una respuesta a ese paquete. Nunca le llegará. El hilo podría resolver esto, pero en el momento de escribir esto, los hilos en Perl aún no están a la altura. Este problema se revisará en el futuro.

EJEMPLOS

use Net::XMPP;
my $client = Net::XMPP::Client->new();

MÉTODOS

El módulo Net::XMPP no define ningún método que usted llame directamente en su código. En su lugar, instanciará objetos que llaman a funciones de este módulo para hacer el trabajo. Los tres objetos principales con los que trabajará son los módulos Message, Presence e IQ. Cada uno corresponde al equivalente de Jabber y le permite obtener y establecer todas las partes de esos paquetes.

Hay algunas funciones que son iguales en todos los objetos:

Funciones de recuperación

GetXML
Devuelve la cadena XML que representa los datos contenidos en el objeto. 
$xml  = $obj->GetXML();
GetChild
Devuelve una matriz de objetos Net::XMPP::Stanza que representan todos los stanzas en el objeto que están en un espacio de nombres. Si especifica un espacio de nombres, solo se devuelven los objetos stanza con ese XMLNS. 
@xObj = $obj->GetChild();
@xObj = $obj->GetChild("my:namespace");
GetTag
Devuelve el nombre de la etiqueta raíz del paquete.
GetTree
Devuelve el objeto XML::Stream::Node que contiene los datos. Consulte XML::Stream::Node para ver los métodos que puede llamar en este objeto.

Funciones de creación

NewChild
NewChild(namespace)
NewChild(namespace,tag)

Crea un nuevo objeto Net::XMPP::Stanza con el espacio de nombres especificado y la etiqueta raíz de lo que sea que diga el espacio de nombres que debería ser su etiqueta raíz. Opcionalmente, puede especificar otra etiqueta raíz si la predeterminada no es deseada, o si el espacio de nombres requiere que establezca una.

$xObj = $obj->NewChild("my:namespace");
$xObj = $obj->NewChild("my:namespace","foo");

es decir, <foo xmlns='my:namespace'...></foo>

InsertRawXML
InsertRawXML(string)

inserta la cadena especificada sin procesar en el paquete XML en el que llama a esto.

$message->InsertRawXML("<foo></foo>")
  <message...>...<foo></foo></message>
$x = $message->NewChild(..);
$x->InsertRawXML("test");
$query = $iq->GetChild(..);
$query->InsertRawXML("test");
ClearRawXML
ClearRawXML()

Elimina el XML sin procesar del paquete.

Funciones de eliminación

RemoveChild
RemoveChild()
RemoveChild(namespace)

Elimina todos los elementos hijos de espacio de nombres del objeto. Si se proporciona un espacio de nombres, solo se eliminan los hijos con ese espacio de nombres.

Funciones de prueba

DefinedChild
DefinedChild()
DefinedChild(namespace)

Devuelve 1 si hay algún stanza con espacio de nombres conocido en el paquete, 0 en caso contrario. Opcionalmente, puede especificar un espacio de nombres y determinar si hay algún stanza con ese espacio de nombres.

$test = $obj->DefinedChild();
$test = $obj->DefinedChild("my:namespace");

PAQUETES

Para más información sobre cada uno de estos paquetes, por favor consulte la página del manual para cada uno.

Net::XMPP::Client

Este paquete contiene el código necesario para comunicarse con un servidor XMPP: iniciar sesión, esperar mensajes, enviar mensajes y cerrar sesión. Utiliza XML::Stream para leer el flujo del servidor y, basándose en el tipo de etiqueta que encuentra, llama a una función para manejar la etiqueta.

Net::XMPP::Protocol

Una colección de funciones de alto nivel que Client utiliza para hacerles la vida más fácil. Estos métodos son heredados por Client.

Net::XMPP::JID

Las ID de XMPP constan de tres partes: ID de usuario, servidor y recurso. Este módulo le da acceso a esos componentes sin tener que analizar la cadena usted mismo.

Net::XMPP::Message

Todo lo necesario para crear y leer un <message/> recibido del servidor.

Net::XMPP::Presence

Todo lo necesario para crear y leer un <presence/> recibido del servidor.

Net::XMPP::IQ

IQ es un envoltorio para una serie de módulos que proporcionan soporte para los diversos espacios de nombres de Info/Query que XMPP reconoce.

Net::XMPP::Stanza

Este módulo representa un stanza con espacio de nombres que se utiliza para extender un <message/>, <presence/> y <iq/>.

La página del manual de Net::XMPP::Stanza contiene una lista de todos los espacios de nombres admitidos y los métodos que admiten los objetos que representan esos espacios de nombres.

Net::XMPP::Namespaces

XMPP permite que cualquier stanza sea extendida por cualquier bit de XML. Este módulo contiene todos los elementos internos para definir las extensiones basadas en XMPP definidas por el IETF. La documentación de este módulo explica más sobre cómo agregar su propio espacio de nombres personalizado y hacer que sea compatible.
