Net::LDAP::Control::Relax(3) Documentación de Perl aportada por el usuario Net::LDAP::Control::Relax(3)

NOMBRE

Net::LDAP::Control::Relax - objeto de control de relajación LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::Relax;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$relax = Net::LDAP::Control::Relax->new();
$msg = $ldap->modify( 'dc=sub,dc=mydomain,dc=eg",
                      changes => [
                        replace => { modifyTimestamp => '19700101000000Z' } ],
                      control  => [ $relax ] );
die "error: ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPCIÓN

"Net::LDAP::Control::Relax" proporciona una interfaz para la creación y manipulación de objetos que representan el control "Relax" según se describe en draft-zeilenga-ldap-relax-03.txt

El control, que no tiene un control de respuesta correspondiente, es apropiado para todas las solicitudes de actualización LDAP, incluidas add, delete, modify y moddn.

La presencia del control Relax en una solicitud de actualización LDAP indica que el servidor relaja temporalmente las restricciones del modelo X.500 durante la ejecución de la actualización del directorio.

No tiene valor y su criticidad siempre se establece en "TRUE".

ARGUMENTOS DEL CONSTRUCTOR

Dado que el control "Relax" no tiene valores, solo se admiten los argumentos del constructor descritos en Net::LDAP::Control.

MÉTODOS

Como no hay valores adicionales en el control, solo los métodos en Net::LDAP::Control están disponibles para los objetos de "Net::LDAP::Control::Relax".
