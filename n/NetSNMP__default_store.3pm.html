NetSNMP__default_store(3pm)

Paquete: net-snmp

Licencias: BSD

default_store(3) Documentación de Perl contribuida por el usuario default_store(3)

NOMBRE

NetSNMP::default_store - Extensión de Perl para el almacenamiento genérico de datos globales de Net-SNMP

SINOPSIS

use NetSNMP::default_store qw(:all);
$port = netsnmp_ds_get_int(NETSNMP_DS_LIBRARY_ID, DS_LIB_DEFAULT_PORT);
netsnmp_ds_set_int(NETSNMP_DS_LIBRARY_ID, DS_LIB_DEFAULT_PORT, 161);

DESCRIPCIÓN

Este módulo es un envoltorio alrededor de las rutinas del almacenamiento predeterminado de net-snmp. Consulte la página del manual de net-snmp default_store para obtener detalles sobre lo que hacen las diversas funciones y los valores que se pueden establecer/recuperar.
