NOMBRE

Net::DBus::Binding::Message::Signal - un mensaje que codifica una señal

SINOPSIS

use Net::DBus::Binding::Message::Signal;
my $signal = Net::DBus::Binding::Message::Signal->new(
    object_path => "/org/example/myobject",
    interface => "org.example.myobject",
    signal_name => "foo_changed");
$connection->send($signal);

DESCRIPCIÓN

Este módulo forma parte de las API de bajo nivel de enlace DBus, y no debe ser utilizado por código de aplicación. No se garantizan la estabilidad de las API bajo el espacio de nombres "Net::DBus::Binding::" entre versiones.

Este módulo proporciona un constructor de conveniencia para crear un mensaje que representa una señal.

MÉTODOS

my $signal = Net::DBus::Binding::Message::Signal->new( object_path => $path, interface => $interface, signal_name => $name);
Crea un nuevo mensaje, representando una señal que será emitida por el objeto ubicado en la ruta dada por el parámetro "object_path". El nombre de la señal se proporciona mediante el parámetro "signal_name", y está limitado a la interfaz dada por el parámetro "interface".
