NOMBRE

Net::DBus::Binding::Iterator - Lectura y escritura de parámetros de mensajes

SINOPSIS

Creación de un nuevo mensaje

my $msg = new Net::DBus::Binding::Message::Signal;
my $iterator = $msg->iterator;
$iterator->append_boolean(1);
$iterator->append_byte(123);

Lectura desde un mensaje

my $msg = ...obtenerlo de algún sitio...
my $iter = $msg->iterator();
my $i = 0;
while ($iter->has_next()) {
  $iter->next();
  $i++;
  if ($i == 1) {
     my $val = $iter->get_boolean();
  } elsif ($i == 2) {
     my $val = $iter->get_byte();
  }
}

DESCRIPCIÓN

Proporciona un iterador para leer o escribir campos de mensajes. Este módulo proporciona una API de Perl para acceder a los métodos dbus_message_iter_XXX de la API C. Los tipos de matriz y diccionario aún no se soportan, y hay errores en el soporte de Quad (es decir, ¡siempre devuelve -1!).

Obtiene el valor actual apuntado por este iterador. Si se proporciona el parámetro opcional $tipo, el tipo de cable se comparará con el tipo deseado y se mostrará una advertencia si difieren. El valor de $tipo debe ser una de las constantes "Net::DBus::Binding::Message::TYPE*".
mi $hashref = $iter->get_dict()

$iter->append($valor)
$iter->append($valor, $tipo)
Añade un valor al mensaje asociado con este iterador. El valor se serializa al formato de cable, según las siguientes reglas.

Si $valor es una instancia de Net::DBus::Binding::Value, se utiliza el tipo de datos incrustado.

Si se proporciona el parámetro $tipo, este representa el tipo de datos. El tipo debe ser una de las constantes "Net::DBus::Binding::Message::TYPE_*".

De lo contrario, el tipo de datos elegido es una cadena, diccionario o matriz según los tipos de datos de Perl ESCALAR, HASH o ARRAY.

mi $tipo = $iter->guess_type($valor)
Hace una suposición lo más acertada posible sobre el tipo de datos en el cable para serializar $valor. Si el valor es una referencia de hash, se devuelve el tipo diccionario; si el valor es una referencia de matriz, se devuelve el tipo matriz; de lo contrario, se devuelve el tipo cadena.
mi $sig = $iter->format_signature($tipo)
Dado una representación de tipo de datos, construye una cadena de firma correspondiente.
$iter->append_array($valor, $tipo)
Añade una matriz de valores al mensaje. El parámetro $valor debe ser una referencia de matriz, cuyos elementos tengan todos el mismo tipo de datos especificado por el parámetro $tipo.
$iter->append_struct($valor, $tipo)
Añade una estructura al mensaje. El parámetro $valor debe ser una referencia de matriz, cuyos elementos correspondan a los miembros de la estructura. El parámetro $tipo codifica el tipo de cada miembro de la estructura.
$iter->append_dict($valor, $tipo)
Añade un diccionario al mensaje. El parámetro $valor debe ser una referencia de hash. El parámetro $tipo codifica el tipo de la clave y el valor del hash.
$iter->append_variant($valor)
Añade un valor al mensaje, codificado como un tipo variante. El $valor puede ser de cualquier tipo, sin embargo, la variante se codificará como una cadena, un diccionario o una matriz según las reglas del método "guess_type".

Recupera el código de tipo del valor al que apunta este iterador. El código devuelto corresponderá a una de las constantes "Net::DBus::Binding::Message::TYPE_*"

Net::DBus::Binding::Iterator(3pm)

NAME

Net::DBus::Binding::Iterator ‐ Iterator for a D-Bus message

SYNOPSIS


        use Net::DBus::Binding::Iterator;

        my $iter = Net::DBus::Binding::Iterator->new($message);
        while ($iter->has_next()) {
            my $value = $iter->get_next();
            # ...
        }

DESCRIPTION

This class provides an iterator to walk through the fields of a Net::DBus::Binding::Message(3pm). It is used to access the fields within a D-Bus message.

METHODS

new($message)
Constructor. Takes a Net::DBus::Binding::Message(3pm) object.
has_next()
Returns true if there are more elements in the iterator.
get_next()
Retrieves the next element from the iterator. The type of the returned value depends on the D-Bus type of the element.
get_element_type()
If the iterator points to an array, retrieves the type code of array elements. The returned code will correspond to one of the constants "Net::DBus::Binding::Message::TYPE_*"
