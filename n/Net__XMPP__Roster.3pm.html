NOMBRE

Net::XMPP::Roster - Objeto de Lista de Contactos XMPP

SINOPSIS

Net::XMPP::Roster es un módulo que proporciona a los desarrolladores una interfaz fácil para una lista de contactos XMPP. Ofrece funciones de alto nivel para consultar, actualizar y gestionar la lista de contactos de un usuario.

DESCRIPCIÓN

El objeto Roster busca proporcionar una API fácil de usar para interactuar con la lista de contactos de un usuario. Cuando se instancia, se registra automáticamente con la conexión para recibir los paquetes correctos y poder rastrear todas las actualizaciones de la lista de contactos y los paquetes de presencia.

Funciones Básicas

my $Cliente = Net::XMPP::Client->new(...);
my $Roster = Net::XMPP::Roster->new(connection=>$Cliente);
  o
my $Roster = $Cliente->Roster();
$Roster->clear();
if ($Roster->exists('bob@jabber.org')) { ... }
if ($Roster->exists(Net::XMPP::JID)) { ... }
if ($Roster->groupExists("Amigos")) { ... }
my @grupos = $Roster->groups();
my @jids    = $Roster->jids();
my @amigos = $Roster->jids("grupo","Amigos");
my @sin_grupo = $Roster->jids("nogroup");
if ($Roster->online('bob@jabber.org')) { ... }
if ($Roster->online(Net::XMPP::JID)) { ... }
my %hash = $Roster->query('bob@jabber.org');
my %hash = $Roster->query(Net::XMPP::JID);
my $nombre = $Roster->query('bob@jabber.org',"nombre");
my $preg  = $Roster->query(Net::XMPP::JID,"preg");
my $recurso = $Roster->resource('bob@jabber.org');
my $recurso = $Roster->resource(Net::XMPP::JID);
my %hash = $Roster->resourceQuery('bob@jabber.org',"Casa");
my %hash = $Roster->resourceQuery(Net::XMPP::JID,"Club");
my $show   = $Roster->resourceQuery('bob@jabber.org',"Casa","show");
my $estado = $Roster->resourceQuery(Net::XMPP::JID,"Trabajo","status");
my @recurso = $Roster->resources('bob@jabber.org');
my @recurso = $Roster->resources(Net::XMPP::JID);
$Roster->resourceStore('bob@jabber.org',"Casa","gpgkey",clave);
$Roster->resourceStore(Net::XMPP::JID,"conectado","2004/04/07 ...");
$Roster->store('bob@jabber.org',"avatar",avatar);
$Roster->store(Net::XMPP::JID,"nombre_a_mostrar","Bob");

Funciones Avanzadas

Estas funciones solo son necesarias si desea controlar manualmente la lista de contactos.

$Roster->add('bob@jabber.org',
             nombre=>"Bob",
             grupos=>["Amigos"]
            );
$Roster->add(Net::XMPP::JID);
$Roster->addResource('bob@jabber.org',
                     "Casa",
                     show=>"dnd",
                     status=>"Trabajando"
                    );
$Roster->addResource(Net::XMPP::JID,"Trabajo");
$Roster->remove('bob@jabber.org');
$Roster->remove(Net::XMPP::JID);
$Roster->removeResource('bob@jabber.org',"Casa");
$Roster->removeResource(Net::XMPP::JID,"Trabajo");
$Roster->handler(Net::XMPP::IQ);
$Roster->handler(Net::XMPP::Presence);

MÉTODOS

Funciones Básicas

new
new(connection=>objeto)

Esto crea e inicializa el objeto Roster. El objeto de conexión es necesario para que el Roster pueda interactuar con el objeto de conexión principal. Debe ser un objeto que herede de Net::XMPP::Connection.

clear
clear()

elimina todo de la base de datos.

exists
exists(jid)

devuelve 1 si el JID existe en la base de datos, indefinido en caso contrario. El jid puede ser una cadena o un objeto Net::XMPP::JID.

groupExists
groupExists(grupo)

devuelve 1 si el grupo existe en la base de datos, indefinido en caso contrario.

groups
groups()

Devuelve una lista de todos los grupos de la lista de contactos.

jids
jids([tipo, [grupo]])

devuelve una lista de todos los JIDs coincidentes. Los tipos válidos son:

all     - devuelve todos los JIDs de la lista de contactos. (por defecto)
nogroup - devuelve todos los JIDs que no están en un grupo de la lista de contactos.
group   - devuelve todos los JIDs del grupo especificado en la lista de contactos.
online
online(jid)

devuelve 1 si el JID está en línea, indefinido en caso contrario. El jid puede ser una cadena o un objeto Net::XMPP::JID.

query
query(jid, [clave])

devuelve un hash que representa todos los datos en la DB para este JID. El jid puede ser una cadena o un objeto Net::XMPP::JID. Si especifica una clave, solo se devuelve el valor para esa clave.

resource
resource(jid)

devuelve la cadena que representa el recurso con la mayor prioridad para el JID. El jid puede ser una cadena o un objeto Net::XMPP::JID.

resourceQuery
resourceQuery(jid,     
              recurso,
              [clave])

devuelve un hash que representa todos los datos de la DB para el recurso de este JID. El jid puede ser una cadena o un objeto Net::XMPP::JID. Si especifica una clave, solo se devuelve el valor para esa clave.

resources
resources(jid)

devuelve la lista de recursos para el JID en orden de mayor a menor prioridad. El jid puede ser una cadena o un objeto Net::XMPP::JID.

resourceStore
resourceStore(jid,     
              recurso,
              clave,     
              valor)

almacena el valor especificado en la DB bajo la clave especificada para el recurso de este JID. El jid puede ser una cadena o un objeto Net::XMPP::JID.

store
store(jid, clave, valor)

almacena el valor especificado en la DB bajo la clave especificada para este JID. El jid puede ser una cadena o un objeto Net::XMPP::JID.

Funciones Avanzadas

add(jid, - Añade manualmente el JID a la lista de contactos con la
preg=>cadena, configuración de elemento de lista de contactos especificada. Esto no
grupos=>ref_array, maneja la suscripción a otros usuarios, solo
nombre=>cadena, la manipulación del objeto Roster. El jid
suscripcion=>cadena) puede ser una cadena o un Net::XMPP::JID.

addResource(jid, - Añade manualmente el recurso al JID en la
recurso, lista de contactos con la configuración de presencia especificada.
prioridad=>entero, Esto no maneja la suscripción a otros
show=>cadena, usuarios, solo la manipulación del objeto Roster.
status=>cadena) El jid puede ser una cadena o un
Net::XMPP::JID.

remove(jid) - Elimina toda referencia al JID del objeto Roster.
El jid puede ser una cadena o un Net::XMPP::JID.

removeResource(jid, - Elimina el recurso del jid en el
recurso) objeto Roster. El jid puede ser una cadena
o un Net::XMPP::JID.

handler(paquete) - Toma un paquete Net::XMPP::IQ o Net::XMPP::Presence
y lo analiza según las reglas del objeto Roster. Tenga en cuenta que solo
desperdiciará tiempo de CPU si pasa IQs o Presencias que no estén
relacionados con la lista de contactos.
