NOMBRE

Net::DNS::RR::AFSDB - Registro de recursos AFSDB de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre AFSDB subtipo nombre_host');

DESCRIPCIÓN

Clase para registros de recursos AFS Data Base (AFSDB) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, ya que podría provocar la terminación del programa u otros comportamientos impredecibles.

subtipo

$subtipo = $rr->subtipo;
$rr->subtipo( $subtipo );

Un entero de 16 bits que indica el servicio ofrecido por el host listado.

nombre_host

$nombre_host = $rr->nombre_host;
$rr->nombre_host( $nombre_host );

El campo `nombre_host` es un nombre de dominio de un host que tiene un servidor para la celda nombrada por el nombre propietario del RR.
