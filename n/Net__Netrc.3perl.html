Net::Netrc(3perl) Manual de Perl Net::Netrc(3perl)

NOMBRE

Net::Netrc - interfaz OO para el archivo .netrc usado por el programa ftp

SINTAXIS

use Net::Netrc;
$mach = Net::Netrc->lookup('some.machine');
$login = $mach->login;
($login, $password, $account) = $mach->lpa;

DESCRIPCIÓN

"Net::Netrc" es una clase que implementa una interfaz simple para el archivo .netrc utilizado por el programa ftp.

"Net::Netrc" también implementa verificaciones de seguridad similares a las del programa ftp; estas verificaciones son, primero, que el archivo .netrc debe ser propiedad del usuario y, segundo, que los permisos del propietario solo deben permitir lectura y escritura al propietario. Si estas condiciones no se cumplen, se emite una advertencia y el archivo .netrc no se lee.

El archivo .netrc

El archivo .netrc contiene información de inicio de sesión y autenticación utilizada por el proceso de inicio de sesión automático. Se encuentra en el directorio del usuario. Se reconocen los siguientes tokens; pueden estar separados por espacios, tabulaciones o saltos de línea:

nombre de máquina
Identifica una máquina remota. El proceso de inicio de sesión automático busca en el archivo .netrc un token de máquina que coincida con el nombre de máquina especificado. Una vez que se encuentra una coincidencia, se procesan los siguientes tokens .netrc, deteniéndose cuando se alcanza el final del archivo o se encuentra otro nombre de máquina o un token predeterminado.
default
Este es el mismo que el nombre de máquina, excepto que el valor predeterminado coincide con cualquier nombre. Solo puede haber un token predeterminado, y debe estar después de todos los tokens de máquina. Esto se usa típicamente como:
default login anonymous password user@site

lo que permite al usuario un inicio de sesión anónimo automático en máquinas no especificadas en .netrc.

nombre de usuario
Identifica a un usuario en la máquina remota. Si este token está presente, el proceso de inicio de sesión automático iniciará una sesión utilizando el nombre especificado.
cadena de contraseña
Proporciona una contraseña. Si este token está presente, el proceso de inicio de sesión automático proporcionará la cadena especificada si el servidor remoto requiere una contraseña durante el proceso de inicio de sesión.
cadena de cuenta
Proporciona una contraseña adicional. Si este token está presente, el proceso de inicio de sesión automático proporcionará la cadena especificada si el servidor remoto requiere una contraseña adicional.
nombre de macro
Define una macro. "Net::Netrc" solo analiza este campo para ser compatible con ftp.

Métodos de Clase

El constructor para un objeto "Net::Netrc" no se llama new, ya que en realidad no crea un objeto nuevo. En su lugar, se llama lookup, ya que eso es lo que hace.

"lookup($machine[, $login])"
Busca y devuelve una referencia al registro correspondiente a $machine. Si se especifica $login, el registro devuelto tendrá este inicio de sesión. Si $login no se especifica, se devuelve el primer registro de .netrc para $machine. Si no se encuentra un registro correspondiente y existe un registro predeterminado, se devuelve una referencia al registro predeterminado.

Si no se encuentra un registro correspondiente y no hay un registro predeterminado definido, o no se encuentra un archivo .netrc, se devuelve undef.

Métodos de Objeto

login()
Devuelve el identificador de inicio de sesión para el registro Net::Netrc
password()
Devuelve la contraseña para el registro Net::Netrc
account()
Devuelve la información de cuenta para el registro Net::Netrc
lpa()
Devuelve una lista de información de inicio de sesión, contraseña y cuenta para el registro Net::Netrc
