NS_GET_USERNS(2const) NS_GET_USERNS(2const)

NOMBRE

NS_GET_USERNS, NS_GET_PARENT - descubrimiento de relaciones de namespaces

SINOPSIS

#include <linux/nsfs.h>  /* Definición de las constantes NS_GET_* */
                                #include <sys/ioctl.h>
int ioctl(int fd, unsigned long op);

DESCRIPCIÓN

Las siguientes operaciones ioctl(2) se proporcionan para permitir el descubrimiento de relaciones de namespaces (ver user_namespaces(7) y pid_namespaces(7)).

En cada caso, fd se refiere a un archivo /proc/pid/ns/*. Ambas operaciones devuelven un nuevo descriptor de archivo en caso de éxito.

NS_GET_USERNS
Devuelve un descriptor de archivo que se refiere al namespace de usuario al que se refiere el namespace indicado por fd. Si el namespace al que se refiere fd es un namespace de usuario, entonces esta operación simplemente devuelve un descriptor de archivo para el mismo namespace. Esto es útil para obtener un descriptor de archivo para el namespace de usuario de un proceso específico.
NS_GET_PARENT
Devuelve un descriptor de archivo que se refiere al namespace padre del namespace indicado por fd. Esta operación es válida solo para namespaces jerárquicos (es decir, namespaces PID y de usuario). Para namespaces de usuario, NS_GET_PARENT es equivalente a NS_GET_USERNS.

El nuevo descriptor de archivo devuelto por estas operaciones se abre con las flags O_RDONLY y O_CLOEXEC (cerrar en ejecución; ver fcntl(2)).

Aplicando fstat(2) al descriptor de archivo devuelto, se obtiene una estructura stat cuya st_dev (dispositivo residente) y st_ino (número de inodo) se utilizan conjuntamente para identificar el namespace de usuario/padre. Este número de inodo puede coincidir con el número de inodo de otro archivo /proc/pid/ns/{pid,user} para determinar si es el namespace de usuario/padre.

VALOR DE RETORNO

Un descriptor de archivo se devuelve con éxito. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EPERM
El namespace solicitado está fuera del ámbito del namespace del llamante. Esto puede ocurrir, por ejemplo, si el namespace de usuario al que se refiere es un ancestro del namespace del llamante actual. También puede ocurrir al intentar obtener el padre del namespace de usuario inicial o el namespace PID inicial.
ENOTTY
La operación no está soportada en este kernel.

Adicionalmente, la operación NS_GET_PARENT puede fallar con el siguiente error:

EINVAL
fd se refiere a un namespace no jerárquico.

ESTÁNDARES

Linux.

HISTORIA

NS_GET_USERNS
Linux 4.9.
NS_GET_PARENT
Linux 4.9.

EJEMPLOS

El siguiente ejemplo usa las operaciones ioctl(2) descritas anteriormente para realizar un simple descubrimiento de relaciones de namespaces. Las siguientes sesiones de shell muestran varios ejemplos de uso de este programa.

Intentar obtener el padre del namespace de usuario inicial falla, ya que no tiene padre:

$ ./ns_show /proc/self/ns/user p

Crear un proceso que esté en un namespace de usuario nuevo y UTS, y mostrar que el nuevo namespace UTS está asociado con el nuevo namespace de usuario:

$ unshare -Uu sleep 1000 &

$ ./ns_show /proc/23235/ns/uts u

Luego, mostrar que el padre del nuevo namespace de usuario en el ejemplo anterior es el namespace de usuario inicial:

$ readlink /proc/self/ns/user

Iniciar un shell en un nuevo namespace de usuario y mostrar que desde dentro de este shell no se puede descubrir el namespace de usuario padre. De manera similar, el namespace UTS (asociado con el namespace de usuario inicial) no puede ser descubierto.

$ PS1="sh2$ " unshare -U bash
$ ./ns_show /proc/self/ns/user p
$ ./ns_show /proc/self/ns/uts u

Código fuente del programa

/* ns_show.c
           Con licencia bajo la Licencia Pública General de GNU v2 o posterior.
       */
#include <errno.h>
#include <fcntl.h>
#include <linux/nsfs.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/ioctl.h>
#include <sys/stat.h>
#include <sys/sysmacros.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int          fd, userns_fd, parent_fd;
    struct stat  sb;
    if (argc < 2) {
        fprintf(stderr, "Uso: %s /proc/[pid]/ns/[file] [p|u]\n", argv[0]);
        fprintf(stderr, "\nMuestra el resultado de una o ambas de las operaciones NS_GET_USERNS (u) o NS_GET_PARENT (p) para el archivo especificado en /proc/[pid]/ns/[file]. Si ninguno de 'p' ni 'u' se especifica, el valor por defecto es NS_GET_USERNS.\n");
        exit(EXIT_FAILURE);
    }
    /* Obtener un descriptor de archivo para el archivo 'ns' especificado en argv[1]. */
    fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /* Obtener un descriptor de archivo para el namespace de usuario y luego obtener y mostrar el número de inodo de ese namespace. */
    if (argc < 3 || strchr(argv[2], 'u')) {
        userns_fd = ioctl(fd, NS_GET_USERNS);
        if (userns_fd == -1) {
            if (errno == EPERM)
                printf("El namespace de usuario al que se refiere está fuera del ámbito de tu namespace\n");
            else
                perror("ioctl-NS_GET_USERNS");
            exit(EXIT_FAILURE);
        }
        if (fstat(userns_fd, &sb) == -1) {
            perror("fstat-userns");
            exit(EXIT_FAILURE);
        }
        printf("El número de dispositivo/inodo del namespace de usuario es: [%x,%x] / %ju\n", major(sb.st_dev), minor(sb.st_dev), (uintmax_t) sb.st_ino);
        close(userns_fd);
    }
    /* Obtener un descriptor de archivo para el namespace padre y luego obtener y mostrar el número de inodo de ese namespace. */
    if (argc > 2 && strchr(argv[2], 'p')) {
        parent_fd = ioctl(fd, NS_GET_PARENT);
        if (parent_fd == -1) {
            if (errno == EINVAL)
                printf("No se puede obtener el namespace padre de un namespace no jerárquico\n");
            else if (errno == EPERM)
                printf("El namespace padre está fuera del ámbito de tu namespace\n");
            else
                perror("ioctl-NS_GET_PARENT");
            exit(EXIT_FAILURE);
        }
        if (fstat(parent_fd, &sb) == -1) {
            perror("fstat-parentns");
            exit(EXIT_FAILURE);
        }
        printf("El número de dispositivo/inodo del namespace padre es: [%x,%x] / %ju\n", major(sb.st_dev), minor(sb.st_dev), (uintmax_t) sb.st_ino);
        close(parent_fd);
    }
    exit(EXIT_SUCCESS);
}
