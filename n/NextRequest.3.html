ARGUMENTOS

DESCRIPCIÓN

La macro AllPlanes devuelve un valor con todos los bits establecidos a 1, adecuado para ser usado como argumento de plano en un procedimiento.

La macro BlackPixel devuelve el valor del píxel negro para la pantalla especificada.

La macro WhitePixel devuelve el valor del píxel blanco para la pantalla especificada.

La macro ConnectionNumber devuelve el número de conexión para el display especificado.

La macro DefaultColormap devuelve el ID del mapa de colores predeterminado para la asignación en la pantalla especificada.

La macro DefaultDepth devuelve la profundidad (número de planos) de la ventana raíz predeterminada para la pantalla especificada.

La función XListDepths devuelve el array de profundidades disponibles en la pantalla especificada. Si el número de pantalla especificado es válido y hay memoria suficiente para el array, XListDepths establece count_return al número de profundidades disponibles. De lo contrario, no establece count_return y devuelve NULL. Para liberar la memoria del array de profundidades, use XFree.

La macro DefaultGC devuelve el GC predeterminado para la ventana raíz de la pantalla especificada.

La macro DefaultRootWindow devuelve la ventana raíz de la pantalla predeterminada.

La macro DefaultScreenOfDisplay devuelve la pantalla del display especificado.

La macro DefaultScreen devuelve el número de pantalla predeterminado al que se hace referencia en la llamada a XOpenDisplay.

La macro DefaultVisual devuelve el tipo visual predeterminado para la pantalla especificada.

La macro DisplayCells devuelve el número de entradas en el mapa de colores predeterminado.

La macro DisplayPlanes devuelve la profundidad de la ventana raíz de la pantalla especificada.

La macro DisplayString devuelve la cadena que se pasó a XOpenDisplay cuando se abrió el display actual.

La función XMaxRequestSize devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) soportado por el servidor sin usar un enfoque de protocolo extendido. Las solicitudes individuales al servidor no pueden ser de mayor tamaño que este tamaño, a menos que el servidor soporte un enfoque de protocolo extendido. El protocolo garantiza que el tamaño no sea menor que 4096 unidades (16384 bytes). Xlib divide automáticamente los datos en múltiples solicitudes de protocolo cuando sea necesario para las siguientes funciones: XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles y XPutImage.

La función XExtendedMaxRequestSize devuelve cero si el display especificado no soporta un enfoque de protocolo extendido, de lo contrario devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) soportado por el servidor usando el enfoque de protocolo extendido. Las funciones de Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangles y XSetRegion usarán el enfoque de protocolo extendido si el servidor lo soporta. El uso del enfoque de protocolo extendido en otras funciones de Xlib (por ejemplo, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles y XPutImage) está permitido pero no es obligatorio; una implementación de Xlib puede optar por dividir los datos en múltiples solicitudes más pequeñas.

La macro LastKnownRequestProcessed extrae el número de serie completo de la solicitud más reciente que fue procesada por el servidor Xlib.

La macro NextRequest extrae el número de serie completo que se utilizará para la siguiente solicitud.

La macro ProtocolVersion devuelve el número de versión principal (11) del protocolo X asociado con el display conectado.

La macro ProtocolRevision devuelve el número de revisión de la versión secundaria del servidor X.

La macro QLength devuelve la longitud de la cola de eventos para el display conectado.

La macro RootWindow devuelve la ventana raíz.

La macro ScreenCount devuelve el número de pantallas disponibles.

La macro ScreenOfDisplay devuelve un puntero a la pantalla del display especificado.

La macro ServerVendor devuelve un puntero a una cadena terminada en null que proporciona una identificación del propietario de la implementación del servidor X.

La macro VendorRelease devuelve un número relacionado con la versión de lanzamiento del servidor X.
