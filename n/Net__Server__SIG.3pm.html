Net::Server::SIG(3) Documentación de Perl aportada por el usuario Net::Server::SIG(3)

NOMBRE

Net::Server::SIG - adpf - Manejo de señales más seguro

SINOPSIS

use Net::Server::SIG qw(register_sig check_sigs);
use IO::Select ();
use POSIX qw(WNOHANG);
my $select = IO::Select->new();
register_sig(PIPE => 'IGNORE',
             HUP  => 'DEFAULT',
             USR1 => sub { print "Recibí una señal SIG $_[0]\n"; },
             USR2 => sub { print "Recibí una señal SIG $_[0]\n"; },
             CHLD => sub { 1 while waitpid(-1, WNOHANG) > 0; },
             );
# añadir algunos manejadores al select
$select->add(\*STDIN);
# bucle infinito intentando mantenerse vivo
while (1) {
    # hacer un timeout para ver si se nos pasaron señales
    # mientras procesábamos otra señal
    my @fh = $select->can_read(10);
    my $key;
    my $val;
    # este es el manejador para seguro (funciona bajo inseguro también)
    if (check_sigs()) {
      # o my @sigs = check_sigs();
      next unless @fh;
    }
    my $handle = $fh[@fh];
    # hacer algo con el manejador
}

DESCRIPCIÓN

Las señales antes de Perl 5.7 eran inseguras. Desde entonces, las señales se han implementado con un algoritmo más seguro. Net::Server::SIG proporciona compatibilidad hacia atrás, mientras sigue funcionando de forma fiable con versiones más recientes.

Utilizando una propiedad de la función select(), Net::Server::SIG intenta corregir el problema de inseguridad. Si un proceso está bloqueado en select(), cualquier señal interrumpirá select. Utilizando este concepto, Net::Server::SIG realiza el menor trabajo posible (cambiando un bit de 0 a 1). Y depende del procesamiento real de las señales para que tenga lugar inmediatamente después de la llamada a select a través de la función "check_sigs". Consulte el ejemplo mostrado arriba y también el script sigtest.pl ubicado en el directorio de ejemplos de esta distribución.

FUNCIONES

"register_sig($SIG => \&code_ref)"
Toma pares clave/valor donde la clave es el nombre de la señal y el argumento es una referencia de código, o las palabras 'DEFAULT' o 'IGNORE'. La función register_sig debe usarse junto con check_sigs y con una llamada a la función select() bloqueante; de lo contrario, observará que la señal registrada desaparece misteriosamente.
unregister_sig($SIG)
Toma el nombre de una señal como argumento. Llama a register_sig con este nombre de señal y 'DEFAULT' como argumentos (igual que register_sig(SIG,'DEFAULT')
check_sigs()
Comprueba si se han producido señales registradas. Si es así, ejecutará el código registrado para esa señal. El valor de retorno es una matriz que contiene cualquier nombre de SEÑAL que haya ocurrido.
sig_is_registered($SIG)
Toma un nombre de señal y devuelve cualquier referencia de código registrada para esa señal.
