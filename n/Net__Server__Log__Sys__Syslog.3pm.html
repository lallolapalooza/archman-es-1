NOMBRE

Net::Server::Log::Sys::Syslog - registrar a través de Syslog

SINOPSIS

use base qw(Net::Server::PreFork);
__PACKAGE__->run(
    log_file => 'Sys::Syslog',
    syslog_ident => 'myapp',
);

DESCRIPCIÓN

Este módulo proporciona el registro Sys::Syslog para el sistema Net::Server.

CONFIGURACIÓN

log_file
Para empezar a usar el registro Sys::Syslog, simplemente establezca el parámetro de configuración log_file de Net::Server a "Sys::Syslog".

Si se utiliza el nombre mágico "Sys::Syslog", todo el registro se realizará a través del módulo Sys::Syslog. Si se usa syslog, los parámetros "syslog_logsock", "syslog_ident", y "syslog_logopt", y "syslog_facility" también pueden ser definidos.

syslog_logsock
Solo disponible si "log_file" es igual a "Sys::Syslog". Puede ser unix, inet, native, console, stream, udp, o tcp, o un arrayref de los tipos a intentar. El valor predeterminado es "unix" si la versión de Sys::Syslog es < 0.15; de lo contrario, el valor predeterminado es no llamar a setlogsock.

Ver Sys::Syslog.

syslog_ident
Solo disponible si "log_file" es igual a "Sys::Syslog". Id para anteponer a las entradas de syslog. El valor predeterminado es "net_server". Ver Sys::Syslog.
syslog_logopt
Solo disponible si "log_file" es igual a "Sys::Syslog". Puede ser cero o más de "pid","cons","ndelay","nowait". El valor predeterminado es "pid". Ver Sys::Syslog.
syslog_facility
Solo disponible si "log_file" es igual a "Sys::Syslog". Ver Sys::Syslog y syslog. El valor predeterminado es "daemon".

ARGUMENTOS PREDETERMINADOS PARA Net::Server

Los siguientes argumentos están disponibles en los módulos predeterminados "Net::Server" o "Net::Server::Single". (Otras personalidades pueden usar parámetros adicionales y opcionalmente no usar parámetros de la clase base).

Clave               Valor                    Predeterminado
## parámetros syslog (si log_file eq Sys::Syslog)
syslog_logsock    (native|unix|inet|udp
                   |tcp|stream|console)    unix (en Sys::Syslog < 0.15)
syslog_ident      "identidad"              "net_server"
syslog_logopt     (cons|ndelay|nowait|pid) pid
syslog_facility   \w+                      daemon

MÉTODOS

"initialize"
Este método se llama durante el método initialize_logging de Net::Server. Devuelve una única referencia de código que se almacenará bajo la propiedad log_function del objeto Net::Server. Esa referencia de código toma log_level y message como argumentos y llama al sistema log4perl inicializado.
"handle_log_error"
Este método se llama si la función de registro falla por alguna razón. Se le pasa el objeto Net::Server, el error que ocurrió al registrar y un arrayref que contiene el nivel de registro y el mensaje. A su vez, esto llama al método legado Net::Server::handle_syslog_error.
