NOMBRE

Net::LDAP::Extra::AD -- Métodos de conveniencia para AD

SINOPSIS

use Net::LDAP::Extra qw(AD);
$ldap = Net::LDAP->new( ... );
...
if ($ldap->is_AD || $ldap->is_ADAM) {
  $ldap->change_ADpassword($dn, $old_password, $new_password);
}

DESCRIPCIÓN

Net::LDAP::Extra::AD intenta evitar a los usuarios la necesidad de reinventar la rueda una y otra vez para codificar correctamente las cadenas de contraseñas de modo que puedan usarse en operaciones de cambio de contraseña de AD.

Para ello, proporciona los siguientes métodos:

MÉTODOS

is_AD ( )
Indica si el servidor LDAP consultado es un Controlador de Dominio de Active Directory.

Como la comprobación se realiza consultando el DSE raíz del directorio, funciona sin necesidad de estar conectado al directorio.

is_ADAM ( )
Indica si el servidor LDAP consultado está ejecutando AD LDS (Servicios de Directorio Activo Ligero), anteriormente conocido como ADAM (Modo de Aplicación de Directorio Activo).

Como la comprobación se realiza consultando el DSE raíz del directorio, funciona sin necesidad de estar conectado al directorio.

change_ADpassword ( DN, CONTRASEÑA_ANTIGUA, CONTRASEÑA_NUEVA )
Cambia la contraseña de la cuenta dada por DN de su valor antiguo CONTRASEÑA_ANTIGUA al nuevo valor CONTRASEÑA_NUEVA.

Este método requiere conexiones cifradas.

reset_ADpassword ( DN, CONTRASEÑA_NUEVA, OPCIONES )
Restablece la contraseña de la cuenta dada por DN al valor dado en CONTRASEÑA_NUEVA. OPCIONES es una lista de pares clave/valor. Se reconocen las siguientes claves:
force_change
Si es VERDADERO, se requiere que el usuario afectado cambie la contraseña en el próximo inicio de sesión.

Para que este método funcione, el llamador debe estar conectado a AD con permisos suficientes y la conexión debe estar cifrada.
