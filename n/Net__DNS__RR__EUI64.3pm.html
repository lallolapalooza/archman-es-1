NOMBRE

Net::DNS::RR::EUI64 - Registro de recurso EUI64 de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre EN EUI64 dirección');
$rr = Net::DNS::RR->new(
                nombre  => 'ejemplo.com',
                tipo    => 'EUI64',
                dirección => '00-00-5e-ef-10-00-00-2a'
                );

DESCRIPCIÓN

Registros de recursos DNS para Identificadores Únicos Extendidos de 64 bits (EUI64).

El registro de recurso EUI64 se utiliza para representar identificadores únicos extendidos de IEEE utilizados en varias redes de capa 2, como Ethernet.

NO se deben publicar direcciones EUI64 en el DNS público. RFC7043 describe implicaciones de privacidad potencialmente graves derivadas de la publicación indiscriminada de direcciones de capa de enlace en el DNS.

Los métodos disponibles son aquellos heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

dirección El campo dirección es una dirección de capa-2 de 8 octetos en orden de bytes de red.

El formato de presentación son hexadecimales separados por "-".
