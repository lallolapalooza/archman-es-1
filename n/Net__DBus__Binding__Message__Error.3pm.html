NOMBRE

Net::DBus::Binding::Message::Error - un mensaje que codifica un error de llamada a método

SINOPSIS

use Net::DBus::Binding::Message::Error;
my $error = Net::DBus::Binding::Message::Error->new(
    replyto => $method_call,
    name => "org.example.myobject.FooException",
    description => "Unable to do Foo when updating bar");
$connection->send($error);

DESCRIPCIÓN

Este módulo forma parte de las APIs de enlace DBus de bajo nivel y no debe ser utilizado por código de aplicación. No se garantizan la estabilidad de las APIs bajo el espacio de nombres "Net::DBus::Binding::" entre versiones.

Este módulo proporciona un constructor de conveniencia para crear un mensaje que representa una condición de error.

MÉTODOS

mi $error = Net::DBus::Binding::Message::Error->new( replyto => $method_call, name => $name, description => $description);
Crea un nuevo mensaje, que representa un error ocurrido durante el manejo del objeto de llamada a método pasado como parámetro "replyto". El parámetro "name" es el nombre formal de la condición de error, mientras que "description" es un breve texto que proporciona información más específica sobre el error.
mi $name = $error->get_error_name
Devuelve el nombre formal del error, tal como se pasó previamente a través del parámetro "name" en el constructor.
