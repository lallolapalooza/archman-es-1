NCONF_new_ex(3ssl)

Paquete: openssl

Licencias: Apache-2.0

NCONF_NEW_EX(3ssl) OpenSSL NCONF_NEW_EX(3ssl)

NOMBRE

NCONF_new_ex, NCONF_new, NCONF_free, NCONF_default, NCONF_load, NCONF_get0_libctx, NCONF_get_section, NCONF_get_section_names - funcionalidad para Cargar y analizar archivos de configuración manualmente

SINOPSIS

#include <openssl/conf.h>
typedef struct {
    char *section;
    char *name;
    char *value;
} CONF_VALUE;
CONF *NCONF_new_ex(OSSL_LIB_CTX *libctx, CONF_METHOD *meth);
CONF *NCONF_new(CONF_METHOD *meth);
void NCONF_free(CONF *conf);
CONF_METHOD *NCONF_default(void);
int NCONF_load(CONF *conf, const char *file, long *eline);
OSSL_LIB_CTX *NCONF_get0_libctx(const CONF *conf);
STACK_OF(CONF_VALUE) *NCONF_get_section(const CONF *conf, const char *name);
STACK_OF(OPENSSL_CSTRING) *NCONF_get_section_names(const CONF *conf);

DESCRIPCIÓN

NCONF_new_ex() crea un nuevo objeto CONF en memoria del montón y le asigna un contexto libctx que puede ser utilizado durante la carga. Si la tabla de métodos meth se establece a NULL, se utiliza el valor predeterminado de NCONF_default().

NCONF_new() es similar a NCONF_new_ex() pero establece libctx a NULL.

NCONF_free() libera los datos asociados con conf y luego libera el objeto conf. Si el argumento es NULL, no se hace nada.

NCONF_load() analiza el archivo llamado filename y añade los valores encontrados a conf. Si ocurre un error, file y eline indican el archivo y la línea en la que falló la carga si no son NULL.

NCONF_default() obtiene la tabla de métodos predeterminada para procesar un archivo de configuración.

NCONF_get0_libctx() obtiene el contexto de la biblioteca asociado con el parámetro conf.

NCONF_get_section_names() obtiene los nombres de las secciones asociadas con conf como cadenas STACK_OF(OPENSSL_CSTRING). Las cadenas individuales están asociadas con conf y serán inválidas después de que se libere conf. La pila devuelta debe liberarse con sk_OPENSSL_CSTRING_free().

NCONF_get_section() obtiene los valores de configuración asociados con conf de la sección de configuración name como estructuras STACK_OF(CONF_VALUE). La pila devuelta está asociada con conf y será inválida después de que se libere conf. El llamador no debe liberarla.

VALORES DE RETORNO

NCONF_load() devuelve 1 en caso de éxito o 0 en caso de error.

NCONF_new_ex() y NCONF_new() devuelven un objeto CONF recién creado o NULL si ocurre un error.
