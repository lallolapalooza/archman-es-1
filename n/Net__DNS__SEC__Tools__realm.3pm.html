Paquete: dnssec-tools

realm(3) Documentación de Perl aportada por el usuario realm(3)

NOMBRE

Net::DNS::SEC::Tools::realm - Manipular un archivo realm de DNSSEC-Tools.

SINOPSIS

use Net::DNS::SEC::Tools::realm;
realm_lock();
realm_read("localhost.realm");
@rlmnames = realm_names();
$flag = realm_exists("example");
$rrec = realm_fullrec("example");
%rrhash = %$rrec;
$zname = $rrhash{"maxttl"};
$val = realm_recval("example","state");
realm_add("realm","example",\%realmfields);
realm_del("example");
realm_rename("example","test-realm");
realm_setval("example","rollrec","example.rrf");
realm_delfield("example","user");
@realmfields = realm_fields();
$count = realmrec_merge("primary.realm", "new0.realm", "new1.realm");
@retvals = realmrec_split("new-realm.rrf", @list_of_realms);
$default_file = realm_default();
realm_write();
realm_close();
realm_discard();
realm_unlock();

DESCRIPCIÓN

El módulo Net::DNS::SEC::Tools::realm manipula el contenido de un archivo realm de DNSSEC-Tools. Los archivos realm describen el estado de un entorno de rollover de zona, tal como lo gestionan los programas de DNSSEC-Tools. Existen interfaces de módulo para buscar registros realm, crear nuevos registros y modificar los existentes.

Un archivo realm está organizado en conjuntos de registros realm. Los realms describen el estado de un entorno de rollover. Un realm consta de un conjunto de entradas de clave/valor. El siguiente es un ejemplo de un realm:

realm "production"
        state           "active"
        realmdir        "/usr/etc/dnssec-tools/realms/production"
        configdir       "/usr/etc/dnssec-tools/configs/production"
        rollrec         "production.rollrec"
        administrator   "sysfolks@example.com"
        display         "1"
        args            "-loglevel phase -logfile log.prod -display"
        user            "prodmgr"

El primer paso para usar este módulo debe ser leer el archivo realm. La interfaz realm_read() lee el archivo y lo analiza en un formato interno. Los registros del archivo se copian en una tabla hash (para una fácil referencia por las rutinas de realm.pm) y en un array (para preservar el formato y los comentarios).

Después de leer el archivo, su contenido se referencia usando realm_fullrec() y realm_recval(). Las interfaces realm_add() y realm_setval() se utilizan para modificar el contenido de un registro realm.

Si el archivo realm ha sido modificado, debe ser escrito explícitamente o los cambios no se guardarán. realm_write() guarda el nuevo contenido en el disco. realm_close() guarda el archivo y cierra el manejador de archivo de Perl para el archivo realm. Si un archivo realm ya no se quiere tener abierto, pero el contenido no debe guardarse, realm_discard() descarta los datos, cierra el manejador de archivo sin guardar ningún dato modificado.

Al leer un archivo realm, las líneas en blanco consecutivas se colapsan en una sola línea en blanco. A medida que se agregan y eliminan entradas realm, se fusionan archivos y se dividen archivos, es posible que los bloques de líneas en blanco consecutivas crezcan. Esto evitará que estos bloques crezcan excesivamente.

BLOQUEO DE REALM

Este módulo incluye interfaces para sincronizar el acceso a los archivos realm. Esta sincronización es muy simple y se basa en el bloqueo y desbloqueo de un único archivo de bloqueo para todos los archivos realm.

No se requiere el bloqueo de realm antes de usar este módulo, pero se recomienda. El uso esperado de estas facilidades sigue:

realm_lock() || die "no se puede bloquear el archivo realm\n";
realm_read();
... realizar otras operaciones de realm ...
realm_close();
realm_unlock();

La sincronización se realiza de esta manera debido a la forma en que se implementa la funcionalidad del módulo, así como a proporcionar flexibilidad a los usuarios del módulo. También proporciona una clara delimitación en el código de los llamadores en cuanto a dónde y cuándo se realiza el bloqueo de realm.

Este método de sincronización tiene la desventaja de tener un único archivo de bloqueo como cuello de botella para todo el acceso a los archivos realm. Sin embargo, reduce la complejidad en las interfaces de bloqueo y disminuye el número potencial de archivos de bloqueo requeridos.

El uso de un único archivo de sincronización puede no ser práctico en instalaciones grandes. Si se encuentra que ese es el caso, entonces esto se revisará.

INTERFACES DE REALM

Las interfaces al módulo realm.pm se dan a continuación.

realm_add(realm_type,realm_name,fields)
Esta rutina agrega un nuevo realm al archivo realm y a la representación interna del contenido del archivo. El realm se agrega tanto a la tabla hash %realms como al array @realmlines. Las entradas solo se agregan si están definidas para realms.

realm_type es el tipo del realm. Debe ser "realm". realm_name es el nombre del realm. fields es una referencia a una tabla hash que contiene los campos realm de nombre/valor. Las claves de la tabla hash siempre se convierten a minúsculas, pero los valores de entrada se dejan tal como se dan.

Se agrega una línea en blanco después de la última línea del nuevo realm. El archivo realm no se escribe después de realm_add(), aunque se marca internamente como modificado.

realm_del(realm_name)
Esta rutina elimina un realm del archivo realm y de la representación interna del contenido del archivo. El realm se elimina tanto de la tabla hash %realms como del array @realmlines.

Solo el realm en sí se elimina del archivo. Cualquier comentario asociado y las líneas en blanco que lo rodean se dejan intactos. El archivo realm no se escribe después de realm_del(), aunque se marca internamente como modificado.

Los valores de retorno son:

 0   eliminación exitosa del realm
-1   nombre desconocido
realm_close()
Esta interfaz guarda la versión interna del archivo realm (abierto con realm_read()) y cierra el manejador de archivo.
realm_delfield(realm_name,field)
Elimina el campo dado del realm especificado. El archivo no se escribe después de actualizar el valor, pero se establece el indicador interno de archivo modificado. El valor se guarda tanto en %realms como en @realmlines.

Valores de retorno:

0 - fallo (realm no encontrado o realm no
    contiene el campo)
1 - éxito
realm_discard()
Esta rutina elimina un archivo realm del uso por parte de un programa. Los datos almacenados internamente se eliminan y se cierra el manejador de archivo realm. Sin embargo, los datos modificados no se guardan antes de cerrar el manejador de archivo. Por lo tanto, los datos modificados y nuevos se perderán.
realm_exists(realm_name)
Esta rutina devuelve un indicador booleano que indica si existe el realm nombrado en realm_name.
realm_fullrec(realm_name)
realm_fullrec() devuelve una referencia al realm especificado en realm_name.
realm_lock()

Si el archivo de sincronización de realm no existe, se creará. Si el proceso no puede crear el archivo de sincronización, se devolverá un error. Se devolverá éxito o fracaso.
Se devuelve el éxito o el fracaso.
realm_merge(target_realm_file, realm_file1, ... realm_fileN)
Esta interfaz fusiona los archivos de realm especificados. Lee cada archivo y parsea los mismos en un hash de realm y un array de contenidos de archivo. El resultado de la fusión se escribe en el archivo denominado por target_realm_file. Si otro realm está ya abierto, se cierra primero y se guarda antes de abrir el nuevo realm.
Si target_realm_file es un archivo existente de realm, se fusionará su contenido con los otros archivos que se pasan a realm_merge(). Si el archivo no existe, realm_merge() creará el archivo y fusionará los restantes archivos en él.
Una vez exitosa, realm_read() devuelve el número de realms leídos del archivo.
Valores de retorno de error:
-1 no se especificaron archivos de realm para realm_merge() -2 no se pudo crear el archivo de sincronización de realm -3 no se pudo leer el primer archivo de realm -4 se produjo un error al leer los nombres de realm -5 los archivos de realm se duplicaron en la lista de archivos de realm
Se devuelve el éxito o el fracaso.
realm_names()
Esta rutina devuelve una lista de los nombres de realm del archivo.
realm_read(realm_file)
Esta interfaz lee el archivo de realm especificado y lo parsea en un hash de realm y un array de contenidos de archivo. realm_read() debe llamarse antes de cualquier llamada a las otras interfaces de realm.pm. Si otro realm está ya abierto, se cierra primero y se guarda antes de abrir el nuevo realm.
realm_read() intenta abrir el archivo de realm para lectura y escritura. Si esto falla, intenta abrirlo solo para lectura.
realm_read() es una interfaz de frente para realm_readfile(). Establece los datos guardados del módulo antes de leer un nuevo archivo de realm. Estas acciones de mantenimiento no se realizan por realm_readfile().
Una vez exitosa, realm_read() devuelve el número de realms leídos del archivo.
Valores de retorno de error:
-1 el archivo de realm especificado no existe -2 no se pudo abrir el archivo de realm -3 nombres duplicados en el archivo de realm
Se devuelve el éxito o el fracaso.
realm_readfile(realm_file_handle)
Esta interfaz lee el archivo de desencriptado especificado y lo parsea en un hash de realm y un array de contenidos de archivo. El hash de realm y el array de contenidos de archivo no se limpian antes de añadir datos a ellos.
Una vez exitosa, realm_read() devuelve 0.
Valores de retorno de error:
-1 nombres duplicados en el archivo de realm
Se devuelve el éxito o el fracaso.
realm_rectype(realm_name,rectype)
Establece el tipo de registro de realm especificado. El archivo no se escribe después de actualizar el valor, pero se establece el flag interno de modificación. El valor se guarda tanto en %realms como en @realmlines.
realm_name es el nombre del realm que se modificará. rectype es el nuevo tipo de realm, que debe ser "realm".
Valores de retorno:
0 - error (tipo de registro inválido o realm no encontrado) 1 - éxito
Se devuelve el éxito o el fracaso.
realm_recval(realm_name,realm_field)
Esta rutina devuelve el valor de un campo específico en un realm. realm_name es el nombre del realm a consultar. realm_field es el nombre del campo dentro del realm.
Ejemplo: el archivo de realm actual contiene el siguiente realm:
realm       "example"  
    rollrec        "example.rrf"
La llamada:
realm_recval("example", "rollrec")
devolverá el valor "example.rrf".
Se devuelve el éxito o el fracaso.
realm_rename(old_realm_name,new_realm_name)
Esta rutina cambia el nombre del realm especificado por old_realm_name a new_realm_name. El efecto real es cambiar el nombre en la línea de realm para que sea new_realm_name. El nombre se cambia solo en la versión interna del archivo de realm. El archivo no se cambia, pero debe ser guardado llamando a realm_write(), realm_save() o realm_saveas().
old_realm_name debe ser el nombre de un realm existente. Por el contrario, new_realm_name no debe ser el nombre de un realm existente.
Valores de retorno:
0 - éxito -1 - old_realm_name es nulo o vacío -2 - new_realm_name es nulo o vacío -3 - old_realm_name no es un realm existente -4 - new_realm_name ya es un realm -5 - error interno que nunca debería ocurrir
Se devuelve el éxito o el fracaso.
realm_setval(realm_name,field,value)
Establece el valor de un par de nombre/campo en un realm especificado. El archivo no se escribe después de actualizar el valor, pero se establece el flag interno de modificación. El valor se guarda tanto en %realms como en @realmlines.
realm_name es el nombre del realm que se modificará. Si el realm especificado no existe, se creará como un realm-tipo realm. field es el campo del realm a modificar. value es el nuevo valor del campo.
Se devuelve el éxito o el fracaso.
realm_split(new_realm_file,realm_names)
Mueve un conjunto de entradas de realm del archivo de realm actual a un nuevo archivo. Las entradas de realm movidas se eliminan tanto del archivo de realm actual como de los datos internos del módulo que representan ese archivo.
El parámetro new_realm_file contiene el nombre del nuevo archivo de realm. Si este archivo no existe, se creará. Si existe, las entradas de realm se añadirán a este archivo.
realm_names es una lista de entradas de realm que se moverán del archivo de realm actual al archivo denominado por new_realm_file. Si algunos de los nombres dados de realm son inválidos, los nombres válidos se moverán al nuevo archivo y los nombres inválidos se devolverán en una lista al llamante.
Solo las entradas de realm se moverán al nuevo archivo de realm. Los comentarios asociados se dejarán en el archivo de realm actual.
Una vez exitosa, se devuelve el número de entradas de realm movidas. Los valores de retorno de error se dan abajo.
Valores de retorno de error:
-1 - no hay archivo de realm como destino en new_realm_file -2 - no hay nombres de realm dados en realm_names -3 - ninguno de los nombres de realm dados es un realm existente -4 - no se puede abrir el archivo de realm en new_realm_file -5 - los nombres de realm inválidos fueron especificados en realm_names, seguido por la lista de nombres inválidos.
Se devuelve el éxito o el fracaso.
realm_unlock()
realm_unlock() desbloquea el archivo de sincronización de realm.
realm_write()
Esta interfaz guarda la versión interna del archivo de realm (abierto con realm_read()). No cierra el handle del archivo. Como medida de eficiencia, se verifica primero el flag interno de modificación antes de escribir el archivo. Si el programa no ha modificado el contenido del archivo de realm, no se reescribirá.
realm_write() obtiene un bloque exclusivo del archivo de realm mientras se escribe.
Se devuelve el éxito o el fracaso.

INTERFACES INTERNAS DE REALM

Las interfaces descritas en esta sección están diseñadas para uso interno del módulo realm.pm. Sin embargo, hay situaciones en las que otras entidades pueden necesitarlas. Úselas con cuidado, ya que su uso incorrecto puede dañar o perder archivos de realm.
realm_init()
Esta rutina inicializa los datos internos de realm. Los cambios pendientes se perderán. Debe leer un nuevo archivo de realm antes de utilizar las interfaces de realm.pm nuevamente.
realm_default()
Esta rutina devuelve el nombre del archivo de realm por defecto.

INTERFACES DE DEPURACIÓN DE REALM

Las siguientes interfaces muestran información sobre el archivo de realm actualmente analizado. Están diseñadas para uso en depuración y pruebas, pero pueden ser útiles en otros momentos.
realm_dump_hash()
Esta rutina imprime el archivo de realm tal como se almacena internamente en un hash. Los realms se imprimen en orden alfabético, con los campos ordenados alfabéticamente para cada realm. Los nuevos realms y campos de realm se imprimen junto con los realms y campos actuales. Los comentarios del archivo de realm no se incluyen en el hash.

DESCRIPCIÓN

El módulo Net::DNS::SEC::Tools::realm proporciona una forma de gestionar la información de dominio de nivel superior (TLD) utilizada por las herramientas DNSSEC-Tools.

Este módulo se utiliza para acceder y manipular los datos de dominio de nivel superior. No debe ser llamado directamente por el usuario; en su lugar, debe ser llamado por las herramientas que proporciona este paquete.

Los datos del dominio de nivel superior se almacenan en un archivo de texto plano que se describe en la página del manual realm(5).

BLOQUEO DE DOMINIO

Si se intenta acceder a los datos del dominio de nivel superior mientras otras herramientas los están modificando, el acceso podría ser bloqueado. Esto se hace para evitar la corrupción de datos. El bloqueo es realizado por el programa realmchk(8).

INTERFACES DE DOMINIO

Las interfaces para el módulo Net::DNS::SEC::Tools::realm están disponibles a través de la API de Perl.

Las funciones exportadas incluyen:

  • realm_read(): lee el archivo de dominio de nivel superior.
  • realm_write(): escribe el archivo de dominio de nivel superior.
  • realm_add_field(): añade un campo a una entrada de dominio de nivel superior existente.
  • realm_new(): añade una nueva entrada de dominio de nivel superior al archivo.

INTERFACES INTERNAS DE DOMINIO

Estas interfaces no deben ser llamadas directamente por el usuario. Se utilizan internamente por otras funciones del módulo.

  • _realm_lock(): adquiere un bloqueo en el archivo de dominio de nivel superior.
  • _realm_unlock(): libera el bloqueo en el archivo de dominio de nivel superior.
  • _realm_parse(): analiza el contenido del archivo de dominio de nivel superior.
  • _realm_format(): formatea los datos del dominio de nivel superior para escribirlos en el archivo.

INTERFACES DE DEPURACIÓN DE DOMINIO

Estas interfaces se pueden utilizar para depurar el módulo Net::DNS::SEC::Tools::realm.

  • realm_debug(): establece el nivel de depuración para el módulo.

ORDEN DEL ARCHIVO

El archivo de dominio de nivel superior se almacena como un arreglo de objetos de dominio de nivel superior. Cada objeto de dominio de nivel superior es un arreglo de campos. Los campos se añaden al final del arreglo de objetos de dominio de nivel superior. Los campos que se añaden a un objeto de dominio de nivel superior existente se añaden al principio de la entrada del objeto de dominio de nivel superior. Los comentarios y el espacio en blanco vertical se conservan tal como se proporcionan en el archivo de dominio de nivel superior.
