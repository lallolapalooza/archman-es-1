Net::DBus::Test::MockObject(3) Documentación de Perl aportada por el usuario Net::DBus::Test::MockObject(3)

NOMBRE

Net::DBus::Test::MockObject - Finge un objeto del bus para pruebas unitarias

SINOPSIS

use Net::DBus;
use Net::DBus::Test::MockObject;
my $bus = Net::DBus->test
# Falsifiquemos la presencia de HAL...
# Primero necesitamos definir el servicio
my $service = $bus->export_service("org.freedesktop.Hal");
# Luego crear un objeto simulado
my $object = Net::DBus::Test::MockObject->new($service,
                                              "/org/freedesktop/Hal/Manager");
# Falsificar el método 'GetAllDevices'
$object->seed_action("org.freedesktop.Hal.Manager",
                     "GetAllDevices",
                     reply => {
                       return => [ "/org/freedesktop/Hal/devices/computer_i8042_Aux_Port",
                                   "/org/freedesktop/Hal/devices/computer_i8042_Aux_Port_logicaldev_input",
                                   "/org/freedesktop/Hal/devices/computer_i8042_Kbd_Port",
                                   "/org/freedesktop/Hal/devices/computer_i8042_Kbd_Port_logicaldev_input"
                       ],
                     });
# Ahora se puede probar cualquier clase que llame a 'GetAllDevices' en HAL
....cosas de prueba....

DESCRIPCIÓN

Esto proporciona una alternativa a Net::DBus::Object para permitir que los objetos del bus sean simulados rápidamente, facilitando así la creación de pruebas unitarias para servicios que puedan necesitar llamar a objetos proporcionados por servicios de terceros en el bus. Típicamente se utiliza como complemento del objeto Net::DBus::MockBus, para permitir probar servicios complejos sin iniciar realmente un bus real.

!!!!! ADVERTENCIA !!!

Este objeto y sus APIs deben considerarse muy experimentales en este momento, y no se proporcionan garantías sobre la compatibilidad futura de la API. Sin embargo, los comentarios y sugerencias sobre cómo evolucionar este marco son bienvenidos y alentados.

MÉTODOS

mi $object = Net::DBus::Test::MockObject->new($service, $path, $interface);
Crea un nuevo objeto simulado, adjuntándose al servicio definido por el parámetro $service. Esta sería una instancia del objeto Net::DBus::Service. El parámetro $path define la ruta del objeto en la que adjuntar este objeto simulado, y $interface define la interfaz que soportará.
mi $service = $object->get_service
Recupera el objeto Net::DBus::Service dentro del cual se exporta este objeto.
mi $path = $object->get_object_path
Recupera la ruta bajo la cual se exporta este objeto.
mi $msg = $object->get_last_message
Recupera el último mensaje procesado por este objeto. El objeto devuelto es una instancia de Net::DBus::Binding::Message.
mi $sig = $object->get_last_message_signature
Recupera la firma de tipo del último mensaje procesado.
mi $value = $object->get_last_message_param
Devuelve el primer valor proporcionado como argumento al último mensaje procesado.
my @values = $object->get_last_message_param_list
Devuelve una lista de todos los valores proporcionados como argumentos al último mensaje procesado.
$object->seed_action($interface, $method, %action);
Registra una acción a realizar cuando se recibe un mensaje que corresponde al método $method dentro de la interfaz $interface. El parámetro %action puede tener una serie de claves posibles establecidas:
signals
Causa que se emita una señal cuando se invoca el método. El valor asociado a esta clave debe ser una instancia de la clase Net::DBus::Binding::Message::Signal.
error
Causa que se genere un error cuando se invoca el método. El valor asociado a esta clave debe ser una referencia a un hash, con dos elementos. El primero, "name", que da el nombre del error, y el segundo, "description", que proporciona el texto descriptivo.
reply
Causa que se genere un retorno normal del método. El valor asociado a esta clave debe ser una referencia a un array, cuyos elementos son los valores que debe devolver el método.

ERRORES

No replica completamente la API de Net::DBus::Binding::Object, simplemente lo suficiente como para que los enlaces de alto nivel funcionen en un escenario de prueba.
