Net::Server::PSGI(3) Documentación de Perl aportada por el usuario Net::Server::PSGI(3)

NOMBRE

Net::Server::PSGI - clase de servidor HTTP PSGI básica basada en Net::Server

TEST DE UNA LÍNEA

perl -e 'use base qw(Net::Server::PSGI); main->run(port => 8080, ipv => "*")'
# ejecuta un servidor de eco predeterminado

SINOPSIS

use base qw(Net::Server::PSGI);
__PACKAGE__->run(app => \&my_echo_handler); # enlazará al puerto 80 de IPv4
sub my_echo_handler {
    my $env = shift;
    my $txt = qq{<form method="post" action="/bam"><input type="text" name="foo"><input type="submit"></form>\n};
    require Data::Dumper;
    local $Data::Dumper::Sortkeys = 1;
    require CGI::PSGI;
    my $form = {};
    my $q = CGI::PSGI->new($env);
    $form->{$_} = $q->param($_) for $q->param;
    $txt .= "<pre>".Data::Dumper->Dump([$env, $form], ['env', 'form'])."</pre>";
    return [200, ['Content-type', 'text/html'], [$txt]];
}

DESCRIPCIÓN

Si desea una experiencia PSGI más completa, sería prudente buscar los módulos Plack y Starman. Net::Server::PSGI está pensado como una puerta de entrada fácil a PSGI. Pero para aprovechar al máximo todo lo que PSGI tiene para ofrecer, debe revisar Plack y Plack::Middleware. Si solo necesita algo un poco más rudimentario, entonces Net::Server::PSGI puede ser bueno para usted.

Net::Server::PSGI lleva Net::Server::HTTP un nivel más allá. Comienza con el tipo base MultiType, que por defecto es Net::Server::Fork. Es fácil cambiarlo a cualquiera de los otros sabores de Net::Server pasando server_type => $otro_sabor en la configuración del servidor. El puerto también se ha predeterminado al puerto 80, pero podría cambiarse fácilmente a otro a través de la configuración del servidor. También puede agregar SSL muy fácilmente incluyendo proto=>"ssl" y proporcionando un archivo SSL_cert_file y SSL_key_file.

Por ejemplo, aquí hay un servidor básico que se enlazará a todas las interfaces, hablará tanto HTTP en el puerto 8080 como HTTPS en el 8443, y hablará tanto IPv4 como IPv6 si está disponible.

use base qw(Net::Server::PSGI);
__PACKAGE__->run(
    port  => [8080, "8443/ssl"],
    ipv   => '*', # IPv6 si está disponible
    SSL_key_file  => '/my/key',
    SSL_cert_file => '/my/cert',
);

MÉTODOS

"process_request"
Este método ha sido sobrescrito en Net::Server::PSGI. No debe usarlo mientras usa Net::Server::PSGI. Este método sobrescrito analiza el entorno y configura alarmas de solicitud y maneja fallos de finalización. Llama a process_psgi_request una vez que la solicitud está lista y las cabeceras han sido analizadas.
"process_psgi_request"
Se utiliza cuando psgi_enabled es verdadero. Durante este método, se llamará a find_psgi_handler para devolver el manejador de respuesta psgi apropiado. Una vez terminado, print_psgi_headers y print_psgi_body se utilizan para imprimir la respuesta. Ver PSGI.

Típicamente, este método no debe ser sobrescrito. En su lugar, se debe proporcionar un método apropiado para encontrar la aplicación a find_psgi_handler o app.

"find_psgi_handler"
Se utiliza para buscar el manejador PSGI apropiado. Se pasa una referencia al hashref de $env ya analizado. PATH_INFO se inicializará con la porción de ruta completa de la URI. SCRIPT_NAME se inicializará con la cadena vacía. Este manejador debe establecer los valores apropiados para SCRIPT_NAME y PATH_INFO dependiendo de la ruta coincidente. Se debe devolver una referencia de código para el manejador. El find_psgi_handler predeterminado llamará al método "app". Si falla, se devuelve una referencia a psgi_echo_handler como aplicación predeterminada. 
sub find_psgi_handler {
    my ($self, $env) = @_;
    if ($env->{'PATH_INFO'} && $env->{'PATH_INFO'} =~ s{^ (/foo) (?= $ | /) }{}x) {
        $env->{'SCRIPT_NAME'} = $1;
        return \&foo_app;
    }
    return $self->SUPER::find_psgi_handler($env);
}
"app"
Devuelve una referencia a la aplicación que se está sirviendo. Debe ser una aplicación PSGI válida. Ver PSGI. Por defecto, mirará el valor de la opción de configuración "app". El método "app" también puede usarse para establecer la opción de configuración "app". 
package MyApp;
use base qw(Net::Server::PSGI);
sub default_server_type { 'Prefork' }
sub my_app {
    my $env = shift;
    return [200, ['Content-type', 'text/html'], ["Hola mundo"]];
}
MyApp->run(app => \&my_app);
# O
sub app { \&my_app }
MyApp->run;
# O
my $server = MyApp->new;
$server->app(\&my_app);
$server->run;

OPCIONES

Además de los argumentos de línea de comandos de las clases base de Net::Server::HTTP, también puede establecer las siguientes opciones.

app
Debería devolver una referencia de código de la aplicación PSGI. Es devuelto por el método app.
