Net::DNS::Question(3) Documentación de Perl aportada por el usuario Net::DNS::Question(3)

NOMBRE

Net::DNS::Question - Registro de pregunta DNS

SINOPSIS

use Net::DNS::Question;
$question = Net::DNS::Question->new('example.com', 'AAAA', 'IN');

DESCRIPCIÓN

Un objeto Net::DNS::Question representa un registro en la sección de preguntas de un paquete DNS.

MÉTODOS

new

$question = Net::DNS::Question->new('example.com', 'AAAA', 'IN');
$question = Net::DNS::Question->new('example.com', 'A', 'IN');
$question = Net::DNS::Question->new('example.com');
$question = Net::DNS::Question->new('2001::DB8::dead:beef', 'PTR', 'IN');
$question = Net::DNS::Question->new('2001::DB8::dead:beef');

Crea un objeto de pregunta a partir del dominio, tipo y clase pasados como argumentos. Uno o ambos argumentos de tipo y clase pueden omitirse y asumirán los valores predeterminados que se muestran arriba.

Se admite la notación de dirección IP/prefijo de RFC4291 y RFC4632 para consultas en los espacios de nombres in-addr.arpa e ip6.arpa.

decodificar

$question = Net::DNS::Question->decode(\$data, $offset);
($question, $offset) = Net::DNS::Question->decode(\$data, $offset);

Decodifica el registro de pregunta en la ubicación especificada dentro de un paquete DNS en formato de cable. El primer argumento es una referencia al búfer que contiene los datos del paquete. El segundo argumento es el desplazamiento del inicio del registro de pregunta.

Devuelve un objeto Net::DNS::Question y el desplazamiento de la siguiente ubicación en el paquete.

Se lanza una excepción si el objeto no se puede crear (por ejemplo, datos corruptos o insuficientes).

codificar

$data = $question->encode( $offset, $hash );

Devuelve el Net::DNS::Question en formato binario adecuado para su inclusión en un búfer de paquete DNS.

Los argumentos opcionales son el desplazamiento dentro de los datos del paquete donde se almacenará el Net::DNS::Question y una referencia a una tabla hash utilizada para indexar nombres comprimidos dentro del paquete.

cadena

print "cadena = ", $question->string, "\n";

Devuelve una representación en cadena del registro de pregunta.

imprimir

$object->print;

Imprime el registro en la salida estándar. Llama al método string() para obtener la representación en cadena.

nombre

$name = $question->name;

Nombre de dominio internacionalizado correspondiente al atributo qname.

La decodificación de nombres de dominio no ASCII es computacionalmente costosa y poco deseable para nombres que probablemente se utilizarán para construir consultas adicionales.

Cuando sea necesario comunicarse con humanos, el nombre de dominio 'correcto' debe extraerse de un paquete de consulta o respuesta.

$query = Net::DNS::Packet->new( $example, 'SOA' );
$reply = $resolver->send($query) or die;
($question) = $reply->question;
$name = $question->name;

qnombre, znambre

$qname = $question->qname;
$zname = $question->zname;

Nombre de dominio completamente calificado en el formato requerido para una consulta transmitida a un servidor de nombres. En paquetes de actualización dinámica, este atributo se conoce como zname() y se refiere al nombre de la zona.

qtipo, ztipo, tipo

$qtype = $question->type;
$qtype = $question->qtype;
$ztype = $question->ztype;

Devuelve el atributo de tipo de pregunta. En paquetes de actualización dinámica, este atributo se conoce como ztype() y se refiere al tipo de zona.

qclase, zclase, clase

$qclass = $question->class;
$qclass = $question->qclass;
$zclass = $question->zclass;

Devuelve el atributo de clase de pregunta. En paquetes de actualización dinámica, este atributo se conoce como zclass() y se refiere a la clase de zona.
