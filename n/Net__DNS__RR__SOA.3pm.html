NOMBRE

Net::DNS::RR::SOA - Registro de recursos SOA de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre SOA mnombre rnombre 0 14400 3600 1814400 3600');

DESCRIPCIÓN

Clase para registros de recursos de Inicio de Autoridad (SOA) de DNS.

MÉTODOS

Los métodos disponibles son aquellos heredados de la clase base aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete ni el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otro comportamiento impredecible.

mnombre

$mnombre = $rr->mnombre;
$rr->mnombre( $mnombre );

El nombre de dominio del servidor de nombres que fue la fuente original o principal de datos para esta zona.

rnombre

$rnombre = $rr->rnombre;
$rr->rnombre( $rnombre );

El buzón que identifica a la persona responsable de mantener esta zona.

serial

$serial = $rr->serial;
$serial = $rr->serial(valor);

Número de versión de 32 bits sin signo de la copia original de la zona. Las transferencias de zona conservan este valor.

RFC1982 define un orden parcial estricto (irreﬂexivo) para los números de serie de zona. El número de serie se incrementará a menos que el valor de reemplazo dado cumpla con la restricción de ordenación.

refresh

$refresh = $rr->refresh;
$rr->refresh( $refresh );

Un intervalo de tiempo de 32 bits antes de que la zona deba ser actualizada.

retry

$retry = $rr->retry;
$rr->retry( $retry );

Un intervalo de tiempo de 32 bits que debe transcurrir antes de que se deba reintentar una actualización fallida.

expire

$expire = $rr->expire;
$rr->expire( $expire );

Un valor de tiempo de 32 bits que especifica el límite superior del intervalo de tiempo que puede transcurrir antes de que la zona ya no sea autoritativa.

minimum

$minimum = $rr->minimum;
$rr->minimum( $minimum );

El campo TTL mínimo de 32 bits sin signo que debe ser exportado con cualquier RR de esta zona.

Gestión del Número de Serie de Zona

La lógica interna del método serial() ofrece soporte para varias políticas de numeración de series de zona ampliamente utilizadas.

Estrictamente Secuencial

$sucesor = $soa->serial( SECUENCIAL );

El número de serie existente se incrementa en módulo 2**32 porque el valor devuelto por la función auxiliar SECUENCIAL() nunca puede cumplir la restricción de ordenación del número de serie.

Codificado por Fecha

$sucesor = $soa->serial( AAAAMMDDxx );

El valor de 32 bits devuelto por la función auxiliar AAAAMMDDxx() se utilizará si cumple con la restricción de ordenación; de lo contrario, el número de serie se incrementará como se indicó anteriormente.

Los incrementos del número de serie deben limitarse a 100 por día para que la información de la fecha siga siendo útil.

Codificado por Tiempo

$sucesor = $soa->serial( TIEMPO_UNIX );

El valor de 32 bits devuelto por la función auxiliar TIEMPO_UNIX() se utilizará si cumple con la restricción de ordenación; de lo contrario, el número de serie existente se incrementará como se indicó anteriormente.
