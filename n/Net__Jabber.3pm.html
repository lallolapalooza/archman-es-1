NOMBRE

Net::Jabber - Biblioteca Perl para Jabber

SINOPSIS

Net::Jabber proporciona a los usuarios de Perl acceso al protocolo de mensajería instantánea Jabber.
Para más información sobre Jabber, visita:
  http://www.jabber.org

DESCRIPCIÓN

Net::Jabber es una herramienta conveniente para cualquier script Perl que desee utilizar el protocolo de mensajería instantánea Jabber. Aunque no es un cliente en sí mismo, proporciona todas las funciones de backend necesarias para hacer que un cliente CGI o un cliente Perl de línea de comandos sea factible y fácil de usar. Net::Jabber es un envoltorio alrededor del resto de los paquetes oficiales Net::Jabber::xxxxxx.
Hay scripts de ejemplo en el directorio de ejemplos que le proporcionan ejemplos de programas Jabber muy sencillos.
NOTA: El analizador que proporciona XML::Stream::Parser, al igual que la mayoría de los analizadores Perl, es síncrono. Si se encuentra en medio del análisis de un paquete y llama a una devolución de llamada definida por el usuario, el Analizador se bloquea hasta que su devolución de llamada finaliza. Esto significa que no puede estar operando en un paquete, enviar otro paquete y esperar una respuesta a ese paquete. Nunca llegará a usted. Los hilos podrían resolver esto, pero en el momento de escribir esto, los hilos en Perl aún no están a la altura. Este problema se revisará en el futuro.

EJEMPLOS

Para un cliente:
  use Net::Jabber;
  my $client = new Net::Jabber::Client();
Para un componente:
  use Net::Jabber;
  my $component = new Net::Jabber::Component();

MÉTODOS

El módulo Net::Jabber no define ningún método que usted llame directamente en su código. En su lugar, instanciará objetos que llaman a funciones de este módulo para realizar el trabajo. Los tres objetos principales con los que trabajará son los módulos Message, Presence e IQ. Cada uno corresponde al equivalente Jabber y le permite obtener y establecer todas las partes de esos paquetes.

PAQUETES

Para más información sobre cada uno de estos paquetes, por favor consulte la página del manual para cada uno.

Net::Jabber::Client

Este paquete contiene el código necesario para comunicarse con un servidor Jabber: iniciar sesión, esperar mensajes, enviar mensajes y cerrar sesión. Utiliza XML::Stream para leer el flujo del servidor y, basándose en el tipo de etiqueta que encuentra, llama a una función para manejar la etiqueta.

Net::Jabber::Component

Este paquete contiene el código necesario para escribir un componente de servidor. Un componente es un programa que maneja la comunicación entre un servidor Jabber y algún programa o paquete de comunicación externo (IRC, talk, email, etc.). Con este módulo puede escribir un componente completo en solo unas pocas líneas de Perl. Utiliza XML::Stream para comunicarse con su servidor host y, basándose en el tipo de etiqueta que encuentra, llama a una función para manejar la etiqueta.

Net::Jabber::Protocol

Una colección de funciones de alto nivel que Client y Component utilizan para facilitarles la vida mediante la herencia.

Net::Jabber::JID

Los ID de Jabber constan de tres partes: ID de usuario, servidor y recurso. Este módulo le da acceso a esos componentes sin tener que analizar la cadena usted mismo.

Net::Jabber::Message

Todo lo necesario para crear y leer un <message/> recibido del servidor.

Net::Jabber::Presence

Todo lo necesario para crear y leer un <presence/> recibido del servidor.

Net::Jabber::IQ

IQ es un envoltorio alrededor de un número de módulos que proporcionan soporte para los diversos espacios de nombres Info/Query que Jabber reconoce.

Net::Jabber::Stanza

Este módulo representa un stanza con espacio de nombres que se utiliza para extender un <message/>, <presence/> y <iq/>. En última instancia, cada espacio de nombres se documenta en una JEP de algún tipo. http://jabber.org/jeps/
La página del manual de Net::Jabber::Stanza contiene una lista de todos los espacios de nombres compatibles y los métodos que admiten los objetos que representan esos espacios de nombres.

Net::Jabber::Namespaces

Jabber permite que cualquier stanza sea extendida por cualquier fragmento de XML. Este módulo contiene todos los detalles internos para definir las extensiones basadas en Jabber definidas por las JEPs. La documentación de este módulo explica más sobre cómo agregar su propio espacio de nombres personalizado y hacer que sea compatible.
