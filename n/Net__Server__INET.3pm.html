use base qw(Net::Server::INET);

    #...código...
}
Net::Server::INET->run();

DESCRIPCIÓN

Por favor, lee primero el pod de Net::Server. Este módulo es una personalidad, o extensión, o subclase del módulo Net::Server.

Esta personalidad está pensada para ser utilizada con inetd. No ofrece métodos adicionales a la clase base Net::Server. Este módulo opera sobrescribiendo los métodos pre_bind, bind, accept y post_accept para dejar todo el procesamiento del socket a cargo de inetd.
