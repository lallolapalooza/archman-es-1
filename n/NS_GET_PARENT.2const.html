NS_GET_USERNS(2const) NS_GET_USERNS(2const)

NOMBRE

NS_GET_USERNS, NS_GET_PARENT - descubrimiento de relaciones de espacio de nombres

SINOPSIS

#include <linux/nsfs.h>  /* Definición de las constantes NS_GET_* */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op);

DESCRIPCIÓN

Las siguientes operaciones de ioctl(2) se proporcionan para permitir el descubrimiento de relaciones de espacio de nombres (ver user_namespaces(7) y pid_namespaces(7)).

En cada caso, fd se refiere a un archivo de /proc/pid/ns/*. Ambas operaciones devuelven un nuevo descriptor de archivo en caso de éxito.

NS_GET_USERNS
Devuelve un descriptor de archivo que se refiere al espacio de nombres de usuario propietario del espacio de nombres al que se refiere fd.
NS_GET_PARENT
Devuelve un descriptor de archivo que se refiere al espacio de nombres padre del espacio de nombres al que se refiere fd. Esta operación solo es válida para espacios de nombres jerárquicos (es decir, espacios de nombres PID y de usuario). Para los espacios de nombres de usuario, NS_GET_PARENT es sinónimo de NS_GET_USERNS.

El nuevo descriptor de archivo devuelto por estas operaciones se abre con las banderas O_RDONLY y O_CLOEXEC (cerrar en ejecución; ver fcntl(2)).

Al aplicar fstat(2) al descriptor de archivo devuelto, se obtiene una estructura stat cuyos campos st_dev (dispositivo residente) y st_ino (número de inodo) juntos identifican el espacio de nombres propietario/padre. Este número de inodo se puede comparar con el número de inodo de otro archivo /proc/pid/ns/{pid,user} para determinar si es el espacio de nombres propietario/padre.

VALOR DE RETORNO

En caso de éxito, se devuelve un descriptor de archivo. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EPERM
El espacio de nombres solicitado está fuera del ámbito del espacio de nombres del llamador. Este error puede ocurrir si, por ejemplo, el espacio de nombres de usuario propietario es un ancestro del espacio de nombres de usuario actual del llamador. También puede ocurrir en intentos de obtener el padre del espacio de nombres inicial de usuario o PID.
ENOTTY
La operación no es compatible con esta versión del kernel.

Además, la operación NS_GET_PARENT puede fallar con el siguiente error:

EINVAL
fd se refiere a un espacio de nombres no jerárquico.

ESTÁNDARES

Linux.

HISTORIA

NS_GET_USERNS
Linux 4.9.
NS_GET_PARENT
Linux 4.9.

EJEMPLOS

El ejemplo que se muestra a continuación utiliza las operaciones de ioctl(2) descritas anteriormente para realizar un descubrimiento simple de relaciones de espacio de nombres. Las siguientes sesiones de shell muestran varios ejemplos de uso de este programa.

Intentar obtener el padre del espacio de nombres de usuario inicial falla, ya que no tiene padre:


$ ./ns_show /proc/self/ns/user p;
El espacio de nombres padre está fuera del ámbito de su espacio de nombres

Cree un proceso que ejecute sleep(1) que resida en nuevos espacios de nombres de usuario y UTS, y muestre que el nuevo espacio de nombres UTS está asociado con el nuevo espacio de nombres de usuario:


$ unshare -Uu sleep 1000 &
[1] 23235
$ ./ns_show /proc/23235/ns/uts u;
Dispositivo/Inodo del espacio de nombres de usuario propietario es: [0,3] / 4026532448
$ readlink /proc/23235/ns/user;
user:[4026532448]

Luego, muestre que el padre del nuevo espacio de nombres de usuario en el ejemplo anterior es el espacio de nombres de usuario inicial:


$ readlink /proc/self/ns/user;
user:[4026531837]
$ ./ns_show /proc/23235/ns/user p;
Dispositivo/Inodo del espacio de nombres padre es: [0,3] / 4026531837

Inicie un shell en un nuevo espacio de nombres de usuario y muestre que desde dentro de este shell, el espacio de nombres de usuario padre no se puede descubrir. De manera similar, el espacio de nombres UTS (que está asociado con el espacio de nombres de usuario inicial) no se puede descubrir.


$ PS1="sh2$ " unshare -U bash;
sh2$ ./ns_show /proc/self/ns/user p;
El espacio de nombres padre está fuera del ámbito de su espacio de nombres
sh2$ ./ns_show /proc/self/ns/uts u;
El espacio de nombres de usuario propietario está fuera del ámbito de su espacio de nombres

Código fuente del programa

/* ns_show.c
   Licenciado bajo la Licencia Pública General de GNU v2 o posterior.
*/
#include <errno.h>
#include <fcntl.h>
#include <linux/nsfs.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/ioctl.h>
#include <sys/stat.h>
#include <sys/sysmacros.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int          fd, userns_fd, parent_fd;
    struct stat  sb;
    if (argc < 2) {
        fprintf(stderr, "Uso: %s /proc/[pid]/ns/[archivo] [p|u]\n",
                argv[0]);
        fprintf(stderr, "\nMostrar el resultado de uno o ambos "
                "de NS_GET_USERNS (u) o NS_GET_PARENT (p)\n"
                "para el /proc/[pid]/ns/[archivo] especificado.  Si no se especifica "
                "'p' ni 'u',\n"
                "NS_GET_USERNS es el predeterminado.\n");
        exit(EXIT_FAILURE);
    }
    /* Obtener un descriptor de archivo para el archivo 'ns' especificado
       en argv[1].  */
    fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /* Obtener un descriptor de archivo para el espacio de nombres de usuario propietario y
       luego obtener y mostrar el número de inodo de ese espacio de nombres.  */
    if (argc < 3 || strchr(argv[2], 'u')) {
        userns_fd = ioctl(fd, NS_GET_USERNS);
        if (userns_fd == -1) {
            if (errno == EPERM)
                printf("El espacio de nombres de usuario propietario está fuera "
                       "del ámbito de su espacio de nombres\n");
            else
               perror("ioctl-NS_GET_USERNS");
            exit(EXIT_FAILURE);
         }
        if (fstat(userns_fd, &sb) == -1) {
            perror("fstat-userns");
            exit(EXIT_FAILURE);
        }
        printf("Dispositivo/Inodo del espacio de nombres de usuario propietario es: "
               "[%x,%x] / %ju\n",
               major(sb.st_dev),
               minor(sb.st_dev),
               (uintmax_t) sb.st_ino);
        close(userns_fd);
    }
    /* Obtener un descriptor de archivo para el espacio de nombres padre y
       luego obtener y mostrar el número de inodo de ese espacio de nombres.  */
    if (argc > 2 && strchr(argv[2], 'p')) {
        parent_fd = ioctl(fd, NS_GET_PARENT);
        if (parent_fd == -1) {
            if (errno == EINVAL)
                printf("No se puede obtener el espacio de nombres padre de un "
                       "espacio de nombres no jerárquico\n");
            else if (errno == EPERM)
                printf("El espacio de nombres padre está fuera "
                       "del ámbito de su espacio de nombres\n");
            else
                perror("ioctl-NS_GET_PARENT");
            exit(EXIT_FAILURE);
        }
        if (fstat(parent_fd, &sb) == -1) {
            perror("fstat-parentns");
            exit(EXIT_FAILURE);
        }
        printf("Dispositivo/Inodo del espacio de nombres padre es: [%x,%x] / %ju\n",
               major(sb.st_dev),
               minor(sb.st_dev),
               (uintmax_t) sb.st_ino);
        close(parent_fd);
    }
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN

ioctl(2), ioctl_nsfs(2)
