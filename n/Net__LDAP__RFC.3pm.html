DESCRIPCIÓN

El protocolo LDAP se define en las siguientes RFCs.

Especificación Core LDAP

RFC-4510 Lightweight Directory Access Protocol (LDAP): Technical Specification Road Map

http://www.ietf.org/rfc/rfc4510.txt

El Lightweight Directory Access Protocol (LDAP) es un protocolo de Internet para acceder a servicios de directorio distribuidos que actúan de acuerdo con los modelos de datos y servicios de X.500. Este documento proporciona un mapa de la especificación técnica de LDAP.

RFC-4511 Lightweight Directory Access Protocol (LDAP): The Protocol

http://www.ietf.org/rfc/rfc4511.txt

Este documento describe los elementos del protocolo, junto con sus semánticas y codificaciones, del Lightweight Directory Access Protocol (LDAP). LDAP proporciona acceso a servicios de directorio distribuidos que actúan de acuerdo con los modelos de datos y servicios de X.500. Estos elementos del protocolo se basan en los descritos en el X.500 Directory Access Protocol (DAP).

RFC-4512 Lightweight Directory Access Protocol (LDAP): Directory Information Models

http://www.ietf.org/rfc/rfc4512.txt

El Lightweight Directory Access Protocol (LDAP) es un protocolo de Internet para acceder a servicios de directorio distribuidos que actúan de acuerdo con los modelos de datos y servicios de X.500. Este documento describe los Modelos de Información de Directorio X.500, tal como se utilizan en LDAP.

RFC-4513 Lightweight Directory Access Protocol (LDAP): Authentication Methods and Security Mechanisms

http://www.ietf.org/rfc/rfc4513.txt

Este documento describe los métodos de autenticación y los mecanismos de seguridad del Lightweight Directory Access Protocol (LDAP). Este documento detalla el establecimiento de Transport Layer Security (TLS) utilizando la operación StartTLS.

Este documento detalla el método de autenticación Bind simple, incluyendo los mecanismos anónimo, no autenticado y de nombre/contraseña, y el método de autenticación Bind Simple Authentication and Security Layer (SASL), incluyendo el mecanismo EXTERNAL.

Este documento discute varios estados de autenticación y autorización a través de los cuales puede pasar una sesión a un servidor LDAP y las acciones que desencadenan estos cambios de estado.

RFC-4514 Lightweight Directory Access Protocol (LDAP): String Representation of Distinguished Names

http://www.ietf.org/rfc/rfc4514.txt

El Directorio X.500 utiliza nombres distintivos (DN) como claves primarias para las entradas del directorio. Este documento define la representación en cadena utilizada en el Lightweight Directory Access Protocol (LDAP) para transferir nombres distintivos. La representación en cadena está diseñada para proporcionar una representación clara de los nombres distintivos de uso común, al tiempo que es capaz de representar cualquier nombre distintivo.

RFC-4515 Lightweight Directory Access Protocol (LDAP): String Representation of Search Filters

http://www.ietf.org/rfc/rfc4515.txt

Los filtros de búsqueda del Lightweight Directory Access Protocol (LDAP) se transmiten en el protocolo LDAP utilizando una representación binaria adecuada para su uso en la red. Este documento define una representación en cadena legible por humanos de los filtros de búsqueda LDAP que es apropiada para su uso en URL LDAP (RFC 4516) y en otras aplicaciones.

RFC-4516 Lightweight Directory Access Protocol (LDAP): Uniform Resource Locator

http://www.ietf.org/rfc/rfc4516.txt

Este documento describe un formato para una URL (Uniform Resource Locator) del Lightweight Directory Access Protocol (LDAP). Una URL LDAP describe una operación de búsqueda LDAP que se utiliza para recuperar información de un directorio LDAP o, en el contexto de una remisión o referencia LDAP, una URL LDAP describe un servicio donde se puede progresar una operación LDAP.

RFC-4517 Lightweight Directory Access Protocol (LDAP): Syntaxes and Matching Rules

http://www.ietf.org/rfc/rfc4517.txt

Cada atributo almacenado en un directorio Lightweight Directory Access Protocol (LDAP), cuyos valores pueden transferirse en el protocolo LDAP, tiene una sintaxis definida que restringe la estructura y el formato de sus valores. Las semánticas de comparación para los valores de una sintaxis no forman parte de la definición de la sintaxis, sino que se proporcionan a través de reglas de coincidencia definidas por separado. Las reglas de coincidencia especifican un argumento, un valor de aserción, que también tiene una sintaxis definida. Este documento define un conjunto base de sintaxis y reglas de coincidencia para su uso en la definición de atributos para directorios LDAP.

RFC-4518 Lightweight Directory Access Protocol (LDAP): Internationalized String Preparation

http://www.ietf.org/rfc/rfc4518.txt

Las especificaciones técnicas anteriores del Lightweight Directory Access Protocol (LDAP) no definían con precisión cómo se debían realizar las comparaciones de cadenas de caracteres. Esto provocó una serie de problemas de usabilidad e interoperabilidad. Este documento define algoritmos de preparación de cadenas para reglas de coincidencia basadas en caracteres definidas para su uso en LDAP.

RFC-4519 Lightweight Directory Access Protocol (LDAP): Schema for User Applications

http://www.ietf.org/rfc/rfc4519.txt

Este documento es una parte integral de la especificación técnica del Lightweight Directory Access Protocol (LDAP). Proporciona una especificación técnica de tipos de atributos y clases de objetos destinados a ser utilizados por los clientes de directorio LDAP para muchos servicios de directorio, como las Páginas Blancas. Estos objetos se utilizan ampliamente como base para el esquema en muchos directorios LDAP. Este documento no cubre los atributos utilizados para la administración de servidores de directorio, ni incluye objetos de directorio definidos para usos específicos en otros documentos.

RFC-5020 The Lightweight Directory Access Protocol (LDAP) entryDN Operational Attribute

Abstract Syntax Notation One (ASN.1) define un marco general para anotar tipos en una especificación ASN.1 con instrucciones de codificación que alteran cómo se codifican los valores de esos tipos de acuerdo con las reglas de codificación ASN.1. Este documento define la notación de soporte para instrucciones de codificación que se aplican a las Reglas de Codificación de Cadenas Genéricas (GSER), y en particular define una instrucción de codificación para proporcionar una representación procesable por máquina para la declaración de un tipo ChoiceOfStrings de GSER.

RFC-4530 Lightweight Directory Access Protocol (LDAP) entryUUID Operational Attribute

http://www.ietf.org/rfc/rfc4530.txt

This document describes the LDAP/X.500 'entryUUID' operational attribute and its associated matching rules and syntax. The attribute contains a universally unique identifier (UUID) assigned by the server to the object entry. Directory clients can use this attribute to differentiate objects identified by an entry name or to locate an object after a rename.

RFC-4528 Lightweight Directory Access Protocol (LDAP) Assertion Control

http://www.ietf.org/rfc/rfc4528.txt

This document defines the LDAP (Lightweight Directory Access Protocol) Assertion Control, which allows a client to specify that a directory operation should only be processed if an assertion applied to the target entry of the operation is true. It can be used to build conditional operations such as "test and set", "test and clear", and others.

RFC-4527 Lightweight Directory Access Protocol (LDAP) Read Entry Controls

http://www.ietf.org/rfc/rfc4527.txt

This document specifies an extension to the Lightweight Directory Access Protocol (LDAP) to allow the client to read the target entry of a modify operation. The client can request to read the entry before and/or after the changes have been applied. These reads are performed as an atomic part of the modify operation.

RFC-4526 Lightweight Directory Access Protocol (LDAP) Absolute True and False Filters

http://www.ietf.org/rfc/rfc4526.txt

This document extends the Lightweight Directory Access Protocol (LDAP) to support absolute true and false filters based on similar capabilities found in X.500 directory systems. The document also extends the LDAP search string representation to support these filters.

RFC-4524 COSINE LDAP/X.500 Schema

http://www.ietf.org/rfc/rfc4524.txt

This document provides a collection of schema elements for use with the COSINE LDAP and the Internet X.500 pilot project.

RFC-4523 Lightweight Directory Access Protocol (LDAP) Schema Definitions for X.509 Certificates

http://www.ietf.org/rfc/rfc4523.txt

This document describes the schema for representing X.509 certificates, X.521 security information, and related elements in directories accessible via the Lightweight Directory Access Protocol (LDAP). The schema definitions for these X.509 and X.521 elements are replaced by the definitions provided in RFC 2252 and RFC 2256.

RFC-4522 Lightweight Directory Access Protocol (LDAP): The Binary Encoding Option

http://www.ietf.org/rfc/rfc4522.txt

Each attribute stored in an LDAP directory has a defined syntax (i.e., data type). A syntax definition specifies how attribute values conforming to the syntax are normally represented when transferred in LDAP operations. This representation is called the LDAP-specific encoding to distinguish it from other methods of encoding attribute values. This document defines an attribute option, the binary option, which can be used to specify that associated values should be encoded according to the Basic Encoding Rules (BER) used in X.500 directories.

RFC-4370 Lightweight Directory Access Protocol (LDAP) Proxied Authorization Control

http://www.ietf.org/rfc/rfc4370.txt

This document defines the LDAP (Lightweight Directory Access Protocol) Proxied Authorization Control. The Proxied Authorization Control allows a client to request that an operation be processed under a provided authorization identity instead of under the current authorization identity associated with the connection.

RFC-4104 Policy Core Extension Lightweight Directory Access Protocol Schema (PCELS)

http://www.ietf.org/rfc/rfc4104.txt

This document defines several modifications and extensions to the Policy Core Information Protocol (RFC 3703) Lightweight Directory Access Protocol (LDAP) schema based on the extensions defined by the Policy Core Information Model (PCIM) (RFC 3460). These modifications and extensions consist of new LDAP object classes and attribute types. Some of the schema elements defined in this document reimplement existing concepts according to their new semantics introduced by RFC 3460. The other schema elements implement new concepts not covered by RFC 3703. This document updates RFC 3703.

RFC-3928 Lightweight Directory Access Protocol (LDAP) Client Update Protocol (LCUP)

http://www.ietf.org/rfc/rfc3928.txt

This document defines the LDAP Client Update Protocol (LCUP). The protocol is intended to allow an LDAP client to synchronize with the content of a directory tree (DIT) stored on an LDAP server and to be notified of changes to that content.

RFC-3909 Lightweight Directory Access Protocol (LDAP) Cancel Operation

http://www.ietf.org/rfc/rfc3909.txt

This document describes a Cancel (or Abandon) operation for a pending operation in the Lightweight Directory Access Protocol (LDAP) as an extension. Although different from the Abandon operation in LDAP, but similar to the Abandon operation in the X.511 Directory Access Protocol (DAP), this operation has a response that indicates the outcome of its execution.

RFC-3876 Returning Matched Values with the Lightweight Directory Access Protocol version 3 (LDAPv3)

http://www.ietf.org/rfc/rfc3876.txt

This document describes a control for Lightweight Directory Access Protocol version 3 (LDAPv3) that is used to return a subset of attribute values from an entry. Specifically, only those values that match a "return values" filter. Without support for this control, a client must retrieve all values of an attribute and locate specific values locally.

RFC-3866 Language Tags and Ranges in the Lightweight Directory Access Protocol (LDAP)

http://www.ietf.org/rfc/rfc3866.txt

It is often desirable to indicate the natural language associated with values stored in a directory and to be able to query the directory for values that satisfy a user's language needs. This document details the use of language tags and ranges in the Lightweight Directory Access Protocol (LDAP).

RFC-3727 ASN.1 Module Definition for the LDAP and X.500 Component Matching Rules

http://www.ietf.org/rfc/rfc3727.txt

This document updates the specification of the Lightweight Directory Access Protocol (LDAP) and X.500 directory matching rules (RFC 3687) by gathering the Abstract Syntax Notation (ASN.1) definitions of the component matching rules into a properly identified ASN.1 module so that other documents may refer to the component matching rule definitions from their own ASN.1 modules.

RFC-3703 Policy Core Lightweight Directory Access Protocol (LDAP) Schema

http://www.ietf.org/rfc/rfc3703.txt

This document defines a mapping of the Policy Core Information Model to a format that can be implemented in a directory using the Lightweight Directory Access Protocol (LDAP) as the access protocol. This model defines two hierarchies of object classes: structural classes representing information for representing and controlling policy data according to RFC 3060, and relationship classes indicating how instances of structural classes relate to each other. Classes are also added to the LDAP schema to improve the performance of a client's interactions with an LDAP server when the client retrieves large amounts of policy-related information. These classes exist solely to optimize LDAP queries: there are no classes in the information model that correspond to them.

RFC-3698 Lightweight Directory Access Protocol (LDAP): Additional Matching Rules

http://www.ietf.org/rfc/rfc3698.txt

This document provides a collection of matching rules for use with the Lightweight Directory Access Protocol (LDAP). As these matching rules are simple adaptations of matching rules specified for use with the X.500 directory, most of them are already in wide use.

RFC-3687 Lightweight Directory Access Protocol (LDAP) and X.500 Component Matching Rules

http://www.ietf.org/rfc/rfc3687.txt

Attribute syntaxes in an LDAP or X.500 directory range from simple data types, such as strings, integers, or booleans, to complex structured data types, such as the operational attribute syntaxes of X.500 directory schemas. Matching rules defined for complex syntaxes typically provide only the most immediately useful matching capability. This document defines generic matching rules that can match any selected part of an attribute value of any arbitrarily complex syntax.

RFC-3672 Subentries in the Lightweight Directory Access Protocol (LDAP)

http://www.ietf.org/rfc/rfc3672.txt

In X.500 directories, subentries are special entries used to store information associated with a subtree or a refinement of the subtree. This document adapts the subentry mechanisms of X.500 for use with the Lightweight Directory Access Protocol (LDAP).

Servicio de Páginas Blancas de Internet - Informativo

El propósito fundamental de Internet es permitir la comunicación entre sus usuarios. Solo puede ser efectiva como tal si los usuarios pueden encontrar las direcciones de los demás. Por lo tanto, Internet se beneficia de un Servicio de Páginas Blancas adecuado, es decir, un servicio de directorio que ofrezca información de direcciones (de Internet) relacionada con personas y organizaciones.

Este documento describe la forma en que se aprovecha mejor el Servicio de Páginas Blancas de Internet (de ahora en adelante IWPS) utilizando la experiencia actual, los protocolos actuales, los productos actuales y los procedimientos actuales.

Otras RFC Relacionadas con LDAP - Informativo

RFC-5803 Lightweight Directory Access Protocol (LDAP) Schema for Storing Salted Challenge Response Authentication Mechanism (SCRAM) Secrets

http://www.ietf.org/rfc/rfc5803.txt

Este memorando describe cómo el atributo "authPassword" del Protocolo Ligero de Acceso a Directorios (LDAP) puede usarse para almacenar secretos utilizados por el mecanismo de autenticación de respuesta a desafío salado (SCRAM) en el marco de Simple Authentication and Security Layer (SASL).

RFC-4876 A Configuration Profile Schema for Lightweight Directory Access Protocol (LDAP)-Based Agents

http://www.ietf.org/rfc/rfc4828.txt

Este documento consta de dos componentes principales: un esquema para agentes que utilizan el Protocolo Ligero de Acceso a Directorios (LDAP) y un caso de uso propuesto de ese esquema, para la configuración distribuida de agentes de usuario de directorio similares. Se proponen un conjunto de tipos de atributos y una clase de objeto. En el caso de uso propuesto, los agentes de usuario de directorio (DUA) pueden usar este esquema para determinar la ubicación de los datos del directorio y los parámetros de acceso para servicios específicos que soportan. Además, en el caso de uso propuesto, el mapeo de atributos y clases de objetos permite a los DUA reconfigurar su esquema esperado (predeterminado) para que coincida con el entorno del usuario final. Este documento está destinado a ser un esqueleto para futuros documentos que describan la configuración de servicios DUA específicos.

http://www.ietf.org/rfc/rfc4529.txt

La operación de búsqueda del Protocolo Ligero de Acceso a Directorios (LDAP) proporciona mecanismos para que los clientes soliciten todos los atributos de la aplicación de usuario, todos los atributos operacionales y/o atributos seleccionados por su descripción. Este documento extiende LDAP para soportar un mecanismo que los clientes LDAP puedan usar para solicitar la devolución de todos los atributos de una clase de objeto.

Este documento describe una extensión a la operación Modify del Protocolo Ligero de Acceso a Directorios (LDAP) para soportar una capacidad de incremento. http://www.ietf.org/rfc/rfc4373.txt

El Protocolo de Actualización/Replicación Masiva del Protocolo Ligero de Acceso a Directorios (LDAP) (LBURP) permite a un cliente LDAP realizar una actualización masiva a un servidor LDAP. El protocolo enmarca un conjunto secuenciado de operaciones de actualización dentro de un par de operaciones extendidas de LDAP para notificar al servidor que las operaciones de actualización en el conjunto enmarcado están relacionadas de tal manera que el orden de todas las operaciones puede preservarse durante el procesamiento, incluso cuando son enviadas asincrónicamente por el cliente. Las operaciones de actualización pueden agruparse dentro de un solo mensaje de protocolo para maximizar la eficiencia de la comunicación cliente-servidor.

El protocolo es adecuado para realizar eficientemente un conjunto sustancial de actualizaciones en las entradas de un servidor LDAP.

Las secciones restantes se incluyen solo en este documento, no en la versión UIT-T.

Otras RFCs relacionadas con LDAP - Experimentales

RFC-5805 Protocolo de Acceso Léxico de Directorio (LDAP) de Transacciones

http://www.ietf.org/rfc/rfc5805.txt

Las operaciones de actualización del Protocolo de Acceso Léxico de Directorio (LDAP), como añadir, eliminar o modificar, tienen propiedades ACID (Consistencia, Aislamiento, Durabilidad). Cada una de estas operaciones actúa sobre un entorno. Es deseable actualizar varios entornos en un único conjunto de interacciones, una transacción. Las transacciones son necesarias para dar soporte a varias aplicaciones, incluyendo la provisión de recursos. Este documento extiende el LDAP para dar soporte a transacciones.

RFC-4533 Operaciones de Sincronización de Contenido del LDAP

http://www.ietf.org/rfc/rfc4533.txt

Este documento describe la operación de sincronización de contenido del Protocolo de Acceso Léxico de Directorio (LDAP). La operación permite a un cliente mantener una copia de un fragmento del árbol de información del directorio (DIT). Soporta tanto la espera por cambios como la escucha de cambios. La operación se define como una extensión de la operación de búsqueda del LDAP.

RFC-4531 Operación de "Turn" del Protocolo de Acceso Léxico de Directorio (LDAP)

http://www.ietf.org/rfc/rfc4531.txt

Este documento describe una operación de extensión del Protocolo de Acceso Léxico de Directorio (LDAP) para revertir (o "turn") los roles del cliente y del servidor para las interacciones siguientes en el protocolo, o para permitir que cada lado actúe como cliente y servidor con respecto al otro.

RFC-3663 Datos de Administración de Dominio en el Protocolo de Acceso Léxico de Directorio (LDAP)

http://www.ietf.org/rfc/rfc3663.txt

Los datos de registro de dominio se han expuesto al público general a través de Nicname/Whois con fines administrativos. Este documento describe el Servicio de Refuerzo del Protocolo de Acceso Léxico de Directorio (LDAP), un servicio experimental que utiliza LDAP y tipos bien conocidos para mostrar datos de administración de dominio.

RFC-3088 Servicio de Referencia del Directorio de LDAP - Un servicio experimental

http://www.ietf.org/rfc/rfc3088.txt

El Proyecto OpenLDAP opera un servicio de referencias de LDAP (Protocolo de Acceso Léxico de Directorio) experimental conocido como "OpenLDAP Root Service". El sistema automatizado genera referencias basadas en la información de ubicación publicada en los registros DNS SRV (registros de ubicación de servicios en el sistema de nombres). Este documento describe este servicio.

RFC-2657 Cliente LDAPv2 vs. el Index Mesh

http://www.ietf.org/rfc/rfc2657.txt

Los clientes LDAPv2 implementados según RFC 1777 no tienen conocimiento de las referencias. La integración entre tales clientes y el Index Mesh, como se define en el Protocolo de Indexación Común, depende en gran medida de las referencias y, por lo tanto, necesita ser gestionada de forma especial. Este documento define una manera posible de lograrlo.

RFC-2649 Operaciones Dirigidas con S/MIME

http://www.ietf.org/rfc/rfc2649.txt

Este documento define un mecanismo de LDAPv3 para firmar operaciones de directorio con el fin de crear un registro seguro de cambios realizados en cada entrada del directorio. Se admiten firmas tanto del cliente como del servidor. También se define una clase de objeto para recuperar posteriormente estas entradas. Este documento especifica los controles LDAPv3 que permiten esta funcionalidad. También define un esquema LDAPv3 que permite la navegación posterior de la información del registro.

RFC-2307 Una Estrategia para Usar LDAP como Servicio de Información de Red

http://www.ietf.org/rfc/rfc2307.txt

Este documento describe un mecanismo experimental para mapear entidades relacionadas con TCP/IP y el sistema UNIX en entradas X.500 para que puedan ser resueltas mediante LDAP. Se propone un conjunto de tipos de atributos y clases de objetos, junto con guías específicas para interpretarlos. El propósito es ayudar en la implementación de LDAP como un servicio de nombres organizacional. No se incluyen soluciones propuestas como estándares para Internet. Se espera que se alcance un consenso general sobre la solución adecuada a tales problemas, lo que eventualmente conducirá a la adopción de estándares. El mecanismo propuesto ya se ha implementado con éxito.

RFCs vencidos pero aún interesantes de Internet Drafts

draft-wahl-ldap-adminaddr -- Dirección de Administrador de Atributo

Las organizaciones que operan múltiples servidores de directorio necesitan una capacidad para que los administradores determinen quién es el responsable de un servidor dado. Esta idea es conceptualmente similar a la 'sysContact' de SNMP. El atributo adminAddr permite a un administrador de servidor proporcionar información de contacto del responsable de un servidor LDAP. Esto puede ser utilizado por clientes de gestión que, por ejemplo, verifican el estado de una replicación o topología de referencias, para permitir que el usuario del cliente de gestión envíe correo a un administrador de un servidor específico.

draft-zeilenga-ldap-noop -- Control de No-Op del LDAP

Este documento define el control de LDAP No-Op que puede usarse para desactivar el efecto normal de una operación. El control puede usarse para descubrir cómo podría reaccionar un servidor a una solicitud de actualización específica sin actualizar el directorio.

draft-legg-ldap-transfer -- Transferencia de

Este documento define una operación de transferencia de LDAPv3 que permite transferir archivos entre servidores de directorio. La operación se basa en el modelo de transferencia de archivos estándar, con el objetivo de facilitar la transferencia de archivos entre servidores de directorio.

Other LDAP Related RFCs - Experimental

draft-peterson-ldap-transfer -- LDAP: Transfer Encoding Options

Cada atributo almacenado en un directorio LDAP (Protocolo de Acceso a Directorios Ligero) tiene una sintaxis definida (es decir, tipo de dato). Una definición de sintaxis especifica cómo se representan normalmente los valores de atributo que se ajustan a la sintaxis cuando se transfieren en operaciones LDAP. Esta representación se conoce como la codificación específica de LDAP para distinguirla de otros métodos de codificación de valores de atributo. Este documento introduce una nueva categoría de opciones de atributos, denominadas opciones de codificación de transferencia, que se pueden utilizar para especificar que los valores de atributos asociados están codificados de acuerdo con uno de estos otros métodos.

draft-furuseth-ldap-untypedobject -- Structural object class 'namedObject' for LDAP/X.500

Este documento define una clase de objeto estructural 'namedObject' para LDAP (Protocolo de Acceso a Directorios Ligero) y X.500. Esto es útil para entradas que no tienen una elección natural de clase de objeto estructural, por ejemplo, si una entrada debe existir aunque su contenido no sea interesante.

draft-wahl-ldap-p3p -- P3P Policy Attributes for LDAP

Este documento define atributos que se pueden recuperar a través de solicitudes de LDAP (Protocolo de Acceso a Directorios Ligero) versión 3, que contienen URIs que apuntan a los documentos de política de privacidad. Estos documentos describen la política de privacidad relacionada con el acceso a un servidor de directorio y las políticas de privacidad que se aplican al contenido del directorio (un subárbol de entradas).

draft-chu-ldap-xordered -- Ordered Entries and Values in LDAP

A medida que LDAP se utiliza de manera más extensa para gestionar diversos tipos de datos, a menudo surge la necesidad de preservar tanto el orden como el contenido de los datos, a pesar de la estructura inherentemente desordenada de las entradas y los valores de los atributos en el directorio. Este documento describe un esquema para adjuntar información de ordenación a los atributos en un directorio para que el orden pueda preservarse y propagarse a otras aplicaciones LDAP.

draft-chu-ldap-logschema -- A Schema for Logging the LDAP Protocol

Para facilitar la administración remota y la auditoría del funcionamiento del servidor LDAP, es deseable proporcionar los registros operativos del servidor como un directorio LDAP consultable. Estos registros también pueden utilizarse como un registro de cambios persistente para admitir diversos mecanismos de replicación. Este documento define un esquema que puede utilizarse para representar todas las solicitudes que han sido procesadas por un servidor LDAP. Puede ser utilizado por diversas aplicaciones para auditoría, grabadora de vuelo, replicación y otros fines.

draft-zeilenga-ldap-relax -- The LDAP Relax Rules Control

Este documento define el Control de Reglas Relajadas de LDAP (Protocolo de Acceso a Directorios Ligero) que permite a un agente de usuario de directorio (un cliente) solicitar al servicio de directorio que relaje temporalmente la aplicación de diversas reglas de datos y modelos de servicio.

draft-gpaterno-dhcp-ldap -- DHCP Option for LDAP Directory Services discovery

Este documento define una nueva opción DHCP para la entrega de información de configuración para servicios de directorio LDAP. A través de esta opción, el cliente recibe una URL LDAP [8] del servidor/réplica LDAP más cercano disponible que puede utilizarse para autenticar usuarios o buscar cualquier dato útil.

draft-schleiff-ldap-xri -- LDAP Schema for eXtensible Resource Identifier (XRI)

Este documento describe Tipos de Atributos y una Clase de Objeto para su uso en la representación de valores XRI (Identificador de Recurso Extensible) en servicios de directorio LDAP (Protocolo de Acceso a Directorios Ligero) y X.500.

draft-wahl-ldap-session -- LDAP Session Tracking Control

Muchos dispositivos de red, servidores de aplicaciones y componentes de middleware de una infraestructura de software empresarial generan alguna forma de identificadores de seguimiento de sesión, que son útiles al analizar la actividad y los registros de contabilidad para agrupar la actividad relacionada con una sesión en particular. Este documento discute cómo los clientes LDAP (Protocolo de Acceso a Directorios Ligero) versión 3 pueden incluir identificadores de seguimiento de sesión con sus solicitudes LDAP. Esta información se proporciona a través de controles en las solicitudes que los clientes envían a los servidores LDAP. El servidor LDAP que recibe estos controles puede incluir los identificadores de seguimiento de sesión en los mensajes de registro que escribe, lo que permite correlacionar las solicitudes LDAP en los registros del servidor LDAP con la actividad en los registros de otros componentes de la infraestructura. El control también permite que los servidores LDAP generen información de seguimiento de sesión y la devuelvan a los clientes y otros servidores. En este documento se definen tres formatos de identificadores de seguimiento de sesión.

draft-wahl-ldap-subtree-source -- LDAP Subtree Data Source URI Attribute

Este documento define un atributo que permite a los clientes administrativos que utilizan el Protocolo de Acceso a Directorios Ligero (LDAP) determinar la fuente de las entradas del directorio.

draft-ietf-ldapext-psearch -- Persistent Search: A Simple LDAP Change Notification Mechanism

Este documento define dos controles que extienden la operación de búsqueda de LDAPv3 para proporcionar un mecanismo simple mediante el cual un cliente LDAP puede recibir notificaciones de cambios que ocurren en un servidor LDAP. El mecanismo está diseñado para ser muy flexible y, al mismo tiempo, fácil de implementar para clientes y servidores.

draft-ietf-ldapext-ldapv3-vlv -- LDAP Extensions for Scrolling View Browsing of Search Results

Este documento describe una extensión de control de Vista de Lista Virtual para la operación de Búsqueda LDAP. Este control está diseñado para permitir la característica de "cuadro de lista virtual", común en las aplicaciones de libreta de direcciones de correo electrónico comerciales existentes, para ser soportada eficientemente por los servidores LDAP. La incapacidad de los servidores LDAP para soportar esta característica del cliente es un impedimento significativo para que LDAP reemplace los protocolos propietarios en los sistemas de correo electrónico comerciales.

El control permite a un cliente especificar que el servidor devuelva, para una búsqueda LDAP dada con claves de ordenación asociadas, un subconjunto contiguo del conjunto de resultados de la búsqueda. Este subconjunto se especifica en términos de desplazamientos en la lista ordenada, o en términos de un valor de comparación mayor o igual.
