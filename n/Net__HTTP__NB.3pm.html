Net__HTTP__NB(3pm)

Paquete: perl-net-http

Licencias: PerlArtistic, GPL

Net::HTTP::NB(3) Documentación de Perl contribuida por el usuario Net::HTTP::NB(3)

NOMBRE

Net::HTTP::NB - Cliente HTTP no bloqueante

VERSIÓN

versión 6.24

SINOPSIS

use Net::HTTP::NB;
my $s = Net::HTTP::NB->new(Host => "www.perl.com") || die $@;
$s->write_request(GET => "/");
use IO::Select;
my $sel = IO::Select->new($s);
READ_HEADER: {
   die "Encabezado expirado" unless $sel->can_read(10);
   my($code, $mess, %h) = $s->read_response_headers;
   redo READ_HEADER unless $code;
}
while (1) {
   die "Cuerpo expirado" unless $sel->can_read(10);
   my $buf;
   my $n = $s->read_entity_body($buf, 1024);
   last unless $n;
   print $buf;
}

DESCRIPCIÓN

Misma interfaz que "Net::HTTP" pero nunca intentará múltiples lecturas cuando se invocan los métodos read_response_headers() o read_entity_body(). Esto hace posible multiplexar múltiples Net::HTTP::NB usando select sin riesgo de bloqueo.

Si read_response_headers() no vio suficientes datos para completar los encabezados, se devuelve una lista vacía.

Si read_entity_body() no vio nuevos datos de entidad en su lectura, se devuelve el valor -1.
