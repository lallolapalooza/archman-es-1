Net::LDAP::FilterMatch(3) Documentación de Perl contribuida por el usuario Net::LDAP::FilterMatch(3)

NOMBRE

Net::LDAP::FilterMatch - Coincidencia de entradas LDAP

SINOPSIS

use Net::LDAP::Entry;
use Net::LDAP::Filter;
use Net::LDAP::FilterMatch;
my $entry = new Net::LDAP::Entry;
$entry->dn("cn=dummy entry");
$entry->add (
 'cn' => 'dummy entry',
 'street' => [ '1 some road','nowhere' ] );
my @filters = (qw/(cn=dummy*)
               (ou=*)
               (&(cn=dummy*)(street=*road))
               (&(cn=dummy*)(!(street=nowhere)))/);
for (@filters) {
  my $filter = Net::LDAP::Filter->new($_);
  print $_,' : ', $filter->match($entry) ? 'match' : 'no match' ,"\n";
}

RESUMEN

Esta extensión de la clase Net::LDAP::Filter proporciona funcionalidad de coincidencia de entradas en el lado de Perl.

Dada una entrada, indicará si la entrada coincide con el objeto de filtro.

Se puede utilizar de forma independiente o como parte de un servidor LDAP basado en Net::LDAP::Server.

MÉTODO

match ( ENTRADA [ ,ESQUEMA ] )
Devuelve si ENTRADA coincide con el objeto de filtro. Si se proporciona un objeto de esquema, la selección de algoritmos de coincidencia se derivará del esquema.

En caso de error, se devuelve undef.

Para coincidencias aproximadas como (cn~=Schmidt) existen varios módulos que se pueden utilizar. Por defecto, se intentarán los siguientes módulos en este orden:

String::Approx
Text::Metaphone
Text::Soundex

Si ninguno de estos módulos se encuentra, recurrirá a un algoritmo simple de expresiones regulares.

Si desea utilizar específicamente solo una implementación, simplemente haga:

use Net::LDAP::FilterMatch qw(Text::Soundex);
