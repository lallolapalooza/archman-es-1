Net::LDAP::Message(3) Documentación de Perl contribuida por el usuario Net::LDAP::Message(3)

NOMBRE

Net::LDAP::Message - Mensaje de respuesta del servidor LDAP

SINOPSIS

use Net::LDAP;

DESCRIPCIÓN

Net::LDAP::Message es una clase base para los objetos devueltos por los métodos abandon, add, bind, compare, delete, modify, moddn, search y unbind de Net::LDAP.

La sub-clase Net::LDAP::Search devuelta por search también define muchos métodos.

Si el objeto Net::LDAP está en modo asíncrono, todos estos métodos, excepto "done" y "mesg_id", provocarán una espera hasta que la solicitud se complete.

MÉTODOS

código ( )
El valor del código en el mensaje de resultado del servidor. Normalmente, un cero indica éxito. Las constantes para los códigos de resultado se pueden importar de los módulos Net::LDAP o Net::LDAP::Constant.
control ( [ OID, ... ] )
Devuelve la lista de controles que se recibieron del servidor. Si se proporcionan uno o más OID como argumentos, devuelve solo los controles de los OID dados.
dn ( )
El DN en el mensaje de resultado del servidor.
hecho ( )
Devuelve *verdadero* si la solicitud se ha completado.
error ( )
Devuelve el mensaje de error en el mensaje de resultado del servidor. Si el servidor no incluyó un mensaje de error, entonces el resultado de ldap_error_desc con el código de error del mensaje de resultado.
nombre_error ( )
Devuelve el nombre del código de error en el mensaje de resultado del servidor. Consulte ldap_error_name para una descripción detallada del valor de retorno.
texto_error ( )
Devuelve la descripción textual corta del código de error en el mensaje de resultado del servidor. Consulte ldap_error_text para una descripción detallada del valor de retorno.
desc_error ( )
Devuelve una descripción textual larga del código de error en el mensaje de resultado del servidor. Consulte ldap_error_desc para una descripción detallada del valor de retorno.
es_error ( )
Devuelve *verdadero* si el código de resultado se considera un error para la operación.
id_mensaje ( )
El ID del mensaje de la solicitud enviada al servidor.
referencias ( )
Devuelve una lista de referencias del mensaje de resultado.
error_servidor ( )
El mensaje de error devuelto por el servidor, o "undef" si el servidor no proporcionó un mensaje.
sincronizar ( )
Espera a que el servidor complete la solicitud.

VER TAMBIÉN

Net::LDAP, Net::LDAP::Search, Net::LDAP::Constant, Net::LDAP::Util
