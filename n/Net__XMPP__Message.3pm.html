NOMBRE

Net::XMPP::Message - Módulo de Mensajes XMPP

SINOPSIS

Net::XMPP::Message es un complemento del módulo Net::XMPP.
Proporciona al usuario una interfaz sencilla para establecer y recuperar
todas las partes de un Mensaje XMPP.

DESCRIPCIÓN

Un objeto Net::XMPP::Message se pasa a la función de devolución de llamada
para el mensaje. Además, el primer argumento de las funciones de devolución de
llamada es el ID de sesión de XML::Stream. Hay algunos casos en los que podrías
querer esta información, como si crearas un Cliente que se conecta a dos
servidores a la vez, o para escribir un mini servidor.
  use Net::XMPP;
  sub mensaje {
    my ($sid,$Mess) = @_;
    .
    .
    .
  }
Ahora tienes acceso a todas las funciones de recuperación disponibles.
Para crear un nuevo mensaje para enviarlo al servidor:
  use Net::XMPP;
  $Mess = Net::XMPP::Message->new();
Ahora puedes llamar a las funciones de creación a continuación para poblar la
etiqueta antes de enviarla.

MÉTODOS

Funciones de recuperación

GetTo()      - devuelve el valor del atributo to='' para el
GetTo("jid")   <message/>. Si especificas "jid" como argumento
               entonces se devuelve un objeto Net::XMPP::JID y
               puedes analizar fácilmente las partes del JID.
               $to    = $Mess->GetTo();
               $toJID = $Mess->GetTo("jid");
GetFrom()      - devuelve el valor del atributo from='' para el
GetFrom("jid")   <message/>. Si especificas "jid" como argumento
                 entonces se devuelve un objeto Net::XMPP::JID y
                 puedes analizar fácilmente las partes del JID.
                 $from    = $Mess->GetFrom();
                 $fromJID = $Mess->GetFrom("jid");
GetType() - devuelve el atributo type='' del <message/>. Cada
            mensaje es de uno de los cuatro tipos:
              normal        mensaje regular (por defecto si el tipo está en blanco)
              chat          chat uno a uno
              groupchat     chat grupal
              headline      titular
              error         mensaje de error
            $type = $Mess->GetType();
GetSubject() - devuelve los datos de la etiqueta <subject/>.
               $subject = $Mess->GetSubject();
GetBody() - devuelve los datos de la etiqueta <body/>.
            $body = $Mess->GetBody();
GetThread() - devuelve los datos de la etiqueta <thread/>.
              $thread = $Mess->GetThread();
GetError() - devuelve una cadena con los datos de la etiqueta <error/>.
             $error = $Mess->GetError();
GetErrorCode() - devuelve una cadena con el atributo code='' del
                 etiqueta <error/>.
                 $errCode = $Mess->GetErrorCode();
GetTimeStamp() - devuelve una cadena que representa la hora en que este
                 objeto de mensaje fue creado (y probablemente recibido)
                 para enviarlo al cliente. Si hay una etiqueta
                 jabber:x:delay, entonces se usa esa hora para mostrar
                 cuándo se envió el mensaje.
                 $date = $Mess->GetTimeStamp();

Funciones de creación

SetMessage(to=>cadena|JID,    - establece múltiples campos en el <message/>
           from=>cadena|JID,    a la vez. Esta es una acción acumulativa
           type=>cadena,        y de sobrescritura. Si estableces
           subject=>cadena,     el atributo "to" dos veces, la segunda
           body=>cadena,        configuración es la que se usa. Si estableces
           thread=>cadena,      el asunto y luego el cuerpo, entonces
           errorcode=>cadena,   ambos estarán en la etiqueta <message/>.
           error=>cadena)       Para configuraciones válidas, lee las
                                funciones Set específicas a continuación.
                          $Mess->SetMessage(TO=>"bob\@jabber.org",
                                            Subject=>"Almuerzo",
                                            BoDy=>"¡Vamos a almorzar!");
                          $Mess->SetMessage(to=>"bob\@jabber.org",
                                            from=>"jabber.org",
                                            errorcode=>404,
                                            error=>"No encontrado");
SetTo(cadena) - establece el atributo to=''. Puedes pasar
SetTo(JID)      una cadena o un objeto JID. Deben ser JIDs válidos
                o el servidor devolverá un mensaje de error.
                (ej. bob@jabber.org/Trabajo)
                $Mess->SetTo("test\@jabber.org");
SetFrom(cadena) - establece el atributo from=''. Puedes pasar
SetFrom(JID)      una cadena o un objeto JID. Deben ser JIDs válidos
                  o el servidor devolverá un mensaje de error. (ej.
                  jabber:bob@jabber.org/Trabajo) Este campo no es
                  obligatorio si estás escribiendo un Cliente, ya que
                  el servidor pondrá el JID de tu conexión allí para
                  evitar spam.
                  $Mess->SetFrom("yo\@jabber.org");
SetType(cadena) - establece el atributo type. Configuraciones válidas son:
                    normal         mensaje regular (por defecto si está en blanco)
                    chat           mensaje estilo chat uno a uno
                    groupchat      mensaje de sala de chat grupal
                    headline       titular de noticias, cotización de bolsa, etc...
                    error          mensaje de error
                  $Mess->SetType("groupchat");
SetSubject(cadena) - establece el asunto del <message/>.
                     $Mess->SetSubject("Esto es una prueba");
SetBody(cadena) - establece el cuerpo del <message/>.
                  $Mess->SetBody("Ser o no ser...");
SetThread(cadena) - establece el hilo del <message/>. Deberías
                    copiarlo del mensaje al que se está respondiendo
                    para que el hilo se mantenga.
                    $Mess->SetThread("AE912B3");
SetErrorCode(cadena) - establece el código de error del <message/>.
                       $Mess->SetErrorCode(403);
SetError(cadena) - establece la cadena de error del <message/>.
                   $Mess->SetError("Permiso denegado");
Reply(hash) - crea un nuevo objeto Message y rellena
              el to/from, y el asunto poniendo "re: " delante.
              Si especificas un hash, igual que con
              SetMessage, esos valores anularán los
              valores de Reply.
              $Reply = $Mess->Reply();
              $Reply = $Mess->Reply(type=>"chat");
