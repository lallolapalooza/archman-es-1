Net::LDAP::Reference(3) Documentación aportada por el usuario de Perl Net::LDAP::Reference(3)

NOMBRE

Net::LDAP::Reference - referencia de búsqueda

SINOPSIS

use Net::LDAP;
$ldap->search( @search_args, callback => \&process);
sub process {
  my $mesg = shift;
  my $obj = shift;
  if (!$obj) {
    # Búsqueda completa
  }
  elsif ($obj->isa('Net::LDAP::Reference')) {
    my $ref;
    foreach $ref ($obj->references) {
      # procesar ref
    }
  }
  else {
    # Procesar Net::LDAP::Entry
  }
}

DESCRIPCIÓN

El objeto Net::LDAP::Reference representa una referencia (a veces llamada "remisión") devuelta por el directorio desde una búsqueda.

MÉTODOS

references
Devuelve una lista de referencias del servidor.

VER TAMBIÉN

Net::LDAP, Net::LDAP::Search
