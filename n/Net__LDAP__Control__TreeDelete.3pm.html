NOMBRE

Net::LDAP::Control::TreeDelete - Objeto de control de borrado de árbol LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::TreeDelete;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$treedel = Net::LDAP::Control::TreeDelete->new( critical => 1 );
$msg = $ldap->delete( 'o=University of Michigan,c=US',
                      control  => [ $treedel ] );
die "error: ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPCIÓN

"Net::LDAP::Control::TreeDelete" proporciona una interfaz para la creación y manipulación de objetos que representan el control "TreeDelete" tal como se describe en draft-armijo-ldap-treedelete-02.txt https://tools.ietf.org/html/draft-armijo-ldap-treedelete-02

Permite al cliente eliminar un subárbol completo.

El control es apropiado para operaciones de borrado LDAP [RFC4511] solamente, e inapropiado para todas las demás operaciones.

Su criticidad puede ser VERDADERA o FALSA; no tiene valor.

No existe un control de respuesta correspondiente.

ARGUMENTOS DEL CONSTRUCTOR

Dado que el control "TreeDelete" no tiene valores, solo se admiten los argumentos del constructor descritos en Net::LDAP::Control.

MÉTODOS

Dado que no hay valores adicionales en el control, solo los métodos en Net::LDAP::Control están disponibles para los objetos "Net::LDAP::Control::TreeDelete".
