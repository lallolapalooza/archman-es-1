NOMBRE

Net::DNS::RR::LP - registro de recursos DNS LP

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre IN LP preferencia FQDN');

DESCRIPCIÓN

Clase para registros de recursos (RR) de DNS Locator Pointer (LP).

El registro de recursos (RR) DNS LP se utiliza para mantener el nombre de una subred para ILNP. El nombre es un FQDN que luego se puede utilizar para buscar registros L32 o L64. LP es, efectivamente, un puntero localizador a registros L32 y/o L64.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas, ya que podrían provocar la terminación del programa u otros comportamientos impredecibles.

preferencia

$preferencia = $rr->preferencia;
$rr->preferencia( $preferencia );

Un entero sin signo de 16 bits en orden de bytes de red que indica la preferencia relativa de este registro LP entre otros registros LP asociados con este nombre de propietario. Los valores más bajos son preferidos sobre los valores más altos.

FQDN, fqdn

objetivo

$objetivo = $rr->objetivo;
$rr->objetivo( $objetivo );

El campo FQDN contiene el nombre de destino DNS que se utiliza para referenciar registros L32 y/o L64.
