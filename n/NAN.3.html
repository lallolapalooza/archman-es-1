INFINITY(3) Manual de funciones de biblioteca INFINITY(3)

NOMBRE

INFINITY, NAN, HUGE_VAL, HUGE_VALF, HUGE_VALL - constantes de punto flotante

BIBLIOTECA

Biblioteca matemática (libm)

SINOPSIS

#define _ISOC99_SOURCE      /* Véase feature_test_macros(7) */
#include <math.h>
INFINITY
NAN
HUGE_VAL
HUGE_VALF
HUGE_VALL

DESCRIPCIÓN

La macro INFINITY se expande a una constante de tipo float que representa infinito positivo.

La macro NAN se expande a una constante de tipo float que representa un NaN silencioso (cuando es compatible). Un NaN *silencioso* es un NaN ("not-a-number", no es un número) que no genera excepciones cuando se utiliza en operaciones aritméticas. Lo opuesto es un NaN *señalizador*. Consultar IEC 60559:1989.

Las macros HUGE_VAL, HUGE_VALF, HUGE_VALL se expanden a constantes de tipos double, float y long double, respectivamente, que representan un valor positivo grande, posiblemente infinito positivo.

ESTÁNDARES

C11.

HISTORIA

C99.

En un sistema glibc, la macro HUGE_VAL siempre está disponible. La disponibilidad de la macro NAN se puede probar usando #ifdef NAN, y de manera similar para INFINITY, HUGE_VALF, HUGE_VALL. Serán definidas por <math.h> si _ISOC99_SOURCE o _GNU_SOURCE están definidos, o si __STDC_VERSION__ está definido y tiene un valor no menor que 199901L.

VER TAMBIÉN

fpclassify(3), math_error(7)
