NOMBRE

Net::DNS::Resolver::Base - Clase base del resolutor DNS

SINOPSIS

use base qw(Net::DNS::Resolver::Base);

DESCRIPCIÓN

Esta clase es la clase base común para las subclases de Net::DNS::Resolver específicas de la plataforma.

No hay partes que el usuario pueda reparar dentro; consulta Net::DNS::Resolver para todas tus necesidades de resolución.
