Net::LDAP::Control::EntryChange(3) Documentación de Perl contribuida por el usuario Net::LDAP::Control::EntryChange(3)

NOMBRE

Net::LDAP::Control::EntryChange - Objeto de control de notificación de cambio de entrada LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::PersistentSearch;
use Net::LDAP::Constant qw(LDAP_CONTROL_ENTRYCHANGE);
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$persist = Net::LDAP::Control::PersistentSearch->new( changeTypes => 15,
                                                      changesOnly => 1,
                                                      returnECs => 1 );
$srch = $ldap->search( base     => "cn=People,dc=mydomain,dc=eg",
                       filter   => "(objectClass=person)",
                       callback => \&process_entry, # llamar para cada entrada
                       control  => [ $persist ] );
die "error: ",$srch->code(),": ",$srch->error()  if ($srch->code());
sub process_entry {
  my $message = shift;
  my $entry = shift;
  my ($control) = $message->control(LDAP_CONTROL_ENTRYCHANGE);
  print $control->changeType()."\t".$entry->dn()."\n";
}

DESCRIPCIÓN

"Net::LDAP::Control::EntryChange" proporciona una interfaz para la creación y manipulación de objetos que representan el control "EntryChangeNotification" como se describe en draft-smith-psearch-ldap-03.txt.

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control, se proporcionan los siguientes.

tipoCambio
Un valor entero que indica el tipo de operación LDAP que ha sufrido la entrada. Es uno de los siguientes valores (que representan las operaciones LDAP indicadas a continuación):
1 = add
2 = delete
4 = modify
8 = modDN
dnAnterior
Cuando tipoCambio es 8 (para modDN), este parámetro indica el DN de la entrada antes de la operación modDN. En todos los demás casos, este valor no está definido.
numeroCambio
Este es el número de cambio según <draft-good-ldap-changelog-03.txt> asignado por un servidor para el cambio. Si un servidor soporta un registro de cambios LDAP, debería incluir este campo.

Normalmente, no necesita crear un control de "Net::LDAP::Control::EntryChange" usted mismo, ya que es proporcionado por el servidor en respuesta a una opción con el control "Net::LDAP::Control::PersistentSearch".

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto que devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.
