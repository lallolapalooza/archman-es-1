NOMBRE

Net::DNS::DomainName - representación de nombres DNS

SINOPSIS

use Net::DNS::DomainName;
$objeto = Net::DNS::DomainName->new('ejemplo.com');
$nombre = $objeto->name;
$datos = $objeto->encode;
( $objeto, $siguiente ) = Net::DNS::DomainName->decode( \$datos, $offset );

DESCRIPCIÓN

El módulo Net::DNS::DomainName implementa la representación concreta de los nombres de dominio DNS utilizados dentro de los paquetes DNS.

Net::DNS::DomainName define métodos para codificar y decodificar cadenas de octetos en formato de cable. Todo el comportamiento restante se hereda de Net::DNS::Domain.

Los paquetes Net::DNS::DomainName1035 y Net::DNS::DomainName2535 implementan subtipos de nombres de dominio disjuntos que proporcionan la compresión de nombres y la canonicalización especificadas por RFC1035 y RFC2535. Estos son necesarios para cumplir con los requisitos de compatibilidad hacia atrás introducidos por RFC3597.

MÉTODOS

new

$objeto = Net::DNS::DomainName->new('ejemplo.com');

Crea un objeto de nombre de dominio que identifica el dominio especificado por el argumento de cadena de caracteres.

decode

$objeto = Net::DNS::DomainName->decode( \$buffer, $offset, $hash );
( $objeto, $siguiente ) = Net::DNS::DomainName->decode( \$buffer, $offset, $hash );

Crea un objeto de nombre de dominio que representa el nombre de dominio DNS identificado por los datos en formato de cable en el desplazamiento indicado dentro del búfer de datos.

La lista de argumentos consta de una referencia a un escalar que contiene los datos en formato de cable y el desplazamiento especificado. La referencia opcional a una tabla hash proporciona una mayor eficiencia al decodificar nombres comprimidos al aprovechar punteros de compresión ya almacenados en caché.

El valor de desplazamiento devuelto indica el inicio del siguiente elemento en el búfer de datos.

encode

$datos = $objeto->encode;

Devuelve la representación en formato de cable del nombre de dominio adecuada para su inclusión en un búfer de paquete DNS.

canonical

$datos = $objeto->canonical;

Devuelve la representación canónica en formato de cable del nombre de dominio tal como se define en RFC2535(8.1).

Net::DNS::DomainName1035

Net::DNS::DomainName1035 implementa una subclase de objetos de nombre de dominio que deben codificarse utilizando el formato de cable comprimido definido en RFC1035.

$datos = $objeto->encode( $offset, $hash );

Los argumentos son el desplazamiento dentro de los datos del paquete donde se almacenará el nombre de dominio y una referencia a una tabla hash utilizada para indexar nombres comprimidos dentro del paquete.

Tenga en cuenta que RFC3597 implica que solo los tipos de RR definidos en RFC1035(3.3) son elegibles para la compresión de nombres de dominio que aparecen en RDATA.

Si la referencia hash no está definida, encode() devuelve la representación canónica en minúsculas sin comprimir definida en RFC2535(8.1).

Net::DNS::DomainName2535

Net::DNS::DomainName2535 implementa una subclase de objetos de nombre de dominio que deben codificarse utilizando formato de cable sin comprimir.

$datos = $objeto->encode( $offset, $hash );

Los argumentos son el desplazamiento dentro de los datos del paquete donde se almacenará el nombre de dominio y una referencia a una tabla hash utilizada para indexar nombres ya codificados dentro del paquete.

Si la referencia hash no está definida, encode() devuelve la representación canónica en minúsculas sin comprimir definida en RFC2535(8.1).

Tenga en cuenta que RFC3597, y posteriormente RFC4034, especifican que la forma canónica en minúsculas se utilizará para los tipos de RR definidos antes de RFC3597.
