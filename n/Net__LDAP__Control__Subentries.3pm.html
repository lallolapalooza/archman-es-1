Net::LDAP::Control::Subentries(3) Documentación de Perl aportada por el usuario Net::LDAP::Control::Subentries(3)

NOMBRE

Net::LDAP::Control::Subentries - objeto de control de subentradas de LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::Subentries;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$subentries = Net::LDAP::Control::Subentries->new( visibilidad => 1 );
$msg = $ldap->search( base => 'dc=sub,dc=mydomain,dc=eg",
                      filtro => '(objectclass=*)',
                      attrs => [ qw/1.1/ ],
                      control => [ $subentries ] );
die "error: ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPCIÓN

"Net::LDAP::Control::Subentries" proporciona una interfaz para la creación y manipulación de objetos que representan el control "Subentries" como se describe en la RFC 3672.

Este control, para el cual no existe un control de respuesta correspondiente, es apropiado solo para operaciones de búsqueda LDAP.

En ausencia de este control, las subentradas solo son visibles para las solicitudes de búsqueda LDAP con "ámbito => 'base'", pero no para las búsquedas con cualquier otro valor de "ámbito".

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control se proporcionan los siguientes:

visibilidad
Un valor booleano que indica la visibilidad de las subentradas o entradas regulares.

El valor "VERDADERO" indica que las subentradas son visibles y las entradas normales no lo son; el valor "FALSO" indica que las entradas normales son visibles y las subentradas no lo son.

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto, el cual devolverá el valor actual del atributo si se llama sin argumentos y establecerá un nuevo valor para el atributo si se llama con un argumento.
