NOMBRE

Net::DNS::SEC::Tools::defaults - Valores por defecto de DNSSEC-Tools.

SINOPSIS

use Net::DNS::SEC::Tools::defaults;
%defs = dnssec_tools_alldefaults();
$defalg = dnssec_tools_default("algorithm");
$cz_path = dnssec_tools_default("zonecheck");
$ksklife = dnssec_tools_default("ksklife");
@default_names = dnssec_tools_defnames();

DESCRIPCIÓN

Este módulo mantiene un conjunto de valores por defecto utilizados por los programas de DNSSEC-Tools. Esto permite que estos valores por defecto se centralicen en un solo lugar y evita que se extiendan por múltiples programas.

INTERFACES

dnssec_tools_alldefaults()
Esta interfaz devuelve una copia de todos los valores por defecto de DNSSEC-Tools en una tabla hash.
dnssec_tools_default(default)
Esta interfaz devuelve el valor de un valor por defecto de DNSSEC-Tools. Se pasa a la interfaz default, que es el nombre de un valor por defecto a buscar. El valor de este valor por defecto se devuelve al llamante.
dnssec_tools_defnames()
Esta interfaz devuelve los nombres de todos los valores por defecto de DNSSEC-Tools. No se devuelven valores por defecto, pero los nombres de los valores por defecto devueltos por dnssec_tools_defnames() pueden pasarse posteriormente a dnssec_tools_default().

CAMPOS POR DEFECTO

Los siguientes son los valores por defecto definidos para DNSSEC-Tools.

admin-email
Este valor por defecto contiene la dirección de correo electrónico por defecto del administrador de DNSSEC-Tools.
archivedir
Este valor por defecto contiene el directorio por defecto donde se archivan las claves.
algorithm
Este valor por defecto contiene el algoritmo de cifrado por defecto.
enddate
Este valor por defecto contiene la vida útil de la zona por defecto, en segundos.
entropy_msg
Este valor por defecto indica si zonesigner debe mostrar o no un mensaje de entropía.
keygen
Este valor por defecto contiene la ruta al programa de generación de claves.
keygen-opts
Este valor por defecto contiene un conjunto de opciones para el programa de generación de claves.
kskcount
Este valor por defecto contiene el número por defecto de claves KSK a generar para una zona.
ksklength
Este valor por defecto contiene la longitud por defecto de una clave KSK.
ksklife
Este valor por defecto contiene la vida útil por defecto de una clave KSK. Esto solo se utiliza para determinar cuándo rotar la clave KSK. Las claves tienen, por lo demás, ningún concepto de vida útil. Se mide en segundos.
lifespan-max
Este valor por defecto es la vida útil máxima de una clave.
lifespan-min
Este valor por defecto es la vida útil mínima de una clave.
log_tz
Este valor por defecto es la zona horaria que se utilizará en las marcas de tiempo de los mensajes de registro.
mailer-server
El servidor de correo que será contactado por dt_adminmail(). Se pasa a Mail::Send.
mailer-type
El tipo de remitente de correo que será contactado por dt_adminmail(). Se pasa a Mail::Mailer (a través de Mail::Send.) Cualquier valor reconocido por Mail::Mailer puede usarse aquí.
prog_ksk1 ... prog_ksk7
Estos valores por defecto contienen los comandos de fase por defecto que debe ejecutar rollerd para cada fase de la rotación KSK. La palabra clave default indica que se debe realizar el procesamiento normal de la fase. Se pueden dar múltiples comandos, pero deben estar separados por signos de exclamación. La palabra clave default puede combinarse con otros comandos.
prog_normal
Estos valores por defecto contienen los comandos de fase por defecto que debe ejecutar rollerd cuando una zona no está en estado de rotación. La palabra clave default indica que se debe realizar el procesamiento normal de la fase. Se pueden dar múltiples comandos, pero deben estar separados por signos de exclamación. La palabra clave default puede combinarse con otros comandos.
prog_zsk1 ... prog_zsk7
Estos valores por defecto contienen los comandos de fase por defecto que debe ejecutar rollerd para cada fase de la rotación ZSK. La palabra clave default indica que se debe realizar el procesamiento normal de la fase. Se pueden dar múltiples comandos, pero deben estar separados por signos de exclamación. La palabra clave default puede combinarse con otros comandos.
random
Este valor por defecto contiene el dispositivo generador de números aleatorios por defecto.
revperiod
Este valor por defecto contiene el período de revocación por defecto de una clave KSK. Este es el período mínimo de tiempo que una KSK revocada debe permanecer en el conjunto de firma para que los resolvedores la observen correctamente. Se mide en segundos.
rndc
Este valor por defecto es la ruta por defecto del programa rndc de BIND.
roll_loadzone
Este valor por defecto es un indicador de si rollerd debe hacer que el demonio DNS recargue sus zonas.
roll_logfile
Este valor por defecto es la ruta al archivo de registro de rollerd.
roll_loglevel
Este valor por defecto es el nivel de registro por defecto para rollerd.
roll_sleeptime
Este valor por defecto contiene el tiempo de espera por defecto utilizado por el demonio de rotación rollerd.
savekeys
Este valor por defecto indica si las claves deben eliminarse o no cuando ya no estén en uso.
tacontact
Esto es meramente un marcador de posición para la información de contacto. No hay un valor por defecto útil para esto.
tadnsvalconffile
Este valor por defecto especifica la ruta del archivo de configuración de dnsval.
tanamedconffile
Este valor por defecto especifica la ruta del archivo de configuración de named.
taresolvconf
Este valor por defecto especifica la ruta al archivo resolv.conf de DNS.
tasleeptime
Este valor por defecto contiene el valor por defecto de cuánto tiempo debe dormir el demonio.
tasmtpserver
Este valor por defecto especifica el nombre del servidor SMTP.
tatmpdir
Este valor por defecto especifica la ubicación del directorio temporal de trustman.
usegui
Este valor por defecto indica si se debe utilizar o no la GUI de DNSSEC-Tools para la entrada de opciones.
zone_errors
Este valor por defecto contiene el número máximo de errores consecutivos que puede tener una zona particular antes de que se cambie a ser una zona skip.
