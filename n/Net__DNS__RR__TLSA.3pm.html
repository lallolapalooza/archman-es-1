NOMBRE

Net::DNS::RR::TLSA - registro de recurso TLSA de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre TLSA uso selector tipodematch certificado');

DESCRIPCIÓN

El registro de recurso DNS TLSA (Transport Layer Security Authentication) se utiliza para asociar un certificado o clave pública TLS con el nombre de dominio donde se encuentra el registro, formando una "asociación de certificado TLSA". La semántica de cómo se interpreta el RR TLSA se describe en la RFC6698.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otro comportamiento impredecible.

uso

$uso = $rr->uso;
$rr->uso( $uso );

Valor entero de 8 bits que especifica la asociación proporcionada que se utilizará para coincidir con el certificado presentado en el handshake TLS.

selector

$selector = $rr->selector;
$rr->selector( $selector );

Valor entero de 8 bits que especifica qué parte del certificado TLS presentado por el servidor se comparará con los datos de asociación.

tipodematch

$tipodematch = $rr->tipodematch;
$rr->tipodematch( $tipodematch );

Valor entero de 8 bits que especifica cómo se presenta la asociación del certificado.

certificado

cert

$cert = $rr->cert;
$rr->cert( $cert );

Representación hexadecimal de los datos del certificado.

certbin

$certbin = $rr->certbin;
$rr->certbin( $certbin );

Representación binaria de los datos del certificado.

babble

print $rr->babble;

El método babble() devuelve la representación 'BubbleBabble' del resumen si el paquete Digest::BubbleBabble está disponible, de lo contrario se devuelve una cadena vacía.

BubbleBabble representa un resumen de mensaje como una cadena de palabras plausibles, para que el resumen sea más fácil de verificar. Las "palabras" no son necesariamente palabras reales, pero se parecen más a palabras que una cadena de caracteres hexadecimales.

La cadena 'BubbleBabble' se añade como comentario cuando se llama al método de cadena.
