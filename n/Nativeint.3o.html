Módulo Nativeint
: sig end

Enteros nativos del procesador.

Este módulo proporciona operaciones sobre el tipo nativeint de enteros firmados de 32 bits (en plataformas de 32 bits) o enteros firmados de 64 bits (en plataformas de 64 bits). Este tipo de entero tiene exactamente el mismo ancho que el de un tipo puntero en el compilador C. Todas las operaciones aritméticas sobre nativeint se toman en módulo 2^32 o 2^64 según el tamaño de palabra de la arquitectura.

Aviso de rendimiento: los valores de tipo nativeint ocupan más espacio de memoria que los valores de tipo int , y las operaciones aritméticas sobre nativeint son generalmente más lentas que las sobre int . Usa nativeint solo cuando la aplicación requiera el bit extra de precisión sobre el tipo int .

Los literales para enteros nativos van seguidos de n:

     let zero: nativeint = 0n
     let one: nativeint = 1n
     let m_one: nativeint = -1n

El entero nativo 0.

val one : nativeint

El entero nativo 1.

val minus_one : nativeint

El entero nativo -1.

Negación unaria.

Suma.

Resta.

Multiplicación.

val div : nativeint -> nativeint -> nativeint

División entera. Esta división redondea el cociente real de sus argumentos hacia cero, como se especifica para (/) .

Lanza Division_by_zero si el segundo argumento es cero.

val unsigned_div : nativeint -> nativeint -> nativeint

Igual que Nativeint.div , excepto que los argumentos y el resultado se interpretan como enteros nativos sin signo.

val rem : nativeint -> nativeint -> nativeint

Resto entero. Si y no es cero, el resultado de Nativeint.rem x y satisface las siguientes propiedades: Nativeint.zero <= Nativeint.rem x y < Nativeint.abs y y x = Nativeint.add (Nativeint.mul (Nativeint.div x y) y)
(Nativeint.rem x y) . Si y = 0 , Nativeint.rem x y lanza Division_by_zero .

val unsigned_rem : nativeint -> nativeint -> nativeint

Igual que Nativeint.rem , excepto que los argumentos y el resultado se interpretan como enteros nativos sin signo.

Desde 4.08

val succ : nativeint -> nativeint

Sucesor. Nativeint.succ x es Nativeint.add x Nativeint.one .

val pred : nativeint -> nativeint

Predecesor. Nativeint.pred x es Nativeint.sub x Nativeint.one .

val abs : nativeint -> nativeint

abs x es el valor absoluto de x . En min_int es min_int en sí mismo y por lo tanto permanece negativo.

val size : int

El tamaño en bits de un entero nativo. Esto es igual a 32 en una plataforma de 32 bits y a 64 en una plataforma de 64 bits.

val max_int : nativeint

El mayor entero nativo representable, ya sea 2^31 - 1 en una plataforma de 32 bits, o 2^63 - 1 en una plataforma de 64 bits.

val min_int : nativeint

El menor entero nativo representable, ya sea -2^31 en una plataforma de 32 bits, o -2^63 en una plataforma de 64 bits.

val logand : nativeint -> nativeint -> nativeint

AND lógico bit a bit.

val logor : nativeint -> nativeint -> nativeint

OR lógico bit a bit.

val logxor : nativeint -> nativeint -> nativeint

XOR lógico bit a bit.

val lognot : nativeint -> nativeint

Negación lógica bit a bit.

val shift_left : nativeint -> int -> nativeint

Nativeint.shift_left x y desplaza x a la izquierda por y bits. El resultado no está especificado si y < 0 o y >= bitsize , donde bitsize es 32 en una plataforma de 32 bits y 64 en una plataforma de 64 bits.

val shift_right : nativeint -> int -> nativeint

Nativeint.shift_right x y desplaza x a la derecha por y bits. Este es un desplazamiento aritmético: el bit de signo de x se replica y se inserta en los bits vaciados. El resultado no está especificado si y < 0 o y >= bitsize .

val shift_right_logical : nativeint -> int -> nativeint

Nativeint.shift_right_logical x y desplaza x a la derecha por y bits. Este es un desplazamiento lógico: se insertan ceros en los bits vaciados independientemente del signo de x . El resultado no está especificado si y < 0 o y >= bitsize .

val of_int : int -> nativeint

Convierte el entero dado (tipo int ) a un entero nativo (tipo nativeint ).

val to_int : nativeint -> int

Convierte el entero nativo dado (tipo nativeint ) a un entero (tipo int ). El bit de orden superior se pierde durante la conversión.

val unsigned_to_int : nativeint -> int option

Igual que Nativeint.to_int , pero interpreta el argumento como un entero sin signo. Devuelve None si el valor sin signo del argumento no cabe en un int .

Desde 4.08

val of_float : float -> nativeint

Convierte el número de punto flotante dado a un entero nativo, descartando la parte fraccionaria (trunca hacia cero). Si el número de punto flotante truncado está fuera del rango [ Nativeint.min_int , Nativeint.max_int ], no se lanza ninguna excepción y se devuelve un entero no especificado y dependiente de la plataforma.

val to_float : nativeint -> float

Convierte el entero nativo dado a un número de punto flotante.

val of_int32 : int32 -> nativeint

Convierte el entero de 32 bits dado (tipo int32 ) a un entero nativo.

val to_int32 : nativeint -> int32

Convierte el entero nativo dado a un entero de 32 bits (tipo int32 ). En plataformas de 64 bits, el entero nativo de 64 bits se toma módulo 2^32, es decir, se pierden los 32 bits superiores. En plataformas de 32 bits, la conversión es exacta.

val of_string : string -> nativeint

Convierte la cadena dada a un entero nativo. La cadena se lee en decimal (por defecto, o si la cadena comienza con 0u ) o en hexadecimal, octal o binario si la cadena comienza con 0x , 0o o 0b respectivamente.

El prefijo 0u lee la entrada como un entero sin signo en el rango [0, 2*Nativeint.max_int+1] . Si la entrada excede Nativeint.max_int se convierte al entero con signo Int64.min_int + entrada - Nativeint.max_int - 1 .

Lanza Failure si la cadena dada no es una representación válida de un entero, o si el entero representado excede el rango de enteros representables en el tipo nativeint .

val of_string_opt : string -> nativeint option

Igual que of_string , pero devuelve None en lugar de lanzar.

Desde 4.05

val to_string : nativeint -> string

Devuelve la representación de cadena de su argumento, en decimal.

type t = nativeint

Un alias para el tipo de enteros nativos.

val compare : t -> t -> int

La función de comparación para enteros nativos, con la misma especificación que compare . Junto con el tipo t , esta función compare permite pasar el módulo Nativeint como argumento a los functores Set.Make y Map.Make .

val unsigned_compare : t -> t -> int

Igual que Nativeint.compare , excepto que los argumentos son enteros nativos sin signo para la comparación.

Nativeint(3o)

Native integer arithmetic

Module

Nativeint

Documentation

This module provides integers that are represented natively by the machine integer type. The size of this type is platform-dependent.

On a 32-bit platform, the type t is a 32-bit signed integer. On a 64-bit platform, the type t is a 64-bit signed integer.

This module is not available on all platforms. It is available on all platforms that support native integers.

val of_int : int -> t

Convert an integer (of type int) to a native integer. On a 32-bit platform, the argument must be in the range [-2^31, 2^31-1]. On a 64-bit platform, the argument must be in the range [-2^63, 2^63-1].

Raises Failure if the argument is out of the range of native integers.
