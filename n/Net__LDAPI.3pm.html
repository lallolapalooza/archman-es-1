Net::LDAPI(3) Documentación de Perl aportada por usuarios Net::LDAPI(3)

NOMBRE

Net::LDAPI - usar LDAP sobre un socket de dominio UNIX

SINOPSIS

use Net::LDAPI;
$ldapi = Net::LDAPI->new('/var/run/ldapi');
# forma alternativa
use Net::LDAP;
$ldapi = Net::LDAP->new('ldapi://');

DESCRIPCIÓN

Comunícate usando el protocolo LDAP con un servidor de directorio a través de un socket de dominio UNIX. Este mecanismo no es estándar, es específico de UNIX y no está ampliamente soportado.

Todos los métodos normales de "Net::LDAP" pueden ser usados con un objeto "Net::LDAPI"; consulta Net::LDAP para más detalles.

CONSTRUCTOR

new ( [SOCKPATH] )
Crea una nueva conexión. Opcionalmente, se puede especificar SOCKPATH para indicar la ubicación del socket de dominio UNIX al que conectarse.

Si no se proporciona SOCKPATH, se evalúa la variable de entorno "LDAPI_SOCK" y, si tampoco existe, se usa el valor "/var/run/ldapi".

Consulta "new" en Net::LDAP para más detalles.

VER TAMBIÉN

Net::LDAP, IO::Socket::UNIX

ERRORES

Ninguno hasta ahora.
