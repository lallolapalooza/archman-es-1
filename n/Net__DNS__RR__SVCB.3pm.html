NOMBRE

Net::DNS::RR::SVCB - Registro de recurso SVCB de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre SVCB  PrioridadSvc NombreObjetivo ParamSvc');

DESCRIPCIÓN

Registro de recurso de Binding de Servicio de DNS (SVCB)

Especificación de binding de servicio y parámetros a través de DNS (registros SVCB e HTTPS)

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

Se desaconseja el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, ya que podrían provocar la terminación del programa u otros comportamientos impredecibles.

SvcPriority

$rr->SvcPriority( $prioridadsv );
$prioridadsv = $rr->SvcPriority;

La prioridad de este registro en relación con otros en el conjunto de registros (RRset), (los valores más bajos son preferidos). Un valor de 0 indica AliasMode.

TargetName

$rr->targetname( $nombreobjetivo );
$nombreobjetivoefectivo = $rr->targetname;

El nombre de dominio del objetivo del alias (para AliasMode) o del punto final alternativo (para ServiceMode).

Para los registros SVCB en modo Alias, un TargetName de "." indica que el servicio no está disponible o no existe.

Para los registros SVCB en modo Servicio, un TargetName de "." indica que el nombre del propietario de este registro debe usarse como el TargetName efectivo.

mandatory, alpn, no-default-alpn, port, ipv4hint, ech, ipv6hint

$rr = Net::DNS::RR->new( 'svcb.example. SVCB 1 svcb.example. port=1234' );
$rr->port(1234);
$octetos = $rr->port();  # 0x04 0xD2
$octetos = $rr->key3();

Métodos constructores para los SvcParams mnemotécnicos prescritos por RFC9460. Cuando se invocan sin argumentos, los métodos devuelven el valor de la clave subyacente como una cadena de octetos sin interpretar. El comportamiento con argumentos indefinidos no está especificado.

keyNN

$keynn = $rr->keyNN;
$rr->keyNN( $keynn );
$rr->keyNN( undef );

Métodos genéricos de constructor y acceso para SvcParams. El índice de clave NN es un entero decimal en el rango 0 .. 65535. El argumento del método es una cadena de caracteres en formato de presentación. El valor devuelto es una cadena de octetos sin interpretar. El método devuelve el valor indefinido si la clave no está presente. La clave especificada se eliminará si el argumento es indefinido.
