Net::DNS::RR::NULL(3) Documentación de Perl contribuida por usuarios Net::DNS::RR::NULL(3)

NOMBRE

Net::DNS::RR::NULL - Registro de recurso NULL de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre NULL \# longitud datos_hexadecimales ...');

DESCRIPCIÓN

Clase para registros de recursos NULL de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete ni el acceso directo a estructuras de datos internas, ya que podría provocar la terminación del programa u otro comportamiento impredecible.

rdlength

$rdlength = $rr->rdlength;

Devuelve la longitud de la sección de datos del registro.

rdata

$rdata = $rr->rdata;
$rr->rdata( $rdata );

Devuelve la sección de datos del registro como datos binarios.
