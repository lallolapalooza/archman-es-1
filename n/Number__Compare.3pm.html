Number::Compare(3) Documentación de Perl aportada por el usuario Number::Compare(3)

NOMBRE

Number::Compare - comparaciones numéricas

SINOPSIS

Number::Compare->new(">1Ki")->test(1025); # ¿es 1025 > 1024?
my $c = Number::Compare->new(">1M");
$c->(1_200_000);                          # invocación ligeramente más concisa

DESCRIPCIÓN

Number::Compare compila una comparación simple a una subrutina anónima, que puedes llamar con un valor para ser probado.

Ahora esto sería muy inútil si Number::Compare no entendiera magnitudes.

El valor objetivo puede usar magnitudes de kilobytes ("k", "ki"), megabytes ("m", "mi"), o gigabytes ("g", "gi"). Aquellos con el sufijo "i" usan la versión apropiada 2**n de acuerdo con el estándar IEC: http://physics.nist.gov/cuu/Units/binary.html

MÉTODOS

->new( $test )

Devuelve un nuevo objeto que compara la prueba especificada.

->test( $value )

Una versión larga de $compare->( $value ). Precede a la implementación de referencia de subrutina bendecida.

->parse_to_perl( $test )

Devuelve un fragmento de código perl equivalente a la prueba.
