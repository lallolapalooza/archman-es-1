NOMBRE

Net::Server::Proto::SSL - Protocolo SSL de Net::Server.

SINOPSIS

Hasta este lanzamiento, era preferible usar el módulo Net::Server::Proto::SSLEAY. Las versiones recientes incluyen código que supera las limitaciones originales.

Ver Net::Server::Proto. Ver Net::Server::Proto::SSLEAY.

use base qw(Net::Server::HTTP);
main->run(
    proto => 'ssl',
    SSL_key_file  => "/ruta/a/mi/archivo.key",
    SSL_cert_file => "/ruta/a/mi/archivo.crt",
);
# O
sub SSL_key_file  { "/ruta/a/mi/archivo.key" }
sub SSL_cert_file { "/ruta/a/mi/archivo.crt" }
main->run(proto = 'ssl');
# O
main->run(
    port => [443, 8443, "80/tcp"],  # enlazar a dos puertos ssl y un tcp
    proto => "ssl",       # usar ssl como predeterminado
    ipv  => "*",          # enlazar a interfaces IPv4 e IPv6
    SSL_key_file  => "/ruta/a/mi/archivo.key",
    SSL_cert_file => "/ruta/a/mi/archivo.crt",
);
# O
main->run(port => [{
    port  => "443",
    proto => "ssl",
    # ipv => 4, # predeterminado - solo hacer IPv4
    SSL_key_file  => "/ruta/a/mi/archivo.key",
    SSL_cert_file => "/ruta/a/mi/archivo.crt",
}, {
    port  => "8443",
    proto => "ssl",
    ipv   => "*", # IPv4 e IPv6
    SSL_key_file  => "/ruta/a/mi/archivo2.key", # clave separada
    SSL_cert_file => "/ruta/a/mi/archivo2.crt", # certificado separado
    SSL_foo => 1, # Cualquier clave prefijada con SSL_ pasada como un hashref de puerto
                  # la clave/valor se pasará automáticamente a IO::Socket::SSL
}]);

DESCRIPCIÓN

Módulo de protocolo para Net::Server basado en IO::Socket::SSL. Este módulo implementa una capa de socket segura sobre tcp (también conocida como SSL) a través del módulo IO::Socket::SSL. Si este módulo no funciona en tu situación, considera también usar el protocolo SSLEAY (Net::Server::Proto::SSLEAY) que se interconecta directamente con Net::SSLeay. Ver Net::Server::Proto.

Si sabes que tu servidor solo necesitará IPv4 (que es el predeterminado para Net::Server), puedes cargar IO::Socket::SSL en modo inet4 lo que evitará que use Socket6, IO::Socket::IP o IO::Socket::INET6 ya que representarían una sobrecarga adicional e innecesaria.

use IO::Socket::SSL qw(inet4);
use base qw(Net::Server::Fork);
__PACKAGE__->run(proto => "ssl");

PARÁMETROS

Además de los parámetros normales de Net::Server, cualquiera de los parámetros SSL de IO::Socket::SSL también se puede especificar. Ver IO::Socket::SSL para información sobre cómo configurarlo. Todos los argumentos prefijados con SSL_ se pasarán al método configure de IO::Socket::SSL.

ERRORES

Hasta la versión 2 de Net::Server, Net::Server::Proto::SSL utilizaba el método accept predeterminado de IO::Socket::SSL. Este enfoque antiguo introduce una vulnerabilidad de DDOS en el servidor, donde el socket se acepta, pero el servidor principal tiene que bloquearse hasta que el cliente negocie la conexión SSL. Esto se ha superado ahora anulando el método accept y aceptando la negociación SSL después de que el socket principal haya tenido la oportunidad de volver a escuchar.

LICENCIA

Distribuido bajo los mismos términos que Net::Server

AGRADECIMIENTOS

Gracias a Vadim por señalar que el accept de IO::Socket::SSL devolvía objetos bendecidos en la clase incorrecta.
