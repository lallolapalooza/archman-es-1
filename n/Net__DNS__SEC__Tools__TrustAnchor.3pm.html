NOMBRE

Net::DNS::SEC::Tools::TrustAnchor

SINOPSIS

Esta es una clase base para múltiples tipos de repositorios de anclas de confianza que saben cómo leer, escribir y modificar repositorios de anclas de confianza.

Este paquete sirve tanto como una envoltura de API alrededor de un conjunto de anclas de confianza, como una clase base para paquetes que necesitan leer/escribir conjuntos de anclas de confianza en diferentes formatos.

Las Anclas de Confianza pueden ser registros DNSKEY o referencias DS.

XXX: se necesita más documentación

API

API de uso definida por este módulo o sub-módulos.

Tenga en cuenta que:

use Net::DNS::SEC::Tools::TrustAnchor;

se asume que ha importado algunas de las rutinas de la API mencionadas a continuación.

$tar = new Net::DNS::SEC::Tools::TrustAnchor();

Inicializa una nueva colección de anclas de confianza.

$module = load_module("tipo");

Intenta cargar dinámicamente una sub-clase lector/escritor de TrustAnchor llamada "Tipo" y devuelve una instancia de ella.

Se asume que todos los sub-módulos contienen un nombre de clase de una sola letra en mayúscula seguido de todo en minúsculas. Cualquier módulo con otro nombre no se cargará utilizando esta rutina.

$module = parse_component("tipo:archivo");

Esto analiza una especificación de tipo y archivo que consiste en un tipo separado por dos puntos (':') seguido de una ruta de nombre de archivo. Luego cargará el módulo de tipo utilizando la rutina load_module() y devolverá el tipo, el archivo y opciones adicionales.

XXX: el soporte de análisis de opciones aún no está completo y probablemente cambiará la especificación del formato tipo:archivo; es decir, la especificación de formato tipo:archivo probablemente cambiará en el futuro y debe considerarse soporte de nivel alfa.

$tar = $module->read($ubicacion, $opciones);

Lee un TAR dado desde una referencia de $ubicacion y devuelve una copia bendecida del objeto Net::DNS::SEC::Tools::TrustAnchor que contiene todos los datos.

Esta función puede ser anulada por una sub-clase.

$tar = $module->read($ubicacion, $opciones);

Lee un TAR dado desde una referencia de $ubicacion y devuelve un hash no bendecido de su contenido. La función read() simplemente lo envuelve y lo bendice después de que se devuelve.

Los sub-módulos deben anular esta función (y/o la función read()) si esperan que el módulo admita la carga.

$tar->merge(@others)

Fusiona la matriz de @other de anclas de confianza en la propia lista de anclas de confianza del objeto $tar.
