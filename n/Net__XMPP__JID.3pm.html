NOMBRE

Net::XMPP::JID - Módulo JID de XMPP

SINOPSIS

Net::XMPP::JID es un complemento del módulo Net::XMPP. Proporciona al usuario una interfaz sencilla para establecer y recuperar todas las partes de un Jabber ID (ID de usuario en un servidor).

DESCRIPCIÓN

Para inicializar el JID, debes pasarle la cadena que representa el jid del paquete XML. Dentro de los módulos XMPP, esto se hace automáticamente y se devuelve el objeto JID en lugar de una cadena. Por ejemplo, en la función de callback para el objeto XMPP foo:

use Net::XMPP;
sub foo {
  my $foo = Net::XMPP::Foo->new(@_);
  my $from = $foo->GetFrom();
  my $JID = Net::XMPP::JID->new($from);
  .
  .
  .
}

Ahora tienes acceso a todas las funciones de recuperación disponibles.

Para crear un nuevo JID para enviar al servidor:

use Net::XMPP;
$JID = Net::XMPP::JID->new();

Ahora puedes llamar a las funciones de creación a continuación para poblar la etiqueta antes de enviarla.

Funciones de recuperación

$userid   = $JID->GetUserID();
$server   = $JID->GetServer();
$resource = $JID->GetResource();
$JID      = $JID->GetJID();
$fullJID  = $JID->GetJID("full");
$baseJID  = $JID->GetJID("base");

Funciones de creación

$JID->SetJID(userid=>"bob",
             server=>"jabber.org",
             resource=>"Work");
$JID->SetJID('blue@moon.org/Home');
$JID->SetUserID("foo");
$JID->SetServer("bar.net");
$JID->SetResource("Foo Bar");

MÉTODOS

Funciones de recuperación

GetUserID
GetUserID()

devuelve una cadena con el userid del JID. Si la cadena es una dirección (bob%jabber.org) entonces la función la devolverá como una dirección (bob@jabber.org).

GetServer
GetServer()

devuelve una cadena con el servidor del JID.

GerResource
GetResource()

devuelve una cadena con el recurso del JID.

GetJID
  GetJID()      
  GetJID("full")
  GetJID("base")
devuelve una cadena que representa el JID almacenado
en su interior.  Si se especifica la cadena "full",
entonces obtienes el JID completo, incluyendo el
Recurso, que debe ser utilizado para enviar al servidor.
Si se especifica la cadena "base", entonces solo
obtendrás user@server, o el JID base.

Funciones de creación

SetJID
SetJID(userid=>string,  
       server=>string,  
       resource=>string)
SetJID(string)

establece múltiples campos en el jid a la vez. Esta es una acción acumulativa y de sobrescritura. Si estableces el atributo "userid" dos veces, la segunda configuración es la que se usa. Si estableces el servidor y luego el recurso, ambos estarán en el jid. Si lo único que pasas es una cadena, esa cadena se usa como el JID. Para configuraciones válidas, lee las funciones Set específicas a continuación.

SetUserID
SetUserID(string)

establece el userid. Debe ser un userid válido o el servidor se quejará si intentas usar este JID para hablar con el servidor. Si la cadena es una dirección, se convertirá a la forma % adecuada para usarla como User ID.

SerServer
SetServer(string)

establece el servidor. Debe ser un host válido en la red o el servidor no podrá hablar con él.

SetResource
SetResource(string)

establece el recurso del userid con el que hablar.
