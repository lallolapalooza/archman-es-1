Net__LDAP__RootDSE(3pm)

Paquete: perl-ldap

Licencias: GPL

Net::LDAP::RootDSE(3) Documentación de Perl aportada por el usuario Net::LDAP::RootDSE(3)

NOMBRE

Net::LDAP::RootDSE - Un objeto RootDSE de LDAP

SINOPSIS

my $dse = $ldap->root_dse();
# obtener los Nombres de Contexto
my @contexts = $dse->get_value('namingContexts');
# obtener las versiones de LDAP soportadas como una referencia a arreglo
my $versions = $dse->get_value('supportedLDAPVersion', asref => 1);

DESCRIPCIÓN

Métodos

get_value
"get_value" es idéntico a "get_value" en Net::LDAP::Entry
supported_extension ( OID_LIST )
Devuelve verdadero si el servidor soporta todos los OIDs de extensión especificados
supported_feature ( OID_LIST )
Devuelve verdadero si el servidor soporta todos los OIDs de características especificados
supported_version ( VERSION_LIST )
Devuelve verdadero si el servidor soporta todas las versiones especificadas
supported_control ( OID_LIST )
Devuelve verdadero si el servidor soporta todos los OIDs de control especificados
supported_sasl_mechanism ( SASL_MECH_LIST )
Devuelve verdadero si el servidor soporta todos los nombres de mecanismo SASL especificados

VER TAMBIÉN

Net::LDAP, Net::LDAP::Entry
