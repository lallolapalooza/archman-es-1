NOMBRE

Net::CIDR::Lite - Extensión de Perl para fusionar direcciones CIDR IPv4 o IPv6

SINOPSIS

use Net::CIDR::Lite;
my $cidr = Net::CIDR::Lite->new;
$cidr->add($direccion_cidr);
@lista_cidr = $cidr->list;
@rangos_ip = $cidr->list_range;

DESCRIPCIÓN

Alternativa más rápida a Net::CIDR al fusionar un gran número de rangos de direcciones CIDR. Funciona para direcciones IPv4 e IPv6.

MÉTODOS

new()
$cidr = Net::CIDR::Lite->new
$cidr = Net::CIDR::Lite->new(@argumentos)

Crea un objeto para representar una lista de rangos de direcciones CIDR. Todavía no se ha establecido ningún formato; una vez que se llama a un método add con un formato IPv4 o IPv6, solo se puede agregar ese formato a este objeto cidr. Cualquier argumento suministrado se pasa a add_any() (ver abajo).

add()
$cidr->add($direccion_cidr)

Agrega un rango de direcciones CIDR a la lista.

add_range()
$cidr->add_range($rango_ip)

Agrega un rango de direcciones IP con guion a la lista.

add_cidr()
$cidr1->add_cidr($cidr2)

Agrega rangos de direcciones de un objeto a otro objeto.

add_ip()
$cidr->add_ip($direccion_ip)

Agrega una única dirección IP a la lista.

add_any()
$cidr->add_any($cidr_o_rango_o_direccion);

Determina el formato del rango o la dirección IP única y llama a add(), add_range(), add_cidr() o add_ip() según corresponda.

$cidr->clean()
$cidr->clean;

Si va a llamar al método list más de una vez con los mismos datos, para un rendimiento óptimo, puede llamar a esto para purgar nodos nulos en rangos superpuestos de la lista. Los nodos de borde en rangos contiguos se purgan automáticamente durante add(). Solo es útil cuando los rangos se superponen o cuando los rangos contiguos se agregan fuera de orden.

$cidr->list()
@lista_cidr = $cidr->list;
$referencia_lista  = $cidr->list;

Devuelve una lista de las direcciones CIDR fusionadas. Devuelve una matriz si se llama en contexto de lista, una referencia de matriz si no.

$cidr->list_range()
@lista_cidr = $cidr->list_range;
$referencia_lista  = $cidr->list_range;

Devuelve una lista de las direcciones fusionadas, pero en formato de rango con guion. Devuelve una matriz si se llama en contexto de lista, una referencia de matriz si no.

$cidr->list_short_range()
@lista_cidr = $cidr->list_short_range;
$referencia_lista  = $cidr->list_short_range;

Devuelve una lista de las direcciones fusionadas de subredes C, en formato de rango corto con guion. Devuelve una matriz si se llama en contexto de lista, una referencia de matriz si no.

Ejemplo:

1.1.1.1-2
1.1.1.5-7
1.1.1.254-255
1.1.2.0-2
1.1.3.5
1.1.3.7
$cidr->find()
$encontrado = $cidr->find($ip);

Devuelve verdadero si la dirección IP se encuentra en el rango CIDR. Falso si no. No es extremadamente eficiente, tiene una complejidad O(n*log(n)) para ordenar los rangos en el objeto cidr y O(n) para buscar en los rangos en el objeto cidr. El ordenamiento se almacena en caché en la primera llamada y se usa en llamadas posteriores, pero si se agregan más direcciones al objeto cidr, se debe llamar a prep_find() en el objeto cidr.

$cidr->bin_find()
Igual que find(), pero fuerza una búsqueda binaria. Ver también prep_find.
$cidr->prep_find()
$cidr->prep_find($num);

Almacena en caché el resultado de ordenar las direcciones IP. Se llama implícitamente en la primera llamada a find, pero debe llamarse explícitamente si se agregan más direcciones al objeto cidr. find() realizará una búsqueda binaria si el número de rangos es mayor o igual a $num (por defecto 20);

$cidr->spanner()
$spanner = $cidr1->spanner($etiqueta1, $cidr2, $etiqueta2, ...);

Crea un objeto spanner para averiguar si múltiples direcciones IP están dentro de múltiples rangos de direcciones etiquetados. También se puede llamar como (con o sin argumentos):

Net::CIDR::Lite::Span->new($cidr1, $etiqueta1, $cidr2, $etiqueta2, ...);
$spanner->add()
$spanner->add($cidr1, $etiqueta1, $cidr2, $etiqueta2,...);

Agrega rangos de direcciones etiquetados al objeto spanner. El 'rango de direcciones' puede ser un objeto Net::CIDR::Lite, un rango de direcciones CIDR único, un rango de direcciones IP con guion único o una dirección IP única.

$spanner->find()
$href = $spanner->find(@direcciones_ip);

Busca en qué rango(s) se encuentran las direcciones IP y devuelve una tabla de consulta de los resultados, con las claves siendo las direcciones IP y el valor siendo una referencia de hash de los rangos de direcciones en los que se encuentra la dirección IP.

$spanner->bin_find()
Igual que find(), pero fuerza una búsqueda binaria. Ver también prep_find.
$spanner->prep_find()
$spanner->prep_find($num);

Se llama implícitamente la primera vez que se llama $spanner->find(..), debe llamarse de nuevo si se agregan más objetos cidr al objeto spanner. Realizará una búsqueda binaria si la relación entre el número de direcciones IP y el número de rangos es menor que $num por ciento (por defecto 4).

$spanner->clean()
$direccion_limpia = $spanner->clean($direccion_ip);

Valida y devuelve una versión limpia de una dirección IP (que es lo que encontrará como clave en el resultado de $spanner->find(..), no necesariamente lo que parecía el argumento original). Por ejemplo, elimina ceros iniciales innecesarios, elimina bloques nulos de direcciones IPv6, etc.

DESCRIPCIÓN

Este módulo proporciona una forma sencilla de manejar listas de direcciones IP y prefijos de red en notación CIDR. Permite crear, manipular y consultar rangos de direcciones IP de manera eficiente.

MÉTODOS

Los métodos principales incluyen:

  • new: Crea un nuevo objeto Net::CIDR::Lite.
  • add: Añade una dirección o prefijo CIDR a la lista.
  • contains: Comprueba si una dirección IP pertenece a algún rango en la lista.
  • list: Devuelve una lista de todos los rangos CIDR gestionados.
  • flatten: Combina rangos superpuestos para crear una lista de rangos no superpuestos.

CAUTIDADES

Tener en cuenta que este módulo trata las direcciones IPv4. No soporta direcciones IPv6 de forma nativa en esta versión. La manipulación de grandes cantidades de rangos puede afectar el rendimiento.
