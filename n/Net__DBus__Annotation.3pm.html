Net::DBus::Annotation(3) Documentación de Perl aportada por el usuario Net::DBus::Annotation(3)

NOMBRE

Net::DBus::Annotation - anotaciones para cambiar el comportamiento de las APIs

SINOPSIS

use Net::DBus::Annotation qw(:call);
my $object = $service->get_object("/org/example/systemMonitor");
# Bloquear hasta que se listen los procesos
my $processes = $object->list_processes("algunusuario");
# Simplemente descartar la lista de procesos, bastante inútil
# en este ejemplo, pero útil si el método no tiene
# valor de retorno
$object->list_processes(dbus_call_noreply, "algunusuario");
# Listar procesos & seguir con otro trabajo hasta
# que se devuelva la lista.
my $asyncreply = $object->list_processes(dbus_call_async, "algunusuario");
... algo de tiempo después...
my $processes = $asyncreply->get_data;
# Listar procesos, con un tiempo de espera de 10 segundos más corto, en lugar de
# los 60 segundos por defecto
my $object->list_processes(dbus_call_timeout, 10 * 1000, "algunusuario");

DESCRIPCIÓN

Este módulo proporciona una serie de anotaciones que serán útiles al tratar con las APIs de DBus. Hay anotaciones para cambiar las llamadas remotas entre los modos síncrono, asíncrono y sin respuesta. Es posible que se añadan más anotaciones con el tiempo.

MÉTODOS

dbus_call_sync
Solicita que una llamada al método se realice de forma síncrona, esperando a recibir la respuesta o el error antes de continuar.
dbus_call_async
Solicita que una llamada al método se realice de forma asíncrona, devolviendo un objeto de llamada pendiente, que recopilará la respuesta cuando llegue eventualmente.
dbus_call_noreply
Solicita que una llamada al método se realice de forma asíncrona, descartando cualquier posible mensaje de respuesta o error.
dbus_call_timeout
Indica que el siguiente parámetro de la llamada al método especificará el tiempo de espera de una respuesta en milisegundos. Si se omite, se utilizará el tiempo de espera predeterminado del objeto.
