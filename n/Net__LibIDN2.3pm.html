NOMBRE

Net::LibIDN2 - Enlaces de Perl para GNU Libidn2

SINOPSIS

use Net::LibIDN2 ':all';
use Encode;
idn2_lookup_u8(Encode::encode_utf8("m\N{U+00FC}\N{U+00DF}li.de"))
  eq 'xn--mli-5ka8l.de';
idn2_register_u8(
  Encode::encode_utf8("m\N{U+00FC}\N{U+00DF}li"),
  "xn--mli-5ka8l"
) eq 'xn--mli-5ka8l';
Encode::decode_utf8(idn2_to_unicode_88("xn--mli-5ka8l.de"))
  eq "m\N{U+00FC}\N{U+00DF}li.de"

DESCRIPCIÓN

Proporciona enlaces para GNU Libidn2, una biblioteca C para manejar nombres de dominio internacionalizados basados en IDNA 2008, Punycode y TR46.

Funciones

Net::LibIDN2::idn2_lookup_u8($src, [$flags, [$rc]]);
Nombre alternativo idn2_to_ascii_8.

Realiza la conversión de cadena de búsqueda IDNA2008 en el nombre de dominio $src, como se describe en la sección 5 de RFC 5891. Tenga en cuenta que la cadena de entrada debe estar codificada en UTF-8 y estar en forma NFC de Unicode.

Pase IDN2_NFC_INPUT en $flags para convertir la entrada a forma NFC antes del procesamiento posterior. IDN2_TRANSITIONAL y IDN2_NONTRANSITIONAL ya implican IDN2_NFC_INPUT.

Pase IDN2_ALABEL_ROUNDTRIP en flags para convertir las etiquetas A de entrada a etiquetas U y realizar pruebas adicionales. Esto es por defecto si se usa con una versión de libidn2 >= 2.2. Para desactivar este comportamiento, pase IDN2_NO_ALABEL_ROUNDTRIP.

Pase IDN2_TRANSITIONAL para habilitar el procesamiento transicional de TR46 de Unicode, y IDN2_NONTRANSITIONAL para habilitar el procesamiento no transicional de TR46 de Unicode.

Se pueden especificar varias banderas haciendo un OR binario de ellas, por ejemplo IDN2_NFC_INPUT | IDN2_ALABEL_ROUNDTRIP.

Si está enlazado a la biblioteca GNU Libidn2 versión > 2.0.3: IDN2_USE_STD3_ASCII_RULES está deshabilitado por defecto. Anteriormente eliminábamos caracteres no-STD3 de cadenas de dominio como _443._tcp.example.com, o IPs 1.2.3.4/24 proporcionadas a las funciones de libidn2. Esa fue una regresión inesperada para aplicaciones que cambiaban de libidn2 y, por lo tanto, ya no se aplica por defecto. Use IDN2_USE_STD3_ASCII_RULES para volver a habilitar ese comportamiento.

En caso de error, devuelve undef. Si se proporciona una variable escalar en $rc, también devuelve el código de resultado interno de la biblioteca C de libidn2.

Net::LibIDN2::idn2_lookup_ul($src, [$flags, [$rc]]);
Nombre alternativo idn2_to_ascii_l.

Similar a la función "idn2_lookup_u8" pero se asume que $src está codificado en el sistema de codificación por defecto del locale, y se transcodificará a UTF-8 y se normalizará a NFC antes de devolver el resultado.

Net::LibIDN2::idn2_register_u8($ulabel, [$alabel, [$flags, [$rc]]]);
Realiza la conversión de cadena de registro IDNA2008 en la etiqueta de dominio $ulabel y $alabel, como se describe en la sección 4 de RFC 5891. Tenga en cuenta que la ulabel de entrada debe estar codificada en UTF-8 y estar en forma NFC de Unicode.

Pase IDN2_NFC_INPUT en $flags para convertir la entrada $ulabel a forma NFC antes del procesamiento posterior.

Se recomienda proporcionar tanto $ulabel como $alabel para una mejor verificación de errores, pero proporcionar solo uno de ellos funcionará. Proporcionar solo $alabel es mejor que solo $ulabel. Ver la sección 4 de RFC 5891 para más información.

En caso de error, devuelve undef. Si se proporciona una variable escalar en $rc, también devuelve el código de resultado interno de la biblioteca C de libidn2.

Net::LibIDN2::idn2_register_ul($ulabel, [$alabel, [$flags, [$rc]]]);
Similar a la función "idn2_register_u8" pero se asume que $ulabel está codificado en el sistema de codificación por defecto del locale, y se transcodificará a UTF-8 y se normalizará a NFC antes de devolver el resultado.
Net::LibIDN2::idn2_to_unicode_88($input, [$flags, [$rc]]);
Convierte un nombre de dominio posiblemente codificado en ACE en formato UTF-8 en una cadena codificada en UTF-8 (decodificación punycode).

En caso de error, devuelve undef. Si se proporciona una variable escalar en $rc, también devuelve el código de resultado interno de la biblioteca C de libidn2.

Net::LibIDN2::idn2_to_unicode_8l($input, [$flags, [$rc]]);
Similar a la función "idn2_to_unicode_88" pero el valor de retorno está codificado en el sistema de codificación por defecto del locale.
Net::LibIDN2::idn2_to_unicode_ll($input, [$flags, [$rc]]);
Similar a la función "idn2_to_unicode_8l" pero se asume también que $input está codificado en el sistema de codificación por defecto del locale.
Net::LibIDN2::idn2_strerror($rc);
Convierte el código de error interno de libidn2 $rc a una cadena legible por humanos.
Net::LibIDN2::idn2_strerror_name($rc);
Convierte el código de error interno de libidn2 $rc a una cadena que corresponde a los nombres de símbolos internos de los archivos de cabecera, como IDN2_MALLOC.
Net::LibIDN2::idn2_check_version([$req_version])
Verifica que la versión de la biblioteca C subyacente de IDN2 sea como mínimo la dada como cadena en $req_version y si es así, devuelve la cadena de versión real de la biblioteca C subyacente o undef si la condición no se cumple. Si no se pasa ningún parámetro a esta función, no se realiza ninguna verificación y solo se devuelve la cadena de versión.

Vea IDN2_VERSION para una cadena $req_version adecuada, corresponde a la versión del archivo de cabecera C de idn2.h en el momento de la compilación de este módulo Perl. Normalmente, estos dos números de versión coinciden, pero si compiló este módulo Perl contra un libidn2 anterior y luego lo ejecuta con una biblioteca compartida de libidn2 más nueva, serán diferentes.

Constantes

IDN2_VERSION
Símbolo de preprocesador con una cadena que describe el número de versión del archivo de cabecera C en el momento de la compilación de este módulo Perl. Se utiliza junto con idn2_check_version() para verificar la consistencia entre el archivo de cabecera y la biblioteca en tiempo de ejecución.
IDN2_VERSION_NUMBER
Símbolo de preprocesador con un valor hexadecimal que describe el número de versión del archivo de cabecera C en el momento de la compilación de este módulo Perl. Por ejemplo, cuando la versión de la cabecera es 1.2.4711, este símbolo tendrá el valor 0x01021267.
