NOMBRE

Net::Server::Proto::SSLEAY - Manejador de protocolo SSL personalizado de Net::Server basado en Net::SSLeay.

SINOPSIS

Ver Net::Server::Proto.

use base qw(Net::Server::HTTP);
main->run(
    proto => 'ssleay',
    SSL_key_file  => "/ruta/a/mi/archivo.key",
    SSL_cert_file => "/ruta/a/mi/archivo.crt",
);
# O
sub SSL_key_file  { "/ruta/a/mi/archivo.key" }
sub SSL_cert_file { "/ruta/a/mi/archivo.crt" }
main->run(proto => 'ssleay');
# O
main->run(
    port => [443, 8443, "80/tcp"],  # enlazar a dos puertos ssleay y uno tcp
    proto => "ssleay",    # usar ssleay por defecto
    ipv  => "*",          # enlazar a interfaces IPv4 e IPv6
    SSL_key_file  => "/ruta/a/mi/archivo.key",
    SSL_cert_file => "/ruta/a/mi/archivo.crt",
);
# O
main->run(port => [{
    port  => "443",
    proto => "ssleay",
    # ipv => 4, # por defecto - solo IPv4
    SSL_key_file  => "/ruta/a/mi/archivo.key",
    SSL_cert_file => "/ruta/a/mi/archivo.crt",
}, {
    port  => "8443",
    proto => "ssleay",
    ipv   => "*", # IPv4 e IPv6
    SSL_key_file  => "/ruta/a/mi/archivo2.key", # clave separada
    SSL_cert_file => "/ruta/a/mi/archivo2.crt", # certificado separado
}]);

DESCRIPCIÓN

Este módulo se ha utilizado de forma fiable en situaciones que reciben millones de accesos diarios en una sola máquina. Si alguien tiene algún éxito o ideas para mejorar bajo SSLEAY, por favor envíe un correo electrónico a <paul@seamons.com>.

Módulo de protocolo para Net::Server. Este módulo implementa una capa de sockets segura sobre tcp (también conocida como SSL). Ver Net::Server::Proto.

Si necesita una mayor personalización de la capa SSL, puede que desee investigar el uso de SSL en lugar de SSLEAY, ya que utiliza el venerable (más o menos) IO::Socket::SSL.

PARÁMETROS

Actualmente hay soporte para lo siguiente:

"SSL_cert_file"
Ruta completa al archivo de certificado que se utilizará para este servidor. Debe estar en formato PEM.
"SSL_key_file"
Ruta completa al archivo de clave que se utilizará para este servidor. Debe estar en formato PEM.
"SSL_max_getline_length"
Se utiliza durante getline para leer solo hasta que se encuentren tantos bytes. El valor predeterminado es undef, lo que significa ilimitado.
"SSL_error_callback"
Debe ser una referencia de código que se llamará cada vez que se encuentren condiciones de error. Pasa un mensaje de origen y una referencia de matriz de los errores.

MÉTODOS

Este módulo implementa la mayoría de las operaciones comunes de manejador de archivos. Sin embargo, hay algunas adiciones:

"read_until"
Toma bytes y coincide con qr. Si bytes no es undef, leerá hasta que se encuentren esa cantidad de bytes. Si coincidir con qr no es undef, leerá hasta que el búfer coincida con ese qr. Si ambos son undef, leerá hasta que no quede nada por leer.
"error"
Si ocurrió un error al escribir, este método devolverá ese error.

ERRORES
