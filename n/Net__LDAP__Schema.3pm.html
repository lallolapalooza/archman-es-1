Net::LDAP::Schema(3) Documentación de contribución de Perl Net::LDAP::Schema(3)

NOMBRE

Net::LDAP::Schema - Cargar y manipular un esquema LDAP v3

SINTAXIS

use Net::LDAP;
use Net::LDAP::Schema;
#
# Leer esquema desde el servidor
#
$ldap = Net::LDAP->new ( $server );
$ldap->bind ( );
$schema = $ldap->schema ( );
#
# Cargar desde LDIF
#
$schema = Net::LDAP::Schema->new;
$schema->parse ( "schema.ldif" ) or die $schema->error;

DESCRIPCIÓN

"Net::LDAP::Schema" proporciona una forma de cargar un esquema LDAP y consultar información sobre las clases de objeto, atributos y sintaxis soportadas.

MÉTODOS

Donde un método se indica como tomando el nombre o OID de un elemento del esquema (que puede ser una clase de objeto, atributo o sintaxis), entonces se puede proporcionar un nombre o OID (en forma de identificador de objeto, en formato de cadena numérica, por ejemplo 2.5.4.0) en mayúsculas o en forma de cadena raw.

Cada elemento devuelto del esquema (por ejemplo, una definición de atributo) se devuelve en un HASH. Las claves de este HASH son versiones minúsculas de las claves leídas del servidor. Aquí hay una lista parcial (no todos los HASHs definen todas las claves), aunque se debe notar que el RFC 4512 permite otros tipos de claves también:

Devuelve una lista de todos los tipos solicitados en el esquema.
attribute ( NOMBRE )
ditcontentrule ( NOMBRE )
ditstructurerule ( NOMBRE )
matchingrule ( NOMBRE )
matchingruleuse ( NOMBRE )
nameform ( NOMBRE )
objectclass ( NOMBRE )
syntax ( NOMBRE )
Devuelve un referencia a un HASH, o "undef" si el elemento del esquema no existe. "NOMBRE" puede ser un nombre o un OID.
dump ( )
Imprime la información del esquema en formato de salida estándar.
dump ( NOMBRE_ARCHIVO )
Imprime la información del esquema en un archivo.
error ( )
Devuelve el error más reciente al parsear el esquema.
may ( CLASE_OBJETO )
Devuelve una lista de HASHs que indican los atributos que son opcionales en la clase.
must ( CLASE_OBJETO )
Devuelve una lista de HASHs que indican los atributos que son obligatorios en la clase.
parse ( MESG )
parse ( ENTRADA )
parse ( NOMBRE_ARCHIVO )
Recibe un argumento que puede ser un objeto de resultado de una búsqueda LDAP, un objeto "Net::LDAP::Entry" o el nombre de un archivo que contiene una representación LDIF del esquema.

Si el argumento es el resultado de una búsqueda LDAP, "Net::LDAP::Schema" parsea el esquema desde la primera entrada devuelta.

Devuelve verdadero en caso de éxito y "undef" en caso de error.

superclass ( NOMBRE )
Devuelve la lista de nombres de las clases hermanas inmediatas.
attribute_syntax ( NOMBRE )
Devuelve la sintaxis real considerando los supertipos de atributo.
matchingrule_for_attribute ( NOMBRE, REGLA )
Devuelve el regla real considerando los supertipos de atributo, dada una regla de coincidencia ("equality", "substr", etc).
