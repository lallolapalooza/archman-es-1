Net::HTTPS(3) Documentación de Perl aportada por el usuario Net::HTTPS(3)

NOMBRE

Net::HTTPS - Conexión HTTP sobre SSL/TLS de bajo nivel (cliente)

VERSIÓN

versión 6.24

DESCRIPCIÓN

"Net::HTTPS" es un cliente HTTP sobre SSL/TLS de bajo nivel. La interfaz es la misma que la interfaz de "Net::HTTP", pero el constructor acepta parámetros adicionales aceptados por IO::Socket::SSL. El objeto "Net::HTTPS" es también un "IO::Socket::SSL", lo que hace que herede métodos adicionales de esa clase base.

Por razones históricas, este módulo también soporta el uso de "Net::SSL" (de la distribución Crypt-SSLeay) como su controlador SSL y clase base. Esta base se selecciona automáticamente si está disponible y "IO::Socket::SSL" no lo está. También puede forzar qué implementación usar estableciendo $Net::HTTPS::SSL_SOCKET_CLASS antes de cargar este módulo. Si no se establece, esta variable se inicializa a partir de la variable de entorno "PERL_NET_HTTPS_SSL_SOCKET_CLASS".

ENTORNO

Puede establecer la variable de entorno "PERL_NET_HTTPS_SSL_SOCKET_CLASS" al nombre de la implementación SSL base (y clase base de Net::HTTPS) a utilizar. El valor predeterminado es "IO::Socket::SSL". Actualmente, el único otro valor admitido es "Net::SSL".

VER TAMBIÉN

Net::HTTP, IO::Socket::SSL
