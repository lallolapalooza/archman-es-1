NOMBRE

Net::Jabber::Dialback - Módulo de Dialback de Jabber

SINOPSIS

Net::Jabber::Dialback es un complemento del módulo Net::Jabber::Server.
Proporciona al usuario una interfaz sencilla para establecer y recuperar
todas las partes de un Dialback del Servidor Jabber.

DESCRIPCIÓN

Para inicializar el Dialback con un Jabber <db:*/> debes pasarle
el hash de XML::Stream. Por ejemplo:
  my $dialback = new Net::Jabber::Dialback(%hash);
Ahora tienes acceso a todas las funciones de recuperación disponibles.
Para crear un nuevo mensaje para enviar al servidor:
  use Net::Jabber qw(Server);
  $DB = new Net::Jabber::Dialback("verify");
  $DB = new Net::Jabber::Dialback("result");
Por favor, consulta la documentación específica para Net::Jabber::Dialback::Result
y Net::Jabber::Dialback::Verify.
Para más información sobre el formato del array que se pasa al
CallBack, por favor lee la documentación de Net::Jabber::Client.
