NOMBRE

Net::Dropbox::API - Una interfaz de API de Dropbox

VERSIÓN

Versión 1.9.8

SINOPSIS

La API de Dropbox es una API basada en OAuth. Intento abstraer tanto como sea posible, así que no deberías necesitar saber mucho al respecto. Así es como funciona:

use Net::Dropbox::API;
my $box = Net::Dropbox::API->new({key => 'CLAVE', secret => 'SECRETO'});
my $login_link = $box->login;  # el usuario necesita hacer clic en este enlace e iniciar sesión
$box->auth;                    # las claves oauth se intercambian
my $info = $box->account_info; # y aquí tenemos la información de nuestra cuenta

Consulta los ejemplos para ver un cliente web Mojolicious que funciona usando la API de Dropbox.

Puedes encontrar la documentación de la API de Dropbox en https://www.dropbox.com/developers/web_docs

FUNCIONES

login

Esto configura el apretón de manos inicial de OAuth y devuelve la URL de inicio de sesión. Esta URL debe ser clicada por el usuario y el usuario debe aceptar la aplicación en Dropbox.

Dropbox luego redirige a la URL de devolución de llamada definida con "$self->callback_url". Si el usuario ya aceptó la aplicación, la redirección puede ocurrir sin que el usuario haga clic en nada.

auth

El método auth cambia el token de solicitud inicial por un token de acceso que necesitamos para el acceso posterior a la API. Este método solo necesita ser llamado una vez después del inicio de sesión.

account_info

account_info consulta la información del usuario desde Dropbox.

list

lista todos los archivos en la ruta definida:

$data = $box->list();           # nivel superior
$data = $box->list( "/Fotos" ); # carpeta

Los datos devueltos son una referencia a un hash que contiene varios campos devueltos por Dropbox, incluido un valor "hash", que se puede usar más tarde para comprobar si los datos de Dropbox debajo de una carpeta especificada han cambiado desde la última llamada.

Para esto, list() acepta un argumento opcional 'hash':

$data = $box->list({ hash => "ce9ccbfb8f255f234c93adcfef33b5a6" },
                   "/Fotos");

Esto devolverá

{ http_response_code => 304 }

en cuyo caso nada ha cambiado desde la última llamada, o

{ http_response_code => 200,
  # ... varios otros campos
}

si hubo modificaciones.

copy

copia una carpeta
copy($desde, $a)

move

mueve una carpeta
move($desde, $a)

mkdir

crea una carpeta
mkdir($ruta)

delete

elimina una carpeta
delete($ruta)

view

crea un enlace protegido por cookies para que el usuario lo vea.
view($ruta)

metadata

crea un enlace protegido por cookies para que el usuario lo vea.
metadata($ruta)

putfile

sube un archivo a Dropbox

getfile

obtiene un archivo de Dropbox

debug

Establezca esto en un valor no falso para imprimir información de depuración en STDOUT.
debug(1)

API INTERNA

_talk

_talk maneja el acceso a los recursos restringidos. Normalmente no necesitarías acceder a esto directamente.

nonce

Genera un nonce diferente para cada solicitud.

    NOMBRE

    Net::Dropbox::API - Interface to the Dropbox API

    SINOPSIS

    use Net::Dropbox::API;

my $dropbox = Net::Dropbox::API->new(
    token => 'your_access_token',
);

my $result = $dropbox->list_folder('/Apps/MyCoolApp');

# Process $result

    DESCRIPCIÓN

    This module provides an interface to the Dropbox API. It allows you to interact with your Dropbox files and folders programmatically.

    MÉTODOS

    new ( %args )
    Creates a new Net::Dropbox::API object. Supported arguments include:
    • token: Your Dropbox API access token.
    • app_key: Your Dropbox App Key (if using OAuth).
    • app_secret: Your Dropbox App Secret (if using OAuth).
    • refresh_token: Your Dropbox Refresh Token (if using OAuth).
    list_folder ( path )
    Lists the contents of a given folder path.
    upload ( path, content )
    Uploads content to a given path.
    download ( path )
    Downloads the content from a given path.
    delete ( path )
    Deletes the file or folder at the given path.
