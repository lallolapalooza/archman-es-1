Net::DBus(3) Documentación Perl contribuida por el usuario Net::DBus(3)

NOMBRE

Net::DBus - Extensión Perl para el sistema de mensajes DBus

SINOPSIS

####### Conexión al bus ###########
use Net::DBus;
# Encuentra el bus más apropiado
my $bus = Net::DBus->find;
# ... o elige explícitamente el bus de sesión
my $bus = Net::DBus->session;
# .... o elige explícitamente el bus del sistema
my $bus = Net::DBus->system
######## Acceso a servicios remotos #########
# Obtiene un manejador del servicio HAL
my $hal = $bus->get_service("org.freedesktop.Hal");
# Obtiene el gestor de dispositivos
my $manager = $hal->get_object("/org/freedesktop/Hal/Manager",
                               "org.freedesktop.Hal.Manager");
# Lista los dispositivos
foreach my $dev (@{$manager->GetAllDevices}) {
    print $dev, "\n";
}
######### Provisión de servicios ##############
# Registra un servicio conocido como 'org.example.Jukebox'
my $service = $bus->export_service("org.example.Jukebox");

DESCRIPCIÓN

Net::DBus proporciona una API de Perl para el sistema de mensajes DBus. La interfaz Perl de DBus está operando actualmente contra la versión de desarrollo 0.32 de DBus, pero también debería funcionar con versiones posteriores, siempre que los cambios en la API no hayan sido demasiado drásticos.

Los usuarios de este paquete suelen ser, o bien proveedores de servicios, en cuyo caso los módulos Net::DBus::Service y Net::DBus::Object son los más relevantes, o bien consumidores clientes, en cuyo caso Net::DBus::RemoteService y Net::DBus::RemoteObject son los más relevantes.

MÉTODOS

my $bus = Net::DBus->find(%params);
Busca el bus más apropiado para conectarse y devuelve una conexión a él. La heurística utilizada para la búsqueda es 
- Si DBUS_STARTER_BUS_TYPE está configurado como 'session', se conecta
  al bus de sesión
- De lo contrario, si DBUS_STARTER_BUS_TYPE está configurado como 'system', se conecta
  al bus del sistema
- De lo contrario, si DBUS_SESSION_BUS_ADDRESS está configurado, se conecta
  al bus de sesión
- De lo contrario, se conecta al bus del sistema

El hash opcional de "params" puede usarse para especificar opciones de conexión. La única opción admitida en este momento es "nomainloop", que impide que el bus se conecte automáticamente al bucle de eventos principal de Net::DBus::Reactor.

my $bus = Net::DBus->system(%params);
Devuelve un manejador para el bus de mensajes del sistema. Tenga en cuenta que el bus de mensajes del sistema está bloqueado por defecto, por lo que a menos que se agreguen reglas de control de acceso apropiadas en /etc/dbus/system.d/, una aplicación puede acceder a servicios, pero no podrá exportar servicios.

El hash opcional de "params" puede usarse para especificar las siguientes opciones:

nomainloop
Si es verdadero, impide que el bus se conecte automáticamente al bucle de eventos principal de Net::DBus::Reactor.
private
Si es verdadero, el socket abierto es privado; se ignorará cualquier socket existente y cualquier intento futuro de abrir el mismo bus devolverá un socket existente diferente o abrirá uno nuevo.
my $bus = Net::DBus->session(%params);
Devuelve un manejador para el bus de mensajes de sesión.

El hash opcional de "params" puede usarse para especificar las siguientes opciones:

nomainloop
Si es verdadero, impide que el bus se conecte automáticamente al bucle de eventos principal de Net::DBus::Reactor.
private
Si es verdadero, el socket abierto es privado; se ignorará cualquier socket existente y cualquier intento futuro de abrir el mismo bus devolverá un socket existente diferente o abrirá uno nuevo.
my $bus = Net::DBus->test(%params);
Devuelve un manejador para un bus virtual para su uso en pruebas unitarias. Este bus no realiza conexiones de red, sino que tiene un pipeline de mensajes en memoria. Consulte Net::DBus::Test::MockConnection para obtener más detalles sobre cómo usar este bus especial.
my $bus = Net::DBus->new($address, %params);
Devuelve una conexión a un bus de mensajes específico. El parámetro $address debe contener la dirección del bus de mensajes al que conectarse. Una dirección de ejemplo para un bus de sesión podría parecerse a "unix:abstract=/tmp/dbus-PBFyyuUiVb,guid=191e0a43c3efc222e0818be556d67500", mientras que una para un bus del sistema se vería como "unix:/var/run/dbus/system_bus_socket". El hash opcional de "params" puede usarse para especificar opciones de conexión. La única opción admitida en este momento es "nomainloop", que impide que el bus se conecte automáticamente al bucle de eventos principal de Net::DBus::Reactor.
my $connection = $bus->get_connection;
Devuelve un manejador para el objeto de conexión subyacente de bajo nivel asociado con este bus. El objeto devuelto será una instancia de la clase Net::DBus::Binding::Bus. Este método no está destinado al uso por parte de (la mayoría de) los desarrolladores de aplicaciones, por lo que si no entiende para qué sirve, ¡entonces no debería llamarlo!
my $service = $bus->get_service($name);
Recupera un manejador para el servicio remoto identificado por el nombre del servicio $name. El objeto devuelto será una instancia de la clase Net::DBus::RemoteService.
my $service = $bus->export_service($name);
Registra un servicio en el bus, devolviendo un manejador para el servicio. El objeto devuelto es una instancia de la clase Net::DBus::Service.

Cuando $name no se especifica o es "undef", el manejador devuelto para el servicio se identifica solo por el nombre único de la conexión del cliente al bus.

my $object = $bus->get_bus_object;
Recupera un manejador para el objeto de bus, "/org/freedesktop/DBus", proporcionado por el servicio "org.freedesktop.DBus". El objeto devuelto es una instancia de Net::DBus::RemoteObject
my $name = $bus->get_unique_name;
Recupera el nombre único de la conexión de este cliente al bus.
my $name = $bus->get_service_owner($service);
Recupera el nombre único del cliente en el bus que posee el servicio nombrado por el parámetro $service.
my $timeout = $bus->timeout(60 * 1000);
Establece o recupera el valor del tiempo de espera que se utilizará para las solicitudes DBus pertenecientes a esta conexión de bus. El tiempo de espera debe especificarse en milisegundos, con un valor predeterminado de 60 segundos.

MÉTODOS DE TIPO DE DATOS

Estos métodos no se suelen usar, ya que la mayoría de los servicios proporcionan datos de introspección para informar a los clientes sobre sus requisitos de tipado de datos. Sin embargo, si los datos de introspección son incompletos, puede ser necesario que un cliente marque los valores con tipos de datos específicos. En tal caso, se pueden usar los siguientes métodos. Sin embargo, no se exportan por defecto, por lo que deben solicitarse en el momento de la importación especificando 'use Net::DBus qw(:typing)'

my $valor_tipado = dbus_int16($valor);
Marca un valor como un entero de 16 bits con signo.
my $valor_tipado = dbus_uint16($valor);
Marca un valor como un entero de 16 bits sin signo.
my $valor_tipado = dbus_int32($valor);
Marca un valor como un entero de 32 bits con signo.
my $valor_tipado = dbus_uint32($valor);
Marca un valor como un entero de 32 bits sin signo.
my $valor_tipado = dbus_int64($valor);
Marca un valor como un entero de 64 bits sin signo.
my $valor_tipado = dbus_uint64($valor);
Marca un valor como un entero de 64 bits sin signo.
my $valor_tipado = dbus_double($valor);

Marca un valor como un flotante de doble precisión IEEE.
$typed_value = dbus_byte($value);
Marca un valor como un byte sin signo.
$typed_value = dbus_string($value);
Marca un valor como una cadena UTF-8. Esto no suele ser necesario ya que 'string' es el tipo de dato predeterminado para cualquier valor escalar de Perl.
$typed_value = dbus_signature($value);
Marca un valor como una cadena UTF-8, cuyo contenido es una firma de tipo válida.
$typed_value = dbus_object_path($value);
Marca un valor como una cadena UTF-8, cuyo contenido es una ruta de objeto válida.
$typed_value = dbus_boolean($value);
Marca un valor como un booleano.
$typed_value = dbus_array($value);
Marca un valor como un array.
$typed_value = dbus_struct($value);
Marca un valor como una estructura.
$typed_value = dbus_dict($value);
Marca un valor como un diccionario.
$typed_value = dbus_variant($value);
Marca un valor como una variante.
$typed_value = dbus_unix_fd($value);
Marca un valor como un descriptor de archivo de Unix.
