* Para establecer un límite en el tamaño de las redes procesadas o devueltas por NetAddr::IP.

Establece el número máximo de redes más allá del cual NetAddr::IP devolverá un error como una potencia de 2 (por defecto 16 o 65536 redes). Cada 2**16 consume aproximadamente 4 MB de memoria. Un 2**20 consume 64 MB de memoria, Un 2**24 consume 1 GB de memoria.

use NetAddr::IP qw(netlimit);
netlimit 20;

El netlimit máximo permitido es 2**24. Los intentos de establecer límites por debajo del valor predeterminado de 16 o por encima del máximo de 24 se ignoran.

Devuelve verdadero si tiene éxito, de lo contrario "undef".

Descomprime la distribución en un directorio apropiado y escribe:

perl Makefile.PL
make
make test

NetAddr::IP depende de NetAddr::IP::Util, que se instala por defecto con sus funciones principales compiladas usando extensiones XS de Perl para construir una biblioteca C. Si no tienes un compilador C disponible o prefieres la versión Pure Perl más lenta por alguna otra razón, entonces escribe:

perl Makefile.PL -noxs
make
make test
make install

DESCRIPCIÓN

Este módulo proporciona una abstracción orientada a objetos sobre direcciones IP o subredes IP que permite manipulaciones sencillas. La versión 4.xx de NetAddr::IP funcionará con versiones anteriores de Perl y es compatible con Math::BigInt.

La representación interna de todos los objetos IP está en notación IPv6 de 128 bits. Los objetos IPv4 e IPv6 pueden mezclarse libremente.

Operadores sobrecargados

Muchos operadores han sido sobrecargados, como se describe a continuación:

Asignación ("=")
Se ha optimizado para copiar un objeto NetAddr::IP a otro muy rápidamente.
"->copy()"
La operación de asignación ("=") se pone en operación solo cuando el objeto copiado es mutado posteriormente por otra operación sobrecargada. Ver las SÍMBOLOS ESPECIALES PARA "use overload" para más detalles.

"->copy()" crea realmente un nuevo objeto cuando se llama.

Apostrofización
Un objeto puede usarse como una cadena. Por ejemplo, el siguiente código: 
my $ip = new NetAddr::IP '192.168.1.123';
print "$ip\n";

Imprimirá la cadena 192.168.1.123/32.

Igualdad
Puedes probar la igualdad con "eq" o "==". "eq" permite la comparación con cadenas arbitrarias así como con objetos NetAddr::IP. El siguiente ejemplo: 
if (NetAddr::IP->new('127.0.0.1','255.0.0.0') eq '127.0.0.1/8')
   { print "Sí\n"; }

Imprimirá "Sí".

La comparación con "==" requiere que ambos operandos sean objetos NetAddr::IP.

En ambos casos, se devuelve un valor verdadero si la representación CIDR de los operandos es igual.

Comparación vía >, <, >=, <=, <=> y "cmp"
Internamente, todos los objetos de red se representan en formato de 128 bits. La representación numérica de la red se compara a través de la operación correspondiente. Las comparaciones se intentan primero en la parte de la dirección del objeto y si esta es igual, entonces se compara la parte CIDR NUMÉRICA de las máscaras. Esto lleva al resultado contraintuitivo de que 
/24 > /16

La comparación no debe realizarse en objetos netaddr con CIDR diferentes, ya que esto puede producir resultados indeterminados o inesperados; en lugar de eso, la determinación de qué bloque de red es mayor o menor debe hacerse comparando

$ip1->masklen <=> $ip2->masklen
Adición de una constante ("+")
Suma una constante con signo de 32 bits a la parte de la dirección de un objeto NetAddr. Esta operación cambia la parte de la dirección para apuntar tantas hosts por encima de la dirección de inicio del objeto actual. Por ejemplo, este código: 
print NetAddr::IP->new('127.0.0.1/8') + 5;

mostrará 127.0.0.6/8. La dirección se desbordará en la difusión de vuelta a la dirección de red. Este código:

print NetAddr::IP->new('10.0.0.1/24') + 255;
devuelve 10.0.0.0/24.

Devuelve el objeto sin cambios cuando la constante falta o está fuera de rango.

2147483647 <= constante >= -2147483648
Sustracción de una constante ("-")
El complemento de la adición de una constante.
Diferencia ("-")
Devuelve la diferencia entre las partes de dirección de dos objetos NetAddr::IP como un número con signo de 32 bits.

Devuelve undef si la diferencia está fuera de rango.

DESCRIPTION

NetAddr::IP is a module that allows you to manipulate network addresses and blocks of network addresses. It supports both IPv4 and IPv6 addresses.

SYNOPSIS

  use NetAddr::IP;

  # Create an IPv4 address object
  my $ip4 = NetAddr::IP->new('192.168.1.1/24');
  print $ip4->addr, "\n"; # 192.168.1.1
  print $ip4->mask, "\n"; # 255.255.255.0
  print $ip4->cidr, "\n"; # 192.168.1.1/24

  # Create an IPv6 address object
  my $ip6 = NetAddr::IP->new6('2001:db8::1/64');
  print $ip6->addr, "\n"; # 2001:db8::1
  print $ip6->mask, "\n"; # ffff:ffff:ffff:ffff::
  print $ip6->cidr, "\n"; # 2001:db8::1/64

  # Auto-increment and decrement
  $ip4++;
  print $ip4->addr, "\n"; # 192.168.1.2
  $ip4--;
  print $ip4->addr, "\n"; # 192.168.1.1

  # Get network and broadcast addresses
  my $subnet = NetAddr::IP->new('192.168.1.100/24');
  print $subnet->network, "\n";  # 192.168.1.0
  print $subnet->broadcast, "\n"; # 192.168.1.255

  # Check if one address contains another
  my $subnet_a = NetAddr::IP->new('192.168.1.0/24');
  my $subnet_b = NetAddr::IP->new('192.168.1.128/25');
  if ($subnet_a->contains($subnet_b)) {
    print "192.168.1.0/24 contains 192.168.1.128/25\n";
  }

  # Check if an address is within RFC1918 range
  if ($ip4->is_rfc1918) {
    print "192.168.1.1 is an RFC1918 address\n";
  }

OVERLOADING

The NetAddr::IP module overloads the C-style operators `++' and `--' for incrementing and decrementing addresses. It also overloads the stringification operator `""' to return the CIDR notation of the address.

Auto-increment
Auto-incrementing a NetAddr::IP object causes the address part to be adjusted to the next host address within the subnet. It will wrap at the broadcast address and start again from the network address.
Auto-decrement
Auto-decrementing a NetAddr::IP object performs exactly the opposite of auto-incrementing it, as you would expect.

Serializing and Deserializing

This module defines hooks to collaborate with Storable for serializing "NetAddr::IP" objects, through compact and human readable strings. You can revert to the old format by invoking this module as

use NetAddr::IP ':old_storable';

You must do this if you have legacy data files containing NetAddr::IP objects stored using the Storable module.

Methods

"->new([$addr, [ $mask|IPv6 ]])"
"->new6([$addr, [ $mask]])"
"->new_no([$addr, [ $mask]])"
"->new_from_aton($netaddr)"
new_cis and new_cis6 are DEPRECATED
"->new_cis("$addr $mask)"
"->new_cis6("$addr $mask)"
The first two methods create a new address with the supplied address in $addr and an optional netmask $mask, which can be omitted to get a /32 or /128 netmask for IPv4 / IPv6 addresses respectively.

The third method "new_no" is exclusively for IPv4 addresses and filters improperly formatted dot quad strings for leading 0's that would normally be interpreted as octal format by NetAddr per the specifications for inet_aton.

new_from_aton takes a packed IPv4 address and assumes a /32 mask. This function replaces the DEPRECATED :aton functionality which is fundamentally broken.

The last two methods new_cis and new_cis6 differ from new and new6 only in that they except the common Cisco address notation for address/mask pairs with a space as a separator instead of a slash (/)

These methods are DEPRECATED because the functionality is now included in the other "new" methods

i.e.  ->new_cis('1.2.3.0 24')

"->broadcast()"
Returns a new object referring to the broadcast address of a given subnet. The broadcast address has all ones in all the bit positions where the netmask has zero bits. This is normally used to address all the hosts in a given subnet.
"->network()"
Returns a new object referring to the network address of a given subnet. A network address has all zero bits where the bits of the netmask are zero. Normally this is used to refer to a subnet.
"->addr()"
Returns a scalar with the address part of the object as an IPv4 or IPv6 text string as appropriate. This is useful for printing or for passing the address part of the NetAddr::IP object to other components that expect an IP address. If the object is an ipV6 address or was created using ->new6($ip) it will be reported in ipV6 hex format otherwise it will be reported in dot quad format only if it resides in ipV4 address space.
"->mask()"
Returns a scalar with the mask as an IPv4 or IPv6 text string as described above.
"->masklen()"
Returns a scalar the number of one bits in the mask.
"->bits()"
Returns the width of the address in bits. Normally 32 for v4 and 128 for v6.
"->version()"
Returns the version of the address or subnet. Currently this can be either 4 or 6.
"->cidr()"
Returns a scalar with the address and mask in CIDR notation. A NetAddr::IP object stringifies to the result of this function. (see comments about ->new6() and ->addr() for output formats)
"->aton()"
Returns the address part of the NetAddr::IP object in the same format as the inet_aton() or "ipv6_aton" function respectively. If the object was created using ->new6($ip), the address returned will always be in ipV6 format, even for addresses in ipV4 address space.
"->range()"
Returns a scalar with the base address and the broadcast address separated by a dash and spaces. This is called range notation.
"->prefix()"
Returns a scalar with the address and mask in ipV4 prefix representation. This is useful for some programs, which expect its input to be in this format. This method will include the broadcast address in the encoding.
"->nprefix()"
Just as "->prefix()", but does not include the broadcast address.
"->numeric()"
When called in a scalar context, will return a numeric representation of the address part of the IP address. When called in an array contest, it returns a list of two elements. The first element is as described, the second element is the numeric representation of the netmask.

This method is essential for serializing the representation of a subnet.

"->bigint()"
When called in scalar context, will return a Math::BigInt representation of the address part of the IP address. When called in an array context, it returns a list of two elements, The first element is as described, the second element is the Math::BigInt representation of the netmask.
"->wildcard()"
When called in a scalar context, returns the wildcard bits corresponding to the mask, in dotted-quad or ipV6 format as applicable.

When called in an array context, returns a two-element array. The first element, is the address part. The second element, is the wildcard translation of the mask.

"->short()"
Returns the address part in a short or compact notation. 
(ie, 127.0.0.1 becomes 127.1).

Works with both, V4 and V6.

"->canon()"
Returns the address part in canonical notation as a string. For ipV4, this is dotted quad, and is the same as the return value from "->addr()". For ipV6 it is as per RFC5952, and is the same as the LOWER CASE value returned by "->short()".
"->full()"
Returns the address part in FULL notation for ipV4 and ipV6 respectively. 
i.e. for ipV4
  0000:0000:0000:0000:0000:0000:127.0.0.1
     for ipV6
  0000:0000:0000:0000:0000:0000:0000:0000

To force ipV4 addresses into full ipV6 format use:

"->full6()"
Returns the address part in FULL ipV6 notation
"->full6m()"
Returns the mask part in FULL ipV6 notation
"$me->contains($other)"
Returns true when $me completely contains $other. False is returned otherwise and "undef" is returned if $me and $other are not both "NetAddr::IP" objects.
"$me->within($other)"
The complement of "->contains()". Returns true when $me is completely contained within $other.

Note that $me and $other must be "NetAddr::IP" objects.

"->splitref($bits,[opcional $bits1,$bits2,...])"
Devuelve una referencia a una lista de objetos, representando subredes de la máscara "bits" producida al dividir el objeto original, el cual permanece sin cambios. Ten en cuenta que $bits debe ser más largo que la máscara original para que pueda ser dividido.

->splitref MORIRÁ con el mensaje 'netlimit exceeded'
  si el número de objetos devueltos excede 'netlimit'.
  Ver la función 'netlimit' arriba (por defecto 2**16 o 65536 redes).
->splitref devuelve undef cuando C<bits> o la (lista de bits)
  no caben dentro del objeto original.
->splitref devuelve undef si una máscara ipV4, ipV6 o NetAddr suministrada
  tiene un formato inapropiado,

bits puede ser una máscara CIDR, una cadena dot-quad o ipV6 o un objeto NetAddr::IP. Si "bits" falta, el objeto se divide en todas las direcciones disponibles dentro del objeto ipV4 o ipV6 (máscara automática de CIDR 32, 128 respectivamente).

Con una lista opcional adicional de "bits", el objeto original se divide en partes cuyo tamaño se basa en la lista. NOTA: una lista corta replicará el último elemento. Si el último elemento es demasiado grande para lo que queda del objeto después de dividir las primeras partes de la lista, se devolverá una lista de objetos restantes "que mejor se ajustan" basada en una ordenación creciente de los valores CIDR de la lista "bits".

Versión más rápida de "->hostenum()", que devuelve una referencia a una lista.

"$me->compact($addr1, $addr2, ...)"
"@lista_objetos_compacta = Compact(@lista_objetos)"
Dada una lista de objetos (incluyendo $me), este método compactará todas las direcciones y subredes en las subredes más grandes (es decir, menos específicas) posibles que contengan exactamente todos los objetos dados.

Tenga en cuenta que en versiones anteriores a 3.02, si se alimentaba con las mismas subredes IP varias veces, estas subredes se devolverían. A partir de la versión 3.02, se ha adoptado un enfoque más "correcto" y solo se devolvería una dirección.

Tenga en cuenta que $me y todos los $addr deben ser objetos "NetAddr::IP".

"$me->compactref(\@lista)"
"$lista_objetos_compacta = Compact(\@lista)"
Como de costumbre, una versión más rápida de "->compact()" que devuelve una referencia a una lista. Tenga en cuenta que este método toma una referencia a una lista en su lugar.

Tenga en cuenta que $me debe ser un objeto "NetAddr::IP".

"$me->coalesce($masklen, $number, @lista_de_subredes)"
"$referencia_array = Coalesce($masklen,$number,@lista_de_subredes)"
Devolverá una referencia a una lista de subredes "NetAddr::IP" de longitud de máscara $masklen, cuando se encuentre que $number o más direcciones de @lista_de_subredes están contenidas en dicha subred.

Las subredes de @lista_de_subredes con una máscara más corta que $masklen se pasan "tal cual" a la lista de retorno.

Las subredes de @lista_de_subredes con una máscara más larga que $masklen se contarán (de hecho, se cuenta el número de direcciones IP) hacia $number.

Cuando se llama como método, la lista incluirá $me.

ADVERTENCIA: la lista de subredes debe ser del mismo tipo. es decir, ipV4 o ipV6

"->first()"
Devuelve un nuevo objeto que representa la primera dirección IP utilizable dentro de la subred (es decir, la primera dirección de host).
"->last()"
Devuelve un nuevo objeto que representa la última dirección IP utilizable dentro de la subred (es decir, uno menos que la dirección de broadcast).
"->nth($index)"
Devuelve un nuevo objeto que representa la *n*-ésima dirección IP utilizable dentro de la subred (es decir, la *n*-ésima dirección de host). Si no hay ninguna dirección disponible (por ejemplo, cuando la red es demasiado pequeña para $index hosts), se devuelve "undef".

La versión 4.00 de NetAddr::IP y la versión 1.00 de NetAddr::IP::Lite implementan "->nth($index)" y "->num()" exactamente como indica la documentación. Las versiones anteriores se comportaban de manera ligeramente diferente y no consistente. Consulte el archivo README para obtener detalles.

Para usar el comportamiento anterior para "->nth($index)" y "->num()":

usar NetAddr::IP::Lite qw(:old_nth);
comportamiento antiguo:
NetAddr::IP->new('10/32')->nth(0) == undef
NetAddr::IP->new('10/32')->nth(1) == undef
NetAddr::IP->new('10/31')->nth(0) == undef
NetAddr::IP->new('10/31')->nth(1) == 10.0.0.1/31
NetAddr::IP->new('10/30')->nth(0) == undef
NetAddr::IP->new('10/30')->nth(1) == 10.0.0.1/30
NetAddr::IP->new('10/30')->nth(2) == 10.0.0.2/30
NetAddr::IP->new('10/30')->nth(3) == 10.0.0.3/30

Tenga en cuenta que en cada caso, la dirección de broadcast se representa en el conjunto de salida y que el índice 'cero' siempre es undef, excepto para una red punto a punto /31 o /127 donde hay exactamente dos direcciones en la red.

nuevo comportamiento:
NetAddr::IP->new('10/32')->nth(0)  == 10.0.0.0/32
NetAddr::IP->new('10.1/32'->nth(0) == 10.0.0.1/32
NetAddr::IP->new('10/31')->nth(0)  == 10.0.0.0/31
NetAddr::IP->new('10/31')->nth(1)  == 10.0.0.1/31
NetAddr::IP->new('10/30')->nth(0) == 10.0.0.1/30 
NetAddr::IP->new('10/30')->nth(1) == 10.0.0.2/30 
NetAddr::IP->new('10/30')->nth(2) == undef

Tenga en cuenta que una red /32 siempre tiene 1 dirección utilizable, mientras que una /31 tiene exactamente dos direcciones utilizables para direccionamiento punto a punto. El primer índice (0) devuelve la dirección inmediatamente posterior a la dirección de red, excepto para una /31 o /127, en cuyo caso devuelve la dirección de red.

"->num()"
A partir de la versión 4.42 de NetAddr::IP y la versión 1.27 de NetAddr::IP::Lite, una /31 y /127 devolverán un valor num de red de 2 en lugar de 0 (cero) para redes punto a punto.

La versión 4.00 de NetAddr::IP y la versión 1.00 de NetAddr::IP::Lite devuelven el número de direcciones IP utilizables dentro de la subred, sin contar la dirección de broadcast o de red.

Las versiones anteriores solo funcionaban para direcciones ipV4, devolvían un span máximo de 2**32 y devolvían el número de direcciones IP sin contar la dirección de broadcast.
(uno mayor que el nuevo comportamiento)

Para usar el comportamiento antiguo para "->nth($index)" y "->num()":

usar NetAddr::IP::Lite qw(:old_nth);

ADVERTENCIA:

NetAddr::IP calculará y devolverá una cadena numérica para rangos de red tan grandes como 2**128. Estos valores son cadenas de TEXTO y perl puede tratarlos como enteros para cálculos numéricos.

Perl en plataformas de 32 bits solo maneja números enteros hasta 2**32 y en plataformas de 64 bits hasta 2**64.

Si desea manipular cadenas numéricas devueltas por NetAddr::IP que son mayores que 2**32 o 2**64, respectivamente, debe cargar módulos adicionales como Math::BigInt, bignum o algún paquete similar para realizar las operaciones matemáticas de enteros.

"->re()"
Devuelve una expresión regular de Perl que coincidirá con una dirección IP dentro de la subred dada. Por defecto, utiliza la notación ipV4. Devolverá una expresión regular ipV6 si la dirección no está en el espacio ipV4.
"->re6()"
Devuelve una expresión regular de Perl que coincidirá con una dirección IP dentro de la subred dada. Siempre devuelve una expresión regular ipV6.
