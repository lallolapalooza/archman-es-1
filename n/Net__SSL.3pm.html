Net::SSL(3) Documentación de Perl aportada por el usuario Net::SSL(3)

NOMBRE

Net::SSL - soporte para Secure Sockets Layer

MÉTODOS

new
Crea un nuevo objeto "Net::SSL".
configure
Configura un socket "Net::SSL" para operar.
configure_certs
Configura un archivo de certificado para usarlo en la comunicación con el socket.
connect
die_with_error
get_cipher
get_lwp_object
Recorre la pila de llamadas y busca algo bendecido en el espacio de nombres "LWP::UserAgent" y lo devuelve. Vagamente obsoleto.
get_peer_certificate
Obtiene el certificado del par del objeto "Crypt::SSLeay::Conn" subyacente.
get_peer_verify
get_shared_ciphers
getchunk
Intenta leer hasta 32KiB de datos del socket. Devuelve "undef" si no se leyó nada, de lo contrario, devuelve los datos como un escalar.
pending
Proporciona acceso al atributo "pending" de OpenSSL en el objeto de conexión SSL.
getline
Lee un carácter a la vez hasta que se encuentra un salto de línea y devuelve la línea, incluido el salto de línea. Grotescamente ineficiente.
print
Concatena los parámetros de entrada y los escribe en el socket. No respeta $, ni $/. Devuelve el número de bytes escritos.
printf
Realiza un "sprintf" de los parámetros de entrada (por lo tanto, el primer parámetro debe ser el formato) y escribe el resultado en el socket. Devuelve el número de bytes escritos.
proxy
Devuelve el nombre de host de un servidor proxy https, según lo especificado por la variable de entorno "HTTPS_PROXY".
proxy_connect_helper
Ayuda a configurar una conexión a través de un proxy.
read
Realiza una lectura en el socket y devuelve el resultado.
ssl_context
sysread
Es un alias de "read".
timeout
Devuelve el valor de tiempo de espera del socket tal como lo define la clase implementadora o 60 segundos por defecto.
blocking
Devuelve un booleano que indica si el socket subyacente está en modo de bloqueo. Por defecto, los sockets Net::SSL están en modo de bloqueo. 
$sock->blocking(0); # establecer a modo no bloqueante

Este método simplemente llama al método "blocking" subyacente del objeto IO::Socket.

write
Escribe los parámetros pasados (por lo tanto, una lista) en el socket. Devuelve el número de bytes escritos.
syswrite
Es un alias de "write".
accept
Aún no implementado. Morirá si se llama.
getc
Aún no implementado. Morirá si se llama.
getlines
Aún no implementado. Morirá si se llama.
ungetc
Aún no implementado. Morirá si se llama.
send_useragent_to_proxy
Por defecto (desde la versión 2.80 de "Net::SSL" en la distribución 0.54 de Crypt::SSLeay), la cadena del agente de usuario ya no se envía al proxy (pero seguirá enviándose al host remoto).

El comportamiento anterior tenía un beneficio marginal y podía causar errores fatales en ciertos escenarios (ver error de CPAN #4759) por lo que ya no ocurre por defecto.

Para restablecer el comportamiento anterior, llame a "Net::SSL::send_useragent_to_proxy" con un valor verdadero (generalmente 1).

DIAGNÓSTICOS

"no port given for proxy server <proxy>"

Se especificó un proxy para configurar un socket, pero no se proporcionó ningún número de puerto. Asegúrese de que el proxy se especifique como un par host:puerto, como "proxy.example.com:8086".

"configure certs failed: <contents of $@>; <contents of $!>"
"proxy connect failed: <contents of $@>; <contents of $!>"
"Connect failed: <contents of $@>; <contents of $!>"

Durante connect().

VER TAMBIÉN

IO::Socket::INET
"Net::SSL" se implementa subclasificando "IO::Socket::INET", por lo tanto, los métodos no anulados específicamente están definidos por ese paquete.
Net::SSLeay
Un paquete que proporciona una interfaz a nivel de Perl a la biblioteca de capa de sockets seguros "openssl".
