Net::DNS::RR::HIP(3) Documentación de Perl aportada por el usuario Net::DNS::RR::HIP(3)

NOMBRE

Net::DNS::RR::HIP - Registro de recursos DNS HIP

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN HIP algorithm hit key servers');

DESCRIPCIÓN

Clase para registros de recursos DNS Host Identity Protocol (HIP).

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otros comportamientos impredecibles.

algorithm

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

El campo PK algorithm indica el algoritmo criptográfico de clave pública y el formato implícito del campo de clave pública. Los valores son los definidos para el tipo de algoritmo IPSECKEY [RFC4025].

hit

$hit = $rr->hit;
$rr->hit( $hit );

La representación hexadecimal de la etiqueta de identidad del host.

hitbin

$hitbin = $rr->hitbin;
$rr->hitbin( $hitbin );

La representación binaria de la etiqueta de identidad del host.

key

$key = $rr->key;
$rr->key( $key );

La representación MIME Base64 de la clave pública.

keybin

$keybin = $rr->keybin;
$rr->keybin( $keybin );

La representación binaria de la clave pública.

servers

@servers = $rr->servers;

Lista opcional de nombres de dominio de servidores de encuentro.
