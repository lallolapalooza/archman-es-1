NAME

Net::DBus::Binding::Introspector - Manejador de datos de introspección de objeto

SYNOPSIS

# Crear un objeto que popule con información de un documento XML conteniendo datos de introspección.
my $ins = Net::DBus::Binding::Introspector->new(xml => $data);
# Crear un objeto, definir datos de introspección programáticamente
my $ins = Net::DBus::Binding::Introspector->new(object_path => $object->get_object_path);
$ins->add_method("DoSomething", ["string"], [], "org.example.MyObject");
$ins->add_method("TestSomething", ["int32"], [], "org.example.MyObject");

DESCRIPTION

Esta clase es responsable de gestionar datos de introspección y responder a preguntas sobre ellos. Esto no es intencional para usuarios de aplicaciones, quienes deberían consultar la API superior en Net::DBus::Exporter.

Devuelve una lista de todas las interfaces proporcionadas por el objeto que contienen un método llamado $name. Esto puede ser una lista vacía. El parámetro opcional $interface puede limitar la verificación a solo esa interfaz.

Verifica si el llamante remoto está permitido a invocar el método $name en el objeto asociado con este introspector. Si este objeto tiene 'strict exports' activado, solo se permitirán métodos explícitamente exportados. El parámetro opcional $interface puede limitar la verificación a solo esa interfaz. Devuelve un valor no cero si el método debe ser permitido.

Devuelve una lista de todas las interfaces proporcionadas por el objeto que contienen un señal llamada $name. Esto puede ser una lista vacía.

Devuelve una lista de todas las interfaces proporcionadas por el objeto que contienen una propiedad llamada $name. Esto puede ser una lista vacía. El parámetro opcional $interface puede limitar la verificación a solo esa interfaz.
$ins->add_method($name, $params, $returns, $interface, $attributes, $paramnames, $returnnames);
Registrar el objeto como proporcionando un método llamado $name que acepte parámetros cuyos tipos son declarados por $params y devuelva valores cuyos tipos son declarados por $returns. El método se escalará a la interfaz nombrada por $interface. El parámetro $attributes es un diccionario de anotaciones del método. Los parámetros $paramnames y $returnames son una lista de nombres de argumento y valor devuelto.
$ins->add_signal($name, $params, $interface, $attributes);
Registrar el objeto como proporcionando una señal llamada $name con parámetros cuyos tipos son declarados por $params. La señal se escalará a la interfaz nombrada por $interface. El parámetro $attributes es un diccionario de anotaciones de la señal.
$ins->add_property($name, $type, $access, $interface, $attributes);
Registrar el objeto como proporcionando una propiedad llamada $name con un tipo de $type. El parámetro $access puede ser uno de "read", "write" o "readwrite". La propiedad se escalará a la interfaz nombrada por $interface. El parámetro $attributes es un diccionario de anotaciones.

NAME

Net::DBus::Binding::Introspector - introspection data API

SYNOPSIS

  use Net::DBus::Binding::Introspector;

  my $introspection = Net::DBus::Binding::Introspector->new();
  # ... populate $introspection ...
  my @methods = $introspection->get_methods($interface);
  my @signals = $introspection->get_signals($interface);
  # ... etc ...

DESCRIPTION

This class provides a Perl API to inspect the D-Bus introspection data for an interface.

METHODS

my $introspection = Net::DBus::Binding::Introspector->new()
Creates a new introspector object.
my $bool = $ins->load_xml_string($xml_string)
Loads introspection data from a string containing an XML document. Returns true on success.
my $bool = $ins->load_xml_file($filename)
Loads introspection data from the specified file. Returns true on success.
my @interfaces = $ins->get_interfaces()
Returns a list of all interfaces that have been loaded into the introspector.
my $bool = $ins->has_interface($interface)
Returns true if the specified interface name is loaded into the introspector.
my @methods = $ins->get_methods($interface)
Returns a list of method names for the specified interface.
my @signals = $ins->get_signals($interface)
Returns a list of signal names for the specified interface.
my @properties = $ins->get_properties($interface)
Returns a list of property names for the specified interface.
my $method_signature = $ins->get_method_signature($interface, $name)
Returns a string representing the signature of the method called $name within the interface $interface.
my $signal_signature = $ins->get_signal_signature($interface, $name)
Returns a string representing the signature of the signal called $name within the interface $interface.
my @types = $ins->get_method_return_types($interface, $name)
Returns a list of declared data types for return values of the method called $name within the interface $interface.
my @names = $ins->_method_return_names($interface, $name)
Returns a list of declared names for return values of the method called $name within the interface $interface.
my @types = $ins->get_signal_params($interface, $name)
Returns a list of declared data types for values associated with the signal called $name within the interface $interface.
my @types = $ins->get_signal_param_names($interface, $name)
Returns a list of declared names for values associated with the signal called $name within the interface $interface.
my $type = $ins->get_property_type($interface, $name)
Returns the declared data type for property called $name within the interface $interface.
my $bool = $ins->is_property_readable($interface, $name);
Returns a true value if the property called $name within the interface $interface can have its value read.
my $bool = $ins->is_property_writable($interface, $name);
Returns a true value if the property called $name within the interface $interface can have its value written to.
my $xml = $ins->format([$obj])
Return a string containing an XML document representing the state of the introspection data. The optional $obj parameter can be an instance of Net::DBus::Object to include object specific information in the XML (eg child nodes).
my $xml_fragment = $ins->to_xml
Returns a string containing an XML fragment representing the state of the introspection data. This is basically the same as the "format" method, but without the leading doctype declaration.
$type = $ins->to_xml_type($type)
Takes a text-based representation of a data type and returns the compact representation used in XML introspection data.
$ins->encode($message, $type, $name, $direction, @args)
Append a set of values <@args> to a message object $message. The $type parameter is either "signal" or "method" and $direction is either "params" or "returns". The introspection data will be queried to obtain the declared data types & the argument marshalling accordingly.
my @args = $ins->decode($message, $type, $name, $direction)
Unmarshalls the contents of a message object $message. The $type parameter is either "signal" or "method" and $direction is either "params" or "returns". The introspection data will be queried to obtain the declared data types & the arguments unmarshalled accordingly.
