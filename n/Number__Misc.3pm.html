Paquete: perl-number-misc

Licencias: PerlArtistic, GPL

Number::Misc(3) Documentación de Perl aportada por el usuario Number::Misc(3)

NOMBRE

Number::Misc - utilidades prácticas para números

SINOPSIS

use Number::Misc ':all';
is_numeric('x');        # falso
to_number('3,000');     # 3000
commafie('3000');       # 3,000
zero_pad(2, 10);        # 0000000002
rand_in_range(3, 10);   # un número aleatorio de 3 a 10, inclusive
is_even(3)              # verdadero
is_odd(4);              # falso

DESCRIPCIÓN

Number::Misc proporciona algunas utilidades prácticas misceláneas para manejar números. Estas utilidades manejan el procesamiento de números como cadenas, la determinación de propiedades básicas de los números o la selección de un número aleatorio de un rango.

INSTALACIÓN

Number::Misc se puede instalar con la rutina habitual:

perl Makefile.PL
make
make test
make install

FUNCIONES

is_numeric

Devuelve verdadero si el escalar dado es un número. Un valor indefinido devuelve falso. Un "número" se define como que consta únicamente de dígitos (es decir, los caracteres 0-9), con como máximo un punto decimal y como máximo un signo menos o más inicial.

is_numeric('3');       # verdadero
is_numeric('-3');      # verdadero
is_numeric('+3');      # verdadero
is_numeric('0003');    # verdadero
is_numeric('0.003');   # verdadero
is_numeric('0.00.3');  # falso
is_numeric('3,003');   # falso
is_numeric('  3');     # falso
is_numeric(undef);     # falso
opcion: convertible
Si quieres comprobar si la cadena podría ser un número si se procesara con to_number(), usa la opción convertible. 
is_numeric('3,003',  convertible=>1);  # verdadero
is_numeric('  3',    convertible=>1);  # verdadero
is_numeric('0.00.3', convertible=>1);  # falso

to_number

Convierte una cadena a un número eliminando comas y espacios. Si la cadena no se puede convertir, devuelve undef. Algunos ejemplos:

to_number(' 3 ');       # devuelve 3
to_number(' 3,000 ');   # devuelve 3000
to_number('whatever');  # devuelve undef
opcion: siempre_numero
Si la cadena no se puede convertir a un número, devuelve 0 en lugar de undef. Por ejemplo, esta llamada: 
to_number('whatever', always_number=>1)

devuelve 0.

commafie

Convierte un número a una cadena que representa el mismo número pero con comas

commafie(2000);     #  2,000
commafie(-2000);    # -1,000
commafie(2000.33);  #  2,000.33
commafie(100);      #    100

opcion: sep

La opción "sep" te permite establecer qué usar como separador en lugar de una coma. Por ejemplo, si quieres usar ":" en lugar de "," lo harías así:

commafie('2000', sep=>':');

lo que te daría esto:

2:000

zero_pad

Añade ceros al principio del número para que tenga una longitud determinada. El primer parámetro es el número, el segundo es la longitud objetivo. Si la longitud del número es igual o mayor que la longitud dada, no se realiza ningún cambio.

zero_pad(2, 3);   # 002
zero_pad(2, 10);  # 0000000002
zero_pad(444, 2); # 444

rand_in_range

Dados los límites inferior y superior, devuelve un número aleatorio mayor o igual que el límite inferior y menor o igual que el superior. Solo funciona con enteros.

rand_in_range(3, 10);   # un número aleatorio de 3 a 10, inclusive
rand_in_range(-1, 10);  # un número aleatorio de -1 a 10, inclusive

is_even / is_odd

"is_even" devuelve verdadero si el número es par. "is_odd" devuelve verdadero si el número es impar. Los no números y los decimales devuelven undef.
