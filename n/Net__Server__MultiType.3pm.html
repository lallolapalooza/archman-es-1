NOMBRE

Net::Server::MultiType - Personalidad de Net::Server

SINOPSIS

use base qw(Net::Server::MultiType);
sub process_request {
    #...código...
}
my @types = qw(PreFork Fork Single);
Net::Server::MultiType->run(server_type => \@types);

DESCRIPCIÓN

Por favor, lea primero la documentación de Net::Server. Este módulo es una personalidad, o extensión, o sub-clase del módulo Net::Server.

Esta personalidad está pensada para permitir un uso fácil de múltiples personalidades de Net::Server. Dado una lista de tipos de servidor, Net::Server::MultiType requerirá uno a la vez hasta que encuentre uno que esté instalado en el sistema. Luego, añade ese paquete a su @ISA, heredando así los métodos de esa personalidad.

ARGUMENTOS

Además de los argumentos de línea de comandos de la clase base Net::Server, Net::Server::MultiType contiene un parámetro configurable adicional.

Clave         Valor           Predeterminado
server_type   'server_type'   'Single'
server_type
Puede ser llamado muchas veces para construir un array de posibles tipos de servidor. En tiempo de ejecución, Net::Server::MultiType encontrará el primero disponible y luego heredará los métodos de esa personalidad.

ARCHIVO DE CONFIGURACIÓN

"Net::Server::MultiType" permite el uso de un archivo de configuración para leer parámetros del servidor. El formato de este archivo de configuración son simples pares clave-valor. Los comentarios y los espacios en blanco se ignoran.

#-------------- archivo test.conf --------------
### información de tipo de servidor
### prueba PreFork primero, luego ve a Single
server_type PreFork
server_type Single
### información del servidor
min_servers   20
max_servers   80
spare_servers 10
max_requests  1000
### usuario y grupo a los que convertirse
user        alguien
group       todos
### ¿registro?
log_file    /var/log/server.log
log_level   3
pid_file    /tmp/server.pid
### control de acceso
allow       .+\.(net|com)
allow       domain\.com
deny        a.+
### ¿ejecutar el proceso en segundo plano?
background  1
### puertos a los que enlazar
host        127.0.0.1
port        localhost:20204
port        20205
### ¿búsquedas inversas?
# reverse_lookups on
#-------------- archivo test.conf --------------
