NetAddr::IP::UtilPP -- funciones puras de Perl para NetAddr::IP::Util

SINOPSIS

use NetAddr::IP::UtilPP qw(
      hasbits
      shiftleft
      addconst
      add128
      sub128
      notcontiguous
      ipv4to6
      mask4to6
      ipanyto6
      maskanyto6
      ipv6to4
      bin2bcd
      bcd2bin
);
use NetAddr::IP::UtilPP qw(:all)
$rv = hasbits($bits128);
$bitsX2 = shiftleft($bits128,$n);
$carry = addconst($ipv6naddr,$signed_32con);
($carry,$ipv6naddr)=addconst($ipv6naddr,$signed_32con);
$carry = add128($ipv6naddr1,$ipv6naddr2);
($carry,$ipv6naddr)=add128($ipv6naddr1,$ipv6naddr2);
$carry = sub128($ipv6naddr1,$ipv6naddr2);
($spurious,$cidr) = notcontiguous($mask128);
($carry,$ipv6naddr)=sub128($ipv6naddr1,$ipv6naddr2);
$ipv6naddr = ipv4to6($netaddr);
$ipv6naddr = mask4to6($netaddr);
$ipv6naddr = ipanyto6($netaddr);
$ipv6naddr = maskanyto6($netaddr);
$netaddr = ipv6to4($pv6naddr);
$bcdtext = bin2bcd($bits128);
$bits128 = bcd2bin($bcdtxt);

DESCRIPCIÓN

NetAddr::IP::UtilPP proporciona funciones puras de Perl para NetAddr::IP::Util

  • $rv = hasbits($bits128);

    Esta función devuelve verdadero si hay unos presentes en la cadena de 128 bits y falso si todos los bits son cero.

    es decir,  if (hasbits($bits128)) {
        &do_something;
      }
o    if (hasbits($bits128 & $mask128) {
        &do_something;
      }

    Esto permite la implementación de funciones lógicas de la forma:

          if ($bits128 & $mask128) {
          ...
entrada:        cadena IPv6 de 128 bits
devuelve:      verdadero si hay bits presentes
  • $bitsXn = shiftleft($bits128,$n); 
    entrada:        variable de cadena de 128 bits,
              número de desplazamientos [opcional]
devuelve:      bits desplazados N veces
NOTA: se devuelven los bits de entrada
      si $n no está especificado
  • addconst($ipv6naddr,$signed_32con);

    Suma una constante con signo a una cadena de 128 bits.

    entrada:        cadena IPv6 de 128 bits,
              entero con signo de 32 bits
devuelve:  escalar      acarreo
          array       (acarreo, resultado)
  • add128($ipv6naddr1,$ipv6naddr2);

    Suma dos variables de cadena de 128 bits.

    entrada:        variable de cadena de 128 bits 1,
              variable de cadena de 128 bits 2
devuelve:  escalar      acarreo
          array       (acarreo, resultado)
  • sub128($ipv6naddr1,$ipv6naddr2);

    Resta dos variables de cadena de 128 bits.

    entrada:        variable de cadena de 128 bits 1,
              variable de cadena de 128 bits 2
devuelve:  escalar      acarreo
          array       (acarreo, resultado)

    Nota: El acarreo de esta operación es el resultado de sumar el complemento a uno del ARG2 +1 al ARG1. Lógicamente **NO es un préstamo**.

    es decir,  si ARG1 >= ARG2 entonces acarreo = 1
o      si ARG1  < ARG2 entonces acarreo = 0
  • ($spurious,$cidr) = notcontiguous($mask128);

    Esta función cuenta las posiciones de bits restantes en la máscara cuando se eliminan los '0' más a la derecha.

    entrada:  máscara de red de 128 bits
devuelve verdadero si hay ceros espurios
            restantes en la máscara, falso si la máscara
            es una secuencia contigua de unos,
        máscara de red CIDR de 128 bits
  • $ipv6naddr = ipv4to6($netaddr);

    Convierte una dirección de red ipv4 en una dirección de red ipv6.

    entrada:        dirección de red de 32 bits
devuelve:      dirección de red de 128 bits
  • $ipv6naddr = mask4to6($netaddr);

    Convierte una dirección de red/máscara ipv4 en una máscara de red ipv6.

    entrada:        dirección de red/máscara de 32 bits
devuelve:      dirección de red/máscara de 128 bits

    NOTA: devuelve los 96 bits superiores como unos

  • $ipv6naddr = ipanyto6($netaddr);

    Similar a ipv4to6 excepto que esta función toma una entrada IPv4 o IPv6 y siempre devuelve una dirección de red IPv6 de 128 bits.

    entrada:        dirección de red de 32 o 128 bits
devuelve:      dirección de red de 128 bits
  • $ipv6naddr = maskanyto6($netaddr);

    Similar a mask4to6 excepto que esta función toma una máscara de red IPv4 o IPv6 y siempre devuelve una máscara de red IPv6 de 128 bits.

    entrada:        máscara de red de 32 o 128 bits
devuelve:      máscara de red de 128 bits
  • $netaddr = ipv6to4($pv6naddr);

    Trunca los 96 bits superiores de una dirección de 128 bits y devuelve los 32 bits inferiores. Devuelve una dirección IPv4 tal como la devuelve inet_aton.

    entrada:        dirección de red de 128 bits
devuelve:      dirección de red inet_aton de 32 bits
  • $bcdtext = bin2bcd($bits128);

    Convierte una cadena binaria de 128 bits en dígitos decimales codificados en binario (BCD).

    entrada:        variable de cadena de 128 bits
devuelve:      cadena de dígitos de texto BCD
  • $bits128 = bcd2bin($bcdtxt);

    Convierte una cadena de texto BCD en una variable de cadena de 128 bits

    entrada:        cadena de dígitos de texto BCD
devuelve:      variable de cadena de 128 bits

NetAddr::IP::UtilPP(3pm)

NetAddr::IP::UtilPP - Funciones de utilidad para NetAddr::IP implementadas en C

Autor: David E. Wheeler <david@kineticode.com>

Versión: 0.09

Fecha: 2016-04-29

Sección: 3pm

DESCRIPCIÓN

Esta es una implementación de algunas de las funciones de utilidad de NetAddr::IP escritas en C. La idea es que sea más rápida que la implementación de Perl en NetAddr::IP, y así sólo se utiliza para las partes que más se benefician de la velocidad.

Funciones

ip_aton($ip_string)

Convierte una cadena de direcciones IP a un entero de 32 bits. Devuelve undef si la cadena no es válida. La cadena se interpreta como una dirección IPv4.

ip_ntoa($ip_int)

Convierte un entero de 32 bits en una cadena de dirección IPv4.

ip_is_private($ip_string)

Devuelve verdadero si la dirección IP dada pertenece a un espacio de direcciones privado según RFC 1918. Las direcciones IPv6 también pueden ser privadas según RFC 4193, pero esta función sólo comprueba las direcciones IPv4.

ip_is_linklocal($ip_string)

Devuelve verdadero si la dirección IP dada es una dirección de enlace local. Para IPv4, esto significa 169.254/16. Para IPv6, esto significa fe80::/10.

ip_is_loopback($ip_string)

Devuelve verdadero si la dirección IP dada es una dirección de loopback. Para IPv4, esto significa 127.0.0.0/8. Para IPv6, esto significa ::1.

ip_is_multicast($ip_string)

Devuelve verdadero si la dirección IP dada es una dirección multicast. Para IPv4, esto significa 224.0.0.0/4. Para IPv6, esto significa ff00::/8.

ip_is_documentation($ip_string)

Devuelve verdadero si la dirección IP dada está en un espacio de direcciones destinado a la documentación. Esto incluye 192.0.2.0/24, 198.51.100.0/24 y 203.0.113.0/24 según RFC 5737.
