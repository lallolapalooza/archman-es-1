Net::Jabber::Dialback::Verify(3) Documentación de Perl aportada por el usuario Net::Jabber::Dialback::Verify(3)

NOMBRE

Net::Jabber::Dialback::Verify - Módulo de verificación de Dialback de Jabber

SINOPSIS

Net::Jabber::Dialback::Verify es un complemento del módulo Net::Jabber::Dialback.
Proporciona al usuario una interfaz simple para establecer y recuperar todas
las partes de una verificación de Dialback de Jabber.

DESCRIPCIÓN

Para inicializar el Dialback con un <db:*/> de Jabber, debe pasarle el
hash de XML::Stream. Por ejemplo:
  my $dialback = new Net::Jabber::Dialback::Verify(%hash);
Ha habido un cambio en la antigua forma de manejar las devoluciones de llamada.
Ya no tiene que hacer lo anterior usted mismo, se pasa un objeto NJ::Dialback::Verify
a la función de devolución de llamada para el mensaje. Además,
el primer argumento a las funciones de devolución de llamada es el ID de sesión de
XML::Streams. Hay algunos casos en los que podría querer esta
información, como si hubiera creado un Cliente que se conecta a dos servidores
a la vez, o para escribir un mini servidor.
  use Net::Jabber qw(Server);
  sub dialbackVerify {
    my ($sid,$Verify) = @_;
    .
    .
    .
  }
Ahora tiene acceso a todas las funciones de recuperación disponibles.
Para crear un nuevo dialback para enviar al servidor:
  use Net::Jabber qw(Server);
  $Verify = new Net::Jabber::Dialback::Verify();
Ahora puede llamar a las funciones de creación a continuación para poblar la etiqueta antes
de enviarla.
Para obtener más información sobre el formato de matriz que se pasa a la devolucion de llamada,
lea la documentación de Net::Jabber::Client.

Funciones de recuperación

$to         = $Verify->GetTo();
$from       = $Verify->GetFrom();
$type       = $Verify->GetType();
$id         = $Verify->GetID();
$data       = $Verify->GetData();
$str        = $Verify->GetXML();
@dialback   = $Verify->GetTree();

Funciones de creación

$Verify->SetVerify(from=>"jabber.org",
                   to=>"jabber.com",
                   id=>id,
                   data=>key);
$Verify->SetTo("jabber.org");
$Verify->SetFrom("jabber.com");
$Verify->SetType("valid");
$Verify->SetID(id);
$Verify->SetData(key);

Funciones de prueba

$test = $Verify->DefinedTo();
$test = $Verify->DefinedFrom();
$test = $Verify->DefinedType();
$test = $Verify->DefinedID();

MÉTODOS

Funciones de recuperación

GetTo() -  devuelve una cadena con el servidor al que se está
           enviando el <db:verify/>.
GetFrom() -  devuelve una cadena con el servidor desde el que se está
             enviando el <db:verify/>.
GetType() - devuelve una cadena con el tipo de <db:verify/> que es.
GetID() - devuelve una cadena con el id de <db:verify/> que es.
GetData() - devuelve una cadena con los cdata del <db:verify/>.
GetXML() - devuelve la cadena XML que representa el <db:verify/>.
           Esto es utilizado por la función Send() en Server.pm para enviar
           este objeto como una verificación de Dialback de Jabber.
GetTree() - devuelve una matriz que contiene la etiqueta <db:verify/>
            en formato XML::Parser::Tree.

Funciones de creación

SetVerify(to=>cadena,   - establece varios campos en el <db:verify/>
          from=>cadena,   a la vez. Esta es una acción acumulativa
          type=>cadena,   y de sobrescritura. Si establece
          id=>cadena,     el atributo "from" dos veces, la segunda
          data=>cadena)   asignación es la que se utiliza. Si establece
                          el tipo y luego establece los datos,
                          entonces ambos estarán en la etiqueta <db:verify/>.
                          Para configuraciones válidas, lea las
                          funciones Set específicas a continuación.
SetTo(cadena) - establece el atributo to.
SetFrom(cadena) - establece el atributo from.
SetType(cadena) - establece el atributo type. Configuraciones válidas son:
                  valid (válido)
                  invalid (inválido)
SetID(cadena) - establece el atributo id.
SetData(cadena) - establece los cdata del <db:verify/>.

Funciones de prueba

DefinedTo() - devuelve 1 si el atributo to está definido en el
              <db:verify/>, 0 en caso contrario.
DefinedFrom() - devuelve 1 si el atributo from está definido en el
                <db:verify/>, 0 en caso contrario.
DefinedType() - devuelve 1 si el atributo type está definido en el
                <db:verify/>, 0 en caso contrario.
DefinedID() - devuelve 1 si el atributo id está definido en el
                <db:verify/>, 0 en caso contrario.
