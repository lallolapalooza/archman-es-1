Net::netent(3perl) Guía de programación de Perl Net::netent(3perl)

NOMBRE

Net::netent - interfaz por nombre a las funciones integradas de Perl getnet*()

SINOPSIS

use Net::netent qw(:FIELDS);
getnetbyname("loopback")               or die "red incorrecta";
printf "%s es %08X\n", $n_name, $n_net;
use Net::netent;
$n = getnetbyname("loopback")          or die "red incorrecta";
{ # tiene que haber una mejor manera, ¿eh?
    @bytes = unpack("C4", pack("N", $n->net));
    shift @bytes while @bytes && $bytes[0] == 0;
}
printf "%s es %08X [%d.%d.%d.%d]\n", $n->name, $n->net, @bytes;

DESCRIPCIÓN

Las exportaciones por defecto de este módulo anulan las funciones centrales getnetbyname() y getnetbyaddr(), reemplazándolas por versiones que devuelven objetos "Net::netent". Este objeto tiene métodos que devuelven el nombre del campo de estructura del mismo nombre de la estructura C netent de netdb.h; a saber, name, aliases, addrtype y net. El método aliases devuelve una referencia de matriz, el resto escalares.

También puede importar todos los campos de la estructura directamente en su espacio de nombres como variables regulares usando la etiqueta de importación :FIELDS. (Tenga en cuenta que esto todavía anula sus funciones centrales). Acceda a estos campos como variables con un prefijo "n_". Por lo tanto, "$net_obj->name()" corresponde a $n_name si importa los campos. Las referencias a matriz están disponibles como variables de matriz regulares, por lo que, por ejemplo, "@{ $net_obj->aliases() }" sería simplemente @n_aliases.

La función getnet() es un simple front-end que reenvía un argumento numérico a getnetbyaddr(), y el resto a getnetbyname().

Para acceder a esta funcionalidad sin las anulaciones centrales, pase a "use" una lista de importación vacía y luego acceda a las funciones con sus nombres completos calificados. Por otro lado, las funciones integradas todavía están disponibles a través del pseudopaquete "CORE::".

EJEMPLOS

Las funciones getnet() hacen esto en el núcleo de Perl:

sv_setiv(sv, (I32)nent->n_net);

Las funciones gethost() hacen esto en el núcleo de Perl:

sv_setpvn(sv, hent->h_addr, len);

Eso significa que la dirección se devuelve en binario para las funciones de host y como un entero perl regular para las de red. Esto parece un error, pero aquí se explica cómo manejarlo:

use strict;
use Socket;
use Net::netent;
@ARGV = ('loopback') unless @ARGV;
my($n, $net);
for $net ( @ARGV ) {
    unless ($n = getnetbyname($net)) {
       warn "$0: no such net: $net\n";
       next;
    }
    printf "\n%s is %s%s\n", 
           $net, 
           lc($n->name) eq lc($net) ? "" : "*really* ",
           $n->name;
    print "\taliases are ", join(", ", @{$n->aliases}), "\n"
               if @{$n->aliases};     
    # esto es estúpido; primero, ¿por qué no está esto en binario?
    # segundo, ¿por qué paso por estas circunvoluciones
    # para que se vea bien?
    {
       my @a = unpack("C4", pack("N", $n->net));
       shift @a while @a && $a[0] == 0;
       printf "\taddr is %s [%d.%d.%d.%d]\n", $n->net, @a;
    }
    if ($n = getnetbyaddr($n->net)) {
       if (lc($n->name) ne lc($net)) {
           printf "\t¡Esa dirección se invierte a la red %s!\n", $n->name;
           $net = $n->name;
           redo;
       } 
    }
}

NOTA

Si bien esta clase se implementa actualmente utilizando el módulo Class::Struct para crear una clase similar a una estructura, no debe confiar en esto.
