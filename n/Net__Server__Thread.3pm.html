NOMBRE

Net::Server::Thread - Personalidad de Net::Server

SINOPSIS

use base qw(Net::Server::Thread);
sub process_request {
    #...código...
}
__PACKAGE__->run();

DESCRIPCIÓN

Por favor, lee primero el pod de Net::Server. Este módulo es una personalidad, o extensión, o sub-clase del módulo Net::Server.

Esta personalidad se enlaza a uno o más puertos y luego espera una conexión de cliente. Cuando se recibe una conexión, el servidor genera un nuevo hilo. El hilo maneja la solicitud y luego se cierra.

Dado que esta variante de Net::Server genera y destruye un hilo para cada solicitud, solo debería usarse donde el procesamiento de cada solicitud pueda ser largo o complejo. Si se utilizan solicitudes cortas y ligeras, perl podría no devolver voluntariamente la memoria utilizada. Esto depende mucho del sistema.

ARGUMENTOS

check_for_dead
Número de segundos a esperar antes de buscar hijos muertos. Esto solo tiene lugar si se ha alcanzado el número máximo de procesos hijos (max_servers). El valor predeterminado es 60 segundos.
max_servers
El número máximo de hijos a bifurcar. El servidor no aceptará conexiones hasta que haya hijos libres. El valor predeterminado es 256 hijos.

ARCHIVO DE CONFIGURACIÓN

Ver Net::Server.

FLUJO DE PROCESOS

El flujo de procesos sigue a Net::Server hasta la fase post_accept. En este punto se bifurca un hijo. El proceso padre es capaz de inmediatamente esperar otra solicitud. El hijo maneja la solicitud y luego sale.

GANCHOS

El servidor Fork tiene los siguientes ganchos además de los ganchos proporcionados por la clase base Net::Server. Ver Net::Server

"$self->pre_accept_hook()"
Este gancho ocurre justo antes de llamar a accept.
"$self->pre_thread_hook()"
Este gancho ocurre justo después de accept pero antes de la bifurcación.
"$self->post_accept_hook()"
Este gancho ocurre en el hijo después de accept y la bifurcación.
