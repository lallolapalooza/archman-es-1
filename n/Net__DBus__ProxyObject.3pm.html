Net::DBus::ProxyObject(3) Documentación de Perl aportada por el usuario Net::DBus::ProxyObject(3)

NOMBRE

Net::DBus::ProxyObject - Implementa objetos para exportar al bus

SINÓPSIS

# Conectar un objeto al bus, bajo un servicio
package main;
use Net::DBus;
# Adjuntarse al bus
my $bus = Net::DBus->find;
# Crear la instancia del objeto de nuestra aplicación
my $object = Demo::HelloWorld->new()
# Adquirir un servicio 'org.demo.Hello'
my $service = $bus->export_service("org.demo.Hello");
# Finalmente exportar el objeto al bus
my $proxy = Demo::HelloWorld::DBus->new($object);
....resto del programa...
# Definir un nuevo paquete para el objeto que vamos
# a exportar
package Demo::HelloWorld;
sub new {
    my $class = shift;
    my $service = shift;
    my $self = {};
    $self->{sighandler} = undef;
    bless $self, $class;
    return $self;
}
sub sighandler {
    my $self = shift;
    my $callback = shift;
    $self->[sighandler} = $callback;
}
sub Hello {
  my $self = shift;
  my $name = shift;
  &{$self->{sighandler}}("Greeting", "Hello $name");
  return "Said hello to $name";
}
sub Goodbye {
  my $self = shift;
  my $name = shift;
  &{$self->{sighandler}}("Greeting", "Goodbye $name");
  return "Said goodbye to $name";
}
# Definir un nuevo paquete para el objeto que vamos
# a exportar
package Demo::HelloWorld::DBus;
# Especificar la interfaz principal proporcionada por nuestro objeto
use Net::DBus::Exporter qw(org.example.demo.Greeter);
# Vamos a ser un objeto DBus
use base qw(Net::DBus::ProxyObject);
# Exportar una señal 'Greeting' que toma un parámetro de cadena
dbus_signal("Greeting", ["string"]);
# Exportar 'Hello' como un método que acepta un único parámetro de cadena
# y devuelve un valor de cadena
dbus_method("Hello", ["string"], ["string"]);
sub new {
    my $class = shift;
    my $service = shift;
    my $impl = shfit;
    my $self = $class->SUPER::new($service, "/org/demo/HelloWorld", $impl);
    bless $self, $class;
    $self->sighandler(sub {
        my $signame = shift;
        my $arg = shift;
        $self->emit_signal($signame, $arg);
    });
    return $self;
}
# Exportar 'Goodbye' como un método que acepta un único parámetro de cadena
# y devuelve una cadena, pero ponerlo en la interfaz 'org.exaple.demo.Farewell'
dbus_method("Goodbye", ["string"], ["string"], "org.example.demo.Farewell");

DESCRIPCIÓN

Esta es la base para crear un proxy entre un objeto de bus y el objeto de una aplicación. Permite que el modelo de objetos de la aplicación se mantenga separado del modelo de objetos RPC. El objeto proxy reenviará las llamadas a métodos desde el bus al objeto de implementación. El objeto proxy también puede registrar callbacks contra el objeto de la aplicación, que puede utilizar para emitir señales en el bus.

MÉTODOS

mi $objeto = Net::DBus::ProxyObject->new($servicio, $ruta, $impl)
Esto crea un nuevo objeto DBus con una ruta de $ruta registrada dentro del servicio $servicio. El parámetro $ruta debería ser una cadena que cumpla con los requisitos habituales de DBus para rutas de objetos, mientras que el parámetro $servicio debería ser una instancia de Net::DBus::Service. Este último se obtiene típicamente llamando al método "export_service" en el objeto Net::DBus. El parámetro $impl es el objeto de la aplicación que implementará los métodos que se exportan al bus.
mi $objeto = Net::DBus::ProxyObject->new($objetopadre, $subruta, $impl)
Esto crea un nuevo objeto hijo de DBus con una ruta de $subruta relativa a su padre $objetopadre. El parámetro $subruta debería ser una cadena que cumpla con los requisitos habituales de DBus para rutas de objetos, mientras que el parámetro $objetopadre debería ser una instancia de Net::DBus::BaseObject o una subclase. El parámetro $impl es el objeto de la aplicación que implementará los métodos que se exportan al bus.
