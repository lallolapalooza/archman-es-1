Net::Server::Log::Log::Log4perl(3) Documentación contribuida por el usuario de Perl Net::Server::Log::Log::Log4perl(3)

NOMBRE

Net::Server::Log::Log::Log4perl - registrar a través de Log4perl

SINOPSIS

use base qw(Net::Server::PreFork);
__PACKAGE__->run(
    log_file => 'Log::Log4perl',
    log4perl_conf => '/ruta/a/mi/log4perl.conf',
    log4perl_logger => 'myapp',
);

DESCRIPCIÓN

Este módulo proporciona registro al estilo Log::Log4perl al sistema Net::Server.

CONFIGURACIÓN

log_file
Para empezar a usar el registro de Log::Log4perl, simplemente establezca el parámetro de configuración log_file de Net::Server a "Log::Log4perl".

Si se usa el nombre mágico "Log::Log4perl", todo el registro se dirigirá al sistema Log4perl. Si se usa, también se pueden definir "log4perl_conf", "log4perl_poll", "log4perl_logger".

log4perl_conf
Solo disponible si "log_file" es igual a "Log::Log4perl". Este es el nombre del archivo de configuración de log4perl - ver Log::Log4perl. Si no está configurado, morirá al arrancar. Si el archivo no es legible, morirá.
log4perl_poll
Si se establece en un valor, se inicializará con Log::Log4perl::init_and_watch con este valor de sondeo. Esto también puede ser la cadena "HUP" para volver a leer el log4perl_conf al recibir una señal HUP. Si se establece en 0, no se realiza ningún sondeo. Ver Log::Log4perl para más detalles.
log4perl_logger
Este es el nombre de la instalación. Por defecto es "Net::Server".

ARGUMENTOS POR DEFECTO PARA Net::Server

Los siguientes argumentos están disponibles en los módulos "Net::Server" o "Net::Server::Single" por defecto. (Otras personalidades pueden usar parámetros adicionales y opcionalmente no usar parámetros de la clase base.)

Clave               Valor                    Por defecto
## parámetros de log4perl (si log_file eq Log::Log4perl)
log4perl_conf     "nombre_archivo"           morirá si no está configurado
log4perl_poll     número o HUP             0 (sin sondeo)
log4perl_logger   "nombre"                 "Net::Server"

MÉTODOS

"initialize"
Este método se llama durante el método initialize_logging de Net::Server. Devuelve una única referencia de código que se almacenará bajo la propiedad log_function del objeto Net::Server. Esa referencia de código toma log_level y mensaje como argumentos y llama al sistema log4perl inicializado.

LICENCIA
