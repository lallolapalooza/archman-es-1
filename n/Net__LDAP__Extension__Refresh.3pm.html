Net::LDAP::Extension::Refresh(3) Documentación de Perl contribuida por el usuario Net::LDAP::Extension::Refresh(3)

NOMBRE

Net::LDAP::Extension::Refresh - Objeto de extensión Refresh de LDAPv3 (RFC 2589)

SINOPSIS

use Net::LDAP;
use Net::LDAP::Extension::Refresh;
$ldap = Net::LDAP->new('localhost');
$ldap->bind('cn=admin,dc=example,dc=com', password => 'password');
$mesg = $ldap->refresh(entryName => 'cn=dynamic,dc=example,dc=com',
       requestTtl => 100);
die "error :", $mesg->code(), ": ", $mesg->error()  if ($mesg->code());
print "TTL cambiado a ", $mesg->get_ttl(), "\n";

DESCRIPCIÓN

"Net::LDAP::Extension::Refresh" implementa la operación extendida de LDAPv3 "Refresh" descrita en la RFC 2589.

No implementa ningún objeto por sí misma, sino que extiende el objeto Net::LDAP con otro método:

MÉTODOS

refresh ( OPCIONES )
Envía una operación de refresh para un objeto.

OPCIONES es una lista de pares clave/valor. Las siguientes claves se reconocen:

entryName
Esta opción contiene el objeto a refrescar. Debe ser un DN.
requestTtl
Esta opción contiene el TTL en segundos solicitado. El servidor puede optar por establecer otro valor como se indica en la RFC 2589.
get_ttl ( )
Devuelve el TTL establecido por el servidor durante la llamada "refresh" anterior.

Este método es un método del objeto de respuesta Net::LDAP::Message devuelto en respuesta a refresh() en caso de que la llamada refresh() tuviera éxito.

VER TAMBIÉN

Net::LDAP, Net::LDAP::Extension
