Net::DNS::SEC::Tools::Donuts(3) Documentación de Perl aportada por el usuario Net::DNS::SEC::Tools::Donuts(3)

NOMBRE

Net::DNS::SEC::Tools::Donuts - Ejecuta pruebas similares a lint de DNS y DNSSEC en datos de zona

SINOPSIS

# carga una zona, reglas y analiza todo
#   por defecto, esto imprimirá errores en formato de 'texto envuelto'
#   en stdout.
my $donuts = new Net::DNS::SEC::Tools::Donuts();
$donuts->load_zone("/ruta/a/example.com.signed", "example.com");
$donuts->load_rule_files("/ruta/a/reglas/instaladas/*.txt");
my ($rulecount, $errorcount) = $donuts->analyze();
# envía la salida en formato json a /tmp/foo.json en su lugar
$donuts->set_output_format('json');
$donuts->set_output_location('file:/tmp/foo.json');
$donuts->analyze();
# muestra las características disponibles
print "características: ", join(", ", $donuts->available_features()), "\n";
# habilita las características 'live' y 'check_data' en los conjuntos de reglas
$donuts->set_feature_list('live', 'check_data);
# ignora algunas reglas (expresiones regulares para coincidir con los nombres de las reglas)
$donuts->set_ignore_list('NSEC');
# recupera las reglas cargadas en la zona
my @rules = $donuts->rules();
# recupera los registros de la zona cargada
#  (estos serán registros basados en Net::DNS::RR)
my @records = $donuts->zone_records();
# o solo de un nombre determinado:
#   (estos serán una referencia hash como { tipo => [registros] })
my $records = $donuts->find_records_by_name('www.example.com');
# o solo de un tipo para un nombre:
#   (estos serán una referencia de array a los [registros])
my $records =
   $donuts->find_records_by_name_and_type('www.example.com', 'A');

DESCRIPCIÓN

El módulo Net::DNS::SEC::Tools::Donuts (también conocido como Donuts) es capaz de cargar un archivo de zona, reglas para probarlas y luego analizar las reglas e informar los resultados.

Creando una instancia de Donuts

Crear una instancia de un objeto Donuts es sencillo:

use Net::DNS::SEC::Tools::Donuts
my $donuts = new Net::DNS::SEC::Tools::Donuts();

Cargando y Accediendo a Datos de Zona

load_zone(ESPECIFICADOR, NOMBRE_ZONA)

Los datos de zona se pueden cargar en el módulo Donuts utilizando la función load_zone(). Esta función toma una ruta de archivo como argumento por defecto, o uno de los especificadores especiales enumerados a continuación.

$donuts->load_zone("/ruta/a/archivo", "example.com");
Carga un archivo de un archivo de datos de zona típico (basado en texto). Utiliza el módulo Net::DNS::Zonefile::Fast para analizar el archivo de zona en registros Net::DNS::RR.
$donuts->load_zone("axfr:example.com", "example.com");
Si el host tiene la capacidad de realizar una transferencia axfr de una zona dada, este especificador se puede utilizar para transferir dinámicamente los datos de la zona de los servidores en línea.
$donuts->load_zone("live:www,ftp:aaaa,ns", "example.com");
Cuando se utiliza el prefijo de especificador live:, el módulo Donuts intentará realizar consultas individuales de la zona para la lista especificada de prefijos de nombres de dominio para la zona. La lista por defecto (es decir, solo "live:") de registros de zona a consultar es solo "www". Los tipos de consulta se pueden especificar separando la etiqueta con un carácter ':', como en el ejemplo anterior que indica que se debe consultar un registro AAAA para el host 'ftp'.

Además de la lista especificada dentro del propio especificador, cada zona siempre se consulta para las siguientes entradas también:

- NOMBRE_ZONA:DNSKEY
- NOMBRE_ZONA:SOA
- NOMBRE_ZONA:NS

Tenga en cuenta que debido a que la zona no estará completa, es probable que se requiera una selección o exclusión cuidadosa de las reglas (ver "Ignorar y Ejecutar Solo Reglas") para filtrar resultados incorrectos durante cualquier análisis que se realice.
