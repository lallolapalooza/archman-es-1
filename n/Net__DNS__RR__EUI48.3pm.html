NOMBRE

Net::DNS::RR::EUI48 - Registro de recursos EUI48 de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre IN EUI48 direccion');
$rr = Net::DNS::RR->new(
                nombre    => 'ejemplo.com',
                tipo    => 'EUI48',
                direccion => '00-00-5e-00-53-2a'
                );

DESCRIPCIÓN

Registros de recursos DNS para Identificadores Únicos Extendidos (EUI48).

El registro de recursos EUI48 se utiliza para representar Identificadores Únicos Extendidos de IEEE utilizados en varias redes de capa 2, como ethernet.

NO se deben publicar direcciones EUI48 en el DNS público. RFC7043 describe posibles implicaciones graves para la privacidad resultantes de la publicación indiscriminada de direcciones de capa de enlace en el DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, ya que podría provocar la terminación del programa u otro comportamiento impredecible.

direccion El campo direccion es una dirección de capa-2 de 6 octetos en orden de bytes de red.

El formato de presentación es hexadecimal separado por "-".
