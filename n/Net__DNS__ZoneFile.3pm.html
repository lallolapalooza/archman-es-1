NAME

Net::DNS::ZoneFile - Archivo de zona DNS

SYNOPSIS

use Net::DNS::ZoneFile;
$zonefile = Net::DNS::ZoneFile->new( 'named.example' );
while ( $rr = $zonefile->read ) {
        $rr->print;
}
@zone = $zonefile->read;

DESCRIPCIÓN

Cada objeto Net::DNS::ZoneFile representa una zona de DNS junto con cualquier archivo hijo introducido por la directiva $INCLUDE. La sintaxis de los archivos de zona se define por RFC1035.

Un programa puede tener varios objetos de zona de DNS, cada uno manteniendo su propia información de estado del parser.

El parser soporta tanto la directiva $TTL definida por RFC2308 como la extensión de sintaxis BIND $GENERATE.

Todas las RR en un archivo de zona deben tener la misma clase, que puede especificarse para la primera RR encontrada y se propagará automáticamente a todas las siguientes.

MÉTODOS

new

$zonefile = Net::DNS::ZoneFile->new( 'filename', ['example.com'] );
$handle   = IO::File->new( 'filename', '<:encoding(ISO8859-7)' );
$zonefile = Net::DNS::ZoneFile->new( $handle, ['example.com'] );

El constructor new() devuelve un objeto Net::DNS::ZoneFile que representa el archivo de zona especificado en la lista de argumentos.

El archivo especificado o el handle es abierto para lectura y se cierra cuando se agota o cuando ya no hay referencias al objeto ZoneFile.

El argumento opcional segundo especifica $ORIGIN para el archivo de zona.

Los archivos de zona se suponen codificados en UTF-8 si eso es posible.

Pueden especificarse codificaciones alternativas indirectamente creando un handle con la capa de codificación deseada, que luego se pasa como argumento a new(). La codificación especificada se propaga a los archivos introducidos por directivas $INCLUDE.

read

$rr = $zonefile->read;
@rr = $zonefile->read;

Cuando se invoca en contexto de escalar, read() devuelve un objeto Net::DNS::RR representando la siguiente RR de zona encontrada en el archivo de zona, o undefined si se ha alcanzado el final de datos.

Cuando se invoca en contexto de lista, read() devuelve una lista de objetos Net::DNS::RR en el orden en que aparecen en el archivo de zona.

Comentarios y líneas en blanco se ignoran de forma silenciosa.

Las directivas $INCLUDE, $ORIGIN, $TTL y $GENERATE se procesan transparentemente.

name

$filename = $zonefile->name;

Devuelve el nombre del archivo de zona actual. Las directivas $INCLUDE embedidas causarán que este nombre sea diferente del argumento proporcionado cuando el objeto fue creado.

line

$line = $zonefile->line;

Devuelve el número de la línea más reciente leída del archivo de zona actual.

origin

$origin = $zonefile->origin;

Devuelve el nombre completo de la origin dentro del archivo de zona actual.

ttl

$ttl = $zonefile->ttl;

Devuelve el TTL predeterminado definido por la directiva $TTL.

COMPATIBILIDAD CON Net::DNS::ZoneFile 1.04

Los programas que dependían del antiguo distribución CPAN de Net::DNS::ZoneFile 1.04 continuarán operando con poca diferencia usando la interfaz de compatibilidad descrita a continuación. Código nuevo debe usar la interfaz orientada a objetos.

use Net::DNS::ZoneFile;
$listref = Net::DNS::ZoneFile->read( $filename );
$listref = Net::DNS::ZoneFile->read( $filename, $include_dir );
$listref = Net::DNS::ZoneFile->readfh( $filehandle );
$listref = Net::DNS::ZoneFile->readfh( $filehandle, $include_dir );
$listref = Net::DNS::ZoneFile->parse( $string );
$listref = Net::DNS::ZoneFile->parse( $string, $include_dir );
$listref = Net::DNS::ZoneFile->parse( \$string );
$listref = Net::DNS::ZoneFile->parse( \$string, $include_dir );
$_->print for @$listref;

El segundo argumento opcional especifica el directorio por defecto para los archivos. El directorio de trabajo actual se utiliza por defecto.

Aunque no está disponible en la implementación original, el listado de RR puede obtenerse directamente llamando a cualquier método en contexto de lista.

@rr = Net::DNS::ZoneFile->read( $filename, $include_dir );

Si hay un error durante el parseo, se devuelve un resultado parcial.

read

$listref = Net::DNS::ZoneFile->read( $filename );
$listref = Net::DNS::ZoneFile->read( $filename, $include_dir );

read() parsea el contenido del archivo especificado y devuelve un referencia a la lista de objetos Net::DNS::RR. El valor devuelto es undefined si hay un error durante el parseo.

readfh

$listref = Net::DNS::ZoneFile->readfh( $filehandle );
$listref = Net::DNS::ZoneFile->readfh( $filehandle, $include_dir );

readfh() parsea los datos del archivo de handle especificado y devuelve una referencia a la lista de objetos Net::DNS::RR. El valor devuelto es undefined si hay un error durante el parseo.

parse

$listref = Net::DNS::ZoneFile->parse( $string );
$listref = Net::DNS::ZoneFile->parse( $string, $include_dir );
$listref = Net::DNS::ZoneFile->parse( \$string );
$listref = Net::DNS::ZoneFile->parse( \$string, $include_dir );

parse() interpreta el texto en el argumento string y devuelve una referencia a la lista de objetos Net::DNS::RR. El valor devuelto es undefined si hay un error durante el parseo.

Net::DNS::ZoneFile(3pm) — Perl 5.42.0 man pages

NAME

Net::DNS::ZoneFile - Zone file parser and generator.

SYNOPSIS

    use Net::DNS::ZoneFile;
    my $zone = new Net::DNS::ZoneFile();
    $zone->read( "example.com.zone" );
    print $zone->write();
    
    my $rr = $zone->rr_add(
        name    => "mail.example.com.",
        type    => "A",
        ttl     => 3600,
        rdata   => "192.168.1.2",
    );

DESCRIPTION

This module provides an object-oriented interface for parsing and generating DNS zone files. Zone files are the standard format for describing DNS resource records.

It parses zone files into a structure that can be manipulated by the Net::DNS module, and can also write this structure back to a zone file format.

METHODS

read( [ $filename | $filehandle | \$string ] )
Reads a zone file from the specified source. If no argument is given, it reads from STDIN. The source can be a filename, a filehandle, or a scalar reference to a string containing zone file data.
write( [ $filehandle | \$string ] )
Writes the current zone file data to the specified destination. If no argument is given, it returns a string containing the zone file data. If a filehandle is provided, it writes to that filehandle. If a scalar reference is provided, it writes the data into that string.
rr_add( \%attributes )
Adds a new resource record to the zone. The \%attributes hash should contain keys such as name, type, ttl, and rdata.
rr_del( \%attributes )
Deletes resource records matching the specified attributes.
soa( )
Returns the SOA (Start of Authority) record for the zone.
ns( )
Returns a list of NS (Name Server) records for the zone.
mx( )
Returns a list of MX (Mail Exchanger) records for the zone.
a( )
Returns a list of A (Address) records for the zone.
aaaa( )
Returns a list of AAAA (IPv6 Address) records for the zone.
cname( )
Returns a list of CNAME (Canonical Name) records for the zone.
ptr( )
Returns a list of PTR (Pointer) records for the zone.
txt( )
Returns a list of TXT (Text) records for the zone.
other( $type )
Returns a list of resource records of the specified type.

COMPATIBILITY WITH Net::DNS::ZoneFile 1.04

This version aims for compatibility with Net::DNS::ZoneFile 1.04, but some minor differences may exist.
