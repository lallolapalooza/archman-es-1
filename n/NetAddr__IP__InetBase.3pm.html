DESCRIPCIÓN

NetAddr::IP::InetBase proporciona un conjunto de funciones de red para conversiones escritas en Perl puro para convertir direcciones IPv4 e IPv6 a y desde formato de dirección de red y formato de texto.

Las funciones IPv6 soportan todos los formatos rfc1884.

es decir,  x:x:x:x:x:x:x:x:x
      x:x:x:x:x:x:x:d.d.d.d
      ::x:x:x
      ::x:d.d.d.d
y así sucesivamente...
  • $dotquad = inet_ntoa($netaddr);

    Convierte una dirección de red IPv4 empaquetada a una dirección IP punto-cuádruple.

    entrada:        dirección de red empaquetada
retorna:      dirección IP, es decir, 10.4.12.123
  • $netaddr = inet_aton($dotquad);

    Convierte una dirección IP punto-cuádruple a una dirección de red IPv4 empaquetada.

    entrada:        dirección IP, es decir, 192.5.16.32
retorna:      dirección de red empaquetada
  • $ipv6addr = ipv6_aton($ipv6_text);

    Toma una dirección IPv6 del formato descrito en rfc1884 y retorna una cadena binaria RDATA de 128 bits.

    entrada:        texto IPv6
retorna:      cadena RDATA de 128 bits
  • $ipv6text = ipv6_ntoa($ipv6naddr);

    Convierte una dirección binaria IPv6 de 128 bits a la representación de texto comprimida rfc 1884.

    entrada:        cadena RDATA de 128 bits
retorna:      texto IPv6
  • $hex_text = ipv6_n2x($ipv6addr);

    Toma una cadena RDATA IPv6 y retorna una dirección hexadecimal IPv6 de 8 segmentos

    entrada:        cadena RDATA de 128 bits
retorna:      x:x:x:x:x:x:x:x
Nota: esta función NO comprime cadenas adyacentes
de 0:0:0:0 en el formato ::
  • $dec_text = ipv6_n2d($ipv6addr);

    Toma una cadena RDATA IPv6 y retorna una dirección IPv6 mixta hexadecimal - decimal con los 6 trozos superiores en hexadecimal y los 32 bits inferiores en representación punto-cuádruple.

    entrada:        cadena RDATA de 128 bits
retorna:      x:x:x:x:x:x:d.d.d.d
Nota: esta función NO comprime cadenas adyacentes
de 0:0:0:0 en el formato ::
  • $ipv6naddr = inet_any2n($dotquad o $ipv6_text);

    Esta función convierte una dirección IPv4 o IPv6 de texto en formato de texto, en cualquier notación estándar, a una cadena de dirección IPv6 de 128 bits. Antepone '::' a cualquier dirección punto-cuádruple (si se encuentra) y la pasa a ipv6_aton.

    entrada:        dirección punto-cuádruple o rfc1844
retorna:      cadena IPv6 de 128 bits
  • $dotquad o $hex_text = inet_n2dx($ipv6naddr);

    Esta función hace lo correcto y retorna el texto para una dirección IPv4 punto-cuádruple o una dirección IPv6 en notación hexadecimal.

    entrada:        cadena IPv6 de 128 bits
retorna:      ddd.ddd.ddd.ddd
          o  x:x:x:x:x:x:x:x
Nota: esta función NO comprime cadenas adyacentes
de 0:0:0:0 en el formato ::
  • $dotquad o $dec_text = inet_n2ad($ipv6naddr);

    Esta función hace lo correcto y retorna el texto para una dirección IPv4 punto-cuádruple o una dirección IPv6 en notación hexadecimal::decimal.

    entrada:        cadena IPv6 de 128 bits
retorna:      ddd.ddd.ddd.ddd
          o  x:x:x:x:x:x:ddd.ddd.ddd.dd
Nota: esta función NO comprime cadenas adyacentes
de 0:0:0:0 en el formato ::
  • $netaddr = inet_pton($AF_family,$text_addr);

    Esta función toma una dirección IP en formato de texto IPv4 o IPv6 y la convierte a formato binario. El tipo de conversión de la dirección IP se controla mediante el argumento FAMILY.

    NOTA: inet_pton, inet_ntop y AF_INET6 provienen de la biblioteca Socket6 si está presente en este host.

  • $text_addr = inet_ntop($AF_family,$netaddr);

    Esta función toma una dirección IP en formato binario y la convierte a formato de texto. El tipo de conversión de la dirección IP se controla mediante el argumento FAMILY.

    NOTA: inet_ntop SIEMPRE retorna caracteres en minúsculas.

    NOTA: inet_ntop, inet_pton y AF_INET6 provienen de la biblioteca Socket6 si está presente en este host.

  • $hex_text = packzeros($hex_text);

    Esta función optimiza una dirección hexadecimal IPv6 rfc 1884 para reducir el número de cadenas largas de bits cero según lo especificado en rfc 1884, 2.2 (2) sustituyendo :: por la primera ocurrencia de la cadena más larga de ceros en la dirección.

  • $ipv6naddr = ipv4to6($netaddr);

    Convierte una dirección de red ipv4 en una dirección de red ipv6.

    entrada:        dirección de red de 32 bits
retorna:      dirección de red de 128 bits
  • $rv = isIPv4($bits128);

    Esta función retorna verdadero si no hay bits activos presentes en la porción IPv6 de la cadena de 128 bits y falso en caso contrario.

    es decir, la dirección debe tener el formato - ::d.d.d.d

    Nota: esta es una dirección IPv6 antigua y obsoleta compatible con IPv4

  • $rv = isNewIPv4($bits128);

    Esta función retorna verdadero si la cadena IPv6 de 128 bits tiene el formato

    ::ffff:d.d.d.d
  • $rv = isAnyIPv4($bits128);

    Esta función retorna verdadero si la cadena de bits IPv6 tiene el formato

    ::d.d.d.d       o      ::ffff:d.d.d.d
  • NetAddr::IP::InetBase::lower();

    Retorna cadenas IPv6 en minúsculas. Este es el valor predeterminado.

  • NetAddr::IP::InetBase::upper();

    Retorna cadenas IPv6 en mayúsculas.

    El valor predeterminado se puede establecer en mayúsculas cuando se carga el módulo invocando la ETIQUETA :upper. es decir,

    use NetAddr::IP::InetBase qw( :upper );
  • $constant = AF_INET;

    Esta función retorna el valor del sistema para AF_INET.

  • $constant = AF_INET6;

    AF_INET6 a veces está presente en la biblioteca Socket y siempre está presente en la biblioteca Socket6. Cuando la biblioteca Socket no contiene AF_INET6 y cuando Socket6 no está presente, se "adivina" un valor marcador basado en el sistema operativo anfitrión subyacente. Ver fake_AF_INET6 a continuación.

    NOTA: inet_pton, inet_ntop y AF_INET6 provienen de la biblioteca Socket6 si está presente en este host.

  • $trueif = fake_AF_INET6;

    Esta función retorna FALSO si AF_INET6 es proporcionado por Socket o Socket6. De lo contrario, retorna el mejor valor estimado basado en el nombre del sistema operativo anfitrión.

  • $ip_filled = fillIPv4($shortIP);

    Esta función convierte direcciones IPv4 del formato 127.1 al formato largo 127.0.0.1

    Si la función recibe un argumento que no coincide con el formato de una dirección IP, se retorna el argumento original. es decir, pásale un nombre de host o una IP corta y se

NAME

NetAddr::IP::InetBase - Base class for IP address objects

SYNOPSIS

 use NetAddr::IP::InetBase;

INSTALLATION

Standard module installation applies.

DESCRIPTION

This module provides the base functionality for handling IP addresses. It is intended to be inherited by other modules such as NetAddr::IP(3), NetAddr::IP::Lite(3) and NetAddr::IP::Util(3).

It is not intended for direct use.

The methods provided by this base class are:

  • inet_aton() - Convert an IP address string to a 32-bit unsigned integer.

  • inet_ntoa() - Convert a 32-bit unsigned integer to an IPv4 address string.

  • ipv6_aton() - Convert an IPv6 address string to a 128-bit unsigned integer (represented as two 64-bit integers).

  • ipv6_ntoa() - Convert a 128-bit unsigned integer to an IPv6 address string.

  • ipv6_n2x() - Convert a 128-bit unsigned integer to its canonical text form, shortest representation.

  • ipv6_n2d() - Convert a 128-bit unsigned integer to its text form, with embedded IPv4 address if applicable.

  • inet_any2n() - Convert an IP address string (either IPv4 or IPv6) to its network number representation.

  • inet_n2dx() - Convert a network number to its text representation (shortest form).

  • inet_n2ad() - Convert a network number to its text representation (with embedded IPv4 if applicable).

  • inet_pton() - Convert an IP address string to its binary representation.

  • inet_ntop() - Convert an IP address string from its binary representation.

  • packzeros() - Pad the packed binary representation of an IPv6 address with zeros.

  • isIPv4() - Returns true if the argument is an IPv4 address.

  • isNewIPv4() - Returns true if the argument is a valid IPv4 address.

  • isAnyIPv4() - Returns true if the argument is an IPv4 address, an IPv4-mapped IPv6 address, or an IPv4-compatible IPv6 address.

  • AF_INET() - Returns the address family constant for IPv4.

  • AF_INET6() - Returns the address family constant for IPv6.

  • fake_AF_INET6() - Returns a fake address family constant that can be used to represent an IPv4 address in a context expecting an IPv6 address.

  • fillIPv4() - Given an IPv6 address object, return an IPv4 address object if the original address was an IPv4-mapped or IPv4-compatible IPv6 address, otherwise return undef. Will return a hostname or a filled IP.
