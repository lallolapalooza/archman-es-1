NOMBRE

Net::DNS::SEC::Tools::dnssectools - Rutinas generales para el paquete DNSSEC-Tools.

SINOPSIS

use Net::DNS::SEC::Tools::dnssectools;
dt_adminmail($asunto,$cuerpomsg,$destinatario);
$rutazs = dt_cmdpath('zonesigner');
$tipof = dt_findtype($ruta);
$segundos = dt_parse_duration("0s3d1h10m20s")
$conjres = dt_parse_zonefile(file => 'example.com');

DESCRIPCIÓN

El módulo dnssectools proporciona un conjunto general de métodos para usar con las utilidades de DNSSEC-Tools.

INTERFACES

Las interfaces al módulo dnssectools se presentan a continuación.

dt_adminmail(asunto,cuerpomsg,destinatario)
Esta rutina envía por correo electrónico un mensaje al usuario administrativo listado en el archivo de configuración de DNSSEC-Tools.

dt_adminmail() requiere dos parámetros, ambos escalares. El parámetro asunto es el asunto del mensaje de correo electrónico. El parámetro cuerpomsg es el cuerpo del mensaje de correo electrónico.

Se puede proporcionar un tercer parámetro, destinatario, para especificar el destinatario del mensaje. Si no se proporciona, el destinatario se tomará del registro admin-email del archivo de configuración de DNSSEC-Tools. Si destinatario es "nomail", no se enviará ningún mensaje y se devolverá éxito.

Valores de retorno:

1 - el mensaje fue creado y enviado.
0 - se especificó un destinatario inválido.

Se basa en los siguientes parámetros de configuración de dnssec-tools.conf:

admin-email
La dirección de correo electrónico de la que debe provenir el correo.
mailer-type
Debe ser uno de: sendmail, smtp, qmail. Esta opción no es obligatoria y, por defecto, intentará enviar el correo usando sendmail y qmail. Si mailer-server se establece en un valor definido pero mailer-type no, entonces mailer-type se establecerá por defecto a
mailer-server
El servidor, si admin-mail está configurado como smtp, al que debe entregarse el correo.
dt_cmdpath(comando)
Esta rutina devuelve la ruta a un comando especificado de DNSSEC-Tools. comando debe ser solo el nombre, sin directorios iniciales. Se verifica el nombre del comando para asegurar que es un comando válido de DNSSEC-Tools.

Valores de retorno:

Se devuelve la ruta absoluta al comando si el comando
es válido.
Se devuelve nulo si el comando no es válido.
dt_filetype(ruta)
Esta rutina devuelve el tipo del archivo nombrado en ruta. Se cuentan los registros rollrec y keyrec contenidos en él y se determina un tipo.

Valores de retorno:

"keyrec" - Se encontró al menos un registro keyrec y no
            se encontraron registros rollrec.
"rollrec" - Se encontró al menos un registro rollrec y
            no se encontraron registros keyrec.
"mixed" -   Se encontró al menos un registro rollrec y al menos un
            registro keyrec.
            Lo más probable es que sea un archivo erróneo.
"unknown" - No se encontraron registros rollrec ni keyrec.
"nofile"  - El archivo especificado no existe.
dt_parse_duration(cadena)
Esta rutina traduce una duración dada en formato "1s2d3h4m5s" y devuelve el número equivalente de segundos, o undef si la duración tiene un formato inválido.
dt_parse_zonefile(opciones)
Esta rutina analiza un archivo de zona dado utilizando el analizador de archivos de zona configurado y devuelve una referencia de matriz que contiene los RR.

El analizador de zonas a utilizar depende de la configuración del valor zonefile-parser. Si este no está establecido, se utilizará el analizador de zonas de Net::DNS::ZoneFile (opción obsoleta: este es el único analizador compatible actualmente).
