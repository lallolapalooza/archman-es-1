Net::SSLeay::Handle(3) Documentación de usuario para Perl Net::SSLeay::Handle(3)

NOMBRE

Net::SSLeay::Handle - Módulo Perl que permite manejar sockets SSL (HTTPS) como handles estándar.

SINTAXIS

use Net::SSLeay::Handle qw/shutdown/;
my ($host, $port) = ("localhost", 443);
tie(*SSL, "Net::SSLeay::Handle", $host, $port);
print SSL "GET / HTTP/1.0\r\n";
shutdown(\*SSL, 1);
print while ();
close SSL;

DESCRIPCIÓN

Net::SSLeay::Handle te permite solicitar y recibir páginas web HTTPS utilizando handles "old school" como en:

print SSL "GET / HTTP/1.0\r\n";

y

print while ();

Si exporta la función shutdown, entonces el único código adicional que necesita agregar a su programa es la función tie, como en:

my $socket;
if ($scheme eq "https") {
    tie(*S2, "Net::SSLeay::Handle", $host, $port);
    $socket = \*S2;
else {
    $socket = Net::SSLeay::Handle->make_socket($host, $port);
}
print $socket $request_headers;
...

FUNCIONES

shutdown
shutdown(\*SOCKET, $mode)

Las llamadas a la función principal shutdown() no funcionan con sockets creados con este módulo. Esta función de shutdown debería ser capaz de distinguir entre sockets ligados y no ligados y hacer lo correcto.

debug
my $debug = Net::SSLeay::Handle->debug()
Net::SSLeay::Handle->debug(1)

Obtiene/establece el modo de depuración. Si se le pasa un argumento adicional, la opción de depuración se establecerá en ese valor.

make_socket
my $sock = Net::SSLeay::Handle->make_socket($host, $port);

Crea un socket conectado a $host usando $port. Usa $Net::SSLeay::proxyhost y $proxyport si están definidos y autentifica contra este proxy según $Net::SSLeay::proxyauth. También activa el autodesbordamiento en el socket creado.

USANDO SOCKETS EXISTENTES

Una de las motivaciones para escribir este módulo fue evitar duplicar el código de creación de sockets (que es principalmente control de errores). Las llamadas a tie() anteriores se pasan un $host y $port para conveniencia en pruebas. Si ya tiene un socket conectado a la dirección y puerto correctos, S1, entonces puede hacer algo como:

my $socket \*S1;
if ($scheme eq "https") {
    tie(*S2, "Net::SSLeay::Handle", $socket);
    $socket = \*S2;
}
my $last_sel = select($socket); $| = 1; select($last_sel);
print $socket $request_headers;
...

Nota: Por lo que sé, debes tener cuidado con las variables globales en la función tie(). El primer parámetro debe ser un glob (*SOMETHING) y el último parámetro debe ser una referencia a un glob (\*SOMETHING_ELSE) o un escalar que se haya asignado a una referencia a un glob (como en el ejemplo anterior).

Los dos globs también deben ser diferentes. Cuando intenté usar el mismo glob, obtuve un volcado de memoria.

EXPORTAR

Sin embargo, no se exporta por defecto.

Puedes exportar la función shutdown().

Se sugiere que exportes shutdown() o uses la función completamente calificada Net::SSLeay::Handle::shutdown() para finalizar sockets SSL. Debe ser lo suficientemente inteligente como para distinguir entre sockets SSL y no SSL y hacer lo correcto.

EJEMPLOS

use Net::SSLeay::Handle qw/shutdown/;
my ($host, $port) = ("localhost", 443);
tie(*SSL, "Net::SSLeay::Handle", $host, $port);
print SSL "GET / HTTP/1.0\r\n";
shutdown(\*SSL, 1);
print while ();
close SSL;

ADVERTENCIAS

Ligar un handle es un poco complicado (al menos para mí).

El primer parámetro de tie() debe ser un glob (*SOMETHING) y el último parámetro debe ser una referencia a un glob (\*SOMETHING_ELSE) o un escalar que se haya asignado a una referencia a un glob (como en el ejemplo anterior).

Los dos globs también deben ser diferentes. Cuando intenté usar el mismo glob, obtuve un volcado de memoria.

Pude asociar atributos a los globs creados por este módulo (como *SSL arriba) usando una tabla hash de hashes, con clave por el encabezado del archivo.
