NOMBRE

Net::DNS::RR::TSIG - registro de recursos TSIG de DNS

SINOPSIS

use Net::DNS;
$tsig = Net::DNS::RR::TSIG->create( $archivo_clave );
$tsig = Net::DNS::RR::TSIG->create(
                        $archivo_clave,
                        fudge => 300
                        );

DESCRIPCIÓN

Clase para registros de recursos de Firma de Transacción (TSIG) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, ya que podría provocar la terminación del programa u otros comportamientos impredecibles.

algoritmo

$algoritmo = $rr->algoritmo;
$rr->algoritmo( $algoritmo );

Un nombre de dominio que especifica el nombre del algoritmo.

clave

$rr->clave( $clave );

Representación Base64 del material de la clave.

clavebin

$rr->clavebin( $clavebin );

Representación binaria del material de la clave.

tiempo_firmado

$tiempo_firmado = $rr->tiempo_firmado;
$rr->tiempo_firmado( $tiempo_firmado );

Tiempo de firma como el número de segundos desde el 1 de enero de 1970 00:00:00 UTC. El tiempo de firma predeterminado es el tiempo actual.

fudge

$fudge = $rr->fudge;
$rr->fudge( $fudge );

"Fudge" representa el error permitido en el tiempo de firma. El fudge predeterminado es de 300 segundos.

mac

$rr->mac( $mac );

Código de autenticación de mensaje (MAC). El programador debe llamar al método del objeto Net::DNS::Packet data() antes de que esto devuelva algo significativo.

macbin

$macbin = $rr->macbin;
$rr->macbin( $macbin );

Código de autenticación de mensaje binario (MAC).

mac_previo

$mac_previo = $rr->mac_previo;
$rr->mac_previo( $mac_previo );

Código de autenticación de mensaje previo (MAC).

macbin_previo

$macbin_previo = $rr->macbin_previo;
$rr->macbin_previo( $macbin_previo );

Código de autenticación de mensaje binario previo.

mac_solicitud

$mac_solicitud = $rr->mac_solicitud;
$rr->mac_solicitud( $mac_solicitud );

Código de autenticación de mensaje de solicitud (MAC).

macbin_solicitud

$macbin_solicitud = $rr->macbin_solicitud;
$rr->macbin_solicitud( $macbin_solicitud );

Código de autenticación de mensaje binario de solicitud.

id_original

$id_original = $rr->id_original;
$rr->id_original( $id_original );

El ID del mensaje de la cabecera del paquete original.

error

cadena_error_verificacion

$rcode = $tsig->error;

Devuelve el RCODE que cubre el procesamiento TSIG. Los valores comunes son NOERROR, BADSIG, BADKEY y BADTIME. Consulte RFC8945 para obtener más detalles.

otro

$otro = $tsig->otro;

Este campo debe estar vacío a menos que el error sea BADTIME, en cuyo caso contendrá el tiempo del servidor como el número de segundos desde el 1 de enero de 1970 00:00:00 UTC.

funcion_firma

sub funcion_firma {
        my ( $clavebin, $datos ) = @_;
        my $hmac = Digest::HMAC->new( $clavebin, 'Digest::MD5' );
        hmac->add( $datos );
        return $hmac->digest;
}
$tsig->funcion_firma( \&funcion_firma );

Esto establece la función de firma que se utilizará para este registro TSIG. La función de firma predeterminada es HMAC-MD5.

datos_firma

$datos_firma = $tsig->datos_firma($paquete);

Devuelve el paquete empaquetado de acuerdo con RFC8945 en un formato para firmar. Esto solo es necesario si desea proporcionar una función de firma externa, como la necesaria para TSIG-GSS.

crear

$tsig = Net::DNS::RR::TSIG->create( $archivo_clave );
$tsig = Net::DNS::RR::TSIG->create(
                        $archivo_clave,
                        fudge => 300
                        );

Devuelve un RR TSIG construido utilizando los parámetros del archivo de clave especificado, que se asume que ha sido generado por tsig-keygen.

verificar

$verificar = $tsig->verificar( $datos );
$verificar = $tsig->verificar( $paquete );
$verificar = $tsig->verificar( $respuesta,  $consulta );
$verificar = $tsig->verificar( $paquete, $previo );

El método booleano verificar devolverá verdadero si el hash sobre los datos del paquete se ajusta a los datos del propio TSIG.

Claves TSIG

El mecanismo de autenticación TSIG emplea una clave secreta compartida para establecer una relación de confianza entre dos entidades.

Cabe señalar que es posible que más de una clave se utilice simultáneamente entre dicho par de entidades.

Las claves TSIG se generan utilizando la utilidad tsig-keygen distribuida con ISC BIND:

tsig-keygen -a HMAC-SHA256 host1-host2.example.

Se pueden sustituir otros algoritmos por HMAC-SHA256 en el ejemplo anterior.

Estas claves deben protegerse de manera similar a las claves privadas, para evitar que un tercero se haga pasar por una de las partes previstas falsificando el código de autenticación de mensajes (MAC).

Configuración del Servidor de Nombres BIND

La clave generada debe añadirse a la configuración /etc/named.conf o a un archivo separado introducido por la directiva $INCLUDE:

key "host1-host2.example. {
        algorithm hmac-sha256;
        secret "Secret+known+only+by+participating+entities=";
};

ERRORES

Se utiliza una representación de tiempo de 32 bits, contrariamente a RFC8945, que exige 48 bits. Esta decisión de diseño deberá ser revisada antes de que el código deje de funcionar el 7 de febrero de 2106.
