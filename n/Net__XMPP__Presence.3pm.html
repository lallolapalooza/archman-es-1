NOMBRE

Net::XMPP::Presence - Módulo de presencia XMPP

SINOPSIS

Net::XMPP::Presence es un complemento al módulo Net::XMPP. Permite a los usuarios una interfaz simple para establecer y recuperar todas las partes de una presencia XMPP.

DESCRIPCIÓN

Un objeto Net::XMPP::Presence se pasa a la función de callback para el mensaje. También, el primer argumento a las funciones de callback es el ID de sesión de XML::Streams. Algunos casos donde podrías querer esta información, como si creaste un Cliente que conecta a dos servidores al mismo tiempo, o para escribir un mini servidor.

use Net::XMPP;
sub presence {
  my ($sid,$Pres) = @_;
  .
  .
  .
}

Ahora tienes acceso a todas las funciones de recuperación disponibles.

Para crear una nueva presencia para enviar al servidor:

use Net::XMPP;
$Pres = Net::XMPP::Presence->new();

Ahora puedes llamar a las funciones de creación debajo para llenar el tag antes de enviarlo.

MÉTODOS

Funciones de recuperación

GetTo
GetTo()

devuelve el valor en el atributo "to" de <presence/>.

GetTo("jid")

Si especificas "jid" como un argumento, se devuelve un objeto Net::XMPP::JID y puedes fácilmente parsear los componentes de la JID.

$to    = $Pres->GetTo();
$toJID = $Pres->GetTo("jid");
GetFrom
GetFrom()

devuelve el valor en el atributo "from" de <presence/>.

GetFrom("jid")

Si especificas "jid" como un argumento, se devuelve un objeto Net::XMPP::JID y puedes fácilmente parsear los componentes de la JID.

$from    = $Pres->GetFrom();
$fromJID = $Pres->GetFrom("jid");
GetType
GetType()

devuelve el atributo tipo de <presence/>. Cada presencia es uno de siete tipos:

available       disponible para recibir mensajes; valor por defecto: unavailable
unavailable    no disponible para recibir nada
subscribe       pide al destinatario que te suscriba
subscribed      dice al emisor que estás suscrito
unsubscribe    pide al destinatario que te desuscriba
unsubscribed   dice al emisor que no estás suscrito
probe           prueba
$type = $Pres->GetType();
GetStatus
GetStatus()

devuelve una cadena con el estado actual del recurso.

$status = $Pres->GetStatus();
GetPriority
GetPriority()

devuelve un entero con la prioridad del recurso. El valor por defecto es 0 si no hay prioridad en esta presencia.

$priority = $Pres->GetPriority();
GetShow
GetShow()

devuelve una cadena con el estado que debe mostrar el cliente.

$show = $Pres->GetShow();

Funciones de creación

SetPresence
SetPresence(to=>string|JID    
            from=>string|JID, 
            type=>string,     
            status=>string,   
            priority=>integer,
            meta=>string,     
            icon=>string,     
            show=>string,     
            loc=>string)

establece múltiples campos en <presence/> al mismo tiempo. Esta es una acción de escritura acumulativa y sobreescribe. Si especificas el atributo "to" dos veces, el segundo establecimiento se utiliza. Si estableces el estado y luego la prioridad, ambos estarán en <presence/>. Para establecer los valores válidos, consulta las funciones específicas de establecimiento.

$Pres->SetPresence(TYPE="away", StatuS="Out for lunch");
SetTo
SetTo(string)
SetTo(JID)

establece el atributo "to". Puedes pasar una cadena o un objeto JID. Ambos deben ser JIDs válidos o el servidor devolverá un mensaje de error. (ej. bob@jabber.org/Silent Bob, etc...)

$Pres->SetTo("bob\@jabber.org");
SetFrom
SetFrom(string)

establece el atributo "from". Puedes pasar una cadena o un objeto JID. Ambos deben ser JIDs válidos o el servidor devolverá un mensaje de error. (ej. jabber:bob@jabber.org/Work) Este campo no es obligatorio si estás escribiendo un Cliente, ya que el servidor colocará el JID de tu conexión allí para prevenir spam.

$Pres->SetFrom("jojo\@jabber.org");
SetType
SetType(string)

establece el atributo tipo. Los valores válidos son:

available      disponible para recibir mensajes; valor por defecto
unavailable    no disponible para recibir nada
subscribe      pide al destinatario que te suscriba
subscribed     dice al emisor que estás suscrito
unsubscribe    pide al destinatario que te desuscriba
unsubscribed   dice al emisor que no estás suscrito
probe          prueba
$Pres->SetType("unavailable");
SetStatus
SetStatus(string)

establece el elemento status asociado al recurso con cualquier cadena que el usuario quiera.

$Pres->SetStatus("Taking a nap");
SetPriority
SetPriority(integer)

establece la prioridad de este recurso. El recurso con la prioridad más alta en la cuenta XMPP recibirá los mensajes.

$Pres->SetPriority(10);
SetShow
SetShow(string)

establece el nombre del icono o la cadena a mostrar para este recurso.

$Pres->SetShow("away");
Reply
Reply(hash)

crea un nuevo objeto Presence y rellena los campos to/from. Si especificas un hash, los valores serán los que se especifican en Reply. Ejemplo: $Reply = $Pres->Reply(); $Reply = $Pres->Reply(type="subscribed");

$Reply = $Pres->Reply();
$Reply = $Pres->Reply(type="subscribed");
