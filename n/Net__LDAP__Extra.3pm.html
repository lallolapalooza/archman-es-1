NOMBRE

Net::LDAP::Extra -- Carga métodos adicionales de Net::LDAP

SINOPSIS

use Net::LDAP::Extra qw(mi_extn);
$ldap = Net::LDAP->new( ... );
$ldap->mi_extn( ... );

DESCRIPCIÓN

"Net::LDAP::Extra" permite añadir métodos adicionales a Net::LDAP. Normalmente, dichos métodos se añadirían creando una subclase de Net::LDAP, pero esto resulta complicado ya que diferentes personas escriben diferentes adiciones y otras quieren usar múltiples de estas subclases. Los usuarios terminan teniendo que crear sus propias subclases que heredan de todas las subclases de extensión solo para poder obtener todas las características.

"Net::LDAP::Extra" permite añadir métodos directamente a todos los objetos Net::LDAP. Esto se puede hacer creando una clase "Net::LDAP::Extra::nombre" que exporta funciones. Una "use Net::LDAP::Extra qw(nombre)" hará que estas funciones estén disponibles como métodos en todos los objetos "Net::LDAP".

Se debe tener cuidado al elegir los nombres para las funciones a exportar para asegurarse de que no entren en conflicto con otros.
