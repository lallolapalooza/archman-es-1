NOMBRE

Net::DBus::Binding::Message::MethodCall - un mensaje que codifica una llamada a método

DESCRIPCIÓN

Este módulo forma parte de las API de bajo nivel de enlace de DBus, y no debe ser utilizado por código de aplicación. No se ofrecen garantías sobre las API bajo el espacio de nombres "Net::DBus::Binding::" que sean estables entre versiones.

Este módulo proporciona un constructor de conveniencia para crear un mensaje que representa una llamada a un método.

MÉTODOS

mi $llamada = Net::DBus::Binding::Message::MethodCall->new( service_name => $servicio, object_path => $objeto, interface => $interfaz, method_name => $nombre);
Crea un mensaje que representa una llamada al objeto ubicado en la ruta "object_path" dentro del cliente que posee el nombre conocido proporcionado por "service_name". El método a invocar tiene el nombre "method_name" dentro de la interfaz especificada por el parámetro "interface".
