NOMBRE

Net::DBus::Test::MockIterator - Iterador sobre un mensaje simulado

SINOPSIS

Creando un nuevo mensaje

my $msg = new Net::DBus::Test::MockMessage
my $iterator = $msg->iterator;
$iterator->append_boolean(1);
$iterator->append_byte(123);

Leyendo desde un mensaje

my $msg = ...obtenerlo de alguna parte...
my $iter = $msg->iterator();
my $i = 0;
while ($iter->has_next()) {
  $iter->next();
  $i++;
  if ($i == 1) {
     my $val = $iter->get_boolean();
  } elsif ($i == 2) {
     my $val = $iter->get_byte();
  }
}

DESCRIPCIÓN

Este módulo proporciona una contraparte "simulada" del objeto Net::DBus::Binding::Iterator, capaz de iterar sobre objetos de mensaje simulados. Las instancias de este módulo no se crean directamente, sino que se obtienen a través del método "iterator" del módulo Net::DBus::Test::MockMessage.

MÉTODOS

$success = $iter->next()

my $value = $iter->get()
my $value = $iter->get($type);
Obtiene el valor actual apuntado por este iterador. Si se proporciona el parámetro opcional $type, se comparará el tipo de transmisión con el tipo deseado y se mostrará una advertencia si difieren. El valor de $type debe ser una de las constantes "Net::DBus::Binding::Message::TYPE*".
my $hashref = $iter->get_dict()
Si el iterador apunta actualmente a un valor de diccionario, desempaqueta y devuelve el valor como una referencia a hash.
my $hashref = $iter->get_array()

my $hashref = $iter->get_struct()
Si el iterador apunta actualmente a un valor de estructura, desempaqueta y devuelve el valor como una referencia a matriz. Los valores en la matriz corresponden a los miembros de la estructura.
$iter->append($value)
$iter->append($value, $type)
Agrega un valor al mensaje asociado con este iterador. El valor se empaqueta en formato de transmisión, de acuerdo con las siguientes reglas.

Si $value es una instancia de Net::DBus::Binding::Value, se utiliza el tipo de datos incrustado.

Si se proporciona el parámetro $type, este representa el tipo de datos. El tipo debe ser una de las constantes "Net::DBus::Binding::Message::TYPE_*".

De lo contrario, el tipo de datos se elige como cadena, diccionario o matriz de acuerdo con los tipos de datos de Perl SCALAR, HASH o ARRAY.

my $type = $iter->guess_type($value)
Intenta adivinar el tipo de datos en transmisión a utilizar para empaquetar $value. Si el valor es una referencia a hash, se devuelve el tipo de diccionario; si el valor es una referencia a matriz, se devuelve el tipo de matriz; de lo contrario, se devuelve el tipo de cadena.
my $sig = $iter->format_signature($type)
Dado una representación de tipo de datos, construye una cadena de firma correspondiente.
$iter->append_array($value, $type)
Agrega una matriz de valores al mensaje. El parámetro $value debe ser una referencia a matriz, cuyos elementos tengan todos el mismo tipo de datos especificado por el parámetro $type.
$iter->append_struct($value, $type)
Agrega una estructura al mensaje. El parámetro $value debe ser una referencia a matriz, cuyos elementos correspondan a los miembros de la estructura. El parámetro $type codifica el tipo de cada miembro de la estructura.
$iter->append_dict($value, $type)
Agrega un diccionario al mensaje. El parámetro $value debe ser una referencia a hash. El parámetro $type codifica el tipo de la clave y el valor del hash.
$iter->append_variant($value)
Agrega un valor al mensaje, codificado como un tipo variante. El $value puede ser de cualquier tipo, sin embargo, la variante se codificará como una cadena, diccionario o matriz de acuerdo con las reglas del método "guess_type".
my $type = $iter->get_arg_type
Recupera el código de tipo del valor que apunta este iterador. El código devuelto corresponderá a una de las constantes "Net::DBus::Binding::Message::TYPE_*".

NAME

Net::DBus::Test::MockIterator – Mock iterator for testing.

SYNOPSIS

 use Net::DBus::Test::MockIterator;

 my $iter = Net::DBus::Test::MockIterator->new(
     [ "string1", 123, "string2", ]
 );
 my $type = $iter->get_element_type;
 my $val  = $iter->get_basic;
 my $str  = $iter->get_string;

DESCRIPTION

This class provides a mock implementation of Net::DBus::Binding::Iterator, suitable for testing code that consumes D-Bus messages without needing a real connection.

METHODS

my $type = $iter->get_element_type
If the iterator points to an array, retrieves the type code of array elements. The returned code will correspond to one of the constants "Net::DBus::Binding::Message::TYPE_*"

BUGS

It doesn't completely replicate the API of Net::DBus::Binding::Iterator, merely enough to make the high level bindings work in a test scenario.
