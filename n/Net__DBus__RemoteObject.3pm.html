NOMBRE

Net::DBus::RemoteObject - Acceder a objetos proporcionados en el bus

SINOPSIS

my $service = $bus->get_service("org.freedesktop.DBus");
my $object = $service->get_object("/org/freedesktop/DBus");
print "Nombres en el bus {\n";
foreach my $name (sort @{$object->ListNames}) {
    print "  ", $name, "\n";
}
print "}\n";

DESCRIPCIÓN

Este módulo proporciona la API para acceder a objetos remotos disponibles en el bus. Utiliza el cargador automático (autoloader) para simular la presencia de métodos basada en la API del objeto remoto. También hay soporte para establecer callbacks para señales y acceder a las propiedades del objeto.

MÉTODOS

my $object = Net::DBus::RemoteObject->new($service, $object_path[, $interface], \%params);
Crea un nuevo manejador para un objeto remoto. El parámetro $service es una instancia del método Net::DBus::RemoteService, y $object_path es el identificador de un objeto exportado por este servicio, por ejemplo "/org/freedesktop/DBus". Para objetos remotos que implementan más de una interfaz, es posible especificar un nombre opcional de una interfaz como tercer parámetro. Sin embargo, esto sólo es realmente necesario si dos interfaces en el objeto proporcionan métodos con el mismo nombre, ya que los datos de introspección se pueden utilizar para resolver automáticamente la interfaz correcta a la que llamar en casos donde los nombres de los métodos son únicos. En lugar de usar este constructor directamente, es preferible usar el método "get_object" de Net::DBus::RemoteService, ya que este cachea los manejadores de objetos remotos, eliminando búsquedas innecesarias de datos de introspección.

El parámetro %params contiene parámetros de configuración adicionales para el objeto. Actualmente se soporta un solo parámetro, "timeout", que toma un valor en milisegundos a utilizar como tiempo de espera para las llamadas a métodos del objeto.

my $object = $object->as_interface($interface);
Convierte el objeto a una interfaz específica, devolviendo una nueva instancia de Net::DBus::RemoteObject especializada a la interfaz deseada. Solo es necesario convertir objetos a una interfaz específica si dos interfaces exportan métodos o señales con el mismo nombre, o si el objeto remoto no soporta introspección.
my $service = $object->get_service
Recupera un manejador para el servicio remoto al que está adjunto este objeto. El objeto devuelto es una instancia de Net::DBus::RemoteService
my $path = $object->get_object_path
Recupera el identificador de ruta único para este objeto dentro del servicio.
my $object = $object->get_child_object($subpath, [$interface])
Recupera un manejador para un hijo de este objeto, identificado por la ruta relativa $subpath. El objeto devuelto es una instancia de "Net::DBus::RemoteObject". El parámetro opcional $interface se puede usar para convertir inmediatamente el objeto a un tipo específico.
my $sigid = $object->connect_to_signal($name, $coderef);
Conecta un callback a una señal emitida por el objeto. El parámetro $name es el nombre de la señal dentro del objeto, y $coderef es una referencia a una subrutina anónima. Cuando la señal $name es emitida por el objeto remoto, la subrutina $coderef será invocada, y se le pasarán los parámetros de la señal. Se devolverá un $sigid único, que más tarde se puede pasar a "disconnect_from_signal" para eliminar el manejador.
$object->disconnect_from_signal($name, $sigid);
Desconecta de una señal emitida por el objeto. El parámetro $name es el nombre de la señal dentro del objeto. El $sigid debe ser el ID único del manejador de señal devuelto por una llamada anterior al método "connect_to_signal".
