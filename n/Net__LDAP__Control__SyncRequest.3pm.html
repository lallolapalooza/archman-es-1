Net::LDAP::Control::SyncRequest(3) Documentación aportada por el usuario de Perl Net::LDAP::Control::SyncRequest(3)

NOMBRE

Net::LDAP::Control::SyncRequest - Objeto de control de solicitud de sincronización LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::SyncRequest;
use Net::LDAP::Constant qw(
 LDAP_SYNC_REFRESH_ONLY
 LDAP_SYNC_REFRESH_AND_PERSIST
 LDAP_SUCCESS );
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$req = Net::LDAP::Control::SyncRequest->new( mode => LDAP_SYNC_REFRESH_ONLY );
my $mesg = $ldap->search(base=> 'dc=mydomain,dc='eg',
                         scope    => 'sub',
                         control  => [ $req ],
                         callback => \&searchCallback, # llamar para cada entrada
                         filter   => "(objectClass=*)",
                         attrs    => [ '*']);
sub searchCallback {
  my $message = shift;
  my $entry = shift;
  my @controls = $message->control;
  if ($controls[0]->isa('Net::LDAP::Control::SyncState')) {
    print "Recibida Control de Estado de Sincronización\n";
    print $entry->dn()."\n";
    print 'Estado: '.$controls[0]->state."\n.", UUID de entrada: '.$controls[0]->entryUUID.', cookie: '.$controls[0]->cookie;
  } elsif ($controls[0]->isa('Net::LDAP::Control::SyncDone')) {
    print "Recibida Control de Sincronización Terminada\n";
    print 'Cookie: '.$controls[0]->cookie.', refreshDeletes: '.$controls[0]->refreshDeletes;
  }
}

DESCRIPCIÓN

"Net::LDAP::Control::SyncRequest" proporciona una interfaz para la creación y manipulación de objetos que representan el "Control de Solicitud de Sincronización" como se describe en el RFC 4533.

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control se proporcionan los siguientes.

mode
cookie
reloadHint

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto que devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.

VER TAMBIÉN

Net::LDAP, Net::LDAP::Control, Net::LDAP::Control::SyncState, Net::LDAP::Control::SyncDone, http://www.ietf.org/rfc/rfc4533.txt
