Paquete: perl-net-dns

Net::DNS::RR::APL(3) Documentación de Perl contribuida por el usuario Net::DNS::RR::APL(3)

NOMBRE

Net::DNS::RR::APL - Registro de recursos APL de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN APL aplist');

DESCRIPCIÓN

Registro APL (Address Prefix List) de DNS

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, y podría dar lugar a la terminación del programa u otro comportamiento impredecible.

aplist

@aplist = $rr->aplist;

@aplist = $rr->aplist( '1:192.168.32.0/21', '!1:192.168.38.0/28' );

@aplist = $rr->aplist( '1:224.0.0.0/4', '2:FF00:0:0:0:0:0:0:0/8' );

@aplist = $rr->aplist(
                negate  => 1,
                family  => 1,
                address => '192.168.38.0',
                prefix  => 28,
                );

Lista ordenada, posiblemente vacía, de elementos de prefijo de dirección. Los elementos adicionales, si están presentes, se añaden a la lista existente sin agregación de prefijos ni reordenamiento.

Net::DNS::RR::APL::Item

Cada elemento de la lista de prefijos es un objeto Net::DNS::RR::APL::Item que está intrínsecamente ligado al registro APL que lo creó.

negate

$rr->negate(1);
if ( $rr->negate ) {
        ...
}

Atributo booleano que indica que el prefijo es una exclusión de rango de direcciones.

family

$family = $rr->family;
$rr->family( $family );

Discriminante de la familia de direcciones.

prefix

$prefix = $rr->prefix;
$rr->prefix( $prefix );

Número de bits que componen el prefijo de dirección.

address

$address = $object->address;

Porción de dirección del elemento de la lista de prefijos.

string

$string = $object->string;

Devuelve el elemento de la lista de prefijos en el formato requerido en los archivos de zona.
