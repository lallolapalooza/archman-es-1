NOMBRE

Net::DBus::Tutorial::UsingObjects - tutorial sobre el acceso a un servicio DBus

DESCRIPCIÓN

Este documento proporciona un tutorial sobre cómo acceder a un servicio DBus utilizando los enlaces de aplicaciones Net::DBus de Perl. Lamentablemente, aún no está escrito.

VER TAMBIÉN

Net::DBus::Tutorial para detalles de otros tutoriales, y Net::DBus para la documentación de la API.
