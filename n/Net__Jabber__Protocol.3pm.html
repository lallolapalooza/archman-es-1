NOMBRE

Net::Jabber::Protocol - Librería de Protocolo Jabber

SINOPSIS

Net::Jabber::Protocol es un módulo que proporciona a los desarrolladores un fácil
acceso al protocolo de mensajería instantánea Jabber. Proporciona funciones de alto
nivel a los objetos Client, Component y Server de Net::Jabber. Estas funciones se
incluyen automáticamente en esos módulos a través de AUTOLOAD y delegados.

DESCRIPCIÓN

Protocol.pm busca proporcionar suficientes APIs de alto nivel y automatización de
las APIs de bajo nivel para que escribir un Cliente/Transporte Jabber en Perl sea
trivial. Para aquellos que deseen trabajar con el bajo nivel, también pueden hacerlo,
pero esas funciones se cubren en la documentación de cada módulo.
Net::Jabber::Protocol proporciona funciones para iniciar sesión, enviar y recibir
mensajes, establecer información personal, crear una nueva cuenta de usuario,
gestionar la lista de contactos y desconectarse. Puede usar todas o ninguna de las
funciones, no hay ningún requisito.
Para más información sobre cómo está escrito Net::Jabber, consulte la ayuda de
Net::Jabber.
Para más información sobre cómo escribir un Cliente, consulte Net::Jabber::Client.
Para más información sobre cómo escribir un Transporte, consulte Net::Jabber::Transport.

Modos

Varias de las funciones toman un argumento de modo que le permite especificar cómo
debe comportarse la función:
  bloqueo - envía el paquete con un ID y luego se bloquea hasta que llega una respuesta.
            Opcionalmente, puede especificar un tiempo de espera para no bloquearse para
            siempre.

  no_bloqueo - envía el paquete con un ID, pero luego devuelve ese ID y
               el control al programa principal. Net::Jabber todavía está
               rastreando este paquete, por lo que debe usar la función CheckID
               para saber cuándo llega. (Esto podría no ser muy
               útil...)
  pasar_por - envía el paquete con un ID, pero NO lo registra con
              Net::Jabber, y luego devuelve el ID. Esto es útil cuando
              se combina con la función XPath porque puede registrar una función
              de un solo uso vinculada al ID que obtiene.

Agents Functions

********************************
*                              *
* Deprecated in favor of Disco *
*                              *
********************************
AgentsGet(to=>string, - takes all of the information and
AgentsGet()             builds a Net::Jabber::IQ::Agents packet.
                        It then sends that packet either to the
                        server, or to the specified transport,
                        with an ID and waits for that ID to return.
                        Then it looks in the resulting packet and
                        builds a hash that contains the values
                        of the agent list.  The hash is layed out
                        like this:  (NOTE: the jid is the key to
                        distinguish the various agents)
                          $hash{<JID>}->{order} = 4
                                      ->{name} = "ICQ Transport"
                                      ->{transport} = "ICQ #"
                                      ->{description} = "ICQ..blah.."
                                      ->{service} = "icq"
                                      ->{register} = 1
                                      ->{search} = 1
                                    etc...
                        The order field determines the order that
                        it came from the server in... in case you
                        care.  For more info on the valid fields
                        see the Net::Jabber::Query jabber:iq:agent
                        namespace.

            $browse{'category'} = "conference"

NAME

Net::Jabber::Protocol - protocol-level functions for jabber

SYNOPSIS

 use Net::Jabber::Protocol;
 my $protocol = Net::Jabber::Protocol->new($host, $port);
 $protocol->Connect();
 $protocol->AuthPlain($user, $password);
 my $response = $protocol->Send(to => $jid,
                                from => $myjid,
                                type => 'message',
                                body => $message);
 # ...
 $protocol->Disconnect();

DESCRIPTION

This module handles the low-level socket communication for jabber. It also handles the jabber xml stream, and provides a simple interface for sending and receiving jabber stanzas.

This module is intended to be used by higher-level modules such as Net::Jabber.

METHODS

Constructor

new(host => string, port => int)
            - Creates a new Net::Jabber::Protocol object.
              host - The jabber server hostname or ip address.
              port - The jabber server port (default 5222).

Connection Methods

Connect() - Connects to the jabber server.
Disconnect() - Disconnects from the jabber server.
IsConnected() - Returns true if connected, false otherwise.

Authentication Methods

AuthPlain(user => string, password => string)
            - Authenticates using the PLAIN mechanism.
AuthDigestMD5(username => string, password => string,
              resource => string)
            - Authenticates using the DIGEST-MD5 mechanism.
              resource - The resource to use for authentication (optional).

Sending and Receiving Methods

Send(to => string,      - Sends a jabber stanza to the server.
     from => string,      - The sender of the stanza.
     type => string,      - The type of stanza (e.g., 'message', 'iq', 'presence').
     subject => string,  - The subject of the stanza (for messages).
     body => string,      - The body of the stanza (for messages).
     id => string,        - The id of the stanza (for iqs).
     query => hashref,    - The query data for iq stanzas.
     ...                  - Other attributes for the stanza.)
     - Returns the stanza id if successful, undef otherwise.
Receive(timeout => int) - Receives a jabber stanza from the server.
             - timeout - The maximum time to wait for a stanza (in seconds).
             - Returns a hashref containing the stanza information, or undef on timeout or error.
             The returned hash may contain the following keys:
             to, from, type, subject, body, id, query,
             and any other attributes present in the stanza.
