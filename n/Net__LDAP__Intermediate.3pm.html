Net::LDAP::Intermediate(3) Documentación de Perl aportada por el usuario Net::LDAP::Intermediate(3)

NOMBRE

Net::LDAP::Intermediate - Clase base de objeto de respuesta intermedia LDAPv3

SINOPSIS

use Net::LDAP::Intermediate;

DESCRIPCIÓN

"Net::LDAP::Intermediate" es una clase base para objetos de respuesta intermedia LDAPv3.

CONSTRUCTORES

new ( ARGS )
ARGS es una lista de pares nombre/valor, los argumentos válidos son:
responseName
Una representación de punto decimal de un IDENTIFICADOR DE OBJETO que identifica únicamente la respuesta intermedia. Esto evita conflictos entre nombres de respuestas intermedias.
responseValue
Información opcional asociada con la respuesta intermedia. Su formato es específico para la respuesta intermedia particular.
from_asn ( ASN )
ASN es una referencia a un HASH, normalmente extraída de un PDU. Contendrá un elemento "responseName" y opcionalmente un elemento "responseValue". Al retornar, ASN será "bendecido" (blessed) a un paquete. Si "responseName" es un OID registrado, entonces ASN será "bendecido" al paquete registrado, si no, ASN será "bendecido" a Net::LDAP::Intermediate.

Este constructor es utilizado internamente por Net::LDAP y asume que el HASH pasado contiene una respuesta intermedia válida. Debe ser usado con **precaución**.

MÉTODOS

Además de los métodos listados a continuación, cada uno de los parámetros nombrados para "new" también está disponible como un método. "responseName" devolverá el OID del objeto de respuesta intermedia. "responseValue" son métodos para establecer/obtener y devolverán el valor actual para cada atributo si se llaman sin argumentos, pero también pueden ser llamados con argumentos para establecer nuevos valores.

error ()
Si ha habido un error, devuelve una descripción del error, de lo contrario devuelve "undef"
init ()
"init" será llamado como el último paso en ambos constructores. Lo que haga dependerá de la subclase. Siempre debe devolver el objeto.
register ( OID )
"register" se proporciona para los implementadores de subclases. Debe ser llamado como un método de clase en una subclase de Net::LDAP::Intermediate con el OID que la clase manejará. Net::LDAP::Intermediate recordará este par clase y OID y lo usará en las siguientes situaciones.
  • Se llama a "new" como un método de clase en el paquete Net::LDAP::Intermediate y se pasa el OID como responseName. El objeto devuelto será "bendecido" al paquete que registró el OID.
  • Se llama a "new" como un método de clase en un paquete registrado y no se especifica el "responseName". El "responseName" se establecerá al OID registrado por ese paquete.
  • Se llama a "from_asn" para construir un objeto a partir de ASN. El objeto devuelto será "bendecido" al paquete que fue registrado para manejar el OID en el ASN.
( to_asn )
Devuelve una estructura adecuada para pasar a Convert::ASN1 para codificar. Este método será llamado por Net::LDAP cuando se utilice la respuesta intermedia.

La implementación de clase base de este método llamará al método "responseValue" sin argumentos para permitir que una subclase codifique su valor. Las subclases no deberían necesitar sobrescribir este método.

valid ()
Devuelve verdadero si el objeto es válido y puede ser codificado. La implementación predeterminada para este método es devolver VERDADERO si no hay error, pero las subclases pueden sobrescribirlo.
