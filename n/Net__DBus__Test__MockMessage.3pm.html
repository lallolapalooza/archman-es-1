Net::DBus::Test::MockMessage(3) Documentación de Perl aportada por el usuario Net::DBus::Test::MockMessage(3)

NOMBRE

Net::DBus::Test::MockMessage - Simula un objeto de mensaje al probar unidades

SINOPSIS

Envío de un mensaje

my $msg = new Net::DBus::Test::MockMessage;
my $iterator = $msg->iterator;
$iterator->append_byte(132);
$iterator->append_int32(14241);
$connection->send($msg);

DESCRIPCIÓN

Este módulo proporciona una contraparte "mock" de la clase Net::DBus::Binding::Message. Es básicamente un objeto de mensaje falso escrito completamente en Perl que proporciona el mismo contrato que el objeto de mensaje real. Está destinado a ser utilizado internamente por las APIs de prueba.

MÉTODOS

my $call = Net::DBus::Test::MockMessage->new_method_call( service_name => $service, object_path => $object, interface => $interface, method_name => $name);
Crea un mensaje que representa una llamada al objeto ubicado en la ruta "object_path" dentro del cliente que posee el nombre bien conocido dado por "service_name". El método a invocar tiene el nombre "method_name" dentro de la interfaz especificada por el parámetro "interface".
my $msg = Net::DBus::Test::MockMessage->new_method_return( replyto => $method_call);
Crea un mensaje que representa una respuesta a la llamada de método pasada en el parámetro "replyto".
my $signal = Net::DBus::Test::MockMessage->new_signal( object_path => $path, interface => $interface, signal_name => $name);
Crea un nuevo mensaje, que representa una señal que se emitirá [o se emitirá] por el objeto ubicado bajo la ruta dada por el parámetro "object_path". El nombre de la señal se da por el parámetro "signal_name", y está limitado a la interfaz dada por el parámetro "interface".
my $msg = Net::DBus::Test::MockMessage->new_error( replyto => $method_call, name => $name, description => $description);
Crea un nuevo mensaje, que representa un error que ocurrió durante el manejo de la llamada de método proporcionada como el parámetro "replyto". El parámetro "name" es el nombre formal de la condición de error, mientras que la "description" es un texto corto que proporciona información más específica sobre el error.
my $type = $msg->get_type
Recupera el código de tipo para este mensaje. El valor devuelto corresponde a una de las cuatro constantes "Net::DBus::Test::MockMessage::MESSAGE_TYPE_*".
my $name = $msg->get_error_name
Devuelve el nombre formal del error, tal como se pasó previamente a través del parámetro "name" en el constructor.
my $interface = $msg->get_interface
Recupera el nombre de la interfaz a la que se dirige este mensaje, posiblemente una cadena vacía si no hay una interfaz aplicable para este mensaje.
my $path = $msg->get_path
Recupera la ruta del objeto asociada con el mensaje, posiblemente una cadena vacía si no hay un objeto aplicable para este mensaje.
my $name = $msg->get_destination
Recupera el nombre de bus único o conocido para el cliente al que se pretende enviar el mensaje. Posiblemente devuelve una cadena vacía si el mensaje se está transmitiendo a todos los clientes.
my $name = $msg->get_sender
Recupera el nombre único del cliente que envía el mensaje.
my $serial = $msg->get_serial
Recupera el número de serie único de este mensaje. El número está garantizado como único mientras la conexión a través de la cual se envió el mensaje permanezca abierta. Puede devolver cero si el mensaje aún no se ha enviado.
my $name = $msg->get_member
Para llamadas de método, recupera el nombre del método a invocar, mientras que para las señales, recupera el nombre de la señal.
$msg->set_sender($name)
Establece el nombre del cliente que envía el mensaje. El nombre debe ser el nombre único del cliente.
$msg->set_destination($name)
Establece el nombre del destinatario previsto del mensaje. Esto se usa típicamente para señales para cambiarlas de difusión a unicast.
my $iterator = $msg->iterator;
Recupera un iterador que puede usarse para leer o escribir campos del mensaje. El objeto devuelto es una instancia de la clase "Net::DBus::Binding::Iterator".
$boolean = $msg->get_no_reply()
Obtiene el indicador que muestra si se espera una respuesta para el mensaje.
$msg->set_no_reply($boolean)
Cambia el indicador que muestra si se espera una respuesta para el mensaje. Todas las llamadas de método esperan una respuesta por defecto. Al cambiar este indicador, se reduce la latencia de comunicación al eliminar la necesidad de que el cliente espere.
my @values = $msg->get_args_list
Desempaqueta todos los valores del cuerpo del mensaje, utilizando la firma del mensaje para identificar los tipos de datos. Los valores se devuelven como una lista.
$msg->append_args_list(@values)
Añade un conjunto de valores al cuerpo del mensaje. Los valores se codificarán como una cadena, lista o diccionario según corresponda a su tipo de datos de Perl. Para necesidades de tipado de datos más específicas, se debe utilizar el objeto Net::DBus::Binding::Iterator en su lugar.
my $sig = $msg->get_signature
Recupera una cadena que representa la firma de tipo de los valores empaquetados en el cuerpo del mensaje.
