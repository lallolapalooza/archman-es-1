NOMBRE

Net::LDAP::Control::Paged - Objeto de control de paginación de resultados LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::Paged;
use Net::LDAP::Constant qw( LDAP_CONTROL_PAGED );
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$page = Net::LDAP::Control::Paged->new( size => 100 );
@args = ( base     => "cn=subnets,cn=sites,cn=configuration,$BASE_DN",
          scope    => "subtree",
          filter   => "(objectClass=subnet)",
          callback => \&process_entry, # Llama a esta subrutina para cada entrada
          control  => [ $page ],
);
my $cookie;
while (1) {
  # Realizar búsqueda
  my $mesg = $ldap->search( @args );
  # Continuar solo en caso de LDAP_SUCCESS
  $mesg->code  and last;
  # Obtener cookie del control paginado
  my($resp)  = $mesg->control( LDAP_CONTROL_PAGED )  or last;
  $cookie    = $resp->cookie;
  # Continuar solo si la cookie no está vacía (= no hemos terminado)
  last  if (!defined($cookie) || !length($cookie));
  # Establecer cookie en el control paginado
  $page->cookie($cookie);
}
if (defined($cookie) && length($cookie)) {
  # Tuvimos una salida anormal, así que informamos al servidor que no queremos más
  $page->cookie($cookie);
  $page->size(0);
  $ldap->search( @args );
}

DESCRIPCIÓN

"Net::LDAP::Control::Paged" proporciona una interfaz para la creación y manipulación de objetos que representan el "pagedResultsControl" según se describe en la RFC 2696.

El control solo está permitido en las solicitudes de búsqueda LDAP ("search" en Net::LDAP). En otras operaciones, dependiendo del valor del parámetro "critical", será ignorado o provocará errores.

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control, se proporcionan los siguientes:

cookie
El valor que se utilizará como cookie. Normalmente no se establece al crear un objeto, sino que se establece a partir del valor de cookie devuelto por el servidor. Esto asocia una búsqueda con una búsqueda anterior, de modo que el servidor sabe que debe devolver la página de entradas que sigue a las entradas que devolvió la vez anterior.
size
El tamaño de página requerido. Este es el número máximo de entradas que el servidor devolverá a la solicitud de búsqueda.

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente está disponible como un método en el objeto, que devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.
