NOMBRE

Net::LDAP::Extension::SetPassword - Objeto de extensión de operación de modificación de contraseña de LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Extension::SetPassword;
$ldap = Net::LDAP->new( "ldap.midominio.ej" );
$ldap->bind('cn=Usuario Joe,cn=Gente,dc=midominio,dc=ej",
            password => 'contraseñaVieja');
$mesg = $ldap->set_password( oldpasswd => 'contraseñaVieja' );
die "error: ", $mesg->code(), ": ", $mesg->error()  if ($mesg->code());
print "cambió tu contraseña a", $mesg->gen_password() , "\n";

DESCRIPCIÓN

"Net::LDAP::Extension::SetPassword" implementa la operación extendida "Modify Password" de LDAPv3, tal como se describe en la RFC 3062.

No implementa ningún objeto por sí mismo, sino que extiende el objeto Net::LDAP con un método adicional:

MÉTODOS

set_password ( OPCIONES )
Establece la contraseña de un usuario.

OPCIONES es una lista de pares clave/valor. Las siguientes claves son reconocidas:

user
Si está presente, esta opción contiene la representación de cadena de octetos del usuario asociado con la solicitud. Dependiendo de cómo se identifiquen los usuarios en el directorio, esta cadena puede ser o no un DN según la RFC 4514.

Si esta opción no está presente, la solicitud actúa sobre la contraseña del usuario actualmente asociado con la sesión LDAP.

oldpasswd
Esta opción, si está presente, debe contener la contraseña actual del usuario para quien se realiza esta operación.

Depende de la implementación del servidor en qué circunstancias se permite que esta opción esté ausente.

newpasswd
Si está presente, esta opción contiene la contraseña deseada para el usuario para quien se realiza la operación.

Dependiendo de la implementación del servidor, esta opción puede ser requerida por el servidor LDAP.

gen_password ( )
Devuelve la contraseña generada por el servidor en respuesta a la llamada set_password() cuando sea aplicable. El servidor no generará una nueva contraseña si se pasó "newpasswd" a set_password().

Este método es un método del objeto de respuesta Net::LDAP::Message retornado en respuesta a set_password() en caso de que la llamada set_password() haya tenido éxito.

Mediante este método, el llamador puede consultar el valor de la contraseña en caso de que no haya llamado a set_password() con la opción "newpasswd".
