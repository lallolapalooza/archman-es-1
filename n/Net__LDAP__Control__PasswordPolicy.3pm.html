NOMBRE

Net::LDAP::Control::PasswordPolicy - Objeto de control de política de contraseñas de LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::PasswordPolicy;
use Net::LDAP::Constant qw( LDAP_CONTROL_PASSWORDPOLICY );
$ldap = Net::LDAP->new( "ldap.example.com" );
$pp = Net::LDAP::Control::PasswordPolicy->new;
$mesg = $ldap->bind( "cn=Bob Smith,dc=example,dc=com",
                     password => "secret",
                     control => [ $pp ] );
# Obtener la respuesta de la política de contraseñas
my($resp)  = $mesg->control( LDAP_CONTROL_PASSWORDPOLICY );
if (defined($resp)) {
  my $v = $resp->pp_error;
  print "Error de política de contraseñas $v\n"  if defined $v;
  $v = $resp->time_before_expiration;
  print "La contraseña expira en $v segundo(s)\n"  if defined $v;
}

DESCRIPCIÓN

"Net::LDAP::Control::PasswordPolicy" proporciona una interfaz para la creación y manipulación de objetos que representan "PasswordPolicyRequest"s y "PasswordPolicyResponse"s según se describe en draft-behera-password-policy-09.

Este control se puede pasar a la mayoría de las operaciones, incluida la vinculación.

ARGUMENTOS DEL CONSTRUCTOR

No hay argumentos de constructor aparte de los proporcionados por Net::LDAP::Control.

MÉTODOS

time_before_expiration
Si está definido, este es un valor entero que contiene el tiempo restante en segundos antes de que expire la contraseña de la cuenta.
grace_authentications_remaining
Si está definido, este es un valor entero que contiene el número de solicitudes de autenticación permitidas antes de que la cuenta se bloquee.
pp_error
Si está definido, contiene un código de error más detallado para la cuenta. Consulte Net::LDAP::Constant para ver las definiciones de cada uno. Los valores pueden incluir:
LDAP_PP_PASSWORD_EXPIRED
LDAP_PP_ACCOUNT_LOCKED
LDAP_PP_CHANGE_AFTER_RESET
LDAP_PP_PASSWORD_MOD_NOT_ALLOWED
LDAP_PP_MUST_SUPPLY_OLD_PASSWORD
LDAP_PP_INSUFFICIENT_PASSWORD_QUALITY
LDAP_PP_PASSWORD_TOO_SHORT
LDAP_PP_PASSWORD_TOO_YOUNG
LDAP_PP_PASSWORD_IN_HISTORY

VER TAMBIÉN
