NOMBRE

Net::DNS::SEC - extensiones DNSSEC a Net::DNS

SINOPSIS

use Net::DNS::SEC;

DESCRIPCIÓN

Net::DNS::SEC se instala como una extensión de una instalación existente de Net::DNS, proporcionando paquetes para soportar DNSSEC según se especifica en las RFC4033, RFC4034, RFC4035 y documentos relacionados.

También proporciona soporte para SIG0, que es útil para actualizaciones dinámicas.

Implementa funciones de generación y verificación de firmas criptográficas utilizando algoritmos RSA, DSA, ECDSA y de curva de Edwards.

Las características extendidas se ponen a disposición reemplazando Net::DNS por Net::DNS::SEC en la declaración use.

FUNCIONES DE UTILIDAD

algoritmo

$mnemotecnico = algoritmo( 5 );
$numerico  = algoritmo( 'RSA-SHA1' );
print "algoritmo mnemotecnico\t", $mnemotecnico, "\n";
print "algoritmo numero:\t",  $numerico,  "\n";

algoritmo() proporciona conversiones entre un número de código de algoritmo y el mnemotécnico correspondiente.

tipo_digesto

$mnemotecnico = tipo_digesto( 2 );
$numerico  = tipo_digesto( 'SHA-256' );
print "tipo de digesto mnemotecnico\t", $mnemotecnico, "\n";
print "tipo de digesto numero:\t",  $numerico,  "\n";

tipo_digesto() proporciona conversiones entre un número de tipo de digesto y el mnemotécnico correspondiente.

diferencia_claves

@resultado = diferencia_claves( \@a, \@b );

Rellena @resultado con todas las claves del array @a que no están en el array @b.
