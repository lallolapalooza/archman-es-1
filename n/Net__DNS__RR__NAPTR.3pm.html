Net::DNS::RR::NAPTR(3) Documentación de Perl aportada por el usuario Net::DNS::RR::NAPTR(3)

NOMBRE

Net::DNS::RR::NAPTR - Registro de recurso NAPTR de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre NAPTR ( orden preferencia
                flags servicio regexp reemplazo )');

DESCRIPCIÓN

Registros de recursos NAPTR (Naming Authority Pointer) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

Se desaconseja el uso de funciones no documentadas del paquete o el acceso directo a estructuras de datos internas, ya que podría resultar en la terminación del programa u otros comportamientos impredecibles.

orden

$orden = $rr->order;
$rr->order( $orden );

Un entero sin signo de 16 bits que especifica el orden en que se deben procesar los registros NAPTR para asegurar el ordenamiento correcto de las reglas. Los números bajos se procesan antes que los números altos.

preferencia

$preferencia = $rr->preference;
$rr->preference( $preferencia );

Un entero sin signo de 16 bits que especifica el orden en que se deben procesar los registros NAPTR con valores de "orden" iguales, procesándose los números bajos antes que los números altos.

flags

$flags = $rr->flags;
$rr->flags( $flags );

Una cadena que contiene indicadores (flags) para controlar aspectos de la reescritura e interpretación de los campos del registro. Los indicadores son caracteres individuales del conjunto [A-Z0-9].

servicio

$servicio = $rr->service;
$rr->service( $servicio );

Especifica el(los) servicio(s) disponible(s) a través de esta ruta de reescritura. También puede especificar el protocolo utilizado para comunicarse con el servicio.

regexp

$regexp = $rr->regexp;
$rr->regexp;

Una cadena que contiene una expresión de sustitución que se aplica a la cadena original mantenida por el cliente para construir el siguiente nombre de dominio a consultar.

reemplazo

$reemplazo = $rr->replacement;
$rr->replacement( $reemplazo );

El siguiente NOMBRE a consultar para obtener registros NAPTR, SRV o de dirección, dependiendo del valor del campo de indicadores (flags).
