Net::DBus::Dumper(3) Documentación de Perl aportada por el usuario Net::DBus::Dumper(3)

NOMBRE

Net::DBus::Dumper - Convierte objetos Net::DBus a cadenas adecuadas para impresión

SINOPSIS

use Net::DBus::Dumper;
use Net::DBus;
# Imprime información sobre el bus
my $bus = Net::DBus->find;
print dbus_dump($bus);
# Imprime información sobre un servicio
my $service = $bus->get_service("org.freedesktop.DBus");
print dbus_dump($service);
# Imprime información sobre un objeto
my $object = $service->get_object("/org/freedesktop/DBus");
print dbus_dump($object);

DESCRIPCIÓN

Este módulo sirve como ayuda para la depuración, proporcionando un medio para convertir a cadena un objeto relacionado con DBus de forma adecuada para su impresión. Puede convertir a cadena cualquiera de los objetos Net::DBus:*, generando la siguiente información para cada uno:

Net::DBus
Una lista de servicios registrados en el bus
Net::DBus::Service =item Net::DBus::RemoteService
El nombre del servicio
Net::DBus::Object =item Net::DBus::RemoteObject
La lista de todos los métodos y señales exportados, junto con sus tipos de parámetros y retorno.

MÉTODOS

my @datos = dbus_dump($objeto);
Genera una representación en cadena de un objeto. El objeto pasado como parámetro debe ser una instancia de uno de Net::DBus, Net::DBus::RemoteService, Net::DBus::Service, Net::DBus::RemoteObject, Net::DBus::Object. La representación en cadena se devolverá como una lista de cadenas, con saltos de línea en los lugares apropiados, de modo que pueda pasarse directamente al método "print".

ERRORES

Debería imprimir una lista de rutas de objetos registradas en un servicio, pero esto actualmente solo funciona para servicios implementados en Perl.
