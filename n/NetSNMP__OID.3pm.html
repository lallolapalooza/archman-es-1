NOMBRE

NetSNMP::OID - Extensión de Perl para manipular OIDs

SINOPSIS

use NetSNMP::OID;
my $oid = new NetSNMP::OID('sysContact.0');
if ($oid < new NetSNMP::OID('ifTable')) {
    do_something();
}
my @numarray = $oid->to_array();
# añadiendo oids
$oid = new NetSNMP::OID('.1.3');
$oid += ".6.1";
# -> .1.3.6.1
# añadiendo cadenas de índice
$oid2 = $oid + "\"wes\"";
# -> .1.3.6.1.3.119.101.115
$oid3 = $oid + "\'wes\'";
# -> .1.3.6.1.119.101.115
$len = $oid3->length();
# -> 7
# recuperando índices de un oid:
$arrayref = $tableoid->get_indexes()

DESCRIPCIÓN

El módulo NetSNMP::OID es un simple envoltorio alrededor de un oid net-snmp basado en C (que es un array de enteros sin signo). El OID se almacena internamente como un array de C de enteros por motivos de velocidad al realizar comparaciones, etc.

Los operadores lógicos de expresión estándar (<, >, ==, ...) se sobrecargan de tal manera que se puedan realizar comparaciones lexicográficas con ellos.

El operador + se sobrecarga para permitirle agregar elementos al final de un OID, como segmentos de índice de una tabla, por ejemplo.

EXPORTAR
