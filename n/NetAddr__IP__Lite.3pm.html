NAME

NetAddr::IP::Lite - Gestión de direcciones IPv4 y IPv6 y subredes

SYNOPSIS

use NetAddr::IP::Lite qw(
      Zeros
      Ones
      V4mask
      V4net
      :aton           DEPRECATED !
      :old_nth
      :upper
      :lower
      :nofqdn
);
my $ip = new NetAddr::IP::Lite '127.0.0.1';
      o si te gusta
my $ip = NetAddr::IP::Lite->new('127.0.0.1);
      o de un address IPv4 packeado
my $ip = new_from_aton NetAddr::IP::Lite (inet_aton('127.0.0.1'));
      o de un address IPv4 octal filtrado
my $ip = new_no NetAddr::IP::Lite '127.012.0.0';
print "La dirección es ", $ip->addr, " con máscara ", $ip->mask, "\n" ;
if ($ip->within(new NetAddr::IP::Lite "127.0.0.0", "255.0.0.0")) {
    print "Es una dirección de loopback\n";
}
                              # Este imprime 127.0.0.1/32
print "También puedes decir $ip...\n";
Los siguientes cuatro funciones devuelven representaciones de IPv6 de:
::                                       = Zeros();
FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF  = Ones();
FFFF:FFFF:FFFF:FFFF:FFFF:FFFF::          = V4mask();
::FFFF:FFFF                              = V4net();
También devuelve una representación de IPv4 o IPv6 de un nombre de dominio completo (FQDN) resoluble.

INSTALACIÓN

Descompone la distribución en un directorio adecuado y ejecuta:

perl Makefile.PL
make
make test
make install

NetAddr::IP::Lite depende de NetAddr::IP::Util, que se instala por defecto con sus funciones principales compiladas utilizando extensiones de lenguaje C del Perl. Si no tienes un compilador C disponible o quieres la versión más lenta de Perl para otros motivos, entonces ejecuta:

perl Makefile.PL -noxs
make
make test
make install

DESCRIPCIÓN

Este módulo proporciona una abstracción orientada a objetos sobre direcciones o subredes de IP, lo que permite manipulaciones fácilmente. La mayoría de las operaciones de NetAddr::IP son soportadas. Este módulo funcionará con versiones antiguas de Perl y será compatible con Math::BigInt.

* Por defecto NetAddr::IP funciona y métodos de objetos devuelven direcciones IPv6 en mayúsculas. Para cambiar esa a minúsculas:

NOTA: El RFC5952 de agosto de 2010 establece:

4.3. Mayúsculas
  Las letras "a", "b", "c", "d", "e", y "f" en una dirección IPv6
  deben representarse en minúsculas.

Se recomienda que los nuevos aplicaciones que usen NetAddr::IP::Lite se invoquen como se muestra en la siguiente línea:

use NetAddr::IP::Lite qw(:lower);

* Para asegurar el comportamiento de la cadena de IPv6 en mayúsculas incluso si el por defecto cambia:

use NetAddr::IP::Lite qw(:upper);

La representación interna de todos los objetos de IP es en notación de 128 bits de IPv6. Las direcciones IPv4 y IPv6 pueden ser mezcladas libremente.

Las operaciones soportadas se describen a continuación:

Operadores sobrecargados

Asignación ("=")
Ha sido optimizada para copiar un objeto NetAddr::IP::Lite a otro muy rápido.
"->copy()"
El operador de asignación ("=") se ejecuta solo cuando el objeto copiado es mutado por otra operación sobrecargada. Ver SOBRE LOS SÍMBOLOS DE ASIGNACIÓN EN EL USO DE OVERLOAD para detalles.

"->copy()" crea un nuevo objeto cuando se lo llama.

Síntesis
Un objeto puede usarse como cadena. Por ejemplo, el siguiente código: 
my $ip = new NetAddr::IP::Lite '192.168.1.123';
print "$ip\n";

Imprime la cadena 192.168.1.123/32.

my $ip = new6 NetAddr::IP::Lite '192.168.1.123';
print "$ip\n";

Imprime la cadena 0:0:0:0:0:0:C0A8:17B/128

Igualdad
Puedes comparar con "eq", "ne", "==" o "!=". "eq", "ne" permite comparar con cadenas arbitrarias y objetos de NetAddr::IP::Lite. El siguiente ejemplo: 
if (NetAddr::IP::Lite->new('127.0.0.1','255.0.0.0') eq '127.0.0.1/8')
   { print "Sí\n"; }

Imprime "Sí"。

Comparaciones con "==" y "!=" requieren ambos operandos ser objetos de NetAddr::IP::Lite.

Comparación
Internamente, todos los objetos de red se representan en notación de 128 bits. La representación numérica de la red se compara mediante la operación correspondiente. Las comparaciones se intentan primero en la parte de la dirección del objeto y, si esa es igual, se comparan la parte numérica de las máscaras. Esto lleva a un resultado contraintuitivo, como: 
/24 > /16

No se debe comparar con objetos de red que tengan diferentes CIDR, ya que puede producir resultados indeterminados o inesperados, más bien se debe comparar

$ip1->masklen <=> $ip2->masklen
Suma de un valor constante ("+")
Suma un valor entero de 32 bits a la parte de la dirección de un objeto de NetAddr. Esta operación cambia la parte de la dirección para que se alinee con la dirección de los hosts que comienzan después de la dirección actual. Por ejemplo, este código: 
print NetAddr::IP::Lite->new('127.0.0.1/8') + 5;

imprime 127.0.0.6/8. La dirección se doblará al redirigir el broadcast a la dirección de red. Este código:

print NetAddr::IP::Lite->new('10.0.0.1/24') + 255;

imprime 10.0.0.0/24.

Devuelve el objeto sin cambios si el valor es ausente o fuera de rango.

2147483647 <= constant >= -2147483648
Resta de un valor constante ("-")
El complemento de la suma de un valor constante.
Diferencia ("-")
Devuelve la diferencia entre las partes de direcciones de los objetos de NetAddr::IP::Lite como un número entero de 32 bits.

Devuelve undef si la diferencia está fuera de rango.

Auto-incremento
Auto-incremento de un objeto NetAddr::IP::Lite causa la parte de la dirección a ser ajustada a la siguiente dirección de host dentro de la subred. Se doblará al dirección de broadcast y comenzará de nuevo desde la dirección de red.
Auto-decremento
Auto-decremento de un objeto NetAddr::IP::Lite realiza exactamente lo opuesto de auto-incremento, como se espera.

new6               ::xxxx:xxxx
new6FFFF      ::FFFF:xxxx:xxxx

    "->broadcast()"
    Devuelve un objeto nuevo que refiere a la dirección de broadcast de una subred. La dirección de broadcast tiene todos los bits 1 en las posiciones donde la máscara tiene 0. Esto se usa normalmente para dirigir a todos los nodos en una subred.
    "->network()"
    Devuelve un objeto nuevo que refiere a la dirección de red de una subred. Una dirección de red tiene todos los bits 0 donde los bits de la máscara son 0. Normalmente se usa para referirse a una subred.
    "->addr()"
    Devuelve un escalar con la parte de la dirección de objeto como una cadena de texto IPv4 o IPv6 correspondiente. Es útil para imprimir o pasar la parte de la dirección de objeto de NetAddr::IP::Lite a otros componentes que esperan una dirección IP. Si el objeto es una dirección IPv6 o fue creada usando ->new6($ip), se reporta en formato hexadecimal IPv6, de lo contrario solo en formato de puntos en cuadrado si reside en el espacio de direcciones IPv4.
    "->mask()"
    Devuelve un escalar con la máscara como una cadena de texto IPv4 o IPv6 correspondiente.
    "->masklen()"
    Devuelve un escalar con el número de bits de la máscara.
    "->bits()"
    Devuelve la anchura en bits de la dirección. Normalmente 32 para IPv4 y 128 para IPv6.
    "->version()"
    Devuelve la versión de la dirección o subred. Actualmente puede ser 4 o 6.
    "->cidr()"
    Devuelve un escalar con la dirección y la máscara en notación CIDR. Un objeto NetAddr::IP::Lite stringifica a la resultado de este método. (ver comentarios sobre ->new6() y ->addr() para formatos de salida)
    "->aton()"
    Devuelve la parte de la dirección de objeto de NetAddr::IP::Lite en el mismo formato que el inet_aton() o "ipv6_aton" función respectivamente. Si el objeto fue creado usando ->new6($ip), la dirección devuelta siempre será en formato IPv6, incluso para direcciones en el espacio de direcciones IPv4.
    "->range()"
    Devuelve un escalar con la dirección base y la dirección de broadcast separados por un guion y espacios. Esto se llama notación de rango.
    "->numeric()"
    Al llamar en contexto escalar, devuelve una representación numérica de la parte de la dirección IP. Al llamar en contexto array, devuelve una lista de dos elementos. El primer elemento es como descrito, el segundo elemento es la representación numérica de la máscara de red.
    Este método es esencial para serializar la representación de una subred.
    "->bigint()"
    Al llamar en contexto escalar, devuelve una representación de Math::BigInt de la parte de la dirección IP. Al llamar en contexto array, devuelve una lista de dos elementos. El primer elemento es como descrito, el segundo elemento es la representación de Math::BigInt de la máscara de red.
    "$me->contains($other)"
    Devuelve verdadero cuando $me completa contiene a $other. Falso se devuelve de lo contrario y "undef" se devuelve si $me y $other no son ambos objetos de tipo "NetAddr::IP::Lite".
    "$me->within($other)"
    La complementaria de "->contains()". Devuelve verdadero cuando $me está completamente contenido en $other, undef si $me y $other no son ambos objetos de tipo "NetAddr::IP::Lite".
