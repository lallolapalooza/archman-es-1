Net::IDN::Punycode(3) Documentación de Perl aportada por el usuario Net::IDN::Punycode(3)

NOMBRE

Net::IDN::Punycode - Codificación Bootstring de Unicode para IDNA (RFC 3492)

SINOPSIS

use Net::IDN::Punycode qw(:all);
$punycode = encode_punycode($unicode);
$unicode  = decode_punycode($punycode);

DESCRIPCIÓN

Este módulo implementa la codificación Punycode, y solo la codificación Punycode.

Este módulo no implementa ningún otro paso necesario para convertir nombres de dominio internacionalizados (IDN) a y desde ASCII. En particular, no realiza ninguna preparación de cadena según lo especificado por Nameprep/IDNA2008/PRECIS y no añade ni elimina el prefijo ACE ("xn--"). Por lo tanto, utilice Net::IDN::Encode si desea convertir nombres de dominio.

Punycode es una instancia de un algoritmo más general llamado Bootstring, que permite que cadenas compuestas de un pequeño conjunto de puntos de código "básicos" representen de forma única cualquier cadena de puntos de código extraída de un conjunto más grande. Punycode es Bootstring con valores de parámetros particulares apropiados para IDNA.

ADVERTENCIA

Puede que se sienta tentado a usar este módulo directamente y añadir/eliminar el prefijo ACE ("xn--") en su código por razones de rendimiento. Por lo general, esto no es una buena idea. Si convierte etiquetas de dominio (u otras cadenas) sin la preparación adecuada, podría terminar con una codificación ASCII que no sea interoperable o que incluso plantee problemas de seguridad debido a la suplantación.

Incluso si cree que sus nombres de dominio son válidos y ya están mapeados a la forma correcta, esto puede no ser cierto. Por ejemplo, algunos entornos podrían convertir automáticamente sus nombres de dominio perfectamente válidos a una forma de normalización Unicode diferente pero equivalente (por ejemplo, NFD en lugar de NFC), lo que ya rompe IDNA.

FUNCIONES

Ninguna función se exporta por defecto. Puede utilizar la etiqueta ":all" o importarlas individualmente.

Las siguientes funciones están disponibles:

encode_punycode($input)
Codifica $input con Punycode y devuelve el resultado.

Esta función lanzará una excepción ante una entrada no válida/no codificable.

decode_punycode($input)
Decodifica $input con Punycode y devuelve el resultado.

Esta función lanzará una excepción ante una entrada no válida.
