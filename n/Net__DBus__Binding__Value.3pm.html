NOMBRE

Net::DBus::Binding::Value - Valor de datos fuertemente tipado

SINOPSIS

# Importar las funciones de conveniencia
use Net::DBus qw(:typing);
# Llamar a un método pasando un int32
$object->doit(dint32("3"));

DESCRIPCIÓN

Este módulo proporciona un simple envoltorio alrededor de un valor Perl en bruto, asociando un tipo DBus explícito con el valor. Esto se utiliza en casos donde un cliente se está comunicando con un servidor que no proporciona datos de introspección, pero para los cuales los tipos de datos básicos no son suficientes. Esta clase no debe usarse directamente, sino que se deben llamar las funciones de conveniencia en Net::DBus.

MÉTODOS

mi $value = Net::DBus::Binding::Value->new($type, $value);
Crea un envoltorio para el valor Perl $value marcandolo como que tiene el tipo de datos dbus $type. No es necesario llamar a este método directamente, en su lugar se deben usar los métodos de tipado de datos en el objeto Net::DBus.
mi $raw = $value->value
Devuelve el valor Perl en bruto envuelto por este objeto
mi $type = $value->type
Devuelve el tipo de datos dbus con el que se marca este valor
