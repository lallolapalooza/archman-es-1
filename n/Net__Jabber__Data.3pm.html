NOMBRE

Net::Jabber::Data - Librería de Datos Jabber

SINOPSIS

Net::Jabber::Data es un complemento del módulo Net::Jabber::XDB. Proporciona al usuario una interfaz simple para establecer y recuperar todas las partes de un Dato XDB de Jabber.

DESCRIPCIÓN

Net::Jabber::Data difiere de los otros módulos en que su comportamiento y las funciones disponibles se basan en el espacio de nombres XML que se establece en él. La lista actual de espacios de nombres compatibles es:
  jabber:iq:auth
  jabber:iq:auth:0k
  jabber:iq:register
  jabber:iq:roster
Para obtener más información sobre para qué sirven estos espacios de nombres, visita 
http://www.jabber.org y explora la Guía del Programador de Jabber.
Cada uno de estos espacios de nombres proporciona a Net::Jabber::Data las funciones para acceder a los datos. Mediante la función AUTOLOAD, las funciones para cada espacio de nombres se utilizan cuando ese espacio de nombres está activo.
Para acceder a un objeto Data, debes crear un objeto XDB y usar las funciones de acceso allí para llegar a los Datos. Para inicializar el XDB con un <xdb/> de Jabber, debes pasarle la tabla hash de XML::Stream del módulo Net::Jabber::Client.
  my $xdb = new Net::Jabber::XDB(%hash);
Ha habido un cambio en la forma de manejar las llamadas de retorno.
Ya no tienes que hacer lo anterior tú mismo, se pasa un objeto Net::Jabber::XDB a la función de llamada de retorno para el mensaje. Además, el primer argumento a las funciones de llamada de retorno es el ID de sesión de XML::Streams. Hay algunos casos en los que podrías querer esta información, como si crearas un Cliente que se conecta a dos servidores a la vez, o para escribir un mini servidor.
  use Net::Jabber qw(Client);
  sub xdbCB {
    my ($sid,$XDB) = @_;
    my $data = $XDB->GetData();
    .
    .
    .
  }
Ahora tienes acceso a todas las funciones de recuperación disponibles para ese espacio de nombres.
Para crear un nuevo xdb para enviar al servidor:
  use Net::Jabber;
  my $xdb = new Net::Jabber::XDB();
  $data = $xdb->NewData("jabber:iq:auth");
Ahora puedes llamar a las funciones de creación para los Datos como se definen en los espacios de nombres apropiados. Ver más abajo para las funciones generales de <data/>, y en cada módulo de datos para esas funciones.
Para más información sobre el formato de array que se pasa a la llamada de retorno, lee la documentación de Net::Jabber::Client.

MÉTODOS

Funciones de recuperación

GetXMLNS() - devuelve una cadena con el espacio de nombres de los datos que
             contiene el <xdb/>.
             $xmlns  = $XDB->GetXMLNS();
GetData() - dado que el comportamiento de este módulo depende del
             espacio de nombres, un objeto Data puede contener objetos Data.
             Esto ayuda a aprovechar la reutilización de código haciendo
             que los hijos se comporten de la misma manera. Lo más probable
             es que esta función nunca se llame.
             @data = GetData()

Funciones de creación

SetXMLNS(string) - establece el xmlns del <data/> a la cadena.
                   $data->SetXMLNS("jabber:xdb:roster");

En un esfuerzo por facilitar el mantenimiento de este documento, no entraré en detalles completos sobre cada una de estas funciones. En su lugar, presentaré las funciones en una lista con un tipo en la primera columna para mostrar qué devuelven o qué toman como argumentos. Aquí está la lista de tipos que usaré:

string  - solo una cadena
array   - array de cadenas
flag    - esto significa que el hijo especificado existe en el
          XML <child/> y actúa como una bandera. get devolverá
          0 o 1.
JID     - ya sea una cadena o un objeto Net::Jabber::JID.
objects - crea nuevos objetos o devuelve un array de
          objetos.
special - esta es una función de caso especial. Normalmente,
          con solo llamar a Set() sin argumentos se establecerá
          el valor a un valor especial, como OS o tiempo.
          A veces modificará el valor que establezcas, como
          en jabber:xdb:version SetVersion(), la función
          añade la versión de Net::Jabber a la cadena
          solo con fines publicitarios. =)
