Net::SMTP(3perl) Guía de referencia del programador de Perl Net::SMTP(3perl)

NOMBRE

Net::SMTP - Cliente del protocolo Simple Mail Transfer Protocol

SINOPSIS

use Net::SMTP;
# Constructores
$smtp = Net::SMTP->new('mailhost');
$smtp = Net::SMTP->new('mailhost', Timeout => 60);

DESCRIPCIÓN

Este módulo implementa una interfaz de cliente para los protocolos SMTP y ESMTP, permitiendo que una aplicación perl5 hable con servidores SMTP. Esta documentación asume que usted está familiarizado con los conceptos del protocolo SMTP descritos en RFC2821. Con IO::Socket::SSL instalado, también proporciona soporte para cifrado TLS implícito y explícito, es decir, SMTPS o SMTP+STARTTLS.

La clase Net::SMTP es una subclase de Net::Cmd y (dependiendo de la disponibilidad) de IO::Socket::IP, IO::Socket::INET6 o IO::Socket::INET.

Métodos de clase

"new([$host][, %options])"
Este es el constructor para un nuevo objeto Net::SMTP. $host es el nombre del host remoto con el que se requiere una conexión SMTP.

En caso de fallo, se devolverá "undef" y $@ contendrá la razón del fallo.

$host es opcional. Si no se proporciona $host, se puede pasar como la opción "Host" descrita a continuación. Si no se proporciona ninguno de los dos, se utilizarán los "SMTP_Hosts" especificados en "Net::Config".

%options se pasan en forma de hash, utilizando pares de clave y valor. Las opciones posibles son:

Hello - SMTP requiere que te identifiques. Esta opción especifica una cadena para pasar como tu dominio de correo. Si no se proporciona, se utilizará localhost.localdomain.

SendHello - Si es falso, el comando EHLO (o HELO) que normalmente se envía al construir el objeto no se enviará. En ese caso, el comando deberá enviarse manualmente llamando a hello() en su lugar.

Host - Servidor SMTP al que conectarse. Puede ser un único escalar (nombre de host[:puerto]), como se define para la opción "PeerAddr" en IO::Socket::INET, o una referencia a una matriz con hosts para probar por turnos. El método "host" devolverá el valor que se utilizó para conectarse al host. Formato - "PeerHost" del método new de IO::Socket::INET.

Port - Puerto al que conectarse. Por defecto - 25 para SMTP normal y 465 para SSL inmediato.

SSL - Si la conexión debe realizarse desde el principio con SSL, en contraposición a la actualización posterior con "starttls". Puede utilizar argumentos SSL tal como se documenta en IO::Socket::SSL, pero normalmente ya utilizará los argumentos correctos.

LocalAddr y LocalPort - Estos parámetros se pasan directamente a IO::Socket para permitir enlazar el socket a una dirección y puerto local específicos.

Domain - Este parámetro se pasa directamente a IO::Socket y hace posible forzar conexiones IPv4 incluso si IO::Socket::IP se utiliza como superclase. Alternativamente se puede usar Family.

Timeout - Tiempo máximo, en segundos, para esperar una respuesta del servidor SMTP (por defecto: 120)

ExactAddresses - Si es verdadero, todos los argumentos $address deben ser tal como se definen en "addr-spec" en RFC2822. Si no se proporciona, o es falso, Net::SMTP intentará extraer la dirección del valor proporcionado.

Debug - Habilita información de depuración

Ejemplo:

$smtp = Net::SMTP->new('mailhost',
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                       Debug   => 1,
                      );
# lo mismo
$smtp = Net::SMTP->new(
                       Host => 'mailhost',
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                       Debug   => 1,
                      );
# lo mismo con SSL directo
$smtp = Net::SMTP->new('mailhost',
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                       Debug   => 1,
                       SSL     => 1,
                      );
# Conectar al servidor por defecto de Net::config
$smtp = Net::SMTP->new(
                       Hello => 'my.mail.domain',
                       Timeout => 30,
                      );

Métodos de objeto

Salvo que se indique lo contrario, todos los métodos devuelven un valor *verdadero* o *falso*, donde *verdadero* significa que la operación fue un éxito. Cuando un método indica que devuelve un valor, el fallo se devolverá como *undef* o una lista vacía.

"Net::SMTP" hereda de "Net::Cmd", por lo que los métodos definidos en "Net::Cmd" pueden utilizarse para enviar comandos al servidor SMTP remoto además de los métodos documentados aquí.

banner()
Devuelve el mensaje de saludo con el que respondió el servidor cuando se estableció la conexión inicial.
domain()
Devuelve el dominio con el que se identificó el servidor SMTP remoto durante la conexión.
hello($domain)
Informa al servidor remoto del dominio de correo en el que se encuentra utilizando el comando EHLO (o HELO si EHLO falla). Dado que este método se invoca automáticamente al construir el objeto Net::SMTP, el usuario normalmente no debería tener que llamarlo manualmente.
host()
Devuelve el valor utilizado por el constructor, y pasado a IO::Socket::INET, para conectarse al host.
etrn($domain)
Solicita la ejecución de la cola para el $domain proporcionado.
starttls(%sslargs)
Actualiza una conexión normal existente a SSL. Puede utilizar argumentos SSL tal como se documenta en IO::Socket::SSL, pero normalmente ya utilizará los argumentos correctos.
"auth($username, $password)"
auth($sasl)
Intenta la autenticación SASL. Requiere el módulo Authen::SASL. La primera forma construye un nuevo objeto Authen::SASL utilizando el nombre de usuario y la contraseña proporcionados; la segunda forma utiliza el objeto Authen::SASL proporcionado.
"mail($address[, %options])"
send($address)
send_or_mail($address)
send_and_mail($address)
Envía el comando apropiado al servidor MAIL, SEND, SOML o SAML. $address es la dirección del remitente. Esto inicia el envío de un mensaje. El método "recipient" debe ser llamado por cada dirección a la que se debe enviar el mensaje.

El método "mail" puede tomar algunas %options adicionales de ESMTP que se pasan en forma de hash, utilizando pares de clave y valor. Las opciones posibles son:

Size        => <bytes>
Return      => "FULL" | "HDRS"
Bits        => "7" | "8" | "binary"
Transaction => <ADDRESS>
Envelope    => <ENVID>     # codifica en xtext su argumento
ENVID       => <ENVID>     # similar a Envelope, pero espera que el argumento esté codificado
XVERP       => 1
AUTH        => <submitter> # dirección codificada según RFC 2554

Los parámetros "Return" y "Envelope" se utilizan para DSN (Notificación de estado de entrega).

La dirección del remitente en la opción "AUTH" se espera en un formato según lo requerido por RFC 2554, en una forma citada RFC2821 y codificada en xtext.

NAME

Net::SMTP - client interface to the Simple Mail Transfer Protocol

SYNOPSIS

    use Net::SMTP;
    # See EXAMPLES section for more detailed examples.

DESCRIPTION

Net::SMTP is a client class for the Simple Mail Transfer Protocol (SMTP), defined in RFC 5321. It is used for sending mail.

There are a number of methods in this class that are not intended to be called directly by the user. These methods are intended for use by subclasses or by Net::Cmd which Net::SMTP inherits from.

Constructor

new($host[, %args])

Creates a new Net::SMTP object and attempts to connect to the SMTP server specified by $host. $host can be a scalar value, or an array reference of host names. If it is an array reference, Net::SMTP will try each host in order until it successfully connects or runs out of hosts.

The following arguments are supported:

  • NOMBRE
  • SINTAXIS
  • DESCRIPCIÓN
  • Métodos de objeto
  • EJEMPLOS
  • EXPORTADOS
  • ERRORES CONOCIDAS
  • VER TAMBIÉN
  • AUTOR
  • DERECHOS DE AUTOR
  • LICENCIA
  • VERSIÓN
  • FECHA
  • HISTORIAL
