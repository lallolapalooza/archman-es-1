Net::SMTP::SSL(3) Documentación de Perl aportada por el usuario Net::SMTP::SSL(3)

NOMBRE

Net::SMTP::SSL - Soporte SSL para Net::SMTP

SINOPSIS

use Net::SMTP::SSL;

my $smtps = Net::SMTP::SSL->new("ejemplo.com", Port => 465);

DESCATALOGADO

¡Oye! ¡Lee esto!

Desde Net::SMTP v1.28 (2014-10-08), el propio Net::SMTP tiene soporte para SMTP sobre SSL, y también para STARTTLS. Usa Net::SMTP, no Net::SMTP::SSL.

DESCRIPCIÓN

Implementa la misma API que Net::SMTP, pero utiliza IO::Socket::SSL para sus operaciones de red. Debido a la naturaleza del método "new" de "Net::SMTP", no está sobreescrito para hacer uso de un puerto por defecto para el servicio SMTPS. Quizás las versiones futuras sean lo suficientemente inteligentes como para eso. El puerto 465 es usualmente lo que quieres, y no es una molestia especificarlo.

Para la documentación de la interfaz, por favor consulta Net::SMTP.

VER TAMBIÉN

Net::SMTP, IO::Socket::SSL, perl.
