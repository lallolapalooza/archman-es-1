Net::LDAP::Util(3) Páginas del manual de contribuciones de Perl Net::LDAP::Util(3)

NOMBRE

Net::LDAP::Util — Funciones de utilidad

SINTAXIS

use Net::LDAP::Util qw(ldap_error_text
                       ldap_error_name
                       ldap_error_desc
                      );
$mesg = $ldap->search( .... );
die "Error ",ldap_error_name($mesg)  if $mesg->code;

DESCRIPCIÓN

Net::LDAP::Util es una colección de funciones de utilidad para el uso con el módulo Net::LDAP.

FUNCIONES

ldap_error_name ( ERR )
Devuelve el nombre correspondiente con ERR. ERR puede ser un número de error LDAP, o un objeto "Net::LDAP::Message" que contiene un código de error. Si el error no es conocido, se devuelve una cadena en el formato "LDAP error" código %d(0x%02X)".
ldap_error_text ( ERR )
Devuelve el texto de descripción del error dado en el POD. ERR puede ser un código de error LDAP, o un objeto "Net::LDAP::Message" que contiene un código de error LDAP. Si el código de error dado es desconocido, se devuelve "undef".
ldap_error_desc ( ERR )
Devuelve una descripción corta del error. ERR puede ser un código de error LDAP o un objeto "Net::LDAP::Message" que contiene un código de error LDAP.
canonical_dn ( DN [ , OPTIONS ] )
Devuelve el DN dado en forma canónica. Devuelve undef si el DN no es válido. (Nota: La cadena vacía "" es un DN válido.) DN puede ser una cadena o una referencia a un array de hashes como se devuelve por ldap_explode_dn, útil al construir un DN.

Ejecuta las siguientes operaciones sobre el DN dado:

  • Quita los caracteres 'OID.' si el tipo es OID en lugar de un nombre.
  • Escapa todos los caracteres especiales RFC 4514 (",", "+", """, "\", "<", ">", ";", "#", "=", " "), guiones ("/"), y cualquier carácter donde el código ASCII es < 32 como \hexpair.
  • Convierte todos los espacios iniciales y finales en \20.
  • Si un RDN contiene múltiples partes, las partes se reordenan de manera que los nombres de tipo de atributo estén en orden alfabético.

LAS OPCIONES

casefold
Controla la conversión a minúsculas de los nombres de tipo de atributo. Los valores de atributo no se ven afectados por esta opción. El valor por defecto es mayúsculas. Valores válidos son:
lower
Convierte a minúsculas los nombres de tipo de atributo.
upper
Convierte a mayúsculas los nombres de tipo de atributo. Este es el valor por defecto.
none
No cambia los nombres de tipo de atributo.
mbcescape
Si es verdadero, los caracteres codificados como una secuencia multi-octet UTF-8 serán escapados como \(hexpair){2,*}.
reverse
Si es verdadero, la secuencia de RDN se invierte.
separator
Separador a usar entre las RDNs. El valor por defecto es la coma (',').
ldap_explode_dn ( DN [ , OPTIONS ] )
Expande el DN dado en un array de hashes y devuelve una referencia a este array. Devuelve undef si el DN no es un nombre de distinción válido.

Un nombre de distinción es una secuencia de nombres de distinción (RDN) que son conjuntos de atributos. Para cada RDN se crea un hash con los nombres de tipo de atributo como claves y los valores de atributos correspondientes. Estos hashes se almacenan en un array en el orden en que aparecen en el DN.

Por ejemplo, el DN 'OU=Sales+CN=J. Smith,DC=example,DC=net' se expone a:
[
{
'OU' => 'Sales',
'CN' => 'J. Smith'
},
{
'DC' => 'example'
},
{
'DC' => 'net'
}
]

(Ejemplo de cadena RFC4514) Los DN pueden contener valores, que son las bytes del BER de X.500 AttributeValue en lugar de algún tipo de sintaxis LDAP. Estos valores se codifican en hexadecimal y se prefijan con #. Para distinguir estos valores BER, ldap_explode_dn usa referencias a los valores reales, por ejemplo, '1.3.6.1.4.1.1466.0=#04024869,DC=example,DC=com' se expone a:
[
{
'1.3.6.1.4.1.1466.0' => "\004\002Hi"
},
{
'DC' => 'example'
},
{
'DC' => 'com'
}
]

También realiza las siguientes operaciones sobre el DN dado:

  • Desescapa "\" seguido de ",", "+", """, "\", "<", ">", ";", "#", "=", " " o un hexpair y cadenas que empiecen con "#".
  • Quita los caracteres 'OID.' si el tipo es OID en lugar de un nombre.

Convierte a mayúsculas los nombres de tipo de atributo. Este es el valor por defecto.

No cambia los nombres de tipo de atributo.

escape_filter_value ( VALUES )
Escapa los valores dados según RFC 4515 para que puedan usarse de forma segura en filtros LDAP.

Cualquier carácter con código ASCII < 32 o caracteres especiales en filtros LDAP como "*", "(", ")", y "\" se convierten en una representación de un backslash seguido de dos dígitos hexadecimales que representan el valor hexadecimal del carácter.

Devuelve la lista convertida en modo lista y el primer elemento en modo escalar.

unescape_filter_value ( VALUES )
Reconvierte la conversión realizada por escape_filter_value().

Convierte cualquier secuencia de backslash seguida de dos dígitos hexadecimales en el carácter correspondiente.

Devuelve la lista convertida en modo lista y el primer elemento en modo escalar.

escape_dn_value ( VALUES )
Escapa los valores dados según RFC 4514 para que puedan usarse de forma segura en DN LDAP.

Los caracteres ",", "+", """, "\", "<", ">", ";", "#", "=" con un significado especial en la sección 2.4 de RFC 4514 son precedidos por un backslash. Los caracteres con código ASCII < 32 se representan como \hexpair. Los caracteres con código ASCII < 32 se representan como \hexpair. Net::LDAP::Util(3pm) — Arch Linux

NAME

Net::LDAP::Util - LDAP utility functions

SYNOPSIS

 use Net::LDAP::Util qw(
  escape_dn_value
  unescape_dn_value
  ldap_url_parse
  generalizedTime_to_time
  time_to_generalizedTime
 );

DESCRIPTION

This module provides a set of utility functions that are useful when working with LDAP.

FUNCTIONS

escape_dn_value ( VALUES )
Converts a list of attribute values from a DN into the representation required for DNs.

This function is used to escape values that would otherwise be interpreted as special characters or hexpairs. The conversion is done by replacing special characters with a backslash-hexpair.

Leading and trailing spaces are preserved, but any internal spaces are converted to a hexpair sequence of \20.

Returns the converted list in list mode and the first element in scalar mode.

unescape_dn_value ( VALUES )
Undoes the conversion done by escape_dn_value().

Any escape sequence starting with a backslash - hexpair or special character - will be transformed back to the corresponding character.

Returns the converted list in list mode and the first element in scalar mode.

ldap_url_parse ( LDAP-URL [, OPTIONS ] )
Parse an LDAP-URL conforming to RFC 4516 into a hash containing its elements.

For easy cooperation with LDAP queries, the hash keys for the elements used in LDAP search operations are named after the parameters to "search" in Net::LDAP.

In extension to RFC 4516, the socket path for URLs with the scheme "ldapi" will be stored in the hash key named "path".

If any element is omitted, the result depends on the setting of the option "defaults".

OPTIONS is a list of key/value pairs with the following keys recognized:

defaults
A Boolean option that determines whether default values according to RFC 4516 shall be returned for missing URL elements.

If set to TRUE, default values are returned, with "ldap_url_parse" using the following defaults in extension to RFC 4516.

  • The default port for "ldaps" URLs is 636.
  • The default path for "ldapi" URLs is the contents of the environment variable "LDAPI_SOCK". If that is not defined or empty, then "/var/run/ldapi" is used.

    This is consistent with the behaviour of "new" in Net::LDAP.

  • The default "host" name for "ldap" and "ldaps" URLs is "localhost".

When set to FALSE, no default values are used.

This leaves all keys in the resulting hash undefined where the corresponding URL element is empty.

To distinguish between an empty base DN and an undefined base DN, "ldap_url_parse" uses the slash between the host:port resp. path part of the URL and the base DN part of the URL. With the slash present, the hash key "base" is set to the empty string, without it, it is left undefined.

Leaving away the "defaults" option entirely is equivalent to setting it to TRUE.

Returns the hash in list mode, or the reference to the hash in scalar mode.

generalizedTime_to_time ( GENERALIZEDTIME )
Convert the generalizedTime string GENERALIZEDTIME, which is expected to match the template "YYYYmmddHH[MM[SS]][(./,)d...](Z|(+/-)HH[MM])" to a floating point number compatible with UNIX time (i.e. the integral part of the number is a UNIX time).

Returns an extended UNIX time or "undef" on error.

Times in years smaller than 1000 will lead to "undef" being returned. This restriction is a direct effect of the year value interpretation rules in Time::Local.

Note: this function depends on Perl's implementation of time and Time::Local. See "Limits of time_t" in Time::Local, "Negative Epoch Values" in Time::Local, and "gmtime" in perlport for restrictions in older versions of Perl.

time_to_generalizedTime ( TIME [, OPTIONS ] )
Convert the UNIX time TIME to a generalizedTime string.

In extension to UNIX times, TIME may be a floating point number, the decimal part will be used for the resulting generalizedTime.

OPTIONS is a list of key/value pairs. The following keys are recognized:

AD
Take care of an ActiveDirectory peculiarity to always require decimals.

Returns the generalizedTime string, or "undef" on error.

Times before BC or after year 9999 result in "undef" as they cannot be represented in the generalizedTime format.

Note: this function depends on Perl's implementation of gmtime. See "Limits of time_t" in Time::Local, "Negative Epoch Values" in Time::Local, and "gmtime" in perlport for restrictions in older versions of Perl.
