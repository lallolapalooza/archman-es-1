NOMBRE

Net::DNS::Resolver::Recurse - Buscador recursivo de DNS

SINOPSIS

use Net::DNS::Resolver::Recurse;
my $resolver = new Net::DNS::Resolver::Recurse();
$resolver->hints('198.41.0.4'); # A.ROOT-SERVER.NET.
my $packet = $resolver->send( 'www.rob.com.au.', 'A' );

DESCRIPCIÓN

Este módulo resuelve consultas siguiendo la ruta de delegación desde la raíz del DNS.

MÉTODOS

Este módulo hereda casi todos los métodos de Net::DNS::Resolver. Los métodos adicionales específicos del módulo se describen a continuación.

hints

Este método especifica una lista de las direcciones IP de los servidores de nombres que se utilizarán para descubrir las direcciones de los servidores de nombres raíz.

$resolver->hints(@ip);

Si no se pasan pistas, la consulta de inicialización se dirige a servidores de nombres extraídos de una lista integrada de direcciones IP.

query, search, send

Los métodos query(), search() y send() producen el mismo resultado que sus homólogos en Net::DNS::Resolver.

$packet = $resolver->send( 'www.example.com.', 'A' );

La recursión del lado del servidor se suprime borrando la bandera de recursión en los paquetes de consulta y la resolución recursiva de nombres se realiza explícitamente.

Los métodos query() y search() se heredan de Net::DNS::Resolver e invocan send() indirectamente.

callback

Este método especifica una referencia de código a una subrutina, que luego se invoca en cada etapa de la búsqueda recursiva.

Por ejemplo, para emular la función "+trace" de dig:

my $coderef = sub {
my $packet = shift;
printf ";; Recibidos %d bytes de %s\n\n",
        $packet->answersize, $packet->answerfrom;
};
$resolver->callback($coderef);

La subrutina de callback no se llama para consultas de registros de pegamento que faltan.
