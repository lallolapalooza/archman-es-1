Net::DNS::SEC::Private(3) Documentación de Perl aportada por el usuario Net::DNS::SEC::Private(3)

NOMBRE

Net::DNS::SEC::Private - Objeto de clave privada DNSSEC

SINOPSIS

use Net::DNS::SEC::Private;
$private = Net::DNS::SEC::Private->new( $keypath );
$private = Net::DNS::SEC::Private->new(
    'algorithm'  => '13',
    'keytag'     => '26512',
    'privatekey' => 'h/mc+iq9VDUbNAjQgi8S8JzlEX29IALchwJmNM3QYKk=',
    'signame'    => 'example.com.'
    );

DESCRIPCIÓN

Clase que representa claves privadas leídas de un archivo de clave generado por BIND dnssec-keygen. La clase está escrita para ser utilizada únicamente en el contexto del método de creación de Net::DNS::RR::RRSIG. Esta clase no está diseñada para interactuar con ningún otro sistema.

MÉTODOS

new (desde archivo de clave privada)

$keypath = '/home/foo/Kexample.com.+013+26512.private';
$private = Net::DNS::SEC::Private->new( $keypath );

El argumento es la ruta completa a un archivo de clave privada generado por la herramienta BIND dnssec-keygen. Tenga en cuenta que el nombre del archivo contiene información sobre el algoritmo y la etiqueta de clave.

new (desde parámetros de clave privada)

$private = Net::DNS::SEC::Private->new(
    'algorithm'  => '13',
    'keytag'     => '26512',
    'privatekey' => 'h/mc+iq9VDUbNAjQgi8S8JzlEX29IALchwJmNM3QYKk=',
    'signame'    => 'example.com.'
    );

Los argumentos definen los parámetros de la clave privada como pares (nombre, valor). El nombre y la representación de los datos son idénticos a los utilizados en un archivo de clave privada de BIND.

formato_clave_privada

$format = $private->private_key_format;

Devuelve una cadena que identifica el formato del archivo de clave privada.

algoritmo, etiqueta_clave, nombre_firma

$algorithm = $private->algorithm;
$keytag    = $private->keytag;
$signame   = $private->signame;

Devuelve el atributo correspondiente determinado a partir del nombre del archivo.

Atributos de clave privada

$attribute = $private->attribute;

Devuelve el valor tal como aparece en el archivo de clave privada. Los nombres de los atributos corresponden a la etiqueta en el archivo de clave, modificados para formar un nombre de subrutina Perl aceptable.

creado, publicar, activar

$created  = $private->created;
$publish  = $private->publish;
$activate = $private->activate;

Devuelve una cadena que representa una fecha en el formato 20141212123456. Devuelve un valor indefinido para formatos de clave anteriores a v1.3.
