NOMBRE

Net::DNS::RR::NSEC3PARAM - registro de recursos NSEC3PARAM de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre NSEC3PARAM algoritmo flags iteraciones salt');

DESCRIPCIÓN

Clase para registros de recursos NSEC3PARAM de DNSSEC.

El registro RR NSEC3PARAM contiene los parámetros NSEC3 (algoritmo de hash, flags, iteraciones y salt) necesarios para calcular nombres de propietario hasheados.

La presencia de un registro RR NSEC3PARAM en el ápice de una zona indica que los parámetros especificados pueden ser utilizados por los servidores autorizados para elegir un conjunto apropiado de registros NSEC3 para respuestas negativas.

Los validadores o resolvedores no utilizan el registro RR NSEC3PARAM.

MÉTODOS

Los métodos disponibles son aquellos heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete ni el acceso directo a estructuras de datos internas, ya que podría provocar la terminación del programa u otros comportamientos impredecibles.

algoritmo

$algoritmo = $rr->algorithm;
$rr->algorithm( $algoritmo );

El campo de algoritmo de 8 bits se representa como un entero decimal sin signo.

flags

$flags = $rr->flags;
$rr->flags( $flags );

El campo Flags es un entero decimal sin signo interpretado como ocho valores booleanos concatenados.

iteraciones

$iteraciones = $rr->iterations;
$rr->iterations( $iteraciones );

El campo Iterations se representa como un entero decimal sin signo. El valor está entre 0 y 65535, ambos inclusive.

salt

$salt = $rr->salt;
$rr->salt( $salt );

El campo Salt se representa como una secuencia continua de dígitos hexadecimales. Se utiliza un guion ("-") (sin comillas) en el formato de cadena para indicar que el campo de salt está ausente.

saltbin

$saltbin = $rr->saltbin;
$rr->saltbin( $saltbin );

El campo Salt como una secuencia de octetos.
