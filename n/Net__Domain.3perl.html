NOMBRE

Net::Domain - Intenta evaluar el nombre de dominio de internet del host actual

SINOPSIS

use Net::Domain qw(hostname hostfqdn hostdomain domainname);

DESCRIPCIÓN

Utilizando varios métodos intenta encontrar el Nombre de Dominio Completamente Cualificado (FQDN) del host actual. A partir de esto, determina el nombre del host y el dominio del host.

Cada una de las funciones devolverá undef si el FQDN no puede ser determinado.

Funciones

hostfqdn()
Identifica y devuelve el FQDN del host actual.
domainname()
Un alias para hostfqdn().
hostname()
Devuelve la parte más pequeña del FQDN que se puede utilizar para identificar el host.
hostdomain()
Devuelve el resto del FQDN después de que se haya eliminado el hostname.
