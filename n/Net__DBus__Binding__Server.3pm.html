NOMBRE

Net::DBus::Binding::Server - Un servidor para aceptar conexiones entrantes

SINOPSIS

Creación de un nuevo servidor y aceptación de conexiones de cliente

use Net::DBus::Binding::Server;
my $server = Net::DBus::Binding::Server->new(address => "unix:path=/ruta/al/socket");
$server->connection_callback(\&nueva_conexion);
sub nueva_conexion {
    my $conexion = shift;
    .. trabajar con la nueva conexion...
}

Gestión del servidor y nuevas conexiones en un bucle de eventos

my $reactor = Net::DBus::Binding::Reactor->new();
$reactor->manage($server);
$reactor->run();
sub nueva_conexion {
    my $conexion = shift;
    $reactor->manage($conexion);
}

DESCRIPCIÓN

Un servidor para recibir conexiones de programas cliente. Los métodos definidos en este módulo tienen una estrecha correspondencia con los métodos dbus_server_XXX de la API C, por lo que para más detalles sobre su comportamiento, la documentación de la API C puede ser de utilidad.

MÉTODOS

my $server = Net::DBus::Binding::Server->new(address => "unix:path=/ruta/al/socket");
Crea un nuevo servidor enlazándolo al socket especificado por el parámetro "address".
$status = $server->is_connected();
Devuelve cero si el servidor se ha desconectado, de lo contrario se devuelve un valor positivo.
$server->disconnect()
Cierra este servidor al host remoto. Este método se llama automáticamente durante la recolección de basura (es decir, en el método DESTROY) si el programador olvida desconectar explícitamente.
$server->set_watch_callbacks(\&add_watch, \&remove_watch, \&toggle_watch);
Registra un conjunto de callbacks para añadir, eliminar y actualizar vigilancias en el bucle de eventos de la aplicación. Cada parámetro debe ser una referencia de código, que en cada invocación, recibirá dos parámetros, el objeto servidor y el objeto vigilancia. Si estás utilizando un objeto "Net::DBus::Binding::Reactor" como bucle de eventos de la aplicación, entonces el método 'manage' de ese objeto lo llamará en tu nombre.
$server->set_timeout_callbacks(\&add_timeout, \&remove_timeout, \&toggle_timeout);
Registra un conjunto de callbacks para añadir, eliminar y actualizar temporizadores en el bucle de eventos de la aplicación. Cada parámetro debe ser una referencia de código, que en cada invocación, recibirá dos parámetros, el objeto servidor y el objeto temporizador. Si estás utilizando un objeto "Net::DBus::Binding::Reactor" como bucle de eventos de la aplicación, entonces el método 'manage' de ese objeto lo llamará en tu nombre.
$server->set_connection_callback(\&handler)
Registra el manejador a usar para tratar las nuevas conexiones entrantes de los clientes. La referencia de código se invocará cada vez que se conecte un nuevo cliente y se le proporcionará un único parámetro que es el objeto "Net::DBus::Binding::Connection" que representa al cliente.
