NOMBRE

Net::DNS::SEC::Tools::realmmgr - Comunícate con el administrador de reinos de DNSSEC-Tools.

SINOPSIS

use Net::DNS::SEC::Tools::realmmgr;
$dir = realmmgr_dir();
$idfile = realmmgr_idfile();
$id = realmmgr_getid();
realmmgr_dropid();
realmmgr_rmid();
realmmgr_cmdint();
$runflag = realmmgr_running();
realmmgr_halt();
realmmgr_channel(1);
($cmd,$data) = realmmgr_getcmd();
$ret = realmmgr_verifycmd($cmd);
realmmgr_sendcmd(CHANNEL_CLOSE,REALMCMD_STARTREALM,"example-realm");
realmmgr_sendcmd(CHANNEL_WAIT,REALMCMD_STARTREALM,"example-realm");
($retcode, $respmsg) = realmmgr_getresp();

DESCRIPCIÓN

El módulo Net::DNS::SEC::Tools::realmmgr proporciona métodos estándar e independientes de la plataforma para que un programa se comunique con el administrador de reinos dtrealms de DNSSEC-Tools. Aquí se describen dos clases de interfaz: interfaces generales e interfaces de comunicación.

INTERFACES GENERALES

Las interfaces para el módulo Net::DNS::SEC::Tools::realmmgr se presentan a continuación.

realmmgr_dir()
Esta rutina devuelve el directorio de dtrealms.
realmmgr_idfile()
Esta rutina devuelve el archivo de identificación de dtrealms.
realmmgr_getid()
Esta rutina devuelve el ID de proceso de dtrealms. Si se pasa un valor no nulo como argumento, el archivo de identificación se dejará abierto y accesible a través del manejador de archivo PIDFILE. Consulte la sección ADVERTENCIAS más abajo.

Valores de retorno:

En caso de éxito, se devuelve la primera parte del contenido del archivo
    (hasta 80 caracteres).
Se devuelve -1 si el archivo de identificación no existe.
realmmgr_dropid()
Esta interfaz asegura que no se esté ejecutando otra instancia de dtrealms y luego crea un archivo de identificación para referencia futura.

Valores de retorno:

 1 - el archivo de identificación se creó correctamente para este proceso
 0 - otro proceso ya está actuando como dtrealms
-1 - no se pudo crear el archivo de identificación
realmmgr_rmid()
Esta interfaz elimina el archivo de identificación de dtrealms.

Valores de retorno:

 1 - el archivo de identificación se eliminó correctamente
 0 - no existe ningún archivo de identificación
-1 - el proceso que llama no es dtrealms
-2 - no se pudo eliminar el archivo de identificación
realmmgr_cmdint()
Esta rutina informa a dtrealms que se ha enviado un comando a través de realmmgr_sendcmd().

Valores de retorno:

-1 - se encontró un ID de proceso no válido para dtrealms
Cualquier otro valor indica el número de procesos que fueron
señalados.
(Esto solo debería ser 1).
realmmgr_running()
Esta rutina determina si dtrealms está en ejecución y devuelve un valor que indica el estado.

Valores de retorno:

 1 - dtrealms está en ejecución.
 0 - El proceso listado en el archivo de ID de proceso de
     dtrealms no está en ejecución.
-1 - No se pudo obtener el ID de proceso de dtrealms.
realmmgr_halt()
Esta rutina informa a dtrealms que se detenga.

En la implementación actual, se devuelve el código de retorno del comando kill().

-1 - se encontró un ID de proceso no válido para dtrealms
Cualquier otro valor indica el número de procesos que fueron
señalados.
(Esto solo debería ser 1).

INTERFACES DE COMUNICACIÓN DE DTREALMS

realmmgr_channel(serverflag)
Esta interfaz configura un canal persistente para la comunicación con dtrealms. Si serverflag es verdadero, se crea el lado del servidor del canal. Si serverflag es falso, se crea el lado del cliente del canal.

Actualmente, la conexión solo se puede establecer con localhost. Esto puede cambiarse para permitir conexiones remotas, si se encuentra necesario.

Valores de retorno:

 1 - Canal de comunicación establecido correctamente.
 0 - No se pudo conectar al servidor.
-1 - No se pudo crear un socket Unix.
-2 - No se pudo enlazar al socket Unix. (solo servidor)
-3 - No se pudieron cambiar los permisos del socket Unix. (solo servidor)
-4 - No se pudo escuchar en el socket Unix. (solo servidor)
-5 - El nombre del socket era más largo de lo permitido para un socket Unix.
realmmgr_queuecmd(cmdname, value)
Esta interfaz recuerda internamente un comando y su valor opcional para su procesamiento posterior. Consulte realmmgr_getcmd() a continuación para obtener más detalles.
realmmgr_getcmd()
realmmgr_getcmd() procesa comandos que deben ser gestionados. Si hay comandos almacenados internamente en cola a través de la función realmmgr_queuecmd(), se gestionan primero. Después de eso, recupera un comando enviado a través del canal de comunicación de dtrealms por un programa cliente. El comando y los datos del comando se envían en cada mensaje.

El comando y los datos del comando se devuelven al llamador.

realmmgr_sendcmd(closeflag,cmd,data)
realmmgr_sendcmd() envía un comando a dtrealms. El comando debe ser uno de los comandos de la tabla a continuación. Esta interfaz crea un canal de comunicación con dtrealms y envía el mensaje. El canal no se cierra, en caso de que el llamador desee recibir una respuesta de dtrealms.

Los comandos disponibles y sus datos requeridos son:

comando              datos           propósito
-------              ----            -------
REALMCMD_COMMAND     reino, comando  ejecutar comando en un reino
REALMCMD_DISPLAY     1/0             iniciar/detener la pantalla gráfica
                                     de dtrealms
REALMCMD_GETSTATUS   ninguno         actualmente no utilizado
REALMCMD_LOGFILE     nombre de archivo de registro   cambiar el archivo de registro
REALMCMD_LOGLEVEL    nivel de registro   establecer un nuevo nivel de registro
REALMCMD_LOGMSG      mensaje de registro   añadir un mensaje al registro
REALMCMD_LOGTZ       zona horaria    establecer la zona horaria para los
                                     mensajes de registro
REALMCMD_NODISPLAY   0               detener la pantalla gráfica de
                                     dtrealms
REALMCMD_REALMSTATUS ninguno         obtener el estado de los reinos
REALMCMD_SHUTDOWN    ninguno         detener dtrealms y sus reinos
REALMCMD_STARTALL    ninguno         iniciar todos los reinos detenidos
REALMCMD_STOPALL     ninguno         detener todos los reinos en ejecución
REALMCMD_STARTREALM  nombre de reino   reiniciar un reino suspendido
REALMCMD_STOPREALM   nombre de reino   detener un reino
REALMCMD_STATUS      ninguno         obtener el estado de dtrealms

Los datos no se verifican en busca de validez por realmmgr_sendcmd(); la verificación de validez es responsabilidad de dtrealms.

Si el llamador no necesita una respuesta de dtrealms, entonces closeflag debe establecerse en CHANNEL_CLOSE; si se requiere una respuesta, entonces closeflag debe ser CHANNEL_WAIT. Estos valores son booleanos, y las constantes no son necesarias.

En caso de éxito, se devuelve 1. Si se proporciona un comando no válido, se devuelve 0.

realmmgr_getresp()
Después de ejecutar un comando de cliente enviado a través de realmmgr_sendcmd(), dtrealms enviará una respuesta al cliente. realmmgr_getresp() permite al cliente recuperar la respuesta.

Se devuelven un código de retorno y una cadena de respuesta, en ese orden. Ambos son específicos del comando enviado.

realmmgr_verifycmd(cmd)
Esta interfaz es llamada por el servidor para verificar que un comando recibido de un cliente sea válido.

Valores de retorno:

1 si el comando es válido
0 si el comando no es válido

ADVERTENCIAS

La implementación actual de realmmgr_getid() deja abierto el archivo PIDFILE. Si bien esto puede ser útil para depurar, la práctica recomendada es cerrar el archivo de identificación de proceso una vez que se obtiene el PID.

La comunicación con el administrador de reinos se realiza a través de un socket Unix. Si el administrador de reinos se detiene de forma abrupta, el socket puede no ser eliminado. En este caso, el módulo intentará eliminar el socket al inicio.

Los comandos enviados a través de realmmgr_sendcmd() se envían sin ninguna verificación de validez. La validación de los comandos es responsabilidad del administrador de reinos.

DTREALMS COMMUNICATIONS INTERFACES

realmmgr_verifycmd()
verifica que cmd es un comando válido para dtrealms. Se devuelve 1 para un comando válido; se devuelve 0 para un comando inválido.

Se devuelve 1 para un comando válido; se devuelve 0 para un comando inválido.

ADVERTENCIAS

1. realmmgr_getid() intenta bloquear exclusivamente el archivo de id. Establezca un temporizador si esto le importa.

2. realmmgr_getid() tiene una pequeña condición de carrera. Deberíamos bloquear el archivo antes de abrirlo, pero no podemos hacerlo sin que esté abierto.
