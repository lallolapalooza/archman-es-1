Net::DNS::RR::OPT(3) Documentación Perl Contribuida por el Usuario Net::DNS::RR::OPT(3)

NOMBRE

Net::DNS::RR::OPT - registro de recurso DNS OPT

SINOPSIS

use Net::DNS;
my $packet = Net::DNS::Packet->new( ... );
$packet->header->do(1);         # bandera de cabecera extendida 
$packet->edns->UDPsize(1232);   # tamaño de carga útil UDP
$packet->edns->option( 'NSID' => {'OPTION-DATA' => 'rawbytes'} );
$packet->edns->option( 'DAU'  => [8, 10, 13, 14, 15, 16] );
$packet->edns->option( 'TCP-KEEPALIVE' => 200 );
$packet->edns->option( 'EXTENDED-ERROR' => {'INFO-CODE' => 123} );
$packet->edns->option( '65023' => {'BASE16' => '076578616d706c6500'} );
$packet->edns->print;
;; {    "EDNS-VERSION": 0,
;;      "FLAGS":        32768,
;;      "RCODE":        0,
;;      "UDPSIZE":      1232,
;;      "OPTIONS":      [
;;              {"NSID": "7261776279746573"},
;;              {"DAU": [ 8, 10, 13, 14, 15, 16 ]},
;;              {"TCP-KEEPALIVE": {"TIMEOUT": 200}},
;;              {"EXTENDED-ERROR": {"INFO-CODE": 123, "EXTRA-TEXT": ""}},
;;              {"65023": {"BASE16": "076578616d706c6500"}} ]
;;      }

DESCRIPCIÓN

Registro de recurso pseudo EDNS OPT. (OPT Record)

El registro OPT soporta las extensiones del protocolo EDNS y no está pensado para ser creado, accedido o modificado directamente por aplicaciones de usuario.

Todas las funcionalidades EDNS se realizan indirectamente mediante operaciones sobre los objetos devueltos por los métodos creadores $packet->header y $packet->edns. Los mecanismos subyacentes están, o deberían estar, completamente ocultos al usuario.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otro comportamiento impredecible.

version

$version = $packet->edns->version;

La versión de EDNS soportada por este registro OPT.

UDPsize

$size = $packet->edns->UDPsize;
$packet->edns->UDPsize($size);

UDPsize() anuncia el tamaño máximo (en octetos) del paquete UDP que puede ser reensamblado en la pila de red del host de origen.

rcode

$extended_rcode = $packet->header->rcode;

Los 12 bits del RCODE extendido. Los 8 bits más significativos se obtienen del registro OPT. Los 4 bits menos significativos residen en la cabecera del paquete.

flags

$do = $packet->header->do;
$packet->header->do(1);
$edns_flags = $packet->edns->flags;

Campo de 16 bits que contiene las banderas extendidas de cabecera EDNS.

options

my @options = $packet->edns->options;

Cuando se llama en contexto de lista, options() devuelve una lista de códigos de opción encontrados en el registro OPT.

option

my $octets = $packet->edns->option('COOKIE');
my $base16 = unpack 'H*', $octets;

Cuando se llama en contexto de escalar con un único argumento, option() devuelve el valor de la opción especificada como una cadena de octetos no interpretada. El método devuelve undef si la opción está ausente.

$packet->edns->option( 'COOKIE' => {'OPTION-DATA' => $octets} );
$packet->edns->option( '10'     => {'BASE16' => $base16} );

Una opción puede ser añadida o reemplazada proporcionando el par (nombre, valor). La opción se elimina si el valor es indefinido.

my ($structure) = $packet->edns->option("DAU");
my $array       = $$structure{"DAU"};
my @algorithms  = @$array;
my ($structure) = $packet->edns->option(15);
my $table       = $$structure{"EXTENDED-ERROR"};
my $info_code   = $$table{'INFO-CODE'};
my $extra_text  = $$table{'EXTRA-TEXT'};

Cuando se llama en contexto de lista con un único argumento, option() devuelve una representación estructurada de la opción especificada.

Se pueden usar formas similares de sintaxis de array o hash para construir el valor de la opción:

$packet->edns->option( 'DAU' => [8, 10, 13, 14, 15, 16] );
$packet->edns->option( 'EXTENDED-ERROR' => {
                                'INFO-CODE'  => 123,
                                'EXTRA-TEXT' => ""
                                } );
