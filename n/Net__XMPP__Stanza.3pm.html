NOMBRE

Net::XMPP::Stanza - Módulo de Stanza XMPP

SINTAXIS

Net::XMPP::Stanza es un paquete privado que sirve como base para todas las stanzas XMPP generadas por Net::XMPP.

DESCRIPCIÓN

Este módulo no se debe usar directamente. Debes estar usando ya sea Net::XMPP::IQ, Net::XMPP::Message, Net::XMPP::Presence, o algún otro paquete que herede de Net::XMPP::Stanza.

Dicho esto, es aquí donde se documentan todas las funciones de los espacios de nombres (namespaces).

Los espacios de nombres actualmente soportados son:

jabber:iq:auth
jabber:iq:privacy
jabber:iq:register
jabber:iq:roster
urn:ietf:params:xml:ns:xmpp-bind
urn:ietf:params:xml:ns:xmpp-session

Para más información sobre qué son estos espacios de nombres, visita http://www.jabber.org y navega por la Guía del Programador de Jabber.

Las siguientes tablas se pueden leer así:

ny:private:ns
Nombre                        Tipo     Get  Set  Eliminar  Definido  Agregar
==========================  ========  ===  ===  ======  =======  ===
Foo                         escalar   X    X     X        X
Bar                         hijo                                X
Bars                        hijo     X
Test                        master    X    X

Dentro del espacio de nombres my:private:ns, hay las siguientes funciones:

GetFoo(), SetFoo(), RemoveFoo(), DefinedFoo()
AddBar()
GetBars(), DefinedBars()
GetTest(), SetMaster()

Espero que sea obvio cómo funciona todo esto. Si no, pide ayuda y trabajaré en añadir más documentación.
