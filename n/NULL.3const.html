NULL(3const) NULL(3const)

NOMBRE

NULL - constante de puntero nulo

BIBLIOTECA

Biblioteca estándar de C (libc)

SINOPSIS

#include <stddef.h>
#define NULL  ((void *) 0)

DESCRIPCIÓN

NULL representa una constante de puntero nulo, es decir, un puntero que no apunta a nada.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIA

C89, POSIX.1-2001.

NOTAS

Las siguientes cabeceras también proporcionan NULL: <locale.h>, <stdio.h>, <stdlib.h>, <string.h>, <time.h>, <unistd.h> y <wchar.h>.

ADVERTENCIAS

Es un comportamiento indefinido desreferenciar un puntero nulo, y esto normalmente causa un fallo de segmentación en la práctica.

También es un comportamiento indefinido realizar aritmética de punteros sobre él.

NULL - NULL es un comportamiento indefinido, según ISO C, pero se define como 0 en C++.

Para evitar confundir a los lectores humanos del código, no compares variables de puntero con 0, ni les asignes 0. En su lugar, usa siempre NULL.

NULL no debe confundirse con NUL, que es un carácter ascii(7), representado en C como '\0'.

ERRORES

Cuando es necesario establecer una variable de puntero a un puntero nulo, no es suficiente usar memset(3) para poner a cero el puntero (esto se hace normalmente al poner a cero una estructura que contiene punteros), ya que ISO C y POSIX no garantizan que un patrón de bits de ceros represente un puntero nulo. Consulta la sección EXAMPLES en getaddrinfo(3) para ver un programa de ejemplo que hace esto correctamente.

VéASE TAMBIÉN
