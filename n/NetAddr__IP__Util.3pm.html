INSTALACIÓN

Descomprime la distribución en un directorio apropiado y escribe:

perl Makefile.PL
make
make test
make install

NetAddr::IP::Util se instala por defecto con sus funciones principales compiladas usando extensiones XS de Perl para construir una biblioteca 'C'. Si no tienes un compilador 'C' disponible o prefieres la versión Pure Perl, más lenta, por cualquier otro motivo, escribe:

perl Makefile.PL -noxs
make
make test
make install

DESCRIPCIÓN

NetAddr::IP::Util proporciona un conjunto de herramientas para manipular y convertir direcciones IPv4 e IPv6 en un contexto de cadena de 128 bits y de vuelta a texto. Las cadenas pueden manipularse con los operadores lógicos de Perl:

and     &
or      |
xor     ^
        ~       complemento

de la misma manera que las cadenas 'vec'.

Las funciones IPv6 admiten todos los formatos rfc1884.

es decir, x:x:x:x:x:x:x:x:x
      x:x:x:x:x:x:x:d.d.d.d
      ::x:x:x
      ::x:d.d.d.d
y así sucesivamente...
  • $dotquad = inet_ntoa($netaddr);

    Convierte una dirección de red IPv4 empaquetada a una dirección IP punto-cuádruple.

    entrada:        dirección de red empaquetada
retorna:      dirección IP, es decir, 10.4.12.123
  • $netaddr = inet_aton($dotquad);

    Convierte una dirección IP punto-cuádruple en una dirección de red IPv4 empaquetada.

    entrada:        dirección IP, es decir, 192.5.16.32
retorna:      dirección de red empaquetada
  • $ipv6addr = ipv6_aton($ipv6_text);

    Toma una dirección IPv6 del formato descrito en rfc1884 y devuelve una cadena binaria RDATA de 128 bits.

    entrada:        texto IPv6
retorna:      cadena RDATA de 128 bits
  • $ipv6_text = ipv6_ntoa($ipv6naddr);

    Convierte una dirección IPv6 binaria de 128 bits a una representación de texto comprimida rfc 1884.

    entrada:        cadena RDATA de 128 bits
retorna:      texto IPv6
  • $hex_text = ipv6_n2x($ipv6addr);

    Toma una cadena RDATA IPv6 y devuelve una dirección IPv6 hexadecimal de 8 segmentos.

    entrada:        cadena RDATA de 128 bits
retorna:      x:x:x:x:x:x:x:x
  • $dec_text = ipv6_n2d($ipv6addr);

    Toma una cadena RDATA IPv6 y devuelve una dirección IPv6 mixta hexadecimal-decimal con los 6 fragmentos superiores en hexadecimal y los 32 bits inferiores en representación punto-cuádruple.

    entrada:        cadena RDATA de 128 bits
retorna:      x:x:x:x:x:x:d.d.d.d
  • $ipv6naddr = inet_any2n($dotquad o $ipv6_text);

    Esta función convierte una dirección IPv4 o IPv6 de texto en cualquier notación estándar a una dirección de cadena IPv6 de 128 bits. Antepone cualquier dirección punto-cuádruple (si se encuentra) con '::' y la pasa a ipv6_aton.

    entrada:        punto-cuádruple o dirección rfc1844
retorna:      cadena IPv6 de 128 bits
  • $rv = hasbits($bits128);

    Esta función devuelve verdadero si hay bits '1' presentes en la cadena de 128 bits y falso si todos los bits son cero.

    es decir,  if (hasbits($bits128)) {
        &do_something;
      }
o    if (hasbits($bits128 & $mask128) {
        &do_something;
      }

    Esto permite la implementación de funciones lógicas del tipo:

          if ($bits128 & $mask128) {
          ...
entrada:        cadena IPv6 de 128 bits
retorna:      verdadero si hay bits presentes
  • $ipv6naddr = inet_4map6($netaddr o $ipv6naddr

    Esta función devuelve una dirección de red IPv6 con los primeros 80 bits establecidos en cero y los siguientes 16 bits establecidos en uno, mientras que los últimos 32 bits se rellenan con la dirección IPv4.

    entrada:        dirección de red IPv4
          o  dirección de red IPv6
retorna:      dirección de red IPv6
retorna: undef en caso de error

    Una dirección de red IPv6 debe estar en uno de los dos espacios de direcciones mapeadas IPv4 compatibles. es decir,

    ::ffff::d.d.d.d    o    ::d.d.d.d
  • $rv = isIPv4($bits128);

    Esta función devuelve verdadero si no hay bits activos presentes en la porción IPv6 de la cadena de 128 bits y falso en caso contrario.

    es decir, la dirección debe tener la forma - ::d.d.d.d

    Nota: Esta es una dirección IPv6 compatible con IPv4 antigua y obsoleta.

  • $rv = isNewIPv4($bits128);

    Esta función devuelve verdadero si la cadena de 128 bits IPv6 tiene la forma

    ::ffff::d.d.d.d
  • $rv = isAnyIPv4($bits128);

    Esta función devuelve verdadero si la cadena de bits IPv6 tiene la forma

    ::d.d.d.d       o      ::ffff::d.d.d.d
  • $dotquad o $hex_text = inet_n2dx($ipv6naddr);

    Esta función hace lo correcto y devuelve el texto de una dirección IPv4 punto-cuádruple o una dirección IPv6 en notación hexadecimal.

    entrada:        cadena IPv6 de 128 bits
retorna:      ddd.ddd.ddd.ddd
          o  x:x:x:x:x:x:x:x
  • $dotquad o $dec_text = inet_n2ad($ipv6naddr);

    Esta función hace lo correcto y devuelve el texto de una dirección IPv4 punto-cuádruple o una dirección IPv6 en notación hexadecimal::decimal.

    entrada:        cadena IPv6 de 128 bits
retorna:      ddd.ddd.ddd.ddd
          o  x:x:x:x:x:x:ddd.ddd.ddd.dd
  • $netaddr = inet_pton($AF_family,$hex_text);

    Esta función toma una dirección IP en formato de texto IPv4 o IPv6 y la convierte a formato binario. El tipo de conversión de la dirección IP se controla mediante el argumento FAMILY.

  • $hex_text = inet_ntop($AF_family,$netaddr);

    Esta función toma una dirección IP en formato binario y

  • $ipv6naddr = ipv4to6($netaddr);

    Convierte una dirección IPv4 a un formato de cadena IPv6 que es compatible con IPv4.

    input:        IPv4 network address
returns:      IPv6 network address
  • $ipv6naddr = mask4to6($netaddr);

    Convierte una máscara IPv4 a su equivalente IPv6.

    input:        IPv4 mask address
returns:      IPv6 mask address
  • $ipv6naddr = ipanyto6($addr);

    Convierte una dirección IPv4 o IPv6 a un formato de cadena IPv6.

    input:        IPv4 or IPv6 text address
returns:      IPv6 network address
  • $ipv6naddr = maskanyto6($mask);

    Convierte una máscara IPv4 o IPv6 a su equivalente IPv6.

    input:        IPv4 or IPv6 mask address
returns:      IPv6 mask address
  • $netaddr = ipv6to4($ipv6naddr);

    Convierte una dirección IPv6 compatible con IPv4 a una dirección IPv4.

    input:        IPv6 network address
returns:      IPv4 network address
  • $bitsX2 = shiftleft($bits128,$n);

    Desplaza los bits hacia la izquierda n posiciones.

    input:        128 bit string
              number of bits to shift
returns:      128 bit string
  • $carry = addconst($ipv6naddr,$signed_32con);

    Suma una constante con signo de 32 bits a la dirección IPv6.

    input:        128 bit string
              signed 32 bit constant
returns:      carry bit
  • ($carry,$ipv6naddr)=addconst($ipv6naddr,$signed_32con);

    Suma una constante con signo de 32 bits a la dirección IPv6.

    input:        128 bit string
              signed 32 bit constant
returns:      ($carry,$new_128_bit_string)
  • $carry = add128($ipv6naddr1,$ipv6naddr2);

    Suma dos direcciones de 128 bits.

    input:        128 bit string
              128 bit string
returns:      carry bit
  • ($carry,$ipv6naddr)=add128($ipv6naddr1,$ipv6naddr2);

    Suma dos direcciones de 128 bits.

    input:        128 bit string
              128 bit string
returns:      ($carry,$sum_128_bit_string)
  • $carry = sub128($ipv6naddr1,$ipv6naddr2);

    Resta la segunda dirección de 128 bits de la primera.

    input:        128 bit string
              128 bit string
returns:      carry bit
  • ($carry,$ipv6naddr)=sub128($ipv6naddr1,$ipv6naddr2);

    Resta la segunda dirección de 128 bits de la primera.

    input:        128 bit string
              128 bit string
returns:      ($borrow,$difference_128_bit_string)
  • ($spurious,$cidr) = notcontiguous($mask128);

    Detecta si una máscara de red es contigua.

    input:        128 bit mask string
returns:      ($spurious,$cidr_mask)
        $spurious is true if the mask is not contiguous
        $cidr_mask is the contiguous mask
  • $bcdtext = bin2bcd($bits128);

    Convierte una cadena binaria de 128 bits a formato BCD.

    input:        128 bit string
returns:      BCD text string
  • $bits128 = bcd2bin($bcdtxt);

    Convierte una cadena BCD a formato binario de 128 bits.

    input:        BCD text string
returns:      128 bit string
  • $modetext = mode;

    Devuelve el modo de operación (XS o Pure Perl).

  • ($name,$aliases,$addrtype,$length,@addrs)=naip_gethostbyname(NAME);

    Esta es una versión modificada de gethostbyname para manejar direcciones IP de forma más robusta.

    input:        hostname or IP address text
returns:      list of results from gethostbyname
  • $trueif = havegethostbyname2();

    Devuelve verdadero si la función gethostbyname2 está disponible (para manejar la familia de direcciones).

  • NetAddr::IP::Util::lower();

    Convierte la cadena de modo actual a minúsculas.

  • NetAddr::IP::Util::upper();

    Convierte la cadena de modo actual a mayúsculas.

convertir en formato de texto. El tipo de conversión de direcciones IP está controlado por el argumento FAMILY.

NOTA: inet_ntop SIEMPRE devuelve caracteres en minúsculas.

  • $hex_text = packzeros($hex_text);

    Esta función optimiza y reduce la dirección hexadecimal IPv6 rfc 1884 para disminuir el número de cadenas largas de bits cero según se especifica en rfc 1884, 2.2 (2) sustituyendo :: por la primera aparición de la cadena más larga de ceros en la dirección.

  • $ipv6naddr = ipv4to6($netaddr);

    Convierte una dirección de red ipv4 en una dirección de red IPv6.

    entrada: dirección de red de 32 bits
retorno: dirección de red de 128 bits
  • $ipv6naddr = mask4to6($netaddr);

    Convierte una dirección/máscara de red ipv4 en una máscara de red ipv6.

    entrada: dirección/máscara de red de 32 bits
retorno: máscara de red de 128 bits

    NOTA: devuelve los 96 bits superiores como unos.

  • $ipv6naddr = ipanyto6($netaddr);

    Similar a ipv4to6, excepto que esta función toma una entrada IPv4 o IPv6 y siempre devuelve una dirección de red IPv6 de 128 bits.

    entrada: dirección de red de 32 o 128 bits
retorno: dirección de red de 128 bits
  • $ipv6naddr = maskanyto6($netaddr);

    Similar a mask4to6, excepto que esta función toma una máscara de red IPv4 o IPv6 y siempre devuelve una máscara de red IPv6 de 128 bits.

    entrada: máscara de red de 32 o 128 bits
retorno: máscara de red de 128 bits
  • $netaddr = ipv6to4($pv6naddr);

    Trunca los 96 bits superiores de una dirección de 128 bits y devuelve los 32 bits inferiores. Devuelve una dirección IPv4 tal como la devuelve inet_aton.

    entrada: dirección de red de 128 bits
retorno: dirección de red de 32 bits (formato inet_aton)
  • $bitsXn = shiftleft($bits128,$n); 
    entrada: variable de cadena de 128 bits,
              número de desplazamientos [opcional]
retorno: bits con X n desplazamientos
NOTA: se realiza un único desplazamiento
      si no se especifica $n
  • addconst($ipv6naddr,$signed_32con);

    Suma una constante con signo a una variable de cadena de 128 bits.

    entrada: cadena IPv6 de 128 bits,
              entero de 32 bits con signo
retorno: escalar      acarreo
          array       (acarreo, resultado)
  • add128($ipv6naddr1,$ipv6naddr2);

    Suma dos variables de cadena de 128 bits.

    entrada: variable de cadena de 128 bits 1,
              variable de cadena de 128 bits 2
retorno: escalar      acarreo
          array       (acarreo, resultado)
  • sub128($ipv6naddr1,$ipv6naddr2);

    Resta dos variables de cadena de 128 bits.

    entrada: variable de cadena de 128 bits 1,
              variable de cadena de 128 bits 2
retorno: escalar      acarreo
          array       (acarreo, resultado)

    Nota: El acarreo de esta operación es el resultado de sumar el complemento a uno de ARG2 +1 a ARG1. Lógicamente, **NO** es un préstamo.

    es decir, si ARG1 >= ARG2 entonces acarreo = 1
o      si ARG1 < ARG2 entonces acarreo = 0
  • ($spurious,$cidr) = notcontiguous($mask128);

    Esta función cuenta las posiciones de bits restantes en la máscara cuando se eliminan los '0' más a la derecha.

    entrada: máscara de red de 128 bits
retorno verdadero si hay bits cero espurios restantes en la
            máscara, falso si la máscara son unos contiguos,
        número cidr de 128 bits
  • $bcdtext = bin2bcd($bits128);

    Convierte una cadena binaria de 128 bits a dígitos de texto decimal codificado en binario.

    entrada: variable de cadena de 128 bits
retorno: cadena de dígitos de texto bcd
  • $bits128 = bcd2bin($bcdtxt);

    Convierte una cadena de texto bcd a una variable de cadena de 128 bits.

    entrada: cadena de dígitos de texto bcd
retorno: variable de cadena de 128 bits
  • $modetext = mode;

    Devuelve el modo de operación de este módulo.

    entrada: ninguno
retorno: "Pure Perl"
           o   "CC XS"
  • ($name,$aliases,$addrtype,$length,@addrs)=naip_gethostbyname(NAME);

    Reemplazo para gethostbyname de Perl si Socket6 está disponible.

    En contexto de ARRAY, devuelve una lista de cinco elementos: el nombre de host o NAME, una lista separada por espacios de C_NAMES, la familia AF, la longitud de la estructura de dirección y una matriz de una o más direcciones de red.

    En contexto de ESCALAR, devuelve la primera dirección de red.

    Esta función SIEMPRE devuelve una dirección IPv6, incluso en sistemas solo IPv4. Las direcciones IPv4 se mapean al espacio IPv6 en la forma:

    ::FFFF:FFFF:d.d.d.d

    Este NO es el resultado esperado de gethostbyname2 de Perl. En su lugar, es equivalente a:

    En un sistema solo IPv4:
  $ipv6naddr = ipv4to6 scalar ( gethostbyname( name ));
En un sistema con Socket6 y un gethostbyname2 que funcione:
  $ipv6naddr = gethostbyname2( name, AF_INET6 );
y si eso falla, la conversión IPv4 anterior.

    Para un emulador de gethostbyname2 que se comporte como Socket6, consulta: Net::DNS::Dig

  • $trueif = havegethostbyname2();

    Esta función devuelve TRUE si Socket6 tiene un gethostbyname2 funcional; de lo contrario, devuelve FALSE. Consulte los comentarios anteriores sobre el comportamiento de naip_gethostbyname.

  • NetAddr::IP::Util::lower();

    Devuelve cadenas IPv6 en minúsculas.

  • NetAddr::IP::Util::upper();

    Devuelve cadenas IPv6 en mayúsculas. Este es el valor predeterminado.

    # convertir cualquier dirección IP textual en un vector de 128 bits
#
sub text2vec {
  my($anyIP,$anyMask) = @_;
# máscara de bits no IPv4
  my $notiv4 = ipv6_aton('FFFF:FFFF:FFFF:FFFF:FFFF:FFFF::');
  my $vecip   = inet_any2n($anyIP);
  my $mask    = inet_any2n($anyMask);
# extender bits de máscara para IPv4
  my $bits = 128;     # predeterminado
  unless (hasbits($mask & $notiv4)) {
    $mask |= $notiv4;
    $bits = 32;
  }
  return ($vecip, $mask, $bits);
}

# devolver direcciones de red y broadcast a partir de IP y máscara
#
sub netbroad {
  my($nip) = shift;
  my $notmask = ~ $nip->{mask};
  my $bcast   = $nip->{addr} | $notmask;
  my $network = $nip->{addr} & $nip->{mask};
  return ($network, $broadcast);
}
# comprobar si una dirección está dentro de una red
#
sub within {
  my($nip,$net) = @_;
  my $addr = $nip->{addr}
  my($nw,$bc) = netbroad($net);
# arg1 >= arg2, sub128 devuelve verdadero
  return (sub128($addr,$nw) && sub128($bc,$addr))
      ? 1 : 0;
}

# suma una constante, envolviendo en los límites del bloque de red
# para restar la constante, niega antes de llamar
# 'addwrap' ya que 'addconst' extenderá los bits de signo
#
sub addwrap {
  my($nip,$const) = @_;
  my $addr    = $nip->{addr};
  my $mask    = $nip->{mask};
  my $bits    = $nip->{bits};
  my $notmask = ~ $mask;
  my $hibits  = $addr & $mask;
  $addr = addconst($addr,$const);
  my $wraponly = $addr & $notmask;
  my $newip = {
      addr    => $hibits | $wraponly,
      mask    => $mask,
      bits    => $bits,
  };
  # bless $newip según corresponda
  return $newip;
}
