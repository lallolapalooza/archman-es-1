NOMBRE

Net::DNS::RR::SRV - registro de recurso SRV de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre SRV prioridad peso puerto destino');

DESCRIPCIÓN

Clase para registros de recursos de Servicio (SRV) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, y podría provocar la terminación del programa u otro comportamiento impredecible.

prioridad

$prioridad = $rr->prioridad;
$rr->prioridad( $prioridad );

Devuelve la prioridad para este host de destino.

peso

$peso = $rr->peso;
$rr->peso( $peso );

Devuelve el peso para este host de destino.

puerto

$puerto = $rr->puerto;
$rr->puerto( $puerto );

Devuelve el número de puerto para el servicio en este host de destino.

destino

$destino = $rr->destino;
$rr->destino( $destino );

Devuelve el nombre de dominio del host de destino.

Clasificación de registros SRV

Por defecto, rrsort() devuelve los registros SRV ordenados de menor a mayor prioridad y, para prioridades iguales, de mayor a menor peso.

Nota: Este NO es el orden en el que se deben intentar las conexiones.
