Net::LDAP::Search(3) Documentación de Perl aportada por el usuario Net::LDAP::Search(3)

NOMBRE

Net::LDAP::Search - Objeto devuelto por el método de búsqueda de Net::LDAP

SINOPSIS

use Net::LDAP;
$mesg = $ldap->search( @search_args );
@entries = $mesg->entries;

DESCRIPCIÓN

Un objeto Net::LDAP::Search es devuelto por el método de búsqueda de un objeto Net::LDAP. Es un objeto contenedor que almacena los resultados de la búsqueda.

MÉTODOS

Net::LDAP::Search hereda de Net::LDAP::Message, por lo que soporta todos los métodos definidos en Net::LDAP::Message.

as_struct ( )
Devuelve una referencia a un HASH, donde las claves son los DN de los resultados y los valores son referencias a HASH. Estos HASHes de segundo nivel contienen los atributos de tal manera que las claves son los nombres de los atributos, en minúsculas, y los valores son referencias a un ARRAY que contiene los valores.

Este método se bloqueará hasta que la solicitud de búsqueda completa haya finalizado.

count ( )
Devuelve el número de entradas devueltas por el servidor.

Este método se bloqueará hasta que la solicitud de búsqueda completa haya finalizado.

entry ( ÍNDICE )
Devuelve la N-ésima entrada (basada en cero), que será un objeto Net::LDAP::Entry. Si ÍNDICE es mayor o igual que el número total de entradas devueltas, se devolverá "undef".

Este método se bloqueará hasta que la solicitud de búsqueda haya devuelto suficientes entradas.

entries ( )
Devuelve un array de objetos Net::LDAP::Entry que fueron devueltos por el servidor.

Este método se bloqueará hasta que la solicitud de búsqueda completa haya finalizado.

pop_entry ( )
Saca una entrada de la lista interna de objetos Net::LDAP::Entry para esta búsqueda. Si no quedan más entradas, se devolverá "undef".

Esta llamada se bloqueará si la lista está vacía, hasta que el servidor devuelva otra entrada.

references ( )
Devuelve una lista de referencias que el servidor devolvió. Será una lista de objetos Net::LDAP::Reference.
sorted ( )
Devuelve una lista de objetos Net::LDAP::Entry, ordenados por sus DN.

La ordenación se realiza en el lado del cliente utilizando el operador de ordenación alfanumérica de Perl "cmp".

sorted ( ATTR, ... )
Devuelve una lista de objetos Net::LDAP::Entry, ordenados por los atributos especificados. Los atributos se comparan en el orden especificado, comparándose cada uno solo si todos los atributos anteriores son iguales.

La ordenación se realiza en el lado del cliente utilizando el operador de ordenación alfanumérica de Perl "cmp".

shift_entry ( )
Desplaza una entrada de la lista interna de objetos Net::LDAP::Entry para esta búsqueda. Si no quedan más entradas, se devolverá "undef".

Esta llamada se bloqueará si la lista está vacía, hasta que el servidor devuelva otra entrada.

VER TAMBIÉN

Net::LDAP, Net::LDAP::Message, Net::LDAP::Entry, Net::LDAP::Reference
