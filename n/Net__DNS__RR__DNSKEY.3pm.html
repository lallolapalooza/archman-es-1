Paquete: perl-net-dns

Licencias: PerlArtistic

Net::DNS::RR::DNSKEY(3) Documentación de Perl contribuida por el usuario Net::DNS::RR::DNSKEY(3)

NOMBRE

Net::DNS::RR::DNSKEY - registro de recurso DNSKEY de DNSSEC

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre DNSKEY flags protocolo algoritmo publickey');

DESCRIPCIÓN

Clase para registros de recursos de Clave DNSSEC (DNSKEY).

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete ni el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otro comportamiento impredecible.

flags

$flags = $rr->flags;
$rr->flags( $flags );

Número de 16 bits sin signo que representa banderas booleanas.

zone
$rr->zone(1);
if ( $rr->zone ) {
        ...
}

Bandera booleana ZONE.

revoke
$rr->revoke(1);
if ( $rr->revoke ) {
        ...
}

Bandera booleana REVOKE.

sep
$rr->sep(1);
if ( $rr->sep ) {
        ...
}

Bandera booleana Secure Entry Point (SEP).

protocol

$protocol = $rr->protocol;
$rr->protocol( $protocol );

El número de protocolo de 8 bits. Este campo DEBE tener el valor 3.

algorithm

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

El número de algoritmo de 8 bits describe el algoritmo de clave pública.

algorithm() también puede invocarse como un método de clase o una función simple para realizar la traducción de mnemónicos y códigos numéricos.

publickey

key

$key = $rr->key;
$rr->key( $key );

Representación Base64 del material de la clave pública.

keybin

$keybin = $rr->keybin;
$rr->keybin( $keybin );

Cadena de octetos opaca que representa el material de la clave pública.

privatekeyname

$privatekeyname = $rr->privatekeyname;

Devuelve el nombre de la clave privada tal como lo generaría el programa BIND dnssec-keygen. El formato de ese nombre es:

K<fqdn>+<algoritmo>+<keyid>.private

signame

$signame = $rr->signame;

Devuelve el nombre canónico del firmante de la clave privada.

keylength

Devuelve la longitud (en bits) del módulo calculado a partir del texto de la clave.

keytag

print "etiqueta_clave = ", $rr->keytag, "\n";

Devuelve la etiqueta de clave numérica de 16 bits de la clave. (RFC2535 4.1.6)
