NOMBRE

Net::DNS::SEC::Tools::keyrec - Operaciones de archivos keyrec de DNSSEC-Tools

SINOPSIS

use Net::DNS::SEC::Tools::keyrec;
keyrec_creat("localzone.keyrec");
keyrec_open("localzone.keyrec");  (DEPRECATED)
$okfile = keyrec_filestat("localzone.keyrec");
keyrec_read("localzone.keyrec");
@krnames = keyrec_names();
$krec = keyrec_fullrec("example.com");
%keyhash = %$krec;
$zname = $keyhash{"algorithm"};
$val = keyrec_recval("example.com","zonefile");
$exists = keyrec_exists("example.com");
keyrec_add("zone","example.com",\%zone_krfields);
keyrec_add("key","Kexample.com.+005+12345",\%keydata);
keyrec_del("example.com");
keyrec_setval("zone","example.com","zonefile","db.example.com");
keyrec_delval("example.com","kskrev");
@kskpaths = keyrec_keypaths("example.com","kskcur");
$obsflag = keyrec_revoke_check("Kexample.com.+005+12345");
$setname = keyrec_signset_newname("example.com");
keyrec_signset_new($zone,"example-set-21","zskcur");
keyrec_signset_addkey("example-keys","Kexample.com+005+12345",
                                       "Kexample.com+005+54321");
keyrec_signset_addkey("example-keys",@keylist);
keyrec_signset_delkey("example-keys","Kexample.com+005+12345");
$flag = keyrec_signset_haskey("example-keys","Kexample.com+005+12345");
keyrec_signset_clear("example-keys","Kexample.com+005+12345");
@signset = keyrec_signsets();
$sset_prefix = keyrec_signset_prefix("example.com");
keyrec_settime("zone","example.com");
keyrec_settime("set","signing-set-42");
keyrec_settime("key","Kexample.com.+005+76543");
@keyfields = keyrec_keyfields();
@zonefields = keyrec_zonefields();
keyrec_write();
keyrec_saveas("filecopy.krf);
keyrec_close();
keyrec_discard();
$current_krf = keyrec_curkrf();
$default_krf = keyrec_defkrf();

DESCRIPCIÓN

El módulo Net::DNS::SEC::Tools::keyrec manipula el contenido de un archivo keyrec de DNSSEC-Tools. Los archivos keyrec contienen datos sobre dominios firmados y claves generadas por los programas de DNSSEC-Tools. Las interfaces existen para consultar registros keyrec, crear nuevos registros y modificar los existentes.

Un archivo keyrec está organizado en conjuntos de registros keyrec. Cada registro keyrec debe ser de tipo key o zone. Los registros keyrec describen cómo se generaron las claves, mientras que los registros zonekeyrec describen cómo se firmaron los dominios. Un registro keyrec consiste en una serie de entradas clave/valor. El siguiente es un ejemplo de un registro keyrec:

key     "Kexample.com.+005+30485"
      zonename        "example.com"
      keyrec_type     "kskcur"
      algorithm       "rsasha1"
      random          "/dev/urandom"
      ksklength       "2048"
      ksklife         "15768000"
      revperiod       "3888000"
      revtime         "1103277532"
      keyrec_gensecs  "1101183727"
      keyrec_gendate  "Tue Nov 23 04:22:07 2004"

El primer paso para usar este módulo debe ser crear un nuevo archivo keyrec o abrir y leer un archivo existente. La interfaz keyrec_creat() crea un archivo keyrec si no existe. La interfaz keyrec_read() abre y lee el archivo, luego lo parsea en un formato interno. Los registros del archivo se copian en una tabla de hashes (para referencia fácil y rápida por las rutinas de Net::DNS::SEC::Tools::keyrec) y en un array (para preservar el formato y los comentarios). La interfaz keyrec_filestat() puede usarse para verificar que el archivo dado sea un archivo keyrec, aunque no verifica el contenido del archivo.

Después de leer el archivo, los contenidos se refieren mediante keyrec_fullrec() y keyrec_recval(). Los contenidos de keyrec se modifican mediante keyrec_add() y keyrec_setval(). La interfaz keyrec_settime() actualiza la marca de tiempo de un registro keyrec en el momento actual. Los registros keyrec pueden eliminarse con la interfaz keyrec_del().

Si el archivo keyrec ha sido modificado, debe ser guardado explícitamente o los cambios no se guardarán. La interfaz keyrec_write() guarda los nuevos contenidos en disco. La interfaz keyrec_saveas() guarda los contenidos en memoria de keyrec en el nombre especificado, sin afectar el archivo original.

La interfaz keyrec_close() guarda el archivo y cierra el handle Perl del archivo keyrec. Si el archivo keyrec no es más necesario abrir, pero los contenidos no deben ser guardados, keyrec_discard() elimina los datos y cierra el handle sin guardar cambios.

INTERFACES DE KEYREC

Las interfaces del módulo Net::DNS::SEC::Tools::keyrec se dan a continuación.

keyrec_add(keyrec_type,keyrec_name,fields)
Esta rutina agrega un nuevo registro keyrec a un archivo keyrec y representa los contenidos internos del archivo. El registro keyrec se agrega tanto a la tabla de hashes %keyrecs como al array @keyreclines.

keyrec_type especifica el tipo del registro keyrec — "key" o "zone". keyrec_name es el nombre del registro keyrec. fields es un referencia a una tabla de pares clave-valor que contiene los campos clave/valor del registro keyrec. Las claves de la tabla son siempre convertidas a minúsculas, pero los valores son dejados como están.

El campo ksklength solo se añade si el valor del campo keyrec_type es "kskcur".

El campo zsklength solo se añade si el valor del campo keyrec_type es "zsk", "zskcur", "zskpub" o "zsknew".

Los campos de marca de tiempo se añaden al final del registro keyrec. Para registros keyrec, los campos keyrec_gensecs y keyrec_gendate se añaden. Para registros zonekeyrec, los campos keyrec_signsecs y keyrec_signdate se añaden.

Si un campo especificado no está definido para el tipo de registro keyrec, el campo no se añade. Esto evita que los datos de registro zonekeyrec se mezclen con los datos de registro keyrec.

Se añade una línea en blanco después de la última línea del nuevo registro keyrec. Después de añadir todos los registros keyrec nuevos, el archivo keyrec se escribe pero no se cierra.

Los valores devueltos son:

0 éxito
-1 valor inválido para krtype
keyrec_close()
Esta interfaz guarda la versión interna del archivo keyrec (abierto con keyrec_read()) y cierra el handle de archivo.
keyrec_creat(keyrec_file)
Esta interfaz crea un archivo keyrec si no existe y trunca el archivo si ya existe.

keyrec_creat() devuelve 1 si el archivo se creó correctamente. Devuelve 0 si hubo un error al crear el archivo.

keyrec_curkrf()
Esta rutina devuelve el nombre del archivo keyrec que está en uso actual. Este valor es el nombre pasado a keyrec_read() o keyrec_creat(); no garantiza que sea un nombre absoluto o relativo.
keyrec_defkrf()
Esta rutina devuelve el nombre por defecto del archivo keyrec desde el archivo de configuración de DNSSEC-Tools.
keyrec_del(keyrec_name)
Esta rutina elimina un registro keyrec de un archivo keyrec y la representación interna de los contenidos del archivo. El registro keyrec se elimina de ambos la tabla de hashes %keyrecs y el array @keyreclines.

El registro keyrec se elimina de la tabla de hashes %keyrecs y del array @keyreclines si se especifica el nombre del registro.

keyrec_discard()
Esta interfaz elimina los datos del archivo keyrec y cierra el handle, sin guardar los cambios realizados.
keyrec_defkrf()
Esta rutina devuelve el nombre por defecto del archivo keyrec desde el archivo de configuración de DNSSEC-Tools.
keyrec_delval(keyrec_name,field)
Esta rutina elimina un campo de un registro keyrec.
keyrec_read()
Esta interfaz abre y lee el archivo keyrec, luego lo parsea en un formato interno.
keyrec_setval(keyrec_type,zone_name,field,valor)
Esta rutina establece un valor en un registro keyrec.
keyrec_settime(keyrec_type,zone_name)
Esta rutina actualiza el campo de marca de tiempo de un registro keyrec a la hora actual.
keyrec_signset_addkey(keyrec_type,keydata)
Esta rutina agrega una clave a un conjunto de claves de firma.
keyrec_signset_clear(keyrec_type,keydata)
Esta rutina elimina una clave de un conjunto de claves de firma.
keyrec_signset_haskey(keyrec_type,keydata)
Esta rutina verifica si una clave está en un conjunto de claves de firma.
keyrec_signset_new($zone,$setname,$keytype)
Esta rutina crea un nuevo conjunto de claves de firma.
keyrec_signset_newname($zone,$setname)
Esta rutina genera un nuevo nombre de conjunto de claves de firma.
keyrec_signset_prefix($zone)
Esta rutina devuelve el prefijo de un conjunto de claves de firma.
keyrec_signset_addkey($keylist,$key1,$key2)
Esta rutina agrega claves a un conjunto de claves de firma.
keyrec_signset_delkey($keylist,$key1)
Esta rutina elimina una clave de un conjunto de claves de firma.
keyrec_signset_haskey($keylist,$key1)
Esta rutina verifica si una clave está en un conjunto de claves de firma.
keyrec_signset_clear($keylist,$key1)
Esta rutina elimina una clave de un conjunto de claves de firma.

KEYREC MANIPULATION INTERFACES

keyrec_del(krtype, keyrec_name)
This routine deletes the specified keyrec. The keyrec is deleted from both the %keyrecs hash table and the @keyreclines array.

Only the keyrec itself is deleted from the file. Any associated comments and blank lines surrounding it are left intact.

Return values are:

 0 successful keyrec deletion
-1 invalid krtype (empty string or unknown name)
keyrec_delval(keyrec_name, field)
Esta rutina elimina el campo del keyrec con el nombre keyrec_name. El keyrec se elimina tanto de la tabla hash %keyrecs como del array @keyreclines.

Los valores de retorno son:

-1 keyrec_name no es el nombre de un keyrec existente
 0 campo no encontrado en keyrec
 1 campo eliminado de keyrec
keyrec_discard()
Esta rutina elimina un archivo keyrec del uso por parte de un programa. Los datos almacenados internamente se eliminan y se cierra el manejador del archivo keyrec. Sin embargo, los datos modificados no se guardan antes de cerrar el manejador del archivo. Por lo tanto, los datos modificados y nuevos se perderán.
keyrec_exists(keyrec_name)
keyrec_exists() devuelve un booleano que indica si existe un keyrec con el keyrec_name especificado.
keyrec_filestat(keyrec_name)
keyrec_filestat() comprueba que un archivo dado pueda ser un candidato razonable para un archivo keyrec de DNSSEC-Tools. Las comprobaciones a realizar se pueden obtener de la lista de valores de retorno.

Valores de retorno:
0 - devuelto si todas las pruebas tienen éxito
1 - no se proporcionó un nombre real
2 - el archivo no existe
3 - el archivo no es un archivo regular
4 - el archivo no es legible
5 - el archivo está vacío

keyrec_fullrec(keyrec_name)
keyrec_fullrec() devuelve una referencia al keyrec especificado en keyrec_name.
keyrec_keyfields()
Esta rutina devuelve una lista de los campos reconocidos para un keyrec de clave.
keyrec_keypaths(zonename,keytype)
keyrec_keypaths() devuelve una lista de rutas a un conjunto de archivos de clave para una zona dada. La zona se especifica en zonename y el tipo de clave se proporciona en keytype.

keytype debe ser uno de los siguientes: "kskcur", "kskpub", "kskrev", "kskobs"", "zskcur", "zskpub", "zsknew", "zskobs", "ksk", "zsk", o "all". La mayúscula/minúscula no importa para el keytype.

Si keytype es una de las etiquetas especiales ("ksk", "zsk", o "all") entonces se devolverá un conjunto de rutas de clave. Un keytype de "ksk" devolverá las rutas a todas las claves KSK de la zona, un keytype de "zsk" devolverá las rutas a todas las claves ZSK de la zona, y un keytype de "all" devolverá las rutas a todas las claves de la zona.

Si el tipo de clave dado no está definido en el keyrec de zona de la zona dada o si el tipo de clave no se reconoce, se devuelve un conjunto nulo.

keyrec_names()
Esta rutina devuelve una lista de los nombres de keyrec del archivo.
keyrec_open(keyrec_file) OBSOLETO
Esta rutina solía abrir un archivo keyrec de DNSSEC-Tools existente. Sin embargo, esto era una operación innecesaria ya que keyrec_read() abría el archivo si no estaba ya abierto.

Esta llamada eventualmente será eliminada. Por ahora, llama a keyrec_filestat() para comprobar la validez del archivo keyrec especificado.

Valores de retorno:

1 si el archivo pasa todas las pruebas de keyrec_filestat()
0 si el archivo falla alguna de las pruebas de keyrec_filestat()

Para compatibilidad retroactiva, el significado de éxito/fracaso de los valores de retorno coincide con el significado de éxito/fracaso de los retornos originales de keyrec_open().

keyrec_read(keyrec_file)
Esta interfaz lee el archivo keyrec especificado y lo analiza en una tabla hash keyrec y un array de contenidos del archivo. keyrec_read() debe ser llamado antes que cualquier otra llamada de Net::DNS::SEC::Tools::keyrec. Si otro keyrec ya está abierto, entonces se guarda y se cierra antes de abrir el nuevo keyrec.

Tras el éxito, keyrec_read() devuelve el número de keyrecs leídos del archivo.

Valores de retorno de error:

-1 el archivo keyrec especificado no existe
-2 no se pudo abrir el archivo keyrec
-3 nombres de keyrec duplicados en el archivo
keyrec_recval(keyrec_name,keyrec_field)
Esta rutina devuelve el valor de un campo especificado en un keyrec dado. keyrec_name es el nombre del keyrec particular a consultar. keyrec_field es el nombre del campo dentro de ese keyrec.

Por ejemplo, el archivo keyrec actual contiene el siguiente keyrec:

zone        "example.com"
            zonefile        "db.example.com"

La llamada:

keyrec_recval("example.com","zonefile")

devolverá el valor "db.example.com".

keyrec_revoke_check(key)
Esta interfaz comprueba el keyrec de una clave KSK revocada para determinar si está dentro o fuera de su período de revocación. La clave debe ser una clave de tipo "kskrev", y debe tener los campos "revtime" y "revperiod" definidos en el keyrec.

La determinación se realiza restando el tiempo de revocación del tiempo actual. Si esto es mayor que el período de revocación, entonces la clave ha excedido el tiempo en el que debe ser revocada. Si no, entonces debe permanecer revocada.

Valores de retorno:

 1 la clave especificada está fuera del período de revocación y debe ser
   marcada como obsoleta
 0 la clave especificada está dentro del período de revocación y debe dejarse
   revocada
-1 error (tipo de clave inválido, datos de keyrec faltantes)
keyrec_saveas(keyrec_file_copy)
Esta interfaz guarda la versión interna del archivo keyrec (abierto con o keyrec_read()) en el archivo nombrado en el parámetro keyrec_file_copy. El manejador del archivo del nuevo archivo se cierra, pero el archivo original y el manejador del archivo para el archivo original no se ven afectados.
keyrec_setval(keyrec_type,keyrec_name,field,value)
Establece el valor de un par nombre/campo en un keyrec especificado. El archivo no se escribe después de actualizar el valor. El valor se guarda tanto en %keyrecs como en @keyreclines, y se establece la bandera de archivo modificado.

keyrec_type especifica el tipo del keyrec. Esto solo se usa si se está creando un nuevo keyrec con esta llamada. keyrec_name es el nombre del keyrec que se modificará. field es el campo del keyrec que se modificará. value es el nuevo valor para el campo.

Los valores de retorno son:

0 si la creación tuvo éxito
-1 se proporcionó un tipo inválido
keyrec_settime(keyrec_type,keyrec_name)
Establece la marca de tiempo de un keyrec especificado. El archivo no se escribe después de actualizar el valor. El valor se guarda tanto en %keyrecs como en @keyreclines, y se establece la bandera de archivo modificado. Los campos keyrec_signdate y keyrec_signsecs del keyrec se modifican.
keyrec_write()
Esta interfaz guarda la versión interna del archivo keyrec (abierto con o keyrec_read()). No cierra el manejador del archivo. Como medida de eficiencia, se comprueba una bandera de modificación interna antes de escribir el archivo. Si el programa no ha modificado el contenido del archivo keyrec, no se reescribe.

keyrec_write() obtiene un bloqueo exclusivo en el archivo keyrec mientras escribe.

keyrec_zonefields()
Esta rutina devuelve una lista de los campos reconocidos para un keyrec de zona.

INTERFACES DE CONJUNTO DE FIRMAS KEYREC

Los conjuntos de firmas son colecciones de claves de cifrado, definidas por su inclusión en un "conjunto" particular de keyrec. Los nombres de las claves están en el registro keys del keyrec, que contiene los nombres de los keyrec de clave. Debido a la forma en que se manejan los nombres de clave, los nombres en un conjunto de firmas no deben contener espacios.

KEYREC SIGNING-SET INTERFACES

The interfaces described in this section are used to manage signing sets. A signing set is a collection of keys that are used together to sign zone data.

keyrec_signset_next(zone_name)
keyrec_signset_next() returns the name of the next signing set for the zone specified by zone_name. The name is formed by finding the lastset field in the keyrec for zone zone_name, if the keyrec has such a field. The set index number (described below) will be incremented and the lastset with the new index number will be returned as the new signing set name. If the zone keyrec does not have a lastset field, then the default set name of signing-set-0 will be used.

The set index number is the first number found in the lastset field. It doesn't matter where in the field it is found, the first number will be considered to be the signing set index. The examples below show how this is determined:

lastset field               index
-------------               -----
signing-set-0                  0
signing-0-set                  0
1-signing-0-set                1
signing-88-set-1              88
signingset4321              4321
keyrec_signset_new(zone,signing_set_name,set_type)
keyrec_signset_new() creates the signing set named by signing_set_name for the zone zone. It is given the type type, which must be one of the following: "kskcur", "kskpub", "kskrev", "kskobs", "zskcur", "zskpub", "zsknew", or "zskobs".

It returns 1 if the call is successful; 0 if it is not.

keyrec_signset_prefix(zone_name)
keyrec_signset_prefix() returns the signing set prefix formed by concatenating the zone name and $DEFSETPREFIX. This prefix should be followed by a numeric index.
keyrec_signset_addkey(signing_set_name,key_list)
keyrec_signset_addkey() adds the keys listed in key_list to the signing set named by signing_set_name. key_list may either be an array or a set or arguments to the routine. The keyrec is created if it does not already exist. It returns 1 if the call is successful; 0 if it is not.
keyrec_signset_delkey(signing_set_name,key_name)
keyrec_signset_delkey() deletes the key given in key_name to the signing set named by signing_set_name. It returns 1 if the call is successful; 0 if it is not.
keyrec_signset_haskey(signing_set_name,key_name)
keyrec_signset_haskey() returns a flag indicating if the key specified in key_name is one of the keys in the signing set named by signing_set_name. It returns 1 if the signing set has the key; 0 if it does not.
keyrec_signset_clear(keyrec_name)
keyrec_signset_clear() clears the entire signing set from the keyrec named by keyrec_name. It returns 1 if the call is successful; 0 if it is not.
keyrec_signsets()
keyrec_signsets() returns the names of the signing sets in the keyrec file. These names are returned in an array.
keyrec_signset_keys(keyrec_name,signset_type)
keyrec_signset_keys() returns the names of the keys that are members of a given signing set in the keyrec file. The keys are returned in a space-separated string.

There are two ways of calling keyrec_signset_keys(). The first method specifies a zone keyrec name and a signing set type. The signing set name is found by referencing the set field in the zone keyrec, then the keys field of that signing set is returned.

The second method specifies the signing set directly, and its keys field is returned.

Valid signing set types are:

kskcur        kskpub        kskrev        kskobs
zskcur        zskpub        zsknew        zskobs

The following errors are recognized, resulting in an undefined return:

keyrec_name is not a defined keyrec
signset_type is an invalid signing set type
the signing set keyrec is not a set keyrec

KEYREC INTERNAL INTERFACES

The interfaces described in this section are intended for internal use by the keyrec.pm module. However, there are situations where external entities may have need of them. Use with caution, as misuse may result in damaged or lost keyrec files.

keyrec_init()
This routine initializes the internal keyrec data. Pending changes will be lost. An open keyrec file handle will remain open, though the data are no longer held internally. A new keyrec file must be read in order to use the keyrec.pm interfaces again.
keyrec_newkeyrec(kr_name,kr_type)
This interface creates a new keyrec. The keyrec_name and keyrec_hash fields in the keyrec are set to the values of the kr_name and kr_type parameters. kr_type must be either "key" or "zone".

Return values are:

0 if the creation succeeded
-1 if an invalid I<keyrec> type was given

KEYREC DEBUGGING INTERFACES

The following interfaces display information about the currently parsed keyrec file. They are intended to be used for debugging and testing, but may be useful at other times.

keyrec_dump_hash()
This routine prints the keyrec file as it is stored internally in a hash table. The keyrecs are printed in alphabetical order, with the fields alphabetized for each keyrec. New keyrecs and keyrec fields are alphabetized along with current keyrecs and fields. Comments from the keyrec file are not included with the hash table.
keyrec_dump_array()
This routine prints the keyrec file as it is stored internally in an array. The keyrecs are printed in the order given in the file, with the fields ordered in the same manner. New keyrecs are appended to the end of the array. keyrec fields added to existing keyrecs are added at the beginning of the keyrec entry. Comments and vertical whitespace are preserved as given in the keyrec file.
