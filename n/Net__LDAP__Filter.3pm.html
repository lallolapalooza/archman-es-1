Net::LDAP::Filter(3) Documentación de Perl contribuida por el usuario Net::LDAP::Filter(3)

NOMBRE

Net::LDAP::Filter - representación de filtros LDAP

SINOPSIS

use Net::LDAP::Filter;
$filtro = Net::LDAP::Filter->new( $str_filtro );

DESCRIPCIÓN

El objeto Net::LDAP::Filter te permite manipular directamente los filtros LDAP sin preocuparte por la representación de la cadena y todos los mecanismos de escape asociados.

CONSTRUCTOR

new ( [ FILTRO ] )
Crea un nuevo objeto. Si se proporciona FILTRO, lo analiza.

MÉTODOS

parse ( FILTRO )
Analiza FILTRO, actualizando el objeto para representarlo.
as_string
Devuelve el filtro en formato de texto.
print ( [ FH ] )
Imprime la representación textual del filtro en FH, o en el manejador de salida actualmente seleccionado si FH no se proporciona.
negate ( )
Niega/invierte lógicamente el objeto filtro para que coincida con el conjunto opuesto de entradas que el original.

En lugar de simplemente negar la forma textual rodeándola con el operador not, la negación se realiza aplicando recursivamente la ley de De Morgan.

Aquí hay un ejemplo:

(|(&(cn=A)(cn=B))(|(!(cn=C))(cn=D)))

se niega a

(&(|(!(cn=A))(!(cn=B)))(&(cn=C)(!(cn=D))))

SINTAXIS DEL FILTRO

A continuación se muestra la sintaxis de un filtro dado en RFC 4515 http://www.ietf.org/rfc/rfc4515.txt

filter       = "(" filtercomp ")"
filtercomp   = and / or / not / item
and          = "&" filterlist
or           = "|" filterlist
not          = "!" filter
filterlist   = 1*filter
item         = simple / present / substring / extensible
simple       = attr filtertype value
filtertype   = equal / approx / greater / less
equal        = "="
approx       = "~="
greater      = ">="
less         = "<="
extensible   = attr [":dn"] [":" matchingrule] ":=" value
               / [":dn"] ":" matchingrule ":=" value
present      = attr "=*"
substring    = attr "=" [initial] any [final]
initial      = value
any          = "*" *(value "*")
final        = value
attr         = AttributeDescription from Section 4.1.4 of RFC 4511
matchingrule = MatchingRuleId from Section 4.1.8 of RFC 4511
value        = AttributeValue from Section 4.1.5 of RFC 4511
Special Character encodings
---------------------------
   *               \2a, \*
   (               \28, \(
   )               \29, \)
   \               \5c, \\
   NUL             \00
