NOMBRE

Net::DNS::RR::AMTRELAY - Registro de recurso DNS AMTRELAY

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('owner AMTRELAY precedence Dbit relaytype relay');

DESCRIPCIÓN

Registro de recurso AMTRELAY diseñado para permitir el Descubrimiento AMT de IP Inversa DNS (DRIAD), un mecanismo para que las puertas de enlace AMT descubran relés AMT capaces de reenviar tráfico multicast desde una dirección IP de origen conocida.

AMT (Automatic Multicast Tunneling) se define en la RFC7450 y proporciona un método para transportar tráfico multicast a través de un túnel unicast para atravesar segmentos de red que no son capaces de multicast.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otros comportamientos impredecibles.

precedence

$precedencia = $rr->precedence;
$rr->precedence( $precedencia );

Entero de 8 bits que indica la precedencia relativa dentro del conjunto de registros (RRset). Los relés listados en registros AMTRELAY con menor precedencia deben ser intentados primero.

Dbit, Discovery Optional

$Dbit = $rr->Dbit;
$rr->Dbit(1);

Campo booleano que indica que la puerta de enlace PUEDE enviar un mensaje de Solicitud AMT directamente a la dirección del relé descubierto sin enviar primero un mensaje de Descubrimiento AMT.

relaytype

$tiporelevador = $rr->relaytype;

El campo tipo de relé indica el formato de la información que se almacena en el campo relé.

Los siguientes valores están definidos:

0: El campo relé está vacío (0 bytes).

1: El campo relé contiene una dirección IPv4 de 4 octetos.

2: El campo relé contiene una dirección IPv6 de 16 octetos.

3: El campo relé contiene un nombre de dominio codificado en forma de bytes.

relay

$relevador = $rr->relay;
$rr->relay( $relevador );

El campo relé es la dirección o nombre de dominio del relé AMT. Se formatea según el campo tipo de relé.
