Net::LDAP::Control::VLVResponse(3) Documentación de Perl contribuida por el usuario Net::LDAP::Control::VLVResponse(3)

NOMBRE

Net::LDAP::Control::VLVResponse -- Respuesta del servidor de Vista de Lista Virtual (VLV) de LDAPv3

SINOPSIS

Ver Net::LDAP::Control::VLV

DESCRIPCIÓN

"Net::LDAP::Control::VLVResponse" es una subclase de Net::LDAP::Control. Proporciona una clase para manipular el control de Respuesta de Vista de Lista Virtual (VLV) de LDAP ""

Si el servidor soporta Vistas de Lista Virtual, la respuesta de una operación de búsqueda incluirá un control VLVResponse.

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control, se proporcionan los siguientes.

content
Una estimación del número de entradas en la lista completa. Este valor debería usarse en cualquier control de Vista de Lista Virtual posterior que utilice la misma lista.
context
Un valor arbitrario que se utiliza para asociar solicitudes posteriores con la solicitud de la cual este control es una respuesta. Este valor debe ser copiado por el cliente en el control de Vista de Lista Virtual para cualquier búsqueda posterior que utilice la misma lista.
result
Un código de resultado que indica el resultado de la solicitud de Vista de Lista Virtual. Puede ser cualquiera de los códigos listados a continuación.
target
El desplazamiento de la lista de la entrada objetivo.

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto que devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.

CÓDIGOS DE RESULTADO

Los posibles resultados de una solicitud de ordenación se enumeran a continuación. Ver Net::LDAP::Constant para una definición de cada uno.

LDAP_SUCCESS
LDAP_OPERATIONS_ERROR
LDAP_TIMELIMIT_EXCEEDED
LDAP_ADMIN_LIMIT_EXCEEDED
LDAP_INSUFFICIENT_ACCESS
LDAP_BUSY
LDAP_UNWILLING_TO_PERFORM
LDAP_OTHER
LDAP_SORT_CONTROL_MISSING
LDAP_INDEX_RANGE_ERROR
