NOMBRE

Net::DBus::BaseObject - clase base para exportar objetos al bus

SINTAXIS

# Vamos a ser un objeto DBus
use base qw(Net::DBus::BaseObject);
# Exportar un señal 'Greeting' con parámetro de tipo string
dbus_signal("Greeting", ["string"]);
# Exportar 'Hello' como método que acepta un parámetro de tipo string
# y devuelve un valor de tipo string
dbus_method("Hello", ["string"], ["string"]);
sub new {
    my $class = shift;
    my $service = shift;
    my $self = $class->SUPER::new($service, "/org/demo/HelloWorld");
    bless $self, $class;
    return $self;
}
sub _dispatch_object {
    my $self = shift;
    my $connection = shift;
    my $message = shift;
    if (....$message se refiere a un método del objeto... ) {
       ... procesar este objeto's interfaces/methods...
       return $reply;
    }
}

DESCRIPCIÓN

Esta es la base de todos los objetos que se exportan al bus de mensaje. Proporciona el soporte básico para la introspección de tipos necesario para objetos exportados al bus. Cuando se hereda de esta clase, el objeto "_dispatch" debe implementarse para manejar el procesamiento de mensajes entrantes. El módulo Net::DBus::Exporter se usa para declarar qué métodos (y señales) se exportan al bus.

Todos los paquetes que heredan de esta clase tendrán automáticamente registrado la interfaz "org.freedesktop.DBus.Introspectable" con Net::DBus::Exporter, y el método "Introspect" dentro de esta exportada.

Los desarrolladores de aplicaciones rara vez usarán esta clase directamente, en lugar de Net::DBus::Object o "Net::DBus::ProxyObject" son las opciones comunes. Esta clase solo se usará si se quiere escribir un nuevo enfoque para la disparación de llamadas de método entrantes.

MÉTODOS

my $objeto = Net::DBus::BaseObject->new($servicio, $ruta)
Esta crea un nuevo objeto DBus con una ruta de $ruta registrada dentro del servicio $servicio. El parámetro $ruta debe ser una cadena que cumple con los requisitos normales de rutas de objetos en DBus, mientras que el parámetro $servicio debe ser un objeto de tipo Net::DBus::Service. El último es típicamente obtenido llamando al método "export_service" en el objeto Net::DBus.
my $objeto = Net::DBus::BaseObject->new($padreobj, $subruta)
Esta crea un nuevo objeto hijo con una ruta de $subruta relativa a su padre $padreobj. El parámetro $subruta debe ser una cadena que cumple con los requisitos normales de rutas de objetos en DBus, mientras que el parámetro $padreobj debe ser un objeto de tipo Net::DBus::BaseObject.
$objeto->disconnect()
Este método desconecta el objeto del bus, así que no recibirá más mensajes enviados por otros clientes. Cualquier objeto hijo también se desconectará recursivamente. Después de que un objeto haya sido desconectado, es posible que Perl pueda recolectar el objeto como residuo. También permitirá conectar un nuevo objeto a la misma ruta.
my $bool = $objeto->is_connected
Devuelve un valor verdadero si el objeto está conectado al bus y, por lo tanto, puede ser accedido por clientes remotos. Devuelve false si el objeto está desconectado y, por lo tanto, está listo para recolección de residuos. Todos los objetos empiezan en estado conectado y solo se convertirán en estado desconectado si se llama al método "disconnect".
my $servicio = $objeto->get_service
Obtiene el objeto Net::DBus::Service en el cual está exportado este objeto.
my $ruta = $objeto->get_object_path
Obtiene la ruta bajo la cual se exporta este objeto.
$objeto->emit_signal_in($nombre, $interfaz, $cliente, @args);
Emite una señal desde el objeto con nombre $nombre. Si el parámetro $interfaz es definido, la señal se escuadrará dentro de esa interfaz. Si el parámetro $cliente es definido, la señal se envía como unicast a ese cliente en el bus. Los tipos de la señal y los tipos de los argumentos @args deben haber sido registrados con Net::DBus::Exporter mediante la llamada a la función "dbus_signal".
$self->emit_signal_to($nombre, $cliente, @args);
Emite una señal desde el objeto con nombre $nombre. Los tipos de la señal y los tipos de los argumentos @args deben haber sido registrados con Net::DBus::Exporter mediante la llamada a la función "dbus_signal". La señal se enviará solo al cliente especificado por el parámetro $cliente.
$self->emit_signal($nombre, @args);
Emite una señal desde el objeto con nombre $nombre. Los tipos de la señal y los tipos de los argumentos @args deben haber sido registrados con Net::DBus::Exporter mediante la llamada a la función "dbus_signal". La señal se enviará a todos los clientes del bus.
$objeto->connect_to_signal_in($nombre, $interfaz, $coderef);
Conecta un callback a una señal emita por el objeto. El parámetro $nombre es el nombre de la señal dentro del objeto, y $coderef es una referencia a una subrutina anónima. Cuando se emita la señal $nombre por el objeto remoto, la subrutina $coderef se invocará y se pasarán los parámetros de la señal. El parámetro $interfaz se usa para especificar la interfaz explícita que se conecta a la señal.
$objeto->connect_to_signal($nombre, $coderef);
Conecta un callback a una señal emita por el objeto. El parámetro $nombre es el nombre de la señal dentro del objeto, y $coderef es una referencia a una subrutina anónima. Cuando se emita la señal $nombre por el objeto remoto, la subrutina $coderef se invocará y se pasarán los parámetros de la señal.
$reply = $objeto->_dispatch_object($conexion, $mensaje);
El método "_dispatch_object" se usa para manejar la disparación de métodos implementados por el objeto. La implementación por defecto es un NOP y debe ser sobrescrito por las clases derivadas. Si el $mensaje puede ser procesado, se devolverá otro "Net::DBus::Binding::Message" instancia para la respuesta. Si "undef" es devuelto, se devolverá un error genérico al llamador.
$currvalue = $objeto->_dispatch_property($nombre); =item $objeto->_dispatch_property($nombre, $newvalue);
El método "_dispatch_property" se usa para manejar la disparación de lectura y escritura de propiedades. El parámetro $nombre es el nombre de la propiedad que se está accediendo. Si $newvalue es proporcionado, la propiedad se actualiza, de lo contrario se devuelve el valor actual. La implementación por defecto lanzará un error, por lo que debe ser sobrescrita en las clases derivadas.
