NOMBRE

Net::IDN::UTS46 - Procesamiento de Compatibilidad IDNA Unicode (UTS #46)

SINOPSIS

use Net::IDN:: ':all';
my $a = uts46_to_ascii("müller.example.org");
my $b = Net::IDN::UTS46::to_unicode('EXAMPLE.XN--11B5BS3A9AJ6G');

$domain =~ m/\P{Net::IDN::UTS46::IsDisallowed} and die 'oops';

DESCRIPCIÓN

Este módulo implementa el Estándar Técnico Unicode #46 (Procesamiento de Compatibilidad IDNA Unicode). UTS #46 es una variante de los Nombres de Dominio Internacionalizados (IDN), que tiene como objetivo ser compatible con los nombres de dominio registrados bajo IDNA2003 o IDNA2008.

Deberías usar este módulo si quieres una implementación exacta de la especificación UTS #46.

Sin embargo, si solo quieres convertir nombres de dominio y no te importa qué estándar se use internamente, deberías usar Net::IDN::Encode en su lugar.

FUNCIONES

Por defecto, este módulo no exporta ninguna subrutina. Puedes usar la etiqueta ":all" para importar todo.

Puedes omitir el prefijo 'uts46_' al acceder a las funciones con un nombre de módulo completamente calificado (por ejemplo, puedes acceder a "uts46_to_unicode" como "Net::IDN::UTS46::uts46_to_unicode" o "Net::IDN::UTS46::to_unicode").

Las siguientes funciones están disponibles:

uts46_to_ascii( $dominio, %param )
Implementa la función "ToASCII" de UTS #46, sección 4.2. Convierte un nombre de dominio a ASCII y lanza una excepción en caso de entrada inválida.

Esta función toma los siguientes parámetros opcionales (%param):

AllowUnassigned
(booleano) Si se establece a un valor verdadero, se permiten los puntos de código no asignados en la etiqueta. Esta es una extensión sobre UTS #46.

El valor por defecto es falso.

UseSTD3ASCIIRules
(booleano) Si se establece a un valor verdadero, verifica que la etiqueta cumpla con la sintaxis STD 3 (RFC 1123) para las partes del nombre de host.

El valor por defecto es verdadero.

TransitionalProcessing
(booleano) Si se establece a verdadero, la conversión será compatible con IDNA2003. Esto solo afecta a cuatro caracteres: 'ß' (U+00DF), 'ς' (U+03C2), ZWJ (U+200D) y ZWNJ (U+200C). Normalmente, querrás establecer esto a falso.

El valor por defecto es falso.

uts46_to_unicode( $etiqueta, %param )
Implementa la función "ToUnicode" de UTS #46, sección 4.3. Convierte un nombre de dominio a Unicode y lanza una excepción en caso de entrada inválida.

Esta función toma los siguientes parámetros opcionales (%param):

AllowUnassigned
ver arriba.
UseSTD3ASCIIRules
ver arriba.
TransitionalProcessing
(booleano) Si se proporciona, este parámetro debe ser falso. La especificación UTS #46 no define el procesamiento transicional para ToUnicode.

PROPIEDADES DE CARACTERES UNICODE

Este módulo también define las propiedades de caracteres que se enumeran a continuación.

Cada carácter tiene exactamente una de las siguientes propiedades:

"\p{Net::IDN::UTS46::IsValid}"
El punto de código es válido y no se modifica (es decir, un carácter de desviación) en UTS #46.
"\p{Net::IDN::UTS46::IsIgnored}"
El punto de código se elimina (es decir, se mapea a una cadena vacía) en UTS #46.
"\p{Net::IDN::UTS46::IsMapped}"
El punto de código se reemplaza por otra cadena en UTS #46.
"\p{Net::IDN::UTS46::IsDeviation}"
El punto de código es mapeado o válido, dependiendo de si el procesamiento es transicional o no.
"\p{Net::IDN::UTS46::IsDisallowed}"
El punto de código no está permitido en UTS #46.
"\p{Net::IDN::UTS46::IsDisallowedSTD3Ignored}"
El punto de código no está permitido en UTS #46 si se usan "UseSTDASCIIRules", pero se ignoraría de lo contrario.
"\p{Net::IDN::UTS46::IsDisallowedSTD3Mapped}"
El punto de código no está permitido en UTS #46 si se usan "UseSTDASCIIRules", pero se mapearía de lo contrario.
