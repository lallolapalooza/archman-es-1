NOMBRE

Net::Jabber::Dialback::Result - Módulo de resultado de Dialback de Jabber

SINOPSIS

Net::Jabber::Dialback::Result es un complemento del módulo Net::Jabber::Dialback. Proporciona al usuario una interfaz sencilla para establecer y recuperar todas las partes de un resultado de Dialback de Jabber.

DESCRIPCIÓN

Para inicializar el Resultado con un <db:*/> de Jabber, debes pasarle el hash de XML::Stream. Por ejemplo:
  my $dialback = new Net::Jabber::Dialback::Result(%hash);
Ha habido un cambio en la forma antigua de manejar las devoluciones de llamada. Ya no tienes que hacer lo anterior tú mismo, se pasa un objeto NJ::Dialback::Result a la función de devolución de llamada para el mensaje. Además, el primer argumento de las funciones de devolución de llamada es el ID de sesión de XML::Streams. Hay algunos casos en los que podrías querer esta información, como si crearas un Cliente que se conecta a dos servidores a la vez, o para escribir un miniseridor.
  use Net::Jabber qw(Server);
  sub dialbackResult {
    my ($sid,$Result) = @_;
    .
    .
    .
  }
Ahora tienes acceso a todas las funciones de recuperación disponibles.
Para crear un nuevo dialback para enviar al servidor:
  use Net::Jabber qw(Server);
  $Result = new Net::Jabber::Dialback::Result();
Ahora puedes llamar a las funciones de creación a continuación para poblar la etiqueta antes de enviarla.
Para más información sobre el formato de array que se pasa a la devolución de llamada, lee la documentación de Net::Jabber::Client.

Funciones de recuperación

$to         = $Result->GetTo();
$from       = $Result->GetFrom();
$type       = $Result->GetType();
$data       = $Result->GetData();
$str        = $Result->GetXML();
@dialback   = $Result->GetTree();

Funciones de creación

$Result->SetResult(from=>"jabber.org",
                   to=>"jabber.com",
                   data=>key);
$Result->SetTo("jabber.org");
$Result->SetFrom("jabber.com");
$Result->SetType("valid");
$Result->SetData(key);

Funciones de prueba

$test = $Result->DefinedTo();
$test = $Result->DefinedFrom();
$test = $Result->DefinedType();

MÉTODOS

Funciones de recuperación

GetTo() -  devuelve una cadena con el servidor al que se envía el <db:result/>.
GetFrom() -  devuelve una cadena con el servidor desde el que se envía el <db:result/>.
GetType() - devuelve una cadena con el tipo de <db:result/>.
GetData() - devuelve una cadena con el cdata del <db:result/>.
GetXML() - devuelve la cadena XML que representa el <db:result/>.
           Esto es utilizado por la función Send() en Server.pm para enviar
           este objeto como un resultado de Dialback de Jabber.
GetTree() - devuelve un array que contiene la etiqueta <db:result/>
            en formato XML::Parser::Tree.

Funciones de creación

SetResult(to=>cadena,   - establece varios campos en el <db:result/>
          from=>cadena,   al mismo tiempo.  Esta es una acción acumulativa
          type=>cadena,   y sobrescrita. Si estableces
          data=>cadena)   el atributo "from" dos veces, la segunda
                          asignación es la que se utiliza. Si estableces
                          el tipo y luego los datos
                          entonces ambos estarán en la etiqueta <db:result/>.
                          Para las asignaciones válidas, lee las
                          funciones Set específicas a continuación.
SetTo(cadena) - establece el atributo to.
SetFrom(cadena) - establece el atributo from.
SetType(cadena) - establece el atributo type. Las asignaciones válidas son:
                  valid
                  invalid
SetData(cadena) - establece el cdata del <db:result/>.

Funciones de prueba

DefinedTo() - devuelve 1 si el atributo to está definido en el
              <db:result/>, 0 en caso contrario.
DefinedFrom() - devuelve 1 si el atributo from está definido en el
                <db:result/>, 0 en caso contrario.
DefinedType() - devuelve 1 si el atributo type está definido en el
                <db:result/>, 0 en caso contrario.
