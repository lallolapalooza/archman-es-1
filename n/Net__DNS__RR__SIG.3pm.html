NOMBRE

Net::DNS::RR::SIG - Registro de recurso SIG de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre SIG tipocubierto algoritmo etiquetas
                        ttl_expiracion_firma inicio_firma
                        etiquetakey nombrefirma firma');
use Net::DNS::SEC;
$sigrr = Net::DNS::RR::SIG->create(
                        $cadena, $ruta_clave,
                        sigval => 10    # minutos
                        );
$sigrr->verify( $cadena, $keyrr ) || die $sigrr->vrfyerrstr;
$sigrr->verify( $paquete, $keyrr ) || die $sigrr->vrfyerrstr;

DESCRIPCIÓN

Clase para registros de recursos de firma digital (SIG) de DNS.

Además de los métodos regulares heredados de Net::DNS::RR, la clase contiene un método para firmar paquetes y cadenas de datos escalares usando claves privadas (create) y un método para verificar firmas.

El registro SIG es una implementación de RFC2931. Vea Net::DNS::RR::RRSIG para una implementación de RFC4034.

MÉTODOS

Los métodos disponibles son aquellos heredados de la clase base aumentados por los métodos específicos del tipo definidos en este paquete.

Se desaconseja el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otro comportamiento impredecible.

algoritmo

$algoritmo = $rr->algorithm;

El campo del número de algoritmo identifica el algoritmo criptográfico utilizado para crear la firma.

algorithm() también puede invocarse como método de clase o función simple para realizar la traducción de códigos numéricos y mnemotécnicos.

tiempos de expiración y inicio de firma

sigex sigin sigval

$expiracion = $rr->sigexpiration;
$expiracion = $rr->sigexpiration( $valor );
$inicio = $rr->siginception;
$inicio = $rr->siginception( $valor );

Los campos de expiración y inicio de la firma especifican un intervalo de tiempo de validez para la firma.

El valor puede ser especificado por una cadena con formato 'aaaammddhhmMSS' o un valor numérico de time() de Perl.

Los valores de retorno son de doble valor, proporcionando ya sea un valor de cadena o un valor numérico de time() de Perl.

etiquetakey

$etiquetakey = $rr->keytag;
$rr->keytag( $etiquetakey );

El campo etiquetakey contiene el valor de etiqueta de clave del registro KEY RR que valida esta firma.

nombrefirma

$nombrefirma = $rr->signame;
$rr->signame( $nombrefirma );

El valor del campo nombre firmante identifica el nombre del propietario del registro KEY RR que un validador debe usar para validar esta firma.

firma

sig

$sig = $rr->sig;
$rr->sig( $sig );

El campo Firma contiene la firma criptográfica que cubre los RDATA del SIG (excluyendo el campo Firma) y los datos del sujeto.

sigbin

$sigbin = $rr->sigbin;
$rr->sigbin( $sigbin );

Representación binaria de la firma criptográfica.

crear

Crea una firma sobre datos escalares.

use Net::DNS::SEC;
$ruta_clave = '/home/olaf/claves/Kbla.foo.+001+60114.private';
$sigrr = Net::DNS::RR::SIG->create( $datos, $ruta_clave );
$sigrr = Net::DNS::RR::SIG->create(
                        $datos, $ruta_clave,
                        sigval => 10
                        );
$sigrr->print;
# Alternativamente usa Net::DNS::SEC::Private
$privada = Net::DNS::SEC::Private->new($ruta_clave);
$sigrr= Net::DNS::RR::SIG->create( $datos, $privada );

create() es un constructor alternativo para un objeto SIG RR.

Este método devuelve un SIG con la firma sobre los datos hecha con la clave privada almacenada en el archivo de clave.

El primer argumento es un escalar que contiene los datos a firmar.

El segundo argumento es una cadena que especifica la ruta a un archivo que contiene la clave privada, tal como se genera usando dnssec-keygen, un programa que viene con la distribución BIND de ISC.

Los argumentos opcionales restantes consisten en pares de ( nombre => valor ) como sigue:

sigin  => 20241201010101,       # inicio de la firma
sigex  => 20241201011101,       # expiración de la firma
sigval => 10,                   # ventana de validez (minutos)

Los valores sigin y sigex pueden ser especificados como valores de tiempo de Perl o como una cadena con el formato 'aaaammddhhmMSS'. El valor predeterminado para sigin es el momento de la firma.

El argumento sigval especifica la ventana de validez de la firma en minutos ( sigex = sigin + sigval ).

Por defecto, la firma es válida durante 10 minutos.

verificar

$verificacion = $sigrr->verify( $datos, $keyrr );
$verificacion = $sigrr->verify( $datos, [$keyrr, $keyrr2, $keyrr3] );

El método verify() realiza la verificación SIG0 de los datos especificados contra la firma contenida en el propio objeto $sigrr usando la clave pública en $keyrr.

Si se proporciona una referencia a un Net::DNS::Packet, el método realiza una verificación SIG0 sobre los datos del paquete.

El segundo argumento puede ser un objeto Net::DNS::RR::KEYRR o una referencia a un array de tales objetos. La verificación devolverá éxito tan pronto como una de las claves en el array conduzca a una validación positiva.

Devuelve falso en caso de error y establece $sig->vrfyerrstr

vrfyerrstr

$sig0 = $paquete->sigrr || die 'no firmado';
print $sig0->vrfyerrstr unless $sig0->verify( $paquete, $keyrr );
$sigrr->verify( $paquete, $keyrr ) || die $sigrr->vrfyerrstr;

GENERACIÓN DE CLAVES

Los archivos de clave privada y los registros DNSKEY públicos correspondientes se generan de manera más conveniente usando dnssec-keygen, un programa que viene con la distribución BIND de ISC.

dnssec-keygen -a 10 -b 2048 rsa.example.
dnssec-keygen -a 13 -f ksk  ecdsa.example.
dnssec-keygen -a 13         ecdsa.example.

No cambie el nombre del archivo de clave privada. El método create usa el nombre del archivo tal como lo genera dnssec-keygen para determinar el propietario de la clave, el algoritmo y el id de clave (etiqueta de clave).
