NOMBRE

Net::DNS::RR::RESINFO - registro de recurso RESINFO de DNS

SINOPSIS

use Net::DNS;
my $target = 'resolver.example.net';
my $resolver = Net::DNS::Resolver->new(
                        nameserver => $target,
                        recurse    => 0
                        );
$resolver->send( $target, 'RESINFO' )->print;
;; SECCIÓN DE CABECERA
;;      id = 46638
;;      qr = 1  aa = 1  tc = 0  rd = 0  opcode = QUERY
;;      ra = 0  z  = 0  ad = 0  cd = 0  rcode  = NOERROR
;;      do = 0  co = 0
;;      qdcount = 1     ancount = 1
;; SECCIÓN DE PREGUNTA (1 registro)
;; resolver.example.net.        IN      RESINFO

resolver.example.net.   7200    IN      RESINFO (

        infourl=https://resolver.example.com/guide )

;; SECCIÓN ADICIONAL (0 registros)

DESCRIPCIÓN

Clase para registros de recursos RESINFO (Resolver Information) de DNS.

RESINFO es un clon de la clase Net::DNS::RR::TXT.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete ni el acceso directo a estructuras de datos internas, ya que podría provocar la terminación del programa u otro comportamiento impredecible.

txtdata

$string = $rr->txtdata;
@list    = $rr->txtdata;

Cuando se invoca en contexto escalar, $rr->txtdata() devuelve las propiedades del resolvedor como una única cadena, con los elementos separados por un solo espacio.

En contexto de lista, $rr->txtdata() devuelve una lista de los elementos de texto.
