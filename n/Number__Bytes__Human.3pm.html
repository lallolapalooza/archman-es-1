NOMBRE

Number::Bytes::Human - Convierte el recuento de bytes a formato legible por humanos

SINOPSIS

use Number::Bytes::Human qw(format_bytes parse_bytes);
$size = format_bytes(0); # '0'
$size = format_bytes(2*1024); # '2.0K'
$size = format_bytes(1_234_890, bs => 1000); # '1.3M'
$size = format_bytes(1E9, bs => 1000); # '1.0G'
my $bytes = parse_bytes('1.0K');   # 1024
my $bytes = parse_bytes('1.0KB');  # 1000, unidad SI
my $bytes = parse_bytes('1.0KiB'); # 1024, unidad SI
# la forma OO
$human = Number::Bytes::Human->new(bs => 1000, si => 1);
$size = $human->format(1E7); # '10MB'
$bytes = $human->parse('10MB');   # 10*1000*1000
$bytes = $human->parse('10MiB');  # 10*1024*1024
$bytes = $human->parse('10M');    # Error, sin unidad SI
$human->set_options(zero => '-');
$size = $human->format(0);    # '-'
$bytes = $human->parse('-');  # 0
$human = Number::Bytes::Human->new(bs => 1000, round_style => 'round', precision => 2);
$size = $human->format(10240000); # '10.24MB'

DESCRIPCIÓN

ESTO ES SOFTWARE ALFA: LA DOCUMENTACIÓN Y EL CÓDIGO SUFRIRÁN CAMBIOS ALGÚN DÍA (¡GRACIAS, DIOS!).

Este módulo proporciona un formateador que convierte recuentos de bytes a un formato legible, como '2.0K', '3.1G', '100B'. Fue inspirado por la opción "-h" de utilidades Unix como "du", "df" y "ls" para la salida "legible por humanos".

De la página del manual de FreeBSD de "df": http://www.freebsd.org/cgi/man.cgi?query=df

"Legible por humanos" salida. Usa sufijos de unidad: Byte, Kilobyte,
Megabyte, Gigabyte, Terabyte y Petabyte en orden para reducir el
número de dígitos a cuatro o menos usando base 2 para los tamaños.
byte      B
kilobyte  K = 2**10 B = 1024 B
megabyte  M = 2**20 B = 1024 * 1024 B
gigabyte  G = 2**30 B = 1024 * 1024 * 1024 B
terabyte  T = 2**40 B = 1024 * 1024 * 1024 * 1024 B
petabyte  P = 2**50 B = 1024 * 1024 * 1024 * 1024 * 1024 B
exabyte   E = 2**60 B = 1024 * 1024 * 1024 * 1024 * 1024 * 1024 B
zettabyte Z = 2**70 B = 1024 * 1024 * 1024 * 1024 * 1024 * 1024 * 1024 B
yottabyte Y = 2**80 B = 1024 * 1024 * 1024 * 1024 * 1024 * 1024 * 1024 * 1024 B

He encontrado este enlace bastante útil:

http://www.t1shopper.com/tools/calculate/

Si te sientes como un fabricante de discos duros, puedes empezar a contar bytes por potencias de 1000 (en lugar de los generosos 1024). Simplemente usa "bs => 1000".

Pero si eres un fabricante de disquetes y quieres empezar a contar en unidades de 1024000 (para tus disquetes de "1.44 MB")? Entonces usa "bs => 1_024_000".

Si te sientes como un académico purista, puedes forzar el uso de prefijos métricos según el estándar de Diciembre de 1998 de la IEC. No te preocupes, las unidades para la base 1000 son "('B', 'kB', 'MB', 'GB', 'TB', 'PB', 'EB', 'ZB', 'YB')" y, aún peor, las de la base 1024 son "('B', 'KiB', 'MiB', 'GiB', 'TiB', 'PiB', 'EiB', 'ZiB', 'YiB')" con los horribles nombres: bytes, kibibytes, mebibytes, etc. Todo lo que tienes que hacer es usar "si => 1". ¿No es hermoso el sistema SI? Lee sobre ello:

http://physics.nist.gov/cuu/Units/binary.html

Puedes probar un comando puro de Perl inspirado en "ls -lh" con la línea de comandos, er, dos líneas:

$ perl -MNumber::Bytes::Human=format_bytes \
       -e 'printf "%5s %s\n", format_bytes(-s), $_ for @ARGV' *

¿Por qué escribir un módulo así? Porque si la gente puede escribir cosas así en C, se puede escribir mucho más fácilmente en Perl y luego reutilizarlo, refactorizarlo, abusar de él. Y entonces, cuando mejore mucho, algún alma valiente puede portarlo de vuelta a C (¡aunque solo sea por la sensación cálida de la programación dolorosa!).

También es posible analizar bytes formateados legibles por humanos. La detección automática de formato reconoce unidades SI con los tamaños de bloque de 1000 y 1024 respectivamente, y además los habituales K / M / G etc. con tamaño de bloque 1024. Cuando se agrega si => 1 a las opciones, solo se reconocen unidades SI. Especificar explícitamente un tamaño de bloque lo cambia para todas las unidades detectadas.

OBJETOS

Una alternativa al estilo funcional de este módulo es la moda OO. Esto es útil para evitar el análisis innecesario de los argumentos una y otra vez si tienes que formatear muchos números.

for (@sizes) {
  my $fmt_size = format_bytes($_, @args);
  ...
}

vs.

my $human = Number::Format::Bytes->new(@args);
for (@sizes) {
  my $fmt_size = $human->format($_);
  ...
}

FUNCIONES

format_bytes
$h_size = format_bytes($size, @options);

Convierte un recuento de bytes (como 1230) a un formato legible como '1.3K'. Tienes un montón de opciones para jugar. Consulta la sección "OPCIONES" para conocer los detalles.

parse_bytes
$size = parse_bytes($h_size, @options);

Convierte un recuento de bytes legible por humanos al número de bytes equivalente.

MÉTODOS

new
$h = Number::Bytes::Human->new(@options);

El constructor. Para detalles sobre los argumentos, consulta la sección "OPCIONES".

format
$h_size = $h->format($size);

Convierte un recuento de bytes (como 1230) a un formato legible como '1.3K'. Las sentencias

$h = Number::Bytes::Human->new(@options);
$h_size = $h->format($size);

son equivalentes a "$h_size = format_bytes($size, @options)", con solo una pasada por los argumentos de las opciones.

parse
$size = $h->parse($h_size)

Convierte un recuento de bytes legible por humanos al número de bytes. Las sentencias

$h = Number::Bytes::Human->new(@options);
$size = $h->format($h_size);

son equivalentes a "$size = parse_bytes($h_size, @options)", con solo una pasada por los argumentos de las opciones.

set_options
$h->set_options(@options);

Para alterar las opciones de un objeto "Number::Bytes::Human". Consulta "OPCIONES".

OPCIONES

BASE
block | base | block_size | bs => 1000 | 1024 | 1024000
base_1024 | block_1024 | 1024 => 1
base_1000 | block_1000 | 1000 => 1

La base a usar: 1024 (por defecto), 1000 o 1024000.

Cualquier otro valor lanzará una excepción.

SUFIJOS
suffixes => 1000 | 1024 | 1024000 | si_1000 | si_1024 | $arrayref

Por defecto, los sufijos usados son '', 'K', 'M', ... para la base 1024 y '', 'k', 'M', ... para la base 1000 (que son de hecho los prefijos métricos habituales con la unidad implícita como bytes, 'B'). Para la base extraña 1024000, los sufijos son '', 'M', 'T', etc.

CERO
zero => string | undef

La cadena 0 se mapea a ('0' por defecto). Si es "undef", se usa el caso general. La cadena puede contener '%S' en cuyo caso se usa el sufijo para byte.

format_bytes(0, zero => '-') => '-'
SISTEMA MÉTRICO
si => 1
REDONDEO
round_style => 'round' | 'ceil' | 'floor' | 'trunc' | 'round_even'
precision => integer

Permite especificar cómo redondear los números con decimales. Los estilos disponibles son los mismos que los de `Math::Round`.

El valor de `precision` (precisión) especifica el número de dígitos después del punto decimal.

Ejemplo:

format_bytes(12345, precision => 0) # '12K'
format_bytes(12345, precision => 1) # '12.2K'
format_bytes(12345, precision => 2) # '12.21K'
format_bytes(12345, precision => 0, round_style => 'floor') # '12K'
format_bytes(12345, precision => 0, round_style => 'ceil') # '13K'
PRECISIÓN

Ver la opción `round_style`.

FORMAT
format => format_string

Permite especificar un formato para la salida. Los marcadores disponibles son: %s (el tamaño formateado), %d (el número de bytes), %u (la unidad).

format_bytes(1234, format => "%d %u") # '1234 B'
format_bytes(1234, format => "%s") # '1.21K'
format_bytes(1234, format => "%s", bs => 1000) # '1.23k'
SEPARADOR DECIMAL
decimal_sep => '.' | ','

Permite especificar el separador decimal a usar en la salida. Por defecto es '.'

format_bytes(1234.56, format => "%.2f", decimal_sep => ',') # '1234,56 B'

DESCRIPCIÓN

Number::Bytes::Human es un módulo de Perl que proporciona un formato legible por humanos para los números, similar a la funcionalidad que se encuentra en el paquete GNU coreutils. Te permite formatear números de una manera fácil de entender, con soporte para varios estilos y configuraciones de precisión.

DIAGNÓSTICOS

Estos son los mensajes de diagnóstico que puedes encontrar:

  • estilo de redondeo desconocido '$style'
  • base inválida: $block (debería ser 1024, 1000 o 1024000)
  • la función de redondeo ($args{round_function}) debería ser una referencia de código
  • sufijos ($args{suffixes}) deberían ser 1000, 1024, 1024000 o una referencia a un array
  • no se permiten números negativos
