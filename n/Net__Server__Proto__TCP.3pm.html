Net::Server::Proto::TCP(3) Documentación de Perl aportada por el usuario Net::Server::Proto::TCP(3)

NOMBRE

Net::Server::Proto::TCP - Protocolo TCP de Net::Server.

SINOPSIS

Ver Net::Server::Proto.

DESCRIPCIÓN

Módulo de protocolo para Net::Server. Este módulo implementa el tipo de socket SOCK_STREAM bajo INET (también conocido como TCP). Ver Net::Server::Proto.

PARÁMETROS

No hay parámetros adicionales que se puedan especificar. Ver Net::Server para más información sobre cómo leer argumentos.

MÉTODOS INTERNOS

"object"
Devuelve un objeto con parámetros adecuados para la eventual creación de un objeto IO::Socket::INET que escuche en UDP.
"log_connect"
Se llama antes de vincular el socket para proporcionar información útil a los logs.
"connect"
Se llama al vincular realmente el puerto. Maneja los parámetros por defecto antes de llamar al método padre.
"reconnect"
Se llama en lugar del método connect durante un hup del servidor.
"accept"
Anulación de la clase padre para asegurarse de que los parámetros necesarios se pasan a los sockets cliente.
"poll_cb"
Permite una interfaz compatible con psgi durante el servidor HTTP.
"read_until"
Toma una expresión regular, lee del socket hasta que se coincide con la expresión regular.
"hup_string"
Devuelve un identificador único que se puede pasar al proceso re-ejecutado durante HUP.
"show"
Volcador básico de las propiedades almacenadas en el glob.
"AUTOLOAD"
Maneja los métodos accesores.

LICENCIA

Distribuido bajo los mismos términos que Net::Server
