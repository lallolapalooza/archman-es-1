NOMBRE

Net::Jabber::Client - Biblioteca de cliente Jabber

SINOPSIS

Net::Jabber::Client es un módulo que proporciona a los desarrolladores un fácil acceso
al protocolo de mensajería instantánea Jabber.

DESCRIPCIÓN

Client.pm hereda sus métodos de Net::XMPP::Client,
Net::XMPP::Protocol y Net::Jabber::Protocol. Los módulos Protocol
proporcionan suficientes APIs de alto nivel y automatización de las APIs de bajo nivel
que escribir un cliente Jabber en Perl es trivial. Para aquellos que deseen
trabajar con el bajo nivel, también pueden hacerlo, pero esas funciones están
cubiertas en la documentación de cada módulo.
Net::Jabber::Client proporciona funciones para conectarse a un servidor Jabber,
iniciar sesión, enviar y recibir mensajes, establecer información personal, crear una
nueva cuenta de usuario, gestionar la lista de contactos y desconectar. Puede utilizar
todas o ninguna de las funciones, no hay requisitos.
Para obtener más información sobre cómo está escrito Net::Jabber,
consulte la ayuda de Net::Jabber en sí.
Para una lista completa de las funciones de alto nivel disponibles, consulte:
  Net::XMPP::Client
  Net::XMPP::Protocol
  Net::Jabber::Protocol
