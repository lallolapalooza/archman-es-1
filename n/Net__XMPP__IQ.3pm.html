NOMBRE

Net::XMPP::IQ - Módulo de Info/Consulta de XMPP

SINOPSIS

Net::XMPP::IQ es un compañero del módulo Net::XMPP. Proporciona una interfaz simple para configurar y recuperar todas las partes de un IQ de XMPP.

DESCRIPCIÓN

Net::XMPP::IQ difiere de los otros módulos de Net::XMPP en que el espacio de nombres de la consulta está dividido en un módulo submódulo bajo IQ. Para especificaciones sobre cada módulo, por favor consulte la documentación del módulo Net::XMPP::Namespaces. Un objeto Net::XMPP::IQ se pasa a la función de callback para el mensaje. También, el primer argumento a las funciones de callback es el ID de sesión desde XML::Stream. Hay algunos casos donde podrías querer esta información, por ejemplo, si creaste un cliente que se conecta a dos servidores simultáneamente, o para crear un mini servidor. 

use Net::XMPP;
sub iq {
    my ($sid,$IQ) = @_;
    .
    .
    my $reply = $IQ->Reply();
    my $replyQuery->GetQuery();
    .
}
Ahora tienes acceso a todas las funciones de recuperación disponibles. Para crear un nuevo IQ para enviar a servidor: 
use Net::XMPP;
$IQ = Net::XMPP::IQ->new();
$IQType = $IQ->NewChild( type );
$IQType->SetXXXXX("yyyyy");
Ahora puedes llamar a las funciones de creación para el IQ, y para el <query/> en el objeto de consulta nuevo. Vea más abajo para las funciones <iq/> y en cada módulo de consulta para esas funciones.

MÉTODOS

Funciones generales

Reply(%args) - Crea una respuesta <iq/> con el a y desde llenados correctamente, y un objeto de consulta ya agregado. Los %args que pasas son pasados a SetIQ() y sobrescriben las configuraciones del IQ que Reply establece.

Funciones de recuperación

GetTo()      - devuelve una cadena con el JID, o un objeto Net::XMPP::JID para el receptor de <iq/>. Para obtener el JID, establece el string a "jid" , de lo contrario usa el texto string.
GetTo("jid")    Objeto Net::XMPP::JID para el que va a recibir <iq/>. Para obtener el JID, establece el string a "jid" , de lo contrario usa el texto string.
$to    = $IQ->GetTo();
$toJID = $IQ->GetTo("jid");
GetFrom()      - devuelve una cadena con el JID, o un objeto Net::XMPP::JID para el que envió <iq/>. Para obtener el JID, establece el string a "jid" , de lo contrario usa el texto string.
$from    = $IQ->GetFrom();
$fromJID = $IQ->GetFrom("jid");
GetType() - devuelve una cadena con el tipo <iq/> actual.
$type = $IQ->GetType();
GetID() - devuelve un entero con el id de <iq/>.
$id = $IQ->GetID();
GetError() - devuelve una cadena con la descripción textual del error.
$error = $IQ->GetError();
GetErrorCode() - devuelve una cadena con el código del error.
$errorCode = $IQ->GetErrorCode();
GetQuery() - devuelve un objeto Net::XMPP::Stanza que contiene los datos de la consulta de <iq/>. basicamente, devuelve el primer hijo en <iq/>.
$query = $IQ->GetQuery();
GetQueryXMLNS() - devuelve una cadena con el espacio de nombres de la consulta para este <iq/>, si existe.
$xmlns = $IQ->GetQueryXMLNS();

Funciones de creación

SetIQ(to=>string|JID,    - establece múltiples campos en <iq/> en un tiempo. Este es un acción acumulativa y sobreescrita. Si estableces el "to" dos veces, el segundo establecimiento se usa. Si estableces el status y el error, luego establece la prioridad, ambos se incluirán en <iq/>.
errorcode=>string,      - qué se usa. Si estableces el status, y el error, luego establece la prioridad, ambos se incluirán en <iq/>.
error=>string)          - sets the error string of the <iq/>.
$IQ->SetIQ(type=>"get",
                                      to=>"bob\@jabber.org");
                           $IQ->SetIQ(to=>"bob\@jabber.org",
                                      errorcode=>403,
                                      error=>"Permission Denied");
SetTo(string) - establece el atributo to. Puedes pasar una cadena o un objeto JID. Deben ser identificadores válidos de Jabber o el servidor devolverá un mensaje de error. (ej. bob@jabber.org, etc...)
$IQ->SetTo("bob\@jabber.org");
SetFrom(string) - establece el atributo from. Puedes pasar una cadena o un objeto JID. Deben ser identificadores válidos de JID o el servidor devolverá un mensaje de error. (ej. bob@jabber.org, etc...)
$IQ->SetFrom("me\@jabber.org");
SetType(string) - establece el atributo type. Valores válidos son:
                  get      pide información
                  set      establece información
                  result   resultados de un get
                  error    hubo un error
$IQ->SetType("set");
SetErrorCode(string) - establece el código de error del <iq/>.
$IQ->SetErrorCode(403);
SetError(string) - establece la cadena de error del <iq/>.
$IQ->SetError("Permission Denied");
NewChild(string) - crea un objeto Net::XMPP::Stanza con el espacio de nombres en la cadena. Para que esta función funcione con un espacio de nombres personalizado, debes definir y registrar ese espacio de nombres con el módulo IQ. Más información por favor lee la documentación del módulo Net::XMPP::Stanza.
$queryObj = $IQ->NewChild("jabber:iq:auth");
$queryObj = $IQ->NewChild("jabber:iq:roster");
Reply(hash) - crea un nuevo objeto IQ y populación los campos to/from. Si especificas un hash igual a con SetIQ, estos valores sobrescriben los de Reply.
$iqReply = $IQ->Reply();
$iqReply = $IQ->Reply(type=>"result");

Funciones de eliminación

RemoveTo() - elimina el atributo to de <iq/>.
$IQ->RemoveTo();
RemoveFrom() - elimina el atributo from de <iq/>.
$IQ->RemoveFrom();
RemoveID() - elimina el atributo id de <iq/>.
$IQ->RemoveID();
RemoveType() - elimina el atributo type de <iq/>.
$IQ->RemoveType();
RemoveError() - elimina el <error/> del <iq/>.
$IQ->RemoveError();
RemoveErrorCode() - elimina el atributo code del <error/> en <iq/>.
$IQ->RemoveErrorCode();

Funciones de prueba

DefinedTo() - devuelve 1 si el atributo to está definido en <iq/>, 0 de lo contrario.
$test = $IQ->DefinedTo();
DefinedFrom() - devuelve 1 si el atributo from está definido en <iq/>, 0 de lo contrario.
$test = $IQ->DefinedFrom();
DefinedID() - devuelve 1 si el atributo id está definido en <iq/>, 0 de lo contrario.
$test = $IQ->DefinedID();
DefinedType() - devuelve 1 si el atributo type está definido en <iq/>, 0 de lo contrario.
$test = $IQ->DefinedType();
DefinedError() - devuelve 1 si <error/> está definido en <iq/>, 0 de lo contrario.
$test = $IQ->DefinedError();
DefinedErrorCode() - devuelve 1 si el atributo code está definido en <error/>, 0 de lo contrario.
$test = $IQ->DefinedErrorCode();
DefinedQuery() - devuelve 1 si hay al menos un hijo nombrado en el objeto.
