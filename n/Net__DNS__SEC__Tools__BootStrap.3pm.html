Net__DNS__SEC__Tools__BootStrap(3pm)

Paquete: dnssec-tools

Licencias: BSD

BootStrap(3) Documentación de Perl aportada por el usuario BootStrap(3)

NOMBRE

Net::DNS::SEC::Tools::BootStrap - Carga opcional de módulos de Perl

SINOPSIS

use Net::DNS::SEC::Tools::BootStrap;
dnssec_tools_load_mods(
   PerlModule => 'Texto adicional de ayuda/error'
);

DESCRIPCIÓN

El paquete DNSSEC-Tools requiere varios módulos de Perl que solo son necesarios para algunas de las herramientas. Este módulo ayuda a determinar en tiempo de ejecución, en lugar de en tiempo de instalación, si las herramientas correctas están disponibles en el sistema. Si algún módulo no se puede cargar, dnssec_tools_load_mods() mostrará un mensaje de error y llamará a exit(). El mensaje de error describe cómo instalar un módulo a través de CPAN.

Los argumentos para dnssec_tools_load_mods() se proporcionan en pares. Cada par es un módulo que se intenta cargar (e importar) y un mensaje de error adicional. Si el módulo no se carga, se mostrará el mensaje de error adicional junto con el mensaje de instalación vía CPAN. Si el mensaje de error consiste en la cadena "noerror", no se mostrará ningún mensaje de error antes de que la función finalice.

ADVERTENCIAS

El módulo intentará importar cualquier subrutina exportada del módulo al espacio de nombres *main*. Esto significa que es probable que el módulo *BootStrap.pm* no sea útil para importar símbolos a otros módulos. Las soluciones alternativas son:

- importar los símbolos manualmente
dnssec_tools_load_mods(
   PerlModule => 'Texto adicional de ayuda/error'
);
import PerlModule qw(func1 func2);
func1(arg1, arg2);
- llamar al nombre de función completamente calificado
dnssec_tools_load_mods(
   PerlModule => 'Texto adicional de ayuda/error'
);
PerlModule::func1(arg1, arg2);
