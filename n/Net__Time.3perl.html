Net::Time(3perl) Guía de programación de Perl Net::Time(3perl)

NOMBRE

Net::Time - interfaz de cliente de red de tiempo y hora del día

SINOPSIS

use Net::Time qw(inet_time inet_daytime);
print inet_time();          # usa el host predeterminado de Net::Config
print inet_time('localhost');
print inet_time('localhost', 'tcp');
print inet_daytime();       # usa el host predeterminado de Net::Config
print inet_daytime('localhost');
print inet_daytime('localhost', 'tcp');

DESCRIPCIÓN

"Net::Time" proporciona subrutinas que obtienen la hora en una máquina remota.

Funciones

"inet_time([$host[, $protocol[, $timeout]]])"
Obtiene la hora en $host, o algún host predeterminado si $host no se proporciona o no está definido, utilizando el protocolo definido en RFC868. El argumento opcional $protocol debe definir el protocolo a usar, ya sea "tcp" o "udp". El resultado será un valor de tiempo en las mismas unidades que las devueltas por time() o undef en caso de fallo.
"inet_daytime([$host[, $protocol[, $timeout]]])"
Obtiene la hora en $host, o algún host predeterminado si $host no se proporciona o no está definido, utilizando el protocolo definido en RFC867. El argumento opcional $protocol debe definir el protocolo a usar, ya sea "tcp" o "udp". El resultado será una cadena ASCII o undef en caso de fallo.
