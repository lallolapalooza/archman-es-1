Net::LDAP::Control::DontUseCopy(3) Documentación de Perl aportada por el usuario Net::LDAP::Control::DontUseCopy(3)

NOMBRE

Net::LDAP::Control::DontUseCopy - Objeto de control LDAPv3 Don't Use Copy

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::DontUseCopy;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$nocopy = Net::LDAP::Control::DontUseCopy->new( critical => 1 );
$msg = $ldap->search( base => 'o=University of Michigan,c=US',
                      filter => '(cn=Barbara Jensen)'
                      control  => [ $nocopy ] );
die "error: ",$msg->code(),": ",$msg->error()  if ($msg->code());

DESCRIPCIÓN

"Net::LDAP::Control::DontUseCopy" proporciona una interfaz para la creación y manipulación de objetos que representan el control "DontUseCopy" tal como se describe en RFC 6171.

Permite al cliente especificar que la información copiada no debe utilizarse para proporcionar el servicio.

El control es apropiado para las operaciones de búsqueda y comparación LDAP [RFC4511] e inapropiado para todas las demás operaciones.

Su criticidad debe ser VERDADERA; no tiene valor.

No existe un control de respuesta correspondiente.

ARGUMENTOS DEL CONSTRUCTOR

Dado que el control "DontUseCopy" no tiene valores, solo se admiten los argumentos del constructor descritos en Net::LDAP::Control.

MÉTODOS

Como no hay valores adicionales en el control, solo los métodos de Net::LDAP::Control están disponibles para los objetos de "Net::LDAP::Control::DontUseCopy".
