Net::Jabber::Log(3) Documentación de Perl aportada por el usuario Net::Jabber::Log(3)

NOMBRE

Net::Jabber::Log - Módulo de registro de Jabber

SINOPSIS

Net::Jabber::Log es un complemento del módulo Net::Jabber.
Proporciona al usuario una interfaz sencilla para establecer y recuperar
todas las partes de un registro de Jabber.

DESCRIPCIÓN

Para inicializar el Registro con un <log/> de Jabber, debes pasarle
el array del Árbol de XML::Parser. Por ejemplo:
  my $log = new Net::Jabber::Log(@tree);
Ha habido un cambio en la forma antigua de manejar las devoluciones de llamada.
Ya no tienes que hacer lo anterior, se pasa un objeto Net::Jabber::Log
a la función de devolución de llamada para el registro:
  use Net::Jabber;
  sub log {
    my ($Log) = @_;
    .
    .
    .
  }
Ahora tienes acceso a todas las funciones de recuperación disponibles.
Para crear un nuevo registro para enviar al servidor:
  use Net::Jabber;
  $Log = new Net::Jabber::Log();
Ahora puedes llamar a las funciones de creación a continuación para poblar la etiqueta antes
de enviarla.
Para obtener más información sobre el formato del array que se pasa a la devolución de llamada
, lee la documentación de Net::Jabber::Client.

Funciones de recuperación

$from       = $Log->GetFrom();
$fromJID    = $Log->GetFrom("jid");
$type       = $Log->GetType();
$data       = $Log->GetData();
$str        = $Log->GetXML();
@log        = $Log->GetTree();

Funciones de creación

$Log->SetLog(type=>"error",
             from=>"users.jabber.org",
             data=>"La luna está llena... ya no puedo correr.");
$Log->SetFrom("foo.jabber.org");
$Log->SetType("warn");
$Log->SetData("No puedo encontrar un archivo de configuración. Usando valores predeterminados.");

Funciones de prueba

$test = $Log->DefinedFrom();
$test = $Log->DefinedType();

MÉTODOS

Funciones de recuperación

GetFrom()      -  devuelve una cadena con el Identificador de Jabber,
GetFrom("jid")    o un objeto Net::Jabber::JID para la persona que
                  envió el <log/>. Para obtener el objeto JID, establece
                  la cadena a "jid", de lo contrario déjala en blanco para
                  la cadena de texto.
GetType() - devuelve una cadena con el tipo de <log/>.
GetData() - devuelve una cadena con los cdata del <log/>.
GetXML() - devuelve la cadena XML que representa el <log/>.
           Esto es utilizado por la función Send() en Client.pm para enviar
           este objeto como un registro de Jabber.
GetTree() - devuelve un array que contiene la etiqueta <log/>
            en formato de Árbol de XML::Parser.

Funciones de creación

SetLog(from=>cadena|JID, - establece múltiples campos en el <log/>
       type=>cadena,       a la vez. Esta es una acción acumulativa
       data=>cadena)       y de sobrescritura. Si estableces
                           el atributo "from" dos veces, se usa el segundo
                           ajuste. Si estableces el tipo y luego los datos
                           entonces ambos estarán en la etiqueta <log/>.
                           Para ajustes válidos, lee las
                           funciones Set específicas a continuación.
SetFrom(cadena) - establece el atributo from. Puedes pasar una cadena
SetFrom(JID)      o un objeto JID. Deben ser Identificadores de Jabber válidos
                  o el servidor devolverá un registro de error.
                  (es decir, jabber:bob@jabber.org/Silent Bob, etc...)
SetType(cadena) - establece el atributo type. Los ajustes válidos son:
                  notice     registro general
                  warn       advertencia
                  alert      error crítico (aún puede ejecutarse pero no
                             correctamente)
                  error      error fatal (no se puede ejecutar más)
SetData(cadena) - establece los cdata del <log/>.

Funciones de prueba

DefinedFrom() - devuelve 1 si el atributo from está definido en el
                <log/>, 0 en caso contrario.
DefinedType() - devuelve 1 si el atributo type está definido en el
                <log/>, 0 en caso contrario.
