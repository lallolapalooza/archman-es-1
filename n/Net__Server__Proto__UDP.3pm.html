NOMBRE

Net::Server::Proto::UDP - Protocolo UDP de Net::Server.

SINOPSIS

Ver Net::Server::Proto.

DESCRIPCIÓN

Módulo de protocolo para Net::Server. Este módulo implementa el tipo de socket SOCK_DGRAM bajo INET (también conocido como UDP). Ver Net::Server::Proto.

PARÁMETROS

Los siguientes parámetros pueden especificarse además de los parámetros normales de línea de comandos para un Net::Server. Ver Net::Server para más información sobre la lectura de argumentos.

udp_recv_len
Especifica el número de bytes a leer del manejador de conexión UDP. Los datos se leerán en $self->{'server'}->{'udp_data'}. El valor por defecto es 4096. Ver IO::Socket::INET y recv.
udp_recv_flags
Ver recv. El valor por defecto es 0.
udp_broadcast
El valor por defecto es undef.

LISTA RÁPIDA DE PARÁMETROS

Clave               Valor                    Por defecto
## Parámetros del protocolo UDP
udp_recv_len      \d+                      4096
udp_recv_flags    \d+                      0
udp_broadcast     booleano                 undef

MÉTODOS INTERNOS

"object"
Devuelve un objeto con parámetros adecuados para la eventual creación de un objeto IO::Socket::INET que escuche en UDP.
"connect"
Se llama cuando realmente se enlaza el puerto. Maneja los parámetros por defecto antes de llamar al método padre.

LICENCIA
