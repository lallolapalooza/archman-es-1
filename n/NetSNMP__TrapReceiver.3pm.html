NOMBRE

NetSNMP::TrapReceiver - Gestión de trazas en Perl para snmptrapd de Net-SNMP

SINTAXIS

Coloca las siguientes líneas en tu archivo snmptrapd.conf:

perl NetSNMP::TrapReceiver::register("trapOID", \&myfunc);

RESUMEN

El módulo NetSNMP::TrapReceiver se utiliza para registrar funciones Perl en el proceso snmptrapd de Net-SNMP. Net-SNMP debe haber sido configurado previamente con --enable-embedded-perl. La registración de funciones se realiza a través del archivo de configuración snmptrapd.conf. Este módulo no puede ser utilizado en un script Perl normal para recibir trazas. Está destinado únicamente para uso embebido dentro del demonio snmptrapd.

DESCRIPCIÓN

En el archivo de configuración snmptrapd.conf, la palabra clave "perl" puede ser usada para llamar a cualquier expresión Perl. Con esta capacidad, puedes usar el módulo NetSNMP::TrapReceiver para registrar funciones que serán llamadas cada vez que se reciba una notificación (una traza o un informe). Las funciones registradas se llaman con dos argumentos. El primero es una referencia a un hash que contiene información sobre cómo se recibió la traza (qué versión del protocolo SNMP se usó, de dónde provino, qué nombre de usuario o nombre de comunidad se usó para enviarla, etc.). El segundo argumento es una referencia a un array que contiene los enlaces de variables (OID e información de valor) que definen la notificación en sí. Cada variable es a su vez una referencia a un array de cuatro valores: un objeto NetSNMP::OID, una representación string del valor asociado, el tipo numérico del valor (ver NetSNMP::ASN para más detalles sobre la información de tipado SNMP), y el valor raw de la traza, codificado según su tipo. Los tipos de entero de 64 bits se devuelven como strings, los tipos de entero como enteros, las cadenas como cadenas, los identificadores de objeto como objetos NetSNMP::OID, y cualquier otro tipo como undefs.

Las funciones registradas deben devolver uno de los siguientes valores:

NETSNMPTRAPD_HANDLER_OK
La traza se procesó con éxito, pero se deja que el demonio snmptrapd revise otros manejadores adecuados.
NETSNMPTRAPD_HANDLER_FAIL
El procesamiento de la traza falló, pero se deja que el demonio snmptrapd revise otros manejadores adecuados.
NETSNMPTRAPD_HANDLER_BREAK
Detiene la evaluación de los manejadores para esta traza específica, pero se deja que el demonio snmptrapd aplique manejadores globales.
NETSNMPTRAPD_HANDLER_FINISH
Detiene la búsqueda de otros manejadores adecuados.

Si una función de manejador no devuelve un valor adecuado o incluso nada, se asume que devuelve NETSNMPTRAPD_HANDLER_OK.

Las funciones se registran usando la función NetSNMP::TrapReceiver::register, que toma dos argumentos. El primero es una cadena que describe la notificación que deseas registrar (como "linkUp" o "MyMIB::MyTrap" o ".1.3.6.1.4.1.2021...."). Dos palabras clave especiales pueden usarse en lugar de un OID: "default" y "all". La palabra clave "default" indica que tu manejador será llamado en el caso donde ningún otro manejador se llama. La palabra clave "all" indica que el manejador debe ser llamado siempre que se reciba una notificación.

EJEMPLO

Como ejemplo, coloca el siguiente código en un archivo (digamos /usr/local/share/snmp/mytrapd.pl):

#!/usr/bin/perl
sub my_receiver {
    print "********** PERL RECIBIO UNA NOTIFICACIÓN:\n";
    # Imprimir la información del PDU (una referencia a un hash)
    print "PDU INFO:\n";
    foreach my $k(keys(%{$_[0]})) {
      if ($k eq "securityEngineID" || $k eq "contextEngineID") {
        printf "  %-30s 0x%s\n", $k, unpack('h*', $_[0]{$k});
      }
      else {
        printf "  %-30s %s\n", $k, $_[0]{$k};
      }
    }
    # Imprimir los enlaces de variables:
    print "VARBINDS:\n";
    foreach my $x (@{$_[1]}) {
        printf "  %-30s type=%-2d value=%s\n", $x->[0], $x->[2], $x->[1];
    }
}
NetSNMP::TrapReceiver::register("all", \&my_receiver) ||
  warn "failed to register our perl trap handler\n";
print STDERR "Loaded the example perl snmptrapd handler\n";

Luego, coloca la siguiente línea en tu archivo snmptrapd.conf:

perl do /usr/local/share/snmp/mytrapd.pl

Inicia snmptrapd (como root, y las siguientes opciones lo mantienen en primer plano y lo registran en stderr):

snmptrapd -f -Le

Deberías ver que se inicia y que muestra el mensaje final del script Perl mostrado anteriormente:

Loaded the perl snmptrapd handler
2004-02-11 10:08:45 NET-SNMP version 5.2 Started.

Luego, si envías una traza falsa a ti mismo usando el siguiente comando de ejemplo:

snmptrap -v 2c -c mycommunity localhost 0 linkUp ifIndex.1 i 1 \
    ifAdminStatus.1 i up ifOperStatus.1 i up ifDescr s eth0

Deberías ver la siguiente salida aparecer desde snmptrapd mientras se ejecuta tu código Perl:

********** PERL RECIBIO UNA NOTIFICACIÓN:
PDU INFO:
  notificationtype               TRAP
  receivedfrom                   127.0.0.1
  version                        1
  errorstatus                    0
  messageid                      0
  community                      mycommunity
  transactionid                  2
  errorindex                     0
  requestid                      765160220
VARBINDS:
  sysUpTimeInstance              type=67 value=0:0:00:00.00
  snmpTrapOID.0                  type=6  value=linkUp
  ifIndex.1                      type=2  value=1
  ifAdminStatus.1                type=2  value=1
  ifOperStatus.1                 type=2  value=1
  ifDescr                        type=4  value="eth0"

Pasar Argumentos

Si necesitas pasar argumentos a tu script, lo harás mediante uno de dos métodos:

Usando Subrutinas

Puedes definir una subrutina en el archivo o hacer que el archivo mismo haga algo. Por ejemplo, en el archivo si colocas:

sub foo {
   print $_[0];
}

y luego colocas estas líneas en el archivo snmptrapd.conf:

perl do /path/to/script
perl foo("hello world");
perl foo("now I am passing something different");

Ejecutará la función foo dos veces, e imprimirá los resultados en la consola donde se inició snmptrapd.

Usando Variables

O podrías siempre definir una variable antes:

perl $myVariable = 42;
perl do /path/to/script

Y el script buscará y usará el valor $myVariable en el script.
