Net::LDAP::Control::PostRead(3) Documentación de Perl aportada por el usuario Net::LDAP::Control::PostRead(3)

NOMBRE

Net::LDAP::Control::PostRead - Objeto de control Post-Read de LDAPv3

SINOPSIS

use Net::LDAP;
use Net::LDAP::Control::PostRead;
use Net::LDAP::Constant qw( LDAP_CONTROL_POSTREAD LDAP_SUCCESS );
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$postread = Net::LDAP::Control::PostRead->new( attrs => [ qw/givenName/ ] );
my $mesg = $ldap->modify( "cn=Barbara Jensen, o=University of Michigan, c=US",
                          replace => { givenName => "Babs" },
                          control => $postread );
if ($mesg->code eq LDAP_SUCCESS) {
  my ($afterwards) = $mesg->control( LDAP_CONTROL_PREREAD );
  my $entry = $afterwards ? $afterwards->entry() : undef;
  if ($entry) {
    print "givenName changed to '" .
          join("', '", $entry->get_value(givenName") .
          "' to 'Babs'\n");
  }
}

DESCRIPCIÓN

"Net::LDAP::Control::PostRead" proporciona una interfaz para la creación y manipulación de objetos que representan los "Controles Post-Read" tal como se describen en el RFC 4527.

En las operaciones de modificación, el "control de solicitud Post-Read" indica al servidor que se debe devolver una copia de la entrada modificada después de la actualización. Después de la finalización exitosa de la operación, el "control de respuesta Post-Read" adjunto permite recuperar el valor actualizado de la respuesta del servidor.

Un caso de uso de este control puede ser la obtención de los valores de atributos operacionales, tales como los atributos "entryUUID" y "modifyTimestamp", actualizados por el servidor como parte de la operación de actualización.

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control, se proporcionan los siguientes.

attrs => [ ATTR, ... ]
Una lista de atributos que se devolverán en la entrada devuelta en el control de respuesta.

Si está ausente, se devuelven todos los atributos.

Los atributos operacionales pueden incluirse en la lista pidiéndolos explícitamente o utilizando la función especial "+" (siempre que el servidor admita esta función).

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método sobre el objeto, que devolverá el valor actual del atributo si se llama sin argumento, y establecerá un nuevo valor para el atributo si se llama con un argumento.

Además de estos métodos, el control también admite el siguiente método:

entry ()
Devuelve la entrada del control de respuesta en el mensaje de respuesta a la solicitud LDAP que contenía el control de solicitud.

El resultado es un objeto Net::LDAP::Entry o indefinido.
