Net::IDN::Overview(3) Documentación de Perl aportada por el usuario Net::IDN::Overview(3)

NOMBRE

Net::IDN::Overwiew - Nombres de dominio internacionalizados para aplicaciones (IDNA)

DESCRIPCIÓN

Los módulos "Net::IDN::*" proporcionan un framework para el manejo de Nombres de Dominio Internacionalizados para Aplicaciones (IDNA) en programas perl.

Este documento proporciona una visión general de los módulos disponibles para permitirle elegir el mejor módulo para la tarea en cuestión.

MÓDULOS DISPONIBLES

ALTO NIVEL (USA ESTO)

Net::IDN::Encode
proporciona una interfaz de alto nivel para convertir nombres de dominio (y por conveniencia, direcciones de correo electrónico).

Utiliza este módulo si solo quieres convertir nombres de dominio y no te importa cómo se hace internamente.

Actualmente, este módulo utiliza Net::IDN::UTS46. Sin embargo, esto podría cambiar en el futuro si otra especificación (por ejemplo, una revisión de IDNA2008) se vuelve más apropiada.

El autor tiene como objetivo que Net::IDN::Encode utilice siempre la especificación que proporcionará los resultados "menos sorprendentes".

ESPECÍFICO DEL ESTÁNDAR

Estos módulos implementan diferentes versiones de las especificaciones IDNA. Utiliza uno de estos módulos solo si requieres compatibilidad con una incarnación específica de IDNA.

Net::IDN::IDNA2003
implementa la especificación original de IDNA, publicada en 2003 (IDNA2003), que ahora está obsoleta.

IDNA2003 se define en la RFC 3490 http://tools.ietf.org/rfc/3490 y documentos relacionados.

Net::IDN::UTS46
implementa el Estándar Técnico Unicode #46 (UTS #46 http://unicode.org/reports/tr46/), Procesamiento de Compatibilidad IDNA Unicode. Esta especificación admite todos los nombres de dominio permitidos bajo IDNA2003 o IDNA2008.

CODIFICACIÓN

Net::IDN::Punycode
realiza la conversión real entre la forma ASCII y Unicode de las cadenas. Punycode se define en la RFC 3492 http://tools.ietf.org/rfc/3492 y documentos relacionados.

Por lo general, no es una buena idea usar este módulo directamente. Si conviertes etiquetas de dominio (u otras cadenas) sin la preparación adecuada, puedes terminar con una codificación ASCII que no sea interoperable o que plantee problemas de seguridad debido a la suplantación de identidad.

Incluso si crees que tus nombres de dominio son válidos y están en formato ya mapeado, puedes ser engañado por diferentes formas de normalización Unicode (por ejemplo, algunos entornos podrían convertir automáticamente tus datos a NFD, lo que rompe IDNA).

OBSOLETO/COMPATIBILIDAD

Estos módulos solo se mantienen para no romper aplicaciones que podrían depender de ellos.

Encode::Punycode
proporciona un plugin Encode para Punycode. Como Punycode no es una codificación de propósito general, tiene aplicaciones limitadas.
IDNA::Punycode
tiene una API que depende de variables globales. No uses este módulo.

DISTRIBUCIONES

Net-IDN-Encode
es la distribución principal que cubre los casos más comunes para convertir nombres de dominio entre ASCII y Unicode.

El autor intenta mantener la cadena de dependencias lo más pequeña posible; actualmente esta distribución solo depende de perl 5.8.5 (incluyendo el módulo central Unicode::Normalize).

Net-IDN-IDNA2003
proporciona el módulo Net::IDN::IDNA2003. Esto es independiente porque tiene una dependencia de Unicode::Stringprep (a través de Net::IDN::Nameprep).
Encode-Punycode
IDNA-Punycode
son independientes porque son de uso limitado para el usuario promedio/programador de perl.
