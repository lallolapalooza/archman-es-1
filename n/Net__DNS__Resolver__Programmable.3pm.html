NOMBRE

Net::DNS::Resolver::Programmable - Clase de resolver DNS programable para emulación offline de DNS

SINOPSIS

use Net::DNS::Resolver::Programmable;
use Net::DNS::RR;

my $resolver = Net::DNS::Resolver::Programmable->new(
    records         => {
        'example.com'     => [
            Net::DNS::RR->new('example.com.     NS  ns.example.org.'),
            Net::DNS::RR->new('example.com.     A   192.168.0.1')
        ],
        'ns.example.org'  => [
            Net::DNS::RR->new('ns.example.org.  A   192.168.1.1')
        ]
    },

    resolver_code   => sub {
        my ($domain, $rr_type, $class) = @_;
        ...
        return ($result, $aa, @rrs);
    }
);

DESCRIPCIÓN

Net::DNS::Resolver::Programmable es una clase descendiente de Net::DNS::Resolver que permite emular un DNS virtual en lugar de consultar el DNS real. Se puede suministrar un conjunto de registros DNS estáticos, o se puede especificar código arbitrario como medio para recuperar registros DNS, o incluso generarlos sobre la marcha.

Constructor

Se proporciona el siguiente constructor:

new(%opciones): devuelve Net::DNS::Resolver::Programmable
Crea un nuevo objeto de resolver DNS programado.

%opciones es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

registros
Una referencia a un hash de arrays que contiene un conjunto estático de objetos Net::DNS::RR. Las claves del hash deben estar indexadas por nombres de dominio completamente calificados (en minúsculas, sin puntos finales), y las entradas en sí deben ser arrays de los objetos RR pertenecientes a estos nombres de dominio. Por ejemplo: 
records => {
    'example.com'     => [
        Net::DNS::RR->new('example.com.     NS  ns.example.org.'),
        Net::DNS::RR->new('example.com.     A   192.168.0.1')
    ],
    'www.example.com' => [
        Net::DNS::RR->new('www.example.com. A   192.168.0.2')
    ],
    'ns.example.org'  => [
        Net::DNS::RR->new('ns.example.org.  A   192.168.1.1')
    ]
}

Si se especifica esta opción, el resolver recupera los RR solicitados de esta estructura de datos.

resolver_code
Una referencia de código utilizada como una llamada de retorno para recuperar dinámicamente los RR solicitados.

El código debe tomar los siguientes parámetros de consulta como argumentos: el dominio, el tipo de RR y la clase.

Debe devolver una lista compuesta por: el RCODE de la respuesta (por nombre, como lo devuelve Net::DNS::Header->rcode), el indicador "aa" (respuesta autorizada) (booleano, use undef si no le importa), y los objetos Net::DNS::RR de respuesta. Si se devuelve una cadena de error en lugar de un RCODE válido, no se construirá un objeto Net::DNS::Packet, sino que se señalará una condición de error para el resolver.

Por ejemplo:

resolver_code => sub {
    my ($domain, $rr_type, $class) = @_;
    ...
    return ($result, $aa, @rrs);
}

Si se especifican tanto esta opción como la opción "records", entonces se utilizan los registros programados estáticamente además de los que se devuelvan por el código del resolver configurado.

defnames
dnsrch
domain
searchlist
debug
Estas opciones de Net::DNS::Resolver también son significativas con Net::DNS::Resolver::Programmable. Consulte Net::DNS::Resolver para ver sus descripciones.

Métodos de instancia

Los siguientes métodos de instancia de Net::DNS::Resolver también son compatibles con Net::DNS::Resolver::Programmable:

search: devuelve Net::DNS::Packet
query: devuelve Net::DNS::Packet
send: devuelve Net::DNS::Packet
Realiza una consulta DNS offline, utilizando los RR DNS programados estáticamente y/o el código del resolver dinámico configurado. Consulte las opciones "registros" y "resolver_code" del constructor "new". Consulte las descripciones de search, query y send para obtener detalles sobre la sintaxis de llamada de estos métodos.
print
string: devuelve cadena
searchlist: devuelve lista de cadenas
defnames: devuelve booleano
dnsrch: devuelve booleano
debug: devuelve booleano
errorstring: devuelve cadena
answerfrom: devuelve cadena
answersize: devuelve entero
Consulte "MÉTODOS" en Net::DNS::Resolver.

Actualmente, los siguientes métodos de Net::DNS::Resolver **no** son compatibles: axfr, axfr_start, axfr_next, nameservers, port, srcport, srcaddr, bgsend, bgread, bgisready, tsig, retrans, retry, recurse, usevc, tcp_timeout, udp_timeout, persistent_tcp, persistent_udp, igntc, dnssec, cdflag, udppacketsize. Los efectos de usar estos en objetos Net::DNS::Resolver::Programmable no están definidos.
