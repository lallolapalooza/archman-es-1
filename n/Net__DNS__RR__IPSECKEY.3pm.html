NOMBRE

Net::DNS::RR::IPSECKEY - Registro de recursos IPSECKEY de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre IPSECKEY precedencia tipogate algoritmo gateway clave');

DESCRIPCIÓN

Registros de recursos de Almacenamiento de Claves IPSEC (IPSECKEY) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de funciones no documentadas del paquete o el acceso directo a estructuras de datos internas, ya que podrían provocar la terminación del programa u otros comportamientos impredecibles.

precedencia

$precedencia = $rr->precedence;
$rr->precedence( $precedencia );

Esta es una precedencia de 8 bits para este registro. Las puertas de enlace enumeradas en los registros IPSECKEY con menor precedencia deben ser intentadas primero.

tipogate

$tipogate = $rr->gatetype;

El campo tipo de puerta de enlace indica el formato de la información que se almacena en el campo puerta de enlace.

algoritmo

$algoritmo = $rr->algorithm;
$rr->algorithm( $algoritmo );

El campo tipo de algoritmo identifica el algoritmo criptográfico de las claves públicas y determina el formato del campo de la clave pública.

puerta_de_enlace

$puerta_de_enlace = $rr->gateway;
$rr->gateway( $puerta_de_enlace );

El campo puerta de enlace indica una puerta de enlace a la que se puede crear un túnel IPsec para llegar a la entidad nombrada por este registro de recursos.

clave_publica

clave

$clave = $rr->key;
$rr->key( $clave );

Representación Base64 del bloque de clave pública opcional para el registro de recursos.

clavebin

$clavebin = $rr->keybin;
$rr->keybin( $clavebin );

Representación binaria del bloque de clave pública para el registro de recursos.
