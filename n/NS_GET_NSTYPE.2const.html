NS_GET_NSTYPE(2const) NS_GET_NSTYPE(2const)

NOMBRE

NS_GET_NSTYPE - descubrir el tipo de espacio de nombres

SINOPSIS

#include <linux/nsfs.h>  /* Definición de NS_GET_NSTYPE */
#include <sys/ioctl.h>
int ioctl(int fd, NS_GET_NSTYPE);

DESCRIPCIÓN

La operación NS_GET_NSTYPE se puede utilizar para descubrir el tipo de espacio de nombres al que se refiere el descriptor de archivo fd.

fd se refiere a un archivo de /proc/pid/ns/*.

VALOR DE RETORNO

En caso de éxito, el valor de retorno es uno de los valores CLONE_NEW* que se pueden especificar a clone(2) o unshare(2) para crear un espacio de nombres.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 4.11.

VER TAMBIÉN

ioctl(2), ioctl_nsfs(2)
