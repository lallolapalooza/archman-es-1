Net::NNTP(3perl) Guía de referencias para programadores Perl Net::NNTP(3perl)

NOMBRE

Net::NNTP - Cliente NNTP (clase)

SINOPSIS

use Net::NNTP;
$nntp = Net::NNTP->new("some.host.name");
$nntp->quit;
# iniciar con SSL, por ejemplo nntps
$nntp = Net::NNTP->new("some.host.name", SSL => 1);
# iniciar con plano y migrar a SSL
$nntp = Net::NNTP->new("some.host.name");
$nntp->starttls;

DESCRIPCIÓN

"Net::NNTP" es una clase que implementa un cliente simple NNTP (como se describe en RFC977 y RFC4642). Con IO::Socket::SSL instalado, también ofrece soporte para encriptación TLS implícita y explícita, es decir, NNTPS o NNTP+STARTTLS.

La clase Net::NNTP es una subclase de Net::Cmd y (según disponibilidad) de IO::Socket::IP, IO::Socket::INET6 o IO::Socket::INET.

Métodos de clase

"new([$host][, %opciones])"
Este es el constructor de un objeto Net::NNTP. $host es el nombre del host remoto al que conectarse. Si no se proporciona, puede pasarse como la opción "Host" descrita a continuación. Si no se proporciona ningún host, primero se buscará "NNTPSERVER" y luego "NEWSHOST", y si no se encuentra, se usará "news".

%opciones se pasan como pares clave-valor. Las opciones posibles incluyen:

Host - El host NNTP al que conectarse. Puede ser un escalar simple, como se define para el par "PeerAddr" en IO::Socket::INET, o una referencia a un array de hosts para probar en orden. El método "host" devolverá el valor que se utilizó para conectarse al host.

Port - El puerto al que conectarse. Por defecto es 119 para NNTP plano y 563 para conexión SSL inmediata (nntps).

SSL - Si la conexión debe iniciarse con SSL, en lugar de migrar a SSL posteriormente con "starttls". Se pueden utilizar los argumentos SSL como se documenta en IO::Socket::SSL, pero generalmente los argumentos correctos se pasarán aquí de todos modos.

Timeout - Tiempo máximo en segundos para esperar una respuesta del servidor NNTP. Un valor de cero hará que todas las operaciones de I/O sean bloqueantes. (Valor por defecto: 120)

Debug - Habilita la impresión de información de depuración en STDERR.

Reader - Si el servidor remoto es INN, inicialmente la conexión se conectará a innd, por defecto "Net::NNTP" emitirá un comando "MODE READER" para que el servidor remoto se convierta en nnrpd. Si se pasa el par "Reader" con un valor de cero, este comando no se enviará y la conexión se dejará hablando con innd.

LocalAddr y LocalPort - Estos parámetros se pasan directamente a IO::Socket y permiten la asignación del socket a un puerto local específico.

Domain - Este parámetro se pasa directamente a IO::Socket y permite forzar conexiones IPv4 incluso si se utiliza IO::Socket::IP como superclase. Alternativamente, se puede usar Family.

Métodos de objeto

A menos que se indique lo contrario, todos los métodos devuelven un valor verdadero o falso, donde verdadero indica que la operación fue exitosa. Cuando un método indica que devuelve un valor, el fallo será devuelto como undef o una lista vacía.

"Net::NNTP" hereda de "Net::Cmd", por lo que los métodos definidos en "Net::Cmd" pueden usarse para enviar comandos al servidor NNTP además de los métodos documentados aquí.

host()
Devuelve el valor utilizado por el constructor y pasado a IO::Socket::INET para conectarse al host.
starttls()
Actualiza la conexión existente de plano a SSL. Cualquier argumento necesario para SSL debe haberse proporcionado ya en "new".
"article([{$msgid|$msgnum}[, $fh]])"
Recupera la cabecera, una línea en blanco y luego el cuerpo (texto) del artículo especificado. Si se especifica $fh, se espera que sea un descriptor de archivo válido y el resultado se imprimirá allí; en caso de éxito, se devuelve un valor verdadero. Si $fh no se especifica, el valor devuelto, en caso de éxito, será un array que contiene el artículo solicitado, cada entrada del array contendrá una línea del artículo.

Si no se proporcionan argumentos, se recupera el artículo actual del grupo seleccionado actualmente.

$msgnum es un ID numérico de un artículo en el grupo actual y cambiará el puntero al artículo actual. $msgid es el identificador del artículo tal como aparece en la cabecera del artículo. Se espera que el cliente obtenga el $msgid de una lista proporcionada por el comando "newnews", de referencias contenidas en otro artículo, o del ID del mensaje en la respuesta a algún otro comando.

Si hay un error, se devolverá undef.

El comando "body" recupera solo el cuerpo del artículo.
El comando "head" recupera solo las cabeceras del artículo.
Estos son similares a article(), body() y head(), pero en lugar de devolver los datos solicitados directamente, devuelven un descriptor de archivo abierto asociado a un objeto tied.
"nntpstat" es similar al comando "article", pero no devuelve texto. Cuando se selecciona por número de mensaje dentro de un grupo, el comando "nntpstat" se utiliza para establecer el puntero al artículo actual sin enviar texto.

Utilizar el comando "nntpstat" para seleccionar por ID de mensaje es válido pero de valor incierto, ya que una selección por ID de mensaje no altera el puntero al artículo actual.

Devuelve el ID del artículo actual.

"group" ([$group])
Establece y/o obtiene el grupo actual. Si no se especifica $group, se devuelve información sobre el grupo actual.

En un contexto escalar, devuelve el nombre del grupo.

En un contexto de array, el valor devuelto es una lista que contiene: el número de artículos en el grupo, el número del primer artículo, el número del último artículo y el nombre del grupo.

"help"
Solicita texto de ayuda (resumen de comandos entendidos por esta implementación) del servidor. Devuelve el texto o undef en caso de fallo.
"ihave" ([$msgid[, $message])
El comando "ihave" informa al servidor que el cliente tiene un artículo cuyo ID es $msgid. Si el servidor desea una copia de ese artículo y se ha proporcionado $message, se enviará. Si se especifica, devuelve verdadero si el servidor deseaba el artículo y $message se envió con éxito.

METHODS

article([$message_id])
Fetches the specified article. If $message_id is not specified then the article will be fetched using the current article pointer.

Returns a Net::NNTP::Article object.

body([$message_id])
Fetches the specified article's body. If $message_id is not specified then the article body will be fetched using the current article pointer.

Returns a reference to an array of lines in the body.

group($group)
Selects the specified newsgroup. $group can be either a group name or a group number.

Returns a list of three items: the number of articles in the group, the first article number, and the last article number.

headers([$message_id])
Fetches the specified article's headers. If $message_id is not specified then the article headers will be fetched using the current article pointer.

Returns a reference to an array of lines in the headers.

help()
Returns a list of the commands supported by the remote NNTP server.
post([$message])
Post a new article to the news server. If $message is specified and posting is allowed then the message will be sent.

If $message is not specified then the message must be sent using the "datasend" and "dataend" methods from Net::Cmd

$message can be either an array of lines or a reference to an array and must be encoded by the caller to octets of whatever encoding is required, e.g. by using the Encode module's encode() function.

The message, either sent via "datasend" or as the $message parameter, must be in the format as described by RFC822 and must contain From:, Newsgroups: and Subject: headers.

last()
Set the "current article pointer" to the previous article in the current newsgroup.

Returns the message-id of the article.

date()
Returns the date on the remote server. This date will be in a UNIX time format (seconds since 1970)
postok()
"postok" will return true if the servers initial response indicated that it will allow posting.
"authinfo($user, $pass)"
Authenticates to the server (using the original AUTHINFO USER / AUTHINFO PASS form, defined in RFC2980) using the supplied username and password. Please note that the password is sent in clear text to the server. This command should not be used with valuable passwords unless the connection to the server is somehow protected.
"authinfo_simple($user, $pass)"
Authenticates to the server (using the proposed NNTP V2 AUTHINFO SIMPLE form, defined and deprecated in RFC2980) using the supplied username and password. As with "authinfo" the password is sent in clear text.
list()
Obtain information about all the active newsgroups. The results is a reference to a hash where the key is a group name and each value is a reference to an array. The elements in this array are:- the last article number in the group, the first article number in the group and any information flags about the group.
"newgroups($since[, $distributions])"
$since is a time value and $distributions is either a distribution pattern or a reference to a list of distribution patterns. The result is the same as "list", but the groups return will be limited to those created after $since and, if specified, in one of the distribution areas in $distributions.
"newnews($since[, $groups[, $distributions]])"
$since is a time value. $groups is either a group pattern or a reference to a list of group patterns. $distributions is either a distribution pattern or a reference to a list of distribution patterns.

Returns a reference to a list which contains the message-ids of all news posted after $since, that are in a groups which matched $groups and a distribution which matches $distributions.

next()
Set the "current article pointer" to the next article in the current newsgroup.

Returns the message-id of the article.

post([$message])
Post a new article to the news server. If $message is specified and posting is allowed then the message will be sent.

If $message is not specified then the message must be sent using the "datasend" and "dataend" methods from Net::Cmd

$message can be either an array of lines or a reference to an array and must be encoded by the caller to octets of whatever encoding is required, e.g. by using the Encode module's encode() function.

The message, either sent via "datasend" or as the $message parameter, must be in the format as described by RFC822 and must contain From:, Newsgroups: and Subject: headers.

postfh()
Post a new article to the news server using a tied filehandle. If posting is allowed, this method will return a tied filehandle that you can print() the contents of the article to be posted. You must explicitly close() the filehandle when you are finished posting the article, and the return value from the close() call will indicate whether the message was successfully posted.
slave()
Tell the remote server that I am not a user client, but probably another news server.
quit()
Quit the remote server and close the socket connection.
can_inet6()
Returns whether we can use IPv6.
can_ssl()
Returns whether we can use SSL.

Extension Methods

These methods use commands that are not part of the RFC977 documentation. Some servers may not support all of them.

newsgroups([$pattern])
Returns a reference to a hash where the keys are all the group names which match $pattern, or all of the groups if no pattern is specified, and each value contains the description text for the group.
distributions()
Returns a reference to a hash where the keys are all the possible distribution names and the values are the distribution descriptions.
distribution_patterns()
Returns a reference to an array where each element, itself an array reference, consists of the three fields of a line of the distrib.pats list maintained by some NNTP servers, namely: a weight, a wildmat and a value which the client may use to construct a Distribution header.
subscriptions()
Returns a reference to a list which contains a list of groups which are recommended for a new user to subscribe to.
overview_fmt()
Returns a reference to an array which contain the names of the fields returned by "xover".
active_times()
Returns a reference to a hash where the keys are the group names and each value is a reference to an array containing the time the groups was created and an identifier, possibly an Email address, of the creator.
active([$pattern])
Similar to "list" but only active groups that match the pattern are returned. $pattern can be a group pattern.
xgtitle($pattern)
Returns a reference to a hash where the keys are all the group names which match $pattern and each value is the description text for the group.
"xhdr($header, $message_spec)"
Obtain the header field $header for all the messages specified.

The return value will be a reference to a hash where the keys are the message numbers and each value contains the text of the requested header for that message.

xover($message_spec)
The return value will be a reference to a hash where the keys are the message numbers and each value contains a reference to an array which contains the overview fields for that message.

The names of the fields can be obtained by calling "overview_fmt".

xpath($message_id)
Returns the path name to the file on the server which contains the specified message.
"xpat($header, $pattern, $message_spec)"
The result is the same as "xhdr" except the is will be restricted to headers where the text of the header matches $pattern
xrover($message_spec)
The XROVER command returns reference information for the article(s) specified.

Returns a reference to a HASH where the keys are the message numbers and the values are the References: lines from the articles

listgroup([$group])
Returns a reference to a list of all the active messages in $group, or the current group if $group is not specified.
reader()
Tell the server that you are a reader and not another server.

This is required by some servers. For example if you are connecting to an INN server and you have transfer permission your connection will be connected to the transfer daemon, not the NNTP daemon. Issuing this command will cause the transfer daemon to hand over control to the NNTP daemon.

Some servers do not understand this command, but issuing it and ignoring the response is harmless.

Net::NNTP(3perl) - Perl documentation

NAME

Net::NNTP - Perl extension for writing NNTP clients.

SYNOPSIS

 use Net::NNTP;

 my $connection = Net::NNTP->new(
     Hostname        => 'news.example.com',
     Port            => 119,
     User            => 'your_username',
     Password        => 'your_password',
     Timeout         => 60,
     Debug           => 1,
 );

 # ... do stuff with $connection ...

 $connection->quit;

DESCRIPTION

The Net::NNTP module implements a client interface to the NNTP protocol as defined in RFC 977.

It allows a Perl program to connect to an NNTP server and retrieve articles, post articles and manage newsgroups.

The module is implemented as a subclass of Net::Cmd.

The Net::NNTP methods return undef on failure unless otherwise specified.

Methods that may fail will return an error code as the first element of a list on failure. On success they will return the status code (usually 2xx) as the first element of the list.

The following methods are available:

$connection = Net::NNTP->new( %args )
Constructs a new Net::NNTP object and attempts to connect to the NNTP server specified by the arguments. The following arguments are supported:
Hostname
The hostname or IP address of the NNTP server. Defaults to "localhost".
Port
The port number to connect to. Defaults to the NNTP port (usually 119).
User
The username for authentication. If not specified, no attempt will be made to authenticate.
Password
The password for authentication. If not specified, no attempt will be made to authenticate.
Timeout
The timeout in seconds for network operations. Defaults to 300 seconds.
Debug
If set to a true value, debugging information will be printed to STDOUT.
$connection->connect( $host, $port )
Connects to the NNTP server at the given $host and $port.
$connection->help()
Requests help information from the server.
$connection->post( $article )
Posts a single article to the server.
$connection->list( $newsgroups )
Lists the specified newsgroups. If $newsgroups is not specified, all newsgroups are listed.
$connection->group( $group )
Selects the specified $group. Returns the number of articles in the group, the first and last article numbers.
$connection->stat( $message_spec )
Returns information about the article specified by $message_spec without retrieving the article body.
$connection->next()
Selects the next article in the current group.
$connection->last()
Selects the previous article in the current group.
$connection->article( $message_spec )
Retrieves the specified article.
$connection->head( $message_spec )
Retrieves the head of the specified article.
$connection->body( $message_spec )
Retrieves the body of the specified article.
$connection->quit()
Disconnects from the server.

The $message_spec argument can be a message ID string or a message number. A range of messages can be specified as a list of two numbers, or as a reference to a list of two numbers. If the first number in the range is equal to the last number in the range, then the range represents only that single message. If the first number in the range is less than the last number in the range, then the range represents all messages between the first and last message numbers, inclusive. If the first number is greater than the last number, it is assumed that the first number is the first message in the group and the range represents all messages in the group after the first message number.

NOTE For compatibility reasons only with earlier versions of Net::NNTP a message spec can be passed as a list of two numbers, this is deprecated and a reference to the list should now be passed

The NNTP protocol uses the WILDMAT format for patterns. The WILDMAT format was first developed by Rich Salz based on the format used in the UNIX "find" command to articulate file names. It was developed to provide a uniform mechanism for matching patterns in the same manner that the UNIX shell matches filenames.

Patterns are implicitly anchored at the beginning and end of each string when testing for a match.

There are five pattern matching operations other than a strict one-to-one match between the pattern and the source to be checked for a match.

The first is an asterisk "*" to match any sequence of zero or more characters.

The second is a question mark "?" to match any single character. The third specifies a specific set of characters.

The set is specified as a list of characters, or as a range of characters where the beginning and end of the range are separated by a minus (or dash) character, or as any combination of lists and ranges. The dash can also be included in the set as a character it if is the beginning or end of the set. This set is enclosed in square brackets. The close square bracket "]" may be used in a set if it is the first character in the set.

The fourth operation is the same as the logical not of the third operation and is specified the same way as the third with the addition of a caret character "^" at the beginning of the test string just inside the open square bracket.

The final operation uses the backslash character to invalidate the special meaning of an open square bracket "[", the asterisk, backslash or the question mark. Two backslashes in sequence will result in the evaluation of the backslash as a character with no special meaning.
