NOMBRE

Net::LDAP::Extension::WhoAmI - Operación de extensión LDAP "Who am I?"

SINOPSIS

use Net::LDAP;
use Net::LDAP::Extension::WhoAmI;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$ldap->bind('cn=Joe User,cn=People,dc=example,dc=com",
            password => 'secret');
$mesg = $ldap->who_am_i();
die "error: ", $mesg->code(), ": ", $mesg->error()  if ($mesg->code());
print "you are bound with authzId ", $mesg->response(), "\n";

DESCRIPCIÓN

"Net::LDAP::Extension::WhoAmI" implementa la operación extendida LDAPv3 "Who am I?" descrita en RFC 4532.

No implementa ningún objeto por sí mismo, sino que extiende el objeto Net::LDAP con otro método:

MÉTODOS

who_am_i
Obtiene la identidad de autorización que el servidor ha asociado con la entidad de usuario o aplicación.

VER TAMBIÉN

Net::LDAP, Net::LDAP::Extension
