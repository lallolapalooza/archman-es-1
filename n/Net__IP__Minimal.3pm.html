Net::IP::Minimal(3) Documentación de Perl contribuida por el usuario Net::IP::Minimal(3)

NOMBRE

Net::IP::Minimal - Funciones mínimas de Net::IP

VERSIÓN

versión 0.06

SINOPSIS

use Net::IP::Minimal qw[:PROC];
my $ip = '172.16.0.216';
ip_is_ipv4( $ip ) and print "$ip es IPv4";
$ip = 'dead:beef:89ab:cdef:0123:4567:89ab:cdef';
ip_is_ipv6( $ip ) and print "$ip es IPv6";
print ip_get_version( $ip );

DESCRIPCIÓN

Net::IP es muy completo en cuanto a características, pero descubrí que solo estaba usando tres de sus funciones y consume bastante memoria https://rt.cpan.org/Public/Bug/Display.html?id=24525.

Este módulo solo proporciona el número mínimo de funciones que uso en mis módulos.

FUNCIONES

Igual que Net::IP, estas funciones no se exportan por defecto. Puedes importarlas explícitamente o usar ":PROC" para importarlas todas.

"ip_get_version"
Intenta adivinar la versión de IP de una dirección IP. 
Parámetros  : Dirección IP
Retorna     : 4, 6, undef (no se puede determinar)

"$version = ip_get_version ($ip)"

"ip_is_ipv4"
Comprueba si una dirección IP es de tipo 4. 
Parámetros  : Dirección IP
Retorna     : 1 (sí) o 0 (no)

"ip_is_ipv4($ip) and print "$ip es IPv4";"

"ip_is_ipv6"
Comprueba si una dirección IP es de tipo 6. 
Parámetros            : Dirección IP
Retorna               : 1 (sí) o 0 (no)

"ip_is_ipv6($ip) and print "$ip es IPv6";"
