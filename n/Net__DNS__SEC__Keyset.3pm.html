Net::DNS::SEC::Keyset(3) Documentación contribuida por el usuario de Perl Net::DNS::SEC::Keyset(3)

NOMBRE

Net::DNS::SEC::Keyset - Objeto de clase de conjunto de claves DNSSEC

SINTAXIS

use Net::DNS::SEC::Keyset;

DESCRIPCIÓN

Un conjunto de claves es una unidad administrativa utilizada para la mantenimiento de DNSSEC.

Esta clase proporciona interfaces para crear, leer y escribir conjuntos de claves.

Se proporcionan métodos de objeto para extraer registros de DNSKEY, RRSIG y DS.

Nota: Esta clase aún está en desarrollo. Atributos y métodos son sujetos a cambios.

new (de archivo)

$keyset = Net::DNS::SEC::Keyset->new( $filename );
$keyset = Net::DNS::SEC::Keyset->new( $filename, $directory );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Método de constructor que lee el archivo de conjunto de claves especificado y devuelve un objeto de conjunto de claves.

El argumento opcional segundo especifica el directorio base del archivo de nombre.

Establece keyset_err y devuelve undef en caso de error.

new (por claves firmadas)

$keyset = Net::DNS::SEC::Keyset->new( [@keyrr], $privatekeypath );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Crea un objeto de conjunto de claves a partir de las claves proporcionadas a través de una referencia a un array de objetos Net::DNS::RR::DNSKEY.

El método creará y firmará el conjunto completo de claves. Las claves privadas generadas con el herramienta BIND dnssec-keygen son asumidas estar en la carpeta actual o, si especificada, en la carpeta indicada por $privatekeypath.

Establece keyset_err y devuelve undef en caso de error.

new (de clave y RRsets firmados)

$keyset = Net::DNS::Keyset->new( [@keyrr], [@sigrr] );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Crea un objeto de conjunto de claves a partir de las claves proporcionadas a través de referencias a arrays de objetos Net::DNS::RR::DNSKEY y Net::DNS::RR::RRSIG.

Establece keyset_err y devuelve undef en caso de error.

new (de paquete)

$resolver = Net::DNS::Resolver->new;
$resolver->dnssec(1);

$reply = $res->send ( "example.com", "DNSKEY" );
$keyset = Net::DNS::SEC::Keyset->new( $reply );
die Net::DNS::SEC::Keyset->keyset_err unless $keyset;

Crea un objeto de conjunto de claves a partir de un paquete Net::DNS::Packet que contiene la respuesta a una consulta para registros de clave en el punto de apéndice del dominio.

Este es el método que deberías usar para obtener las claves automáticamente.

Establece keyset_err y devuelve undef en caso de error.

clave

@keyrr = $keyset->keys;

Devuelve un array de objetos Net::DNS::RR::DNSKEY.

firmas

@sigrr = $keyset->sigs;

Devuelve un array de objetos Net::DNS::RR::RRSIG.

extraer_ds

@ds = $keyset->extract_ds();        # por defecto SHA-1
@ds = $keyset->extract_ds( digtype => 'SHA-256' );
die Net::DNS::SEC::Keyset->keyset_err unless @ds;

Extrae registros DS del conjunto de claves. Nota: El conjunto de claves se verificará durante la extracción. Todos los claves necesitarán una firma válida de auto-firma.

El método establece keyset_err si la verificación falla.

verificar

@keytags = $keyset->verify();
die Net::DNS::SEC::Keyset->keyset_err unless @keytags;
$keyset->verify( $keytag ) || die $keyset->keyset_err;

Si no se dan argumentos:

  • Verifica si todas las firmas presentes verifican el conjunto de claves.
  • Verifica si hay DNSKEYs con el flag SEP activo, hay al menos una RRSIG firmada con esa clave.
  • Verifica que si no hay DNSKEYs con el flag SEP activo, hay al menos una RRSIG firmada con una de las claves del conjunto de claves.

Si se proporciona un argumento, debe ser el número de etiqueta de clave en el conjunto de claves que se verificará con la correspondiente RRSIG.

El método devuelve una lista de etiquetas de claves verificadas en el conjunto de claves.

El método establece keyset_err y devuelve una lista vacía si la verificación falla.

keyset_err

$keyset_err = Net::DNS::SEC::Keyset->keyset_err;

Devuelve la cadena de error del conjunto de claves.

string

$string = $keyset->string;

Devuelve una representación cadena del conjunto de claves.

print

$keyset->print;             # similar a print( $keyset->string )

Imprime el conjunto de claves.

writekeyset

$keyset->writekeyset;
$keyset->writekeyset( $path );
$keyset->writekeyset( $prefix );
$keyset->writekeyset( $prefix, $path );

Escribe el conjunto de claves en un archivo denominado "keyset-" en la carpeta de trabajo actual o en la carpeta definida por el argumento opcional $path.

El argumento opcional $prefix especifica el prefijo que se añadirá al nombre del dominio para formar el nombre del archivo del conjunto de claves.
