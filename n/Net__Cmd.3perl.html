Net::Cmd(3perl) Guía de referencia para programadores de Perl Net::Cmd(3perl)

NOMBRE

Net::Cmd - Clase de comandos de red (como la usan FTP, SMTP etc)

SINOPSIS

use Net::Cmd;
@ISA = qw(Net::Cmd);

DESCRIPCIÓN

"Net::Cmd" es una colección de métodos que pueden ser heredados por una subclase de "IO::Socket::INET". Estos métodos implementan la funcionalidad requerida para un protocolo basado en comandos, por ejemplo FTP y SMTP.

Si su subclase no deriva también de "IO::Socket::INET" o similar (por ejemplo, "IO::Socket::IP", "IO::Socket::INET6" o "IO::Socket::SSL") entonces debe proporcionar los siguientes métodos por otros medios usted mismo: close() y timeout().

Métodos Públicos

Estos métodos proporcionan una interfaz de usuario para el objeto "Net::Cmd".

debug($level)
Establece el nivel de información de depuración para este objeto. Si no se proporciona $level, se devuelve el estado actual. De lo contrario, el estado se cambia a $level y se devuelve el estado anterior.

Diferentes paquetes pueden implementar diferentes niveles de depuración, pero un valor distinto de cero da como resultado que copias de todos los comandos y respuestas también se envíen a STDERR.

Si $level es "undef", el nivel de depuración se establecerá al nivel de depuración predeterminado para la clase.

Este método también se puede llamar como un método *estático* para establecer/obtener el nivel de depuración predeterminado para una clase dada.

message()
Devuelve el mensaje de texto devuelto por el último comando. En un contexto escalar, devuelve una sola cadena; en un contexto de lista, devolverá cada línea como un elemento separado. (Véase "RESPUESTAS PSEUDO" más abajo).
code()
Devuelve el código de 3 dígitos del último comando. Si un comando está pendiente, se devuelve el valor 0. (Véase "RESPUESTAS PSEUDO" más abajo).
ok()
Devuelve un valor distinto de cero si el último valor de código fue mayor que cero y menor que 400. Esto se cumple para la mayoría de los servidores de comandos. Los servidores donde esto no se cumple pueden anular este método.
status()
Devuelve el dígito más significativo del código de estado actual. Si un comando está pendiente, se devuelve "CMD_PENDING".
datasend($data)
Envía datos al servidor remoto, convirtiendo LF a CRLF. Cualquier línea que comience con un '.' se prefijará con otro '.'. $data puede ser un array o una referencia a un array. Los $data pasados deben ser codificados por el llamador a octetos de la codificación requerida, por ejemplo, usando la función encode() del módulo Encode.
dataend()
Finaliza el envío de datos al servidor remoto. Esto se hace asegurando que los datos ya enviados terminen con CRLF y luego enviando '.CRLF' para finalizar la transmisión. Una vez enviados estos datos, "dataend" llama a "response" y devuelve verdadero si "response" devuelve CMD_OK.

Métodos Protegidos

Estos métodos no están destinados a ser llamados por el usuario, sino que son utilizados o anulados por una subclase de "Net::Cmd"

"debug_print($dir, $text)"
Imprime información de depuración. $dir denota la dirección, siendo *verdadero* datos que se envían al servidor. Llama a "debug_text" antes de imprimir en STDERR.
"debug_text($dir, $text)"
Este método se llama para imprimir información de depuración. $text es el texto que se está enviando. El método debe devolver el texto que se va a imprimir.

Esto está diseñado principalmente para el uso de módulos como FTP, donde se envían contraseñas, pero no queremos mostrarlas en la información de depuración.

"command($cmd[, $args, ... ])"
Envía un comando al servidor de comandos. Todos los argumentos se unen primero con un espacio y se añade CRLF; esta cadena se envía luego al servidor de comandos.

Devuelve undef en caso de fallo.

unsupported()
Establece el código de estado a 580 y el texto de respuesta a 'Comando no soportado'. Devuelve cero.
response()
Obtiene una respuesta del servidor. En caso de éxito, devuelve el dígito más significativo del código de estado. En caso de fallo, tiempo de espera, etc., se devuelve *CMD_ERROR*.
parse_response($text)
Este método es llamado por "response" como un método con un argumento. Debe devolver un array de 2 valores, el código de estado de 3 dígitos y una bandera que es verdadera cuando esto es parte de una respuesta multilínea y esta línea no es la última.
getline()
Recupera una línea, delimitada por CRLF, del servidor remoto. Devuelve *undef* en caso de fallo.

NOTA: Si utiliza este método por alguna razón, recuerde agregar algunas llamadas a "debug_print" en su método.

ungetline($text)
Devuelve una línea de texto del servidor.
rawdatasend($data)
Envía datos al servidor remoto sin realizar ninguna conversión. $data es un escalar. Al igual que con datasend(), los $data pasados deben ser codificados por el llamador a octetos de la codificación requerida, por ejemplo, usando la función encode() del módulo Encode.
read_until_dot()
Lee datos del servidor remoto hasta encontrar una línea que consista en un solo '.'. Cualquier línea que comience con '..' tendrá uno de los '.' eliminado.

Devuelve una referencia a una lista que contiene las líneas, o *undef* en caso de fallo.

tied_fh()
Devuelve un manejador de archivo enlazado al objeto Net::Cmd. Después de emitir un comando, puede leer de este manejador de archivo usando read() o <>. El manejador de archivo devolverá EOF cuando se encuentre el punto final. De manera similar, puede escribir en el manejador de archivo para enviar datos al servidor después de emitir un comando que espera que se escriban datos.

Consulte los módulos Net::POP3 y Net::SMTP para ver ejemplos de esto.

Respuestas Pseudo

Normalmente, los valores devueltos por message() y code() se obtienen del servidor remoto, pero en algunas circunstancias, como se detalla a continuación, "Net::Cmd" devolverá valores que él mismo establece. Puede alterar este comportamiento anulando DEF_REPLY_CODE() para especificar un código de respuesta predeterminado diferente, o anulando uno de los métodos específicos de manejo de errores a continuación.

Valor inicial
Antes de que se ejecute cualquier comando o si ocurre un error inesperado, code() devolverá "421" (fallo temporal de conexión) y message() devolverá undef.
Conexión cerrada
Si el "IO::Handle" subyacente está cerrado, o si hay algún fallo de lectura o escritura, el manejador de archivo se cerrará forzosamente y

NAME

Net::Cmd - Base class for network protocol command objects

SYNOPSIS

    use Net::Cmd;
    @ISA = qw(Net::Cmd);
    sub cmd_name { 'cmd' }
    sub process_response {
        my ($self, $response, $fh) = @_;
        # Check $response for $self->{ok} or $self->{err} etc.
        return $response;
    }
    # ... etc ...

DESCRIPTION

This module provides a base class for implementing network protocol command objects. It handles the basic structure of sending a command and receiving a response. Subclasses will need to implement methods to define the command string, process the response, and handle specific status codes.

The methods code() and message() return the numeric code and the associated message of the last response received. These are typically set by Net::Cmd::process_response() or by helper methods like _set_status_ok().

Closing connection
If the connection is closed unexpectedly during a read or write operation, code() will return "421" (temporary connection failure) and message() will return "[$pkg] Connection closed" (where $pkg is the name of the class that subclassed "Net::Cmd"). The _set_status_closed() method can be overridden to set a different message (by calling set_status()) or otherwise trap this error.
Timeout
If there is a read or write timeout, code() will return "421" (temporary connection failure) and message() will return "[$pkg] Timeout" (where $pkg is the name of the class that subclassed "Net::Cmd"). The _set_status_timeout() method can be overridden to set a different message (by calling set_status()) or otherwise trap this error.

EXPORTS

The following symbols are, or can be, exported by this module:

Default Exports
"CMD_INFO", "CMD_OK", "CMD_MORE", "CMD_REJECT", "CMD_ERROR", "CMD_PENDING".

(These correspond to possible results of response() and status().)

Optional Exports
None.
Export Tags
None.
