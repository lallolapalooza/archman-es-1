Net::POP3(3perl) Guía de referencia para programadores de Perl Net::POP3(3perl)

NOMBRE

Net::POP3 - Clase de cliente del protocolo Post Office 3 (RFC1939)

SINOPSIS

use Net::POP3;
# Constructores
$pop = Net::POP3->new('pop3host');
$pop = Net::POP3->new('pop3host', Timeout => 60);
$pop = Net::POP3->new('pop3host', SSL => 1, Timeout => 60);
if ($pop->login($username, $password) > 0) {
  my $msgnums = $pop->list; # hashref de msgnum => tamaño
  foreach my $msgnum (keys %$msgnums) {
    my $msg = $pop->get($msgnum);
    print @$msg;
    $pop->delete($msgnum);
  }
}
$pop->quit;

DESCRIPCIÓN

Este módulo implementa una interfaz cliente al protocolo POP3, permitiendo a una aplicación perl5 comunicarse con servidores POP3. Esta documentación asume que usted está familiarizado con el protocolo POP3 descrito en el RFC1939. Con IO::Socket::SSL instalado, también proporciona soporte para cifrado TLS implícito y explícito, es decir, POP3S o POP3+STARTTLS.

Se debe crear un nuevo objeto Net::POP3 con el método new. Una vez hecho esto, todos los comandos POP3 se acceden a través de llamadas de método en el objeto.

La clase Net::POP3 es una subclase de Net::Cmd y (dependiendo de la disponibilidad) de IO::Socket::IP, IO::Socket::INET6 o IO::Socket::INET.

Métodos de clase

"new([$host][, %options])"
Este es el constructor para un nuevo objeto Net::POP3. $host es el nombre del host remoto al que se requiere una conexión POP3.

$host es opcional. Si $host no se proporciona, puede pasarse como la opción "Host" descrita a continuación. Si no se proporciona ninguno, se utilizarán los "POP3_Hosts" especificados en "Net::Config".

%options se pasan en un formato de hash, utilizando pares clave-valor. Las opciones posibles son:

Host - Host POP3 al que conectarse. Puede ser un escalar simple, como se define para la opción "PeerAddr" en IO::Socket::INET, o una referencia a una matriz con hosts para probar en orden. El método "host" devolverá el valor que se utilizó para conectarse al host.

Port - Puerto al que conectarse. Predeterminado: 110 para POP3 simple y 995 para POP3s (SSL directo).

SSL - Si la conexión debe realizarse desde el principio con SSL, en contraposición a una mejora posterior con "starttls". Puede usar argumentos SSL como se documenta en IO::Socket::SSL, pero normalmente utilizará los argumentos correctos ya.

LocalAddr y LocalPort - Estos parámetros se pasan directamente a IO::Socket para permitir enlazar el socket a una dirección y puerto local específicos. Para compatibilidad con versiones anteriores, se puede usar ResvPort en lugar de LocalPort.

Domain - Este parámetro se pasa directamente a IO::Socket y permite forzar conexiones IPv4 incluso si IO::Socket::IP se usa como clase base. Alternativamente, se puede usar Family.

Timeout - Tiempo máximo, en segundos, para esperar una respuesta del servidor POP3 (predeterminado: 120)

Debug - Habilita información de depuración

Métodos de objeto

A menos que se indique lo contrario, todos los métodos devuelven un valor *verdadero* o *falso*, donde *verdadero* significa que la operación fue exitosa. Cuando un método indica que devuelve un valor, el fallo se devolverá como *undef* o una lista vacía.

"Net::POP3" hereda de "Net::Cmd", por lo que los métodos definidos en "Net::Cmd" se pueden usar para enviar comandos al servidor POP3 remoto además de los métodos documentados aquí.

host()
Devuelve el valor utilizado por el constructor y pasado a IO::Socket::INET para conectarse al host.
"auth($usuario, $contraseña)"
Intenta autenticación SASL.
user($usuario)
Envía el comando USER.
pass($contraseña)
Envía el comando PASS. Devuelve el número de mensajes en el buzón.
"login([$user[, $pass]])"
Envía los comandos USER y PASS. Si no se proporciona $pass, "Net::POP3" usa "Net::Netrc" para buscar la contraseña utilizando el host y el nombre de usuario. Si no se especifica el nombre de usuario, se utilizará el nombre de usuario actual.

Devuelve el número de mensajes en el buzón. Sin embargo, si no hay mensajes en el servidor, se devolverá la cadena "0E0". Esto dará un valor verdadero en un contexto booleano, pero cero en un contexto numérico.

Si hubo un error al autenticar al usuario, se devolverá *undef*.

starttls(%sslargs)
Actualiza la conexión simple existente a SSL. Puede usar argumentos SSL como se documenta en IO::Socket::SSL, pero normalmente utilizará los argumentos correctos ya.
"apop([$user[, $pass]])"
Autentica con el servidor identificándose como $user con contraseña $pass. Similar a "login", pero la contraseña no se envía en texto plano.

Para usar este método, debe tener instalado el módulo Digest::MD5 o MD5, de lo contrario, este método devolverá *undef*.

banner()
Devuelve el banner de conexión del servidor
capa()
Devuelve una referencia a un hash de las capacidades del servidor. APOP se añade como una pseudo-capacidad. Tenga en cuenta que no he podido encontrar una lista de los valores de capacidad estándar, y algunos parecen tener varias palabras y otros no. Hacemos un intento de analizarlos de forma inteligente, pero puede que no sea correcto.
capabilities()
Igual que capa, pero solo utiliza una caché de la última vez que le preguntamos al servidor, para evitar preguntar más de una vez.
"top($msgnum[, $numlines])"
Obtiene la cabecera y las primeras $numlines del cuerpo para el mensaje $msgnum. Devuelve una referencia a una matriz que contiene las líneas de texto leídas del servidor.
list([$msgnum])
Si se llama con un argumento, "list" devuelve el tamaño del mensaje en octetos.

Si se llama sin argumentos, se devuelve una referencia a un hash. Las claves serán los $msgnum de todos los mensajes no eliminados y los valores serán su tamaño en octetos.

"get($msgnum[, $fh])"
Obtiene el mensaje $msgnum del buzón remoto. Si no se proporciona $fh, get devuelve una referencia a una matriz que contiene las líneas de texto leídas del servidor. Si se proporciona $fh, las líneas devueltas por el servidor se imprimen en el manejador de archivo $fh.
getfh($msgnum)
Al igual que get(), pero devuelve un manejador de archivo enlazado. Leer de este manejador de archivo devuelve el mensaje solicitado. El manejador de archivo devolverá EOF al final del mensaje y no debe reutilizarse.
last()
Devuelve el $msgnum más alto de todos los mensajes accedidos.
popstat()
Devuelve una lista de dos elementos. Estos son el número de elementos no eliminados y el tamaño del buzón en octetos.
ping($user)
Devuelve una lista de dos elementos. Estos son el número de mensajes nuevos y el número total de mensajes para $user.

Net::POP3(3pm)

NAME

Net::POP3 - POP3 client protocol module

SYNOPSIS

 use Net::POP3;
 my $pop = Net::POP3->new("pop.example.com");
 $pop->user("your_username");
 $pop->pass("your_password");
 my $msgs = $pop->list;
 for my $msg (@$msgs) {
     my ($num, $size) = @$msg;
     my $mesg = $pop->get($num);
     # process $mesg
     # $pop->delete($num);
 }
 $pop->quit;

DESCRIPTION

The Net::POP3 module is a client-side interface to the POP3 protocol. It allows you to connect to a POP3 server, retrieve mail, and manage messages on the server.

Methods that access the remote server return undef on error and set $@ to the error message.

new(HOST[,PORT[,DEBUG]])
Creates a new Net::POP3 object connecting to HOST on PORT (default 110). If DEBUG is true, debugging messages are printed.
user(USERNAME)
Sets the username for authentication.
pass(PASSWORD)
Sets the password for authentication.
login([USER[,PASS]])
Logins to the POP3 server using the provided USER and PASS. If USER and PASS are not provided, the values previously set using user() and pass() will be used.
stat()
Returns the number of messages and the total size of the mailbox.
list([MSGNUM])
If $msgnum is given, returns the size of that message. If $msgnum is not given, returns a reference to an array of arrays, where each inner array contains the message number and its size.
top($msgnum[,N])
Returns the first $N lines of message $msgnum. The default value for $N is 0, which means all lines will be returned.
get($msgnum)
Retrieves the entire message $msgnum from the server.
uidl([msgnum])
If $msgnum is given, returns the unique message identifier for that message. If $msgnum is not given, returns a reference to a hash where the keys are the message numbers and the values are the unique identifiers.
delete($msgnum)
Marks message $msgnum for deletion from the remote mailbox. All messages that are marked for deletion will be removed from the remote mailbox when the server connection is closed.
reset()
Resets the status of the remote POP3 server. This includes resetting the status of all messages to not be deleted.
quit()
Quits and closes the connection to the remote POP3 server. Any messages marked as deleted will be deleted from the remote mailbox.
can_inet6()
Returns whether IPv6 can be used.
can_ssl()
Returns whether SSL can be used.

Notes

If a "Net::POP3" object goes out of scope before the "quit" method is called, then the "reset" method will be called before the connection is closed. This means that any messages marked for deletion will not be.
