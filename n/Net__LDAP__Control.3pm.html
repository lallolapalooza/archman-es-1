Net::LDAP::Control(3) Documentación de Perl aportada por el usuario Net::LDAP::Control(3)

NOMBRE

Net::LDAP::Control - Clase base de objetos de control LDAPv3

SINOPSIS

use Net::LDAP::Control;
use Net::LDAP::Constant qw( LDAP_CONTROL_MANAGEDSAIT );
my $req_ctrl1 = Net::LDAP::Control->new( type => LDAP_CONTROL_MANAGEDSAIT );
my $req_ctrl2 = Net::LDAP::Control->new(
  type     => "1.2.3.4",
  value    => "help",
  critical => 0
);
$mesg = $ldap->search( @args, control => [ $req_ctrl1, $req_ctrl2 ]);
my @res_ctrls = $mesg->control();

DESCRIPCIÓN

"Net::LDAP::Control" es la clase base para objetos de control LDAPv3.

Los controles proporcionan un mecanismo que permite extender la semántica y los argumentos de las operaciones LDAP. Los controles pueden adjuntarse a operaciones LDAP y solo afectan a la semántica de la operación a la que están adjuntos.

Los controles enviados por los clientes se denominan controles de solicitud y se establecen utilizando la opción "control" de las operaciones LDAP respectivas. Los controles enviados por los servidores se denominan controles de respuesta, se pueden encontrar utilizando el método control() de los objetos de mensaje de respuesta.

Los servidores anuncian los controles que soportan en el atributo "supportedControls" de su RootDSE.

CONSTRUCTORES

new ( ARGUMENTOS )
ARGUMENTOS es una lista de pares nombre/valor, los argumentos válidos son:
critical
Un valor booleano, si es VERDADERO y el control no es reconocido por el servidor o es inapropiado para la operación solicitada, el servidor devolverá un error y la operación no se realizará.

Si es FALSO y el control no es reconocido por el servidor o es inapropiado para la operación solicitada, el servidor ignorará el control y realizará la operación solicitada como si el control no se hubiera proporcionado.

Si está ausente, se asume FALSO.

type
Una representación decimal con puntos de un IDENTIFICADOR DE OBJETO que identifica unívocamente el control. Esto evita conflictos entre nombres de control.

Esto puede omitirse si el constructor se llama en una subclase de Net::LDAP::Control que se ha registrado para asociarse con un OID. Si el constructor se llama en el paquete Net::LDAP::Control, entonces se debe proporcionar este argumento. Si el OID proporcionado ha sido registrado por un paquete, entonces el objeto devuelto será del tipo registrado para manejar ese OID.

value
Información opcional asociada con el control. Su formato es específico para el control en particular.
from_asn ( ASN )
ASN es una referencia HASH, normalmente extraída de una PDU. Contendrá un elemento "type" y opcionalmente elementos "critical" y "value". Al devolver, ASN será bendecido en un paquete. Si "type" es un OID registrado, entonces ASN será bendecido en el paquete registrado; si no, ASN será bendecido en Net::LDAP::Control.

Este constructor es utilizado internamente por Net::LDAP y asume que el HASH pasado contiene un control válido. Debe usarse con **precaución**.

MÉTODOS

Además de los métodos que se enumeran a continuación, cada uno de los parámetros con nombre de "new" también está disponible como método. "type" devolverá el OID del objeto de control. "value" y "critical" son métodos de establecimiento/obtención y devolverán el valor actual de cada atributo si se llaman sin argumentos, pero también pueden llamarse con argumentos para establecer nuevos valores.

error ()
Si ha habido un error, devuelve una descripción del error; de lo contrario, devuelve "undef"
init ()
"init" será llamado como el último paso en ambos constructores. Lo que haga dependerá de la subclase. Siempre debe devolver el objeto.
register ( OID )
"register" se proporciona para los implementadores de subclases. Debe llamarse como un método de clase en una subclase de Net::LDAP::Control con el OID que la clase manejará. Net::LDAP::Control recordará este par clase/OID y lo utilizará en las siguientes situaciones.
  • Se llama a "new" como un método de clase en el paquete Net::LDAP::Control y se pasa el OID como tipo. El objeto devuelto será bendecido en el paquete que registró el OID.
  • Se llama a "new" como un método de clase en un paquete registrado y no se especifica el "type". El "type" se establecerá en el OID registrado por ese paquete.
  • Se llama a "from_asn" para construir un objeto a partir de ASN. El objeto devuelto será bendecido en el paquete que fue registrado para manejar el OID en el ASN.
( to_asn )
Devuelve una estructura adecuada para pasar a Convert::ASN1 para su codificación. Este método será llamado por Net::LDAP cuando se utilice el control.

La implementación de la clase base de este método llamará al método "value" sin argumentos para permitir que una subclase codifique su valor. Las subclases no deberían necesitar sobrescribir este método.

valid ()
Devuelve verdadero si el objeto es válido y puede ser codificado. La implementación predeterminada de este método es devolver VERDADERO si no hay error, pero las subclases pueden anular esto.
