NOMBRE

Net::DNS::RR::DELEG - Registro de recursos DELEG de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('zone DELEG server-ip4=192.0.2.1 ...');
$rr = Net::DNS::RR->new('zone DELEG server-ip6=2001:db8::53 ...');
$rr = Net::DNS::RR->new('zone DELEG server-name=nameserver.example ...');
$rr = Net::DNS::RR->new('zone DELEG include-name=devolved.example');

DESCRIPCIÓN

El conjunto de registros de recursos DELEG de DNS, dondequiera que aparezca, anuncia los servidores de nombres autoritativos y los parámetros de transporte que se utilizarán para resolver consultas de datos en el nombre del propietario o cualquier subordinado del mismo.

El conjunto de registros DELEG es un dato autoritativo dentro de la zona delegadora. Un conjunto de registros DELEG no debe aparecer en el ápice de una zona delegada.

MÉTODOS

Los métodos disponibles son aquellos heredados de la clase base aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características no documentadas del paquete o el acceso directo a estructuras de datos internas y podría dar lugar a la terminación del programa u otro comportamiento impredecible.

server_ip4

eg.example. DELEG server-ip4=192.0.2.1,...
@ip = $rr->server_ip4;

Establece o obtiene una lista de direcciones IP.

server_ip6

eg.example. DELEG server-ip6=2001:db8::53,...
@ip = $rr->server_ip6;

Establece o obtiene una lista de direcciones IP.

server_name

eg.example. DELEG server-name=nameserver.example.
$nameserver = $rr->server_name;

Especifica el nombre de dominio del servidor de nombres.

Devuelve el nombre de dominio del servidor de nombres o el valor indefinido si no se especificó.

include_name

eg.example. DELEG include-name=devolved.example.
$destination = $rr->include_name;

Especifica la ubicación de una configuración de servidor de nombres devolucionada.

Devuelve el nombre de dominio de destino o el valor indefinido si no se especificó.
