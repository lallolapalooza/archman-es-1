NOMBRE

Net::DNS::RR - Clase base para registros de recursos (RR) de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('example.com IN AAAA 2001:DB8::1');
$rr = Net::DNS::RR->new(
                owner   => 'example.com',
                type    => 'AAAA',
                address => '2001:DB8::1'
                );

DESCRIPCIÓN

Net::DNS::RR es la clase base para objetos de registros de recursos (RR) de DNS. Ver también las páginas de manual para cada tipo específico de RR.

MÉTODOS

¡¡¡ADVERTENCIA!!! No asumas que los objetos RR que recibes de una consulta son de un tipo particular. Siempre debes verificar el tipo de objeto antes de llamar a cualquier método. Si llamas a un método desconocido, obtendrás un mensaje de error y el programa terminará.

new (desde cadena)

$aaaa   = Net::DNS::RR->new('host.example.com. 86400 AAAA 2001:DB8::1');
$mx     = Net::DNS::RR->new('example.com. 7200 MX 10 mailhost.example.com.');
$cname  = Net::DNS::RR->new('www.example.com 300 IN CNAME host.example.com');
$txt    = Net::DNS::RR->new('txt.example.com 3600 HS TXT "text data"');

Devuelve un objeto de tipo RR adecuado, o un objeto Net::DNS::RR si el tipo no está implementado. Los valores de los atributos se extraen de la cadena proporcionada por el usuario. La sintaxis del argumento sigue la especificación RFC1035 para archivos de zona y es compatible con la salida devuelta por el método string.

El propietario y el tipo de RR son obligatorios; todo lo demás es opcional. Omitir los campos opcionales es útil para crear las secciones de datos vacías necesarias para ciertas operaciones de actualización dinámica. Ver la página de manual de Net::DNS::Update para ejemplos adicionales.

Todos los nombres se interpretan como nombres de dominio completamente cualificados. El punto final (.) es opcional.

new (desde hash)

$rr = Net::DNS::RR->new(%hash);
$rr = Net::DNS::RR->new(
                owner   => 'host.example.com',
                ttl     => 86400,
                class   => 'IN',
                type    => 'AAAA',
                address => '2001:DB8::1'
                );

$rr = Net::DNS::RR->new(
                owner   => 'txt.example.com',
                type    => 'TXT',
                txtdata => [ 'one', 'two' ]
                );

Devuelve un objeto de tipo RR adecuado, o un objeto Net::DNS::RR si el tipo no está implementado. Consulta las páginas de manual correspondientes para el uso de atributos específicos del tipo.

El propietario y el tipo de RR son obligatorios; todo lo demás es opcional. Omitir los atributos opcionales es útil para crear las secciones de datos vacías necesarias para ciertas operaciones de actualización dinámica.

decode

( $rr, $next ) = Net::DNS::RR->decode( \$data, $offset, @opaque );

Decodifica un registro de recurso (RR) en la ubicación especificada dentro de un paquete DNS.

El argumento consiste en una referencia al búfer que contiene los datos del paquete y un desplazamiento que indica dónde comienza el registro de recurso (RR). Cualquier argumento restante se pasa como datos opacos a los decodificadores descendentes y no forma parte de la interfaz pública.

Devuelve un objeto "Net::DNS::RR" y el desplazamiento del siguiente registro en el paquete.

Se lanza una excepción si el búfer de datos contiene datos insuficientes o corruptos.

encode

$data = $rr->encode( $offset, @opaque );

Devuelve el formato binario "Net::DNS::RR" adecuado para incluir en un búfer de paquete DNS.

El desplazamiento indica la ubicación deseada dentro de los datos del paquete donde se debe almacenar el "Net::DNS::RR".

Cualquier argumento restante son datos opacos que se pasan íntegros a los codificadores descendentes.

canonical

$data = $rr->canonical;

Devuelve el formato binario "Net::DNS::RR" adecuado para la validación de firmas DNSSEC.

La ausencia de un argumento de mapeo indica a los codificadores descendentes que se utilizará la forma no comprimida del nombre de dominio incrustado.

print

$rr->print;

Imprime el registro de recurso (RR) en el archivo de salida actual. Llama al método string para obtener la representación formateada del RR.

string

print $rr->string, "\n";

Devuelve una representación de cadena del RR siguiendo el formato de archivo de zona mandado por RFC1035. Todos los nombres de dominio se interpretan como nombres completamente cualificados con un punto final. Esto difiere de los métodos de atributos de RR, que omiten el punto final.

plain

$plain = $rr->plain;

Devuelve una representación simplificada de una sola línea del RR. Esto facilita la interacción con programas como nsupdate que tienen analizadores rudimentarios.

token

@token = $rr->token;

Devuelve una lista de tokens representativa de la cadena de archivo de zona.

generic

$generic = $rr->generic;

Devuelve la representación genérica del RR definida en RFC3597. Esto facilita la creación de archivos de zona con RRs no reconocidos por servidores antiguos y software de aprovisionamiento.

nombre del propietario

$name = $rr->owner;

Devuelve el nombre del propietario del registro.

type

$type = $rr->type;

Devuelve el tipo del registro.

class

$class = $rr->class;

Clase del registro de recurso (RR).

ttl

$ttl = $rr->ttl;
$ttl = $rr->ttl(3600);

Tiempo de vida (TTL) del registro de recurso (RR) en segundos.

rdata

$rr = Net::DNS::RR->new( type => NULL, rdata => 'arbitrary' );

Sección de datos del RR cuando se ve como octetos no comprimidos.

rdstring

$rdstring = $rr->rdstring;

Devuelve una representación de cadena de los datos específicos del RR.

rdlength

$rdlength = $rr->rdlength;

Devuelve la longitud no comprimida de los datos específicos del RR.

Ordenación de arrays de RR

La ordenación de arrays de RR se realiza mediante Net::DNS::rrsort(), ver la documentación de Net::DNS. Este paquete proporciona métodos de clase para establecer la función de comparador utilizada para un RR particular según sus atributos.

set_rrsort_func

my $function = sub {    ## ordenación numérica ascendente
        $Net::DNS::a->{'preference'} <=> $Net::DNS::b->{'preference'};
        };
Net::DNS::RR::MX->set_rrsort_func( 'preference', $function );
Net::DNS::RR::MX->set_rrsort_func( 'default_sort', $function );

set_rrsort_func() debe llamarse como método de clase. El primer argumento es el nombre del atributo en el que se realizará la ordenación. Si especificas "default_sort", entonces se utilizará ese algoritmo de ordenación cuando se llame a get_rrsort_func() sin argumento de atributo RR.

El segundo argumento es una referencia a una función de comparador que utiliza las variables globales $a y $b.

NAME

Net::DNS::RR::MX - resource record base class for MX RRs

SYNOPSIS

    use Net::DNS;

DESCRIPTION

Net::DNS::RR::MX is a subclass of Net::DNS::RR.

It represents the DNS MX (Mail eXchanger) resource record.

MX records are used to specify the mail servers responsible for accepting electronic mail for a domain name, and the order in which to contact them. The preference is a 16-bit integer, with lower numbers indicating higher priority.

METHODS

An object of this class inherits methods from the base class Net::DNS::RR, and provides the following additional methods:

preference
Returns the preference value of the MX record.
exchange
Returns the hostname of the mail exchange server.

Sorting of RR arrays

The following example shows how to sort an array of MX RRs by preference:

    use Net::DNS::RR;

    my @mx_rr;
    push @mx_rr, Net::DNS::RR::MX->new(
        'mx.example.com.', 10, 'mail.example.com.'
    );
    push @mx_rr, Net::DNS::RR::MX->new(
        'mx.example.com.', 20, 'mail2.example.com.'
    );
    push @mx_rr, Net::DNS::RR::MX->new(
        'mx.example.com.', 5, 'mail3.example.com.'
    );

    # Sort by preference
    Net::DNS::RR::MX->set_rrsort_func(sub {
        my ($a, $b) = @_;
        return $a->preference <= $b->preference ? -1 : 1;
    });

    @mx_rr = sort @mx_rr;

    # The above sorting function will only be applied to Net::DNS::RR::MX objects.
    # The variables $a and $b will contain references to objects of the class
    # whose set_rrsort_func() was called.

The example above is the sorting function implemented in MX.

get_rrsort_func

$function = Net::DNS::RR::MX->get_rrsort_func('preference');
$function = Net::DNS::RR::MX->get_rrsort_func();

get_rrsort_func() returns a reference to the comparator function.
