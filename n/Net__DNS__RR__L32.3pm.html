NOMBRE

Net::DNS::RR::L32 - Registro de recursos L32 de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name IN L32 preference locator32');
$rr = Net::DNS::RR->new(
                name       => 'example.com',
                type       => 'L32',
                preference => 10,
                locator32  => '10.1.02.0'
                );

DESCRIPCIÓN

Clase para registros de recursos de Localizador de 32 bits (L32) de DNS.

El registro de recursos L32 se utiliza para mantener valores de Localizador de 32 bits para nodos compatibles con ILNPv4.

MÉTODOS

Los métodos disponibles son los heredados de la clase base aumentados por los métodos específicos del tipo definidos en este paquete.

Se desaconseja el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas, y podría dar lugar a la terminación del programa u otros comportamientos impredecibles.

preference

$preference = $rr->preference;
$rr->preference( $preference );

Un entero sin signo de 16 bits en orden de bytes de red que indica la preferencia relativa para este registro L32 entre otros registros L32 asociados con este nombre de propietario. Los valores más bajos se prefieren sobre los valores más altos.

locator32

$locator32 = $rr->locator32;

El campo Locator32 es un entero sin signo de 32 bits en orden de bytes de red que tiene la misma sintaxis y semántica que un prefijo de enrutamiento IPv4 de 32 bits.
