NOMBRE

Net::DNS::Resolver::Mock - Simula un objeto Resolver de DNS para pruebas

DESCRIPCIÓN

Una subclase de Net::DNS::Resolver que analiza un archivo de zona para obtener su fuente de datos. Principalmente para uso en pruebas.

SINOPSIS

use Net::DNS::Resolver::Mock;
my $Resolver = Net::DNS::Resolver::Mock-new();
$Resolver->zonefile_read( $FileName );
# o
$Resolver->zonefile_parse( $String );

MÉTODOS PÚBLICOS

zonefile_read ( $FileName )
Lee el archivo especificado para obtener datos de zona
zonefile_parse ( $String )
Lee los datos de zona de la cadena proporcionada
die_on ( $Name, $Type, $Error )
Falla con $Error para una consulta de $Name y $Type
enable_debug ()
Una vez establecido, el resolvedor escribirá en STDERR cualquier consulta recibida y estará disponible a través de los siguientes métodos
disble_debug ()
Deshabilita la depuración
clear_debug ()
Borra la lista de depuración
get_debug ()
Devuelve una lista de entradas de depuración

DEPENDENCIAS

Net::DNS::Resolver
Net::DNS::Packet
Net::DNS::Question
Net::DNS::ZoneFile
