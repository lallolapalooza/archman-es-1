NOMBRE

Net::LDAP::LDIF - Lectura y escritura de LDIF

SINOPSIS

use Net::LDAP::LDIF;
$ldif = Net::LDAP::LDIF->new( "file.ldif", "r", onerror => 'undef' );
while ( not $ldif->eof ( ) ) {
  $entry = $ldif->read_entry ( );
  if ( $ldif->error ( ) ) {
    print "Error msg: ", $ldif->error ( ), "\n";
    print "Error lines:\n", $ldif->error_lines ( ), "\n";
  } else {
    # hacer algo
  }
}
$ldif->done ( );

DESCRIPCION

Net::LDAP::LDIF proporciona un medio para convertir entre objetos Net::LDAP::Entry y entradas LDAP representadas en archivos de formato LDIF. Se soportan la lectura y escritura, y pueden manipular entradas individuales o listas de entradas.

Al igual que al leer un archivo completo en memoria con perl normalmente, tenga en cuenta el posible uso de memoria al cargar un archivo LDIF de una sola vez.

CARACTERISTICAS ESPECIALES

Por defecto, Net::LDAP::LDIF soporta la lectura de valores de atributos de URLs de tipo "file://".

Cuando el paquete del módulo LWP de Gisle Aas está instalado, Net::LDAP::LDIF lo utiliza para también soportar la lectura de datos de los tipos de URL soportados por estos módulos; destacando "http://", "https://", y "ftp://" recursos. Esta característica extendida se detecta dinámicamente en tiempo de ejecución.

CONSTRUCTOR

new ( ARCHIVO [[, MODO ], OPCIONES ] )
Abre el archivo con el modo dado.

"ARCHIVO" puede ser el nombre de un archivo o un manejador de archivo ya abierto. Si "ARCHIVO" comienza o termina con un "|" entonces "ARCHIVO" será pasado directamente a "open".

"MODO" puede ser cualquiera de los modos permitidos para la función open() de Perl, potencialmente extendido por capas PerlIO como se describe en perlopentut. Alternativamente, puede ser uno de los indicadores de modo "r", "r+", "w", "w+", "a", "a+" conocidos de la función fopen() de C, que se mapean a sus contrapartes de Perl. Si "MODO" se omite, por defecto es "r" para lectura.

"OPCIONES" es una lista de pares nombre/valor, reconociendo:

encode => 'none' | 'canonical' | 'base64'
Algunos valores de DN en LDIF no pueden ser escritos textualmente y tienen que ser codificados de alguna manera:
'none'
Por defecto.
'canonical'
Ver "canonical_dn" en Net::LDAP::Util.
'base64'
Usa base64.
onerror => 'die' | 'warn' | 'undef'
Especifica qué sucede cuando se detecta un error.
'die'
"Net::LDAP::LDIF" provocará un error con un mensaje apropiado.
'warn'
"Net::LDAP::LDIF" advertirá con un mensaje apropiado.
'undef'
"Net::LDAP::LDIF" advertirá con un mensaje apropiado si "-w" está en efecto. El método que se llamó devolverá "undef".

Nota: este valor es la cadena 'undef', no el valor "undef".

change => 1
Escribe cambios de entrada en el archivo LDIF en lugar de las entradas mismas. Es decir, escribe operaciones LDAP que actúan sobre las entradas en el archivo en lugar del contenido de las entradas.
lowercase => 1
Convierte los nombres de atributos a minúsculas al escribir.
sort => 1
Ordena los nombres de atributos al escribir entradas según la regla: objectclass primero, luego todos los demás atributos ordenados alfabéticamente.
version => '1'
Establece la versión LDIF a escribir en el archivo LDIF resultante.

Según RFC 2849, actualmente el único valor legal para esta opción es 1.

Cuando esta opción se establece, Net::LDAP::LDIF intenta adherirse más estrictamente a la especificación LDIF en RFC2489 en algunos lugares.

Por defecto es undef, lo que significa que no se escribe información de versión en el archivo LDIF.

wrap => 78
Número de columnas donde ocurrirá el ajuste de línea de salida.

Por defecto es 78. Establecerlo a 40 o menos inhibe el ajuste.

raw => REGEX
Usa REGEX para denotar los nombres de los atributos que deben considerarse binarios al leer.

Cuando se proporciona esta opción, Net::LDAP convierte todos los valores de atributos que no coinciden con esta REGEX en cadenas UTF-8 de Perl para que los operadores regulares de Perl (coincidencia de patrones, ...) puedan operar como se espera, incluso en cadenas con caracteres internacionales.

Si esta opción no se proporciona, los valores de los atributos se tratan como cadenas de bytes.

Ejemplo: raw => qr/(?i:^jpegPhoto|;binary)/

METODOS

read_entry ( )
Lee una entrada del archivo y la devuelve como un objeto "Net::LDAP::Entry".

En modo escalar, se devuelve solo el objeto "Net::LDAP::Entry", mientras que en modo lista se devuelve una lista que consiste en el objeto "Net::LDAP::Entry" como primer elemento, seguido por todos los objetos "Net::LDAP::Control" que formaban parte de la entrada LDIF. Ver RFC 2849 para detalles.

eof ( )
Devuelve verdadero cuando se llega al final del archivo.
write_entry ( ENTRADA [, OPCIONES ], ... )
Escribe entradas en el archivo LDIF.

Los argumentos aceptados son una lista de entradas, opcionalmente intercaladas con opciones que pertenecen a la entrada precedente.

Para cada entrada, "OPCIONES" es una lista de pares clave-valor, reconociendo:

control => CONTROL
control => [ CONTROL, ... ]
Ver "CONTROLS" en Net::LDAP.
write_version ( )
Si la versión del objeto está definida, este método permite escribir explícitamente la versión antes de que se escriba una entrada.

Si no se llama explícitamente, se llama automáticamente al escribir la primera entrada.

version ( [ VERSION ] )
Si se llama sin argumentos, devuelve la versión del archivo LDIF o undef si no se ha establecido ninguna versión. Si se llama con un argumento, establece la versión LDIF a VERSION.

Según RFC 2849, actualmente el único valor legal para VERSION es 1.

handle ( )
Devuelve el manejador de archivo del que lee o al que escribe el objeto "Net::LDAP::LDIF".
