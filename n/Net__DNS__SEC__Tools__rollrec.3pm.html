NOMBRE

Net::DNS::SEC::Tools::rollrec - Manipula un archivo de rollrec de DNSSEC-Tools.

SINTAXIS

use Net::DNS::SEC::Tools::rollrec;
rollrec_lock();
rollrec_read("localhost.rollrec");
$valid = rollrec_current();
$rrinfo = rollrec_info();
@rrnames = rollrec_names();
$flag = rollrec_exists("example.com");
$rrec = rollrec_fullrec("example.com");
%rrhash = %$rrec;
$zname = $rrhash{"maxttl"};
$val = rollrec_recval("example.com","zonefile");
rollrec_add("roll","example.com",\%rollfields);
rollrec_add("skip","example.com",\%rollfields);
rollrec_del("example.com");
rollrec_rename("example.com","subdom.example.com");
rollrec_type("example.com","roll");
rollrec_type("example.com","skip");
rollrec_setval("example.com","zonefile","db.example.com");
rollrec_delfield("example.com","directory");
rollrec_settime("example.com");
rollrec_settime("example.com",0);
@rollrecfields = rollrec_fields();
$default_file = rollrec_default();
$count = rollrec_merge("primary.rrf", "new0.rrf", "new1.rrf");
@retvals = rollrec_split("new-rollrec.rrf", @rollrec_list);
%zgroups = rollrec_zonegroups();
@zgroup = rollrec_zonegroup($zonegroupname);
@zgcmds = rollrec_zonegroup_cmds();
rollrec_write();
rollrec_close();
rollrec_discard();
rollrec_unlock();

DESCRIPCIÓN

El módulo Net::DNS::SEC::Tools::rollrec manipula el contenido de un archivo de rollrec de DNSSEC-Tools. Los archivos de rollrec describen el estado de un proceso de rotación de zonas, realizado por los programas de DNSSEC-Tools. Las interfaces existen para buscar registros de rollrec, crear nuevos registros y modificar los existentes.

Un archivo de rollrec está organizado en conjuntos de registros de rollrec. Los registros de rollrec describen el estado de una operación de rotación. Un registro de rollrec consiste en un conjunto de entradas clave/valor. El siguiente es un ejemplo de un registro de rollrec:

roll "example"
    zonename                "example.com"
    zonefile                "/etc/dnssec-tools/zones/db.example.com"
    keyrec                  "/etc/dnssec-tools/keyrec/example.keyrec"
    zonegroup               "example zones"
    directory               "/etc/dnssec-tools/dir-example.com"
    kskphase                "0"
    zskphase                "2"
    maxttl                  "86400"
    administrator           "bob@bobhost.example.com"
    phasestart              "Wed Mar 09 21:49:22 2005"
    display                 "0"
    loglevel                "info"
    rollrec_rollsecs        "1115923362"
    rollrec_rolldate        "Tue Mar 09 19:12:54 2005"
    curerrors               0
    maxerrors               5
    # registros opcionales:
    istrustanchor           "yes"
    holddowntime            "8W"

Además, se pueden definir comandos a ejecutar al iniciar usando el token "cmd" como se muestra en el siguiente ejemplo.

cmd "rollzsk example.com"

Use esta característica con cautela y solo si comprende los internos de rollerd y lo que se realizará con el comando especificado.

La primera etapa en el uso de este módulo debe ser leer el archivo de rollrec. La interfaz rollrec_read() lee el archivo y lo parsea en un formato interno. Los registros del archivo se copian en una tabla de hash (para referencia fácil por las rutinas rollrec.pm) y en un array (para preservar el formato y los comentarios).

Después de leer el archivo, se refieren los contenidos usando rollrec_fullrec() y rollrec_recval(). Las interfaces rollrec_add(), rollrec_setval() y rollrec_settime() se utilizan para modificar los contenidos de un registro de rollrec.

Si el archivo de rollrec ha sido modificado, debe ser explicitamente escrito o los cambios no se guardarán. La interfaz rollrec_write() guarda los nuevos contenidos en el disco. La interfaz rollrec_close() guarda el archivo y cierra el handle Perl del archivo de rollrec. Si el archivo de rollrec no es más deseado y los contenidos no deben ser guardados, rollrec_discard() elimina los datos y cierra el handle sin guardar los cambios modificados.

Al leer un archivo de rollrec, las líneas consecutivas de espacios en blanco se compactan en una sola línea de espacios en blanco. Al agregar y eliminar registros de rollrec y unir y dividir archivos, es posible que bloques de líneas consecutivas de espacios en blanco crezcan. Esta compactación de líneas de espacios en blanco previene que estos bloques crezcan excesivamente.

Hay un especial registro de rollrec llamado el rollrec de información. Contiene información sobre el archivo de rollrec, como el número de versión de rollrec almacenado en el archivo. Solo se puede acceder a través de la interfaz rollrec_info() y la interfaz rollrec_current() indica si el número de versión del archivo es actual.

LOCKING DEL rollrec

Este módulo incluye interfaces para sincronizar el acceso a los archivos de rollrec. Esta sincronización es muy simple y se basa en bloquear y desbloquear un archivo de bloqueo único para todos los archivos de rollrec.

La sincronización de los archivos de rollrec no es necesaria antes de usar este módulo, pero se recomienda. El uso esperado de estas funciones es:

rollrec_lock() || die "no se puede bloquear el archivo rollrec\n";
rollrec_read();
... realizar otras operaciones con rollrec ...
rollrec_close();
rollrec_unlock();

La sincronización se lleva a cabo de este modo debido a cómo se implementa la funcionalidad del módulo, así como para ofrecer flexibilidad a los usuarios que usen el módulo. También ofrece una delineación clara en el código de los llamadores sobre dónde y cuando se realiza la sincronización de rollrec.

Este método de sincronización tiene el desventaje de tener un archivo de bloqueo único como un bloqueo para todos los archivos de rollrec. Sin embargo, reduce la complejidad en las interfaces de bloqueo y reduce el número de archivos de bloqueo necesarios.

Usar un solo archivo de sincronización puede no ser práctico en instalaciones grandes. Si se encuentra que es así, entonces este será reworkado.

INTERFACES DEL MODULO rollrec.pm

Las interfaces del módulo rollrec.pm se dan a continuación.

rollrec_add(rollrec_type,rollrec_name,fields)
Esta rutina añade un nuevo registro de rollrec a un archivo de rollrec y representa internamente los contents del archivo. El registro de rollrec se añade a ambos la tabla de hash %rollrecs y al array @rollreclines. Las entradas se añaden solo si son definidas para los registros de rollrec.

rollrec_type es el tipo del registro de rollrec. Este debe ser either "roll" o "skip". rollrec_name es el nombre del registro de rollrec. fields es un referencia a una tabla de nombre/valor que contiene los campos del registro de rollrec. Las claves de la tabla de hash siempre se convierten en minúsculas, pero los valores de la entrada se mantienen como están.

Los campos de timestamp se añaden al final del registro de rollrec. Estos campos tienen los valores clave rollrec_gensecs y rollrec_gendate.

Una línea de espacios en blanco se añade después de la última línea del nuevo registro de rollrec. El archivo de rollrec no se escribe después de rollrec_add(), aunque se marca internamente como haber sido modificado.

rollrec_close()
Esta interfaz guarda la versión interna del archivo de rollrec (abierto con rollrec_read()) y cierra el handle del archivo de rollrec.
rollrec_current()
Esta rutina devuelve un booleano indicando si este rollrec abierto es actual, según el número de versión en el rollrec de información. Las versiones 0, 1 y 2 son consideradas equivalentes.

Valores devueltos:

1 rollrec es

0 rollrec está obsoleto
0 rollrec tiene una versión inválida

La última condición nunca debería ocurrir y se podría argumentar que se debería devolver un valor de fallo. Sin embargo, se quería una función booleana fácil de dos valores, no una función de tres valores.

rollrec_del(rollrec_name)
Esta rutina elimina un rollrec del conjunto de rollrecs cargados en memoria por el módulo rollrec.pm. El rollrec se elimina tanto de la tabla hash %rollrecs como del array @rollreclines.

El archivo rollrec no se escribe después de rollrec_del(), aunque la colección de rollrecs se marca internamente como modificada.

Solo se elimina el rollrec en sí. Los comentarios asociados y las líneas en blanco que lo rodean se dejan intactos.

Los valores de retorno son:

 0 eliminación exitosa de rollrec
-1 nombre desconocido
rollrec_delfield(rollrec_name,field)
Elimina el campo dado del rollrec especificado. El archivo **no** se escribe después de actualizar el valor, pero se establece el indicador interno de archivo modificado. El valor se guarda tanto en %rollrecs como en @rollreclines.

Valores de retorno:

0 - fallo (rollrec no encontrado o rollrec no
    contiene el campo)
1 - éxito
rollrec_discard()
Esta rutina elimina un archivo rollrec del uso por parte de un programa. Los datos almacenados internamente se eliminan y se cierra el descriptor de archivo del rollrec. Sin embargo, los datos modificados no se guardan antes de cerrar el descriptor de archivo. Por lo tanto, se perderán los datos modificados y nuevos.
rollrec_exists(rollrec_name)
Esta rutina devuelve un indicador booleano que indica si existe el rollrec nombrado en rollrec_name.
rollrec_fullrec(rollrec_name)
rollrec_fullrec() devuelve una referencia al rollrec especificado en rollrec_name.
rollrec_info()
rollrec_info() devuelve una referencia al info rollrec dado en el archivo actual. Esta interfaz es la única forma para que un programa que llama recupere esta información.
rollrec_lock()
rollrec_lock() bloquea el archivo de bloqueo de rollrec. Se solicita un bloqueo exclusivo, por lo que la ejecución se suspenderá hasta que el bloqueo esté disponible. Si el archivo de sincronización de rollrec no existe, se creará. Si el proceso no puede crear el archivo de sincronización, se devolverá un error. Se devuelve éxito o fracaso.
rollrec_merge(target_rollrec_file, rollrec_file1, ... rollrec_fileN)
Esta interfaz fusiona los archivos rollrec especificados. Lee cada archivo y los analiza en una tabla hash rollrec y un array de contenidos de archivo. La fusión resultante se escribe en el archivo nombrado por target_rollrec_file. Si otro rollrec ya está abierto, se guarda y se cierra antes de abrir el nuevo rollrec.

Si target_rollrec_file es un archivo rollrec existente, su contenido se fusionará con los otros archivos pasados a rollrec_merge(). Si el archivo no existe, rollrec_merge() lo creará y fusionará los archivos restantes en él.

El info rollrec puede afectar cómo funcionará la fusión. Si target_rollrec_file no existe o está vacío, se agregará un simple info rollrec al archivo. Ninguna parte de los info rollrecs se fusionará con la de target_rollrec_file.

Si el archivo existe pero no tiene un info rollrec, entonces el info rollrec de la fuente se copia al destino. Los info rollrecs de los archivos deben tener la misma versión o las versiones deben ser todas menores que la versión de target_rollrec_file.

En caso de éxito, rollrec_merge() devuelve el número de rollrecs leídos del archivo.

Valores de retorno en caso de fallo:

-1 no se proporcionaron archivos rollrec a rollrec_merge
-2 no se pudo crear el archivo rollrec de destino
-3 no se pudo leer el primer archivo rollrec
-4 ocurrió un error al leer los nombres de rollrec
-5 los archivos rollrec se duplicaron en la lista de archivos rollrec
rollrec_names()
Esta rutina devuelve una lista de los nombres de rollrec del archivo. El nombre del info rollrec no se incluye en esta lista.
rollrec_read(rollrec_file)
Esta interfaz lee el archivo rollrec especificado y lo analiza en una tabla hash rollrec y un array de contenidos de archivo. rollrec_read() **debe** ser llamada antes que cualquiera de las otras llamadas a rollrec.pm. Si otro rollrec ya está abierto, se guarda y se cierra antes de abrir el nuevo rollrec.

rollrec_read() intenta abrir el archivo rollrec para lectura y escritura. Si esto falla, intenta abrir el archivo solo para lectura.

rollrec_read() es un front-end para rollrec_readfile(). Configura los datos guardados del módulo en preparación para leer un nuevo archivo rollrec. Estas acciones de mantenimiento no son realizadas por rollrec_readfile().

En caso de éxito, rollrec_read() devuelve el número de rollrecs leídos del archivo.

Valores de retorno en caso de fallo:

-1 el archivo rollrec especificado no existe
-2 no se pudo abrir el archivo rollrec
-3 nombres de rollrec duplicados en el archivo
rollrec_readfile(rollrec_file_handle,mergeflag)
Esta interfaz lee el descriptor de archivo especificado para un archivo rollrec y analiza el contenido del archivo en una tabla hash rollrec y un array de contenidos de archivo. La tabla hash y el array de contenidos de archivo **no** se borran antes de agregarles datos.

El argumento mergeflag indica si la llamada fusionará un archivo rollrec con un rollrec leído previamente o si leerá un archivo rollrec nuevo.

En caso de éxito, rollrec_read() devuelve cero.

Valores de retorno en caso de fallo:

-1 nombres de rollrec duplicados en el archivo
rollrec_rectype(rollrec_name,rectype)
Establece el tipo del registro rollrec especificado. El archivo **no** se escribe después de actualizar el valor, pero se establece el indicador interno de archivo modificado. El valor se guarda tanto en %rollrecs como en @rollreclines.

rollrec_name es el nombre del rollrec que se modificará. rectype es el nuevo tipo del rollrec, que debe ser "roll" o "skip".

Valores de retorno:

0 - fallo (tipo de registro inválido o rollrec no encontrado)
1 - éxito
rollrec_recval(rollrec_name,rollrec_field)
Esta rutina devuelve el valor de un campo especificado en un rollrec dado. rollrec_name es el nombre del rollrec particular a consultar. rollrec_field es el nombre del campo dentro de ese rollrec.

Por ejemplo, el archivo rollrec actual contiene el siguiente rollrec.

roll        "example.com"
            zonefile        "db.example.com"

La llamada:

rollrec_recval("example.com","zonefile")

devolverá el valor "db.example.com".

rollrec_rename(old_rollrec_name,new_rollrec_name)
Esta rutina renombra el rollrec nombrado por old_rollrec_name a new_rollrec_name. El efecto real es cambiar el nombre en la línea de roll o skip a new_rollrec_name. El nombre se cambia solo en la versión interna del archivo rollrec. El archivo en sí no se modifica, pero debe guardarse llamando a rollrec_write(), rollrec_save() o rollrec_saveas().

old_rollrec_name debe ser el nombre de un rollrec existente. Por el contrario, new_rollrec_name no debe nombrar un rollrec existente.

Valores de retorno:

  0 - éxito
-1 - old_rollrec_name estaba vacío o era nulo
-2 - new_rollrec_name estaba vacío o era nulo
-3 - old_rollrec_name no es un rollrec existente
-4 - new_rollrec_name ya es un rollrec
-5 - error interno que nunca debería ocurrir
rollrec_settime(rollrec_name,val)
Establece la marca de tiempo de inicio de fase en el rollrec especificado por rollrec_name a la hora actual. Si se proporciona el parámetro opcional val y es cero, entonces la marca de tiempo de inicio de fase se establece a un valor nulo.

El archivo **no** se escribe después de actualizar el valor.

rollrec_setval(rollrec_name,field,value)
Establece el valor de un par nombre/campo en un rollrec especificado. El archivo **no** se escribe después de actualizar el valor, pero se establece el indicador interno de archivo modificado. El valor se guardad en ambos %rollrecs y en @rollreclines.

rollrec_name es el nombre del rollrec que será modificado. Si el rollrec nombrado no existe, será creado como un rollrec de tipo "roll". field es el campo del rollrec que será modificado. value es el nuevo valor para el campo.

rollrec_split(new_rollrec_file,rollrec_names)
Mueve un conjunto de entradas rollrec del archivo rollrec actual a un nuevo archivo. Las entradas rollrec movidas se eliminan tanto del archivo actual como de los datos internos del módulo que representan ese archivo.

El parámetro new_rollrec_file contiene el nombre del nuevo archivo rollrec. Si este archivo no existe, será creado. Si existe, las entradas rollrec se añadirán a ese archivo.

rollrec_names es una lista de entradas rollrec que serán movidas del archivo actual al archivo nombrado en new_rollrec_file. Si algunos de los nombres de rollrec dados son inválidos, los nombres válidos serán movidos al nuevo archivo y los nombres inválidos serán devueltos en una lista al llamador.

Solo las entradas rollrec en sí mismas serán movidas al nuevo archivo rollrec. Los comentarios asociados se quedarán en el archivo rollrec actual.

La división de rollrec se vuelve interesante con la adición del rollrec de info. Si el archivo new_rollrec_file no existe, el rollrec de info del archivo rollrec fuente se copia al archivo de destino. Si el archivo existe pero no tiene un rollrec de info, entonces el rollrec de info del fuente se copia al destino. Si el archivo de destino existe y tiene un rollrec de info, entonces los dos archivos deben tener números de versión coincidentes.

En caso de éxito, se devuelve el recuento de entradas rollrec movidas. Los retornos de error se dan a continuación.

Valores de retorno de fallo:
-1 - no se proporcionó archivo rollrec de destino en new_rollrec_file
-2 - no se proporcionaron nombres de rollrec en rollrec_names
-3 - ninguno de los nombres de rollrec dados son rollrecs existentes
-4 - no se pudo abrir new_rollrec_file
-5 - se especificaron nombres de rollrec inválidos en rollrec_names,
seguido de la lista de nombres incorrectos
-6 - el rollrec de información del destino tiene una versión anterior a la actual
-7 - el rollrec de información del destino tiene (indefinido) una versión posterior
a la actual
-8 - el rollrec de información del destino existe sin número de versión

rollrec_unlock()
rollrec_unlock() desbloquea el archivo de sincronización rollrec.
rollrec_write()
Esta interfaz guarda la versión interna del archivo rollrec (abierto con rollrec_read()). No cierra el manejador de archivo. Como medida de eficiencia, se comprueba una bandera de modificación interna antes de escribir el archivo. Si el programa no ha modificado el contenido del archivo rollrec, no se vuelve a escribir.

rollrec_write() obtiene un bloqueo exclusivo en el archivo rollrec mientras escribe.

rollrec_zonegroup($zonegroupname)
Esta interfaz devuelve una lista de las zonas del grupo de zonas (nombrado por $zonegroupname) definido en el archivo rollrec actual. Se devuelve nulo si no hay zonas en el grupo de zonas.

Aunque se utiliza el término "zona", en realidad se refiere al nombre de las entradas rollrec. Para una entrada rollrec particular, el nombre del rollrec suele ser el mismo que el nombre de la zona, pero esto no es un requisito.

rollrec_zonegroup_cmds()
Esta interfaz devuelve una lista de los comandos de rollctl cuyo comportamiento cambia cuando se utilizan con la opción -group.
rollrec_zonegroups()
Esta interfaz devuelve una tabla hash de los grupos de zonas definidos en el archivo rollrec actual. La clave hash es el nombre del grupo de zonas; el valor hash es el número de zonas en el grupo de zonas. Se devuelve nulo si no hay grupos de zonas en el archivo rollrec.

Aunque se utiliza el término "zona", en realidad se refiere al nombre de las entradas rollrec. Para una entrada rollrec particular, el nombre del rollrec suele ser el mismo que el nombre de la zona, pero esto no es un requisito.

INTERFACES INTERNAS DE ROLLREC

Las interfaces descritas en esta sección están destinadas al uso interno por el módulo rollrec.pm. Sin embargo, hay situaciones en las que entidades externas pueden necesitarlas. Úselas con precaución, ya que un uso indebido puede resultar en archivos rollrec dañados o perdidos.

rollrec_init()
Esta rutina inicializa los datos internos de rollrec. Los cambios pendientes se perderán. Un manejador de archivo rollrec abierto permanecerá abierto, aunque los datos ya no se mantengan internamente. Se debe leer un nuevo archivo rollrec para volver a utilizar las interfaces de rollrec.pm.
rollrec_default()
Esta rutina devuelve el nombre del archivo rollrec predeterminado.

INTERFACES DE DEPURACIÓN DE ROLLREC

Las siguientes interfaces muestran información sobre el archivo rollrec analizado actualmente. Están destinadas a ser utilizadas para la depuración y pruebas, pero pueden ser útiles en otros momentos.

rollrec_dump_hash()
Esta rutina imprime el archivo rollrec tal como está almacenado internamente en una tabla hash. Los rollrec se imprimen en orden alfabético, con los campos alfabetizados para cada rollrec. Los nuevos rollrec y los campos de rollrec se alfabetizan junto con los rollrec y campos actuales. Los comentarios del archivo rollrec no se incluyen con la tabla hash.
rollrec_dump_array()
Esta rutina imprime el archivo rollrec tal como está almacenado internamente en un array. Los rollrec se imprimen en el orden dado en el archivo, con los campos ordenados de la misma manera. Los nuevos rollrec se añaden al final del array. Los campos de rollrec añadidos a los rollrec existentes se añaden al principio de la entrada rollrec. Los comentarios y el espacio en blanco vertical se conservan tal como se dan en el archivo rollrec.
