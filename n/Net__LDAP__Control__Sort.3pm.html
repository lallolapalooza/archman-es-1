NOMBRE

Net::LDAP::Control::Sort - objeto de control de ordenación del lado del servidor (SSS)

SINOPSIS

use Net::LDAP::Control::Sort;
use Net::LDAP::Constant qw(LDAP_CONTROL_SORTRESULT);
$sort = Net::LDAP::Control::Sort->new(
  order => "cn -telefono"
);
$mesg = $ldap->search( @args, control => [ $sort ]);
($resp) = $mesg->control( LDAP_CONTROL_SORTRESULT );
print "Los resultados están ordenados\n"  if $resp and !$resp->result;

DESCRIPCIÓN

"Net::LDAP::Control::Sort" es una subclase de Net::LDAP::Control. Proporciona una clase para manipular el control de solicitud de ordenación del lado del servidor (SSS) de LDAP 1.2.840.113556.1.4.473 tal como se define en RFC-2891

Si el servidor soporta la ordenación, la respuesta de una operación de búsqueda incluirá un control de resultado de ordenación. Este control es manejado por Net::LDAP::Control::SortResult.

ARGUMENTOS DEL CONSTRUCTOR

orden
Una cadena que define cómo se pueden ordenar las entradas. Consta de múltiples directivas, separadas por espacios en blanco. Cada directiva describe cómo ordenar las entradas utilizando un solo atributo. Si dos entradas tienen atributos idénticos, se utiliza la siguiente directiva de la lista.

Cada directiva especifica un orden de ordenación de la siguiente manera

-tipo_atributo:regla_ordenación

El "-" inicial es opcional, y si está presente, indica que el orden de ordenación debe invertirse. "tipo_atributo" es el nombre del atributo por el que ordenar. "regla_ordenación" es opcional e indica la regla a utilizar para la ordenación y debe ser válida para el "tipo_atributo" dado.

Cada tipo_atributo solo debe aparecer una vez en la lista de ordenación.

Ejemplos

"cn"         ordenar por cn usando la regla de ordenación predeterminada para el atributo cn
"-cn"        ordenar por cn usando la inversión de la regla de ordenación predeterminada
"edad cn"     ordenar primero por edad, luego por cn usando las reglas de ordenación predeterminadas
"cn:1.2.3.4" ordenar por cn usando la regla de ordenación definida como 1.2.3.4

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto que devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.
