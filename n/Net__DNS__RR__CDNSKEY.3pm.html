Net::DNS::RR::CDNSKEY(3) Documentación de Perl aportada por el usuario Net::DNS::RR::CDNSKEY(3)

NOMBRE

Net::DNS::RR::CDNSKEY - Registro de recurso CDNSKEY de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre CDNSKEY flags protocolo algoritmo clave_publica');

DESCRIPCIÓN

Registro de recurso DNS Child DNSKEY (CDNSKEY)

Este es un clon del registro DNSKEY y hereda todas las propiedades de la clase Net::DNS::RR::DNSKEY.

Consulte la documentación de Perl de Net::DNS::RR::DNSKEY para obtener detalles.

MÉTODOS
