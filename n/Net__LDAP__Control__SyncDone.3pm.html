Net::LDAP::Control::SyncDone(3) Documentación de Contribución de Usuarios de Perl Net::LDAP::Control::SyncDone(3)

NOMBRE

Net::LDAP::Control::SyncDone - Objeto de control Sync Done de LDAPv3

SINOPSIS

Ver Net::LDAP::Control::SyncRequest

DESCRIPCIÓN

"Net::LDAP::Control::SyncDone" proporciona una interfaz para la creación y manipulación de objetos que representan el "Sync Request Control" como se describe en la RFC 4533.

ARGUMENTOS DEL CONSTRUCTOR

Además de los argumentos del constructor descritos en Net::LDAP::Control, se proporcionan los siguientes:

cookie
refreshDeletes

MÉTODOS

Al igual que con Net::LDAP::Control, cada argumento del constructor descrito anteriormente también está disponible como un método en el objeto que devolverá el valor actual del atributo si se llama sin argumentos, y establecerá un nuevo valor para el atributo si se llama con un argumento.

VER TAMBIÉN

Net::LDAP, Net::LDAP::Control, Net::LDAP::Control::SyncRequest, Net::LDAP::Control::SyncState, http://www.ietf.org/rfc/rfc4533.txt
