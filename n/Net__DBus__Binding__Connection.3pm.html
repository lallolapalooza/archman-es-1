NAME

Net::DBus::Binding::Connection - Conexión entre cliente y servidor

SYNOPSIS

Crear una conexión a un servidor y enviar un mensaje

use Net::DBus::Binding::Connection;
my $con = Net::DBus::Binding::Connection->new(address => "unix:/path/to/socket");
$con->send($message);

Registrar manejadores de mensajes

sub handle_something {
    my $con = shift;
    my $msg = shift;
    ... hacer algo con el mensaje...
}
$con->register_message_handler(
  "/some/object/path",
  \&handle_something);

Unirse a un bucle de eventos:

my $reactor = Net::DBus::Binding::Reactor->new();
$reactor->manage($con);
$reactor->run();

DESCRIPTION

Una conexión saliente hacia un servidor, o una conexión entrante desde un cliente. Los métodos definidos en este módulo tienen una correspondencia cercana a los métodos dbus_connection_XXX del API C, así que para más detalles sobre su comportamiento, puede ser útil consultar la documentación del API C.

MÉTODOS

my $con = Net::DBus::Binding::Connection->new(address => "unix:/path/to/socket");
Crear una nueva conexión hacia el servidor especificado en el parámetro "address". Si se especifica el parámetro "private" y se establece a un valor verdadero, la conexión abierta es privada; de lo contrario, se abre una conexión compartida. Una conexión privada debe ser cerrada explícitamente con el método "disconnect" antes de liberar el último referenciado al objeto. Una conexión compartida nunca debe ser cerrada explícitamente.
$status = $con->is_connected();
Devuelve cero si la conexión ha sido desconectada, de lo contrario un valor positivo.
$status = $con->is_authenticated();
Devuelve cero si la conexión aún no ha completado la autenticación exitosamente, de lo contrario un valor positivo.
$con->disconnect()
Cierra esta conexión hacia el host remoto. Este método se llama automáticamente durante la recolección de objetos (es decir, en el método DESTROY) si el programador omite explícitamente la desconexión.
$con->flush()
Detiene la ejecución hasta que todos los datos en el canal de salida hayan sido enviados. Este método no reentra en el bucle de eventos de la aplicación.
$con->send($message)
Coloca un mensaje en cola para enviar hacia el host remoto. Los datos se envían asincrónicamente según el bucle de eventos de la aplicación. Para forzar el envío inmediato de los datos, seguir este método con una llamada a "flush". Este método devolverá el número de secuencia del mensaje, que puede usarse para identificar un mensaje posterior (si es posible).
my $reply = $con->send_with_reply_and_block($msg, $timeout);
Coloca un mensaje en cola para enviar hacia el host remoto y bloquea hasta que se haya enviado el mensaje, y se haya recibido una respuesta correspondiente. El valor devuelto por este método será un objeto "Net::DBus::Binding::Message::MethodReturn" o "Net::DBus::Binding::Message::Error".
my $pending_call = $con->send_with_reply($msg, $timeout);
Coloca un mensaje en cola para enviar hacia el host remoto y devuelve inmediatamente una referencia a un objeto "Net::DBus::Binding::PendingCall". Este objeto puede usarse para esperar / observar una respuesta. Esto permite procesar métodos de forma asincrónica.
$con->dispatch;
Dispara cualquier mensaje pendiente en la cola de entrada hacia sus handlers de mensajes. Este método se suele llamar en cada iteración del bucle de eventos principal donde se ha leído datos de la cola de entrada.
$message = $con->borrow_message
Retira temporalmente el primer mensaje de la cola de mensajes entrantes. Ningún otro hilo puede acceder al mensaje mientras está 'borrowed', así que debe reemplazarlo con el método "return_message" o eliminarlo permanentemente con el método "steal_message" lo antes posible.
$con->return_message($msg)
Reemplaza un mensaje anteriormente 'borrowed' en la cola de mensajes entrantes para su posterior despliegue a los handlers registrados.
$con->steal_message($msg)
Elimina permanentemente un mensaje 'borrowed' de la cola de mensajes entrantes. No se ejecutarán más handlers registrados para este mensaje.
$msg = $con->pop_message();
Elimina permanentemente el primer mensaje de la cola de mensajes entrantes, sin ejecutar ningún handler registrado. Si estás conectado a un bucle de eventos ("Net::DBus::Binding::Reactor" por ejemplo), probablemente no quieras llamar a este método.
$con->set_watch_callbacks(\&add_watch, \&remove_watch, \&toggle_watch);
Registra un conjunto de callbacks para añadir, remover y actualizar watches en el bucle de eventos de la aplicación. Cada parámetro debe ser una referencia a una subrutina, que en cada invocación se le pasarán dos parámetros, el objeto de conexión y el objeto de watch. Si estás usando un objeto "Net::DBus::Binding::Reactor" como bucle de eventos de la aplicación, el método 'manage' de este objeto llamará este método por ti.
$con->set_timeout_callbacks(\&add_timeout, \&remove_timeout, \&toggle_timeout);
Registra un conjunto de callbacks para añadir, remover y actualizar temporizadores en el bucle de eventos de la aplicación. Cada parámetro debe ser una referencia a una subrutina, que en cada invocación se le pasarán dos parámetros, el objeto de conexión y el temporizador. Si estás usando un objeto "Net::DBus::Binding::Reactor" como bucle de eventos de la aplicación, el método 'manage' de este objeto llamará este método por ti.
$con->register_object_path($path, \&handler)
Registra un handler para mensajes cuyo camino coincide con el especificado en el parámetro $path. La referencia de la subrutina proporcionada se invocará con dos parámetros, el objeto de conexión en el que se recibió el mensaje y el mensaje a procesar (un objeto de clase "Net::DBus::Binding::Message").
$con->unregister_object_path($path)
Desregistra el handler asociado al camino de objeto $path. El handler habría sido previamente registrado con los métodos "register_object_path" o "register_fallback".
$con->register_fallback($path, \&handler)
Registra un handler para mensajes cuyo camino empieza con el prefijo especificado en el parámetro $path. La referencia de la subrutina proporcionada se invocará con dos parámetros, el objeto de conexión en el que se recibió el mensaje y el mensaje a procesar (un objeto de clase "Net::DBus::Binding::Message").
$con->set_max_message_size($bytes)
Establece el tamaño máximo permitido para un mensaje único entrante. Los mensajes superiores a este límite se rechazarán antes de superar el umbral. El tamaño del mensaje se especifica en bytes.
$bytes = $con->get_max_message_size();
Recupera el tamaño máximo permitido de mensaje entrante. El tamaño devuelto se mide en bytes.
$con->set_max_received_size($bytes)
Establece el tamaño máximo de la cola de mensajes entrantes. Una vez superado este umbral, no se leerán más mensajes antes de que uno o más de los mensajes existentes sean enviados a sus handlers registrados. La implicación es que la cola de mensajes puede exceder este umbral por un máximo del tamaño de un mensaje.
$bytes = $con->get_max_received_size()
Recupera el tamaño máximo de la cola de mensajes entrantes. El tamaño devuelto se mide en bytes.
$con->add_filter($coderef);
Añade un filtro a la conexión que se invocará cada vez que se reciba un mensaje. El $coderef debe ser una referencia a una subrutina, que devuelva un valor verdadero si el mensaje debe ser filtrado, o un valor falso si el despliegue normal del mensaje debe continuar.

NAME

Net::DBus::Binding::Connection - Object representing a DBus connection

SYNOPSIS

 use Net::DBus::Binding;

 my $bus = Net::DBus::Binding::Bus->new('session');
 my $con = $bus->get_connection;
 my $msg = $con->make_method_call_message(...);

DESCRIPTION

This object represents an active connection to a DBus bus. It is used to create new messages, and to send and receive messages.

The connection object is obtained from a Net::DBus::Binding::Bus object.

METHODS

my $con = $bus->get_connection
Returns the active connection to the bus object. If no connection exists, it will be created.
my $con = $con->new
This constructor should not be called directly. Use $bus->get_connection instead.
my $count = $con->write($message, $fd_list)
Writes a message and an optional list of file descriptors to the connection. Returns the number of bytes written. This method is called internally by the send method of the Net::DBus::Binding::Message class and should not normally be called directly.
my $msg = $con->make_raw_message($rawmsg)
Creates a new message, initializing it from the low-level C message object provided by the $rawmsg parameter. The returned object will be cast to the appropriate subclass of Net::DBus::Binding::Message.
my $msg = $con->make_error_message( replyto => $method_call, name => $name, description => $description);
Creates a new message, representing an error which occurred during the handling of the method call object passed in as the "replyto" parameter. The "name" parameter is the formal name of the error condition, while the "description" is a short piece of text giving more specific information on the error.
my $call = $con->make_method_call_message( $service_name, $object_path, $interface, $method_name);
Create a message representing a call on the object located at the path $object_path within the client owning the well-known name given by $service_name. The method to be invoked has the name $method_name within the interface specified by the $interface parameter.
my $msg = $con->make_method_return_message( replyto => $method_call);
Create a message representing a reply to the method call passed in the "replyto" parameter.
my $signal = $con->make_signal_message( object_path => $path, interface => $interface, signal_name => $name);
Creates a new message, representing a signal [to be] emitted by the object located under the path given by the "object_path" parameter. The name of the signal is given by the "signal_name" parameter, and is scoped to the interface given by the "interface" parameter.
