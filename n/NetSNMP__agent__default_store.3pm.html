NOMBRE

NetSNMP::agent::default_store - Accede al almacén de variables de configuración del agente Net-SNMP.

SINOPSIS

    use NetSNMP::agent::default_store;

    # Establecer una variable de configuración
    $_[0]->{NETSNMP_DS_AGENT_ROLE} = 'master';

    # Obtener una variable de configuración
    my $role = $_[0]->{NETSNMP_DS_AGENT_ROLE};

    # Iterar sobre todas las variables de configuración
    my $vars = NetSNMP::agent::default_store();
    for my $var (@$vars) {
        print "$var = " . $_[0]->{$var} . "\n";
    }

DESCRIPCION

El módulo NetSNMP::agent::default_store proporciona acceso al almacén de variables de configuración global del agente Net-SNMP.

Estas variables se utilizan para configurar el comportamiento del agente Net-SNMP, como la forma en que maneja las conexiones, el registro, la seguridad y la comunicación AgentX.

La función NetSNMP::agent::default_store() devuelve una referencia a un array que contiene todos los nombres de las variables de configuración disponibles.

Puedes acceder y modificar estas variables utilizando la notación de hash, donde la clave es el nombre de la variable de configuración.
