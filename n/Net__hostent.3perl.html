Net::hostent(3perl) Guía de referencia del programador de Perl Net::hostent(3perl)

NOMBRE

Net::hostent - interfaz por nombre a las funciones gethost*() integradas de Perl

SINOPSIS

use Net::hostent;

DESCRIPCIÓN

Las exportaciones predeterminadas de este módulo anulan las funciones principales gethostbyname() y gethostbyaddr(), reemplazándolas por versiones que devuelven objetos "Net::hostent". Este objeto tiene métodos que devuelven el nombre del campo de estructura con el mismo nombre de la estructura hostent de C de netdb.h; a saber, name, aliases, addrtype, length y addr_list. Los métodos aliases y addr_list devuelven una referencia a un array, los otros escalares. El método addr es equivalente al elemento cero de la referencia al array addr_list.

También puede importar todos los campos de la estructura directamente a su espacio de nombres como variables regulares usando la etiqueta de importación :FIELDS. (Tenga en cuenta que esto aún anula sus funciones principales.) Acceda a estos campos como variables que comienzan con un prefijo "h_". Por lo tanto, "$host_obj->name()" corresponde a $h_name si importa los campos. Las referencias a arrays están disponibles como variables de arrays regulares, por lo que, por ejemplo, "@{ $host_obj->aliases() }" sería simplemente @h_aliases.

La función gethost() es un simple front-end que reenvía un argumento numérico a gethostbyaddr() a través de Socket::inet_aton, y el resto a gethostbyname().

Para acceder a esta funcionalidad sin anular las funciones principales, pase a "use" una lista de importación vacía, y luego acceda a las funciones con sus nombres completos calificados. Por otro lado, las funciones integradas todavía están disponibles a través del pseudo-paquete "CORE::".

EJEMPLOS

use Net::hostent;
use Socket;
@ARGV = ('netscape.com') unless @ARGV;
for $host ( @ARGV ) {
   unless ($h = gethost($host)) {
       warn "$0: no such host: $host\n";
       next;
   }
   printf "\n%s is %s%s\n", 
           $host, 
           lc($h->name) eq lc($host) ? "" : "*really* ",
           $h->name;
   print "\taliases are ", join(", ", @{$h->aliases}), "\n"
               if @{$h->aliases};     
   if ( @{$h->addr_list} > 1 ) { 
       my $i;
       for $addr ( @{$h->addr_list} ) {
           printf "\taddr #%d is [%s]\n", $i++, inet_ntoa($addr);
       } 
   } else {
       printf "\taddress is [%s]\n", inet_ntoa($h->addr);
   } 
   if ($h = gethostbyaddr($h->addr)) {
       if (lc($h->name) ne lc($host)) {
           printf "\tThat addr reverses to host %s!\n", $h->name;
           $host = $h->name;
           redo;
       } 
   }
}

NOTA

Aunque esta clase está implementada actualmente utilizando el módulo Class::Struct para construir una clase similar a una estructura, no debe confiar en ello.
