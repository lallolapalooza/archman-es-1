NOMBRE

Net::DBus::Binding::Bus - Manejador de una instancia de bus de mensajes conocida

SINOPSIS

use Net::DBus::Binding::Bus;
# Obtener un manejador del bus del sistema
my $bus = Net::DBus::Binding::Bus->new(type => &Net::DBus::Binding::Bus::SYSTEM);

DESCRIPCIÓN

Esta es una especialización del módulo Net::DBus::Binding::Connection que proporciona un constructor conveniente para conectarse a uno de los tipos de bus conocidos. No hay razón para usar este módulo directamente, en su lugar, obtenga un manejador del bus con los métodos "session" o "system" en Net::DBus.

MÉTODOS

my $bus = Net::DBus::Binding::Bus->new(type => $type);
my $bus = Net::DBus::Binding::Bus->new(address => $addr);
Abre una conexión a un bus de mensajes, ya sea un tipo de bus conocido especificado usando el parámetro "type", o un bus arbitrario especificado usando el parámetro "address". Si el parámetro "private" está establecido a un valor verdadero, se obtiene una conexión privada al bus. El llamador debe desconectar explícitamente este bus antes de liberar la última instancia del objeto.
$bus->request_name($service_name)
Envía una solicitud al bus registrando el nombre conocido especificado en el parámetro $service_name. Si otro cliente ya posee el nombre, el registro se pondrá en cola, a la espera de la salida del otro cliente.
my $name = $bus->get_unique_name
Devuelve el nombre único por el cual se conoce la conexión de este proceso al bus. Los nombres únicos nunca se reutilizan durante toda la vida del demonio del bus.
$bus->add_match($rule)
Registra una regla de coincidencia de señales con el controlador del bus, permitiendo que las señales transmitidas coincidentes se enruten a este cliente.
$bus->remove_match($rule)
Anula el registro de una regla de coincidencia de señales con el controlador del bus, impidiendo que señales transmitidas adicionales se enruten a este cliente.
