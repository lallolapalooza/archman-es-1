NOMBRE

Net::OpenSSH::ShellQuoter::MSCmd - Creador de citas para Windows cmd.exe

DESCRIPCIÓN

Este creador de citas está pensado para la interacción con servidores SSH que ejecutan en Windows, los cuales invocan los comandos solicitados a través del shell "cmd.exe".

Debido a que "cmd.exe" no realiza expansión de comodines (en Windows esta tarea se deja al comando final), la creación de citas para comodines simplemente cita todo.

Algunos servidores de Windows utilizan "Win32::CreateProcess" para ejecutar el shell "cmd.exe", el cual ejecuta el comando solicitado. En ese caso, tanto los creadores de citas "MSCmd" como "MSWin" deben encadenarse (y por cierto, el orden importa):

$ssh = Net::OpenSSH->new(...,
                         remote_shell => 'MSCmd,MSWin');

De hecho, "cmd.exe" puede no requerir ninguna cita en absoluto cuando el comando solicitado es una orden integrada (por ejemplo, "echo").
