NOMBRE

Net::DNS::RR::RRSIG - Registro de recurso RRSIG de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('nombre RRSIG tipocubierto algoritmo etiquetas
                        ttloriginal expiracionsig inception firma
                        etiquetasfirma firma');
use Net::DNS::SEC;
$sigrr = Net::DNS::RR::RRSIG->create(
                        \@rrset, $ruta_clave,
                        sigex => 20241230010101,
                        sigin => 20241201010101
                        );
$sigrr->verify( \@rrset, $keyrr ) || die $sigrr->vrfyerrstr;

DESCRIPCIÓN

Clase para registros de recursos de firma digital de DNS (RRSIG).

Además de los métodos regulares heredados de Net::DNS::RR, la clase contiene un método para firmar conjuntos de RR utilizando claves privadas (create) y un método para verificar firmas sobre conjuntos de RR (verify).

El RR RRSIG es una implementación de RFC4034. Consulte Net::DNS::RR::SIG para ver una implementación de SIG0 (RFC2931).

MÉTODOS

Los métodos disponibles son aquellos heredados de la clase base aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas, y podría resultar en la terminación del programa u otro comportamiento impredecible.

tipocubierto

$tipocubierto = $rr->typecovered;

El campo typecovered identifica el tipo del conjunto de RR que está cubierto por este registro RRSIG.

algoritmo

$algoritmo = $rr->algorithm;

El campo del número de algoritmo identifica el algoritmo criptográfico utilizado para crear la firma.

algorithm() también puede invocarse como un método de clase o una función simple para realizar la traducción de códigos mnemónicos y numéricos.

etiquetas

$etiquetas = $rr->labels;
$rr->labels( $etiquetas );

El campo etiquetas especifica el número de etiquetas en el nombre del propietario del RR RRSIG original.

ttloriginal

$ttloriginal = $rr->orgttl;
$rr->orgttl( $ttloriginal );

El campo TTL original especifica el TTL del conjunto de RR cubierto tal como aparece en la zona autoritativa.

tiempos sigexpiration y siginception

sigex sigin sigval

$expiracion = $rr->sigexpiration;
$expiracion = $rr->sigexpiration( $valor );
$inception = $rr->siginception;
$inception = $rr->siginception( $valor );

Los campos de expiración e inception de la firma especifican un intervalo de tiempo de validez para la firma.

El valor puede especificarse mediante una cadena con el formato 'yyyymmddhhmmss' o un valor de time() de Perl.

Los valores de retorno son de doble valor, proporcionando ya sea un valor de cadena o un valor numérico de time() de Perl.

etiquetakey

$etiquetakey = $rr->keytag;
$rr->keytag( $etiquetakey );

El campo etiquetakey contiene el valor de etiqueta de la clave del RR DNSKEY que valida esta firma.

nombrefirma

$nombrefirma = $rr->signame;
$rr->signame( $nombrefirma );

El valor del campo nombre del firmante identifica el nombre del propietario del RR DNSKEY que un validador debe utilizar para validar esta firma.

firma

sig

$sig = $rr->sig;
$rr->sig( $sig );

El campo Firma contiene la firma criptográfica que cubre los RDATA de RRSIG (excluyendo el campo Firma) y el conjunto de RR especificado por el nombre del propietario RRSIG, la clase RRSIG y los campos de tipo de RR cubierto.

sigbin

$sigbin = $rr->sigbin;
$rr->sigbin( $sigbin );

Representación binaria de la firma criptográfica.

create

Crear una firma sobre un conjunto de RR.

use Net::DNS::SEC;
$ruta_clave = '/home/olaf/keys/Kbla.foo.+001+60114.private';
$sigrr = Net::DNS::RR::RRSIG->create( \@rrsetref, $ruta_clave );
$sigrr = Net::DNS::RR::RRSIG->create(
                        \@rrsetref, $ruta_clave,
                        sigex => 20241230010101,
                        sigin => 20241201010101
                        );
$sigrr->print;
# Alternativamente, usar Net::DNS::SEC::Private 
$private = Net::DNS::SEC::Private->new($ruta_clave);
$sigrr= Net::DNS::RR::RRSIG->create( \@rrsetref, $private );

create() es un constructor alternativo para un objeto RR RRSIG.

Este método devuelve un RRSIG con la firma sobre el conjunto de RR sujeto (una matriz de RRs) creada con la clave privada almacenada en el archivo de clave.

El primer argumento es una referencia a una matriz que contiene el conjunto de RR que necesita ser firmado.

El segundo argumento es una cadena que especifica la ruta a un archivo que contiene la clave privada tal como la genera dnssec-keygen.

Los argumentos opcionales restantes consisten en pares ( nombre => valor ) como los siguientes:

sigex   => 20241230010101,      # expiración de la firma
sigin   => 20241201010101,      # inception de la firma
sigval  => 30,                  # ventana de validez (días)
ttl     => 3600

Los valores sigin y sigex pueden especificarse como valores de tiempo de Perl o como una cadena con el formato 'yyyymmddhhmmss'. El valor por defecto para sigin es el momento de la firma.

El argumento sigval especifica la ventana de validez de la firma en días ( sigex = sigin + sigval ).

Por defecto, la firma es válida por 30 días.

Por defecto, el TTL coincide con el conjunto de RR que se presenta para la firma.

verify

$verificar = $sigrr->verify( $rrsetref, $keyrr );
$verificar = $sigrr->verify( $rrsetref, [$keyrr, $keyrr2, $keyrr3] );

$rrsetref contiene una referencia a una matriz de objetos RR y el método verifica el conjunto de RR contra la firma contenida en el propio objeto $sigrr utilizando la clave pública en $keyrr.

El segundo argumento puede ser un objeto Net::DNS::RR::KEYRR o una referencia a una matriz de dichos objetos. La verificación se considerará exitosa tan pronto como una de las claves en la matriz conduzca a una validación positiva.

Devuelve 0 en caso de error y establece $sig->vrfyerrstr

vrfyerrstr

$verificar = $sigrr->verify( $rrsetref, $keyrr );
print $sigrr->vrfyerrstr unless $verificar;
$sigrr->verify( $rrsetref, $keyrr ) || die $sigrr->vrfyerrstr;

GENERACIÓN DE CLAVES

Los archivos de clave privada y los registros DNSKEY correspondientes se generan más convenientemente utilizando dnssec-keygen, un programa que viene con la distribución ISC BIND.

dnssec-keygen -a 10 -b 2048 rsa.example.
dnssec-keygen -a 13 -f ksk ecdsa.example.
dnssec-keygen -a 13        ecdsa.example.

No cambie el nombre del archivo de clave privada. El método create utiliza el nombre del archivo tal como lo genera dnssec-keygen para determinar el propietario de la clave, el algoritmo y el id de clave (etiqueta de clave).

OBSERVACIONES

El código no está optimizado para la velocidad. Probablemente no sea adecuado para firmar zonas grandes.

Si este código todavía existe en el año 2100 (que no es bisiesto), necesitará verificar el manejo adecuado de las fechas posteriores al 28 de febrero.
