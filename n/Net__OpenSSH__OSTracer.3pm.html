NOMBRE

Net::OpenSSH::OSTracer - rastrea el proceso maestro de ssh a nivel del sistema operativo

SINOPSIS

use Net::OpenSSH;
$Net::OpenSSH::debug |= 512;
Net::OpenSSH->new($host)->system("echo hola mundo");
system "less /tmp/net_openssh_master.*.strace";

DESCRIPCIÓN

Este es un módulo auxiliar de Net::OpenSSH que te permite rastrear el proceso maestro "ssh" a nivel del sistema operativo utilizando la utilidad adecuada disponible en tu sistema (por ejemplo, "strace", "truss", "ktruss", "tusc", etc.).

Esta función se puede utilizar para depurar tus programas o para informar de errores en el módulo.

Se habilita estableciendo el bit 512 en la variable $Net::OpenSSH::debug:

$Net::OpenSSH::debug |= 512;

Por defecto, los archivos de salida del rastreador se guardan como "/tmp/net_openssh_master.$pid.$tracer_type".

Además, la salida enviada por el rastreador a stdout/stderr se guarda como "/tmp/net_openssh_master.$pid.txt".

El módulo se puede configurar a través de las siguientes variables globales:

$Net::OpenSSH::OSTracer::type
Por defecto, el módulo decide qué rastreador usar basándose en el nombre del sistema operativo. Esta variable permite seleccionar un rastreador diferente.

Los tipos actualmente aceptados son: "strace" (Linux), "ktrace" (*BSD), "tusc" (HP-UX) y "truss" (Solaris y AIX).

$Net::OpenSSH::OSTracer::cmd
Comando a ejecutar para rastrear el proceso "ssh".

Por defecto, lo infiere del tipo de rastreador seleccionado.

$Net::OpenSSH::OSTracer::output
Nombre base para el archivo de destino. Se añadirán el PID del proceso "ssh" y el tipo de rastreador.
$Net::OpenSSH::OSTracer::sudo
Esta variable se puede usar para solicitar que el rastreador se ejecute con "sudo" (algunos sistemas operativos, como Ubuntu por ejemplo, no permiten adjuntar rastreadores, ni siquiera a tus propios procesos, a menos que lo hagas como root).

La variable debe establecerse con la ruta al binario "sudo". Por ejemplo:

$Net::OpenSSH::OSTracer::sudo = '/usr/bin/sudo';

Si necesitas pasar una contraseña a "sudo", establece la variable de entorno "SUDO_ASKPASS". Por ejemplo:

SUDO_ASKPASS=/usr/bin/ssh-askpass
$Net::OpenSSH::OSTracer::delay
Esta variable se puede usar para retrasar la ejecución de "ssh" para que el rastreador pueda adjuntar el proceso primero. Esto es especialmente útil cuando se usa "sudo" con una contraseña.

ERRORES

Este módulo no ha sido probado en todos los sistemas operativos que dice soportar.

Si encuentras algún problema, ¡simplemente repórtalo, por favor!
