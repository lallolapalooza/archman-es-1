NOMBRE

Net::DNS - Interfaz de Perl para el Sistema de Nombres de Dominio

SINOPSIS

use Net::DNS;
my $resolver = Net::DNS::Resolver->new(...);
my $response = $resolver->send(...);

DESCRIPCIÓN

Net::DNS es una colección de módulos de Perl que actúan como un resolutor del Sistema de Nombres de Dominio (DNS). Permite al programador realizar consultas DNS que van más allá de las capacidades de "gethostbyname" y "gethostbyaddr".

El programador debe estar familiarizado con la estructura de un paquete DNS y el formato de presentación del archivo de zona descrito en RFC1035.

Objetos Resolutor

Un objeto resolutor es una instancia de la clase Net::DNS::Resolver. Un programa puede tener múltiples objetos resolutor, cada uno manteniendo su propia información de estado, como los servidores de nombres a consultar, si la recursión es deseada, etc.

Objetos Paquete

Las consultas de Net::DNS::Resolver devuelven objetos Net::DNS::Packet. Un objeto paquete tiene cinco secciones:

  • cabecera, representada por un objeto Net::DNS::Header
  • pregunta, una lista de no más de un objeto Net::DNS::Question
  • respuesta, una lista de objetos Net::DNS::RR
  • autoridad, una lista de objetos Net::DNS::RR
  • adicional, una lista de objetos Net::DNS::RR

Objetos Actualización

Net::DNS::Update es una subclase de Net::DNS::Packet útil para crear solicitudes de actualización dinámica.

Objeto Cabecera

El objeto Net::DNS::Header media el acceso a los datos de cabecera que residen dentro del Net::DNS::Packet correspondiente.

Objeto Pregunta

El objeto Net::DNS::Question representa el contenido de la sección de pregunta del paquete DNS.

Objetos RR

Net::DNS::RR es la clase base para los objetos de registro de recurso DNS (RR) en las secciones de respuesta, autoridad y adicional de un paquete DNS.

No asuma que los objetos RR serán del tipo solicitado. El tipo de un objeto RR debe ser verificado antes de llamar a cualquier método.

MÉTODOS

Net::DNS exporta métodos y funciones auxiliares para soportar actualizaciones DNS, gestión de números de serie de zonas y consultas DNS simples.

version

use Net::DNS;
print Net::DNS->version, "\n";

Devuelve la versión de Net::DNS.

rr

# Usa un resolutor por defecto -- no se puede obtener una cadena de error de esta manera.
use Net::DNS;
my @rr = rr("example.com");
my @rr = rr("example.com", "AAAA");
my @rr = rr("example.com", "AAAA", "IN");
# Usa tu propio objeto resolutor.
my $res = Net::DNS::Resolver->new;
my @rr  = rr($res, "example.com" ... );
my ($ptr) = rr("2001:DB8::dead:beef");

El método rr() proporciona una búsqueda simple de RR para escenarios donde no se requiere la flexibilidad completa de Net::DNS.

Devuelve una lista de objetos Net::DNS::RR para el nombre especificado o una lista vacía si la consulta falló o no se encontró ningún registro.

Ver "EJEMPLOS" para ejemplos más completos.

mx

# Usa un resolutor por defecto -- no se puede obtener una cadena de error de esta manera.
use Net::DNS;
my @mx = mx("example.com");
# Usa tu propio objeto resolutor.
my $res = Net::DNS::Resolver->new;
my @mx  = mx($res, "example.com");

Devuelve una lista de objetos Net::DNS::RR::MX que representan los registros MX para el nombre especificado. La lista se ordenará por preferencia. Devuelve una lista vacía si la consulta falló o no se encontró ningún registro MX.

Este método no busca registros de dirección; resuelve solo MX.

Soporte de Actualización Dinámica DNS

El módulo Net::DNS proporciona funciones auxiliares que soportan solicitudes de actualización dinámica DNS.

$update = Net::DNS::Update->new( 'example.com' );
$update->push( prereq => nxrrset('example.com. AAAA') );
$update->push( update => rr_add('example.com. 86400 AAAA 2001::DB8::F00') );

yxrrset

Utilice este método para añadir un prerrequisito de "RRset existe" a un paquete de actualización dinámica. Hay dos formas, independiente del valor y dependiente del valor:

# RRset existe (independiente del valor)
$update->push( pre => yxrrset("host.example.com AAAA") );

Significado: Debe existir al menos un RR con el nombre y tipo especificados.

# RRset existe (dependiente del valor)
$update->push( pre => yxrrset("host.example.com AAAA 2001:DB8::1") );

Significado: Debe existir al menos un RR con el nombre y tipo especificados y debe tener datos coincidentes.

Devuelve un objeto Net::DNS::RR o "undef" si el objeto no pudo ser creado.

nxrrset

Utilice este método para añadir un prerrequisito de "RRset no existe" a un paquete de actualización dinámica.

$update->push( pre => nxrrset("host.example.com AAAA") );

Significado: No pueden existir RRs con el nombre y tipo especificados.

Devuelve un objeto Net::DNS::RR o "undef" si el objeto no pudo ser creado.

yxdomain

Utilice este método para añadir un prerrequisito de "el nombre está en uso" a un paquete de actualización dinámica.

$update->push( pre => yxdomain("host.example.com") );

Significado: Debe existir al menos un RR con el nombre especificado.

Devuelve un objeto Net::DNS::RR o "undef" si el objeto no pudo ser creado.

nxdomain

Utilice este método para añadir un prerrequisito de "el nombre no está en uso" a un paquete de actualización dinámica.

$update->push( pre => nxdomain("host.example.com") );

Significado: No puede existir ningún RR con el nombre especificado.

Devuelve un objeto Net::DNS::RR o "undef" si el objeto no pudo ser creado.

rr_add

Utilice este método para añadir RRs a una zona.

$update->push( update => rr_add("host.example.com AAAA 2001:DB8::c001:a1e") );

Significado: Añadir este RR a la zona.

Los objetos RR creados por este método deben añadirse a la sección "update" de un paquete de actualización dinámica. El TTL por defecto es 86400 segundos (24 horas) si no se especifica.

Devuelve un objeto Net::DNS::RR o "undef" si el objeto no pudo ser creado.

rr_del

Utilice este método para eliminar RRs de una zona. Hay tres formas: eliminar todos los RRsets, eliminar un RRset y eliminar un RR específico.

# Eliminar todos los RRsets.
$update->push( update => rr_del("host.example.com") );

Significado: Eliminar todos los RRs que tengan el nombre especificado.

# Eliminar un RRset.
$update->push( update => rr_del("host.example.com AAAA") );

Significado: Eliminar todos los RRs que tengan el nombre y tipo especificados.

# Eliminar un RR específico.
$update->push( update => rr_del("host.example.com AAAA 2001:DB8::dead:beef") );

Significado: Eliminar el RR que coincide con el argumento especificado.

Los objetos RR creados por este método deben añadirse a la sección "update" de un paquete de actualización dinámica.

Devuelve un objeto Net::DNS::RR o "undef"

EJEMPLOS

Los siguientes breves ejemplos ilustran algunas de las características de Net::DNS. La documentación para módulos individuales y los scripts de demostración incluidos con la distribución proporcionan ejemplos más extensos.

Ver Net::DNS::Update para un ejemplo de realización de actualizaciones dinámicas.

Buscar direcciones de host.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->search( "www.example.com", "AAAA" );
die "la consulta falló: ", $res->errorstring unless $reply;
foreach my $rr ( $reply->answer ) {
        print $rr->address, "\n" if $rr->can("address");
}

Encontrar los servidores de nombres para un dominio.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->query( "example.com", "NS");
die "la consulta falló: ", $res->errorstring unless $reply;
foreach $rr ( grep {$_->type eq "NS"} $reply->answer ) {
        print $rr->nsdname, "\n";
}

Encontrar los registros MX para un dominio.

use Net::DNS;
my $name = "example.com";
my $res  = Net::DNS::Resolver->new;
my @mx   = mx( $res, $name );
foreach $rr (@mx) {
        print $rr->preference, "\t", $rr->exchange, "\n";
}

Imprimir el registro SOA del dominio en formato de archivo de zona.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->query( "example.com", "SOA" );
die "la consulta falló: ", $res->errorstring unless $reply;
foreach my $rr ( $reply->answer ) {
        $rr->print;
}

Realizar una transferencia de zona e imprimir todos los registros.

use Net::DNS;
my $res  = Net::DNS::Resolver->new(
        nameservers => ["a.iana-servers.net", "b.iana-servers.net"],
        tcp_timeout => 20
        );
my @zone = $res->axfr("example.com");
warn $res->errorstring if $res->errorstring;
foreach $rr (@zone) {
        $rr->print;
}

Realizar una consulta en segundo plano e imprimir la respuesta.

use Net::DNS;
my $res    = Net::DNS::Resolver->new;
$res->udp_timeout(10);
$res->tcp_timeout(20);
my $socket = $res->bgsend( "www.example.com", "AAAA" );
while ( $res->bgbusy($socket) ) {
        # hacer algo de trabajo aquí mientras se espera la respuesta
        # ...y algo más aquí
}
my $packet = $res->bgread($socket);
die "la consulta falló: ", $res->errorstring unless $packet;
$packet->print;
