NOMBRE

Net::DNS::RR::DSYNC - Registro de recursos DSYNC de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name DSYNC rrtype scheme port target');

DESCRIPCIÓN

Clase para registros de recursos de Notificación Generalizada (DSYNC) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas y podría resultar en la terminación del programa u otro comportamiento impredecible.

rrtype

$rrtype = $rr->rrtype;
$rr->rrtype($rrtype);

El tipo de NOTIFY generalizada para la cual este RR DSYNC define la dirección de destino deseada.

scheme

$scheme = $rr->scheme;
$rr->scheme( $scheme );

El esquema indica el modo utilizado para localizar la dirección de notificación. Este es un entero sin signo de 8 bits. Los registros con valor 0 (esquema nulo) son ignorados por los consumidores.

port

$port = $rr->port;
$rr->port( $port );

El puerto en el host que proporciona el servicio de notificación. Este es un entero sin signo de 16 bits.

target

$target = $rr->target;
$rr->target( $target );

El nombre de dominio del host de destino que proporciona el servicio que escucha las notificaciones del tipo especificado. Este nombre DEBE resolverse en uno o más registros de dirección.
