Net::DNS::Text(3) Documentación Perl aportada por el usuario Net::DNS::Text(3)

NOMBRE

Net::DNS::Text - representación de texto DNS

SINOPSIS

use Net::DNS::Text;
$objeto = Net::DNS::Text->new('ejemplo');
$cadena = $objeto->string;
$objeto = Net::DNS::Text->decode( \$datos, $offset );
( $objeto, $siguiente ) = Net::DNS::Text->decode( \$datos, $offset );
$datos = $objeto->encode;
$texto = $objeto->value;

DESCRIPCIÓN

El módulo "Net::DNS::Text" implementa una clase de objetos de texto con métodos de clase y de instancia asociados.

Cada instancia de objeto de texto tiene una identidad fija durante toda su vida.

MÉTODOS

new

$objeto = Net::DNS::Text->new('ejemplo');

Crea un objeto de texto que encapsula un único componente de cadena de caracteres de un registro de recursos.

Se pueden representar caracteres arbitrarios de un solo byte con \ seguido de exactamente tres dígitos decimales. Dichos caracteres carecen de significado especial.

Un carácter precedido por \ representa sí mismo, sin ninguna interpretación especial.

decode

$objeto = Net::DNS::Text->decode( \$buffer, $offset );
( $objeto, $siguiente ) = Net::DNS::Text->decode( \$buffer, $offset );

Crea un objeto de texto que representa los datos decodificados en el desplazamiento indicado dentro del búfer de datos.

La lista de argumentos consta de una referencia a un escalar que contiene los datos en formato de cable y el desplazamiento de los datos de texto.

El valor de desplazamiento devuelto indica el inicio del siguiente elemento en el búfer de datos.

encode

$datos = $objeto->encode;

Devuelve la representación codificada en formato de cable del objeto de texto, adecuada para su inclusión en un búfer de paquete DNS.

raw

$datos = $objeto->raw;

Devuelve la representación codificada en formato de cable del objeto de texto sin el campo de longitud explícito.

value

$valor = $texto->value;

Representación en cadena de caracteres del objeto de texto.

string

$cadena = $texto->string;

Representación de archivo de zona RFC1035, entrecomillada condicionalmente, del objeto de texto.

unicode

$cadena = $texto->unicode;

Representación Unicode, entrecomillada condicionalmente, del objeto de texto.

ERRORES

La estrategia de codificación está pensada para evitar la creación de listas de argumentos y marcos de pila innecesarios. Esto mejora la eficiencia a expensas de la legibilidad del código.

Las características de codificación de caracteres específicas de la plataforma se compilan condicionalmente en el código.
