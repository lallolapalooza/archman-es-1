Net::DNS::Domain(3) Documentación de Perl aportada por el usuario Net::DNS::Domain(3)

NOMBRE

Net::DNS::Domain - dominios DNS

SINOPSIS

use Net::DNS::Domain;
$dominio = Net::DNS::Domain->new('ejemplo.com');
$nombre  = $dominio->name;

DESCRIPCIÓN

El módulo Net::DNS::Domain implementa una clase de objetos de dominio DNS abstractos con métodos de clase e instancia asociados.

Cada instancia de objeto de dominio representa un único dominio DNS que tiene una identidad fija durante toda su vida útil.

Internamente, la representación principal es una lista (posiblemente vacía) de etiquetas de nombres de dominio ASCII y un enlace opcional a un objeto de dominio de origen topológicamente más cercano a la raíz de DNS.

El coste computacional de la conversión del conjunto de caracteres Unicode se mitiga parcialmente mediante el uso de cachés.

MÉTODOS

new

$objeto = Net::DNS::Domain->new('ejemplo.com');

Crea un objeto de dominio que representa el dominio DNS especificado por el argumento de cadena de caracteres. El argumento consiste en una secuencia de etiquetas delimitadas por puntos.

Un carácter precedido por \ representa sí mismo, sin ninguna interpretación especial.

Los códigos arbitrarios de 8 bits se pueden representar por \ seguido de exactamente tres dígitos decimales. Los puntos de código de caracteres son ASCII, independientemente del esquema de codificación de caracteres empleado por la plataforma subyacente.

Las cadenas literales de argumento deben delimitarse con comillas simples para evitar que las secuencias de escape se interpreten como códigos de caracteres octales por el compilador de Perl.

El formato de presentación de la cadena de caracteres sigue las convenciones para archivos de zona descritas en RFC1035.

Los usuarios deben tener en cuenta que los nombres de dominio no ASCII se transcodificarán a NFC antes de la codificación, lo que es un proceso irreversible.

name

$nombre = $dominio->name;

Devuelve el nombre del dominio como una cadena de caracteres que corresponde a la "interpretación común" a la que alude RFC1034, 3.1, párrafo 9.

Las secuencias de escape de caracteres se utilizan para representar un punto dentro de una etiqueta de nombre de dominio y el propio carácter de escape.

Cualquier punto de código no imprimible se representa utilizando la secuencia de escape numérica apropiada.

fqdn

$fqdn = $dominio->fqdn;

Devuelve una cadena de caracteres que contiene el nombre de dominio completamente cualificado, incluido el punto final.

xname

$xname = $dominio->xname;

Interpreta un nombre extendido que contiene etiquetas de nombres de dominio Unicode codificadas como A-labels Punycode.

Si la decodificación no es posible, se devuelve el nombre codificado en ACE.

label

@etiqueta = $dominio->label;

Identifica el dominio mediante una lista de etiquetas de dominio.

string

$cadena = $objeto->string;

Devuelve una cadena de caracteres que contiene el nombre de dominio completamente cualificado tal como aparece en un archivo de zona.

Los caracteres que son reconocidos por la sintaxis de archivo de zona RFC1035 se representan mediante la secuencia de escape apropiada.

origin

$crear = Net::DNS::Domain->origin( $ORIGIN );
$resultado = &$crear( sub{ Net::DNS::RR->new( 'mx MX 10 a' ); } );
$esperado = Net::DNS::RR->new( "mx.$ORIGIN. MX 10 a.$ORIGIN." );

Método de clase que devuelve una referencia a un envoltorio de subrutina que ejecuta un constructor dado en un contexto de ámbito dinámico donde los nombres relativos se convierten en descendientes del $ORIGIN especificado.

ERRORES

La estrategia de codificación está pensada para evitar la creación de listas de argumentos y marcos de pila innecesarios. Esto mejora la eficiencia a expensas de la legibilidad del código.

Las características de codificación de caracteres específicas de la plataforma se compilan condicionalmente en el código.
