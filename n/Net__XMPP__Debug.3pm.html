NOMBRE

Net::XMPP::Debug - Módulo de depuración XMPP

SINOPSIS

Net::XMPP::Debug es un módulo que proporciona a los desarrolladores un fácil acceso al registro de información de depuración.

DESCRIPCIÓN

Debug es un módulo auxiliar para los módulos Net::XMPP. Proporciona a los módulos Net::XMPP un objeto para controlar dónde, cómo y qué se registra.

Funciones básicas

$Debug = Net::XMPP::Debug->new();
$Debug->Init(
       level  => 2,
       file   => "stdout",
       header =>"MiScript");
$Debug->Log0("Conexión establecida");

MÉTODOS

Funciones básicas

new
new(hash)

Crea el objeto Debug. El argumento hash se pasa a la función Init. Consulte la descripción de esa función a continuación para conocer la configuración válida.

Init
Init(
     level      => entero,
     file       => cadena,
     header     => cadena,
     setdefault => 0|1,
     usedefault => 0|1,
     time       => 0|1)

Inicializa el objeto de depuración.

El level determina el nivel máximo de mensajes de depuración a registrar:

0 - Salida de nivel base (por defecto)
1 - Llamadas a API de alto nivel
2 - Llamadas a API de bajo nivel
...
N - Lo que quieras....

El file determina a dónde va el registro de depuración. Puede especificar una ruta a un archivo o "stdout" (el valor predeterminado). "stdout" le indica a Debug que envíe toda la información de depuración enviada a este objeto a stdout.

header es una cadena que se antepondrá al principio de todas las entradas de registro. Esto facilita ver qué generó la entrada de registro (el valor predeterminado es "Debug").

setdefault guarda el manejador de archivos actual y lo pone a disposición para que lo usen otros objetos Debug. Para usar el valor predeterminado, establezca usedefault en 1.

El parámetro time especifica si se debe agregar o no una marca de tiempo al principio de cada línea registrada.

LogN
LogN(array)

Registra los elementos de la matriz en el nivel de depuración correspondiente N. Si pasa una referencia a una matriz o hash, se imprimirán de manera legible. (es decir... Log0, Log2, Log100, etc...)

EJEMPLO

$Debug = Net::XMPP:Debug->new(level=>2,
                             header=>"Ejemplo");
$Debug->Log0("prueba");
$Debug->Log2("prueba de nivel 2");
$hash{a} = "pruebaa";
$hash{b} = "pruebab";
$Debug->Log1("prueba de hash", \%hash);

Obtendría el siguiente registro:

Ejemplo: prueba
Ejemplo: prueba de nivel 2
Ejemplo: prueba de hash { a=>"pruebaa" b=>"pruebab" }

Si hubiera establecido el nivel en 1 en lugar de 2, obtendría:

Ejemplo: prueba
Ejemplo: prueba de hash { a=>"pruebaa" b=>"pruebab" }
