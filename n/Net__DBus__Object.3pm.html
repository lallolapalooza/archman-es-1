NOMBRE

Net::DBus::Object - Implementa objetos para exportar al bus

SINOPSIS

# Conectar un objeto al bus, bajo un servicio
package main;
use Net::DBus;
# Adjuntar al bus
my $bus = Net::DBus->find;
# Adquirir un servicio 'org.demo.Hello'
my $service = $bus->export_service("org.demo.Hello");
# Exportar nuestro objeto dentro del servicio
my $object = Demo::HelloWorld->new($service);
....resto del programa...
# Definir un nuevo paquete para el objeto que vamos
# a exportar
package Demo::HelloWorld;
# Especificar la interfaz principal proporcionada por nuestro objeto
use Net::DBus::Exporter qw(org.example.demo.Greeter);
# Seremos un objeto DBus
use base qw(Net::DBus::Object);
# Exportar una señal 'Greeting' que toma un parámetro de cadena
dbus_signal("Greeting", ["string"]);
# Exportar 'Hello' como un método que acepta un único parámetro de cadena
# y devuelve un único valor de cadena
dbus_method("Hello", ["string"], ["string"]);
sub new {
    my $class = shift;
    my $service = shift;
    my $self = $class->SUPER::new($service, "/org/demo/HelloWorld");
    bless $self, $class;
    return $self;
}
sub Hello {
  my $self = shift;
  my $name = shift;
  $self->emit_signal("Greeting", "Hello $name");
  return "Said hello to $name";
}
# Exportar 'Goodbye' como un método que acepta un único parámetro de cadena
# y devuelve una única cadena, pero ponerlo en la interfaz
# 'org.exaple.demo.Farewell'
dbus_method("Goodbye", ["string"], ["string"], "org.example.demo.Farewell");
sub Goodbye {
  my $self = shift;
  my $name = shift;
  $self->emit_signal("Greeting", "Goodbye $name");
  return "Said goodbye to $name";
}

DESCRIPCIÓN

Esta es la base para implementar objetos que se exportan directamente al bus. Los métodos implementados en una subclase se mapean a métodos en el bus. Al usar esta clase, una aplicación está vinculando directamente la funcionalidad RPC a su modelo de objetos. Por lo tanto, las aplicaciones pueden preferir usar la clase "Net::DBus::ProxyObject" que permite que la funcionalidad RPC se mantenga separada del modelo de objetos central, proxyficando las llamadas a métodos RPC.

MÉTODOS

mi $objeto = Net::DBus::Object->new($servicio, $ruta)
Esto crea un nuevo objeto DBus con una ruta de $ruta registrada dentro del servicio $servicio. El parámetro $ruta debe ser una cadena que cumpla con los requisitos habituales de DBus para rutas de objetos, mientras que el parámetro $servicio debe ser una instancia de Net::DBus::Service. Este último se obtiene típicamente llamando al método "export_service" en el objeto Net::DBus.
mi $objeto = Net::DBus::Object->new($parentobj, $subruta)
Esto crea un nuevo objeto hijo DBus con una ruta de $subruta relativa a su padre $parentobj. El parámetro $subruta debe ser una cadena que cumpla con los requisitos habituales de DBus para rutas de objetos, mientras que el parámetro $parentobj debe ser una instancia de Net::DBus::BaseObject o una subclase.
