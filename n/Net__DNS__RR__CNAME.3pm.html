NOMBRE

Net::DNS::RR::CNAME - Registro de recurso CNAME de DNS

SINOPSIS

use Net::DNS;
$rr = Net::DNS::RR->new('name CNAME cname');
$rr = Net::DNS::RR->new(
                name  => 'alias.example.com',
                type  => 'CNAME',
                cname => 'example.com',
                );

DESCRIPCIÓN

Clase para los registros de recurso CNAME (Canonical Name) de DNS.

MÉTODOS

Los métodos disponibles son los heredados de la clase base, aumentados por los métodos específicos del tipo definidos en este paquete.

No se recomienda el uso de características del paquete no documentadas o el acceso directo a estructuras de datos internas, ya que podría provocar la terminación del programa u otro comportamiento impredecible.

cname

$cname = $rr->cname;
$rr->cname( $cname );

Un nombre de dominio que especifica el nombre canónico o principal del propietario. El nombre del propietario es un alias.
