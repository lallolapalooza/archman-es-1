NOMBRE

Net::DNS::RR::NSEC3 - Registro de recurso DNS NSEC3

SINTAXIS

use Net::DNS;
$rr = Net::DNS::RR->new('name NSEC3 algorithm flags iterations salt hnxtname');

DESCRIPCIÓN

Clase para registros de recursos DNS NSEC3.

El Registro de Recurso DNS NSEC3 (RR) proporciona una denegación de existencia autenticada para los conjuntos de recursos DNS.

El Registro de RR NSEC3 lista los tipos de recursos presentes en el nombre original del registro NSEC3. Incluye el siguiente nombre de propietario hashado en el orden de hash del zona. El conjunto completo de registros de RR NSEC3 en una zona indica qué RRsets existen para el nombre original del registro y forman una cadena de nombres hashados en la zona.

MÉTODOS

Los métodos disponibles son aquellos heredados de la clase base, ajenos a los métodos específicos definidos en este paquete.

La utilización de características no documentadas del paquete o el acceso directo a estructuras internas se desaconseja y podría provocar el cierre del programa o comportamientos inesperados.

algoritmo

$algorithm = $rr->algorithm;
$rr->algorithm( $algorithm );

El campo algoritmo de 8 bits se representa como un entero decimal sin signo, pero puede especificarse utilizando el mero nombre del algoritmo.

algorithm() puede también invocarse como método de clase o función simple para realizar la traducción de código mnemónico y numérico.

flags

$flags = $rr->flags;
$rr->flags( $flags );

El campo Flags se representa como un entero decimal sin signo que se interpreta como ocho valores booleanos concatenados.

optout
$rr->optout(1);
if ( $rr->optout ) {
        ...
}

Flag de Opt Out booleano.

iterations

$iterations = $rr->iterations;
$rr->iterations( $iterations );

El campo Iterations se representa como un entero decimal sin signo. El valor está entre 0 y 65535, incluido.

salt

$salt = $rr->salt;
$rr->salt( $salt );

El campo Salt se representa como una secuencia continua de dígitos hexadecimales. Se utiliza un signo (-) (sin comillas) en formato de cadena para indicar que el campo salt es ausente.

saltbin

$saltbin = $rr->saltbin;
$rr->saltbin( $saltbin );

El campo Salt como secuencia de octetos.

hnxtname

$hnxtname = $rr->hnxtname;
$rr->hnxtname( $hnxtname );

El Nombre de Propietario Hashado Siguiente indica el siguiente nodo que tiene datos autoritarios o contiene un punto de delegación NS RRset.

typelist

@typelist = $rr->typelist;
$typelist = $rr->typelist;
$rr->typelist( @typelist );

typelist() identifica los tipos de RRset que existen en el nombre de dominio correspondiente al registro NSEC3. Cuando se llama en contexto escalar, la lista se interpola en una cadena.

typemap

$exists = $rr->typemap($rrtype);

typemap() devuelve un valor booleano true si el tipo de RR especificado ocurre en el bitmap de tipos del registro NSEC3.

match

$matched = $rr->match( 'example.foo' );

match() devuelve un valor booleano true si el hash del nombre de dominio argumento coincide con el nombre de propietario hashado del registro NSEC3.

covers

$covered = $rr->covers( 'example.foo' );

covers() devuelve un valor booleano true si el hash del nombre de dominio argumento, o ascendiente de ese nombre, se encuentra entre el nombre de propietario y el siguiente nombre de propietario hashado del registro NSEC3.

encloser, nextcloser, wildcard

$encloser = $rr->encloser( 'example.foo' );
print "encloser: $encloser\n" if $encloser;

encloser() devuelve el nombre de un encloser provable del nombre de consulta argumento obtenido del registro NSEC3.

nextcloser() devuelve el siguiente closer nombre, que es un nombre de etiqueta más largo que el encloser más cercano. Esto es válido solo después de que encloser() haya devuelto un nombre de dominio válido.

wildcard() devuelve el nombre de wildcard no expandido desde el cual el siguiente closer nombre podría haber sido sintetizado. Esto es válido solo después de que encloser() haya devuelto un nombre de dominio válido.
