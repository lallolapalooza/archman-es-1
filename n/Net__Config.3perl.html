Net::Config(3perl) Guía de referencia para programadores Perl Net::Config(3perl)

Nombre

Net::Config - Datos de configuración locales para libnet

Sintaxis

use Net::Config qw(%NetConfig);

Descripción

Net::Config almacena datos de configuración para los módulos en la distribución libnet. Durante la instalación, se le pedirá estos valores.

Los datos de configuración se mantienen globalmente en un archivo dentro del árbol de instalación Perl, pero un usuario puede reemplazar cualquier valor proporcionando su propio. Esto puede hacerse mediante un archivo .libnetrc en su directorio de usuarios. Este archivo debe devolver una referencia a un HASH con las claves descritas a continuación. Por ejemplo:

# .libnetrc
{
    nntp_hosts => [ "my_preferred_host" ],
    ph_hosts   => [ "my_ph_server" ],
}
__END__

Métodos de Clase

Net::Config define los siguientes métodos. Son métodos como los invocados como métodos de clase. Esto se debe a que Net::Config hereda de Net::LocalCfg, por lo que se puede reemplazar estos métodos si lo desea.

requires_firewall($host)
Intenta determinar si un host dado está fuera de su firewall. Los valores posibles son. 
-1  No se puede consultar el nombre del host
 0  El host está dentro del firewall (o no hay entrada ftp_firewall)
 1  El host está fuera del firewall

Esto se hace usando la consulta del nombre del host y la entrada local_netmask en el archivo de configuración.

Valores de NetConfig

nntp_hosts
snpp_hosts
pop3_hosts
smtp_hosts
ph_hosts
daytime_hosts
time_hosts
Cada uno es una referencia a un array de nombres de host (en orden de preferencia), que deben ser utilizados para el protocolo dado
inet_domain
El nombre de dominio de internet de su sistema
ftp_firewall
Si tiene un proxy FTP (no un HTTP o un SOCKS), entonces este valor debería ser el nombre del firewall. Si su firewall no escucha en el puerto 21, entonces este valor debería ser "hostname:port" (ej. "hostname:99")
ftp_firewall_type

ftp_ext_passive
ftp_int_passive
Los servidores de FTP pueden funcionar en modo pasivo o activo. El modo activo implica que tienes que decir al servidor la dirección y el puerto para conectarse. El modo pasivo es cuando el servidor proporciona la dirección y el puerto y establece la conexión.

Con algunos firewalls, el modo activo no funciona porque el servidor no puede conectar a su máquina (debido a que está tras un firewall) y el firewall no reescribe el comando. En este caso, se debe establecer "ftp_ext_passive" a un valor true.

Algunos servidores están configurados para funcionar solo en modo pasivo. Si tienes uno de estos, puedes forzar Net::FTP a siempre transferir en modo pasivo; cuando no vaya por un firewall, mediante el establecimiento de "ftp_int_passive" a un valor true.

local_netmask
Una referencia a un listado de cadenas de red en el formato "134.99.4.0/24". Estos se usan por la función requires_firewall para determinar si un host dado está dentro o fuera de su firewall.

Las siguientes entradas son utilizadas durante la instalación y las pruebas en el paquete libnet:

test_hosts
Si es verdadero, make test puede intentar conectar a hosts dados en la configuración.
test_exists
Si es verdadero, Configure comprobará que cada nombre de host dado existe.
