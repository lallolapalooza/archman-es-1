NOMBRE

Net::DNS::SEC::Tools::conf - Rutinas de configuración de DNSSEC-Tools.

SINOPSIS

use Net::DNS::SEC::Tools::conf;
%dtconf = parseconfig();
%dtconf = parseconfig("localzone.keyrec");
cmdcheck(\%options_hashref);
$conferrs = dt_confcheck();
$prefixdir = getprefixdir();
$confdir = getconfdir();
$conffile = getconffile();
setconffile("dt-local.conf");
$statedir = getlocalstatedir();
$statedir = makelocalstatedir();
$statesub = makelocalstatedir("logs/zones");
$packed = runpacked();
erraction(ERR_MSG);
err("unable to open keyrec file",1);

DESCRIPCIÓN

Las rutinas de este módulo realizan operaciones de configuración. Algunas rutinas acceden al archivo de configuración de DNSSEC-Tools, mientras que otras validan el entorno de ejecución.

Las herramientas de DNSSEC tienen un archivo de configuración para los valores de uso común. Estos valores son los predeterminados para una variedad de cosas, como el algoritmo de cifrado y la longitud de la clave de cifrado. El módulo Net::DNS::SEC::Tools::conf proporciona métodos para acceder a los datos de configuración de este archivo.

dnssec-tools.conf es el nombre de archivo de la configuración de las herramientas DNSSEC. La ruta completa depende de cómo se configuraron las DNSSEC-Tools; consulte la sección DIRECTORIOS para ver la ruta completa. Las rutas requeridas por conf.pm se establecen en el momento de la configuración de DNSSEC-Tools.

El archivo de configuración de las herramientas DNSSEC consta de un conjunto de entradas de valores de configuración, con una sola entrada por línea. Cada entrada tiene el formato "keyword value". Durante el análisis, la línea se divide en tokens, y los tokens están separados por espacios y tabulaciones. El primer token de una línea se considera la palabra clave. Todos los demás tokens de esa línea se concatenan en una sola cadena, con un espacio separando cada token. La cadena sin tokenizar se agrega a una tabla hash, con la palabra clave como clave del valor.

Se pueden incluir comentarios anteponiéndoles los caracteres de comentario '#' o ';'. Estos comentarios pueden ocupar una línea completa o seguir a una entrada de configuración. Si un comentario comparte una línea con una entrada, la tokenización del valor se detiene justo antes del carácter de comentario.

A continuación, se muestra un ejemplo de archivo de configuración:

# Sample configuration entries.
algorithm       rsasha1     # Encryption algorithm.
ksk_length      2048        ; KSK key length.

Otro aspecto de la configuración de DNSSEC-Tools es la acción de error utilizada por los módulos Perl de DNSSEC-Tools. La acción dicta si una condición de error solo dará un valor de retorno de error, imprimirá un mensaje de error en STDERR o imprimirá un mensaje de error y saldrá. Las interfaces erraction() y err() se utilizan para estas operaciones.

INTERFACES

dt_confcheck(errflag)
Esta rutina realiza una serie de comprobaciones de configuración para garantizar que el entorno sea suficiente para soportar la configuración de DNSSEC-Tools. Si errflag es 0, las comprobaciones se realizan silenciosamente; de lo contrario, se imprimirán mensajes de error.

Las comprobaciones son:

* El directorio sysconf de dnssec-tools existe.
* El directorio sysconf de dnssec-tools es un directorio.
* El directorio de dnssec-tools existe.
* El directorio de dnssec-tools es un directorio.
* El archivo de configuración de dnssec-tools existe.
* El archivo de configuración de dnssec-tools es un archivo regular.
* El archivo de configuración de dnssec-tools no está vacío.
* El nombre del directorio de estado local no tiene más de 75
  caracteres (para permitir el socket del comando rollmgr.)
* El directorio de estado local es un directorio.
* El directorio de estado local se puede crear si es necesario.
* El subdirectorio dnssec-tools del directorio de estado local
  se puede crear si es necesario, o es escribible si ya existe.
* El subdirectorio run del directorio de estado local
  se puede crear si es necesario, o es escribible si ya existe.

Valores de retorno:

0       no se encontraron errores
>0      fallaron algunas comprobaciones de configuración
parseconfig()
Esta rutina lee y analiza el archivo de configuración del sistema de herramientas DNSSEC. El contenido analizado se coloca en una tabla hash, que se devuelve al llamador.
parseconfig(conffile)
Esta rutina lee y analiza un archivo de configuración de herramientas DNSSEC especificado por el llamador. El contenido analizado se coloca en una tabla hash, que se devuelve al llamador. La rutina devuelve silenciosamente si el archivo de configuración no existe.
cmdcheck(\%options_hashref)
Esta rutina garantiza que los comandos necesarios estén disponibles y sean ejecutables. Si alguno de los comandos no existe o no es ejecutable, se mostrará un mensaje de error y el proceso finalizará. Si todo está bien, todo continuará silenciosamente.

Las claves de comandos que se comprueban actualmente son zonecheck, keygen y zonesign. Las rutas de estos comandos se encuentran en el hash de opciones proporcionado, al que se hace referencia en \%options_hashref. Si el hash no contiene una entrada para uno de esos comandos, no se comprueba.

Si esta rutina se llama desde un script empaquetado en PAR, buscará los comandos en el directorio del paquete. También establecerá sus modos de archivo en 0755, ya que PAR parece ignorar los modos de archivo al empaquetar programas.

getconfdir()
Esta rutina devuelve el nombre del directorio de configuración de DNSSEC-Tools.
getconffile()
Esta rutina devuelve el nombre del archivo de configuración de DNSSEC-Tools.
setconffile()
Esta rutina establece el nombre del archivo de configuración de DNSSEC-Tools.

Valores de retorno:
1 devuelto en caso de éxito
0 devuelto si el archivo de configuración especificado no
existe o no es un archivo regular

getprefixdir()
Esta rutina devuelve el nombre del directorio de prefijo de DNSSEC-Tools.
getlocalstatedir()
Esta rutina devuelve el nombre del directorio de estado local.
runpacked()
Esta rutina devuelve un booleano que indica si el comando en ejecución se está ejecutando desde un script empaquetado en PAR.
makelocalstatedir(subdir)
Esta rutina crea el directorio de estado local y devuelve su nombre. El directorio se crea solo si aún no existe.

Si se especifica el subdirectorio opcional subdir, entonces se crea ese directorio dentro del directorio de estado local. En este caso, se devuelve la ruta de subdir. subdir puede constar de varios directorios intermedios, así como del directorio terminal. Por ejemplo, makelocalstatedir("logs/zones/errors") creará la jerarquía logs/zones/errors dentro del directorio de estado local.

makelocalstatedir(subdir) utiliza el módulo File::Path, que está disponible en todas las versiones modernas de Perl.

Se devuelve una cadena vacía si hay algún error. Los siguientes errores pueden ser encontrados:

* No se pudo cargar I<File::Path>
* No se pudo crear el directorio de estado local
* No se pudo crear un componente de I<subdir>
* La ruta completa (directorio de estado local y I<subdir>) ya
  existe y no es un directorio
boolconvert(config-value)
Esta rutina convierte los valores de configuración en valores booleanos apropiados. Las siguientes conversiones de texto se realizan: 
1 - 'true', 't', 'yes', 'y'
0 - 'false', 'f', 'no', 'n'

Todos los demás valores de texto se convierten a 0.

Los valores positivos se convierten a 1. Los valores negativos se convierten a 0.

El segundo argumento es un código de salida, si la acción de error requiere que el proceso salga.

DIRECTORIOS

Los directorios predeterminados para esta instalación son:

prefix                         : /usr
sysconf                        : /etc
localstatedir                  : /usr/var
DNSSEC-Tools configuration file: /etc/dnssec-tools

Estos pueden ser anulados utilizando las siguientes variables ambientales:

prefix                         : DT_PREFIX
sysconf                        : DT_SYSCONFDIR
localstatedir                  : DT_STATEDIR
