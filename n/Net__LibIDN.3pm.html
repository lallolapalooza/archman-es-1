NOMBRE

Net::LibIDN - Enlaces de Perl para GNU Libidn

SINOPSIS

use Net::LibIDN ':all';
idn_to_ascii("Räksmörgås.Josefßon.ORG") eq
  idn_to_ascii(idn_to_unicode("xn--rksmrgs-5wao1o.josefsson.org"));
idn_prep_name("LibÜDN") eq "libüdn";
idn_punycode_encode("kistenmöhre") eq
  idn_punycode_encode(idn_punycode_decode("kistenmhre-kcb"));
my $errpos;
tld_check("mèrle.se", $errpos) eq undef;
  $errpos == 1;
tld_get("mainbase.mars") eq "mars";
my $hashref = Net::LibIDN::tld_get_table("de");
print "$hashref->{version}\n";
foreach (@{$hashref->{valid}})
{
  print "Rango Unicode de " . $_->{start} . " a " . $_->{end} . "\n";
}

DESCRIPCIÓN

Proporciona enlaces para GNU Libidn, una biblioteca C para manejar Nombres de Dominio Internacionalizados según IDNA (RFC 3490), de una manera muy inspirada en PHP-IDN de Turbo Fredriksson.

Funciones

Net::LibIDN::idn_to_ascii($hostname_claro, [$charset, [$flags]]);
Convierte $hostname_claro, que podría contener caracteres fuera del rango permitido en nombres DNS, a ACE IDNA. Si se especifica $charset, trata la cadena como si estuviera codificada en él, de lo contrario, asume que está codificada en ISO-8859-1. Si el indicador IDNA_ALLOW_UNASSIGNED está establecido en $flags, acepta también caracteres Unicode no asignados; si está establecido IDNA_USE_STD3_ASCII_RULES, solo acepta caracteres LDH ASCII (letras-dígitos-guión). Los indicadores se pueden combinar con ||. Devuelve el resultado de la conversión o undef en caso de error.
Net::LibIDN::idn_to_unicode($idn_hostname, [$charset, [$flags]]);
Convierte el $idn_hostname ASCII, que podría estar codificado como ACE IDNA, a su forma decodificada en $charset o ISO-8859-1. Los indicadores se interpretan como arriba. Devuelve el resultado de la conversión o undef en caso de error.
Net::LibIDN::idn_punycode_encode($cadena, [$charset]);
Codifica $cadena a "punycode" (RFC 3492). Si $charset está presente, trata $cadena como si estuviera en $charset, de lo contrario usa ISO-8859-1. Devuelve el resultado de la conversión o undef en caso de error.
Net::LibIDN::idn_punycode_decode($cadena, [$charset]);
Decodifica $cadena de "punycode" (RFC 3492). Si $charset está presente, el resultado se convierte a $charset, de lo contrario se convierte a ISO-8859-1. Devuelve el resultado de la conversión o undef en caso de error.
Net::LibIDN::idn_prep_name($cadena, [$charset]);
Net::LibIDN::idn_prep_kerberos5($cadena, [$charset]);
Net::LibIDN::idn_prep_node($cadena, [$charset]);
Net::LibIDN::idn_prep_resource($cadena, [$charset]);
Net::LibIDN::idn_prep_plain($cadena, [$charset]);
Net::LibIDN::idn_prep_trace($cadena, [$charset]);
Net::LibIDN::idn_prep_sasl($cadena, [$charset]);
Net::LibIDN::idn_prep_iscsi($cadena, [$charset]);
Realiza "stringprep" (RFC 3454) en $cadena según el perfil nombrado (por ejemplo, *_name -> "nameprep" (RFC 3491)). Si $charset está presente, se convierte desde y hacia este charset antes y después de la operación respectivamente. Devuelve la cadena resultante o undef en caso de error.
Net::LibIDN::tdl_check($cadena, $pos_error, [$charset, [$tld]]);
Verifica si $cadena se ajusta a las restricciones en los conjuntos de caracteres válidos definidos por las autoridades TLD en todo el mundo. Trata $cadena como un nombre de host si $tld no está presente, determinando el TLD a partir del nombre de host. Si $tld está presente, utiliza las restricciones definidas por las partes responsables del TLD $tld. $charset se puede usar para especificar el conjunto de caracteres en el que se encuentra $cadena. Si se detecta un carácter inválido, devuelve 0 y la posición basada en 0 del carácter infractor en $pos_error. En caso de otras condiciones de error, $pos_error no se modifica y se devuelve undef. Si $cadena se ajusta a las restricciones del TLD, se devuelve 1.
Net::LibIDN::tld_get($hostname);
Devuelve el dominio de nivel superior del $hostname, o undef si ocurre un error o si no se encuentra ningún dominio de nivel superior.
Net::LibIDN::tld_get_table($tld);
Recupera una referencia hash con la información de restricciones del TLD del TLD dado $tld, o undef si $tld no se encuentra. La referencia hash contiene los siguientes campos:
  • $h->{nombre} ... nombre del TLD
  • $h->{version} ... cadena de versión de esta tabla de restricciones
  • $h->{nvalid} ... número de intervalos Unicode
  • $h->{valid} ... [ {inicio => número, fin => número}, ...] ... intervalos Unicode

Limitaciones

Actualmente no hay soporte para las capacidades unicode de Perl (man perlunicode). Se asume que todas las cadenas de entrada son cadenas de octetos, todas las cadenas de salida se generan como cadenas de octetos. Por lo tanto, si requieres las características unicode de Perl, tendrás que convertir tus cadenas manualmente. Por ejemplo:

use Encode;

use Data::Dumper;

print Dumper(Net::LibIDN::idn_to_unicode('xn--uro-j50a.com', 'utf-8'));

print Dumper(decode('utf-8', Net::LibIDN::idn_to_unicode('xn--uro-j50a.com', 'utf-8')));
