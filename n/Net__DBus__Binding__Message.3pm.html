NOMBRE

Net::DBus::Binding::Message - Clase base para mensajes

SINOPSIS

Envío de un mensaje

my $msg = new Net::DBus::Binding::Message::Signal;
my $iterator = $msg->iterator;
$iterator->append_byte(132);
$iterator->append_int32(14241);
$connection->send($msg);

DESCRIPCIÓN

Proporciona una clase base para los diferentes tipos de mensaje que pueden ser enviados/recibidos. Las instancias de esta clase nunca se instancian directamente, en su lugar se deben usar uno de los cuatro subtipos Net::DBus::Binding::Message::Signal, Net::DBus::Binding::Message::MethodCall, Net::DBus::Binding::Message::MethodReturn, Net::DBus::Binding::Message::Error.

MÉTODOS

mi $msg = Net::DBus::Binding::Message->new(message => $rawmessage);
Crea un nuevo objeto mensaje, inicializándolo con el objeto mensaje C subyacente proporcionado por el objeto "message". Este constructor está destinado únicamente a uso interno; en su lugar, consulte uno de los cuatro subtipos para este tipo de clase para tipos de mensaje específicos.
mi $type = $msg->get_type
Recupera el código de tipo de este mensaje. El valor devuelto corresponde a una de las cuatro constantes "Net::DBus::Binding::Message::MESSAGE_TYPE_*".
mi $interface = $msg->get_interface
Recupera el nombre de la interfaz a la que se dirige este mensaje, posiblemente una cadena vacía si no hay una interfaz aplicable para este mensaje.
mi $path = $msg->get_path
Recupera la ruta del objeto asociada con el mensaje, posiblemente una cadena vacía si no hay un objeto aplicable para este mensaje.
mi $name = $msg->get_destination
Recupera el nombre único o conocido del bus para el cliente destinado a ser el destinatario del mensaje. Posiblemente devuelve una cadena vacía si el mensaje se está transmitiendo a todos los clientes.
mi $name = $msg->get_sender
Recupera el nombre único del cliente que envía el mensaje.
mi $serial = $msg->get_serial
Recupera el número de serie único de este mensaje. El número está garantizado que sea único mientras la conexión a través de la cual se envió el mensaje permanezca abierta. Puede devolver cero si el mensaje aún no se ha enviado.
mi $name = $msg->get_member
Para llamadas a métodos, recupera el nombre del método a invocar, mientras que para señales, recupera el nombre de la señal.
mi $sig = $msg->get_signature
Recupera una cadena que representa la firma de tipo de los valores empaquetados en el cuerpo del mensaje.
$msg->set_sender($name)
Establece el nombre del cliente que envía el mensaje. El nombre debe ser el nombre único del cliente.
$msg->set_destination($name)
Establece el nombre del destinatario previsto del mensaje. Esto se utiliza normalmente para señales para cambiar de difusión a unicast.
mi $iterator = $msg->iterator;
Recupera un iterador que se puede utilizar para leer o escribir campos del mensaje. El objeto devuelto es una instancia de la clase "Net::DBus::Binding::Iterator".
$boolean = $msg->get_no_reply()
Obtiene el indicador que indica si se espera una respuesta para el mensaje.
$msg->set_no_reply($boolean)
Activa o desactiva el indicador que indica si se espera una respuesta para el mensaje. Todas las llamadas a métodos esperan una respuesta por defecto. Al activar/desactivar este indicador, se reduce la latencia de comunicación al eliminar la necesidad de que el cliente espere.
mi @values = $msg->get_args_list
Desempaqueta todos los valores en el cuerpo del mensaje, utilizando la firma del mensaje para identificar los tipos de datos. Los valores se devuelven como una lista.
$msg->append_args_list(@values)
Añade un conjunto de valores al cuerpo del mensaje. Los valores se codificarán como una cadena, lista o diccionario según corresponda a su tipo de dato en Perl. Para necesidades de tipado de datos más específicas, se debe usar el objeto Net::DBus::Binding::Iterator en su lugar.
