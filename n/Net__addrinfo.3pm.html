addrinfo(3) Documentación de Perl aportada por el usuario addrinfo(3)

NOMBRE

Net::addrinfo - interfaz para getaddrinfo(3) POSIX y constantes, estructuras y funciones relacionadas.

SINOPSIS

use Net::addrinfo;
my $ainfo = getaddrinfo("www.marzot.net");

DESCRIPCIÓN

Este módulo Perl está diseñado para implementar y exportar funcionalidades relacionadas con la llamada al sistema getaddrinfo(3) POSIX. Se proporciona el objeto de datos Net::addrinfo con funciones accesoras de nombres de campo, con nombres similares a la definición de la estructura de datos C en netdb.h. Se exportan las llamadas getaddrinfo(3), gai_strerror(3), y las constantes relacionadas.

La rutina getaddrinfo() imita la función documentada POSIX (ver la página del manual del sistema getaddrinfo(3)).

En caso de éxito, getaddrinfo() devolverá una matriz de objetos de datos Net::addrinfo.

En contexto escalar, getaddrinfo() devolverá el primer elemento de la matriz Net::addrinfo.

En caso de error, se devolverá un código de error numérico.

El código de error puede pasarse a gai_strerror() para obtener una representación de cadena del error.

Se pueden crear nuevos objetos Net::addrinfo con el constructor del paquete y se pueden especificar cualquiera (o ninguna) de los campos.

flags => entero escalar
family => entero escalar (p. ej., AF_INET,m AF_INET6, etc.)
socktype => entero escalar (p. ej., SOCK_DGRAM, SOCK_STREAM, etc.)
protocol => entero escalar (p. ej., IPPROTO_UDP, IPPROTO_TCP, etc.)
addrlen => entero escalar (se puede calcular por length($self->addr))
addr => bytes empaquetados (p. ej., $self->addr(inet_aton("192.168.1.1")); )

Los flags se pueden establecer en la estructura para que pueda utilizarse como parámetro de 'hint' (pista) para la función getaddrinfo(). Consulte @AI_FLAGS exportado para obtener una lista de constantes aceptables.

(Nota: se proporciona un campo escalar entero especial, 'val_status', en apoyo de los resultados de addrinfo conscientes de DNSSEC (ver Net::DNS::SEC::Validator))

EJEMPLOS

use Net::addrinfo;
use Socket qw(:all);
my $hint = new Net::addrinfo(flags => AI_CANONNAME,
                             family => AF_INET, 
                             socktype => SOCK_DGRAM);
my (@ainfo) = getaddrinfo("www.marzot.net", "http", $hint);
foreach $ainfo (@ainfo) {
   if (ref $ainfo eq 'Net::addrinfo') {
      print $ainfo->stringify(), "\n";
      print "addr = ", inet_ntoa($ainfo->addr), "\n";
      ...
      connect(SH, $ainfo->addr);
    } else {
       print "Error($ainfo):", gai_strerror($ainfo), "\n";
    }
}

NOTA

No se debe confiar en la representación interna de esta clase.
