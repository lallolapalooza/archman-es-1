NOMBRE

Net::LDAPS - usar LDAP sobre una conexión SSL

SINOPSIS

use Net::LDAPS;
$ldaps = Net::LDAPS->new('mihost.example.com',
                         port => '10000',
                         verify => 'require',
                         capath => '/usr/local/cacerts/');
# forma alternativa
use Net::LDAP;
$ldaps = Net::LDAP->new('ldaps://mihost.example.com:10000',
                        verify => 'require',
                        capath => '/usr/local/cacerts/');

DESCRIPCIÓN

Comunícate usando el protocolo LDAP a un servidor de directorio utilizando una conexión de red cifrada (SSL). Este mecanismo no es estándar pero es ampliamente soportado; considera usar LDAPv3 con la extensión TLS estándar si es posible (muchos servidores aún no lo soportan.) Ver "start_tls" en Net::LDAP.

Todos los métodos normales de "Net::LDAP" pueden ser usados con un objeto "Net::LDAPS"; ver Net::LDAP para detalles.

CONSTRUCTOR

new ( HOST [, OPCIONES ] )
Crea una nueva conexión. HOST es el nombre de host al que contactar. OPCIONES es un número de pares clave/valor. Ver "new" en Net::LDAP para detalles.

VER TAMBIÉN

Net::LDAP, IO::Socket::SSL

ERRORES

No puedes tener más de una conexión LDAPS a la vez, debido a restricciones en el código subyacente Net::SSLeay.
