Net::LDAP::Extra::eDirectory(3) Documentación de Perl aportada por el usuario Net::LDAP::Extra::eDirectory(3)

NOMBRE

Net::LDAP::Extra::eDirectory -- extensiones para Novell eDirectory

SINOPSIS

use Net::LDAP::Extra qw(eDirectory);
$ldap = Net::LDAP->new( ... );
...
if ($ldap->is_eDirectory)
  my $mesg $ldap->list_replicas($server_dn);
  print "Réplicas en $server_dn\n* " . join("\n* ", $mesg->replicas) . "\n"
    if (!$mesg->code);
}

DESCRIPCIÓN

Net::LDAP::Extra::eDirectory proporciona funciones / extensiones LDAP específicas para Novell eDirectory.

Para ello, proporciona los siguientes métodos:

MÉTODOS

is_eDirectory ( )
Indica si el servidor LDAP consultado es un servidor Novell eDirectory.

Dado que la comprobación se realiza consultando el DSE raíz del directorio, funciona sin necesidad de estar enlazado al directorio.

En contraste con otros métodos de Net::LDAP, este método devuelve TRUE / FALSE respectivamente, o undef en caso de error.

list_replicas ( SERVER_DN, OPCIONES )
Consulta las réplicas en el servidor dado SERVER_DN.

En caso de éxito, el objeto Net::LDAP::Message resultante soporta el método "replicas" que devuelve la lista de réplicas en SERVER_DN.

get_replica_info ( SERVER_DN, REPLICA_DN, OPCIONES )
Consulta información de REPLICA_DN en SERVER_DN.

En caso de éxito, el objeto Net::LDAP::Message resultante soporta el método "replica_info" que devuelve un hash que contiene información sobre REPLICA_DN.

trigger_backlinker ( OPCIONES )
Dispara el proceso BackLinker, que resuelve referencias externas para asegurar que apuntan a entradas reales.
trigger_janitor ( OPCIONES )
Dispara el proceso Janitor, que comprueba la conectividad con todos los servidores de la base de datos.
trigger_limber ( OPCIONES )
Dispara el proceso Limber, que verifica el nombre del servidor, la dirección IPX interna y la conectividad del árbol de todas las réplicas.
trigger_skulker ( OPCIONES )
Dispara el proceso Skulker, que comprueba el estado de sincronización de cada servidor en el anillo de réplicas.
trigger_schemasync ( OPCIONES )
Dispara SchemaSync.
trigger_partitionpurge ( OPCIONES )
Dispara PartitionPurge.
refresh_ldap_server ( OPCIONES )
Dispara la actualización del servicio NLDAP.
