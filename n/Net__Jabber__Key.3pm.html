Net::Jabber::Key(3) Documentación de Perl aportada por el usuario Net::Jabber::Key(3)

NOMBRE

Net::Jabber::Key - Biblioteca de claves Jabber

SINÓPSIS

Net::Jabber::Key es un módulo que proporciona al desarrollador un fácil acceso
para generar, almacenar en caché y comparar claves.

DESCRIPCIÓN

Key.pm es un módulo auxiliar para Net::Jabber::Transport. Cuando
Transport habla con un Cliente, envía una clave y espera recibir esa
clave del Cliente. Este módulo proporciona una API para generar,
almacenar en caché y luego comparar la clave enviada por el Cliente.

Funciones básicas

$Key = new Net::Jabber::Key();
$key = $Key->Generate();
$key = $Key->Create("bob\@jabber.org");
$test = $Key->Compare("bob\@jabber.org","alguna clave");

MÉTODOS

Funciones básicas

new(debug=>string,       - crea el objeto Key. debug debe
    debugfh=>FileHandle,   ser la ruta para el registro de
    debuglevel=>integer)   depuración. Si se establece en "stdout"
                           entonces la depuración irá allí. También,
                           puede especificar un manejador de archivo que ya
                           exista y usarlo. debuglevel controla
                           la cantidad de depuración. 0 es ninguna, 1 es
                           normal, 2 es toda.
Generate() - devuelve una clave en formato Digest SHA1 basada en el tiempo
             actual y el PID.
Create(cacheString) - genera una clave y la almacena en caché con la clave
                      de cacheString. Create devuelve la clave.
Compare(cacheString, - compara la clave almacenada en caché bajo
        keyString)     cacheString con keyString. Devuelve 1
                       si coinciden y 0 en caso contrario.
