NOMBRE

MrmFetchWidget — Obtiene y crea un widget de aplicación indexado (con nombre UIL) y sus hijos

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchWidget(
MrmHierarchy hierarchy_id,
String index,
Widget parent_widget,
Widget *widget,
MrmType *class);

DESCRIPCIÓN

La función MrmFetchWidget obtiene y crea un widget de aplicación indexado y sus hijos. El widget de aplicación indexado es cualquier widget que tenga nombre en UIL. En las operaciones de obtención, también se obtienen y crean los subárboles del widget obtenido. Este widget no debe aparecer como hijo de un widget dentro de su propio subárbol. MrmFetchWidget no ejecuta XtManageChild para el widget recién creado.

Todos los widgets obtenidos mediante una llamada a MrmFetchWidget no están gestionados en el momento de sus llamadas de creación.

hierarchy_id
Especifica el ID de la jerarquía UID que contiene la definición de la interfaz. El valor de hierarchy_id se devolvió en una llamada anterior a MrmOpenHierarchyPerDisplay.
index
Especifica el nombre UIL del widget a obtener.
parent_widget
Especifica el ID del widget padre.
widget
Devuelve el ID del widget creado.
class
Este argumento debe establecerse como un puntero real; no puede ser un puntero NULL. MrmFetchWidget establece este argumento con un valor dependiente de la implementación.

Una aplicación puede obtener cualquier widget con nombre en la jerarquía UID usando MrmFetchWidget. MrmFetchWidget se puede llamar en cualquier momento para obtener un widget que no se obtuvo al inicio de la aplicación. MrmFetchWidget se puede utilizar para posponer la obtención de widgets emergentes hasta que se referencien por primera vez (presumiblemente en una devolución de llamada), y luego se utiliza para obtenerlos una sola vez.

MrmFetchWidget también puede crear múltiples instancias de un widget (y su subárbol). En este caso, la definición UID funciona como una plantilla; una definición de widget puede obtenerse cualquier número de veces. Una aplicación puede utilizar esta plantilla para crear múltiples instancias de un widget, por ejemplo, en un cuadro de diálogo o un menú.

El índice (nombre UIL) que identifica el widget debe ser conocido por la aplicación.

RETORNAR

Esta función devuelve una de las siguientes constantes de retorno de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmBAD_HIERARCHY
El ID de jerarquía no era válido.
MrmNOT_FOUND
El widget no se encontró en la jerarquía UID.
MrmFAILURE
La función falló.

RELACIONADO

MrmOpenHierarchyPerDisplay(3), MrmFetchWidgetOverride(3).
