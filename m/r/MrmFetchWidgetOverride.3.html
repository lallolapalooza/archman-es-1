Licencias: LGPL-2.1-or-later

MrmFetchWidgetOverride(llamada a biblioteca) MrmFetchWidgetOverride(llamada a biblioteca)

NOMBRE

MrmFetchWidgetOverride — Obtiene cualquier widget de aplicación indexado (con nombre UIL). Sobrescribe los argumentos especificados para este widget de aplicación en UIL

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchWidgetOverride(
MrmHierarchy hierarchy_id,
String index,
Widget parent_widget,
String override_name,
ArgList override_args,
Cardinal override_num_args,
Widget *widget,
MrmType *class);

DESCRIPCIÓN

La función MrmFetchWidgetOverride es la versión extendida de MrmFetchWidget. Es idéntica a MrmFetchWidget, excepto que permite al llamador sobrescribir el nombre del widget y cualquier argumento que MrmFetchWidget recuperaría de otro modo del archivo UID o de uno de los mecanismos de predeterminación. Es decir, la lista de argumentos de sobrescritura no se limita a los argumentos del archivo UID.

Los argumentos de sobrescritura solo se aplican al widget obtenido y devuelto por esta función. Sus hijos (subárbol) no reciben ningún parámetro de sobrescritura.

hierarchy_id
Especifica el ID de la jerarquía UID que contiene la definición de interfaz. El valor de hierarchy_id se devolvió en una llamada anterior a MrmOpenHierarchyPerDisplay.
index
Especifica el nombre UIL del widget a obtener.
parent_widget
Especifica el ID del widget padre.
override_name
Especifica el nombre para sobrescribir el nombre del widget. Utilice un valor NULL si no desea sobrescribir el nombre del widget.
override_args
Especifica la lista de argumentos de sobrescritura, exactamente como se proporciona a XtCreateWidget (conversión completa y así sucesivamente). Utilice un valor NULL si no desea sobrescribir la lista de argumentos.
override_num_args
Especifica el número de argumentos en override_args.
widget
Devuelve el ID del widget creado.
class
Devuelve el código de clase que identifica la clase de widget de MRM. Los literales que identifican los códigos de clase de widget de MRM se definen en el archivo de inclusión Mrm/MrmPublic.h.

VALOR DE RETORNO

Esta función devuelve una de las siguientes constantes de retorno de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmBAD_HIERARCHY
El ID de jerarquía no era válido.
MrmNOT_FOUND
El widget no se encontró en la jerarquía UID.
MrmFAILURE
La función falló.

RELACIONADO

MrmOpenHierarchyPerDisplay(3), MrmFetchWidget(3).
