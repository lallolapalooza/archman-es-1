Paquete: openmotif

Licencias: LGPL-2.1-or-later

MrmOpenHierarchyPerDisplay(llamada de biblioteca) MrmOpenHierarchyPerDisplay(llamada de biblioteca)

NOMBRE

MrmOpenHierarchyPerDisplay — Asigna un ID de jerarquía y abre todos los archivos UID en la jerarquía

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmOpenHierarchyPerDisplay(
Display *display,
MrmCount num_files,
String file_names_list[],
MrmOsOpenParamPtr *ancillary_structures_list,
MrmHierarchy *hierarchy_id);

DESCRIPCIÓN

MrmOpenHierarchyPerDisplay le permite especificar la lista de archivos UID que MRM busca en operaciones de obtención posteriores. Todas las operaciones de obtención posteriores devuelven la primera ocurrencia del elemento nombrado encontrada al recorrer la jerarquía de UID desde el primer elemento de la lista (especificación de archivo UID) hasta el último elemento de la lista. Esta función también asigna un ID de jerarquía y abre todos los archivos UID en la jerarquía. Inicializa las listas de búsqueda optimizadas en la jerarquía. Si MrmOpenHierarchyPerDisplay encuentra algún error durante su ejecución, se cerrarán los archivos que se hayan abierto.

La aplicación debe llamar a XtAppInitialize antes de llamar a MrmOpenHierarchyPerDisplay.

display
Especifica la conexión con el servidor X y el valor que se pasará a XtResolvePathname. Para más información sobre la estructura Display, consulte la función de Xlib XOpenDisplay.
num_files
Especifica el número de archivos en la lista de nombres.
file_names_list
Especifica una matriz de cadenas de caracteres que identifican los archivos UID.
ancillary_structures_list
Una lista de estructuras auxiliares dependientes del sistema operativo correspondientes a elementos como nombres de archivo, banderas de borrado, etc. Este argumento debe ser NULL para la mayoría de las operaciones. Si necesita hacer referencia a esta estructura, consulte la definición de MrmOsOpenParamPtr en el archivo de cabecera MrmPublic.h para más información.
hierarchy_id
Devuelve el ID de la jerarquía de búsqueda. El ID de la jerarquía de búsqueda identifica la lista de archivos UID que MRM busca (en orden) al realizar llamadas de obtención posteriores.

Cada cadena de archivo UID en file_names_list puede especificar una ruta completa o un nombre de archivo. Si una cadena de archivo UID tiene una / (barra) al principio, especifica una ruta completa y MRM abre el archivo como se especifica. De lo contrario, la cadena de archivo UID especifica un nombre de archivo. En este caso, MRM busca el archivo a lo largo de una ruta de búsqueda especificada por la variable de entorno UIDPATH o por una ruta de búsqueda predeterminada, que varía según si la variable de entorno XAPPLRESDIR está establecida o no.

La variable de entorno UIDPATH especifica una ruta de búsqueda y convenciones de nombres asociadas con los archivos UID. Puede contener el campo de sustitución %U, donde la cadena de archivo UID del argumento file_names_list para MrmOpenHierarchyPerDisplay se sustituye por %U. También puede contener los campos de sustitución aceptados por XtResolvePathname. El campo de sustitución %T siempre se mapea a uid. Toda la ruta se busca primero con %S mapeado a .uid. Si no se encuentra ningún archivo, se vuelve a buscar con %S mapeado a NULL. Por ejemplo, el siguiente valor de UIDPATH y la llamada a MrmOpenHierarchyPerDisplay hacen que MRM abra dos archivos UID separados:

UIDPATH=/uidlib/%L/%U.uid:/uidlib/%U/%L
  static char *uid_files[] = {"/usr/users/me/test.uid", "test2"};
  MrmHierarchy  *Hierarchy_id;
  MrmOpenHierarchyPerDisplay((MrmCount)2,uid_files, NULL, Hierarchy_id)

MRM abre el primer archivo, /usr/users/me/test.uid, como se especifica en el argumento file_names_list de MrmOpenHierarchyPerDisplay, porque la cadena de archivo UID en el argumento file_names_list especifica una ruta completa. MRM busca el segundo archivo, test2, primero como /uidlib/%L/test2.uid y segundo como /uidlib/test2/%L, donde la cadena de idioma de la pantalla se sustituye por %L.

Después de que MrmOpenHierarchyPerDisplay abra la jerarquía de UID, no debe eliminar ni modificar los archivos UID hasta que cierre la jerarquía de UID llamando a MrmCloseHierarchy.

Si UIDPATH no está configurado, pero la variable de entorno XAPPLRESDIR está configurada, MRM busca las siguientes rutas:

•
%U%S
•
$XAPPLRESDIR/%L/uid/%N/%U%S
•
$XAPPLRESDIR/%l/uid/%N/%U%S
•
$XAPPLRESDIR/uid/%N/%U%S
•
$XAPPLRESDIR/%L/uid/%U%S
•
$XAPPLRESDIR/%l/uid/%U%S
•
$XAPPLRESDIR/uid/%U%S
•
$HOME/uid/%U%S
•
$HOME/%U%S
•
/usr/lib/X11/%L/uid/%N/%U%S
•
/usr/lib/X11/%l/uid/%N/%U%S
•
/usr/lib/X11/uid/%N/%U%S
•
/usr/lib/X11/%L/uid/%U%S
•
/usr/lib/X11/%l/uid/%U%S
•
/usr/lib/X11/uid/%U%S
•
/usr/include/X11/uid/%U%S

Si ni UIDPATH ni XAPPLRESDIR están configurados, MRM busca las siguientes rutas:

•
%U%S
•
$HOME/%L/uid/%N/%U%S
•
$HOME/%l/uid/%N/%U%S
•
$HOME/uid/%N/%U%S
•
$HOME/%L/uid/%U%S
•
$HOME/%l/uid/%U%S
•
$HOME/uid/%U%S
•
$HOME/%U%S
•
/usr/lib/X11/%L/uid/%N/%U%S
•
/usr/lib/X11/%l/uid/%N/%U%S
•
/usr/lib/X11/uid/%N/%U%S
•
/usr/lib/X11/%L/uid/%U%S
•
/usr/lib/X11/%l/uid/%U%S
•
/usr/lib/X11/uid/%U%S
•
/usr/include/X11/uid/%U%S

Estas rutas son valores predeterminados que los proveedores pueden cambiar. Por ejemplo, un proveedor puede usar directorios diferentes para /usr/lib/X11 y /usr/include/X11.

Las siguientes sustituciones se utilizan en estas rutas:

%U
La cadena del archivo UID, del argumento file_names_list.
%N
El nombre de clase de la aplicación.
%L
La cadena de idioma de la pantalla. Esta cadena está influenciada por XtSetLanguageProc. La cadena predeterminada se determina llamando a setlocale(LC_ALL, NULL).
%l
El componente de idioma de la cadena de idioma de la pantalla.
%S
El sufijo del nombre de archivo. Toda la ruta se busca primero con un sufijo de .uid. Si no se encuentra ningún archivo, se vuelve a buscar con un sufijo NULL.

RETORNAR

Esta función devuelve una de las siguientes constantes de retorno de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmNOT_FOUND
Archivo no encontrado.
MrmFAILURE
La función falló.
