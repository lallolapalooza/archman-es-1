MrmFetchColorLiteral(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

MrmFetchColorLiteral(library call) MrmFetchColorLiteral(library call)

NOMBRE

MrmFetchColorLiteral — Recupera un literal de color con nombre de un archivo UID

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchColorLiteral(
MrmHierarchy hierarchy_id,
String index,
Display *display,
Colormap colormap_id,
Pixel *pixel);

DESCRIPCIÓN

La función MrmFetchColorLiteral recupera un literal de color con nombre de un archivo UID y convierte el literal de color a un valor de color de píxel.

hierarchy_id
Especifica el ID de la jerarquía UID que contiene el literal especificado. El valor de hierarchy_id se devolvió en una llamada anterior a MrmOpenHierarchyPerDisplay.
index
Especifica el nombre UIL del literal de color a recuperar. Debes definir este nombre en UIL como un valor exportado.
display
Especifica la pantalla utilizada para el mapa de bits. El argumento display especifica la conexión con el servidor X. Para obtener más información sobre la estructura Display, consulta la función Xlib XOpenDisplay.
colormap_id
Especifica el ID del mapa de colores. Si colormap_id es NULL, se utiliza el mapa de colores predeterminado.
pixel
Devuelve el ID del literal de color.

RETORNO

Esta función devuelve una de las siguientes constantes de retorno de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmBAD_HIERARCHY
El ID de la jerarquía no era válido.
MrmNOT_FOUND
El literal de color no se encontró en el archivo UIL.
MrmWRONG_TYPE
El llamador intentó recuperar un literal de un tipo no admitido por esta función.
MrmFAILURE
La función falló.

RELACIONADO

MrmFetchBitmapLiteral(3), MrmOpenHierarchyPerDisplay(3), MrmFetchIconLiteral(3), MrmFetchLiteral(3), y XOpenDisplay(3).
