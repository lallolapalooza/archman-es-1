NOMBRE

MrmFetchLiteral — Recupera un literal de un archivo UID

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchLiteral(
MrmHierarchy hierarchy_id,
String index,
Display *display,
XtPointer *value,
MrmCode *type);

DESCRIPCIÓN

La función MrmFetchLiteral lee y devuelve el valor y el tipo de un literal (valor con nombre) que se almacena como un recurso público en un único archivo UID. Esta función devuelve un puntero al valor del literal. Por ejemplo, un entero siempre se devuelve como un puntero a un entero, y una cadena siempre se devuelve como un puntero a una cadena.

Las aplicaciones no deben usar MrmFetchLiteral para recuperar literales de iconos o de color. Si se intenta esto, MrmFetchLiteral devuelve un error.

hierarchy_id
Especifica el ID de la jerarquía UID que contiene el literal especificado. El valor de hierarchy_id se devolvió en una llamada anterior a MrmOpenHierarchyPerDisplay.
index
Especifica el nombre UIL del literal (pixmap) a recuperar. Debe definir este nombre en UIL como un valor exportado.
display
Especifica la pantalla utilizada para el pixmap. El argumento display especifica la conexión al servidor X. Para obtener más información sobre la estructura Display, consulte la función de Xlib XOpenDisplay.
value
Devuelve el ID del valor del literal con nombre. La función asigna espacio para el valor devuelto. La aplicación es responsable de administrar el espacio asignado llamando a la función de desasignación adecuada. Por ejemplo, si el ID devuelto simboliza un pixmap, la aplicación puede recuperar el espacio asignado llamando a XmDestroyPixmap.
type
Devuelve el tipo de datos del literal con nombre. Los tipos se definen en el archivo de inclusión Mrm/MrmPublic.h.

RETORNO

Esta función devuelve una de las siguientes constantes de retorno de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmBAD_HIERARCHY
El ID de la jerarquía era inválido.
MrmNOT_FOUND
El literal no se encontró en el archivo UIL.
MrmWRONG_TYPE
El llamante intentó recuperar un literal de un tipo no admitido por esta función.
MrmFAILURE
La función falló.

RELACIONADO

MrmFetchBitmapLiteral(3), MrmOpenHierarchyPerDisplay(3), MrmFetchIconLiteral(3), MrmFetchColorLiteral(3), y XOpenDisplay(3).
