NOMBRE

MrmFetchIconLiteral — Recupera un literal de icono de una jerarquía

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchIconLiteral(
MrmHierarchy hierarchy_id,
String index,
Screen *screen,
Display *display,
Pixel fgpix,
Pixel bgpix,
Pixmap *pixmap);

DESCRIPCIÓN

La función MrmFetchIconLiteral recupera un literal de icono de una jerarquía MRM y convierte el literal de icono a un pixmap X.

hierarchy_id
Especifica el ID de la jerarquía UID que contiene el literal de icono especificado. El hierarchy_id se devolvió en una llamada anterior a MrmOpenHierarchyPerDisplay.
index
Especifica el nombre UIL del literal de icono a recuperar.
screen
Especifica la pantalla utilizada para el pixmap. El argumento screen especifica un puntero a la estructura Xlib Screen, que contiene la información sobre esa pantalla y está vinculada a la estructura Display. Para obtener más información sobre las estructuras Display y Screen, consulte la función Xlib XOpenDisplay y las macros asociadas de información de pantalla.
display
Especifica la pantalla utilizada para el pixmap. El argumento display especifica la conexión con el servidor X. Para obtener más información sobre la estructura Display, consulte la función Xlib XOpenDisplay.
fgpix
Especifica el color de primer plano para el pixmap.
bgpix
Especifica el color de fondo para el pixmap.
pixmap
Devuelve el valor resultante del pixmap X. La función asigna espacio para este pixmap. La aplicación es responsable de administrar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmDestroyPixmap.

RETORNO

Esta función devuelve una de las siguientes constantes de retorno de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmBAD_HIERARCHY
El ID de la jerarquía era inválido.
MrmNOT_FOUND
El literal de icono no se encontró en la jerarquía.
MrmWRONG_TYPE
El llamador intentó recuperar un literal de un tipo no admitido por esta función.
MrmFAILURE
La función falló.

RELACIONADOS

MrmFetchBitmapLiteral(3), MrmOpenHierarchyPerDisplay(3), MrmFetchLiteral(3), MrmFetchColorLiteral(3), y XOpenDisplay(3).
