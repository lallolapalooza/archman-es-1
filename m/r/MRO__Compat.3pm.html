MRO::Compat(3) Documentación de Perl aportada por el usuario MRO::Compat(3)

NOMBRE

MRO::Compat - compatibilidad de la interfaz mro::* para Perls < 5.9.5

SINOPSIS

package PPP;      use base qw/Exporter/;
package X;        use base qw/PPP/;
package Y;        use base qw/PPP/;
package Z;        use base qw/PPP/;
package FooClass; use base qw/X Y Z/;
package main;
use MRO::Compat;
my $linear = mro::get_linear_isa('FooClass');
print join(q{, }, @$linear);
# Imprime: FooClass, X, PPP, Exporter, Y, Z

DESCRIPCIÓN

El espacio de nombres "mro" proporciona varias utilidades para manejar el orden de resolución de métodos y la caché de métodos en general en Perl 5.9.5 y versiones posteriores.

Este módulo proporciona esas interfaces para versiones anteriores de Perl (al menos desde 5.6.0).

No tiene ningún efecto adverso utilizar este módulo en versiones 5.9.5+. Es decir, el código que utiliza correctamente MRO::Compat funcionará sin modificaciones tanto en Perls más antiguos como en versiones 5.9.5+.

Si estás escribiendo una pieza de software que quisiera utilizar las partes de las interfaces mro:: de 5.9.5+ que se soportan aquí, y deseas compatibilidad con versiones anteriores de Perl, este es el módulo para ti.

Algunas partes de este código funcionarán mejor y/o más rápido con Class::C3::XS instalado (que es un requisito previo opcional de Class::C3, que a su vez es un requisito previo de este paquete), pero no es obligatorio.

Este módulo nunca exporta ninguna función. Todas las llamadas deben estar completamente calificadas con el prefijo "mro::".

La documentación de la interfaz aquí sirve solo como una referencia rápida de lo que básicamente hace la función y de las diferencias entre MRO::Compat y 5.9.5+ a las que se debe prestar atención. La documentación principal en mro de 5.9.5 son los documentos de interfaz reales y contienen mucha otra información útil.

Funciones

mro::get_linear_isa($classname[, $type])

Devuelve una referencia a array que es el "ISA" linealizado de la clase dada. Utiliza la MRO que esté actualmente en vigor para esa clase por defecto, o la MRO dada (ya sea "c3" o "dfs" si se especifica como $type).

El ISA linealizado de una clase es una única lista ordenada de todas las clases que se visitarían en el proceso de resolución de un método en la clase dada, comenzando por sí misma. No incluye entradas duplicadas.

Ten en cuenta que "UNIVERSAL" (y cualquier miembro de la MRO de "UNIVERSAL") no forman parte de la MRO de una clase, aunque todas las clases hereden implícitamente métodos de "UNIVERSAL" y sus padres.

mro::import

Esto permite las sintaxis "use mro 'dfs'" y "use mro 'c3'", proporcionándote "use MRO::Compat" primero. Consulta la sección "USANDO C3" para obtener detalles adicionales.

mro::set_mro($classname, $type)

Establece la MRO de $classname a uno de los tipos "dfs" o "c3". Consulta la sección "USANDO C3" para obtener detalles adicionales.

mro::get_mro($classname)

Devuelve la MRO de la clase dada (ya sea "c3" o "dfs").

Considera cualquier clase que use Class::C3 como si tuviera MRO C3 incluso antes de que se llame a Class::C3::initialize().

mro::get_isarev($classname)

Devuelve una referencia a array de clases que son subclases de la clase dada. En otras palabras, clases en cuya jerarquía @ISA aparecemos, sin importar cuán indirectamente.

Esto es mucho más lento en Perls pre-5.9.5 con MRO::Compat que en versiones 5.9.5+, ya que tiene que buscar en todo el espacio de nombres de paquetes.

mro::is_universal($classname)

Devuelve un estado booleano que indica si la clase dada es "UNIVERSAL" en sí misma, o uno de los padres de "UNIVERSAL" por herencia @ISA.

Cualquier clase para la que esta función devuelva verdadero es "universal" en el sentido de que todas las clases potencialmente heredan métodos de ella.

mro::invalidate_all_method_caches

Incrementa "PL_sub_generation", lo que invalida la caché de métodos en todos los paquetes.

Ten en cuenta que esto rara vez es necesario, a menos que estés tratando con una situación que se sabe que confunde la caché de métodos de Perl.

mro::method_changed_in($classname)

Invalida la caché de métodos de cualquier clase dependiente de la clase dada. En MRO::Compat en Perls pre-5.9.5, esto es un alias para "mro::invalidate_all_method_caches" arriba, ya que los Perls pre-5.9.5 no tienen otra forma de hacer esto. Todavía forzará el requisito de que le pases un nombre de clase, por compatibilidad.

Ten en cuenta que esto rara vez es necesario, a menos que estés tratando con una situación que se sabe que confunde la caché de métodos de Perl.

mro::get_pkg_gen($classname)

Devuelve un entero que se incrementa cada vez que un método local o el @ISA del paquete dado cambian en Perl 5.9.5+. En Perls anteriores con este módulo MRO::Compat, probablemente se incrementará mucho más a menudo de lo necesario.

USANDO C3

Si bien este módulo pone a disposición las sintaxis "use mro 'c3'" y "mro::set_mro("Foo", 'c3')" de 5.9.5+ en versiones anteriores de Perl, lo hace simplemente delegando el trabajo a Class::C3.

No elimina la necesidad de llamar a Class::C3::initialize(), Class::C3::reinitialize() y/o Class::C3::uninitialize() en los momentos apropiados, como se documenta en los documentos de Class::C3. Estas tres funciones siempre son proporcionadas por MRO::Compat, ya sea a través de Class::C3 mismo en versiones anteriores de Perl, o directamente como no-operaciones en versiones 5.9.5+.
