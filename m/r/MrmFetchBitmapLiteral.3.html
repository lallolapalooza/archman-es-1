NOMBRE

MrmFetchBitmapLiteral — Recupera un literal de mapa de bits de una jerarquía

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmFetchBitmapLiteral(
MrmHierarchy hierarchy_id,
String index,
Screen *screen,
Display *display,
Pixmap *pixmap_return,
Dimension *width,
Dimension *height);

DESCRIPCIÓN

La función MrmFetchBitmapLiteral recupera un literal de mapa de bits de una jerarquía MRM y lo convierte en un mapa de bits X de profundidad 1. La función devuelve este mapa de bits, así como su anchura y altura.

hierarchy_id
Especifica el ID de la jerarquía UID que contiene el literal de icono especificado. El valor de hierarchy_id se obtuvo en una llamada anterior a MrmOpenHierarchyPerDisplay.
index
Especifica el nombre UIL del literal de mapa de bits a recuperar.
screen
Especifica la pantalla utilizada para el mapa de bits. El argumento screen apunta a la estructura Screen de Xlib, que contiene información sobre esa pantalla y está vinculada a la estructura Display. Para más información sobre las estructuras Display y Screen, consulte la función de Xlib XOpenDisplay y las macros asociadas de información de pantalla.
display
Especifica la pantalla utilizada para el mapa de bits. El argumento display especifica la conexión con el servidor X. Para más información sobre la estructura Display, consulte la función de Xlib XOpenDisplay.
pixmap_return
Devuelve el valor resultante del mapa de bits X. La función asigna espacio para este mapa de bits. La aplicación es responsable de la gestión del espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmDestroyPixmap.
width
Especifica un puntero a la anchura del mapa de bits.
height
Especifica un puntero a la altura del mapa de bits.

RETORNAR

Esta función devuelve una de las siguientes constantes de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmBAD_HIERARCHY
El ID de la jerarquía no era válido.
MrmNOT_FOUND
El literal de mapa de bits no se encontró en la jerarquía.
MrmWRONG_TYPE
El llamador intentó recuperar un literal de un tipo no soportado por esta función.
MrmFAILURE
La función falló.

RELACIONADO

MrmFetchIconLiteral(3), MrmFetchLiteral(3), y XOpenDisplay(3).
