MrmRegisterClass(llamada a biblioteca) MrmRegisterClass(llamada a biblioteca)

NOMBRE

MrmRegisterClass — Guarda la información necesaria para que MRM acceda a la función de creación de widgets para widgets definidos por el usuario

SINOPSIS

#include <Mrm/MrmPublic.h>
Cardinal MrmRegisterClass(
MrmType class_code,
String class_name,
String create_name,
Widget (*create_proc) (),
WidgetClass class_record);

DESCRIPCIÓN

La función MrmRegisterClass permite a MRM acceder a clases de widgets definidas por el usuario. Esta función registra la información necesaria para que MRM cree widgets de esta clase. Debe llamar a MrmRegisterClass antes de obtener cualquier widget de clase definido por el usuario.

MrmRegisterClass guarda la información necesaria para acceder a la función de creación de widgets y para realizar la conversión de tipos de listas de argumentos utilizando la información en las bases de datos de MRM.

class_code
Este argumento se ignora; está presente por compatibilidad con versiones anteriores.
class_name
Este argumento se ignora; está presente por compatibilidad con versiones anteriores.
create_name
Especifica el nombre sensible a mayúsculas y minúsculas de la función de creación de widgets de bajo nivel para la clase. Un ejemplo del Toolkit Motif es XmCreateLabel. Los argumentos son parent_widget, name, override_arglist y override_argcount.
Para widgets definidos por el usuario, create_name es el procedimiento de creación en el UIL que define este widget.
create_proc
Especifica la dirección de la función de creación que nombró en create_name.
class_record
Especifica un puntero al registro de clase.

RETORNO

Esta función devuelve una de las siguientes constantes de retorno de estado:

MrmSUCCESS
La función se ejecutó correctamente.
MrmFAILURE
La función falló.
