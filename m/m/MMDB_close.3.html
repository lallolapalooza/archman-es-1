DESCRIPCIÓN

La librería libmaxminddb proporciona funciones para trabajar con archivos de MaxMind DB. Consulte https://maxmind.github.io/MaxMind-DB/ para la especificación de formato de MaxMind DB. Los datos de la base de datos y los resultados se representan mediante estructuras diferentes. Las bases de datos se abren llamando a MMDB_abrir(). Puedes buscar direcciones IP como cadenas con MMDB_lookup_string() o como punteros a estructuras de sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esa estructura indica que la base de datos tiene datos para la IP, hay varias funciones que pueden usarse para recuperar ese dato. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Consulte la documentación de las funciones por más detalles.

Cuando termines con el handle de la base de datos, debes llamar a MMDB_cerrar().

Todas las funciones, estructuras y macros públicas comienzan con MMDB_.

ESTRUCTURAS DE DATOS

Todas las estructuras de datos expuestas por el archivo de cabecera maxminddb.h de esta librería se definen como typedef struct foo_s { ... } foo_s, por lo que puedes referirte a ellas sin el prefijo struct.

Esta librería proporciona las siguientes estructuras de datos:

MMDB_s

Esta es la referencia del handle de un archivo de MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados a uso público. Todos los otros campos están sujetos a cambios y se utilizan únicamente internamente.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - los flags con los que se abrió esta base de datos. Consulte la documentación de MMDB_abrir() para más detalles.
  • const char *filename - el nombre del archivo que se abrió, como se pasó a MMDB_abrir().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura se puede obtener de la estructura MMDB_s. Contiene los metadatos leídos de un archivo de base de datos. Nota: puede ser más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list().

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deberían ser bastante autodescriptivas.

El miembro ip_version debe ser siempre 4 o 6. El miembro binary_format_major_version debe ser siempre 2.

No hay requisitos específicos de que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que los miembros count de estos aspectos pueden ser cero. Todos los demás miembros de MMDB_metadata_s deben estar poblados.

MMDB_lookup_result_s

Esta estructura es el resultado de la búsqueda de una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, los demás miembros de esta estructura no contienen valores significativos. Debes verificar primero que found_entry es verdadero.

El miembro entry se usa para buscar los datos asociados con la dirección IP.

El miembro netmask indica qué subred pertenece la dirección IP en esta base de datos. Por ejemplo, si buscas la dirección 1.1.1.1 en una base de datos IPv4 y el valor devuelto es 16, entonces la dirección pertenece a la subred 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, el valor devuelto del netmask siempre es un largo de prefijo IPv6 (de 0 a 128), incluso si esa base de datos también contiene redes IPv4. Si buscas una dirección IPv4 y deseas convertir el netmask en un valor de máscara IPv4, simplemente resta 96 del valor.

MMDB_result_s

No necesitas profundizar en esta estructura. Obtendrás esta estructura de un MMDB_lookup_result_s y la pasarás a varias funciones.

MMDB_entry_data_s

Esta estructura se usa para devolver un único elemento de datos de una dirección IP. Estos elementos pueden apuntar a otros elementos, como en el caso de mapas y arrays. Algunos miembros de esta estructura no están documentados debido a su uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontró datos para una búsqueda específica. Consulte MMDB_get_value() para más detalles. Si este miembro es falso, ninguno de los otros valores en esta estructura es significativo.

La unión al inicio de la estructura define los datos reales. Para determinar qué miembro de la unión se está utilizando, vea el valor de has_data.

MMDB_entry_data_list_s

Esta estructura se usa para devolver un único elemento de datos de una dirección IP. Estos elementos pueden apuntar a otros elementos, como en el caso de mapas y arrays. Algunos miembros de esta estructura no están documentados debido a su uso interno.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

You must inspect the union's type member. The union's pointer member should never be populated in any data returned by the API. Pointers should be resolved internally.

The data_size member is only relevant for utf8_string and bytes data. utf8_string is not null terminated and data_size must be used to determine its length.

The type member may be compared against one of the MMDB_DATA_TYPE_* macros.

128-bit Integers

The handling of uint128 data depends on whether and how your platform supports 128-bit integers. With GCC 4.4 and 4.5 we can write unsigned int __attribute__ ((__mode__ (TI))). With more recent versions of GCC (4.6+) and clang (3.2+) we can simply write "unsigned __int128".

To avoid these differences, this library defines a mmdb_uint128_t type. This type is defined in maxminddb.h and you may use it in your own code.

With older compilers we cannot use an integer, so we use an array of 16 bytes of uint8_t. This is the raw data from the database.

This library provides a public macro MMDB_UINT128_IS_BYTE_ARRAY. If it is true (1), uint128 values will be returned as a byte array, if false they will be returned as a mmdb_uint128_t integer.

Data Type Macros

This library provides a macro for each data type defined by the MaxMind DB schema.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

There are also some types that are for internal use:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

If you see one of these in returned data, something has gone very wrong. The database is corrupted or was generated incorrectly or there is a bug in the libmaxminddb code.

Pointer Values and MMDB_close()

The utf8_string, bytes, and (possibly) uint128 members of this struct are pointers directly into the database's data section. This may be a calloc'd block of memory or mmap'd memory. In either case, these pointers will become invalid after calling MMDB_close().

If you need to refer to this data after that time, you must copy the data with an appropriate function (strdup, memcpy, etc.).

MMDB_entry_data_list_s

This struct encapsulates a linked list of MMDB_entry_data_s structs.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

This struct allows you to view the contents of a map or array of data by iterating over the linked list.

MMDB_search_node_s

This struct encapsulates the two records of a search node. This is really only useful if you wish to write code that iterates over the entire search tree rather than searching for an IP specifically.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

The record types may take one of the following values:

  • MMDB_RECORD_TYPE_SEARCH_NODE - The record points to the next search node.
  • MMDB_RECORD_TYPE_EMPTY - The record is a placeholder indicating that there is no data for the IP. The search should terminate here.
  • MMDB_RECORD_TYPE_DATA - The record contains data in the database's data section. Use the record when looking up the record's data.
  • MMDB_RECORD_TYPE_INVALID - The record is invalid. Either an invalid node was searched for, or the database is corrupt.

The MMDB_entry_s of the record is only valid if the type is MMDB_RECORD_TYPE_DATA. Attempts to use a record for other record types will result in error or invalid data.

STATUS CODES

This library returns (or populates) status codes for many functions. These status codes are:

  • MMDB_SUCCESS - everything worked.
  • MMDB_FILE_OPEN_ERROR - there was an error opening the MaxMind DB file.
  • MMDB_IO_ERROR - an I/O operation failed. Check errno for details.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - searching for an IP in the search tree yielded an impossible result. The database is corrupt or was generated incorrectly or there is a bug in the libmaxminddb code.
  • MMDB_INVALID_METADATA_ERROR - something in the database's metadata is wrong. This includes missing metadata keys or impossible values (like an ip_version of 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - the database's metadata indicates that its version is something other than 2. This library can only handle version 2.
  • MMDB_OUT_OF_MEMORY_ERROR - a memory allocation call (malloc, etc.) failed.
  • MMDB_INVALID_DATA_ERROR - a data field in the data section contains invalid data. For example, a uint16 field claims to be longer than 2 bytes. The database may be corrupt or have been generated incorrectly.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - The lookup path passed to MMDB_get_value, MMDB_vget_value, or MMDB_aget_value contains an array offset greater than LONG_MAX or less than LONG_MIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - The lookup path passed to MMDB_get_value, MMDB_vget_value, or MMDB_aget_value does not match the data structure for the record. There are a number of reasons this may occur. The lookup path might include a key not in a map. The lookup path might include an array index greater than an array or less than the minimum offset from the end of an array. It can also occur when the path expects to find a map or array that does not exist.

All status codes should be treated as int values.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

This function takes a status code and returns an English string explaining the status.

FUNCTIONS

This library provides the following exported functions:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

This function opens a handle to a MaxMind DB file. The return value is a status code as defined above. You should check the return value of this call.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

The filename must be UTF-8 encoded on Windows.

The MMDB_s struct you pass in can be on the stack or heap allocated. However, if opening is successful, it will contain heap allocated data, so you must close it with MMDB_close(). If the returned status is not MMDB_SUCCESS, this library ensures that all allocated memory blocks are freed before returning.

The flags currently provided are:

•
MMDB_MODE_MMAP - open the file using mmap().

Passing other values for flags may yield unpredictable results. In the future, we may add more flags that you can use with the mode, as well as other modes.

You may also pass 0 as the value for flags in which case the file will be opened with default flags. However, these values may change in future releases. The default value is MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

This frees any memory allocated or mmap'd that is held within the MMDB_s struct. It does *not* free memory allocated by the library itself.

Data Structure Allocation

The MMDB_s structure is used to represent an open MaxMind DB file. You can get one of these by calling MMDB_open().

    MMDB_s mmdb;
    int gai_error, mmdb_error;
    mmdb_error = MMDB_open("/path/to/maxmind.mmdb", 0, &gai_error, &mmdb_error);
    if (MMDB_SUCCESS != mmdb_error) {
        // handle error
    }

When you are done with the database you MUST call MMDB_close() to free the resources associated with it.

    MMDB_close(&mmdb);

It is important to note that MMDB_open() may return an MMDB_s structure that is only partially initialized. For this reason you should always call MMDB_close() on the structure, regardless of whether MMDB_open() succeeded or not.

The MMDB_s structure itself is not allocated from the heap. If you allocate the structure from the heap then you are responsible for freeing it.

Lookup Functions

There are two functions that can be used to look up an IP address in the database. The primary difference between them is how the IP address is passed in.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

This function looks up an IP address that is passed in as a null-terminated string. Internally it calls getaddrinfo() to resolve the address into a binary form. It then calls MMDB_lookup_sockaddr() to look the address up in the database. If you have already resolved an address you can call MMDB_lookup_sockaddr() directly, rather than resolving the address twice.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

This function always returns an MMDB_lookup_result_s structure, but you should also check the gai_error and mmdb_error parameters. If either of these indicates an error then the returned structure is meaningless.

If no error occurred you still need to make sure that the found_entry member in the returned result is true. If it's not, this means that the IP address does not have an entry in the database.

This function will work with IPv4 addresses even when the database contains data for both IPv4 and IPv6 addresses. The IPv4 address will be looked up as '::xxx.xxx.xxx.xxx' rather than being remapped to the ::ffff:xxx.xxx.xxx.xxx block allocated for IPv4-mapped IPv6 addresses.

If you pass an IPv6 address to a database with only IPv4 data then the found_entry member will be false, but the mmdb_error status will still be MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

This function looks up an IP address that has already been resolved by getaddrinfo().

Other than not calling getaddrinfo() itself, this function is identical to the MMDB_lookup_string() function.

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Data Lookup Functions

There are three functions for looking up data associated with an IP address.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

The three functions allow three slightly different calling styles, but they all do the same thing.

The first parameter is an MMDB_entry_s value. In most cases this will come from the MMDB_lookup_result_s value returned by MMDB_lookup_string() or MMDB_lookup_sockaddr().

The second parameter is a reference to an MMDB_entry_data_s structure. This will be populated with the data that is being looked up, if any is found. If nothing is found, then the has_data member of this structure will be false. If has_data is true then you can look at the data_type member.

The final parameter is a lookup path. The path consists of a set of strings representing either map keys (e.g, "city") or array indexes (e.g., "0", "1", "-1") to use in the lookup.

Negative array indexes will be treated as an offset from the end of the array. For instance, "-1" refers to the last element of the array.

The lookup path allows you to navigate a complex data structure. For example, given this data:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

We could look up the English name with this code:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

If we wanted to find the first city the lookup path would be "cities", "0". If you don't provide a lookup path at all, you'll get the entry which corresponds to the top level map. The lookup path must always end with NULL, regardless of which function you call.

The MMDB_get_value function takes a variable number of arguments. All of the arguments after the MMDB_entry_data_s * structure pointer are the lookup path. The last argument must be NULL.

The MMDB_vget_value function accepts a va_list as the lookup path. The last element retrieved by va_arg() must be NULL.

Finally, the MMDB_aget_value accepts an array of strings as the lookup path. The last member of this array must be NULL.

If you want to get all of the entry data at once you can call MMDB_get_entry_data_list() instead.

For each of the three functions, the return value is a status code as defined above.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

This function allows you to get all of the data for a complex data structure at once, rather than looking up each piece using repeated calls to MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// save this so we can free this data later
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

It's up to you to interpret the entry_data_list data structure. The list is linked in a depth-first traversal. Let's use this structure as an example:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

The list will consist of the following items:

1.
MAP - top level map
2.
UTF8_STRING - "names" key
3.
MAP - map for "names" key
4.
UTF8_STRING - "en" key
5.
UTF8_STRING - value for "en" key
6.
UTF8_STRING - "de" key
7.
UTF8_STRING - value for "de" key
8.
UTF8_STRING - "cities" key
9.
ARRAY - value for "cities" key
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

The return value of the function is a status code as defined above.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

The MMDB_get_entry_data_list() and MMDB_get_metadata_as_entry_data_list() functions will allocate the linked list structure from the heap. Call this function to free the MMDB_entry_data_list_s structure.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

This function allows you to retrieve the database metadata as a linked list of MMDB_entry_data_list_s structures. This can be a more convenient way to deal with the metadata than using the metadata structure directly.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // do something with the data
    MMDB_free_entry_data_list(first);

The return value of the function is a status code as defined above.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

This function takes a linked list of MMDB_entry_data_list_s structures and stringifies it to the given stream. The indent parameter is the starting indent level for the generated output. It is incremented for nested data structures (maps, array, etc.).

The stream must be a file handle (stdout, etc). If your platform provides something like the GNU open_memstream() you can use that to capture the output as a string.

The output is formatted in a JSON-ish fashion, but values are marked with their data type (except for maps and arrays which are shown with "{}" and "[]" respectively).

MMDB_close(3) — libmaxminddb — Arch Linux

NAME

MMDB_close - close a MaxMind DB database

SYNOPSIS

#include <maxminddb.h>
void MMDB_close(MMDB_s *mmdb);

DESCRIPTION

This function closes the MaxMind DB database file handle that was previously opened by MMDB_open. It will also free any memory that was allocated by libmaxminddb for the database structure.

It is important that you call MMDB_close when you are finished with a database to prevent file descriptor leaks and memory leaks.

The function takes a pointer to an MMDB_s structure as an argument. This structure is assumed to have been initialized by a prior call to MMDB_open.

This function does not return a value.

DATA STRUCTURES

MMDB_s
The structure that represents an open MaxMind DB database.
MMDB_search_node_s
Represents a node in the MaxMind DB search tree. This is used internally by the library. You can read these nodes using MMDB_read_node if you want to iterate over the entire search tree.
MMDB_entry_data_list_s
A list of MaxMind DB entries. This is returned by MMDB_get_entry_data_list.
MMDB_lookup_result_s
The result of a lookup. Contains a boolean indicating if an entry was found, and if so, the entry itself. MMDB_lookup_string(3) can be used to get this structure.

STATUS CODES

This library returns a status code for most functions. They are defined in maxminddb.h as integers. They are explained below:

MMDB_SUCCESS
The operation was successful.
MMDB_END_OF_DATABASE
There are no more records in the database. This is mainly used when iterating over the database.
MMDB_INVALID_METADATA_ERROR
The database metadata is invalid.
MMDB_INVALID_DATA_ERROR
The database data is invalid.
MMDB_INVALID_NODE_ERROR
The requested node is invalid.
MMDB_CORRUPT_DATABASE_FILE_ERROR
The database file is corrupt.
MMDB_CORRUPT_SEARCH_TREE_ERROR
The search tree within the database file is corrupt.
MMDB_IO_ERROR
An error occurred while reading from the database file.
MMDB_OUT_OF_MEMORY_ERROR
There was not enough memory to complete the operation.
MMDB_NULL_POINTER_ERROR
A null pointer was passed to the function where it was not expected.
MMDB_INVALID_ARGUMENT_ERROR
An invalid argument was passed to the function.
MMDB_FILE_NOT_FOUND_ERROR
The database file specified could not be found.
MMDB_UNEXPECTED_END_OF_FILE_ERROR
The end of the file was reached unexpectedly.
MMDB_INVALID_RETURN_TYPE_ERROR
The return type from the database is not valid for the requested lookup.
MMDB_DATA_TYPE_MISMATCH_ERROR
The data type requested is not what was returned from the database.
MMDB_INVALID_SEARCH_TREE_DEPTH_ERROR
The search tree is too deep. This usually indicates a corrupt database file.
MMDB_LOOKUP_PATH_ERROR
There was an error traversing the lookup path in the database.
MMDB_OUT_OF_ веке_ERROR
This should not happen. If it does, please report it as a bug.
MMDB_NOT_IMPLEMENTED_ERROR
The requested function or feature is not implemented.

You can convert these status codes to human-readable strings using the MMDB_strerror function.

FUNCTIONS

MMDB_open
int MMDB_open(const char *filename, MMDB_mode_e mode, MMDB_s *const mmdb);

Opens a MaxMind DB database file. Returns a status code.

filename is the path to the database file. mode specifies how the file should be opened. You can choose between MMDB_MODE_MMAP (memory-map the database, default), MMDB_MODE_FILE (read the database from disk as needed), and MMDB_MODE_STRICT_MMAP (memory-map the database, but perform read checks).

mmdb is a pointer to an MMDB_s structure that will be populated by this function.

Returns MMDB_SUCCESS on success, or an error code otherwise.

MMDB_close
void MMDB_close(MMDB_s *mmdb);

Closes the database file handle and frees any allocated memory. See description above.

MMDB_lookup_string
MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *ip_address,
    int *gai_error,
    int *mmdb_error);

Looks up an IP address in the database. The ip_address can be an IPv4 or IPv6 address. It returns an MMDB_lookup_result_s structure which contains a boolean found_entry and the MMDB_entry_s structure if found.

It also returns two error codes: gai_error for errors from getaddrinfo() (e.g. invalid IP address format) and mmdb_error for errors from libmaxminddb itself.

MMDB_get_entry_data_list
int MMDB_get_entry_data_list(
    const MMDB_entry_s *const entry,
    MMDB_entry_data_list_s **entry_data_list);

Retrieves the data for a given entry as a linked list of MMDB_entry_data_s structures. The list can be iterated over.

Returns MMDB_SUCCESS on success.

MMDB_free_entry_data_list
void MMDB_free_entry_data_list(MMDB_entry_data_list_s *entry_data_list);

Frees the memory allocated for an entry data list returned by MMDB_get_entry_data_list.

MMDB_strerror
const char *MMDB_strerror(int status);

Converts a libmaxminddb status code into a human-readable error string.

MMDB_dump_entry_data_list
void MMDB_dump_entry_data_list(
    FILE *file,
    const MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Prints the contents of an MMDB_entry_data_list_s to the specified FILE pointer, with the given indentation level. This function is mainly intended for debugging and testing. The formatting is not guaranteed to be stable across library versions.

The return value of the function is a status code as defined above.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

This reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void)

This function returns the library version as a string, something like "2.0.0".

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
