DESCRIPCIÓN

La biblioteca libmaxminddb proporciona funciones para trabajar con archivos MaxMind DB. Ver https://maxmind.github.io/MaxMind-DB/ para la especificación del formato MaxMind DB. Las bases de datos y los resultados se representan mediante diferentes estructuras de datos. Las bases de datos se abren llamando a MMDB_open(). Puede buscar direcciones IP como una cadena con MMDB_lookup_string() o como un puntero a una estructura sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esa estructura indica que la base de datos tiene datos para la IP, hay una serie de funciones que se pueden usar para obtener esos datos. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Ver la documentación de la función a continuación para más detalles.

Cuando haya terminado con el manejador de la base de datos, debe llamar a MMDB_close().

Todas las funciones, estructuras y macros visibles públicamente comienzan con "MMDB_".

ESTRUCTURAS DE DATOS

Todas las estructuras de datos exportadas por el encabezado maxminddb.h de esta biblioteca están definidas con el formato typedef struct foo_s { ... } foo_s para que pueda referirse a ellas sin el prefijo struct.

Esta biblioteca proporciona las siguientes estructuras de datos:

MMDB_s

Este es el manejador de un archivo MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados al uso público. Todos los demás campos están sujetos a cambios y solo están destinados a uso interno.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - las banderas con las que se abrió esta base de datos. Ver la documentación de MMDB_open() para más detalles.
  • const char *filename - el nombre del archivo que se abrió, tal como se pasó a MMDB_open().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura se puede recuperar de la estructura MMDB_s. Contiene los metadatos leídos del archivo de la base de datos. Tenga en cuenta que puede resultar más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list() en su lugar.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deberían ser en su mayoría autoexplicativas.

El miembro ip_version siempre debe ser 4 o 6. El miembro binary_format_major_version siempre debe ser 2.

No hay ningún requisito de que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que el count para estas partes de los metadatos puede ser cero. Todos los demás campos de MMDB_metadata_s deben estar poblados.

MMDB_lookup_result_s

Esta estructura se devuelve como resultado de la búsqueda de una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, los demás miembros de esta estructura no contienen valores significativos. Siempre verifique primero que found_entry sea verdadero.

El miembro entry se utiliza para buscar los datos asociados con la dirección IP.

El miembro netmask le indica a qué subred pertenece la dirección IP en esta base de datos. Por ejemplo, si busca la dirección 1.1.1.1 en una base de datos IPv4 y la máscara de red devuelta es 16, entonces la dirección es parte de la subred 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, la máscara de red devuelta es siempre una longitud de prefijo IPv6 (de 0 a 128), incluso si esa base de datos también contiene redes IPv4. Si busca una dirección IPv4 y desea convertir la máscara de red en un valor de máscara de red IPv4, puede simplemente restar 96 del valor.

MMDB_result_s

Realmente no necesita examinar esta estructura. La obtendrá de una estructura MMDB_lookup_result_s y la pasará a varias funciones.

MMDB_entry_data_s

Esta estructura se utiliza para devolver una entrada de sección de datos única para una IP. Estas entradas pueden, a su vez, apuntar a otras entradas, como es el caso de cosas como mapas y arreglos. Algunos miembros de esta estructura no están documentados ya que son solo para uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontraron datos para una búsqueda dada. Ver MMDB_get_value() para más detalles. Si este miembro es falso, ninguno de los otros valores en la estructura tiene sentido.

MMDB_entry_data_list_s

Se utiliza para devolver listas de entradas de datos. Las bases de datos MaxMind DB pueden contener mapas y arreglos, y estas estructuras se utilizan para devolverlos. El miembro entry_data contiene los datos reales, y el miembro next apunta a la siguiente entrada en la lista (o es NULL si es la última entrada).

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

MMDB_search_node_s

Esta estructura se utiliza para devolver información sobre un nodo en el árbol de búsqueda de la base de datos. Solo se expone un pequeño subconjunto de estos campos.

typedef struct MMDB_search_node_s {
    uint32_t number;
    uint32_t prefix_bit_length;
    uint32_t data_offset;
    uint32_t data_size;
    uint32_t data_type;
    const void *data;
} MMDB_search_node_s;

FUNCIONES

MMDB_open()

Abre un archivo MaxMind DB y lo inicializa.

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

filename es el nombre del archivo a abrir. flags puede ser cero o MMDB_MODE_MMAP. MMDB_MODE_MMAP intenta mapear el archivo en memoria, lo que generalmente resulta en un mejor rendimiento.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_close()

Cierra un archivo MaxMind DB abierto.

void MMDB_close(MMDB_s *const mmdb);

MMDB_lookup_string()

Busca una dirección IP representada como una cadena.

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

ipstr es la dirección IP a buscar (por ejemplo, "1.1.1.1" o "2001:4860:4860::8888").

gai_error es un puntero a un entero que recibirá el código de error de getaddrinfo si ocurre un error al analizar ipstr. Si no ocurre ningún error de análisis, este valor no se establecerá.

mmdb_error es un puntero a un entero que recibirá un código de error de libmaxminddb si ocurre un error durante la búsqueda en la base de datos.

Devuelve una estructura MMDB_lookup_result_s.

MMDB_lookup_sockaddr()

Busca una dirección IP representada como una estructura sockaddr.

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

sockaddr es un puntero a la estructura sockaddr que contiene la dirección IP a buscar.

mmdb_error es un puntero a un entero que recibirá un código de error de libmaxminddb si ocurre un error durante la búsqueda en la base de datos.

Devuelve una estructura MMDB_lookup_result_s.

MMDB_get_value()

Obtiene un valor de un puntero de entrada dado.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);

Se espera que start sea un puntero a una estructura MMDB_entry_s que se obtuvo de una búsqueda (por ejemplo, el miembro entry de MMDB_lookup_result_s). entry_data es un puntero a una estructura MMDB_entry_data_s que se llenará con los datos recuperados.

La lista de argumentos de variable se utiliza para especificar la ruta al valor deseado. Por ejemplo, para obtener el valor de "country.iso_code", usaría:

MMDB_get_value(&lookup_result.entry, &entry_data, "country", "iso_code", NULL);

La lista de argumentos debe terminar con un puntero nulo.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_vget_value()

Obtiene un valor de un puntero de entrada dado, utilizando una lista de argumentos de variable.

int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);

Similar a MMDB_get_value(), pero toma una va_list en lugar de una lista de argumentos de variable separados.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_aget_value()

Obtiene un valor de un puntero de entrada dado, utilizando un arreglo de cadenas.

int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Similar a MMDB_get_value(), pero toma un arreglo de cadenas terminadas en NULL para la ruta.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_get_entry_data_list()

Obtiene todos los datos para una entrada como una lista enlazada.

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

start es un puntero a una estructura MMDB_entry_s que se obtuvo de una búsqueda. entry_data_list es un puntero a un puntero a MMDB_entry_data_list_s que se llenará con la lista de entradas de datos.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_free_entry_data_list()

Libera la memoria asignada por MMDB_get_entry_data_list().

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

MMDB_get_metadata_as_entry_data_list()

Obtiene los metadatos de la base de datos como una lista enlazada de entradas de datos.

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

mmdb es el manejador de la base de datos. entry_data_list es un puntero a un puntero a MMDB_entry_data_list_s que se llenará con los metadatos.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_dump_entry_data_list()

Imprime el contenido de una lista de entradas de datos en un flujo de archivo.

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

stream es el flujo de archivo en el que escribir. entry_data_list es la lista de entradas de datos a imprimir. indent es el nivel de indentación inicial.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_read_node()

Lee un nodo específico de la base de datos.

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

mmdb es el manejador de la base de datos. node_number es el número del nodo a leer. node es un puntero a una estructura MMDB_search_node_s que se llenará con la información del nodo.

Devuelve 0 en caso de éxito, o un código de error de libmaxminddb en caso de fallo.

MMDB_lib_version()

Devuelve la versión de la biblioteca libmaxminddb como una cadena.

const char *MMDB_lib_version(void);

MMDB_strerror()

Devuelve una cadena que describe un código de error de libmaxminddb.

const char *MMDB_strerror(int error_code);

VALORES DE RETORNO

Las funciones que devuelven un int devuelven 0 en caso de éxito y un código de error negativo en caso de fallo. Los códigos de error son constantes definidas en maxminddb.h y comienzan con MMDB_SUCCESS (que es 0), MMDB_IO_ERROR, MMDB_INVALID_ARGUMENT, MMDB_FILE_NOT_FOUND, MMDB_INVALID_METADATA_ERROR, MMDB_INVALID_DATA_ERROR, MMDB_OUT_OF_MEMORY_ERROR, MMDB_ROOT_POINTER_ERROR, MMDB_LOOKUP_NODE_ERROR, MMDB_LOOKUP_PATH_ERROR, MMDB_INVALID_DATA_TYPE_ERROR, MMDB_INVALID_FILE_ERROR, MMDB_UNEXPECTED_END_OF_FILE_ERROR, MMDB_SOCKET_ERROR, MMDB_NULL_POINTER_ERROR, MMDB_GET_ENTRY_ERROR, MMDB_MEMORY_ACCESS_ERROR, MMDB_READ_NODE_ERROR, MMDB_MODE_ERROR.

EJEMPLOS

A continuación se muestra un ejemplo simple de uso de la biblioteca para buscar una dirección IP y obtener su código de país:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <maxminddb.h>
int main(int argc, char **argv) {
    MMDB_s mmdb;
    MMDB_lookup_result_s result;
    int gai_error, mmdb_error;
    int ret;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <maxminddb_file> <ip_address>\n", argv[0]);
        return 1;
    }
    ret = MMDB_open(argv[1], MMDB_MODE_MMAP, &mmdb);
    if (ret != MMDB_SUCCESS) {
        fprintf(stderr, "Error opening database: %s\n", MMDB_strerror(ret));
        return 1;
    }
    result = MMDB_lookup_string(&mmdb, argv[2], &gai_error, &mmdb_error);
    if (gai_error != 0) {
        fprintf(stderr, "Error resolving address: %s\n", gai_strerror(gai_error));
        MMDB_close(&mmdb);
        return 1;
    }
    if (result.found_entry) {
        MMDB_entry_data_s entry_data;
        ret = MMDB_get_value(&result.entry, &entry_data, "country", "iso_code", NULL);
        if (ret == MMDB_SUCCESS && entry_data.has_data) {
            printf("Country ISO Code: %s\n", entry_data.utf8_string);
        } else {
            fprintf(stderr, "Could not get country ISO code\n");
        }
    } else {
        printf("IP address not found in database.\n");
    }
    MMDB_close(&mmdb);
    return 0;
}

El miembro data_size solo es relevante para los datos utf8_string y bytes. utf8_string no termina en nulo y se *debe* usar data_size para determinar su longitud.

El miembro type se puede comparar con uno de los macros MMDB_DATA_TYPE_*.

Enteros de 128 bits

El manejo de datos uint128 depende de cómo tu plataforma soporte enteros de 128 bits, si es que lo hace. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más nuevas de GCC (4.6+) y clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para solucionar estas diferencias, esta biblioteca define un tipo mmdb_uint128_t. Este tipo está definido en el encabezado maxminddb.h para que puedas usarlo en tu propio código.

Con compiladores más antiguos, no podemos usar un entero, sino que utilizamos un array de 16 bytes de valores uint8_t. Estos son los datos brutos de la base de datos.

Esta biblioteca proporciona un macro público MMDB_UINT128_IS_BYTE_ARRAY. Si este es verdadero (1), entonces los valores uint128 se devuelven como un array de bytes; si es falso, se devuelven como un entero mmdb_uint128_t.

Macros de tipo de datos

Esta biblioteca proporciona un macro para cada tipo de dato definido por la especificación MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que son solo para uso interno:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ves uno de estos en los datos devueltos, algo ha ido muy mal. La base de datos está dañada o se generó incorrectamente, o hay un error en el código de libmaxminddb.

Valores de puntero y MMDB_close()

Los miembros utf8_string, bytes y (quizás) uint128 de esta estructura son todos punteros directos a la sección de datos de la base de datos. Este puede ser un bloque de memoria asignado con calloc o con mmap. En cualquiera de los casos, estos punteros se invalidarán después de llamar a MMDB_close().

Si necesitas referirte a estos datos después de ese momento, debes copiar los datos con una función apropiada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Esta estructura te permite ver una entrada de datos de mapa o array completa iterando sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros en un nodo de búsqueda. Esto es realmente útil solo si deseas escribir código que itere sobre todo el árbol de búsqueda en lugar de buscar una dirección IP específica.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Los dos tipos de registro tomarán uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un marcador de posición que indica que no hay datos para la dirección IP. La búsqueda debe terminar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro es para datos en la sección de datos de la base de datos. Usa la entrada para el registro al buscar los datos del registro.
  • MMDB_RECORD_TYPE_INVALID - El registro no es válido. Se buscó un nodo no válido o la base de datos está corrupta.

El MMDB_entry_s para el registro solo es válido si el tipo es MMDB_RECORD_TYPE_DATA. Intentar usar una entrada para otros tipos de registro resultará en un error o datos inválidos.

CÓDIGOS DE ESTADO

Esta biblioteca devuelve (o rellena) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo funcionó
  • MMDB_FILE_OPEN_ERROR - hubo un error al intentar abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - falló una operación de E/S. Consulta errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - buscar una dirección IP en el árbol de búsqueda nos dio un resultado imposible. La base de datos está dañada o se generó incorrectamente, o hay un error en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos faltantes así como valores imposibles (como una ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - Los metadatos de la base de datos indican que su versión principal no es 2. Esta biblioteca solo puede manejar la versión principal 2.
  • MMDB_OUT_OF_MEMORY_ERROR - falló una llamada de asignación de memoria (malloc, etc.).
  • MMDB_INVALID_DATA_ERROR - una entrada en la sección de datos contiene datos inválidos. Por ejemplo, un campo uint16 afirma tener más de 2 bytes de longitud. Probablemente la base de datos está dañada o se generó incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - La ruta de búsqueda pasada a MMDB_get_value, MMDB_vget_value o MMDB_aget_value contiene un índice de array que es mayor que LONGMAX o menor que LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - La ruta de búsqueda pasada a MMDB_get_value,MMDB_vget_value o MMDB_aget_value no coincide con la estructura de datos de la entrada. Hay varias razones por las que esto puede suceder. La ruta de búsqueda podría incluir una clave que no está en un mapa. La ruta de búsqueda podría incluir un índice de array mayor que un array o menor que el desplazamiento mínimo desde el final de un array. También puede suceder cuando la ruta espera encontrar un mapa o array donde no existe ninguno.

Todos los códigos de estado deben tratarse como valores int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés que explica el estado.

FUNCIONES

Esta biblioteca proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Esta función abre un manejador para un archivo MaxMind DB. Su valor de retorno es un código de estado según se define anteriormente. Siempre comprueba el valor de retorno de esta llamada.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename debe estar codificado como UTF-8 en Windows.

La estructura MMDB_s que pasas puede estar en la pila o asignada desde el heap. Sin embargo, si la apertura es exitosa contendrá datos asignados del heap, por lo que necesitas cerrarla con MMDB_close(). Si el estado devuelto no es MMDB_SUCCESS, esta biblioteca se asegura de que toda la memoria asignada se libere antes de devolver.

Las banderas actualmente proporcionadas son:

•
MMDB_MODE_MMAP - abre la base de datos con mmap().

Pasar otros valores para flags puede producir resultados impredecibles. En el futuro, podríamos agregar banderas adicionales que puedas combinar con OR bit a bit con el modo, así como modos adicionales.

También puedes pasar 0 como valor de flags, en cuyo caso la base de datos se abrirá con las banderas predeterminadas. Sin embargo, estos valores predeterminados pueden cambiar en futuras versiones. El valor predeterminado actual es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esto libera cualquier memoria asignada o mapeada por mmap que esté contenida en la estructura MMDB_s. *No libera la memoria

MMDB_LOOKUP_STRING

This function looks up an IP address that is passed in as a null-terminated string. Internally it calls getaddrinfo() to resolve the address into a binary form. It then calls MMDB_lookup_sockaddr() to look the address up in the database. If you have already resolved an address you can call MMDB_lookup_sockaddr() directly, rather than resolving the address twice.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

This function always returns an MMDB_lookup_result_s structure, but you should also check the gai_error and mmdb_error parameters. If either of these indicates an error then the returned structure is meaningless.

If no error occurred you still need to make sure that the found_entry member in the returned result is true. If it's not, this means that the IP address does not have an entry in the database.

This function will work with IPv4 addresses even when the database contains data for both IPv4 and IPv6 addresses. The IPv4 address will be looked up as '::xxx.xxx.xxx.xxx' rather than being remapped to the ::ffff:xxx.xxx.xxx.xxx block allocated for IPv4-mapped IPv6 addresses.

If you pass an IPv6 address to a database with only IPv4 data then the found_entry member will be false, but the mmdb_error status will still be MMDB_SUCCESS.

MMDB_LOOKUP_SOCKADDR

This function looks up an IP address that has already been resolved by getaddrinfo().

Other than not calling getaddrinfo() itself, this function is identical to the MMDB_lookup_string() function.

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Funciones de Búsqueda de Datos

Hay tres funciones para buscar datos asociados con una dirección IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Las tres funciones permiten tres estilos de llamada ligeramente diferentes, pero todas hacen lo mismo.

El primer parámetro es un valor MMDB_entry_s. En la mayoría de los casos, provendrá del valor MMDB_lookup_result_s devuelto por MMDB_lookup_string() o MMDB_lookup_sockaddr().

El segundo parámetro es una referencia a una estructura MMDB_entry_data_s. Esta se poblará con los datos que se están buscando, si se encuentra alguno. Si no se encuentra nada, el miembro has_data de esta estructura será falso. Si has_data es verdadero, puede consultar el miembro data_type.

El último parámetro es una ruta de búsqueda. La ruta consiste en un conjunto de cadenas que representan claves de mapa (por ejemplo, "city") o índices de matriz (por ejemplo, "0", "1", "-1") a utilizar en la búsqueda.

Los índices de matriz negativos se tratarán como un desplazamiento desde el final de la matriz. Por ejemplo, "-1" se refiere al último elemento de la matriz.

La ruta de búsqueda le permite navegar por una estructura de datos compleja. Por ejemplo, dados estos datos:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Podríamos buscar el nombre en inglés con este código:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si quisiéramos encontrar la primera ciudad, la ruta de búsqueda sería "cities", "0". Si no proporciona ninguna ruta de búsqueda, obtendrá la entrada que corresponde al mapa de nivel superior. La ruta de búsqueda siempre debe terminar en NULL, independientemente de la función que llame.

La función MMDB_get_value toma un número variable de argumentos. Todos los argumentos después del puntero a la estructura MMDB_entry_data_s * son la ruta de búsqueda. El último argumento debe ser NULL.

La función MMDB_vget_value acepta un va_list como ruta de búsqueda. El último elemento recuperado por va_arg() debe ser NULL.

Finalmente, MMDB_aget_value acepta una matriz de cadenas como ruta de búsqueda. El último miembro de esta matriz debe ser NULL.

Si desea obtener todos los datos de entrada a la vez, puede llamar a MMDB_get_entry_data_list() en su lugar.

Para cada una de las tres funciones, el valor de retorno es un código de estado según se define anteriormente.

MMDB_GET_ENTRY_DATA_LIST

Esta función permite obtener todos los datos de una estructura de datos compleja a la vez, en lugar de buscar cada pieza mediante llamadas repetidas a MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// guardamos esto para poder liberar estos datos más tarde
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Depende de usted interpretar la estructura de datos entry_data_list. La lista está enlazada en un recorrido en profundidad. Usemos esta estructura como ejemplo:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La lista constará de los siguientes elementos:

1.
MAP - mapa de nivel superior
2.
UTF8_STRING - clave "names"
3.
MAP - mapa para la clave "names"
4.
UTF8_STRING - clave "en"
5.
UTF8_STRING - valor para la clave "en"
6.
UTF8_STRING - clave "de"
7.
UTF8_STRING - valor para la clave "de"
8.
UTF8_STRING - clave "cities"
9.
ARRAY - valor para la clave "cities"
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

El valor de retorno de la función es un código de estado según se define anteriormente.

MMDB_FREE_ENTRY_DATA_LIST

Las funciones MMDB_get_entry_data_list() y MMDB_get_metadata_as_entry_data_list() asignarán la estructura de lista enlazada desde el heap. Llame a esta función para liberar la estructura MMDB_entry_data_list_s.

MMDB_GET_METADATA_AS_ENTRY_DATA_LIST

Esta función permite recuperar los metadatos de la base de datos como una lista enlazada de estructuras MMDB_entry_data_list_s. Esta puede ser una forma más conveniente de tratar con los metadatos que usar la estructura de metadatos directamente.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // hacer algo con los datos
    MMDB_free_entry_data_list(first);

El valor de retorno de la función es un código de estado según se define anteriormente.

MMDB_DUMP_ENTRY_DATA_LIST

Esta función toma una lista enlazada de estructuras MMDB_entry_data_list_s y la convierte en una cadena en el stream dado. El parámetro indent es el nivel de sangría inicial para la salida generada. Se incrementa para estructuras de datos anidadas (mapas, matrices, etc.).

El stream debe ser un manejador de archivo (stdout, etc.). Si su plataforma proporciona algo como open_memstream() de GNU, puede usarlo para capturar la salida como una cadena.

La salida tiene un formato similar a JSON, pero los valores están marcados con su tipo de datos (excepto para los mapas y las matrices que se muestran con "{}" y "[]" respectivamente).

El formato de salida específico puede cambiar en futuras versiones de la biblioteca.

NOMBRE

MMDB_lookup_string

SINOPSIS

int MMDB_lookup_string( MMDB_s *const mmdb, const char *const ip_address, int *const gai_error, int *const mmdb_error);

DESCRIPCIÓN

Esta función busca una dirección IP en la base de datos. El segundo argumento es un puntero a un objeto de tipo MMDB_lookup_result_s que contendrá el resultado de la búsqueda.

ESTRUCTURAS DE DATOS

La estructura MMDB_lookup_result_s contiene los siguientes campos:

  • found_entry (bool): indica si se encontró un registro de entrada.

  • entry (MMDB_entry_s *const): apunta a un registro de entrada.

  • gai_error (int): código de error de getaddrinfo.

  • mmdb_error (int): código de error de libmaxminddb.

CÓDIGOS DE ESTADO

Los códigos de estado de esta función se definen como:

  • MMDB_SUCCESS: éxito.

  • MMDB_INVALID_NODE_NUMBER_ERROR: número de nodo inválido.

  • MMDB_IO_ERROR: error de lectura.

  • MMDB_NOT_FOUND: no se encontró el registro.

  • MMDB_LOOKUP_FAILED: falló la búsqueda.

FUNCIONES

int MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ip_address,
    int *const gai_error,
    int *const mmdb_error);

Esta función busca una dirección IP en la base de datos. El segundo argumento es un puntero a un objeto de tipo MMDB_lookup_result_s que contendrá el resultado de la búsqueda.

El valor devuelto es un código de estado. Si se pasa un número de nodo mayor que el número de nodos en la base de datos, esta función devolverá MMDB_INVALID_NODE_NUMBER_ERROR, de lo contrario devolverá MMDB_SUCCESS.

El primer nodo en la arborescencia de búsqueda siempre es nodo 0. Si quieres iterar sobre toda la arborescencia, debes leer el nodo 0 primero, luego seguir los registros que forman este nodo, según el tipo de cada registro. Si el tipo es MMDB_RECORD_TYPE_SEARCH_NODE, el registro contiene un entero para el siguiente nodo a buscar.

EJEMPLO

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
