DESCRIPCIÓN

La biblioteca libmaxminddb proporciona funciones para trabajar con archivos MaxMind DB. Consulte https://maxmind.github.io/MaxMind-DB/ para la especificación del formato MaxMind DB. Las bases de datos y los resultados se representan mediante diferentes estructuras de datos. Las bases de datos se abren llamando a MMDB_open(). Puede buscar direcciones IP como una cadena de texto con MMDB_lookup_string() o como un puntero a una estructura sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esa estructura indica que la base de datos tiene datos para la IP, hay varias funciones que se pueden usar para obtener esos datos. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Consulte la documentación de la función a continuación para más detalles.

Cuando haya terminado con el manejador de la base de datos, debe llamar a MMDB_close().

Todas las funciones, estructuras y macros visibles públicamente comienzan con "MMDB_".

ESTRUCTURAS DE DATOS

Todas las estructuras de datos exportadas por el encabezado maxminddb.h de esta biblioteca están definidas con el formato typedef struct foo_s { ... } foo_s para que pueda referirse a ellas sin el prefijo struct.

Esta biblioteca proporciona las siguientes estructuras de datos:

MMDB_s

Este es el manejador para un archivo MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados a uso público. Todos los demás campos están sujetos a cambios y solo están destinados a uso interno.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - las banderas con las que se abrió esta base de datos. Consulte la documentación de MMDB_open() para más detalles.
  • const char *filename - el nombre del archivo que se abrió, tal como se pasó a MMDB_open().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura se puede recuperar de la estructura MMDB_s. Contiene los metadatos leídos del archivo de base de datos. Tenga en cuenta que puede resultar más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list() en su lugar.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deberían ser en su mayoría autoexplicativas.

El miembro ip_version siempre debe ser 4 o 6. El miembro binary_format_major_version siempre debe ser 2.

No hay ningún requisito de que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que el count para estas partes de los metadatos puede ser cero. Todos los demás campos de MMDB_metadata_s deben estar poblados.

MMDB_lookup_result_s

Esta estructura se devuelve como resultado de la búsqueda de una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, entonces los otros miembros de esta estructura no contienen valores significativos. Siempre verifique primero que found_entry sea verdadero.

El miembro entry se utiliza para buscar los datos asociados con la dirección IP.

El miembro netmask le indica de qué subred forma parte la dirección IP en esta base de datos. Por ejemplo, si busca la dirección 1.1.1.1 en una base de datos IPv4 y la máscara de red (netmask) devuelta es 16, entonces la dirección es parte de la subred 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, la máscara de red devuelta es siempre una longitud de prefijo IPv6 (de 0 a 128), incluso si esa base de datos *también* contiene redes IPv4. Si busca una dirección IPv4 y desea convertir la máscara de red a un valor de máscara de red IPv4, simplemente puede restar 96 del valor.

MMDB_result_s

Realmente no necesita indagar en esta estructura. La obtendrá de una estructura MMDB_lookup_result_s y la pasará a varias funciones.

MMDB_entry_data_s

Esta estructura se utiliza para devolver una única sección de datos para una IP. Estas entradas, a su vez, pueden apuntar a otras entradas, como es el caso de elementos como mapas y arreglos. Algunos miembros de esta estructura no están documentados ya que son solo para uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontraron datos para una búsqueda determinada. Consulte MMDB_get_value() para más detalles. Si este miembro es falso, entonces ninguno de los otros valores en la estructura es significativo.

Enteros de 128 bits

El manejo del dato uint128 depende de cómo tu plataforma soporta los enteros de 128 bits, si lo hace o no. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más recientes de GCC (4.6+) y clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para trabajar alrededor de estas diferencias, esta librería define un tipo mmdb_uint128_t. Este tipo está definido en el encabezado maxminddb.h para que puedas usarlo en tu propio código.

Con compiladores antiguos, no podemos usar un entero, así que usamos un array de 16 bytes de uint8_t. Esto es el datos raw del base de datos.

Esta librería proporciona un macro público MMDB_UINT128_IS_BYTE_ARRAY. Si este es true (1), entonces los valores uint128 se devuelven como un array de bytes, si es false entonces se devuelven como un mmdb_uint128_t entero.

Macros de Tipo de Dato

Esta librería proporciona un macro para cada tipo de dato definido por el esquema MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que se usan exclusivamente internamente:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ves uno de estos en los datos devueltos, algo ha ido muy mal. La base de datos está dañada o fue generada incorrectamente o hay un error en el código de libmaxminddb.

Valores Puntero y MMDB_close()

Los miembros utf8_string, bytes y (posiblemente) el miembro uint128 de esta estructura son todos punteros directamente hacia la sección de datos de la base de datos. Esto puede ser un bloque de memoria calloc o mmap. En cualquier caso, estos punteros se invalidarán después de llamarse a MMDB_close().

Si necesitas referirte a este dato después de ese tiempo, debes copiar los datos con una función adecuada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Esta estructura te permite ver datos de mapa o array completo iterando sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros de un nodo de búsqueda. Esto es realmente útil solo si quieres escribir código que itera sobre el árbol de búsqueda completo en lugar de buscar un IP específica.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Los tipos de registro podrán tomar uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un placeholder que indica que no hay datos para el IP. El busquedas debe terminar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro es para datos en la sección de datos de la base de datos. Usa la entrada del registro cuando busques los datos del registro.
  • MMDB_RECORD_TYPE_INVALID - El registro es inválido. O bien se encontró un nodo inválido o la base de datos está corrupta.

El registro MMDB_entry_s es válido solo si el tipo es MMDB_RECORD_TYPE_DATA. El uso de un registro para otros tipos de registro causará un error o datos inválidos.

CÓDIGOS DE ESTADO

Esta librería devuelve (o rellena) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo el trabajo fue exitoso
  • MMDB_FILE_OPEN_ERROR - hubo un error al intentar abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - una operación de I/O falló. Verifica errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - al buscar un IP en el árbol de búsqueda se obtuvo un resultado imposible. La base de datos está dañada o fue generada incorrectamente o hay un error en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos ausentes y valores imposibles (como un ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - los metadatos de la base de datos indican que su versión mayor es diferente de 2. Esta librería solo puede manejar la versión 2.
  • MMDB_OUT_OF_MEMORY_ERROR - un llamado a una operación de asignación de memoria (malloc, etc.) falló.
  • MMDB_INVALID_DATA_ERROR - una entrada en la sección de datos contiene datos inválidos. Por ejemplo, un campo uint16 afirma ser más largo que 2 bytes. La base de datos es probablemente dañada o fue generada incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - el camino de busqueda pasado a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value contiene un desplazamiento de array mayor que LONG_MAX o menor que LONG_MIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - el camino de busqueda pasado a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value no coincide con el estructura de datos para el registro. Hay varias razones por las que esto puede ocurrir. El camino de busqueda puede incluir un clave no en un mapa. El camino de busqueda puede incluir un índice de array mayor que un array o menor que el offset mínimo desde el final de un array. También puede ocurrir cuando el camino espera encontrar un mapa o array que no existan.

Todos los códigos de estado deben tratarse como valores de tipo int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés explicando el estado.

FUNCIONES

Esta librería proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Esta función abre una referencia al archivo MaxMind DB. El valor de retorno es un código de estado como se define anteriormente. Always check the return value of this call.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

El filename debe codificarse como UTF-8 en Windows.

La estructura MMDB_s que pasas puede estar en la pila o asignada en el heap. Sin embargo, si el abrir es exitoso, contendrá datos asignados en el heap, así que debes cerrarla con MMDB_close(). Si el estado devuelto no es MMDB_SUCCESS, esta librería asegura que se libere toda la memoria asignada antes de devolver.

Los flags actualmente proporcionados son:

•
MMDB_MODE_MMAP - abre el archivo con mmap().

Pasando otros valores para flags puede dar resultados impredecibles. En el futuro, podríamos agregar otros flags que puedas unir con el modo, así como otros modos.

También puedes pasar 0 como valor para flags, en lo cual el archivo se abrirá con los flags por defecto. Sin embargo, estos valores de defecto pueden cambiar en futuras versiones. El valor por defecto actual es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esta librería libera cualquier memoria asignada o mmap'd que se encuentre en la estructura MMDB_s. No libera la memoria del sistema.

NAME

libmaxminddb

a C library for reading MaxMind database files

SYNOPSIS

#include <maxminddb.h>

MMDB_s mmdb_ctx;

MMDB_open(filename, mode, &mmdb_ctx);

MMDB_lookup_result_s result = MMDB_lookup_string(&mmdb_ctx, ip_address, &gai_error, &mmdb_error);

MMDB_free_entry_data_list(entry_data_list);

MMDB_close(&mmdb_ctx);

DESCRIPTION

libmaxminddb is a C library for reading MaxMind database files. These database files are distributed in the MMDB format. They map IP addresses to geographical or other information.

You can find more information about the MMDB format on the MaxMindDB website.

The library supports database files in version 1 and 2 of the MMDB format.

This library is thread-safe.

DATA STRUCTURES

The library defines the following data structures:

MMDB_s
The main structure for a MaxMind DB file. It is returned by MMDB_open and used in all subsequent calls. The structure members are not intended for direct use and may change between releases. So you should not rely on the specific formatting produced by this function. It is intended to be used to show data to users in a readable way and for debugging purposes.
MMDB_lookup_result_s
Contains the result of a lookup. It has the following members:
entry
The entry found in the database. If the IP address was not found, this will be an empty entry.
found_entry
A boolean indicating whether an entry was found for the given IP address. Even if this is false, you may still want to examine the entry member as it might contain information about the closest matching IP address.
MMDB_entry_data_list_s
A singly linked list of MMDB_entry_data_s structures. Each node in the list represents a key-value pair within the database entry. The list is NULL-terminated.
MMDB_entry_data_s
Represents a single key-value pair. It has the following members:
key
The key for this entry data. This is a null-terminated C string.
iov
An array of MMDB_iovec_s structures representing the value of this entry data. This is used for efficiency, to avoid copying data when possible.
data_list
If the value is a map or an array, this will point to the linked list of its contents. Otherwise, it will be NULL.
type
The type of the value, as an integer. See the `MMDB_DATA_TYPE_*` constants below.
next
A pointer to the next node in the linked list, or NULL if this is the last node.
MMDB_iovec_s
Represents a piece of data. It has the following members:
base
A pointer to the beginning of the data.
len
The length of the data in bytes.
MMDB_search_node_s
Represents a node in the search tree. It has the following members:
type
The type of the record. Possible values are:
MMDB_RECORD_TYPE_INVALID
MMDB_RECORD_TYPE_SEARCH_NODE
MMDB_RECORD_TYPE_KEY_VALUE
MMDB_RECORD_TYPE_FULL_NODE
MMDB_RECORD_TYPE_LOOKUP_NODE
value
The value of the record. The interpretation of this value depends on the type.
left_child
If type is MMDB_RECORD_TYPE_SEARCH_NODE, this is the left child node number.
right_child
If type is MMDB_RECORD_TYPE_SEARCH_NODE, this is the right child node number.
db_node
If type is MMDB_RECORD_TYPE_KEY_VALUE, this is the database node number.

STATUS CODES

The library returns status codes as defined in the following enum:

    MMDB_SUCCESS = 0,

    MMDB_INVALID_FILE_ERROR,

    MMDB_LEGACY_DATABASE_ERROR,
    MMDB_NOT_IMPLEMENTED_ERROR,
    MMDB_NULL_POINTER_ERROR,
    MMDB_INVALID_DATA_ERROR,
    MMDB_INVALID_RETURN_Meta_DATA_ERROR,
    MMDB_CORRUPTED_DATABASE_ERROR,
    MMDB_TOO_SMALL_DATABASE_ERROR,
    MMDB_IO_ERROR,
    MMDB_INVALID_NODE_NUMBER_ERROR,
    MMDB_INVALID_SEARCH_NODE_TYPE_ERROR,
    MMDB_INTERNAL_ERROR,
    MMDB_URI_PARSE_ERROR,
    MMDB_UNEXPECTED_NULL_DATA_ERROR,
    MMDB_LOOKUP_NODE_ERROR,
    MMDB_LOOKUP_METADATA_ERROR,
    MMDB_LOOKUP_NODE_TYPE_ERROR,
    MMDB_LOOKUP_VALUE_ERROR,
    MMDB_LOOKUP_IO_ERROR,
    MMDB_LOOKUP_OUT_OF_MEMORY_ERROR,
    MMDB_LOOKUP_INVALID_DATA_ERROR,
    MMDB_LOOKUP_METADATA_INVALID_ERROR,
    MMDB_LOOKUP_CORRUPTED_DATABASE_ERROR,

The function MMDB_strerror can be used to get a human-readable string representation of a status code.

FUNCTIONS

MMDB_open()

int MMDB_open(
    const char *filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Opens a MaxMind DB file for reading. filename is the path to the database file. flags are bitwise OR'd options. Supported flags are:

MMDB_MODE_MMAP
Memory-map the database file. This is the most efficient mode.
MMDB_MODE_FILE
Read the database file into memory. This uses more memory than MMDB_MODE_MMAP, but may be faster on some systems.
MMDB_MODE_FOREIGN
The database file is already open and memory-mapped by the caller. The caller is responsible for unmapping the file.

The opened database is represented by the MMDB_s structure pointed to by mmdb. It is recommended to close the database with MMDB_close when done.

Returns MMDB_SUCCESS on success, or an error code on failure.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Closes a MaxMind DB file previously opened with MMDB_open.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ip_address,
    int *const gai_error,
    int *const mmdb_error);

Looks up an IP address in the MaxMind DB database. ip_address is a string representation of the IP address (IPv4 or IPv6). gai_error and mmdb_error are pointers to integers that will be populated with error codes from getaddrinfo and libmaxminddb, respectively. If the lookup is successful, returns an MMDB_lookup_result_s structure containing the result. If the lookup fails, the found_entry member of the returned structure will be false, and the error codes will indicate the nature of the error.

If gai_error is non-zero, the lookup failed due to a getaddrinfo error. Use gai_strerror to get a human-readable error message.

If mmdb_error is non-zero, the lookup failed due to a libmaxminddb error. Use MMDB_strerror to get a human-readable error message.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    const MMDB_lookup_result_s *const result,
    MMDB_entry_data_list_s **const entry_data_list);

Retrieves the data for the entry found in the lookup result as a linked list of key-value pairs. The list is allocated by this function and must be freed using MMDB_free_entry_data_list.

Returns MMDB_SUCCESS on success, or an error code on failure.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(MMDB_entry_data_list_s *const entry_data_list);

Frees the linked list of entry data allocated by MMDB_get_entry_data_list.

MMDB_entry_data_s_free()

void MMDB_entry_data_s_free(MMDB_entry_data_s *const entry_data);

Frees a single MMDB_entry_data_s structure and its contents. This is usually called by MMDB_free_entry_data_list.

MMDB_strerror()

const char *MMDB_strerror(int status);

Returns a human-readable string for the given status code.

MMDB_dump_entry_data_list()

void MMDB_dump_entry_data_list(
    FILE *const file,
    MMDB_entry_data_list_s *entry_data_list,
    int depth);

Dumps the entry data list to the given file pointer. depth is the current indentation level, used for pretty-printing nested data structures. This function is mainly intended for debugging and testing. The output format is not guaranteed to remain stable across releases.

The return value of the function is a status code as defined above.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

This reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void)

This function returns the library version as a string, something like "2.0.0".

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}

REQUIREMENTS

libmaxminddb requires a minimum of POSIX.1-2001 support. If not specified at compilation time, it defaults to requesting POSIX.1-2008 support.

THREAD SAFETY

This library is thread safe when compiled and linked with a thread-safe malloc and free implementation.
