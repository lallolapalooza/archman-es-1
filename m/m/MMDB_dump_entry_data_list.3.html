DESCRIPCIÓN

La biblioteca libmaxminddb proporciona funciones para trabajar con archivos MaxMind DB. Consulte https://maxmind.github.io/MaxMind-DB/ para la especificación del formato MaxMind DB. La base de datos y los resultados se representan mediante diferentes estructuras de datos. Las bases de datos se abren llamando a MMDB_open(). Puede buscar direcciones IP como una cadena con MMDB_lookup_string() o como un puntero a una estructura sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esa estructura indica que la base de datos tiene datos para la IP, hay una serie de funciones que se pueden utilizar para obtener esos datos. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Consulte la documentación de la función a continuación para obtener más detalles.

Cuando haya terminado con el manejador de la base de datos, debe llamar a MMDB_close().

Todas las funciones, estructuras y macros públicamente visibles comienzan con "MMDB_".

ESTRUCTURAS DE DATOS

Todas las estructuras de datos exportadas por el encabezado maxminddb.h de esta biblioteca están definidas con el formato typedef struct foo_s { ... } foo_s, por lo que puede referirse a ellas sin el prefijo struct.

Esta biblioteca proporciona las siguientes estructuras de datos:

MMDB_s

Este es el manejador para un archivo MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados al uso público. Todos los demás campos están sujetos a cambios y solo están destinados al uso interno.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - las banderas con las que se abrió esta base de datos. Consulte la documentación de MMDB_open() para obtener más detalles.
  • const char *filename - el nombre del archivo que se abrió, tal como se pasó a MMDB_open().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura se puede recuperar de la estructura MMDB_s. Contiene los metadatos leídos del archivo de base de datos. Tenga en cuenta que puede resultarle más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list() en su lugar.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deberían ser en su mayor parte autoexplicativas.

El miembro ip_version siempre debe ser 4 o 6. El miembro binary_format_major_version siempre debe ser 2.

No hay ningún requisito de que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que el count para estas partes de los metadatos puede ser cero. Todos los demás campos de MMDB_metadata_s deben estar poblados.

MMDB_lookup_result_s

Esta estructura se devuelve como resultado de la búsqueda de una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, los demás miembros de esta estructura no contienen valores significativos. Siempre verifique primero que found_entry sea verdadero.

El miembro entry se utiliza para buscar los datos asociados con la dirección IP.

El miembro netmask le indica a qué subred pertenece la dirección IP en esta base de datos. Por ejemplo, si busca la dirección 1.1.1.1 en una base de datos IPv4 y la máscara de red devuelta es 16, entonces la dirección es parte de la subred 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, la máscara de red devuelta es siempre una longitud de prefijo IPv6 (de 0 a 128), incluso si esa base de datos *también* contiene redes IPv4. Si busca una dirección IPv4 y desea convertir la máscara de red en un valor de máscara de red IPv4, puede simplemente restar 96 del valor.

MMDB_result_s

Realmente no necesita examinar esta estructura. La obtendrá de una estructura MMDB_lookup_result_s y la pasará a varias funciones.

MMDB_entry_data_s

Esta estructura se utiliza para devolver una entrada de sección de datos única para una IP. Estas entradas, a su vez, pueden apuntar a otras entradas, como es el caso de elementos como mapas y matrices. Algunos miembros de esta estructura no están documentados, ya que son solo para uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t o uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontraron datos para una búsqueda determinada. Consulte MMDB_get_value() para obtener más detalles. Si este miembro es falso, ninguno de los otros valores de la estructura es significativo.

Enteros de 128 bits

El manejo de datos uint128 depende de cómo tu plataforma soporte enteros de 128 bits, si es que lo hace. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más recientes de GCC (4.6+) y clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para solucionar estas diferencias, esta biblioteca define un tipo mmdb_uint128_t. Este tipo se define en la cabecera maxminddb.h para que puedas usarlo en tu propio código.

Con compiladores más antiguos, no podemos usar un entero, por lo que en su lugar usamos un array de 16 bytes de valores uint8_t. Estos son los datos brutos de la base de datos.

Esta biblioteca proporciona una macro pública MMDB_UINT128_IS_BYTE_ARRAY. Si esta es verdadera (1), entonces los valores uint128 se devuelven como un array de bytes; si es falsa, se devuelven como un entero mmdb_uint128_t.

Macros de Tipo de Dato

Esta biblioteca proporciona una macro para cada tipo de dato definido por la especificación MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que son solo para uso interno:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ves uno de estos en los datos devueltos, algo ha ido muy mal. La base de datos está dañada o se generó incorrectamente, o hay un error en el código de libmaxminddb.

Valores de Puntero y MMDB_close()

Los miembros utf8_string, bytes, y (quizás) uint128 de esta estructura son punteros directos a la sección de datos de la base de datos. Esto puede ser un bloque de memoria asignado con calloc o mmap. En cualquier caso, estos punteros se invalidarán después de llamar a MMDB_close().

Si necesitas referirte a estos datos después de ese momento, debes copiar los datos con una función apropiada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Esta estructura te permite ver entradas completas de datos de mapa o array iterando sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros en un nodo de búsqueda. Esto es realmente útil solo si quieres escribir código que itere sobre todo el árbol de búsqueda en lugar de buscar una dirección IP específica.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Los dos tipos de registro tomarán uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un marcador de posición que indica que no hay datos para la dirección IP. La búsqueda debería terminar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro es para datos en la sección de datos de la base de datos. Usa la entrada para el registro al buscar los datos del registro.
  • MMDB_RECORD_TYPE_INVALID - El registro no es válido. Se buscó un nodo inválido o la base de datos está corrupta.

La MMDB_entry_s para el registro solo es válida si el tipo es MMDB_RECORD_TYPE_DATA. Intentar usar una entrada para otros tipos de registro resultará en un error o datos inválidos.

CÓDIGOS DE ESTADO

Esta biblioteca devuelve (o rellena) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo funcionó
  • MMDB_FILE_OPEN_ERROR - hubo un error al intentar abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - una operación de E/S falló. Revisa errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - buscar una dirección IP en el árbol de búsqueda nos dio un resultado imposible. La base de datos está dañada o se generó incorrectamente, o hay un error en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos faltantes así como valores imposibles (como un ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - Los metadatos de la base de datos indican que su versión principal no es 2. Esta biblioteca solo puede manejar la versión principal 2.
  • MMDB_OUT_OF_MEMORY_ERROR - una llamada de asignación de memoria (malloc, etc.) falló.
  • MMDB_INVALID_DATA_ERROR - una entrada en la sección de datos contiene datos inválidos. Por ejemplo, un campo uint16 dice tener más de 2 bytes de longitud. La base de datos probablemente está dañada o se generó incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - La ruta de búsqueda pasada a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value contiene un índice de array que es mayor que LONGMAX o menor que LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - La ruta de búsqueda pasada a MMDB_get_value,MMDB_vget_value, o MMDB_aget_value no coincide con la estructura de datos de la entrada. Hay varias razones por las que esto puede suceder. La ruta de búsqueda podría incluir una clave que no está en un mapa. La ruta de búsqueda podría incluir un índice de array mayor que un array o menor que el desplazamiento mínimo desde el final de un array. También puede suceder cuando la ruta espera encontrar un mapa o un array donde no existen.

Todos los códigos de estado deben tratarse como valores int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés que explica el estado.

FUNCIONES

Esta biblioteca proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Esta función abre un manejador para un archivo MaxMind DB. Su valor de retorno es un código de estado como se define arriba. Siempre verifica el valor de retorno de esta llamada.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename debe estar codificado como UTF-8 en Windows.

La estructura MMDB_s que pasas puede estar en la pila o asignada desde el heap. Sin embargo, si la apertura es exitosa, contendrá datos asignados en el heap, por lo que necesitas cerrarla con MMDB_close(). Si el estado devuelto no es MMDB_SUCCESS, entonces esta biblioteca se asegura de que toda la memoria asignada sea liberada antes de devolver.

Las flags actualmente proporcionadas son:

•
MMDB_MODE_MMAP - abre la base de datos con mmap().

Pasar otros valores para flags puede producir resultados impredecibles. En el futuro podríamos agregar flags adicionales que puedas combinar bit a bit con el modo, así como modos adicionales.

También puedes pasar 0 como valor para flags, en cuyo caso la base de datos se abrirá con las flags por defecto. Sin embargo, estos valores por defecto pueden cambiar en futuras versiones. El valor por defecto actual es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esto libera cualquier memoria asignada o mapeada (mmap'd) que esté siendo utilizada por la estructura MMDB_s. *No libera la memor

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Esta función busca una dirección IP que se pasa como una cadena terminada en nulo. Internamente llama a getaddrinfo() para resolver la dirección a un formato binario. Luego llama a MMDB_lookup_sockaddr() para buscar la dirección en la base de datos. Si ya ha resuelto una dirección, puede llamar MMDB_lookup_sockaddr() directamente, en lugar de resolver la dirección dos veces.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Esta función siempre devuelve una estructura MMDB_lookup_result_s, pero también debe verificar los parámetros gai_error y mmdb_error. Si alguno de estos indica un error, la estructura devuelta no tiene sentido.

Si no ocurrió ningún error, aún debe asegurarse de que found_entry en el resultado devuelto sea verdadero. Si no lo es, significa que la dirección IP no tiene una entrada en la base de datos.

Esta función funcionará con direcciones IPv4 incluso cuando la base de datos contenga datos tanto para direcciones IPv4 como IPv6. La dirección IPv4 se buscará como '::xxx.xxx.xxx.xxx' en lugar de ser reasignada al bloque ::ffff:xxx.xxx.xxx.xxx asignado para direcciones IPv6 mapeadas a IPv4.

Si pasa una dirección IPv6 a una base de datos que solo contiene datos IPv4, el miembro found_entry será falso, pero el estado mmdb_error seguirá siendo MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Esta función busca una dirección IP que ya ha sido resuelta por getaddrinfo().

Aparte de no llamar a getaddrinfo(), esta función es idéntica a la función MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Funciones de Búsqueda de Datos

Existen tres funciones para buscar datos asociados con una dirección IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Las tres funciones permiten tres estilos de llamada ligeramente diferentes, pero todas hacen lo mismo.

El primer parámetro es un valor MMDB_entry_s. En la mayoría de los casos, provendrá del valor MMDB_lookup_result_s devuelto por MMDB_lookup_string() o MMDB_lookup_sockaddr().

El segundo parámetro es una referencia a una estructura MMDB_entry_data_s. Esta se llenará con los datos que se están buscando, si se encuentra alguno. Si no se encuentra nada, el miembro has_data de esta estructura será falso. Si has_data es verdadero, puede mirar el miembro data_type.

El último parámetro es una ruta de búsqueda. La ruta consta de un conjunto de cadenas que representan claves de mapa (por ejemplo, "city") o índices de matriz (por ejemplo, "0", "1", "-1") para usar en la búsqueda.

Los índices de matriz negativos se tratarán como un desplazamiento desde el final de la matriz. Por ejemplo, "-1" se refiere al último elemento de la matriz.

La ruta de búsqueda le permite navegar por una estructura de datos compleja. Por ejemplo, dados estos datos:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Podríamos buscar el nombre en inglés con este código:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si quisiéramos encontrar la primera ciudad, la ruta de búsqueda sería "cities", "0". Si no proporciona ninguna ruta de búsqueda, obtendrá la entrada que corresponde al mapa de nivel superior. La ruta de búsqueda siempre debe terminar en NULL, independientemente de la función que llame.

La función MMDB_get_value toma un número variable de argumentos. Todos los argumentos después del puntero a la estructura MMDB_entry_data_s * son la ruta de búsqueda. El último argumento debe ser NULL.

La función MMDB_vget_value acepta una va_list como ruta de búsqueda. El último elemento recuperado por va_arg() debe ser NULL.

Finalmente, MMDB_aget_value acepta una matriz de cadenas como ruta de búsqueda. El último miembro de esta matriz debe ser NULL.

Si desea obtener todos los datos de la entrada a la vez, puede llamar a MMDB_get_entry_data_list() en su lugar.

Para cada una de las tres funciones, el valor de retorno es un código de estado según se define anteriormente.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función permite obtener todos los datos de una estructura de datos compleja a la vez, en lugar de buscar cada pieza mediante llamadas repetidas a MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// guardar esto para poder liberar estos datos más tarde
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Depende de usted interpretar la estructura de datos entry_data_list. La lista está enlazada en una recorrida en profundidad. Usemos esta estructura como ejemplo:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La lista constará de los siguientes elementos:

1.

    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,

Esta función toma una lista enlazada de estructuras MMDB_entry_data_list_s y la convierte en cadena para el stream dado. El parámetro indent es el nivel de sangría inicial para la salida generada. Se incrementa para estructuras de datos anidadas (mapas, matrices, etc.).

El stream debe ser un manejador de archivo (stdout, etc.). Si su plataforma proporciona algo como open_memstream() de GNU, puede usarlo para capturar la salida como una cadena.

La salida se formatea de manera similar a JSON, pero los valores están marcados con su tipo de datos (excepto para mapas y matrices que se muestran con ""{}"" y ""[]"" respectivamente).

MMDB_dump_entry_data_list.3 - libmaxminddb

NAME

MMDB_dump_entry_data_list - dump entry data list

SYNOPSIS

#include <maxminddb.h>

void MMDB_dump_entry_data_list(
    FILE *const file,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

DESCRIPTION

This function is intended for debugging and showing data to users. The output is not guaranteed to be stable between library versions. You should not rely on the specific formatting produced by this function.

It will print the entry data list in a human-readable format to the specified file descriptor. The indent parameter controls the indentation level.

DATA STRUCTURES

The function takes an MMDB_entry_data_list_s which is a pointer to a linked list of MMDB_entry_data_s structures. Each MMDB_entry_data_s structure contains the type, data, and pointer to the next MMDB_entry_data_s in the list.

typedef struct MMDB_entry_data_s {
    MMDB_entry_data_list_s *next;
    MMDB_type_t type;
    union {
        char *string;
        uint32_t uint32;
        uint64_t uint64;
        double double_val;
        void *ptr;
    } data;
} MMDB_entry_data_s;

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s *entry;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

STATUS CODES

This function does not return a status code. It is a void function.

FUNCTIONS

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_lookup_result_s *const lookup_result,
    MMDB_entry_data_list_s **const entry_data_list);

This function retrieves the entry data for a given lookup result. It populates the entry_data_list with the data found. You must free the returned list using MMDB_free_entry_data_list().

The return value is a status code. It can be MMDB_SUCCESS on success, or an error code otherwise.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(MMDB_entry_data_list_s *entry_data_list);

Frees the memory allocated for an entry data list.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

This function reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void)

This function returns the library version as a string, something like "2.0.0".

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
