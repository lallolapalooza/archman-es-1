DESCRIPCIÓN

La biblioteca libmaxminddb proporciona funciones para trabajar con archivos MaxMind DB. Ver https://maxmind.github.io/MaxMind-DB/ para la especificación del formato MaxMind DB. La base de datos y los resultados se representan mediante diferentes estructuras de datos. Las bases de datos se abren llamando a MMDB_open(). Puede buscar direcciones IP como una cadena con MMDB_lookup_string() o como un puntero a una estructura sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esa estructura indica que la base de datos tiene datos para la IP, hay una serie de funciones que se pueden utilizar para obtener esos datos. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Ver la documentación de la función a continuación para más detalles.

Cuando haya terminado con el manejador de la base de datos, debe llamar a MMDB_close().

Todas las funciones, estructuras y macros visibles públicamente comienzan con "MMDB_".

ESTRUCTURAS DE DATOS

Todas las estructuras de datos exportadas por el encabezado maxminddb.h de esta biblioteca están tipificadas con la forma typedef struct foo_s { ... } foo_s para que puedas referirte a ellas sin el prefijo struct.

Esta biblioteca proporciona las siguientes estructuras de datos:

MMDB_s

Este es el manejador para un archivo MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados al uso público. Todos los demás campos están sujetos a cambios y están destinados únicamente al uso interno.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - las banderas con las que se abrió la base de datos. Ver la documentación de MMDB_open() para más detalles.
  • const char *filename - el nombre del archivo que se abrió, tal como se pasó a MMDB_open().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura se puede recuperar de la estructura MMDB_s. Contiene los metadatos leídos del archivo de base de datos. Tenga en cuenta que puede resultar más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list() en su lugar.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deberían ser en su mayor parte autoexplicativas.

El miembro ip_version siempre debe ser 4 o 6. El miembro binary_format_major_version siempre debe ser 2.

No hay requisito de que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que el count para estas partes de los metadatos puede ser cero. Todos los demás campos de MMDB_metadata_s deben estar poblados.

MMDB_lookup_result_s

Esta estructura se devuelve como resultado de buscar una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, los demás miembros de esta estructura no contienen valores significativos. Verifique siempre que found_entry sea verdadero primero.

El miembro entry se utiliza para buscar los datos asociados con la dirección IP.

El miembro netmask le indica a qué subred pertenece la dirección IP en esta base de datos. Por ejemplo, si busca la dirección 1.1.1.1 en una base de datos IPv4 y la netmask devuelta es 16, entonces la dirección es parte de la subred 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, la máscara de red devuelta es siempre una longitud de prefijo IPv6 (de 0 a 128), incluso si esa base de datos *también* contiene redes IPv4. Si busca una dirección IPv4 y desea convertir la máscara de red en un valor de máscara de red IPv4, puede simplemente restar 96 del valor.

MMDB_result_s

Realmente no necesitas hurgar en esta estructura. La obtendrás de una estructura MMDB_lookup_result_s y la pasarás a varias funciones.

MMDB_entry_data_s

Esta estructura se utiliza para devolver una única entrada de sección de datos para una IP. Estas entradas pueden, a su vez, apuntar a otras entradas, como ocurre con elementos como mapas y arreglos. Algunos miembros de esta estructura no están documentados, ya que son solo para uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t o uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontraron datos para una búsqueda determinada. Ver MMDB_get_value() para más detalles. Si este miembro es falso, entonces ninguno de los otros valores en la estructura tiene significado.

La unión al principio de la estructura define los datos reales. Para determinar qué unión

Si un miembro es poblado, debes examinar el miembro type. El miembro pointer de la unión nunca debe ser poblado en ningún dato devuelto por la API. Los punteros deben ser resueltos internamente.

El miembro data_size solo es relevante para datos de tipo utf8_string y bytes. utf8_string no está terminado con NULL y data_size debe usarse para determinar su longitud.

El miembro type puede compararse con uno de los macros MMDB_DATA_TYPE_*.

128-bit Integers

El manejo de datos de tipo uint128 depende de cómo tu plataforma soporta enteros de 128 bits, si es que lo hace. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más recientes de GCC (4.6+) y Clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para trabajar alrededor de estas diferencias, esta librería define un tipo mmdb_uint128_t. Este tipo está definido en el encabezado maxminddb.h para que puedas usarlo en tu propio código.

Con compiladores más antiguos, no podemos usar un entero, por lo que usamos un array de 16 bytes de uint8_t. Estos son los datos directos de la base de datos.

Esta librería proporciona una macro pública MMDB_UINT128_IS_BYTE_ARRAY. Si esta es verdadera (1), los valores de uint128 se devuelven como un array de bytes, si no, como un entero mmdb_uint128_t.

Data Type Macros

Esta librería proporciona una macro para cada tipo de datos definido por la especificación de MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que son únicamente para uso interno:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ves uno de estos en los datos devueltos, algo ha ido muy mal. La base de datos está dañada o fue generada incorrectamente, o hay un error en el código de libmaxminddb.

Pointer Values and MMDB_close()

Los miembros utf8_string, bytes y (posiblemente) el miembro uint128 de esta estructura son todos punteros directamente a la sección de datos de la base de datos. Esto puede ser un bloque de memoria calloc o mmap. En cualquier caso, estos punteros se vuelven inválidos después de llamarse a MMDB_close().

Si necesitas referirte a estos datos después de ese tiempo, debes copiar los datos con una función adecuada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Esta estructura te permite examinar datos de mapa o array mediante la iteración sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros de un nodo de búsqueda. Esto es realmente útil si quieres escribir código que itere sobre todo el árbol de búsqueda en lugar de buscar un IP específico.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Los tipos de registro serán uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un marcador de posición que indica que no hay datos para el IP. La búsqueda debe terminar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro contiene datos en la sección de datos de la base de datos. Usa el registro cuando busques los datos del registro.
  • MMDB_RECORD_TYPE_INVALID - El registro es inválido. La razón puede ser un nodo inválido buscado o la base de datos dañada.

El MMDB_entry_s del registro es válido solo si el tipo es MMDB_RECORD_TYPE_DATA. El uso de un registro de otros tipos genera un error o datos inválidos.

STATUS CODES

Esta librería devuelve (o popula) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo funcionó.
  • MMDB_FILE_OPEN_ERROR - hubo un error al abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - una operación de entrada/salida falló. Verifica errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - al buscar un IP en el árbol de búsqueda se obtuvo un resultado imposible. La base de datos está dañada o fue generada incorrectamente, o hay un error en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos faltantes o valores imposibles (como ip_version = 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - los metadatos de la base de datos indican que su versión mayor no es 2. Esta librería solo puede manejar la versión mayor 2.
  • MMDB_OUT_OF_MEMORY_ERROR - un llamado a la asignación de memoria falló (malloc, etc.).
  • MMDB_INVALID_DATA_ERROR - un campo de datos contiene datos inválidos. Por ejemplo, un campo uint16 afirma ser más de 2 bytes. La base de datos probablemente está dañada o fue generada incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - la ruta de búsqueda pasada a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value contiene un desplazamiento de array mayor que LONG_MAX o menor que LONG_MIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - la ruta de búsqueda pasada a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value no coincide con la estructura de datos de la entrada. Pueden ocurrir varias razones. La ruta de búsqueda podría incluir una clave no presente en un mapa. La ruta de búsqueda podría incluir un índice de array mayor que un array o menor que el desplazamiento mínimo desde el final de un array. También puede ocurrir cuando la ruta espera encontrar un mapa o array donde ninguno existe.

Todos los códigos de estado deben tratarse como valores de tipo int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés explicando el estado.

FUNCTIONS

Esta librería proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Esta función abre un handle a un archivo MaxMind DB. El valor de retorno es un código de estado como se define anteriormente. Debes verificar el valor de retorno de esta llamada.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

El filename debe estar codificado como UTF-8 en Windows.

La estructura MMDB_s que pasas puede estar en la pila o reservada en memoria heap. Sin embargo, si la apertura tiene éxito, contendrá datos reservados en memoria heap, por lo que debes cerrarla con MMDB_close(). Si el código de estado no es MMDB_SUCCESS, esta librería se asegurará de que toda la memoria reservada se libere antes de devolver.

Los flags actuales son:

•
MMDB_MODE_MMAP - abre el archivo con mmap().

Puedes pasar 0 como valor de flags para abrir el archivo con los flags por defecto. Sin embargo, estos valores pueden cambiar en futuras versiones. El valor por defecto es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esta librería libera cualquier memoria reservada o mmap'd que esté asociada con la estructura MMDB_s. No libera la memoria de la base de datos.

y asignada a la propia estructura! Si has asignado la estructura desde el montón (heap), eres responsable de liberarla.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Esta función busca una dirección IP que se pasa como una cadena terminada en nulo. Internamente llama a getaddrinfo() para resolver la dirección a un formato binario. Luego llama a MMDB_lookup_sockaddr() para buscar la dirección en la base de datos. Si ya has resuelto una dirección, puedes llamar directamente a MMDB_lookup_sockaddr(), en lugar de resolver la dirección dos veces.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Esta función siempre devuelve una estructura MMDB_lookup_result_s, pero también debes comprobar los parámetros gai_error y mmdb_error. Si alguno de ellos indica un error, la estructura devuelta no tiene sentido.

Si no ocurrió ningún error, aún debes asegurarte de que found_entry en el resultado devuelto sea verdadero. Si no lo es, significa que la dirección IP no tiene una entrada en la base de datos.

Esta función funcionará con direcciones IPv4 incluso cuando la base de datos contenga datos tanto para direcciones IPv4 como IPv6. La dirección IPv4 se buscará como '::xxx.xxx.xxx.xxx' en lugar de ser mapeada al bloque ::ffff:xxx.xxx.xxx.xxx asignado a direcciones IPv6 mapeadas a IPv4.

Si pasas una dirección IPv6 a una base de datos con solo datos IPv4, el miembro found_entry será falso, pero el estado mmdb_error seguirá siendo MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Esta función busca una dirección IP que ya ha sido resuelta por getaddrinfo().

Aparte de no llamar a getaddrinfo() en sí, esta función es idéntica a la función MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Funciones de búsqueda de datos

Hay tres funciones para buscar datos asociados con una dirección IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Las tres funciones permiten tres estilos de llamada ligeramente diferentes, pero todas hacen lo mismo.

El primer parámetro es un valor MMDB_entry_s. En la mayoría de los casos, provendrá del valor MMDB_lookup_result_s devuelto por MMDB_lookup_string() o MMDB_lookup_sockaddr().

El segundo parámetro es una referencia a una estructura MMDB_entry_data_s. Esta se poblará con los datos que se están buscando, si se encuentra alguno. Si no se encuentra nada, el miembro has_data de esta estructura será falso. Si has_data es verdadero, puedes ver el miembro data_type.

El último parámetro es una ruta de búsqueda. La ruta consta de un conjunto de cadenas que representan claves de mapa (por ejemplo, "city") o índices de array (por ejemplo, "0", "1", "-1") para usar en la búsqueda.

Los índices de array negativos se tratarán como un desplazamiento desde el final del array. Por ejemplo, "-1" se refiere al último elemento del array.

La ruta de búsqueda permite navegar por una estructura de datos compleja. Por ejemplo, dados estos datos:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Podríamos buscar el nombre en inglés con este código:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si quisiéramos encontrar la primera ciudad, la ruta de búsqueda sería "cities", . Si no proporcionas ninguna ruta de búsqueda, obtendrás la entrada que corresponde al mapa de nivel superior. La ruta de búsqueda siempre debe terminar con NULL, independientemente de la función que llames.

La función MMDB_get_value toma un número variable de argumentos. Todos los argumentos después del puntero de la estructura MMDB_entry_data_s * son la ruta de búsqueda. El último argumento debe ser NULL.

La función MMDB_vget_value acepta una va_list como ruta de búsqueda. El último elemento recuperado por va_arg() debe ser NULL.

Finalmente, MMDB_aget_value acepta un array de cadenas como ruta de búsqueda. El último miembro de este array debe ser NULL.

Si deseas obtener todos los datos de la entrada a la vez, puedes llamar a MMDB_get_entry_data_list() en su lugar.

Para cada una de las tres funciones, el valor de retorno es un código de estado según se define arriba.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función te permite obtener todos los datos de una estructura de datos compleja a la vez, en lugar de buscar cada pieza mediante llamadas repetidas a MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// guarda esto para poder liberar estos datos más tarde
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Depende de ti interpretar la estructura de datos entry_data_list. La lista está enlazada en un recorrido en profundidad. Usemos esta estructura como ejemplo:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La lista constará de los siguientes elementos:

1.
MAP - mapa de nivel superior
2.
UTF8_STRING - clave "names"
3.
MAP - mapa para la clave "names"
4.
UTF8_STRING - clave "en"
5.
UTF8_STRING - valor para la clave "en"
6.
UTF8_STRING - clave "de"
7.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

Las funciones MMDB_get_entry_data_list() y MMDB_get_metadata_as_entry_data_list() asignarán la estructura de lista enlazada desde el montón (heap). Llama a esta función para liberar la estructura MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función te permite recuperar los metadatos de la base de datos como una lista enlazada de estructuras MMDB_entry_data_list_s. Esta puede ser una forma más conveniente de manejar los metadatos que usar la estructura de metadatos directamente.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // haz algo con los datos
    MMDB_free_entry_data_list(first);

El valor de retorno de la función es un código de estado según se define arriba.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Esta función toma una lista enlazada de estructuras MMDB_entry_data_list_s y la convierte en una cadena para el stream dado. El parámetro indent es el nivel de sangría inicial para la salida generada. Se incrementa para estructuras de datos anidadas (mapas, arrays, etc.).

El stream debe ser un manejador de archivo (stdout, etc.). Si tu plataforma proporciona algo como open_memstream() de GNU, puedes usarlo para capturar la salida como una cadena.

La salida está formateada de manera similar a JSON, pero los valores están marcados con su tipo de datos (excepto para mapas y arrays que se muestran con "{}" y "[]" respectivamente).

libmaxminddb — MaxMind DB file access library

NAME

libmaxminddb — MaxMind DB file access library

SYNOPSIS

#include <maxminddb.h>

DESCRIPTION

The libmaxminddb library provides access to MaxMind DB files. MaxMind DB is a binary file format that stores geolocation data. This library allows you to look up information based on IP addresses.

MaxMind DB files are immutable. When you open a database, you are given read-only access. All data is read directly from the file, so there is no need to load the entire database into memory.

This library is designed to be fast and efficient, and is suitable for use in high-performance applications. It uses memory-mapped files (on systems that support them) to achieve this.

DATA STRUCTURES

• MMDB_s
Represents an open MaxMind DB database. This structure is opaque and should not be accessed directly.
• MMDB_lookup_result_s
Contains the result of a lookup. If the lookup was successful, found_entry will be true, and entry will contain information about the entry found.
• MMDB_entry_data_list_s
Represents a list of entry data values. This is typically used to represent the data associated with an IP address in the database.
• MMDB_entry_data_s
Represents a single entry data value. This structure contains the type of the data (e.g., string, integer, array) and a union to hold the actual data.
• MMDB_search_node_s
Represents a node in the MaxMind DB search tree. This is used internally by the library and is primarily for debugging purposes.

STATUS CODES

The following status codes are returned by the library functions:

• MMDB_SUCCESS
Operation completed successfully.
• MMDB_IO_ERROR
An I/O error occurred while accessing the database file.
• MMDB_CORRUPT_MMDB_ERROR
The database file is corrupt or not a valid MaxMind DB file.
• MMDB_INVALID_INTERFACE_ERROR
An invalid interface was specified when opening the database.
• MMDB_INVALID_METADATA_ERROR
The database metadata is invalid.
• MMDB_INVALID_NODE_NUMBER_ERROR
An invalid node number was specified.
• MMDB_OUT_OF_MEMORY_ERROR
An out-of-memory error occurred.
• MMDB_FUNCTION_NOT_IMPLEMENTED_ERROR
The requested function is not implemented.
• MMDB_NULL_POINTER_ERROR
A null pointer was passed to a function.
• MMDB_UNKNOWN_ATTRIBUTE_ERROR
An unknown attribute was encountered.
• MMDB_UNSUPPORTED_METADATA_VERSION_ERROR
The database metadata version is unsupported.

FUNCTIONS

MMDB_open()

int MMDB_open(
    const char *filename,
    MMDB_mode_e mode,
    MMDB_s *const mmdb);

Opens a MaxMind DB file for reading. The filename argument is the path to the database file. The mode argument specifies how the file should be opened. Supported modes are:

• MMDB_MODE_MMAP
Use memory-mapped files for efficient access. This is the recommended mode.
• MMDB_MODE_FILE
Read the entire database into memory. This can be slower and consume more memory, but may be useful on systems that do not support memory-mapped files well.
• MMDB_MODE_STDIN
Read the database from standard input. This is primarily for testing and debugging.

The mmdb argument is a pointer to an MMDB_s structure that will be populated by this function. The return value is a status code.

MMDB_close()

void MMDB_close(
    MMDB_s *mmdb);

Closes an open MaxMind DB database and frees any associated resources.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ip_address,
    int *gai_error,
    int *mmdb_error);

Looks up an IP address in the MaxMind DB database. The ip_address argument is a string representation of the IP address to look up. The gai_error and mmdb_error arguments are pointers to integers that will be populated with error codes from getaddrinfo and libmaxminddb, respectively. The function returns an MMDB_lookup_result_s structure containing the lookup result.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    const MMDB_lookup_result_s *const lookup_result,
    MMDB_entry_data_list_s **entry_data_list);

Retrieves the data associated with a lookup result as a linked list of MMDB_entry_data_s structures. The second argument is a pointer to a pointer to an MMDB_entry_data_list_s structure, which will be populated by this function. The return value is a status code.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *entry_data_list);

Frees the memory associated with an MMDB_entry_data_list_s structure.

MMDB_dump_entry_data_list()

void MMDB_dump_entry_data_list(
    FILE *const file,
    const MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Dumps the contents of an MMDB_entry_data_list_s structure to a file. This function is primarily intended for debugging and testing purposes. The indent argument specifies the indentation level for pretty-printing.

Warning: The formatting produced by this function is not stable and may change in future releases. You should not rely on the specific formatting produced by this function. It is intended to be used to show data to users in a readable way and for debugging purposes.

The return value of the function is a status code as defined above.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

This reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void)

This function returns the library version as a string, something like "2.0.0".

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}

REQUIREMENTS

libmaxminddb requires a minimum of POSIX.1-2001 support. If not specified at compilation time, it defaults to requesting POSIX.1-2008 support.

THREAD SAFETY

This library is thread safe when compiled and linked with a thread-safe malloc and free implementation.
