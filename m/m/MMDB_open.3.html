DESCRIPCIÓN

La biblioteca libmaxminddb proporciona funciones para trabajar con archivos MaxMind DB. Consulte https://maxmind.github.io/MaxMind-DB/ para la especificación del formato MaxMind DB. La base de datos y los resultados se representan mediante diferentes estructuras de datos. Las bases de datos se abren llamando a MMDB_open(). Puede buscar direcciones IP como una cadena con MMDB_lookup_string() o como un puntero a una estructura sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esa estructura indica que la base de datos tiene datos para la IP, hay una serie de funciones que se pueden usar para recuperar esos datos. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Consulte la documentación de la función a continuación para obtener más detalles.

Cuando haya terminado con el manejador de la base de datos, debe llamar a MMDB_close().

Todas las funciones, estructuras y macros públicamente visibles comienzan con "MMDB_".

ESTRUCTURAS DE DATOS

Todas las estructuras de datos exportadas por el encabezado maxminddb.h de esta biblioteca están definidas con el formato typedef struct foo_s { ... } foo_s, por lo que puede referirse a ellas sin el prefijo struct.

Esta biblioteca proporciona las siguientes estructuras de datos:

MMDB_s

Este es el manejador para un archivo MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados al uso público. Todos los demás campos están sujetos a cambios y están destinados únicamente al uso interno.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - las banderas con las que se abrió esta base de datos. Consulte la documentación de MMDB_open() para obtener más detalles.
  • const char *filename - el nombre del archivo que se abrió, tal como se pasó a MMDB_open().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura se puede recuperar de la estructura MMDB_s. Contiene los metadatos leídos del archivo de base de datos. Tenga en cuenta que puede resultarle más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list() en su lugar.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deberían ser en su mayor parte autoexplicativas.

El miembro ip_version siempre debe ser 4 o 6. El binary_format_major_version siempre debe ser 2.

No hay ningún requisito de que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que el count para estas partes de los metadatos puede ser cero. Todos los demás campos de MMDB_metadata_s deben estar poblados.

MMDB_lookup_result_s

Esta estructura se devuelve como resultado de la búsqueda de una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, los demás miembros de esta estructura no contienen valores significativos. Compruebe siempre que found_entry sea verdadero primero.

El miembro entry se utiliza para buscar los datos asociados con la dirección IP.

El miembro netmask le indica a qué subred pertenece la dirección IP en esta base de datos. Por ejemplo, si busca la dirección 1.1.1.1 en una base de datos IPv4 y el netmask devuelto es 16, entonces la dirección es parte de la subred 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, la máscara de red devuelta es siempre una longitud de prefijo IPv6 (de 0 a 128), incluso si esa base de datos *también* contiene redes IPv4. Si busca una dirección IPv4 y desea convertir la máscara de red en un valor de máscara de red IPv4, simplemente puede restar 96 del valor.

MMDB_result_s

Realmente no necesita investigar mucho en esta estructura. La obtendrá de una estructura MMDB_lookup_result_s y la pasará a varias funciones.

MMDB_entry_data_s

Esta estructura se utiliza para devolver una única entrada de sección de datos para una IP. Estas entradas pueden, a su vez, apuntar a otras entradas, como ocurre con cosas como mapas y matrices. Algunos campos de esta estructura no están documentados, ya que son solo para uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontraron datos para una búsqueda determinada. Consulte MMDB_get_value() para obtener más detalles. Si este miembro es falso, ninguno de los otros valores de la estructura tiene sentido.

La unión al principio de la estructura define los datos reales. Para determinar qué miembro de la unión está poblado

STRUCTURES

This library provides the following exported structures:

MMDB_entry_data_s

This is the primary structure for retrieving data from the database. It is filled out by the various MMDB_get_value functions.

typedef struct MMDB_entry_data_s {
    uint32_t data_size;
    MMDB_data_type_e type;
    union {
        uint8_t *bytes;
        char *utf8_string;
        uint16_t uint16;
        uint32_t uint32;
        uint64_t uint64;
        mmdb_uint128_t uint128;
        double double_val;
        float float_val;
        int32_t int32;
        int boolean;
        void *pointer;
    } data;
} MMDB_entry_data_s;

The type member specifies what kind of data is stored in the data union. You should use this to determine which member of the union is valid.

The pointer member of the union should never be populated in any data returned by the API. Pointers should always be resolved internally.

The data_size member is only relevant for utf8_string and bytes data. utf8_string is not null terminated and data_size must be used to determine its length.

The type member can be compared to one of the MMDB_DATA_TYPE_* macros.

Enteros de 128 bits

El manejo de datos uint128 depende de cómo tu plataforma soporte enteros de 128 bits, si es que lo hace. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más nuevas de GCC (4.6+) y clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para solucionar estas diferencias, esta biblioteca define un tipo mmdb_uint128_t. Este tipo está definido en el encabezado maxminddb.h para que puedas usarlo en tu propio código.

Con compiladores más antiguos, no podemos usar un entero así que en su lugar usamos un array de 16 bytes de valores uint8_t. Estos son los datos brutos de la base de datos.

Esta biblioteca proporciona una macro pública MMDB_UINT128_IS_BYTE_ARRAY. Si este es verdadero (1), entonces los valores uint128 se devuelven como un array de bytes, si es falso, se devuelven como un entero mmdb_uint128_t.

Macros de tipo de datos

Esta biblioteca proporciona una macro para cada tipo de dato definido por la especificación de MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que son solo para uso interno:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ves uno de estos en los datos devueltos, algo ha salido muy mal. La base de datos está dañada o fue generada incorrectamente, o hay un error en el código de libmaxminddb.

Valores de puntero y MMDB_close()

Los miembros utf8_string, bytes y (quizás) uint128 de esta estructura son todos punteros directos a la sección de datos de la base de datos. Esto puede ser un bloque de memoria calloc'd o mmap'd. En cualquier caso, estos punteros se volverán inválidos después de que se llame a MMDB_close().

Si necesitas referirte a estos datos después de ese momento, debes copiar los datos con una función apropiada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Esta estructura te permite ver una entrada de datos de mapa o array completa iterando sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros en un nodo de búsqueda. Esto es realmente útil solo si quieres escribir código que itere sobre todo el árbol de búsqueda en lugar de buscar una dirección IP específica.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Los dos tipos de registro tomarán uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un marcador de posición que indica que no hay datos para la dirección IP. La búsqueda debería terminar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro es para datos en la sección de datos de la base de datos. Usa la entrada para el registro al buscar los datos del registro.
  • MMDB_RECORD_TYPE_INVALID - El registro no es válido. Se buscó un nodo no válido o la base de datos está corrupta.

El MMDB_entry_s para el registro solo es válido si el tipo es MMDB_RECORD_TYPE_DATA. Intentar usar una entrada para otros tipos de registro resultará en un error o datos inválidos.

CÓDIGOS DE ESTADO

Esta biblioteca devuelve (o rellena) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo funcionó
  • MMDB_FILE_OPEN_ERROR - hubo un error al intentar abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - una operación de E/S falló. Verifica errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - buscar una dirección IP en el árbol de búsqueda nos dio un resultado imposible. La base de datos está dañada o fue generada incorrectamente, o hay un error en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos faltantes así como valores imposibles (como un ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - Los metadatos de la base de datos indican que su versión principal no es 2. Esta biblioteca solo puede manejar la versión principal 2.
  • MMDB_OUT_OF_MEMORY_ERROR - una llamada de asignación de memoria (malloc, etc.) falló.
  • MMDB_INVALID_DATA_ERROR - una entrada en la sección de datos contiene datos inválidos. Por ejemplo, un campo uint16 está reclamando ser de más de 2 bytes de longitud. La base de datos probablemente está dañada o fue generada incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - La ruta de búsqueda pasada a MMDB_get_value, MMDB_vget_value, o MMDB_aget_value contiene un índice de array que es mayor que LONGMAX o menor que LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - La ruta de búsqueda pasada a MMDB_get_value,MMDB_vget_value, o MMDB_aget_value no coincide con la estructura de datos de la entrada. Hay varias razones por las que esto puede suceder. La ruta de búsqueda podría incluir una clave que no está en un mapa. La ruta de búsqueda podría incluir un índice de array mayor que un array o menor que el desplazamiento mínimo desde el final de un array. También puede suceder cuando la ruta espera encontrar un mapa o un array donde no existen.

Todos los códigos de estado deben tratarse como valores int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés que explica el estado.

FUNCIONES

Esta biblioteca proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Esta función abre un manejador para un archivo MaxMind DB. Su valor de retorno es un código de estado como se define arriba. Siempre verifica el valor de retorno de esta llamada.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename debe estar codificado como UTF-8 en Windows.

La estructura MMDB_s que pasas puede estar en la pila o asignada desde el heap. Sin embargo, si la apertura es exitosa, contendrá datos asignados desde el heap, por lo que necesitas cerrarla con MMDB_close(). Si el estado devuelto no es MMDB_SUCCESS, esta biblioteca se asegura de que toda la memoria asignada se libere antes de devolverla.

Las banderas actualmente proporcionadas son:

•
MMDB_MODE_MMAP - abre la base de datos con mmap().

Pasar otros valores para flags puede producir resultados impredecibles. En el futuro, podemos agregar banderas adicionales que puedas combinar con un OR bit a bit con el modo, así como modos adicionales.

También puedes pasar 0 como valor para flags, en cuyo caso la base de datos se abrirá con las banderas predeterminadas. Sin embargo, estos predeterminados pueden cambiar en futuras versiones. El predeterminado actual es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esto libera cualquier memoria asignada o mapeada que se mantenga de la estructura MMDB_s. No libera la memoria asignada

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Esta función busca una dirección IP que se pasa como una cadena terminada en nulo. Internamente llama a getaddrinfo() para resolver la dirección en una forma binaria. Luego llama a MMDB_lookup_sockaddr() para buscar la dirección en la base de datos. Si ya ha resuelto una dirección, puede llamar a MMDB_lookup_sockaddr() directamente, en lugar de resolver la dirección dos veces.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Esta función siempre devuelve una estructura MMDB_lookup_result_s, pero también debe verificar los parámetros gai_error y mmdb_error. Si alguno de estos indica un error, la estructura devuelta no tiene sentido.

Si no ocurrió ningún error, aún debe asegurarse de que el miembro found_entry en el resultado devuelto sea verdadero. Si no lo es, significa que la dirección IP no tiene una entrada en la base de datos.

Esta función funcionará con direcciones IPv4 incluso cuando la base de datos contenga datos tanto para direcciones IPv4 como IPv6. La dirección IPv4 se buscará como '::xxx.xxx.xxx.xxx' en lugar de ser remapeada al bloque ::ffff:xxx.xxx.xxx.xxx asignado para direcciones IPv6 mapeadas a IPv4.

Si pasa una dirección IPv6 a una base de datos con solo datos IPv4, el miembro found_entry será falso, pero el estado mmdb_error seguirá siendo MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Esta función busca una dirección IP que ya ha sido resuelta por getaddrinfo().

Aparte de no llamar a getaddrinfo() en sí, esta función es idéntica a la función MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Funciones de Búsqueda de Datos

Hay tres funciones para buscar datos asociados con una dirección IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Las tres funciones permiten tres estilos de llamada ligeramente diferentes, pero todas hacen lo mismo.

El primer parámetro es un valor MMDB_entry_s. En la mayoría de los casos, provendrá del valor MMDB_lookup_result_s devuelto por MMDB_lookup_string() o MMDB_lookup_sockaddr().

El segundo parámetro es una referencia a una estructura MMDB_entry_data_s. Esta se poblará con los datos que se están buscando, si se encuentra algo. Si no se encuentra nada, el miembro has_data de esta estructura será falso. Si has_data es verdadero, puede examinar el miembro data_type.

El parámetro final es una ruta de búsqueda. La ruta consta de un conjunto de cadenas que representan claves de mapa (por ejemplo, "ciudad") o índices de matriz (por ejemplo, "0", "1", "-1") para usar en la búsqueda.

Los índices de matriz negativos se tratarán como un desplazamiento desde el final de la matriz. Por ejemplo, "-1" se refiere al último elemento de la matriz.

La ruta de búsqueda le permite navegar por una estructura de datos compleja. Por ejemplo, dados estos datos:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Podríamos buscar el nombre en inglés con este código:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si quisiéramos encontrar la primera ciudad, la ruta de búsqueda sería "cities", "0". Si no proporciona ninguna ruta de búsqueda, obtendrá la entrada que corresponde al mapa de nivel superior. La ruta de búsqueda siempre debe terminar en NULL, independientemente de la función que llame.

La función MMDB_get_value toma un número variable de argumentos. Todos los argumentos después del puntero a la estructura MMDB_entry_data_s * son la ruta de búsqueda. El último argumento debe ser NULL.

La función MMDB_vget_value acepta un va_list como ruta de búsqueda. El último elemento recuperado por va_arg() debe ser NULL.

Finalmente, MMDB_aget_value acepta una matriz de cadenas como ruta de búsqueda. El último miembro de esta matriz debe ser NULL.

Si desea obtener todos los datos de la entrada a la vez, puede llamar a MMDB_get_entry_data_list() en su lugar.

Para cada una de las tres funciones, el valor de retorno es un código de estado según se define anteriormente.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función le permite obtener todos los datos de una estructura de datos compleja a la vez, en lugar de buscar cada pieza mediante llamadas repetidas a MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// guardamos esto para poder liberar estos datos más tarde
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Depende de usted interpretar la estructura de datos entry_data_list. La lista está enlazada en un recorrido en profundidad. Usemos esta estructura como ejemplo:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La lista constará de los siguientes elementos:

1.
MAP - mapa de nivel superior
2.
UTF8_STRING - clave "names"
3.
MAP - mapa para la clave "names"
4.
UTF8_STRING - clave "en"
5.
UTF8_STRING - valor para la clave "en"
6.
UTF8_STRING - clave "de"
7.
UTF8_STRING - valor para la clave "de"
8.
UTF8_STRING - clave "cities"
9.
ARRAY - valor para la clave "cities"
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

El valor de retorno de la función es un código de estado según se define anteriormente.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

Las funciones MMDB_get_entry_data_list() y MMDB_get_metadata_as_entry_data_list() asignarán la estructura de lista enlazada desde el heap. Llame a esta función para liberar la estructura MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función le permite recuperar los metadatos de la base de datos como una lista enlazada de estructuras MMDB_entry_data_list_s. Esta puede ser una forma más conveniente de trabajar con los metadatos que usar la estructura de metadatos directamente.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // hacer algo con los datos
    MMDB_free_entry_data_list(first);

El valor de retorno de la función es un código de estado según se define anteriormente.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Esta función toma una lista enlazada de estructuras MMDB_entry_data_list_s y la convierte en cadena para el stream dado. El parámetro indent es el nivel de sangría inicial para la salida generada. Se incrementa para estructuras de datos anidadas (mapas, matrices, etc.).

El stream debe ser un manejador de archivos (stdout, etc.). Si su plataforma proporciona algo como el open_memstream() de GNU, puede usarlo para capturar la salida como una cadena.

La salida tiene un formato similar a JSON, pero los valores están marcados con su tipo de datos (excepto para mapas y matrices que se muestran con "{}" y "[]" respectivamente).

El formato de salida específico puede cambiar en futuras versiones.

NAME

libmaxminddb - API for the MaxMind DB file format

SYNOPSIS

#include <maxminddb.h>
int MMDB_open(const char *filename, uint32_t flags, MMDB_s *mmdb);
void MMDB_close(MMDB_s *mmdb);
int MMDB_read_node(MMDB_s *const mmdb, uint32_t node_number,
                   MMDB_search_node_s *const node);
const char *MMDB_lib_version(void);
void MMDB_dump_reader_log(FILE *file, MMDB_s *mmdb);
void MMDB_free_entry_data_list(MMDB_entry_data_list_s *list);
MMDB_lookup_result_s MMDB_lookup_string(MMDB_s *const mmdb,
                                       const char *ip_address,
                                       int *gai_error, int *mmdb_error);
const char *MMDB_strerror(int status);

DESCRIPTION

libmaxminddb is a library for reading MaxMind DB files. The MaxMind DB file format is a simple, flat key value store. It is designed to be fast and efficient.

This library can be used for looking up data in MaxMind DB files. The primary use case is for looking up geographical data for IP addresses.

MMDB_open()

int MMDB_open(const char *filename, uint32_t flags, MMDB_s *mmdb);

Opens a MaxMind DB file specified by filename. The flags argument specifies how the database should be opened. Currently, the following flags are supported:

MMDB_MODE_MMAP
Use mmap(2) to map the database into memory. This is the fastest mode.
MMDB_MODE_FILE
Read the database from the file directly. This is slower than mmap but uses less memory.
MMDB_MODE_LOCAL
Read the database from memory. The database must have been loaded into memory beforehand using MMDB_read_all. This is the fastest mode and uses the least memory.

The mmdb argument is a pointer to an MMDB_s structure that will be populated by this function. If the database is opened successfully, this function will return MMDB_SUCCESS. Otherwise, it will return an error code as defined in the STATUS CODES section.

MMDB_close()

void MMDB_close(MMDB_s *mmdb);

Closes a MaxMind DB file previously opened with MMDB_open. This function will free any memory allocated by MMDB_open.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(MMDB_s *const mmdb,
                                               const char *ip_address,
                                               int *gai_error,
                                               int *mmdb_error);

Looks up an IP address in the MaxMind DB file. The ip_address argument is a string representation of the IP address to look up. The gai_error and mmdb_error arguments are pointers to integers that will be populated with error codes from getaddrinfo and libmaxminddb, respectively. If the IP address is found in the database, the returned MMDB_lookup_result_s structure will have its found_entry member set to true.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(MMDB_s *const mmdb,
                                     MMDB_lookup_result_s *result,
                                     MMDB_entry_data_list_s **entry_data_list);

Retrieves the data associated with a found entry as a linked list. The result argument is the result from MMDB_lookup_string. The entry_data_list argument is a pointer to a pointer to an MMDB_entry_data_list_s structure. This structure will be populated with the entry data. It is the caller's responsibility to free the memory allocated for this structure using MMDB_free_entry_data_list.

MMDB_dump_entry_data_list()

void MMDB_dump_entry_data_list(FILE *file,
                                       MMDB_entry_data_list_s *entry_data_list,
                                       int spaces);

Dumps the contents of an MMDB_entry_data_list_s structure to a file. The spaces argument specifies the number of spaces to use for indentation. This function is intended for debugging and displaying data to users. The formatting may change between releases, so you should not rely on the specific formatting produced by this function. It is intended to be used to show data to users in a readable way and for debugging purposes.

The return value of the function is a status code as defined above.

MMDB_read_node()

int MMDB_read_node(MMDB_s *const mmdb,
                           uint32_t node_number,
                           MMDB_search_node_s *const node);

This reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void);

This function returns the library version as a string, something like "2.0.0".

DATA STRUCTURES

MMDB_s
Structure representing an open MaxMind DB database.
MMDB_lookup_result_s
Structure representing the result of a lookup operation.
MMDB_entry_data_list_s
Structure representing a linked list of entry data.
MMDB_entry_data_s
Structure representing a single piece of entry data.
MMDB_search_node_s
Structure representing a node in the MaxMind DB search tree.

STATUS CODES

The following status codes are returned by the functions in this library:

MMDB_SUCCESS
Operation successful.
MMDB_SUCCESS_USER_TYPED_IP_IN_PRIVATE_RANGE
Lookup successful, but the IP address was in a private range and may not be globally unique.
MMDB_FILE_NOT_FOUND_ERROR
The specified database file could not be found.
MMDB_INVALID_INTERFACE_ERROR
Invalid interface specified for lookup.
MMDB_INVALID_METADATA_ERROR
The database file is missing or has invalid metadata.
MMDB_INVALID_DATA_ERROR
The database file contains invalid data.
MMDB_OUT_OF_MEMORY_ERROR
Out of memory.
MMDB_IO_ERROR
An I/O error occurred while reading the database file.
MMDB_NULL_POINTER_ERROR
A null pointer was passed to a function.
MMDB_INVALID_RETURN_TYPE_ERROR
The returned data has an invalid type.
MMDB_CORRUPT_DATA_ERROR
The database file is corrupt.
MMDB_LOOKUP_FAILED_ERROR
The lookup failed for an unspecified reason.
MMDB_NOT_IMPLEMENTED_ERROR
The requested feature is not implemented.
MMDB_INVALID_NODE_NUMBER_ERROR
The specified node number is invalid.
MMDB_INVALID_LOOKUP_PATH_ERROR
The lookup path is invalid.

FUNCTIONS

The following functions are available:

MMDB_open()
Opens a MaxMind DB database file.
MMDB_close()
Closes a MaxMind DB database file.
MMDB_lookup_string()
Looks up an IP address in the database.
MMDB_get_entry_data_list()
Retrieves the data associated with a found entry as a linked list.
MMDB_dump_entry_data_list()
Dumps the contents of an entry data list to a file.
MMDB_read_node()
Reads a specific node in the search tree.
MMDB_lib_version()
Returns the library version.
MMDB_strerror()
Returns a string representation of a status code.

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
