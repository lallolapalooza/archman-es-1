DESCRIPCIÓN

La librería libmaxminddb proporciona funciones para trabajar con archivos MaxMind DB. Consulte https://maxmind.github.io/MaxMind-DB/ para la especificación del formato de MaxMind DB. Las bases de datos y los resultados se representan mediante estructuras diferentes. Las bases de datos se abren llamando a MMDB_open(). Puede buscar direcciones IP como strings con MMDB_lookup_string() o como punteros a estructuras sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esta estructura indica que la base de datos tiene datos para la dirección IP, hay varias funciones que pueden usarse para obtener ese dato. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Consulte la documentación de las funciones por más detalles.

Cuando hayas terminado con el manejador de la base de datos, debes llamar a MMDB_close().

Todas las funciones públicas, estructuras y macros empiezan con MMDB_.

ESTRUCTURAS DE DATOS

Todas las estructuras exportadas por el encabezado maxminddb.h de esta librería se definen como typedefs en la forma typedef struct foo_s { ... } foo_s, por lo que puedes referirte a ellas sin el prefijo struct.

Esta librería proporciona las siguientes estructuras:

MMDB_s

Esta es la handle de un archivo MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados a uso público. Todos los demás campos son sujetos a cambio y son destinados solo para uso interno.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - los flags con los que esta base de datos fue abierta. Consulte la documentación de MMDB_open() para más detalles.
  • const char *filename - el nombre del archivo que se abrió, como fue pasado a MMDB_open().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura puede obtenerse desde la estructura MMDB_s. Contiene los metadatos leídos desde el archivo de base de datos. Nota que puede ser más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list().

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deben ser bastante autonómicas.

El miembro ip_version debe siempre ser 4 o 6. El miembro binary_format_major_version debe siempre ser 2.

No hay requisito que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que el count de estos elementos de metadatos puede ser cero. Todos los demás miembros de MMDB_metadata_s deben estar poblados.

MMDB_lookup_result_s

Esta estructura se devuelve como resultado de la búsqueda de una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, los demás miembros de esta estructura no contienen valores significativos. Siempre verifica que found_entry sea verdadero primero.

El miembro entry se usa para buscar los datos asociados con la dirección IP.

El miembro netmask indica qué red de subred pertenece a esta base de datos. Por ejemplo, si buscas la dirección 1.1.1.1 en una base de datos IPv4 y el valor devuelto es 16, entonces la dirección pertenece a la red 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, el valor devuelto de netmask siempre es una longitud de prefijo IPv6 (de 0 a 128), incluso si esa base de datos también contiene redes IPv4. Si buscas una dirección IPv4 y deseas convertir el netmask en un valor de máscara de red IPv4, simplemente resta 96 del valor.

MMDB_result_s

No necesitas profundizar en esta estructura. La obtendrás de una estructura MMDB_lookup_result_s y pasarás esta a diversas funciones.

MMDB_entry_data_s

Esta estructura se utiliza para devolver un único segmento de datos para una dirección IP. Estos segmentos pueden apuntar a otros segmentos, como en el caso de mapas y arrays. Algunos miembros de esta estructura no están documentados debido a que son únicamente para uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontró datos para una búsqueda específica. Consulte MMDB_get_value() para más detalles. Si este miembro es falso, ningún valor en la estructura es significativo.

La unión al inicio de la estructura define los datos reales. Para determinar qué miembro de la unión se está usando, se debe ver el valor de type.

MMDB_entry_data_list_s

Esta estructura se utiliza para devolver un único segmento de datos para una dirección IP. Estos segmentos pueden apuntar a otros segmentos, como en el caso de mapas y arrays. Algunos miembros de esta estructura no están documentados debido a que son únicamente para uso interno.

DATA STRUCTURES

This library returns data in a number of structures. See the maxminddb.h header file for the full definitions.

MMDB_entry_s

This structure contains information about a database entry. It contains a pointer to a null-terminated string specifying the key and a pointer to the data associated with that key.

typedef struct MMDB_entry_s {
    MMDB_entry_data_s data;
    const char *key;
} MMDB_entry_s;

Note that the key member may be NULL if the entry is not a map entry.

MMDB_entry_data_s

This structure contains the actual data for a database entry. It is a union of all possible data types.

typedef struct MMDB_entry_data_s {
    int type;
    union {
        uint8_t *bytes;
        char *utf8_string;
        uint16_t uint16;
        uint32_t uint32;
        uint64_t uint64;
        uint128_t uint128;
        int32_t int32;
        float a_float;
        double a_double;
        int boolean;
        MMDB_entry_data_list_s *list;
        MMDB_entry_data_s *map;
    } data;
    size_t data_size;
    void *pointer;
} MMDB_entry_data_s;

The type member can be compared to one of the MMDB_DATA_TYPE_* macros.

The pointer member of the union should never be populated in any data returned by the API. Pointers should always be resolved internally.

The data_size member is only relevant for utf8_string and bytes data. utf8_string is not null terminated and data_size must be used to determine its length.

The type member can be compared to one of the MMDB_DATA_TYPE_* macros.

128-bit Integers

The handling of uint128 data depends on how your platform supports 128-bit integers, if it does so at all. With GCC 4.4 and 4.5 we can write unsigned int __attribute__ ((__mode__ (TI))). With newer versions of GCC (4.6+) and clang (3.2+) we can simply write "unsigned __int128".

In order to work around these differences, this library defines an mmdb_uint128_t type. This type is defined in the maxminddb.h header so you can use it in your own code.

With older compilers, we can't use an integer so we instead use a 16 byte array of uint8_t values. This is the raw data from the database.

This library provides a public macro MMDB_UINT128_IS_BYTE_ARRAY macro. If this is true (1), then uint128 values are returned as a byte array, if it is false then they are returned as a mmdb_uint128_t integer.

Data Type Macros

This library provides a macro for every data type defined by the MaxMind DB spec.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

There are also a few types that are for internal use only:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

If you see one of these in returned data then something has gone very wrong. The database is damaged or was generated incorrectly or there is a bug in the libmaxminddb code.

Pointer Values and MMDB_close()

The utf8_string, bytes, and (maybe) the uint128 members of this structure are all pointers directly into the database's data section. This can either be a calloc'd or mmap'd block of memory. In either case, these pointers will become invalid after MMDB_close() is called.

If you need to refer to this data after that time you should copy the data with an appropriate function (strdup, memcpy, etc.).

MMDB_entry_data_list_s

This structure encapsulates a linked list of MMDB_entry_data_s structures.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

This structure lets you look at entire map or array data entry by iterating over the linked list.

MMDB_search_node_s

This structure encapsulates the two records in a search node. This is really only useful if you want to write code that iterates over the entire search tree as opposed to looking up a specific IP address.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

The two record types will take one of the following values:

  • MMDB_RECORD_TYPE_SEARCH_NODE - The record points to the next search node.
  • MMDB_RECORD_TYPE_EMPTY - The record is a placeholder that indicates there is no data for the IP address. The search should end here.
  • MMDB_RECORD_TYPE_DATA - The record is for data in the data section of the database. Use the entry for the record when looking up the data for the record.
  • MMDB_RECORD_TYPE_INVALID - The record is invalid. Either an invalid node was looked up or the database is corrupt.

The MMDB_entry_s for the record is only valid if the type is MMDB_RECORD_TYPE_DATA. Attempts to use an entry for other record types will result in an error or invalid data.

STATUS CODES

This library returns (or populates) status codes for many functions. These status codes are:

  • MMDB_SUCCESS - everything worked
  • MMDB_FILE_OPEN_ERROR - there was an error trying to open the MaxMind DB file.
  • MMDB_IO_ERROR - an IO operation failed. Check errno for more details.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - looking up an IP address in the search tree gave us an impossible result. The database is damaged or was generated incorrectly or there is a bug in the libmaxminddb code.
  • MMDB_INVALID_METADATA_ERROR - something in the database is wrong. This includes missing metadata keys as well as impossible values (like an ip_version of 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - The database metadata indicates that it's major version is not 2. This library can only handle major version 2.
  • MMDB_OUT_OF_MEMORY_ERROR - a memory allocation call (malloc, etc.) failed.
  • MMDB_INVALID_DATA_ERROR - an entry in the data section contains invalid data. For example, a uint16 field is claiming to be more than 2 bytes long. The database is probably damaged or was generated incorrectly.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - The lookup path passed to MMDB_get_value, MMDB_vget_value, or MMDB_aget_value contains an array offset that is larger than LONGMAX or smaller than LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - The lookup path passed to MMDB_get_value,MMDB_vget_value, or MMDB_aget_value does not match the data structure for the entry. There are number of reasons this can happen. The lookup path could include a key not in a map. The lookup path could include an array index larger than an array or smaller than the minimum offset from the end of an array. It can also happen when the path expects to find a map or array where none exist.

All status codes should be treated as int values.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

This function takes a status code and returns an English string explaining the status.

FUNCTIONS

This library provides the following exported functions:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

This function opens a handle to a MaxMind DB file. Its return value is a status code as defined above. Always check this call's return value.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename must be encoded as UTF-8 on Windows.

The MMDB_s structure you pass in can be on the stack or allocated from the heap. However, if the open is successful it will contain heap-allocated data, so you need to close it with MMDB_close(). If the status returned is not MMDB_SUCCESS then this library makes sure that all allocated memory is freed before returning.

The flags currently provided are:

•
MMDB_MODE_MMAP - open the database with mmap().

Passing in other values for flags may yield unpredictable results. In the future we may add additional flags that you can bitwise-or together with the mode, as well as additional modes.

You can also pass 0 as the flags value in which case the database will be opened with the default flags. However, these defaults may change in future releases. The current default is MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

This frees any allocated or mmap'd memory that is held from the MMDB_s structure. It does not free the memory pointed to by the MMDB_entry_data_s members. See Pointer Values and MMDB_close().

MMDB_get_value()

int MMDB_get_value(
    MMDB_s *const mmdb,
    const char *const key,
    MMDB_entry_data_s *const entry_data);

This function looks up a value in the MaxMind DB database by key. It returns MMDB_SUCCESS on success or one of the error codes above. The data for the value is populated into the entry_data structure.

Note that the key must be a valid UTF-8 string.

The entry_data structure will contain pointers into the database's memory space. If you need to keep this data after calling MMDB_close(), you will need to copy the data using strdup(), memcpy(), or similar.

MMDB_vget_value()

int MMDB_vget_value(
    MMDB_s *const mmdb,
    MMDB_lookup_path_s *const path,
    MMDB_entry_data_s *const entry_data);

This function looks up a value in the MaxMind DB database by a lookup path. It returns MMDB_SUCCESS on success or one of the error codes above. The data for the value is populated into the entry_data structure.

See the MMDB_lookup_path_s structure for more information on lookup paths.

The entry_data structure will contain pointers into the database's memory space. If you need to keep this data after calling MMDB_close(), you will need to copy the data using strdup(), memcpy(), or similar.

MMDB_aget_value()

int MMDB_aget_value(
    MMDB_s *const mmdb,
    MMDB_lookup_path_s *const path,
    MMDB_entry_data_s *const entry_data);

This function is similar to MMDB_vget_value(), but it takes a variable argument list instead of a MMDB_lookup_path_s structure.

The variable argument list should consist of NULL-terminated arguments of type char * (for map keys) and int (for array indices). See the example below.

int status = MMDB_aget_value(
    &mmdb,
    "country", "names", "en",
    NULL,
    &entry_data);

The entry_data structure will contain pointers into the database's memory space. If you need to keep this data after calling MMDB_close(), you will need to copy the data using strdup(), memcpy(), or similar.

MMDB_lookup_path_new()

MMDB_lookup_path_s *MMDB_lookup_path_new(void);

This function creates and returns a new, empty lookup path. The caller is responsible for freeing the returned pointer using MMDB_lookup_path_free().

MMDB_lookup_path_free()

void MMDB_lookup_path_free(MMDB_lookup_path_s *path);

This function frees a lookup path created with MMDB_lookup_path_new().

MMDB_lookup_path_append_key()

int MMDB_lookup_path_append_key(
    MMDB_lookup_path_s *const path,
    const char *const key);

This function appends a map key to the lookup path. It returns MMDB_SUCCESS on success or MMDB_OUT_OF_MEMORY_ERROR if memory could not be allocated.

The key must be a valid UTF-8 string.

MMDB_lookup_path_append_uint32()

int MMDB_lookup_path_append_uint32(
    MMDB_lookup_path_s *const path,
    uint32_t index);

This function appends an array index to the lookup path. It returns MMDB_SUCCESS on success or MMDB_OUT_OF_MEMORY_ERROR if memory could not be allocated.

MMDB_free_entry_data()

void MMDB_free_entry_data(MMDB_entry_data_s *data);

This function frees any memory that was allocated for the given MMDB_entry_data_s structure. This is necessary for data types that are not simple integers or booleans (e.g. strings, byte arrays, lists, maps).

This function is automatically called by MMDB_close() if the database was opened with MMDB_MODE_FREE_CONTENTS flag.

MMDB_lib_version()

const char *MMDB_lib_version(void);

This function returns the version of the library.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Esta función busca una dirección IP que se pasa como una cadena terminada en nulo. Internamente, llama a getaddrinfo() para resolver la dirección a una forma binaria. Luego llama a MMDB_lookup_sockaddr() para buscar la dirección en la base de datos. Si ya ha resuelto una dirección, puede llamar directamente a MMDB_lookup_sockaddr(), en lugar de resolver la dirección dos veces.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Esta función siempre devuelve una estructura MMDB_lookup_result_s, pero también debe comprobar los parámetros gai_error y mmdb_error. Si alguno de ellos indica un error, la estructura devuelta no tiene sentido.

Si no se produjo ningún error, aún debe asegurarse de que el miembro found_entry en el resultado devuelto sea verdadero. Si no lo es, significa que la dirección IP no tiene una entrada en la base de datos.

Esta función funcionará con direcciones IPv4 incluso cuando la base de datos contenga datos tanto para direcciones IPv4 como IPv6. La dirección IPv4 se buscará como '::xxx.xxx.xxx.xxx' en lugar de ser reasignada al bloque ::ffff:xxx.xxx.xxx.xxx asignado para direcciones IPv6 mapeadas de IPv4.

Si pasa una dirección IPv6 a una base de datos con solo datos IPv4, el miembro found_entry será falso, pero el estado mmdb_error seguirá siendo MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Esta función busca una dirección IP que ya ha sido resuelta por getaddrinfo().

Aparte de no llamar a getaddrinfo() en sí, esta función es idéntica a la función MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Funciones de búsqueda de datos

Hay tres funciones para buscar datos asociados con una dirección IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Las tres funciones permiten tres estilos de llamada ligeramente diferentes, pero todas hacen lo mismo.

El primer parámetro es un valor MMDB_entry_s. En la mayoría de los casos, provendrá del valor MMDB_lookup_result_s devuelto por MMDB_lookup_string() o MMDB_lookup_sockaddr().

El segundo parámetro es una referencia a una estructura MMDB_entry_data_s. Esta se poblará con los datos que se buscan, si se encuentra alguno. Si no se encuentra nada, el miembro has_data de esta estructura será falso. Si has_data es verdadero, puede consultar el miembro data_type.

El último parámetro es una ruta de búsqueda. La ruta consta de un conjunto de cadenas que representan claves de mapa (por ejemplo, "city") o índices de matriz (por ejemplo, "0", "1", "-1") para usar en la búsqueda.

Los índices de matriz negativos se tratarán como un desplazamiento desde el final de la matriz. Por ejemplo, "-1" se refiere al último elemento de la matriz.

La ruta de búsqueda le permite navegar por una estructura de datos compleja. Por ejemplo, dados estos datos:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Podríamos buscar el nombre en inglés con este código:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si quisiéramos encontrar la primera ciudad, la ruta de búsqueda sería "cities", "0". Si no proporciona ninguna ruta de búsqueda, obtendrá la entrada que corresponde al mapa de nivel superior. La ruta de búsqueda siempre debe terminar en NULL, independientemente de la función que llame.

La función MMDB_get_value toma un número variable de argumentos. Todos los argumentos después del puntero a la estructura MMDB_entry_data_s * son la ruta de búsqueda. El último argumento debe ser NULL.

La función MMDB_vget_value acepta un va_list como ruta de búsqueda. El último elemento recuperado por va_arg() debe ser NULL.

Finalmente, MMDB_aget_value acepta una matriz de cadenas como ruta de búsqueda. El último miembro de esta matriz debe ser NULL.

Si desea obtener todos los datos de la entrada a la vez, puede llamar a MMDB_get_entry_data_list() en su lugar.

Para cada una de las tres funciones, el valor de retorno es un código de estado según se define anteriormente.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función le permite obtener todos los datos de una estructura de datos compleja a la vez, en lugar de buscar cada pieza mediante llamadas repetidas a MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// guardar esto para poder liberar estos datos más tarde
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Depende de usted interpretar la estructura de datos entry_data_list. La lista está enlazada en una traversa de profundidad. Usemos esta estructura como ejemplo:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La lista constará de los siguientes elementos:

1.
MAP - mapa de nivel superior
2.
UTF8_STRING - clave "names"
3.
MAP - mapa para la clave "names"
4.
UTF8_STRING - clave "en"
5.
UTF8_STRING - valor para la clave "en"
6.
UTF8_STRING - clave "de"
7.
UTF8_STRING - valor para la clave "de"
8.
UTF8_STRING - clave "cities"
9.
ARRAY - valor para la clave "cities"
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

El valor de retorno de la función es un código de estado según se define anteriormente.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

Las funciones MMDB_get_entry_data_list() y MMDB_get_metadata_as_entry_data_list() asignarán la estructura de lista enlazada desde el heap. Llame a esta función para liberar la estructura MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función le permite recuperar los metadatos de la base de datos como una lista enlazada de estructuras MMDB_entry_data_list_s. Esta puede ser una forma más conveniente de tratar los metadatos que usar la estructura de metadatos directamente.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // hacer algo con los datos
    MMDB_free_entry_data_list(first);

El valor de retorno de la función es un código de estado según se define anteriormente.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Esta función toma una lista enlazada de estructuras MMDB_entry_data_list_s y la convierte en una cadena para el stream dado. El parámetro indent es el nivel de sangría inicial para la salida generada. Se incrementa para estructuras de datos anidadas (mapas, matrices, etc.).

El stream debe ser un manejador de archivos ( stdout, etc.). Si su plataforma proporciona algo como open_memstream() de GNU, puede usarlo para capturar la salida como una cadena.

La salida está formateada de manera similar a JSON, pero los valores están marcados con su tipo de datos (excepto para mapas y matrices que se muestran con "& {}&" y "& []&" respectivamente).

El formato de salida específico puede cambiar en futuras versiones.

NAME

MMDB_lookup_sockaddr.3

SYNOPSIS

int MMDB_lookup_sockaddr(const MMDB_s *const mmdb,
                           const struct sockaddr *const addr,
                           MMDB_lookup_result_s *const result);

DESCRIPTION

This function looks up an IP address in the MaxMind data file. The second argument is a pointer to a struct sockaddr object containing the address to look up. The third argument is a pointer to a MMDB_lookup_result_s object that will contain the result of the lookup.

DATA STRUCTURES

The MMDB_lookup_result_s object contains the following data:

  • result_type: lookup result type
  • result_value: lookup result value
  • result_error: lookup result error

STATUS CODES

The return value of the function is a status code as defined above.

FUNCTIONS

int MMDB_lookup_sockaddr(
    const MMDB_s *const mmdb,
    const struct sockaddr *const addr,
    MMDB_lookup_result_s *const result);

This function looks up an IP address in the MaxMind data file. The second argument is a pointer to a struct sockaddr object containing the address to look up. The third argument is a pointer to a MMDB_lookup_result_s object that will contain the result of the lookup.

The return value is a status code. If an invalid addr is passed, the function will return MMDB_INVALID_ADDR_ERROR. If the addr is valid, the function will return MMDB_SUCCESS.

The first address in the lookup tree is always 0. If you wish to iterate over the entire lookup tree, you must begin by reading address 0 and then follow the entries that make up this address, according to the type of each entry. If the type is MMDB_RECORD_TYPE_IPV4_ADDR, the entry contains an integer for the next address to look up.

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
