DESCRIPCIÓN

La librería libmaxminddb proporciona funciones para trabajar con archivos MaxMind DB. Ver https://maxmind.github.io/MaxMind-DB/ para la especificación del formato MaxMind DB. Las bases de datos y los resultados están representados por diferentes estructuras de datos. Las bases de datos se abren llamando a MMDB_open(). Puedes buscar direcciones IP como una cadena de texto con MMDB_lookup_string() o como un puntero a una estructura sockaddr con MMDB_lookup_sockaddr().

Si la búsqueda encuentra la dirección IP en la base de datos, devuelve una estructura MMDB_lookup_result_s. Si esa estructura indica que la base de datos tiene datos para la IP, hay una serie de funciones que se pueden usar para obtener esos datos. Estas incluyen MMDB_get_value() y MMDB_get_entry_data_list(). Ver la documentación de las funciones más abajo para más detalles.

Cuando hayas terminado con el manejador de la base de datos, deberías llamar a MMDB_close().

Todas las funciones, estructuras y macros visibles públicamente comienzan con "MMDB_".

ESTRUCTURAS DE DATOS

Todas las estructuras de datos exportadas por la cabecera maxminddb.h de esta librería están definidas con el formato typedef struct foo_s { ... } foo_s para que puedas referirte a ellas sin el prefijo struct.

Esta librería proporciona las siguientes estructuras de datos:

MMDB_s

Este es el manejador para un archivo MaxMind DB. Solo documentamos algunos de los campos de esta estructura destinados a uso público. Todos los demás campos están sujetos a cambios y están destinados únicamente a uso interno.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - las banderas con las que se abrió esta base de datos. Ver la documentación de MMDB_open() para más detalles.
  • const char *filename - el nombre del archivo que se abrió, tal como se pasó a MMDB_open().
  • MMDB_metadata_s metadata - los metadatos de la base de datos.

MMDB_metadata_s y MMDB_description_s

Esta estructura se puede recuperar de la estructura MMDB_s. Contiene los metadatos leídos del archivo de la base de datos. Ten en cuenta que podrías encontrar más conveniente acceder a estos metadatos llamando a MMDB_get_metadata_as_entry_data_list() en su lugar.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Estas estructuras deberían ser mayormente autoexplicativas.

El miembro ip_version siempre debería ser 4 o 6. El binary_format_major_version siempre debería ser 2.

No hay requisito de que los metadatos de la base de datos incluyan idiomas o descripciones, por lo que el count para estas partes de los metadatos puede ser cero. Todos los demás campos de MMDB_metadata_s deberían estar poblados.

MMDB_lookup_result_s

Esta estructura se devuelve como resultado de buscar una dirección IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si el miembro found_entry es falso, entonces los otros miembros de esta estructura no contienen valores significativos. Siempre verifica primero que found_entry sea verdadero.

El miembro entry se utiliza para buscar los datos asociados con la dirección IP.

El miembro netmask te dice a qué subred pertenece la dirección IP en esta base de datos. Por ejemplo, si buscas la dirección 1.1.1.1 en una base de datos IPv4 y la netmask devuelta es 16, entonces la dirección es parte de la subred 1.1.0.0/16.

Si la base de datos es una base de datos IPv6, la máscara de red devuelta es siempre una longitud de prefijo IPv6 (de 0-128), incluso si esa base de datos *también* contiene redes IPv4. Si buscas una dirección IPv4 y deseas convertir la máscara de red en un valor de máscara de red IPv4, simplemente puedes restar 96 del valor.

MMDB_result_s

Realmente no necesitas indagar en esta estructura. La obtendrás de una estructura MMDB_lookup_result_s y la pasarás a varias funciones.

MMDB_entry_data_s

Esta estructura se utiliza para devolver una única entrada de sección de datos para una IP. Estas entradas, a su vez, pueden apuntar a otras entradas, como es el caso de cosas como mapas y arreglos. Algunos miembros de esta estructura no están documentados ya que son solo para uso interno.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

El miembro has_data es verdadero si se encontraron datos para una búsqueda dada. Ver MMDB_get_value() para más detalles. Si este miembro es falso, entonces ninguno de los otros valores en la estructura son significativos.

ESTRUCTURAS_DE_DATOS

La información del MaxMind DB se devuelve en un par de estructuras. La estructura principal es MMDB_entry_data_s:

typedef struct MMDB_entry_data_s {
    uint8_t type;
    union {
        uint8_t *bytes;
        char *utf8_string;
        uint16_t uint16;
        uint32_t uint32;
        uint64_t uint64;
        uint32_t double_val;  /* represented as uint32_t */
        uint32_t float_val;  /* represented as uint32_t */
        void *pointer;
        uint8_t uint128[16];
        struct {
            uint32_t count;
            MMDB_entry_s *entries;
        } map;
        struct {
            uint32_t count;
            MMDB_entry_s *entries;
        } array;
        bool boolean;
    } data;
    uint32_t data_size;
} MMDB_entry_data_s;

En la mayoría de los casos, esta estructura contiene todos los datos que necesita. Si necesita acceder a un valor, puede inspeccionar el miembro type y luego acceder a la unión data en consecuencia.

Si type es MMDB_DATA_TYPE_POINTER, entonces el miembro pointer de la unión contendrá un desplazamiento relativo al inicio del bloque de memoria del archivo MaxMind DB. En otras palabras, obtendrá un puntero a los datos en el archivo. Sin embargo, los punteros de tipo pointer están destinados a ser resueltos internamente por el código de la biblioteca. Nunca debe intentar resolver un puntero usted mismo. Si el puntero no está poblado, mire el miembro type. El miembro pointer de la unión nunca debe ser poblado en ningún dato devuelto por la API. Los punteros siempre deben resolverse internamente.

El miembro data_size solo es relevante para los datos utf8_string y bytes. utf8_string no termina en nulo y data_size *debe* usarse para determinar su longitud.

El miembro type se puede comparar con una de las macros MMDB_DATA_TYPE_*.

Enteros_de_128_bits

El manejo de datos uint128 depende de cómo su plataforma admite enteros de 128 bits, si es que lo hace. Con GCC 4.4 y 4.5 podemos escribir unsigned int __attribute__ ((__mode__ (TI))). Con versiones más nuevas de GCC (4.6+) y clang (3.2+) podemos simplemente escribir "unsigned __int128".

Para solucionar estas diferencias, esta biblioteca define un tipo mmdb_uint128_t. Este tipo se define en el encabezado maxminddb.h para que pueda usarlo en su propio código.

Con compiladores más antiguos, no podemos usar un entero, sino que utilizamos una matriz de 16 bytes de valores uint8_t. Estos son los datos brutos de la base de datos.

Esta biblioteca proporciona una macro pública MMDB_UINT128_IS_BYTE_ARRAY. Si esto es verdadero (1), entonces los valores uint128 se devuelven como una matriz de bytes, si es falso, se devuelven como un entero mmdb_uint128_t.

Macros_de_Tipo_de_Dato

Esta biblioteca proporciona una macro para cada tipo de dato definido por la especificación MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

También hay algunos tipos que son solo para uso interno:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si ve alguno de estos en los datos devueltos, algo salió muy mal. La base de datos está dañada o se generó incorrectamente, o hay un error en el código de libmaxminddb.

Valores_de_Puntero_y_MMDB_close()

Los miembros utf8_string, bytes y (quizás) uint128 de esta estructura son punteros directos a la sección de datos de la base de datos. Este puede ser un bloque de memoria asignado con calloc o mmap. En cualquier caso, estos punteros se volverán inválidos después de que se llame a MMDB_close().

Si necesita hacer referencia a estos datos después de ese momento, debe copiar los datos con una función apropiada (strdup, memcpy, etc.).

MMDB_entry_data_list_s

Esta estructura encapsula una lista enlazada de estructuras MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Esta estructura le permite ver todos los datos de un mapa o arreglo iterando sobre la lista enlazada.

MMDB_search_node_s

Esta estructura encapsula los dos registros en un nodo de búsqueda. Esto es realmente útil solo si desea escribir código que itere sobre todo el árbol de búsqueda en lugar de buscar una dirección IP específica.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Los dos tipos de registro tomarán uno de los siguientes valores:

  • MMDB_RECORD_TYPE_SEARCH_NODE - El registro apunta al siguiente nodo de búsqueda.
  • MMDB_RECORD_TYPE_EMPTY - El registro es un marcador de posición que indica que no hay datos para la dirección IP. La búsqueda debería terminar aquí.
  • MMDB_RECORD_TYPE_DATA - El registro es para datos en la sección de datos de la base de datos. Use la entrada para el registro al buscar los datos del registro.
  • MMDB_RECORD_TYPE_INVALID - El registro no es válido. Se buscó un nodo inválido o la base de datos está corrupta.

La MMDB_entry_s para el registro solo es válida si el tipo es MMDB_RECORD_TYPE_DATA. Intentar usar una entrada para otros tipos de registro resultará en un error o datos inválidos.

CÓDIGOS_DE_ESTADO

Esta biblioteca devuelve (o popula) códigos de estado para muchas funciones. Estos códigos de estado son:

  • MMDB_SUCCESS - todo funcionó
  • MMDB_FILE_OPEN_ERROR - hubo un error al intentar abrir el archivo MaxMind DB.
  • MMDB_IO_ERROR - una operación de E/S falló. Consulte errno para más detalles.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - buscar una dirección IP en el árbol de búsqueda nos dio un resultado imposible. La base de datos está dañada o se generó incorrectamente, o hay un error en el código de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - algo en la base de datos está mal. Esto incluye claves de metadatos faltantes, así como valores imposibles (como una ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - Los metadatos de la base de datos indican que su versión principal no es 2. Esta biblioteca solo puede manejar la versión principal 2.
  • MMDB_OUT_OF_MEMORY_ERROR - una llamada de asignación de memoria (malloc, etc.) falló.
  • MMDB_INVALID_DATA_ERROR - una entrada en la sección de datos contiene datos inválidos. Por ejemplo, un campo uint16 afirma tener más de 2 bytes de largo. La base de datos probablemente está dañada o se generó incorrectamente.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - La ruta de búsqueda pasada a MMDB_get_value, MMDB_vget_value o MMDB_aget_value contiene un índice de arreglo que es mayor que LONGMAX o menor que LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - La ruta de búsqueda pasada a MMDB_get_value, MMDB_vget_value o MMDB_aget_value no coincide con la estructura de datos de la entrada. Hay varias razones por las que esto puede suceder. La ruta de búsqueda podría incluir una clave que no está en un mapa. La ruta de búsqueda podría incluir un índice de arreglo mayor que un arreglo o menor que el desplazamiento mínimo desde el final de un arreglo. También puede suceder cuando la ruta espera encontrar un mapa o un arreglo donde no existe ninguno.

Todos los códigos de estado deben tratarse como valores int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Esta función toma un código de estado y devuelve una cadena en inglés que explica el estado.

FUNCIONES

Esta biblioteca proporciona las siguientes funciones exportadas:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Esta función abre un manejador para un archivo MaxMind DB. Su valor de retorno es un código de estado como se define anteriormente. Siempre verifique el valor de retorno de esta llamada.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename debe estar codificado como UTF-8 en Windows.

La estructura MMDB_s que pasa puede estar en la pila o asignada desde el montículo. Sin embargo, si la apertura es exitosa, contendrá datos asignados desde el montículo, por lo que debe cerrarla con MMDB_close(). Si el estado devuelto no es MMDB_SUCCESS, esta biblioteca se asegura de que toda la memoria asignada se libere antes de devolver.

Las banderas actualmente proporcionadas son:

•
MMDB_MODE_MMAP - abre la base de datos con mmap().

Pasar otros valores para flags puede producir resultados impredecibles. En el futuro, podemos agregar banderas adicionales que puede combinar con un OR bit a bit con el modo, así como modos adicionales.

También puede pasar 0 como valor de flags, en cuyo caso la base de datos se abrirá con las banderas predeterminadas. Sin embargo, estos valores predeterminados pueden cambiar en futuras versiones. El valor predeterminado actual es MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Esto libera cualquier memoria asignada o mapeada que se mantenga desde la estructura MMDB_s. *No libera la memoria allo

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Esta función busca una dirección IP que se pasa como una cadena terminada en nulo. Internamente, llama a getaddrinfo() para resolver la dirección en forma binaria. Luego llama a MMDB_lookup_sockaddr() para buscar la dirección en la base de datos. Si ya has resuelto una dirección, puedes llamar directamente a MMDB_lookup_sockaddr() sin tener que resolver la dirección dos veces.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Esta función siempre devuelve una estructura MMDB_lookup_result_s, pero también debes verificar los parámetros gai_error y mmdb_error. Si alguno indica un error, la estructura devuelta será inútil.

Si no ha ocurrido ningún error, aún debes asegurarte de que el miembro found_entry en la estructura devuelta sea verdadero. Si no lo es, esto significa que la dirección IP no tiene registro en la base de datos.

Esta función funciona con direcciones IPv4 incluso cuando la base de datos contiene datos tanto para IPv4 como para IPv6. La dirección IPv4 se buscará como '::xxx.xxx.xxx.xxx' en lugar de ser remapeada al bloqueo ::ffff:xxx.xxx.xxx.xxx asignado para direcciones IPv6 mapeadas a IPv4.

Si pasas una dirección IPv6 a una base de datos que solo contiene datos IPv4, el miembro found_entry será falso, pero el estado mmdb_error seguirá siendo MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Esta función busca una dirección IP que ya ha sido resuelta mediante getaddrinfo().

A menos que no llames a getaddrinfo() por sí misma, esta función es idéntica a la función MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Funciones de Búsqueda de Datos

Existen tres funciones para buscar datos asociados a una dirección IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Las tres funciones permiten tres estilos de llamada ligeramente diferentes, pero todas realizan la misma tarea.

El primer parámetro es un valor MMDB_entry_s. En la mayoría de los casos, este valor provendrá de la estructura MMDB_lookup_result_s devuelta por MMDB_lookup_string() o MMDB_lookup_sockaddr().

El segundo parámetro es una referencia a una estructura MMDB_entry_data_s. Esta estructura se llenará con los datos que se están buscando, si se encuentra algún dato. Si no se encuentra ningún dato, el miembro has_data de esta estructura será falso. Si has_data es verdadero, puedes examinar el miembro data_type.

El último parámetro es un camino de búsqueda. El camino consiste en una serie de strings que representan claves de mapa (por ejemplo, "city") o índices de array (por ejemplo, "0", "1", "-1") para usar en la búsqueda.

Los índices negativos en el array se tratan como un desplazamiento desde el final del array. Por ejemplo, "-1" se refiere al último elemento del array.

El camino de búsqueda permite navegar una estructura compleja. Por ejemplo, dada esta data:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Podrías buscar el nombre en inglés con este código:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si deseas encontrar la primera ciudad, el camino de búsqueda sería "cities", "0". Si no proporcionas un camino de búsqueda, obtendrás el registro que corresponde al nivel superior del mapa. El camino de búsqueda debe siempre terminar con NULL, independientemente de qué función uses.

La función MMDB_get_value acepta un número variable de argumentos. Todos los argumentos después del puntero MMDB_entry_data_s * son el camino de búsqueda. El último argumento debe ser NULL.

La función MMDB_vget_value acepta un va_list como camino de búsqueda. El último elemento recuperado mediante va_arg() debe ser NULL.

Finalmente, la función MMDB_aget_value acepta un array de strings como camino de búsqueda. El último elemento del array debe ser NULL.

Si quieres obtener todos los datos de entrada al mismo tiempo, puedes llamar a MMDB_get_entry_data_list().

Para cada una de las tres funciones, el valor devuelto es un código de estado como se define anteriormente.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función te permite obtener todos los datos de una estructura compleja de una vez, en lugar de buscar cada parte mediante llamadas repetidas a MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// guardar esta estructura para poder liberarla más tarde
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

Es cuestión de interpretar la estructura entry_data_list. La lista está vinculada en una travesía en profundidad. Vamos a usar esta estructura como ejemplo:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

La lista consistirá en los siguientes elementos:

1.
MAP - mapa del nivel superior
2.
UTF8_STRING - clave "names"
3.
MAP - mapa de la clave "names"
4.
UTF8_STRING - clave "en"
5.
UTF8_STRING - valor de la clave "en"
6.
UTF8_STRING - clave "de"
7.
UTF8_STRING - valor de la clave "de"
8.
UTF8_STRING - clave "cities"
9.
ARRAY - valor de la clave "cities"
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

El valor devuelto de la función es un código de estado como se define anteriormente.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    MMDB_entry_data_list_s *const entry_data_list);

Las funciones MMDB_get_entry_data_list() y MMDB_get_metadata_as_entry_data_list() asignan la estructura vinculada a la heap. Llama esta función para liberar la estructura MMDB_entry_data_list_s.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(
    MMDB_s *const mmdb,
    MMDB_entry_data_list_s **const entry_data_list);

Esta función permite recuperar la metadata de la base de datos como una lista de estructuras MMDB_entry_data_list_s. Esto puede ser una forma más cómoda de manejar la metadata que usar la estructura de metadata directamente.

    MMDB_entry_data_list_s *entry_data_list, *first;
    int status =
        MMDB_get_metadata_as_entry_data_list(&mmdb, &entry_data_list);
    if (MMDB_SUCCESS != status) { ... }
    first = entry_data_list;
    ... // hacer algo con los datos
    MMDB_free_entry_data_list(first);

El valor devuelto de la función es un código de estado como se define anteriormente.

MMDB_dump_entry_data_list()

int MMDB_dump_entry_data_list(
    FILE *const stream,
    MMDB_entry_data_list_s *const entry_data_list,
    int indent);

Esta función toma una lista enlazada de estructuras MMDB_entry_data_list_s y la serializa en el flujo dado stream. El parámetro indent es el nivel de indentación inicial para la salida generada. Se incrementa para estructuras anidadas (mapas, arrays, etc.).

El stream debe ser un manejador de archivo (stdout, etc). Si tu plataforma ofrece algo como open_memstream() de GNU, puedes usarlo para capturar la salida como una cadena.

La salida está formateada de manera similar a JSON, pero los valores están marcados con su tipo de dato (excepto para mapas y arrays, que se muestran como "{}" y "[]" respectivamente).

El formato específico de la salida puede cambiar en futuras versiones.

NAME

MMDB_read_node()

SYNOPSIS

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

DESCRIPTION

Esta función lee un nodo específico en el árbol de búsqueda. El tercer argumento es una referencia a una estructura MMDB_search_node_s que será populada por esta función.

DATA STRUCTURES

La estructura MMDB_search_node_s contiene información sobre el nodo actual.

STATUS CODES

El valor de retorno es un código de estado como se define anteriormente.

FUNCTIONS

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

Esta función lee un nodo específico en el árbol de búsqueda. El tercer argumento es una referencia a una estructura MMDB_search_node_s que será populada por esta función.

El valor de retorno es un código de estado. Si se pasa un node_number mayor que el número de nodos en la base de datos, esta función devolverá MMDB_INVALID_NODE_NUMBER_ERROR, de lo contrario devolverá MMDB_SUCCESS.

El primer nodo en el árbol de búsqueda es siempre el nodo 0. Si deseabas iterar sobre todo el árbol de búsqueda, comenzarías por leer el nodo 0 y luego seguías las entradas que conforman este nodo, según el tipo de cada entrada. Si el tipo es MMDB_RECORD_TYPE_SEARCH_NODE, la entrada contiene un entero para el siguiente nodo a buscar.

MMDB_lib_version()

const char *MMDB_lib_version(void)

Esta función devuelve la versión del biblioteca como una cadena, algo así como "2.0.0".

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
