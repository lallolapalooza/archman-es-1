MPI_Group_range_incl(3) Open MPI MPI_Group_range_incl(3)

MPI_Group_range_incl — Crea un nuevo grupo a partir de rangos de rango en un grupo existente.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Group_range_incl(MPI_Group group, int n, int ranges[][3],
     MPI_Group *newgroup)

Sintaxis Fortran

USE MPI
! o el antiguo formato: INCLUDE 'mpif.h'
MPI_GROUP_RANGE_INCL(GROUP, N, RANGES, NEWGROUP, IERROR)
     INTEGER GROUP, N, RANGES(3,*), NEWGROUP, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Group_range_incl(group, n, ranges, newgroup, ierror)
     TYPE(MPI_Group), INTENT(IN) :: group
     INTEGER, INTENT(IN) :: n, ranges(3,n)
     TYPE(MPI_Group), INTENT(OUT) :: newgroup
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

  • group: Grupo (manejador).
  • n: Número de tripletas en el array ranges (entero).
  • ranges: Array unidimensional de tripletas de enteros, de la forma (primer rango, último rango, paso), indicando los rangos en el grupo o procesos a incluir en el nuevo grupo.

Parámetros de salida

  • newgroup: Nuevo grupo derivado de lo anterior, en el orden definido por ranges (manejador).
  • ierror: Solo Fortran: Código de error (entero).

Descripción

Si ranges consisten en los tripletas

(first1, last1, stride1), ..., (firstn, lastn, striden)

entonces newgroup consiste en la secuencia de procesos en el grupo con los rangos

                                               last(1)-first(1)
first(1), first(1) + stride(1),..., first(1) + ---------------- stride(1),...
                                                   stride(1)
                                               last(n)-first(n)
first(n), first(n) + stride(n),..., first(n) + ---------------- stride(n).
                                                   stride(n)

Cada rango calculado debe ser un rango válido en el grupo y todos los rangos calculados deben ser distintos, o de lo contrario el programa es erróneo. Nota: podemos tener first(i) > last(i) y stride(i) puede ser negativo, pero no puede ser cero.

La funcionalidad de esta rutina se especifica como equivalente a expandir el array de rangos a un array de rangos incluidos y pasar el array de rangos y otros argumentos a MPI_Group_incl. Una llamada a MPI_Group_incl es equivalente a una llamada a MPI_Group_range_incl con cada rango i en ranges reemplazado por el triplet (i, i, 1) en los argumentos ranges.

Nota

Esta implementación no verifica actualmente que los listados de rangos a incluir sean válidos en el grupo.

Errores

La mayoría de las rutinas MPI devuelven un valor de error; las rutinas C devuelven el resultado de la función y las rutinas Fortran en el último argumento.

Antes de que el valor de error sea devuelto, se llama a la manejador de error actual asociada al objeto de comunicación (por ejemplo, el comunicador, ventana, archivo) relacionado con el llamado MPI. Si no hay objeto de comunicación asociado con el llamado MPI, el llamado se considera vinculado a MPI_COMM_SELF y se llama a la manejador de error asociada a MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa el Modelo de Sesiones exclusivamente), el error invoca la manejador de error inicial. La manejador de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se usa el Modelo del Mundo, o el argumento mpi_initial_errhandler de CLI de mpiexec o la clave info del MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otra manejador de error adecuada establecida, se llama a la manejador MPI_ERRORS_RETURN para las funciones de E/S MPI y a la manejador MPI_ERRORS_ABORT para todas las otras funciones MPI.

Open MPI incluye tres manejadores de error predeterminados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL : El programa aborta todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT : Una manejador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene los procesos de la ventana o archivo correspondiente. Si se invoca en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN : Devuelve un código de error a la aplicación.

Los programas MPI también pueden implementar sus propias manejadores de error llamando:

  • MPI_Comm_create_errhandler y MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y MPI_File_set_errhandler
  • MPI_Session_create_errhandler y MPI_Session_set_errhandler o en el MPI_Session_init
  • MPI_Win_create_errhandler y MPI_Win_set_errhandler

Nota: MPI no garantiza que un programa MPI pueda continuar después de un error.

Ver la página del manual de MPI para una lista completa de códigos de error MPI.

Ver la sección de manejo de errores de la norma MPI-3.1 para más información.
