MPI_Intercomm_create_from_groups — Crea un inter-communicador a partir de un grupo local y remoto y una etiqueta de cadena

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Intercomm_create_from_groups(MPI_Group local_group, int local_leader, MPI_Group remote_group, int remote_leader, const char *stringtag, MPI_Info info, MPI_Errhandler errhandler, MPI_Comm *newintercomm)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_INTERCOMM_CREATE_FROM_GROUPS(LOCAL_GROUP, LOCAL_LEADER, REMOTE_GROUP, REMOTE_LEADER, STRINGTAG, INFO, ERRHANDLER, NEWINTERCOMM, IERROR)
    INTEGER LOCAL_GROUP, LOCAL_LEADER, REMOTE_GROUP, REMOTE_LEADER, INFO, ERRHANDLER, NEWINTERCOMM, IERROR
    CHARACTER(LEN=*), INTENT(IN) :: STRINGTAG

Sintaxis Fortran 2008

USE mpi_f08
MPI_Intercomm_create_from_groups(local_group, local_leader, remote_group, remote_leader, stringtag, info, errhandler, newintercomm, ierror)
    TYPE(MPI_Group), INTENT(IN) :: local_group, remote_group
    INTEGER, INTENT(IN) :: local_leader, remote_leader
    CHARACTER(LEN=*), INTENT(IN) :: stringtag
    TYPE(MPI_Info), INTENT(IN) :: info
    TYPE(MPI_Errhandler), INTENT(IN) :: errhandler
    TYPE(MPI_Comm), INTENT(OUT) :: newintercomm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

  • local_group : Grupo local (manejador)
  • local_leader : líder en el grupo local (entero)
  • remote_group : Grupo remoto (manejador)
remote_leader
líder en el grupo remoto, significativo solo en el líder local (entero)
  • stringtag : identificador único para esta operación (cadena)
  • info : objeto de información (manejador)
errhandler
manejador de errores que se adjunta al nuevo inter-communicador (manejador)

Parámetros de salida

  • newintercomm : nuevo inter-communicador (manejador).
  • ierror : solo Fortran: estado de error (entero).

Descripción

MPI_Intercomm_create_from_groups crea un inter-communicador. A diferencia de MPI_Intercomm_create, esta función usa grupos locales y remotos previamente definidos y desapartados. El proceso de llamada debe ser miembro del grupo local. La llamada es colectiva sobre la unión de los grupos locales y remotos. Todos los procesos involucrados deberán proporcionar un valor idéntico para el argumento stringtag. Dentro de cada grupo, todos los procesos deben proporcionar los argumentos local_group, local_leader idénticos. No se permiten comodines para los argumentos remote_leader o local_leader. El stringtag sirve el mismo propósito que el stringtag usado en la función MPI_Comm_create_from_group; distingue llamadas concurrentes en un entorno multihilo. El stringtag no debe exceder los 63 caracteres de MPI_MAX_STRINGTAG_LEN. Para C, incluye espacio para el carácter nulo. Si MPI_GROUP_EMPTY se proporciona como local_group o remote_group1 o ambos, entonces la llamada es local y se devuelve MPI_COMM_NULL como newintercomm.

Notas

El argumento errhandler especifica un manejador de errores que se adjunta al nuevo inter-communicador. El argumento info proporciona sugerencias y afirmaciones, posiblemente dependientes de la implementación de MPI, que indican características deseadas y guían la creación del comunicador. MPI_MAX_STRINGTAG_LEN debe tener un valor de al menos 63.

Errores

Más allá de los errores de MPI, las rutinas C devuelven el valor de error como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de error asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) actual. Si no hay un objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada con MPI_COMM_SELF y se llama al manejador de error asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa el modelo de Sesiones exclusivamente), el error desencadena el manejador inicial. El manejador inicial puede cambiarse llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo de Mundo, o al argumento mpi_initial_errhandler de mpiexec o a la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador adecuado, se llama al manejador MPI_ERRORS_RETURN para funciones de E/S MPI y al manejador MPI_ERRORS_ABORT para otras funciones MPI.

Open MPI incluye tres manejadores de error predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL : detiene todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT : manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera invocado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera invocado MPI_Abort en un comunicador que contiene los procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, detiene solo el proceso local.
  • MPI_ERRORS_RETURN : devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o al MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Nota: MPI no garantiza que un programa MPI pueda continuar después de un error.

Ver la página de documentación de MPI para una lista completa de códigos de error de MPI.

Ver la sección de manejo de errores del estándar MPI-3.1 para más información.
