MPI_Status_f2f08(3)

Paquete: openmpi

MPI_STATUS_F2F08(3) Open MPI MPI_STATUS_F2F08(3)

MPI_Status_f082f, MPI_Status_c2f08 - Traduce un estado Fortran 2008 a un estado estilo ENTERO de Fortran, o viceversa.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Status_f082f(const MPI_F08_status *f08_status, MPI_Fint *f_status)
int MPI_Status_f2f08(const MPI_Fint *f_status, MPI_F08_status *f08_status)

Sintaxis del Módulo mpi de Fortran

USE MPI
MPI_STATUS_F082F(F08_STATUS, F_STATUS, IERROR)
    TYPE(MPI_Status) :: F08_STATUS
    INTEGER :: STATUS(MPI_STATUS_SIZE), IERROR
MPI_STATUS_F2F08(F_STATUS, F08_STATUS, IERROR)
    INTEGER :: F_STATUS(MPI_STATUS_SIZE), IERROR
    TYPE(MPI_Status) :: F08_STATUS

Sintaxis del Módulo mpi_f08 de Fortran

USE mpi_f08
MPI_Status_f082f(f08_status, f_status, ierror)
    TYPE(MPI_Status), INTENT(IN) :: f08_status
    INTEGER, INTENT(OUT) :: f_status(MPI_STATUS_SIZE)
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Status_f2f08(f_status, f08_status, ierror)
    INTEGER, INTENT(IN) :: f_status(MPI_STATUS_SIZE)
    TYPE(MPI_Status), INTENT(OUT) :: f08_status
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS

  • f08_status : Objeto de estado MPI estilo mpi_f08
  • f_status : Objeto de estado MPI estilo ENTERO de mpi

DESCRIPCIÓN

Estos dos procedimientos se proporcionan para convertir de un estado Fortran 2008 (que es un tipo derivado compuesto por enteros) a un estado Fortran (que es un array de enteros), y viceversa. La conversión se aplica a toda la información del estado, incluida la que está oculta. Es decir, no se pierde información del estado en la conversión.

Al usar MPI_Status_f082f, si f08_status es un estado Fortran válido, pero no es el valor Fortran de MPI_F08_STATUS_IGNORE (en C), MPI_STATUS_IGNORE (en Fortran) o MPI_F08_STATUSES_IGNORE (en C) o MPI_STATUSES_IGNORE (en Fortran), entonces MPI_Status_f082f devuelve en f_status un array válido con el mismo contenido. Si f08_status es el valor C de MPI_F08_STATUS_IGNORE o MPI_F08_STATUSES_IGNORE o el valor Fortran de MPI_STATUS_IGNORE o MPI_STATUSES_IGNORE, o si f08_status no es un estado Fortran válido, entonces la llamada es errónea.

Al usar MPI_Status_f2f08, se aplica la conversión opuesta. Si f_status es MPI_STATUS_IGNORE o MPI_STATUSES_IGNORE, o si f_status no es un estado Fortran válido, entonces la llamada es errónea.

El estado de entrada tiene la misma fuente, etiqueta y códigos de error que el estado de salida, y devuelve las mismas respuestas cuando se consulta por el recuento, los elementos y la cancelación. La función de conversión puede ser llamada con un argumento de estado de entrada que tenga un campo de error indefinido, en cuyo caso el valor del campo de error en el argumento de estado de salida es indefinido.

NOTAS

Las subrutinas Fortran para estas rutinas MPI solo están disponibles en los módulos mpi y mpi_f08 (incluida la especificación de tipo para TYPE(MPI_Status); no están disponibles (intencionadamente) en mpif.h.
