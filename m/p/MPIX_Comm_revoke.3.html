MPIX_Comm_revoke(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPIX_COMM_REVOKE(3) Open MPI MPIX_COMM_REVOKE(3)

MPIX_Comm_revoke - Revoca un comunicador, provocando errores en todas las filas para operaciones no locales en el comunicador.

Esto es parte de la extensión ULFM (User Level Fault Mitigation) de MPI.

SINTAXIS

Sintaxis C

#include <mpi.h>
#include <mpi-ext.h>
int MPIX_Comm_revoke(MPI_Comm comm)

Sintaxis Fortran

USE MPI
USE MPI_EXT
! o la forma antigua: INCLUDE 'mpif.h'
MPIX_COMM_REVOKE(COMM, IERROR)
     INTEGER COMM, IERROR

Sintaxis Fortran 2008

USE mpi_f08
USE mpi_ext_f08
MPIX_Comm_revoke(comm, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

•
comm: Comunicador (handle).

PARÁMETROS DE SALIDA

•
ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Esta función marca el comunicador comm como revocado en todos los procesos MPI de los grupos (locales y remotos) asociados con el comunicador comm. Esta función no es colectiva y, por lo tanto, no tiene una llamada equivalente en los procesos MPI remotos.

La documentación de MPIX_Comm_is_revoked detalla las condiciones bajo las cuales un comunicador se revoca localmente y qué semánticas se aplican a un comunicador revocado. En resumen, cuando un comunicador se revoca, las operaciones no locales generan una excepción de clase MPIX_ERR_REVOKED, excepto para operaciones selectas de tolerancia a fallos.

PROPAGACIÓN DEL ESTADO REVOCADO Y ORDENAMIENTO

La implementación propaga el estado revocado de manera tolerante a fallos; por lo tanto, el comunicador se revoca en todos los procesos MPI que no han fallado y que pertenecen a comm, a pesar de los procesos fallidos.

No existe un orden particular entre la llamada de revocación en otro proceso y la finalización de las operaciones en un proceso local. Por ejemplo, una operación de recepción puede generar un error de clase MPIX_ERR_REVOKED, incluso si el procedimiento de llamada de la operación de envío se realiza antes que el procedimiento de revocación en el remitente.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; en C, como resultado del retorno de la función y en Fortran, en el último argumento.

Antes de devolver el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error genera el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de CLI mpi_initial_errhandler para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
