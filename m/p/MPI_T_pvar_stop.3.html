MPI_T_PVAR_STOP(3) Open MPI MPI_T_PVAR_STOP(3)

MPI_T_pvar_start, MPI_T_pvar_stop - Iniciar/detener una variable de rendimiento

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_pvar_start(MPI_T_pvar_session session, MPI_T_pvar_handle handle)
int MPI_T_pvar_stop(MPI_T_pvar_session session, MPI_T_pvar_handle handle)

PARÁMETROS DE ENTRADA

  • session: Sesión de experimento de rendimiento.
  • handle: Identificador de variable de rendimiento.

DESCRIPCIÓN

MPI_T_pvar_start inicia la variable de rendimiento con el identificador especificado en handle. El valor especial MPI_T_PVAR_ALL_HANDLES puede pasarse en handle para iniciar todos los identificadores no continuos en la sesión especificada en session.

MPI_T_pvar_stop detiene la variable de rendimiento con el identificador especificado en handle. El valor especial MPI_T_PVAR_ALL_HANDLES puede pasarse en handle para detener todos los identificadores no continuos en la sesión especificada en session.

Las variables de rendimiento continuas no pueden iniciarse ni detenerse.

ERRORES

MPI_T_pvar_start y MPI_T_pvar_stop() fallarán si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de Herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_SESSION: El parámetro session no es una sesión válida.
  • MPI_T_ERR_INVALID_HANDLE: Identificador inválido o identificador no asociado con la sesión.
  • MPI_T_ERR_PVAR_NO_STARTSTOP: La variable no puede iniciarse ni detenerse.
