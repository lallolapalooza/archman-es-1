MPI_File_get_info(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_File_get_info(3) Open MPI MPI_File_get_info(3)

MPI_File_get_info devuelve un nuevo objeto de información que contiene valores para las actualizaciones actuales asociadas a un archivo.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_File_get_info(MPI_File fh, MPI_Info *info_used)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_FILE_GET_INFO(FH, INFO_USED, IERROR)
     INTEGER FH, INFO_USED, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_File_get_info(fh, info_used, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     TYPE(MPI_Info), INTENT(OUT) :: info_used
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

•
fh: Llamada de archivo (handle).

Parámetros de salida

  • info_used: Objeto de información nuevo (handle).
  • ierror: Solo Fortran: Estado de error (entero).

Descripción

MPI_File_get_info devuelve un nuevo objeto de información que contiene todos los intentos actuales asociados al archivo fh. El estado actual de todos los intentos que el sistema usa en este archivo abierto se devuelve en info_used. El usuario debe liberar info_used mediante MPI_Info_free.

Nota: El conjunto de intentos devuelto en info_used puede ser mayor o menor que el conjunto de intentos proporcionados en MPI_File_open, MPI_File_set_view o MPI_File_set_info, ya que el sistema puede no reconocer algunos intentos de los que el usuario ha establecido y puede automáticamente establecer otros intentos que el usuario no ha solicitado. Consulte la sección de INTENTOS para una lista de intentos que pueden ser establecidos.

INTENTOS

Los siguientes intentos pueden usarse como valores para el parámetro info_used.

INTENTOS SETTABLE

  • shared_file_timeout: Cantidad de tiempo (en segundos) a esperar antes de salir con MPI_ERR_TIMEDOUT para acceder al puntero de archivo compartido.
  • rwlock_timeout: Cantidad de tiempo (en segundos) a esperar antes de salir con MPI_ERR_TIMEDOUT para obtener un bloque de lectura o escritura en un bloque contiguo de un archivo Unix antes de salir.
  • noncoll_read_bufsize: Tamaño máximo del buffer utilizado por I/O de MPI para satisfacer consultas de lectura en rutinas de acceso de datos no coloquiales.

    • NOTA:

Un tamaño de buffer menor que la distancia (en bytes) entre el primer byte y el último byte de la solicitud de acceso en un archivo Unix causa que MPI I/O realice iteraciones y realice múltiples llamadas a read() o write() de UNIX. Si la solicitud incluye múltiples bloques no contiguos de datos y el tamaño del buffer es mayor que el tamaño de esos bloques, entonces las llamadas a read() o write() (realizadas en el nivel de I/O de MPI) accederán a datos no solicitados por este proceso para reducir el número total de llamadas a write(). Si este comportamiento no es deseable, se debe reducir el tamaño del buffer a igual que el tamaño de los bloques contiguos dentro de la solicitud agregada.
  • noncoll_write_bufsize: Tamaño máximo del buffer utilizado por I/O de MPI para satisfacer las solicitudes de escritura en las rutinas de acceso de datos no coloquiales.

    • Ver la nota anterior en noncoll_read_bufsize.

  • coll_read_bufsize: Tamaño máximo del buffer utilizado por I/O de MPI para satisfacer las solicitudes de lectura en las rutinas de acceso de datos coloquiales.

    • Ver la nota anterior en noncoll_read_bufsize.

  • coll_write_bufsize: Tamaño máximo del buffer utilizado por I/O de MPI para satisfacer las solicitudes de escritura en las rutinas de acceso de datos coloquiales.

    • Ver la nota anterior en noncoll_read_bufsize.

  • mpiio_concurrency: (boolean) controla si las rutinas de I/O no bloqueadas pueden vincular un hilo adicional a un LWP.
  • mpiio_coll_contiguous: (boolean) controla si los siguientes accesos de datos coloquiales solicitarán regiones contiguas del archivo.

INTENTOS NO SETTABLE

•
filename: Usa este intento para obtener el nombre del archivo.

ERRORES

Más del 90% de las rutinas MPI devuelven un valor de error; en las rutinas C, el valor de error es el resultado de la función y en las rutinas Fortran, el último argumento es el valor de error.

Antes de devolver el valor de error, se llama al error handler actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay objeto de comunicación asociado con la llamada MPI, la llamada se considera asociada a MPI_COMM_SELF y se llama al error handler correspondiente. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se use el modelo de Sesiones exclusivamente), el error levanta el error handler inicial. El error handler inicial puede cambiarse llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se use el modelo del Mundo, o a la opción mpi_initial_errhandler del mpiexec o al parámetro de información del MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro error handler adecuado, se llama al error handler MPI_ERRORS_RETURN para las funciones de I/O de MPI y al error handler MPI_ERRORS_ABORT para todas las otras funciones de MPI.

Open MPI incluye tres handlers de error prediseñados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un error handler que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios handlers de error llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: El MPI no garantiza que un programa MPI pueda continuar tras un error.

Ve el man de MPI para una lista completa de códigos de error de MPI.

Ve la sección de manejo de errores de la estándar MPI-3.1 para más información.
