MPI_Comm_create_from_group — Crea un nuevo comunicador a partir de un grupo y una etiqueta de cadena

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Comm_create_from_group(MPI_Group group, const char *stringtag, MPI_Info info, MPI_Errhandler errhandler, MPI_Comm *newcomm)

Sintaxis Fortran

USE MPI
! o la forma más antigua: INCLUDE 'mpif.h'
MPI_COMM_CREATE_FROM_GROUP(GROUP, STRINGTAG, INFO, ERRHANDLER, NEWCOMM, IERROR)
    INTEGER GROUP, INFO, ERRHANDLER, NEWCOMM, IERROR
    CHARACTER*(*) STRINGTAG

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_create_from_group(group, stringtag, info, errhandler, newcomm, ierror)
    TYPE(MPI_Group), INTENT(IN) :: group
    CHARACTER(LEN=*), INTENT(IN) :: stringtag
    TYPE(MPI_Info), INTENT(IN) :: info
    TYPE(MPI_Errhandler), INTENT(IN) :: errhandler
    TYPE(MPI_Comm), INTENT(OUT) :: newcomm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • group : Grupo (manejador)
  • stringtag : Identificador único para esta operación (cadena)
  • info : Objeto de información (manejador)
errhandler
manejador de errores que se adjuntará al nuevo intra-comunicador (manejador)

PARÁMETROS DE SALIDA

  • newcomm : Nuevo comunicador (manejador).
  • ierror : Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

MPI_Comm_create_from_group es similar a MPI_Comm_create_group, excepto que el conjunto de procesos MPI involucrados en la creación del nuevo intra-comunicador se especifica mediante un argumento de grupo, en lugar del grupo asociado con un comunicador preexistente. Si se especifica un grupo no vacío, entonces todos los procesos MPI de ese grupo deben llamar a la función y cada uno de estos procesos MPI debe proporcionar los mismos argumentos, incluido un grupo que contenga los mismos miembros con el mismo orden y un valor de etiqueta de cadena idéntico. En caso de que se proporcione MPI_GROUP_EMPTY como argumento de grupo, la llamada es una operación local y MPI_COMM_NULL se devuelve como newcomm. El argumento stringtag es análogo a la etiqueta utilizada para MPI_Comm_create_group. Si varios hilos en un proceso MPI dado realizan operaciones concurrentes de MPI_Comm_create_from_group, el usuario debe distinguir estas operaciones proporcionando diferentes argumentos stringtag. La etiqueta de cadena no debe exceder los caracteres de longitud de MPI_MAX_STRINGTAG_LEN. Para C, esto incluye espacio para un carácter de terminación nulo.

NOTAS

El argumento errhandler especifica un manejador de errores que se adjuntará al nuevo intracommunicador. El argumento info proporciona sugerencias y aserciones, posiblemente dependientes de la implementación de MPI, que indican características deseadas y guían la creación del comunicador. MPI_MAX_STRINGTAG_LEN debe tener un valor de al menos 63.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores de MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores de MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones), el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento CLI mpi_initial_errhandler a mpiexec o la clave info a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
