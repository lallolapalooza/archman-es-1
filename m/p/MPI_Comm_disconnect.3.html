MPI_Comm_disconnect(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_COMM_DISCONNECT(3) Open MPI MPI_COMM_DISCONNECT(3)

MPI_Comm_disconnect — Desasigna el objeto comunicador y establece el manejador a MPI_COMM_NULL.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Comm_disconnect(MPI_Comm *comm)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_COMM_DISCONNECT(COMM, IERROR)
    INTEGER COMM, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_disconnect(comm, ierror)
    TYPE(MPI_Comm), INTENT(INOUT) :: comm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO ENTRADA/SALIDA

•
comm : Comunicador (manejador).

PARÁMETRO DE SALIDA

•
ierror : Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Comm_disconnect espera a que toda la comunicación pendiente en comm se complete internamente, desasigna el objeto comunicador y establece el manejador a MPI_COMM_NULL. Es una operación colectiva. No se puede llamar con los comunicadores MPI_COMM_WORLD o MPI_COMM_SELF. MPI_Comm_disconnect solo puede llamarse si toda la comunicación está completa y emparejada, de modo que los datos almacenados en búfer puedan ser entregados a su destino. Este requisito es el mismo que para MPI_Finalize. MPI_Comm_disconnect tiene la misma acción que MPI_Comm_free, excepto que espera a que la comunicación pendiente termine internamente y permite la garantía sobre el comportamiento de los procesos desconectados.

NOTAS

Para desconectar dos procesos, puede que necesite llamar a MPI_Comm_disconnect, MPI_Win_free y MPI_File_close para eliminar todas las rutas de comunicación entre los dos procesos. Tenga en cuenta que puede ser necesario desconectar varios comunicadores (o liberar varias ventanas o archivos) antes de que dos procesos sean completamente independientes.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores de MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores de MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el controlador de errores inicial. El controlador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento CLI mpi_initial_errhandler a mpiexec o la clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y se llama al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para más información.
