MPI_Type_indexed, MPI_Type_create_hindexed - Crea un tipo de dato indexado.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Type_indexed(int count, const int array_of_blocklengths[],
     const int array_of_displacements[], MPI_Datatype oldtype,
     MPI_Datatype *newtype)
int MPI_Type_create_hindexed(int count,
     const int array_of_blocklengths[],
     const MPI_Aint array_of_displacements[], MPI_Datatype oldtype,
     MPI_Datatype *newtype)

Sintaxis Fortran

USE MPI
! o la antigua forma: INCLUDE 'mpif.h'
MPI_TYPE_INDEXED(COUNT, ARRAY_OF_BLOCKLENGTHS,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, ARRAY_OF_BLOCKLENGTHS(*)
     INTEGER ARRAY_OF_DISPLACEMENTS(*), OLDTYPE, NEWTYPE
     INTEGER IERROR
MPI_TYPE_CREATE_HINDEXED(COUNT, ARRAY_OF_BLOCKLENGTHS,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, ARRAY_OF_BLOCKLENGTHS(*)
     INTEGER OLDTYPE, NEWTYPE
     INTEGER(KIND=MPI_ADDRESS_KIND) ARRAY_OF_DISPLACEMENTS(*)
     INTEGER IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Type_indexed(count, array_of_blocklengths, array_of_displacements,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, array_of_blocklengths(count),
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Type_create_hindexed(count, array_of_blocklengths,
             array_of_displacements, oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, array_of_blocklengths(count)
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) ::
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

  • count: Número de bloques — también número de entradas en array_of_displacements y array_of_blocklengths (entero no negativo).
  • array_of_blocklengths: Número de elementos por bloque (array de enteros no negativos).
  • array_of_displacements: Desplazamiento de cada bloque, en múltiplos de la extensión del tipo antiguo para MPI_Type_indexed y bytes para MPI_Type_create_hindexed (array de enteros para MPI_TYPE_INDEXED, array de MPI_Aint para MPI_TYPE_CREATE_HINDEXED).
  • oldtype: Tipo de dato antiguo (handle).

Parámetros de salida

  • newtype: Tipo de dato nuevo (handle).
  • ierror: Solo en Fortran: Código de error (entero).

Descripción

La función MPI_Type_indexed permite replicar un tipo de dato antiguo en una secuencia de bloques (cada bloque es una concatenación del tipo antiguo), donde cada bloque puede contener un número diferente de copias y tener un desplazamiento diferente. Todos los desplazamientos de bloque son múltiplos de la extensión del tipo de dato antiguo.

Ejemplo: Supongamos que el tipo antiguo tiene tipo map {(double, 0), (char, 8)}, con extensión 16. Sea B = (3, 1) y D = (4, 0). Una llamada a MPI_Type_indexed(2, B, D, oldtype, newtype) devuelve un tipo de dato con tipo map

{(double, 64), (char, 72), (double, 80), (char, 88),
(double, 96), (char, 104),
(double, 0), (char, 8)}

Es decir, tres copias del tipo antiguo que comienzan en desplazamiento 4 x 16 = 64, y una copia que comienza en desplazamiento 0.

En general, asume que el tipo antiguo tiene tipo map

{(type(0), disp(0)), ..., (type(n-1), disp(n-1))},
con extensión ex. Sea B el argumento array_of_blocklength y D el argumento array_of_displacements. El tipo de dato nuevo tiene
n x S ^count-1
    i = 0           B[i]  entradas:
    {(type(0), disp(0) + D[0]* ex), ...,
    (type(n-1), disp(n-1) + D[0]* ex), ...,
    (type(0), disp(0) + (D[0] + B[0] -1)* ex), ...,
    (type(n-1), disp(n-1) + (D[0]+ B[0] -1)* ex), ...,
    (type(0), disp(0) + D[count-1]* ex), ...,
    (type(n-1), disp(n-1) + D[count-1]* ex), ...,
    (type(0), disp(0) +  (D[count-1] + B[count-1] -1)* ex), ...,
    (type(n-1), disp(n-1) + (D[count-1] + B[count-1] -1)* ex)}

Una llamada a MPI_Type_vector(count, blocklength, stride, oldtype, newtype) es equivalente a una llamada a MPI_Type_indexed(count, B, D, oldtype, newtype) donde

    D[j] = j * stride, j = 0,..., count-1
y
    B[j] = blocklength, j = 0, .., count-1

La función MPI_Type_create_hindexed es idéntica a MPI_Type_indexed, excepto que los desplazamientos de bloque en array_of_displacements se especifican en bytes, no en múltiplos de la extensión del tipo antiguo.

Errores

La mayoría de las rutinas MPI devuelven un valor de error; en las rutinas C, el resultado es el valor de retorno de la función, y en las rutinas Fortran, en el último argumento.

Antes de que el valor de error se devuelva, se llama al manejador de error asociado con el objeto de comunicación (por ejemplo, el comunicador, ventana, archivo) actual. Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y llamará al manejador de error asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se use exclusivamente el modelo de sesiones), el error genera el manejador de error inicial. El manejador de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se use el modelo de mundo, o el argumento mpi_initial_errhandler de mpiexec o la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de error adecuado configurado, se llama el manejador de error MPI_ERRORS_RETURN para funciones de I/O MPI y el manejador de error MPI_ERRORS_ABORT para otras funciones MPI.

Open MPI incluye tres manejadores de error predeterminados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL Causa que el programa termine todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, se detiene solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error al aplicativo.

Los aplicativos MPI también pueden implementar sus propios manejadores de error llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o al MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: El MPI no garantiza que un programa MPI pueda continuar después de un error.

Ver la página de manuales de MPI para una lista completa de códigos de error MPI.
