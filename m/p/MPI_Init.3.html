MPI_INIT(3) Open MPI MPI_INIT(3)

MPI_Init — Inicializa el modelo mundial de MPI

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Init(int *argc, char ***argv)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_INIT(IERROR)
     INTEGER IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Init(ierror)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • argc: Solo C: Puntero al número de argumentos.
  • argv: Solo C: Vector de argumentos.

PARÁMETRO DE SALIDA

•
ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Esta rutina, o MPI_Init_thread, inicializa el modelo mundial de MPI. Cualquiera de estas rutinas debe ser llamada antes de que se llamen las rutinas de comunicación MPI dentro del modelo mundial de MPI. El modelo mundial de MPI puede inicializarse como máximo exactamente una vez en la vida de un proceso MPI. Esto es diferente del modelo de sesión MPI, que puede inicializarse y finalizarse múltiples veces en un proceso MPI. Ver MPI_Session_init y MPI_Session_finalize.

Ver MPI-5.0:11.4.1 para una lista de funcionalidad MPI que está disponible (por ejemplo, incluso cuando el modelo mundial de MPI aún no se ha inicializado o ya se ha finalizado).

MPI_Init y MPI_Init_thread de Open MPI aceptan ambos los argumentos C argc y argv a main, pero ninguno los modifica, interpreta ni distribuye:

#include <mpi.h>
int main(int argv, char *argv[]) {
    MPI_Init(&argc, &argv);
    /* ...cuerpo del programa principal MPI... */
    MPI_Finalize();
    return 0;
}

Por defecto, MPI_Init es efectivamente equivalente a invocar MPI_Init_thread con un valor requerido de MPI_THREAD_SINGLE. Sin embargo, si la variable de entorno OMPI_MPI_THREAD_LEVEL se establece en un valor válido cuando se invoca MPI_Init, es equivalente a invocar MPI_Init_thread con requerido establecido en el valor correspondiente de la variable de entorno OMPI_MPI_THREAD_LEVEL. Ver MPI_Init_thread para más detalles.

NOTAS

La versión Fortran no tiene provisiones para argc y argv y solo toma IERROR.

El Estándar MPI no especifica qué puede hacer un programa que utiliza el modelo mundial de MPI antes de invocar MPI_Init o MPI_Init_thread o después de invocar MPI_Finalize. En la implementación de Open MPI, debe hacer lo menos posible. En particular, evite cualquier cosa que cambie el estado externo del programa, como abrir archivos, leer la entrada estándar o escribir en la salida estándar.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay un objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial puede ser cambiado llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo Mundial, o el argumento de línea de comandos mpi_initial_errhandler para mpiexec o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro manejador de errores apropiado, entonces el manejador de errores MPI_ERRORS_RETURN se llama para las funciones de E/S de MPI y el manejador de errores MPI_ERRORS_ABORT se llama para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Ver la página del manual de MPI para una lista completa de los códigos de error de MPI.

Ver la sección de Manejo de Errores del estándar MPI-3.1 para más información.
