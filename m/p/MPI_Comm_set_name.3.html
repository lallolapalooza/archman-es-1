MPI_COMM_SET_NAME(3) Open MPI MPI_Comm_set_name(3)

MPI_Comm_set_name — Asocia un nombre a un comunicador.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Comm_set_name(MPI_Comm comm, const char *comm_name)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_COMM_SET_NAME(COMM, COMM_NAME, IERROR)
     INTEGER COMM, IERROR
     CHARACTER*(*) COMM_NAME

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_set_name(comm, comm_name, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     CHARACTER(LEN=*), INTENT(IN) :: comm_name
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA/SALIDA

•
comm: Identificador del comunicador cuyo nombre se va a establecer (handle).

PARÁMETRO DE ENTRADA

•
comm_name: Cadena de caracteres que se utilizará como identificador del comunicador (cadena).

PARÁMETRO DE SALIDA

•
ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

MPI_Comm_set_name permite a un usuario asociar una cadena de nombre a un comunicador. La cadena de caracteres que se pasa a MPI_Comm_set_name se guarda dentro de la biblioteca MPI (por lo que el llamador puede liberarla inmediatamente después de la llamada, o asignarla en la pila). Los espacios iniciales en name son significativos, pero los finales no.

MPI_Comm_set_name es una operación local (no colectiva), que afecta solo al nombre del comunicador tal como se ve en el proceso que realizó la llamada a MPI_Comm_set_name. No hay ningún requisito de que el mismo nombre (o cualquier nombre) se asigne a un comunicador en cada proceso donde exista.

La longitud del nombre que se puede almacenar está limitada al valor de MPI_MAX_OBJECT_NAME en Fortran y MPI_MAX_OBJECT_NAME-1 en C (para permitir el terminador nulo). Los intentos de establecer nombres más largos que esto darán como resultado el truncamiento del nombre. MPI_MAX_OBJECT_NAME debe tener un valor de al menos 64.

NOTAS

Dado que MPI_Comm_set_name se proporciona para ayudar a depurar el código, es sensato dar el mismo nombre a un comunicador en todos los procesos donde exista, para evitar confusiones.

Con respecto a la longitud del nombre, en circunstancias de agotamiento de almacenamiento, un intento de establecer un nombre de cualquier longitud podría fallar; por lo tanto, el valor de MPI_MAX_OBJECT_NAME debe verse solo como un límite superior estricto para la longitud del nombre, no como una garantía de que establecer nombres de longitud menor a esta siempre tendrá éxito.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el controlador de errores inicial. El controlador de errores inicial puede modificarse llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o la clave de información de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, entonces se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Hace que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo interrumpe el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para más información.
