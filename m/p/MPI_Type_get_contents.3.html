MPI_TYPE_GET_CONTENTS(3) Open MPI MPI_TYPE_GET_CONTENTS(3)

MPI_Type_get_contents — Devuelve información sobre los argumentos utilizados en la creación de un tipo de dato.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Type_get_contents(MPI_Datatype datatype, int max_integers,
     int max_addresses, int max_datatypes, int array_of_integers[], MPI_Aint array_of_addresses[], MPI_Datatype array_of_datatypes[])

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_TYPE_GET_CONTENTS(DATATYPE, MAX_INTEGERS, MAX_ADDRESSES,
             MAX_DATATYPES, ARRAY_OF_INTEGERS, ARRAY_OF_ADDRESSES,
             ARRAY_OF_DATATYPES, IERROR)
     INTEGER DATATYPE, MAX_INTEGERS, MAX_ADDRESSES, MAX_DATATYPES
     INTEGER ARRAY_OF_INTEGERS(*), ARRAY_OF_DATATYPES(*), IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) ARRAY_OF_ADDRESSES(*)

Sintaxis Fortran 2008

USE mpi_f08
MPI_Type_get_contents(datatype, max_integers, max_addresses, max_datatypes,
     array_of_integers, array_of_addresses, array_of_datatypes,
             ierror)
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(IN) :: max_integers, max_addresses, max_datatypes
     INTEGER, INTENT(OUT) :: array_of_integers(max_integers)
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) ::
     array_of_addresses(max_addresses)
     TYPE(MPI_Datatype), INTENT(OUT) :: array_of_datatypes(max_datatypes)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETROS DE ENTRADA

  • datatype: Tipo de dato a acceder (handle).
  • max_integers: Número de elementos en array_of_integers (entero no negativo).
  • max_addresses: Número de elementos en array_of_addresses (entero no negativo).
  • max_datatypes: Número de elementos en array_of_datatypes (entero no negativo).

PARAMETROS DE SALIDA

  • array_of_integers: Contiene los argumentos enteros utilizados en la construcción de datatype (array de enteros).
  • array_of_addresses: Contiene los argumentos de dirección utilizados en la construcción de datatype (array de enteros).
  • array_of_datatypes: Contiene los argumentos de tipo de dato utilizados en la construcción de datatype (array de enteros).
  • ierror: Solo Fortran: Estado del error (entero).

DESCRIPCION

Para el tipo de dato dado, MPI_Type_get_envelope devuelve información sobre el número y tipo de argumentos de entrada utilizados en la llamada que creó el tipo de dato. Los valores del número de argumentos devueltos pueden usarse para proporcionar arrays lo suficientemente grandes en la rutina de decodificación MPI_Type_get_contents. Esta llamada y el significado de los valores devueltos se describen a continuación. El combinador refleja la llamada al constructor de tipos de datos MPI que se utilizó para crear datatype.

El parámetro datatype debe ser un tipo de dato no nombrado predefinido o derivado . La llamada es errónea si datatype es un tipo de dato nombrado predefinido .

Los valores dados para max_integers, max_addresses, y max_datatypes deben ser al menos tan grandes como el valor devuelto en num_integers, num_addresses, y num_datatypes, respectivamente, en la llamada :ref:`MPI_Type_get_envelope` para el mismo argumento datatype.

Los tipos de datos devueltos en array_of_datatypes son handles a objetos de tipo de dato que son equivalentes a los tipos de datos utilizados en la llamada de construcción original. Si estos eran tipos de datos derivados, entonces los tipos de datos devueltos son nuevos objetos de tipo de dato, y el usuario es responsable de liberarlos con :ref:`MPI_Type_free`. Si estos eran tipos de datos predefinidos , entonces el tipo de dato devuelto es igual a ese tipo de dato predefinido (constante) y no puede ser liberado.

El estado comprometido de los tipos de datos derivados devueltos es indefinido, es decir, los tipos de datos pueden estar comprometidos o no. Además, el contenido de los atributos de los tipos de datos devueltos es indefinido.

Tenga en cuenta que MPI_Type_get_contents puede invocarse con un argumento de tipo de dato que se construyó utilizando MPI_Type_create_f90_real, MPI_Type_create_f90_integer, o MPI_Type_create_f90_complex (un tipo de dato predefinido no nombrado). En tal caso, se devuelve un array_of_datatypes vacío.

En las llamadas constructoras de tipos de datos legadas de MPI-1, los argumentos de dirección en Fortran son de tipo INTEGER. En versiones posteriores del Estándar MPI, los argumentos de dirección son de tipo INTEGER(KIND=MPI_ADDRESS_KIND). La llamada MPI_Type_get_contents devuelve todas las direcciones en un argumento de tipo INTEGER(KIND=MPI_ADDRESS_KIND). Esto es cierto incluso si se usaron las llamadas antiguas de MPI-1. Por lo tanto, la ubicación de los valores devueltos se puede pensar como devuelta por las vinculaciones C. También se puede determinar examinando las llamadas MPI actuales para los constructores de tipos de datos para las llamadas MPI-1 obsoletas que involucran direcciones.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento CLI mpi_initial_errhandler de mpiexec o la clave de información de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para más información.

MPI_Type_get_contents

MPI_Type_get_contents - Retrieve contents of a datatype

3

SYNTAX

int MPI_Type_get_contents(MPI_Datatype datatype, int max_integers, int max_addresses, int max_displacements, MPI_Datatype types[], MPI_Aint displacements[], int integers[])

INPUT PARAMETERS

datatype

Handle of the datatype to inspect.

max_integers

Number of entries in the integers array.

max_addresses

Number of entries in the displacements array.

max_displacements

Number of entries in the types array. The number of entries in these arrays must be at least as large as the number of basic components in the datatype.

OUTPUT PARAMETERS

types

Array of basic datatypes that are components of the datatype.

displacements

Array of displacements of components in the datatype.

integers

Array of integers that are components of the datatype.

DESCRIPTION

MPI_Type_get_contents returns information about the components of a datatype. The information returned depends on the type of the datatype. For committed datatypes that are derived from existing datatypes, the information returned describes how the new datatype is constructed from the existing datatypes.

The types array contains the MPI datatypes that are used to construct the datatype. The displacements array contains the displacements of these components in bytes. The integers array contains additional integer information that may be required to describe the datatype. The exact meaning of the entries in the integers array depends on the type of the datatype.

For example, if the datatype is a contiguous array of elements of type oldtype, then types will contain oldtype, displacements will contain 0, and integers will contain the number of elements in the array.

If the datatype is a vector of elements of type oldtype, then types will contain oldtype, displacements will contain 0, and integers will contain the block length, stride, and count.

The values returned in types, displacements, and integers describe the structure of the datatype. The number of entries in these arrays that are actually used is determined by the type of the datatype. The caller must provide arrays that are large enough to hold all the information.

ERRORS

When an error occurs, the C/C++ binding of the MPI standard specifies that no error return value is returned. Instead, the routine is required to behave as if MPI_ERRORS_ARE_FATAL is set. The MPI runtime environment determines the error handling.
