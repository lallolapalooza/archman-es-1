MPIX_COMM_AGREE(3) Open MPI MPIX_COMM_AGREE(3)

MPIX_Comm_agree, MPIX_Comm_iagree - Acordar un valor de bandera de todos los procesos activos y distribuir el resultado a todos los procesos activos, incluso después de fallos de procesos.

Esto forma parte de la extensión ULFM (User Level Fault Mitigation).

SINTAXIS

Sintaxis C

#include <mpi.h>
#include <mpi-ext.h>
int MPIX_Comm_agree(MPI_Comm comm, int *flag)
int MPIX_Comm_iagree(MPI_Comm comm, int *flag, MPI_Request *request)

Sintaxis Fortran

USE MPI
USE MPI_EXT
! o la forma más antigua: INCLUDE 'mpif.h'
MPIX_COMM_AGREE(COMM, FLAG, IERROR)
     INTEGER COMM, FLAG, IERROR
MPIX_COMM_IAGREE(COMM, FLAG, REQUEST, IERROR)
     INTEGER COMM, FLAG, REQUEST, IERROR

Sintaxis Fortran 2008

USE mpi_f08
USE mpi_ext_f08
MPIX_Comm_agree(comm, flag, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(INOUT) :: flag
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPIX_COMM_IAGREE(COMM, FLAG, REQUEST, IERROR)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(INOUT), ASYNCHRONOUS :: flag
     TYPE(MPI_Request), INTENT(OUT) :: request
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • comm: Comunicador (manejador).
  • flag: Banderas binarias (entero).

PARÁMETROS DE SALIDA

  • flag: Banderas binarias reducidas (entero).
  • request: Manejador de solicitud (solo no bloqueante).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Esta comunicación colectiva acuerda el valor entero flag y (implícitamente) el grupo de procesos fallidos en comm.

Al completarse, todos los procesos MPI no fallidos han acordado establecer el valor entero de salida flag al resultado de una operación AND bit a bit sobre los valores de entrada de flag aportados.

MPIX_Comm_iagree es la variante no bloqueante de MPIX_Comm_agree.

FALLOS DE PROCESOS

Cuando un proceso MPI falla antes de contribuir a la operación de acuerdo, el flag se calcula ignorando su contribución, y la operación genera un error de clase MPIX_ERR_PROC_FAILED.

Cuando se genera un error de clase MPIX_ERR_PROC_FAILED, se genera de forma consistente en todos los procesos MPI del grupo(s) de comm.

Después de que MPIX_Comm_agree generara un error de clase MPIX_ERR_PROC_FAILED, el grupo producido por una llamada posterior a MPIX_Comm_get_failed en comm contiene cada proceso MPI que no contribuyó al cálculo del flag.

CUANDO EL COMUNICADOR CONTIENE FALLOS CONFIRMADOS

Si todos los procesos MPI del grupo de comm han confirmado el fallo de un proceso MPI (usando MPIX_Comm_ack_failed) antes de la llamada a MPIX_Comm_agree (o MPIX_Comm_iagree), el error MPIX_ERR_PROC_FAILED no se genera cuando el valor de salida de flag ignora la contribución de ese proceso fallido. Tenga en cuenta que esta es una propiedad uniforme: si se encuentra que un proceso no contribuyente no ha sido confirmado en ningún proceso activo en comm, todos los procesos generan un error de clase MPIX_ERR_PROC_FAILED.

Ejemplo 1: Usando una combinación de MPIX_Comm_ack_failed y MPIX_Comm_agree, los usuarios pueden propagar y sincronizar el conocimiento de fallos en todos los procesos MPI en comm.

Comm_get_failed_consistent(MPI_Comm c, MPI_Group * g) {
    int rc; int T=1;
    int size; int num_acked;
    MPI_Group gf;
    int ranges[3] = {0, 0, 1};
    MPI_Comm_size(c, &size);
    do {
        /* esta rutina no es pura: llamar a MPI_Comm_ack_failed
         * afecta el estado del comunicador c */
        MPIX_Comm_ack_failed(c, size, &num_acked);
        /* simplemente ignoramos el valor T en este ejemplo */
        rc = MPIX_Comm_agree(c, &T);
    } while( rc != MPI_SUCCESS );
    /* después de este bucle, MPIX_Comm_agree ha devuelto MPI_SUCCESS en
     * todos los procesos, por lo que todos los procesos han Confirmado el mismo conjunto
     * de fallos. Obtengamos ese conjunto de fallos en el grupo g. */
    if( 0 == num_acked ) {
        *g = MPI_GROUP_EMPTY;
    }
    else {
        MPIX_Comm_get_failed(c, &gf);
        ranges[1] = num_acked - 1;
        MPI_Group_range_incl(gf, 1, ranges, g);
        MPI_Group_free(&gf);
    }
}

CUANDO EL COMUNICADOR ES REVOCADO

Esta función nunca genera un error de clase MPIX_ERR_REVOKED. La semántica definida de MPIX_Comm_agree se mantiene cuando comm es revocado, o cuando el grupo de comm contiene procesos MPI fallidos. En particular, MPIX_Comm_agree es una operación colectiva, incluso cuando comm está revocado.

CUANDO EL COMUNICADOR ES UN INTERCOMUNICADOR

Cuando el comunicador es un intercomunicador, el valor de flag es una operación AND bit a bit sobre los valores aportados por el grupo remoto.

Cuando se genera un error de clase MPIX_ERR_PROC_FAILED, se genera de forma consistente en todos los procesos MPI de los grupos de comm, es decir, tanto en los grupos locales como remotos del intercomunicador.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error genera el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos MPI_ERRORS_RETURN a mpiexec o la clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces el manejador de errores MPI_ERRORS_RETURN se llama para las funciones de E/S MPI y el manejador de errores MPI_ERRORS_ABORT se llama para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

MPIX_Comm_agree(3)

SYNOPSIS

C/C++:
#include <mpi.h>
int MPIX_Comm_agree(MPI_Comm comm, int *flag);

INPUT PARAMETERS

comm
Un comunicador. Debe ser un comunicador intracomunicador.

OUTPUT PARAMETERS

flag
Un puntero a un entero. Si el valor de *flag es distinto de cero (verdadero) en la entrada, entonces el valor de *flag será distinto de cero (verdadero) a la salida si todos los procesos en el comunicador `comm` tienen el mismo valor para *flag. Si el valor de *flag es cero (falso) en la entrada, entonces el valor de *flag será cero (falso) a la salida. La entrada solo se usa si se va a informar de un fallo.

DESCRIPTION

MPIX_Comm_agree se utiliza para sincronizar los procesos de un comunicador y para determinar si todos los procesos de un comunicador tienen el mismo valor. Si el valor de entrada de *flag es distinto de cero, y todos los procesos tienen el mismo valor en la entrada, entonces el valor de salida de *flag será distinto de cero.

Si el valor de entrada de *flag es cero, entonces el valor de salida de *flag será cero.

Este llamado se puede usar para la propagación de errores. Por ejemplo, si un proceso detecta un error y desea que todos los demás procesos del comunicador fallen de manera predecible, puede llamar a MPIX_Comm_agree con *flag establecido en un valor no cero (por ejemplo, 1). Si todos los demás procesos tienen *flag establecido en 1, entonces todos los procesos saldrán de la llamada con *flag = 1. Si algunos procesos tienen *flag = 0, entonces saldrán con *flag = 0.

Si se va a informar de un fallo, el valor de entrada de *flag debe ser distinto de cero.

PROCESS FAILURES

Si algún proceso dentro del comunicador `comm` falla antes de que todos los procesos hayan salido de la llamada MPIX_Comm_agree, entonces la llamada fallará para todos los procesos restantes.

WHEN THE COMMUNICATOR CONTAINS ACKNOWLEDGED FAILURES

Si el comunicador `comm` contiene procesos que han sido reconocidos como fallidos por medio de MPIX_Comm_ack_failed, entonces MPIX_Comm_agree fallará con el código de error MPIX_ERR_PROC_FAILED.

WHEN THE COMMUNICATOR IS REVOKED

Si el comunicador `comm` ha sido revocado por medio de MPIX_Comm_revoke, entonces MPIX_Comm_agree fallará con el código de error MPIX_ERR_REVOKED.

WHEN COMMUNICATOR IS AN INTER-COMMUNICATOR

Si el comunicador `comm` es un inter-comunicador, entonces MPIX_Comm_agree fallará con el código de error MPIX_ERR_COMM.

ERRORS

La llamada MPIX_Comm_agree fallará si el comunicador `comm` está revocado o si contiene procesos fallidos que no han sido reconocidos. También fallará si los procesos en `comm` no tienen el mismo valor de entrada para *flag.

La llamada fallará si se detecta un error durante la ejecución de la rutina.

La llamada puede fallar para indicar que un proceso se ha desconectado inesperadamente. En este caso, el código de retorno será MPIX_ERR_PROC_FAILED.

Si el comunicador ha sido revocado, el código de retorno será MPIX_ERR_REVOKED.

La llamada puede fallar para indicar que un fallo ha sido detectado y que el programa debe salir. Esto asegura que un programa MPI puede continuar después de un error.

Ver la página man de MPI para una lista completa de códigos de error de MPI.

Ver la sección Manejo de Errores del estándar MPI-3.1 para más información.
