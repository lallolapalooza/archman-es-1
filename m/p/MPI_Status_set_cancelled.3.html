MPI_Status_set_cancelled(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_STATUS_SET_CANCELLED(3) Open MPI MPI_STATUS_SET_CANCELLED(3)

MPI_Status_set_cancelled — Establece status para indicar que una solicitud ha sido cancelada.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Status_set_cancelled(MPI_Status *status, int flag)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_STATUS_SET_CANCELLED(STATUS, FLAG, IERROR)
     INTEGER STATUS(MPI_STATUS_SIZE), IERROR
     LOGICAL FLAG

Sintaxis Fortran 2008

USE mpi_f08
MPI_Status_set_cancelled(status, flag, ierror)
     TYPE(MPI_Status), INTENT(INOUT) :: status
     LOGICAL, INTENT(OUT) :: flag
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO ENTRADA/SALIDA

•
status: Estado con el que asociar la bandera de cancelación (estado).

PARÁMETRO DE ENTRADA

•
flag: Si es verdadero, indica que la solicitud fue cancelada (lógico).

PARÁMETRO DE SALIDA

•
ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Si flag se establece a verdadero, entonces una llamada posterior a MPI_Test_cancelled(status, flag*) también devolverá flag = verdadero; de lo contrario, devolverá falso.

NOTAS

Se recomienda a los usuarios que no reutilicen los campos de estado para valores distintos de aquellos para los que fueron destinados. Hacerlo puede llevar a resultados inesperados al usar el objeto de estado. Por ejemplo, llamar a MPI_Get_elements puede causar un error si el valor está fuera de rango, o puede ser imposible detectar dicho error. El argumento extra_state proporcionado con una solicitud generalizada puede usarse para devolver información que no pertenece lógicamente a status. Además, modificar los valores en un estado establecido internamente por MPI, como MPI_Recv, puede llevar a resultados impredecibles y se desaconseja encarecidamente.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el controlador de errores inicial. El controlador de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, entonces el controlador de errores MPI_ERRORS_RETURN se llama para las funciones de E/S MPI y el controlador de errores MPI_ERRORS_ABORT se llama para todas las demás funciones MPI.

Open MPI incluye tres controladores de errores predefinidos que pueden usarse:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
