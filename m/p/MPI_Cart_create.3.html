MPI_Cart_create(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_CART_CREATE(3) Open MPI MPI_CART_CREATE(3)

MPI_Cart_create — Crea un nuevo comunicador al que se le adjunta información de topología Cartesiana.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Cart_create(MPI_Comm comm_old, int ndims, const int dims[],
    const int periods[], int reorder, MPI_Comm *comm_cart)

Sintaxis Fortran

USE MPI
! o la forma más antigua: INCLUDE 'mpif.h'
MPI_CART_CREATE(COMM_OLD, NDIMS, DIMS, PERIODS, REORDER,
        COMM_CART, IERROR)
    INTEGER COMM_OLD, NDIMS, DIMS(*), COMM_CART, IERROR
    LOGICAL PERIODS(*), REORDER

Sintaxis Fortran 2008

USE mpi_f08
MPI_Cart_create(comm_old, ndims, dims, periods, reorder, comm_cart, ierror)
    TYPE(MPI_Comm), INTENT(IN) :: comm_old
    INTEGER, INTENT(IN) :: ndims, dims(ndims)
    LOGICAL, INTENT(IN) :: periods(ndims), reorder
    TYPE(MPI_Comm), INTENT(OUT) :: comm_cart
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • comm_old : Comunicador de entrada (handle).
  • ndims : Número de dimensiones de la cuadrícula Cartesiana (entero).
dims
Array de enteros de tamaño ndims especificando el número de procesos en cada dimensión.
•
periods
Array lógico de tamaño ndims especificando si la cuadrícula es periódica (true) o no (false) en cada dimensión.
•
reorder
La clasificación puede ser reordenada (true) o no (false) (lógico).

PARÁMETROS DE SALIDA

  • comm_cart : Comunicador con nueva topología Cartesiana (handle).
  • ierror : Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Cart_create devuelve un handle a un nuevo comunicador al que se le adjunta la información de topología cartesiana. Si reorder = false, entonces el rango de cada proceso en el nuevo grupo es idéntico a su rango en el grupo antiguo. De lo contrario, la función puede reordenar los procesos (posiblemente para elegir una buena incrustación de la topología virtual en la máquina física). Si el tamaño total de la cuadrícula cartesiana es menor que el tamaño del grupo de comm, entonces algunos procesos devuelven MPI_COMM_NULL, en analogía con MPI_Comm_split. La llamada es errónea si especifica una cuadrícula que es más grande que el tamaño del grupo.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; rutinas C como el resultado de la función y rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de error MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay un objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de error MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el controlador de error inicial. El controlador de error inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento CLI mpiexec mpi_initial_errhandler o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de error apropiado, entonces se llama al controlador de error MPI_ERRORS_RETURN para las funciones de E/S MPI y al controlador de error MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres controladores de error predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de error que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de error llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
