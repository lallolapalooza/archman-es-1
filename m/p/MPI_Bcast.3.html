MPI_BCAST(3) Open MPI MPI_BCAST(3)

MPI_Bcast, MPI_Ibcast - Difunde un mensaje desde el proceso con rango root a todos los demás procesos del grupo.

SINTAXIS

Sintaxis en C

#include <mpi.h>
int MPI_Bcast(void *buffer, int count, MPI_Datatype datatype,
    int root, MPI_Comm comm)
int MPI_Ibcast(void *buffer, int count, MPI_Datatype datatype,
    int root, MPI_Comm comm, MPI_Request *request)

Sintaxis en Fortran

USE MPI
! o la forma más antigua: INCLUDE 'mpif.h'
MPI_BCAST(BUFFER, COUNT, DATATYPE, ROOT, COMM, IERROR)
    <type>  BUFFER(*)
    INTEGER COUNT, DATATYPE, ROOT, COMM, IERROR
MPI_IBCAST(BUFFER, COUNT, DATATYPE, ROOT, COMM, REQUEST, IERROR)
    <type>  BUFFER(*)
    INTEGER COUNT, DATATYPE, ROOT, COMM, REQUEST, IERROR

Sintaxis en Fortran 2008

USE mpi_f08
MPI_Bcast(buffer, count, datatype, root, comm, ierror)
    TYPE(*), DIMENSION(..) :: buffer
    INTEGER, INTENT(IN) :: count, root
    TYPE(MPI_Datatype), INTENT(IN) :: datatype
    TYPE(MPI_Comm), INTENT(IN) :: comm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Ibcast(buffer, count, datatype, root, comm, request, ierror)
    TYPE(*), DIMENSION(..), ASYNCHRONOUS :: buffer
    INTEGER, INTENT(IN) :: count, root
    TYPE(MPI_Datatype), INTENT(IN) :: datatype
    TYPE(MPI_Comm), INTENT(IN) :: comm
    TYPE(MPI_Request), INTENT(OUT) :: request
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA/SALIDA

  • buffer: Dirección de inicio del búfer (elección).
  • count: Número de entradas en el búfer (entero).
  • datatype: Tipo de datos del búfer (identificador).
  • root: Rango de la raíz de difusión (entero).
  • comm: Comunicador (identificador).

PARÁMETROS DE SALIDA

  • request: Solicitud (identificador, solo no bloqueante).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Bcast difunde un mensaje desde el proceso con rango root a todos los procesos del grupo, incluyéndose a sí mismo. Es llamado por todos los miembros del grupo utilizando los mismos argumentos para comm, root. Al regresar, el contenido del búfer de comunicación de root ha sido copiado a todos los procesos.

Se permiten tipos de datos generales y derivados para datatype. La firma del tipo de count, datatype en cualquier proceso debe ser igual a la firma del tipo de count, datatype en la raíz. Esto implica que la cantidad de datos enviados debe ser igual a la cantidad recibida, par a par entre cada proceso y la raíz. MPI_Bcast y todas las demás rutinas colectivas de movimiento de datos hacen esta restricción. Los tipos de mapas distintos entre remitente y receptor todavía están permitidos.

Ejemplo: Difundir 100 enteros desde el proceso 0 a cada proceso del grupo.

MPI_Comm comm;
int array[100];
int root=0;
//...
MPI_Bcast( array, 100, MPI_INT, root, comm);

Como en muchos de nuestros fragmentos de código de ejemplo, asumimos que algunas de las variables (como comm en el ejemplo anterior) han sido asignadas con valores apropiados.

CUANDO EL COMUNICADOR ES UN INTERCOMUNICADOR

Cuando el comunicador es un intercomunicador, el proceso raíz en el primer grupo difunde datos a todos los procesos del segundo grupo. El primer grupo define el proceso raíz. Ese proceso utiliza MPI_ROOT como valor de su argumento root. Los procesos restantes utilizan MPI_PROC_NULL como valor de su argumento root. Todos los procesos del segundo grupo utilizan el rango de ese proceso raíz en el primer grupo como valor de su argumento root. Los argumentos de búfer de recepción de los procesos del segundo grupo deben ser consistentes con el argumento de búfer de envío del proceso raíz en el primer grupo.

NOTAS

Esta función no soporta la opción in-place.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas de C como resultado de retorno de la función y las rutinas de Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error genera el controlador de errores inicial. El controlador de errores inicial puede ser cambiado llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento CLI mpi_initial_errhandler para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, entonces se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres controladores de errores predefinidos que pueden ser utilizados:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección Manejo de Errores del estándar MPI-3.1 para más información.
