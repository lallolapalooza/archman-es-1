MPI_T_cvar_read — Lee el valor de una variable de control

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_cvar_read(MPI_T_cvar_handle handle, const void *buf)

PARAMETROS DE ENTRADA

  • handle: Handle de la variable de control a leer.
  • buf: Dirección inicial de la ubicación de almacenamiento para el valor de la variable.

DESCRIPCION

MPI_T_cvar_read lee el valor de la variable de control identificada por el handle especificado en handle y almacena el valor en el buffer apuntado por buf. El llamante debe asegurarse de que el buffer apuntado por buf sea lo suficientemente grande como para contener el valor completo de la variable de control.

ERRORES

MPI_T_cvar_read fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_HANDLE: El handle no es válido.
