MPI_T_cvar_write — Escribe el valor de una variable de control vinculada

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_cvar_write(MPI_T_cvar_handle handle, const void *buf)

PARÁMETROS DE ENTRADA

  • handle: Identificador de la variable de control a escribir.
  • buf: Dirección inicial de la ubicación de almacenamiento para el valor de la variable.

DESCRIPCIÓN

MPI_T_cvar_write establece el valor de la variable de control identificada por el identificador especificado en handle desde el búfer proporcionado en buf. El llamante debe asegurarse de que el búfer especificado en buf sea lo suficientemente grande como para contener todo el valor de la variable de control. Si la variable tiene ámbito global, cualquier llamada de escritura debe emitirse en todos los procesos MPI conectados. Para más información, consulte la sección 14.3.6 de MPI-3.

ERRORES

MPI_T_cvar_write fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_HANDLE: El identificador no es válido.
  • MPI_T_ERR_CVAR_SET_NOT_NOW: La variable no se puede establecer en este momento.
  • MPI_T_ERR_CVAR_SET_NEVER: La variable no se puede establecer hasta el final de la ejecución.

VER TAMBIÉN:

  • MPI_T_cvar_handle_alloc
  • MPI_T_cvar_get_info
