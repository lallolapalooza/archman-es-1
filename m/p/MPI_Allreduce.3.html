MPI_Allreduce(3) Open MPI MPI_Allreduce(3)

MPI_Allreduce, MPI_Iallreduce, MPI_Allreduce_init - Combinan valores de todos los procesos y distribuyen el resultado de vuelta a todos los procesos.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Allreduce(const void *sendbuf, void *recvbuf, int count,
                  MPI_Datatype datatype, MPI_Op op, MPI_Comm comm)
int MPI_Iallreduce(const void *sendbuf, void *recvbuf, int count,
                   MPI_Datatype datatype, MPI_Op op, MPI_Comm comm,
                   MPI_Request *request)
int MPI_Allreduce_init(const void *sendbuf, void *recvbuf, int count,
                       MPI_Datatype datatype, MPI_Op op, MPI_Comm comm,
                       MPI_Info info, MPI_Request *request)

PARÁMETROS DE ENTRADA

  • sendbuf: Dirección de inicio del buffer de envío (opcional).
  • count: Número de elementos en el buffer de envío (entero).
  • datatype: Tipo de datos de los elementos del buffer de envío (handle).
  • op: Operación (handle).
  • comm: Comunicador (handle).
  • info: Información (handle, solo persistente).

PARÁMETROS DE SALIDA

  • recvbuf: Dirección de inicio del buffer de recepción (opcional).
  • request: Solicitud (handle, solo no bloqueante).
  • ierror: Solo en Fortran: Código de error (entero).

DESCRIPCIÓN

Más detallada que MPI_Reduce, excepto que el resultado se encuentra en el buffer de recepción de todos los miembros del grupo.

Ejemplo 1: Un rutina que calcula el producto de un vector y un array distribuidos entre un grupo de procesos y devuelve el resultado en todos los nodos (comparar con el Ejemplo 2, con MPI_Reduce, abajo).

SUBROUTINE PAR_BLAS2(m, n, a, b, c, comm)
REAL a(m), b(m,n)    ! parte local del array
REAL c(n)            ! resultado
REAL sum(n)
INTEGER n, comm, i, j, ierr
! suma local
DO j= 1, n
  sum(j) = 0.0
  DO i = 1, m
    sum(j) = sum(j) + a(i)*b(i,j)
  END DO
END DO
! suma global
CALL MPI_ALLREDUCE(sum, c, n, MPI_REAL, MPI_SUM, comm, ierr)
! devuelve resultado en todos los nodos
RETURN

Ejemplo 2: Un rutina que calcula el producto de un vector y un array distribuidos entre un grupo de procesos y devuelve el resultado en el nodo cero.

SUBROUTINE PAR_BLAS2(m, n, a, b, c, comm)
REAL a(m), b(m,n)    ! parte local del array
REAL c(n)            ! resultado
REAL sum(n)
INTEGER n, comm, i, j, ierr
! suma local
DO j= 1, n
  sum(j) = 0.0
  DO i = 1, m
    sum(j) = sum(j) + a(i)*b(i,j)
  END DO
END DO
! suma global
CALL MPI_REDUCE(sum, c, n, MPI_REAL, MPI_SUM, 0, comm, ierr)
! devuelve resultado en el nodo cero (y desecho en otros nodos)
RETURN

USO DE LA OPCION EN LUGAR DE LA BUFERA

Cuando el comunicador es un comunicador intracommunicador, puedes realizar una operación all-reduce en lugar de la buffer (el buffer de recepción se usa como el buffer de envío). Usa la variable MPI_IN_PLACE como el valor de sendbuf en todos los procesos.

Nota: MPI_IN_PLACE es un tipo especial de valor; tiene las mismas restricciones que MPI_BOTTOM.

Dado que la opción en lugar de la buffer convierte el buffer de recepción en un buffer de envío y recepción, una vinculación de Fortran que incluya INTENT debe marcar estos como INOUT, no como OUT.

CUANDO EL COMUNICADOR ES UN COMUNICADOR INTER

Cuando el comunicador es un comunicador inter, la operación de reducción ocurre en dos etapas. Los datos son reducidos de todos los miembros del primer grupo y recibidos por todos los miembros del segundo grupo. Luego, los datos son reducidos de todos los miembros del segundo grupo y recibidos por todos los miembros del primer. La operación muestra un comportamiento simétrico, de dupla dirección.

Cuando el comunicador es un comunicador intracommunicador, estos grupos son los mismos y la operación ocurre en una sola etapa.

NOTAS SOBRE LAS OPERACIONES COLLECTIVAS

Las funciones de reducción (MPI_Op) no devuelven un valor de error. Por lo tanto, si detectan un error, lo único que pueden hacer es llamar a MPI_Abort o pasar silenciosamente el problema. Así, si cambias el manejador de errores de MPI_ERRORS_ARE_FATAL a algo más, por ejemplo, MPI_ERRORS_RETURN, entonces no se indicará ningún error.

ERRORES

Más de casi todas las rutinas MPI devuelven un valor de error; C rutinas lo devuelve como el resultado de la función y las rutinas Fortran en el último argumento.

Antes de que el valor de error sea devuelto, se llama al manejador de error asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) del proceso actual. Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y llamará al manejador de error asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se use el modelo de Sesiones exclusivamente), el error levanta el manejador de error inicial. El manejador de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se use el modelo del Mundo, o el argumento CLI mpi_initial_errhandler para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de error apropiado, se llama el manejador de error MPI_ERRORS_RETURN para las funciones de I/O de MPI y el manejador de error MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de error predeterminados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL Deja que el programa aborte todos los procesos conectados a MPI.
  • MPI_ERRORS_ABORT Un manejador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador.

SINTAXIS

La sintaxis siguiente contiene la lista de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.

  • MPI_Comm_create_errhandler seguido de MPI_Comm_set_errhandler
  • MPI_File_create_errhandler seguido de MPI_File_set_errhandler
  • MPI_Session_create_errhandler seguido de MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler seguido de MPI_Win_set_errhandler

Nota: MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la sección de Manejo de Errores de la documentación MPI-3.1 para más información.
