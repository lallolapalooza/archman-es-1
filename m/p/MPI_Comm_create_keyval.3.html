MPI_Comm_create_keyval(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_COMM_CREATE_KEYVAL(3) Open MPI MPI_COMM_CREATE_KEYVAL(3)

MPI_Comm_create_keyval — Genera una nueva clave de atributo.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Comm_create_keyval(MPI_Comm_copy_attr_function
    *comm_copy_attr_fn, MPI_Comm_delete_attr_function
    *comm_delete_attr_fn, int *comm_keyval,
    void *extra_state)

Sintaxis Fortran

USE MPI
! o la forma más antigua: INCLUDE 'mpif.h'
MPI_COMM_CREATE_KEYVAL(COMM_COPY_ATTR_FN, COMM_DELETE_ATTR_FN,
    COMM_KEYVAL, EXTRA_STATE, IERROR)
    EXTERNAL COMM_COPY_ATTR_FN, COMM_DELETE_ATTR_FN
    INTEGER COMM_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_create_keyval(comm_copy_attr_fn, comm_delete_attr_fn, comm_keyval,
        extra_state, ierror)
    PROCEDURE(MPI_Comm_copy_attr_function) :: comm_copy_attr_fn
    PROCEDURE(MPI_Comm_delete_attr_function) :: comm_delete_attr_fn
    INTEGER, INTENT(OUT) :: comm_keyval
    INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: extra_state
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETROS DE ENTRADA

•
comm_copy_attr_fn
Función de callback de copia para comm_keyval (función).
•
comm_delete_attr_fn
Función de callback de eliminación para comm_keyval (función).
•
extra_state : Estado adicional para las funciones de callback.

PARAMETRO DE SALIDA

  • comm_keyval : Valor de la clave para acceso futuro (entero).
  • ierror : Solo Fortran: Estado del error (entero).

DESCRIPCION

Esta función reemplaza a MPI_Keyval_create, cuyo uso está obsoleto. La vinculación C es idéntica. La vinculación Fortran difiere en que extra_state es un entero del tamaño de una dirección. Además, las funciones de callback de copia y eliminación tienen vinculaciones Fortran que son consistentes con los atributos del tamaño de una dirección. El argumento comm_copy_attr_fn puede especificarse como MPI_COMM_NULL_COPY_FN o MPI_COMM_DUP_FN desde C o Fortran. MPI_COMM_NULL_COPY_FN es una función que no hace nada más que devolver flag = 0 y MPI_SUCCESS. MPI_COMM_DUP_FN es una función de copia simple que establece flag = 1, devuelve el valor de attribute_val_in en attribute_val_out y devuelve MPI_SUCCESS. Estas reemplazan las callbacks predefinidas de MPI-1 MPI_NULL_COPY_FN y MPI_DUP_FN, cuyo uso está obsoleto. Las dos funciones de callback C son:

typedef int MPI_Comm_copy_attr_function(MPI_Comm oldcomm, int comm_keyval,
             void *extra_state, void *attribute_val_in,
             void *attribute_val_out, int *flag);
typedef int MPI_Comm_delete_attr_function(MPI_Comm comm, int comm_keyval,
             void *attribute_val, void *extra_state);

que son las mismas que las llamadas de MPI-1.1 pero con un nuevo nombre. Los nombres antiguos están obsoletos. Las dos funciones de callback Fortran son:

SUBROUTINE COMM_COPY_ATTR_FN(OLDCOMM, COMM_KEYVAL, EXTRA_STATE,
             ATTRIBUTE_VAL_IN, ATTRIBUTE_VAL_OUT, FLAG, IERROR)
    INTEGER OLDCOMM, COMM_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE, ATTRIBUTE_VAL_IN,
        ATTRIBUTE_VAL_OUT
    LOGICAL FLAG
SUBROUTINE COMM_DELETE_ATTR_FN(COMM, COMM_KEYVAL, ATTRIBUTE_VAL, EXTRA_STATE,
             IERROR)
    INTEGER COMM, COMM_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) ATTRIBUTE_VAL, EXTRA_STATE

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado del retorno de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento CLI mpi_initial_errhandler a mpiexec o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y se llama al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Hace que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.

MPI_Comm_create_keyval(3)

NOMBRE

MPI_Comm_create_keyval - Crea un nuevo valor de clave de comunicador.

SINÓPSIS

int MPI_Comm_create_keyval(MPI_Comm_copy_attr_function *copy_fn, MPI_Comm_delete_attr_function *delete_fn, int *keyval, void *extra_state)

DESCRIPCIÓN

MPI_Comm_create_keyval crea un nuevo valor de clave de comunicador y lo devuelve en keyval. Este valor de clave se puede utilizar para asociar atributos con comunicadores. Los atributos son pares de clave-valor que se pueden adjuntar a objetos MPI. Cada objeto MPI tiene un conjunto de atributos que se pueden acceder mediante valores de clave. Los valores de clave se utilizan para identificar atributos únicos.

Cuando se duplica un comunicador utilizando MPI_Comm_dup o MPI_Comm_split, los atributos asociados se copian utilizando la función de copia especificada en copy_fn. Si copy_fn es MPI_COMM_NULL_COPY_FN, no se copian los atributos. La función de copia se llama con el comunicador de origen, el valor de clave, el estado adicional y un puntero al valor del atributo de destino. La función de copia debe devolver el valor del atributo de destino.

Cuando se destruye un comunicador, los atributos asociados se eliminan utilizando la función de eliminación especificada en delete_fn. Si delete_fn es MPI_COMM_NULL_DELETE_FN, no se eliminan los atributos. La función de eliminación se llama con el comunicador, el valor de clave y el estado adicional. La función de eliminación puede liberar cualquier recurso asociado con el atributo.

El parámetro extra_state se puede utilizar para pasar información adicional a las funciones de copia y eliminación.

ERRORES

Cuando ocurre un error, el nombre del subrutina aplicable es MPI_Comm_create_keyval.

MPI_ERR_NO_MEM: No hay suficiente memoria disponible.
