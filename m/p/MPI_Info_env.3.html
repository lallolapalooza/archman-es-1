MPI_Info_env — Objeto MPI_Info estático que contiene información sobre la aplicación

DESCRIPCIÓN

El estándar MPI-3 estableció un objeto MPI_Info estático llamado MPI_Info_env que puede usarse para acceder a información sobre cómo se ejecutó la aplicación desde el tiempo de ejecución.

CAMPOS SOPORTADOS

command
Si está disponible, el valor se establecerá en argv[0]. Tenga en cuenta que el valor puede no estar siempre disponible; por ejemplo, es válido que un programa llame a MPI_Init con parámetros NULL, en cuyo caso argv[0] no se establecerá si se ejecuta como un singleton. Este valor nunca se establecerá en un programa Fortran ya que los argv no están disponibles.
argv
Los argumentos argv proporcionados para la aplicación. Si no se pasan argumentos a la aplicación, este valor no se establecerá. Tampoco se establecerá en el caso de un singleton que llame a MPI_Init con parámetros NULL, o un programa Fortran.
maxprocs
El número de procesos en el trabajo.
soft
Open MPI no admite la opción soft para especificar el número de procesos a ejecutar, por lo que este valor se establece igual que maxprocs.
host
El nombre del host en el que se está ejecutando el proceso; el valor devuelto por gethostname().
arch
La arquitectura del host en el que se está ejecutando el proceso. Este valor indica la arquitectura del chip subyacente (por ejemplo, x86_64), si se puede determinar.
wdir
El directorio de trabajo en el momento del lanzamiento del proceso por mpiexec. Tenga en cuenta que este valor no se establecerá para los procesos lanzados como singletons, ya que no hay una forma fiable para que la biblioteca MPI determine la ubicación.
file
Aunque especificado por el estándar MPI-3, actualmente no se establece ningún valor para este campo.
thread_level
El nivel de hilo MPI solicitado; tenga en cuenta que este puede diferir del nivel de hilo MPI real de la aplicación.
ompi_num_apps
El número de contextos de aplicación en un trabajo MPMD. Este es un campo y valor específico de Open MPI.
ompi_np
El número de procesos en cada contexto de aplicación, proporcionado como una lista de enteros separada por espacios. Este es un campo y valor específico de Open MPI.
ompi_first_rank
El rango MPI del primer proceso en cada contexto de aplicación, proporcionado como una lista de enteros separada por espacios. Este es un campo y valor específico de Open MPI.
ompi_positioned_file_dir
Si a Open MPI se le pidió pre-posicionar archivos, este campo proporciona el directorio de nivel superior donde se colocaron esos archivos. Este es un campo y valor específico de Open MPI.

ERRORES

Al llamar a MPI_Info_get, el parámetro flag se establecerá en cero
(falso) si no se ha establecido un valor para el campo.
