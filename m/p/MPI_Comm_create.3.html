MPI_Comm_create(3) Open MPI MPI_Comm_create(3)

MPI_Comm_create — Crea un nuevo comunicador.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Comm_create(MPI_Comm comm, MPI_Group group, MPI_Comm *newcomm)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_COMM_CREATE(COMM, GROUP, NEWCOMM, IERROR)
    INTEGER COMM, GROUP, NEWCOMM, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_create(comm, group, newcomm, ierror)
    TYPE(MPI_Comm), INTENT(IN) :: comm
    TYPE(MPI_Group), INTENT(IN) :: group
    TYPE(MPI_Comm), INTENT(OUT) :: newcomm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA

  • comm : Comunicador (manejador).
  • group : Grupo, que es un subconjunto del grupo de comm (manejador).

PARÁMETROS DE SALIDA

  • newcomm : Nuevo comunicador (manejador).
  • ierror : Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Esta función crea un nuevo comunicador newcomm con un grupo de comunicación definido por group y un nuevo contexto. La función asigna newcomm a un nuevo comunicador que abarca todos los procesos que están en el grupo. Asigna newcomm a MPI_COMM_NULL para los procesos que no están en el grupo. Cada proceso debe llamar con un argumento group que sea un subgrupo del grupo asociado a comm; este podría ser MPI_GROUP_EMPTY. Los procesos pueden especificar valores diferentes para el argumento group. Si un proceso llama con un grupo no vacío, entonces todos los procesos de ese grupo deben llamar a la función con el mismo grupo como argumento, es decir: los mismos procesos en el mismo orden. De lo contrario, la llamada es errónea.

NOTAS

MPI_Comm_create proporciona un medio para crear un subconjunto de procesos para el propósito de cómputo MIMD separado, con espacio de comunicación separado. newcomm, que es creado por MPI_Comm_create, puede ser usado en llamadas subsiguientes a MPI_Comm_create (u otros constructores de comunicadores) para subdividir aún más un cómputo en sub-cálculos paralelos. Un servicio más general es proporcionado por MPI_Comm_split.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas en C como resultado de retorno de la función y las rutinas en Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/ MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial puede ser cambiado llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos mpi_initial_errhandler de mpiexec o la clave de información de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que pueden ser usados:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si MPI_Abort fuera llamado en ese comunicador. Si se llama en una ventana o archivo, actúa como si MPI_Abort fuera llamado en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Vea la página del manual de MPI para una lista completa de los códigos de error MPI.

Vea la sección de Manejo de Errores del estándar MPI-3.1 para más información.
