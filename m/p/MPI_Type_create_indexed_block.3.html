MPI_Type_create_indexed_block(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_TYPE_CREATE_INDEXED_BLOCK(3) Open MPI MPI_TYPE_CREATE_INDEXED_BLOCK(3)

MPI_Type_create_indexed_block, MPI_Type_create_hindexed_block - Crea un tipo de datos indexado con la misma longitud de bloque para todos los bloques.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Type_create_indexed_block(int count, int blocklength, const int array_of_displacements[], MPI_Datatype oldtype, MPI_Datatype *newtype)
int MPI_Type_create_hindexed_block(int count, int blocklength, const MPI_Aint array_of_displacements[], MPI_Datatype oldtype, MPI_Datatype *newtype)

Sintaxis Fortran

USE MPI
! o la forma anterior: INCLUDE 'mpif.h'
MPI_TYPE_CREATE_INDEXED_BLOCK(COUNT, BLOCKLENGTH,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, BLOCKLENGTH, ARRAY_OF_DISPLACEMENTS(*),
             OLDTYPE, NEWTYPE, IERROR
MPI_TYPE_CREATE_HINDEXED_BLOCK(COUNT, BLOCKLENGTH,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, BLOCKLENGTH, OLDTYPE, NEWTYPE
     INTEGER(KIND=MPI_ADDRESS_KIND) ARRAY_OF_DISPLACEMENTS(*)
     INTEGER IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Type_create_indexed_block(count, blocklength, array_of_displacements,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, blocklength,
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Type_create_hindexed_block(count, blocklength, array_of_displacements,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, blocklength
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) ::
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • count: Longitud del array de desplazamientos (entero).
  • blocklength: Tamaño del bloque (entero).
  • array_of_displacements: Array de desplazamientos (array de enteros). En unidades de la extensión de oldtype para MPI_Type_create_indexed_block y en bytes para MPI_Type_create_hindexed_block.
  • oldtype: Tipo de datos antiguo (handle).

PARÁMETROS DE SALIDA

  • newtype: Nuevo tipo de datos (handle).
  • ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

MPI_Type_create_indexed_block y MPI_Type_create_hindexed_block crean un tipo de datos indexado con la misma longitud de bloque para todos los bloques. La única diferencia entre las dos funciones es que MPI_Type_create_indexed_block toma un array de desplazamientos en unidades de la extensión de oldtype, mientras que MPI_Type_create_hindexed_block toma desplazamientos en bytes.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el controlador de errores inicial. El controlador de errores inicial puede ser cambiado llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler para mpiexec o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, entonces se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
