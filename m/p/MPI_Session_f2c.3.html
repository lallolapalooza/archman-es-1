MPI_SESSION_F2C(3) Open MPI MPI_SESSION_F2C(3)

MPI_Session_c2f, MPI_Session_f2c - Convierte un manejador de sesión C en un manejador de sesión tipo INTEGER de Fortran, o viceversa.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Session_f2c(const MPI_Fint *f_session, MPI_Session *c_session)
int MPI_Session_c2f(const MPI_Session *c_session, MPI_Fint *f_session)

PARÁMETROS

  • f_session: Objeto de sesión MPI estilo mpi INTEGER.
  • c_session: Objeto de sesión MPI estilo C.

DESCRIPCIÓN

Estos dos procedimientos se proporcionan en C para convertir una sesión de Fortran (que es un array de enteros) a una sesión de C (que es una estructura), y viceversa. La conversión afecta a toda la información en session, incluida la que está oculta. Es decir, no se pierde información de la sesión en la conversión.

Al usar MPI_Session_f2c(), si f_session es una sesión de Fortran válida, entonces MPI_Session_f2c() devuelve en c_session una sesión de C válida con el mismo contenido. Si f_session es el valor de Fortran de MPI_SESSION_NULL, o si f_session no es una sesión de Fortran válida, entonces la llamada es errónea.

Al usar MPI_Session_c2f(), se aplica la conversión opuesta. Si c_session es MPI_SESSION_NULL, o si c_session no es una sesión de C válida, entonces la llamada es errónea.

NOTAS

Estas funciones solo están disponibles en C; no están disponibles en ninguna de las interfaces Fortran de MPI.
