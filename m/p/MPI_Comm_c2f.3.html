DESCRIPCIÓN

Los identificadores se pasan entre Fortran y C utilizando un envoltorio C explícito para convertir los identificadores de Fortran a identificadores C. No hay acceso directo a los identificadores C en Fortran. El tipo de definición MPI_Fint se proporciona en C para un entero del tamaño que coincide con un INTEGER de Fortran; normalmente, MPI_Fint será equivalente a int. Las funciones de traducción de identificadores se proporcionan en C para convertir de un identificador Fortran (que es un entero) a un identificador C, y viceversa.

Por ejemplo, si comm es un identificador Fortran válido para un comunicador, entonces MPI_Comm_f2c devuelve un identificador C válido para el mismo comunicador; si comm = MPI_COMM_NULL (valor de Fortran), entonces MPI_Comm_f2c devuelve un identificador C nulo; si comm es un identificador Fortran inválido, entonces MPI_Comm_f2c devuelve un identificador C inválido.

NOTA

Esta función no devuelve un valor de error. En consecuencia, el resultado de llamarla antes de MPI_Init o después de MPI_Finalize no está definido.
