MPI_T_ENUM_GET_INFO(3) Open MPI MPI_T_ENUM_GET_INFO(3)

MPI_T_enum_get_info — Consultar información sobre un enumerador

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_enum_get_info(MPI_T_enum enumtype, int *num, char *name, int *name_len)

PARÁMETROS DE ENTRADA

•
enumtype: Enumerador a consultar.

PARÁMETROS DE ENTRADA/SALIDA

•
name_len: Longitud de la cadena y/o buffer para el nombre.

PARÁMETROS DE SALIDA

  • num: número de valores discretos representados por esta enumeración.
  • name: Buffer para devolver la cadena que contiene el nombre de la categoría.

DESCRIPCIÓN

MPI_T_enum_get_info se puede utilizar para consultar información sobre un enumerador. La función devuelve el número de valores discretos representados por este enumerador en el parámetro num.

NOTAS

Esta función de interfaz de herramientas MPI devuelve el nombre de la enumeración como una cadena de caracteres. Esta función toma dos argumentos para la cadena: name, que especifica un buffer donde se debe almacenar el nombre, y name_len, que debe especificar inicialmente el tamaño del buffer apuntado por name. Esta función copiará como máximo name_len - 1 caracteres del nombre y establecerá name_len en el número de caracteres devueltos + 1. Si name_len es NULL o el valor especificado en name_len es 0, se ignora el buffer name y no se devuelve el nombre de la enumeración.

ERRORES

MPI_T_enum_get_info fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de Herramientas MPI no está inicializada
  • MPI_T_ERR_INVALID_INDEX: La enumeración no es válida o ha sido eliminada
