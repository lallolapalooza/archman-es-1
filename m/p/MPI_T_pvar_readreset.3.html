MPI_T_pvar_readreset — Lee y restablece el valor de una variable de rendimiento de forma atómica

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_pvar_readreset(MPI_T_pvar_session session, MPI_T_pvar_handle handle, const void *buf)

PARÁMETROS DE ENTRADA

  • session: Sesión de experimento de rendimiento.
  • handle: Identificador de la variable de rendimiento.
  • buf: Dirección inicial de la ubicación de almacenamiento para el valor de la variable.

DESCRIPCIÓN

MPI_T_pvar_readreset consulta y restablece de forma atómica el valor de una variable de rendimiento asociada al identificador especificado por handle en la sesión especificada por session. El resultado se almacena en el búfer al que apunta buf. Esta función solo se puede utilizar con variables de rendimiento que sean atómicas y no de solo lectura. El llamador debe asegurarse de que el búfer apuntado por buf sea lo suficientemente grande para contener el valor completo de la variable de rendimiento.

ERRORES

MPI_T_pvar_readreset fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada
  • MPI_T_ERR_INVALID_HANDLE: El identificador no es válido o no está asociado con la sesión
  • MPI_T_ERR_INVALID_SESSION: El argumento session no es una sesión válida
  • MPI_T_ERR_PVAR_NO_ATOMIC: La variable no se puede leer y escribir de forma atómica
  • MPI_T_ERR_PVAR_NO_WRITE: La variable no se puede restablecer
