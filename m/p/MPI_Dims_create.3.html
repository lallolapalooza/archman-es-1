MPI_Dims_create(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_Dims_create(3) Open MPI MPI_Dims_create(3)

MPI_Dims_create — Crea una división de procesadores en un espacio de coordenadas cartesiano.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Dims_create(int nnodes, int ndims, int dims[])

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_DIMS_CREATE(NNODES, NDIMS, DIMS, IERROR)
     INTEGER NNODES, NDIMS, DIMS(*), IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Dims_create(nnodes, ndims, dims, ierror)
     INTEGER, INTENT(IN) :: nnodes, ndims
     INTEGER, INTENT(INOUT) :: dims(ndims)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

  • nnodes: Número de nodos en una red de coordenadas (entero).
  • ndims: Número de dimensiones cartesianas (entero).

Parámetro de entrada/salida

•
dims: Array de enteros de tamaño ndims que especifican el número de nodos en cada dimensión.

Parámetro de salida

•
ierror: Solo en Fortran: Código de estado de error (entero).

Descripción

Para topologías cartesianas, la función MPI_Dims_create ayuda al usuario a seleccionar una distribución equilibrada de procesos por cada dirección de coordenada, dependiendo del número de procesos en el grupo a equilibrar y las restricciones que el usuario puede especificar. Una aplicación común es dividir todos los procesos (el tamaño del grupo de MPI_COMM_WORLD) en una topología n-dimensional.

Los valores en el array dims se establecen para describir una red de coordenadas cartesianas con ndims dimensiones y un total de nnodes nodos. Los valores se establecen de manera tan cercanas como sea posible, utilizando un algoritmo adecuado de divisibilidad. El llamante puede aún constrictir el comportamiento de esta rutina especificando elementos del array dims. Si dims[i] es establecido a un número positivo, la rutina no modificará el número de nodos en la dirección i; solo aquellos entradas donde dims[i] = 0 son modificadas por el llamante.

Valores negativos de dims[i] son errores. Se produce un error si nnodes no es múltiplo de ((pi) / (i, dims[i] != 0)).

Para dims[i] establecido por el llamante, dims[i] se ordena en orden no creciente. El array dims es adecuado para uso como entrada en la rutina MPI_Cart_create. MPI_Dims_create es local.

Ejemplo:

dims
antes                                     dims
llamada         función                  después
-----------------------------------------------------
(0,0)           MPI_Dims_create(6, 2, dims)     (3,2)
(0,0)           MPI_Dims_create(7, 2, dims)     (7,1)
(0,3,0)         MPI_Dims_create(6, 3, dims)     (2,3,1)
(0,3,0)         MPI_Dims_create(7, 3, dims)     llamada errónea
------------------------------------------------------

Errores

La mayoría de las rutinas MPI devuelven un valor de error; en C, el valor de retorno de la función; en Fortran, el último argumento de la rutina.

Antes de devolver el valor de error, se llama al manejador de errores asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) relacionado con el llamado. Si no hay objeto de comunicación asociado con el llamado MPI, se considera que el llamado está asociado a MPI_COMM_SELF y llamará al manejador de errores correspondiente. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza el Modelo de Sesiones exclusivamente), se levanta el manejador de errores inicial. El manejador de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se use el Modelo del Mundo, o a través del parámetro mpi_initial_errhandler en mpiexec o a la clave info en MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de error adecuado, se llama el manejador de errores MPI_ERRORS_RETURN para las funciones de I/O MPI y el manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predeterminados que pueden utilizarse:

  • MPI_ERRORS_ARE_FATAL — Detiene todos los procesos conectados a MPI.
  • MPI_ERRORS_ABORT — Manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, detiene solo el proceso local.
  • MPI_ERRORS_RETURN — Devuelve un código de error a la aplicación.

Los aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: Los programas MPI no garantizan que puedan continuar después de un error.

Para una lista completa de códigos de error MPI, vea la página de man de MPI.

Para más información sobre los manejadores de errores, vea la sección de manejo de errores de la norma MPI-3.1.
