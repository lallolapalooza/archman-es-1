MPI_Comm_test_inter(3) Open MPI MPI_Comm_test_inter(3)

MPI_Comm_test_inter — Prueba si un comunicador es un intercommunicador.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Comm_test_inter(MPI_Comm comm, int *flag)

Sintaxis Fortran

USE MPI
! o la antigua forma: INCLUDE 'mpif.h'
MPI_COMM_TEST_INTER(COMM, FLAG, IERROR)
     INTEGER COMM, IERROR
     LOGICAL FLAG

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_test_inter(comm, flag, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     LOGICAL, INTENT(OUT) :: flag
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

•
comm: Comunicador (handle).

Parámetros de salida

  • flag (Lógico.):
  • ierror: Solo Fortran: Estado de error (entero).

Descripción

Esta rutina local permite a la aplicación determinar el tipo de un comunicador. Devuelve verdadero para un intercommunicador, falso para un intracommunicador.

El tipo de comunicador también afecta el valor devuelto por tres funciones más. Cuando se trata de un intracommunicador (permite comunicación dentro de un grupo), las siguientes funciones devuelven los valores esperados: tamaño del grupo, grupo y rango. Cuando se trata de un intercommunicador, sin embargo, devuelven los siguientes valores:

MPI_Comm_size
Devuelve el tamaño del grupo local.
MPI_Comm_group
Devuelve el grupo local.
MPI_Comm_rank
Devuelve el rango en el grupo local.

Para devolver el grupo remoto y el tamaño del grupo remoto de un intercommunicador, usa las funciones MPI_Comm_remote_group y MPI_Comm_remote_size.

La operación MPI_Comm_compare es válida para intercommunicadores. Ambos comunicadores deben ser intracommunicadores o intercommunicadores, o se obtendrá MPI_UNEQUAL. Ambos grupos locales y remotos deben compararse correctamente para obtener los resultados MPI_CONGRUENT y MPI_SIMILAR. Es posible que MPI_SIMILAR se obtenga porque el grupo local o el remoto fuera similar pero no idéntico.

Los accesorios de intercommunicador (MPI_Comm_test_inter, MPI_Comm_remote_size, MPI_Comm_remote_group) son todas operaciones locales.

Errores

Más de casi todas las rutinas MPI devuelven un valor de error; en las rutinas C, el valor de error se devuelve como resultado de la función y en las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama a la función de manejo de errores asociada con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) que está en uso. Si no hay ningún objeto de comunicación asociado con la llamada MPI, se considera que la llamada se está asociando con MPI_COMM_SELF y se llama al manejador de errores correspondiente. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa el modelo de Sesiones exclusivamente), el error eleva el manejador de errores inicial. El manejador de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se usa el modelo del Mundo, o a través del argumento mpi_initial_errhandler de mpiexec o la clave de info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay ningún otro manejador de errores adecuado establecido, se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predeterminados que pueden ser utilizados:

  • MPI_ERRORS_ARE_FATAL hace que la ejecución de todos los procesos MPI conectados se aborte.
  • MPI_ERRORS_ABORT un manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: Los manejadores de errores de MPI no garantizan que una aplicación MPI pueda continuar después de un error.

Ver la sección de Gestión de Errores de la documentación de MPI-3.1 para más información.
