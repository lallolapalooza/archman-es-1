NAME

MP3::Info - Manipular o recuperar información de archivos de audio MP3

SYNOPSIS

#!perl -w
use MP3::Info;
my $file = 'Pearls_Before_Swine.mp3';
set_mp3tag($file, 'Pearls Before Swine', q"77's",
        'Sticks and Stones', '1990',
        q"(c) 1990 77's LTD.", 'rock & roll');
my $tag = get_mp3tag($file) or die "No TAG info";
$tag->{GENRE} = 'rock';
set_mp3tag($file, $tag);
my $info = get_mp3info($file);
printf "$file length is %d:%d\n", $info->{MM}, $info->{SS};
my $mp3 = new MP3::Info $file;
$mp3->title('Perls Before Swine');
printf "$file length is %s, title is %s\n",
        $mp3->time, $mp3->title;

DESCRIPCIÓN

$mp3 = MP3::Info->new(FILE)
Interfaz OOP para el resto de la librería. Las mismas claves disponibles mediante get_mp3info y get_mp3tag están disponibles en el objeto devuelto (en mayúsculas o minúsculas; pero notar que el valor "VERSION" devuelve la versión de la librería, no la de MP3).

Pasando un valor a una de las funciones cambiará el valor para ese tag en el archivo MP3.

use_mp3_utf8([STATUS])
Indica a MP3::Info (o no) devolver información de etiquetas en UTF-8. TRUE es 1, FALSE es 0. El valor por defecto es TRUE si está disponible.

Solo podrá habilitarlo si el módulo Encode está disponible. Las etiquetas ID3v2 se convertirán a UTF-8 según la codificación especificada en cada etiqueta; las etiquetas ID3v1 se considerarán en latín-1 y se convertirán a UTF-8.

La función devuelve el estado (TRUE/FALSE). Si no se especifica ningún argumento o se especifica un argumento no aceptado, la función devuelve simplemente el estado.

Esta función no es exportada por defecto, pero puede ser exportada con el etiquetado ":utf8" o ":all".

use_winamp_genres()
Coloca géneros de WinAmp en @mp3_genres y %mp3_genres (añade 68 géneros adicionales a la lista predeterminada de 80). Este es un funcionamiento separado porque estos son géneros no estándar, pero están incluidos debido a su amplia utilización.

Puedes importar las estructuras de datos con uno de los siguientes:

use MP3::Info qw(:genres);
use MP3::Info qw(:DEFAULT :genres);
use MP3::Info qw(:all);
remove_mp3tag (FILE [, VERSION, BUFFER])
Podría eliminar etiquetas ID3v1 o ID3v2. VERSION debe ser 1 para ID3v1 (el valor por defecto), 2 para ID3v2, y "ALL" para ambos.

Para ID3v1, elimina los últimos 128 bytes del archivo si estos comienzan con el texto 'TAG'. El archivo será 128 bytes más corto.

Para ID3v2, elimina la etiqueta ID3v2. Como una etiqueta ID3v2 está al inicio del archivo, se reescribe el archivo después de eliminar los datos de la etiqueta. El buffer para reescribir el archivo es de 4MB. El valor del buffer (en bytes) puede cambiar el tamaño del buffer.

Devuelve el número de bytes eliminados, o -1 si no se eliminó ningún tag, o undef si hay un error.

set_mp3tag (FILE, TITLE, ARTIST, ALBUM, YEAR, COMMENT, GENRE [, TRACKNUM])
set_mp3tag (FILE, $HASHREF)
Añade o cambia información de etiqueta en un archivo de audio MP3. Sobrescribe cualquier información existente en el archivo.

Los campos son TITLE, ARTIST, ALBUM, YEAR, COMMENT, GENRE. Todos los campos tienen un límite de 30 bytes, excepto YEAR, que tiene un límite de 4 bytes, y GENRE, que es un campo en el archivo. El género pasado en la función es una cadena de texto en minúsculas, representando un género encontrado en @mp3_genres.

Puedes pasar una lista de valores o un hashref de tipo devuelto por "get_mp3tag".

Si TRACKNUM es presente (para ID3v1.1), el campo COMMENT puede tener solo 28 bytes.

El soporte de ID3v2 puede llegar eventualmente. Nota: si estableces una etiqueta en un archivo con ID3v2, la etiqueta establecida será solo para ID3v1[.1], y si llamas "get_mp3tag" en el archivo, mostrará la (etiqueta no modificada) ID3v2, a menos que especifiques ID3v1.

get_mp3tag (FILE [, VERSION, RAW_V2, APE2])
Devuelve un hash reference con la información de etiqueta de un archivo de audio MP3. Los campos devueltos son los mismos que los proporcionados en "set_mp3tag", excepto en el caso de RAW_V2.

Si VERSION es 1, la información se obtiene de la etiqueta ID3v1 (si está presente). Si VERSION es 2, la información se obtiene de la etiqueta ID3v2 (si está presente). Si VERSION no se especifica o es false, se lee la etiqueta ID3v1 (si está presente) y luego, si está presente, se sobrescribe cualquier información de la etiqueta ID3v1 existente.

Si RAW_V2 es 1, se devuelve los datos de la etiqueta ID3v2 sin manipulación de la codificación del texto. El nombre del campo es el mismo que el ID de la etiqueta (ID a nombre de las etiquetas en el global %v2_tag_names).

Si RAW_V2 es 2, se devuelve los datos de la etiqueta ID3v2, que se manipulan para Unicode si es necesario, etc. También acepta múltiples valores para un campo dado (como comentarios) y los coloca en un arrayref.

Si APE es 1, se encuentra una etiqueta APE antes de cualquier otra etiqueta.

Si el número de versión de ID3v2 es menor que ID3v2.2.0 o mayor que ID3v2.4.0, no se leerá la información.

Las cadenas devueltas serán en latín-1, a menos que se especifique UTF-8 (us_mp3_utf8), (a menos que RAW_V2 sea 1).

También devuelve una clave TAGVERSION, que contiene la versión ID3 usada para los datos devueltos (si el argumento TAGVERSION es 0, puede contener dos versiones).

get_mp3info (FILE)
Devuelve un hash reference con la información del archivo de audio de MP3. Esta información no puede modificarse. Los datos devueltos incluyen: 
VERSION         Versión de audio MPEG (1, 2, 2.5)
LAYER           Descripción de la capa MPEG (1, 2, 3)
STEREO          Verdadero si el audio está en stereo
VBR             Verdadero si el bitrate es variable
BITRATE         Bitrate en kbps (promedio para archivos VBR)
FREQUENCY       Frecuencia en kHz
SIZE            Bytes en la stream de audio
OFFSET          Offset en bytes donde comienza la stream
SECS            Total segundos
MM              Minutos
SS              Segundos restantes
MS              Milisegundos restantes
TIME            Tiempo en MM:SS
COPYRIGHT       Verdadero si el audio está protegido por derechos de autor
PADDING         Verdadero si los frames de MP3 están rellenados
MODE            Modo de canal (0 = stereo, 1 = joint stereo,
                2 = dual channel, 3 = single channel)
FRAMES          Número aproximado de frames
FRAME_LENGTH    Tamaño aproximado de un frame
VBR_SCALE       Escala de VBR desde el encabezado de VBR

En caso de error, devuelve nada y establece $@.

SOLUCIONES DE PROBLEMAS

Si encuentras un error, por favor envía un parche (ver la página del proyecto en "SEE ALSO"). Si no puedes entender por qué no funciona para ti, por favor envía el archivo MP3 a un lugar donde pueda obtenerlo (preferiblemente por FTP, HTTP o .Mac iDisk) y envía un correo sobre dónde puedo obtener el archivo, con una descripción detallada del problema.

Si lo descargo después de diagnosticar el problema, no mantendré el archivo MP3 si no es legible para mí. Solo dime si es legible para mí mantenerlo o no.

NAME

MP3::Info - Module for fetching information about MP3 files

SYNOPSIS

 use MP3::Info;
 my $mp3_info = MP3::Info->new();
 my $tag = $mp3_info->get_tags($filename);
 # Access tags
 print $tag->{'title'};
 print $tag->{'artist'};
 print $tag->{'album'};
 print $tag->{'year'};
 print $tag->{'genre'};
 print $tag->{'comment'};
 print $tag->{'track'};
 print $tag->{'VBR'};
 print $tag->{'bitrate'};
 print $tag->{'mode'};
 print $tag->{'mode_extension'};
 print $tag->{'emphasis'};
 print $tag->{'protected'};
 print $tag->{'copyright'};
 print $tag->{'original'};
 print $tag->{'sampling_rate'};
 print $tag->{'channels'};
 print $tag->{'bytes'};
 print $tag->{'length'};
 my $tag = $mp3_info->get_mp3tag($filename);
 my $tag = $mp3_info->get_id3tag($filename);
 my $tag = $mp3_info->get_xsf($filename);

DESCRIPTION

This module provides a simple interface for retrieving information about MP3 files, including ID3 tag information, Xing VBR header info, and other MPEG audio frame header data.

The primary method is get_tags(), which takes a filename as an argument and returns a hash reference containing the MP3 information.

The keys in the returned hash reference are:

title
Title of the song.
artist
Artist of the song.
album
Album the song belongs to.
year
Year the song was released.
genre
Genre of the song.
comment
Comment associated with the song.
track
Track number on the album.
VBR
Boolean indicating if the file uses Variable Bit Rate encoding.
bitrate
The bit rate of the MP3 file in kbps.
mode
Audio mode (e.g., 'stereo', 'joint stereo', 'mono').
mode_extension
Mode extension (relevant for joint stereo).
emphasis
Emphasis flag (e.g., 'none', '50/15').
protected
Boolean indicating if the file is protected.
copyright
Boolean indicating if copyright information is present.
original
Boolean indicating if the recording is an original.
sampling_rate
Sampling rate of the audio in Hz.
channels
Number of audio channels.
bytes
Size of the MP3 data in bytes.
length
Estimated length of the MP3 file in seconds.

The module also provides convenience methods:

get_mp3tag()
Retrieves information using the Xing VBR header.
get_id3tag()
Retrieves information from ID3v1 and ID3v2 tags.
get_xsf()
Retrieves information from the MPEG audio frame header.

TROUBLESHOOTING

If you encounter issues with MP3 files, ensure that:

  • The MP3 file is not corrupted.
  • The file permissions allow the script to read the file.
  • The ID3 tags are correctly formatted.
