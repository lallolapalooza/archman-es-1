MPI_Type_get_true_extent_x(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_TYPE_GET_TRUE_EXTENT_X(3) Open MPI MPI_TYPE_GET_TRUE_EXTENT_X(3)

MPI_Type_get_true_extent, MPI_Type_get_true_extent_x - Devuelve el límite inferior y la extensión reales de un tipo de datos correspondiente al typemap, ignorando los marcadores MPI_UB y MPI_LB.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Type_get_true_extent(MPI_Datatype datatype,
     MPI_Aint *true_lb, MPI_Aint *true_extent)
int MPI_Type_get_true_extent_x(MPI_Datatype datatype,
     MPI_Count *true_lb, MPI_Count *true_extent)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_TYPE_GET_TRUE_EXTENT(DATATYPE, TRUE_LB, TRUE_EXTENT, IERROR)
     INTEGER DATATYPE, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) TRUE_LB, TRUE_EXTENT
MPI_TYPE_GET_TRUE_EXTENT_X(DATATYPE, TRUE_LB, TRUE_EXTENT, IERROR)
     INTEGER DATATYPE, IERROR
     INTEGER(KIND=MPI_COUNT_KIND) TRUE_LB, TRUE_EXTENT

Sintaxis Fortran 2008

USE mpi_f08
MPI_Type_get_true_extent(datatype, true_lb, true_extent, ierror)
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) :: true_lb, true_extent
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Type_get_true_extent_x(datatype, true_lb, true_extent, ierror)
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER(KIND = MPI_COUNT_KIND), INTENT(OUT) :: true_lb, true_extent
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA

•
datatype: Tipo de datos para el que se desea información (manejador).

PARÁMETROS DE SALIDA

  • true_lb: Límite inferior real del tipo de datos (entero).
  • true_extent: Tamaño real del tipo de datos (entero).
  • ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

El parámetro true_lb devuelve el desplazamiento de la unidad mínima de almacenamiento a la que se accede mediante el tipo de datos, es decir, el límite inferior del typemap correspondiente, ignorando los marcadores MPI_LB. El parámetro true_extent devuelve el tamaño real del tipo de datos, es decir, la extensión del typemap correspondiente, ignorando los marcadores MPI_LB y MPI_UB, y sin realizar ningún redondeo para la alineación. Para ambas funciones, si el parámetro true_lb o true_extent no puede expresar el valor a devolver (por ejemplo, si el parámetro es demasiado pequeño para contener el valor de salida), se establece en MPI_UNDEFINED.

El true_extent es el número mínimo de bytes de memoria necesarios para contener un tipo de datos, sin comprimir.

Consulte la sección 4.1.8 del estándar MPI-3 para obtener definiciones más detalladas de estos parámetros en relación con el typemap.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas en C como resultado de la función y las rutinas en Fortran en el último argumento.

Antes de devolver el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones), el error eleva el controlador de errores inicial. El controlador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o la clave info a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que pueden utilizarse:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Gestión de Errores del estándar MPI-3.1 para obtener más información.
