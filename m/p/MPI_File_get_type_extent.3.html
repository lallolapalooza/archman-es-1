MPI_File_get_type_extent(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_FILE_GET_TYPE_EXTENT(3) Open MPI MPI_FILE_GET_TYPE_EXTENT(3)

MPI_File_get_type_extent — Devuelve la extensión del tipo de datos en un archivo.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_File_get_type_extent(MPI_File fh, MPI_Datatype
     datatype, MPI_Aint *extent)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_FILE_GET_TYPE_EXTENT(FH, DATATYPE, EXTENT, IERROR)
     INTEGER FH, DATATYPE, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND)  EXTENT

Sintaxis Fortran 2008

USE mpi_f08
MPI_File_get_type_extent(fh, datatype, extent, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) :: extent
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • fh: Identificador del archivo (handle).
  • datatype: Tipo de datos (handle).

PARÁMETROS DE SALIDA

  • extent: Extensión del tipo de datos (entero).
  • ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

MPI_File_get_type_extent puede usarse para calcular la extensión de datatype en el archivo. La extensión es la misma para todos los procesos que acceden al archivo asociado con fh. Si la vista actual utiliza una representación de datos definida por el usuario, MPI_File_get_type_extent utiliza la función de callback dtype_file_extent_fn para calcular la extensión.

NOTAS

Si la representación de datos del archivo es diferente de "nativo", se debe tener cuidado al construir etypes y filetypes. Cualquiera de las funciones constructoras de tipos de datos puede ser utilizada; sin embargo, para aquellas funciones que aceptan desplazamientos en bytes, los desplazamientos deben especificarse en términos de sus valores en el archivo para la representación de datos del archivo que se está utilizando. MPI interpretarará estos desplazamientos en bytes tal cual; no se realizará escalado. La función MPI_File_get_type_extent puede usarse para calcular las extensiones de los tipos de datos en el archivo. Para etypes y filetypes que son tipos de datos portátiles, MPI escalará cualquier desplazamiento en los tipos de datos para que coincida con la representación de datos del archivo. Los tipos de datos pasados como argumentos a las rutinas de lectura/escritura especifican la disposición de los datos en memoria; por lo tanto, siempre deben construirse utilizando desplazamientos que correspondan a los desplazamientos en memoria.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al controlador de error de MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay un objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de error de MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el controlador de error inicial. El controlador de error inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF al usar el modelo World, o el argumento CLI mpi_initial_errhandler para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de error apropiado, entonces se llama al controlador de error MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de error MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de error predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de error llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
