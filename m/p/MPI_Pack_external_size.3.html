MPI_PACK_EXTERNAL_SIZE(3) Open MPI MPI_PACK_EXTERNAL_SIZE(3)

MPI_Pack_external_size — Calcula el límite superior del espacio necesario para escribir en un formato portable

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Pack_external_size(const char *datarep, int incount,
     MPI_Datatype datatype, MPI_Aint *size)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_PACK_EXTERNAL_SIZE(DATAREP, INCOUNT, DATATYPE, SIZE, IERROR)
     INTEGER         INCOUNT, DATATYPE, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) SIZE
     CHARACTER*(*)   DATAREP

Sintaxis Fortran 2008

USE mpi_f08
MPI_Pack_external_size(datarep, incount, datatype, size, ierror)
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(IN) :: incount
     CHARACTER(LEN=*), INTENT(IN) :: datarep
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) :: size
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • datarep: Representación de datos (cadena).
  • incount: Número de elementos de datos de entrada (entero).
  • datatype: Tipo de datos de cada elemento de datos de entrada (identificador).

PARÁMETROS DE SALIDA

  • size: Límite superior del tamaño del mensaje empaquetado, en bytes (entero).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Pack_external_size permite a la aplicación saber cuánto espacio se necesita para empaquetar un mensaje en el formato portable definido por el Foro MPI. Devuelve en size un límite superior sobre el incremento en position que ocurriría en una llamada a MPI_Pack_external con los mismos valores para datarep, incount y datatype.

La llamada devuelve un límite superior, en lugar de un límite exacto, ya que la cantidad exacta de espacio necesaria para empaquetar el mensaje puede depender del contexto y la alineación (por ejemplo, el primer mensaje empaquetado en una unidad de empaquetado puede requerir más espacio).

NOTAS

El argumento datarep especifica el formato de datos. El único valor válido en la versión actual de MPI es “external32”. El argumento se proporciona para futura extensibilidad.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado del retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa el Modelo de Sesiones exclusivamente), el error activa el controlador de errores inicial. El controlador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpiexec mpi_initial_errhandler o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro controlador de errores apropiado, entonces se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
