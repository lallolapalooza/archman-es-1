MPI_File_read_at_all_begin(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_FILE_READ_AT_ALL_BEGIN(3) Open MPI MPI_FILE_READ_AT_ALL_BEGIN(3)

MPI_File_read_at_all_begin — Lee un archivo en posiciones explícitamente especificadas; parte inicial de una rutina colectiva dividida (no bloqueante).

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_File_read_at_all_begin(MPI_File fh, MPI_Offset
     offset, void *buf, int count, MPI_Datatype
     datatype)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_FILE_READ_AT_ALL_BEGIN(FH, OFFSET, BUF,
     COUNT, DATATYPE, IERROR)
     <type>  BUF(*)
     INTEGER FH, COUNT, DATATYPE, IERROR
     INTEGER(KIND=MPI_OFFSET_KIND)   OFFSET

Sintaxis Fortran 2008

USE mpi_f08
MPI_File_read_at_all_begin(fh, offset, buf, count, datatype, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: offset
     TYPE(*), DIMENSION(..), ASYNCHRONOUS :: buf
     INTEGER, INTENT(IN) :: count
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • fh: Manejador de archivo (handle).
  • offset: Desplazamiento del archivo (entero).
  • count: Número de elementos en el buffer (entero).
  • datatype: Tipo de dato de cada elemento del buffer.

PARÁMETROS DE SALIDA

  • buf: Dirección inicial del buffer (choice).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_File_read_at_all_begin es la parte inicial de una rutina colectiva dividida que intenta leer del archivo asociado con fh (en la posición offset) un número total de count elementos de datos de tipo datatype en el buffer buf del usuario. El offset está en unidades etype relativas a la vista actual. Es decir, los huecos no se cuentan al localizar un desplazamiento. Los datos se toman de las partes del archivo especificadas por la vista actual.

NOTAS

Todas las rutinas colectivas no bloqueantes para el acceso a datos están "divididas" en dos rutinas, cada una con _begin o _end como sufijo. Estas rutinas colectivas divididas están sujetas a las reglas semánticas descritas en la sección 9.4.5 del estándar MPI-2.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado del retorno de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init / MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error genera el manejador de errores inicial. El manejador de errores inicial puede ser cambiado llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos mpiexec mpi_initial_errhandler o clave de información para MPI_Comm_spawn / MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Vea la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Vea la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
