MPI_Win_shared_query — Consulta una ventana de memoria compartida

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Win_shared_query (MPI_Win win, int rank, MPI_Aint *size,
                          int *disp_unit, void *baseptr)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_WIN_SHARED_QUERY(WIN, RANK, SIZE, DISP_UNIT, BASEPTR, IERROR)
        INTEGER WIN, RANK, DISP_UNIT, IERROR
        INTEGER(KIND=MPI_ADDRESS_KIND) SIZE, BASEPTR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Win_shared_query(win, rank, size, disp_unit, baseptr, ierror)
     USE, INTRINSIC :: ISO_C_BINDING, ONLY : C_PTR
     TYPE(MPI_Win), INTENT(IN) :: win
     INTEGER, INTENT(IN) :: rank
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(OUT) :: size
     INTEGER, INTENT(OUT) :: disp_unit
     TYPE(C_PTR), INTENT(OUT) :: baseptr
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • win: Objeto de ventana de memoria compartida (manejador).
  • rank: Rango en el grupo de la ventana win (entero no negativo) o MPI_PROC_NULL.

PARÁMETROS DE SALIDA

  • size: Tamaño del segmento de ventana (entero no negativo).
  • disp_unit: Unidad local de tamaño para los desplazamientos, en bytes (entero positivo).
  • baseptr: Dirección para acceso de carga/almacenamiento al segmento de ventana (elección).
  • ierror: Solo Fortran: estado de error (entero).

DESCRIPCIÓN

MPI_Win_shared_query consulta la dirección local del proceso para segmentos de memoria remota creados con MPI_Win_allocate_shared. Esta función puede devolver direcciones locales del proceso diferentes para la misma memoria física en procesos distintos. La memoria devuelta se puede utilizar para accesos de carga/almacenamiento sujetos a las restricciones definidas en la sección 11.7 de MPI-3.1. Esta función solo se puede llamar con ventanas de tipo (flavor) MPI_WIN_FLAVOR_SHARED. Si la ventana pasada no es de tipo MPI_WIN_FLAVOR_SHARED, se genera el error MPI_ERR_RMA_FLAVOR. Cuando rank es MPI_PROC_NULL, el puntero, disp_unit y size devueltos son el puntero, disp_unit y tamaño del segmento de memoria perteneciente al rango más bajo que especificó size > 0. Si todos los procesos del grupo adjunto a la ventana especificaron size = 0, entonces la llamada devuelve size = 0 y un baseptr como si MPI_Alloc_mem se hubiera llamado con size = 0.

NOTAS C

El parámetro baseptr es de tipo void * para permitir pasar cualquier objeto puntero para este parámetro. El argumento proporcionado debe ser un puntero a un puntero de tipo arbitrario (por ejemplo, void **).

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error genera el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o la clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si MPI_Abort se hubiera llamado en ese comunicador. Si se llama en una ventana o archivo, actúa como si MPI_Abort se hubiera llamado en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
