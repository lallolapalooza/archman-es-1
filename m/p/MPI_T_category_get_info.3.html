MPI_T_category_get_info — Consultar información de una categoría

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_category_get_info(int cat_index, char *name, int *name_len,
char *desc, int *desc_len, int *num_cvars, int *num_pvars,
int *num_categories)

PARÁMETROS DE ENTRADA

•
cat_index: Índice de la categoría a consultar.

PARÁMETROS DE ENTRADA/SALIDA

  • name_len: Longitud de la cadena y/o búfer para el nombre.
  • desc_len: Longitud de la cadena y/o búfer para la descripción.

PARÁMETROS DE SALIDA

  • name: Búfer para devolver la cadena que contiene el nombre de la categoría.
  • desc: Búfer para devolver la cadena que contiene la descripción de la categoría.
  • num_cvars: Número de variables de control en la categoría.
  • num_pvars: Número de variables de rendimiento en la categoría.
  • num_categories: Número de categorías contenidas en la categoría.

DESCRIPCIÓN

MPI_T_category_get_info se puede utilizar para consultar información de una categoría. La función devuelve el número de variables de control, variables de rendimiento y subcategorías en la categoría consultada en los argumentos num_cvars, num_pvars y num_categories, respectivamente.

NOTAS

Esta función de interfaz de herramientas MPI devuelve dos cadenas. Esta función toma dos argumentos para cada cadena: un búfer para almacenar la cadena y una longitud que inicialmente debe especificar el tamaño del búfer. Si la longitud pasada es n, esta función copiará como máximo n - 1 caracteres de la cadena en el búfer correspondiente y establecerá la longitud en el número de caracteres copiados - 1. Si el argumento de longitud es NULL o el valor especificado en la longitud es 0, se ignora el búfer de cadena correspondiente y no se devuelve la cadena.

ERRORES

MPI_T_category_get_info fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_INDEX: El índice de categoría no es válido.
