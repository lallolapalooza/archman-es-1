MPI_Isendrecv — envía y recibe un mensaje.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Isendrecv(const void *sendbuf, int sendcount, MPI_Datatype sendtype,
    int dest, int sendtag, void *recvbuf, int recvcount,
    MPI_Datatype recvtype, int source, int recvtag,
    MPI_Comm comm, MPI_Request *request)

Sintaxis Fortran

USE MPI
! o o o: INCLUDE 'mpif.h'
MPI_ISENDRECV(SENDBUF, SENDCOUNT, SENDTYPE, DEST, SENDTAG,
        RECVBUF, RECVCOUNT, RECVTYPE, SOURCE, RECVTAG, COMM,
        REQUEST, IERROR)
    TYPE(*), DIMENSION(..), INTENT(IN) :: sendbuf
    TYPE(*), DIMENSION(..) :: recvbuf

    recvtg, sendtype, recvtg
    TYPE(MPI_Datatype), INTENT(IN) :: sendtype, recvtg
    TYPE(MPI_Comm), INTENT(IN) :: comm
    TYPE(MPI_Request) :: request

PARÁMETROS DE ENTRADA

  • sendbuf: Dirección inicial del buffer de envío (opcional).
  • sendcount: Número de elementos a enviar (entero).
  • sendtype: Tipo de elementos en el buffer de envío (referencia).
  • dest: Rango del destinatario (entero).
  • sendtag: Etiqueta de envío (entero).
  • recvcount: Máximo número de elementos a recibir (entero).
  • recvtype: Tipo de elementos en el buffer de recepción (referencia).
  • source: Rango del emisor (entero).
  • recvtag: Etiqueta de recepción (entero).
  • comm: Comunicador (referencia).

PARÁMETROS DE SALIDA

  • recvbuf: Dirección inicial del buffer de recepción (opcional).
  • request: Petición de comunicación (referencia).
  • ierror: Solo en Fortran: Estado de error (entero).

DESCRIPCIÓN

Las operaciones de envío y recepción no bloqueadas combinan en una llamada el envío de un mensaje a un destino y la recepción de otro mensaje, de otro proceso. Los dos (emisor y destinatario) pueden ser el mismo. Esta operación es útil para ejecutar una operación de desplazamiento en una cadena de procesos. La operación de envío y recepción puede usarse junto con las funciones descritas en el capítulo de topologías de procesos de la estándar MPI para realizar desplazamientos en diferentes topologías lógicas.

Un mensaje enviado por una operación de envío y recepción puede ser recibido por una operación de recepción regular o probado por una operación de prueba; una operación de envío y recepción puede recibir un mensaje enviado por una operación de envío regular.

MPI_Isendrecv ejecuta una operación de envío y recepción no bloqueada. Ambos, envío y recepción, utilizan el mismo comunicador, pero pueden tener etiquetas diferentes. Los buffers de envío y recepción deben ser dispares, y pueden tener distintas longitudes y tipos de datos.

Una solicitud de envío y recepción no bloqueada puede determinarse como completada llamando a MPI_Wait, MPI_Waitany, MPI_Test o MPI_Testany con la solicitud retornada por esta función.

ERRORES

La mayoría de las rutinas MPI devuelven un valor de error; las rutinas C devuelven el resultado de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al manejador de error asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) actual. Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y se llama al manejador de error asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa el modelo de Sesiones exclusivamente), el error levanta el manejador de error inicial. El manejador de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se usa el modelo del Mundo, o el argumento mpi_initial_errhandler CLI para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de error adecuado configurado, se llama al manejador de error MPI_ERRORS_RETURN para funciones de I/O MPI y al manejador de error MPI_ERRORS_ABORT para todas las funciones MPI.

Open MPI incluye tres manejadores de error predeterminados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL — detiene a todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT — un manejador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el conjunto de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, detiene solo el proceso local.
  • MPI_ERRORS_RETURN — devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de error llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: Los manejadores de error de MPI no garantizan que un programa MPI pueda continuar después de un error.

Ver la página de man de MPI para una lista completa de códigos de error MPI.

Ver la sección de manejo de errores de la estándar MPI-3.1 para más información.
