MPI_Register_datarep(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_Register_datarep(3) Open MPI MPI_Register_datarep(3)

MPI_Register_datarep define la representación de datos.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Register_datarep(const char *datarep,
     MPI_Datarep_conversion_function *read_conversion_fn,
     MPI_Datarep_conversion_function *write_conversion_fn,
     MPI_Datarep_extent_function *dtype_file_extent_fn,
     void *extra_state)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_REGISTER_DATAREP(DATAREP, READ_CONVERSION_FN,
     WRITE_CONVERSION_FN, DTYPE_FILE_EXTENT_FN,
     EXTRA_STATE, IERROR)
     CHARACTER*(*)   DATAREP
     EXTERNAL        READ_CONVERSION_FN, WRITE_CONVERSION_FN, DTYPE_FILE_EXTENT_FN
     INTEGER IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND)  EXTRA_STATE

Sintaxis Fortran 2008

USE mpi_f08
MPI_Register_datarep(datarep, read_conversion_fn, write_conversion_fn,
             dtype_file_extent_fn, extra_state, ierror)
     CHARACTER(LEN=*), INTENT(IN) :: datarep
     PROCEDURE(MPI_Datarep_conversion_function) :: read_conversion_fn
     PROCEDURE(MPI_Datarep_conversion_function) :: write_conversion_fn
     PROCEDURE(MPI_Datarep_extent_function) :: dtype_file_extent_fn
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: extra_state
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

  • datarep: Identificador de la representación de datos (cadena).
  • read_conversion_fn: Función que se llama para convertir de la representación en archivo a la representación nativa (función).
  • write_conversion_fn: Función que se llama para convertir de la representación nativa a la representación en archivo (función).
  • dtype_file_extent_fn: Función que se llama para obtener el tamaño de un tipo de datos como se representa en el archivo (función).
  • extra_state: Estado adicional.

Parámetro de salida

•
ierror: Estado de error (entero) solo en Fortran.

Descripción

MPI_Register_datarep define una representación de datos. Asocia el identificador de la representación de datos (una cadena) con las funciones que convierten de la representación en archivo a la representación nativa y viceversa, con la función que obtiene el tamaño de un tipo de datos como se representa en el archivo, así como con el "estado adicional" que se usa para pasar argumentos. Una vez que una representación de datos ha sido registrada mediante esta rutina, puedes especificar su identificador como argumento a MPI_File_set_view, lo que causará que las operaciones posteriores de acceso a datos llamen a las funciones de conversión especificadas. La llamada asociará read_conversion_fn, write_conversion_fn y dtype_file_extent_fn con el identificador de la representación de datos datarep. datarep puede luego usarse como argumento a MPI_File_set_view, causando que las operaciones posteriores de acceso a datos llamen a las funciones de conversión para convertir todos los elementos de datos accedidos entre la representación en archivo y la representación nativa. MPI_Register_datarep es una operación local y solo registra la representación de datos para el proceso de MPI que llama. Si datarep ya está definido, se lanzará un error de clase MPI_ERR_DUP_DATAREP usando el gestor de errores por defecto para el archivo. La longitud de una cadena de representación de datos está limitada al valor de MPI_MAX_DATAREP_STRING. MPI_MAX_DATAREP_STRING debe tener un valor de al menos 64. No se proporcionan rutinas para eliminar representaciones de datos y liberar los recursos asociados; no se espera que una aplicación genere estas en grandes cantidades.

Notas

Cada rutina de I/O de MPI incluye un argumento final, IERROR, que no está definido en las secciones de PARÁMETROS. Este argumento se usa para devolver el estado de error de la rutina en el estilo típico de las rutinas de biblioteca de Fortran.

Cada rutina devuelve un valor de error como valor de retorno entero.

Las clases de error se encuentran en mpi.h (para C) y mpif.h (para Fortran).

Errores

La mayoría de las rutinas MPI devuelven un valor de error; en el caso de las rutinas C, el resultado se devuelve como valor de retorno de la función, y en el caso de las rutinas Fortran, en el último argumento.

Antes de devolver el valor de error, se llama al gestor de error asociado con el objeto de comunicación (por ejemplo, communicator, window, file) relacionado con la llamada. Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y se llama al gestor de error asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza el modelo de Sesiones exclusivamente), se levanta el gestor de error inicial. El gestor de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se utiliza el modelo del Mundo, o el argumento mpi_initial_errhandler de mpiexec o la clave info del MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido un gestor de error adecuado, se llama al gestor de error MPI_ERRORS_RETURN para las funciones de I/O de MPI y al gestor de error MPI_ERRORS_ABORT para todas las otras funciones de MPI.

Open MPI incluye tres gestores de errores predeterminados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT un gestor de error que puede invocarse en un communicator, window, file o sesion. Cuando se invoca en un communicator, actúa como si se hubiera llamado MPI_Abort en ese communicator. Si se invoca en un window o file, actúa como si se hubiera llamado MPI_Abort en un communicator que contiene el grupo de procesos en el correspondiente window o file. Si se invoca en una sesion, se aborta solo el proceso local.
  • MPI_ERRORS_RETURN devuelve un código de error a la aplicación.

Los programas MPI también pueden implementar sus propios gestores de errores llamando:

  • MPI_Comm_create_errhandler seguido de MPI_Comm_set_errhandler
  • MPI_File_create_errhandler seguido de MPI_File_set_errhandler
  • MPI_Session_create_errhandler seguido de MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler seguido de MPI_Win_set_errhandler

Nota: MPI no garantiza que un programa MPI pueda continuar tras un error.

Ver la página de man de MPI para una lista completa de códigos de error de MPI.

Ver la sección de manejo de errores de la estándar MPI-3.1 para más información.
