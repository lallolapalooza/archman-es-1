MPI_GROUP_INCL(3) Open MPI MPI_GROUP_INCL(3)

MPI_Group_incl — Produce un grupo reordenando un grupo existente y tomando solo los miembros listados.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Group_incl(MPI_Group group, int n, const int ranks[],
    MPI_Group *newgroup)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_GROUP_INCL(GROUP, N, RANKS, NEWGROUP, IERROR)
    INTEGER GROUP, N, RANKS(*), NEWGROUP, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Group_incl(group, n, ranks, newgroup, ierror)
    TYPE(MPI_Group), INTENT(IN) :: group
    INTEGER, INTENT(IN) :: n, ranks(n)
    TYPE(MPI_Group), INTENT(OUT) :: newgroup
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • group : Grupo (handle).
n
Número de elementos en el array ranks (y tamaño de newgroup)(entero).
•
ranks
Ranks de los procesos en group que aparecerán en newgroup (array de enteros).

PARÁMETROS DE SALIDA

•
newgroup
Nuevo grupo derivado de lo anterior, en el orden definido por ranks (handle).
•
ierror : Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

La función MPI_Group_incl crea un grupo group_out que consiste en los n procesos en group con ranks rank[0], …, rank[n-1]; el proceso con rank i en group_out es el proceso con rank ranks[i] en group. Cada uno de los n elementos de ranks debe ser un rank válido en group y todos los elementos deben ser distintos, o el programa será erróneo. Si n = 0, entonces group_out es MPI_GROUP_EMPTY. Esta función puede, por ejemplo, usarse para reordenar los elementos de un grupo.

NOTA

Esta implementación no comprueba actualmente si hay duplicados en la lista de ranks.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de error MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de error MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el controlador de error inicial. El controlador de error inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o la clave info a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de error apropiado, entonces se llama al controlador de error MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de error MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de error predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de error llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
