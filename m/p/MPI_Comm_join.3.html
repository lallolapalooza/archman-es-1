MPI_COMM_JOIN(3) Open MPI MPI_COMM_JOIN(3)

MPI_Comm_join — Establece la comunicación entre trabajos MPI

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Comm_join(int fd, MPI_Comm *intercomm)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_COMM_JOIN(FD, INTERCOMM, IERROR)
     INTEGER FD, INTERCOMM, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_join(fd, intercomm, ierror)
     INTEGER, INTENT(IN) :: fd
     TYPE(MPI_Comm), INTENT(OUT) :: intercomm
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA

•
fd: descriptor de archivo de socket (socket).

PARÁMETROS DE SALIDA

  • intercomm: Intercomunicador entre procesos (handle).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Comm_join crea un intercomunicador a partir de la unión de dos procesos MPI que están conectados por un socket. fd es un descriptor de archivo que representa un socket de tipo SOCK_STREAM (una conexión de flujo de bytes confiable y bidireccional). La E/S no bloqueante y la notificación asíncrona a través de SIGIO no deben estar habilitadas para el socket. El socket debe estar en estado conectado y debe estar inactivo cuando se llama a MPI_Comm_join.

MPI_Comm_join debe ser llamado por el proceso en cada extremo del socket. No regresa hasta que ambos procesos hayan llamado a MPI_Comm_join.

NOTAS

No hay llamadas a la biblioteca MPI para abrir y manipular un socket. El socket fd se puede abrir utilizando llamadas estándar a la API de sockets. MPI utiliza el socket para iniciar la creación del intercomunicador y para nada más. Al regresar, el descriptor de archivo estará abierto e inactivo.

En un proceso multihilo, la aplicación debe asegurarse de que otros hilos no accedan al socket mientras uno está en medio de la llamada a MPI_Comm_join.

El comunicador devuelto contendrá los dos procesos conectados por el socket y podrá ser utilizado para establecer comunicación MPI con procesos adicionales, a través de los mecanismos habituales de creación de comunicadores MPI.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; rutinas C como resultado de retorno de la función y rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/ MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones), el error activa el manejador de errores inicial. El manejador de errores inicial puede ser cambiado llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo Mundial, o el argumento de línea de comandos mpiexec mpi_initial_errhandler o la clave de información de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que pueden ser utilizados:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
