MPI_Dist_graph_create — Crea un nuevo comunicador con topología de grafo distribuido.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Dist_graph_create(MPI_Comm comm_old, int n, const int sources[],
     const int degrees[], const int destinations[], const int weights[],
        MPI_Info info, int reorder, MPI_Comm *comm_dist_graph)

Sintaxis Fortran

USE MPI
! o la antigua forma: INCLUDE 'mpif.h'
MPI_DIST_GRAPH_CREATE(COMM_OLD, N, SOURCES, DEGREES, DESTINATIONS, WEIGHTS,
                INFO, REORDER, COMM_DIST_GRAPH, IERROR)
     INTEGER COMM_OLD, N, SOURCES(*), DEGRES(*), WEIGHTS(*), INFO
     INTEGER COMM_DIST_GRAPH, IERROR
     LOGICAL   REORDER

Sintaxis Fortran 2008

USE mpi_f08
MPI_Dist_Graph_create(COMM_OLD, N, SOURCES, DEGREES, DESTINATIONS, WEIGHTS,
             INFO, REORDER, COMM_DIST_GRAPH, IERROR)
     TYPE(MPI_Comm), INTENT(IN) :: COMM_OLD
     INTEGER, INTENT(IN) :: N, SOURCES(N), DEGRES(N), DESTINATIONS(*)
     INTEGER, INTENT(IN) :: WEIGHTS(*)
     TYPE(MPI_Info), INTENT(IN) :: INFO
     LOGICAL, INTENT(IN) :: REORDER
     TYPE(MPI_Comm), INTENT(OUT) :: COMM_DIST_GRAPH
     INTEGER, OPTIONAL, INTENT(OUT) :: IERROR

Parámetros de entrada

  • comm_old: Comunicador sin topología (handle).
  • n: Número de nodos de fuente para los cuales este proceso especifica bordes (entero no negativo).
  • sources: Array con los n nodos de fuente para los cuales este proceso especifica bordes (array de enteros no negativos).
  • degrees: Array que especifica el número de nodos de destino para cada nodo de fuente en el array de nodos de fuente (array de enteros no negativos).
  • destinations: Nodos de destino para los nodos de fuente en el array de nodos de fuente (array de enteros no negativos).
  • weights: Pesos para bordes de fuente a destino (array de enteros no negativos).
  • info: Hints sobre optimización e interpretación de pesos (handle).
  • reorder: La jerarquía puede reordenarse (verdadero) o no (falso) (lógico).

Parámetros de salida

  • comm_dist_graph: Comunicador con topología de grafo distribuido añadida (handle).
  • ierror: Solo en Fortran: Estado de error (entero).

Descripción

MPI_Dist_graph_create crea un nuevo comunicador comm_dist_graph con topología de grafo distribuido y retorna un handle al nuevo comunicador. El número de procesos en comm_dist_graph es idéntico al número de procesos en comm_old. Concretamente, cada proceso llama al constructor con un conjunto de bordes dirigidos (fuente, destino) como se describe a continuación. Cada proceso pasa un array de n nodos de fuente en el array de sources. Para cada nodo de fuente, un número no negativo de nodos de destino se especifica en el array de degrees. Los nodos de destino se almacenan en el segmento correspondiente de la array de destinations. Más precisamente, si el nodo i-ésimo en sources es s, esta especifica degrees[i] bordes (s, d) con d de los bordes j-ésimos almacenados en destinations[degrees[0] + ... + degrees[i-1] + j]. El peso de este borde se almacena en weights[degrees[0] + ... + degrees[i-1] + j]. Los arrays sources y destinations pueden contener el mismo nodo más de una vez, y el orden en que los nodos se listan como fuente o destino no es significativo. Así mismo, diferentes procesos pueden especificar bordes con nodos de fuente y destino idénticos. Los nodos de fuente y destino deben ser rangos de procesos en comm_old. Diferentes procesos pueden especificar diferente número de nodos de fuente y destino, así como bordes de fuente a destino diferentes. Esto permite una especificación completamente distribuida del grafo de comunicación. Los procesos aislados (es decir, procesos que no tienen salida o entrada, es decir, que no ocurren como nodo de fuente o destino en la especificación de grafo) son permitidos. La llamada a MPI_Dist_graph_create es colectiva.

Si reorder = false, todos los procesos tendrán el mismo rango en comm_dist_graph que en comm_old. Si reorder = true, la librería MPI será libre de reasignar a otros procesos (de comm_old) en orden para mejorar la comunicación en los bordes del grafo de comunicación. Peso de bordes

Los pesos se especifican como enteros no negativos y pueden usarse para influir en la estrategia de remapeo de procesos y otras optimizaciones internas de MPI. Por ejemplo, los argumentos de contagem aproximada de llamadas posteriores a comunicación en ciertas aristas podrían usarse como sus pesos de bordes. La multiplicidad de bordes puede indicar una comunicación más intensa entre pares de procesos. Sin embargo, el significado exacto de los pesos de bordes no está especificado por la estándar MPI y está a discreción de la implementación. Una aplicación puede proporcionar el valor especial MPI_UNWEIGHTED para el array de pesos para indicar que todos los bordes tienen el mismo (efectivamente, no) peso. Es erróneo proporcionar MPI_UNWEIGHTED para algunos pero no para todos los procesos de comm_old. Si el grafo es ponderado pero n = 0, se puede pasar a weights cualquier array de peso. Nota que MPI_UNWEIGHTED y MPI_WEIGHTS_EMPTY no son valores especiales de peso; son valores especiales para el argumento total del array. En Fortran, MPI_UNWEIGHTED y MPI_WEIGHTS_EMPTY son objetos como MPI_BOTTOM (no usables para inicialización o asignación). Véase la sección MPI-3 2.5.4.

Errores

La mayoría de las rutinas MPI devuelven un valor de error; las rutinas C devuelven el resultado de la función y las rutinas Fortran en el último argumento.

Antes de que el valor de error sea devuelto, se llama la función de manejador de error asociada con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) actual. Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y llamará al manejador de error asociado con MPI_COMM_SELF. Si MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza el modelo de Sesiones exclusivamente), el error levanta el manejador de error inicial. El manejador de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler con MPI_COMM_SELF cuando se use el modelo del Mundo, o el argumento CLI mpi_initial_errhandler de mpiexec o la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de error adecuado, el manejador de error MPI_ERRORS_RETURN se llama para las funciones de I/O de MPI y el manejador de error MPI_ERRORS_ABORT se llama para todas las otras funciones de MPI.

El Open MPI incluye tres manejadores de error prediseñados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL — Causa que el programa aborte en todos los procesos conectados a MPI.
  • MPI_ERRORS_ABORT — Un manejador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, detiene solo el proceso local.
  • MPI_ERRORS_RETURN — Devuelve un código de error a la aplicación.

Las aplicaciones MPI pueden también implementar sus propios manejadores de error llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

ERRORS

The MPI_Dist_graph_create function will fail if any of the following conditions occur:

  • MPI_ERR_ARG: A MPI_Comm was invalid.
  • MPI_ERR_ARG: A source or destination rank was invalid.
  • MPI_ERR_ARG: A weight was invalid.
  • MPI_ERR_NO_MEM: Insufficient memory to allocate required structures.
  • MPI_ERR_RANK: A source or destination rank was out of range.
  • MPI_ERR_ROOT: The root parameter was invalid.
  • MPI_ERR_TRUNCATE: The newcomm parameter was too small to hold the created communicator.

See the MPI man page for a full list of MPI error codes.

See the Error Handling section of the MPI-3.1 standard for more information.
