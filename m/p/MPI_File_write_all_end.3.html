MPI_File_write_all_end(3)

MPI_FILE_WRITE_ALL_END(3) Open MPI MPI_FILE_WRITE_ALL_END(3)

MPI_File_write_all_end — Escribe un archivo comenzando en las ubicaciones especificadas por los punteros de archivo individuales; parte final de una rutina colectiva dividida (bloqueante).

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_File_write_all_end(MPI_File fh, const void *buf, MPI_Status *status)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_FILE_WRITE_ALL_END(FH, BUF, STATUS, IERROR)
     <type>  BUF(*)
     INTEGER FH, STATUS, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_File_write_all_end(fh, buf, status, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     TYPE(*), DIMENSION(..), INTENT(IN), ASYNCHRONOUS :: buf
     TYPE(MPI_Status) :: status
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA/SALIDA

•
fh: Identificador del archivo (handle).

PARÁMETRO DE ENTRADA

•
buf: Dirección inicial del búfer (a elección).

PARÁMETROS DE SALIDA

  • status: Objeto de estado (status).
  • ierror: Solo Fortran: estado de error (entero).

DESCRIPCIÓN

MPI_File_write_all_end es la parte final de una rutina colectiva dividida que almacena el número de elementos realmente escritos en el archivo asociado con fh desde el búfer de usuario buf en status. MPI_File_write_all_end se bloquea hasta que la operación iniciada por MPI_File_write_all_begin se completa. Los datos se escriben en las partes del archivo especificadas por la vista actual. Todos los demás campos de status no están definidos.

NOTAS

Todas las rutinas colectivas no bloqueantes para el acceso a datos se han "dividido" en dos rutinas, cada una con el sufijo _begin o _end. Estas rutinas colectivas divididas están sujetas a las reglas semánticas descritas en la Sección 9.4.5 del estándar MPI-2.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el controlador de errores inicial. El controlador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de CLI mpi_initial_errhandler para mpiexec o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro controlador de errores apropiado, entonces se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
