MPI_ISSEND(3) Open MPI MPI_ISSEND(3)

MPI_Issend — Inicia un envío síncrono no bloqueante.

SINTAXIS

Sintaxis en C

#include <mpi.h>
int MPI_Issend(const void *buf, int count, MPI_Datatype datatype, int dest,
     int tag, MPI_Comm comm, MPI_Request *request)

Sintaxis en Fortran

USE MPI
! o la forma más antigua: INCLUDE 'mpif.h'
MPI_ISSEND(BUF, COUNT, DATATYPE, DEST, TAG, COMM, REQUEST, IERROR)
     <type>  BUF(*)
     INTEGER COUNT, DATATYPE, DEST, TAG, COMM, REQUEST, IERROR

Sintaxis en Fortran 2008

USE mpi_f08
MPI_Issend(buf, count, datatype, dest, tag, comm, request, ierror)
     TYPE(*), DIMENSION(..), INTENT(IN), ASYNCHRONOUS :: buf
     INTEGER, INTENT(IN) :: count, dest, tag
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     TYPE(MPI_Comm), INTENT(IN) :: comm
     TYPE(MPI_Request), INTENT(OUT) :: request
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • buf: Dirección inicial del búfer de envío (opcional).
  • count: Número de elementos en el búfer de envío (entero).
  • datatype: Tipo de dato de cada elemento del búfer de envío (identificador).
  • dest: Rango del destino (entero).
  • tag: Etiqueta del mensaje (entero).
  • comm: Comunicador (identificador).

PARÁMETROS DE SALIDA

  • request: Solicitud de comunicación (identificador).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Inicia un envío no bloqueante en modo síncrono.

Las llamadas no bloqueantes asignan un objeto de solicitud de comunicación y lo asocian con el manejador de solicitud (el argumento request). La solicitud se puede usar más tarde para consultar el estado de la comunicación o esperar su finalización.

Una llamada de envío no bloqueante indica que el sistema puede comenzar a copiar datos fuera del búfer de envío. El remitente no debe modificar ninguna parte del búfer de envío después de que se llama a una operación de envío no bloqueante, hasta que se complete el envío.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; en C, como resultado del retorno de la función, y en Fortran, en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores de MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores de MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usan exclusivamente los Sessions Model) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el World model, o el argumento CLI mpi_initial_errhandler a mpiexec o la clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la *página del manual de MPI* para obtener una lista completa de los *códigos de error de MPI*.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
