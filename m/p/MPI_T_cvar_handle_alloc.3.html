MPI_T_cvar_handle_alloc(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_T_CVAR_HANDLE_ALLOC(3) Open MPI MPI_T_CVAR_HANDLE_ALLOC(3)

MPI_T_cvar_handle_alloc, MPI_T_cvar_handle_free - Asigna/libera manejadores de variables de control

SINTAX

Sintaxis C

#include <mpi.h>
int MPI_T_cvar_handle_alloc(int cvar_index, void *obj_handle,
                            MPI_T_cvar_handle *handle, int *count)
int MPI_T_cvar_handle_free(MPI_T_cvar_handle *handle)

DESCRIPCIÓN

MPI_T_cvar_handle_alloc enlaza la variable de control especificada en cvar_index con el objeto MPI especificado en obj_handle. Si MPI_T_cvar_get_info devuelve MPI_T_BIND_NO_OBJECT como el enlace de la variable, se ignora el argumento obj_handle. El número de valores representados por esta variable de control se devuelve en el parámetro count. Si la variable de control representa una cadena, entonces count será la longitud máxima de la cadena.

MPI_T_cvar_handle_free libera un manejador asignado por MPI_T_cvar_handle_alloc y establece el argumento handle a MPI_T_CVAR_HANDLE_NULL.

NOTAS

Open MPI actualmente no admite el enlace de objetos MPI a variables de control, por lo que el argumento obj_handle siempre se ignora.

ERRORES

MPI_T_cvar_handle_alloc fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada
  • MPI_T_ERR_INVALID_INDEX: El índice de la variable de control no es válido
  • MPI_T_ERR_OUT_OF_HANDLES: No hay más manejadores disponibles

MPI_T_cvar_handle_free fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada
  • MPI_T_ERR_INVALID_HANDLE: El manejador no es válido
