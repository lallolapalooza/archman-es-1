MPI_Session_init(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_Session_init(3) Open MPI MPI_Session_init(3)

MPI_Session_init crea un nuevo handle de sesión.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Session_init(MPI_Info info, MPI_Errhandler errhandler, MPI_Session *session)

Sintaxis Fortran

USE MPI
! o la antigua forma: INCLUDE 'mpif.h'
MPI_SESSION_INIT(INFO, ERRHANDLER, SESSION, IERROR)
    INTEGER INFO, ERRHANDLER, SESSION, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Session_init(info, errhandler, session, ierror)
    TYPE(MPI_Info), INTENT(IN) :: info
    TYPE(MPI_Errhandler), INTENT(IN) :: errhandler
    TYPE(MPI_Session), INTENT(OUT) :: session
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

  • info : handle de información
errhandler
manejador de errores a asociar con el handle de sesión devuelto

Parámetros de salida

  • session : Nueva sesión (handle).
  • ierror : Solo Fortran: Estado de error (entero).

Descripción

MPI_Session_init se usa para crear una sesión MPI. El handle de sesión devuelto puede ser usado para consultar al sistema de ejecución sobre las características del proceso en el cual se está ejecutando, así como otros recursos del sistema. Otras comunicaciones MPI también pueden iniciarse en el contexto de un handle de sesión. Todas las sesiones deben finalizarse mediante MPI_Session_finalize antes de que el proceso MPI termine.

Múltiples sesiones pueden ser creadas y destruidas durante la vida de un proceso MPI. Esto es diferente del modelo del mundo MPI, que puede ser iniciado como máximo una vez (y luego finalizado) durante la vida de un proceso MPI.

Notas

El argumento info se usa para solicitar requisitos de funcionalidad de MPI y capacidades específicas de implementación de MPI.

El argumento errhandler especifica un manejador de errores a invocar en caso de que la llamada a MPI_Session_init encuentre un error.

Errores

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C devuelven el valor de error como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores actual asociado con el objeto de comunicación (por ejemplo, communicator, window, file) de la llamada. Si no hay objeto de comunicación asociado con la llamada MPI, la llamada se considera asociada con MPI_COMM_SELF y se invoca el manejador de errores asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el modelo de sesiones), se genera el error inicial. El manejador de error inicial puede ser cambiado llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo del mundo, o el argumento de CLI mpi_initial_errhandler para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de error adecuado, se llama al manejador de error MPI_ERRORS_RETURN para funciones de I/O MPI y al manejador de error MPI_ERRORS_ABORT para otras funciones MPI.

Open MPI incluye tres manejadores de error prediseñados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede invocarse en un communicator, window, file o sesión. Cuando se invoca en un communicator, actúa como si se hubiera llamado MPI_Abort en ese communicator. Si se invoca en un window o file, actúa como si se hubiera llamado MPI_Abort en un communicator que contiene los procesos en el correspondiente window o file. Si se invoca en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de error llamando:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o al MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Nota: MPI no garantiza que una aplicación MPI pueda continuar después de un error.

Ver la sección de manejo de errores de la documentación de MPI-3.1 para más información.
