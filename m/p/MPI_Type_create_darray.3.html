MPI_Type_create_darray — Crea un tipo de dato de array distribuido;

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Type_create_darray(int size, int rank, int ndims,
     const int array_of_gsizes[], const int array_of_distribs[],
     const int array_of_dargs[], const int array_of_psizes[],
     int order, MPI_Datatype oldtype, MPI_Datatype *newtype)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_TYPE_CREATE_DARRAY(SIZE, RANK, NDIMS, ARRAY_OF_GSIZES,
     ARRAY_OF_DISTRIBS, ARRAY_OF_DARGS, ARRAY_OF_PSIZES, ORDER,
     OLDTYPE, NEWTYPE, IERROR)
     INTEGER SIZE, RANK, NDIMS, ARRAY_OF_GSIZES(*), ARRAY_OF_DISTRIBS(*),
             ARRAY_OF_DARGS(*), ARRAY_OF_PSIZES(*), ORDER, OLDTYPE,
             NEWTYPE, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Type_create_darray(size, rank, ndims, array_of_gsizes,
     array_of_distribs, array_of_dargs, array_of_psizes, order,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: size, rank, ndims, array_of_gsizes(ndims),
     array_of_distribs(ndims), array_of_dargs(ndims),
     array_of_psizes(ndims), order
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • size: Tamaño del grupo de procesos (entero positivo).
  • rank: Rango en el grupo de procesos (entero no negativo).
  • ndims: Número de dimensiones del array, así como de las dimensiones de la cuadrícula de procesos (entero positivo).
  • array_of_gsizes: Número de elementos del tipo oldtype en cada dimensión del array global (array de enteros positivos).
  • array_of_distribs: Distribución del array en cada dimensión (array de estados).
  • array_of_dargs: Argumento de distribución en cada dimensión (array de enteros positivos).
  • array_of_psizes: Tamaño de la cuadrícula de procesos en cada dimensión (array de enteros positivos).
  • order: Indicador de orden de almacenamiento del array (estado).
  • oldtype: Tipo de dato antiguo (manejador).

PARÁMETROS DE SALIDA

  • newtype: Nuevo tipo de dato (manejador).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Type_create_darray se puede usar para generar los tipos de datos correspondientes a la distribución de un array ndims-dimensional de elementos oldtype en una cuadrícula ndims-dimensional de procesos lógicos. Las dimensiones no utilizadas de array_of_psizes deben establecerse en 1. Para que una llamada a MPI_Type_create_darray sea correcta, la ecuación

  ndims-1
pi              array_of_psizes[i] = size
  i=0

debe satisfacerse. Se asume que el orden de los procesos en la cuadrícula de procesos es por filas (row-major), como en el caso de las topologías de procesos cartesianos virtuales en el Estándar MPI.

Cada dimensión del array puede distribuirse de una de las tres maneras:

  • MPI_DISTRIBUTE_BLOCK - Distribución por bloques
  • MPI_DISTRIBUTE_CYCLIC - Distribución cíclica
  • MPI_DISTRIBUTE_NONE - Dimensión no distribuida.

La constante MPI_DISTRIBUTE_DFLT_DARG especifica un argumento de distribución predeterminado. El argumento de distribución para una dimensión que no está distribuida se ignora. Para cualquier dimensión i en la que la distribución sea MPI_DISTRIBUTE_BLOCK, es erróneo especificar array_of_dargs[i] * array_of_psizes[i] < array_of_gsizes[i].

Por ejemplo, el layout HPF ARRAY(CYCLIC(15)) corresponde a MPI_DISTRIBUTE_CYCLIC con un argumento de distribución de 15, y el layout HPF ARRAY(BLOCK) corresponde a MPI_DISTRIBUTE_BLOCK con un argumento de distribución de MPI_DISTRIBUTE_DFLT_DARG.

El argumento order se utiliza como en MPI_Type_create_subarray para especificar el orden de almacenamiento. Por lo tanto, los arrays descritos por este constructor de tipos pueden almacenarse en orden Fortran (column-major) o C (row-major). Los valores válidos para order son MPI_ORDER_FORTRAN y MPI_ORDER_C.

Esta rutina crea un nuevo tipo de dato MPI con un typemap definido en términos de una función llamada "cyclic()" (ver más abajo).

Sin pérdida de generalidad, basta con definir el typemap para el caso MPI_DISTRIBUTE_CYCLIC donde MPI_DISTRIBUTE_DFLT_DARG no se utiliza.

MPI_DISTRIBUTE_BLOCK y MPI_DISTRIBUTE_NONE se pueden reducir al caso MPI_DISTRIBUTE_CYCLIC para la dimensión i de la siguiente manera.

MPI_DISTRIBUTE_BLOCK con array_of_dargs[i] igual a MPI_DISTRIBUTE_DFLT_DARG es equivalente a MPI_DISTRIBUTE_CYCLIC con array_of_dargs[i] establecido en

(array_of_gsizes[i] + array_of_psizes[i] - 1)/array_of_psizes[i]

Si array_of_dargs[i] no es MPI_DISTRIBUTE_DFLT_DARG, entonces MPI_DISTRIBUTE_BLOCK y DISTRIBUTE_CYCLIC son equivalentes.

MPI_DISTRIBUTE_NONE es equivalente a MPI_DISTRIBUTE_CYCLIC con array_of_dargs[i] establecido en array_of_gsizes[i].

Finalmente, MPI_DISTRIBUTE_CYCLIC con array_of_dargs[i] igual a MPI_DISTRIBUTE_DFLT_DARG es equivalente a MPI_DISTRIBUTE_CYCLIC con array_of_dargs[i] establecido en 1.

NOTAS

Tanto para los arrays Fortran como para los C, se asume que el orden de los procesos en la cuadrícula de procesos es por filas (row-major). Esto es coherente con el orden utilizado en las topologías de procesos cartesianos virtuales en MPI. Para crear tales topologías de procesos virtuales, o para encontrar las coordenadas de un proceso en la cuadrícula de procesos, etc., los usuarios pueden utilizar las funciones correspondientes proporcionadas en MPI.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado del retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones), el error eleva el controlador de errores inicial. El controlador de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler de mpiexec o la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y se llama al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_W

SINTAXIS

Fortran

Fortran 77

 SUBROUTINE MPI_TYPE_CREATE_DARRAY(size, rank, ndims, array_of_sizes, array_of_subsizes, array_of_starts, oldtype, newtype, ierror)
 INTEGER size, rank, ndims, array_of_sizes(*)
 INTEGER array_of_subsizes(*), array_of_starts(*), oldtype, newtype, ierror

DESCRIPCIÓN

MPI_Type_create_darray crea un nuevo tipo de datos de matriz distribuida.

Los parámetros son los siguientes:

size
Número de procesos en el grupo de comunicadores. Este valor debe ser el mismo para todos los procesos que crean el tipo de datos.
rank
El rango del proceso dentro del grupo de comunicadores. Este valor debe ser único para cada proceso.
ndims
Número de dimensiones de la matriz distribuida.
array_of_sizes
Un array que contiene el tamaño de cada dimensión de la matriz distribuida en todos los procesos. El tamaño de este array debe ser ndims.
array_of_subsizes
Un array que contiene el tamaño de la submatriz de cada dimensión que será visible para el proceso actual. El tamaño de este array debe ser ndims.
array_of_starts
Un array que contiene las coordenadas de inicio de la submatriz en cada dimensión para el proceso actual. El tamaño de este array debe ser ndims.
oldtype
El tipo de datos de los elementos de la matriz.
newtype
Puntero al nuevo tipo de datos de matriz distribuida.

ERRORS

Cuando ocurre un error, las funciones de MPI devuelven un código de error. Si el programa está compilado con la opción --enable-error-checking, se ejecutará la rutina MPI_ERRhandler_error para manejar el error.

  • MPI_ERR_ARG: Se produjo un error en uno de los argumentos de entrada.
  • MPI_ERR_TYPE: Se produjo un error en un tipo de datos de MPI.
  • MPI_ERR_OTHER: Se produjo otro error. No se pudo determinar la causa del error.

La nota es que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para más información.
