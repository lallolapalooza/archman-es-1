MPI_Type_get_envelope(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_TYPE_GET_ENVELOPE(3) Open MPI MPI_TYPE_GET_ENVELOPE(3)

MPI_Type_get_envelope — Devuelve información sobre los argumentos de entrada asociados a un tipo de dato.

SINTAXIS

Sintaxis en C

#include <mpi.h>
int MPI_Type_get_envelope(MPI_Datatype datatype, int *num_integers,
     int *num_addresses, int *num_datatypes, int *combiner)

Sintaxis en Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_TYPE_GET_ENVELOPE(DATATYPE, NUM_INTEGERS, NUM_ADDRESSES,
             NUM_DATATYPES, COMBINER, IERROR)
     INTEGER DATATYPE, NUM_INTEGERS, NUM_ADDRESSES
     INTEGER NUM_DATATYPES, COMBINER, IERROR

Sintaxis en Fortran 2008

USE mpi_f08
MPI_Type_get_envelope(datatype, num_integers, num_addresses, num_datatypes,
             combiner, ierror)
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(OUT) :: num_integers, num_addresses, num_datatypes,
     combiner
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA

•
datatype: Tipo de dato a acceder (handle).

PARÁMETROS DE SALIDA

  • num_integers: Número de enteros de entrada utilizados en la llamada que construye combiner (entero no negativo).
  • num_addresses: Número de direcciones de entrada utilizadas en la llamada que construye combiner (entero no negativo).
  • num_datatypes: Número de tipos de dato de entrada utilizados en la llamada que construye combiner (entero no negativo).
  • combiner: Combinador (estado).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Para el tipo de dato dado, MPI_Type_get_envelope devuelve información sobre el número y tipo de argumentos de entrada utilizados en la llamada que creó el tipo de dato. Los valores del número de argumentos devueltos pueden usarse para proporcionar matrices suficientemente grandes en la rutina de decodificación MPI_Type_get_contents. Esta llamada y el significado de los valores devueltos se describen a continuación. El combinador refleja la llamada al constructor de tipo de dato MPI que se utilizó para crear datatype.

NOTAS

Estos son los valores que se pueden devolver en combiner y sus llamadas asociadas:

Valores                          Llamadas asociadas
MPI_COMBINER_NAMED              un tipo de dato predefinido con nombre
MPI_COMBINER_DUP                MPI_Type_dup
MPI_COMBINER_CONTIGUOUS         MPI_Type_contiguous
MPI_COMBINER_VECTOR             MPI_Type_vector
MPI_COMBINER_HVECTOR            MPI_Type_hvector
                                  y MPI_Type_create_hvector
MPI_COMBINER_INDEXED            MPI_Type_indexed
MPI_COMBINER_HINDEXED           MPI_Type_hindexed
                                  y MPI_Type_create_hindexed
MPI_COMBINER_INDEXED_BLOCK      MPI_Type_create_indexed_block
MPI_COMBINER_STRUCT             MPI_Type_struct
                                  y MPI_Type_create_struct
MPI_COMBINER_SUBARRAY           MPI_Type_create_subarray
MPI_COMBINER_DARRAY             MPI_Type_create_darray
MPI_COMBINER_F90_REAL           MPI_Type_create_f90_real
MPI_COMBINER_F90_COMPLEX        MPI_Type_create_f90_complex
MPI_COMBINER_F90_INTEGER        MPI_Type_create_f90_integer
MPI_COMBINER_RESIZED            MPI_Type_create_resized

Si combiner es MPI_COMBINER_NAMED, entonces datatype es un tipo de dato predefinido con nombre.

Los argumentos reales utilizados en la llamada de creación para un tipo de dato se pueden obtener de la llamada MPI_Type_get_contents.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas de C como resultado de retorno de la función y las rutinas de Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores de MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores de MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utilizan exclusivamente los modos de sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo de mundo, o el argumento CLI mpi_initial_errhandler a mpiexec o clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa finalice todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo finaliza el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección Manejo de errores del estándar MPI-3.1 para obtener más información.
