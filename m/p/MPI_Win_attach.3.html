MPI_Win_attach(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_WIN_ATTACH(3) Open MPI MPI_WIN_ATTACH(3)

MPI_Win_attach, MPI_Win_detach - Llamada MPI de un solo lado que adjunta/desadjunta una región de memoria a/de un objeto de ventana para operaciones RMA.

SINTAXIS

Sintaxis C

#include <mpi.h>
MPI_Win_attach(MPI_Win win, void *base, MPI_Aint size)
MPI_Win_detach(MPI_Win win, void *base)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_WIN_ATTACH(WIN, BASE, SIZE, IERROR)
     <tipo> BASE(*)
     INTEGER(KIND=MPI_ADDRESS_KIND) SIZE
     INTEGER WIN, IERROR
MPI_WIN_DETACH(WIN, BASE, IERROR)
     <tipo> BASE(*)
     INTEGER WIN, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Win_attach(win, base, size, ierror)
     TYPE(MPI_Win), INTENT(IN) :: win
     TYPE(*), DIMENSION(..), INTENT(IN) :: base
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: size
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Win_detach(win, base, ierror)
     TYPE(MPI_Win), INTENT(IN) :: win
     TYPE(*), DIMENSION(..), INTENT(IN) :: base
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • win: Una ventana que se creó con MPI_Win_create_dynamic
  • base: Dirección inicial de la ventana (elección).
  • size: Tamaño de la ventana en bytes (entero no negativo).

PARÁMETROS DE SALIDA

  • win: Objeto de ventana devuelto por la llamada (handle).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Win_attach es una llamada de comunicación MPI de un solo lado utilizada para adjuntar una región de memoria de size bytes que comienza en la dirección base a una ventana para acceso RMA. La ventana win debe haber sido creada usando MPI_Win_create_dynamic. Se pueden adjuntar múltiples regiones de memoria no superpuestas a la misma ventana dinámica. Adjuntar regiones de memoria superpuestas a la misma ventana dinámica es erróneo.

Si el valor base utilizado por MPI_Win_attach fue asignado por MPI_Alloc_mem, el tamaño de la ventana no puede ser mayor que el valor establecido por la función MPI_Alloc_mem.

MPI_Win_detach se puede usar para desadjuntar una región de memoria adjuntada previamente de win. La dirección de memoria base y win deben coincidir con los argumentos pasados a una llamada anterior a MPI_Win_attach.

NOTAS

Utilice memoria asignada por MPI_Alloc_mem para garantizar límites de ventana correctamente alineados (como palabra, doble palabra, línea de caché, marco de página, etc.).

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección Manejo de Errores del estándar MPI-3.1 para obtener más información.
