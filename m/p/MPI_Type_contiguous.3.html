MPI_TYPE_CONTIGUOUS(3) Open MPI MPI_TYPE_CONTIGUOUS(3)

MPI_Type_contiguous — Crea un tipo de dato contiguo.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Type_contiguous(int count, MPI_Datatype oldtype,
     MPI_Datatype *newtype)

Sintaxis Fortran

USE MPI
! o la forma anterior: INCLUDE 'mpif.h'
MPI_TYPE_CONTIGUOUS(COUNT, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, OLDTYPE, NEWTYPE, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Type_contiguous(count, oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • count: Contador de replicación (entero no negativo).
  • oldtype: Tipo de dato antiguo (manejador).

PARÁMETROS DE SALIDA

  • newtype: Nuevo tipo de dato (manejador).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

El constructor de tipos de datos más simple es MPI_Type_contiguous, que permite la replicación de un tipo de dato en ubicaciones contiguas.

newtype es el tipo de dato obtenido al concatenar count copias de oldtype. La concatenación se define usando la extensión de oldtype como el tamaño de las copias concatenadas.

Ejemplo: Sea oldtype con mapa de tipos {(double, 0), (char, 8)}, con extensión 16, y sea count = 3. El mapa de tipos del tipo de dato devuelto por newtype es

{(double, 0), (char, 8), (double, 16), (char, 24),
(double, 32), (char, 40)];

es decir, elementos alternos de double y char, con desplazamientos 0, 8, 16, 24, 32, 40.

En general, supongamos que el mapa de tipos de oldtype es

{(type(0), disp(0)),...,(type(n-1), disp(n-1))},

con extensión ex. Entonces newtype tiene un mapa de tipos con count veces n entradas definidas por:

{(type(0), disp(0)), ...,(type(n-1), disp(n-1)),
(type(0), disp(0) + ex), ...,(type(n-1),
disp(n-1) + ex), ...,(type(0), disp(0) + ex * (count - 1)),
...,(type(n-1), disp(n-1) + ex * (count - 1))}.

Para más información sobre tipos de datos derivados, consulte el capítulo Tipos de Datos en el Estándar MPI.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error activa el manejador de errores inicial. El manejador de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpiexec mpi_initial_errhandler o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección Manejo de Errores del estándar MPI-3.1 para más información.
