MPI_Add_error_code — Crea un nuevo código de error asociado con errorclass

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Add_error_code(int errorclass, int *errorcode)

Sintaxis Fortran

USE MPI
! o la forma anterior: INCLUDE 'mpif.h'
MPI_ADD_ERROR_CODE(ERRORCLASS, ERRORCODE, IERROR)
     INTEGER  ERRORCLASS, ERRORCODE, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Add_error_code(errorclass, errorcode, ierror)
     INTEGER, INTENT(IN) :: errorclass
     INTEGER, INTENT(OUT) :: errorcode
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

•
errorclass: Clase de error de MPI (entero).

PARÁMETROS DE SALIDA

  • errorcode: Código de error devuelto por una rutina de MPI o una clase de error de MPI (entero).
  • ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

Crea un nuevo código de error asociado con errorclass y devuelve su valor en errorcode.

NOTAS

No se proporciona ninguna función para liberar códigos de error, ya que no se espera que una aplicación los cree en cantidades significativas.

El valor devuelto es siempre mayor o igual a MPI_ERR_LASTCODE.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al manejador de errores de MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada de MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores de MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usan exclusivamente los Modelos de Sesión) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento CLI mpi_initial_errhandler a mpiexec o la clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos de MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones de MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa de MPI pueda continuar después de un error.

Vea la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Vea la sección Manejo de Errores del estándar MPI-3.1 para más información.
