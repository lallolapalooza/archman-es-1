MPI_Graph_create(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_GRAPH_CREATE(3) Open MPI MPI_GRAPH_CREATE(3)

MPI_Graph_create — Crea un nuevo comunicador al que se ha adjuntado información de topología.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Graph_create(MPI_Comm comm_old, int nnodes, const int index[],
    const int edges[], int reorder, MPI_Comm *comm_graph)

Sintaxis Fortran

USE MPI
! o la forma anterior: INCLUDE 'mpif.h'
MPI_GRAPH_CREATE(COMM_OLD, NNODES, INDEX, EDGES, REORDER,
        COMM_GRAPH, IERROR)
    INTEGER COMM_OLD, NNODES, INDEX(*), EDGES(*)
    INTEGER COMM_GRAPH, IERROR
    LOGICAL   REORDER

Sintaxis Fortran 2008

USE mpi_f08
MPI_Graph_create(comm_old, nnodes, index, edges, reorder, comm_graph,
        ierror)
    TYPE(MPI_Comm), INTENT(IN) :: comm_old
    INTEGER, INTENT(IN) :: nnodes, index(nnodes), edges(*)
    LOGICAL, INTENT(IN) :: reorder
    TYPE(MPI_Comm), INTENT(OUT) :: comm_graph
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • comm_old : Comunicador de entrada sin topología (manejador).
  • nnodes : Número de nodos en el grafo (entero).
  • index : Arreglo de enteros que describe los grados de los nodos (ver abajo).
  • edges : Arreglo de enteros que describe los aristas del grafo (ver abajo).
  • reorder : El ordenamiento puede ser reordenado (true) o no (false) (lógico).

PARÁMETROS DE SALIDA

  • comm_graph : Comunicador con la topología de grafo añadida (manejador).
  • ierror : Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Graph_create devuelve un manejador a un nuevo comunicador al que se adjunta la información de la topología del grafo. Si reorder = false entonces el rango de cada proceso en el nuevo grupo es idéntico a su rango en el grupo antiguo. De lo contrario, la función puede reordenar los procesos. Si el tamaño, nnodes, del grafo es menor que el tamaño del grupo de comm_old, entonces a algunos procesos se les devuelve MPI_COMM_NULL, en analogía con MPI_Cart_create y MPI_Comm_split. La llamada es errónea si especifica un grafo que es más grande que el tamaño del grupo del comunicador de entrada.

Los tres parámetros nnodes, index, y edges definen la estructura del grafo. nnodes es el número de nodos del grafo. Los nodos se numeran de 0 a nnodes-1. La entrada i del arreglo index almacena el número total de vecinos de los primeros i nodos del grafo. Las listas de vecinos de los nodos 0, 1, …, nnodes-1 se almacenan en ubicaciones consecutivas en el arreglo edges. El arreglo edges es una representación aplanada de las listas de aristas. El número total de entradas en index es nnodes y el número total de entradas en edges es igual al número de aristas del grafo.

Las definiciones de los argumentos nnodes, index y edges se ilustran con el siguiente ejemplo sencillo.

Ejemplo: Supongamos que hay cuatro procesos 0, 1, 2, 3 con la siguiente matriz de adyacencia:

——- ——— Procesos Vecinos ——- ——— 0 1, 3 1 0 2 3 3 0, 2 ——- ———

Entonces, los argumentos de entrada son:

  • nodos = 4
  • index = 2, 3, 4, 6
  • edges = 1, 3, 0, 3, 0, 2

Por lo tanto, en C, index[0] es el grado del nodo cero, e index[i] - index[i-1] es el grado del nodo i, i=1, … , nnodes-1; la lista de vecinos del nodo cero se almacena en edges[j], para 0 <= j <= index[0] - 1 y la lista de vecinos del nodo i, i > 0 , se almacena en edges[j], index[i-1] <= j <= index[i] - 1.

En Fortran, index(1) es el grado del nodo cero, e index(i+1) - index(i) es el grado del nodo i, i=1, … , nnodes-1; la lista de vecinos del nodo cero se almacena en edges(j), para 1 <= j <= index(1) y la lista de vecinos del nodo i, i > 0, se almacena en edges(j), index(i) + 1 <= j <= index(i + 1).

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de error MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de error MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el controlador de error inicial. El controlador de error inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de error apropiado, entonces se llama al controlador de error MPI_ERRORS_RETURN para las funciones de E/S MPI y al controlador de error MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres controladores de error predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de error que puede ser invocado en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de error llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.

MPI_Graph_create(3)

NOMBRE

MPI_Graph_create - Crea un comunicador de grafo.

SINOPSIS


#include <mpi.h>
int MPI_Graph_create(MPI_Comm comm_old, int nnodes, const int indx[],
                     const int edges[], MPI_Comm *comm_graph);

ENTRADAS

comm_old
Comunicador antiguo (debe ser un comunicador de grupo).
nnodes
Número de nodos en el grafo.
indx
Array de tamaño nnodes. indx[i] contiene la posición en el array edges donde comienzan las aristas del nodo i. La entrada indx[nnodes] debe ser igual al número total de aristas.
edges
Array de tamaño indx[nnodes]. edges[j] contiene el índice de un nodo vecino para la arista j.

SALIDAS

comm_graph
Comunicador de grafo asociado con la topología de grafo.

DESCRIPCIÓN

La rutina MPI_Graph_create crea un nuevo comunicador de grafo con una topología de grafo asociada. Este nuevo comunicador contendrá el mismo conjunto de procesos que el comunicador comm_old.

El grafo se describe mediante los argumentos nnodes, indx y edges. El número de nodos en el grafo es nnodes. Los nodos se indexan de 0 a nnodes-1.

El array indx se utiliza para determinar los vecinos de cada nodo. Específicamente, los vecinos del nodo i son los nodos especificados por edges[k] para k desde indx[i] hasta indx[i+1]-1. Se debe cumplir que indx[nnodes] sea igual al número total de aristas en el grafo.

El array edges contiene los índices de los nodos vecinos. Para cada nodo i, el sub-array de edges especificado por indx[i] a indx[i+1]-1 define los nodos directamente conectados al nodo i.

NOTAS

La topología de grafo puede recuperarse del comunicador de grafo utilizando la rutina MPI_Graph_get.

El número de nodos especificado por nnodes debe ser igual al tamaño del comunicador comm_old.

ERRORES

La rutina MPI_Graph_create fallará si el comunicador comm_old no es un comunicador de grupo válido o si los argumentos de entrada son incorrectos (por ejemplo, nnodes no coincide con el tamaño del comunicador, o los arrays indx y edges están mal formados).
