MPI_T_PVAR_HANDLE_ALLOC(3) Open MPI MPI_T_PVAR_HANDLE_ALLOC(3)

MPI_T_pvar_handle_alloc, MPI_T_pvar_handle_free - Asignar/liberar identificadores de variables de rendimiento MPI

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_pvar_handle_alloc(int session, int pvar_index, void *obj_handle,
                            MPI_T_pvar_handle *handle, int *count)
int MPI_T_pvar_handle_free(int session, MPI_T_pvar_handle *handle)

DESCRIPCIÓN

MPI_T_pvar_handle_alloc enlaza la variable de rendimiento especificada en pvar_index con el objeto MPI especificado en obj_handle en la sesión identificada por el parámetro session. El objeto se pasa en el argumento obj_handle como una dirección a una variable local que almacena el identificador del objeto. Si MPI_T_pvar_get_info devuelve MPI_T_BIND_NO_OBJECT como el enlace para la variable, el argumento obj_handle se ignora. El identificador asignado para referenciar la variable se devuelve en el argumento handle. Tras una devolución exitosa, count contiene el número de elementos (del tipo de datos devuelto por una llamada previa a MPI_T_pvar_get_info) utilizados para representar esta variable.

El valor de pvar_index debe estar en el rango de 0 a num_pvar - 1, donde num_pvar es el número de variables de rendimiento disponibles, determinado por una llamada previa a MPI_T_pvar_get_num. El tipo del objeto MPI al que hace referencia debe ser consistente con el tipo devuelto en el argumento de enlace en una llamada previa a MPI_T_pvar_get_info.

MPI_T_pvar_handle_free libera un identificador asignado por MPI_T_pvar_handle_alloc y establece el argumento handle a MPI_T_PVAR_HANDLE_NULL.

ERRORES

MPI_T_pvar_handle_alloc fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_INDEX: El índice de la variable de rendimiento es inválido.
  • MPI_T_ERR_OUT_OF_HANDLES: No hay más identificadores disponibles.

MPI_T_pvar_handle_free fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_HANDLE: El identificador es inválido o el argumento de identificador pasado no está asociado con el argumento de sesión.

VER TAMBIÉN:

  • MPI_T_pvar_get_info
  • MPI_T_pvar_get_num
