MPI_COMM_SET_ATTR(3) Open MPI MPI_COMM_SET_ATTR(3)

MPI_Comm_set_attr — Almacena el valor del atributo asociado a una clave.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Comm_set_attr(MPI_Comm comm, int comm_keyval, void *attribute_val)

Sintaxis Fortran

USE MPI
! o la forma más antigua: INCLUDE 'mpif.h'
MPI_COMM_SET_ATTR(COMM, COMM_KEYVAL, ATTRIBUTE_VAL, IERROR)
     INTEGER COMM, COMM_KEYVAL, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) ATTRIBUTE_VAL

Sintaxis Fortran 2008

USE mpi_f08
MPI_Comm_set_attr(comm, comm_keyval, attribute_val, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(IN) :: comm_keyval
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: attribute_val
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO ENTRADA/SALIDA

•
comm: Comunicador del cual se adjuntará el atributo (identificador).

PARÁMETROS DE ENTRADA

  • comm_keyval: Valor de clave (entero).
  • attribute_val: Valor del atributo.

PARÁMETRO DE SALIDA

•
ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

MPI_Comm_set_attr almacena el valor de atributo especificado attribute_val para su posterior recuperación por MPI_Comm_get_attr. Si el valor ya está presente, entonces el resultado es como si MPI_Comm_delete_attr se hubiera llamado primero para eliminar el valor anterior (y la función de devolución de llamada delete_fn se hubiera ejecutado), y a continuación se almacenara un nuevo valor. La llamada es un error si no existe una clave con el valor comm_keyval; en particular, MPI_KEYVAL_INVALID es un valor de clave erróneo. La llamada fallará si la función delete_fn devolvió un código de error distinto de MPI_SUCCESS.

Esta función reemplaza a MPI_Attr_put, cuyo uso está deprecado. La vinculación C es idéntica. La vinculación Fortran difiere en que attribute_val es un entero del tamaño de una dirección.

NOTAS

Los valores de los atributos permanentes MPI_TAG_UB, MPI_HOST, MPI_IO y MPI_WTIME_IS_GLOBAL no se pueden cambiar.

El tipo del valor del atributo depende de si se está utilizando C o Fortran. En C, un valor de atributo es un puntero (void *); en Fortran, es un sistema de enteros único del tamaño de una dirección para el cual un puntero no cabe en un entero.

Si ya hay un atributo presente, se llamará a la función de eliminación (especificada cuando se creó el correspondiente keyval).

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error invoca al controlador de errores inicial. El controlador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o al argumento de línea de comandos mpi_initial_errhandler de mpiexec o a la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro controlador de errores apropiado, entonces se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo termina el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para ver una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para más información.
