MPI_Waitany(3) Open MPI MPI_Waitany(3)

MPI_Waitany — Espera la finalización de cualquier solicitud de envío o recepción especificada.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Waitany(int count, MPI_Request array_of_requests[],
     int *index, MPI_Status *status)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_WAITANY(COUNT, ARRAY_OF_REQUESTS, INDEX, STATUS, IERROR)
     INTEGER COUNT, ARRAY_OF_REQUESTS(*), INDEX
     INTEGER STATUS(MPI_STATUS_SIZE), IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Waitany(count, array_of_requests, index, status, ierror)
     INTEGER, INTENT(IN) :: count
     TYPE(MPI_Request), INTENT(INOUT) :: array_of_requests(count)
     INTEGER, INTENT(OUT) :: index
     TYPE(MPI_Status) :: status
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • count: Número (entero).
  • array_of_requests: Array de solicitudes (array de handles).

PARÁMETROS DE SALIDA

  • index: Índice del handle para la operación que se completó (entero). En el rango 0 a count-1. En Fortran, el rango es 1 a count.
  • status: Objeto de estado (status).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Una llamada a MPI_Waitany puede usarse para esperar la finalización de una solicitud de múltiples. La lista de solicitudes puede contener solicitudes nulas o inactivas. Si la lista no contiene solicitudes activas (lista de longitud cero o todos los elementos son nulos o inactivos), la llamada devuelve inmediatamente con index = MPI_UNDEFINED, y un estado vacío.

La ejecución de MPI_Waitany(count, array_of_requests, index, status) tiene el mismo efecto que la ejecución de MPI_Wait(&array_of_requests[i], status), donde i es el valor devuelto por index (a menos que el valor de index sea MPI_UNDEFINED). MPI_Waitany con una lista que contiene una sola entrada activa es equivalente a MPI_Wait.

Si tu aplicación no necesita examinar el campo status, puedes ahorrar recursos utilizando el valor predeterminado MPI_STATUS_IGNORE como valor especial para el argumento status.

Ejemplo: Código cliente-servidor (puede surgir el hambre).

CALL MPI_COMM_SIZE(comm, size, ierr)
CALL MPI_COMM_RANK(comm, rank, ierr)
IF(rank > 0) THEN         ! cliente
    DO
       CALL MPI_ISEND(a, n, MPI_REAL, 0, tag, comm, request, ierr)
       CALL MPI_WAIT(request, status, ierr)
    END DO
ELSE         ! rank=0: servidor
       DO i=1, size-1
          CALL MPI_IRECV(a(1,i), n, MPI_REAL, i tag, &
                   comm, request_list(i), ierr)
       END DO
       DO
          CALL MPI_WAITANY(size-1, request_list, index, status, ierr)
          CALL DO_SERVICE(a(1,index))  ! manejar un mensaje
          CALL MPI_IRECV(a(1, index), n, MPI_REAL, index, tag, &
                    comm, request_list(index), ierr)
       END DO
END IF

ERRORES

La mayoría de las rutinas MPI devuelven un valor de error; en las rutinas C, el valor es el valor de retorno de la función y en las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al manejador de error asociado con el objeto de comunicación (por ejemplo, communicator, window, file). Si no hay ningún objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada con MPI_COMM_SELF y se llama al manejador de error asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa el Modelo de Sesión exclusivamente), se genera el error inicial. El manejador de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se usa el Modelo del Mundo, o el argumento CLI mpi_initial_errhandler para mpiexec o la clave info para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay ningún otro manejador adecuado, se llama al manejador de error MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de error MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de error predeterminados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene los procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de error llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: Los errores de MPI no garantizan que un programa MPI pueda continuar después de un error.

Ver la página de manual de MPI para una lista completa de códigos de error de MPI.

Ver la sección de Manejo de Errores del estándar MPI-3.1 para más información.

Nota: Según la sección "Retorno de Estado" en el capítulo "Comunicación punto a punto" del estándar MPI, los errores en las solicitudes pasadas a MPI_Waitany no establecen el campo status.MPI_ERROR en el estado devuelto. El código de error siempre se pasa al manejador de errores de backend y puede ser devuelto al llamador a través del valor de retorno de MPI_Waitany si el manejador de errores de backend lo devuelve. El manejador de errores predeterminado MPI_ERRORS_RETURN muestra este comportamiento, por ejemplo.

NAME

MPI_Waitany - Waits for any one of a list of non-blocking communications to complete

SYNTAX

C

int MPI_Waitany(int count, MPI_Request array_of_requests[], MPI_Status statuses[]);

Fortran

SUBROUTINE MPI_WAITANY(COUNT, ARRAY_OF_REQUESTS, STATUSES, IERROR)
    INTEGER :: COUNT
    INTEGER, DIMENSION(..) :: ARRAY_OF_REQUESTS
    INTEGER, DIMENSION(MPI_MAX_STATE) :: STATUSES
    INTEGER :: IERROR

Fortran 03

SUBROUTINE MPI_WAITANY(COUNT, ARRAY_OF_REQUESTS, STATUSES, IERROR)
    INTEGER :: COUNT
    TYPE(MPI_Request), DIMENSION(..), ASYNCHRONOUS :: ARRAY_OF_REQUESTS
    TYPE(MPI_Status) :: STATUSES(..)
    INTEGER :: IERROR

Python

MPI.Request.Waitany(requests)

DESCRIPTION

MPI_Waitany blocks until one of the non-blocking communications specified in array_of_requests completes. The count argument specifies the number of requests in the list. The array_of_requests is an array of MPI_Request objects. The statuses argument is an array of MPI_Status objects that will contain information about the completed communication. The completed request in array_of_requests will be set to MPI_REQUEST_NULL and its corresponding status will be stored in statuses. If multiple communications complete at the same time, any one of them may be returned.

RETURN VALUE

Returns 0 on success. Otherwise, an error code is returned.

NOTES

The MPI_Request objects in array_of_requests are modified by this function. The completed request is set to MPI_REQUEST_NULL.

ERRORS

MPI_ERR_ARG: Invalid argument. One of the arguments is invalid. This is handled by the MPI library, and does not need to be handled by the user.
