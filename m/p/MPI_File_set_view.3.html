MPI_FILE_SET_VIEW(3) Open MPI MPI_FILE_SET_VIEW(3)

MPI_File_set_view — Cambia la vista de datos de un proceso en un archivo (colectivo).

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_File_set_view(MPI_File fh, MPI_Offset disp,
     MPI_Datatype etype, MPI_Datatype filetype,
     const char *datarep, MPI_Info info)

Sintaxis Fortran

USE MPI
! o la forma anterior: INCLUDE 'mpif.h'
MPI_FILE_SET_VIEW(FH, DISP, ETYPE,
     FILETYPE, DATAREP, INFO, IERROR)
     INTEGER FH, ETYPE, FILETYPE, INFO, IERROR
     CHARACTER*(*)   DATAREP
     INTEGER(KIND=MPI_OFFSET_KIND)   DISP

Sintaxis Fortran 2008

USE mpi_f08
MPI_File_set_view(fh, disp, etype, filetype, datarep, info, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: disp
     TYPE(MPI_Datatype), INTENT(IN) :: etype, filetype
     CHARACTER(LEN=*), INTENT(IN) :: datarep
     TYPE(MPI_Info), INTENT(IN) :: info
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA/SALIDA

•
fh: Manejador de archivo (handle).

PARÁMETROS DE ENTRADA

  • disp: Desplazamiento (entero).
  • etype: Tipo de dato elemental (handle).
  • filetype: Tipo de archivo (handle). Ver Restricciones, abajo.
  • datarep: Representación de datos (cadena).
  • info: Objeto de información (handle).

PARÁMETRO DE SALIDA

•
ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

La rutina MPI_File_set_view cambia la vista de los datos en el archivo para un proceso: el inicio de los datos accesibles en el archivo a través de esa vista se establece en disp; el tipo de datos se establece en etype; y la distribución de datos a los procesos se establece en filetype. Además, MPI_File_set_view reinicia los punteros de archivo independientes y el puntero de archivo compartido a cero. MPI_File_set_view es colectivo en fh; todos los procesos del grupo deben pasar valores idénticos para datarep y proporcionar un etype con una extensión idéntica. Los valores para disp, filetype e info pueden variar. Es erróneo usar las rutinas de acceso a datos del puntero de archivo compartido a menos que también se proporcionen valores idénticos para disp y filetype. Los tipos de datos pasados en etype y filetype deben estar comprometidos.

El argumento de desplazamiento disp especifica la posición (desplazamiento absoluto en bytes desde el principio del archivo) donde comienza la vista.

La interfaz MPI_File_set_view permite al usuario pasar una cadena de representación de datos a MPI I/O a través del argumento datarep. Para obtener el valor predeterminado, pase el valor "native". El usuario también puede pasar información a través del argumento info. Consulte la sección HINTS para obtener una lista de las sugerencias que se pueden establecer.

SUGERENCIAS

Las siguientes sugerencias se pueden usar como valores para el argumento info.

SUGERENCIAS ESTABLECIDAS

  • MPI_INFO_NULL
  • shared_file_timeout: Tiempo (en segundos) de espera para acceder al puntero de archivo compartido antes de salir con MPI_ERR_TIMEDOUT.
  • rwlock_timeout: Tiempo (en segundos) de espera para obtener un bloqueo de lectura o escritura en un fragmento contiguo de un archivo UNIX antes de salir con MPI_ERR_TIMEDOUT.
  • noncoll_read_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de lectura en las rutinas de acceso a datos no colectivas.

    NOTA:

Un tamaño de búfer menor que la distancia (en bytes) en un archivo UNIX entre el primer byte y el último byte de la solicitud de acceso hace que MPI I/O itere y realice múltiples llamadas read() o write() de UNIX. Si la solicitud incluye múltiples fragmentos de datos no contiguos, y el tamaño del búfer es mayor que el tamaño de esos fragmentos, entonces la llamada read() o write() de UNIX (hecha a nivel de MPI I/O) accederá a datos no solicitados por este proceso para reducir el número total de llamadas write() realizadas. Si este no es el comportamiento deseado, debe reducir este tamaño de búfer para que sea igual al tamaño de los fragmentos contiguos dentro de la solicitud agregada.
  • noncoll_write_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de escritura en las rutinas de acceso a datos no colectivas.

    Consulte la nota anterior en noncoll_read_bufsize.

  • coll_read_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de lectura en las rutinas de acceso a datos colectivas.

    Consulte la nota anterior en noncoll_read_bufsize.

  • coll_write_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de escritura en las rutinas de acceso a datos colectivas.

    Consulte la nota anterior en noncoll_read_bufsize.

  • mpiio_concurrency: (booleano) controla si las rutinas de E/S no bloqueantes pueden vincular un hilo adicional a un LWP.
  • mpiio_coll_contiguous: (booleano) controla si los accesos de datos colectivos subsiguientes solicitarán regiones contiguas colectivas del archivo.

SUGERENCIAS NO ESTABLECIDAS

•
filename: Acceda a esta sugerencia para obtener el nombre del archivo.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de error MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de error MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones), el error eleva el controlador de error inicial. El controlador de error inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler para mpiexec o clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de error apropiado, entonces se llama al controlador de error MPI_ERRORS_RETURN para las funciones de E/S MPI y al controlador de error MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres controladores de error predefinidos que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Hace que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de error que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si MPI_Abort fuera llamado en ese comunicador. Si se llama en una ventana o archivo, actúa como si MPI_Abort fuera llamado en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de error llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar

MPI_File_set_view(3)

NAME

MPI_File_set_view - Sets a new file view for a given MPI file handle.

SYNTAX

C

int MPI_File_set_view(MPI_File fh, MPI_Offset disp, MPI_Datatype datarep,
                      const char* datarep_string, MPI_Info info);

Fortran

subroutine MPI_FILE_SET_VIEW(FH, DISP, DATAREP, DATAREP_STRING, INFO, IERROR)
    integer :: FH, INFO, IERROR
    integer :: DATAREP
    character*(*) :: DATAREP_STRING
    long int :: DISP

C++

void MPI::File::Set_view(MPI::Offset disp, const MPI::Datatype& datarep,
                        const char* datarep_string, const MPI::Info& info);

INPUT/OUTPUT PARAMETER

MPI_File fh
File handle.
MPI_Offset disp
Displacement of the new view relative to the beginning of the file.
MPI_Datatype datarep
The new datatype representation.
const char* datarep_string
String representation of the datatype. This argument is deprecated and should be NULL.
MPI_Info info
Info object with hints for the file system.
MPI_Fint IERROR (Fortran)
Fortran only: MPI error status.

INPUT PARAMETERS

fh
File handle.
disp
Displacement of the new view relative to the beginning of the file.
datarep
The new datatype representation.
datarep_string
String representation of the datatype. This argument is deprecated and should be NULL.
info
Info object with hints for the file system.

OUTPUT PARAMETER

IERROR (Fortran)
Fortran only: MPI error status.

DESCRIPTION

MPI_File_set_view sets a new file view for the file referenced by fh. The file view defines how the data in the file is interpreted. The view consists of a displacement (disp), a datatype representation (datarep), and a datatype string (datarep_string).

The disp argument specifies the offset of the new view from the beginning of the file. The datarep argument specifies the datatype that will be used to access the data in the file. The datarep_string argument is a string representation of the datatype, and it is deprecated and should be set to NULL.

The info argument can be used to provide hints to the file system about how to optimize the access to the file. For example, it can specify the striping pattern of the file.

After calling MPI_File_set_view, all subsequent I/O operations on fh will use the new file view.

HINTS

The info parameter can be used to specify hints for the file system. Some common hints include:

  • striping_factor: The number of file servers to stripe across.
  • striping_unit: The size of each stripe.
  • access_direct: Whether to use direct access to the file system.

The specific hints supported depend on the underlying file system.

ERRORS

When the MPI standard is violated, the MPI_File_set_view function will raise an error. The error code is passed to the IERROR argument in Fortran. The following error codes are defined for MPI_File_set_view:

  • MPI_ERR_FILE: File handle is invalid.
  • MPI_ERR_DISP: Displacement is invalid.
  • MPI_ERR_DATATYPE: Datatype is invalid.
  • MPI_ERR_INFO: Info object is invalid.

See the MPI man page for a full list of MPI error codes.

See the Error Handling section of the MPI-3.1 standard for more information.

DESCRIPCIÓN

MPI_File_set_view establece una nueva vista de archivo para el archivo referenciado por fh. La vista de archivo define cómo se interpretan los datos en el archivo. La vista consta de un desplazamiento (disp), una representación de tipo de datos (datarep) y una cadena de tipo de datos (datarep_string).

El argumento disp especifica el desplazamiento de la nueva vista desde el principio del archivo. El argumento datarep especifica el tipo de datos que se utilizará para acceder a los datos en el archivo. El argumento datarep_string es una representación en cadena del tipo de datos, y está obsoleto y debe establecerse en NULL.

El argumento info se puede utilizar para proporcionar sugerencias al sistema de archivos sobre cómo optimizar el acceso al archivo. Por ejemplo, puede especificar el patrón de distribución (striping) del archivo.

Después de llamar a MPI_File_set_view, todas las operaciones de E/S subsiguientes en fh utilizarán la nueva vista de archivo.

SUGERENCIAS

El parámetro info se puede utilizar para especificar sugerencias para el sistema de archivos. Algunas sugerencias comunes incluyen:

  • striping_factor: El número de servidores de archivos sobre los que se distribuirá (striping).
  • striping_unit: El tamaño de cada tira (stripe).
  • access_direct: Si se utilizará acceso directo al sistema de archivos.

Las sugerencias específicas admitidas dependen del sistema de archivos subyacente.

ERRORES

Cuando se viola el estándar MPI, la función MPI_File_set_view generará un error. El código de error se pasa al argumento IERROR en Fortran. Los siguientes códigos de error están definidos para MPI_File_set_view:

  • MPI_ERR_FILE: El manejador de archivo no es válido.
  • MPI_ERR_DISP: El desplazamiento no es válido.
  • MPI_ERR_DATATYPE: El tipo de datos no es válido.
  • MPI_ERR_INFO: El objeto de información no es válido.

Consulte la página man de MPI para obtener una lista completa de códigos de error de MPI.

Consulte la sección Manejo de Errores del estándar MPI-3.1 para obtener más información.
