MPI_File_set_info(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_FILE_SET_INFO(3) Open MPI MPI_FILE_SET_INFO(3)

MPI_File_set_info — Establece nuevos valores para las pistas (colectivo).

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_File_set_info(MPI_File fh, MPI_Info info)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_FILE_SET_INFO(FH, INFO, IERROR)
     INTEGER FH, INFO, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_File_set_info(fh, info, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     TYPE(MPI_Info), INTENT(IN) :: info
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO DE ENTRADA/SALIDA

•
fh: Manejador de archivo (handle).

PARÁMETRO DE ENTRADA

•
info: Objeto Info (handle).

PARÁMETRO DE SALIDA

•
ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_File_set_info es una rutina colectiva que establece nuevos valores para las pistas del archivo asociado con fh. Estas pistas se establecen para cada archivo, utilizando las rutinas MPI_File_open, MPI_File_delete, MPI_File_set_view y MPI_File_set_info. El objeto info opaco, que permite proporcionar pistas para la optimización de su código, puede ser diferente en cada proceso, pero algunas entradas de info deben ser iguales en todos los procesos: En estos casos, deben aparecer con el mismo valor en el objeto info de cada proceso. Consulte la sección PISTAS para ver una lista de las pistas que se pueden establecer.

PISTAS

Las siguientes pistas se pueden utilizar como valores para el argumento info.

PISTAS ESTABLECIBLES

  • shared_file_timeout: Cantidad de tiempo (en segundos) para esperar el acceso al puntero de archivo compartido antes de salir con MPI_ERR_TIMEDOUT.
  • rwlock_timeout: Cantidad de tiempo (en segundos) para esperar a obtener un bloqueo de lectura o escritura en un fragmento contiguo de un archivo UNIX antes de salir con MPI_ERR_TIMEDOUT.
  • noncoll_read_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de lectura en las rutinas de acceso a datos no colectivas.

    NOTA:

Un tamaño de búfer menor que la distancia (en bytes) en un archivo UNIX entre el primer byte y el último byte de la solicitud de acceso hace que MPI I/O itere y realice múltiples llamadas read() o write() de UNIX. Si la solicitud incluye múltiples fragmentos de datos no contiguos, y el tamaño del búfer es mayor que el tamaño de esos fragmentos, entonces la llamada read() o write() de UNIX (realizada a nivel de MPI I/O) accederá a datos no solicitados por este proceso para reducir el número total de llamadas write() realizadas. Si este comportamiento no es deseable, debe reducir este tamaño de búfer para que sea igual al tamaño de los fragmentos contiguos dentro de la solicitud agregada.
  • noncoll_write_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de escritura en las rutinas de acceso a datos no colectivas.

    Consulte la nota anterior en noncoll_read_bufsize.

  • coll_read_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de lectura en las rutinas de acceso a datos colectivas.

    Consulte la nota anterior en noncoll_read_bufsize.

  • coll_write_bufsize: Tamaño máximo del búfer utilizado por MPI I/O para satisfacer las solicitudes de escritura en las rutinas de acceso a datos colectivas.

    Consulte la nota anterior en noncoll_read_bufsize.

  • mpiio_concurrency: (booleano) controla si las rutinas de E/S no bloqueantes pueden vincular un hilo adicional a un LWP.
  • mpiio_coll_contiguous: (booleano) controla si los accesos a datos colectivos posteriores solicitarán regiones contiguas colectivamente del archivo.

    PISTAS NO ESTABLECIBLES

  • filename: Acceda a esta pista para obtener el nombre del archivo.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo Mundial, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o la clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Hace que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para más información.
