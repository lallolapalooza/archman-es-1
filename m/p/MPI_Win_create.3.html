MPI_Win_create(3) Open MPI MPI_Win_create(3)

MPI_Win_create — Una llamada MPI unidireccional que devuelve un objeto de ventana para operaciones RMA.

SINTAXIS

Sintaxis C

#include <mpi.h>
MPI_Win_create(void *base, MPI_Aint size, int disp_unit,
     MPI_Info info, MPI_Comm comm, MPI_Win *win)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_WIN_CREATE(BASE, SIZE, DISP_UNIT, INFO, COMM, WIN, IERROR)
     <type> BASE(*)
     INTEGER(KIND=MPI_ADDRESS_KIND) SIZE
     INTEGER DISP_UNIT, INFO, COMM, WIN, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Win_create(base, size, disp_unit, info, comm, win, ierror)
     TYPE(*), DIMENSION(..), ASYNCHRONOUS :: base
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: size
     INTEGER, INTENT(IN) :: disp_unit
     TYPE(MPI_Info), INTENT(IN) :: info
     TYPE(MPI_Comm), INTENT(IN) :: comm
     TYPE(MPI_Win), INTENT(OUT) :: win
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • base: Dirección inicial de la ventana (elección).
  • size: Tamaño de la ventana en bytes (entero no negativo).
  • disp_unit: Unidad de desplazamiento local, en bytes (entero positivo).
  • info: Argumento de información (handle).
  • comm: Comunicador (handle).

PARÁMETROS DE SALIDA

  • win: Objeto de ventana devuelto por la llamada (handle).
  • ierror: Solo en Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Win_create es una llamada MPI comunicativa colectiva unidireccional ejecutada por todos los procesos en el grupo de comm. Devuelve un objeto de ventana que puede usarse por estos procesos para realizar operaciones RMA. Cada proceso especifica una ventana de memoria existente que expone a las operaciones RMA de los procesos en el grupo de comm. La ventana consiste en size de bytes, comenzando en la dirección base. Un proceso puede elegir exponer ninguna memoria especificando size = 0.

Si el valor base utilizado por MPI_Win_create fue asignado por MPI_Alloc_mem, el tamaño de la ventana no puede ser mayor que el valor establecido por la función MPI_Alloc_mem.

El valor de disp_unit se proporciona para facilitar el cálculo de desplazamientos en operaciones RMA: el desplazamiento argumento de una operación RMA se escala por el factor disp_unit especificado por el proceso objetivo, al crear la ventana.

Las siguientes claves de información son soportadas:

no_locks
Si se establece en true, la implementación puede asumir que la ventana local no está bloqueada (por una llamada a MPI_Win_lock o MPI_Win_lock_all). La configuración de este valor si es solo de sincronización activa puede permitir a la implementación habilitar ciertas optimizaciones.
accumulate_ordering
Por defecto, las operaciones de acumulación de un iniciador a un objetivo en la misma ubicación de memoria de la ventana son estrictamente ordenadas. Si la clave de información accumulate_ordering se establece en none, no se garantiza ninguna ordenación de operaciones de acumulación. La clave también puede ser una lista separada por comas de ordenes requeridas de rar, war, raw y waw para lectura después de lectura, escritura después de lectura, lectura después de escritura y escritura después de escritura, respectivamente. Las restricciones de ordenación más laxas pueden resultar en mejor rendimiento.
accumulate_ops
Si se establece en same_op, la implementación asume que todas las llamadas concurrentes a la misma dirección objetivo utilizarán la misma operación. Si se establece en same_op_no_op, la implementación asume que todas las llamadas concurrentes a la misma dirección objetivo utilizarán la misma operación o MPI_NO_OP. El valor por defecto es same_op_no_op.
same_size
Si se establece en true, la implementación puede asumir que el valor size es idéntico en todos los procesos, y que todos los procesos han proporcionado esta clave de información con el mismo valor.
same_disp_unit
Si se establece en true, la implementación puede asumir que el valor disp_unit es idéntico en todos los procesos, y que todos los procesos han proporcionado esta clave de información con el mismo valor.

NOTAS

Las elecciones comunes para disp_unit son 1 (sin escalado) y, en la sintaxis C, sizeof(type), para una ventana que consiste en un array de elementos de tipo type. La elección posterior permite usar índices de array en llamadas RMA y tener los desplazamientos escalados correctamente, incluso en entornos heterogéneos.

Use la memoria asignada por MPI_Alloc_mem para garantizar bordes de ventana bien alineados (como palabra, doble palabra, línea de caché, página de frame, etc.).

ERRORES

La mayoría de las rutinas MPI devuelven un valor de error; las rutinas C devuelven el resultado de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al manejador de errores asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) actual. Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y se llamará al manejador de errores asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza el modelo de Sesiones exclusivamente), se eleva el error inicial. El manejador de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler con MPI_COMM_SELF cuando se use el modelo del Mundo, o mediante el argumento cli mpi_initial_errhandler en mpiexec o mediante la clave de información MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de errores adecuado, se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos conectados a MPI.
  • MPI_ERRORS_ABORT Un manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene los procesos en la correspondiente ventana o archivo. Si se invoca en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: Las aplicaciones MPI no garantizan que un programa MPI pueda continuar después de un error.

Ver la página del manual de MPI para una lista completa de códigos de error MPI.
