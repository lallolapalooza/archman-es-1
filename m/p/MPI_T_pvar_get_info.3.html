MPI_T_pvar_get_info — Consultar información de una variable de rendimiento

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_T_pvar_get_info(int pvar_index, char *name, int *name_len,
                        int *verbosity, int *var_class, MPI_Datatype *datatype, MPI_T_enum *enumtype,
                        char *desc, int *desc_len, int *bind, int *readonly, int *continuous,
                        int *atomic)

PARÁMETROS DE ENTRADA

•
pvar_index: Índice de la variable de rendimiento a consultar.

PARÁMETROS DE ENTRADA/SALIDA

  • name_len: Longitud de la cadena y/o buffer para el nombre.
  • desc_len: Longitud de la cadena y/o buffer para la descripción.

PARÁMETROS DE SALIDA

  • name: Buffer para devolver la cadena que contiene el nombre de la variable de rendimiento.
  • verbosity: Nivel de verbosidad de esta variable.
  • var_class: Clase de la variable de rendimiento.
  • datatype: Tipo de dato MPI de la información almacenada en la variable de rendimiento.
  • enumtype: Descriptor opcional para información de enumeración.
  • desc: Buffer para devolver la cadena que contiene la descripción de la variable de rendimiento.
  • bind: Tipo de objeto MPI al que debe enlazarse esta variable.
  • readonly: Indicador de si la variable puede ser escrita/reiniciada.
  • continuous: Indicador de si la variable puede iniciarse y detenerse o si está continuamente activa.
  • atomic: Indicador de si la variable puede leerse y reiniciarse atómicamente.

DESCRIPCIÓN

MPI_T_pvar_get_info se puede usar para consultar información de una variable de rendimiento. La función devuelve la verbosidad, clase, tipo de dato, tipo de enumeración y enlace de la variable de control consultada en los argumentos verbosity, var_class, datatype, enumtype y bind respectivamente. Los indicadores que señalan si la variable es de solo lectura, continua o atómica se devuelven en readonly, continuous y atomic respectivamente. Véase la sección 14.3.7 de MPI-3 para más información. Véase la página del manual de MPI_T_cvar_get_info para obtener información sobre la verbosidad de las variables.

CLASE DE VARIABLE

Las variables de rendimiento se categorizan en clases que describen su valor inicial, tipos válidos y comportamiento. La clase devuelta en el parámetro var_class puede ser una de las siguientes:

  • MPI_T_PVAR_CLASS_STATE: La variable representa un conjunto de estados discretos que pueden ser descritos por un enumerador. Las variables de esta clase deben representarse mediante un MPI_INT. El valor inicial es el estado actual de la variable.
  • MPI_T_PVAR_CLASS_LEVEL: La variable representa el nivel de utilización actual de un recurso. Las variables de esta clase deben representarse mediante un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG o MPI_DOUBLE. El valor inicial es el nivel de utilización actual del recurso.
  • MPI_T_PVAR_CLASS_SIZE: La variable representa el tamaño fijo de un recurso. Las variables de esta clase se representan mediante un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG o MPI_DOUBLE. El valor inicial es el tamaño actual del recurso.
  • MPI_T_PVAR_CLASS_PERCENTAGE: La variable representa el nivel de utilización porcentual actual de un recurso. Las variables de esta clase se representan mediante un MPI_DOUBLE. El valor inicial es la utilización porcentual actual del recurso.
  • MPI_T_PVAR_CLASS_HIGHWATERMARK: La variable representa la marca de agua alta de la utilización de un recurso. Las variables de esta clase se representan mediante un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG o MPI_DOUBLE. El valor inicial es la utilización actual del recurso.
  • MPI_T_PVAR_CLASS_LOWWATERMARK: La variable representa la marca de agua baja de la utilización de un recurso. Las variables de esta clase se representan mediante un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG o MPI_DOUBLE. El valor inicial es la utilización actual del recurso.
  • MPI_T_PVAR_CLASS_COUNTER: La variable representa un recuento del número de ocurrencias de un evento específico. Las variables de esta clase se representan mediante un MPI_UNSIGNED, MPI_UNSIGNED_LONG o MPI_UNSIGNED_LONG_LONG. El valor inicial es 0.
  • MPI_T_PVAR_CLASS_AGGREGATE: La variable representa un valor agregado que representa una suma de argumentos procesados durante un evento específico. Las variables de esta clase se representan mediante un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG o MPI_DOUBLE. El valor inicial es 0.
  • MPI_T_PVAR_CLASS_TIMER: La variable representa el tiempo agregado gastado por la implementación MPI mientras procesaba un evento, tipo de evento o sección de código. Las variables de esta clase se representan mediante un MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG o MPI_DOUBLE. Si la variable se representa mediante un MPI_DOUBLE, las unidades serán las mismas que las utilizadas por MPI_Wtime(). El valor inicial es 0.
  • MPI_T_PVAR_CLASS_GENERIC: La variable no encaja en ninguna otra clase. Puede representarse mediante un tipo de dato compatible con la interfaz de información de herramientas MPI (véase DATATYPE). El valor inicial es específico de la variable.

Para más información, véase la sección 14.3.7 de MPI-3.

TIPO DE DATO

El tipo de dato devuelto por MPI_T_pvar_get_info está restringido a uno de los siguientes tipos de datos: MPI_INT, MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG, MPI_COUNT, MPI_CHAR y MPI_DOUBLE. Para más información sobre los tipos de datos en la interfaz de información de herramientas MPI, véase la sección 14.3.5 de MPI-3.

ENLACE

Las variables de rendimiento pueden enlazarse a un objeto MPI. El enlace devuelto en el parámetro bind puede ser uno de los siguientes:

  • MPI_T_BIND_NO_OBJECT: Ningún objeto
  • MPI_T_BIND_MPI_COMM: Comunicador MPI
  • MPI_T_BIND_MPI_DATATYPE: Tipo de dato MPI
  • MPI_T_BIND_MPI_ERRHANDLER: Manejador de errores MPI
  • MPI_T_BIND_MPI_FILE: Manejador de archivo MPI
  • MPI_T_BIND_MPI_GROUP: Grupo MPI
  • MPI_T_BIND_MPI_OP: Operador de reducción MPI
  • MPI_T_BIND_MPI_REQUEST: Petición MPI
  • MPI_T_BIND_MPI_WIN: Ventana MPI para comunicación unidireccional
  • MPI_T_BIND_MPI_MESSAGE: Objeto de mensaje MPI
  • MPI_T_BIND_MPI_INFO: Objeto de información MPI

Para más información, véase la sección 14.3.2 de MPI-3.

NOTAS

Esta función de interfaz de herramientas MPI devuelve dos cadenas de caracteres. Esta función toma dos argumentos para cada cadena: un buffer para almacenar la cadena y una longitud que inicialmente debe especificar el tamaño del buffer. Si la longitud pasada es n, esta función copiará como máximo n - 1 caracteres de la cadena en el buffer correspondiente y establecerá la longitud en el número de caracteres copiados - 1. Si el argumento de longitud es NULL o el valor especificado en la longitud es 0, se ignora el buffer de cadena correspondiente y no se devuelve la cadena. Para más información, véase la sección 14.3.3 de MPI-3.

ERRORES

MPI_T_pvar_get_info fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_INDEX: El índice de la variable de rendimiento no es válido.
