MPI_File_preallocate(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_FILE_PREALLOCATE(3) Open MPI MPI_FILE_PREALLOCATE(3)

MPI_File_preallocate — Preasigna una cantidad especificada de espacio de almacenamiento al principio de un archivo (colectivo).

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_File_preallocate(MPI_File fh, MPI_Offset size)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_FILE_PREALLOCATE(FH, SIZE, IERROR)
     INTEGER FH, IERROR
     INTEGER(KIND=MPI_OFFSET_KIND)   SIZE

Sintaxis Fortran 2008

USE mpi_f08
MPI_File_preallocate(fh, size, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: size
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETRO ENTRADA/SALIDA

•
fh: Identificador del archivo (identificador).

PARÁMETRO DE ENTRADA

•
size: Tamaño a preasignar al archivo, en bytes (entero).

PARÁMETRO DE SALIDA

•
ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_File_preallocate asegura que se asigne espacio de almacenamiento para los primeros size bytes del archivo asociado con fh. MPI_File_preallocate puede ser una operación que consume mucho tiempo.

MPI_File_preallocate es colectiva; todos los procesos del grupo deben pasar valores idénticos para size. Las regiones del archivo que se han escrito previamente no se ven afectadas. Para las regiones del archivo recién asignadas, MPI_File_preallocate tiene el mismo efecto que escribir datos indefinidos. Si size es mayor que el tamaño actual del archivo, el tamaño del archivo aumenta a size. Si size es menor o igual que el tamaño actual del archivo, el tamaño del archivo no cambia.

El tratamiento de los punteros de archivo, accesos no bloqueantes pendientes y consistencia del archivo es el mismo que con MPI_File_set_size. Si se especificó el modo MPI_MODE_SEQUENTIAL al abrir el archivo, es erróneo llamar a esta rutina.

NOTAS

Cuando se utiliza la rutina colectiva MPI_File_set_size en un archivo UNIX, si el tamaño que se establece es menor que el tamaño actual del archivo, el archivo se trunca en la posición definida por size. Si el tamaño se establece para ser mayor que el tamaño actual del archivo, el tamaño del archivo se convierte en el tamaño establecido. Cuando el tamaño del archivo aumenta de esta manera con MPI_File_set_size, se crean nuevas regiones en el archivo con desplazamientos entre el tamaño antiguo del archivo y el tamaño más grande recién establecido.

El I/O de Sun MPI no necesariamente asigna espacio en el archivo para dichas nuevas regiones. Puede reservar espacio en el archivo utilizando MPI_File_preallocate o realizando una lectura o escritura en bytes determinados.

ERRORES

Casi todas las rutinas de MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores de MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores de MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/ MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones) el error eleva el controlador de errores inicial. El controlador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler a mpiexec o la clave de información a MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de errores apropiado, entonces se llama al controlador de errores MPI_ERRORS_RETURN para las funciones de I/O de MPI y al controlador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos de la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
