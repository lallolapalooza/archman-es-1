Paquete: openmpi

MPI_CART_SHIFT(3) Open MPI MPI_CART_SHIFT(3)

MPI_Cart_shift — Devuelve los rangos de origen y destino desplazados, dada una dirección y cantidad de desplazamiento.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Cart_shift(MPI_Comm comm, int direction, int disp,
    int *rank_source, int *rank_dest)

Sintaxis Fortran

USE MPI
! o la forma más antigua: INCLUDE 'mpif.h'
MPI_CART_SHIFT(COMM, DIRECTION, DISP, RANK_SOURCE,
        RANK_DEST, IERROR)
    INTEGER COMM, DIRECTION, DISP, RANK_SOURCE
    INTEGER RANK_DEST, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Cart_shift(comm, direction, disp, rank_source, rank_dest, ierror)
    TYPE(MPI_Comm), INTENT(IN) :: comm
    INTEGER, INTENT(IN) :: direction, disp
    INTEGER, INTENT(OUT) :: rank_source, rank_dest
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • comm : Comunicador con estructura Cartesiana (handle).
  • direction : Dimensión de coordenada del desplazamiento (entero).
disp
Desplazamiento (> 0: desplazamiento ascendente, < 0: desplazamiento descendente) (entero).

PARÁMETROS DE SALIDA

  • rank_source : Rango del proceso de origen (entero).
  • rank_dest : Rango del proceso de destino (entero).
  • ierror : Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Si la topología del proceso es una estructura Cartesiana, es probable que se utilice una operación MPI_Sendrecv a lo largo de una dirección de coordenada para realizar un desplazamiento de datos. Como entrada, MPI_Sendrecv toma el rango de un proceso de origen para la recepción y el rango de un proceso de destino para el envío. Si la función MPI_Cart_shift se llama para un grupo de procesos Cartesiano, proporciona al proceso que llama los identificadores anteriores, que luego pueden pasarse a MPI_Sendrecv. El usuario especifica la dirección de coordenada y el tamaño del paso (positivo o negativo). La función es local.

El argumento direction indica la dimensión del desplazamiento, es decir, la coordenada cuyo valor se modifica con el desplazamiento. Las coordenadas se numeran de 0 a ndims-1, donde ndims es el número de dimensiones.

Nota: El argumento direction está en el rango [0, n-1] para una malla Cartesiana n-dimensional.

Dependiendo de la periodicidad del grupo Cartesiano en la dirección de coordenada especificada, MPI_Cart_shift proporciona los identificadores para un desplazamiento circular o un desplazamiento de extremo cerrado. En el caso de un desplazamiento de extremo cerrado, el valor MPI_PROC_NULL puede devolverse en rank_source o rank_dest, lo que indica que el origen o el destino del desplazamiento está fuera de rango.

Ejemplo: El comunicador comm tiene una topología Cartesiana bidimensional y periódica asociada con él. Un array bidimensional de REALs se almacena un elemento por proceso, en la variable A. Se desea sesgar este array, desplazando la columna i (verticalmente, es decir, a lo largo de la columna) en i pasos.

! encontrar rango del proceso
    CALL MPI_COMM_RANK(comm, rank, ierr)
! encontrar coordenadas cartesianas
    CALL MPI_CART_COORDS(comm, rank, maxdims, coords, ierr)
! calcular origen y destino del desplazamiento
    CALL MPI_CART_SHIFT(comm, 0, coords(2), source, dest, ierr)
! sesgar array
    CALL MPI_SENDRECV_REPLACE(A, 1, MPI_REAL, dest, 0, source, 0, comm, status,
                              ierr)

NOTA

En Fortran, la dimensión indicada por DIRECTION = i tiene DIMS(i+1) nodos, donde DIMS es el array que se utilizó para crear la malla. En C, la dimensión indicada por direction = i es la dimensión especificada por dims[i].

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de error MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay ningún objeto de comunicación asociado con la llamada MPI, la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de error MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se utiliza exclusivamente el Modelo de Sesiones), el error eleva el controlador de error inicial. El controlador de error inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o al argumento de CLI mpi_initial_errhandler para mpiexec o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro controlador de error apropiado, entonces el controlador de error MPI_ERRORS_RETURN se llama para las funciones de E/S MPI y el controlador de error MPI_ERRORS_ABORT se llama para todas las demás funciones MPI.

Open MPI incluye tres controladores de error predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de error que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado a MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado a MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de error llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección Manejo de errores del estándar MPI-3.1 para obtener más información.

MPI_Cart_shift(3)

NAME

MPI_Cart_shift - Computes ranks of processes in a Cartesian topology

SYNOPSIS

C++:

int MPI::Cartcomm::Shift(int direction, int displacement, int& rank_source, int& rank_dest) const;

C:

int MPI_Cart_shift(MPI_Comm comm, int direction, int displacement, int* rank_source, int* rank_dest);

Fortran:

SUBROUTINE MPI_CART_SHIFT(COMM, DIRECTION, DISPLACEMENT, RANK_SOURCE, RANK_DEST, IERROR)

Fortran 2008:

FUNCTION MPI_CART_SHIFT(COMM, DIRECTION, DISPLACEMENT, RANK_SOURCE, RANK_DEST) RESULT(IERROR)

DESCRIPTION

MPI_Cart_shift calculates the ranks of the source and destination processes for a communication operation in a given direction of a Cartesian topology.

The communicator must be a Cartesian communicator created by MPI_Cart_create or MPI_Cart_create_with_dims.

The direction specifies the dimension along which the shift is performed. For a topology with N dimensions, direction can range from 0 to N-1.

The displacement specifies the number of steps to shift in the given direction. A positive displacement shifts in the increasing direction, while a negative displacement shifts in the decreasing direction.

rank_source and rank_dest are output arguments that will contain the ranks of the source and destination processes, respectively. If no process exists in the specified direction and displacement (e.g., shifting off the grid), the rank will be MPI_PROC_NULL.

ARGUMENTS

  • comm: Communicator with a Cartesian topology.
  • direction: The dimension along which to shift.
  • displacement: The number of steps to shift.
  • rank_source: Rank of the source process.
  • rank_dest: Rank of the destination process.
  • IERROR (Fortran): Error code.

RETURN VALUE

On success, MPI_Cart_shift returns MPI_SUCCESS. Otherwise, it returns an error code.

EXAMPLES

Consider a 2x3 Cartesian topology:


int rank_source, rank_dest;
MPI_Cart_shift(cart_comm, 0, 1, &rank_source, &rank_dest);
// rank_source will be the rank of the process "below" in the first dimension
// rank_dest will be the rank of the process "above" in the first dimension
