MPI_T_enum_get_item — Consulta información sobre un enumerador

SINTAXIS

Sintaxis en C

#include <mpi.h>
int MPI_T_enum_get_item(MPI_T_enum enumtype, int index, int *value, char *name,
                        int *name_len)

PARÁMETROS DE ENTRADA

  • enumtype: Enumeración a consultar.
  • index: Número del valor a consultar en esta enumeración.

PARÁMETROS DE ENTRADA/SALIDA

•
name_len: Longitud de la cadena y/o búfer para el nombre.

PARÁMETROS DE SALIDA

  • value: Valor de la variable.
  • name: Búfer para devolver la cadena que contiene el nombre de la categoría.

DESCRIPCIÓN

MPI_T_enum_get_item se puede utilizar para consultar información sobre un elemento de un enumerador. Esta función devuelve el valor de enumeración en el parámetro value.

NOTAS

Esta función de interfaz de herramientas MPI devuelve el nombre del elemento como una cadena. Esta función toma dos argumentos para la cadena: un búfer para almacenar la cadena y una longitud que inicialmente debe especificar el tamaño del búfer. Si la longitud proporcionada es n, esta función copiará como máximo n - 1 caracteres de la cadena en el búfer y establecerá la longitud en el número de caracteres copiados, menos 1. Si el argumento de longitud es NULL o el valor especificado en la longitud es 0, se ignora el búfer de cadena y no se devuelve la cadena. Para más información, consulte la sección 14.3.3 de MPI-3.

ERRORES

MPI_T_enum_get_item fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_INDEX: La enumeración no es válida o ha sido eliminada.
