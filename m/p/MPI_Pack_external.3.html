MPI_Pack_external(3) Open MPI MPI_Pack_external(3)

MPI_Pack_external escribe datos en un formato portable

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Pack_external(const char *datarep, const void *inbuf,
     int incount, MPI_Datatype datatype,
     void *outbuf, MPI_Aint outsize,
     MPI_Aint *position)

Sintaxis Fortran

USE MPI
! o la antigua forma: INCLUDE 'mpif.h'
MPI_PACK_EXTERNAL(DATAREP, INBUF, INCOUNT, DATATYPE,
     OUTBUF, OUTSIZE, POSITION, IERROR)
     INTEGER         INCOUNT, DATATYPE, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) OUTSIZE, POSITION
     CHARACTER*(*)   DATAREP
               INBUF(*), OUTBUF(*)

Sintaxis Fortran 2008

USE mpi_f08
MPI_Pack_external(datarep, inbuf, incount, datatype, outbuf, outsize,
             position, ierror)
     CHARACTER(LEN=*), INTENT(IN) :: datarep
     TYPE(*), DIMENSION(..), INTENT(IN) :: inbuf
     TYPE(*), DIMENSION(..) :: outbuf
     INTEGER, INTENT(IN) :: incount
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: outsize
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(INOUT) :: position
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • datarep: Formato de datos (cadena).
  • inbuf: Puntero de buffer de entrada (opcional).
  • incount: Número de elementos de entrada (entero).
  • datatype: Tipo de dato de cada elemento de entrada (handle).
  • outsize: Tamaño del buffer de salida en bytes (entero).

PARÁMETRO DE ENTRADA/SALIDA

•
position: Posición actual en el buffer, en bytes (entero).

PARÁMETROS DE SALIDA

  • outbuf: Puntero de buffer de salida (opcional).
  • ierror: Solo en Fortran: Estado de error (entero).

DESCRIPCIÓN

MPI_Pack_external empaqueta datos en el formato extern32, un formato universal de representación de datos definido por el Foro MPI. Este formato es útil para intercambiar datos entre implementaciones de MPI, o cuando se escriben datos a un archivo.

El buffer de entrada se especifica mediante inbuf, incount y datatype, y puede ser cualquier buffer de comunicación permitido en MPI_Send. El buffer de salida outbuf debe ser un área de almacenamiento contigua que contenga outsize bytes.

El valor inicial de position es la posición inicial en outbuf para empaquetar (medida en bytes, no en elementos, relativa al inicio del buffer). Cuando la función devuelve, position se incrementa por el tamaño del mensaje empaquetado, así señalando el primer lugar en outbuf después del mensaje empaquetado. De esta manera, puede usarse como entrada para una llamada posterior a MPI_Pack_external.

Ejemplo: Un ejemplo usando MPI_Pack_external:

int position, i;
double msg[5];
char buf[1000];
...
MPI_Comm_rank(MPI_COMM_WORLD, &myrank);
if (myrank == 0) {      /* CÓDIGO DEL EMISOR */
        position = 0;
        i = 5; /* número de doubles en msg[] */
        MPI_Pack_external("external32", &i, 1, MPI_INT,
            buf, 1000, &position);
        MPI_Pack_external("external32", &msg, i, MPI_DOUBLE,
            buf, 1000, &position);
        MPI_Send(buf, position, MPI_BYTE, 1, 0,
            MPI_COMM_WORLD);
} else {                /* CÓDIGO DEL RECEPTOR */
        MPI_Recv(buf, 1, MPI_BYTE, 0, 0, MPI_COMM_WORLD,
            MPI_STATUS_IGNORE);
        MPI_Unpack_external("external32", buf, 1000,
            MPI_INT, &i, 1, &position);
        MPI_Unpack_external("external32", buf, 1000,
            MPI_DOUBLE, &msg, i, &position);
}

NOTAS

El argumento datarep especifica el formato de los datos. El único valor válido en la versión actual de MPI es external32. El argumento se proporciona para futura extensibilidad.

Para entender el comportamiento de empaquetado y desempaquetado, es conveniente pensar que la parte de datos de un mensaje es la secuencia obtenida al concatenar los valores sucesivos enviados en ese mensaje. La operación de empaquetado almacena esta secuencia en el espacio de buffer, como si estuviera enviando el mensaje a ese buffer. La operación de desempaquetado recoge esta secuencia del espacio de buffer, como si estuviera recibiendo un mensaje de ese buffer. (Es útil pensar en archivos internos de Fortran o en sscanf en C para una función similar.)

Varios mensajes pueden ser empaquetados sucesivamente en una unidad de empaquetado. Esto se logra mediante varias llamadas sucesivas relacionadas a MPI_Pack_external, donde la primera llamada proporciona position=0, y cada llamada sucesiva introduce el valor de position que fue devuelto por la llamada anterior, junto con los mismos valores para outbuf y outcount. Esta unidad de empaquetado ahora contiene la información equivalente que se hubiera almacenado en un mensaje con un único envío con un buffer de envío que es la concatenación de los buffers de envío individuales.

Una unidad de empaquetado puede ser enviada usando el tipo MPI_BYTE. Cualquier función de comunicación punto a punto o colectiva puede usarse para mover la secuencia de bytes que forma la unidad de empaquetado desde un proceso a otro. Esta unidad de empaquetado puede ahora ser recibida mediante cualquier operación de recepción, con cualquier tipo de dato. (Las reglas de correspondencia de tipos se relajan para los mensajes enviados con tipo MPI_BYTE.)

Una unidad de empaquetado puede ser desempacada en varios mensajes sucesivos. Esto se logra mediante varias llamadas sucesivas relacionadas a MPI_Unpack_external, donde la primera llamada proporciona position=0, y cada llamada sucesiva introduce el valor de posición que fue devuelto por la llamada anterior, y los mismos valores para inbuf y insize.

La concatenación de dos unidades de empaquetado no necesariamente es una unidad de empaquetado; ni una subcadena de una unidad de empaquetado necesariamente es una unidad de empaquetado. Por lo tanto, no se puede concatenar dos unidades de empaquetado y luego desempacar el resultado como una sola unidad de empaquetado; ni se puede desempacar una subcadena de una unidad de empaquetado como una unidad separada. Cada unidad de empaquetado que fue creada mediante una secuencia relacionada de llamadas de empaquetado debe desempacarse como unidad por una secuencia de llamadas relacionadas de desempaquetado.

ERRORES

Más allá de los errores MPI, las funciones C devuelven el valor de error y en el último argumento de las funciones Fortran. Antes de devolver el valor de error, se llama al manejador de error asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) actual. Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y se llama al manejador de error asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize o cuando se utiliza el modelo de Sesiones exclusivamente), el error invoca el manejador de error inicial. El manejador de error inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se utiliza el modelo del Mundo, o el argumento mpi_initial_errhandler de CLI para mpiexec o la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro manejador de error adecuado establecido, se llama al manejador de error MPI_ERRORS_RETURN para funciones de I/O MPI y al manejador de error MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de error predeterminados que pueden usarse:

  • MPI_ERRORS_ARE_FATAL Hace que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, se aborta.

  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler
