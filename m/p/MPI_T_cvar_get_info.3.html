MPI_T_cvar_get_info — Consultar información de una variable de rendimiento (cvar)

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_T_cvar_get_info(int cvar_index, char *name, int *name_len,
                        int *verbosity, MPI_Datatype *datatype, MPI_T_enum *enumtype,
                        const char *desc, int *desc_len, int *bind, int *scope);

Parámetros de entrada

•
cvar_index: Índice de la variable de rendimiento a consultar.

Parámetros de entrada/salida

  • name_len: Longitud del buffer para el nombre.
  • desc_len: Longitud del buffer para la descripción.

Parámetros de salida

  • name: Buffer para devolver el nombre de la variable de rendimiento.
  • verbosity: Nivel de verboridad de esta variable.
  • datatype: Tipo de dato MPI de la información almacenada en la variable de rendimiento.
  • enumtype: Descriptor opcional de información de enumeración.
  • desc: Buffer para devolver la descripción de la variable de rendimiento.
  • bind: Tipo de objeto MPI al cual debe ser vinculada esta variable.
  • scope: Ámbito en el cual se pueden realizar cambios en esta variable.

Descripción

MPI_T_cvar_get_info se utiliza para consultar información sobre una variable de rendimiento. La función devuelve el nivel de verboridad, el tipo de dato MPI, el tipo de enumeración, el vínculo y el ámbito de la variable consultada en los argumentos verbosity, datatype, enumtype, bind y scope, respectivamente. Las variables de rendimiento en Open MPI son los mismos que los parámetros MCA.

Verboridad

Como Open MPI expone un número muy grande de parámetros MCA (variables de rendimiento), las variables de rendimiento se clasifican en nueve niveles de verboridad correspondientes al nivel equivalente de ompi_info. Los nueve niveles son (en orden creciente):

1.
MPI_T_VERBOSITY_USER_BASIC: Información básica de interés para los usuarios.
2.
MPI_T_VERBOSITY_USER_DETAIL: Información detallada de interés para los usuarios.
3.
MPI_T_VERBOSITY_USER_ALL: Toda la demás información de interés para los usuarios.
4.
MPI_T_VERBOSITY_TUNER_BASIC: Información básica necesaria para el ajuste.
5.
MPI_T_VERBOSITY_TUNER_DETAIL: Información detallada necesaria para el ajuste.
6.
MPI_T_VERBOSITY_TUNER_ALL: Toda la demás información necesaria para el ajuste.
7.
MPI_T_VERBOSITY_MPIDEV_BASIC: Información básica para los desarrolladores de MPI.
8.
MPI_T_VERBOSITY_MPIDEV_DETAIL: Información detallada para los desarrolladores de MPI.
9.
MPI_T_VERBOSITY_MPIDEV_ALL: Toda la demás información para los desarrolladores de MPI.

Para más información, véase MPI-3 sección 14.3.1.

Tipo de dato

El tipo de dato devuelto por MPI_T_cvar_get_info se limita a uno de los siguientes tipos de dato: MPI_INT, MPI_UNSIGNED, MPI_UNSIGNED_LONG, MPI_UNSIGNED_LONG_LONG, MPI_COUNT, MPI_CHAR y MPI_DOUBLE. Para más información sobre los tipos de dato en MPI_T, véase MPI-3 sección 14.3.5.

Ámbito

El ámbito describe cuándo y cómo se pueden realizar cambios en una variable de rendimiento. Según la sección 14.3.6 de MPI-3, el ámbito puede ser cualquiera de los siguientes:

  • MPI_T_SCOPE_CONSTANT: Solo lectura, valor constante.
  • MPI_T_SCOPE_READONLY: Solo lectura, no se puede escribir, pero puede cambiar.
  • MPI_T_SCOPE_LOCAL: Se puede escribir, la escritura es una operación local.
  • MPI_T_SCOPE_GROUP: Se puede escribir, debe realizarse en un grupo de procesos, todos los procesos de un grupo deben tener valores consistentes.
  • MPI_T_SCOPE_GROUP_EQ: Se puede escribir, debe realizarse en un grupo de procesos, todos los procesos de un grupo deben tener el mismo valor.
  • MPI_T_SCOPE_ALL: Se puede escribir, debe realizarse en todos los procesos, todos los procesos conectados deben tener valores consistentes.
  • MPI_T_SCOPE_ALL_EQ: Se puede escribir, debe realizarse en todos los procesos, todos los procesos conectados deben tener el mismo valor.

Para más información, véase MPI-3 sección 14.3.6 Tabla 14.4.

Notas

Esta función de interfaz de herramientas MPI devuelve dos cadenas. Esta función toma dos argumentos para cada cadena: un búfer para almacenar la cadena y una longitud que debe especificar inicialmente el tamaño del búfer. Si el valor pasado es n, esta función copiará como máximo n-1 caracteres de la cadena en el búfer correspondiente y establecerá la longitud en el número de caracteres copiados menos 1. Si el argumento de longitud es NULL o el valor especificado es 0, el búfer correspondiente se ignora y la cadena no se devuelve.

Open MPI no admite actualmente la vinculación de variables de rendimiento a objetos MPI.

Errores

MPI_T_cvar_get_info fallará si:

  • MPI_T_ERR_NOT_INITIALIZED: La interfaz de herramientas MPI no está inicializada.
  • MPI_T_ERR_INVALID_INDEX: El índice de la variable de rendimiento es inválido.
