MPI_Graph_neighbors(3) Open MPI MPI_Graph_neighbors(3)

MPI_Graph_neighbors — Devuelve los vecinos de un nodo asociado con una topología de grafo.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Graph_neighbors(MPI_Comm comm, int rank, int maxneighbors,
     int neighbors[])

Sintaxis Fortran

USE MPI
! ola ola ola
MPI_GRAPH_NEIGHBORS(COMM, RANK, MAXNEIGHBORS, NEIGHBORS, IERROR)
     INTEGER COMM, RANK, MAXNEIGHBORS, NEIGHBORS(*), IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Graph_neighbors(comm, rank, maxneighbors, neighbors, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(IN) :: rank, maxneighbors
     INTEGER, INTENT(OUT) :: neighbors(maxneighbors)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARAMETROS DE ENTRADA

  • comm: Topología de grafo con la que se define el comunicador (handle).
  • rank: Número de proceso en el grupo de comm (entero).
  • maxneighbors: Tamaño del array neighbors (entero).

PARAMETROS DE SALIDA

  • neighbors: Ranks de procesos que son vecinos del proceso especificado (array de enteros).
  • ierror: Solo Fortran: Valor de error (entero).

DESCRIPCIÓN

Ejemplo: Supongamos que comm es un comunicador con una topología de shuffle-exchange. El grupo tiene 2n miembros. Cada proceso se etiqueta con a(1), ..., a(n) con a(i) ∈ {0,1}, y tiene tres vecinos: exchange (a(1), ..., a(n) = a(1), ..., a(n-1), 1 - an), shuffle (a(1), ..., a(n)) = a(2), ..., a(n), a(1) y unshuffle (a(1), ..., a(n)) = a(n), a(1), ..., a(n-1). La lista de adyacencia del grafo se ilustra a continuación para n=3.

                 exchange                shuffle         unshuffle
node             neighbors(1)    neighbors(2)    neighbors(3)
0(000)       1               0               0
1(001)       0               2               4
2(010)       3               4               1
3(011)       2               6               5
4(100)       5               1               2
5(101)       4               3               6
6(110)       7               5               3
7(111)       6               7               7

Supongamos que el comunicador comm tiene esta topología asociada. El siguiente fragmento de código itera por los tres tipos de vecinos y realiza una permutación adecuada para cada.

!  suponer: cada proceso tiene almacenado un número real A.
!  extraer información de vecinos
CALL MPI_COMM_RANK(comm, myrank, ierr)
CALL MPI_GRAPH_NEIGHBORS(comm, myrank, 3, neighbors, ierr)
!  realizar permutación de exchange
CALL MPI_SENDRECV_REPLACE(A, 1, MPI_REAL, neighbors(1), 0, &
                          neighbors(1), 0, comm, status, ierr)
!  realizar permutación de shuffle
CALL MPI_SENDRECV_REPLACE(A, 1, MPI_REAL, neighbors(2), 0, &
                          neighbors(3), 0, comm, status, ierr)
!  realizar permutación de unshuffle
CALL MPI_SENDRECV_REPLACE(A, 1, MPI_REAL, neighbors(3), 0, &
                          neighbors(2), 0, comm, status, ierr)

ERRORES

Mayormente, las rutinas MPI devuelven un valor de error; en las rutinas C, el valor de retorno es el resultado de la función, y en las rutinas Fortran, el último argumento es el valor de error.

Antes de que se devuelva el valor de error, se llama al manejador de errores asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo) actual. Si no hay ningún objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y se llama al manejador de errores asociado con MPI_COMM_SELF. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize o cuando se utiliza el modelo de sesiones exclusivamente), el error invoca el manejador de errores inicial. El manejador de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se utiliza el modelo del mundo, o al argumento mpi_initial_errhandler de mpiexec o a la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se configura ningún otro manejador de errores adecuado, se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones de MPI.

Open MPI incluye tres manejadores de errores predeterminados que se pueden usar:

  • MPI_ERRORS_ARE_FATAL Detiene a todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene los procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, detiene solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error al programa.

Los programas MPI también pueden implementar sus propios manejadores de errores llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: Los programas MPI no garantizan que puedan continuar ejecutándose tras un error.

Ver la página del manual de MPI para una lista completa de códigos de error de MPI.

Ver la sección de manejo de errores del estándar MPI-3.1 para más información.
