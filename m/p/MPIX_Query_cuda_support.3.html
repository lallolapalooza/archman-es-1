MPIX_Query_cuda_support(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPIX_QUERY_CUDA_SUPPORT(3) Open MPI MPIX_QUERY_CUDA_SUPPORT(3)

MPIX_Query_cuda_support - Devuelve 1 si hay soporte consciente de CUDA y 0 si no lo hay.

SINTAXIS

Sintaxis C

#include <mpi.h>
#include <mpi-ext.h>
int MPIX_Query_cuda_support(void)

Sintaxis Fortran

No hay enlace Fortran para esta función.

Sintaxis C++

No hay enlace C++ para esta función.

DESCRIPCIÓN

Esta función es parte de una extensión de Open MPI; no es parte de MPI estándar.

Esta rutina devuelve 1 si la biblioteca MPI se compiló con la biblioteca NVIDIA CUDA y el tiempo de ejecución admite búferes CUDA. De lo contrario, devuelve 0. Esta rutina debe llamarse después de que MPI esté inicializado, por ejemplo, mediante una llamada a MPI_Init(3) o MPI_Init_thread(3).

Incluir el archivo específico de Open MPI <mpi-ext.h> definirá la macro preprocesador C OMPI_HAVE_MPI_EXT como 1. De lo contrario, estará indefinido. Las aplicaciones pueden usar esta macro como un centinela para saber si se ha incluido o no <mpi-ext.h>.

La extensión CUDA de Open MPI se compila por defecto (independientemente de si Open MPI se compiló o no con soporte CUDA), pero podría haber sido deshabilitada por una acción administrativa. Por lo tanto, es más seguro que las aplicaciones verifiquen que la macro preprocesador OMPI_HAVE_MPI_EXT_CUDA esté definida y establecida en 1 para saber si la función MPIX_Query_CUDA_support() está disponible. La verificación de esta macro también protege el uso de esta función al compilar la aplicación con versiones anteriores de Open MPI u otras implementaciones de MPI que no tienen esta función.

EJEMPLOS

#include <stdio.h>
#include <mpi.h>
#include <mpi-ext.h> /* Necesario para la comprobación de conciencia de CUDA */
int main(int argc, char *argv[])
{
    MPI_Init(&argc, &argv);
    bool feliz = false;
#if defined(OMPI_HAVE_MPI_EXT_CUDA) && OMPI_HAVE_MPI_EXT_CUDA
    feliz = (bool) MPIX_Query_cuda_support();
#endif
    if (feliz) {
        printf("Esta instalación de Open MPI tiene soporte de conciencia de CUDA.\n");
    } else {
        printf("Esta instalación de Open MPI no tiene soporte de conciencia de CUDA.\n");
    }
    MPI_Finalize();
    return 0;
}
