MPI_Pack(3)

Paquete: openmpi

Licencias: BSD-3-Clause AND LicenseRef-MPICH

MPI_PACK(3) Open MPI MPI_PACK(3)

MPI_Pack — Empaqueta datos de un tipo de dato dado en memoria contigua.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Pack(const void *inbuf, int incount, MPI_Datatype datatype,
     void *outbuf, int outsize, int *position, MPI_Comm comm)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_PACK(INBUF, INCOUNT, DATATYPE, OUTBUF,OUTSIZE, POSITION,
             COMM, IERROR)
     <type>  INBUF(*), OUTBUF(*)
     INTEGER INCOUNT, DATATYPE, OUTSIZE, POSITION, COMM, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Pack(inbuf, incount, datatype, outbuf, outsize, position, comm, ierror)
     TYPE(*), DIMENSION(..), INTENT(IN) :: inbuf
     TYPE(*), DIMENSION(..) :: outbuf
     INTEGER, INTENT(IN) :: incount, outsize
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(INOUT) :: position
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • inbuf: Inicio del búfer de entrada (elección).
  • incount: Número de elementos de datos de entrada (entero).
  • datatype: Tipo de dato de cada elemento de datos de entrada (manejador).
  • outsize: Tamaño del búfer de salida, en bytes (entero).
  • comm: Comunicador para el mensaje empaquetado (manejador).

PARÁMETRO DE ENTRADA/SALIDA

•
position: Posición actual en el búfer, en bytes (entero).

PARÁMETROS DE SALIDA

  • outbuf: Inicio del búfer de salida (elección).
  • ierror: Solo Fortran: Estado de error (entero).

DESCRIPCIÓN

Empaqueta el mensaje en el búfer de envío especificado por inbuf, incount, datatype en el espacio de búfer especificado por outbuf y outsize. El búfer de entrada puede ser cualquier búfer de comunicación permitido en MPI_Send. El búfer de salida es un área de almacenamiento contigua que contiene outsize bytes, comenzando en la dirección outbuf (la longitud se cuenta en bytes, no en elementos, como si fuera un búfer de comunicación para un mensaje de tipo MPI_Packed).

El valor de entrada de position es la primera ubicación en el búfer de salida que se utilizará para empaquetar. position se incrementa en el tamaño del mensaje empaquetado, y el valor de salida de position es la primera ubicación en el búfer de salida después de las ubicaciones ocupadas por el mensaje empaquetado. El argumento comm es el comunicador que se utilizará posteriormente para enviar el mensaje empaquetado.

Ejemplo: Un ejemplo que usa MPI_Pack:

int myrank, position, i, j, a[2];
char buff[1000];
// ...
MPI_Comm_rank(MPI_COMM_WORLD, &myrank);
if (myrank == 0) {
  /* CÓDIGO DEL REMITENTE */
  position = 0;
  MPI_Pack(&i, 1, MPI_INT, buff, 1000, &position, MPI_COMM_WORLD);
  MPI_Pack(&j, 1, MPI_INT, buff, 1000, &position, MPI_COMM_WORLD);
  MPI_Send(buff, position, MPI_PACKED, 1, 0, MPI_COMM_WORLD);
} else {
  /* CÓDIGO DEL RECEPTOR */
  MPI_Recv(a, 2, MPI_INT, 0, 0, MPI_COMM_WORLD);
}

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al controlador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay un objeto de comunicación asociado con la llamada MPI, la llamada se considera adjunta a MPI_COMM_SELF y llamará al controlador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el modelo de sesiones) el error eleva el controlador de errores inicial. El controlador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos mpi_initial_errhandler de mpiexec o la clave de información para MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha configurado ningún otro controlador de errores apropiado, entonces el controlador de errores MPI_ERRORS_RETURN se llama para las funciones de E/S de MPI y el controlador de errores MPI_ERRORS_ABORT se llama para todas las demás funciones de MPI.

Open MPI incluye tres controladores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa finalice todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un controlador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo finaliza el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios controladores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
