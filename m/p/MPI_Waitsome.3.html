MPI_WAITSOME(3) Open MPI MPI_WAITSOME(3)

MPI_Waitsome — Espera hasta que se complete alguna de las operaciones asociadas a los handles activos en la lista.

Sintaxis

Sintaxis C

#include <mpi.h>
int MPI_Waitsome(int incount, MPI_Request array_of_requests[],
     int *outcount, int array_of_indices[],
     MPI_Status array_of_statuses[])

Sintaxis Fortran

USE MPI
! o la antigua forma: INCLUDE 'mpif.h'
MPI_WAITSOME(INCOUNT, ARRAY_OF_REQUESTS, OUTCOUNT,
             ARRAY_OF_INDICES, ARRAY_OF_STATUSES, IERROR)
     INTEGER INCOUNT, ARRAY_OF_REQUESTS(*), OUTCOUNT
     INTEGER ARRAY_OF_INDICES(*)
     INTEGER ARRAY_OF_STATUSES(MPI_STATUS_SIZE*)
     INTEGER IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Waitsome(incount, array_of_requests, outcount, array_of_indices,
             array_of_statuses, ierror)
     INTEGER, INTENT(IN) :: incount
     TYPE(MPI_Request), INTENT(INOUT) :: array_of_requests(incount)
     INTEGER, INTENT(OUT) :: outcount, array_of_indices(*)
     TYPE(MPI_Status) :: array_of_statuses(*)
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

Parámetros de entrada

  • incount: Tamaño de array_of_requests (entero).
  • array_of_requests: Array de requests (array de handles).

Parámetros de salida

  • outcount: Número de solicitudes completadas (entero).
  • array_of_indices: Array de índices de operaciones completadas (array de enteros).
  • array_of_statuses: Array de objetos de estado para operaciones completadas (array de estado).
  • ierror: Solo en Fortran: Estado de error (entero).

Descripción

Espera hasta que se complete al menos una de las operaciones asociadas a los handles activos en la lista. Devuelve en outcount el número de solicitudes que hayan completado desde el array array_of_requests. Devuelve en los primeros outcount lugares del array array_of_indices los índices de estas operaciones (índice dentro del array array_of_requests; el array se indexa de 0 en C y de 1 en Fortran). Devuelve en los primeros outcount lugares del array array_of_status el estado para estas operaciones completadas. Si una solicitud que haya completado fue asignada por una llamada no bloqueante, se desaloca y el handle se establece a MPI_REQUEST_NULL.

Si la lista contiene ningún handle activo, el llamado devuelve inmediatamente con outcount = MPI_UNDEFINED.

Cuando una o más de las comunicaciones completadas por MPI_Waitsome fallan, es deseable devolver información específica sobre cada comunicación. Los argumentos outcount, array_of_indices y array_of_statuses se ajustarán para indicar la completación de todas las comunicaciones que hayan éxito o fallado. El llamado devolverá el código de error MPI_ERR_IN_STATUS y el campo de error de cada estado devolverá se establecerá para indicar éxito o el error específico que ocurrió. El llamado devolverá MPI_SUCCESS si no se generó un error al solicitar, y devolverá otro código de error si falló por otras razones (como argumentos inválidos). En tales casos, no se actualizarán los campos de error de los estados.

Si tu aplicación no necesita examinar el campo array_of_statuses, puedes ahorrar recursos utilizando la constante predefinida MPI_STATUSES_IGNORE como valor especial para el argumento array_of_statuses.

Ejemplo: Código similar al ejemplo de MPI_Waitany, pero usando MPI_Waitsome.

CALL MPI_COMM_SIZE(comm, size, ierr)
CALL MPI_COMM_RANK(comm, rank, ierr)
IF(rank > 0) THEN         ! código del cliente
    DO
       CALL MPI_ISEND(a, n, MPI_REAL, 0, tag, comm, request, ierr)
       CALL MPI_WAIT(request, status, ierr)
    END DO
ELSE         ! rank=0: código del servidor
    DO i=1, size-1
       CALL MPI_IRECV(a(1,i), n, MPI_REAL, i, tag, &
                      comm, requests(i), ierr)
    END DO
    DO
       CALL MPI_WAITSOME(size, request_list, numdone, &
                        indices, statuses, ierr)
       DO i=1, numdone
          CALL DO_SERVICE(a(1, indices(i)))
          CALL MPI_IRECV(a(1, indices(i)), n, MPI_REAL, i, tag, &
                       comm, requests(indices(i)), ierr)
       END DO
    END DO
END IF

Notas

Los índices del array son en el rango 0 a incount-1 en C y en el rango 1 a incount en Fortran.

Errores

La mayoría de las rutinas MPI devuelven un valor de error; las rutinas C devuelven el resultado de la función y las rutinas Fortran en el último argumento.

Antes de devolver el valor de error, se llama al gestor de errores asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay objeto de comunicación asociado con la llamada MPI, se considera que la llamada está asociada a MPI_COMM_SELF y se llama al gestor de errores correspondiente. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize o cuando se use el modelo de Sesiones exclusivamente), el error eleva el gestor de errores inicial. El gestor de errores inicial puede cambiarse llamando a MPI_Comm_set_errhandler sobre MPI_COMM_SELF cuando se use el modelo del Mundo, o a través del argumento mpi_initial_errhandler en mpiexec o a la clave info en MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no hay otro gestor de errores adecuado establecido, se llama el gestor de error MPI_ERRORS_RETURN para las funciones de I/O MPI y el gestor de error MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres gestores de errores predefinidos que pueden utilizarse:

  • MPI_ERRORS_ARE_FATAL Causa que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un gestor de error que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se invoca en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se invoca en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el conjunto de procesos en la ventana o archivo correspondiente. Si se invoca en una sesión, aborta solo el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error al aplicación.

Las aplicaciones MPI también pueden implementar sus propios gestores de errores llamando:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o al MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Nota: MPI no garantiza que una aplicación MPI pueda continuar después de un error.

Ver la página de manuales de MPI para una lista completa de códigos de error MPI.

Ver la sección de Gestión de Errores de la especificación MPI-3.1 para más información.

Para cada invocación de MPI_Waitsome, si alguna solicitud genera un error MPI, solo se pasa al gestor de error correspondiente el primer MPI request que causó el error. No se invocan otros gestores de errores (incluso si múltiples solicitudes generaron errores). Sin embargo, todas las solicitudes que generan un error tendrán un código de error relevante establecido en el campo correspondiente status.MPI_ERROR (a menos que se haya utilizado MPI_STATUSES_IGNORE).

Si el gestor de error invocado permite que MPI_Waitsome devuelva a la llamada del usuario, el valor MPI_ERR_IN_STATUS se devuelve en las bindings C y Fortran.

MPI_Waitsome(3) - Open MPI Manual

NAME

MPI_Waitsome - Waits for some operations from a set to complete

SYNTAX

int MPI_Waitsome(int count, MPI_Request *requests, int *indices, MPI_Status *statuses)

INPUT PARAMETERS

count
Number of requests in the list (integer).
requests
Array of requests to wait on (MPI_Request array).

OUTPUT PARAMETERS

indices
Array of indices of the completed requests in the original requests array (integer array). The size of this array should be at least count. The number of completed requests is returned in the count parameter.
statuses
Array of status objects corresponding to the completed requests (MPI_Status array). The size of this array should be at least count. The status objects for the non-completed requests are undefined.

DESCRIPTION

MPI_Waitsome is a blocking function that waits for at least one operation from the list of requests to complete. It returns as soon as one or more operations have finished. The function returns the number of completed operations and provides the indices and status objects for the completed requests.

The count parameter is an input parameter specifying the number of requests in the requests array. Upon return, count is updated to indicate the number of requests that have completed. The indices array contains the original indices of the completed requests within the requests array. The statuses array contains the status objects for the completed requests, ordered according to the indices array.

If multiple operations complete simultaneously, MPI_Waitsome may return any subset of the completed operations. It is guaranteed to return at least one completed operation if any are available.

If all operations in the requests array complete, count will be returned as the original input count, and indices will contain the indices of all completed requests.

If the requests array is empty (i.e., count is 0), the function returns immediately with count set to 0.

The MPI_Request objects for the completed operations are set to MPI_REQUEST_NULL upon return.

NOTES

  • This function is part of the MPI standard and is available in all MPI implementations.

  • It is often used in conjunction with MPI_Isend, MPI_Irecv, MPI_Isendrecv, MPI_Wait, MPI_Test, MPI_Waitany, MPI_Testany, MPI_Waitsome, MPI_Testsome, MPI_Waitall, and MPI_Testall.

ERRORS

All MPI functions must detect errors that occur during their execution and handle them according to the MPI error handler set on the communicator. The MPI standard specifies that these errors are detected and handled by the MPI implementation.
