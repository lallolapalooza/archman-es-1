MPI_Errhandler_create(3)

Paquete: openmpi

Licencias: BSD-3-Clause Y LicenseRef-MPICH

MPI_ERRHANDLER_CREATE(3) Open MPI MPI_ERRHANDLER_CREATE(3)

MPI_Errhandler_create — Crea un manejador de errores estilo MPI — esta rutina está obsoleta en favor de MPI_Comm_create_errhandler.

SINTAXIS

Sintaxis en C

#include <mpi.h>
int MPI_Errhandler_create(MPI_Handler_function *function,
     MPI_Errhandler *errhandler)

Sintaxis en Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_ERRHANDLER_CREATE(FUNCTION, ERRHANDLER, IERROR)
     EXTERNAL        FUNCTION
     INTEGER ERRHANDLER, IERROR

PARÁMETRO DE ENTRADA

•
function: Procedimiento de manejo de errores definido por el usuario.

PARÁMETROS DE SALIDA

  • errhandler: Manejador de errores MPI (identificador).
  • ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

Tenga en cuenta que el uso de esta rutina está obsoleto a partir de MPI-2. Por favor, use MPI_Comm_create_errhandler en su lugar.

Registra la rutina de usuario function para su uso como manejador de errores MPI. Devuelve en errhandler un identificador del manejador de errores registrado.

En el lenguaje C, la rutina de usuario debe ser una función C de tipo MPI_Handler_function, que se define como

typedef void (MPI_Handler_function)(MPI_Comm *, int *, ...);

El primer argumento es el comunicador en uso. El segundo es el código de error que será devuelto por la rutina MPI que generó el error. Si la rutina hubiera devuelto MPI_ERR_IN_STATUS, es el código de error devuelto en el estado de la solicitud que provocó la invocación del manejador de errores. Los argumentos restantes son argumentos stdargs cuyo número y significado depende de la implementación. Una implementación debe documentar claramente estos argumentos. Se utilizan direcciones para que el manejador pueda escribirse en Fortran.

NOTA

El Estándar MPI establece que una implementación puede hacer que el valor de salida (errhandler) sea simplemente la dirección de la función. Sin embargo, la acción de MPI_Errhandler_free hace que esto sea imposible, ya que se requiere establecer el valor del argumento a MPI_ERRHANDLER_NULL. Además, el manejador de errores real debe permanecer hasta que todos los comunicadores que lo utilicen sean liberados.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como el resultado de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa el Modelo de Sesiones exclusivamente) el error invoca el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se utiliza el modelo World, o el argumento de línea de comandos mpi_initial_errhandler de mpiexec o la clave info de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que puede invocarse en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler y luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler y luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler y luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler y luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de códigos de error de MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
