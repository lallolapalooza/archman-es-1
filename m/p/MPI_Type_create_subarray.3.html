MPI_TYPE_CREATE_SUBARRAY(3) Open MPI MPI_TYPE_CREATE_SUBARRAY(3)

MPI_Type_create_subarray — Crea un tipo de datos que describe un subarreglo n-dimensional de un arreglo n-dimensional.

SINTAXIS

Sintaxis C

#include <mpi.h>
int MPI_Type_create_subarray(int ndims, const int array_of_sizes[],
    const int array_of_subsizes[], const int array_of_starts[],
    int order, MPI_Datatype oldtype, MPI_Datatype *newtype)

Sintaxis Fortran

USE MPI
! o la forma antigua: INCLUDE 'mpif.h'
MPI_TYPE_CREATE_SUBARRAY(NDIMS, ARRAY_OF_SIZES, ARRAY_OF_SUBSIZES,
     ARRAY_OF_STARTS, ORDER, OLDTYPE, NEWTYPE, IERROR)
     INTEGER NDIMS, ARRAY_OF_SIZES(*), ARRAY_OF_SUBSIZES(*),
     ARRAY_OF_STARTS(*), ORDER, OLDTYPE, NEWTYPE, IERROR

Sintaxis Fortran 2008

USE mpi_f08
MPI_Type_create_subarray(ndims, array_of_sizes, array_of_subsizes,
             array_of_starts, order, oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: ndims, array_of_sizes(ndims),
     array_of_subsizes(ndims), array_of_starts(ndims), order
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

PARÁMETROS DE ENTRADA

  • ndims: Número de dimensiones del arreglo (entero positivo).
  • array_of_sizes: Número de elementos de tipo oldtype en cada dimensión del arreglo completo (arreglo de enteros positivos).
  • array_of_subsizes: Número de elementos de tipo oldtype en cada dimensión del subarreglo (arreglo de enteros positivos).
  • array_of_starts: Coordenadas de inicio del subarreglo en cada dimensión (arreglo de enteros no negativos).
  • order: Indicador de orden de almacenamiento del arreglo (estado).
  • oldtype: Tipo de datos del elemento del arreglo (manejador).

PARÁMETROS DE SALIDA

  • newtype: Nuevo tipo de datos (manejador).
  • ierror: Solo Fortran: Estado del error (entero).

DESCRIPCIÓN

El constructor de tipo de subarreglo crea un tipo de datos MPI que describe un subarreglo n-dimensional de un arreglo n-dimensional. El subarreglo puede estar ubicado en cualquier lugar dentro del arreglo completo y puede ser de cualquier tamaño no nulo hasta el tamaño del arreglo mayor, siempre que esté confinado dentro de este arreglo. Este constructor de tipo facilita la creación de tipos de archivo para acceder a arreglos distribuidos en bloques entre procesos en un solo archivo que contiene el arreglo global.

Este constructor de tipo puede manejar arreglos con un número arbitrario de dimensiones y funciona tanto para matrices con orden C como con orden Fortran (es decir, orden de fila principal o de columna principal). Tenga en cuenta que un programa C puede usar orden Fortran y un programa Fortran puede usar orden C.

El parámetro ndims especifica el número de dimensiones en el arreglo de datos completo y da el número de elementos en array_of_sizes, array_of_subsizes y array_of_starts.

El número de elementos de tipo oldtype en cada dimensión del arreglo n-dimensional y del subarreglo solicitado se especifican por array_of_sizes y array_of_subsizes, respectivamente. Para cualquier dimensión i, es erróneo especificar array_of_subsizes[i] < 1 o array_of_subsizes[i] > array of sizes[i].

array_of_starts contiene las coordenadas de inicio de cada dimensión del subarreglo. Los arreglos se suponen indexados a partir de cero. Para cualquier dimensión i, es erróneo especificar

array_of_starts[i] < 0

o

array_of_starts[i] > (array_of_sizes[i] - array_of_subsizes[i]).

El argumento order especifica el orden de almacenamiento para el subarreglo, así como para el arreglo completo. Debe establecerse en uno de los siguientes:

  • MPI_ORDER_C: El orden utilizado por los arreglos C (es decir, orden de fila principal).
  • MPI_ORDER_FORTRAN: El orden utilizado por los arreglos Fortran (es decir, orden de columna principal).

Un subarreglo ndims-dimensional (newtype) sin relleno adicional puede definirse mediante la función Subarray() de la siguiente manera:

newtype = Subarray(ndims, {size_0, size_1,..., size_ndims-1},
          {subsize_0, subsize_1, ..., subsize_ndims-1},
          {start_0, start_1, ..., start_ndims-1}, oldtype)

Sea el typemap de oldtype de la forma:

{(type_0, disp_0), (type_1, disp_1), ..., (type_n-1, disp_n-1)}

donde typei es un tipo de datos MPI predefinido, y sea ex la extensión de oldtype.

La función Subarray() se define recursivamente en tres ecuaciones en la página 72 del estándar MPI-2.

Para un ejemplo de uso de MPI_Type_create_subarray en el contexto de E/S, consulte la Sección 9.9.2 del estándar MPI-2.

NOTAS

En un programa Fortran con arreglos indexados a partir de 1, si la coordenada de inicio de una dimensión particular del subarreglo es n, entonces la entrada en array of starts para esa dimensión es n-1.

ERRORES

Casi todas las rutinas MPI devuelven un valor de error; las rutinas C como resultado de retorno de la función y las rutinas Fortran en el último argumento.

Antes de que se devuelva el valor de error, se llama al manejador de errores MPI actual asociado con el objeto de comunicación (por ejemplo, comunicador, ventana, archivo). Si no hay un objeto de comunicación asociado con la llamada MPI, entonces la llamada se considera adjunta a MPI_COMM_SELF y llamará al manejador de errores MPI asociado. Cuando MPI_COMM_SELF no está inicializado (es decir, antes de MPI_Init/MPI_Init_thread, después de MPI_Finalize, o cuando se usa exclusivamente el Modelo de Sesiones) el error eleva el manejador de errores inicial. El manejador de errores inicial se puede cambiar llamando a MPI_Comm_set_errhandler en MPI_COMM_SELF cuando se usa el modelo World, o el argumento de línea de comandos mpi_initial_errhandler de mpiexec o la clave de información de MPI_Comm_spawn/MPI_Comm_spawn_multiple. Si no se ha establecido ningún otro manejador de errores apropiado, entonces se llama al manejador de errores MPI_ERRORS_RETURN para las funciones de E/S de MPI y al manejador de errores MPI_ERRORS_ABORT para todas las demás funciones MPI.

Open MPI incluye tres manejadores de errores predefinidos que se pueden utilizar:

  • MPI_ERRORS_ARE_FATAL Provoca que el programa aborte todos los procesos MPI conectados.
  • MPI_ERRORS_ABORT Un manejador de errores que se puede invocar en un comunicador, ventana, archivo o sesión. Cuando se llama en un comunicador, actúa como si se hubiera llamado MPI_Abort en ese comunicador. Si se llama en una ventana o archivo, actúa como si se hubiera llamado MPI_Abort en un comunicador que contiene el grupo de procesos en la ventana o archivo correspondiente. Si se llama en una sesión, solo aborta el proceso local.
  • MPI_ERRORS_RETURN Devuelve un código de error a la aplicación.

Las aplicaciones MPI también pueden implementar sus propios manejadores de errores llamando a:

  • MPI_Comm_create_errhandler luego MPI_Comm_set_errhandler
  • MPI_File_create_errhandler luego MPI_File_set_errhandler
  • MPI_Session_create_errhandler luego MPI_Session_set_errhandler o en MPI_Session_init
  • MPI_Win_create_errhandler luego MPI_Win_set_errhandler

Tenga en cuenta que MPI no garantiza que un programa MPI pueda continuar después de un error.

Consulte la página del manual de MPI para obtener una lista completa de los códigos de error MPI.

Consulte la sección de Manejo de Errores del estándar MPI-3.1 para obtener más información.
