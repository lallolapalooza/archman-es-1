NOMBRE

Mail::Message::Body::File - cuerpo de un mensaje almacenado temporalmente en un archivo

HERENCIA

Mail::Message::Body::File
  es un Mail::Message::Body
  es un Mail::Reporter

SINOPSIS

Ver Mail::Message::Body

DESCRIPCIÓN

El cuerpo (contenido) de un mensaje puede almacenarse de varias maneras. En esta documentación encontrará la descripción de la funcionalidad adicional que tiene cuando un mensaje se almacena en un archivo.

Almacenar un mensaje completo en un archivo es útil cuando el cuerpo es grande. Aunque el acceso a través de un archivo es más lento, ahorra mucha memoria.

DIAGNÓSTICOS

Error: No se puede escribir en el archivo temporal del cuerpo $filename: $!
El cuerpo del mensaje se almacenará en un archivo temporal (probablemente porque es un cuerpo grande), pero por la razón indicada, este archivo no se puede crear. Lanzado por new()
Advertencia: Charset $name no es conocido
La codificación o decodificación de un cuerpo de mensaje encuentra un conjunto de caracteres que no es entendido por el módulo Encode de Perl. Lanzado por encode()
Advertencia: Content-Transfer-Encoding `$encoding' requiere un charset explícito, predeterminado a utf-8
Lanzado por encode()
Advertencia: No hay decodificador definido para la codificación de transferencia $name.
Los datos (cuerpo del mensaje) están codificados de una manera que no se entiende actualmente, por lo tanto, no se puede realizar ninguna decodificación (o recodificación). Lanzado por encode()
Advertencia: No hay codificador definido para la codificación de transferencia $name.
Los datos (cuerpo del mensaje) han sido decodificados, pero la codificación requerida es desconocida. Se devuelven los datos decodificados. Lanzado por encode()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, sin embargo, la clase en cuestión no lo hace. Probablemente deberías investigar esto y probablemente informar al autor del paquete. Lanzado por notImplemented()
Error: No se puede leer el archivo $filename para el archivo del cuerpo del mensaje: $!
Se va a crear un objeto Mail::Message::Body::File a partir de un archivo con nombre, pero es imposible leer ese archivo para recuperar las líneas dentro. Por lo tanto, no se puede hacer una copia a un archivo temporal. Lanzado por new()
Advertencia: Terminador de línea desconocido $eol ignorado
Lanzado por eol()
