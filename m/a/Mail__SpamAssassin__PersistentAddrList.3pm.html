NOMBRE

Mail::SpamAssassin::PersistentAddrList - clase base de listas de direcciones persistentes

SINOPSIS

my $factory = PersistentAddrListSubclass->new();
$spamtest->set_persistent_addr_list_factory ($factory);
... llamar a las clases de SpamAssassin...

SpamAssassin llamará:

my $addrlist = $factory->new_checker($spamtest);
$entry = $addrlist->get_addr_entry ($addr);
...

DESCRIPCIÓN

Todas las implementaciones de listas de direcciones persistentes, utilizadas por el código de la lista de bienvenida automática para rastrear direcciones de correo electrónico conocidas como buenas, usan esta como clase base.

Ver "Mail::SpamAssassin::DBBasedAddrList" para un ejemplo.

MÉTODOS

$factory = PersistentAddrListSubclass->new();
Esto crea un objeto fábrica, que SpamAssassin llamará para crear un nuevo objeto verificador para la lista de direcciones persistentes.
mi $addrlist = $factory->new_checker();
Crea un nuevo objeto verificador de lista de direcciones desde la fábrica. Llamado por las clases de SpamAssassin.
$entry = $addrlist->get_addr_entry ($addr);
Dada una dirección de correo electrónico $addr, devuelve un objeto de entrada con los detalles de esa dirección.

El objeto de entrada es una referencia a un hash, que debe contener al menos dos claves: "count", que es el recuento de cuántas veces se ha encontrado esa dirección anteriormente; y "totscore", que es la suma de todas las puntuaciones para los mensajes asociados con esa dirección. A partir de estos dos campos, se calculará una puntuación promedio, y la puntuación del mensaje actual se regresará hacia esa puntuación media del mensaje.

El hash puede contener cualquier otro dato que su backend necesite almacenar, bajo otras claves.

El método nunca debe devolver "undef", o un hash que no contenga una clave "count" y una clave "totscore".

$entry = $addrlist->add_score($entry, $score);
Este método debe añadir la puntuación dada a la base de datos de la lista de bienvenida para la entrada dada, y luego devolver la nueva entrada.
$entry = $addrlist->remove_entry ($entry);
Este método debe eliminar la entrada dada de la base de datos de la lista de bienvenida.
$entry = $addrlist->finish ();
Limpieza, si es necesario. Llamado por SpamAssassin cuando ha terminado de verificar, o añadir a, la base de datos de la lista de bienvenida automática.
