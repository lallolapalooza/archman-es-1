Paquete: spamassassin

Mail::SpamAssassin::Plugin::ASN(3) Documentación de Perl aportada por el usuario Mail::SpamAssassin::Plugin::ASN(3)

NOMBRE

Mail::SpamAssassin::Plugin::ASN - Plugin de SpamAssassin para buscar el número del Sistema Autónomo (ASN) de la dirección IP de conexión.

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::ASN
# Configuraciones predeterminadas / recomendadas
asn_use_geodb 1
asn_use_dns 1
asn_prefer_geodb 1
# Realizar búsquedas y añadir etiquetas / cabecera X-Spam-ASN
asn_lookup asn.routeviews.org _ASN_ _ASNCIDR_
asn_lookup_ipv6 origin6.asn.cymru.com _ASN_ _ASNCIDR_
add_header all ASN _ASN_ _ASNCIDR_
# Reglas para probar el ASN o la Organización
# NOTA: No usar reglas que comprueben metadatos de la cabecera X-ASN,
# solo la función de evaluación check_asn() funciona correctamente.
# El argumento de la regla es una expresión regular completa para hacer coincidir.
# Número de ASN: GeoIP ASN o DNS
# La cadena coincidente incluye el prefijo asn si está definido, y normalmente
# se parece a "AS1234" (DNS) o "AS1234 Google LLC" (GeoIP)
header AS_1234 eval:check_asn('/^AS1234\b/')
# Organización de ASN: GeoIP ASN tiene, las listas DNS podrían no tener
# Nota el segundo parámetro que comprueba la etiqueta MYASN (el valor predeterminado es ASN)
asn_lookup myview.example.com _MYASN_ _MYASNCIDR_
header AS_GOOGLE eval:check_asn('/\bGoogle\b/i', 'MYASN')

DESCRIPCIÓN

Este plugin utiliza búsquedas DNS en los servicios de una zona DNS externa como en "https://www.routeviews.org/" para realizar el trabajo real. Por favor, asegúrate de que tu uso del plugin no sobrecarga su infraestructura; esto generalmente significa que no debes usar este plugin en un entorno de alto volumen o que debes usar un espejo local de la zona (ver "ftp://ftp.routeviews.org/dnszones/"). Otras zonas similares también pueden ser utilizadas.

Las búsquedas en la base de datos GeoDB (GeoIP ASN) son compatibles desde SpamAssassin 4.0 y se recomienda usarlas en lugar de las consultas DNS, a menos que se necesite "_ASNCIDR_".

ETIQUETAS DE PLANTILLA

Este plugin te permite crear etiquetas de plantilla que contienen el número AS de la IP de conexión e información de ruta para ese número AS.

Si utilizas add_header como se documenta en el ejemplo anterior, se añade un campo de cabecera que se ve así:

X-Spam-ASN: AS24940 213.239.192.0/18

donde "24940" es el ASN y "213.239.192.0/18" es la ruta anunciada por ese ASN de donde provino la dirección IP de conexión. Si el AS anuncia múltiples redes (más/menos específicas), todas se añadirán a la etiqueta "_ASNCIDR_", separadas por espacios, p.ej.:

X-Spam-ASN: AS1680 89.138.0.0/15 89.139.0.0/16

Ten en cuenta que el literal "AS" antes del ASN en la etiqueta _ASN_ es configurable a través de la directiva asn_prefix y puede establecerse como una cadena vacía.

"_ASNCIDR_" no está disponible con las búsquedas locales de ASN de GeoDB.

CONFIGURACIÓN DEL USUARIO

clear_asn_lookups
Elimina todas las entradas asn_lookup o asn_lookup_ipv6 declaradas previamente de la lista de consultas.
asn_prefix 'cadena_prefijo' (predeterminado: 'AS')
La cadena especificada en el argumento se antepone a cada ASN al almacenarlo como etiqueta. Este prefijo es bastante redundante, pero su valor predeterminado 'AS' se mantiene por compatibilidad con versiones anteriores de SpamAssassin anteriores a 3.4.0. Una configuración sensata es una cadena vacía. El argumento puede ser (pero no es necesario) entre comillas simples o dobles para mayor claridad.

DEFINICIONES DE REGLAS Y CONFIGURACIÓN PRIVILEGIADA

asn_lookup zona-asn.example.com [ _ETIQUETA_ASN_ _ETIQUETACIDR_ASN_ ]
Utiliza esto para buscar la información ASN en la zona especificada para la primera dirección IPv4 externa y añade el número AS a la primera etiqueta especificada y la información de enrutamiento a la segunda etiqueta especificada.

Si no se especifican etiquetas, el número AS se añadirá a la etiqueta _ASN_ y la información de enrutamiento se añadirá a la etiqueta _ASNCIDR_. Debes especificar ninguna o ambas de las etiquetas. Los nombres de las etiquetas deben empezar y terminar con un guion bajo.

Si dos o más asn_lookups utilizan el mismo conjunto de etiquetas de plantilla, los resultados de sus búsquedas se añadirán unos a otros en los valores de las etiquetas de plantilla en ningún orden particular. Los resultados duplicados se omitirán al combinar resultados. De manera similar, también puedes usar la misma etiqueta de plantilla tanto para la etiqueta del número AS como para la información de enrutamiento.

Ejemplos:

asn_lookup asn.routeviews.org
asn_lookup asn.routeviews.org _ASN_ _ASNCIDR_
asn_lookup myview.example.com _MYASN_ _MYASNCIDR_
asn_lookup asn.routeviews.org _COMBINEDASN_ _COMBINEDASNCIDR_
asn_lookup myview.example.com _COMBINEDASN_ _COMBINEDASNCIDR_
asn_lookup in1tag.example.net _ASNDATA_ _ASNDATA_
asn_lookup_ipv6 zona6-asn.example.com [_ASN_ _ASNCIDR_]
Utiliza la zona especificada para búsquedas de direcciones IPv6. Si la zona soporta consultas IPv4 e IPv6, usa tanto asn_lookup como asn_lookup_ipv6 para la misma zona.

CONFIGURACIÓN DEL ADMINISTRADOR

asn_use_geodb ( 0 / 1 ) (predeterminado: 1)
Usa el módulo Mail::SpamAssassin::GeoDB para buscar números ASN. Necesitas un módulo compatible adecuado como GeoIP2 o GeoIP con una base de datos ISP o ASN instalada (por ejemplo, añade EditionIDs GeoLite2-ASN en GeoIP.conf para el programa geoipupdate).

GeoDB solo puede establecer la etiqueta _ASN_, no tiene datos para _ASNCIDR_. Si necesitas ambos, entonces establece asn_prefer_geodb 0 para que se intenten las reglas DNS.

asn_prefer_geodb ( 0 / 1 ) (predeterminado: 1)
Si se establece, las búsquedas DNS (reglas asn_lookup) no se ejecutarán si GeoDB encuentra exitosamente el ASN. Establece esto a 0 para obtener _ASNCIDR_ incluso si GeoDB encuentra _ASN_.
asn_use_dns ( 0 / 1 ) (predeterminado: 1)
Establece a 0 para nunca permitir consultas DNS.

BAYES

El tokenizador bayesiano usará datos ASN para los cálculos bayesianos, y por lo tanto afectará a qué regla BAYES_* se activará para un mensaje particular. No se ha realizado un análisis en profundidad de la utilidad de la tokenización bayesiana de datos ASN.
