NOMBRE

Mail::Box::Net::Message - un mensaje de una carpeta remota

HERENCIA

Mail::Box::Net::Message
  es un Mail::Box::Message
  es un Mail::Message
  es un Mail::Reporter
Mail::Box::Net::Message es extendido por
  Mail::Box::IMAP4::Message
  Mail::Box::POP3::Message

SINOPSIS

my $folder = Mail::Box:POP3->new(...);
my $message = $folder->message(10);

DESCRIPCIÓN

Un Mail::Box::Net::Message representa un mensaje en una carpeta que sólo se puede acceder a través de algún tipo de protocolo. En este momento, sólo hay disponible un cliente POP3. IMAP, DBI y NNTP son otras candidatas.

DIAGNÓSTICO

Error: No se puede forzar un objeto de clase $class a ser un objeto de clase $class
Lanzado por coerce()
Error: No se puede incluir una fuente de reenvío como $include.
Alternativa desconocida para el reenvío (incluir). Las opciones válidas son "NO", "INLINE", "ATTACH", y "ENCAPSULATE". Lanzado por forward()
Error: No se puede incluir una fuente de respuesta como $include.
Alternativa desconocida para la opción "include" de reply(). Las opciones válidas son "NO", "INLINE", y "ATTACH". Lanzado por reply()
Error: El método bounce requiere To, Cc, o Bcc
El método bounce() del mensaje reenvía un mensaje recibido a otra persona sin modificaciones; debes especificar su nuevo destino. Si tienes la tentación de no especificar ningún destino, probablemente estés buscando reply(). Cuando desees modificar el contenido, usa forward(). Lanzado por bounce()
Error: El método forwardAttach requiere un preámbulo
Lanzado por forwardAttach()
Error: El método forwardEncapsulate requiere un preámbulo
Lanzado por forwardEncapsulate()
Error: No hay dirección para reenviar.
Si se crea un mensaje de reenvío, se debe especificar una dirección de destino. Lanzado por forward()
Error: No se encontró ningún mailer por defecto para enviar el mensaje.
El mecanismo send() del mensaje no tenía suficiente información para encontrar automáticamente un agente de transferencia de correo para enviar este mensaje. Especifica un mailer explícitamente usando las opciones "via". Lanzado por send()
Error: No hay regla de reconstrucción $name definida.
Lanzado por rebuild()
Error: Solo build() mensajes de Mail::Message; aún no están en una carpeta
Puede que desees construir un mensaje para almacenarlo en algún tipo de carpeta, pero necesitas hacerlo en dos pasos. Primero, crea un Mail::Message normal, y luego añádelo a la carpeta. Durante este proceso de Mail::Box::addMessage(), el mensaje será coerce()-d al tipo de mensaje correcto, añadiendo información de almacenamiento y demás. Lanzado por build()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que alguna otra
Mail::Box::Net::Message(3pm)

DIAGNOSTICS

The Mail::Box module throws exceptions on error. The following diagnostic messages are produced:

Error: Method MIME_text is not implemented in Mail::Box::Net::Message.
This is an unexpected error. Related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
Error: Unable to read delayed body.
Cast by loadBody()
Error: Unable to read delayed head.
Cast by loadBody()
Error: coercion starts with some object
Cast by coerce()
