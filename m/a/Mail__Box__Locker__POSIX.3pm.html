Nombre

Mail::Box::Locker::POSIX - bloquear un directorio usando la funcionalidad de bloqueo de archivos del sistema POSIX

Herencia

Mail::Box::Locker::POSIX
  es una Mail::Box::Locker
  es una Mail::Reporter

SINTAXIS

Ver Mail::Box::Locker

Descripción

Este objeto de bloqueo se crea mediante el directorio para obtener un bloqueo exclusivo en el archivo que contiene los datos usando las funcionalidades del sistema POSIX. Este bloqueo se crea en un archivo de desbloqueo separado del directorio, por lo que no es el handle que está leyendo.

ADVERTENCIA: No todos los sistemas soportan el bloqueo POSIX (a través de fcntl) y no siempre de manera idéntica. Esta implementación no usa XS para acceder a la estructura de fcntl; es mejor usar ::FcntlLock que no, esta implementación "supera" el lugar de los bytes.

Diagnósticos

Advertencia: El directorio $folder ya está bloqueado con lockf
Cast por lock()
Error: El paquete $package no implementa $method.
Error: La clase específica (o una de sus superclases) no implementa este método donde debería. Esta mensaje indica que otras clases relacionadas implementan este método, pero la clase en cuestión no lo hace. Probablemente debes investigar esto y probablemente informar al autor del paquete. Cast por notImplemented()
Error: No puedo verificar el archivo de bloqueo $file para $folder: $!
Para verificar si el archivo $file se usa para flockar el directorio $folder, debe abrirse el archivo. Aparentemente esto falla, lo cual no significa que el directorio esté bloqueado ni que esté desbloqueado. Cast por isLocked()
Error: No puedo abrir el archivo de bloqueo POSIX $file para $folder: $!
Para el bloqueo POSIX, debe abrirse el directorio $folder, lo cual no se logra por el motivo especificado. Cast por lock()
Error: No conseguiré un bloqueo POSIX en $file para $folder: $!
Intentó bloquear el directorio $folder, pero no tuvo éxito. El código de error recibido del sistema indica que nunca se conseguirá un bloqueo POSIX, por lo que no es necesario intentarlo de nuevo. Cast por lock()
