NOMBRE

Mail::Message::Construct::Build - construir un mensaje de correo

SINOPSIS

my $msg1 = Mail::Message->build(
  From => 'me',
  data => 'solo dos\nlineas\n',
);
my $msg2 = Mail::Message->buildFromBody($body);
Mail::Message->build(
  From     => 'me@myhost.com',
  To       => 'you@yourhost.com',
  Subject  => '¡Lee nuestra carpeta!',
  data     => \@lines,
  file     => 'folder.pdf',
)->send(via => 'postfix');

DESCRIPCIÓN

La funcionalidad compleja en los objetos Mail::Message se implementa en diferentes archivos que se cargan de forma automática. Este archivo implementa la construcción de mensajes a partir de componentes más simples.

MÉTODOS

Construyendo un mensaje

$class->build( [$message|$part|$body], @fields, %options )
Constructor de objeto de mensaje simplificado. Si se especifica un $message o un $part, se crea un nuevo mensaje con el mismo cuerpo, pero con nuevas cabeceras. También se puede especificar un $body. Sin embargo, hay más formas de agregar datos simplemente.

Puedes pasar @fields como objetos, incluso mezclados con pares de opción. Los campos se envían en el orden en que se crearon, por lo que podría ser necesario.

En la lista de %options, los campos que empiezan con mayúsculas se usan como líneas de cabecera. Los campos en minúsculas se usan para otros propósitos, como se lista a continuación. Cada campo puede usarse más de una vez. Los pares donde el valor es undef son ignorados.

Si se especifican más de un $data, $file o $attach, se crea un mensaje multipart. Algunos campos de tipo "Content-*" se tratan por separado: para forzar las líneas de cabecera del mensaje producido se deben especificar después de que el cuerpo se ha creado. Por ejemplo, para especificar explícitamente que se desea un $multipart/alternative en lugar del $multipart/mixed por defecto. Si quieres especificar el tipo para cada dato, debes jugar con los objetos Mail::Message::Body tú mismo.

Este método constructor build utilizará buildFromBody() cuando el objeto cuerpo ha sido construido. Juntos, producen tu mensaje.

-Opción-Valor por defecto
 attach  undef
 data    undef
 file    undef
 files   [ ]
 head    undef
attach => $body|$part|$message|\@attach
Un adjunto para el mensaje. Cada adjunto puede ser un $message, un $part o un $body. Cualquier $message se encapsula en un cuerpo $message/rfc822. Puedes especificar muchos elementos (pueden ser de diferentes tipos) al mismo tiempo.
data => $text|\@lines
El $text para una parte, especificado como una cadena, o un ARRAY de @lines. Cada línea, incluida la última, debe terminar con un salto de línea. Este argumento se pasa a Mail::Message::Body::new(data) para construir un cuerpo.
file => $file|$fh|$io|\@files
Crea un cuerpo donde los datos se leen del archivo especificado por nombre, filehandle $fh o objeto $io de tipo IO::Handle. Este cuerpo también se usa para crear un Mail::Message::Body. [2.119] Puedes incluso pasar más de un archivo al mismo tiempo: 'file' y 'files' son equivalentes.
files => \@files
Alias de la opción "file".
head => $head
Empieza con una cabecera preparada, de lo contrario se crea una.

» ejemplo:

my $msg = Mail::Message->build(
  From    => 'me@home.nl',
  To      => Mail::Address->new('your name', 'you@yourplace.aq'),
  Cc      => 'everyone@example.com',
  Subject => 'Hablemos',
  $other_message->get('Bcc'),
  data   => [ 'Esto es\n', 'la primera parte de\n', 'el mensaje\n' ],
  file   => 'myself.gif',
  file   => 'you.jpg',
  attach => $signature,
);
my $msg = Mail::Message->build(
  To     => 'you',
  'Content-Type' => 'text/html',
  data   => '<html></html>',
);
$class->buildFromBody($body, [$head], $headers)
Forma un mensaje alrededor de un $body. Los cuerpos tienen información sobre su contenido que se usa para construir la cabecera del mensaje. Puedes especificar un objeto $head que se inicializa previamente, o uno se crea para ti (también cuando $head es undef). Además, se pueden especificar más $headers que se almacenan en esa cabecera.

Los campos de cabecera se agregan en orden, y antes de las líneas de cabecera definidas por el cuerpo. Pueden ser proporcionados como pares clave-valor u objetos Mail::Message::Field. En caso de un par clave-valor, el nombre del campo se usa como clave y el valor es una cadena, dirección (objeto Mail::Address) o lista de direcciones.

Los campos de tipo Date, Message-Id y MIME-Version se agregan salvo que se especifiquen.

» ejemplo:

my $type = Mail::Message::Field->new('Content-Type', 'text/html',
'charset="us-ascii"');
my @to   = (
  Mail::Address->new('Your name', 'you@example.com'),
  'world@example.info',
);
my $msg  = Mail::Message->buildFromBody($body,
From => 'me@example.nl',
To   => \@to,
$type,
);

DETALLES

Construyendo un mensaje

Construcción rápida

Los mensajes que necesitas construir son relativamente simples. Por eso, este módulo proporciona un método para preparar un mensaje con solo una llamada de método: build().

Comparado conMIME::Entity::build()

El método build() en MailBox se modela después del método build() de MIMETools, pero con algunas simplificaciones:

Cuando una clave comienza con mayúsculas, siempre es un campo de cabecera
Cuando una clave está en minúsculas, siempre es algo más
Uso los nombres reales de los campos, no abreviaciones
Todos los nombres de campo son aceptados
Puedes especificar objetos de campo entre pares clave-valor
Muchos factores se autodetectan, como el tipo de contenido y la codificación
Puedes crear un multipart en un solo paso
