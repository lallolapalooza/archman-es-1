NOMBRE

Mail::SpamAssassin::Plugin::Razor2 - realiza la comprobación de Razor de mensajes

SINOPSIS

loadplugin     Mail::SpamAssassin::Plugin::Razor2

DESCRIPCIÓN

Vipul's Razor es una red distribuida y colaborativa de detección y filtrado de spam basada en envíos de usuarios de spam. La detección se realiza con firmas que localizan eficientemente contenido de spam mutante y la entrada del usuario se valida mediante asignaciones de reputación.

Para más información sobre Razor, consulte http://razor.sourceforge.net/.

DEPENDENCIAS

Razor2 requiere que el módulo Perl "Razor2::Client::Agent" esté instalado.

DEFINICIONES DE REGLAS

Razor2 calcula una firma para cada parte de un mensaje multipart y luego compara esas firmas con una base de datos de firmas de spam conocidas. El servidor devuelve un valor de confianza (0-100) para cada parte del mensaje. La parte con el valor de confianza más alto se utiliza como valor de confianza para el mensaje.

Las siguientes reglas de evaluación son proporcionadas por este plugin:

full   RULENAME   eval:check_razor2()
   Devuelve verdadero si el valor de confianza del mensaje es mayor o igual que `min_cf` tal como se define en
   el archivo de configuración de Razor2 'razor-agent.conf(1)'.
full   RULENAME   eval:check_razor2_range(<engine>,<min>,<max>)
   <engine>  Número de motor (4, 8 o '')
   <min>     Valor de confianza mínimo (0-100)
   <max>     Valor de confianza máximo (0-100)
   Devuelve verdadero si el valor de confianza de spam para el mensaje es mayor o igual que <min> y
   menor o igual que <max>. Si no se especifica <engine>, se utiliza el motor con el valor de confianza más
   alto.

CONFIGURACIÓN DEL USUARIO

usar_razor2 (0|1) (por defecto: 1)
Si se debe usar Razor2, si está disponible.

CONFIGURACIÓN DEL ADMINISTRADOR

razor_fork (0|1) (por defecto: 1)
En lugar de ejecutar Razor2 de forma síncrona, crea un proceso separado para él y lee los resultados más tarde (similar a las búsquedas DNS asíncronas). Aumenta el rendimiento. Se considera experimental en Windows, donde el valor por defecto es 0.
razor_timeout n (por defecto: 5)
Cuántos segundos espera a que Razor se complete antes de continuar sin los resultados.
razor_config nombre_archivo
Define el nombre de archivo utilizado para almacenar la configuración de Razor. Actualmente, esto lo decide Razor.
