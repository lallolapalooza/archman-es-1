Mail::SPF::Mech::IP4(3) Documentación de Perl contribuida por el usuario Mail::SPF::Mech::IP4(3)

NOMBRE

Mail::SPF::Mech::IP4 - Clase de mecanismo "ip4" de registro SPF

VERSIÓN

versión 3.20250505

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::Mech::IP4 representa un mecanismo de registro SPF de tipo "ip4".

Constructores

Se proporcionan los siguientes constructores:

new(%options): devuelve Mail::SPF::Mech::IP4
Crea un nuevo objeto de mecanismo "ip4" de registro SPF.

%options es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

qualifier
ip_network
Ver "new" en Mail::SPF::Mech.
new_from_string($text, %options): devuelve Mail::SPF::Mech::IP4; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMech
Crea un nuevo objeto de mecanismo "ip4" de registro SPF analizando la cadena y las opciones dadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

default_qualifier
default_ipv4_prefix_length
qualifier_pattern
Ver "Métodos de clase" en Mail::SPF::Mech.
name: devuelve cadena
Devuelve 'ip4'.
name_pattern: devuelve Regexp
Devuelve una expresión regular que coincide con un nombre de mecanismo de 'ip4'.

Ver Mail::SPF::Mech para otros métodos de clase admitidos.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

text
qualifier
params
stringify
Ver "Métodos de instancia" en Mail::SPF::Mech.
ip_network: devuelve NetAddr::IP
Devuelve el parámetro de red de la dirección IP del mecanismo.
match($server, $request): devuelve booleano
Devuelve true si la "ip_network" del mecanismo es igual o contiene la dirección IP de la solicitud dada, o false en caso contrario. Ver RFC 4408, 5.6, para más detalles.
