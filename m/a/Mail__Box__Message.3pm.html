NAME

Mail::Box::Message - manage one message within a mail-folder

INHERITANCE

Mail::Box::Message
  is a Mail::Message
  is a Mail::Reporter
Mail::Box::Message is extended by
  Mail::Box::Dir::Message
  Mail::Box::File::Message
  Mail::Box::Message::Destructed
  Mail::Box::Net::Message

SYNOPSIS

# Usually these message objects are created indirectly
use Mail::Box::Manager;
my $manager = Mail::Box::Manager->new;
my $folder  = $manager->open(folder => 'Mail/Drafts');
my $msg     = $folder->message(1);
$msg->delete;
$msg->size;   # and much more

DESCRIPTION

These pages do only describe methods which relate to folders. If you access the knowledge of a message, then read Mail::Message.

During its life, a message will pass through certain stages. These stages were introduced to reduce the access-time to the folder. Changing from stage, the message's body and head objects may change.

The message

Extends "The message" in Mail::Message.

$obj->container()
Inherited, see "The message" in Mail::Message
$obj->copyTo($folder, %options)
Copy the message to the indicated opened $folder, without deleting the original. The coerced message (the clone in the destination folder) is returned. 
-Option      --Default
 shallow       false
 shallow_body  false
 shallow_head  false
 share         false
shallow => BOOLEAN
Used for clone(shallow).
shallow_body => BOOLEAN
Used for clone(shallow_body).
shallow_head => BOOLEAN
Used for clone(shallow_head).
share => BOOLEAN
Try to share the physical storage of the message between the two folders. Sometimes, they even may be of different types. When not possible, this options will be silently ignored.

» example:

my $draft = $mgr->open(folder => 'Draft');
$message->copyTo($draft, share => 1);
$obj->delete()
Delete the message from the folder it belongs to. No message object remains available after this action. When the folder is closed, the message is gone forever.
$obj->duplicate(%options)
Make a copy of the message in the same folder. The new message gets a new message-id and is placed at the end of the folder. This does not change the folder structure.

» example:

my $copy = $msg->duplicate;
$obj->move($folder, %options)
Move the message to another folder. If the move is successful, the original message object is destroyed. The new message object in the destination folder is returned.

» example:

my $sent = $mgr->open(folder => 'Sent');
my $new_msg = $msg->move($sent);

Check or set the 'marked' status of the message. This status is specific to the folder implementation. Some folders use this flag for deletion, others for flags like 'read' or 'answered'.
$obj->isPrivate([$boolean])
Check or set the 'private' status of the message. This is a generic flag that can be used by applications to mark messages.
$obj->isUnread([$boolean])
Check or set the 'unread' status of the message. This is a generic flag that can be used by applications to mark messages.

Set the message as 'marked'. Equivalent to isMarked(1).
$obj->new(%options)
See "Constructors".
$obj->open()
Open the message. This might be necessary to get access to the message body and head. This method is called automatically when needed.
$obj->read()
Read the message from the folder. This method is called automatically when accessing message attributes or methods that depend on the message content. The effect is that the message object is loaded into memory.
$obj->undelete()
Make a deleted message available again. This is only possible before the folder is closed.
$obj->unmark()
Remove the 'marked' status. Equivalent to isMarked(0).
$obj->unread()
Set the message as 'unread'. Equivalent to isUnread(1).

$obj->moveTo($folder, %options)
Move the message from this folder to the $folder specified. This will create a copy using clone() first. Then, this original message is flagged to get deleted. So until the source folder is closed, two copies of the message may stay in memory.

The newly created message clone (part of the destination folder) is returned. All %options are passed to copyTo()

-Option      --Default
 shallow_body  undef
 share         <true unless shallow_body exists>
shallow_body => BOOLEAN
Only create a shallow body, which means that the header can not be reused. A message can therefore not be shared in storage unless explicitly stated.
share => BOOLEAN
When there is a chance that the original message can be undeleted, then this must be set to "false". Otherwise a shallow clone will be made, which will share the header which can be modified in the undeleted message.

» example: of moving a message

my $trash = Mail::Box::Mbox->new(folder => 'trash');
my $t = $msg->moveTo($trash);

is equivalent to

my $t = $msg->copyTo($trash, share => 1);

$obj->readBody( $parser, $head, [$bodytype] )
Read the body of one message. The $parser gives access to the folder file. The $head has been read with readHead(). The optional $bodytype supplies the class name of the body to be created, or a code reference to a routine which can produce a body type based on the head (passed as first argument).

$obj->destruct()
Removes most of the memory occupied by the message by detaching the header and body. Then, the object changes into a Mail::Box::Message::Destructed which will catch all attempts to access the header and body. Be careful with the usage of this method. Improves base, see "Cleanup" in Mail::Message

DIAGNÓSTICOS

Error: No se puede convertir un objeto de clase $class a un objeto de clase $class
Generado por coerce()
Error: No se puede incluir la fuente de reenvío como $include.
Alternativa desconocida para el reenvío (incluir). Las opciones válidas son "NO", "EN LÍNEA", "ADJUNTO" y "ENCAPSULAR". Generado por forward()
Error: No se puede incluir la fuente de respuesta como $include.
Alternativa desconocida para la opción "include" de reply(). Las opciones válidas son "NO", "EN LÍNEA" y "ADJUNTO". Generado por reply()
Error: El método bounce requiere To, Cc o Bcc
El método bounce() del mensaje reenvía un mensaje recibido a otra persona sin modificaciones; debes especificar su nuevo destino. Si tienes la tentación de no especificar ningún destino, probablemente estés buscando reply(). Cuando desees modificar el contenido, usa forward(). Generado por bounce()
Error: El método forwardAttach requiere un preámbulo
Generado por forwardAttach()
Error: El método forwardEncapsulate requiere un preámbulo
Generado por forwardEncapsulate()
Error: No hay dirección para crear el reenvío.
Si se crea un mensaje de reenvío, se debe especificar una dirección de destino. Generado por forward()
Error: No se encontró ningún remitente predeterminado para enviar el mensaje.
El mecanismo send() del mensaje no tenía suficiente información para encontrar automáticamente un agente de transferencia de correo para enviar este mensaje. Especifica un remitente explícitamente usando las opciones "via". Generado por send()
Error: No se definió ninguna regla de reconstrucción $name.
Generado por rebuild()
Error: Solo build() mensajes de Mail::Message; todavía no están en una carpeta
Es posible que desees construir un mensaje para ser almacenado en algún tipo de carpeta, pero debes hacerlo en dos pasos. Primero, crea un Mail::Message normal, y luego agrégalo a la carpeta. Durante este proceso de Mail::Box::addMessage(), el mensaje será coerce()-d al tipo de mensaje correcto, agregando información de almacenamiento y similar. Generado por build()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, sin embargo, la clase en cuestión no lo hace. Probablemente deberías investigar esto y probablemente informar al autor del paquete. Generado por notImplemented()
Error: la coerción comienza con algún objeto
Generado por coerce()
