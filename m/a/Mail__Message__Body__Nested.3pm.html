NOMBRE

El cuerpo (contenido) de un mensaje puede almacenarse en diversos modos. En esta página de manual, se describe la funcionalidad extra que se tiene cuando un mensaje contiene un mensaje nested, como "message/rfc822".

Un mensaje nested es diferente de un mensaje multipart que contiene solo un elemento, porque un mensaje nested tiene un conjunto completo de campos de encabezado definidos por el RFC882, donde parte de un multipart tiene solo unos pocos. Pero debido a que no seguimos el trackeo de si todos los campos están presentes, se usa "Mail::Message::Part" siempre.

ADVERTENCIA: Desde 2023, al menos Outlook comenzó a interpretar incorrectamente el RFC6533. Los cuerpos de tipo 'message/rfc822' solo pueden ser 'nested', pero cuando ellos (illegally) tienen Content-Transfer-Encoding, ahora pueden comportarse como partes normales del mensaje (el mismo que una pdf o imagen).

Extiende "DESCRIPTION" en Mail::Message::Body.

  es un Mail::Message::Body
  es un Mail::Reporter

si ($body->isNested) {
   mi $nest = $body->nested;
   $nest->delete;

NAME

Mail::Message::Body::Message - represents a message body which is a message

INHERITANCE

Mail::Message::Body::Message is a subclass of Mail::Message::Body.

It exports no functions.

SYNOPSIS

require Mail::Message;

  my $msg  = ...;
  my $body = $msg->body;
  if ($body->isa(__PACKAGE__)) {
     my $nested = $body->nested;
     print $nested->subject;
  }

DESCRIPTION

This class represents a message body part that contains another message. This is typically used for the body of a multipart/digest message, or for a message that is being forwarded.

The methods defined here are only a small selection of the methods that are available on the object. A Mail::Message::Body::Message object is a Mail::Message::Body object, and therefore all methods from that class (and its superclasses) are also available. However, some methods are overloaded or have a different meaning.

Specifically, the content of the body is the nested message itself. Methods like string(), print(), and lines() will operate on the nested message, not on the raw encoded data.

SUBCLASSING

Extends "SUBCLASSING" in Mail::Message::Body.

Mail::Message::Body::Message->new(%args)
Creates a new message body object. It expects the nested message as the message argument.

EXAMPLE

This example shows how to extract a nested message from a multipart email.

    use Mail::Message;

    my $msg = Mail::Message->new();
    $msg->parse(<<'END_EMAIL');
    Content-Type: multipart/mixed; boundary=boundary1

    --boundary1
    Content-Type: text/plain

    This is the first part.

    --boundary1
    Content-Type: message/rfc822

    From: sender@example.com
    To: recipient@example.org
    Subject: A nested message

    This is the content of the nested message.
    --boundary1--
    END_EMAIL

    my $body = $msg->body;
    foreach my $part ($body->parts) {
        if ($part->mimeType eq 'message/rfc822') {
            my $nested_msg = $part->nested;
            print "Nested message subject: ", $nested_msg->subject, "\n";
            print "Nested message body:\n", $nested_msg->body->string, "\n";
        }
    }

DIAGNOSTICS

Warning: Charset $name is not known
The encoding or decoding of a message body encounters a character set which is not understood by Perl's Encode module. Cast by encode()
Warning: Content-Transfer-Encoding `$encoding' requires explicit charset, defaulted to utf-8
Cast by encode()
Warning: No decoder defined for transfer encoding $name.
The data (message body) is encoded in a way which is not currently understood, therefore no decoding (or recoding) can take place. Cast by encode()
Warning: No encoder defined for transfer encoding $name.
The data (message body) has been decoded, but the required encoding is unknown. The decoded data is returned. Cast by encode()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
Warning: Unknown line terminator $eol ignored
Cast by eol()
Error: You cannot use foreachLine on a nested
foreachLine() should be used on decoded message bodies only, because it would modify the header of the encapsulated message. which is clearly not acceptable. Cast by foreachLine()
