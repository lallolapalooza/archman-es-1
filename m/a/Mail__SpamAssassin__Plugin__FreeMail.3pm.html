Paquete: spamassassin

Licencias: APACHE

Mail::SpamAssassin::Plugin::FreeMail(3) Documentación de Perl contribuida por el usuario Mail::SpamAssassin::Plugin::FreeMail(3)

NOMBRE

FreeMail - comprueba la cabecera/cuerpo del mensaje en busca de dominios de correo gratuito

SINOPSIS

Si, por ejemplo, la dirección del remitente es freemail, y la dirección de Reply-To o la dirección encontrada en el cuerpo del correo es una dirección de freemail diferente, devuelve éxito. Buena señal de estafas nigerianas, etc. Idea de prueba de Marc Perkel.

También funciones separadas para comprobar varias partes del mensaje en busca de freemails.

CONFIGURACIóN

freemail_domains dominio ...

Lista de dominios a utilizar en las comprobaciones.
No se admiten expresiones regulares, pero los siguientes comodines funcionan:
? para un solo carácter (no coincide con un punto)
* para múltiples caracteres (no coincide con un punto)
Por ejemplo:
freemail_domains hotmail.com hotmail.co.?? yahoo.* yahoo.*.*

freemail_welcomelist email/dominio ...

Anteriormente freemail_whitelist, que funcionará indistintamente hasta la versión 4.1.
Los correos electrónicos o dominios listados aquí se ignoran (se simula que no son
freemail). ¡No hay comodines!

freemail_import_welcomelist_auth 1/0

Las entradas en welcomelist_auth también se utilizarán para incluir correos electrónicos
o dominios en la lista blanca para que no sean considerados freemail. Por defecto es 0.

freemail_import_def_welcomelist_auth 1/0

Las entradas en def_welcomelist_auth también se utilizarán para incluir correos electrónicos
o dominios en la lista blanca para que no sean considerados freemail. Por defecto es 0.

header FREEMAIL_REPLYTO eval:check_freemail_replyto(['opción'])

Comprueba/compara direcciones de freemail encontradas en las cabeceras y el cuerpo.
Opciones posibles:
replyto      La dirección From: o del cuerpo es diferente de Reply-To
             (este es el valor por defecto)
reply        igual que lo anterior, pero si no se encuentra la cabecera Reply-To,
             compara From: y el cuerpo

header FREEMAIL_FROM eval:check_freemail_from(['expresión_regular'])

Comprueba todas las cabeceras "from" posibles para ver si el remitente es freemail.
Utiliza la función SA all_from_addrs() (incluye 'Resent-From', 'From',
'EnvelopeFrom', etc.).
Añada una expresión regular opcional para hacer coincidir la(s) dirección(es) de correo electrónico encontrada(s). Por ejemplo,
para ver si el usuario termina en un dígito: check_freemail_from('\d@')
Si utiliza varias reglas check_freemail_from con expresiones regulares, recuerde
que pueden afectar a correos electrónicos diferentes de cabeceras diferentes. Para hacer coincidir
solo una cabecera determinada, utilice check_freemail_header.

header FREEMAIL_HDRX eval:check_freemail_header('cabecera' [, 'expresión_regular'])

Busca en la cabecera definida una dirección de freemail. Expresión regular opcional para hacer coincidir
la dirección encontrada (como en check_freemail_from).

header FREEMAIL_BODY eval:check_freemail_body(['expresión_regular'])

Busca en el cuerpo una dirección de freemail. Con una expresión regular opcional para hacer coincidir.
