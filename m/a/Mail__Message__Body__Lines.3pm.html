NAME

Mail::Message::Body::Lines - body of a Mail::Message stored as array of lines

INHERITANCE

Mail::Message::Body::Lines
  is a Mail::Message::Body
  is a Mail::Reporter

SYNOPSIS

See Mail::Message::Body

DESCRIPTION

The body (content) of a message can be stored in various ways. In this documentation you find the description of extra functionality you have when a message is stored in an array of lines.

Storing a whole message as an array of lines is useful when the data is not encoded, and you want to process it on a line-by-line basis (a common practice for inspecting message bodies).

The content as lines

This class is a subclass of Mail::Message::Body, which means that it has a method lines().

$obj->lines( [ARRAY] )
When called without arguments, returns the list of lines.
When called with an argument, that argument is assigned as the new list of lines.

The return value of lines() is an array reference.

There is one situation where the object does not contain an array reference: when it is used on a part of a multipart message that does not have any content at all. In this case, the return value is undef.

When used on a message part with content, you will get an array reference with the lines that make up the content. The lines may or may not include their line termination characters (CRLF).

DIAGNÓSTICOS

Advertencia: El juego de caracteres $name no se conoce
La codificación o decodificación del cuerpo de un mensaje se encuentra con un conjunto de caracteres que no es entendido por el módulo Encode de Perl. Emitido por encode()
Advertencia: Content-Transfer-Encoding `$encoding' requiere un juego de caracteres explícito, por defecto utf-8
Emitido por encode()
Advertencia: No hay decodificador definido para la codificación de transferencia $name.
Los datos (cuerpo del mensaje) están codificados de una manera que no se entiende actualmente, por lo tanto, no se puede realizar ninguna decodificación (o recodificación). Emitido por encode()
Advertencia: No hay codificador definido para la codificación de transferencia $name.
Los datos (cuerpo del mensaje) se han decodificado, pero la codificación requerida es desconocida. Se devuelven los datos decodificados. Emitido por encode()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, sin embargo, la clase en cuestión no lo hace. Probablemente deberías investigar esto y, probablemente, informar al autor del paquete. Emitido por notImplemented()
Error: No se puede leer el archivo $filename para las líneas del cuerpo del mensaje: $!
Se va a crear un objeto Mail::Message::Body::Lines a partir de un archivo con nombre, pero es imposible leer ese archivo para recuperar las líneas que contiene. Emitido por new()
Advertencia: Terminador de línea desconocido $eol ignorado
Emitido por eol()
