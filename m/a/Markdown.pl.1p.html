MARKDOWN(1) Documentación de Perl contribuida por el usuario MARKDOWN(1)

NOMBRE

Markdown.pl - Convierte la sintaxis Markdown a (X)HTML

DESCRIPCIÓN

Este programa se distribuye como parte del módulo Text::Markdown de Perl, ilustrando un uso de ejemplo.

Markdown se puede invocar sobre cualquier archivo que contenga sintaxis Markdown, y producirá el (X)HTML correspondiente en STDOUT:

$ cat file.txt
This is a *test*.
Absolutely _nothing_ to see here. _Just a **test**_!
* test
* Yup, test.
$ Markdown.pl file.txt
<p>This is a <em>test</em>.</p>
<p>Absolutely <em>nothing</em> to see here. <em>Just a <strong>test</strong></em>!</p>
<ul>
<li>test</li>
<li>Yup, test.</li>
</ul>

Si no se especifica ningún archivo, esperará la entrada de STDIN:

$ echo "A **simple** test" | markdown
<p>A <strong>simple</strong> test</p>

OPCIONES

version
Muestra la información completa de esta versión
shortversion
Muestra solo el número de versión
html4tags
Produce etiquetas estilo HTML 4 en lugar de XHTML. XHTML requiere que los elementos que no envuelven un bloque (es decir, la etiqueta "hr") indiquen que no se cerrarán, cerrando con "/>". Estilo HTML 4 mostrará simplemente la etiqueta tal como viene: 
$ echo '---' | markdown
<hr />
$ echo '---' | markdown --html4tags
<hr>
help
Muestra esta documentación
