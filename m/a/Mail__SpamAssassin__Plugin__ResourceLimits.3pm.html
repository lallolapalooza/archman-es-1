NOMBRE

Mail::SpamAssassin::Plugin::ResourceLimits - Limita la memoria y/o CPU de los procesos hijos de spamd

SINOPSIS

# Este plugin es solo para administradores y no puede especificarse en la configuración del usuario.
loadplugin     Mail::SpamAssassin::Plugin::ResourceLimits
# Establece RLIMIT_CPU de BSD::Resource. La cuota se basa en el tiempo máximo de CPU en segundos.
resource_limit_cpu 120
# Establece RLIMIT_RSS y RLIMIT_AS a través de BSD::Resource.
resource_limit_cpu 536870912

DESCRIPCIÓN

Este módulo utiliza BSD::Resource para asegurar que tus procesos hijos de spamd no excedan los límites de CPU o memoria especificados. Si esto ocurre, el proceso hijo morirá. Consulta BSD::Resource para más detalles.

NOTA: Dado que este plugin utiliza BSD::Resource, no funcionará en Windows.

CONFIGURACIÓN DEL ADMINISTRADOR

resource_limit_cpu 120 (por defecto: 0 o sin límite)
Cuántos ciclos de CPU se permiten en este proceso antes de que muera.
resource_limit_mem 536870912 (por defecto: 0 o sin límite)
El número máximo de bytes de memoria permitidos tanto para:
  • bytes de espacio de direcciones (virtuales)
  • tamaño del conjunto residente
