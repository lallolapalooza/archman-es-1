NOMBRE

Mail::SpamAssassin::Plugin::TextCat - Adivinador de idioma TextCat

SINOPSIS

loadplugin     Mail::SpamAssassin::Plugin::TextCat

DESCRIPCIÓN

Este plugin intentará adivinar el idioma utilizado en el texto del cuerpo del mensaje.

Puedes usar la directiva "ok_languages" para establecer qué idiomas se consideran aceptables para el correo entrante y si el idioma adivinado no es aceptable, se activa "UNWANTED_LANGUAGE_BODY". Alternativamente, puedes usar la cabecera de metadatos X-Languages directamente en las reglas.

Siempre agregará los resultados a un par nombre-valor "X-Languages" en la estructura de datos de metadatos del mensaje. Esto puede ser útil como tokens de Bayes y también puede usarse en reglas para puntuación. Los resultados también pueden agregarse a mensajes marcados usando "add_header", con la etiqueta _LANGUAGES_. Consulte Mail::SpamAssassin::Conf para obtener detalles.

Nota: el idioma no siempre se puede reconocer con suficiente confianza. En ese caso, no se toma ninguna acción.

Puedes usar la etiqueta _TEXTCATRESULTS_ para ver la puntuación interna de n-gramas, podría ayudar a ajustar la configuración.

Ejemplos de uso de la cabecera X-Languages directamente en reglas:

header OK_LANGS X-Languages =~ /\ben\b/
score OK_LANGS -1
header BAD_LANGS X-Languages =~ /\b(?:ja|zh)\b/
score BAD_LANGS 1

CONFIGURACIÓN DEL USUARIO

ok_languages xx [ yy zz ... ] (predeterminado: todos)
Esta opción se usa para especificar qué idiomas se consideran aceptables para el correo entrante. SpamAssassin intentará detectar el idioma utilizado en el texto del cuerpo del mensaje.

Tenga en cuenta que el idioma no siempre se puede reconocer con suficiente confianza. En ese caso, no se toma ninguna acción.

La regla "UNWANTED_LANGUAGE_BODY" se activa si ninguno de los idiomas detectados está en la lista "ok". Tenga en cuenta que esta es la única consecuencia de la lista "ok". No actúa como una lista de bienvenida contra ninguna otra forma de escaneo de spam.

En su configuración, debe usar el especificador de idioma de dos o tres letras en minúsculas, no el nombre en inglés del idioma. También puede especificar "all" si un idioma deseado no está listado, o si desea permitir cualquier idioma. La configuración predeterminada es "all".

Ejemplos:

ok_languages all         (permite todos los idiomas)
ok_languages en          (solo permite inglés)
ok_languages en ja zh    (permite inglés, japonés y chino)

Nota: si hay varias líneas ok_languages, solo se utiliza la última.

inactive_languages xx [ yy zz ... ] (predeterminado: ver abajo)
Esta opción se usa para especificar qué idiomas no se considerarán al intentar adivinar el idioma. Por razones de rendimiento, los idiomas soportados que tienen menos de aproximadamente 5 millones de hablantes están deshabilitados por defecto. Tenga en cuenta que listar un idioma en "ok_languages" lo habilita automáticamente para ese usuario.

La configuración predeterminada es:

bs cy eo et eu fy ga gd is la lt lv r

Para la lista completa de idiomas y sus códigos de dos o tres letras, consulte la sección "USER SETTINGS" anterior.

textcat_max_languages N (default: 3)
The maximum number of languages a message can match before its classification is considered unknown. You can try lowering this to 2 or even 1 for more confident results, as it is rare for a message to contain multiple languages.

Read the description for textcat_acceptable_score as well, since these settings are very related. The score affects how many languages might match and here we set the "false positive cutoff", where we believe the engine cannot decide what languages the message actually contains.

textcat_optimal_ngrams N (default: 0)
If the number of ngrams is less than this number, they will be discarded. This can be used to speed up the program on longer inputs. For shorter inputs this should be set to 0.
textcat_max_ngrams N (default: 400)
The maximum number of ngrams that should be compared against each language model (note that each of those models is fully utilized).
textcat_acceptable_score N (default: 1.02)
Include any language that scores at least "textcat_acceptable_score" of the top score in the list of returned languages.

This setting is basically a percentage range. Any language that has an ngram-score within N percent of the top score is included in the results. Values greater than 1.05 are not recommended, as they might produce a lot of false matches. A setting of 1.00 means that the highest scoring language is always selected, although this is not recommended, as textcat_max_languages cannot do its job of classifying the language as uncertain.

Read the description for textcat_max_languages, as these settings are very related.

You can use the _TEXTCATRESULTS_ tag to view the internal ngram score, and it may help in tuning the parameters.
