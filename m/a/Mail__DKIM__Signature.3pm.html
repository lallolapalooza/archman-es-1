Mail::DKIM::Signature(3) Documentación de Perl contribuida por el usuario Mail::DKIM::Signature(3)

NOMBRE

Mail::DKIM::Signature - representa una cabecera DKIM-Signature

VERSIÓN

versión 1.20240923

CONSTRUCTORES

new() - crea una nueva firma a partir de parámetros

my $signature = Mail::DKIM::Signature->new(
                    [ Algorithm => 'rsa-sha1', ]
                    [ Signature => $base64, ]
                    [ Method => 'relaxed', ]
                    [ Domain => 'example.org', ]
                    [ Identity => 'user@example.org', ]
                    [ Headers => 'from:subject:date:message-id', ]
                    [ Query => 'dns', ]
                    [ Selector => 'alpha', ]
                    [ Timestamp => time(), ]
                    [ Expiration => time() + 86400, ]
                );

parse() - crea una nueva firma a partir de una cabecera DKIM-Signature

my $sig = Mail::DKIM::Signature->parse(
                'DKIM-Signature: a=rsa-sha1; b=yluiJ7+0=; c=relaxed'
          );

Construye una firma analizando el contenido de la cabecera DKIM-Signature proporcionada. No tiene que incluir el nombre de la cabecera (es decir, "DKIM-Signature:"), pero se recomienda, para que el nombre de la cabecera se conserve y se devuelva de la misma manera en as_string().

Nota: La entrada a este constructor tiene el mismo formato que la salida del método as_string.

MÉTODOS

algorithm() - obtiene o establece el algoritmo (campo a=)

El algoritmo utilizado para generar la firma. Debe ser uno de los siguientes: - "rsa-sha1", un digest SHA-1 firmado con RSA - "rsa-sha256", un digest SHA-256 firmado con RSA - "ed25519-sha256", un digest SHA-256 firmado con Ed25519

Ver también hash_algorithm().

as_string() - la cabecera de firma como una cadena

print $signature->as_string . "\n";

salida

DKIM-Signature: a=rsa-sha1; b=yluiJ7+0=; c=relaxed

Como se muestra en el ejemplo, el método as_string se puede utilizar para generar la DKIM-Signature que se antepone a un mensaje firmado.

as_string_without_data() - firma sin los datos de la firma

print $signature->as_string_without_data . "\n";

salida

DKIM-Signature: a=rsa-sha1; b=; c=relaxed

Esto es similar al método as_string(), pero siempre excluye la parte de los "datos". Esto es utilizado por los métodos de canonicación DKIM, que requieren incorporar esta parte de la firma en el mensaje firmado.

body_count() - obtiene o establece el recuento del cuerpo (campo l=)

my $i = $signature->body_count;

Informa al verificador del número de bytes en el cuerpo del correo electrónico incluido en el hash criptográfico, comenzando desde 0 inmediatamente después del CRLF que precede al cuerpo. También conocido como la etiqueta l=.

Al crear una firma, esta etiqueta puede omitirse o establecerse después de que el sistema de canonicación seleccionado haya recibido el cuerpo completo del mensaje (pero antes de que canonice la DKIM-Signature).

body_hash() - obtiene o establece el hash del cuerpo (campo bh=)

my $bh = $signature->body_hash;

El hash de la parte del cuerpo del mensaje. Los espacios en blanco se ignoran en este valor. Esta etiqueta es obligatoria.

Al acceder a este valor, se eliminan los espacios en blanco de la etiqueta por usted.

canonicalization() - obtiene o establece la canonicación (campo c=)

$signature->canonicalization('relaxed', 'simple');
($header, $body) = $signature->canonicalization;

Canonicación del mensaje (el valor predeterminado es "simple/simple"). Esto informa al verificador del tipo de canonicación utilizado para preparar el mensaje para firmar.

En contexto escalar, esto devuelve la canonicación de cabecera/cuerpo como una sola cadena separada por /. En contexto de lista, devuelve una matriz de dos elementos, que contiene primero la canonicación de cabecera, luego el cuerpo.

data() - obtiene o establece los datos de la firma (campo b=)

my $base64 = $signature->data;
$signature->data($base64);

Los datos de la firma. Los espacios en blanco se eliminan automáticamente del valor devuelto. Los datos están codificados en Base64.

domain() - obtiene o establece el dominio (campo d=)

my $d = $signature->domain;          # obtiene el valor del dominio
$signature->domain('example.org');   # establece el valor del dominio

El dominio de la entidad firmante, según lo especificado en la firma. Este es el dominio que se consultará para obtener la clave pública.

Si se utiliza un "nombre de dominio internacionalizado", el nombre de dominio debe convertirse a ASCII (siguiendo la sección 4.1 de RFC 3490) antes de pasarlo a este método.

expiration() - obtiene o establece la expiración de la firma (campo x=)

Expiración de la firma (el valor predeterminado es undef, lo que significa que no hay expiración). La expiración de la firma, si se define, es un entero sin signo que identifica los segundos estándar de Unix desde 1970 del momento en que la firma expirará.

get_public_key() - recupera la clave pública a la que hace referencia esta firma

my $pubkey = $signature->get_public_key;

La clave pública a recuperar está determinada por los campos de protocolo, selector y dominio.

Este método almacena en caché el resultado de la recuperación, por lo que las llamadas posteriores no requerirán consultas DNS adicionales.

Este método "morirá" si ocurre un error.

get_tag() - accede al valor sin procesar de una etiqueta en esta firma

my $raw_identity = $signature->get_tag('i');

Utilice este método para acceder a una etiqueta que aún no sea compatible con Mail::DKIM, o si desea omitir la decodificación del valor por parte de Mail::DKIM.

Por ejemplo, la etiqueta sin procesar i= (identidad) está codificada en formato quoted-printable. Si utiliza el método identity(), Mail::DKIM decodificará de quoted-printable antes de devolver el valor. Pero si utiliza get_tag('i'), puede acceder a la forma codificada quoted-printable del valor.

hash_algorithm() - accede al algoritmo de hash especificado en esta firma

my $hash = $signature->hash_algorithm;

Determina qué algoritmo de hash se utiliza como parte del algoritmo especificado en la firma.

Para el algoritmo "rsa-sha1", el algoritmo de hash es "sha1". Del mismo modo, para el algoritmo "rsa-sha256", el algoritmo de hash es "sha256". Si el algoritmo no se reconoce, se devuelve undef.

headerlist() - obtiene o establece los campos de cabecera firmados (campo h=)

$signature->headerlist('a:b:c');
my $headerlist = $signature->headerlist;
my @headers = $signature->headerlist;

Campos de cabecera firmados. Una lista separada por dos puntos de nombres de campos de cabecera que identifican los campos de cabecera presentados al algoritmo de firma.

En contexto escalar, la lista de nombres de campos de cabecera se devolverá como una sola cadena, con los nombres unidos por dos puntos. En contexto de lista, los nombres de campos de cabecera se devolverán como una lista.

identity() - obtiene o establece la identidad de firma (campo i=)

my $i = $signature->identity;

Identidad del usuario o agente en nombre del cual se firma este mensaje. La identidad tiene una parte local opcional, seguida de "@", luego un nombre de dominio. El nombre de dominio debe ser el mismo o un subdominio del dominio devuelto por el método domain().

Idealmente, la identidad debe coincidir con la identidad listada en la cabecera From:, o la cabecera Sender:, pero no es obligatorio tener una firma válida. Si la identidad utilizada está "autorizada" para firmar el mensaje dado no se determina aquí.

Si se utiliza un "nombre de dominio internacionalizado", el nombre de dominio debe convertirse a ASCII (siguiendo la sección 4.1 de RFC 3490) antes de pasarlo a este método.

Los valores de identidad se codifican en la firma en formato quoted-printable. El uso de este método se traducirá hacia/desde quoted-printable según sea necesario. Si desea la versión raw quoted-printable de la identidad, utilice $signature->get_t
