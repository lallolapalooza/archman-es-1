NOMBRE

Mail::SpamAssassin::Pyzor::Digest::Pieces - Módulo de lógica de backend de Pyzor

DESCRIPCIÓN

Este módulo contiene la lógica de backend para Mail::SpamAssassin::Pyzor::Digest.

Reimplementa la lógica encontrada en el módulo digest.py de pyzor (https://github.com/SpamExperts/pyzor/blob/master/pyzor/digest.py).

FUNCIONES

$cadenas_ar = digest_payloads( $EMAIL_MIME )

Esto imita el método de objeto correspondiente en digest.py. Devuelve una referencia a un array de cadenas. Cada cadena puede ser una cadena de bytes o una cadena de caracteres (por ejemplo, decodificada en UTF-8).

NB: RFC 2822 estipula que los cuerpos de los mensajes deben usar saltos de línea CRLF, no LF simple (ni CR simple). Por lo tanto, convertiremos cualquier CR simple en un cuerpo de mensaje quoted-printable a CRLF. Python, sin embargo, no hace esto, por lo que la salida de nuestra implementación de digest_payloads() diverge de la del original de Python. En última instancia, no hace diferencia ya que los finales de línea se recortan independientemente, pero es necesario tenerlo en cuenta al comparar la salida de nuestra implementación con la salida de Python.

normalize( $CADENA )

Esto imita el método de objeto correspondiente en digest.py. Modifica $CADENA in situ.

Al igual que con la implementación original, si $CADENA contiene caracteres Unicode (decodificados), esos caracteres se analizarán en consecuencia. Así:

$str = "123\xc2\xa0";   # [ c2 a0 ] == \u00a0, espacio de no separación
normalize($str);

Lo anterior dejará $str tal cual, pero esto:

utf8::decode($str);
normalize($str);

... eliminará los dos últimos bytes de $str.

$sn = should_handle_line( $CADENA )

Esto imita el método de objeto correspondiente en digest.py. Devuelve un booleano.

$sa = assemble_lines( \@LINES )

Esto ensambla un búfer de cadena a partir de @LÍNEAS. La cadena es el búfer de octetos que se hasheará para producir el resumen del mensaje.

Se espera que cada miembro de @LÍNEAS sea una cadena de octetos, no una cadena de caracteres.

($main, $sub, $encoding, $checkval) = parse_content_type( $CONTENT_TYPE )

@lines = splitlines( $TEXT )

Imita "str.splitlines()". (cf. "pydoc str")

Devuelve una lista simple en contexto de lista. Devuelve el número de elementos que se devolverán en contexto escalar.
