NOMBRE

Mat_VarGetStructs — Indexa una variable de estructura utilizando porciones de cada dimensión

SINOPSIS

#include <matio.h>

matvar_t *
Mat_VarGetStructs(const matvar_t *matvar, const int *start, const int *stride, const int *edge, int copy_fields);

DESCRIPCIÓN

La función Mat_VarGetStructs() selecciona una submatriz de un array de estructuras matvar. Cada uno de los elementos de la submatriz contiene todos los campos de la estructura. El índice de cada dimensión comienza en el elemento start del array (siendo 0 el primer elemento), y lee cada stride valores (siendo 1 cada elemento, 2 cada dos elementos, etc.). El número total de elementos en la submatriz se especifica como edge. La opción copy_fields especifica si los campos de la estructura original se copian para la nueva submatriz. Si se establece en 0, los campos del array de estructuras devuelto tienen el mismo puntero que el array original, y el campo data de la estructura de la submatriz. La submatriz se marca con la bandera de conservación de memoria, indicando que los campos no deben liberarse. Se liberan cuando se libera la estructura original.

VALORES DE RETORNO

Una submatriz del array de estructuras original, o NULL si se produce un error.
