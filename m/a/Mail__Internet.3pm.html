NOMBRE

Mail::Internet - manipular mensajes de correo

SINTAXIS

use Mail::Internet;
my $msg = Mail::Internet->new(\*STDIN);

DESCRIPCIÓN

Este paquete implementa la lectura, creación, manipulación y escritura de mensajes de correo. A veces, la implementación intenta ser demasiado inteligente, pero en el caso general funciona como se espera.

Si estás escribiendo una nueva aplicación, deberías usar la distribución Mail::Box, que tiene más funciones y maneja los mensajes mejor según los RFCs. Ve a http://perl.overmeer.net/mailbox/. También puedes elegir MIME::Entity, para obtener al menos algún soporte multipart en tu aplicación.

MÉTODOS

Constructor

$obj->dup()
Clona el mensaje completo. Tanto el encabezado como el cuerpo se copian profundamente: se devuelve un nuevo objeto Mail::Internet.
$obj->extract(\@lines)
Extrae el encabezado y cuerpo de un ARRAY de líneas de mensaje. Requiere un objeto ya creado con new(), cuyos contenidos se sobrescribirán.
$obj->new( [$arg], [%options] )
Mail::Internet->new( [$arg], [%options] )
$arg es opcional y puede ser un descriptor de archivo (referencia a un GLOB) o una referencia a un array. Si se le da, el nuevo objeto se inicializará con los encabezados y cuerpo de la lista de líneas leída desde el descriptor de archivo.

Los parámetros Mail::Header::new() %options "Modify", "MailFrom" y "FoldLength" también pueden ser dados.

-Opción--Predeterminada
 Body    []
 Header  undef
Body => ARRAY-de-LÍNEAS
El valor de esta opción debe ser una referencia a un array que contiene las líneas del cuerpo del mensaje. Cada línea debe terminar con "\n" (LF). Si se proporciona Body, "Mail::Internet" no intentará leer el cuerpo desde $arg (incluso si se especifica).
Header => Mail::Header
El valor de esta opción debe ser un objeto Mail::Header. Si se le da, "Mail::Internet" no intentará leer un encabezado de correo desde $arg, si se especificó.
$obj->read($fh)
Lee un mensaje desde el $fh en un objeto mensaje ya existente. Se recomienda usar new() con el $fh como primer argumento.

Accesores

$obj->body( [$body] )
Devuelve el cuerpo del mensaje. Este es una referencia a un array. Cada entrada en el array representa una línea del mensaje.

Si $body se proporciona, puede ser una referencia a un array o un array, en cuyo caso el cuerpo se reemplazará. Si se pasa una referencia, se usa directamente y no se copia, por lo que cualquier cambio posterior a este array afecta el contenido del cuerpo.

$obj->head()
Devuelve el objeto "Mail::Header" que contiene los encabezados del mensaje actual

Tratamiento del mensaje como un todo

$obj->as_mbox_string( [$already_escaped] )
Devuelve el mensaje como una cadena en formato mbox. $already_escaped, si es verdadero, indica que escape_from() ha sido llamado en este objeto.
$obj->as_string()
Devuelve el mensaje como una cadena única.
$obj->print( [$fh] )
Imprime el encabezado, cuerpo o mensaje completo en el descriptor de archivo $fh. $fd debe ser una referencia a un GLOB. Si $fh no está dado, la salida se enviará a STDOUT.

Ejemplo:

$mail->print( \*STDOUT );  # Imprime el mensaje a STDOUT
$obj->print_body( [$fh] )
Imprime solo el cuerpo a $fh (por defecto STDOUT).
$obj->print_header( [$fh] )
Imprime solo el encabezado a $fh (por defecto STDOUT).

Tratamiento del encabezado

Muchos de estos métodos son simplemente wrappers alrededor de los métodos proporcionados por Mail::Header.

$obj->add(PAIRS)
PAIRS son campo y contenido del campo. Para cada PAIR, se llama a Mail::Header::add(). Todos los campos se agregan después de los campos existentes. El último agregado es devuelto.
$obj->combine( $tag, [$with] )
Ver Mail::Header::combine().
$obj->delete( $tag, [$tags] )
Elimina todos los campos con el nombre $tag. Mail::Header::delete() realiza el trabajo.
$obj->fold( [$length] )
Ver Mail::Header::fold().
$obj->fold_length( [$tag], [$length] )
Ver Mail::Header::fold_length().
$obj->get( $tag, [$tags] )
En contexto de lista, se devuelven todos los campos con el nombre $tag. En contexto escalar, solo se devuelve el primer campo que coincide con el primer $tag encontrado. Mail::Header::get() se llama para recoger los datos.
$obj->header(\@lines)
Ver Mail::Header::header().
$obj->replace(PAIRS)
PAIRS son campo y contenido del campo. Para cada PAIR, se llama a Mail::Header::replace() con el índice 0. Si un campo $field ya está en el encabezado, se eliminará primero. No se debe especificar el mismo nombre de campo dos veces.

Tratamiento del cuerpo

$obj->remove_sig( [$nlines] )
Intenta eliminar la firma del usuario del cuerpo de un mensaje. Esto lo hace buscando una línea igual a '-- ' en las últimas $nlines del mensaje. Si se encuentra, esa línea y todas las posteriores se eliminarán. Si $nlines no está especificado, se usará un valor predeterminado de 10. Esto sería más útil en scripts de auto-respuesta.
$obj->sign(%options)
Añade tu firma al cuerpo. remove_sig() eliminará primero las firmas existentes. 
-Opción--Predeterminada
 File       undef
 Signature  []
File => MANEJADOR_DE_ARCHIVO
Tomar del manejador de archivo $FILEHANDLE todas las líneas desde el primer "--".
Signature => CADENA|ARRAY-de-LÍNEAS
$obj->tidy_body()
Elimina todas las líneas al principio y al final del cuerpo que contienen solo espacios en blanco.

Funcionalidad de nivel alto

$obj->escape_from()
Puede causar problemas en algunas aplicaciones si un mensaje contiene una línea que comienza con `From ', especialmente cuando se intenta dividir una carpeta. Este método inserta un "`"' al principio de cualquier línea que coincida con el patrón regular "/^"*From/>
$obj->nntppost( [%options] )
Publica un artículo mediante NNTP. Requiere que Net::NNTP esté instalado. 
-Opción--Predeterminada
 Debug   <falso>
 Host    <requerido>
 Port    119
Mail::Internet(3pm)

NAME

Mail::Internet - An object-oriented interface to Internet mail messages

SYNOPSIS

    use Mail::Internet;
    my $message = Mail::Internet->read(\*STDIN);
    # ... manipulate $message ...
    $message->print(\*STDOUT);

DESCRIPTION

This module provides an object-oriented interface to Internet mail messages. It provides methods to read, manipulate and write mail messages.

A Mail::Internet object represents a single Internet mail message. It consists of a header and a body. The header is a collection of fields, and the body is a single string.

METHODS

$obj->new( [$type, [%options]] )
Creates a new Mail::Internet object.
type
The type of message to create. Defaults to "Mail::Internet".
options
A hash of options to initialize the object. See below for details.
$obj->read( [STREAM] )
Reads a mail message from the given STREAM, or from STDINF if STREAM is not specified. Returns a new Mail::Internet object.
Debug => BOOLEAN
Debug value to pass to Net::NNTP, see Net::NNTP
Host => HOSTNAME|Net::NNTP object
Name of NNTP server to connect to, or a Net::NNTP object to use.
Port => INTEGER
Port number to connect to on remote host
$obj->reply(%options)
Create a new object with header initialised for a reply to the current object. And the body will be a copy of the current message indented.

The ".mailhdr" file in your home directory (if exists) will be read first, to provide defaults.

-Option  --Default
 Exclude   []
 Indent    '>'
 Keep      []
 ReplyAll  false
Exclude => ARRAY-of-FIELDS
Remove the listed FIELDS from the produced message.
Indent => STRING
Use as indentation string. The string may contain "%%" to get a single "%", %f to get the first from name, %F is the first character of %f, %l is the last name, %L its first character, %n the whole from string, and %I the first character of each of the names in the from string.
Keep => ARRAY-of-FIELDS
Copy the listed FIELDS from the original message.
ReplyAll => BOOLEAN
Automatically include all To and Cc addresses of the original mail, excluding those mentioned in the Bcc list.
$obj->send( [$type, [$args...]] )
Send a Mail::Internet message using Mail::Mailer. $type and $args are passed on to Mail::Mailer::new().
$obj->smtpsend( [%options] )
Send a Mail::Internet message using direct SMTP to the given ADDRESSES, each can be either a string or a reference to a list of email addresses. If none of "To", <Cc> or "Bcc" are given then the addresses are extracted from the message being sent.

The return value will be a list of email addresses that the message was sent to. If the message was not sent the list will be empty.

Requires Net::SMTP and Net::Domain to be installed.

-Option  --Default
 Bcc       undef
 Cc        undef
 Debug     <false>
 Hello     localhost.localdomain
 Host      $ENV{SMTPHOSTS}
 MailFrom  Mail::Util::mailaddress()
 Port      25
 To        undef
Bcc => ADDRESSES
Cc => ADDRESSES
Debug => BOOLEAN
Debug value to pass to Net::SMTP, see <Net::SMTP>
Hello => STRING
Send a HELO (or EHLO) command to the server with the given name.
Host => HOSTNAME
Name of the SMTP server to connect to, or a Net::SMTP object to use

If "Host" is not given then the SMTP host is found by attempting connections first to hosts specified in $ENV{SMTPHOSTS}, a colon separated list, then "mailhost" and "localhost".

MailFrom => ADDRESS
The e-mail address which is used as sender. By default, Mail::Util::mailaddress() provides the address of the sender.
Port => INTEGER
Port number to connect to on remote host
To => ADDRESSES
$obj->unescape_from(())
Remove the escaping added by escape_from().
