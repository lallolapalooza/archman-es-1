NOMBRE

Mail::Box::File::Message - un mensaje en una carpeta Mbox

HERENCIA

Mail::Box::File::Message
  es un Mail::Box::Message
  es un Mail::Message
  es un Mail::Reporter
Mail::Box::File::Message es extendido por
  Mail::Box::Mbox::Message

SINOPSIS

my $folder  = new Mail::Box::File folder => $ENV{MAIL}, ...;
my $message = $folder->message(0);

DESCRIPCIÓN

Mantiene un mensaje en una carpeta basada en archivos, cualquier extensión de Mail::Box::File.

Extiende "DESCRIPTION" en Mail::Box::Message.

Mail::Box::File::Message(3pm)

NAME

Mail::Box::File::Message - File-based message object

INHERITANCE

This module is part of the Mail::Box distribution.

Inheritance: Mail::Box::Message

SYNOPSIS

 use Mail::Box::File;
 my $box = Mail::Box::File->new( ... );
 my $msg = $box->message_create();
 # ... fill the message ...
 my $folder = $box->folder_get('INBOX');
 $folder->add_message($msg);

DESCRIPTION

This object represents a single message within a Mail::Box::File folder. It knows how to find and access the physical file that holds the message content.

METHODS

This class implements the following methods:

encapsulate()
Returns a new Mail::Box::Message object which is encapsulated by this message. The new message will be stored in the same physical file and folder.
forward()
Create a new message object that contains the current message as a forwarded body. The content of the new message is the current message, embedded as an attachment. The returned object is a Mail::Box::Message object, ready to be filled with new headers and sent.
send()
Send this message using a mailer.
rebuild()
Rebuilds the message from scratch. All parts are collected and written into a new file.
build()
This method is used internally by the folder object to create a new message.
notImplemented()
Placeholder for methods that are not implemented in this specific class.
loadBody()
Loads the message body from the file.
coerce()
Coerces the message object into the correct type for the folder.

DETAILS

This class inherits all methods from Mail::Box::Message and provides a specific implementation for file-based storage.
