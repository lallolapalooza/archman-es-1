Mail::SPF::Mech::IP6(3) Documentación de Perl aportada por el usuario Mail::SPF::Mech::IP6(3)

NOMBRE

Mail::SPF::Mech::IP6 - Clase del mecanismo "ip6" del registro SPF

VERSIÓN

versión 3.20250505

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::Mech::IP6 representa un mecanismo de registro SPF de tipo "ip6".

Constructores

Se proporcionan los siguientes constructores:

new(%opciones): devuelve Mail::SPF::Mech::IP6
Crea un nuevo objeto de mecanismo "ip6" para registros SPF.

%opciones es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

calificador
red_ip
Véase "new" en Mail::SPF::Mech.
new_from_string($texto, %opciones): devuelve Mail::SPF::Mech::IP6; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMech
Crea un nuevo objeto de mecanismo "ip6" para registros SPF analizando la cadena y las opciones dadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

calificador_predeterminado
longitud_prefijo_ipv6_predeterminada
patron_calificador
Véase "Métodos de clase" en Mail::SPF::Mech.
nombre: devuelve cadena
Devuelve 'ip6'.
patron_nombre: devuelve Regexp
Devuelve una expresión regular que coincide con un nombre de mecanismo de 'ip6'.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

texto
calificador
parametros
convertir_a_cadena
Véase "Métodos de instancia" en Mail::SPF::Mech.
red_ip: devuelve NetAddr::IP
Devuelve el parámetro de red de IP de la dirección IP del mecanismo.
coincidir($servidor, $solicitud): devuelve booleano
Devuelve true si la "red_ip" del mecanismo es igual o contiene la dirección IP de la solicitud dada, o false en caso contrario. Consulte RFC 4408, 5.6, para obtener detalles.
