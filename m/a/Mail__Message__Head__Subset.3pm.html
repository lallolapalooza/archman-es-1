Nombre

Mail::Message::Head::Subset - información de campo de mensaje en un subconjunto

Herencia

Mail::Message::Head::Subset hereda de Mail::Message::Head
Mail::Message::Head::Subset
  es un Mail::Message::Head
  es un Mail::Reporter

Sintaxis

my $subset = Mail::Message::Head::Subset->new(...)
$subset->isa('Mail::Message::Head')  # true
$subset->guessBodySize               # entero o undef
$subset->isDelayed                   # true

Descripción

Algunos tipos de carpetas contienen un archivo de índice que lista una o dos líneas de información por cada mensaje. Especialmente cuando es costoso leer las líneas de cabecera, el índice acelera considerablemente el acceso. Por ejemplo, los asuntos de todos los mensajes son a menudo deseables, pero esperar a que un millón de mensajes de una carpeta se lean puede implicar un millón de lecturas (IMAP) o aperturas de archivos (MH)

Cuando accedes a campos de cabecera que no están en el subconjunto de cabecera, la cabecera completa debe ser parseada (lo cual puede consumir un tiempo considerable, dependiendo del tipo de carpeta).

Acceso a la cabecera

Extiende "Acceso a la cabecera" en Mail::Message::Head.

$obj->count($name)
Cuenta el número de campos con este $name. Si el $name no se puede encontrar, se carga la cabecera completa. En el caso de que encuentre cualquier campo $name, se decide que todos los campos se conocen y no se necesita cargar.
$obj->get( $name, [$index] )
Obtiene los datos relacionados con el campo de $name. El caso de las letras en $name no importa. Cuando se utiliza un $name que no se conoce todavía, se realizará la carga. Mejora la base, ver "Acceso a la cabecera" en Mail::Message::Head
$obj->study( $name, [$index] )
Inherente, ver "Acceso a la cabecera" en Mail::Message::Head

Sobre el cuerpo

Extiende "Sobre el cuerpo" en Mail::Message::Head.

$obj->guessBodySize()
El tamaño del cuerpo se define en el campo "Content-Length". Sin embargo, este campo puede no estar definido. En ese caso, se hace un cálculo basado en el campo conocido "Lines". Cuando también ese campo no está definido, se devuelve "undef". Mejora la base, ver "Sobre el cuerpo" en Mail::Message::Head
