NOMBRE

Mail::Box::Locker::Multi - bloquea una carpeta de todas las maneras posibles

HERENCIA

Mail::Box::Locker::Multi
  es un Mail::Box::Locker
  es un Mail::Reporter

SINOPSIS

Ver Mail::Box::Locker

DESCRIPCION

El bloqueador "::Multi" bloquea una carpeta de cada manera que puede. De esta forma, hay una mayor probabilidad de que cualquier otro programa deje la carpeta en paz durante nuestro acceso a ella.

Se prueban NFS-lock y Flock. Pueden añadirse más cuando se amplíen las formas de bloqueo. DotLock se solapa con NFS-lock, pero NFS-lock es más seguro, por lo que se prefiere esa versión.

Extiende "DESCRIPTION" en Mail::Box::Locker.

También puede pasar todas las %opciones que entienden los bloqueadores iniciados que utiliza el bloqueador múltiple. Mejora la base, ver "METHODS" en Mail::Box::Locker 
-Opción --Definido en       --Por defecto
 expires  Mail::Box::Locker  1 hora
 file     Mail::Box::Locker  undef
 folder   Mail::Box::Locker  <C<undef>>
 log      Mail::Reporter     'WARNINGS'
 method   Mail::Box::Locker  'MULTI'
 timeout  Mail::Box::Locker  10
 trace    Mail::Reporter     'WARNINGS'
 use                         <todo lo posible>
expires => $segundos
file => $archivo
folder => $carpeta
log => NIVEL
method => $nombre|CLASE|\@nombres
timeout => $segundos|'NOTIMEOUT'
trace => NIVEL
use => ARRAY-de-(NOMBRES|BLOQUEADOR)
Matriz de NOMBRES de tipo de bloqueador o objetos BLOQUEADOR para ser usados para bloquear una carpeta. Los NOMBRES de tipo se convierten en objetos. Cuando cree sus propios objetos BLOQUEADOR, asegúrese de establecer el tiempo de espera muy corto (preferiblemente a 1).

Algunos tipos de bloqueo no están disponibles en algunas plataformas, por lo que no se excluirán de la lista por defecto (NFS POSIX Flock).

» ejemplo: usando un subconjunto de bloqueadores múltiples

my $locker = Mail::Box::Locker::Multi->new(use => ['DOTLOCK','FLOCK']);
