SINOPSIS

Mail::DomainKeys es una implementación en Perl del protocolo de firma de correo de Yahoo.

Esta biblioteca permite firmar y verificar firmas según el borrador 03 de la especificación DomainKeys:

http://www.ietf.org/internet-drafts/draft-delany-domainkeys-base-03.txt

Un ejemplo simple

Este ejemplo muestra el verificador de firmas DomainKeys más simple posible.

require Mail::DomainKeys::Message;
# carga un mensaje desde un manejador de archivo glob
my $mail = load Mail::DomainKeys::Message(File => \*STDIN) or
  die "no se puede cargar el mensaje\n";
# comprueba para asegurarse de que el remitente tiene un dominio completamente calificado
$mail->senderdomain or
  die "no se puede verificar el mensaje: sin dominio de remitente\n";
# comprueba si el correo está firmado por DomainKeys
$mail->signed or
  die "sin firma\n";
# comprueba la firma
if ($mail->verify) {
  print STDERR "firma válida\n";
  exit 0;
}
# la firma no fue válida
die "no se puede verificar la firma\n";

Este ejemplo muestra el firmante DomainKeys más simple posible.

require Mail::DomainKeys::Message;
require Mail::DomainKeys::Key::Private;
# carga el mensaje, o muere intentándolo
my $mail = load Mail::DomainKeys::Message(File => \*STDIN) or
  die "no se puede cargar el mensaje";
# carga la clave privada, o muere intentándolo
my $priv = load Mail::DomainKeys::Key::Private(File => "private.key") or
  die "no se puede cargar la clave";
# firma el mensaje usando el canonificador "simple" y el selector "test"
$mail->sign(Method => "simple", Selector => "test", Private => $priv);
# imprime la firma
print $mail->signature->as_string;
