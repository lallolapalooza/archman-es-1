NOMBRE

Mail::Message::Construct::Text - captura un Mail::Message como texto

SINOPSIS

my $text = $msg->string;
my $text = "$msg";   # vía overload
my @text = $msg->lines;
my @text = @$lines;  # vía overload
my $fh   = $msg->file;
my $line = <$fh>;
$msg->printStructure;

DESCRIPCIÓN

La funcionalidad compleja en objetos Mail::Message se implementa en diferentes archivos que se cargan automáticamente. Este archivo implementa la funcionalidad relacionada con la creación de respuestas de mensajes.

MÉTODOS

El mensaje completo como texto

$obj->file()
Devuelve el mensaje como un manejador de archivo.
$obj->lines()
Devuelve el mensaje completo como un conjunto de líneas. En contexto de LISTA, se devuelven copias de las líneas. En contexto ESCALAR, se devuelve una referencia a un array de líneas.
$obj->printStructure( [$fh|undef],[$indent] )
Imprime la estructura de un mensaje en el $fh especificado o en el manejador de archivo seleccionado. Cuando explícitamente se especifica "undef" como manejador, la salida se devolverá como una cadena.

Se muestran el asunto del mensaje y los tipos de todas las partes que lo componen.

$indent especifica la cadena de indentación inicial: se añade delante de cada línea. El $indent debe contener al menos un espacio en blanco.

» ejemplo:

my $msg = ...;
$msg->printStructure(\*OUTPUT);
$msg->printStructure;
my $struct = $msg->printStructure(undef);
# Posible salida para un mensaje:
multipart/mixed: mensaje reenviado de Pietje Puk (1550 bytes)
   text/plain (164 bytes)
   message/rfc822 (1043 bytes)
      multipart/alternative: Un alternativo multipart (942 bytes)
         text/plain (148 bytes, eliminado)
         text/html (358 bytes)
$obj->string()
Devuelve el mensaje completo como una cadena.
