Mail::Box::Locker::DotLock(3pm)

Mail::Box::Locker::DotLock - manage a lock file for Mail::Box

NAME

Mail::Box::Locker::DotLock - manage a lock file for Mail::Box

INHERITANCE

Mail::Box::Locker::DotLock - manage a lock file for Mail::Box

  • Mail::Box::Locker
  • perl

SYNOPSIS

  use Mail::Box::Locker::DotLock;

  my $locker = Mail::Box::Locker::DotLock->new(file => $lockfile);
  $locker->lock;
  # ... work with the mailbox ...
  $locker->unlock;

DESCRIPTION

This locker class implements the locking mechanism for Mail::Box. It creates a lock file with a .lock extension in the same directory as the mailbox file. The lock file contains the process ID (PID) of the process that holds the lock.

When lock() is called, it checks if the lock file exists. If it does, it checks if the process ID in the lock file is still running. If the process is not running, the old lock file is removed and a new one is created.

If the lock file does not exist, a new one is created with the current process ID.

When unlock() is called, the lock file is removed.

METHODS

new( file => $lockfile )

Creates a new Mail::Box::Locker::DotLock object.

The file argument specifies the path to the lock file. If not provided, it defaults to $mailbox.lock, where $mailbox is the path to the mailbox file.

lock()

Acquires the lock. If the lock is already held by another process, it will wait until the lock is released or a timeout occurs (if configured).

unlock()

Releases the lock.

locked()

Returns true if the lock is currently held, false otherwise.

owner()

Returns the process ID of the process that currently holds the lock, or undef if the lock is not held.

DIAGNOSTICS

This module may produce the following error messages:

  • Lock file "%s" is stale.: The lock file is old and the process holding it is no longer running.
  • Cannot lock "%s": %s: Failed to acquire the lock, with the system error message.
  • Cannot unlock "%s": %s: Failed to release the lock, with the system error message.
