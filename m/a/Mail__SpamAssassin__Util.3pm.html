NOMBRE

Mail::SpamAssassin::Util - funciones de utilidad

DESCRIPCIÓN

Una clase general para funciones de utilidad. Por favor, utiliza esto para funciones que son independientes, sin necesidad de un objeto $self, especialmente funciones de portabilidad.

NOTA: Las funciones de este módulo se consideran privadas. Su API puede cambiar en cualquier momento y se espera que solo sean utilizadas por otros módulos de Mail::SpamAssassin. (TODO: probablemente deberíamos revisar esto si es útil para el desarrollo de plugins.)

NOTA: Las funciones de utilidad no deben cambiar variables globales como $_, $1, $2, ... $/, etc., a menos que se documente explícitamente. Si estas variables son utilizadas por estas funciones, deben ser localizadas.

$module = first_available_module (@module_list)
Devuelve el nombre del primer módulo que se puede cargar con éxito con "require" de la lista. Devuelve "undef" si ninguno está disponible.

Esto se utiliza en lugar de "AnyDBM_File" de la siguiente manera:

my $module = Mail::SpamAssassin::Util::first_available_module
                      (qw(DB_File GDBM_File NDBM_File SDBM_File));
tie %hash, $module, $path, [... args];

Tenga en cuenta que se garantiza que "SDBM_File" estará presente, ya que viene con Perl.

touch_file(file, { args });
Actualiza o crea un archivo.

Posibles argumentos:

create_exclusive => 1
Crea un archivo nuevo y vacío de forma segura, solo si no existía antes

my ($filepath, $filehandle) = secure_tmpfile();
Genera un nombre de archivo para un archivo temporal, lo abre de forma exclusiva y segura, y devuelve un manejador de archivo al archivo abierto (abierto O_RDWR).

Si no puede abrir un archivo después de 20 intentos, devuelve "undef".

my ($dirpath) = secure_tmpdir();
Genera un directorio para archivos temporales. Lo crea de forma segura y devuelve la ruta al directorio.

Si no puede crear un directorio después de 20 intentos, devuelve "undef".
