NOMBRE

Mail::Box::Locker::NFS - bloquear una carpeta con un archivo separado, de forma segura para NFS

HERENCIA

Mail::Box::Locker::NFS
  es un Mail::Box::Locker
  es un Mail::Reporter

SINOPSIS

Ver Mail::Box::Locker

DESCRIPCIÓN

Como el bloqueador "::DotLock", pero de forma más segura para NFS. En NFS, la creación de un archivo no es atómica. El bloqueador "::DotLock" depende de una llamada de sistema atómica "open", por lo que no es útil para bloquear una carpeta accedida por NFS. El bloqueador "::NFS" es por tanto más complejo (por lo tanto más lento), pero funciona para NFS — y para discos locales también.

Extiende "DESCRIPCIÓN" en Mail::Box::Locker.

DIAGNÓSTICOS

Advertencia: Carpeta $folder ya bloqueada sobre NFS
No intentes bloquear la carpeta cuando el programa ya tiene el bloqueo: esto generará colisiones de bloqueo. Usa lock()
Error: Paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje indica que algunas otras clases relacionadas implementan este método, pero la clase en cuestión no. Probablemente debas investigar esto y probablemente informar al autor del paquete. Usa notImplemented()
Advertencia: Eliminado lockfile expirado $file
Se encontró un lockfile $file que es más antiguo que el período de expiración especificado con timeout. El lockfile se eliminó con éxito. Usa lock()
Error: No se pudo eliminar lockfile expirado $file: $!
Se encontró un lockfile que es más antiguo que el período de expiración especificado con timeout. No es posible eliminar este lockfile, así que debes esperar hasta que se elimine por causas externas. Usa lock()
