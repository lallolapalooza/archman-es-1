Mail::SPF(3) Documentación de Perl aportada por el usuario Mail::SPF(3)

NOMBRE

Mail::SPF - Una implementación orientada a objetos de Sender Policy Framework

VERSIÓN

versión 3.20250505

SINOPSIS

use Mail::SPF;
my $spf_server  = Mail::SPF::Server->new();
my $request     = Mail::SPF::Request->new(
    versions        => [1, 2],              # opcional
    scope           => 'mfrom',             # o 'helo', 'pra'
    identity        => 'fred@example.com',
    ip_address      => '192.168.0.1',
    helo_identity   => 'mta.example.com'    # opcional,
                                            #   para expansión de macro %{h}
);
my $result      = $spf_server->process($request);
print("$result\n");
my $result_code     = $result->code;        # 'pass', 'fail', etc.
my $local_exp       = $result->local_explanation;
my $authority_exp   = $result->authority_explanation
    if $result->is_code('fail');
my $spf_header      = $result->received_spf_header;

DESCRIPCIÓN

Mail::SPF es una implementación orientada a objetos de Sender Policy Framework (SPF). Véase https://tools.ietf.org/html/rfc7208 para más información sobre SPF.

Esta colección de clases tiene como objetivo cumplir plenamente con la especificación SPF (RFC 4408) para servir tanto como una implementación SPF de calidad de producción como una referencia para otros desarrolladores de implementaciones SPF.

VéASE TAMBIÉN

Mail::SPF::Server, Mail::SPF::Request, Mail::SPF::Result

Para disponibilidad, soporte e información de licencia, consulte el archivo README incluido con Mail::SPF.
