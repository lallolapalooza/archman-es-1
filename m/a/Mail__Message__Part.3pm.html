NAME

Mail::Message::Part - a part of a message, but a message itself

INHERITANCE

Mail::Message::Part
  is a Mail::Message
  is a Mail::Reporter

SYNOPSIS

my Mail::Message $message = ...;
if($message->isMultipart) {
   my Mail::Message::Part $part;
   foreach $part ($message->body->parts) {
      $part->print(\*OUT);
      my $attached_head = $part->head;
      my $attached_body = $part->body;      # encoded as is
      my $attached_body = $part->decoded;   # transfer-encoding removed
   }
}

DESCRIPTION

An object of "Mail::Message::Part" holds a message that is included in the body of another message. For example, attachments are parts.

The MAIL::MESSAGE FIRST. A part is a special message: it has a reference to its parent message, and is generally not sub-classed into specific mail folder variants.

DIAGNÓSTICOS

Error: No se puede incluir el origen de un mensaje reenviado como $include.
El alternativo desconocido para el modo de incluir (forward(include)). Los valores válidos son "NO", "INLINE", "ATTACH" y "ENCAPSULATE". Se castea por forward()
Error: No se puede incluir el origen de un mensaje de respuesta como $include.
El modo de incluir (include) del método reply() tiene un valor desconocido. Los valores válidos son "NO", "INLINE" y "ATTACH". Se castea por reply()
Error: El método bounce() requiere To, Cc o Bcc.
El método bounce() envía un mensaje recibido a alguien más sin modificaciones; debe especificarse su nuevo destino. Si no quieres especificar ningún destino, probablemente estés buscando el método reply(). Para modificar el contenido, usa el método forward(). Se castea por bounce()
Error: El método forwardAttach requiere un preludio.
Se castea por forwardAttach()
Error: El método forwardEncapsulate requiere un preludio.
Se castea por forwardEncapsulate()
Error: No se puede crear el destinatario de un mensaje reenviado.
Si se crea un mensaje reenviado, debe especificarse un destinatario. Se castea por forward()
Error: No se encontró un Mailer por defecto para enviar el mensaje.
El mecanismo de envío del mensaje send() no tenía suficiente información para encontrar automáticamente un agente de envío. Especifica explícitamente un Mailer usando la opción "via". Se castea por send()
Error: No se definió ninguna regla de reconstrucción $name.
Se castea por rebuild()
Error: Solo se pueden construir los mensajes con build() de Mail::Message; aún no están en una carpeta.
Podrías desear construir un mensaje para almacenarlo en algún tipo de carpeta, pero debes hacerlo en dos pasos. Primero, crea un mensaje normal de Mail::Message, y luego añádele
