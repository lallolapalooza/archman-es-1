NOMBRE

Mail::Message::Field::AddrGroup - Grupo de direcciones de correo electrónico

HERENCIA

Mail::Message::Field::AddrGroup
  es una User::Identity::Collection::Emails
  es una User::Identity::Collection
  es una User::Identity::Item

SINOPSIS

mi $g = Mail::Message::Field::AddrGroup->new(name => 'nombre');
mi $a = Mail::Message::Field::Address->new(...);
$g->addAddress($a);
mi $f = Mail::Message::Field::Addresses->new;
$f->addGroup($g);

DESCRIPCIÓN

Un grupo de direcciones de correo electrónico recoge un conjunto de direcciones de correo electrónico (en este caso, son objetos de Mail::Message::Field::Address).

Extiende "DESCRIPCIÓN" en User::Identity::Collection::Emails.

MÉTODOS

Extiende "MÉTODOS" en User::Identity::Collection::Emails.

$obj->string()
Devuelve la representación del grupo de direcciones de correo electrónico como cadena. Sin nombre, solo se devolverá una lista separada por comas de direcciones. Con un nombre, el nombre del grupo será precedido y se añadirá un punto y coma. Sin direcciones y sin nombre, se devolverá "undef".

Direcciones de correo

$obj->addAddress(STRING|$address|%options)
Añade una dirección de correo a la lista mantenida en el grupo. Este es un wrapper al método addRole() que agrega flexibilidad en cómo se especifican las direcciones. Una $address puede ser cualquier cosa aceptable para Mail::Message::Field::Address::coerce() o una lista de opciones que creará un objeto así.

Ejemplo: de añadir una dirección de correo a un grupo de direcciones de correo

mi @data = (full_name => "Myself", address => 'me@tux.org');
$group->addAddress(@data);
mi $addr = Mail::Message::Field::Address->new(@data);
$group->addAddress(@data);
mi $ma = Mail::Address->new(...);
$group->addAddress($ma);
$obj->addresses()
Devuelve todas las direcciones definidas en este grupo. Las direcciones se ordenan alfabéticamente para permitir pruebas automáticas: los roles están almacenados en un hash, por lo que el orden predeterminado es impredecible.

Ejemplo: obtener todas las direcciones de un grupo

mi @addrs = $group->addresses;
mi @addrs = map $_->address, $self->roles; # mismo

DIAGNÓSTICOS

Error: No se puede convertir un $type en un Mail::Message::Field::AddrGroup
Conversión por coerce()
Error: no se puede crear un $type para agregar este a mi colección.
Algunas opciones son especificadas para crear un $type objeto, que es nativo de esta colección. Sin embargo, por algún motivo esto falló. Conversión por addRole()
Error: no se puede cargar el módulo de colección para $type ($class): $err
El tipo especificado $type no existe o el módulo con nombre $class devuelve errores de compilación. Si el tipo especificado en el aviso no es el nombre de un paquete, se especificó un alias no definido. Tal vez olvidaste el 'require' la paquete que define el alias. Conversión por addCollection()
Error: no se puede renombrar $from a $to: ya existe.
Conversión por renameRole()
Error: no se puede renombrar $from a $to: no existe.
Conversión por renameRole()
Error: $name no es un tipo de colección válido.
La colección con nombre $name no existe y no puede ser creada. Conversión por add()
Error: este $object no es una colección.
Conversión por addCollection()
Error: tipo de colección incorrecto $name.
El tipo de colección $name es incorrecto.

DIAGNOSTICS

role for $collection: requires a $expect but got a $type.
Each $collection groups sets of roles of one specific type ($expect). You cannot add objects of a different $type. Cast by addRole()
