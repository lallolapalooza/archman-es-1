NOMBRE

Mail::SpamAssassin::Plugin::AutoLearnThreshold - discriminador basado en umbral para el auto-aprendizaje de Bayes

SINOPSIS

loadplugin     Mail::SpamAssassin::Plugin::AutoLearnThreshold

DESCRIPCIÓN

Este plugin implementa el discriminador de auto-aprendizaje basado en umbrales para el subsistema Bayes de SpamAssassin. El auto-aprendizaje es un mecanismo por el cual los correos con puntuaciones altas (o puntuaciones bajas, para correos no spam) se introducen en sus sistemas de aprendizaje sin intervención del usuario, durante el escaneo.

Tenga en cuenta que ciertas pruebas se ignoran al determinar si un mensaje debe ser entrenado:

  • reglas con tflags establecidos en 'learn' (las reglas bayesianas)
  • reglas con tflags establecidos en 'userconf' (configuración del usuario)
  • reglas con tflags establecidos en 'noautolearn'

También tenga en cuenta que el auto-aprendizaje se realiza utilizando puntuaciones del conjunto de puntuaciones 0 o 1, dependiendo de qué conjunto de puntuaciones se utilice durante la comprobación del mensaje. Es probable que las puntuaciones de comprobación del mensaje y de auto-aprendizaje sean diferentes.

AJUSTES DE USUARIO

Los siguientes ajustes de configuración se utilizan para controlar el auto-aprendizaje:

bayes_auto_learn_threshold_nonspam n.nn (por defecto: 0.1)
El umbral de puntuación por debajo del cual un correo debe puntuar para ser introducido automáticamente en los sistemas de aprendizaje de SpamAssassin como un mensaje no spam.
bayes_auto_learn_threshold_spam n.nn (por defecto: 12.0)
El umbral de puntuación por encima del cual un correo debe puntuar para ser introducido automáticamente en los sistemas de aprendizaje de SpamAssassin como un mensaje spam.

Nota: SpamAssassin requiere al menos 3 puntos del encabezado y 3 puntos del cuerpo para auto-aprender como spam. Por lo tanto, el valor mínimo de trabajo para esta opción es 6.

Si la opción de prueba "autolearn_header" o "autolearn_body" está establecida, los puntos de esa regla se fuerzan a contar como provenientes del encabezado o del cuerpo respectivamente. Esto puede ser útil para ajustar algunas meta-reglas.

Si la opción de prueba "autolearn_force" está establecida, el valor mínimo seguirá siendo 6 puntos, pero no hay requisito de que los puntos provengan de reglas de cuerpo y encabezado. Esta opción es útil para el auto-aprendizaje con reglas que se consideran indicadores extremadamente seguros de la naturaleza spam de un mensaje.

bayes_auto_learn_on_error (0 | 1) (por defecto: 0)
Con "bayes_auto_learn_on_error" desactivado, el auto-aprendizaje se realizará incluso si el clasificador bayes ya está de acuerdo con la nueva clasificación (es decir, produjo BAYES_00 para lo que ahora estamos intentando enseñar como ham, o produjo BAYES_99 para spam). Esta es una configuración tradicional, el valor por defecto fue elegido para mantener la compatibilidad con versiones anteriores.

Con "bayes_auto_learn_on_error" activado, el auto-aprendizaje se realizará solo cuando un clasificador bayes haya tenido una opinión diferente a la que el auto-aprendedor está intentando enseñar ahora (es decir, cometió un error de juicio). Esta estrategia puede o no producir mejores clasificaciones futuras, pero generalmente funciona muy bien, al tiempo que evita el sobre-aprendizaje innecesario y ralentiza el crecimiento de la base de datos.
