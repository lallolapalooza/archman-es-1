NOMBRE

Mail::SpamAssassin::RegistryBoundaries - reglas de delegación de dominio

MÉTODOS

($hostname, $domain) = split_domain ($fqdn, $is_ascii)
Divide un nombre de host completamente calificado en la parte del nombre de host y la parte del dominio, dividiendo en el límite del registro de DNS.

Ejemplos:

"www.foo.com" => ( "www", "foo.com" )
"www.foo.co.uk" => ( "www", "foo.co.uk" )

Si se proporciona $is_ascii y es verdadero, omite la conversión idn_to_ascii()

$domain = trim_domain($fqdn, $is_ascii)
Divide un nombre de host completamente calificado en la parte del nombre de host y la parte del dominio, devolviendo solo el dominio.

Ejemplos:

"www.foo.com" => "foo.com"
"www.foo.co.uk" => "foo.co.uk"

Si se proporciona $is_ascii y es verdadero, omite la conversión idn_to_ascii()

$ok = is_domain_valid($dom, $is_ascii)
Devuelve 1 si el dominio/nombre de host utiliza un TLD conocido válido, "undef" de lo contrario.

Si se proporciona $is_ascii y es verdadero, omite la conversión idn_to_ascii().

Tenga en cuenta que esto solo verifica la validez del TLD y nada más. Para verificar que el nombre de host completo (fqdn) tiene un formato legal válido, se puede usar adicionalmente Util::is_fqdn_valid().
