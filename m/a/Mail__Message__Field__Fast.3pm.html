NOMBRE

Mail::Message::Field::Fast - una línea de una cabecera de mensaje

HERENCIA

  es un Mail::Message::Field
  es un Mail::Reporter

DESCRIPCION

Esta es la implementación más rápida, pero menos flexible, de un campo de cabecera. Los datos se almacenan en un array y se realizan algunos trucos para acelerar las cosas. Sé amable conmigo y ten en cuenta que cada mensaje contiene muchas de estas líneas, por lo que la velocidad es muy importante aquí.

$class->new(($line | $name, $body, [$attributes]), %options)
El constructor de este objeto no sigue la práctica habitual dentro de la suite Mail::Box: no utiliza el constructor Mail::Reporter::new(). Por lo tanto, no tiene facilidades de registro ni de seguimiento.

El método puede usarse de una de las siguientes maneras:

  • new($line, %options)

    Pasa una $line tal como podría encontrarse en un archivo: una línea (posiblemente plegada) que termina con un salto de línea.

  • new($name, $body, [$attributes], %options)

    Un conjunto de valores que dan forma a la línea.

Crea un nuevo objeto de campo de cabecera. Especifica toda la $line (octetos codificados) a la vez, y se dividirá por ti. En caso de que ya tengas las partes de la línea de cabecera, puedes especificarlas por separado como $name y el cuerpo del campo $body.

En caso de que especifiques un único objeto $body, o un ARRAY de objetos, estos se procesan para que sean adecuados para llenar un campo, generalmente mediante una simple conversión a cadena. Cuando especificas uno o más objetos Mail::Address, estos se transforman en una cadena usando su método "format". También puedes agregar un Mail::Message::Field, cuyo cuerpo se toma. En caso de un array, los elementos se unen en una sola cadena con una coma.

El $attributes puede ser exactamente una cadena que contenga múltiples atributos a la vez, entre comillas y formateados según lo requerido en RFC2822. Como alternativa, se pueden usar listas de pares clave-valor. En este caso, los valores se pondrán entre comillas si es necesario y todo se formateará según lo exige el protocolo. Mail::Message::Field::Fast 3.019 man page

NAME

Mail::Message::Field::Fast - campos de encabezado rápido para mensajes de correo electrónico

HERENCIA

Mail::Message::Field::Fast hereda de Mail::Message::Field.

Mail::Message::Field::Fast es implementado en la clase Mail::Message.

Mail::Message::Field::Fast es analizado por Mail::Message.

Mail::Message::Field::Fast hereda de Mail::Reporter.

SINOPSIS

  use Mail::Message::Field::Fast;

  my $obj = Mail::Message::Field::Fast->new($name, $value);
  $obj->parse($string);

  # Propiedades
  $obj->name;
  $obj->value;

  # Acceso al contenido
  $obj->attributes;
  $obj->comment;
  $obj->study;
  $any->toDate( [$time] );
  $obj->toInt;

  # Otros métodos
  $any->dateToTimestamp(STRING);

  # Internos
  $obj->consume( $line | <$name,<$body|$objects> );
  $obj->defaultWrapLength( [$length] );
  $any->fold( $name, $body, [$maxchars] );
  $obj->setWrapLength( [$length] );
  $obj->stringifyData(STRING|ARRAY|$objects);
  $obj->unfold(STRING);

  # Manejo de errores
  $obj->AUTOLOAD;
  $obj->addReport($object);
  $any->defaultTrace( [$level]|[$loglevel, $tracelevel]|[$level, $callback] );
  $obj->errors;
  $any->log( [$level, [$strings]] );
  $any->logPriority($level);
  $obj->notImplemented;
  $obj->report( [$level] );
  $obj->reportAll( [$level] );
  $obj->trace( [$level] );
  $obj->warnings;

  # Limpieza
  $obj->DESTROY;

DESCRIPCIÓN

Este módulo implementa el contenido de los campos de encabezado de un mensaje. La mayoría de los campos de encabezado no tienen una estructura específica, por lo que se representan como un nombre y un valor simple. Los campos más comunes, como 'From', 'To', 'Subject', se gestionan en clases hijas más específicas.

Este módulo se enfoca en la velocidad y evita la sobrecarga de las clases hijas cuando sea posible. Las clases hijas se utilizan solo cuando la estructura del campo de encabezado se conoce y se puede interpretar de forma más útil.

La información sobre el campo se almacena como una cadena de texto. Esto significa que la mayoría de las operaciones de acceso son simplemente accesos a esta cadena.

DIAGNÓSTICOS

Alerta: El contenido del campo $content no es numérico
Se requiere el valor numérico de un campo (por ejemplo, el valor numérico de los campos "Lines" o "Content-Length"), pero el dato contiene caracteres extraños. Casted por toInt()
Error: El nombre del campo $name es demasiado largo (máximo $length)
El RFC no especifica cuánto puede ser largo el nombre de un campo, pero al menos debería ser un poco más corto que el límite de línea. Casted por fold()
Alerta: Carácter inválido en el nombre del campo $name
Se está creando un nuevo campo que contiene caracteres no permitidos por los RFC. Usar este campo en mensajes puede romper otros clientes de correo o transfer agents, y por lo tanto, modificar o extinguir tu mensaje. Casted por consume()
Error: El paquete $package no implementa $method.
Error grave: el paquete específico (o uno de sus superclases) no implementa esta método donde debería. Esta mensaje significa que otros clases relacionadas implementan esta método pero la clase en cuestión no. Probablemente deberías investigar esto y probablemente informar al autor del paquete. Casted por notImplemented()
