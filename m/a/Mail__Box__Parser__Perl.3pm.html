NOMBRE

Mail::Box::Parser::Perl - lectura de mensajes desde un archivo usando Perl

HERENCIA

Mail::Box::Parser::Perl
  es un Mail::Box::Parser
  es un Mail::Reporter

SINOPSIS

DESCRIPCIÓN

El "Mail::Box::Parser::Perl" implementa el análisis de mensajes en Perl. Esto puede ser un poco más lento que el analizador basado en "C" Mail::Box::Parser::C, pero también funcionará en plataformas donde no hay compilador C disponible.

DIAGNÓSTICOS

Advertencia: El archivo $file cambió durante el acceso.
Cuando un analizador de mensajes comienza a trabajar, toma el tamaño y la hora de modificación del archivo en cuestión. Si la carpeta se escribe, verifica si hubo cambios en el archivo realizados por programas externos.

Llamar a Mail::Box::update() en una carpeta antes de cerrarla leerá estos nuevos mensajes. Pero la verdadera fuente de este problema es el bloqueo: algún programa externo (por ejemplo, el agente de transferencia de correo, como sendmail) usa un mecanismo de bloqueo diferente al tuyo y, por lo tanto, viola tus derechos. Lanzado por stop()

Mail::Box::Parser::Perl(3pm)

NAME

Mail::Box::Parser::Perl - The Perl implementation of the message parser

INHERITANCE

This module is part of the Mail::Box distribution.

Mail::Box::Parser

.

Mail::Box::Parser::Perl

SYNOPSIS

    use Mail::Box::Parser::Perl;
    my $parser = Mail::Box::Parser::Perl->new(%args);
    my $message = $parser->parse($stream);

DESCRIPTION

This is the default implementation for parsing messages. It reads message lines from a stream until it reaches the end of the message. The message is then constructed by the abstract Mail::Message class.

The implementation is a simple state-machine that reads header and body lines. It follows the RFC specifications for message structure.

You normally do not need to include this file explicitly. The Mail::Box module will select and load this parser implementation for you.

METHODS

new()
The constructor accepts the same arguments as the abstract Mail::Box::Parser class.
parse($stream)
Read the message from the given $stream. The stream must support the standard Perl I/O methods like read, eof, and close.

Returns a Mail::Message object with the parsed contents.

The parser returns undef when the end-of-file is reached before any content was read.

DIAGNOSTICS

Warning: The method $method is not implemented
A method from the abstract base class was called which is not implemented in this concrete implementation. Some related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
Warning: Unknown header field: $name
The parser found a header line which it does not understand. It will be added to the message object as is. Cast by addHeader()
Warning: Unexpected end of header in $source: $line
While parsing a message from the specified source (usually a file name), the parser found a syntax error. According to the MIME specification in the RFCs, each header line must either contain a colon, or start with a blank to indicate a folded field. Apparently, this header contains a line which starts on the first position, but not with a field name.

By default, parsing of the header will be stopped. If there are more header lines after the erroneous line, they will be added to the body of the message. In case of new(fix_header_errors) set, the parsing of the header will be continued. The erroneous line will be added to the preceding field. Cast by readHeader()
