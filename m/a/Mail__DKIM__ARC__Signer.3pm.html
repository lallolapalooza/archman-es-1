NOMBRE

Mail::DKIM::ARC::Signer - genera una firma DKIM para un mensaje

VERSIÓN

versión 1.20240923

SINOPSIS

use Mail::DKIM::ARC::Signer;
use Mail::DKIM::TextWrap;  #recomendado
# crear un objeto de firma
my $signer = Mail::DKIM::ARC::Signer->new(
                Algorithm => 'rsa-sha256',
                Chain => 'none',    # o pass|fail|ar
                Domain => 'example.org',
                SrvId => 'example.org',
                Selector => 'selector1',
                KeyFile => 'private.key',
                Headers => 'x-header:x-header2',
           );
# leer un email de un manejador de archivo
$signer->load(*STDIN);
# NOTA: cualquier email que se firme con ARC debe tener una cabecera Authentication-Results
# para que el sello ARC pueda cubrir los resultados copiados en
# una cabecera ARC-Authentication-Results.
# o leer un email y pasarlo al firmante, una línea a la vez
while (<STDIN>)
{
    # eliminar terminadores de línea locales
    chomp;
    s/\015$//;
    # usar terminadores de línea SMTP
    $signer->PRINT("$_\015\012");
}
$signer->CLOSE;
die 'Fallo' $signer->result_detail() unless $signer->result() eq 'sealed';
# Obtener todas las cabeceras de firma para anteponer al mensaje
# ARC-Seal, ARC-Message-Signature y ARC-Authentication-Results
# en ese orden.
print $signer->as_string;

DESCRIPCIÓN

Esta clase es la parte de Mail::DKIM responsable de generar Sellos ARC para un mensaje dado. Creas un objeto de esta clase, especificando los parámetros para la firma ARC-Message-Signature que deseas crear.

También debes pasar el valor 'Chain' (pass o fail) de la validación de los sellos ARC anteriores en el mensaje.

A continuación, le pasas el mensaje completo usando "PRINT()", completando con "CLOSE()".

Finalmente, utiliza el método "as_string()" para obtener las cabeceras ARC nuevas.

Nota: solo puedes sellar un mensaje al que ya se le haya agregado una cabecera Authentication-Results, ya sea usando "PRINT()" para alimentarla previamente a este módulo, o agregando un mensaje que ya haya sido autenticado por tus mecanismos de escaneo de entrada.

No es necesario firmar con ARC un mensaje que ya tenga firmas DKIM si no estás modificando el mensaje y, por lo tanto, rompiendo la firma DKIM existente o la firma ARC-Message-Signature superior del correo.

Firmas Bonitas

Mail::DKIM incluye un módulo de envoltura de firmas (que inserta saltos de línea en la firma generada para que se vea más bonita en el mensaje resultante. Para habilitar este módulo, simplemente llama a

use Mail::DKIM::TextWrap;

en tu programa antes de generar la firma.

CONSTRUCTOR

new()

Construye un firmante orientado a objetos.

# crear un firmante usando la política por defecto
my $signer = Mail::DKIM::ARC::Signer->new(
                Algorithm => 'rsa-sha256',
                Chain => 'none',    # o pass|fail|ar
                Domain => 'example.org',
                SrvId => 'example.org',
                Selector => 'selector1',
                KeyFile => 'private.key',
                Headers => 'x-header:x-header2',
           );
Clave
en lugar de usar "KeyFile", usa "Key" para usar un objeto Mail::DKIM::PrivateKey ya cargado.
Cadena
El valor cv= para la cabecera Arc-Seal. "ar" significa copiarla de una cabecera Authentication-Results, o usar none si no hay una.
SrvId
El authserv-id en las cabeceras Authentication-Results, por defecto es Domain.
Cabeceras
Una lista separada por dos puntos de las cabeceras a firmar, esto se agrega a la lista de cabeceras por defecto como se muestra en la especificación DKIM.

Para cada cabecera especificada, se firmarán todas las cabeceras de ese tipo presentes en el mensaje, pero no firmaremos en exceso ni firmaremos cabeceras que no estén presentes.

Si requiere un mayor control sobre las cabeceras firmadas, por favor use el método extended_headers() en su lugar.

La lista de cabeceras firmadas por defecto es la siguiente:

From Sender Reply-To Subject Date
Message-ID To Cc MIME-Version
Content-Type Content-Transfer-Encoding Content-ID Content-Description
Resent-Date Resent-From Resent-Sender Resent-To Resent-cc
Resent-Message-ID
In-Reply-To References
List-Id List-Help List-Unsubscribe List-Subscribe
List-Post List-Owner List-Archive
Etiquetas
Un hashref opcional de etiquetas adicionales para agregar a la firma ARC generada.
SealEtiquetas
Un hashref opcional de etiquetas adicionales para agregar al sello ARC generado.

MÉTODOS

PRINT()

Alimenta parte del mensaje al firmante.

$signer->PRINT("una línea del mensaje\015\012");

Alimenta el contenido del mensaje que se está firmando al firmante. La API está diseñada de esta manera para que el mensaje completo NO necesite ser leído en memoria de una vez.

Tenga en cuenta que aunque el método PRINT() espera que usted use caracteres de terminación de línea estilo SMTP, NO debe usar la técnica de "dot-stuffing" estilo SMTP descrita en la RFC 2821, sección 4.5.2. Tampoco debe usar una secuencia <CR><LF>.<CR><LF> para terminar el mensaje.

CLOSE()

Llámalo cuando hayas terminado de alimentar el mensaje.

$signer->CLOSE;

Este método finaliza el proceso de canonicalización, calcula un hash y genera una firma.

extended_headers()

Este método anula las cabeceras a firmar y permite un mayor control que el posible con la propiedad Headers en el constructor.

El método espera que se le pase un HashRef.

Las claves son las cabeceras a firmar, y los valores son el número de cabeceras de ese tipo a firmar, o los valores especiales '*' y '+'.

* firmará TODAS las cabeceras de ese tipo presentes en el mensaje.

+ firmará TODAS las cabeceras de ese tipo presentes en el mensaje más 1 para evitar que se agreguen cabeceras adicionales.

Puedes anular cualquiera de las cabeceras por defecto incluyéndolas en el hashref, y deshabilitarlas asignándoles un valor 0.

Las claves no distinguen entre mayúsculas y minúsculas, y los valores se acumulan hasta el valor más alto.

Headers => {
    'X-test'  => '*',
    'x-test'  => '1',
    'Subject' => '+',
    'Sender'  => 0,
},

add_signature()

Usado por la política del firmante para crear una nueva firma.

$signer->add_signature(new Mail::DKIM::Signature(...));

Las políticas de firma pueden usar este método para especificar parámetros completos para la firma a agregar, incluyendo el tipo de firma. Para más información, ver Mail::DKIM::SignerPolicy.

algorithm()

Obtiene o establece el algoritmo seleccionado.

$alg = $signer->algorithm;
$signer->algorithm('rsa-sha256');

domain()

Obtiene o establece el dominio seleccionado.

$alg = $signer->domain;
$signer->domain('example.org');

load()

Carga el mensaje completo desde un manejador de archivo.

$signer->load($file_handle);

Lee un mensaje completo del manejador de archivo designado, alimentándolo al firmante. El mensaje debe usar terminadores de línea <CRLF> (igual que el protocolo SMTP).

headers()

Determina qué cabeceras incluir en la firma.

my $headers = $signer->headers;

Esta es una cadena que contiene los nombres de los campos de cabecera que serán firmados, separados por dos puntos.

NAME

Mail::DKIM::ARC::Signer - sign and verify ARC signatures

VERSION

1.20240923

SYNOPSIS

  use Mail::DKIM::ARC::Signer;
  use Mail::Address;

  my $signer = Mail::DKIM::ARC::Signer->new(
      domain    => 'example.com',
      selector  => 'key1',
      key_file  => 'private.key',
  );

  $signer->add_message_header('Subject: Hello');
  $signer->add_message_header('From: sender@example.com');

  # ARC-Message-Signature header field
  $signer->sign_message;

  # ARC-Authentication-Results header field
  # The results are from a verification step, not generation.
  # If you need to generate this, you need to use Mail::DKIM::ARC::Verifier
  # $signer->arc_auth_results;

  my $signed_message = $signer->as_string;

DESCRIPTION

This class implements ARC (Authenticated Received Chain) signing, as described in RFC 8617.

ARC provides a way for intermediaries (like mailing lists, forwarders, or spam filters) to add their own cryptographic signature to a message, indicating that they have seen it and are passing it along. This allows the final recipient to verify that the message wasn't altered in transit by such intermediaries, and also helps to identify the origin of the message more reliably, especially when DKIM signatures are re-created by intermediaries.

This module supports ARC signing and verification. It may be used to add ARC signatures to outgoing messages, or to verify incoming ARC signatures.

Note that ARC signatures are always appended to the message, and are never placed in the body. They are stored in specially formatted header fields.

See Mail::DKIM::ARC::Verifier for verification details.

CONSTRUCTOR

new()

Creates a new Mail::DKIM::ARC::Signer object.

  my $signer = Mail::DKIM::ARC::Signer->new(
      domain    => 'example.com', # Required
      selector  => 'key1',        # Required
      key_file  => 'private.key', # Required, unless key is set
      key       => $private_key_object, # Required, unless key_file is set
      # The following parameters are optional:
      algorithm => 'rsa-sha256', # Defaults to 'rsa-sha256'
      # The following parameters are only for ARC signing:
      instance  => '1',           # Defaults to '1'
      body_hash => 'N',           # Defaults to 'N' (no body hash)
      # The following parameters are only for ARC verification:
      # report_output_type => 'a' # Defaults to 'a' (arc-seal)
      # query_method       => 'd' # Defaults to 'd' (dns)
  );

The following parameters are required:

domain
The domain name to be included in the ARC signature.
selector
The selector to be used for the ARC signature. This is used in conjunction with the domain to form the DNS lookup name for the public key.
key_file
The path to the file containing the private key. This key is used to sign the ARC signature.
key
A private key object. This object must support the sign_digest() method. This is an alternative to specifying key_file.

The following parameters are optional:

algorithm
The signing algorithm to use. Defaults to 'rsa-sha256'. Other supported algorithms include 'rsa-sha1' (discouraged).
instance
The ARC instance identifier. Defaults to '1'. This is used to differentiate multiple ARC signatures in a chain.
body_hash
Specifies whether to include a hash of the message body in the signature. Valid values are 'Y' (include hash) and 'N' (do not include hash). Defaults to 'N'.

The following parameters are used for verification (see Mail::DKIM::ARC::Verifier):

report_output_type
Specifies the type of ARC report to generate. Defaults to 'a' (ARC-Seal).
query_method
Specifies the method for querying the public key. Defaults to 'd' (DNS).

You must provide either key_file or key.

METHODS

add_message_header()

Add a header field from the original message to the list of headers to be signed.

my $signer = Mail::DKIM::ARC::Signer->new(...);
$signer->add_message_header('Subject: Hello World');
$signer->add_message_header('From: sender@example.com');

This method is used to record the headers that will be included in the ARC signature. The header field name and value are passed as a single string, as they appear in the message.

The method automatically handles multi-line headers by folding them into a single line. It also handles repeated header fields correctly.

For ARC signing, this method is used to record the headers that were present in the message *before* the ARC signature was added. This is important because the ARC signature needs to be based on the message as it was seen by the signing intermediary.

You can call this method multiple times to add multiple headers.

add_header()

Add a header field to the list of headers to be signed.

my $signer = Mail::DKIM::ARC::Signer->new(...);
$signer->add_header('Subject: Hello World');
$signer->add_header('From: sender@example.com');

This method is similar to "add_message_header()", but it does not assume that the header field was part of the original message. This is useful when signing headers that have been added or modified by the signing process itself.

For ARC signing, this method is typically used to add the ARC-Seal or ARC-Message-Signature header fields that are being generated.

arc_auth_results()

Generate an ARC-Authentication-Results header field.

my $auth_results_header = $signer->arc_auth_results;

This method is used to generate the ARC-Authentication-Results header field, which contains the results of verifying ARC signatures in the message. This method is typically called by a verifier, not a signer.

It returns the header field as a string, suitable for injection into the message.

instance()

Get or set the current ARC instance identifier.

my $instance = $signer->instance;
$signer->instance('2');

body_hash()

Get or set whether to include a hash of the message body in the signature.

my $hash_flag = $signer->body_hash;
$signer->body_hash('Y');

Valid values are 'Y' (include hash) and 'N' (do not include hash).

key()

Get or set the private key object.

my $key = $signer->key;
$signer->key(Mail::DKIM::PrivateKey->load(File => 'private.key'));

The key object can be any object that implements the sign_digest() method. (Providing your own object can be useful if your actual keys are stored out-of-process.)

If you use this method to specify a private key, do not use "key_file()".

key_file()

Get or set the filename containing the private key.

my $filename = $signer->key_file;
$signer->key_file('private.key');

If you use this method to specify a private key file, do not use "key()".

message_originator()

Access the "From" header.

my $address = $signer->message_originator;

Returns the "originator address" found in the message, as a Mail::Address object. This is typically the (first) name and email address found in the From: header. If there is no From: header, then an empty Mail::Address object is returned.

To get just the email address part, do:

my $email = $signer->message_originator->address;

See also "message_sender()".

message_sender()

Access the "From" or "Sender" header.

my $address = $dkim->message_sender;

Returns the "sender" found in the message, as a Mail::Address object. This is typically the (first) name and email address found in the Sender: header. If there is no Sender: header, it is the first name and email address in the From: header. If neither header is present, then an empty Mail::Address object is returned.

To get just the email address part, do:

my $email = $dkim->message_sender->address;

The "sender" is the mailbox of the agent responsible for the actual transmission of the message. For example, if a secretary were to send a message for another person, the "sender" would be the secretary and the "originator" would be the actual author.

selector()

Get or set the current key selector.

$alg = $dkim->selector;
$dkim->selector('alpha');

signatures()

Access list of generated signature objects.

my @signatures = $dkim->signatures;

Returns all generated signatures, as a list.

as_string()

Returns the new ARC headers

my $pre_headers = $signer->as_string();

The headers are separated by \015\012 (SMTP line separator) including a trailing separator, so can be directly injected in front of the raw message.

as_strings()

Returns the new ARC headers

my @pre_headers = $signer->as_string();

The headers are returned as a list so you can add whatever line ending your local MTA prefers.
