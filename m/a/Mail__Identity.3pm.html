NAME

Mail::Identity - un rol de correo electrónico

INHERITANCE

Mail::Identity
  hereda User::Identity::Item

SYNOPSIS

use User::Identity;
use Mail::Identity;
my $me   = User::Identity->new(...);
my $addr = Mail::Identity->new(address => 'x@y');
$me->add(email => $addr);
# Simplificado
use User::Identity;
my $me   = User::Identity->new(...);
my $addr = $me->add(email => 'x@y');
my $addr = $me->add(email => 'home', address => 'x@y');
# Conversión
my $ma   = Mail::Address->new(...);
my $mi   = Mail::Identity->coerce($ma);

DESCRIPTION

El objeto "Mail::Identity" contiene la descripción del rol que juega una persona cuando envía correo electrónico. La mayoría de las personas tienen más de un rol hoy en día: por ejemplo, un rol privado y uno de empresa con diferentes direcciones de correo.

Un objeto "Mail::Identity" combina una dirección de correo electrónico, una descripción del usuario (una "frase"), una firma, una clave PGP, y otros. Todos los campos son opcionales, y algunos son inteligentes. Un conjunto de datos así representa un rol. "Mail::Identity" es por lo tanto el hermano inteligente del objeto "Mail::Address".

Attributes

Hereda "Attributes" de User::Identity::Item.

$obj->address()
Devuelve la dirección de correo para este rol. Si no se especifica, se construye a partir del usuario y dominio. Si estos no están definidos, se utiliza el name() si contiene un "@", de lo contrario se toma el nickname del usuario.
$obj->charset()
Devuelve el conjunto de caracteres usado en el comentario y la phrase. Cuando se establece a "undef", los strings (ya codificados a) contienen solo caracteres ASCII. Este predomina sobre el valor del charset del usuario, si está definido.
$obj->comment( [STRING] )
La dirección de correo - cuando se incluye en cabeceras MIME de mensaje - puede contener un comentario. Las RFCs advierten no almacenar información útil en estos comentarios, pero si quieres, puedes hacerlo. El comentario por defecto es el fullname del usuario si la phrase no es el fullname y hay un usuario definido.

Los comentarios se encierran entre paréntesis cuando se usan. Los paréntesis (coincidentes o no) que ya estén en la cadena se escaparán cuidadosamente cuando sea necesario. No tienes que preocuparte.

$obj->description()
Inerente, ver "Attributes" en User::Identity::Item
$obj->domain()
El dominio es la parte de la dirección de correo después del signo "@". Cuando no está definido, puede deducirse de la dirección de correo (ver address()). Si nada se conoce, se devuelve "localhost".
$obj->language()
Devuelve el idioma usado para los campos de descripción de esta dirección de correo, que predomina sobre el idioma del usuario.
$obj->location()
Devuelve el objeto que describe a qué lugar corresponde esta dirección de correo. El lugar puede usarse para encontrar el nombre de la organización involucrada, o para crear una firma. Si no se especifica un lugar, pero hay un usuario definido con lugares, se elige uno de ellos al azar.
$obj->name( [$newname] )
Inerente, ver "Attributes" en User::Identity::Item
$obj->organization()
Devuelve la organización que está relacionada con esta identidad de correo. Si no se especifica explícitamente, se intenta encontrar a través del lugar.
$obj->phrase()
La frase se usa en una dirección de correo para explicar quién envía el mensaje. Esto suele ser el fullname (el fullname del usuario se usa por defecto), una descripción de tu rol (Webmaster), o cualquier texto adicional.

Cuando se genera una cadena de correo, la frase se cita si es necesario. Los códigos de comillas que están dentro de la cadena se escaparán automáticamente, por lo que no tienes que preocuparte: ¡la entrada no puede romper la salida!

$obj->username()
Devuelve el nombre de usuario de esta dirección de correo. Si no se especifica, se intenta extraer de la dirección de correo especificada. Si tampoco hay nombre en la dirección de correo, se toma el nickname del usuario identity.
