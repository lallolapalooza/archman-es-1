Mail::SpamAssassin::BayesStore::BDB - Implementación de Almacenamiento Bayesiano con BerkeleyDB

DESCRIPCIÓN

Este módulo implementa un módulo de almacenamiento bayesiano basado en BDB.

get_storage_variables

instancia pública (@) get_storage_variables ()

Descripción: Este método recupera las diversas variables administrativas utilizadas por el proceso Bayes y la base de datos.

Los valores devueltos en el array están en el siguiente orden:

0: contador de escaneo base

1: número de spam

2: número de ham

3: número de tokens en la base de datos

4: último `atime` de expiración

5: `atime` del token más antiguo en la base de datos

6: valor de la versión de la base de datos

7: última sincronización del diario

8: último delta `atime`

9: último recuento de reducción de expiración

10: `atime` del token más reciente en la base de datos

NOMBRE

Mail::SpamAssassin::BayesStore::BDB

DESCRIPCIÓN

Este módulo proporciona un almacenamiento de bayes basado en BDB (Berkeley DB), utilizado para la detección de spam en mensajes electrónicos.

MÉTODOS

Las siguientes son las funciones disponibles:

nspam_nham_get

instancia pública ($spam_count, $ham_count)

Este método recupera el número total de spam y el número total de ham aprendidos.

nspam_nham_change

instancia pública (Booleano) nspam_nham_change (Entero $num_spam, Entero $num_ham)

Este método actualiza el número de spam y el número de ham en la base de datos.

tok_touch

instancia pública (Booleano) tok_touch (Cadena $token, Cadena $atime)

Este método actualiza la fecha de modificación (atime) de los tokens dados ($token).

Se asume que el token ya existe en la base de datos.

No se actualizarán las atime para versiones antiguas.

tok_touch_all

instancia pública (Booleano) tok_touch (\@ $tokens, Cadena $atime)

Este método realiza una actualización masiva de los tokens dados ($tokens), si la atime existente es menor que ($atime).

Se asume que los tokens ya existen en la base de datos.

Se recomienda no tocar más de N_SIGNIFICANT_TOKENS, por lo que se pueden hacer suposiciones sobre cómo manejar los datos (sin necesidad de batch, como en tok_get_all).

cleanup

instancia pública (Booleano) cleanup ()

Este método realiza cualquier limpieza necesaria antes de realizar la siguiente operación.

get_magic_re

instancia pública (Cadena) get_magic_re ()

Este método devuelve un patrón de regular expresión que indica un token mágico.

No se utiliza en la implementación de BDB.

sync

instancia pública (Booleano) sync (\% $opts)

Este método realiza una sincronización de la base de datos.

perform_upgrade

instancia pública (Booleano) perform_upgrade (\% $opts);

Este método realiza una actualización de la base de datos de una versión a otra, no utilizado en esta implementación.

clear_database

instancia pública (Booleano) clear_database ()

Este método elimina todas las entradas para un usuario específico.

Los llamadores deben tener en cuenta que cualquier error devuelto por este método podría causar la inconsistencia del base de datos para el usuario dado.

backup_database

instancia pública (Booleano) backup_database ()

Este método realiza una copia de seguridad del base de datos en formato legible para el sistema.

restore_database

instancia pública (Booleano) restore_database (Cadena $filename, Booleano $showdots)

Este método restaura el base de datos desde el archivo dado ($filename).

Los llamadores deben tener en cuenta que cualquier error devuelto por este método podría causar la inconsistencia del base de datos para el usuario dado.

db_readable

instancia pública (Booleano) db_readable()

Este método devuelve un valor booleano indicando si el base de datos está en un estado leído.

db_writable

instancia pública (Booleano) db_writable()

Este método devuelve un valor booleano indicando si el base de datos está en un estado escribible.

_extract_atime

instancia privada () _extract_atime (Cadena $token, Cadena $value, Cadena $index)

Este método asegura que la conexión a la base de datos esté correctamente configurada y trabajando. Si lo hace adecuadamente, inicializará las variables de bayes del usuario para que puedan comenzar a usar la base de datos inmediatamente.
