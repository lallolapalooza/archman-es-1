NOMBRE

Mail::Cap - entender los archivos mailcap

SINOPSIS

my $mc   = Mail::Cap->new;
my $desc = $mc->description('image/gif');
print "GIF desc: $desc\n";
my $cmd  = $mc->viewCmd('text/plain; charset=iso-8859-1', 'file.txt');

DESCRIPCIÓN

Analiza archivos mailcap según se especifica en "RFC 1524 --A User Agent Configuration Mechanism For Multimedia Mail Format Information>. En la descripción a continuación $type se refiere al tipo MIME especificado en el encabezado "Content-Type" de los correos o mensajes HTTP. Ejemplos de tipos son:

image/gif
text/html
text/plain; charset=iso-8859-1

También podría echar un vistazo a la distribución File::MimeInfo, que accede a tablas utilizadas por muchas aplicaciones en un sistema y, por lo tanto, ha superado las especificaciones de mail-cap en los sistemas modernos (UNIX).

MÉTODOS

Constructores

Mail::Cap->new(%options)
Crea e inicializa un nuevo objeto Mail::Cap. Si le proporciona un argumento, intentará analizar el archivo especificado. Sin ningún argumento, buscará el archivo mailcap utilizando la ruta estándar de mailcap, o la variable de entorno MAILCAPS si está definida. 
-Option  --Default
 filename  undef
 take      'FIRST'
filename => NOMBRE_ARCHIVO
Agrega el archivo especificado a la lista de ubicaciones estándar. Este archivo se intenta primero.
take => 'ALL'|'FIRST'
Incluye todos los archivos mailcap que puedas encontrar. Por defecto, solo se analiza el primer archivo, sin embargo, la RFC nos dice que incluyamos TODOS. Para mantener la compatibilidad con versiones anteriores, el valor predeterminado solo toma el PRIMERO.

ejemplo:

$mcap = new Mail::Cap;
$mcap = new Mail::Cap "/mydir/mailcap";
$mcap = new Mail::Cap filename => "/mydir/mailcap";
$mcap = new Mail::Cap take => 'ALL';
$mcap = Mail::Cap->new(take => 'ALL');

Ejecutar comandos

Estos métodos invocan un programa adecuado que presenta o manipula el objeto multimedia en el archivo especificado. Todos devuelven 1 si se encontró un comando y 0 en caso contrario. Podría probar $? para conocer el resultado del comando.

$obj->compose($type, $file)
$obj->edit($type, $file)
$obj->print($type, $file)
$obj->view($type, $file)

Creador de comandos

Estos métodos devuelven una cadena que es adecuada para pasar a system() con el fin de invocar un programa adecuado que presente o manipule el objeto multimedia en el archivo especificado. Devolverá "undef" si no existe una especificación adecuada.

$obj->composeCmd($type, $file)
$obj->editCmd($type, $file)
$obj->printCmd($type, $file)
$obj->viewCmd($type, $file)

Búsqueda de definiciones

Los métodos devuelven el campo mailcap correspondiente al tipo.

$obj->description($type)
$obj->field($type, $field)
Devuelve el campo especificado para el tipo. Devuelve undef si no existe ninguna especificación.
$obj->nametemplate($type)
$obj->textualnewlines($type)
$obj->x11_bitmap($type)
