NOMBRE

Mail::SPF::v2::Record - Clase de registro Sender ID ("spf2.0")

VERSIÓN

versión 3.20250505

SINOPSIS

Ver Mail::SPF::Record.

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::v2::Record representa un registro Sender ID ("spf2.0").

Constructores

Se proporcionan los siguientes constructores:

new(%options): devuelve Mail::SPF::v2::Record
Crea un nuevo objeto de registro Sender ID ("spf2.0").

%options es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

text
terms
global_mods
Ver "new" en Mail::SPF::Record.
scopes
Requerido. Ver "new" en Mail::SPF::Record. Se soportan los ámbitos 'mfrom' y 'pra'. No hay un valor predeterminado.
new_from_string($text, %options): devuelve Mail::SPF::v2::Record; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidRecordVersion, Mail::SPF::ESyntaxError
Crea un nuevo objeto de registro Sender ID ("spf2.0") analizando la cadena y las opciones proporcionadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

version_tag_pattern: devuelve Regexp
Devuelve una expresión regular que coincide con una etiqueta de versión de 'spf2.0/' más una lista separada por comas de cualquiera de los ámbitos 'mfrom' y 'pra'. Las siguientes son etiquetas de versión válidas: 
spf2.0/mfrom
spf2.0/pra
spf2.0/mfrom,pra
spf2.0/pra,mfrom
default_qualifier
results_by_qualifier
Ver "Métodos de clase" en Mail::SPF::Record.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

text
scopes
terms
global_mods
global_mod
stringify
eval
Ver "Métodos de instancia" en Mail::SPF::Record.
version_tag: devuelve string
Devuelve 'spf2.0/' más una lista separada por comas de los ámbitos del registro. Ver "version_tag_pattern" para una lista de posibles valores de retorno.
