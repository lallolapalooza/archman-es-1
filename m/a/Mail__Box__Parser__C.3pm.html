Mail::Box::Parser::C - Analizadores de carpetas para MailBox con rutinas en C

HERENCIA

Mail::Box::Parser::C
  es un Mail::Box::Parser
  es un Mail::Reporter
Mail::Box::Parser::C
  es un DynaLoader

SINOPSIS

DESCRIPCIÓN

Mail::Box::Parser::C implementa el análisis de mensajes en ANSI C, usando la instalación de extensiones XS de Perl.

Este es un módulo opcional para MailBox, y (una vez instalado) será utilizado automáticamente por MailBox para analizar el contenido de mensajes de correo electrónico cuando el mensaje se proporciona como un manejador de archivo. En todos los demás casos, MailBox utilizará Mail::Box::Parser::Perl.

Esta es una versión de mantenimiento de la interfaz antigua. Lea https://github.com/markov2/perl5-Mail-Box/wiki/ cómo moverse hacia la versión 4.

Advertencia: Archivo $file cambió durante el acceso.
Cuando un analizador de mensajes comienza a trabajar, toma el tamaño y la hora de modificación del archivo en cuestión. Si la carpeta se escribe, verifica si hubo cambios en el archivo realizados por programas externos.

Mail::Box::Parser::C(3pm)

NAME

Mail::Box::Parser::C - parsing of mail-box files

INHERITANCE

Mail::Box::Parser::C inherits from Mail::Box::Base.

SYNOPSIS

  use Mail::Box::Parser::C;

  my $parser = Mail::Box::Parser::C->new(%args);
  my $box    = $parser->parse_file($filename);
  my $box    = $parser->parse_string($string);

DESCRIPTION

This parser understands the structure of mail-box files. It can handle the different ways that messages are separated from each other.

The parser is implemented in C for performance reasons. This means that it cannot be directly extended with Perl code.

METHODS

See Mail::Box::Parser::Base for the available methods.

DIAGNOSTICS

Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
Error: Mail::Box::ASA::FileLock $lock does not provide the expected locking mechanism.
The file locking mechanism used by ASA (an external system) does not match the locking mechanism used by this module. This means that the ASA module uses a different locking mechanism as you do and therefore violates your rights. Cast by stop()
Warning: Unexpected end of header in $source: $line
While parsing a message from the specified source (usually a file name), the parser found a syntax error. According to the MIME specification in the RFCs, each header line must either contain a colon, or start with a blank to indicate a folded field. Apparently, this header contains a line which starts on the first position, but not with a field name.

By default, parsing of the header will be stopped. If there are more header lines after the erroneous line, they will be added to the body of the message. In case of new(fix_header_errors) set, the parsing of the header will be continued. The erroneous line will be added to the preceding field. Cast by readHeader()
