DESCRIPCIÓN

Realiza varias pruebas contra la estructura y el cuerpo MIME.

has_check_for_ascii_text_illegal
Añade una comprobación de capacidad para "if can()" para check_for_ascii_text_illegal
check_for_ascii_text_illegal
Si una parte MIME afirma ser text/plain o text/plain;charset=us-ascii y el Content-Transfer-Encoding es 7bit (explícitamente o por defecto), entonces debemos asegurar que el texto real solo contenga TAB, NL, ESPACIO hasta TILDE, es decir, todos los caracteres de 7 bits excluyendo NO-WS-CTL (según RFC-2822).

Todos los MTA principales manejan esto correctamente.

has_check_abundant_unicode_ratio
Añade una comprobación de capacidad para "if can()" para check_abundant_unicode_ratio
check_abundant_unicode_ratio
Una parte MIME que afirma ser text/plain y que contiene caracteres Unicode debe estar codificada como quoted-printable o base64, o usar la codificación de datos UTF (típicamente con codificación 8bit). Cualquier mensaje en codificación 7bit o 8bit que contenga entidades Unicode (HTML) no las renderizará como Unicode, sino literalmente.

Por lo tanto, unas pocas secuencias de este tipo podrían aparecer en una lista de correo de desarrolladores que discuten dichos caracteres, pero un mensaje con una alta densidad de tales caracteres es probablemente spam.

has_check_qp_ratio
Añade una comprobación de capacidad para "if can()" para check_qp_ratio
check_qp_ratio
Toma una ratio mínima para usar en eval y ver si hay un nivel de spam en la ratio de bytes quoted-printable frente al total de bytes en un correo electrónico.
