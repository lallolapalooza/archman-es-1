Magick++-Config(1) Manual de comandos generales Magick++-Config(1)

NOMBRE

Magick++-config - obtener información sobre la versión instalada de Magick++

SINOPSIS

Magick++-config [--cppflags] [--cxxflags] [--exec-prefix] [--ldflags] [--libs] [--prefix] [--version]

DESCRIPCIÓN

Magick++-config imprime las opciones del compilador y del enlazador necesarias para compilar y enlazar programas que usan la interfaz de programación de aplicaciones (API) C++ de ImageMagick (conocida como Magick++).

EJEMPLOS

Para imprimir la versión de la distribución instalada de Magick++, use:

  Magick++-config --version

Para compilar un programa que llama a la API C++ de ImageMagick, use:

  c++ `Magick++-config --cxxflags --cppflags --ldflags --libs` program.cpp

OPCIONES

--cppflags
Imprime las opciones del preprocesador que son necesarias para encontrar los archivos de inclusión de C y C++ de ImageMagick y define las directivas para asegurar que las estructuras de datos de ImageMagick coincidan entre su programa y las bibliotecas instaladas.
--cxxflags
Imprime las opciones del compilador que se utilizaron para compilar libMagick++.
--exec-prefix
Imprime el directorio bajo el cual se instalan los binarios y ejecutables específicos del objetivo.
--ldflags
Imprime las opciones del enlazador que son necesarias para enlazar con la biblioteca libMagick++.
--libs
Imprime las opciones del enlazador que son necesarias para enlazar un programa con libMagick++.
--prefix
Imprime el directorio bajo el cual se instala el paquete.
--version
Imprime la versión de la distribución de ImageMagick en la salida estándar.
