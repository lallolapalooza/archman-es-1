Mail::Box::Mbox::Message(3) Documentación de Perl contribuida por el usuario Mail::Box::Mbox::Message(3)

NOMBRE

Mail::Box::Mbox::Message - un mensaje en una carpeta Mbox

HERENCIA

Mail::Box::Mbox::Message
  es un Mail::Box::File::Message
  es un Mail::Box::Message
  es un Mail::Message
  es un Mail::Reporter

SINOPSIS

my $folder  = Mail::Box::Mbox->new(folder => $ENV{MAIL}, ...);
my $message = $folder->message(0);

DESCRIPCION

Mantiene un mensaje en una carpeta Mail::Box::Mbox.

Extiende "DESCRIPCION" en Mail::Box::File::Message.

DIAGNÓSTICOS

Error: No se puede forzar un objeto $class a un objeto $class
Forzado por coerce()
Error: No se puede incluir la fuente de reenvío como $include.
Alternativa desconocida para el reenvío (incluir). Las opciones válidas son "NO", "INLINE", "ATTACH", y "ENCAPSULATE". Forzado por forward()
Error: No se puede incluir la fuente de respuesta como $include.
Alternativa desconocida para la opción "include" de reply(). Las opciones válidas son "NO", "INLINE", y "ATTACH". Forzado por reply()
Error: El método bounce requiere To, Cc, o Bcc
El método bounce() del mensaje reenvía un mensaje recibido a alguien más sin modificaciones; debes especificar su nuevo destino. Si tienes la tentación de no especificar ningún destino, probablemente estás buscando reply(). Cuando desees modificar el contenido, usa forward(). Forzado por bounce()
Error: El método forwardAttach requiere un preámbulo
Forzado por forwardAttach()
Error: El método forwardEncapsulate requiere un preámbulo
Forzado por forwardEncapsulate()
Error: No hay dirección para reenviar.
Si se crea un mensaje reenviado, se debe especificar una dirección de destino. Forzado por forward()
Error: No se encontró ningún remitente predeterminado para enviar el mensaje.
El mecanismo send() del mensaje no tenía suficiente información para encontrar automáticamente un agente de transferencia de correo para enviar este mensaje. Especifica un remitente explícitamente usando las opciones "via". Forzado por send()
Error: No se define la regla de reconstrucción $name.
Forzado por rebuild()
Error: Solo build() Mensajes Mail::; aún no están en una carpeta
Es posible que desees construir un mensaje para almacenarlo en algún tipo de carpeta, pero debes hacerlo en dos pasos. Primero, crea un Mail::Message normal, y luego agrégalo a la carpeta. Durante este proceso de Mail::Box::addMessage(), el mensaje será coerce()-d al tipo de mensaje correcto, añadiendo información de almacenamiento y demás. Forzado por build()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas sí implementan este método, pero la clase en cuestión no. Probablemente deberías investigar esto y, posiblemente, informar al autor del paquete. Forzado por notImplemented()
Error: No se puede leer el cuerpo retrasado.
Forzado por loadBody()
Error: la coerción comienza con algún objeto
Forzado por coerce()
