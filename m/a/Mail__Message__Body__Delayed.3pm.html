NOMBRE

Mail::Message::Body::Delayed - cuerpo de un Mail::Message pero aún no leído.

HERENCIA

Mail::Message::Body::Delayed realiza un Mail::Message::Body
Mail::Message::Body::Delayed
  es un Mail::Reporter

SINOPSIS

Ver Mail::Message::Body

DESCRIPCIÓN

Los cuerpos de mensaje de este tipo serán reemplazados por otro tipo en el momento en que acceda al contenido. En esta documentación encontrará la descripción de cómo se carga un cuerpo de mensaje de forma retardada.

Extiende "DESCRIPCIÓN" en Mail::Reporter.

SOBRECARGADO

sobrecarga: "" conversión a cadena
Devuelve el cuerpo como una cadena, lo que activará la finalización, a menos que se llame para producir una cadena para "Carp". Esto último es para evitar recursiones profundas.

» ejemplo: conversión a cadena de cuerpo retardado

print $msg->body;   # implícito por print
my $body = $msg->body;
my $x    = "$body"; # explícito por interpolación
sobrecarga: @{} acceso como ARRAY
Cuando un objeto de cuerpo se utiliza como referencia de array, se devuelven las líneas del cuerpo. Esto es lo mismo que usar el método "lines".
sobrecarga: bool existencia
Siempre devuelve un valor "verdadero", que es necesario para que los objetos sobrecargados se utilicen en if($body). De lo contrario, se necesitaría "if(defined $body)" para evitar un error en tiempo de ejecución.

NAME

Mail::Message::Body::Delayed - maneja cuerpos de mensajes de correo diferidos

SYNOPSIS

use Mail::Message::Body::Delayed;

my $body = Mail::Message::Body::Delayed->new;
$body->read_body($message);

my $content = $body->as_string;

DESCRIPTION

Esta clase representa el cuerpo de un mensaje de correo que se carga de forma diferida. El cuerpo no se lee realmente de la fuente hasta que se solicita explícitamente (por ejemplo, llamando a as_string o as_stream).

Esto es útil para evitar cargar cuerpos de mensajes grandes en memoria innecesariamente cuando solo se necesita examinar las cabeceras.

METHODS

new()

Crea una nueva instancia de Mail::Message::Body::Delayed.

read_body($message)

Lee el cuerpo del mensaje de forma diferida a partir del objeto mensaje proporcionado. El método no lee el cuerpo inmediatamente, sino que almacena una referencia al mensaje para su posterior procesamiento.

as_string()

Devuelve el cuerpo del mensaje como una cadena. Si el cuerpo aún no se ha leído, se leerá de la fuente en este punto.

as_stream()

Devuelve el cuerpo del mensaje como un objeto stream (IO::Handle). Si el cuerpo aún no se ha leído, se leerá de la fuente en este punto.
