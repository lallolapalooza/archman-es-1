Mail::SPF::Record(3) Documentación de Perl contribuida por el usuario Mail::SPF::Record(3)

NOMBRE

Mail::SPF::Record - Clase base abstracta para registros SPF

VERSIÓN

versión 3.20250505

SINOPSIS

Creando un registro a partir de una cadena

use Mail::SPF::v1::Record;
my $record = Mail::SPF::v1::Record->new_from_string("v=spf1 a mx -all");

Creando un registro sintéticamente

use Mail::SPF::v2::Record;
my $record = Mail::SPF::v2::Record->new(
    scopes      => ['mfrom', 'pra'],
    terms       => [
        Mail::SPF::Mech::A->new(),
        Mail::SPF::Mech::MX->new(),
        Mail::SPF::Mech::All->new(qualifier => '-')
    ],
    global_mods => [
        Mail::SPF::Mod::Exp->new(domain_spec => 'spf-exp.example.com')
    ]
);

DESCRIPCIÓN

Mail::SPF::Record es una clase base abstracta para registros SPF. No se puede instanciar directamente. Cree una instancia de una sub-clase concreta en su lugar.

Constructor

Se proporcionan los siguientes constructores:

new(%options): devuelve Mail::SPF::Record
Crea un nuevo objeto de registro SPF.

%options es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

text
Una cadena que denota el texto sin analizar del registro.
scopes
Una referencia a un array de cadenas que denotan los ámbitos cubiertos por el registro (ver la descripción de la opción "scope" del constructor "new" de Mail::SPF::Request).
terms
Una referencia a un array de objetos Mail::SPF::Term (es decir, Mail::SPF::Mech o Mail::SPF::Mod) que componen el registro. Los objetos Mail::SPF::GlobalMod no deben incluirse aquí, sino que deben especificarse usando la opción "global_mods" en su lugar.
global_mods
Una referencia a un array de objetos Mail::SPF::GlobalMod que son modificadores globales del registro.
new_from_string($text, %options): devuelve Mail::SPF::Record; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidRecordVersion, Mail::SPF::ESyntaxError
Crea un nuevo objeto de registro SPF analizando la cadena y las opciones proporcionadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

version_tag_pattern: devuelve Regexp
Abstracto. Devuelve una expresión regular que coincide con una etiqueta de versión legal.

Este método es abstracto y debe ser implementado por sub-clases de Mail::SPF::Record.

default_qualifier: devuelve cadena
Devuelve el calificador por defecto, es decir, '+'.
results_by_qualifier: devuelve hash de cadena
Devuelve una referencia a un hash que mapea calificadores a códigos de resultado de la siguiente manera: 
 Calificador | Código de resultado
-----------+-----------------
     +     | pass
     -     | fail
     ~     | softfail
     ?     | neutral

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

text: devuelve cadena; lanza Mail::SPF::ENoUnparsedText
Devuelve el texto sin analizar del registro. Lanza una excepción Mail::SPF::ENoUnparsedText si el registro se creó sintéticamente en lugar de analizarse, y no se proporcionó texto.
version_tag: devuelve cadena
Abstracto. Devuelve la etiqueta de versión del registro.

Este método es abstracto y debe ser implementado por sub-clases de Mail::SPF::Record.

scopes: devuelve lista de cadena
Devuelve una lista de los ámbitos cubiertos por el registro. Ver la descripción de la opción "scopes" del constructor "new".
terms: devuelve lista de Mail::SPF::Term
Devuelve una lista de los términos que componen el registro, excluyendo los modificadores globales, que son devueltos por el método "global_mods". Ver la descripción de la opción "terms" del constructor "new".
global_mods: devuelve lista de Mail::SPF::GlobalMod
Devuelve una lista de los modificadores globales del registro, ordenados ascendentemente por precedencia de modificador. Ver la descripción de la opción "global_mods" del constructor "new".
global_mod($mod_name): devuelve Mail::SPF::GlobalMod
Devuelve el modificador global del nombre dado si está presente en el registro. Devuelve undef de lo contrario. Utilice este método si desea recuperar un modificador global específico en lugar de obtener todos.
stringify: devuelve cadena
Devuelve la etiqueta de versión y los términos del registro (incluidos los modificadores globales) formateados como una cadena. Puede utilizar simplemente un objeto Mail::SPF::Record como cadena para el mismo efecto, ver "SOBRECARGA".
eval($server, $request): lanza Mail::SPF::Result
Evalúa el registro SPF en el contexto de los parámetros de solicitud representados por el objeto Mail::SPF::Request dado. El objeto Mail::SPF::Server dado se utiliza para realizar búsquedas DNS. Lanza un objeto Mail::SPF::Result que coincide con el resultado de la evaluación; ver Mail::SPF::Result. Ver RFC 4408, 4.6 y 4.7, para el algoritmo exacto utilizado.

SOBRECARGA

Si se utiliza un objeto Mail::SPF::Record como cadena, el método "stringify" se utiliza para convertir el objeto en una cadena.
