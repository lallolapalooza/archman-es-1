NOMBRE

Mail::SpamAssassin::Conf::LDAP - cargar puntuaciones de SpamAssassin desde la base de datos LDAP

SINOPSIS

(ver Mail::SpamAssassin)

DESCRIPCIÓN

Mail::SpamAssassin es un módulo para identificar spam usando análisis de texto y varias listas de bloqueo en tiempo real basadas en internet.

Esta clase es utilizada internamente por SpamAssassin para cargar puntuaciones desde una base de datos LDAP. Por favor, consulte la documentación de "Mail::SpamAssassin" para las interfaces públicas.

MÉTODOS

$f->load ($username)
Lee los parámetros de configuración del servidor LDAP y analiza las puntuaciones de él.
