Mail::SpamAssassin::Plugin::AuthRes(3) Documentación de Perl contribuida por el usuario Mail::SpamAssassin::Plugin::AuthRes(3)

NOMBRE

Mail::SpamAssassin::Plugin::AuthRes - utiliza campos de encabezado Authentication-Results

SINOPSIS

Configuración de SpamAssassin:

loadplugin Mail::SpamAssassin::Plugin::AuthRes

authres_trusted_authserv myserv.example.com authres_networks all

DESCRIPCIÓN

Este plugin analiza los campos de encabezado Authentication-Results y puede suministrar los resultados obtenidos a otros plugins, para evitar repetir comprobaciones que ya se han realizado.

CONFIGURACIÓN DE ADMINISTRADOR

authres_networks internal/trusted/all (predeterminado: internal)
Procesa encabezados Authentication-Results establecidos por servidores de estas redes (se refiere a las zonas *_networks de SpamAssassin). Cualquier encabezado fuera de esto se ignora por completo (afecta a todas las configuraciones del módulo). 
internal   = internal_networks
trusted    = internal_networks + trusted_networks
all        = all above + all external

Establecer "all" es seguro solo si tus servidores MX filtran correctamente todos los encabezados A-R entrantes, y utilizas authres_trusted_authserv para que coincida con tu authserv-id. Esto es adecuado para OpenDKIM por defecto, por ejemplo. Estas configuraciones también pueden ser requeridas si tus filtros no insertan el encabezado A-R en la posición correcta encima del encabezado Received interno (algunos infractores conocidos: OpenDKIM, OpenDMARC, amavisd-milter).

authres_trusted_authserv authservid1 id2 ... (predeterminado: none)
IDs de servidores de autenticación confiables (la primera palabra similar a un nombre de dominio del campo Authentication-Results, también conocido como "authserv-id").

Ten en cuenta que si se establece, TODOS los encabezados A-R se ignoran a menos que se encuentre una coincidencia.

Se recomienda encarecidamente su uso, posiblemente junto con authres_networks all.

authres_ignored_authserv authservid1 id2 ... (predeterminado: none)
IDs de servidores de autenticación ignorados (la primera palabra similar a un nombre de dominio del campo Authentication-Results, también conocido como "authserv-id").

Cualquier encabezado A-R se ignora si se encuentra una coincidencia.

METADATOS

Los encabezados analizados se almacenan en $pms->{authres_parsed}, como un hash de arrays de hashes donde los resultados se recopilan por método. Por ejemplo, el campo de encabezado:

Authentication-Results: server.example.com;
  spf=pass smtp.mailfrom=bounce.example.org;
  dkim=pass header.i=@example.org;
  dkim=fail header.i=@another.signing.domain.example

Produce la siguiente estructura:

$pms->{authres_parsed} = {
  'dkim' => [
    {
      'properties' => {
        'header' => {
          'i' => '@example.org'
        }
      },
      'authserv' => 'server.example.com',
      'result' => 'pass',
      'version' => 1,
      'reason' => ''
    },
    {
      'properties' => {
        'header' => {
          'i' => '@another.signing.domain.example'
        }
      },
      'result' => 'fail',
      'authserv' => 'server.example.com',
      'version' => 1,
      'reason' => ''
    },
  ],
}

Dentro de cada array, el orden de los resultados es el original, que debería ser los resultados más recientes primero.

Para comprobar el resultado de los métodos, $pms->{authres_result} está disponible:

$pms->{authres_result} = {
  'dkim' => 'pass',
  'spf' => 'fail',
}

FUNCIONES DE EVALUACIÓN

header RULENAME eval:check_authres_result(method, result)
Se puede usar para comprobar resultados.

Referencia de métodos y valores de resultados válidos: "https://www.iana.org/assignments/email-auth/email-auth.xhtml"

Adicionalmente, el valor de resultado 'missing' se puede usar para comprobar si no hay ningún resultado en absoluto.

ifplugin Mail::SpamAssassin::Plugin::AuthRes
ifplugin !(Mail::SpamAssassin::Plugin::SPF)
  header  SPF_PASS      eval:check_authres_result('spf', 'pass')
  header  SPF_FAIL      eval:check_authres_result('spf', 'fail')
  header  SPF_SOFTFAIL  eval:check_authres_result('spf', 'softfail')
  header  SPF_TEMPFAIL  eval:check_authres_result('spf', 'tempfail')
endif
ifplugin !(Mail::SpamAssassin::Plugin::DKIM)
  header  DKIM_VERIFIED  eval:check_authres_result('dkim', 'pass')
  header  DKIM_INVALID   eval:check_authres_result('dkim', 'fail')
endif
endif
