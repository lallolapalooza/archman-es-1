Nombre

Mail::Box::Manage::User - gestiona las carpetas de un usuario

Herencia

Mail::Box::Manage::User
  is a Mail::Box::Manager
  is a Mail::Reporter
Mail::Box::Manage::User is extended by
  Mail::Server::IMAP4::User

Sintaxis

use Mail::Box::Manage::User;
use User::Identity;
my $id      = User::Identity->new(...);
my $user    = Mail::Box::Manage::User->new(
  identity  => $id,
  folderdir => "$ENV{HOME}/Mail",
  inbox     => $ENV{MAIL},
);
my $inbox   = $user->open($user->inbox);
my $top     = $user->topfolder;

Descripción

Donde Mail::Box::Manager toma en cuenta algunos conjuntos de carpetas abiertas, esta extensión añade conocimiento sobre algunos relacionados con una persona. A la vez, intenta cachear información sobre los archivos de carpetas de esa persona.

Gestionar carpetas

$obj->create($name, %options)
Crea una nueva carpeta con el nombre especificado. Se devuelve la estructura administrativa de una carpeta (Mail::Box::Identity), pero la carpeta no se abre.

En el caso accidental de que la carpeta ya exista, se emitirá una advertencia y se devolverá una lista vacía/"undef".

Las %options se pasan a Mail::Box::create() de tu tipo de carpeta por defecto, excepto las opciones destinadas a este método en sí.

-Option       --Default
 create_real    true
 create_supers  false
 deleted        false
 id_options     []
create_real => BOOLEAN
Cuando esta opción es "false", la carpeta física no se creará, solo se actualizará la administración.
create_supers => BOOLEAN
Cuando creas una carpeta donde faltan niveles de jerarquía superiores, también se crearán.
deleted => BOOLEAN
La carpeta comienza como eliminada.
id_options => ARRAY
Valores pasados a la instancia de Mail::Box::Identity. Ese objeto es muy exigente con los valores de inicialización que acepta.
$obj->delete($name)
Elimina todos los rastros de la carpeta en el sistema de archivos. Los mensajes que aún estén en la carpeta serán eliminados. Este método devuelve un valor "true" si la carpeta ha sido eliminada o no se encontró, por lo que ""false"" significa fallo.

También es posible eliminar una carpeta usando "$folder->delete", que llamará a este método aquí. Las OPCIONES, que se utilizan para otros tipos de carpetas, se ignorarán aquí: el índice del usuario contiene los detalles necesarios. Mejora la base, ver "Manage existing folders" en Mail::Box::Manager

-Option   --Defined in        --Default
 recursive  Mail::Box::Manager  <el valor por defecto de la carpeta>
recursive => BOOLEAN

» ejemplo: cómo eliminar una carpeta

print "no xyz (anymore)\n" if $user->delete('xyz');
$obj->folder($name)
Devuelve la descripción de la carpeta, un Mail::Box::Identity.
$obj->folderCollection($name)
Devuelve un par: la colección de carpetas (Mail::Box::Collection) y el nombre base de $name.
$obj->rename($oldname, $newname, %options)
Renombra la carpeta con el nombre $oldname a $newname. Ambos nombres son rutas completas. 
-Option       --Default
 create_supers  false
create_supers => BOOLEAN
Cuando renombra una carpeta a un lugar donde faltan niveles de jerarquía superiores, se definirán, pero con la bandera de eliminado establecida.

DIAGNÓSTICOS

Error: No se puede crear $name: faltan niveles superiores
A menos que establezca create(create_supers), todas las carpetas de nivel superior deben existir antes de que se pueda crear esta nueva. Emitido por create()
Error: No se puede renombrar $name a $new: faltan niveles superiores
A menos que establezca create(create_supers), todas las carpetas de nivel superior deben existir antes de que se pueda crear esta nueva. Emitido por rename()
Error: La carpeta $name ya está abierta.
No se puede solicitar al gestor una carpeta que ya está abierta. En algunas versiones anteriores (antes de MailBox 2.049), esto estaba permitido, pero el comportamiento cambió, ya que se esperan muchos efectos secundarios desagradables. Por ejemplo, un Mail::Box::update() en un manejador de carpeta influiría en el segundo, probablemente de forma inesperada. Emitido por open()
Error: La carpeta $name no es una Mail::Box; no se puede añadir un mensaje.
La carpeta a la que se debe adjuntar el mensaje es un objeto que no es de un tipo de carpeta que extienda Mail::Box. Probablemente, ni siquiera es una carpeta. Emitido por appendMessage()
Advertencia: La carpeta no existe, fallo al abrir la carpeta de tipo $type $name.
La carpeta no existe y no se permite crearla (ver open(create)) o no se pudo crear. Si no tiene suficientes derechos de acceso a la carpeta (por ejemplo, contraseña incorrecta para POP3), esta advertencia también se producirá.

El gestor intentó abrir una carpeta del tipo especificado. Puede ser útil indicar explícitamente el tipo de su carpeta con la opción "type". Probablemente habrá otra advertencia o mensaje de error relacionado con este informe que proporcione más detalles sobre su causa. También puede consultar new(autodetect) y new(folder_types). Emitido por open()

Advertencia: El tipo de carpeta $type es desconocido, usando autodetect.
El tipo de carpeta especificado (ver open(type), posiblemente derivado del nombre de la carpeta cuando se especifica como URL) no es conocido por el gestor. Esto puede significar que olvidó requerir la extensión Mail::Box que implementa este tipo de carpeta, pero probablemente es un error de tipografía. Normalmente, el gestor es capaz de averiguar qué tipo usar por sí mismo. Emitido por open()
Error: URL de carpeta ilegal '$url'.
El nombre de la carpeta se especificó como URL, pero no de acuerdo con la sintaxis. Ver decodeFolderURL() para una descripción de la sintaxis. Emitido por open()
Error: No se especificó nombre de carpeta para abrir.
open() necesita un nombre de carpeta como primer argumento (antes de la lista de opciones), o con la opción "folder" dentro de la lista. Si no se encontró ningún nombre, se comprueba la variable de entorno MAIL. Si incluso eso no da como resultado una carpeta utilizable, entonces se produce este error. El error puede ser causado por una lista de opciones de longitud impar accidental. Emitido por open()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, pero la clase en cuestión no lo hace. Probablemente debería investigar esto y, posiblemente, informar al autor del paquete. Emitido por notImplemented()
Error: No se puede eliminar la carpeta $dir
Emitido por delete()
Error: Use appendMessage() para añadir mensajes que no están en una carpeta.
No necesita copiar este mensaje en la carpeta, porque no comparte el mensaje entre carpetas. Emitido por copyMessage()
Advertencia: Use moveMessage() o copyMessage() para mover entre carpetas abiertas.
El mensaje ya forma parte de una carpeta y ahora debe adjuntarse a una carpeta diferente. Debe decidir entre copiar o mover, ambos clonarán el mensaje (no el cuerpo, ya que son inmutables). Emitido por appendMessage()
Advertencia: Nunca se creará una carpeta $name sin tener acceso de escritura.
Ha establecido open(create), pero solo quiere leer la carpeta. Create solo es útil para carpetas que tienen modos de acceso de escritura o adición (ver Mail::Box::new(access)). Emitido por open()
