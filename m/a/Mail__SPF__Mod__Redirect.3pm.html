Mail::SPF::Mod::Redirect(3) Documentación de Perl aportada por el usuario Mail::SPF::Mod::Redirect(3)

NOMBRE

Mail::SPF::Mod::Redirect - clase del modificador de registro SPF "redirect"

VERSIÓN

version 3.20250505

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::Mod::Redirect representa un modificador de registro SPF de tipo "redirect".

Constructores

Se proporcionan los siguientes constructores:

new(%options): devuelve Mail::SPF::Mod::Redirect
Crea un nuevo objeto modificador "redirect" de registro SPF.

%options es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

domain_spec
Ver "new" en Mail::SPF::Mod.
new_from_string($text, %options): devuelve Mail::SPF::Mod::Redirect; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMod
Crea un nuevo objeto modificador "redirect" de registro SPF analizando la cadena y las opciones dadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

name: devuelve string
Devuelve 'redirect'.
name_pattern: devuelve Regexp
Devuelve una expresión regular que coincide con un nombre de modificador de 'redirect'.
precedence: devuelve real
Devuelve un valor de precedencia de 0.8. Ver "precedence" en Mail::SPF::Mod.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

params
Ver "params" en Mail::SPF::Mod.
domain_spec: devuelve Mail::SPF::MacroString
Devuelve el parámetro "domain-spec" del modificador.
process($server, $request, $result): lanza Mail::SPF::Result
Si ningún mecanismo coincidió durante la evaluación del registro SPF actual, realiza una comprobación SPF recursiva utilizando los objetos de servidor y solicitud SPF dados y sustituyendo el nombre de dominio de destino del modificador por el dominio de autoridad de la solicitud. El resultado de la comprobación SPF recursiva se lanza entonces como resultado de la evaluación del registro actual. Sin embargo, si el dominio de destino no tiene un registro SPF aceptable, se lanza un resultado de "permerror". Ver RFC 4408, 6.1, para más detalles.

Ver Mail::SPF::Mod para otros métodos de instancia admitidos.
