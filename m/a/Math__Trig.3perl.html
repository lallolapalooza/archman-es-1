NOMBRE

Math::Trig - funciones trigonométricas

SINOPSIS

use Math::Trig;
$x = tan(0.9);
$y = acos(3.7);
$z = asin(2.4);
$halfpi = pi/2;
$rad = deg2rad(120);
# Importar las constantes pi2, pi4, pip2, pip4 (2*pi, 4*pi, pi/2, pi/4).
use Math::Trig ':pi';
# Importar las conversiones entre cartesiana/esférica/cilíndrica.
use Math::Trig ':radial';
    # Importar las fórmulas del círculo máximo.
use Math::Trig ':great_circle';

DESCRIPCIÓN

"Math::Trig" define muchas funciones trigonométricas no definidas por el núcleo de Perl, que solo define sin() y cos(). La constante pi también está definida, al igual que algunas funciones de conveniencia para conversiones de ángulos y fórmulas de círculo máximo para movimiento esférico.

La tangente

tan

Las cofunciones del seno, coseno y tangente (secante/cosecante y cotangente son alias)

csc, cosec, sec, sec, cot, cotan

Las funciones arcus (también conocidas como inversas) del seno, coseno y tangente

asin, acos, atan

El valor principal del arco tangente de y/x

atan2(y, x)

Las cofunciones arcus del seno, coseno y tangente (acosec/acsc y acotan/acot son alias). Nótese que atan2(0, 0) no está bien definido.

acsc, acosec, asec, acot, acotan

El seno, coseno y tangente hiperbólicos

Las cofunciones del seno, coseno y tangente hiperbólicos (cosech/csch y cotanh/coth son alias)

Las funciones de área (también conocidas como inversas) del seno, coseno y tangente hiperbólicos

asinh, acosh, atanh

Las cofunciones de área del seno, coseno y tangente hiperbólicos (acsch/acosech y acoth/acotanh son alias)

no pueden calcularse para todos los argumentos porque eso implicaría dividir por cero o tomar el logaritmo de cero. Estas situaciones causan errores fatales en tiempo de ejecución que se parecen a esto

o

Para las funciones "csc", "cot", "asec", "acsc", "acot", "csch", "coth", "asech", "acsch", el argumento no puede ser 0 (cero). Para las funciones "atanh", "acoth", el argumento no puede ser 1 (uno). Para las funciones "atanh", "acoth", el argumento no puede ser -1 (menos uno). Para las funciones "tan", "sec", "tanh", "sech", el argumento no puede ser pi/2 + k * pi, donde k es cualquier entero.

Nótese que atan2(0, 0) no está bien definido.

ARGUMENTOS SIMPLES (REALES), RESULTADOS COMPLEJOS

Tenga en cuenta que algunas de las funciones trigonométricas pueden salir del eje real hacia el plano complejo. Por ejemplo, asin(2) no tiene definición para números reales simples, pero sí la tiene para números complejos.

En términos de Perl, esto significa que proporcionar los números habituales de Perl (también conocidos como escalares, véase perldata) como entrada para las funciones trigonométricas podría producir resultados que ya no son números reales simples: en su lugar, son números complejos.

El paquete "Math::Trig" maneja esto utilizando el paquete "Math::Complex", que sabe cómo manejar números complejos; consulte Math::Complex para obtener más información. En la práctica, no necesita preocuparse por obtener números complejos como resultados, ya que "Math::Complex" se encarga de detalles como, por ejemplo, cómo mostrar números complejos. Por ejemplo:

print asin(2), "\n";

debería producir algo como esto (con algunas o pocas cifras decimales al final):

1.5707963267949-1.31695789692482i

Es decir, un número complejo con una parte real de aproximadamente 1.571 y una parte imaginaria de aproximadamente -1.317.

CONVERSIONES DE ÁNGULOS PLANOS

(Ángulos planos, 2-dimensionales) pueden convertirse con las siguientes funciones.

deg2rad
$radianes  = deg2rad($grados);
grad2rad
$radianes  = grad2rad($grados_sexagesimales);
rad2deg
$grados  = rad2deg($radianes);
grad2deg
$grados  = grad2deg($grados_sexagesimales);
deg2grad
$grados_sexagesimales = deg2grad($grados);
rad2grad
$grados_sexagesimales = rad2grad($radianes);

El círculo completo es 2 pi radianes o 360 grados o 400 grados centesimales. El resultado se ajusta por defecto para estar dentro del círculo [0, {2pi,360,400}). Si no desea esto, proporcione un segundo argumento verdadero:

$miles_de_radianes  = deg2rad($miles_de_grados, 1);
$grados_negativos     = rad2deg($radianes_negativos, 1);

También puede hacer el ajuste explícitamente con rad2rad(), deg2deg(), y grad2grad().

rad2rad
$radianes_ajustados_por_2pi = rad2rad($radianes);
deg2deg
$grados_ajustados_por_360 = deg2deg($grados);
grad2grad
$grados_sexagesimales_ajustados_por_400 = grad2grad($grados_sexagesimales);

CONVERSIONES DE COORDENADAS RADIALES

Los sistemas de coordenadas radiales son los sistemas esféricos y cilíndricos, explicados brevemente a continuación.

Puede importar funciones de conversión de coordenadas radiales utilizando la etiqueta ":radial":

use Math::Trig ':radial';
($rho, $theta, $z)     = cartesian_to_cylindrical($x, $y, $z);
($rho, $theta, $phi)   = cartesian_to_spherical($x, $y, $z);
($x, $y, $z)           = cylindrical_to_cartesian($rho, $theta, $z);
($rho_s, $theta, $phi) = cylindrical_to_spherical($rho_c, $theta, $z);
($x, $y, $z)           = spherical_to_cartesian($rho, $theta, $phi);
($rho_c, $theta, $z)   = spherical_to_cylindrical($rho_s, $theta, $phi);

Todos los ángulos están en radianes.

COORDENADAS ESFÉRICAS Y CILÍNDRICAS

Este módulo proporciona funciones para convertir entre coordenadas cartesianas, esfóricas y cilíndricas. También proporciona funciones para calcular la distancia y la dirección de un gran círculo en una esfera.

La notación para las coordenadas se describe a continuación. Los valores angulares están en radianes. Si se usan grados, se puede usar la función deg2rad() y rad2deg() para convertir.

Las coordenadas cartesianas, (x, y, z), son las coordenadas tridimensionales estándar. La coordenada z es la altura sobre el plano xy. La coordenada theta es el ángulo en el plano xy, medido desde el eje x. La coordenada rho es el radio, la distancia desde el origen.

Las coordenadas esfóricas, (rho, theta, phi), son coordenadas tridimensionales que definen un punto en el espacio tridimensional. Se basan en la superficie de una esfera. El radio de la esfera es rho, también conocido como la coordenada radial. El ángulo en el plano xy (alrededor del eje z) es theta, también conocido como la coordenada azimutal. El ángulo desde el eje z es phi, también conocido como la coordenada polar. El Polo Norte es, por lo tanto, rho, 0, 0, y el Golfo de Guinea (piensa en el gran trozo que falta de África) rho, 0, pi/2. En términos geográficos, phi es la latitud (norte positivo, sur negativo) y theta es la longitud (este positivo, oeste negativo).

TENGA CUIDADO: algunos textos definen theta y phi al revés, algunos textos definen phi para que comience desde el plano horizontal, algunos textos usan r en lugar de rho.

Las coordenadas cilíndricas, (rho, theta, z), son coordenadas tridimensionales que definen un punto en el espacio tridimensional. Se basan en la superficie de un cilindro. El radio del cilindro es rho, también conocido como la coordenada radial. El ángulo en el plano xy (alrededor del eje z) es theta, también conocido como la coordenada azimutal. La tercera coordenada es la z, que apunta hacia arriba desde el plano de theta.

CONVERSIONES DE ÁNGULOS 3D

Las conversiones hacia y desde coordenadas esféricas y cilíndricas están disponibles. Tenga en cuenta que las conversiones no son necesariamente reversibles debido a igualdades como los ángulos pi que son iguales a los ángulos -pi.

cartesian_to_cylindrical
($rho, $theta, $z) = cartesian_to_cylindrical($x, $y, $z);
cartesian_to_spherical
($rho, $theta, $phi) = cartesian_to_spherical($x, $y, $z);
cylindrical_to_cartesian
($x, $y, $z) = cylindrical_to_cartesian($rho, $theta, $z);
cylindrical_to_spherical
($rho_s, $theta, $phi) = cylindrical_to_spherical($rho_c, $theta, $z);

Tenga en cuenta que cuando $z no es 0, $rho_s no es igual a $rho_c.

spherical_to_cartesian
($x, $y, $z) = spherical_to_cartesian($rho, $theta, $phi);
spherical_to_cylindrical
($rho_c, $theta, $z) = spherical_to_cylindrical($rho_s, $theta, $phi);

Tenga en cuenta que cuando $z no es 0, $rho_c no es igual a $rho_s.

DISTANCIAS Y DIRECCIONES DE GRANDES CÍRCULOS

Un gran círculo es una sección de un círculo que contiene el diámetro del círculo: la distancia más corta entre dos puntos (no antipodales) en la superficie esférica va a lo largo del gran círculo que conecta esos dos puntos.

great_circle_distance

Devuelve la distancia del gran círculo entre dos puntos en una esfera.

$distance = great_circle_distance($theta0, $phi0, $theta1, $phi1, [, $rho]);

Donde ($theta0, $phi0) y ($theta1, $phi1) son las coordenadas esféricas de los dos puntos, respectivamente. La distancia está en unidades de $rho. El $rho es opcional. Por defecto es 1 (la esfera unitaria).

Si está utilizando coordenadas geográficas, latitud y longitud, debe tener en cuenta el hecho de que la latitud es cero en el ecuador, aumentando hacia el norte y disminuyendo hacia el sur. Suponiendo que ($lat0, $lon0) y ($lat1, $lon1) son las coordenadas geográficas en radianes de los dos puntos, la distancia se puede calcular con

$distance = great_circle_distance($lon0, pi/2 - $lat0,
                                  $lon1, pi/2 - $lat1, $rho);

great_circle_direction

La dirección que debe seguir el gran círculo (también conocida como rumbo) se puede calcular mediante la función great_circle_direction():

use Math::Trig 'great_circle_direction';
$direction = great_circle_direction($theta0, $phi0, $theta1, $phi1);

great_circle_bearing

El alias 'great_circle_bearing' para 'great_circle_direction' también está disponible.

use Math::Trig 'great_circle_bearing';
$direction = great_circle_bearing($theta0, $phi0, $theta1, $phi1);

El resultado de great_circle_direction está en radianes, cero indicando norte directo, pi o -pi sur directo, pi/2 oeste directo y -pi/2 este directo.

great_circle_destination

Puede calcular inversamente el destino si conoce el punto de partida, la dirección y la distancia:

use Math::Trig 'great_circle_destination';
# $diro es la dirección original,
# por ejemplo, de great_circle_bearing().
# $distance es la distancia angular en radianes,
# por ejemplo, de great_circle_distance().
# $thetad y $phid son las coordenadas de destino,
# $dird es la dirección final en el destino.
($thetad, $phid, $dird) =
  great_circle_destination($theta, $phi, $diro, $distance);

o el punto medio si conoce los puntos finales:

great_circle_midpoint

use Math::Trig 'great_circle_midpoint';
($thetam, $phim) =
  great_circle_midpoint($theta0, $phi0, $theta1, $phi1);

El great_circle_midpoint() es solo un caso especial de

great_circle_waypoint

use Math::Trig 'great_circle_waypoint';
($thetai, $phii) =
  great_circle_waypoint($theta0, $phi0, $theta1, $phi1, $way);

Donde $way indica la posición del punto de paso a lo largo del arco del gran círculo a través del punto de partida ($theta0, $phi0) y el punto final ($theta1, $phi1) en relación con la distancia desde el punto de partida hasta el punto final. Por lo tanto, $way = 0 da el punto de partida, $way = 1 da el punto final, $way < 0 da un punto "detrás" del punto de partida, y $way > 1 da un punto más allá del punto final. $way tiene un valor predeterminado de 0.5 si no se proporciona.

Tenga en cuenta que los puntos antipodales (donde su distancia es pi radianes) no tienen puntos de paso únicos entre ellos y, por lo tanto, se devuelve "undef" en tales casos. Si los puntos son los mismos, por lo que la distancia entre ellos es cero, todos los puntos de paso son idénticos al punto de partida/final.

Los thetas, phis, dirección y distancia en lo anterior están todos en radianes.

Puede importar todas las fórmulas de gran círculo con

use Math::Trig ':great_circle';

Tenga en cuenta que las direcciones resultantes pueden ser algo sorprendentes si está mirando un mapa mundial plano: en tales proyecciones de mapa, los grandes círculos a menudo no parecen las rutas más cortas, pero por ejemplo, las rutas más cortas posibles desde Europa o América del Norte a Asia a menudo cruzan las regiones polares. (La proyección Mercator común no muestra los grandes círculos como líneas rectas: las líneas rectas en la proyección Mercator son líneas de rumbo constante).

EJEMPLOS

Para calcular la distancia entre Londres (51.3N 0.5W) y Tokio (35.7N 139.8E) en kilómetros:

use Math::Trig qw(great_circle_distance deg2rad);
# Tenga en cuenta el 90 - latitud: phi cero está en el Polo Norte.
sub NESW { deg2rad($_[0]), deg2rad(90 - $_[1]) }
my @L = NESW( -0.5, 51.3);
my @T = NESW(139.8, 35.7);
my $km = great_circle_distance(@L, @T, 6378); # Unos 9600 km.

La dirección que tendría que tomar desde Londres a Tokio (en radianes, norte directo siendo cero, este directo siendo pi/2).

use Math::Trig qw(great_circle_direction);
my $rad = great_circle_direction(@L, @T); # Alrededor de 0.547 o 0.174 pi.

El punto medio entre Londres y Tokio es

use Math::Trig qw(great_circle_midpoint rad2deg);
my @M = great_circle_midpoint(@L, @T);
sub SWNE { rad2deg( $_[0] ), 90 - rad2deg( $_[1] ) }
my @lonlat = SWNE(@M);

o aproximadamente 69 N 89 E, en la Meseta de Putorana de Siberia.

NOTA: no puede ir de A a B de esta manera:

Dist = great_circle_distance(A, B)
Dir  = great_circle_direction(A, B)
C    = great_circle_destination(A, Dist, Dir)

y esperar que C sea B, porque el rumbo cambia constantemente al ir de A a B (excepto en algunos casos especiales como los meridianos o los círculos de latitud) y en great_circle_destination() se proporciona un rumbo constante a seguir.
