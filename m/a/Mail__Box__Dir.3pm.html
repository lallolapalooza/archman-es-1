NOMBRE

Mail::Box::Dir - maneja carpetas con un archivo por mensaje.

HERENCIA

Mail::Box::Dir
  es un Mail::Box
  es un Mail::Reporter
Mail::Box::Dir es extendido por
  Mail::Box::MH
  Mail::Box::Maildir

SINOPSIS

# No instanciar este objeto

DESCRIPCION

Esta documentación describe la forma en que funcionan los buzones de correo organizados en directorios. Por el momento, este objeto es extendido por

  • Mail::Box::MH

    Carpetas MH, que se representan mediante un directorio que contiene archivos numerados secuencialmente.

  • Mail::Box::Maildir

    Carpetas Maildir, que se encuentran en un directorio con subdirectorios llamados "tmp", "new" y "cur". Cada uno de estos directorios puede contener archivos con nombres que son una combinación de una marca de tiempo numérica y algunas banderas de estado.

  • Mail::Box::Netzwert

    Este tipo de carpeta fue desarrollado especialmente para Netzwert AG, optimizado para ejecutarse en un clúster de servidores con carpetas en NFS. El código no está disponible públicamente (todavía).

DIAGNÓSTICOS

Advertencia: Cambios no escritos en la carpeta de solo lectura $self.
Ha abierto la carpeta en modo de solo lectura --que es el predeterminado establecido por new(access)--, ha realizado modificaciones y ahora desea cerrarla. Establezca close(force) si desea anular el modo de acceso, o cierre la carpeta con close(write) establecido en "NEVER". Emitido por close()
Error: Copia fallida para un mensaje.
Por alguna razón, por ejemplo disco lleno, eliminado por un proceso externo, o protección de lectura, es imposible copiar uno de los mensajes. La copia continuará para los demás mensajes. Emitido por copyTo()
Error: La carpeta de destino $name no es escribible.
La carpeta a la que se copian los mensajes no está abierta con acceso de escritura (ver new(access)). Esto no tiene relación con el permiso de escritura a la carpeta, que es controlado por su sistema operativo. Emitido por copyTo()
Advertencia: Diferentes mensajes con id $msgid
El id del mensaje se descubre más de una vez dentro de la misma carpeta, pero el contenido del mensaje parece ser diferente. Esto no debería ser posible: cada mensaje debe ser único. Emitido por messageId()
Error: La carpeta $name está abierta en modo de solo lectura
No puede escribir en esta carpeta a menos que la haya abierto para escribir o añadir con new(access), o que la opción "force" esté establecida en "true". Emitido por write()
Error: Carpeta $name no eliminada: no escribible.
La carpeta debe abrirse con acceso de escritura a través de new(access), de lo contrario se denegará su eliminación. Por lo tanto, puede tener acceso de escritura según el sistema operativo, pero eso no significará automáticamente que este método de "delete" se lo permita. La observación inversa también es válida. Emitido por delete()
Advertencia: El directorio de carpetas $directory está protegido contra escritura
Emitido por new()
Advertencia: El directorio de carpetas $directory está protegido contra escritura.
La carpeta $directory ya existe y está protegida contra escritura, lo que puede interferir con el acceso de escritura solicitado. Cambie new(access) o los permisos del directorio. Emitido por new()
Error: Se especificó un intervalo de tiempo no válido '$timespan'.
La cadena no sigue las reglas estrictas de la sintaxis del intervalo de tiempo que está permitido como parámetro. Emitido por timespan2seconds()
Advertencia: El ID de mensaje '$msgid' no contiene un dominio.
De acuerdo con las RFC, los ID de mensaje deben contener una parte aleatoria única, luego un "@", y luego un nombre de dominio. Esto se hace para evitar la creación de dos mensajes con el mismo ID. La advertencia surge cuando falta el "@" en la cadena. Emitido por

DIAGNOSTICS

Warning: No directory $name for folder of $class
Lanzado por new()
Error: Package $package does not implement $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, pero la clase en cuestión no. Probablemente deberías investigar esto y, posiblemente, informar al autor del paquete. Lanzado por notImplemented()
Error: Unable to create subfolder $name of $folder.
La copia incluye las subcarpetas, pero por alguna razón no fue posible copiar una de ellas. La copia continuará para todas las demás subcarpetas. Lanzado por copyTo()
Error: Writing folder $name failed
Por alguna razón (probablemente obtuviste más mensajes de error sobre este problema) es imposible escribir la carpeta, aunque deberías poder hacerlo porque se realizaron cambios. Lanzado por write()
