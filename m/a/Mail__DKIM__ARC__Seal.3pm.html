NOMBRE

Mail::DKIM::ARC::Seal - representa una cabecera ARC-Seal

VERSIÓN

versión 1.20240923

CONSTRUCTORES

new() - crea una nueva firma a partir de parámetros

my $signature = Mail::DKIM::ARC::Seal->new(
                    [ Algorithm => 'rsa-sha256', ]
                    [ Signature => $base64, ]
                    [ Domain => 'example.org', ]
                    [ Instance => 1, ]
                    [ Chain => 'none', ] # none|fail|pass
                    [ Query => 'dns', ]
                    [ Selector => 'alpha', ]
                    [ Timestamp => time(), ]
                    [ Expiration => time() + 86400, ]
                );

El ARC-Seal es similar a una firma DKIM pero con los siguientes cambios:

https://tools.ietf.org/html/draft-ietf-dmarc-arc-protocol-06

5.1.1.1. Etiquetas en el valor del campo de cabecera ARC-Seal

Las siguientes etiquetas son las únicas etiquetas admitidas para un campo ARC-Seal.
Todas ellas DEBEN estar presentes. Las etiquetas desconocidas DEBEN ignorarse y no
afectan la validez de la cabecera.
o  a = algoritmo de hash; la sintaxis es la misma que la etiqueta "a=" definida en
   la Sección 3.5 de [RFC6376];
o  b = firma digital; la sintaxis es la misma que la etiqueta "b=" definida
   en la Sección 3.5 de [RFC6376];
o  cv = estado de validación de la cadena: valores válidos:
   *  'none' = no hay cadena preexistente;
   *  'fail' = la cadena recibida no valida o no puede validar; o
   *  'pass' = la cadena recibida es válida.
o  d = dominio para la clave; la sintaxis es la misma que la etiqueta "d=" definida en
   la Sección 3.5 de [RFC6376];
o  i = "instancia" o número de secuencia; debe aumentar monotónicamente en cada
   entidad de "sellado", comenzando con '1', consulte la Sección 5.1.1.1.1
   con respecto al rango válido
o  s = selector para la clave; la sintaxis es la misma que la etiqueta "s=" definida
   en la Sección 3.5 de [RFC6376];
o  t = marca de tiempo; la sintaxis es la misma que la etiqueta "t=" definida
   en la Sección 3.5 de [RFC6376].

chain() - obtener o establecer el parámetro de cadena (cv=)

Debe ser uno de "pass", "fail" o "none". Para que una cadena sea válida, el primer sello (i=1) DEBE ser cv=none, y todos los sellos posteriores DEBEN ser cv=pass.

instance() - obtener o establecer el campo de instancia de firma (i=)

my $i = $signature->instance;

Las instancias deben ser enteros menores que 1024 según la especificación.

VER TAMBIÉN

Mail::DKIM::Signature para cabeceras DKIM-Signature

Mail::DKIM::ARC::MessageSignature para cabeceras ARC-Message-Signature
