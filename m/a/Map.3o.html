Tablas de asociación sobre tipos ordenados.

Este módulo implementa tablas de asociación aplicativas, también conocidas como mapas finitos o diccionarios, dadas una función de ordenación total sobre las claves. Todas las operaciones sobre mapas son puramente aplicativas (sin efectos secundarios). La implementación utiliza árboles binarios equilibrados, y por lo tanto la búsqueda y la inserción tardan un tiempo logarítmico en el tamaño del mapa.

Por ejemplo:

     module IntPairs =
       struct
         type t = int * int
         let compare (x0,y0) (x1,y1) =
           match Stdlib.compare x0 x1 with
               0 -> Stdlib.compare y0 y1
             | c -> c
       end
     module PairsMap = Map.Make(IntPairs)
     let m = PairsMap.(empty |> add (0,1) "hello" |> add (1,0) "world")

Esto crea un nuevo módulo PairsMap, con un nuevo tipo 'a PairsMap.t de mapas de int * int a 'a. En este ejemplo, m contiene valores string por lo que su tipo es string PairsMap.t.
