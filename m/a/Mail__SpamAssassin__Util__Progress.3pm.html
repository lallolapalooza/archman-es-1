NOMBRE

Mail::SpamAssassin::Util::Progress - Soporte de barra de progreso para SpamAssassin

SINOPSIS

my $progress = Mail::SpamAssassin::Util::Progress->new({total => 100});
$msgcount = 0;
foreach my $message (@messages) {
  # hacer algo aquí
  $msgcount++;
  $progress->update($msgcount);
}
$progress->final();

DESCRIPCIÓN

Este módulo implementa una barra de progreso para su uso en scripts y módulos de SpamAssassin. Te permite crear la barra de progreso, actualizarla e imprimir los resultados finales de una ejecución particular.

new

public class (Mail::SpamAssassin::Util::Progress) new (\% $args)

Descripción: Crea un nuevo objeto Mail::SpamAssassin::Util::Progress, los valores válidos para el hashref $args son:

total (requerido)
El número total de mensajes que se espera procesar. Este elemento es requerido.
fh [opcional]
Se puede pasar un manejador de archivo opcional, de lo contrario, se usará STDERR por defecto.
term [opcional]
El módulo intentará determinar si existe una terminal válida en el manejador de archivo STDIN. Este elemento te permite anular ese valor.

init_bar

public instance () init_bar()

Descripción: Este método crea la barra de progreso inicial y se llama automáticamente desde new. Además, puedes llamar a init_bar en un objeto existente para restablecer la barra a su estado original.

update

public instance () update ([Integer $num_done])

Descripción: Este método es el que se llama para actualizar la barra de progreso. Opcionalmente puedes pasar un valor entero que indica cuántos mensajes se han procesado. Si no pasas nada, el valor de num_done se incrementará en uno.

final

public instance () final ([Integer $num_done])

Descripción: Este método debe llamarse una vez que todo el procesamiento haya finalizado. Imprimirá el cálculo final de mensajes por segundo y el tiempo total transcurrido. Opcionalmente puedes pasar un valor de num_done, de lo contrario, utilizará el valor calculado a partir de la última llamada a update.
