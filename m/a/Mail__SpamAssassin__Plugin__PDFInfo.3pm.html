Mail::SpamAssassin::Plugin::PDFInfo - Plugin PDFInfo para SpamAssassin

SINOPSIS

loadplugin     Mail::SpamAssassin::Plugin::PDFInfo

DESCRIPCIÓN

Este plugin ayuda a detectar spam utilizando archivos PDF adjuntos

Plugin PDFInfo para SpamAssassin
Versión: 0.8
Info: $Id: PDFInfo.pm 904 2007-08-12 01:36:23Z root $
Creado: 2007-08-10
Modificado: 2007-08-10
Por: Dallas Engelken
Cambios:
  0.8 - añadido detección de .fdf (gracias John Lundin) [axb]
  0.7 - corregido buglet de recuento de cuerpo/pdf vacío (gracias Jeremy) [axb]
  0.6 - añadido soporte para etiquetas - PDFCOUNT, PDFVERSION, PDFPRODUCER, etc.
      - corregido problema en perl 5.6.1 donde pdf_match_details() no llamaba
        a _find_pdf_mime_parts(), resultando en ninguna detección de partes mime de pdf.
      - soporte quoted-printable - requiere MIME::QuotedPrint (que debería estar en la instalación de todos
        como parte del paquete MIME-Base64 que es un requisito de SA)
      - añadida función simple pdf_is_empty_body() que cuenta los bytes del cuerpo menos la
        línea de asunto. Puede añadir un parámetro opcional <bytes> si necesita permitir unos pocos bytes.
  0.5 - corregir advertencias para undef $pdf_tags
      - eliminar { } y \ antes de ejecutar eval en pdf_match_details para evitar errores de eval
  0.4 - añadida función pdf_is_encrypted()
      - añadido opción para buscar HxW de imagen en la misma línea
  0.3 - añadido segundo md5 difuso que utiliza el diseño de etiquetas pdf como datos
      - renombrada pdf_image_named() a pdf_named()
         - Las imágenes PDF están encapsuladas y no tienen nombres. Estamos comparando el nombre del archivo PDF.
      - renombrada pdf_image_name_regex() a pdf_name_regex()
         - Las imágenes PDF están encapsuladas y no tienen nombres. Estamos comparando el nombre del archivo PDF.
      - cambiado pdf_image_count() un poco y añadido pdf_count().
         - pdf_count() comprueba cuántos adjuntos pdf hay en el correo
         - pdf_image_count() comprueba cuántas imágenes se encuentran dentro de todos los pdf en el correo.
      - eliminado la restricción de que el pdf contenga una imagen para hacerle md5.
      - añadida función pdf_match_details() para comprobar los siguientes 'detalles'
         - author: Autor del PDF si se especifica
         - producer: Software utilizado para producir el PDF
         - creator: Software utilizado para producir el PDF, generalmente similar al producer
         - title: Título del PDF
         - created: Fecha de creación
         - modified: Última modificación
  0.2 - soporte para octet-stream PDF
  0.1 - solo se portó el código de imageinfo, y se renombró a pdfinfo.
        - se eliminó todo el soporte para png, gif y jpg del código.
        - se antepuso pdf_ a todos los nombres de función para evitar conflictos con ImageInfo en SA 3.2.
Uso:
 pdf_count()
    body RULENAME  eval:pdf_count(<min>,[max])
       min: requerido, el mensaje contiene al menos x partes mime de pdf
       max: opcional, si se especifica, no debe contener más de x partes mime de pdf
 pdf_image_count()
    body RULENAME  eval:pdf_image_count(<min>,[max])
       min: requerido, el mensaje contiene al menos x imágenes en adjuntos pdf.
       max: opcional, si se especifica, no debe contener más de x imágenes pdf
 pdf_pixel_coverage()
    body RULENAME  eval:pdf_pixel_coverage(<min>,[max])
       min: requerido, el mensaje contiene al menos esta área de píxeles
       max: opcional, si se especifica, el mensaje no debe contener más de esta área de píxeles
 pdf_named()
    body RULENAME  eval:pdf_named(<string>)
       string: coincidencia exacta del nombre del archivo, si necesitas coincidencia parcial, consulta pdf_name_regex()
 pdf_name_regex()
    body RULENAME  eval:pdf_name_regex(<regex>)
       regex: expresión regular, consulta los ejemplos en el conjunto de reglas
 pdf_match_md5()
    body RULENAME  eval:pdf_match_md5(<string>)
       string: md5 hexadecimal de 32 bytes
 pdf_match_fuzzy_md5()
    body RULENAME  eval:pdf_match_md5(<string>)
       string: md5 hexadecimal de 32 bytes - consulta el conjunto de reglas para obtener el md5 difuso
 pdf_match_details()
    body RULENAME  eval:pdf_match_details(<detail>,<regex>);
       detail: author, creator, created, modified, producer, title
       regex: expresión regular, consulta los ejemplos en el conjunto de reglas
 pdf_is_encrypted()
    body RULENAME eval:pdf_is_encrypted()
 pdf_is_empty_body()
    body RULENAME eval:pdf_is_empty_body(<bytes>)
       bytes: recuento máximo de bytes a permitir y aún considerarlo vacío
 pdf_image_to_text_ratio()
    body RULENAME eval:pdf_image_to_text_ratio(<min>,<max>)
       Ratio calculado como longitud_cuerpo / área_total_imagen
       min: ratio mínimo
       max: ratio máximo
 pdf_image_size_exact()
    body RULENAME eval:pdf_image_size_exact(<h>,<w>)
       h: la altura de la imagen es exactamente h
       w: el ancho de la imagen es exactamente w
 pdf_image_size_range()
    body RULENAME eval:pdf_image_size_range(<minh>,<minw>,[<maxh>],[<maxw>])
       minh: la altura de la imagen es al menos minh
       minw: el ancho de la imagen es al menos minw
       maxh: (opcional) la altura de la imagen no es mayor que maxh
       maxw: (opcional) el ancho de la imagen no es mayor que maxw
 NOTA: Consulta el conjunto de reglas para ver más ejemplos que no están documentados aquí.
