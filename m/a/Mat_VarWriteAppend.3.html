Mat_VarWriteAppend(3)

Paquete: libmatio

Licencias: BSD-2-Clause

MAT_VARWRITEAPPEND(3) Manual de Funciones de Biblioteca MAT_VARWRITEAPPEND(3)

NOMBRE

Mat_VarWriteAppend — Escribe/añade una variable MATLAB a un archivo MAT en formato HDF5.

SINOPSIS

#include <matio.h>

int
Mat_VarWriteAppend(mat_t *matfp, matvar_t *matvar, enum matio_compression compress, int dim);

DESCRIPCIÓN

La función Mat_VarWriteAppend() escribe (y opcionalmente añade) la variable MATLAB matvar al archivo MAT matfp, el cual debe haber sido abierto para escritura. Si la variable MATLAB ya existe en el archivo MAT, los nuevos datos se añaden a esta variable a lo largo de la dimensión d (basada en índice 1). La opción compress permite que la variable se escriba usando compresión zlib si está disponible. Si la compresión no está disponible, la variable se escribe sin comprimir.

VALORES DE RETORNO

La función devuelve 0 si la variable se escribió/añadió exitosamente al archivo MAT. De lo contrario, se devuelve un valor de error.

EJEMPLOS

Este programa de ejemplo crea un archivo MAT cuyo nombre se proporciona como primer argumento del programa y escribe la variable llamada m_pi en el archivo para construir un array de 2x1.

#include <math.h>
#include "matio.h"

int
main(int argc, char **argv)
{
    mat_t    *matfp;
    matvar_t *matvar;
    size_t    dims[2] = {1, 1};
    double    m_pi = M_PI;

    matfp = Mat_CreateVer(argv[1], NULL, MAT_FT_MAT73);
    if ( NULL == matfp ) {
        fprintf(stderr, "Error creating MAT file %s0, argv[1]);
        return EXIT_FAILURE;
    }

    matvar = Mat_VarCreate("m_pi", MAT_C_DOUBLE, MAT_T_DOUBLE,
                           2, dims, &m_pi, 0);
    if ( NULL != matvar ) {
        int dim = 1;
        Mat_VarWriteAppend(matfp, matvar, MAT_COMPRESSION_ZLIB, dim);
        Mat_VarWriteAppend(matfp, matvar, MAT_COMPRESSION_ZLIB, dim);
        Mat_VarFree(matvar);
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
