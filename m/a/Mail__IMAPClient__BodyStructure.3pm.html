Mail__IMAPClient__BodyStructure(3pm)

Mail::IMAPClient::BodyStructure(3) Documentación de contribuciones de Perl Mail::IMAPClient::BodyStructure(3)

NOMBRE

Mail::IMAPClient::BodyStructure - parse fetched results

SINOPSIS

use Mail::IMAPClient;
use Mail::IMAPClient::BodyStructure;
my $imap = Mail::IMAPClient->new(
    Server => $server, User => $login, Password => $pass
);
$imap->select("INBOX") or die "Could not select INBOX: $@\n";
my @recent = $imap->search("recent") or die "No recent msgs in INBOX\n";
foreach my $id (@recent) {
    my $bsdat = $imap->fetch( $id, "bodystructure" );
    my $bso   = Mail::IMAPClient::BodyStructure->new( join("", $imap->History) );
    my $mime  = $bso->bodytype . "/" . $bso->bodysubtype;
    my $parts = map( "\n\t" . $_, $bso->parts );
    print "Msg $id (Content-type: $mime) contains these parts:$parts\n";
}

DESCRIPCIÓN

Esta extensión parseará los resultados de un comando FETCH BODYSTRUCTURE en una estructura de datos de Perl. También proporciona métodos de ayuda para extraer información de esta estructura.

Este módulo requiere Parse::RecDescent.

Métodos de clase

El siguiente método de clase está disponible:

new

Este método de clase es el constructor para instanciar objetos Mail::IMAPClient::BodyStructure. El método new acepta un argumento, una cadena que contiene una respuesta del servidor a un comando FETCH BODYSTRUCTURE.

El módulo Mail::IMAPClient proporciona el método de conveniencia get_bodystructure para facilitar el uso de este módulo cuando se empieza con solo un número de secuencia de mensaje o un identificador único (UID).

Métodos de objeto

Los siguientes métodos de objeto están disponibles:

bodytype

El método bodytype del objeto no requiere argumentos. Devuelve el tipo de cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodysubtype

El método bodysubtype del objeto no requiere argumentos. Devuelve el subtipo de cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodyparms

El método bodyparms del objeto no requiere argumentos. Devuelve los parámetros del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodydisp

El método bodydisp del objeto no requiere argumentos. Devuelve la disposición del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodyid

El método bodyid del objeto no requiere argumentos. Devuelve el ID del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodydesc

El método bodydesc del objeto no requiere argumentos. Devuelve la descripción del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodyenc

El método bodyenc del objeto no requiere argumentos. Devuelve la codificación del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodysize

El método bodysize del objeto no requiere argumentos. Devuelve el tamaño del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodylang

El método bodylang del objeto no requiere argumentos. Devuelve el idioma del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

bodystructure

El método bodystructure del objeto no requiere argumentos. Devuelve la estructura del cuerpo para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

envelopestruct

El método envelopestruct del objeto no requiere argumentos. Devuelve un objeto Mail::IMAPClient::BodyStructure::Envelope para el mensaje del que se invoca el objeto Mail::IMAPClient::BodyStructure.

textlines

El método textlines del objeto no requiere argumentos. Devuelve las líneas de texto para el mensaje cuya estructura se describe por el objeto Mail::IMAPClient::BodyStructure invocado.

Mail::IMAPClient::BodyStructure::Envelope

El estándar IMAP especifica que la salida del comando FETCH ENVELOPE será una estructura de correo RFC2060. Además, especifica que la salida del comando FETCH BODYSTRUCTURE también puede contener estructuras de correo incrustadas (si, por ejemplo, las subpartes de un mensaje contienen uno o más mensajes incrustados). Los objetos que pertenecen a Mail::IMAPClient::BodyStructure::Envelope son representaciones de Perl de estas estructuras de correo, es decir, listas anidadas de estructuras RFC2060 traducidas a una estructura de datos de Perl.

Nota: Todos los campos se refieren a la parte específica a la que pertenecen. En otras palabras, la salida de un comando FETCH nnnn ENVELOPE (o, en Mail::IMAPClient, $imap->fetch($msgid, "ENVELOPE") o my $env = $imap->get_envelope($msgid)) se refiere al mensaje, pero los campos dentro de una estructura de cuerpo se refieren al submensaje y no al mensaje principal.

La representación de Mail::IMAPClient::BodyStructure::Envelope es un hash de elementos que se ve así:

{
   subject   => "asunto",
   inreplyto => "id_mensaje_referencia",
   from      => [ addressStruct1 ],
   messageid => "id_mensaje",
   bcc       => [ addressStruct1, addressStruct2 ],
   date      => "Mar, 09 Jul 2002 14:15:53 -0400",
   replyto   => [ addressStruct1, addressStruct2 ],
   to        => [ addressStruct1, addressStruct2 ],
   sender    => [ addressStruct1 ],
   cc        => [ addressStruct1, addressStruct2 ],
}

El objeto Mail::IMAPClient::BodyStructure::Envelope también tiene métodos para acceder a los datos de la estructura. Estos métodos son:

date
Devuelve la fecha del mensaje.
inreplyto
Devuelve el ID del mensaje al que responde este mensaje.
subject
Devuelve el asunto del mensaje.
messageid
Devuelve el ID del mensaje.

También puedes usar los siguientes métodos para obtener información de direcciones. Cada uno de estos métodos devuelve un array de objetos Mail::IMAPClient::BodyStructure::Address, que son estructuras de datos de Perl que representan direcciones RFC2060. Algunos de estos arrays contienen un solo elemento (como el campo from, que normalmente contiene una sola dirección "From:"); otros contendrán más de una dirección. Sin embargo, dado que RFC2060 define todos estos como "listas de estructuras de dirección", se traducen a arrays de objetos Mail::IMAPClient::BodyStructure::Address.

Ver la sección sobre Mail::IMAPClient::BodyStructure::Envelope.

Mail::IMAPClient::BodyStructure::Envelope

Mail::IMAPClient::Envelope tiene los siguientes métodos disponibles:

date
Retorna la fecha y hora en que se envió el mensaje.
message_id
Retorna el id del mensaje.
references
Retorna una lista de los ids de los mensajes a los que este mensaje hace referencia.
envelope
Retorna una referencia a un hash que contiene todos los campos del sobre del mensaje. No es recomendable usar esto, ya que los otros métodos son más amigables.

Además, el sobre contendrá referencias a los datos de los destinatarios y remitentes, que son objetos de tipo Mail::IMAPClient::BodyStructure::Address. Para obtener una lista de las direcciones, puede usar los métodos que se describen a continuación.

Para obtener una lista de los objetos de dirección completos, puede acudir a la estructura de datos subyacente, Mail::IMAPClient::BodyStructure::Address, a continuación, para acceder a formas alternativas (y preferidas) de acceder a estos datos.

Los métodos disponibles son:

bcc
Retorna un array de estructuras de direcciones de los destinatarios ocultos (cc oculto). (Por cierto, no esperes mucho aquí a menos que el mensaje se haya enviado desde el buzón en el que estás investigando.)
cc
Retorna un array de estructuras de direcciones de los destinatarios cc.
from
Retorna un array de estructuras de direcciones de "De:" - usualmente solo uno.
replyto
Retorna un array de estructuras de direcciones de "Responder a:". Una vez más, usualmente solo hay una dirección en la lista.
sender
Retorna un array de estructuras de direcciones de los remitentes - usualmente solo uno y usualmente el mismo que from.
to
Retorna un array de estructuras de direcciones de los destinatarios.

Cada uno de los métodos que retorna una lista de estructuras de direcciones (es decir, una lista de arrays de Mail::IMAPClient::BodyStructure::Address) también tiene un método análogo que retornará una lista de direcciones de correo electrónico en su lugar. Las direcciones están en el formato "nombrepersonal <nombredebuszon@dominio>" (ver la sección sobre Mail::IMAPClient::BodyStructure::Address, a continuación) Sin embargo, si el nombre personal es 'NIL', se omite de la dirección.

Estos métodos son:

bcc_addresses
Retorna una lista (o una referencia a un array si se llama en contexto escalar) de direcciones de correo electrónico de los destinatarios ocultos (cc oculto). (Por cierto, no esperes mucho aquí a menos que el mensaje se haya enviado desde el buzón en el que estás investigando.)
cc_addresses
Retorna una lista de direcciones de correo electrónico de los destinatarios cc. Si se llama en un contexto escalar, retorna una referencia a un array de direcciones de correo electrónico.
from_addresses
Retorna una lista de direcciones de correo electrónico de "De:". Si se llama en un contexto escalar, retorna la primera dirección de correo electrónico de la lista. (Usualmente es una lista de solo una de todos modos.)
replyto_addresses
Retorna una lista de direcciones de correo electrónico de "Responder a:". Si se llama en un contexto escalar, retorna la primera dirección de correo electrónico de la lista.
sender_addresses
Retorna una lista de direcciones de correo electrónico de los remitentes. Si se llama en un contexto escalar, retorna la primera dirección de correo electrónico de la lista.
to_addresses
Retorna una lista de direcciones de correo electrónico de los destinatarios. Si se llama en un contexto escalar, retorna una referencia a un array de direcciones de correo electrónico.

Tenga en cuenta que el contexto afecta el comportamiento de todos los métodos anteriores.

Aquellos campos que comúnmente contendrán múltiples entradas (es decir, son destinatarios) retornarán una referencia a un array cuando se llamen en contexto escalar. Puede usar este comportamiento para optimizar el rendimiento.

Aquellos campos que comúnmente contendrán solo una dirección (la del remitente) retornarán la primera (y usualmente única) dirección. Puede usar este comportamiento para optimizar su tiempo de desarrollo.

Direcciones y Mail::IMAPClient::BodyStructure::Address

Varios componentes de una estructura de sobre son estructuras de dirección. Cada uno se analiza en su propio objeto, Mail::IMAPClient::BodyStructure::Address, que se ve así:

{
   mailboxname  => 'alguien.especial',
   hostname     => 'algunlugar.raro.com'
   personalname => 'Alguien Especial
   sourceroute  => 'NIL'
}

RFC2060 especifica que cada componente de dirección de una estructura de cuerpo es una lista de estructuras de dirección, por lo que Mail::IMAPClient::BodyStructure analiza cada una de estas en un array de objetos Mail::IMAPClient::BodyStructure::Address.

Cada uno de estos objetos tiene los siguientes métodos disponibles para él:

mailboxname
Retorna la porción "nombredebuszon" de la dirección, que es la parte a la izquierda del signo '@'.
hostname
Retorna la porción "dominio" de la dirección, que es la parte a la derecha del signo '@'.
personalname
Retorna la porción "nombrepersonal" de la dirección, que es la parte de la dirección que se trata como un comentario.
sourceroute
Retorna la porción "ruta de origen" de la dirección, que típicamente es "NIL".

En conjunto, las partes de una estructura de dirección forman una dirección que se verá algo así:

"nombrepersonal <nombredebuszon@dominio>"

Tenga en cuenta que dado que los objetos Mail::IMAPClient::BodyStructure::Address vienen en arrays, generalmente es más fácil usar los métodos disponibles para Mail::IMAPClient::BodyStructure::Envelope para obtener todas las direcciones en un array particular en una operación. Sin embargo, estos métodos se proporcionan en caso de que prefiera hacer las cosas de la manera difícil. (Y también porque los métodos antes mencionados de Mail::IMAPClient::BodyStructure::Envelope los necesitan de todos modos).
