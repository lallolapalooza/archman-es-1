NOMBRE

Mail::Box::Locker::Flock - bloquea una carpeta usando bloqueos de archivos del kernel

HERENCIA

Mail::Box::Locker::Flock
  es un Mail::Box::Locker
  es un Mail::Reporter

SINOPSIS

Ver la interfaz genérica Mail::Box::Locker

DESCRIPCIÓN

El objeto "::Flock" bloquea la carpeta creando un bloqueo exclusivo en el archivo usando las instalaciones de bloqueo de archivos del kernel ("flock"). Este bloqueo se crea en un manejador de archivo separado del archivo de la carpeta, por lo que no es el manejador que está leyendo.

El bloqueo de archivos no funciona en algunas situaciones, por ejemplo, para sistemas operativos que no soportan "flock".

Extiende "DESCRIPTION" en Mail::Box::Locker.

DIAGNÓSTICOS

Advertencia: Carpeta $folder ya bloqueada
La carpeta $folder ya está bloqueada, pero intentas bloquearla de nuevo. El comportamiento de los bloqueos dobles depende de la plataforma y, por lo tanto, no debe intentarse. El segundo bloqueo se ignora (pero el desbloqueo no). Lanzado por lock()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas sí implementan este método, sin embargo, la clase en cuestión no lo hace. Probablemente deberías investigar esto y, posiblemente, informar al autor del paquete. Lanzado por notImplemented()
Error: No se puede comprobar el archivo de bloqueo $filename para $folder: $!
Para comprobar si el $filename se utiliza para "flock" una $folder, el archivo debe abrirse. Aparentemente esto falla, lo que no significa que la carpeta esté bloqueada ni desbloqueada. Lanzado por isLocked()
Error: No se puede abrir el archivo de bloqueo $file para $folder: $!
Para "flock" una $folder, debe abrirse, lo cual no tiene éxito por la razón especificada. Lanzado por lock()
Error: Nunca se obtendrá un bloqueo en $file para $folder: $!
Se intentó "flock" la $folder, pero no tuvo éxito. El código de error recibido del sistema operativo indica que nunca tendrá éxito, por lo que no necesitamos volver a intentarlo. Lanzado por lock()
