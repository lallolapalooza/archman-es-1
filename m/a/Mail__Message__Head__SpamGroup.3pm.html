NOMBRE

Mail::Message::Head::SpamGroup - campos de encabezado relacionados con el combate contra el spam

HERENCIA

Mail::Message::Head::SpamGroup
  es una Mail::Message::Head::FieldGroup
  es una Mail::Reporter

SINOPSIS

my $sg = Mail::Message::Head::SpamGroup->new(head => $head, ...);
$head->addSpamGroup($sg);
my $sg = $head->addSpamGroup( <opciones> );
$sg->delete;
my @sgs = $head->spamGroups;

DESCRIPCION

Un grupo de spam es un conjunto de campos de encabezado que se agregan mediante software de detección y combate contra el spam. Esta clase conoce diversos detalles sobre ese software.

$any->fighter($name, %options)
Obtiene las configuraciones de un cierto spam-fighter, opcionalmente después de establecerlas. El método knownFighters() devuelve los nombres definidos. Los nombres son sensibles a mayúsculas y minúsculas.

Las %options son todas las pasadas como configuraciones al spamfilter, excepto las especificadas aquí específicamente.

-Opción --Predeterminada
 fields   <requerido>
 isspam   <requerido>
 version  undef
fields => REGEXP
La expresión regular que indica cuales de los campos de encabezado se agregan por el software de detección y combate contra el spam.
isspam => COD
El COD debe devolver "true" o "false", para indicar si el spamfighter piensa que el mensaje contiene spam. El COD ref se llama con el objeto de spamgroup (en construcción) y el encabezado que se inspecciona.
version => COD
Puede llamarse para recolectar el nombre oficial y la versión del software que se utiliza para detectar el spam. El COD ref se llama con el objeto de spamgroup (en construcción) y el encabezado que se inspecciona.

» ejemplo: agregando tus propias definiciones de spam-fighter

Mail::Message::Head::SpamGroup->fighter( 'MY-OWN',
   fields => qw/^x-MY-SPAM-DETECTOR-/,
   isspam => sub { my ($sg, $head) = @_; $head->fields > 100 },
);
$obj->from($head|$message, %options)
Devuelve una lista de objetos "Mail::Message::Head::SpamGroup", basada en el especificado $message o encabezado $head. Mejora la clase base, ver los constructores en Mail::Message::Head::FieldGroup 
-Opción--Predeterminada
 types   undef
types => ARRAY-OF-NAMES
Solo los tipos especificados serán probados. Si el ARRAY está vacío, se devuelve una lista vacía. Sin esta opción, se devuelven todos los conjuntos.
$any->habeasSweFieldsCorrect( [$message|$head] )
Devuelve un valor "true" si el $message o $head contiene encabezados "Habeas-SWE" que son correctos. Sin argumento, se utiliza como método de instancia en un Spam-Group existente.

» ejemplo: verificar encabezados Habeas-SWE

if(Mail::Message::Head::SpamGroup->habeasSweFieldsCorrect($message))
{   $message->label(spam => 0);
}
my $sg = $message->head->spamGroups('Habeas-SWE');
if($sg->habeasSweFieldsCorrect) { ... };
use List::Util 'first';
if(first {$_->habeasSweFieldsCorrect} $head->spamGroups)
{   ...
}

Mail::Message::Head::FieldGroup - Perl documentation

NAME

Mail::Message::Head::FieldGroup - collection of message header fields

INHERITANCE

Extends Mail::Message::Head::Field.

    Mail::Message::Head::Field
        Mail::Message::Head::FieldGroup

SYNOPSIS

  use Mail::Message::Head::FieldGroup;

  my $group = Mail::Message::Head::FieldGroup->new();
  my $field = $group->add(
      name  => 'X-Mailer',
      value => 'MyMailer/1.0',
  );
  $group->add(
      name  => 'Received',
      value => 'from host by otherhost with esmtp',
  );

  print $group->asString;
  # X-Mailer: MyMailer/1.0
  # Received: from host by otherhost with esmtp

  my $fields = $group->fields('X-Mailer');
  print $fields->[0]->value;
  # MyMailer/1.0

DESCRIPTION

This class represents a group of related header fields. For example, all Received: headers form a group.

It implements the list interface for the fields it contains.

METHODS

$obj->add( %args )
Adds a new field to the group. %args are passed to the Mail::Message::Head::Field constructor. Returns the created field.
$obj->fields( $name )
Returns a list of fields with the specified $name. The $name can be case-insensitive.
$obj->field( $name )
Returns the first field with the specified $name. Returns undef when no field is found.
$obj->remove( $field )
Removes the specified $field from the group.
$obj->clear()
Removes all fields from the group.
$obj->asString( [ $indent] )
Returns the group of fields as a string, formatted for a message header.
$obj->isEmpty()
Returns true when the group is empty.
