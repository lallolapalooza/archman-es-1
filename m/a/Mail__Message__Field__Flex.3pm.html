DESCRIPCION

Esta es la implementación flexible de un campo: se puede extender fácilmente porque almacena sus datos en un hash y el constructor ("new") y el inicializador ("init") están divididos. Sin embargo, pagas el precio en rendimiento. Mail::Message::Field::Fast es más rápido (como predice el nombre).

Si te ciñes a esta clase flexible de campos de encabezado, tienes un poco más de facilidades que con Mail::Message::Field::Fast. Entre ellas, puedes especificar opciones con la creación. Posibles argumentos:
  • new $line

    Pasa una $line tal como podría encontrarse en un archivo: una línea (posiblemente plegada) que termina con un salto de línea.

  • new $name, ($body|$object|\@objects), [@attributes], [\%options|\@options]

    Un conjunto de valores que dan forma a la línea.

Para poder distinguir los diferentes parámetros, tendrás que especificar las @options como ARREGLO de PARES de opciones, o HASH de %options. Los @attributes son una LISTA plana de PARES clave-valor. El $body se especifica como una cadena, un $object, o un ARREGLO de @objects. Ver Mail::Message::Field. Mejora la base, ver "Constructores" en Mail::Message::Field

Mail::Message::Field::Flex(3pm)

NAME

Mail::Message::Field::Flex - A flexible field implementation for Mail::Message

INHERITANCE

Extends Mail::Message::Field.

SYNOPSIS

  use Mail::Message::Field::Flex;

  my $field = Mail::Message::Field::Flex->new('Subject', 'Hello world');
  print $field->asString; # Subject: Hello world

DESCRIPTION

This is a simple implementation of a field for an e-mail message. It does not impose any specific structure on the field's content, making it suitable for fields that do not conform to a strict format, or when the exact format is not yet known.

DIAGNOSTICS

Warning: Field content is not numerical: $content
The numeric value of a field is requested (for instance the "Lines" or "Content-Length" fields should be numerical), however the data contains weird characters. Cast by toInt()
Error: Field name too long (max $length), in '$name'
It is not specified in the RFCs how long a field name can be, but at least it should be a few characters shorter than the line wrap. Cast by fold()
Warning: Illegal character in field name $name
A new field is being created which does contain characters not permitted by the RFCs. Using this field in messages may break other e-mail clients or transfer agents, and therefore mutulate or extinguish your message. Cast by consume()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
