MAT_GETVERSION(3) Manual de Funciones de Biblioteca MAT_GETVERSION(3)

NOMBRE

Mat_GetVersion — Devuelve la versión de un archivo MAT de MATLAB dada una estructura de archivo MAT.

SINOPSIS

#include <matio.h>

enum mat_ft
Mat_GetVersion(const mat_t *matfp);

DESCRIPCIÓN

La función Mat_GetVersion() devuelve la versión del archivo MAT de MATLAB dado por la estructura del archivo MAT.

VALORES DE RETORNO

El valor de retorno es uno de los siguientes:

  • MAT_FT_MAT4 si el archivo es un archivo MAT versión 4.
  • MAT_FT_MAT5 si el archivo es un archivo MAT versión 5.
  • MAT_FT_MAT73 si el archivo es un archivo MAT HDF5.
