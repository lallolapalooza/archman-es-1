Mail::SPF::MacroString(3) Documentación de Perl aportada por el usuario Mail::SPF::MacroString(3)

NOMBRE

Mail::SPF::MacroString - Clase para cadenas de macros SPF

VERSIÓN

versión 3.20250505

SINOPSIS

Proporcionar el contexto de expansión temprano

use Mail::SPF::MacroString;
my $macrostring = Mail::SPF::MacroString->new(
    text    => '%{ir}.%{v}._spf.%{d2}',
    server  => $server,
    request => $request
);
my $expanded = $macrostring->expand;

Proporcionar el contexto de expansión tardíamente

use Mail::SPF::MacroString;
my $macrostring = Mail::SPF::MacroString->new(
    text    => '%{ir}.%{v}._spf.%{d2}'
);
my $expanded1 = $macrostring->expand($server, $request1);
$macrostring->context($server, $request2);
my $expanded2 = $macrostring->expand;

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::MacroString representa una cadena de macros que puede ser expandida a una cadena simple en el contexto de una solicitud SPF.

Constructor

Se proporciona el siguiente constructor:

new(%opciones): devuelve Mail::SPF::MacroString
Crea un nuevo objeto de cadena de macros de registro SPF.

%opciones es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

text
Requerido. El texto sin expandir de la nueva cadena de macros.
servidor
El objeto Mail::SPF::Server que se utilizará al expandir la cadena de macros. No es necesario adjuntar un objeto de servidor estáticamente a la cadena de macros; se puede especificar dinámicamente al llamar al método "expand".
solicitud
El objeto Mail::SPF::Request que se utilizará al expandir la cadena de macros. No es necesario adjuntar un objeto de solicitud estáticamente a la cadena de macros; se puede especificar dinámicamente al llamar al método "expand".
es_explicacion
Un *booleano* que indica si la cadena de macros es una cadena de explicación obtenida a través de un modificador "exp". Si es verdadero, las macros "c", "r" y "t" pueden aparecer en la cadena de macros, de lo contrario no pueden, y si lo hacen, se lanzará una excepción Mail::SPF::EInvalidMacro cuando se expanda la cadena de macros. Por defecto es falso.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

text: devuelve cadena
Devuelve el texto sin expandir de la cadena de macros.
contexto($servidor, $solicitud): lanza Mail::SPF::EOptionRequired
Adjunta los objetos Mail::SPF::Server y Mail::SPF::Request dados como contexto para la cadena de macros.
expandir: devuelve cadena; lanza Mail::SPF::EMacroExpansionCtxRequired, Mail::SPF::EInvalidMacroString, Mail::SPF::Result::PermError
expandir($servidor, $solicitud): devuelve cadena; lanza Mail::SPF::EMacroExpansionCtxRequired, Mail::SPF::EInvalidMacroString, Mail::SPF::Result::PermError
Expande el texto de la cadena de macros utilizando el contexto especificado a través de una llamada anterior al método contexto(), o el contexto dado, y devuelve la cadena resultante. Ver RFC 4408, 8, sobre cómo se expanden las macros.
es_explicacion: devuelve booleano
Devuelve verdadero si la cadena de macros es una cadena de explicación obtenida a través de un modificador "exp". Ver la descripción de la opción "es_explicacion" del constructor "new".
stringify: devuelve cadena
Devuelve el texto expandido de la cadena de macros si hay un contexto adjunto al objeto. Devuelve el texto sin expandir en caso contrario. Simplemente puede usar un objeto Mail::SPF::MacroString como cadena para el mismo efecto, ver "SOBRECARGA".

SOBRECARGA

Si un objeto Mail::SPF::MacroString se utiliza como una *cadena*, se utiliza el método "stringify" para convertir el objeto en una cadena.
