NOMBRE

Mail::Message::TransferEnc - codificador/decodificador de transferencia de mensajes

HERENCIA

Mail::Message::TransferEnc
  es un Mail::Reporter
Mail::Message::TransferEnc es extendido por
  Mail::Message::TransferEnc::Base64
  Mail::Message::TransferEnc::Binary
  Mail::Message::TransferEnc::EightBit
  Mail::Message::TransferEnc::QuotedPrint
  Mail::Message::TransferEnc::SevenBit

SINOPSIS

my Mail::Message $msg = ...;
my $decoded = $msg->decoded;
my $encoded = $msg->encode(transfer => 'base64');

DESCRIPCIÓN

Esta clase es la base para varios codificadores y decodificadores, que se utilizan durante el transporte del mensaje. Estos paquetes, y todos los que se derivan, son invocados por los métodos Mail::Message::decoded() y Mail::Message::encode() del mensaje:

my $message = $folder->message(3);
my $decoded_body = $message->decoded;
my $encoded_body = $message->encode(transfer => 'base64');

Las reglas para las codificaciones de transferencia se especifican en RFC4289. La lista completa de codificaciones de transferencia de contenido permisibles se puede encontrar en https://www.iana.org/assignments/transfer-encodings/transfer-encodings.xhtml

Los siguientes codificadores/decodificadores son compatibles actualmente (abril de 2025, la lista completa en IANA):

  • Mail::Message::TransferEnc::Base64

    "base64" para información binaria.

  • Mail::Message::TransferEnc::SevenBit

    "7bit" solo para caracteres ASCII.

  • Mail::Message::TransferEnc::EightBit

    "8bit" para datos de conjuntos de caracteres extendidos, no codificados.

  • Mail::Message::TransferEnc::QuotedPrint

    "quoted-printable" datos de conjuntos de caracteres extendidos codificados.

2025-11-28 Mail::Message::TransferEnc(3pm)

NAME

Mail::Message::TransferEnc - represent MIME transfer encodings

INHERITANCE

Mail::Message::TransferEnc is a subclass of Mail::Message.

SYNOPSIS


use Mail::Message::TransferEnc;

my $te = Mail::Message::TransferEnc->new(
    type     => 'quoted-printable',
    encoding => 'UTF-8',
);

print $te->type, "\n";
print $te->encoding, "\n";

DESCRIPTION

This is an abstract class. It represents the MIME transfer encoding. The transfer encoding is a property of a Mail::Message object, and is part of its meta-data. The transfer encoding defines how the body content is encoded before it is sent over the wire.

METHODS

  • type()

    Returns the name of the transfer encoding used. Examples: '7bit', '8bit', 'quoted-printable', 'base64'.

  • encoding()

    Returns the character encoding of the body content. This is typically 'UTF-8' or 'US-ASCII'. This information is used to select the correct decoder.
