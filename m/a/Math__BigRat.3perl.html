NOMBRE

Math::BigRat - paquete de matemáticas de números racionales de tamaño arbitrario

DESCRIPCIÓN

Math::BigRat complementa Math::Bi

DESCRIPCIÓN

Este módulo implementa números racionales con precisión arbitraria (fracciones). Funciona como Math::BigFloat, pero todos los resultados de las operaciones se mantienen como racionales, es decir, las divisiones no se redondean sino que se dejan como fracciones.

Por ejemplo, si se suman Math::BigInt y Math::BigFloat, el resultado es un Math::BigFloat. Si se suman dos Math::BigFloat, el resultado es un Math::BigFloat.

En el caso de Math::BigRat:

  * sumar/restar/multiplicar un entero con un racional resulta en un racional.
  * dividir un entero por un racional resulta en un racional.
  * dividir un racional por un entero resulta en un racional.
  * sumar/restar/multiplicar/dividir dos racionales resulta en un racional.
  * sumar/restar/multiplicar/dividir un flotante con un racional resulta en un flotante.
  * dividir un entero/racional por un flotante resulta en un flotante.

El objetivo es que Math::BigRat sea compatible con Math::BigInt y Math::BigFloat por medio de la promoción y la degradación automática.

Biblioteca Math

Puedes cambiar el módulo subyacente que realiza las operaciones matemáticas de bajo nivel usando:

use Math::BigRat try => 'GMP';

Nota: Esto necesita tener instalado Math::BigInt::GMP.

Lo siguiente primero intentará encontrar Math::BigInt::Foo, luego Math::BigInt::Bar, y cuando esto también falle, recurrirá a Math::BigInt::Calc:

use Math::BigRat try => 'Foo,Math::BigInt::Bar';

Si quieres recibir una advertencia cuando ocurra la recurrencia, reemplaza "try" con "lib":

use Math::BigRat lib => 'Foo,Math::BigInt::Bar';

Si quieres que el código falle en lugar de eso, reemplaza "try" con "only":

use Math::BigRat only => 'Foo,Math::BigInt::Bar';

MÉTODOS

Cualquier método no listado aquí se deriva de Math::BigFloat (o Math::BigInt), así que asegúrate de consultar estos dos módulos para obtener más información.

new()
$x = Math::BigRat->new('1/3');

Crea un nuevo objeto Math::BigRat. La entrada puede venir en varias formas:

$x = Math::BigRat->new(123);                            # escalares
$x = Math::BigRat->new('inf');                          # infinito
$x = Math::BigRat->new('123.3');                        # flotante
$x = Math::BigRat->new('1/3');                          # cadena simple
$x = Math::BigRat->new('1 / 3');                        # con espacios
$x = Math::BigRat->new('1 / 0.1');                      # con flotantes
$x = Math::BigRat->new(Math::BigInt->new(3));           # BigInt
$x = Math::BigRat->new(Math::BigFloat->new('3.1'));     # BigFloat
$x = Math::BigRat->new(Math::BigInt::Lite->new('2'));   # BigLite
# También puedes dar D y N como objetos diferentes:
$x = Math::BigRat->new(
        Math::BigInt->new(-123),
        Math::BigInt->new(7),
     );                      # => -123/7
from_dec()
my $h = Math::BigRat->from_dec("1.2");

Crea un BigRat a partir de un número decimal en formato de cadena. Es equivalente a "new()", pero no acepta nada más que cadenas que representen números decimales finitos.

from_hex()
my $h = Math::BigRat->from_hex("0x10");

Crea un BigRat a partir de un número hexadecimal en formato de cadena.

from_oct()
my $o = Math::BigRat->from_oct("020");

Crea un BigRat a partir de un número octal en formato de cadena.

from_bin()
my $b = Math::BigRat->from_bin("0b10000000");

Crea un BigRat a partir de un número binario en formato de cadena.

from_bytes()
$x = Math::BigRat->from_bytes("\xf3\x6b");  # $x = 62315

Interpreta la entrada como una cadena de bytes, asumiendo orden de bytes big-endian. La salida es siempre un entero finito no negativo.

Ver "from_bytes()" en Math::BigInt.

from_ieee754()
# establece $x a 13176795/4194304, el valor más cercano a pi que se puede
# representar en el formato binario32 (simple)
$x = Math::BigRat -> from_ieee754("40490fdb", "binary32");

Interpreta la entrada como un valor codificado según se describe en IEEE754-2008.

Ver "from_ieee754()" en Math::BigFloat.

from_base()
Ver "from_base()" en Math::BigInt.
bzero()
$x = Math::BigRat->bzero();

Crea un nuevo objeto BigRat que representa cero. Si se usa en un objeto, lo establecerá a cero:

$x->bzero();
bone()
$x = Math::BigRat->bone($sign);

Crea un nuevo objeto BigRat que representa uno. El argumento opcional es '-' o '+', indicando si quieres uno o menos uno. Si se usa en un objeto, lo establecerá a uno:

$x->bone();                 # +1
$x->bone('-');              # -1
binf()
$x = Math::BigRat->binf($sign);

Crea un nuevo objeto BigRat que representa infinito. El argumento opcional es '-' o '+', indicando si quieres infinito o menos infinito. Si se usa en un objeto, lo establecerá a infinito:

$x->binf();
$x->binf('-');
bnan()
$x = Math::BigRat->bnan();

Crea un nuevo objeto BigRat que representa NaN (Not A Number). Si se usa en un objeto, lo establecerá a NaN:

$x->bnan();
bpi()
$x = Math::BigRat -> bpi();         # precisión por defecto
$x = Math::BigRat -> bpi(7);        # precisión especificada

Devuelve una aproximación racional de PI con la precisión especificada o la precisión por defecto si no se especifica ninguna. Si se llama como método de instancia, el valor se asigna al invocador.

$x = Math::BigRat -> bpi(1);        # devuelve "3"
$x = Math::BigRat -> bpi(3);        # devuelve "22/7"
$x = Math::BigRat -> bpi(7);        # devuelve "355/113"
copy()
my $z = $x->copy();

Crea una copia profunda del objeto.

Por favor, consulta la documentación en Math::BigInt para más detalles.

as_int()
$y = $x -> as_int();        # $y es un Math::BigInt

Devuelve $x como un objeto Math::BigInt independientemente de la promoción y degradación. Si $x es finito, pero no un entero, $x se trunca.

as_rat()
$y = $x -> as_rat();        # $y es un Math::BigRat

Devuelve $x como un objeto Math::BigRat independientemente de la promoción y degradación. El invocador no se modifica.

as_float()
$x = Math::BigRat->new('13/7');
print $x->as_float(), "\n";             # '1'
$x = Math::BigRat->new('2/3');
print $x->as_float(5), "\n";            # '0.66667'

Devuelve una copia del objeto como un objeto Math::BigFloat independientemente de la promoción y degradación, preservando la precisión deseada, o la precisión por defecto de 40 dígitos.

bround()/round()/bfround()
Aún no están implementados.
is_zero()
print "$x es 0\n" if $x->is_zero();

Devuelve verdadero si $x es exactamente cero, de lo contrario falso.

is_one()
print "$x es 1\n" if $x->is_one();

Devuelve verdadero si $x es exactamente uno, de lo contrario falso.

is_finite()
$x->is_finite();    # verdadero si $x no es +inf, -inf ni NaN

Devuelve verdadero si el invocador es un número finito, es decir, no es +inf, -inf ni NaN.

is_positive()
is_pos()
print "$x es >= 0\n" if $x->is_positive();

Devuelve verdadero si $x es positivo (mayor o igual que cero), de lo contrario falso. Ten en cuenta que '+inf' también es positivo, mientras que 'NaN' y '-inf' no lo son.

"is_positive()" es un alias para "is_pos()".

is_negative()
is_neg()
print "$x es < 0\n" if $x->is_negative();

Devuelve verdadero si $x es negativo (menor que cero), de lo contrario falso. Ten en cuenta que '-inf' también es negativo, mientras que 'NaN' y '+inf' no lo son.

"is_negative()" es un alias para "is_neg()".

is_odd()
print "$x es impar\n" if $x->is_odd();

Devuelve verdadero si $x es impar, de lo contrario falso.

is_even()
print "$x es par\n" if $x->is_even();

Devuelve verdadero si $x es par, de lo contrario falso.

is_int()
print "$x es un entero\n" if $x->is_int();

Devuelve verdadero si $x tiene un denominador de 1 (es decir, sin partes fraccionarias), de lo contrario falso. Ten en cuenta que '-inf', 'inf' y 'NaN' no son enteros.

Métodos de comparación

Ninguno de estos métodos modifica el objeto invocador. Ten en cuenta que un "NaN" no es ni menor que, ni mayor que, ni igual a nada más, ni siquiera a otro "NaN".

bcmp()
$x->bcmp($y);

Compara $x con $y y devuelve:

-1 si $x < $y
 0 si $x == $y
 1 si $x > $y

O devuelve undef si alguno de ellos es NaN.

beq()
$x->beq($y);

Devuelve verdadero si $x es igual a $y, de lo contrario falso.

bne()
$x->bne($y);

Devuelve verdadero si $x no es igual a $y, de lo contrario falso.

blt()
$x->blt($y);

Devuelve verdadero si $x es menor que $y, de lo contrario falso.

ble()
$x->ble($y);

Devuelve verdadero si $x es menor o igual que $y, de lo contrario falso.

bgt()
$x->bgt($y);

Devuelve verdadero si $x es mayor que $y, de lo contrario falso.

bge()
$x->bge($y);

Devuelve verdadero si $x es mayor o igual que $y, de lo contrario falso.

OPERADORES

Los siguientes operadores están sobrecargados para Math::BigRat:

addition +
$c = $a + $b;
subtraction -
$c = $a - $b;
multiplication *
$c = $a * $b;
division /
$c = $a / $b;

La división de dos racionales siempre da como resultado un racional.

modulo %
$c = $a % $b;

Devuelve el resto de la división de $a por $b. El resultado es un racional.

exponentiation **
$c = $a ** $b;

El exponente $b puede ser un entero o un racional. Si $b es un entero, el resultado es un racional (a menos que $a sea también un entero, en cuyo caso el resultado será un BigInt). Si $b es un racional, el resultado puede ser un racional o un flotante, dependiendo de si el resultado es racional o no.

print 2**3, "\n";       # 8
print 2**(-3), "\n";      # 1/8
print (1/2)**3, "\n";     # 1/8
print (1/2)**(-3), "\n";    # 8
print (2)**(1/2), "\n";   # 1.41421356237309504880168872420969807857 (un BigFloat)
print (4)**(1/2), "\n";   # 2 (un BigRat)
unary minus -
$c = -$a;
unary plus +
$c = +$a;
equality ==
$bool = ($a == $b);
inequality != 
$bool = ($a != $b);
less than <
$bool = ($a < $b);
less than or equal to <=
$bool = ($a <= $b);
greater than >
$bool = ($a > $b);
greater than or equal to >=
$bool = ($a >= $b);
spaceship <=>
$cmp = ($a <=> $b);

Devuelve -1, 0 o 1 si $a es menor, igual o mayor que $b, respectivamente. Devuelve undef si alguno de ellos es NaN.

boolean operators
if ($a) { ... }

Cualquier número que no sea cero se evalúa como verdadero. Cero se evalúa como falso.

OPERADORES TRADICIONALES

Este módulo también permite el uso de operadores tradicionales mediante el uso de la sintaxis:

    use Math::BigRat ':overload'; # o ':trad'; o ':all';

Ten en cuenta que si usas ':overload' o ':trad', sólo estarán disponibles los operadores de esta lista. Si usas ':all', todos los operadores anteriores estarán disponibles.

Los operadores disponibles son:

addition +
print $a + $b;
subtraction -
print $a - $b;
multiplication *
print $a * $b;
division /
print $a / $b;
modulo %
print $a % $b;
exponentiation **
print $a ** $b;
equality ==
print $a == $b;
inequality != 
print $a != $b;
less than <
print $a < $b;
less than or equal to <=
print $a <= $b;
greater than >
print $a > $b;
greater than or equal to >=
print $a >= $b;
spaceship <=>
print $a <=> $b;
unary minus -
print -$a;
unary plus +
print +$a;
stringification
print $a;

Imprime la representación de cadena del número racional.

integer evaluation
if ($a) { ... }

Evalúa a verdadero si el número no es cero.

Si también cargas `use Math::BigInt ':overload';` y `use Math::BigFloat ':overload';`, entonces `Math::BigRat` se encargará de las conversiones adecuadas. Por ejemplo, sumar un entero a un racional resultará en un racional, y sumar un flotante a un racional resultará en un flotante.

Tenga en cuenta que la división de un entero por un entero dará como resultado un racional, no un entero.

    use Math::BigInt ':overload';
    use Math::BigFloat ':overload';
    use Math::BigRat ':overload';

    my $a = Math::BigRat->new(1);
    my $b = Math::BigRat->new(3);
    my $c = $a / $b; # $c es 1/3, no un BigFloat

Sin embargo, si realizas una operación que resulta en un flotante (por ejemplo, la raíz cuadrada de un número que no es un cuadrado perfecto), el resultado será un flotante.

    print 4**(1/2), "\n"; # imprime 2 (como un BigRat)
    print 2**(1/2), "\n"; # imprime 1.41421356237309504880168872420969807857 (como un BigFloat)

Math::BigRat

The Math::BigRat object is a string representation of a fraction, which is implemented using the Math::BigInt and Math::BigFloat objects.

A fraction is represented as a numerator and a denominator. The denominator is always a positive integer. The fraction is always reduced to its smallest terms. For example:

    use Math::BigRat;
    my $x = Math::BigRat->new('8/4');        # creates 2/1
    my $y = Math::BigRat->new('2/3');
    print $x + $y;                           # prints 8/3

Class methods

new()
my $x = Math::BigRat->new( $numerator, $denominator );
my $y = Math::BigRat->new( 'string' );
my $z = Math::BigRat->new( $value );

Constructs a new Math::BigRat object. The input can be a scalar or a string. If the input is a string, it can be a fraction like '1/3' or just a number like '123' or '12.34'. It can also be a complex fraction like '1/2/3' which is calculated as 1/(2/3) = 3/2.

If two arguments are given, they are treated as numerator and denominator.

The input is automatically reduced to the smallest terms. A denominator of 0 is not allowed and will cause an error.

NUMERIC LITERALS

After "use Math::BigRat ':constant'" all numeric literals in the given scope are converted to "Math::BigRat" objects. This conversion happens at compile time. Every non-integer is convert to a NaN.

For example,

perl -MMath::BigRat=:constant -le 'print 2**150'

prints the exact value of "2**150". Note that without conversion of constants to objects the expression "2**150" is calculated using Perl scalars, which leads to an inaccurate result.

Please note that strings are not affected, so that

use Math::BigRat qw/:constant/;
$x = "1234567890123456789012345678901234567890"
        + "123456789123456789";

does give you what you expect. You need an explicit Math::BigRat->new() around at least one of the operands. You should also quote large constants to prevent loss of precision:

use Math::BigRat;
$x = Math::BigRat->new("1234567889123456789123456789123456789");

Without the quotes Perl first converts the large number to a floating point constant at compile time, and then converts the result to a Math::BigRat object at run time, which results in an inaccurate result.

Hexadecimal, octal, and binary floating point literals

Perl (and this module) accepts hexadecimal, octal, and binary floating point literals, but use them with care with Perl versions before v5.32.0, because some versions of Perl silently give the wrong result. Below are some examples of different ways to write the number decimal 314.

Hexadecimal floating point literals:

0x1.3ap+8         0X1.3AP+8
0x1.3ap8          0X1.3AP8
0x13a0p-4         0X13A0P-4

Octal floating point literals (with "0" prefix):

01.164p+8         01.164P+8
01.164p8          01.164P8
011640p-4         011640P-4

Octal floating point literals (with "0o" prefix) (requires v5.34.0):

0o1.164p+8        0O1.164P+8
0o1.164p8         0O1.164P8
0o11640p-4        0O11640P-4

Binary floating point literals:

0b1.0011101p+8    0B1.0011101P+8
0b1.0011101p8     0B1.0011101P8
0b10011101000p-2  0B10011101000P-2
