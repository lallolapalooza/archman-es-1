NOMBRE

Mail::Message::Body::Multipart - cuerpo de un mensaje con anexos

HERENCIA

Mail::Message::Body::Multipart
  es un Mail::Message::Body
  es un Mail::Reporter

SINOPSIS

Ver Mail::Message::Body
si($body->isMultipart) {
   mi @adjuntos = $body->partes;
   mi $adjunto3 = $body->parte(2);
   mi $antes      = $body->preambulo;
   mi $despues       = $body->epilogo;
   $body->parte(1)->eliminar;
}

DESCRIPCIÓN

El contenido (cuerpo) de un mensaje puede almacenarse de varias formas. En esta página de manuales, se describe la funcionalidad adicional que tienes cuando un mensaje contiene anexos (partes).

El número de alternativas multipart es creciente. Una lista completa se mantiene por IANA af

  • multipart/mixed
  • multipart/alternative
  • multipart/related
  • multipart/report, RFC6522
  • multipart/signed, RFC1847
  • multipart/encrypted
  • multipart/multilingual, RFC8255 (no se utiliza)

boundary => $separador
El string $separador a usarse entre las partes del mensaje. Este separador debe ser único en caso el mensaje contenga múltiples partes (lo cual no es raro). Si "undef", se genera un separador único atractivo.
charset => CHARSET|'PERL'|<undef>

epilogue => $body|$texto
El texto que se incluye en el cuerpo principal después de la última separación. Esto suele ser vacío y carece de sentido.

Proporciona un $body objeto o texto plano $texto (que se convertirá automáticamente en un cuerpo de tipo text/plain).

file => FILENAME|FILEHANDLE|IOHANDLE
filename => FILENAME
language => STRING|ARRAY|LIST|FIELD
log => LEVEL
message => MESSAGE
mime_type => STRING|FIELD|MIME
modified => BOOLEAN
parts => [$message, $body, ...]
Define una lista inicial de partes en este cuerpo. Estas pueden ser objetos completos $message, o objetos $body que se convierten en mensajes antes de su uso. Cada mensaje se convierte en un objeto Mail::Message::Part.

Los objetos MIME::Entity y Mail::Internet son aceptables en la lista, ya que se pueden convertir en objetos Mail::Message::Part. Los valores "undef" se omiten silenciosamente.

preamble => $body|$texto
El texto que se incluye en el cuerpo antes de la primera parte. Es comúnmente usar incluir un texto para advertir al usuario que el mensaje es multipart. Sin embargo, esto fue útil en días anteriores: la mayoría de los agentes de correo son muy capaces de advertir al usuario por sí mismos.

Proporciona un $body objeto o texto plano $texto (que se convertirá automáticamente en un cuerpo de tipo text/plain).

trace => LEVEL
transfer_encoding => STRING|FIELD

» ejemplo:

my $intro = Mail::Message::Body->new(data => ['parte uno']);
my $pgp   = Mail::Message::Body->new(data => ['parte tres']);
my $body  = Mail::Message::Body::Multipart->new(
  boundary => time . '--it-s-mine',
  preamble => "Este es un mensaje multipart en formato MIME.\n\n",
  parts    => [ $intro, $folder->message(3)->decoded, $pgp ],
);

$obj->foreachComponent(CODE)
Ejecuta el "CODE" para cada componente del mensaje: el preámbulo, el epílogo y cada una de las partes.

Cada componente es un cuerpo y se pasa como segundo argumento al "CODE". El primer argumento es una referencia a este cuerpo multipart. El "CODE" devuelve un objeto de cuerpo. Cuando cualquiera de los cuerpos devueltos difiere del cuerpo que se pasó, se devolverá un nuevo cuerpo multipart. Las referencias a los cuerpos no modificados y a los cuerpos modificados se incluirán en esa nueva multipart.

» ejemplo:

my $checked = $multi->foreachComponent(sub {$_[1]->check});
$obj->foreachLine((CODE))
NO es posible llamar a un código para cada línea de una multipart, porque eso no solo causaría daños al cuerpo de cada parte del mensaje, sino también a las cabeceras y a los separadores de partes. Mejora la base, véase "Constructing a body" en Mail::Message::Body::Construct

$obj->part($index)
Devuelve solo la parte con el $index especificado. Puede utilizar un valor negativo aquí, que cuenta desde el final de la lista. Las partes marcadas para ser eliminadas se incluyen en el recuento.

» ejemplo:

$message->body->part(2)->print;
$body->part(1)->delete;
$obj->parts( [<'ALL'|'ACTIVE'|'DELETED'|'RECURSE'|$filter>] )
Devuelve todas las partes por defecto, o cuando "ALL" se especifica. "ACTIVE" devuelve las partes que no están marcadas para su eliminación, a diferencia de "DELETED". "RECURSE" desciende en todas las multiparts anidadas para recopilar todas las partes.

También puede especificar una referencia de código que se llama para cada parte anidada. El primer argumento será la parte del mensaje. Cuando el código devuelve "true", la parte se incorpora a la lista devuelta.

» ejemplo:

print "Number of attachments: ",
   scalar $message->body->parts('ACTIVE');
foreach my $part ($message->body->parts) {
   print "Type: ", $part->get('Content-Type');
}
$obj->preamble()
Devuelve el preámbulo; el texto antes de la primera parte del mensaje (antes del primer archivo adjunto real). El preámbulo se almacena en un objeto BODY, y su codificación se toma de la cabecera multipart.

DIAGNÓSTICOS

Advertencia: Charset $name no es conocido
La codificación o decodificación de un cuerpo de mensaje encuentra un conjunto de caracteres que no es entendido por el módulo Encode de Perl. Emitido por encode()
Advertencia: Content-Transfer-Encoding `$encoding' requiere un charset explícito, se asumió utf-8
Emitido por encode()
Error: Datos no convertibles a un mensaje (tipo es $type)
Se pasó un objeto que no es coercible a un objeto Mail::Message::Part a la iniciación. Los datos son ignorados. Emitido por new()
Advertencia: No se definió un decodificador para la codificación de transferencia $name.
Los datos (cuerpo del mensaje) están codificados de una manera que no se entiende actualmente, por lo tanto, no se puede realizar ninguna decodificación (o recodificación). Emitido por encode()
Advertencia: No se definió un codificador para la codificación de transferencia $name.
Los datos (cuerpo del mensaje) han sido decodificados, pero la codificación requerida es desconocida. Se devuelven los datos decodificados. Emitido por encode()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería hacerlo. Este mensaje significa que otras clases relacionadas sí implementan este método, sin embargo, la clase en cuestión no lo hace. Probablemente debería investigar esto y posiblemente informar al autor del paquete. Emitido por notImplemented()
Error: Criterio desconocido $what para seleccionar partes.
Las opciones válidas para la selección de partes son "ALL", "ACTIVE", "DELETED", "RECURSE" o una referencia de código. Sin embargo, se pasó otro argumento. Emitido por parts()
Advertencia: Terminador de línea desconocido $eol ignorado
Emitido por eol()
Error: No puedes usar foreachLine en un multipart
foreachLine() solo debe usarse en cuerpos de mensajes decodificados, ya que intentaría modificar también las cabeceras de las partes y los separadores, lo cual es claramente inaceptable. Emitido por foreachLine()
