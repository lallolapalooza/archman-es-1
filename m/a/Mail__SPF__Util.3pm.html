Mail::SPF::Util(3) Documentación de Perl aportada por el usuario Mail::SPF::Util(3)

NOMBRE

Mail::SPF::Util - Clase de utilidad de Mail::SPF

VERSIÓN

versión 3.20250505

SINOPSIS

use Mail::SPF::Util;
$hostname = Mail::SPF::Util->hostname;
$ipv6_address_v4mapped =
    Mail::SPF::Util->ipv4_address_to_ipv6($ipv4_address);
$ipv4_address =
    Mail::SPF::Util->ipv6_address_to_ipv4($ipv6_address_v4mapped);
$is_v4mapped =
    Mail::SPF::Util->ipv6_address_is_ipv4_mapped($ipv6_address);
$ip_address_string  = Mail::SPF::Util->ip_address_to_string($ip_address);
$reverse_name       = Mail::SPF::Util->ip_address_reverse($ip_address);
$validated_domain = Mail::SPF::Util->valid_domain_for_ip_address(
    $spf_server, $request,
    $ip_address, $domain,
    $find_best_match,       # por defecto es falso
    $accept_any_domain      # por defecto es falso
);
$sanitized_string = Mail::SPF::Util->sanitize_string($string);

DESCRIPCIÓN

Mail::SPF::Util es la clase de utilidad de Mail::SPF.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

hostname: devuelve cadena
Devuelve el nombre de dominio totalmente cualificado (FQDN) del host local.
ipv4_address_to_ipv6($ipv4_address): devuelve NetAddr::IP; lanza Mail::SPF::EInvalidOptionValue
Convierte la dirección IPv4 de NetAddr::IP especificada en una dirección IPv6 mapeada a IPv4. Lanza una excepción Mail::SPF::EInvalidOptionValue si la dirección IP especificada no es una dirección IPv4.
ipv6_address_to_ipv4($ipv6_address): devuelve NetAddr::IP; lanza Mail::SPF::EInvalidOptionValue
Convierte la dirección IPv6 mapeada a IPv4 de NetAddr::IP especificada en una dirección IPv4 correcta. Lanza una excepción Mail::SPF::EInvalidOptionValue si la dirección IP especificada no es una dirección IPv6 mapeada a IPv4.
ipv6_address_is_ipv4_mapped($ipv6_address): devuelve booleano
Devuelve verdadero si la dirección IPv6 de NetAddr::IP especificada es una dirección mapeada a IPv4, falso en caso contrario.
ip_address_to_string($ip_address): devuelve cadena; lanza Mail::SPF::EInvalidOptionValue
Devuelve la dirección IPv4 o IPv6 de NetAddr::IP dada de forma compacta como una cadena. Para direcciones IPv4, esto es equivalente a llamar al método "addr" de NetAddr::IP. Para direcciones IPv6, esto es equivalente a llamar al método "short" de NetAddr::IP. Lanza una excepción Mail::SPF::EInvalidOptionValue si el objeto especificado no es un objeto de dirección IPv4 o IPv6 de NetAddr::IP.
ip_address_reverse($ip_address): devuelve cadena; lanza Mail::SPF::EInvalidOptionValue
Devuelve la notación inversa "in-addr.arpa."/"ip6.arpa." de la dirección IPv4 o IPv6 de NetAddr::IP dada. Lanza una excepción Mail::SPF::EInvalidOptionValue si el objeto especificado no es un objeto de dirección IPv4 o IPv6 de NetAddr::IP.
valid_domain_for_ip_address($server, $request, $ip_address, $domain, $find_best_match = false, $accept_any_domain = false): devuelve cadena o undef
Encuentra un nombre de dominio válido para la dirección IP de NetAddr::IP dada que coincida con el dominio dado o un subdominio del mismo. Un nombre de dominio es válido para la dirección IP dada si la dirección IP se resuelve inversamente a ese nombre de dominio en DNS, y el nombre de dominio a su vez se resuelve directamente a la dirección IP. Utiliza los objetos Mail::SPF::Server y Mail::SPF::Request dados para realizar consultas DNS. Devuelve el nombre de dominio validado.

Si $find_best_match es verdadero, se selecciona el nombre de dominio que mejor coincide con el nombre de dominio dado, prefiriendo coincidencias directas sobre coincidencias de subdominios. Por defecto es falso.

Si $accept_any_domain es verdadero, se consideran aceptables cualquier nombre de dominio, incluso si difieren completamente del nombre de dominio dado (que entonces se usa efectivamente de forma inútil a menos que se solicite una mejor coincidencia). Por defecto es falso.

sanitize_string($string): devuelve cadena o undef
Reemplaza todos los caracteres no imprimibles o no ASCII en una cadena con su representación escapada en hexadecimal (por ejemplo, "\x00").
