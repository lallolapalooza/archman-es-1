Paquete: spamassassin

Mail::SpamAssassin::Plugin::DCC(3) Documentación de Perl contribuida por el usuario Mail::SpamAssassin::Plugin::DCC(3)

NOMBRE

Mail::SpamAssassin::Plugin::DCC - realiza la comprobación DCC de mensajes

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::DCC
full DCC_CHECK        eval:check_dcc()
full DCC_CHECK_50_79  eval:check_dcc_reputation_range('50','79')

DESCRIPCIÓN

DCC o Distributed Checksum Clearinghouse es un sistema de servidores que recopila y cuenta checksums de millones de mensajes de correo. Los recuentos pueden ser utilizados por SpamAssassin para detectar y filtrar spam.

Vea https://www.dcc-servers.net/dcc/ para más información sobre DCC.

Tenga en cuenta que DCC está deshabilitado por defecto en "v310.pre" porque su uso requiere software que no se distribuye con SpamAssassin y que tiene restricciones de licencia para ciertos usos comerciales. Vea la licencia de DCC en https://www.dcc-servers.net/dcc/LICENSE para detalles.

Habilítelo descomentando la línea "loadplugin Mail::SpamAssassin::Plugin::DCC" en confdir/v310.pre o añadiendo esta línea a su local.pre. También puede ser necesario instalar un paquete DCC, port, rpm o equivalente de su distribuidor de sistema operativo o desde un tarball de la fuente principal de DCC en https://www.dcc-servers.net/dcc/#download Vea también https://www.dcc-servers.net/dcc/INSTALL.html

ETIQUETAS

Las siguientes etiquetas se añaden al conjunto, disponibles para su uso en informes, campos de cabecera, otros plugins, etc.:

_DCCB_    ID del servidor DCC en el nombre del campo de cabecera X-DCC-*-Metrics
_DCCR_    Cuerpo del campo de cabecera X-DCC-*-Metrics
_DCCREP_  Reputación DCC o porcentaje de correo masivo (0..100) del
            software comercial DCC

CONFIGURACIÓN DEL USUARIO

use_dcc (0|1) (valor por defecto: 1)
Si se utiliza DCC, si está disponible.
use_dcc_rep (0|1) (valor por defecto: 1)
Si se utiliza la función de Reputación DCC comercial, si está disponible. Tenga en cuenta que los datos de reputación son gratuitos para todos a partir de la versión 2.x de DCC, donde se utiliza automáticamente.
dcc_body_max NÚMERO
dcc_fuz1_max NÚMERO
dcc_fuz2_max NÚMERO
Establece con qué frecuencia debe haberse notificado el checksum del cuerpo/fuz1/fuz2 de un mensaje al servidor DCC antes de que SpamAssassin considere que la comprobación DCC ha sido un éxito. 999999 es el recuento MANY de DCC.

El valor por defecto es 999999 para todas estas opciones.

dcc_rep_percent NÚMERO
Solo el software comercial DCC proporciona Reputaciones DCC (pero a partir de la versión 2.x de DCC está disponible para todos). Una Reputación DCC es el porcentaje de correo masivo recibido del último relay no confiable en la ruta tomada por un mensaje de correo, según lo medido por todas las instalaciones comerciales de DCC. Vea http://www.rhyolite.com/dcc/reputations.html Usted "debe" agregar a la lista blanca sus relays confiables o servidores MX con líneas MX o MXDCC en /var/dcc/whiteclnt como se describe en la página principal del manual de DCC para evitar ver sus propios servidores MX como fuentes de correo masivo. Vea https://www.dcc-servers.net/dcc/dcc-tree/dcc.html#White-and-Blacklists El valor por defecto es 90.

CONFIGURACIÓN DEL ADMINISTRADOR

dcc_timeout n (valor por defecto: 5)
Cuántos segundos espera a que DCC se complete, antes de que el escaneo continúe sin los resultados de DCC. Un valor numérico se sufija opcionalmente con una unidad de tiempo (s, m, h, d, w, indicando segundos (por defecto), minutos, horas, días, semanas).
dcc_home CADENA
Esta opción le dice a SpamAssassin dónde encontrar el directorio principal de dcc. Si no se especifica, intente usar el directorio configurado localmente desde el comando "cdcc homedir". Intente /var/dcc si ese comando falla.
dcc_dccifd_path CADENA
Esta opción le dice a SpamAssassin dónde encontrar el socket dccifd en lugar de un socket Unix local llamado "dccifd" en el directorio "dcc_home". Si se especifica o se encuentra un socket, úselo en lugar de "dccproc".

Si se especifica, "dcc_dccifd_path" es la ruta absoluta del socket Unix local o un socket INET especificado como "[Host]:Puerto" o "Host:Puerto". Host puede ser una dirección IPv4 o IPv6 o un nombre de host. Puerto es un número de puerto TCP. Los corchetes son requeridos para una dirección IPv6.

El valor por defecto es "undef".

dcc_path CADENA
Dónde encontrar el programa cliente "dccproc" en lugar de depender de SpamAssassin para encontrarlo en la PATH actual o en "dcc_home/bin". Esto a menudo debe establecerse, ya que la PATH actual es limpiada por el *modo tainting* en el intérprete de Perl,

Si se encuentra un socket "dccifd" en "dcc_home" o se especifica explícitamente con "dcc_dccifd_path", use la interfaz dccifd(8) en lugar de "dccproc".

El valor por defecto es "undef".

dcc_options opciones
Especifica opciones adicionales para el comando dccproc(8). Solo se permiten caracteres en el rango [0-9A-Za-z ,._/-] por razones de seguridad.

El valor por defecto es "undef".

dccifd_options opciones
Especifica opciones adicionales para enviar al demonio dccifd con el protocolo ASCII descrito en la página del manual de dccifd(8). Solo se permiten caracteres en el rango [0-9A-Za-z ,._/-] por razones de seguridad.

El valor por defecto es "undef".

dcc_learn_score n (valor por defecto: undef)
Reporta mensajes con puntuaciones totales que superan en esta cantidad el umbral de spam de SpamAssassin a DCC como spam.
