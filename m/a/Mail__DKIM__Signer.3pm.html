Mail::DKIM::Signer(3) Documentación contribuida por usuarios de Perl Mail::DKIM::Signer(3)

Nombre

Mail::DKIM::Signer - genera una firma DKIM para un mensaje

Versión

versión 1.20240923

SINTAXIS

use Mail::DKIM::Signer;
use Mail::DKIM::TextWrap;  # recomendado
# crear un objeto de signador
my $dkim = Mail::DKIM::Signer->new(
                Algorithm => 'rsa-sha1',
                Method => 'relaxed',
                Domain => 'example.org',
                Selector => 'selector1',
                KeyFile => 'private.key',
                Headers => 'x-header:x-header2',
           );
# leer un correo electrónico desde un archivo de entrada
$dkim->load(*STDIN);
# o leer un correo electrónico y pasarlo a la firma, una línea a la vez
while (<STDIN>)
{
    # eliminar los terminadores locales
    chomp;
    s/\015$//;
    # usar terminadores SMTP
    $dkim->PRINT("$_\015\012");
}
$dkim->CLOSE;
# ¿cuál es el resultado de la firma?
my $signature = $dkim->signature;
print $signature->as_string;

DESCRIPCIÓN

Esta clase es parte de Mail::DKIM responsable de generar firmas para un mensaje dado. Usted crea un objeto de esta clase, especificando los parámetros de la firma que desea crear, o especificando una función de callback para que los parámetros de la firma puedan ser determinados más tarde. Luego, le da el mensaje completo usando "PRINT()", terminando con "CLOSE()". Finalmente, use el método "signatures()" para acceder a las firmas generadas.

Firmas de estilo

Mail::DKIM incluye un módulo de firmas que inserta linebreaks en la firma generada para que sea más bonita en el mensaje final. Para habilitar este módulo, simplemente llame

use Mail::DKIM::TextWrap;

a su programa antes de generar la firma.

CONSTRUCTOR

new()

Crea un signador orientado a objetos.

# crear un signador usando la política por defecto
my $dkim = Mail::DKIM::Signer->new(
                Algorithm => 'rsa-sha1',
                Method => 'relaxed',
                Domain => 'example.org',
                Selector => 'selector1',
                KeyFile => 'private.key',
                Headers => 'x-header:x-header2',
           );
# crear un signador usando una política personalizada
my $dkim = Mail::DKIM::Signer->new(
                Policy => $policyfn,
           );

La política por defecto crea una firma DKIM utilizando los parámetros especificados, pero solo si el emisor del mensaje coincide con el dominio. Los siguientes parámetros pueden pasar a este new() para influir en la firma resultante: Algorithm, Method, Domain, Selector, KeyFile, Identity, Timestamp, Expiration.

Si quieres diferente comportamiento, puedes proporcionar una "política de signador". Una política de signador es una subrutina o clase que determina los parámetros de la firma después de que se hayan parseado las cabeceras del mensaje. Ver la sección "POLÍTICAS DE SIGNADOR" para más información.

Ver Mail::DKIM::SignerPolicy para más información sobre objetos de política.

Además de los parámetros demostrados anteriormente, los siguientes son reconocidos:

Key
en lugar de usar "KeyFile", use "Key" para usar una objeto de clave privada ya cargado de Mail::DKIM::PrivateKey.
Headers
una lista separada por colones de cabeceras a firmar, esto se agrega a la lista de cabeceras por defecto como mostrado en el esquema DKIM.

Para cada cabecera especificada, todas las cabeceras de ese tipo presentes en el mensaje se firmarán, pero no se firmarán cabeceras que no estén presentes.

Si quieres mayor control sobre las cabeceras firmadas, usa el método extended_headers() en lugar.

La lista de cabeceras por defecto es la siguiente:

From Sender Reply-To Subject Date
Message-ID To Cc MIME-Version
Content-Type Content-Transfer-Encoding Content-ID Content-Description
Resent-Date Resent-From Resent-Sender Resent-To Resent-cc
Resent-Message-ID
In-Reply-To References
List-Id List-Help List-Unsubscribe List-Subscribe
List-Post List-Owner List-Archive
Tags
un hashref opcional de etiquetas adicionales a agregar a la firma DKIM generada.

MÉTODOS

PRINT()

Enviar parte del mensaje a la firma.

$dkim->PRINT("a line of the message\015\012");

Envía el contenido del mensaje a firmar a la firma. La API está diseñada de esta manera para que el mensaje completo no necesite ser leído en memoria a toda la vez.

Nota: aunque el método PRINT() espera que uses los caracteres de terminación SMTP, no debes usar el técnica de dot-stuffing descrita en el RFC 2821 sección 4.5.2. tampoco debes usar una secuencia de <CR><LF>.<CR><LF> para terminar el mensaje.

CLOSE()

Llama esta cuando hay terminado de enviar el mensaje.

$dkim->CLOSE;

Este método termina el proceso de canonización, calcula una hash y genera una firma.

extended_headers()

Este método sobrescribe las cabeceras a firmar y permite más control que lo que se puede lograr con el parámetro Headers en el constructor.

El método espera un HashRef a pasar.

Los Keys son las cabeceras a firmar, y los valores son el número de cabeceras de ese tipo a firmar, o los valores especiales '*' y '+'.

* firmará todas las cabeceras de ese tipo presentes en el mensaje.

+ firmará todas las cabeceras de ese tipo más 1 presentes en el mensaje para prevenir la adición de cabeceras adicionales.

Puedes sobrescribir cualquier cabecera por defecto incluyéndola en el hashref, y desactivarlas dando un valor 0.

Los Keys son case-insensibles, y los valores se añaden hasta el valor más alto.

Headers => {
    'X-test'  => '*',
    'x-test'  => '1',
    'Subject' => '+',
    'Sender'  => 0,
},

add_signature()

Usado por las políticas de signador para crear una nueva firma.

$dkim->add_signature(new Mail::DKIM::Signature(...));

Las políticas de signador pueden usar este método para especificar los parámetros completos para la firma a agregar, incluyendo el tipo de firma. Para más información, véase Mail::DKIM::SignerPolicy.

algorithm()

Obtiene o establece el algoritmo seleccionado.

$alg = $dkim->algorithm;
$dkim->algorithm('rsa-sha1');

domain()

Obtiene o establece el dominio seleccionado.

$alg = $dkim->domain;
$dkim->domain('example.org');

load()

Carga el mensaje completo desde un archivo de entrada.

$dkim->load($file_handle);

Lee un mensaje completo desde el archivo designado, alimentándolo a la firma. El mensaje debe usar terminadores de línea <CRLF> (iguales al protocolo SMTP).

headers()

Determina cuáles cabeceras se incluirán en la firma.

my $headers = $dkim->headers;

Este es una cadena que contiene los nombres de los campos de cabecera que se firmarán, separados por colones.

key()

Obtiene o establece la objeto de clave privada.

my $key = $dkim->key;
$dkim->key(Mail::DKIM::PrivateKey->load(File => 'private.key'));

El objeto de clave puede ser cualquier objeto que implemente el método sign_digest(). (Ofrecer un objeto propio puede ser útil si tus claves reales están almacenadas fuera de proceso.)

Si usas este método para especificar una clave privada, no debes usar "key_file()".

key_file()

Obtiene o establece el nombre del archivo que contiene la clave privada.

my $filename = $dkim->key_file;
$dkim->key_file('private.key');

El archivo de clave privada se usa para leer el objeto de clave privada. El nombre del archivo se debe especificar como "private.key".

Mail::DKIM::Signer - Mail::DKIM man page

NAME

Mail::DKIM::Signer - Crear firmas DKIM

VERSION

1.20240923

SYNOPSIS

    use Mail::DKIM::Signer;

    my $dkim = Mail::DKIM::Signer->new(
        KeyFile      => '/etc/mail/dkim.private',
        KeyPassphrase => 'secret',
        Domain       => 'example.com',
        Selector     => 'mx',
        Canonicalization => 'relaxed/simple', # opcional
        Method       => 'relaxed',            # opcional
    );

    # para enviar un mensaje con firma DKIM
    $dkim->header_hash(\%header_hash);
    $dkim->body_raw($body_ref);
    my $signed_message = $dkim->print_message;

    # o añadir una firma a un mensaje existente
    $dkim->load_message($message_ref);
    $dkim->sign();
    my $signed_message = $dkim->print_message;

    # o añadir una firma a un mensaje de correo que se está enviando
    use Mail::Send;
    my $ms = new Mail::Send;
    $ms->to('recipient@example.com');
    $ms->from('sender@example.com');
    $ms->subject('Test subject');

    my $fh = $ms->open;
    $dkim->open($fh); # Enlaza la salida a la firma DKIM
    print $fh $dkim->body_raw; # Imprime el cuerpo
    $dkim->close; # Finaliza la firma y escribe la cabecera DKIM
    $ms->close;

DESCRIPTION

Este módulo implementa un signador DKIM (DomainKeys Identified Mail).

El método de uso más común es crear un nuevo objeto Mail::DKIM::Signer, luego cargar el mensaje que se desea firmar (ya sea proporcionando las cabeceras y el cuerpo, o cargando un mensaje existente), y finalmente llamar a print_message() para obtener el mensaje firmado. También se puede utilizar para añadir una firma DKIM a un mensaje que se está construyendo y enviando actualmente usando Mail::Send.

Si se firman múltiples mensajes en una sola ejecución, o si se desea crear múltiples firmas para un solo mensaje, debe obtener la firma resultante como un objeto Mail::DKIM::Signature (ver signature() y signatures()) y añadirla usted mismo al mensaje.

CONSTRUCTOR

El constructor new() toma una serie de argumentos que se pueden utilizar para inicializar el objeto signador.

KeyFile
La ruta al archivo que contiene la clave privada.
KeyPassphrase
La frase de contraseña para la clave privada, si está protegida.
Domain
El dominio de correo electrónico a firmar. Debe coincidir con el dominio que se publica en el registro DNS TXT.
Selector
El selector DKIM. Este es el nombre del registro DNS TXT que contiene la clave pública.
Canonicalization
Especifica el método de canonización de cabeceras y cuerpo. Los valores posibles son relaxed/relaxed, relaxed/simple, simple/relaxed y simple/simple. El valor por defecto es relaxed/simple.
Method
Especifica el método de canonización del cuerpo. Esto es un alias para la parte del cuerpo de la canonización. Los valores posibles son relaxed y simple. Por defecto es relaxed. Ver la opción Canonicalization para la especificación completa.
Headers
Un arrayref de nombres de cabeceras a incluir en la firma. Por defecto, se firman todas las cabeceras.
Algorithm
El algoritmo de firma a utilizar. Por defecto es rsa-sha256.
ChunkSize
El tamaño de los trozos del cuerpo a usar al calcular el hash. Por defecto es 4096.
Policy
Ver la sección SIGNER POLICIES.
CAN_SIGN_HEADER
Si está configurado a un valor falso, la firma sólo incluirá el cuerpo. Esto se usa para DKIM-ADSP.
SignHeader
Si está configurado a un valor verdadero, la firma incluirá la cabecera 'DKIM-Signature'. Esto se usa para ARC (Authenticated Received Chain).

METHODS

algorithm()

Obtener o establecer el algoritmo de firma.

my $alg = $dkim->algorithm;
$dkim->algorithm('rsa-sha1');

body_raw()

Establece el cuerpo del mensaje para la firma.

my $body_ref = $dkim->body_raw($raw_body_string);

Devuelve una referencia al cuerpo del mensaje que se está firmando.

chunk_size()

Obtener o establecer el tamaño de los trozos del cuerpo.

my $size = $dkim->chunk_size;
$dkim->chunk_size(8192);

close()

Finaliza la firma y añade la cabecera DKIM al mensaje.

$dkim->close;

Esto debe llamarse después de haber escrito el cuerpo del mensaje o después de llamar a print_message().

domain()

Obtener o establecer el dominio de firma.

my $domain = $dkim->domain;
$dkim->domain('example.com');

header_hash()

Establece las cabeceras del mensaje para la firma.

my $headers_ref = $dkim->header_hash(\%header_hash);

Devuelve una referencia al hash de cabeceras del mensaje que se está firmando.

headers()

Obtener o establecer las cabeceras a firmar.

my $headers_ref = $dkim->headers;
$dkim->headers(['From', 'To', 'Subject']);

key_file()

Obtener o establecer la ruta al archivo de clave privada.

my $keyfile = $dkim->key_file;
$dkim->key_file('/path/to/private.key');

key_passphrase()

Obtener o establecer la frase de contraseña de la clave privada.

my $passphrase = $dkim->key_passphrase;
$dkim->key_passphrase('secret');

load_message()

Carga un mensaje de texto completo para firmar.

$dkim->load_message(\$message_string);

Analiza el mensaje para extraer las cabeceras y el cuerpo.

open()

Prepara el objeto para escribir el cuerpo del mensaje directamente a un manejador de archivo.

$dkim->open($filehandle);

Cuando se llama a esto, las futuras llamadas a print() o syswrite() en el manejador de archivo proporcionado se redirigirán a través del objeto Mail::DKIM::Signer.

Nota: Si usas este método para especificar un archivo de clave privada, no uses "key()".

method()

Obtener o establecer el método de canonización seleccionado.

$alg = $dkim->method;
$dkim->method('relaxed');

message_originator()

Acceder a la cabecera "From".

my $address = $dkim->message_originator;

Devuelve la "dirección de origen" encontrada en el mensaje, como un objeto Mail::Address. Esto es típicamente la (primera) dirección de nombre y correo electrónico encontrada en la cabecera From: . Si no hay una cabecera From: , se devuelve una objeto Mail::Address vacío.

Para obtener solo la dirección de correo electrónico, haz:

my $email = $dkim->message_originator->address;

Ver también "message_sender()".

message_sender()

Acceder a la cabecera "From" o "Sender".

my $address = $dkim->message_sender;

Devuelve la "dirección del emisor" encontrada en el mensaje, como un objeto Mail::Address. Esto es típicamente la (primera) dirección de nombre y correo electrónico encontrada en la cabecera Sender: . Si no hay una cabecera Sender: , es la (primera) dirección de nombre y correo electrónico en la cabecera From: . Si no hay ninguna cabecera, se devuelve un objeto Mail::Address vacío.

Para obtener solo la dirección de correo electrónico, haz:

my $email = $dkim->message_sender->address;

La "dirección del emisor" es el buzón del agente responsable de la transmisión del mensaje. Por ejemplo, si un secretario enviará un mensaje para otra persona, la "dirección del emisor" sería el secretario y la "dirección de origen" sería la persona real.

selector()

Obtener o establecer el selector actual.

$alg = $dkim->selector;
$dkim->selector('alpha');

signature()

Acceder al objeto de firma generado.

my $signature = $dkim->signature;

Devuelve el objeto de firma generado. El firma es un objeto de tipo Mail::DKIM::Signature. Si se han generado múltiples firmas, este método devuelve la última una.

La firma (como texto) debe ser preparada antes del mensaje para producir el mensaje resultado. Por lo menos, debe preceder a cualquier cabecera que se haya firmado.

signatures()

Acceder a la lista de objetos de firma generados.

my @signatures = $dkim->signatures;

Devuelve todas las firmas generadas, como una lista.

SIGNER POLICIES

El constructor new() toma un argumento opcional de tipo Policy. Este puede ser un objeto o clase con un método apply(), o simplemente una referencia a una subrutina. El método/subrutina se llamará con el objeto de firmante como argumento. La política está responsable de verificar el mensaje y especificar parámetros de firma. La política debe devolver un valor no cero para crear la firma, de lo contrario no se crearía ninguna. Ejemplo:

my $policyfn = sub {
    my $dkim = shift;
    # especificar parámetros de firma
    $dkim->algorithm('rsa-sha1');
    $dkim->method('relaxed');
    $dkim->domain('example.org');
    $dkim->selector('mx1');
    # devolver valor no cero para crear la firma
    return 1;
};

O la política puede crear la firma realmente usando el método add_signature() dentro del objeto de política. Si añades una firma, no necesitas devolver un valor no cero. Este mecanismo puede utilizarse para crear múltiples firmas, o para crear las firmas antiguas de estilo DomainKey.

my $policyfn = sub {
    my $dkim = shift;
    $dkim->add_signature(
            new Mail::DKIM::Signature(
                    Algorithm => 'rsa-sha1',
                    Method => 'relaxed',
                    Headers => $dkim->headers,
                    Domain => 'example.org',
                    Selector => 'mx1',
            ));
    $dkim->add_signature(
            new Mail::DKIM::DkSignature(
                    Algorithm => 'rsa-sha1',
                    Method => 'nofws',
                    Headers => $dkim->headers,
                    Domain => 'example.org',
                    Selector => 'mx1',
            ));
    return;
};

Si no se especifica una política, se usa el política por defecto. El política por defecto firma cada mensaje usando el dominio, el algoritmo, el método y el selector especificados en el constructor new().
