Mail::SpamAssassin::Plugin::FromNameSpoof(3) Documentación de Perl contribuida por el usuario Mail::SpamAssassin::Plugin::FromNameSpoof(3)

NOMBRE

FromNameSpoof - realiza varias pruebas para detectar intentos de suplantación utilizando la sección de nombre del encabezado From

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::FromNameSpoof

# From:nombre y From:dirección no coinciden, la coincidencia depende de la configuración de C<fns_check>
header  __PLUGIN_FROMNAME_SPOOF  eval:check_fromname_spoof()
# From:nombre y From:dirección no coinciden (igual que la regla anterior y C<fns_check 0>)
header  __PLUGIN_FROMNAME_DIFFERENT  eval:check_fromname_different()
# From:nombre y From:dirección difieren dominios
header  __PLUGIN_FROMNAME_DOMAIN_DIFFER  eval:check_fromname_domain_differ()
# From:nombre parece contener una dirección de correo electrónico (no es la misma que From:dirección)
header  __PLUGIN_FROMNAME_EMAIL  eval:check_fromname_contains_email()
# From:nombre coincide con cualquier To:dirección
header  __PLUGIN_FROMNAME_EQUALS_TO  eval:check_fromname_equals_to()
# From:nombre y From:propietarios de dirección difieren
header  __PLUGIN_FROMNAME_OWNERS_DIFFER  eval:check_fromname_owners_differ()
# From:nombre coincide con Reply-To:dirección
header  __PLUGIN_FROMNAME_EQUALS_REPLYTO  eval:check_fromname_equals_replyto()

DESCRIPCIÓN

Realiza varias pruebas contra el encabezado From:name para detectar suplantación. Se toman medidas para garantizar un mínimo de FP.

CONFIGURACIÓN

El plugin te permite omitir correos electrónicos que han sido firmados con DKIM por remitentes específicos:

fns_ignore_dkim googlegroups.com

FromNameSpoof permite una cercanía configurable al comparar From:dirección y From:nombre, la cercanía se puede ajustar con:

fns_extrachars 50

Nota que FromNameSpoof detecta el "propietario" de un dominio mediante la siguiente búsqueda:

<propietario>.<tld>

Por defecto, FromNameSpoof ignorará el TLD al comparar direcciones:

fns_check 1

Niveles de verificación:

0 - Verificación estricta de From:nombre != From:dirección
1 - Permite diferentes TLDs
2 - Permite diferentes alias pero el mismo dominio

La información del "propietario" también se puede mapear como alias con "fns_add_addrlist". Por ejemplo, para considerar "googlemail.com" como "gmail":

fns_add_addrlist (gmail) *@googlemail.com

ETIQUETAS

Las siguientes etiquetas se añaden al conjunto si se detecta una suplantación. Están disponibles para su uso en informes, campos de encabezado, otros plugins, etc.:

_FNSFNAMEADDR_
  Dirección de suplantación detectada del encabezado From:nombre
_FNSFNAMEDOMAIN_
  Dominio de suplantación detectado del encabezado From:nombre
_FNSFNAMEOWNER_
  Propietario de suplantación detectado del encabezado From:nombre
_FNSFADDRADDR_
  Dirección From:addr real
_FNSFADDRDOMAIN_ 
  Dominio From:addr real
_FNSFADDROWNER_
  Propietario From:addr real

EJEMPLO

header  __PLUGIN_FROMNAME_SPOOF  eval:check_fromname_spoof()
header  __PLUGIN_FROMNAME_EQUALS_TO  eval:check_fromname_equals_to()
meta     FROMNAME_SPOOF_EQUALS_TO (__PLUGIN_FROMNAME_SPOOF && __PLUGIN_FROMNAME_EQUALS_TO)
describe FROMNAME_SPOOF_EQUALS_TO From:name es suplantado para parecerse a la dirección To:
score    FROMNAME_SPOOF_EQUALS_TO 1.2
