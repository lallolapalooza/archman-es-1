Mail::Field::AddrList(3) Documentación de Perl contribuida por el usuario Mail::Field::AddrList(3)

NOMBRE

Mail::Field::AddrList - representación de objeto de listas de direcciones de correo electrónico

HERENCIA

Mail::Field::AddrList
  es un Mail::Field

SINOPSIS

use Mail::Field::AddrList;
$to   = Mail::Field->new('To');
$from = Mail::Field->new('From', 'poe@daimi.aau.dk (Peter Orbaek)');

$from->create('foo@bar.com' => 'Mr. Foo', poe => 'Peter');
$from->parse('foo@bar.com (Mr Foo), Peter Orbaek <poe>');
# crear una cadena de encabezado RFC822
print $from->stringify(),"\n";
# extraer direcciones de correo electrónico y nombres
@addresses = $from->addresses(); # cadenas
@names     = $from->names();     # cadenas
@addr      = $from->addr_list(); # objetos Mail::Address (v2.00)
# añadir una nueva dirección a la lista
$from->set_address('foo@bar.com', 'Mr. Foo');

DESCRIPCION

Define el análisis y formato del campo de direcciones, para los siguientes campos: "To", "From", "Cc", "Reply-To" y "Sender".

Se implementan todas las características de uso normal de la especificación del campo de direcciones de RFC2822, pero algunas construcciones complejas (y por lo tanto, apenas usadas) no serán comprendidas. Use Mail::Message::Field::Full en MailBox si necesita el cumplimiento total de RFC.

DIAGNÓSTICOS

Error: Se llamó a una subrutina indefinida <método>
Los objetos Mail::Field utilizan la carga automática para compilar nueva funcionalidad. Aparentemente, el método llamado no está implementado para la clase específica del objeto de campo.
