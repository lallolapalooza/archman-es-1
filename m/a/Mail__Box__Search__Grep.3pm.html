NOMBRE

Mail::Box::Search::Grep - seleccionar mensajes dentro de un buzón como grep lo hace

HERENCIA

Mail::Box::Search::Grep
  es un Mail::Box::Search
  es un Mail::Reporter

SINOPSIS

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open('Inbox');
my $filter = Mail::Box::Search::Grep->new(
   label => 'seleccionados',
   in => 'CUERPO', match => qr/abc?d*e/
);
my @msgs   = $filter->search($folder);
my $filter = Mail::Box::Search::Grep->new(
  field => 'To',
  match => $my_email,
);
if($filter->search($message)) {...}

DESCRIPCIÓN

Intenta encontrar algunas cadenas de texto en la cabecera y el pie de los mensajes. Se proporcionan varias formas de limitar la búsqueda a ciertos campos de cabecera, la cabecera completa, solo el cuerpo, el mensaje completo, e incluso multiparte binario.

El nombre grep deriva de la herramienta de UNIX grep, que significa: "Get Regular Expression and Print" (Obtener expresión regular e imprimir). Aunque puedes buscar usando expresiones regulares (a la manera de Perl), no tienes que imprimirlas como resultado.

Extiende "DESCRIPTION" en Mail::Box::Search.

Almacena los detalles sobre dónde se encontró la coincidencia. La búsqueda puede llevar mucho más tiempo cuando esta característica está activada.

Cuando se especifica una ARRAY, contendrá una lista de referencias a hashes. Cada hash contiene la información de una coincidencia. Una coincidencia en una línea de cabecera resultará en una línea con los campos "message", "part" y "field", donde el campo es un objeto Mail::Message::Field. Cuando la coincidencia está en el cuerpo, el hash contendrá un "message", "part", "linenr" y "line".

En caso de una referencia a CÓDIGO, esa rutina se llama para cada coincidencia. El primer argumento es este objeto de búsqueda y el segundo una referencia al mismo hash que se almacenaría en la array.

La opción "PRINT" llamará a printMatchedHead() o printMatchedBody() cuando se encuentre una cabecera o línea de cuerpo coincidente. La salida se minimiza al no reimprimir la información del mensaje en múltiples coincidencias en el mismo mensaje.

"DELETE" marcará el mensaje para ser eliminado en caso de coincidencia. Cuando se coincide con una parte de un multiparte, el mensaje completo se marcará para su eliminación.

field => undef|$campo|REGEX|CÓDIGO
No es válido en combinación con "in" establecido en "CUERPO". Pasa un nombre de $campo completo (sin distinción de mayúsculas y minúsculas). Usa una REGEX para seleccionar más de una línea de cabecera que se examinará. CÓDIGO es una rutina que se llama para cada campo en la cabecera. Se llama a CÓDIGO con la cabecera como primer argumento y el campo como segundo. Si CÓDIGO devuelve "true", se selecciona el mensaje.
in => 'CABECERA'|'CUERPO'|'MENSAJE'
label => $etiqueta
limit => $número
log => NIVEL
logical => 'REPLACE'|'AND'|'OR'|'NOT'|'AND NOT'|'OR NOT'
match => CADENA|REGEX|CÓDIGO
El patrón a buscar puede ser una EXPRESIÓN REGULAR o una CADENA. En ambos casos, la coincidencia tiene éxito si se encuentra en cualquier lugar dentro de los campos seleccionados.

Con una referencia a CÓDIGO, esa función se llamará para cada campo o línea de cuerpo. Cuando el resultado es "true", se entregan los detalles. Los formatos de llamada son

$code->($head, $field);          # para búsquedas en CABECERA
$code->($body, $linenr, $line);  # para búsquedas en CUERPO

El $head o $body son la cabecera o el cuerpo de un mensaje, respectivamente. El $field es una línea de cabecera que coincide. El $line y $linenr indican la línea coincidente en el cuerpo.

Ten en cuenta que cuando buscas en "MENSAJE", el código debe aceptar ambos formatos.

multiparts => BOOLEANO
trace => NIVEL

SYNOPSIS

  use Mail::Box::Search::Grep;
  my $grepbox = Mail::Box::Search::Grep->new(
      folder => $folder,
      pattern => qr/^Subject: .* RE:/,
  );
  $grepbox->init;
  my @matches = $grepbox->search($folder);
  print $grepbox->printMatch($match) for @matches;

DESCRIPTION

This class implements searching for messages which match a given pattern. It is a subclass of Mail::Box::Search.

The pattern can be a regular expression or a string. If it is a string, it is compiled into a regular expression.
