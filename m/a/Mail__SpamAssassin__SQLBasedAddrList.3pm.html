NOMBRE

Mail::SpamAssassin::SQLBasedAddrList - Lista de direcciones automática basada en SQL de SpamAssassin

SINOPSIS

  my $factory = Mail::SpamAssassin::SQLBasedAddrList->new()
  $spamtest->set_persistent_addr_list_factory ($factory);
... llamadas a clases de SpamAssassin...

SpamAssassin llamará:

  my $addrlist = $factory->new_checker($spamtest);
  $entry = $addrlist->get_addr_entry ($addr, $origip);
...

DESCRIPCIÓN

Una implementación de lista de direcciones persistente basada en SQL.

Ver "Mail::SpamAssassin::PersistentAddrList" para más información.

Utiliza el módulo DBI::DBD para acceder a tu base de datos favorita (probado con MySQL, SQLite y PostgreSQL) para almacenar las listas de bienvenida automática de los usuarios.

La estructura de tabla por defecto se ve así: CREATE TABLE awl (
username varchar(100) NOT NULL default '',
email varchar(255) NOT NULL default '',
ip varchar(40) NOT NULL default '',
msgcount int(11) NOT NULL default '0',
totscore float NOT NULL default '0',
signedby varchar(255) NOT NULL default '',
last_hit timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
PRIMARY KEY (username,email,signedby,ip) ) TYPE=MyISAM;

La definición de tu tabla puede cambiar dependiendo del controlador de base de datos que elijas. Hay una opción de configuración para anular el nombre de la tabla.

Este módulo introduce varias variables de configuración nuevas:

user_awl_dsn

user_awl_sql_username

user_awl_sql_password

user_awl_sql_table

user_awl_sql_override_username

ver "Mail::SpamAssassin::Conf" para más información.

new

clase pública (Mail::SpamAssassin::SQLBasedAddrList) new ()

Descripción: Este método crea una nueva instancia del factor SQLBasedAddrList y llama al método new del padre (PersistentAddrList).

new_checker

instancia pública (Mail::SpamAssassin::SQLBasedAddrList) new_checker (\% $main)

Descripción: Este método se llama para configurar una nueva interfaz de verificación y devolver una copia marcada de sí misma. Aquí es donde configuramos la conexión a la base de datos SQL basándonos en los valores de configuración.

get_addr_entry

instancia pública (\%) get_addr_entry (String $addr, String $signedby)

Descripción: Este método toma una $addr dada, la divide entre el componente de dirección de correo electrónico y el componente de IP, y realiza una búsqueda en la base de datos. Si no se encuentra nada en la base de datos, se crea y devuelve un hash de entrada vacío; de lo contrario, se devuelve una entrada que contiene la información encontrada. Si la opción de configuración with_awl_signer está habilitada, solo se tienen en cuenta las direcciones firmadas por la identidad de firma dada, o, si $signedby no está definido (o está vacío), solo se consideran las entradas no firmadas.

Se establece una clave, "exists_p", en 1 si una entrada ya existe en la base de datos; de lo contrario, se establece en 0.

add_score

instancia pública (\%) add_score (\% $entry, Integer $score)

Descripción: Este método agrega una $score dada a una $entry dada. Si la entrada se marcó como que no existía en la base de datos, se insertará una entrada; de lo contrario, se realizará una actualización simple.

NOTA: Este código utiliza una llamada SQL autorreferencial (es decir, set foo = foo + 1) que es compatible con la mayoría de los backends de bases de datos modernos, pero no con todo lo que se autodenomina base de datos SQL.

remove_entry

instancia pública () remove_entry (\% $entry)

Descripción: Este método elimina una $entry dada de la base de datos. Si la parte IP de la dirección de la entrada es igual a "none", entonces también se eliminan las entradas de IP de Perl para esta dirección.

finish

instancia pública () finish ()

Descripción: Este método proporciona la limpieza necesaria para la lista de direcciones.

_unpack_addr

instancia privada (String, String) _unpack_addr(string $addr)

Descripción: Este método divide una dirección de lista de bienvenida automática en sus dos componentes, correo electrónico y dirección IP.
