SINTAXIS

Los métodos disponibles son muy específicos para convertidores.

DESCRIPCIÓN

Esta clase es la base para diversos convertidores de mensajes (y partes de mensaje).

Extiende "DESCRIPCIÓN" en Mail::Reporter.

Convertidores entre objetos de mensaje

Internamente, se llama a Mail::Message::coerce() cuando se usen objetos externos donde se esperan objetos de mensaje. Este método creará automáticamente los objetos de conversión y los reutilizará.

  • Mail::Message::Convert::MailInternet

    Convierte los mensajes simples de Email::Simple a objetos de Mail::Message.

  • Mail::Message::Convert::MimeEntity

    Convierte los mensajes más complejos de MIME::Entity a objetos de Mail::Message.

  • Mail::Message::Convert::EmailSimple

    Convierte los mensajes de Email::Simple a objetos de Mail::Message.

Otros convertidores

  • Mail::Message::Convert::Html

    Realiza trucos con HTML/XMHTML sin ayuda de módulos externos.

  • Mail::Message::Convert::HtmlFormatText

    Convierte los objetos de cuerpo HTML a objetos de texto plano usando el módulo HTML::FormatText.

  • Mail::Message::Convert::HtmlFormatPS

    Convierte los objetos de cuerpo HTML a objetos de PostScript usando el módulo HTML::FormatPS.

  • Mail::Message::Convert::TextAutoformat

    Convierte un mensaje de texto en texto usando Text::Autoformat.

campos => NOMBRES|ARRAY-OF-NOMBRES|REGEXS
Selecciona los campos de encabezado que se van a manejar. Los campos demás no se usarán. El valor de esta opción se pasa a Mail::Message::Head::Complete::grepNames() cuando los convertidores necesiten seleccionar líneas de encabezado. Por defecto, los campos "To", "From", "Cc", "Bcc", "Date", "Subject", y sus "Resent-" correspondientes se seleccionan. Especifique una lista vacía para obtener todos los campos.
