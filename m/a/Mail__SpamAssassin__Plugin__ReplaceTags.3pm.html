NOMBRE

Mail::SpamAssassin::Plugin::ReplaceTags - etiquetas para reglas de SpamAssassin

El plugin permite que las reglas contengan etiquetas de expresiones regulares para ser utilizadas en reglas de expresiones regulares. Las etiquetas facilitan mucho el mantenimiento de reglas complicadas.

Advertencia: Este plugin depende de estructuras de datos específicas de esta versión de SpamAssassin; no se garantiza que funcione con otras versiones de SpamAssassin.

SINOPSIS

loadplugin    Mail::SpamAssassin::Plugin::ReplaceTags
replace_start <
replace_end   >
replace_tag   A       [a@]
replace_tag   G       [gk]
replace_tag   I       [il|!1y\?\xcc\xcd\xce\xcf\xec\xed\xee\xef]
replace_tag   R       [r3]
replace_tag   V       (?:[vu]|\\\/)
replace_tag   SP      [\s~_-]
body          VIAGRA_OBFU     /(?!viagra)<V>+<SP>*<I>+<SP>*<A>+<SP>*<G>+<SP>*<R>+<SP>*<A>+/i
describe      VIAGRA_OBFU     Intento de ofuscar "viagra"
replace_rules VIAGRA_OBFU

DEFINICIONES DE REGLAS Y AJUSTES PRIVILEGIADOS

replace_tag nombre_etiqueta expresión
Asigna una expresión regular válida a nombre_etiqueta.

Nota: No se recomienda incluir cuantificadores dentro de la etiqueta; es mejor incluirlos dentro de la propia regla para una mayor flexibilidad.

replace_pre nombre_etiqueta expresión
Asigna una expresión regular válida a nombre_etiqueta. La expresión se colocará antes de cada etiqueta que se reemplace.
replace_inter nombre_etiqueta expresión
Asigna una expresión regular válida a nombre_etiqueta. La expresión se colocará entre cada par de etiquetas adyacentes que se reemplace.
replace_post nombre_etiqueta expresión
Asigna una expresión regular válida a nombre_etiqueta. La expresión se colocará después de cada etiqueta que se reemplace.
replace_rules lista_de_pruebas
Especifica una lista de nombres de pruebas simbólicos (separados por espacios) de pruebas que deben modificarse utilizando etiquetas de reemplazo. Solo se admiten pruebas simples de expresiones regulares de cuerpo, encabezado, uri, completo y crudo.
replace_start cadena
replace_end cadena
Cadena(s) que indican el inicio y el final de una etiqueta dentro de una regla. Solo se encontrarán y reemplazarán las etiquetas encerradas por las cadenas de inicio y fin.
