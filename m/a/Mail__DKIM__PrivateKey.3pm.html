Mail__DKIM__PrivateKey(3pm)

Paquete: perl-mail-dkim

Licencias: PerlArtistic, GPL

Mail::DKIM::PrivateKey(3) Documentación de Perl aportada por el usuario Mail::DKIM::PrivateKey(3)

NOMBRE

Mail::DKIM::PrivateKey - una clave privada cargada en memoria para la firma DKIM

VERSIÓN

versión 1.20240923

SINOPSIS

my $key1 = Mail::DKIM::PrivateKey->load(
              File => '/ruta/a/private.key');
my $key2 = Mail::DKIM::PrivateKey->load(
              Data => $base64);
# usar la clave cargada en un objeto de firma DKIM
my $dkim = Mail::DKIM::Signer->new(
              Key => $key2,
            );

CONSTRUCTOR

load() - carga una clave privada en memoria

my $key1 = Mail::DKIM::PrivateKey->load(
              File => '/ruta/a/private.key');

Carga la clave codificada en Base64 desde el archivo especificado.

my $key2 = Mail::DKIM::PrivateKey->load(Data => $base64);

Carga la clave codificada en Base64 desde una cadena ya en memoria.

my $key3 = Mail::DKIM::PrivateKey->load(Cork => $openssl_object);

Crea un objeto envoltorio Mail::DKIM::PrivateKey para el objeto de clave OpenSSL dado. El objeto de clave debe ser de tipo Crypt::OpenSSL::RSA.

MÉTODOS

cork() - accede al objeto de clave OpenSSL subyacente

$openssl_object = $key->cork;

El objeto devuelto es de tipo Crypt::OpenSSL::RSA.

sign_digest()

Firma criptográficamente el digest del mensaje dado.

$key->sign_digest('SHA-1', sha1('mi texto del mensaje'));

El primer parámetro es el nombre del digest: uno de "SHA-1", "SHA-256".

El segundo parámetro es el digest del mensaje como una cadena binaria.

El resultado debe ser el digest firmado como una cadena binaria.
