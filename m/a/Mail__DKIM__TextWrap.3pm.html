NAME

Mail::DKIM::TextWrap - módulo de texto que se escribió para usar con DKIM

VERSION

versión 1.20240923

DESCRIPCIÓN

Este es un módulo general de texto que escribí porque tenía algunas necesidades específicas con Mail::DKIM que ninguno de los módulos de texto contemporáneos ofrecía.

En particular, ofrece la capacidad de cambiar las opciones de quebrado en el medio de un párrafo. Por ejemplo, con un firma DKIM:

DKIM-Signature: a=rsa; c=simple; h=first:second:third:fourth;
        b=Xr2mo2wmb1LZBwmEJElIPezal7wQQkRQ8WZtxpofkNmXTjXf8y2f0

se pueden insertar saltos de línea alrededor de cualquiera de los colones del tag h=, o cualquier carácter del tag b=. La manera en que implementé esto fue serializando la firma una elemento a la vez, cambiando las opciones de quebrado al inicio y al final de cada tag.

SYNOPSIS (PARA USOS DE MAIL::DKIM)

use Mail::DKIM::TextWrap;

Solo agrega la línea anterior a cualquier programa que use Mail::DKIM::Signer y tus firmas se automatizan para que estén quebradas a 72 caracteres.

SYNOPSIS (PARA OTROS USUARIOS)

my $output = "";
my $tw = Mail::DKIM::TextWrap->new(
                Margin => 10,
                Output => \$output,
            );
$tw->add("Mary had a little lamb, whose fleece was white as snow.\n");
$tw->finish;
print $output;

OPCIONES DE QUEBRADO

Opciones de quebrado pueden especificarse al llamar a new(), o cambiando propiedad como se necesita. Por ejemplo, para cambiar el número de caracteres permitidos por línea:

$tw->{Margin} = 20;
Break
una expresión regular que mapea caracteres donde se puede insertar un salto de línea. Los salto de línea se insertan DESPUÉS de un substring que coincide. El valor por defecto es "/\s/".
BreakBefore
una expresión regular que mapea caracteres donde se puede insertar un salto de línea. Los salto de línea se insertan ANTES de un substring que coincida. Aunque normalmente se usa Break, suele ser mejor usar BreakBefore. El valor por defecto es "undef".
Margin
define cuántos caracteres se permiten por línea. El valor por defecto es 72. Si no se encuentra un lugar para quebrar en una línea, la línea se extiende más allá de este margen.
Separator
el texto a insertar cuando se necesita un salto de línea. El valor por defecto es "\n". Si quieres establecer un indentado de línea siguiente (por ejemplo, todas las líneas excepto la primera comienzan con cuatro espacios), usa algo como "\n".
Swallow
una expresión regular que mapea caracteres que pueden omitirse cuando se produce un salto de línea. Por ejemplo, si insertas un salto de línea entre dos palabras, estás reemplazando un espacio con el salto de línea, así que estás omitiendo el espacio. Por otro lado, si insertas un salto de línea entre dos partes de un término hyphenado, estás quebrando en el guion, pero aún así quieres mostrar el guion. El valor por defecto es "/\s/".

CONSTRUCTOR

new() - crear un objeto de quebrado de texto

my $tw = Mail::DKIM::TextWrap->new(
                    Output => \$output,
                    %wrapping_options,
                );

El objeto de quebrado de texto encapsula las opciones actuales y el estado actual de la cadena de texto. Además de especificar las opciones de quebrado como se describe en el apartado anterior, los siguientes opciones son reconocidas:

Output
un referencia a escalar, o una referencia a globo, que especifica donde se va a escribir el texto "quebrado". Si no se especifica, se usa por defecto STDOUT.

MÉTODOS

add() - procesar algún texto que puede ser quebrado

$tw->add("Mary had a little lamb.\n");

Puedes add() todo el texto de una vez, o add() el texto en partes llamando add() varias veces.

finish() - llamar cuando no hay más texto que agregar

$tw->finish;

Llama esto cuando hay terminado el texto que se va a agregar, para que cualquier texto restante en los buffers de TextWrap se emita.

flush() - emitir el texto parcial actual, si lo hay

$tw->flush;

Llama esto cuando cambias las opciones de quebrado de TextWrap en el medio de una cadena de palabras. Explicitamente permite un salto de línea en la posición actual de la cadena, independientemente de si coincide con el patrón actual de quebrado.
