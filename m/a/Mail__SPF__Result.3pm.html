Mail::SPF::Result(3) Documentación Perl aportada por el usuario Mail::SPF::Result(3)

NOMBRE

Mail::SPF::Result - Clase de resultados SPF

VERSIÓN

versión 3.20250505

SINOPSIS

Para el uso general de objetos Mail::SPF::Result en código que llama a Mail::SPF, ver Mail::SPF. Para la interfaz detallada de Mail::SPF::Result y sus derivados, ver más abajo.

Lanzar resultados

package Mail::SPF::Foo;
use Error ':try';
use Mail::SPF::Result;
sub foo {
    if (...) {
        $server->throw_result('pass', $request)
    }
    else {
        $server->throw_result('permerror', $request, 'Invalid foo');
    }
}

Capturar resultados

package Mail::SPF::Bar;
use Error ':try';
use Mail::SPF::Foo;
try {
    Mail::SPF::Foo->foo();
}
catch Mail::SPF::Result with {
    my ($result) = @_;
    ...
};

Usar resultados

my $result_name     = $result->name;
my $result_code     = $result->code;
my $request         = $result->request;
my $local_exp       = $result->local_explanation;
my $authority_exp   = $result->authority_explanation
    if $result->can('authority_explanation');
my $spf_header      = $result->received_spf_header;

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::Result representa el resultado de una solicitud SPF.

Normalmente no hay necesidad de construir un objeto de resultado SPF directamente usando el constructor "new". En su lugar, use el método de clase "throw" para indicar al código que llama que se ha determinado un resultado SPF definitivo. En otras palabras, use Mail::SPF::Result y sus derivados igual que las excepciones. Ver Error o "eval" en perlfunc para saber cómo manejar excepciones en Perl.

Constructor

Se proporciona el siguiente constructor:

new($server, $request): devuelve Mail::SPF::Result
new($server, $request, $text): devuelve Mail::SPF::Result
Crea un nuevo objeto de resultado SPF y asocia los objetos Mail::SPF::Server y Mail::SPF::Request dados con él. Se puede especificar un texto de resultado opcional.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

throw($server, $request): lanza Mail::SPF::Result
throw($server, $request, $text): lanza Mail::SPF::Result
Lanza un nuevo objeto de resultado SPF, asociando los objetos Mail::SPF::Server y Mail::SPF::Request dados con él. Se puede especificar un texto de resultado opcional.

Nota: No escriba código que invoque "throw" en nombres de clase de resultado *literales*, ya que esto ignoraría cualquier clase de resultado derivada proporcionada por los módulos de extensión de Mail::SPF. Invoque el método "throw_result" en un objeto de Mail::SPF::Server en su lugar.

name: devuelve string
Abstracto. Devuelve el nombre del resultado de la clase (u objeto) de resultado. Para las clases de la jerarquía Mail::SPF::Result::*, esto corresponde aproximadamente a la parte final del nombre de la clase. Por ejemplo, devuelve "neutral-by-default" si se invoca en Mail::SPF::Result::NeutralByDefault. Ver también el método "code". Este método también se puede usar como método de instancia.

Este método debe ser implementado por subclases de Mail::SPF::Result para las cuales el nombre del resultado difiere del código del resultado.

class: devuelve class
class($name): devuelve class
Mapea el nombre de resultado dado a la clase correspondiente de Mail::SPF::Result::*, o devuelve la clase base de resultado (la clase en la que se invoca) si no se proporciona ningún nombre de resultado. Si se especifica un nombre de resultado desconocido, devuelve undef.
isa_by_name($name): devuelve boolean
Si la clase (u objeto) en la que se invoca este método representa el nombre de resultado dado (o un nombre derivado), devuelve true. De lo contrario, devuelve false. Este método también se puede usar como método de instancia.

Por ejemplo, "Mail::SPF::Result::NeutralByDefault->isa_by_name('neutral')" devuelve true.

code: devuelve string
Abstracto. Devuelve el código de resultado SPF básico ("pass", "fail", "softfail", "neutral", "none", "error", "permerror", "temperror") de la clase de resultado en la que se invoca. Todos los códigos de resultado válidos son también nombres de resultado válidos, pero lo contrario no se aplica. Este método también se puede usar como método de instancia.

Este método es abstracto y debe ser implementado por subclases de Mail::SPF::Result.

is_code($code): devuelve boolean
Si la clase (u objeto) en la que se invoca este método representa el código de resultado dado, devuelve true. De lo contrario, devuelve false. Este método también se puede usar como método de instancia.

Nota: El método "isa_by_name" proporciona un superconjunto de la funcionalidad de este método.

received_spf_header_name: devuelve string
Devuelve 'Received-SPF' como el nombre del campo para los campos de encabezado "Received-SPF". Este método debe ser anulado por módulos de extensión de Mail::SPF que proporcionan características no estándar (como política local) con la capacidad de diluir la pureza de los resultados SPF, para no engañar a los usuarios del campo de encabezado haciéndoles confundirlo con una indicación de un resultado SPF natural.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

throw: lanza Mail::SPF::Result
throw($server, $request): lanza Mail::SPF::Result
throw($server, $request, $text): lanza Mail::SPF::Result
Relanza un objeto de resultado SPF existente. Si se especifican objetos Mail::SPF::Server y Mail::SPF::Request, los asocia con el objeto de resultado, reemplazando los objetos de servidor y solicitud anteriores. Si también se especifica un texto de resultado, anula el texto de resultado anterior.
server: devuelve Mail::SPF::Server
Devuelve el objeto servidor de Mail::SPF que produjo el resultado en cuestión.
request: devuelve Mail::SPF::Request
Devuelve la solicitud SPF que condujo al resultado en cuestión.
text: devuelve string
Devuelve el mensaje de texto del objeto de resultado.
