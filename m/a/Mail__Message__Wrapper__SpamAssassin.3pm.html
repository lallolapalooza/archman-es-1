Mail::Message::Wrapper::SpamAssassin(3) Documentación de Perl aportada por el usuario Mail::Message::Wrapper::SpamAssassin(3)

NOMBRE

Mail::Message::Wrapper::SpamAssassin - Conecta un Mail::Message con Mail::SpamAssassin

HERENCIA

Mail::Message::Wrapper::SpamAssassin
  es un Mail::SpamAssassin::Message

SINOPSIS

# ADVERTENCIA: requiere el SpamAssassin ANTIGUO 2.x, no el nuevo 3.x
# Vea Mail::Box::Search::SpamAssassin para la interfaz preferida
# Sin embargo, es posible hacer:
my $msg    = ...;   # algún objeto Mail::Message
my $sa     = Mail::Message::Wrapper::SpamAssassin->new($msg);
my $spam   = Mail::SpamAssassin->new;
my $status = $spam->check($sa);
$msg->label(spam => 1) if $status->is_spam;
$status->rewrite_mail;  # Añade líneas de spam a la cabecera

DESCRIPCIÓN

ADVERTENCIA: Este módulo solo funciona con la versión antigua de SpamAssassin: versión 2.x. Las versiones más nuevas 3.x han cambiado la forma en que se guardan los mensajes. Por favor, contribuya con código mejorado.

La clase "Mail::Message::Wrapper::SpamAssassin" --perdón por el largo nombre del paquete-- es un envoltorio alrededor de Mail::SpamAssassin::Message, que es una interfaz al software de detección de spam de Mail::SpamAssassin.

MÉTODOS

$class->new($mensaje, %opciones)
Crea un envoltorio alrededor del $mensaje. Los campos ya presentes de una ejecución anterior de Spam::Assassin (o probablemente líneas falsas) se eliminan primero.
