NOMBRE

Mail::SpamAssassin::Plugin::Shortcircuit - cortocircuito de evaluación para ciertas reglas

SINOPSIS

loadplugin     Mail::SpamAssassin::Plugin::Shortcircuit
report Content analysis details:   (_SCORE_ puntos, _REQD_ requerido, s/c _SCTYPE_)
add_header all Status "_YESNO_, score=_SCORE_ required=_REQD_ tests=_TESTS_ shortcircuit=_SCTYPE_ autolearn=_AUTOLEARN_ version=_VERSION_"

DESCRIPCIÓN

Este plugin implementa un cortocircuito de pruebas simple. Hacer un cortocircuito de una prueba omitirá todas las reglas pendientes si esa prueba se activa. Además, se activará una regla simbólica llamada "SHORTCIRCUIT".

Se recomienda usar la opción "priority" para establecer reglas con valores S/O fuertes (es decir, 1.0) para que se ejecuten primero, y hacer una clasificación instantánea de spam o no spam basada en eso.

AJUSTES DE CONFIGURACIÓN

Los siguientes ajustes de configuración se utilizan para controlar el cortocircuito:

shortcircuit NOMBRE_DE_PRUEBA_SIMBÓLICA {ham|spam|on|off}
Hacer un cortocircuito de una prueba omitirá todas las reglas pendientes si esa prueba se activa.

Se recomienda usar la opción "priority" para establecer reglas con valores S/O fuertes (es decir, 1.0) para que se ejecuten primero, y hacer una clasificación instantánea de spam o no spam basada en eso.

Para anular una prueba que utiliza cortocircuito, puede establecer el tipo de clasificación en "off".

Tenga en cuenta que las consultas DNS y otras consultas de red se inician cuando SA alcanza la prioridad -100. Si desea hacer un cortocircuito del escaneo antes de que se envíen las consultas de red, necesita establecer una prioridad menor que -100 para cualquier regla de este tipo, como -200, como en los ejemplos a continuación.

La prueba con cortocircuito se establecerá automáticamente en prioridad -200, pero solo si la prioridad original no se modifica y es 0 por defecto.

on
Hace un cortocircuito del resto de las pruebas, pero no realiza una clasificación estricta de spam o no spam. En su lugar, utiliza la puntuación por defecto para la regla que está haciendo cortocircuito. Esto le permitiría, por ejemplo, definir una regla como 
body TEST /test/
describe TEST test rule that scores barely over spam threshold
score TEST 5.5
priority TEST -200
shortcircuit TEST on

El resultado de un mensaje que active la regla anterior sería una puntuación final de 5.5, en comparación con 100 (por defecto) si se clasificara como spam.

off
Deshabilita el cortocircuito en dicha regla.
spam
Hace un cortocircuito de la regla utilizando un conjunto de valores por defecto; anula la puntuación por defecto de esta regla con la puntuación de "shortcircuit_spam_score", establece la bandera de tflags "noautolearn" y establece la prioridad en -200. En otras palabras, es equivalente a: 
shortcircuit TEST on
priority TEST -200
score TEST 100
tflags TEST noautolearn
ham
Hace un cortocircuito de la regla utilizando un conjunto de valores por defecto; anula la puntuación por defecto de esta regla con la puntuación de "shortcircuit_ham_score", establece las banderas de tflags "noautolearn" y "nice", y establece la prioridad en -200. En otras palabras, es equivalente a: 
shortcircuit TEST on
priority TEST -200
score TEST -100
tflags TEST noautolearn nice
shortcircuit_spam_score n.nn (por defecto: 100)
Cuando se utiliza cortocircuito en una regla y el tipo de clasificación de cortocircuito se establece en "spam", este valor se aplicará en lugar de la puntuación por defecto para esa regla.
shortcircuit_ham_score n.nn (por defecto: -100)
Cuando se utiliza cortocircuito en una regla y el tipo de clasificación de cortocircuito se establece en "ham", este valor se aplicará en lugar de la puntuación por defecto para esa regla.
shortcircuit_min_ham_score n.nn (por defecto: undef)
Cuando se establece shortcircuit_min_ham_score, SpamAssassin dejará de procesar cuando la puntuación total sea inferior a este valor.
shortcircuit_max_spam_score n.nn (por defecto: undef)
Cuando se establece shortcircuit_max_spam_score, SpamAssassin dejará de procesar cuando la puntuación total sea superior a este valor.

ETIQUETAS

Las siguientes etiquetas se añaden al conjunto disponible para su uso en informes, encabezados, etc.:

_SC_              estado del cortocircuito (clasificación y nombre de la regla)
_SCRULE_          nombre de la regla que causó el cortocircuito 
_SCTYPE_          clasificación del cortocircuito ("spam", "ham", "default", "none")
