NOMBRE

Mail::Box::Tie::HASH - acceder a una carpeta de mensajes existente como un hash

HERENCIA

Mail::Box::Tie::HASH
  es un Mail::Box::Tie

SINOPSIS

tie my(%inbox), 'Mail::Box::Tie::HASH', $folder;
foreach my $msgid (keys %inbox)
{   print $inbox{$msgid};
    delete $inbox{$msgid};
}
$inbox{$msg->messageId} = $msg;

DESCRIPCIÓN

Ciertamente, al ver una carpeta como un conjunto de mensajes relacionados basados en el message-id, es lógico acceder a la carpeta a través de un hash.

Para un hash atado, se usa el message-id como clave. El message-id es generalmente único, pero cuando dos o más instancias del mismo mensaje están en la misma carpeta, una será marcada para eliminación y la otra será devuelta.

Esta implementación utiliza rutinas básicas de acceso a carpetas que están relacionadas con el message-id.

Extiende "DESCRIPCIÓN" en Mail::Box::Tie.

Interfaz Atada

$obj->CLEAR()
Elimina el contenido del hash. Esto no es realmente posible, pero todos los mensajes serán marcados para su eliminación.

» ejemplo:

%inbox = ();
%inbox = ($msg->messageId, $msg); #antes de agregar msg
$obj->DELETE($message_id)
Elimina el mensaje con el $message_id especificado.

» ejemplo:

delete $inbox{$msgid};
$obj->EXISTS($message_id)
Comprueba si existe un mensaje con un $message_id determinado.

» ejemplo:

if(exists $inbox{$msgid}) ...
$obj->FETCH($message_id)
Obtiene el mensaje con el id especificado. El mensaje devuelto puede ser un dummy si se utiliza la detección de hilos de mensajes. Devuelve "undef" cuando no hay ningún mensaje con el id especificado.

» ejemplo:

my $msg = $inbox{$msgid};
if($inbox{$msgid}->isDummy)  ...
$obj->FIRSTKEY()
Ver NEXTKEY().
$obj->NEXTKEY($previous)
FIRSTKEY() devuelve el primer par message-id/mensaje de la carpeta, y NEXTKEY devuelve el par message-id/mensaje del siguiente mensaje, en el orden en que el mensaje está almacenado en la carpeta.

Los mensajes marcados para eliminación **no** serán devueltos. Ver el método Mail::Box::messages() del tipo de carpeta para más información sobre el orden de los mensajes de la carpeta.

» ejemplo:

foreach my $msgid (keys %inbox) ...
foreach my $msg (values %inbox) ...
while(my ($msgid, $msg) = each %inbox) {
   $msg->print unless $msg->isDeleted;
}
$obj->STORE(undef, $message)
Almacena un mensaje en la carpeta. La clave debe ser "undef", porque se toma el message-id del mensaje especificado. Esto se muestra en el primer ejemplo. Sin embargo, como se ve, es un poco complicado especificar "undef", por lo tanto se acepta la cadena "undef".

El mensaje puede ser convertido a algo que pueda ser almacenado en el tipo de carpeta en cuestión. Se devuelve la instancia añadida.

» ejemplo:

$inbox{ (undef) } = $msg;
$inbox{undef} = $msg;
