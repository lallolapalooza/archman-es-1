Mail::Util(3) Documentación de Perl contribuida por el usuario Mail::Util(3)

NOMBRE

Mail::Util - funciones de utilidad de correo

HERENCIA

Mail::Util
  es un Exporter

SINOPSIS

use Mail::Util qw( ... );

DESCRIPCIÓN

Este paquete proporciona varias funciones de utilidad relacionadas con el correo. Cualquier función requerida debe especificarse explícitamente en la línea de uso para ser exportada al paquete que la llama.

FUNCIONES

mailaddress( [$direccion] )
Devuelve una suposición de la dirección de correo del usuario actual. El usuario puede forzar el valor de retorno estableciendo la variable de entorno MAILADDRESS. [2.10] Puede establecer la $direccion a través del parámetro.

ADVERTENCIA: Cuando no se proporciona a través de la variable de entorno, <mailaddress> busca varios archivos de configuración y otros datos ambientales. Aunque esto parece un comportamiento inteligente, (en mi opinión) no es lo suficientemente predecible como para ser utilizado. Por favor, establezca MAILADDRESS explícitamente y no confíe en la "detección automática", incluso cuando esta produzca una dirección correcta (en el momento).

ejemplo:

# en tu script principal
$ENV{MAILADDRESS} = 'yo@ejemplo.com';
# en cualquier otro lugar
use Mail::Util 'mailaddress';
print mailaddress;
# desde la v2.10
mailaddress "yo@ejemplo.com";
maildomain()
Intenta determinar la cadena del dominio de correo del usuario actual a través de los siguientes métodos
  • Busca la variable de entorno MAILDOMAIN, que se puede configurar desde fuera del programa. Esta es, con diferencia, la mejor manera de configurar el dominio.
  • Busca un archivo sendmail.cf y extrae el parámetro DH
  • Busca un archivo de configuración smail y usa el primer host definido en hostname(s)
  • Intenta una conexión SMTP (si Net::SMTP existe) primero a mailhost y luego a localhost
  • Usa el valor de Net::Domain::domainname (si Net::Domain existe)

ADVERTENCIA: En máquinas modernas, solo hay una buena manera de proporcionar información a este método: la primera; configure siempre MAILDOMAIN explícitamente.

ejemplo:

# en tu script principal
$ENV{MAILDOMAIN} = 'ejemplo.com';
# en cualquier otro lugar
use Mail::Util 'maildomain';
print maildomain;
read_mbox($archivo)
Lee el $archivo, un archivo de buzón de correo binmail, y devuelve una lista de referencias. Cada referencia es una referencia a un array que contiene un mensaje.

ADVERTENCIA: Este método no cita las líneas que accidentalmente también comienzan con el separador de mensajes "From", por lo que esta implementación puede considerarse defectuosa. Ver Mail::Box::Mbox
