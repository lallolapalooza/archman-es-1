NOMBRE

Mail::Box::Message::Destructed - un mensaje destruido

HERENCIA

Mail::Box::Message::Destructed
  es un Mail::Box::Message
  es un Mail::Message
  es un Mail::Reporter

SINOPSIS

$folder->message(3)->destruct;

DESCRIPCIÓN

Cuando se lee una carpeta de mensajes, cada mensaje se analizará en estructuras de Perl. Especialmente la estructura de la cabecera puede consumir una gran cantidad de memoria (los cuerpos de los mensajes se pueden mover a archivos temporales externos). Los mensajes destruidos han limpiado forzosamente toda la información de la cabecera y del cuerpo, y por lo tanto son mucho más pequeños. Alguna información útil todavía está en el objeto.

TENGA CUIDADO: una vez que un mensaje es destruido, no puede ser revivido. La destrucción impone la eliminación irreversible de la carpeta. Si tiene una carpeta abierta en modo de solo lectura, el mensaje permanecerá en esa carpeta, pero de lo contrario puede ser eliminado.

Extiende "DESCRIPCIÓN" en Mail::Box::Message.

Mail::Box::Message::Destructed

Este módulo proporciona la clase para un mensaje de correo electrónico que ha sido marcado para su eliminación.

SYNOPSIS

    use Mail::Box::Message::Destructed;

    my $msg = Mail::Box::Message::Destructed->new(%args);
    my $folder = Mail::Folder->new(...);
    my $destructed_msg = $folder->message(1)->destruct;
    my $destructed_msg = Mail::Box::Message::Destructed->coerce($folder->message(1));

DESCRIPTION

Esta clase representa un mensaje de correo electrónico que ha sido marcado para su eliminación. Se utiliza para optimizar el uso de memoria, ya que los mensajes marcados para su eliminación no necesitan mantener toda su información en memoria.

Mail::Box::Message::Destructed(3pm) - Arch Linux

NAME

Mail::Box::Message::Destructed - represents a message that has been destructed

INHERITANCE

This class is a subclass of Mail::Box::Message.

SYNOPSIS

  # Normally, you do not need to use this class directly.
  # It is used internally by Mail::Box.

  use Mail::Box;
  my $box = Mail::Box->new(...);
  my $msg = $box->get(1);
  $msg->destruct;
  # $msg is now a Mail::Box::Message::Destructed object

DESCRIPTION

A message object becomes a Mail::Box::Message::Destructed object when you explicitly free its memory using the destruct() method. This is typically done when a message is removed from a folder and you do not expect to access its content anymore.

Once destructed, the message object cannot be used anymore to access header or body content. It can only be used to get its unique message identifier (which is the same as its sequence number in the folder).

METHODS

This class inherits all methods from Mail::Box::Message. The following methods are overloaded:

head()
Called on a destructed message, this method will always fail with an error.
body()
Called on a destructed message, this method will always fail with an error.
get()
Called on a destructed message, this method will always fail with an error.
folder()
Returns the folder object where this message used to be stored.
id()
Returns the unique message identifier. This is the same as the sequence number within the folder.
sequence()
Returns the sequence number of the message within its folder.

DETAILS

The primary purpose of this class is to make sure that memory is freed when a message is no longer needed. It prevents accidental access to data that has been discarded.
