MAT_GETDIR(3) Manual de funciones de biblioteca MAT_GETDIR(3)

NOMBRE

Mat_GetDir — Devuelve una lista de los nombres de variables de un archivo MAT de MATLAB dada una estructura de archivo MAT

SINOPSIS

#include <matio.h>

char * const *
Mat_GetDir(mat_t *matfp, size_t *n);

DESCRIPCIÓN

La función Mat_GetDir() devuelve una lista de los nombres de variables de un archivo MAT de MATLAB dada la estructura del archivo MAT. El argumento de salida n contiene el número de variables del archivo MAT de MATLAB.

VALORES DE RETORNO

La función devuelve una lista de solo lectura de los nombres de variables de un archivo MAT de MATLAB.
