NOMBRE

Mat_VarFree — Libera una estructura de variable MAT.

SINOPSIS

#include <matio.h>

void
Mat_VarFree(matvar_t *matvar);

DESCRIPCIÓN

La función Mat_VarFree() libera la memoria utilizada por una estructura de variable MAT. Si la variable no se creó con la bandera MAT_F_DONT_COPY_DATA, los datos de la variable también se liberan.

VER TAMBIÉN

Mat_VarCreate(3), Mat_VarCreateStruct(3)
