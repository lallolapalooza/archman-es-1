NOMBRE

Mail::SpamAssassin::Message::Metadata - extraer metadatos de un mensaje

DESCRIPCIÓN

Esta clase se encarga de extraer "metadatos" de los mensajes para su uso como tokens Bayes, material para pruebas de evaluación u otras reglas. Los metadatos son datos suplementarios inferidos del mensaje, como los ejemplos a continuación.

Se mantiene en dos formas:

1. como pares nombre-valor de cadenas, presentados en formato de cabecera de correo. Por ejemplo, "X-Languages" => "en". Esta es la forma general para metadatos simples que son útiles como tokens Bayes, se pueden agregar a mensajes con marcas usando "add_header", etc., como la inferencia de relé confiable y la detección de idioma.

2. como estructuras de datos más complejas en el objeto $msg->{metadata}. Esta es la forma utilizada para metadatos como los datos de análisis HTML, que se almacenan allí para el acceso por parte del código de reglas de evaluación. Dado que no son cadenas simples, no se agregan como tokens Bayes por defecto (Bayes necesita cadenas simples).
