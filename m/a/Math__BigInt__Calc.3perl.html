Math::BigInt::Calc(3perl) Guía de referencia del programador de Perl Math::BigInt::Calc(3perl)

NOMBRE

Math::BigInt::Calc - Módulo Perl puro para dar soporte a Math::BigInt

SINOPSIS

# para usarlo con Math::BigInt
use Math::BigInt lib => 'Calc';
# para usarlo con Math::BigFloat
use Math::BigFloat lib => 'Calc';
# para usarlo con Math::BigRat
use Math::BigRat lib => 'Calc';
# establecer explícitamente la longitud de la base y si "usar enteros"
use Math::BigInt::Calc base_len => 4, use_int => 1;
use Math::BigInt lib => 'Calc';

DESCRIPCIÓN

Math::BigInt::Calc hereda de Math::BigInt::Lib.

En esta biblioteca, los números se representan internamente en base B = 10**N, donde N es el mayor entero posible que no causa desbordamiento en los cálculos intermedios. Los elementos de la base B se almacenan en un array, con el elemento menos significativo almacenado en el elemento de índice cero. No hay elementos de cero iniciales, excepto un único elemento cero cuando el número es cero. Por ejemplo, si B = 10000, el número 1234567890 se representa internamente como [7890, 3456, 12].

OPCIONES

Al cargar el módulo, calcula el exponente máximo, es decir, la potencia de 10, que se puede usar con y sin "use integer" en los cálculos. El valor predeterminado es usar este exponente máximo. Si la combinación del valor 'base_len' y el valor 'use_int' excede el valor máximo, se produce un error.

base_len
La longitud de la base se puede especificar explícitamente con la opción 'base_len'. El valor debe ser un entero positivo. 
use Math::BigInt::Calc base_len => 4;  # usar 10000 como base interna
use_int
Esta opción se utiliza para especificar si se debe usar "use integer" en los cálculos internos. El valor se interpreta como un valor booleano, por lo que se usa 0 o "" para falso y cualquier otra cosa para verdadero. Si 'base_len' no se especifica junto con 'use_int', se utiliza el valor actual para la longitud de la base. 
use Math::BigInt::Calc use_int => 1;   # usar "use integer" internamente

MÉTODOS

Esta descripción general contiene solo los métodos específicos de "Math::BigInt::Calc". Para los demás métodos, consulte Math::BigInt::Lib.

_base_len()
Especifica la longitud de base deseada y si se debe habilitar "use integer" en los cálculos. 
Math::BigInt::Calc -> _base_len($base_len, $use_int);

Tenga en cuenta que es mejor especificar la longitud de base y si se deben usar enteros como opciones al cargar el módulo, por ejemplo, así:

use Math::BigInt::Calc base_len => 6, use_int => 1;

VER TAMBIÉN

Math::BigInt::Lib para una descripción de la API.

Bibliotecas alternativas Math::BigInt::FastCalc, Math::BigInt::GMP, Math::BigInt::Pari, Math::BigInt::GMPz y Math::BigInt::BitVect.

Algunos de los módulos que utilizan estas bibliotecas: Math::BigInt, Math::BigFloat y Math::BigRat.
