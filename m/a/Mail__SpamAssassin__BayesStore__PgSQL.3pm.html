NOMBRE

Mail::SpamAssassin::BayesStore::PgSQL - Implementación del Módulo de Almacenamiento Bayesiano Específico de PostgreSQL

DESCRIPCIÓN

Este módulo implementa un módulo de almacenamiento bayesiano específico de PostgreSQL.

Extiende Mail::SpamAssassin::BayesStore::SQL y sobrescribe cualquier método que realice llamadas SQL involucrando la columna de tokens. Dado que PostgreSQL usa BYTEA para el tipo de columna de token, debes asegurarte de que el controlador DBD realice el escape adecuado. Puedes lograr esto enlazando la columna de token a un tipo específico.

En las versiones 8.3 y posteriores, synchronous_commit está deshabilitado para un mayor rendimiento. No se garantiza que los datos se almacenen hasta (3 * wal_writer_delay) (por defecto: 0.6s) después de ser escritos. Esta compensación funciona para Bayes porque nos preocupamos por los datos agregados y un pequeño período de tiempo puede perderse sin sacrificar la precisión.

Descripción: Este método recupera los tokens especificados ($tokens) del almacenamiento y devuelve una referencia de array de arrays con el conteo de spam, conteo de ham y tiempo del último acceso.

tok_touch

instancia pública (Booleano) tok_touch (Cadena $token,
Cadena $atime)

Descripción: Este método actualiza el tiempo de acceso (atime) de los tokens dados ($token).

Se asume que el token ya existe en la base de datos.

tok_touch_all

instancia pública (Booleano) tok_touch (\@ $tokens
Cadena $atime)

Descripción: Este método realiza una actualización masiva de la lista dada de tokens $tokens, si el tiempo de acceso del token existente (atime) es < $atime.

Se asume que los tokens ya existen en la base de datos.

Nunca deberíamos tocar más que N_SIGNIFICANT_TOKENS, por lo que podemos hacer algunas suposiciones sobre cómo manejar los datos (es decir, no es necesario agrupar como lo hacemos en tok_get_all)

cleanup

instancia pública (Booleano) cleanup ()

Descripción: Este método realiza cualquier limpieza necesaria antes de pasar a la siguiente operación.

clear_database

instancia pública (Booleano) clear_database ()

Descripción: Este método elimina todos los registros para un usuario en particular.

Los llamadores deben ser conscientes de que cualquier error devuelto por este método podría causar inconsistencias en la base de datos para el usuario dado.

NAME

Mail::SpamAssassin::BayesStore::PgSQL - PostgreSQL Bayes database backend

DESCRIPTION

This is a Bayes database backend for SpamAssassin that uses PostgreSQL as the database. It uses the DBI Perl module and the DBD::Pg driver to connect to the PostgreSQL server.

METHODS

This class inherits from Mail::SpamAssassin::BayesStore, so all the methods defined there are available. Additionally, it provides the following methods:

new ( %Args )

Creates a new BayesStore::PgSQL object. The following arguments are supported:

dbhandle

A DBI database handle to an existing PostgreSQL database connection.

dbname

The name of the PostgreSQL database to connect to.

dbuser

The username to use for connecting to the database.

dbpass

The password to use for connecting to the database.

dbhost

The hostname or IP address of the PostgreSQL server.

dbport

The port number of the PostgreSQL server.

table

The name of the Bayes table to use. Defaults to 'bayes'.

Private Methods

These methods are intended for internal use only and should not be called directly.

_init_storage ( )

Initializes the database storage by creating the necessary table if it doesn't exist.

_execute_sql ( $sql, @bind_args )

Executes a given SQL query with optional bind arguments.

_fetch_all_rows ( $sql, @bind_args )

Executes a given SQL query and fetches all resulting rows.

_fetch_one_row ( $sql, @bind_args )

Executes a given SQL query and fetches a single resulting row.

_execute_single_update ( $sql, @bind_args )

Executes a single SQL update statement and returns the number of affected rows.
