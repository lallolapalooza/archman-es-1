NAME

DecodeShortURLs - Verificar URLs cortas

SYNOPSIS

loadplugin    DecodeShortURLs
url_shortener tinyurl.com
url_shortener_get bit.ly
body HAS_SHORT_URL          eval:short_url()
describe HAS_SHORT_URL      Mensaje contiene una o más URLs cortadas
body SHORT_URL_REDIR        eval:short_url_redir()
describe SHORT_URL_REDIR    Mensaje contiene una URL cortada que resultó en una redirección válida
body SHORT_URL_CHAINED      eval:short_url_chained()
describe SHORT_URL_CHAINED  Mensaje contiene una URL cortada que se enlaza a otras enlaces cortados
body SHORT_URL_MAXCHAIN     eval:short_url_maxchain()
describe SHORT_URL_MAXCHAIN Mensaje contiene una URL cortada que causa demasiadas redirecciones
body SHORT_URL_LOOP         eval:short_url_loop()
describe SHORT_URL_LOOP     Mensaje contiene una URL cortada que se recorre hacia sí mismo
body SHORT_URL_200          eval:short_url_code('200') # Puede verificar cualquier código HTTP no redirect
describe SHORT_URL_200      Mensaje contiene una URL cortada que devuelve código HTTP 200
body SHORT_URL_404          eval:short_url_code('404') # Puede verificar cualquier código HTTP no redirect
describe SHORT_URL_404      Mensaje contiene una URL cortada que devuelve código HTTP 404
uri URI_TINYURL_BLOCKED      m,https://tinyurl.com/app/nospam,
describe URI_TINYURL_BLOCKED Mensaje contiene una URL tinyurl que ha sido bloqueada debido al abuso
uri URI_BITLY_BLOCKED       m,^https://bitly.com/a/blocked,
describe URI_BITLY_BLOCKED  Mensaje contiene una URL bit.ly que ha sido bloqueada debido al abuso

DESCRIPTION

Este plugin busca URLs cortadas por una lista de servicios de enlace de URL. Al encontrar una URL que coincida, el plugin enviará una solicitud HTTP al servicio de enlace de URL y recuperará el header Location que apunta a la URL real cortada. Luego, esta URL se agregará a la lista de URIs extraídas por SpamAssassin, que puede ser accedida por reglas de URI y plugins como URIDNSBL.

Este plugin seguirá las redirecciones enlazadas, donde una URL cortada se enlaza a otra URL cortada. El límite de profundidad de las redirecciones enlazadas puede ser configurado con "max_short_url_redirections".

El máximo de "max_short_urls" URLs cortadas se verifica en un mensaje (10 por defecto). Al establecerlo en 0, se desactivan las solicitudes HTTP, permitiendo solo el test short_url() y reportar encontrados los enlaces cortados.

Todas las reglas de tipo soportadas para verificar URLs cortadas y el estado de redirección se documentan en la sección SYNOPSIS.

NOTAS

Este plugin ejecuta en la hook check_dnsbl (prioridad -100), permitiendo que modifique la lista de URI parseada antes de las reglas normales de URI o el plugin URIDNSBL.

USUARIOS DE CONFIGURACIÓN

url_shortener dominio [dominio...] (valor por defecto: ninguno)
Dominios que deben considerarse como un enlace cortado. Si el dominio comienza con un punto, se verifica el TLD del nivel 3 principal.
url_shortener_get dominio [dominio...] (valor por defecto: ninguno)
Alias de "url_shortener". La solicitud HTTP se realizará con el método GET, en lugar del defecto HEAD. Es necesario para servicios como bit.ly para devolver una URL bloqueada correctamente.
clear_url_shortener [dominio] [dominio...]
Elimina los dominios configurados para url_shortener y url_shortener_get, por ejemplo, para reemplazar los valores por defecto desde una canalización de actualización. Si se especifican dominios, solo se eliminan de la lista.

CONFIGURACIÓN DE USO DE SERVICIOS

url_shortener_cache_type (valor por defecto: ninguno)
El tipo de caché que se está utilizando. Actualmente solo se soporta el valor "dbi" que implica "url_shortener_cache_dsn" es una cadena de conexión DBI. Se necesita el módulo DBI.
url_shortener_cache_dsn (valor por defecto: ninguno)
La cadena de conexión DBI del banco de datos a utilizar.

Para SQLite, el banco de datos se creará automáticamente si no existe, y el camino y archivo especificado deben ser lectibles y escritos por el usuario que ejecuta spamassassin o spamd.

Para MySQL/MariaDB o PostgreSQL, vea sql-directory para cláusulas de creación de tablas de bases de datos.

Se necesita el módulo DBI adecuado para tu base de datos. Por ejemplo, DBD::SQLite, DBD::mysql, DBD::MariaDB o DBD::Pg.

La versión mínima requerida de SQLite es 3.24.0 (disponible desde DBD::SQLite 1.59_01).

Ejemplo:

url_shortener_cache_dsn dbi:SQLite:dbname=/var/lib/spamassassin/DecodeShortURLs.db
url_shortener_cache_username (valor por defecto: ninguno)
El usuario que se usará para conectarse al banco de datos. No se usa para SQLite.
url_shortener_cache_password (valor por defecto: ninguno)
La contraseña que se usará para conectarse al banco de datos. No se usa para SQLite.
url_shortener_cache_ttl (valor por defecto: 86400)
La longitud de tiempo que una entrada de caché será válida en segundos. El valor por defecto es 86400 (1 día).

Ver "url_shortener_cache_autoclean" para limpieza de bases de datos.

CONFIGURACIÓN DE ADMINISTRADOR

url_shortener_cache_autoclean (valor por defecto: 1000)
Automáticamente elimina entradas antiguas de la base de datos. El valor describe la probabilidad de un run aleatorio de 1/x. El valor por defecto de 1000 significa que la limpieza se realiza aproximadamente una vez por cada 1000 mensajes procesados. Un valor de 1 significa que la base de datos se limpia cada vez que se procesa un mensaje.
url_shortener_loginfo (valor por defecto: 0 (desactivado))
Si esta opción está activada (establecida como 1), entonces las URLs cortadas y las URLs descodificadas se registran con prioridad info.
url_shortener_timeout (valor por defecto: 5)
El tiempo máximo que puede tomar una solicitud HTTP para una URL cortada, en segundos.
max_short_urls (valor por defecto: 10)
El máximo de URLs cortadas que se buscarán por mensaje. Las redirecciones enlazadas no se cuentan, solo las URLs cortadas iniciales.

Establecerlo en 0 desactiva las solicitudes HTTP, permitiendo solo el test short_url() y reportar cualquier URL cortada encontrada.

max_short_url_redirections (valor por defecto: 10)
El máximo de profundidad de redirecciones enlazadas que puede generar una URL cortada.
url_shortener_user_agent (valor por defecto: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/101.0.4951.67 Safari/537.36)
El valor de User-Agent que se usa para las solicitudes HTTP. Algunos servicios requieren que sea similar a un navegador común.

Mail::SpamAssassin::Plugin::DecodeShortURLs(3pm)

NOMBRE

Mail::SpamAssassin::Plugin::DecodeShortURLs - extraer información de URLs cortas

SINOPSIS

use Mail::SpamAssassin::Plugin::DecodeShortURLs;

DESCRIPCIÓN

Este plugin intenta descomprimir URLs cortas de servicios como bit.ly, t.co, etc. Esto permite que SpamAssassin examine el contenido de la página de destino en lugar de solo la URL corta, lo que puede ayudar a detectar correos electrónicos de phishing y otros contenidos maliciosos.

NOTAS

Este plugin requiere acceso a Internet para realizar las solicitudes de descompresión. Tenga en cuenta las implicaciones de rendimiento y seguridad al habilitarlo.

AJUSTES DE USUARIO

No hay ajustes de usuario específicos para este plugin.

AJUSTES PRIVILEGIADOS

No hay ajustes privilegiados específicos para este plugin.

AJUSTES DE ADMINISTRADOR

Los administradores pueden configurar el comportamiento de este plugin a través de la configuración global de SpamAssassin.

AGRADECIMIENTOS

Este plugin se basa en las capacidades de la biblioteca LWP para realizar solicitudes HTTP.
