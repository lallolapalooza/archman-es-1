Math::BigInt::Lib(3perl) Guía de referencia para programadores de Perl Math::BigInt::Lib(3perl)

NOMBRE

Math::BigInt::Lib - clase padre virtual para bibliotecas de Math::BigInt

SINOPSIS

# En la biblioteca backend para Math::BigInt et al.
package Math::BigInt::MiBackend;
use Math::BigInt::Lib;
our @ISA = qw< Math::BigInt::Lib >;
sub _new { ... }
sub _str { ... }
sub _add { ... }
sub _sub { ... }
...
# En tu programa principal.
use Math::BigInt lib => 'MiBackend';

DESCRIPCION

Este módulo proporciona soporte para cálculos con números enteros grandes. No está diseñado para ser utilizado directamente, sino más bien como una clase padre para bibliotecas backend utilizadas por Math::BigInt, Math::BigFloat, Math::BigRat y módulos relacionados.

Otras bibliotecas backend incluyen Math::BigInt::Calc, Math::BigInt::FastCalc, Math::BigInt::GMP y Math::BigInt::Pari.

Para permitir múltiples bibliotecas de números enteros grandes, Math::BigInt fue reescrito para usar una biblioteca plug-in para las rutinas matemáticas centrales. Cualquier módulo que cumpla con la API puede ser usado por Math::BigInt al usar esto en tu programa:

use Math::BigInt lib => 'nombre_libreria';

'nombre_libreria' es el nombre largo, como 'Math::BigInt::Pari', o solo la versión corta, como 'Pari'.

Notas generales

Una biblioteca solo necesita manejar números enteros grandes sin signo. La prueba de validez de los parámetros de entrada la realiza el llamador, por lo que no hay necesidad de preocuparse por desbordamientos (por ejemplo, en _sub() y _dec()) o por división por cero (por ejemplo, en _div() y _mod()) o casos similares.

Algunas bibliotecas usan métodos que no modifican su argumento, y algunas bibliotecas ni siquiera usan objetos, sino referencias sin bendecir. Debido a esto, los métodos de la biblioteca siempre se llaman como métodos de clase, no como métodos de instancia:

$x = Clase -> metodo($x, $y);     # así
$x = $x -> metodo($y);            # no así ...
$x -> metodo($y);                 # ... ni así

Y con métodos booleanos

$bool = Clase -> metodo($x, $y);  # así
$bool = $x -> metodo($y);         # no así

Los valores de retorno son siempre objetos, cadenas, escalares de Perl o verdadero/falso para las rutinas de comparación.

Constructores

Los siguientes métodos son obligatorios: _new(), _str(), _add() y _sub(). Sin embargo, los cálculos serán muy lentos sin _mul() y _div().

CLASE->_new(CADENA)
Convierte una cadena que representa un número decimal sin signo a un objeto que representa el mismo número. La entrada está normalizada, es decir, coincide con "^(0|[1-9]\d*)$".
CLASE->_cero()
Devuelve un objeto que representa el número cero.
CLASE->_uno()
Devuelve un objeto que representa el número uno.
CLASE->_dos()
Devuelve un objeto que representa el número dos.
CLASE->_diez()
Devuelve un objeto que representa el número diez.
CLASE->_from_bin(CADENA)
Devuelve un objeto dada una cadena que representa un número binario. La entrada tiene un prefijo '0b' y coincide con la expresión regular "^0[bB](0|1[01]*)$".
CLASE->_from_oct(CADENA)
Devuelve un objeto dada una cadena que representa un número octal. La entrada tiene un prefijo '0' y coincide con la expresión regular "^0[1-7]*$".
CLASE->_from_hex(CADENA)
Devuelve un objeto dada una cadena que representa un número hexadecimal. La entrada tiene un prefijo '0x' y coincide con la expresión regular "^0x(0|[1-9a-fA-F][\da-fA-F]*)$".
CLASE->_from_bytes(CADENA)
Devuelve un objeto dada una cadena de bytes que representa el número. La cadena de bytes está en orden de bytes big-endian, por lo que la cadena de dos bytes "\x01\x00" debería dar un valor de salida que represente el número 256.
CLASE->_from_base(CADENA, BASE, COLLSEQ)
Devuelve un objeto dada una cadena CADENA, una base BASE y una secuencia de colación COLLSEQ. Cada carácter en CADENA representa un valor numérico idéntico a la posición del carácter en COLLSEQ. Todos los caracteres en CADENA deben estar presentes en COLLSEQ.

Si BASE es menor o igual a 94, y no se especifica una secuencia de colación, se utiliza la siguiente secuencia de colación predeterminada. Consiste en todos los 94 caracteres ASCII imprimibles excepto el espacio en blanco:

0123456789                  # ASCII  48 a  57
ABCDEFGHIJKLMNOPQRSTUVWXYZ  # ASCII  65 a  90
abcdefghijklmnopqrstuvwxyz  # ASCII  97 a 122
!"#$%&'()*+,-./             # ASCII  33 a  47
:;<=>?@                     # ASCII  58 a  64
[\]^_`                      # ASCII  91 a  96
{|}~                        # ASCII 123 a 126

Si se usa la secuencia de colación predeterminada y BASE es menor o igual a 36, se ignora la capitalización de CADENA.

Por ejemplo, con base 3 y la secuencia de colación "-/|", el carácter "-" representa 0, "/" representa 1 y "|" representa 2. Así, si CADENA es "/|-", la salida es 1 * 3**2 + 2 * 3**1 + 0 * 3**0 = 15.

Los siguientes ejemplos muestran la conversión binaria, octal, decimal y hexadecimal estándar. Todos los ejemplos devuelven 250.

$x = $clase -> _from_base("11111010", 2)
$x = $clase -> _from_base("372", 8)
$x = $clase -> _from_base("250", 10)
$x = $clase -> _from_base("FA", 16)

Algunos ejemplos más, todos devolviendo 250:

$x = $clase -> _from_base("100021", 3)
$x = $clase -> _from_base("3322", 4)
$x = $clase -> _from_base("2000", 5)
$x = $clase -> _from_base("caaa", 5, "abcde")
$x = $clase -> _from_base("42", 62)
$x = $clase -> _from_base("2!", 94)
CLASE->_from_base_num(ARRAY, BASE)
Devuelve un objeto dada una matriz de valores y una base. Este método es equivalente a _from_base(), pero opera sobre números en una matriz en lugar de caracteres en una cadena. A diferencia de _from_base(), todos los valores de entrada pueden ser arbitrariamente grandes. 
$x = $clase -> _from_base_num([1, 1, 0, 1], 2)    # $x es 13
$x = $clase -> _from_base_num([3, 125, 39], 128)  # $x es 65191

CLASS->_modinv(OBJ1, OBJ2)
Devuelve el inverso multiplicativo módulo OBJ2, es decir, devuelve OBJ3 tal que (OBJ3 * OBJ1) % OBJ2 = 1 % OBJ2. El resultado se devuelve como dos argumentos. Si no existe el inverso multiplicativo, ambos argumentos son indefinidos. De lo contrario, el primer argumento es un número (objeto) y su signo ("+" o "-").
El valor devuelto, con su signo, debe ser un valor positivo en el rango 1, 2, ..., OBJ2-1 o el mismo valor menos OBJ2. Por ejemplo, si los argumentos son objetos representando los números 7 y 5, el método debe devolver un objeto representando el número 3 y un signo "+", ya que (3*7) % 5 = 1 % 5, o un objeto representando el número 2 y un signo "-", ya que (-2*7) % 5 = 1 % 5.
CLASS->_modpow(OBJ1, OBJ2, OBJ3)
Devuelve la exponenciação modular, es decir, (OBJ1 ** OBJ2) % OBJ3.
CLASS->_rsft(OBJ, N, B)
Devuelve el resultado después de desplazar OBJ N dígitos a la derecha en base B. Esto es equivalente a realizar la división entera por B**N y descartar el resto, a menos que sea mucho más rápido.
Por ejemplo, si el objeto $obj representa el número hexadecimal 0xabcde, "_rsft($obj, 2, 16)" devuelve un objeto representando el número 0xabc. El "resto", 0xde, es descartado y no se devuelve.
CLASS->_lsft(OBJ, N, B)
Devuelve el resultado después de desplazar OBJ N dígitos a la izquierda en base B. Esto es equivalente a multiplicar por B**N, a menos que sea mucho más rápido.
CLASS->_log_int(OBJ, B)
Devuelve el logaritmo de OBJ en base BASE truncado a un entero. Este método devuelve dos argumentos, el OBJ y un ESTADO. El ESTADO es un escalar Perl; es 1 si OBJ es el resultado exacto, 0 si el resultado se truncó para dar OBJ, y undefined si no se sabe si OBJ es el resultado exacto.
CLASS->_ilog2(OBJ)

El ESTADO es un escalar Perl; es 1 si OBJ es el resultado exacto, 0 si el resultado se truncó para dar OBJ, y undefined si no se sabe si OBJ es el resultado exacto.
Este método es equivalente al método más general _log_int() cuando se usa con un argumento de base 2, pero el método _ilog2() puede ser más rápido.
CLASS->_ilog10(OBJ)
Devuelve el logaritmo base 10 de OBJ redondeado hacia abajo a la más cercana entera, es decir, int(log10(OBJ)). En contexto de lista, este método devuelve dos argumentos, el OBJ y un ESTADO. El ESTADO es un escalar Perl; es 1 si OBJ es el resultado exacto, 0 si el resultado se truncó para dar OBJ, y undefined si no se sabe si OBJ es el resultado exacto.
Este método es equivalente al método más general _log_int() cuando se usa con un argumento de base 10, pero el método _ilog10() puede ser más rápido. Además, el resultado de _ilog10() siempre es 1 menor que el resultado de _len().

ENVUELVE TU PROPIA

Si deseas portar tu biblioteca C favorita para números grandes a la interfaz Math::BigInt, puedes tomar cualquiera de los módulos existentes como una guía aproximada. Deberías realmente envolver las últimas suites de pruebas de Math::BigInt y Math::BigFloat con tu módulo, y reemplazar en ellas cualquiera de lo siguiente:

use Math::BigInt;

por esto:

use Math::BigInt lib => 'tu_libreria';

De esta manera te aseguras de que tu biblioteca realmente funcione al 100% dentro de Math::BigInt.
