NOMBRE

Mail::Send - Interfaz simple de correo electrónico

SINOPSIS

require Mail::Send;
$msg = Mail::Send->new;
$msg = Mail::Send->new(Subject => 'ejemplo', To => 'timbo');
$msg->to('usuario@host');
$msg->to('usuario@host', 'usuario2@ejemplo.com');
$msg->subject('asunto de ejemplo');
$msg->cc('usuario@host');
$msg->bcc('alguien@otro.com');
$msg->set($encabezado, @valores);
$msg->add($encabezado, @valores);
$msg->delete($encabezado);
# Inicia el cliente de correo y establece los encabezados. El manejador de archivo devuelto
# por open() es una instancia de la clase Mail::Mailer.
# Los argumentos para el método open() se pasan al constructor de Mail::Mailer.
$fh = $msg->open;   # algún cliente de correo por defecto
$fh = $msg->open('sendmail'); # explícito
print $fh "Cuerpo del mensaje";
$fh->close          # completa el mensaje y lo envía
    or die "no se pudo enviar el mensaje completo: $!\n";

DESCRIPCIÓN

Mail::Send crea mensajes de correo electrónico sin usar el conocimiento de Mail::Header, lo que significa que ¡tú debes realizar todo el escape y plegado! También: no olvides escapar los puntos al inicio de línea. La simplicidad tiene su precio.

Cuando tengas tiempo, échale un vistazo a Mail::Transport, que forma parte de la suite MailBox.

MÉTODOS

Constructores

Mail::Send->new(PARES)
Se puede usar una lista de campos de encabezado (proporcionados como PARES clave-valor) para inicializar el objeto, limitados a los pocos proporcionados como métodos: "to", "subject", "cc" y "bcc". Para otros campos de encabezado, usa add().

Campos de encabezado

$obj->add($nombre_campo, @valores)
Agrega valores a la lista de valores definidos para el $nombre_campo.
$obj->bcc(@valores)
$obj->cc(@valores)
$obj->delete($nombre_campo)
$obj->set($nombre_campo, @valores)
Los @valores reemplazarán los valores antiguos para el $nombre_campo. Se devuelve la LISTA de valores después de la modificación.
$obj->subject(@valores)
$obj->to(@valores)

Envío

$obj->open(%opciones)
Las %opciones se usan para iniciar un objeto de cliente de correo a través de Mail::Mailer::new(). Luego, se llama a Mail::Mailer::open() con el conocimiento recopilado en este objeto "Mail::Send".

Advertencia: este módulo implementa smtp crudo, lo que significa que debes escapar las líneas que comienzan con un punto, añadiendo uno delante.
