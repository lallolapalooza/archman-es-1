NOMBRE

Mail::SpamAssassin::Plugin::AccessDB - comprueba el mensaje contra la base de datos de acceso

SINOPSIS

loadplugin     Mail::SpamAssassin::Plugin::AccessDB
header   ACCESSDB  eval:check_access_database('/etc/mail/access.db')
describe ACCESSDB  El mensaje habría sido capturado por accessdb
tflags   ACCESSDB  userconf
score    ACCESSDB  2

DESCRIPCIÓN

Muchos MTA admiten bases de datos de acceso, como Sendmail, Postfix, etc. Este plugin realiza comprobaciones similares para ver si un mensaje habría sido marcado.

La regla devuelve falso si no se encuentra una entrada, o si la entrada tiene un RHS de OK o SKIP.

La regla devuelve verdadero si existe una entrada y tiene un RHS de REJECT, ERROR o DISCARD.

Nota: solo se comprueba la primera palabra (dividida por caracteres no alfanuméricos) del RHS, por lo que "error:5.7.1:..." significa "ERROR".
