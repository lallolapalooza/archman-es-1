MAT_OPEN(3) Manual de funciones de biblioteca MAT_OPEN(3)

NOMBRE

Mat_Open — Abre un archivo MAT de MATLAB.

SINOPSIS

#include <matio.h>

mat_t
Mat_Open(const char *matname, int mode);

DESCRIPCIÓN

La función Mat_Open() abre un archivo MAT de MATLAB para acceso de solo lectura o de lectura-escritura.

EJEMPLOS

#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

int main(int argc, char **argv)
{
    mat_t *matfp;

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Error al abrir el archivo MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
