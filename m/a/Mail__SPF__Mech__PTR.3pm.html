Mail::SPF::Mech::PTR(3) Documentación de Perl aportada por el usuario Mail::SPF::Mech::PTR(3)

NOMBRE

Mail::SPF::Mech::PTR - clase del mecanismo "ptr" del registro SPF

VERSIÓN

versión 3.20250505

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::Mech::PTR representa un mecanismo de registro SPF de tipo "ptr".

Constructores

Se proporcionan los siguientes constructores:

new(%options): devuelve Mail::SPF::Mech::PTR
Crea un nuevo objeto de mecanismo "ptr" de registro SPF.

%options es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

qualifier
domain_spec
Véase "new" en Mail::SPF::Mech.
new_from_string($text, %options): devuelve Mail::SPF::Mech::PTR; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMech
Crea un nuevo objeto de mecanismo "ptr" de registro SPF analizando la cadena y las opciones dadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

default_qualifier
qualifier_pattern
Véase "Métodos de clase" en Mail::SPF::Mech.
name: devuelve string
Devuelve 'ptr'.
name_pattern: devuelve Regexp
Devuelve una expresión regular que coincide con un nombre de mecanismo de 'ptr'.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

text
qualifier
params
stringify
Véase "Métodos de instancia" en Mail::SPF::Mech.
domain_spec: devuelve Mail::SPF::MacroString
Devuelve el parámetro "domain-spec" del mecanismo.
match($server, $request): devuelve boolean
Comprueba si el nombre de dominio de destino del mecanismo, o un subdominio del mismo, es un nombre de dominio "válido" para la dirección IP de la solicitud dada (véase "ip_address" en Mail::SPF::Request), y devuelve true si lo es, o false en caso contrario. Véase "valid_domain_for_ip_address" en Mail::SPF::Util para ver cómo se validan los dominios. Véase RFC 4408, 5.5, para la descripción de un algoritmo equivalente.
