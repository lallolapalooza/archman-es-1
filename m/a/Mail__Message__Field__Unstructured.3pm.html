NOMBRE

Mail::Message::Field::Unstructured - campo no estructurado inteligente

HERENCIA

Mail::Message::Field::Unstructured
  es un Mail::Message::Field::Full
  es un Mail::Message::Field
  es un Mail::Reporter

SINOPSIS

my $f = Mail::Message::Field::Unstructured->new('Comments', 'hi!');

DESCRIPCION

Los campos no estructurados contienen información que no está restringida de ninguna manera. RFC2822 define algunos campos no estructurados, pero por defecto, todos los campos desconocidos también son no estructurados. Los atributos y comentarios no tienen significado para los campos no estructurados, pero la codificación sí.

Extiende "DESCRIPTION" en Mail::Message::Field::Full.

Cuando $data se especifica como una sola línea, la parte del contenido se considera correctamente codificada (de caracteres) y escapada. Típicamente, es una línea tal como se lee de un archivo. El plegado de la línea se mantiene tal cual.

En caso de que se proporcionen más de un argumento, el segundo se considera el CUERPO. Los atributos y otras cosas especiales no están definidos para campos no estructurados y, por lo tanto, no son opciones válidas. El CUERPO puede ser una sola cadena, un solo OBJETO o un array de OBJETOS. Los objetos se convierten a cadena (en una lista separada por comas). Cada elemento del CUERPO se interpreta con la codificación especificada.

Cuando el CUERPO está vacío, la construcción del objeto falla: se devuelve "undef". Mejora la base, ver "METHODS" en Mail::Message::Field::Full

NAME

Mail::Message::Field::Unstructured - abstract class for unstructured fields

INHERITANCE

Extends Mail::Message::Field::Full.

This class is part of the Perl Message object.

This class is abstract: you MUST NOT create instances of this class. The subclasses define the actual structure of the field.

SYNOPSIS

  use Mail::Message::Field::Unstructured;

    # This class is abstract, no examples to show.

DESCRIPTION

This is an abstract base class for fields that contain unstructured data.

Unstructured fields are not defined by RFC-822, but are used often enough.

The content of such a field is presented to the user as a single block of text. The system does not parse this content further.

All subclasses MUST implement the parse() method and the new() constructor.

OVERLOADED

-
The arithmetic negation operator ~ is overloaded to return the string representation of the field.
==
Compares the field name with the argument. Case is ignored.
eq
Compares the field value with the argument. Case is ignored.
ne
Compares the field value with the argument. Case is ignored.
lt
Compares the field value with the argument. Case is sensitive.
le
Compares the field value with the argument. Case is sensitive.
gt
Compares the field value with the argument. Case is sensitive.
ge
Compares the field value with the argument. Case is sensitive.

DIAGNOSTICS

Warning: Attributes are not supported for unstructured fields
Cast by new()
Warning: Field content is not numerical: $content
The numeric value of a field is requested (for instance the "Lines" or "Content-Length" fields should be numerical), however the data contains weird characters. Cast by toInt()
Error: Field name too long (max $length), in '$name'
It is not specified in the RFCs how long a field name can be, but at least it should be a few characters shorter than the line wrap. Cast by fold()
Warning: Illegal character in charset '$charset'
The field is created with an utf8 string which only contains data from the specified character set. However, that character set can never be a valid name because it contains characters which are not permitted. Cast by encode()
Warning: Illegal character in field name $name
A new field is being created which does contain characters not permitted by the RFCs. Using this field in messages may break other e-mail clients or transfer agents, and therefore mutulate or extinguish your message. Cast by consume()
Warning: Illegal character in language '$lang'
The field is created with data which is specified to be in a certain language, however, the name of the language cannot be valid: it contains characters which are not permitted by the RFCs. Cast by encode()
Warning: Illegal encoding '$encoding', used 'q'
The RFCs only permit base64 ("b " or "B ") or quoted-printable ("q" or "Q") encoding. Other than these four options are illegal. Cast by encode()
Warning: No extras for unstructured fields
Cast by new()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
