NOMBRE

Mail::SpamAssassin::Client - Cliente para el Protocolo spamd

SINOPSIS

my $client = Mail::SpamAssassin::Client->new({
                              port => 783,
                              host => 'localhost',
                              username => 'algunusuario'});
o
my $client = Mail::SpamAssassin::Client->new({
                              socketpath => '/ruta/al/socket',
                              username => 'algunusuario'});
Opcionalmente toma timeout, que se aplica a IO::Socket para la
conexión inicial. Si no se proporciona, por defecto son 30 segundos.
if ($client->ping()) {
  print "Ping está ok\n";
}
my $result = $client->process($testmsg);
if ($result->{isspam} eq 'True') {
  hacer algo con el mensaje spam aquí
}

DESCRIPCIÓN

Mail::SpamAssassin::Client es un módulo que proporciona una implementación en perl del protocolo spamd.

MÉTODOS PÚBLICOS

new

clase pública (Mail::SpamAssassin::Client) new (\% $args)

Descripción: Este método crea un nuevo objeto Mail::SpamAssassin::Client.

process

instancia pública (\%) process (String $msg)

Descripción: Este método llama al servidor spamd con el comando PROCESS.

El valor de retorno es una referencia de hash que contiene varias piezas de información, si están disponibles:

content_length

isspam

score

threshold

message

report

spam_report

instancia pública (\%) spam_report (String $msg)

Descripción: El método implementa la llamada report.

Ver el método process para el valor de retorno.

spam_report_ifspam

instancia pública (\%) spam_report_ifspam (String $msg)

Descripción: El método implementa la llamada report_ifspam. Se devolverá un informe solo si el mensaje es spam.

Ver el método process para el valor de retorno.

check

instancia pública (\%) check (String $msg)

Descripción: El método implementa la llamada check.

Ver el método process para el valor de retorno.

headers

instancia pública (\%) headers (String $msg)

Descripción: Este método implementa la llamada headers.

Ver el método process para el valor de retorno.

learn

instancia pública (Boolean) learn (String $msg, Integer $learntype)

Descripción: Este método implementa la llamada learn. $learntype debe ser un entero, 0 para spam, 1 para ham y 2 para olvidar. El valor de retorno es un booleano que indica si el mensaje fue aprendido o no.

Un valor de retorno undef indica que hubo un error y deberías comprobar los valores resp_code/resp_msg para determinar cuál fue el error.

report

instancia pública (Boolean) report (String $msg)

Descripción: Este método proporciona la interfaz report a spamd.

revoke

instancia pública (Boolean) revoke (String $msg)

Descripción: Este método proporciona la interfaz revoke a spamd.

ping

instancia pública (Boolean) ping ()

Descripción: Este método realiza un ping del servidor y devuelve 0 o 1 dependiendo de si el servidor respondió correctamente.

MÉTODOS PRIVADOS

_create_connection

instancia privada (IO::Socket) _create_connection ()

Descripción: Este método establece una conexión IO::Socket adecuada basada en los argumentos utilizados al crear el objeto cliente.

En caso de fallo, establece un código de error interno y devuelve undef.

_parse_response_line

instancia privada (@) _parse_response_line (String $line)

Descripción: Este método analiza la línea/cabecera de respuesta inicial del servidor y devuelve sus partes.

Tenemos esto como un método separado en caso de que algún día decidamos ser elegantes con la línea de respuesta.

_clear_errors

instancia privada () _clear_errors ()

Descripción: Este método borra cualquier error actual.

_filter

instancia privada (\%) _filter (String $msg, String $command)

Descripción: Realiza la llamada real al servidor spamd para los diversos métodos de filtro (es decir, PROCESS, CHECK, HEADERS, etc.). El comando que se pasa se envía al servidor spamd.

El valor de retorno es una referencia de hash que contiene varias piezas de información, si están disponibles:

content_length

isspam

score

threshold

message (si está disponible)

report (si está disponible)
