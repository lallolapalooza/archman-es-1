Mail::AuthenticationResults::Token(3) Documentación de Perl aportada por el usuario Mail::AuthenticationResults::Token(3)

NOMBRE

Mail::AuthenticationResults::Token - Clase base para modelar partes de la cabecera AuthenticationResults

VERSIÓN

version 2.20250709

DESCRIPCIÓN

Clases que representan una cabecera Authentication Results tokenizada, utilizada en el análisis sintáctico.

MÉTODOS

new( $cabecera, $args )

Devuelve un nuevo objeto Token analizado a partir de la cadena $cabecera dada, utilizando $args

El valor de $args depende de la subclase de Token utilizada; los tipos posibles son:

Mail::AuthenticationResults::Token::Assignment un operador de asignación Mail::AuthenticationResults::Token::Comment un comentario Mail::AuthenticationResults::Token::QuotedString una cadena entre comillas Mail::AuthenticationResults::Token::Separator un separador Mail::AuthenticationResults::Token::String una cadena

new_from_value( $valor )

Crea un nuevo token a partir del valor dado.

value()

Devuelve el valor de la instancia de Token actual.

remainder()

Devuelve el resto de la cadena de cabecera después de analizar el token actual.

parse()

Ejecuta el analizador sintáctico en $cabecera actual y configura value() y remainder().

is()

Devuelve el tipo de token que somos.
