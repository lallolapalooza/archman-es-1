Mail::SpamAssassin::Plugin::DNSEval(3) Documentación de Perl contribuida por el usuario Mail::SpamAssassin::Plugin::DNSEval(3)

NOMBRE

DNSEVAL - buscar URLs en listas negras DNS

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::DNSEval
rbl_headers EnvelopeFrom,Reply-To,Disposition-Notification-To
header     RBL_IP    eval:check_rbl_headers('rbl', 'rbl.example.com.', '127.0.0.2')
describe   RBL_IP    Dirección de remitente asociada con dominios de spam
tflags     RBL_IP    net
reuse      RBL_IP
Banderas tflags adicionales compatibles a partir de SpamAssassin 3.4.3:
 domains_only - solo se consultan los componentes de "host" que no son direcciones IP
 ips_only - solo se consultarán direcciones IP como componente "host"

DESCRIPCIÓN

El plugin DNSEval consulta el DNS para ver si un dominio o una dirección IP presente en una de las cabeceras de correo electrónico se encuentra en una lista negra RBL específica.

PREFERENCIAS DEL USUARIO

Las siguientes opciones se pueden usar tanto en archivos de configuración a nivel de sitio ("local.cf") como específicos del usuario ("user_prefs") para personalizar cómo SpamAssassin maneja los mensajes de correo entrantes.

rbl_headers
Esta opción indica a SpamAssassin en qué cabeceras buscar contenido
utilizado para consultar la RBL especificada.
Si en el contenido de las cabeceras hay una dirección de correo electrónico,
una dirección IP o un nombre de dominio, se comprobará en la RBL especificada.
La opción de configuración puede ser anulada pasando una lista de cabeceras como
último parámetro a check_rbl_headers.
Las cabeceras predeterminadas que se comprueban son:
  • EnvelopeFrom
  • Reply-To
  • Disposition-Notification-To
  • X-WebmailclientIP
  • X-Source-IP
check_rbl_from_domain
Esto comprueba todos los nombres de dominio de las direcciones de remitente como una alternativa a check_rbl_from_host. A partir de la v3.4.1, ha sido mejorado para incluir una subprueba para un octeto específico.
check_rbl_ns_from
Esto comprueba el servidor DNS del nombre de dominio de la dirección de remitente. Es posible incluir una subprueba para un octeto específico.
check_rbl_rcvd
Esto comprueba todas las cabeceras recibidas de dominios o direcciones IP contra una RBL específica. Es posible incluir una subprueba para un octeto.
