Mat_Rewind(3)

Paquete: libmatio

MAT_REWIND(3) Manual de funciones de biblioteca MAT_REWIND(3)

NOMBRE

Mat_Rewind — Rebobina un archivo MAT abierto al principio.

SINOPSIS

#include <matio.h>

int
Mat_Rewind(mat_t *matfp);

DESCRIPCIÓN

Rebobina un archivo MAT abierto para que Mat_VarReadNext() o Mat_VarReadNextInfo() lea la primera variable en el archivo.

VALORES DE RETORNO

La función devuelve 0 si tiene éxito, o -1 si falla.

EJEMPLOS

El siguiente ejemplo muestra una lista de variables en el archivo MAT y solicita al usuario el índice de la variable a leer. Si el índice es válido, el archivo se restablece al principio y las variables se leen hasta que se alcanza el índice seleccionado.

#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

int
main(int argc, char **argv)
{
    mat_t    *matfp;
    matvar_t *matvar;
    int       idx, num_variables;

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Error abriendo el archivo MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    idx = 0;
    while ( NULL != (matvar = Mat_VarReadNextInfo(matfp)) ) {
        idx++;
        printf("%3d. %s0, idx, matvar->name);
        Mat_VarFree(matvar);
    }
    num_variables = idx;
    if ( num_variables > 0 ) {
        printf("¿Qué variable quieres leer? ");
        if ( 0 == fscanf(stdin,"%d",&idx) ) {
            printf("¡Selección de variable inválida!0);
        } else if ( idx < 1 || idx > num_variables ) {
            fprintf(stderr, "¡Este es un índice de variable inválido!0);
        } else {
            int k;
            Mat_Rewind(matfp);
            for ( k = 1; k < idx; k++ ) {
                matvar = Mat_VarReadNextInfo(matfp);
                Mat_VarFree(matvar);
            }
            matvar = Mat_VarReadNext(matfp);
            Mat_VarPrint(matvar, 1);
            Mat_VarFree(matvar);
        }
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}

VER TAMBIÉN

Mat_Open(3), Mat_Close(3), Mat_VarReadNext(3), Mat_VarReadNextInfo(3), Mat_VarPrint(3)
