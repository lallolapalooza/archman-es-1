NOMBRE

Mail::Message::Field::Addresses - Campos con direcciones de correo electrónico

HERENCIA

Mail::Message::Field::Addresses
  es un Mail::Message::Field::Structured
  es un Mail::Message::Field::Full
  es un Mail::Message::Field
  es un Mail::Reporter

SINAPSIS

my $cc = Mail::Message::Field::Full->new('Cc');
my $me = Mail::Message::Field::Address->parse('"Test" <test@mail.box>')
   o morir;
my $other = Mail::Message::Field::Address->new(phrase => 'Otro',
      address => 'other@example.com')
   o morir;
$cc->addAddress($me);
$cc->addAddress($other, group => 'ellos');
$cc->addAddress(phrase => 'tercero', address => 'more@any.museum',
  group => 'ellos');
my $group = $cc->addGroup(name => 'colegas');
$group->addAddress($me);
$group->addAddress(phrase => "Tú", address => 'you@example.com');
my $msg = Mail::Message->build(Cc => $cc);
imprimir $msg->string;
my $g  = Mail::Message::Field::AddrGroup->new(...);
$cc->addGroup($g);

DESCRIPCIÓN

Todos los campos de encabezado que solo contienen direcciones de correo electrónico. No todos los campos de dirección tienen las mismas posibilidades, pero todos se analizan de la misma manera: nunca se sabe cuán rotas están las aplicaciones que producen estos mensajes.

Cuando intente crear construcciones que no estén permitidas para un cierto tipo de campo, recibirá una advertencia.

RFC5322 permitía grupos de direcciones para "To" y "Cc", pero no para ser utilizados en (entre otros) los campos "From" y "Sender". Esta restricción fue levantada por RFC6854 (2013). https://www.rfc-editor.org/rfc/rfc6854

Extiende "Acceso al contenido" en Mail::Message::Field::Structured.

$obj->addAddress( [$address], %options )
Añade una $address al campo. Las direcciones están organizadas en grupos. Si no se especifica ningún grupo, se toma el grupo predeterminado para almacenar la dirección. Si no se especifica ninguna $address, la opción debe ser suficiente para crear un Mail::Message::Field::Address a partir de ella. Véase las %options de Mail::Message::Field::Address::new().

Métodos de la clase

addGroup($group|%options)
Añade un grupo de direcciones a este campo. Se puede especificar un $group, que es un objeto Mail::Message::Field::AddrGroup, o se crea uno para ti usando las %options. Se devuelve el grupo. 
-Opción--Por defecto
 name    ''
name => CADENA
addresses()
Devuelve una lista con todas las direcciones definidas en cualquier grupo de direcciones: todas las direcciones que se especifican en la línea. Las direcciones son objetos Mail::Message::Field::Address. Mejora la base, ver "Acceso al contenido" en Mail::Message::Field.

» ejemplo:

my @addr = $field->addresses;

DIAGNÓSTICOS

Advertencia: El contenido del campo no es numérico: $content
Se solicita el valor numérico de un campo (por ejemplo, los campos "Lines" o "Content-Length" deberían ser numéricos), sin embargo, los datos contienen caracteres extraños. Se convierte con toInt()
Error: El nombre del campo es demasiado largo (máx $length), en '$name'
No se especifica en las RFC cómo de largo puede ser un nombre de campo, pero al menos debería ser unos pocos caracteres más corto que el ajuste de línea. Se convierte con fold()
Advertencia: Carácter ilegal en charset '$charset'
El campo se crea con una cadena utf8 que solo contiene datos del conjunto de caracteres especificado. Sin embargo, ese conjunto de caracteres nunca puede ser un nombre válido porque contiene caracteres que no están permitidos. Se convierte con encode()
Advertencia: Carácter ilegal en el nombre del campo $name
Se está creando un nuevo campo que contiene caracteres no permitidos por las RFCs. El uso de este campo en mensajes puede romper otros clientes de correo electrónico o agentes de transferencia, y por lo tanto mutilar o extinguir tu mensaje. Se convierte con consume()
Advertencia: Carácter ilegal en el idioma '$lang'
El campo se crea con datos que se especifican para estar en un idioma determinado, sin embargo, el nombre del idioma no puede ser válido: contiene caracteres que no están permitidos por las RFCs. Se convierte con encode()
Advertencia: Codificación ilegal '$encoding', se usó 'q'
Las RFCs solo permiten la codificación base64 ("b " o "B ") o quoted-printable ("q" o "Q"). Cualquier otra de estas cuatro opciones es ilegal. Se convierte con encode()
Error: No hay atributos para campos de dirección.
No es posible añadir atributos a los campos de dirección: no está permitido por las RFCs. Se convierte con addAttribute()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas sí implementan este método, sin embargo la clase en cuestión no lo hace. Probablemente deberías investigar esto y posiblemente informar al autor del paquete. Se convierte con notImplemented()
