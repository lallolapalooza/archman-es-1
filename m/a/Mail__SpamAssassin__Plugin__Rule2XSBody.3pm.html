NOMBRE

Mail::SpamAssassin::Plugin::Rule2XSBody - acelera SpamAssassin compilando expresiones regulares

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::Rule2XSBody

DESCRIPCIÓN

Este plugin utilizará archivos de objeto de código nativo que representan el conjunto de reglas, para proporcionar mejoras significativas en la evaluación de reglas.

Tenga en cuenta que "sa-compile" debe ejecutarse con antelación, para compilar el conjunto de reglas utilizando "re2c" y el compilador C. Consulte la documentación de "sa-compile" para obtener más detalles.
