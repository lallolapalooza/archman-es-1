NAME

Mail::Box::Locker - gestionar el control de archivos de correo

INHERITANCE

Mail::Box::Locker
  es un Mail::Reporter
Mail::Box::Locker es extendido por
  Mail::Box::Locker::DotLock
  Mail::Box::Locker::FcntlLock
  Mail::Box::Locker::Flock
  Mail::Box::Locker::Multi
  Mail::Box::Locker::Mutt
  Mail::Box::Locker::NFS
  Mail::Box::Locker::POSIX

SYNOPSIS

use Mail::Box::Locker;
my $locker = new Mail::Box::Locker(folder => $folder);
$locker->lock;
$locker->isLocked;
$locker->hasLock;
$locker->unlock;
use Mail::Box;
my $folder = Mail::Box->new(lock_method => 'DOTLOCK');
print $folder->locker->type;

DESCRIPTION

Cada objeto Mail::Box crea su propio objeto "Mail::Box::Locker" que gestionará el control de archivos de correo. Puedes acceder directamente al objeto desde el objeto de carpeta, como se muestra en los ejemplos a continuación.

Extiende "DESCRIPTION" en Mail::Reporter.

METHODS

Extiende "METHODS" en Mail::Reporter.

Constructores

Extiende "Constructores" en Mail::Reporter.

$class->new(%options)
Crea un nuevo control de archivos. Puedes hacerlo directamente. Sin embargo, en la mayoría de los casos, el control no será instanciado por separado, sino que será el segundo objeto en una construcción multihilos con un objeto Mail::Box.

Generalmente, el programa cliente especifica el comportamiento de bloqueo a través de las opciones proporcionadas al objeto de carpeta. Mejora la base, ver "Constructores" en Mail::Reporter.

-Option --Defined in     --Default
 expires                   1 hora
 file                      undef
 folder                    <C<undef>>
 log      Mail::Reporter   'WARNINGS'
 method                    'DOTLOCK'
 timeout                   10
 trace    Mail::Reporter   'WARNINGS'
expires => $seconds
¿Cómo largo puede durar un control de archivos? Si un programa diferente deja un control vencido, este se eliminará automáticamente después del número de segundos especificado.
file => $file
Nombre del archivo $file a bloquear. Por defecto, el nombre de la carpeta se usa.
folder => $folder
¿Cuál es la carpeta a bloquear, un objeto Mail::Box.
log => LEVEL
method => $name|CLASS|\@names
¿Cuál es el tipo de bloqueo, especificado como uno de los siguientes tokens como $name. También puedes especificar un nombre de clase o múltiples @names. En el caso de múltiples @names, se iniciará un controlador 'multi' con todos los @names especificados.

Los nombres de métodos de bloqueo soportados son (en minúsculas también aceptados).

'DOTLOCK'
El manejador de carpeta crea un archivo que señala que está en uso. Esto puede ser problemático, ya que no todos los programas de correo coinciden en el nombre del archivo a crear.

En diferentes tipos de carpeta, el archivo de bloqueo difiere. Ver la documentación de cada carpeta, que describe la estrategia de bloqueo y opciones especiales para cambiar el comportamiento predeterminado.

'FLOCK'
Para algunos manejadores de carpeta, el bloqueo se basa en un mecanismo de bloqueo de archivo proporcionado por el sistema operativo. No funciona en todos los sistemas, como los sistemas de archivos en red, y también no funciona en carpetas basadas en directorios (Mail::Box::Dir y derivadas).
'FCNTLLOCK'
Bloqueo POSIX mediante File::FcntlLock, que funciona en más plataformas. Sin embargo, este módulo requiere un compilador C para instalarse.
'POSIX'
Usar el bloqueo POSIX estándar fcntl.
'MULTI'
Usar todos los métodos de bloqueo disponibles al mismo tiempo, para aumentar la probabilidad de que la carpeta no se modifique por otros programas que usen un método de bloqueo no especificado. Cuando uno de los métodos de bloqueo impide el acceso, el bloqueo falla.
'MUTT'
Usar el programa externo 'mutt_dotlock' para bloquear y desbloquear.
'NFS'
Un tipo de mecanismo de bloqueo 'dotlock' adaptado para funcionar en NFS. Se requiere una precaución adicional, ya que un 'open O_EXCL' en NFS no es una acción atómica.
'NONE'
Usar bloqueo de forma nula.

Otra opción es crear tu propio clase derivada de "Mail::Box::Locker", que implemente el método de bloqueo deseado. (Considera ofrecerla como parte del módulo público Mail::Box!) Crea una instancia de esa clase con este parámetro:

my $locker = Mail::Box::Locker::MyOwn->new;
$folder->open(locker => $locker);
timeout => $seconds|'NOTIMEOUT'
¿Por cuánto tiempo espera por obtener el bloqueo. El solicitud de bloqueo fallará cuando el número de segundos especificado se alcance. Si se especifica 'NOTIMEOUT', el módulo esperará hasta que el bloqueo pueda ser tomado.

¿Es posible limitar el tiempo de espera dependiendo de la plataforma y del método de bloqueo? Por ejemplo, el método 'dotlock' en Windows siempre espera hasta que el bloqueo haya sido recibido.

trace => LEVEL

Atributos

Extiende "Atributos" en Mail::Reporter.

$obj->expires( [SECONDS] )
Obtener/Asignar el tiempo de vencimiento. No disponible en todos los bloqueadores.
$obj->filename( [$filename] )
Devuelve el nombre del archivo que se usa para bloquear la carpeta, opcionalmente después de establecerlo a $filename.

» ejemplo:

print $locker->filename;
$obj->folder( [$folder] )
Devuelve el objeto de carpeta que es el bloqueador.
$obj->logSettings()
Inherido, ver "Atributos" en Mail::Reporter
$obj->name()
Devuelve el método utilizado para bloquear la carpeta. Ver la nueva (method) para detalles sobre cómo especificar el método de bloqueo. El nombre del método se devuelve en mayúsculas.

» ejemplo:

if($locker->name eq 'FLOCK') ...
$obj->timeout( [SECONDS] )
Obtener/Asignar el tiempo de espera. No disponible en todos los bloqueadores.

Bloqueo

$obj->hasLock()
Verifica si la carpeta tiene el bloqueo.
$obj->isLocked()
Prueba si la carpeta está bloqueada por este o otro programa.
$obj->lock($folder)
Obtiene un bloqueo en una carpeta. Este devolverá "false" si el bloqueo falla.
$obj->unlock()
Desbloquea una carpeta.
