Mail::Message::Head(3) Documentación de Perl aportada por el usuario Mail::Message::Head(3)

NOMBRE

Mail::Message::Head - la cabecera de un mensaje

HERENCIA

Mail::Message::Head
  es un Mail::Reporter
Mail::Message::Head es extendido por
  Mail::Box::IMAP4::Head
  Mail::Message::Head::Complete
  Mail::Message::Head::Delayed
  Mail::Message::Head::Subset

SINOPSIS

my $head = Mail::Message::Head->new;
$head->add('From: me@localhost');
$head->add(From => 'me@localhost');
$head->add(Mail::Message::Field->new(From => 'me'));
my $subject = $head->get('subject');
my @rec = $head->get('received');
$head->delete('From');

DESCRIPCIÓN

"Mail::Message::Head" Las cabeceras MIME son parte de los mensajes Mail::Message, que se agrupan en carpetas Mail::Box.

Una larga lista de campos de cabecera MIME estándar con definiciones se puede encontrar en RFC4021 (https://www.rfc-editor.org/rfc/rfc4021.html) y sus actualizaciones RFC5322 y RFC6854.

¡¡¡ATENCIÓN!!! La mayor parte de la funcionalidad relacionada con las cabeceras de correo electrónico se describe en Mail::Message::Head::Complete, que es un objeto de cabecera maduro. Otros tipos de cabeceras se traducirán a ese tipo cuando sea el momento.

En esta página, se describen los métodos generales que están disponibles en cualquier cabecera. Lea sobre las diferencias en las páginas específicas de las subclases.

Extiende "DESCRIPTION" en Mail::Reporter.

SOBRECARGADO

sobrecarga: "" conversión a cadena
La cabecera, cuando se usa como cadena, se formateará como si se hubiera llamado a Mail::Message::Head::Complete::string(), devolviendo así una cabecera completa y bien ordenada. Se hace una excepción para Carp, a la que se le dará una cadena simplificada para evitar mensajes ilegibles de "croak" y "confess".

» ejemplo: usar un objeto de cabecera como cadena

print $head;     # conversión implícita a cadena por print
$head->print;    # lo mismo
print "$head";   # conversión explícita a cadena
sobrecarga: bool verdadero/falso
Cuando la cabecera no contiene ninguna línea (lo cual es ilegal, según las RFC), se devuelve "falso". En todos los demás casos, se produce un valor "verdadero".

MÉTODOS

Constructores

Extiende "Constructors" en Mail::Reporter.

$class->build( [PAR|campo]-LISTA )
Una forma rápida de construir una cabecera con muchas líneas. Los PARES son pares de "(nombre, contenido)" de la cabecera, pero también es posible pasar objetos Mail::Message::Field. Se crea una cabecera Mail::Message::Head::Complete simplemente llamando a Mail::Message::Head::Complete::build(), y luego se añade cada campo. Se permiten nombres de campo duplicados.

» ejemplo:

my $subject = Mail::Message::Field->new(Subject => 'xyz');
my $head = Mail::Message::Head->build(
  From     => 'me@example.com',
  To       => 'you@anywhere.aq',
  $subject,
  Received => 'one',
  Received => 'two',
);
print ref $head;
 # -->  Mail::Message::Head::Complete
$class->new(%options)
Crea un nuevo objeto de cabecera de mensaje. El objeto almacenará todos los campos de una cabecera. Cuando obtenga información de la cabecera, se le devolverá como objetos Mail::Message::Field, aunque los campos puedan almacenarse de forma diferente internamente.

Si intenta instanciar un Mail::Message::Head, se actualizará automáticamente a un Mail::Message::Head::Complete, una cabecera completa. Mejora la base, véase "Constructors" en Mail::Reporter

La cabecera

$obj->isDelayed()
Las cabeceras pueden ser leídas solo parcialmente, en cuyo caso se llaman retardadas. Este método devuelve "verdadero" si todavía queda información de la cabecera por leer. Devuelve "falso" si se han leído todos los datos de la cabecera. Nunca activará la finalización.
$obj->isEmpty()
¿Hay algún campo definido en la cabecera actual? Tenga en cuenta que la cabecera no se cargará para esto: las cabeceras retardadas devolverán "verdadero" en cualquier caso.
$obj->isModified()
Devuelve si la cabecera ha sido modificada después de ser leída.

» ejemplo:

if($head->isModified) { ... }
$obj->knownNames()
Similar a Mail::Message::Head::Complete::names(), pero solo devuelve los campos de cabecera conocidos, que pueden ser menos que "names" para tipos de cabecera que son parciales. names() activará la finalización, mientras que knownNames() no lo hará.
$obj->message( [$message] )
Obtiene (después de establecerlo) el mensaje al que pertenece esta cabecera. Esto no activa la finalización.
$obj->modified( [BOOLEAN] )
Establece el indicador de modificado a "BOOLEAN". Sin valor, se devuelve la configuración actual, pero en ese caso es mejor usar isModified(). Cambiar este indicador no activará la finalización de la cabecera.

» ejemplo:

$head->modified(1);
if($head->modified) { ... }
if($head->isModified) { ... }
$obj->orderedFields()
Devuelve los campos ordenados de la manera en que fueron leídos o añadidos.

Acceso a la cabecera

$obj->get( $name, [$index] )
Obtiene los datos que están relacionados con el campo con el $name. La capitalización de los caracteres en $name no importa.

Si solo hay un elemento de datos definido para el $name, o si hay un $index especificado como segundo argumento, solo se devolverá el elemento especificado. Si el campo $name coincide con más de una cabecera, el valor de retorno depende del contexto. En contexto de LISTA, todos los valores se devolverán en el orden en que se leen. En contexto de ESCALAR, solo se devolverá el último valor.

» ejemplo:

my $head = Mail::Message::Head->new;
$head->add('Received: abc');
$head->add('Received: xyz');
$head->add('Subject: greetings');
my @rec_list   = $head->get('Received');
my $rec_scalar = $head->get('Received');
print ",@rec_list,$rec_scalar,"     # ,abc xyz, xyz,
print $head->get('Received', 0);
 # --> abc
print $head->get('Subject');
 # --> greetings
