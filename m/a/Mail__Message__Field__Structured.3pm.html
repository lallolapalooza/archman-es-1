NOMBRE

Mail::Message::Field::Structured - una línea de una cabecera de mensaje estructurada

HERENCIA

Mail::Message::Field::Structured
  es un Mail::Message::Field::Full
  es un Mail::Message::Field
  es un Mail::Reporter
Mail::Message::Field::Structured es extendido por
  Mail::Message::Field::Addresses
  Mail::Message::Field::AuthResults
  Mail::Message::Field::DKIM
  Mail::Message::Field::Date
  Mail::Message::Field::URIs

SINOPSIS

my $f = Mail::Message::Field::Full
           ->new('Content-Type' => 'text/html');
my @encode = (charset => 'jp', use_continuations => 1);
$f->attribute('filename=passwd');
$f->attribute(filename => 'passwd', @encode);
my $attr = Mail::Message::Field::Attribute->new(...);
$f->attribute($attr);

  • new($line)

    Pasa una $line tal como se podría encontrar en un archivo: una línea (posiblemente plegada) que termina con un salto de línea.

  • new($name, $body, @attributes, %options)

    Un conjunto de valores que dan forma a la línea.

El $name es un nombre de cabecera bien formado (puedes usar wellformedName()) para estar seguro de la capitalización. El $body es una cadena, un objeto de cuerpo o una LISTA de objetos de cuerpo. En caso de objetos, deben ajustarse al constructor del campo: los tipos que se aceptan pueden variar. La LISTA @attributes contiene objetos Mail::Message::Field::Attribute. Finalmente, hay algunas %options. Mejora la base, ver "MÉTODOS" en Mail::Message::Field::Full

-Opción    --Definido en                --Por defecto
 attributes                              +[ ]
 charset     Mail::Message::Field::Full  undef
 datum                                   undef
 encoding    Mail::Message::Field::Full  'q'
 force       Mail::Message::Field::Full  false
 language    Mail::Message::Field::Full  undef
 log         Mail::Reporter              'WARNINGS'
 trace       Mail::Reporter              'WARNINGS'
attributes => \@attributes|\%attributes
Hay varias formas de especificar estos atributos: pasar una LISTA que contenga pares clave-valor que representen @attributes, o un HASH que contenga estos pares, o una LISTA con objetos Mail::Message::Field::Attribute.
charset => $charset
datum => $date
El nombre del método *body* es muy confuso, incluso en el RFC. En MailBox, por razones históricas, body() devuelve la parte del contenido del campo anterior al primer punto y coma. foldedBody() y unfoldedBody() se refieren a todo el campo.

No hay un nombre común para la pieza de datos anterior a los parámetros (atributos) en el contenido del campo mencionado en los RFC, así que llamémosle "datum".

encoding => 'q'|'Q'|'b'|'B'
force => BOOLEAN
language => $language
log => LEVEL
trace => LEVEL

» ejemplo: de un campo estructurado

my @attrs   = (Mail::Message::Field::Attribute->new(...), ...);
my %options = (extra => 'el color azul');
my $t = Mail::Message::Field::Full->new(To => \@addrs, @attrs, %options);

Devuelve una lista con pares de nombre y valor de atributos.
$obj->attribute( $object|<STRING, %options>|<$name,$value,%options> )
Añade un atributo al campo. Los atributos se añaden de izquierda a derecha en la representación en cadena del campo, aunque el orden de los atributos no es importante, según las RFCs.

Puede pasar un objeto Mail::Message::Field::Attribute completamente preparado $object, si desea realizar todas las preparaciones para una representación correcta de los datos usted mismo. También puede pasar una "STRING", que es un atributo completamente preparado. Esta "STRING" no será modificada, así que tenga cuidado con las comillas y las codificaciones.

Como tercera posibilidad, puede especificar un atributo $name y su $value. Se creará un objeto de atributo para usted implícitamente en ambos casos donde dicho objeto no se proporcione, pasando las %options. Ver Mail::Message::Field::Attribute::new() sobre las %options disponibles.

Se devuelve el objeto atributo, sin embargo, cuando se utilizan continuaciones, puede ser un objeto que ya conoce. Se devuelve "undef" cuando la construcción falla (cuando el atributo es incorrecto). Mejora la base, ver "Acceso al contenido" en Mail::Message::Field

DIAGNÓSTICOS

Advertencia: El contenido del campo no es numérico: $content
Se solicita el valor numérico de un campo (por ejemplo, los campos "Lines" o "Content-Length" deberían ser numéricos), sin embargo, los datos contienen caracteres extraños. Se convierte con toInt()
Error: Nombre de campo demasiado largo (máximo $length), en '$name'
No se especifica en las RFCs cuán largo puede ser un nombre de campo, pero al menos debería ser unos pocos caracteres más corto que el ajuste de línea. Se convierte con fold()
Advertencia: Carácter ilegal en charset '$charset'
El campo se crea con una cadena utf8 que solo contiene datos del conjunto de caracteres especificado. Sin embargo, ese conjunto de caracteres nunca puede ser un nombre válido porque contiene caracteres que no están permitidos. Se convierte con encode()
Advertencia: Carácter ilegal en el nombre del campo $name
Se está creando un nuevo campo que contiene caracteres no permitidos por las RFCs. El uso de este campo en mensajes puede romper otros clientes de correo o agentes de transferencia, y por lo tanto mutilar o extinguir su mensaje. Se convierte con consume()
Advertencia: Carácter ilegal en el idioma '$lang'
El campo se crea con datos que se especifican como pertenecientes a un idioma determinado, sin embargo, el nombre del idioma no puede ser válido: contiene caracteres que no están permitidos por las RFCs. Se convierte con encode()
Advertencia: Codificación ilegal '$encoding', se usó 'q'
Las RFCs solo permiten la codificación base64 ( "b " o "B ") o quoted-printable ( "q" o "Q"). Otras opciones que estas cuatro son ilegales. Se convierte con encode()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método sin embargo la clase en cuestión no lo hace. Probablemente debería investigar esto y probablemente informar al autor del paquete. Se convierte con notImplemented()
