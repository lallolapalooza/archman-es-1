Mail::Message::Head::FieldGroup(3) Documentación de usuario para Perl contribuyente Mail::Message::Head::FieldGroup(3)

NAME

Mail::Message::Head::FieldGroup - un subconjunto de campos en un encabezado

INHERITANCE

Mail::Message::Head::FieldGroup
  es una Mail::Reporter
Mail::Message::Head::FieldGroup es extendido por
  Mail::Message::Head::ListGroup
  Mail::Message::Head::ResentGroup
  Mail::Message::Head::SpamGroup

SYNOPSIS

No se instancia directamente.

DESCRIPTION

Algunos campos tienen un significado combinado: un conjunto de campos que representan un paso intermedio durante el transporte del mensaje (un resent group, implementado en Mail::Message::Head::ResentGroup), campos añadidos por software de listas (implementado en Mail::Message::Head::ListGroup), o campos añadidos por software de detección de spam (implementado por Mail::Message::Head::SpamGroup). Cada conjunto de campos puede ser extraído o añadido como grupo con objetos basados en la implementación en esta clase.

Extiende "DESCRIPTION" en Mail::Reporter.

Extiende "METHODS" en Mail::Reporter.

$obj->clone()
Haz una copia de este objeto. Las nombres de los campos recogidos se copian y la información de tipo de lista se mantiene. No se hace una copia profunda para el encabezado: solo se copia como referencia.
$obj->from($head|$message)
Crea un grupo de campos basado en el mensaje especificado $message o el encabezado $head. Este puede devolver uno o más de los objetos, que dependen del tipo de grupo. Los campos de lista son todos almacenados en un solo objeto, donde grupos de resent y spam pueden aparecer más de una vez.

The header

$obj->add( <$field, $value> | $object )
Añade un campo a la cabecera, usando el grupo de campos. Cuando el grupo de campos ya está asociado a un encabezado real, aparecerá en ese mismo como bien como registrado en este conjunto. Si no se define un encabezado, el campo solo aparece internamente.

» ejemplo: añadiendo un campo a un grupo de lista desatado

my $this = Mail::Message::Head::ListGroup->new(...);
$this->add('List-Id' => 'mailbox');
$msg->addListGroup($this);
$msg->send;

» ejemplo: añadiendo un campo a un grupo de lista atado

my $lg = Mail::Message::Head::ListGroup->from($msg);
$lg->add('List-Id' => 'mailbox');

Acceso al encabezado

$obj->software()
Devuelve el nombre del software como se define en los encabezados. Puede ser ligeramente diferente del resultado de type(), pero usualmente no muy diferente.
$obj->type()
Devuelve un nombre abstracto para el grupo de campos; el software que lo controla. "undef" se devuelve en caso de que el tipo no esté definido. Los nombres válidos son dependientes del tipo de grupo: véase las páginas man correspondientes. Una lista completa de todos los tipos puede obtenerse con implementedTypes().
$obj->version()
Devuelve el número de versión del software que produjo los campos. Algunos tipos de software dejan tal rastro, otros casos devolverán "undef".

Internos

$obj->collectFields( [$name] )
Escanea el encabezado para campos que suelen estar en un grupo de campos con el nombre especificado $name. Para grupos de lista, no puedes especificar $name: solo se encontrará una única colección de encabezados (todos los encabezados se consideran producidos por exactamente una paqueteria de software de lista).

Este método se llama automáticamente cuando se construye un grupo de campos mediante from() en un encabezado o mensaje existente.

Devueltos son los nombres de los campos de encabezado de lista encontrados, en contexto de escalar el número de campos. Una lista vacía/0 indica que no se encontró ningún grupo.

Asegúrate de notificar al autor de MailBox si ves que se incluyen demasiados o demasiados campos.

$obj->detected($type, $software, $version)
Establece los valores para el tipo de grupo, software y versión, posiblemente a "undef".

Mail::Message::Head::FieldGroup(3pm)

NAME

Mail::Message::Head::FieldGroup - represent a group of header fields

INHERITANCE

This class is part of Mail-Message version 3.019.

Inherits methods from Mail::Reporter.

Extends Mail::Message::Head::Object.

SYNOPSIS

    use Mail::Message::Head::FieldGroup;

    my $group = Mail::Message::Head::FieldGroup->new;
    $group->put( $field1, $field2 );

    # print the content of the group
    print $group->print;

    # get all fields from the group
    my @fields = $group->fields;

DESCRIPTION

A FieldGroup is a collection of Mail::Message::Head::Field objects. It is used to represent MIME-related header fields that are grouped.

The object is created by the parser when it encounters a group of related fields. For example, the fields From:, Sender: and Reply-To: are often represented as a group.
