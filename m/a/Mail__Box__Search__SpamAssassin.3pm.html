NAME

Mail::Box::Search::SpamAssassin - seleccionar mensajes de spam con Mail::SpamAssassin

INHERITANCE

Mail::Box::Search::SpamAssassin
  es un Mail::Box::Search
  es un Mail::Reporter

SYNOPSIS

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open('Inbox');
my $spam = Mail::Box::Search::SpamAssassin->new;
if($spam->search($message)) {...}
my @msgs   = $filter->search($folder);
foreach my $msg ($folder->messages)
{   $msg->delete if $msg->label('spam');
}
my $spam2 = Mail::Box::Search::SpamAssassin->new(deliver => 'DELETE');
$spam2->search($folder);
$mgr->moveMessages($spamfolder, $folder->messages('spam'));

DESCRIPTION

El spam significa "correo no solicitado", y se deriva del nombre del escrito de Monty Python. Aunque Monty Python es divertido, el spam es un dolor de cabeza: desgasta minutos de tiempo de la vida de la mayoría de los usuarios: facturas telefónicas, cajeros de correo que bloquean correos honestos y la eliminación accidental de correos honestos que parecen spam. El spam es el invasor de Internet.

Felizmente, Mail::Box puede usarse como un filtro de spam, en combinación con el útil module Mail::SpamAssassin (que debe instalarse por separado). Cada mensaje que se busca está envuelto en un objeto Mail::Message::Wrapper::SpamAssassin.

El módulo spam-assassin versión 2 no está realmente bien adaptado para objetos Mail::Message, lo cual hará que este tipo de búsqueda sea aún más lento que el spam-detección ya es.

NOMBRE

Mail::Box::Search::SpamAssassin - extension para Mail::Box::Search para detectar spam

HEREDAD

Mail::Box::Search::SpamAssassin se extiende directamente desde Mail::Box::Search.

SYNOPSIS

Este módulo es una extensión para la funcionalidad de búsqueda de Mail::Box. Normalmente no se usa directamente.

  use Mail::Box::Search::SpamAssassin;

  # No hay ejemplos de uso directo ya que es una extensión.

DESCRIPCIÓN

Este módulo proporciona la funcionalidad para integrar la detección de spam de SpamAssassin con el framework Mail::Box. Permite buscar correos electrónicos basándose en la probabilidad de ser spam, o marcas específicas de SpamAssassin.

Herda todos los métodos de Mail::Box::Search y añade funcionalidad específica para SpamAssassin.
