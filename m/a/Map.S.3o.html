Mapas

type key

El tipo de las claves del mapa.

type !+'a t

El tipo de mapas de tipo key a tipo 'a .

val empty : 'a t

El mapa vacío.

val add : key -> 'a -> 'a t -> 'a t

add key data m devuelve un mapa que contiene las mismas asociaciones que m , más una asociación de key a data . Si key ya estaba asociada en m a un valor que es físicamente igual a data , m se devuelve sin cambios (el resultado de la función es entonces físicamente igual a m ). De lo contrario, la asociación anterior de key en m desaparece.

Before4.03 La igualdad física no estaba garantizada.

val add_to_list : key -> 'a -> 'a list t -> 'a list t

add_to_list key data m es m con key mapeada a l tal que l es data :: Map.find key m si key estaba asociado en m y [data] en caso contrario.

Desde 5.1

val update : key -> ('a option -> 'a option) -> 'a t -> 'a t

update key f m devuelve un mapa que contiene las mismas asociaciones que m , excepto la asociación de key . Dependiendo del valor de y donde y es f (find_opt key m) , la asociación de key se añade, elimina o actualiza. Si y es None , la asociación se elimina si existe; de lo contrario, si y es Some z entonces key se asocia a z en el mapa resultante. Si key ya estaba asociada en m a un valor que es físicamente igual a z , m se devuelve sin cambios (el resultado de la función es entonces físicamente igual a m ).

Desde 4.06

val singleton : key -> 'a -> 'a t

singleton x y devuelve el mapa de un solo elemento que contiene una asociación y para x .

Desde 3.12

val remove : key -> 'a t -> 'a t

remove x m devuelve un mapa que contiene las mismas asociaciones que m , excepto x que no está asociado en el mapa resultante. Si x no estaba en m , m se devuelve sin cambios (el resultado de la función es entonces físicamente igual a m ).

Before4.03 La igualdad física no estaba garantizada.

val merge : (key -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

merge f m1 m2 calcula un mapa cuyas claves son un subconjunto de las claves de m1 y m2 . La presencia de cada asociación, y el valor correspondiente, se determina con la función f . En términos de la operación find_opt , tenemos find_opt x (merge f m1 m2) = f x (find_opt x m1) (find_opt x m2) para cualquier clave x , siempre que f x None None = None .

Desde 3.12

val union : (key -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union f m1 m2 calcula un mapa cuyas claves son un subconjunto de las claves de m1 y m2 . Cuando la misma asociación está definida en ambos argumentos, la función f se utiliza para combinarlas. Este es un caso especial de merge : union f m1 m2 es equivalente a merge f' m1 m2 , donde

- f' _key None None = None

- f' _key (Some v) None = Some v

- f' _key None (Some v) = Some v

- f' key (Some v1) (Some v2) = f key v1 v2

Desde 3.12

Asociaciones

val bindings : 'a t -> (key * 'a) list

Devuelve la lista de todas las asociaciones del mapa dado. La lista resultante está ordenada en orden creciente de claves con respecto al orden Ord.compare , donde Ord es el argumento dado a Map.Make .

Desde 3.12

val min_binding : 'a t -> key * 'a

Devuelve la asociación con la clave más pequeña en un mapa dado (con respecto al orden Ord.compare ), o lanza Not_found si el mapa está vacío.

Desde 3.12

val min_binding_opt : 'a t -> (key * 'a) option

Devuelve la asociación con la clave más pequeña en el mapa dado (con respecto al orden Ord.compare ), o None si el mapa está vacío.

Desde 4.05

val max_binding : 'a t -> key * 'a

Igual que Map.S.min_binding , pero devuelve la asociación con la clave más grande en el mapa dado.

Desde 3.12

val max_binding_opt : 'a t -> (key * 'a) option

Igual que Map.S.min_binding_opt , pero devuelve la asociación con la clave más grande en el mapa dado.

Desde 4.05

val choose : 'a t -> key * 'a

Devuelve una asociación del mapa dado, o lanza Not_found si el mapa está vacío. Qué asociación se elige no está especificado, pero se elegirán asociaciones iguales para mapas iguales.

Desde 3.12

val choose_opt : 'a t -> (key * 'a) option

Devuelve una asociación del mapa dado, o None si el mapa está vacío. Qué asociación se elige no está especificado, pero se elegirán asociaciones iguales para mapas iguales.

Desde 4.05

Búsqueda

val find : key -> 'a t -> 'a

find x m devuelve el valor actual de x en m , o lanza Not_found si no existe ninguna asociación para x .

val find_opt : key -> 'a t -> 'a option

find_opt x m devuelve Some v si el valor actual de x en m es v , o None si no existe ninguna asociación para x .

Desde 4.05

val find_first : (key -> bool) -> 'a t -> key * 'a

find_first f m , donde f es una función monótonamente creciente, devuelve la asociación de m con la clave más baja k tal que f k , o lanza Not_found si no existe tal clave.

Por ejemplo, find_first (fun k -> Ord.compare k x >= 0) m devolverá la primera asociación k, v de m donde Ord.compare k x >= 0 (intuitivamente: k >= x ), o lanzará Not_found si x es mayor que cualquier elemento de m .

Desde 4.05

val find_first_opt : (key -> bool) -> 'a t -> (key * 'a) option

find_first_opt f m , donde f es una función monótonamente creciente, devuelve una opción que contiene la asociación de m con la clave más baja k tal que f k , o None si no existe tal clave.

Desde 4.05

val find_last : (key -> bool) -> 'a t -> key * 'a

find_last f m , donde f es una función monótonamente decreciente, devuelve la asociación de m con la clave más alta k tal que f k , o lanza Not_found si no existe tal clave.

Desde 4.05

val find_last_opt : (key -> bool) -> 'a t -> (key * 'a) option

find_last_opt f m , donde f es una función monótonamente decreciente, devuelve una opción que contiene la asociación de m con la clave más alta k tal que f k , o None si no existe tal clave.
