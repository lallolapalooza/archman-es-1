NOMBRE

Mail::Address - analiza direcciones de correo

SINOPSIS

use Mail::Address;
my @addrs = Mail::Address->parse($line);
foreach $addr (@addrs) {
    print $addr->format,"\n";
}

DESCRIPCIÓN

"Mail::Address" extrae y manipula direcciones de correo electrónico de un encabezado de mensaje. No se puede usar para extraer direcciones de texto aleatorio. Puedes usar este módulo para crear campos compatibles con RFC822.

Aunque "Mail::Address" es un tema muy popular para libros y se usa en muchas aplicaciones, hace un trabajo muy pobre en los campos de mensaje más complejos. Solo maneja formatos de dirección simples (que cubren alrededor del 95% de lo que se puede encontrar). Los problemas son con

  • no hay soporte para grupos de direcciones, ni siquiera con el punto y coma como separador entre direcciones;
  • soporte limitado para escapes en frases y comentarios. Hay casos en los que puede equivocarse; y
  • tienes que encargarte de la mayoría de los escapes cuando creas una dirección tú mismo: "Mail::Address" no hace eso por ti.

A menudo se hacen solicitudes a los mantenedores de este código para mejorar esta situación, pero no es una buena idea, ya que rompería millones de aplicaciones existentes. Si deseas una implementación totalmente compatible con RFC2822, puedes echar un vistazo a Mail::Message::Field::Full, parte de MailBox.

. Ejemplo

my $s = Mail::Message::Field::Full->new($from_header);
# ref $s isa Mail::Message::Field::Addresses;
my @g = $s->groups;          # todos los grupos, al menos uno
# ref $g[0] isa Mail::Message::Field::AddrGroup;
my $ga = $g[0]->addresses;   # direcciones del grupo
my @a = $s->addresses;       # todas las direcciones
# ref $a[0] isa Mail::Message::Field::Address;

MÉTODOS

Constructores

Mail::Address->new( $phrase, $address, [ $comment ] )
Crea un nuevo objeto "Mail::Address" que representa una dirección con los elementos dados. En un mensaje, estos 3 elementos se verían así: 
FRASA <DIRECCIÓN> (COMENTARIO)
DIRECCIÓN (COMENTARIO)

ejemplo:

Mail::Address->new("Perl5 Porters", "perl5-porters@africa.nicoh.com");
$obj->parse($line)
Analiza la línea dada y devuelve una lista de objetos "Mail::Address" extraídos. La línea normalmente sería una tomada de una línea To, Cc o Bcc en un mensaje

ejemplo:

my @addr = Mail::Address->parse($line);

Accesorios

$obj->address()
Devuelve la parte de la dirección del objeto.
$obj->comment()
Devuelve la parte del comentario del objeto
$obj->format(@addresses)
Devuelve una cadena que representa la dirección en una forma adecuada para ser colocada en una línea "To", "Cc", o "Bcc" de un mensaje. Este método se llama en la primera dirección a usar; otras direcciones especificadas se añadirán, separadas por comas.
$obj->phrase()
Devuelve la parte de la frase del objeto.

Accesorios inteligentes

$obj->host()
Devuelve la dirección excluyendo el id de usuario y '@'
$obj->name()
Usando la información contenida en el objeto, intenta identificar cuál es el nombre de la persona o grupo.

Nota: Esta función intenta ser inteligente con la "frase" de la dirección de correo, lo cual es probablemente una muy mala idea. Considera usar phrase() directamente.

$obj->user()
Devuelve la dirección excluyendo el '@' y el dominio del correo
