Mail::Message::Convert::Html - Formatear mensajes en HTML

HERENCIA

Mail::Message::Convert::Html
                              es un Mail::Message::Convert
                              es un Mail::Reporter

SINOPSIS

use Mail::Message::Convert::Html;
    my $Html = Mail::Message::Convert::Html->new;
    print $html->fieldToHtml($head);
    print $html->headToHtmlHead($head);
    print $html->headToHtmlTable($head);
    print $html->textToHtml($text);

DESCRIPCIÓN

El paquete contiene varios traductores que manejan HTML o XHTML sin ayuda de módulos externos. Hay más módulos relacionados con HTML que requieren paquetes adicionales para ser instalados.

Conversión

Extiende Converting en Mail::Message::Convert.

$obj->fieldContentsToHtml( $field, [$subject] )
Formatea un campo de encabezado a HTML. Cuando la línea de encabezado contiene usualmente direcciones de correo electrónico, la línea se escanea y se enlazan las direcciones válidas con un enlace "mailto:". El campo $subject puede especificarse para incluirlo en ese enlace.
$obj->fieldToHtml( $field, [$subject] )
Reformatea una línea de encabezado a HTML. El nombre del campo $field se imprime en negrita, seguido por el contenido formateado, que se produce mediante fieldContentsToHtml().
$obj->headToHtmlHead($head, $meta)
Traduce líneas de encabezado seleccionadas (campos) a un encabezado HTML. Cada campo seleccionado tendrá su propia línea meta con el mismo nombre que la línea. Además, el campo "Subject" se convertirá en "title", y el campo "From" se usará como autor del "Author".

Además, puedes especificar tus propios campos meta, que sobrescribirán los campos de encabezado. Los campos vacíos no se incluirán. Cuando se especifique un "title", esto se convertirá en el título HTML, de lo contrario se usará el campo "Subject". En contexto de lista, las líneas se procesan por separado; en contexto escalar, el texto completo se devuelve como uno.

Si necesitas agregar líneas al encabezado (por ejemplo, líneas http-equiv), entonces inserta las líneas antes del último elemento en la lista devuelta.

» ejemplo:

my @head = $html->headToHtmlHead(
                $head,
                description => 'This is a message',
                generator   => 'Mail::Box',
            );
            splice @head, -1, 0, '<meta http-equiv=...>';
            print @head;
$obj->headToHtmlTable( $head, [$table_params] )
Genera una tabla de visualización de los campos seleccionados del encabezado. Los parámetros opcionales $table_params se agregan como parámetros al elemento TABLE producido. En contexto de lista, cada línea se devuelve por separado; en contexto escalar, todo se devuelve como uno.
$obj->selectedFields($head)

$obj->textToHtml($lines)
Traduce una o más líneas de texto a HTML. Cada línea se procesa una por una, y solo se traducen cosas simples. "textToHtml" puede convertir textos grandes de forma descentralizada. En contexto escalar, los resultados se devuelven como uno.

Mail::Message::Convert::Html(3pm)

NAME Mail::Message::Convert::Html - convert message to HTML
SYNOPSIS 
  use Mail::Message::Convert::Html;

  my $html = convert( $message );
DESCRIPTION

This converter creates an HTML representation of a Mail::Message object. The conversion is simple and does not try to make the HTML look pretty. It simply represents the structure of the message.

This is a plugin for the Mail::Message::Convert class.
METHODS
convert( $message )

The method is called by Mail::Message::Convert. It takes the message object as argument and returns the HTML string.
DIAGNOSTICS

No special diagnostics are produced.
