NOMBRE

Mail::Box::Locker::FcntlLock - bloquear una carpeta usando File::FcntlLock

HERENCIA

Mail::Box::Locker::FcntlLock
  es un Mail::Box::Locker
  es un Mail::Reporter

SINOPSIS

Ver Mail::Box::Locker

DESCRIPCIÓN

Este objeto de bloqueo utiliza File::FcntlLock y fue contribuido por Jim in Aus. Está cerca de Mail::Box::Locker::POSIX, pero funciona en más sistemas, por ejemplo Darwin.

Necesitará instalar File::FcntlLock por separado: no hay dependencia de él por la distribución MailBox.

Extiende "DESCRIPCIÓN" en Mail::Box::Locker.

DIAGNÓSTICOS

Advertencia: Carpeta $carpeta ya bloqueada con lockf
Emitido por lock()
Error: El paquete $paquete no implementa $metodo.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, pero la clase en cuestión no. Probablemente deberías investigar esto y, probablemente, informar al autor del paquete. Emitido por notImplemented()
Error: No se puede verificar el archivo de bloqueo $archivo para $carpeta: $!
Para verificar si el nombre de archivo se utiliza para bloquear una carpeta, se debe abrir el archivo. Aparentemente, esto falla, lo que no significa que la carpeta esté bloqueada ni que esté desbloqueada. Emitido por isLocked()
Error: No se puede abrir el archivo de bloqueo FcntlLock $archivo para $carpeta: $!
Para el bloqueo estilo FcntlLock, una $carpeta debe ser abierta, lo que no tiene éxito por el motivo especificado. Emitido por lock()
Error: Nunca se obtendrá un bloqueo FcntlLock en $archivo para $carpeta: $!
Se intentó bloquear la $carpeta, pero no tuvo éxito. El código de error recibido del sistema operativo indica que nunca tendrá éxito, por lo que no necesitamos volver a intentarlo. Emitido por lock()
