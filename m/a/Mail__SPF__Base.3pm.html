DESCRIPCIÓN

Mail::SPF::Base es una clase base común para todas las clases de Mail::SPF.

Constructor

Se proporciona el siguiente constructor:

new(%options): devuelve Mail::SPF::Base
Crea un nuevo objeto de la clase en la que se invocó el constructor. Las opciones proporcionadas se almacenan como pares clave/valor en el nuevo objeto.

El constructor "new" también puede llamarse sobre un objeto, en cuyo caso el objeto se clona. Cualquier opción proporcionada anula las del objeto anterior.

No hay opciones comunes definidas en Mail::SPF::Base.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

class: devuelve string
Devuelve el nombre de la clase de la clase u objeto sobre el que se invoca.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

make_accessor($name, $readonly): devuelve código-ref
Crea un método de acceso en la clase en la que se invoca. El acceso tiene el nombre dado y accede al campo del objeto del mismo nombre. Si $readonly es true, el acceso se hace de solo lectura.

Métodos de instancia
