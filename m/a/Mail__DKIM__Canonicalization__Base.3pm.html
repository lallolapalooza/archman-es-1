NOMBRE

Mail::DKIM::Canonicalization::Base - clase base para métodos de canonicidad

VERSIÓN

versión 1.20240923

SINOPSIS

# los resultados de la canonicidad se envían a STDOUT
my $method = new Mail::DKIM::Canonicalization::relaxed(
                  output_fh => *STDOUT,
                  Signature => $dkim_signature);
# añadir cabeceras
$method->add_header("Subject: esta es la cabecera\015\012");
$method->finish_header(Headers => \@all_headers);
# añadir cuerpo
$method->add_body("Este es el cuerpo.\015\012");
$method->add_body("Otras dos líneas\015\012del cuerpo.\015\012");
$method->finish_body;
# esto añade la firma al final
$method->finish_message;

CONSTRUCTOR

Utilice el método new() de la clase de implementación de canonicidad deseada para construir un objeto de canonicidad. Por ejemplo:

my $method = new Mail::DKIM::Canonicalization::relaxed(
                  output_fh => *STDOUT,
                  Signature => $dkim_signature);

Los constructores aceptan estos argumentos:

Firma
(Requerido) Proporcione la firma DKIM que se está construyendo (si el mensaje se está firmando), o la firma DKIM que se está verificando (si el mensaje se está verificando). El método de canonicidad escribe parámetros en la firma, o lee parámetros de la firma (por ejemplo, la etiqueta h=).
salida
Si se especifica, el mensaje canonicado se pasará a este objeto con el método PRINT.
salida_digest
Si se especifica, el mensaje canonicado se añadirá a este digest. (Utiliza el método add().)
salida_fh
Si se especifica, el mensaje canonicado se escribirá en este manejador de archivos.

Si no se especifican ninguno de los parámetros de salida, el mensaje canonicado se añade a un buffer interno. El contenido de este buffer se puede acceder utilizando el método result().

MÉTODOS

add_body() - introduce parte del cuerpo en la canonicidad

$method->add_body("Este es el cuerpo.\015\012");
$method->add_body("Otras dos líneas\015\012del cuerpo.\015\012");

El cuerpo debe ser introducido una o más "líneas" a la vez. Es decir, no se debe introducir parte de una línea.

finish_header() - se llama cuando la cabecera ha sido completamente analizada

$method->finish_header(Headers => \@all_headers);

Anteriormente, el objeto de canonicidad solo recibía los datos de la cabecera a través de invocaciones sucesivas de add_header(). Sin embargo, eso requería que el objeto de canonicidad almacenara una copia de toda la cabecera para poder elegir el orden en que las cabeceras se introducían en el objeto digest. Esto es un uso ineficiente de memoria, ya que un mensaje con muchas firmas puede utilizar muchos objetos de canonicidad y cada objeto de canonicidad tiene su propia copia de la cabecera.

El array de cabeceras es un array de un elemento por campo de cabecera, con las cabeceras no procesadas/canonicadas de ninguna manera.

result()

my $result = $method->result;

Si no especificó un objeto o manejador al que enviar la salida, el resultado de la canonicidad se almacena en el propio método de canonicidad, y se puede acceder a él utilizando este método.
