Mail::Box::Tie::ARRAY(3) Documentación de Perl contribuida por el usuario Mail::Box::Tie::ARRAY(3)

NOMBRE

Mail::Box::Tie::ARRAY - acceder a una carpeta de mensajes existente como un array

HERENCIA

Mail::Box::Tie::ARRAY
  es un Mail::Box::Tie

SINOPSIS

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open(folder => 'inbox');
use Mail::Box::Tie::ARRAY;
tie my(@inbox), 'Mail::Box::Tie::ARRAY', $folder;
# obsoleto, pero también funciona
use Mail::Box::Tie;
tie my(@inbox), 'Mail::Box::Tie', $folder;
foreach (@inbox) {print $_->short}
print $_->print foreach @inbox;
my $emails = @inbox;
print $inbox[3];
print scalar @inbox;
push @inbox, Mail::Box::Message->new(...);
delete $inbox[6];
print $inbox[0]->head->get('status');
my $folder = tied @inbox;
untie @inbox;

DESCRIPCION

Ciertamente, cuando se mira una carpeta como una lista de mensajes, es lógico acceder a la carpeta a través de un array.

No todas las operaciones sobre arrays son compatibles. De hecho, la mayoría de las funciones que reducirían el tamaño del array se modifican en su lugar para marcar los mensajes para su eliminación.

Ejemplos de lo que *no* se puede hacer:

shift/unshift/pop/splice @inbox;

Extiende "DESCRIPCION" en Mail::Box::Tie.

Interfaz Vinculada

$obj->DELETE()
Marca un mensaje para ser eliminado. Tenga en cuenta que el mensaje permanece en la carpeta y no se elimina hasta que la carpeta se guarda.

» ejemplo:

delete $inbox[5];
$inbox[5]->delete;   # lo mismo
$obj->FETCH($indice)
Obtiene el mensaje que se encuentra en la ubicación indicada en la lista de mensajes contenidos en esta carpeta. Los mensajes eliminados se devolverán como "undef".

» ejemplo:

print $inbox[3];     # 4º mensaje en la carpeta
print @inbox[3,0];   # 4º y 1º de la carpeta
print $inbox[-1];    # último mensaje
$obj->FETCHSIZE()
Devuelve el número total de mensajes en una carpeta. Esto se llama cuando la carpeta-array se utiliza en contexto escalar, por ejemplo.

» ejemplo:

if(@inbox > 10)    # contiene más de 10 mensajes?
my $nromesgs = @inbox;
$obj->PUSH(@mensajes)
Añade @mensajes al final de la carpeta.

» ejemplo:

push @inbox, $newmsg;
$obj->STORE($indice, $mensaje)
El reemplazo aleatorio de mensajes no está permitido; hacerlo alteraría los hilos, etc. Se produce un error si se intenta hacer esto. Lo único que se permite es almacenar un mensaje en el primer índice libre al final de la carpeta (lo cual también se puede conseguir con PUSH()).

» ejemplo:

$inbox[8]  = $add;
$inbox[-1] = $add;
push @inbox, $add;
$obj->STORESIZE($longitud)
Marca para su eliminación todos los mensajes a partir de la posición $longitud hasta el final de la carpeta.

DETALLES

Carpeta vinculada como array

Limitaciones

Este módulo implementa "TIEARRAY", "FETCH", "STORE", "FETCHSIZE", "STORESIZE", "DELETE", "PUSH", y "DESTROY".

Este módulo no implementa todos los demás métodos descritos en la documentación de Tie::Array, ya que no se permite que el array real de mensajes se reduzca o se mutile.
