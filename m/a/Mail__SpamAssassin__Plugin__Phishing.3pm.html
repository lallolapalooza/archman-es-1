NOMBRE

Mail::SpamAssassin::Plugin::Phishing - comprueba las URIs contra un feed de phishing

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::Phishing
ifplugin Mail::SpamAssassin::Plugin::Phishing
  phishing_openphish_feed /etc/mail/spamassassin/openphish-feed.txt
  phishing_phishtank_feed /etc/mail/spamassassin/phishtank-feed.csv
  body     URI_PHISHING      eval:check_phishing()
  describe URI_PHISHING      Url coincide con phishing en el feed
endif

DESCRIPCIÓN

Este plugin encuentra URIs utilizadas en campañas de phishing detectadas por los feeds de OpenPhish, PhishTank o PhishStats.

El feed gratuito de Openphish se actualiza cada 6 horas y se puede descargar desde https://openphish.com/feed.txt.

El feed gratuito de PhishTank se actualiza cada hora y se puede descargar desde http://data.phishtank.com/data/online-valid.csv. Para evitar límites de descarga se requiere registro.

PREFERENCIAS DE ADMINISTRADOR

Las siguientes opciones se pueden utilizar en los archivos de configuración de todo el sitio ("local.cf") para personalizar cómo el módulo maneja las URIs de phishing.

phishing_openphish_feed
Ruta absoluta del feed de datos OpenPhish descargado.
phishing_phishtank_feed
Ruta absoluta del feed de datos PhishTank descargado.
phishing_uri_noparam ( 0 | 1 ) (predeterminado: 0)
Si esta opción está activada, los parámetros de la URI no se tendrán en cuenta al analizar el feed de datos de URIs de phishing. Si esta opción está habilitada y la URL sin parámetros es "genérica" (como https://www.kisa.link/url_redirector.php?url=...) la URL será omitida.
