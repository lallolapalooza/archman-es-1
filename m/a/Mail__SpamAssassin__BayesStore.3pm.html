Mail::SpamAssassin::BayesStore(3) Documentación de Perl contribuida por la comunidad Mail::SpamAssassin::BayesStore(3)

NOMBRE

Mail::SpamAssassin::BayesStore - Módulo de almacenamiento para el clasificador Bayes por defecto

DESCRIPCIÓN

Esta es la API pública para los métodos de almacenamiento de los clasificadores Bayes. Cualquier implementación del módulo de almacenamiento para el clasificador Bayes por defecto debe implementar estos métodos.

MÉTODOS

new
clase pública (Mail::SpamAssassin::BayesStore) new (Mail::SpamAssassin::Plugin::Bayes $bayes)

Descripción: Este método crea una nueva instancia del objeto Mail::SpamAssassin::BayesStore. Debes pasar un objeto de tipo Mail::SpamAssassin::Plugin::Bayes, que se almacena para su uso en todo el módulo.

DB_VERSION
instancia pública (Valor entero) DB_VERSION ()

Descripción: Este método devuelve la versión de la base de datos actualmente soportada por la implementación.

read_db_configs
instancia pública () read_db_configs ()

Descripción: Este método lee las variables de configuración necesarias del objeto de configuración y luego llama al método read_db_configs de Mail::SpamAssassin::Plugin::Bayes.

prefork_init
instancia pública (Valor booleano) prefork_init ()

Descripción: Este método se llama en el proceso padre poco antes de que se bifurquen los procesos hijos.

spamd_child_init
instancia pública (Valor booleano) spamd_child_init ()

Descripción: Este método se llama en un proceso hijo después de que se ha bifurcado.

tie_db_readonly
instancia pública (Valor booleano) tie_db_readonly ()

Descripción: Este método abre la base de datos en modo de solo lectura.

tie_db_writable
instancia pública (Valor booleano) tie_db_writable ()

Descripción: Este método abre la base de datos en modo de escritura.

Cualquier llamador de este método debe asegurarse de llamar a untie_db() después.

untie_db
instancia pública () untie_db ()

Descripción: Este método desvincula la base de datos.

Descripción: Este método realiza la expiración de tokens en la base de datos según los valores pasados $newest_atime y $newdelta especificados.

expire_old_tokens_trapped
instancia pública (Valor booleano) expire_old_tokens_trapped (\% $opts)

Descripción: Este método realiza la expiración de tokens.

sync_due
instancia pública (Valor booleano) sync_due ()

Descripción: Este método determina si es necesaria una sincronización.

expiry_due
instancia pública (Valor booleano) expiry_due ()

Descripción: Este método determina si es necesaria una expiración.

seen_get
instancia pública (Carácter) seen_get (String $msgid)

Descripción: Este método recupera el valor almacenado, si existe, para $msgid. El valor devuelto es la cadena almacenada ('s' para spam y 'h' para ham) o undef si $msgid no se encuentra.

seen_put
instancia pública (Valor booleano) seen_put (String $msgid, Carácter $flag)

Descripción: Este método registra $msgid como el tipo dado por $flag. $flag es uno de los dos valores 's' para spam y 'h' para ham.

seen_delete
instancia pública (Valor booleano) seen_delete (String $msgid)

Descripción: Este método elimina $msgid de la base de datos.

get_storage_variables
instancia pública (@) get_storage_variables ()

Descripción: Este método recupera las variables administrativas utilizadas por la implementación de almacenamiento Bayes.

Los valores devueltos en el array están en el siguiente orden:

0: base de recuento de escaneos

1: recuento de spam

2: recuento de ham

3: recuento de tokens en la base de datos

4: tiempo de expiración más reciente

5: tiempo más antiguo de token en la base de datos

6: valor de la versión de la base de datos

7: último diario sincronizado

8: último delta de tiempo de acceso

9: último contador de expiración

10: tiempo más reciente de token en la base de datos

dump_db_toks
instancia pública () dump_db_toks (String $template, String $regex, @ @vars)

Descripción: Este método recorre todos los tokens, calculando la probabilidad para cada token y luego imprime el resultado según la plantilla proporcionada.

set_last_expire
instancia pública (Valor booleano) _set_last_expire (Integer $time)

Descripción: Este método establece la hora de expiración más reciente.

get_running_expire_tok
instancia pública (Tiempo) get_running_expire_tok ()

Descripción: Este método determina si una expiración está en curso y devuelve el tiempo en que comenzó la expiración.

set_running_expire_tok
instancia pública (Tiempo) set_running_expire_tok ()

Descripción: Este método establece la hora de expiración en curso a la hora actual.

remove_running_expire_tok
instancia pública (Valor booleano) remove_running_expire_tok ()

Descripción: Este método elimina una hora de expiración en curso que se estableció previamente.

tok_get
instancia pública (Integer, Integer, Tiempo) tok_get (String $token)

Descripción: Este método recupera el token especificado ($token) de la base de datos y devuelve el recuento de spam, recuento de ham y tiempo de acceso reciente.

tok_get_all
instancia pública (@) tok_get_all (@ @tokens)

Descripción: Este método recupera los tokens especificados (@tokens) de la base de datos y devuelve una referencia de array de arrays con el recuento de spam, recuento de ham y tiempo de acceso reciente.

tok_count_change
instancia pública (@) tok_count_change (@ @tokens)

Descripción: Este método cambia el recuento de los tokens (@tokens) en la base de datos.

tok_count_change
instancia pública (Booleano) tok_count_change (Entero $spam_count,
Entero $ham_count,
Cadena $token,
Tiempo $atime)

Descripción: Este método toma un $spam_count y $ham_count y lo añade a $token, actualizando también la fecha de acceso (atime) de $token con $atime.

multi_tok_count_change
instancia pública (Booleano) multi_tok_count_change (Entero $spam_count,
Entero $ham_count, \% $tokens, Cadena $atime)

Descripción: Este método toma un $spam_count y $ham_count y lo añade a todos los tokens en el referencia hash de $tokens, actualizando también la fecha de acceso (atime) de cada token con $atime.

Descripción: Este método actualiza el número de correos spam y el número de correos ham en la base de datos.

tok_touch

Tiempo $atime)

tok_touch_all

Tiempo $atime)

Descripción: Este método realiza una actualización masiva de la lista de tokens proporcionada $tokens, si la fecha de acceso (atime) del token existente es menor que $atime.

perform_upgrade
instancia pública (Booleano) perform_upgrade (\% $opts)
