NOMBRE

Mat_VarGetStructsLinear — Indexa linealmente una variable de estructura

SINOPSIS

#include <matio.h>

matvar_t *
Mat_VarGetStructsLinear(const matvar_t *matvar, int start, int stride, int edge, int copy_fields);

DESCRIPCIÓN

La función Mat_VarGetStructsLinear() selecciona una submatriz de un arreglo de estructuras matvar. Cada uno de los elementos de la submatriz contiene todos los campos de la estructura. La indexación comienza en el start elemento del arreglo (0 siendo el primer elemento), y lee cada stride valores (1 siendo cada elemento, 2 cada dos elementos, etc.). El número total de elementos en la submatriz se especifica como edge. El arreglo original debe tener al menos start+(stride-1)*edge+1 elementos. La opción copy_fields especifica si los campos de la estructura original se copian para la nueva submatriz. Si se establece en 0, los campos del arreglo de submatriz devuelto tienen el mismo puntero que el arreglo original, y el campo data de la estructura de submatriz. La submatriz se marca con el indicador de conservación de memoria, lo que indica que los campos no deben liberarse. Se liberan cuando se libera la estructura original.

VALORES DE RETORNO

Una submatriz del arreglo de estructuras original, o NULL si hay un error.
