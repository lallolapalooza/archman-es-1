Mail::DKIM::DNS(3) Documentación de Perl aportada por el usuario Mail::DKIM::DNS(3)

NOMBRE

Mail::DKIM::DNS - realiza consultas DNS para Mail::DKIM

VERSIÓN

versión 1.20240923

DESCRIPCIÓN

Este es el módulo que realiza consultas DNS para Mail::DKIM.

CONFIGURACIÓN

Este módulo tiene un par de configuraciones que el llamador puede desear usar para personalizar el comportamiento de este módulo.

$Mail::DKIM::DNS::TIMEOUT

Esta variable global especifica la cantidad máxima de tiempo (en segundos) para esperar a que se complete una consulta DNS individual. El valor predeterminado es 10.

Mail::DKIM::DNS::resolver()

Utilice esta subrutina global para obtener o reemplazar la instancia de Net::DNS::Resolver que utiliza Mail::DKIM. Si se establece en undef (el valor predeterminado), se creará una instancia nueva y predeterminada de Net::DNS::Resolver la primera vez que se necesite una consulta DNS.

Llamará a esta subrutina si desea especificar opciones no predeterminadas para Net::DNS::Resolver, como tiempos de espera diferentes o habilitar el uso de un socket persistente. Por ejemplo:

# primero, construir un resolvedor DNS personalizado
my $res = Net::DNS::Resolver->new(
                  udp_timeout => 3, tcp_timeout => 3, retry => 2,
               );
$res->udppacketsize(1240);
$res->persistent_udp(1);
# luego, indicar a Mail::DKIM que use este resolvedor
Mail::DKIM::DNS::resolver($res);

Mail::DKIM::DNS::enable_EDNS0()

Esta es una subrutina de conveniencia que construirá un resolvedor DNS apropiado que utiliza EDNS0 (Mecanismos de extensión para DNS) para admitir respuestas DNS grandes, y configurará Mail::DKIM para usarlo. (Como tal, NO debe usarse en conjunción con la subrutina resolver() descrita anteriormente).

Mail::DKIM::DNS::enable_EDNS0();

Se recomienda el uso de EDNS0, ya que reduce la necesidad de recurrir a TCP cuando se trata de paquetes DNS grandes. Sin embargo, no está habilitado por defecto porque algunos cortafuegos de Internet que realizan una inspección profunda de paquetes no pueden procesar paquetes habilitados para EDNS0. Cuando hay un cortafuegos en una ruta hacia un resolvedor DNS, la función EDNS0 debe probarse específicamente antes de habilitarla.
