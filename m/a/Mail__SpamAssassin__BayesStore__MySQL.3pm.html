NOMBRE

Mail::SpamAssassin::BayesStore::MySQL - Implementación del Módulo de Almacenamiento Bayesiano Específico de MySQL

DESCRIPCIÓN

Este módulo implementa un módulo de almacenamiento bayesiano basado específicamente en MySQL. Requiere que esté ejecutando al menos la versión 4.1 de MySQL. Si está ejecutando una versión de MySQL < 4.1, varios aspectos de este módulo fallarán y posiblemente corromperán los datos de su base de datos bayesiana.

Además, este módulo admitirá la reversión de errores si está utilizando el tipo de tabla de base de datos InnoDB en MySQL. Para obtener más información, consulte las instrucciones en sql/README.bayes.

Este módulo también es compatible con MariaDB y se puede usar DBD::MariaDB en lugar del controlador DBD::mysql.

token_expiration

public instance (Integer, Integer,

Integer $newdelta,
@ @vars)

Descripción: Este método realiza la expiración de tokens específica de la base de datos basándose en los parámetros $newdelta y @vars proporcionados.

seen_put

public (Boolean) seen_put (string $msgid, char $flag)

Descripción: Este método registra $msgid como el tipo dado por $flag. $flag es uno de los dos valores: 's' para spam y 'h' para ham.

seen_delete

public instance (Boolean) seen_delete (string $msgid)

Descripción: Este método elimina $msgid de la base de datos.

set_last_expire

public instance (Boolean) set_last_expire (Integer $time)

Descripción: Este método establece la hora de la última expiración.

set_running_expire_tok

public instance (String $time) set_running_expire_tok ()

Descripción: Este método establece la hora en que una expiración comienza a ejecutarse.

remove_running_expire_tok

public instance (Boolean) remove_running_expire_tok ()

Descripción: Este método elimina la fila en la base de datos que indica que una expiración se está ejecutando actualmente.

tok_get

public instance (Integer, Integer, Integer) tok_get (String $token)

Descripción: Este método recupera un token especificado ($token) de la base de datos y devuelve su recuento de spam, recuento de ham y hora del último acceso.

tok_get_all

public instance (\@) tok_get (@ $tokens)

Descripción: Este método recupera los tokens especificados ($tokens) del almacenamiento y devuelve una referencia a una matriz de matrices que contiene el recuento de spam, el recuento de ham y la hora del último acceso.

nspam_nham_change

public instance (Boolean) nspam_nham_change (Integer $num_spam,
Integer $num_ham)

Descripción: Este método actualiza el número de spam y el número de ham en la base de datos.

tok_touch

public instance (Boolean) tok_touch (String $token,
String $atime)

Descripción: Este método actualiza la hora de acceso del token especificado ($token).

Se asume que el token ya existe en la base de datos.

tok_touch_all

public instance (Boolean) tok_touch (\@ $tokens
String $atime)

Descripción: Este método realiza una actualización masiva de la lista dada de tokens $tokens, si la hora de acceso del token existente es < $atime.

Se asume que los tokens ya existen en la base de datos.

Nunca deberíamos tocar más de N_SIGNIFICANT_TOKENS, por lo que podemos hacer algunas suposiciones sobre cómo manejar los datos (es decir, no es necesario agruparlos como lo hacemos en tok_get_all).

cleanup

public instance (Boolean) cleanup ()

Descripción: Este método realiza cualquier limpieza necesaria antes de pasar a la siguiente operación.

clear_database

public instance (Boolean) clear_database ()

Descripción: Este método elimina todos los registros de un usuario en particular.

Los llamadores deben tener en cuenta que cualquier error devuelto por este método podría provocar inconsistencias en la base de datos para el usuario dado.
