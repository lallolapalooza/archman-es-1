NOMBRE

Mail::SpamAssassin::DnsResolver - motor de resolución DNS

DESCRIPCIÓN

Este es un motor de resolución DNS para SpamAssassin, implementado con el fin de reducir el uso de descriptores de archivo por parte de Net::DNS y evitar un error de colisión de respuesta en dicho módulo.

MÉTODOS

$res->load_resolver()
Carga el objeto "Net::DNS::Resolver". Devuelve 0 si Net::DNS no se puede utilizar, 1 si está disponible.
$resolver = $res->get_resolver()
Devuelve el objeto "Net::DNS::Resolver".
$res->configured_nameservers()
Obtiene una lista de servidores de nombres tal como se configuran mediante directivas dns_server o tal como los proporciona Net::DNS, típicamente desde /etc/resolv.conf
$res->available_nameservers()
Obtiene o establece una lista de servidores de nombres actualmente disponibles, que típicamente es un subconjunto de servidores de nombres configurados y que se sabe que funcionan.
$res->connect_sock()
Reconecta al primer servidor de nombres listado en "/etc/resolv.conf" o una fuente similar dependiente de la plataforma, tal como la proporciona "Net::DNS".
$res->get_sock()
Devuelve el objeto "IO::Socket::INET" utilizado para comunicarse con el servidor de nombres.
$packet = new_dns_packet ($domain, $type, $class)
Un envoltorio para Net::DNS::Packet::new() que atrapa una llamada a die lanzada por él.

Para usar esto, cambie las llamadas a "Net::DNS::Resolver::bgsend" de:

$res->bgsend($domain, $type);

a:

$res->bgsend(Mail::SpamAssassin::DnsResolver::new_dns_packet($domain, $type, $class));
$id = $res->bgsend($domain, $type, $class, $cb)
SU USO DIRECTO NO ES RECOMENDABLE, utilice bgsend_and_start_lookup en plugins.

Bastante similar a "Net::DNS::Resolver::bgsend", excepto que cuando un paquete de respuesta llega eventualmente, y se llama a "poll_responses", se llamará a la subrutina de referencia de callback $cb.

Tenga en cuenta que $type y $class pueden ser "undef", en cuyo caso se establecerán por defecto a "A" y "IN", respectivamente.

La subrutina de callback se llamará con tres argumentos: el paquete que fue entregado, y una cadena de ID que identifica el paquete de consulta y la respuesta esperada. El tercer argumento es una marca de tiempo (hora Unix, punto flotante), capturada en el momento en que se recogió el paquete. Se espera que se utilice un closure de callback, así:

my $id = $self->{resolver}->bgsend($domain, $type, undef, sub {
      my ($reply, $reply_id, $timestamp) = @_;
      $self->got_a_reply($reply, $reply_id);
    });

El callback puede ignorar la respuesta como un paquete inválido enviado al puerto de escucha si el ID de respuesta no coincide con el valor devuelto por bgsend.

$id = $res->bgread()
Similar a "Net::DNS::Resolver::bgread". Lee un paquete DNS de un socket proporcionado, lo decodifica y devuelve un objeto Net::DNS::Packet si tiene éxito. Muere en caso de error.
$nfound = $res->poll_responses()
Comprueba si hay paquetes de respuesta "bgsend" listos, y devuelve el número de dichos paquetes entregados a sus callbacks.
$res->bgabort()
Llame a esto para liberar las solicitudes pendientes de la memoria, al abortar solicitudes en segundo plano o cuando el escaneo esté completo. "Mail::SpamAssassin::PerMsgStatus::check" llama a esto antes de devolver.
$packet = $res->send($name, $type, $class)
Emula Net::DNS::Resolver::send().

Esta subrutina es una simple reliquia síncrona de la versión 3.3 de SpamAssassin y no participa en el almacenamiento en caché de consultas de paquetes y la agrupación de callbacks tal como se implementa en AsyncLoop::bgsend_and_start_lookup(). Como tal, debe evitarse para el uso general. Actualmente utilizado a través de Mail::SPF::Server por el plugin SPF.

$res->errorstring()
Poco más que un stub para los llamadores que esperan esto de "Net::DNS::Resolver".

Si se llama inmediatamente después de una llamada a $res->send, devolverá "query timed out" si la consulta DNS de $res->send expiró. De lo contrario, se devolverá "unknown error or no error".

No se informan otros errores.

$res->finish_socket()
Restablece el socket cuando se termina de usar.
$res->finish()
Limpia para la destrucción.
