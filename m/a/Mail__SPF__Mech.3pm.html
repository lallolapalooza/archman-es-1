Mail::SPF::Mech(3) Documentación de Perl aportada por el usuario Mail::SPF::Mech(3)

NOMBRE

Mail::SPF::Mech - Clase base para mecanismos de registros SPF

VERSIÓN

versión 3.20250505

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::Mech representa un mecanismo dentro de un registro SPF. Mail::SPF::Mech no se puede instanciar directamente. Cree una instancia de una sub-clase concreta en su lugar.

Constructores

Se proporcionan los siguientes constructores:

new(%options): devuelve Mail::SPF::Mech
Abstracto. Crea un nuevo objeto de mecanismo de registro SPF.

%options es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

text
Una cadena que denota el texto sin analizar del mecanismo.
qualifier
Un cadena de un solo carácter que denota el calificador del mecanismo. Se pueden especificar cualquiera de los siguientes: '+' ("Pass"), '-' ("Fail"), '~' ("SoftFail"), '?' ("Neutral"). Consulte RFC 4408, 4.6.2 y 2.5, para conocer sus significados. Por defecto es '+'.
name
Una cadena que denota el nombre del mecanismo. Requerido si se está construyendo un objeto genérico Mail::SPF::Mech (en contraposición a una sub-clase específica).
ip_network
Un objeto NetAddr::IP que denota un parámetro opcional de red IP del mecanismo. Puede ser una dirección IPv4 o IPv6, con una longitud de prefijo de red opcional. Las direcciones IPv6 mapeadas a IPv4 (por ejemplo, '::ffff:192.168.0.1') no deben especificarse directamente, sino como direcciones IPv4 normales.
domain_spec
Una cadena simple o un objeto Mail::SPF::MacroString que denota un parámetro opcional de "domain-spec" del mecanismo.
ipv4_prefix_length
ipv6_prefix_length
Una cadena que denota una longitud de prefijo de red IPv4 o IPv6 opcional para el "domain_spec" del mecanismo. Tenga en cuenta que estas opciones no se aplican a la opción "ip_network", que ya incluye una longitud de prefijo de red opcional.

Otras opciones pueden ser especificadas por sub-clases de Mail::SPF::Mech.

new_from_string($text, %options): devuelve Mail::SPF::Mech; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMech
Abstracto. Crea un nuevo objeto de mecanismo de registro SPF analizando la cadena y las opciones proporcionadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

default_qualifier: devuelve string
Devuelve el calificador por defecto, es decir, '+'.
default_ipv4_prefix_length: devuelve integer
Devuelve la longitud de prefijo de red IPv4 por defecto, es decir, 32.
default_ipv6_prefix_length: devuelve integer
Devuelve la longitud de prefijo de red IPv6 por defecto, es decir, 128.
qualifier_pattern: devuelve Regexp
Devuelve una expresión regular que coincide con cualquier calificador de mecanismo legal, es decir, '+', '-', '~' o '?'.
name: devuelve string
Abstracto. Devuelve el nombre del mecanismo.

Este método es abstracto y debe ser implementado por sub-clases de Mail::SPF::Mech.

name_pattern: devuelve Regexp
Devuelve una expresión regular que coincide con cualquier nombre de mecanismo legal.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

text: devuelve string; lanza Mail::SPF::ENoUnparsedText
Devuelve el texto sin analizar del mecanismo. Lanza una excepción Mail::SPF::ENoUnparsedText si el mecanismo se creó sintéticamente en lugar de analizarse y no se proporcionó texto.
qualifier: devuelve string
Devuelve el calificador del mecanismo. Consulte la descripción de la opción "qualifier" del constructor "new".
params: devuelve string
Abstracto. Devuelve los parámetros del mecanismo formateados como una cadena.

Una sub-clase de Mail::SPF::Mech no tiene que implementar este método si no admite parámetros.

stringify: devuelve string
Formatea el calificador, el nombre y los parámetros del mecanismo como una cadena y la devuelve. (Se omite un calificador que coincida con el valor por defecto de '+'). Puede utilizar simplemente un objeto Mail::SPF::Mech como cadena para el mismo efecto, consulte "OVERLOADING".
domain($server, $request): devuelve string
Devuelve el dominio de destino del mecanismo. Dependiendo de si el mecanismo tiene un parámetro explícito de "domain_spec", este es el parámetro "domain_spec" expandido por macro, o el dominio de autoridad de la solicitud (consulte "authority_domain" en Mail::SPF::Request) en caso contrario. Se requieren tanto un objeto Mail::SPF::Server como un objeto Mail::SPF::Request para resolver el dominio de destino.
match($server, $request): devuelve boolean; lanza Mail::SPF::Result::Error
Abstracto. Comprueba si el mecanismo coincide con los parámetros de la solicitud dada (consulte Mail::SPF::Request) y devuelve true si coincide, o false en caso contrario. En cualquier caso, toma un objeto Mail::SPF::Server y un objeto Mail::SPF::Request.

Este método es abstracto y debe ser implementado por sub-clases de Mail::SPF::Mech.

match_in_domain($server, $request): devuelve boolean; lanza Mail::SPF::Result::Error
match_in_domain($server, $request, $domain): devuelve boolean; lanza Mail::SPF::Result::Error
Comprueba si el nombre de dominio de destino del mecanismo (es decir, cualquiera de sus registros DNS "A" o "AAAA") coincide con la dirección IP de la solicitud dada (consulte "ip_address" en Mail::SPF::Request), y devuelve true si coincide, o false en caso contrario. Si se especifica un dominio explícito, se utiliza en lugar del dominio de destino del mecanismo. Las longitudes de prefijo de red IP del mecanismo se respetan al comparar los registros de direcciones DNS con la dirección IP de la solicitud. Consulte RFC 4408, 5, para conocer el algoritmo exacto utilizado.

Este método existe principalmente para la comodidad de las sub-clases de Mail::SPF::Mech.

Mail::SPF::Mech(3pm) — Perl documentació

NAME

Mail::SPF::Mech - representa un mecanisme SPF

VERSION

3.20250505-2

DESCRIPTION

El Mail::SPF::Mech la classe base per a tots els mecanismes SPF. Típicament, no voldràs crear instàncies d'aquesta classe directament, sinó una de les seves subclasses.

Vegeu també Mail::SPF::Mech::All, Mail::SPF::Mech::IP4, Mail::SPF::Mech::IP6, Mail::SPF::Mech::A, Mail::SPF::Mech::MX, Mail::SPF::Mech::PTR, Mail::SPF::Mech::Exists, i Mail::SPF::Mech::Include.

METHODS

explain($server, $request, $result)
Genera localment una explicació de per què el mecanisme va causar el resultat donat, i la desa en l'estat de l'objecte de sol·licitud donat.

No cal sobreescriure aquest mètode en les subclasses. Vegeu el mètode "explanation_template".

explanation_template($server, $request, $result): returns string
Retorna una plantilla de cadena de macros per a una explicació generada localment de per què el mecanisme va causar l'objecte de resultat donat.

Les subclasses haurien de definir o bé una constant de tipus hash "explanation_templates_by_result_code" amb les seves pròpies plantilles, o bé sobreescriure aquest mètode.

OVERLOADING

Si un objecte Mail::SPF::Mech s'utilitza com a string, el mètode "stringify" s'utilitza per convertir l'objecte en una cadena.
