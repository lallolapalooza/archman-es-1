NOMBRE

Mail::DKIM - Firma/verifica correos de Internet con firmas DKIM/DomainKey

VERSIÓN

versión 1.20240923

SINOPSIS

# verificar un mensaje
use Mail::DKIM::Verifier;
# crear un objeto verificador
my $dkim = Mail::DKIM::Verifier->new();
# leer un correo de stdin, pasarlo al verificador
while (<STDIN>)
{
    # eliminar terminadores de línea locales
    chomp;
    s/\015$//;
    # usar terminadores de línea SMTP
    $dkim->PRINT("$_\015\012");
}
$dkim->CLOSE;
# ¿cuál es el resultado de la verificación?
my $result = $dkim->result;

DESCRIPCIÓN

Este módulo implementa los varios componentes de los estándares DKIM y DomainKeys de firma y verificación de mensajes para correo de Internet. Actualmente intenta implementar estas especificaciones:

RFC4871, para DKIM
RFC4870, para DomainKeys
draft-ietf-dmarc-arc-protocol-06, para ARC

El módulo utiliza una interfaz orientada a objetos. Utiliza una de las dos clases diferentes, dependiendo de si estás firmando o verificando un mensaje. Para firmar, usa la clase Mail::DKIM::Signer. Para verificar, usa la clase Mail::DKIM::Verifier. Sencillo, ¿verdad?

Igualmente para ARC, usa los módulos ARC Mail::DKIM::ARC::Signer y Mail::DKIM::ARC::Verifier

Si estás enviando a bibliotecas de prueba que esperan que las etiquetas en las cabeceras estén ordenadas, puedes establecer $Mail::DKIM::SORTTAGS a un valor verdadero, y todas las cabeceras creadas tendrán claves ordenadas

BUGS CONOCIDOS

Los problemas al pasar `make test' parecen apuntar generalmente a una configuración de DNS defectuosa en tu máquina, o algo extraño en tus bibliotecas OpenSSL.

El componente de "política de firma del autor" aún está en construcción. La política de firma del autor se supone que identifica la práctica del autor del mensaje, por lo que podrías, por ejemplo, rechazar un mensaje de un autor que afirma que siempre firma sus mensajes. Ver Mail::DKIM::Policy.

Por favor, reporta errores al CPAN RT, o al rastreador de problemas de github.

https://rt.cpan.org/Public/Dist/Display.html?Name=Mail-DKIM

https://github.com/fastmail/mail-dkim/issues
