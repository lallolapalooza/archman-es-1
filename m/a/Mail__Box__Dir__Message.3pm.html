NOMBRE

Mail::Box::Dir::Message - un mensaje en una carpeta organizada por directorio

HERENCIA

Mail::Box::Dir::Message
  es un Mail::Box::Message
  es un Mail::Message
  es un Mail::Reporter
Mail::Box::Dir::Message es extendido por
  Mail::Box::MH::Message
  Mail::Box::Maildir::Message

SINOPSIS

my $folder = new Mail::Box::MH ...
my $message = $folder->message(10);

DESCRIPCIÓN

Un "Mail::Box::Dir::Message" es una clase base para un mensaje en una carpeta organizada por directorio; cada mensaje se almacena en un archivo separado. No hay objetos de tipo "Mail::Box::Dir::Message", solo se permiten crear extensiones.

En este momento, se implementan tres de estos tipos de mensajes extendidos:

  • Mail::Box::MH::Message

    que representa un mensaje en una carpeta Mail::Box::MH. Las carpetas MH son muy, muy simples... y por lo tanto no son sofisticadas ni rápidas.

  • Mail::Box::Maildir::Message

    que representa un mensaje en una carpeta Mail::Box::Maildir. Las banderas se conservan en el nombre del archivo del mensaje. No tiene estado, por lo que nunca perderá un mensaje.

  • Mail::Box::Netzwert::Message

    que representa un mensaje en una carpeta Mail::Box::Netzwert. Como ventaja, almacena información pre-analizada en el archivo del mensaje. Como desventaja: el código no tiene licencia GPL (todavía).

NAME

Mail::Message::Construct - represent a mail message

SYNOPSIS

  use Mail::Message::Construct;

  my $msg = Mail::Message::Construct->new();
  # ... add header fields and body parts ...
  $msg->to('recipient@example.com');
  $msg->subject('Hello');
  $msg->text('This is the message body.');

  print $msg->asString;

DESCRIPTION

This class implements the message construction interface. It extends Mail::Box::Message and inherits all its functionality.
