NOMBRE

Mail::Box::Search - seleccionar mensajes dentro de una caja de correo

HERENCIA

Mail::Box::Search
  es un Mail::Reporter
Mail::Box::Search es extendido por
  Mail::Box::Search::Grep
  Mail::Box::Search::SpamAssassin
  Mail::Server::IMAP4::Search

SINOPSIS

use Mail::Box::Manager;
my $mgr    = Mail::Box::Manager->new;
my $folder = $mgr->open('Inbox');
my $filter = Mail::Box::Search::[algo]->new;
my @msgs   = $filter->search($folder, ...);
if($filter->search($message)) {...}

DESCRIPCIÓN

Esta clase "Mail::Box::Search" es la clase base para varios algoritmos de escaneo de mensajes. Los mensajes seleccionados pueden ser etiquetados. Se admiten operaciones booleanas en los mensajes.

Búsquedas implementadas actualmente:

Mail::Box::Search::Grep
Coincide la cabecera o el cuerpo con una expresión regular al estilo "grep" de UNIX.
Mail::Box::Search::SpamAssassin
Intenta detectar spam, usando Mail::SpamAssassin.
Mail::Box::Search::IMAP
Busca en una carpeta IMAP utilizando las carpetas especiales de interfaz IMAP que proporcionan. EN CONSTRUCCIÓN hasta que Mail::Transport::IMAP4 esté completo.

Extiende "DESCRIPTION" en Mail::Reporter.

binaries => BOOLEAN
Si incluir o no cuerpos binarios en la búsqueda.
decode => BOOLEAN
Decodifica los mensajes antes de que se realice la búsqueda. Incluso los mensajes de texto plano pueden estar codificados, por ejemplo como "quoted-printable", lo que puede afectar los resultados. Sin embargo, la decodificación ralentizará la búsqueda.
delayed => BOOLEAN
Incluye los mensajes diferidos (que serán analizados) en la búsqueda. Si establece esto en "false", puede encontrar menos coincidencias.
deleted => BOOLEAN
En la mayoría de los casos, no estará interesado en resultados que se encuentran en mensajes marcados para ser eliminados. Sin embargo, con esta opción puede especificar que también desea que se busquen.
deliver => undef|CODE|'DELETE'
La funcionalidad exacta de este parámetro difiere según el método de búsqueda, así que lea la página de manual aplicable. En cualquier caso, "undef" significa que no se recopila información para esta búsqueda, lo que resulta en la búsqueda más rápida.

"DELETE" marcará el mensaje para ser eliminado. También puede especificar su propio código de referencia. Con una referencia a un array, la información sobre las coincidencias se recopila como una lista de hashes, un hash por coincidencia.

in => 'HEAD'|'BODY'|'MESSAGE'
Dónde buscar la coincidencia.
label => $label
Marca todos los mensajes seleccionados con la etiqueta especificada. Si este campo no está especificado, el mensaje no recibirá una etiqueta; search() también devuelve una LISTA de mensajes seleccionados.
limit => $numero
Limita la búsqueda al $numero de mensajes especificado. Cuando el $numero es positivo, la búsqueda comienza en el primer mensaje de la carpeta o hilo. Un $numero negativo comienza al final de la carpeta. Si el límite se establece en cero, no hay límite.
log => NIVEL
logical => 'REPLACE'|'AND'|'OR'|'NOT'|'AND NOT'|'OR NOT'
Solo aplicable en combinación con una "label". Cómo manejar las etiquetas existentes. En el caso de "REPLACE", los mensajes que ya llevan la etiqueta se eliminan de su selección (a menos que coincidan de nuevo). Con "AND", el mensaje debe ser seleccionado por esta búsqueda y ya llevar la etiqueta, de lo contrario, la etiqueta no se establecerá. Especifique "OR" para que los mensajes recién seleccionados se agreguen al conjunto de mensajes ya seleccionados.

"NOT" es "true" para los mensajes que no cumplen la búsqueda. La salida de detalles aún contendrá los lugares donde se encontró la coincidencia, sin embargo, esos mensajes serán el conjunto complementario de mensajes que se etiquetarán y devolverán.

multiparts => BOOLEAN
¿Se incluirán las partes múltiples en los resultados de la búsqueda? Algunos MUA tienen problemas para manejar los detalles recibidos de la búsqueda. Cuando esta bandera está desactivada, el cuerpo de las partes múltiples se ignorará. La búsqueda de partes incluirá el preámbulo y el epílogo.

NAME

Mail::Box::Search - base class for mail search engines

INHERITANCE

Mail::Box::Search is a base class. It provides the interface for mail searching. Implementations exist for specific search criteria.

    Mail::Box::Search
      is a Mail::Reporter

SYNOPSIS

  # After creating a concrete search object, like
  use Mail::Box::Search::Grep;
  my $grep = Mail::Box::Search::Grep->new(
      match => 'important',
      in    => 'BODY'
  );

  # Search a folder
  my $results = $grep->search($folder);

  # Or search a single message
  my $message = $folder->message(1);
  my $results = $grep->search($message);

  # Print the found messages
  $grep->printMatch($fh, { messages => $results });

DESCRIPTION

This is the base class for all search engines in Mail::Box. You rarely use this class directly. Instead, you instantiate one of its subclasses, like Mail::Box::Search::Grep.

The main goal is to find messages within a Mail::Box based structure (folder, thread, message, or array of messages) that meet certain criteria.

METHODS

Constructor

$obj->new( ... )
The constructor is called to create a specific search object. The options that can be passed depend on the specific subclass. Common options are:
  • deliver => 'PRINT' | 'ARRAY' | 'OBJECT' | 'NONE'

    How to deliver the results. Defaults to 'PRINT'.

    PRINT
    Print the matching messages. This is the default.
    ARRAY
    Return a list of matched messages.
    OBJECT
    Return a list of Mail::Message objects.
    NONE
    No results are delivered. Useful for counting matches.
  • in => 'BODY' | 'HEAD' | 'MESSAGE'

    Where to search. Defaults to 'MESSAGE' which means both body and head.

    BODY
    HEAD
    MESSAGE
  • limit => NUMBER

    How many messages to find at maximum. Defaults to -1 (no limit).

See also Mail::Reporter for inherited options.

Inherited Methods

$obj->reporter( [$name] )
Returns the Mail::Reporter object associated with this object.
$obj->notImplemented( $method )
Called when a method is not implemented by the concrete search object. See also Mail::Reporter.

Cleanup

$obj->delete()
Clean up resources used by the search object. See Mail::Reporter for detail. Note that the specific search object might add functionality to this method.

Searching

$obj->inBody($part, $body)
Tests whether body contains the requesting information. See the specific search module for its parameters.
$obj->inHead($part, $head)
Tests whether header contains the requesting information. See the specific search module for its parameters.
$obj->search($folder|$thread|$message|ARRAY)
Check which messages from the $folder (Mail::Box) match the search parameters. The matched messages are returned as list. You can also specify a $thread (a Mail::Box::Thread::Node), one single $message (a Mail::Message), or an "ARRAY" of messages.

Sometimes we know how only one match is needed. In this case, this searching will stop at the first match. For instance, when "limit" is -1 or 1, or when the search in done in scalar context.

» example:

my $grep = Mail::Box::Search::Grep->new(
  match   => 'My Name Is Nobody',
  deliver => 'PRINT'
);
$grep->search($folder);
my $message = $folder->message(3);
$grep->search($message);
my $thread  = $message->threadStart;
$grep->search($thread);
$obj->searchPart($part)
Search this message $part for matches.

The Results

$obj->printMatch( [$fh], HASH )
Print the information about the match (see new(deliver)) in some understandable way. If no file handle $fh is specified, the output will go to the selected filehandle (see "perldoc -f select").

DIAGNOSTICS

Error: Cannot search in body.
The search object does not implement inBody(), and can therefore not search a message body. Cast by new()
Error: Cannot search in header.
The search object does not implement inHead(), and can therefore not search a message header. Cast by new()
Error: Don't know how to deliver via results in $way.
The search results cannot be delivered in the specific way, because that is not a defined alternative. Cast by new()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
Error: Search in BODY, HEAD or MESSAGE not $in.
The "in" option defines only three names. Cast by new()
