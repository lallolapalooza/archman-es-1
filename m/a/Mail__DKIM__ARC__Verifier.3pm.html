Mail::DKIM::ARC::Verifier(3) Documentación de Perl contribuida por el usuario Mail::DKIM::ARC::Verifier(3)

NOMBRE

Mail::DKIM::ARC::Verifier - verifica un mensaje sellado con ARC

VERSIÓN

versión 1.20240923

SINOPSIS

use Mail::DKIM::ARC::Verifier;
# crea un objeto verificador
my $arc = Mail::DKIM::ARC::Verifier->new();
# lee un correo desde un manejador de archivo
$arc->load(*STDIN);
# o lee un correo y lo pasa al verificador, incrementalmente
while (<STDIN>)
{
    # elimina terminadores de línea locales
    chomp;
    s/\015$//;
    # usa terminadores de línea SMTP
    $arc->PRINT("$_\015\012");
}
$arc->CLOSE;
# ¿cuál es el resultado de la verificación?
my $result = $arc->result;
# imprime los resultados de todas las firmas y sellos del mensaje
foreach my $signature ($arc->signatures)
{
    print $signature->prefix() . ' v=' . $signature->instance .
                                   ' ' . $signature->result_detail . "\n";
}
# ejemplo de salida. Nótese que para que sea válido, solo la firma
# ARC-Message-Signature MÁS RECIENTE debe coincidir, ya que otros pasos
# pueden haber modificado la firma. Lo que importa es que todos los sellos ARC
# sean válidos y que la firma ARC-Message-Signature más reciente sea válida.

DESCRIPCIÓN

El objeto verificador permite escanear un mensaje de correo en busca de sellos ARC y verificar sus firmas asociadas. El verificador rastrea el estado del mensaje a medida que se lee en memoria. Cuando el mensaje ha sido completamente leído, las firmas se verifican y se puede acceder a los resultados de la verificación.

Para usar el verificador, primero cree el objeto verificador. Luego comience a "alimentarlo" con el mensaje de correo a verificar. Cuando se han leído todas las _cabeceras_, el verificador:

1. verifica si se encontraron firmas ARC
2. consulta las claves públicas necesarias para verificar las firmas
3. configura los objetos de algoritmos y canonicalización apropiados
4. canonicaliza las cabeceras y calcula el hash de cabeceras

Luego, cuando el _cuerpo_ del mensaje ha sido completamente alimentado al verificador, se calcula el hash del cuerpo y se verifican las firmas.

Los resultados de la verificación se pueden consultar con "result()" o "signatures()".

El resultado final se calcula según el algoritmo descrito en https://tools.ietf.org/html/draft-ietf-dmarc-arc-protocol-06 - si TODAS las cabeceras ARC-Seal son válidas y la ARC-Message-Signature de mayor índice (i=) es válida, entonces el sello está intacto.

CONSTRUCTOR

new()

Construye un verificador orientado a objetos.

my $arc = Mail::DKIM::ARC::Verifier->new();
my $arc = Mail::DKIM::ARC::Verifier->new(%options);

Las únicas opciones admitidas en este momento son:

AS_Canonicalization
si se especifica, el mensaje canonizado para el ARC-Seal se escribe en la cadena o manejador de archivo referenciado.
AMA_Canonicalization
si se especifica, el mensaje canonizado para el ARC-Message-Signature se escribe en la cadena o manejador de archivo referenciado.
Strict
Si es verdadero, rechaza hashes sha1 y claves de firma menores a 1024 bits.

MÉTODOS

PRINT()

Alimenta parte del mensaje al verificador.

$arc->PRINT("una línea del mensaje\015\012");
$arc->PRINT('más de');
$arc->PRINT(" el mensaje\015\012adiós\015\012");

Alimenta el contenido del mensaje que se está verificando al verificador. La API está diseñada de esta manera para que no sea necesario cargar todo el mensaje en memoria a la vez.

Tenga en cuenta que, aunque el método PRINT() espera que utilice caracteres de terminación de línea estilo SMTP, NO debe usar la técnica de relleno de puntos estilo SMTP descrita en la RFC 2821 sección 4.5.2. Tampoco debe usar una secuencia <CR><LF>.<CR><LF> para terminar el mensaje.

CLOSE()

Llame a esto cuando termine de alimentar el mensaje.

$arc->CLOSE;

Este método finaliza el proceso de canonicalización, calcula un hash y verifica la firma.

load()

Carga el mensaje completo desde un manejador de archivo.

$arc->load($file_handle);

Lee un mensaje completo del manejador de archivo designado, alimentándolo al verificador. El mensaje debe usar terminadores de línea <CRLF> (igual que el protocolo SMTP).

message_originator()

Accede a la cabecera "From".

my $address = $arc->message_originator;

Devuelve la "dirección del originador" encontrada en el mensaje, como un objeto Mail::Address. Este es típicamente el (primer) nombre y dirección de correo electrónico encontrados en la cabecera From:. Si no hay cabecera From:, se devuelve un objeto Mail::Address vacío.

Para obtener solo la parte de la dirección de correo electrónico, haga:

my $email = $arc->message_originator->address;

Ver también "message_sender()".

message_sender()

Accede a la cabecera "From" o "Sender".

my $address = $arc->message_sender;

Devuelve el "remitente" encontrado en el mensaje, como un objeto Mail::Address. Este es típicamente el (primer) nombre y dirección de correo electrónico encontrados en la cabecera Sender:. Si no hay cabecera Sender:, es el primer nombre y dirección de correo electrónico en la cabecera From:. Si no hay ninguna de las cabeceras presentes, se devuelve un objeto Mail::Address vacío.

Para obtener solo la parte de la dirección de correo electrónico, haga:

my $email = $arc->message_sender->address;

El "remitente" es el buzón del agente responsable de la transmisión real del mensaje. Por ejemplo, si un secretario enviara un mensaje para otra persona, el "remitente" sería el secretario y el "originador" sería el autor real.

result()

Accede al resultado de la verificación.

my $result = $arc->result;

Proporciona el resultado de la verificación. Los siguientes valores son posibles:

pass
Devuelto si se encontró una cadena ARC válida, con todos los ARC-Seals válidos, y la ARC-Message-Signature más reciente (con mayor índice) válida.
fail
Devuelto si algún ARC-Seal falló, o si la ARC-Message-Signature falló. También será un fallo si hay un fallo temporal de DNS, que es una falla conocida en esta versión de ARC::Verifier. Las versiones futuras pueden rechazar este mensaje directamente (4xx) y pedir al remitente que intente la entrega más tarde para evitar crear una cadena rota. No hay temperror para ARC, ya que no tiene sentido firmar una cadena con temperror o todos los spammers la usarían.
invalid
Devuelto si no se pudo verificar un ARC-Seal debido a un problema en la firma misma o en el registro de la clave pública. Es decir, la firma no se pudo procesar.
none
Devuelto si no se encontraron cabeceras ARC-*.

result_detail()

Accede al resultado, más detalles si están disponibles.

my $detail = $dkim->result_detail;

El detalle se construye tomando el resultado (por ejemplo, "pass", "fail", "invalid" o "none") y añadiendo cualquier detalle proporcionado por el proceso de verificación para el ARC-Seal de nivel superior entre paréntesis.

Los siguientes son resultados posibles del método result_detail():

pass
fail (mala firma RSA)
fail (error de OpenSSL: ...)
fail (mensaje alterado)
fail (cuerpo alterado)
invalid (instancia incorrecta)
invalid (dominio incorrecto en etiqueta d)
invalid (falta etiqueta q)
invalid (falta etiqueta d)
invalid (falta etiqueta s)
invalid (versión no soportada 0.1)
invalid (algoritmo no soportado ...)
invalid (canonicalización no soportada ...)
invalid (protocolo de consulta no soportado ...)
invalid (firma caducada)
invalid (clave pública: no disponible)

signatures()

Devuelve una lista de objetos de firma.

my @signatures = $arc->signatures;

Cada objeto en la lista es una instancia de Mail::DKIM::ARC::Signature(3pm). La lista está ordenada del índice más bajo al más alto (es decir, del más antiguo al más reciente).

signatures()

Accede a todas las firmas de este mensaje.

my @all_signatures = $arc->signatures;

Utiliza $signature->result o $signature->result_detail para acceder a los resultados de verificación de cada firma.

Utiliza $signature->instance y $signature->prefix para encontrar la instancia y el nombre de cabecera de cada firma.
