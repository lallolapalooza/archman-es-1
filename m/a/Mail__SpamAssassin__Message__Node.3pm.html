Mail::SpamAssassin::Message::Node(3) Documentación de Perl aportada por el usuario Mail::SpamAssassin::Message::Node(3)

NOMBRE

Mail::SpamAssassin::Message::Node - decodifica, renderiza y pone a disposición partes de mensajes MIME

DESCRIPCIÓN

Este módulo encapsulará un mensaje de correo electrónico y permitirá el acceso a las diversas partes del mensaje MIME.

MÉTODOS PÚBLICOS

new()
Genera un objeto Node vacío y lo devuelve. Normalmente, solo es llamado por funciones en Message.
find_parts()
Se utiliza para buscar en el árbol partes MIME específicas. Se devuelve una matriz de objetos Node coincidentes (punteros en el árbol). Los parámetros que se pueden pasar son (en orden, todos escalares):

Regexp - Se utiliza para coincidir con la cabecera Content-Type de cada parte, específicamente el tipo y no el resto de la cabecera. Por ejemplo: "Content-type: text/html; encoding=quoted-printable" tiene un tipo "text/html". Si no se especifica ninguna regexp, find_parts() devolverá una matriz vacía.

Only_leaves - Por defecto, find_parts() devolverá cualquier parte que coincida con la regexp, incluyendo multipart. Si solo desea ver las hojas del árbol (es decir, partes que no son multipart), establezca esto en verdadero (1).

Recursive - Por defecto, cuando find_parts() encuentra un multipart que tiene partes debajo de él, recorrerá recursivamente a todos los sub-hijos. Si se establece en 0, solo examinará la parte y cualquier hijo directo de la parte.

header()
Almacena y recupera cabeceras de una parte MIME específica. El primer parámetro es el nombre de la cabecera. Si no hay otro parámetro, se recupera la cabecera. Si hay un segundo parámetro, se almacena la cabecera.

Los nombres de las cabeceras no distinguen entre mayúsculas y minúsculas y se almacenan tanto en formato raw como decodificado. Usando header(), solo se puede recuperar el formato decodificado.

Para la recuperación, si header() se llama en un contexto de matriz, se devolverá una matriz con cada entrada de cabecera en un elemento diferente. En un contexto escalar, se devuelve la última cabecera específica.

Por ejemplo: Si se especifica 'Subject' como cabecera, y hay 2 cabeceras Subject en un mensaje, la última/inferior en el mensaje se devuelve en contexto escalar o ambas se devuelven en contexto de matriz.

raw_header()
Recupera la versión raw de las cabeceras de una parte MIME específica. El único parámetro es el nombre de la cabecera. Los nombres de las cabeceras no distinguen entre mayúsculas y minúsculas.

Para la recuperación, si raw_header() se llama en un contexto de matriz, se devolverá una matriz con cada entrada de cabecera en un elemento diferente. En un contexto escalar, se devuelve la última cabecera específica.

Por ejemplo: Si se especifica 'Subject' como cabecera, y hay 2 cabeceras Subject en un mensaje, la última/inferior en el mensaje se devuelve en contexto escalar o ambas se devuelven en contexto de matriz.

add_body_part()
Añade un objeto hijo Node al objeto Node actual.
is_leaf()
Devuelve verdadero si el nodo del árbol en cuestión es una hoja del árbol (es decir, no tiene hijos propios). Nota: ¡Esta función puede devolver resultados extraños a menos que el mensaje haya sido analizado por MIME a través de _do_parse()!
raw()
Devuelve una referencia a la matriz raw. Trátela como SOLO LECTURA.
decode()
Si es necesario, decodifica el texto de la parte como base64 o quoted-printable. El texto decodificado se devolverá como una cadena escalar. Se puede pasar un parámetro de longitud opcional que limita la cantidad de datos decodificados que se devuelven. Si el escalar no es necesario, llámelo con "0" como parámetro.
rendered()
rendered() toma la parte MIME de tipo text/* dada e intenta renderizarla en un escalar de texto. Siempre renderizará text/html y usará una heurística para determinar si otras partes text/* deben considerarse text/html. Se devuelven dos escalares: el tipo renderizado (text/html o el que sea el tipo original) y el texto renderizado.
set_rendered($text, $type)
Establece el texto y el tipo renderizados para la parte dada. Si no se especifica el tipo y el texto es un valor definido, se utiliza un valor predeterminado de 'text/plain'. Esto se puede usar, por ejemplo, para renderizar partes no textuales usando plugins.
visible_rendered()
Renderiza y devuelve el texto visible en esta parte.
invisible_rendered()
Renderiza y devuelve el texto invisible en esta parte.
content_summary()
Devuelve una matriz de escalares que describen las partes MIME del mensaje. Nota: ¡Esta función requiere que el mensaje se analice primero!
delete_header()
Elimina la cabecera especificada (decodificada y raw) de la información del Node.
get_header()
Recupera una cabecera específica. Tendrá un salto de línea al final y se desplegará. El primer parámetro es el nombre de la cabecera (no distingue mayúsculas y minúsculas), y el segundo parámetro (opcional) es si se debe devolver la cabecera raw.

Si get_header() se llama en un contexto de matriz, se devolverá una matriz con cada entrada de cabecera en un elemento diferente. En un contexto escalar, se devuelve la última cabecera específica.

Por ejemplo: Si se especifica 'Subject' como cabecera, y hay 2 cabeceras Subject en un mensaje, la última/inferior en el mensaje se devuelve en contexto escalar o ambas se devuelven en contexto de matriz.

Por cierto, devolver el último campo de cabecera (no el primero) coincide con las firmas DKIM, que buscan y cubren múltiples campos de cabecera de abajo hacia arriba según la etiqueta 'h'. Mantengámoslo así.

get_all_headers()
Recupera todas las cabeceras. Cada cabecera tendrá un salto de línea al final y se desplegará. El primer parámetro (opcional) es si se deben devolver las cabeceras raw, y el segundo parámetro (opcional) es si se debe incluir el separador de mbox.

Si get_all_header() se llama en un contexto de matriz, se devolverá una matriz con cada entrada de cabecera en un elemento diferente. En un contexto escalar, las cabeceras se devuelven en una sola cadena escalar.
