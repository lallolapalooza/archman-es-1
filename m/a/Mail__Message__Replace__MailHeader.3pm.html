NOMBRE

Mail::Message::Replace::MailHeader: objeto falso de Mail::Header

HERENCIA

Mail::Message::Replace::MailHeader
                          es una Mail::Message::Head::Complete
                          es una Mail::Message::Head
                          es una Mail::Reporter

SINOPSIS

# Cambio
use Mail::Internet;
use Mail::Header;
# en código existente, y el código seguirá funcionando, pero
# con las características de Mail::Message.

DESCRIPCIÓN

Este módulo es una capa alrededor de Mail::Message::Head::Complete, que simula un objeto Mail::Header. El espacio de nombres de ese módulo es heredado y se añaden muchos métodos.

Más métodos funcionarán sin cambios, pero debería probar tu software de nuevo. Se han hecho pequeños cambios en fold_length(), header_hashref().

NAME

Mail::Message::Head::HTML - access to the header of a mail message

SYNOPSIS

    use Mail::Message::Head;
    my $head = Mail::Message::Head->new();
    # ... fill the header ...
    my $html = $head->as_html;
    print $html;
    # ---
    my $message = Mail::Message->new();
    my $head    = $message->head;
    $head->add( Date => 'Mon, 24 May 1994 13:57:07 PDT' );
    $head->add( From => 'God ' );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->read( $file );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->new( \%hash );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->new( 'From: god@heaven.org' );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->new( ['From: god@heaven.org'] );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->new(
        From    => 'god@heaven.org',
        Subject => 'Hello',
    );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->new(
        from    => 'god@heaven.org',
        subject => 'Hello',
    );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->new(
        'X-Mailer' => 'My Command Line Mailer v1.1',
        'Subject'  => 'Test',
        'To'       => 'you@example.com',
        'Cc'       => 'someone@example.com',
    );
    print $head->as_html;
    # ---
    my $head = Mail::Message::Head->read( $file );
    my $html = $head->as_html(
        class_header   => 'my-header',
        class_field    => 'my-field',
        class_tag      => 'my-tag',
        class_value    => 'my-value',
        field_renderer => sub { ... }, # custom renderer
        tag_renderer   => sub { ... }, # custom renderer
        value_renderer => sub { ... }, # custom renderer
    );
    print $html;
    # ---
    # Example of custom renderer
    my $head = Mail::Message::Head->new( Subject => 'Hello World' );
    my $html = $head->as_html(
        tag_renderer   => sub {
            my ($tag, $class) = @_;
            return '<strong class="' . $class . '">' . $tag . '</strong>';
        },
        value_renderer => sub {
            my ($value, $class) = @_;
            return '<em class="' . $class . '">' . $value . '</em>';
        },
    );
    # Output:
    # <table class="my-header">
    #  <tr>
    #   <td class="my-field">
    #    <strong class="my-tag">Subject</strong>
    #   </td>
    #   <td class="my-value">Hello World</td>
    #  </tr>
    # </table>

DESCRIPTION

This class provides an HTML representation of the header of a mail message. It extends Mail::Message::Head::Complete::as_html().

The primary method is as_html().

METHODS

Public methods

$obj->as_html( [%options] )
Returns the header as an HTML table. The header fields are presented as rows in the table. Each row consists of two cells: the first cell contains the tag (field name), and the second cell contains the value.

The following options can be provided:

class_header
The CSS class for the enclosing <table> tag. Defaults to "my-header".
class_field
The CSS class for the <td> tag enclosing the tag and value. Defaults to "my-field".
class_tag
The CSS class for the tag (field name) cell. Defaults to "my-tag".
class_value
The CSS class for the value cell. Defaults to "my-value".
field_renderer
A callback function that renders a single field. It receives the tag, the value, and the CSS classes as arguments: sub { my ($tag, $value, $classes) = @_; ... }. The default renderer creates a table row with two cells.
tag_renderer
A callback function that renders the tag (field name). It receives the tag and its CSS class as arguments: sub { my ($tag, $class) = @_; ... }. The default renderer wraps the tag in a <td> tag.
value_renderer
A callback function that renders the value. It receives the value and its CSS class as arguments: sub { my ($value, $class) = @_; ... }. The default renderer wraps the value in a <td> tag.

If a renderer is provided, it takes precedence over the corresponding CSS class options.

The default output structure is:

<table class="my-header">
  <tr>
    <td class="my-field">
      <span class="my-tag">Tag-Name</span>
    </td>
    <td class="my-value">Field-Value</td>
  </tr>
  ...
</table>

The field_renderer allows for more complex structures, like nested tables or lists, by overriding the default row creation.

The tag_renderer and value_renderer are used by the default field_renderer.

The values are HTML-escaped by default to prevent XSS attacks.

Returns the line wrap, optionally after setting it to $length. The old value is returned. The $tag argument is ignored, because it is silly to have different lines fold in different ways. This method cannot be called statically anymore.
$obj->header( [ARRAY] )
Extract the fields from the "ARRAY", if specified, and then fold the fields. Returned is an array with all fields, produced via orderedFields().

$obj->mail_from( ['IGNORE'|'ERROR'|'COERCE'|'KEEP'] )
What to do when a header line in the form `From ' is encountered. Valid values are "IGNORE" - ignore and discard the header, "ERROR" - invoke an error (call die), "COERCE" - rename them as Mail-From and "KEEP" - keep them.
$obj->modify( [BOOLEAN] )

$obj->read($file)

$obj->tags()
Returns all the names of fields, implemented by Mail::Message::Head::Complete::names().
$obj->unfold( [$tag] )
Remove the folding for all instances of $tag, or all fields at once.

DIAGNOSTICS

Warning: Cannot remove field $name from header: not found.
You ask to remove a field which is not known in the header. Using delete(), reset(), or set() to do the job will not result in warnings: those methods check the existence of the field first. Cast by removeField()
Warning: Field objects have an implied name ($name)
Cast by build()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
