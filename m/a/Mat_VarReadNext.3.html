Mat_VarReadNext(3)

Paquete: libmatio

Licencias: BSD-2-Clause

MAT_VARREADNEXT(3) Manual de funciones de biblioteca MAT_VARREADNEXT(3)

NOMBRE

Mat_VarReadNext — Lee la información y los datos de la siguiente variable en un archivo MAT de MATLAB.

SINOPSIS

#include <matio.h>

matvar_t *
Mat_VarReadNext(mat_t *matfp);

DESCRIPCIÓN

La función Mat_VarReadNext() lee la información y los datos de la siguiente variable almacenada en el archivo MAT abierto.

VALORES DE RETORNO

Si hay otra variable en el archivo MAT y se lee con éxito, se devuelve un puntero a la estructura de la variable de MATLAB. Si no hay más variables, o si hubo un error al leer la variable, se devuelve NULL.

EJEMPLOS

Este programa de ejemplo abre un archivo MAT denominado con el primer argumento del programa y utiliza Mat_VarReadNext() para leer cada variable del archivo. Para cada variable leída, se utiliza la función Mat_VarPrint(3) para mostrar la información y los datos de la variable.

#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

int
main(int argc, char **argv)
{
    mat_t    *matfp;
    matvar_t *matvar;

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Error al abrir el archivo MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    while ( NULL != (matvar = Mat_VarReadNext(matfp)) ) {
        Mat_VarPrint(matvar, 1);
        Mat_VarFree(matvar);
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
