NOMBRE

URILocalBL - bloquea URIs usando información local (nombres de ISP, listas de direcciones y códigos de país)

SINOPSIS

Este plugin crea algunos nuevos tipos de prueba de reglas, como "uri_block_cc", "uri_block_cidr" y "uri_block_isp". Estas reglas se aplican a las URIs encontradas en la parte HTML de un mensaje, es decir, en el marcado <a href=...>.

loadplugin    Mail::SpamAssassin::Plugin::URILocalBL

¿Por qué listas negras locales? Hay algunas DNSBL excelentes, efectivas y bien mantenidas. Pero tienen varios inconvenientes:

  • las listas negras pueden abarcar decenas de miles de entradas, y no puedes seleccionar cuáles usas;
  • verificar que está configurada correctamente puede no ser trivial;
  • las nuevas entradas en listas negras pueden tardar en ser detectadas e ingresadas, por lo que no es instantáneo.

A veces, todo lo que quieres es una lista negra rápida, fácil y muy quirúrgica de un sitio en particular o de un ISP en particular. Este plugin está definido para ese caso de uso exacto.

DEFINICIONES DE REGLAS Y CONFIGURACIONES PRIVILEGIADAS

El formato para definir una regla es el siguiente:

uri_block_cc NOMBRE_DE_PRUEBA_SIMBÓLICA cc1 cc2 cc3 cc4 ..
uri_block_cc NOMBRE_DE_PRUEBA_SIMBÓLICA !cc1 !cc2 ..

o:

uri_block_cont NOMBRE_DE_PRUEBA_SIMBÓLICA co1 co2 co3 co4 ..
uri_block_cont NOMBRE_DE_PRUEBA_SIMBÓLICA !co1 !co2 ..

o:

uri_block_cidr NOMBRE_DE_PRUEBA_SIMBÓLICA a.a.a.a b.b.b.b/cc

o:

uri_block_isp NOMBRE_DE_PRUEBA_SIMBÓLICA "Data Rancid" McCarrier Phishers-r-Us

Regla de ejemplo para coincidir con una URI en China:

uri_block_cc TEST1 cn

Si especificas una lista de negaciones, dicha regla coincidirá con CUALQUIER país excepto los listados (Finlandia, Suecia):

uri_block_cc TEST1 !fi !se

Los continentes uri_block_cont funcionan exactamente igual que uri_block_cc.

Esto bloquearía la URL http://www.baidu.com/index.htm. Del mismo modo, para coincidir con un bloque de red de Spam:

uri_block_cidr TEST2 65.181.64.0/18

coincidiría con un bloque de red donde varios sitios de phishing se alojaron recientemente.

Y para bloquear todos los bloques CIDR registrados en un ISP, se podría usar:

uri_block_isp TEST3 "Data Rancid" ColoCrossing

Entre comillas los nombres de ISP que contienen espacios.

Finalmente, si hay un país que deseas bloquear pero hay un host explícito que deseas eximir de esa lista negra, puedes usar:

uri_block_exclude TEST1 www.baidu.com

si deseas eximir URLs que se refieran a este host. La misma sintaxis es aplicable también a los bloques CIDR e ISP.

DEPENDENCIAS

El filtrado basado en códigos de país puede utilizar cualquier módulo soportado por Mail::SpamAssassin::GeoDB como MaxMind::DB::Reader (GeoIP2) o Geo::IP. El filtrado basado en ISP podría requerir una base de datos con suscripción de pago como GeoIPISP.
