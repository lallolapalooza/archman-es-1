Math::BigInt::FastCalc(3perl) Guía de referencia para programadores de Perl Math::BigInt::FastCalc(3perl)

NOMBRE

Math::BigInt::FastCalc - Math::BigInt::Calc con algunas extensiones XS para mayor velocidad

SINOPSIS

# para usarlo con Math::BigInt
use Math::BigInt lib => 'FastCalc';
# para usarlo con Math::BigFloat
use Math::BigFloat lib => 'FastCalc';
# para usarlo con Math::BigRat
use Math::BigRat lib => 'FastCalc';

DESCRIPCIÓN

Math::BigInt::FastCalc hereda de Math::BigInt::Calc.

Proporciona soporte para cálculos de enteros grandes. No está diseñado para ser utilizado por otros módulos. Otros módulos que ofrezcan las mismas funciones también pueden utilizarse para dar soporte a Math::BigInt, como Math::BigInt::GMP o Math::BigInt::Pari.

Para permitir múltiples bibliotecas de enteros grandes, Math::BigInt fue reescrito para utilizar módulos de biblioteca para las rutinas matemáticas principales. Cualquier módulo que siga la misma API que este puede ser utilizado en su lugar usando lo siguiente:

use Math::BigInt lib => 'nombre_lib';

'nombre_lib' es el nombre largo ('Math::BigInt::Pari') o solo la versión corta como 'Pari'. Para usar esta biblioteca:

use Math::BigInt lib => 'FastCalc';

El comportamiento por defecto es elegir la mejor representación interna de los enteros grandes, pero la longitud base utilizada en la representación interna puede especificarse explícitamente. Tenga en cuenta que esto debe hacerse antes de que se cargue Math::BigInt. Por ejemplo,

use Math::BigInt::FastCalc base_len => 3;
use Math::BigInt lib => 'FastCalc';

ALMACENAMIENTO

Math::BigInt::FastCalc funciona exactamente como Math::BigInt::Calc. Los números se almacenan en forma decimal divididos en partes.
