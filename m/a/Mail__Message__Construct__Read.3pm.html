NOMBRE

Mail::Message::Construct::Read - leer un Mail::Message desde un manejador de archivo

SINOPSIS

my $msg1 = Mail::Message->read(\*STDIN);
my $msg2 = Mail::Message->read(\@lines);

DESCRIPCIÓN

Cuando se llaman métodos complejos en un objeto "Mail::Message", este paquete se carga automáticamente para admitir la lectura de mensajes directamente desde cualquier manejador de archivo.

MÉTODOS

Construcción de un mensaje

$class->read($fh|STRING|SCALAR|ARRAY, %options)
Lee un mensaje desde un $fh, "STRING", "SCALAR" o una referencia a un "ARRAY" de líneas. La mayoría de %options se pasan al método new() del mensaje que se crea, pero se definen algunas adicionales.

Por favor, echa un vistazo a build() y buildFromBody() antes de pensar en este método "read". Usa este "read" solo cuando tengas un manejador de archivo como STDIN para analizar, o alguna fuente externa de líneas de mensajes. Cuando ya tienes un conjunto separado de líneas de encabezado y cuerpo, entonces "read" ciertamente no es tu mejor opción.

Algunas personas usan este método en un script procmail: el mensaje llega a stdin, por lo que solo tenemos un manejador de archivo. En este caso, estás limitado a este método. El mensaje va precedido por una línea que se puede usar como separador de mensajes en carpetas mbox. Consulta el ejemplo sobre cómo manejar eso.

Este método eliminará los campos "Status" y "X-Status" cuando aparezcan en la fuente, para evitar el riesgo de que estos campos interfieran accidentalmente con tu administración interna, lo que podría tener implicaciones de seguridad.

-Opción             --Por defecto
 body_type            undef
 parser_class         undef
 seekable             false
 strip_status_fields  <C<true>>
 trusted              true
body_type => CLASE
Fuerza el uso de un tipo de cuerpo (cualquier implementación específica de Mail::Message::Body) para almacenar el contenido del mensaje. Cuando el cuerpo es multipart o anidado, esto se anulará.
parser_class => CLASE
Obliga a usar un tipo de analizador específico, que debe ser una extensión de la clase de analizador que se toma por defecto.
seekable => BOOLEANO
Indica que se ha pasado un manejador de archivo buscable. En este caso, podemos usar el analizador Mail::Box::Parser::Perl que lee mensajes directamente del flujo de entrada.
strip_status_fields => BOOLEANO
Elimina los campos "Status" y "X-Status" del mensaje después de leerlo, para reducir el riesgo de que los mensajes recibidos de fuentes externas interfieran con tu administración interna. Si deseas que los campos no se eliminen (quieres deshabilitar la eliminación), probablemente estés procesando carpetas tú mismo, ¡lo cual es algo malo!
trusted => BOOLEANO

my $msg1 = Mail::Message->read(\*STDIN);
my $msg2 = Mail::Message->read(\@lines, log => 'PROGRESS');
$folder->addMessages($msg1, $msg2);
my $msg3 = Mail::Message->read(<<MSG);
Subject: hola mundo
To: you@example.com
                     # ¡¡¡ advertencia: se requiere línea vacía !!!
Hi, greetings!
MSG
# ejemplo procmail
my $fromline = <STDIN>;
my $msg      = Mail::Message->read(\*STDIN);
my $coerced  = $mboxfolder->addMessage($msg);
$coerced->fromLine($fromline);
