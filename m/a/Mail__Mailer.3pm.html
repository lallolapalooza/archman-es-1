Mail::Mailer(3) Documentación de Perl aportada por el usuario Mail::Mailer(3)

NOMBRE

Mail::Mailer - enviar correos simples

HERENCIA

Mail::Mailer
  es un IO::Handle

SINOPSIS

use Mail::Mailer;
use Mail::Mailer qw(mail);    # especifica el mailer por defecto
$mailer = Mail::Mailer->new;
$mailer = Mail::Mailer->new($type, @args);
$mailer->open(\%headers);
print $mailer $body;
$mailer->close
    or die "no se pudo enviar el mensaje completo: $!\n";

DESCRIPCIÓN

Envía correos usando cualquiera de los métodos preinstalados. Como argumento TYPE al método new(), puedes especificar cualquiera de los siguientes:

"sendmail"
Usa el programa "sendmail" para enviar los correos.
"smtp"
Usa el protocolo "smtp" mediante Net::SMTP para enviar los correos. El servidor a usar puede especificarse en @args con
$mailer = Mail::Mailer->new('smtp', Server => $server);

El mailer smtp no maneja líneas "Cc" y "Bcc", ni sus hermanos "Resent-*". La opción "Debug" habilita la salida de depuración de "Net::SMTP".

[agregado 2.21] También puedes usar las opciones "StartTLS => 1" para actualizar la conexión con STARTTLS. La misma aplicación se aplica a la opción "SSL => 1".

También puedes usar la opción "Auth => [ $user, $password ]" para autenticación SASL. Para que funcione, tienes que instalar la distribución Authen::SASL por ti mismo: no se instala automáticamente.

"smtps"
Esta opción está obsoleta cuando tienes "libnet" 1.28 (2014) y superior. Usa el protocolo smtp sobre ssl mediante Net::SMTP::SSL para enviar correos. La utilización es idéntica a "smtp". Debes instalar Authen::SASL también.
$mailer = Mail::Mailer->new('smtps', Server => $server);
"qmail"
Usa el programa qmail-inject de qmail para enviar los correos.
"testfile"
Usado para depuración, muestra los datos en el archivo nombrado en $Mail::Mailer::testfile::config{outfile} que por defecto se llama "mailer.testfile". No se envía nunca ningún correo.

"Mail::Mailer" buscará en la orden de los siguientes ejecutables. El mailer por defecto será el primero encontrado.

MÉTODOS

Constructores

Mail::Mailer->new($type, %options)
El $type es uno de los implementadores de envío de correos, como se describe en el capítulo DESCRIPTION de esta página de manual. Las %options se pasan a ese implementador.
$obj->open(HASH)
La HASH contiene pares de clave y valor, donde la clave es el nombre del campo de encabezado (por ejemplo, "To"), y el valor es el contenido correspondiente del campo de encabezado. El valor puede ser un escalar (por ejemplo, "gnat@frii.com") o una referencia a un array de escalares (por ejemplo, "p.ej., ['gnat@frii.com', 'Tim.Bunce@ig.co.uk']").

DETALLES

VARIABLES DE ENTORNO

PERL_MAILERS
Aumenta/sobrescribe la elección del binario usado para enviar nuestros mensajes de correo.

Formato:

"type1:mailbinary1;mailbinary2;...:type2:mailbinaryX;...:..."

Ejemplo: si quieres usar un binario privado de sendmail en lugar de mailx, podrías establecer

"PERL_MAILERS"

a:

"mail:/no/existe/|sendmail:$HOME/test/bin/sendmail"

En sistemas que puedan incluir ":" en nombres de archivos, usa "|" como separador entre grupos de tipo.

"mail:c:/no/existe|sendmail:$HOME/test/bin/sendmail"

ERRORES

Mail::Mailer no ayuda con el doble envío y no protege contra diversos ataques de scripts web, por ejemplo, donde se inserta una nueva línea en el contenido de un campo.
