Nombre

Mail::Box::Maildir::Message - un mensaje en un folder Maildir

Herencia

Mail::Box::Maildir::Message
  es un Mail::Box::Dir::Message
  es un Mail::Box::Message
  es un Mail::Message
  es un Mail::Reporter

Sintaxis

mi $folder  = Mail::Box::Maildir->new(...);
mi $message = $folder->message(10);

Descripción

Una "Mail::Box::Maildir::Message" representa un mensaje en un folder Maildir. Cada mensaje se almacena en un archivo separado.

Flags in filename

When new messages arrive on system and have to be stored in a maildir folder, they are put in the "new" sub-directory of the folder (first created in the "tmp" sub-directory and then immediately moved to "new"). The following information was found at https://cr.yp.to/proto/maildir.html.

Each message is written in a separate file. The filename is constructed from the time-of-arrival, a hostname, an unique component, a syntax marker, and flags. For example "1014220791.meteor.42:2,DF". The filename must match:

my ($time, $unique, $hostname, $info) =
   $filename =~ m!^(\d+)\.(.*)\.(\w+)(\:.*)?$!;
my ($semantics, $flags) =
   $info =~ m!([12])\,([DFPRST]*)$!;
my @flags = split //, $flags;

When an application opens the folder, there may be messages in "new" which are new arival, and messages in "cur". The latter are labeled "accepted". To move a message from "new" to "cur", you have two options with the same effect:

$msg->accept;
$msg->label(accept => 1);

See accept(), label(), Mail::Box::Maildir::new(accept_new), and Mail::Box::Maildir::acceptMessages()

The messages are moved, and their name is immediately extended with flags. An example:

new/897979431.meteor.42      may become
cur/897979431.meteor.42:2,FS

The added characters ':2,' refer to the "second state of processing", where the message has been inspected. And the characters (which should be in alphabetic order) mean

D      => draft
F      => flagged
R      => replied  (answered)
S      => seen
T      => deleted  (tagged for deletion)

Some maildir clients support

P      => passed   (resent/forwarded/bounced to someone else)

The flags will immediately change when label() or delete() is used, which differs from other message implementations: maildir is stateless, and should not break when applications crash.

DIAGNOSTICS

Error: Cannot coerce a $c
A message object is not of the expected class (e.g. it was expected to be a Mail::Message::Construct, but was a simple string).

DIAGNOSTICS

Error: Cannot coerce $object into a $class object
Convertido por coerce()
Error: Cannot create parser for $filename.
Por alguna razón (el mensaje anterior ya te lo ha dicho) no fue posible crear un analizador de mensajes para el nombre de archivo especificado. Convertido por parser()
Error: Cannot include forward source as $include.
Alternativa desconocida para el forward (include). Las opciones válidas son "NO", "INLINE", "ATTACH" y "ENCAPSULATE". Convertido por forward()
Error: Cannot include reply source as $include.
Alternativa desconocida para la opción "include" de reply(). Las opciones válidas son "NO", "INLINE" y "ATTACH". Convertido por reply()
Error: Cannot write message to $filename: $!
Cuando un mensaje modificado o nuevo se escribe en disco, primero se escribe en un archivo temporal en el directorio de la carpeta. Por alguna razón, es imposible crear este archivo. Convertido por create()
Error: Failed to move $new to $filename: $!
Cuando un mensaje modificado o nuevo se escribe en disco, primero se escribe en un archivo temporal en el directorio de la carpeta. Luego, el nuevo archivo se mueve para reemplazar el archivo existente. Aparentemente, esto último falla. Convertido por create()
Error: Method bounce requires To, Cc, or Bcc
El método bounce() del mensaje reenvía un mensaje recibido a otra persona sin modificaciones; debes especificar su nuevo destino. Si tienes la necesidad de no especificar ningún destino, probablemente estás buscando reply(). Cuando desees modificar el contenido, usa forward(). Convertido por bounce()
Error: Method forwardAttach requires a preamble
Convertido por forwardAttach()
Error: Method forwardEncapsulate requires a preamble
Convertido por forwardEncapsulate()
Error: No address to create forwarded to.
Si se crea un mensaje reenviado, se debe especificar una dirección de destino. Convertido por forward()
Error: No default mailer found to send message.
El mecanismo send() del mensaje no tenía suficiente información para encontrar automáticamente un agente de transferencia de correo para enviar este mensaje. Especifica un agente de correo explícitamente usando las opciones "via". Convertido por send()
Error: No rebuild rule $name defined.
Convertido por rebuild()
Error: Only build() Mail::Message's; they are not in a folder yet
Es posible que desees construir un mensaje para almacenarlo en algún tipo de carpeta, pero necesitas hacerlo en dos pasos. Primero, crea un Mail::Message normal, y luego agrégalo a la carpeta. Durante este proceso de Mail::Box::addMessage(), el mensaje será convertido (coerce) al tipo de mensaje correcto, agregando información de almacenamiento y similar. Convertido por build()
Error: Package $package does not implement $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, pero la clase en cuestión no lo hace. Probablemente deberías investigar esto y, posiblemente, informar al autor del paquete. Convertido por notImplemented()
Error: Unable to read delayed body.
Por alguna razón, la cabecera del mensaje se pudo leer, pero el cuerpo no. Probablemente el archivo ha desaparecido o los permisos cambiaron durante la ejecución del programa. Convertido por loadBody()
Error: Unable to read delayed head.
Mail::Box intenta ser "perezoso" con respecto al análisis de mensajes. Cuando se abre una carpeta organizada por directorios, solo se recopilan los nombres de archivo de los mensajes. Al primer uso, los mensajes se leen de su archivo. Aparentemente, un mensaje se utiliza por primera vez aquí, pero ha desaparecido o no se puede leer por alguna otra razón. Convertido por loadBody()
Error: coercion starts with some object
Convertido por coerce()
