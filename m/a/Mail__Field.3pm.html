NOMBRE

Mail::Field - clase base para la manipulación de campos de encabezado de correo

HERENCIA

Mail::Field es extendido por
  Mail::Field::AddrList
  Mail::Field::Date
  Mail::Field::Generic

SINOPSIS

use Mail::Field;

my $field = Mail::Field->new('Subject', 'algun texto de asunto');
my $field = Mail::Field->new(Subject => 'algun texto de asunto');
print $field->tag,": ",$field->stringify,"\n";
my $field = Mail::Field->subject('algun texto de asunto');

DESCRIPCIÓN

"Mail::Field" crea y manipula campos en encabezados MIME, recolectados dentro de un objeto Mail::Header. Diferentes tipos de campo tienen su propia subclase (extensión), definiendo acceso adicionales útiles al contenido del campo.

Se invita a la gente a fusionar sus implementaciones de campos especiales en MailTools, para mantener un conjunto consistente de paquetes y documentación.

MÉTODOS

Constructores

Mail::Field (y sus subclases) definen varios métodos que devuelven nuevos objetos. Todos estos pueden ser categorizados como constructores.

Mail::Field->combine($campos)
Toma una LISTA de objetos "Mail::Field" (que deben ser todos de la misma subclase) y crea un nuevo objeto en la misma clase.
Mail::Field->extract( $tag, $head [, $indice ] )
Toma como argumentos el nombre de la etiqueta, un objeto "Mail::Head" y opcionalmente un índice.

Si se proporciona el argumento de índice, entonces "extract" recuperará la etiqueta dada del objeto "Mail::Head" y creará un nuevo objeto basado en "Mail::Field". Se devolverá undef si el campo no existe.

Si el argumento de índice no se proporciona, el resultado depende del contexto en el que se llama a "extract". Si se llama en un contexto escalar, el resultado será como si "extract" hubiera sido llamado con un valor de índice de cero. Si se llama en un contexto de lista, se recuperarán todas las etiquetas y se devolverá una lista de objetos "Mail::Field".

Mail::Field->new( $tag [, STRING | %opciones ] )
Crea un objeto en la clase que define el campo especificado por el argumento $tag.

Constructores "falsos"

$obj->create(%opciones)
Este constructor se usa internamente con información de campo preprocesada. Cuando se llama sobre un objeto existente, su contenido original se reemplazará.
$obj->parse()
Analiza una línea de campo.

Accesoress

$obj->set(%opciones)
Cambia la configuración (el contenido, pero de forma inteligente) de este campo.
$obj->stringify()
Devuelve el campo como una cadena.
$obj->tag()
Mail::Field->tag()
Devuelve la etiqueta (en la capitalización correcta) para este elemento. Bueno, en realidad, cualquier capitalización está bien, porque las etiquetas de campo se tratan sin distinción de mayúsculas y minúsculas; sin embargo, la gente tiene algunas preferencias.

Accesoress inteligentes

$obj->text( [CADENA] )
Sin argumentos, el campo se devuelve como lo hace stringify(). De lo contrario, la CADENA se analiza con parse() para reemplazar el contenido del objeto.

Es más claro llamar directamente a stringify() o parse(), porque este método no agrega procesamiento adicional.

DETALLES

NOMBRES DE PAQUETES DE SUBCLASES

Todas las subclases deben llamarse Mail::Field::nombre donde nombre se deriva de la etiqueta usando estas reglas.

  • Considere una etiqueta como compuesta por elementos separados por '-'
  • Convierta todos los caracteres a minúsculas excepto el primero de cada elemento, que debe estar en mayúsculas.
  • nombre se crea a partir de estos elementos usando los primeros N caracteres de cada elemento.
  • N se calcula usando la fórmula :- 
    int((7 + #elementos) / #elementos)
  • nombre se limita a un máximo de 8 caracteres, conservando los primeros 8 caracteres.

Como ejemplo de esto, eche un vistazo a la definición de la subrutina _header_pkg_name() en "Mail::Field"

DIAGNÓSTICOS

Error: Se llamó a una subrutina indefinida <método>
Los objetos Mail::Field usan el cargado automático para compilar nueva funcionalidad. Aparentemente, el método llamado no está implementado para la clase específica del objeto de campo.

Mail::Field(3pm)

Mail::Field - An interface to Mail::Header fields

NAME

Mail::Field - An interface to Mail::Header fields

SYNOPSIS


use Mail::Field;

my $field = Mail::Field->new($name, $value);
my $name = $field->name;
my $value = $field->value;
my $string = $field->as_string;

DESCRIPTION

This module provides an object-oriented interface to mail header fields. It is used by the Mail::Header module.

The Mail::Field class provides methods for accessing the name and value of a mail header field, and for returning a string representation of the field.
