NOMBRE

Mail::SpamAssassin::Pyzor::Client - Lógica del cliente Pyzor

SINOPSIS

use Mail::SpamAssassin::Pyzor::Client ();
use Mail::SpamAssassin::Pyzor::Digest ();
my $client = Mail::SpamAssassin::Pyzor::Client->new();
my $digest = Mail::SpamAssassin::Pyzor::Digest::get( $msg );
my $check_ref = $client->check($digest);
die $check_ref->{'Diag'} if $check_ref->{'Code'} ne '200';
my $report_ref = $client->report($digest);
die $report_ref->{'Diag'} if $report_ref->{'Code'} ne '200';

DESCRIPCIÓN

Un cliente Pyzor http://pyzor.org básico que actualmente solo implementa la funcionalidad necesaria para Mail::SpamAssassin.

DETALLES DEL PROTOCOLO

El protocolo Pyzor no es un estándar publicado, y parece no haber documentación pública significativa. Lo que sigue es información suficiente, en gran parte obtenida de publicaciones de foros y ingeniería inversa, para facilitar el uso efectivo de este módulo:

Pyzor es un protocolo orientado a RPC y basado en mensajes. Cada mensaje es un simple diccionario de claves y valores ASCII de 7 bits. Las respuestas del servidor siempre incluyen al menos lo siguiente:

  • "Code" - Similar a los códigos de estado HTTP; cualquier cosa que no sea 200 es un error.
  • "Diag" - Similar a las razones de estado HTTP: una descripción textual del estado.

(Nota: Hay encabezados de respuesta estándar adicionales que son útiles solo para el protocolo en sí y, por lo tanto, no forman parte de los valores devueltos por este módulo.)

Fiabilidad

Pyzor utiliza UDP en lugar de TCP, por lo que no se garantiza que ningún mensaje llegue a su destino. Puede ocurrir un error de transmisión tanto en la solicitud como en la respuesta; en cualquier caso, se producirá un error de tiempo de espera. Dichos errores se representan como instancias lanzadas de Mail::Pyzor::X::Timeout.

CONSTRUCTOR

new(%OPTS)

Crea un nuevo cliente pyzor.

Entrada
%OPTS son (todas opcionales):
  • "server_host" - El host del servidor pyzor al que conectarse (el valor predeterminado es "public.pyzor.org")
  • "server_port" - El puerto del servidor pyzor al que conectarse (el valor predeterminado es 24441)
  • "username" - El nombre de usuario a presentar al servidor pyzor (el valor predeterminado es "anonymous")
  • "password" - La contraseña a presentar al servidor pyzor (el valor predeterminado está vacío)
  • "timeout" - El tiempo máximo, en segundos, para esperar una respuesta del servidor pyzor (el valor predeterminado es 3.5)
Salida
Devuelve un objeto Mail::SpamAssassin::Pyzor::Client.

MÉTODOS DE SOLICITUD

report($digest)

Informa el digest de un mensaje de spam al servidor pyzor. Esta función lanzará una excepción si ocurre un error de mensajería o un tiempo de espera agotado.

Entrada
$digest "SCALAR"
El digest del mensaje a informar, tal como lo proporciona Mail::SpamAssassin::Pyzor::Digest::get().
Salida
"HASHREF"
Devuelve una referencia hash de los atributos estándar anotados anteriormente.

check($digest)

Comprueba el digest de un mensaje para ver si el servidor pyzor tiene un informe para él. Esta función lanzará una excepción si ocurre un error de mensajería o un tiempo de espera agotado.

Entrada
$digest "SCALAR"
El digest del mensaje a comprobar, tal como lo proporciona Mail::SpamAssassin::Pyzor::Digest::get().
Salida
"HASHREF"
Devuelve una referencia hash de los atributos estándar anotados anteriormente, así como los siguientes:
  • "Count" - El número de informes que el servidor ha recibido para el digest dado.
  • "WL-Count" - El número de solicitudes de lista blanca que el servidor ha recibido para el digest dado.
