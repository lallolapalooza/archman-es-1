MAT_VARDELETE(3) Manual de funciones de la biblioteca MAT_VARDELETE(3)

NOMBRE

Mat_VarDelete — Elimina una variable MAT de un archivo.

SINOPSIS

#include <matio.h>

int
Mat_VarDelete(mat_t *matfp, const char *name);

DESCRIPCIÓN

La función Mat_VarDelete() elimina la variable MAT name del archivo MAT dado por la estructura del archivo MAT matfp.

VALORES DE RETORNO

La función devuelve 0 si tiene éxito. De lo contrario, se devuelve un valor de error.
