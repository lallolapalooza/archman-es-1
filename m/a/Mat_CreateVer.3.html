Mat_CreateVer(3)

Paquete: libmatio

Licencias: BSD-2-Clause

MAT_CREATEVER(3) Manual de funciones de biblioteca MAT_CREATEVER(3)

NOMBRE

Mat_CreateVer, Mat_Create — Crea un archivo MAT de MATLAB.

SINOPSIS

#include <matio.h>

mat_t *
Mat_CreateVer(const char *matname, const char *hdr_str, enum mat_ft mat_file_ver);

mat_t *
Mat_Create(const char *matname, const char *hdr_str);

DESCRIPCIÓN

La función Mat_CreateVer() crea un archivo MAT de MATLAB abierto para acceso de escritura. El hdr_str es una cadena que se escribe en la cabecera del archivo de los archivos MAT de versión 5 y 7.3 (HDF). Solo se escriben los primeros 128 bytes de la cadena. Si hdr_str es NULL, se escribe una cadena predeterminada que contiene la plataforma, la fecha y la versión de la biblioteca matio.

El argumento mat_file_ver especifica la versión del archivo MAT a crear. La biblioteca matio puede escribir archivos de versión 4 (MAT_FT_MAT4), archivos de versión 5 (MAT_FT_MAT5) y un formato de archivo HDF5 introducido en la versión 7.3 de MATLAB (MAT_FT_MAT73).

La función Mat_Create() es equivalente a llamar a Mat_CreateVer() con MAT_FT_DEFAULT como versión del archivo.

EJEMPLOS

#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

int main(int argc, char **argv)
{
    mat_t *matfp;

    matfp = Mat_CreateVer(argv[1], NULL, MAT_FT_73);
    if ( NULL == matfp ) {
        fprintf(stderr, "Error al crear el archivo MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
