Mail::Message::Replace::MailInternet(3) Documentación de Perl contribuida por el usuario Mail::Message::Replace::MailInternet(3)

NOMBRE

Mail::Message::Replace::MailInternet - simula Mail::Internet

HERENCIA

Mail::Message::Replace::MailInternet
  es un Mail::Message
  es un Mail::Reporter

SINOPSIS

# cambia
use Mail::Internet;
# por
use Mail::Message::Replace::MailInternet;
# en código existente, y el código debería seguir funcionando, pero
# con las características de Mail::Message.

DESCRIPCIÓN

Este módulo es un envoltorio alrededor de un Mail::Message, que simula un objeto Mail::Internet. El espacio de nombres de ese módulo es secuestrado y se añaden muchos métodos.

La mayoría de los métodos funcionarán sin ningún cambio, pero puede que necesites echar un vistazo a tus llamadas a smtpsend() y send().

Extiende "DESCRIPTION" en Mail::Message.

DIAGNÓSTICOS

Error: Cannot create message for non-existing folder $folder
Un intento de crear un mensaje para una carpeta que no existe.
Error: Cannot delete $folder : $error
Un intento de borrar una carpeta que no existe.
Error: No content to send
El mensaje está vacío y no se puede enviar.
Error: No destination, but no "bounce" either
Cuando se crea un mensaje reenviado, una dirección de destino debe ser especificada. Si no desea especificar un destino, probablemente esté buscando reply(). Cuando desee modificar el contenido, use forward(). Emitido por bounce()
Error: El método forwardAttach requiere un preámbulo
Emitido por forwardAttach()
Error: El método forwardEncapsulate requiere un preámbulo
Emitido por forwardEncapsulate()
Error: No hay dirección para crear el reenvío.
Si se crea un mensaje de reenvío, se debe especificar una dirección de destino. Emitido por forward()
Error: No hay regla de reconstrucción $name definida.
Emitido por rebuild()
Error: Solo build() Mensajes de correo; aún no están en una carpeta
Puede que desee construir un mensaje para ser almacenado en algún tipo de carpeta, pero necesita hacerlo en dos pasos. Primero, cree un Mail::Message normal, y luego agréguelo a la carpeta. Durante este proceso de Mail::Box::addMessage(), el mensaje será coerce()-d al tipo de mensaje correcto, añadiendo información de almacenamiento y similar. Emitido por build()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, sin embargo, la clase en cuestión no lo hace. Probablemente debería investigar esto y probablemente informar al autor del paquete. Emitido por notImplemented()
