Mail::DKIM::Policy(3) Documentación de Perl contribuida por el usuario Mail::DKIM::Policy(3)

NOMBRE

Mail::DKIM::Policy - clase base abstracta para políticas de "firma" del originador

VERSIÓN

versión 1.20240923

SINOPSIS

# obtener todas las políticas que se aplican a un mensaje verificado
foreach my $policy ($dkim->policies)
{
    # el nombre de esta política
    my $name = $policy->name;
    # la ubicación en DNS donde se encontró esta política
    my $location = $policy->location;
    # aplicar esta política al mensaje que se está verificando
    my $result = $policy->apply($dkim);
}

DESCRIPCIÓN

Entre las diversas versiones de los estándares DomainKeys/DKIM, se han definido varias formas de políticas de "firma" del remitente. Para que la biblioteca Mail::DKIM pueda soportar estas diferentes políticas, utiliza varias subclases diferentes. Todas las subclases soportan esta interfaz general, de modo que un programa que utilice Mail::DKIM pueda soportar cualquier política o todas las políticas encontradas para un mensaje.

MÉTODOS

Estos métodos son soportados por todas las clases que implementan la interfaz Mail::DKIM::Policy.

apply()

Aplica la política a los resultados de un verificador DKIM.

my $result = $policy->apply($dkim_verifier);

El llamador debe proporcionar una instancia de Mail::DKIM::Verifier, una que ya haya recibido el mensaje que se está verificando.

Los resultados posibles son:

aceptar
El mensaje es aprobado por la política de firma del remitente.
rechazar
El mensaje es rechazado por la política de firma del remitente.
neutral
El mensaje no es aprobado ni rechazado por la política de firma del remitente. Puede considerarse sospechoso.

as_string()

La política como una cadena de texto.

Tenga en cuenta que la cadena devuelta por este método no tendrá necesariamente las etiquetas ordenadas de la misma manera que el registro de texto encontrado en DNS.

is_implied_default_policy()

¿Se implica esta política?

my $is_implied = $policy->is_implied_default_policy;

Si recupera la política para un dominio particular, pero ese dominio no tiene una política publicada, entonces está en vigor la "política por defecto". Utilice este método para detectar cuándo ocurre eso.

location()

De dónde se obtuvo la política.

Generalmente es un nombre de dominio, el nombre de dominio donde se publicó la política.

Si no se publica nada para el dominio y se devolvió la política por defecto en su lugar, la ubicación será "undef".

name()

Identifica qué tipo de política es esta.

Actualmente devuelve cadenas como "sender", "author" y "ADSP". Está sujeta a cambios en la próxima versión de Mail::DKIM.

VER TAMBIÉN

Mail::DKIM::DkPolicy - para políticas de firma de remitente DomainKeys RFC4870 (históricas)

Mail::DKIM::DkimPolicy - para políticas de firma de remitente DKIM en borrador temprano

Mail::DKIM::AuthorDomainPolicy - para Prácticas de Firma de Dominio del Autor (ADSP)
