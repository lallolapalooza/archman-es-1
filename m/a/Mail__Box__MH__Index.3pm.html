Mail::Box::MH::Index(3) Documentación de paquetes contribuidos de Perl Mail::Box::MH::Index(3)

NOMBRE

Mail::Box::MH::Index - mantener archivos de índice para mensajes.

INHERENCIA

Mail::Box::MH::Index
  hereda de Mail::Reporter

SYNOPSIS

my $index = Mail::Box::MH::Index->new;
$index->read(...)
$index->write(...)

DESCRIPCIÓN

Los carpetas de mensaje que almacenan sus datos en un único archivo por mensaje son muy ineficientes para producir sobrescrituras de asunto y calcular hilas de mensajes. El objeto Mail::Box::MH::Index puede almacenar y leer las cabeceras de un conjunto de mensajes Mail::Box::MH::Message que forman parte de una sola carpeta Mail::Box::MH en un único archivo.

Cuando la funcionalidad de Mail::Box::MH::Index se habilita especificando Mail::Box::MH::new(keep_index) al abrir una carpeta, el archivo de índice se lee automáticamente. Cuando la carpeta se cierra, se crea un nuevo archivo de índice.

Se da especial cuidado para evitar problemas cuando el usuario cambia o elimina archivos de mensaje sin actualizar el índice. Si el índice no es confiable, no se usará (cueste algunas performance para el lector de la carpeta).

El_Indice

$obj->append(@messages)
Añadir @messages al archivo de índice.
$obj->get($msgfile)
Ver si hay información de cabecera para el archivo de mensaje $msgfile. El nombre del archivo representa un mensaje en una carpeta de tipo directorio. Este método devuelve un objeto de la nueva clase (head_type) especificada durante la creación del objeto de índice, o "undef" si no se encuentra la información o no es confiable -i.e. el tamaño del archivo cambió.
$obj->read()
Leer el archivo de índice. Después de esta llamada, las objetos de cabecera pueden ser solicitados con el método get().
$obj->write(@messages)
Escribir un archivo de índice conteniendo las cabeceras especificadas @messages (objetos Mail::Message).
