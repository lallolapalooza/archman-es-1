Mail::Message::Field::Attribute(3) Documentación de Contribución de Usuarios de Perl Mail::Message::Field::Attribute(3)

NOMBRE

Mail::Message::Field::Attribute - un atributo de un campo completo

HERENCIA

Mail::Message::Field::Attribute
  es un Mail::Reporter

SINOPSIS

my $field    = $msg->head->get('Content-Disposition') or return;
my $full     = $field->study;   # comprensión completa en unicode
my $filename = $full->attribute('filename')           or return;
print ref $filename;     # nombre de esta clase
print $filename;         # el contenido de los atributos en utf-8
print $filename->value;  # lo mismo
print $filename->string; # imprime la cadena tal como se encontró en el archivo
$filename->print(\*OUT); # imprime tal como se encontró en el archivo

DESCRIPCIÓN

Los atributos dentro de los campos MIME pueden ser bastante complejos, y por lo tanto, lentos y consumen mucha memoria. Mail::Message::Field::Fast y Mail::Message::Field::Flex los simplifican mucho, lo que puede resultar en un comportamiento erróneo en casos raros. Con el aumento de idiomas no occidentales en Internet, la necesidad de cabeceras complejas es cada vez mayor.

Un "Mail::Message::Field::Attribute" se puede encontrar en cualquier campo de cabecera estructurado de Mail::Message::Field::Full.

Extiende "DESCRIPTION" en Mail::Reporter.

SOBRECARGADO

sobrecarga: "" estandarización
Devuelve el contenido decodificado del atributo.
sobrecarga: cmp comparación de cadenas
Cuando el segundo argumento es un campo, tanto el nombre del atributo (sensible a mayúsculas y minúsculas) como el valor decodificado deben ser los mismos. De lo contrario, se compara el valor.

Constructores

Extiende "Constructors" en Mail::Reporter.

$class->new( <$name, [$value] | CADENA>, %options )
Crea un nuevo atributo $name con el $value opcional. Si no se especifica $value, se inspecciona el primer argumento de este método en busca de un signo igual '='. Si ese carácter está presente, el argumento se toma como "CADENA", que contiene un atributo preformateado que se procesa. De lo contrario, el argumento se toma como nombre sin $value: establezca el valor más tarde con value().

Si se realiza la codificación depende de las %options y la existencia de caracteres no ASCII en el $value. El $name solo puede contener caracteres ASCII, por lo tanto, nunca se codifica.

Para acelerar las cosas, los atributos no se derivan de la clase base Mail::Reporter. Mejora la base, ver "Constructors" en Mail::Reporter

-Opción           --Definido en     --Por defecto
 charset                             'us-ascii'
 language                            undef
 log                Mail::Reporter   'WARNINGS'
 trace              Mail::Reporter   'WARNINGS'
 use_continuations                   <C<true>>
charset => CADENA
El $value se traduce de utf-8 (interno de Perl) a este conjunto de caracteres, y la cadena resultante se codifica si es necesario. "us-ascii" es la codificación normal para el correo electrónico. Los conjuntos de caracteres válidos se pueden encontrar con Encode::encodings(':all').
language => CADENA
RFC2231 añade la posibilidad de especificar un idioma con el campo. Cuando no se especifica ningún idioma, no se incluye en la codificación. Los nombres de idioma válidos están definidos por RFC2130. Este módulo solo tiene soporte limitado para esta característica.
log => LEVEL
trace => LEVEL
use_continuations => BOOLEANO
Las continuaciones se utilizan para dividir parámetros largos en partes que no superan los 76 caracteres. Las codificaciones se especifican en RFC2231, pero no son compatibles con algunos Agentes de Usuario de Correo.

» ejemplo:

my $fn    = Mail::Message::Field::Attribute->new(filename => 'xyz');
my $fattr = 'Mail::Message::Field::Attribute';  # abreviatura
my $fn    = $fattr->new(
  filename => "Re\xC7u",
  charset  => 'iso-8859-15',
  language => 'nl-BE'
);
print $fn;
  # -->  filename*=iso-8859-15'nl-BE'Re%C7u

El atributo

$obj->addComponent(CADENA)
Un componente es un parámetro tal como se define en RFC2045, utilizando opcionalmente codificación o continuaciones tal como se define en RFC2231. Los componentes de un atributo se encuentran cuando se analiza un campo. Los RFC son muy estrictos con los caracteres válidos, pero nosotros no podemos serlo: tienes que aceptar lo que venga si puedes.

» ejemplo:

my $param = Mail::Message::Field::Attribute->new;
$param->addComponent("filename*=iso10646'nl-BE'%Re\47u");
$obj->charset()
Devuelve el conjunto de caracteres que se utiliza para este parámetro. Si se añade algún componente que contenga información del conjunto de caracteres, está directamente disponible. Tenga en cuenta que un conjunto de caracteres no distingue entre mayúsculas y minúsculas.
$obj->language()
Devuelve el idioma que se define en el argumento. Si no se define ningún idioma, se devuelve "undef", lo que debería interpretarse como "CUALQUIERA"
$obj->name()
Devuelve el nombre de este atributo.
$obj->string()
Cuando se llama en contexto de LISTA, se devuelven las líneas para ser procesadas una tras otra. En contexto ESCALAR, esto devuelve la lista de atributos formateada.
$obj->value( [CADENA] )
Devuelve el valor de este parámetro, o

Mail::Message::Field::Attribute(3pm)

NAME

Mail::Message::Field::Attribute - represent a specific part of a header line.

INHERITANCE

Mail::Message::Field::Attribute.

SYNOPSIS

    # ABSTRACT METHODS
    $obj->decode;
    $obj->encode;
    $obj->mergeComponent($attribute);

    # FROM Mail::Message::Field::Envelope
    $obj->add("field-name" => "field-value");
    $obj->printHeader;

    # FROM Mail::Message::Field::Simple
    $obj->is($name, $value);
    $obj->has($name);

    # FROM Mail::Message::Field
    $obj->next;
    $obj->parent;
    $obj->name;
    $obj->value;
    $obj->text;
    $obj->parse;
    $obj->add($field);
    $obj->remove($field);
    $obj->fields($name);
    $obj->fields;
    $obj->get($name);
    $obj->set($name, $value);
    $obj->printMimeHeader;
    $obj->printRfc822Header;
    $obj->flatten;

DESCRIPTION

This class is an abstract base class for message header fields that are composed of multiple components. For example, the From: header can contain multiple addresses, each of which can be represented by an Attribute object. The field objects themselves contain a list of Attribute objects.

The goal of this class is to make it possible to generate header fields from structured data. When a header field is composed of multiple items that follow specific rules, these items are represented by subclasses of Mail::Message::Field::Attribute.

For example, the To: header field can contain multiple recipients. Each recipient is represented by an instance of Mail::Message::Field::Attribute::Address. The Mail::Message::Field::To object holds a list of these Address objects.

The methods decode and encode are abstract and must be implemented by concrete subclasses.

OVERLOADED

:
Calls the decode method.
~
Calls the encode method.

METHODS

Constructor

new()
Creates a new Mail::Message::Field::Attribute object. The decode method must be called on the created object to set its value.

Attribute encoding

decode()
Translate all known continuations into a value. The produced value is returned and may be utf-8 encoded or a plain string.
encode()

Internals

$obj->mergeComponent($attribute)
Merge the components from the specified attribute into this attribute. This is needed when components of the same attribute are created separately. Merging is required by the field parsing.
