NOMBRE

Mail::SpamAssassin::BayesStore::SQL - Implementación del Módulo de Almacenamiento Bayesiano SQL

DESCRIPCIÓN

Este módulo implementa un módulo de almacenamiento bayesiano basado en SQL. Es compatible con SQLite y posiblemente con otros servidores SQL estándar.

No utilice esto para MySQL/MariaDB o PgSQL, ya que tienen sus propios módulos específicos.

get_storage_variables

instancia pública (@) get_storage_variables ()

Descripción: Este método recupera las diversas variables administrativas utilizadas por el proceso Bayesiano y la base de datos.

Los valores devueltos en el array están en el siguiente orden:

0: base de conteo de escaneo

1: número de correos spam

2: número de correos ham

3: número de tokens en la base de datos

4: tiempo de acceso de última expiración

5: tiempo de acceso del token más antiguo en la base de datos

6: valor de la versión de la base de datos

7: última sincronización de diario

8: último delta de tiempo de acceso

9: último conteo de reducción de expiración

10: tiempo de acceso del token más reciente en la base de datos

NOMBRE

Mail::SpamAssassin::BayesStore::SQL

DESCRIPCIÓN

Este módulo proporciona una interfaz para interactuar con una base de datos SQL de tipo Bayes, utilizada en el sistema de SpamAssassin.

MÉTODOS

Este módulo incluye métodos para manipular la base de datos SQL de Bayes.

Métodos privados

Este módulo incluye métodos privados para operaciones internas de la base de datos SQL.

_connect_db

método privado (booleano) _connect_db ()

Este método conecta a la base de datos SQL.

_get_db_version

método privado (entero) _get_db_version ()

Obtiene la versión actual de la base de datos desde las tablas globales especializadas.

_initialize_db

método privado (booleano) _initialize_db ()

Verifica si los variables de bayes de un usuario han sido inicializadas. Si no lo han sido, se realiza la inicialización.

_put_token

método privado (booleano) _put_token (cadena $token, entero $spam_count, entero $ham_count, cadena $atime)

Este método realiza la operación de insertar o actualizar un token en la base de datos.

_put_tokens

método privado (booleano) _put_tokens (\% $tokens,
entero $spam_count,
entero $ham_count, cadena $atime)

Este método realiza la operación de insertar o actualizar múltiples tokens en la base de datos.

_get_oldest_token_age

método privado (entero) _get_oldest_token_age ()

Este método encuentra la edad del token más antiguo en la base de datos.

La utilización de min(atime) en SQL es ineficiente, pero es la forma más rápida de obtener la edad del token más antiguo después de una expiración masiva. Debe llamarse solo durante el proceso de expiración.

_get_num_hapaxes

método privado (entero) _get_num_hapaxes ()

Este método obtiene el número total de hapaxes (spam_count + ham_count == 1) en la base de datos de tokens para un usuario.

_get_num_lowfreq

método privado (entero) _get_num_lowfreq ()

Este método obtiene el número total de tokens bajos frecuencia (spam_count < 8 y ham_count < 8) en la base de datos de tokens para un usuario.

_token_select_string

método privado (cadena) _token_select_string

Este método devuelve la cadena que se utilizará en consultas SELECT para representar la columna de tokens.

El valor por defecto es usar la función SUBSTR para alinear los tokens a 5 caracteres.
