NOMBRE

Mail::Message::Body::Construct - añade funcionalidad a Mail::Message::Body

SINOPSIS

DESCRIPCIÓN

Este paquete añade funcionalidad compleja a la clase Mail::Message::Body. Estas funciones se usan con menos frecuencia, por lo que muchos programas no compilarán este paquete.

MÉTODOS

Construcción de un cuerpo

$obj->attach(@messages, %options)
Crea un multipart que contiene este cuerpo y los @messages especificados. Las opciones se pasan al constructor del cuerpo multipart. Si necesitas más control, crea el cuerpo multipart tú mismo. Al menos, échale un vistazo a Mail::Message::Body::Multipart.

Las partes del mensaje se convertirán a Mail::Message::Part, así que puedes adjuntar objetos Mail::Internet o MIME::Entity si quieres --ver Mail::Message::coerce(). Se devuelve un nuevo cuerpo con los mensajes adjuntos.

» ejemplo:

my $pgpkey = Mail::Message::Body::File->new(file => 'a.pgp');
my $msg    = Mail::Message->buildFromBody($message->decoded->attach($pgpkey));
# El último mensaje del cuerpo multipart $multi se convierte en la entidad $entity.
my $entity  = MIME::Entity->new;
my $multi   = $msg->body->attach($entity);
# Ahora crea un nuevo mensaje
my $msg     = Mail::Message->new(head => ..., body => $multi);
$obj->concatenate(@components)
Concatena el contenido textual de una LISTA de elementos en un nuevo cuerpo. El objeto de cuerpo resultante se basa en el llamador, el cual puede no estar incluido en el resultado.

Especifica una lista de textos @components. Cada componente puede ser

  • un mensaje (Mail::Message, se usa el cuerpo del mensaje),
  • un cuerpo simple (Mail::Message::Body),
  • "undef" (que se omitirá),
  • un escalar (que se divide en líneas), o
  • un array de escalares (cada uno proporciona una línea).

» ejemplo:

# todos los argumentos son Mail::Message::Body.
my $sum = $body->concatenate($preamble, $body, $epilogue, "-- \n" , $sig);
$obj->foreachLine(CODE)
Crea un nuevo cuerpo realizando una acción en cada una de sus líneas. Si ninguna de las líneas cambia, se devolverá el cuerpo actual, de lo contrario se creará un nuevo cuerpo del mismo tipo que el actual.

El "CODE" se refiere a una subrutina que se llama, donde $_ contiene la línea original del cuerpo. ¡¡¡NO CAMBIES $_!!! El resultado de la rutina se toma como la nueva línea. Cuando la rutina devuelve "undef", la línea se omitirá.

» ejemplo:

my $content  = $msg->decoded;
my $reply    = $content->foreachLine( sub { '> '.$_ } );
my $rev      = $content->foreachLine( sub { reverse } );
sub filled() { length $_ > 1 ? $_ : undef }
my $nonempty = $content->foreachLine( \&filled );
my $WRONG    = $content->foreachLine( sub { s/a/A/ } );
my $right    = $content->foreachLine( sub { s/a/A/r });
$obj->stripSignature(%options)
Elimina la firma del cuerpo. El cuerpo ya debe estar decodificado, de lo contrario se podrían eliminar las líneas incorrectas. Se devuelve la versión del cuerpo sin la firma, y en contexto de lista también la firma, encapsulada en su propio objeto de cuerpo. El separador de firma es la primera línea del cuerpo de firma devuelto.

La firma es añadida por el remitente para hablar de él/ella. Es superflua en algunas situaciones, por ejemplo, si quieres crear una respuesta al mensaje de la persona, no necesitas incluir esa firma.

Si el cuerpo no tenía firma, se devuelve el objeto de cuerpo original y "undef" para el cuerpo de firma.

-Option     --Default
 max_lines    10
 pattern      qr/^--\s?$/
 result_type  <same as current>
max_lines => INTEGER|undef
El número máximo de líneas que puede tener la longitud de una firma. Especifica "undef" para eliminar el límite.
pattern => REGEX|STRING|CODE
Qué patrón define la línea que indica el separador entre el mensaje y la firma. En caso de STRING, esto se compara con el principio de la línea, y REGEX es una expresión regular completa.

En caso de CODE, cada línea (de la última a la primera) se pasa a la subrutina especificada como primer argumento. La subrutina debe devolver TRUE cuando se encuentra el separador.

result_type => CLASS
El tipo de cuerpo a crear para el cuerpo sin firma (y quizás también para contener la firma eliminada)

» ejemplo:

my $start = $message->decoded;
my $start = $body->decoded;
my $stripped = $start->stripSignature;
my ($stripped, $sign) = $start->stripSignature
    (max_lines => 5, pattern => '-*-*-');
