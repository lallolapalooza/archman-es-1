Mail::SPF::Mod(3) Documentación de Perl aportada por el usuario Mail::SPF::Mod(3)

NOMBRE

Mail::SPF::Mod - Clase base del modificador de registro SPF

VERSIÓN

versión 3.20250505

DESCRIPCIÓN

Un objeto de la clase Mail::SPF::Mod representa un modificador dentro de un registro SPF. Mail::SPF::Mod no se puede instanciar directamente. Cree una instancia de una subclase concreta en su lugar.

Constructores

Se proporcionan los siguientes constructores:

new(%options): devuelve Mail::SPF::Mod
Abstracto. Crea un nuevo objeto modificador de registro SPF.

%options es una lista de pares clave/valor que representan cualquiera de las siguientes opciones:

text
Una cadena de texto que denota el texto sin analizar del modificador.
name
Una cadena de texto que denota el nombre del modificador. Requerido si se está construyendo un objeto genérico Mail::SPF::Mod (a diferencia de una subclase específica).
domain_spec
Una cadena de texto simple o un objeto Mail::SPF::MacroString que denota un parámetro opcional "domain-spec" del mecanismo.
new_from_string($text, %options): devuelve Mail::SPF::Mod; lanza Mail::SPF::ENothingToParse, Mail::SPF::EInvalidMod
Abstracto. Crea un nuevo objeto modificador de registro SPF analizando la cadena de texto y las opciones proporcionadas.

Métodos de clase

Se proporcionan los siguientes métodos de clase:

name_pattern: devuelve Regexp
Devuelve una expresión regular que coincide con cualquier nombre de modificador legal.

Métodos de instancia

Se proporcionan los siguientes métodos de instancia:

text: devuelve cadena de texto; lanza Mail::SPF::ENoUnparsedText
Devuelve el texto sin analizar del modificador. Lanza una excepción Mail::SPF::ENoUnparsedText si el modificador se creó sintéticamente en lugar de analizarse, y no se proporcionó ningún texto.
name: devuelve cadena de texto
Devuelve el nombre del modificador.
params: devuelve cadena de texto
Abstracto. Devuelve los parámetros del modificador formateados como cadena de texto.

Una subclase de Mail::SPF::Mod no tiene que implementar este método si no admite parámetros, aunque esto es muy improbable.

stringify: devuelve cadena de texto
Formatea el nombre y los parámetros del modificador como cadena de texto y los devuelve. Puede simplemente usar un objeto Mail::SPF::Mod como cadena para obtener el mismo efecto; consulte "SOBRECARGA".
process: lanza Mail::SPF::Result, Mail::SPF::Result::Error, Mail::SPF::Exception
Abstracto. Procesa el modificador. Lo que eso significa depende de la implementación real en las subclases. Consulte "TIPOS DE MODIFICADOR" a continuación.

Este método es abstracto y debe ser implementado por subclases de Mail::SPF::Mod.

TIPOS DE MODIFICADOR

Hay diferentes tipos básicos de modificadores, que se describen a continuación. Todos ellos son proporcionados por el módulo Mail::SPF::Mod.

Modificadores globales - Mail::SPF::GlobalMod

SPFv1 (RFC 4408) solo conoce modificadores "globales". Un modificador global puede aparecer en cualquier parte de un registro SPF, pero solo una vez. Durante la evaluación del registro, los modificadores globales se procesan después de que se haya evaluado el último mecanismo y se haya determinado un resultado SPF.

El siguiente método de clase adicional es proporcionado por Mail::SPF::GlobalMod:

precedence: devuelve real
Abstracto. Devuelve un número real entre 0 y 1 que denota la precedencia del tipo del modificador global. Los modificadores globales presentes en un registro SPF se procesan en el orden de sus valores de precedencia, siendo 0 "el primero".

Este método es abstracto y debe ser implementado por subclases de Mail::SPF::GlobalMod.

El siguiente método de instancia específico es proporcionado por Mail::SPF::GlobalMod:

process($server, $request, $result): lanza Mail::SPF::Result
Abstracto. Procesa el modificador. Lo que eso significa depende de la implementación real en las subclases. Toma tanto un objeto Mail::SPF::Server como un objeto Mail::SPF::Request. Como los modificadores globales generalmente se procesan después de que ya se ha determinado un resultado SPF, también toma el objeto Mail::SPF::Result actual. Si el modificador desea modificar el resultado SPF, puede lanzar un objeto Mail::SPF::Result diferente.

Este método es abstracto y debe ser implementado por subclases de Mail::SPF::GlobalMod.

Modificadores posicionales - Mail::SPF::PositionalMod

Sender ID (RFC 4406) introduce el concepto de modificadores "posicionales". Según RFC 4406, un modificador posicional debe seguir a un mecanismo y se aplica a ese, y solo a ese, mecanismo. Sin embargo, dado que esta definición no es muy útil, y dado que aún no se han definido modificadores posicionales basados en ella, Mail::SPF se desvía de RFC 4406 de la siguiente manera:

Un modificador posicional puede aparecer en cualquier lugar de un registro SPF, y es stateful, es decir, se aplica a todos los mecanismos y modificadores que le siguen. Los modificadores posicionales son generalmente múltiples, es decir, pueden aparecer cualquier número de veces en todo el registro. Durante la evaluación del registro, los modificadores posicionales se procesan en el momento exacto en que el evaluador los encuentra. En consecuencia, todos los modificadores posicionales se procesan antes de determinar un resultado SPF.

El siguiente método de instancia específico es proporcionado por Mail::SPF::PositionalMod:

process($server, $request): lanza Mail::SPF::Result::Error, Mail::SPF::Exception
Abstracto. Procesa el modificador. Lo que eso significa depende de la implementación real en las subclases. Toma tanto un objeto Mail::SPF::Server como un objeto Mail::SPF::Request. Como los modificadores globales generalmente se procesan antes de que se determine un resultado SPF, no hay ningún objeto de resultado disponible para el modificador. El modificador (al menos en este momento) no puede modificar directamente el resultado SPF final, sin embargo, puede lanzar una excepción para señalar una condición de error.

Este método es abstracto y debe ser implementado por subclases de Mail::SPF::PositionalMod.

NOMBRE

Mail::SPF::Mod

VERSIÓN

Mail::SPF::Mod 3.20250505-2

DESCRIPCIÓN

Mail::SPF::Mod es un módulo Perl que permite realizar comprobaciones de SPF (Service Provider Filtering) en registros de correo. Este módulo proporciona modificadores que se pueden aplicar a registros de SPF para realizar comprobaciones de forma estándar. Los modificadores se pueden usar de forma similar a otros módulos de SPF, pero con algunas diferencias específicas. Por ejemplo, los modificadores pueden tener valores que se pueden procesar o no, dependiendo de la configuración del registro.

TIPOS DE MODIFICADORES

Los modificadores de SPF se pueden aplicar a un registro de SPF para realizar comprobaciones de forma estándar. Algunos modificadores se pueden usar de forma similar a otros módulos de SPF, pero con algunas diferencias específicas. Por ejemplo, los modificadores pueden tener valores que se pueden procesar o no, dependiendo de la configuración del registro.

SOBRECARGA

Si un objeto Mail::SPF::Mod se usa como una cadena, se utiliza el método "stringify" para convertir el objeto en una cadena.
