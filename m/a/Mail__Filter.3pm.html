NOMBRE

Mail::Filter - filtrar correo a través de múltiples subrutinas

SINOPSIS

use Mail::Filter;

my $filtro = Mail::Filter->new( \&filtro1, \&filtro2 );

my $mail   = Mail::Internet->new( [<>] );
my $mail   = $filtro->filter($mail);
my $carpeta = Mail::Folder->new( .... );
my $filtro->filter($carpeta);

DESCRIPCIÓN

"Mail::Filter" proporciona una interfaz para filtrar correos electrónicos a través de múltiples subrutinas.

"Mail::Filter" filtra el correo llamando a cada subrutina de filtro en orden. Cada subrutina de filtro es llamada con dos argumentos, el primero es el objeto filtro y el segundo es el objeto de correo o carpeta que se está filtrando.

El resultado de cada subrutina de filtro se pasa a la siguiente subrutina de filtro como objeto de correo. Si una subrutina de filtro devuelve undef, entonces "Mail::Filter" se abortará y devolverá inmediatamente.

La función devuelve el resultado de la última subrutina en operar sobre el objeto de correo.

MÉTODOS

Constructores

Mail::Filter->new(@filtros)
Crea un nuevo objeto "Mail::Filter" con las subrutinas de filtro dadas. Cada filtro puede ser una referencia de código o el nombre de un método a llamar en el objeto <Mail::Filter>.

Accesorios

$obj->add(@filtros)
Añade los @filtros dados al final de la lista de filtros.

Procesamiento

$obj->filter($mail|$carpeta)
Si el primer argumento es un objeto Mail::Internet, este objeto pasará por la lista de filtros. Si el primer argumento es un objeto Mail::Folder, cada mensaje se pasará por la lista de filtros en orden.
$obj->folder()
Mientras el método filter() es llamado con un objeto Mail::Folder, estas subrutinas de filtro pueden llamar a este método para obtener el objeto de carpeta que se está procesando.
$obj->msgnum()
Si el método filter() es llamado con un objeto Mail::Folder, las subrutinas de filtro pueden llamar a este método para obtener el número de mensaje del mensaje que se está procesando.
