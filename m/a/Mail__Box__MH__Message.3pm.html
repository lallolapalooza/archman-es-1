NOMBRE

Mail::Box::MH::Message - un mensaje en una carpeta MH

HERENCIA

Mail::Box::MH::Message
  es Mail::Box::Dir::Message
  es Mail::Box::Message
  es Mail::Message
  es Mail::Reporter

SINOPSIS

my $folder = new Mail::Box::MH ...
my $message = $folder->message(10);

DESCRIPCIÓN

Un "Mail::Box::MH::Message" representa un mensaje en una carpeta Mail::Box::MH. Cada mensaje se almacena en un archivo separado, como en todos los tipos de carpetas Mail::Box::Dir.

El archivo .mh_sequences

Típicamente, el archivo que contiene las etiquetas se llama ".mh_sequences". Los mensajes MH se numeran a partir de 1. Como ejemplo de contenido para ".mh_sequences":

cur: 93
unseen: 32 35-56 67-80

Para generalizar las etiquetas en los mensajes, dos se tratan especialmente:

  • cur

    El "cur" especifica el número del mensaje donde el usuario dejó de leer correo de esta carpeta en el último acceso. Internamente en estos módulos se refiere como la etiqueta "current".

  • unseen

    Con "unseen" se lista qué mensaje nunca fue leído. Esto debe ser un error en el diseño de MH: debe ser una fuente de confusión. La gente nunca debería usar etiquetas con una negación en el nombre:

    if($seen)           if(!$unseen)    #yuk!
if(!$seen)          if($unseen)
unless($seen)       unless($unseen) #yuk!

    Así que: la etiqueta "unseen" se traduce a "seen" para uso interno.

DIAGNÓSTICOS

Error: No se puede convertir un objeto de clase $class en un objeto de clase $class
Lanzado por coerce()
Error: No se puede crear un parser para $filename.
Por alguna razón (el mensaje anterior ya te lo ha dicho) no ha sido posible crear un parser de mensajes para el nombre de archivo especificado. Lanzado por parser()
Error: No se puede incluir el origen de reenvío como $include.
Alternativa desconocida para el reenvío (incluir). Las opciones válidas son "NO", "INLINE", "ATTACH" y "ENCAPSULATE". Lanzado por forward()
Error: No se puede incluir el origen de respuesta como $include.
Alternativa desconocida para la opción "include" de reply(). Las opciones válidas son "NO", "INLINE" y "ATTACH". Lanzado por reply()
Error: No se puede escribir el mensaje a $filename: $!
Cuando un mensaje modificado o nuevo se escribe en disco, primero se escribe en un archivo temporal en el directorio de la carpeta. Por alguna razón, es imposible crear este archivo. Lanzado por create()
Error: Fallo al mover $new a $filename: $!
Cuando un mensaje modificado o nuevo se escribe en disco, primero se escribe en un archivo temporal en el directorio de la carpeta. Luego, el nuevo archivo se mueve para reemplazar el archivo existente. Aparentemente, esto último falla. Lanzado por create()
Error: El método bounce requiere To, Cc, o Bcc
El método bounce() del mensaje reenvía un mensaje recibido a otra persona sin modificaciones; debes especificar su nuevo destino. Si tienes la urgencia de no especificar ningún destino, probablemente estés buscando reply(). Cuando desees modificar el contenido, usa forward(). Lanzado por bounce()
