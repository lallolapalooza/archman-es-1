NOMBRE

Mail::SpamAssassin::Plugin::OLEVBMacro - escanea documentos de Office en busca de evidencia de Macros OLE u otros exploits

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::OLEVBMacro
ifplugin Mail::SpamAssassin::Plugin::OLEVBMacro
  body     OLEMACRO eval:check_olemacro()
  describe OLEMACRO Archivo adjunto tiene una Macro de Office
  body     OLEOBJ eval:check_oleobject()
  describe OLEOBJ Archivo adjunto tiene un Objeto Ole
  body     OLERTF eval:check_olertfobject()
  describe OLERTF Archivo adjunto tiene un Objeto Rtf Ole
  body     OLEMACRO_MALICE eval:check_olemacro_malice()
  describe OLEMACRO_MALICE Potencialmente Macro maliciosa de Office
  body     OLEMACRO_ENCRYPTED eval:check_olemacro_encrypted()
  describe OLEMACRO_ENCRYPTED Tiene un documento de Office que está cifrado
  body     OLEMACRO_RENAME eval:check_olemacro_renamed()
  describe OLEMACRO_RENAME Tiene un documento de Office que ha sido renombrado
  body     OLEMACRO_ZIP_PW eval:check_olemacro_zip_password()
  describe OLEMACRO_ZIP_PW Tiene un documento de Office protegido con contraseña en un zip
  body     OLEMACRO_CSV eval:check_olemacro_csv()
  describe OLEMACRO_CSV Se detectó archivo csv malicioso que intenta ejecutar cmd.exe
  body     OLEMACRO_DOWNLOAD_EXE eval:check_olemacro_download_exe()
  describe OLEMACRO_DOWNLOAD_EXE Se detectó código malicioso dentro del documento de Office que intenta descargar un archivo .exe
  body     OLEMACRO_URI_TARGET eval:check_olemacro_redirect_uri()
  describe OLEMACRO_URI_TARGET Uri dentro de un documento de Office
  body     OLEMACRO_MHTML_TARGET eval:check_olemacro_mhtml_uri()
  describe OLEMACRO_MHTML_TARGET Uri mhtml explotable dentro de un documento de Office
endif

DESCRIPCIÓN

Este plugin detecta Macros OLE u otros exploits dentro de documentos de Office adjuntos a correos electrónicos. Puede detectar documentos dentro de archivos zip, así como documentos cifrados.

REQUISITO

Este plugin requiere los módulos Perl Archive::Zip e IO::String.

PREFERENCIAS DEL USUARIO

Las siguientes opciones se pueden usar tanto en el archivo de configuración a nivel de sitio ("local.cf") como en el archivo específico del usuario ("user_prefs") para personalizar cómo el módulo maneja los documentos adjuntos:

olemacro_num_mime (predeterminado: 5)
Configura el número máximo de partes MIME coincidentes (adjuntos) que el plugin escaneará.
olemacro_num_zip (predeterminado: 8)
Configura el número máximo de archivos coincidentes dentro del zip a escanear. Para deshabilitar el escaneo de zip, establece 0.
olemacro_zip_depth (predeterminado: 2)
Profundidad para recursar dentro de los archivos zip.
olemacro_extended_scan ( 0 | 1 ) (predeterminado: 0)
Escanea todos los archivos en busca de posibles archivos de office y/o macros, el parámetro "olemacro_skip_exts" aún se respetará. Este parámetro está desactivado por defecto, esta opción solo es necesaria para ejecutar la regla "eval:check_olemacro_renamed". Si se activa, considera ajustar los valores de "olemacro_num_mime" y "olemacro_num_zip" y prepárate para más carga de CPU.
olemacro_prefer_contentdisposition ( 0 | 1 ) (predeterminado: 1)
Elige si se prefiere el nombre de archivo de la cabecera content-disposition si se encuentra ambigüedad al intentar obtener el nombre del archivo.
olemacro_max_file (predeterminado: 1024000)
Limita la cantidad de bytes que el plugin decodificará y escaneará de los objetos MIME (adjuntos).
olemacro_exts (predeterminado: (?:doc|docx|dot|pot|ppa|pps|ppt|rtf|sldm|xl|xla|xls|xlsx|xlt|xltx|xslb)$)
Establece la expresión regular insensible a mayúsculas y minúsculas utilizada para configurar las extensiones que el plugin tiene como objetivo para el escaneo de macros.
olemacro_macro_exts (predeterminado: (?:docm|dotm|ppam|potm|ppst|ppsm|pptm|sldm|xlm|xlam|xlsb|xlsm|xltm|xps)$)
Establece la expresión regular insensible a mayúsculas y minúsculas utilizada para configurar las extensiones que el plugin trata como que contienen una macro.
olemacro_skip_exts (predeterminado: (?:dotx|potx|ppsx|pptx|sldx)$)
Establece la expresión regular insensible a mayúsculas y minúsculas utilizada para configurar las extensiones que el plugin debe omitir por completo, estos deberían ser solo archivos garantizados sin macros.
olemacro_skip_ctypes (predeterminado: ^(?:text\/))
Establece la expresión regular insensible a mayúsculas y minúsculas utilizada para configurar los tipos de contenido que el plugin debe omitir por completo, estos deberían ser solo tipos garantizados sin macros.
olemacro_zips (predeterminado: (?:zip)$)
Establece la expresión regular insensible a mayúsculas y minúsculas utilizada para configurar las extensiones que el plugin debe tener como objetivo como archivos zip, los archivos listados en las configuraciones anteriores también se prueban como zip.
olemacro_download_marker (predeterminado: (?:cmd(?:\.exe)? \/c ms\^h\^ta ht\^tps?:\/\^\/))
Establece la expresión regular insensible a mayúsculas y minúsculas para coincidir con el script utilizado para descargar archivos del documento de Office.
