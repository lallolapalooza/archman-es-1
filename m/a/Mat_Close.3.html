NOMBRE

Mat_Close — Cierra un archivo MAT de MATLAB abierto.

SINOPSIS

#include <matio.h>

int
Mat_Close(mat_t *matfp);

DESCRIPCIÓN

La función Mat_Close() cierra un archivo MAT de MATLAB abierto con Mat_Open() o creado con Mat_CreateVer().

VALORES DE RETORNO

La función devuelve 0 si tiene éxito. De lo contrario, se devuelve un valor de error.

EJEMPLOS

#include "matio.h"

int main(int argc, char **argv)
{
    mat_t *matfp;

    matfp = Mat_Open(argv[1], MAT_ACC_RDONLY);
    if ( NULL == matfp ) {
        fprintf(stderr, "Error abriendo el archivo MAT %s0, argv[1]);
        return EXIT_FAILURE;
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}

VER TAMBIÉN
