MAX(3) Manual de funciones de biblioteca MAX(3)

NOMBRE

MAX, MIN - máximo o mínimo de dos valores

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/param.h>
MAX(a, b);
MIN(a, b);

DESCRIPCIÓN

Estas macros devuelven el máximo o mínimo de a y b.

VALOR DE RETORNO

Estas macros devuelven el valor de uno de sus argumentos, posiblemente convertido a un tipo diferente (ver ERRORES).

ERRORES

Estas macros pueden generar la excepción de punto flotante "inválida" cuando alguno de los argumentos es NaN.

ESTÁNDARES

GNU, BSD.

NOTAS

Si alguno de los argumentos es de tipo punto flotante, puede preferir usar fmax(3) o fmin(3), que pueden manejar NaN.

Los argumentos pueden ser evaluados más de una vez, o ninguna.

Algunos sistemas UNIX podrían proporcionar estas macros en una cabecera diferente, o no proporcionarlas en absoluto.

ERRORES COMUNES (BUGS)

Debido a las conversiones aritméticas habituales, el resultado de estas macros puede ser muy diferente de cualquiera de los argumentos. Para evitar esto, asegúrese de que ambos argumentos tengan el mismo tipo.

EJEMPLOS

#include <stdio.h>
#include <stdlib.h>
#include <sys/param.h>
int
main(int argc, char *argv[])
{
    int a, b, x;
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <num> <num>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    a = atoi(argv[1]);
    b = atoi(argv[2]);
    x = MAX(a, b);
    printf("MAX(%d, %d) es %d\n", a, b, x);
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN

fmax(3), fmin(3)
