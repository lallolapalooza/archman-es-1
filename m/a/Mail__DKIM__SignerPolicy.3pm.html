NOMBRE

Mail::DKIM::SignerPolicy - determina los parámetros de firma para un mensaje

VERSIÓN

versión 1.20240923

DESCRIPCIÓN

Una "política de firma" (signer policy) es un objeto, clase o función utilizada por Mail::DKIM::Signer para determinar qué firmas añadir al mensaje actual. Para aprovechar las políticas de firma, crea tu propia clase Perl que extienda la clase Mail::DKIM::SignerPolicy. El único método que necesitas implementar es el método apply().

El método apply() toma como parámetro el objeto Mail::DKIM::Signer. Usando este objeto, puede determinar algunas propiedades del mensaje (p. ej., cuál es la dirección From: o Sender:). Luego establece varias propiedades del firmante según sea deseado. El método apply() debe devolver un valor distinto de cero si el mensaje debe ser firmado. Si se devuelve un valor falso, el mensaje se "omite" (es decir, no se firma).

Aquí tienes un ejemplo de una política que siempre devuelve los mismos valores:

package MySignerPolicy;
use base 'Mail::DKIM::SignerPolicy';
sub apply
{
    my $self = shift;
    my $signer = shift;

    $signer->algorithm('rsa-sha1');
    $signer->method('relaxed');
    $signer->domain('example.org');
    $signer->selector('selector1');
    $signer->key_file('private.key');

    return 1;
}

Para usar esta política, simplemente especifica el nombre de la clase como el parámetro Policy...

my $dkim = Mail::DKIM::Signer->new(
                Policy => 'MySignerPolicy',
           );

AVANZADO

También puedes hacer que la política construya la firma para que la use el Signer. Para hacer esto, llama al método add_signature() del signer desde dentro de tu callback apply(). Por ejemplo:

sub apply
{
    my $self = shift;
    my $signer = shift;

    $signer->add_signature(
            new Mail::DKIM::Signature(
                Algorithm => $signer->algorithm,
                Method => $signer->method,
                Headers => $signer->headers,
                Domain => $signer->domain,
                Selector => $signer->selector,
            ));
    return;
}

De nuevo, si no quieres ninguna firma, devuelve cero o undef. Si usas add_signature() para crear una firma, la firma predeterminada no se creará, incluso si devuelves un valor distinto de cero.
