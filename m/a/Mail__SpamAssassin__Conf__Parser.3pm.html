NOMBRE

Mail::SpamAssassin::Conf::Parser - analizar la configuración de SpamAssassin

SINOPSIS

(ver Mail::SpamAssassin)

DESCRIPCIÓN

Mail::SpamAssassin es un módulo para identificar spam mediante el análisis de texto y varias listas de bloqueo en tiempo real basadas en Internet.

Esta clase es utilizada internamente por SpamAssassin para analizar sus archivos de configuración. Por favor, consulte la documentación de "Mail::SpamAssassin" para las interfaces públicas.

ESTRUCTURA DE UN BLOQUE DE CONFIGURACIÓN

Esta es la estructura de un bloque de configuración. Cada uno es un hashref que puede contener las siguientes claves:

setting
el nombre de la configuración que modifica, p. ej., "required_score". esto también funciona como el valor predeterminado para 'command' (abajo). ESTO ES REQUERIDO.
command
La cadena de comando utilizada en el archivo de configuración para esta configuración. Opcional; se usará 'setting' para el comando si esto se omite.
aliases
Una [aryref] de otros alias para el mismo comando. opcional.
type
El tipo de esta configuración: 
- $CONF_TYPE_NOARGS: no debe tener ningún argumento, como "clear_headers"
- $CONF_TYPE_STRING: cadena de texto
- $CONF_TYPE_NUMERIC: valor numérico (flotante o entero)
- $CONF_TYPE_BOOL: booleano (0/no o 1/sí)
- $CONF_TYPE_TEMPLATE: plantilla, como "report"
- $CONF_TYPE_ADDRLIST: lista de direcciones de correo, como "welcomelist_from"
- $CONF_TYPE_HASH_KEY_VALUE: par clave/valor de hash, como "describe" o tflags
- $CONF_TYPE_STRINGLIST: lista de cadenas de texto, almacenada como un array
- $CONF_TYPE_IPADDRLIST: lista de direcciones IP, almacenada como un array de SA::NetSet
- $CONF_TYPE_DURATION: un intervalo de tiempo no negativo en segundos - un valor numérico
                     (flotante o entero), opcionalmente con sufijo de unidad de tiempo (s, m,
                     h, d, w), se implican segundos si falta la unidad

Si esto está configurado, y un bloque 'code' no existe ya, se asigna un bloque 'code' basado en el tipo.

Además, el conjunto de pruebas de SpamAssassin validará que las configuraciones no se 'filtran' entre usuarios.

Tenga en cuenta que las configuraciones de tipo $CONF_TYPE_HASH_KEY_VALUE requieren que el valor no esté vacío, de lo contrario, producirán un mensaje de advertencia.

code
Una subrutina para manejar la configuración. SE REQUIERE UNO DE code O type. Los argumentos que se pasan a la función son "($self, $key, $value, $line)", donde $key es la configuración (no el comando), $value es la cadena de valor y $line es la línea completa.

Hay dos valores de retorno especiales que la subrutina code puede devolver para indicar que hay un error en la configuración:

$Mail::SpamAssassin::Conf::MISSING_REQUIRED_VALUE -- esta configuración requiere que se establezca un valor, pero no se proporcionó ninguno.

$Mail::SpamAssassin::Conf::INVALID_VALUE -- esta configuración requiere un valor de un conjunto de valores 'válidos', pero el usuario proporcionó uno inválido.

$Mail::SpamAssassin::Conf::INVALID_HEADER_FIELD_NAME -- esta configuración requiere un nombre de campo de encabezado sintácticamente válido, pero el usuario proporcionó uno inválido.

Cualquier otro valor (incluido "undef") devuelto por la subrutina se considera que significa 'éxito'.

Es una buena práctica establecer un 'type', si es posible, que describa cómo se almacenan sus configuraciones en el objeto Conf; esto permite que el conjunto de pruebas de SpamAssassin valide que las configuraciones no se 'filtran' entre usuarios.

default
El valor predeterminado para la configuración. puede omitirse si el valor predeterminado es de un tipo no escalar, que debe establecerse en el constructor de Conf. nota para tipos de ruta: se recomienda usar "__userstate__" para los valores predeterminados, ya que permite a los usuarios del módulo Mail::SpamAssassin que establecen esa configuración, recibir los valores correctos.
is_priv
Establecer en 1 si esta configuración requiere 'allow_user_rules' cuando se ejecuta desde spamd.
is_admin
Establecer en 1 si esta configuración solo se puede establecer en la configuración a nivel de sistema cuando se ejecuta desde spamd. (Todos los programas locales ejecutados directamente por el usuario pueden usar todas las configuraciones.)
