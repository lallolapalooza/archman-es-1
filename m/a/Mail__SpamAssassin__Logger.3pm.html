NOMBRE

Mail::SpamAssassin::Logger - Módulo de registro de SpamAssassin

SINOPSIS

use Mail::SpamAssassin::Logger;
$SIG{__WARN__} = sub {
  log_message("warn", $_[0]);
};
$SIG{__DIE__} = sub {
  log_message("error", $_[0])  if !$^S;
};

MÉTODOS

add_facilities(facilities)
Habilita el registro de depuración para instalaciones específicas. Cada instalación es el área del código a depurar. Las instalaciones se pueden especificar como una referencia a hash (se usan los nombres de las claves), una referencia a array, un array o una cadena escalar separada por comas. Los nombres de las instalaciones distinguen entre mayúsculas y minúsculas.

Si se lista "all", todas las instalaciones de depuración se habilitan implícitamente, excepto aquellas que se deshabilitan explícitamente. Un nombre de instalación puede ir precedido de "no" (sin distinguir mayúsculas y minúsculas), lo que lo deshabilita explícitamente, anulando "all". Por ejemplo: all,norules,noconfig,nodcc. Cuando los nombres de las instalaciones se dan como una lista ordenada (array o escalar, no hash), la última entrada se aplica, por ejemplo, 'nodcc,dcc,dcc,noddc' es equivalente a 'nodcc'. Tenga en cuenta que actualmente ningún nombre de instalación comienza con "no", se recomienda mantener esta práctica con los nombres de instalaciones recién agregados para facilitar las cosas.

Los mensajes informativos de mayor prioridad que son adecuados para registrarse en circunstancias normales están disponibles con un área de "info". Algunos mensajes muy detallados requieren que la instalación se habilite específicamente (ver "would_log" a continuación).

log_message($level, @message)
Registra un mensaje en un nivel específico. Los niveles se especifican como cadenas: "warn", "error", "info" y "dbg". El primer elemento del mensaje debe ir precedido por un nombre de instalación seguido directamente de dos puntos.
dbg("instalación: mensaje")
Esto se utiliza para todos los mensajes de depuración de baja prioridad.
info("instalación: mensaje")
Esto se utiliza para mensajes informativos que indican una condición normal pero significativa. Esto debe llamarse con poca frecuencia. Estos mensajes generalmente se registran cuando SpamAssassin se ejecuta como un demonio.
add(method => 'syslog', socket => $socket, facility => $facility, escape => $escape)
"socket" es el tipo de syslog ("unix" o "inet"). "facility" es la instalación de syslog (típicamente "mail").

Si el opcional "escape" es verdadero, todos los caracteres no ASCII se escapan para una salida segura: las barras invertidas cambian a \\ y los caracteres no ASCII a \x{XX} o \x{XXXX} (Unicode). Si no se define, se utiliza la limpieza estilo pre-4.0 ( tr/\x09\x20\x00-\x1f/_/s ).

El valor de escape puede ser anulado con la variable de entorno "SA_LOGGER_ESCAPE".

add(method => 'file', filename => $file, escape => $escape)
"filename" es el nombre del archivo de registro. "escape" funciona como se describe arriba.
add(method => 'stderr', escape => $escape)
No se necesitan opciones para el registro en stderr, simplemente no cierre stderr primero. "escape" funciona como se describe arriba.
remove(method)
Elimina un método de registro. Solo el nombre del método debe pasarse como escalar.
would_log($level, $facility)
Devuelve falso si un mensaje en el nivel dado y con la instalación dada no se registraría. Devuelve 1 si un mensaje en un nivel y una instalación dados se registraría normalmente. Devuelve 2 si la instalación se habilitó específicamente.

El argumento de instalación es opcional.

close_log()
Cierra todos los registros.
