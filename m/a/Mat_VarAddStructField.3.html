MAT_VARADDSTRUCTFIELD(3) Manual de funciones de la biblioteca MAT_VARADDSTRUCTFIELD(3)

NOMBRE

Mat_VarAddStructField — Añade un campo a un array de estructuras.

SINOPSIS

#include <matio.h>

int
Mat_VarAddStructField(matvar_t *matvar, const char *fieldname);

DESCRIPCIÓN

La función Mat_VarAddStructField() añade un nombre de campo a la variable de estructura matvar.

VALORES DE RETORNO

Se devuelve 0 en caso de éxito.
