NOMBRE

Mail::Message::Body::String - cuerpo de una Mail::Message almacenado como cadena única

INHERITANCIA

Mail::Message::Body::String
  es un Mail::Message::Body
  es un Mail::Reporter

SINOPSIS

Ver Mail::Message::Body

DESCRIPCIÓN

El cuerpo (contenido) de un mensaje puede almacenarse de varias formas. En esta documentación encontrarás la descripción de funcionalidades adicionales que tienes cuando un mensaje se almacena como una sola variable escalar.

Almacenar todo el mensaje en una cadena es solo una elección inteligente cuando el contenido es pequeño o codificado. Aunque se almacene como una variable escalar, aún puedes tratar el cuerpo como si el datos esté almacenado en líneas o en un archivo externo, pero esto será más lento.

Mail::Message::Body::String(3pm)

NAME

Mail::Message::Body::String - create a message body from a string

INHERITANCE

Extends Mail::Message::Body.

Part of the Mail-Message distribution.

This class handles the body of a mail message that is represented as a single string, or is stored in a file. The string is used as the source for the body.

SYNOPSIS

  use Mail::Message::Body::String;

  my $body=Mail::Message::Body::String->new($string);
  # or
  my $body=Mail::Message::Body::String->new(<<'END_MESSAGE', EOL => "\n");
    From: sender
    To:   recipient
    Subject: test

    This is the message body.
  END_MESSAGE

  # or
  my $body=Mail::Message::Body::String->new($filename);

  print $body->string();

DESCRIPTION

The Mail::Message::Body::String class represents the body of an email message, where the content is stored as a string or read from a file. It inherits most of its functionality from Mail::Message::Body and provides specific methods for handling string-based content.

OVERLOADED

A reference to a Mail::Message::Body::String object is overloaded as a string to return the content of the body.

$obj->AUTOLOAD()
Overloaded to return the string content of the body.

Warning: Charset $name is not known
The encoding or decoding of a message body encounters a character set which is not understood by Perl's Encode module. Cast by encode()
Warning: Content-Transfer-Encoding `$encoding' requires explicit charset, defaulted to utf-8
Cast by encode()
Warning: No decoder defined for transfer encoding $name.
The data (message body) is encoded in a way which is not currently understood, therefore no decoding (or recoding) can take place. Cast by encode()
Warning: No encoder defined for transfer encoding $name.
The data (message body) has been decoded, but the required encoding is unknown. The decoded data is returned. Cast by encode()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
