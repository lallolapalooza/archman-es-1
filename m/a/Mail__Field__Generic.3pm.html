NOMBRE

Mail::Field::Generic - implementación para campos inespecíficos

HERENCIA

Mail::Field::Generic
  es un Mail::Field

SINOPSIS

use Mail::Field;
my $field = Mail::Field->new('Subject', 'algun texto de asunto');
my $field = Mail::Field->new(subject => 'algun texto de asunto');

DESCRIPCIÓN

Una implementación genérica para campos de encabezado sin implementación propia. Esto está bien para campos como "Subject", "X-Mailer", etc., donde el campo solo contiene una cadena de ninguna importancia/formato particular.

Extiende "DESCRIPCIÓN" en Mail::Field.

DIAGNÓSTICO

Error: Subrutina indefinida <método> llamada

Los objetos Mail::Field utilizan la carga automática para compilar nueva funcionalidad. Aparentemente, el método llamado no está implementado para la clase específica del objeto de campo.
