NOMBRE

Mail::Message::Construct::Bounce - rebotar un Mail::Message

SINOPSIS

$message->bounce(To => 'tú')->send;

DESCRIPCIÓN

La funcionalidad compleja sobre objetos Mail::Message se implementa en diferentes archivos que se cargan automáticamente. Este archivo implementa la funcionalidad relacionada con el rebote de mensajes a otros destinos.

¡Advertencia!: Rebotar mensajes era una práctica muy común en el pasado, pero no se lleva bien con la protección anti-spam SPF. A menos que rebotes mensajes que se originan dentro de tu propia infraestructura, los filtros de spam de los receptores pueden rechazar el mensaje. La solución es implementar ARC... que la suite MailBox no ha intentado (todavía).

MÉTODOS

Construyendo un mensaje

$obj->bounce( [<$rg_object|%options>] )
El programa que llama a este método se considera un paso intermedio en el proceso de entrega del mensaje; por lo tanto, deja un grupo de campos de encabezado reenviados como rastro.

Cuando se recibe un mensaje, el Agente de Transferencia de Correo (MTA) añade un campo "Received" al encabezado. Como %options, puedes especificar líneas que se añaden al grupo reenviado de ese campo recibido. "Resent-*" se antepone automáticamente a los nombres de campo, a menos que ya estén presentes.

También puedes especificar un objeto Mail::Message::Head::ResentGroup (RG) instanciado. Consulta Mail::Message::Head::ResentGroup::new() para ver las opciones disponibles. Esto es necesario si quieres añadir un nuevo grupo reenviado: crea también una nueva línea "Received" en el encabezado.

Si planeas modificar el cuerpo de un mensaje rebotado, ¡no lo hagas! Los mensajes rebotados tienen el mismo message-id que el mensaje original y, por lo tanto, deberían tener el mismo contenido (los message-ids son universalmente únicos). Si aun así insistes, usa Mail::Message::body().

» ejemplo:

my $bounce = $folder->message(3)->bounce(To => 'tú', Bcc => 'todos');
$bounce->send;
$outbox->addMessage($bounce);
my $rg     = Mail::Message::Head::ResentGroup->new(To => 'tú',
   Received => 'from ... by ...');
$msg->bounce($rg)->send;

DIAGNÓSTICOS

Error: El método bounce requiere To, Cc o Bcc
El método bounce() del mensaje reenvía un mensaje recibido a otra persona sin modificaciones; debes especificar su nuevo destino. Si tienes la necesidad de no especificar ningún destino, probablemente estés buscando reply(). Cuando desees modificar el contenido, usa forward(). Lanzado por bounce()
