NOMBRE

Mail::SpamAssassin::Pyzor::Digest::StripHtml - Módulo Pyzor para eliminar HTML

SINOPSIS

mi $stripped = Mail::SpamAssassin::Pyzor::Digest::StripHtml::strip($html);

DESCRIPCIÓN

Este módulo intenta duplicar la lógica de eliminación de HTML de pyzor.

PRECISIÓN

Esta biblioteca no puede lograr una paridad del 100%, error por error, con pyzor porque para hacerlo requeriría duplicar la propia biblioteca de análisis de HTML de Python. Dado que la salida de esa biblioteca ha cambiado con el tiempo, y esos cambios a su vez afectan a pyzor, es literalmente imposible llegar a una única implementación de reescritura totalmente compatible.

Dicho esto, todas las divergencias conocidas entre pyzor y esta biblioteca implican HTML inválido como entrada.

Por favor, abra informes de errores para cualquier divergencia que identifique, particularmente si la entrada es HTML válido.

FUNCIONES

$despojado = eliminar( $HTML )

Dadle algo de HTML y os devolverá el texto despojado.

En **general**, la eliminación consiste en eliminar etiquetas, así como elementos "<script>" y "<style>"; sin embargo, también elimina entidades HTML.

Esto intenta arduamente duplicar el comportamiento de pyzor con HTML inválido.
