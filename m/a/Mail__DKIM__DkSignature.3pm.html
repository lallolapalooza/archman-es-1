Mail__DKIM__DkSignature(3pm)

Paquete: perl-mail-dkim

Licencias: PerlArtistic, GPL

Mail::DKIM::DkSignature(3) Documentación de Contribución de Usuarios de Perl Mail::DKIM::DkSignature(3)

NOMBRE

Mail::DKIM::DkSignature - representa una cabecera DomainKeys-Signature

VERSIÓN

versión 1.20240923

CONSTRUCTORES

new()

Crea una nueva firma DomainKey a partir de parámetros

my $signature = Mail::DKIM::DkSignature->new(
                    [ Algorithm => 'rsa-sha1', ]
                    [ Signature => $base64, ]
                    [ Method => 'simple', ]
                    [ Domain => 'example.org', ]
                    [ Headers => 'from:subject:date:message-id', ]
                    [ Query => 'dns', ]
                    [ Selector => 'alpha', ]
                    [ Key => $private_key, ]
                );

parse()

Crea una nueva firma a partir de una cabecera DomainKey-Signature

my $sig = Mail::DKIM::DkSignature->parse(
                'DomainKey-Signature: a=rsa-sha1; b=yluiJ7+0=; c=nofws'
          );

Construye una firma analizando el contenido de la cabecera DomainKey-Signature proporcionada. No es necesario incluir el nombre de la cabecera (es decir, "DomainKey-Signature:") pero se recomienda, de modo que el nombre de la cabecera pueda conservarse y devolverse de la misma manera en "as_string()".

Nota: La entrada a este constructor tiene el mismo formato que la salida del método as_string.

MÉTODOS

as_string()

Convierte la cabecera de firma como una cadena.

print $signature->as_string . "\n";

salida

DomainKey-Signature: a=rsa-sha1; b=yluiJ7+0=; c=nofws

Como se muestra en el ejemplo, el método as_string puede usarse para generar la DomainKey-Signature que se antepone a un mensaje firmado.

algorithm()

Obtiene o establece el campo del algoritmo (a=)

El algoritmo utilizado para generar la firma. Por defecto es "rsa-sha1", un hash SHA-1 firmado con RSA.

canonicalization()

Obtiene o establece el campo de canonicalización (c=).

$signature->canonicalization('nofws');
$signature->canonicalization('simple');
$method = $signature->canonicalization;

Canonicalización del mensaje (el valor predeterminado es "simple"). Esto informa al verificador del tipo de canonicalización utilizado para preparar el mensaje para la firma.

domain()

Obtiene o establece el campo del dominio (d=).

my $d = $signature->domain;          # obtiene el valor del dominio
$signature->domain('example.org');   # establece el valor del dominio

El dominio de la entidad firmante, tal como se especifica en la firma. Este es el dominio que se consultará para obtener la clave pública.

headerlist()

Obtiene o establece el campo de campos de cabecera firmados (h=).

$signature->headerlist('a:b:c');
my $headerlist = $signature->headerlist;
my @headers = $signature->headerlist;

Campos de cabecera firmados. Una lista separada por dos puntos de nombres de campos de cabecera que identifican los campos de cabecera presentados al algoritmo de firma.

En contexto escalar, la lista de nombres de campos de cabecera se devolverá como una sola cadena, con los nombres unidos por dos puntos. En contexto de lista, los nombres de campos de cabecera se devolverán como una lista.

identity()

Obtiene la identidad de la firma.

my $i = $signature->identity;

En las firmas DomainKey, la identidad de la firma es la primera dirección encontrada en la cabecera Sender o en la cabecera From. Este campo es poblado por el Verificador al procesar una firma DomainKey.

identity_source()

Determina qué cabecera tuvo la identidad.

my $source = $signature->identity_source;

Si se está verificando el mensaje, este método le indicará qué cabecera del mensaje se utilizó para determinar la identidad de la firma. Los valores posibles son "header.sender" y "header.from".

protocol()

Obtiene o establece el campo de métodos de consulta (q=).

Una lista separada por dos puntos de métodos de consulta utilizados para recuperar la clave pública (el valor predeterminado es "dns").

selector()

Obtiene o establece el campo selector (s=).

El selector subdivide el espacio de nombres para la etiqueta "d=" (dominio).

signature()

Obtiene o establece el campo de datos de firma (b=).

Los datos de la firma. Los espacios en blanco se eliminan automáticamente del valor devuelto.
