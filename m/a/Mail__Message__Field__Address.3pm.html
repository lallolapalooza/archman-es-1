NOMBRE

Mail::Message::Field::Address - Una dirección de correo electrónico

HERENCIA

Mail::Message::Field::Address
  es un Mail::Identity
  es un User::Identity::Item

SINOPSIS

my $addr = Mail::Message::Field::Address->new(...);
my $ui   = User::Identity->new(...);
my $addr = Mail::Message::Field::Address->coerce($ui);
my $mi   = Mail::Identity->new(...);
my $addr = Mail::Message::Field::Address->coerce($mi);
print $addr->address;
print $addr->fullName;   # posiblemente unicode!
print $addr->domain;

DESCRIPCIÓN

Muchos campos de encabezado pueden contener direcciones de correo electrónico. Cada dirección de correo electrónico puede ser representada por un objeto de esta clase. Estos objetos manejarán la interpretación y la codificación/decodificación de juegos de caracteres por usted.

Extiende "DESCRIPCIÓN" en Mail::Identity.

SOBRECARGADO

sobrecarga: "" conversion a cadena
Cuando el objeto se utiliza en contexto de cadena, devolverá la representación codificada de la dirección de correo electrónico, al igual que lo hace string().
sobrecarga: booleano verdadero/falso
El objeto utilizado como booleano siempre devolverá "verdadero"
sobrecarga: cmp comparación de cadenas
Dos objetos de dirección son iguales cuando sus direcciones de correo electrónico son iguales.

MÉTODOS

Extiende "MÉTODOS" en Mail::Identity.

Constructores

Extiende "Constructores" en Mail::Identity.

$obj->coerce( <CADENA|$objeto>, %opciones )
Intenta forzar (coerce) el $objeto a una "Mail::Message::Field::Address". En caso de una "CADENA", se interpreta como una dirección de correo electrónico.

Las %opciones se pasan a la creación del objeto y anulan los valores encontrados en el $objeto. El resultado puede ser "undef" o un objeto recién creado. Si el $objeto ya es del tipo correcto, se devuelve sin modificar.

El $objeto puede ser actualmente un Mail::Address, un Mail::Identity, o un User::Identity. En caso de este último, se elige una de las direcciones del usuario al azar.

$clase->new( [$nombre], %opciones )
Heredado, ver "Constructores" en Mail::Identity
$obj->parse(CADENA)
Analiza la cadena para una dirección. Nunca se sabe si se especifican una o más direcciones en una línea (a menudo las aplicaciones están equivocadas), por lo tanto, la "CADENA" se analiza primero para obtener tantas direcciones como sea posible y luego se toma una al azar.

Accesores

$obj->encoding()
Codificación del juego de caracteres, como 'q' y 'b', a utilizar cuando se deban transmitir caracteres no ASCII.

Acceso al contenido

$obj->string()
Devuelve una dirección de correo electrónico conforme a RFC, que tendrá codificación de juego de caracteres si es necesario. Los objetos también están sobrecargados para llamar a este método en contexto de cadena.

» ejemplo:

print $address->string;
print $address;          # a través de sobrecarga

DIAGNÓSTICOS

Error: No se puede forzar (coerce) $tipo a Mail::Message::Field::Address
Cuando se especifican direcciones para ser incluidas en campos de encabezado, pueden ser forzadas a objetos Mail::Message::Field::Address primero. Lo que usted especifica no es aceptado como especificación de dirección. Esto puede ser un error interno. Lanzado por coerce()
Error: no se puede cargar el módulo de colección para $tipo ($clase): $err
O el $tipo especificado no existe, o el módulo llamado $clase devuelve errores de compilación. Si el tipo especificado en la advertencia no es el nombre de un paquete, usted especificó un apodo que no estaba definido. Quizás olvidó 'require' el paquete que define el apodo. Lanzado por addCollection()
Error: colección inválida $nombre.
La colección con $nombre no existe y no puede ser creada. Lanzado por add()
Error: este $objeto no es una colección.
Lanzado por addCollection()
