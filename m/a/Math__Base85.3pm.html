Math::Base85(3) Documentación de Perl contribuida por el usuario Math::Base85(3)

NOMBRE

Math::Base85 - Extensión de Perl para números base 85, como se referencia en la RFC 1924

SINOPSIS

use Math::Base85;
$bigint = from_base85($number);
$b85str = to_base85($bigint);

DESCRIPCIÓN

La RFC 1924 describe una representación compacta y de tamaño fijo de las direcciones IPv6 que utiliza un sistema numérico de base 85. Este módulo maneja algunos de los detalles más engorrosos.

Los números base 85 (de 0 a 84) son los siguientes:

0..9 A..Z a..z ! # $ % & ( ) * + - ; < = > ? @ ^ _ ` { | } ~

Por el momento, no hay mucho en este módulo. Pero debería ser suficiente para los propósitos de la RFC 1924.

Este módulo tiene una variable llamada $Math::Base85::base85_digits, que es una cadena que contiene los dígitos del alfabeto base 85 desde el más bajo (0) hasta el más alto (~), en ese orden.

Además, las siguientes dos funciones están definidas para uso general. (Serán exportadas bajo petición).

from_base85

Parámetros

Una cadena compuesta por dígitos base 85 válidos.

Retorna

Un objeto "Math::BigInt" que representa el número.

to_base85

Parámetros

Un objeto "Math::BigInt".

Retorna

Una cadena de dígitos base 85 que representa el número.
