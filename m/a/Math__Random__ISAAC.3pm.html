Math::Random::ISAAC(3) Documentación de Perl contribuida por el usuario Math::Random::ISAAC(3)

NOMBRE

Math::Random::ISAAC - Interfaz de Perl para el algoritmo ISAAC PRNG

VERSIÓN

versión 1.004

SINOPSIS

use Math::Random::ISAAC;
my $rng = Math::Random::ISAAC->new(@seeds);
for (0..30) {
  print 'Resultado: ' . $rng->irand() . "\n";
}

DESCRIPCIÓN

Al igual que otros algoritmos de Generación de Números Pseudoaleatorios (PRNG) como el Mersenne Twister (ver Math::Random::MT), este algoritmo está diseñado para tomar información de semilla y producir resultados aparentemente aleatorios como salida.

Sin embargo, ISAAC (Indirection, Shift, Accumulate, Add, and Count) tiene objetivos diferentes a estos algoritmos de uso común. En particular, es realmente rápido: en promedio, requiere solo 18.75 ciclos de máquina para generar un valor de 32 bits. Esto lo hace adecuado para aplicaciones donde se necesita producir una cantidad significativa de datos aleatorios rápidamente, como la solución mediante el método de Monte Carlo o para juegos.

Los resultados están uniformemente distribuidos, sin sesgos e impredecibles a menos que se conozca la semilla. El algoritmo fue publicado por Bob Jenkins a finales de los 90 y, a pesar de los mejores esfuerzos de muchos investigadores de seguridad, hasta la fecha no se han encontrado ataques factibles.

ADVERTENCIA DE USO

El autor no proporcionó un método para proporcionar los datos de semilla iniciales. En su sitio web, Bob Jenkins escribe:

Sembrar un generador de números aleatorios es esencialmente el mismo problema que
encriptar la semilla con un cifrado de bloque.

En el mismo espíritu, por defecto, este módulo no siembra el algoritmo en absoluto: simplemente rellena el estado con ceros, si no se proporciona ninguna semilla. La idea es recordar a los usuarios que seleccionar buenos datos de semilla para su propósito es importante, y que el módulo lo establezca convenientemente a algo como "localtime" detrás de escena perjudica a los usuarios a largo plazo, ya que no comprenden las limitaciones de hacerlo.

El tipo de semilla que podría querer usar depende completamente del propósito de usar este algoritmo en su programa en primer lugar. Aquí hay algunos métodos de siembra posibles:

1 Math::TrulyRandom
El módulo Math::TrulyRandom proporciona una forma de obtener datos verdaderamente aleatorios utilizando interrupciones de temporización. Esta es probablemente una de las mejores maneras de sembrar el algoritmo.
2 /dev/random
Usar el dispositivo aleatorio del sistema es, en principio, la mejor idea, ya que recopila entropía de varias fuentes, incluyendo tiempos de interrupción, otras interrupciones de dispositivos, etc. Sin embargo, no es portable a nada más que plataformas tipo Unix, y podría no producir buenos datos en algunos sistemas.
3 localtime()
Esto funciona para cosas básicas como simulaciones, pero da como resultado una salida no tan aleatoria, especialmente si crea nuevas instancias rápidamente (ya que las semillas serían las mismas dentro de la resolución por segundo).
4 Time::HiRes
En teoría, usar Time::HiRes es lo mismo que la opción (2), pero obtienes una resolución de tiempo mayor, por lo que es menos probable que tengas la misma semilla dos veces. Ten en cuenta que necesitas transformar la salida en un entero de alguna manera, quizás tomando los bits menos significativos o usando una función hash. Esto sería menos propenso a instancias duplicadas, pero aún así no es ideal.

MÉTODOS

new

Math::Random::ISAAC->new( @seeds )

Crea un objeto "Math::Random::ISAAC", basado en la versión optimizada en C/XS del algoritmo, Math::Random::ISAAC::XS, o recurre al módulo Pure Perl incluido, Math::Random::ISAAC::PP.

Código de ejemplo:

my $rng = Math::Random::ISAAC->new(time);

Este método devolverá un objeto apropiado de Math::Random::ISAAC o lanzará una excepción en caso de error.

rand

$rng->rand()

Devuelve un número de punto flotante de doble precisión aleatorio que está normalizado entre 0 y 1 (inclusive; es un intervalo cerrado).

Internamente, esto simplemente toma el entero sin signo uniformemente distribuido de "$rng->irand()" y lo divide por "2**32-1" (tamaño máximo del entero sin signo).

Código de ejemplo:

my $next = $rng->rand();

Este método devolverá un número de punto flotante de doble precisión o lanzará una excepción en caso de error.

irand

$rng->irand()

Devuelve el siguiente entero aleatorio sin signo de 32 bits. Devolverá un valor tal que: 0 <= x <= 2**32-1.

Código de ejemplo:

my $next = $rng->irand();

Este método devolverá un entero sin signo de 32 bits o lanzará una excepción en caso de error.

PROPÓSITO

La intención de este módulo es proporcionar una única interfaz simple a las dos implementaciones compatibles de este módulo, a saber, Math::Random::ISAAC::XS y Math::Random::ISAAC::PP.

Si, por alguna razón, necesita determinar qué versión del módulo está siendo incluida actualmente por "Math::Random::ISAAC", entonces:

print 'Tipo de backend: ', $Math::Random::ISAAC::DRIVER, "\n";

Para forzar el uso de uno u otro, simplemente cargue el módulo apropiado:

use Math::Random::ISAAC::XS;
my $rng = Math::Random::ISAAC::XS->new();
# o
use Math::Random::ISAAC::PP;
my $rng = Math::Random::ISAAC::PP->new();

VER TAMBIÉN

Math::Random::ISAAC::XS, la versión optimizada en C/XS de este módulo, que se utilizará automáticamente si está disponible.

http://burtleburtle.net/bob/rand/isaacafa.html, página de Bob Jenkins sobre ISAAC, que explica el algoritmo así como posibles ataques.

http://eprint.iacr.org/2006/438.pdf, un artículo titulado "On the pseudo-random generator ISAAC,", que afirma que hay muchas semillas que producirán resultados no uniformes. El autor, Jean-Philippe Aumasson, argumenta que ISAAC debería usar rotaciones (desplazamientos circulares) en lugar de desplazamientos normales para aumentar la difusión del estado, entre otras cosas.

http://eprint.iacr.org/2001/049.pdf, un artículo de Marina Pudovkina que discute ataques de texto plano al generador de flujo de claves ISAAC. Entre otras cosas, señala que la complejidad temporal es Tmet = 4.67*10^1240, por lo que sigue siendo un cifrado seguro para aplicaciones prácticas.

ADVERTENCIAS

  • No hay un método que permita volver a sembrar los algoritmos. Esto no es realmente necesario ya que uno puede simplemente llamar a "new" nuevamente con los nuevos datos de semilla periódicamente.

    Pero él también proporciona una solución simple:

    Como ISAAC está destinado a ser un cifrado seguro, si desea volver a sembrarlo,
una forma es usar algún otro cifrado para sembrar una versión inicial de ISAAC,
luego usar la salida de ISAAC como semilla para otras instancias de ISAAC siempre que
necesiten ser resiembradas.
  • No hay forma de clonar una instancia de PRNG. No estoy seguro de por qué esto podría ser necesario o útil. Registre un informe de error con una explicación de por qué y consideraré agregarlo a la próxima versión.
