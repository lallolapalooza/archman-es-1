NOMBRE

Mail::Sendmail - Mailer independiente de plataformas

SINOPSIS

use Mail::Sendmail;
%mail = ( To      => 'tú@allí.com',
          From    => 'yo@aquí.com',
          Message => "Este es un mensaje muy corto"
         );
sendmail(%mail) or die $Mail::Sendmail::error;
print "OK. El log dice:\n", $Mail::Sendmail::log;

DESCRIPCIÓN

Envío de correo electrónico de forma independiente de plataformas desde tu script Perl. Solo requiere Perl 5 y una conexión a Internet.

Mail::Sendmail toma un hash con el mensaje a enviar y lo envía a tu servidor de correo. Es intencionalmente muy fácil de configurar y usar. Ve también "CARACTERÍSTICAS" a continuación, y como siempre, lee esta documentación.

También hay una FAQ (ver "NOTAS").

INSTALACIÓN

Mejor
"perl -MCPAN -e "install Mail::Sendmail""
Tradicional
perl Makefile.PL
make
make test
make install
Manual
Coloca Sendmail.pm en la carpeta lib/perl de tu script Perl. 
(ej. c:\Perl\site\lib\Mail\
 o  /usr/lib/perl5/site_perl/Mail/
 o  lo que sea que esté en tu sistema.  
        Estarás listo cuando ejecutes C< perl -V >)
PPM de ActivePerl
Dependiendo de tu versión de PPM: 
ppm install --location=http://alma.ch/perl/ppm Mail-Sendmail

o

ppm install http://alma.ch/perl/ppm/Mail-Sendmail.ppd

Pero esto te impide ver otros archivos (Changes, Todo, test.pl, ...).

En la parte superior de Sendmail.pm, establece tu servidor SMTP por defecto, a menos que lo especifiques con cada mensaje o quieras usar el predeterminado (localhost).

Instala MIME::QuotedPrint. No es obligatorio, pero está recomendado.

CARACTERÍSTICAS

Detección automática de la hora, encabezado Date, codificación MIME quoted-printable (si está instalado MIME::QuotedPrint), todo lo cual puede ser sobrescrito.

Soporte para Bcc: y Cc:.

Permite nombres reales en los campos From:, To: y Cc:.

No envía un encabezado X-Mailer: (a menos que lo especifiques), y permite enviar cualquier encabezado que desees.

Configurable para reintentos y uso de servidores alternativos si el servidor de correo está fuera de servicio.

Reporte de errores en texto plano.

Soporte experimental para autenticación SMTP.

LIMITACIONES

Los encabezados no se codifican, incluso si tienen caracteres acentuados.

Como el mensaje completo está en memoria, no es adecuado para enviar archivos adjuntos grandes.

El servidor SMTP debe ser configurado manualmente en Sendmail.pm o en tu script, a menos que tengas un servidor de correo en localhost.

No funciona en OpenVMS, como me dijeron. No puedo probarlo.

CONFIGURACIÓN

Servidor SMTP predeterminado
Esta es probablemente la que quieres configurar. Se hace normalmente a través de $mailcfg{smtp}, que puedes editar en la parte superior del archivo Sendmail.pm. Esta es una referencia a una lista de servidores SMTP. También puedes establecerlo desde tu script:

"unshift @{$Mail::Sendmail::mailcfg{'smtp'}} , 'mi.servidor.correo';"

Alternativamente, puedes especificar el servidor en el hash %mail que envías desde tu script, lo que hará lo mismo:

"$mail{smtp} = 'mi.servidor.correo';"

Una futura versión (esperemos) intentará establecer valores predeterminados útiles para ti durante el Makefile.PL.

Otras configuraciones
Ver %mailcfg bajo "DETALLES" para otras opciones de configuración.

DETALLES

sendmail()

sendmail es el único elemento que se exporta al espacio de nombres por defecto.

"sendmail(%mail) || print "Error enviando correo: $Mail::Sendmail::error\n";"

Toma un hash con el mensaje completo, con claves para todos los encabezados y el cuerpo, así como para algunas opciones específicas.

Devuelve 1 en éxito o 0 en error, y sobrescribe $Mail::Sendmail::error y $Mail::Sendmail::log.

Las claves no distinguen entre mayúsculas y minúsculas.

El separador de dos puntos después de los encabezados no es necesario.

La parte del cuerpo se puede llamar 'Body', 'Message' o 'Text'.

El servidor SMTP se puede llamar 'Smtp' o 'Server'. Si la conexión a uno falla, se intentarán los otros en $mailcfg{smtp}.

Los siguientes encabezados se agregan a menos que los especifiques tú mismo:

Mime-Version: 1.0
Content-Type: 'text/plain; charset="iso-8859-1"'
Content-Transfer-Encoding: quoted-printable
o (si no está instalado MIME::QuotedPrint)
Content-Transfer-Encoding: 8bit
Date: [cadena devuelta por time_to_date()]

Si deseas usar un remitente de correo diferente del encabezado From: establece $mail{Sender} en tu hash %mail.

Los siguientes no se exportan por defecto, pero puedes acceder a ellos con su nombre completo, o solicitar su exportación en la línea `use` como en: "use Mail::Sendmail qw(sendmail $address_rx time_to_date);"

opciones de inyección en tu%mail hash

Las siguientes opciones se pueden establecer en tu%mail hash. Las claves correspondientes se eliminarán antes de enviar el correo.

$mail{smtp} o $mail{server}
El servidor SMTP a intentar primero. Se agregará
$mail{port}
Esta opción se eliminará. Para usar un puerto no estándar, establécelo en tu nombre de servidor:

$mail{server}='mi.smtp.server:2525' intentará conectar al puerto 2525 en el servidor my.smtp.server

$mail{auth}
Este debe ser una referencia a un hash con todas tus opciones de autenticación:

$mail{auth} = \%options; o $mail{auth} = {user="nombreusuario", password="contraseña", method="DIGEST-MD5", required="0"};

user
nombre de usuario
pass o password
contraseña
method
método opcional. Comparado (sin distinción de mayúsculas/minúsculas) con los métodos disponibles. Si está vacío, intentará todos los disponibles.
required
opcional. Por defecto es falso. Si se establece en verdadero, no se intentará la entrega si falla la autenticación. Si es falso o indefinido y la autenticación falla o no está disponible, se intentará la entrega sin autenticación.

(¿autenticación diferente para servidores diferentes?)

$Mail::Sendmail::error

Cuando no ejecutas con el flag -w, el módulo no envía errores a STDERR, pero los que se deben lamentar se guardan aquí. Debes revisar si dice algo.

$Mail::Sendmail::log

Un resumen que podrías escribir en un archivo de registro después de cada envío.

NAME

Mail::Sendmail - How to send mail from a Perl script

SYNOPSIS

  use Mail::Sendmail;
  %mail = (
      To      => 'Recipient Name <recipient@example.com>',
      From    => 'Sender Name <sender@example.com>',
      Subject => 'Test message',
      Message => "Hi!\nThis is a test message.\nBye!\n",
  );
  if (sendmail %mail) {
      print "Mail sent OK.\n";
  } else {
      print "Error sending mail: $Mail::Sendmail::error \n";
  }

DESCRIPTION

This module provides a simple interface to send e-mail from Perl scripts. It uses the standard SMTP protocol to send mail to any mail server. It should be able to send mail to any host on the internet.

It's a wrapper around Net::SMTP, so you'll need that module installed too. It adds some convenience features like automatic MIME encoding, retries, default settings etc.

INSTALLATION

To install this module, run the following commands:

  perl Makefile.PL
  make
  make install

Or if you are using PPM:

  ppm install Mail-Sendmail

You need to have Net::SMTP installed as well. It's available from CPAN.

FEATURES

  • Send mail to any SMTP server.
  • Automatic MIME encoding for attachments, HTML mail, accented characters.
  • Support for multiple SMTP servers (failover).
  • Retry mechanism for temporary connection failures.
  • Configurable sender address, subject, etc.
  • Plain text, HTML or MIME multipart messages.
  • Support for custom headers.
  • Support for SMTP authentication (LOGIN, PLAIN, CRAM-MD5, DIGEST-MD5).

LIMITATIONS

  • Does not support POP before SMTP authentication.
  • Does not support sending mail through a SOCKS proxy.

CONFIGURATION

Configuration can be done by editing the %mailcfg hash within the module itself (usually in Mail/Sendmail.pm) or by accessing it from your scripts.

For the latter, you should import it:

  use Mail::Sendmail qw(sendmail %mailcfg);

The keys are case-insensitive and are converted to lowercase.

$mailcfg{smtp}
A reference to an array of SMTP servers to try in order. Default: ['localhost'].
$mailcfg{port}
The default port to use if none is specified for a server. Default: 25.
$mailcfg{from}
The default sender address if none is provided in the mail hash. Default: undef.
$mailcfg{mime}
Set to 0 to disable automatic MIME encoding. Default: 1.
$mailcfg{retries}
Number of times to retry connecting to the same SMTP server. Default: 1.
$mailcfg{delay}
Seconds to wait between retries and before trying the next server. Default: 1.
$mailcfg{tz}
Time zone offset for date headers (e.g., '+0800'). Default: auto-detected.
$mailcfg{debug}
Set to a value greater than 0 to enable debugging output to STDERR. Default: 0.

DETAILS

$Mail::Sendmail::address_rx

A handy regex to recognize e-mail addresses.

A correct regex for valid e-mail addresses was written by one of the judges in the obfuscated Perl contest... :-) It is quite big. This one is an attempt to a reasonable compromise, and should accept all real-world internet style addresses. The domain part is required and comments or characters that would need to be quoted are not supported.

Example:
  $rx = $Mail::Sendmail::address_rx;
  if (/$rx/) {
    $address=$1;
    $user=$2;
    $domain=$3;
  }

%Mail::Sendmail::mailcfg

This hash contains installation-wide configuration options. You normally edit it once (if ever) in Sendmail.pm and forget about it, but you could also access it from your scripts. For readability, I'll assume you have imported it (with something like "use Mail::Sendmail qw(sendmail %mailcfg)").

The keys are not case-sensitive: they are all converted to lowercase before use. Writing "$mailcfg{Port} = 2525;" is OK: the default $mailcfg{port} (25) will be deleted and replaced with your new value of 2525.

$mailcfg{smtp}
"$mailcfg{smtp} = [qw(localhost my.other.mail.server)];"

This is a reference to a list of smtp servers, so if your main server is down, the module tries the next one. If one of your servers uses a special port, add it to the server name with a colon in front, to override the default port (like in my.special.server:2525).

Default: localhost.

$mailcfg{from}
"$mailcfg{from} = 'Mailing script me@mydomain.com';"

From address used if you don't supply one in your script. Should not be of type 'user@localhost' since that may not be valid on the recipient's host.

Default: undefined.

$mailcfg{mime}
"$mailcfg{mime} = 1;"

Set this to 0 if you don't want any automatic MIME encoding. You normally don't need this, the module should 'Do the right thing' anyway.

Default: 1;

$mailcfg{retries}
"$mailcfg{retries} = 1;"

How many times should the connection to the same SMTP server be retried in case of a failure.

Default: 1;

$mailcfg{delay}
"$mailcfg{delay} = 1;"

Number of seconds to wait between retries. This delay also happens before trying the next server in the list, if the retries for the current server have been exhausted. For CGI scripts, you want few retries and short delays to return with a results page before the http connection times out. For unattended scripts, you may want to use many retries and long delays to have a good chance of your mail being sent even with temporary failures on your network.

Default: 1 (second);

$mailcfg{tz}
"$mailcfg{tz} = '+0800';"

Normally, your time zone is set automatically, from the difference between time() and gmtime(). This allows you to override automatic detection in cases where your system is confused (such as some Win32 systems in zones which do not use daylight savings time: see Microsoft KB article Q148681)

Default: undefined (automatic detection at run-time).

$mailcfg{port}
"$mailcfg{port} = 25;"

Port used when none is specified in the server name.

Default: 25.

$mailcfg{debug}
"$mailcfg{debug} = 0;"

Prints stuff to STDERR. Current maximum is 6, which prints the whole SMTP session, except data exceeding 500 bytes.

Default: 0;

$Mail::Sendmail::VERSION

The package version number (you can not import this one)

Configuration variables from previous versions

The following global variables were used in version 0.74 for configuration. As from version 0.78_1, they are not supported anymore. Use the %mailcfg hash if you need to access the configuration from your scripts.

$Mail::Sendmail::default_smtp_server
$Mail::Sendmail::default_smtp_port
$Mail::Sendmail::default_sender
$Mail::Sendmail::TZ
$Mail::Sendmail::connect_retries
$Mail::Sendmail::retry_delay
$Mail::Sendmail::use_MIME

ANOTHER EXAMPLE

use Mail::Sendmail;
print "Testing Mail::Sendmail version $Mail::Sendmail::VERSION\n";
print "Default server: $Mail::Sendmail::mailcfg{smtp}->[0]\n";
print "Default sender: $Mail::Sendmail::mailcfg{from}\n";
%mail = (
    #To      => 'No to field this time, only Bcc and Cc',
    #From    => 'not needed, use default',
    Bcc     => 'Someone <him@there.com>, Someone else her@there.com',
    # only addresses are extracted from Bcc, real names disregarded
    Cc      => 'Yet someone else <xz@whatever.com>',
    # Cc will appear in the header. (Bcc will not)
    Subject => 'Test message',
    'X-Mailer' => "Mail::Sendmail version $Mail::Sendmail::VERSION",
);
$mail{Smtp} = 'special_server.for-this-message-only.domain.com';
$mail{'X-custom'} = 'My custom additional header';
$mail{'mESSaGE : '} = "The message key looks terrible, but works.";
# cheat on the date:
$mail{Date} = Mail::Sendmail::time_to_date( time() - 86400 );
if (sendmail %mail) { print "Mail sent OK.\n" }
else { print "Error sending mail: $Mail::Sendmail::error \n" }
print "\n\$Mail::Sendmail::log says:\n", $Mail::Sendmail::log;

Also see http://alma.ch/perl/Mail-Sendmail-FAQ.html for examples of HTML mail and sending attachments.

CHANGES

Main changes since version 0.79:

Experimental SMTP AUTH support (LOGIN PLAIN CRAM-MD5 DIGEST-MD5)

Fix bug where one refused RCPT TO: would abort everything

send EHLO, and parse response

Better handling of multi-line responses, and better error-messages

Non-conforming line-endings also normalized in headers

Now keeps the Sender header if it was used. Previous versions only used it for the MAIL FROM: command and deleted it.

See the Changes file for the full history. If you don't have it because you installed through PPM, you can also find the latest one on http://alma.ch/perl/scripts/Sendmail/Changes.

NOTES

MIME::QuotedPrint is used by default on every message if available. It allows reliable sending of accented characters, and also takes care of too long lines (which can happen in HTML mails). It is available in the MIME-Base64 package at http://www.perl.com/CPAN/modules/by-module/MIME/ or through PPM.

Look at http://alma.ch/perl/Mail-Sendmail-FAQ.html for additional info (CGI, examples of sending attachments, HTML mail etc...)
