Mail::Message::Dummy(3) Documentación de contribuciones de Perl Mail::Message::Dummy(3)

NOMBRE

Mensajes dummy para un módulo que mantenga listas ordenadas de mensajes

HEREDAD

Mail::Message::Dummy
  es un Mail::Message
  es un Mail::Reporter

SINOPSIS

DESCRIPCIÓN

Los mensajes dummy se utilizan por módulos que mantienen listas ordenadas de mensajes, a menudo basadas en el identificador del mensaje. Un buen ejemplo es Mail::Box::Thread::Manager, que detecta mensajes relacionados al escanear las cabeceras conocidas de otros mensajes. A menos que los mensajes referidos no se encuentren en el buzón, su lugar es ocupado por un mensaje dummy.

Cuando uses módulos que puedan crear dummies, debes usar isDummy() antes de acceder a la cabecera o cuerpo.

Extiende "DESCRIPCIÓN" en Mail::Message.

DIAGNÓSTICO

Error: No se puede forzar un objeto de clase $class en un objeto de clase $class
Lanzado por coerce()
Error: No se puede incluir fuente de reenvío como $include.
Alternativa desconocida para el reenvío (incluir). Las opciones válidas son "NO", "INLINE", "ATTACH", y "ENCAPSULATE". Lanzado por forward()
Error: No se puede incluir fuente de respuesta como $include.
Alternativa desconocida para la opción "include" de reply(). Las opciones válidas son "NO", "INLINE", y "ATTACH". Lanzado por reply()
Error: Se requiere Message-Id para un dummy.
Un mensaje dummy ocupa el lugar de un mensaje real. Cuando se crea un dummy, se debe conocer el id del mensaje cuyo lugar está ocupando. Lanzado por new()
Error: El método bounce requiere To, Cc, o Bcc
El método de mensaje bounce() reenvía un mensaje recibido a alguien más sin modificaciones; debes especificar su nueva destinación. Si tienes la tentación de no especificar ningún destino, probablemente estés buscando reply(). Cuando quieras modificar el contenido, usa forward(). Lanzado por bounce()
Error: El método forwardAttach requiere un preámbulo
Lanzado por forwardAttach()
Error: El método forwardEncapsulate requiere un preámbulo
Lanzado por forwardEncapsulate()
Error: No hay dirección para crear el reenvío.
Si se crea un mensaje reenviado, se debe especificar una dirección de destino. Lanzado por forward()
Error: No se encontró servidor de correo por defecto para enviar el mensaje.
El mecanismo send() del mensaje no tenía suficiente información para encontrar automáticamente un agente de transferencia de correo para enviar este mensaje. Especifica un servidor explícitamente usando las opciones "via". Lanzado por send()
Error: No hay regla de reconstrucción $name definida.
Lanzado por rebuild()
Error: Solo build() Mensajes de correo; aún no están en una carpeta
Es posible que desees construir un mensaje para ser almacenado en algún tipo de carpeta, pero necesitas hacerlo en dos pasos. Primero, crea un Mail::Message normal, y luego agrégalo a la carpeta. Durante este proceso de Mail::Box::addMessage(), el mensaje será coerce()-d al tipo de mensaje correcto, agregando información de almacenamiento y similares. Lanzado por build()
Error: El paquete $package no implementa $method.
Error fatal: el paquete específico (o una de sus superclases) no implementa este método donde debería. Este mensaje significa que otras clases relacionadas implementan este método, sin embargo, la clase en cuestión no lo hace. Probablemente deberías investigar esto y quizás informar al autor del paquete. Lanzado por notImplemented()
Error: No puedes obtener la cabecera/cuerpo de un mensaje dummy
Los mensajes dummy son marcadores de posición en los hilos de mensajes: el hilo detectó la existencia del mensaje, porque encontró el message-id en un campo Reply-To o References, sin embargo, aún no encontró la cabecera y el cuerpo del mensaje. Usa isDummy() para comprobar si el nodo del hilo devolvió un dummy o no. Lanzado por head()

Mail::Message::Dummy(3pm)

NAME

Mail::Message::Dummy - the message object when no other is found

INHERITANCE

Mail::Message::Dummy is an abstract class.

SYNOPSIS

use Mail::Box;
my $mbox = Mail::Box::Manager->new('File::Maildir');
my $folder = $mbox->folder('new') || die "Cannot open folder: $!";
my $msg = $folder->get(1);
print $msg->head('Subject');

DESCRIPTION

This class is used when no specific Mail::Message implementation is found or loaded. It represents an empty message.

METHODS

coerce($object)
This method creates a new Mail::Message::Dummy object.
head($name)
Returns undef for any header field.
body()
Returns undef.
new(%args)
Creates a new Mail::Message::Dummy object.

DETAILS

new($object)
The new method takes an argument that is some object that starts with some object
