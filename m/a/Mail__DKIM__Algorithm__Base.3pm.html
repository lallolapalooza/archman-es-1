NOMBRE

Mail::DKIM::Algorithm::Base - clase base para "algoritmos" de DKIM

VERSIÓN

versión 1.20240923

SINOPSIS

my $algorithm = new Mail::DKIM::Algorithm::rsa_sha1(
                    Signature => $dkim_signature
                );
# añadir cabeceras
$algorithm->add_header("Subject: esto es el asunto\015\012");
$algorithm->finish_header;
# añadir cuerpo
$algorithm->add_body("Este es el cuerpo.\015\012");
$algorithm->add_body("Otra línea del cuerpo.\015\012");
$algorithm->finish_body;
# ahora firmar o verificar...
# TODO...

CONSTRUCTOR

No deberías crear un objeto de esta clase directamente. En su lugar, usa una de las clases de implementación de algoritmos DKIM, como rsa_sha1:

my $algorithm = new Mail::DKIM::Algorithm::rsa_sha1(
                    Signature => $dkim_signature
                );

MÉTODOS

add_body() - introduce parte del cuerpo en el algoritmo/canonización

$algorithm->add_body("Este es el cuerpo.\015\012");
$algorithm->add_body("Otra línea del cuerpo.\015\012");

El cuerpo debe ser introducido una "línea" a la vez.

add_header() - introduce un campo de cabecera en el algoritmo/canonización

$algorithm->add_header("Subject: esto es el asunto\015\012");

La cabecera debe comenzar con el nombre del campo de cabecera y continuar a través de cualquier línea plegada (incluidas las secuencias <CRLF> incrustadas). Termina con el <CRLF> al final del campo de cabecera.

finish_body() - señala el fin del cuerpo del mensaje

$algorithm->finish_body

Llama a este método cuando todas las líneas del cuerpo hayan sido enviadas. Después de llamar a este método, usa sign() o verify() para obtener los resultados del algoritmo.

finish_header() - señala el fin del bloque de campos de cabecera

$algorithm->finish_header;

Llama a este método cuando todas las cabeceras hayan sido enviadas.

sign() - genera una firma usando una clave privada

$base64 = $algorithm->sign($private_key);

signature() - obtiene/establece la firma sobre la que trabaja este algoritmo

my $old_signature = $algorithm->signature;
$algorithm->signature($new_signature);

verify() - verifica una firma

$result = $algorithm->verify();

Debe llamarse después de finish_body().

El resultado es un valor verdadero/falso: verdadero indica que los datos de la firma son válidos, falso indica que son inválidos.

Para una firma inválida, los detalles pueden obtenerse de $algorithm->{verification_details} o $@.
