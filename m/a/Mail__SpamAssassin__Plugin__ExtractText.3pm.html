Mail::SpamAssassin::Plugin::ExtractText(3) Documentación de Perl contribuida por el usuario Mail::SpamAssassin::Plugin::ExtractText(3)

NOMBRE

ExtractText - extrae texto de documentos.

SINOPSIS

loadplugin Mail::SpamAssassin::Plugin::ExtractText

ifplugin Mail::SpamAssassin::Plugin::ExtractText

extracttext_external  pdftotext  /usr/bin/pdftotext -nopgbrk -layout -enc UTF-8 {} -
extracttext_use       pdftotext  .pdf application/pdf
# http://docx2txt.sourceforge.net
extracttext_external  docx2txt   /usr/bin/docx2txt {} -
extracttext_use       docx2txt   .docx application/docx
extracttext_external  antiword   /usr/bin/antiword -t -w 0 -m UTF-8.txt {}
extracttext_use       antiword   .doc application/(?:vnd\.?)?ms-?word.*
extracttext_external  unrtf      /usr/bin/unrtf --nopict {}
extracttext_use       unrtf      .doc .rtf application/rtf text/rtf
extracttext_external  odt2txt    /usr/bin/odt2txt --encoding=UTF-8 {}
extracttext_use       odt2txt    .odt .ott application/.*?opendocument.*text
extracttext_use       odt2txt    .sdw .stw application/(?:x-)?soffice application/(?:x-)?starwriter
extracttext_external  tesseract  {OMP_THREAD_LIMIT=1} /usr/bin/tesseract -c page_separator= {} -
extracttext_use       tesseract  .jpg .png .bmp .tif .tiff image/(?:jpeg|png|x-ms-bmp|tiff)
# Decodificador de códigos QR
extracttext_external  zbar       /usr/bin/zbarimg -q -D {}
extracttext_use       zbar       .jpg .png .pdf image/(?:jpeg|png) application/pdf
add_header   all          ExtractText-Flags _EXTRACTTEXTFLAGS_
header       PDF_NO_TEXT  X-ExtractText-Flags =~ /\bpdftotext_NoText\b/
describe     PDF_NO_TEXT  PDF sin texto
score        PDF_NO_TEXT  0.001
header       DOC_NO_TEXT  X-ExtractText-Flags =~ /\b(?:antiword|openxml|unrtf|odt2txt)_NoText\b/
describe     DOC_NO_TEXT  Documento sin texto
score        DOC_NO_TEXT  0.001
header       EXTRACTTEXT  exists:X-ExtractText-Flags
describe     EXTRACTTEXT  Plugin extracttext procesó el correo
score        EXTRACTTEXT  0.001

endif

DESCRIPCIÓN

Este módulo utiliza herramientas externas para extraer texto de las partes del mensaje, y luego establece el texto como la parte renderizada. La herramienta externa debe generar texto plano, no HTML u otro resultado no textual.

Cómo extraer texto es completamente configurable y se basa en el tipo de parte MIME y el nombre del archivo.

CONFIGURACIÓN

Se ignorarán todas las líneas de configuración en los archivos user_prefs.

extracttext_maxparts (predeterminado: 10)
Configura el número máximo de partes MIME a analizar, un valor de 0 significa que se analizarán todas las partes MIME.
extracttext_timeout (predeterminado: 5 10)
Configura el tiempo de espera en segundos de las comprobaciones de herramientas externas, por archivo adjunto.

El segundo argumento especifica el tiempo total máximo para todas las comprobaciones.

Herramientas

extracttext_use
Especifica qué herramienta usar para qué partes del mensaje.

La sintaxis general es

extracttext_use "nombre" "especificadores"

nombre
el nombre interno de una herramienta.
especificadores
Extensión de archivo y expresiones regulares para nombres de archivo y tipos MIME. Las expresiones regulares están ancladas al principio y al final.

Ejemplos

extracttext_use  antiword  .doc application/(?:vnd\.?)?ms-?word.*
extracttext_use  openxml   .docx .dotx .dotm application/(?:vnd\.?)openxml.*?word.*
extracttext_use  openxml   .doc .dot application/(?:vnd\.?)?ms-?word.*
extracttext_use  unrtf     .doc .rtf application/rtf text/rtf
extracttext_external
Define una herramienta externa. La herramienta debe leer un documento de la entrada estándar o de un archivo y escribir texto en la salida estándar.

La palabra clave especial "{}" se sustituirá en tiempo de ejecución con el nombre del archivo temporal a escanear por la herramienta externa.

Las variables de entorno se pueden definir con "{CLAVE=VALOR}", estas cadenas se eliminarán de la línea de comandos.

Es obligatorio que la línea de comandos utilizada genere el resultado directamente en STDOUT.

La sintaxis general es

extracttext_external "nombre" "comando" "parámetros"

nombre
El nombre interno de esta herramienta.
comando
La ruta completa al comando externo a ejecutar.
parámetros
Parámetros para el comando externo. El nombre del archivo temporal que contiene el documento se agregará automáticamente como el último parámetro.

Ejemplos

extracttext_external  antiword  /usr/bin/antiword -t -w 0 -m UTF-8.txt {} -
extracttext_external  unrtf     /usr/bin/unrtf --nopict {}
extracttext_external  odt2txt   /usr/bin/odt2txt --encoding=UTF-8 {}

Metadatos

El plugin agrega algunos pseudo-encabezados al mensaje. Estos encabezados son vistos por el sistema bayesiano y se pueden usar en reglas normales de SpamAssassin.

Los encabezados también están disponibles como etiquetas de plantilla como se indica a continuación.

Ejemplo

Los encabezados ficticios de ejemplo a continuación se basan en un mensaje que contiene lo siguiente:

1 Un PDF perfectamente normal.
2 Un documento OpenXML con un documento de Word dentro. Ningún documento de Office contiene texto.

Encabezados

X-ExtractText-Chars
Etiqueta: _EXTRACTTEXTCHARS_

Contiene un recuento de caracteres que fueron extraídos.

X-ExtractText-Chars: 10970

X-ExtractText-Words
Etiqueta: _EXTRACTTEXTWORDS_

Contiene un recuento de "palabras" que fueron extraídas.

X-ExtractText-Chars: 1599

X-ExtractText-Tools
Etiqueta: _EXTRACTTEXTTOOLS_

Contiene cadenas de herramientas utilizadas para la extracción.

X-ExtractText-Tools: pdftotext openxml_antiword

X-ExtractText-Types
Etiqueta: _EXTRACTTEXTTYPES_

Contiene cadenas de tipos MIME para partes encontradas durante la extracción.

X-ExtractText-Types: application/pdf; application/vnd.openxmlformats-officedocument.wordprocessingml.document, application/ms-word

X-ExtractText-Extensions
Etiqueta: _EXTRACTTEXTEXTENSIONS_

Contiene cadenas de extensiones de archivo canónicas para partes encontradas durante la extracción.

X-ExtractText-Extensions: pdf docx

X-ExtractText-Flags
Etiqueta: _EXTRACTTEXTFLAGS_

Contiene notas del plugin.

X-ExtractText-Flags: openxml_NoText

X-ExtractText-Uris
Etiqueta: _EXTRACTTEXTURIS_

Contiene URIs extraídas del plugin.

X-ExtractText-Uris: https://spamassassin.apache.org

Reglas

Ejemplo:

header    PDF_NO_TEXT  X-ExtractText-Flags =~ /\bpdftotext_Notext\b/
describe  PDF_NO_TEXT  PDF sin texto
