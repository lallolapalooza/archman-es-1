Mail::DKIM::Verifier(3) Documentación de Perl contribuida por el usuario Mail::DKIM::Verifier(3)

NOMBRE

Mail::DKIM::Verifier - verifica un mensaje firmado con DKIM

VERSIÓN

versión 1.20240923

SINOPSIS

use Mail::DKIM::Verifier;
# crear un objeto verificador
my $dkim = Mail::DKIM::Verifier->new();
# leer un correo desde un manejador de archivo
$dkim->load(*STDIN);
# o leer un correo y pasarlo al verificador, incrementalmente
while (<STDIN>)
{
    # eliminar terminadores de línea locales
    chomp;
    s/\015$//;
    # usar terminadores de línea SMTP
    $dkim->PRINT("$_\015\012");
}
$dkim->CLOSE;
# ¿cuál es el resultado de la verificación?
my $result = $dkim->result;
# puede haber múltiples firmas, ¿cuál es el resultado por firma?
foreach my $signature ($dkim->signatures)
{
    print 'identidad de la firma: ' . $signature->identity . "\n";
    print 'detalle del resultado de la verificación: ' . $signature->result_detail . "\n";
}
# el supuesto autor del correo puede especificar cómo manejar el correo
foreach my $policy ($dkim->policies)
{
    die 'mensaje fraudulento' if ($policy->apply($dkim) eq 'reject');
}

DESCRIPCIÓN

El objeto verificador permite escanear un mensaje de correo electrónico en busca de firmas DKIM y DomainKeys y verificar esas firmas. El verificador rastrea el estado del mensaje a medida que se lee en memoria. Cuando el mensaje se ha leído por completo, se verifican las firmas y se puede acceder a los resultados de la verificación.

Para usar el verificador, primero cree el objeto verificador. Luego comience a "alimentarlo" con el mensaje de correo electrónico que se va a verificar. Cuando se hayan leído todas las _cabeceras_, el verificador:

1. comprueba si se encontraron firmas DomainKeys/DKIM
2. consulta las claves públicas necesarias para verificar las firmas
3. configura los objetos de algoritmos y canonización apropiados
4. canoniza las cabeceras y calcula el hash de las cabeceras

Luego, cuando el _cuerpo_ del mensaje se haya alimentado por completo al verificador, se calcula el hash del cuerpo y se verifican las firmas.

Los resultados de la verificación se pueden comprobar con "result()" o "signatures()".

Los mensajes que no se verifican pueden comprobarse con la política de firma publicada del remitente supuesto con "policies()" y "apply()" en Mail::DKIM::Policy.

CONSTRUCTOR

new()

Construye un verificador orientado a objetos.

my $dkim = Mail::DKIM::Verifier->new();
my $dkim = Mail::DKIM::Verifier->new(%options);

Las únicas opciones admitidas en este momento son:

Debug_Canonicalization
si se especifica, el mensaje canonizado para la primera firma se escribe en la cadena o manejador de archivo referenciado.
Strict
Si es verdadero, rechaza hashes sha1 y claves de firma de menos de 1024 bits.

MÉTODOS

PRINT()

Alimenta parte del mensaje al verificador.

$dkim->PRINT("una línea del mensaje\015\012");
$dkim->PRINT('más de');
$dkim->PRINT(" el mensaje\015\012adiós\015\012");

Alimenta el contenido del mensaje que se está verificando al verificador. La API está diseñada de esta manera para que el mensaje completo NO necesite ser cargado en memoria a la vez.

Tenga en cuenta que aunque el método PRINT() espera que utilice caracteres de terminación de línea estilo SMTP, NO debe usar la técnica de relleno de puntos estilo SMTP descrita en RFC 2821 sección 4.5.2. Tampoco debe usar una secuencia <CR><LF>.<CR><LF> para terminar el mensaje.

CLOSE()

Llame a esto cuando termine de alimentar el mensaje.

$dkim->CLOSE;

Este método finaliza el proceso de canonización, calcula un hash y verifica la firma.

fetch_author_domain_policies()

Recupera registros ADSP de DNS.

my @policies = $dkim->fetch_author_domain_policies;
foreach my $policy (@policies)
{
    my $policy_result = $policy->apply($dkim);
}

Este método recuperará todas las "author-domain-signing-practices" aplicables publicadas en DNS para este mensaje. Las políticas de autor están indexadas a la(s) dirección(es) de correo electrónico en la cabecera From:, es decir, el autor declarado del mensaje.

Este método devuelve una *lista* de registros de política, ya que se permite cero o varias direcciones de correo electrónico en la cabecera From:.

El resultado del método apply() es uno de: "accept", "reject", "neutral".

Ver también: "policies()".

fetch_author_policy()

Recupera una política de firma de DNS.

my $policy = $dkim->fetch_author_policy;
my $policy_result = $policy->apply($dkim);

Este método recupera el registro DKIM Sender Signing Practices tal como se describe en Internet Draft draft-ietf-dkim-ssp-00-01dc. Este Internet Draft ahora está obsoleto; este método solo se mantiene por motivos de compatibilidad hacia atrás.

Utilice el método "policies()" en su lugar.

fetch_sender_policy()

Recupera una política de firma de DNS.

my $policy = $dkim->fetch_sender_policy;
my $policy_result = $policy->apply($dkim);

La política del "remitente" es la política de firma del remitente tal como se describe en la especificación DomainKeys, ahora disponible en RFC4870 (histórico). Lo llamo política de "remitente" porque está indexada a la dirección de correo electrónico en la cabecera Sender:, o en la cabecera From: si no hay cabecera Sender. Esta es la persona que el mensaje reclama como el "transmisor" del mensaje (no necesariamente el autor).

Si el correo que se está verificando no tiene una cabecera From o Sender de la cual obtener una dirección de correo electrónico (lo que viola los estándares de correo electrónico), este método "morirá".

El resultado del método apply() es uno de: "accept", "reject", "neutral".

Ver también: "policies()".

load()

Carga el mensaje completo desde un manejador de archivo.

$dkim->load($file_handle);

Lee un mensaje completo del manejador de archivo designado, alimentándolo al verificador. El mensaje debe usar terminadores de línea <CRLF> (igual que el protocolo SMTP).

message_originator()

Accede a la cabecera "From".

my $address = $dkim->message_originator;

Devuelve la "dirección del originador" encontrada en el mensaje, como un objeto Mail::Address. Típicamente es el (primer) nombre y dirección de correo electrónico encontrados en la cabecera From:. Si no hay cabecera From:, se devuelve un objeto Mail::Address vacío.

Para obtener solo la parte de la dirección de correo electrónico, haga:

my $email = $dkim->message_originator->address;

Ver también "message_sender()".

message_sender()

Accede a la cabecera "From" o "Sender".

my $address = $dkim->message_sender;

Devuelve el "remitente" encontrado en el mensaje, como un objeto Mail::Address. Típicamente es el (primer) nombre y dirección de correo electrónico encontrados en la cabecera Sender:. Si no hay cabecera Sender:, es el primer nombre y dirección de correo electrónico en la cabecera From:. Si no hay ninguna de las cabeceras presentes, se devuelve un objeto Mail::Address vacío.

Para obtener solo la parte de la dirección de correo electrónico, haga:

my $email = $dkim->message_sender->address;

El "remitente" es el buzón del agente responsable de la transmisión real del mensaje. Por ejemplo, si un secretario enviara un mensaje para otra persona, el "remitente" sería el secretario y el "originador" sería el autor real.

policies()

Recupera las políticas de firma aplicables de DNS.

my @policies = $dkim->policies;
foreach my $policy (@policies)
{
    $policy_result = $policy->apply($dkim);
    # $policy_result es uno de "accept", "reject", "neutral"
}

PRINT()

Alimenta parte del mensaje al verificador.

$dkim->PRINT("una línea del mensaje\015\012");
$dkim->PRINT('más de');
$dkim->PRINT(" el mensaje\015\012adiós\015\012");

Alimenta el contenido del mensaje que se está verificando al verificador. La API está diseñada de esta manera para que el mensaje completo NO necesite ser cargado en memoria a la vez.

Tenga en cuenta que aunque el método PRINT() espera que utilice caracteres de terminación de línea estilo SMTP, NO debe usar la técnica de relleno de puntos estilo SMTP descrita en RFC 2821 sección 4.5.2. Tampoco debe usar una secuencia <CR><LF>.<CR><LF> para terminar el mensaje.

result()

Devuelve el resultado de la verificación de DKIM.

my $result = $dkim->result;

Devuelve el resultado de la verificación de la firma DKIM. Los valores posibles son:

  • pass: La firma DKIM es válida y el mensaje no ha sido modificado desde que fue firmado.

  • fail: La firma DKIM no es válida o el mensaje ha sido modificado.

  • none: No se encontró ninguna firma DKIM.

  • neutral: La verificación no pudo determinar si la firma era válida (por ejemplo, la clave pública no se pudo recuperar).

  • temperror: Se produjo un error temporal durante la verificación (por ejemplo, un problema de DNS).

  • permerror: Se produjo un error permanente durante la verificación (por ejemplo, la firma DKIM tiene un formato incorrecto).

Si hay varias firmas, este método devuelve el resultado de la primera firma válida encontrada.

signatures()

Devuelve una lista de objetos de firma DKIM.

my @signatures = $dkim->signatures;

Cada objeto de firma en la lista devuelta tiene los siguientes métodos:

identity
El dominio o dirección de correo electrónico asociado con la firma.
result_detail
El resultado detallado de la verificación de esta firma específica. Puede ser uno de los valores devueltos por "result()", o una cadena que describe el error específico.
header_hash_valid
Verdadero si el hash de la cabecera es válido, falso en caso contrario.
body_hash_valid
Verdadero si el hash del cuerpo es válido, falso en caso contrario.
Mail::DKIM::Verifier(3pm)

NAME

Mail::DKIM::Verifier - verify DKIM signatures

VERSION

1.20240923

SYNOPSIS

    use Mail::DKIM::Verifier;
    my $verifier = Mail::DKIM::Verifier->new($message);
    
    # get the result of the verification
    my $result = $verifier->result;
    
    # get more details
    my $detail = $verifier->result_detail;
    
    # get the signature object (if any)
    my $signature = $verifier->signature;
    
    # get all signature objects (if any)
    my @signatures = $verifier->signatures;

DESCRIPTION

This class is used to verify a DKIM signature which has been applied to an email message.

You may need to have the Net::DNS module installed if you intend to verify signatures which have not been cached.

The DKIM verification process involves fetching the public key of the signing domain from DNS, and using it to verify the signature.

This module has been tested against the DKIM test vectors.

verify()

This method is called implicitly by the constructor.

This method searches for and returns any signing policies that would apply to this message. Signing policies are selected based on the domain that the message *claims* to be from. So, for example, if a message claims to be from security@bank, and forwarded by trusted@listserv, when in reality the message came from foe@evilcorp, this method would check for signing policies for security@bank and trusted@listserv. The signing policies might tell whether foe@evilcorp (the real sender) is allowed to send mail claiming to be from your bank or your listserv.

I say "might tell", because in reality this is still really hard to specify with any accuracy. In addition, most senders do not publish useful policies.

CONSTRUCTOR

new($message)

The constructor takes the message which is to be verified as its argument. The message may be passed either as a scalar string (containing the raw message), or as an array reference (containing the raw message line-by-line).

The constructor will automatically call the verify() method, and perform the verification. The result of the verification is stored internally, and may be accessed by subsequent calls to the result() and result_detail() methods.

METHODS

result()

Access the result of the verification.

my $result = $dkim->result;

Gives the result of the verification. The following values are possible:

pass
Returned if a valid DKIM-Signature header was found, and the signature contains a correct value for the message.
fail
Returned if a valid DKIM-Signature header was found, but the signature does not contain a correct value for the message.
invalid
Returned if a DKIM-Signature could not be checked because of a problem in the signature itself or the public key record. I.e. the signature could not be processed.
temperror
Returned if a DKIM-Signature could not be checked due to some error which is likely transient in nature, such as a temporary inability to retrieve a public key. A later attempt may produce a better result.
none
Returned if no DKIM-Signature headers (valid or invalid) were found.

In case of multiple signatures, the "best" result will be returned. Best is defined as "pass", followed by "fail", "invalid", and "none". To examine the results of individual signatures, use the "signatures()" method to retrieve the signature objects. See "result()" in Mail::DKIM::Signature.

result_detail()

Access the result, plus details if available.

my $detail = $dkim->result_detail;

The detail is constructed by taking the result (e.g. "pass", "fail", "invalid" or "none") and appending any details provided by the verification process in parenthesis.

The following are possible results from the result_detail() method:

pass
fail (bad RSA signature)
fail (OpenSSL error: ...)
fail (message has been altered)
fail (body has been altered)
invalid (bad identity)
invalid (invalid domain in d tag)
invalid (missing q tag)
invalid (missing d tag)
invalid (missing s tag)
invalid (unsupported version 0.1)
invalid (unsupported algorithm ...)
invalid (unsupported canonicalization ...)
invalid (unsupported query protocol ...)
invalid (signature is expired)
invalid (public key: not available)
invalid (public key: unknown query type ...)
invalid (public key: syntax error)
invalid (public key: unsupported version)
invalid (public key: unsupported key type)
invalid (public key: missing p= tag)
invalid (public key: invalid data)
invalid (public key: does not support email)
invalid (public key: does not support hash algorithm 'sha1')
invalid (public key: does not support signing subdomains)
invalid (public key: revoked)
invalid (public key: granularity mismatch)
invalid (public key: granularity is empty)
invalid (public key: OpenSSL error: ...)
none

signature()

Access the message's DKIM signature.

my $sig = $dkim->signature;

Accesses the signature found and verified in this message. The returned object is of type Mail::DKIM::Signature.

In case of multiple signatures, the signature with the "best" result will be returned. Best is defined as "pass", followed by "fail", "invalid", and "none".

signatures()

Access all of this message's signatures.

my @all_signatures = $dkim->signatures;

Use $signature->result or $signature->result_detail to access the verification results of each signature.
