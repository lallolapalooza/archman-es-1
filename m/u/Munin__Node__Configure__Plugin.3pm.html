Munin::Node::Configure::Plugin(3pm) Documentación Perl contribuida por el usuario Munin::Node::Configure::Plugin(3pm)

NOMBRE

Munin::Node::Configure::Plugin - Clase que representa un plugin, junto con sus servicios instalados y sugeridos.

SINOPSIS

my $plugin = Munin::Node::Configure::Plugin->new();

MÉTODOS

new(%args)
Constructor.

Los argumentos requeridos son 'name' y 'path', que deben ser el nombre base y la ruta completa del plugin, respectivamente.

is_wildcard()
Devuelve verdadero si el plugin es un comodín. En el caso de los plugins SNMP, solo los plugins de doble comodín devolverán verdadero (es decir, 'snmp__memory' devolvería falso, pero 'snmp__if_' devolvería verdadero).
is_snmp()
Devuelve verdadero si el plugin es un plugin SNMP.
in_family(@families)
Devuelve verdadero si la familia del plugin está en @families, falso en caso contrario.
is_installed()
Devuelve 'yes' si uno o más enlaces a este plugin existen en el directorio de servicios, 'no' en caso contrario.
suggestion_string()
Devuelve una cadena que detalla si la autoconfiguración considera que el plugin debe instalarse o no. La cadena también puede informar el motivo por el cual el plugin se negó a instalarse, o la lista de sugerencias que proporcionó, si esta información está disponible.
installed_services_string()
Devuelve una cadena que detalla qué comodines están instalados para este plugin.
services_to_add()
services_to_remove()
Devuelve una lista de nombres de servicios que deben agregarse o eliminarse para este plugin.
add_instance($name)
Asocia un enlace del directorio de servicios con este plugin.
add_suggestions(@suggestions)
Agrega @suggestions a la lista de comodines sugeridos para este plugin. No se validan.
read_magic_markers()
Establece la familia y las capacidades a partir de los marcadores mágicos incrustados en el ejecutable del plugin, según se especifica en http://munin-monitoring.org/wiki/ConcisePlugins#Magicmarkers
parse_autoconf_response(@response)
Analiza y valida la respuesta de autoconfiguración del plugin, en el formato especificado por http://munin-monitoring.org/wiki/ConcisePlugins#autoconf

Una entrada inválida provocará que se registre un error para el plugin.

parse_suggest_response(@response)
Valida las sugerencias del plugin.

Las sugerencias inválidas provocarán que se registre un error para el plugin.

parse_snmpconf_response(@response)
Analiza y valida la respuesta de snmpconf del plugin, en el formato especificado por http://munin-monitoring.org/wiki/ConcisePlugins#suggest

Una entrada inválida o inconsistente provocará que se registre un error para el plugin.

log_error($message)
Registra un error para su posterior recuperación. El error también se mostrará si la salida de depuración está habilitada.
