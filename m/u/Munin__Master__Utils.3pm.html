Munin::Master::Utils(3pm) Documentación de Perl contribuida por el usuario Munin::Master::Utils(3pm)

NOMBRE

Munin::Master::Utils - Exporta un montón de funciones de utilidad.

SINOPSIS

use Munin::Master::Utils;

SUBRUTINAS

munin_category_status
Obtiene el estado actual de una categoría.

Parámetros:
- $hash: Una referencia al hash nodo cuyos hijos se revisarán
- $limits: Una referencia al nodo raíz del árbol de límites
- $category: La categoría a revisar
- $check_draw: [opcional] Ignorar campos no dibujados

Retorna:
- Éxito: El estado del campo
- Fallo: undef

munin_readconfig_base
Lee el archivo de configuración, incluye archivos del directorio e inicializa valores por defecto importantes que son opcionales.

Parámetros:
- $file: Nombre del archivo munin.conf. Si se omite, se usa el nombre de archivo por defecto.

Retorna:
- Éxito: El hash $config (también almacenado en caché en el módulo)

munin_copy_node
Copia un nodo hash.

Parámetros:
- $from: Nodo hash a copiar
- $to: Dónde copiarlo

Retorna:
- Éxito: $to
- Fallo: undef

munin_copy_node_toloc
Copia un nodo hash en una ubicación.

Parámetros:
- $from: Nodo hash a copiar
- $to: Dónde copiarlo
- $loc: Ruta al nodo bajo $to

Retorna:
- Éxito: $to
- Fallo: undef

munin_createlock
munin_delete
munin_draw_field
Comprueba si un campo será visible en el gráfico o no.

Parámetros:
- $hash: Una referencia al nodo hash para el campo

Retorna:
- Éxito: Booleano; verdadero si el campo se graficará, falso si no
- Fallo: undef

munin_field_status
Obtiene el estado actual de un campo.

Parámetros:
- $hash: Una referencia al nodo hash del campo
- $limits: Una referencia al nodo raíz del árbol de límites
- $check_draw: [opcional] Ignorar campos no dibujados

Retorna:
- Éxito: El estado del campo
- Fallo: undef

munin_find_field
Busca en un hash para encontrar nodos hash con $field definido.

Parámetros:
- $hash: Un hash de referencia para buscar
- $field: El nombre del campo a buscar, o una expresión regular
- $avoid: [opcional] Dejar de recorrer más abajo si se encuentra este campo

Retorna:
- Éxito: Una referencia a un array de los nodos hash que contienen $field.
- Fallo: undef

munin_get
Obtiene una variable.

Parámetros:
- $hash: Referencia al nodo hash
- $field: Nombre del campo a obtener
- $default: [opcional] Valor a retornar si $field no está establecido

Retorna:
- Éxito: Contenido del campo
- Fallo: $default si está definido, de lo contrario undef

munin_get_bool
Obtiene una variable booleana.

Parámetros:
- $hash: Referencia al nodo hash
- $field: Nombre del campo a obtener
- $default: [opcional] Valor a retornar si $field no está establecido

Retorna:
- Éxito: 1 o 0 (verdadero o falso)
- Fallo: $default si está definido, de lo contrario undef

munin_get_bool_val
munin_get_children
Obtiene todos los nodos hash hijos.

Parámetros:
- $hash: Una referencia hash al nodo padre

Retorna:
- Éxito: Una referencia a un array de los nodos hijos
- Fallo: undef

munin_get_field_order
Obtiene el orden de los campos en un gráfico.

Parámetros:
- $hash: Una referencia hash al servicio

Retorna:
- Éxito: Una referencia a un array de los nombres de los campos
- Fallo: undef

munin_get_filename
Obtiene el nombre de archivo rrd para un campo, sin adornos. Lo usa munin-update para determinar qué archivo actualizar.

Parámetros:
- $hash: Referencia al campo hash

Retorna:
- Éxito: Ruta completa al archivo rrd
- Fallo: undef

munin_get_html_filename
Obtiene el nombre de archivo html completo.

Parámetros:
- $hash: Una referencia al nodo hash del servicio

Retorna:
- Éxito: El nombre del archivo con ruta completa
- Fallo: undef

munin_get_max_label_length
Obtiene la longitud de la etiqueta más larga en un gráfico.

Parámetros:
- $hash: el gráfico en cuestión
- $order: Una referencia a un array de campos (orden del gráfico)

Retorna:
- Éxito: La longitud de la etiqueta más larga en el gráfico
- Fallo: undef

munin_get_node
Obtiene un nodo por ubicación.

Parámetros:
- $hash: Una referencia al hash donde establecer la variable
- $loc: Una referencia a un array con la ruta completa del nodo

Retorna:
- Éxito: La referencia del nodo encontrada por $loc
- Fallo: undef

munin_get_node_loc
Obtiene el array de ubicación para un nodo hash.

Parámetros:
- $hash: Una referencia al nodo

Retorna:
- Éxito: Referencia a un array con la ruta completa de la variable
- Fallo: undef

munin_get_node_name
Retorna el nombre del nodo hash suministrado.

Parámetros:
- $hash: Una referencia al nodo hash

Retorna:
- Éxito: El nombre del nodo

munin-callbacks

The munin callbacks.

SYNOPSIS

use munin;

  my $hash = munin_root();
  my $node = munin_get_node($hash, 'load');
  my $picture = munin_get_picture_filename($node);
  my $loc     = munin_get_loc($hash, 'load.load');
  my $val     = munin_get_var($hash, 'load.load');
  munin_set_var($hash, 'load.load', 0);
  munin_get_var_path($hash, 'load.load');
  munin_set_var_path($hash, 'load.load', 0);
  munin_get_parent($hash);
  munin_get_parent_name($hash);
  munin_get_root_node($hash);
  munin_get_rrd_filename($field, $path);
  munin_get_picture_loc($hash);
  munin_get_separated_node($hash);
  munin_has_subservices($hash);
  munin_overwrite($hash, $other_hash);
  munin_mkdir_p('/a/path/', oct('777'));
  munin_service_status($field, $limits, $check_draw);
  munin_set($hash, $var, $val);
  munin_set_var_loc($hash, $loc, $val);
  munin_set_var_path($hash, $path, $val);
  munin_parse_config();
  munin_readconfig_part('datafile');
  munin_writeconfig();
  munin_writeconfig_loop();
  munin_path_to_loc('load.load');
  munin_getlock();
  munin_runlock();
  munin_removelock();
  munin_nscasend();
  munin_graph_column_headers();
  munin_node_status();
  munin_overwrite();
  munin_getlock();
  munin_removelock();
  munin_runlock();
