Munin::Common::Timeout(3pm) Documentación de Perl aportada por el usuario Munin::Common::Timeout(3pm)

NOMBRE

Munin::Common::Timeout - Ejecutar código con un tiempo de espera. Puede anidar.

SINOPSIS

use Munin::Common::Timeout;
do_with_timeout(50, sub {
    # ...
       do_with_timeout(5, sub {
               # ...
               # ...
       });
    # ...
});

DESCRIPCIÓN

Ver también Time::Out, Sys::AlarmCall

SUBRUTINAS

do_with_timeout
my $finished_with_no_timeout = do_with_timeout($seconds, $code_ref)
    or die "Timed out!";

Ejecuta $block con un tiempo de espera de $seconds. Devuelve el valor de retorno de $block si se completó dentro del tiempo de espera. Si se alcanza el tiempo de espera y el código sigue en ejecución, lo detiene y devuelve undef.

NOTA: cada $code_ref debe devolver algo definido, de lo contrario, el llamador no sabrá si ocurrió un tiempo de espera.

Las llamadas a do_with_timeout() se pueden anidar. Cualquier excepción generada por $block se propaga.
