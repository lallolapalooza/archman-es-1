Munin::Node::Server(3pm) Documentación de Perl contribuida por el usuario Munin::Node::Server(3pm)

NOMBRE

Munin::Node::Server - Este módulo implementa un servidor Net::Server para el nodo munin.

SINOPSIS

use Munin::Node::Server;
Munin::Node::Server->run(...);

Para los argumentos de run(), véase Net::Server.

MÉTODOS

NET::SERVER "CALLBACKS"

pre_loop_hook
Carga todos los plugins (servicios).
request_denied_hook
Registra el origen de las conexiones rechazadas.
process_request
Procesa la solicitud.
