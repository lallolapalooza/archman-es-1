Munin::Node::OS(3pm) Documentación aportada por el usuario en Perl Munin::Node::OS(3pm)

NOMBRE

Munin::Node::OS - Métodos de utilidad relacionados con el SO para el nodo Munin.

SINOPSIS

use Munin::Node::OS;
my $uid  = Munin::Node::OS->get_uid('foo');
my $host = Munin::Node::OS->get_fq_hostname();

MÉTODOS

get_uid
$uid = $class->get_uid($user)

Devuelve el ID de usuario. $user puede ser un nombre de usuario o un ID de usuario. Devuelve undef si el usuario no existe.

get_gid
$gid = $class->get_gid($group)

Devuelve el ID de grupo. $group puede ser un nombre de grupo o un ID de grupo. Devuelve undef si el grupo no existe.

get_fq_hostname
$host = $class->get_fq_hostname()

Devuelve el nombre de host completo de la máquina.

check_perms_if_paranoid
$bool = $class->check_perms_if_paranoid($target);

Si la paranoia está activada, devuelve falso a menos que $target sea propiedad de root y tenga permisos seguros. Si $target es un archivo, también verifica el directorio en el que se encuentra.

run_as_child
$result = run_as_child($timeout, $coderef, @arguments);

Crea un proceso hijo para ejecutar $code y espera hasta $timeout segundos para que se complete. Devuelve un hashref que contiene las siguientes claves:

"stdout", "stderr"
Referencias de array que contienen la salida de estos filehandles;
"retval"
El resultado de wait();
"timed_out"
Verdadero si el hijo tuvo que ser interrumpido.

Los errores del sistema harán que emita un carp.

reap_child_group
$class->reap_child_group($pid);

Envía SIGHUP y SIGKILL al grupo de procesos identificado por $pid.

Duerme durante 2 segundos entre SIGHUP y SIGKILL.

possible_to_signal_process
my $bool = $class->possible_to_signal_process($pid)

Comprueba si es posible enviar una señal a $pid (es decir, para ser breve, que el proceso pertenece al mismo usuario, o somos el superusuario). Esta es una forma útil de comprobar que un proceso hijo está vivo (incluso si solo es un zombi) y no ha cambiado su UID.

set_effective_user_id
eval {
    $class->set_effective_user_id($uid);
};
if ($@) {
    # Falló al establecer EUID
}
