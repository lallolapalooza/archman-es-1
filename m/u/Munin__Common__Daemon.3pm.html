NOMBRE

Munin::Common::Daemon - utilidades para daemons.

SINOPSIS

Se admiten las siguientes características relacionadas con daemons:

sd_notify: señalizar la disponibilidad del daemon

SUBRUTINAS

emit_sd_notify_message

Ejemplo:

emit_sd_notify_message();

Envía una señal de "listo" según la interfaz "sd_notify":

1. comprueba si la variable de entorno "NOTIFY_SOCKET" está definida
2. elimina esta variable del entorno (esta interfaz no se propaga a los hijos)
3. envía la cadena "READY=1" al socket

La función devuelve silenciosamente si algo falla.

La función debe llamarse tan pronto como el servicio esté listo para aceptar solicitudes. Llamar a esta función es siempre seguro, independientemente de si el llamador admite la interfaz "sd_notify" o no.

Ejemplos para llamadores que admiten la interfaz "sd_notify":

systemd: ver "Type=Notify" en "5" en systemd.exec
start-stop-daemon: ver "--notify-await" en "8" en start-stop-daemon

Consulte la especificación de "sd_notify" https://www.freedesktop.org/software/systemd/man/sd_notify.html para obtener más detalles sobre esta interfaz.
