NOMBRE

Munin::Node::Configure::HostEnumeration - Toma una lista de hosts y devuelve las IPs correspondientes en formato de cuádruple punto.

SINOPSIS

@hosts = ('switch1', 'host1/24', '10.0.0.60/30');
foreach my $host (expand_hosts(@hosts)) {
    # ...
}

SUBRUTINAS

expand_hosts
@expanded = expand_hosts(@list);

Toma una lista de hosts y devuelve las IPs correspondientes en formato de cuádruple punto.

Los elementos se pueden especificar como un nombre de host o una IP de cuádruple punto, con o sin máscara de red.

Actualmente, solo se admiten direcciones IPv4.
