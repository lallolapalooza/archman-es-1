Paquete: munin-node

Licencias: GPL

Munin::Node::SNMPConfig(3pm) Documentación de Perl contribuida por el usuario Munin::Node::SNMPConfig(3pm)

NOMBRE

Munin::Node::SNMPConfig - Subrutinas que proporcionan las capacidades de escaneo SNMP de munin-node-configure.

SINOPSIS

mi $snmp = Munin::Node::SNMPConfig->new(
      community => 'secreto',
      version   => 1,
);
$snmp->probe_hosts(\%plugins);

SUBRUTINAS

new(%argumentos)
Constructor. Los argumentos válidos son:
hosts
La lista de hosts a escanear, en un formato comprensible por Munin::Node::Configure::HostEnumeration. Requerido.
port
Puerto al que conectarse. El valor predeterminado es 161.
version
La versión SNMP a utilizar. El valor predeterminado es '2c'.
community
La cadena de comunidad a utilizar para SNMP versión 1 o 2c. El valor predeterminado es 'public'.
domain
El Dominio de Transporte a utilizar para intercambiar mensajes SNMP. El valor predeterminado es UDP/IPv4. Valores posibles: 'udp', 'udp4', 'udp/ipv4'; 'udp6', 'udp/ipv6'; 'tcp', 'tcp4', 'tcp/ipv4'; 'tcp6', 'tcp/ipv6'.
username
El nombre de usuario SNMPv3 a utilizar.
authpassword
Contraseña de autenticación SNMPv3. Opcional cuando también se habilita el cifrado, en cuyo caso, el valor predeterminado es la contraseña de privacidad ("privpassword"). La contraseña se envía cifrada (hash unidireccional) a través de la red.
authprotocol
Protocolo de autenticación SNMPv3. Uno de 'md5' o 'sha' (HMAC-MD5-96, RFC1321 y SHA-1/HMAC-SHA-96, NIST FIPS PIB 180, RFC2264). El valor predeterminado es 'md5'.
privpassword
Contraseña de privacidad SNMPv3 para habilitar el cifrado. Una contraseña vacía ('') se considera sin contraseña y no habilitará el cifrado.

La privacidad requiere un v3privprotocol, así como un v3authprotocol y un v3authpassword, pero todos estos tienen valores predeterminados (a 'des', 'md5' y el valor de v3privpassword, respectivamente) y, por lo tanto, pueden dejarse sin especificar.

privprotocol
Si se establece v3privpassword, esta configuración controla qué tipo de cifrado se utiliza para lograr la privacidad en la sesión. Oficialmente, solo se admite el método de cifrado 'des', que es muy débil. El valor predeterminado es 'des'.

El módulo perl de implementación (Net::SNMP) también admite '3des' (CBC-3DES-EDE también conocido como Triple-DES, NIST FIPS 46-3) según lo especificado en el borrador de IETF draft-reeder-snmpv3-usm-3desede. Si esto funciona o no con un dispositivo en particular, no lo sabemos.

run_probes($plugins)
Se conecta a cada host en orden y verifica qué plugins admite, basándose en los OID que informaron durante snmpconf. Si se cumplen todos los requisitos, se agregará a la lista de sugerencias del plugin correspondiente.

$plugins debe ser un objeto Munin::Node::Configure::PluginList.
