NOMBRE

Munin::Master::LimitsOld - Clase base abstracta para workers.

SINOPSIS

Este es Munin::Master::LimitsOld, un envoltorio de paquete mínimo para hacer que munin-limits sea modular (para que pueda cargarse persistentemente en un demonio, por ejemplo) sin hacerlo orientado a objetos todavía. El módulo no-'old' presentará una orientación a objetos adecuada como munin-update y tendrá que esperar hasta más tarde.

Obtiene una lista de severidades y devuelve una lista ordenada, en minúsculas, única y validada de severidades.

Espera y devuelve una referencia a un array.

Si ninguna de las severidades dadas está en la lista `allowed_severities`, devolverá una referencia a un array vacío.
