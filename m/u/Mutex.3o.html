Módulo Mutex

Bloqueos para exclusión mutua.

Los mutexes (bloqueos de exclusión mutua) se utilizan para implementar secciones críticas y proteger estructuras de datos mutables compartidas contra accesos concurrentes. El uso típico es (si m es el mutex asociado a la estructura de datos D ):

     Mutex.lock m;
     (* Sección crítica que opera sobre D *);
     Mutex.unlock m

tipo t

El tipo de mutexes.

val create : unit -> t

Devuelve un nuevo mutex.

val lock : t -> unit

Bloquea el mutex dado. Solo un hilo puede tener el mutex bloqueado en un momento dado. Un hilo que intente bloquear un mutex ya bloqueado por otro hilo se suspenderá hasta que el otro hilo desbloquee el mutex.

Antes de 4.12

Sys_error no se lanzaba para bloqueos recursivos (comportamiento dependiente de la plataforma)

Lanza Sys_error si el mutex ya está bloqueado por el hilo que llama a Mutex.lock .

val try_lock : t -> bool

Igual que Mutex.lock , pero no suspende el hilo que llama si el mutex ya está bloqueado: simplemente devuelve false inmediatamente en ese caso. Si el mutex está desbloqueado, lo bloquea y devuelve true .

val unlock : t -> unit

Desbloquea el mutex dado. Otros hilos suspendidos intentando bloquear el mutex se reiniciarán. El mutex debe haber sido previamente bloqueado por el hilo que llama a Mutex.unlock .

Antes de 4.12

Sys_error no se lanzaba al desbloquear un mutex desbloqueado o al desbloquear un mutex de otro hilo.

Lanza Sys_error si el mutex está desbloqueado o fue bloqueado por otro hilo.

val protect : t -> (unit -> 'a) -> 'a

protect mutex f ejecuta f() en una sección crítica donde mutex está bloqueado (usando Mutex.lock ); luego se encarga de liberar mutex , ya sea que f() haya devuelto un valor o haya lanzado una excepción.

La operación de desbloqueo está garantizada a realizarse siempre, incluso en el caso de que se lance una excepción asíncrona (por ejemplo, Sys.Break ) en algún manejador de señales.
