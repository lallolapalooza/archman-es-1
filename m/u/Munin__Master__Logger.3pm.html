Munin::Master::Logger(3pm) Documentación de Perl contribuida por el usuario Munin::Master::Logger(3pm)

NOMBRE

Munin::Master::Logger - Rutinas antiguas de registro del maestro Munin

SINOPSIS

Este módulo contiene las rutinas antiguas de registro del maestro Munin mientras cambiamos a Log::Log4perl. También configura Log::Log4perl según nuestras necesidades.

No uses "logger" al escribir código nuevo, usa la API fácil de Log::Log4perl. Este módulo se encarga de inicializar Log::Log4perl en el momento de la carga.

SUBRUTINAS

logger_open
debe ser llamada una vez en el programa principal con un argumento: El directorio donde van los registros de munin. El nombre del programa en ejecución ($0) se usará como nombre del registro (por ejemplo, munin-graph.log).
logger
No usar.
logger_level
Se usa para establecer el nivel de registro del programa a debug, info, warn, error o fatal. Esto corresponde a los niveles de registro utilizados en syslog, pero syslog no se utiliza para el registro.
logger_debug
Configura el registro DEBUG. Tanto STDOUT como el archivo de registro recibirán salida de nivel DEBUG.

AUTOR
