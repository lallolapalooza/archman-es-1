NOMBRE

Munin::Plugin - Funciones de utilidad para plugins de Perl de Munin.

Uso

use lib $ENV{'MUNIN_LIBDIR'};
use Munin::Plugin;

Si tu instalación de Munin es anterior a las variables de entorno MUNIN_* (introducidas en 1.3.3) puedes poner esto en la configuración de tu plugin:

[*]
    env.MUNIN_PLUGSTATE /var/lib/munin-node/plugin-state
    env.MUNIN_LIBDIR /usr/share/munin

SI, de hecho, ese es el directorio de estado de los plugins de Munin. El directorio de instalación por defecto para Munin::Plugin está en la ruta de búsqueda de módulos de Perl, el "use lib" está ahí para los casos en que no sea así, y la variable necesita ser establecida para evitar que Perl se queje.

El módulo exporta estas funciones: clean_fieldname, set_state_name, save_state, restore_state, tail_open, tail_close.

Variables

El módulo instancia un número de variables en el ámbito de $Munin::Plugin. Ninguna de estas se exporta, y deben ser referenciadas por sus nombres completos tal como se muestran aquí.

$Munin::Plugin::me

El nombre del plugin sin nombres de directorio prefijados ni nada similar. Igual que "basename $0" en una shell. Es una muy buena idea usar esto en mensajes de advertencia y/o error para que los logs muestren claramente de qué plugin proviene el mensaje de error.

$Munin::Plugin::pluginstatedir

Idéntico a la variable de entorno MUNIN_PLUGSTATE (disponible desde Munin 1.3.3)

Puedes usar esto si necesitas guardar varios archivos de estado diferentes. Pero también hay una función para cambiar el nombre del archivo de estado para que las funciones de soporte de archivo de estado puedan ser usadas para varios archivos de estado.

Si su valor no puede ser determinado, el plugin será abortado inmediatamente con un mensaje explicativo. Las causas más probables son:

  • Estás ejecutando el plugin directamente y no desde munin-node o munin-run;
  • Tu munin-node es demasiado antiguo;
  • munin-node fue instalado incorrectamente.

Los dos últimos puntos pueden ser solucionados con la configuración del plugin mostrada al principio de este documento.

$Munin::Plugin::statefile

El nombre calculado automáticamente para el archivo de estado del plugin. El nombre es proporcionado por munin-node o munin-run (en la variable de entorno MUNIN_STATEFILE). El nombre del archivo contiene el nombre del plugin y la dirección IP del munin-master con el que el nodo está hablando (munin-run deja la parte del master en blanco). Esto permite que los plugins con estado que calculan medidores y asumen un intervalo de ejecución de 5 minutos funcionen correctamente en configuraciones con múltiples masters (esta no es una forma inusual de configurar Munin).

Para cambiar el valor de esto, por favor usa el procedimiento set_state_name($) (ver abajo).

$Munin::Plugin::DEBUG

Establecido a verdadero si el plugin debe emitir salida de depuración. Hay algunas (pero no muchas) sentencias de impresión de depuración en el Módulo también, las cuales obedecen a esta variable. Establecido desde la variable de entorno MUNIN_DEBUG. Por defecto es falso (0).

Funciones

$fieldname = clean_fieldname($input_fieldname)

Los nombres de campo de los plugins de Munin están restringidos en cuanto a los caracteres que pueden usar: los caracteres deben ser "[a-zA-Z0-9_]", mientras que el primer carácter debe ser "[a-zA-Z_]". Para satisfacer estas demandas, la función reemplaza los caracteres ilegales con un '_'.

Ver también http://munin-monitoring.org/wiki/notes_on_datasource_names

set_state_name($statefile_name)

Anula el nombre de archivo de estado por defecto. Esto solo modifica la parte del nombre del archivo, no el nombre del directorio. La función añade incondicionalmente "-$MUNIN_MASTER_IP" al nombre del archivo para soportar múltiples masters como se describe en la documentación de la variable statefile (arriba).

Llamar a esta función normalmente no es necesario y no se recomienda.

save_state(@state_vector)

Guarda el vector de estado pasado al archivo de estado apropiado para el plugin. El vector de estado solo debe contener cadenas (o números), y absolutamente ningún objeto o referencia. Las cadenas pueden contener saltos de línea sin efectos adversos.

Si el archivo no puede ser abierto para escritura, el plugin será abortado.

El nombre del archivo de estado se determina automáticamente en función del nombre del proceso que se está ejecutando. Ver $Munin::Plugin::me, $Munin::Plugin::statefile y set_state_name arriba sobre el nombre del archivo.

El archivo contendrá una línea de inicio con un número mágico para que la biblioteca pueda ver la diferencia entre un archivo de estado real y un archivo que contiene basura. Actualmente este número mágico es '%MUNIN-STATE1.0\n'. Los archivos con este número mágico contendrán el vector literalmente codificado en URL con \r, \n y %.

La función toma precauciones de seguridad, como protestar fatalmente si el archivo de estado es un enlace simbólico (la sobrescritura de enlaces simbólicos puede tener consecuencias de seguridad desafortunadas).

@state_vector = restore_state()

Lee el estado del archivo de estado escrito por save_state(@). Si todo está OK, se devolverá el vector de estado.

Se devolverá undef si el archivo no puede ser abierto. Igualmente si no tiene un número mágico reconocido (en este caso también se imprimirá una advertencia, que aparecerá en los logs de munin-node).

($warning, $critical) = get_thresholds($field, [$warning_env, [$critical_env]])

Busca los umbrales para el campo especificado en las variables de entorno nombradas después del campo: "$field_warning" y "$field_critical". Devuelve sus valores. Si no hay valores $field_warning o $field_critical, entonces busca las variables "warning" y "critical" y devuelve esos valores si los hay.

Si se especifican el segundo y/o tercer argumento, se usarán para especificar el nombre de las variables que dan los niveles de advertencia y crítico.

Si no se encuentran valores para un umbral, se devolverá undef.

print_thresholds($field, [$warning_env, [$critical_env]])

Si $field tiene umbrales de advertencia o críticos establecidos para él, los imprime de la forma predeterminada (ej. 'field.warning 42').

Ver get_thresholds para una explicación de los argumentos.

adjust_threshold($threshold, $base)

Si $threshold contiene signos %, devuelve un nuevo umbral con valores ajustados para estos porcentajes contra $base.

($file_handle,$rotated) = tail_open($file_name, $position)

Abre el archivo y se posiciona en la posición dada. Si esta posición está más allá del final del archivo, la función asume que el archivo ha sido rotado y la posición del archivo estará al principio del archivo.

Si el archivo se abre correctamente, la función devuelve una tupla que consiste en el manejador de archivo y un indicador de rotación de archivo. $rotated será 1 si el archivo ha sido rotado y 0 en caso contrario. Además, si el archivo fue rotado se imprime una advertencia (solo en modo de depuración, esto se puede encontrar en el log de munin-node o verse en la terminal al usar munin-run).

En este punto, el plugin puede leer del archivo con <$file_handle> en un bucle como de costumbre hasta que se encuentre el final del archivo (EOF).

Si el archivo no puede ser estático "(undef,undef)" es devuelto. Si el archivo no puede ser abierto para lectura, el plugin es abortado con un error en interés de la obviedad del error.

$position = tail_close($file_handle)

Cierra el archivo y devuelve la posición actual en el archivo. Esta posición puede ser almacenada en un archivo de estado hasta la próxima vez que se ejecute el plugin.

Si la llamada al sistema "close" falla, se imprimirá una advertencia (que se puede encontrar en el log de munin-node o verse al usar munin-run).

NAME

Munin::Plugin - Wrapper for Munin node plugins

SYNOPSIS

  use Munin::Plugin;
  my $bytes = $bytes = 123456;
  print bytes2human($bytes);
  print bytes2human($bytes, 'B');
  print bytes2human($bytes, 'B', 'No data');
  print bytes2human($bytes, 'B', 'No data', '%9.2f%s%s');
  print bytes2human($bytes, 'B', 'No data', 'The interface speed is %.2f%s%s.');
  need_multigraph();

DESCRIPTION

This module is a wrapper for Munin node plugins, providing utility functions for writing them, and a standard way of doing things.

bytes2human( $num, $unit, $ifZero, $format )

This function takes a number, scales it to human-readable SI prefixes, and returns it as a string.

The $num is the number of bytes to format.

The $unit is the base unit for the number and is appended to the prefix. Defaults to "".

The contents of $ifZero is used if the number is 0 (or smaller than 10^-26), instead of any other string. Defaults to "0".

The $format can be any valid Perl printf format string. Defaults to "%.1f%s%s".

This function scales numbers from 10^-24 to 10^24. The prefixes used are:

 Y  (yotta)      10^24
 Z  (zetta)      10^21
 E  (exa)        10^18
 P  (peta)       10^15
 T  (tera)       10^12
 G  (giga)       10^9
 M  (mega)       10^6
 k  (kilo)       10^3
 da (deca)       10^1
 d  (deci)       10^-1
 c  (centi)      10^-2
 m  (milli)      10^-3
 u  (micro)      10^-6
 n  (nano)       10^-9
 p  (pico)       10^-12
 f  (femto)      10^-15
 a  (atto)       10^-18
 z  (zepto)      10^-21
 y  (yocto)      10^-24

The format string is interpreted as follows:

%s (first)
The SI prefix.
%s (second)
The unit.

Example:

 print bytes2human(1234567);       # Outputs: 1.2M
 print bytes2human(1234567, 'B');  # Outputs: 1.2MB
 print bytes2human(0, 'B', 'No data'); # Outputs: No data
 print bytes2human(12345, 'B', undef, '%.1f%s%s'); # Outputs: 12.3k
 print bytes2human(12345, 'B', 'Interface down', 'The interface speed is %.1f%s%s.'); # Outputs: The interface speed is 12.3k.

need_multigraph()

This function should be called at the top of all multigraph plugins.

It checks the current environment and exits with appropriate output if it doesn't support multigraph plugins.

TESTING

There is some test stuff in this module.

 Test like this:
 MUNIN_PLUGSTATE=/var/lib/munin-node/plugin-state perl -M
 Munin::Plugin -e 'Munin::Plugin::_test;'

The _test subroutine:

 sub _test () {
   my $pos;
   my $fh;
   my $reset;
   warn "Testing tail and state file. Press ^C to stop\n";
   do {
       $pos = undef;
       ($pos) = restore_state();
       $pos = 0 unless defined($pos);
       ($fh,$reset) = tail_open('/var/log/messages',$pos);
       while (<$fh>) {
           print;
       }
       $pos = tail_close($fh);
       print "**Position is $pos\n";
       save_state($pos);
   } while sleep 1;
 }
