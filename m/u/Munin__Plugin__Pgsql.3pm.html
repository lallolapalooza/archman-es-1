NOMBRE

Munin::Plugin::Pgsql - Módulo base para plugins de PostgreSQL para Munin

SINOPSIS

El módulo Munin::Plugin::Pgsql proporciona funcionalidad base para todos los plugins de Munin para PostgreSQL, incluyendo parámetros comunes de configuración.

CONFIGURACIÓN

Toda la configuración se realiza a través de variables de entorno.

VARIABLES DE ENTORNO

Todos los plugins basados en Munin::Plugin::Pgsql aceptan todas las variables de entorno que libpq acepta. Las más comunes utilizadas son:

PGHOST      nombre del host al que conectarse, o ruta al socket Unix
PGPORT      número de puerto al que conectarse
PGUSER      nombre de usuario con el que conectarse
PGPASSWORD  contraseña para conectarse, si se requiere contraseña

Los plugins se conectarán por defecto a la base de datos 'template1', excepto para los plugins comodín por base de datos. Esto se puede anular usando la variable PGDATABASE, pero generalmente es una mala idea.

Si utilizas el plugin para varias instancias de postgres, puedes personalizar el título del gráfico con la variable de entorno PGLABEL.

Advertencia y crítica se pueden personalizar estableciendo las variables de entorno "warning" y "critical" por plugin.

Ejemplo

[postgres_*]
   user postgres
   env.PGUSER postgres
   env.PGPORT 5433
 [postgres_connections_ALL]
   env.warning :450
   env.critical :500

COINCIDENCIA DE COMODINES

Los plugins comodín basados en este módulo coincidirán con cualquier tipo de objeto especificado para un filtro, generalmente una base de datos. Si se utiliza el nombre de objeto ALL (por ejemplo, un enlace simbólico a postgres_connections_ALL), el filtro no se aplicará y el plugin se comportará como uno no comodín.

REQUISITOS

El módulo requiere DBD::Pg para funcionar.

DOCUMENTACIÓN DE LA API

Las siguientes funciones están disponibles para los plugins que utilizan este módulo.

Inicialización

use Munin::Plugin::Pgsql;
my $pg = Munin::Plugin::Pgsql->new(
   parameter=>value,
   parameter=>value
);

Parámetros

minversion     Versión mínima de PostgreSQL requerida, formateada como 8.2. Si la
               base de datos es una versión anterior a esta, el plugin saldrá con un error.
category       La categoría de este plugin. Copiada directamente a la salida de
               configuración. Por defecto 'db'.
title          El título de este plugin. Copiado directamente a la salida de
               configuración.
info           La información de este plugin. Copiada directamente a la salida de
               configuración.
vlabel         La etiqueta vertical para el gráfico. Copiada directamente a la salida de
               configuración.
basename       Para plugins comodín, este es el nombre base del plugin, incluyendo el
               guion bajo final.
basequery      Consulta SQL ejecutada para obtener los valores del plugin. La consulta debe
               devolver dos columnas, una siendo el nombre del contador y la segunda el
               valor actual del contador.
pivotquery     Establecer a 1 para indicar que la consulta en basequery devuelve una única
               fila, con un campo para cada contador. El nombre del contador se toma del
               nombre de la columna devuelta, y el valor de la primera fila del resultado.
configquery    Consulta SQL ejecutada para generar la información de configuración del
               plugin. La consulta debe devolver al menos dos columnas, que son el
               nombre del contador y la etiqueta del contador. Si hay una tercera
               columna presente, se utilizará como parámetro info.
suggestquery   Consulta SQL a ejecutar para generar la lista de sugerencias para un
               plugin comodín. No olvides incluir ALL si el plugin soporta estadísticas agregadas.
autoconfquery  Consulta SQL a ejecutar como último paso de "autoconf", para determinar
               si el plugin debe ejecutarse en esta máquina. Debe devolver una única
               fila, dos columnas. La primera es un campo booleano que representa sí o
               no, la segunda una razón para "no".
warning        Los umbrales de advertencia bajo y/o alto.
critical       Los umbrales críticos bajo y/o alto.
graphdraw      El parámetro draw para el gráfico. El valor por defecto es LINE1.
graphtype      El parámetro type para el gráfico. El valor por defecto es GAUGE.
graphperiod    El parámetro period para el gráfico. Copiado directamente a la salida de
               configuración.
graphmin       El parámetro min para el gráfico. El valor por defecto es sin mínimo.
graphmax       El parámetro max para el gráfico. El valor por defecto es sin máximo.
stack          Si se establece a 1, todos los contadores excepto el primero se escribirán
               con un tipo de dibujo STACK.
base           Utilizado para graph_args --base. El valor por defecto es 1000, se establece
               a 1024 cuando se devuelven tamaños en Kb, por ejemplo.
wildcardfilter El SQL a sustituir cuando un plugin comodín se ejecuta contra una
               entidad específica, por ejemplo una base de datos. Todas las ocurrencias
               de la cadena %%FILTER%% serán reemplazadas con esta cadena, y por cada
               ocurrencia se añadirá un parámetro con el valor de la condición de filtrado
               a la sentencia DBI.
paramdatabase  Hace que el plugin se conecte a la base de datos en el primer parámetro
               (solo plugins comodín) en lugar de 'template1'.
defaultdb      Hace que el plugin se conecte a la base de datos especificada en este
               parámetro en lugar de 'template1'.
extraconfig    Esta cadena se copia directamente en la salida de configuración cuando
               el plugin se ejecuta en modo de configuración, permitiendo personalización
               de bajo nivel.
postprocess    Una función que se llama con el resultado de la consulta base, y que
               puede post-procesar el resultado y devolver un nuevo conjunto de resultados.
postconfig     Una función que se llama con el resultado de la consulta de configuración,
               y que puede post-procesar el resultado y devolver un nuevo conjunto de resultados.
postautoconf   Una función que se llama con el resultado de la consulta autoconf,
               y que puede post-procesar el resultado y devolver un nuevo conjunto de resultados.
postsuggest    Una función que se llama con el resultado de la consulta suggest,
               y que puede post-procesar el resultado y devolver un nuevo conjunto de resultados.

Especificando consultas

Las consultas especificadas en uno de los parámetros anteriores pueden tomar una de dos formas. La más fácil es una cadena simple, que se ejecutará siempre, independientemente de la versión del servidor. La otra forma es un array, que se ve así:
[
"SELECT 'default',... FROM ...",
[
"8.3", "SELECT 'consulta para 8.3 o anterior',... FROM ...",
"8.1", "SELECT 'consulta para 8.1 o anterior',... FROM ..."
]
] Este array se analiza de arriba a abajo, por lo que las entradas deben estar en orden de número de versión. El *último* valor encontrado donde la versión especificada es mayor o igual a la versión del servidor se utilizará (sí, se cuenta hacia atrás).

Procesamiento

$pg->Process();
Este comando ejecuta el plugin. Analizará automáticamente el array ARGV para
comandos dados por Munin.

NAME

Munin::Plugin::Pgsql - PostgreSQL database monitoring plugin for Munin

SYNOPSIS

This plugin monitors a PostgreSQL database using the Munin monitoring framework.

CONFIGURATION

The plugin requires a configuration file (e.g., /etc/munin/plugin-conf.d/pgsql.conf) with the following parameters:

user
The database user to connect as.
password
The password for the database user.
database
The name of the database to monitor.
host
The database host (default: localhost).
port
The database port (default: 5432).

Example configuration:

[pgsql]
user     myuser
password mypassword
database mydb
host     localhost
port     5432

ENVIRONMENT VARIABLES

The plugin respects the following environment variables:

MUNIN_PLUGINS_CONF
Specifies the path to the Munin plugins configuration directory.
MUNIN_CONF
Specifies the path to the Munin main configuration file.

WILDCARD MATCHING

This plugin does not support wildcard matching.

REQUIREMENTS

The plugin requires the following Perl modules:

  • DBI
  • DBD::Pg

You can install these modules using CPAN or your distribution's package manager (e.g., perl-dbd-pg and perl-dbi on Arch Linux).
