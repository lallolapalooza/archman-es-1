Munin::Common::TLS(3pm) Documentación de Perl contribuida por el usuario Munin::Common::TLS(3pm)

NOMBRE

Munin::Node::TLS - Clase base abstracta que implementa el protocolo STARTTLS

SINOPSIS

No debe llamarse directamente. Ver sinopsis para Munin::Common::TLSServer y Munin::Common::TLSClient.

MÉTODOS

new
my $tls = Munin::Common::TLSFoo->new({ # Sustituya Foo por Client o Server
    # Atributos obligatorios:  
    logger      => \&una_función_de_registro,
    read_fd     => fileno($socket),
    read_func   => \&una_función_de_lectura_de_socket,
    write_fd    => fileno($socket),
    write_func  => \&una_función_de_lectura_de_socket,
    # Atributos opcionales                          VALORES PREDETERMINADOS
    DEBUG              => 0,                       # 0
    tls_ca_cert        => "ruta/a/certificado_ca.pem",   # ''
    tls_cert           => "ruta/a/certificado.pem",      # ''
    tls_paranoia       => 1,                       # 0
    tls_priv           => "ruta/a/clave_privada.pem",  # ''
    tls_vdepth         => 5,                       # 0
    tls_verify         => 1,                       # 0
});

Constructor. No debe llamarse directamente. Esto documenta los atributos que son comunes para Munin::Common::TLSServer y Munin::Common::TLSClient.

read
my $msg = $tls->read();

Lectura cifrada.

write
$tls->write($msg);

Escritura cifrada.

session_started
my $bool = $tls->session_started();

Devuelve verdadero si el objeto TLS está listo para leer/escribir datos cifrados.
