val exists2 : ('a -> 'b -> bool) -> 'a array -> 'b array -> bool

Igual que Array.exists2 de la biblioteca estándar.

val for_alli : (int -> 'a -> bool) -> 'a array -> bool

Igual que Array.for_all de la biblioteca estándar, pero la función se aplica con el índice del elemento como primer argumento y el elemento en sí como segundo argumento.
