NOMBRE

MIME::Type - descripción de un tipo MIME

SINÓPSIS

use MIME::Types;
my $mimetypes = MIME::Types->new;
my MIME::Type $plaintext = $mimetypes->type('text/plain');
print $plaintext->mediaType;   # text
print $plaintext->subType;     # plain
my @ext = $plaintext->extensions;
print "@ext"                   # txt asc c cc h hh cpp
print $plaintext->encoding     # 8bit
if($plaintext->isBinary)       # false
if($plaintext->isText)         # true
if($plaintext->equals('text/plain') {...}
if($plaintext eq 'text/plain') # same
print MIME::Type->simplified('x-appl/x-zip') #  'appl/zip'

DESCRIPCIÓN

Los tipos MIME se utilizan en entidades MIME, por ejemplo, como parte de correos electrónicos y tráfico HTTP. A veces se necesita conocimiento real sobre un tipo MIME. Los objetos de "MIME::Type" almacenan la información sobre un tipo de este tipo.

SOBRECARGADO

sobrecarga: "" conversión a cadena
La conversión a cadena (uso del objeto en un lugar donde se requiere una cadena) dará como resultado el nombre del tipo, lo mismo que devuelve type().

ejemplo: uso de la conversión a cadena

my $mime = MIME::Type->new('text/html');
print "$mime\n";   # conversión explícita a cadena
print $mime;       # conversión implícita a cadena
sobrecarga: == comparación numérica
Compara si el type() de los objetos es el mismo.
sobrecarga: cmp comparación de cadenas
Cuando un objeto MIME::Type se compara con una cadena u otro MIME::Type, se llama al método equals(). La comparación es inteligente, lo que significa que extiende la comparación de cadenas común con algunas características definidas en los RFC relacionados.

MÉTODOS

Iniciación

$class->new(%options)
Crea (instancia) un nuevo objeto MIME::Type que gestiona un tipo MIME. 
-Opción    --Por defecto
 charset     undef
 encoding    <depende del tipo>
 extensions  []
 simplified  <derivado del tipo>
 system      undef
 type        <requerido>
charset => $charset
Especifica el conjunto de caracteres predeterminado para este tipo.
encoding => '7bit'|'8bit'|'base64'|'quoted-printable'
Cómo deben codificarse estos datos para transportarse de forma segura. El valor predeterminado depende del tipo: los MIME con el tipo principal "text/" tendrán por defecto "quoted-printable" y todos los demás "base64".
extensions => REF-ARRAY
Una matriz de extensiones que utilizan este MIME.
simplified => STRING
Las etiquetas principal y secundaria de los tipos MIME pueden comenzar con "x-", para indicar que es un nombre no registrado. Por supuesto, después del registro, esta bandera puede desaparecer, lo que aumenta la confusión. La cadena simplificada tiene las cosas de "x-" eliminadas y se traducen a minúsculas.
system => REGEX
Expresión regular que define para qué sistemas es válida esta regla. El REGEX se compara con $^O.
type => STRING
El tipo que se define aquí. Consta de un *tipo* y un *subtipo*, ambos sin distinción de mayúsculas y minúsculas. Este módulo devolverá en minúsculas, pero aceptará mayúsculas.

Atributos

$obj->charset()
[2.28] RFC6657 prescribe que las registraciones IANA para tipos de la categoría de texto declaren explícitamente su conjunto de caracteres predeterminado. MIME-Types contiene una lista producida manualmente de estos valores predeterminados.

Este método también puede devolver "_REQUIRED", cuando no hay un valor predeterminado, o "_FRAMED" cuando el conjunto de caracteres se determina por el contenido.

$obj->encoding()
Devuelve el tipo de codificación que se requiere para transportar datos de este tipo de forma segura.
$obj->extensions()
Devuelve una lista de extensiones que se sabe que se utilizan para este tipo MIME.
$any->simplified( [$string] )
Devuelve el tipo MIME simplificado para este objeto o la CADENA especificada. Los nombres de los tipos MIME pueden registrarse oficialmente. Hasta entonces, deben llevar un preámbulo "x-" para indicarlo. Por supuesto, después del reconocimiento, el "x-" puede desaparecer. En muchos casos, preferimos la versión simplificada del tipo.

ejemplo: resultados de simplified()

my $mime = MIME::Type->new(type => 'x-appl/x-zip');
print $mime->simplified;                     # 'appl/zip'
print $mime->simplified('text/PLAIN');       # 'text/plain'
print MIME::Type->simplified('x-xyz/x-abc'); # 'xyz/abc'
$obj->system()
Devuelve la expresión regular que se puede utilizar para determinar si este tipo está activo en el sistema en el que estás trabajando.
$obj->type()
Devuelve el tipo largo de este objeto, por ejemplo 'text/plain'

Conocimiento

$obj->defaultCharset()
[2.29] Según RFC6657, todos los tipos "text/*" deben especificar un conjunto de caracteres predeterminado en su registro IANA, o requerir el parámetro charset. Los tipos no textuales también pueden requerir un charset.

Es difícil extraer esta información de los archivos de registro IANA automáticamente, por lo que se mantiene manualmente.

ejemplo: uso del conjunto de caracteres predeterminado

$charset //= $type->defaultCharset // 'utf-8';
$obj->equals($string|$mime)
Compara este objeto de tipo MIME con una CADENA u otro objeto. En caso de una CADENA, se realizará la simplificación.
$obj->isAscii()
Nombre antiguo de isText().
$obj->isBinary()
Devuelve "true" cuando no se sabe que el tipo sea de texto. Ver isText().
$obj->isExperimental()
[2.00] Devuelve "true" cuando el tipo está definido para uso experimental; el subtipo comienza con "x."
$obj->isPersonal()
[2.00] Devuelve "true" cuando el tipo está definido por una persona para uso privado; el subtipo comienza con "prs."
$obj->isRegistered()
Los tipos MIME que no están registrados por IANA ni definidos en los RFC comenzarán con un "x-". Esto se aplica tanto al tipo de medio como al subtipo. En caso de que alguno de los tipos comience con "x-", este método devolverá "false".
$obj->isSignature()
Devuelve "true" cuando el tipo está en la lista de firmas conocidas.
$obj->isText()
[2.05] Todos los tipos que pueden tener el atributo charset, son de texto. Sin embargo, actualmente no hay registro de atributos en este módulo... así que adivinamos.
$obj->isVendor()
[2.00] Devuelve "true" cuando el tipo está definido por un proveedor; el subtipo comienza con "vnd."
$obj->mediaType()
El tipo de medio del MIME simplificado. Para 'text/plain' devolverá 'text'.

Por razones históricas, el método 'mainType' aún puede usarse para recuperar el mismo valor. Sin embargo, ese método está obsoleto.

subType

$obj->subType()
El subtipo del MIME simplificado. Para 'text/plain' devolverá 'plain'.

MIME-Types

$mimes->type($type)
Devuelve un objeto MIME::Type que se ajusta al tipo dado. Si no se encuentra ninguno, se devolverá undef. La comparación se hace sin distinción de mayúsculas y minúsculas.

example: retrieve type

my $html = $mimes->type('text/html');
if ($html) {
    print $html->extensions;
}
$mimes->byMatch($path|$type)
Devuelve la mejor coincidencia para la ruta dada (el nombre del archivo) o el tipo MIME. La lista de tipos MIME se revisa para la mejor coincidencia con la ruta, y si no se encuentra, se revisa la lista de tipos MIME para el tipo dado.

example: match path

my $img = $mimes->byMatch('image.jpg');
if ($img) {
    print $img->mediaType; # image
}
$mimes->byExtension($ext)
Devuelve la mejor coincidencia MIME::Type para la extensión dada. Devuelve undef si no se encuentra ninguna coincidencia.

example: match extension

my $pdf = $mimes->byExtension('pdf');
if ($pdf) {
    print $pdf->type; # application/pdf
}
$mimes->byDescription($desc)
Busca el tipo MIME que tiene la descripción dada. Devuelve undef si no se encuentra ninguna coincidencia. La búsqueda se realiza sin distinción de mayúsculas y minúsculas.

example: match description

my $type = $mimes->byDescription('Adobe Postscript');
if ($type) {
    print $type->type; # application/postscript
}
$obj->subType()
El subtipo del mime simplificado. Para 'text/plain' devolverá 'plain'.

DIAGNÓSTICOS

Error: El parámetro de tipo es obligatorio.
Cuando se crea un objeto MIME::Type, el tipo debe especificarse con el flag "type". Causado por new()
