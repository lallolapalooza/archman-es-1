Módulo Magic_number
: sig end

un número mágico típico es "Caml1999I011"; está formado por un prefijo alfanumérico, aquí Caml1990I, seguido de una versión, aquí 011. El prefijo identifica el tipo de datos versionados: aquí la I indica que es el número mágico para archivos .cmi.

Todos los números mágicos tienen la misma longitud de bytes, magic_length , y esto es importante para los usuarios, ya que les da el número de bytes a leer para obtener la secuencia de bytes que debería ser un número mágico. El código típico del usuario se verá así:

        let ic = open_in_bin path in
        let magic =
          try really_input_string ic Magic_number.magic_length
          with End_of_file -> ... in
        match Magic_number.parse magic with
        | Error parse_error -> ...
        | Ok info -> ...

Una versión determinada del compilador espera una versión específica para cada tipo de archivo objeto, y fallará si se le da una versión no compatible. Dado que las versiones crecen monótonamente, puedes comparar la versión analizada con la "versión actual" esperada para un tipo, para saber si el archivo objeto con número mágico incorrecto proviene del pasado o del futuro.

Un ejemplo de bloque de código que espera la "versión actualmente compatible" de un tipo determinado de números mágicos, aquí Cmxa , es el siguiente:

        let ic = open_in_bin path in
        begin
          try Magic_number.(expect_current Cmxa (get_info ic)) with
          | Parse_error error -> ...
          | Unexpected error -> ...
        end;
        ...

Los errores de análisis distinguen las entradas que son Not_a_magic_number str , que probablemente provienen de que el archivo es completamente diferente, y Truncated str , lanzada por encabezados que son el prefijo (posiblemente vacío) de un número mágico válido.

Los errores inesperados corresponden a números mágicos válidos que no son el esperado, ya sea porque corresponde a un tipo diferente, o a una versión más nueva o más antigua.

Las funciones auxiliares explain_parse_error y explain_unexpected_error generarán una explicación textual de cada error, para su uso en mensajes de error.

los archivos objeto nativos tienen un formato y un número mágico que dependen de ciertos parámetros de configuración del compilador nativo. Este espacio de configuración se expresa mediante el tipo native_obj_config .

type raw = string

el tipo de números mágicos en bruto, como "Caml1999A027" para los archivos .cma de OCaml 4.10

Análisis de números mágicos

type parse_error =
| Truncated of string
| Not_a_magic_number of string

val explain_parse_error : kind option -> parse_error -> string

Produce una explicación de un error de análisis. Si no se proporciona ningún tipo, utilizamos una formulación inespecífica que sugiere que cualquier archivo objeto producido por el compilador habría sido satisfactorio.

val parse : raw -> (info, parse_error) result

Analiza un número mágico en bruto

val read_info : in_channel -> (info, parse_error) result

Lee un número mágico en bruto de un canal de entrada.

Si los datos leídos str no son un número mágico válido, se pueden recuperar del payload Truncated str | Not_a_magic_number str del caso Error parse_error .

Si también desea garantizar que el número mágico sea de la versión actual, consulte Misc.Magic_number.read_current_info a continuación.

val magic_length : int

todos los números mágicos ocupan el mismo número de bytes

Comprobación de que los números mágicos son actuales

type 'a unexpected = {
expected : 'a ;
actual : 'a ;
}

type unexpected_error =
| Kind of kind unexpected
| Version of kind * version unexpected

val check_current : kind -> info -> (unit, unexpected_error) result

check_current kind info comprueba que la info mágica proporcionada sea la versión actual del encabezado mágico de kind .

val explain_unexpected_error : unexpected_error -> string

Proporciona una explicación del unexpected_error .

type error =
| Parse_error of parse_error
| Unexpected_error of unexpected_error

val read_current_info : expected_kind:kind option -> in_channel -> (info, error) result

Lee un número mágico como read_info , y comprueba que es la versión actual de su tipo. Si el argumento expected_kind es None , se acepta cualquier tipo.

Representaciones en bruto

Principalmente para uso interno y pruebas.

type raw_kind = string

el tipo de tipos de números mágicos en bruto, como "Caml1999A" para archivos .cma

val parse_kind : raw_kind -> kind option

analiza un tipo en bruto en un tipo

val raw_kind : kind -> raw_kind

la representación en bruto actual de un tipo.

En algunos casos, la representación en bruto de un tipo ha cambiado a lo largo de las versiones del compilador, por lo que otros archivos del mismo tipo pueden tener tipos en bruto diferentes. Tenga en cuenta que todos los casos conocidos actualmente son analizados correctamente por parse_kind .

val raw : info -> raw

Una representación en bruto válida del número mágico.

Debido a cambios pasados y futuros en la representación de cadena de los números mágicos, no podemos garantizar que las cadenas en bruto devueltas para versiones pasadas y futuras coincidan realmente con las expectativas de esos compiladores. La representación es precisa para las versiones actuales y se analiza correctamente de nuevo en la versión deseada por las funciones de análisis anteriores.
