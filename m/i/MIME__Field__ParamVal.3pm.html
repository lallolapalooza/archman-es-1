MIME::Field::ParamVal(3) Documentación de Perl contribuida por el usuario MIME::Field::ParamVal(3)

NOMBRE

MIME::Field::ParamVal - subclase de Mail::Field, para campos MIME estructurados

SINOPSIS

# Crear un objeto para un campo de tipo de contenido:
$field = new Mail::Field 'Content-type';
# Establecer algunos atributos:
$field->param('_'        => 'text/html');
$field->param('charset'  => 'us-ascii');
$field->param('boundary' => '---ABC---');
# Igual:
$field->set('_'        => 'text/html',
            'charset'  => 'us-ascii',
            'boundary' => '---ABC---');
# Obtener un atributo, o undef si no está presente:
print "¡no hay id!"  if defined($field->param('id'));
# Igual, pero usa cadena vacía para valores faltantes:
print "¡no hay id!"  if ($field->paramstr('id') eq '');
# Salida como cadena:
print $field->stringify, "\n";

DESCRIPCIÓN

Esta es una superclase abstracta de la mayoría de los campos MIME. Maneja campos con una sintaxis general como esta:

Content-Type: Message/Partial;
    number=2; total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

Los comentarios son compatibles *entre* elementos, de esta manera:

Content-Type: Message/Partial; (un comentario)
    number=2  (otro comentario) ; (aún otro comentario) total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

INTERFAZ PÚBLICA

set [\%PARAMHASH | CLAVE=>VALOR,...,CLAVE=>VALOR]
Método de instancia. Establece este campo. El hashref de parámetros debe contener nombres de parámetros en *todas las minúsculas*, con el nombre especial de parámetro "_" que significa el parámetro "predeterminado" (sin nombre) para el campo: 
# Configurar para ser...
#
#     Content-type: Message/Partial; number=2; total=3; id="ocj=pbe0M2"
#
$conttype->set('_'       => 'Message/Partial',
               'number'  => 2,
               'total'   => 3,
               'id'      => "ocj=pbe0M2");

Tenga en cuenta que se toma un solo argumento para ser una *referencia* a un hashref de parámetros, mientras que los argumentos múltiples se toman como los elementos del hashref de parámetros mismos.

Suministrar undef para un hashref, o un conjunto vacío de valores, efectivamente limpia el objeto.

Se devuelve el objeto de sí mismo.

parse_params CADENA
Método de utilidad de clase/instancia. Extrae información de parámetros de un campo estructurado y la devuelve como una referencia a un hashref. Por ejemplo, aquí hay un campo con parámetros: 
Content-Type: Message/Partial;
    number=2; total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

Así es como los extraerías:

$params = $class->parse_params('content-type');
if ($$params{'_'} eq 'message/partial') {
    $number = $$params{'number'};
    $total  = $$params{'total'};
    $id     = $$params{'id'};
}

Al igual que los nombres de campo, los nombres de los parámetros se convierten a minúsculas. El parámetro especial '_' significa el parámetro predeterminado para el campo.

NOTA: Esto se ha proporcionado como un método público para admitir la compatibilidad con versiones anteriores, pero probablemente no deberías usarlo.

parse CADENA
Método de clase/instancia. Analiza la cadena en la instancia. Se elimina cualquier información previa. Se devuelve el objeto de sí mismo.

También se puede usar como constructor.

param NOMBREPARAM,[VALOR]
Método de instancia. Devuelve el parámetro dado, o undef si no está allí. Con argumento, establece el parámetro a ese VALOR. El NOMBREPARAM no distingue entre mayúsculas y minúsculas. Un "_" se refiere al parámetro "predeterminado".
paramstr NOMBREPARAM,[VALOR]
Método de instancia. Similar a param(): devuelve el parámetro dado, o *vacío* si no está allí. Con argumento, establece el parámetro a ese VALOR. El NOMBREPARAM no distingue entre mayúsculas y minúsculas. Un "_" se refiere al parámetro "predeterminado".
stringify
Método de instancia. Convierte el campo a una cadena y la devuelve.
tag
Método de instancia, abstracto. Devuelve la etiqueta para este campo.
