MIME::WordDecoder(3) Documentación de contribuciones de Perl MIME::WordDecoder(3)

NOMBRE

MIME::WordDecoder - decodificar palabras RFC 2047 a una representación local

AVISO: Gran parte de este módulo está desapareciendo y puede ser obsoleta. La única función que debes usar para decodificar MIME es mime_to_perl_string.

SINOPSIS

Ver MIME::Words para lo básico de las palabras RFC 2047. Ver DESCRIPCIÓN para cómo funciona esta clase.

use MIME::WordDecoder;
### Obtener el decoder por defecto (usado por unmime()):
$wd = default MIME::WordDecoder;
### Obtener un decoder que mapea a ISO-8859-1 (Latin1):
$wd = supported MIME::WordDecoder 'ISO-8859-1';
### Decodificar una cadena MIME (por ejemplo, en Latin1) usando el decoder por defecto:
$str = $wd->decode('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
### Decodificar una cadena usando el decoder por defecto, estilo no OO:
$str = unmime('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
### Decodificar una cadena a una cadena interna Perl, estilo no OO
### El resultado es probablemente CON el flag UTF8.
$str = mime_to_perl_string('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');

DESCRIPCIÓN

AVISO: Gran parte de este módulo está desapareciendo y puede ser obsoleta. Se duplica (muy mal) la función del módulo estándar 'Encode'. La única función que debes depender es mime_to_perl_string.

Un MIME::WordDecoder consiste, fundamentalmente, en un mapa que mapea un nombre de conjunto de caracteres (US-ASCII, ISO-8859-1, etc.) a una subrutina que sabe cómo convertir bytes en ese conjunto de caracteres a una representación objetivo. Idealmente, esta representación objetivo sería Unicode, pero no queremos especificar demasiado la traducción: si quieres convertir strings MIME directamente a Big5, es tu decisión.

La subrutina se invocará con dos argumentos: DATA (los datos en el conjunto de caracteres dado), y CHARSET (el nombre del conjunto de caracteres en mayúsculas).

Por ejemplo:

### Mantén los caracteres 7-bit como tal, y convierte los caracteres 8-bit a '#':
sub keep7bit {
    local $_ = shift;
    tr/\x00-\x7F/#/c;
    $_;
}

Aquí hay un decoder que usa eso:

### Construir un decoder:
$wd = MIME::WordDecoder->new({'US-ASCII'   => 'KEEP',   ### sub { $_[0] }
                              'ISO-8859-1' => \&keep7bit,
                              'ISO-8859-2' => \&keep7bit,
                              'Big5'       => 'WARN',
                              '*'          => 'DIE'));
### Convertir algunos textos MIME a una cadena ASCII pura...
$ascii = $wd->decode('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
### ...que ahora contendrá: "To: Keld J#rn Simonsen <keld>"

El decodificador de UTF-8 convierte todo en una representación interna de Perl, posiblemente activando el flag UTF8 internamente. Usa esto así:

$wd = supported MIME::WordDecoder 'UTF-8';
$perl_string = $wd->decode('To: =?ISO-8859-1?Q?Keld_J=F8rn_Simonsen?= <keld>');
# $perl_string será una cadena válida con el flag UTF8 activado.

Generalmente, deberías usar el decodificador de UTF-8 en lugar de unmime.

INTERFAZ PÚBLICA

default [DECODER]
Método de clase. Obtiene/establece el objeto DECODER por defecto.
supported CHARSET, [DECODER]
Método de clase. Si se da solo CHARSET, devuelve un objeto DECODER que mapea los datos en ese conjunto de caracteres (el conjunto de caracteres se fuerza a mayúsculas). 
$wd = supported MIME::WordDecoder 'ISO-8859-1';

Si se da DECODER, instala tal objeto:

MIME::WordDecoder->supported('ISO-8859-1' =>
                             (new MIME::WordDecoder::ISO_8859 '1'));

No debes sobrescribir este método.

new [\@HANDLERS]
Método de clase, constructor. Si \@HANDLERS se da, entonces \@HANDLERS se pasa a handler() para inicializar el mapa interno.
handler CHARSET=>\&SUBREF, ...
Método de instancia. Establece la subrutina SUBREF para un conjunto de caracteres dado, para tantos pares como quieras.

Cuando se realiza la traducción de un texto MIME codificado, una subrutina dada se invocará cuando se traduzca un bloque de texto en el conjunto de caracteres CHARSET. La subrutina se invocará con los siguientes argumentos:

DATA    - los datos en el conjunto de caracteres dado.
CHARSET - el nombre del conjunto de caracteres en mayúsculas, que puede ser útil si estás usando el mismo SUBREF para múltiples CHARSETs.
DECODER - el decodificador mismo, si contiene información de configuración que tu función de handler necesita.

Por ejemplo:

$wd = new MIME::WordDecoder;
$wd->handler('US-ASCII'   => 'KEEP');
$wd->handler('ISO-8859-1' => \&handle_latin1,
             'ISO-8859-2' => \&handle_latin1,
             '*'          => 'DIE');

Nota que, aunque así como con %SIG, el SUBREF también puede ser tomado de un conjunto especial de palabras clave:

KEEP     Pasar los datos sin cambios.
IGNORE   Ignorar los datos en este conjunto de caracteres, sin aviso.
WARN     Ignorar los datos en este conjunto de caracteres, con aviso.
DIE      Excepción fatalError con mensaje "can't handle character set".

La subrutina para el conjunto de caracteres especial 'raw' se usa para texto no MIME (sin codificación MIME), que es supuestamente ASCII. El handler para 'raw' se comporta por defecto como lo especificado para 'US-ASCII' al momento de la construcción.

La subrutina para el conjunto de caracteres especial '*' se usa para cualquier conjunto de caracteres no reconocido. El comportamiento por defecto para '*' es WARN.

decode STRING
Método de instancia. Decodifica una STRING que puede contener componentes MIME codificados en una representación local (por ejemplo, UTF-8, etc.).
unmime STRING
Función, exportada. Decodifica la STRING dada usando el default() decoder. Ver default().

Deberías considerar usar el decodificador de UTF-8 en lugar de unmime. Este decodifica strings MIME en una representación interna de Perl.

mime_to_perl_string
Función, exportada. Decodifica la STRING dada en una cadena interna Perl Unicode. Deberías usar esta función en preferencia a todas las otras.

El resultado de mime_to_perl_string es probablemente tener el flag UTF8 activado en la cadena Perl.

SUBCLASES

MIME::WordDecoder::ISO_8859
Un simple decoder que mantiene US-ASCII y los caracteres 7-bit de los conjuntos de caracteres ISO-8859, así como los caracteres 8-bit de los conjuntos indicados. También mantiene los caracteres 8-bit de los conjuntos de caracteres indicados. 
### Construir:
$wd = new MIME::WordDecoder::ISO_8859 2;    ### ISO-8859-2
### Qué hacer con caracteres desconocidos (también se puede usar vacío):
### Valor por defecto es '?'.
$wd->unknown('?');
### Collapse runs of unknown characters to a single unknown()?
### Valor por defecto es false.
$wd->collapse(1);

Según http://czyborra.com/charsets/iso8859.html (ca. Noviembre 2000):

ISO 8859 es una serie completa de 10 (y pronto incluso más) conjuntos de caracteres estándar de gráficos multilingües (8bit) para escribir en lenguas alfabéticas:

 1. Latin1 (Europa occidental)
 2. Latin2 (Europa oriental)
 3. Latin3 (Europa sur)
 4. Latin4 (Europa norte)
 5. Cyrillic
 6. Arabic
 7. Greek
 8. Hebrew
 9. Latin5 (Turco)
10. Latin6 (Nordico)

Los conjuntos de caracteres ISO 8859 no son tan completos como el verdadero gran Unicode, pero han estado disponibles y usables por bastante tiempo (primero registrados como charsets para uso con MIME) y ya ofrecieron una mejora significativa sobre el 7bit US-ASCII tradicional.

Los caracteres 0 a 127 son siempre idénticos con US-ASCII, y las posiciones 128 a 159 contienen algunos caracteres de control menos utilizados: los llamados C1 de ISO 6429.

MIME::WordDecoder::US_ASCII
Una subclase del decoder ISO-8859-1 que descarta los 8-bit de los conjuntos de caracteres.

MIME::WordDecoder(3pm) — Perl

NAME

MIME::WordDecoder — Decode MIME encoded "words"

SYNOPSIS

use MIME::WordDecoder;

# object-oriented interface
my $decoder = MIME::WordDecoder->new;
my $decoded_string = $decoder->decode($encoded_string);

# functional interface
my $decoded_string = decode_mime_word($encoded_string);

# using the default decoder instance
my $decoded_string = MIME::WordDecoder::decode($encoded_string);

DESCRIPTION

MIME encoded words are strings that are encoded using base64 or quoted-printable encoding within a MIME message. This module provides a way to decode these strings back into their original form.

The format of a MIME encoded word is:

 =?charset?encoding?encoded_text?=
  • charset is the character set of the encoded text.
  • encoding is either B for base64 or Q for quoted-printable.
  • encoded_text is the actual encoded string.

This module handles multiple encoded words within a single string, as well as automatically detecting the character set and encoding if they are not explicitly specified.

PUBLIC INTERFACE

new()
Creates a new MIME::WordDecoder object. Accepts optional arguments to configure the decoder.
decode( $string )
Decodes the given string, which may contain one or more MIME encoded words. Returns the decoded string.
decode_mime_word( $string )
A functional interface to decode a single MIME encoded word. This is equivalent to calling the decode method on a default decoder instance.
decode( $string )
This is the class method version of decode_mime_word. It uses a default decoder instance.

SUBCLASSES

You can subclass MIME::WordDecoder to customize the decoding process, for example, to handle different character sets or encodings.

If you are dealing with character sets that are not supported by default, you might need to install additional modules like Encode.

Note that for non-ASCII character sets, it's generally recommended to use UTF-8. If your input is not UTF-8, you might want to use ISO-8859-1 or another appropriate encoding.
