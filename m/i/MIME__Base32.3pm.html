NOMBRE

MIME::Base32 - codificador y decodificador Base32

SINOPSIS

#!/usr/bin/env perl
use strict;
use warnings;
use MIME::Base32;
my $encoded = encode_base32('Aladdin: open sesame');
my $decoded = decode_base32($encoded);

DESCRIPCIÓN

Este módulo sirve para codificar/decodificar datos de forma similar a MIME::Base64.

Antes de la versión 1.0, MIME::Base32 utilizaba los métodos de codificación y decodificación "base32hex" (o "[0-9A-V]") por defecto. Si necesita mantener ese comportamiento, por favor, llame directamente a las funciones "encode_base32hex" o "decode_base32hex".

Ahora, de acuerdo con la RFC-3548, Sección 5 https://tools.ietf.org/html/rfc3548#section-5, MIME::Base32 utiliza las funciones "encode_base32" y "decode_base32" por defecto.

FUNCIONES

Se proporcionan las siguientes funciones principales:

decode

Sinónimo de "decode_base32"

decode_rfc3548

Sinónimo de "decode_base32"

decode_base32

my $string = decode_base32($encoded_data);

Decodifica datos codificados de vuelta a una cadena de texto o datos binarios.

decode_09AV

Sinónimo de "decode_base32hex"

decode_base32hex

my $string_or_binary_data = MIME::Base32::decode_base32hex($encoded_data);

Decodifica datos codificados de vuelta a una cadena de texto o datos binarios.

encode

Sinónimo de "encode_base32"

encode_rfc3548

Sinónimo de "encode_base32"

encode_base32

my $encoded = encode_base32("some string");

Codifica una cadena de texto o datos binarios.

encode_09AV

Sinónimo de "encode_base32hex"

encode_base32hex

my $encoded = MIME::Base32::encode_base32hex("some string");

Codifica una cadena de texto o datos binarios. Utiliza el método "hex" (o "[0-9A-V]").
