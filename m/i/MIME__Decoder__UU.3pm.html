MIME::Decoder::UU(3) Documentación Perl aportada por el usuario MIME::Decoder::UU(3)

NOMBRE

MIME::Decoder::UU - decodificar un flujo "uuencoded"

SINOPSIS

Un objeto decodificador genérico; ver MIME::Decoder para el uso.

También soporta un método preamble() para recuperar texto antes de la porción uuencoded del flujo.

DESCRIPCIÓN

Una subclase de MIME::Decoder para una codificación no estándar donde los datos se uuencode. Codificaciones MIME no estándar comunes para esto:

x-uu
x-uuencode

VER TAMBIÉN

MIME::Decoder
