NOMBRE

MIME::Decoder - un objeto para decodificar la parte del cuerpo de un flujo MIME

SINOPSIS

Antes de seguir leyendo, deberías consultar MIME::Tools para asegurarte de que entiendes dónde encaja este módulo en el gran esquema de las cosas. ¡Adelante, hazlo ahora! Esperaré.

¿Listo? Ok...

Decodificando un flujo de datos

Aquí tienes un simple programa filtro para leer datos quoted-printable de STDIN (hasta EOF) y escribir los datos decodificados en STDOUT:

use MIME::Decoder;
$decoder = new MIME::Decoder 'quoted-printable' or die "no soportado";
$decoder->decode(\*STDIN, \*STDOUT);

Codificando un flujo de datos

Aquí tienes un simple programa filtro para leer datos binarios de STDIN (hasta EOF) y escribir datos codificados en base64 en STDOUT:

use MIME::Decoder;
$decoder = new MIME::Decoder 'base64' or die "no soportado";
$decoder->encode(\*STDIN, \*STDOUT);

Codificaciones no estándar

Puedes escribir e instalar tus propios decodificadores para que MIME::Decoder los conozca:

use MyBase64Decoder;
install MyBase64Decoder 'base64';

También puedes probar si una codificación dada es compatible:

if (supported MIME::Decoder 'x-uuencode') {
    ### ¡podemos uuencode!
}

DESCRIPCIÓN

Esta clase abstracta, y sus subclases concretas privadas (ver abajo), proporcionan una interfaz orientada a objetos para las acciones de...

  • Decodificar un flujo codificado en MIME
  • Codificar un flujo de datos crudos en un flujo codificado en MIME.

El constructor de MIME::Decoder toma el nombre de una codificación ("base64", "7bit", etc.), y devuelve una instancia de una subclase de MIME::Decoder cuyo método decode() realizará la acción de decodificación apropiada, y cuyo método encode() realizará la acción de codificación apropiada.

INTERFAZ PÚBLICA

Interfaz estándar

Si solo estás usando esta clase, esto es todo lo que necesitarás...

new CODIFICACIÓN
Método de clase, constructor. Crea y devuelve un nuevo objeto decodificador que puede manejar la CODIFICACIÓN dada. 
my $decoder = new MIME::Decoder "7bit";

Devuelve el valor indefinido si ningún decodificador conocido es apropiado.

best CODIFICACIÓN
Método de clase, constructor. Exactamente igual que new(), excepto que este asigna por defecto cualquier codificación no soportada a "binary", después de generar una advertencia adecuada (es un error fatal si no hay un decodificador binario). 
my $decoder = best MIME::Decoder "x-gzip64";

Devolverá un decodificador o lanzará una excepción fatal.

decode FLJUE_ENTRADA,FLJO_SALIDA
Método de instancia. Decodifica el documento que espera en el manejador de entrada FLUE_ENTRADA, escribiendo la información decodificada en el manejador de salida FLJO_SALIDA.

Lee la sección de este documento sobre manejadores de E/S para más información sobre los argumentos. Ten en cuenta que todavía puedes proporcionar referencias de archivo sin bendecir de estilo antiguo para FLUE_ENTRADA y FLJO_SALIDA.

Devuelve verdadero en caso de éxito, lanza una excepción en caso de fallo.

encode FLJUE_ENTRADA,FLJO_SALIDA
Método de instancia. Codifica el documento que espera en el manejador de archivo de entrada FLUE_ENTRADA, escribiendo la información codificada en el flujo de salida FLJO_SALIDA.

Lee la sección de este documento sobre manejadores de E/S para más información sobre los argumentos. Ten en cuenta que todavía puedes proporcionar referencias de archivo sin bendecir de estilo antiguo para FLUE_ENTRADA y FLJO_SALIDA.

Devuelve verdadero en caso de éxito, lanza una excepción en caso de fallo.

encoding
Método de instancia. Devuelve la codificación para la que se creó este objeto, convertida a minúsculas (por ejemplo, "base64").
head [HEAD]
Método de instancia. Completamente opcional: algunos decodificadores necesitan saber un poco sobre el archivo que están codificando/decodificando; por ejemplo, a x-uu le gusta tener el nombre del archivo. HEAD es cualquier objeto que responda a mensajes como: 
$head->mime_attr('content-disposition.filename');
supported [CODIFICACIÓN]
Método de clase. Con un argumento (un nombre de CODIFICACIÓN), devuelve verdadero si esa codificación es manejada actualmente, y falso en caso contrario. La CODIFICACIÓN se convertirá automáticamente a minúsculas: 
if (supported MIME::Decoder '7BIT') {
    ### sí, podemos manejarlo...
}
else {
    ### retrocede seis y abandona...
}

Sin argumentos, devuelve una referencia a un hash de todos los decodificadores disponibles, donde la clave es el nombre de la codificación (todo en minúsculas, como '7bit'), y el valor es verdadero (es el nombre de la clase que maneja la decodificación, pero probablemente no deberías confiar en eso). Puedes modificar este hash de forma segura; *no* cambiará la forma en que el módulo realiza sus búsquedas. Solo "install" puede hacer eso.

Gracias a Achim Bohnet por sugerir este método.

Interfaz de subclase

Si estás escribiendo (o instalando) una nueva subclase de decodificador, hay algunos otros métodos que necesitarás conocer:

decode_it FLJUE_ENTRADA,FLJO_SALIDA
Método de instancia abstracto. La parte trasera del método decode. Toma un manejador de entrada abierto para lectura (FLUE_ENTRADA), y un manejador de salida abierto para escritura (FLJO_SALIDA).

Si estás escribiendo tu propia subclase de decodificador, debes sobrescribir este método en tu clase. Tu método debe leer del manejador de entrada usando getline() o read(), decodificar esta entrada e imprimir los datos decodificados en el manejador de salida usando print(). Puedes hacerlo como mejor te parezca, siempre que el resultado final sea el mismo.

Ten en cuenta que las referencias sin bendecir y los globrefs se convierten automáticamente en manejadores de E/S para ti mediante decode(), por lo que no necesitas preocuparte por ello.

Tu método debe devolver bien "undef" (para indicar fallo), o 1 (para indicar éxito). También puede lanzar una excepción para indicar fallo.

NOMBRE

MIME::Decoder

SINTAXIS

use MIME::Decoder;

DESCRIPCIÓN

MIME::Decoder es un módulo de Perl que proporciona un decodificador para contenido MIME. Te permite decodificar datos que están codificados en varios formatos, como quoted-printable, base64, y otros.

INTERFACIO DE USO

La interfaz pública de MIME::Decoder incluye métodos para decodificar y codificar datos. Estos métodos se llaman con los argumentos apropiados y devuelven los datos decodificados o codificados.

SUBCLASES DE DECODER

No necesitas "usar" ningún otro módulo de Perl; las siguientes subclases "estándar" se incluyen como parte de MIME::Decoder:

Clase:                         Maneja codificaciones:
------------------------------------------------------------
MIME::Decoder::Binary          binary
MIME::Decoder::NBit            7bit, 8bit
MIME::Decoder::Base64          base64
MIME::Decoder::QuotedPrint     quoted-printable

Las siguientes subclases "no estándar" también se incluyen:

Clase:                         Maneja codificaciones:
------------------------------------------------------------
MIME::Decoder::UU              x-uu, x-uuencode
MIME::Decoder::Gzip64          x-gzip64            ** ¡requiere gzip!

NOTAS

Manejo de entrada/salida

A partir de MIME-tools 2.0, esta clase tiene que funcionar bien con la nueva clase MIME::Body... lo que significa que las rutinas de entrada y salida no pueden simplemente asumir que están tratando con manejadores de archivos.

Por lo tanto, todo lo que MIME::Decoder y sus subclases requieren (y, por lo tanto, todo lo que pueden asumir) es que INSTREAMs y OUTSTREAMs sean objetos que respondan a un subconjunto de los mensajes definidos en la interfaz IO::Handle; como mínimo:

print
getline
read(BUF,NBYTES)

Gracias a Achim Bohnet por sugerir este modelo de E/S más genérico.

Escribir un decodificador

Si estás experimentando con tus propias codificaciones, probablemente querrás escribir un decodificador. Aquí tienes lo básico:

1.
Crea un módulo, como "MyDecoder::", para tu decodificador. Decláralo como una subclase de MIME::Decoder.
2.
Crea los siguientes métodos de instancia en tu clase, como se describe anteriormente:
decode_it
encode_it
init
3.
En tu programa de aplicación, activa tu decodificador para una o más codificaciones de esta manera:
require MyDecoder;
install MyDecoder "7bit";   ### usa MyDecoder para decodificar "7bit"
install MyDecoder "x-foo";  ### usa también MyDecoder para decodificar "x-foo"

Para ilustrar, aquí tienes una clase decodificadora personalizada para la codificación "quoted-printable":

package MyQPDecoder;
@ISA = qw(MIME::Decoder);
use MIME::Decoder;
use MIME::QuotedPrint;
### decode_it - el método de decodificación privado
sub decode_it {
    my ($self, $in, $out) = @_;
    local $_;
    while (defined($_ = $in->getline)) {
        my $decoded = decode_qp($_);
        $out->print($decoded);
    }
    1;
}
### encode_it - el método de codificación privado
sub encode_it {
    my ($self, $in, $out) = @_;
    my ($buf, $nread) = ('', 0);
    while ($in->read($buf, 60)) {
        my $encoded = encode_qp($buf);
        $out->print($encoded);
    }
    1;
}

Eso es todo. La tarea fue bastante simple porque la codificación "quoted-printable" se puede convertir fácilmente línea por línea... al igual que incluso "7bit" y "8bit" (ya que todas estas codificaciones garantizan líneas cortas, con un máximo de 1000 caracteres). La buena noticia es que es muy probable que sea igualmente fácil escribir un MIME::Decoder para cualquier codificación estándar futura.

El decodificador "binary", sin embargo, realmente requirió lecturas y escrituras por bloques: consulta "MIME::Decoder::Binary" para obtener detalles.
