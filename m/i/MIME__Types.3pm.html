Nombre

MIME::Types - Definición de tipos MIME

Herencia

MIME::Types
  es un Exporter

SINTAXIS

use MIME::Types;
my $mt    = MIME::Types->new(...);    # Objeto MIME::Types
my $type  = $mt->type('text/plain');  # Objeto MIME::Type
my $type  = $mt->mimeTypeOf('gif');
my $type  = $mt->mimeTypeOf('picture.jpg');
my @types = $mt->httpAccept('text/html, application/json;q=0.1')

DESCRIPCIÓN

"Tipo MIME" es el antiguo nombre de "Tipo de Medio". Este módulo data de 1999 y los cambios de nombre son dolorosos, así que nos quedamos con el nombre original.

Los tipos de medios se usan en muchas aplicaciones (por ejemplo, como parte de correos electrónicos y tráfico HTTP) para indicar el tipo de contenido que se transmite o espera. Lea RFC6838 https://www.rfc-editor.org/rfc/rfc6838 (registros) y RFC9694 https://www.rfc-editor.org/rfc/rfc9694 (niveles superiores) para la especificación.

A veces se necesita una gran cantidad de conocimiento sobre un tipo MIME, pero este módulo solo conoce las extensiones de archivos que se relacionan con algunos tipo de archivo. También puede usarse para producir el formato correcto: tipos que no estén registrados en IANA deben usar prefijos 'x-'.

Este objeto administra una lista muy larga de tipos conocidos, combinada de varios orígenes. Por ejemplo, contiene todos los tipos de IANA y la conocida de Apache. Probablemente es la tabla más completa del mundo!

MIME::Types y robots (fork)

Si tu programa usa fork (normalmente para un daemon), entonces quieres tener la tabla de tipos inicializada antes de que empieces a forjar. Así que, primero llama

my $mt = MIME::Types->new;

Luego, cada vez que creates esta objeto (puedes, de hecho, también reutilizar el objeto que creamos aquí) obtendrás acceso al mismo tabla global de tipos.

MÉTODOS

Constructores

$class->new(%options)
Crea un objeto "MIME::Types" que gestiona los datos. En la implementación actual, no importa si creas este objeto muchas veces dentro de tu programa, pero en el futuro esto puede cambiar.
db_file => FILENAME
Ubicación de la base de datos que contiene la información de tipos. Solo la primera vez que instancias este objeto, se le aplicará este parámetro. [2.10] Este parámetro puede ser sobrescrito globalmente mediante el entorno de variable "PERL_MIME_TYPE_DB", que puede ser necesario en casos de PAR o instalaciones complicadas. Para PAR, probablemente debes establecer este variable en "inc/lib/MIME/types.db"
only_complete => BOOLEAN
Único incluye definiciones completas de tipos MIME: requiere al menos una extensión conocida. Esto reducirá el número de entradas - y así el consumo de memoria - considerablemente.
only_iana => BOOLEAN
Único carga los tipos que están actualmente conocidos por IANA.
skip_extensions => BOOLEAN
Evita cargar la tabla para mapear extensiones a tipos, que es bastante grande.

Conocimiento

$obj->addType($type, ...)
Añade uno o más tipos MIME a la lista de tipos conocidos. Cada tipo es un "MIME::Type", que debe ser experimental: debe comenzar con "x-", sea el tipo principal o el subtipo.
$obj->extensions()
Devuelve una lista de todas las extensiones definidas.
$obj->listTypes()
Devuelve una lista de todos los tipos MIME por nombre. Este no instanciará objetos "MIME::Type". Ve types()
$obj->mimeTypeOf($filename)
Devuelve el objeto "MIME::Type" que corresponde al archivo FILENAME (o simplemente su extensión) o "undef" si el tipo del archivo es desconocido. La extensión se usa y se considera en mayúsculas.
$obj->type($string)
Devuelve el "MIME::Type" que describe el tipo relacionado con STRING. [2.00] Solo devolverá un tipo.
$obj->types()
Devuelve una lista de todos los tipos MIME definidos. Para compatibilidad con el pasado, este devolverá objetos "MIME::Type", que se devolverán. Ve listTypes().

Soporte HTTP

$obj->httpAccept($header)
[2.07] Descompone un típico encabezado HTTP-Accept y lo ordena según la información de prioridad incluida. Devuelve una lista ordenada de tipos, donde el tipo de prioridad más alta es el primero. La lista puede contener '*'/* (aceptar cualquier) o '*' como subtipo.
$obj->httpAcceptBest($accept|\@types, @have)
[2.07] El string $accept se procesa mediante httpAccept() para ordenar los tipos según la prioridad. También puedes pasar una lista de tipos ordenados @types que podrían haber resultado de este método, llamado previamente.
$obj->httpAcceptSelect($accept|\@types, @filenames|\@filenames)
[2.07] Como httpAcceptBest(), pero ahora no devolverá un par con el tipo y el nombre de archivo, sino solo el tipo. Si $accept es undef, devuelve el primer nombre de archivo.

ejemplo:

use HTTP::Status ':constants';
use File::Glob   'bsd_glob';    # comprensión de nombres con espacios en blanco
my @filenames   = bsd_glob "$imagedir/$fnbase.*;
my $accept      = $req->header('Accept');
my ($fn, $mime) = $mt->http

NOMBRE

MIME::Types - Gestor de tipos MIME para Perl

HERENCIA

No hay herencia.

SINOPSIS

use MIME::Types;
my $mime_types = MIME::Types->new();
my $mime_type  = $mime_types->mimeTypeOf('html');
print $mime_type->type;       # text/html
print $mime_type->subType;    # html
print $mime_type->encoding;   # 8bit
print $mime_type->icon;       # html.gif
my $mime_type  = $mime_types->mimeType('application/x-some-thing');
my @types      = $mime_types->typeOf('image'); # all image/*
my @types      = $mime_types->typeOf('image/png');
my @types      = $mime_types->typeOf('/\.png$/i'); # by regex
my @types      = $mime_types->find_type(filename => 'photo.png');
my @types      = $mime_types->find_type(suffix => 'png');
my @types      = $mime_types->find_type(type => 'image/png');
my @types      = $mime_types->find_type(type => 'image');
my @types      = $mime_types->find_type(type => qr/image\//i);
my $refdata    = $mime_types->lookup('png');
print $refdata->[0]; # text/html
print $refdata->[1]; # html
print $refdata->[2]; # 8bit
my $refdata    = $mime_types->lookup('html');
my $refdata    = $mime_types->lookup('application/octet-stream');
$mime_types->add_type(type => 'application/x-new-type', suffix => 'new', encoding => '7bit');
my $added_type = $mime_types->mimeTypeOf('new');
print $added_type->type; # application/x-new-type
my $add_ref    = $mime_types->add_type(type => 'application/x-another-new-type', suffix => 'anew');
my $refdata    = $mime_types->lookup('anew');
print $refdata->[0]; # application/x-another-new-type
my $accept     = MIME::Types::Accept->new();
my $code       = $accept->AcceptSelect($mime_types, 'text/html');
my $code       = $accept->AcceptSelect($mime_types, ['text/html', 'image/gif']);
my $code       = $accept->AcceptSelect($mime_types, ['text/html', 'image/gif'], 'image/png');
my $code       = $accept->AcceptSelect($mime_types, ['text/html', 'image/gif'], ['image/png', 'image/jpeg']);
my $code       = $accept->AcceptSelect($mime_types, ['text/html', 'image/gif'], ['image/png', 'image/jpeg'], '/\.gif$/');
my $code       = $accept->AcceptSelect($mime_types, ['text/html', 'image/gif'], ['image/png', 'image/jpeg'], qr/gif$/);
my @filenames  = $mime_types->select(@types);
my $code       = MIME::Types::Accept->AcceptSelect($accept, @filenames);
my $code       = defined $mime ? HTTP_NOT_ACCEPTABLE : HTTP_OK;

MÉTODOS

new( OPTIONS )
Crea e inicializa un nuevo objeto MIME::Types. Los OPTIONS son pares clave/valor que se pasan directamente al método add_type. Si no se especifican OPTIONS, se cargan todos los tipos MIME estándar.
add_type( TYPE => TYPE, SUFFIX => SUFFIX, ENCODING => ENCODING )
Añade un nuevo tipo MIME. Los argumentos son los mismos que los devueltos por lookup.
mimeTypeOf( SUFFIX )
Devuelve un objeto MIME::Type para el sufijo dado. Si no se encuentra, devuelve undef.
mimeType( TYPE )
Devuelve un objeto MIME::Type para el tipo MIME dado. El argumento TYPE puede ser un tipo completo (ej. text/html) o una expresión regular para buscar en todos los tipos.
typeOf( TYPE )
Devuelve una lista de objetos MIME::Type que coinciden con el argumento TYPE. TYPE puede ser un tipo MIME completo (ej. text/html), un tipo parcial (ej. image), o una expresión regular.
find_type( OPTIONS )
Similar a typeOf, pero acepta varias opciones para la búsqueda:
  • filename: Nombre de archivo completo.
  • suffix: Sufijo del nombre de archivo.
  • type: Tipo MIME (completo, parcial o regex).

Ejemplo:

my @types = $mime_types->find_type(suffix => 'png');
my @types = $mime_types->find_type(type => qr/image\//i);
lookup( SUFFIX )
Busca un tipo MIME por su sufijo y devuelve una referencia a un array de tres elementos: el tipo MIME, el subtipo y la codificación. Devuelve undef si no se encuentra.
select( TYPES )
Dada una lista de tipos MIME (objetos MIME::Type), devuelve una lista de sufijos de nombre de archivo correspondientes.

CLASES RELACIONADAS

MIME::Type
Representa un único tipo MIME.
MIME::Types::Accept
Maneja la cabecera HTTP Accept.

El método AcceptSelect de la clase MIME::Types::Accept se utiliza para determinar si un conjunto de tipos MIME es aceptable según los criterios especificados.

use MIME::Types::Accept;
my $accept = MIME::Types::Accept->new();
my $code = $accept->AcceptSelect($mime_types, $mime_type_request, $mime_type_accept, $suffix_regex);

Los argumentos son:

  • $mime_types: Un objeto MIME::Types.
  • $mime_type_request: El tipo MIME solicitado.
  • $mime_type_accept: Los tipos MIME aceptables.
  • $suffix_regex: Una expresión regular para los sufijos de archivo.

El valor de retorno $code indica el resultado de la comparación:

  • HTTP_OK (200): El tipo MIME solicitado es aceptable.
  • HTTP_NOT_ACCEPTABLE (406): El tipo MIME solicitado no es aceptable.

También hay funciones compatibles con versiones anteriores de MIME::Types.

use MIME::Types qw(by_suffix by_mediatype);
my ($mediatype, $encoding) = by_suffix('image.gif');
my $refdata = by_suffix('image.gif');
my ($mediatype, $encoding) = @$refdata;

La función import_mime_types ha sido eliminada.
