Excepciones y finalización

val try_finally : ?always:(unit -> unit) -> ?exceptionally:(unit -> unit) -> (unit -> 'a) -> 'a

try_finally work ~always ~exceptionally está diseñado para ejecutar código en work que puede fallar con una excepción, y tiene dos tipos de rutinas de limpieza: always, que debe ejecutarse después de cualquier ejecución de la función (típicamente, liberando recursos del sistema), y exceptionally, que solo debe ejecutarse si work o always fallaron con una excepción (típicamente, deshaciendo cambios visibles por el usuario que solo tendrían sentido si la función se completa correctamente). Por ejemplo:

      let objfile = outputprefix ^ ".cmo" in
      let oc = open_out_bin objfile in
      Misc.try_finally
        (fun () ->
           bytecode
           ++ Timings.(accumulate_time (Generate sourcefile))
               (Emitcode.to_file oc modulename objfile);
           Warnings.check_fatal ())
        ~always:(fun () -> close_out oc)
        ~exceptionally:(fun _exn -> remove_file objfile);

Si exceptionally falla con una excepción, se propaga como de costumbre.

Si always o exceptionally usan excepciones internamente para el flujo de control pero no lanzan, entonces try_finally se cuida de preservar cualquier rastro de excepción proveniente de work o always para facilitar la depuración.

val reraise_preserving_backtrace : exn -> (unit -> unit) -> 'a

reraise_preserving_backtrace e f es (f (); raise e) excepto que el rastro de pila actual se preserva, incluso si f usa excepciones internamente.

Operaciones con listas

val map_end : ('a -> 'b) -> 'a list -> 'b list -> 'b list

map_end f l t es map f l @ t, solo que más eficiente.

val rev_map_end : ('a -> 'b) -> 'a list -> 'b list -> 'b list

map_end f l t es map f (rev l) @ t, solo que más eficiente.

val map_left_right : ('a -> 'b) -> 'a list -> 'b list

Similar a List.map, con orden de evaluación garantizado de izquierda a derecha.

val for_all2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Igual que List.for_all pero para un predicado binario. Además, este for_all2 nunca falla: dadas dos listas de longitudes diferentes, devuelve falso.

val replicate_list : 'a -> int -> 'a list

replicate_list elem n es la lista con n elementos todos idénticos a elem.

val list_remove : 'a -> 'a list -> 'a list

val split_last : 'a list -> 'a list * 'a

Devuelve el último elemento y los demás elementos de la lista dada.

val repeated_label : (string option * 'a) list -> string option

Detecta una etiqueta repetida - para usar con tuplas etiquetadas.

Operaciones con archivos y rutas de archivos

val find_in_path : string list -> string -> string

Busca un archivo en una lista de directorios.

val find_in_path_rel : string list -> string -> string

Busca un archivo relativo en una lista de directorios.

val normalized_unit_filename : string -> (string, string) Result.t

Normaliza el nombre del archivo Foo.ml a foo.ml, usando NFC y plegado de mayúsculas/minúsculas. Devuelve Error si la entrada no es una secuencia de bytes utf-8 válida.

val find_in_path_normalized : string list -> string -> string

Igual que Misc.find_in_path_rel, pero también busca el nombre de archivo de unidad normalizado, es decir, si el nombre es Foo.ml, permite que /path/Foo.ml y /path/foo.ml coincidan.

val remove_file : string -> unit

Elimina el archivo dado si existe y es un archivo regular. No hace nada para otros tipos de archivos. Nunca lanza un error.

val expand_directory : string -> string -> string

expand_directory alt file expande eventualmente un + al principio del archivo en alt (un directorio raíz alternativo).

val split_path_contents : ?sep:char -> string -> string list

split_path_contents ?sep s interpreta s como el valor de una variable tipo "PATH" y devuelve la lista correspondiente de directorios. s se divide usando el delimitador específico de la plataforma, o ~sep si se pasa.

Devuelve la lista vacía si s está vacía.

val copy_file : in_channel -> out_channel -> unit

copy_file ic oc lee el contenido del archivo ic y lo copia a oc. Se detiene al encontrar EOF en ic.

val copy_file_chunk : in_channel -> out_channel -> int -> unit

copy_file_chunk ic oc n lee n bytes de ic y los copia a oc. Lanza End_of_file al encontrar EOF en ic.

val string_of_file : in_channel -> string

string_of_file ic lee el contenido del archivo ic y lo copia a una cadena. Se detiene al encontrar EOF en ic.

val output_to_file_via_temporary : ?mode:open_flag list -> string -> (string -> out_channel -> 'a) -> 'a

Produce salida en un archivo temporal, luego lo renombra (tan atmicamente como sea posible) al nombre de archivo de salida deseado. output_to_file_via_temporary filename fn abre un archivo temporal que se pasa a fn (nombre + canal de salida). Cuando fn devuelve, el canal se cierra y el archivo temporal se renombra a filename.

val protect_writing_to_file : filename:string -> f:(out_channel -> 'a) -> 'a

Abre el filename dado para escritura (en modo binario), pasa el out_channel a la función dada, luego cierra el canal. Si la función lanza una excepción, entonces se eliminará filename.

val find_first_mono : (int -> bool) -> int

find_first_mono p toma un predicado entero p : int -> bool que asumimos: 1. es monótono en números naturales: si a <= b entonces p a implica p b , 2. se satisface para algunos números naturales en el rango 0; max_int (esto es equivalente a: p max_int = true ).

find_first_mono p es el número natural más pequeño N que satisface p , calculado en O(log(N)) llamadas a p .

Nuestra implementación soporta dos casos en los que las precondiciones sobre p no se respetan:

- Si p es siempre false , devolvemos silenciosamente max_int en lugar de entrar en un bucle o fallar.

- Si p no es monótono pero eventualmente es verdadero, devolvemos algún valor que lo satisface.

Operaciones de cadena

val search_substring : string -> string -> int -> int

search_substring pat str start devuelve la posición de la primera ocurrencia de la cadena pat en la cadena str . La búsqueda comienza en el desplazamiento start en str . Lanza Not_found si pat no ocurre.

val replace_substring : before:string -> after:string -> string -> string

replace_substring ~before ~after str reemplaza todas las ocurrencias de before con after en str y devuelve la cadena resultante.

val rev_split_words : string -> string list

rev_split_words s divide s en palabras separadas por espacios en blanco y devuelve la lista de palabras en orden inverso.

val cut_at : string -> char -> string * string

String.cut_at s c devuelve un par que contiene la subcadena antes de la primera ocurrencia de c en s , y la subcadena después de la primera ocurrencia de c en s . let (before, after) = String.cut_at s c in
before ^ String.make 1 c ^ after es la identidad si s contiene c .

Lanza Not_found si el carácter no aparece en la cadena

Since 4.01

val ordinal_suffix : int -> string

ordinal_suffix n es el sufijo apropiado para agregar al numeral n como número ordinal: 1 -> "st" , 2 -> "nd" , 3 -> "rd" , 4 -> "th" , y así sucesivamente. Maneja números más grandes (por ejemplo, 42 -> "nd" ) y los números 11--13 (que todos obtienen "th" ) correctamente.

val normalise_eol : string -> string

normalise_eol s devuelve una copia nueva de s con los caracteres '\r' eliminados. Previsto para preprocesar texto que se imprimirá posteriormente en un canal que realiza transformaciones de EOL (es decir, Windows)

val delete_eol_spaces : string -> string

delete_eol_spaces s devuelve una copia nueva de s con los espacios finales de línea eliminados. Previsto para normalizar la salida del toplevel para pruebas.

Operaciones en referencias

type ref_and_value =
| R : 'a ref * 'a -> ref_and_value

val protect_refs : ref_and_value list -> (unit -> 'a) -> 'a

protect_refs l f establece temporalmente r a v para cada R (r, v) en l mientras ejecuta f . El contenido anterior de las referencias se restaura incluso si f lanza una excepción, sin alterar la traza de la excepción.

val get_ref : 'a list ref -> 'a list

get_ref lr devuelve el contenido de la referencia de lista lr y restablece su contenido a la lista vacía.

val set_or_ignore : ('a -> 'b option) -> 'b option ref -> 'a -> unit

set_or_ignore f opt x establece opt a f x si devuelve Some _ , o lo deja sin modificar si devuelve None .

Corrección ortográfica y sugerencias de ``quizás querías decir''

val edit_distance : string -> string -> int -> int option

edit_distance a b cutoff calcula la distancia de edición entre las cadenas a y b . Para ayudar a la eficiencia, utiliza un límite: si la distancia d es menor que cutoff , devuelve Some d , de lo contrario None .

El algoritmo de distancia utilizado actualmente es Damerau-Levenshtein: calcula el número de inserciones, eliminaciones, sustituciones de letras o intercambios de letras adyacentes para pasar de una palabra a la otra. El algoritmo específico puede cambiar en el futuro.

val spellcheck : string list -> string -> string list

spellcheck env name toma una lista de nombres env que existen en el entorno actual y un name erróneo, y devuelve una lista de sugerencias tomadas de env , que están lo suficientemente cerca de name como para que pueda ser un error tipográfico de uno de ellos.

val align_hint : prefix:string -> main:Format_doc.t -> hint:Format_doc.t -> Format_doc.t * Format_doc.t

aligned_hint main hint alinea verticalmente un mensaje main y un mensaje de pista hint . La alineación vertical se controla mediante el uso de cajas @{<ralign> ...
@}: el inicio de una caja, ya sea en la pista o en el mensaje principal, se desplazará hacia la izquierda para garantizar que el final de las dos cajas estén alineadas verticalmente, teniendo en cuenta un prefix preexistente antes del mensaje principal. Por ejemplo,

let main, sub =
  align_hint
    ~prefix:"Error: "
    (doc_printf "@{<ralign>The value @}%a is not an instance variable"
      Style.inline_code "foobar"
    )
    (doc_printf
      "@{<ralign>Did you mean @}%a" Style.inline_code "foobaz"
    ) in
   printf "Error: %a%a" pp_doc main pp_doc sub

produce el siguiente texto:

Error:   The value "foobaz" is not an instance variable
Hint: Did you mean "foobar"?

donde el mensaje principal se ha desplazado hacia la izquierda para alinear "foobaz" y "foobar" .

val align_error_hint : main:Format_doc.t -> hint:Format_doc.t -> Format_doc.t * Format_doc.t

Igual que align_hint ~prefix:"Error: "

val aligned_hint : prefix:string -> Format_doc.formatter -> ('a, Format_doc.formatter, unit, Format_doc.t option -> unit) format4 -> 'a

aligned_hint ~prefix fmt ... hint alinea la pista potencial con el mensaje de error principal generado por la cadena de formato fmt antes de imprimir los dos mensajes.

val did_you_mean : ?pp:string Format_doc.printer -> string list -> Format_doc.t option

did_you_mean ~pp choices sugiere que el usuario puede haber querido decir una de las opciones en choices .

Cada elección se imprime con la función pp , o con Style.inline_code si pp = None .
