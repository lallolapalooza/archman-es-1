: sig end

type t = string

val normalize : string -> (t, t) Result.t

Normaliza la cadena codificada en UTF-8 dada. Las secuencias UTF-8 inválidas resultan en un error y se reemplazan por U+FFFD. Los caracteres identificadores se ponen en forma normalizada NFC. Otros caracteres Unicode se dejan sin cambios.

val capitalize : string -> (t, t) Result.t

Similar a normalize, pero si la cadena comienza con un carácter identificador en minúscula, se reemplaza por el carácter en mayúscula correspondiente. Los caracteres subsiguientes no se cambian.

val uncapitalize : string -> (t, t) Result.t

Similar a normalize, pero si la cadena comienza con un carácter identificador en mayúscula, se reemplaza por el carácter en minúscula correspondiente. Los caracteres subsiguientes no se cambian.

val is_capitalized : t -> bool

Devuelve true si la cadena normalizada dada comienza con un carácter identificador en mayúscula, false en caso contrario. Puede devolver resultados incorrectos si la cadena no está normalizada.

val is_valid_identifier : t -> bool

Comprueba si la cadena normalizada dada es un identificador OCaml válido:

-todos los caracteres son caracteres identificadores

-no comienza con un dígito o una comilla simple

val is_lowercase : t -> bool

Devuelve true si la cadena normalizada dada solo contiene caracteres identificadores en minúscula, false en caso contrario. Puede devolver resultados incorrectos si la cadena no está normalizada.

type validation_result =
| Valid
| Invalid_character of Uchar.t
(* Carácter no permitido
*)
| Invalid_beginning of Uchar.t
(* Carácter no permitido como primer carácter
*)

val validate_identifier : ?with_dot:bool -> t -> validation_result

Similar a is_valid_identifier, pero devuelve un código de error más detallado. Se pueden permitir puntos para extender el soporte a identificadores similares a rutas.

val starts_like_a_valid_identifier : t -> bool

Comprueba si la cadena normalizada dada comienza con un carácter identificador que no sea un dígito o una comilla simple. Los caracteres subsiguientes no se comprueban.
