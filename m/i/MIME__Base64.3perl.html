NOMBRE

MIME::Base64 - Codificación y decodificación de cadenas base64

SINOPSIS

use MIME::Base64;
$codificado = encode_base64('Aladdin:open sesame');
$decodificado = decode_base64($codificado);

DESCRIPCIÓN

Este módulo proporciona funciones para codificar y decodificar cadenas hacia y desde la codificación base64 especificada en RFC 2045 - *MIME (Multipurpose Internet* *Mail Extensions)*. La codificación base64 está diseñada para representar secuencias arbitrarias de octetos en un formato que no necesita ser legible por humanos. Se utiliza un subconjunto de 65 caracteres ([A-Za-z0-9+/=]) de US-ASCII, lo que permite representar 6 bits por carácter imprimible.

Se proporcionan las siguientes funciones principales:

encode_base64( $bytes )
encode_base64( $bytes, $eol );
Codifica datos llamando a la función encode_base64(). El primer argumento es la cadena de bytes a codificar. El segundo argumento es la secuencia de fin de línea a usar. Es opcional y por defecto es "\n". La cadena codificada devuelta se divide en líneas de no más de 76 caracteres cada una y terminará con $eol a menos que esté vacía. Pase una cadena vacía como segundo argumento si no desea que la cadena codificada se divida en líneas.

La función fallará con "Wide character in subroutine entry" si $bytes contiene caracteres con códigos superiores a 255. La codificación base64 solo está definida para caracteres de un solo byte. Utilice el módulo Encode para seleccionar la codificación de bytes que desee.

decode_base64( $str )
Decodifica una cadena base64 llamando a la función decode_base64(). Esta función toma un solo argumento que es la cadena a decodificar y devuelve los datos decodificados.

Cualquier carácter que no forme parte del subconjunto de 65 caracteres base64 se ignora silenciosamente. Los caracteres que ocurren después de un carácter de relleno '=' nunca se decodifican.

Si prefiere no importar estas rutinas a su espacio de nombres, puede llamarlas como:

use MIME::Base64 ();
$codificado = MIME::Base64::encode($decodificado);
$decodificado = MIME::Base64::decode($codificado);

Funciones adicionales no exportadas por defecto:

encode_base64url( $bytes )
decode_base64url( $str )
Codifica y decodifica según el esquema base64 para "aplicaciones URL" [1]. Esta es una variante de la codificación base64 que no usa relleno, no divide la cadena en múltiples líneas y utiliza los caracteres "-" y "_" en lugar de "+" y "/" para evitar el uso de caracteres reservados de URL.
encoded_base64_length( $bytes )
encoded_base64_length( $bytes, $eol )
Devuelve la longitud que tendría la cadena codificada sin codificarla realmente. Esto devolverá el mismo valor que "length(encode_base64($bytes))", pero debería ser más eficiente.
decoded_base64_length( $str )
Devuelve la longitud que tendría la cadena decodificada sin decodificarla realmente. Esto devolverá el mismo valor que "length(decode_base64($str))", pero debería ser más eficiente.

EJEMPLOS

Si desea codificar un archivo grande, debe codificarlo en fragmentos que sean múltiplos de 57 bytes. Esto asegura que las líneas base64 se alineen y que no termine con relleno en el medio. 57 bytes de datos llenan una línea base64 completa (76 == 57*4/3):

use MIME::Base64 qw(encode_base64);
open(FILE, "/var/log/wtmp") or die "$!";
while (read(FILE, $buf, 60*57)) {
    print encode_base64($buf);
}

o si sabe que tiene suficiente memoria

use MIME::Base64 qw(encode_base64);
local($/) = undef;  # slurp
print encode_base64(<STDIN>);

El mismo enfoque como línea de comandos:

perl -MMIME::Base64 -0777 -ne 'print encode_base64($_)' <archivo

La decodificación no necesita modo slurp si cada línea contiene un múltiplo de cuatro caracteres base64:

perl -MMIME::Base64 -ne 'print decode_base64($_)' <archivo

Perl v5.8 y superiores permiten caracteres Unicode extendidos en cadenas. Dichas cadenas no se pueden codificar directamente, ya que la codificación base64 solo está definida para caracteres de un solo byte. La solución es usar el módulo Encode para seleccionar la codificación de bytes que desee. Por ejemplo:

use MIME::Base64 qw(encode_base64);
use Encode qw(encode);
$codificado = encode_base64(encode("UTF-8", "\x{FFFF}\n"));
print $codificado;
