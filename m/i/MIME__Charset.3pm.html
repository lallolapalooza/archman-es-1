NOMBRE

MIME::Charset - Información sobre los códigos de caracteres para MIME

SINOPSIS

use MIME::Charset:
$charset = MIME::Charset->new("euc-jp");

Obtener información sobre códigos de caracteres:

$benc = $charset->body_encoding; # e.g. "Q"
$cset = $charset->as_string; # e.g. "US-ASCII"
$henc = $charset->header_encoding; # e.g. "S"
$cset = $charset->output_charset; # e.g. "ISO-2022-JP"

Traducir datos de texto:

$linea = "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef";
($text, $charset, $encoding) =
    $charset->header_encode(
       $linea,
       Charset => 'euc-jp');
# ...devuelve e.g. (<convertido>, "ISO-2022-JP", "B").
$linea = "Collectioneur path\xe9tiquement ".
         "\xe9clectique de d\xe9chets";
($text, $charset, $encoding) =
    $charset->body_encode(
        $linea,
        Charset => 'latin1');
# ...devuelve e.g. (<original>, "ISO-8859-1", "QUOTED-PRINTABLE").
$len = $charset->encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e",
    Charset => 'utf-8',
    Encoding => "b");
# ...devuelve e.g. 28.

Manipular los valores por defecto de la librería:

MIME::Charset::alias("csEUCKR", "euc-kr");
MIME::Charset::default("iso-8859-1");
MIME::Charset::fallback("us-ascii");

Funciones no OO (podrían ser obsoletas en un futuro cercano):

use MIME::Charset qw(:info);
$benc = body_encoding("iso-8859-2"); # "Q"
$cset = canonical_charset("ANSI X3.4-1968"); # "US-ASCII"
$henc = header_encoding("utf-8"); # "S"
$cset = output_charset("shift_jis"); # "ISO-2022-JP"
use MIME::Charset qw(:trans);
$linea = "\xc9\xc2\xc5\xaa\xc0\xde\xc3\xef\xc5\xaa".
       "\xc7\xd1\xca\xaa\xbd\xd0\xce\xcf\xb4\xef";
($text, $charset, $encoding) =
    header_encode(
       $linea,
       "euc-jp");
# ...devuelve (<convertido>, "ISO-2022-JP", "B").
$linea = "Collectioneur path\xe9tiquement ".
         "\xe9clectique de d\xe9chets";
($text, $charset, $encoding) =
    body_encode(
        $linea,
        "latin1");
# ...devuelve (<original>, "ISO-8859-1", "QUOTED-PRINTABLE");
$len = encoded_header_len(
    "Perl\xe8\xa8\x80\xe8\xaa\x9e", "b", "utf-8"); # 28

DESCRIPCIÓN

MIME::Charset proporciona información sobre los códigos de caracteres utilizados en mensajes MIME de Internet.

Definiciones

El charset es un «código de caracteres» utilizado en MIME para referirse a un método de convertir una secuencia de octetos en una secuencia de caracteres. Incluye tanto conceptos de «código de caracteres» (CCS) como de «esquema de codificación» (CES) de ISO/IEC.

El encoding es el método utilizado en MIME para referirse a la representación de un cuerpo de mensaje o cuerpo de cabecera como secuencias de caracteres imprimibles de US-ASCII.

Constructor

$charset = MIME::Charset->new([CHARSET [, OPTS]])
Crear un objeto de tipo charset.

OPTS puede aceptar los siguientes pares clave-valor. **NOTA:** Cuando el soporte a Unicode/multibyte esté desactivado (ver "USE_ENCODE"), la conversión no se realizará. Por lo tanto, estas opciones no tendrán efectos.

Mapping => MAPTYPE
¿Se extienden los mapeos utilizados para los nombres de charset o no? "EXTENDED" usa mapeos extendidos. "STANDARD" usa mapeos estandarizados estrictos. El valor por defecto es "EXTENDED".

Obtener información de códigos de caracteres

$charset->body_encoding
body_encoding CHARSET
Obtener el tipo de codificación recomendado para el cuerpo del mensaje para CHARSET. El valor devuelto será uno de "B" (BASE64), "Q" (QUOTED-PRINTABLE), "S" (el menor de ambos) o "undef" (no transferido; 7BIT o 8BIT). Esto no será siempre el mismo que el tipo de codificación para el encabezado del mensaje.
$charset->as_string
canonical_charset CHARSET
Obtener el nombre canónico de un charset.
$charset->decoder
Obtener el objeto "Encode::Encoding" para decodificar cadenas en Unicode mediante el charset. Si el charset no se especifica o no es reconocido por esta librería, se devolverá undef.
$charset->dup
Obtener una copia del objeto de charset.
$charset->encoder([CHARSET])
Obtener el objeto "Encode::Encoding" para codificar una cadena de Unicode usando el charset recomendado para mensajes en Internet.

Si se especifica un CHARSET opcional, reemplazará el codificador (y el nombre del charset de salida) del objeto $charset con los de CHARSET, por lo tanto, el objeto $charset se convertirá entre el charset original y el nuevo CHARSET.

$charset->header_encoding
header_encoding CHARSET
Obtener el esquema de codificación recomendado para el encabezado del mensaje de CHARSET. El valor devuelto será uno de "B", "Q", "S" (el menor de ambos) o "undef" (no codificado). Esto no será siempre el mismo que el tipo de codificación para el cuerpo del mensaje.
$charset->output_charset
output_charset CHARSET
Obtener un charset compatible con el CHARSET dado y recomendado para mensajes MIME en Internet (si es conocido por esta librería).

Cuando el soporte a Unicode/multibyte esté desactivado (ver "USE_ENCODE"), esta función devolverá simplemente el resultado de "canonical_charset".

Traducir datos de texto

$charset->body_encode(STRING [, OPTS])
body_encode STRING, CHARSET [, OPTS]
Obtener los datos convertidos (si es necesario) y el tipo de codificación recomendada para el cuerpo del mensaje de STRING. CHARSET es el charset por el cual se codifica STRING.

OPTS puede aceptar los siguientes pares clave-valor. **NOTA:** Cuando el soporte a Unicode/multibyte esté desactivado (ver "USE_ENCODE"), la conversión no se realizará. Por lo tanto, estas opciones no tendrán efectos.

Detect7bit => YESNO
Intenta detectar el charset 7-bit cuando CHARSET no está especificado. El valor por defecto es "YES".
Replacement => REPLACEMENT
Esquema de manejo de errores. Ver "Manejo de errores".

Una lista de 3 elementos de (cadena convertida, charset de salida, tipo de codificación) será devuelta. El tipo de codificación será uno de "BASE64", "QUOTED-PRINTABLE", "7BIT" o "8BIT". Si el charset de salida no puede ser determinado y la cadena convertida contiene bytes no ASCII, el charset de salida será "undef" y el tipo de codificación será "BASE64". El charset de salida será "US-ASCII" si y solo si la cadena no contiene ningún byte no ASCII.

$charset->decode(STRING [,CHECK])
Decodificar STRING a Unicode.

Nota: Cuando el soporte a Unicode/multibyte esté desactivado (ver "USE_ENCODE"), esta función se detendrá.

NOMBRE

MIME::Charset - Obtener la codificación de caracteres MIME y el nombre de la codificación.

SINOPSIS

    use MIME::Charset;

    # Obtener información sobre un nombre de codificación
    my $charset = MIME::Charset->new('iso-2022-jp');
    print $charset->mime_name(); # iso-2022-jp
    print $charset->description(); # ISO 2022, Japanese

    # Obtener el nombre MIME para una codificación
    my $name = MIME::Charset->whatwg_name('iso-2022-jp'); # iso-2022-jp

    # Obtener la codificación para un nombre MIME
    my $encoding = MIME::Charset->mime_name('iso-2022-jp'); # iso-2022-jp

    # Obtener el nombre MIME para una descripción (solo el primero que coincida)
    my $name = MIME::Charset->whatwg_name('ISO 2022, Japanese'); # iso-2022-jp

    # Obtener un hash de todos los nombres MIME
    my %names = MIME::Charset->names();

    # Obtener un hash de todas las descripciones
    my %descriptions = MIME::Charset->descriptions();

DESCRIPCIÓN

Este módulo proporciona una forma de determinar el nombre MIME adecuado para una codificación de caracteres dada, y viceversa. También puede proporcionar una descripción de la codificación.

  • new()

    Crea un nuevo objeto MIME::Charset para la codificación dada. La codificación puede ser un nombre de codificación (por ejemplo, "iso-2022-jp") o un nombre MIME (por ejemplo, "ISO-2022-JP"). Si se proporciona un nombre MIME, se puede convertir en un nombre de codificación.

    Si se proporciona un nombre desconocido, se devuelve undef.

  • mime_name()

    Devuelve el nombre MIME de la codificación.

  • description()

    Devuelve una descripción legible por humanos de la codificación.

  • iana_name()

    Devuelve el nombre oficial de IANA para la codificación.

  • body_encoding()

    Devuelve la codificación de cuerpo recomendada para la codificación de caracteres dada, como se define en RFC 2045. Los valores posibles son "7bit", "8bit", "QUOTED-PRINTABLE" o "BASE64".

    Puede devolver "S" si la codificación es desconocida (ver más abajo).

  • body_encode()

    Este método está obsoleto y solo se incluye para compatibilidad con versiones anteriores. En su lugar, utilice body_encoding.

  • whatwg_name()

    Devuelve el nombre de codificación de caracteres recomendado por WHATWG para la codificación dada. Esto suele ser el mismo que el nombre MIME, pero puede haber diferencias.

  • name()

    Este método está obsoleto y solo se incluye para compatibilidad con versiones anteriores. En su lugar, utilice whatwg_name.

  • lookup()

    Este método está obsoleto y solo se incluye para compatibilidad con versiones anteriores. En su lugar, utilice new.

  • names()

    Devuelve un hash donde las claves son los nombres MIME y los valores son los objetos MIME::Charset correspondientes.

  • descriptions()

    Devuelve un hash donde las claves son las descripciones y los valores son los objetos MIME::Charset correspondientes.

  • from_mailname()

    Devuelve el nombre MIME para una codificación dada por su nombre de correo electrónico.

  • add()

    Añade una nueva codificación al conjunto de codificaciones conocidas. Espera un objeto MIME::Charset como argumento.

    use MIME::Charset;
    my $charset = MIME::Charset->new('euc-jp');
    print $charset->mime_name(), "\n"; # euc-jp
    print $charset->description(), "\n"; # EUC-JP, Japanese
    print $charset->body_encoding(), "\n"; # 8bit

    my $charset = MIME::Charset->new('ISO-2022-JP');
    print $charset->mime_name(), "\n"; # iso-2022-jp
    print $charset->description(), "\n"; # ISO 2022, Japanese
    print $charset->body_encoding(), "\n"; # 7bit

    my $charset = MIME::Charset->new('Shift_JIS');
    print $charset->mime_name(), "\n"; # shift_jis
    print $charset->description(), "\n"; # Shift_JIS, Japanese
    print $charset->body_encoding(), "\n"; # 8bit

    my $charset = MIME::Charset->new('koi8-r');
    print $charset->mime_name(), "\n"; # koi8-r
    print $charset->description(), "\n"; # KOI8-R, Russian
    print $charset->body_encoding(), "\n"; # 8bit

    my $charset = MIME::Charset->new('iso-8859-1');
    print $charset->mime_name(), "\n"; # iso-8859-1
    print $charset->description(), "\n"; # ISO 8859-1, West European
    print $charset->body_encoding(), "\n"; # 8bit

    my $charset = MIME::Charset->new('us-ascii');
    print $charset->mime_name(), "\n"; # us-ascii
    print $charset->description(), "\n"; # US ASCII, US English
    print $charset->body_encoding(), "\n"; # 7bit

    my $charset = MIME::Charset->new('utf-8');
    print $charset->mime_name(), "\n"; # utf-8
    print $charset->description(), "\n"; # UTF-8, Unicode
    print $charset->body_encoding(), "\n"; # 8bit

El método body_encoding puede devolver también "S" si la codificación es desconocida. En este caso, se recomienda el uso de la codificación "BASE64".

  • El valor de retorno del método body_encode para UTF-8 puede incluir el elemento de codificación "QUOTED-PRINTABLE" que en versiones anteriores estaba fijado a "BASE64".
