Extensiones al módulo List

tipo 'a t = 'a list

val compare : ('a -> 'a -> int) -> 'a t -> 'a t -> int

El orden lexicográfico soportado por el orden proporcionado. No hay restricción en las longitudes relativas de las listas.

val equal : ('a -> 'a -> bool) -> 'a t -> 'a t -> bool

Devuelve true si y solo si las listas dadas tienen la misma longitud y contenido con respecto a la función de igualdad dada.

val some_if_all_elements_are_some : 'a option t -> 'a t option

Si todos los elementos de la lista dada son Some _ entonces se devuelve Some xs con xs siendo el contenido de esos Some s, preservando el orden. De lo contrario, devuelve None.

val map2_prefix : ('a -> 'b -> 'c) -> 'a t -> 'b t -> 'c t * 'b t

let r1, r2 = map2_prefix f l1 l2 Si l1 tiene longitud n y l2 = h2 @ t2 con h2 de longitud n, r1 es List.map2 f l1 h1 y r2 es t2.

val iteri2 : (int -> 'a -> 'b -> unit) -> 'a list -> 'b list -> unit

Igual que List.iter2, pero la función se aplica al índice del elemento como primer argumento (contando desde 0)

val split_at : int -> 'a t -> 'a t * 'a t

split_at n l devuelve el par before, after donde before son los n primeros elementos de l y after los restantes. Si l tiene menos de n elementos, lanza Invalid_argument.

val chunks_of : int -> 'a t -> 'a t t

chunks_of n t devuelve una lista de listas no vacías cuya concatenación es igual a la lista original. Cada lista tiene n elementos, excepto posiblemente la última lista, que puede tener menos. chunks_of lanza si n <= 0.

val is_prefix : equal:('a -> 'a -> bool) -> 'a list -> of_:'a list -> bool

Devuelve true si y solo si la lista dada, con respecto a la función de igualdad dada sobre los miembros de la lista, es un prefijo de la lista of_.

type 'a longest_common_prefix_result = private {
longest_common_prefix : 'a list ;
first_without_longest_common_prefix : 'a list ;
second_without_longest_common_prefix : 'a list ;
}

val find_and_chop_longest_common_prefix : equal:('a -> 'a -> bool) -> first:'a list -> second:'a list -> 'a longest_common_prefix_result

Devuelve la lista más larga que, con respecto a la función de igualdad proporcionada, es un prefijo de ambas listas dadas. También se devuelven las listas de entrada, cada una con dicho prefijo común más largo eliminado.
