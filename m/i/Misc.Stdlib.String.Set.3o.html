val find_first : (elt -> bool) -> t -> elt

find_first f s , donde f es una función monótonamente creciente, devuelve el elemento más bajo e de s tal que f e , o lanza Not_found si no existe tal elemento.

Por ejemplo, find_first (fun e -> Ord.compare e x >= 0) s devolverá el primer elemento e de s donde Ord.compare e x >= 0 (en pocas palabras: e >= x ), o lanzará Not_found si x es mayor que cualquier elemento de s .

Transformación

val map : (elt -> elt) -> t -> t

map f s es el conjunto cuyos elementos son f a0 , f a1 ... f aN , donde a0 , a1 ... aN son los elementos de s .

Los elementos se pasan a f en orden creciente según la ordenación sobre el tipo de los elementos.

Si ningún elemento de s es modificado por f , se devuelve s sin cambios. (Si cada salida de f es físicamente igual a su entrada, el conjunto devuelto es físicamente igual a s ).

val filter : (elt -> bool) -> t -> t

filter f s devuelve el conjunto de todos los elementos de s que satisfacen el predicado f . Si f satisface cada elemento de s , se devuelve s sin cambios (el resultado de la función es entonces físicamente igual a s ).

Antes de 4.03 No se garantizaba la igualdad física.

val filter_map : (elt -> elt option) -> t -> t

filter_map f s devuelve el conjunto de todos los v tales que f x = Some v para algún elemento x de s .

Por ejemplo,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
es el conjunto de las mitades de los elementos pares de s .

Si ningún elemento de s es modificado o descartado por f (si f x = Some x para cada elemento x ), entonces se devuelve s sin cambios: el resultado de la función es entonces físicamente igual a s .

Set.S (Ocamldoc)

NAME

Set.S - Set operations.

Module

module S : sig ... end

A module for ordered sets.

The elements must be comparable. More precisely, the type elt must be an instance of the Ordered module.

Documentation

The functions of this module are similar to the functions of Set.Make. The only difference is that the elements are ordered.

This module implements ordered sets. It is parameterized by a module Ordered giving the type of elements and the ordering function.

The set is represented as a balanced binary tree.

The complexity of the operations is logarithmic in the size of the set.

split x s returns a triplet (l, present, r), where l is the set of elements of s that are strictly less than x ; r is the set of elements of s that are strictly greater than x ; present is false if s contains no element equal to x , or true if s contains an element equal to x .
