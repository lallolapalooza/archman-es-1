NOMBRE

MooX::Types::MooseLike::Base - Una colección de tipos básicos parecidos a Moose para Moo

SINOPSIS

package MyPackage;
use Moo;
use MooX::Types::MooseLike::Base qw(:all);
has "beers_by_day_of_week" => (
    isa => HashRef
);
has "current_BAC" => (
    isa => Num
);
# También soportan is_$type.  Por ejemplo, se puede usar como sigue
has 'legal_age' => (
    is => 'ro',
    isa => sub { die "$_[0] no es legal"
                 unless (is_Int($_[0]) && $_[0] > 17) },
);

DESCRIPCIÓN

Los atributos de Moose (como Moose) tienen una propiedad 'isa'. Este módulo proporciona algunos tipos básicos para esta propiedad. Se pueden importar todos los tipos con la etiqueta ':all' o importar una lista de tipos como:

use MooX::Types::MooseLike::Base qw/HashRef ArrayRef/;

así se pueden declarar algunos atributos como:

has 'contact' => (
  is => 'ro',
  isa => HashRef,
);
has 'guest_list' => (
  is => 'ro',
  isa => ArrayRef[HashRef],
);

Estos tipos ofrecen un control que el atributo contact es una referencia de "array", y que la guest_list es una referencia de "array de hash".

TIPOS PARAMETRIZADOS

Parametrizando Tipos Con un Solo Tipo

Los siguientes tipos pueden ser parametrizados con otros tipos.

ArrayRef

Por ejemplo, ArrayRef[HashRef]

HashRef

ScalarRef

Maybe

Por ejemplo, Maybe[Int] sería un entero o undef

Parametrizando Tipos Con Múltiples Tipos

AnyOf

Verifica si el atributo es cualquiera de los tipos listados (es decir, unión). Recibe una lista de tipos como argumento.

isa => AnyOf[Int, ArrayRef[Int], HashRef[Int]]

Nota: AnyOf recibe un ArrayRef[CodeRef]

AllOf

Verifica si el atributo es todos los tipos listados (es decir, intersección). Recibe una lista de tipos como argumento. Por ejemplo:

isa => AllOf[
  InstanceOf['Human'],
  ConsumerOf['Air'],
  HasMethods['breath', 'dance']
],

Parametrizando Tipos Con Cadenas (Múltiples)

Además, tenemos algunos tipos parametrizados que aceptan argumentos de cadena.

InstanceOf

Verifica si el atributo es una instancia de un objeto de una o más clases. Usa "blessed" y "isa" para hacerlo. Recibe una lista de nombres de clase como argumento. Por ejemplo:

isa => InstanceOf['MyClass','MyOtherClass']

Nota: InstanceOf recibe un ArrayRef[Str]

ConsumerOf

Verifica si el atributo es un objeto y consume uno o más roles. Usa "blessed" y "does" para hacerlo. Recibe una lista de nombres de roles como argumentos. Por ejemplo:

isa => ConsumerOf['My::Role', 'My::AnotherRole']

HasMethods

Verifica si el atributo es un objeto y tiene uno o más métodos. Usa "blessed" y "can" para hacerlo. Recibe una lista de nombres de métodos como argumentos. Por ejemplo:

isa => HasMethods[qw/postulate contemplate liberate/]

Enum

Verifica si el atributo es uno de los valores enumerados. Recibe una lista de valores posibles como argumento. Por ejemplo:

isa => Enum['rock', 'spock', 'paper', 'lizard', 'scissors']
