Module::Install::Can(3) Documentación de Perl aportada por el usuario Module::Install::Can(3)

NOMBRE

Module::Install::Can - Funciones de utilidad para la detección de capacidades

DESCRIPCIÓN

"Module::Install::Can" contiene una serie de funciones para que los autores las utilicen al crear instaladores inteligentes personalizados. Las funciones simplifican las pruebas estándar para que puedas expresar tus dependencias y condiciones de forma mucho más sencilla, y hacer que tu instalador sea mucho más fácil de mantener.

COMANDOS

can_use

can_use('Module::Name');
can_use('Module::Name', 1.23);

La función "can_use" prueba la capacidad de cargar un módulo con nombre específico. Actualmente, también cargará el módulo en el proceso, aunque esto puede cambiar en el futuro.

Acepta un segundo parámetro opcional de un número de versión. La versión actualmente instalada del módulo se probará para asegurarse de que sea igual o superior a la versión especificada.

Devuelve verdadero si el módulo se puede cargar, o falso (tanto en contexto escalar como de lista) si no.

can_run

can_run('cvs');

La función "can_run" prueba la capacidad de ejecutar un comando o programa con nombre en el sistema local.

Devuelve verdadero si es así, o falso (tanto en contexto escalar como de lista) si no.

can_cc

can_cc();

La función "can_cc" prueba la capacidad de localizar un compilador C que funcione en el sistema local. Devuelve verdadero si el compilador C se puede encontrar, o falso (tanto en contexto escalar como de lista) si no.

can_xs

can_xs();

La función "can_xs" prueba un compilador C que funcione y las cabeceras correctas para construir módulos XS contra la instancia actual de Perl.

PENDIENTE

Actualmente, el uso de un comando "can_foo" en un solo dominio de problemas (por ejemplo, "can_use") resulta en la inclusión de funcionalidad adicional de diferentes dominios de problemas (por ejemplo, "can_run").

Este módulo debería dividirse finalmente, y las funciones individuales redistribuirse a diferentes extensiones específicas de dominio.
