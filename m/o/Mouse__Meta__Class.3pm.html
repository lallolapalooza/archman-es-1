Mouse::Meta::Class(3pm) Documentación de Perl contribuida por el usuario Mouse::Meta::Class(3pm)

NOMBRE

Mouse::Meta::Class - Metaclase de clases de Mouse

VERSIÓN

Este documento describe la versión de Mouse v2.6.0

DESCRIPCIÓN

Esta clase es un protocolo de metaobjetos para clases de Mouse, que es un subconjunto de Moose::Meta:::Class.

MÉTODOS

"inicializar(NombreClase) -> Mouse::Meta::Class"

Encuentra o crea una instancia de "Mouse::Meta::Class" para el NombreClase dado. Solo debe existir una instancia para una clase dada.

"nombre -> NombreClase"

Devuelve el nombre de la clase propietaria.

"superclases -> NombresClase" superclase(NombresClase)

Obtiene (o establece) la lista de superclases de la clase propietaria.

"agregar_método(nombre => ReferenciaCód)"

Agrega un método a la clase propietaria.

"tiene_método(nombre) -> Booleano"

Devuelve si tenemos un método con el nombre dado.

"obtener_método(nombre) -> Mouse::Meta::Método | indefinido"

Devuelve un Mouse::Meta::Método con el nombre dado.

Nótese que también puedes usar "$metaclas->nombre->puede($nombre)" para el cuerpo de un método.

"obtener_lista_métodos -> Nombres"

Devuelve una lista de nombres de métodos que están definidos en la clase local. Si deseas una lista de todos los métodos aplicables para una clase, usa el método "obtener_todos_los_métodos".

"obtener_todos_los_métodos -> (Mouse::Meta::Método)"

Devuelve la lista de todas las instancias de Mouse::Meta::Método asociadas con la clase y sus superclases.

"agregar_atributo(nombre => especificación | Mouse::Meta::Atributo)"

Comienza a realizar un seguimiento del Mouse::Meta::Atributo existente para la clase propietaria.

"tiene_atributo(Nombre) -> Booleano"

Devuelve si tenemos un Mouse::Meta::Atributo con el nombre dado.

"obtener_atributo Nombre -> Mouse::Meta::Atributo | indefinido"

Devuelve el Mouse::Meta::Atributo con el nombre dado.

"obtener_lista_atributos -> Nombres"

Devuelve una lista de nombres de atributos que están definidos en la clase local. Si deseas una lista de todos los atributos aplicables para una clase, usa el método "obtener_todos_los_atributos".

"obtener_todos_los_atributos -> (Mouse::Meta::Atributo)"

Devuelve la lista de todas las instancias de Mouse::Meta::Atributo asociadas con esta clase y sus superclases.

"isa_linearizada -> [NombresClase]"

Devuelve la lista de clases en orden de despacho de métodos, con duplicados eliminados.

"nuevo_objeto(Parámetros) -> Instancia"

Crea una nueva instancia.

"clonar_objeto(Instancia, Parámetros) -> Instancia"

Clona la instancia dada, que debe ser una instancia gobernada por esta metaclase.

"lanzar_error(Mensaje, Parámetros)"

Lanza un error con el mensaje dado.
