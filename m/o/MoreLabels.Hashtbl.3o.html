Tablas hash y funciones hash.

Las tablas hash son tablas de asociación en memoria, con modificación en lugar de la entrada. Debido a que las operaciones en una tabla hash modifican su entrada, se utilizan comúnmente en código impaciente. La búsqueda de valor asociado a una clave (ver MoreLabels.Hashtbl.find, MoreLabels.Hashtbl.find_opt) es normalmente muy rápida, a menudo más rápida que la búsqueda equivalente en MoreLabels.Map.

Los funtores MoreLabels.Hashtbl.Make y MoreLabels.Hashtbl.MakeSeeded pueden usarse cuando se requiera rendimiento o flexibilidad. El usuario proporciona funciones de igualdad y hash personalizadas para el tipo de clave, obteniendo así un tipo de tabla hash personalizada para este tipo de clave.

Una advertencia: Una tabla hash es tan buena como su función hash. Una función hash mala convertirá la tabla en una lista de asociación lineal, con búsqueda lineal en lugar de constante.

La tabla hash polimórfica MoreLabels.Hashtbl.t es útil en casos sencillos o en entornos interactivos. Usa la función hash polimórfica MoreLabels.Hashtbl.hash definida en el lenguaje OCaml (a la hora de escribirse, es SipHash), así como la igualdad polimórfica (=).

Ver MoreLabels.Hashtbl.examples.

Accesos no sincronizados

Los accesos no sincronizados a una tabla hash pueden llevar a un estado inválido de la tabla. Por lo tanto, los accesos concurrentes a una tabla hash deben ser sincronizados (por ejemplo con Mutex.t).

Interfaz genérica

type ('a, 'b) t = ('a, 'b) Hashtbl.t

El tipo de tablas hash desde el tipo 'a hasta el tipo 'b

val create : ?random:bool -> int -> ('a, 'b) t

Hashtbl.create n crea una nueva tabla hash vacía, con tamaño inicial mayor o igual que el tamaño sugerido n. Para resultados óptimos, n debería estar en el orden de los elementos esperados en la tabla. La tabla crece como sea necesario, por lo que n es solo un estimado inicial. Si n es muy pequeño o negativo, se ignora y se usa un tamaño pequeño por defecto.

El parámetro opcional ~random (un booleano) controla si la organización interna de la tabla hash es aleatoria cada vez que se ejecuta Hashtbl.create o determinista en todas las ejecuciones.

Una tabla hash creada con ~random como false usa una función hash fija (MoreLabels.Hashtbl.hash) para distribuir claves entre los buckets. Como consecuencia, las colisiones entre claves ocurren de forma determinista. En aplicaciones web o en otros contextos seguros, los patrones de colisión deterministas pueden ser explotados por un usuario malicioso para crear un ataque de denegación de servicio: el atacante envía entrada construida para crear muchas colisiones en la tabla, ralentizando la aplicación.

Una tabla hash creada con ~random como true utiliza la función hash semilla MoreLabels.Hashtbl.seeded_hash con una semilla elegida aleatoriamente al crear la tabla. En efecto, la función hash utilizada es seleccionada aleatoriamente entre 2^30 funciones hash diferentes. Todas estas funciones tienen patrones de colisión distintos, haciendo ineficiente el ataque de denegación de servicio descrito anteriormente. Sin embargo, debido a la aleatorización, la enumeración de todos los elementos de la tabla utilizando MoreLabels.Hashtbl.fold o MoreLabels.Hashtbl.iter ya no es determinista: los elementos se enumeran en diferentes órdenes en diferentes ejecuciones del programa.

Si no se proporciona el parámetro ~random, se crea la tabla hash en modo no aleatorio por defecto. Este modo puede cambiarse programáticamente llamando a MoreLabels.Hashtbl.randomize o estableciendo el flag R en el archivo de configuración OCAMLRUNPARAM.

Antes de 4.00, el parámetro ~random no existía y todas las tablas hash se creaban en modo no aleatorio.

val clear : ('a, 'b) t -> unit

Vacía una tabla hash. Usa reset para reducir el tamaño de la tabla de buckets a su tamaño inicial.

val reset : ('a, 'b) t -> unit

Vacía una tabla hash y reduce el tamaño de la tabla de buckets a su tamaño inicial.

Desde 4.00

val copy : ('a, 'b) t -> ('a, 'b) t

Devuelve una copia de la tabla hash dada.

val add : ('a, 'b) t -> key:'a -> data:'b -> unit

Hashtbl.add tbl ~key ~data agrega una asociación de key a data en la tabla tbl.

Advertencia: Las asociaciones previas para key no se eliminan, sino que simplemente se ocultan. Es decir, después de realizar MoreLabels.Hashtbl.remove tbl key, la asociación previa para key se restaura, si existe. (Comportamiento similar a las listas de asociación.)

Si deseas el comportamiento clásico de reemplazar los elementos, consulta MoreLabels.Hashtbl.replace.

val find : ('a, 'b) t -> 'a -> 'b

Hashtbl.find tbl x devuelve la asociación actual de x en tbl, o Not_found si no existe dicha asociación.

val find_opt : ('a, 'b) t -> 'a -> 'b option

Hashtbl.find_opt tbl x devuelve la asociación actual de x en tbl, o None si no existe dicha asociación.

Desde 4.05

val find_all : ('a, 'b) t -> 'a -> 'b list

Hashtbl.find_all tbl x devuelve la lista de datos asociados a x en tbl. Los datos actuales se devuelven primero, luego las asociaciones previas, en orden inverso de introducción en la tabla.

val mem : ('a, 'b) t -> 'a -> bool

Hashtbl.mem tbl x verifica si x está asociado en tbl.

val remove : ('a, 'b) t -> 'a -> unit

Hashtbl.remove tbl x elimina la asociación actual de x en tbl, restaurando la asociación previa si existe. Si x no está asociado en tbl, no hace nada.

val replace : ('a, 'b) t -> key:'a -> data:'b -> unit

Hashtbl.replace tbl ~key ~data reemplaza la asociación actual de key en tbl por una asociación de key a data. Si key no está asociado en tbl, se agrega una nueva asociación de key a data a tbl. Esto es funcionalmente equivalente a MoreLabels.Hashtbl.remove tbl key seguido por MoreLabels.Hashtbl.add tbl key data.

val iter : f:(key:'a -> data:'b -> unit) -> ('a, 'b) t -> unit

Hashtbl.iter ~f tbl aplica f a todas las asociaciones en la tabla tbl. f recibe la clave como primer argumento, y el valor asociado como segundo argumento. Cada asociación se presenta exactamente una vez a f.

El orden en que las asociaciones se pasan a f no está especificado. Sin embargo, si la tabla contiene varias asociaciones para la misma clave, se pasan a f en orden inverso de introducción, es decir, la asociación más reciente se pasa primero.

Si la tabla hash fue creada en modo no aleatorio, el orden en que las asociaciones se enumeran es reproducible entre ejecuciones sucesivas del programa, incluso entre versiones menores de OCaml. Para tablas hash aleatorizadas, el orden de enumeración es totalmente aleatorio.

El comportamiento no está especificado si la tabla hash se modifica durante la iteración con f.

val filter_map_inplace : f:(key:'a -> data:'b -> 'b option) -> ('a, 'b) t -> unit

Hashtbl.filter_map_inplace ~f tbl aplica f a todas las asociaciones en la tabla tbl y actualiza cada asociación según el resultado de f. Si f retorna None, la asociación se descarta. Si retorna Some new_val, la asociación se actualiza para asociar la clave a new_val.

Otros comentarios para MoreLabels.Hashtbl.iter aplican también.

Desde 4.03

val fold : f:(key:'a -> data:'b -> 'acc -> 'acc) -> ('a, 'b) t -> init:'acc -> 'acc

Hashtbl.fold ~f tbl ~init calcula (f kN dN ... (f k1 d1 init)...), donde k1 ... kN son las claves de todas las tablas.

Tablas hash y secuencias

val to_seq : ('a, 'b) t -> ('a * 'b) Seq.t

Itera sobre toda la tabla. El orden en que aparecen las entradas en la secuencia es impredecible. Sin embargo, si la tabla contiene varias entradas con la misma clave, aparecen en orden inverso de introducción, es decir, la más reciente aparece primero.

El comportamiento no está especificado si la tabla se modifica durante la iteración.

val replace_seq : ('a, 'b) t -> ('a * 'b) Seq.t -> unit

Añade las entradas dadas a la tabla, usando MoreLabels.Hashtbl.replace

Since 4.07

val of_seq : ('a * 'b) Seq.t -> ('a, 'b) t

Crea una tabla a partir de las entradas dadas. Las entradas se añaden en el mismo orden que aparecen en la secuencia, usando MoreLabels.Hashtbl.replace_seq, lo que significa que si dos pares tienen la misma clave, solo aparece el último en la tabla.

Interfaz functorial

La interfaz functorial permite el uso de funciones de comparación y de hash específicas, ya sea por motivos de rendimiento o seguridad, o porque las claves no son hashable/comparable con los builtins polimórficos.

Por ejemplo, uno podría querer especializar una tabla para claves de tipo entero:

        module IntHash =
          struct
            type t = int
            let equal i j = i=j
            let hash i = i land max_int
          end
        module IntHashtbl = Hashtbl.Make(IntHash)
        let h = IntHashtbl.create 17 in
        IntHashtbl.add h 12 "hello"

Esta crea un nuevo módulo IntHashtbl, con un nuevo tipo 'a de IntHashtbl.t de tablas de int a 'a. En este ejemplo, h contiene valores de tipo string, por lo que su tipo es string IntHashtbl.t.

Nota: El nuevo tipo 'a IntHashtbl.t no es compatible con el tipo ('a,'b) Hashtbl.t de la interfaz genérica. Por ejemplo, Hashtbl.length h no se type-checkará, debes usar IntHashtbl.length.

module type HashedType = sig type t val equal : t -> t -> bool val hash : t -> int end

Las funciones de hash polimórficas

val hash : 'a -> int

La función Hashtbl.hash x asocia un número no negativo a cualquier valor de cualquier tipo. Se garantiza que si x = y o Stdlib.compare x y = 0, entonces hash x = hash y. Además, hash termina siempre, incluso en estructuras cíclicas.

val seeded_hash : int -> 'a -> int

Variante de MoreLabels.Hashtbl.hash con un parámetro de semilla entera.

Since 4.00

val hash_param : int -> int -> 'a -> int

La función Hashtbl.hash_param meaningful total x calcula un valor de hash para x, con las mismas propiedades que hash. Los parámetros adicionales meaningful y total ofrecen mayor control sobre el hash. La función de hash realiza un recorrido de ancho, desde la izquierda a la derecha, de la estructura x, deteniéndose después de meaningful nodos significativos o total nodos (significativos o no). Si el valor de total especificado por el usuario excede un valor determinado (actualmente 256), se limita a ese valor. Los nodos significativos son enteros, números de punto flotante, cadenas, caracteres, booleanos y construcciones constantes. Valores más altos de meaningful y total implican que más nodos se consideren para calcular el valor de hash final, reduciendo así las colisiones. Sin embargo, el hash es más lento. Los parámetros meaningful y total regulan el equilibrio entre la precisión y la velocidad. Como opciones por defecto, MoreLabels.Hashtbl.hash y MoreLabels.Hashtbl.seeded_hash usan meaningful = 10 y total = 100.

val seeded_hash_param : int -> int -> int -> 'a -> int

Variante de Mor...

eLabels.Hashtbl.hash_param que está además parametrizado por una semilla entera. Uso: Hashtbl.seeded_hash_param semilla_total_significativa x .

Ejemplos

Ejemplo Básico

      (* 0...99 *)
      let seq = Seq.ints 0 |> Seq.take 100
      (* construir a partir de Seq.t *)
      # let tbl =
          seq
          |> Seq.map (fun x -> x, string_of_int x)
          |> Hashtbl.of_seq
      val tbl : (int, string) Hashtbl.t = <abstr>
      # Hashtbl.length tbl
      - : int = 100
      # Hashtbl.find_opt tbl 32
      - : string option = Some "32"
      # Hashtbl.find_opt tbl 166
      - : string option = None
      # Hashtbl.replace tbl 166 "one six six"
      - : unit = ()
      # Hashtbl.find_opt tbl 166
      - : string option = Some "one six six"
      # Hashtbl.length tbl
      - : int = 101

Contando Elementos

Dada una secuencia de elementos (aquí, un Seq.t ), queremos contar cuántas veces ocurre cada elemento distinto en la secuencia. Una forma sencilla de hacer esto, asumiendo que los elementos son comparables y se pueden hashear, es usar una tabla hash que mapea elementos a su número de ocurrencias.

Aquí ilustramos ese principio usando una secuencia de caracteres (ascii) (tipo char ). Usamos una Char_tbl personalizada especializada para char .

      # module Char_tbl = Hashtbl.Make(struct
          type t = char
          let equal = Char.equal
          let hash = Hashtbl.hash
        end)
      (*  contar ocurrencias distintas de chars en [seq] *)
      # let count_chars (seq : char Seq.t) : _ list =
          let counts = Char_tbl.create 16 in
          Seq.iter
            (fun c ->
              let count_c =
                Char_tbl.find_opt counts c
                |> Option.value ~default:0
              in
              Char_tbl.replace counts c (count_c + 1))
            seq;
          (* convertir a una lista *)
          Char_tbl.fold (fun c n l -> (c,n) :: l) counts []
            |> List.sort (fun (c1,_)(c2,_) -> Char.compare c1 c2)
      val count_chars : Char_tbl.key Seq.t -> (Char.t * int) list = <fun>
      (* seq básica de una cadena *)
      # let seq = String.to_seq "hello world, and all the camels in it!"
      val seq : char Seq.t = <fun>
      # count_chars seq
      - : (Char.t * int) list =
      [(' ', 7); ('!', 1); (',', 1); ('a', 3); ('c', 1); ('d', 2); ('e', 3);
       ('h', 2); ('i', 2); ('l', 6); ('m', 1); ('n', 2); ('o', 2); ('r', 1);
       ('s', 1); ('t', 2); ('w', 1)]
      (* "abcabcabc..." *)
      # let seq2 =
          Seq.cycle (String.to_seq "abc") |> Seq.take 31
      val seq2 : char Seq.t = <fun>
      # String.of_seq seq2
      - : String.t = "abcabcabcabcabcabcabcabcabcabca"
      # count_chars seq2
      - : (Char.t * int) list = [('a', 11); ('b', 10); ('c', 10)]
