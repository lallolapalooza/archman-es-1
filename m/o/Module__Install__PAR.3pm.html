NOMBRE

Module::Install::PAR - Soporte de Module::Install para paquetes PAR::Dist

SINOPSIS

Para ofrecer a sus usuarios la posibilidad de instalar binarios si no podemos compilar una versión XS del módulo, podría usar este simple stub:

use inc::Module::Install;

name            'Foo';
all_from        'lib/Foo.pm';

# ¿De qué directorio de CPAN obtenemos los binarios?
par_base        'SMUELLER';

unless ( can_xs ) {
    my $okay = extract_par( fetch_par );
    if (not $okay) {
        die "No se encontró compilador ni paquete binario. Abortando.\n";
    }
}

WriteAll;

DESCRIPCIÓN

Este módulo añade un par de directivas a Module::Install relacionadas con la instalación y creación de distribuciones PAR::Dist.

par_base

Esta directiva establece el ID de CPAN desde cuyo directorio de CPAN se obtendrán los binarios. Por ejemplo, puede optar por descargar binarios desde http://www.cpan.org/authors/id/S/SM/SMUELLER/ o su contraparte ftp escribiendo:

par_base 'SMUELLER';

Por defecto, el nombre del archivo a obtener se genera a partir del nombre de la distribución, su versión, el nombre de su plataforma y su versión de perl concatenados con guiones.

La directiva, sin embargo, toma un segundo argumento opcional que especifica el nombre del archivo a obtener. (Aunque "par_base" no obtiene archivos por sí mismo, ver más abajo).

par_base 'SMUELLER', 'foo';

Una vez que se llama a "fetch_par", el archivo 'foo' se descargará del directorio CPAN de SMUELLER. (No existe).

El segundo argumento podría usarse para obtener binarios agnósticos de plataforma:

par_base 'SMUELLER', "Some-Distribution-0.01.par";

(TODO Documentación: Usar el nombre de distribución y versión previamente definidos en el ejemplo.)

fetch_par

Obtiene el archivo .par referenciado previamente en la documentación de la directiva "par_base".

"fetch_par" se puede usar sin argumentos dado que la directiva "par_base" se usó antes. Devolverá el nombre del archivo que obtuvo.

Si el primer argumento es una URL o un ID de usuario de CPAN, el archivo se obtiene de ese directorio a menos que se haya establecido una URL previamente. (Lea eso de nuevo).

Si el segundo argumento es un nombre de archivo, se usa como el nombre del archivo a descargar.

Si el archivo no se pudo obtener, se imprime un mensaje de error adecuado sobre que no hay paquete disponible, etc. Puede desactivar esto especificando un tercer argumento verdadero.

# Intentar obtener el paquete (ver par_base) pero
# no ser verboso sobre los fallos
my $file = fetch_par('', '', undef);

extract_par

Toma el nombre de un archivo de archivo PAR::Dist como primer argumento. Se extrae el directorio 'blib/' de este archivo y se crea 'pm_to_blib'.

Uso abreviado típico:

extract_par( fetch_par ) or die "No se pudo instalar el archivo PAR::Dist.";

make_par

Esta directiva requiere PAR::Dist (versión 0.03 o superior) en su sistema. (Y verifica que esté disponible antes de continuar).

Crea un archivo PAR::Dist a partir del subdirectorio 'blib/'.

El primer argumento debe ser el nombre del archivo PAR::Dist a crear.

Si su Makefile.PL tiene una directiva "par_base", estará disponible el objetivo de make "par". Utiliza esta directiva "make_par" internamente, por lo que en su sistema de desarrollo, puede hacer esto para crear un archivo binario .par para su plataforma:

perl Makefile.PL
make
make par
