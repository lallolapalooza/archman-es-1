Module::Loaded(3perl) Guía de referencia para programadores de Perl Module::Loaded(3perl)

NOMBRE

Module::Loaded - marca módulos como cargados o descargados

SINOPSIS

use Module::Loaded;
$bool = mark_as_loaded('Foo');   # Foo.pm ahora está marcado como cargado
$loc  = is_loaded('Foo');        # la ubicación de Foo.pm se establece en la
                                 # ubicación del cargador
eval "require 'Foo'";            # ahora es una operación nula
$bool = mark_as_unloaded('Foo'); # Foo.pm ya no está marcado como cargado
eval "require 'Foo'";            # Intentará encontrar Foo.pm en @INC

DESCRIPCIÓN

Al probar aplicaciones, a menudo te encuentras necesitando proporcionar funcionalidad en tu entorno de prueba que normalmente sería proporcionada por módulos externos. En lugar de manipular la %INC manualmente para marcar estos módulos externos como cargados, de modo que perl no intente cargarlos, este módulo te ofrece una forma muy sencilla de marcar módulos como cargados y/o descargados.

FUNCIONES

$bool = mark_as_loaded( PAQUETE );

Marca el paquete como cargado para perl. "PAQUETE" puede ser una palabra clave desnuda o una cadena.

Si el módulo ya está cargado, "mark_as_loaded" se quejará al respecto y te dirá desde dónde se ha cargado ya el "PAQUETE".

$bool = mark_as_unloaded( PAQUETE );

Marca el paquete como descargado para perl, que es exactamente lo contrario de "mark_as_loaded". "PAQUETE" puede ser una palabra clave desnuda o una cadena.

Si el módulo ya está descargado, "mark_as_unloaded" se quejará al respecto y te dirá que el "PAQUETE" ya ha sido descargado.

$loc = is_loaded( PAQUETE );

"is_loaded" te dice si "PAQUETE" ya ha sido marcado como cargado. "PAQUETE" puede ser una palabra clave desnuda o una cadena.

Devuelve falso si "PAQUETE" aún no se ha cargado y la ubicación desde la que se dice que está cargado en caso de éxito.
