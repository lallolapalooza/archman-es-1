NOMBRE

Mouse::Meta::Attribute - La clase metacuerpo para atributos de Mouse

VERSIÓN

Este documento describe la versión de Mouse v2.6.0

DESCRIPCIÓN

Este es un protocolo de objetos metacuerpo para atributos de Mouse, que es un subconjunto del Moose::Meta::Attribute.

MÉTODOS

"new(%options) -> Mouse::Meta::Attribute"

Crea una nueva instancia de Mouse::Meta::Attribute. No realiza ninguna otra acción.

Añade las siguientes opciones al constructor:

"is => 'ro', 'rw', 'bare'"
Esta opción proporciona una abreviatura para especificar el nombre del "lector", "escribidor" o "accesor". Si el atributo es solo lectura ('ro'), tendrá un método "lector" con el mismo nombre que el atributo. Si es de lectura y escritura ('rw'), tendrá un método "accesor" con el mismo nombre. Si se proporciona un "escribidor" explícito para un atributo de lectura y escritura, se tendrá un "lector" con el mismo nombre que el atributo, y un "escribidor" con el nombre proporcionado.
Usa 'bare' cuando quieras deliberadamente no instalar ningún método (accesor, lector, etc.) asociado con este atributo; de lo contrario, Moose emitirá un aviso de desactivación cuando este atributo se agregue a un metacuerpo.
"isa => Type"
Esta opción acepta un tipo. El tipo puede ser una cadena, que debe ser el nombre de un tipo. Si el nombre del tipo es desconocido, se asumirá que es el nombre de una clase.

Esta opción también puede aceptar un objeto Moose::Meta::TypeConstraint.

Si también proporcionas un "does", entonces tu "isa" debe ser un nombre de clase, y esta clase debe hacer la role especificada con "does".

"does => Role"
Esta es abreviatura para decir que el tipo del atributo debe ser un objeto que haga la role especificada.
Esta opción no está disponible aún.
"coerce => Bool"
Esta opción es válida solo para objetos con una restricción de tipo ("isa"). Si es verdadero, se aplicarán coerciones cada vez que este atributo se establezca.

Puedes hacer ambos esto y el "weak_ref" verdadero.

"trigger => CodeRef"
Esta opción acepta una referencia a una subrutina que se llama después de que el atributo se establezca.
"required => Bool"
Un atributo requerido debe ser proporcionado al constructor. Un atributo que sea requerido también puede tener un "default" o "builder", que satisfarán su requisición.

Un atributo requerido debe tener un "default", "builder" o una "init_arg" no "undef".

"lazy => Bool"
Un atributo lento debe tener un "default" o "builder". Cuando un atributo es lento, el valor por defecto no se calculará hasta que el atributo se lea.
"weak_ref => Bool"
Si es verdadero, el valor del atributo se almacenará como una referencia débil.
"auto_deref => Bool"
Si es verdadero, el lector dereferenciará el valor cuando lo llame. El atributo debe tener una restricción de tipo que defina el atributo como un referencia a un array o un hash.
"lazy_build => Bool"
Al establecer este a verdadero, el atributo se hace lento y se proporcionan varios métodos por defecto.

Ejemplo:

has 'size' => (
    is         => 'ro',
    lazy_build => 1,
);

es equivalente a:

has 'size' => (
    is        => 'ro',
    lazy      => 1,
    builder   => '_build_size',
    clearer   => 'clear_size',
    predicate => 'has_size',
);

associate_method(MethodName)

Asocia un método con el atributo. En general, esto se llama internamente cuando un atributo genera sus accesores.

Actualmente, el argumento MethodName es ignorado en Mouse.

"verify_against_type_constraint(Item) -> TRUE | ERROR"

Verifica que el valor dado pasa la restricción del atributo. Devuelve "true" en éxito, de lo contrario "confess".

"clone_and_inherit_options(options) -> Mouse::Meta::Attribute"

Crea un nuevo atributo en la clase propietaria, heredando las opciones de las clases padres. Los accesores y métodos de ayuda se instalan. Algunas verificaciones de errores se realizan.

"get_read_method_ref"

"get_write_method_ref"

Devuelve la referencia a la subrutina adecuada para leer o escribir el valor del atributo en la clase asociada. Estas métodos siempre devuelven una referencia a la subrutina, independientemente de si el atributo es solo lectura o escritura.
