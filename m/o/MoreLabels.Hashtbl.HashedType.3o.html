type t

El tipo de las claves de la tabla hash.

val equal : t -> t -> bool

El predicado de igualdad utilizado para comparar claves.

val hash : t -> int

Una función hash sobre claves. Debe ser tal que si dos claves son iguales según equal , entonces tienen valores hash idénticos según lo calculado por hash . Ejemplos: pares adecuados ( equal , hash ) para tipos de claves arbitrarios incluyen

- ( (=) , MoreLabels.Hashtbl.HashedType.hash ) para comparar objetos por estructura (siempre que los objetos no contengan flotantes)

- ( (fun x y -> compare x y = 0) , MoreLabels.Hashtbl.HashedType.hash ) para comparar objetos por estructura y manejar nan correctamente

- ( (==) , MoreLabels.Hashtbl.HashedType.hash ) para comparar objetos por igualdad física (por ejemplo, para objetos mutables o cíclicos).
