NOMBRE

MOVE - posicionar un cursor

SINOPSIS

MOVE [ dirección ] [ FROM | IN ] nombre_cursor
donde dirección puede ser una de las siguientes:
    NEXT
    PRIOR
    FIRST
    LAST
    ABSOLUTE número
    RELATIVE número
    número
    ALL
    FORWARD
    FORWARD número
    FORWARD ALL
    BACKWARD
    BACKWARD número
    BACKWARD ALL

DESCRIPCIÓN

MOVE reposiciona un cursor sin recuperar datos. MOVE funciona exactamente igual que el comando FETCH, excepto que solo posiciona el cursor y no devuelve filas.

Los parámetros del comando MOVE son idénticos a los del comando FETCH; consulte FETCH(7) para obtener detalles sobre la sintaxis y el uso.

SALIDAS

Al completarse con éxito, un comando MOVE devuelve una etiqueta de comando con el formato

MOVE número

El número es la cantidad de filas que un comando FETCH con los mismos parámetros habría devuelto (posiblemente cero).

EJEMPLOS

BEGIN WORK;
DECLARE liahona CURSOR FOR SELECT * FROM films;
-- Saltar las primeras 5 filas:
MOVE FORWARD 5 IN liahona;
MOVE 5
-- Recuperar la sexta fila del cursor liahona:
FETCH 1 FROM liahona;
 code  | title  | did | date_prod  |  kind  |  len
-------+--------+-----+------------+--------+-------
 P_303 | 48 Hrs | 103 | 1982-10-22 | Action | 01:37
(1 fila)
-- Cerrar el cursor liahona y finalizar la transacción:
CLOSE liahona;
COMMIT WORK;

COMPATIBILIDAD

No existe una instrucción MOVE en el estándar SQL.
