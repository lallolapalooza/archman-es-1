MooX::late(3) Documentación de Perl aportada por el usuario MooX::late(3)

NOMBRE

MooX::late - traduce fácilmente código Moose a Moo

SINOPSIS

package Foo;
use Moo;
use MooX::late;
has bar => (is => "ro", isa => "Str", default => "MacLaren's Pub");

(Ejemplos de roles de Moo en la sección siguiente.)

DESCRIPCIÓN

Moo es un framework de programación orientada a objetos ligero que tiene como objetivo ser compatible con Moose. Lo hace detectando cuándo se ha cargado Moose y "infla" automáticamente sus clases y roles en clases y roles completos de Moose. De esta manera, las clases Moo pueden consumir roles de Moose, las clases de Moose pueden extender clases Moo, y así sucesivamente.

Sin embargo, la sintaxis superficial de Moo difiere algo de la de Moose. Por ejemplo, la opción "isa" al definir atributos en Moose debe ser una cadena o un objeto bendecido de Moose::Meta::TypeConstraint; pero en Moo debe ser un coderef. Estas diferencias en la sintaxis superficial hacen que la portabilidad de código de Moose a Moo sea potencialmente complicada. MooX::late proporciona cierta ayuda al habilitar una sintaxis superficial ligeramente más "Moosey".

MooX::late hace lo siguiente:

1.
Soporta "isa => $stringytype".
2.
Soporta "does => $rolename".
3.
Soporta "lazy_build => 1".
4.
Exporta las funciones "blessed" y "confess" a tu espacio de nombres.
5.
Maneja traits de atributos nativos.

Cinco características. El objetivo de "MooX::late" no es hacer que cada aspecto de Moo se comporte exactamente igual que Moose. Simplemente va a por la fruta madura. Por lo tanto, hace cinco cosas en este momento, y prometo que las versiones futuras nunca harán más de siete.

Las versiones anteriores de MooX::late agregaron soporte para "coerce => 1" y "default => $nonref". Estas características ahora se han agregado a Moo mismo, por lo que MooX::late ya no tiene que lidiar con ellas.

Uso en Moo::Roles

MooX::late debería funcionar en Moo::Roles, sin advertencias particulares.

package MyRole;
use Moo::Role;
use MooX::late;

Package::Variant se puede usar para construir el equivalente de Moo de roles parametrizados. MooX::late debería funcionar en roles creados con Package::Variant.

use Package::Variant
   importing => [ qw( Moo::Role MooX::late ) ],
   subs      => [ qw( has with ) ];

Restricciones de tipo

Las cadenas de restricciones de tipo se interpretan usando Type::Parser, utilizando las restricciones de tipo definidas en Types::Standard. Esto proporciona un superconjunto muy ligero de la sintaxis de restricciones de tipo de Moose y restricciones de tipo incorporadas.

Cualquier cadena no reconocida que parezca ser un nombre de clase se interpreta como una restricción de tipo de clase.

Subclases

MooX::late está diseñado para ser razonablemente fácil de subclasar. Hay comentarios en el código fuente que explican los puntos de extensión para la extensibilidad.

VER TAMBIÉN

"MooX::late" utiliza Types::Standard para verificar las restricciones de tipo.

"MooX::late" utiliza Sub::HandlesVia para proporcionar soporte nativo para traits de atributos.

Los siguientes módulos aportan funcionalidad adicional de Moose a Moo, más allá de lo que ofrece MooX::late:

  • MooX::Override - soporte override/super
  • MooX::Augment - soporte augment/inner

MooX te permite cargar Moo junto con múltiples módulos de extensión de MooX en una sola línea.
