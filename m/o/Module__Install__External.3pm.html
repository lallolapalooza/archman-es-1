NOMBRE

Module::Install::External - Especifica dependencias de cosas externas que no son de Perl

DESCRIPCIÓN

"Module::Install::External" proporciona comandos que le permiten especificar declarativamente una dependencia en un programa o sistema que no es de Perl.

Los comandos que proporciona son similares a los de Module::Install::Can, excepto que implementan una dependencia explícita, además de simplemente verificar si la cosa en particular está disponible.

COMANDOS

requires_xs

requires_xs;

El comando "requires_xs" especifica explícitamente que se requiere un compilador C y los archivos de cabecera de Perl para compilar (en tiempo de *make*) la distribución (específicamente archivos XS).

No toma ningún parámetro y aborta la ejecución de *Makefile.PL* de una manera que un sistema de instalación o prueba automatizado interpretará como un resultado "NA" ("no aplicable a esta plataforma").

Esto puede cambiarse a un resultado de aborto alternativo en un momento posterior.

Devuelve verdadero como conveniencia.

requires_external_cc

requires_external_cc;

El comando "requires_external_cc" especifica explícitamente que se requiere un compilador C para compilar (en tiempo de *make*) la distribución.

No toma ningún parámetro y aborta la ejecución de *Makefile.PL* de una manera que un sistema de instalación o prueba automatizado interpretará como un resultado "NA" ("no aplicable a esta plataforma").

Esto puede cambiarse a un resultado de aborto alternativo en un momento posterior.

Devuelve verdadero como conveniencia.

requires_external_bin

requires_external_bin 'cvs';

El comando "requires_external_bin" toma el nombre de un comando o programa del sistema, similar al comando "can_run", excepto que "requires_external_bin" comprueba de una manera que es una dependencia explícita declarativa.

Toma un único parámetro del nombre del comando/programa y aborta la ejecución de "Makefile.PL" de una manera que un sistema de instalación o prueba automatizado interpretará como un resultado "NA" ("no aplicable a esta plataforma").

Devuelve verdadero como conveniencia.

POR HACER
