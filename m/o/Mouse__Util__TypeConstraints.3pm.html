NOMBRE

Mouse::Util::TypeConstraints - Sistema de restricciones de tipo para Mouse

VERSIÓN

Este documento describe la versión de Mouse v2.6.0

SINOPSIS

use Mouse::Util::TypeConstraints;
subtype 'Natural'
    => as 'Int'
    => where { $_ > 0 };
subtype 'NaturalLessThanTen'
    => as 'Natural'
    => where { $_ < 10 }
    => message { "Este número ($_) es no menor de diez!" };
coerce 'Num'
    => from 'Str'
      => via { 0+$_ };
enum 'RGBColors' => qw(red green blue);
no Mouse::Util::TypeConstraints;

DESCRIPCIÓN

Este módulo proporciona a Mouse la capacidad de crear restricciones de tipo personalizadas para ser utilizadas en la definición de atributos.

Advertencia Importante

Este no es un sistema de tipos para Perl 5. Son restricciones de tipo, y no se utilizan por Mouse, a menos que se le indique. No se realiza inferencia de tipos, expresiones no se tipifican, etc. etc. etc.

Una restricción de tipo es básicamente una función pequeña "verifica si un valor es válido". Una restricción puede ser asociada a un atributo. Esto simplifica la validación de parámetros y hace que tu código sea más fácil de leer, ya que puedes referirte a las restricciones por nombre.

Advertencia Ligeramente Menos Importante

Siempre es buena idea citar tus tipos de nombre.

Esto previene a Perl de intentar ejecutar la llamada como una llamada indirecta de objeto. Esto puede ser un problema cuando tienes un subtipo con el mismo nombre que una clase válida.

Por ejemplo:

subtype DateTime => as Object => where { $_->isa('DateTime') };

funciona *tan bien*, mientras que esto:

use DateTime;
subtype DateTime => as Object => where { $_->isa('DateTime') };

causa problemas silenciosos y muchos problemas. La solución simple, así como la futura seguridad de tus subtipos de clases que aún no han sido creadas, es citar el nombre del tipo:

use DateTime;
subtype 'DateTime' => as 'Object' => where { $_->isa('DateTime') };

Restricciones de Tipo Por Defecto

Este módulo también proporciona una jerarquía simple para los tipos de Perl 5, aquí se representa visualmente.

NOTA: Cualquier tipo seguido de un parámetro de tipo "[`a]" puede ser parametrizado, lo que significa que puedes decir:

ArrayRef[Int]    # un array de enteros
HashRef[CodeRef] # una tabla de asociación de string a ref de código
Maybe[Str]       # el valor puede ser un string o undefined

Si Mouse encuentra un nombre entre paréntesis que no reconoce como un tipo existente, asume que es un nombre de clase, por ejemplo "ArrayRef[DateTime]".

NOTA: El tipo de restricción "Undef" funciona correctamente en general, pero hay casos extremos que aún pueden existir, por favor úselo con moderación.

NOTA: La restricción de tipo "ClassName" realiza una verificación compleja de la existencia de un paquete. Esto significa que tu clase debe estar cargada para que esta restricción de tipo funcione.

NOTA: La restricción de tipo "RoleName" verifica que una cadena sea un nombre de paquete que sea un rol, como 'MyApp::Role::Comparable'. La restricción de tipo "Role" verifica que un cumpla con el rol especificado.

Nomenclatura de Restricciones de Tipo

Los nombres de tipo declarados mediante este módulo pueden contener solo caracteres alfanuméricos, puntos (.), y puntos y comas (;).

Dado que los tipos creados por este módulo son globales, se sugiere que nombres tus tipos de manera similar a como lo harías con tus módulos. Así, en lugar de crear un tipo Color para tu módulo My::Graphics, llamarías al tipo My::Graphics::Types::Color.

Usar con Otros Módulos de Restricciones

Este módulo puede integrarse bien con otros módulos de restricciones con un poco de ajuste. La cláusula "where" en los tipos espera que sea una referencia "CODE" que verifique el primer argumento y devuelva un booleano. Dado que la mayoría de los módulos de restricciones funcionan de manera similar, debería ser simple adaptarlos para que funcionen con Mouse.

Por ejemplo, esto es cómo podrías usarlo con Declare::Constraints::Simple para declarar un tipo completamente nuevo.

type 'HashOfArrayOfObjects',
    {
    where => IsHashRef(
        -keys   => HasLength,
        -values => IsArrayRef(IsObject)
    )
};

Aquí hay un ejemplo de uso de Test::Deep y su función "eq_deeply" no relacionada con la prueba.

type 'ArrayOfHashOfBarsAndRandomNumbers'
    => where {
        eq_deeply($_,
            array_each(subhashof({
                bar           => isa('Bar'),
                random_number => ignore()
            })))
      };
