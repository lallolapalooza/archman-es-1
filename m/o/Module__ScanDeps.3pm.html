Nombre

Module::ScanDeps - Escanear código Perl para dependencias

Sintaxis

A través del programa de línea de comandos scandeps.pl:

% scandeps.pl *.pm          # Mostrar la sección PREREQ_PM para *.pm
% scandeps.pl -e "use utf8" # Leer el script desde la línea de comandos
% scandeps.pl -B *.pm       # Incluir módulos de base
% scandeps.pl -V *.pm       # Mostrar archivos de autoload, shared y data

Usado en un programa:

use Module::ScanDeps;
# Uso estándar
my $hash_ref = scan_deps(
    files   => [ 'a.pl', 'b.pl' ],
    recurse => 1,
);
# Formato corto; asumir recurse == 1
my $hash_ref = scan_deps( 'a.pl', 'b.pl' );
# Interfaz compatible con App::Packer::Frontend
# ver App::Packer::Frontend para el formato de retorno de get_files
my $scan = Module::ScanDeps->new;
$scan->set_file( 'a.pl' );
$scan->set_options( add_modules => [ 'Test::More' ] );
$scan->calculate_info;
my $files = $scan->get_files;

Descripción

Este módulo escanea módulos potenciales utilizados por programas Perl y devuelve un referencia a un hash; sus claves son los nombres de módulos como aparecen en %INC (por ejemplo, "Test/More.pm"); los valores son referencias a un hash con esta estructura:

{
    file    => '/usr/local/lib/perl5/5.8.0/Test/More.pm',
    key     => 'Test/More.pm',
    type    => 'module',    # o 'autoload', 'data', 'shared'
    used_by => [ 'Test/Simple.pm', ... ],
    uses    => [ 'Test/Other.pm', ... ],
}

Una función, "scan_deps", se exporta por default. Otros funciones como ("scan_line", "scan_chunk", "add_deps", "path_to_inc_name") se exportan cuando se solicita.

Los usuarios de App::Packer pueden también utilizar este módulo como la interfaz de frontend para verificar dependencias, ajustando su p2e.pl como se muestra a continuación:

use Module::ScanDeps;
...
my $packer = App::Packer->new( frontend => 'Module::ScanDeps' );
...

Por favor vea App::Packer::Frontend para una explicación detallada sobre el formato de retorno de get_files.

scan_deps

$rv_ref = scan_deps(
    files      => \@files,     recurse => $recurse,
    rv         => \%rv,        skip    => \%skip,
    compile    => $compile,    execute => $execute,
);
$rv_ref = scan_deps(@files); # sintaxis corta, con recurse == 1

Esta función escanea cada archivo en @files, registrando sus dependencias en %rv, y devuelve una referencia a %rv actualizada. El significado de los claves y valores se explica arriba.

Si $recurse es verdadero, scan_deps llama recursivamente a sí misma, para realizar un búsqueda de anchura en archivos de texto (como definido por el operador -T).

Si se especifica \%skip, los archivos que existen como sus claves son omitidos. Esto se usa internamente para evitar la recursión infinita.

Si $compile o $execute es verdadero, se ejecutan los archivos en modo solo compilación o modo normal, y se inspeccionan sus %INC después del cierre para determinar dependencias de ejecución adicionales.

Si $execute es un arreglo de referencia, pasa @$execute como argumentos a cada archivo en @files cuando se ejecuta.

Si se preocupa por la velocidad del proceso de escaneo, puede establecer la opción cache_file a un nombre de archivo. Los resultados del escaneo se almacenarán en el archivo y se usará para acelerar el escaneo en futuras ejecuciones.

Además, una opción "warn_missing" es reconocida. Si se establece en verdadero, scan_deps emite un aviso a STDERR para cada archivo de módulo que depende pero no se encuentra. Nota que esto puede también reportar muchos falsos positivos. Por eso, por defecto, el algoritmo de heurística silenciosamente descarta todas las dependencias que no se pueden encontrar.

scan_deps_runtime

Similar a scan_deps, pero omite la parte de escaneo estático.

scan_line

@modules = scan_line($line);

Divide una línea en bloques (actualmente con los caracteres semicolon), y devuelve la unión de llamadas a scan_chunk de ellos.

Si la línea es "__END__" o "__DATA__", se devuelve un elemento "__END__" para indicar el fin del programa.

Similarmente, devuelve un elemento "__POD__" si la línea coincide con "/^=\w/"; el llamador es responsable de saltar el número adecuado de líneas hasta "=cut" antes de llamar a scan_line de nuevo.

scan_chunk

$module = scan_chunk($chunk);
@modules = scan_chunk($chunk);

Aplican diversas heurísticas a $chunk para encontrar y devolver el nombre de módulo (o los nombres) que contiene. En contexto escalar, devuelve solo el primer módulo o "undef".

add_deps

$rv_ref = add_deps( rv => \%rv, modules => \@modules );
$rv_ref = add_deps( @modules ); # sintaxis corta, sin rv

Resuelve una lista de nombres de módulos en su ubicación en disco real, buscando en @INC y @Module::ScanDeps::IncludeLibs; los módulos que no se pueden encontrar son ignorados.

Esta función popula la hash %rv con pares de módulo/filename, y devuelve una referencia a ella.

path_to_inc_name

$perl_name = path_to_inc_name($path, $warn)

Asume $path refiere a un archivo Perl y hace lo mejor posible para devolver el nombre como aparecería en %INC. Devuelve undef si no hay coincidencia y imprime un aviso a STDERR si $warn es verdadero.

Ejemplo: si $path = perl/site/lib/Module/ScanDeps.pm, entonces $perl_name será Module/ScanDeps.pm.

Notas

@Module::ScanDeps::IncludeLibs

Puede establecer esta variable global para especificar directorios adicionales en los cuales buscar módulos sin modificar @INC.

$Module::ScanDeps::ScanFileRE

Puede establecer esta variable global para especificar un patron regular a identificar qué archivos escanear. Por defecto incluye todos los archivos de los siguientes tipos: .pm, .pl, .t y .al. Además, considera todos los archivos sin sufijo.

Por ejemplo, si quieres escanear todos los archivos usa el siguiente:

"$Module::ScanDeps::ScanFileRE = qr/./"

Cuidados

Este módulo intencionalmente ignora el hack BSDPAN en FreeBSD — el directorio adicional se elimina de @INC.

El algoritmo de escaneo estático no es probablemente 100% preciso, especialmente en módulos que cargan otros módulos dinámicamente.

Los bloques que spanjan múltiples líneas no se manejan correctamente. Por ejemplo, este funciona:

use base 'Foo::Bar';

Pero este no funciona:

use base
    'Foo::Bar';

Ver también

scandeps.pl es un utilidad integrada que escribe la sección PREREQ_PM para varios archivos.

Un uso de Module::ScanDeps es generar ejecutables a partir de scripts que contienen módulos de dependencia; este módulo soporta dos proyectos así: PAR y App::Packer. Por favor vea sus respectivas documentaciones en CPAN para más información.

Otras módulos que logran el mismo objetivo con diferente enfoque: Module::ExtractUse, Perl::PrereqScan
