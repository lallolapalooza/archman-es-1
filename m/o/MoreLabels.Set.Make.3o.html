val elements : t -> elt list

Devuelve la lista de todos los elementos del conjunto dado. La lista devuelta está ordenada de forma creciente según el ordenamiento Ord.compare , donde Ord es el argumento dado a MoreLabels.Set.Make .

Devuelve el elemento más pequeño del conjunto dado (según el ordenamiento Ord.compare ), o None si el conjunto está vacío.

Búsqueda

val find : elt -> t -> elt

find x s devuelve el elemento de s igual a x (según Ord.compare ), o lanza Not_found si no existe tal elemento.

Desde 4.01

val find_opt : elt -> t -> elt option

find_opt x s devuelve el elemento de s igual a x (según Ord.compare ), o None si no existe tal elemento.

Desde 4.05

val find_first : f:(elt -> bool) -> t -> elt

find_first ~f s , donde f es una función monótonamente creciente, devuelve el elemento más bajo e de s tal que f e , o lanza Not_found si no existe tal elemento.

Por ejemplo, find_first (fun e -> Ord.compare e x >= 0) s devolverá el primer elemento e de s donde Ord.compare e x >= 0 (intuitivamente: e >= x ), o lanza Not_found si x es mayor que cualquier elemento de s .

Desde 4.05

val find_last : f:(elt -> bool) -> t -> elt

Recorrido

val iter : f:(elt -> unit) -> t -> unit

iter ~f s aplica f sucesivamente a todos los elementos de s . Los elementos de s se presentan a f en orden creciente según el ordenamiento sobre el tipo de los elementos.

val fold : f:(elt -> 'acc -> 'acc) -> t -> init:'acc -> 'acc

fold ~f s init calcula (f xN ... (f x2 (f x1 init))...) , donde x1 ... xN son los elementos de s , en orden creciente.

Transformación

val map : f:(elt -> elt) -> t -> t

map ~f s es el conjunto cuyos elementos son f a0 , f a1 ... f
aN , donde a0 , a1 ... aN son los elementos de s .

Los elementos se pasan a f en orden creciente según el ordenamiento sobre el tipo de los elementos.

Si ningún elemento de s es modificado por f , se devuelve s sin cambios. (Si cada salida de f es físicamente igual a su entrada, el conjunto devuelto es físicamente igual a s .)

Desde 4.04

val filter : f:(elt -> bool) -> t -> t

filter ~f s devuelve el conjunto de todos los elementos de s que satisfacen el predicado f . Si f satisface todos los elementos de s , se devuelve s sin cambios (el resultado de la función es físicamente igual a s ).

Antes de 4.03 La igualdad física no estaba garantizada.

val filter_map : f:(elt -> elt option) -> t -> t

filter_map ~f s devuelve el conjunto de todos los v tales que f x = Some v para algún elemento x de s .

Por ejemplo,

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
es el conjunto de las mitades de los elementos pares de s .

Si ningún elemento de s es modificado o descartado por f (si f x = Some x para cada elemento x ), entonces se devuelve s sin cambios: el resultado de la función es físicamente igual a s .

Key functions

val empty : t

The empty set.

val singleton : elt -> t

A set with one element.

val is_singleton : t -> elt option

Return Some x if the set is a singleton {x}, and None otherwise.

val find_singleton : t -> elt

Return the element of the set. Raise an exception if the set is not a singleton.

val remove : elt -> t -> t

Remove the given element from the set.

val add : elt -> t -> t

Add the given element to the set.

val union : t -> t -> t

Return the union of two sets.

val disjoint_union : t -> t -> t

Return the disjoint union of two sets. Raise an exception if the two sets have a non-empty intersection.

val intersection : t -> t -> t

Return the intersection of two sets.

val diff : t -> t -> t

Return the difference of two sets.

val filter : f:(elt -> bool) -> t -> t

Keep only the elements satisfying the predicate.

val partition : f:(elt -> bool) -> t -> t * t

Partition the set into two sets: those satisfying the predicate, and those not satisfying it.

val partition_map : f:(elt -> elt * elt) -> t -> t * t

Partition the set according to the result of the function. The function must return two values, and the elements are put into the first or the second set.

val split : elt -> t -> t * bool * t

split x s returns a triple (l, present, r) , where l is the set of elements of s that are strictly less than x ; r is the set of elements of s that are strictly greater than x ; present is false if s contains no element equal to x , or true if s contains an element equal to x .

Predicates and comparisons

val is_empty : t -> bool

Test whether a set is empty or not.

val mem : elt -> t -> bool

mem x s tests whether x belongs to the set s .

val equal : t -> t -> bool

equal s1 s2 tests whether the sets s1 and s2 are equal, that is, contain equal elements.

val compare : t -> t -> int

Total ordering between sets. Can be used as the ordering function for doing sets of sets.

val subset : t -> t -> bool

subset s1 s2 tests whether the set s1 is a subset of the set s2 .

val for_all : f:(elt -> bool) -> t -> bool

for_all ~f s checks if all elements of the set satisfy the predicate f .

val exists : f:(elt -> bool) -> t -> bool

exists ~f s checks if at least one element of the set satisfies the predicate f .
