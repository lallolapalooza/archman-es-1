Mouse::Exporter(3pm) Documentación de Perl contribuida por el usuario Mouse::Exporter(3pm)

NOMBRE

Mouse::Exporter - crea un import() y un unimport() igual que Mouse.pm

VERSIÓN

Este documento describe Mouse versión v2.6.0

SINOPSIS

package MyApp::Mouse;
use Mouse ();
use Mouse::Exporter;
Mouse::Exporter->setup_import_methods(
  as_is => [ 'has_rw', 'other_sugar', \&Some::Random::thing ],
  also  => 'Mouse',
);
sub has_rw {
    my $meta = caller->meta;
    my ( $name, %options ) = @_;
    $meta->add_attribute(
      $name,
      is => 'rw',
      %options,
    );
}
# luego más tarde...
package MyApp::User;
use MyApp::Mouse;
has 'name';
has_rw 'size';
thing;
no MyApp::Mouse;

DESCRIPCIÓN

Este módulo encapsula la exportación de funciones de azúcar de una manera similar a "Mouse.pm". Lo hace construyendo métodos personalizados "import" y "unimport" para tu módulo, basándose en una especificación que proporciones.

Ten en cuenta que "Mouse::Exporter" no proporciona la opción "with_meta", pero puedes obtener fácilmente la metaclasse usando "caller->meta" como muestra la "SINOPSIS".

MÉTODOS

setup_import_methods( ARGUMENTOS )

"build_import_methods( ARGUMENTOS ) -> (\&import, \&unimport)"

VER TAMBIÉN

Moose::Exporter
