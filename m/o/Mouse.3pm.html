NOMBRE

Mouse - Moose sin los antílope

VERSION

Este documento describe la versión de Mouse v2.6.0

SYNOPSIS

package Point;
use Mouse; # automáticamente activa strict y warnings
has 'x' => (is => 'rw', isa => 'Int');
has 'y' => (is => 'rw', isa => 'Int');
sub clear {
    my($self) = @_;
    $self->x(0);
    $self->y(0);
}
__PACKAGE__->meta->make_immutable();
package Point3D;
use Mouse;
extends 'Point';
has 'z' => (is => 'rw', isa => 'Int');
after 'clear' => sub {
    my($self) = @_;
    $self->z(0);
};
__PACKAGE__->meta->make_immutable();

DESCRIPCIÓN

Moose es un sistema de objetos postmoderno para Perl5. Moose es increíble.

Sin embargo, Moose tiene un costo de compilación. Aunque se ha hecho un gran progreso en los años, el costo de compilación es un no-estudiante para algunas aplicaciones muy específicas. Si estás escribiendo una aplicación de línea de comandos o un script CGI donde el tiempo de inicialización es esencial, tal vez no puedas usar Moose (recomendamos que uses entornos de ejecución de Perl persistente como FastCGI para los últimos, si es posible).

Mouse es un sistema de objetos compatible con Moose, que busca aliviar este costo mediante una parte de las funcionalidades de Moose.

También estamos intentando ser tan light en dependencias como sea posible. Mouse actualmente tiene ninguna dependencia excepto para los módulos de construcción y prueba. Mouse también funciona sin XS, aunque tiene un backend XS para hacerlo más rápido.

Compatibilidad con Moose

La compatibilidad con Moose ha sido la más preocupante. La interfaz dulce es altamente compatible con Moose. Incluso los mensajes de error son tomados de Moose. El código de Mouse solo corre su test suite 4x más rápido.

La idea es que, si necesitas el poder extra, deberías poder ejecutar "s/Mouse/Moose/g" en tu código y que nada se rompa. Para este fin, hemos escrito Any::Moose que actuará como Mouse, a menos que Moose esté cargado, en cuyo caso actúa como Moose. Dado que Mouse es un poco más flojo que Moose, si hay errores inusuales, sería valioso ejecutar:

ANY_MOOSE=Moose perl your-script.pl

para ver si el error está causado por Mouse. Las диагностicas y validaciones de Moose también son mejores.

Ver también Mouse::Spec para compatibilidad y incompatibilidad con Moose.

Extensión de Mouse

No te copies el código de MooseX a MouseX. Si necesitas extensiones, deberías actualizar a Moose. No necesitamos dos conjuntos paralelos de extensiones!

Si realmente debes escribir una extensión de Mouse, por favor contacta al listado de correo de Moose o #moose en IRC previamente.

PALABRAS CLAVE

"$object->meta -> Mouse::Meta::Class"

Devuelve este clase' instanciador de metaclass.

"extends superclasses"

Establece las superclases de esta clase.

"before (method|methods|regexp) => CodeRef"

Instala un modificador de método "before". Véase "before" en Moose.

"after (method|methods|regexp) => CodeRef"

Instala un modificador de método "after". Véase "after" en Moose.

"around (method|methods|regexp) => CodeRef"

Instala un modificador de método "around". Véase "around" en Moose.

"has (name|names) => parameters"

Añade una propiedad (o si se le pasa un arrayref de nombres, múltiples propiedades) a esta clase. Opciones:

"is => ro|rw|bare"
El opción is acepta either rw (para lectura/escritura), ro (para lectura solo) o bare (sin nada). Estos crearán un acceso lector/escritor o un acceso solo lector, usando el mismo nombre que el $name de la propiedad.

Si quieres tener más control sobre cómo se denominan tus accesorios, puedes usar las opciones "reader", "writer" y "accessor", pero si usas esas, no necesitas la opción is.

"isa => TypeName | ClassName"
Proporciona validación de tipo en el constructor y accesor. Las siguientes tipos son soportados. Cualquier tipo desconocido se considera un chequeo de clase (por ejemplo, "isa => 'DateTime'" acepta solo objetos DateTime). 
Any Item Bool Undef Defined Value Num Int Str ClassName
Ref ScalarRef ArrayRef HashRef CodeRef RegexpRef GlobRef
FileHandle Object

Para más información sobre las restricciones de tipos, vea Mouse::Util::TypeConstraints.

"does => RoleName"
Está aceptado el nombre de una rol que el valor almacenado en esta propiedad espera que tenga consumido.
"coerce => Bool"
Intenta usar coerción con el tipo de restricción proporcionado para cambiar el valor pasado a cualquier accesor o constructor. Debes especificar un tipo de restricción para que esto funcione. Véase Moose::Cookbook::Basics::Recipe5 para un ejemplo.
"required => Bool"
¿Es necesaria una valor para esta propiedad? Si la propiedad es lazada o tiene un constructor, entonces proporcionar un valor para la propiedad en el constructor es opcional.
"init_arg => Str | Undef"
Permite usar un nombre de clave diferente en el constructor. Si es undef, la propiedad no puede ser pasada al constructor.
"default => Value | CodeRef"
Establece el valor por defecto de la propiedad. Si el valor por defecto es un código de referencia, se invocará para obtener el valor por defecto. Debido a los cuirios de Perl, cualquier referencia bárica está prohibida, debes envolver la referencia en un código de referencia. De lo contrario, todas las instancias compartirán la misma referencia.
"lazy => Bool"
Si especificado, el valor por defecto se calcula en tiempo de demanda en lugar del constructor.
"predicate => Str"
Permite especificar un nombre de método para instalar un método predicat, que verifica que la propiedad tiene un valor. No invoca un valor por defecto o un método de constructor.
"clearer => Str"
Permite instalar un método para borrar el valor de la propiedad de la instancia. En la siguiente lectura, el valor por defecto o el método de constructor se invocará.
"handles => HashRef|ArrayRef|Regexp"
Permite especificar métodos para delegar a la propiedad. El ArrayRef pasa los nombres de métodos dadas a las llamadas de método de la propiedad. El HashRef mapa los métodos locales a los nombres remotos de la propiedad. Otros formas de "handles", como RolName y Código de referencia, no son aún soportadas.
"weak_ref => Bool"
Permite automaticamente debilizar cualquier referencia almacenada en la propiedad.

La utilización de esta característica requiere Scalar::Util!

"trigger => CodeRef"
Cualquier vez que el valor de la propiedad se establece (a través del accesor o del constructor), se llama al trigger. El trigger recibe como argumentos la instancia, el nuevo valor y opcionalmente el valor anterior si es diferente del antiguo.

Mouse - Perl documentation

NAME

Mouse - object oriented framework for Perl

VERSION

v2.6.0

SYNOPSIS

    package MyClass;
    use Mouse;
    extends 'AnotherClass';
    
    has 'foo' => (
        is => 'rw',
        isa => 'Str',
        required => 1,
    );
    
    has 'bar' => (
        is => 'rw',
        isa => 'Int',
        default => 0,
    );
    
    sub BUILD {
        my ($self, $args) = @_;
        # ...
    }
    
    sub _build_foo {
        my $self = shift;
        # ...
        return $new_value;
    }
    
    sub DESTROY {
        # ...
    }
    
    __PACKAGE__->meta->make_immutable;
    
    package main;
    my $obj = MyClass->new( foo => 'baz' );
    $obj->foo('bar');
    print $obj->foo;
    print $obj->bar;

DESCRIPTION

Mouse is an object oriented framework for Perl. It provides a powerful and flexible way to define classes, attributes, methods, and roles.

Mouse aims to be a lighter alternative to Moose, providing the most commonly used features of Moose with a simpler interface.

KEYWORDS

Mouse provides several keywords that can be used within a class definition:

"package NAME;"
Declares a package as a class.
"use Mouse;"
Enables the Mouse framework for the current package. This will also set the superclass of the class to Mouse::Object unless specified otherwise with extends.
"extends 'SuperClass';"
Explicitly sets the superclass for the current class. This must be called before use Mouse.
"has $name => (%options);"
Defines an attribute for the class. The attribute name is the scalar variable preceded by a dollar sign (e.g., $foo). The options hash allows you to configure the attribute's behavior.

Attribute Options

"is => 'rw' | 'r' | 'w' | 'wo' | 'lazy' | 'ro'"
Specifies the visibility and mutability of the attribute.
"rw"
Read-write attribute. Creates an accessor and a mutator.
"r"
Read-only attribute. Creates only an accessor.
"w"
Write-only attribute. Creates only a mutator.
"wo"
Write-only attribute. Alias for "w".
"lazy"
Lazy initialization. The attribute's value is computed only when it's first accessed. This implies read-only access after initialization.
"ro"
Read-only attribute. Alias for "r".
"isa => $type_constraint"
Specifies the type constraint for the attribute. This can be a simple type name (e.g., 'Str', 'Int') or a more complex constraint defined using MooseX::Types or similar modules.
"required => Bool"
If true, the attribute must be provided when creating an instance of the class. If false (the default), it is optional.
"default => $value | \&coderef"
Specifies the default value for the attribute. This can be a scalar value or a coderef that will be called to compute the default value. The coderef receives the object itself as the first argument.
"builder => $method_name"
Defines a method name to be called to provide the default value of the attribute. "builder => 'build_foo'" is mostly equivalent to "default => sub { $_[0]->build_foo }".
"auto_deref => Bool"
Allows you to automatically dereference ArrayRef and HashRef attributes in list context. In scalar context, the reference is returned (NOT the list length or bucket status). You must specify an appropriate type constraint to use auto_deref.
"lazy_build => Bool"
Automatically define the following options: 
has $attr => (
# ...
    lazy      => 1
    builder   => "_build_$attr",
    clearer   => "clear_$attr",
    predicate => "has_$attr",
);

"confess(message) -> BOOM"

"confess" in Carp for your convenience.

"blessed(value) -> ClassName | undef"

"blessed" in Scalar::Util for your convenience.

MISC

import

Importing Mouse will default your class' superclass list to Mouse::Object. You may use "extends" to replace the superclass list.

unimport

Please unimport Mouse ("no Mouse") so that if someone calls one of the keywords (such as "extends") it will break loudly instead breaking subtly.

cpanm Minilla

minil release
