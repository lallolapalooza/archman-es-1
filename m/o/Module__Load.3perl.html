Module::Load(3perl) Perl Programmers Reference Guide Module::Load(3perl)

NOMBRE

Module::Load - carga en tiempo de ejecución de módulos y archivos

SINOPSIS

use Module::Load;
my $module = 'Data::Dumper';
load Data::Dumper;     # carga ese módulo, pero no importa ninguna función
                       # -> no se puede usar la función 'Dumper'
load 'Data::Dumper';   # lo mismo
load $module           # lo mismo
autoload Data::Dumper; # carga ese módulo e importa las funciones por defecto
                       # -> se puede usar la función 'Dumper'
my $script = 'some/script.pl'
load $script;
load 'some/script.pl';  # usar comillas porque hay puntuación
load thing;             # intenta 'thing' primero, luego 'thing.pm'
load CGI, ':all';       # como 'use CGI qw[:standard]'

DESCRIPCIÓN

"Module::Load" elimina la necesidad de saber si estás intentando requerir un archivo o un módulo.

Si consultas "perldoc -f require" verás que "require" se comportará de manera diferente cuando se le da una palabra desnuda o una cadena.

En el caso de una cadena, "require" asume que quieres cargar un archivo. Pero en el caso de una palabra desnuda, asume que te refieres a un módulo.

Esto da una sobrecarga desagradable cuando intentas requerir módulos dinámicamente en tiempo de ejecución, ya que necesitarás cambiar la notación del módulo ("Acme::Comment") a una notación de archivo que se ajuste a la plataforma específica en la que te encuentras.

"Module::Load" elimina la necesidad de esta sobrecarga y simplemente hará lo que tú quieres (DWYM).

Diferencia entre "load" y "autoload"

"Module::Load" importa las dos funciones: "load" y "autoload".

"autoload" importa las funciones por defecto automáticamente, pero "load" no importa ninguna función.

"autoload" es usable bajo "BEGIN{};".

Ambas funciones pueden importar las funciones especificadas.

Los siguientes códigos son iguales.

load File::Spec::Functions, qw/splitpath/;
autoload File::Spec::Functions, qw/splitpath/;

FUNCIONES

load
Carga un módulo especificado.

Ver "Reglas" para detalles de la regla de carga.

autoload
Carga un módulo especificado e importa las funciones por defecto.

Excepto por la importación de funciones, 'autoload' es lo mismo que 'load'.

load_remote
Carga un módulo especificado en el paquete especificado. 
use Module::Load 'load_remote';
my $pkg = 'Other::Package';
load_remote $pkg, 'Data::Dumper'; # carga un módulo en 'Other::Package'
                                  # pero no importa la función 'Dumper'

El módulo a cargar debe ir entre comillas.

Excepto por especificar el paquete y el nombre del módulo entre comillas, 'load_remote' es lo mismo que 'load'.

autoload_remote
Carga un módulo especificado e importa las funciones por defecto en el paquete especificado. 
use Module::Load 'autoload_remote';
my $pkg = 'Other::Package';
autoload_remote $pkg, 'Data::Dumper'; # carga un módulo en 'Other::Package'
                                      # e importa la función 'Dumper'

El módulo a cargar debe ir entre comillas.

Excepto por especificar el paquete y el nombre del módulo entre comillas, 'autoload_remote' es lo mismo que 'load_remote'.

Reglas

Todas las funciones tienen las siguientes reglas para decidir qué piensan que quieres:

  • Si el argumento tiene algún carácter que no sea los que coinciden con "\w", ":" o "'", debe ser un archivo.
  • Si el argumento solo coincide con "[\w:']", debe ser un módulo.
  • Si el argumento solo coincide con "\w", podría ser un módulo o un archivo. Intentaremos encontrar "file.pm" primero en @INC y si eso falla, intentaremos encontrar "file" en @INC. Si ambos fallan, morimos con los respectivos mensajes de error.

IMPORTA LAS FUNCIONES

'load' y 'autoload' se importan por defecto, pero 'load_remote' y 'autoload_remote' no se importan.

Para usar 'load_remote' o 'autoload_remote', especifícalo en 'use'.

"load","autoload","load_remote","autoload_remote"
Importa las funciones seleccionadas. 
# importa 'load' y 'autoload' (por defecto)
use Module::Load;
# importa solo 'autoload'
use Module::Load 'autoload';
# importa 'autoload' y 'autoload_remote', pero no importa 'load';
use Module::Load qw/autoload autoload_remote/;
'all'
Importa todas las funciones. 
use Module::Load 'all'; # importa load, autoload, load_remote, autoload_remote
'','none',undef
No importa ninguna función (no se importan "load" y "autoload"). 
use Module::Load '';
use Module::Load 'none';
use Module::Load undef;

Advertencias

Debido a un error en perl (#19213), al menos en la versión 5.6.1, tenemos que codificar la ruta del separador para un require en Win32 como "/", como en Unix en lugar del Win32 "\". De lo contrario, perl no leerá su propio %INC con precisión, cargará archivos doblemente si se requieren de nuevo, o en el peor de los casos, fallará.

"Module::Load" no puede hacer importaciones implícitas, solo explícitas. (en otras palabras, siempre tienes que especificar explícitamente qué deseas importar de un módulo, incluso si las funciones están en el @EXPORT de ese módulo)

"require" en perlfunc https://metacpan.org/pod/perlfunc#require y "use" en perlfunc https://metacpan.org/pod/perlfunc#use.

Mojo::Loader es un "cargador de clases y framework de plugins", y está incluido en la distribución de Mojolicious https://metacpan.org/release/Mojolicious.

Module::Loader es un módulo para encontrar y cargar módulos en un espacio de nombres dado, inspirado por "Mojo::Loader".

NAME

Module::Load - A module to load modules

SYNOPSIS

use Module::Load;

load module => 'Some::Module';
load module => 'Some::Module', '1.23'; # Load if version is at least 1.23
load qw(Some::Module Another::Module);  # Load multiple modules

load qw(Some::Module), $version;       # Load a module with a version constraint
load qw(Some::Module), '1.23';        # Load a module with a specific version constraint
load qw(Some::Module), &$version;       # Load a module with a version constraint from a variable

# Can also load functions from a module and specify a version constraint
load qw(My::Module &my_function), '1.0';

# load will also load the module in the current scope, not just globally
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace';
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace', functions => [qw(my_func another_func)];
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace', functions => [qw(my_func another_func)], import_names => 1;

# Load multiple modules with version constraints
load qw(Module::A Module::B), ['1.0', '2.0'];

# Load modules with specific versions
load qw(Module::A Module::B), { 'Module::A' => '1.0', 'Module::B' => '2.0' };

# Load modules from a hash ref with version constraints
load $modules_with_versions;

# Load modules in a specific package with specific versions
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace';
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace', functions => [qw(my_func another_func)];
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace', functions => [qw(my_func another_func)], import_names => 1;

# If you want to load a module and get its subroutines into the current package,
# you can do so like this:
load module => 'My::Module', import_names => 1;
load module => 'My::Module', import_names => [qw(my_func another_func)];

# load also supports loading of functions from a module that has
# EXPORT_OK defined.
load module => 'My::Module', functions => [qw(my_func another_func)];
load module => 'My::Module', functions => [qw(my_func another_func)], import_names => 1;

# If you want to load a module, but don't want to import anything from it,
# you can use 'import_names => 0'.
load module => 'My::Module', import_names => 0;

# If you want to load a module, but don't want to import anything from it,
# but want to load some functions from it, you can use 'import_names => 0'
# and specify the functions you want to load.
load module => 'My::Module', functions => [qw(my_func another_func)], import_names => 0;

# Load modules and their functions into a specific namespace
load module => 'My::Module', in_package => 'My::Namespace', functions => [qw(my_func another_func)];
load module => 'My::Module', in_package => 'My::Namespace', functions => [qw(my_func another_func)], import_names => 1;

# Load a module with a version constraint and import its functions into a specific namespace
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace', functions => [qw(my_func another_func)];
load module => 'My::Module', version => '1.23', in_package => 'My::Namespace', functions => [qw(my_func another_func)], import_names => 1;

# Load modules and their functions, specifying the target package for the functions
load module => 'My::Module', functions => [qw(my_func another_func)], target_package => 'My::Target::Namespace';
load module => 'My::Module', functions => [qw(my_func another_func)], import_names => 1, target_package => 'My::Target::Namespace';

# Load modules and their functions, specifying the target package for the functions and a version constraint
load module => 'My::Module', version => '1.23', functions => [qw(my_func another_func)], target_package => 'My::Target::Namespace';
load module => 'My::Module', version => '1.23', functions => [qw(my_func another_func)], import_names => 1, target_package => 'My::Target::Namespace';

# Load all modules from a list of module names
load qw(Module::A Module::B Module::C);

# Load all modules from a list of module names with version constraints
load qw(Module::A Module::B Module::C), '1.0';
load qw(Module::A Module::B Module::C), ['1.0', '2.0', '3.0'];
load qw(Module::A Module::B Module::C), { 'Module::A' => '1.0', 'Module::B' => '2.0', 'Module::C' => '3.0' };

# Load all modules from a list of module names with version constraints and import all their functions
load qw(Module::A Module::B Module::C), import_names => 1;
load qw(Module::A Module::B Module::C), ['1.0', '2.0', '3.0'], import_names => 1;
load qw(Module::A Module::B Module::C), { 'Module::A' => '1.0', 'Module::B' => '2.0', 'Module::C' => '3.0' }, import_names => 1;

# Load all modules from a list of module names with version constraints and import specific functions
load qw(Module::A Module::B Module::C), functions => [qw(funcA funcB funcC)];
load qw(Module::A Module::B Module::C), ['1.0', '2.0', '3.0'], functions => [qw(funcA funcB funcC)];
load qw(Module::A Module::B Module::C), { 'Module::A' => '1.0', 'Module::B' => '2.0', 'Module::C' => '3.0' }, functions => [qw(funcA funcB funcC)];

# Load all modules from a list of module names with version constraints and import specific functions into a specific package
load qw(Module::A Module::B Module::C), functions => [qw(funcA funcB funcC)], in_package => 'My::Namespace';
load qw(Module::A Module::B Module::C), ['1.0', '2.0', '3.0'], functions => [qw(funcA funcB funcC)], in_package => 'My::Namespace';
load qw(Module::A Module::B Module::C), { 'Module::A' => '1.0', 'Module::B' => '2.0', 'Module::C' => '3.0' }, functions => [qw(funcA funcB funcC)], in_package => 'My::Namespace';

# Load all modules from a list of module names with version constraints and import specific functions into a specific package with import_names set to 1
load qw(Module::A Module::B Module::C), functions => [qw(funcA funcB funcC)], in_package => 'My::Namespace', import_names => 1;
load qw(Module::A Module::B Module::C), ['1.0', '2.0', '3.0'], functions => [qw(funcA funcB funcC)], in_package => 'My::Namespace', import_names => 1;
load qw(Module::A Module::B Module::C), { 'Module::A' => '1.0', 'Module::B' => '2.0', 'Module::C' => '3.0' }, functions => [qw(funcA funcB funcC)], in_package => 'My::Namespace', import_names => 1;

# Load a module with a version constraint and import all its functions
load module => 'My::Module', version => '1.23', import_names => 1;

# Load a module with a version constraint and import specific functions
load module => 'My::Module', version => '1.23', functions => [qw(my_func another_func)];

# Load a module with a version constraint and import specific functions into a specific package
load module => 'My::Module', version => '1.23', functions => [qw(my_func another_func)], in_package => 'My::Namespace';

# Load a module with a version constraint and import specific functions into a specific package with import_names set to 1
load module => 'My::Module', version => '1.23', functions => [qw(my_func another_func)], in_package => 'My::Namespace', import_names => 1;

DESCRIPTION

Module::Load is a module that provides a convenient way to load other modules. It can load modules by name, and optionally specify a version constraint. It can also load specific functions from a module, and import them into the current package or a specified package.

FUNCTIONS

load

Loads one or more modules. The arguments can be:

  • module => 'Module::Name': Loads the module 'Module::Name'.
  • module => 'Module::Name', version => '1.23': Loads the module 'Module::Name' if its version is at least '1.23'.
  • qw(Module::A Module::B): Loads multiple modules.
  • qw(Module::A Module::B), '1.0': Loads multiple modules with a version constraint of '1.0'.
  • qw(Module::A Module::B), ['1.0', '2.0']: Loads multiple modules with version constraints '1.0' and '2.0' respectively.
  • qw(Module::A Module::B), { 'Module::A' => '1.0', 'Module::B' => '2.0' }: Loads multiple modules with specific version constraints.
  • functions => [qw(func1 func2)]: Specifies the functions to import from the module(s).
  • in_package => 'Package::Name': Specifies the package into which the functions should be imported.
  • import_names => 1: Imports all available functions from the module(s).
  • import_names => [qw(func1 func2)]: Imports specific functions from the module(s).
  • import_names => 0: Does not import any functions from the module(s).
  • target_package => 'Package::Name': Specifies the target package for the imported functions. This is an alias for in_package.

Rules

  • If a version constraint is provided, Module::Load will check if the loaded module meets the constraint. If not, it will throw an error.
  • If import_names => 1 is used, all functions exported by the module (including those in EXPORT_OK) will be imported.
  • If functions => [...] is used, only the specified functions will be imported.
  • If in_package => 'Package::Name' is used, the functions will be imported into the specified package. Otherwise, they will be imported into the current package.

IMPORTS THE FUNCTIONS

Module::Load exports the load function.

Caveats

  • Module::Load will die if it cannot load a module or if the version constraint is not met.
  • Module::Load will also die if it cannot import the requested functions.
