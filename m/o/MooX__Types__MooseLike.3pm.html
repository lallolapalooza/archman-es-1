NOMBRE

MooX::Types::MooseLike - algunos tipos al estilo Moose y un constructor de tipos

SINOPSIS

package MyApp::Types;
use MooX::Types::MooseLike;
use base qw(Exporter);
our @EXPORT_OK = ();
# Definir algunos tipos
my $defs = [{
  name => 'MiTipo',
  test => sub { predicado($_[0]) },
  message => sub { "$_[0] no es el tipo que queremos!" }
},
{
  name => 'VarChar',
  test => sub {
    my ($valor, $parametro) = @_;
    length($valor) <= $parametro;
  },
  message => sub { "$_[0] es demasiado grande! Debería ser menor o igual a $_[1]." }
}];
# Hacer los tipos disponibles - esto los añade automáticamente a @EXPORT_OK.
MooX::Types::MooseLike::register_types($defs, __PACKAGE__);
...
# En algún lugar del código que usa el tipo
package MyApp::Foo;
use Moo;
use MyApp::Types qw(MiTipo VarChar);
has atributo => (
  is  => 'ro',
  isa => MiTipo,
);
has cadena => (
  is  => 'ro',
  isa => VarChar[25]
);

DESCRIPCIÓN

Este módulo proporciona una posibilidad para construir tu propio conjunto de tipos al estilo Moose. Estos tipos personalizados se pueden usar para describir campos en clases basadas en Moo.

Ver MooX::Types::MooseLike::Base para una lista de tipos base disponibles. Su fuente también proporciona un ejemplo de cómo construir tipos base, junto con tipos parametrizables y no parametrizables.

FUNCIONES

register_types

register_types( tipos, paquete, namespace_moose )

Instala los tipos dados dentro del paquete. Esto hace que los tipos sean automáticamente exportables al añadirlos a @EXPORT_OK del paquete. Se espera que los tipos sean una referencia de array donde cada tipo tiene el siguiente formato:

{
  name            => 'MiTipo',
  test            => sub { comprobar_el_valor_de_alguna_manera($_[0]) },
  message         => sub { "$_[0] no es el tipo que queremos!" },
  subtype_of      => 'TipoPadreAlguno',           # Opcional
  from            => 'Algun/Paquete/TiposGeniales',  # Opcional
  parameterizable => sub { ... },                # Opcional
  inflate         => sub { ... },                # Opcional
}

Un tipo puede declararse con una referencia (subtype_of) a algún tipo declarado previamente. En este caso, el nuevo tipo heredará el comportamiento del tipo referenciado.

El tipo referenciado puede provenir del mismo paquete o de un paquete de terceros:

MooX::Types::MooseLike::register_types([{
  name       => 'MayorQue10',
  subtype_of => 'Int',
  from       => 'MooX::Types::MooseLike::Base',
  test       => sub { $_[0] > 10 },
  message    => sub { 'no es mayor que 10' },
}], __PACKAGE__);
MooX::Types::MooseLike::register_types([{
  name       => 'Entre10y20',
  subtype_of => 'MayorQue10',
  from       => __PACKAGE__,
  test       => sub { $_[0] < 20 },
  message    => sub { 'no es un entero entre 10 y 20' },
}], __PACKAGE__);
MooX::Types::MooseLike::register_types([{
  name       => 'Entre10y30',
  subtype_of => MayorQue10(),
  test       => sub { $_[0] < 30 },
  message    => sub { 'no es un entero entre 10 y 30' },
}], __PACKAGE__);

exception_message

exception_message( valor, parte_de_la_cadena_de_excepcion )

Función auxiliar para ser usada en la definición de un tipo:

{
  ...
  message => sub { return exception_message($_[0], 'un HashRef' },
  ...
}

En caso de que el <valor> no cumpla las restricciones del tipo, produce el mensaje:

"<valor> no es un HashRef!"

inflate_type

inflate_type( coderef )

Infla el tipo a un tipo Moose. Requiere Moose.
