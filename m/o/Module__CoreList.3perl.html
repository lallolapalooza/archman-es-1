Module::CoreList(3perl) Guía de referencia para programadores de Perl Module::CoreList(3perl)

NOMBRE

Module::CoreList - qué módulos se incluyeron con cada versión de Perl

SYNOPSIS

use Module::CoreList;
print $Module::CoreList::version{5.00503}{CPAN}; # imprime 1.48
print Module::CoreList->first_release('File::Spec');
# imprime 5.00405
print Module::CoreList->first_release_by_date('File::Spec');
# imprime 5.005
print Module::CoreList->first_release('File::Spec', 0.82);
# imprime 5.006001
if (Module::CoreList::is_core('File::Spec')) {
  print "File::Spec es un módulo de core\n";
}
print join ', ', Module::CoreList->find_modules(qr/Data/);
   # imprime 'Data::Dumper'
print join ', ',
         Module::CoreList->find_modules(qr/test::h.*::.*s/i, 5.008008);
   # imprime 'Test::Harness::Assert, Test::Harness::Straps'
print join ", ", @{ $Module::CoreList::families{5.005} };
   # imprime "5.005, 5.00503, 5.00504"

DESCRIPCIÓN

Module::CoreList proporciona información sobre qué módulos de core y de vida dual se incluyeron con cada versión de Perl.

Ofrece varios mecanismos para consultar esta información.

Hay una utilidad llamada corelist proporcionada con este módulo que es un método conveniente para consultar desde la línea de comandos.

También está disponible una API funcional para programadores que desean consultar información.

Los programadores también pueden consultar las estructuras de datos contenidas para encontrar información relevante.

FUNCIONES API

Estas son las funciones disponibles, pueden llamarse como funciones o como métodos de clase:

Module::CoreList::first_release('File::Spec'); # como función
Module::CoreList->first_release('File::Spec'); # como método de clase
first_release( MÓDULO )
Comportamiento desde la versión 2.11

Requiere un nombre de módulo como argumento, devuelve la versión de Perl cuando ese módulo se incluyó en core, ordenada por número de versión de Perl, o indefinido (en contexto de escalar) o una lista vacía (en contexto de lista) si ese módulo no está en core.

first_release_by_date( MÓDULO )
Requiere un nombre de módulo como argumento, devuelve la versión de Perl cuando ese módulo se incluyó en core, ordenada por fecha de lanzamiento, o indefinido (en contexto de escalar) o una lista vacía (en contexto de lista) si ese módulo no está en core.
"find_modules( REGEX, [ LISTA_DE_PERLS ] )"
Recibe un regex como argumento, devuelve una lista de módulos que coincidan con el regex dado. Si solo se proporciona un regex, aplica a todos los módulos de todas las versiones de Perl. Opcionalmente, puedes proporcionar una lista de versiones de Perl para limitar la búsqueda del regex.
find_version( VERSIÓN_PERL )
Recibe una versión de Perl como argumento. Una vez que se completa con éxito, devuelve una referencia a un hash. Cada elemento de ese hash tiene una clave que es el nombre de un módulo (e.g., 'File::Path') que se incluyó con esa versión de Perl y un valor que es la versión numérica (e.g., '2.09') del módulo que se incluyó con esa versión de Perl. Devuelve "undef" en caso de error.
"is_core( MÓDULO, [ VERSIÓN_MÓDULO, [ VERSIÓN_PERL ] ] )"
Disponible desde 2.99 y adelante.

Devuelve true si el módulo MÓDULO se incluyó con la versión específica de Perl especificada. Tú puedes opcionalmente especificar una versión mínima del módulo y también puedes especificar una versión de Perl. Si no se especifica una versión de Perl, is_core() usará la versión numérica de Perl que se está ejecutando (es decir, $]).

Si quieres especificar la versión de Perl, pero no importes la versión del módulo, pasa "undef" para el módulo versión:

"is_deprecated( MÓDULO, VERSIÓN_PERL )"
Disponible desde 2.22 y adelante.

Devuelve true si el módulo MÓDULO está marcado como obsoleto en la versión de Perl especificada. Si VERSIÓN_PERL no se especifica, se usa la versión actual de Perl.

deprecated_in( MÓDULO )
Disponible desde 2.77 y adelante.

Devuelve la primera versión de Perl en la cual el módulo MÓDULO fue marcado como obsoleto. Devuelve "undef" si el módulo no ha sido marcado como obsoleto.

removed_from( MÓDULO )
Disponible desde 2.32 y adelante

Toma un nombre de módulo como argumento, devuelve la primera versión de Perl en la cual ese módulo se eliminó de core. Devuelve undef si el módulo dado nunca fue en core o aún está en core.

removed_from_by_date( MÓDULO )
Disponible desde 2.32 y adelante

Toma un nombre de módulo como argumento, devuelve la primera versión de Perl por fecha de lanzamiento en la cual ese módulo se eliminó de core. Devuelve undef si el módulo dado nunca fue en core o aún está en core.

"changes_between( VERSIÓN_PERL, VERSIÓN_PERL )"
Disponible desde 2.66 y adelante.

Dadas dos versiones de Perl, devuelve una lista de pares que describen los cambios en el contenido de módulos de core entre ellas. La lista es adecuada para almacenar en un hash. Los valores son nombres de bibliotecas y los valores son referencias a hashs. Cada hash tiene una entrada para uno o ambos de "left" y "right", que dan las versiones de la biblioteca en cada distribución de Perl de izquierda y derecha.

Por ejemplo, podría devolver estos datos (entre otros) para la diferencia entre 5.008000 y 5.008001:

'Pod::ParseLink'  => { left => '1.05', right => '1.06' },
'Pod::ParseUtils' => { left => '0.22', right => '0.3'  },
'Pod::Perldoc'    => {                 right => '3.10' },
'Pod::Perldoc::BaseTo' => {            right => undef  },

Esto muestra que dos bibliotecas están actualizadas y dos están añadidas, una de las cuales tiene una versión undefined en la versión de derecha.

DATOS DE ESTRUCTURA

Estas son las estructuras de datos hash disponibles:

%Module::CoreList::version
Un hash de hashes que está clave por la versión de Perl indicada en $]. El segundo nivel del hash es pares de módulo => versión.

Nota: es posible que la versión de un módulo sea no especificada, en cuyo caso el valor es "undef", por lo que se debe usar "exists $version{$foo}{$bar}" si estás probando esto.

Desde 2.10, el módulo especial "Unicode" se refiere a la versión del base de caracteres Unicode bundled con Perl.

%Module::CoreList::delta
Disponible desde 3.00 y adelante.

Es un hash de hashes que está clave por la versión de Perl. Cada hash clave tendrá las siguientes claves:

delta_from - una versión de Perl anterior que las modificaciones se basan en
changed    - un hash de módulos/versión que han cambiado
removed    - un hash de módulos que han sido eliminados
%Module::CoreList::released
Clave por la versión de Perl, contiene versiones ISO de fechas de lanzamiento, obtenidas de perlhist.
%Module::CoreList::families
Nueva, en 1.96, un hash que agrupa conocidos releases de Perl por sus versiones principales.
%Module::CoreList::deprecated
Un hash de hashes clave por la versión de Perl y el nombre del módulo. Si un módulo está definido, indica que el módulo es obsoleto en esa versión de Perl y se está programado para su eliminación de core en algún futuro.
%Module::CoreList::upstream
Un hash que contiene información sobre dónde deben dirigirse las parches para cada módulo de core.

UPSTREAM indica dónde deben ir los parches. "undef" implica que este no ha sido discutido para el módulo en cuestión. "blead" indica que la copia del módulo en los sources de blead debe considerarse canónica, "cpan" significa que el módulo en CPAN debe ser parcheado primero. "first-come" significa que el blead puede ser parcheado libremente.

Module::CoreList - Arch Linux Man Pages

NAME

Module::CoreList - Determine if a module is part of Perl's core modules.

SYNOPSIS

  use Module::CoreList;

  # Has the module been around since perl 5.8.0?
  if (Module::CoreList->version('Module::Name') >= 5.008000) {
      print "Module::Name is a core module since perl 5.8.0";
  }

  # What's the first version of perl that included Module::Name?
  my $first_version = Module::CoreList->first('Module::Name');
  if ($first_version) {
      print "Module::Name was first included in version $first_version";
  }

  # What version of perl is Module::Name included in?
  my $version = Module::CoreList->version('Module::Name');
  if ($version) {
      print "Module::Name is included in version $version";
  }

  # List all modules included in Perl 5.10.0
  my @modules = Module::CoreList->modules(5.010000);
  foreach my $module (@modules) {
      print "$module\n";
  }

  # Get the bug tracker for a core module
  my $bug_tracker = Module::CoreList->bug_tracker('Module::Name');
  if ($bug_tracker) {
      print "Bug tracker for Module::Name is $bug_tracker\n";
  }

DESCRIPTION

This module provides a list of modules that are considered part of Perl's core distribution. It can be used to determine if a given module is part of the core, and if so, which version of Perl it was first included in.

This is useful for module authors who want to determine if they can safely use a particular module without requiring users to install it separately.

FUNCTIONS API

The following functions are available:

version($module_name)
Returns the version of Perl (as a numeric value, e.g. 5.008001) that the given module was first included in. Returns undef if the module is not a core module.
first($module_name)
Returns the version of Perl (as a string, e.g. '5.8.1') that the given module was first included in. Returns undef if the module is not a core module.
modules([$perl_version])
Returns a list of all core modules included in the specified Perl version. If no version is specified, it defaults to the version of Perl running the code. The Perl version should be specified as a numeric value (e.g. 5.008001).
is_core($module_name)
Returns true if the module is a core module, false otherwise.

DATA STRUCTURES

This module also exposes several data structures that can be used directly:

%Module::CoreList::modules
A hash where keys are Perl versions (numeric) and values are lists of core module names included in that version. This is the data structure that the modules() function uses.
%Module::CoreList::version
A hash where keys are module names and values are the first Perl version (numeric) that included that module. This is the data structure that the version() and first() functions use.
%Module::CoreList::bug_tracker
A hash that contains information on the appropriate bug tracker for each core module.

BUGS is an email or url to post bug reports. For modules with UPSTREAM => 'blead', use <mailto:perl5-porters@perl.org>. rt.cpan.org appears to automatically provide a URL for CPAN modules; any value given here overrides the default: http://rt.cpan.org/Public/Dist/Display.html?Name=$ModuleName

CAVEATS

Module::CoreList currently covers the 5.000, 5.001, 5.002, 5.003_07, 5.004, 5.004_05, 5.005, 5.005_03, 5.005_04 and 5.7.3 releases of perl.

All stable releases of perl since 5.6.0 are covered.

All development releases of perl since 5.9.0 are covered.
