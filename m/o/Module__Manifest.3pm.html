Module::Manifest(3) Documentación de Perl aportada por el usuario Module::Manifest(3)

NOMBRE

Module::Manifest - Analiza y examina un archivo MANIFEST de distribución de Perl

VERSIÓN

versión 1.09

SINOPSIS

Abre y analiza MANIFEST y MANIFEST.SKIP:

my $manifest = Module::Manifest->new( 'MANIFEST', 'MANIFEST.SKIP' );

Comprueba si un archivo dado coincide con alguna máscara de omisión conocida:

print "yes\n" if $manifest->skipped('.svn');

DESCRIPCIÓN

Module::Manifest es un módulo de utilidad simple creado originalmente para su uso en Module::Inspector.

Puede cargar un archivo MANIFEST que viene en un archivo tarball de distribución de Perl, examinar su contenido y realizar algunas tareas simples. También puede cargar el archivo MANIFEST.SKIP y comprobarlo.

Ciertamente, la funcionalidad necesaria para hacer esto es bastante simple, pero la especificación MANIFEST de las distribuciones de Perl contiene un par de pequeñas idiosincrasias, como comentarios de línea y comentarios en línea separados por espacios.

El uso de este módulo significa que cualquier pequeña molestia se maneja detrás de escena, y usted puede concentrarse en la tarea principal en cuestión.

Comparación con ExtUtil::Manifest

Este módulo es bastante similar a ExtUtils::Manifest, o al menos similar en alcance. Sin embargo, hay una diferencia general en el enfoque.

ExtUtils::Manifest es imperativo, requiere la existencia del archivo MANIFEST real en el disco y requiere que su directorio actual permanezca igual.

Module::Manifest trata el archivo MANIFEST como un objeto, puede cargar el archivo desde cualquier lugar del disco y puede ejecutar parte de la misma funcionalidad sin tener que cambiar el contexto de su directorio actual.

Dicho esto, tenga en cuenta que Module::Manifest está dirigido a leer y comprobar archivos MANFIFEST existentes, en lugar de crear nuevos.

COMPATIBILIDAD

Este módulo debería ser compatible con Perl 5.005 y superior. Sin embargo, solo ha sido probado rigurosamente bajo Perl 5.10.0 en Linux.

Si encuentra algún problema en una versión o arquitectura diferente, póngase en contacto con el mantenedor.

MÉTODOS

new

Module::Manifest->new( $manifest, $skip )

Crea un objeto "Module::Manifest", que analiza los archivos referenciados por $manifest (para MANIFEST) y $skip (para MANIFEST.SKIP). Si no se especifican parámetros, crea un objeto vacío.

Código de ejemplo:

my $manifest = Module::Manifest->new;
my $manifest = Module::Manifest->new( $manifest );
my $manifest = Module::Manifest->new( $manifest, $skip );

Este método devolverá un objeto Module::Manifest apropiado o lanzará una excepción en caso de error.

open

$manifest->open( $type => $filename )

Abre y analiza el archivo dado por $filename, que puede ser una ruta relativa. Las opciones de $type disponibles son: 'skip' o 'manifest'

Código de ejemplo:

$manifest->open( skip => 'MANIFEST.SKIP' );
$manifest->open( manifest => 'MANIFEST' );

Este método no devuelve nada, pero puede lanzar una excepción en caso de error.

parse

$manifest->parse( $type => \@files )

Analiza "\@files", que es una referencia a un array que contiene una lista de archivos o máscaras de expresión regular. Las opciones de $type disponibles son: 'skip' o 'manifest'

Código de ejemplo:

$manifest->parse( skip => [
     '\B\.svn\b',
     '^Build$',
     '\bMakefile$',
]);

Este método no devuelve nada, pero puede lanzar una excepción en caso de error.

skipped

$manifest->skipped( $filename )

Comprueba si $filename coincide con alguna máscara que deba omitirse, dados los expresiones regulares proporcionados a los métodos "parse" u "open".

Los nombres de ruta absolutos deben primero relativizarse y convertirse a una cadena de ruta similar a Unix utilizando el método "normalize".

Código de ejemplo:

if ($manifest->skipped('Makefile.PL')) {
  # hacer algo
}

Este método devuelve un valor booleano verdadero o falso que indica si la ruta del archivo se omite según el "skipfile".

normalize

Module::Manifest->normalize( $path, $rel )
$manifest->normalize( $path, $rel )

Este método toma una cadena de ruta específica de la plataforma dada y la convierte en una cadena de estilo Unix compatible con las especificaciones de MANIFEST y MANIFEST.SKIP.

Tenga en cuenta que este método normaliza las rutas dependiendo de la plataforma detectada por $^O; es decir, las rutas al estilo Win32 solo se pueden normalizar si el módulo se está ejecutando actualmente en Win32.

Por defecto, este método relativizará las rutas de archivo al directorio de trabajo actual (utilizando el método "abs2rel" de File::Spec sin un $root). Para deshabilitar este comportamiento, establezca $rel a un valor falso.

Código de ejemplo:

# Útil para normalizar rutas al estilo Win32
my $normal = Module::Manifest->normalize('t\\test\\file');
# Devuelve: t/test/file (es decir, en estilo Unix para MANIFEST)

Esto devuelve una versión normalizada de la ruta dada.

file

$manifest->file

El accesor "file" devuelve la ruta absoluta del archivo MANIFEST que se cargó.

skipfile

$manifest->skipfile

El accesor "skipfile" devuelve la ruta absoluta del archivo MANIFEST.SKIP que se cargó.

dir

$manifest->dir

El accesor "dir" devuelve la ruta al directorio que contiene el archivo MANIFEST o skip, y por lo tanto DEBERÍA ser la raíz de la distribución.

files

$manifest->files

El método "files" devuelve la lista (relativa, estilo Unix) de archivos dentro del manifiesto. En contexto escalar, devuelve el número de archivos en el manifiesto.

Código de ejemplo:

my @files = $manifest->files;

LIMITACIONES

El directorio devuelto por el método "dir" se sobrescribe cada vez que se llama a "open". Esto significa que, si MANIFEST y MANIFEST.SKIP no están en el mismo directorio, el módulo puede confundirse un poco.
