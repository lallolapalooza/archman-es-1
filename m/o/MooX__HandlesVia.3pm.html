MooX::HandlesVia(3) Documentación de Perl aportada por el usuario MooX::HandlesVia(3)

NOMBRE

MooX::HandlesVia - Comportamiento similar a NativeTrait para Moo.

VERSIÓN

version 0.001009

SINOPSIS

{
  package Hashy;
  use Moo;
  use MooX::HandlesVia;
  has hash => (
    is => 'rw',
    handles_via => 'Hash',
    handles => {
      get_val => 'get',
      set_val => 'set',
      all_keys => 'keys'
    }
  );
}
my $h = Hashy->new(hash => { a => 1, b => 2});
$h->get_val('b'); # 2
$h->set_val('a', 'BAR'); # establece a en BAR
my @keys = $h->all_keys; # devuelve a, b

DESCRIPCIÓN

MooX::HandlesVia es una extensión de la funcionalidad del atributo 'handles' de Moo. Proporciona un medio para delegar funcionalidad de una clase externa al atributo dado. Esto se usa comúnmente como una forma de emular el comportamiento de 'Native Trait' que se ha vuelto común en el código Moose, para lo cual no existía una alternativa en Moo.

DESVENTAJAS

Debido a los detalles de implementación actuales de Moo, existen algunas deficiencias en MooX::HandlesVia en comparación con lo que cabría esperar de los traits nativos de Moose.

  • los métodos delegados a través de la interfaz 'handles' de Moo reciben el valor del atributo directamente, y no hay forma de acceder a la clase padre. Esto significa que si se actualiza un atributo, los disparadores o las coerciones de tipo NO se activarán.
  • Las delegaciones de métodos de atributos de Moo reciben el valor del atributo. Esto está bien para referencias (objetos, arrays, hashrefs...), pero significa que los tipos escalares simples son de SOLO LECTURA. Desafortunadamente, esto significa que Number, String, Counter, Bool no pueden modificar el valor de los atributos, haciéndolos en gran medida inútiles.

Si estos son problemas para usted, considere Sub::HandlesVia, que utiliza una arquitectura diferente, respetando los disparadores y las coerciones, y permitiendo acceso de lectura/escritura a valores no referenciados. Debería ser posible usar Sub::HandlesVia como un reemplazo directo para MooX::HandlesVia.

INTERFAZ/FUNCIONES PROPORCIONADAS

process_has(@_)
MooX::HandlesVia preprocesa los argumentos pasados a las declaraciones del atributo has() a través de la función process_has. En una clase Moo dada, si 'handles_via' está configurado como una cadena ClassName, y 'handles' está configurado con un mapeo de hashref de los métodos de clase moo deseados que deberían mapearse a métodos de ClassName, process_has() creará la vinculación apropiada para crear el mapeo SI ClassName proporciona ese método con nombre. 
has options => (
  is => 'rw',
  handles_via => 'Array',
  handles => {
    mixup => 'shuffle',
    unique_options => 'uniq',
    all_options => 'elements'
  }
);

Las siguientes palabras clave de handles_via están reservadas como atajos para mapear a Data::Perl:

  • Hash mapea a Data::Perl::Collection::Hash::MooseLike
  • Array mapea a Data::Perl::Collection::Array::MooseLike
  • String mapea a Data::Perl::String::MooseLike
  • Number mapea a Data::Perl::Number::MooseLike
  • Bool mapea a Data::Perl::Bool::MooseLike
  • Code mapea a Data::Perl::Code
