Module::CoreList::Utils(3perl) Guía de referencia del programador de Perl Module::CoreList::Utils(3perl)

NOMBRE

Module::CoreList::Utils - qué utilidades se incluyeron con las versiones de perl

SINOPSIS

use Module::CoreList::Utils;
print $Module::CoreList::Utils::utilities{5.009003}{ptar}; # imprime 1
print Module::CoreList::Utils->first_release('corelist');
# imprime 5.008009
print Module::CoreList::Utils->first_release_by_date('corelist');
# imprime 5.009002

DESCRIPCIÓN

Module::CoreList::Utils proporciona información sobre qué utilidades centrales y de doble vida se incluyeron con cada versión de perl.

Proporciona una serie de mecanismos para consultar esta información.

Hay una API de programación funcional disponible para que los programadores consulten información.

Los programadores también pueden consultar la estructura de hash contenida para encontrar información relevante.

API DE FUNCIONES

Estas son las funciones disponibles, que se pueden llamar como funciones o como métodos de clase:

Module::CoreList::Utils::first_release('corelist'); # como función
Module::CoreList::Utils->first_release('corelist'); # método de clase
"utilities"
Requiere una versión de perl como argumento, devuelve una lista de utilidades que se incluyeron con esa versión de perl, o undef/lista vacía si esa perl no existe.
first_release( UTILITY )
Requiere un nombre de UTILITY como argumento, devuelve la versión de perl en la que esa utilidad apareció por primera vez en el núcleo, ordenado por número de versión de perl, o undef (en contexto escalar) o una lista vacía (en contexto de lista) si esa utilidad no está en el núcleo.
first_release_by_date( UTILITY )
Requiere un nombre de UTILITY como argumento, devuelve la versión de perl en la que esa utilidad apareció por primera vez en el núcleo, ordenado por fecha de lanzamiento, o undef (en contexto escalar) o una lista vacía (en contexto de lista) si esa utilidad no está en el núcleo.
removed_from( UTILITY )
Toma un nombre de UTILITY como argumento, devuelve la primera versión de perl en la que esa utilidad fue eliminada del núcleo. Devuelve undef si la utilidad dada nunca estuvo en el núcleo o permanece en el núcleo.
removed_from_by_date( UTILITY )
Toma un nombre de UTILITY como argumento, devuelve la primera versión de perl por fecha de lanzamiento en la que esa utilidad fue eliminada del núcleo. Devuelve undef si la utilidad dada nunca estuvo en el núcleo o permanece en el núcleo.

ESTRUCTURAS DE DATOS

Estas son las estructuras de hash disponibles:

%Module::CoreList::Utils::utilities
Un hash de hashes que se indexa por la versión de perl indicada en $]. El hash de segundo nivel son pares de utilidad / definidos.
