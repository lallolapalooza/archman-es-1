NOMBRE

Module::Build::ConfigData - Configuración para Module::Build

SINOPSIS

use Module::Build::ConfigData;
$valor = Module::Build::ConfigData->config('foo');
$valor = Module::Build::ConfigData->feature('bar');
@nombres = Module::Build::ConfigData->config_names;
@nombres = Module::Build::ConfigData->feature_names;
Module::Build::ConfigData->set_config(foo => $nuevo_valor);
Module::Build::ConfigData->set_feature(bar => $nuevo_valor);
Module::Build::ConfigData->write;  # Guardar cambios

DESCRIPCIÓN

Este módulo almacena los datos de configuración del módulo "Module::Build". También proporciona una interfaz programática para obtener o establecer dichos datos de configuración. Tenga en cuenta que para realizar cambios reales, deberá tener acceso de escritura al módulo "Module::Build::ConfigData", y debe intentar comprender las repercusiones de sus acciones.

MÉTODOS

config($name)
Dado un argumento de cadena, devuelve el valor del elemento de configuración con ese nombre, o "undef" si no existe tal elemento.
feature($name)
Dado un argumento de cadena, devuelve el valor de la característica con ese nombre, o "undef" si no existe tal característica.
set_config($name, $value)
Establece el elemento de configuración con el nombre dado al valor dado. El valor puede ser cualquier escalar de Perl que se serialice correctamente usando "Data::Dumper". Esto incluye referencias, objetos (generalmente) y estructuras de datos complejas. Probablemente no incluya elementos transitorios como manejadores de archivos o sockets.
set_feature($name, $value)
Establece la característica con el nombre dado al valor booleano dado. El valor se convertirá automáticamente a 0 o 1.
config_names()
Devuelve una lista de todos los nombres de los elementos de configuración actualmente definidos en "Module::Build::ConfigData", o en contexto escalar el número de elementos.
feature_names()
Devuelve una lista de todos los nombres de las características actualmente definidas en "Module::Build::ConfigData", o en contexto escalar el número de características.
auto_feature_names()
Devuelve una lista de todos los nombres de las características cuya disponibilidad se determina dinámicamente, o en contexto escalar el número de dichas características. No incluye características que posteriormente se hayan establecido a un valor fijo.
write()
Confirma cualquier cambio de set_config() y set_feature() en el disco. Requiere acceso de escritura al módulo "Module::Build::ConfigData".
