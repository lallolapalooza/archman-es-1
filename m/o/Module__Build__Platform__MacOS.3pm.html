NOMBRE

Module::Build::Platform::MacOS - Clase constructora para plataformas MacOS

DESCRIPCIÓN

El único propósito de este módulo es heredar de "Module::Build::Base" y sobrescribir algunos métodos. Por favor, consulte Module::Build para la documentación.

Métodos sobrescritos

new()
MacPerl no define $Config{sitelib} ni $Config{sitearch} por alguna razón, pero $Config{installsitelib} y $Config{installsitearch} están ahí. Así que copiamos las variables de instalación a la otra ubicación.
make_executable()
En MacOS, establecemos el tipo de archivo y el creador a MacPerl para que se ejecute con un doble clic.
dispatch()
Como no hay una forma fácil de decir "./Build test" en MacOS, si dispatch se llama sin argumentos y sin @ARGV, aparecerá un cuadro de diálogo preguntando qué acción tomar y cualquier argumento adicional.

La acción predeterminada es "test".

ACTION_realclean()
Es necesario desbloquear el programa Build antes de eliminarlo.
