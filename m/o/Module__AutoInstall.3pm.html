Module::AutoInstall(3) Documentación de Perl contribuida por el usuario Module::AutoInstall(3)

NOMBRE

Module::AutoInstall - Instalación automática de dependencias vía CPAN

SINOPSIS

En Makefile.PL, con Module::Install disponible en el sistema del autor:

use inc::Module::Install;

name        'Joe-Hacker';
abstract    'Interfaz Perl para Joe Hacker';
author      'Joe Hacker <joe@hacker.org>';
include     'Module::AutoInstall';

requires    'Module0';          # módulos obligatorios

feature     'Feature1',
    -default    => 0,
    'Module2'   => '0.1';

feature     'Feature2',
    -default    => 0,
    'Module3'   => '1.0';

auto_install(
    make_args   => '--hello',   # opción(es) para CPAN::Config
    force       => 1,           # pseudo-opción para forzar la instalación
    do_once     => 1,           # omitir módulos fallidos previamente
);

WriteAll;

Invocando el Makefile.PL resultante:

% perl Makefile.PL                  # comportamiento interactivo
% perl Makefile.PL --defaultdeps    # aceptar el valor por defecto en las preguntas
% perl Makefile.PL --checkdeps      # solo comprobar, no se produce Makefile
% perl Makefile.PL --skipdeps       # ignora todas las dependencias
% perl Makefile.PL --testonly       # no escribir objetivos de instalación

Tenga en cuenta que también se pueden omitir los 'deps' finales de los argumentos.

Usar "--defaultdeps" hará que Makefile.PL se comporte de forma similar a un archivo Makefile.PL normal con dependencias "PREREQ_PM".

Se pueden usar variables de entorno (ver "ENTORNO") a continuación para establecer un comportamiento predeterminado en lugar de especificarlo en la línea de comandos para cada invocación de Makefile.PL.

Usando make (o nmake):

% make [all|test|install]           # instala dependencias primero
% make checkdeps                    # igual que --checkdeps anterior
% make installdeps                  # solo instala dependencias
% make installdeps_notest           # igual sin ejecutar pruebas
% make upgradedeps                  # actualiza todas las dependencias, incluso si están instaladas
% make upgradedeps_notest           # igual sin ejecutar pruebas
% make listdeps                     # imprime dependencias no satisfechas, una por línea
% make listalldeps                  # imprime todas las dependencias, una por línea

DESCRIPCIÓN

Module::AutoInstall permite a los autores de módulos especificar una forma más sofisticada de información de dependencias que la opción "PREREQ_PM" ofrecida por ExtUtils::MakeMaker.

Este módulo funciona mejor con el framework Module::Install, un reemplazo directo para MakeMaker. Sin embargo, este módulo también soporta archivos Makefile.PL basados en MakeMaker; ver "EJEMPLOS" para instrucciones.

Especificar "installdeps_target;" en lugar de "auto_install;" no intentará instalar dependencias al ejecutar "make", sino solo al ejecutar "make installdeps".

Prerrequisitos y Características

Los prerrequisitos se agrupan en características, y el usuario puede elegir sí/no en cada una de sus dependencias; el autor del módulo también puede proporcionar un valor booleano a través de "-default" para especificar la elección predeterminada.

Las Características Principales marcadas con el nombre "-core" volverán a consultar al usuario, si el usuario elige no instalar los módulos obligatorios. Esto difiere del comportamiento de 'instalación silenciosa' anterior a la versión 0.26.

A partir de la versión 0.27, si "-core" se establece en la cadena "all" (sin distinción entre mayúsculas y minúsculas), cada característica se considerará obligatoria.

Las dependencias se expresan como pares de "Módulo" => "versión" dentro de una referencia de array. Si el orden no importa, y no hay directivas "-default", "-tests" o "-skiptests" para esa característica, también puede usar una referencia de hash.

El Proceso de Instalación

Una vez que Module::AutoInstall ha determinado qué(s) módulo(s) son necesarios, comprueba si se está ejecutando bajo el shell de CPAN y, por lo tanto, debería dejar que CPAN maneje la dependencia.

Finalmente, se anula WriteMakefile() para realizar algunas comprobaciones adicionales, así como omitir las pruebas asociadas con características deshabilitadas por la opción "-tests".

La instalación real ocurre al final del objetivo "make config"; tanto "make test" como "make install" activarán la instalación de los módulos requeridos.

Si no se está ejecutando bajo CPAN, el instalador sondeará una conexión activa intentando resolver el dominio "cpan.org" y verificará el permiso del usuario para usar CPAN. Si todo fue bien, se crea una instancia separada de
CPAN para instalar los módulos requeridos.

Si tiene el paquete CPANPLUS instalado en su sistema, se prefiere por defecto sobre CPAN; también acepta algunas opciones adicionales (por ejemplo, "-target => 'skiptest', -skiptest => 1" para omitir las pruebas).

Todos los módulos programados para ser instalados se eliminarán de %INC primero, por lo que ExtUtils::MakeMaker comprobará los módulos recién instalados.

Adicionalmente, puede usar el objetivo "make installdeps" para instalar los módulos, y el objetivo "make checkdeps" para verificar las dependencias sin instalarlas realmente; el comando "perl Makefile.PL --checkdeps" tiene un efecto equivalente.

Si el propio Makefile.PL necesita usar un módulo independiente (por ejemplo, Acme::KillarApp, v1.21 o superior), entonces use algo como lo siguiente:

BEGIN {
    require Module::AutoInstall;
    # el primer argumento es un arrayref de los flags -config
    Module::AutoInstall->install([], 'Acme::KillerApp' => 1.21);
}
use Acme::KillerApp 1.21;
Module::AutoInstall->import(
    # ... argumentos como de costumbre ...
);

Observe la prueba de versión en la cláusula use; si está tan cerca del borde que Acme::KillerApp 1.20 es la última versión en CPAN, esto evitará que su módulo funcione mal.

Ganchos Definidos por el Usuario

Los ganchos de preinstalación y postinstalación definidos por el usuario están disponibles a través de las subrutinas "MY::preinstall" y "MY::postinstall", como se muestra a continuación:

# manejador de preinstalación; toma $nombre_modulo y $version
sub MY::preinstall  { return 1; } # devolver falso para omitir la instalación
# manejador de postinstalación; toma $nombre_modulo, $version, $exito
sub MY::postinstall { return; }   # el valor de retorno no importa

Tenga en cuenta que dado que Module::AutoInstall realiza la instalación en el momento de "use" (es decir, antes de que perl analice el resto de Makefile.PL), debe declarar esos dos manejadores antes de la declaración "use" para que tengan efecto.

Si el usuario no eligió instalar un módulo o este ya existe en el sistema, ninguno de los manejadores será invocado. Ambos manejadores se invocan exactamente una vez por cada módulo cuando se intenta la instalación.

"MY::preinstall" toma dos argumentos, $nombre_modulo y $version; si devuelve un valor falso, la instalación para ese módulo se omitirá y "MY::postinstall" no se llamará en absoluto.

Module::AutoInstall(3pm)

NAME

Module::AutoInstall - automatically install dependencies for modules

SYNOPSIS

  perl Makefile.PL

DESCRIPTION

This module is for Module::Install to automatically install dependencies.

When Module::Install installs a module, it has the option of installing its dependencies as well. This module can help you with that.

The behaviour is controlled by a configuration variable that is often set as the argument to Makefile.PL.

By default, Module::AutoInstall will try to install missing dependencies. It will prompt you whether you want to install them, or you can control this behavior with the PERL_AUTOINSTALL environment variable (see ENVIRONMENT).

Why didn't it install all my deps?

This can happen for several reasons:

  • The module author has not specified any dependencies.
  • The module author has not specified any dependencies that are not already installed.
  • You have explicitly disabled dependency installation.
  • You are running this without a working CPAN client installed (e.g., without CPAN or CPANPLUS).
  • There are connection problems, or that module does not exist on CPAN at all.

Customized "MY::postamble"

Starting from version 0.43, Module::AutoInstall supports modules that require a "MY::postamble" subroutine in their Makefile.PL. The user-defined "MY::postamble", if present, is responsible for calling "Module::AutoInstall::postamble" and include the output in its return value.

For example, the DBD::* (database driver) modules for the Perl DBI are required to include the postamble generated by the function "dbd_postamble", so their Makefile.PL may contain lines like this:

sub MY::postamble {
    return &Module::AutoInstall::postamble . &dbd_postamble;
}

Note that the Module::AutoInstall module does not export the "postamble" function, so the name should always be fully qualified.

CAVEATS

Module::AutoInstall will add "UNINST=1" to your make install flags if your effective uid is 0 (root), unless you explicitly disable it by setting CPAN's "make_install_arg" configuration option (or the "makeflags" option of CPANPLUS) to include "UNINST=0". This may cause dependency problems if you are using a fine-tuned directory structure for your site. Please consult "FAQ" in CPAN for an explanation in detail.

If either version or Sort::Versions is available, they will be used to compare the required version with the existing module's version and the CPAN module's. Otherwise it silently falls back to use cmp. This may cause inconsistent behaviours in pathetic situations.

ENVIRONMENT

Module::AutoInstall uses a single environment variable, "PERL_AUTOINSTALL". It is taken as the command line argument passed to Makefile.PL; you could set it to "--alldeps", "--defaultdeps" or "--skipdeps" to avoid all interactive behaviour.

"--alldeps" will install all features, while "--defaultdeps" will only install features for which the default answer is 'y'.

"--skipdeps" will refrain from loading CPAN and not install anything, unless you're running under CPAN or CPANPLUS, in which case required dependencies will be installed.

It is also read from the "PERL_EXTUTILS_AUTOINSTALL" environment variable if "PERL_AUTOINSTALL" is not defined.

You can also set "PERL_AUTOINSTALL_PREFER_CPAN" to use CPAN to install dependencies. By default CPANPLUS is used.
