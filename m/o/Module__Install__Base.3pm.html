Module::Install::Base(3) Documentación de Perl aportada por el usuario Module::Install::Base(3)

NOMBRE

Module::Install::Base - Clase base para extensiones de Module::Install

SINOPSIS

En una extensión de Module::Install:

use Module::Install::Base ();
@ISA = qw(Module::Install::Base);

DESCRIPCIÓN

Este módulo proporciona métodos esenciales para todas las extensiones de Module::Install, en particular el constructor común "new" y el despachador de métodos "AUTOLOAD".

MÉTODOS

new(%args)
Constructor -- necesita preservar al menos _top
AUTOLOAD
El despachador principal - copia extensiones si faltan
_top()
Devuelve el objeto Module::Install de nivel superior.
admin()
Devuelve el objeto Module::Install::Admin asociado del objeto "_top" en la primera ejecución (es decir, cuando no había inc/ al inicio del programa); en ejecuciones posteriores (del lado del usuario), devuelve un objeto admin falso con un método "AUTOLOAD" vacío que no hace nada en absoluto.
is_admin()
Indica si esta es la primera ejecución del instalador (del lado del autor). Es decir, cuando no había inc/ al inicio del programa. Devuelve verdadero si es así. Falso en caso contrario.
