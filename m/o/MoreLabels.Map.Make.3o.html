val add : key:key -> data:'a -> 'a t -> 'a t

add ~key ~data m devuelve un mapa que contiene las mismas asociaciones que m , más una asociación de key a data . Si key ya estaba asociado en m con un valor que es físicamente igual a data , m se devuelve sin cambios (el resultado de la función es entonces físicamente igual a m ). De lo contrario, la asociación previa de key en m desaparece.

val add_to_list : key:key -> data:'a -> 'a list t -> 'a list t

add_to_list ~key ~data m es m con key mapeado a l tal que l es data :: Map.find key m si key estaba asociado en m y [data] en caso contrario.

val update : key:key -> f:('a option -> 'a option) -> 'a t -> 'a t

update ~key ~f m devuelve un mapa que contiene las mismas asociaciones que m , excepto la asociación de key . Dependiendo del valor de y donde y es f (find_opt key m) , la asociación de key se agrega, se elimina o se actualiza. Si y es None , la asociación se elimina si existe; de lo contrario, si y es Some z entonces key se asocia con z en el mapa resultante. Si key ya estaba asociado en m con un valor que es físicamente igual a z , m se devuelve sin cambios (el resultado de la función es entonces físicamente igual a m ).

val remove : key -> 'a t -> 'a t

remove x m devuelve un mapa que contiene las mismas asociaciones que m , excepto x que no está asociado en el mapa devuelto. Si x no estaba en m , m se devuelve sin cambios (el resultado de la función es entonces físicamente igual a m ).

val merge : f:(key -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

merge ~f m1 m2 calcula un mapa cuyas claves son un subconjunto de las claves de m1 y m2 . La presencia de cada asociación, y el valor correspondiente, se determina con la función f . En términos de la operación find_opt , tenemos find_opt x (merge f m1 m2) = f x (find_opt x m1) (find_opt x m2) para cualquier clave x , siempre que f x None None = None .

Desde 3.12

val union : f:(key -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union ~f m1 m2 calcula un mapa cuyas claves son un subconjunto de las claves de m1 y m2 . Cuando la misma asociación está definida en ambos argumentos, la función f se utiliza para combinarlas. Esto es un caso especial de merge : union f m1 m2 es equivalente a merge f' m1 m2 , donde

- f' _key None None = None

- f' _key (Some v) None = Some v

- f' _key None (Some v) = Some v

- f' key (Some v1) (Some v2) = f key v1 v2

BÚSQUEDA

val find : key -> 'a t -> 'a

find x m devuelve el valor actual de x en m , o lanza Not_found si no existe ninguna asociación para x .

val find_opt : key -> 'a t -> 'a option

find_opt x m devuelve Some v si el valor actual de x en m es v , o None si no existe ninguna asociación para x .

Desde 4.05

val find_first : f:(key -> bool) -> 'a t -> key * 'a

find_first ~f m , donde f es una función monótonamente creciente, devuelve la asociación de m con la clave más baja k tal que f k , o lanza Not_found si no existe tal clave.

Por ejemplo, find_first (fun k -> Ord.compare k x >= 0) m devolverá la primera asociación k, v de m donde Ord.compare k x >= 0 (en pocas palabras: k >= x ), o lanzará Not_found si x es mayor que cualquier elemento de m .

Desde 4.05

val find_first_opt : f:(key -> bool) -> 'a t -> (key * 'a) option

find_first_opt ~f m , donde f es una función monótonamente creciente, devuelve una opción que contiene la asociación de m con la clave más baja k tal que f k , o None si no existe tal clave.

Desde 4.05

val find_last : f:(key -> bool) -> 'a t -> key * 'a

Recorrido

val iter : f:(clave:clave -> datos:'a -> unidad) -> 'a t -> unidad

iter ~f m aplica f a todas las asociaciones en el mapa m. f recibe la clave como primer argumento y el valor asociado como segundo argumento. Las asociaciones se pasan a f en orden creciente con respecto al orden sobre el tipo de las claves.

val fold : f:(clave:clave -> datos:'a -> 'acc -> 'acc) -> 'a t -> init:'acc -> 'acc

fold ~f m ~init calcula (f kN dN ... (f k1 d1 init)...) , donde k1 ... kN son las claves de todas las asociaciones en m (en orden creciente), y d1 ... dN son los datos asociados.

Transformación

val map : f:('a -> 'b) -> 'a t -> 'b t

map ~f m devuelve un mapa con el mismo dominio que m , donde el valor asociado a de todas las asociaciones de m ha sido reemplazado por el resultado de la aplicación de f a a. Las asociaciones se pasan a f en orden creciente con respecto al orden sobre el tipo de las claves.

val mapi : f:(clave -> 'a -> 'b) -> 'a t -> 'b t

Igual que MoreLabels.Map.S.map , pero la función recibe como argumentos tanto la clave como el valor asociado para cada asociación del mapa.

val filter : f:(clave -> 'a -> bool) -> 'a t -> 'a t

filter ~f m devuelve el mapa con todas las asociaciones en m que satisfacen el predicado p. Si todas las asociaciones en m satisfacen f , m se devuelve sin cambios (el resultado de la función es entonces físicamente igual a m)

Desde 3.12

val filter_map : f:(clave -> 'a -> 'b option) -> 'a t -> 'b t

filter_map ~f m aplica la función f a cada asociación de m y construye un mapa a partir de los resultados. Para cada asociación (k, v) en el mapa de entrada:

- Si f k v es None entonces k no está en el resultado,

- Si f k v es Some v' entonces la asociación (k, v') está en el mapa de salida.

Por ejemplo, la siguiente función sobre mapas cuyos valores son listas

          filter_map
            (fun _k li -> match li with [] -> None | _::tl -> Some tl)
            m
descarta todas las asociaciones de m cuyo valor es una lista vacía, y elimina el primer elemento de cada valor no vacío.

Desde 4.11

val partition : f:(clave -> 'a -> bool) -> 'a t -> 'a t * 'a t

partition ~f m devuelve un par de mapas (m1, m2) , donde m1 contiene todas las asociaciones de m que satisfacen el predicado f , y m2 es el mapa con todas las asociaciones de m que no satisfacen f.

Desde 3.12

val split : clave -> 'a t -> 'a t * 'a option * 'a t

split x m devuelve un triple (l, data, r) , donde l es el mapa con todas las asociaciones de m cuya clave es estrictamente menor que x ; r es el mapa con todas las asociaciones de m cuya clave es estrictamente mayor que x ; data es None si m no contiene ninguna asociación para x , o Some v si m asocia v a x.

Predicados y comparaciones

val is_empty : 'a t -> bool

Comprueba si un mapa está vacío o no.

val mem : clave -> 'a t -> bool

mem x m devuelve true si m contiene una asociación para x , y false en caso contrario.

val equal : cmp:('a -> 'a -> bool) -> 'a t -> 'a t -> bool

equal ~cmp m1 m2 comprueba si los mapas m1 y m2 son iguales, es decir, si contienen claves iguales y las asocian con datos iguales. cmp es el predicado de igualdad utilizado para comparar los datos asociados con las claves.

val compare : cmp:('a -> 'a -> int) -> 'a t -> 'a t -> int

Orden total entre mapas. El primer argumento es un orden total utilizado para comparar los datos asociados con claves iguales en los dos mapas.

val for_all : f:(clave -> 'a -> bool) -> 'a t -> bool

for_all ~f m comprueba si todas las asociaciones del mapa satisfacen el predicado f.

Desde 3.12

val exists : f:(clave -> 'a -> bool) -> 'a t -> bool

exists ~f m comprueba si al menos una asociación del mapa satisface el predicado f.
