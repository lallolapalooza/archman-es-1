NOMBRE

Module::Build::XSUtil - Una clase de Module::Build para construir módulos XS

SINOPSIS

Usar en tu Build.PL

use strict;
use warnings;
use Module::Build::XSUtil;

my $builder = Module::Build::XSUtil->new(
    dist_name            => 'Tu-Modulo-XS',
    license              => 'perl',
    dist_author          => 'Tu Nombre <tunombre@ejemplo.com>',
    dist_version_from    => 'lib/Tu/Modulo/XS',
    generate_ppport_h    => 'lib/Tu/Modulo/XS/ppport.h',
    generate_xshelper_h  => 'lib/Tu/Modulo/XS/xshelper.h',
    needs_compiler_c99   => 1,
);

$builder->create_build_script();

Usar en un módulo de constructor personalizado.

package builder::MiConstructor;
use strict;
use warnings;
use base 'Module::Build::XSUtil';

sub new {
    my ($class, %args) = @_;
    my $self = $class->SUPER::new(
        %args,
        generate_ppport_h    => 'lib/Tu/Modulo/XS/ppport.h',
        generate_xshelper_h  => 'lib/Tu/Modulo/XS/xshelper.h',
        needs_compiler_c99   => 1,
    );
    return $self;
}

1;

DESCRIPCIÓN

Module::Build::XSUtil es una subclase de Module::Build para soportar la construcción de módulos XS.

Esta es una lista de los nuevos parámetros en el método Module::Build::new:

needs_compiler_c99
Esta opción verifica la disponibilidad del compilador C99. Si no está disponible, Build.PL sale con código 0.
needs_compiler_cpp
Esta opción verifica la disponibilidad del compilador C++. Si no está disponible, Build.PL sale con código 0.

Además, añade 'extra_compiler_flags' y 'extra_linker_flags' para C++.

generate_ppport_h
Genera ppport.h usando Devel::PPPort.
generate_xshelper_h
Genera xshelper.h, que es un archivo de cabecera auxiliar para incluir EXTERN.h, perl.h, XSUB.h y ppport.h, y define algunas cosas de portabilidad que no son soportadas por ppport.h.

Está adaptado de Module::Install::XSUtil.

cc_warnings
Habilita la opción de advertencias del compilador. Está habilitada por defecto.
opciones -g
Si se invoca Build.PL con la opción '-g', se construirá con opciones de depuración.
