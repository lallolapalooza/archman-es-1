Module::Install::Makefile(3) Documentación de Perl aportada por el usuario Module::Install::Makefile(3)

NOMBRE

Module::Install::MakeMaker - Reglas de Extensión para ExtUtils::MakeMaker

SINOPSIS

En tu Makefile.PL:

use inc::Module::Install;
WriteMakefile();

DESCRIPCIÓN

Este módulo es un envoltorio alrededor de ExtUtils::MakeMaker. Exporta dos funciones: "prompt" (un alias para "ExtUtils::MakeMaker::prompt") y "WriteMakefile".

La función "WriteMakefile" pasará las funciones de par clave/valor a "ExtUtils::MakeMaker::WriteMakefile". Los parámetros requeridos "NAME" y "VERSION" (o "VERSION_FROM") no son necesarios si puede encontrarlos inequívocamente en tu código.

OPCIONES DE CONFIGURACIÓN

Este módulo también añade algunos parámetros de Configuración propios:

NOMBRE

El parámetro NAME es requerido por ExtUtils::MakeMaker. Si tienes un solo módulo en tu distribución, o si el nombre del módulo indicado por el directorio actual existe bajo lib/, este módulo usará el nombre del paquete adivinado como valor predeterminado.

Si este módulo no puede encontrar un valor predeterminado para "NAME" te pedirá que lo especifiques manualmente.

VERSIÓN

ExtUtils::MakeMaker requiere el parámetro "VERSION" o "VERSION_FROM". Si este módulo puede adivinar el "NAME" del paquete, intentará analizar la "VERSION" a partir de él.

Si este módulo no puede encontrar un valor predeterminado para "VERSION" te pedirá que lo especifiques manualmente.

OBJETIVOS MAKE

ExtUtils::MakeMaker te proporciona muchos objetivos útiles de "make". Un objetivo de "make" es la palabra que especificas después de "make", como "test" para "make test". Algunos de los objetivos más útiles son:

  • all

    Este es el objetivo predeterminado. Cuando escribes "make" es lo mismo que introducir "make all". Este objetivo compila todo tu código y lo prepara en el directorio "blib".

  • test

    Ejecuta la suite de pruebas de tu distribución.

  • install

    Copia el contenido del directorio "blib" a los directorios apropiados en tu instalación de Perl.

  • dist

    Crea un archivo tarball de distribución, listo para ser subido a CPAN o compartido con un amigo.

  • clean distclean purge

    Elimina los archivos creados por "perl Makefile.PL" y "make".

  • help

    Igual que escribir "perldoc ExtUtils::MakeMaker".

Este módulo modifica el comportamiento de algunos de estos objetivos, dependiendo de tus requerimientos, y también añade los siguientes objetivos a tu Makefile:

  • cpurge

    Al igual que purge, excepto que también elimina los archivos originalmente añadidos por este mismo módulo.

  • chelp

    Atajo para escribir "perldoc Module::Install".

  • distsign

    Atajo para escribir "cpansign -s", para que los usuarios de Module::Signature firmen la distribución antes de liberarla.
