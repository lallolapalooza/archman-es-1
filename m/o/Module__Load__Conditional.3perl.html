Module::Load::Conditional(3perl) Guía de Referencia para Programadores de Perl Module::Load::Conditional(3perl)

NOMBRE

Module::Load::Conditional - Buscar información de módulos / cargar módulos en tiempo de ejecución

SINOPSIS

use Module::Load::Conditional qw[can_load check_install requires];
my $use_list = {
        CPANPLUS        => 0.05,
        LWP             => 5.60,
        'Test::More'    => undef,
};
print can_load( modules => $use_list )
        ? 'todos los módulos cargados correctamente'
        : 'fallo al cargar los módulos necesarios';
my $rv = check_install( module => 'LWP', version => 5.60 )
            or print 'LWP no está instalado!';
print 'LWP actualizado' if $rv->{uptodate};
print "Versión de LWP es $rv->{version}\n";
print "LWP está instalado como archivo $rv->{file}\n";
print "Los módulos que requiere deben estar instalados:\n";
print join "\n", requires('LWP');
### permite a M::L::C ver en %INC que no solo escanea @INC
$Module::Load::Conditional::CHECK_INC_HASH = 1;
### resetea la caché de 'can_load'
undef $Module::Load::Conditional::CACHE;
### no mostrar advertencia de Module::Load::Conditional -- por defecto es '1'
$Module::Load::Conditional::VERBOSE = 0;
### El último error que ocurrió durante una llamada a 'can_load'
my $err = $Module::Load::Conditional::ERROR;

DESCRIPCIÓN

Module::Load::Conditional ofrece formas sencillas de consultar y, en algunos casos, cargar cualquier módulo que esté instalado en tu sistema durante el tiempo de ejecución.

Puede cargar múltiples módulos a la vez o ninguno si uno de ellos no se pudo cargar. También se encarga de cualquier verificación de errores.

Métodos

$href = check_install( module => NOMBRE [, version => VERSIÓN, verbose => BOOL ] );

"check_install" permite verificar si un módulo específico está instalado o no. Puedes llamarlo con los siguientes argumentos:

módulo
Nombre del módulo que deseas verificar -- este es un parámetro obligatorio
versión
La versión que este módulo necesita -- opcional
verbose
¿Deberías ser notificado sobre lo que está haciendo? -- por defecto es $Module::Load::Conditional::VERBOSE

Devolverá undef si no pudo encontrar dónde estaba instalado el módulo, o una referencia a un hash con las siguientes claves si pudo encontrar el archivo:

archivo
Ruta completa del archivo que contiene el módulo
dir
Directorio, o más precisamente la entrada @INC donde se cargó el módulo.
versión
El número de versión del módulo instalado - esto será "undef" si el módulo no tiene (o no es interpretable) un número de versión, o si la variable $Module::Load::Conditional::FIND_VERSION está establecida a true. (Ver la sección "VARIABLES GLOBALES" para detalles)
actualizado
Un valor booleano que indica si el módulo se encontró al menos con la versión especificada. Si no especificaste una versión, actualizado será verdadero si se encontró el módulo. Si no se encontró una versión interpretable en el módulo, también será verdadero, ya que "check_install" no tenía forma de verificarlo claramente.

$bool = can_load( modules => { NOMBRE => VERSIÓN [,NOMBRE => VERSIÓN] }, [verbose => BOOL, nocache => BOOL, autoload => BOOL] )

"can_load" determina si puede cargar una lista de módulos, opcionalmente con versiones. Si puede cargarlos todos, lo hará. Si uno o más no se pueden cargar, ninguno será cargado.

Es especialmente útil si tienes más de una forma de resolver un problema en un programa, y solo quieres continuar si todos los módulos se pueden cargar, y no cargarlos si no se pueden.

Esta función utiliza la función "load" o la función "autoload_remote" de Module::Load como base.

"can_load" toma los siguientes argumentos:

módulos
Un hashref de pares módulo/versión. La versión indica la versión mínima a cargar. Si no se proporciona una versión, se asume que cualquier versión es suficiente.
verbose
¿Se deben mostrar advertencias si un módulo no se puede cargar? El valor por defecto es usar el valor de $Module::Load::Conditional::VERBOSE.
nocache
"can_load" mantiene sus resultados en una caché, para que no cargue el mismo módulo dos veces, ni intente cargar un módulo que ya falló antes. Por defecto, "can_load" comprueba la caché, pero puedes cambiar esto especificando "nocache" a true.
autoload
Controla si importar las funciones de un módulo cargado al paquete del llamador. El valor por defecto es no importar ninguna función.

Ver la función "load" y la función "autoload_remote" de Module::Load para detalles.

@list = requires( MÓDULO );

"requires" te permite saber qué módulos requiere un módulo específico. Es especialmente útil cuando estás escribiendo un módulo para su lanzamiento público y estás listando sus dependencias.

"requires" toma solo un argumento: el nombre de un módulo. Primero verifica si puede cargar este módulo, y devuelve undef si no puede. De lo contrario, devuelve una lista de módulos y pragmas que serían cargados en su nombre.

Nota: La lista que "require" devuelve se origina de tu intérprete perl actual y tu instalación actual.

VARIABLES GLOBALES

El comportamiento de Module::Load::Conditional puede modificarse cambiando las siguientes variables globales:

$Module::Load::Conditional::VERBOSE

Esto controla si Module::Load::Conditional emitirá advertencias y explicaciones sobre por qué ciertos elementos pueden haber fallado. Si estableces esto a 0, Module::Load::Conditional no emitirá ninguna advertencia. El valor por defecto es 0;

$Module::Load::Conditional::FIND_VERSION

Esto controla si Module::Load::Conditional intentará interpretar (y evaluar) la versión del módulo que está intentando cargar.

Si no quieres hacer esto, establece esta variable a "false". Entonces, las comparaciones de versión no son posibles, y Module::Load::Conditional no puede decirte qué versión de módulo tienes.

Module::Load::Conditional(3pm)

NAME

Module::Load::Conditional — A module to load modules conditionally

SYNOPSIS

 use Module::Load::Conditional;

 # Check if a module can be loaded
 if (can_load('Module::Name')) {
     require Module::Name;
     Module::Name->import();
 }

 # Load a module if it exists
 load_module('Module::Name');

 # Load a module that requires a specific version
 if (check_install('Module::Name', '1.0')) {
     load_module('Module::Name');
 }

 # Load a module if it has a specific function
 if (check_coderef('Module::Name', 'function_name')) {
     load_module('Module::Name');
 }

DESCRIPTION

This module provides a simple interface to load modules conditionally. It is useful for modules that have optional dependencies, or for modules that might not be installed on all systems.

Methods

can_load
Takes one or more module names as arguments and returns the name of the first module that can be loaded, or undef if none of the modules can be loaded.
load_module
Takes one or more module names as arguments and loads the first module that can be loaded. It returns true on success and false on failure.
check_install
Takes a module name and an optional version string as arguments. It returns true if the module is installed and is at least the specified version, or if no version is specified and the module is installed. Otherwise, it returns false.
check_coderef
Takes a module name and a coderef name as arguments. It returns true if the module is installed and contains the specified coderef, or false otherwise.

Global Variables

$Module::Load::Conditional::FIND_VERSION

This controls whether "Module::Load::Conditional" will try to find the version of the module you are looking for. By default this is set to 1, but if you don't care about the version, setting this to 0 will make check_install faster. It will skip the version checking part, and just check if the module is loadable.

Setting this to 0 will make "Module::Load::Conditional" behave more like "Module::Load", in that it will not check the version, but only if the module can be loaded.

Note that $FIND_VERSION code runs safely under "taint mode".

The default is 1;

$Module::Load::Conditional::CHECK_INC_HASH

This controls whether "Module::Load::Conditional" checks your %INC hash to see if a module is available. By default, only @INC is scanned to see if a module is physically on your filesystem, or available via an "@INC-hook". Setting this variable to "true" will trust any entries in %INC and return them for you.

The default is 0;

$Module::Load::Conditional::FORCE_SAFE_INC

This controls whether "Module::Load::Conditional" sanitises @INC by removing ""."". The current default setting is 0, but this may change in a future release.

$Module::Load::Conditional::CACHE

This holds the cache of the "can_load" function. If you explicitly want to remove the current cache, you can set this variable to "undef"

$Module::Load::Conditional::ERROR

This holds a string of the last error that happened during a call to "can_load". It is useful to inspect this when "can_load" returns "undef".

$Module::Load::Conditional::DEPRECATED

This controls whether "Module::Load::Conditional" checks if a dual-life core module has been deprecated. If this is set to true "check_install" will return false to "uptodate", if a dual-life module is found to be loaded from $Config{privlibexp}

The default is 0;
