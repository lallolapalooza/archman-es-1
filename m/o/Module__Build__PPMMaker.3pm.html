Module::Build::PPMMaker(3pm) Documentación de Perl contribuida por el usuario Module::Build::PPMMaker(3pm)

NOMBRE

Module::Build::PPMMaker - Creación de archivos de gestor de paquetes Perl

SINOPSIS

En la línea de comandos, construye un archivo .ppd:
./Build ppd

DESCRIPCIÓN

Este paquete contiene el código que construye archivos .ppd "Perl Package Description", en soporte del "Perl Package Manager" de ActiveState. Los detalles están aquí: http://aspn.activestate.com/ASPN/Downloads/ActivePerl/PPM/
