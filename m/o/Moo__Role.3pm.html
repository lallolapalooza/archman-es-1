Moo::Role(3) Documentación de Perl aportada por el usuario Moo::Role(3)

NOMBRE

Moo::Role - Soporte de orientación mínima para Roles

SINOPSIS

package My::Role;
use Moo::Role;
use strictures 2;
sub foo { ... }
sub bar { ... }
has baz => (
  is => 'ro',
);
1;

Y en otro lugar:

package Some::Class;
use Moo;
use strictures 2;
# bar se importa, pero no foo
with 'My::Role';
sub foo { ... }
1;

DESCRIPCIÓN

"Moo::Role" se basa en Role::Tiny, así que consulta allí la mayor parte de la documentación sobre cómo funciona esto (en particular, el uso de "Moo::Role" también habilita `strict` y `warnings`). La principal adición aquí son fragmentos adicionales para hacer los roles más "Moosey;", es decir, añade "has".

SUBRUTINAS IMPORTADAS

Consulta "IMPORTED SUBROUTINES" en Role::Tiny para ver todas las demás subrutinas que son importadas por este módulo.

has

has attr => (
  is => 'ro',
);

Declara un atributo para la clase a la que se compondrá. Consulta "has" en Moo para ver todas las opciones.

LIMPIEZA DE IMPORTACIONES

Moo::Role limpia sus propios métodos importados y cualquier importación declarada antes de la sentencia "use Moo::Role" automáticamente. Cualquier cosa importada después de "use Moo::Role" se compondrá en los paquetes consumidores. Un paquete que consume este rol:

package My::Role::ID;
use Digest::MD5 qw(md5_hex);
use Moo::Role;
use Digest::SHA qw(sha1_hex);
requires 'name';
sub as_md5  { my ($self) = @_; return md5_hex($self->name);  }
sub as_sha1 { my ($self) = @_; return sha1_hex($self->name); }
1;

..ahora tendrá un método "$self->sha1_hex()" disponible que probablemente no haga lo que esperas. Por otro lado, una llamada a "$self->md5_hex()" fallará con el útil mensaje de error: "Can't locate object method "md5_hex"".

Consulta "CLEANING UP IMPORTS" en Moo para más detalles.
