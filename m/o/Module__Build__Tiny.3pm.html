Module::Build::Tiny(3pm) Documentación de Perl contribuida por el usuario Module::Build::Tiny(3pm)

NOMBRE

Module::Build::Tiny - Un reemplazo diminuto para Module::Build

VERSIÓN

versión 0.052

SINOPSIS

use Module::Build::Tiny;
Build_PL();

DESCRIPCIÓN

Muchas distribuciones de Perl utilizan un archivo Build.PL en lugar de un archivo Makefile.PL para impulsar la configuración, compilación, prueba e instalación de la distribución. Tradicionalmente, Build.PL utiliza Module::Build como sistema de compilación subyacente. Este módulo proporciona un reemplazo simple, ligero y directo.

Mientras que Module::Build tiene más de 6.700 líneas de código; este módulo tiene menos de 200, pero soporta las características necesarias para la mayoría de las distribuciones.

Soportado

  • Distribuciones puras de Perl
  • Compilación de XS o C
  • Archivos de prueba recursivos
  • MYMETA
  • Generación de páginas de manual
  • Código generado desde archivos PL
  • Directorios compartidos de módulos
  • Prerrequisitos dinámicos

No Soportado

  • Generación de documentación HTML
  • Extensión de Module::Build::Tiny

Estructura de directorios

Sus archivos .pm, .xs y .pod deben estar en lib/. Cualquier ejecutable debe estar en script/. Los archivos de prueba deben estar en t/. Los directorios compartidos de distribución deben estar en share/, los directorios compartidos de módulos están bajo module-share (por ejemplo, module-share/Foo-Bar para el módulo "Foo::Bar").

Los archivos ".c" en el directorio src/ se compilan junto con el archivo .xs que coincide con el nombre de la distribución.

USO

Todos estos funcionan prácticamente igual que sus equivalentes de Module::Build.

perl Build.PL

Build [ build ]

Build test

Build install

Esto soporta las siguientes opciones:

  • verbose
  • install_base
  • installdirs
  • prefix
  • install_path
  • destdir
  • uninst
  • config
  • pure-perl
  • create_packlist

CREACIÓN

Este módulo no soporta la creación. Para desarrollar módulos usando Module::Build::Tiny, se recomienda el uso de Dist::Zilla::Plugin::ModuleBuildTiny o App::ModuleBuildTiny.

ARCHIVO DE CONFIGURACIÓN Y ENTORNO

Las opciones pueden proporcionarse en la variable de entorno "PERL_MB_OPT" de la misma manera que con Module::Build. Esto debe hacerse durante la etapa de configuración.

Incompatibilidades

  • Análisis de argumentos

    Module::Build tiene una forma extremadamente permisiva de manejar argumentos, Module::Build::Tiny solo soporta un subconjunto (sensato) de ellos. En particular, "./Build destdir=/foo" no funciona, necesitará pasarlo como "./Build --destdir=/foo".

  • .modulebuildrc

    Module::Build::Tiny no soporta archivos .modulebuildrc. En particular, esto significa que las versiones de local::lib anteriores a 1.006008 pueden fallar con "ERROR: Can't create /usr/local/somepath". Si la salida de "perl -Mlocal::lib" contiene "MODULEBUILDRC" pero no "PERL_MB_OPT ", necesitará actualizarlo para resolver este problema.
