Mouse::Util(3pm) Documentación de Perl aportada por el usuario Mouse::Util(3pm)

NOMBRE

Mouse::Util - Utilidades para trabajar con clases Mouse

VERSIÓN

Este documento describe la versión de Mouse v2.6.0

SINOPSIS

use Mouse::Util; # activa strict y warnings

DESCRIPCIÓN

Este módulo proporciona un conjunto de funciones de utilidad. Muchas de estas funciones están destinadas a ser utilizadas en el propio Mouse o en módulos MouseX, pero algunas de ellas pueden ser útiles para su uso en su propio código.

IMPLEMENTACIONES PARA

Funciones de Moose::Util

Las siguientes funciones son exportables.

find_meta($clase_o_objeto)

Lo mismo que Mouse::Util::class_of().

"does_role($clase_o_objeto, $rol_o_objeto)"

"resolve_metaclass_alias($categoria, $nombre, %opciones)"

"apply_all_roles($solicitante, @roles)"

english_listi(@elementos)

Funciones de Class::MOP

Las siguientes funciones no son exportables.

"Mouse::Util::is_class_loaded($nombre_clase) -> Bool"

Devuelve si $nombre_clase está realmente cargada o no. Utiliza una heurística que implica comprobar la existencia de $VERSION, @ISA, y cualquier método definido localmente.

"Mouse::Util::load_class($nombre_clase) -> NombreClase"

Esto cargará la $nombre_clase dada (o fallará si no se puede cargar). Esta función se puede usar en lugar de trucos como "eval "use $modulo ()"" o usando "require".

"Mouse::Util::class_of($nombre_clase_o_objeto) -> MetaClase"

"Mouse::Util::get_metaclass_by_name($nombre_clase) -> MetaClase"

"Mouse::Util::get_all_metaclass_instances() -> (MetaClases)"

"Mouse::Util::get_all_metaclass_names() -> (NombresClase)"
