Module::Install::Admin(3) Documentación de Perl aportada por el usuario Module::Install::Admin(3)

NOMBRE

Module::Install::Admin - Gestor del lado del autor para Module::Install

SINOPSIS

En un módulo de extensión de Module::Install:

sub extension_method {
    my $self = shift;
    $self->admin->some_method(@args);
}

Como una única línea:

% perl "-MModule::Install::Admin" -e'&some_method(@args);'

Los dos fragmentos anteriores son realmente atajos para

$some_obj->some_method(@args)

donde $some_obj es el objeto singleton de una clase del espacio de nombres "Module::Install::Admin::*" que proporciona el método "some_method". Véase "MÉTODOS" para una lista de métodos integrados.

DESCRIPCIÓN

Este módulo implementa el mecanismo interno para inicializar, incluir y gestionar extensiones, y solo debería ser de interés para los desarrolladores de extensiones; nunca se incluye en el directorio inc/ de una distribución, ni tampoco ninguna de las extensiones de Module::Install::Admin::*.

Para el uso normal de Module::Install, por favor consulte Module::Install y "MANUAL DE COCINA / EJEMPLOS" en Module::Install en su lugar.

Arranque

Cuando alguien ejecuta un Makefile.PL que tiene "use inc::Module::Install", y no hay ningún inc/ en el directorio actual, Module::Install se iniciará a sí mismo, siguiendo los pasos a continuación:

  • Primero, Module/Install.pm se despoja de POD y se copia desde @INC a inc/. Esto solo debería ocurrir del lado del autor, nunca del lado del usuario final.
  • Recarga inc/Module/Install.pm si el archivo actual está en otro lugar. Esto asegura que la versión incluida de inc/Module/Install.pm siempre sea preferida sobre la versión instalada.
  • Busca en inc/Module/Install/*.pm y carga todos ellos.
  • Configura una función "main::AUTOLOAD" para delegar las llamadas a funciones que falten a "Module::Install::Admin::load" - de nuevo, esto solo debería ocurrir del lado del autor.
  • Proporciona una función "Module::Install::purge_self" para eliminar los archivos incluidos bajo inc/.
