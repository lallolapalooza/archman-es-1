NOMBRE

Mouse::Object - El objeto base para clases de Mouse

VERSIÓN

Este documento describe la versión v2.6.0 de Mouse

MÉTODOS

"$class->new(%args | \%args) -> Object"

Instancia un nuevo "Mouse::Object". Obviamente, esto está pensado para subclases.

"$class->BUILDARGS(@args) -> HashRef"

Permite anular los argumentos que toma "new". Debe devolver un HashRef de parámetros.

"$object->BUILDALL(\%args)"

Llama a "BUILD" en cada clase de la jerarquía de clases. Esto se llama al final de "new".

"$object->BUILD(\%args)"

Puedes poner cualquier lógica de inicialización de negocio en los métodos BUILD. No necesitas redispatchar ni devolver ningún valor específico.

"$object->DEMOLISHALL"

Llama a "DEMOLISH" en cada clase de la jerarquía de clases. Esto se llama en el momento de "DESTROY".

"$object->DEMOLISH"

Puedes poner cualquier lógica de desinicialización de negocio en los métodos DEMOLISH. No necesitas redispatchar ni devolver ningún valor específico.

"$object->does($role_name) -> Bool"

Esto comprobará si la clase invocadora *hace* un $role_name dado. Esto es similar a "isa" para objetos, pero comprueba los roles en su lugar.

"$object->dump($maxdepth) -> Str"

Esta es una utilidad útil para volcar un objeto con Data::Dumper. Por defecto, la profundidad máxima es 3, para evitar crear un lío.

"$object->meta() -> MetaClass"

Este es un método que proporciona acceso a la metaclasse del objeto.
