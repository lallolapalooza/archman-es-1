Módulo Set
: sig end

Conjuntos sobre tipos ordenados.

Este módulo implementa la estructura de datos de conjuntos, dada una función de ordenación total sobre los elementos del conjunto. Todas las operaciones sobre conjuntos son puramente aplicativas (sin efectos secundarios). La implementación utiliza árboles binarios equilibrados y, por lo tanto, es razonablemente eficiente: la inserción y la pertenencia toman tiempo logarítmico en el tamaño del conjunto, por ejemplo.

El functor MoreLabels.Set.Make construye implementaciones para cualquier tipo, dada una función compare. Por ejemplo:

       module IntPairs =
         struct
           type t = int * int
           let compare (x0,y0) (x1,y1) =
             match Stdlib.compare x0 x1 with
                 0 -> Stdlib.compare y0 y1
               | c -> c
         end
       module PairsSet = Set.Make(IntPairs)
       let m = PairsSet.(empty |> add (2,3) |> add (5,7) |> add (11,13))

Esto crea un nuevo módulo PairsSet , con un nuevo tipo PairsSet.t de conjuntos de int * int .
