Module::Metadata(3perl) Guía de referencia del programador de Perl Module::Metadata(3perl)

NOMBRE

Module::Metadata - Recopila información de paquetes y POD de archivos de módulos perl

VERSIÓN

version 1.000038

SINOPSIS

use Module::Metadata;
# información sobre un archivo .pm
my $info = Module::Metadata->new_from_file( $file );
my $version = $info->version;
# campo 'provides' de CPAN META para archivos .pm en un directorio
my $provides = Module::Metadata->provides(
  dir => 'lib', version => 2
);

DESCRIPCIÓN

Este módulo proporciona una forma estándar de recopilar metadatos de un archivo .pm a través de análisis (mayormente) estático y (algo de) ejecución de código. Al determinar la versión de un módulo, la asignación de $VERSION se evalúa (se usa "eval"), como es tradicional en la cadena de herramientas de CPAN.

MÉTODOS DE CLASE

"new_from_file($filename, collect_pod => 1, decode_pod => 1)"

Construye un objeto "Module::Metadata" dado la ruta a un archivo. Devuelve undef si el nombre del archivo no existe.

"collect_pod" es un argumento booleano opcional que determina si los datos POD se recopilan y almacenan para referencia. Los datos POD no se recopilan por defecto. Los encabezados POD siempre se recopilan.

Si el archivo comienza con una marca de orden de bytes UTF-8, UTF-16BE o UTF-16LE, esta se omite antes del procesamiento, y el contenido del archivo también se decodifica apropiadamente a partir de perl 5.8.

Alternativamente, si "decode_pod" está activado, decodificará las secciones POD recopiladas según la declaración "=encoding".

"new_from_handle($handle, $filename, collect_pod => 1, decode_pod => 1)"

Esto funciona igual que "new_from_file", excepto que se puede proporcionar un manejador (handle) como primer argumento.

Tenga en cuenta que no hay validación para confirmar que el manejador es un manejador o algo que pueda actuar como tal. Pasar algo que no es un manejador causará una excepción al intentar leer de él. El argumento "filename" es obligatorio o se devolverá undef.

Usted es responsable de establecer las capas de decodificación en $handle si es necesario.

"new_from_module($module, collect_pod => 1, inc => \@dirs, decode_pod => 1)"

Construye un objeto "Module::Metadata" dado un nombre de módulo o paquete. Devuelve undef si el módulo no se puede encontrar.

Además de aceptar los argumentos "collect_pod" y "decode_pod" como se describe arriba, este método acepta un argumento "inc" que es una referencia a un array de directorios donde buscar el módulo. Si no se proporcionan, el valor predeterminado es @INC.

Si el archivo que contiene el módulo comienza con una marca de orden de bytes UTF-8, UTF-16BE o UTF-16LE, esta se omite antes del procesamiento, y el contenido del archivo también se decodifica apropiadamente a partir de perl 5.8.

"find_module_by_name($module, \@dirs)"

Devuelve la ruta a un módulo dado el nombre del módulo o paquete. Se puede pasar una lista de directorios como parámetro opcional, de lo contrario se busca en @INC.

Se puede llamar tanto como método de objeto como de clase.

"find_module_dir_by_name($module, \@dirs)"

Devuelve la entrada en @dirs (o @INC por defecto) que contiene el módulo $module. Se puede pasar una lista de directorios como parámetro opcional, de lo contrario se busca en @INC.

Se puede llamar tanto como método de objeto como de clase.

provides( %options )

Este es un envoltorio de conveniencia para "package_versions_from_directory" para generar una estructura de datos "provides" de CPAN META. Acepta pares clave/valor. Las claves de opción válidas incluyen:

version (requerido)
Especifica qué versión de CPAN::Meta::Spec se utilizará como formato de la salida de "provides". Actualmente solo se admiten '1.4' y '2' (y su formato es idéntico). Esto puede cambiar en el futuro a medida que la definición de "provides" cambie.

La opción "version" es obligatoria. Si se omite o si se proporciona una versión no admitida, "provides" lanzará un error.

dir
Directorio para buscar recursivamente archivos .pm. No se puede especificar con "files".
files
Referencia de array de archivos a examinar. No se puede especificar con "dir".
prefix
Cadena a anteponer al campo "file" de la salida resultante. El valor predeterminado es lib, que es el caso común para la mayoría de las distribuciones de CPAN con sus archivos .pm en lib. Esta opción asegura que la información META tenga la ruta relativa correcta incluso cuando los argumentos "dir" o "files" son absolutos o tienen rutas relativas desde una ubicación distinta a la raíz de la distribución.

Por ejemplo, dado "dir" 'lib' y "prefix" 'lib', el valor de retorno es un hashref de la forma:

{
  'Package::Name' => {
    version => '0.123',
    file => 'lib/Package/Name.pm'
  },
  'OtherPackage::Name' => ...
}

"package_versions_from_directory($dir, \@files?)"

Escanea $dir en busca de archivos .pm (a menos que se proporcione @files, en cuyo caso busca esos archivos en $dir - y lee cada archivo en busca de paquetes y versiones, devolviendo un hashref de la forma:

{
  'Package::Name' => {
    version => '0.123',
    file => 'Package/Name.pm'
  },
  'OtherPackage::Name' => ...
}

Los paquetes "DB" y "main" siempre se omiten, al igual que cualquier paquete "privado" que tenga guiones bajos al principio en el espacio de nombres (por ejemplo, "Foo::_private")

Tenga en cuenta que la ruta del archivo es relativa a $dir si se especifica este último. Esto **no debe** usarse directamente para "provides" de CPAN META. Consulte el método "provides" en su lugar.

"log_info_ (interno)"

Páginas del manual de Arch Linux traducidas por el equipo de documentación de Arch Linux.

NAME

Module::Metadata - Extract metadata from Perl modules

VERSION

This describes the version of this module, and provides access to metadata about the module itself.

SYNOPSIS

  use Module::Metadata;

  # For a module file
  my $meta = Module::Metadata->new_from_file( 'Path/To/My/Module.pm' );
  my $name = $meta->name;
  my $version = $meta->version;
  my $filename = $meta->filename;
  my $packages = $meta->packages_inside;
  my $pod = $meta->pod_inside ? $meta->pod('NAME') : undef;

  # For a script (which is just a module in the 'main' package)
  my $script_meta = Module::Metadata->new_from_file( 'Path/To/My/Script' );
  print $script_meta->name; # Prints "main"

  # For a module already in memory (e.g. via require)
  require Some::Module;
  my $in_memory_meta = Module::Metadata->new_from_object(Some::Module);

  # Get metadata about this module itself
  my $this_meta = Module::Metadata->new_from_object( __PACKAGE__ );
  print $this_meta->version;

  # Check if a module is indexable by PAUSE
  if ($meta->is_indexable) {
    print "This module is indexable by PAUSE\n";
  }

DESCRIPTION

This module provides a simple interface for extracting metadata (like package name, version, POD, etc.) from Perl modules. It can read this metadata from a file, or from a module already loaded into memory.

It is primarily intended for use by build systems (like Module::Build) and other tools that need to inspect Perl modules without necessarily loading them fully.

The module works by parsing the module file (or the source code if available) looking for:

  • The package declaration(s).
  • The $VERSION variable.
  • POD sections.

It is careful not to execute the module's code, as this could have unintended side-effects.

log_info (internal)

Used internally to perform logging; imported from Log::Contextual if Log::Contextual has already been loaded, otherwise simply calls warn.

OBJECT METHODS

name()

Returns the name of the package represented by this module. If there is more than one package, it makes a best guess based on the filename. If it's a script (i.e. not a *.pm) the package name is 'main'.

version($package)

Returns the version as defined by the $VERSION variable for the package as returned by the "name" method if no arguments are given. If given the name of a package it will attempt to return the version of that package if it is specified in the file.

filename()

Returns the absolute path to the file. Note that this file may not actually exist on disk yet, e.g. if the module was read from an in-memory filehandle.

packages_inside()

Returns a list of packages. Note: this is a raw list of packages discovered (or assumed, in the case of "main"). It is not filtered for "DB", "main" or private packages the way the "provides" method does. Invalid package names are not returned, for example "Foo:Bar". Strange but valid package names are returned, for example "Foo::Bar::", and are left up to the caller on how to handle.

pod_inside()

Returns a list of POD sections.

contains_pod()

Returns true if there is any POD in the file.

pod($section)

Returns the POD data in the given section.

is_indexable($package) or is_indexable()

Available since version 1.000020.

Returns a boolean indicating whether the package (if provided) or any package (otherwise) is eligible for indexing by PAUSE, the Perl Authors Upload Server. Note This only checks for valid "package" declarations, and does not take any ownership information into account.
