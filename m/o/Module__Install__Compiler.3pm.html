NOMBRE

Module::Install::Compiler - Comandos para interactuar con el compilador de C

SINOPSIS

Para completar

DESCRIPCIÓN

Muchos módulos de Perl que contienen código C y XS tienen archivos Makefile.PL diabólicamente complejos, porque ExtUtils::MakeMaker no proporciona por sí mismo mucha ayuda y automatización en esta área.

Module::Install::Compiler proporciona una serie de comandos que se encargan de tareas de utilidad comunes y que intentan eliminar parte de la complejidad de la creación de módulos C y XS.

COMANDOS

Para completar

POR HACER

La implementación actual es relativamente frágil y minimalista.

Solo maneja un envoltorio muy básico alrededor de ExtUtils::MakeMaker.

Actualmente se está sometiendo a una extensa refactorización para proporcionar una capacidad de generación de banderas del compilador más genérica. Esto puede llevar algún tiempo, y si alguien que mantiene un módulo de Perl que hace uso del compilador quisiera ayudar, su asistencia sería muy apreciada.
