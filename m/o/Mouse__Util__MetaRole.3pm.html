NOMBRE

Mouse::Util::MetaRole - Aplicar roles a cualquier metaclass, así como a la clase base del objeto

SINOPSIS

package MyApp::Mouse;
use Mouse ();
use Mouse::Exporter;
use Mouse::Util::MetaRole;
use MyApp::Role::Meta::Class;
use MyApp::Role::Meta::Method::Constructor;
use MyApp::Role::Object;
Mouse::Exporter->setup_import_methods( also => 'Mouse' );
sub init_meta {
    shift;
    my %args = @_;
    Mouse->init_meta(%args);
    Mouse::Util::MetaRole::apply_metaroles(
        for             => $args{for_class},
        class_metaroles => {
            class       => ['MyApp::Role::Meta::Class'],
            constructor => ['MyApp::Role::Meta::Method::Constructor'],
        },
    );
    Mouse::Util::MetaRole::apply_base_class_roles(
        for   => $args{for_class},
        roles => ['MyApp::Role::Object'],
    );
    return $args{for_class}->meta();
}

DESCRIPCIÓN

Este módulo de utilidad está diseñado para ayudar a los autores de extensiones de Mouse a escribir extensiones que puedan cooperar con otras extensiones de Mouse. Para hacer esto, debes escribir tus extensiones como roles, que luego pueden aplicarse dinámicamente a las metaclasses del llamador.

Este módulo se asegura de preservar cualquier superclase y rol existente ya establecido para los metaobjetos, lo que significa que cualquier número de extensiones puede aplicar roles en cualquier orden.

USO

Es muy importante que solo llames a las funciones de este módulo cuando tu módulo sea importado por el llamador. El proceso de aplicar roles a la metaclass reinicia el objeto metaclass, lo que elimina cualquier atributo ya definido. Sin embargo, siempre que hagas esto cuando tu módulo sea importado, el llamador no debería tener ningún atributo definido todavía.

La forma más fácil de asegurar que esto ocurra es usar Mouse::Exporter, que puede generar el método "init_meta" apropiado para ti y asegurarse de que se llame cuando se importe.

FUNCIONES

Este módulo proporciona dos funciones.

apply_metaroles( ... )

Esta función aplicará roles a una o más metaclasses para la clase especificada. Acepta los siguientes parámetros:

  • for => $name

    Esto especifica la clase o para la cual se alterarán las metaclasses. Puede ser un nombre de paquete o un metaobjeto apropiado (un Mouse::Meta::Class o Mouse::Meta::Role).

  • class_metaroles => \%roles

    Esta es una referencia de hash que especifica qué metaroles se aplicarán a la metaclass de la clase y a sus metaclasses y clases de ayuda contenidas.

    Cada clave debe apuntar a su vez a una referencia de array de nombres de roles.

    Acepta las siguientes claves:

class
attribute
method
constructor
destructor
•
role_metaroles => \%roles

Esta es una referencia de hash que especifica qué metaroles se aplicarán a la metaclass de rol y a sus metaclasses y clases de ayuda contenidas.

Acepta las siguientes claves:

role
method

apply_base_class_roles( for => $class, roles => \@roles )

Esta función aplicará los roles especificados a la clase base del objeto.
