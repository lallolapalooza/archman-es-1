MediaWiki__API(3pm)

Paquete: perl-mediawiki-api

Licencias: GPL3

MediaWiki::API(3) Documentación de paquetes contribuidos en Perl MediaWiki::API(3)

Nombre

MediaWiki::API - Permite una interfaz Perl con la API de MediaWiki (https://www.mediawiki.org/wiki/API)

Versión

Versión 0.52

Sintaxis

Este módulo proporciona una interfaz entre Perl y la API de MediaWiki (https://www.mediawiki.org/wiki/API), permitiendo la creación de scripts para automatizar la edición y la extracción de datos de sitios como Wikipedia.

use MediaWiki::API;
my $mw = MediaWiki::API->new();
$mw->{config}->{api_url} = 'https://en.wikipedia.org/w/api.php';
# iniciar sesión en la wiki
$mw->login( { lgname => 'username', lgpassword => 'password' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
# obtener una lista de artículos en categoría
my $articles = $mw->list ( {
  action => 'query',
  list => 'categorymembers',
  cmtitle => 'Category:Perl',
  cmlimit => 'max' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
# y mostrar los títulos de los artículos
foreach (@{$articles}) {
    print "$_->{title}\n";
}
# obtener información del usuario
my $userinfo = $mw->api( {
  action => 'query',
  meta => 'userinfo',
  uiprop => 'blockinfo|hasmsg|groups|rights|options|editcount|ratelimits' } );
  ...

Funciones

MediaWiki::API->new( $config_hashref )

Devuelve un objeto de API de MediaWiki. Puedes pasar un configuración como un hash de configuración cuando se llame a new, o establecerla más tarde. Cuando se crea un nuevo objeto, los valores por defecto para max_lag y retries se establecen.

my $mw = MediaWiki::API->new( { api_url => 'https://en.wikipedia.org/w/api.php' }  );

Las opciones de configuración son:

  • api_url = 'Ruta a la API de MediaWiki api.php';
  • files_url = 'URL base para archivos'; (necesario si el api devuelve un URL relativo para imágenes como /images/a/picture.jpg)
  • upload_url = 'https://en.wikipedia.org/wiki/Special:Upload'; (ruta a la página especial de subida que es requerida si quieres subir imágenes)
  • on_error = Referencia a una función que se llama si ocurre un error en el módulo.
  • use_http_get = Boolean 0 o 1 (por defecto es 0). Si se establece en 1, el módulo Perl usará el método GET HTTP para acceder a la API. Por defecto, usa el método POST. Nota: el módulo seguirá usando POST para las llamadas a la API que requieren POST, independientemente del valor de esta opción de configuración. Las acciones siguientes que trabajan con GET son: query, logout, paraminfo - ver get_actions configuración a continuación.
  • get_actions = Hashref (por defecto es { 'query' => 1, 'logout' => 1, 'paraminfo' => 1 } ). Este contiene las acciones de API que se pueden usar con el método GET HTTP si está habilitado. Algunas wikis pueden tener extensiones que agreguen más funciones que trabajan con un request GET. Si así es, puedes añadir las acciones de manera necesaria.
  • retries = Valor entero; El número de intentos a realizar para enviar una solicitud de API si ocurre un error HTTP o un error de decodificación JSON. Por defecto es 0 (intentar solo una vez - no reintentar). Si max_retries está establecido en 4, y el sitio web está fuera de servicio, el error no se reportará hasta después del 5º intento de conexión.
  • retry_delay = Valor entero en segundos; El tiempo que se debe esperar antes de reintentar una solicitud si ocurre un error HTTP o un error de decodificación JSON.
  • max_lag = Valor entero en segundos; Wikipedia funciona en un cluster de bases de datos y así, las velocidades de edición altas causan que los servidores secundarios se retrasen. Si esta opción de configuración se establece, si el retraso es más grande que el valor de max_lag, el API esperará antes de reintentar la solicitud. 5 es un valor recomendado. Más información sobre este tema puede encontrarse en https://www.mediawiki.org/wiki/Manual:Maxlag_parameter. nota: la opción de configuración incluye un guion bajo, así que debe coincidir con el nombre de la otra opción de configuración del tipo.
  • max_lag_delay = Valor entero en segundos; Esta opción de configuración especifica el tiempo que debe esperar antes de reintentar una solicitud si el servidor ha reportado un retraso más grande que el valor de max_lag. Por defecto es 5 si se usa la opción de configuración max_lag.
  • max_lag_retries = Valor entero; El número de intentos a realizar para enviar una solicitud de API si el servidor ha reportado un retraso más grande que el valor de max_lag. Si el número máximo de intentos se alcanza, se devuelve un error. Establecer este valor en un valor negativo como -1 significa que la solicitud se reenvía hasta que el servidor max_lag sea menor que el umbral o otro error ocurra. Por defecto es 4.
  • no_proxy = Boolean; Establecer en 1 para desactivar el uso de cualquier proxy establecido en el entorno. Nota: por defecto, si hay variables de entorno de proxy establecidas, el módulo intentará usarlos. Esta función fue agregada en la versión 0.29. Versiones anteriores ignoran cualquier configuración de proxy, pero puedes establecerla tú mismo haciendo MediaWiki::API->{ua}->env_proxy() después de crear una nueva instancia de la clase MediaWiki::API. Más información sobre env_proxy puede encontrarse en http://search.cpan.org/~gaas/libwww-perl-5.834/lib/LWP/UserAgent.pm#Proxy_attributes

Un ejemplo para la opción on_error podría ser algo así:

$mw->{config}->{on_error} = \&on_error;
sub on_error {
  print "Código de error: " . $mw->{error}->{code} . "\n";
  print $mw->{error}->{stacktrace}."\n";
  die;
}

Los errores se almacenan en $mw->{error}-{code} con más información en $mw->{error}-{details}. $mw->{error}-{stacktrace} incluye los detalles y una traza de pila para localizar dónde se originaron los problemas (en algunos código que utiliza este módulo por ejemplo).

Los códigos de error son los siguientes:

  • ERR_NO_ERROR = 0 (Sin error)
  • ERR_CONFIG = 1 (Error con la configuración)
  • ERR_HTTP = 2 (Error relacionado con la conexión HTTP)
  • ERR_API = 3 (Error devuelto por la API de MediaWiki)
  • ERR_LOGIN = 4 (Error al iniciar sesión en MediaWiki)
  • ERR_EDIT = 5 (Error con una función de edición)
  • ERR_PARAMS = 6 (Error con parámetros pasados a una función de ayuda)
  • ERR_UPLOAD = 7 (Error con el sistema de subida de archivos)
  • ERR_DOWNLOAD = 8 (Error con la descarga de un archivo)

Otros parámetros y objetos utilizados en el objeto MediaWiki::API incluyen:

  • MediaWiki::API->{ua} = Objeto LWP::UserAgent. Puedes modificar este para obtener o modificar los cachés (MediaWiki::API->{ua}->cookie_jar) o para cambiar la cadena de usuario agent enviada por este módulo Perl (MediaWiki::API->{ua}->agent)
  • MediaWiki::API->{response} = El objeto de respuesta devuelto por el LWP::UserAgent después de una solicitud de API.

MediaWiki::API->login( $query_hashref )

Inicia sesión en una instancia de MediaWiki. Los parámetros son aquellos utilizados por la API de MediaWiki (https://www.mediawiki.org/wiki/API:Login). Devuelve un hash con algunos detalles de sesión, o undef en caso de error de inicio de sesión. Si MediaWiki envía solicitudes con un token de inicio de sesión, se intenta de nuevo, pero con el token enviado en la primera sesión. Los errores se almacenan en MediaWiki::API->{error}->{code} y MediaWiki::API->{error}->{details}.

my $mw = MediaWiki::API->new( { api_url => 'https://en.wikipedia.org/w/api.php' }  );
# iniciar sesión en la wiki
$mw->login( {lgname => 'username', lgpassword => 'password' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

MediaWiki::API->api( $query_hashref, $options_hashref )

Llama a la interfaz de API de MediaWiki. Los parámetros se pasan como un hash de configuración que se describe en la página de la API de MediaWiki (https://www.mediawiki.org/wiki/API). Devuelve un hash con los resultados de la llamada o undef en caso de error, con el código de error y detalles almacenados en MediaWiki::API->{error}->{code} y MediaWiki::API->{error}->{details}. MediaWiki::API usa el módulo LWP::UserAgent para enviar las solicitudes HTTP a la API de MediaWiki. Después de cualquier llamada a la API, el objeto de respuesta devuelto por LWP::UserAgent se encuentra en $mw->{response}. Esta función NO modifica en ningún momento el hash de parámetros $query_hashref.

binmode STDOUT, ':utf8';
# obtener el nombre del sitio
if ( my $ref = $mw->api( { action => 'query', meta => 'siteinfo' } ) ) {
  print $ref->{query}->{general}->{sitename};
}
# lista de títulos para "Albert Einstein" en diferentes lenguas.
my $titles

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

= $mw->api( { action => 'query', titles => 'Albert Einstein', prop => 'langlinks', lllimit => 'max' } ) || die $mw->{error}->{code} . ': ' . $mw->{error}->{details}; my ($pageid,$langlinks) = each ( %{ $titles->{query}->{pages} } ); foreach ( @{ $langlinks->{langlinks} } ) { print "$_->{'*'}\n"; }

La API de MediaWiki utiliza UTF-8 y los parámetros de cadenas de 8 bits se codifican automáticamente en la llamada a la API. Si tus parámetros ya están en UTF-8, esto se detectará y se omitirá la codificación. Si tus parámetros por alguna razón contienen datos UTF-8 pero no se establece la bandera UTF-8 (es decir, no usaste el pragma "use utf8;"), debes evitar la recodificación pasando una opción skip_encoding => 1 en el $options_hash. Por ejemplo:

my $mw = MediaWiki::API->new();
$mw->{config}->{api_url} = 'https://fr.wiktionary.org/w/api.php';
my $query = {action => 'query',
  list => 'categorymembers',
  cmlimit => 'max'};
$query->{cmtitle} ="Cat\x{e9}gorie:moyen_fran\x{e7}ais"; # cadena latin1
$mw->list ( $query ); # ok
$query->{cmtitle} = "Cat". pack("U", 0xe9)."gorie:moyen_fran".pack("U",0xe7)."ais"; # cadena unicode
$mw->list ( $query ); # ok
$query->{cmtitle} ="Cat\x{c3}\x{a9}gorie:moyen_fran\x{c3}\x{a7}ais";  # datos unicode sin bandera utf-8
# $mw->list ( $query ); # NO OK
$mw->list ( $query, {skip_encoding => 1} ); # ok

Si estás llamando a una función de la API que requiere la carga de un archivo, por ejemplo, import o upload, especifica el archivo a cargar como un arrayref que contenga el nombre del archivo local. La API puede devolver una advertencia, por ejemplo, para indicar que el archivo es un duplicado. Para ignorar las advertencias y forzar la carga, usa ignorewarnings => 1. Todos los parámetros, como todo lo demás, se pueden encontrar en la página de la API de MediaWiki.

$mw->api( {
  action => 'import',
  xml => ['wiki_dump.xml']
 } );
$mw->api( {
  action => 'upload',
  filename => 'test.png',
  comment => 'a test image',
  file => ['test.png'],
 } );

También puedes proporcionar los datos a cargar directamente, si deseas leer los datos tú mismo. En este caso, proporciona un arrayref con tres parámetros, comenzando con un "undef", seguido del nombre del archivo y luego un par Content => $data que contenga los datos.

$mw->api( {
  action => 'import',
  xml => [ undef, 'wiki_dump.xml', Content => $data ]
 } );
$mw->api( {
  action => 'upload',
  filename => 'test.png',
  comment => 'a test image',
  file => [ undef, 'test.png', Content => $data ],
 } );

MediaWiki::API->logout()

Cierra la sesión del usuario actual y borra las cookies y tokens de edición asociados.

MediaWiki::API->edit( $query_hashref, $options_hashref )

Una función auxiliar para realizar ediciones utilizando la API de MediaWiki. Los parámetros se pasan como un hashref que se describen en la página de edición de la API de MediaWiki (https://www.mediawiki.org/wiki/API:Changing_wiki_content). Ten en cuenta que necesitas $wgEnableWriteAPI = true en tu LocalSettings.php para usar estas funciones. Esta función modificará el hashref de entrada.

Actualmente

  • Crear/Editar páginas (Mediawiki >= 1.13)
  • Mover páginas (Mediawiki >= 1.12)
  • Deshacer (Mediawiki >= 1.12)
  • Eliminar páginas (Mediawiki >= 1.12)
  • Cargar imágenes (Mediawiki >= 1.16)
  • Importar páginas (Mediawiki >= 1.15)
  • (Des)proteger páginas (Mediawiki >= 1.12)
  • (Des)bloquear usuarios (Mediawiki >= 1.12)
  • (De)vigilar una página (Mediawiki >= 1.18)
  • Enviar correo electrónico a un usuario (Mediawiki >= 1.14)
  • Patrullar cambios (Mediawiki >= 1.14)

son compatibles a través de esta llamada. Utiliza esta llamada para editar páginas sin tener que preocuparse de obtener primero un token de edición de la API. La función almacenará en caché los tokens de edición para acelerar ediciones futuras.

Devuelve un hashref con los resultados de la llamada o undef en caso de fallo, con el código de error y los detalles almacenados en MediaWiki::API->{error}->{code} y MediaWiki::API->{error}->{details}.

El hashref de opciones tiene actualmente un parámetro opcional (skip_encoding => 1). Esto se describe anteriormente en la documentación de la llamada MediaWiki::API->api.

Aquí hay algunos fragmentos de código de ejemplo. El primer ejemplo es para añadir algo de texto a una página existente (si la página no existe, no sucederá nada). Ten en cuenta que se guarda la marca de tiempo de la revisión que estamos cambiando. Esto nos permite evitar conflictos de edición. El valor se devuelve a la función de edición, y si alguien hubiera editado la página en el ínterin, se devolvería un error.

my $pagename = "Wikipedia:Sandbox";
my $ref = $mw->get_page( { title => $pagename } );
unless ( $ref->{missing} ) {
  my $timestamp = $ref->{timestamp};
  $mw->edit( {
    action => 'edit',
    title => $pagename,
    basetimestamp => $timestamp, # para evitar conflictos de edición
    text => $ref->{'*'} . "\nAdditional text" } )
    || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
}

El siguiente código elimina una página con el nombre "DeleteMe". Puedes especificar una razón para la eliminación; de lo contrario, se utilizará una razón generada.

# delete a page
$mw->edit( {
  action => 'delete', title => 'DeleteMe', reason => 'no longer needed' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

Este código mueve una página de MoveMe a MoveMe2.

# move a page
$mw->edit( {
  action => 'move', from => 'MoveMe', to => 'MoveMe2' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

El siguiente script revierte una o más ediciones del usuario MrVandal. Si el usuario no es el último editor de la página, se devolverá un error. Si no se pasa ningún usuario, se revertirán las ediciones de quien haya modificado la página por última vez.

$mw->edit( {
  action => 'rollback', title => 'Sandbox', user => 'MrVandal' } )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

MediaWiki::API->get_page( $params_hashref )

Una función auxiliar para obtener el contenido más reciente de una página (y otros metadatos). Llama a la función de API de nivel inferior con una consulta de revisiones para obtener la revisión más reciente.

# get some page contents
my $page = $mw->get_page( { title => 'Main Page' } );
# print page contents
print $page->{'*'};

Devuelve un hashref con las siguientes claves o undef en caso de error. Si la página no existe, el hashref devuelto contendrá solo ns, title y una clave llamada "missing".

  • '*' - contenido de la página
  • 'pageid' - id de la página
  • 'revid' - id de la revisión
  • 'timestamp' - marca de tiempo de la revisión
  • 'user' - usuario que realizó la revisión
  • 'title' - el título de la página
  • 'ns' - el espacio de nombres en el que se encuentra la página
  • 'size' - tamaño de la página en bytes

Se puede leer información completa sobre estos en (https://www.mediawiki.org/wiki/API:Query_-_Properties#revisions_.2F_rv)

MediaWiki::API->list( $query_hashref, $options_hashref )

Una función auxiliar para obtener listas utilizando la API de MediaWiki. Los parámetros se pasan como un hashref que se describen en la página de edición de la API de MediaWiki (https://www.mediawiki.org/wiki/API:Query_-_Lists). Esta función modifica el query_hashref de entrada.

Esta función devolverá una referencia a un array de hashes o undef en caso de fallo. Se encarga de obtener listas de datos de la API de MediaWiki, continuando la solicitud con otra conexión si es necesario. El options_hashref tiene actualmente tres parámetros:

  • max => value
  • hook => \&function_hook
  • skip_encoding => 1

El valor de max especifica el número máximo de "consultas" que se utilizarán para extraer datos. Por ejemplo, el límite predeterminado por consulta es de 10 elementos, pero esto puede aumentarse a 500 para usuarios normales y más alto para administradores y bots. Si el límite se aumenta a 500 y max se estableció en 2, se devolvería un máximo de 1000 resultados.

Si deseas procesar listas grandes, por ejemplo, los artículos de una categoría grande, puedes pasar una función hook, que recibirá una referencia a un array de resultados por cada conexión de consulta.

El parámetro skip_encoding funciona como se describe anteriormente en la documentación de la llamada MediaWiki::API->api.

binmode STDOUT, ':utf8';
# procesa los primeros 400 artículos en el espacio de nombres principal de la categoría "Surnames".
# obtén 100 a la vez, con un máximo de 4 y pasa cada 100 a nuestro hook.
$mw->list ( { action => 'query',
              list => 'categorymembers',
              cmtitle => 'Category:Surnames',
              cmnamespace => 0,
              cmlimit=>'100' },
            { max => 4, hook => \&print_articles } )
|| die $mw->{error}->{code} . ': ' . $mw->{error}->{details};
# imprime el nombre de cada artículo
sub print_articles {
  my ($ref) = @_;
  foreach (@$ref) {
    print "$_->{title}\n";
  }
}

MediaWiki::API->upload( $params_hashref )

Esta función está obsoleta. Para cargar en versiones de mediawiki 1.16 o posteriores, se recomienda usar MediaWiki::API->edit o MediaWiki::API->api directamente, que tiene un manejo de errores mucho mejor y soporta la carga de archivos simplemente pasando un nombre de archivo.

Una función para cargar archivos en un MediaWiki. Esta función no utiliza la API de MediaWiki actualmente, ya que el soporte para la carga de archivos aún no se ha implementado. En su lugar, carga utilizando la página Special:Upload, y como tal, se necesita un valor de configuración adicional.

my $mw = MediaWiki::API->new( {
 api_url => 'https://en.wikipedia.org/w/api.php' }  );
# configura la ubicación especial de carga.
$mw->{config}->{upload_url} = 'https://en.wikipedia.org/wiki/Special:Upload';

La función de carga se llama de la siguiente manera

# upload a file to MediaWiki
open FILE, "myfile.jpg" or die $!;
binmode FILE;
my ($buffer, $data);
while ( read(FILE, $buffer, 65536) )  {
  $data .= $buffer;
}
close(FILE);
$mw->upload( { title => 'file.jpg',
               summary => 'This is the summary to go on the Image:file.jpg page',
               data => $data } ) || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

La comprobación de errores es limitada. Ten en cuenta también que el módulo forzará la carga de un archivo, ignorando cualquier advertencia sobre el tamaño del archivo o la sobrescritura de un archivo antiguo.

NAME

MediaWiki::API->download( $params_hashref )

VERSION

Una función para descargar imágenes/archivos de un MediaWiki. Es posible que sea necesario configurar una URL de archivo si la API devuelve una URL relativa.

my $mw = MediaWiki::API->new( {
  api_url => 'https://www.exotica.org.uk/mediawiki/api.php' }  );
# configurar la url del archivo. Wikipedia no necesita esto, pero el wiki ExoticA sí.
$mw->{config}->{files_url} = 'https://www.exotica.org.uk';

La función download se llama entonces de la siguiente manera:

my $file = $mw->download( { title => 'Image:Mythic-Beasts_Logo.png'} )
  || die $mw->{error}->{code} . ': ' . $mw->{error}->{details};

Si el archivo no existe (en el wiki) se devuelve una cadena vacía. Si el archivo no se puede descargar, se devuelve undef.
