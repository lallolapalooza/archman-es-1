Memory::Usage(3) Documentación de Perl contribuida por el usuario Memory::Usage(3)

NOMBRE

Memory::Usage - Herramientas para determinar el uso real de memoria

VERSIÓN

Versión 0.201

SINOPSIS

use Memory::Usage;
my $mu = Memory::Usage->new();
# Registrar la cantidad de memoria utilizada por el proceso actual
$mu->record('inicio del trabajo');
# Hacer la cosa que quieres medir
$object->something_memory_intensive();
# Registrar la cantidad en uso después
$mu->record('después de something_memory_intensive()');
# Imprimir un informe
$mu->dump();

DESCRIPCIÓN

Este módulo te permite intentar medir, desde la perspectiva de tu sistema operativo, cuánta memoria está utilizando un proceso en un momento dado.

MÉTODOS

Métodos de clase

new ( )
Crea un nuevo objeto Memory::Usage. Este objeto contendrá el estado de uso tal como se registró a lo largo del tiempo.

Métodos de instancia

record ( $message [, $pid ])
Registra el uso de memoria en el momento de la llamada, registrándolo internamente con el mensaje proporcionado. Opcionalmente, toma un ID de proceso para registrar el uso de memoria, que por defecto es el proceso actual.
report ( )
Genera un informe sobre el uso de memoria.
dump ( )
Imprime el informe sobre el uso de memoria en stderr.
state ( )
Devuelve una referencia de array del estado interno. La referencia de array devuelta contiene cero o más referencias a arrays con las siguientes columnas (en orden). Todos los tamaños están en kilobytes.
timestamp (en segundos desde la época)
mensaje (tal como se pasó a ->record())
tamaño de memoria virtual
tamaño del conjunto residente
tamaño de memoria compartida
tamaño de texto (también conocido como código o ejecutable)
tamaño de datos y pila

VER TAMBIÉN

  • Memchmark

    Ejecuta repetidamente coderefs (similar a Benchmark) y compara su uso de memoria. Útil para optimizar subrutinas específicas con un alto uso de memoria una vez que las has identificado como consumidoras intensivas. Utiliza la misma técnica para recopilar información de uso que este módulo, por lo que la precisión y la exactitud sufren de manera similar.

  • Devel::Size

    Muestra el tamaño de las variables de Perl. También es útil para microoptimizaciones cuando sabes lo que buscas. Examina los internos de Perl, por lo que la precisión es buena.
