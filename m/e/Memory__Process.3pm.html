Memory__Process(3pm)

Paquete: perl-memory-process

Licencias: PerlArtistic, GPL

Process(3) Documentación de Perl contribuida por el usuario Process(3)

NOMBRE

Memory::Process - Clase de Perl para determinar el uso real de memoria.

SINOPSIS

use Memory::Process;
my $m = Memory::Process->new(%params);
$m->dump;
$m->record($message, $pid);
my @report = $m->report;
my $report = $m->report;
$m->reset;
$m->state;

MÉTODOS

"new"

my $m = Memory::Process->new(%params);

Constructor.

Devuelve una instancia del objeto.

"dump"

$m->dump;

Imprime el informe en STDERR.

Devuelve el valor de retorno de print().

"record"

$m->record($message, $pid);

Establece el registro. Si no se establece el mensaje, se usa ''.

Devuelve undef.

"report"

my @report = $m->report;
my $report = $m->report;

Obtiene el informe.

En contexto escalar devuelve una cadena con el informe. En contexto de array devuelve un array de líneas del informe. La primera línea es el título.

"reset"

$m->reset;

Reinicia los registros.

Devuelve undef.

"state"

$m->state;

Obtiene el estado interno.

Cada elemento de estado consta de:

- marca de tiempo (en segundos desde la época)
- mensaje (de record())
- tamaño de memoria virtual (en kB)
- tamaño del conjunto residente (en kB)
- tamaño de memoria compartida (en kB)
- tamaño de texto (en kB)
- tamaño de datos y pila (en kB)

Devuelve una referencia a un array con los elementos del estado.

EJEMPLO1

use strict;
use warnings;
use Memory::Process;
# Objeto.
my $m = Memory::Process->new;
# Proceso de ejemplo.
$m->record("Antes de mi gran método");
my $var = ('foo' x 100);
sleep 1;
$m->record("Después de mi gran método");
sleep 1;
$m->record("Fin");
# Imprime el informe.
print $m->report."\n";
# Salida similar a:
#   hora    vsz (  diff)    rss (  diff) compartido (  diff)   código (  diff)   datos (  diff)
#      1  19120 (     0)   2464 (     0)   1824 (     0)      8 (     0)   1056 (     0) Después de mi gran método
#      2  19120 (     0)   2464 (     0)   1824 (     0)      8 (     0)   1056 (     0) Fin
