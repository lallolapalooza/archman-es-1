XtPopdown(3) FUNCIONES XT XtPopdown(3)

NOMBRE

XtPopdown, XtCallbackPopdown - desvincular una ventana emergente

SINTAXIS

#include <X11/Intrinsic.h>

void XtPopdown(Widget popup_shell);

void XtCallbackPopdown(Widget w, XtPointer client_data, XtPointer call_data);

ACCIONES

void XtMenuPopdown(String shell_name);

ARGUMENTOS

call_data
Especifica los datos de la devolución de llamada, que no son utilizados por este procedimiento.
client_data
Especifica un puntero a la estructura XtPopdownID.
popup_shell
Especifica el widget shell a desvincular.
shell_name
Especifica el nombre del widget shell a desvincular.
w
Especifica el widget.

DESCRIPCIÓN

La función XtPopdown realiza lo siguiente:

  • Llama a XtCheckSubclass para asegurar que popup_shell sea una subclase de Shell.
  • Verifica que popup_shell esté actualmente desvinculado (popped_up); de lo contrario, genera un error.
  • Desvincula la ventana de popup_shell.
  • Si el tipo de agarre (grab_kind) de popup_shell es XtGrabNonexclusive o XtGrabExclusive, llama a XtRemoveGrab.
  • Establece el campo popped_up del shell emergente a False.
  • Llama a los procedimientos de devolución de llamada en la lista popdown_callback del shell.

La función XtCallbackPopdown convierte el parámetro de datos del cliente en un puntero XtPopdownID:

typedef struct {
        Widget shell_widget;
        Widget enable_widget;
} XtPopdownIDRec, *XtPopdownID;

shell_widget es el shell emergente a desvincular, y enable_widget es el widget que se usó para desvincularlo.

XtCallbackPopdown llama a XtPopdown con el shell_widget especificado y luego llama a XtSetSensitive para volver a sensibilizar el enable_widget.

Si no se proporciona un nombre de shell, XtMenuPopdown llama a XtPopdown con el widget para el cual se especifica la traducción. Si se especifica un nombre de shell en la tabla de traducción, XtMenuPopdown intenta encontrar el shell buscando en el árbol de widgets comenzando desde el padre del widget en el que se invoca. Si encuentra un shell con el nombre especificado en los hijos emergentes de ese padre, desvincula el shell; de lo contrario, sube en la cadena de padres según sea necesario. Si XtMenuPopdown llega al widget shell de nivel superior de la aplicación y no puede encontrar un shell coincidente, genera un error.
