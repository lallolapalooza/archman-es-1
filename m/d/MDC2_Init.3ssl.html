MDC2_Init(3ssl)

Paquete: openssl

Licencias: Apache-2.0

MDC2_INIT(3ssl) OpenSSL MDC2_INIT(3ssl)

NOMBRE

MDC2, MDC2_Init, MDC2_Update, MDC2_Final - Función hash MDC2

SINOPSIS

#include <openssl/mdc2.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

unsigned char *MDC2(const unsigned char *d, unsigned long n,
                    unsigned char *md);
int MDC2_Init(MDC2_CTX *c);
int MDC2_Update(MDC2_CTX *c, const unsigned char *data,
                unsigned long len);
int MDC2_Final(unsigned char *md, MDC2_CTX *c);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_DigestInit_ex(3), EVP_DigestUpdate(3) y EVP_DigestFinal_ex(3).

MDC2 es un método para construir funciones hash con salida de 128 bits a partir de cifrados de bloque. Estas funciones son una implementación de MDC2 con DES.

MDC2() calcula el resumen de mensaje MDC2 de los n bytes en d y lo coloca en md (que debe tener espacio para MDC2_DIGEST_LENGTH == 16 bytes de salida). Si md es NULL, el resumen se coloca en un array estático.

Las siguientes funciones pueden ser usadas si el mensaje no está completamente almacenado en memoria:

MDC2_Init() inicializa una estructura MDC2_CTX.

MDC2_Update() puede ser llamada repetidamente con fragmentos del mensaje a hashear (len bytes en data).

MDC2_Final() coloca el resumen del mensaje en md, que debe tener espacio para MDC2_DIGEST_LENGTH == 16 bytes de salida, y borra el MDC2_CTX.

Las aplicaciones deberían usar las funciones de nivel superior EVP_DigestInit(3) etc. en lugar de llamar directamente a las funciones hash.

VALORES DE RETORNO

MDC2() devuelve un puntero al valor hash.

MDC2_Init(), MDC2_Update() y MDC2_Final() devuelven 1 en caso de éxito, 0 en caso contrario.

CONFORME A

ISO/IEC 10118-2:2000 Hash-Function 2, con DES como cifrado de bloque subyacente.

VER TAMBIÉN

EVP_DigestInit(3)

HISTORIA

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
