NOMBRE

MD2, MD4, MD5, MD2_Init, MD2_Update, MD2_Final, MD4_Init, MD4_Update, MD4_Final, MD5_Init, MD5_Update, MD5_Final - Funciones hash MD2, MD4 y MD5

SINOPSIS

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

#include <openssl/md2.h>
unsigned char *MD2(const unsigned char *d, unsigned long n, unsigned char *md);
int MD2_Init(MD2_CTX *c);
int MD2_Update(MD2_CTX *c, const unsigned char *data, unsigned long len);
int MD2_Final(unsigned char *md, MD2_CTX *c);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

#include <openssl/md4.h>
unsigned char *MD4(const unsigned char *d, unsigned long n, unsigned char *md);
int MD4_Init(MD4_CTX *c);
int MD4_Update(MD4_CTX *c, const void *data, unsigned long len);
int MD4_Final(unsigned char *md, MD4_CTX *c);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0 y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

#include <openssl/md5.h>
unsigned char *MD5(const unsigned char *d, unsigned long n, unsigned char *md);
int MD5_Init(MD5_CTX *c);
int MD5_Update(MD5_CTX *c, const void *data, unsigned long len);
int MD5_Final(unsigned char *md, MD5_CTX *c);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_DigestInit_ex(3), EVP_DigestUpdate(3) y EVP_DigestFinal_ex(3).

MD2, MD4 y MD5 son funciones hash criptográficas con una salida de 128 bits.

MD2(), MD4() y MD5() calculan el hash del mensaje MD2, MD4 y MD5 de los n bytes en d y lo colocan en md (que debe tener espacio para MD2_DIGEST_LENGTH == MD4_DIGEST_LENGTH == MD5_DIGEST_LENGTH == 16 bytes de salida). Si md es NULL, el hash se coloca en un array estático.

Las siguientes funciones pueden usarse si el mensaje no está completamente almacenado en memoria:

MD2_Init() inicializa una estructura MD2_CTX.

MD2_Update() puede ser llamada repetidamente con fragmentos del mensaje a hashear (len bytes en data).

MD2_Final() coloca el hash del mensaje en md, que debe tener espacio para MD2_DIGEST_LENGTH == 16 bytes de salida, y borra el MD2_CTX.

MD4_Init(), MD4_Update(), MD4_Final(), MD5_Init(), MD5_Update() y MD5_Final() son análogas utilizando una estructura MD4_CTX y MD5_CTX. El parámetro NO DEBE ser NULL.

Las aplicaciones deberían usar las funciones de nivel superior EVP_DigestInit(3) etc. en lugar de llamar directamente a las funciones hash.

NOTA

MD2, MD4 y MD5 se recomiendan solo por compatibilidad con aplicaciones existentes. En nuevas aplicaciones, se prefieren los hashes de la familia SHA-2 o SHA-3.

VALORES DE RETORNO

MD2(), MD4() y MD5() devuelven punteros al valor hash.

MD2_Init(), MD2_Update(), MD2_Final(), MD4_Init(), MD4_Update(), MD4_Final(), MD5_Init(), MD5_Update() y MD5_Final() devuelven 1 en caso de éxito, 0 en caso contrario.

CONFORMIDAD

RFC 1319, RFC 1320, RFC 1321

VER TAMBIÉN
