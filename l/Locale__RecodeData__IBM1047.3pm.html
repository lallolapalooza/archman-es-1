DESCRIPCIÓN

Locale::RecodeData::IBM1047 es un módulo que proporciona datos para la codificación de caracteres IBM1047.

COMENTARIOS

Este módulo está diseñado para proporcionar los datos necesarios para la codificación de caracteres IBM1047, que se utiliza en algunos sistemas y aplicaciones.
