NAME

Locale::RecodeData::MAC_SAMI - Rutinas de conversión para MAC-SAMI

SYNOPSIS

Este módulo es interno de libintl. No lo use directamente!

DESCRIPTION

Este módulo contiene las tablas de conversión y rutinas para MAC-SAMI.

COMMENTS

Las siguientes comentarios han sido extraídos del original charmap:

source:  http://www.indigo.ie/egt/standards/se/mac-sami.html
author:  Regnor Jernsletten E<lt>Regnor.Jernsletten@sami.uit.noE<gt>
date:    2001-07-31
comment: Estándar de sami de Macintosh.

Nota: Los alias mencionados anteriormente no necesariamente son válidos!
