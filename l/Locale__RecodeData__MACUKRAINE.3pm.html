NOMBRE

Locale::RecodeData::MACUKRAINE - datos de codificación para el juego de caracteres MAC Ukrainian.

SINOPSIS

    use Locale::RecodeData::MACUKRAINE;

DESCRIPCIÓN

Este módulo proporciona los datos de mapeo de caracteres necesarios para la codificación MAC_UKRAINE (también conocida como MAC Ukrainian) utilizada en Apple Macintosh.

Define los mapeos de caracteres entre diferentes codificaciones y la representación interna de Locale::Recode.

COMENTARIOS

Este módulo es parte de la distribución libintl-perl y se utiliza junto con el módulo Locale::Recode para realizar conversiones de codificación de caracteres.
