NOMBRE

Lire::Aggregate - Clase base para todos los operadores que calculan valores de un grupo de registros DLF

SINOPSIS

use Lire::Aggregate;
use base qw/ Lire::Aggregate /;

DESCRIPCIÓN

Lire::Aggregate es la clase base de todos los operadores que calculan valores a partir de un grupo de registros DLF. Estos son los operadores que se utilizan dentro de los agregadores.

Este paquete también define la mayoría de las clases que representan los operadores de grupo disponibles en la especificación de informes de Lire.

MÉTODOS PARA SUBCLASES DE Aggregate

init( %params )

Se necesitan dos parámetros suplementarios para los Agregados:

padre
El Lire::Aggregator que contiene este Agregado.
nombre
El identificador que se puede utilizar para encontrar este operador en la especificación del informe. Será devuelto por el método name().

print( $fh, $prefijo)

Este método implementa el método print() requerido por Lire::ReportOperator. Imprime un elemento XML vacío con el nombre del operador (obtenido de op()). También se encarga de escribir los atributos de nombre y etiqueta. Se pueden añadir otros atributos al elemento XML sobrescribiendo el método xml_attrs().

xml_attrs()

Este método puede ser utilizado para escribir atributos XML adicionales. La cadena devuelta se mostrará en el elemento XML.

set_name( $nombre )

Cambia el nombre de este operador.

create_numerical_info( $info_grupo )

Las subclases deben implementar este método.

El parámetro $info_grupo es un objeto Lire::Report::GroupInfo al que la implementación del operador debe añadir el objeto ColumnInfo apropiado para representar los datos generados por el agregado.

build_query( $query )

FIXME.

Proporciona una implementación predeterminada de build_query

set_missing_cases_aggr_expr( $query )

Añade la expresión de agregado para calcular el número de casos faltantes basándose en los campos requeridos devueltos por el método sql_required_fields().

El método set_missing_cases_value() puede ser utilizado para establecer el valor de la fila DLF devuelta.

set_missing_cases_value( $row, $valor )

Establece el valor de casos faltantes en $valor al valor calculado por la expresión establecida usando set_missing_cases_aggr_expr().

sql_aggr_expr()

Método utilizado por la implementación predeterminada de build_query(). Debería devolver la expresión de agregado SQL que debería asociarse al nombre de este Agregado. Por ejemplo, una simple implementación de Conteo podría haber devuelto 'count(*)' aquí.

sql_required_fields()

Método utilizado por set_missing_cases_aggr_expr() para establecer una expresión de agregado que devolverá el número de casos faltantes para este agregado. Debería devolver una lista de campos que crearán un caso faltante cuando un valor sea NULL.

create_value( $grupo_padre, $row )

Método que es utilizado por Aggregator al construir la tabla de informe. El informe debería devolver una referencia hash con las claves apropiadas establecidas. Consultar Lire::Report::Entry(3pm) para más detalles.

El parámetro $grupo_padre es el Lire::Report::Group al que se añade el valor. Este será la tabla o el grupo que contiene los valores añadidos a las Entradas, y será el padre del Grupo al crear un valor resumen.

El parámetro $row es una referencia hash que contiene la fila DlfResult para la cual se debe crear el valor.

La implementación debería usar el método set_missing_cases_value() para establecer el atributo 'missing_cases' del valor.
