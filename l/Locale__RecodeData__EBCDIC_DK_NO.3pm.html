NAME

Locale::RecodeData::EBCDIC_DK_NO - Rutinas de conversión para EBCDIC_DK_NO

SYNOPSIS

Este módulo es interno de libintl. No lo use directamente.

DESCRIPTION

Este módulo contiene las tablas de conversión y rutinas para EBCDIC_DK_NO.

COMMENTS

Las siguientes observaciones han sido extraídas del charmap original:

version: 1.0
repertoiremap: mnemonic,ds
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, April 1987

Nota: ¡los alias mencionados anteriormente no son necesariamente válidos!
