NAME

Locale::RecodeData::IBM874 — Thai (CP874, TIS-620, UTF-8) conversion table.

SYNOPSIS

    use Locale::RecodeData::IBM874;

DESCRIPTION

This module defines the conversion table for Thai characters. It supports the following encodings:

    IBM874, CP874, TIS-620, UTF-8

It does *not* support the older Thai encodings like MIK or VISCI.

This module is used by Locale::Recode(3).

COMMENTS

This module is a data file, and is not meant to be used directly. It is a part of the Locale(3) package.
