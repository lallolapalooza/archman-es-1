Lire::FilterSpec - Especificación de filtro global.

use Lire::FilterSpec;

DESCRIPCIÓN

MÉTODOS DE INFORMACIÓN META

list_specs( $superservice )

Devuelve una referencia de array que contiene todos los tipos de especificación de filtro disponibles para el super servicio $superservice.

has_spec( $superservice, $type )

Devuelve verdadero si hay una especificación de $type disponible para el super servicio $superservice.
