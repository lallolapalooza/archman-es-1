NOMBRE

Lire::DlfAnalyser - Interfaz base para todos los analizadores DLF.

SINOPIS

use base qw/ Lire::DlfAnalyser /;

DESCRIPCIÓN

Este paquete define la interfaz que debe ser implementada por todos los Analizadores DLF. Todos los métodos definidos en este paquete lanzarán una excepción de 'método no implementado' si son llamados.

Los analizadores que producen registros DLF para un esquema extendido probablemente deberían usar la interfaz más simple Lire::DlfCategoriser.

MÉTODOS DE INFORMACIÓN DE METADATOS

Estos métodos proporcionan información al framework Lire sobre los analizadores DLF.

La interfaz Lire::DlfAnalyser extiende la interfaz Lire::Plugin, por lo que deben implementar todos los métodos estándar de metadatos (name(), title(), description()).

src_schema()

Devuelve el esquema Dlf que es analizado por este analizador.

Ejemplo: "www"

dst_schema()

Devuelve el esquema Dlf que es producido por este analizador.

Ejemplo: "www-user_session"

MÉTODO DE IMPLEMENTACIÓN

El analizador realiza su trabajo usando el método analyse().

analyse( $process, $config )

El parámetro $process contiene el objeto Lire::DlfAnalyserProcess que está controlando el proceso de conversión.

El parámetro $config contiene datos de configuración que se especificaron en el AnalysisJob para ese conversor. Para registrar la especificación de configuración para tu DlfAnalyser, solo necesitas definir una especificación de configuración bajo el nombre analyser_name_properties. Esto debería ser un RecordSpec o un ObjectSpec.

VER TAMBIÉN

Lire::DlfAnalyserProcess(3pm), Lire::DlfStore(3pm), Lire::PluginManager(3pm), Lire::DlfCategoriser(3pm).
