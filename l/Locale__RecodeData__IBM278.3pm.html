NOMBRE Documentación del usuario de Perl Locale::RecodeData::IBM278(3)

NOMBRE

Locale::RecodeData::IBM278 - Rutinas de conversión para IBM278

RESUMEN

Este módulo es interno de libintl. ¡No lo use directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para IBM278.

COMENTARIOS

Los siguientes comentarios se han extraído del charmap original:

versión: 1.0
 fuente: IBM NLS RM Vol2 SE09-8002-01, Marzo 1990
 alias CP278
 alias EBCDIC-CP-FI
 alias EBCDIC-CP-SE

Nota: ¡Los alias mencionados anteriormente no son necesariamente válidos!
