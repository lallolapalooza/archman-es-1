NOMBRE

Locale::Po4a::Common - partes comunes de los scripts y utilidades po4a

DESCRIPCIÓN

Locale::Po4a::Common contiene partes comunes de los scripts po4a y algunas funciones útiles usadas junto con otros módulos.

Si es necesario, puedes deshabilitar el uso de Text::WrapI18N de la siguiente manera:

use Locale::Po4a::Common qw(nowrapi18n);
use Locale::Po4a::Text;

en lugar de:

use Locale::Po4a::Text;

El orden es importante aquí: como la mayoría de los módulos de Locale::Po4a se cargan a sí mismos Locale::Po4a::Common, la primera vez que se carga este módulo determina si se utiliza Text::WrapI18N.

FUNCIONES

Mostrar mensajes de salida

  • show_version($)

    Muestra la versión actual del script y un breve mensaje de copyright. Toma el nombre del script como argumento.

  • wrap_msg($@)

    Esta función muestra un mensaje de la misma manera que lo hace sprintf(), pero ajusta el resultado para que se vea bien en la terminal.

  • wrap_mod($$@)

    Esta función funciona como wrap_msg(), pero toma un nombre de módulo como primer argumento y deja un espacio a la izquierda del mensaje.

  • wrap_ref_mod($$$@)

    Esta función funciona como wrap_msg(), pero toma una referencia archivo:línea como primer argumento, un nombre de módulo como segundo y deja un espacio a la izquierda del mensaje.

Envolturas para otros módulos

•
Locale::Gettext

Cuando el módulo Locale::Gettext no se puede cargar, este módulo proporciona una implementación ficticia (vacía) de las siguientes funciones. En ese caso, los mensajes de po4a no se traducirán, pero el programa continuará funcionando.

Si Locale::gettext está presente, esta envoltura también llama a setlocale(LC_MESSAGES, "") para que los llamadores no dependan tampoco del módulo POSIX.

  • bindtextdomain($$)
  • textdomain($)
  • gettext($)
  • dgettext($$)
