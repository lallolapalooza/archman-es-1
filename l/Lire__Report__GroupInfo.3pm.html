GroupInfo(3pm) Documentación de Lire de LogReport GroupInfo(3pm)

NOMBRE

Lire::Report::GroupInfo - Objeto que agrupa columnas creadas por el mismo agregador. .

SINOPSIS

my $info = $subreport->group_info( 0 );
print "Nombre del grupo: ", $info->name(),   "\n";
print "Las columnas del grupo comienzan en: ", $info->index(), "\n";

DESCRIPCIÓN

El objeto Lire::Report::GroupInfo contiene los objetos ColumnInfo que fueron creados por el mismo agregador.

CONSTRUCTOR

nuevo( $nombre )

Creas un nuevo objeto Lire::Report::GroupInfo llamando al método create_group_info() en un objeto Lire::Report::TableInfo u otro objeto Lire::Report::GroupInfo.

MÉTODOS DE OBJETO

name()

Devuelve el nombre de este grupo. Este nombre se puede usar para encontrar el agregador (de la especificación del informe) que es responsable de los datos contenidos en este grupo.

row_idx()

Devuelve el índice de fila en el que se deben mostrar las etiquetas de la columna categórica de este grupo en la cabecera de la tabla.

max_row_idx()

parent_group_info()

Devuelve el GroupInfo que contiene este GroupInfo. Será indefinido para el objeto TableInfo de nivel superior.

index()

Devuelve el índice de columna en la tabla en el que comienzan las columnas de este grupo. Será indefinido hasta que el objeto group info se agregue a un Lire::Subreport u otro objeto Lire::Group.

children()

Devuelve como un array, los objetos ColumnInfo y GroupInfo de Lire::Report contenidos en este grupo.

info_by_index( $idx )

Devuelve el ColumnInfo o GroupInfo que se encuentra en el índice $idx entre los hijos de este GroupInfo.

group_children

Devuelve como un array, solo los GroupInfo de Lire::Report contenidos en este GroupInfo.

column_children

Devuelve como un array, solo los ColumnInfo de Lire::Report contenidos en este GroupInfo.

categorical_names()

Devuelve los nombres de las columnas categóricas como una referencia de array.

create_column_info( $name, $class, $type, [$label]])

Crea un nuevo objeto Lire::Report::ColumnInfo como hijo de este GroupInfo. Los atributos de la información de la columna se inicializan en función de $name, $class, $type y $label.

Esto establecerá el índice del objeto ColumnInfo.

Devuelve el objeto ColumnInfo creado.

create_group_info( $name )

Crea un Lire::Report::GroupInfo como hijo de este grupo. Esto también establecerá el índice de columna inicial en el objeto GroupInfo. El parámetro $name debe contener el nombre del agregador de la especificación del informe que es responsable del contenido de este grupo.

Devuelve el objeto GroupInfo creado.

column_info_by_name( $name )

Devuelve el objeto Lire::Report::ColumnInfo que tiene el nombre $name. Este método busca en el grupo actual y también en sus subgrupos.

Devuelve indefinido si la columna no se encuentra.

column_info_by_col_start( $col_idx )

Devuelve el objeto Lire::Report::ColumnInfo que comienza en el índice de columna $col_idx. Este método busca en el grupo actual y también en sus subgrupos.

Devuelve indefinido si la columna no se encuentra en el grupo actual.

group_info( $name )

Devuelve el objeto Lire::Report::GroupInfo que tiene el nombre $name. Esto será indefinido si no se puede encontrar en esta información de grupo.

VER TAMBIÉN

Lire::Report::Subreport(3pm) Lire::Report::ColumnInfo(3pm)
