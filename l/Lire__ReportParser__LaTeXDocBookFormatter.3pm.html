LaTeXDocBookFormatter(3pm) Documentación de Lire de LogReport LaTeXDocBookFormatter(3pm)

NOMBRE

Lire::ReportParser::LaTeXDocBookFormatter - Subclase de Lire::DocBookParser que formatea la descripción a LaTeX.

SINOPSIS

Para convertir una descripción DocBook a LaTeX:

use Lire::ReportParser::LaTeXDocBookFormatter qw/dbk2latex/;
my $LaTeX = dbk2latex( "<para>Prueba</para>" );

DESCRIPCIÓN

Este paquete implementa métodos que pueden manejar el contenido de los elementos "description" y puede ser utilizado por una subclase de Lire::ReportParser. El cliente solo tiene que heredar de este módulo para que esté disponible un método handle_description() para procesar el texto de la descripción formateada en DocBook.

Este módulo también proporciona una función conveniente dbk2txt() que puede ser utilizada para formatear una cadena que contiene elementos DocBook a un equivalente ASCII.

USO DE Lire::ReportParser::LaTeXDocBookFormatter

Los procesadores de Lire::ReportParser que deseen trabajar con la versión de texto de la descripción deben heredar de Lire::ReportParser::LaTeXDocBookFormatter además de Lire::ReportParser. Si sobrescriben los métodos description_start() y description_end(), deben enlazar a la versión de sus padres usando "SUPER::".

Adicionalmente, deben fusionar el valor de elements_spec() en su implementación de elements_spec().

Lire::ReportParser::LaTeXDocBookFormatter debe listarse antes que Lire::ReportParser en el array @ISA. LaTeXDocBookFormatter no hereda directamente de Lire::ReportParser para que pueda ser utilizado en escenarios de herencia múltiple.

dbk_start_processing()

Inicializa la estructura del analizador para formatear XML DocBook como ASCII. Esto se utiliza desde la implementación de description_start.

dbk_end_processing()

Limpia la estructura del analizador. Esto se utiliza desde la implementación de description_end().

handle_description( $description )

Este método se invoca después de que se encuentra la etiqueta de cierre del elemento "description". $description contiene la descripción convertida a LaTeX.

PROCESAMIENTO DE DESCRIPCIÓN LaTeX

El LaTeX generado está codificado en UTF-8, por lo que se debe usar Omega para procesarlo. Adicionalmente, el resultado de llamar a dbk_latex_environment() debe añadirse al preámbulo del documento. Añade algunas definiciones de entorno y comandos utilizadas por el formateador.

FORMATEO DE CADENAS DocBook

Si tienes contenido DocBook en una cadena, como puedes obtener de algunos de los objetos de Especificación de Informe, puedes convertirlo a LaTeX utilizando la función dbx2latex().

dbk2txt( $docbook_str, [$columnas] )

Devuelve una versión de texto plano del fragmento XML DocBook $docbook_str. El parámetro "columnas" establece el número de columnas en las que se debe formatear el texto DocBook.

Este método morirá() en caso de error.
