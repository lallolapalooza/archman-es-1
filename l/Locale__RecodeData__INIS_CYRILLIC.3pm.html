NOMBRE

Locale::RecodeData::INIS_CYRILLIC - Rutinas de conversión para INIS_CYRILLIC

SINOPSIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas de conversión y las rutinas para INIS-CYRILLIC.

COMENTARIOS

Las siguientes observaciones se extrajeron del charmap original:

version: 1.0
 source: ECMA registry
alias ISO-IR-51

Nota: ¡Los alias mencionados arriba no son necesariamente válidos!
