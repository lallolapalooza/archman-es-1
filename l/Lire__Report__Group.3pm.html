NOMBRE

Lire::Report::Group - Objeto que incluye subgrupos y otras entradas.

SINOPSIS

foreach my $e ( $group->entries() ) {
    # Procesa los datos de las entradas.
}

DESCRIPCIÓN

El objeto Lire::Report::Group contiene entradas agrupadas juntas en un subinforme.

CONSTRUCTOR

Creas un nuevo objeto Lire::Report::Group llamando al método create_group() en un objeto Lire::Report::Entry.

MÉTODOS DEL OBJETO

parent_entry()

Devuelve la entrada en la que está contenido este grupo. Esto será undef para el subinforme ya que no está contenido en ninguna entrada.

group_info()

Devuelve el Lire::Report::GroupInfo que contiene la información que describe las entradas de este grupo.

subreport()

Devuelve el objeto Lire::Report::Subreport en el que está esta entrada.

row_idx()

Devuelve el índice de fila en el cuerpo de la tabla donde se debe mostrar el resumen de este grupo. Si es undef, este grupo no se muestra.

show( [$show] )

Devuelve el número de entradas que deben mostrarse en el informe formateado. Puede haber más entradas que ese número en el grupo. Cuando este parámetro es cero o indefinido, se deben mostrar todas las entradas disponibles.

Si se establece el parámetro $show, el parámetro show del grupo se establecerá en este nuevo valor.

nrecords( [$n] )

Devuelve el número de registros DLF que se incluyeron en este grupo.

missing_cases( [$n] )

Devuelve el número de registros DLF que contenían casos faltantes que impidieron que se incluyeran en el subinforme.

summary_values()

Devuelve los valores resumen de este grupo. Es un array de referencias a hash como los devueltos por el método values() descrito en Lire::Report::Entry(3pm).

get_summary_value( $name )

Devuelve el valor resumen del operador $name. Es una referencia a hash como la devuelta por el método values() descrito en Lire::Report::Entry(3pm). Devuelve undef si el valor resumen no se calculó para el operador $name.

set_summary_value( $name, %value )

Establece el valor del operador $name calculado sobre todos los registros DLF del grupo. Consulte el método add_value() en Lire::Report::Entry(3pm) para obtener información sobre los parámetros.

entries()

Devuelve las entradas del grupo.

create_entry()

Añade una entrada de datos a este grupo. Esto creará un nuevo objeto Lire::Report::Entry que luego podrá ser llenado con datos.

find_entry( $name, $dlf )
