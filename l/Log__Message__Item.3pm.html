Log::Message::Item(3) Documentación de Perl contribuida por el usuario Log::Message::Item(3)

NOMBRE

Log::Message::Item - Objetos de mensaje para Log::Message

SINOPSIS

# Utilizado implícitamente por Log::Message para crear objetos Log::Message::Item
print "el id del mensaje es: ",     $item->id;
print "el mensaje almacenado es: ",   $item->message;
print "cuándo ocurrió: ",     $item->when;
print "el mensaje fue etiquetado: ",       $item->tag;
print "este fue el nivel de severidad: ",  $item->level;
$item->remove;  # eliminar el elemento de la pila en la que estaba
# Además de estos métodos, también puedes llamar a los manejadores en
# el objeto específicamente.
# Consulta la página del manual de Log::Message::Handlers para obtener documentación sobre qué
# manejadores están disponibles por defecto y cómo añadir los tuyos.

DESCRIPCIÓN

Log::Message::Item es una clase que genera elementos de registro genéricos. Estos elementos se almacenan en una pila de Log::Message, así que consulta la página del manual de Log::Message sobre detalles de cómo recuperarlos.

Probablemente no deberías crear nuevos elementos tú mismo, sino utilizar el mecanismo de almacenamiento proporcionado por Log::Message.

Sin embargo, los accesores y manejadores son de interés si deseas afinar cómo se manejan tus mensajes.

Los accesores y métodos se describen a continuación, los manejadores se documentan en la página del manual de Log::Message::Handlers.

Métodos y Accesorios

remove

Llamar a `remove` eliminará el objeto de la pila en la que se encontraba, por lo que ya no aparecerá en las recuperaciones posteriores de mensajes.

Sin embargo, todavía puedes llamar a los accesores y manejadores sobre él, para gestionarlo como desees.

id

Devuelve el ID interno del elemento. Esto puede ser útil para comparar, ya que el ID se incrementa cada vez que se crea un nuevo elemento. Por lo tanto, un elemento con ID 4 debe haberse registrado antes que un elemento con ID 9.

when

Devuelve la marca de tiempo de cuándo se registró el mensaje.

message

El mensaje real que se almacenó.

level

El tipo de severidad de este mensaje, así como el nombre del manejador que se llamó al almacenarlo.

tag

Devuelve la etiqueta de identificación que se puso al mensaje.

shortmess

Devuelve el equivalente de "Carp::shortmess" para este elemento. Consulta la página del manual de "Carp" para obtener más detalles.

longmess

Devuelve el equivalente de "Carp::longmess" para este elemento, que es esencialmente un rastreo de pila. Consulta la página del manual de "Carp" para obtener más detalles.

parent

Devuelve una referencia al objeto Log::Message que almacenó este elemento. Esto es útil si deseas tener acceso a la pila completa en un manejador.

VER TAMBIÉN

Log::Message, Log::Message::Handlers, Log::Message::Config
