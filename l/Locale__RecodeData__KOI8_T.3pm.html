NAME

Locale::RecodeData::KOI8_T - KOI8-T encoding

SYNOPSIS

 use Locale::RecodeData::KOI8_T qw( :all );

DESCRIPTION

This module implements the KOI8-T character set encoding.

KOI8-T is an 8-bit character set that supports the Cyrillic alphabet used in Tajikistan. It's a variant of KOI8-R.

COMMENTS

This encoding is seldom used. It's unlikely that you will ever need this module.
