NOMBRE

Locale::Maketext::Extract::Plugin::FormFu - Parser de formato FormFu

VERSIÓN

versión 1.00

SYNOPSIS

$plugin = Locale::Maketext::Extract::Plugin::FormFu->new(
    $lexicon            # Objeto Locale::Maketext::Extract
    @file_types         # Opcional: lista de tipos de archivos reconocidos
)
$plugin->extract($filename,$filecontents);

DESCRIPCIÓN

HTML::FormFu utiliza un archivo de configuración para generar formularios, con soporte integrada para localizar errores, etiquetas, etc.

NOMBRE DE PLUGIN BREVE

formfu

FORMATOS VÁLIDOS

Extraemos el texto después de cualquier clave que termine en "\_loc":

content_loc: esta es la cadena
message_loc: ['Max length [_1]', 10]

TIPOS DE ARCHIVOS CONOCIDOS

.yaml
.yml
.conf

REQUIERE

YAML

NOTAS

Las explicaciones del módulo YAML describen que es código alpha. No es tan tolerante a errores como YAML::Syck. Sin embargo, porque es Perl pura, es fácil de integrar.

He visto que entra en bucles infinitos, así que si xgettext.pl se queda bloqueado, intenta ejecutarlo de nuevo con "--verbose --verbose" (dos veces), para ver si el error está en el YAML. Si es así, corrige el archivo de fuente YAML o usa el archivo_types para excluir ese archivo.

VER TAMBIÉN

xgettext.pl
para extraer strings translatable de sistemas de plantillas comunes y archivos de Perl.
