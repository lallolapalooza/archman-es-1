List::MoreUtils(3) Documentación aportada por Perl List::MoreUtils(3)

NOMBRE

List::MoreUtils - Proporcionar el contenido que falta en List::Util

SINOPSIS

# importar funciones específicas
use List::MoreUtils qw(any uniq);
if ( any { /foo/ } uniq @has_duplicates ) {
    # haz algo
}
# importar todo
use List::MoreUtils ':all';
# importar por API
# tiene el comportamiento original de "original" any/all/none/notall
use List::MoreUtils ':like_0.22';
# 0.22 + bsearch
use List::MoreUtils ':like_0.24';
# tiene el comportamiento simplificado de "simplified" any/all/none/notall + (n)sort_by
use List::MoreUtils ':like_0.33';

DESCRIPCIÓN

List::MoreUtils proporciona algunas funciones triviales pero necesarias en listas que no van a ir a List::Util.

Todas las funciones siguientes son implementables en solo unas líneas de código de Perl. Usar estas funciones desde este módulo dará un ligeramente mejor rendimiento, ya que todo está implementado en C. La implementación pura de estas funciones en Perl solo sirve como fallback en caso de que las partes C de este módulo no puedan compilarse en este dispositivo.

EXPORTS

Comportamiento por defecto

Nada por defecto. Para importar todos los símbolos de este módulo usa la etiqueta ":all". De otro modo, las funciones pueden importarse por nombre como usual:

use List::MoreUtils ':all';
use List::MoreUtils qw{ any firstidx };

Por motivos históricos, los cambios en la API pueden hacer que la actualización de List::MoreUtils sea difícil para algunos proyectos. Por eso, el API antiguo está disponible mediante etiquetas de importación especial.

Como la versión 0.22 (última versión con API original)

Este API estuvo disponible desde 2006 hasta 2009, devolviendo undef para listas vacías en "all"/"any"/"none"/"notall":

use List::MoreUtils ':like_0.22';

Esta etiqueta de importación importará todas las funciones disponibles en la versión 0.22. Sin embargo, "any_u" se importará como "any", "all_u" como "all", "none_u" como "none" y "notall_u" como "notall".

Como la versión 0.24 (primer cambio incompatible)

Este API estuvo disponible desde 2010 hasta 2011. Cambió el valor devuelto por "none" y añadió la función "bsearch".

use List::MoreUtils ':like_0.24';

Esta etiqueta de importación importará todas las funciones disponibles en la versión 0.24. Sin embargo, "any_u" se importará como "any", "all_u" como "all" y "notall_u" como "notall". También importará "none" como se describe en la documentación (verdadero para lista vacía).

Como la versión 0.33 (segundo cambio incompatible)

Este API estuvo disponible desde 2011 hasta 2014. Es ampliamente utilizado en varios módulos CPAN y por lo tanto es el más cercano al API actual. Cambió los valores devueltos de "any", "all" y "notall". Añadió las funciones "sort_by" y "nsort_by" y el alias "distinct" para "uniq". Omitió "bsearch".

use List::MoreUtils ':like_0.33';

Esta etiqueta de importación importará todas las funciones disponibles en la versión 0.33. Nota: no importará "bsearch" para mantener la consistencia con el API 0.33.

FUNCIONES

Junciones

Tratamiento de una lista vacía

Hay dos escuelas de pensamiento sobre cómo evaluar una junción en una lista vacía:

  • Reducción a una identidad (booleana)
  • El resultado es indefinido (tres valores)

En el primer caso, el resultado de la junción aplicada a una lista vacía se determina por una reducción matemática a una identidad dependiendo de si la comparación subyacente es "o" o "y". Conceptualmente:

                "any are true"      "all are true"
                --------------      --------------
2 elements:     A || B || 0         A && B && 1
1 element:      A || 0              A && 1
0 elements:     0                   1

En el segundo caso, se desea lógica de tres valores, en la cual una junción aplicada a una lista vacía devuelve "undef" en lugar de verdadero o falso.

Las junciones con un sufijo "_u" implementan lógica de tres valores. Las que no tienen sufijo son booleanas.

all BLOCK LIST

all_u BLOCK LIST

Devuelve un valor verdadero si todos los elementos en LIST cumplen la condición dada a través de BLOCK. Asigna $_ a cada elemento en LIST por turnos:

print "All values are non-negative"
  if all { $_ >= 0 } ($x, $y, $z);

Para una LIST vacía, "all" devuelve verdadero (es decir, ningún valor falló la condición) y "all_u" devuelve "undef".

Por lo tanto, all_u(@list) es equivalente a "@list ? all(@list) : undef".

Nota: debido a que Perl considera "undef" como falsa, debes verificar el valor de retorno de "all_u" con "defined" o obtendrás el resultado inverso de lo que esperas.

any BLOCK LIST

any_u BLOCK LIST

Devuelve un valor verdadero si al menos un elemento en LIST cumple la condición dada a través de BLOCK. Asigna $_ a cada elemento en LIST por turnos:

print "At least one non-negative value"
  if any { $_ >= 0 } ($x, $y, $z);

Para una LIST vacía, "any" devuelve falso y "any_u" devuelve "undef".

Por lo tanto, any_u(@list) es equivalente a "@list ? any(@list) : undef".

Nota: debido a que Perl considera "undef" como falsa, debes verificar el valor de retorno de "none_u" con "defined" o obtendrás el resultado inverso de lo que esperas.

none BLOCK LIST

none_u BLOCK LIST

Lógicamente la negación de "any". Devuelve un valor verdadero si ningún elemento en LIST cumple la condición dada a través de BLOCK. Asigna $_ a cada elemento en LIST por turnos:

print "No non-negative values"
  if none { $_ >= 0 } ($x, $y, $z);

Para una LIST vacía, "none" devuelve verdadero (es decir, ningún valor falló la condición) y "none_u" devuelve "undef".

Por lo tanto, none_u(@list) es equivalente a "@list ? none(@list) : undef".

Nota: debido a que Perl considera "undef" como falsa, debes verificar el valor de retorno de "none_u" con "defined" o obtendrás el resultado inverso de lo que esperas.

notall BLOCK LIST

notall_u BLOCK LIST

Lógicamente la negación de "all". Devuelve un valor verdadero si no todos los elementos en LIST cumplen la condición dada a través de BLOCK. Asigna $_ a cada elemento en LIST por turnos:

print "Not all values are non-negative"
  if notall { $_ >= 0 } ($x, $y, $z);

Para una LIST vacía, "notall" devuelve falso (ya que todos los elementos, que son cero, cumplen la condición) y "notall_u" devuelve "undef".

Por lo tanto, notall_u(@list) es equivalente a "@list ? notall(@list) : undef".

Nota: debido a que Perl considera "undef" como falsa, debes verificar el valor de retorno de "notall_u" con "defined" o obtendrás el resultado inverso de lo que esperas.

Busca y encuentra

after $listref,$item

before $listref,$item

Devuelve una referencia a una sublista que contiene todos los elementos después (o antes) de la primera ocurrencia de $item en la lista referenciada por $listref.

Si $item no se encuentra, "after" devuelve una lista vacía y "before" devuelve una lista que contiene todos los elementos.

my @list = qw( a b c d e );
my $href = \@list;
my $sub  = after $href, 'c'; # $sub contendrá ( d e )
my $sub2 = before $href, 'c'; # $sub2 contendrá ( a b )

first_DEPRECATED BLOCK LIST

Devuelve el primer elemento en LIST para el cual BLOCK devuelve un valor verdadero. Si no se encuentra ninguno, devuelve "undef".

Este es un alias para "firstidx" cuando se utiliza como una función de lista.

firstidx BLOCK LIST

Devuelve el índice del primer elemento en LIST para el cual BLOCK devuelve un valor verdadero. Si no se encuentra ninguno, devuelve "-1".

my @list = qw( foo bar baz );
my $idx = firstidx { $_ eq 'bar' } @list; # $idx sera 1

firstup BLOCK LIST

Devuelve el primer elemento de LIST que es mayor que el elemento anterior.

my @nums = (1, 5, 3, 7, 2);
my $first = firstup @nums; # $first sera 5

in_list LIST ITEM

Devuelve verdadero si $item está en la LISTA.

my @list = qw( a b c );
print "Found b" if in_list @list, 'b';

icyclo BLOCK LIST

Devuelve el primer elemento que tiene un valor consistente y repetido.

my @list = qw( a b c c d e );
my $first = cyclop @list; # $first sera c

Mutación de listas

uniq LIST

Devuelve una lista que contiene solo los elementos únicos de la lista dada.

El orden de los elementos en la lista devuelta se conserva de la lista original. El primer elemento de cada conjunto de duplicados se mantiene.

my @list = (1, 2, 1, 3, 2, 4);
my @unique = uniq @list; # @unique sera (1, 2, 3, 4)

insert_after LIST_REF ITEM ITEM_TO_INSERT

insert_before LIST_REF ITEM ITEM_TO_INSERT

Inserta $item_to_insert en la lista referenciada por $list_ref justo después (o antes) de la primera ocurrencia de $item.

Si $item no se encuentra, la lista no se modifica.

my @list = qw( a b c d );
insert_after \@list, 'b', 'X'; # @list ahora es ( a b X c d )
insert_before \@list, 'd', 'Y'; # @list ahora es ( a b X c Y d )

Ordenar y buscar

sort_by BLOCK LIST

nsort_by BLOCK LIST

Devuelve una lista ordenada basada en los valores devueltos por BLOCK para cada elemento.

Ejemplo:

my @array = ( [1, 'z'], [3, 'a'], [2, 'c'] );
my @sorted = sort_by { $a->[0] } @array; # ordenado numéricamente por el primer elemento
# @sorted es ( [1, 'z'], [2, 'c'], [3, 'a'] )
my @sorted_str = nsort_by { $a->[1] } @array; # ordenado alfabéticamente por el segundo elemento
# @sorted_str es ( [3, 'a'], [2, 'c'], [1, 'z'] )

nsort_by es idéntico a sort_by, excepto que nsort_by utiliza la ordenación numérica por defecto.

bsearch LIST ITEM

Utiliza búsqueda binaria para encontrar $item en la LISTA. La LISTA debe estar ordenada.

Si se encuentra $item, devuelve su índice. De lo contrario, devuelve el índice donde se insertaría $item para mantener el orden.

Ejemplo:

my @sorted = (1, 2, 3, 5, 8);
my $idx = bsearch @sorted, 3; # $idx es 2
$idx = bsearch @sorted, 4; # $idx es 3 (el índice donde se insertaría 4)

Varias

count BLOCK LIST

Devuelve el número de elementos en LIST para los cuales BLOCK devuelve un valor verdadero.

my @nums = (1, 5, 3, 7, 2);
my $even_count = count { $_ % 2 == 0 } @nums; # $even_count sera 1 (por el 2)

natorder LIST

Ordena la LISTA de forma natural. Esto significa que las cadenas que contienen números se ordenan de manera más intuitiva. Por ejemplo, "img2.png" vendría antes que "img10.png".

my @files = qw( img1.png img10.png img2.png );
my @sorted_files = natorder @files;
# @sorted_files sera ( img1.png img2.png img10.png )

drop BLOCK LIST

Devuelve una lista que contiene los elementos de LIST para los cuales BLOCK devuelve un valor falso.

my @list = (1, 2, 3, 4, 5);
my @odd = drop { $_ % 2 == 0 } @list; # @odd sera (1, 3, 5)

take BLOCK LIST

Devuelve una lista que contiene los elementos de LIST para los cuales BLOCK devuelve un valor verdadero.

my @list = (1, 2, 3, 4, 5);
my @even = take { $_ % 2 == 0 } @list; # @even sera (2, 4)

pairwise BLOCK LIST1 LIST2 ...

Devuelve una lista de resultados, donde cada resultado es el valor devuelto por BLOCK aplicado a los elementos correspondientes de las listas proporcionadas.

Ejemplo:

my @a = (1, 2, 3);
my @b = (4, 5, 6);
my @c = pairwise { $a+$b } @a, @b; # @c sera (5, 7, 9)

Si las listas tienen longitudes diferentes, la lista resultante tendrá la longitud de la lista más corta.

shuffle LIST

Devuelve una versión aleatoria de la LISTA.

Ejemplo:

my @list = (1, 2, 3, 4, 5);
my @shuffled = shuffle @list; # @shuffled sera una permutación aleatoria de @list

zip LIST1 LIST2 ...

Similar a pairwise, pero devuelve una lista de listas, donde cada sublista contiene los elementos correspondientes de las listas de entrada.

Ejemplo:

my @a = (1, 2, 3);
my @b = (4, 5, 6);
my @zipped = zip @a, @b; # @zipped sera ( [1, 4], [2, 5], [3, 6] )

Si las listas tienen longitudes diferentes, la lista resultante tendrá la longitud de la lista más corta.

"No todos los valores son no negativos" if notall { $_ >= 0 } ($x, $y, $z);

Para una LISTA vacía, "notall" devuelve falso y "notall_u" devuelve "undef".

Por lo tanto, notall_u(@list) es equivalente a "@list ? notall(@list) : undef".

one BLOCK LIST

one_u BLOCK LIST

Devuelve un valor verdadero si precisamente un elemento de LISTA cumple el criterio dado a través de BLOCK. Establece $_ para cada elemento de LISTA en turno:

print "Precisamente un valor definido"
    if one { defined($_) } @list;

Devuelve falso en caso contrario.

Para una LISTA vacía, "one" devuelve falso y "one_u" devuelve "undef".

La expresión "one BLOCK LIST" es casi equivalente a "1 == true BLOCK LIST", excepto por el atajo. La evaluación de BLOCK se detendrá inmediatamente en el segundo valor verdadero.

Transformación

apply BLOCK LIST

Aplica BLOCK a cada elemento de LISTA y devuelve una lista de los valores después de que BLOCK haya sido aplicado. En contexto escalar, se devuelve el último elemento. Esta función es similar a "map" pero no modificará los elementos de la lista de entrada:

my @list = (1 .. 4);
my @mult = apply { $_ *= 2 } @list;
print "@list\n";
print "@mult\n";
__END__
@list = 1 2 3 4
@mult = 2 4 6 8

Piensa en ello como azúcar sintáctico para

for (my @mult = @list) { $_ *= 2 }

insert_after BLOCK VALUE LIST

Inserta VALUE después del primer elemento de LISTA para el cual el criterio en BLOCK es verdadero. Establece $_ para cada elemento de LISTA en turno.

my @list = qw/This is a list/;
insert_after { $_ eq "a" } "longer" => @list;
print "@list";
__END__
This is a longer list

insert_after_string STRING VALUE LIST

Inserta VALUE después del primer elemento de LISTA que es igual a STRING.

my @list = qw/This is a list/;
insert_after_string "a", "longer" => @list;
print "@list";
__END__
This is a longer list

pairwise BLOCK ARRAY1 ARRAY2

Evalúa BLOCK para cada par de elementos en ARRAY1 y ARRAY2 y devuelve una nueva lista que consiste en los valores de retorno de BLOCK. Los dos elementos se establecen en $a y $b. Tenga en cuenta que estos dos son alias del valor original, por lo que cambiarlos modificará las matrices de entrada.

@a = (1 .. 5);
@b = (11 .. 15);
@x = pairwise { $a + $b } @a, @b;     # devuelve 12, 14, 16, 18, 20
# malla con pairwise
@a = qw/a b c/;
@b = qw/1 2 3/;
@x = pairwise { ($a, $b) } @a, @b;    # devuelve a, 1, b, 2, c, 3

mesh ARRAY1 ARRAY2 [ ARRAY3 ... ]

zip ARRAY1 ARRAY2 [ ARRAY3 ... ]

Devuelve una lista que consiste en los primeros elementos de cada matriz, luego el segundo, luego el tercero, etc., hasta que todas las matrices se agoten.

Ejemplos:

@x = qw/a b c d/;
@y = qw/1 2 3 4/;
@z = mesh @x, @y;         # devuelve a, 1, b, 2, c, 3, d, 4
@a = ('x');
@b = ('1', '2');
@c = qw/zip zap zot/;
@d = mesh @a, @b, @c;   # x, 1, zip, undef, 2, zap, undef, undef, zot

"zip" es un alias de "mesh".

zip6

zip_unflatten

Devuelve una lista de matrices que consiste en los primeros elementos de cada matriz, luego el segundo, luego el tercero, etc., hasta que todas las matrices se agoten.

@x = qw/a b c d/;
@y = qw/1 2 3 4/;
@z = zip6 @x, @y;         # devuelve [a, 1], [b, 2], [c, 3], [d, 4]
@a = ('x');
@b = ('1', '2');
@c = qw/zip zap zot/;
@d = zip6 @a, @b, @c;     # [x, 1, zip], [undef, 2, zap], [undef, undef, zot]

"zip_unflatten" es un alias de "zip6".

listcmp ARRAY0 ARRAY1 [ ARRAY2 ... ]

Devuelve una lista asociativa de elementos y cada *id* de la lista en la que se encontró. Permite la implementación fácil de @a & @b, @a | @b, @a ^ @b y así sucesivamente. Las entradas indefinidas en cualquier matriz dada se omiten.

my @a = qw(one two three four five six seven eight nine ten eleven twelve thirteen);
my @b = qw(two three five seven eleven thirteen seventeen);
my @c = qw(one one two three five eight thirteen twentyone);
my %cmp = listcmp @a, @b, @c; # devuelve (one => [0, 2], two => [0, 1, 2], three => [0, 1, 2], four => [0], ...)
my @seq = (1, 2, 3);
my @prim = (undef, 2, 3, 5);
my @fib = (1, 1, 2);
my %cmp = listcmp @seq, @prim, @fib;
# devuelve ( 1 => [0, 2], 2 => [0, 1, 2], 3 => [0, 1], 5 => [1] )

arrayify LIST[,LIST[,LIST...]]

Devuelve una lista que consiste en cada elemento de las matrices dadas. Las matrices recursivas también se aplanan.

@a = (1, [[2], 3], 4, [5], 6, [7], 8, 9);
@l = arrayify @a;         # devuelve 1, 2, 3, 4, 5, 6, 7, 8, 9

uniq LIST

distinct LIST

Devuelve una nueva lista eliminando los valores duplicados en LISTA al comparar los valores como claves de hash, excepto que undef se considera separado de ''. El orden de los elementos en la lista devuelta es el mismo que en LISTA. En contexto escalar, devuelve el número de elementos únicos en LISTA.

my @x = uniq 1, 1, 2, 2, 3, 5, 3, 4; # devuelve 1 2 3 5 4
my $x = uniq 1, 1, 2, 2, 3, 5, 3, 4; # devuelve 5
# devuelve "Mike", "Michael", "Richard", "Rick"
my @n = distinct "Mike", "Michael", "Richard", "Rick", "Michael", "Rick"
# devuelve "A8", "", undef, "A5", "S1"
my @s = distinct "A8", "", undef, "A5", "S1", "A5", "A8"
# devuelve "Giulia", "Giulietta", undef, "", 156, "GTA", "GTV", 159, "Brera", "4C"
my @w = uniq "Giulia", "Giulietta", undef, "", 156, "GTA", "GTV", 159, "Brera", "4C", "Giulietta", "Giulia"

"distinct" es un alias de "uniq".

RT#49800 se puede utilizar para dar comentarios sobre este comportamiento.

singleton LIST

Devuelve una nueva lista eliminando los valores en LISTA que ocurren más de una vez al comparar los valores como claves de hash, excepto que undef se considera separado de ''. El orden de los elementos en la lista devuelta es el mismo que en LISTA. En contexto escalar, devuelve el número de elementos que ocurren solo una vez en LISTA.

my @x = singleton 1,1,2,2,3,4,5 # devuelve 3 4 5

duplicates LIST

Devuelve una nueva lista eliminando los valores en LISTA que ocurren menos de dos veces al comparar los valores como claves de hash, excepto que undef se considera separado de ''. El orden de los elementos en la lista devuelta es el mismo que en LISTA. En contexto escalar, devuelve el número de elementos que ocurren más de una vez en LISTA.

my @y = duplicates 1,1,2,4,7,2,3,4,6,9; #devuelve 1,2,4

frequency LIST

Devuelve una lista asociativa de valores distintos y la frecuencia correspondiente.

my @f = frequency values %radio_nrw; # devuelve (
#  'Deutschlandfunk (DLF)' => 9, 'WDR 3' => 10,
#  'WDR 4' => 11, 'WDR 5' => 14, 'WDR Eins Live' => 14,
#  'Deutschlandradio Kultur' => 8,...)

occurrences LIST

Devuelve una nueva lista de frecuencias y los valores correspondientes de LISTA.

my @o = occurrences ((1) x 3, (2) x 4, (3) x 2, (4) x 7, (5) x 2, (6) x 4);
#  @o = (undef, undef, [3, 5], [1], [2, 6], undef, undef, [4]);

mode LIST

Devuelve el valor modal de LISTA. En contexto escalar, solo se devuelve el valor modal; en contexto de lista, también se devuelven todas las sondas que ocurren un número *modal* de veces.

my @m = mode ((1) x 3, (2) x 4, (3) x 2, (4) x 7, (5) x 2, (6) x 4, (7) x 3, (8) x 7);
#  @m = (7, 4, 8) - LISTA bimodal

slide BLOCK LIST

La función "slide" opera sobre pares de elementos de lista como:

my @s = slide { "$a and $b" } (0..3);
# @s = ("0 and 1", "1 and 2", "2 and 3")

La idea detrás de esta función es una especie de lupa que se mueve a lo largo de una lista y llama a "BLOCK" cada vez que se alcanza el siguiente elemento de la lista.

Particionamiento

after BLOCK LIST

Devuelve una lista de los valores de LISTA después (y sin incluir) el punto en el que BLOCK devuelve un valor verdadero. Establece $_ para cada elemento de LISTA en turno.

@x = after { $_ % 5 == 0 } (1..9);    # devuelve 6, 7, 8, 9

after_incl BLOCK LIST

Igual que "after" pero también incluye el elemento para el cual BLOCK es verdadero.

before BLOCK LIST

Devuelve una lista de valores de LISTA hasta (y sin incluir) el punto en el que BLOCK devuelve un valor verdadero. Establece $_ para cada elemento de LISTA en turno.

before_incl BLOCK LIST

Igual que "before" pero también incluye el elemento para el cual BLOCK es verdadero.

part BLOCK LIST

Particiona LISTA basándose en el valor de retorno de BLOCK, que indica en qué partición se coloca el valor actual.

Devuelve una lista de las particiones creadas de esta manera. Cada partición creada es una referencia a una matriz.

my $i = 0;
my @part = part { $i++ % 2 } 1 .. 8;   # devuelve [1, 3, 5, 7], [2, 4, 6, 8]

También puede tener una lista dispersa de particiones donde las particiones no establecidas serán indefinidas:

my @part = part { 2 } 1 .. 10;            # devuelve undef, undef, [ 1 .. 10 ]

Tenga cuidado con los valores negativos, sin embargo:

my @part = part { -1 } 1 .. 10;
__END__
Se intentó modificar un valor de matriz no creable, subíndice -1 ...

Los valores negativos solo son válidos cuando se refieren a una partición creada previamente:

my @idx  = ( 0, 1, -1 );
my $i    = 0;
my @part = part { $idx[$i++ % 3] } 1 .. 8; # [1, 4, 7], [2, 3, 5, 6, 8]

samples COUNT LIST

Devuelve una nueva lista que contiene COUNT muestras aleatorias de LISTA. Es similar a "shuffle" en List::Util, pero se detiene después de COUNT.

@r  = samples 10, 1..10; # igual que shuffle
@

Iteración

cada_array ARRAY1 ARRAY2 ...

Crea un iterador de arrays para devolver los elementos de la lista de arrays ARRAY1, ARRAY2, ..., en orden. Esto significa que la primera vez que se llame, devuelve el primer elemento de cada array. La siguiente vez, devuelve el segundo elemento, y así sucesivamente hasta que se hayan agotado todos los elementos.

Esto es útil para iterar sobre más de un array al mismo tiempo:

my $ea = cada_array(@a, @b, @c);
while ( my ($a, $b, $c) = $ea->() )   { .... }

El iterador devuelve la lista vacía cuando se llega al final de todos los arrays.

Si se pasa un argumento de '"index"' al iterador, entonces devuelve el índice del último valor obtenido, como un escalar.

cada_arrayref LIST

Similar a cada_array, pero los argumentos son referencias a arrays, no los arrays puros.

natatime EXPR, LIST

Crea un iterador de arrays para iterar sobre un array en bloques de $n elementos a la vez. (n a la vez, ¿lo entiendes?). Un ejemplo puede ser mejor que lo que puedo explicar con palabras.

Ejemplo:

my @x = ('a' .. 'g');
my $it = natatime 3, @x;
while (my @vals = $it->()) {
  print "@vals\n";
}

Esto imprime:

Ordenar

ordena_por BLOCK LIST

Devuelve la lista de valores ordenada según los valores de cadena devueltos por el bloque KEYFUNC o función. Un uso típico podría ser ordenar objetos según el valor de acceso a algún accesor, como:

ordena_por { $_->nombre } @personas

La función clave se llama en contexto escalar, recibiendo cada valor en orden como $_ y el único argumento en los parámetros @_. Los valores se ordenan según comparaciones de cadena de los valores devueltos. Esto es equivalente a:

ordena { $a->nombre cmp $b->nombre } @personas

aunque garantiza que el accesor nombre se ejecute solo una vez por valor. Una aplicación interesante es ordenar strings que puedan tener números incrustados en ellos de forma "natural", en lugar de lexicográficamente.

ordena_por { s/(\d+)/sprintf "%09d", $1/eg; $_ } @strings

Esto ordena strings generando claves de ordenamiento que rellenan con ceros los números incrustados a un nivel (9 dígitos en este caso), ayudando a asegurar que el ordenamiento lexicográfico los coloque en el orden correcto.

nsort_by BLOCK LIST

qsort BLOCK ARRAY

Esto ordena in-place la matriz dada usando el código de comparación dado. Excepto por comparaciones muy pequeñas como "$a <=> $b", qsort es mucho más rápido que el "sort" de Perl dependiendo de la versión.

Comparado 5.8 y 5.26:

my @rl;
for(my $i = 0; $i < 1E6; ++$i) { push @rl, rand(1E5) }
my $idx;
sub ext_cmp { $_[0] <=> $_[1] }
cmpthese( -60, {
    'qsort' => sub {
        my @qrl = @rl;
        qsort { ext_cmp($a, $b) } @qrl;
        $idx = bsearchidx { ext_cmp($_, $rl[0]) } @qrl
    },
    'reverse qsort' => sub {
        my @qrl = @rl;
        qsort { ext_cmp($b, $a) } @qrl;
        $idx = bsearchidx { ext_cmp($rl[0], $_) } @qrl
    },
    'sort' => sub {
        my @srl = @rl;
        @srl = sort { ext_cmp($a, $b) } @srl;
        $idx = bsearchidx { ext_cmp($_, $rl[0]) } @srl
    },
    'reverse sort' => sub {
        my @srl = @rl;
        @srl = sort { ext_cmp($b, $a) } @srl;
        $idx = bsearchidx { ext_cmp($rl[0], $_) } @srl
    },
});
