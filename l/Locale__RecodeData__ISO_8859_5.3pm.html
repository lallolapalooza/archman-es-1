NOMBRE Documentación contribuida por Perl Locale::RecodeData::ISO_8859_5(3)

NOMBRE

Locale::RecodeData::ISO_8859_5 - Rutinas de conversión para ISO-8859-5

SINTAXIS

Este módulo es interno de libintl. No lo uses directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para ISO-8859-5.

COMENTARIOS

Los siguientes comentarios se han extraído del original charmap:

versión: 1.0
 fuente: registro ECMA
 alias: ISO-IR-144
 alias: ISO_8859-5:1988
 alias: ISO_8859-5
 alias: CYRILLIC

Nota: los alias mencionados arriba no necesariamente son válidos!
