NOMBRE

Locale::Po4a::Gemtext - convierte documentos Gemtext desde/hacia archivos PO.

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y lo que es más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::Gemtext es un módulo para ayudar a la traducción de documentos Gemtext a otros idiomas [humanos].

ESTADO DE ESTE MÓDULO

Probado con éxito en archivos Gemtext simples, como la documentación oficial de Gemtext.

VER TAMBIÉN
