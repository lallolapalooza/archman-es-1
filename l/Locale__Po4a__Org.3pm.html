NOMBRE

Locale::Po4a::Org - convierte documentos Org de/a archivos PO.

SINOPSIS

[type:org] /ruta/a/master.org              \
       $lang:/ruta/a/translation.$lang.org \
       opt:"                                \
       --option skip_keywords='             \
           include                          \
           export_file_name                 \
           link'                            \
       --option skip_properties='           \
           copying                          \
           NOBLOCKING                       \
           ORDERED'"

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y, lo que es más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

"Locale::Po4a::Org" es un módulo para ayudar a la traducción de documentación en formato Org, utilizado por el Modo Org https://orgmode.org/.

CONFIGURACIÓN

skip_keywords
Lista de palabras clave separadas por espacios que no serán traducidas.
skip_properties
Lista de propiedades separadas por espacios que no serán traducidas.
skip_heading
Si este es un valor verdadero, omite la traducción de los encabezados. Cuando tu traducción se convierte al formato Texinfo, la traducción de los encabezados puede causar nombres de nodos extraños. Esta opción lo previene.

ESTADO DE ESTE MÓDULO

Este módulo se encuentra en una etapa temprana de desarrollo. Se ha probado con éxito en archivos Org simples, como la Guía Compacta del Modo Org https://orgmode.org/guide/. Sin embargo, no soporta toda la sintaxis de Org https://orgmode.org/worg/org-syntax.html; por ejemplo, las notas al pie y las listas planas anidadas no pueden ser analizadas actualmente.
