NOMBRE

Locale::RecodeData::VISCII - VISCII encoding for Locale::Recode.

SINOPSIS

    use Locale::Recode;

DESCRIPCIÓN

This module provides the VISCII character set encoding for Locale::Recode.

VISCII is an 8-bit character set for the Vietnamese language.
