NAME

Locale::RecodeData::IBM862 - The IBM862 character set

SYNOPSIS

 use Locale::RecodeData::IBM862;

DESCRIPTION

This module provides the character set definitions for IBM862.

IBM862 is an 8-bit character set that was used by IBM for code pages on MS-DOS in Israel.

It's an extension of the ASCII character set and contains Hebrew letters as well as some graphical box drawing characters.

This module is usually loaded automatically by Locale::Recode(3) when needed.

COMMENTS

 =begin comment

This is a character set definition file for the Locale::Recode module.
It is automatically generated from the data in the file
<URL:http://www.unicode.org/Public/MAPPINGS/VENDORS/MICS/IBM/862.TXT>
This file contains the definition for the IBM862 character set.

This character set is also known as "Hebrew".

This character set is a 8-bit character set and maps to/from Unicode.

    Single byte: 0x00 - 0xFF

=end comment
