NOMBRE

Locale::Po4a::LaTeX - convierte documentos LaTeX y derivados desde/hacia archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y lo que es más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::LaTeX es un módulo para ayudar a la traducción de documentos LaTeX a otros idiomas [humanos]. También se puede utilizar como base para crear módulos para documentos basados en LaTeX.

Este módulo contiene las definiciones de comandos y entornos LaTeX comunes.

Consulte la página del manual de Locale::Po4a::TeX(3pm) para ver la lista de opciones reconocidas.

VER TAMBIÉN
