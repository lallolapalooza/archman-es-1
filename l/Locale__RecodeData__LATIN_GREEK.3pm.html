NAME

Locale::RecodeData::LATIN_GREEK - Rutinas de conversión para LATIN_GREEK

SYNOPSIS

Este módulo es interno en libintl. ¡No lo use directamente!

DESCRIPTION

Este módulo contiene las tablas de conversión y rutinas para LATIN_GREEK.

COMMENTS

Las siguientes observaciones se han extraído del original charmap:

versión: 1.0
 fuente: ECMA registro
 alias ISO-IR-19

Nota: ¡los alias mencionados anteriormente no necesariamente son válidos!
