NOMBRE

Lire::Test::DlfAnalyserTestCase - Clase base para escribir pruebas unitarias de DlfAnalyser

SINOPSIS

use base qw/ Lire::Test::DlfAnalyserTestCase /;
use MyAnalyser;
use File::Basename;
sub create_analyser {
  return new MyAnalyser();
}
sub schemasdir {
  return dirname( __FILE__ ) .  "../..";
}
sub registration_file {
  return dirname( __FILE__ ) .  "../../myanalyser_init";
}

DESCRIPCIÓN

Esta es una subclase de Test::Unit::TestCase que puede usarse para escribir fácilmente pruebas para DlfAnalyser. Esta clase implementa lo necesario para proporcionar el fixture necesario en set_up() y tear_down().

Proporciona dos pruebas base: test_api() y test_registration_file().

La clase de prueba necesita implementar tres métodos para ayudar a completar el fixture.

FIXTURES

Estos son los métodos que las subclases normalmente anularán para proporcionar los datos necesarios para que se configuren los fixtures de prueba de DlfAnalyser.

registration_file()

Debe devolver el script responsable de registrar el analizador con el Lire::PluginManager. Esto es utilizado por el test_registration_file() por defecto.

schemasdir()

Este método debe devolver el directorio que contiene los esquemas utilizados por el analizador. Esto se añadirá a la variable de configuración lr_schemas_path.

create_analyser()

Debe devolver una instancia del Lire::DlfAnalyser que se va a probar.

Proceso Mock de Conversión

create_mock_process( [ $store ])

Este método devolverá un MockDlfAnalyserProcess que puede ser utilizado para ayudar a probar DlfAnalyser. Todos los valores para write_dlf() y error() se guardan y se pueden consultar a través de los métodos dlf() y errors(). Tenga en cuenta que el método dlf() devuelve una referencia a un array de referencias a arrays. El primer elemento de los arrays internos es el DLF y los otros elementos son el ID de DLF relacionado, si lo hay.

El método mock analyser_instance() devuelve el DlfAnalyser creado por create_analyser() y asociado a su instancia.

El parámetro opcional $store debe ser una instancia de Lire::DlfStore que estará disponible a través del método dlf_store().

PRUEBAS POR DEFECTO

test_api()

Asegura que todos los métodos requeridos por Lire::DlfAnalyser estén implementados. También comprueba que src_schema() y dst_schema() estén disponibles.

Comprueba que description() se formatea correctamente como DocBook.

test_registration_file()

Comprueba que el script de registro registra correctamente el analizador con el PluginManager.

VER TAMBIÉN

Lire::Test::TestCase(3pm), Lire::DlfAnalyser(3pm)
