NOMBRE

Lire::ReportSection - API para reportar la sección de configuración

SINOPSIS

use Lire::ReportConfig;
use Lire::ReportSection;
my $report_cfg = new Lire::ReportConfig( "www" );
my $section = new Lire::ReportSection( "www", "General" );
$report_cfg->add_section( $section );

DESCRIPCIÓN

Esta clase ofrece una API orientada a objetos para reportar la sección de configuración. Ofrece métodos para acceder y modificar los atributos de la sección.

CONSTRUCTOR

new( $superservicio, [$título] )

Crea un nuevo objeto Lire::Section que contendrá las especificaciones de reporte del super-servicio $superservicio. El título de la sección se establecerá al valor de $título.

MÉTODOS DE OBJETO

superservice()

Devuelve el super-servicio de esta sección.

título([$título])

Devuelve el título actual de la sección.

Cuando se usa el parámetro $título, se establecerá el título de la sección a un nuevo valor.

filtros()

Devuelve las especificaciones de filtro de esta sección como un array de objetos Lire::FilterSpec. Esas especificaciones de filtro serán usadas por todas las especificaciones de reporte de esta sección, además de la especificación de filtro que ya puedan estar usando.

agregar_filtro($espec_filtro)

Añade la especificación de filtro $espec_filtro a la lista de esta sección. El parámetro $espec_filtro debe ser una instancia de Lire::FilterSpec o una de sus descendientes.

Este método fallará si el esquema de la especificación de filtro no es compatible con el super-servicio de esta sección.

reportes()

Devuelve las especificaciones de reporte de esta sección como un array de objetos Lire::ReportSpec.

agregar_reporte( $espec_reporte )

Añade la especificación de reporte $espec_reporte a esta sección. Este método fallará si el esquema de la especificación de reporte no es compatible con el super-servicio de esta sección.

VER TAMBIÉN

Lire::ReportConfig(3pm), Lire::ReportSpec(3pm), Lire::FilterSpec(3pm)
Lire::Report::Section(3pm), Lire::Config::ReportSectionSpec(3pm)
