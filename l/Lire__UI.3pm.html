UI(3pm) Documentación de Lire de LogReport UI(3pm)

NOMBRE

Lire::UI - Interfaz con un almacén DLF

SINOPSIS

use Lire::Config;
use Lire::UI;
use Lire::PluginManager;
Lire::Config->init();
Lire::PluginManager->register_default_plugins();
my $ui = Lire::UI->new();
$ui->curses_ui()->clear_on_exit( 1 );
exit( $ui->mainloop() );

DESCRIPCIÓN

El objeto Lire::UI crea una aplicación Curses::UI.

curses_ui()

Devuelve el objeto Curses::UI utilizado para la interfaz.

edit_value_dialog( $value, [$title] )

Abre un diálogo modal que puede editar el Lire::Config::Value $value. El diálogo tiene un botón OK y Cancelar y contiene un Lire::UI::Widget apropiado para el tipo $value. El método devuelve verdadero cuando se seleccionó el botón OK, de lo contrario devuelve falso.

VER TAMBIÉN

lire(1), Curses::UI(3pm)
