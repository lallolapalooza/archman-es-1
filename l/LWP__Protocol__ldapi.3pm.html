LWP::Protocol::ldapi(3) Documentación de Perl contribuida por el usuario LWP::Protocol::ldapi(3)

NOMBRE

LWP::Protocol::ldapi - Proporcionar soporte LDAPI para LWP::UserAgent

SINOPSIS

use LWP::UserAgent;
use MIME::Base64;
$ua = LWP::UserAgent->new();
$res = $ua->get('ldapi:///' .
                'o=University%20of%20Michigan,c=US??sub?(cn=Babs%20Jensen)',
                Authorization => 'Basic '.encode_Base64('cn=John Doe:secret')):

DESCRIPCIÓN

El módulo LWP::Protocol::ldapi proporciona soporte para el uso de URLs con esquema ldapi con LWP. Este módulo es un plugin para el manejo de protocolos de LWP, por lo que no se usa directamente.

VER TAMBIÉN

LWP::Protocol::ldap, LWP::Protocol::ldaps
