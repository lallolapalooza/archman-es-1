NOMBRE

List::Util::XS — Indica si List::Util se compiló con un compilador C

SINOPSIS

use List::Util::XS 1.20;

DESCRIPCIÓN

"List::Util::XS" se puede usar como dependencia para asegurar que List::Util se instaló usando un compilador C y que la versión XS está instalada.

Durante la instalación, $List::Util::XS::VERSION se establecerá en "undef" si la versión XS no se compiló.

A partir de la versión 1.23_03, Scalar-List-Util utiliza **siempre** la implementación XS, pero por compatibilidad hacia atrás, seguimos distribuyendo el módulo "List::Util::XS" que simplemente carga "List::Util".

VER TAMBIÉN

Scalar::Util, List::Util, List::MoreUtils
