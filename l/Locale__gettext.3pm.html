NOMBRE

Locale::gettext - funciones de manejo de mensajes

SINOPSIS

use Locale::gettext;
use POSIX;     # Necesario para setlocale()
setlocale(LC_MESSAGES, "");
# Interfaz OO
my $d = Locale::gettext->domain("mi_programa");
print $d->get("Bienvenido a mi programa"), "\n";
        # (impreso en el idioma local)
# Acceso directo a funciones C
textdomain("mi_programa");
print gettext("Bienvenido a mi programa"), "\n";
        # (impreso en el idioma local)

DESCRIPCIÓN

El módulo gettext permite el acceso desde perl a la familia de funciones gettext() para obtener cadenas de mensajes de bases de datos construidas para internacionalizar software.

$d = Locale::gettext->domain(DOMINIO)
$d = Locale::gettext->domain_raw(DOMINIO)
Crea un nuevo objeto para obtener cadenas en el dominio DOMINIO y lo devuelve. "domain" solicita que las cadenas se devuelvan como cadenas de Perl (posiblemente con caracteres amplios) si es posible, mientras que "domain_raw" solicita cadenas de octetos directamente de funciones como dgettext().
$d->get(MSGID)
Llama a dgettext() para devolver la cadena traducida para el MSGID dado.
$d->cget(MSGID, CATEGORÍA)
Llama a dcgettext() para devolver la cadena traducida para el MSGID dado en la CATEGORÍA dada.
$d->nget(MSGID, MSGID_PLURAL, N)
Llama a dngettext() para devolver la cadena traducida para el MSGID o MSGID_PLURAL dado, dependiendo de N.
$d->ncget(MSGID, MSGID_PLURAL, N, CATEGORÍA)
Llama a dngettext() para devolver la cadena traducida para el MSGID o MSGID_PLURAL dado, dependiendo de N, en la CATEGORÍA dada.
$d->dir([NUEVODIR])
Si se proporciona NUEVODIR, llama a "bindtextdomain" para establecer el nombre del directorio donde se encuentran los mensajes para el dominio representado por $d. Devuelve el nombre del directorio actual (posiblemente cambiado).
$d->codeset([NUEVOCódigo])
Para instancias creadas con "Locale::gettext->domain_raw", manipula el conjunto de caracteres de las cadenas devueltas. Si se proporciona NUEVOCódigo, llama a "bind_textdomain_codeset" para establecer la codificación de caracteres en la que se devuelven los mensajes para el dominio representado por $d. Devuelve el nombre de la codificación actual (posiblemente cambiado).

gettext(), dgettext() y dcgettext() intentan recuperar una cadena que coincida con su parámetro "msgid" dentro del contexto de la configuración regional actual. dcgettext() toma la categoría del mensaje y el dominio de texto como parámetros, mientras que dgettext() utiliza por defecto la categoría LC_MESSAGES y gettext() utiliza por defecto LC_MESSAGES y el dominio de texto actual. Si la cadena no se encuentra en la base de datos, se devuelve "msgid".

ngettext(), dngettext() y dcngettext() funcionan de manera similar pero implementan la diferenciación de mensajes entre singular y plural. Consulte la documentación de las funciones C correspondientes para obtener más detalles.

textdomain() establece el dominio de texto actual y devuelve el dominio activo anteriormente.

bindtextdomain(dominio, nombre_directorio) instruye a las funciones de recuperación para que busquen las bases de datos que pertenecen al dominio "dominio" en el directorio "nombre_directorio".

bind_textdomain_codeset(dominio, código_caracteres) instruye a las funciones de recuperación para que traduzcan los mensajes devueltos a la codificación de caracteres dada por código_caracteres si se conoce la codificación del catálogo de mensajes.

NOTAS

No todas las plataformas proporcionan todas las funciones. Las funciones que no están disponibles en la biblioteca C subyacente tampoco estarán disponibles en Perl.

Los programas Perl deben utilizar la interfaz de objetos. Además de poder devolver cadenas de caracteres amplios nativas de Perl, "bind_textdomain_codeset" se emulará si la biblioteca C no lo proporciona.
