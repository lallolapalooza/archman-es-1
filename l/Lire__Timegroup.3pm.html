NOMBRE

Lire::Timegroup - Clase base para la implementación del agregador de grupos de tiempo

SINOPSIS

use Lire::Timegroup;

DESCRIPCIÓN

Este módulo es la clase base para la implementación del agregador de grupos de tiempo. Este agregador dividirá los registros DLF basándose en un período de tiempo controlado por el atributo `period`. Por ejemplo, usando `1d` como valor del período, este agregador agrupará todos los registros del mismo período de día juntos.

CONSTRUCTOR

new( %parámetros )

Crea una nueva instancia de un agregador de grupos de tiempo. Además de los parámetros normales del operador de informe, el agregador de grupos de tiempo puede aceptar varios parámetros:

campo
Este parámetro opcional contiene el campo DLF que contiene el valor de tiempo utilizado para agrupar los registros DLF. Consulte el método campo() para obtener más información.
periodo
Este parámetro obligatorio debe contener la duración del período que se utilizará para agrupar los registros. Consulte el método periodo() para obtener más información.

MÉTODOS

campo( [$nuevo_campo] )

Devuelve el nombre del campo DLF que se utiliza para agrupar los registros DLF. Debe ser un campo DLF de marca de tiempo válido en el esquema actual. Por defecto, se utiliza el campo de marca de tiempo predeterminado del esquema DLF.

Puede cambiar el campo pasando un parámetro $nuevo_campo.

periodo( [$nuevo_periodo])

Devuelve la duración del período en el que se agrupan los registros. Puede ser un valor de duración o el nombre de un parámetro de especificación de informe que contenga un valor de duración.

La duración del período se puede cambiar utilizando el parámetro $nuevo_periodo.
