NOMBRE

Locale::Po4a::Text - convertir documentos de texto desde/hacia archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y más interesante aún, el mantenimiento de las traducciones) usando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::Text es un módulo para ayudar a la traducción de documentos de texto a otros idiomas [humanos].

Los párrafos se dividen en líneas vacías (o líneas que solo contienen espacios o tabulaciones).

Si un párrafo contiene una línea que comienza con un espacio (o tabulación), este párrafo no se ajustará.

OPCIONES ACEPTADAS POR ESTE MÓDULO

Estas son las opciones particulares de este módulo:

clavevalor
Tratar los párrafos que se parecen a pares clave-valor separados por dos puntos como literales (con la bandera "no-wrap" en el archivo PO). Una cadena de par clave-valor es una cadena como "clave: valor", que contiene uno o más caracteres que no son dos puntos ni espacios, seguidos de dos puntos, seguidos de al menos un carácter que no sea un espacio antes del final de la línea.
nobullets
Desactivar la detección de viñetas.

Por defecto, cuando se detecta una viñeta, el párrafo de la viñeta no se considera un párrafo literal (con la bandera "no-wrap" en el archivo PO). En cambio, el párrafo correspondiente se ajustará en la traducción.

tabulaciones=modo
Especificar cómo se deben manejar las tabulaciones. El modo puede ser cualquiera de:
dividir
Las líneas con tabulaciones introducen saltos en el párrafo actual.
literal
Los párrafos que contienen tabulaciones no se ajustarán.

Por defecto, las tabulaciones se consideran como espacios.

saltos=regex
Una expresión regular que coincide con líneas que introducen saltos. La expresión regular se anclará para que coincida toda la línea.
debianchangelog
Manejar el encabezado y pie de página de las versiones publicadas, que solo contienen información no traducible.
fortunes
Manejar el formato de fortunes, que separa las fortunes con una línea que consiste en '%' o '%%', y usa '%%' como el inicio de un comentario.
markdown
Manejar marcados especiales en textos formateados en Markdown.
yfm_keys (solo markdown)
Lista separada por comas de claves a procesar para traducción en la sección YAML Front Matter. Todas las demás claves se omiten. Las claves coinciden con una comparación sensible a mayúsculas y minúsculas. Si se usan yfm_paths y yfm_keys juntos, los valores se incluyen si coinciden con al menos una de las opciones. Los valores de tipo array siempre se traducen, a menos que se proporcione la opción yfm_skip_array.
yfm_lenient (solo markdown)
Permitir que el analizador de YAML Front Matter falle en encabezados mal formados. Esto es particularmente útil cuando tu archivo comienza con una regla horizontal en lugar de un YAML Front Matter, pero insistes en usar solo tres guiones para tu regla.
yfm_paths (solo markdown)
yfm_paths
Lista separada por comas de rutas de hash a procesar para la extracción en la sección YAML Front Matter, todas las demás rutas se omiten. Las rutas coinciden con una comparación sensible a mayúsculas y minúsculas. Si se usan yfm_paths y yfm_keys juntos, los valores se incluyen si coinciden con al menos una de las opciones. Los valores de tipo array siempre se devuelven a menos que se proporcione la opción yfm_skip_array.
yfm_skip_array (solo markdown)
No traducir valores de array en la sección YAML Front Matter.
control[=lista_campos]
Manejar archivos de control de Debian. Se puede proporcionar una lista separada por comas de campos a traducir.
neverwrap
Evitar que po4a ajuste las líneas. Esto significa que todo el contenido se trata literalmente, incluso los párrafos simples.

ESTADO DE ESTE MÓDULO

Probado con éxito en archivos de texto simples y archivos NEWS.Debian.
