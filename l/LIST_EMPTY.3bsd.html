DESCRIPTION

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas (Listas doblemente enlazadas)
  2. Listas enlazadas simples (Singly-linked lists)
  3. Colas de cola enlazadas simples (Singly-linked tail queues)
  4. Colas de cola (Tail queues - doblemente enlazadas)
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada en la cabeza de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento en la lista.
  3. Eliminación en O(1) de una entrada de la cabeza de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO (Last-In, First-Out). Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier entrada en la lista.
  2. Concatenación en O(n) de dos listas.

Las colas de cola enlazadas simples añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Eliminación en O(n) de cualquier entrada en la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lentas que las listas enlazadas simples.

Las colas de cola enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO (First-In, First-Out).

Todos los tipos de estructuras de datos doblemente enlazadas (listas y colas de cola) permiten adicionalmente:

  1. Inserción de una nueva entrada antes de cualquier elemento en la lista.
  2. Eliminación en O(1) de cualquier entrada en la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos doblemente enlazadas. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar una entrada para comenzar el recorrido y la lista en la que está contenida.

Las colas de cola añaden la siguiente funcionalidad:

  1. Las entradas se pueden añadir al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de lista deben especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lentas que las listas enlazadas simples.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que sea de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que sea de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse utilizando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Consulte los ejemplos a continuación para obtener más explicaciones sobre cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación en O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista puede declararse posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe utilizar una cola de cola enlazada simple si esta macro es necesaria en rutas de código de alto uso o para operar sobre listas largas.

La macro SLIST_EMPTY se evalúa como verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH() aquí está permitido tanto eliminar var como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en el SLIST referenciado por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

	...

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación desde el principio. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido hacia adelante seguro. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();

COLAS DE LISTA ENLAZADA SIMPLE CON COLA

Una cola de lista enlazada simple se encabeza mediante una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos se enlazan en simple para minimizar el uso de espacio y la manipulación de punteros, a costa de una complejidad de O(n) para la eliminación de elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro STAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola head.

La macro STAILQ_CONCAT concatena la cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola.

La macro STAILQ_FIRST devuelve el primer elemento de la cola o NULL si la cola está vacía.

La macro STAILQ_FOREACH recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola. Si la cola está vacía, el valor devuelto es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento que sigue a elm de la cola. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola.

La macro STAILQ_REMOVE_HEAD elimina el elemento de la cabeza de la cola. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la cola deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe usar una cola doblemente enlazada si esta macro es necesaria en rutas de código de uso intensivo o para operar en colas largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

	...
	STAILQ_ENTRY(entry) entries;	/* Cola de lista. */
	...

STAILQ_INSERT_AFTER(&head, n1, n2, entries);

free(n2);

STAILQ_REMOVE_HEAD(&head, entries);
free(n3);

	np-> ...
					/* Recorrido hacia adelante seguro. */

	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}

LISTAS

Una lista se encabeza mediante una estructura definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos se enlazan doblemente para que se pueda eliminar un elemento arbitrario sin recorrer la lista. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro LIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe usar una cola de lista si esta macro es necesaria en rutas de código de uso intensivo o para operar en listas largas.

La macro LIST_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var.

La macro LIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de LIST_FOREACH() aquí está permitido tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro LIST_FOREACH_FROM_SAFE se comporta idénticamente a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento de LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LIST referenciada por head.

La macro LIST_INIT inicializa la lista referenciada por head.

La macro LIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro LIST_NEXT devuelve el siguiente elemento en la lista, o NULL si este es el último.

La macro LIST_PREV devuelve el elemento anterior en la lista, o NULL si este es el primero. La lista head debe contener el elemento elm.

La macro LIST_REMOVE elimina el elemento elm de la lista.

La macro LIST_SWAP intercambia el contenido de head1 y head2.

COLAS DE COLA

Una cola de cola se encabeza con una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento en la cola de cola y el otro al último elemento en la cola de cola. Los elementos están doblemente enlazados para que un elemento arbitrario pueda eliminarse sin recorrer la cola de cola. Los nuevos elementos pueden agregarse a la cola de cola después de un elemento existente, antes de un elemento existente, al principio de la cola de cola o al final de la cola de cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a enlazar en la cola de cola. Un puntero a la cabecera de la cola de cola se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola de cola head.

La macro TAILQ_CONCAT concatena la cola de cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro TAILQ_EMPTY se evalúa como verdadera si no hay elementos en la cola de cola.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos en la cola de cola.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

La macro TAILQ_FOREACH recorre la cola de cola referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. var se establece a NULL si el bucle se completa normalmente, o si no hubo elementos.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de cola referenciada por head en la dirección inversa, asignando cada elemento en turno a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta idénticamente a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referenciada por head en la dirección hacia adelante o inversa respectivamente, asignando cada elemento en turno a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE hacen posible tanto eliminar var como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario trata a var como un elemento de TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

La macro TAILQ_INIT inicializa la cola de cola referenciada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de cola.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de cola.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de cola. Si la cola de cola está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento en la cola de cola, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior en la cola de cola, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de cola.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

DIAGNÓSTICOS


Al depurar queue(3), puede ser útil rastrear los cambios en la cola. Para habilitar el rastreo, defina el macro QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.


También puede ser útil desechar punteros que han sido desvinculados de una cola, para detectar el uso después de la eliminación. Para habilitar el desechar de punteros, defina el macro QUEUE_MACRO_DEBUG_TRASH en tiempo de compilación. El macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido desechado por la opción QUEUE_MACRO_DEBUG_TRASH.
