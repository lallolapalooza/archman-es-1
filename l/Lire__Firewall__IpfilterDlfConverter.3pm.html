NOMBRE

Lire::Firewall::IpfilterDlfConverter - convierte logs de ipf (ipmon) a formato DLF de firewall

DESCRIPCION

Lire::Firewall::IpfilterDlfConverter convierte logs de Ipfilter al formato DLF de firewall. La entrada para este conversor es el archivo de log syslog estándar de ipf producido por ipmon. IP Filter se incluye con FreeBSD, OpenBSD (hasta la versión 2.9) y algunos otros sistemas operativos.
