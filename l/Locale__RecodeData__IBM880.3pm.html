Locale::RecodeData::IBM880 - Rutinas de conversión para IBM880

SINOPSIS

Este módulo es interno de libintl. ¡No lo use directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para IBM880.

COMENTARIOS

Las siguientes observaciones se han extraído del charmap original:

versión: 1.0
fuente: IBM NLS RM Vol2 SE09-8002-01, Marzo 1990
alias CP880
alias EBCDIC-CYRILLIC

¡Por favor, tenga en cuenta que los alias mencionados anteriormente no son necesariamente válidos!

Locale::RecodeData::IBM880(3pm)

NAME

Locale::RecodeData::IBM880 - Code converter for IBM code page 880.

SYNOPSIS

 use Locale::RecodeData::IBM880;

DESCRIPTION

This module provides a code converter for IBM code page 880, which is an extension of the ISO 8859-1 (Latin-1) code page. It is intended for use with the Locale::Recode module.
