NOMBRE

Locale::RecodeData::MACTHAI - Rutinas de conversión para MACTHAI

SINOPSIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas y rutinas de conversión para MACTHAI.
