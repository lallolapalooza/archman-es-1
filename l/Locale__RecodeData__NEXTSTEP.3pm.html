NAME

Locale::RecodeData::NEXTSTEP - NEXTSTEP, Sun Microsystems, and HP encoding definitions

SYNOPSIS 

use Locale::RecodeData qw( :nextstep :sun :hp );

DESCRIPTION

This module provides definitions of the NEXTSTEP, Sun Microsystems, and HP character encodings.

These definitions are used internally by the Locale::Recode module.

The following constants are exported:

:nextstep
Exports constants that define the NEXTSTEP encoding.
:sun
Exports constants that define the Sun Microsystems encoding (same as NEXTSTEP).
:hp
Exports constants that define the HP encoding (same as NEXTSTEP).

COMMENTS

The NEXTSTEP encoding is based on ISO-8859-1. The differences are in the character codes above 0xA0.
