DlfCategoriser(3pm) Documentación de Lire de LogReport DlfCategoriser(3pm)

NOMBRE

Lire::DlfCategoriser - Clase base para analizadores que producen registros DLF extendidos.

SINOPSIS

use base qw/ Lire::DlfCategoriser /;
sub categorise {
  my ( $self, $dlf ) = @_;
  # Añade el campo extendido a DLF.
  return;
}

DESCRIPCIÓN

Este paquete define una clase base que puede ser utilizada para Lire::DlfAnalyser que escribe en un ExtendedSchema. El categorizador solo necesita implementar el método categorise() en lugar del más genérico analyse().

MÉTODOS DE INFORMACIÓN META

El Lire::DlfCategoriser debe implementar los mismos métodos de información meta que el Lire::DlfAnalyser (name(), src_schema(), dst_schema(), title(), description()).

MÉTODOS DE IMPLEMENTACIÓN

El categorizador realiza su trabajo utilizando los métodos initialise() y categorise().

analyse( $process, $config )

El Lire::DlfCategoriser implementa el método analyse(). Ejecutará la consulta en el src_schema() utilizando el filtro correcto y llamará a categorise() en cada DLF devuelto. Los campos extendidos se escribirán luego en dst_schema(). Los errores deben ser reportados muriendo (dying).

initialise( $config )

Este método se llama antes de que se llame al método categorise().

El parámetro $config contiene datos de configuración que se especificaron en el AnalysisJob para ese analizador. Para registrar la especificación de configuración para tu DlfCategoriser, solo necesitas definir una especificación de configuración bajo el nombre analyser_name_properties. Esto debería ser un RecordSpec o un ObjectSpec.

categorise( $dlf )

Se llama una vez por cada registro DLF que debe ser categorizado. El categorizador debe añadir los campos extendidos directamente a la referencia del hash $dlf.

finalise( $config )

Este método se llama después de que todos los registros DLF hayan sido categorizados.

El parámetro $config contiene datos de configuración que se especificaron en el AnalysisJob para ese analizador. Para registrar la especificación de configuración para tu DlfCategoriser, solo necesitas definir una especificación de configuración bajo el nombre analyser_name_properties. Esto debería ser un RecordSpec o un ObjectSpec.

La implementación predeterminada no hace nada.
