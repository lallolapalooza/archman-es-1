NOMBRE

Lire::OutputFormat - Interfaz base para todos los OutputFormat.

SINOPSIS

use base qw/ Lire::OutputFormat /;

DESCRIPCIÓN

Los objetos Lire::OutputFormat se utilizan para

Este paquete define la interfaz que implementan los diferentes OutputFormat que Lire es capaz de producir. Es este objeto el que tiene la responsabilidad de convertir el informe XML a su formato final.

MÉTODOS DE INFORMACIÓN META

La interfaz Lire::OutputFormat extiende la interfaz Lire::Plugin, por lo que deben implementar todos los métodos de metainformación estándar (name(), title(), description()).

missing_requirements()

Este método se consulta en tiempo de ejecución para determinar si falta algún requisito. Debe devolver una matriz de mensajes explicando cada requisito faltante para el formato.

FORMATEANDO UN INFORME

format_report( $xml_file, $output_file, $format_cfg )

Este método debe formatear el informe XML contenido en $xml_file en el $output_file (o directorio). Las opciones de configuración adicionales se pasan en el objeto Lire::Config::TypeSpec $format_cfg específico del plugin.

mime_report( $xml_file, $format_cfg )

Cuando se invoca este método, el plugin debe formatear el informe contenido en $xml_file y encapsularlo MIME en un objeto MIME::Entity que se devuelve. Las opciones de formato pueden estar en el objeto Lire::Config::TypeSpec $format_cfg.
