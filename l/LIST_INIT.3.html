LIST(3) Manual de Funciones de Librería LIST(3)

NOMBRE

LIST_EMPTY, LIST_ENTRY, LIST_FIRST, LIST_FOREACH, LIST_HEAD, LIST_HEAD_INITIALIZER, LIST_INIT, LIST_INSERT_AFTER, LIST_INSERT_BEFORE, LIST_INSERT_HEAD, LIST_NEXT, LIST_REMOVE - implementación de una lista doblemente enlazada

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
LIST_ENTRY(TYPE);
LIST_HEAD(HEADNAME, TYPE);
LIST_HEAD LIST_HEAD_INITIALIZER(LIST_HEAD head);
void LIST_INIT(LIST_HEAD *head);
int LIST_EMPTY(LIST_HEAD *head);
void LIST_INSERT_HEAD(LIST_HEAD *head,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_BEFORE(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_AFTER(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
struct TYPE *LIST_FIRST(LIST_HEAD *head);
struct TYPE *LIST_NEXT(struct TYPE *elm, LIST_ENTRY NAME);
LIST_FOREACH(struct TYPE *var, LIST_HEAD *head, LIST_ENTRY NAME);
void LIST_REMOVE(struct TYPE *elm, LIST_ENTRY NAME);

DESCRIPCIÓN

Estas macros definen y operan sobre listas doblemente enlazadas.

En las definiciones de las macros, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo LIST_ENTRY, llamado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando la macro LIST_HEAD().

Creación

Una lista está encabezada por una estructura definida por la macro LIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la lista. Se pueden añadir nuevos elementos a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:


LIST_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura que se va a definir, y struct TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista se puede declarar posteriormente como:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

LIST_ENTRY() declara una estructura que conecta los elementos de la lista.

LIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista head.

LIST_INIT() inicializa la lista referenciada por head.

LIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

LIST_INSERT_HEAD() inserta el nuevo elemento elm al principio de la lista.

LIST_INSERT_BEFORE() inserta el nuevo elemento elm antes del elemento listelm.

LIST_INSERT_AFTER() inserta el nuevo elemento elm después del elemento listelm.

Recorrido

LIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

LIST_NEXT() devuelve el siguiente elemento de la lista, o NULL si es el último.

LIST_FOREACH() recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var.

Eliminación

LIST_REMOVE() elimina el elemento elm de la lista.

VALOR DE RETORNO

LIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

LIST_FIRST() y LIST_NEXT() devuelven un puntero a la estructura TYPE primera o siguiente, respectivamente.

LIST_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la lista head.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ERRORES

LIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. LIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    LIST_ENTRY(entry) entries;              /* Lista */
};
LIST_HEAD(listhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct listhead head;                   /* Cabeza de la lista */
    int i;
    LIST_INIT(&head);                       /* Inicializar la lista */
    n1 = malloc(sizeof(struct entry));      /* Insertar al principio */
    LIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    LIST_INSERT_AFTER(n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    LIST_INSERT_BEFORE(n2, n3, entries);
    i = 0;                                  /* Recorrido hacia adelante */
    LIST_FOREACH(np, &head, entries)
        np->data = i++;
    LIST_REMOVE(n2, entries);               /* Borrado */
    free(n2);
                                            /* Recorrido hacia adelante */
    LIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Borrado de la lista */
    n1 = LIST_FIRST(&head);
    while (n1 != NULL) {
        n2 = LIST_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    LIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
