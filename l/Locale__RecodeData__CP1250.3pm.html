Locale::RecodeData::CP1250 - Rutas de conversión para CP1250

SINTAXIS

Esta sección es interna a libintl. ¡No la use directamente!

DESCRIPCIÓN

Esta sección contiene las tablas de conversión y rutinas para CP1250.

COMENTARIOS

Los siguientes comentarios se han extraído de la charmap original:

version: 1.0
repertoiremap: mnemonic,ds
 source: UNICODE 1.0
alias MS-EE

Nota: ¡Los alias mencionados anteriormente no son necesariamente válidos!

NOMBRE

Locale::RecodeData

SINTAXIS

use Locale::RecodeData;

DESCRIPCIÓN

Locale::RecodeData es un módulo que contiene datos para la conversión de caracteres en sistemas locales.

COMENTARIOS

Este módulo está diseñado para manejar la conversión de caracteres entre diferentes codificaciones locales.
