LWP::Simple(3) Documentación de Perl aportada por el usuario LWP::Simple(3)

NOMBRE

LWP::Simple - interfaz procedural simple para LWP

SINOPSIS

perl -MLWP::Simple -e 'getprint "http://www.sn.no"'
use LWP::Simple;
$content = get("http://www.sn.no/");
die "¡No pude obtenerlo!" unless defined $content;
if (mirror("http://www.sn.no/", "foo") == RC_NOT_MODIFIED) {
    ...
}
if (is_success(getprint("http://www.sn.no/"))) {
    ...
}

DESCRIPCIÓN

Este módulo está destinado a personas que desean una vista simplificada de la biblioteca libwww-perl. También debería ser adecuado para líneas de comandos de un solo uso. Si necesita más control o acceso a los campos de encabezado en las solicitudes enviadas y las respuestas recibidas, entonces debería usar la interfaz orientada a objetos completa proporcionada por el módulo LWP::UserAgent.

El módulo también exportará el objeto LWP::UserAgent como $ua si lo solicita explícitamente.

El agente de usuario creado por este módulo se identificará como "LWP::Simple/#.##" e inicializará sus valores predeterminados de proxy a partir del entorno (llamando "$ua->env_proxy").

FUNCIONES

Las siguientes funciones son proporcionadas (y exportadas) por este módulo:

get

my $res = get($url);

La función get() obtendrá el documento identificado por la URL dada y lo devolverá. Devuelve "undef" si falla. El argumento $url puede ser una cadena o una referencia a un objeto URI.

No podrá examinar el código de respuesta ni los encabezados de respuesta (como "Content-Type") cuando acceda a la web utilizando esta función. Si necesita esa información, debería utilizar la interfaz OO completa (ver LWP::UserAgent).

head

my $res = head($url);

Obtiene los encabezados del documento. Devuelve los siguientes 5 valores si tiene éxito: ($content_type, $document_length, $modified_time, $expires, $server)

Devuelve una lista vacía si falla. En contexto escalar, devuelve TRUE si tiene éxito.

getprint

my $code = getprint($url);

Obtiene e imprime un documento identificado por una URL. El documento se imprime en el manejador de archivo predeterminado seleccionado para la salida (normalmente STDOUT) a medida que los datos se reciben de la red. Si la solicitud falla, el código de estado y el mensaje se imprimen en STDERR. El valor de retorno es el código de respuesta HTTP.

getstore

my $code = getstore($url, $file)
my $code = getstore($url, $filehandle)

Obtiene un documento identificado por una URL y lo almacena en el archivo. El valor de retorno es el código de respuesta HTTP. También puede pasar un manejador de archivo escribible o similar, como un objeto File::Temp.

mirror

my $code = mirror($url, $file);

Obtiene y almacena un documento identificado por una URL, utilizando If-modified-since y verificando el Content-Length. Devuelve el código de respuesta HTTP.

FUNCIONES DE CLASIFICACIÓN

Las funciones de clasificación de HTTP::Status son:

is_success

my $bool = is_success($rc);

Verdadero si el código de respuesta indicó una solicitud exitosa.

is_error

my $bool = is_error($rc)

Verdadero si el código de respuesta indicó que ocurrió un error.

ADVERTENCIA

Tenga en cuenta que si está utilizando tanto LWP::Simple como el muy popular módulo CGI, es posible que esté importando una función "head" de cada módulo, produciendo una advertencia como "Prototype mismatch: sub main::head ($) vs none". Supere este problema simplemente sin importar la función "head" de LWP::Simple, de esta manera:

use LWP::Simple qw(!head);
use CGI qw(:standard);  # entonces solo CGI.pm define un head()

Luego, si necesita la función "head" de LWP::Simple, puede llamarla simplemente como LWP::Simple::head($url).
