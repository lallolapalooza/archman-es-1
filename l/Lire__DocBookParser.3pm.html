NOMBRE

Lire::XMLParser - Analizador DocBook base.

SINOPSIS

package MiAnalizador;
use base qw/ Lire::XMLParser /;

DESCRIPCIÓN

Este paquete contiene un analizador DocBook de Lire::XMLParser. Define los métodos relevantes "_start", "_end" y "_char" para el subconjunto de DocBook utilizado por Lire. Todos los manejadores definidos tienen la forma "dbk_nombre_start", "dbk_nombre_end" y "dbk_nombre_char" (cuando el elemento acepta contenido PCDATA).

Su funcionalidad base es recopilar el marcado DocBook para su uso posterior. La mayoría de las veces será una subclase.

MÉTODOS CLIENTE

dbk_init()

Las subclases deben llamar a este método siempre que deba iniciarse el estado del análisis de DocBook. Esto se llama desde el método parse_start() cuando el analizador se utiliza de forma autónoma.

dbk_string()

Devuelve el XML DocBook acumulado por el analizador. Esto se devuelve desde el método parse_end() cuando se utiliza de forma autónoma.

MÉTODOS IMPLEMENTACIÓN ESPECIFICACIÓN XML

namespaces()

DocBook no utiliza namespaces, por lo que este método devuelve una referencia a un hash vacío.

elements_spec()

Devuelve la especificación de elementos para el subconjunto de DocBook soportado por Lire.
