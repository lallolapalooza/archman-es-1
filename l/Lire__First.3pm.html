NOMBRE

Lire::First - Clase de Lire que implementa el operador first

SINOPSIS

use Lire::First

DESCRIPCIÓN

Clase que implementa el operador first. Este operador generará el primer valor que aparezca en su campo cuando los registros DLF se ordenen según el atributo "sort_fields". El orden de ordenación predeterminado es la marca de tiempo predeterminada.

MÉTODOS

new( %params )

Crea un nuevo objeto Lire::First. El atributo del campo se puede especificar en el parámetro "field" y el orden de ordenación se puede pasar en el parámetro "sort_fields".

sort_fields( [$new_sort_fields] )

Devuelve los campos que se utilizarán para ordenar los registros DLF. Esto es una referencia a un array de nombres de campos DLF.

Si se establece el parámetro $new_sort_fields, se utilizará como el nuevo orden de ordenación. Debe ser una referencia a un array y solo debe contener nombres de campos válidos para el esquema de la especificación del informe actual.

Cuando no se establecen sort_fields, el valor predeterminado es utilizar el campo de marca de tiempo predeterminado.
