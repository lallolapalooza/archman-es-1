NOMBRE

Lingua::Translit::Tables - proporciona tablas de transliteración

SINOPSIS

use Lingua::Translit::Tables qw/:checks/;
my $truth;
$truth = translit_supported("ISO 9");
$truth = translit_reverse_supported("ISO 9");
use Lingua::Translit::Tables qw/:list/;
translit_list_supported();

DESCRIPCIÓN

Este módulo se utiliza principalmente para proporcionar tablas de transliteración para Lingua::Translit y, por lo tanto, permite separar los datos y el algoritmo.

Además de eso, proporciona rutinas para comprobar si una transliteración dada es compatible y permite imprimir una lista simple de transliteraciones compatibles junto con alguna metainformación.

EXPORTACIONES

No se exportan símbolos por defecto.

Utilice el nombre de la rutina o una de las siguientes etiquetas para importar símbolos a su espacio de nombres.

todas
Importar todas las rutinas.
checks
Importar todas las rutinas que permiten comprobar si una transliteración dada es compatible: translit_supported() y translit_reverse_supported().
list
Importar translit_list_supported(). (Etiqueta de conveniencia)

RUTINAS

translit_supported(translit_name)

Devuelve verdadero (1), si translit_name es compatible. Falso (0) en caso contrario.

translit_reverse_supported(translit_name)

Devuelve verdadero (1), si translit_name es compatible y permite la transliteración inversa. Falso (0) en caso contrario.

translit_list_supported()

Imprime una lista de todas las transliteraciones compatibles en STDOUT (codificado en UTF-8), proporcionando la siguiente información:

* Nombre
* Reversibilidad
* Descripción

La misma información se proporciona también en este documento:

Lingua::Translit::Tables - Base de datos de tablas de transliteración

NAME

Lingua::Translit::Tables - Base de datos de tablas de transliteración

SYNOPSIS

                    use Lingua::Translit::Tables;

DESCRIPTION

Este módulo proporciona una forma de almacenar y recuperar tablas de transliteración para el módulo Lingua::Translit.

No se pretende usar directamente. Debe ser utilizado por Lingua::Translit o por un módulo que cree sus propias tablas de transliteración.

EXPORTS

Ninguno.

ROUTINES

Las rutinas principales de este módulo son métodos para cargar y guardar tablas. 

                    # Cargar una tabla de transliteración
                    my $tables = Lingua::Translit::Tables->new();
                    my $table = $tables->load_table('nombre_tabla');

                    # Guardar una tabla de transliteración
                    $tables->save_table('nombre_tabla', $table);

SUPPORTED TRANSLITERATIONS

Este módulo no define ninguna transliteración. Se espera que las tablas sean cargadas o guardadas por otros módulos.

ADDING NEW TRANSLITERATIONS

Para añadir nuevas transliteraciones, debe crear un nuevo módulo que use este módulo como base o que implemente la misma interfaz.
