NOMBRE

Locale::Po4a::SimplePod::Parser - módulo auxiliar para analizar POD

DESCRIPCIÓN

Este módulo sirve como auxiliar para Locale::Po4a::SimplePod y no está destinado a ser utilizado directamente por usuarios finales, como los traductores.

PENDIENTE

Eliminar la indentación de los bloques de verbatim podría ser útil. Estoy considerando usar la función "strip_verbatim_indent" para controlar este comportamiento.

VER TAMBIÉN

Este módulo se basa en Pod::Simple::JustPod, que realiza una transformación de identidad de POD *a POD*. Ese módulo es particularmente útil para comprender cómo serializar eventos de documentos POD analizados en el formato de archivo POD.

Para una visión general fundamental de la biblioteca, consulte Pod::Simple. Además, Locale::Po4a::SimplePod utiliza este módulo dentro de po4a.
