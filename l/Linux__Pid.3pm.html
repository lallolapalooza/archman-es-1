NOMBRE

Linux::Pid - Obtener el PID nativo y el PPID en Linux

SINOPSIS

use Linux::Pid;
print Linux::Pid::getpid(), "\t", Linux::Pid::getppid(), "\n";
use Linux::Pid qw(getpid getppid);
print getpid(), "\t", getppid(), "\n";

DESCRIPCIÓN

¿Por qué usar un módulo para obtener el PID y el PPID de un proceso cuando existen la variable $$ y la función integrada getppid()? (Sin mencionar las funciones equivalentes POSIX::getpid() y POSIX::getppid()).

De hecho, esto es útil en Linux, con programas multihilo. La biblioteca C de Linux, utilizando el modelo de hilos de Linux, devuelve valores diferentes de PID y PPID desde diferentes hilos. (Otros modelos de hilos como NPTL no tienen el mismo comportamiento). Este módulo fuerza a Perl a llamar a las funciones subyacentes de C getpid() y getppid().
