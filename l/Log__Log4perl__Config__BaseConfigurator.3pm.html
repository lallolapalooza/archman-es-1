NOMBRE

Log::Log4perl::Config::BaseConfigurator - Clase base de configurador

SINOPSIS

Esta es una clase base virtual, todos los configuradores deben derivar de ella.

DESCRIPCIÓN

MÉTODOS

"new"
Constructor, típicamente llamado como 
my $config_parser = SomeConfigParser->new(
    file => $file,
);
my $data = $config_parser->parse();

En lugar de "file", la clase derivada "SomeConfigParser" puede definir cualquier tipo de medio de entrada de configuración (p. ej., "url => 'http://foobar'"). Solo tiene que asegurarse de que su método parse() obtendrá los datos de entrada del medio especificado.

La clase base acepta un nombre de archivo o una referencia a un array de líneas de texto:

"file"
Especifica un archivo que el método parse() parsea más tarde.
"text"
Especifica una referencia a un array de escalares, representando registros de configuración (típicamente líneas de un archivo). También acepta un simple escalar, que divide por sus saltos de línea y lo transforma en un array: 
my $config_parser = MyYAMLParser->new(
    text => ['foo: bar',
             'baz: bam',
            ],
);
my $data = $config_parser->parse();

Si se han especificado los parámetros "file" o "text" en la llamada al constructor, una llamada posterior al método text() del configurador devolverá una referencia a un array de líneas de texto de configuración. Esto será utilizado típicamente por el método parse() para procesar la entrada.

"parse"
Método virtual, debe ser definido por la clase derivada.

Requisitos del analizador

  • Si el analizador proporciona funcionalidad de sustitución de variables, debe implementarla.
  • El método parse() del analizador devuelve una referencia a un hash de hashes (HoH). El hash más externo contiene las palabras clave de nivel superior ("category", "appender") como claves, asociadas con valores que son referencias a hashes más anidados.
  • El prefijo "log4perl." (p. ej., como se usa en la clase PropertyConfigurator) se elimina, no forma parte de la estructura HoH.
  • Cada valor de configuración de Log4perl se indica mediante la clave "value", como en 
    $data->{category}->{Bar}->{Twix}->{value} = "WARN, Logfile"

EJEMPLOS

La siguiente configuración de Log::Log4perl:

log4perl.category.Bar.Twix        = WARN, Screen
log4perl.appender.Screen          = Log::Log4perl::Appender::File
log4perl.appender.Screen.filename = test.log
log4perl.appender.Screen.layout   = Log::Log4perl::Layout::SimpleLayout

debe ser transformada por el método parse() del analizador en esta estructura de datos:

{ appender => {
    Screen  => {
      layout => { 
        value  => "Log::Log4perl::Layout::SimpleLayout" },
        value  => "Log::Log4perl::Appender::Screen",
    },
  },
  category => { 
    Bar => { 
      Twix => { 
        value => "WARN, Screen" } 
    } }
}

Para un ejemplo completo, consulta la implementación de ejemplo del analizador YAML en "eg/yamlparser". Utiliza una sintaxis YAML simple para especificar la configuración de Log4perl e ilustrar el concepto.
