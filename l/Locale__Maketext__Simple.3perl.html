Locale::Maketext::Simple(3perl) Guía de referencias para programadores de Perl Locale::Maketext::Simple(3perl)

NOMBRE

Locale::Maketext::Simple - Interfaz simple para Locale::Maketext::Lexicon

VERSIÓN

Este documento describe la versión 0.18 de Locale::Maketext::Simple, lanzada el 8 de septiembre de 2006.

SINOPSIS

Configuración mínima (busca automáticamente auto/Foo/*.po y auto/Foo/*.mo):

package Foo;
use Locale::Maketext::Simple;       # exporta 'loc'
loc_lang('fr');                     # establece el idioma a francés
sub hello {
    print loc("Hello, [_1]!", "World");
}

Ejemplo más complejo:

package Foo::Bar;
use Locale::Maketext::Simple (
    Class       => 'Foo',       # busca en auto/Foo/
    Style       => 'gettext',   # %1 en lugar de [_1]
    Export      => 'maketext',  # maketext() en lugar de loc()
    Subclass    => 'L10N',      # Foo::L10N en lugar de Foo::I18N
    Decode      => 1,           # decodifica entradas a strings Unicode
    Encoding    => 'locale',    # pero codifica los lexicons en el idioma actual
                                # (necesita Locale::Maketext::Lexicon 0.36)
);
sub japh {
    print maketext("Just another %1 hacker", "Perl");
}

DESCRIPCIÓN

Este módulo es una capa simple sobre Locale::Maketext::Lexicon, diseñada para aliviar la necesidad de crear clases de idioma para los desarrolladores de módulos.

El idioma utilizado se elige mediante la llamada a loc_lang(). Si no se puede encontrar una búsqueda, se utilizará el idioma predeterminado. Si la búsqueda no está en el idioma predeterminado, se devolverá la clave.

Si Locale::Maketext::Lexicon no está presente, implementa una función de localización minimal al simplemente interpolar [_1] con el primer argumento, [_2] con el segundo, etc. Las funciones interpoladas como [quant,_1] se tratan como [_1], con la excepción de [tense,_1,X], que añadirá 'ing' a _1 si X es 'present', o 'ed' a _1 de lo contrario.

OPCIONES

Todas las opciones se pasan mediante la instrucción "use" o mediante una opción explícita "import".

Clase

Por defecto, Locale::Maketext::Simple obtiene sus fuentes del directorio auto/ de la carpeta actual; puedes cambiar este comportamiento especificando otra carpeta como valor de "Class".

Ruta

Si tus archivos .po y .mo están en una carpeta aparte de "auto/", puedes especificarla mediante la opción "Path".

Estilo

Por defecto, este módulo usa el estilo "maketext" de "[_1]" y [quant,_1]" para la interpolación. Alternativamente, puedes especificar el estilo "gettext", que usa %1 y %quant(%1) para la interpolación.

Esta opción es insensible a mayúsculas y minúsculas.

Exportar

Por defecto, este módulo exporta una única función, "loc", a namespace del llamador. Puedes especificar otro nombre o dejarlo vacío para deshabilitar la exportación.

Clase sub

Por defecto, este módulo crea una subclase "::I18N" bajo el paquete del llamador (o el paquete especificado por "Class"), y almacena los datos de lexicon en sus subclases. Puedes asignar un nombre distinto de "I18N" mediante esta opción.

Decodificar

Si se establece un valor verdadero, los archivos de entrada se convertirán en strings UTF-8 (disponible en Perl 5.6.1 o posterior). Esta función requiere el módulo Encode o Encode::compat.

Codificación

Indica una codificación para almacenar los datos de lexicon, en lugar de strings UTF-8. Si se establece "locale", se utilizará la codificación del entorno actual del idioma. Implica un valor verdadero para "Decode".
