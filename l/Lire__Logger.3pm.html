NOMBRE

Lire::Logger - Interfaz de registro de Lire.

SINOPSIS

Cualquier programa:

use Lire::Logger qw/ lr_info lr_debug lr_warn /;
lr_info( "haciendo cosas" );
lr_debug( "información de depuración" );
lr_warn( "se encontró un valor inesperado: ", $valor );
open( ARCHIVOCFG, "mi.conf" ) or lr_err( "error al abrir: ", $! );

DESCRIPCIÓN

Este módulo contiene funciones que deben ser utilizadas por todo dentro del framework Lire que necesite registrar información.

Todas las funciones de registro aceptan cualquier número de parámetros que se unirán para formar el mensaje (similar a print(), die(), warn() y sus similares).

lr_emerg()

Esto registra un mensaje con el nivel "emerg" y aborta tu programa. Probablemente no debería usarse.

lr_crit()

Esto registra un mensaje con el nivel "crit" y aborta tu programa. Esto solo debe usarse cuando algo está realmente roto en el programa Lire o en el entorno. Se usa en algunos lugares de Lire cuando las aserciones que realmente nunca deberían fallar (como un archivo DLF con el número incorrecto de campos).

lr_err()

Esto registra un mensaje con el nivel "err" y generalmente aborta tu programa. (Es el equivalente de un die().) El programa no abortará si se usa en un bloque eval. Usa esto para condiciones de error.

lr_warn()

Esto registra un mensaje con el nivel "warning". El warn incorporado de Perl se mapea a esta función. Usa esto para errores no fatales.

lr_notice()

Esto registra un mensaje con el nivel "notice". Esto debe usarse para mensajes informativos significativos que el usuario debería ver. (Por defecto, el usuario solo verá mensajes en el nivel "notice" o superior.)

lr_info()

Esto registra un mensaje con el nivel "info". Usa esto para mensajes informativos generales.

lr_debug()

Esto registra un mensaje con el nivel "debug". Usa esto para mensajes de depuración.
