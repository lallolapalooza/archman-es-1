NOMBRE

Lire::Report - Interfaz a un informe de Lire.

SINOPSIS

use Lire::ReportParser::ReportBuilder;
my $parser = new Lire::ReportParser::ReportBuilder;
my $report = $parser->parse( "report.xml" );
print $report->superservice(), " informe\n";
print "Generado el ", scalar( localtime( $report->date() ) ), "\n";
print "El período comienza el ", scalar( localtime( $report->timespan_start() ) ), "\n";
print "El período finaliza el ", scalar( localtime( $report->timespan_start() ) ), "\n";
foreach my $s ( $report->sections() ) {
    print "Sección: '", $s->title(), "' tiene ", scalar $s->subreports(),
        " subinformes en ella\n";
}

DESCRIPCIÓN

Este módulo ofrece una API para el informe generado por Lire. Se puede usar el Lire::ReportParser::ReportBuilder(3pm) para crear un objeto Lire::Report a partir de un archivo XML que cumpla con la DTD del Lenguaje de Marcado de Informes de Lire.

CONSTRUCTOR

Se puede construir un objeto Lire::Report a partir de un archivo de informe XML, desde el método new() o desde un objeto Lire::ReportConfig.

new( [ $timespan_period ], [ $timespan_start ], [ $timespan_end ] )

Crea un nuevo Lire::Report. Los parámetros $timespan_period, $timespan_start y $timespan_end inicializan los atributos del mismo nombre.

MÉTODOS DE OBJETO

version()

Devuelve el número de versión del formato del informe que se utilizó en la representación externa de este informe. La versión actual es 2.1.

generator([$generator)

Devuelve la cadena del generador que se incluirá en los comentarios cuando se utilice el método write_report(). Se puede cambiar este valor pasando un nuevo valor a través del parámetro $generator.

date( [ $new_date ] )

Devuelve (y opcionalmente cambia) la fecha en segundos desde la época en la que se generó este informe.

timespan_period( [ $new_period ] )

Devuelve (y opcionalmente cambia) el período del informe. El período puede ser 'hourly', 'daily', 'weekly', 'monthly' o 'yearly'. Cuando el período es undef, es un período arbitrario.

timespan_start( [ $new_start ] )

Devuelve (y opcionalmente cambia) el inicio del período cubierto por este informe en segundos desde la época.

timespan_end( [ $new_end ] )

Devuelve (y opcionalmente cambia) el final del período cubierto por este informe en segundos desde la época.

title( [$title] )

Devuelve el título del informe, si tiene uno.

Si se establece el parámetro $title, el título del informe se establecerá a este nuevo valor.

description( [$new_desc] )

Devuelve la descripción del informe. Esta descripción está codificada en XML DocBook.

Si se establece el parámetro $description, este método establecerá la descripción a este nuevo valor. Si el parámetro $description es undef, se eliminará dicha descripción.

sections( )

Devuelve las secciones del informe como un array. Será un array de objetos Lire::Report::Section.

add_section( $section )

Añade una sección a este informe. El parámetro $section debería ser un objeto Lire::Report::Section.

subreport_by_id( $id )

Devuelve el objeto Lire::Report::Subreport con $id. Devuelve undef cuando no hay ningún subinforme con ese ID.

schemas()

Devuelve una referencia de array que contiene todos los esquemas utilizados por este informe.

write_report( [FH] );

Escribe el informe en formato XML en el manejador de archivo FH o en STDOUT si se omite.

Este método se encarga de añadir cosas como la cabecera XML "<?xml version=[...]". Codifica el informe XML en UTF-8, utilizando Lire::I18N::set_fh_encoding().

delete( )

Elimina todas las referencias circulares para que el objeto pueda ser liberado.
