Operaciones sobre listas.

Algunas funciones están marcadas como no recursivas en cola. Una función recursiva en cola utiliza espacio constante en la pila, mientras que una función no recursiva en cola utiliza espacio proporcional a la longitud de su argumento de lista, lo cual puede ser un problema con listas muy largas. Cuando se pasan varios argumentos de lista, una fórmula aproximada que da el uso de la pila (en algún unidad constante) se muestra en paréntesis.

Estas consideraciones suelen ser ignoradas si tus listas no son más largas que aproximadamente 10000 elementos.

La versión etiquetada de este módulo puede utilizarse como descrito en el módulo StdLabels.

tipo 'a t = 'a list =
| []
| (::) de 'a * 'a list

Un alias para el tipo de listas.

val longitud : 'a list -> int

Devuelve la longitud (número de elementos) de la lista dada.

val comparar_longitudes : 'a list -> 'b list -> int

Compara las longitudes de dos listas. comparar_longitudes l1 l2 es equivalente a comparar (longitud l1) (longitud l2), excepto que el cálculo se detiene después de alcanzar el final de la lista más corta.

Desde 4.05

val comparar_longitud_con : 'a list -> len:int -> int

Compara la longitud de una lista con un número entero. comparar_longitud_con l len es equivalente a comparar (longitud l) len, excepto que el cálculo se detiene después de al menos len iteraciones en la lista.

Desde 4.05

val es_vacia : 'a list -> bool

es_vacia l es verdadero si y solo si l tiene ningún elemento. Es equivalente a comparar_longitud_con l 0 = 0 .

val cons : 'a -> 'a list -> 'a list

Desde 4.05

val singleton : 'a -> 'a list

singleton x devuelve la lista de un elemento [x] .

val hd : 'a list -> 'a

Devuelve el primer elemento de la lista dada.

Alza Failure si la lista está vacía.

Alza Failure si la lista es demasiado corta.

Devuelve el n-ésimo elemento de la lista dada. El primer elemento (cabeza de la lista) está en la posición 0. Devuelve None si la lista es demasiado corta.

Alza Invalid_argument si n es negativo.

val rev : 'a list -> 'a list

Invierte la lista.

val init : len:int -> f:(int -> 'a) -> 'a list

init ~len ~f es [f 0; f 1; ...; f (len-1)], evaluada de izquierda a derecha.

Desde 4.06

Alza Invalid_argument si len < 0 .

val append : 'a list -> 'a list -> 'a list

append l0 l1 anexa l1 a l0. La misma función que el operador de concatenación @.

Desde 5.1 esta función es recursiva en cola.

val rev_append : 'a list -> 'a list -> 'a list

rev_append l1 l2 invierte l1 y concatenála con l2. Esto es equivalente a (ListLabels.rev l1) @ l2.

val concat : 'a list list -> 'a list

Concatena una lista de listas. Los elementos del argumento se concatenan todos juntos (en el mismo orden) para dar el resultado. No es recursiva en cola (longitud del argumento + longitud de la sublista más larga).

val flatten : 'a list list -> 'a list

Es el mismo que ListLabels.concat. No es recursiva en cola (longitud del argumento + longitud de la sublista más larga).

Comparación

val igual : eq:('a -> 'a -> bool) -> 'a list -> 'a list -> bool

igual eq [a1; ...; an] [b1; ..; bm] se cumple cuando las dos listas de entrada tienen la misma longitud, y para cada par de elementos ai, bi en la misma posición tenemos eq ai bi.

Nota: el función eq puede llamarse incluso si las listas tienen diferente longitud. Si conoces tu función de igualdad es costosa, podrías querer verificar ListLabels.compare_lengths primero.

Desde 4.12

val comparar : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> int

comparar cmp [a1; ...; an] [b1; ...; bm] realiza una comparación lexicográfica de las dos listas de entrada, utilizando la misma interfaz 'a -> 'a -> int que comparar:

- a1 :: l1 es menor que a2 :: l2 (resultado negativo) si a1 es menor que a2, o si son iguales (resultado cero) y l1 es menor que l2. - La lista vacía [] es menor que listas no vacías.

Nota: la función cmp se llamará incluso si las listas tienen diferente longitud.

Desde 4.12

Iteradores

val iter : f:('a -> unit) -> 'a list -> unit

iter ~f [a1; ...; an] aplica la función f en orden a [a1; ...; an]. Es equivalente a f a1; f a2; ...; f an.

val iteri : f:(int -> 'a -> unit) -> 'a list -> unit

Es el mismo que ListLabels.iter, pero la función se aplica al índice del elemento como primer argumento (contando desde 0), y al elemento como segundo argumento.

Desde 4.00

val map : f:('a -> 'b) -> 'a list -> 'b list

map ~f [a1; ...; an] aplica la función f a a1, ..., an y construye la lista [f a1; ...; f an] con los resultados devueltos por f.

val mapi : f:(int -> 'a -> 'b) -> 'a list -> 'b list

Es el mismo que ListLabels.map, pero la función se aplica al índice del elemento como primer argumento (contando desde 0), y al elemento como segundo argumento.

Desde 4.00

val rev_map : f:('a -> 'b) -> 'a list -> 'b list

rev_map ~f l da el mismo resultado que ListLabels.rev (ListLabels.map f l), pero es más eficiente.

val filter_map : f:('a -> 'b option) -> 'a list -> 'b list

filter_map ~f l aplica f a cada elemento de l, filtra los elementos None y devuelve la lista de los argumentos de los elementos Some.

Desde 4.08

val concat_map : f:('a -> 'b list) -> 'a list -> 'b list

concat_map ~f l da el mismo resultado que ListLabels.concat (ListLabels.map f l), es recursivo en cola.

Desde 4.10

val fold_left_map : f:('acc -> 'a -> 'acc * 'b) -> init:'acc -> 'a list -> 'acc * 'b list

fold_left_map es una combinación de fold_left y map que atraviesa una acumuladora en cada llamada a f.

Desde 4.11

val fold_left : f:('acc -> 'a -> 'acc) -> init:'acc -> 'a list -> 'acc

fold_left ~f ~init [b1; ...; bn] es f (... (f (f init b1) b2) ...) bn .

val fold_right : f:('a -> 'acc -> 'acc) -> 'a list -> init:'acc -> 'acc

fold_right ~f [a1; ...; an] ~init es f a1 (f a2 (... (f an init) ...)) . No es recursiva en cola.

Iteradores en dos listas

val iter2 : f:('a -> 'b -> unit) -> 'a list -> 'b list -> unit

iter2 ~f [a1; ...; an] [b1; ...; bn] llama sucesivamente f a1 b1; ...; f an bn .

Raises Invalid_argument si se determina que las dos listas tienen longitudes diferentes.

val map2 : f:('a -> 'b -> 'c) -> 'a list -> 'b list -> 'c list

map2 ~f [a1; ...; an] [b1; ...; bn] es [f a1 b1; ...; f an bn] .

Raises Invalid_argument si se determina que las dos listas tienen longitudes diferentes.

val rev_map2 : f:('a -> 'b -> 'c) -> 'a list -> 'b list -> 'c list

rev_map2 ~f l1 l2 da el mismo resultado que ListLabels.rev ( ListLabels.map2 f l1 l2) , pero es más eficiente.

val fold_left2 : f:('acc -> 'a -> 'b -> 'acc) -> init:'acc -> 'a list -> 'b list -> 'acc

fold_left2 ~f ~init [a1; ...; an] [b1; ...; bn] es f (... (f (f init a1 b1) a2 b2) ...) an bn .

Raises Invalid_argument si se determina que las dos listas tienen longitudes diferentes.

val fold_right2 : f:('a -> 'b -> 'acc -> 'acc) -> 'a list -> 'b list -> init:'acc -> 'acc

fold_right2 ~f [a1; ...; an] [b1; ...; bn] ~init es f a1 b1 (f a2 b2 (... (f an bn init) ...)) .

Raises Invalid_argument si se determina que las dos listas tienen longitudes diferentes. No es recursivo de cola.

Escaneo de listas

val for_all : f:('a -> bool) -> 'a list -> bool

for_all ~f [a1; ...; an] comprueba si todos los elementos de la lista satisfacen el predicado f . Es decir, devuelve (f a1) && (f a2) && ... && (f an) para una lista no vacía y true si la lista está vacía.

val exists : f:('a -> bool) -> 'a list -> bool

exists ~f [a1; ...; an] comprueba si al menos un elemento de la lista satisface el predicado f . Es decir, devuelve (f a1) || (f a2) || ... || (f an) para una lista no vacía y false si la lista está vacía.

val for_all2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Igual que ListLabels.for_all , pero para un predicado de dos argumentos.

Raises Invalid_argument si se determina que las dos listas tienen longitudes diferentes.

val exists2 : f:('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Igual que ListLabels.exists , pero para un predicado de dos argumentos.

Raises Invalid_argument si se determina que las dos listas tienen longitudes diferentes.

val mem : 'a -> set:'a list -> bool

mem a ~set es verdadero si y solo si a es igual a un elemento de set .

val memq : 'a -> set:'a list -> bool

Igual que ListLabels.mem , pero utiliza la igualdad física en lugar de la igualdad estructural para comparar los elementos de la lista.

Búsqueda de listas

val find : f:('a -> bool) -> 'a list -> 'a

find ~f l devuelve el primer elemento de la lista l que satisface el predicado f .

Raises Not_found si no hay ningún valor que satisfaga f en la lista l .

val find_opt : f:('a -> bool) -> 'a list -> 'a option

find ~f l devuelve el primer elemento de la lista l que satisface el predicado f . Devuelve None si no hay ningún valor que satisfaga f en la lista l .

Since 4.05

val find_index : f:('a -> bool) -> 'a list -> int option

find_index ~f xs devuelve Some i , donde i es el índice del primer elemento de la lista xs que satisface f x , si existe tal elemento.

Devuelve None si no existe tal elemento.

Since 5.1

val find_map : f:('a -> 'b option) -> 'a list -> 'b option

find_map ~f l aplica f a los elementos de l en orden, y devuelve el primer resultado de la forma Some v , o None si no existen.

Since 4.10

val find_mapi : f:(int -> 'a -> 'b option) -> 'a list -> 'b option

Igual que find_map , pero el predicado se aplica al índice del elemento como primer argumento (contando desde 0), y al elemento mismo como segundo argumento.

Since 5.1

val filter : f:('a -> bool) -> 'a list -> 'a list

filter ~f l devuelve todos los elementos de la lista l que satisfacen el predicado f . Se preserva el orden de los elementos en la lista de entrada.

val find_all : f:('a -> bool) -> 'a list -> 'a list

find_all es otro nombre para ListLabels.filter .

val filteri : f:(int -> 'a -> bool) -> 'a list -> 'a list

Igual que ListLabels.filter , pero el predicado se aplica al índice del elemento como primer argumento (contando desde 0), y al elemento mismo como segundo argumento.

Since 4.11

Manipulación de listas

val take : int -> 'a list -> 'a list

take n l devuelve el prefijo de l de longitud n , o una copia de l si n > length l . Es la lista vacía si n es negativo.

Advertencia. Solo en la versión 5.3, esta función eleva Invalid_argument para valores negativos de n.

Since 5.3

val drop : int -> 'a list -> 'a list

drop n l devuelve el sufijo de l después de n elementos, o [] si n > length l . Es l si n es negativo.

Advertencia. Solo en la versión 5.3, esta función eleva Invalid_argument para valores negativos de n.

Since 5.3

val take_while : f:('a -> bool) -> 'a list -> 'a list

take_while p l es el prefijo más largo (posiblemente vacío) de l que contiene solo elementos que satisfacen p .

Since 5.3

val drop_while : f:('a -> bool) -> 'a list -> 'a list

drop_while p l es el sufijo más largo (posiblemente vacío) de l que comienza en el primer elemento que no satisface p .

Since 5.3

val partition : f:('a -> bool) -> 'a list -> 'a list * 'a list

partition ~f l devuelve un par de listas (l1, l2) , donde l1 es la lista de todos los elementos de l que satisfacen el predicado f , y l2 es la lista de todos los elementos de l que no satisfacen f . Se preserva el orden de los elementos en la lista de entrada.

val partition_map : f:('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l devuelve un par de listas (l1, l2) tal que, para cada elemento x de la lista de entrada l :

-si f x es Left y1 , entonces y1 está en l1 , y

-si f x es Right y2 , entonces y2 está en l2 .

Los elementos de salida se incluyen en l1 y l2 en el mismo orden relativo que los elementos de entrada correspondientes en l .

En particular, partition_map (fun x -> if f x then Left x else Right x) l es equivalente a partition f l .

Since 4.12

Listas de asociación

val assoc : 'a -> ('a * 'b) list -> 'b

assoc a l devuelve el valor asociado a la clave a en la lista de pares l . Es decir, assoc a [ ...; (a,b); ...] = b si (a,b) es la vinculación más a la izquierda de a en la lista l .

Raises Not_found si no hay ningún valor asociado con a en la lista l .

val assoc_opt : 'a -> ('a * 'b) list -> 'b option

assoc_opt a l devuelve el valor asociado a la clave a en la lista de pares l . Es decir, assoc_opt a [ ...; (a,b); ...] = Some b si (a,b) es la vinculación más a la izquierda de a en la lista l . Devuelve None si no hay ningún valor asociado con a en la lista l .

Since 4.05

val assq : 'a -> ('a * 'b) list -> 'b

Igual que ListLabels.assoc , pero utiliza la igualdad física en lugar de la igualdad estructural para comparar las claves.

val assq_opt : 'a -> ('a * 'b) list -> 'b option

Igual que ListLabels.assoc_opt , pero utiliza la igualdad física en lugar de la igualdad estructural para comparar las claves.

Since 4.05

val mem_assoc : 'a -> map:('a * 'b) list -> bool

Igual que ListLabels.assoc , pero simplemente devuelve true si existe una vinculación y false si no existen vinculaciones para la clave dada.

val mem_assq : 'a -> map:('a * 'b) list -> bool

Igual que ListLabels.mem_assoc , pero utiliza la igualdad física en lugar de la igualdad estructural para comparar las claves.

val remove_assoc : 'a -> ('a * 'b) list -> ('a * 'b) list

remove_assoc a l devuelve la lista de pares l sin el primer par con clave a , si existe. No es recursivo de cola.

val remove_assq : 'a -> ('a * 'b) list -> ('a * 'b) list

Igual que ListLabels.remove_assoc , pero utiliza la igualdad física en lugar de la igualdad estructural para comparar las claves. No es recursivo de cola.

NAME

ListLabels — Labeled list operations.

Module

Module ListLabels

Documentation

The functions for manipulating lists are defined in the List module. The labeled version of these functions are available in the ListLabels module.

val fold_left : f:('a -> 'b -> 'a) -> init:'a -> 'b list -> 'a

Same as List.fold_left, but the arguments are labeled.

val fold_right : f:('a -> 'b -> 'b) -> x:'a list -> init:'b -> 'b

Same as List.fold_right, but the arguments are labeled.

val iter : f:('a -> unit) -> 'a list -> unit

Same as List.iter, but the arguments are labeled.

val iter_right : f:('a -> unit) -> 'a list -> unit

Same as List.iter_right, but the arguments are labeled.

val map : f:('a -> 'b) -> 'a list -> 'b list

Same as List.map, but the arguments are labeled.

val mapi : f:(int -> 'a -> 'b) -> 'a list -> 'b list

Same as List.mapi, but the arguments are labeled.

val rev_map : f:('a -> 'b) -> 'a list -> 'b list

Same as List.rev_map, but the arguments are labeled.

Construction

val create_list : length:int -> ('a -> 'b) -> 'b list

Return a list of length length. The function f is applied to the integers 0, 1, ..., length - 1 to generate the elements of the list.

Since 5.1

Destruction

val nth : list:'a list -> n:int -> 'a

Return the element at position n in the given list. The first element is at position 0. The last element is at position length list - 1.

Raises Invalid_argument if n is out of bounds.

val try_nth : list:'a list -> n:int -> 'a option

Return the element at position n in the given list, or None if n is out of bounds.

Since 4.12

val split_at : list:'a list -> n:int -> 'a list * 'a list

Split the list into two lists at position n. The first list contains the first n elements, and the second list contains the remaining elements.

Raises Invalid_argument if n is out of bounds.

Since 4.11

val take_while : p:('a -> bool) -> 'a list -> 'a list

Return the longest prefix of the given list such that all elements satisfy the predicate p.

Since 4.11

val drop_while : p:('a -> bool) -> 'a list -> 'a list

Return the longest suffix of the given list such that all elements satisfy the predicate p.

Since 4.11

val find : p:('a -> bool) -> 'a list -> 'a option

Return the first element of the list that satisfies the predicate p, or None if no such element exists.

val find_all : p:('a -> bool) -> 'a list -> 'a list

Return the list of all elements of the given list that satisfy the predicate p.

val partition : p:('a -> bool) -> 'a list -> 'a list * 'a list

Return a pair of lists: the first list contains the elements of the given list that satisfy the predicate p, and the second list contains the elements that do not satisfy p. The relative order of elements is preserved in each list.

val assoc : key:'a -> ('a * 'b) list -> 'b

Search for the first pair in the list whose first component is equal to key, and return the corresponding second component. This function is the same as List.assoc.

Raises Not_found if no matching pair is found.

val try_assoc : key:'a -> ('a * 'b) list -> 'b option

Same as assoc, but return `None` when no matching pair is found.

Since 4.08

val mem_assoc : key:'a -> ('a * 'b) list -> bool

Test whether a key is present in the association list.

val remove_assoc : key:'a -> ('a * 'b) list -> ('a * 'b) list

Remove the first pair that has key as its first component from the association list.

val split : ('a * 'b) list -> 'a list * 'b list

Transform a list of pairs into a pair of lists: split [(a1,b1); ...; (an,bn)] is ([a1; ...; an], [b1; ...; bn]) . Not tail-recursive.

val combine : 'a list -> 'b list -> ('a * 'b) list

Transform a pair of lists into a list of pairs: combine [a1; ...; an] [b1; ...; bn] is [(a1,b1); ...; (an,bn)] .

Raises Invalid_argument if the two lists have different lengths. Not tail-recursive.

Sorting

val sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Sort a list in increasing order according to a comparison function. The comparison function must return 0 if its arguments compare as equal, a positive integer if the first is greater, and a negative integer if the first is smaller (see Array.sort for a complete specification). For example, compare is a suitable comparison function. The resulting list is sorted in increasing order. ListLabels.sort is guaranteed to run in constant heap space (in addition to the size of the result list) and logarithmic stack space.

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val stable_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but the sorting algorithm is guaranteed to be stable (i.e. elements that compare equal are kept in their original order).

The current implementation uses Merge Sort. It runs in constant heap space and logarithmic stack space.

val fast_sort : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort or ListLabels.stable_sort , whichever is faster on typical input.

val sort_uniq : cmp:('a -> 'a -> int) -> 'a list -> 'a list

Same as ListLabels.sort , but also remove duplicates: if multiple elements compare equal, keep only the first.

Before5.4 the element kept was not necessarily the first one.

Since 4.03

val merge : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> 'a list

Merge two lists: Assuming that l1 and l2 are sorted according to the comparison function cmp , merge ~cmp l1 l2 will return a sorted list containing all the elements of l1 and l2 . If several elements compare equal, the elements of l1 will be before the elements of l2 . Not tail-recursive (sum of the lengths of the arguments).
