ReportConfig(3pm) Documentación de Lire ReportConfig(3pm)

NOMBRE

Lire::ReportConfig - API para la configuración de reportes

SINOPSIS

use Lire::ReportConfig;
my $templates = Lire::ReportConfig->templates();
if ( Lire::ReportConfig->has_template( 'www_default' ) ) {
    my $report_cfg = Lire::ReportConfig->template( 'www_default' )->as_value();
    my $report = $report_cfg->generate_report( $report );
}

DESCRIPCIÓN

Esta clase representa las configuraciones de reportes. Las configuraciones de reportes se almacenan como archivos de especificación de plantillas usando el tipo de configuración Lire::Report::ReportSpec.

PLANTILLAS

Las plantillas de reportes son archivos de especificación de plantillas encontrados en los directorios especificados por la variable de configuración 'lr_templates_path'.

templates()

Devuelve un referencia a un array de nombres de todas las plantillas definidas.

has_template( $name )

Devuelve verdadero si existe una plantilla con el nombre $name disponible.

template( $name )

Devuelve un objeto Lire::Config::Object que define la plantilla de reporte Lire::ReportConfig con el nombre $name. Su método spec() devuelve un objeto Lire::Config::ReportSpec y su método as_value() instancia un objeto Lire::ReportConfig.

CONSTRUCTORES

new()

Crea un objeto vacío de Lire::ReportConfig.

El objeto de configuración de reporte creado no tiene ninguna sección, reporte o filtro especificada.

new_from_file( $superservice, $report_cfg )

Crea un objeto de configuración de reporte para el $superservice superservice basado en el archivo de configuración de reporte $report_cfg.

MÉTODOS DE OBJETO

filename( [ $new_filename ] )

Devuelve (y opcionalmente cambia) el nombre de archivo desde el cual se cargó este ReportConfig. Devuelve undef si el ReportConfig no fue cargado desde un archivo.

title( [ $new_title ] )

Devuelve (y opcionalmente cambia) el título que se asignará al reporte.

schemas()

Devuelve un referencia a un array de nombres de esquemas utilizados en este reporte.

sections()

Devuelve este reporte de configuración como un array de objetos Lire::Section.

add_section( $section )

Añade una sección a este reporte de configuración. El parámetro $section debe ser un objeto Lire::ReportSection.

merge_filters()

Llamando a este método asegurará que todas las especificaciones de reporte tomen en cuenta su especificación de filtro de la sección.

Este método modificará a todas las especificaciones de reporte. Después de llamar a este método, su representación objeto no será idéntica a la de la especificación XML del reporte.

print( [$fh] )

Imprime el reporte de configuración en el archivo de salida $fh. Si el parámetro $fh no se especifica, el reporte de configuración se imprimirá en STDOUT.

create_report( $timespan_start, $timespan_end )

Devuelve un objeto Lire::Report basado en esta configuración de reporte. Los atributos $timespan_start y $timespan_end se usarán para iniciar el objeto Report.

Usado cuando se genera un reporte XML a partir de una fuente DLF y cuando se mergean reportes XML.

El trabajo real se delega a Lire::ReportSection::create_report_section().

create_analyser_streams( $store )

Este método asegurará que un DlfStream esté disponible en el Lire::DlfStore $store para cada esquema utilizado por esta configuración de reporte. El flujo se creará ejecutando el primer analizador que pueda generar el esquema con los flujos existentes.

generate_report( $store )

Genera un Lire::Report a partir de esta configuración de reporte. El reporte se calcula usando los flujos en el Lire::DlfStore $store.

merge_report_files( @report_files )

Genera un nuevo Lire::Report basado en esta configuración de reporte mediante la unión de reportes XML. Cada especificación de reporte contenida en la configuración será el resultado de la unión de todas las subreportes con el mismo id.

VER TAMBIÉN

Lire::ReportSection(3pm), Lire::ReportSpec(3pm), Lire::FilterSpec(3pm) Lire::Report(3pm)
