NOMBRE

Locale::Po4a::Debconf - convierte plantillas debconf desde/hacia archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y lo que es más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::Debconf es un módulo para ayudar a la traducción de las plantillas debconf a otros idiomas [humanos].

OPCIONES ACEPTADAS POR ESTE MÓDULO

NINGUNA.

ESTADO DE ESTE MÓDULO

No probado.

NO UTILICE ESTE MÓDULO PARA PRODUCIR PLANTILLAS. Sólo sirve para extraer datos.
