NOMBRE

Lire::ReportParser::RowColHandler - Subclase de Lire::ReportParser que sintetiza filas

SINOPSIS

En procesadores de informes XML:

package MiParser;
use base qw/Lire::ReportParser::RowColHandler/;
sub handle_header_row {
    my ( $self, $row ) = @_;
    ...
}
sub handle_row {
    my ( $self, $row ) = @_;
    ...
}
sub handle_table_summary {
    my ( $self, $nrecords, $row ) = @_;
    ....
}

DESCRIPCIÓN

El módulo Lire::ReportParser::RowColHandler es una subclase de Lire::ReportParser que sintetizará eventos de handle_row(). Esto facilita la escritura de subclases cuyo único propósito es formatear el informe. En lugar de tener que reconstruir la fila de la tabla a partir de los diversos eventos entry_start, group_start, handle_name, la subclase solo tiene que procesar los eventos de handle_row().

USO DE Lire::ReportParser::RowColHandler

El cliente solo tiene que heredar de Lire::ReportParser::RowColHandler. Después de eso, puede definir los métodos handle_row(), handle_header_row() y handle_table_summary().

Hay un parámetro que RowColHandler acepta y es "summary_when", que especifica cuándo se sintetizará el evento handle_table_summary() ( "before" o "after" el cuerpo de la tabla). Cuando es "before", el evento se generará después de los eventos de header_row pero antes de cualquier evento de handle_row(). De lo contrario, se generará una vez que se hayan procesado todos los eventos de handle_row(). El valor predeterminado es "before".

handle_table_summary( $nrecords, $row )

Se llama después de que el resumen de la tabla esté disponible (y dependiendo del parámetro de inicialización "summary_when"). $nrecords contiene el número de registros utilizados para calcular el informe y $row es una referencia a un array con el valor del resumen de la tabla. El array $row contiene tantos elementos como columnas tenga la tabla. Solo las columnas numéricas tendrán un valor allí, las demás se establecerán a undef.

Los valores del resumen son referencias a un hash que contienen los mismos valores que están disponibles en el evento handle_summary_value() de Lire::ReportParser.

handle_header_row( $row )

Se llamará una vez por cada fila de encabezado que exista. La primera fila de encabezado contiene todas las columnas numéricas, así como la columna categórica principal.

$row es una referencia a un array que contiene tantos elementos como columnas tenga la tabla. Las etiquetas de columna que no deberían aparecer en esta fila son undef. Los demás elementos contendrán el objeto Lire::Report::ColumnInfo relacionado.

handle_row( $row )

Este evento se llamará para cada fila que se deba mostrar en la tabla.

$row es una referencia a un array que contiene los datos que deberían aparecer en la fila. Contiene tantos elementos como columnas definidas en la tabla. Las columnas vacías tendrán undef como contenido. Los demás elementos serán una referencia a un hash idéntica a lo que se recibiría en el método handle_name() o handle_value() de Lire::ReportParser. La única diferencia es que el valor del resumen tendrá una clave "is_summary" establecida a 1.

En el caso de columnas que abarcan varias celdas, el elemento de datos estará en el elemento col_start(). Las otras celdas serán undef.
