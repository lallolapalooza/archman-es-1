List::UtilsBy(3) Documentación de Perl contribuida por el usuario List::UtilsBy(3)

NOMBRE

List::UtilsBy - funciones de utilidad de lista de orden superior

SINOPSIS

use List::UtilsBy qw( nsort_by min_by );
use File::stat qw( stat );
my @files_by_age = nsort_by { stat($_)->mtime } @files;
my $shortest_name = min_by { length } @names;

DESCRIPCIÓN

Este módulo proporciona una serie de funciones de utilidad de lista, todas las cuales toman un bloque de código inicial para controlar su comportamiento. Son variaciones de funciones principales de Perl o de "List::Util" con nombres similares, pero que usan el bloque para controlar su comportamiento. Por ejemplo, la función principal de Perl "sort" toma una lista de valores y los devuelve, ordenados según su valor de cadena. La función "sort_by" los ordena de acuerdo con el valor de cadena devuelto por la función adicional, cuando se le pasa cada valor.

my @names_sorted = sort @names;
my @people_sorted = sort_by { $_->name } @people;

FUNCIONES

Todas las funciones añadidas desde la versión 0.04 a menos que se indique lo contrario, ya que los nombres originales de versiones anteriores fueron renombrados.

sort_by

@vals = sort_by { KEYFUNC } @vals

Devuelve la lista de valores ordenados según los valores de cadena devueltos por el bloque o función "KEYFUNC". Un uso típico de esto puede ser ordenar objetos según el valor de cadena de algún accesor, como

sort_by { $_->name } @people

La función clave se llama en contexto escalar, pasándose cada valor por turno como $_ y como único argumento en los parámetros, @_. Los valores se ordenan luego según comparaciones de cadenas sobre los valores devueltos.

Esto es equivalente a

sort { $a->name cmp $b->name } @people

excepto que garantiza que el accesor "name" se ejecutará solo una vez por valor.

Un caso de uso interesante es ordenar cadenas que pueden tener números incrustados en ellas de forma "natural", en lugar de léxicamente.

sort_by { s/(\d+)/sprintf "%09d", $1/eg; $_ } @strings

Esto ordena cadenas generando claves de ordenación que rellenan con ceros los números incrustados hasta cierto nivel (9 dígitos en este caso), ayudando a asegurar que el ordenamiento léxico los coloque en el orden correcto.

nsort_by

@vals = nsort_by { KEYFUNC } @vals

Similar a "sort_by" pero compara sus valores clave numéricamente.

rev_sort_by

rev_nsort_by

@vals = rev_sort_by { KEYFUNC } @vals
@vals = rev_nsort_by { KEYFUNC } @vals

Desde la versión 0.06.

Similar a "sort_by" y "nsort_by" pero devuelve la lista en orden inverso. Equivalente a

@vals = reverse sort_by { KEYFUNC } @vals

excepto que estas funciones son un poco más eficientes porque evitan la operación final de "reverse".

max_by

$optimal = max_by { KEYFUNC } @vals
@optimal = max_by { KEYFUNC } @vals

Devuelve el (primer) valor de @vals que produce el resultado numéricamente mayor de la función clave.

my $tallest = max_by { $_->height } @people
use File::stat qw( stat );
my $newest = max_by { stat($_)->mtime } @files;

En contexto escalar, se devuelve el primer valor máximo. En contexto de lista, se devuelve una lista de todos los valores máximos. Esto puede usarse para obtener posiciones distintas de la primera, si el orden es significativo.

Si se llama en una lista vacía, se devuelve una lista vacía.

Para simetría con la función "nsort_by", esta también se proporciona bajo el nombre "nmax_by" ya que se comporta numéricamente.

min_by

$optimal = min_by { KEYFUNC } @vals
@optimal = min_by { KEYFUNC } @vals

Similar a "max_by" pero devuelve los valores que producen el resultado numéricamente menor de la función clave. También se proporciona como "nmin_by"

minmax_by

( $minimal, $maximal ) = minmax_by { KEYFUNC } @vals

Desde la versión 0.11.

Similar a llamar tanto a "min_by" como a "max_by" con la misma función clave en la misma lista. Esta versión es más eficiente que llamar a las dos funciones por separado, ya que tiene menos trabajo que realizar en general. En caso de empates, solo se devuelve el primer elemento óptimo encontrado en cada caso. También se proporciona como "nminmax_by".

uniq_by

@vals = uniq_by { KEYFUNC } @vals

Devuelve una lista del subconjunto de valores para los cuales el bloque de la función clave devuelve valores únicos. Se elige el primer valor que produce una clave particular, los valores subsiguientes se rechazan.

my @some_fruit = uniq_by { $_->colour } @fruit;

Para seleccionar en su lugar el último valor por clave, invierte la lista de entrada. Si el orden de los resultados es significativo, no olvides invertir el resultado también:

my @some_fruit = reverse uniq_by { $_->colour } reverse @fruit;

Dado que los valores devueltos por la función clave se utilizan como claves de hash, deberían ser cadenas, o al menos comportarse bien como cadenas (como números, o referencias de objetos que sobrecargan la representación de cadena de forma adecuada).

partition_by

%parts = partition_by { KEYFUNC } @vals

Devuelve una lista clave/valor de referencias ARRAY que contienen todos los valores originales distribuidos según el resultado del bloque de la función clave. Cada valor será una referencia ARRAY que contiene todos los valores que devolvieron la cadena de la función clave, en su orden original.

my %balls_by_colour = partition_by { $_->colour } @balls;

Dado que los valores devueltos por la función clave se utilizan como claves de hash, deberían ser cadenas, o al menos comportarse bien como cadenas (como números, o referencias de objetos que sobrecargan la representación de cadena de forma adecuada).

count_by

%counts = count_by { KEYFUNC } @vals

Desde la versión 0.07.

Devuelve una lista clave/valor de enteros, que indica el número de veces que el bloque de la función clave devolvió la clave, por cada valor de la lista.

my %count_of_balls = count_by { $_->colour } @balls;

Dado que los valores devueltos por la función clave se utilizan como claves de hash, deberían ser cadenas, o al menos comportarse bien como cadenas (como números, o referencias de objetos que sobrecargan la representación de cadena de forma adecuada).

zip_by

@vals = zip_by { ITEMFUNC } \@arr0, \@arr1, \@arr2,...

Devuelve una lista de cada uno de los valores devueltos por el bloque de función, cuando se invoca con valores de cada una de las referencias ARRAY dadas. Cada valor en la lista devuelta será el resultado de la función invocada con los argumentos en esa posición, de cada una de las listas dadas.

my @transposition = zip_by { [ @_ ] } @matrix;
my @names = zip_by { "$_[1], $_[0]" } \@firstnames, \@surnames;
print zip_by { "$_[0] => $_[1]\n" } [ keys %hash ], [ values %hash ];

Si algunas de las listas son más cortas que otras, la función se comportará como si tuvieran "undef" en las posiciones finales. Las dos líneas siguientes son equivalentes:

zip_by { f(@_) } [ 1, 2, 3 ], [ "a", "b" ]
f( 1, "a" ), f( 2, "b" ), f( 3, undef )

La función de ítem es llamada por "map", por lo que si devuelve una lista, la lista completa se incluye en el resultado. Esto puede ser útil, por ejemplo, para generar un hash a partir de dos listas separadas de claves y valores

List::UtilsBy(3pm) - Arch Linux Manual Pages

NAME

List::UtilsBy - functions that operate on lists of lists

SYNOPSIS

 use List::UtilsBy qw( zip_by unzip_by extract_by extract_first_by weighted_shuffle_by bundle_by );

 my %hash = zip_by { @_ } [qw( a b c )], [ 1 2 3 ];
 # %hash = ( a => 1, b => 2, c => 3 )

 my ( $fnames, $lnames ) = unzip_by { m/^(.*?) (.*)$/ } @names;

 my @red_items = extract_by { $_->color eq "red" } @items;

 my $first_red = extract_first_by { $_->color eq "red" } @items;

 my @shuffled = weighted_shuffle_by { $_->priority } @items;

 my @bundles = bundle_by { join '-', @_ } 2, @items;

DESCRIPTION

This module provides a collection of functions that operate on lists, that you may find useful.

Many of these functions are generalisations of functions found in other list utility modules, or are analogues of functions found in functional programming languages.

FUNCTIONS

zip_by

$hashref = zip_by BLOCK, LIST1, LIST2, ...
%hash = zip_by BLOCK, LIST1, LIST2, ...

Takes a list of lists, and returns a hash reference, where the keys of the hash are the elements of the first list, and the values are the corresponding elements of the second list, and so on. The block is executed for each corresponding set of elements, and its return value is used as the value in the hash.

my %nums = zip_by { @_ } [qw( one two three )], [ 1, 2, 3 ];
# %nums = ( one => 1, two => 2, three => 3 )

(A function having this behaviour is sometimes called "zipWith", e.g. in Haskell, but that name would not fit the naming scheme used by this module).

unzip_by

$arr0, $arr1, $arr2, ... = unzip_by { ITEMFUNC } @vals

Since version 0.09.

Returns a list of ARRAY references containing the values returned by the function block, when invoked for each of the values given in the input list. Each of the returned ARRAY references will contain the values returned at that corresponding position by the function block. That is, the first returned ARRAY reference will contain all the values returned in the first position by the function block, the second will contain all the values from the second position, and so on.

my ( $firstnames, $lastnames ) = unzip_by { m/^(.*?) (.*)$/ } @names;

If the function returns lists of differing lengths, the result will be padded with "undef" in the missing elements.

This function is an inverse of "zip_by", if given a corresponding inverse function.

extract_by

@vals = extract_by { SELECTFUNC } @arr

Since version 0.05.

Removes elements from the referenced array on which the selection function returns true, and returns a list containing those elements. This function is similar to "grep", except that it modifies the referenced array to remove the selected values from it, leaving only the unselected ones.

my @red_balls = extract_by { $_->color eq "red" } @balls;
# Now there are no red balls in the @balls array

This function modifies a real array, unlike most of the other functions in this module. Because of this, it requires a real array, not just a list.

This function is implemented by invoking "splice" on the array, not by constructing a new list and assigning it. One result of this is that weak references will not be disturbed.

extract_by { !defined $_ } @refs;

will leave weak references weakened in the @refs array, whereas

@refs = grep { defined $_ } @refs;

will strengthen them all again.

extract_first_by

$val = extract_first_by { SELECTFUNC } @arr

Since version 0.10.

A hybrid between "extract_by" and "List::Util::first". Removes the first element from the referenced array on which the selection function returns true, returning it.

As with "extract_by", this function requires a real array and not just a list, and is also implemented using "splice" so that weak references are not disturbed.

If this function fails to find a matching element, it will return an empty list in list context. This allows a caller to distinguish the case between no matching element, and the first matching element being "undef".

weighted_shuffle_by

@vals = weighted_shuffle_by { WEIGHTFUNC } @vals

Since version 0.07.

Returns the list of values shuffled into a random order. The randomisation is not uniform, but weighted by the value returned by the "WEIGHTFUNC". The probability of each item being returned first will be distributed with the distribution of the weights, and so on recursively for the remaining items.

bundle_by

@vals = bundle_by { BLOCKFUNC } $number, @vals

Since version 0.07.

Similar to a regular "map" functional, returns a list of the values returned by "BLOCKFUNC". Values from the input list are given to the block function in bundles of $number.

If given a list of values whose length does not evenly divide by $number, the final call will be passed fewer elements than the others.

EXAMPLES

As many of these functions both take and return lists of values, more useful behaviours can be created by combining them together.

Modal Value

To pick the modal value in a list (i.e. the value that appears most frequently according to some key function) combine "count_by" and "max_by":

my %counts = count_by { KEYFUNC } ITEMS;
my $modal = max_by { $counts{$_} } keys %counts;

This can be performed in a single step by use of the "pairs" function from List::Util:

use List::Util qw( pairs );
my $modal = ( max_by { $_->value } pairs count_by { KEYFUNC } ITEMS )->key;
