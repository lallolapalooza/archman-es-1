Locale::Maketext::Extract::Plugin::TextTemplate(3) Documentación de Contribución de Usuarios de Perl Locale::Maketext::Extract::Plugin::TextTemplate(3)

NOMBRE

Locale::Maketext::Extract::Plugin::TextTemplate - Analizador de formato Text::Template

VERSIÓN

versión 1.00

SINOPSIS

$plugin = Locale::Maketext::Extract::Plugin::TextTemplate->new(
    $lexicon            # Un objeto Locale::Maketext::Extract
    @tipos_archivo         # Opcionalmente especificar una lista de tipos de archivo reconocidos
)
$plugin->extract($nombre_archivo,$contenido_archivo);

DESCRIPCIÓN

Extrae cadenas para localizar de archivos Text::Template.

NOMBRE CORTO DEL PLUGIN

text

FORMATOS VÁLIDOS

Las oraciones entre STARTxxx y ENDxxx se extraen individualmente.

TIPOS DE ARCHIVO CONOCIDOS

Todos los tipos de archivo

VER TAMBIÉN

xgettext.pl
para extraer cadenas traducibles de sistemas de plantillas comunes y archivos de código fuente de perl.
