NOMBRE

Locale::RecodeData::KOI_8 - Rutinas de conversión para KOI-8

SINOPSIS

Este módulo es interno de libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas y rutinas de conversión para KOI-8.
