NOMBRE

Lire::Firewall::WatchguardDlfConverter - convierte registros de Watchguard a DLF de firewall

DESCRIPCIÓN

Lire::Firewall::WatchguardDlfConverter convierte registros de Watchguard al formato DLF de firewall. La entrada para este conversor es el archivo de registro syslog estándar de Watchguard.

AUTOR

Wessel Dankers <wsl@logreport.org>

Código inicial de Joost Bekkers <joost@jodocus.org>, ahora mantenido por el equipo de LogReport. Basado en el script cisco_ios2dlf.in.

VER TAMBIÉN

El sitio web de WatchGuard en http://www.watchguard.com/ para obtener información sobre el sistema WatchGuard Firebox. Desafortunadamente, solo hay muy poca información disponible libremente.
