NOMBRE

Locale::Po4a::Xhtml - convierte documentos XHTML desde/hacia archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y lo que es más interesante, el mantenimiento de las traducciones) utilizando las herramientas de gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::Xhtml es un módulo para ayudar a la traducción de documentos XHTML a otros idiomas [humanos].

OPCIONES ACEPTADAS POR ESTE MÓDULO

Estas son las opciones particulares de este módulo:

includessi[=ruta_base]
Incluye archivos especificados por un elemento de inclusión SSI (Server Side Includes) (por ejemplo, <!--#include virtual="/foo/bar.html" -->).

Nota: Solo debes usarlo para archivos estáticos.

Se puede especificar un parámetro adicional de ruta_base. Especifica la ruta base para encontrar los archivos incluidos por un atributo virtual.

ESTADO DE ESTE MÓDULO

Este módulo es totalmente funcional, ya que se basa en el módulo Locale::Po4a::Xml. Este solo define las etiquetas y atributos traducibles.

"Funciona para mí", lo que significa que lo uso con éxito en mi sitio web personal. Sin embargo, tu experiencia puede variar: por favor, házmelo saber si algo no funciona para ti.
