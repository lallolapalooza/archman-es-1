NOMBRE

Lire::Config::Build - Busca información en tiempo de compilación

SINOPSIS

Este módulo proporciona información en tiempo de compilación al módulo de configuración. Está destinado principalmente a ser utilizado internamente por el módulo de configuración, pero también puede ser utilizado en otros lugares. Considere usar la configuración adecuada, ya que el usuario puede desear anular ciertos parámetros.
