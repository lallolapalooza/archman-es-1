NAME

Locale::RecodeData::IBM420 — Charset data for IBM420 (Arabic)

SYNOPSIS

 use Locale::RecodeData::IBM420;

DESCRIPTION

The Locale::RecodeData::IBM420 module provides the character mapping table for the IBM420 (Arabic) character set.

This module is intended to be used by the Locale::Recode module.

The IBM420 character set is also known as the Arabic ISO 8859-6 character set.

COMMENTS

The following characters are not part of the standard IBM420 character set and have been mapped to sensible defaults:

  • 00000000: Null character (NUL)
  • 00000001: Start of Heading (SOH)
  • 00000002: Start of Text (STX)
  • 00000003: End of Text (ETX)
  • 00000004: End of Transmission (EOT)
  • 00000005: Enquiry (ENQ)
  • 00000006: Acknowledge (ACK)
  • 00000007: Bell (BEL)
  • 00000008: Backspace (BS)
  • 0000000B: Vertical Tab (VT)
  • 0000000C: Form Feed (FF)
  • 0000000E: Shift Out (SO)
  • 0000000F: Shift In (SI)
  • 00000010: Data Link Escape (DLE)
  • 00000011: Device Control 1 (DC1)
  • 00000012: Device Control 2 (DC2)
  • 00000013: Device Control 3 (DC3)
  • 00000014: Device Control 4 (DC4)
  • 00000015: Negative Acknowledge (NAK)
  • 00000016: Synchronous Idle (SYN)
  • 00000017: End of Transmission Block (ETB)
  • 00000018: Cancel (CAN)
  • 00000019: End of Medium (EM)
  • 0000001A: Substitute (SUB)
  • 0000001B: Escape (ESC)
  • 0000001C: File Separator (FS)
  • 0000001D: Group Separator (GS)
  • 0000001E: Record Separator (RS)
  • 0000001F: Unit Separator (US)
  • 0000007F: Delete (DEL)
