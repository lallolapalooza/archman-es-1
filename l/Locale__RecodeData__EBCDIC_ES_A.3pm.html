Locale::RecodeData::EBCDIC_ES_A(3) Páginas del manual de Perl contribuidas por el usuario Locale::RecodeData::EBCDIC_ES_A(3)

NOMBRE

Locale::RecodeData::EBCDIC_ES_A - Rutinas de conversión para EBCDIC_ES_A

SINTAXIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo está generado y contiene las tablas de conversión y rutinas para EBCDIC-ES-A.

COMENTARIOS

Los siguientes comentarios se han extraído del archivo charmap original:

versión: 1.0
 fuente: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, abril 1987

¡Por favor, ten en cuenta que los alias mencionados anteriormente no son necesariamente válidos!
