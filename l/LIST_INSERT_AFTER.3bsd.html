DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden ser utilizadas tanto en código fuente C como C++:

  1. Listas
  2. Listas enlazadas simples
  3. Colas finales enlazadas simples
  4. Colas finales
Las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de un nuevo elemento al principio de la lista.
  2. Inserción de un nuevo elemento después de cualquier elemento de la lista.
  3. Eliminación en O(1) de un elemento del principio de la lista.
  4. Recorrido hacia adelante a través de la lista.
  5. Intercambio del contenido de dos listas.

Las listas enlazadas simples son las más sencillas de las cuatro estructuras de datos y solo soportan la funcionalidad anterior. Las listas enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola LIFO. Las listas enlazadas simples añaden la siguiente funcionalidad:

  1. Eliminación en O(n) de cualquier elemento de la lista.
  2. Concatenación en O(n) de dos listas.

Las colas finales enlazadas simples añaden la siguiente funcionalidad:

  1. Los elementos pueden ser añadidos al final de una lista.
  2. Eliminación en O(n) de cualquier elemento de la lista.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones en la lista deben especificar la cabeza de la lista.
  2. Cada elemento de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que las listas enlazadas simples.

Las colas finales enlazadas simples son ideales para aplicaciones con grandes conjuntos de datos y pocas o ninguna eliminación, o para implementar una cola FIFO.

Todos los tipos de estructuras de datos enlazadas doblemente (listas y colas finales) permiten adicionalmente:

  1. Inserción de un nuevo elemento antes de cualquier elemento de la lista.
  2. Eliminación en O(1) de cualquier elemento de la lista.
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que el de las estructuras de datos enlazadas simples.

Las listas enlazadas son las más sencillas de las estructuras de datos enlazadas doblemente. Añaden la siguiente funcionalidad sobre las anteriores:

  1. Concatenación en O(n) de dos listas.
  2. Pueden ser recorridas hacia atrás.
Sin embargo:
  1. Para recorrer hacia atrás, se debe especificar un elemento para iniciar el recorrido y la lista en la que está contenido.

Las colas finales añaden la siguiente funcionalidad:

  1. Los elementos pueden ser añadidos al final de una lista.
  2. Pueden ser recorridas hacia atrás, de cola a cabeza.
  3. Pueden ser concatenadas.
Sin embargo:
  1. Todas las inserciones y eliminaciones de listas deben especificar la cabeza de la lista.
  2. Cada elemento de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente un 15% mayor y las operaciones se ejecutan aproximadamente un 20% más lento que las listas enlazadas simples.

En las definiciones de las macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME que sea de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de las macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME que sea de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse utilizando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Consulte los ejemplos a continuación para obtener más explicaciones sobre cómo se utilizan estas macros.

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple está encabezada por una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados simplemente para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación en O(n) para elementos arbitrarios. Se pueden añadir nuevos elementos a la lista después de un elemento existente o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista puede ser declarado posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todos los elementos del primero. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe utilizar una cola final enlazada simple si se necesita esta macro en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_EMPTY se evalúa como verdadera si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí se permite eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento en la lista después del elemento elm.

La macro SLIST_REMOVE elimina el elemento elm de la lista.

La macro SLIST_SWAP intercambia el contenido de las listas head1 y head2.

COLAS FINALES

Una cola final es una lista doblemente enlazada con un puntero al primer y al último elemento de la lista. Las colas finales son adecuadas para implementar colas FIFO. La estructura de cola final se define con la macro TAILQ_HEAD. La macro TAILQ_HEAD define una estructura que contendrá un puntero al primer y al último elemento de la lista.

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista puede ser declarado posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la lista head.

La macro TAILQ_CONCAT concatena la cola final encabezada por head2 al final de la encabezada por head1. Todos los elementos son eliminados de la segunda cola final.

La macro TAILQ_EMPTY evalúa como verdadera si no hay elementos en la cola final.

La macro TAILQ_ENTRY define una estructura que contiene los punteros de enlace necesarios para las colas finales.

La macro TAILQ_FIRST devuelve el primer elemento de la cola final, o NULL si la cola final está vacía.

La macro TAILQ_FOREACH recorre la cola final referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la TAILQ referenciada por head.

La macro TAILQ_FOREACH_SAFE recorre la cola final referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de TAILQ_FOREACH, aquí se permite eliminar var así como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la TAILQ referenciada por head.

La macro TAILQ_INIT inicializa la cola final referenciada por head.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola final.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola final.

La macro TAILQ_LAST devuelve el último elemento de la cola final.

La macro TAILQ_NEXT devuelve el siguiente elemento en la cola final después del elemento elm.

La macro TAILQ_PREV devuelve el elemento anterior en la cola final antes del elemento elm.

La macro TAILQ_REMOVE elimina el elemento elm de la cola final.

La macro TAILQ_SWAP intercambia el contenido de las colas finales head1 y head2.

LISTAS

LIST_HEAD(HEADNAME, TYPE) head;

La macro LIST_EMPTY evalúa como verdadera si no hay elementos en la lista.

La macro LIST_ENTRY define una estructura que contiene los punteros de enlace necesarios para las listas.

EJEMPLOS

Las siguientes definiciones crean una lista enlazada simple de estructuras `foo` llamadas `my_list_head` y un puntero a ella llamado `listp`.

typedef struct foo {
        int data;
        SLIST_ENTRY(foo) next;
} foo_t;

SLIST_HEAD(my_list_head, foo);
my_list_head *listp;

A continuación se muestra un ejemplo de cómo inicializar la lista, insertar elementos en ella, recorrerla y eliminar elementos.

#include <stdio.h>

#include <sys/queue.h>

typedef struct foo {
        int data;
        SLIST_ENTRY(foo) next;
} foo_t;

SLIST_HEAD(my_list_head, foo);

int
main(void)
{
        foo_t *elem, *temp;
        struct my_list_head list;

        SLIST_INIT(&list);

        elem = malloc(sizeof(foo_t));
        elem->data = 1;
        SLIST_INSERT_HEAD(&list, elem, next);

        elem = malloc(sizeof(foo_t));
        elem->data = 2;
        SLIST_INSERT_HEAD(&list, elem, next);

        elem = malloc(sizeof(foo_t));
        elem->data = 3;
        SLIST_INSERT_TAIL(&list, elem, next);

        printf("List contents:\n");
        SLIST_FOREACH(elem, &list, next) {
                printf("data = %d\n", elem->data);
        }

        printf("Removing elements:\n");
        while (!SLIST_EMPTY(&list)) {
                elem = SLIST_FIRST(&list);
                SLIST_REMOVE_HEAD(&list, next);
                printf("Removed element with data = %d\n", elem->data);
                free(elem);
        }

        return (0);
}

LISTAS ENLAZADAS SIMPLES

Una lista enlazada simple se encabeza mediante una estructura definida por la macro SLIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la lista después de un elemento existente, o al principio de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir y TYPE es el tipo de los elementos que se van a enlazar en la lista. Más tarde, se puede declarar un puntero a la cabeza de la lista como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí está permitido eliminar var así como liberarlo del interior del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista referenciada por head.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_NEXT devuelve el siguiente elemento en la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm de la cabeza de la lista. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe utilizar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación desde el principio. */
free(n3);

NAME

queue — macros for implementing queues and lists

LIBRARY

libbsd

SYNOPSIS

#include <sys/queue.h>

struct typehead head;

struct typename *elm, *n;

DESCRIPTION

These macros provide support for implementing singly and doubly linked lists and queues.

SINGLY-LINKED LISTS

The singly linked list implementation uses the following macros:

LIST_HEAD(name, type)
Declares a singly linked list head of the specified type named name.
LIST_HEAD_INITIALIZER(head)
Initializes a singly linked list head named head.
LIST_INIT(head)
Initializes a singly linked list head named head.
LIST_ENTRY(type)
Declares a singly linked list entry for the specified type. This macro is used inside the struct definition of the elements that will be stored in the list.
LIST_INSERT_AFTER(listelm, elm, field)
Inserts the element elm after listelm in the list. field is the name of the LIST_ENTRY field in the structure.
LIST_INSERT_BEFORE(listelm, elm, field)
Inserts the element elm before listelm in the list. field is the name of the LIST_ENTRY field in the structure.
LIST_INSERT_HEAD(head, elm, field)
Inserts the element elm at the head of the list. field is the name of the LIST_ENTRY field in the structure.
LIST_INSERT_TAIL(head, elm, field)
Inserts the element elm at the tail of the list. field is the name of the LIST_ENTRY field in the structure.
LIST_REMOVE(elm, field)
Removes the element elm from the list. field is the name of the LIST_ENTRY field in the structure.
LIST_SORT(head, comp, field)
Sorts the list using the comparison function comp. field is the name of the LIST_ENTRY field in the structure.
LIST_FIND(head, find, comp, field)
Finds an element in the list using the comparison function comp. The search starts from the head of the list. find is the element to search for. field is the name of the LIST_ENTRY field in the structure.
LIST_FIND_TRAVERSE(head, find, comp, field)
Finds an element in the list using the comparison function comp. The search starts from the head of the list and traverses the list. find is the element to search for. field is the name of the LIST_ENTRY field in the structure.
LIST_NEXT(elm, field)
Returns the next element in the list after elm. field is the name of the LIST_ENTRY field in the structure.
LIST_FIRST(head)
Returns the first element in the list. head is the list head.
LIST_LAST(head)
Returns the last element in the list. head is the list head.
LIST_EMPTY(head)
Returns true if the list is empty. head is the list head.
LIST_FOREACH(head, elm, field)
Iterates over the list. elm will be set to each element in the list in turn. field is the name of the LIST_ENTRY field in the structure.
LIST_SWAP(head1, head2, type)
Swaps the contents of two lists. type is the type of the list elements.

SINGLY-LINKED LIST EXAMPLE

struct my_list_entry {
    int data;

SINGLY-LINKED TAIL QUEUES

The singly linked tail queue implementation uses the following macros:

SLIST_HEAD(name, type)
Declares a singly linked tail queue head of the specified type named name.
SLIST_HEAD_INITIALIZER(head)
Initializes a singly linked tail queue head named head.
SLIST_INIT(head)
Initializes a singly linked tail queue head named head.
SLIST_ENTRY(type)
Declares a singly linked tail queue entry for the specified type. This macro is used inside the struct definition of the elements that will be stored in the queue.
SLIST_INSERT_AFTER(listelm, elm, field)
Inserts the element elm after listelm in the queue. field is the name of the SLIST_ENTRY field in the structure.
SLIST_INSERT_HEAD(head, elm, field)
Inserts the element elm at the head of the queue. field is the name of the SLIST_ENTRY field in the structure.
SLIST_INSERT_TAIL(head, elm, field)
Inserts the element elm at the tail of the queue. field is the name of the SLIST_ENTRY field in the structure.
SLIST_REMOVE(head, elm, type, field)
Removes the element elm from the queue. type is the type of the elements in the queue. field is the name of the SLIST_ENTRY field in the structure.
SLIST_REMOVE_HEAD(head, field)
Removes and returns the head element from the queue. field is the name of the SLIST_ENTRY field in the structure.
SLIST_NEXT(elm, field)
Returns the next element in the queue after elm. field is the name of the SLIST_ENTRY field in the structure.
SLIST_FIRST(head)
Returns the first element in the queue. head is the queue head.
SLIST_EMPTY(head)
Returns true if the queue is empty. head is the queue head.
SLIST_FOREACH(head, elm, field)
Iterates over the queue. elm will be set to each element in the queue in turn. field is the name of the SLIST_ENTRY field in the structure.
SLIST_SWAP(head1, head2, type)
Swaps the contents of two queues. type is the type of the queue elements.

DIAGNOSTICS

When debugging queue(3), it can be useful to trace queue changes. To enable tracing, define the macro QUEUE_MACRO_DEBUG_TRACE at compile time.

It can also be useful to trash pointers that have been unlinked from a queue, to detect use after removal. To enable pointer trashing, define the macro QUEUE_MACRO_DEBUG_TRASH at compile time. The macro QMD_IS_TRASHED(void *ptr) returns true if ptr has been trashed by the QUEUE_MACRO_DEBUG_TRASH option.
