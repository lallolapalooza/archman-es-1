NOMBRE

Locale::RecodeData::ISO_8859_16 - Rutinas de conversión para ISO-8859-16

SINOPSIS

Este módulo es interno a libintl. ¡No lo use directamente!

DESCRIPCIÓN

Este módulo contiene la tabla de conversión y rutinas para ISO-8859-16.

COMENTARIOS

Las siguientes observaciones se extraen del charmap original:

generado automáticamente desde charDB
alias ISO-IR-226
alias LATIN10
alias L10

¡Por favor, tenga en cuenta que los alias mencionados arriba no son necesariamente válidos!

NAME


Locale::RecodeData::ISO_8859_16 - ISO-8859-16 (Latin-10)
    character set






SYNOPSIS


 use Encode::Locale;






DESCRIPTION


This module provides the definition for the ISO-8859-16 (Latin-10)
    character set.


ISO-8859-16 is an 8-bit character set containing characters for
    languages like Albanian, Bosnian, Croatian, Finnish, Latvian, Lithuanian,
    Macedonian, Maltese, Norwegian, Romanian, Serbian, Slovak, Slovenian,
    Swedish, and Turkish.


For details, see the ISO-8859-16
    standard.






COMMENTS


This module is part of the libintl-perl
    package.
