LIST(3) Manual de funciones de biblioteca LIST(3)

NOMBRE

LIST_EMPTY, LIST_ENTRY, LIST_FIRST, LIST_FOREACH, LIST_HEAD, LIST_HEAD_INITIALIZER, LIST_INIT, LIST_INSERT_AFTER, LIST_INSERT_BEFORE, LIST_INSERT_HEAD, LIST_NEXT, LIST_REMOVE - implementación de una lista doblemente enlazada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/queue.h>
LIST_ENTRY(TIPO);
LIST_HEAD(NOMBRECABECERA, TIPO);
LIST_HEAD NOMBRECABECERA_INITIALIZER(LIST_HEAD cabecera);
void LIST_INIT(LIST_HEAD *cabecera);
int LIST_EMPTY(LIST_HEAD *cabecera);
void LIST_INSERT_HEAD(LIST_HEAD *cabecera,
                        struct TIPO *elem, LIST_ENTRY NOMBRE);
void LIST_INSERT_BEFORE(struct TIPO *elem_lista,
                        struct TIPO *elem, LIST_ENTRY NOMBRE);
void LIST_INSERT_AFTER(struct TIPO *elem_lista,
                        struct TIPO *elem, LIST_ENTRY  NOMBRE);
struct TIPO *LIST_FIRST(LIST_HEAD *cabecera);
struct TIPO *LIST_NEXT(struct TIPO *elem, LIST_ENTRY  NOMBRE);
LIST_FOREACH(struct TIPO *var, LIST_HEAD *cabecera, LIST_ENTRY  NOMBRE);
void LIST_REMOVE(struct TIPO *elem, LIST_ENTRY  NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas doblemente enlazadas.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo LIST_ENTRY, llamado NOMBRE. El argumento NOMBRECABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro LIST_HEAD().

Creación

Una lista está encabezada por una estructura definida por la macro LIST_HEAD(). Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están doblemente enlazados de modo que un elemento arbitrario puede eliminarse sin recorrer la lista. Se pueden añadir nuevos elementos a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:


LIST_HEAD(NOMBRECABECERA, TIPO) cabecera;

donde struct NOMBRECABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabecera de la lista puede declararse posteriormente como:


struct NOMBRECABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario.)

LIST_ENTRY() declara una estructura que conecta los elementos de la lista.

LIST_HEAD_INITIALIZER() se evalúa como un inicializador para la lista cabecera.

LIST_INIT() inicializa la lista referenciada por cabecera.

LIST_EMPTY() se evalúa como verdadero si no hay elementos en la lista.

Inserción

LIST_INSERT_HEAD() inserta el nuevo elemento elem al principio de la lista.

LIST_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elem_lista.

LIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

LIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

LIST_NEXT() devuelve el siguiente elemento de la lista, o NULL si es el último.

LIST_FOREACH() recorre la lista referenciada por cabecera en dirección hacia adelante, asignando cada elemento en su turno a var.

Eliminación

LIST_REMOVE() elimina el elemento elem de la lista.

VALOR DE RETORNO

LIST_EMPTY() devuelve distinto de cero si la lista está vacía, y cero si la lista contiene al menos una entrada.

LIST_FIRST() y LIST_NEXT() devuelven un puntero a la estructura TIPO primera o siguiente, respectivamente.

LIST_HEAD_INITIALIZER() devuelve un inicializador que se puede asignar a la lista cabecera.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

ERRORES

LIST_FOREACH() no permite que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. LIST_FOREACH_SAFE(), que está presente en los BSD pero no en glibc, soluciona esta limitación al permitir que var se elimine de forma segura de la lista y se libere desde dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    LIST_ENTRY(entrada) entradas;              /* Lista */
};
LIST_HEAD(cabeceradelista, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabeceradelista cabeza;                   /* Cabecera de lista */
    int i;
    LIST_INIT(&cabeza);                       /* Inicializar la lista */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al principio */
    LIST_INSERT_HEAD(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    LIST_INSERT_AFTER(n1, n2, entradas);
    n3 = malloc(sizeof(struct entrada));      /* Insertar antes */
    LIST_INSERT_BEFORE(n2, n3, entradas);
    i = 0;                                  /* Recorrido hacia adelante */
    LIST_FOREACH(np, &cabeza, entradas)
        np->datos = i++;
    LIST_REMOVE(n2, entradas);               /* Borrado */
    free(n2);
                                            /* Recorrido hacia adelante */
    LIST_FOREACH(np, &cabeza, entradas)
        printf("%i\n", np->datos);
                                            /* Borrado de lista */
    n1 = LIST_FIRST(&cabeza);
    while (n1 != NULL) {
        n2 = LIST_NEXT(n1, entradas);
        free(n1);
        n1 = n2;
    }
    LIST_INIT(&cabeza);
    exit(EXIT_SUCCESS);
}
