NOMBRE

Locale::RecodeData::IBM284 - Funciones de conversión para IBM284

SINOPSIS

Este módulo es interno de libintl. ¡No lo use directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas de conversión y rutinas para IBM284.

COMENTARIOS

Los siguientes comentarios se extrajeron del original charmap:

versión: 1.0
 fuente: IBM NLS RM Vol2 SE09-8002-01, Marzo 1990
 alias CP284
 alias EBCDIC-CP-ES

¡Nota: Los alias mencionados anteriormente no son necesariamente válidos!

Locale::RecodeData::IBM284(3pm)

NAME

Locale::RecodeData::IBM284 - Encoding IBM284

SYNOPSIS

    use Locale::RecodeData "IBM284";

DESCRIPTION

This module provides the IBM284 character set to the Locale::Recode module.

IBM284 is a character set from IBM's code page series, used primarily on mainframe systems.

COMMENTS

This module is part of the libintl-perl package.
