SINOPSIS

¡Este módulo es interno a libintl! ¡No lo use directamente!

DESCRIPCIÓN

Este módulo está generado y contiene las tablas y rutinas de conversión para IBM285.

COMENTARIOS

Los siguientes comentarios han sido extraídos del mapacarácter original:

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP285
alias EBCDIC-CP-GB

¡Tenga en cuenta que los alias enumerados anteriormente no son necesariamente válidos!

NOMBRE


Locale::RecodeData::IBM285






SYNOPSIS


use Locale::RecodeData::IBM285;






DESCRIPCIÓN


Locale::RecodeData::IBM285 es un módulo que contiene la tabla de caracteres para el sistema de codificación IBM285. Esta tabla se utiliza para recodificar strings en formato ASCII en otros formatos de codificación.






COMENTARIOS


Esta tabla de caracteres está diseñada para ser utilizada en sistemas que requieren recodificación de texto en formato ASCII a otros formatos. El módulo proporciona una manera eficiente de manejar esta conversión mediante la utilización de funciones predefinidas.
