NOMBRE

Lire::ReportParser::HTMLDocBookFormatter - subclase de Lire::ReportParser que formatea la descripción.

SINOPSIS

Para formatear DocBook:

use Lire::ReportParser::HTMLDocBookFormatter qw/dbk2html/;
my $txt = dbk2html( "<para>Prueba</para>" );

En procesadores de informes XML:

package MyParser;
use base qw/ Lire::ReportParser::HTMLDocBookFormatter Lire::ReportParser /;
sub new {
    my $self = shift->SUPER::new( @_ );
    $self->init_docbook_formatter( @_ );
    return $self;
}
sub handle_description {
    my ( $self, $desc ) = @_;
    print $desc;
    return;
}

DESCRIPCIÓN

Lire::ReportParser::HTMLDocBookFormatter es la contraparte de Lire::ReportParser::AsciiDocBookFormatter para el formato de salida HTML. Por favor, lee su documentación para aprender a usar esta clase. Su uso es exactamente el mismo.

dbk2html( $docbook_str, [$columns], [$xhtml] )

Devuelve una versión HTML del fragmento XML DocBook $docbook_str. El parámetro "columns" establece el número de columnas en las que se debe formatear el texto HTML de DocBook. El parámetro "xhtml" define si el código generado cumplirá con XHTML; el valor predeterminado es sí.

Este método morirá() en caso de error.

VER TAMBIÉN
