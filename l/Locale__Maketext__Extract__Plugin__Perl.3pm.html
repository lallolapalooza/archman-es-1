NOMBRE

Locale::Maketext::Extract::Plugin::Perl - Analizador de formato Perl

VERSIÓN

versión 1.00

SINOPSIS

$plugin = Locale::Maketext::Extract::Plugin::Perl->new(
    $lexicon            # Un objeto Locale::Maketext::Extract
    @file_types         # Opcionalmente especifica una lista de tipos de archivo reconocidos
)
$plugin->extract($filename,$filecontents);

DESCRIPCIÓN

Extrae cadenas a localizar (incluyendo HEREDOCS y cadenas concatenadas) del código Perl.

Este analizador de Perl es muy rápido y muy bueno, pero no perfecto; comete errores. El analizador PPI (Locale::Maketext::Extract::Plugin::PPI) es más preciso, pero mucho más lento, y por lo tanto no está habilitado por defecto.
