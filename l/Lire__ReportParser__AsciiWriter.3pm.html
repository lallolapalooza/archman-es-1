NOMBRE

Lire::ReportParser::AsciiWriter - Procesador de Lire::ReportParser que formatea el informe en ASCII

SINOPSIS

use Lire::ReportParser::AsciiWriter;
my $parser = new Lire::ReportParser::AsciiWriter;
eval { $parser->parsefile( "report.xml" ) };
print "Fallo al analizar: $@" if $@;

DESCRIPCIÓN

Este es un procesador de Lire::ReportParser que imprimirá el Informe XML de Lire en ASCII en STDOUT.

Su constructor acepta los siguientes parámetros:

columnas
El número de columnas para las que se debe formatear el informe. Por defecto es 80.
max_name_length
El número máximo de caracteres que se conservarán en el elemento de nombre. Por defecto es 180.
userlevel
En la descripción, el nivel máximo de elementos que se mostrarán. Por defecto es "normal" (es decir, los elementos "avanzados" no se formatean).
