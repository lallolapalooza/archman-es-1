PluginManager(3pm) Documentación de Lire para LogReport PluginManager(3pm)

NOMBRE

Lire::PluginManager - Gestiona los plugins de Lire.

SINOPSIS

use Lire::PluginManager;
Lire::PluginManager->register_default_plugins();
my $plugin = new MyDlfConverter();
Lire::PluginManager->register_plugin( $plufin );
my $plugins = Lire::PluginManager->plugins( 'dlf_analyser' );
my $converter = Lire::PluginManager->get_plugin('dlf_analyser', 'combined');

DESCRIPCIÓN

Todos los métodos se pueden llamar como métodos de clase en el módulo Lire::PlugingManager o en una instancia.

TIPOS DE PLUGINS

Hay cuatro tipos de plugins definidos en Lire: dlf_analyser, dlf_converter, chart_type y output_format.

instance()

Devuelve la instancia singleton del PluginManager

plugin_names( $type )

Devuelve una referencia de array que contiene los nombres de todos los plugins registrados de tipo $type.

plugins( $type )

Devuelve una referencia de array que contiene todos los objetos Plugin registrados para $type.

has_plugin( $type, $name )

Devuelve verdadero si existe un plugin de Lire llamado $name registrado para el tipo $type.

get_plugin( $type, $name )

Devuelve el objeto Lire::Plugin llamado $name de tipo $type. Da un error cuando no hay ningún plugin registrado bajo ese nombre.

register_plugin( $plugin )

Registra el Lire::Plugin $plugin. El tipo y el nombre del plugin se consultan usando la interfaz Lire::Plugin. Se lanzará un error si ya hay un plugin registrado con el mismo nombre y tipo.

unregister_plugin( $type, $name )

Anula el registro del plugin $name de tipo $type. El método fallará si no existe dicho plugin.

analysers_by_src( $schema )

Devuelve en una referencia de array todos los analizadores que declaran $schema como su src_schema().

analysers_by_dst( $schema )

Devuelve en una referencia de array todos los analizadores que declaran $schema como su dst_schema().

register_default_plugins()

Este método cargará e inicializará todos los plugins disponibles. Los plugins se registran ejecutando todos los scripts de perl que se encuentren en los directorios listados en la variable de configuración 'plugins_init_path'.

Estos scripts deberían llamar a Lire::PluginManager->register_plugin() para registrar los plugins.

Para compatibilidad con versiones anteriores de Lire, también registrará los DlfConverters inicializados usando mecanismos más antiguos.

VER TAMBIÉN

Lire::Plugin(3pm), Lire::OutputFormat(3pm), Lire::DlfAnalyser(3pm), Lire::DlfConverter(3pm)
