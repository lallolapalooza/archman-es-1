NAME

Locale::RecodeData::ISO_8859_2 - Rutinas de conversión para ISO-8859-2

SYNOPSIS

Este módulo es interno de libintl. No lo use directamente!

DESCRIPTION

Este módulo está generado y contiene las tablas de conversión y rutinas para ISO-8859-2.

COMMENTS

Las siguientes observaciones se extrajeron de la original charmap:

versión: 1.0
 fuente: registro ECMA
 alias ISO-IR-101
 alias ISO_8859-2:1987
 alias ISO_8859-2
 alias LATIN2
 alias L2

Nota: los alias mencionados arriba no necesariamente son válidos!
