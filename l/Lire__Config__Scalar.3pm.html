NOMBRE

Lire::Config::Scalar - Contenedor de configuración de Lire para valores escalares

SINOPSIS

use Lire::Config::Scalar

DESCRIPCIÓN

Este paquete contiene la clase para representar un escalar en una configuración real.

Lire::Config::Scalar

Contenedor de valor para valores escalares. Implementa métodos simples para get() y set() datos de cadena.

get()

Devuelve el valor de este escalar.

set( $val )

Este método se puede utilizar para cambiar el valor de este escalar.

is_valid()

Comprueba con la especificación del parámetro que el valor actual es válido.
