NAME

List::Util - Un conjunto de funciones de listas de utilidad general

SYNOPSIS

use List::Util qw(
  reduce any all none notall first reductions
  max maxstr min minstr product sum sum0
  pairs unpairs pairkeys pairvalues pairfirst pairgrep pairmap
  shuffle uniq uniqint uniqnum uniqstr head tail zip mesh
);

DESCRIPTION

«List::Util» contiene una selección de funciones que los usuarios han expresado que serían bonitas de tener en el núcleo de Perl, aunque su uso no sería suficientemente alto para justificar el uso de un término clave, y su tamaño es tan pequeño que ser funciones individuales en el repositorio de extensión sería ineficiente.

Por defecto, «List::Util» no exporta ninguna función.

FUNCIONES DE REDUCCIÓN DE LISTAS

Las siguientes funciones aplican un bloque de código a una lista de valores.

reduce

$result = reduce { BLOCK } @list

Reduce @list llamando a BLOCK en contexto escalar múltiples veces, estableciendo $a y $b cada vez. La primera llamada tendrá $a y $b establecidos en los primeros dos elementos de la lista, y las llamadas subsiguientes se realizarán cambiando $a al resultado de la llamada anterior y $b al elemento siguiente en la lista.

Devuelve el resultado de la última llamada a BLOCK. Si @list está vacío se devuelve undef. Si @list solo contiene un elemento se devuelve ese elemento y no se ejecuta BLOCK.

Los siguientes ejemplos demuestran cómo podría usarse reduce para implementar otras funciones de reducción de listas en este módulo. (No se implementan de esta manera, sino de forma más eficiente en funciones individuales C).

$foo = reduce { defined($a)            ? $a :
                $code->(local $_ = $b) ? $b :
                                         undef } undef, @list # primer
$foo = reduce { $a > $b ? $a : $b } 1..10       # max
$foo = reduce { $a gt $b ? $a : $b } 'A'..'Z'   # maxstr
$foo = reduce { $a < $b ? $a : $b } 1..10       # min
$foo = reduce { $a lt $b ? $a : $b } 'aa'..'zz' # minstr
$foo = reduce { $a + $b } 1 .. 10               # sum
$foo = reduce { $a . $b } @bar                  # concatenar
$foo = reduce { $a || $code->(local $_ = $b) } 0, @bar   # any
$foo = reduce { $a && $code->(local $_ = $b) } 1, @bar   # all
$foo = reduce { $a && !$code->(local $_ = $b) } 1, @bar  # none
$foo = reduce { $a || !$code->(local $_ = $b) } 0, @bar  # notall
   # Nota: estos implementaciones no completamente cortocircuitan

Si tu algoritmo requiere que reduce produzca un valor identidad, asegúrate de siempre pasar ese valor como primer argumento para evitar que se devuelva undef.

$foo = reduce { $a + $b } 0, @values;             # sum con valor identidad 0

Los bloques de código mencionados también sugieren cómo usar reduce para construir una versión más eficiente de una de estas funciones básicas junto con un bloque de mapa. Por ejemplo, para encontrar la longitud total de todas las cadenas en una lista, podríamos usar:

$total = sum map { length } @strings;

Sin embargo, esta forma produce valores temporales de tipo entero como longitudes de cada cadena en la lista original, solo para reducirlos de nuevo a un valor único. Podemos obtener el mismo resultado de forma más eficiente utilizando reduce con un bloque de código que acumule las longitudes escribiendo esto en lugar de:

$total = reduce { $a + length $b } 0, @strings

Los otros funciones de retorno escalar de lista son especializaciones de este concepto general.

reductions

@results = reductions { BLOCK } @list

Desde la versión 1.54.

Similar a reduce, pero también devuelve los valores intermedios junto con el resultado final. Como antes, $a se establece en el primer elemento de la lista dada, y el bloque de código se llama una vez para cada elemento restante en la lista, con el resultado capturado para devolver y becoming el nuevo valor de $a.

La lista devuelta comenzará con el valor inicial de $a, seguido por cada valor devuelto por el bloque en orden. El valor final del resultado será idéntico al que el función reduce devolvería dado el mismo bloque y lista.

reduce     { "$a-$b" } "a".."d"    # "a-b-c-d"
reductions { "$a-$b" } "a".."d"    # "a", "a-b", "a-b-c", "a-b-c-d"

any

my $bool = any { BLOCK } @list;

Desde la versión 1.33.

Similar a grep en que evalúa BLOCK asignando $_ a cada elemento de @list. any devuelve true si algún elemento hace que BLOCK devuelva un valor verdadero. Si BLOCK nunca devuelve verdadero o @list está vacío, devuelve false.

Muchos casos de uso de grep en condiciones pueden escribirse usando any, ya que puede cortocircuitar después del primer resultado verdadero.

if( any { length > 10 } @strings ) {
    # al menos una cadena tiene más de 10 caracteres
}

Nota: Debido a problemas de XS, el bloque pasado puede acceder directamente a @_ externo. Esto no es intencional y se romperá bajo el debugger.

all

my $bool = all { BLOCK } @list;

Desde la versión 1.33.

Similar a any, excepto que requiere que todos los elementos de @list hagan que BLOCK devuelva verdadero. Si algún elemento devuelve falso, devuelve falso. Si el bloque nunca devuelve falso o @list está vacío, devuelve verdadero.

Nota: Debido a problemas de XS, el bloque pasado puede acceder directamente a @_ externo. Esto no es intencional y se romperá bajo el debugger.

none

notall

my $bool = none { BLOCK } @list;
my $bool = notall { BLOCK } @list;

Desde la versión 1.33.

Similar a any y all, pero con el sentido de retorno inverso. none devuelve true solo si ningún valor en @list hace que BLOCK devuelva verdadero, y notall devuelve true solo si no todos los valores lo hacen.

Nota: Debido a problemas de XS, el bloque pasado puede acceder directamente a @_ externo. Esto no es intencional y se romperá bajo el debugger.

first

my $val = first { BLOCK } @list;

Similar a grep en que evalúa BLOCK asignando $_ a cada elemento de @list. first devuelve el primer elemento donde el resultado de BLOCK es un valor verdadero. Si BLOCK nunca devuelve verdadero o @list está vacío, devuelve undef.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

= first { defined($_) } @list # primer valor definido en @list $foo = first { $_ > $value } @list # valor en @list más grande que $value

max

my $num = max @list;

Devuelve el elemento en la lista con el valor numérico más alto. Si la lista está vacía, se devuelve "undef".

$foo = max 1..10                # 10
$foo = max 3,9,12               # 12
$foo = max @bar, @baz           # cualquier valor

maxstr

my $str = maxstr @list;

Similar a "max", pero trataba todos los elementos de la lista como strings y devuelve el string más alto según el operador "gt". Si la lista está vacía, se devuelve "undef".

$foo = maxstr 'A'..'Z'          # 'Z'
$foo = maxstr "hello","world"   # "world"
$foo = maxstr @bar, @baz        # cualquier valor

min

my $num = min @list;

Similar a "max", pero devuelve el elemento en la lista con el valor numérico más bajo. Si la lista está vacía, se devuelve "undef".

$foo = min 1..10                # 1
$foo = min 3,9,12               # 3
$foo = min @bar, @baz           # cualquier valor

minstr

my $str = minstr @list;

Similar a "min", pero trataba todos los elementos de la lista como strings y devuelve el string más bajo según el operador "lt". Si la lista está vacía, se devuelve "undef".

$foo = minstr 'A'..'Z'          # 'A'
$foo = minstr "hello","world"   # "hello"
$foo = minstr @bar, @baz        # cualquier valor

product

my $num = product @list;

Desde la versión 1.35.

Devuelve el producto numérico de todos los elementos en "@list". Si "@list" está vacío, se devuelve 1.

$foo = product 1..10            # 3628800
$foo = product 3,9,12           # 324

sum

my $num_or_undef = sum @list;

Devuelve la suma numérica de todos los elementos en "@list". Para la compatibilidad retroactiva, si "@list" está vacío, se devuelve "undef".

$foo = sum 1..10                # 55
$foo = sum 3,9,12               # 24
$foo = sum @bar, @baz           # cualquier valor

sum0

my $num = sum0 @list;

Desde la versión 1.26.

Similar a "sum", pero devuelve 0 cuando se le pasa una lista vacía, en lugar de "undef".

FUNCIONES DE LISTA DE PARES CLAVE/VALOR

El siguiente conjunto de funciones, todos inspirados en List::Pairwise, consumen una lista de pares de tamaño par. Los pares pueden ser asociaciones clave-valor de un hash o simplemente una lista de valores. Todas las funciones preservan la ordenación original de los pares y no se confundirán con múltiples pares que tengan el mismo valor de clave. Ni siquiera necesitan que el primer elemento de cada par sea una cadena común.

NOTA: A la hora de escribir, los siguientes funciones "pair*" que aceptan un bloque no modifican el valor de $_ dentro del bloque, y en su lugar operan usando los globales $a y $b. Esto ha resultado ser un diseño malo, ya que prevenía la posibilidad de proporcionar una función "pairsort". Mejoraría al pasar objetos de pares similares como referencias a listas de dos elementos en $_, en un estilo similar al valor devuelto por la función "pairs". A futuro, este comportamiento podría ser añadido.

Hasta entonces, los usuarios están advertidos NO a depender del valor de $_ entre el exterior y el interior del bloque de control. En particular, el siguiente ejemplo es INSEGURO:

my @kvlist = ...
foreach (qw( some keys here )) {
   my @items = pairgrep { $a eq $_ } @kvlist;
   ...
}

En lugar de eso, escribir esto con una variable lexical:

foreach my $key (qw( some keys here )) {
   my @items = pairgrep { $a eq $key } @kvlist;
   ...
}

pairs

my @pairs = pairs @kvlist;

Desde la versión 1.29.

Un acceso cómodo a operar en listas de pares de tamaño par, esta función devuelve una lista de referencias a arrays, cada una conteniendo dos elementos de la lista dada. Es una versión más eficiente de

@pairs = pairmap { [ $a, $b ] } @kvlist

Es más conveniente usar en un bucle "foreach", por ejemplo:

foreach my $pair ( pairs @kvlist ) {
   my ( $key, $value ) = @$pair;
   ...
}

Desde la versión 1.39, estas referencias a arrays son objetos bien vestidos, reconociendo los métodos "key" y "value". El siguiente código es equivalente:

foreach my $pair ( pairs @kvlist ) {
   my $key   = $pair->key;
   my $value = $pair->value;
   ...
}

Desde la versión 1.51, también tienen un método "TO_JSON" para facilitar la serialización.

unpairs

my @kvlist = unpairs @pairs

Desde la versión 1.42.

La función inversa de "pairs"; esta función toma una lista de referencias a arrays que contienen dos elementos cada uno, y devuelve una lista de los dos valores de cada par, en orden. Esta es notaciónmente equivalente a

my @kvlist = map { @{$_}[0,1] } @pairs

aunque está implementada de forma más eficiente internamente. Específicamente, para cualquier entrada, extraerá exactamente dos valores para la lista de salida; usando "undef" si las referencias a arrays de entrada son cortas.

Entre "pairs" y "unpairs", un función de lista de alto nivel puede usarse para operar sobre los pares como escalares; por ejemplo, las siguientes equivalentes near-equalities de las otras funciones "pair*":

@kvlist = unpairs grep { FUNC } pairs @kvlist
# Como pairgrep, pero usa $_ en lugar de $a y $b
@kvlist = unpairs map { FUNC } pairs @kvlist
# Como pairmap, pero usa $_ en lugar de $a y $b

Sin embargo, estos versiones no se comportarán de forma tan amigable en contexto escalar.

Finalmente, esta técnica puede usarse para implementar un sort en una lista de pares clave-valor; por ejemplo:

@kvlist = unpairs sort { $a->key cmp $b->key } pairs @kvlist

pairkeys

my @keys = pairkeys @kvlist;

Desde la versión 1.29.

Un acceso cómodo a operar en listas de pares de tamaño par, esta función devuelve una lista de los primeros valores de cada par en la lista dada. Es una versión más eficiente de

@keys = pairmap { $a } @kvlist

pairvalues

my @values = pairvalues @kvlist;

Desde la versión 1.29.

Un acceso cómodo a operar en listas de pares de tamaño par, esta función devuelve una lista de los segundos valores de cada par en la lista dada. Es una versión más eficiente de

@values = pairmap { $b } @kvlist

pairgrep

my @kvlist = pairgrep { BLOCK } @kvlist;
my $count = pairgrep { BLOCK } @kvlist;

Desde la versión 1.29.

Similar a la palabra clave "grep" de Perl, pero interpreta la lista dada como una lista de pares de tamaño par. Invoca el bloque "BLOCK" múltiples veces, en contexto escalar, con "$a" y "$b" establecidos a pares sucesivos de valores de "@kvlist".

Devuelve una lista de pares de tamaño par donde el bloque "BLOCK" devuelve verdadero en contexto lista, o el número de pares en escalar (el tamaño de la lista de pares es el doble). (Note, por lo tanto, en contexto escalar, devuelve un número que es la mitad del tamaño de la lista de elementos que habría devuelto en contexto lista).

@subset = pairgrep { $a =~ m/^[[:upper:]]+$/ } @kvlist

Como con "grep", aliasa "$_" a elementos de la lista; "pairgrep" aliasa "$a" y "$b" a elementos de la lista dada. Cualquier modificación de esta lista por el código del bloque será visible al llamante.

pairfirst

my ( $key, $val ) = pairfirst { BLOCK } @kvlist;
my $found = pairfirst { BLOCK } @kvlist;

Desde la versión 1.30.

Similar a la función "first", pero interpreta la lista dada como una lista de pares de tamaño par. Invoca el bloque "BLOCK" múltiples veces, en contexto escalar, con "$a" y "$b" establecidos a pares sucesivos de valores de "@kvlist".

Devuelve el primer par de valores de la lista donde el bloque "BLOCK" devuelve verdadero en contexto lista, o una lista vacía si no se encontró ningún par así. En contexto escalar, devuelve un valor booleano simple, en lugar de la clave o el valor encontrado.

( $key, $value ) = pairfirst { $a =~ m/^[[:upper:]]+$/ } @kvlist

Como con "grep", aliasa "$_" a elementos de la lista; "pairfirst" aliasa "$a" y "$b" a elementos de la lista dada. Cualquier modificación de esta lista por el código del bloque será visible al llamante.

FUNCIONES DE LISTA

pairmap

my @list = pairmap { BLOCK } @kvlist;
my $count = pairmap { BLOCK } @kvlist;

Desde la versión 1.29.

Similar a la palabra clave "map" de perl, pero interpreta la lista dada como una lista de pares de tamaño par. Invoca el "BLOCK" múltiples veces, en contexto de lista, con $a y $b establecidos en pares sucesivos de valores de @kvlist.

Devuelve la concatenación de todos los valores devueltos por el "BLOCK" en contexto de lista, o el recuento del número de elementos que se habrían devuelto en contexto escalar.

@result = pairmap { "La clave $a tiene valor $b" } @kvlist

Al igual que "map" que aliase $_ a los elementos de la lista, "pairmap" aliase $a y $b a elementos de la lista dada. Cualquier modificación de la misma por el bloque de código será visible para el llamador.

Ver "BUGS CONOCIDOS" para un bug conocido con "pairmap" y una solución.

OTRAS FUNCIONES

shuffle

my @values = shuffle @values;

Devuelve los valores de entrada en un orden aleatorio

@cards = shuffle 0..51      # 0..51 en orden aleatorio

Esta función se ve afectada por la variable $RAND.

sample

my @items = sample $count, @values

Desde la versión 1.54.

Selecciona aleatoriamente el número dado de elementos de la lista de entrada. Cualquier posición dada en la lista de entrada se seleccionará como máximo una vez.

Si hay menos de $count elementos en la lista, la función devolverá una vez que todos hayan sido seleccionados aleatoriamente; efectivamente, la función se comporta de manera similar a "shuffle".

Esta función se ve afectada por la variable $RAND.

uniq

my @subset = uniq @values

Desde la versión 1.45.

Filtra una lista de valores para eliminar duplicados posteriores, según un test de igualdad de cadena DWIM-ish o un test de "undef". Conserva el orden de los elementos únicos y retiene el primer valor de cualquier conjunto de duplicados.

my $count = uniq @values

En contexto escalar, devuelve el número de elementos que se habrían devuelto como lista.

El valor "undef" es tratado por esta función como distinto de la cadena vacía, y no se producirá ninguna advertencia. Se deja tal cual en la lista devuelta. Los valores "undef" posteriores todavía se consideran idénticos al primero y se eliminarán.

uniqint

my @subset = uniqint @values

Desde la versión 1.55.

Filtra una lista de valores para eliminar duplicados posteriores, según un test de igualdad numérica entera. Conserva el orden de los elementos únicos y retiene el primer valor de cualquier conjunto de duplicados. Los valores en la lista devuelta se convertirán a enteros.

my $count = uniqint @values

En contexto escalar, devuelve el número de elementos que se habrían devuelto como lista.

Tenga en cuenta que "undef" se trata de manera similar a como lo tratan otras operaciones numéricas; se compara igual a cero pero además produce una advertencia si dichas advertencias están habilitadas ("use warnings 'uninitialized';"). Además, un "undef" en la lista devuelta se convierte en un cero numérico, de modo que toda la lista de valores devuelta por "uniqint" se comporta bien como enteros.

uniqnum

my @subset = uniqnum @values

Desde la versión 1.44.

Filtra una lista de valores para eliminar duplicados posteriores, según un test de igualdad numérica. Conserva el orden de los elementos únicos y retiene el primer valor de cualquier conjunto de duplicados.

my $count = uniqnum @values

En contexto escalar, devuelve el número de elementos que se habrían devuelto como lista.

Tenga en cuenta que "undef" se trata de manera similar a como lo tratan otras operaciones numéricas; se compara igual a cero pero además produce una advertencia si dichas advertencias están habilitadas ("use warnings 'uninitialized';"). Además, un "undef" en la lista devuelta se convierte en un cero numérico, de modo que toda la lista de valores devuelta por "uniqnum" se comporta bien como números.

Tenga en cuenta también que se tratan múltiples valores IEEE "NaN" como duplicados entre sí, independientemente de cualquier diferencia en sus cargas útiles, y a pesar del hecho de que "0+'NaN' == 0+'NaN'" da como resultado falso.

uniqstr

my @subset = uniqstr @values

Desde la versión 1.45.

Filtra una lista de valores para eliminar duplicados posteriores, según un test de igualdad de cadena. Conserva el orden de los elementos únicos y retiene el primer valor de cualquier conjunto de duplicados.

my $count = uniqstr @values

En contexto escalar, devuelve el número de elementos que se habrían devuelto como lista.

Tenga en cuenta que "undef" se trata de manera similar a como lo tratan otras operaciones de cadena; se compara igual a la cadena vacía pero además produce una advertencia si dichas advertencias están habilitadas ("use warnings 'uninitialized';"). Además, un "undef" en la lista devuelta se convierte en una cadena vacía, de modo que toda la lista de valores devuelta por "uniqstr" se comporta bien como cadenas.

head

my @values = head $size, @list;

Desde la versión 1.50.

Devuelve los primeros $size elementos de @list. Si $size es negativo, devuelve todos excepto los últimos $size elementos de @list.

@result = head 2, qw( foo bar baz );
# foo, bar
@result = head -2, qw( foo bar baz );
# foo

tail

my @values = tail $size, @list;

Desde la versión 1.50.

Devuelve los últimos $size elementos de @list. Si $size es negativo, devuelve todos excepto los primeros $size elementos de @list.

@result = tail 2, qw( foo bar baz );
# bar, baz
@result = tail -2, qw( foo bar baz );
# baz

zip

my @result = zip [1..3], ['a'..'c'];
# [1, 'a'], [2, 'b'], [3, 'c']

Desde la versión 1.56.

Devuelve una lista de referencias a arrays, compuesta por elementos de la lista dada de referencias a arrays. Cada array en la lista devuelta se compone de elementos en esa posición correspondiente de cada uno de los arrays de entrada dados. Si algún array de entrada agota sus elementos antes que otros, se insertará "undef" en el resultado para llenar los huecos.

La función "zip" es particularmente útil para iterar sobre múltiples arrays al mismo tiempo con un bucle "foreach", tomando un elemento de cada uno:

foreach ( zip \@xs, \@ys, \@zs ) {
    my ($x, $y, $z) = @$_;
    ...
}

NOTA para usuarios de List::MoreUtils: Esta función no se comporta igual que "List::MoreUtils::zip", sino que es en realidad un equivalente no prototipado a "List::MoreUtils::zip_unflatten". Esta función no aplica un prototipo, por lo que asegúrese de invocarla con referencias a arrays.

Para una función similar a la función "zip" de "List::MoreUtils", vea mesh.

my @result = zip_shortest ...

Una variación de la función que difiere en su comportamiento cuando se le dan arrays de entrada de longitudes diferentes. "zip_shortest" se detendrá tan pronto como uno de los arrays de entrada agote sus elementos, descartando cualquier valor restante no utilizado de los otros.

my @result = zip_longest ...

"zip_longest" es un alias de la función "zip", proporcionado simplemente para ser explícito sobre ese comportamiento en comparación con "zip_shortest".

mesh

my @result = mesh [1..3], ['a'..'c'];
# (1, 'a', 2, 'b', 3, 'c')

Desde la versión 1.56.

Devuelve una lista de elementos recolectados de los elementos de la lista dada de referencias a arrays. Cada sección de elementos en la lista devuelta se compone de elementos en la posición correspondiente de cada uno de los arrays de entrada dados. Si algún array de entrada agota sus elementos antes que otros, se insertará "undef" en el resultado para llenar los huecos.

Esto es similar a zip, excepto que todos los rangos en el resultado se devuelven en una lista larga y aplanada, en lugar de agruparse en arrays separados.

Debido a que devuelve una lista plana de elementos, la función "mesh" es particularmente útil para construir un hash a partir de dos arrays separados de claves y valores:

my %hash = mesh \@keys, \@values;
my $href = { mesh \@keys, \@values };

NOTA para usuarios de List::MoreUtils: Esta función es un equivalente no prototipado a "List::MoreUtils::mesh

FUNCIONES DE REDUCCIÓN DE LISTAS

mesh_shortest, mesh_longest

Similar to "zip", but they take an array of arrays as their argument. They are aliases of each other. They are also aliases for "zip_longest" and "zip_shortest" respectively.

This function does not apply a prototype, so make sure to invoke it with references to arrays.

my @result = mesh_shortest ...
my @result = mesh_longest ...

These variations are similar to those of zip, in that they differ in behaviour when one of the input lists runs out of elements before the others.

VARIABLES DE CONFIGURACIÓN

$RAND

local $List::Util::RAND = sub { ... };

Desde la versión 1.54.

Esta variable del paquete es utilizada por el código que necesita generar números aleatorios (como las funciones "shuffle" y "sample"). Si se establece a una referencia CODE, proporciona una alternativa a la función incorporada rand() de perl. Cuando se necesita un nuevo número aleatorio, esta función será invocada sin argumentos y se espera que devuelva un valor de punto flotante, de los cuales solo se utilizará la parte fraccionaria.

BUGS CONOCIDOS

RT #95409

https://rt.cpan.org/Ticket/Display.html?id=95409

Si el bloque de código proporcionado a "pairmap" contiene variables léxicas que son capturadas por un closure devuelto, y el closure se ejecuta después de que el bloque ha sido reutilizado para la siguiente iteración, estos léxicos no verán los valores correctos. Por ejemplo:

my @subs = pairmap {
   my $var = "$a is $b";
   sub { print "$var\n" };
} one => 1, two => 2, three => 3;
$_->() for @subs;

Imprimirá incorrectamente

three is 3
three is 3
three is 3

Esto se debe a la optimización de rendimiento de usar "MULTICALL" para el bloque de código, lo que significa que no se asignan SVs nuevos para cada llamada al bloque. En su lugar, el mismo SV se reasigna para cada iteración, y todos los closures compartirán el valor visto en la última iteración.

Para solucionar este bug, rodea el código con un segundo conjunto de llaves. Esto crea un bloque interno que deshabilita la lógica de "MULTICALL", y se asignan SVs nuevos cada vez:

my @subs = pairmap {
   {
      my $var = "$a is $b";
      sub { print "$var\n"; }
   }
} one => 1, two => 2, three => 3;

Este bug solo afecta a los closures que se generan a partir del bloque pero se utilizan después. Las variables léxicas que solo se utilizan durante la vida útil de la ejecución del bloque tomarán sus valores individuales para cada invocación, como es normal.

uniqnum() en bignums sobredimensionados

Debido a la forma en que uniqnum() compara números, no puede distinguir las diferencias entre bignums (especialmente bigints) que son demasiado grandes para caber en los tipos nativos de la plataforma. Por ejemplo,

my $x = Math::BigInt->new( "1" x 100 );
my $y = $x + 1;
say for uniqnum( $x, $y );

Imprimirá solo el valor de $x, creyendo que $y es un valor numéricamente equivalente. Este bug no afecta a uniqstr(), que observará correctamente que los dos valores se convierten en cadenas diferentes.
