NAME

Locale::RecodeData::GOST_19768_74 — GOST 19768-74 a UTF-8 tabla de codificación para Locale::Recode

SYNOPSIS

use Locale::RecodeData::GOST_19768_74;

DESCRIPTION

Este módulo proporciona la tabla de codificación GOST 19768-74 a UTF-8 para el módulo Locale::Recode.

GOST 19768-74 es un estándar para los alfabetos cirílico, latino y otros caracteres similares. Se utiliza principalmente en países que forman parte de la antigua Unión Soviética.

Para más detalles sobre los diferentes códigos de caracteres, consulta la documentación de este módulo.

COMMENTS

Este módulo es parte de la distribución libintl-perl.
