NAME

Locale::RecodeData::MACICELAND — Charset information for MACICELAND

SYNOPSIS

 use Locale::RecodeData::MACICELAND qw( :all );

DESCRIPTION

This module provides information about the MACICELAND character set.

This module is part of the libintl-perl distribution.

The MACICELAND character set is a small character set for Icelandic language.

COMMENTS
