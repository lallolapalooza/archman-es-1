NOMBRE

Locale::RecodeData::ECMA_CYRILLIC - Rutinas de conversión para ECMA_CYRILLIC

SINOPSIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo está generado y contiene las tablas y rutinas de conversión para ECMA-CYRILLIC.

COMENTARIOS

Los siguientes comentarios han sido extraídos del mapa de caracteres original:

version: 1.0
 source: ECMA registry
alias ISO-IR-111

¡Por favor, ten en cuenta que los alias listados arriba no son necesariamente válidos!

NAME

Locale::RecodeData::ECMA_CYRILLIC - ECMA Cyrillic character table

SYNOPSIS

    use Locale::RecodeData::ECMA_CYRILLIC;
    recode_iconv_open( ... );
    recode_iconv_close( ... );
    recode_iconv_read( ... );
    recode_iconv_write( ... );

DESCRIPTION

This module provides the ECMA Cyrillic character table for the Locale::Recode module.

ECMA-113, Table 3, page 15 uses the following encoding.

COMMENTS

This code is a Perl port of the C code written by Paul Grisenthwaite.
