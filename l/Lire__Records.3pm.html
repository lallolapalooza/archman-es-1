NOMBRE

Lire::Records - Clase base para la implementación del operador de registros.

SINOPSIS

use Lire::Records;

DESCRIPCIÓN

Este módulo es la clase base para la implementación del operador de registros. El operador de registros no es un agregador ni una operación de agrupación. Solo recopila información sobre cada registro DLF que se incluirá en el informe.

CONSTRUCTOR

nuevo( %parámetros )

Crea una nueva instancia de un operador de registros. Además de los parámetros normales del operador de informes, el operador de registros toma un parámetro adicional:

campos
Una referencia a un array que contiene los nombres de los campos DLF que deberían incluirse en el informe.
