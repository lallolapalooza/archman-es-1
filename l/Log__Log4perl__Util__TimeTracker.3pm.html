NOMBRE

Log::Log4perl::Util::TimeTracker - Rastrea el tiempo transcurrido

SINOPSIS

use Log::Log4perl::Util::TimeTracker;
my $timer = Log::Log4perl::Util::TimeTracker->new();
  # equivalente a Time::HiRes::gettimeofday(), independientemente de
  # si Time::HiRes está presente o no. 
my($segundos, $microsegundos) = $timer->gettimeofday();
  # reinicia el temporizador interno
$timer->reset();
  # devuelve milisegundos desde el último reinicio
$miliseg = $timer->milliseconds();
  # devuelve milisegundos desde la última llamada
$miliseg = $timer->delta_milliseconds();

DESCRIPCIÓN

Este módulo de utilidad ayuda a rastrear el tiempo transcurrido para los marcadores de fecha y hora de PatternLayout. Su precisión depende de la disponibilidad del módulo Time::HiRes. Si está disponible, su granularidad es de milisegundos, si no, de segundos.

El uso más común de este módulo es llamar al método gettimeofday():

my($segundos, $microsegundos) = $timer->gettimeofday();

Devuelve segundos y microsegundos de la hora actual de la época. Si Time::HiRes está instalado, simplemente delegará a su función gettimeofday(), si falta, se llamará a time() en su lugar y $microsegundos siempre será 0.

Para medir el tiempo transcurrido en milisegundos, use el método reset() para reiniciar el temporizador a la hora actual, seguido de una o más llamadas al método milliseconds():

  # reinicia el temporizador interno
$timer->reset();
  # devuelve milisegundos desde el último reinicio
$miliseg = $timer->milliseconds();

Además del intervalo de tiempo entre el último reinicio y la hora actual, el módulo realiza un seguimiento del tiempo entre llamadas a delta_milliseconds():

$miliseg = $timer->delta_milliseconds();

En la primera llamada, esto devolverá el número de milisegundos desde el último reset(), en llamadas posteriores, devolverá el tiempo transcurrido en milisegundos desde la última llamada a delta_milliseconds() en su lugar. Tenga en cuenta que reset() también reinicia la hora de la última llamada.

El temporizador interno de este módulo obtiene su entrada de tiempo de la función POSIX time() o, si el módulo Time::HiRes está disponible, de su función gettimeofday(). Para averiguar cuál es, use

if( $timer->hires_available() ) {
    print "¡Genial, obtenemos milisegundos reales!\n";
} else {
    print "Los milisegundos son solo falsos\n";
}

Para fines de prueba, se puede proporcionar una fuente de tiempo diferente, por lo que las suites de prueba pueden simular el paso del tiempo sin tener que esperar realmente:

my $start_time = time();
my $timer = Log::Log4perl::Util::TimeTracker->new(
        time_function => sub {
            return $start_time++;
        },
);

Cada llamada a $timer->epoch() devolverá un valor de tiempo que es un segundo más que el valor devuelto en la llamada anterior. Esto también significa que cada llamada a delta_milliseconds() devolverá un valor que excede el valor devuelto en la llamada anterior en 1000.
