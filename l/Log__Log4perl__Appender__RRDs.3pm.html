Appender::RRDs(3) Documentación de Perl contribuida por el usuario Appender::RRDs(3)

NOMBRE

Log::Log4perl::Appender::RRDs - Registrar en un archivo de RRDtool

SINOPSIS

use Log::Log4perl qw(get_logger);
use RRDs;

my $DB = "myrrddb.dat";

RRDs::create(
  $DB, "--step=1",
  "DS:myvalue:GAUGE:2:U:U",
  "RRA:MAX:0.5:1:120");

print time(), "\n";

Log::Log4perl->init(\qq{
  log4perl.category = INFO, RRDapp
  log4perl.appender.RRDapp = Log::Log4perl::Appender::RRDs
  log4perl.appender.RRDapp.dbname = $DB
  log4perl.appender.RRDapp.layout = Log::Log4perl::Layout::PatternLayout
  log4perl.appender.RRDapp.layout.ConversionPattern = N:%m
});

my $logger = get_logger();

for(10, 15, 20, 25) {
    $logger->info($_);
    sleep 1;
}

DESCRIPCIÓN

"Log::Log4perl::Appender::RRDs" los apéndices facilitan la escritura de datos en archivos circulares RRDtool a través de Log4perl. Para obtener documentación sobre RRD y su interfaz Perl "RRDs" (que viene con la distribución), consulta http://rrdtool.org.

Se espera que los mensajes enviados al apéndice RRDs de Log4perl sean valores numéricos (enteros o flotantes), que luego se utilizan para ejecutar un comando "rrdtool update" en una base de datos circular existente. El nombre de esta base de datos debe configurarse en el parámetro de configuración "dbname" del apéndice.

Si hay más parámetros que deseas pasar al método "update", utiliza el parámetro de configuración "rrdupd_params":

log4perl.appender.RRDapp.rrdupd_params = --template=in:out

Para leer la base de datos circular más tarde, utiliza "rrdtool fetch" o "rrdtool graph" para obtener visualizaciones gráficas.
