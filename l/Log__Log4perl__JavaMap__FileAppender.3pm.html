Log::Log4perl::JavaMap::FileAppender - encapsula Log::Dispatch::File

SINOPSIS

DESCRIPCIÓN

Propiedades de configuración posibles para log4j ConsoleAppender son

File
Append      "true|false|1|0" por defecto=true
BufferedIO  "true|false|1|0" por defecto=false (es decir, autoflush está activado)

Propiedades de configuración posibles para Log::Dispatch::File son

filename
mode  "write|append"
autoflush 0|1

http://jakarta.apache.org/log4j/docs/
