LWP::ConnCache(3) Documentación de Perl contribuida por usuarios LWP::ConnCache(3)

NOMBRE

LWP::ConnCache - Gestor de caché de conexiones

NOTA

Este módulo es experimental. Los detalles de su interfaz probablemente cambiarán en el futuro.

SINTAXIS

use LWP::ConnCache;
my $cache = LWP::ConnCache->new;
$cache->deposit($type, $key, $sock);
$sock = $cache->withdraw($type, $key);

DESCRIPCIÓN

La clase "LWP::ConnCache" es el gestor estándar de caché de conexiones para LWP::UserAgent.

MÉTODOS

Los siguientes métodos básicos se proporcionan:

new

my $cache = LWP::ConnCache->new( %options )

Este método construye un nuevo objeto LWP::ConnCache. El único parámetro aceptado actualmente es "total_capacity". Si se especifica, inicializa la opción "total_capacity" en el objeto LWP::ConnCache. Por defecto, es 1.

total_capacity

my $cap = $cache->total_capacity;
$cache->total_capacity(0); # eliminar todas inmediatamente
$cache->total_capacity(undef); # sin límite
$cache->total_capacity($number);

Obtener/actualizar el número de conexiones que se almacenarán. Las conexiones comenzarán a ser eliminadas cuando se alcance este límite. Si se establece a 0, todas las conexiones se eliminarán inmediatamente. Si se establece a "undef", no hay límite.

capacity

my $http_capacity = $cache->capacity('http');
$cache->capacity('http', 2 );

Obtener/actualizar un límite para el número de conexiones de un tipo específico que pueden ser almacenadas. El primer parámetro es una cadena corta como "http" o "ftp".

drop

$cache->drop(); # Eliminar todas las conexiones
# que es un sinónimo de:
$cache->drop(sub{1}); # Eliminar todas las conexiones
# eliminar todas las conexiones más antiguas de 22 segundos y añadir una razón para ello!
$cache->drop(22, "Older than 22 secs dropped");
# que es un sinónimo de:
$cache->drop(sub {
    my ($conn, $type, $key, $deposit_time) = @_;
    if ($deposit_time < 22) {
        # valores verdaderos eliminan la conexión
        return 1;
    }
    # valores falsos no eliminan la conexión
    return 0;
}, "Older than 22 secs dropped" );

Eliminar conexiones por criterios. El argumento $checker es una subrutina que se llama para cada conexión. Si devuelve TRUE, se elimina la conexión. La subrutina se llama con "($conn, $type, $key, $deposit_time)" como argumentos.

Cortafiltros: Si el argumento $checker no está presente (o es "undef"), todas las conexiones en el caché se eliminan. Si el $checker es un número, se eliminan todas las conexiones que han estado almacenadas por más de ese número de segundos. Si el $checker es una cadena, se eliminan todas las conexiones del tipo especificado.

La razón "reason" se pasa a la propiedad "dropped" en el método LWP::ConnCache.

prune

$cache->prune();

Llamar a este método eliminará todas las conexiones que están muertas. Esto se prueba llamando al método "ping" en el método LWP::ConnCache en las conexiones. Si el "ping" en el método LWP::ConnCache existe y devuelve un valor falso, la conexión se elimina.

get_types

my @types = $cache->get_types();

Devuelve todos los "type" usados en las conexiones actualmente almacenadas.

get_connections

my @conns = $cache->get_connections(); # todas las conexiones
my @conns = $cache->get_connections('http'); # conexiones para http

Devuelve todos los objetos de conexión de un tipo específico. Si no se especifica un tipo, se devuelven todas las conexiones. En contexto escalar, se devuelve el número de conexiones almacenadas del tipo especificado.

MÉTODOS DE PROTOCOLO

Los siguientes métodos son llamados por módulos de protocolo de bajo nivel para intentar almacenar y recuperar conexiones.

deposit

$cache->deposit($type, $key, $conn);

Este método agrega una nueva conexión al caché. Como resultado, otras conexiones ya almacenadas podrían ser eliminadas. Pueden agregarse múltiples conexiones con el mismo tipo/clave.

withdraw

my $conn = $cache->withdraw($type, $key);

Este método intenta recuperar una conexión que se había depositado previamente. Si no hay una conexión almacenada con el tipo $type/$key, se devuelve "undef". No hay garantía de que una conexión depositada pueda ser retirada, ya que el gestor del caché puede eliminar conexiones en cualquier momento.

MÉTODOS INTERNOS

Los siguientes métodos son llamados internamente. Las subclases podrían querer sobrescribirlos.

enforce_limits

$conn->enforce_limits([$type])

Este método se llama después de que una nueva conexión se haya agregado (depositado) al caché o se han ajustado los límites de capacidad. La implementación por defecto elimina conexiones hasta que los límites especificados no se excedan.

dropping

$conn->dropping($conn_record, $reason)

Este método se llama cuando se elimina una conexión. El registro de la conexión que se ha eliminado se pasa como el primer argumento y una cadena que describe la razón de la eliminación como el segundo argumento. La implementación por defecto emite un `warn` si la variable $LWP::ConnCache::DEBUG está activa y nada más.

SUBCLASES

Para una política de caché especializada, es útil heredar de "LWP::ConnCache" y sobrescribir los métodos "deposit", "enforce_limits" y "dropping" de "LWP::ConnCache".

El objeto en sí es un hash. Las claves prefijadas con "cc_" están reservadas para la clase base.
