NOMBRE

Log::Log4perl::Appender::ScreenColoredLevels - Colorea mensajes según el nivel

SINOPSIS

use Log::Log4perl qw(:easy);
Log::Log4perl->init(\ <<'EOT');
  log4perl.category = DEBUG, Screen
  log4perl.appender.Screen = \
      Log::Log4perl::Appender::ScreenColoredLevels
  log4perl.appender.Screen.layout = \
      Log::Log4perl::Layout::PatternLayout
  log4perl.appender.Screen.layout.ConversionPattern = \
      %d %F{1} %L> %m %n
EOT
  # Aparece negro
DEBUG "Mensaje de depuración";
  # Aparece verde
INFO  "Mensaje informativo";
  # Aparece azul
WARN  "Mensaje de advertencia";
  # Aparece magenta
ERROR "Mensaje de error";
  # Aparece rojo
FATAL "Mensaje fatal";

DESCRIPCIÓN

Este appender actúa como Log::Log4perl::Appender::Screen, excepto que colorea su salida, basándose en la prioridad del mensaje enviado.

Puedes configurar los colores y atributos utilizados para los diferentes niveles, especificándolos en tu configuración:

log4perl.appender.Screen.color.TRACE=cyan
log4perl.appender.Screen.color.DEBUG=bold blue

También puedes especificar nada, para indicar que ese nivel no tendrá color aplicado, lo que significa que el texto será el color por defecto para tu terminal. Este es el valor por defecto para los mensajes de depuración.

log4perl.appender.Screen.color.DEBUG=

Puedes usar cualquier atributo soportado por Term::ANSIColor como opción de configuración.

log4perl.appender.Screen.color.FATAL=\
    bold underline blink red on_white

Los colores y atributos comúnmente usados son:

atributos
BOLD, DARK, UNDERLINE, UNDERSCORE, BLINK
colores
BLACK, RED, GREEN, YELLOW, BLUE, MAGENTA, CYAN, WHITE
colores de fondo
ON_BLACK, ON_RED, ON_GREEN, ON_YELLOW, ON_BLUE, ON_MAGENTA, ON_CYAN, ON_WHITE

Consulta Term::ANSIColor para una lista completa, e información sobre cuáles son soportados por varios emuladores de terminal comunes.

Los valores por defecto para estas opciones son:

Rastreo
Amarillo
Depurar
Ninguno (el que sea por defecto en el terminal)
Informar
Verde
Advertir
Azul
Error
Magenta
Fatal
Rojo

El constructor new() toma un parámetro opcional "stderr", si se establece a un valor verdadero, el appender registrará todos los niveles en STDERR. Si "stderr" se establece a un valor falso, registrará todos los niveles en STDOUT. De lo contrario, "stderr" puede establecerse a un hash, con una clave para cada "log4p_level" y un valor verdadero para usar dinámicamente stderr. El ajuste por defecto para "stderr" es 1, por lo que todos los mensajes se registrarán en STDERR por defecto.

# Todos los mensajes/niveles a STDERR
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => 1,
);
# Solo ERROR y FATAL a STDERR (sensible a mayúsculas)
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => { ERROR => 1, FATAL => 1},
);

El constructor también puede tomar un parámetro opcional "color", cuyo valor es un hashref de opciones de configuración de color, cualquier nivel que no esté incluido en el hashref se establecerá a sus valores por defecto.

Usando ScreenColoredLevels en Windows

Tenga en cuenta que si está utilizando este appender en Windows, necesita obtener Win32::Console::ANSI de CPAN y agregar

use Win32::Console::ANSI;

a su script.
