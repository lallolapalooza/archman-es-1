NOMBRE

Lire::Config::DlfAnalyserSpec - PluginSpec para seleccionar un analizador.

DESCRIPCIÓN

Este Lire::Config::TypeSpec es un PluginSpec que se puede usar para seleccionar DlfAnalyser que se utilizarán para crear los registros Dlf de un esquema extendido o derivado.

new( 'nombre' => $nombre_flujo_dst, ['esquema_src' => $esquema_origen])

El nombre de la especificación de tipo es el nombre del esquema para el cual se selecciona el analizador. Si se utiliza el parámetro 'src_stream', solo se seleccionarán los analizadores que utilicen ese valor como su src_schema().

El constructor rellenará automáticamente el PluginSpec con las opciones disponibles y establecerá el primer analizador como predeterminado.

src_schema()

Devuelve el src_schema() que debe ser utilizado por el DlfAnalyser seleccionado. Si no se requiere ningún esquema en particular, se devolverá undef.

VER TAMBIÉN

Lire::Config::PluginSpec(3pm), Lire::Config::DlfStreamSpec(3pm)
