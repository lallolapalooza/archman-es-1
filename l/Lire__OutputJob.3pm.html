NOMBRE

Lire::OutputJob - Objeto utilizado para representar una configuración de formato de un informe

SINOPSIS

use Lire::OutputJob;
use Lire::OutputFormat;
my $email = new Lire::OutputJob( 'email', $output, $output_cfg,
                                 'emails' => [ 'email@dominio.org' ] );
$email->run( 'informe.xml' );
my $archivo = new Lire::OutputJob( 'archivo', $output, $output_cfg,
                                'nombre_archivo' => '/var/www/informes/diario-%Y%m%d'  );
$archivo->run( 'informe.xml' );

DESCRIPCION

Los objetos Lire::OutputJob se utilizan para representar cómo se debe formatear un informe. Estos objetos se crean con mayor frecuencia a partir de la configuración de Lire. (La especificación 'output_jobs'.)

new( $tipo_destino, $formato, $cfg_formato, ... );

Crea un nuevo objeto Lire::OutputJob. Se requieren dos parámetros:

$tipo_destino
Puede ser 'email' o 'archivo'.
$formato
Un objeto Lire::OutputFormat.
$cfg_formato
Los datos de configuración que se pasarán al objeto OutputFormat.

El método devolverá una instancia de Lire::EmailOutputJob o Lire::FileOutputJob.

formato

Devuelve el Lire::OutputFormat asociado con este OutputJob.

cfg_formato

Devuelve los datos de configuración que se utilizarán al formatear el informe.

run( $archivo_informe )

Formatea y envía o guarda el informe XML $archivo_informe según los parámetros del OutputJob.

Lire::EmailOutputJob

Parámetros adicionales para el tipo 'email'

emails
Una referencia de array con los correos electrónicos que recibirán el informe formateado.
asunto
El asunto del correo electrónico.
archivo_extra
Un archivo de texto adicional que se adjuntará al informe de texto o se adjuntará a otros tipos de informes.

emails()

Devuelve como un array los correos electrónicos a los que se enviará el informe.

asunto()

Devuelve el asunto del correo electrónico.

archivo_extra()

Devuelve el nombre del archivo que se adjuntará al informe de texto o se adjuntará al mensaje para otros tipos de informes.

Lire::FileOutputJob

Parámetros adicionales para el tipo 'archivo'.

archivo
Una ruta de archivo con posible interpolación de strftime(3pm). Aquí es donde se guardará el informe formateado.

archivo()

Devuelve el archivo de destino de este OutputJob.

archivo_salida( [$tiempo] )

Devuelve el archivo de destino con el especificador strftime(3) interpolado.
