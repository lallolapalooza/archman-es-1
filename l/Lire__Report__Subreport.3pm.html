NOMBRE

Lire::Subreport - Interfaz a un subinforme de Lire.

SINOPSIS

use Lire::ReportParser::ReportBuilder;
my $parser = new Lire::ReportParser::ReportBuilder;
my $report = $parser->parse( "report.xml" );
foreach my $s ( $report->sections() ) {
    print "Sección: '", $s->title(), "\n\n";
    foreach my $r ( $s->subreports() ) {
        print "Subinforme ", $r->title(), " tiene ", scalar $r->entries(),
            " entradas\n";
    }
}

DESCRIPCIÓN

Este módulo ofrece una API a los subinformes incluidos en las secciones de un informe de Lire.

Este objeto tiene todos los métodos que ofrece el objeto Lire::Report::Group(3pm). Encontrará más información sobre cómo acceder a los datos contenidos en un subinforme en esa página del manual.

CONSTRUCTORES

new( $superservice, $tipo)

Crea un nuevo objeto Lire::Report::Subreport. Los parámetros $superservice y $tipo definen la especificación del informe que se utilizó para generar los datos de este subinforme.

new_missing( $superservice, $tipo, [$razón])

Crea un nuevo objeto Lire::Report::Subreport marcado como faltante. Los parámetros $superservice y $tipo definen la especificación del informe que se utilizó para generar los datos de este subinforme. El parámetro $razón establece la razón por la cual este subinforme falta.

MÉTODOS DE OBJETO

id( [ $nuevo_id ] )

Devuelve (y opcionalmente cambia) el ID de este subinforme. El ID del subinforme lo identifica de forma única en su Informe. Los subinformes con el mismo ID se fusionarán.

is_missing()

Devuelve verdadero si este subinforme fue marcado como faltante en el archivo XML. Un subinforme faltante es un subinforme que estaba presente en el archivo de configuración del informe pero que fue marcado como faltante en el informe XML. Esto sucede cuando la especificación del informe requiere campos que no estaban disponibles en los archivos DLF generados. También puede ocurrir cuando se produce un error en el proceso de generación del informe.

missing_reason()

Informa por qué falta el subinforme. Esto será indefinido cuando el subinforme no falte.

superservice()

Devuelve el superservicio de este subinforme. Este es el superservicio que definió la especificación del informe a partir de la cual se generó el subinforme.

type()

Devuelve el tipo de este subinforme. Este es el ID de la especificación del informe que se utilizó para generar este subinforme.

schemas( [ $schema, ... ] )

Devuelve los esquemas utilizados por este Subinforme.

field_schema( $field )

Devuelve el esquema que contiene el campo $field. Devuelve indefinido si este nombre no está definido en ningún esquema.

chart_configs()

Devuelve una referencia de array que contiene objetos Lire::Report::ChartConfig especificando los gráficos que deben generarse a partir de este Subinforme.

add_chart_config( $chart_config )

Añade un objeto Lire::Report::ChartConfig especificando un gráfico que debe generarse a partir de los datos de este Subinforme.

title( [$title] )

Devuelve el título del subinforme.

Si el parámetro $title está establecido, el título del subinforme se establecerá a este nuevo valor.

description( [$new_desc] )

Devuelve la descripción de este subinforme. La descripción está codificada en XML de DocBook.

Si el parámetro $description está establecido, este método establecerá la descripción de este subinforme a este nuevo valor. Si el parámetro $description es indefinido, esa descripción se eliminará.

table_info( [$table_info] )

Devuelve el objeto Lire::Report::TableInfo de nivel superior que describe el diseño de esta tabla. Si se establece el parámetro $table_info, la información de la tabla del subinforme se establecerá a este objeto.

nrows()

Devuelve el número de filas de la tabla.

last_row_idx()

Devuelve el índice de la última fila de datos.

getrow_by_idx( $index )

Devuelve una referencia de array que contiene la fila 'idx' de los datos del subinforme. Una fila contendrá todos los valores (categóricos y numéricos) que aparecerían en la misma fila. Cuando una entrada está compuesta por variables categóricas más grupos anidados, los valores resumen del grupo aparecerán en la misma fila que la variable categórica.

Cada valor es la referencia del hash que devuelve Entry::data_by_name() para esa columna y está en la fila en el índice de la columna.

getrows()

Devuelve todas las filas contenidas en el subinforme. Este método es útil para renderizar la tabla del subinforme.

finalize()

Este método debe ser llamado después de que todas las entradas hayan sido añadidas. Asigna índices de fila y calcula el ancho y las estadísticas de las columnas.

NAME

Lire::Report::Subreport - Represents a subreport within a main report

SYNOPSIS

use Lire::Report::Subreport;

my $subreport = Lire::Report::Subreport->new(
    name    => 'MySubReport',
    title   => 'A Detailed Subreport',
    columns => [ 'ID', 'Name', 'Value' ]
);

$subreport->add_row([ 1, 'Item A', 100 ]);
$subreport->add_row([ 2, 'Item B', 200 ]);

print $subreport->render;

DESCRIPTION

The Lire::Report::Subreport class provides a way to define and manage subreports within a larger report structure. Subreports allow for the organization and presentation of data in a hierarchical or modular fashion.

Each subreport has a unique name, a display title, and a set of columns that define the structure of the data it will contain. You can add rows of data to the subreport, and then render the subreport in a desired format (e.g., plain text, HTML).

CONSTRUCTORS

new( %args )

Creates a new Lire::Report::Subreport object. Accepts the following arguments:

name (required)
A string representing the unique name of the subreport.
title (optional)
A string representing the title of the subreport. Defaults to the name if not provided.
columns (optional)
An array reference of strings, where each string is a column header for the subreport. If not provided, the subreport will have no columns defined initially.

OBJECT METHODS

add_row( \@data )

Adds a row of data to the subreport. The \@data argument should be an array reference containing the values for each column in the row. The number of elements in \@data should match the number of columns defined for the subreport.

render( $format )

Renders the subreport in the specified format. The $format argument is a string indicating the desired output format (e.g., 'text', 'html'). The default format is 'text'.

name()
Returns the name of the subreport.
title()
Returns the title of the subreport.
columns()
Returns the array reference of column headers for the subreport.
