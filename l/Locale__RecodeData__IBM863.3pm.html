NOMBRE

Locale::RecodeData::IBM863 - Funciones de conversión para IBM863

SINOPSIS

Este módulo es interno en libintl. ¡No lo use directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y funciones para IBM863.

COMENTARIOS

Las siguientes observaciones se han extraído del charmap original:

version: 1.0
 source: IBM Keyboard layouts and code pages, PN 07G4586 June 1991
alias CP863
alias 863

¡Nota: los alias mencionados anteriormente no son necesariamente válidos!

NAME

Locale::RecodeData::IBM863 - Data for character set conversion

SYNOPSIS

    use Locale::RecodeData::IBM863;

DESCRIPTION

This module provides the character set conversion data for IBM code page 863 (Canada French).

This module is used by the Locale::Recode module.

COMMENTS

    This file is part of the libintl-perl package.

    This code page is used in Canada for French.
