NOMBRE

Lire::ReportJob - Objeto utilizado para configurar la generación de informes periódicos

SINOPSIS

use Lire::ReportJob;
use Lire::ReportSchedule;
my $store = Lire::DlfStore->open( 'aStore' );
my $job = new Lire::ReportJob( "webServer" );
my $cfg = $store->get_report_config( 'my_report' );
$job->add_schedule( new Lire::ReportSchedule( 'daily', $cfg );
$job->run( $store, 'daily' );

DESCRIPCIÓN

El objeto Lire::ReportJob se utiliza para configurar y ejecutar trabajos de generación de informes. Estos objetos se configuran habitualmente en un almacén a través del comando lire(1).

new( $nombre, );

Crea un nuevo Lire::ReportJob(). El constructor toma un parámetro que es un identificador.

name()

Devuelve el nombre de este ReportJob.

add_schedule( $horario, ... )

Añade uno o más Lire::ReportSchedule al objeto ReportJob.

schedules()

Devuelve el Lire::ReportSchedule relacionado con este objeto.

run( $tienda, $periodo, [$tiempo] )

Ejecuta todas las generaciones configuradas con un período de 'periodo' utilizando la tienda DlfStore $tienda. Una vez que el método devuelve, se habrán generado informes XML en la DlfStore y se habrán enviado los trabajos de salida asociados con el trabajo de programación. El parámetro $tiempo se utilizará para determinar la ventana de tiempo cubierta por el período. Por defecto, es la hora actual.

VER TAMBIÉN
