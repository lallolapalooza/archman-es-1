DlfQuery(3pm) Documentación de Lire de LogReport DlfQuery(3pm)

NOMBRE

Lire::DlfQuery - Interfaz a envolturas SQL especializadas utilizadas internamente por la API de Lire.

SINOPSIS

use Lire::DlfQuery;

DESCRIPCIÓN

nuevo( $nombre_flujo )

Este es el método constructor para la clase Lire::DlfQuery. Toma un nombre de flujo dlf y un objeto Lire::DlfStore como parámetros. Se espera que Lire::DlfStore contenga el flujo especificado. Ambos parámetros son obligatorios. Este método devuelve una instancia de Lire::DlfQuery.

nombre_flujo()

Devuelve el nombre del flujo DLF sobre el cual se define esta DlfQuery.

unir_flujo( $nombre_flujo )

Este método se puede usar para agregar un flujo ExtendedSchema que se unirá en la consulta.

flujos_unidos()

Devuelve como una referencia de array todos los flujos que forman parte de la consulta.

liberar()

Las DlfQuery anidadas introducen una referencia circular entre los hijos y el padre. Llama a liberar() en la DlfQuery de nivel superior para eliminar la referencia circular cuando el objeto DlfQuery ya no es necesario, de modo que perl pueda recolectar los objetos.

crear_consulta_anidada()

Este método creará y devolverá una instancia de Lire::DlfQuery anidada dentro de la consulta actual. La consulta devuelta se modificará más tarde con métodos regulares.

consultas_anidadas()

Este método devuelve una referencia a un array que contiene todas las consultas anidadas de la consulta actual.

tiene_campo( $nombre_campo )

Devuelve verdadero si hay un campo $nombre_campo definido en la consulta.

definicion_campo( $nombre_campo )

Devuelve la expresión SQL que está asociada con el campo $nombre_campo en la consulta. Este método lanzará una excepción si no hay ningún campo $nombre_campo definido en la consulta.

campos()

Devuelve el nombre de los campos definidos como campos simples en una referencia de array. Estos son campos agregados a través del método agregar_campo().

campos_agrupados()

Devuelve el nombre de los campos definidos como campos de grupo en una referencia de array. Estos son campos agregados a través del método agregar_campo_grupo().

campos_agregados()

Devuelve el nombre de los campos definidos como campos agregados en una referencia de array. Estos son campos agregados a través del método agregar_campo_agregado().

agregar_campo( $nombre_campo, $expr )

Agrega un campo simple a la consulta actual. El primer parámetro será el nombre del campo. El segundo representa una expresión que luego se aliará con el nombre de campo especificado. Solo el nombre del campo es obligatorio.

Se aplican ciertas restricciones: no se pueden agregar campos simples a consultas que contengan subconsultas o campos de grupo.

agregar_campo_agregado( $nombre_campo, $agregado )

Agrega un campo de grupo a la consulta actual. El primer parámetro será el nombre del campo. El segundo representa la expresión agregada que luego se aliará con el nombre de campo especificado. Ambos parámetros son obligatorios.

Solo se pueden agregar campos agregados a consultas que contengan campos de grupo.

agregar_campo_grupo( $nombre_campo, $expr )

Agrega un campo de grupo a la consulta actual. El primer parámetro será el nombre del campo. El segundo representa una expresión que luego se aliará con el nombre de campo especificado. Solo el nombre del campo es obligatorio.

Se aplican ciertas restricciones: no se pueden agregar campos de grupo a consultas que contengan campos simples.

establecer_clausula_ordenar_por( $clausula )

Establece la cláusula de orden de la consulta, es decir, lo que aparecerá en la cláusula "ORDER BY" de la declaración SQL.

clausula_ordenar_por()

Devuelve la cláusula ORDER BY actual o undef cuando no se estableció ninguna.

establecer_especificacion_ordenacion( $espec )

especificacion_ordenacion()

Devuelve la especificación de ordenación que se estableció usando establecer_especificacion_ordenacion(). Si no se estableció ninguna especificación de ordenación (o se estableció usando el método establecer_clausula_ordenar_por()), esto será undef.

establecer_limite()

Establece la cláusula de límite de la consulta, es decir, lo que aparecerá en la cláusula "LIMIT" de la declaración SQL. Este método también tendrá un impacto en el manejo interno de la consulta.

limite()

Devuelve el número máximo de registros que deben ser devueltos por la consulta. Cuando no se estableció ningún límite, devuelve 0.

establecer_clausula_filtro( $clausula, @parametros )

Establece la cláusula de filtro de la consulta, siendo la cláusula de filtro las restricciones SQL sobre los resultados que serán devueltos por la consulta, es decir, lo que aparecerá en la cláusula "WHERE" de la declaración SQL.

Es compatible con el manejo de DBI de marcadores de posición ('?'). Por supuesto, la cantidad de marcadores de posición debe ser la misma que la cantidad de valores y variables que se pasan en @parametros.

Solo el parámetro de cláusula es obligatorio, la cantidad de elementos en @parametros depende de la cantidad de marcadores de posición especificados en él.

clausula_filtro()

Devuelve la cláusula WHERE actual o undef cuando no se estableció ninguna.

ejecutar()

Este método ejecuta la consulta a través de la interfaz de base de datos y devuelve una instancia de Lire::DlfResult para obtener los datos.

ejecutar_resumen()

Igual que ejecutar(), excepto que la consulta se ejecuta como una consulta de resumen.

Lire::DlfQuery(3pm) — Lire 2.1.1

NAME

Lire::DlfQuery - Interface to the DLF Query Language

SYNOPSIS

use Lire::DlfQuery;

my $query = Lire::DlfQuery->new(
    db = >&DB_DATA,
);

my @results = $query->search(
    query = "author='Douglas Adams'",
);

for my $hit in @results {
    print "Found: ", $hit->title, "\n";
}

my $hit = $query->get(
    id = 123,
);
print $hit->title, "\n";

my $count = $query->count(
    query = "year:1980",
);
print $count, "\n";

my $field = $query->field(
    name = "title",
);
print $field->type, "\n";

my $field = $query->field(
    name = "title",
);
my @terms = $field->terms();
print "Found ", scalar @terms, " terms in title.\n";

my @fields = $query->fields();
for my $f in @fields {
    print $f->name, "\n";
}

my $terms = $query->terms(
    field = "title",
);
print "Found ", scalar @terms, " terms in title.\n";

$query->commit();

$query->close();

DESCRIPTION

This module provides an interface to the DLF query language.

The DLF Query Language is a simple query language that allows you to search for documents based on their metadata.

The Lire::DlfQuery module provides the following methods:

new
Creates a new Lire::DlfQuery object.
search
Searches for documents matching the given query.
get
Retrieves a document by its ID.
count
Counts the number of documents matching the given query.
field
Retrieves a field by its name.
fields
Retrieves all fields in the index.
terms
Retrieves all terms in a given field.
commit
Commits any changes to the index.
close
Closes the connection to the index.
