NOMBRE

Log::Message::Handlers - Manejadores de mensajes para Log::Message

SINOPSIS

# Usado implícitamente por Log::Message para servir como manejadores para
# objetos Log::Message::Item
# Crea tu propio archivo con un paquete llamado
# Log::Message::Handlers para añadir a los existentes, o incluso
# para sobrescribirlos
$item->carp;
$item->trace;

DESCRIPCIÓN

Log::Message::Handlers proporciona manejadores para objetos Log::Message::Item. El manejador correspondiente al nivel (ver la página del manual de Log::Message::Item para una explicación sobre los niveles) será llamado automáticamente al almacenar el error.

Los manejadores también pueden ser llamados explícitamente en un objeto Log::Message::Item si se desea (ver la página del manual de Log::Message sobre cómo recuperar los objetos Item).

Manejadores por defecto

log

Simplemente registrará el error en la pila, y no hará nada especial

carp

Utilizará `carp` (ver la página del manual de Carp) con el error, y añadirá la marca de tiempo de cuándo ocurrió.

croak

Utilizará `croak` (ver la página del manual de Carp) con el error, y añadirá la marca de tiempo de cuándo ocurrió.

cluck

Utilizará `cluck` (ver la página del manual de Carp) con el error, y añadirá la marca de tiempo de cuándo ocurrió.

confess

Utilizará `confess` (ver la página del manual de Carp) con el error, y añadirá la marca de tiempo de cuándo ocurrió.

die

Simplemente fallará (`die`) con el mensaje de error del ítem.

warn

Simplemente advertirá (`warn`) con el mensaje de error del ítem.

trace

Proporcionará un rastreo de este ítem de error hasta el primero que ocurrió, utilizando `cluck` con cada ítem a medida que lo encuentra.

Manejadores personalizados

Si deseas proporcionar tus propios manejadores, simplemente puedes hacer lo siguiente:

  • Crea un archivo que contenga un paquete con el nombre "Log::Message::Handlers"
  • Crea subrutinas con el mismo nombre que los niveles que deseas manejar en el módulo Log::Message (ver la página del manual de Log::Message para explicación sobre los niveles)
  • Incluye ese archivo en tu programa, o añádelo en tu configuración (ver la página del manual de Log::Message::Config para explicación sobre cómo usar un archivo de configuración)

Y eso es todo, el manejador estará ahora disponible para manejar mensajes por ti.

Los argumentos que un manejador puede recibir son aquellos especificados por la clave "extra", al almacenar el mensaje. Ver la página del manual de Log::Message para detalles sobre los argumentos.

VER TAMBIÉN

Log::Message, Log::Message::Item, Log::Message::Config
