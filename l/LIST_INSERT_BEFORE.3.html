NOMBRE

LIST_EMPTY, LIST_ENTRY, LIST_FIRST, LIST_FOREACH, LIST_HEAD, LIST_HEAD_INITIALIZER, LIST_INIT, LIST_INSERT_AFTER, LIST_INSERT_BEFORE, LIST_INSERT_HEAD, LIST_NEXT, LIST_REMOVE - implementación de una lista doblemente enlazada

BIBLIOTECA DE FUNCIONES

Biblioteca C estándar (libc, -lc)

SINTAXIS

#include <sys/queue.h>
LIST_ENTRY(TYPE);
LIST_HEAD(HEADNAME, TYPE);
LIST_HEAD LIST_HEAD_INITIALIZER(LIST_HEAD head);
void LIST_INIT(LIST_HEAD *head);
int LIST_EMPTY(LIST_HEAD *head);
void LIST_INSERT_HEAD(LIST_HEAD *head,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_BEFORE(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_AFTER(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
struct TYPE *LIST_FIRST(LIST_HEAD *head);
struct TYPE *LIST_NEXT(struct TYPE *elm, LIST_ENTRY NAME);
LIST_FOREACH(struct TYPE *var, LIST_HEAD *head, LIST_ENTRY NAME);
void LIST_REMOVE(struct TYPE *elm, LIST_ENTRY NAME);

DESCRIPCIÓN

Estas macros definen y operan sobre listas doblemente enlazadas.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo LIST_ENTRY, llamado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario, que debe ser declarada usando la macro LIST_HEAD().

Creación

Una lista está encabezada por una estructura definida por la macro LIST_HEAD(). Esta estructura contiene un puntero único al primer elemento de la lista. Los elementos están enlazados doblemente, de manera que un elemento arbitrario puede ser removido sin recorrer la lista. Los elementos nuevos pueden agregarse a la lista después de un elemento existente, antes de otro existente o al frente de la lista. Una estructura LIST_HEAD se declara así:


LIST_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos que se enlazan a la lista. Una dirección de puntero al frente de la lista puede ser luego declarada así:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

LIST_ENTRY() declara una estructura que conecta los elementos de la lista.

LIST_HEAD_INITIALIZER() evalúa a un inicializador para la lista head.

LIST_INIT() inicializa la lista referenciada por head.

LIST_EMPTY() devuelve verdadero si la lista está vacía, y falso si contiene al menos un elemento.

Inserción

LIST_INSERT_HEAD() inserta el elemento elm al frente de la lista.

LIST_INSERT_BEFORE() inserta el elemento elm antes del elemento listelm.

LIST_INSERT_AFTER() inserta el elemento elm después del elemento listelm.

Traslado

LIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

LIST_NEXT() devuelve el siguiente elemento de la lista, o NULL si es el último.

LIST_FOREACH() recorre la lista referenciada por head en la dirección forward, asignando cada elemento a var.

Eliminación

LIST_REMOVE() elimina el elemento elm de la lista.

VALOR DE RETORNO

LIST_EMPTY() devuelve no cero si la lista está vacía, y cero si contiene al menos un elemento.

LIST_FIRST() y LIST_NEXT() devuelven un puntero al primer o siguiente TYPE estructura, respectivamente.

LIST_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la lista head.

ESTANDARES

BSD.

HISTORIA

4.4BSD.

PROBLEMAS

LIST_FOREACH() no permite remover o liberar var dentro del bucle, ya que podría interferir con el recorrido. LIST_FOREACH_SAFE(), que está presente en los BSDs pero no en glibc, corrige este límite al permitir que var sea removido y liberado dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    LIST_ENTRY(entry) entries;              /* Lista */
};
LIST_HEAD(listhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct listhead head;                   /* Lista encabezada */
    int i;
    LIST_INIT(&head);                       /* Inicializar la lista */
    n1 = malloc(sizeof(struct entry));      /* Insertar al frente */
    LIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    LIST_INSERT_AFTER(n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    LIST_INSERT_BEFORE(n2, n3, entries);
    i = 0;                                  /* Recorrido forward */
    LIST_FOREACH(np, &head, entries)
        np->data = i++;
    LIST_REMOVE(n2, entries);               /* Eliminación */
    free(n2);
                                            /* Recorrido forward */
    LIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de lista */
    n1 = LIST_FIRST(&head);
    while (n1 != NULL) {
        n2 = LIST_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    LIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
