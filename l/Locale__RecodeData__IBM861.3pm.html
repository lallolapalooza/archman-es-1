NAME

Locale::RecodeData::IBM861 - Rutinas de conversión para IBM861

SYNOPSIS

Este módulo es interno en libintl. No lo use directamente!

DESCRIPTION

Este módulo contiene las tablas de conversión y rutinas para IBM861.

COMMENTS

Las siguientes observaciones se extrajeron del original charmap:

versión: 1.0
 fuente: IBM NLS RM Vol2 SE09-8002-01, marzo 1990
 alias CP861
 alias 861
 alias CP-IS

Nota: Los alias mencionados arriba no son necesariamente válidos!

Locale::RecodeData::IBM861(3pm)

NAME

Locale::RecodeData::IBM861 - Perl module for recoding IBM code page 861 (Croatian/Serbian Latin)

SYNOPSIS

use Locale::RecodeData::IBM861;

DESCRIPTION

This module provides the character mapping for IBM code page 861, also known as Croatian/Serbian Latin.

This code page is a subset of Latin 1 with some additional characters. It's typically used on DOS systems.

COMMENTS

This code page is identical to CP861 and CP861(PC).
