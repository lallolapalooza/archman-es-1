NOMBRE

Lire::DlfConverter - Interfaz base de todos los convertidores DLF.

SINOPSIS

use base qw/ Lire::DlfConverter /;

DESCRIPCIÓN

Este paquete define la interfaz que debe ser implementada por todos los convertidores DLF. Todos los métodos definidos en este paquete lanzarán una excepción de 'método no implementado' si son llamados.

MÉTODOS DE INFORMACIÓN DE METADATOS

Estos métodos proporcionan información al framework Lire sobre el convertidor DLF.

name()

Devuelve el nombre del convertidor DLF, es decir, el nombre del servicio (también conocido como formato de registro).

Ejemplo: "combined"

title()

Devuelve un nombre más amigable para el Convertidor DLF.

Ejemplo: "Convertidor DLF de Formato de Registro Combinado"

description()

Devuelve una documentación basada en XML DocBook del Convertidor DLF.

Ejemplo: <para>Este convertidor DLF se puede utilizar para procesar archivos de registro en el Formato de Registro Combinado al esquema DLF de www.</para>

schemas()

Devuelve una lista de esquemas DLF para los cuales se pueden escribir registros DLF a partir de los datos contenidos en el archivo de registro.

Ejemplo: Para los convertidores DLF combinados, sería 'www'.

Para el convertidor 'nms' podría ser "qw/daemon email/" lo que significa que el convertidor DLF escribe registros DLF en el hipotético esquema "daemon" (inicio, paradas, reinicios de servidor, etc.) y el esquema de correo electrónico.

Solo debe contener esquemas 'base' (también conocido como super-servicio). No deben aparecer nombres de esquemas extendidos o derivados en esa lista. (Esos están reservados para los analizadores).

handle_log_lines()

Este método debe devolver verdadero si el DlfConverter procesa archivos de registro orientados a líneas. Este es el valor predeterminado. Si este método devuelve falso, solo se llamará al método process_log_file(), de lo contrario, el método process_log_line() se utilizará para cada línea de entrada.

Métodos de implementación

Estos son los métodos donde se realiza el trabajo del convertidor DLF. El método init_dlf_converter() se llamará una vez antes de que ocurra cualquier procesamiento. Después, process_log_line() se llamará una vez por cada línea que fue marcada para continuación del registro y por cada línea contenida en el archivo de registro. El método finish_conversion() se llamará una vez que se procesen todas las líneas. Cualquier excepción (die no capturada) que ocurra durante cualquiera de los métodos abortará el proceso de conversión.

init_dlf_converter( $process, [$config] )

Este método será llamado por el framework antes de procesar el archivo de registro. Este método debe ser utilizado por el convertidor para inicializar su estado.

El parámetro $process contiene el objeto Lire::DlfConverterProcess que está controlando el proceso de conversión.

El parámetro $config contiene datos de configuración que se especificaron en el ImportJob para ese convertidor. Para registrar especificaciones de configuración para su DlfConverter, solo necesita definir una especificación de configuración bajo el nombre converter_name_properties. Esto debería ser un RecordSpec o un ObjectSpec.

process_log_file( $process, $fd )

Se llama a este método para que el convertidor pueda convertir los datos contenidos en el manejador de archivo $fd a DLF. Este método solo se utiliza cuando el método handle_log_lines() devolvió falso.

$process contiene una referencia al objeto Lire::DlfConverterProcess que controla el proceso de conversión y define la API para escribir DLF e informar errores.

process_log_line( $process, $line )

Este método es llamado por el framework una vez por cada línea de registro presente en el archivo de registro. Este método solo se llama si el método handles_log_lines() devolvió verdadero.

$process es una referencia al objeto Lire::DlfConverterProcess. Este objeto define un método para informar errores, guardar líneas para fines de continuación y escribir registros DLF.

$line contiene la línea de registro que debe procesarse con el final de línea eliminado.

finish_conversion( $dlf_store )

Este método es llamado una vez por el framework una vez que todas las líneas de registro han sido procesadas. Puede ser utilizado por el convertidor para escribir cualquier registro DLF que pueda quedar debido a un análisis con estado.
