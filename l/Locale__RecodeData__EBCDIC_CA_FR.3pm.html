NOMBRE

Locale::RecodeData::EBCDIC_CA_FR - Rutinas de conversión para EBCDIC_CA_FR

SINTAXIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para EBCDIC-CA-FR.

COMENTARIOS

Los siguientes comentarios se han extraído del charmap original:

versión: 1.0
 fuente: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, Abril 1987

¡Por favor, ten en cuenta que los alias mencionados anteriormente no son necesariamente válidos!
