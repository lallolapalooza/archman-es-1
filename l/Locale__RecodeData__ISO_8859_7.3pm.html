Nombre

Locale::RecodeData::ISO_8859-7 - Rutinas de conversión para ISO-8859-7

Sinopsis

Este módulo es interno en libintl. ¡No lo use directamente!

Descripción

Este módulo contiene las tablas de conversión y las rutinas para ISO-8859-7.

Comentarios

NOMBRE

Locale::RecodeData::ISO_8859_7 — Greek (ISO 8859-7) character set

SINOPSIS

    use Locale::RecodeData::ISO_8859_7;

DESCRIPCION

This module provides the mappings for the Greek (ISO 8859-7) character set. It is used by the Locale::Recode module.

The ISO 8859-7 character set covers the Greek alphabet.

The following table lists the characters.

COMMENTS

The character set is also known as ELOT-928.
