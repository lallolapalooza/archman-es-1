NOMBRE

Lire::DlfStream - Interfaz para el flujo de datos DLF

SINOPSIS

use Lire::DlfStore;
my $store = Lire::DlfStore->open( "mi_tienda" );
my $dlf_stream = $store->open_dlf_stream( "www", "r" );
print "Los datos comienzan el ", scalar localtime $dlf_stream->start_time(), "\n";
print "Los datos terminan el   ", scalar localtime $dlf_stream->end_time(), "\n";
while ( my $dlf = $dlf_stream->read_dlf() ) {
  ...
}

DESCRIPCIÓN

Este objeto encapsula un flujo DLF.

nombre

Devuelve el nombre del esquema del DlfStream.

mode()

Devuelve el modo en el que se abrió el DlfStream.

sort_spec()

Devuelve la especificación de ordenación establecida en el flujo.

close()

Este método debe llamarse cuando Lire::DlfStream ya no sea necesario, de lo contrario, el mismo DlfStream no podrá abrirse hasta entonces.

nrecords()

Devuelve el número de registros DLF en el flujo.

start_time()

Devuelve la marca de tiempo del registro DLF más antiguo en el flujo en segundos desde la época.

end_time()

Devuelve la marca de tiempo del registro DLF más reciente en el flujo en segundos desde la época.

read_dlf()

Devuelve una referencia hash que contiene el siguiente registro DLF en el flujo. Devuelve undef una vez que se alcanza el final del flujo.

Este método lanzará una excepción si el DlfStream no está abierto en modo 'r' o si hay un error al leer el registro DLF.

read_dlf_aref()

Devuelve el siguiente registro DLF en el flujo como una referencia array. Los campos están en el orden especificado por el esquema.

Este método lanzará una excepción si el DlfStream no está abierto en modo 'r' o si hay un error al leer el registro DLF.

write_dlf( $dlf, [ $link_ids ] )

Escribe los campos contenidos en la referencia hash $dlf al flujo DLF.

Este método lanzará una excepción si hay un error al escribir el registro DLF o si el flujo no está abierto en modo 'w'.

El parámetro $link_ids se utiliza cuando el esquema del flujo es un Lire::DerivedSchema. Debe ser una referencia array que contenga los ids DLF de los registros que están enlazados a este registro.

clean( [ $time ] )

Este método eliminará todos los registros DLF anteriores a $time. Si $time se omite, se eliminarán todos los registros Dlf.
