NAME

Locale::RecodeData::MACGREEK – Mac Greek.

SYNOPSIS

use Locale::RecodeData qw( :macgreek );

DESCRIPTION

This module defines the Mac Greek character set.

The mapping is taken from the MAC_GREEK encoding defined in the recodedata.pm file.

COMMENTS

This encoding contains a MAC_GREEK definition, which is used to convert between Mac Greek and other character sets.
