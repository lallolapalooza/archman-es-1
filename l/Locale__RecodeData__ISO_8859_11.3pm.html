NOMBRE

Locale::RecodeData::ISO_8859_11 - Rutinas de conversión para ISO-8859-11

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas y rutinas de conversión para ISO-8859-11.

COMENTARIOS

Los siguientes comentarios se han extraído del mapade caracteres original:

fuente: Guido Flohr E<lt>guido.flohr@cantanea.comE<gt>
La codificación ISO-8859-11 aún no es oficial en el momento de escribir esto.
Se basa en TIS-620, pero con la adición del espacio de no separación.
El mapeo de 0xfc-0xff es idéntico a Latin-1, pero esto debería comprobarse.

¡Tenga en cuenta que los alias enumerados anteriormente no son necesariamente válidos!

NAME

Locale::RecodeData::ISO_8859_11 — Thai (TIS 620-2533) to Unicode mapping

SYNOPSIS

use Locale::RecodeData::ISO_8859_11;

DESCRIPTION

This module provides the mapping for the Thai character set as defined by TIS 620-2533 (also known as ISO 8859-11). It is used by the Locale::Recode module to convert between this character set and other character sets.

COMMENTS

The Thai TIS 620-2533 standard is essentially a subset of Unicode, specifically the characters in the U+0E00 to U+0E7F range.

The following table shows the mapping between TIS 620-2533 and Unicode. Note that TIS 620-2533 does not define all characters within the U+0E00 to U+0E7F range, and this mapping only includes the characters defined by the standard.
