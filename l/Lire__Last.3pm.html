NOMBRE

Lire::Last - Clase de Lire que implementa el operador last

SINOPSIS

use Lire::Last

DESCRIPCIÓN

Clase que implementa el operador last. Este operador mostrará el último valor que aparezca en su campo cuando los registros DLF se ordenen de acuerdo con el atributo "sort_fields". El orden de clasificación predeterminado es la clasificación de marca de tiempo predeterminada.

MÉTODOS

new( %params )

Crea un nuevo objeto Lire::Last.

sort_fields( [$new_sort_fields] )

Devuelve los campos que se utilizarán para ordenar los registros DLF. Esta es una referencia a una matriz de nombres de campos DLF.

Si se establece el parámetro $new_sort_fields, se utilizará como el nuevo orden de clasificación. Debe ser una referencia a una matriz y solo debe contener nombres de campo válidos para el esquema de la especificación del informe actual.

Cuando no se establecen sort_fields, el valor predeterminado es utilizar el campo de marca de tiempo predeterminado. =cut
