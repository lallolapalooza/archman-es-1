NOMBRE

Locale::RecodeData::IBM855 - Rutinas de conversión para IBM855

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo está generado y contiene las tablas y rutinas de conversión para IBM855.

COMENTARIOS

Los siguientes comentarios han sido extraídos del mapacarácter original:

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP855
alias 855

¡Tenga en cuenta que los alias enumerados anteriormente no son necesariamente válidos!

Locale::RecodeData::IBM855(3pm) -- Arch Linux man pages

NAME

Locale::RecodeData::IBM855 – Locale::RecodeData(3) Backend for the IBM CP855 character encoding.

SYNOPSIS

use Locale::RecodeData::IBM855;

DESCRIPTION

This module provides the necessary data for Locale::Recode(3) to convert data to and from the IBM855 character encoding. IBM855 is a codepage used by MS-DOS for Cyrillic languages.

This module is not meant to be used directly. It is intended to be loaded and used by Locale::Recode(3).
