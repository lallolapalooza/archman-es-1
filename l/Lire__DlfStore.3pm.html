DlfStore(3pm) Documentación de Lire de LogReport DlfStore(3pm)

NOMBRE

Lire::DlfStore - Interfaz a una tienda DLF

SINOPSIS

use Lire::DlfStore;
my $store = Lire::DlfStore->open( "mystore", 1 );
my $avail_streams = $store->dlf_streams;

DESCRIPCIÓN

open( $store_path, [ $create ] );

Abre una Lire::DlfStore ubicada en el directorio señalado por $store_path y devuelve una instancia de Lire::DlfStore que puede usarse para acceder a su contenido.

Si la tienda $store_path no fue creada, el método fallará a menos que el parámetro $create haya sido establecido a true.

Si la tienda está bloqueada por otro proceso, el método también fallará.

Intentar abrir la misma tienda dos veces desde el mismo proceso fallará.

close()

Llama a este método para liberar el bloqueo que tiene el proceso actual sobre la tienda. Si no lo llamas, se llamará automáticamente cuando la referencia a la tienda salga del ámbito, pero es mejor no depender de esto para cerrar tus tiendas.

is_closed()

Devuelve true si esta DlfStore fue cerrada y ya no puede ser utilizada.

path

Devuelve la ruta a la tienda. Este es el argumento utilizado para crear la tienda.

config

Devuelve la configuración de la tienda instanciada como un Lire::Config::ConfigFile.

import_jobs()

Devuelve como una referencia a array la lista de ImportJob actualmente configurados en la DlfStore

report_jobs()

Devuelve como una referencia a array la lista de ReportJob actualmente configurados en la DlfStore

has_report_config( $name )

Devuelve true si existe una configuración de informe llamada $name en esta DlfStore.

report_configurations()

Devuelve como una referencia a array la lista de ReportConfig actualmente configurados en la DlfStore

get_report_config( $name )

Devuelve el objeto Lire::ReportConfig llamado $name. Lanza una excepción si no existe.

MÉTODO RELACIONADO CON STREAMS DLF

Una DlfStore puede contener múltiples Dlf Streams. Dlf Stream son datos que cumplen con un esquema DLF. Los streams se representan mediante objetos Lire::DlfStream.

dlf_streams()

Lista los streams DLF disponibles en la tienda DLF. Esto devuelve una lista de nombres de DlfSchema.

has_dlf_stream( $name )

Devuelve true si la DlfStore contiene un DlfStream que cumple con el esquema $name.

get_stream_config( $name )

Devuelve la instancia de Lire::Config::Dictionary que contiene la configuración del stream para el DlfStream $name. Este método creará una instancia de la configuración por defecto si es necesario. Si $name no es un nombre de esquema válido, este método lanzará un error.

configured_dlf_streams()

Devuelve la lista de DlfStreams que son referenciados por la configuración de la tienda. Este es el resultado de dlf_streams() más todos los esquemas que existen y son utilizados por algún ImportJob o DlfStreamSpec configurado.

open_dlf_stream( $name, [$mode], [$sort_spec] )

Devuelve un objeto Lire::DlfStream que puede ser utilizado para acceder a un stream DLF en el esquema $name. El parámetro $mode puede ser "r" o "w" y por defecto es "r".

Si el modo es "w", el Lire::DlfStream se abre para escritura (se pueden insertar nuevos registros DLF). Si la DlfStore no contenía un stream $name, se creará uno vacío.

Si el modo es "r", el Lire::DlfStream se abre para lectura (no se pueden insertar registros DLF). Se lanzará una excepción si no hay un stream $name disponible.

Cuando el stream se abre en modo "r", se puede especificar un orden de ordenación pasando un $sort_spec. Un $sort_spec es una lista separada por espacios de nombres de campos que deben especificar el orden de ordenación. El orden de ordenación inverso se puede especificar prefijando el nombre del campo con '-'.

run_analysers( $stream, [ $dlf_source ] )

Ejecuta todos los analizadores configurados en el stream DLF $stream. $dlf_source limita los registros que deben ser analizados.

clean_streams()

Elimina registros que son más antiguos que lo configurado en el parámetro 'keep_days'.

MÉTODO RELACIONADO CON INFORMES

Una DlfStore también contiene los informes generados periódicamente. Estos informes generalmente se configuran a través del comando lire(1). Los informes generados se almacenan en el formato nativo XML de Lire por período.

put_report( $job, $schedule, $report )

Guarda el Lire::Report $report que fue generado por $job y $schedule. Devuelve el nombre del archivo donde se guardó el informe.

find_report_source( $job, $schedule, [$time] )

Este método devolverá una referencia a un hash que contiene parámetros sobre cómo se debe generar el ReportJob $job para el ReportSchedule $schedule. Los límites del período se determinan según $time, que por defecto es ahora.

La referencia al hash contendrá una clave 'source' y posiblemente otras:

source
Especifica a partir de qué tipo de fuente se debe generar el informe. Los valores posibles son 'dlf' cuando el informe debe generarse a partir de DLF, 'merging' cuando el informe debe generarse fusionando informes XML previos y 'none' cuando no hay datos disponibles para ese período y el informe no puede generarse.

Tenga en cuenta que 'merging' solo está disponible como fuente para horarios superiores a 'diario'. Es decir, los informes 'horarios' y 'diarios' solo se pueden generar a partir de DLF. También es importante el hecho de que solo los informes 'diarios' están disponibles como fuente de fusión. Por lo tanto, necesita un horario de informes diarios para generar horarios 'semanales', 'mensuales' y 'anuales' fusionando.

start
La marca de tiempo en la que comienzan los datos disponibles para el período. Esto puede ser mayor que el límite inicial del período solicitado.
end
La marca de tiempo en la que finalizan los datos disponibles para el período. Esto puede ser menor que el límite final del período solicitado.
coverage
Un entero entre 0 y 100 que representa la proporción de datos disponibles para el período solicitado
