NOMBRE

Locale::RecodeData::IBM500 - Rutinas de conversión para IBM500

SINOPSIS

Este módulo es interno de libintl. ¡No lo use directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para IBM500.

COMENTARIOS

Las siguientes observaciones se han extraído del original charmap:

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP500
alias 500
alias 500V1
alias EBCDIC-CP-BE
alias EBCDIC-CP-CH

Nota: ¡Los alias mencionados arriba no son necesariamente válidos!

NAME

Locale::RecodeData::IBM500 - Locale::Recode character set.

SYNOPSIS

  use Locale::Recode::IBM500;
  # ...

DESCRIPTION

This module provides the mapping for the IBM500 character set (also known as CP500, Code page 500). It is a variant of EBCDIC.

COMMENTS

This module is part of the Locale::Recode distribution. It is not intended to be used directly. See the documentation for Locale::Recode for details.
