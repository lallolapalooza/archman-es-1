NOMBRE

Lire::Group - Clase base para la implementación del agrupador de rangegroup

SINOPSIS

use Lire::Rangegroup;

DESCRIPCIÓN

Este módulo es la clase base para la implementación del agrupador de rangegroup. Este agrupador dividirá los registros DLF según un campo numérico. Los agrupadores de rangegroup crean clases numéricas (por ejemplo, 1-10, 11-20, etc.) y los registros DLF serán agrupados con otros registros que están en la misma clase.

CONSTRUCTOR

new( %params )

Crea una nueva instancia de un agrupador de rangegroup. En adición a los parámetros normales de operadores de reporte, el agrupador de rangegroup puede tomar varios parámetros adicionales:

field
Este parámetro es obligatorio. Debe ser el nombre del campo DLF que se utilizará como clave para este agrupador.
range-size
Este parámetro es obligatorio. Se utilizará como el tamaño de cada grupo de rangegroup.
range-start
El número a partir del cual comienza el primer grupo de rangegroup. Por defecto es 0.
min-value
El valor inferior a este número se sorteará en el primer grupo de rangegroup.
max-value
El valor superior a este número se sorteará en el último grupo de rangegroup.
size-scale
Este parámetro puede usarse para crear una escala logarítmica. En este caso, cada nuevo grupo de rangegroup será más grande que el anterior según el valor de size-scale. Por ejemplo, establecer range-size=5 y size-scale=2 creará rangegroups como [0-5>, [5-15>, [15-35>, ...

MÉTODOS

field( [$new_field] )

Devuelve el nombre del campo DLF que se utilizará como clave de agrupación.

Si el parámetro $new_field es establecido, cambia el campo de agrupación. Este debe ser el nombre de un campo tipo de reporte en el esquema de especificaciones DLF.

range_start( [$new_start] )

Devuelve el número que es el límite inferior del primer grupo de rangegroup.

Si el parámetro $new_start es establecido, cambia el límite inferior del primer grupo de rangegroup. Esto debe ser un entero positivo o el nombre de uno de los parámetros de la especificación del reporte.

range_size( [$new_size] )

Devuelve el ancho de cada grupo de rangegroup.

Si el parámetro $new_size es establecido, cambia el ancho de cada grupo de rangegroup. Esto debe ser un entero positivo o el nombre de uno de los parámetros de la especificación del reporte.

min_value( [$new_min] )

Devuelve el número bajo el cual no se creará ningún nuevo grupo de rangegroup.

Si el parámetro $new_min es establecido, cambia el límite inferior bajo el cual no se creará ningún nuevo grupo. Esto debe ser un número o el nombre de uno de los parámetros de la especificación del reporte.

max_value( [$new_max] )

Devuelve el número sobre el cual no se creará ningún nuevo grupo de rangegroup.

Si el parámetro $new_max es establecido, cambia el límite superior sobre el cual no se creará ningún nuevo grupo. Esto debe ser un número o el nombre de uno de los parámetros de la especificación del reporte.

size_scale( [$new_size_scale] )

Devuelve el multiplicador que se aplicará a cada ancho de grupo de rangegroup después del primero.

Cuando este atributo es mayor que 1, crea una escala logarítmica donde cada nuevo grupo de rangegroup es más ancho que el anterior según el valor de size_scale. Por ejemplo, establecer size_scale=2 y range-size=5 crea rangegroups como [0-5>, [5-15>, [15-35>, ...

Si el parámetro $new_size_scale es usado, cambia el atributo a este nuevo valor. Debe ser un entero positivo o también puede ser un referencia a un parámetro.
