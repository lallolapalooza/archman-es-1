NOMBRE

Lire::Param - Objeto que representa un parámetro en una especificación XML.

DESCRIPCIÓN

Lire::Param son objetos que representan parámetros en una especificación XML. El objeto se utiliza para representar la especificación del parámetro así como su valor actual.

new( 'nombre' => $nombre, 'tipo' => $tipo, [ 'defecto' => $defecto ] )

Crea un nuevo objeto Lire::Param.

nombre()

Devuelve el nombre de este parámetro.

tipo()

Devuelve el tipo de este parámetro.

valor( [ $nuevo_valor ] )

Devuelve (y opcionalmente modifica) el valor actual para este parámetro. Si no se estableció ningún valor, pero hay un valor predeterminado disponible, se devolverá el valor predeterminado.

defecto( [ $nuevo_defecto ] )

Devuelve (y opcionalmente cambia) el valor predeterminado del parámetro.

descripción( [ $nueva_descripción ] )

Devuelve (y opcionalmente cambia) la descripción actual del parámetro.

as_type_spec()

Devuelve un objeto Lire::Config::TypeSpec que representa adecuadamente el parámetro actual.

VER TAMBIÉN

Lire::Config::TypeSpec(3pm), Lire::XMLSpecContainer(3pm)
