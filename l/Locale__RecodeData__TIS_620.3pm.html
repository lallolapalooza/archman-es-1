NAME

Locale::RecodeData::TIS_620 - TIS-620 character set

SYNOPSIS

    require Locale::RecodeData::TIS_620;

DESCRIPTION

This module provides the mapping for the Thai TIS-620 character set. It does not export any subroutines.

This module is used by the Locale::Recode(3) module. You should not use this module directly.

COMMENTS

TIS-620 is the Thai Industrial Standard for encoding Thai characters. It is basically the same as the character set previously known as CP874, but with some differences for some characters.

You should always use the alias TIS-620 instead of the alias CP874, as CP874 may be implemented differently on other platforms.
