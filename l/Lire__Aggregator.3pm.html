NAME

Lire::Aggregator - Clase base para todos los operadores de agrupador

SYNOPSIS

use base qw/ Lire::Aggregator /;

DESCRIPCIÓN

La clase Lire::Aggregator es la clase base para todos los operadores de agrupador disponibles en Lire. Implementa comportamientos comunes a todos los operadores de agrupador y define algunas métodos que deben ser implementadas por subclases.

En Lire, un operador de agrupador es un operador que agrupa registros de DLF. Otros operadores como avg o sum calculan valores en estos grupos de registros de DLF. Los operadores de agrupador pueden ser anidados para calcular valores en grupos hierárquicos.

MÉTODOS

ops( [$new_ops] )

Devuelve los operadores contenidos en este agrupador. El valor devuelto es un referencia a un array de objetos Lire::ReportOperator.

Si el $new_ops se utiliza, cambia el contenido de este agrupador a estos nuevos valores.

El $new_ops debe ser un referencia a un array conteniendo objetos Lire::ReportOperator.

op_by_name( $name )

Devuelve el operador con nombre $name en este agrupador. Se lanzará una excepción si no existe tal operador.

is_name_defined( $name )

Devuelve verdadero si este agrupador contiene un operador con nombre $name.

MÉTODOS PARA SUBCLASES

print( $fh, $pfx )

Este método implementa el método print() requerido por Lire::ReportOpetor. Imprime el elemento XML nombrado después de op() y se encarga de escribir la representación XML de todos los hijos operadores. También se encarga de escribir el nombre y el atributo label. Otros atributos pueden ser añadidos al elemento XML mediante la sobrescripción de la método xml_attrs(). Otros elementos hijos pueden ser añadidos al flujo de salida mediante la sobrescripción de la método print_content().

xml_attrs()

Este método puede usarse para añadir atributos XML adicionales. El string devuelto será output en el elemento XML.

print_content( $fh, $pfx )

Este método imprime los operadores contenidos en este agrupador. Puede sobrescribirse para añadir otros elementos.

create_group_info( $info )

FIXME

Las subclases deben sobrescribir el método create_categorical_info() para esta implementación.

create_categorical_info( $info )

Este método se usa por la implementación de create_group_info() para añadir la información de ColumnInfo categorica proporcionada por el agrupador.

create_entries( $subreport )

Este método se usa por Lire::ReportSpec para llenar el Lire::Report::Subreport con los registros cuando se crea el subreport.

El parámetro $subreport contiene el objeto Subreport al cual se deben agregar los registros del subreport.

Este método se llamara solo en el agrupador de nivel superior del informe.

build_query( $query )

FIXME

set_group_summary( $group, $row )

FIXME

create_entry( $group, $row )

FIXME

API DE AGREGADOR DE MERGADO

Define métodos adicionales requeridos por la implementación de Aggregator para poder mergar datos.

La implementación de base del Aggregator se encarga de mergar la información de resumen incluida en los informes de Lire XML.

Las especificaciones de mergado específicas para el agrupador deben ser implementadas en los métodos init_agggregator_data(), update_agggregator_data() y end_agggregator_data().

Esta clase también se encarga del caso cuando el agrupador es el agrupador de nivel superior, es decir, el hijo directo del elemento report-calc-spec en la especificación del informe.

IMPLEMENTACIÓN DE LOS MÉTODOS DE MERGADO DE Lire::ReportOperator

init_merge( $period_start, $period_end )

La implementación por defecto asegura que todos los operadores contados sean inicializados.

La implementación de un agregador específico debe heredar de este método, si lo sobrescribe.

end_merge()

La implementación por defecto asegura que todos los operadores reciban el evento end_report().

Las subclases deben heredar de este método, si lo sobrescriben.

init_group_data()

El Aggregator implementa init_group_data(). Se encarga de calcular la información de resumen. La subclase realiza lo mismo en init_agggregator_data().

merge_group_data( $value, $data )

El Aggregator implementa merge_group_data(). Se encarga de mergar la información de resumen. La subclase realiza lo mismo en merge_agggregator_data().

end_group_data($data)

El Aggregator implementa end_group_data(). Se encarga de calcular la información de resumen. La subclase realiza lo mismo en end_agggregator_data().

add_entry_value( $entry, $data )

Este método asegura que los registros de agrupador anidados sean envueltos en un elemento Lire::Report::Group.

No hay razón para sobrescribir este método, ya que los registros de agrupador se añaden en el método create_group_entries().

MÉTODOS QUE DEBEN SER IMPLEMENTADOS POR SUBCLASES PARA MERGADO

init_agggregator_data()

Este es equivalente a init_group_data() y se llama desde la implementación de init_group_data() del Aggregator.

merge_agggregator_data( $value, $data )

Este método es equivalente a merge_group_data() y se llama desde la implementación de merge_group_data() del Aggregator.

end_agggregator_data( $data )

Este método es equivalente a end_group_data() y se llama desde la implementación de end_group_data() del Aggregator.

NAME

Lire::Aggregator - An abstract class for data aggregators.

SYNOPSIS

  package Lire::MyAggregator;
  use base qw(Lire::Aggregator);
  # ... implement methods ...

DESCRIPTION

This class is an abstract base class for all aggregators in the Lire report generator.

Aggregators are used to group log entries by some criteria. For example, a Rangegroup aggregator groups entries that fall within a specified range. A Timegroup aggregator groups entries by time slots.

The main purpose of an aggregator is to process log entries and group them into Lire::Report::Group objects. These groups are then processed by operators to generate the final report.

This class defines the interface that all aggregator subclasses must implement. It also provides some common functionality used by aggregators.

METHODS

This section describes the methods that are part of the public interface of an aggregator.

METHODS FOR SUBCLASSES

The following methods must be implemented by any subclass of Lire::Aggregator.

init_group_data()
This method is called once for each group created by the aggregator. It should return a data structure that will be associated with the group. This data structure can be used to store any information needed by the aggregator to process the entries belonging to that group.
process_entry( $entry, $group_data )
This method is called for each log entry that falls within the scope of the aggregator. The aggregator should determine which group the entry belongs to and update the corresponding group's data structure (passed as $group_data).
create_group_entries( $group, $data )
In this method, the aggregator should add one Lire::Report::Entry object for every group merged by the aggregator.
$group is an instance of Lire::Report::Group to which the entries should be added. $data is the data structure returned by init_group_data() for the group in which the aggregator is nested (or the only structure that was created when the aggregator is the top-level aggregator).
In this method, the aggregator must make sure to call add_entry_value() on its contained operators for each entry created.

MERGING AGGRATOR API

This section describes the methods related to merging aggregators, which is used when an aggregator is nested within another aggregator.

IMPLEMENTATION OF Lire::ReportOperator MERGING METHODS

When an aggregator is nested within another aggregator, it needs to provide methods that allow the parent aggregator to merge its results. This is done by implementing the following methods, which are part of the Lire::ReportOperator interface.

init_merge( $period_start, $period_end )
This method is called by the parent aggregator to initialize the merging process. It should prepare the aggregator to receive merged data from its children. $period_start and $period_end define the time period for which the merging is performed.
merge_group( $group, $data )
This method is called by the parent aggregator for each group created by the child aggregator. The aggregator should incorporate the information from the child group into its own structure.
$group is the Lire::Report::Group object from the child aggregator. $data is the data structure associated with that group (as returned by init_group_data()).
create_group_entries( $group, $data )
This method is called by the parent aggregator after all child groups have been merged. It should create the final Lire::Report::Entry objects for the merged group. This method is the same as the one described in the "METHODS FOR SUBCLASSES" section, but it is called in the context of merging.
