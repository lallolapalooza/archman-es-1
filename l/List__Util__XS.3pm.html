NOMBRE

List::Util::XS - Indica si List::Util fue compilado con un compilador C

SINOPSIS

use List::Util::XS 1.20;

DESCRIPCIÓN

"List::Util::XS" puede usarse como dependencia para asegurar que List::Util se instaló usando un compilador C y que está instalada la versión XS.

Durante la instalación, $List::Util::XS::VERSION se establecerá a "undef" si la versión XS no fue compilada.

A partir de la versión 1.23_03, Scalar-List-Util utiliza **siempre** la implementación XS, pero por compatibilidad con versiones anteriores, todavía incluimos el módulo "List::Util::XS" que simplemente carga "List::Util".

VER TAMBIÉN

Scalar::Util, List::Util, List::MoreUtils
