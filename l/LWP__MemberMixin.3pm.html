NOMBRE

LWP::MemberMixin - Clase de mezcla de acceso a miembros

SINOPSIS

package Foo;
use parent qw(LWP::MemberMixin);

DESCRIPCIÓN

Una clase de mezcla para obtener métodos que proporcionan un fácil acceso a las variables miembro en el %$self. Idealmente, debería haber un mejor soporte para este lenguaje en Perl.

MÉTODOS

Solo se proporciona un método:

_elem

_elem($elem [, $val])

Método interno para obtener/establecer el valor de la variable miembro $elem. Si $val está presente, se utiliza como el nuevo valor para la variable miembro. Si no está presente, el valor actual no se modifica. En ambos casos, se devuelve el valor anterior de la variable miembro.
