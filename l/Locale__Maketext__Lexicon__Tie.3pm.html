Locale::Maketext::Lexicon::Tie(3) Documentación aportada por el usuario de Perl Locale::Maketext::Lexicon::Tie(3)

NOMBRE

Locale::Maketext::Lexicon::Tie - Usar hashes "tied" como léxicos para Maketext

VERSIÓN

versión 1.00

SINOPSIS

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    en => [ Tie => [ DB_File => 'en.db' ] ],
};

DESCRIPCIÓN

Este módulo te permite hacer fácilmente "tie" (enlazar) el hash %Lexicon a una base de datos u otras fuentes de datos. Toma una referencia de array de argumentos y los pasa directamente a tie().

Las entradas se obtendrán cuando se utilicen; este módulo no las almacena en caché.

VER TAMBIÉN

Locale::Maketext, Locale::Maketext::Lexicon
