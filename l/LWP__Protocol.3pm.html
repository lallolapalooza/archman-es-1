LWP::Protocol(3) Documentación de Perl contribuida por el usuario LWP::Protocol(3)

NOMBRE

LWP::Protocol - Clase base para protocolos LWP

SINOPSIS

package LWP::Protocol::foo;
use parent qw(LWP::Protocol);

DESCRIPCIÓN

Esta clase se utiliza como clase base para todas las implementaciones de protocolos compatibles con la biblioteca LWP.

Al crear una instancia de esta clase usando LWP::Protocol::create($url), obtendrás una subclase inicializada apropiada para ese método de acceso. En otras palabras, la función "create" de LWP::Protocol llama al constructor de una de sus subclases.

Todas las clases derivadas de "LWP::Protocol" deben sobrescribir el método request() que se utiliza para atender una solicitud. El método sobrescrito puede utilizar el método collect() para recopilar fragmentos de datos a medida que se reciben.

MÉTODOS

Se proporcionan los siguientes métodos y funciones:

new

my $prot = LWP::Protocol->new();

El constructor LWP::Protocol es heredado por las subclases. Como esta es una clase base virtual, este método no debe llamarse directamente.

create

my $prot = LWP::Protocol::create($scheme)

Crea un objeto de la clase que implementa el protocolo para manejar el esquema dado. Esta es una función, no un método. Es más una fábrica de objetos que un constructor. Esta es la función que los agentes de usuario deben utilizar para acceder a los protocolos.

implementor

my $class = LWP::Protocol::implementor($scheme, [$class])

Obtiene y/o establece la clase implementadora para un esquema. Devuelve '' si el esquema especificado no es compatible.

request

$response = $protocol->request($request, $proxy, undef);
$response = $protocol->request($request, $proxy, '/tmp/sss');
$response = $protocol->request($request, $proxy, \&callback, 1024);
$response = $protocol->request($request, $proxy, $fh);

Despacha una solicitud a través del protocolo y devuelve un objeto de respuesta. Este método debe ser sobrescrito en las subclases. Consulte LWP::UserAgent para obtener una descripción de los argumentos.

collect

my $res = $prot->collect(undef, $response, $collector); # almacenado en $response
my $res = $prot->collect($filename, $response, $collector);
my $res = $prot->collect(sub { ... }, $response, $collector);

Recopila el contenido de una solicitud y lo procesa adecuadamente en un escalar, archivo o llamando a una devolución de llamada. Si el primer parámetro no está definido, el contenido se almacena dentro de $response. Si es un escalar simple, se interpreta como un nombre de archivo y el contenido se escribe en este archivo. Si es una referencia de código, el contenido se pasa a esta rutina. Si es un manejador de archivos, o similar, como un objeto File::Temp, se escribirá el contenido en él.

El colector es una rutina que será llamada y que es responsable de devolver fragmentos (como referencia a un escalar) del contenido a procesar. El $collector señala "EOF" devolviendo una referencia a una cadena vacía.

El valor de retorno es la referencia al objeto HTTP::Response.

Nota: Solo utilizaremos el argumento de devolución de llamada o archivo si "$response->is_success()". Esto evita enviar datos de contenido para redirecciones y respuestas de autenticación a la devolución de llamada, lo que sería confuso.

collect_once

$prot->collect_once($arg, $response, $content)

Puede ser llamado cuando todo el contenido de la respuesta está disponible como contenido. Esto invocará "collect" en LWP::Protocol con una devolución de llamada colectora que devuelve una referencia a $content la primera vez y una cadena vacía la siguiente.

VER TAMBIÉN

Inspeccione los archivos LWP/Protocol/file.pm y LWP/Protocol/http.pm para ver ejemplos de uso.
