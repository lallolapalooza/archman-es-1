Módulo Longident
: sig fin

Identificadores largos, utilizados en el árbol de análisis sintáctico.

Advertencia: este módulo no es estable y forma parte de Compiler_libs .

Para imprimir un longident, consulta Pprintast.longident , usando Format.asprintf para convertir a una cadena.

type t =
| Lident de string
| Ldot de t Location.loc * string Location.loc
| Lapply de t Location.loc * t Location.loc

val same : t -> t -> bool

same t t' compara los longident t y t' sin tener en cuenta las ubicaciones.

val flatten : t -> string list

val unflatten : string list -> t option

Para una lista no vacía l , unflatten l es Some lid donde lid es el identificador largo creado al concatenar los elementos de l con Ldot . unflatten [] es None .

val last : t -> string

val parse : string -> t

En desuso. esta función puede analizar incorrectamente su entrada, utiliza "Parse.longident" o "Longident.unflatten"

Esta función es defectuosa en identificadores que no son solo "Word.Word.word"; por ejemplo, devuelve resultados incorrectos en operadores infijos y rutas de módulo extendidas.

Si deseas generar longident que sean una lista de identificadores separados por puntos, la función Longident.unflatten es más segura y rápida. Longident.unflatten está disponible desde OCaml 4.06.0.

Si deseas analizar cualquier identificador correctamente, utiliza las funciones de longident del módulo Parse, en particular Parse.longident . Están disponibles desde OCaml 4.11, y también proporcionan soporte adecuado para la ubicación de entrada.
