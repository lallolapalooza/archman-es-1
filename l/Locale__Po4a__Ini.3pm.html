NOMBRE

Locale::Po4a::Ini - convierte archivos INI de/a archivos PO

DESCRIPCIÓN

Locale::Po4a::Ini es un módulo para ayudar a la traducción de archivos INI a otros idiomas [humanos].

El módulo busca líneas del siguiente formato y extrae el texto entre comillas:

identificador="texto que puede ser traducido"

NOTA: Si el texto no está entre comillas, será ignorado.

VER TAMBIÉN

Locale::Po4a::TransTractor(3pm), po4a(7)
