LWP::Debug(3) Documentación de Perl aportada por el usuario LWP::Debug(3)

NOMBRE

LWP::Debug - obsoleto

DESCRIPCIÓN

Este módulo ha quedado obsoleto. Por favor, consulte LWP::ConsoleLogger para sus necesidades de depuración.

LWP::Debug se utiliza para proporcionar funciones de rastreo, pero estas ya no son utilizadas por LWP. El código de este módulo se mantiene (sin documentar) para que el código de terceros que utilice las interfaces antiguas continúe funcionando.

Una característica útil que proporcionaba LWP::Debug (de forma imprecisa y problemática) era la monitorización del tráfico de red. La siguiente sección proporciona algunas pistas sobre los reemplazos recomendados.

Monitorización del tráfico de red

La mejor manera de monitorizar el tráfico de red que genera LWP es utilizar un programa externo de monitorización de TCP. Se recomienda encarecidamente el programa WireShark http://www.wireshark.org/ para ello.

Otro enfoque es utilizar un servidor proxy HTTP de depuración y hacer que LWP dirija todo su tráfico a través de él. Llame a "$ua->proxy" para configurarlo y luego simplemente use LWP como antes.

Para necesidades de monitorización menos precisas, basta con configurar algunos manejadores sencillos. El siguiente ejemplo configura manejadores para volcar los objetos de solicitud y respuesta que pasan por LWP:

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$ua->default_header('Accept-Encoding' => scalar HTTP::Message::decodable());
$ua->add_handler("request_send",  sub { shift->dump; return });
$ua->add_handler("response_done", sub { shift->dump; return });
$ua->get("http://www.example.com");

VER TAMBIÉN

LWP::ConsoleLogger, LWP::ConsoleLogger::Everywhere, LWP::UserAgent
