Locale::PO(3) Documentación de Perl contribuida por el usuario Locale::PO(3)

NOMBRE

Locale::PO - Módulo Perl para manipular entradas .po de GNU gettext

SINOPSIS

use Locale::PO;
$po = new Locale::PO([-option=>valor,...])
[$cadena =] $po->msgid([nueva cadena]);
[$cadena =] $po->msgstr([nueva cadena]);
[$cadena =] $po->comment([nueva cadena]);
[$cadena =] $po->automatic([nueva cadena]);
[$cadena =] $po->reference([nueva cadena]);
[$valor =] $po->fuzzy([valor]);
[$valor =] $po->add_flag('c-format');
print $po->dump;
$cadena_citada = $po->quote($cadena);
$cadena = $po->dequote($cadena_citada);
$aref = Locale::PO->load_file_asarray(<nombre_archivo>,[codificación]);
$href = Locale::PO->load_file_ashash(<nombre_archivo>,[codificación]);
Locale::PO->save_file_fromarray(<nombre_archivo>,$aref,[codificación]);
Locale::PO->save_file_fromhash(<nombre_archivo>,$href,[codificación]);

DESCRIPCIÓN

Este módulo simplifica la gestión de archivos .po de GNU gettext y es una alternativa a usar el modo po de emacs. Proporciona una interfaz orientada a objetos en la que cada entrada de un archivo .po es un objeto Locale::PO.

MÉTODOS

new
my Locale::PO $po = new Locale::PO;
my Locale::PO $po = new Locale::PO(%options);

Crea un nuevo objeto Locale::PO para representar una entrada po. Opcionalmente, puede establecer los atributos de la entrada pasando una lista/hash de la forma:

-opción=>valor, -opción=>valor, etc.

Donde las opciones son msgid, msgid_plural, msgstr, msgctxt, comment, automatic, reference, fuzzy_msgctxt, fuzzy_msgid, fuzzy_msgid_plural, fuzzy y c-format. Consulte los métodos accesores a continuación.

Para generar una cabecera de archivo po, agregue una entrada con un msgid vacío, de la siguiente manera:

$po = new Locale::PO(-msgid=>'', -msgstr=>
        "Project-Id-Version: PACKAGE VERSION\n" .
        "PO-Revision-Date: YEAR-MO-DA HO:MI +ZONE\n" .
        "Last-Translator: FULL NAME <EMAIL@ADDRESS>\n" .
        "Language-Team: LANGUAGE <LL@li.org>\n" .
        "MIME-Version: 1.0\n" .
        "Content-Type: text/plain; charset=CHARSET\n" .
        "Content-Transfer-Encoding: ENCODING\n");
msgid
Establece u obtiene la cadena sin traducir del objeto.

Este método espera la nueva cadena en forma no citada pero devuelve la cadena actual en forma citada.

msgid_plural
Establece u obtiene la cadena plural sin traducir del objeto.

Este método espera la nueva cadena en forma no citada pero devuelve la cadena actual en forma citada.

msgstr
Establece u obtiene la cadena traducida del objeto.

Este método espera la nueva cadena en forma no citada pero devuelve la cadena actual en forma citada.

msgstr_n
Obtiene o establece las traducciones si hay plurales involucrados. Toma y devuelve un hashref donde las claves son el caso 'N' y los valores son las cadenas. por ejemplo: 
$po->msgstr_n(
    {
        0 => 'found %d plural translations',
        1 => 'found %d singular translation',
    }
);

Este método espera las nuevas cadenas en forma no citada pero devuelve las cadenas actuales en forma citada.

msgctxt
Establece u obtiene la cadena de contexto de traducción del objeto.

Este método espera la nueva cadena en forma no citada pero devuelve la cadena actual en forma citada.

fuzzy_msgid
Establece u obtiene la cadena sin traducir obsoleta del objeto.

Este método espera la nueva cadena en forma no citada pero devuelve la cadena actual en forma citada.

fuzzy_msgid_plural
Establece u obtiene la cadena plural sin traducir obsoleta del objeto.

Este método espera la nueva cadena en forma no citada pero devuelve la cadena actual en forma citada.

fuzzy_msgctxt
Establece u obtiene la cadena de contexto de traducción obsoleta del objeto.

Este método espera la nueva cadena en forma no citada pero devuelve la cadena actual en forma citada.

obsolete
Devuelve 1 si la entrada está obsoleta. Las entradas obsoletas tienen sus líneas msgid, msgid_plural, msgstr, msgstr_n y msgctxt comentadas con "#~"

Al usar load_file_ashash, las entradas no obsoletas siempre reemplazarán a las obsoletas con el mismo msgid.

comment
Establece u obtiene los comentarios del traductor del objeto.

Si no hay tales comentarios, el valor es undef. De lo contrario, el valor es una cadena que contiene las líneas de comentarios delimitadas con "\n". La cadena no incluye ni el "# " al principio de cada línea de comentario ni el salto de línea al final de la última línea de comentario.

automatic
Establece u obtiene los comentarios automáticos del objeto (insertados por el modo po de emacs o xgettext).

Si no hay tales comentarios, el valor es undef. De lo contrario, el valor es una cadena que contiene las líneas de comentarios delimitadas con "\n". La cadena no incluye ni el "#. " al principio de cada línea de comentario ni el salto de línea al final de la última línea de comentario.

reference
Establece u obtiene los comentarios de marcado de referencia del objeto (insertados por el modo po de emacs o gettext).
fuzzy
Establece u obtiene la marca fuzzy en el objeto ("verificar esta traducción"). Al establecer, use 1 para activar fuzzy, y 0 para desactivarlo.
c_format
Establece u obtiene la marca c-format o no-c-format en el objeto.

Esto puede tomar 3 valores: 1 implica c-format, 0 implica no-c-format, y indefinido implica ninguno.

php_format
Establece u obtiene la marca php-format o no-php-format en el objeto.

Esto puede tomar 3 valores: 1 implica php-format, 0 implica no-php-format, y indefinido implica ninguno.

has_flag
if ($po->has_flag('perl-format')) {
        ...
}

Devuelve verdadero si la marca existe en el comentario #~ de la entrada

add_flag
$po->add_flag('perl-format');

Agrega la marca al comentario #~

remove_flag
$po->remove_flag('perl-format');

Elimina la marca del comentario #~

loaded_line_number
Al usar uno de los métodos load_file_as*, esto devolverá el número de línea en el que comenzó la entrada en el archivo.
dump
Devuelve la entrada como una cadena, adecuada para su salida a un archivo po.
quote
Aplica las reglas de citación de po a una cadena y devuelve la cadena citada. La cadena citada tendrá todos los caracteres de comillas dobles existentes escapados con barras invertidas, y estará encerrada entre comillas dobles.
dequote
Devuelve una cadena po citada a su forma natural.
load_file_asarray
Dado el nombre de archivo de un archivo po, lee el archivo y devuelve una referencia a una lista de objetos Locale::PO correspondientes al contenido del archivo, en el mismo orden. Acepta un parámetro de codificación opcional (por ejemplo, "utf8") que define cómo se configurará el flujo de entrada del archivo po.
load_file_ashash
Dado el nombre de archivo de un archivo po, lee el archivo y devuelve una referencia a un hash de objetos Locale::PO correspondientes al contenido del archivo. La clave del hash es el msgid (o msgctxt y msgid para entradas contextualizadas). Si hay varias entradas con el mismo msgid, solo se conservará la última. Acepta un parámetro de codificación opcional (por ejemplo, "utf8") que define cómo se configurará el flujo de entrada del archivo po.
save_file_fromarray
Toma el nombre de archivo de un archivo po y una referencia a una lista de objetos Locale::PO, y escribe los objetos en el archivo. Acepta un parámetro de codificación opcional (por ejemplo, "utf8") que define cómo se configurará el flujo de salida del archivo po.
save_file_fromhash
Toma el nombre de archivo de un archivo po y una referencia a un hash de objetos Locale::PO, y escribe los objetos en el archivo. Acepta un parámetro de codificación opcional (por ejemplo, "utf8") que define cómo se configurará el flujo de salida del archivo po.

VER TAMBIÉN

gettext(1), Locale::Gettext(3)

AUTOR

Ashley Sheridan <ash@variety.com>

NOMBRE

Locale::PO

SYNOPSIS

Uso del módulo Locale::PO para manejar archivos de traducción en formato PO.

DESCRIPCIÓN

El módulo Locale::PO gestiona archivos de traducción en formato PO. Las claves de hash son las cadenas no traducidas, lo que permite eliminar duplicados de forma económica. El método prioriza mantener entradas traducidas. Se acepta un parámetro opcional 'encoding' (por ejemplo, "utf8") que define cómo se configurará el flujo de entrada del archivo PO.

MÉTODOS

Los métodos incluyen:

  • save_file_fromarray
  • save_file_fromhash

El método save_file_fromarray guarda objetos de Locale::PO en un archivo PO, creando uno si no existe. Se acepta un parámetro opcional 'encoding' (por ejemplo, "utf8") que define cómo se configurará el flujo de salida del archivo PO.

El método save_file_fromhash guarda objetos de Locale::PO en un archivo PO, creando uno si no existe. Las entradas están ordenadas alfabéticamente por cadena no traducida. Se acepta un parámetro opcional 'encoding' (por ejemplo, "utf8") que define cómo se configurará el flujo de salida del archivo PO.

BUGS

Si se carga un archivo con load_file_as* y se guarda con save_file_from*, el archivo de salida puede tener diferencias cosméticas (una línea en blanco extra).

msgid, msgid_plural, msgstr, msgstr_n y msgctxt esperan un string no entrecomillado como entrada, pero devuelven strings entrecomillados. Me siento indeciso sobre cambiar esto por miedo a romper módulos/scripts de usuarios que ya usen Locale::PO.

Locale::PO requiere líneas en blanco entre entradas, pero los archivos PO de estilo Uniforum no las tienen.

Por favor, envíe todos los reportes de bugs a través del sistema de tickets de CPAN.
