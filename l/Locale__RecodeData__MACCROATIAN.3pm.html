NOMBRE

Locale::RecodeData::MACCROATIAN - Rutinas de conversión para MACCROATIAN

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo use directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas y rutinas de conversión para MACCROATIAN.
