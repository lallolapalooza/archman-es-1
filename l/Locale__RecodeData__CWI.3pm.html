NAME

Locale::RecodeData::CWI — CWI (character width information) data for Locale::Recode

SYNOPSIS

 use Locale::RecodeData::CWI;
 my $cwi = Locale::RecodeData::CWI->new;
 print $cwi->cwi_char_width(0x20);

DESCRIPTION

This module provides the character width information for the Locale::Recode module. It is used internally by Locale::Recode to determine if a character is single-byte or double-byte.

The CWI data is stored in a compact binary format and is accessed through a simple interface.

COMMENTS

This module is part of the Locale::Recode distribution and is not intended for direct use by end-users. It is recommended to use Locale::Recode instead.
