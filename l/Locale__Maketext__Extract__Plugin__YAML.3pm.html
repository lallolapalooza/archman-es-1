Locale::Maketext::Extract::Plugin::YAML(3) Documentación aportada por el usuario de Perl Locale::Maketext::Extract::Plugin::YAML(3)

NOMBRE

Locale::Maketext::Extract::Plugin::YAML - Analizador de formato YAML

VERSIÓN

versión 1.00

SINOPSIS

$plugin = Locale::Maketext::Extract::Plugin::YAML->new(
    $lexicon            # Un objeto Locale::Maketext::Extract
    @file_types         # Opcionalmente, especificar una lista de tipos de archivo reconocidos
)
$plugin->extract($filename,$filecontents);

DESCRIPCIÓN

Extrae cadenas para localizar desde archivos YAML.

NOMBRE CORTO DEL PLUGIN

yaml

FORMATOS VÁLIDOS

Los formatos válidos son:

  • key: _"string"

  • key: _'string'

  • key: _'string con 'comillas' incrustadas'

  • key: |-
     _'mi cadena plegada
     para traducir'

    Nota: El lado izquierdo de la cadena plegada debe alinearse con el "_", de lo contrario YAML añadirá espacios al principio de cada línea.

  •     key: |-
         _'mi bloque
         de cadena
         para traducir
         '
Nota: Debes usar el C<-> final para que YAMl no añada un retorno de carro
después de tu última comilla.

TIPOS DE ARCHIVO CONOCIDOS

.yaml
.yml
.conf

REQUIERE

YAML

NOTAS

La documentación del módulo YAML la describe como código alfa. No es tan tolerante a errores como YAML::Syck. Sin embargo, como es Perl puro, es fácil de integrar.

He visto que entra en bucles infinitos, así que si xgettext.pl se bloquea, intenta ejecutarlo de nuevo con "--verbose --verbose" (dos veces) habilitado, para que puedas ver si la falla reside en YAML. Si es así, corrige el archivo fuente de YAML o usa file_types para excluir ese archivo.

VER TAMBIÉN

xgettext.pl
para extraer cadenas traducibles de sistemas de plantillas comunes y archivos fuente de perl.
