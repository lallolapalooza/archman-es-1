DESCRIPCIÓN

These macros provide a generic implementation of singly linked lists (SLIST_ macros) and singly linked lists with a tail pointer (STAILQ_ macros). These data structures are typically used for implementing various queues and stacks. The SLIST_ macros implement a singly linked list, while the STAILQ_ macros implement a singly linked list with a tail pointer. This tail pointer allows for constant time insertion at the end of the list.

The macros operate on list entries defined using SLIST_ENTRY and STAILQ_ENTRY, respectively. These macros should be used within a structure that contains the entry as a member. For example:

struct my_item {
    int data;
    SLIST_ENTRY(my_item) next;
};

List heads are defined using SLIST_HEAD and STAILQ_HEAD.

SLIST_HEAD(my_list_head, my_item);
struct my_list_head my_list;

Here, my_list_head is the name of the list head structure, and my_item is the type of items in the list.

The _CLASS_ENTRY and _CLASS_HEAD macros are used for creating list entry and head definitions that are specific to a particular class or data type, ensuring type safety.

SLIST_INIT and STAILQ_INIT initialize an empty list. SLIST_EMPTY and STAILQ_EMPTY check if a list is empty.

SLIST_INSERT_HEAD, SLIST_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_INSERT_AFTER, and STAILQ_INSERT_BEFORE are used for inserting elements into the lists.

SLIST_REMOVE, SLIST_REMOVE_HEAD, SLIST_REMOVE_AFTER, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, and STAILQ_REMOVE_AFTER are used for removing elements.

SLIST_FIRST and STAILQ_FIRST return a pointer to the first element in the list. SLIST_NEXT and STAILQ_NEXT return a pointer to the next element. STAILQ_LAST returns a pointer to the last element in a stailq.

SLIST_FOREACH, SLIST_FOREACH_SAFE, SLIST_FOREACH_FROM, SLIST_FOREACH_FROM_SAFE, STAILQ_FOREACH, STAILQ_FOREACH_SAFE, STAILQ_FOREACH_FROM, and STAILQ_FOREACH_FROM_SAFE are macros for iterating over the elements of a list. The _SAFE variants are designed to be used when removing elements during iteration.

SLIST_SWAP and STAILQ_SWAP exchange the contents of two lists.

SLIST_CONCAT appends the contents of one singly linked list to another.

STAILQ_CONCAT appends the contents of one singly linked list with a tail pointer to another.

DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden usarse en ambos C y C++:

  1. Lista
  2. Lista doblemente enlazada
  3. Lista doblemente enlazada como cola
  4. Cola
Todas las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de un nuevo elemento al inicio de la lista.
  2. Inserción de un nuevo elemento después de cualquier elemento en la lista.
  3. Eliminación de un elemento en el inicio de la lista en tiempo constante (O(1)).
  4. Traversión forward de la lista.
  5. Cambiar el contenido de dos listas.
Las listas doblemente enlazadas son las más sencillas de las cuatro estructuras y soportan solo la funcionalidad descrita anteriormente. Las listas doblemente enlazadas son ideales para aplicaciones con grandes datasets y pocos o ningún eliminados, o para implementar una cola LIFO. Las listas doblemente enlazadas añaden la siguiente funcionalidad:
  1. Eliminación de cualquier elemento en la lista en tiempo lineal (O(n)).
  2. Concatenación de dos listas en tiempo lineal (O(n)).
Las listas doblemente enlazadas como cola añaden la siguiente funcionalidad:
  1. Elementos pueden añadirse al final de una lista.
  2. Eliminación de cualquier elemento en la lista en tiempo lineal (O(n)).
  3. Pueden concatenarse.
Pero:
  1. Todo el insertar en una lista debe especificar el encabezado de la lista.
  2. Cada entrada de encabezado requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente el 15% mayor y las operaciones corren aproximadamente 20% más lentas que en listas doblemente enlazadas.
Las listas doblemente enlazadas como cola son ideales para aplicaciones con grandes datasets y pocos o ningún eliminados, o para implementar una cola FIFO. Todas las estructuras de datos doblemente enlazadas (listas y colas) además permiten:
  1. Inserción de un nuevo elemento antes de cualquier elemento en la lista.
  2. Eliminación de cualquier elemento en la lista en tiempo constante (O(1)).
Pero:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto la eliminación) es aproximadamente el doble que en las estructuras de datos doblemente enlazadas simples.
Las listas son las más simples de las estructuras de datos doblemente enlazadas. Añaden la siguiente funcionalidad sobre las anteriores:
  1. Concatenación de dos listas en tiempo lineal (O(n)).
  2. Pueden ser recorridas en sentido inverso.
Pero:
  1. Para recorrer en sentido inverso, debe especificarse un elemento que comience la travesía y la lista en la cual se encuentra dicho elemento.
Las colas añaden la siguiente funcionalidad:
  1. Elementos pueden añadirse al final de una lista.
  2. Poden ser recorridas en sentido inverso, desde el final hacia el principio.
  3. Poden concatenarse.
Pero:
  1. Todo el insertar y eliminar en una lista debe especificar el encabezado de la lista.
  2. Cada entrada de encabezado requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente el 15% mayor y las operaciones corren aproximadamente 20% más lentas que en listas doblemente enlazadas.
En las definiciones de macro, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macro, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe ser declarada usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Véase los ejemplos siguientes para una explicación más detallada de cómo se utilizan estas macros.

LISTAS DOBLEMENTE ENLACEADAS

Una lista doblemente enlazada está encabezada por una estructura definida mediante la macro SLIST_HEAD. Esta estructura contiene un único puntero hacia el primer elemento de la lista. Los elementos son doblemente enlazados para minimizar el espacio y el overhead de manipulación de punteros, pero con el costo de O(n) para la eliminación de elementos arbitrarios. Los nuevos elementos pueden agregarse a la lista después de un elemento existente o al inicio de la lista. Una estructura SLIST_HEAD se declara así:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos a enlazar en la lista. Se puede declarar posteriormente un puntero a la cabeza de la lista como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatená la lista encabezada por head2 al final de la lista encabezada por head1, eliminando todos los elementos de la anterior. Se debe evitar el uso de esta macro ya que recorre completamente la lista head1. Debe usarse una lista doblemente enlazada como cola si se necesita esta macro en caminos de uso alto o para operar sobre listas largas.

La macro SLIST_EMPTY evalúa a true si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referida por head en la dirección forward, asignando cada elemento en su orden a var.

La macro SLIST_FOREACH_FROM funciona de manera similar a SLIST_FOREACH cuando var es NULL, en cuyo caso trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head.

La macro SLIST_FOREACH_SAFE recorre la lista referida por head en la dirección forward, asignando cada elemento en su orden a var. Sin embargo, a diferencia de SLIST_FOREACH() aquí es permitido tanto remover var como liberarlo de dentro del bucle de manera segura sin interferir con la travesía.

La macro SLIST_FOREACH_FROM_SAFE funciona de manera similar a SLIST_FOREACH_SAFE cuando var es NULL, en cuyo caso trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head.

La macro SLIST_INIT inicializa la lista referida por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al inicio de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm en la lista.

La macro SLIST_INIT inicializa la lista referida por head.

LISTAS SIMPLEMENTE ENLAZADAS

Una lista simplemente enlazada está encabezada por una estructura definida por la macro SLIST_HEAD. Los elementos son enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta idénticamente a SLIST_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento SLIST previamente encontrado y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la lista referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí está permitido tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta idénticamente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento SLIST previamente encontrado y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_INIT inicializa la lista simplemente enlazada referenciada por head.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro SLIST_NEXT devuelve el siguiente elemento en la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm de la cabeza de la lista. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe usar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

	...

SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación desde la cabeza. */
free(n3);

COLAS DE EXTREMO SIMPLEMENTE ENLAZADAS

Una cola de extremo simplemente enlazada está encabezada por una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de extremo y el otro al último elemento de la cola de extremo. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden agregar nuevos elementos a la cola de extremo después de un elemento existente, al principio de la cola de extremo, o al final de la cola de extremo. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la cola de extremo. Un puntero a la cabeza de la cola de extremo se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de extremo head.

La macro STAILQ_CONCAT concatena la cola de extremo encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de extremo.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola de extremo.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de extremo o NULL si la cola de extremo está vacía.

La macro STAILQ_FOREACH recorre la cola de extremo referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro STAILQ_FOREACH_FROM se comporta idénticamente a STAILQ_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento STAILQ previamente encontrado y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de extremo referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí está permitido tanto eliminar var como liberarlo desde dentro del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta idénticamente a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento STAILQ previamente encontrado y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola de extremo referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de extremo.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de extremo.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de extremo. Si la cola de extremo está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de extremo, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola de extremo. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola de extremo.

La macro STAILQ_REMOVE_HEAD elimina el elemento al principio de la cola de extremo. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la cola de extremo deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de extremo. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe usar una cola de extremo doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas de extremo largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLA DE EXTREMO SIMPLEMENTE ENLAZADA

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Cabeza de cola de extremo simplemente enlazada. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola de extremo. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar al principio. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación desde la cabeza. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido hacia adelante seguro. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Eliminación de TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación de TailQ más rápida. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista está encabezada por una estructura definida por la macro LIST_HEAD. Esta estructura contiene un solo puntero al primer elemento de la lista. Los elementos están enlazados doblemente para que un elemento arbitrario pueda ser eliminado sin recorrer la lista. Se pueden agregar nuevos elementos a la lista después de un elemento existente, antes de un elemento existente, o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1 eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe usar una cola de extremo si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por head

/var> en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro LIST_FOREACH_FROM se comporta idénticamente a LIST_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

La macro LIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de LIST_FOREACH(), aquí está permitido tanto remover var como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro LIST_FOREACH_FROM_SAFE se comporta idénticamente a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

La macro LIST_INIT inicializa la lista referenciada por head.

La macro LIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

La macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro LIST_NEXT devuelve el siguiente elemento de la lista, o NULL si es el último.

La macro LIST_PREV devuelve el elemento anterior de la lista, o NULL si es el primero. La lista head debe contener el elemento elm.

La macro LIST_REMOVE elimina el elemento elm de la lista.

La macro LIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE LIST

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Cabecera de la lista. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Lista. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Inicializar la lista. */

n1 = malloc(sizeof(struct entry));	/* Insertar al principio. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insertar antes. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Eliminación. */
free(n2);
					/* Recorrido hacia adelante. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Recorrido seguro hacia adelante. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->hacer_algo();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Eliminación de la lista. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);
}

n1 = LIST_FIRST(&head);			/* Eliminación de lista más rápida. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

COLAS FINALES

Una cola final (tail queue) está encabezada por una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola final y otro al último elemento de la cola final. Los elementos están enlazados doblemente para que un elemento arbitrario pueda ser removido sin recorrer la cola final. Los nuevos elementos pueden ser agregados a la cola final después de un elemento existente, antes de un elemento existente, al principio de la cola final o al final de la cola final. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos que se enlazarán en la cola final. Un puntero a la cabeza de la cola final puede ser declarado más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola final head.

La macro TAILQ_CONCAT concatena la cola final encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro TAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola final.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos en la cola final.

La macro TAILQ_FIRST devuelve el primer elemento de la cola final o NULL si la cola final está vacía.

La macro TAILQ_FOREACH recorre la cola final referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola final referenciada por head en la dirección inversa, asignando cada elemento en su turno a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta idénticamente a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referenciada por head en dirección hacia adelante o inversa respectivamente, asignando cada elemento en su turno a var. Sin embargo, a diferencia de sus contrapartes no seguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten tanto remover var como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

La macro TAILQ_INIT inicializa la cola final referenciada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola final.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola final.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola final. Si la cola final está vacía, el valor de retorno es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola final, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola final, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola final.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

DIAGNÓSTICOS


Al depurar queue(3), puede ser útil rastrear los cambios en la cola. Para habilitar el rastreo, defina la macro QUEUE_MACRO_DEBUG_TRACE en el momento de la compilación.


También puede ser útil "ensuciar" los punteros que se han desvinculado de una cola, para detectar su uso después de la eliminación. Para habilitar la "suciedad" de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH en el momento de la compilación. La macro QMD_IS_TRASHED(void *ptr) devuelve verdadero si ptr ha sido "ensuciado" por la opción QUEUE_MACRO_DEBUG_TRASH.
