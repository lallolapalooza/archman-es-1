DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element or at the head of the list. An SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A singly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element listelm in the list.

The macro SLIST_NEXT returns the next element in the list after elm.

The macro SLIST_REMOVE removes the element elm from the list.

The macro SLIST_REMOVE_HEAD removes the first element from the list.

The macro SLIST_SWAP swaps the contents of the lists headed by head1 and head2.

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains two pointers to the first and last elements on the queue. The elements are doubly linked for efficient insertion and removal at either end of the queue. The cost of this efficiency is the addition of a pointer to each element and roughly twice the code size and execution time for operations (other than removal) over the singly-linked list implementation.

A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro TAILQ_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro TAILQ_EMPTY evaluates to true if there are no elements in the list.

The macro TAILQ_ENTRY declares a structure that connects the elements in the list.

The macro TAILQ_FIRST returns the first element in the list or NULL if the list is empty.

The macro TAILQ_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike TAILQ_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the list referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the list.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the tail of the list.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm in the list.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm in the list.

The macro TAILQ_LAST returns the last element in the list or NULL if the list is empty.

The macro TAILQ_NEXT returns the next element in the list after elm.

The macro TAILQ_PREV returns the previous element in the list before elm.

The macro TAILQ_REMOVE removes the element elm from the list.

The macro TAILQ_REMOVE_HEAD removes the first element from the list.

The macro TAILQ_SWAP swaps the contents of the lists headed by head1 and head2.

EJEMPLO DE LISTA DE ENLACE SIMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Lista de enlace simple cabeza. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Lista de enlace simple. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializar la lista. */

n1 = malloc(sizeof(struct entry));	/* Insertar al frente. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación de la cabeza. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Eliminación de la lista. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

COLAS DE CÓDIGO DE ENLACE SIMPLE

Una cola de enlace simple está encabezada por una estructura definida mediante la macro STAILQ_HEAD. Esta estructura contiene dos punteros: uno al primer elemento en la cola de código y otro al último elemento en la cola de código. Los elementos están enlazados de forma singular para minimizar el overhead de espacio y manipulación de punteros, a pesar de que el tiempo de eliminación puede ser O(n) para elementos arbitrarios. Los nuevos elementos pueden agregarse a la cola de código después de un elemento existente, en la cabeza de la cola de código o al final de la cola de código. Una estructura STAILQ_HEAD se declara así:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se define y TYPE es el tipo de los elementos que se enlazan en la cola de código. Una dirección puntero a la cabeza de la cola de código puede ser declarada más tarde así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de código head.

La macro STAILQ_CONCAT concatena la cola de código encabezada por head2 al final de la cola de código encabezada por head1, eliminando todos los elementos de la anterior.

La macro STAILQ_EMPTY devuelve verdadero si no hay elementos en la cola de código.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola de código.

La macro STAILQ_FIRST devuelve el primer elemento en la cola de código o NULL si la cola de código está vacía.

La macro STAILQ_FOREACH recorre la cola de código encabezada por head en la dirección forward, asignando cada elemento a var.

La macro STAILQ_FOREACH_FROM funciona de manera similar a STAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de código y comienza el ciclo desde var en lugar del primer elemento de la cola de código encabezada por head).

La macro STAILQ_FOREACH_SAFE recorre la cola de código encabezada por head en la dirección forward, asignando cada elemento a var. Sin embargo, diferente de STAILQ_FOREACH() aquí es permitido remover var y liberar su contenido dentro del ciclo sin interferir con la travesada.

La macro STAILQ_FOREACH_FROM_SAFE funciona de manera similar a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la cola de código y comienza el ciclo desde var en lugar del primer elemento de la cola de código encabezada por head).

La macro STAILQ_INIT inicializa la cola de código encabezada por head.

La macro STAILQ_INSERT_HEAD inserta el elemento nuevo elm al frente de la cola de código.

La macro STAILQ_INSERT_TAIL inserta el elemento nuevo elm al final de la cola de código.

La macro STAILQ_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento en la cola de código. Si la cola de código está vacía, el valor devuelto es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento en la cola de código, o NULL si este es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola de código. Diferente de STAILQ_REMOVE, esta macro no recorre toda la cola de código.

La macro STAILQ_REMOVE_HEAD elimina el elemento en la cabeza de la cola de código. Para la eficiencia óptima, los elementos que se eliminan de la cabeza de la cola de código deben usar esta macro explícitamente en lugar de la macro general STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de código. Su uso debe evitarse ya que recorre toda la lista. Una cola de código doblemente enlazada debe usarse si esta macro es necesaria en rutas de código de alta utilización o para operar en listas largas de cola de código.

La macro STAILQ_SWAP intercambia los contenidos de head1 y head2.

EJEMPLO DE COLA DE CÓDIGO DE ENLACE SIMPLE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Cabeza de la cola de código de enlace simple. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola de código. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar al frente. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación de la cabeza. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Eliminación de la cola de código. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación más rápida. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista está encabezada por una estructura definida mediante la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma doble, permitiendo eliminar cualquier elemento sin recorrer la lista completa. Los nuevos elementos pueden agregarse a la lista después de un elemento existente, antes de uno existente o al frente de la lista. Una estructura LIST_HEAD se declara así:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos en la lista. Una dirección puntero a la cabeza de la lista puede ser declarada más tarde así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatenará la lista encabezada por head2 al final de la lista encabezada por head1, eliminando todos los elementos de la anterior. Su uso debe evitarse ya que recorre toda la lista head1. Una cola de código debe usarse si esta macro es necesaria en rutas de código de alta utilización o para operar en listas largas.

La macro LIST_EMPTY devuelve verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento en la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista encabezada por head en la dirección forward, asignando cada elemento a var.

EJEMPLO_DE_LISTA

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Cabecera de lista. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Lista. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Inicializa la lista. */

n1 = malloc(sizeof(struct entry));	/* Inserta al principio. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Inserta después. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Inserta antes. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Eliminación. */
free(n2);
					/* Recorrido hacia adelante. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Recorrido hacia adelante seguro. */
LIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	LIST_REMOVE(np, entries);
	free(np);
}

while (!LIST_EMPTY(&head)) {		/* Eliminación de la lista. */
	n1 = LIST_FIRST(&head);
	LIST_REMOVE(n1, entries);
	free(n1);

n1 = LIST_FIRST(&head);			/* Eliminación de lista más rápida. */
while (n1 != NULL) {
	n2 = LIST_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
LIST_INIT(&head);

COLAS_DE_PUNTA

Una cola de punta está encabezada por una estructura definida mediante la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento en la cola de punta y el otro al último elemento en la cola de punta. Los elementos están enlazados doblemente, lo que permite eliminar cualquier elemento sin recorrer la cola de punta. Los nuevos elementos pueden ser añadidos a la cola de punta después de un elemento existente, antes de un elemento existente, al principio de la cola de punta o al final de la cola de punta. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos enlazados en la cola de punta. Una dirección a la cabecera de la cola de punta puede ser declarada posteriormente de la siguiente manera:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de punta head.

La macro TAILQ_CONCAT concatenará la cola de punta encabezada por head2 al final de la cola de punta encabezada por head1, vaciando la primera.

La macro TAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de punta.

La macro TAILQ_ENTRY declara una estructura que enlaza los elementos de la cola de punta.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de punta o NULL si la cola de punta está vacía.

La macro TAILQ_FOREACH recorre la cola de punta encabezada por head en la dirección hacia adelante, asignando cada elemento a var. var se establece a NULL si el bucle termina normalmente o si no hay elementos.

La macro TAILQ_FOREACH_FROM se comporta de manera idéntica a TAILQ_FOREACH cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punta y comienza el bucle en var en lugar del primer elemento de la cola de punta encabezada por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de punta encabezada por head en la dirección inversa, asignando cada elemento a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta de manera idéntica a TAILQ_FOREACH_REVERSE cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punta y comienza el bucle inverso en var en lugar del último elemento de la cola de punta encabezada por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista encabezada por head en la dirección hacia adelante o inversa respectivamente, asignando cada elemento a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten tanto la eliminación de var como su liberación dentro del bucle de forma segura sin interferir con la trayectoria.

La macro TAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a TAILQ_FOREACH_SAFE cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punta y comienza el bucle en var en lugar del primer elemento de la cola de punta encabezada por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta de manera idéntica a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL; de lo contrario, trata var como un elemento encontrado previamente en la cola de punta y comienza el bucle inverso en var en lugar del último elemento de la cola de punta encabezada por head.

La macro TAILQ_INIT inicializa la cola de punta encabezada por head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola de punta.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de punta.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de punta. Si la cola de punta está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento de la cola de punta, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior de la cola de punta, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de punta.

La macro TAILQ_SWAP intercambia los contenidos de head1 y head2.
