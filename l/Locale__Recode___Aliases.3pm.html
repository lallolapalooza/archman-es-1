NOMBRE

Locale::Recode::_Aliases - Base de datos interna de alias de juegos de caracteres para libintl-perl

SINOPSIS

use Locale::Recode::_Aliases

die "¡Este módulo es interno de libintl. No lo uses directamente!\n";

DESCRIPCIÓN

Contiene una lista de alias de códigos conocidos internamente por libintl.

CONSTANTES

ALIASES
La constante Locale::Recode::_Aliases::ALIASES contiene una referencia a un hash cuyas claves son nombres de alias de juegos de caracteres conocidos internamente, todos en mayúsculas. El valor correspondiente es el nombre canónico del juego de caracteres.
