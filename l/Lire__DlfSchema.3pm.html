NOMBRE

Lire::DlfSchema - Interfaz a las especificaciones XML de esquemas DLF de Lire

SINOPSIS

En los conversores DLF:

use Lire::DlfSchema;
my $schema = Lire::DlfSchema::load_schema( "email" );
my $fields = $schema->fields();
my $dlf_id = $schema->field( 'dlf_id' );
my $dlf_src = $schema->field( 'dlf_source' );

DESCRIPCIÓN

Este módulo es la interfaz a los esquemas DLF de Lire definidos en archivos XML. Un esquema define el orden de los campos junto con sus nombres, descripciones y tipos.

Cada DlfSchema tiene al menos dos campos predefinidos:

dlf_id
Este es un entero que identifica de forma única un registro DLF en su flujo. Se utiliza para vincular el registro a los campos de sus esquemas extendidos y también para vincular el registro a los registros de esquemas derivados.
dlf_source
Este es un identificador que se puede utilizar para rastrear el registro del ImportJob que lo creó.

ACCESO A UN OBJETO DE ESQUEMA

La forma de acceder a un esquema para un superservicio es a través de la función de módulo load_schema(). La usas así:

my $schema = Lire::DlfSchema::load_schema( $superservice);

Esta función devolverá un objeto de esquema que luego se puede utilizar para consultar información sobre el esquema. Esta función morirá() en caso de error.

has_superservice( $superservice )

Devuelve verdadero si hay un superservicio llamado $schema_name disponible. Se generará un error si el nombre del esquema no es válido para un superservicio.

has_schema( $schema_name )

Devuelve verdadero si $schema_name está disponible. Se generará un error si el nombre del esquema no es válido.

superservices()

Devuelve el nombre de los superservicios disponibles en un array.

schemas()

Devuelve el nombre de los esquemas disponibles en un array.

MÉTODOS DEL OBJETO DE ESQUEMA

id()

my $id = $schema->id();

Este método devolverá el id del esquema. Este será el nombre del superservicio para el esquema principal del superservicio. (Hay otros tipos de esquemas (esquemas derivados y extendidos) para los cuales el id será diferente al nombre del superservicio).

superservice()

my $super = $schema->superservice();

Este método devolverá el nombre del superservicio del esquema.

title( [$new_title] )

Este método devolverá (o cambiará) el título legible del esquema. (Este es el contenido del elemento title en la especificación XML).

description( [$new_description] )

Este método devolverá (o cambiará) la descripción del esquema. (Este es el contenido del elemento description en la especificación XML). Ten en cuenta que lo más probable es que contenga marcado DocBook.

field_by_pos()

my $field = $schema->field_by_pos( 0 );

Este método toma un entero como parámetro y devuelve el campo en esa posición en el esquema. Los campos se indexan comenzando desde 0. Este método morirá() si se pasa una posición no válida como parámetro.

El método devuelve un objeto Lire::Field(3pm).

add_field( $field )

Añade el Lire::Field $field a este esquema.

has_field()

if ( $schema->has_field( 'test ) ) { 
    print "el esquema tiene el campo 'test'\n"; 
}

Este método toma una cadena como parámetro y devuelve un valor booleano. Ese valor será verdadero si hay un campo en el esquema con ese nombre, de lo contrario será falso.

field()

my $field = $schema->field( 'from_email' );

Este método toma el nombre de un campo como parámetro y devuelve el objeto Lire::Field(3pm) que describe ese campo en el esquema. El método morirá() si no hay un campo con ese nombre en el esquema.

fields()

my $fields = $schema->fields();
my @fields = $schema->fields();

En contexto de array, este método devolverá un array que contiene todos los campos (como objetos Lire::Field(3pm)) en el esquema. El orden de los campos en el array es el orden de los campos en el esquema.

En contexto escalar, devolverá una referencia a un array. Este método es más eficiente que crear un array. NO MODIFIQUES EL ARRAY DEVUELTO.

field_names()

Devuelve el nombre de los campos en este esquema. Los nombres están en el mismo orden que los campos.

field_count()

my $number_of_field = $schema->field_count;

Este método devuelve el número de campos en el esquema.

timestamp_field()

my $time_field = $schema->timestamp_field;

Este método devolverá el objeto Lire::Field(3pm) que representa el campo de marca de tiempo en el esquema. El campo de marca de tiempo es el que define el orden de clasificación de los registros DLF.

is_schema_compatible()

if ( $schema->is_schema_compatible( $other_schema ) ) {
}

Este método toma un objeto Lire::DlfSchema(3pm) como parámetro y devuelve un valor booleano. Ese valor será verdadero si el esquema pasado como parámetro es compatible con el otro, de lo contrario será falso.

Para el esquema de un superservicio, el único esquema compatible es un objeto que representa el esquema del mismo superservicio.

can_join_schema( $schema )

Devuelve verdadero si $schema se puede unir con este esquema. Para un DlfSchema, esto será verdadero solo cuando $schema sea un ExtendedSchema de este esquema.

Métodos relacionados con SQL

Estos métodos se utilizan para mapear registros DLF a tablas SQL.

sql_table()

Devuelve la tabla SQL utilizada para contener los registros DLF de este esquema.

create_sql_schema( $dlf_store, [ $remove ] )

Esto creará los esquemas SQL necesarios para contener los registros DLF de este esquema en el Lire::DlfStore. Si $remove es verdadero, se realizará un DROP TABLE antes de crear el esquema.

needs_sql_schema_migration( $dlf_store )

Este método devolverá verdadero si el esquema SQL no está actualizado en el DlfStore. El método migrate_sql_schema() se puede utilizar para actualizar el esquema.

migrate_sql_schema( $dlf_store )

Actualiza los esquemas SQL a la versión actual.

NOMBRE

Lire::DlfSchema

SINOPSIS

use Lire::DlfSchema;

DESCRIPCION

Lire::DlfSchema es un módulo que proporciona acceso a registros DLF en el esquema. Permite a los usuarios consultar, insertar y eliminar registros DLF utilizando sentencias SQL.

ACCESO A UN OBJETO DE ESQUEMA

Para acceder a un objeto de esquema, puedes usar los siguientes métodos:

  • El método get_schema() devuelve una referencia al objeto de esquema.
  • El método get_schema_by_name() devuelve una referencia al objeto de esquema por nombre.
  • El método get_schema_by_id() devuelve una referencia al objeto de esquema por ID.

MÉTODOS DEL OBJETO DE ESQUEMA

El objeto de esquema proporciona los siguientes métodos:

  • El método query() devuelve un objeto Lire::DlfQuery que se puede usar para recuperar registros DLF.
  • El método insert_sql_query() devuelve la sentencia SQL INSERT para insertar registros DLF.
  • El método sql_clean_query() devuelve la sentencia SQL DELETE para limpiar registros DLF.
  • El método sql_clean_period_query() devuelve la sentencia SQL DELETE para limpiar registros DLF con límites de tiempo.
  • El método sort_spec() devuelve la especificación de ordenación para consultar registros DLF.
  • El método sort_spec($sort_spec) establece la especificación de ordenación para consultar registros DLF.
  • El método insert_query() devuelve la sentencia SQL INSERT para insertar registros DLF.
  • El método execute_insert_query() ejecuta la sentencia SQL INSERT con un manejador DBI::st.
  • El método clean_query() devuelve la sentencia SQL DELETE para limpiar registros DLF.
  • El método clean_period_query() devuelve la sentencia SQL DELETE para limpiar registros DLF con límites de tiempo.
  • El método clean_period_query($with_time) devuelve la sentencia SQL DELETE para limpiar registros DLF con límites de tiempo.
  • El método clean_period_query($with_time, $time1, $time2) devuelve la sentencia SQL DELETE para limpiar registros DLF con límites de tiempo.

MÉTODOS RELACIONADOS CON SQL

El objeto de esquema proporciona los siguientes métodos relacionados con SQL:

  • El método query() devuelve un objeto Lire::DlfQuery que se puede usar para recuperar registros DLF.
  • El método insert_sql_query() devuelve la sentencia SQL INSERT para insertar registros DLF.
  • El método sql_clean_query() devuelve la sentencia SQL DELETE para limpiar registros DLF.
  • El método sql_clean_period_query() devuelve la sentencia SQL DELETE para limpiar registros DLF con límites de tiempo.
  • El método sort_spec() devuelve la especificación de ordenación para consultar registros DLF.
  • El método sort_spec($sort_spec) establece la especificación de ordenación para consultar registros DLF.
  • El método insert_query() devuelve la sentencia SQL INSERT para insertar registros DLF.
  • El método execute_insert_query() ejecuta la sentencia SQL INSERT con un manejador DBI::st.
  • El método clean_query() devuelve la sentencia SQL DELETE para limpiar registros DLF.
  • El método clean_period_query() devuelve la sentencia SQL DELETE para limpiar registros DLF con límites de tiempo.
  • El método clean_period_query($with_time, $time1, $time2) devuelve la sentencia SQL DELETE para limpiar registros DLF con límites de tiempo.
