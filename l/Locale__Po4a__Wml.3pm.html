NOMBRE

Locale::Po4a::Wml - convierte documentos WML (lenguaje de marcado web) desde/hacia archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y más interesante aún, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::Wml es un módulo para ayudar a la traducción de documentos WML a otros idiomas [humanos]. No mezcle el WML del que estamos hablando aquí (lenguaje de marcado web) y la basura WAP utilizada en los teléfonos móviles.

Tenga en cuenta que este módulo se basa en el módulo Locale::Po4a::Xhtml, que a su vez se basa en el módulo Locale::Po4a::Xml. Esto significa que se asume que todas las etiquetas para expresiones de páginas web están escritas en sintaxis XHTML.

OPCIONES ACEPTADAS POR ESTE MÓDULO

NINGUNA.

ESTADO DE ESTE MÓDULO

Este módulo funciona para algunos documentos sencillos, pero aún es joven. Actualmente, el mayor problema del módulo es probablemente que no puede manejar documentos que contengan etiquetas en línea no XML, como <email "foo@example.org">, que a menudo se definen en WML. Se añadirán mejoras en futuras versiones.
