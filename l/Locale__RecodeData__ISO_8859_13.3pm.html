Este módulo está generado y contiene las tablas y rutinas de conversión para ISO-8859-13.

NAME

                    
Locale::RecodeData::ISO_8859_13 - Recode data for ISO-8859-13

                

                

                    
SYNOPSIS

                    
 use Locale::RecodeData::ISO_8859_13;

                

                

                    
DESCRIPTION

                    
This module provides the recode data for ISO-8859-13.

                    
ISO-8859-13 is the Latin-9 character set, designed for the Baltic Rim languages.

                

                

                    
COMMENTS

                    
 This module is part of the libintl-perl package.
 It is used by the Locale::Recode module to provide character set conversions.
