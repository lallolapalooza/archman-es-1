Locale::RecodeData::MACARABIC(3pm)

NAME

Locale::RecodeData::MACARABIC - recode data for Arabic characters

SYNOPSIS

    use Locale::Recode::all 'MACARABIC';
    use Locale::RecodeData::MACARABIC;

    $recode = Locale::RecodeData::MACARABIC->new();
    $recode->parse ( q{
    SAD
        D6 |  00000636 | ARABIC LETTER DAD
        D7 |  00000637 | ARABIC LETTER TAH
        D8 |  00000638 | ARABIC LETTER ZAH
        D9 |  00000639 | ARABIC LETTER AIN

        EF |  0000064F | ARABIC DAMMA

        F7 |  000006A4 | ARABIC LETTER VEH

        FA |  00000691 | ARABIC LETTER RREH
        FE |  00000698 | ARABIC LETTER JEH
        FF |  000006D2 | ARABIC LETTER YEH BARREE
    } );

DESCRIPTION

This module provides a data structure for mapping character encodings to and from the internal Unicode representation used by the Locale::Recode module.

The data for Arabic characters is encoded in a manner compatible with the recodedata format.
