NOMBRE

Lire::DerivedSchema - Define un esquema para el cual los registros se derivan de otro esquema

SINOPSIS

my $schema = Lire::DlfSchema::load_schema( 'www-user_session' );
my $fields = $schema->fields();

DESCRIPCIÓN

Un Lire::DerivedSchema define un esquema para el cual los registros son computados por un analizador utilizando los registros de un esquema base. Un ejemplo de un esquema derivado es el esquema www-user_session que computa información de sesión a partir de los registros en el esquema www.

base()

Devuelve el objeto Lire::DlfSchema del cual se derivan los registros de este esquema.

puede_unir_esquema( $esquema )

Devuelve verdadero si $esquema puede ser unido con este esquema. Para un DerivedSchema, esto será verdadero solo cuando $esquema es un ExtendedSchema de este esquema o de la base de este esquema. También es posible unir el DerivedSchema con su base.
