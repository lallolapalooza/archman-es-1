NOMBRE

Lingua::EN::Numbers::Ordinate -- pasar de número cardinal (3) a ordinal ("3º")

SINOPSIS

use Lingua::EN::Numbers::Ordinate;
print ordinate(4), "\n";
 # imprime 4th
print ordinate(-342), "\n";
 # imprime -342nd
# Ejemplo de uso real:
...
for(my $i = 0; $i < @records; $i++) {
  unless(is_valid($record[$i]) {
    warn "El registro ", ordinate($i), " no es válido!\n"; 
    next;
  }
  ...
}

DESCRIPCIÓN

Hay dos tipos de números en inglés: cardinales (1, 2, 3...) y ordinales (1º, 2º, 3º...). Esta biblioteca proporciona funciones para obtener la forma ordinal de un número, dado su valor cardinal.

FUNCIONES

ordinate(SCALAR)
Devuelve una cadena que consiste en la forma de cadena de ese escalar, más el sufijo ordinal apropiado. Ejemplo: ordinate(23) devuelve "23rd".

Como caso especial, ordinate(undef) y ordinate("") devuelven "0th", no "th".

Esta función se exporta por defecto.

th(SCALAR)
Simplemente un alias de "ordinate", pero no se exporta por defecto.
ordsuf(SCALAR)
Devuelve solo el sufijo ordinal apropiado para el valor numérico escalar dado. Esto es lo que "ordinate" usa para realizar su trabajo. Por ejemplo, ordsuf(3) es "rd".

No se exporta por defecto.

Las funciones anteriores están todas prototipadas para tomar un valor escalar, por lo que ordinate(@stuff) es lo mismo que "ordinate(scalar @stuff)".

ADVERTENCIAS

* Tenga en cuenta que esta biblioteca solo conoce números, no palabras numéricas. ordinate('seven') podría ser igualmente ordinate('superglue') o ordinate("\x1E\x9A"): obtendrá el caso de paso de la cadena de entrada más "th".

* Como es inevitable, ordinate(0256) devuelve "174th" (porque ordinate ve el valor 174). De manera similar, ordinate(1E12) devuelve "1000000000000th". Devolver "trillionth" sería agradable, pero es un caso muy atípico.

* Tenga en cuenta que el algoritmo de esta biblioteca (así como el concepto básico y la implementación de los números ordinales) es totalmente específico del idioma.

Para tomar un ejemplo trivial, considere que en francés, 1 se ordena como "1er", mientras que 41 se ordena como "41ième".

VER TAMBIÉN

Lingua::EN::Inflect proporciona una función "ORD", que devuelve la forma ordinal de un número cardinal.

Lingua::EN::Number::IsOrdinal proporciona una función "is_ordinal", que devuelve verdadero si se le pasa un número ordinal.

Lingua::EN::Numbers proporciona la función num2en_ordinal() que tomará un número y devolverá el ordinal como una palabra. Así que 3 resultará en "third".
