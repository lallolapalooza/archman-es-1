NOMBRE

Locale::Maketext::Lexicon - Usar formatos de catálogo distintos a los predeterminados en Maketext

VERSIÓN

1.00

SINOPSIS

Como parte de una clase de localización, buscar automáticamente los catálogos disponibles:

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    '*' => [Gettext => '/usr/local/share/locale/*/LC_MESSAGES/hello.mo'],
    ### Descomenta para el caso de que una clave no se encuentre en un léxico
    # _auto   => 1,
    ### Descomenta para decodificar entradas del léxico a cadenas Unicode
    # _decode => 1,
    ### Descomenta para cargar y parsear todo de inmediato
    # _preload => 1,
    ### Descomenta para usar %1 / %quant(%1) en lugar de [_1] / [quant, _1]
    # _style  => 'gettext',
};

Especificar explícitamente idiomas, en tiempo de compilación o en tiempo de ejecución:

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello_de.po'],
    fr => [
        Gettext => 'hello_fr.po',
        Gettext => 'local/hello/fr.po',
    ],
};
# ... añadir incrementalmente nuevos léxicos
Locale::Maketext::Lexicon->import({
    de => [Gettext => 'local/hello/de.po'],
})

Alternativamente, como parte de una subclase de localización:

package Hello::I18N::de;
use base 'Hello::I18N';
use Locale::Maketext::Lexicon (Gettext => \*DATA);
__DATA__
# Algunos datos de ejemplo
msgid ""
msgstr ""
"Project-Id-Version: Hello 1.3.22.1\n"
"MIME-Version: 1.0\n"
"Content-Type: text/plain; charset=iso8859-1\n"
"Content-Transfer-Encoding: 8bit\n"
#: Hello.pm:10
msgid "Hello, World!"
msgstr "Hallo, Welt!"
#: Hello.pm:11
msgid "You have %quant(%1,piece) of mail."
msgstr "Sie haben %quant(%1,Poststueck,Poststuecken)."

DESCRIPCIÓN

Este módulo proporciona módulos de manejo de catálogos que leen de otros formatos de localización, como Gettext, Msgcat, y otros.

Si no estás familiarizado con el concepto de módulos de catálogo, consulta Locale::Maketext y los archivos HTML "webl10n" en el directorio "docs/" de este módulo.

También se instaló una utilidad de línea de comandos xgettext.pl para extraer las cadenas traducibles de los archivos fuente.

La función import()

La función import() acepta dos formas de argumentos:

(formato => fuente ...)
Esta forma toma cualquier número de pares de argumentos (generalmente uno); fuente puede ser un nombre de archivo, un descriptor de archivo o una referencia a un array.
Para cada par, pasa el contenido especificado por el segundo argumento a Locale::Maketext::Lexicon::format->parse como una lista normal, y exporta su valor devuelto como el %Lexicon en el paquete de llamada.
En el caso de múltiples pares, el catálogo definido por los últimos sobrescribe a los anteriores.
{ idioma => [formato, fuente ...] ... }
Esta forma acepta una referencia a un hash. Se exportará un %Lexicon a cada subclase especificada por cada idioma, usando el proceso descrito anteriormente. Está diseñada para reducir la necesidad de crear una subclase separada para cada idioma localizado, y simplemente usar los archivos de catálogo.
Este módulo convertirá los argumentos de idioma a minúsculas, y reemplazará todos los "-" por "_", por lo tanto "zh_TW" y "zh-tw" se mapearán a "zh_tw".
Si el idioma comienza con "_", se considera una opción que controla cómo se parsean los catálogos. Consulta "Opciones" para una lista de opciones disponibles.
El "*" es un idioma especial; debe usarse junto con un nombre de archivo que también contenga "*". Todos los archivos que coincidan con un código de idioma válido en lugar de "*" se prepararán automáticamente como una subclase de catálogo. Si hay múltiples "*" en el nombre del archivo, el último se usará como el nombre del idioma.

Opciones

"_auto"
Si se establece a un valor verdadero, las consultas que se realicen en catálogos vacíos se manejarán silenciosamente, como si se hubiera añadido un catálogo "Auto" a todos los catálogos de idioma.
"_decode"
Si se establece a un valor verdadero, las entradas fuente se convertirán a cadenas UTF-8 (disponible en Perl 5.6.1 o posterior). Esta característica requiere el módulo Encode o Encode::compat.
Actualmente, solo el backend "Gettext" soporta esta opción.
"_encoding"
Esta opción solo tiene efecto cuando _decode se establece a true. Especifica una codificación para almacenar las entradas del catálogo, en lugar de cadenas UTF-8.
Si _encoding se establece a "locale", la codificación se usará del entorno del locale actual.
"_preload"
Por defecto, el parseo se retrasa hasta que se use el catálogo por primera vez. Si se establece a un valor verdadero, se parsea inmediatamente. La carga incremental de catálogos fuerza el parseo.

Subclase de manejadores de formato

Si deseas reemplazar cómo se manejan los datos fuente de diferentes tipos, usa una subclase que reemplace Locale::Maketext::lexicon_get_...

NOTAS

Cuando intentas localizar una entrada que no existe en el catálogo, Maketext lanzará una excepción por defecto. Para evitar este comportamiento, sobrescribe la clave _AUTO en tu subclase de idioma, por ejemplo:

$Hello::I18N::en::Lexicon{_AUTO} = 1; # crear claves faltantes automáticamente

Si quieres implementar un nuevo backend de catálogo "Lexicon::*", ten en cuenta que la función parse() toma un array que contiene las cadenas fuente de los archivos de entrada o descriptores de archivo, que no están cortadas (chomp). Aunque si el fuente es una referencia de array, sus elementos probablemente no contengan caracteres de nueva línea.

La función parse() debería devolver una referencia a un hash, que se asigna al %Lexicon (glob de tipo *Lexicon) de la modulación del idioma. Lo importante es que si la referencia devuelta apunta a un hash vinculado, el %Lexicon se aliñará al mismo hash vinculado si no fue inicializado previamente.
