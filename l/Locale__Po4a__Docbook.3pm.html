NOMBRE

Locale::Po4a::Docbook - convierte documentos DocBook XML desde/hacia archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y, de manera más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::Docbook es un módulo para ayudar a la traducción de documentos DocBook XML a otros idiomas [humanos].

ESTADO DE ESTE MÓDULO

Este módulo es completamente funcional, ya que se basa en el módulo Locale::Po4a::Xml. Este solo define las etiquetas y atributos traducibles.

El único problema conocido es que aún no maneja entidades, y esto incluye las entidades de inclusión de archivos, pero puedes traducir la mayoría de esos archivos individualmente (excepto los archivos de entidades típicos), y generalmente es mejor mantenerlos separados.

SOBRESCRIBIR EL COMPORTAMIENTO PREDETERMINADO CON OPCIONES DE LÍNEA DE COMANDOS

El comportamiento predeterminado de los módulos proporcionados por el sistema está configurado para ser precavido.

Por ejemplo, el valor predeterminado de la etiqueta <author> tiene como objetivo que aparezca dentro de <para>. Pero puede que solo la estés utilizando dentro de <bookinfo>. Para este caso, es posible que desees traducirla de forma independiente para cada autor.

Si no te gusta el comportamiento predeterminado del módulo xml y sus módulos derivados, puedes proporcionar opciones de línea de comandos para cambiar su comportamiento. Por ejemplo, puedes añadir lo siguiente al archivo de configuración de po4a:

opt:"-k 0 -o nodefault=\"<bookinfo> <author>\" \
          -o break=\"<bookinfo> <author>\" \
          -o untranslated=\"<bookinfo>\" \
          -o translated=\"<author>\""

Esto anula el comportamiento predeterminado para <bookinfo> y <author>, establece <bookinfo> y <author> para dividir el flujo de datos de entrada en estas etiquetas, establece <bookinfo> para que no traduzca su contenido etiquetado y establece <author> para traducir su contenido etiquetado.
