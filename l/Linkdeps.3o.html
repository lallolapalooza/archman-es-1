tipo t

El estado de la verificación de enlace. Mantiene un registro de las unidades de compilación proporcionadas y requeridas hasta el momento.

tipo compunit = string

tipo filename = string

val crear : completo:bool -> t

crear ~completo devuelve un estado vacío. Si completo es true , las unidades de compilación que falten se tratarán como errores.

val agregar : t -> nombre_archivo:filename -> unidad_comp:compunit -> proporciona:compunit list -> requiere:compunit list -> unit

agregar t ~nombre_archivo ~unidad_comp ~proporciona ~requiere registra la unidad de compilación unidad_comp encontrada en nombre_archivo en t .

- proporciona son las unidades y subunidades proporcionadas por unidad_comp

- requiere son las unidades requeridas por unidad_comp

agregar debe llamarse en orden topológico inverso.

val requerido : t -> compunit -> bool

requerido t unidad_comp devuelve true si unidad_comp es una dependencia de unidades de compilación añadidas anteriormente.

tipo compunit_y_fuente = {
unidad_comp : compunit ;
nombre_archivo : filename ;
}

tipo error =
| Implementaciones_faltantes de (compunit * compunit_y_fuente list) list
| Orden_enlace_incorrecto de (compunit_y_fuente * compunit_y_fuente list) list
| Múltiples_definiciones de (compunit * filename list) list

val verificar : t -> error option

verificar t debe llamarse una vez que se hayan añadido todas las unidades de compilación que se van a enlazar. Devuelve un error si:

-Hay implementaciones faltantes y completo es true

-Alguna implementación aparece antes de sus dependencias
