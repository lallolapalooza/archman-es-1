Locale::Script(3) Documentación de Perl aportada por el usuario Locale::Script(3)

NOMBRE

Locale::Script - módulo para tratar con conjuntos de códigos de script

SINOPSIS

use Locale::Script;
$nombre = code2script(CÓDIGO);
$código = script2code(NOMBRE);
@códigos   = all_script_codes();
@nombres   = all_script_names();

DESCRIPCIÓN

Este módulo proporciona acceso a conjuntos de códigos de script.

Por favor, consulte el documento Locale::Codes::Types para una descripción de los conjuntos de códigos disponibles.

La mayoría de las rutinas toman un argumento adicional opcional que especifica el conjunto de códigos a utilizar. El conjunto de códigos se puede especificar utilizando el nombre de un conjunto de códigos o la constante perl especificada en el documento anterior. Si no se especifica, se utilizará el conjunto de códigos predeterminado.

RUTINAS

Todas las rutinas de este módulo llaman al método apropiado en el módulo Locale::Codes, utilizando un objeto del tipo: script. Consulte la documentación del módulo Locale::Codes para obtener detalles sobre cada función.

Las siguientes funciones se exportan automáticamente:

code2script(CÓDIGO [,CONJUNTO_DE_CÓDIGOS] [,'retirado'])
Véase code2name en Locale::Codes
code2scripts(CÓDIGO [,CONJUNTO_DE_CÓDIGOS])
Véase code2names en Locale::Codes
script2code(NOMBRE [,CONJUNTO_DE_CÓDIGOS] [,'retirado'])
Véase name2code en Locale::Codes
script_code2code(CÓDIGO ,CONJUNTO_DE_CÓDIGOS ,CONJUNTO_DE_CÓDIGOS2)
Véase code2code en Locale::Codes
all_script_codes([CONJUNTO_DE_CÓDIGOS] [,'retirado'])
Véase all_codes en Locale::Codes
all_script_names([CONJUNTO_DE_CÓDIGOS] [,'retirado'])
Véase all_names en Locale::Codes

Las siguientes funciones no se exportan y deben llamarse con el nombre completo del paquete:

Locale::Script::show_errors(FLAG)
Por defecto, la entrada no válida producirá resultados vacíos, pero no errores. Al pasar un valor distinto de cero para FLAG, se producirán errores.

Véase show_errors en Locale::Codes, pero tenga en cuenta que el valor predeterminado para los módulos no OO es NO producir errores.

Locale::Script::rename_script(CÓDIGO ,NUEVO_NOMBRE [,CONJUNTO_DE_CÓDIGOS])
Véase rename_code en Locale::Codes
Locale::Script::add_script(CÓDIGO ,NOMBRE [,CONJUNTO_DE_CÓDIGOS])
Véase add_code en Locale::Codes
Locale::Script::delete_script(CÓDIGO [,CONJUNTO_DE_CÓDIGOS])
Véase delete_code en Locale::Codes
Locale::Script::add_script_alias(NOMBRE ,NUEVO_NOMBRE)
Véase add_alias en Locale::Codes
Locale::Script::delete_script_alias(NOMBRE)
Véase delete_alias en Locale::Codes
Locale::Script::rename_script_code(CÓDIGO ,NUEVO_CÓDIGO [,CONJUNTO_DE_CÓDIGOS])
Véase replace_code en Locale::Codes
Locale::Script::add_script_code_alias(CÓDIGO ,NUEVO_CÓDIGO [,CONJUNTO_DE_CÓDIGOS])
Véase add_code_alias en Locale::Codes
Locale::Script::delete_script_code_alias(CÓDIGO [,CONJUNTO_DE_CÓDIGOS])
Véase delete_code_alias en Locale::Codes
