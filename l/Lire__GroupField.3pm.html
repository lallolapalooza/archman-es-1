NOMBRE

Lire::GroupField - Clase que implementa el elemento de campo en las especificaciones de informes.

SINOPSIS

use Lire::GroupField;

DESCRIPCIÓN

Este módulo se utiliza para representar los elementos de campo que aparecen en el elemento agregador de grupo en las especificaciones de informes.

CONSTRUCTOR

nuevo( %parámetros )

Crea un nuevo objeto Lire::GroupField. Toma varios parámetros similares a Lire::ReportOperator.

nombre
El nombre del campo DLF que representa este GroupField. No debe ser un campo de cantidad o tiempo (se deben usar otros agregadores para estos).
especificación_informe
La especificación del informe en la que se agrega este campo de grupo.
etiqueta
La etiqueta de la columna que se debe usar para este campo.

nombre()

Devuelve el nombre del campo DLF que representamos.

etiqueta( [$nueva_etiqueta] )

Devuelve la etiqueta que se debe utilizar para la columna que generamos en el informe. Por defecto, se utiliza la etiqueta del campo DLF.

Se puede cambiar pasando un parámetro $nueva_etiqueta.

campo()

Devuelve el campo DLF que representamos como un objeto Lire::Field.

VER TAMBIÉN
