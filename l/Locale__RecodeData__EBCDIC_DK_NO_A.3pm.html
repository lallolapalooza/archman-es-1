NOMBRE

Locale::RecodeData::EBCDIC_DK_NO_A - Rutinas de conversión para EBCDIC_DK_NO_A

SINOPSIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para EBCDIC-DK-NO-A.

COMENTARIOS

Las siguientes observaciones se han extraído del original charmap:

version: 1.0
 source: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, April 1987

Nota: ¡Los alias mencionados anteriormente no son necesariamente válidos!
