NOMBRE

Lire::DlfConverterProcess - Objeto que controla el proceso de conversión de DLF

SINOPSIS

use Lire::ImportJob;
use Lire::DlfStore;
use Lire::DlfConverterProcess;
my $src = new Lire::ImportJob( "archivo", 'patrón' => "/var/log/messages" );
my $store = Lire::DlfStore->open( "almacén" );
my $process = new Lire::DlfConverterProcess( $src, $store );
$process->run_import_job();
print "Líneas de registro leídas: " ,      $process->line_count(), "\n";
print "Registros DLF creados: " , $process->dlf_count,    "\n";
print "Errores encontrados: " ,  $process->errors_count, "\n";
print "Registros ignorados: " ,     $process->ignored_count,"\n";

DESCRIPCIÓN

Este objeto encapsula el proceso de conversión DLF de Lire. Toma como parámetros un Lire::ImportJob y un Lire::DlfStore. Configura el conversor y convertirá el contenido de Lire::ImportJob a DLF, que se guardará en el Lire::DlfStore.

El objeto proporciona la API al conversor. También hay métodos disponibles para consultar información sobre el proceso de conversión.

new( $job, $store );

Crea un Lire::DlfConverterProcess que se utilizará para importar el registro especificado en Lire::ImportJob a registros DLF que se almacenarán en Lire::DlfStore.

run_import_job( [$tiempo] )

Importa los datos del registro del ImportJob como DLF. Este método lanzará una excepción si se llama más de una vez. El parámetro $tiempo se usará para determinar la ventana de tiempo cubierta por el período. Por defecto es la hora actual.

job_id()

Devuelve el identificador del trabajo asociado a este proceso.

dlf_store()

Devuelve el Lire::DlfStore en el que este proceso de conversión está almacenando los registros DLF.

import_job()

Devuelve el Lire::ImportJob sobre el que está operando este proceso de conversión.

line_count()

Devuelve el número de líneas procesadas. Será 0 en caso de que el proceso de conversión DLF sea de archivos y no de líneas de registro. Durante un procesamiento, esto siempre es igual a la línea que se está convirtiendo actualmente.

dlf_count()

Devuelve el número de registros DLF creados.

error_count()

Devuelve el número de errores encontrados en el proceso de conversión.

ignored_count()

Devuelve el número de registros que fueron ignorados en el proceso de conversión.

saved_count()

Devuelve el número de líneas que se guardaron para su posterior procesamiento.

API PARA LOS CONVERSORES DLF

Este es el objeto que encapsula la implementación DLF y oculta la complejidad del marco de almacenamiento al conversor DLF. Ofrece los siguientes métodos al conversor DLF.

write_dlf( $schema, $dlf )

Escribe el registro DLF $dlf que cumple con el esquema de $schema en el Lire::DlfStore. El esquema es el nombre del esquema (por ejemplo, 'www'). $dlf es una referencia a un hash. Las claves son el nombre del campo del esquema. Un valor indefinido significa que este campo no está disponible en ese registro.

save_log_line( $line )

Método que debe usarse para guardar $line para una futura ejecución de procesamiento del conversor en el mismo Lire::ImportJob.

ignored_log_line( $line, [ $razon ] )

Método que puede ser utilizado por el Lire::DlfConverter para informar que la línea de registro '$line' fue ignorada durante ese procesamiento. La razón por la que se ignoró la línea se puede dar en $razon. Por ejemplo, un conversor basado en syslog debería usar este método para informar líneas que son para un servicio diferente al suyo.

error( $error_msg, [ $line ] );

Método que debe ser utilizado por el Lire::DlfConverter para informar que se encontró un error al procesar el Lire::ImportJob. $error_msg debe usarse para informar la naturaleza del error. El parámetro $line debe ser utilizado por los conversores que operan sobre líneas para asociar el mensaje de error a una línea en particular.
