NOMBRE

Locale::RecodeData::CP1252 - Rutinas de conversión para CP1252

SINOPSIS

Este módulo es interno de libintl. No lo debes usar directamente.

DESCRIPCIÓN

Este módulo es generado y contiene las tablas de conversión y rutinas para CP1252.

COMENTARIOS

Las siguientes observaciones se han extraído del charmap original:

version: 1.0
repertoiremap: mnemonic,ds
 source: UNICODE 1.0
alias MS-ANSI

Nota: Los alias mencionados anteriormente no son necesariamente válidos.
