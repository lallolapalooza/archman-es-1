NOMBRE


Locale::RecodeData::IBM865 — Tabla de asignación de codificación para IBM 865.






SINOPSIS


use Locale::RecodeData::IBM865;






DESCRIPCIÓN


Este módulo define la tabla de asignación de caracteres para
    la codificación IBM865.


La codificación IBM865, también conocida como
    CP865, es una página de códigos utilizada en
    algunos sistemas informáticos.






COMENTARIOS


Esta sección contiene comentarios adicionales, pero no hay
    comentarios en este ejemplo.
