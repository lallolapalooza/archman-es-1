NOMBRE

Lire::Test::DlfConverterTestCase - Clase base para escribir pruebas unitarias de DLfConverter

SINOPSIS

use base qw/ Lire::Test::DlfConverterTestCase /;
use MyConverter;
use File::Basename;
sub create_converter {
  return new MyConverter();
}
sub schemasdir {
  return dirname( __FILE__ ) .  "../..";
}
sub registration_file {
  return dirname( __FILE__ ) .  "../../myconverter_init";
}

DESCRIPCIÓN

Esta es una subclase de Test::Unit::TestCase que se puede usar para escribir pruebas fácilmente para DlfConverter. Esta clase implementa lo necesario para proporcionar el fixture requerido en set_up() y tear_down().

Proporciona dos pruebas base: test_api() y test_registration_file().

La clase de prueba necesita implementar tres métodos para ayudar a completar el fixture.

FIXTURES

Estos son los métodos que las subclases normalmente anularán para proporcionar los datos necesarios para que se configuren los fixtures de prueba de DlfConverter.

registration_file()

Debe devolver el script responsable de registrar el convertidor con Lire::PluginManager. Esto es utilizado por el test_registration_file() predeterminado.

schemasdir()

Este método debe devolver el directorio que contiene los esquemas utilizados por el convertidor. Esto se añadirá a la variable de configuración lr_schemas_path si se llama a set_up_path().

create_converter()

Debe devolver una instancia del objeto Lire::DlfConverter a probar.

set_up_path()

Esto añadirá el schemasdir a 'lr_schemas_path'.

Proceso de Mock de Convertidor

create_mock_process()

Este método devolverá un MockDlfConverterProcess que se puede usar para ayudar a probar DlfConverter. Todos los valores para write_dlf(), error(), ignore_log_line() y save_log_line() se guardan y se pueden consultar a través de los métodos dlf( 'schema' ), errors(), ignored() y saved().

El proceso simulado también tiene un método converter() que devuelve el DlfConverter creado por create_converter() y asociado a su instancia.

PRUEBAS PREDETERMINADAS

test_api()

Asegura que todos los métodos requeridos por Lire::DlfConverter estén implementados. También prueba que los esquemas devueltos por schemas() estén disponibles.

Comprueba que description() se formatea correctamente como DocBook.

test_registration_file()

Comprueba que el script de registro registra correctamente el convertidor con el PluginManager.

VER TAMBIÉN

Lire::Test::TestCase(3pm), Lire::DlfConverter(3pm)
