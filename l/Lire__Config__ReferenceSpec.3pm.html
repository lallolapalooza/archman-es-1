NOMBRE

Lire::Config::ReferenceSpec - SelectSpec que toma sus opciones de un Índice.

DESCRIPCIÓN

Este Lire::Config::TypeSpec es un SelectSpec que define una opción para cada entrada disponible en el Índice nombrado en su propiedad index.

new( 'nombre' => $nombre, 'indice' => $indice, ... )

Crea un nuevo objeto ReferenceSpec. Las opciones disponibles se consultarán en tiempo de ejecución bajo Index.

indice( [$nuevo_indice )

Devuelve (y opcionalmente cambia) la configuración de los atributos del índice.

VER TAMBIÉN

Lire::Config::ReportConfigIndex(3pm) Lire::Config::Index(3pm)
