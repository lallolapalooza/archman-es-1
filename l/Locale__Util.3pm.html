Locale::Util(3) Documentación de Perl aportada por el usuario Locale::Util(3)

NOMBRE

Locale::Util - Funciones portátiles de l10n e i10n

SINOPSIS

use Locale::Util;
my @linguas = parse_http_accept_language $ENV{HTTP_ACCEPT_LANGUAGE};
my @charsets = parse_http_accept_charset $ENV{HTTP_ACCEPT_CHARSET};
# Intenta establecer la configuración regional a portugués de Brasil en UTF-8.
my $set_locale = set_locale LC_ALL, 'pt', 'BR', 'utf-8';
set_locale_cache $last_cache;

my $cache = get_locale_cache;
web_set_locale ($ENV{HTTP_ACCEPT_LANGUAGE}, $ENV_ACCEPT_CHARSET);
web_set_locale (['fr-BE', 'fr', 'it'], ['cp1252', 'utf-8']);

DESCRIPCIÓN

Este módulo proporciona funciones portátiles para la localización (l10n) y la internacionalización (i10n). No exporta nada por defecto, debes especificar cada función que necesites en la lista de importación, o usar el nombre completamente calificado.

Las funciones aquí presentes se centran en el desarrollo web, aunque son lo suficientemente generales como para incluirlas en el espacio de nombres Locale::.

Este módulo se considera código alfa. La interfaz no es estable. Ponte en contacto con el autor si deseas utilizarlo en código de producción.

Este módulo se introdujo en libintl-perl 1.17.

FUNCIONES

parse_http_accept_language CADENA
Analiza una cadena como se pasa en la cabecera HTTP "Accept-Language". Devuelve una lista de tokens ordenados por el valor de calidad, ver RFC 2616 para más detalles.

Ejemplo:

parse_http_accept ("fr-fr, fr; q=0.7, de; q=0.3");

Esto significa: dame francés para Francia con un valor de calidad de 1.0 (el máximo). De lo contrario, tomaré cualquier otra versión francesa (calidad 0.7), el alemán tiene una calidad de 0.3 para mí.

La función devolverá una lista de tokens en el orden de sus valores de calidad, en este caso "fr-fr", "fr" y "de".

La función es más tolerante que la RFC 2616. Acepta valores de calidad mayores que 1.0 y con más de 3 decimales. También acepta nombres de idioma y país con más de 8 caracteres. El idioma "*" se traduce a "C".

parse_http_accept_charset CADENA
Analiza una cadena como se pasa en la cabecera HTTP "Accept-Charset". Devuelve una lista de tokens ordenados por el valor de calidad, ver RFC 2616 para más detalles.

El conjunto de caracteres especial "*" (significa todos los conjuntos de caracteres) se traducirá al valor indefinido.

set_locale CATEGORÍA, IDIOMA[, PAÍS, JUEGO_DE_CARACTERES]
Intenta establecer la configuración regional del usuario mediante POSIX::setlocale(). Esta última función tiene la desventaja de que su segundo argumento (la cadena de descripción de la configuración regional) es completamente no estándar y dependiente del sistema. Esta función hace todo lo posible por adivinar la noción del sistema de un identificador de configuración regional, con los argumentos proporcionados:
CATEGORÍA
Un argumento entero para una categoría de configuración regional válida. Estas son las constantes LC_* (LC_ALL, LC_CTIME, LC_COLLATE, ...) definidas tanto en Locale::Messages(3pm) como en POSIX(3pm).
IDIOMA
Un identificador de idioma de 2 letras según ISO 639. No distingue mayúsculas de minúsculas, pero siempre se intentará usar una versión no modificada (es decir, no en minúsculas) del idioma que proporcionaste.
PAÍS
Un identificador de idioma de 2 letras según ISO 639. No distingue mayúsculas de minúsculas, pero siempre se intentará usar una versión no modificada (es decir, no en minúsculas) del idioma que proporcionaste.

Este parámetro es opcional. Si no se define, la función intentará adivinar un país apropiado, de lo contrario lo dejará en manos del sistema operativo.

JUEGO_DE_CARACTERES
Un nombre de conjunto de caracteres válido. ¡Válido significa válido! El conjunto de caracteres "utf8" no es válido (es "utf-8"). Los nombres de conjunto de caracteres que son aceptados por los algoritmos de adivinación en Encode(3pm) tampoco son necesariamente válidos.

Si el parámetro no está definido, se ignora. Siempre se ignora en Windows.

La función intenta abordar la configuración regional deseada en bucles, refinándola en cada éxito. Primero intentará establecer el idioma (para cualquier país), luego intentará seleccionar el idioma correcto y, finalmente, intentará seleccionar el conjunto de caracteres correcto.

El valor de retorno es falso en caso de fallo, o el valor de retorno de la llamada subyacente a POSIX::setlocale() en caso de éxito.

En contexto de lista, la función devuelve el nombre del país que se pasó en la llamada exitosa a POSIX::setlocale(). Si esta cadena es igual al nombre del país que pasaste como argumento, puedes estar razonablemente seguro de que la configuración para ese país se está utilizando realmente. Si no es igual, la función ha hecho una suposición sobre el país (tiene una lista de países "predeterminados" para cada idioma). Parece que en Windows, POSIX::setlocale() también tiene éxito si pasas un nombre de país que en realidad no es compatible. Por lo tanto, la información no es completamente fiable.

Tenga en cuenta que esta función está pensada para procesos servidor (especialmente aplicaciones web) que necesitan cambiar de forma portable a una configuración regional determinada. **No** es la forma recomendada de establecer la configuración regional del programa para una aplicación normal. En una aplicación normal, deberías hacer lo siguiente:

use POSIX qw (setlocale LC_ALL);
setlocale LC_ALL, '';

La cadena vacía como segundo argumento significa que el sistema debe cambiar a la configuración regional predeterminada del usuario.

get_locale_cache
La función set_locale() es potencialmente costosa, especialmente cuando falla, ya que puede intentar muchas combinaciones diferentes, y el sistema puede tener que cargar muchas definiciones de configuración regional de su base de datos interna.

Para acelerar las cosas, los resultados se almacenan en caché internamente en un hash, las claves son los idiomas, las subclaves los países, las sub-subclaves los conjuntos de caracteres. Puedes obtener una referencia a este hash con get_locale_cache().

La función no puede fallar.

set_locale_cache HASH
Establece la caché interna. Puedes pasar un hash o una referencia a un hash. La función usará esto como su caché, descartando su caché antigua. Esto te permite mantener el hash persistente.

La función no puede fallar.

web_set_locale (ACCEPT_LANGUAGE, ACCEPT_CHARSET, CATEGORÍA, DISPONIBLES)
Intenta cambiar la configuración regional a los ajustes descritos por ACCEPT_LANGUAGE y ACCEPT_CHARSET. Para cada argumento puedes pasar una cadena como en la cabecera http correspondiente, o una referencia a una lista de identificadores de idioma o conjunto de caracteres, respectivamente.

Actualmente, solo se utiliza el primer conjunto de caracteres pasado como argumento. Se te recomienda encarecidamente que pases un valor codificado aquí, para que tengas control sobre tu salida.

El argumento CATEGORÍA especifica la categoría (una de las constantes LC_* como se definen en Locale::Messages(3pm) o en POSIX(3pm)). La categoría por defecto es LC_ALL.

Puedes pasar una referencia opcional a una lista de configuraciones regionales en formato XPG4 que están disponibles en tu aplicación. Esto es útil si sabes qué idiomas soporta tu aplicación. Locale::Util - Perl module to determine the locale, the country, and the charset actually used.

NAME

Locale::Util - Perl module to determine the locale, the country, and the charset actually used.

SYNOPSIS

  use Locale::Util;
  my $util = Locale::Util->new();
  my $locale = $util->get_locale();
  my $lang   = $util->get_language();
  my $country = $util->get_country();
  my $charset = $util->get_charset();

DESCRIPTION

This module can determine the language, the country, and the charset of the system, where the script is running.

It relies on environment variables like LANG, LANGUAGE and LC_ALL.

FUNCTIONS

new()
Creates a new Locale::Util object.
get_locale()
Returns the locale string. This is the full string like en_US.UTF-8.
get_language()
Returns the language code, e.g. en.
get_country()
Returns the country code, e.g. US.
get_charset()
Returns the charset, e.g. UTF-8.
set_locale()
Tries to guess the locale, the country, and the charset actually used.

BUGS

The function set_locale() probably fails to guess the correct locale identifier on a lot of systems. If you have found such a case, please submit it as a bug report.

The bug tracking system for this packags is at http://rt.cpan.org/NoAuth/Bugs.html?libintl-perl

Please note that this module is considered alpha code, and the interface is not stable. Please contact the author, if you want to use it in production code.
