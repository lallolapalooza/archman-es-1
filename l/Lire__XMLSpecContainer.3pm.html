NOMBRE

Lire::XMLSpecContainer - Clase base para especificaciones de reporte y filtro XML

SYNOPSIS

use base qw/Lire::XMLSpecContainer/;

DESCRIPCIÓN

Esta es la clase base para Lire::ReportSpec y Lire::FilterSpec, que son especificaciones XML utilizadas para calcular informes. Este manúal documenta los atributos comunes a ambos tipos de especificación.

id( [ $new_id ] )

Devuelve el tipo de identidad de esta especificación. Si $new_id es establecido, cambiará la identidad de la especificación.

superservice( [ $new_superservice ] )

Devuelve el supersección (también conocida como base DLF) utilizada por esta especificación. Si $new_superservice es establecido, cambiará la supersección de la especificación.

schema( [ $new_schema ] )

Devuelve el objeto Lire::DLfSchema usado por esta especificación. Esto puede ser la supersección o cualquier de sus Lire::ExtendedSchema o Lire::DerivedSchema.

Si $new_schema es una cadena, la especificación's schema se cambiará a esa cadena. Si $new_schema es undef, se utilizará el base DlfSchema (también conocido como supersección).

joined_schemas( [ $new_schemas ] )

Devuelve como referencia de array, la lista de esquemas unidos en esta especificación.

Si $new_schemas es establecido, la lista de esquemas unidas se cambiará a ese listado. Este es un array de nombres de esquema. Todos estos esquemas deben ser compatibles con el esquema especificado en el atributo schema().

schemas()

Devuelve en un array de referencia todas las esquemas utilizadas por esta especificación. Esto incluirá la esquema base así como cualquier esquema unido.

has_field( $name )

Devuelve si el campo denominado $name está disponible en esta especificación o en cualquier de sus esquemas unidos.

field( $name )

Devuelve el objeto Lire::Field objeto denominado $name presente en uno de los esquemas unidos de esta especificación.

title( [ $new_title ]

Este método devuelve el título de esta especificación. Si $new_title es establecido, la título de la especificación se cambiará a ese valor.

El valor devuelto es localizado si hay una cadena de traducción disponible. El dominio utilizado para la traducción es 'lire-<superservice'.

description( [ $new_description ]

Este método devuelve la descripción de esta especificación. Si $new_description es establecido, la descripción de la especificación se cambiará a ese valor. La descripción es una cadena DocBook describiendo el propósito de la especificación.

El valor devuelto es localizado si hay una cadena de traducción disponible. El dominio utilizado para la traducción es 'lire-<superservice'.

display_title( [ $new_title ]

Este método devuelve el título que se mostrará en la especificación generada. Este valor puede contener referencias a parámetros de la especificación usando el símbolo '$name'.

Si $new_title es establecido, el título de la especificación se cambiará a ese valor.

El valor devuelto es localizado si hay una cadena de traducción disponible. El dominio utilizado para la traducción es 'lire-<superservice'.

display_description( [ $new_description ]

Este método devuelve la descripción que se mostrará en el informe generado. Este valor puede contener referencias a parámetros de la especificación usando el símbolo '$name'.

Si $new_description es establecido, la descripción de la especificación se cambiará a ese valor. La descripción es una cadena DocBook describiendo el propósito de la especificación.

El valor devuelto es localizado si hay una cadena de traducción disponible. El dominio utilizado para la traducción es 'lire-<superservice'.

expanded_display_title()

Devuelve display_title() con los parámetros referidos expandidos.

expanded_display_description()

Devuelve display_description() con los parámetros referidos expandidos.

print( $fh )

Imprime esta especificación como XML en $fh.

VER TAMBIÉN

Lire::XMLSpecContainer(3pm)

NAME

Lire::XMLSpecContainer - XML specification data container

SYNOPSIS

use Lire::XMLSpecContainer;

my $container = Lire::XMLSpecContainer->new();
$container->add_spec( spec_id => 'spec-1', uri => 'http://example.com/spec.xml' );
my $spec = $container->get_spec( spec_id => 'spec-1' );
my @specs = $container->list_specs();

DESCRIPTION

This class provides a simple container for storing and retrieving XML specification data. Each specification is identified by a unique ID and can be associated with a URI. The container manages the loading and caching of specification data.

METHODS

new()
Constructs a new Lire::XMLSpecContainer object.
add_spec( spec_id => $id, uri => $uri )
Adds a new specification to the container. $id is the unique identifier for the specification, and $uri is the URI where the specification can be found.
get_spec( spec_id => $id )
Retrieves the specification data associated with the given $id. If the specification has not been loaded yet, it will be fetched from its URI.
list_specs()
Returns a list of all specification IDs currently stored in the container.
