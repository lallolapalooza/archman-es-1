NOMBRE

List::Compare::Functional - Comparar elementos de dos o más listas

VERSIÓN

Este documento se refiere a la versión 0.55 de List::Compare::Functional. Esta versión fue publicada el 16 de agosto de 2020. La primera versión publicada de List::Compare::Functional fue v0.21. Los números de versión son consistentes con otros elementos de la distribución List::Compare.

Notas de cambios de interfaz

Al introducir la versión 0.25 de abril de 2004, se realizaron cambios significativos en la interfaz de List::Compare::Functional. La documentación inmediatamente debajo refleja esos cambios, por lo que si estás usando esta módulo por primera vez con esa o una versión posterior, simplemente lee y sigue la documentación debajo. Sin embargo, si ya usaste List::Compare::Functional antes de la versión 0.25, vea la discusión de cambios de interfaz más abajo: Cambio de interfaz de abril de 2004.

SINOPSIS

Empieza a usar

List::Compare::Functional no exporta subrutinas por defecto. Para importar todas las subrutinas públicas de List::Compare::Functional, usa:

use List::Compare::Functional qw(:originals :aliases);

Para importar solo una subrutina específica de List::Compare::Functional, usa el siguiente modelo:

use List::Compare::Functional qw( get_intersection );

Probablemente sea más conveniente para el usuario importar funciones usando uno de los dos tags de exportación siguientes:

use List::Compare::Functional qw(:main :mainrefs);

La asignación de las funciones de comparación a los tags de exportación se discute más abajo.

Para mayor claridad, comenzaremos discutiendo comparaciones de solo dos listas. Más adelante, discutiremos comparaciones de tres o más listas.

Comparando dos listas almacenadas en arrays

  • Dadas dos listas: 
    @Llist = qw(abel abel baker cámara delta edward fargo golfero);
@Rlist = qw(baker cámara delta delta edward fargo golfero hilton);
  • Obtén los elementos que aparecen al menos una vez en ambas listas (su intersección). 
    @intersection = get_intersection( [ \@Llist, \@Rlist ] );

    Nota: puedes colocar las referencias a las listas a comparar en un array nombrado y luego pasar a get_intersection() una referencia a ese array.

    @to_be_compared = ( \@Llist, \@Rlist );
@intersection = get_intersection( \@to_be_compared );

    Desde la versión 0.29 (mayo de 2004), List::Compare::Functional ofrece un método adicional de pasar argumentos a sus funciones. Si prefieres una división más explícita entre los tipos de argumentos que se pasan a una función, pasa una única referencia de hash que contenga las listas a comparar en un array anónimo, que es el valor correspondiente a la clave "lists":

    @intersection = get_intersection( {
   lists => [ \@Llist, \@Rlist ],
} );
  • Obtén los elementos que aparecen al menos una vez en cada lista (su unión). 
    @union = get_union( [ \@Llist, \@Rlist ] );

    o

    @union = get_union( { lists => [ \@Llist, \@Rlist ] } );
  • Obtén los elementos que aparecen (al menos una vez) solamente en la primera lista. 
    @Lonly = get_unique( [ \@Llist, \@Rlist ] );

    o

    @Lonly = get_unique( { lists => [ \@Llist, \@Rlist ] } );
  • Obtén los elementos que aparecen (al menos una vez) solamente en la segunda lista. 
    @Ronly = get_complement( [ \@Llist, \@Rlist ] );

    o

    @Ronly = get_complement( { lists => [ \@Llist, \@Rlist ] } );
  • @LorRonly = get_symmetric_difference( [ \@Llist, \@Rlist ] );
@LorRonly = get_symdiff( [ \@Llist, \@Rlist ] );       # alias

    o

    @LorRonly = get_symmetric_difference( { lists => [ \@Llist, \@Rlist ] } );
  • Genera un "bag" (multiconjunto) de todos los elementos de ambas listas. El bag difiere de la unión de las dos listas en que mantiene tantas copias de cada elemento como aparecen en las listas originales. 
    @bag = get_bag( [ \@Llist, \@Rlist ] );

    o

    @bag = get_bag( { lists => [ \@Llist, \@Rlist ] } );
  • Un enfoque alternativo a las funciones anteriores: si no requieres un array como valor de retorno de la llamada a la función, pero simplemente necesitas una *referencia* a un array anónimo, usa una de las siguientes funciones: 
    $intersection_ref = get_intersection_ref(         [ \@Llist, \@Rlist ] );
$union_ref        = get_union_ref(                [ \@Llist, \@Rlist ] );
$Lonly_ref        = get_unique_ref(               [ \@Llist, \@Rlist ] );
$Ronly_ref        = get_complement_ref(           [ \@Llist, \@Rlist ] );
$LorRonly_ref     = get_symmetric_difference_ref( [ \@Llist, \@Rlist ] );
$LorRonly_ref     = get_symdiff_ref(              [ \@Llist, \@Rlist ] ); # alias
$bag_ref          = get_bag_ref(                  [ \@Llist, \@Rlist ] );

    o

    $intersection_ref =
    get_intersection_ref(         { lists => [ \@Llist, \@Rlist ] } );
$union_ref        =
    get_union_ref(                { lists => [ \@Llist, \@Rlist ] } );
$Lonly_ref        =
    get_unique_ref(               { lists => [ \@Llist, \@Rlist ] } );
$Ronly_ref        =
    get_complement_ref(           { lists => [ \@Llist, \@Rlist ] } );
$LorRonly_ref     =
    get_symmetric_difference_ref( { lists => [ \@Llist, \@Rlist ] } );
$LorRonly_ref     =
    get_symdiff_ref(              { lists => [ \@Llist, \@Rlist ] } ); # alias
$bag_ref          =
    get_bag_ref(                  { lists => [ \@Llist, \@Rlist ] } );
  • Devuelve un valor verdadero si la primera lista ('L' para 'izquierda') es un subconjunto de la segunda lista ('R' para 'derecha'). 
    $LR = is_LsubsetR( [ \@Llist, \@Rlist ] );

    o

    $LR = is_LsubsetR( { lists => [ \@Llist, \@Rlist ] } );
  • Devuelve un valor verdadero si 'R' es un subconjunto de 'L'. 
    $RL = is_RsubsetL( [ \@Llist, \@Rlist ] );

    o

    $RL = is_RsubsetL( { lists => [ \@Llist, \@Rlist ] } );
  • Devuelve un valor verdadero si 'L' y 'R' son equivalentes, es decir, si cada elemento de 'L' aparece al menos una vez en 'R' y viceversa. 
    $eqv = is_LequivalentR( [ \@Llist, \@Rlist ] );
$eqv = is_LeqvlntR( [ \@Llist, \@Rlist ] );            # alias

    o

    $eqv = is_LequivalentR( { lists => [ \@Llist, \@Rlist ] } );
  • Devuelve un valor verdadero si 'L' y 'R' son disjuntos, es decir, si no tienen elementos comunes. 
    $disj = is_LdisjointR( [ \@Llist, \@Rlist ] );

    o

    $disj = is_LdisjointR( { lists => [ \@Llist, \@Rlist ] } );
  • Imprime un gráfico con formato estilizado que muestre si una lista es un subconjunto de la otra. 
    print_subset_chart( [ \@Llist, \@Rlist ] );

    o

    print_subset_chart( { lists => [ \@Llist, \@Rlist ] } );
  • Imprime un gráfico con formato estilizado que muestre si las dos listas son equivalentes (tienen los mismos elementos, al menos una vez en cada una). 
    print_equivalence_chart( [ \@Llist, \@Rlist ] );

    o

    print_equivalence_chart( { lists => [ \@Llist, \@Rlist ] } );
  • Determina en qué (si acaso) de las listas se puede encontrar una cadena de texto. En el contexto de lista, devuelve una lista de índices correspondientes a las listas que contienen la cadena de texto que se está probando. 
    @memb_arr = is_member_which( [ \@Llist, \@Rlist ] , [ 'abel' ] );

    o

    @memb_arr = is_member_which( {
    lists => [ \@Llist, \@Rlist ],  # el valor es una referencia
    item  => 'abel',                # el valor es una cadena
} );

    En el ejemplo anterior, @memb_arr será:

    ( 0 )

    ya que 'abel' está solo en @Llist, que tiene el índice 0 en la lista de argumentos pasada a new().

  • Al igual que otras funciones de List::Compare::Functional que devuelven una lista, puedes hacer que la función devuelva una referencia (escalar) a un array que contenga la lista. 
    $memb_arr_ref = is_member_which_ref( [ \@Llist, \@Rlist ] , [ 'abel' ] );

    o

    $memb_arr_ref = is_member_which_ref( {
    lists => [ \@Llist, \@Rlist ],
    item  => 'abel',
} );

Comparando tres o más listas

Las siguientes funciones se adaptan a la comparación de más de dos listas. Ten en cuenta que la mayoría de las funciones de comparación de dos listas son aplicables a tres o más listas si se invocan de la manera que se muestra a continuación:

  • Determina qué listas contienen un elemento en particular. 
    @lists_containing_item = get_item_memberships(
    [ \@list1, \@list2, \@list3, \@list4 ],
    'item_to_find'
);

    Si 'item_to_find' aparece en @list1 y @list3, entonces @lists_containing_item contendrá ( 0, 2 ).

    O, usando la notación de hash:

    @lists_containing_item = get_item_memberships( {
    lists => [ \@list1, \@list2, \@list3, \@list4 ],
    item  => 'item_to_find',
} );
  • Obtén una lista de todos los elementos que son únicos para cada una de las listas de entrada. 
    @uniques = get_all_uniques( [ \@list1, \@list2, \@list3 ] );

    O, usando la notación de hash:

    @uniques = get_all_uniques( { lists => [ \@list1, \@list2, \@list3 ] } );

    Esto devuelve una lista de arrays, donde el primer array contiene los elementos que son únicos en la primera lista de entrada, el segundo array contiene los elementos únicos en la segunda lista de entrada, y así sucesivamente.

  • Obtén un mapa de cada elemento a las listas en las que aparece. 
    %element_map = get_element_map( [ \@list1, \@list2, \@list3 ] );

    O, usando la notación de hash:

    %element_map = get_element_map( { lists => [ \@list1, \@list2, \@list3 ] } );

    Por ejemplo, si @list1 tiene 'a' y 'b', @list2 tiene 'b' y 'c', y @list3 tiene 'c' y 'd', entonces %element_map se verá así:

        a => [ 0 ],
    b => [ 0, 1 ],
    c => [ 1, 2 ],
    d => [ 2 ],

DESCRIPCIÓN

El módulo List::Compare::Functional proporciona un conjunto de funciones para comparar dos o más listas (pasadas como referencias a arrays). A diferencia de otras bibliotecas de comparación de listas, estas funciones son puramente funcionales, lo que significa que no modifican ninguna de las listas de entrada. Todas las funciones devuelven un nuevo array (o una referencia a un array) que representa el resultado de la comparación.

El módulo soporta dos formas principales de pasar las listas a comparar:

  • Una referencia a un array anónimo que contiene referencias a los arrays que se van a comparar. Ejemplo: [ \@array1, \@array2 ].
  • Una referencia a un hash que contiene una clave "lists" cuyo valor es el array anónimo de referencias a arrays de entrada. Ejemplo: { lists => [ \@array1, \@array2 ] }. Esto es especialmente útil cuando se pasan argumentos adicionales a las funciones, como el argumento item para is_member_which.

Las comparaciones se basan en la igualdad de elementos. Por defecto, los elementos se comparan usando el operador eq (igualdad de cadenas). Si necesitas comparar elementos numéricamente o usando alguna otra medida de igualdad personalizada, deberás normalizar tus listas antes de pasarlas a estas funciones o usar un módulo de comparación diferente.

El módulo maneja de forma eficiente las listas duplicadas. Por ejemplo, en get_intersection(), si un elemento aparece dos veces en la lista izquierda y tres veces en la derecha, solo aparecerá una vez en el resultado.

SUBRUTINAS

Las subrutinas disponibles se agrupan por su funcionalidad principal. Para obtener una lista completa, consulta la sección de Tags de Exportación.

Funciones de Conjuntos Básicos

get_intersection
Devuelve una lista de elementos que aparecen en *todas* las listas de entrada.
get_union
Devuelve una lista de elementos que aparecen en *al menos una* de las listas de entrada.
get_unique
Devuelve una lista de elementos que aparecen *solo* en la primera lista de entrada (la lista 'L').
get_complement
Devuelve una lista de elementos que aparecen *solo* en la segunda lista de entrada (la lista 'R').
get_symmetric_difference, get_symdiff
Devuelve una lista de elementos que aparecen en la primera lista ('L') O en la segunda lista ('R'), pero no en ambas.
get_bag
Devuelve una lista que contiene todos los elementos de todas las listas de entrada, preservando las duplicaciones.

Funciones de Relación de Conjuntos

is_LsubsetR
Devuelve verdadero (1) si todos los elementos de la lista 'L' también están presentes en la lista 'R'. Falso (0) en caso contrario.
is_RsubsetL
Devuelve verdadero (1) si todos los elementos de la lista 'R' también están presentes en la lista 'L'. Falso (0) en caso contrario.
is_LequivalentR, is_LeqvlntR
Devuelve verdadero (1) si las listas 'L' y 'R' contienen exactamente los mismos elementos (sin importar el orden o las duplicaciones dentro de cada lista). Falso (0) en caso contrario.
is_LdisjointR
Devuelve verdadero (1) si las listas 'L' y 'R' no tienen ningún elemento en común. Falso (0) en caso contrario.

Funciones de Referencia de Retorno

Cada una de las funciones de conjunto y relación anteriores tiene una contraparte que termina en _ref. Estas funciones devuelven una referencia a un array anónimo que contiene el resultado, en lugar del array en sí. Esto puede ser útil para la eficiencia si el array resultante es muy grande.

get_intersection_ref
Igual que get_intersection, pero devuelve una referencia al array resultante.
get_union_ref
Igual que get_union, pero devuelve una referencia al array resultante.
get_unique_ref
Igual que get_unique, pero devuelve una referencia al array resultante.
get_complement_ref
Igual que get_complement, pero devuelve una referencia al array resultante.
get_symmetric_difference_ref, get_symdiff_ref
Igual que get_symmetric_difference, pero devuelve una referencia al array resultante.
get_bag_ref
Igual que get_bag, pero devuelve una referencia al array resultante.
is_LsubsetR_ref
Igual que is_LsubsetR, pero devuelve una referencia a un array que contiene el valor booleano.
is_RsubsetL_ref
Igual que is_RsubsetL, pero devuelve una referencia a un array que contiene el valor booleano.
is_LequivalentR_ref, is_LeqvlntR_ref
Igual que is_LequivalentR, pero devuelve una referencia a un array que contiene el valor booleano.
is_LdisjointR_ref
Igual que is_LdisjointR, pero devuelve una referencia a un array que contiene el valor booleano.

Funciones de Gráficos

print_subset_chart
Imprime una tabla formateada que muestra la relación de subconjunto entre las listas de entrada. Útil para visualizar las relaciones.
print_equivalence_chart
Imprime una tabla formateada que muestra si las listas de entrada son equivalentes entre sí.

Funciones de Análisis Avanzado

is_member_which
Toma una lista de listas y un elemento, y devuelve un array de índices que indican en qué listas de entrada se encuentra el elemento.
is_member_which_ref
Igual que is_member_which, pero devuelve una referencia al array de índices.
get_item_memberships
Generalización de is_member_which para comparar un elemento contra múltiples listas. Devuelve una lista de índices de las listas que contienen el elemento.
get_all_uniques
Para tres o más listas, devuelve una lista de arrays. Cada array interno contiene los elementos que son únicos en la lista de entrada correspondiente.
get_element_map
Para tres o más listas, devuelve un hash donde las claves son los elementos y los valores son arrays de índices que indican en qué listas de entrada aparece cada elemento.

CAMBIO DE INTERFAZ DE ABRIL DE 2004

Antes de la versión 0.25 de List::Compare::Functional (publicada en abril de 2004), el módulo funcionaba de manera diferente. Los cambios principales fueron:

  • Uso de referencias a arrays anónimos para pasar las listas: Antes, las listas se pasaban como argumentos separados. Ahora, se espera una referencia a un array anónimo que contenga referencias a los arrays que se van a comparar.
  • Introducción del argumento de hash: A partir de la versión 0.29, las funciones también aceptan una referencia de hash para pasar las listas y otros argumentos opcionales.
  • Introducción de funciones "_ref": Se agregaron nuevas funciones que devuelven referencias a arrays en lugar de arrays completos para mejorar la eficiencia en ciertos casos.
  • Introducción de funciones para 3+ listas: Se agregaron funciones específicas para manejar comparaciones de más de dos listas, como get_item_memberships, get_all_uniques y get_element_map.

Si tienes código antiguo que utiliza versiones anteriores a la 0.25, deberás actualizarlo para que coincida con la nueva interfaz. La documentación anterior a abril de 2004 ya no es válida.

    @Lonly = get_unique( [ \@Al, \@Bob, \@Carmen, \@Don, \@Ed ], [ 0 ] );

    • Comparando Listas en Seen-Hashes

    ¿Qué es un seen-hash? Un seen-hash es una implementación típica de Perl de una tabla de búsqueda: un hash donde el valor para un elemento dado representa el número de veces que se observa la clave del elemento en una lista. Para los propósitos de List::Compare::Functional, lo crucial es si un elemento se observa o no en una lista; cuántas veces aparece el elemento en una lista es, *con una excepción*, irrelevante. (Esa excepción es la función get_bag() y su gemela get_bag_ref(). En este caso únicamente, la clave de cada elemento del seen-hash se coloca en la bolsa tantas veces como lo indique el valor de ese elemento). El valor de un elemento en un seen-hash de List::Compare debe ser un entero positivo, pero si ese entero es 1 o 1,000,001 es irrelevante para todas las funciones de List::Compare::Functional *excepto* para la formación de una bolsa.

    Las dos listas comparadas anteriormente estaban representadas por matrices; se pasaron referencias a esas matrices a las diversas funciones de List::Compare::Functional. Sin embargo, también podrían haber sido representadas por seen-hashes como los siguientes y pasadas exactamente de la misma manera a las diversas funciones.

    %Llist = (
    abel   => 2,
    baker  => 1,
    camera => 1,
    delta  => 1,
    edward => 1,
    fargo  => 1,
    golfer => 1,
);
%Rlist = (
    baker  => 1,
    camera => 1,
    delta  => 2,
    edward => 1,
    fargo  => 1,
    golfer => 1,
    hilton => 1,
);
@intersection = get_intersection( [ \%Llist, \%Rlist ] );
@union        = get_union(        [ \%Llist, \%Rlist ] );
@complement   = get_complement(   [ \%Llist, \%Rlist ] );

    y así sucesivamente.

    Para comparar tres o más listas simultáneamente, proporcione a la función List::Compare::Functional apropiada una referencia de matriz que contenga una lista de tres o más referencias a seen-hashes. Por lo tanto,

    @union = get_intersection( [ \%Alpha, \%Beta, \%Gamma ] );

    El formato de 'hashref único' para las funciones de List::Compare::Functional también está disponible al pasar seen-hashes como argumentos. Ejemplos:

    lists => [ \%Alpha, \%Beta, \%Gamma ],
} );

    Resultados más rápidos con la opción Unsorted

    Por defecto, las funciones de List::Compare::Function devuelven listas ordenadas en el modo ASCII-betical por defecto de Perl. La ordenación implica un coste de rendimiento, y si no necesita una lista ordenada y no desea pagar este coste de rendimiento, puede llamar a las siguientes funciones de List::Compare::Function con la opción 'unsorted':

    @intersection = get_intersection(        '-u',  [ \@Llist, \@Rlist ] );
@union        = get_union(               '-u',  [ \@Llist, \@Rlist ] );
@Lonly        = get_unique(              '-u',  [ \@Llist, \@Rlist ] );
@Ronly        = get_complement(          '-u',  [ \@Llist, \@Rlist ] );
@LorRonly     = get_symmetric_difference('-u',  [ \@Llist, \@Rlist ] );
@bag          = get_bag(                 '-u',  [ \@Llist, \@Rlist ] );

    Para una mayor legibilidad, la opción se puede escribir:

    @intersection = get_intersection('--unsorted',  [ \@Llist, \@Rlist ] );

    o

    @intersection = get_intersection( {
    unsorted => 1,
    lists    => [ \@Llist, \@Rlist ],
} );

    Si necesita una referencia a una lista no ordenada como valor de retorno, puede llamar a la opción no ordenada de la siguiente manera:

    $intersection_ref = get_intersection_ref(
                        '-u',         [ \@Llist, \@Rlist ] );
$intersection_ref = get_intersection_ref(
                        '--unsorted', [ \@Llist, \@Rlist ] );

    Comentarios Generales

    List::Compare::Functional es una implementación no orientada a objetos de código Perl muy común utilizada para determinar relaciones interesantes entre dos o más listas a la vez. List::Compare::Functional se basa en List::Compare del mismo autor, que se encuentra en la misma distribución de CPAN. List::Compare::Functional está estrechamente modelado según el modo ''Acelerado'' en List::Compare.

    @to_be_compared = (\@Llist, \@Rlist);
@opts = ( 'abel' );
@memb_arr = is_member_which( \@to_be_compared, \@opts );

    Como en versiones anteriores, para mejorar la velocidad, el usuario puede proporcionar la opción '-u' o '--unsorted' como el primer argumento a algunas funciones de List::Compare::Funcional. Usando esta opción, la función get_intersection() anterior aparecería así:

    @intersection = get_intersection( '-u', [ \@Llist, \@Rlist ] );

    O alternativamente:

    @intersection = get_intersection( '--unsorted', [ \@Llist, \@Rlist ] );

    Los argumentos de cualquier función de List::Compare::Funcional serán posiblemente la opción '-u', seguida de una o dos referencias a arrays, la primera de las cuales es una referencia a un array de arrays o un array de hashes visible.
