NOMBRE

Locale::Po4a::Guide - convierte documentos XML de Guía desde/hacia archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y de forma más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::Guide es un módulo para ayudar en la traducción de la documentación de Gentoo Linux en formato XML de Guía a otros idiomas [humanos].

Este formato se documenta aquí: http://www.gentoo.org/doc/en/xml-guide.xml

ESTADO DE ESTE MÓDULO

Este módulo es totalmente funcional, ya que se basa en el módulo Locale::Po4a::Xml. Este solo define las etiquetas y atributos traducibles.

El único problema conocido es que no incluye archivos con la etiqueta <include href="...">, pero puedes traducir todos esos archivos por separado, y normalmente es mejor tenerlos separados.

VER TAMBIÉN
