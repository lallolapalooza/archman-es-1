Operaciones de lista.

Algunas funciones son marcadas como no recursivas tail. Una función tail-recursive usa espacio de pila constante, mientras que una función no tail-recursive usa espacio de pila proporcional al tamaño de la lista de entrada, lo cual puede ser un problema con listas muy largas. Cuando se pasan varios argumentos de lista, se muestra una fórmula aproximada que da el uso de pila (en algún unidad constante especificada).

Las consideraciones anteriores suelen poder ignorarse si tus listas no son más de unos 10000 elementos.

La versión etiquetada de este modulo puede usarse como se describe en el modulo StdLabels.

tipo 'a t = 'a list =
| []
| (::) de 'a * 'a list

Un alias para el tipo de listas.

val length : 'a list -> int

Devuelve el largo (número de elementos) de la lista dada.

val compare_lengths : 'a list -> 'b list -> int

Compara los largos de dos listas. compare_lengths l1 l2 es equivalente a compare (length l1) (length l2), excepto que el cálculo detiene después de alcanzar el final de la lista más corta.

Since 4.05

val compare_length_with : 'a list -> int -> int

Compara el largo de una lista con un entero. compare_length_with l len es equivalente a compare (length l) len, excepto que el cálculo detiene después de hasta len iteraciones en la lista.

Since 4.05

val is_empty : 'a list -> bool

is_empty l es verdadero si y solo si l no tiene elementos. Es equivalente a compare_length_with l 0 = 0 .

Since 5.1

val cons : 'a -> 'a list -> 'a list

cons x xs es x :: xs

Since 4.03 (4.05 en ListLabels)

val singleton : 'a -> 'a list

singleton x devuelve la lista de un elemento [x].

Since 5.4

val hd : 'a list -> 'a

Devuelve el primer elemento de la lista dada.

Raises Failure si la lista está vacía.

val tl : 'a list -> 'a list

Devuelve la lista dada sin su primer elemento.

Raises Failure si la lista está vacía.

val nth : 'a list -> int -> 'a

Devuelve el n-ésimo elemento de la lista dada. El primer elemento (cabeza de la lista) está en la posición 0.

Raises Failure si la lista es demasiado corta.

Raises Invalid_argument si n es negativo.

val nth_opt : 'a list -> int -> 'a option

Devuelve el n-ésimo elemento de la lista dada. El primer elemento (cabeza de la lista) está en la posición 0. Devuelve None si la lista es demasiado corta.

Since 4.05

Raises Invalid_argument si n es negativo.

val rev : 'a list -> 'a list

Invierte la lista.

val init : int -> (int -> 'a) -> 'a list

init len f es [f 0; f 1; ...; f (len-1)], evaluada de izquierda a derecha.

Since 4.06

Raises Invalid_argument si len < 0 .

val append : 'a list -> 'a list -> 'a list

append l0 l1 añade l1 a l0. Función equivalente al operador infix @.

Since 5.1 esta función es tail-recursive.

val rev_append : 'a list -> 'a list -> 'a list

rev_append l1 l2 invierte l1 y la concatenación con l2. Es equivalente a (List.rev l1) @ l2 .

val concat : 'a list list -> 'a list

Concatena una lista de listas. Los elementos de la entrada son concatenados (en el mismo orden) para dar el resultado. No es tail-recursive (longitud de la entrada + longitud de la sub-lista más larga).

val flatten : 'a list list -> 'a list

Es equivalente a List.concat. No es tail-recursive (longitud de la entrada + longitud de la sub-lista más larga).

Comparación

val equal : ('a -> 'a -> bool) -> 'a list -> 'a list -> bool

equal eq [a1; ...; an] [b1; ..; bm] se cumple cuando las dos listas de entrada tienen el mismo tamaño, y para cada par de elementos ai y bi en la misma posición tenemos eq ai bi .

Nota: el eq puede ser llamado incluso si las listas tienen diferentes longitudes. Si sabes que tu función de igualdad es costosa, podría ser útil comprobar List.compare_lengths primero.

Since 4.12

val compare : ('a -> 'a -> int) -> 'a list -> 'a list -> int

compare cmp [a1; ...; an] [b1; ...; bm] compara de forma lexicográfica las dos listas de entrada, usando la misma interfaz 'a -> 'a -> int que compare :

- a1 :: l1 es menor que a2 :: l2 (resultado negativo) si a1 es menor que a2, o si son iguales (resultado 0) y l1 es menor que l2. - La lista vacía [] es menor que listas no vacías.

Nota: el cmp se llamará incluso si las listas tienen longitudes diferentes.

Since 4.12

Iteradores

val iter : ('a -> unit) -> 'a list -> unit

iter f [a1; ...; an] aplica la función f a cada elemento de la lista [a1; ...; an]. Es equivalente a f a1; f a2; ...; f an .

val iteri : (int -> 'a -> unit) -> 'a list -> unit

Es equivalente a List.iter, pero la función se aplica al índice del elemento como primer argumento (comenzando en 0), y al elemento como segundo argumento.

Since 4.00

val map : ('a -> 'b) -> 'a list -> 'b list

map f [a1; ...; an] aplica la función f a cada elemento de la lista [a1; ...; an], y construye la lista [f a1; ...; f an] con los resultados obtenidos de f .

val mapi : (int -> 'a -> 'b) -> 'a list -> 'b list

Es equivalente a List.map, pero la función se aplica al índice del elemento como primer argumento (comenzando en 0), y al elemento como segundo argumento.

Since 4.00

val rev_map : ('a -> 'b) -> 'a list -> 'b list

rev_map f l da el mismo resultado que List.rev (List.map f l), pero es más eficiente.

val filter_map : ('a -> 'b option) -> 'a list -> 'b list

filter_map f l aplica f a cada elemento de l, filtra los elementos None y devuelve la lista de los argumentos de los elementos Some .

Since 4.08

val concat_map : ('a -> 'b list) -> 'a list -> 'b list

concat_map f l da el mismo resultado que List.concat (List.map f l), y es tail-recursive.

Since 4.10

val fold_left_map : ('acc -> 'a -> 'acc * 'b) -> 'acc -> 'a list -> 'acc * 'b list

fold_left_map combina fold_left y map para pasar un acumulador por las llamadas a f .

Since 4.11

val fold_left : ('acc -> 'a -> 'acc) -> 'acc -> 'a list -> 'acc

fold_left f init [b1; ...; bn] es f (... (f (f init b1) b2) ...) bn .

val fold_right : ('a -> 'acc -> 'acc) -> 'a list -> 'acc -> 'acc

fold_right f [a1; ...; an] init es f a1 (f a2 (... (f an init) ...)) . No es tail-recursive.

List - OCaml Standard Library

List

module List : sig ... end

Built-in list functions.

Note: The functions described in this section only work on lists of finite length. For instance, List.iter on the infinite list let rec from = function x -> x :: from (x+1) in from 0 will loop forever.

Combining lists

val iter2 : ('a -> 'b -> unit) -> 'a list -> 'b list -> unit

iter2 f [a1; ...; an] [b1; ...; bn] calls in turn f a1 b1; ...; f an bn .

Raises Invalid_argument if the two lists are determined to have different lengths.

val map2 : ('a -> 'b -> 'c) -> 'a list -> 'b list -> 'c list

map2 f [a1; ...; an] [b1; ...; bn] is [f a1 b1; ...; f an bn] .

Raises Invalid_argument if the two lists are determined to have different lengths.

val rev_map2 : ('a -> 'b -> 'c) -> 'a list -> 'b list -> 'c list

rev_map2 f l1 l2 gives the same result as List.rev ( List.map2 f l1 l2) , but is more efficient.

val fold_left2 : ('acc -> 'a -> 'b -> 'acc) -> 'acc -> 'a list -> 'b list -> 'acc

fold_left2 f init [a1; ...; an] [b1; ...; bn] is f (... (f (f init a1 b1) a2 b2) ...) an bn .

Raises Invalid_argument if the two lists are determined to have different lengths.

val fold_right2 : ('a -> 'b -> 'acc -> 'acc) -> 'a list -> 'b list -> 'acc -> 'acc

fold_right2 f [a1; ...; an] [b1; ...; bn] init is f a1 b1 (f a2 b2 (... (f an bn init) ...)) .

Raises Invalid_argument if the two lists are determined to have different lengths. Not tail-recursive.

List scanning

val for_all : ('a -> bool) -> 'a list -> bool

for_all f [a1; ...; an] checks if all elements of the list satisfy the predicate f . That is, it returns (f a1) && (f a2) && ... && (f an) for a non-empty list and true if the list is empty.

val exists : ('a -> bool) -> 'a list -> bool

exists f [a1; ...; an] checks if at least one element of the list satisfies the predicate f . That is, it returns (f a1) || (f a2) || ... || (f an) for a non-empty list and false if the list is empty.

val for_all2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Same as List.for_all , but for a two-argument predicate.

Raises Invalid_argument if the two lists are determined to have different lengths.

val exists2 : ('a -> 'b -> bool) -> 'a list -> 'b list -> bool

Same as List.exists , but for a two-argument predicate.

Raises Invalid_argument if the two lists are determined to have different lengths.

val mem : 'a -> 'a list -> bool

mem a set is true if and only if a is equal to an element of set .

val memq : 'a -> 'a list -> bool

Same as List.mem , but uses physical equality instead of structural equality to compare list elements.

List searching

val find : ('a -> bool) -> 'a list -> 'a

find f l returns the first element of the list l that satisfies the predicate f .

Raises Not_found if there is no value that satisfies f in the list l .

val find_opt : ('a -> bool) -> 'a list -> 'a option

find f l returns the first element of the list l that satisfies the predicate f . Returns None if there is no value that satisfies f in the list l .

Since 4.05

val find_index : ('a -> bool) -> 'a list -> int option

find_index f xs returns Some i , where i is the index of the first element of the list xs that satisfies f x , if there is such an element.

It returns None if there is no such element.

Since 5.1

val find_map : ('a -> 'b option) -> 'a list -> 'b option

find_map f l applies f to the elements of l in order, and returns the first result of the form Some v , or None if none exist.

Since 4.10

val find_mapi : (int -> 'a -> 'b option) -> 'a list -> 'b option

Same as find_map , but the predicate is applied to the index of the element as first argument (counting from 0), and the element itself as second argument.

Since 5.1

val filter : ('a -> bool) -> 'a list -> 'a list

filter f l returns all the elements of the list l that satisfy the predicate f . The order of the elements in the input list is preserved.

val find_all : ('a -> bool) -> 'a list -> 'a list

find_all is another name for List.filter .

val filteri : (int -> 'a -> bool) -> 'a list -> 'a list

Same as List.filter , but the predicate is applied to the index of the element as first argument (counting from 0), and the element itself as second argument.

Since 4.11

List manipulation

val take : int -> 'a list -> 'a list

take n l returns the prefix of l of length n , or a copy of l if n > length l . This is the empty list if n is negative.

Warning. In version 5.3 only, this function raises Invalid_argument for negative n values.

Since 5.3

val drop : int -> 'a list -> 'a list

drop n l returns the suffix of l after n elements, or [] if n > length l . This is l if n is negative.

Warning. In version 5.3 only, this function raises Invalid_argument for negative n values.

Since 5.3

val take_while : ('a -> bool) -> 'a list -> 'a list

take_while p l is the longest (possibly empty) prefix of l containing only elements that satisfy p .

Since 5.3

val drop_while : ('a -> bool) -> 'a list -> 'a list

drop_while p l is the longest (possibly empty) suffix of l starting at the first element that does not satisfy p .

Since 5.3

val partition : ('a -> bool) -> 'a list -> 'a list * 'a list

partition f l returns a pair of lists (l1, l2) , where l1 is the list of all the elements of l that satisfy the predicate f , and l2 is the list of all the elements of l that do not satisfy f . The order of the elements in the input list is preserved.

val partition_map : ('a -> ('b, 'c) Either.t) -> 'a list -> 'b list * 'c list

partition_map f l returns a pair of lists (l1, l2) such that, for each element x of the input list l :

-if f x is Left y1 , then y1 is in l1 , and

-if f x is Right y2 , then y2 is in l2 .

The output elements are included in l1 and l2 in the same relative order as the corresponding input elements in l .

In particular, partition_map (fun x -> if f x then Left x else Right x) l is equivalent to partition f l .

Since 4.12

Association lists

val assoc : 'a -> ('a * 'b) list -> 'b

assoc a l returns the value associated with key a in the list of pairs l . That is, assoc a [ ...; (a,b); ...] = b if (a,b) is the leftmost binding of a in list l .

Raises Not_found if there is no value associated with a in the list l .

val assoc_opt : 'a -> ('a * 'b) list -> 'b option

assoc_opt a l returns the value associated with key a in the list of pairs l . That is, assoc_opt a [ ...; (a,b); ...] = Some b if (a,b) is the leftmost binding of a in list l . Returns None if there is no value associated with a in the list l .

Since 4.05

val assq : 'a -> ('a * 'b) list -> 'b

Same as List.assoc , but uses physical equality instead of structural equality to compare keys.

val assq_opt : 'a -> ('a * 'b) list -> 'b option

Same as List.assoc_opt , but uses physical equality instead of structural equality to compare keys.

Since 4.05

val mem_assoc : 'a -> ('a * 'b) list -> bool

Same as List.assoc , but simply return true if a binding exists, and false if no bindings exist for the given key.

val mem_assq : 'a -> ('a * 'b) list -> bool

Same as List.mem_assoc , but uses physical equality instead of structural equality to compare keys.

val remove_assoc : 'a -> ('a * 'b) list -> ('a * 'b) list

remove_assoc a l returns the list of pairs l without the first pair with key a , if any. Not tail-recursive.

val remove_assq : 'a -> ('a * 'b) list -> ('a * 'b) list

Same as List.remove_assoc , but uses physical equality instead of structural equality to compare keys. Not tail-recursive.

Lists of pairs

val split : ('a * 'b) list -> 'a list * 'b list

Transform a list of pairs into a pair of lists: split [(a1,b1); ...; (an,bn)] is ([a1; ...; an], [b1; ...; bn]) . Not tail-recursive.

val combine : 'a list -> 'b list -> ('a * 'b) list

Transform a pair of lists into a list of pairs: combine [a1; ...; an] [b1; ...; bn] is [(a1,b1); ...; (an,bn)] . Invalid_argument is raised if the two lists have different lengths.

Clasificación

val sort : ('a -> 'a -> int) -> 'a list -> 'a list

Clasifica una lista en orden ascendente según una función de comparación. La función de comparación debe devolver 0 si sus argumentos se comparan como iguales, un entero positivo si el primero es mayor y un entero negativo si el primero es menor (ver Array.sort para una especificación completa). Por ejemplo, compare es una función de comparación adecuada. La lista resultante está clasificada en orden ascendente. Se garantiza que List.sort se ejecuta en espacio de heap constante (además del tamaño de la lista de resultados) y espacio de pila logarítmico.

La implementación actual utiliza Merge Sort. Se ejecuta en espacio de heap constante y espacio de pila logarítmico.

val stable_sort : ('a -> 'a -> int) -> 'a list -> 'a list

Igual que List.sort, pero se garantiza que el algoritmo de clasificación es estable (es decir, los elementos que se comparan como iguales se mantienen en su orden original).

La implementación actual utiliza Merge Sort. Se ejecuta en espacio de heap constante y espacio de pila logarítmico.

val fast_sort : ('a -> 'a -> int) -> 'a list -> 'a list

Igual que List.sort o List.stable_sort, el que sea más rápido en entradas típicas.

val sort_uniq : ('a -> 'a -> int) -> 'a list -> 'a list

Igual que List.sort, pero también elimina duplicados: si varios elementos se comparan como iguales, se conserva solo el primero.

Antes de 5.4, el elemento conservado no era necesariamente el primero.

Desde 4.02 (4.03 en ListLabels)

val merge : ('a -> 'a -> int) -> 'a list -> 'a list -> 'a list

Fusiona dos listas: Suponiendo que l1 y l2 están ordenadas según la función de comparación cmp, merge cmp l1 l2 devolverá una lista ordenada que contiene todos los elementos de l1 y l2. Si varios elementos se comparan como iguales, los elementos de l1 estarán antes que los elementos de l2. No es recursiva de cola (suma de las longitudes de los argumentos).
