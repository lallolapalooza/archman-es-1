Locale::Maketext::Lexicon::Auto(3) Documentación de Perl contribuida por el usuario Locale::Maketext::Lexicon::Auto(3)

NOMBRE

Locale::Maketext::Lexicon::Auto - Léxico de respaldo automático para Maketext

VERSIÓN

versión 1.00

SINOPSIS

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    en => ['Auto'],
    # ... otros idiomas
};

DESCRIPCIÓN

Este módulo construye un hash de Léxico simple que no contiene nada más que "( '_AUTO' => 1)", lo que le dice a "Locale::Maketext" que no se necesita localización; simplemente usa la clave de búsqueda como la cadena devuelta.

Es especialmente útil si estás empezando a prototipar un programa y aún no quieres lidiar con los archivos de localización.

ADVERTENCIAS

Si la clave para "->maketext" comienza con un "_", "Locale::Maketext" seguirá lanzando una excepción. Ver "CONTROL DEL FALLO DE BÚSQUEDA" en Locale::Maketext para saber cómo evitarlo.

VER TAMBIÉN

Locale::Maketext, Locale::Maketext::Lexicon
