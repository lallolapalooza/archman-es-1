NOMBRE

Lire::ReportOperator - Clase base para todos los operadores que se pueden usar para computar informes

SINOPSIS

print $op->name(), "\n";
print $op->op(), "\n";
print $op->label(), "\n";

DESCRIPCIÓN

Lire::ReportOperator es la clase base para todos los operadores que se pueden utilizar para computar los datos que aparecen en los informes de Lire. Esta clase solo proporciona el comportamiento común a todos los operadores.

Actualmente, los operadores definidos en Lire se presentan en dos variedades principales: primero, están los agregadores, que son operadores que pueden dividir registros DLF en múltiples grupos; segundo, están los operadores de grupo, que pueden computar datos basados en un grupo de registros DLF. Los agregadores son subclases de Lire::Aggregator y las operaciones de grupo son subclases de Lire::Aggregate.

MÉTODOS

op()

Devuelve el nombre del elemento XML que se refiere a este operador.

report_spec()

Devuelve el objeto Lire::ReportSpec en el que se encuentra este operador.

parent()

Devuelve el padre de este operador. Esto será indefinido para el agregador de nivel superior en la especificación del informe. Solo Lire::Aggregator puede tener hijos y, por lo tanto, ser un padre.

last_parent()

Devuelve nuestro padre de nivel superior.

name( [$new_name] )

Devuelve el nombre de este operador en la especificación del informe actual. El nombre del operador es un identificador que debe ser único en una determinada especificación de informe. Este nombre se utilizará para identificar los valores generados por este operador en el informe generado.

Si se establece $new_name, el nombre de este operador se cambiará a este nuevo valor.

has_label()

Devuelve verdadero si a este operador se le ha asignado una etiqueta explícita.

label( [$new_label] )

Devuelve lo que debería usarse como etiqueta de columna para los datos generados por este operador.

Si se establece el segundo argumento, la etiqueta de la columna se establecerá a este nuevo valor.

MÉTODOS PARA SUBCLASES

Las subclases deben usar un hash para representar los datos de su instancia. Deben llamar a init() desde su método constructor.

init( %params )

Lire::Report es una clase abstracta que no debe ser instanciada directamente. Las subclases deben llamar al método init() en su constructor. Este método inicializa los atributos comunes a todos los operadores. Las claves %params que deben definirse son:

op
El tipo de operador. Este es el nombre del elemento XML. Es un parámetro obligatorio.
parent
El padre de este operador. Debe estar presente a menos que el elemento sea el agregador de nivel superior.
report_spec
La especificación del informe a la que se añade este operador.
label
La etiqueta de este operador. Es información opcional.

Este método devuelve el objeto.

print( $fh, $prefix )

Este es el método que se llama para escribir una representación XML de este operador.

$fh es el manejador de archivo en el que se debe volcar la representación XML. $indent es un entero que indica el número de espacios que deben usarse como indentación al escribir el XML.

build_query( $query )

API DE FUSIÓN

Los métodos deben implementarse para admitir la fusión de datos generados por este operador a partir de dos informes.

init_merge()

Este método se llama una vez antes de que comience la fusión de informes XML.

end_merge()

Este método se llama una vez después de que se hayan fusionado todos los informes XML.

init_group_data()

Este método debe devolver una estructura de datos que se pasará a la llamada a update_group_data() y merge_group_data(). Habrá una estructura de datos de este tipo por cada grupo que exista en el agregador que contenga este operador.

Hay algunas restricciones sobre esta estructura de datos para garantizar que pueda ser ordenada por el agregador que necesite ordenar sus entradas. Si la estructura de datos es

ESCALAR
Ese valor puede usarse para fines de ordenación.
REFERENCIA ESCALAR
El valor escalar se usará como clave de ordenación.
REFERENCIA DE ARRAY
El primer elemento en la referencia del array se usará como clave de ordenación.
REFERENCIA HASH
Los elementos "sort_value" en el hash se usarán como clave de ordenación.
REFERENCIA DE OBJETO
El valor devuelto por el método sort_value() se usará como clave de ordenación.

Se puede utilizar una función group_data_value() para extraer el valor de la clave de ordenación según estas reglas. Se puede importar:

use Lire::ReportOperator qw/group_data_value/;
my $v = group_data_value( $data );

merge_group_data( $value, $data )

Este método se llamará una vez por cada valor generado por este operador en los informes XML a fusionar.

El parámetro $value puede ser una referencia hash o un objeto Lire::Report::Group. Serán las mismas cosas que se generaron por este operador.

$data es la estructura de datos de grupo devuelta por init_group_data() para el grupo donde se debe fusionar este $value.

end_group_data( $data )

Este método se llamará una vez por cada grupo que fue creado por el agregador que contiene este operador. El parámetro $data es la estructura de datos que fue devuelta por init_group_data() para el grupo actual.

Un uso posible de este método sería, por ejemplo, para que el operador de promedio calcule el promedio real, ya que no se puede hacer hasta que se procesen todos los registros.

add_entry_value( $entry, $data )

Este método se llamará una vez por cada grupo creado por el agregador. En este método, el operador debe agregar el nombre y/o valor apropiado para esta entrada. $entry es el objeto Lire::Report::Entry al que se deben agregar los nombres y/o valores. $data es la estructura de datos devuelta por init_group_data() correspondiente al grupo actual.

Por ejemplo, es en este método donde el operador de suma agregará el valor que contiene la suma para la entrada actual.

group_data_value($data)

Devuelve el "valor" de un elemento de datos creado por un método init_group_data(). Esta es una función, no un método.
