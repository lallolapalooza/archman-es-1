NAME

Locale::RecodeData::CSN_369103 - Rutinas de conversión para CSN_369103

SYNOPSIS

Este módulo es interno a libintl. No lo use directamente!

DESCRIPTION

Este módulo está generado y contiene las tablas de conversión y rutinas para CSN_369103.

COMMENTS

Los comentarios siguientes se han extraído del original charmap:

version: 1.0
repertoiremap: mnemonic,ds
 source: ECMA registry
alias ISO-IR-139

Nota: los alias mencionados arriba no son necesariamente válidos!
