NOMBRE

Log::Message::Config - Opciones de configuración para Log::Message

SINOPSIS

# Este módulo es usado implícitamente por Log::Message para crear una configuración
# que usa para registrar mensajes.
# Para las opciones que puedes pasar, consulta el método C<Log::Message new()>.
# Abajo hay un ejemplo de un archivo de configuración que podrías usar
# los comentarios se denotan con un solo '#'
# ¿usar una pila compartida o tener una instancia privada?
# si no se proporciona ninguna, se establece en '0',
private = 1
# no ser verboso
verbose = 0
# etiqueta predeterminada para establecer en los nuevos elementos
# si no se proporciona ninguna, se establece en 'NONE'
tag = ETIQUETA_ALGUNA
# nivel predeterminado para manejar elementos
# si no se proporciona ninguno, se establece en 'log'
level = carp
# archivos adicionales para incluir
# si no se proporciona ninguno, no se incluyen archivos automáticamente
include = mylib.pl
include = ../my/other/lib.pl
# eliminar automáticamente los elementos
# cuando los recuperas de la pila?
# si no se proporciona ninguno, se establece en '0'
remove = 1
# recuperar errores en orden cronológico, ¿o no?
# si no se proporciona ninguno, se establece en '1'
chrono = 0

DESCRIPCIÓN

Log::Message::Config proporciona un objeto de configuración estandarizado para objetos Log::Message.

Puede leer opciones como argumentos de Perl, o como un archivo de configuración. Consulta la página del manual de Log::Message para obtener más información sobre qué argumentos son válidos, y consulta la Sinopsis para ver un ejemplo de archivo de configuración que puedes usar.

VER TAMBIÉN

Log::Message, Log::Message::Item, Log::Message::Handlers
