NOMBRE

Log::Log4perl::Config::Watch - Detectar cambios en archivos

SINOPSIS

use Log::Log4perl::Config::Watch;
my $watcher = Log::Log4perl::Config::Watch->new(
                      file            => "/data/my.conf",
                      check_interval  => 30,
              );
while(1) {
    if($watcher->change_detected()) {
        print "¡Cambio detectado!\n";
    }
    sleep(1);
}

DESCRIPCIÓN

Este módulo ayuda a detectar cambios en archivos. Aunque viene con la distribución "Log::Log4perl", puede usarse independientemente.

El constructor define el archivo a vigilar y el intervalo de verificación en segundos. Las llamadas posteriores a change_detected():

  • devolverán un valor falso inmediatamente sin realizar comprobaciones físicas del archivo si no ha transcurrido el "check_interval".
  • realizarán una prueba física en el archivo especificado si han transcurrido los segundos especificados en "check_interval" desde la última prueba física. Si la fecha de modificación del archivo ha cambiado desde la última prueba física, devolverá un valor verdadero, de lo contrario, se devolverá un valor falso.

En resumen: "check_interval" te permite llamar a la función change_detected() tan a menudo como quieras, sin incurrir en una penalización de rendimiento significativa porque se estén realizando operaciones del sistema de archivos (sin embargo, pagas el precio de no conocer los cambios en el archivo hasta que hayan transcurrido "check_interval" segundos).

El módulo distingue claramente el tiempo del sistema del tiempo del sistema de archivos. Si tu sistema de archivos (por ejemplo, montado en NFS) tiene una diferencia constante de tiempo en comparación con el reloj del ordenador que ejecuta el código, funcionará correctamente.

Para deshabilitar la función de retraso de ahorro de recursos, simplemente establece "check_interval" a 0 y change_detected() realizará una prueba física del archivo en cada llamada.

Si ya dispones de la hora actual, puedes pasarla a change_detected() como un parámetro opcional, como en

change_detected($time)

que entonces no activará una llamada a time(), sino que utilizará el valor proporcionado.

MODO SEÑAL

En lugar de verificar periódicamente el tiempo y los cambios en los archivos, se puede indicar a new() que configure un manejador de señales. Si llamas al constructor así:

my $watcher = Log::Log4perl::Config::Watch->new(
                      file    => "/data/my.conf",
                      signal  => 'HUP'
              );

entonces se instalará un manejador de señales, que establecerá la variable del objeto "$self->{signal_caught}" a un valor verdadero cuando llegue la señal. Viene con todos los problemas que conllevan los manejadores de señales.

VERIFICACIONES DE DISPARO

Para disparar una verificación física del archivo en la próxima llamada a change_detected() independientemente de si ha expirado el "check_interval" o no, llama a

$watcher->force_next_check();

en el objeto watcher.

DETECTAR ARCHIVOS MOVIDOS

El watcher también se puede usar para detectar archivos que se han movido. No solo detectará si un archivo vigilado ha desaparecido, sino también si ha sido reemplazado por un archivo nuevo en el ínterin.

my $watcher = Log::Log4perl::Config::Watch->new(
    file           => "/data/my.conf",
    check_interval => 30,
);
while(1) {
    if($watcher->file_has_moved()) {
        print "¡El archivo se ha movido!\n";
    }
    sleep(1);
}

Los parámetros "check_interval" y "signal" limitan el número de verificaciones físicas del sistema de archivos, de manera similar a change_detected().
