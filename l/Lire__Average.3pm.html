NOMBRE

Lire::Average - Clase de Lire que implementa el operador avg

SINOPSIS

use Lire::Average

DESCRIPCIÓN

Clase que implementa el operador avg. Este operador calculará el valor promedio de un campo DLF en un grupo de registros DLF.

Si el campo utilizado por average no es un campo numérico, se utilizará el número de valores diferentes en ese campo como numerador.

Es posible calcular un promedio ponderado especificando un campo de ponderación.

Por defecto, el promedio es un promedio por registro. Es posible calcular un promedio por valores diferentes. La lista de campos que se utiliza para determinar los valores diferentes se especifica en el atributo 'by-fields'.

MÉTODOS

new( %params )

Crea un nuevo objeto Lire::Average. Además de los valores admitidos por sus padres, los atributos 'by-fields' y 'weight' se inicializarán a los valores especificados en el argumento %params.

by_fields( [$nuevo_by_fields] )

Devuelve los campos que se utilizarán para contar los valores diferentes que compondrán la parte 'by' del promedio.

Es una referencia a una matriz de nombres de campos DLF.

Si se establece el parámetro $nuevo_by_fields, se utilizará como el nuevo valor de $by_fields. Debe ser una referencia a una matriz y solo debe contener nombres de campo válidos para el esquema de especificación del informe actual.

weigth( [$nueva_ponderación] )

Devuelve el nombre del campo DLF por el cual se multiplicarán los valores antes de sumarlos.

Puede cambiar el campo de ponderación especificando un nuevo nombre como parámetro $nueva_ponderación. Use undef para eliminar el uso de un campo de ponderación.
