Módulo Load_path
: sig end

Gestión de directorios de inclusión.

Este módulo ofrece una interfaz de alto nivel para localizar archivos en la ruta de carga, que se construye a partir de las opciones de línea de comandos -I y -H, así como de algunos otros parámetros.

Asume que el contenido de los directorios de inclusión no cambia durante la ejecución del compilador.

val add_dir : hidden:bool -> string -> unit

Añade un directorio al final de la ruta de carga (es decir, con la menor prioridad).

val remove_dir : string -> unit

Elimina un directorio de la ruta de carga.

val reset : unit -> unit

Elimina todos los directorios.

module Dir : sig end

type auto_include_callback = (Dir.t -> string -> string option) -> string -> string

El tipo de funciones de devolución de llamada para init ~auto_include.

val no_auto_include : auto_include_callback

No hay inclusión automática de directorios: las ausencias en la ruta de carga generan Not_found como de costumbre.

val init : auto_include:auto_include_callback -> visible:string list -> hidden:string list -> unit

init ~visible ~hidden es lo mismo que reset ();
List.iter add_dir (List.rev hidden);
List.iter add_dir (List.rev visible)

val auto_include_otherlibs : (string -> unit) -> auto_include_callback

auto_include_otherlibs alert es una función de devolución de llamada que se pasa a Load_path.init y que añade automáticamente -I +lib a la ruta de carga después de llamar a alert lib.

val get_path_list : unit -> string list

Devuelve la lista de directorios pasados a add_dir hasta el momento.

type paths = {
visible : string list ;
hidden : string list ;
}

val get_paths : unit -> paths

Devuelve los directorios pasados a add_dir hasta el momento.

val find : string -> string

Localiza un archivo en la ruta de carga. Genera Not_found si el archivo no se encuentra. Esta función está optimizada para el caso en que el nombre de archivo es un nombre base, es decir, no contiene un separador de directorios.

val find_normalized : string -> string

Igual que find, pero también busca el nombre de unidad normalizado (ver Misc.normalized_unit_filename), es decir, si el nombre es Foo.ml, permite que coincidan /path/Foo.ml y /path/foo.ml.

type visibility =
| Visible
| Hidden

val find_normalized_with_visibility : string -> string * visibility

Igual que find_normalized, pero también informa si el cmi se encontró en un directorio -I (Visible) o en un directorio -H (Hidden).

val add : Dir.t -> unit

Obsoleto.

Nombre antiguo para Load_path.append_dir.

val append_dir : Dir.t -> unit

append_dir d añade d al final de la ruta de carga (es decir, con la menor prioridad).

val prepend_dir : Dir.t -> unit

prepend_dir d añade d al principio de la ruta de carga (es decir, con la mayor prioridad).

val get_visible : unit -> Dir.t list

Igual que get_paths (), excepto que devuelve una lista Dir.t y no incluye las rutas -H.
