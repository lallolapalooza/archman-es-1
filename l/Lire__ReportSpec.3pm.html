ReportSpec(3pm) Documentación de Lire de LogReport ReportSpec(3pm)

NOMBRE

Lire::ReportSpec - API para las especificaciones de informes XML.

SINÓPSIS

use Lire::ReportSpec;

DESCRIPCIÓN

MÉTODOS DE INFORMACIÓN META

list_specs( $superservice )

Devuelve una referencia de array que contiene todos los tipos de especificación de informes disponibles para el superservicio $superservice.

has_spec( $superservice, $type )

Devuelve verdadero si hay una especificación de tipo $type disponible para el superservicio $superservice.

MÉTODOS DE OBJETO

subreport_id( [ $new_subreport_id ] )

Devuelve (y opcionalmente cambia) el ID que se asociará al Subinforme que será generado por esta especificación.

chart_configs()

Devuelve una referencia de array que contiene los objetos Lire::Report::ChartConfig que especifican los gráficos que deben generarse cuando el objeto Lire::Report::Subreport especificado por este objeto se formatee.

add_chart_config( $chart_config )

Añade un objeto Lire::Report::ChartConfig que debe añadirse al objeto Lire::Report::Subreport especificado por este objeto.

filter_spec( [ $new_filter_spec ] )

Devuelve (y opcionalmente cambia) la Lire::FilterExpr que debe aplicarse para crear el Lire::Report::Subreport especificado por este objeto. Será undef si no se debe aplicar ningún filtro.

calc_spec( [ $new_aggregator ] )

Devuelve (y opcionalmente cambia) el agregador Lire::Aggregator que debe usarse para crear el Lire::Report::Subreport especificado por este objeto.

mark_missing( $reason )

Marca que el informe que debe generarse a partir de esta especificación de informe debe marcarse como ausente. El parámetro $reason proporciona la razón por la que el subinforme estará ausente.

is_missing()

Devuelve verdadero si el subinforme generado por esta especificación de informe debe marcarse como ausente.

set_store( $store )

Establece el almacén DLF sobre el cual se generará esta ReportSpec cuando se llame a create_subreport().

create_subreport()

Crea un objeto Lire::Report::Subreport basado en esta especificación de informe. Será un subinforme ausente si se llamó al método mark_missing().

Llamado por Lire::ReportSection::create_report_section().

create_table_info()

Devuelve un objeto Lire::Report::TableInfo que describe la tabla generada por el subinforme de este tipo.

VER TAMBIÉN
