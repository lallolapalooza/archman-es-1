Program(3pm) Documentación de Lire para LogReport Program(3pm)

NOMBRE

Lire::Program - Infraestructura común de los programas de Lire.

SINÓPSIS

Cualquier programa:

use Lire::Program qw/ :msg /;
lr_info( "haciendo cosas " );
lr_debug( "información de depuración" );
lr_warn( "valor inesperado encontrado: ", $valor );
open( CFGFILE, "my.conf" ) or lr_err( "error al abrir: ", $! );

DESCRIPCIÓN

Este módulo debe ser utilizado por todos los programas de Lire (¡al menos los de Perl!).

Incluye:

1.
Comportamiento común para una buena integración en la suite de Lire. (Salida de información de rendimiento y otras cosas).
2.
Funciones para portabilidad.
3.
Funciones de registro (logging).

COMPORTAMIENTO COMÚN PARA PROGRAMAS DE LIRE

Al utilizar el módulo Lire::Program, te aseguras de que tu programa se comportará correctamente en la cadena de herramientas de Lire. Este módulo instalará bloques BEGIN y END para cumplir con la política de Lire.

1.
Solo los mensajes en el formato de registro adecuado 
I<superservicio> I<servicio> I<id_lr> I<programa> I<nivel> I<mensaje>

deben ser emitidos. Este módulo instalará un manejador de señal __WARN__ que se asegura de que todos los módulos que usan `warn` para emitir mensajes se reescriban en el formato adecuado.

Ver también lr_run(1).

2.
Todos los programas deben comenzar con un mensaje de "info" que registre sus argumentos. Este módulo se encarga de esto.
3.
Todos los programas deben finalizar imprimiendo mensajes de "info" con estadísticas de rendimiento y el mensaje 'ended'. El uso de este módulo se encarga de esto. Al final de tu programa se emitirá lo siguiente (despojado de la información común): 
memory stats: vsize=10688K rss=9380K majflt=406
elapsed time in seconds real=9 user=8.72 system=0.06
stopped

La información de perfilado de memoria solo se emitirá en plataformas que ejecuten el kernel de Linux.

VARIABLES COMUNES

Como conveniencia, puedes importar en tu espacio de nombres usando la etiqueta :env algunas variables comunes a todos los programas de Lire. (Nota que también puedes usar estas variables sin importarlas prefijando las variables con el espacio de nombres Lire::Program::).

$PROG
El nombre de tu programa (es el valor de $0 sin la ruta del directorio).
$LR_SUPERSERVICE
El super-servicio que estás procesando, o "all" si esta información no está disponible.
$LR_SERVICE
El servicio que estás procesando, o "all" si este información no está especificada.
$LR_ID
Este es el identificador del trabajo. Debería ser compartido por todos los comandos en un trabajo de Lire. Este es el valor UNSET cuando no se especificó ninguno.
$LR_TAG
Este es el prefijo para todos los mensajes de registro. Debería corresponder a 
$LR_SUPERSERVICE $LR_SERVICE $LR_ID $PROG

FUNCIONES DE REGISTRO

Las funciones de registro ahora son parte del módulo Lire::Logger. Consulta Lire::Logger(3pm) para más información. Los nombres antiguos todavía se exportan desde este módulo usando la etiqueta ':msg'.

FUNCIONES CONVERSORAS DLF

La API del conversor DLF ahora está definida en Lire::DlfConverter(3pm). El Lire::OldDlfAdapter(3pm) puede ser utilizado para trabajar con conversores DLF de estilo antiguo.

VER TAMBIÉN

Lire::DlfSchema(3pm), lr_run(1)
