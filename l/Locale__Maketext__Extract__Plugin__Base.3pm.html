NOMBRE

Locale::Maketext::Extract::Plugin::Base - Módulo base para plugins de análisis de formato

VERSIÓN

versión 1.00

SINÓPSIS

package My::Parser::Plugin;
use base qw(Locale::Maketext::Extract::Plugin::Base);
sub file_types {
    return [qw( ext ext2 )]
}
sub extract {
    my $self = shift;
    local $_ = shift;
    my $line = 1;
    while (my $found = $self->routine_to_extract_strings) {
        $self->add_entry($str,[$filename,$line,$vars])
    }
    return;
}

DESCRIPCIÓN

Todos los plugins de análisis de formato en Locale::Maketext::Extract heredan de Locale::Maketext::Extract::Plugin::Base.

Si deseas escribir tu propio plugin de análisis personalizado, necesitarás heredar de este módulo y proporcionar los métodos file_types() y extract(), como se muestra arriba.

MÉTODOS

new()
$plugin = My::Parser->new(
    @file_types         # Opcionalmente especificar una lista de tipos de archivo reconocidos
)
add_entry()
$plugin->add_entry($str,$line,$vars)
entries()
$entries = $plugin->entries;
clear()
$plugin->clear

Borra todas las entradas almacenadas.

file_types()
@default_file_types = $plugin->file_types

Devuelve una lista de tipos de archivos que tu módulo sabe cómo analizar.

Cada tipo de archivo puede ser:

  • Una cadena simple 
    'pl'  => el nombre del archivo se mapea contra qr/\.pl$/
'*'   => se aceptan todos los archivos
  • Una expresión regular 
    qr/\.tt2?\./ => el nombre del archivo se mapea contra esta expresión regular
  • Un coderef 
    sub {}  => este coderef se llama como $coderef->($base_filename,$path_to_file)
           Debe devolver verdadero o falso
extract()
$plugin->extract($filecontents);

El método extract() se llama para procesar el contenido del archivo actual.

Cuando encuentra una cadena que debe ser extraída, debe llamar a

$self->add_entry($string,$line,$vars])

donde $vars se refiere a cualquier argumento que se esté pasando a la función localize. Por ejemplo:

l("You found [quant,_1,file,files]",files_found)
  string: "You found [quant,_1,file,files]"
  vars  : (files_found)

IMPORTANTE: Se usa una única instancia de plugin para todos los archivos, así que si planeas almacenar información de estado en el objeto $plugin, deberías limpiarla al principio de extract()

known_file_type()
if ($plugin->known_file_type($filename_with_path)) {
    ...
}

Determina si el archivo actual debe ser procesado por este analizador, basándose en la lista de tipos de archivo especificada al crear este objeto o en los tipos de archivo por defecto del módulo.
