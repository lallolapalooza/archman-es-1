NOMBRE

Lire::DlfAnalyseProcess - Objeto que controla el proceso de análisis.

SINOPSIS

use Lire::DlfStore;
use Lire::DlfAnalyserProcess;
my $store = Lire::DlfStore->open( "store" );
my $process = new Lire::DlfAnalyserProcess( $store, $analyser_name,
                                            $analyser_config, $dlf_source );
$process->run_analysis_job();
print "Registros DLF creados: ", $process->dlf_count(),    "\n";
print "Errores encontrados: ",  $process->errors_count(), "\n";

DESCRIPCIÓN

Este objeto encapsula el proceso de análisis DLF de Lire. Recibe como un Lire::DlfStore, el nombre del analizador, su configuración y opcionalmente, un ID de fuente dlf. Cuando se utiliza una fuente dlf, el análisis solo se realizará utilizando el DLF proveniente de esa fuente.

El objeto proporciona la API al conversor. También hay métodos disponibles para consultar información sobre el proceso de conversión.

new( $store, $analyser_name, $analyser_config, [ $dlf_source ] );

Crea un Lire::DlfAnalysisProcess.

run_analysis_job()

Importa los datos de registro de ImportJob como DLF. Este método lanzará una excepción si se llama más de una vez.

job_id()

Devuelve el identificador del trabajo asociado a este proceso.

dlf_store()

Devuelve el Lire::DlfStore en el que este proceso de conversión está almacenando los registros DLF.

dlf_source()

Devuelve la fuente de la que debe provenir el DLF en el src_schema para ser analizado.

dlf_analyser()

Devuelve el nombre del analizador que se ejecutará.

dlf_analyser_config()

Devuelve los datos de configuración del análisis que deben ser utilizados por el conversor.

dlf_count()

Devuelve el número de registros DLF creados.

error_count()

Devuelve el número de errores encontrados en el proceso de conversión.

source_filter()

Devuelve una expresión Lire::FilterExpr que debe usarse para limitar los registros DLF a analizar.

Este método devuelve nulo si se debe analizar todo el flujo DLF.

API PARA LOS ANALIZADORES DLF

Este es el objeto que encapsula la implementación DLF y oculta la complejidad del marco de almacenamiento a los analizadores DLF. Ofrece los siguientes métodos al conversor DLF.

write_dlf( $dlf, [$related_to] )

Esto escribe el registro DLF $dlf que conforma el esquema de $schema en el Lire::DlfStore. $Dlf es una referencia a un hash. Las claves son el nombre del campo del esquema. Un valor indefinido significa que este campo no está disponible en ese registro.

Al escribir en un esquema derivado, el parámetro $related_to puede ser una referencia a un array que contiene los dlf_ids del registro relacionado.

error( $error_msg );

Método que debe ser utilizado por Lire::Analyser para informar que se encontró un error durante el proceso de análisis. $error_msg debe usarse para informar la naturaleza del error.
