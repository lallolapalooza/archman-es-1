Appender::Screen(3) Documentación de Perl contribuida por el usuario Appender::Screen(3)

NOMBRE

Log::Log4perl::Appender::Screen - Registrar en STDOUT/STDERR

SINOPSIS

use Log::Log4perl::Appender::Screen;
my $app = Log::Log4perl::Appender::Screen->new(
  autoflush => 1,
  stderr    => 0,
  utf8      => 1,
);
$file->log(message => "Regístrame\n");

DESCRIPCIÓN

Este es un appender simple para escribir en STDOUT o STDERR.

El constructor new() toma un parámetro opcional "stderr":

  • Si se establece a un valor falso, registrará todos los niveles en STDOUT (o, más precisamente, en el manejador de archivos seleccionado a través de select(), STDOUT por defecto).
  • Si se establece a un hash, entonces cualquier "log4p_level" con un valor verdadero usará dinámicamente STDERR, o STDOUT en caso contrario.
  • De lo contrario, si es un valor verdadero (el ajuste por defecto es 1), los mensajes se registrarán en STDERR.
# Todos los mensajes/niveles a STDERR
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => 1,
);
# Solo ERROR y FATAL a STDERR (sensible a mayúsculas/minúsculas)
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => { ERROR => 1, FATAL => 1},
);

El diseño e implementación de este módulo se ha inspirado en gran medida en el framework de appenders "Log::Dispatch" de Dave Rolsky.

Para habilitar la impresión de caracteres utf8 anchos, establezca la opción utf8 a un valor verdadero:

my $app = Log::Log4perl::Appender::Screen->new(
  stderr    => 1,
  utf8      => 1,
);

Esto emitirá el comando binmode necesario al canal de salida seleccionado (stderr/stdout).

Para habilitar el autoflush, establezca la opción "autoflush" a un valor verdadero:

my $app = Log::Log4perl::Appender::Screen->new(
  autoflush => 1,
);

Esto emitirá el comando autoflush necesario al canal de salida seleccionado (stderr/stdout).

Esto es necesario en contenedores, especialmente cuando el volumen de registros es bajo, para no almacenar en caché los mensajes de registro y causar un retraso significativo.
