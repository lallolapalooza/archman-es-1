NAME

Locale::RecodeData::CP10007 — CP10007 (ISO 8859-7) character table

SYNOPSIS

    use Locale::RecodeData::CP10007;

DESCRIPTION

This module provides the character table for the CP10007 encoding, also known as ISO 8859-7.

The following tables are defined:

  • CP10007: The mapping from ISO 8859-7 characters to Unicode.
  • TO_CP10007: The mapping from Unicode characters to ISO 8859-7.

COMMENTS

This encoding is the Latin-1 character set with Greek characters.
