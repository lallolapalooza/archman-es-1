Nombre

Locale::RecodeData::CP1257 - Rutinas de conversión para CP1257

Sintaxis

Este módulo es interno a libintl. ¡No lo use directamente!

Descripción

Este módulo está generado y contiene las tablas de conversión y rutinas para CP1257.

Comentarios

Los siguientes comentarios se extrajeron del original charmap:

version: 1.0
 source: CEN/TC304 N283
alias WINBALTRIM

¡Nota: los alias mencionados arriba no son necesariamente válidos!

NOMBRE

Locale::RecodeData::CP1257

SINOPSIS

use Locale::RecodeData::CP1257;

DESCRIPCIÓN

Locale::RecodeData::CP1257 es un módulo que proporciona datos para la codificación CP1257.

COMENTARIOS

El módulo proporciona información sobre la codificación CP1257, incluyendo mapeos de caracteres y otros detalles.
