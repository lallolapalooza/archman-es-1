DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element or at the head of the list. An SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A singly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro SLIST_REMOVE removes the element elm from the list.

The macro SLIST_SWAP swaps the contents of the list headed by head1 and the list headed by head2.

LISTAS SIMPLEMENTE ENLAZADAS

Una lista simplemente enlazada es una cola con cabeza definida por la macro SLIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola después de un elemento existente, o al principio de la cola. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la cola. Un puntero a la cabeza de la cola se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la cola head.

La macro SLIST_CONCAT concatena la cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro SLIST_EMPTY evalúa a verdadero si no hay elementos en la cola.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la cola.

La macro SLIST_FIRST devuelve el primer elemento de la cola o NULL si la cola está vacía.

La macro SLIST_FOREACH recorre la cola referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro SLIST_FOREACH_FROM se comporta de manera idéntica a SLIST_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_FOREACH_SAFE recorre la cola referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de SLIST_FOREACH(), aquí está permitido tanto eliminar var como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE se comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento SLIST encontrado previamente y comienza el bucle en var en lugar del primer elemento de la SLIST referenciada por head.

La macro SLIST_INIT inicializa la cola referenciada por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento después de elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre toda la lista.

La macro SLIST_REMOVE_HEAD elimina el elemento elm del principio de la lista. Para una eficiencia óptima, los elementos que se eliminan del principio de la lista deben usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe utilizar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE LISTA SIMPLEMENTE ENLAZADA

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Cabeza de lista simplemente enlazada. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Lista simplemente enlazada. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializar la lista. */

n1 = malloc(sizeof(struct entry));	/* Insertar al principio. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación del principio. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Eliminación de lista. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

COLAS CON CABEZA SIMPLEMENTE ENLAZADAS

Una cola con cabeza simplemente enlazada es una cola con cabeza definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola con cabeza y otro al último elemento de la cola con cabeza. Los elementos están enlazados de forma simple para minimizar el espacio y la sobrecarga de manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola con cabeza después de un elemento existente, al principio de la cola con cabeza, o al final de la cola con cabeza. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la cola con cabeza. Un puntero a la cabeza de la cola con cabeza se puede declarar posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola con cabeza head.

La macro STAILQ_CONCAT concatena la cola con cabeza head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola con cabeza.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola con cabeza.

La macro STAILQ_FIRST devuelve el primer elemento de la cola con cabeza o NULL si la cola con cabeza está vacía.

La macro STAILQ_FOREACH recorre la cola con cabeza referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola con cabeza referenciada por head en la dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí está permitido tanto eliminar var como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola con cabeza referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola con cabeza.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola con cabeza.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola con cabeza. Si la cola con cabeza está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola con cabeza, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento después de elm de la cola con cabeza. A diferencia de STAILQ_REMOVE, esta macro no recorre toda la cola con cabeza.

La macro STAILQ_REMOVE_HEAD elimina el elemento al principio de la cola con cabeza. Para una eficiencia óptima, los elementos que se eliminan del principio de la cola con cabeza deben usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola con cabeza. Se debe evitar el uso de esta macro ya que recorre toda la lista. Se debe utilizar una cola con cabeza doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas con cabeza largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLA CON CABEZA SIMPLEMENTE ENLAZADA

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Cabeza de cola con cabeza simplemente enlazada. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola con cabeza. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar al principio. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar al final. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación del principio. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido seguro hacia adelante. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Eliminación de TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación más rápida de TailQ. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS DOBLEMENTE ENLAZADAS

Una lista doblemente enlazada es una cola con cabeza definida por la macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados de forma doble para que un elemento arbitrario pueda ser eliminado sin recorrer la lista. Los nuevos elementos pueden añadirse a la lista después de un elemento existente, antes de un elemento existente, o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se enlazarán en la lista. Un puntero a la cabeza de la lista puede declararse posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de esta macro ya que recorre la totalidad de la lista head1. Se debe usar una cola con cabeza si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos en la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referenciada por head

en la dirección hacia adelante, asignando cada elemento en su turno a var.

El macro LIST_FOREACH_FROM se comporta idénticamente a LIST_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

El macro LIST_FOREACH_SAFE recorre la lista referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de LIST_FOREACH(), aquí está permitido tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

El macro LIST_FOREACH_FROM_SAFE se comporta idénticamente a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LISTA referenciada por head.

El macro LIST_INIT inicializa la lista referenciada por head.

El macro LIST_INSERT_HEAD inserta el nuevo elemento elm al principio de la lista.

El macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

El macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

El macro LIST_NEXT devuelve el siguiente elemento de la lista, o NULL si es el último.

El macro LIST_PREV devuelve el elemento anterior de la lista, o NULL si es el primero. La lista head debe contener el elemento elm.

El macro LIST_REMOVE elimina el elemento elm de la lista.

El macro LIST_SWAP intercambia el contenido de head1 y head2.

COLAS FINALES

Una cola final está encabezada por una estructura definida por el macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola final y otro al último elemento de la cola final. Los elementos están enlazados doblemente para que se pueda eliminar un elemento arbitrario sin recorrer la cola final. Se pueden agregar nuevos elementos a la cola final después de un elemento existente, antes de un elemento existente, al principio de la cola final o al final de la cola final. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se va a definir, y TYPE es el tipo de los elementos que se van a enlazar en la cola final. Posteriormente, se puede declarar un puntero a la cabecera de la cola final de la siguiente manera:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

El macro TAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola final head.

El macro TAILQ_CONCAT concatena la cola final encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

El macro TAILQ_EMPTY se evalúa como verdadero si no hay elementos en la cola final.

El macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola final.

El macro TAILQ_FIRST devuelve el primer elemento de la cola final o NULL si la cola final está vacía.

El macro TAILQ_FOREACH recorre la cola final referenciada por head en la dirección hacia adelante, asignando cada elemento en su turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

El macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

El macro TAILQ_FOREACH_REVERSE recorre la cola final referenciada por head en la dirección inversa, asignando cada elemento en su turno a var.

El macro TAILQ_FOREACH_REVERSE_FROM se comporta idénticamente a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

Los macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referenciada por head en la dirección hacia adelante o inversa respectivamente, asignando cada elemento en su turno a var. Sin embargo, a diferencia de sus contrapartes no seguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten eliminar var y liberarlo del bucle de forma segura sin interferir con el recorrido.

El macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ referenciada por head.

El macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ referenciada por head.

El macro TAILQ_INIT inicializa la cola final referenciada por head.

El macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm al principio de la cola final.

El macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola final.

El macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

El macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

El macro TAILQ_LAST devuelve el último elemento de la cola final. Si la cola final está vacía, el valor devuelto es NULL.

El macro TAILQ_NEXT devuelve el siguiente elemento de la cola final, o NULL si este elemento es el último.

El macro TAILQ_PREV devuelve el elemento anterior de la cola final, o NULL si este elemento es el primero.

El macro TAILQ_REMOVE elimina el elemento elm de la cola final.

El macro TAILQ_SWAP intercambia el contenido de head1 y head2.

DESCRIPCIÓN


La función queue(3) se utiliza para manejar listas enlazadas simples. La función queue(3) implementa una lista enlazada simple con un puntero al primer nodo de la lista.






LISTAS ENLAZADAS SIMPLES


La función queue(3) implementa una lista enlazada simple con un puntero al primer nodo de la lista.






EJEMPLO DE LISTA ENLAZADA SIMPLE


El ejemplo siguiente muestra cómo se usa la función queue(3) para crear una lista enlazada simple:


#include <stdio.h>
#include <stdlib.h>
#include <queue.h>

int main() {
    queue_t *q = queue_create();
    queue_append(q, 10);
    queue_append(q, 20);
    queue_append(q, 30);
    printf("Queue: %d, %d, %d\n", queue_get(q, 0), queue_get(q, 1), queue_get(q, 2));
    queue_destroy(q);
    return 0;
}

DIAGNÓSTICOS


Cuando se debuguea queue(3), puede ser útil trazar cambios en la cola. Para habilitar el trazado, define la macro QUEUE_MACRO_DEBUG_TRACE al compilar.


También puede ser útil destruir punteros que hayan sido desenlazados de una cola para detectar uso después del desenlace. Para habilitar la destrucción de punteros, define la macro QUEUE_MACRO_DEBUG_TRASH al compilar. La macro QMD_IS_TRASHED(void *ptr) devuelve true si ptr ha sido destruido por la opción QUEUE_MACRO_DEBUG_TRASH.
