NOMBRE

Lire::UI::Widget - Vistas para el objeto Lire::Config::Value.

SINOPSIS

use Curses::UI;
use Lire::Config;
Lire::Config->init();
my $ui = new Curses::UI();
my $window = $ui->add( 'window', 'Window' );
my $widget = $window->add( 'widget', 'Lire::UI::Widget',
                           'value' => Lire::Config->get_var( 'name' ));

DESCRIPCIÓN

Lire::UI::Widget define subclases de Curses::UI::Widget que pueden ser utilizadas para editar objetos Lire::Config::Value.

new( %args, 'valor' => $valor, [ onvalorcambiado => $manejador ] )

El método new() es en realidad un método fábrica que instancia una subclase apropiada de Lire::UI::Widget basada en el tipo del objeto Lire::Config::Value $valor. onvalorcambiado es un evento que se disparará cada vez que el objeto Lire::Config::Value sea modificado por el usuario.

valor()

Devuelve el objeto Lire::Config::Value que está siendo editado por esta vista.

onValorCambiado( $codigo )

Cambia el manejador de eventos conectado al evento 'onvalorcambiado'. Este evento se dispara cada vez que el objeto Lire::Config::Value asociado a este widget es modificado.

refrescar_vista()

Este método puede ser llamado para actualizar la vista y reflejar modificaciones en el objeto Lire::COnfig::Value subyacente.

VER TAMBIÉN

Lire::UI(3pm), Curses::UI(3pm)
