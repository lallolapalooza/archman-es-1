DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden utilizarse en ambos C y C++:

  1. Lista
  2. Lista doblemente enlazada
  3. Cola de lista doblemente enlazada
  4. Cola de lista
Todas las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de un nuevo elemento al frente de la lista.
  2. Inserción de un nuevo elemento después de cualquier elemento de la lista.
  3. Eliminación de un elemento en la cabeza de la lista en O(1).
  4. Traversión de la lista en sentido avanzado.
  5. Cambiar el contenido de dos listas.
Las listas doblemente enlazadas son las más simples de las cuatro estructuras y soportan solo la funcionalidad mencionada. Las listas doblemente enlazadas son ideales para aplicaciones con grandes conjuntos de datos y pocos o ningunos eliminaciones, o para implementar una cola LIFO. Las listas doblemente enlazadas añaden la siguiente funcionalidad:
  1. Eliminación de cualquier elemento de la lista en O(n).
  2. Conexión de dos listas en O(n).
Las listas doblemente enlazadas tail queues añaden la siguiente funcionalidad:
  1. Elementos pueden ser agregados al final de una lista.
  2. Eliminación de cualquier elemento de la lista en O(n).
  3. Podrían ser concatenadas.
Sin embargo:
  1. Todo el insertar en una lista debe especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente 15% mayor y las operaciones corren aproximadamente 20% más lentas que las listas doblemente enlazadas.

Las listas doblemente enlazadas tail queues son ideales para aplicaciones con grandes conjuntos de datos y pocos o ninguna eliminaciones, o para implementar una cola FIFO.

Todas las estructuras de datos doblemente enlazadas (listas y colas de lista) adicionan también:

  1. Inserción de un nuevo elemento antes de cualquier elemento de la lista.
  2. Eliminación de cualquier elemento de la lista en O(1).
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño del código y el tiempo de ejecución de las operaciones (excepto para la eliminación) es aproximadamente el doble que en las estructuras de lista doblemente enlazadas.

Las listas son las más simples de las estructuras de datos doblemente enlazadas. Añaden la siguiente funcionalidad sobre las mencionadas anteriormente:

  1. Conexión de dos listas en O(n).
  2. Podrían ser recorridas en sentido inverso.
Sin embargo:
  1. Para recorrer en sentido inverso, se debe especificar el elemento a iniciar el recorrido y la lista en la cual está contenido.

Las colas de lista añaden la siguiente funcionalidad:

  1. Elementos pueden ser agregados al final de una lista.
  2. Podrían ser recorridas en sentido inverso, de cola a cabeza.
  3. Podrían ser concatenadas.
Sin embargo:
  1. Todo el insertar y eliminar en una lista debe especificar la cabeza de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño del código es aproximadamente 15% mayor y las operaciones corren aproximadamente 20% más lentas que las listas doblemente enlazadas.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse usando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Vea los ejemplos siguientes para una explicación más detallada de cómo se utilizan estas macros.

LÍISTAS SIMPLEMENTE ENLACADAS

Una lista doblemente enlazada es dirigida por una estructura definida mediante la macro SLIST_HEAD. Esta estructura contiene un único puntero hacia el primer elemento de la lista. Los elementos están doblemente enlazados para minimizar el espacio y el overhead de manipulación de punteros, pero con el costo de O(n) para eliminar cualquier elemento arbitrario. Los nuevos elementos pueden agregarse a la lista después de un elemento existente o al frente de la lista. Una estructura SLIST_HEAD se declara así:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definirse y TYPE es el tipo de los elementos a enlazar en la lista. Una dirección puntera al frente de la lista puede ser declarada posteriormente como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatenará la lista dirigida por head2 al final de la lista dirigida por head1, eliminando todos los elementos del former. El uso de esta macro debería evitarse ya que recorre todo el contenido de la lista head1. Debe usarse una cola de lista doblemente enlazada si esta macro es necesaria en caminos de código de alto uso o para operar sobre listas largas.

La macro SLIST_EMPTY evalúa a true si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referida por head en el sentido avanzado, asignando cada elemento en su orden a var.

La macro SLIST_FOREACH_FROM comporta similarmente a SLIST_FOREACH cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head.

La macro SLIST_FOREACH_SAFE recorre la lista referida por head en el sentido avanzado, asignando cada elemento en su orden a var. Sin embargo, diferente de SLIST_FOREACH() aquí es permitido tanto remover var como liberarla de dentro del bucle sin interferir con el recorrido.

La macro SLIST_FOREACH_FROM_SAFE comporta similarmente a SLIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head.

La macro SLIST_INIT inicializa la lista referida por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al frente de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm en la lista.

La macro SLIST_INIT inicializa la lista referida por head.

El macro SLIST_REMOVE_AFTER elimina el elemento posterior a elm de la lista. A diferencia de SLIST_REMOVE, este macro no recorre la lista completa.

El macro SLIST_REMOVE_HEAD elimina el elemento elm de la cabeza de la lista. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la lista deberían usar explícitamente este macro en lugar del macro genérico SLIST_REMOVE.

El macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de este macro, ya que recorre la lista completa. Se debe utilizar una lista doblemente enlazada si este macro es necesario en rutas de código de alto uso o para operar en listas largas.

El macro SLIST_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE LISTA ENLAZADA SIMPLEMENTE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Cabeza de lista enlazada simplemente. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Lista enlazada simplemente. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Inicializar la lista. */

n1 = malloc(sizeof(struct entry));	/* Insertar en la cabeza. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Eliminación. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Eliminación de la cabeza. */
free(n3);
					/* Recorrido hacia adelante. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido hacia adelante seguro. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* Eliminación de la lista. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

COLAS DE LISTA ENLAZADA SIMPLEMENTE CON COLA

Una cola de lista enlazada simplemente con cola está encabezada por una estructura definida por el macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados de forma simplemente para una mínima sobrecarga de espacio y manipulación de punteros, a expensas de una eliminación O(n) para elementos arbitrarios. Se pueden agregar nuevos elementos a la cola después de un elemento existente, al principio de la cola o al final de la cola. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la cola. Posteriormente, se puede declarar un puntero a la cabeza de la cola como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

El macro STAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola head.

El macro STAILQ_CONCAT concatena la cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

El macro STAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola.

El macro STAILQ_ENTRY declara una estructura que conecta los elementos de la cola.

El macro STAILQ_FIRST devuelve el primer elemento de la cola o NULL si la cola está vacía.

El macro STAILQ_FOREACH recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var.

El macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario, trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

El macro STAILQ_FOREACH_SAFE recorre la cola referenciada por head en dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí se permite tanto eliminar var como liberarlo dentro del bucle de forma segura sin interferir con el recorrido.

El macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario, trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

El macro STAILQ_INIT inicializa la cola referenciada por head.

El macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la cola.

El macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola.

El macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

El macro STAILQ_LAST devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

El macro STAILQ_NEXT devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

El macro STAILQ_REMOVE_AFTER elimina el elemento posterior a elm de la cola. A diferencia de STAILQ_REMOVE, este macro no recorre la cola completa.

El macro STAILQ_REMOVE_HEAD elimina el elemento de la cabeza de la cola. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la cola deberían usar este macro explícitamente en lugar del macro genérico STAILQ_REMOVE.

El macro STAILQ_REMOVE elimina el elemento elm de la cola. Se debe evitar el uso de este macro, ya que recorre la lista completa. Se debe utilizar una cola doblemente enlazada si este macro es necesario en rutas de código de alto uso o para operar en colas largas.

El macro STAILQ_SWAP intercambia el contenido de head1 y head2.

EJEMPLO DE COLA DE LISTA ENLAZADA SIMPLEMENTE CON COLA

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Cabeza de cola de lista enlazada simplemente. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Cola de lista. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Inicializar la cola. */

n1 = malloc(sizeof(struct entry));	/* Insertar en la cabeza. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insertar en la cola. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insertar después. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Eliminación. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Eliminación de la cabeza. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Recorrido hacia adelante. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Recorrido hacia adelante seguro. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* Eliminación de TailQ. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Eliminación más rápida de TailQ. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

LISTAS

Una lista está encabezada por una estructura definida por el macro LIST_HEAD. Esta estructura contiene un único puntero al primer elemento de la lista. Los elementos están enlazados doblemente para que un elemento arbitrario pueda eliminarse sin recorrer la lista. Se pueden agregar nuevos elementos a la lista después de un elemento existente, antes de un elemento existente o al principio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir, y TYPE es el tipo de los elementos a enlazar en la lista. Posteriormente, se puede declarar un puntero a la cabeza de la lista como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

El macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

El macro LIST_CONCAT concatena la lista encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera. Se debe evitar el uso de este macro, ya que recorre la totalidad de la lista head1. Se debe usar una cola de lista si este macro es necesario en rutas de código de alto uso o para operar en listas largas.

El macro LIST_EMPTY evalúa a verdadero si no hay elementos en la lista.

El macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

El macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

El macro LIST_FOREACH recorre la lista referenciada por head/var> en la dirección hacia adelante, asignando cada elemento en su turno a var.

La macro LIST_FOREACH_FROM se comporta idénticamente a LIST_FOREACH cuando var es NULL, de lo contrario trata var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LIST a la que hace referencia head.

La macro LIST_FOREACH_SAFE recorre la lista a la que hace referencia head en la dirección hacia adelante, asignando cada elemento en su turno a var. Sin embargo, a diferencia de LIST_FOREACH(), aquí se permite tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro LIST_FOREACH_FROM_SAFE se comporta idénticamente a LIST_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento LIST encontrado previamente y comienza el bucle en var en lugar del primer elemento en la LIST a la que hace referencia head.

La macro LIST_INIT inicializa la lista a la que hace referencia head.

La macro LIST_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la lista.

La macro LIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro LIST_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro LIST_NEXT devuelve el siguiente elemento de la lista, o NULL si es el último.

La macro LIST_PREV devuelve el elemento anterior en la lista, o NULL si es el primero. La lista head debe contener el elemento elm.

La macro LIST_REMOVE elimina el elemento elm de la lista.

La macro LIST_SWAP intercambia los contenidos de head1 y head2.

EJEMPLO DE LIST

LIST_HEAD(listhead, entry) head =
    LIST_HEAD_INITIALIZER(head);
struct listhead *headp;			/* Cabecera de la lista. */
struct entry {
	...
	LIST_ENTRY(entry) entries;	/* Lista. */
	...
} *n1, *n2, *n3, *np, *np_temp;

COLAS DE COLA

Una cola de cola se encabeza con una estructura definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de cola y otro al último elemento de la cola de cola. Los elementos están doblemente enlazados para que un elemento arbitrario pueda ser eliminado sin recorrer la cola de cola. Los nuevos elementos pueden agregarse a la cola de cola después de un elemento existente, antes de un elemento existente, al principio de la cola de cola, o al final de la cola de cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá, y TYPE es el tipo de los elementos que se enlazarán en la cola de cola. Un puntero a la cabecera de la cola de cola se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario).

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de cola head.

La macro TAILQ_CONCAT concatena la cola de cola encabezada por head2 al final de la encabezada por head1, eliminando todas las entradas de la primera.

La macro TAILQ_EMPTY evalúa a verdadero si no hay elementos en la cola de cola.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos en la cola de cola.

La macro TAILQ_FIRST devuelve el primer elemento de la cola de cola o NULL si la cola de cola está vacía.

La macro TAILQ_FOREACH recorre la cola de cola a la que hace referencia head en la dirección hacia adelante, asignando cada elemento en su turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

La macro TAILQ_FOREACH_FROM se comporta idénticamente a TAILQ_FOREACH cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ a la que hace referencia head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de cola a la que hace referencia head en la dirección inversa, asignando cada elemento en su turno a var.

La macro TAILQ_FOREACH_REVERSE_FROM se comporta idénticamente a TAILQ_FOREACH_REVERSE cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ a la que hace referencia head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista a la que hace referencia head en la dirección hacia adelante o inversa respectivamente, asignando cada elemento en su turno a var. Sin embargo, a diferencia de sus contrapartes no seguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE hacen posible tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro TAILQ_FOREACH_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento en la TAILQ a la que hace referencia head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE se comporta idénticamente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, de lo contrario trata var como un elemento TAILQ encontrado previamente y comienza el bucle inverso en var en lugar del último elemento en la TAILQ a la que hace referencia head.

La macro TAILQ_INIT inicializa la cola de cola a la que hace referencia head.

La macro TAILQ_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la cola de cola.

La macro TAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de cola.

La macro TAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el nuevo elemento elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento de la cola de cola. Si la cola de cola está vacía, el valor de retorno es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento en la cola de cola, o NULL si este elemento es el último.

La macro TAILQ_PREV devuelve el elemento anterior en la cola de cola, o NULL si este elemento es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de cola.

La macro TAILQ_SWAP intercambia los contenidos de head1 y head2.

DIAGNÓSTICOS


Al depurar queue(3), puede ser útil
    rastrear los cambios en la cola. Para habilitar el rastreo, defina la macro
    QUEUE_MACRO_DEBUG_TRACE en tiempo de compilación.


También puede ser útil "desordenar" (trash) punteros que se han
    desvinculado de una cola, para detectar el uso después de la eliminación. Para
    habilitar el desorden de punteros, defina la macro QUEUE_MACRO_DEBUG_TRASH
    en tiempo de compilación. La macro QMD_IS_TRASHED(void
    *ptr) devuelve verdadero si ptr ha sido
    "desordenado" por la opción QUEUE_MACRO_DEBUG_TRASH.
