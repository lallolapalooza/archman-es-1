Lire__Config(3pm)

Paquete: lire

Licencias: GPL-2.0-only

Config(3pm) Documentación de Lire de LogReport Config(3pm)

NOMBRE

Lire::Config - importar variables de configuración de Lire a perl

SINOPSIS

use Lire::Config;
Lire::Config->init();
my $cfg->value = Lire::Config->get( 'lr_schemas_path' );
my $var = Lire::Config->get_var( 'lr_schemas_path' );

DESCRIPCIÓN

Este paquete proporciona la API para acceder a la configuración de Lire.

MÉTODOS

Estos métodos se pueden llamar directamente en una instancia de Lire::Config o en el paquete Lire::Config en sí. En este último caso, es lo mismo que llamar al método en el objeto devuelto por el método instance().

instance()

Devuelve el objeto singleton Lire::Config desde el cual se pueden consultar la configuración.

config_spec()

Devuelve la especificación de configuración utilizada por la configuración actual.

config_spec_path()

Devuelve una lista de directorios que se buscarán para el archivo de especificación de configuración. Por defecto, las especificaciones de configuración solo se buscan en <datadir/lire/config-spec>.

add_config_spec_path_dir( $dir )

Este método añade un directorio a la lista de directorios que se utiliza para buscar archivos de especificación de configuración.

del_config_spec_path_dir( $dir )

Este método elimina un directorio de la lista de directorios que se utiliza para buscar archivos de especificación de configuración.

config_files()

Devuelve la lista de archivos de configuración que se utilizarán para esta configuración.

add_config_path( $path )

Añade archivos de configuración a la lista de archivos que forman parte de la configuración. Los directorios se escanearán recursivamente.

add_config_file( $file )

Añade un archivo de configuración a la lista de archivos que se analizarán para inicializar la configuración.

del_config_file( $file )

Elimina un archivo de configuración de la lista de archivos que forman parte de la configuración.

get_config_file($file)

Obtiene un objeto de archivo de configuración analizado de la lista de archivos.

init()

Este método carga y analiza los archivos de configuración. Debe llamarse antes de usar el método get() para obtener datos de configuración. Este método lanzará una excepción en caso de que haya un parámetro inválido en la configuración.

get( $varname )

Devuelve el valor de configuración de la variable de configuración $varname. init() debería haberse llamado para cargar los datos de configuración antes de usar este método. De lo contrario, hará croak(). Si $varname es desconocido, también se lanzará una excepción.

get_var( $varname )

Devuelve el valor de configuración de la variable de configuración $varname como objeto de configuración. init() debería haberse llamado para cargar los datos de configuración antes de usar este método. De lo contrario, hará croak(). Si $varname es desconocido, también se lanzará una excepción.

DEPURACIÓN

Se puede llamar a este módulo directamente desde la línea de comandos, por ejemplo, con fines de depuración, haciendo algo como:

perl -e 'use lib "/path/to/your/share/perl5"; use Lire::Config; \
 use Lire::Program; print Lire::Config->get( "lr_mail_from" ), "\n"'

o

perl -e 'use Lire::Config; use Lire::Program; \
 $a = Lire::Config->get( lr_converters_init_path );  print "@$a\n"; '

.
