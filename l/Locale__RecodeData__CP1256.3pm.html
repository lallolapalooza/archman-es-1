NOMBRE

Locale::RecodeData::CP1256 - Rutinas de conversión para CP1256

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo use directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas y rutinas de conversión para CP1256.

COMENTARIOS

Los siguientes comentarios se han extraído del mapa de caracteres original:

version: 1.0
repertoiremap: mnemonic,ds
 source: UNICODE 1.0
alias MS-ARAB

¡Tenga en cuenta que los alias que se muestran arriba no son necesariamente válidos!

NOMBRE

Locale::RecodeData::CP1256 - conjunto de datos para la codificación CP1256

SINOPSIS

    require Locale::RecodeData::CP1256;

DESCRIPCIÓN

Este módulo proporciona los datos de la tabla de mapeo para el conjunto de códigos CP1256 (Windows-1256).

CP1256 es una codificación de caracteres para el árabe.

Este módulo es utilizado por el módulo principal Locale::Recode. No debe ser llamado directamente.

COMENTARIOS

Este es un archivo de datos para el módulo Locale::Recode.
No se requiere ninguna acción especial por parte del usuario.
