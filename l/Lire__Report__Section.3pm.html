NOMBRE

Lire::Section - Interfaz al contenido del elemento de la sección.

SINOPSIS

my $section = Lire::ReportParser::ReportBuilder( "report.xml" );
foreach my $s ( $report->sections() ) {
    print "Sección: '", $s->title(), "' tiene ", scalar $s->subreports(),
        " subinformes en ella\n";
}

DESCRIPCIÓN

Esta clase ofrece una API a los elementos de sección de un informe Lire.

CONSTRUCTOR

nuevo( [$titulo] )

Crea una nueva Lire::Report::Section. El título de la sección se establecerá en el parámetro $titulo si está presente.

MÉTODOS DE OBJETO

título( [$titulo] )

Devuelve el título de la sección, si tiene uno. El título de la sección se cambiará a $titulo si se establece dicho parámetro.

descripción( [$descripción] )

Devuelve la descripción de esta sección. La descripción está codificada en XML DocBook.

Si se establece el parámetro $descripción, este método establecerá la descripción de esta sección a este nuevo valor. Si el parámetro $descripción es undef, se eliminará esa descripción.

subreports()

Devuelve los subinformes incluidos en esa sección. Será una matriz de objetos Lire::Report::Subreport.

agregar_subinforme( $subinforme )

Agrega un subinforme a este informe. El parámetro $subinforme debería ser un objeto Lire::Report::Subreport.

subinformes_por_tipo( $tipo )

Devuelve todos los subinformes de esta sección del tipo $tipo. El tipo del subinforme es el id de la especificación del informe utilizada para calcular los informes. Los subinformes se devuelven como una matriz de objetos Lire::Report::Subreport.
