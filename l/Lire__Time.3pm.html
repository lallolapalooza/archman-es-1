NOMBRE

Lire::Time - analiza e imprime fechas en formatos comunes en muchos archivos de registro.

SINOPSIS

use Lire::Time qw/ syslog2cal /;
my @ltime = localtime;
while ( <LOGFILE> ) {
    #...
    my $time = syslog2cal( $m, $d, $t, \@ltime );
}

DESCRIPCIÓN

Este módulo proporciona muchas funciones para analizar fechas en formatos que es probable que encuentre en los archivos de registro. También ofrece muchas funciones para formatear el tiempo de época en formatos útiles.

NOTA SOBRE LA EXPORTACIÓN DE FUNCIONES

Aunque todas las funciones documentadas se exportan por defecto al espacio de nombres del llamador, debe importar explícitamente las funciones que necesite, ya que la exportación por defecto no está recomendada por las directrices de los módulos de Perl.

FUNCIONES DE ANÁLISIS DE FECHAS

Este módulo incluye varias funciones que convierten entre un formato de fecha más legible para humanos y el tiempo de época UNIX. Todas las funciones de análisis devolverán el número de segundos transcurridos desde el 1 de enero de 1970 00:00:00 UTC y morirán() (se cerrarán con error) cuando se les pasen argumentos inválidos.

date2cal()

my $time = date2cal( $year, $month, $day, $time, [$timezone] );
my $time = date2cal( "2001 Mar 20 09:32:29 +0100" );

Esta función convertirá una fecha en el formato de salida predeterminado de date(1) a tiempo de época UNIX. La función acepta la fecha en una cadena o dividida por espacios en blanco. Si se omite el componente de zona horaria, se asume la zona horaria local (generalmente basada en el valor de la variable de entorno TZ).

syslog2cal()

my $time = syslog2cal( $month, $day, $time, $local_tm_ref );
my $time = syslog2cal( "Mar 11 13:21:00", $local_tm_ref );

Esta función convertirá una fecha en el formato de salida predeterminado de syslog a tiempo de época UNIX. La función acepta la fecha en una cadena o dividida por espacios en blanco.

Dado que el formato syslog no contiene información de zona horaria, se asume la zona horaria local (generalmente determinada por la variable de entorno TZ).

El último argumento es una referencia a una matriz devuelta por localtime().

my $local_tm_ref = [localtime()];

Se utiliza para determinar el año.

clf2cal()

my $time = clf2cal( "[18/Mar/2001:15:59:30 +0100]" );

Esta función convertirá una fecha tal como se encuentra en el Formato de Registro Común (Common Log Format) a tiempo de época UNIX.

FUNCIONES DE FORMATEO DE FECHAS

Este módulo incluye algunas funciones para convertir la fecha en tiempo de época UNIX a una salida más legible para humanos. Todas las funciones morirán() (se cerrarán con error) cuando se les pasen argumentos inválidos.

cal2rfc()

print cal2rfc( $time );

Esta función convertirá una fecha en tiempo de época UNIX al formato RFC822 (utilizado en correos electrónicos, por ejemplo). Una fecha RFC822 se ve así:

Wed, 30 May 2001 12:45:13 +0000

La especificación del desplazamiento de la zona horaria corresponderá a la zona horaria local (generalmente determinada por la variable de entorno TZ).

cal2ymdhms()

print cal2ymdhms( $time );

Esta función convierte una fecha en tiempo de época UNIX a una cadena del tipo:

YYYYMMDDHHMMSS

Esta representación corresponderá al tiempo en la zona horaria local (generalmente determinada por la variable de entorno TZ).

getMonthName()

print getMonthName( 0 ); # Devuelve 'Jan'

Esta función toma como parámetro un número (0-11) que representa el mes (como el devuelto por localtime(), por ejemplo) y devolverá el nombre abreviado en inglés de ese mes (Ene, Feb, etc.).
