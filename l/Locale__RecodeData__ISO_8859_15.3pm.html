Locale::RecodeData::ISO_8859_15(3pm)

NOMBRE

Locale::RecodeData::ISO_8859_15 - Recodificación para ISO-8859-15

SINOPSIS

    use Locale::RecodeData::ISO_8859_15;

DESCRIPCIÓN

Este módulo proporciona una tabla de recodificación para ISO-8859-15 (Latin-9). Se utiliza por el módulo Locale::Recode.

COMENTARIOS

ISO-8859-15 es una extensión de ISO-8859-1, diseñada para incluir el símbolo del Euro (€) y otros caracteres de uso común en Europa Occidental.
