List::AllUtils(3) Documentación de paquetes contribuidos en Perl List::AllUtils(3)

NOMBRE

List::AllUtils - Combina List::Util, List::SomeUtils y List::UtilsBy en un paquete de tamaño reducido

VERSION

versión 0.19

SYNOPSIS

use List::AllUtils qw( primero cualquier );
# _Todo_ de List::Util, List::SomeUtils y List::UtilsBy
use List::AllUtils qw( :all );
my @numeros = ( 1, 2, 3, 5, 7 );
# o no importar nada
return List::AllUtils::primero { $_ > 5 } @numeros;

DESCRIPCIÓN

¿Te estás cansando de recordar si una particular ayuda está definida en List::Util, List::SomeUtils o List::UtilsBy? Claro que sí. Ahora no tendrás que recordar. Este módulo exportará todas las funciones que estos tres módulos definen.

Nota: La documentación de todas las funciones ha sido copiada sin remordimiento de List::Util, List::SomeUtils y List::UtilsBy.

¿Cuál es el ganador?

Recientemente, List::Util ha comenzado a incluir algunos de los subs que solían estar únicamente en List::SomeUtils. De manera similar, List::SomeUtils tiene algunos pequeños puntos de sobreposición con List::UtilsBy.

"List::AllUtils" siempre favorece la subrutina proporcionada por List::Util, List::SomeUtils o List::UtilsBy en el orden de preferencia. Sin embargo, desde List::Util 1.56, incluyó algunas funciones, "mesh" y "zip", con el mismo nombre que las funciones de List::SomeUtils, pero con comportamiento diferente.

Por lo tanto, a partir de ahora, siempre preferiremos la compatibilidad retro. Esto significa que "mesh" y "zip" siempre veniderán de List::SomeUtils. Si otras funciones incompatibles se añadieran a List::Util, también se las omitirán en favor de la versión de List::SomeUtils.

Las notas debajo provienen de List::Util 1.56, List::SomeUtils 0.58 y List::UtilsBy 0.11.

¿Qué se exporta?

Todo este módulo hace es lo siguiente: carga List::Util, List::SomeUtils y List::UtilsBy, y luego reexporta todo lo que ellos ofrecen. Esto significa que, independientemente de la documentación debajo, obtendrás cualquier subrutina que tu versión instalada proporcione.

FUNCIONES_DE_REDUCCIÓN_DE_LISTAS

Las siguientes funciones aplican un bloque de código a una lista de valores.

reduce

$resultado = reduce { BLOCK } @lista

Reduce @lista llamando a "BLOCK" en contexto escalar varias veces, estableciendo $a y $b cada vez. La primera llamada tendrá $a y $b establecidos en los primeros dos elementos de la lista, y las llamadas posteriores se realizarán cambiando $a al resultado de la llamada previa y $b al siguiente elemento de la lista.

Devuelve el resultado de la última llamada a "BLOCK". Si @lista está vacío, se devuelve "undef". Si @lista tiene solo un elemento, se devuelve dicho elemento y "BLOCK" no se ejecuta.

Los siguientes ejemplos muestran cómo "reduce" podría usarse para implementar las otras funciones de reducción de lista en este módulo. (No se implementan de hecho así, pero de forma más eficiente en funciones C individuales).

$foo = reduce { definido($a) ? $a :
                $codigo-(local $_ = $b) ? $b :
                                         undef } undef, @lista # primer
$foo = reduce { $a > $b ? $a : $b } 1..10       # máximo
$foo = reduce { $a gt $b ? $a : $b } 'A'..'Z'   # máximostr
$foo = reduce { $a < $b ? $a : $b } 1..10       # mínimo
$foo = reduce { $a lt $b ? $a : $b } 'aa'..'zz' # mínimostr
$foo = reduce { $a + $b } 1 .. 10               # suma
$foo = reduce { $a . $b } @bar                  # concatenar
$foo = reduce { $a || $codigo-(local $_ = $b) } 0, @bar   # cualquier
$foo = reduce { $a && $codigo-(local $_ = $b) } 1, @bar   # todos
$foo = reduce { $a && !$codigo-(local $_ = $b) } 1, @bar  # ninguno
$foo = reduce { $a || !$codigo-(local $_ = $b) } 0, @bar  # no todos
   # Nota que estos implementaciones no completamente cortan en brecha

Si tu algoritmo requiere que "reduce" produzca un valor identidad, asegúrate de pasar siempre ese valor identidad como primer argumento para evitar que se devuelva "undef".

$foo = reduce { $a + $b } 0, @valores;             # suma con valor identidad 0

Los ejemplos de código anteriores también sugieren cómo usar "reduce" para construir una versión más eficiente de una de estas funciones básicas combinada con un bloque de "map". Por ejemplo, para encontrar la longitud total de todas las strings en una lista, podríamos usar

$total = sum map { length } @strings;

Sin embargo, este produce un lista de valores temporales enteros de longitud como la lista original de strings, solo para reducirlo a un solo valor de nuevo. Podemos calcular el mismo resultado más eficientemente usando "reduce" con un bloque que acumule las longitudes escribiendo esto como:

$total = reduce { $a + length $b } 0, @strings

Las otras funciones de reducción de listas son especializaciones de esta idea general.

reductions

@resultados = reductions { BLOCK } @lista

Desde la versión 1.54.

Similar a "reduce", salvo que también devuelve los valores intermedios junto con el resultado final. Como antes, $a se establece en el primer elemento de la lista dada, y el bloque se llama una vez para cada elemento restante en la lista, con el resultado capturado para devolver como también el nuevo valor para $a.

La lista devuelta comenzará con el valor inicial de $a, seguido por cada valor devuelto por el bloque en orden. El valor final del resultado será idéntico al del resultado que el funcionamiento "reduce" hubiera devuelto dado el mismo bloque y lista.

reduce     { "$a-$b" } "a".."d"    # "a-b-c-d"
reductions { "$a-$b" } "a".."d"    # "a", "a-b", "a-b-c", "a-b-c-d"

any

my $bool = any { BLOCK } @lista;

Desde la versión 1.33.

Similar a "grep" en que evalúa "BLOCK" estableciendo $_ a cada elemento de @lista en orden. "any" devuelve true si algún elemento hace que "BLOCK" devuelva un valor verdadero. Si "BLOCK" nunca devuelve verdadero o @lista está vacía, devuelve false.

Muchas ocasiones de usar "grep" en condiciones pueden ser escritas usando "any" ya que puede cortar en brecha después del primer resultado verdadero.

if( any { length > 10 } @strings ) {
    # al menos un string tiene más de 10 caracteres
}

Nota: Debido a problemas de XS, el bloque pasado puede acceder directamente a @_ externo. Esto no es intencional y puede causar problemas en el debugger.

all

my $bool = all { BLOCK } @lista;

Desde la versión 1.33.

Similar a "any", pero requiere que todos los elementos de @lista hagan que "BLOCK" devuelva verdadero. Si algún elemento devuelve falso, devuelve falso. Si el "BLOCK" nunca devuelve falso o @lista está vacía, devuelve verdadero.

none

my $bool = none { BLOCK } @lista;

Desde la versión 1.33.

Es lo opuesto a "any". Devuelve verdadero si ningún elemento hace que "BLOCK" devuelva verdadero. Si "BLOCK" alguna vez devuelve verdadero o @lista está vacía, devuelve falso.

Esto es lo mismo que !any { BLOCK } @lista, pero puede ser más explícito.

not_any

my $bool = not_any { BLOCK } @lista;

Desde la versión 1.33.

Equivalente a none { BLOCK } @lista.

first

my $elem = first { BLOCK } @lista;

Desde la versión 1.33.

Devuelve el primer elemento de @lista para el que el bloque evalúa a verdadero. Devuelve "undef" si el bloque nunca evalúa a verdadero, o si la lista está vacía.

Si necesitas distinguir entre un "undef" devuelto por el bloque y un "undef" que indica no se encontró nada, puedes usar "firstidx" en su lugar.

my $s = first { /^\s*$/ } @lines; # El primer elemento de línea vacío, o undef

firstidx

my $idx = firstidx { BLOCK } @lista;

Desde la versión 1.41.

Devuelve el índice del primer elemento de @lista para el que el bloque evalúa a verdadero. Devuelve -1 si el bloque nunca evalúa a verdadero, o si la lista está vacía.

my $i = firstidx { $_ > 100 } @values;
if ( $i == -1 ) {
    print "No value over 100 found\n";
} else {
    print "Value $values[$i] found at index $i\n";
}

last

my $elem = last { BLOCK } @lista;

Desde la versión 1.33.

Devuelve el último elemento de @lista para el que el bloque evalúa a verdadero. Devuelve "undef" si el bloque nunca evalúa a verdadero, o si la lista está vacía.

Si necesitas distinguir entre un "undef" devuelto por el bloque y un "undef" que indica no se encontró nada, puedes usar "lastidx" en su lugar.

lastidx

my $idx = lastidx { BLOCK } @lista;

Desde la versión 1.41.

Devuelve el índice del último elemento de @lista para el que el bloque evalúa a verdadero. Devuelve -1 si el bloque nunca evalúa a verdadero, o si la lista está vacía.

grep

my @elems = grep { BLOCK } @lista;

Esta es la subrutina grep estándar, pero en una forma que está garantizada para ser rápida, ya que está implementada en C.

map

my @elems = map { BLOCK } @lista;

Esta es la subrutina map estándar, pero en una forma que está garantizada para ser rápida, ya que está implementada en C.

max

my $max = max @lista;

Devuelve el elemento más grande de @lista.

max 1, 3, 2 # 3

Devuelve "undef" si la lista está vacía.

En caso de empate, se devuelve el primer valor máximo encontrado.

min

my $min = min @lista;

Devuelve el elemento más pequeño de @lista.

min 1, 3, 2 # 1

Devuelve "undef" si la lista está vacía.

En caso de empate, se devuelve el primer valor mínimo encontrado.

sum

my $sum = sum @lista;

Devuelve la suma de los elementos de @lista.

sum 1, 2, 3 # 6

Devuelve 0 si la lista está vacía.

product

my $prod = product @lista;

Devuelve el producto de los elementos de @lista.

product 1, 2, 3 # 6

Devuelve 1 si la lista está vacía.

shuffle

my @shuffled = shuffle @lista;

Desde la versión 1.33.

Devuelve una copia aleatoria de @lista.

shuffle 1..5 # (alguna permutación de 1, 2, 3, 4, 5)

uniq

my @unique = uniq @lista;

Desde la versión 1.46.

Devuelve una lista que contiene solo los elementos únicos de @lista, en el orden en que aparecieron por primera vez.

uniq 1, 2, 1, 3, 2, 4 # (1, 2, 3, 4)

zip

my @zipped = zip @lists;

Desde la versión 1.56 (List::SomeUtils).

Toma una o más listas y devuelve una lista de tuplas, donde la n-ésima tupla contiene los elementos n-ésimos de cada una de las listas de entrada.

zip 1..3, a..c           # (1, 'a'), (2, 'b'), (3, 'c')
zip 1..5, a..c           # (1, 'a'), (2, 'b'), (3, 'c')
zip 1..3, a..e           # (1, 'a'), (2, 'b'), (3, 'c')

Si las listas tienen longitudes diferentes, la lista resultante se trunca a la longitud de la lista más corta.

mesh

my @meshed = mesh @lists;

Desde la versión 1.56 (List::SomeUtils).

Similar a "zip", pero si las listas de entrada tienen longitudes diferentes, la lista resultante se extiende a la longitud de la lista más larga, rellenando con "undef" donde sea necesario.

mesh 1..5, a..c           # (1, 'a'), (2, 'b'), (3, 'c'), (4, undef), (5, undef)
mesh 1..3, a..e           # (1, 'a'), (2, 'b'), (3, 'c'), (undef, 'd'), (undef, 'e')

runlength_encode

my @encoded = runlength_encode @list;

Desde la versión 1.40.

Codifica una lista en el formato de codificación por longitud de ejecución. Por ejemplo:

runlength_encode a, a, a, b, c, c, d, d, d, d

devuelve

(a, 3, b, 1, c, 2, d, 4)

Si la lista de entrada está vacía, se devuelve una lista vacía.

runlength_decode

my @decoded = runlength_decode @list;

Desde la versión 1.40.

Decodifica una lista que ha sido codificada por longitud de ejecución.

runlength_decode a, 3, b, 1, c, 2, d, 4

devuelve

(a, a, a, b, c, c, d, d, d, d)

Si la lista de entrada está vacía, se devuelve una lista vacía.

Si la lista de entrada tiene una longitud impar, el último elemento se ignora.

FUNCIONES_DE_LISTA_PARA_VOCABULARIO

maxstr

my $max = maxstr @lista;

Devuelve el elemento más grande lexicográficamente de @lista.

maxstr 'a', 'c', 'b' # 'c'

Devuelve "undef" si la lista está vacía.

En caso de empate, se devuelve el primer valor máximo encontrado.

minstr

my $min = minstr @lista;

Devuelve el elemento más pequeño lexicográficamente de @lista.

minstr 'a', 'c', 'b' # 'a'

Devuelve "undef" si la lista está vacía.

En caso de empate, se devuelve el primer valor mínimo encontrado.

FUNCIONES_DE_FILTRO_DE_LISTAS

uniqstr

my @unique = uniqstr @lista;

Desde la versión 1.46.

Similar a "uniq", pero usa una comparación lexicográfica para determinar la unicidad.

uniqstr a, b, A, c, B, a # (a, b, A, c, B)

delete_one

my @list = delete_one { BLOCK } @list;

Desde la versión 1.33.

Elimina la primera ocurrencia del elemento para el cual el bloque devuelve verdadero.

delete_one { $_ eq 'c' } a, b, c, d, c # (a, b, d, c)

Si el bloque nunca devuelve verdadero, o si la lista está vacía, se devuelve una copia de la lista original.

delete_all

my @list = delete_all { BLOCK } @list;

Desde la versión 1.33.

Elimina todas las ocurrencias de los elementos para los cuales el bloque devuelve verdadero.

delete_all { $_ eq 'c' } a, b, c, d, c # (a, b, d)

Si el bloque nunca devuelve verdadero, o si la lista está vacía, se devuelve una copia de la lista original.

FUNCIONES_DE_AGRUPACIÓN_DE_LISTAS

bucket

my %buckets = bucket { BLOCK } @list;

Desde la versión 1.33.

Agrupa los elementos de @list en cubos basados en el valor devuelto por el bloque. El bloque se llama para cada elemento de la lista, y el valor que devuelve se utiliza como clave en el hash de cubos devuelto.

my @numeros = ( 1, 2, 3, 4, 5, 6 );
my %par_impar = bucket { $_ % 2 ? 'impar' : 'par' } @numeros;
# %par_impar = ( impar => [1, 3, 5], par => [2, 4, 6] )

group_by

my %groups = group_by { BLOCK } @list;

Desde la versión 1.33.

Similar a "bucket", pero agrupa los elementos en listas. El bloque se llama para cada elemento, y el valor devuelto se usa como clave en el hash devuelto. Los valores de las listas se anexan a la lista asociada con la clave.

my @nombres = qw( Alice Bob Charlie );
my %longitudes = group_by { length } @nombres;
# %longitudes = ( 5 => ['Alice'], 3 => ['Bob'], 7 => ['Charlie'] )

OTRAS_FUNCIONES_DE_UTILIDAD_DE_LISTAS

firstdefined

my $defined = firstdefined @lista;

Devuelve el primer valor definido de la lista.

firstdefined undef, 0, undef, 1 # 0

firstfalse

my $false = firstfalse @lista;

Devuelve el primer valor falso de la lista.

firstfalse 1, 1, 0, 1 # 0

firsttrue

my $true = firsttrue @lista;

Devuelve el primer valor verdadero de la lista.

firsttrue 0, undef, 1, 0 # 1

natorder

my $result = natorder $str1, $str2;

Compara dos strings de forma natural, es decir, trata los números dentro de los strings como números.

natorder 'img10.png', 'img2.png' # -1 (img2.png viene antes)

Esto es útil para ordenar listas de nombres de archivo que contienen números.

my @archivos = sort natorder @lista_de_archivos;

natcaseorder

my $result = natcaseorder $str1, $str2;

Similar a "natorder", pero ignora mayúsculas/minúsculas.

pairs

my @pairs = pairs @list;

Devuelve una lista de parejas de elementos adyacentes de @list.

pairs 1, 2, 3, 4, 5 # (1, 2), (2, 3), (3, 4), (4, 5)

Si la lista tiene un número impar de elementos, el último elemento se ignora.

pairs_symetric

my @pairs = pairs_symetric @list;

Devuelve una lista de parejas simétricas de elementos de @list.

pairs_symetric 1, 2, 3, 4 # (1, 2), (1, 3), (1, 4), (2, 3), (2, 4), (3, 4)

slides

my @slides = slides $n, @list;

Devuelve una lista de "diapositivas" de longitud $n de @list.

slides 3, 1..5 # (1, 2, 3), (2, 3, 4), (3, 4, 5)

cat

my $string = cat @strings;

Concatena una lista de strings en una sola string.

cat 'a', 'b', 'c' # 'abc'

Devuelve una string vacía si la lista está vacía.

mix

my @mixed = mix @lista;

Devuelve una lista donde los elementos de @lista están intercalados con elementos de @{[ list ]}.

mix 1, 2, 3, 4 # Devuelve una lista aleatoria de 1, 2, 3, 4

Esto es para usar en contextos donde necesitas que la lista devuelta sea aleatoria.

throttle

my @throttled = throttle @lista;

Devuelve una lista de elementos de @lista que se repiten como máximo una vez.

throttle 1, 1, 2, 2, 3, 3 # (1, 2, 3)

FUNCIONES DE LISTA

Estas funciones proporcionan utilidades para operar sobre listas de valores. Para la mayoría de ellas, el último valor de la lista se evalúa en contexto escalar, y los demás en contexto de lista.

Nota: Debido a problemas con XS, el bloque pasado puede acceder directamente a @_ externo. Esto no es intencional y fallará bajo el depurador.

none

my $bool = none { BLOCK } @list;
my $bool = notall { BLOCK } @list;

Desde la versión 1.33.

Similar a "any" y "all", pero con el sentido de retorno invertido. "none" devuelve verdadero solo si ningún valor en @list hace que el "BLOCK" devuelva verdadero, y "notall" devuelve verdadero solo si no todos los valores lo hacen.

Nota: Debido a problemas con XS, el bloque pasado puede acceder directamente a @_ externo. Esto no es intencional y fallará bajo el depurador.

first

my $val = first { BLOCK } @list;

Similar a "grep" en que evalúa "BLOCK" estableciendo $_ a cada elemento de @list en turno. "first" devuelve el primer elemento para el cual el resultado de "BLOCK" es un valor verdadero. Si "BLOCK" nunca devuelve verdadero o @list estaba vacío, entonces se devuelve "undef".

$foo = first { defined($_) } @list    # primer valor definido en @list
$foo = first { $_ > $value } @list    # primer valor en @list que
                                      # es mayor que $value

max

my $num = max @list;

Devuelve la entrada en la lista con el valor numérico más alto. Si la lista está vacía, se devuelve "undef".

$foo = max 1..10                # 10
$foo = max 3,9,12               # 12
$foo = max @bar, @baz           # lo que sea

maxstr

my $str = maxstr @list;

Similar a "max", pero trata todas las entradas de la lista como cadenas y devuelve la cadena más alta según lo definido por el operador "gt". Si la lista está vacía, se devuelve "undef".

$foo = maxstr 'A'..'Z'          # 'Z'
$foo = maxstr "hello","world"   # "world"
$foo = maxstr @bar, @baz        # lo que sea

min

my $num = min @list;

Similar a "max" pero devuelve la entrada en la lista con el valor numérico más bajo. Si la lista está vacía, se devuelve "undef".

$foo = min 1..10                # 1
$foo = min 3,9,12               # 3
$foo = min @bar, @baz           # lo que sea

minstr

my $str = minstr @list;

Similar a "min", pero trata todas las entradas de la lista como cadenas y devuelve la cadena más baja según lo definido por el operador "lt". Si la lista está vacía, se devuelve "undef".

$foo = minstr 'A'..'Z'          # 'A'
$foo = minstr "hello","world"   # "hello"
$foo = minstr @bar, @baz        # lo que sea

product

my $num = product @list;

Desde la versión 1.35.

Devuelve el producto numérico de todos los elementos de @list. Si @list está vacía, se devuelve 1.

$foo = product 1..10            # 3628800
$foo = product 3,9,12           # 324

sum

my $num_or_undef = sum @list;

Devuelve la suma numérica de todos los elementos de @list. Por compatibilidad hacia atrás, si @list está vacía, se devuelve "undef".

$foo = sum 1..10                # 55
$foo = sum 3,9,12               # 24
$foo = sum @bar, @baz           # lo que sea

sum0

my $num = sum0 @list;

Desde la versión 1.26.

Similar a "sum", excepto que este devuelve 0 cuando se le da una lista vacía, en lugar de "undef".

FUNCIONES DE LISTAS DE PARES CLAVE/VALOR

El siguiente conjunto de funciones, todas inspiradas en List::Pairwise, consume una lista de tamaño par de pares. Los pares pueden ser asociaciones clave/valor de un hash, o simplemente una lista de valores. Las funciones preservarán el orden original de los pares, y no se confundirán por múltiples pares que tengan el mismo valor de "clave" - ni siquiera requieren que la primera de cada par sea una cadena simple.

NOTA: En el momento de escribir esto, las siguientes funciones "pair*" que toman un bloque no modifican el valor de $_ dentro del bloque, y en su lugar operan utilizando las variables globales $a y $b. Este ha resultado ser un diseño pobre, ya que impide la capacidad de proporcionar una función "pairsort". Sería mejor pasar objetos tipo par como referencias de array de 2 elementos en $_, en un estilo similar al valor de retorno de la función "pairs". En alguna versión futura este comportamiento puede ser añadido.

Hasta entonces, se advierte a los usuarios que **NO** dependan del valor de $_ que permanezca sin modificar entre el exterior y el interior del bloque de control. En particular, el siguiente ejemplo **NO ES SEGURO**:

my @kvlist = ...
foreach (qw( some keys here )) {
   my @items = pairgrep { $a eq $_ } @kvlist;
   ...
}

Uniones (Junctions)

Tratamiento de una lista vacía

Existen dos corrientes de pensamiento sobre cómo evaluar una unión en una lista vacía:

  • Reducción a una identidad (booleana)
  • El resultado no está definido (lógica trivaluada)

En el primer caso, el resultado de la unión aplicada a la lista vacía se determina por una reducción matemática a una identidad, dependiendo de si la comparación subyacente es "o" o "y". Conceptualmente:

                "algún es verdadero" "todos son verdaderos"
                --------------      --------------
2 elementos:    A || B || 0         A && B && 1
1 elemento:     A || 0              A && 1
0 elementos:    0                   1

En el segundo caso, se desea lógica trivaluada, en la cual una unión aplicada a una lista vacía devuelve "undef" en lugar de verdadero o falso.

Las uniones con un sufijo "_u" implementan lógica trivaluada. Las que no lo tienen son booleanas.

all BLOCK LIST

all_u BLOCK LIST

Devuelve un valor verdadero si todos los elementos en LIST cumplen el criterio dado a través de

h BLOCK. Establece <span class="Li">$_</span> para cada elemento en LIST en orden:

print "Todos los valores son no negativos"
  if all { $_ >= 0 } ($x, $y, $z);

Para una LISTA vacía, <span class="Li">"all"</span> devuelve verdadero (es decir, ningún valor falló la condición) y <span class="Li">"all_u"</span> devuelve <span class="Li">"undef"</span>.

Por lo tanto, <span class="Li">all_u(@list)</span> es equivalente a <span class="Li">"@list ? all(@list) : undef"</span>.

Nota: como Perl trata <span class="Li">"undef"</span> como falso, debes verificar el valor de retorno de <span class="Li">"all_u"</span> con <span class="Li">"defined"</span> o obtendrás el resultado opuesto al que esperas.

apply BLOCK LIST

Crea una copia de la lista y luego pasa cada elemento _desde la copia_ a BLOCK. Cualquier cambio o asignación a <span class="Li">$_</span> en BLOCK solo afectará a los elementos de la nueva lista. Sin embargo, si <span class="Li">$_</span> es una referencia, los cambios en el valor referenciado se verán tanto en la lista original como en la nueva.

Esta función es similar a <span class="Li">"map"</span> pero no modificará los elementos de la lista de entrada:

my @list = (1 .. 4);
my @mult = apply { $_ *= 2 } @list;
print "@list\n";
print "@mult\n";
__END__
@list = 1 2 3 4
@mult = 2 4 6 8

Piénsalo como azúcar sintáctico para

for (my @mult = @list) { $_ *= 2 }

Ten en cuenta que debes alterar <span class="Li">$_</span> directamente dentro de BLOCK para que los cambios tengan efecto. Los nuevos valores devueltos desde BLOCK se ignoran:

# @new es idéntico a @list.
my @new = apply { $_ * 2 } @list;
# @new es diferente de @list
my @new = apply { $_ =* 2 } @list;

Evalúa BLOCK para cada par de elementos en ARRAY1 y ARRAY2 y devuelve una nueva lista que consiste en los valores de retorno de BLOCK. Los dos elementos se establecen en <span class="Li">$a</span> y <span class="Li">$b</span>. @a = (1 .. 5);

@a = qw/a b c/;

@x = pairwise { ($a, $b) } @a, @b;    # devuelve a, 1, b, 2, c, 3

Particiona LIST basándose en el valor de retorno de BLOCK, que denota en qué partición se coloca el valor actual.

Devuelve una lista de las particiones así creadas. Cada partición creada es una referencia a un array.

my $i = 0;

my @part = part { 2 } 1 .. 10;            # devuelve undef, undef, [ 1 .. 10 ]

my @part = part { -1 } 1 .. 10;

my @idx  = ( 0, 1, -1 );

Iteración

each_array ARRAY1 ARRAY2 ...

Crea un iterador de arrays para devolver los elementos de la lista de arrays ARRAY1, ARRAY2 ... ARRAYn en orden. Es decir, la primera vez que se llama, devuelve el primer elemento de cada array. La siguiente vez, devuelve los segundos elementos. Y así sucesivamente, hasta que todos los elementos se agoten.

Creates an array iterator, for looping over an array. Each call to the iterator returns the next element of the array. Sorting

sort_by BLOCK LIST

Returns the list of values sorted according to the string values returned by the KEYFUNC block or function. A typical use of this may be to sort objects according to the string value of some accessor, such as

sort_by { $_->name } @people

The key function is called in scalar context, being passed each value in turn as both $_ and the only argument in the parameters, @_. The values are then sorted according to string comparisons on the values returned. This is equivalent to

sort { $a->name cmp $b->name } @people

except that it guarantees the name accessor will be executed only once per value. One interesting use-case is to sort strings which may have numbers embedded in them "naturally", rather than lexically.

sort_by { s/(\d+)/sprintf "%09d", $1/eg; $_ } @strings

This sorts strings by generating sort keys which zero-pad the embedded numbers to some level (9 digits in this case), helping to ensure the lexical sort puts them in the correct order.

nsort_by BLOCK LIST

Similar to sort_by but compares its key values numerically.

Counting and calculation

true BLOCK LIST

Counts the number of elements in LIST for which the criterion in BLOCK is true. Sets $_ for each item in LIST in turn:

printf "%i item(s) are defined", true { defined($_) } @list;

false BLOCK LIST

Counts the number of elements in LIST for which the criterion in BLOCK is false. Sets $_ for each item in LIST in turn:

printf "%i item(s) are not defined", false { defined($_) } @list;

minmax LIST

Calculates the minimum and maximum of LIST and returns a two element list with the first element being the minimum and the second the maximum. Returns the empty list if LIST was empty.

The "minmax" algorithm differs from a naive iteration over the list where each element is compared to two values being the so far calculated min and max value in that it only requires 3n/2 - 2 comparisons. Thus it is the most efficient possible algorithm.

However, the Perl implementation of it has some overhead simply due to the fact that there are more lines of Perl code involved. Therefore, LIST needs to be fairly big in order for "minmax" to win over a naive implementation. This limitation does not apply to the XS version.

mode LIST

Calculates the most common items in the list and returns them as a list. This is effectively done by string comparisons, so references will be stringified. If they implement string overloading, this will be used.

If more than one item appears the same number of times in the list, all such items will be returned. For example, the mode of a unique list is the list itself.

This function returns a list in list context. In scalar context it returns a count indicating the number of modes in the list.

sort_by

@vals = sort_by { KEYFUNC } @vals

Returns the list of values sorted according to the string values returned by the "KEYFUNC" block or function. A typical use of this may be to sort objects according to the string value of some accessor, such as

sort_by { $_->name } @people

The key function is called in scalar context, being passed each value in turn as both $_ and the only argument in the parameters, @_. The values are then sorted according to string comparisons on the values returned.

This is equivalent to

sort { $a->name cmp $b->name } @people

excepto que garantiza que el accesorio "name" se ejecutará solo una vez por valor.

Un caso de uso interesante es ordenar cadenas que pueden tener números incrustados en ellas "naturalmente", en lugar de léxicamente.

sort_by { s/(\d+)/sprintf "%09d", $1/eg; $_ } @strings

Esto ordena cadenas generando claves de ordenación que rellenan con ceros los números incrustados hasta cierto nivel (9 dígitos en este caso), ayudando a asegurar que el ordenamiento léxico los coloque en el orden correcto.

zip_by

@vals = zip_by { ITEMFUNC } \@arr0, \@arr1, \@arr2,...

Devuelve una lista de cada uno de los valores devueltos por el bloque de función, cuando se invoca con valores de cada una de las referencias a ARRAY dadas. Cada valor en la lista devuelta será el resultado de que la función se haya invocado con argumentos en esa posición, de cada una de las arrays dadas.

my @transposition = zip_by { [ @_ ] } @matrix;
my @names = zip_by { "$_[1], $_[0]" } \@firstnames, \@surnames;
print zip_by { "$_[0] => $_[1]\n" } [ keys %hash ], [ values %hash ];

Si algunas de las arrays son más cortas que otras, la función se comportará como si tuvieran "undef" en las posiciones finales. Las dos líneas siguientes son equivalentes:

zip_by { f(@_) } [ 1, 2, 3 ], [ "a", "b" ]
f( 1, "a" ), f( 2, "b" ), f( 3, undef )

La función de ítem es llamada por "map", así que si devuelve una lista, la lista completa se incluye en el resultado. Esto puede ser útil, por ejemplo, para generar un hash a partir de dos listas separadas de claves y valores

my %nums = zip_by { @_ } [qw( one two three )], [ 1, 2, 3 ];
# %nums = ( one => 1, two => 2, three => 3 )

(Una función que tiene este comportamiento a veces se llama "zipWith", por ejemplo en Haskell, pero ese nombre no encajaría con el esquema de nombres utilizado por este módulo).

$arr0, $arr1, $arr2, ... = unzip_by { ITEMFUNC } @vals

Desde la versión 0.09.

Devuelve una lista de referencias a ARRAY que contienen los valores devueltos por el bloque de función, cuando se invoca para cada uno de los valores dados en la lista de entrada. Cada una de las referencias a ARRAY devueltas contendrá los valores devueltos en esa posición correspondiente por el bloque de función. Es decir, la primera referencia a ARRAY devuelta contendrá todos los valores devueltos en la primera posición por el bloque de función, la segunda contendrá todos los valores de la segunda posición, y así sucesivamente.

extract_by

@vals = extract_by { SELECTFUNC } @arr

Desde la versión 0.05.

Elimina elementos del array referenciado en el que la función de selección devuelve verdadero, y devuelve una lista que contiene esos elementos. Esta función es similar a "grep", excepto que modifica el array referenciado para eliminar los valores seleccionados de él, dejando solo los no seleccionados.

my @red_balls = extract_by { $_->color eq "red" } @balls;
# Ahora no hay bolas rojas en el array @balls

Esta función modifica un array real, a diferencia de la mayoría de las otras funciones de este módulo. Debido a esto, requiere un array real, no solo una lista.

Esta función se implementa invocando "splice" en el array, no construyendo una nueva lista y asignándola. Un resultado de esto es que las referencias débiles no se verán perturbadas.

extract_by { !defined $_ } @refs;

dejará referencias débiles debilitadas en el array @refs, mientras que

@refs = grep { defined $_ } @refs;

las fortalecerá a todas de nuevo.

$val = extract_first_by { SELECTFUNC } @arr

Desde la versión 0.10.

Un híbrido entre "extract_by" y "List::Util::first". Elimina el primer elemento del array referenciado en el que la función de selección devuelve verdadero, devolviéndolo.

Al igual que con "extract_by", esta función requiere un array real y no solo una lista, y también se implementa utilizando "splice" para que las referencias débiles no se vean perturbadas.

Si esta función no encuentra un elemento coincidente, devolverá una lista vacía en contexto de lista. Esto permite al llamador distinguir el caso entre ningún elemento coincidente y que el primer elemento coincidente sea "undef".

La probabilidad de que cada elemento sea devuelto primero se distribuirá con la distribución de los pesos, y así sucesivamente recursivamente para los elementos restantes.
