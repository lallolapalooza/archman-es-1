TableInfo(3pm) Documentación de Lire::Report TableInfo(3pm)

NOMBRE

Lire::Report::TableInfo - Objeto que contiene toda la información de Grupo y Columna para un subinforme

SINOPSIS

my $info = $subreport->table_info;
my $col_info = $info->colum_info( "request_total" );

DESCRIPCIÓN

El objeto Lire::Report::TableInfo contiene los objetos ColumnInfo y GroupInfo para un subinforme.

CONSTRUCTOR

new()

Crea un nuevo objeto Lire::Report::TableInfo.

column_info_by_name( $name )

Devuelve el objeto Lire::Report::ColumnInfo que tiene el nombre $name.

A diferencia del método en Lire::Report::GroupInfo, este lanzará una excepción si no hay una columna llamada $name.

column_info_by_col_start( $idx )

Devuelve el objeto Lire::Report::ColumnInfo que comienza en el índice de columna $idx.

A diferencia del método en Lire::Report::GroupInfo, este lanzará una excepción si esta columna está fuera de los límites.

group_info( $name )

Devuelve el objeto Lire::Report::GroupInfo que tiene el nombre $name.

A diferencia del método en Lire::Report::GroupInfo, este lanzará una excepción si no hay una columna llamada $name.

ncols()

Devuelve el número de columnas que hay en esta tabla.

column_infos()

Devuelve un array que contiene todas las columnas de la tabla. Cada elemento es un objeto Lire::Report::ColumnInfo.

groups()

Devuelve un array que contiene todos los grupos de la tabla. Cada elemento es un objeto Lire::Report::GroupInfo.

columns_width()

Devuelve un array donde cada elemento representa el ancho sugerido de las columnas en caracteres.

header_rows()

Devuelve una referencia a un array que contiene una referencia a un array por cada fila en la cabecera. Cada fila contiene la ColumnInfo que debe aparecer en la línea de cabecera. Los índices de la columna son siempre iguales al inicio de su columna. La primera fila contiene todas las columnas numéricas y las columnas categóricas aparecen según su anidamiento.

set_variables_indices()

Registra las variables de este TableInfo usando Lire::Config::VariableIndex.

reset_variable_indices()

Elimina los índices de las variables. Esto se puede llamar para deshacer el efecto de set_variables_indices().
