NOMBRE

Log::Log4perl::Filter::Boolean - Filtro especial para combinar los resultados de otros

SINOPSIS

log4perl.logger = WARN, AppWarn, AppError
log4perl.filter.Match1       = sub { /dejar pasar esto/ }
log4perl.filter.Match2       = sub { /y eso también/ }
log4perl.filter.MyBoolean       = Log::Log4perl::Filter::Boolean
log4perl.filter.MyBoolean.logic = Match1 || Match2
log4perl.appender.Screen        = Log::Dispatch::Screen
log4perl.appender.Screen.Filter = MyBoolean
log4perl.appender.Screen.layout = Log::Log4perl::Layout::SimpleLayout

DESCRIPCIÓN

A veces, es útil combinar los resultados de varios filtros para llegar a una decisión de registrar/no registrar. Mientras que Log4j, la nave nodriza de Log4perl, optó por implementar esta característica como una cadena de filtros, similar a las cadenas IP de Linux, Log4perl intenta un enfoque diferente.

Típicamente, los resultados de los filtros no necesitarán pasarse en cadenas, sino que se combinarán de manera programática utilizando lógica booleana. "Registrar si este filtro dice 'sí' y ese filtro dice 'no'" es un requisito bastante común pero difícil de implementar como una cadena.

"Log::Log4perl::Filter::Boolean" es un filtro personalizado predefinido especial para Log4perl que combina los resultados de otros filtros personalizados de maneras arbitrarias, utilizando expresiones booleanas:

log4perl.logger = WARN, AppWarn, AppError
log4perl.filter.Match1       = sub { /dejar pasar esto/ }
log4perl.filter.Match2       = sub { /y eso también/ }
log4perl.filter.MyBoolean       = Log::Log4perl::Filter::Boolean
log4perl.filter.MyBoolean.logic = Match1 || Match2
log4perl.appender.Screen        = Log::Dispatch::Screen
log4perl.appender.Screen.Filter = MyBoolean
log4perl.appender.Screen.layout = Log::Log4perl::Layout::SimpleLayout

"Log::Log4perl::Filter::Boolean"'s las expresiones booleanas permiten combinar diferentes appenders por nombre utilizando AND (&& o &), OR (|| o |) y NOT (!) como expresiones lógicas. Los paréntesis se utilizan para agrupar. La precedencia sigue la estándar de Perl. Aquí hay una serie de ejemplos:

Match1 && !Match2            # Match1 y no Match2
!(Match1 || Match2)          # Ni Match1 ni Match2
(Match1 && Match2) || Match3 # Tanto Match1 como Match2 o Match3
