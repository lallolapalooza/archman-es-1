LWP::RobotUA(3) Documentación aportada por el usuario de Perl LWP::RobotUA(3)

NOMBRE

LWP::RobotUA - una clase para robots de web bien portados

SINOPSIS

use LWP::RobotUA;
my $ua = LWP::RobotUA->new('mi-robot/0.1', 'yo@foo.com');
$ua->delay(10);  # ¡sé muy amable -- máximo una petición cada diez minutos!
...
# Luego úsalo igual que un LWP::UserAgent normal:
my $response = $ua->get('http://whatever.int/...');
...

DESCRIPCIÓN

Esta clase implementa un agente de usuario adecuado para aplicaciones de robots. Los robots deben ser amables con los servidores que visitan. Deben consultar el archivo /robots.txt para asegurarse de que son bienvenidos y no deben realizar peticiones con demasiada frecuencia.

Pero antes de considerar escribir un robot, echa un vistazo a http://www.robotstxt.org/.

Cuando uses un objeto LWP::RobotUA como tu agente de usuario, no tendrás que pensar en estas cosas tú mismo; los archivos de "robots.txt" se consultan y se obedecen automáticamente, el servidor no se consulta demasiado rápido, etc. Simplemente envía peticiones como lo harías con un objeto LWP::UserAgent normal (usando "$ua->get(...)", "$ua->head(...)", "$ua->request(...)", etc.), y este agente especial se asegurará de que seas amable.

MÉTODOS

LWP::RobotUA es una subclase de LWP::UserAgent e implementa los mismos métodos. Además, se proporcionan los siguientes métodos:

new

my $ua = LWP::RobotUA->new( %opciones )
my $ua = LWP::RobotUA->new( $agente, $de )
my $ua = LWP::RobotUA->new( $agente, $de, $reglas )

Las opciones de LWP::UserAgent "agent" y "from" son obligatorias. Las opciones "delay", "use_sleep" y "rules" inicializan atributos privados de RobotUA. Si no se proporcionan "rules", se instancia WWW::RobotRules proporcionando una base de datos interna de robots.txt.

También es posible pasar simplemente el valor de "agent", "from" y opcionalmente "rules" como argumentos posicionales simples.

delay

my $retraso = $ua->delay;
$ua->delay( $minutos );

Obtiene/establece el retraso mínimo entre peticiones al mismo servidor, en minutos. El valor por defecto es 1 minuto. Ten en cuenta que este número no tiene por qué ser un entero; por ejemplo, esto establece el retraso a 10 segundos:

$ua->delay(10/60);

use_sleep

my $bool = $ua->use_sleep;
$ua->use_sleep( $booleano );

Obtiene/establece un valor que indica si el UA debe "dormir" en LWP::RobotUA si las peticiones llegan demasiado rápido, definido como "$ua->delay" minutos no transcurridos desde la última petición al servidor dado. El valor por defecto es verdadero. Si este valor es falso, se generará una respuesta interna "SERVICE_UNAVAILABLE". Tendrá una cabecera "Retry-After" que indica cuándo está bien enviar otra petición a este servidor.

rules

my $reglas = $ua->rules;
$ua->rules( $reglas );

Establece/obtiene qué objeto WWW::RobotRules usar.

no_visits

my $num = $ua->no_visits( $netloc )

Devuelve el número de documentos recuperados de este host del servidor. Sí, lo sé, este método probablemente debería haberse llamado "num_visits" o algo así. :-(

host_wait

my $num = $ua->host_wait( $netloc )

Devuelve el número de segundos (a partir de ahora) que debes esperar antes de poder hacer una nueva petición a este host.

as_string

my $string = $ua->as_string;

Devuelve una cadena que describe el estado del UA. Principalmente útil para depuración.

VER TAMBIÉN

LWP::UserAgent, WWW::RobotRules
