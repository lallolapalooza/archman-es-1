NOMBRE

Locale::Maketext::Extract::Plugin::TT2 - Analizador de formato Template Toolkit

VERSIÓN

versión 1.00

SINOPSIS

$plugin = Locale::Maketext::Extract::Plugin::TT2->new(
    $lexicon            # Un objeto Locale::Maketext::Extract
    @file_types         # Opcionalmente especificar una lista de tipos de archivo reconocidos
)
$plugin->extract($filename,$filecontents);

DESCRIPCIÓN

Extrae cadenas para localizar desde plantillas de Template Toolkit.

NOMBRE CORTO DEL PLUGIN

tt2

FORMATOS VÁLIDOS

Los formatos válidos son:

[% |l(args) %]cadena[% END %]
[% 'cadena' | l(args) %]
[% l('cadena',args) %]
[% c.l('cadena') %]
También todas las combinaciones anteriores con "c." precediéndolas deberían funcionar correctamente. Esta es la sintaxis predeterminada al usar plantillas TT con Mojolicious.

l y loc son intercambiables.

| y FILTER son intercambiables.

TIPOS DE ARCHIVO CONOCIDOS

.tt
.tt2
.html
.tt.*
.tt2.*

REQUIERE

Template

NOTAS

  • TENGA CUIDADO Usar la forma "loc" puede generar falsos positivos si utiliza el plugin del analizador Perl en archivos TT. Si desea usar la forma "loc", entonces debe especificar los tipos de archivo que desea que el plugin Perl analice, o habilitar los tipos de archivo predeterminados, por ejemplo: 
    xgetext.pl -P perl ....        # tipos de archivo predeterminados
xgettext.pl -P perl=pl,pm  ... # tipos de archivo especificados
  • La cadena a localizar debe ser una cadena, no una variable. Intentamos no extraer llamadas a su función de localización que contengan variables, por ejemplo: 
    l('cadena',argumento)  # extraído
l(variable,argumento)       # no extraído

    Esto no funciona para filtros de bloque, así que no lo haga. Por ejemplo:

    [%  FILTER l %]
   cadena [% variable %]      # ¡MAL!
[% END %]
  • Obtener el número de línea correcto es difícil en TT. A menudo será un rango de líneas, o puede ser descartado por el uso de PRE_CHOMP o POST_CHOMP. Siempre estará a unas pocas líneas de la ubicación correcta.
  • Si tiene PRE/POST_CHOMP habilitado por defecto en sus plantillas, entonces debe extraer las cadenas usando los mismos valores. Para configurarlos, puede usar el siguiente script de envoltura: 
    #!/usr/bin/perl
use Locale::Maketext::Extract::Run qw(xgettext);
use Locale::Maketext::Extract::Plugin::TT2();
%Locale::Maketext::Extract::Plugin::TT2::PARSER_OPTIONS = (
     PRE_CHOMP  => 1, # o 2
     POST_CHOMP => 1, # o 2
     # También START/END_TAG, ANYCASE, INTERPOLATE, V1DOLLAR, EVAL_PERL
);
xgettext(@ARGV);
