NOMBRE

Lire::Test::PluginTestCase - Clase base para escribir pruebas unitarias de Plugins

SINOPSIS

use base qw/ Lire::Test::PluginTestCase /;
use MyPlugin;
use File::Basename;
sub create_plugin {
  return new MyPlugin();
}
sub registration_file {
  return dirname( __FILE__ ) .  "../../plugin_init";
}

DESCRIPCIÓN

Esta es una subclase de Test::Unit::TestCase que se puede usar para escribir fácilmente pruebas para Lire::Plugin. Esta clase implementa lo necesario para proporcionar el entorno necesario en set_up() y tear_down().

Proporciona dos pruebas predeterminadas: test_api() y test_registration_file().

La clase de prueba necesita implementar dos métodos para ayudar a completar el entorno.

ENTORNOS

Estos son los métodos que las subclases normalmente anularán para proporcionar los datos necesarios para que se configure el entorno de prueba de ChartType.

registration_file()

Debe devolver el script que es responsable de registrar el analizador con Lire::PluginManager. Esto es utilizado por el test_registration_file() predeterminado.

properties_spec_file()

Si este método devuelve un nombre de archivo, se establecerá como la especificación de configuración predeterminada para la prueba. Úselo cuando el plugin tenga propiedades.

create_plugin()

Debe devolver una instancia del objeto Lire::Plugin a probar.

PRUEBAS PREDETERMINADAS

test_api()

Asegura que todos los métodos requeridos por Lire::Plugin estén implementados.

Comprueba que description() se formatea correctamente como DocBook.

test_registration_file()

Comprueba que el script de registro registra correctamente el analizador con el PluginManager.

VER TAMBIÉN

Lire::Test::TestCase(3pm), Lire::Plugin(3pm)
