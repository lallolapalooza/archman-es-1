NOMBRE

Lire::Config::Plugin - Objeto de valor para la configuración de plugins.

SINOPSIS

use Lire::Config::Plugin;

DESCRIPCIÓN

Este objeto de configuración contiene el nombre de un plugin seleccionado, así como sus opciones.

get_plugin()

Devuelve el plugin actualmente seleccionado.

set_plugin( $plugin )

Cambia el plugin seleccionado. Si se cambia el plugin seleccionado, se creará un nuevo conjunto de propiedades a partir de las propiedades definidas del plugin.

get_properties_spec()

Devuelve el TypeSpec que se utiliza para especificar las propiedades del plugin. Este método devolverá un RecordSpec vacío cuando el plugin no haya definido ninguna propiedad. También se puede usar el método has_properties() para comprobar si el plugin ha definido propiedades de configuración.

has_properties()

Devuelve un valor booleano que indica si el plugin actual es configurable.

get_properties()

Devuelve el objeto Lire::Config::Dictionary que contiene la configuración del plugin.

as_value()

Devuelve una referencia hash con dos claves: 'plugin', que contiene el plugin seleccionado, y 'properties', que es una referencia hash que contiene las propiedades del plugin.

get( $name )

Delega al Diccionario que contiene las propiedades del plugin.

set( $name, $value )

Delega al Diccionario que contiene las propiedades del plugin.

is_set( $name )

Delega al Diccionario que contiene las propiedades del plugin.
