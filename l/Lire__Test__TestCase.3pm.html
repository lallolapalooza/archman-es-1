NOMBRE

Lire::Test::TestCase - Base común para casos de prueba de Lire.

SINOPSIS

use base qw/Lire::Test::TestCase/;
sub set_up {
    my $self = shift->SUPER::set_up();
    $self->{'cfg'}{'lr_schemas_path'} = [ $self->{'tmpdir'} ];
}

DESCRIPCIÓN

Este paquete se puede usar para escribir casos de prueba para Lire en lugar de heredar directamente de Test::Unit::TestCase.

El método set_up por defecto creará un objeto Lire::Test::HashConfig y lo configurará en el framework de configuración. Esto facilita el establecimiento de variables de configuración a valores arbitrarios en el método set_up().

También establece la categoría de localización LC_MESSAGES a 'C'.

Si anula set_up() y tear_down(), asegúrese de llamar a la implementación de SUPER::.

Esta subclase también define un nuevo tipo de aserción que se asegura de que un fragmento de código falle con un mensaje de error adecuado.

assert_died( $test, $regex, [ $msg ] )

Ejecuta $test y falla a menos que falle con un mensaje que coincida con $regex. $test debería ser una referencia a CODE. $regex debería ser una referencia Regexp.

assert_dies( $regex, $test, [ $msg ] )

Similar a assert_died() pero con una firma más cercana a la definida en Test::Unit::Assert.

assert_isa( $class, $instance, [ $msg ] )

Falla a menos que $instance sea una instancia de $class.

MÉTODO RELACIONADO CON FIXTURE

lire_default_config_spec()

Devuelve un objeto Lire::Config::ConfigSpec inicializado a partir de la especificación de configuración por defecto de Lire.

set_up_tz( $tz )

Cuando sus pruebas utilicen timelocal() o localtime(), debería usar este método para especificar la TZ bajo la cual se ejecutará.

La TZ se restablecerá a su valor anterior durante tear_down().

set_up_plugin_mgr()

Esto hará que el PluginManager global sea una instancia que solo vivirá para la prueba actual. El PluginManager anterior se reinstaurará durante tear_down(). De esta manera, no necesitará rastrear las llamadas a register_plugin().
