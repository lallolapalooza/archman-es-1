Locale::RecodeData::MACHEBREW(3pm)

NAME

Locale::RecodeData::MACHEBREW – MacHbrew to UTF-8 recode data

SYNOPSIS

    use Locale::RecodeData;

DESCRIPTION

This module provides the data for the MacHbrew character set (alias MACHEBREW) to UTF-8 recoding.

COMMENTS

MacHbrew is a character set used by the MacHbrew package from the Mac Perl project.
