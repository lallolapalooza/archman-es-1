NOMBRE

Locale::RecodeData::IBM870 - Rutinas de conversión para IBM870

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo es generado y contiene las tablas y rutinas de conversión para IBM870.

COMENTARIOS

Los siguientes comentarios se han extraído del mapacarácteres original:

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP870
alias EBCDIC-CP-ROECE
alias EBCDIC-CP-YU

¡Tenga en cuenta que los alias enumerados anteriormente no son necesariamente válidos!

NOMBRE

Locale::RecodeData

SINOPSIS

use Locale::RecodeData;

DESCRIPCIÓN

Locale::RecodeData es un módulo que proporciona una tabla de caracteres para la recodificación de datos de localización.

COMENTARIOS

La tabla de caracteres contiene mapeos para varios caracteres utilizados en la recodificación de datos de localización.
