NOMBRE

Locale::RecodeData::MACTURKISH - Rutinas de conversión para MACTURKISH

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas y rutinas de conversión para MACTURKISH.

COMENTARIOS

Los siguientes comentarios se han extraído del mapamundis original:

This charmap has been generated automatically from GNU libiconv
conversions.

¡Tenga en cuenta que los alias enumerados anteriormente no son necesariamente válidos!

NAME

Locale::RecodeData::MACTURKISH - Mac Turk-ish characters for recode.

SYNOPSIS

use Locale::RecodeData;

my $recode = Locale::RecodeData->new( 'MACTURKISH' );

This module provides the mapping tables for Mac Turk-ish characters. It is used by the Locale::Recode(3) module.
