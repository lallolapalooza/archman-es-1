NOMBRE

SINTAXIS

#include <sys/queue.h>
LIST_ENTRY(TYPE);
LIST_HEAD(HEADNAME, TYPE);
LIST_HEAD LIST_HEAD_INITIALIZER(LIST_HEAD head);
void LIST_INIT(LIST_HEAD *head);
int LIST_VACIO(LIST_HEAD *head);
void LIST_INSERT_HEAD(LIST_HEAD *head,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_BEFORE(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
void LIST_INSERT_AFTER(struct TYPE *listelm,
                        struct TYPE *elm, LIST_ENTRY NAME);
struct TYPE *LIST_PRIMERO(LIST_HEAD *head);
struct TYPE *LIST_SALIR(struct TYPE *elm, LIST_ENTRY NAME);
LIST_ITERAR(struct TYPE *var, LIST_HEAD *head, LIST_ENTRY NAME);
void LIST_REMOVE(struct TYPE *elm, LIST_ENTRY NAME);

DESCRIPCIÓN

Estas macros definen y operan sobre listas doblemente enlazadas.

En las definiciones de macro, TYPE es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo LIST_ENTRY, llamado NAME. El argumento HEADNAME es el nombre de una estructura definida por el usuario, que debe declararse usando la macro LIST_HEAD().

Creación

Una lista está encabezada por una estructura definida por la macro LIST_HEAD(). Esta estructura contiene un puntero único hacia el primer elemento de la lista. Los elementos son doblemente enlazados de modo que un elemento arbitrario puede ser eliminado sin recorrer la lista. Los nuevos elementos pueden agregarse a la lista después de un elemento existente, antes de uno existente o al frente de la lista. Una estructura LIST_HEAD se declara así:


LIST_HEAD(HEADNAME, TYPE) head;

donde struct HEADNAME es la estructura a definir, y struct TYPE es el tipo de los elementos en la lista. Una dirección del puntero al encabezado de la lista puede ser declarada más tarde como:


struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

LIST_ENTRY() declara una estructura que conecta los elementos de la lista.

LIST_HEAD_INITIALIZER() evalúa a un inicializador para la lista head.

LIST_INIT() inicializa la lista referida por head.

LIST_VACIO() evalúa a verdadero si la lista está vacía, y falso en caso contrario.

Inserción

LIST_INSERT_HEAD() inserta el elemento nuevo elm al frente de la lista.

LIST_INSERT_BEFORE() inserta el elemento nuevo elm antes del elemento listelm.

LIST_INSERT_AFTER() inserta el elemento nuevo elm después del elemento listelm.

Recorrido

LIST_PRIMERO() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

LIST_SALIR() devuelve el siguiente elemento de la lista, o NULL si es el último.

LIST_ITERAR() recorre la lista referida por head en la dirección hacia adelante, asignando cada elemento a var en orden.

Eliminación

LIST_REMOVE() elimina el elemento elm de la lista.

VALOR DE RETORNO

LIST_VACIO() devuelve no cero si la lista está vacía, y cero si contiene al menos un elemento.

LIST_PRIMERO() y LIST_SALIR() devuelven un puntero a la estructura TYPE del primer o siguiente elemento, respectivamente.

LIST_HEAD_INITIALIZER() devuelve un inicializador que puede asignarse a la lista head.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

PROBLEMAS

LIST_ITERAR() no permite que var sea eliminado o liberado dentro del bucle, ya que podría interferir con el recorrido. LIST_ITERAR_SAFE(), que está presente en los BSDs pero no en glibc, corrige este límite al permitir que var sea eliminado de la lista y liberado dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    LIST_ENTRY(entry) entries;              /* Lista */
};
LIST_HEAD(listhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct listhead head;                   /* Encabezado de la lista */
    int i;
    LIST_INIT(&head);                       /* Inicializar la lista */
    n1 = malloc(sizeof(struct entry));      /* Insertar al frente */
    LIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insertar después */
    LIST_INSERT_AFTER(n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insertar antes */
    LIST_INSERT_BEFORE(n2, n3, entries);
    i = 0;                                  /* Recorrido hacia adelante */
    LIST_ITERAR(np, &head, entries)
        np->data = i++;
    LIST_REMOVE(n2, entries);               /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    LIST_ITERAR(np, &head, entries)
        printf("%i\n", np->data);
                                            /* Eliminación de la lista */
    n1 = LIST_PRIMERO(&head);
    while (n1 != NULL) {
        n2 = LIST_SALIR(n1, entries);
        free(n1);
        n1 = n2;
    }
    LIST_INIT(&head);
    exit(EXIT_SUCCESS);
}
