NOMBRE

Log::Log4perl::Filter::StringMatch - Filtro por cadena de mensaje de registro

SINOPSIS

log4perl.filter.Match1               = Log::Log4perl::Filter::StringMatch
log4perl.filter.Match1.StringToMatch = blah blah
log4perl.filter.Match1.AcceptOnMatch = true

DESCRIPCIÓN

Este filtro personalizado de Log4perl comprueba si el mensaje actualmente enviado coincide con una expresión regular predefinida, como se establece en el parámetro "StringToMatch". Utiliza expresiones regulares comunes de Perl 5.

El parámetro adicional "AcceptOnMatch" define si el filtro debe pasar o bloquear el mensaje cuando hay una coincidencia ("true" o "false").
