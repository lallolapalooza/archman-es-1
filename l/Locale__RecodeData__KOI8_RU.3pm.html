Locale::RecodeData::KOI8_RU(3pm) -- Perl I/O Layers

NAME

Locale::RecodeData::KOI8_RU - Character encoding data for KOI8-R

SYNOPSIS

 use Encode;
 use Locale::Recode;

 my $string = decode("KOI8-R", "\xd5\xd4\xc1\xc2"); # CYRILLIC SMALL LETTER EF, TSE, BE, DE
 my $recode = Locale::Recode->new("KOI8-R");
 print $recode->translate($string);
 print encode("KOI8-R", $string);

DESCRIPTION

This module provides the character mapping data for the KOI8-R character set, which is a popular character set for the Russian language. It is used by the Perl I/O Layer system (Locale::Recode) and the Encode module.

KOI8-R is an 8-bit character set where the characters from ASCII are mapped to the corresponding positions in the lower 128 code points, and the Cyrillic characters are mapped to the upper 128 code points. The mapping is designed such that the Cyrillic characters retain their relative order from the GOST character set.

COMMENTS

The mapping from KOI8-R to Unicode is defined as follows:

  • ASCII characters (0x00-0x7F) are mapped to the corresponding Unicode code points.
  • KOI8-R characters (0xC0-0xFF) are mapped to Unicode code points U+0410 through U+044F, with the exception of U+0402, U+040B, U+040C, U+040E, U+0452, U+045B, U+045C, U+045E which are not used in KOI8-R.

The mapping from Unicode to KOI8-R is the inverse of the above.
