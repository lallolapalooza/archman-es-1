Módulo Dir
: sig end

type t

Representa un directorio en la ruta de carga.

val create : hidden:bool -> string -> t

val path : t -> string

val files : t -> string list

Todos los archivos en ese directorio. Esto no incluye archivos en subdirectorios de este directorio.

val hidden : t -> bool

Si los módulos en este directorio no deben ser enlazados en el ámbito inicial

val find : t -> string -> string option

find dir fn devuelve la ruta completa a fn en dir.

val find_normalized : t -> string -> string option

Al igual que Load_path.Dir.find, pero también busca nombres no capitalizados, es decir, si el nombre es Foo.ml, puede devolver /ruta/Foo.ml o /ruta/foo.ml.
