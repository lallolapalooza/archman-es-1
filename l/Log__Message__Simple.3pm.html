NOMBRE

Log::Message::Simple - Interfaz simplificada para Log::Message

SINOPSIS

use Log::Message::Simple qw[msg error debug
                            carp croak cluck confess];
use Log::Message::Simple qw[:STD :CARP];
### funcionalidad de reporte estándar
msg(    "Conectando a la base de datos",           $verbose );
error(  "Fallo al conectar a la base de datos: $@",   $verbose );
debug(  "Los argumentos de conexión fueron: $args", $debug );
### funcionalidad estándar de carp
carp(   "Argumentos incorrectos pasados: @_" );
croak(  "Fatal: argumentos incorrectos pasados: @_" );
cluck(  "Argumentos incorrectos pasados -- incluyendo rastreo de pila: @_" );
confess("Fatal: argumentos incorrectos pasados -- incluyendo rastreo de pila: @_" );
### recuperar mensaje individual
my @stack = Log::Message::Simple->stack;
my @stack = Log::Message::Simple->flush;
### recuperar toda la pila en formato imprimible
my $msgs  = Log::Message::Simple->stack_as_string;
my $trace = Log::Message::Simple->stack_as_string(1);
### redirigir salida
local $Log::Message::Simple::MSG_FH     = \*STDERR;
local $Log::Message::Simple::ERROR_FH   = \*STDERR;
local $Log::Message::Simple::DEBUG_FH   = \*STDERR;
### forzar un rastreo de pila en caso de error
local $Log::Message::Simple::STACKTRACE_ON_ERROR = 1

DESCRIPCIÓN

Este módulo proporciona instalaciones de registro estandarizadas utilizando el módulo "Log::Message".

FUNCIONES

msg("cadena mensaje" [,VERBOSE])

Registra un mensaje en la pila e lo imprime en "STDOUT" (o realmente $MSG_FH, ver la sección "VARIABLES GLOBALES" abajo), si la opción "VERBOSE" es verdadera. La opción "VERBOSE" es falsa por defecto.

Exportado por defecto, o usando la etiqueta ":STD".

debug("cadena mensaje" [,VERBOSE])

Registra un mensaje de depuración en la pila e lo imprime en "STDOUT" (o realmente $DEBUG_FH, ver la sección "VARIABLES GLOBALES" abajo), si la opción "VERBOSE" es verdadera. La opción "VERBOSE" es falsa por defecto.

Exportado por defecto, o usando la etiqueta ":STD".

error("cadena error" [,VERBOSE])

Registra un error en la pila e lo imprime en "STDERR" (o realmente $ERROR_FH, ver las secciones "VARIABLES GLOBALES" abajo), si la opción "VERBOSE" es verdadera. La opción "VERBOSE" es verdadera por defecto.

Exportado por defecto, o usando la etiqueta ":STD".

carp();

Proporciona funcionalidad igual a Carp::carp() mientras aún registra en la pila.

Exportado usando la etiqueta ":CARP".

croak();

Proporciona funcionalidad igual a Carp::croak() mientras aún registra en la pila.

Exportado usando la etiqueta ":CARP".

confess();

Proporciona funcionalidad igual a Carp::confess() mientras aún registra en la pila.

Exportado usando la etiqueta ":CARP".

cluck();

Proporciona funcionalidad igual a Carp::cluck() mientras aún registra en la pila.

Exportado usando la etiqueta ":CARP".

MÉTODOS DE CLASE

Log::Message::Simple->stack()

Recupera todos los elementos en la pila. Ya que "Log::Message::Simple" está implementado usando "Log::Message", consulta su página de manual para la función "retrieve" para ver qué se devuelve y cómo usar los elementos.

Log::Message::Simple->stack_as_string([TRACE])

Devuelve toda la pila como una cadena imprimible. Si la opción "TRACE" es verdadera, todos los elementos se devuelven con la salida de "Carp::longmess", en lugar de solo el mensaje. "TRACE" es falsa por defecto.

Log::Message::Simple->flush()

Elimina todos los elementos de la pila y los devuelve. Ya que "Log::Message::Simple" está implementado usando "Log::Message", consulta su página de manual para la función "retrieve" para ver qué se devuelve y cómo usar los elementos.

VARIABLES GLOBALES

$ERROR_FH
Este es el manejador de archivo donde todos los mensajes enviados a error() se imprimen. Por defecto es *STDERR.
$MSG_FH
Este es el manejador de archivo donde todos los mensajes enviados a msg() se imprimen. Por defecto es *STDOUT.
$DEBUG_FH
Este es el manejador de archivo donde todos los mensajes enviados a debug() se imprimen. Por defecto es *STDOUT.
$STACKTRACE_ON_ERROR
Si esta opción se establece en "true", cada llamada a error() generará un rastreo de pila usando Carp::shortmess(). Por defecto es "false"
