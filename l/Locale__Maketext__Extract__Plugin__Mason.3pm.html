Locale::Maketext::Extract::Plugin::Mason(3) Documentación de Perl contribuida por el usuario Locale::Maketext::Extract::Plugin::Mason(3)

NOMBRE

Locale::Maketext::Extract::Plugin::Mason - Analizador de formato HTML::Mason (alias Mason 1) y Mason (alias Mason 2)

VERSIÓN

versión 1.00

SINOPSIS

$plugin = Locale::Maketext::Extract::Plugin::Mason->new(
    $lexicon            # Un objeto Locale::Maketext::Extract
    @tipos_archivo         # Opcionalmente especifica una lista de tipos de archivo reconocidos
)
$plugin->extract($nombre_archivo,$contenido_archivo);

DESCRIPCIÓN

Extrae cadenas para localizar desde archivos Mason.

NOMBRE CORTO DEL PLUGIN

mason

FORMATOS VÁLIDOS

HTML::Mason (alias Mason 1)
Las cadenas dentro de <&|/l>...</&> y <&|/loc>...</&> se extraen.

Mason (alias Mason 2) Las cadenas dentro de <% $.floc { %>...</%> o <% $.fl { %>...</%> o <% $self->floc { %>...</%> o <% $self->fl { %>...</%> se extraen.

TIPOS DE ARCHIVO CONOCIDOS

Todos los tipos de archivo

VER TAMBIÉN

xgettext.pl
para extraer cadenas traducibles de sistemas de plantillas comunes y archivos de código fuente perl.
