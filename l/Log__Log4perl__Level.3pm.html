Paquete: perl-log-log4perl

Licencias: PerlArtistic, GPL

Level(3) Documentación de Perl aportada por el usuario Level(3)

NOMBRE

Log::Log4perl::Level - Niveles de registro predefinidos

SINOPSIS

use Log::Log4perl::Level;
print $ERROR, "\n";
# -- o --
use Log::Log4perl qw(:levels);
print $ERROR, "\n";

DESCRIPCIÓN

"Log::Log4perl::Level" simplemente exporta un conjunto predefinido de niveles de registro de Log4perl al espacio de nombres del llamador. Se utiliza internamente por "Log::Log4perl". Los siguientes escalares se definen:

$OFF
$FATAL
$ERROR
$WARN
$INFO
$DEBUG
$TRACE
$ALL

"Log::Log4perl" también exporta estas constantes al espacio de nombres del llamador si se importa con la etiqueta ":levels":

use Log::Log4perl qw(:levels);

Esta es la forma preferida, generalmente no hay necesidad de llamar a "Log::Log4perl::Level" explícitamente.

Los valores numéricos asignados a estas constantes son puramente virtuales, solo utilizados por Log::Log4perl internamente y pueden cambiar en cualquier momento, así que por favor no hagas ninguna suposición. Puedes probar la igualdad numérica comparando directamente dos valores de nivel, eso está bien:

if( get_logger()->level() == $DEBUG ) {
    print "El nivel del logger es DEBUG\n";
}

Pero si quieres averiguar cuál de los dos niveles es más verboso, usa el propio comparador de Log4perl:

if( Log::Log4perl::Level::isGreaterOrEqual( $level1, $level2 ) ) {
    print Log::Log4perl::Level::to_level( $level1 ), 
        " es igual o más verboso que ", 
        Log::Log4perl::Level::to_level( $level2 ), "\n";
}

Si el llamador quiere importar constantes de nivel en un espacio de nombres diferente, se puede proporcionar con el comando "use":

use Log::Log4perl::Level qw(MiEspacioDeNombres);

Después de esto, $MiEspacioDeNombres::ERROR, $MiEspacioDeNombres::INFO, etc., se definirán correspondientemente.

Niveles numéricos y cadenas

Las variables de nivel como $DEBUG o $WARN tienen valores numéricos que son internos a Log4perl. Para transformarlas a cadenas que puedan usarse en un archivo de configuración de Log4perl, utiliza la función c<to_level()> proporcionada por Log::Log4perl::Level:

use Log::Log4perl qw(:easy);
use Log::Log4perl::Level;
    # imprime "DEBUG"
print Log::Log4perl::Level::to_level( $DEBUG ), "\n";

Para realizar la transformación inversa, que toma una cadena como "DEBUG" y la convierte en una constante como $DEBUG, usa la función to_priority():

use Log::Log4perl qw(:easy);
use Log::Log4perl::Level;
my $numval = Log::Log4perl::Level::to_priority( "DEBUG" );

después de lo cual $numval podría usarse donde se requiera un valor numérico:

Log::Log4perl->easy_init( $numval );
