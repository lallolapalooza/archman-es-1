NOMBRE

Log::Log4perl::Layout - Clase base virtual de diseño de Log4perl

SINOPSIS

# No usar directamente, ver abajo

DESCRIPCIÓN

"Log::Log4perl::Layout" es una clase base virtual para los dos tipos de diseño actualmente implementados:

Log::Log4perl::Layout::SimpleLayout
Log::Log4perl::Layout::PatternLayout

A menos que estés implementando una nueva clase de diseño para Log4perl, no deberías usar esta clase directamente, sino referirte a Log::Log4perl::Layout::SimpleLayout o Log::Log4perl::Layout::PatternLayout.
