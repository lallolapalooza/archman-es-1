NOMBRE

Locale::Maketext::Lexicon::Gettext - Analizador de archivos PO y MO para Maketext

VERSIÓN

versión 1.00

SINOPSIS

Llamar mediante Locale::Maketext::Lexicon:

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello/de.mo'],
};

Llamar directamente a parse():

use Locale::Maketext::Lexicon::Gettext;
my %Lexicon = %{ Locale::Maketext::Lexicon::Gettext->parse(<DATA>) };
__DATA__
#: Hello.pm:10
msgid "Hello, World!"
msgstr "Hallo, Welt!"
#: Hello.pm:11
msgid "You have %quant(%1,piece) of mail."
msgstr "Sie haben %quant(%1,Poststueck,Poststuecken)."

DESCRIPCIÓN

Este módulo implementa un analizador de archivos de texto para el sistema de traducción Gettext, basado en Perl. Transforma todas las secuencias de %1, %2, <%*>... a "[_1]", "[_2]", "[_*]", y así sucesivamente. Recibe archivos PO o MO, que se procesan con un analizador de Perl adaptado de Imacat's "Locale::Maketext::Gettext").

Desde la versión 0.03, este módulo también busca en las cadenas de léxico "%function(args...)" y los transforma en "[function,args...]". Cualquier secuencia %1, %2... dentro de los args se reemplazarán sus signos del porcentaje ("%") por guiones ("_").

El nombre de function anterior debería comenzar con una letra o guion bajo, seguido por cualquier número de caracteres alfanuméricos y guiones. Como excepción, el nombre de la función puede consistir en un solo asterisco ("*") o numeral ("#"), que son abreviaciones de "quant" y "numf", respectivamente.

Además de una función adicional, este módulo también analiza la cabecera MIME estilo especificada en el msgstr vacío (""), y la agrega a %Lexicon con un prefijo "__". Por ejemplo, el ejemplo anterior establecerá "__Content-Type" a "text/plain; charset=iso8859-1", sin el carácter de nueva línea o el guion.

Cualquier entrada normal que duplica un registro de metadatos se prioriza. Por lo tanto, cualquier línea "msgid "__Content-Type"" que aparezca en cualquier lugar debe sobreescribir el valor anterior.

OPCIONES

use_fuzzy

Cuando se analizan archivos PO, las entradas fuzzy (marcadas con "#, fuzzy") se ignoran silenciosamente. Si deseas usar entradas fuzzy, especifica un valor verdadero a la opción "_use_fuzzy":

use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello/de.mo'],
    _use_fuzzy => 1,
};

allow_empty

Cuando se analizan archivos PO, las entradas vacías (con "msgstr """) se ignoran silenciosamente. Si deseas permitir entradas vacías, especifica un valor verdadero a la opción "_allow_empty":

use Locale::Maketext::Lexicon {
    de => [Gettext => 'hello/de.mo'],
    _allow_empty => 1,
};
