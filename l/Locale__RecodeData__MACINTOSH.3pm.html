NOMBRE

Locale::RecodeData::MACINTOSH.3pm

SINOPSIS

use Locale::RecodeData::MACINTOSH;

DESCRIPCIÓN

Locale::RecodeData::MACINTOSH es un módulo de Perl que proporciona los datos para la configuración regional MACINTOSH en el módulo Locale::Recode.

COMENTARIOS

Este módulo se utiliza para decodificar y codificar texto en la configuración regional MACINTOSH, que es un subconjunto del sistema de configuración regional más amplio en Perl.
