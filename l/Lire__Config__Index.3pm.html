NOMBRE

Lire::Config::Index - Registro e interfaz de índice

SINOPSIS

use base qw/Lire::Config::Index/;
sub has_entry { my ($self, $name) = @_; ... }
sub entries { my $self = $_[0]; ... }
sub get_ref { my ($self, $name) = @_; ... }

DESCRIPCIÓN

La interfaz Lire::Config::Index es utilizada por Lire::Config::ReferenceSpec(3pm) para validar y obtener objetos referenciados.

REGISTRO DE ÍNDICE

Estos son los métodos de clase utilizados para registrar y obtener objetos de Índice.

has_index( $nombre )

Devuelve verdadero si se registró un índice bajo $nombre.

get_index( $nombre )

Devuelve el Índice llamado $nombre. Produce un error si no se registró ningún índice de este tipo.

set_index( $nombre, $indice )

Registra $indice bajo $nombre. Reemplaza cualquier índice anterior registrado bajo el mismo nombre.

INTERFAZ DE ÍNDICE

has_entry( $nombre )

Debería devolver verdadero si $nombre está definido en este índice.

entries()

Debería devolver todas las entradas definidas en el índice.

get_ref( $nombre )

Debería devolver el objeto indexado bajo $nombre. Se debe lanzar un error si no existe tal entrada.
