NOMBRE

Log::Log4perl::Appender::Socket - Registrar en un socket

SINOPSIS

use Log::Log4perl::Appender::Socket;
my $appender = Log::Log4perl::Appender::Socket->new(
  PeerAddr => "servidor.foo.com",
  PeerPort => 1234,
);
$appender->log(message => "Regístrame\n");

DESCRIPCIÓN

Este es un apéndice simple para escribir en un socket. Se basa en IO::Socket::INET y ofrece todos los parámetros que este módulo ofrece.

Al destruir el objeto, los mensajes pendientes se enviarán y el socket se cerrará.

Si el apéndice no puede contactar al servidor durante la fase de inicialización (al ejecutar el constructor "new"), se morirá().

Si el apéndice falla al registrar un mensaje porque el método send() del socket falla (lo más probable es que el servidor se haya caído), intentará reconectar una vez. Si tiene éxito, el mensaje se enviará. Si la reconexión falla, se enviará una advertencia a STDERR y el método log() retornará, descartando el mensaje.

Si se proporciona la opción "silent_recovery" al constructor y se establece a un valor verdadero, el comportamiento es diferente: Si la conexión del socket no se puede establecer en el momento de la inicialización, se emitirá una única advertencia. Cada intento de registro intentará establecer la conexión y descartará el mensaje silenciosamente si falla. Si ni siquiera desea la advertencia, establezca la opción "no_warning" a un valor verdadero.

Conectar en el momento de la inicialización puede no ser la mejor opción al ejecutarse bajo Apache1 Apache2/prefork, porque el proceso padre crea el socket y las conexiones son compartidas entre los hijos que se desglosan; todos los hijos escribiendo en el mismo socket podrían entremezclar mensajes. Así que en lugar de eso, puede usar "defer_connection" que pospondrá la conexión hasta que se envíe el primer mensaje de registro.

EJEMPLO

Escriba un servidor rápidamente usando el módulo IO::Socket::INET:

use IO::Socket::INET;
my $sock = IO::Socket::INET->new(
    Listen    => 5,
    LocalAddr => 'localhost',
    LocalPort => 12345,
    Proto     => 'tcp');
while(my $client = $sock->accept()) {
    print "Cliente conectado\n";
    while(<$client>) {
        print "$_\n";
    }
}

Inícielo y luego ejecute el siguiente script como cliente:

use Log::Log4perl qw(:easy);
my $conf = q{
    log4perl.category                  = WARN, Socket
    log4perl.appender.Socket           = Log::Log4perl::Appender::Socket
    log4perl.appender.Socket.PeerAddr  = localhost
    log4perl.appender.Socket.PeerPort  = 12345
    log4perl.appender.Socket.layout    = SimpleLayout
};
Log::Log4perl->init(\$conf);
sleep(2);
for(1..10) {
    ERROR("¡Cuac!");
    sleep(5);
}
