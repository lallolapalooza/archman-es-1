NOMBRE

LOAD - cargar un archivo de biblioteca compartida

SINOPSIS

LOAD 'nombre_archivo'

DESCRIPCIÓN

Este comando carga un archivo de biblioteca compartida en el espacio de direcciones del servidor PostgreSQL. Si el archivo ya se ha cargado, el comando no hace nada. Los archivos de biblioteca compartida que contienen funciones C se cargan automáticamente cada vez que se llama a una de sus funciones. Por lo tanto, un LOAD explícito suele ser necesario solo para cargar una biblioteca que modifica el comportamiento del servidor a través de "hooks" en lugar de proporcionar un conjunto de funciones.

El nombre del archivo de la biblioteca se suele dar como un nombre de archivo simple, que se busca en la ruta de búsqueda de bibliotecas del servidor (establecida por dynamic_library_path). Alternativamente, se puede dar como un nombre de ruta completo. En cualquier caso, la extensión del archivo de biblioteca compartida estándar de la plataforma puede omitirse. Consulte la Sección 36.10.1 para obtener más información sobre este tema.

Los no superusuarios solo pueden aplicar LOAD a archivos de biblioteca ubicados en $libdir/plugins/ — el nombre_archivo especificado debe comenzar exactamente con esa cadena. (Es responsabilidad del administrador de la base de datos asegurarse de que solo se instalen bibliotecas "seguras" allí).

COMPATIBILIDAD

LOAD es una extensión de PostgreSQL.
