NAME

Locale::RecodeData::IBM037 - Charset data for IBM037.

SYNOPSIS

    use Locale::RecodeData::IBM037;
    # ...

DESCRIPTION

This module provides the necessary data to convert between the IBM037 character set and other character sets.

IBM037 is an EBCDIC (Extended Binary Coded Decimal Interchange Code) character set used in various IBM mainframe and midrange systems. It's a superset of the basic 6-bit code page, incorporating additional characters and symbols.

This module is designed to be used by the Locale::Recode module, which handles the actual conversion logic.
