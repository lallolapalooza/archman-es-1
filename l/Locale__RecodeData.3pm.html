Locale::RecodeData(3) Documentación de Perl aportada por el usuario Locale::RecodeData(3)

NOMBRE

Locale::RecodeData - Clase base abstracta para conversores de conjuntos de caracteres

SINOPSIS

# Para compatibilidad con Perl 5.005 y anteriores, debes
# *usar* el módulo antes de heredar de él.
use qw (Locale::RecodeData);
use base qw (Locale::RecodeData);

DESCRIPCIÓN

El módulo Locale::RecodeData sirve como clase base abstracta para todos los conversores utilizados por Locale::Recode(3).

Añadir nuevos módulos de conversión actualmente no es sencillo, y tendrás que editar las fuentes de algunos módulos para ese propósito.

Primero, debes añadir tu nueva clase de conversor a la lista que se encuentra en Locale::_Conversions(3), para que Locale::Recode(3) conozca su presencia. Si hay alias válidos para el codeset de tu conversor, también tendrás que editar Locale::_Aliases(3).

Finalmente, tienes que implementar la rutina de conversión (protegida) _recode(). Ver abajo ("INTERFAZ") para más detalles.

CONSTRUCTOR

new (from => FROM_CODESET, to => TO_CODESET)
El constructor toma dos argumentos (nombrados):
from
El nombre canónico del codeset de origen. Los alias ya han sido resueltos y el nombre se ha convertido a mayúsculas.
to
El nombre canónico del codeset de destino. Los alias ya han sido resueltos y el nombre se ha convertido a mayúsculas.

Normalmente no tienes que implementar el constructor. El constructor predeterminado implementado aquí almacenará los codesets de origen y destino en los miembros protegidos "_from" y "_to".

MÉTODOS

La clase implementa un método:

_getError
Devuelve el miembro (protegido) "_error".

INTERFAZ

Las nuevas clases de conversión deben proporcionar la siguiente interfaz:

new (from => FROM_CODESET, to => TO_CODESET)
El constructor toma dos argumentos (nombrados):
from
El nombre canónico del codeset de origen. Los alias ya han sido resueltos y el nombre se ha convertido a mayúsculas.
to
El nombre canónico del codeset de destino. Los alias ya han sido resueltos y el nombre se ha convertido a mayúsculas.
_getError
Debe devolver el último error (como una cadena) o falso si no hubo error.

Este método ya está implementado en la clase base.

_recode STRINGREF
Debe convertir el argumento "STRINGREF" in-situ. En caso de fallo, devolver falso, y asegurarse de que el método _getError() devuelva un mensaje de error informativo.
