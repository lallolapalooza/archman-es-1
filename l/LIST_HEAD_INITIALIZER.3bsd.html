DESCRIPCIÓN

Estas macros definen y operan sobre cuatro tipos de estructuras de datos que pueden usarse tanto en C como en C++:

  1. Lista
  2. Lista doblemente ligada
  3. Cola de cola final
  4. Cola final
Todas las cuatro estructuras soportan la siguiente funcionalidad:
  1. Inserción de una nueva entrada al frente de la lista.
  2. Inserción de una nueva entrada después de cualquier elemento en la lista.
  3. Eliminación de una entrada en el frente de la lista con complejidad O(1).
  4. Traversión lineal de la lista.
  5. Cambiar el contenido de dos listas.

Las listas doblemente ligadas son las más simples de las cuatro estructuras de datos y solo soportan la funcionalidad mencionada anteriormente. Las listas doblemente ligadas son ideales para aplicaciones con grandes conjuntos de datos y pocos o ningún eliminaciones, o para implementar un cola LIFO. Las listas doblemente ligadas añaden la siguiente funcionalidad:

  1. Eliminación de cualquier entrada en la lista con complejidad O(n).
  2. Conexión de dos listas.

Las colas de cola final añaden la siguiente funcionalidad:

  1. Se pueden añadir entradas al final de una lista.
  2. Eliminación de cualquier entrada en la lista con complejidad O(n).
  3. Pueden ser concatenadas.
Sin embargo:
  1. Las inserciones en las listas deben especificar el frente de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño de código es aproximadamente el 15% mayor y las operaciones llevan aproximadamente 20% más tiempo que en listas doblemente ligadas.

Las colas de cola final son ideales para aplicaciones con grandes conjuntos de datos y pocos o ningún eliminaciones, o para implementar una cola FIFO.

Además de las estructuras de datos doblemente ligadas (listas y colas de cola final), las estructuras de tipo doblemente ligadas también permiten:

  1. Inserción de una nueva entrada antes de cualquier elemento en la lista.
  2. Eliminación de cualquier entrada en la lista con complejidad O(1).
Sin embargo:
  1. Cada elemento requiere dos punteros en lugar de uno.
  2. El tamaño de código y el tiempo de ejecución de las operaciones (excepto para la eliminación) son aproximadamente el doble que en las estructuras de datos doblemente ligadas.

Las listas son las más simples de las estructuras de datos doblemente ligadas. Añaden la siguiente funcionalidad sobre lo mencionado anteriormente:

  1. Conexión de dos listas con complejidad O(n).
  2. Se pueden recorrer en sentido inverso.
Sin embargo:
  1. Para recorrer en sentido inverso, se debe especificar el elemento inicial de la travesía y la lista en la cual se encuentra.

Las colas de cola añaden la siguiente funcionalidad:

  1. Se pueden añadir entradas al final de una lista.
  2. Se pueden recorrer en sentido inverso, desde la cola final hacia la cabeza.
  3. Se pueden concatenar.
Sin embargo:
  1. Las inserciones y eliminaciones en las listas deben especificar el frente de la lista.
  2. Cada entrada de cabeza requiere dos punteros en lugar de uno.
  3. El tamaño de código es aproximadamente el 15% mayor y las operaciones llevan aproximadamente 20% más tiempo que en las listas doblemente ligadas.

En las definiciones de macros, TYPE es el nombre de una estructura definida por el usuario. La estructura debe contener un campo llamado NAME de tipo SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY o TAILQ_ENTRY. En las definiciones de macros, CLASSTYPE es el nombre de una clase definida por el usuario. La clase debe contener un campo llamado NAME de tipo SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY o TAILQ_CLASS_ENTRY. El argumento HEADNAME es el nombre de una estructura definida por el usuario que debe declararse utilizando las macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD o TAILQ_CLASS_HEAD. Para más información sobre cómo se utilizan estas macros, ve las ejemplos a continuación.

LISTAS SIMPLES

Una lista doblemente ligada está dirigida por una estructura definida mediante la macro SLIST_HEAD. Esta estructura contiene un único puntero hacia el primer elemento de la lista. Los elementos son doblemente ligados para minimizar el espacio y el overhead de manipulación de punteros, pero con un costo de O(n) para eliminar elementos arbitrarios. Se pueden agregar nuevos elementos a la lista después de un elemento existente o al frente de la lista. Una estructura SLIST_HEAD se declara de la siguiente manera:

SLIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos de la lista. Se puede declarar luego un puntero a la cabeza de la lista como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro SLIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro SLIST_CONCAT concatenará la lista dirigida por head2 en la parte final de la lista dirigida por head1, eliminando todos los elementos de la anterior. Se debe evitar su uso en rutas de código de alta utilización, ya que recorre todo el contenido de la lista dirigida por head1. Se debe usar una cola de cola final si es necesario en rutas de código de alta utilización o para operar en listas largas.

La macro SLIST_EMPTY evalúa a true si no hay elementos en la lista.

La macro SLIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro SLIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro SLIST_FOREACH recorre la lista referida por head en el sentido forward, asignando cada elemento a var por orden.

La macro SLIST_FOREACH_FROM comporta de manera idéntica a SLIST_FOREACH cuando var es NULL, en cuyo caso trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head).

La macro SLIST_FOREACH_SAFE recorre la lista referida por head en el sentido forward, asignando cada elemento a var. Sin embargo, aunque no se especifica SLIST_FOREACH aquí, es permitido tanto eliminar var como liberar su memoria dentro del bucle de manera segura, sin interferir con la travesía.

La macro SLIST_FOREACH_FROM_SAFE comporta de manera idéntica a SLIST_FOREACH_SAFE cuando var es NULL, en cuyo caso trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head).

La macro SLIST_INIT inicializa la lista referida por head.

La macro SLIST_INSERT_HEAD inserta el nuevo elemento elm al frente de la lista.

La macro SLIST_INSERT_AFTER inserta el nuevo elemento elm después del elemento

listelm.

La macro SLIST_NEXT devuelve el siguiente elemento de la lista.

La macro SLIST_REMOVE_AFTER elimina el elemento que sigue a elm de la lista. A diferencia de SLIST_REMOVE, esta macro no recorre la lista completa.

La macro SLIST_REMOVE_HEAD elimina el elemento elm de la cabeza de la lista. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la lista deberían usar explícitamente esta macro en lugar de la macro genérica SLIST_REMOVE.

La macro SLIST_REMOVE elimina el elemento elm de la lista. Se debe evitar el uso de esta macro, ya que recorre la lista completa. Se debe usar una lista doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en listas largas.

La macro SLIST_SWAP intercambia el contenido de head1 y head2.

COLAS DE DATOS SIMPLEMENTE ENLAZADAS

Una cola de datos simplemente enlazada está encabezada por una estructura definida por la macro STAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento de la cola de datos y otro al último elemento de la cola de datos. Los elementos están enlazados de forma simple para una mínima sobrecarga de espacio y manipulación de punteros, a costa de una eliminación O(n) para elementos arbitrarios. Los nuevos elementos se pueden añadir a la cola de datos después de un elemento existente, al principio de la cola de datos o al final de la cola de datos. Una estructura STAILQ_HEAD se declara de la siguiente manera:

STAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura que se definirá, y TYPE es el tipo de los elementos que se enlazarán en la cola de datos. Un puntero a la cabeza de la cola de datos se puede declarar más tarde como:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro STAILQ_HEAD_INITIALIZER se evalúa como un inicializador para la cola de datos head.

La macro STAILQ_CONCAT concatena la cola de datos encabezada por head2 al final de la cola encabezada por head1, eliminando todas las entradas de la primera.

La macro STAILQ_EMPTY se evalúa como verdadero si no hay elementos en la cola de datos.

La macro STAILQ_ENTRY declara una estructura que conecta los elementos en la cola de datos.

La macro STAILQ_FIRST devuelve el primer elemento de la cola de datos o NULL si la cola de datos está vacía.

La macro STAILQ_FOREACH recorre la cola de datos referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var.

La macro STAILQ_FOREACH_FROM se comporta de manera idéntica a STAILQ_FOREACH cuando var es NULL, de lo contrario trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_FOREACH_SAFE recorre la cola de datos referenciada por head en dirección hacia adelante, asignando cada elemento en turno a var. Sin embargo, a diferencia de STAILQ_FOREACH(), aquí está permitido tanto eliminar var como liberarlo del bucle de forma segura sin interferir con el recorrido.

La macro STAILQ_FOREACH_FROM_SAFE se comporta de manera idéntica a STAILQ_FOREACH_SAFE cuando var es NULL, de lo contrario trata a var como un elemento STAILQ encontrado previamente y comienza el bucle en var en lugar del primer elemento de la STAILQ referenciada por head.

La macro STAILQ_INIT inicializa la cola de datos referenciada por head.

La macro STAILQ_INSERT_HEAD inserta el nuevo elemento elm en la cabeza de la cola de datos.

La macro STAILQ_INSERT_TAIL inserta el nuevo elemento elm al final de la cola de datos.

La macro STAILQ_INSERT_AFTER inserta el nuevo elemento elm después del elemento listelm.

La macro STAILQ_LAST devuelve el último elemento de la cola de datos. Si la cola de datos está vacía, el valor de retorno es NULL.

La macro STAILQ_NEXT devuelve el siguiente elemento de la cola de datos, o NULL si este elemento es el último.

La macro STAILQ_REMOVE_AFTER elimina el elemento que sigue a elm de la cola de datos. A diferencia de STAILQ_REMOVE, esta macro no recorre la cola de datos completa.

La macro STAILQ_REMOVE_HEAD elimina el elemento de la cabeza de la cola de datos. Para una eficiencia óptima, los elementos que se eliminan de la cabeza de la cola de datos deberían usar explícitamente esta macro en lugar de la macro genérica STAILQ_REMOVE.

La macro STAILQ_REMOVE elimina el elemento elm de la cola de datos. Se debe evitar el uso de esta macro, ya que recorre la lista completa. Se debe usar una cola de datos doblemente enlazada si esta macro es necesaria en rutas de código de alto uso o para operar en colas de datos largas.

La macro STAILQ_SWAP intercambia el contenido de head1 y head2.

LISTS

A singly linked list is headed by a structure defined by the LIST_HEAD macro. This structure contains a pointer to the first element in the list. The elements are singly linked so that the list must be traversed from the beginning to find an arbitrary element. New elements can be added to the list at the head of the list, or after an existing element. A LIST_HEAD structure is declared as follows:

LIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro LIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro LIST_EMPTY evaluates to true if there are no items on the list.

The macro LIST_ENTRY declares a structure that connects the elements in the list.

The macro LIST_FIRST returns the first item on the list or NULL if the list is empty.

The macro LIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro LIST_FOREACH_FROM behaves identically to LIST_FOREACH when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike LIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro LIST_FOREACH_FROM_SAFE behaves identically to LIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found LIST element and begins the loop at var instead of the first element in the LIST referenced by head.

The macro LIST_INIT initializes the list referenced by head.

The macro LIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro LIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro LIST_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro LIST_NEXT returns the next element in the list, or NULL if this is the last.

The macro LIST_PREV returns the previous element in the list, or NULL if this is the first. List head must contain element elm.

The macro LIST_REMOVE removes the element elm from the list.

The macro LIST_SWAP swaps the contents of head1 and head2.

    LIST_HEAD_INITIALIZER(head);

struct entry {
	...
	LIST_ENTRY(entry) entries;	/* List. */
	...
} *n1, *n2, *n3, *np, *np_temp;

LIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
LIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
LIST_INSERT_AFTER(n1, n2, entries);

n3 = malloc(sizeof(struct entry));	/* Insert before. */
LIST_INSERT_BEFORE(n2, n3, entries);

LIST_REMOVE(n2, entries);		/* Deletion. */
free(n2);
					/* Forward traversal. */
LIST_FOREACH(np, &head, entries)
	np-> ...

					/* Safe forward traversal. */

	np->do_stuff();
	...
	LIST_REMOVE(np, entries);

	n1 = LIST_FIRST(&head);

TAIL QUEUES

A tail queue is headed by a structure defined by the TAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are doubly linked so that an arbitrary element can be removed without traversing the tail queue. New elements can be added to the tail queue after an existing element, before an existing element, at the head of the tail queue, or at the end of the tail queue. A TAILQ_HEAD structure is declared as follows:

TAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro TAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro TAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro TAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro TAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro TAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro TAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. var is set to NULL if the loop completes normally, or if there were no elements.

The macro TAILQ_FOREACH_FROM behaves identically to TAILQ_FOREACH when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE traverses the tail queue referenced by head in the reverse direction, assigning each element in turn to var.

The macro TAILQ_FOREACH_REVERSE_FROM behaves identically to TAILQ_FOREACH_REVERSE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macros TAILQ_FOREACH_SAFE and TAILQ_FOREACH_REVERSE_SAFE traverse the list referenced by head in the forward or reverse direction respectively, assigning each element in turn to var. However, unlike their unsafe counterparts, TAILQ_FOREACH and TAILQ_FOREACH_REVERSE make it possible to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro TAILQ_FOREACH_FROM_SAFE behaves identically to TAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the loop at var instead of the first element in the TAILQ referenced by head.

The macro TAILQ_FOREACH_REVERSE_FROM_SAFE behaves identically to TAILQ_FOREACH_REVERSE_SAFE when var is NULL, else it treats var as a previously found TAILQ element and begins the reverse loop at var instead of the last element in the TAILQ referenced by head.

The macro TAILQ_INIT initializes the tail queue referenced by head.

The macro TAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro TAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro TAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro TAILQ_INSERT_BEFORE inserts the new element elm before the element listelm.

The macro TAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro TAILQ_NEXT returns the next item on the tail queue, or NULL if this item is the last.

The macro TAILQ_PREV returns the previous item on the tail queue, or NULL if this item is the first.

The macro TAILQ_REMOVE removes the element elm from the tail queue.

The macro TAILQ_SWAP swaps the contents of head1 and head2.
