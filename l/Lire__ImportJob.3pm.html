NOMBRE

Lire::ImportJob - Objeto utilizado para representar una fuente de datos de logs

SINTAXIS

use Lire::ImportJob;
my $src = new Lire::ImportJob( "nombre",
                               'patrón'    => "/var/log/messsages",
                               'periodicidad'     => "única",
                               'procesador'  => $nombre,
                              );
my $archivo = $src->archivo,

DESCRIPCIÓN

El objeto Lire::ImportJob se utiliza para representar una fuente de datos de logs. También se puede crear a partir de datos de configuración (La especificación de configuración 'import_job').

new( $nombre, ... );

Crea un objeto Lire::ImportJob nuevo. Como parámetro obligatorio, toma el nombre de la fuente de logs.

Parámetros adicionales:

patrón
El camino a un archivo que contiene los datos de logs. Este nombre de archivo puede contener patrones de strftime(3) que se sustituirán para obtener el nombre del archivo. (Usable para rotación automática).
periodicidad
La periodicidad a la cual debe procesarse este ImportJob. Por defecto es 'única', lo que significa que este es un ImportJob de un solo uso. Otros valores reconocidos son 'horaria', 'diaria', 'semanal', 'mensual' y 'anual'.
convertidor
El nombre del convertidor que puede usarse para procesar el ImportJob. Este debe ser conocido por Lire::PluginManager.
configuración del convertidor
Parámetro de configuración para el DlfConverter.
filtro
Una comanda shell que se usará para filtrar el archivo de logs.
código de codificación
Codificación del archivo de logs. Si no se especifica, se usará la codificación por defecto del sistema.

name()

Devuelve el nombre de este ImportJob.

periodicidad( [$nueva_periodicidad] )

Sin argumento, devuelve la periodicidad de este ImportJob. Con un parámetro, establece la periodicidad del ImportJob a este valor nuevo.

archivo( [$tiempo] )

Devuelve el archivo a usar. El parámetro opcional $tiempo (que por defecto es ahora) se usa para calcular el nombre del archivo. Para encontrar el archivo a usar para los datos de ayer, se podría pasar el tiempo - 86400.

patrón( [$nuevo_archivo] )

Devuelve el patrón de archivo que se usará como fuente de datos de logs. Este patrón puede contener sustituciones de strftime(3). Si se usa un argumento, cambia el archivo.

filtro( [$nuevo_filtro] )

Devuelve la comanda shell que se usará como filtro. Undef o '' no usará un filtro.

codificación( [$nueva_codificación] )

Devuelve la codificación del archivo de logs. Undef y '' significan usar la codificación por defecto del sistema.

convertidor( [$nuevo_nombre] )

Devuelve el nombre del convertidor que se usará para este ImportJob.

configuración_del_convertidor( [$nueva_config] )

Devuelve un objeto de configuración que se usará por el DlfConverter (a través de la método set_configuration()).

manejador_log(_[ $tiempo ]_ )

Devuelve un handle de archivo que se puede usar para leer del archivo de logs. $tiempo es el parámetro tomado por el archivo para determinar el nombre final del archivo. Todos los filtros y codificaciones se configurarán correctamente.

ejecutar( $almacenamiento, [$tiempo] )

Ejecuta este ImportJob y lo importa en el $almacenamiento DlfStore. El parámetro $tiempo se usará para determinar el intervalo de tiempo cubierto por la periodicidad. Por defecto, es el tiempo actual.

VÉASE TAMBIÉN

Lire::DlfStore(3pm) Lire::DlfConverter(3pm)
