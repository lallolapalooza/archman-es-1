NOMBRE

Log::Log4perl::Config - Sintaxis del archivo de configuración de Log4perl

DESCRIPCIÓN

En "Log::Log4perl", se utilizan archivos de configuración para describir cómo deben comportarse los loggers del sistema.

El formato es el mismo que el utilizado para "log4j", solo con algunas extensiones específicas de Perl, como permitir la sintaxis de "Bar::Twix" en lugar de insistir en la específica de Java "Bar.Twix".

Las líneas de comentarios y las líneas en blanco (todo espacio en blanco o vacías) se ignoran.

Las líneas de comentarios pueden comenzar con espacios en blanco arbitrarios seguidos de uno de los siguientes:

# - Delimitador de comentario común
! - Delimitador de comentario de archivo Java .properties aceptado por log4j
; - Delimitador de comentario común de archivo .ini

Los comentarios al final de una línea no son compatibles. Así que si escribes

log4perl.appender.A1.filename=error.log #en el directorio actual

encontrarás tus mensajes en un archivo llamado "error.log #en el directorio actual".

Además, los espacios entre entidades sintácticas se ignoran, no importa si escribes

log4perl.logger.Bar.Twix=WARN,Screen

o

log4perl.logger.Bar.Twix = WARN, Screen

"Log::Log4perl" eliminará los espacios al analizar tu entrada.

Las asignaciones deben estar en una sola línea. Sin embargo, puedes dividir la línea si lo deseas usando un carácter de continuación al final de la línea. En lugar de escribir

log4perl.appender.A1.layout=Log::Log4perl::Layout::SimpleLayout

puedes dividir la línea en cualquier punto poniendo una barra invertida al final de la línea a continuar:

log4perl.appender.A1.layout=\
    Log::Log4perl::Layout::SimpleLayout

Ten cuidado con los espacios finales después de la barra invertida, los cuales impedirían que la línea se concatenara correctamente.

Loggers

Los loggers se abordan por categoría:

log4perl.logger.Bar.Twix      = WARN, Screen

Esto establece todos los loggers en la jerarquía de "Bar::Twix" con prioridad "WARN" y les adjunta un appender a definir posteriormente llamado "Screen". La configuración para el appender raíz (que no tiene nombre) se puede lograr simplemente omitiendo el nombre:

log4perl.logger = FATAL, Database, Mailer

Esto establece el nivel del appender raíz en "FATAL" y también les adjunta los appenders "Database" y "Mailer" a definir posteriormente. Alternativamente, el logger raíz puede ser abordado como "rootLogger":

log4perl.rootLogger = FATAL, Database, Mailer

El flag de aditividad de un logger se establece o se borra mediante la palabra clave "additivity":

log4perl.additivity.Bar.Twix = 0|1

(Nota el orden invertido de la palabra clave y el nombre del logger, resultado del dilema de que un nombre de logger podría terminar en ".additivity" según la documentación de log4j).

Appenders y Layouts

Los nombres de appenders utilizados en las líneas del archivo de configuración de Log4perl necesitan ser resueltos posteriormente, para definir las propiedades del appender y su layout. Para especificar propiedades de un appender, simplemente usa la palabra clave "appender" después de la introducción "log4perl" y el nombre del appender:

    # El logger Bar::Twix y su appender
log4perl.logger.Bar.Twix = DEBUG, A1
log4perl.appender.A1=Log::Log4perl::Appender::File
log4perl.appender.A1.filename=test.log
log4perl.appender.A1.mode=append
log4perl.appender.A1.layout=Log::Log4perl::Layout::SimpleLayout

Esto establece una prioridad de "DEBUG" para los loggers en la jerarquía de "Bar::Twix" y le asigna el appender "A1", que posteriormente se resuelve como un appender de tipo "Log::Log4perl::Appender::File", que simplemente añade a un archivo de log. Según el manual de "Log::Log4perl::Appender::File", el parámetro "filename" especifica el nombre del archivo de log y el parámetro "mode" puede establecerse en "append" o "write" (el primero añadirá al archivo de log si ya existe uno con el nombre especificado, mientras que el segundo lo sobrescribirá).

El orden de las entradas en el archivo de configuración no es importante, "Log::Log4perl" leerá todo el archivo primero e intentará darle sentido a las líneas después de conocer todo el contexto.

Puedes definir todos los loggers primero y luego sus appenders (incluso podrías definir tus appenders primero y luego tus loggers, pero no vayamos por ahí):

log4perl.logger.Bar.Twix = DEBUG, A1
log4perl.logger.Bar.Snickers = FATAL, A2
log4perl.appender.A1=Log::Log4perl::Appender::File
log4perl.appender.A1.filename=test.log
log4perl.appender.A1.mode=append
log4perl.appender.A1.layout=Log::Log4perl::Layout::SimpleLayout
log4perl.appender.A2=Log::Log4perl::Appender::Screen
log4perl.appender.A2.stderr=0
log4perl.appender.A2.layout=Log::Log4perl::Layout::PatternLayout
log4perl.appender.A2.layout.ConversionPattern = %d %m %n

Nota que tienes que especificar la ruta completa a la clase de layout y que "ConversionPattern" es la palabra clave para especificar las instrucciones de formato estilo printf.

Recetario de Archivo de Configuración

Aquí tienes algunos ejemplos de archivos de configuración de Log4perl usados frecuentemente:

Añadir a STDERR

log4perl.category.Bar.Twix      = WARN, Screen
log4perl.appender.Screen        = Log::Log4perl::Appender::Screen
log4perl.appender.Screen.layout = \
    Log::Log4perl::Layout::PatternLayout
log4perl.appender.Screen.layout.ConversionPattern = %d %m %n

Añadir a STDOUT

log4perl.category.Bar.Twix      = WARN, Screen
log4perl.appender.Screen        = Log::Log4perl::Appender::Screen
log4perl.appender.Screen.stderr = 0
log4perl.appender.Screen.layout = \
    Log::Log4perl::Layout::PatternLayout
log4perl.appender.Screen.layout.ConversionPattern = %d %m %n

Añadir a un archivo de log

log4perl.logger.Bar.Twix = DEBUG, A1
log4perl.appender.A1=Log::Log4perl::Appender::File
log4perl.appender.A1.filename=test.log
log4perl.appender.A1.mode=append
log4perl.appender.A1.layout = \
    Log::Log4perl::Layout::PatternLayout
log4perl.appender.A1.layout.ConversionPattern = %d %m %n

Nota que podrías incluso omitir

log4perl.appender.A1.mode=append

y aún así tener el logger añadiendo al archivo de log por defecto, aunque el módulo "Log::Log4perl::Appender::File" hace exactamente lo contrario. Esto se debe a algunas triquiñuelas "Log::Log4perl" realiza tras bambalinas para asegurarse de que las aplicaciones CGI de principiantes no sobrescriban el archivo de log cada vez que se ejecutan.

Escribir un archivo de log desde cero

Si detestas la estrategia de añadir por defecto de Log::Log4perl, ciertamente puedes anularla:

log4perl.logger.Bar.Twix = DEBUG, A1
log4perl.appender.A1=Log::Log4perl::Appender::File
log4perl.appender.A1.filename=test.log
log4perl.appender.A1.mode=write
log4perl.appender.A1.layout=Log::Log4perl::Layout::SimpleLayout

"write" es el "mode" que hace que "Log::Log4perl::Appender::File" sobrescriba explícitamente el archivo de log si existe.

Archivos de configuración codificados en utf-8

Los archivos de configuración pueden ser codificados en UTF-8. Asegúrate de que tu editor guarde el archivo con esa codificación y de que tu aplicación Perl pueda leerla. Para usar UTF-8, debes añadir la siguiente línea al principio de tu archivo de configuración:

# -*- coding: utf-8 -*-

O puedes especificar la codificación UTF-8 directamente en el código Perl:

use Log::Log4perl qw(:easy);
Log::Log4perl::init( '/etc/log4perl.conf' );

O bien, si quieres usar la codificación UTF-8 y tu sistema no la soporta por defecto:

use encoding 'utf8';
use Log::Log4perl qw(:easy);
Log::Log4perl::init( '/etc/log4perl.conf' );

¡Ojo! Si tu archivo de configuración está en UTF-8, debes asegurarte de que la declaración de codificación sea la primera línea del archivo. De lo contrario, el intérprete de Perl podría no reconocerla y podrías tener problemas de visualización de caracteres.
