NOMBRE

Log::Log4perl::Appender::TestFileCreeper - Añadidor de prueba intencionalmente lento

SINOPSIS

use Log::Log4perl::Appender::TestFileCreeper;
my $app = Log::Log4perl::Appender::TestFileCreeper->new(
  filename  => 'file.log',
  mode      => 'append',
);
$file->log(message => "Log me\n");

DESCRIPCIÓN

Este es un añadidor de prueba, y es intencionalmente lento. Escribe un byte a la vez para provocar errores de sincronización. No lo uses, a menos que sea para pruebas.
