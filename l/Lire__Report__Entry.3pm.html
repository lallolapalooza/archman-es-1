Entry(3pm) Documentación de Lire::Report Entry(3pm)

NOMBRE

Lire::Report::Entry - Interfaz a los datos del subinforme.

SINOPSIS

foreach my $name ( $entry->names() ) {
    print "Nombre: ", $name->{'content'}, "\n";
}
foreach my $value ( $entry->values() ) {
    if ( ref $value eq 'Lire::Report::Group' ) {
        # El valor es un grupo
        foreach my $e ( $value->entries() ) {
            print_entry( $e );
        }
    } else {
        print "Valor: ", $value->{'content'}, "\n";
    }
}

DESCRIPCIÓN

Los objetos Lire::Report::Entry se utilizan para mantener los datos del subinforme.

CONSTRUCTOR

Se crea un nuevo objeto Entry utilizando el método create_entry en un objeto Lire::Report::Subreport o Lire::Report::Group. Utilice los métodos add_name(), create_group() y add_value() para rellenar la entrada.

MÉTODOS DEL OBJETO

row_idx()

Devuelve el índice de fila en el cuerpo de la tabla donde se deben mostrar los datos de esta entrada. Si es indefinido, esta entrada no debe mostrarse.

subreport()

Devuelve el objeto Lire::Report::Subreport en el que está contenida esta entrada.

group()

Devuelve el objeto Lire::Report::Group que contiene esta entrada.

group_info()

Devuelve el Lire::Report::GroupInfo que contiene la información relacionada con el grupo en el que se encuentra esta entrada.

data()

Devuelve como un array los datos contenidos en esta entrada. Es una lista de hashes u objetos Lire::Report::Group.

data_by_name( $name )

Devuelve el elemento de datos contenido en esta Entrada que fue generado por el operador llamado $name. Devuelve undef si no se puede encontrar dicho elemento de datos.

names()

Devuelve los nombres de la entrada. Es un array de hashes. El hash del nombre contiene las siguientes claves:

type
Siempre establecido en 'name'.
content
Ese es el contenido real del elemento de nombre. Contiene el nombre en un formato adecuado para mostrar.
value
Contiene el valor sin formato. Por ejemplo, cuando el nombre es una cadena de tiempo, este atributo contendrá el tiempo en segundos desde la época (epoch).
missing_cases
Este valor contiene el número de registros DLF que tenían un valor indefinido en uno de los campos requeridos para calcular esta estadística.
range
Para algunos nombres, el contenido real expresa un rango (tiempo, tamaño, etc.). Este atributo contiene la longitud del rango.
col_info
El objeto Lire::Report::ColumnInfo que describe este nombre.

add_name( $content, [$value], [$range] )

Añade un nuevo nombre a esta entrada. Consulte la documentación del método names() para obtener una descripción del significado de los diversos parámetros, que tienen el mismo significado que las claves con el mismo nombre.

Los nombres, valores y grupos deben añadirse en el orden especificado por el GroupInfo de esta entrada. De lo contrario, se producirá una excepción.

values()

Devuelve los valores de la entrada. Es un array de hashes u objetos. Si el valor es un hash, tiene las siguientes claves:

type
Siempre establecido en 'value'.
content
Ese es el contenido real del elemento de valor. Contiene el valor en un formato adecuado para mostrar.
value
Contiene el valor sin formato. Por ejemplo, cuando los bytes se muestran usando "1M" o "1.1G", esto contendrá el valor en bytes individuales.
missing_cases
El número de registros DLF que tenían un valor indefinido en uno de los campos requeridos por este operador.
total
Esto se utiliza para valores que representan un promedio. Contiene el total que compone el promedio.
n
Esto se utiliza para valores que representan un promedio. Contiene el total que se utilizó en la división para calcular el promedio.
col_info
El objeto Lire::Report::ColumnInfo que describe este valor.

groups()

Devuelve en un array los Lire::Report::Group contenidos en esta Entrada.

create_group()

Crea un nuevo grupo para esta entrada. Esto también lo añadirá a los datos de esta entrada. Si crea el grupo fuera de orden en comparación con los nombres y valores que deberían ir en esa entrada, obtendrá una excepción.

add_value( %value )

Añade un nuevo valor a esta entrada. El hash del valor debe contener al menos la clave 'content'. También puede incluir valores para las claves 'n', 'total' y 'missing_cases'. Consulte la documentación del método values() para obtener una descripción del significado de los diversos parámetros: tienen el mismo significado que las claves con los mismos nombres.

Los nombres, valores y grupos deben añadirse en el orden especificado por el GroupInfo de esta entrada. De lo contrario, se producirá una excepción.
