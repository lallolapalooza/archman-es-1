NOMBRE

Lire::Group - Clase base para la implementación del agregador de grupo

SINOPSIS

use Lire::Group;

DESCRIPCIÓN

Este módulo es la clase base para la implementación del agregador de grupo. Este agregador dividirá los registros DLF en grupos que tengan la misma clave. La clave se compone de uno o más campos no numéricos. El número de claves a mantener en el informe se puede configurar a través del atributo limit. Las claves también se pueden ordenar usando el atributo sort.

CONSTRUCTOR

nuevo( %parámetros )

Crea una nueva instancia de un agregador de grupo. Además de los parámetros normales del operador de informe, el atributo limit se puede inicializar en el momento de la creación.

MÉTODOS

límite( [$nuevo_límite] )

Devuelve el número de claves a mostrar en el informe. Puede ser un entero o el nombre de uno de los parámetros de especificación del informe (cuando comienza con $).

El atributo limit se puede cambiar pasando un parámetro $nuevo_límite.

campos_ordenación( [$nuevos_campos_ordenación] )

Devuelve los campos y/o los valores del operador que se utilizarán para ordenar las entradas generadas por este agregador. Se trata de una referencia a una matriz que contiene nombres de campos de grupo y/o nombres de operadores.

Los campos de ordenación se pueden cambiar pasando una nueva referencia a matriz.

campos_grupo( [$nuevos_campos] )

Devuelve como referencia a una matriz de objetos Lire::GroupField los campos DLF que se utilizan para agrupar los registros.

Si se establece $nuevos_campos, se cambiarán los campos DLF utilizados para agrupar los registros. Este parámetro debe ser una referencia a una matriz de objetos Lire::GroupField.

inserción_binaria

Función recursiva que utiliza una búsqueda binaria para insertar $item en $array utilizando $cmp como operador de comparación. $first_idx y $max_idx especifican los límites de la búsqueda. La búsqueda finaliza cuando $first_idx == $max_idx o cuando $sort_key se ordena en o antes de $first_idx o en o después de $max_idx
