LOGIMPORT(3) Manual de funciones de biblioteca LOGIMPORT(3)

NOMBRE

LOGIMPORT - introducción a la biblioteca para importar datos y crear un archivo PCP

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/import.h>

cc ... -lpcp_import -lpcp

SINOPSIS de Perl

use PCP::LogImport;

SINOPSIS de Python

from pcp import pmi

DESCRIPCIÓN

La API de importación de registros de Performance Co-Pilot (LOGIMPORT) es una biblioteca (con envoltorios Perl y Python) que soporta la creación de archivos PCP a partir de fuentes externas de datos de rendimiento, ya sea en forma de registros históricos y hojas de cálculo, o de fuentes en tiempo real que **no** están integradas como un Agente de Dominio de Métricas de Rendimiento (PMDA) bajo el control de pmcd(1).

El uso típico para LOGIMPORT implicaría:

  • Una llamada inicial a pmiStart(3).
  • Llamadas opcionales a pmiSetHostname(3) y/o pmiSetTimezone(3) para establecer el nombre de host y la zona horaria de la fuente de los datos de rendimiento.
  • Una o más llamadas a pmiAddMetric(3) para definir las métricas de rendimiento.
  • Una o más llamadas a pmiAddInstance(3) para definir las instancias asociadas con las métricas.
  • Llamadas opcionales a pmiGetHandle(3) para definir manejadores de conveniencia para pares métrica-instancia.
  • Un bucle principal en el que se ingieren los datos de rendimiento y, para cada intervalo de tiempo de muestreo, se construye el registro del archivo PCP mediante llamadas a pmiPutValue(3), pmiPutValueHandle(3), pmiPutText(3), y/o pmiPutLabel(3), seguido de una llamada a pmiWrite(3) para vaciar todos los datos y cualquier metadato nuevo asociado al archivo PCP. Alternativamente, se podría usar pmiPutResult(3) para empaquetar y procesar todos los datos para un intervalo de tiempo de muestreo.
  • Una vez que la fuente de entrada de datos se ha consumido, llamar a pmiEnd(3) para completar la creación del archivo PCP y cerrar todos los archivos abiertos.

Si se descubren nuevas métricas y/o instancias durante la ingesta de datos, estas se pueden añadir mediante llamadas posteriores a pmiAddMetric(3) y/o pmiAddInstance(3), siempre que todas las métricas e instancias se hayan definido antes de una llamada a pmiGetHandle(3), pmiPutValue(3) **o** pmiPutResult(3) que haga referencia a esas métricas e instancias.
