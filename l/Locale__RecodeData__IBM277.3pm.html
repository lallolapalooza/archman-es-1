NOMBRE

Locale::RecodeData::IBM277 - Rutinas de conversión para IBM277

SINOPSIS

Este módulo es interno en libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para IBM277.

COMENTARIOS

Las siguientes observaciones se extraen de la charmap original:

versión: 1.0
 fuente: IBM NLS RM Vol2 SE09-8002-01, marzo 1990
 alias EBCDIC-CP-DK
 alias EBCDIC-CP-NO

Nota: ¡los alias mencionados anteriormente no son necesariamente válidos!
