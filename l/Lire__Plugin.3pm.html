Plugin(3pm) Documentación de Lire de LogReport Plugin(3pm)

NOMBRE

Lire::Plugin - Interfaz base de todos los plugins de Lire.

SINOPSIS

use base qw/ Lire::Plugin /;

DESCRIPCIÓN

Este paquete define la interfaz base implementada por todos los plugins.

CONSTRUCTOR POR DEFECTO

La clase plugin tiene el constructor new() que bendice una referencia a un hash.

name()

Devuelve el nombre del plugin.

title()

Devuelve un nombre más amigable para el plugin.

description()

Devuelve una documentación basada en XML DocBook del plugin.

type

Devuelve el tipo de plugin. Hay tres tipos de plugins en Lire:

dlf_converter
Estos plugins se utilizan para convertir archivos de registro a DLF. El plugin también necesitará implementar la interfaz Lire::DlfConverter.
output_format
Estos plugins se utilizan para formatear informes XML. El plugin de este tipo debe implementar la interfaz Lire::OutputFormat.
dlf_analyser
Estos plugins se utilizan para generar otros registros DLF a partir de registros Dlf existentes. Deben implementar la interfaz Lire::Analaser.
chart_type
Estos plugins se utilizan para generar gráficos.

VER TAMBIÉN

Lire::PluginManager(3pm), Lire::DlfConverter(3pm), Lire::OutputFormat(3pm), Lire::DlfAnalyser(3pm), Lire::DlfChartType(3pm)
