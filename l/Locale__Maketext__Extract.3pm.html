Locale::Maketext::Extract(3pm) Documentación de Perl contribuida por el usuario Locale::Maketext::Extract(3pm)

NOMBRE

Locale::Maketext::Extract - Extraer cadenas traducibles de la fuente

VERSIÓN

versión 1.00

SINOPSIS

my $Ext = Locale::Maketext::Extract->new;
$Ext->read_po('messages.po');
$Ext->extract_file($_) for <*.pl>;
# Establecer $entries_are_in_gettext_format si los archivos .pl anteriores usan
# loc('%1') en lugar de loc('[_1]')
$Ext->compile($entries_are_in_gettext_format);
$Ext->write_po('messages.po');
-----------------------------------
### Especificar plugins de análisis ###
my $Ext = Locale::Maketext::Extract->new(
    # Especificar qué plugins de análisis usar
    plugins => {
        # Usar el analizador de Perl, procesar archivos con extensión .pl .pm .cgi
        perl => [],
        # Usar el analizador de YAML, procesar todos los archivos
        yaml => ['*'],
        # Usar el analizador de TT2, procesar archivos con extensión .tt2 .tt .html
        # o que coincidan con la regex
        tt2  => [
            'tt2',
            'tt',
            'html',
            qr/\.tt2?\./
        ],
        # Usar My::Module como un analizador para todos los archivos
        'My::Module' => ['*'],
    },
    # Advertir si un analizador no puede procesar un archivo o hay problemas al cargar un plugin
    warnings => 1,
    # Listar archivos procesados
    verbose => 1,
);

DESCRIPCIÓN

Este módulo puede extraer cadenas traducibles de archivos y escribirlas de nuevo en archivos PO. También puede analizar archivos PO existentes y fusionar su contenido con las cadenas recién extraídas.

Una utilidad de línea de comandos, xgettext.pl, se instala con este módulo también.

Los analizadores de formato se cargan como plugins, por lo que es posible definir sus propios analizadores.

Los siguientes formatos de archivos de entrada son compatibles:

Archivos fuente de Perl (plugin: perl)
Los nombres válidos de funciones de localización son: "translate", "maketext", "gettext", "l", "loc", "x", "_" y "__".

Para un analizador de Perl ligeramente más preciso, pero mucho más lento, puede usar el plugin PPI. Este no tiene un nombre corto (como "perl"), pero debe especificarse en su totalidad.

HTML::Mason (Mason 1) y Mason (Mason 2) (plugin: mason)
HTML::Mason (también conocido como Mason 1)
Las cadenas dentro de <&|/l>...</&> y <&|/loc>...</&> son extraídas.

Mason (también conocido como Mason 2) Las cadenas dentro de <% $.floc { %>...</%> o <% $.fl { %>...</%> o <% $self->floc { %>...</%> o <% $self->fl { %>...</%> son extraídas.

Template Toolkit (plugin: tt2)
Las formas válidas son: 
[% | l(arg1,argn) %]cadena[% END %]
[% 'cadena' | l(arg1,argn) %]
[% l('cadena',arg1,argn) %]
FILTER y | son intercambiables
l y loc son intercambiables
los argumentos son opcionales
Text::Template (plugin: text)
Las oraciones entre "STARTxxx" y "ENDxxx" se extraen individualmente.
YAML (plugin: yaml)
Las formas válidas son _"cadena" o _'cadena', por ejemplo: 
title: _"Mi título"
desc:  _'Mi "cadena" entre comillas'

Las comillas no necesitan escaparse, así que también podrías hacer:

desc:  _"Mi "cadena" entre comillas"
HTML::FormFu (plugin: formfu)
HTML::FormFu utiliza un archivo de configuración para generar formularios, con soporte incorporado para localizar errores, etiquetas, etc.

Extraemos el texto después de "_loc: ":
content_loc: esta es la cadena
message_loc: ['Cadena máxima: [_1]', 10]

Plantilla Genérica (plugin: generic)
Las cadenas dentro de {{...}} se extraen.

Constructor

new()
new(
    plugins   => {...},
    warnings  => 1 | 0,
    verbose   => 0 | 1 | 2 | 3,
)

Ver "Plugins", "Warnings" y "Verbose" para más detalles

Plugins

$ext->plugins({...});

Locale::Maketext::Extract utiliza plugins (ver más abajo la lista) para analizar diferentes formatos.

Cada plugin también puede especificar qué tipos de archivo puede analizar.

# usar solo el plugin YAML
# analizar solo archivos con la lista de extensiones predeterminada definida en el plugin
# es decir, .yaml .yml .conf
$ext->plugins({
    yaml => [],
})
# usar solo el plugin Perl
# analizar todos los tipos de archivo
$ext->plugins({
    perl => '*'
})
$ext->plugins({
    tt2  => [
        'tt',              # coincide con el nombre base del archivo contra /\.tt$/
        qr/\.tt2?\./,      # coincide con el nombre base del archivo contra la regex
        \&my_filter,       # se llama a la ref de código
    ]
})
sub my_filter {
    my ($base_filename,$path_to_file) = @_;
    return 1 | 0;
}
# Especificar tu propio analizador
# analizar solo archivos con la lista de extensiones predeterminada definida en el plugin
$ext->plugins({
    'My::Extract::Parser'  => []
})

Por defecto, si no se especifican plugins, primero intenta determinar qué plugins están destinados específicamente al tipo de archivo y los usa. Si no se encuentran tales plugins, utiliza todos los plugins incorporados, anulando los tipos de archivo especificados en cada uno.

Plugins disponibles

"perl" : Locale::Maketext::Extract::Plugin::Perl
Para un analizador de Perl ligeramente más preciso pero mucho más lento, puede usar el plugin PPI. Este no tiene un nombre corto, pero debe especificarse en su totalidad, es decir: Locale::Maketext::Extract::Plugin::PPI
"tt2" : Locale::Maketext::Extract::Plugin::TT2
"yaml" : Locale::Maketext::Extract::Plugin::YAML
"formfu" : Locale::Maketext::Extract::Plugin::FormFu
"mason" : Locale::Maketext::Extract::Plugin::Mason
"text" : Locale::Maketext::Extract::Plugin::TextTemplate
"generic" : Locale::Maketext::Extract::Plugin::Generic

Además, consulta Locale::Maketext::Extract::Plugin::Base para obtener detalles sobre cómo escribir tu propio plugin.

Advertencias

Dado que los plugins YAML y TT2 utilizan analizadores adecuados, en lugar de solo regex, si un archivo fuente no es válido y no puede analizar el archivo, el analizador lanzará un error y abortará el análisis.

Se intentará el siguiente plugin habilitado.

Por defecto, no verás estos errores. Si deseas verlos, habilita las advertencias a través de new(). Todos los errores de análisis se imprimirán en STDERR.

Además, si estás desarrollando tu propio plugin, activa las advertencias para ver cualquier error que resulte de la carga de tu plugin.

Detallado

Si deseas ver qué archivos se han procesado, qué plugins se usaron y qué cadenas se extrajeron, habilita "verbose". Si no se encontró ningún plugin aceptable, o no se extrajeron cadenas, el archivo no se lista:

   $ext = Locale::Extract->new( verbose => 1 | 2 | 3);
O
   xgettext.pl ... -v           # se informan los archivos
   xgettext.pl ... -v -v        # se informan los archivos y plugins
   xgettext.pl ... -v -v -v     # se informan los archivos, plugins y cadenas

Manipulación de archivos PO

$ext->read_po($file);
$ext->write_po($file);

Estos métodos leen y escriben archivos PO. Si el archivo PO existe cuando se escribe, los nuevos elementos extraídos se fusionarán con los existentes. Si no se ha leído ningún archivo PO, se creará uno nuevo.

El archivo PO es una lista de entradas de PO. Cada entrada es una referencia a una matriz, donde el primer elemento es una cadena de referencia y el segundo es una cadena de traducción.

   $ext->add_entry(
       $msgctxt => $msgid,
       $msgstr  => $translation,
       $comment => $comment, # optional comment
       $extracted_comment => $comment # optional comment from parser
   )

Por defecto, el comentario de extracción se antepone al comentario existente.

   $ext->add_entry( undef, 'Hello', 'Hola');
   $ext->add_entry( undef, 'Hello', 'Bonjour', undef, 'This is a comment');
   $ext->add_entry( 'Context', 'Hello', 'Hola');
   $ext->add_entry( 'Context', 'Hello', 'Bonjour', 'A comment');
   $ext->add_entry( 'Context', 'Hello', 'Hola', undef, 'An extraction comment');

Para obtener la lista de todas las entradas del léxico actual:

   my $entries = $ext->entries;

Para obtener una entrada específica (devuelve undef si no se encuentra):

   my $entry = $ext->entry($msgctxt, $msgid);

Para eliminar una entrada (devuelve 0 si no se encuentra):

   my $deleted = $ext->del_entry($msgctxt, $msgid);

Establecer la cabecera del archivo PO (por defecto, se establece la cabecera estándar de gettext).

   $ext->set_header( $header_string );

Establecer la forma en que se genera el formato de archivo POT/PO.

 $ext->entries_are_in_gettext_format(1); # Defaults to false

Esto es útil si el código fuente está usando la forma de locale-gen (loc('%1') en lugar de la forma que se usa en la mayoría de las traducciones (loc('[_1]')).

Compilación

$ext->compile( $entries_are_in_gettext_format? 1 : 0 );

Convierte el léxico actual (cadenas de referencia) en un hash de traducciones.

Este método se llama automáticamente cuando se llama a write_po. Lo llamarás solo si deseas acceder a las entradas compiladas antes de escribir en un archivo PO.

Las entradas compiladas se almacenan como un hash donde la clave es la cadena de referencia y el valor es la cadena de traducción.

   my $compiled_entries = $ext->compiled_entries;

Para obtener una traducción específica (devuelve undef si no se encuentra):

   my $translation = $ext->compiled_entry($msgid);

Extracción de archivos

$ext->extract_file($file);
$ext->extract_directory($dir);

El método extract_file toma un nombre de archivo y lo analiza utilizando el plugin apropiado (si se encuentra uno). Todas las cadenas extraídas se agregan al léxico interno.

Si se especifican plugins, se utilizarán solo esos plugins. Si no, se probarán todos los plugins incorporados.

El método extract_directory hace lo mismo para todos los archivos dentro de un directorio, recursivamente.

Si el argumento plugins se pasa al constructor, entonces solo se considerarán los plugins especificados.

   my $ext = Locale::Maketext::Extract->new(
       plugins => { perl => [], tt2 => [] }
   );
   $ext->extract_file('my_file.pl'); # Only the perl plugin is tried
   $ext->extract_file('my_file.tt'); # Only the tt2 plugin is tried

Si el argumento plugins no se pasa al constructor, entonces se intentarán todos los plugins incorporados:

   my $ext = Locale::Maketext::Extract->new;
   $ext->extract_file('my_file.pl'); # Perl plugin is tried, then tt2, etc.

Si un plugin especifica qué extensiones de archivo debe procesar, entonces solo esos archivos se procesarán.

   my $ext = Locale::Maketext::Extract->new(
       plugins => { perl => [qw( .pl .pm )] }
   );
   $ext->extract_file('my_file.pl'); # Processed by perl plugin
   $ext->extract_file('my_file.txt'); # Not processed (not a .pl or .pm)

Si un plugin no tiene una lista de extensiones, se asumirá que procesará cualquier archivo que se le pase.

   my $ext = Locale::Maketext::Extract->new(
       plugins => { perl => [], yaml => [] }
   );
   $ext->extract_file('my_file.pl'); # Processed by perl plugin, then yaml plugin
   $ext->extract_file('my_file.yaml'); # Processed by perl plugin, then yaml plugin

Puede especificar un glob o una expresión regular para que coincida con los nombres de archivo.

   my $ext = Locale::Maketext::Extract->new(
       plugins => { perl => [ qr/ ( \.pl | \.pm ) $/x ] }
   );

Lectura de archivos PO

$ext->read_po($file);

Lee un archivo PO existente y agrega sus entradas al léxico interno. Si existe una entrada con el mismo contexto y cadena de referencia, entonces se actualizará su cadena de traducción.

Si el archivo PO tiene cabeceras, estas se usarán para establecer las cabeceras internas del objeto Extract.

Limpieza

$ext->clear;

Elimina todas las entradas del léxico interno.

Manejo de formas plurales

$ext->plural_forms( $plural_form_string );

Esto se utiliza para configurar las reglas de pluralización de un archivo PO.

Por ejemplo, para español:

 $ext->plural_forms( 'nplurals=2; plural=(n != 1);' );

Si el archivo PO tiene una cabecera que especifica las formas plurales, este método no es necesario, ya que se leerá de la cabecera.

NAME

Locale::Maketext::Extract - Extraer y compilar cadenas de texto

VERSION

Esta documentación describe la versión 1.00 de Locale::Maketext::Extract.

SYNOPSIS

 use Locale::Maketext::Extract;

 my $extractor = Locale::Maketext::Extract->new(
     -encoding => 'utf-8',
 );

 # Extraer de código fuente
 $extractor->extract(
     $file_content,
     -source_file => $filename,
 );

 # o
 $extractor->extract_file($filename);

 # Compilar a PO
 my $po = $extractor->write_po(\&add_po_entry);

 # Leer desde PO
 $extractor->read_po($po_filename);

 # Acceder a los datos
 my @msgids = $extractor->msgids;
 my $msgstr = $extractor->msgstr('Hello World');

DESCRIPTION

Este módulo se centra en la extracción de cadenas de texto internacionalizables de código fuente y en su posterior compilación en un formato manejable, típicamente un archivo PO (Portable Object) para herramientas como GNU gettext.

Permite la extracción de cadenas de los formatos Maketext y Gettext, y la compilación en un formato interno unificado.

PO File manipulation

method read_po ($file)

method write_po ($file, $add_format_marker?)

Extraction

extract
extract_file

Compilation

compile($entries_are_in_gettext_style?)

Fusiona las "entries" en "compiled_entries".

Si $entries_are_in_gettext_style es verdadero, se asume que las entradas extraídas previamente están en el estilo de Gettext (por ejemplo, %1).

De lo contrario, se asume que están en el estilo de Maketext (por ejemplo, "[_1]") y se convierten al estilo de Gettext antes de fusionarse en "compiled_entries".

Las "entries" *no* se borran después de cada compilación; use "-"set_entries()> para borrarlas si necesita extraer de fuentes con estilos diferentes.
