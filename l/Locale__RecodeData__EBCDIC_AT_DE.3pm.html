NOMBRE

Locale::RecodeData::EBCDIC_AT_DE - Rutinas de conversión para EBCDIC_AT_DE

SINOPSIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo contiene las tablas de conversión y rutinas para EBCDIC-AT-DE.

COMENTARIOS

Las siguientes observaciones se han extraído del charmap original:

versión: 1.0
 fuente: IBM 3270 Char Set Ref Ch 10, GA27-2837-9, Abril 1987

¡Por favor, ten en cuenta que los alias mencionados anteriormente no son necesariamente válidos!
