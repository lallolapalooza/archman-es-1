WELF(3pm) Documentación de Lire de LogReport WELF(3pm)

NOMBRE

Lire::WELF - Implementación base de un analizador del formato de registro mejorado de WebTrends(tm)

SINOPSIS

use Lire::WELF;

my $parser = new Lire::WELF;

my $welf_rec = $parser->parse( $line );

DESCRIPCIÓN

Este módulo define un objeto capaz de analizar el formato de registro mejorado (WELF) de WebTrends(tm). Ese formato de registro fue definido por WebTrends(tm) para su suite de firewall. Define un formato extensible que ahora es utilizado por varios firewalls de filtrado de paquetes y/o proxy.

El documento que describe este formato está disponible en http://www.webtrends.com/partners/welfOverview.htm

Una lista de productos/vendedores que soportan este formato se puede encontrar en http://www.webtrends.com/partners/firewall.htm

Se crea un objeto analizador WELF utilizando el método new():

my $parser = new Lire::WELF();

Para analizar un registro WELF, se invoca el método parse() con la línea que contiene el registro como parámetro:

my $rec    = $parser->parse( $line );

El $rec es una referencia hash con el nombre del campo WELF utilizado como clave y el valor del registro como valor.

Ningún valor se interpreta o verifica, excepto por lo siguiente:

tiempo
El campo de tiempo se convertirá a tiempo epoch.
comillas
Las comillas utilizadas cuando el valor contiene espacios se eliminan.

EXTENCIONES WELF

El analizador también soporta "extensiones" al formato encontradas en los campos.

puerto
Interpretaremos correctamente los campos src (origen) y dst (destino) que tienen el puerto incrustado en ellos: 
src=192.168.1.1:1037
interfaz
Un posible :IFNAME también se interpretará como el nombre de la interfaz: 
dst=192.168.100.10:23:WAN
zona horaria
El campo de tiempo puede contener un identificador de zona horaria: 
time="2001-12-02 12:34:12 UTC"

Campos Derivados

El analizador generará algunos campos 'derivados' para completar el formato.

puerto_src
Contendrá la porción del puerto de origen del campo dst cuando se utilizan extensiones de SonicWall.
puerto_dst
Contendrá la porción de la interfaz del campo dst cuando se utilizan extensiones de SonicWall.
if_src
Contendrá la porción de la interfaz del campo src cuando se utilizan extensiones de SonicWall.
if_dst
Contendrá la porción de la interfaz del campo dst cuando se utilizan extensiones de SonicWall.
