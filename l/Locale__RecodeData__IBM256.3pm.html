Locale::RecodeData::IBM256 - Rutinas de conversión para IBM256

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo use directamente!

DESCRIPCIÓN

Este módulo es generado y contiene las tablas y rutinas de conversión para IBM256.

COMENTARIOS

Los siguientes comentarios se han extraído del mapa de caracteres original:

version: 1.0
 source: IBM Registry C-H 3-3220-050
alias EBCDIC-INT1

¡Tenga en cuenta que los alias enumerados anteriormente no son necesariamente válidos!

Locale::RecodeData::IBM256(3pm) man page

NAME

Locale::RecodeData::IBM256 - IBM Code Page 256 character data

SYNOPSIS

  use Encode;
  use Locale::RecodeData::IBM256;

  my $string = decode("IBM256", "\x80\x82\x95");
  my $bytes  = encode("IBM256", "\xE2\x82\xAC"); # EuroSign

DESCRIPTION

This module provides the character mapping data for the IBM Code Page 256 encoding.

It is intended to be used with the Encode module.

This encoding is also known as cp256, cp037, or CP037.

The mapping is based on the XPG4 standard.

COMMENTS

This encoding is used for EBCDIC on IBM mainframes and AS/400 systems.

The EBCDIC encoding for Latin-1 characters is defined by the ISO 8859-1 standard.
