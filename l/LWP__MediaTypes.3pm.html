LWP::MediaTypes(3) Documentación de Perl aportada por el usuario LWP::MediaTypes(3)

NOMBRE

LWP::MediaTypes - adivina el tipo de medio para un archivo o una URL

SINOPSIS

use LWP::MediaTypes qw(guess_media_type);
$type = guess_media_type("/tmp/foo.gif");

DESCRIPCIÓN

Este módulo proporciona funciones para manejar tipos de medios (también conocidos como tipos MIME) y codificaciones. El mapeo de extensiones de archivo a tipos de medios se define en el archivo media.types. Si el archivo ~/.media.types existe, se utiliza en su lugar. Para compatibilidad hacia atrás, también buscaremos ~/.mime.types.

Las siguientes funciones se exportan por defecto:

guess_media_type( $filename )
guess_media_type( $uri )
guess_media_type( $filename_or_object, $header_to_modify )
Esta función intenta adivinar el tipo de medio y la codificación para un archivo u objetos que soportan un método "path" o "filename", por ejemplo, objetos URI o File::Temp. Cuando un objeto no soporta ninguno de los métodos, se convertirá a cadena para determinar el nombre del archivo. Devuelve el tipo de contenido, que es una cadena como "text/html". En contexto de array, también devuelve cualquier codificación de contenido aplicada (en el orden utilizado para codificar el archivo). Puede pasar una referencia de objeto URI en lugar del nombre del archivo.

Si el tipo no puede deducirse a partir del nombre del archivo, entonces guess_media_type() permitirá que el operador Perl "-T" lo intente. Si esto funciona (y "-T" devuelve un valor VERDADERO) entonces devolveremos text/plain como tipo, de lo contrario devolveremos application/octet-stream como tipo.

El segundo argumento opcional debe ser una referencia a un objeto HTTP::Headers o cualquier objeto que implemente el método $obj->header de manera similar. Cuando está presente, los valores de 'Content-Type' y 'Content-Encoding' se establecerán para esta cabecera.

media_suffix( $type, ... )
Esta función devolverá todos los sufijos que se pueden usar para denotar el/los tipo(s) de medio especificado(s). Se pueden usar tipos comodín. En contexto escalar, devolverá el primer sufijo encontrado. Ejemplos: 
@suffixes = media_suffix('image/*', 'audio/basic');
$suffix = media_suffix('text/html');

Las siguientes funciones solo se exportan por solicitud explícita:

add_type( $type, @exts )
Asociar una lista de extensiones de archivo con el tipo de medio dado. Ejemplo: 
add_type("x-world/x-vrml" => qw(wrl vrml));
add_encoding( $type, @ext )
Asociar una lista de extensiones de archivo con un tipo de codificación. Ejemplo: 
add_encoding("x-gzip" => "gz");
read_media_types( @files )
Analizar archivos de tipos de medios y agregar los mapeos de tipos que se encuentran allí. Ejemplo: 
read_media_types("conf/mime.types");
