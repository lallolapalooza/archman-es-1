NOMBRE

Lire::ReportSchedule - Objeto que representa la generación de un informe periódico.

SINOPSIS

use Lire::ReportJob;
use Lire::ReportSchedule;
my $store = Lire::DlfStore->open( 'aStore' );
my $job = new Lire::ReportJob( "webServer" );
my $cfg = $store->get_report_config( 'daily_www_report' );
$job->add_schedule( new Lire::ReportSchedule( 'daily', $cfg );
$job->run( 'daily', $store );

DESCRIPCIÓN

Los objetos Lire::ReportSchedule, junto con los objetos Lire::OutputJob, hacen posible configurar todo tipo de generación de informes periódicos. Mientras que Lire::OutputJob se utiliza para representar el formato de un informe generado, Lire::ReportSchedule representa dicha generación. Se utilizará para generar periódicamente un informe XML en un DlfStore utilizando un archivo de configuración de informes.

Se asume que los ReportSchedules agrupados en un ReportJob generan informes compatibles en lo que respecta a la fusión. La idea es que los informes anteriores generados en un ReportJob (según diferentes programaciones) puedan usarse como fuente de datos cuando el DlfStore no contenga todos los registros DLF para todo el período. Por ejemplo, si no conserva un año de DLF de www en su tienda, aún podría generar un informe anual utilizando los informes diarios generados durante el año.

new( $periodo, $cfg );

Crea un nuevo Lire::ReportSchedule que generará un informe XML utilizando el Lire::ReportConfig $cfg en un período de $periodo. $periodo debe ser uno de 'hourly', 'daily', 'weekly', 'monthly' o 'yearly'.

period()

Devuelve el período de este ReportSchedule.

period_range( [ $tiempo ] )

Devuelve los límites de inicio y fin del período del programa que incluye $tiempo. (Por defecto, ahora). El límite final se excluye del período y el límite inicial se incluye.

report_config( [ $nueva_cfg ] )

Devuelve (y opcionalmente cambia) el objeto Lire::ReportConfig a utilizar para esta programación.

init_report_config( [ $tiempo ] )

Devuelve el objeto Lire::ReportConfig con los filtros establecidos. Se habrá añadido un FilterSpec a cada sección del objeto ReportConfig que restringirá la generación de informes al período definido para la programación. Los límites del período se determinan según $tiempo, que por defecto es ahora.

add_output_jobs( $job, ... )

Añade uno o más Lire::OutputJob al objeto ReportSchedule.

output_jobs()

Devuelve los Lire::OutputJobs relacionados con este objeto.

run( $tienda, $report_job, [$tiempo] )

Genera un informe XML y lo guarda en el Lire::DlfStore $tienda. El informe se generará utilizando los DlfStreams o informes generados previamente. Se da preferencia a la generación del informe utilizando los datos DLF. Para más detalles, consulte la documentación de find_report_source() en Lire::DlfStore(3pm).

El período para el cual se generará el informe se realiza utilizando el parámetro $tiempo que por defecto es ahora. Por ejemplo, un informe 'daily' generará un informe para todo el día (medianoche-medianoche basado en el día que representa $tiempo).

Una vez generado el informe, todos los OutputJob registrados se ejecutarán con el nuevo informe.
