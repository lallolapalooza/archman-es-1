NOMBRE

Locale::RecodeData::IBM273 - Rutinas de conversión para IBM273

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo es generado y contiene las tablas y rutinas de conversión para IBM273.

COMENTARIOS

Los siguientes comentarios han sido extraídos del charmap original:

version: 1.0
 source: IBM NLS RM Vol2 SE09-8002-01, March 1990
alias CP273

¡Tenga en cuenta que los alias enumerados anteriormente no son necesariamente válidos!

Locale::RecodeData::IBM273(3pm) -- Locale::Recode sub-class for IBM Code Page 273

NAME

Locale::RecodeData::IBM273 - Locale::Recode sub-class for IBM Code Page 273

SYNOPSIS

    use Locale::RecodeData::IBM273;
    # ...

DESCRIPTION

This class provides the character set information for the IBM Code Page 273 (which is similar to ISO 8859-1, also known as Latin-1).

This class is used internally by the Locale::Recode module.

COMMENTS

This module is a part of the libintl-perl package.
