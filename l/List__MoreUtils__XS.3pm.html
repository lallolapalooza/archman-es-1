List::MoreUtils::XS(3) Documentación contribuida por el usuario de Perl List::MoreUtils::XS(3)

NOMBRE

List::MoreUtils::XS - Proporciona funciones compiladas de List::MoreUtils

SINOPSIS

use List::MoreUtils::XS (); # no exporta nada
use List::MoreUtils ':all'; # se requiere para importar funciones
my @procs = get_process_stats->fetchall_array;
# ordenar por ppid, luego pid
qsort { $a->[3] <=> $b->[3] or $a->[2] <=> $b->[2] } @procs;
while( @procs ) {
    my $proc = shift @procs;
    my @children = equal_range { $_->[3] <=> $proc->[2] } @procs;
}
my @left = qw(this is a test);
my @right = qw(this is also a test);
my %rlinfo = listcmp @left, @right;
# sin ordenar
my $i = firstidx { $_ eq 'yeah' } @foo;
# ordenado - siempre el primero, pero podría no ser 'yeah'
my $j = lower_bound { $_ cmp 'yeah' } @bar;
# ordenado - cualquiera de las ocurrencias, es seguro 'yeah'
my $k = bsearchidx { $_ cmp 'yeah' } @bar;

DESCRIPCIÓN

List::MoreUtils::XS es un backend para List::MoreUtils. Aunque es posible (debido a los deseos del usuario) tenerlo prácticamente independiente de List::MoreUtils, técnicamente depende de "List::MoreUtils". Dado que solo es un backend, la API no es pública y puede cambiar sin previo aviso.

VER TAMBIÉN

List::Util, List::AllUtils
