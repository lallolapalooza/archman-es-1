NOMBRE

Lire::Utils - Funciones genéricas.

SINOPSIS

use Lire:Utils qw/ xml_encode /;

DESCRIPCIÓN

Este módulo define varias funciones genéricas. No se exportan funciones por defecto; tienes que especificar cuáles quieres importar en tu espacio de nombres cuando uses el módulo.

xml_encode( $str )

Convierte los caracteres estándar <,>,&," y ' a sus entidades XML.

Ejemplo

print XML_STREAM xml_encode( $value );

latex_encode( $str )

Devuelve $str con todos los caracteres especiales de LaTeX escapados.

tilde_expand( $path )

Expande las tildes en una ruta, si es posible. Esto significa que las rutas de la forma ~/foo se transforman en algo como /home/user/foo, donde "/home/user" es el contenido de la variable $HOME. Las rutas de la forma ~otheruser/foo se traducen de forma similar mediante una búsqueda en el directorio del usuario.

diff_lists( $list1, $list2 )

Compara dos listas. Si las dos listas contienen los mismos elementos (incluso si están en orden diferente), devuelve undef. De lo contrario, devuelve una referencia a un hash que contiene la lista de elementos nuevos en la clave 'new' y la lista de elementos a eliminar (para que $list1 se convierta en $list2) en la clave 'remove'.

FUNCIONES DE PORTABILIDAD

Para la portabilidad entre versiones de Perl, este módulo define algunas funciones que suelen estar presentes en la última versión de Perl pero que pueden no estar disponibles en algunas versiones antiguas (la más antigua que soportamos es Perl 5.00503).

tmpdir()

Este método (proporcionado por las versiones recientes de File::Spec) devuelve dónde deben ir los archivos temporales.

tempfile()

my $fh = tempfile();
my $fh = tempfile( $template, 'SUFFIX' => ".txt" )
my ( $fh, $name ) = tempfile( $template, 'SUFFIX' => ".dlf" );

Este es un envoltorio para la función File::Temp::tempfile de Perl cuando está disponible, y ofrece una versión "casera" que debería ser segura cuando no esté disponible. La única diferencia es que el archivo siempre se creará en el directorio especificado en $ENV{'TMPDIR'} o /tmp cuando no esté definido.

El primer argumento a la función debe ser una plantilla de nombre que contenga al menos 6 X (es decir, tempXXXXXX) que se sustituirán para generar un nombre aleatorio. Cuando no se pasen argumentos, se usará un modelo por defecto de tempfileXXXXXX.

Otras opciones pueden pasarse a la función mediante pares clave-valor. La única opción entendida por la versión "casera" es SUFFIX, que se añadirá al nombre del archivo. (La versión de Perl entiende más opciones, pero no deberías usarlas por compatibilidad.)

La función es resistente a ataques de carreras (y crea el archivo con permisos de solo lectura y escritura para el propietario). Si falla al crear un archivo temporal después de 10 intentos, se lanzará die(). (Esto no debería ocurrir a menos que alguien esté intentando atacarnos.)

La función devolverá en contexto escalar un manejador de archivo anónimo abierto al archivo temporal. El archivo temporal se eliminará automáticamente cuando cierres el manejador de archivo.

Cuando se usa en contexto de array, la función devolverá un manejador de archivo y la ruta del archivo temporal (esto puede ser útil para fines de depuración o cuando no puedes pasar el archivo por manejador a otro proceso). En este caso, el archivo debe eliminarse manualmente.

tempdir()

my $dir = tempdir();
my $dir = tempdir( $template )

Este es un envoltorio para la función File::Temp::tempdir de Perl cuando está disponible, y ofrece una versión "casera" que debería ser segura cuando no esté disponible. La única diferencia es que el directorio siempre se creará en el directorio especificado en $ENV{'TMPDIR'} o /tmp cuando no esté definido.

El primer argumento a la función debe ser una plantilla de nombre que contenga al menos 6 X (es decir, tempXXXXXX) que se sustituirán para generar un nombre aleatorio. Cuando no se pasen argumentos, se usará un modelo por defecto de tempdirXXXXXX.

Otras opciones pueden pasarse a la función mediante pares clave-valor. La única opción entendida por la versión "casera" es DIR, que especifica dónde se creará el directorio (La versión de Perl entiende más opciones, pero no deberías usarlas por compatibilidad.)

La función es resistente a ataques de carreras (y crea el archivo con permisos de solo lectura y escritura para el propietario). Si falla al crear un directorio temporal después de 10 intentos, se lanzará die(). (Esto no debería ocurrir a menos que alguien esté intentando atacarnos.)

La función devolverá el nombre del directorio que se creó.

min()

my $least = min(@values);
my $least = min($a,$b,$c);

max()

my $greatest = max(@values);
my $greatest = max($a,$b,$c);

Estos encuentran el valor más pequeño o el más grande en una lista de números. Una lista vacía devolverá undef. Los valores indefinidos se ignoran y solo se devolverán si la lista está vacía o contiene solo valores indefinidos.

ratio( $dividend, $divisor )

Devuelve $dividendo / $divisor y devuelve "NaN" cuando $divisor es igual a 0. Redondea el resultado a dos decimales.

ratio100( $part, $total )

Devuelve un porcentaje de $part sobre $total. Esta función es segura de usar cuando $total es igual a 0 (devolverá "NaN"). El porcentaje se redondea a un decimal.

shell_quote($string)

Devuelve $string en un formato seguro para pasar a la shell, de modo que los metacaracteres no sean interpretados por la shell. Esto se hace devolviendo $string entre comillas y escapando las comillas que están dentro de $string.

indent( $string, [ $count ] )

Devuelve $string indentado con $count espacios. Si $count no se especifica, se asumirá un valor por defecto de 2.

check_param( $param, $name, [ $regex | $coderef, $msg ] )

Verifica que el parámetro "$name" no sea indefinido y que opcionalmente coincida con la expresión regular dada. La validación también puede lograrse mediante una referencia de código pasada como tercer parámetro. La convención en este caso es que la subrutina devolverá un booleano indicando si $param es válido.

Ejemplos:

check_param( $req_param, 'req_param' );
check_param( $param_string, 'param_string', qr/^[a-z]+$/ );
check_param( $integer, 'integer', qr/^[0-9]+$/, "no es un entero válido" );
check_param( $bool, 'bool', sub { return $_[0] }, "booleano era falso" );

NAME

Lire::Utils - Utility functions used by Lire

SYNOPSIS

 use Lire::Utils qw(
     check_param
     sql_quote_name
     tree_apply
     item_index
     deep_copy
     unique
     text_for_width
     is_url
     parse_url
     file_content
     create_file
     period_range
 );

DESCRIPTION

This module provides a collection of utility functions used by the Lire package.

PORTABILITY FUNCTIONS

check_param( $object, $name, $expected_type )

Checks if the object is of the correct type. Checks if the object is an instance of $expected_type or if it is an instance of a class within the given package.

Examples:

check_param( $object, 'object', 'Wawa::Class' );
check_param( $object, 'object', [ 'Wawa::Class', 'Other::Class' ] );

sql_quote_name( $name )

tree_apply( $root, $children_func, $apply_func )

Preorder processing

item_index( $array_ref, $item )

Returns the index of $item in $array. It returns undef if the item isn't found. $array_ref should be an ARRAY reference and $item should be a non-null scalar.

deep_copy( $object, [$exclusion] )

Makes a recursive copy of $object. Cyclic references are maintained in the copy. Optionnally, an array ref of packages for which the objects shouldn't be deeply copied can be provided.

unique( $list )

Returns an array reference with the duplicate elements of $list removed.

text_for_width( $text, $width )

Returns a stripped-down representation of 'text', ensuring its length is shorter or equal to 'width'. If the original text already fits the given width, it is returned unchanged, otherwise, it is shortened and '...' is put in the middle to indicate the cut.

is_url( $string )

Determines whether $string is a url or not, returning 'true' or 'false' as result code.

parse_url( $string )

Returns an hash reference containing keys for the following URL parts: 'scheme', 'host', 'port', 'path', 'query', 'fragment'. The value will be empty if this wasn't present in the URL. This function is somewhat 'http' biased and one should use the URI module for full blown URI parsing.

The function dies if the URL cannot be parsed.

file_content( $filename )

Returns the content of $filename. Dies if an error occurs.

create_file( $filename, [$content], [$utf8_encoding] )

Creates file $filename with $content. The $utf8_encoding flag specifies whether you want to keep strings in their UTF-8 encoding with versions of Perl that supports it (5.8.0 and above).

period_range( $period, $time )

Returns an array reference containing the starting and ending boundaries for the $period that includes $time. $period should be one of 'hourly', 'daily', 'weekly', 'monthly' or 'yearly'. $time should be in seconds since epoch.
