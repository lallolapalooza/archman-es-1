NAME

Locale::RecodeData::CP1253 - Greek encoding for Locale::Recode

SYNOPSIS

 use Locale::Recode::CP1253;

DESCRIPTION

This module provides the routines for the conversion of Greek (ISO 8355-1:1987, also known as ISO Latin 1) encoding.

The encoding is mapped to the Unicode encoding. See the Locale::Recode(3) manual page for details.

COMMENTS

The encoding is known as CP1253, WINDOWS-1253, and ELOT-928.
