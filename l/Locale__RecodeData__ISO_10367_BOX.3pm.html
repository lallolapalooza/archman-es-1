Locale::RecodeData::ISO_10367_BOX(3pm)

NAME

Locale::RecodeData::ISO_10367_BOX - ISO_10367_BOX character set

SYNOPSIS

    use Locale::RecodeData::ISO_10367_BOX;

DESCRIPTION

The Locale::RecodeData::ISO_10367_BOX module provides character set information for the ISO_10367_BOX encoding.

This is a data module and should not be used directly. Instead, it is used by the Locale::Recode(3) module.

COMMENTS

This encoding is described in the standard ISO 10367:1991 (Information processing -- Character-code structures for the electronic interchange of the graphical representation of product identification codes).
