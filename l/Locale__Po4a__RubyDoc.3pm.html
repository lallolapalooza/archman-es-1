NOMBRE

Locale::Po4a::RubyDoc -- Convierte datos de Documento Ruby de/a archivos PO

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y, lo que es más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

Locale::Po4a::RubyDoc es un módulo para ayudar a la traducción de documentación en formato Ruby Document (RD) (un lenguaje utilizado para documentar Ruby) a otros idiomas [humanos].

ESTADO DE ESTE MÓDULO

Este módulo ha sido probado con éxito en archivos simples de Ruby Document que cubren una buena parte de la sintaxis del formato.

Una limitación conocida es que no reconoce adecuadamente la estructura anidada de Ruby Document de entrada: esto implica que cuando, por ejemplo, un EnumListItem consiste en más de un Block, solo el primer Block se reconoce como EnumListItem, mientras que los subsiguientes se consideran simplemente como TextBlocks...

OPCIONES ACEPTADAS POR ESTE MÓDULO

Este módulo soporta la siguiente opción:

puredoc
Procesa archivos compuestos enteramente por texto con formato Ruby Document (sin ninguna línea "=begin").

Por defecto, este módulo solo procesa texto con formato Ruby Document entre líneas "=begin" y "=end" (ignorando así, entre otras cosas, todo lo que precede a la primera línea "=begin").
