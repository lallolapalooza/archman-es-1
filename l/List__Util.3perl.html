List::Util(3perl) Guía de referencia para programadores de Perl List::Util(3perl)

NOMBRE

List::Util - Una selección de subrutinas de utilidad general para listas

SINOPSIS

use List::Util qw(
  reduce any all none notall first reductions
  max maxstr min minstr product sum sum0
  pairs unpairs pairkeys pairvalues pairfirst pairgrep pairmap
  shuffle uniq uniqint uniqnum uniqstr head tail zip mesh
);

DESCRIPCIÓN

"List::Util" contiene una selección de subrutinas que la gente ha expresado que le gustaría tener en el núcleo de Perl, pero cuyo uso no sería realmente lo suficientemente alto como para justificar el uso de una palabra clave, y cuyo tamaño es tan pequeño que ser extensiones individuales sería un desperdicio.

Por defecto, "List::Util" no exporta ninguna subrutina.

FUNCIONES DE REDUCCIÓN DE LISTAS

El siguiente conjunto de funciones aplica un bloque de código dado a una lista de valores.

reduce

$resultado = reduce { BLOQUE } @lista

Reduce @lista llamando a "BLOQUE" en un contexto escalar múltiples veces, estableciendo $a y $b cada vez. La primera llamada será con $a y $b establecidos a los dos primeros elementos de la lista, las llamadas subsiguientes se harán estableciendo $a al resultado de la llamada anterior y $b al siguiente elemento de la lista.

Devuelve el resultado de la última llamada al "BLOQUE". Si @lista está vacía, se devuelve "undef". Si @lista solo contiene un elemento, se devuelve ese elemento y no se ejecuta el "BLOQUE".

Los siguientes ejemplos demuestran cómo "reduce" podría usarse para implementar las otras funciones de reducción de listas de este módulo. (De hecho, no se implementan de esta manera, sino de una manera más eficiente en funciones individuales de C).

$foo = reduce { defined($a)            ? $a :
                $code->(local $_ = $b) ? $b :
                                         undef } undef, @list # first
$foo = reduce { $a > $b ? $a : $b } 1..10       # max
$foo = reduce { $a gt $b ? $a : $b } 'A'..'Z'   # maxstr
$foo = reduce { $a < $b ? $a : $b } 1..10       # min
$foo = reduce { $a lt $b ? $a : $b } 'aa'..'zz' # minstr
$foo = reduce { $a + $b } 1 .. 10               # sum
$foo = reduce { $a . $b } @bar                  # concat
$foo = reduce { $a || $code->(local $_ = $b) } 0, @bar   # any
$foo = reduce { $a && $code->(local $_ = $b) } 1, @bar   # all
$foo = reduce { $a && !$code->(local $_ = $b) } 1, @bar  # none
$foo = reduce { $a || !$code->(local $_ = $b) } 0, @bar  # notall
   # Nótese que estas implementaciones no cortocircuitan completamente

Si su algoritmo requiere que "reduce" produzca un valor identidad, entonces asegúrese de pasar siempre ese valor identidad como primer argumento para evitar que se devuelva "undef".

$foo = reduce { $a + $b } 0, @values;             # sum con valor identidad 0

El código de ejemplo anterior también sugiere cómo usar "reduce" para construir una versión combinada más eficiente de una de estas funciones básicas y un bloque "map". Por ejemplo, para encontrar la longitud total de todas las cadenas en una lista, podríamos usar

$total = sum map { length } @strings;

Sin embargo, esto produce una lista de valores enteros temporales de la misma longitud que la lista original de cadenas, solo para reducirla de nuevo a un solo valor. Podemos calcular el mismo resultado de manera más eficiente usando "reduce" con un bloque de código que acumula longitudes escribiendo esto en su lugar como:

$total = reduce { $a + length $b } 0, @strings

Las otras funciones de reducción de listas que devuelven un escalar son especializaciones de esta idea genérica.

reductions

@resultados = reductions { BLOQUE } @lista

Desde la versión 1.54.

Similar a "reduce", excepto que también devuelve los valores intermedios junto con el resultado final. Como antes, $a se establece en el primer elemento de la lista dada, y el "BLOQUE" se llama una vez para cada elemento restante en la lista establecido en $b, con el resultado capturado para ser devuelto y también convirtiéndose en el nuevo valor para $a.

La lista devuelta comenzará con el valor inicial para $a, seguido de cada valor de retorno del bloque en orden. El valor final del resultado será idéntico a lo que la función "reduce" habría devuelto dado el mismo bloque y lista.

reduce     { "$a-$b" }  "a".."d"    # "a-b-c-d"
reductions { "$a-$b" }  "a".."d"    # "a", "a-b", "a-b-c", "a-b-c-d"

any

mi $booleano = any { BLOQUE } @lista;

Desde la versión 1.33.

Similar a "grep" en que evalúa "BLOQUE" estableciendo $_ a cada elemento de @lista en turno. "any" devuelve verdadero si algún elemento hace que el "BLOQUE" devuelva un valor verdadero. Si "BLOQUE" nunca devuelve verdadero o @lista estaba vacía, devuelve falso.

Muchos casos de uso de "grep" en una condicional se pueden escribir usando "any" en su lugar, ya que puede cortocircuitar después del primer resultado verdadero.

if( any { length > 10 } @strings ) {
    # al menos una cadena tiene más de 10 caracteres
}

Nota: Debido a problemas de XS, el bloque pasado puede acceder a @_ externo directamente. Esto no es intencional y fallará bajo el depurador.

all

mi $booleano = all { BLOQUE } @lista;

Desde la versión 1.33.

Similar a "any", excepto que requiere que todos los elementos de @lista hagan que el "BLOQUE" devuelva verdadero. Si algún elemento devuelve falso, entonces devuelve falso. Si el "BLOQUE" nunca devuelve falso o @lista estaba vacía, devuelve verdadero.

Nota: Debido a problemas de XS, el bloque pasado puede acceder a @_ externo directamente. Esto no es intencional y fallará bajo el depurador.

none

notall

mi $booleano = none { BLOQUE } @lista;
mi $booleano = notall { BLOQUE } @lista;

Desde la versión 1.33.

Similar a "any" y "all", pero con el sentido de retorno invertido. "none" devuelve verdadero solo si ningún valor en @lista causa que el "BLOQUE" devuelva verdadero, y "notall" devuelve verdadero solo si no todos los valores lo hacen.

Nota: Debido a problemas de XS, el bloque pasado puede acceder a @_ externo directamente. Esto no es intencional y fallará bajo el depurador.

first

mi $valor = first { BLOQUE } @lista;

Similar a "grep" en que evalúa "BLOQUE" estableciendo $_ a cada elemento de @lista en turno. "first" devuelve el primer elemento donde el resultado de "BLOQUE" es un valor verdadero. Si "BLOQUE" nunca devuelve verdadero o @lista estaba vacía, se devuelve "undef".

Muchos casos de uso de "grep" en una condicional que buscan el primer elemento que coincide se pueden escribir con "first" en su lugar, ya que puede cortocircuitar después del primer resultado verdadero.

my $n = first { $_ > 5 } @numbers;
# $n contendrá el primer número mayor que 5, o undef si ninguno lo es

Nota: Debido a problemas de XS, el bloque pasado puede acceder a @_ externo directamente. Esto no es intencional y fallará bajo el depurador.

max

my $val = max @list;

Devuelve el elemento más grande de la lista en un contexto numérico.

my $big = max 1, 10, 5, 8;

maxstr

my $val = maxstr @list;

Devuelve el elemento más grande de la lista en un contexto de cadena. Esto significa que "Z" es mayor que "a".

my $biggest = maxstr qw(a b Z A); # $biggest contendrá "Z"

min

my $val = min @list;

Devuelve el elemento más pequeño de la lista en un contexto numérico.

my $small = min 1, 10, 5, 8;

minstr

my $val = minstr @list;

Devuelve el elemento más pequeño de la lista en un contexto de cadena. Esto significa que "A" es menor que "a".

my $smallest = minstr qw(a b Z A); # $smallest contendrá "A"

product

my $prod = product @list;

Devuelve el producto de todos los elementos de la lista. Si la lista está vacía, devuelve 1.

my $p = product 1..5; # $p contendrá 120

sum

my $total = sum @list;

Devuelve la suma de todos los elementos de la lista. Si la lista está vacía, devuelve 0.

my $s = sum 1..5; # $s contendrá 15

sum0

my $total = sum0 @list;

Devuelve la suma de todos los elementos de la lista. Si la lista está vacía, devuelve 0.

Esta función se proporciona principalmente para la coherencia con otras funciones que tienen una variante "0" (como "product"). No hay diferencia funcional entre "sum" y "sum0".

FUNCIONES DE MANIPULACIÓN DE LISTAS

pairs

my @pairs = pairs @list;

Desde la versión 1.52.

Toma una lista de elementos y la divide en pares de dos. Si la lista tiene un número impar de elementos, el último elemento se descarta.

pairs 1, 2, 3, 4, 5, 6       # (1, 2, 3, 4)

Útil cuando se trabaja con listas de claves/valor o nombres/valor donde se desea ignorar el último elemento si hay un número impar.

unpairs

my @list = unpairs @pairs;

Desde la versión 1.52.

Toma una lista de pares (es decir, una lista donde cada elemento es una lista o array de dos elementos) y la "desempareja" en una lista simple de elementos.

unpairs [1,2], [3,4], [5,6]   # (1, 2, 3, 4, 5, 6)

Es la operación inversa de "pairs" en el sentido de que:

unpairs( pairs(@list) ) eq @list  # en la mayoría de los casos

pairkeys

my @keys = pairkeys @list;

Desde la versión 1.52.

Toma una lista de elementos y extrae las claves de los pares. Ignora el último elemento si hay un número impar.

pairkeys 1, 2, 3, 4, 5       # (1, 3)

pairvalues

my @values = pairvalues @list;

Desde la versión 1.52.

Toma una lista de elementos y extrae los valores de los pares. Ignora el último elemento si hay un número impar.

pairvalues 1, 2, 3, 4, 5       # (2, 4)

pairfirst

my $first_pair = pairfirst BLOCK @list;

Desde la versión 1.52.

Itera sobre la lista en pasos de dos elementos, estableciendo $k al primer elemento y $v al segundo. Devuelve el primer par ($k, $v) para el cual el BLOCK devuelve un valor verdadero.

my ($key, $value) = pairfirst { $v > 10 } 'a', 5, 'b', 15, 'c', 2;

Esto establecería $key a 'b' y $value a 15.

Si no se encuentra ningún par que coincida, devuelve undef.

pairgrep

my @results = pairgrep BLOCK @list;

Desde la versión 1.52.

Itera sobre la lista en pasos de dos elementos, estableciendo $k al primer elemento y $v al segundo. Devuelve una lista plana de todos los pares ($k, $v) para los cuales el BLOCK devuelve un valor verdadero.

my @matches = pairgrep { $v > 10 } 'a', 5, 'b', 15, 'c', 2;

Esto establecería @matches a ('b', 15).

pairmap

my @results = pairmap BLOCK @list;

Desde la versión 1.52.

Itera sobre la lista en pasos de dos elementos, estableciendo $k al primer elemento y $v al segundo. El BLOCK puede devolver cero, uno o dos valores. Estos se aplanan en la lista resultante.

my @transformed = pairmap { $v =~ s/x/y/r } 'a', 'x1', 'b', 'x2';

Esto establecería @transformed a ('y1', 'y2').

my @transformed = pairmap { $k, $v * 2 } 'a', 5, 'b', 10;

Esto establecería @transformed a ('a', 10, 'b', 20).

my @transformed = pairmap { if ($v > 7) { $k, $v } } 'a', 5, 'b', 10;

Esto establecería @transformed a ('b', 10).

shuffle

my @shuffled = shuffle @list;

Desde la versión 1.25.

Devuelve una copia de la lista en un orden aleatorio. Utiliza el algoritmo de Fisher-Yates.

my @deck = 1..52;
my @shuffled_deck = shuffle @deck;

uniq

my @unique = uniq @list;

Devuelve una lista de elementos únicos de la lista dada. El orden se preserva; se devuelve la primera aparición de cada elemento.

my @a = uniq 1, 2, 1, 3, 4, 2, 5;

Esto establece @a a (1, 2, 3, 4, 5).

uniqint

my @unique = uniqint @list;

Similar a "uniq", pero utiliza un ordenamiento numérico estricto para determinar la unicidad. Los elementos que son numéricamente iguales se consideran los mismos.

my @a = uniqint 1, 2, 1.0, 3, 4, 2.00, 5;

Esto establece @a a (1, 2, 3, 4, 5).

uniqnum

my @unique = uniqnum @list;

Desde la versión 1.31.

Similar a "uniq", pero utiliza un ordenamiento numérico estricto para determinar la unicidad. Los elementos que son numéricamente iguales se consideran los mismos.

Esta función es funcionalmente idéntica a "uniqint".

uniqstr

my @unique = uniqstr @list;

Similar a "uniq", pero utiliza un ordenamiento de cadenas estricto para determinar la unicidad. Los elementos que son de cadena iguales se consideran los mismos.

my @a = uniqstr 1, 2, "1", 3, 4, "2.00", 5;

Esto establece @a a (1, 2, "1", 3, 4, "2.00", 5). Tenga en cuenta que 1 y "1" son diferentes en este contexto.

head

my @head = head @list;

Desde la versión 1.47.

Devuelve los elementos iniciales de la lista. Si la lista tiene 5 o menos elementos, devuelve la lista completa. De lo contrario, devuelve los primeros 5 elementos.

head 1..10                 # (1, 2, 3, 4, 5)

tail

my @tail = tail @list;

Desde la versión 1.47.

Devuelve los elementos finales de la lista. Si la lista tiene 5 o menos elementos, devuelve la lista completa. De lo contrario, devuelve los últimos 5 elementos.

tail 1..10                 # (6, 7, 8, 9, 10)

zip

my @zipped = zip @list1, @list2, ...;

Desde la versión 1.54.

Toma varias listas y las "cremallera" juntas. El resultado es una lista plana de tuplas. La longitud de cada tupla se determina por el número de listas de entrada. La iteración se detiene cuando la lista más corta se agota.

zip 1..3, A..C, x..z      # (1, 'A', 'x', 2, 'B', 'y', 3, 'C', 'z')

Si desea pares de elementos, puede usar "zip" con dos listas:

zip qw(key1 key2), qw(val1 val2) # ('key1', 'val1', 'key2', 'val2')

Para obtener una lista de arrays de pares, puede usar esto con "unpairs":

unpairs( zip [@keys], [@values] ) # Crea un hash apropiado para construir un hash

mesh

my @meshed = mesh @list1, @list2, ...;

Desde la versión 1.54.

Similar a "zip", pero la iteración continúa hasta que la lista más larga se agota, rellenando con undef donde sea necesario.

mesh 1..3, A..E           # (1, 'A', 2, 'B', 3, 'C', undef, 'D', undef, 'E')

Se mantuvo y se mejoró posteriormente, y se incluyó en el núcleo de Perl a partir de la versión 5.7.0.

Este módulo está libremente distribuible y puede ser modificado y/o redistribuido bajo los mismos términos que Perl mismo.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

max

my $num = max @list;

Devuelve el elemento de la lista con el valor numérico más alto. Si la lista está vacía, devuelve "undef".

$foo = max 1..10                # 10
$foo = max 3,9,12               # 12
$foo = max @bar, @baz           # lo que sea

maxstr

my $str = maxstr @list;

Similar a max, pero trata todos los elementos de la lista como cadenas y devuelve la cadena más larga según el operador gt. Si la lista está vacía, devuelve "undef".

$foo = maxstr 'A'..'Z'          # 'Z'
$foo = maxstr "hello","world"   # "world"
$foo = maxstr @bar, @baz        # lo que sea

min

my $num = min @list;

Similar a max, pero devuelve el elemento de la lista con el valor numérico más bajo. Si la lista está vacía, devuelve "undef".

$foo = min 1..10                # 1
$foo = min 3,9,12               # 3
$foo = min @bar, @baz           # lo que sea

minstr

my $str = minstr @list;

Similar a min, pero trata todos los elementos de la lista como cadenas y devuelve la cadena más pequeña según el operador lt. Si la lista está vacía, devuelve "undef".

$foo = minstr 'A'..'Z'          # 'A'
$foo = minstr "hello","world"   # "hello"
$foo = minstr @bar, @baz        # lo que sea

product

my $num = product @list;

Desde la versión 1.35.

Devuelve el producto numérico de todos los elementos de @list. Si @list está vacío, devuelve 1.

$foo = product 1..10            # 3628800
$foo = product 3,9,12           # 324

sum

my $num_or_undef = sum @list;

Devuelve la suma numérica de todos los elementos de @list. Por compatibilidad con versiones anteriores, si @list está vacío, devuelve "undef".

$foo = sum 1..10                # 55
$foo = sum 3,9,12               # 24
$foo = sum @bar, @baz           # lo que sea

sum0

my $num = sum0 @list;

Desde la versión 1.26.

Similar a sum, excepto que devuelve 0 cuando se le pasa una lista vacía, en lugar de "undef".

FUNCIONES DE LISTA DE PARES CLAVE/VALOR

El siguiente conjunto de funciones, inspiradas en List::Pairwise, consumen una lista de pares de tamaño par. Los pares pueden ser asociaciones clave-valor de un hash o simplemente una lista de valores. Todas las funciones conservan el orden original de los pares y no se confunden con múltiples pares que tengan el mismo valor de clave. Ni siquiera necesitan que el primer elemento de cada par sea una cadena ordinaria.

NOTA: En el momento de escribir esto, las siguientes funciones pair* que toman un bloque no modifican el valor de $_ dentro del bloque, sino que operan usando las variables globales $a y $b. Esto ha resultado en un diseño deficiente, ya que impide el uso de una función pairsort. Sería mejor pasar objetos similares a pares como referencias de arrays de 2 elementos en $_, en un estilo similar al valor devuelto por la función pairs. Esto puede ser agregado en el futuro.

Hasta ahora, se advierte a los usuarios que NO dependan del valor de $_ entre el exterior y el interior del bloque de control. En particular, el siguiente ejemplo es INSEGURO:

my @kvlist = ...
foreach (qw( algunas claves aquí )) {
   my @items = pairgrep { $a eq $_ } @kvlist;
   ...
}

En su lugar, escriba esto usando una variable léxica:

foreach my $key (qw( algunas claves aquí )) {
   my @items = pairgrep { $a eq $key } @kvlist;
   ...
}

pairs

my @pairs = pairs @kvlist;

Desde la versión 1.29.

Un atajo para operar en listas de pares de tamaño par, esta función devuelve una lista de referencias a arrays, cada una conteniendo dos elementos de la lista dada. Es una versión más eficiente de

@pairs = pairmap { [ $a, $b ] } @kvlist

Es más conveniente usar en un bucle foreach, por ejemplo:

foreach my $pair ( pairs @kvlist ) {
   my ( $key, $value ) = @$pair;
   ...
}

Desde la versión 1.39 estas referencias a arrays son objetos encadenables, reconociendo los métodos key y value. El siguiente código es equivalente:

foreach my $pair ( pairs @kvlist ) {
   my $key   = $pair->key;
   my $value = $pair->value;
   ...
}

Desde la versión 1.51 también tienen un método TO_JSON para facilitar la serialización.

unpairs

my @kvlist = unpairs @pairs

Desde la versión 1.42.

La función inversa de pairs; esta función toma una lista de referencias a arrays que contienen dos elementos cada uno y devuelve una lista de valores de los dos elementos de cada par, en orden. Esto es notacionalmente equivalente a

my @kvlist = map { @{$_}[0,1] } @pairs

a menos que se implemente internamente de forma más eficiente. Específicamente, para cualquier elemento de entrada, extrae exactamente dos valores para la lista de salida; usando "undef" si las referencias a arrays son cortas.

Entre pairs y unpairs, una función de lista de orden superior puede usarse para operar sobre los pares como escalares; por ejemplo, las siguientes versiones de otras funciones pair* de orden superior:

@kvlist = unpairs grep { FUNC } pairs @kvlist
# Similar a pairgrep, pero toma $_ en lugar de $a y $b
@kvlist = unpairs map { FUNC } pairs @kvlist
# Similar a pairmap, pero toma $_ en lugar de $a y $b

Sin embargo, estas versiones no se comportarán tan amigablemente en el contexto escalar.

Finalmente, esta técnica puede usarse para implementar una ordenación según una clave de una lista de pares clave-valor; por ejemplo:

@kvlist = unpairs sort { $a->key cmp $b->key } pairs @kvlist

pairkeys

my @keys = pairkeys @kvlist;

Desde la versión 1.29.

Un atajo para operar en listas de pares de tamaño par, esta función devuelve una lista de los primeros valores de cada par en la lista dada. Es una versión más eficiente de

@keys = pairmap { $a } @kvlist

pairvalues

my @values = pairvalues @kvlist;

Desde la versión 1.29.

Un atajo para operar en listas de pares de tamaño par, esta función devuelve una lista de los segundos valores de cada par en la lista dada. Es una versión más eficiente de

@values = pairmap { $b } @kvlist

pairgrep

my @kvlist = pairgrep { BLOCK } @kvlist;
my $count = pairgrep { BLOCK } @kvlist;

Desde la versión 1.29.

Similar a la palabra clave perl grep, pero interpreta la lista dada como una lista de pares de tamaño par. Invoca el bloque { BLOCK } múltiples veces, en contexto escalar, con $a y $b establecidos a los pares sucesivos de valores de @kvlist.

Devuelve una lista de pares de tamaño par para los cuales el bloque { BLOCK } devuelve verdadero en contexto escalar, o el número de pares en contexto escalar. (Nota, por lo tanto, en contexto escalar devuelve un número que es la mitad del número de elementos que se habrían devuelto en contexto lista).

@subset = pairgrep { $a =~ m/^[[:upper:]]+$/ } @kvlist

Al igual que grep que asigna $_ a los elementos de la lista, el bloque { pairgrep } asigna $a y $b a los elementos de la lista dada. Cualquier modificación de este bloque será visible para el llamador.

pairfirst

my ( $key, $val ) = pairfirst { BLOCK } @kvlist;
my $found = pairfirst { BLOCK } @kvlist;

Desde la versión 1.30.

Similar a la función first, pero interpreta la lista dada como una lista de pares de tamaño par. Invoca el bloque { BLOCK } múltiples veces, en contexto escalar, con $a y $b establecidos a los pares sucesivos de valores de @kvlist.

Devuelve el primer par de valores de la lista para los cuales el bloque { BLOCK } devuelve verdadero en contexto escalar, o una lista vacía si no se encontró tal par. En contexto escalar devuelve un valor booleano simple, en lugar del valor de la clave o el valor encontrado.

( $key, $value ) = pairfirst { $a =~ m/^[[:upper:]]+$/ } @kvlist

Al igual que grep que asigna $_ a los elementos de la lista, el bloque { pairfirst } asigna $a y $b a los elementos de la lista dada. Cualquier modificación de este bloque será visible para el llamador.

OPERADORES DE LISTA

Las siguientes funciones operan en listas. Tenga en cuenta que, como en el caso de los operadores de Perl estándar, estas funciones operan en una lista de valores en lugar de en una referencia a una lista. Esto significa que se puede pasar una lista de escalares que se expanden a más de una lista como argumentos.

pairmap

my @list = pairmap { BLOCK } @kvlist;
my $count = pairmap { BLOCK } @kvlist;

Desde la versión 1.29.

Similar al operador "map" de Perl, pero interpreta la lista dada como una lista de pares de tamaño par. Invoca el "BLOCK" múltiples veces, en contexto de lista, con $a y $b asignados a pares consecutivos de valores de la @kvlist.

Devuelve la concatenación de todos los valores devueltos por el "BLOCK" en contexto de lista, o el número de elementos que habrían sido devueltos en contexto de escalar.

@result = pairmap { "La clave $a tiene valor $b" } @kvlist

Como con "map", "pairmap" aliasa $_ a elementos de la lista. Cualquier modificación de ella realizada por el bloque de código será visible para el llamador.

Ver "KNOWN BUGS" para un bug conocido con "pairmap", y una solución.

OTRAS FUNCIONES

shuffle

my @values = shuffle @values;

Devuelve los valores de la entrada en orden aleatorio.

@cards = shuffle 0..51      # 0..51 en orden aleatorio

Esta función está afectada por la variable $RAND.

sample

my @items = sample $count, @values

Desde la versión 1.54.

Elige aleatoriamente un número dado de elementos de la lista de entrada. Cada posición en la lista de entrada será seleccionada al menos una vez.

Si hay menos de $count elementos en la lista, la función devolverá una vez que todos los elementos hayan sido seleccionados aleatoriamente; efectivamente, la función se comporta de manera similar a "shuffle".

Esta función está afectada por la variable $RAND.

uniq

my @subset = uniq @values

Desde la versión 1.45.

Filtra una lista de valores para eliminar duplicados consecutivos, según una prueba de igualdad de cadenas o prueba de "undef". Preserva el orden de los elementos únicos y mantiene el primer valor de cualquier conjunto duplicado.

my $count = uniq @values

En contexto de escalar, devuelve el número de elementos que habrían sido devueltos como lista.

El valor "undef" se trata como distinto de la cadena vacía, y no se emitirá un aviso. Se deja como está en la lista devuelta. Los valores posteriores "undef" se consideran iguales al primero y se eliminarán.

uniqint

my @subset = uniqint @values

Desde la versión 1.55.

Filtra una lista de valores para eliminar duplicados consecutivos, según una prueba de igualdad numérica. Preserva el orden de los elementos únicos y mantiene el primer valor de cualquier conjunto duplicado. Los valores devueltos en la lista serán forzados a enteros.

my $count = uniqint @values

En contexto de escalar, devuelve el número de elementos que habrían sido devueltos como lista.

Nota: El valor "undef" se trata de manera similar a otras operaciones numéricas; compara igual a cero pero genera un aviso adicional si se habilita el aviso "use warnings 'uninitialized';". Además, un valor "undef" en la lista devuelta se fuerza a cero, por lo que la lista de valores devuelta por "uniqint" será bien comportada como enteros.

Nota adicional: Los valores IEEE "NaN" se tratan como duplicados entre sí, independientemente de las diferencias en sus cargas, y aunque "0+'NaN' == 0+'NaN'" produzca falso.

uniqnum

my @subset = uniqnum @values

Desde la versión 1.44.

Filtra una lista de valores para eliminar duplicados consecutivos, según una prueba de igualdad numérica. Preserva el orden de los elementos únicos y mantiene el primer valor de cualquier conjunto duplicado.

my $count = uniqnum @values

En contexto de escalar, devuelve el número de elementos que habrían sido devueltos como lista.

Nota: El valor "undef" se trata de manera similar a otras operaciones numéricas; compara igual a cero pero genera un aviso adicional si se habilita el aviso "use warnings 'uninitialized';". Además, un valor "undef" en la lista devuelta se fuerza a cero, por lo que la lista de valores devuelta por "uniqnum" será bien comportada como números.

Nota adicional: múltiples "NaN" de IEEE se tratan como duplicados entre sí, independientemente de las diferencias en sus cargas, y aunque "0+'NaN' == 0+'NaN'" produzca falso.

uniqstr

my @subset = uniqstr @values

Desde la versión 1.45.

Filtra una lista de valores para eliminar duplicados consecutivos, según una prueba de igualdad de cadenas. Preserva el orden de los elementos únicos y mantiene el primer valor de cualquier conjunto duplicado.

my $count = uniqstr @values

En contexto de escalar, devuelve el número de elementos que habrían sido devueltos como lista.

Nota: El valor "undef" se trata de manera similar a otras operaciones de cadenas; compara igual a la cadena vacía pero genera un aviso adicional si se habilita el aviso "use warnings 'uninitialized';". Además, un valor "undef" en la lista devuelta se fuerza a cadena vacía, por lo que la lista de valores devuelta por "uniqstr" será bien comportada como cadenas.

head

my @values = head $size, @list;

Desde la versión 1.50.

Devuelve los primeros $size elementos de @list. Si $size es negativo, devuelve todos los elementos excepto los últimos $size de @list.

@result = head 2, qw( foo bar baz );
# foo, bar
@result = head -2, qw( foo bar baz );
# foo

tail

my @values = tail $size, @list;

Desde la versión 1.50.

Devuelve los últimos $size elementos de @list. Si $size es negativo, devuelve todos los elementos excepto los primeros $size de @list.

@result = tail 2, qw( foo bar baz );
# bar, baz
@result = tail -2, qw( foo bar baz );
# baz

zip

my @result = zip [1..3], ['a'..'c'];
# [1, 'a'], [2, 'b'], [3, 'c']

Desde la versión 1.56.

Devuelve una lista de referencias a arrays, compuesta de elementos de la lista de referencias de arrays dadas. Cada array en la lista devuelta es compuesta de elementos en la posición correspondiente de cada una de las listas de arrays de entrada. Si algún array de entrada se agota antes que otros, se insertará "undef" en el resultado para llenar los espacios vacíos.

La función "zip" es especialmente útil para iterar sobre múltiples arrays simultáneamente con un bucle "foreach", tomando un elemento de cada:

foreach ( zip \@xs, \@ys, \@zs ) {
    my ($x, $y, $z) = @$_;
    ...
}

NOTA para usuarios de List::MoreUtils: Esta función no comporta la misma forma que "List::MoreUtils::zip", pero es en realidad un equivalente no prototipado a "List::MoreUtils::zip_unflatten". Esta función no aplica un prototipo, por lo que debe invocarse con referencias a arrays.

Para una función similar a la "zip" de "List::MoreUtils", véase "mesh".

my @result = zip_shortest ...

Una variación de la función que difiere en cómo se comporta cuando se dan arrays de entrada de diferentes longitudes. "zip_shortest" detiene inmediatamente cuando alguno de los arrays de entrada se agota, descartando cualquier valor restante de los otros. "zip_longest" es un alias de la función "zip" para ser explícito sobre su comportamiento en comparación con "zip_shortest".

mesh

my @result = mesh [1..3], ['a'..'c'];
# (1, 'a', 2, 'b', 3, 'c')

Desde la versión 1.56.

Devuelve una lista de elementos recopilados a partir de elementos de la lista de referencias de arrays dadas. Cada sección de elementos en la lista devuelta es compuesta de elementos en la posición correspondiente de cada una de las listas de arrays de entrada. Si algún array de entrada se agota antes que otros, se insertará "undef" en el resultado para llenar los espacios vacíos.

Este es similar a "zip", excepto que todos los rangos en la salida se devuelven en una lista lineal, en lugar de estar empaquetados en arrays separados.

Dado que devuelve una lista de elementos planos, la función "mesh" es especialmente útil para construir un hash a partir de dos listas separadas de claves y valores.

my %hash = mesh \@keys, \@values;
my $href = { mesh \@keys, \@values };

NOTA para usuarios de List::MoreUtils: Esta función es un equivalente no prototipado a "List::MoreUtils::mesh". Esta función no aplica un prototipo, por lo que debe invocarse con referencias a arrays.

Para una función similar a la "zip" de "List::MoreUtils", véase "zip".

FUNCIONES DE REDUCCIÓN DE LISTAS

sum

sum ARRAY

Devuelve la suma de todos los elementos de ARRAY. Si ARRAY está vacío, devuelve 0.

my $sum = sum @list_of_numbers;

Se utiliza el operador + para sumar los elementos. Esto significa que los elementos son tratados como números, y si no lo son, Perl intentará convertirlos.

product

product ARRAY

Devuelve el producto de todos los elementos de ARRAY. Si ARRAY está vacío, devuelve 1.

my $product = product @list_of_numbers;

Se utiliza el operador * para multiplicar los elementos. Esto significa que los elementos son tratados como números, y si no lo son, Perl intentará convertirlos.

min

min ARRAY

Devuelve el elemento más pequeño de ARRAY. Si ARRAY está vacío, devuelve undef.

my $min = min @list_of_numbers;

Utiliza la comparación numérica para encontrar el valor mínimo.

max

max ARRAY

Devuelve el elemento más grande de ARRAY. Si ARRAY está vacío, devuelve undef.

my $max = max @list_of_numbers;

Utiliza la comparación numérica para encontrar el valor máximo.

first

first BLOCK LIST

Devuelve el primer elemento de LIST para el cual el BLOCK evalúa a verdadero. Si ningún elemento satisface la condición, devuelve undef.

my $first_even = first { $_ % 2 == 0 } @numbers;

Esto es similar a la función incorporada grep, pero se detiene después de encontrar el primer elemento que coincide.

uniq

uniq LIST

Devuelve una lista con elementos únicos de LIST. El orden de los elementos únicos se basa en el orden en que aparecen por primera vez en la lista de entrada.

my @unique_numbers = uniq 1, 2, 3, 2, 1, 4;

Esto es equivalente a List::MoreUtils::uniq.

uniqnum

uniqnum LIST

Similar a uniq, pero utiliza la comparación numérica para determinar la unicidad. Por ejemplo, uniqnum(1, 1.0) devolverá solo un elemento, ya que 1 y 1.0 se consideran numéricamente iguales.

my @unique_numbers = uniqnum 1, 1.0, 2, 3, 2.0;

Esto es equivalente a List::MoreUtils::uniqnum.

uniqstr

uniqstr LIST

Similar a uniq, pero utiliza la comparación de cadenas para determinar la unicidad. Por ejemplo, uniqstr(1, 1.0) devolverá dos elementos, ya que 1 y 1.0 se consideran diferentes como cadenas.

my @unique_strings = uniqstr 1, 1.0, 2, 3, 2.0;

Esto es equivalente a List::MoreUtils::uniqstr.

shuffle

shuffle LIST

Devuelve una lista con los elementos de LIST en orden aleatorio. Utiliza el algoritmo de Fisher-Yates para barajar.

my @shuffled_list = shuffle @original_list;

Esto es equivalente a List::MoreUtils::shuffle.

zip

zip LISTS

Toma una o más listas como entrada y devuelve una nueva lista donde cada elemento es una lista que contiene los elementos correspondientes de las listas de entrada. La longitud de la lista resultante está determinada por la lista más corta. Si una lista de entrada es más corta que las otras, los elementos faltantes se tratan como undef en la lista resultante.

my @zipped = zip [1, 2, 3], [a, b, c], [x, y, z];
# @zipped contendrá: [ [1, a, x], [2, b, y], [3, c, z] ]

Esto es equivalente a List::MoreUtils::zip.

mesh_shortest

mesh_shortest LISTS

Similar a zip, pero si una lista de entrada se agota, se siguen tomando elementos de las otras listas hasta que todas las listas se agoten. Los elementos faltantes se tratan como undef.

my @zipped = mesh_shortest [1, 2], [a, b, c];
# @zipped contendrá: [ [1, a], [2, b], [undef, c] ]

mesh_longest

mesh_longest LISTS

Similar a zip, pero la longitud de la lista resultante está determinada por la lista más larga. Los elementos faltantes de las listas más cortas se tratan como undef.

my @zipped = mesh_longest [1, 2, 3], [a, b];
# @zipped contendrá: [ [1, a], [2, b], [3, undef] ]

Las variaciones mesh_shortest y mesh_longest son similares a las de zip, en el sentido de que difieren en el comportamiento cuando una de las listas de entrada se agota antes que las otras.

Estas funciones son alias de "List::Util::mesh" o "List::MoreUtils::zip" (que a su vez son alias entre sí). Esta función no aplica un prototipo, por lo que asegúrate de invocarla con referencias a arrays.

my @result = mesh_shortest ...
my @result = mesh_longest ...

VARIABLES DE CONFIGURACIÓN

$RAND

local $List::Util::RAND = sub { ... };

Desde la versión 1.54.

Esta variable del paquete es utilizada por el código que necesita generar números aleatorios (como las funciones "shuffle" y "sample"). Si se establece como una referencia de código, proporciona una alternativa a la función incorporada rand() de Perl. Cuando se necesita un nuevo número aleatorio, esta función será invocada sin argumentos y se espera que devuelva un valor de punto flotante, del cual solo se utilizará la parte fraccionaria.

BUGS CONOCIDOS

RT #95409

https://rt.cpan.org/Ticket/Display.html?id=95409

Si el bloque de código proporcionado a "pairmap" contiene variables léxicas que son capturadas por un cierre devuelto, y el cierre se ejecuta después de que el bloque ha sido reutilizado para la siguiente iteración, estos léxicos no verán los valores correctos. Por ejemplo:

my @subs = pairmap {
   my $var = "$a is $b";
   sub { print "$var\n" };
} one => 1, two => 2, three => 3;
$_->() for @subs;

Imprimirá incorrectamente

three is 3
three is 3
three is 3

Esto se debe a la optimización de rendimiento de usar "MULTICALL" para el bloque de código, lo que significa que no se asignan SVs nuevos para cada llamada al bloque. En su lugar, el mismo SV se reasigna para cada iteración, y todos los cierres compartirán el valor visto en la última iteración.

Para solucionar este bug, rodea el código con un segundo conjunto de llaves. Esto crea un bloque interno que evita la lógica de "MULTICALL", y se asignan SVs nuevos cada vez:

my @subs = pairmap {
   {
      my $var = "$a is $b";
      sub { print "$var\n"; }
   }
} one => 1, two => 2, three => 3;

Este bug solo afecta a los cierres que se generan en el bloque pero se utilizan posteriormente. Las variables léxicas que solo se utilizan durante la vida útil de la ejecución del bloque tomarán sus valores individuales para cada invocación, como es normal.

uniqnum() en bignums sobredimensionados

Debido a la forma en que uniqnum() compara números, no puede distinguir las diferencias entre bignums (especialmente bigint) que son demasiado grandes para caber en los tipos nativos de la plataforma. Por ejemplo,

my $x = Math::BigInt->new( "1" x 100 );
my $y = $x + 1;
say for uniqnum( $x, $y );

Imprimirá solo el valor de $x, creyendo que $y tiene un valor numéricamente equivalente. Este bug no afecta a uniqstr(), que observará correctamente que los dos valores se convierten a cadenas diferentes.
