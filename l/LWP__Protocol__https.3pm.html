LWP::Protocol::https(3) Documentación de Perl aportada por el usuario LWP::Protocol::https(3)

NOMBRE

LWP::Protocol::https - Proporciona soporte https para LWP::UserAgent

SINOPSIS

use LWP::UserAgent;
$ua = LWP::UserAgent->new(ssl_opts => { verify_hostname => 1 });
$res = $ua->get("https://www.example.com");
# especificar una ruta de CA
$ua = LWP::UserAgent->new(
    ssl_opts => {
        SSL_ca_path     => '/etc/ssl/certs',
        verify_hostname => 1,
    }
);

DESCRIPCIÓN

El módulo LWP::Protocol::https proporciona soporte para el uso de URLs con el esquema https con LWP. Este módulo es un complemento del manejo de protocolos de LWP, por lo que no se utiliza directamente. Una vez instalado el módulo, LWP puede acceder a sitios que utilizan HTTP sobre SSL/TLS.

Si LWP::UserAgent solicita la verificación del nombre de host a través de "ssl_opts", y no se ha establecido ni "SSL_ca_file" ni "SSL_ca_path", se asume que "SSL_ca_file" es el proporcionado por Mozilla::CA. Si el módulo Mozilla::CA no está disponible, las solicitudes SSL fallarán. Instale este módulo, configure un "SSL_ca_file" alternativo o desactive la verificación del nombre de host.

Este módulo solía venir incluido con libwww-perl, pero se separó en la versión v6.02 para poder declarar sus dependencias correctamente para la cadena de herramientas CPAN. Las aplicaciones que necesitan soporte https pueden simplemente declarar su dependencia de LWP::Protocol::https y ya no necesitarán saber qué módulos subyacentes instalar.

VER TAMBIÉN

IO::Socket::SSL, Crypt::SSLeay, Mozilla::CA
