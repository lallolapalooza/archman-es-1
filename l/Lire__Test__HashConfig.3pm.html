NOMBRE

Lire::Test::HashConfig - Implementación rudimentaria de Lire::Config

SINOPSIS

use base qw/Test::Unit::TestCase/;
use Lire::Test::HashConfig;
sub set_up {
    my $self = $_[0];
    $self->{'old_config'} = $Lire::Config::SINGLETON;
    $Lire::Config::SINGLETON = new Lire::Test::HashConfig( {
                                                            'lr_archive' => undef,
                                                           } );
}

DESCRIPCIÓN

Este es un módulo simple que está pensado para ser utilizado desde el método set_up() en pruebas unitarias. Puede ser utilizado para crear una configuración 'falsa' para proporcionar valores conocidos al módulo bajo prueba.

El método new() toma una referencia de hash que contiene la variable de configuración.

Los únicos métodos de la interfaz Lire::Config implementados son get() y config_spec(). El método get() devolverá exactamente los valores proporcionados en el método new(). Intentar obtener otras variables de configuración lanzará una excepción de 'No existe la variable de configuración' (como si la variable no estuviera definida en el esquema).

El método config_spec() devolverá el objeto asociado a la clave '_lr_config_spec'. Lanzará una excepción si esta clave no fue establecida.

Todos los demás métodos de Lire::Config lanzarán una excepción de 'Método no implementado'.

VER TAMBIÉN

Lire::Config(3pm), Test::Unit::TestCase(3pm)
