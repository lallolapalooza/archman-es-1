WeekCalculator(3pm) Documentación de Lire de LogReport WeekCalculator(3pm)

NOMBRE

Lire::WeekCalculator - maneja diferentes esquemas de numeración de semanas

SINOPSIS

use Lire::WeekCalculator;
my $week_calc = new Lire::WeekCalculator();
my $week_no   = $week_calc->week_number( $time );

DESCRIPCIÓN

Soportamos tres valores para LR_WEEK_NUMBERING: ISO (%V de strftime): la semana comienza el lunes; W (la semana comienza el lunes) y U (la semana comienza el domingo). Ver strftime(1).

CONSTRUCTOR

new( %params )

Crea una nueva calculadora de semanas. El estilo de numeración de semanas se selecciona usando el parámetro "style". Si ese parámetro se omite, se utiliza por defecto el estilo establecido en la variable de configuración 'lr_week_numbering'.

style()

Devuelve el estilo de numeración de semanas utilizado. Será "U", "W" o "ISO".

week_number( $time )

Devuelve el número de semana de $time según el esquema de numeración de semanas actual. El número de semana devuelto está entre 1 y 53.

week_idx( $time )

Devuelve el índice de semana de $time según el esquema de numeración de semanas. El índice de semana es específico de Lire y se utiliza para normalizar los cálculos entre diferentes esquemas en cuanto a la primera semana incompleta del año. En el caso ISO, el índice de semana es siempre igual a week_number() - 1, para el otro estilo, el índice de semana de la semana 0 será uno menos que el último número de semana del año anterior.

last_week_of_year($year)

Devuelve el número de semana de la última semana del año $year.

week_start( $year, $week_no )

Devuelve el tiempo de época del primer día de la semana $week_no en el año $year cuando se calcula utilizando el estilo actual.

find_year_week1_start_date($year)

Devuelve la fecha (época) en la que comienza el primer día de la primera semana del año $year.

strformat()

Devuelve una cadena que puede utilizarse como especificador de formato en llamadas a strftime para imprimir el número de semana de este estilo.

strfdate()

Emula POSIX::strftime() pero utiliza el especificador %V si el strftime del sistema no lo soporta. Debe llamarse siempre que se utilicen cadenas de formato que puedan contener códigos de semana del año.
