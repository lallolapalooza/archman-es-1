NOMBRE

Lire::ReportParser::AsciiDocBookFormatter - Subclase de Lire::ReportParser que formatea la descripción.

SINOPSIS

Para formatear DocBook:

use Lire::ReportParser::AsciiDocBookFormatter qw/dbk2txt/;
my $txt = dbk2txt( "<para>Prueba</para>" );

En los procesadores de informes XML:

package MyParser;
use base qw/ Lire::ReportParser::AsciiDocBookFormatter Lire::ReportParser /;
sub new {
    my $self = shift->SUPER::new( @_ );
    $self->init_docbook_formatter( @_ );
    return $self;
}
sub handle_description {
    my ( $self, $desc ) = @_;
    print $desc;
    return;
}

DESCRIPCIÓN

Este paquete implementa métodos que pueden manejar el contenido de los elementos "description" y puede ser utilizado por una subclase de Lire::ReportParser. El cliente solo tiene que heredar de este módulo para que esté disponible un método handle_description() que procese la descripción DocBook formateada en texto.

Este módulo también proporciona una función útil dbk2txt() que puede ser utilizada para formatear una cadena que contiene elementos DocBook en un equivalente ASCII.

USANDO Lire::ReportParser::AsciiDocBookFormatter

Los procesadores de Lire::ReportParser que deseen trabajar con la versión en texto de la descripción deben heredar de Lire::ReportParser::AsciiDocBookFormatter además de Lire::ReportParser. Si sobrescriben los métodos description_start(), description_end(), deben enlazar a la versión de sus padres usando "SUPER::".

Adicionalmente, deben fusionar el valor de elements_spec() en su implementación de elements_spec().

Lire::ReportParser::AsciiDocBookFormatter debe listarse antes que Lire::ReportParser en @ISA. AsciiDocBookFormatter no hereda directamente de Lire::ReportParser para que pueda ser utilizado en escenarios de herencia múltiple.

La subclase debe llamar al método init_docbook_formatter() desde su método constructor para inicializar el módulo DocBookFormatter.

init_docbook_formatter( %params )

El inicializador reconoce algunos parámetros que pueden ser utilizados para controlar el comportamiento del manejo de DocBook:

columnas
El número de columnas en las que se debe formatear el texto DocBook. Por defecto es 72.

dbk_start_processing()

Inicializa la estructura del analizador para formatear XML DocBook como ASCII. Esto se utiliza desde la implementación de description_start.

dbk_end_processing()

Limpia la estructura del analizador. Esto se utiliza desde la implementación de description_end().

handle_description( $description )

Este método se invoca después de encontrar la etiqueta de cierre del elemento "description". El $description contiene la descripción formateada en texto plano.

FORMATENDO CADENAS DocBook

Si tienes contenido DocBook en una cadena, como puedes obtener de algunos de los objetos de Especificación de Informes, puedes formatearlo en texto plano usando la función dbx2txt().

dbk2txt( $docbook_str, [$columnas] )

Devuelve una versión en texto plano del fragmento XML DocBook $docbook_str. El parámetro "columnas" establece el número de columnas en las que se debe formatear el texto DocBook.

Este método morirá() en caso de error.
