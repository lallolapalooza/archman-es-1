NOMBRE

Lire::Field - Interfaz a la especificación de campos Dlf.

SINOPSIS

my $field = $schema->field( 'time' );
print "Nombre: ", $field->name(), "\n", "Tipo: ", $field->type(), "\n";

DESCRIPCIÓN

Este módulo representa las especificaciones de los campos Dlf. Obtendrá una referencia a este tipo de objeto cuando llame a los métodos field(), timestamp_field() o fields() en un objeto Lire::DlfSchema(3pm). Puede obtener información sobre este campo consultando sus métodos.

MÉTODOS DEL OBJETO

name()

Devuelve el nombre del campo.

label()

Devuelve la etiqueta predeterminada que se debe utilizar para la columna que contiene los valores de este campo.

pos()

Devuelve la posición del campo en el registro. Las posiciones de los campos se indexan a partir de 0.

type()

Devuelve el tipo del campo. Será una cadena que describe el nombre del tipo tal como se utiliza en las especificaciones XML.

sql_type()

Devuelve el tipo SQL que se debe utilizar para almacenar los valores de este campo.

default()

Este método es obsoleto ya que los campos ya no tienen valores predeterminados.

description()

Este método devolverá la descripción del campo. (Este es el contenido del elemento de descripción en la especificación XML). Tenga en cuenta que es muy probable que contenga marcado DocBook.

VER TAMBIÉN
