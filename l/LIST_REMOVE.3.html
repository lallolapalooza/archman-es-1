NOMBRE

LIST_EMPTY, LIST_ENTRY, LIST_FIRST, LIST_FOREACH, LIST_HEAD, LIST_HEAD_INITIALIZER, LIST_INIT, LIST_INSERT_AFTER, LIST_INSERT_BEFORE, LIST_INSERT_HEAD, LIST_NEXT, LIST_REMOVE - implementación de lista doble

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <sys/queue.h>
LIST_ENTRY(TIPO);
LIST_HEAD(NOMBRECABECERA, TIPO);
LIST_HEAD LIST_HEAD_INITIALIZER(LIST_HEAD cabecera);
void LIST_INIT(LIST_HEAD *cabecera);
int LIST_EMPTY(LIST_HEAD *cabecera);
void LIST_INSERT_HEAD(LIST_HEAD *cabecera,
                        struct TIPO *elem, LIST_ENTRY NOMBRE);
void LIST_INSERT_BEFORE(struct TIPO *elem_lista,
                        struct TIPO *elem, LIST_ENTRY NOMBRE);
void LIST_INSERT_AFTER(struct TIPO *elem_lista,
                        struct TIPO *elem, LIST_ENTRY NOMBRE);
struct TIPO *LIST_FIRST(LIST_HEAD *cabecera);
struct TIPO *LIST_NEXT(struct TIPO *elem, LIST_ENTRY NOMBRE);
LIST_FOREACH(struct TIPO *var, LIST_HEAD *cabecera, LIST_ENTRY NOMBRE);
void LIST_REMOVE(struct TIPO *elem, LIST_ENTRY  NOMBRE);

DESCRIPCIÓN

Estas macros definen y operan sobre listas doblemente enlazadas.

En las definiciones de macros, TIPO es el nombre de una estructura definida por el usuario, la cual debe contener un miembro de tipo LIST_ENTRY, denominado NOMBRE. El argumento NOMBRECABECERA es el nombre de una estructura definida por el usuario que debe ser declarada usando la macro LIST_HEAD().

Creación

Una lista está encabezada por una estructura definida con la macro LIST_HEAD(). Esta estructura contiene un puntero al primer elemento de la lista. Los elementos están doblemente enlazados, lo que permite eliminar cualquier elemento sin recorrer la lista. Los nuevos elementos pueden ser añadidos a la lista después de un elemento existente, antes de uno existente, o al frente de la lista. Una estructura LIST_HEAD se declara así:


LIST_HEAD(NOMBRECABECERA, TIPO) cabecera;

donde struct NOMBRECABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos que se enlazarán en la lista. Una dirección de puntero a la cabecera de la lista puede ser declarada más tarde así:


struct NOMBRECABECERA *cabecerp;

(Los nombres cabecera y cabecerp son elegidos por el usuario.)

LIST_ENTRY() declara una estructura que conecta los elementos de la lista.

LIST_HEAD_INITIALIZER() evalúa a un inicializador para la lista cabecera.

LIST_INIT() inicializa la lista referenciada por cabecera.

LIST_EMPTY() evalúa a verdadero si la lista no tiene elementos.

Inserción

LIST_INSERT_HEAD() inserta el nuevo elemento elem al frente de la lista.

LIST_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elem_lista.

LIST_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

LIST_FIRST() devuelve el primer elemento de la lista, o NULL si la lista está vacía.

LIST_NEXT() devuelve el siguiente elemento de la lista, o NULL si es el último.

LIST_FOREACH() recorre la lista referenciada por cabecera en dirección hacia adelante, asignando cada elemento a var por turnos.

Eliminación

LIST_REMOVE() elimina el elemento elem de la lista.

VALOR DE RETORNO

LIST_EMPTY() devuelve un valor distinto de cero si la lista está vacía, y cero si contiene al menos un elemento.

LIST_FIRST() y LIST_NEXT() devuelven un puntero a la estructura TIPO del primer o siguiente elemento, respectivamente.

LIST_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la lista cabecera.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

BUGS

LIST_FOREACH() no permite eliminar o liberar var dentro del bucle, ya que esto interferiría con el recorrido. LIST_FOREACH_SAFE(), presente en los BSDs pero no en glibc, resuelve esta limitación al permitir que var sea eliminado y liberado dentro del bucle sin interferir con el recorrido.

EJEMPLOS

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entrada {
    int datos;
    LIST_ENTRY(entrada) entradas;              /* Lista */
};
LIST_HEAD(cabeceradelista, entrada);
int
main(void)
{
    struct entrada *n1, *n2, *n3, *np;
    struct cabeceradelista cabeza;                   /* Cabeza de la lista */
    int i;
    LIST_INIT(&cabeza);                       /* Inicializar la lista */
    n1 = malloc(sizeof(struct entrada));      /* Insertar al frente */
    LIST_INSERT_HEAD(&cabeza, n1, entradas);
    n2 = malloc(sizeof(struct entrada));      /* Insertar después */
    LIST_INSERT_AFTER(n1, n2, entradas);
    n3 = malloc(sizeof(struct entrada));      /* Insertar antes */
    LIST_INSERT_BEFORE(n2, n3, entradas);
    i = 0;                                  /* Recorrido hacia adelante */
    LIST_FOREACH(np, &cabeza, entradas)
        np->datos = i++;
    LIST_REMOVE(n2, entradas);               /* Eliminación */
    free(n2);
                                            /* Recorrido hacia adelante */
    LIST_FOREACH(np, &cabeza, entradas)
        printf("%i\n", np->datos);
                                            /* Eliminación de la lista */
    n1 = LIST_FIRST(&cabeza);
    while (n1 != NULL) {
        n2 = LIST_NEXT(n1, entradas);
        free(n1);
        n1 = n2;
    }
    LIST_INIT(&cabeza);
    exit(EXIT_SUCCESS);
}

NOMBRE

LIST_REMOVE - elimina un elemento de una lista enlazada doblemente.

SINOPSIS

#include <sys/queue.h>

void LIST_REMOVE(struct LIST_HEAD *head, struct LIST_ENTRY *elm);

DESCRIPCIÓN

La macro LIST_REMOVE elimina el elemento elm de la lista enlazada doblemente definida por head. La macro asume que el elemento elm está efectivamente en la lista.

VALORES DE RETORNO

No aplica.

ERRORES

No aplica.

HISTORIAL

Esta macro apareció por primera vez en FreeBSD 2.1.0.

ERRORES CONOCIDOS

Si se intenta eliminar un elemento que no está en la lista, el comportamiento es indefinido.

EJEMPLOS

Para eliminar un elemento de una lista:


struct mylist_head my_list;
struct mylist_entry *elem_to_remove;

LIST_INIT(&my_list);
/* ... agregar elementos a my_list ... */
elem_to_remove = /* obtener el elemento a eliminar */;

if (elem_to_remove != NULL) {
    LIST_REMOVE(&my_list, elem_to_remove);
    /* ahora elem_to_remove ya no está en la lista */
}
