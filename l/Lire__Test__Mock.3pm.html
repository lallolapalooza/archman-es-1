NAME

Lire::Test::Mock - Crear un objeto de mock

SYNOPSIS

use Lire::Report;
use Lire::Test::Mock;
use Lire::DlfResult;
my $mock = new Lire::Test::Mock( 'Lire::Report' );
$mock->set_result( 'timestamp', $time );
$mock->timestamp(); # will return $time
$mock->get_calls(); # [ 'timestamp' ]
$mock->get_invocation( 'timestamp', 0 ); # [ $mock ]

DESCRIPTION

Esta clase hace fácil definir objetos de mock. Los objetos de mock ofrecen la misma interfaz que otro objeto pero no comparten su funcionalidad. Esto hace más fácil probar objetos que requieren fixtures con muchas dependencias.

El objeto de mock puede usarse para colectar información sobre llamadas realizadas a este objeto. También se puede especificar el valor devuelto para estas invocaciones de método.

new( $class, 'method' => $result, 'method' => $result )

Crea un nuevo objeto de mock que envuelva $class. Todos los otros argumentos clave se usan para inicializar el resultado de las invocaciones de método. Véase set_result() para más información sobre cómo funciona esto.

new_proxy( $class, @constructor_params )

Este crea un objeto de mock que monitorea llamadas a $class. Un objeto de proxy de mock monitorea las llamadas a este objeto, pero se invocan los métodos reales, a menos que se haya especificado un resultado usando set_result(). Todos los restantes parámetros se pasan a la método new() que debe definirse en la clase.

new_proxy( $instance )

Crea un objeto de Lire::Test::Mock que es un clon de $instance.

is_proxy()

Devuelve si este objeto de mock proxyará a los métodos reales cuando no se defina un resultado para un método específico.

get_calls()

Devuelve un arreglo referencial que contiene todas las métodos llamadas en este objeto.

invocation_count( $method )

Devuelve el número de veces que se llamó a $method.

get_invocation( $method, $index )

Devuelve los parámetros que se proporcionaron cuando se llamó a método $method.

set_result( method => $result, ... )

Asigna el resultado $result a método $method. Si $result es un código de referencia, se invocará con el mismo argumento que el método para calcular el resultado.

USING MOCK FACTORIES

A veces, no es posible instanciar un objeto de proxy o de mock durante la configuración de fixture. Esto suele ocurrir cuando el objeto al que queremos registrar el acceso se instanca mediante el método bajo prueba. En estos casos, se puede usar el método set_mock_factory() de la clase para cambiar el método de fabricación a uno que devuelva un objeto de proxy en lugar de un objeto real. Debe llamar a reset_factories() durante tear_down() para que el método real de fabricación se vuelva accesible de nuevo.

set_mock_factory( $class, %results )

Hace que el método new() de la clase $class devuelva un objeto de proxy Lire::Test::Mock. Los objetos creados se accederán a través de la método mock_instances(). Todos los otros argumentos se pasan a la método set_result() cuando el objeto de mock es creado.

mock_instances( $class )

Devuelve un arreglo referencial con todas las instancias creadas por el factor de mock instalado en $class. Este método lanzará una excepción si no se ha instalado aún el factor de mock para la clase $class.

reset_factories()

Elimina todos los factores de mock que se establecieron usando set_mock_factory().
