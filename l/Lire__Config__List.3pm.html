NOMBRE

Lire::Config::List - Objeto de valor de lista.

DESCRIPCIÓN

Se utiliza para parámetros de configuración que contienen una lista de valores.

elements()

Devuelve los valores de esta lista como una matriz de objetos Lire::Config::Value.

get( $idx )

Devuelve el valor almacenado en el índice $idx de esta lista. Se lanza una excepción si el índice está fuera de límites.

remove( $idx )

Elimina el valor almacenado en el índice $idx de esta lista. Se lanza una excepción si el índice está fuera de límites. Devuelve el elemento eliminado.

clear()

Elimina todos los elementos de esta lista

append( $val, [ $idx ] )

Añade $val después del elemento $idx. Si se omite $idx, el elemento se añadirá al final de la matriz. Un índice negativo se interpreta en relación con el final de la matriz.

move( $idx, $new_idx )

Mueve el elemento $idx a la posición $new_idx. Los índices pueden ser negativos y se interpretan como posiciones relativas al final de la matriz.

set( $idx, $value )

Reemplaza el valor en el índice $idx con $value.
