NAME

Locale::RecodeData::CP1251 - Funciones de conversión para CP1251

SYNOPSIS

Este módulo es interno de libintl. No lo use directamente!

DESCRIPTION

Este módulo está generado y contiene las tablas de conversión y rutinas para CP1251.

COMMENTS

Las siguientes observaciones se han extraído del original charmap:

versión: 1.0
repertoiremap: mnemonic,ds
 fuente: UNICODE 1.0
 alias MS-CYRL

Nota: los alias mencionados arriba no son necesariamente válidos!

NAME

Locale::RecodeData::CP1251 - Cyrillic Windows codepage 1251

SYNOPSIS

use Locale::RecodeData::CP1251;

DESCRIPTION

This module provides character mappings for the Windows-1251 codepage.

It is used by Locale::Recode(3) to convert to and from this encoding.

COMMENTS

This module is part of the libintl-perl package.
