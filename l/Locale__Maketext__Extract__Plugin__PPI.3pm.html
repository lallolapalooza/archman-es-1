NOMBRE

Locale::Maketext::Extract::Plugin::PPI - Analizador de formatos Perl

VERSIÓN

versión 1.00

SINOPSIS

$plugin = Locale::Maketext::Extract::Plugin::PPI->new(
    $lexicon            # Un objeto Locale::Maketext::Extract
    @file_types         # Opcionalmente especifica una lista de tipos de archivo reconocidos
)
$plugin->extract($filename,$filecontents);

DESCRIPCIÓN

Hace exactamente lo mismo que el analizador Locale::Maketext::Extract::Plugin::Perl, pero de forma más precisa y más lenta. ¡Considerablemente más lenta! Por esta razón, no es un plugin incorporado.

NOMBRE CORTO DEL PLUGIN

ninguno - el módulo debe especificarse en su totalidad
