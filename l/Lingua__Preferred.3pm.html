NOMBRE

Lingua::Preferred - Extensión de Perl para elegir un idioma

SINOPSIS

use Lingua::Preferred qw(which_lang acceptable_lang);
my @wanted = qw(en de fr it de_CH);
my @available = qw(fr it de);
my $which = which_lang(\@wanted, \@available);
print "el idioma $which es el mejor de los disponibles\n";
foreach (qw(en_US fr nl de_DE)) {
    print "el idioma $_ es aceptable\n"
      if acceptable_lang(\@wanted, $_);
}

DESCRIPCIÓN

A menudo, la información legible por humanos está disponible en más de un idioma. ¿Cuál deberías usar? Este módulo proporciona una forma para que el usuario especifique los idiomas posibles en orden de preferencia, y luego elija el mejor idioma de los disponibles. También se admiten diferentes 'dialectos' dados por la parte de 'territorio' del especificador de idioma (como en, en_GB y en_US).

La rutina which_lang() elige el mejor idioma de una lista de alternativas. Los argumentos son:

  • una referencia a una lista de idiomas preferidos (el primero es el mejor). Aquí, un idioma es una cadena como 'en' o 'fr_CA'. (También se puede dar 'fr_*', ver más abajo). 'C' (nombrado por la configuración regional 'C' de Unix) coincide con cualquier idioma.
  • una referencia a una lista no vacía de idiomas disponibles. Aquí, un idioma puede ser como 'en', 'en_CA' o "undef" que significa 'desconocido'.

El código de retorno es qué idioma usar. Siempre será un elemento de la lista de idiomas disponibles.

La astucia de este módulo (si se le puede llamar así) proviene de inferir preferencias de idioma implícitas basadas en la lista explícita proporcionada. Por ejemplo, si dices que 'en' es aceptable, entonces 'en_IE' y 'en_DK' serán presumiblemente aceptables también (pero no tan buenos como solo 'en'). Si das tu idioma como 'en_US', entonces 'en' es casi tan bueno, con los otros dialectos de 'en' siguiéndole pronto.

Si hay un empate entre dos opciones, como cuando dos dialectos del mismo idioma están disponibles y ninguno es explícitamente preferido, o cuando ninguno de los idiomas disponibles aparece en la lista del usuario, entonces se prefiere la opción que aparece antes en la lista disponible.

A veces, la inferencia automática de dialectos relacionados no es lo que quieres, porque un dialecto de idioma puede ser muy diferente del idioma 'principal', por ejemplo, el alemán suizo o algunas formas de inglés. Para este caso, está disponible la forma especial 'XX_*'. Si no te gusta el español mexicano (como un ejemplo completamente arbitrario), entonces "[ 'es', 'es_*', 'es_MX' ]" clasificaría este dialecto por debajo de cualquier otro dialecto de 'es' (pero aún aceptable). No tienes que listar explícitamente cada otro dialecto del español antes de 'es_MX'.

Así que, por ejemplo, suponiendo que @avail contiene los idiomas disponibles:

  • Sabes inglés y prefieres el inglés de EE. UU.: 
    $which = which_lang([ 'en_US' ], \@avail);
  • Sabes inglés y alemán, se prefiere alemán/Alemania: 
    $which = which_lang([ 'en', 'de_DE' ], \@avail);
  • Sabes inglés y alemán, pero preferiblemente no alemán suizo: 
    $which = which_lang([ 'en', 'de', 'de_*', 'de_CH' ], \@avail);

    Aquí, cualquier dialecto del alemán (por ejemplo, de_DE, de_AT) es preferible a de_CH.

    Mientras que which_lang() elige el mejor idioma de una lista de alternativas, acceptable_lang() responde si un solo idioma está incluido (explícita o implícitamente) en la lista de idiomas deseados. Añade los dialectos implícitos de la misma manera.
