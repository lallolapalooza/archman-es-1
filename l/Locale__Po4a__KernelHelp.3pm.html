NOMBRE

Locale::Po4a::KernelHelp - convertir la ayuda de configuración del kernel de/a archivos PO

DESCRIPCIÓN

Locale::Po4a::KernelHelp es un módulo para ayudar a la traducción de la documentación de las opciones de configuración del kernel de Linux a otros idiomas [humanos].

ESTADO DE ESTE MÓDULO

Este módulo acaba de ser escrito y necesita más pruebas. La mayor parte del trabajo necesario se centrará en las herramientas utilizadas para analizar este archivo (y configurar el kernel), para que acepten leer la documentación desde otro archivo (traducido).

VER TAMBIÉN

Pod::Parser, Locale::Po4a::Man(3pm), Locale::Po4a::Pod(3pm), Locale::Po4a::TransTractor(3pm), po4a(7)
