Locale::Maketext::Lexicon::Msgcat(3) Documentación de Perl contribuida por el usuario Locale::Maketext::Lexicon::Msgcat(3)

NOMBRE

Locale::Maketext::Lexicon::Msgcat - Analizador de catálogos Msgcat para Maketext

VERSIÓN

versión 1.00

SINOPSIS

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    en => ['Msgcat', 'en_US/hello.pl.m'],
};
package main;
my $lh = Hello::I18N->get_handle('en');
print $lh->maketext(1,2);   # set 1, msg 2
print $lh->maketext("1,2"); # lo mismo

DESCRIPCIÓN

Este módulo analiza uno o más catálogos Msgcat en formato de texto plano y devuelve un hash Lexicon, que puede ser buscado con una forma de dos argumentos ("$id_set, $id_msg") o como una cadena única ("$id_set,$id_msg").

NOTAS

Todos los caracteres especiales ("[", "]" y "~") en los catálogos se escaparán para que pierdan sus significados mágicos. Eso significa que las llamadas "->maketext" a este léxico *no* tomarán argumentos adicionales.

VER TAMBIÉN

Locale::Maketext, Locale::Maketext::Lexicon
