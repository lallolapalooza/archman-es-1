NOMBRE

Lire::ChartType - Interfaz base para todos los ChartType.

SINOPSIS

use base qw/ Lire::ChartType /;

DESCRIPCIÓN

Este paquete define la interfaz que implementan los diferentes gráficos que Lire puede producir utilizando el comando ploticus pl(1).

Un tipo de gráfico generará un gráfico utilizando datos de un subinforme.

MÉTODOS DE METADATOS

La interfaz Lire::ChartType extiende la interfaz Lire::Plugin, por lo que deben implementar todos los métodos de metadatos estándar (name(), title(), description()).

GENERAR UN GRÁFICO

write_chart( $chart_config, $subreport, [ %params ] )

Esto escribirá un gráfico a partir de los datos contenidos en el Lire::Report::Subreport $subreport utilizando la configuración $chart_config. Se pasan parámetros adicionales en forma de 'clave' => $valor. Los parámetros de $chart_config deben ser un objeto Lire::Config::Dictionary instanciado a partir de un Lire::Config::ChartSpec.

outputdir
Directorio donde se creará el archivo. Usa el directorio de trabajo por defecto.
format
Uno de eps, png, jpeg o gif. Por defecto usa la variable de configuración lr_image_format.

La función devuelve la ruta al archivo creado. El nombre del archivo se genera basándose en el valor de configuración 'name' o el id del subinforme si el otro no está definido. La extensión se añade según el formato de salida.

Devuelve el archivo donde se escribió el gráfico.

prefab()

Esta función debe ser implementada por la subclase y debe devolver una cadena que represente los primeros parámetros para pasar a ploticus (que es el nombre -prefab o la ruta a un archivo script).

write_parameters( $chart_config, $fh )

Esta función se utiliza para escribir parámetros en el manejador de archivos de ploticus. Este es el lugar para usar el comando #set para establecer todos los parámetros predefinidos. Las subclases deben encadenarse a esta implementación para los parámetros estándar del gráfico. También escribe directivas '#set name' para cada variable numérica definida por get_vars().

write_data( $chart_config, $subreport, $fh )

Esta función es utilizada por la implementación de write_chart() para escribir los datos del gráfico desde $subreport al comando Ploticus abierto en $fh. Utiliza el método get_vars() para obtener las variables numéricas que deben escribirse en el flujo y el método encode_value() para organizar los valores antes de escribirlos. Antes de que se escriban los datos en $fh, se determina el valor máximo en el eje Y y se emite como una configuración de ploticus. (ploticus falla si esto no está configurado, se dibuja una sola barra y el valor es mayor que 1.1e9.)

get_vars( $chart_config )

Esta función debe ser sobrescrita por las subclases para devolver una referencia de arreglo que contenga las especificaciones Lire::Report::ColumnInfo que especifican las columnas numéricas de datos que deben escribirse. Esto generalmente se especifica usando un ReferenceSpec con el índice 'numerical_variables'.

Estas variables comenzarán en el índice de ploticus 2 (@2).

encode_value( $value )

Por defecto, esta función simplemente devuelve el componente 'content' del elemento cuando $value es un nombre y el componente 'value' en caso contrario. Puede usarse para tipos de datos que necesiten codificación especial (como datetime).
