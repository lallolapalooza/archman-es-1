NOMBRE

Locale::Po4a::Yaml - convierte archivos YAML de/a archivos PO

DESCRIPCIÓN

Locale::Po4a::Yaml es un módulo para ayudar a la traducción de archivos Yaml a otros idiomas [humanos].

El módulo extrae el valor de los hashes y arrays de YAML. Las claves de hash no se extraen.

NOTA: Este módulo analiza el archivo YAML con YAML::Tiny.

OPCIONES ACEPTADAS POR ESTE MÓDULO

Estas son las opciones particulares de este módulo:

claves
Lista separada por espacios de claves de hash a procesar para su extracción, todas las demás claves se omiten. Las claves se comparan de forma sensible a mayúsculas y minúsculas. Si se usan paths y keys juntas, los valores se incluyen si coinciden con al menos una de las opciones. Los valores de array siempre se devuelven a menos que se proporcione la opción skip_array.
paths
Lista separada por comas de rutas de hash a procesar para su extracción, todas las demás rutas se omiten. Las rutas se comparan de forma sensible a mayúsculas y minúsculas. Si se usan paths y keys juntas, los valores se incluyen si coinciden con al menos una de las opciones. Los valores de array siempre se devuelven a menos que se proporcione la opción skip_array.
skip_array
No traducir valores de array.
