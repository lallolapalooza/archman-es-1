NOMBRE

Locale::RecodeData::ATARI_ST_EURO - Rutinas de conversión para ATARI-ST-EURO

SINOPSIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPCIÓN

Este módulo es generado y contiene las tablas y rutinas de conversión para ATARI-ST-EURO.

COMENTARIOS

Los siguientes comentarios han sido extraídos del mapa de caracteres original:

version: 1.1
 source: Guido Flohr E<lt>guido.flohr@cantanea.comE<gt>

NAME

Locale::RecodeData::ATARI_ST_EURO - ATARI ST Euro character set.

SYNOPSIS

 use Locale::RecodeData::ATARI_ST_EURO;

DESCRIPTION

This module provides the ATARI ST Euro character set.

The ATARI ST Euro character set is an 8-bit character set that is ISO 8859-1 (Latin-1) compatible for the first 128 characters, but has additional characters in the upper 128 positions.

COMMENTS

This character set is based on the IBM Code Page 437 (US) but is extended for European languages.
