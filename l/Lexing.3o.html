Posiciones

type position = {
pos_fname : string ;
pos_lnum : int ;
pos_bol : int ;
pos_cnum : int ;
}

Un valor de tipo position describe un punto en un archivo fuente. pos_fname es el nombre del archivo; pos_lnum es el número de línea; pos_bol es el desplazamiento del inicio de la línea (número de caracteres entre el inicio del lexbuf y el inicio de la línea); pos_cnum es el desplazamiento de la posición (número de caracteres entre el inicio del lexbuf y la posición). La diferencia entre pos_cnum y pos_bol es el desplazamiento de caracteres dentro de la línea (es decir, el número de columna, asumiendo que cada carácter ocupa una columna de ancho).

Ver la documentación del tipo lexbuf para obtener información sobre cómo el motor de análisis léxico gestionará las posiciones.

val dummy_pos : position

Un valor de tipo position, garantizado ser diferente de cualquier posición válida.

Buffers Lexer

type lexbuf = {
refill_buff : lexbuf -> unit ;

mutable lex_buffer : bytes ;

mutable lex_buffer_len : int ;

mutable lex_abs_pos : int ;

mutable lex_start_pos : int ;

mutable lex_curr_pos : int ;

mutable lex_last_pos : int ;

mutable lex_last_action : int ;

mutable lex_eof_reached : bool ;

mutable lex_mem : int array ;

mutable lex_start_p : position ;

mutable lex_curr_p : position ;
}

El tipo de buffers lexer. Un buffer lexer es el argumento pasado a las funciones de escaneo definidas por los escáneres generados. El buffer lexer contiene el estado actual del escáner, además de una función para rellenar el buffer desde la entrada.

Los lexers pueden mantener opcionalmente los campos de posición lex_curr_p y lex_start_p. Este modo de "seguimiento de posición" es el predeterminado y corresponde a pasar ~with_position:true a las funciones que crean buffers lexer. En este modo, el motor de análisis léxico y las acciones del lexer son co-responsables de actualizar correctamente los campos de posición, como se describe en el siguiente párrafo. Cuando el modo se deshabilita explícitamente (con ~with_position:false), el motor de análisis léxico no tocará los campos de posición y las acciones del lexer deberían tener cuidado de no hacerlo tampoco; los campos lex_curr_p y lex_start_p contendrán entonces siempre la posición inválida dummy_pos. No rastrear posiciones evita asignaciones y escrituras de memoria y puede mejorar significativamente el rendimiento del lexer en contextos donde lex_start_p y lex_curr_p no son necesarios.

El modo de seguimiento de posición funciona de la siguiente manera. En cada token, el motor de análisis léxico copiará lex_curr_p a lex_start_p, luego cambiará el campo pos_cnum de lex_curr_p actualizándolo con el número de caracteres leídos desde el inicio del lexbuf. Los otros campos son dejados sin cambios por el motor de análisis léxico. Para mantenerlos precisos, deben ser inicializados antes del primer uso del lexbuf, y actualizados por las acciones relevantes del lexer (es decir, en cada fin de línea -- ver también new_line).

val from_channel : ?with_positions:bool -> in_channel -> lexbuf

Crea un buffer lexer en el canal de entrada dado. Lexing.from_channel inchan devuelve un buffer lexer que lee del canal de entrada inchan, en la posición de lectura actual.

val from_string : ?with_positions:bool -> string -> lexbuf

Crea un buffer lexer que lee de la cadena dada. La lectura comienza desde el primer carácter de la cadena. Se genera una condición de fin de entrada cuando se alcanza el final de la cadena.

val from_function : ?with_positions:bool -> (bytes -> int -> int) -> lexbuf

Crea un buffer lexer con la función dada como su método de lectura. Cuando el escáner necesita más caracteres, llamará a la función dada, proporcionándole una secuencia de bytes s y un recuento de bytes n. La función debe colocar n bytes o menos en s, comenzando en el índice 0, y devolver el número de bytes proporcionados. Un valor de retorno de 0 significa fin de entrada.

val set_position : lexbuf -> position -> unit

Establece la posición de entrada inicial rastreada para lexbuf a un valor personalizado. Ignora pos_fname. Ver Lexing.set_filename para cambiar este campo.

Desde 4.11

val set_filename : lexbuf -> string -> unit

Establece el nombre de archivo en la posición inicial rastreada a file en lexbuf.

Desde 4.11

val with_positions : lexbuf -> bool

Indica si el buffer lexer realiza un seguimiento de los campos de posición lex_curr_p / lex_start_p, según lo determinado por el argumento opcional correspondiente para las funciones que crean buffers lexer (cuyo valor predeterminado es true).

Cuando with_positions es false, las acciones del lexer no deben modificar los campos de posición. Hacerlo de todos modos podría reactivar el modo with_position y degradar el rendimiento.

Funciones para acciones semánticas de lexer

Las siguientes funciones pueden ser llamadas desde las acciones semánticas de las definiciones de lexer (el código ML encerrado entre llaves que calcula el valor devuelto por las funciones de lexing). Dan acceso a la cadena de caracteres coincidente con la expresión regular asociada a la acción semántica. Estas funciones deben aplicarse al argumento lexbuf, que, en el código generado por ocamllex, está vinculado al buffer lexer pasado a la función de análisis.

val lexeme : lexbuf -> string

Lexing.lexeme lexbuf devuelve la cadena coincidente con la expresión regular.

val lexeme_char : lexbuf -> int -> char

Lexing.lexeme_char lexbuf i devuelve el carácter número i en la cadena coincidente.

val lexeme_start : lexbuf -> int

Lexing.lexeme_start lexbuf devuelve el desplazamiento en el flujo de entrada del primer carácter de la cadena coincidente. El primer carácter del flujo tiene el desplazamiento 0.

val lexeme_end : lexbuf -> int

Lexing.lexeme_end lexbuf devuelve el desplazamiento en el flujo de entrada del carácter siguiente al último carácter de la cadena coincidente. El primer carácter del flujo tiene el desplazamiento 0.

val lexeme_start_p : lexbuf -> position

Similar a lexeme_start, pero devuelve una position completa en lugar de un desplazamiento. Cuando el seguimiento de posición está deshabilitado, la función devuelve dummy_pos.

val lexeme_end_p : lexbuf -> position

Similar a lexeme_end, pero devuelve una position completa en lugar de un desplazamiento. Cuando el seguimiento de posición está deshabilitado, la función devuelve dummy_pos.

val new_line : lexbuf -> unit

Actualiza el campo lex_curr_p del lexbuf para reflejar el inicio de una nueva línea. Puedes llamar a esta función en la acción semántica de la regla que coincide con el carácter de fin de línea. La función no hace nada cuando el seguimiento de posición está deshabilitado.

Desde 3.11

Funciones varias

val flush_input : lexbuf -> unit

Descarta el contenido del buffer y restablece la posición actual a 0. El próximo uso del lexbuf activará un rellenado.

NOMBRE

Lexing - Análisis léxico básico para OCaml.

Módulo

Lexing

Documentación

Este módulo proporciona las funciones y tipos básicos para el análisis léxico en OCaml.

Se utiliza para crear analizadores léxicos que escanean la entrada de texto y la dividen en una secuencia de "tokens". Los tokens son las unidades básicas que un analizador sintáctico utiliza para construir una estructura de datos (como un árbol de sintaxis abstracta).

lexbuf

Un tipo que representa el buffer de entrada para el analizador léxico. Contiene la cadena de entrada, la posición actual en la cadena, y otra información necesaria para el análisis léxico.

position

Un tipo que representa una posición en el buffer de entrada, incluyendo el número de línea y la posición dentro de la línea.

set_position

Función para establecer la posición inicial del buffer léxico.

new_line

Función para registrar un salto de línea en el buffer léxico, actualizando las estadísticas de línea y columna.

lexeme_start

Devuelve la posición de inicio del lexema actual (el token que se está analizando).

lexeme_end

Devuelve la posición de fin del lexema actual.

lexeme_char

Devuelve el carácter en una posición dada dentro del lexema actual.

Engine.lexbuf_from_string

Crea un buffer léxico a partir de una cadena.

Engine.lexbuf_from_channel

Crea un buffer léxico a partir de un canal de entrada (como un archivo o la entrada estándar).

El módulo Lexing es fundamental para construir compiladores e intérpretes en OCaml, ya que proporciona las herramientas para procesar la entrada de texto de manera estructurada.
