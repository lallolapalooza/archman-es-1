DOCUMENTACIÓN

Módulo Local_store
: sig end

Este módulo proporciona algunas facilidades para crear referencias (y tablas hash) que se pueden guardar y restaurar fácilmente a una versión arbitraria.

Se utiliza en todo el frontend (es decir, el verificador de tipos) para registrar todo el estado global (bueno, con suerte). Esto facilita que herramientas como Merlin vayan y vuelvan para verificar diferentes archivos.

CREADORES

val s_ref : 'a -> 'a ref

Similar a ref , excepto que la referencia asignada se registra en el almacén.

val s_table : ('a -> 'b) -> 'a -> 'b ref

Se utiliza para registrar tablas hash. Estas también necesitan ser colocadas en refs para poder ser intercambiadas fácilmente, pero no se puede simplemente "guardar" el valor inicial para crear instancias nuevas, por lo que se requiere un inicializador.

Úsalo de esta manera:

      let my_table = s_table Hashtbl.create 42

GESTIÓN DE ESTADO

Nota: todas las siguientes funciones no se utilizan actualmente en el código fuente del compilador. Merlin es su único usuario en este momento.

type store

val fresh : unit -> store

Devuelve una nueva instancia del almacén.

La primera vez que se llama a esta función, guarda el valor de todas las referencias registradas, las llamadas posteriores a fresh devolverán instancias inicializadas con esos valores.

val with_store : store -> (unit -> 'a) -> 'a

with_store s f restablece todas las referencias registradas al valor que tienen en s durante la ejecución de f . Si f actualiza alguna de las referencias registradas, s se actualiza para recordar esos cambios.

val reset : unit -> unit

Restablece todas las referencias a la instantánea inicial (es decir, a los mismos valores con los que comienzan las nuevas instancias).

val is_bound : unit -> bool

Devuelve true cuando hay un almacén activo (es decir, cuando se llama desde la devolución de llamada pasada a Local_store.with_store ), false en caso contrario.
