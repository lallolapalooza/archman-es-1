NOMBRE

Lire::Config::ConfigFile - Clase para la manipulación de archivos de configuración.

SINOPSIS

use Lire::Config::ConfigFile;

DESCRIPCIÓN

Objeto que representa un archivo de configuración de Lire.

new( 'nombre_archivo' => $archivo, espec => $espec_config )

Crea un nuevo objeto Lire::Config::ConfigFile. El constructor toma dos parámetros:

nombre_archivo
El archivo desde donde se almacenó o cargó la configuración.
espec
El objeto Lire::Config::TypeSpec al que se adhiere esta configuración.

nombre_archivo( [%s_nuevo_nombre_archivo_] )

Devuelve (y opcionalmente cambia) el nombre del archivo donde debe almacenarse este archivo de configuración.

espec()

Devuelve el objeto Lire::Config::TypeSpec al que se adhiere este archivo de configuración.

global( [ $config] )

Devuelve o modifica la parte de configuración 'global' del archivo. Esta es una instancia del objeto Lire::Config::Compound.

guardar()

Guarda este objeto ConfigConfigFile de nuevo en el nombre de archivo desde el cual fue cargado.

revertir()

Vuelve a leer la configuración desde el archivo.

como_valor()

Devuelve este archivo de configuración como una referencia hash. Delega al objeto de configuración global contenido en el archivo.

obtener( $nombre )

Devuelve el parámetro de configuración $nombre de este archivo de configuración. Delega al objeto de configuración global contenido en el archivo.

esta_establecido( $nombre )

Comprueba que un parámetro de configuración está establecido en este archivo. Delega al objeto de configuración global contenido en el archivo.

establecer( $param )

Establece una variable de configuración en el archivo. Delega al objeto de configuración global contenido en el archivo.
