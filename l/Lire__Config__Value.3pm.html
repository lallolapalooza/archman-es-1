NOMBRE

Lire::Config::Value - Contenedores de valor de Lire para variables de configuración

SINOPSIS

use base qw/ Lire::Config::Value /;

DESCRIPCIÓN

Contenedores de valor para variables de configuración. Esta es la superclase abstracta para las otras clases de Lire::Config::Value.

nuevo( ['espec' => $espec], ... )

Este es el constructor para el objeto de valor. Los objetos de Lire::Config::Value deben instanciarse desde el método instancia() definido en el objeto TypeSpec.

nombre()

Devuelve el nombre de este parámetro de configuración.

espec()

Devuelve la especificación para este parámetro.

resumen()

Devuelve el resumen de la especificación para este valor.

descripción()

Devuelve la descripción de la especificación para este valor.

descripción_texto()

Devuelve la descripción de la especificación (formateada en texto plano) para este valor.

como_valor()

Devuelve este valor como un valor nativo de perl. Este será un valor escalar, o referencias de hash o array. Los valores devueltos deben normalizarse.

como_etiqueta()

Devuelve la etiqueta de este objeto para mostrarlo en interfaces gráficas.

como_variable_shell()

Devuelve el valor de esta variable de configuración en un formato que puede ser evaluado en un script de shell.

clonar()

Devuelve una copia profunda de esta instancia. Se mantiene la referencia a la especificación, pero no se copia.

es_igual_a( $param )

Devuelve si la instancia $param es idéntica a esta.

es_valido()

Comprueba que el valor actual es válido de acuerdo con la especificación.

es_por_defecto()

Devuelve verdadero si este valor es igual a su valor por defecto en la especificación.

guardar_xml( $fh )

Escribe una configuración XML de la variable recursivamente en $fh.
