NOMBRE

Locale::RecodeData::ISO_8859_6 - Rutinas de conversión para ISO-8859-6

SINOPSIS

¡Este módulo es interno a libintl! ¡No lo use directamente!

DESCRIPCIÓN

Este módulo se genera y contiene las tablas y rutinas de conversión para ISO-8859-6.

COMENTARIOS

Los siguientes comentarios se han extraído del mapa de caracteres original:

version: 1.0
 source: ECMA registry
alias ISO-IR-127
alias ISO_8859-6:1987
alias ISO_8859-6
alias ECMA-114
alias ASMO-708
alias ARABIC

¡Tenga en cuenta que los alias listados anteriormente no son necesariamente válidos!

NAME

Locale::RecodeData::ISO_8859_6 - Arabo (ISO 8859-6) to Unicode mapping

SYNOPSIS

  use Locale::RecodeData::ISO_8859_6;
  # or
  use Locale::Recode 'ISO_8859_6';

DESCRIPTION

This module provides the mapping between the ISO 8859-6 character set and Unicode. It is intended to be used with the Locale::Recode module.

ISO 8859-6 is an older standard for encoding Arabic characters. Unicode provides a more comprehensive and standardized way to represent characters from all languages.

COMMENTS

The ISO 8859-6 character set is a superset of ASCII. Characters in the range 0x00-0x7F are identical to ASCII.

This module uses the following mapping:

    0xEA  ARABIC LETTER ALEF MAKSURA
    0xEB  ARABIC FATHATAN
    0xEC  ARABIC DAMMATAN
    0xED  ARABIC KASRATAN
    0xEE  ARABIC FATHA
    0xEF  ARABIC DAMMA
    0xF0  ARABIC KASRA
    0xF1  ARABIC SHADDA
    0xF2  ARABIC SUKUN
