NAME Documentación de usuarios de Perl contribuida Locale::RecodeData::IBM905(3)

NAME

Locale::RecodeData::IBM905 - Rutinas de conversión para IBM905

SYNOPSIS

Este módulo es interno a libintl. ¡No lo uses directamente!

DESCRIPTION

Este módulo es generado y contiene las tablas de conversión y rutinas para IBM905.

COMMENTS

Las siguientes observaciones se extrajeron de la charmap original:

 versión: 1.0
 fuente: IBM 3174 Character Set Ref, GA27-3831-02, Marzo 1990
 alias: CP905
 alias: EBCDIC-CP-TR

Nota: ¡los alias mencionados anteriormente no son necesariamente válidos!

Locale::RecodeData::IBM905(3pm) — Arch Linux

NAME

Locale::RecodeData::IBM905 - Perl module for character encoding conversion. It defines the character set IBM905.

SYNOPSIS

 use Locale::RecodeData::IBM905;

DESCRIPTION

This module provides the definition of the character set IBM905 (also known as CP037).

The Locale::Recode module uses this definition to convert strings to and from the IBM905 encoding.

COMMENTS

The character set IBM905 is an EBCDIC character set used on IBM mainframes.
